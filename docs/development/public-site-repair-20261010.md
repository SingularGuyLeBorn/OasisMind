## 渲染与发布防线

两版复用的 Markdown 管线在 raw HTML 建树之后识别表格文字中的数学片段, 然后经过原有安全清洗和 KaTeX 渲染. 跳过代码块、代码行和已解析数学节点, 不把普通金额转换为公式. 增加表格公式、代码与金额、危险属性清洗的回归测试.

公开构建按当前发布清单检查正文、摘要、知识库首页与关于页中的 KaTeX 错误和裸露数学命令. 代码示例与无障碍数学节点不误报. 旧路径缓存不计入验收, 清单中文件丢失直接失败. 正文含 NUL 或工具截断标记时停止发布. 无效 frontmatter 也停止构建, 不再静默跳过文章. 增加清单隔离、摘要错误、裸露数学命令和正文缺失的回归测试.

## 配图显示复核

综合浏览器检查发现, 标点整理把图片标记拆成了 `! [说明](路径)`, 部分译稿的相对路径还变成了 `. /images`. 文件格式验证能确认图片没坏, 但不能证明页面真的生成了 `<img>`. 恢复完整 Markdown 图片语法, 同时修正引用中被拆开的网址与路径. 正文经 PostService 更新, 知识库首页修订后同步 Garden 缓存.

DeepSeek LLM 与 Coder-V2 两份译稿存在缺失的旧图片文件. 分别从 [DeepSeek LLM 原论文](https://arxiv.org/pdf/2401.02954) 与 [Coder-V2 原论文](https://arxiv.org/pdf/2406.11931) 恢复 14 个和 3 个图页, 专库与 model-library 使用同一批 PNG. Coder-V2 Figure 1 单独裁出完整图表、图例与图注; 其它页面保留原图页. 同页重复引用合并, 不改实验数字, 不重画无法核对的曲线.

恢复配图后的 101 份正文生成 810 个 `<img>`, KaTeX 错误为 0; 补齐两份 R1 参考文献网址后, 全库 1,690 份 Markdown 通过源稿检查. 新恢复的 17 个 PNG 解码验证通过. 全库 files、links、frontmatter、markers 检查通过.
