# 公开站发布

## 2026-10-09 静态阅读优化

首页、知识库卡片、资源、真实个人资料与搜索共用一组公开导航。资源区新增 5 篇已发布文章；公开集合为 1617 篇文章、21 个主题知识库及资源区。草稿、私人批注与 Agent 服务仍不发布。

文章和首页在构建时用共享 Markdown 管线预排版，初始 HTML 包含正文、公式、左侧文章树和右侧页内目录。目录树、锚点和数学竖线处理与本地工作台共用实现。浏览器只加载搜索、分页和目录高亮所需的小控件，不启动 Next 客户端路由，不再下载文章 JSON 后重新排版全文。清理的是框架脚本及路由副本，不是文章内容。

完整搜索索引按需读取，支持标题、标签、分类、综合字段、多关键词与知识库筛选。文章列表每页 24 篇，索引读取失败可手动重试。桌面双侧目录固定在正文两旁；手机保留可收起的目录。折叠图标使用细线图标，移除原生黑色三角。无脚本时正文、公式、目录与普通链接仍可使用。

本次按用户确认先交付静态界面；跨设备保存划线和评论需要后端，未接入，也没有提供假保存按钮。本地原有私人批注不受影响。

本地验收：site lint 与 15 项测试、共享包 lint/test、web lint 与 393 项测试、server lint 与公开投影 13 项测试通过；完整静态构建和上传产物审计通过。浏览器验证 1280px、390px、无脚本阅读、实际搜索分页、目录跳转、资源和个人资料；另验证搜索 HTTP 503 后重试恢复。

全量扫描发现 39 篇旧稿仍有原始 TeX 格式问题，清单见 [旧稿公式格式待核对](public-site-rendering-issues.md)。本次修复确定的通用格式问题，未猜测或改写损坏公式，不声称全站公式零错误。原有 3 篇 YAML 错误稿仍安全跳过。

## 部署边界

`apps/site` 是公开知识库博客；`apps/web` 与 `apps/server` 是本地 Agent 工作台。公开站只部署 `apps/site/out`，不上传 SQLite、环境变量、Cookie、私人批注、工作空间或 Agent 服务。

部署使用 `.github/workflows/deploy-public-site.yml`，在 `master` 更新公开内容或站点代码时构建，也支持手动触发。构建采用 Node.js 24 与 pnpm 11.9.0。Pages 项目路径由平台提供，文章、资源、搜索、Feed 与 sitemap 共用同一个路径前缀。

## 发布验收

推送前检查工作区、内容链接、公开站 lint/test、生产构建及上传产物。上线后检查 HTTPS 首页、知识库、搜索、文章、公式、图片、JSON/Markdown、Feed、sitemap、404 与桌面/手机视口。部署成功和实际访问成功分别记录。

本地 Agent 工作台不在本次公网部署范围。公开站可供访客与外部 Agent 只读访问，这与具有工具权限的本地 Agent 工作台不同。
