# FlexAttention 候选图提示词

实际使用内置 ImageGen, 接口未提供可核验模型版本. 白底横版科研教学图, 深蓝、青绿、橙色, 矩形规整, 无卡通装饰, 无冗余双语标签.

标题: FlexAttention：从元素规则到块工作表. 参数: 长度8, 因果窗口W=4, 块大小2×2, 位置从0开始.

左侧为8×8布尔矩阵, 行query i、列key j, 每两行/列加粗块边界. 逐行数据为10000000、11000000、11100000、11110000、01111000、00111100、00011110、00001111. 允许条件j≤i且i−j<4.

中间为4×4三态块表, 行列标签0–1、2–3、4–5、6–7. 四行依次为部分/跳过/跳过/跳过, 全满/部分/跳过/跳过, 部分/全满/部分/跳过, 跳过/部分/全满/部分. 全满仍计算注意力, 无需逐元素mask;部分逐元素过滤;跳过不执行.

右侧放大query4–5,key0–1的部分块, 数据[0,1;0,0];以及query4–5,key2–3的全满块[1,1;1,1]. 不加无意义箭头.

底部:26条合法边,执行9个块覆盖36个元素,跳过7个块;部分块内10个非法元素在softmax前过滤. 图内不放来源或制作说明, 不编造数值.
