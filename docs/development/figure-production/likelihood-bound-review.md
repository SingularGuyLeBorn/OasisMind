# 似然与似然界教学图

## 来源与计算

机制依据为MDLM v2 §2.1、§3.3–3.5: https://arxiv.org/html/2406.07524v2 . AR条件概率连乘可计算文本概率;离散扩散对潜在去噪轨迹求和, ELBO不大于对数似然, 因而负ELBO不小于NLL. 本图为机制教学, 未作为论文原图重绘. 每token NLL=2与负ELBO=2.3为自设教学数值, 复算e²约7.39、e²·³约9.97, 界差距0.3;不作为实验结果.
