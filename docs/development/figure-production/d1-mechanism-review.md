## v1 实际查看结果

保留多步生成与一步估计的分区、全掩码回答区、提示独立遮盖、三模型同输入和只更新当前模型等结构. 本版仅为候选, 尚未进入正文.

修正后才能验收:

1. 回答组大小误写成 M, 应统一为 G. M 仅表示 MASK. 表格末行和顶部回答数量同改.
2. 按已生成答案取概率的连线从参考模型框出发, 应改从批次表的生成答案列出发, 到达三个预测分布的取值操作. 答案不能作为预测器的可见回答输入.
3. 参考 KL 缺少当前模型概率的明确输入, 应同时接入当前与参考概率.
4. 批次表中的优势应明确连接下方优势输入, 当前悬置的 A_i 框需要补全来源.
5. 提交顺序示例应完整结束为 A B C D, 当前底部看似只有 A B C, 需要检查并补足第四格.
6. 顶部提示连线应明确进入多步去噪的条件输入, 不能只连向掩码初始状态而省略条件作用.

修订后需再次查看公式、连接端点及正文宽度预览. 未完成实际文章渲染与移动端验收, 不认定本图或本篇完成.

## v2–v4 修订复核

三个版本均实际查看, 保留各版候选, 未进入正文. v2 修正组大小和完整 ABCD 示例, 但仍从参考模型框取答案, 且更新箭头分支指向取值操作. 改用纵向布局生成 v3, 分开展示逐位置词表分布与按已生成 token 取值. v3 的概率比被错误生成成加法, 优势连线从提示出发, 共同输入未接扰动提示, KL 使用旧模型而非当前模型概率.

v4 局部修正概率比为分式, 优势外侧连线改从优势框出发. 仍有三项阻止正式采用: KL 左输入继续来自旧模型概率;扰动提示到共同输入之间存在断线;顶端优势输出长线穿过奖励节点边界. 需保持已正确的概率比、模型冻结关系、全掩码回答区与取值操作, 单独修正这些连接. 纵向版在完整正文宽度及移动端尚未预览.

修订提示词: `d1-edit-v2.txt`, `d1-mechanism-v3-prompt.txt`, `d1-edit-v4.txt`. 使用内置生图, 模型版本仍不可确认. 此记录是候选复核, 不作为本篇或知识库配图完成证明.
