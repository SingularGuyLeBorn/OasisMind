## 手算与正文

对照 ParallelBench v1 §4.2.2 与 Table 1, 修正「两个任务高准确率阈值区间为空」的错误. n>2时, gamma不小于(n−1)/n同时满足Shuffle的gamma>0.5;配合无人通过时提交最高置信位置的回退规则, 理想模型两项准确率均为1, 但退回逐位置生成. 共同正确不代表共同保留并行收益. 来源:https://arxiv.org/html/2510.04767v1 .

括号教学分布已改为 `()`、`[]` 各0.5. 两个边际熵各1 bit, 联合熵1 bit, 总相关1 bit;独立采样四种组合各0.25, 合法率0.5, 真实条件采样合法率1. argmax的并列选择与随机采样分别解释. 后续图使用这组明确标识的教学数值, 不作为论文实验结果.
