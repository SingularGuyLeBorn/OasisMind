来源：节点记法参照 Sutton、Barto [《Reinforcement Learning: An Introduction》第 2 版，Figure 3.4](https://www.incompleteideas.net/book/bookdraft2018mar21.pdf)（PDF 第 86 页，阅读器从 0 起算的第 85 页）。该图的空心圆表示状态，实心圆表示状态—动作节点。本站图中的 $A,B,T$、奖励、转移概率与迭代数值为文章中的原创教学例子，绝非教材实验数据或 Figure 3.4 的逐像素复刻。制作前检查了教材原图和本篇同步 Bellman 更新公式。

生成方式：Codex 内置 `image_gen`，2026-10-11；工具没有返回可核对的具体模型版本，所以不标称 Image 2.5。以教材原图页面和仓库科学图风格参考图作为视觉参考，生成白底高对比 PNG。首版的 `loop` 箭头错误地指回动作节点，第二版又漏了 $B\to loop$ 边；最终版分别补上 $B\to loop\to B$，并复核全部边的起点与终点。

数学核对：固定策略下 $V_{k+1}(B)=2.5+0.25V_k(B)$，故 $V_0(B)=0,V_1(B)=2.5,V_2(B)=3.125$，不动点为 $10/3$。$A$ 在第二轮读取上一轮 $V_1(B)$，得到 $V_2(A)=1.3125$；$V_3(A)=1.546875$。$T$ 始终为 0。绿色回传箭头表示一次同步备份的计算依赖，环境转移另用深色箭头绘制。

配图作用：把「后继状态的价值下一轮才影响前驱」放到同一张图上，读者能把递归公式、表格迭代与转移方向一一对应。最终检查：PNG 真正可打开；状态、动作节点与自环可辨；数字与正文一致；没有悬空边。
