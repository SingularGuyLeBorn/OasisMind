# 见微 · 用户交互剧本（全场景）

> 给产品验收、E2E、自己走查用。  
> 每个场景写的是**人坐在屏幕前会经历的顺序**，不是内部变量表。  
> 变量级断言见 [`user-action-contracts.md`](./user-action-contracts.md)（契约 ID 如 `C-S1-A1`）。  
> Agent 该调什么工具见 [`scenarios.md`](./scenarios.md)。  
> 状态机见 [`chat-scenario-states.md`](./chat-scenario-states.md)。

**读法**：每步先写「你做什么」，再写「屏上必须接着发生什么」。若某步没发生，就是这个场景坏了，不要用「刷新一下」当修复。

六部：Chat 核心 → 审批与定时 → 知识库 → 能力向 → 组合旅程 → **身份 / QQ / 语音 / 多模态 / 文件**。文末是测试、时序、偶发、模块化、DSH 的诚实账，不是进度粉饰。

## 0. 全场通用：你眼睛里的坐标系

打开 `/chat` 后，默认记住这些位置，后面不再重复解释。

| 位置 | 你看到的 | 含义 |
|---|---|---|
| 对话区**右侧** | 用户气泡，无角标 | 你手打的 |
| 对话区**右侧** + 角标「Async · …」 | 投递气泡 | 后台子 Agent / 异步任务回报，**不是**你打的 |
| 对话区**右侧** + 角标「父 Agent」 | 子会话里的任务 | 上级派下来的，不是你在子会话手打 |
| 对话区**右侧** + 角标「定时节律」 | cron 写进会话的消息 | 不是你打的 |
| 对话区**右侧** + 角标「来自子 Agent」 | `notify_parent` | 子主动汇报进度 |
| 对话区**左侧** | 助手气泡 | 当前 Agent 的话 |
| 左侧气泡上方时间线 | 工具条 `tool-pill` | 搜索/派工/读文等，**不是**独立聊天气泡 |
| 工具条绿点 | 成功 | 可以当这件事做成了 |
| 工具条红点 + 红字「失败」 | 失败 | 禁止当成成功 |
| 工具条「运行中」 | 还在跑 | 禁止出现绿点 |
| 输入框上方「待发消息 N」 | 队列 | 折叠时**看不到**正文；点「点击展开」才看到 |
| 输入框上方提问卡 | Agent 在问你 | 点选项或提交后变成「已提交答复」 |
| 中栏一条「后台任务 N」 | 派工条 | 点「打开运行栏」去左栏看卡片 |
| 顶栏 Goal / 调研 / 自治 | 进行中目标 | 超长先截断，点「展开」看全文 |
| 发送钮变成「停止生成」 | 本轮占用中 | 点它是中断，不是再发一条 |

**全场禁止出现的交付文案**：`刷新一下` / `请刷新页面` / `刷新后再试`。开着的页必须自己动；F5 只是再水合，不是修复手段。

**气泡左右铁律（再读一遍）**

- 同步 `spawn_subagent(waitForResult=true)`：父会话**只有**工具条 + 左侧父总结，**没有**右侧 Async 投递角标。
- 异步 `waitForResult=false` / `async_task_run`：父可以先结束；结果回来后右侧出现带角标的投递，父再在左侧总结。
- 工具过程永远不是聊天气泡。

## 第一部 · Chat 核心

### 场景 1 · 普通对话（不调工具）

**一句话**：你问一句闲话，右侧立刻是你，左侧慢慢长出回答，没有工具条、没有待发、没有角标。

**前置**：`/chat` 已就绪，输入框可点，发送钮是「发送」不是「停止」。

**交互过程**

1. 你在输入框打「你好」（或「用三句话说明本地优先，不要搜网」），点发送。  
   → 输入框立刻变空。发送钮变成停止。右侧马上出现你的气泡，内容就是刚才那句，贴在右边，**没有**来源角标。
2. 你盯着左侧。  
   → 很快出现流式助手气泡（字往外长），或 Mock 下不到 1 秒就定格成终态左侧气泡。时间线里可以有 Thinking，**不能**出现 `web_search` / `spawn_subagent` 工具条。
3. 你什么都不点，等它说完。  
   → 流式气泡消失，左侧定格一篇完整回复。发送钮变回「发送」。输入框上方**没有**「待发消息」。
4. 你按 F5。  
   → 短暂骨架后，同一会话里左右两条都在，原文一字不差。不会重跑一遍、不会冒出工具条。
5. 你点左栏「新对话」，在新会话里随便再发一条（甚至触发搜索）。再回到原来的会话。  
   → 旧会话仍是「你好」那一轮；新会话的搜索工具条**不会**出现在旧会话。
6. 你从旧会话点进 `/agents`，再按地址回到 `/chat?sessionId=原来的`。  
   → 「我的 Agents」页先出现；回来气泡还在，不是空会话。

**结束你应看到**：一右一左；你的话在右；回答在左。  
**你不应看到**：待发面板闪一下；角标；工具条；空白当修复。  
**契约**：`C-S1-A1`～`A6`

### 场景 2 · 同步工具（搜索 / 读文）

**一句话**：你要出处，时间线先跑工具，成功绿点、失败红点，最终回答仍在左侧。

**前置**：同场景 1，会话空闲。

**交互过程**

1. 你发送「搜索 OasisMind 并一句话介绍」（或「搜索 React 19 相对 18 的变化，列出处」）。  
   → 右侧出现你的问句。左侧时间线出现工具条，名字是搜索类（界面显示 `WebSearch`，标记 `data-tool=web_search`）。
2. 工具还没返回时你盯着这条。  
   → 工具条状态是 running：有「运行中」、脉冲点。**没有**绿点，**没有**红字「失败」，**没有**耗时 hint（hint 只在结束时出现）。
3. 工具成功结束。  
   → 工具条变 done，绿点，hint 是耗时/引擎一类，**不含**「失败」。然后左侧助手开始写「本地优先」或带链接的要点。工具 JSON **不会**变成一条你的用户消息。
4. 若你发的是「读取文章 https://example.com/broken」。  
   → 工具条是 `read_article`，结束时红点 + 红 hint「失败」。**没有**绿点假装读到了。
5. 失败（或成功）之后你 F5。  
   → 时间线直接是终态（红或绿），**不会**重新变成「运行中」，也不会再打一次网。

**结束你应看到**：问在右，工具条在左时间线，答在左。  
**你不应看到**：右侧 Async 角标（这不是子 Agent 投递）；失败变绿。  
**契约**：`C-S2-A1`～`A5`

### 场景 3 · 同步派生子 Agent（你愿意干等）

**一句话**：你说「这次同步等它跑完」。父会话转圈到子结束，你只在左侧看到父整合后的话。

**前置**：选中 assistant（或能 spawn 的管理/超级 Agent）。左栏可切到「对话历史 → 子 Agent」。

**交互过程**

1. 你发送「派一个资料员调研……这次同步等它跑完」（Mock：`派子 Agent 慢速总结`）。  
   → 右侧是你的指令。左侧出现 `spawn_subagent` 工具条，长时间 running。父**不会**先胡编一篇「调研结论」。
2. 子在跑时，你点左栏「子 Agent」。  
   → 侧栏从「当前 Workspace 暂无子 Agent」变成出现同名卡片。**不必 F5**。
3. 子跑完。  
   → 工具条变 done。左侧父气泡出现「已收到子 Agent 结果」并给出整合建议。  
   → 父会话**没有**右侧「Async ·」投递角标。子的过程在子会话里，不在父会话变成一串气泡。
4. 你点进子会话看一眼。  
   → 右侧第一条任务带角标「父 Agent」；左侧是子自己的话；你在子会话手打没有角标，也**不会**自动打回父会话。
5. 你回到父会话按 F5。  
   → spawn 工具条终态 + 父总结还在，不会空白、不会重派一个子。

**结束你应看到**：父同一轮里先工具条后总结；侧栏有子。  
**你不应看到**：父右侧投递气泡；必须刷新才出子卡片。  
**契约**：`C-S3-A1`～`A4`

### 场景 4 · 异步派子 / 后台任务（你先别干等）

**一句话**：你说「跑完告诉我，你先别干等」。父先短答，你能继续打字；结果自己回来。

**前置**：父会话空闲。

**交互过程（非阻塞子 Agent）**

1. 你发送「派个子 Agent 去调研，跑完告诉我；你先一句话说派了谁」。  
   → 右侧你的话。左侧很快短回复「已派某某」。`spawn_subagent` 工具条很快 done（只表示派生成功，不是调研结束）。
2. 父流结束后。  
   → 发送钮恢复，你**可以**继续跟父聊天。中栏可能出现「后台任务 N」，左栏「运行」里有进行中卡片。
3. 子自己 `report_back` 之后（你开着父会话、不刷新）。  
   → 右侧冒出一条带 **Async** 角标的投递（名字/任务标签）。父再在左侧写一版总结。  
   → 全程你不用 F5。
4. 你 F5。  
   → 那条右侧 Async 角标还在，不会变成普通手打。

**交互过程（纯工具后台 `async_task_run`）**

1. 你发送「请启动一个后台任务总结当前项目」或「后台统计 posts 下有多少 md」。  
   → 父短答「已入队」。左栏运行出现进度。父流结束，你能继续打字。
2. 任务完成后。  
   → 投递进父会话；助手再多一条，用一句话报结果，不把整段 shell 日志当正文（除非你要）。来源是工具/Async，不是「子 Agent 回报」那种人名（没有子）。
3. 最终至少两条左侧助手：先「已启动」，后「结果」。

**结束你应看到**：父不卡死；结果自己出现。  
**你不应看到**：父一直转圈到后台跑完才让打字（那是场景 3）；轮询 `async_task_status` 刷屏。  
**契约**：`C-S7-A1`～`A3`，派工条 `C-S18-A2`

### 场景 5 · 流式中连发（队列）

**一句话**：第一句还在答，你又打第二、第三句；每句都有完整回答，不合并成一条。

**前置**：已发出问题 A，发送钮已是「停止生成」。

**交互过程**

1. 你再打「问题 B」点发送。  
   → 输入框清空。A 的流式**不停**。输入框上方出现「待发消息 1 · 点击展开」。  
   → **折叠时看不到「问题 B」正文**，也不能把 B 当成已经出现的左侧回答。
2. 你点「点击展开」。  
   → 才看到 B 的正文（可改、可删、可排序）。仍然没有 B 的助手气泡。
3. 你再发「问题 C」。  
   → 待发变成 2。A 仍在流。
4. 你什么都不点，等。  
   → A 结束后待发少一条，右侧出现 B 的用户气泡，左侧完整答 B；再轮到 C。最后是 3 问 3 答。流式气泡归零。待发面板消失。
5. 若 A 还在流时你空闲再发——不对，空闲直发**不应**闪「待发消息」。只有占用中才出面板。

**结束你应看到**：问与答条数一致。  
**你不应看到**：只答了第一条；三条合成一条假装答完；折叠态就把 B 画成助手。  
**契约**：`C-S4-A1`～`A3`

### 场景 6 · 停止生成

**一句话**：点停止就停，半成品留下并标明「已停止生成」，发送钮马上能再用。

**交互过程**

1. 你已发送，钮是「停止生成」。点它。  
   → 字不再往外长。钮变回「发送」。
2. 若已经落库半成品。  
   → 左侧气泡留下已写出的字，底下琥珀色「已停止生成」。这不是一篇完整成功答复。
3. 若还没有任何助手行。  
   → 流式区收掉，你立刻可以再发，页面不假死。
4. 你 F5。  
   → 半成品若已落库还在，仍带中断含义；不会自动续写成一篇完整论文。

**结束你应看到**：停得干脆，能再发。  
**你不应看到**：卡在转圈必须刷新；停止后却又长出一篇假装答完。  
**契约**：`C-S5-A1`～`A4`

### 场景 7 · 流还没结束就刷新 / 切走

**一句话**：F5 或切到别的会话再回来，最终结果还在，不是只剩 Thinking。

**交互过程**

1. 你发出长任务（慢速 spawn 或长文），在「还没说完」时按 F5。  
   → 骨架后回到同一会话。用户气泡在。随后续上或直接出现最终助手/工具终态。  
   → 不会整页空白，不会教你「再刷新一次」。
2. 你在 A 会话流式中点「新对话」看 B，再回到 A。  
   → A 的字还在长或已经定格；B 的 begin **不会**把 A 洗成空。
3. 子 Agent 还在跑时你刷新父会话。  
   → 派工条/工具条还在，子结束后父仍能收到结果（同步路径）或投递（异步路径）。

**契约**：`C-S6-A1` `C-S6-A2`，子续传见既有 resume E2E

### 场景 8 · 两个标签同一会话

**一句话**：标签 B 发送，标签 A 自己出现气泡。

**交互过程**

1. 标签 A、B 打开同一个 `sessionId`。你在 B 打「跨标签你好」发送，等结束。A **不刷新**。  
   → A 右侧出现同一句，左侧出现助手。
2. A 全程没有「去刷新另一个标签」的提示。

**契约**：`C-S12-A1`

### 场景 9 · 重试 / 重新生成 / 编辑

**一句话**：从哪条重来，那条后面的旧轮全部消失，再长出一轮新的。

**交互过程**

1. **重新生成**：悬停最后一条助手，点重新生成。  
   → 该用户问题之后的旧助手（以及更后面误留的轮）从列表消失。新的流式助手出现。不会旧+新叠两条。
2. **重试**：悬停某条用户气泡点重试。  
   → 从这条开始重跑，后面的全没。不会出现「A 消失、后面的 B 却重发」的错位。
3. **编辑 Markdown**：点编辑，改源码，点保存。  
   → 气泡换成新正文。点取消则回到旧文，不写库。编辑用户消息则按删尾重发。

**契约**：`C-S9-A1`～`A3`

### 场景 10 · Agent 问你（ask_user）

**一句话**：输入框上方出现问题卡，你点完它就变成「已提交」，Agent 继续。

**交互过程**

1. Agent 需要你拍板时。  
   → 输入区上方出现提问卡：问题正文 + 编号选项 +「自定义回答」输入 +「提交」。这不是普通左侧气泡。
2. 你点「1. knowledge」。  
   → 提问卡变成绿底「已提交答复，Agent 继续中…」。选项消失，不能再点出第二个答案。随后助手续跑。
3. 你改走输入框打字点提交。  
   → 同样进入已提交态。
4. 你用邮件回复了，Chat 开着。  
   → 卡上出现「已收到邮件回复并填入答复框」，你不用再点提交。

**契约**：`C-S25-A1`～`A3`

### 场景 11 · 工具失败的三种脸（权限 / 超时 / 落盘）

**一句话**：失败就是红；超长结果是「已落盘」瘦卡，点开才见路径，气泡里没有 2 万字。

**交互过程**

1. 工具不在当前可见集。  
   → 红点 + 红「失败」。不是绿点。
2. 截图等超时。  
   → 红点 +「失败/超时」。不是成功。
3. 长文已落盘。  
   → 时间线写「落盘」，绿点表示**落盘成功**不是「正文已灌进气泡」。点开 details 看到 `data/tool-results/…` 路径。DOM 里没有那 20k 正文。
4. 你 F5。  
   → 仍是瘦卡 + 落盘，不会变回「运行中」，也不会把全文灌进 hint。

**契约**：`C-S10-A1`～`A4`

### 场景 12 · 谁在说话（角标矩阵）

把这些当对照表看，出现错位就是场景坏了。

| 你看到的气泡 | 左右 | 角标 |
|---|---|---|
| 自己打的 | 右 | 无 |
| 子会话里父派的任务 | 右 | 「父 Agent」 |
| 异步 report_back / 异步任务结果 | 右 | Async · 名或任务 |
| 子 notify | 右 | 「来自子 Agent · 名」 |
| cron 写进会话 | 右 | 「定时节律」或「定时节律 · 名」 |
| 当前 Agent 回答 | 左 | 无 |

刷新后角标必须还在。  
**契约**：`C-S3-A3` `C-S7-A2` `C-S11-A1`

### 场景 13 · 中栏派工条

**交互过程**

1. 没有后台任务。  
   → 中栏没有「后台任务」这一条。
2. 有执行中 / 等待 / 待消费 / 同步任务。  
   → 出现「后台任务 N · 1 执行中 · …」和「打开运行栏」。点它打开左栏运行。任务卡片只在左栏，中栏不再堆第二份卡。
3. 任务变少到 0。  
   → 整条消失。

**契约**：`C-S18-A1` `C-S18-A2`

---

### 场景 14 · 换模型

**交互过程**

1. 点输入区模型名。  
   → 弹出模型菜单（不是一个文本框冒充菜单）。可点具体模型；可 hover 思考强度 / 免费 / 本地。
2. 选一个本地模型（如 Ollama），再发「先别上网，整理这段」。  
   → 触发器显示新模型。上面聊过的气泡还在，同一会话。
3. 本机服务没开。  
   → 本地飞出面板里该后端显示「未连接」和地址/错误摘要；若一个模型都没有，文案是「未发现本地模型。请先启动服务，例如 ollama serve…」。不是无限 Thinking。

**契约**：`C-S19-A1`～`A3`

### 场景 15 · Goal 顶栏

**交互过程**

1. 你让 Agent 设 Goal，或 cron 拉起一个 Goal 会话。  
   → 顶栏出现「Goal / 调研 / 自治」+ `2/20` 轮次 +「进行中」+ 一行摘要。摘要超过约 48 字会截断加省略号。

没有进行中 Goal 时，顶栏整块不出现。子会话不挂这条。

## 第二部 · 审批与定时

### 场景 16 · 危险操作要你点头

**交互过程**

1. 你让 Agent `git push` 或删除类操作。

2. 你打开 `/approvals`（或本来就开着）。  
   → 出现待审批卡：工具名、参数预览、「拒绝 / 仅批准 / 批准并执行」。状态是 pending。开着的审批页应**自己出现**新卡，不用手刷。
3. 你点「批准并执行」。  
   → 卡离开 pending。Chat 工具条继续 running→done。助手按真实结果汇报。
4. 你点「拒绝」。  
   → 卡变拒绝。助手收尾说明没执行。远程/删除**没有**发生。
5. `/runs` 上对应 Run 在等待时可看到「等待审批」。

## 第六部 · 身份、通道、多模态（你点名缺的那些）

前面 S1–S30 是 Chat 核心 + 知识库 + 定时。**不够。** 下面按你坐在屏幕前的顺序写：切谁、切哪间房、QQ、语音、图、视频、文件。

### 场景 28 · 切换 Agent

**今天真实入口不是顶栏树。** 仓库里有 `AgentTreeSelect`（「选择 Agent」、超级/管理/子分层），**Chat 没有挂它**。你现在这样切：

**交互过程**

1. 左栏「对话历史」，点另一条会话。  
   → 中栏换成那串气泡。当前 Agent 变成这条会话绑定的人。输入框可以接着说。
2. 点「子 Agent」，点某个子的名字。  
   → 进它的会话。没有会话的子是灰的，点不动。
3. 同空间有两个主 Agent（比如超级和管理）。  
   → 左栏树 **只显示其中一个**。要换另一个：点它已有的会话，或去 `/agents` 点「对话」（`?agentId=`），或先切 Workspace。
4. 从 `/channels` 或别处带 `?sessionId=&agentId=` 进来。  
   → 以 URL 为准打开那个人。
5. 你在 A 的会话里看过搜索工具条，再点进 B 的会话。  
   → B 里**没有** A 的工具条。再点回 A，A 还在。
6. 你在顶栏点当前 Agent 名，树里换另一个。  
   → 名字换成那个人，进它的主会话。旧会话气泡不跟过来。

**结束你应看到**：一次只跟一个 Agent 的一个会话说话。  
**你不应看到**：两个人的气泡叠在同一列表。  
**契约**：`C-S31-A1`～`A3`

---

### 场景 29 · 切换 / 控制 Workspace

**交互过程**

1. 左栏最上，点当前空间名。  
   → 飞出菜单：系统空间（皇冠）在上，业务空间在下。
2. 点另一个空间。  
   → 触发器换成新名字。下面会话列表换成这个空间的。
3. 你原来的 Agent **不属于**新空间（比如从助手家切到 QQ 指挥空间）。  
   → 自动落到该空间的主 Agent（超级或管理），旧气泡清掉，像新开对话。不是把旧房间的话搬过来。
4. 打开 `/workspaces`。  
   → 标题「Workspaces 工作空间」。能建新空间（路径、是否带管理 Agent、槽位）。建完 Chat 左栏下拉里应自己出现，不用 F5。
5. 「重置助手家」只清助手会话和默认工具，**不清**记忆。

**契约**：`C-S32-A1`～`A3`

### 场景 30 · 切换 QQ 助手

QQ 助手是一个 **Agent + 一个 Workspace + 一条通道绑定**，不是设置里的开关。

**交互过程**

1. 打开 `/channels`。  
   → 大标题「IM 通道」。能看到官方 Bot 默认 Agent 名字（来自 `qq-bot.md`）。没有这人会黄字让你 `db:sync`。
2. 已经有人从 QQ 说过话。  
   → 一块「当前 QQ 连到哪里」：Agent、Workspace、会话、私聊或群。点「打开这个会话」进 Chat。
3. 不从通道页走：Chat 左栏切到「QQ 远程指挥 Workspace」，打开「QQ 远程指挥助手」那条主会话。  
   → 现在你在跟 QQ 助手说话。工具里才有 `send_qq_*`。
4. 你切回普通 assistant 再说话。  
   → 那是家里助手，**不会**自动发到 QQ。

**契约**：`C-S33-A1` `C-S33-A2`

### 场景 31 · QQ 远程发送 / 接收

**入站（手机 → 家里）**

1. 调试：`/channels` 填 peer 和「你好」，点「注入 MessageGateway」。  
   → 绑定列表多一行。点开会话。开着的 Chat **自己**出现这条，不是让你刷新。
2. 真机：白名单用户私聊，或群里 **@机器人**（不 @ 平台不推）。  
   → 家里对应会话右侧出现来文；助手左侧回答；你手机 QQ 收到回文。来文右侧气泡带「来自 QQ」角标，不能看起来像你手打。
3. 群白名单为空 = 不接群；用户白名单为空 = 拒所有人。被拒看 server 日志 `rejectedUser` / `rejectedGroup`。

**出站（家里 Agent → 手机）**

4. 在 QQ 助手会话说「回他一句」。  
   → 时间线 `send_qq_text`，绿点后手机是**纯文本**（禁止把 Chat Markdown 原样刷到 QQ）。
5. 「发这张图 / 这段视频 / 这个文件 / 用音色说一句」。  
   → `send_qq_image` / `send_qq_video` / `send_qq_file` / `send_qq_voice`。目标是官方 **openid**，填 QQ 号算错。
6. 同一句不能发两次（出站账本）。进度用 `kind=progress`，正式回复用 `answer`，避免系统终稿再发一遍。

**契约**：`C-S34-A1`～`A4`

### 场景 32 · 语音：听、说、念、合成

三条入口，别混。

**A · 听写（不发送）**

1. 输入条麦克风（Chrome/Edge 才有）。  
   → 红脉冲「正在听」。你说话，字进输入框。**不会**自己发出去。再点停止，你自己点发送。

**B · 语音对话（说完就发，答完就念）**

2. 点耳机钮。  
   → 「语音对话开启中」。你说完停顿 → 自动发送（右侧出现你的话）→ 左侧答完 → 扬声器念。你再开口能打断它。麦克风钮这时不出现，避免两套听写打架。

**C · 点气泡朗读**

3. 悬停左侧回答，点喇叭。  
   → 在念；再点停止。一次只念一条。

**D · 给 QQ 对端发语音（服务端）**

4. 在 QQ 助手里走 CosyVoice：`voice_list` → 没有就 `voice_clone` → `send_qq_voice`。没配密钥必须红字说缺什么，不许绿点撒谎。

不支持 Web Speech 的浏览器：**不画**麦克风/耳机，不是画了点不动。

**契约**：`C-S35-A1`～`A4`

### 场景 35 · 文件（不同格式）

三条管道，别指望一个按钮吃所有格式。

| 你想做的 | 走哪 | 收什么 |
|---|---|---|
| 跟 Agent 讨论一张图 | Chat 附件 | 仅 `image/*` |
| 给文章备一份 pdf/zip/txt/图 | `/files`「资源与文件柜」 | `image/*,.pdf,.zip,.txt`（**没有** docx/xlsx） |

**交互过程**

1. Chat 点附件。  
   → 只能选图。选不了 docx。
2. 打开 `/files`，点「上传本地资源」，选一个 pdf。  
   → 列表多一行。从本页传的应自己出现。
3. 对 Agent 说「在工作区写 `outline.md`」。  
   → 工具条 `write_file`，回报相对路径。右栏文件条可以抽出这篇 md。F5 工具卡还在。
4. 你要它写进花园正文。  
   → 走「写入知识库」或 `post_*`，不是 `write_file` 砸 `content/posts`。

### 2. 时序问题怎么解决的？

**只在 Chat 发送/停止/提交这条链上，用 reducer 不变量收过，不是到处收过。**

已收进 store、编排层写错也不该破的：

- `done → idle` 只能 `commitStream`（消息对齐后才闲）
- occupied 时拒绝第二次 `beginStream`
- stop 带半成品 id 必须等对齐，禁止 `streaming → idle` 直跳
- 两路 SSE 用幂等 upsert / 幂等 commit，不拿 `await hydrate` 赌谁先到
- 工具结果长文：瘦卡进 `ChatMessage`，全文在 `data/tool-results`

**没收进不变量、仍靠短拉或本地状态的：**

- `/channels` 适配器/绑定：5s / 10s `refetchInterval`，页内无 SSE。开着通道页、手机来了新绑定，最坏等一轮轮询
- 切 Workspace / 清 session：`router.replace` + `resetSession`，没有「切空间」状态机测试钉死串台
- 语音：浏览器事件，没有服务端序。停顿自动发送与流式结束朗读已有 hook 测（C-S35-A1/A2）；说话打断仍无硬测
- 图片 OCR：按附件 id 蒙版，竞态（连贴两张）没有契约测

发现再加 `setTimeout` 赌时序 = 打补丁，本仓库不允许当验收。

### 3. 偶发的呢？

**没消灭，做了几类减灾，不能当「偶发=0」。**

| 类 | 现状 |
|---|---|
| TanStack 取消 | 禁 `void promise`，`invalidate` 走 `.catch`。单测绿仍不等于浏览器零 unhandled rejection |
| 定时器/DB 轮询 flaky | 部分 `vi.waitFor` 加到 5s。负载高仍可能红 |
| E2E | 内容/配置/数据三桶隔离；真 LLM 测会抖；Mock 栈本会话后半 **没跑完** |
| Web Speech / 真 QQ / 真 Ollama | 环境依赖，CI 不能当严酷门禁 |
| 心跳决策 | 曾经 1s 轮询假红，加宽超时，不是根治「偶发逻辑」 |

偶发测试的正确姿势：不变量 + 幂等 + 禁止时序赌。用 `retries: 2` 把红盖绿，本仓库不算过。
