# 章节结构规划

本文件管两件事: 新文落在哪, 文件和文件夹叫什么. 目录规则的总纲在 `docs/writing-spec.md` §3.5 第 7 条, 这里只写 llm-guide 的具体落点.

## 目录规则

- **一篇一个夹.** 文章一律是 `{编号-名}/{编号-名}.md`, 配图放同夹 `images/fig-{kebab}.png`. 有子文档的父文档 (章, 节, 小节) 同样是夹里的同名 md, 侧栏靠「最后一段与上一段同名」把它挂到文件夹节点上; 缺了这个文件, 文件夹在侧栏里是点不开正文的空分组. 禁止 `index.md`.
- **同一目录只用一种编号.** 一个目录下要么全是点分号子节 (`2.5.1-`, `2.5.2-`), 要么全是两位序号文章 (`01-`, `02-`). 两种不混放. 两位序号可以挂在节 (`2.3/01-`) 或小节 (`2.7.2/01-`) 下.
- **编号连续.** 从 1 (或 0) 起, 不留空号, 不重号. 删文或挪文后同一次改动里补号, 并改标题和 H1 开头的编号.
- **点分号最多三层**, 同层约 ≤10. 要超过 10 篇就拆出新的小节, 不发 `11-`. 第 10 章 (综述与前沿论文) 和第 12 章 (回顾与访谈) 是合集, 文章直接挂在章下按主题顺序编 `01-`起, 不受 10 篇限制.
- **没有无号文章.** 有编号的目录下, 每篇文章和子节都带号. 花园根目录 (只有 `_garden.md` 作首页) 不要求编号.
- 夹名不用全角冒号, 顿号, 空格, 括号, 逗号.

检查: `python layout_check.py content/llm-guide` (脚本在 agent store). `BARE` 只表示仍要承载子节点却裸放在上一级的父文章, 直接挂在父目录下的叶子 Markdown 合法; `NOIDX` 表示非叶子目录缺少同名首页; `GAP`, `MIX`, `PREFIX`, `NONUM`, `NAME` 分别表示断号、编号体系混用、子节前缀错误、有号层级夹入无号知识节点、目录或文件命名不合规. 新开但尚未完成首页的非叶子节点也不能长期保留 `NOIDX`.

## 发号前的检查

1. 读者的问题是组件, 训练, 硬件, 叙事, 应用, 还是 Agent 系统? 落错章以后必出双份.
2. `ls` 过父目录了吗? 同层是否已经约 10 篇? 父目录用的是点分号还是两位序号?
3. 别处是否已有本体? 有就只链, 加一两句说明这章关心哪一面.
4. 写完跑 `layout_check.py` 和 `node scripts/content-check.mjs`.
