# RSI · Recursive Self-Improvement · 递归自我改进

本库只回答一个问题：AI 系统的哪一部分被持久改变，改进后的系统是否继续充当下一轮改进器，以及证据能否在更新边界之外复核。通用 Agent 教程、产品功能和模型参数表留在对应兄弟库，本库只保留 RSI 判定与实验边界。
