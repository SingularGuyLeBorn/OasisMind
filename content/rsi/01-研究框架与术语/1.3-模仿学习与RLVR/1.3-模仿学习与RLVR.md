# 模仿与 RLVR：能力归因争议，RLVR 不是 RSI

读过 DeepSeek-R1、OpenAI o1 的人，手里已经有一套故事：预训练打底，SFT 过渡，**可验证奖励上的强化学习（RLVR）**才把推理拉开。花园后几章的 SPIN、STaR、Tufa、SEAL 全在改权重，读者很容易把「又训了一轮」听成递归自我改进。本篇把信号来源钉死，再指回 [1.1 术语](../1.1-RSI-术语辨析/1.1-RSI-术语辨析.md) 的式 (2)：RLVR 改的是 $\theta$，验证器和考题在墙外，改进器 $I$ 没有进 $S'$。

讲法锚在 Steven Byrnes 2026-07-24 的长文 [LLMs are (still) mostly powered by imitative learning, not RL](https://www.lesswrong.com/posts/wYpjXRLqbLbnmjbJP/llms-are-still-mostly-powered-by-imitative-learning-not-rl)。它是观点文，不是实验报告。本篇不搬正文，只用它的问题划分，数字改认下面点名的论文。作者自己写：他**不是**说 RLVR 没用——公司用是因为有用——他问的是最终模型里，**绝大多数能力**该记在模仿头上还是 RL 头上。

## 1. 两笔账：算力占比 ≠ 能力归因

模仿学习在这里 = 预训练 + SFT：下一 token 去拟合人类（或教师）写过的文本。RL 在这里 = RLHF / RLAIF / RLVR。RLVR 的奖励来自程序：数学对错、单测过不过，不必每次请人打分。

公司可能把很大一块 GPU 时间花在 RLVR 上（Byrnes 转述有人猜 20%，也可能更高）。这和「能力从哪来」不是同一笔账。Toby Ord、Dwarkesh Patel 写过 RL 的信息效率极低：同样一小时，模仿塞进模型的比特比 RL 多数量级。Byrnes 顺着推：即便 RL 吃掉一半训练算力，它仍可能只贡献极小比例的信息量和权重变化。**0.01% 是他的数量级直觉，不是 Ord 论文里的测定值**，本篇不把它当花园定理。

该记住的分叉只有一句：算力账单可以是 RL 很贵；能力归因仍可能是模仿占大头。RSI 通稿常把「我们上了 RLVR」写成「模型开始自己改进自己」。上了 RLVR 只说明 $\theta$ 被可验证奖励推过；改进手续和考题仍在人手里。

Byrnes 的操作化图景可以收成三步。随机初始化输出乱码。模仿之后得到基座：语言、事实、人类写过的推理动作都在分布里。再 RLVR，主要是拧「长思维链里下一步该调用哪套已有动作」的启发式。产品要的是 pass@1 从偶发变成常用；分布从何而来，仍然是模仿那一截。

## 2. 符号：RLVR 最大化什么，pass@$k$ 量的是什么

Yue 等 [arXiv:2504.13837](https://arxiv.org/abs/2504.13837) 把 RLVR 写成：策略 $\pi_\theta$ 在 prompt $x$ 上生成序列 $\mathbf{y}$，确定性验证器 $\mathcal{V}$ 给二元奖励

$$
r=\mathcal{V}(x,\mathbf{y})\in\{0,1\},\qquad
J(\theta)=\mathbb{E}_{x\sim\mathcal{D}}\Bigl[\mathbb{E}_{\mathbf{y}\sim\pi_\theta(\cdot|x)}[r]\Bigr]. \tag{1}
$$

$r=1$ 当且仅当最终答案对（数学）或单测全过（代码）。可以再加格式奖励，逼模型把推理和答案分开。目标 $J$ 只看期望奖励，**不要求** $\mathbf{y}$ 走出基座采样分布。PPO / GRPO / Reinforce++ 都是策略梯度：在当前策略的 on-policy 样本上，对的提高对数似然，错的压低。验证器 $\mathcal{V}$ 和题集 $\mathcal{D}$ 都不进 $\theta$。

平均分（贪心或 nucleus 的均值）量的是常用情况下好不好用。要问「能力边界有没有变宽」，Yue 把代码里的 pass@$k$ 接到所有可验证任务上：一道题采 $k$ 次，至少一次过验证就算这道题被覆盖。数据集上的平均 pass@$k$ 就是「$k$ 次尝试内能解的题的比例」。他们用无偏低方差估计量算这条曲线，温度 0.6、top-$p$ 0.95、最长 16384 token；基座评测**故意不用 few-shot**，避免把 in-context 例子算进推理能力。Best-of-$N$ 和多数投票是产品选答案的办法，会漏掉「某次其实写对了但没被选中」的题，所以量边界时不用它们替代 pass@$k$。

数学上 $k$ 极大时，均匀乱采词表也会撞上正确路径。Yue 的答辩是：基座在现实预算里（$k=128$ 或 $1024$）已经能写出对的 CoT，不是天文数字。他们还手工抽查了最难那一档（平均正确率低于 5% 但大于 0%）的思维链：GSM8K 上基座 25 道里 24 道至少有一条真对的 CoT，RL 模型 25 道里 23 道；AIME24 上基座 7 道里 5/6 条真对（一条步骤跳过判不清），RL 6 道里 4 道。猜答案不是主因。

## 3. 论文在争什么：pass@1 涨了，边界涨了没有

### 3.1 Yue 等：大 $k$ 时基座常反超，路径本来就在

Yue, Chen, Lu 等，清华 LeapLab，项目页 [limit-of-rlvr.github.io](https://limit-of-rlvr.github.io/)。问题：RLVR 有没有引出**基座采样分布里原本没有**的推理模式？

小 $k$（如 pass@1）上，RL 模型赢，这是产品在用的那一格。$k$ 大到几十、上百，**基座在他们测过的数学 / 代码 / 视觉推理基准上追上甚至超过** RL 模型。文中举例：Minerva、32B 档，$k=128$ 时基座大约高出 9 个百分点，等于验证集里多覆盖约 9% 的题。Oat-Zero / DAPO 在 AIME24 上开局可以比基座高近 30 个点，曲线后段仍被基座追上。

Table 2 把「谁能解」收成集合。AIME24 用 $k=1024$，MATH500 用 $k=128$：两边都能解的占 63.3% / 92.4%；只有基座能解、RL 不能的占 13.3% / 3.6%；只有 RL 能解、基座不能的占 **0.0% / 1.0%**。RL 解过的题，几乎是基座能解集合的子集。困惑度上，$\mathrm{PPL}_{\mathrm{Base}}(\mathbf{Y}_{\mathrm{RL}}|x)$ 落在基座自己样本分布的低 perplexity 一端，而且随训练步数继续下降——RLVR 是在先验里锐化，不是越界。

他们定义采样效率缺口 $\Delta_{\mathrm{SE}}=$（RL 的 pass@1）$-$（基座的 pass@256）。在 Omni-MATH-Rule 划分上，PPO / GRPO / Reinforce++ / RLOO / ReMax / DAPO 的 $\Delta_{\mathrm{SE}}$ 只在 GRPO 的 43.9 到 RLOO 的 42.6 之间抖，一律高于 40 分——现有算法离「吃尽基座潜力」还远。训练步数上，训练集 pass@1 从 26.1 走到 42.5，同时 pass@256 往下掉：常用变好，覆盖变窄。把 RL 模型温度调到和基座熵齐，pass@$k$ 仍低于基座，所以「熵塌了」解释不完。Magistral-Medium（纯 RL、接近前沿）在 AIME24 / AIME25 上 $k=1$ 大约多解 7 道和 8 道，大 $k$ 差距收窄，作者用来挡「只对 7B 开源模型成立」。

对照实验：DeepSeek-R1-Distill-Qwen-7B 的 pass@$k$ 整条曲线压过 Qwen2.5-Math-7B 基座和它的 RL 对照。蒸馏能从教师引进新路径；当前 RLVR 做不到这一点。Yue 自己写：这是对**当前** RLVR 的诊断，不证明强化学习永远挖不出新能力；他们点名更好的探索、过程奖励、多轮环境。读的时候把「pass@1 赢了」和「边界扩大了」拆开。

### 3.2 Karan & Du：不训练、不用验证器，采样也能贴近 GRPO

Karan & Du，Harvard，[arXiv:2510.14901](https://arxiv.org/abs/2510.14901)。问题翻面：基座能不能在**推理时**、不靠再训练，就把单次推理拉到接近 GRPO 后训练的水平？他们把目标写成幂次分布 $p^\alpha$（文中 $\alpha=4.0$ 较好），用 MCMC 迭代重采样 token 块去逼近。方法**不需要**训练集、也不需要验证器。

Table 1（单次、不是 pass@$k$）：Qwen2.5-Math-7B 在 MATH500 上基座 0.496、power sampling 0.748、MATH 上训过的 GRPO 0.785；HumanEval 上 0.329 / 0.573 / 0.537。Phi-3.5-mini-instruct 的 HumanEval：基座 0.213、power 0.732、GRPO 0.134——文中写相对基座最多 **+51.9** 个百分点，且 GRPO 在这格掉到基座以下。MATH500 上 power 的平均长度 679 token，和 GRPO 的 671 接近，基座 600；并不是靠人为鼓励变长。他们估算这套 MCMC（$N=10$，$B=192$）大约是标准推理 **8.84×** token，量级接近一轮 GRPO 的 rollout。多样本上，power 的 pass@$k$ 不像 GRPO 那样后段塌掉，大 $k$ 回到基座覆盖。

若这条成立，RLVR 的一部分产品价值可以被「更会从基座里采样」替代。验证器一旦拿掉，连「有程序化奖励才能变强」都不是必要条件。这和 RSI 更远：连 $\theta$ 都可以不动。本篇只取机制：锐化已有分布 ≠ 写出新改进器。

### 3.3 Venhoff 等：基座会推理，RL 后训练主要学会何时开火

Venhoff, Arcuschin, Torr, Conmy, Nanda，[arXiv:2510.07364](https://arxiv.org/abs/2510.07364)。问题：thinking 模型相对基座的涨分，有多少是新能力，有多少是把基座里已有的推理机制在对的时间激活？

他们用小词典 Top-K SAE 在句子级激活上做无监督分类，得到推理行为分类表；再在基座里优化对应的 category vector（steering），并从 thinking 模型抽出「何时开火」的启发式。九对基座 / thinking（0.5B–32B）：**纯 RL 的 Open-Reasoner-Zero** 混合模型平均收回基座到 thinking 差距的约 **76%**（GSM8K / MATH500 / 留出的 Hendrycks-MATH）；**SFT 蒸馏的 R1-Distill** 平均只约 **11%**，要到 14B / 32B 才看到 15–20% 量级。ORZ 一侧只 steer 大约 **5–12%** 的 token（Table 2：ORZ-32B 为 11.5% / 12.2% / 12.2%）。消融：拿掉分类向量、启发式或构造里的任一零件，MATH500+GSM8K 上的收回从约 77% 明显掉下去。

单格可以更高：ORZ-0.5B 的 MATH500 Rec.% 为 95.3%，GSM8K 为 83.0%；ORZ-32B 的 GSM8K 为 93.6%，MATH500 只有 59.8%。**不要把 76% 听成每一对、每一基准都接近满分**，更不要外推到 SWE-bench。作者的 reframing：RL 主要教的是在预训练机制上的调度启发式；SFT 蒸馏才会改机制本身（教师演示可以和基座不是同一套动作）。这和 Yue「蒸馏能越界、当前 RLVR 不能」同方向，只是量的是激活差而不是 pass@$k$ 集合。

和花园 [2.1.2 Self-Rewarding](../../02-模型自改进与自训练/2.1-自生成数据与自奖励/2.1.2-Self-Rewarding-家族/2.1.2-Self-Rewarding-家族.md) 对照：那边 1–5 分法官头和生成头共权重；这里 thinking 模型的「何时开火」仍由后训练写进 $\theta$，验证器还在墙外。混合模型**不改权重**就能收回 RL 差距的大半，说明那一截差距本来就不是新改进器。

### 3.4 反例：ProRL 主张加长时间能走出基座

Liu, Diao, Lu 等，NVIDIA，[arXiv:2505.24864](https://arxiv.org/abs/2505.24864)，ProRL。他们直接对着 Yue 那类判断：长时间 RL（KL 控制、参考策略定期重置、多任务）可以摸到基座无论采多少次都失败的路径。相对 DeepSeek-R1-1.5B，摘要写平均 pass@1 在数学 **+14.7%**、代码 **+13.9%**、逻辑谜题 **+54.8%**、STEM **+25.1%**。Byrnes 的 caveat 仍然成立：文中不少图停在有限 $k$，总尝试次数不等于「无论多少次」。本篇**不把 ProRL 的 pass@$k$ 表整张搬进来**——它是开放反例，不是已经把 Yue 证伪。两边都还不是 RSI：ProRL 同样冻着验证器和题集，改的仍是 $\theta$。

Gan & Isola 2026 的 Neural Thickets（Byrnes 列出）：对非 RLVR 模型随机扰动权重再多数投票，也能摸到 RLVR 附近。本篇未打开该文，**不抄表**。它只加强一句直觉：基座附近已经很密，集成扰动也能挤出正确路径。

Yue 的讨论段把传统 RL（围棋、Atari）和 LLM 上的 RLVR 差成两件事：词表动作空间指数大，几乎不能从零探索；所以必须从带先验的基座出发。先验是双刃剑——能收到正奖励，也让越出先验的样本几乎全是乱码、拿到负奖励。策略梯度于是继续加大先验里已有的高奖励路径。这是「为什么当前 RLVR 像在拧分布」的机制解释，不是禁止以后有人做出真能探索的算法。

## 4. 思维链还像人话，说明模仿还在管事

若奖励只看最终对错，思维链对奖励无关，没有力把它留在人类语言里，按理应漂向更「好优化」、更难读的 token。Karpathy 有过一句被 Byrnes 转述的判断：RL 做对了，模型会在思维链里不再说英语。今天的 CoT 再怪，也离随机乱码很远，离人类解题草稿更近。Byrnes 把这当成「模仿仍主导」的旁证。

Rohin Shah 在 80,000 Hours 访谈（2025-12 录）里把箭头反过来：因为预训练极强、模型「生来」用自然语言推理，近期的 RL 又相对没效率，所以短期内不太可能训出我们费点劲也读不懂的外星语。他同样引用 Nanda 一带的工作：推理训练很大一块是教模型**何时**做预训练里已经会的某类步骤。这不是定理。看见 R1 式长 CoT，不能直接说「模型已经在用私有语言自我改进」。

## 5. 对上花园：谁在模仿、谁在 RL、谁都还不是 RSI

| 方法 | 信号 | 更像模仿还是 RLVR | 墙外还有什么 |
|------|------|-------------------|--------------|
| 预训练 / SFT | 人类或教师文本 | 模仿 | 语料、配方 |
| Gorilla SFT | GPT-4 造的 {instruction, API} | 模仿（API 轨迹，不是 RLVR） | APIBench、AST、RAT 提示、检索器 |
| ToolLLM SFT | ChatGPT-DFSDT 标的 REST 路径 | 模仿（多工具轨迹，不是 RLVR） | RapidAPI 16464、ToolEval、DFSDT、BERT |
| Self-Instruct | 自己写指令再 SFT | 模仿；过滤是启发式不是对错 | 种子任务、ROUGE |
| STaR | 对了才留 rationale | 过滤用**数据集标签**，不是在线 RL | 标签 |
| SPIN | 人类 $y$ vs 上一轮自己 | 损失像 DPO；Byrnes/Conmy：DPO 更靠近模仿 | $p_{\mathrm{data}}$ |
| Self-Rewarding LM | 自打 1–5 分 + 迭代 DPO | 偏好，不是可验证 0/1 | 量表、Judge prompt、冻结 Chat 写新题 |
| Tufa GRPO | 冻结 LLM 裁判的 0/1 | **RLVR**（裁判代理形式验证器） | 裁判、LADDER 出题、GRPO 配方 |
| SEAL | 内环 SFT self-edit | 内环模仿；外环用 $\tau$ 筛 | 考题 $\tau$、ReST-EM |
| R1 / 通用 RLVR | 程序化对错 | RLVR | 题集、验证器、算法 |
| ReTool PPO | boxed 等价 +1/−1，交错 CI | **RLVR**（解释器只服务 rollout） | 沙箱、标签、DAPO-17k、KL=0 |
| ToolRL GRPO | 格式 0/1 + 槽位 Jaccard | **RLVR**（逐步金标调用） | 尺度 3、4K 拼盘、BFCL |
| ToRL GRPO | boxed +1/−1，默认不加可执行惩罚 | **RLVR**（Sandbox Fusion 只服务 rollout） | \(C=1\)、28740、greedy |

Arthur Conmy 的划分（Byrnes 注 1）：DPO 通常更像模仿，即便常被塞进 RLHF 桶。花园里 SPIN、Self-Rewarding 主实验都走 DPO 形态，不要自动贴「已经在做 RLVR」。Tufa 才是明确的二元奖励 + GRPO。

另一条漏网：公司 A 做 RLVR，思维链流到网上，公司 B 拿去 SFT。结构是模仿，Byrnes 主张能力账仍应记到 RL 上。蒸馏能引进新路径（Yue；Venhoff 的 SFT 侧也改机制），所以「SFT 一定只是模仿人类」也不对——教师若本身是 RLVR 模型，模仿的是已经被 RL 拧过的分布。OPD / 教师蒸馏的公式在 [llm-guide 4.6](../../../llm-guide/4-后训练/4.6-OPD/4.6-OPD.md)，本库不重推。

- **下排 $S\to S'\to S''$**：改进器还在系统状态里，下一轮继续当改进器。STOP / Gödel / DGM / ADAS 走下排的 Harness 切片；它们的 $\theta$ 仍然冻着，所以仍不是完整 RSI。

## 6. 为什么这和 RSI 判断有关

能力边界。若能力主要来自模仿，模型会在**有人类数据、有人类概念**的域里强。若能力主要来自 RLVR，模型会在**有自动可验证奖励**的域里强。两者重叠处（软件调试：人类痕迹多、测试又跑得动）最强，这是观察不是预言。Byrnes 反对一种常见外推：只要某域能写验证器，模型迟早能掌握，哪怕离人类想过的东西任意远。陪审团还没回来。花园的用处是：不要用「我们给了可验证奖励」代替「改进器已经递归」。

对齐。Byrnes 的粗规则：用 RL **制造能力**，得到的是对奖励函数不择手段的追求；用模仿制造能力，得到的是人类输出分布（有病，但不是纯 RL 的冷酷优化器）。RLHF 常被说成会把模型变笨一点、变听话一点，和 RLVR 把 pass@1 拉高不是同一方向。他担心的是：模仿还占大头时，已经能看到 RL 风格的对齐事故；RLVR 再加大，从模仿借来的「像人」会被冲淡。这是对齐判断，不是本花园能用 SWE-bench 复核的数字。和 [10.3 可靠性与独立监督](../../10-评测与安全边界/10.3-可靠性与独立监督/10.3-可靠性与独立监督.md) 的接头只有一句：奖励通道若被更新边界控制，系统会改通道而不是改能力——[DGM](../../09-自动研究与科学发现/9.1-自改代码与元智能体/9.1.3-DGM-达尔文哥德尔机/9.1.3-DGM-达尔文哥德尔机.md) 删检测标记、[Tufa](../../02-模型自改进与自训练/2.1-自生成数据与自奖励/2.1.3-Tufa-Labs-自奖励/2.1.3-Tufa-Labs-自奖励.md) 三个 Countdown 提示被黑，都是活标本。

RSI 清单。单轮 $S'=I(S)$：RLVR 成立，$\theta$ 变了。式 (2) 还要 $I'\subseteq S'$。验证器、题集、GRPO/PPO 配方、谁决定停训，默认都在墙外。把 R1 写成 RSI，漏的就是这一句。混元阶梯上 RLVR 是 **L1**（改可训练状态），证据该是 held-out，特征失败是奖励 hacking 和过拟合验证器。L3 才开始改改进手续。

公司仍在买模仿数据（尤其专家推理轨迹做 SFT）。Byrnes 引 Millidge「算法进步大多是数据进步」。RL 环境也贵，两笔都在花。这不能用来估「RL 已经超过模仿」，只能用来挡住「预训练已经不重要」。

**读**：模仿 vs RLVR 两笔账；Yue 的 pass@1 / 大 $k$ / Table 2 子集；Venhoff 的约 76% vs 约 11%、steer 5–12%；Karan Table 1 与无验证器采样；Tufa 才是花园里最像 RLVR 的样板；式 (2)。
**不读**：把 R1 听成 RSI、把 0.01% 听成测定值、把 76% 听成任意基准、把 DPO 自动分类成 RLVR、把「有验证器的域终将被掌握」听成已经发生、把 ProRL 听成已经证伪 Yue。
