# 搜索规划与提示优化

搜索可以改变提示、示范、思维节点或动作序列，但“搜索了很多候选”不等于系统在递归改进自己。本章统一记录四件事：**搜索对象、候选生成器、评分器、结果是否跨任务持久**。

- [5.1 · 提示与上下文优化](5.1-提示与上下文优化/5.1-提示与上下文优化.md)：从离散触发词、文本批评到进化与贝叶斯搜索。
- [5.2 · 推理搜索与规划](5.2-推理搜索与规划/5.2-推理搜索与规划.md)：树、图、MCTS、世界模型与行动交错。

**事实**：各方法的分数只在原论文模型、数据集与搜索预算内比较。**推测**：把提示或搜索策略持久化可能形成更强的运行时；除非下一轮改进器也被更新，否则仍不是递归。**开放问题**：搜索预算、公平基线、评分器泄漏和跨任务迁移如何统一报告。

通用 prompt engineering 与 Agent 教程由 `llm-guide` 负责；本章只保留它们与自改进边界有关的实验证据。
