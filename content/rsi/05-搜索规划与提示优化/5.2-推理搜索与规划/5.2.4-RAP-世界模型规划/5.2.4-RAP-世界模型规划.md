# RAP：脑内世界模型，跨题清空

摘要写 Blocksworld 上 RAP 均成功率 **64%**，CoT 几乎全灭；LLaMA-33B 加 RAP 相对 GPT-4 加 CoT 再高 **33%**。打开 Table 1：切分是最少 2 / 4 / 6 步，样本 **30 / 57 / 114**。RAP(20) 是 1.00 / 0.88 / 0.42。加权 \((30\times1+57\times0.88+114\times0.42)/201\approx0.637\)，才是那句 64%。GPT-4 的 CoT 是 0.50 / 0.63 / 0.40，加权约 **0.48**。相对涨幅 \((0.637-0.48)/0.48\approx33\%\)，不是六个点的 0.42 对 0.40，更不是把 64 减 40。6 步那一档 RAP 只比 GPT-4 高两个点，搜索空间作者写成最多 \(5^6\)。人把「世界模型加规划」听成自我进化，缺的是：下一状态是同一只冻结模型用另一份提示模拟出来的，真环境一次都没碰，题换了树清空。

本篇夹在 [ToT](../5.2.1-ToT-本题推理树/5.2.1-ToT-本题推理树.md) 和 [LATS](../5.2.2-LATS-Agent树搜/5.2.2-LATS-Agent树搜.md) 中间。[ReAct](../5.2.3-ReAct-推理与动作/5.2.3-ReAct-推理与动作.md) 的观察来自维基、厨房、商品页；这边观察来自语言模型自己写的下一句状态。ToT 的节点是中间思维，搜法是 BFS / DFS，作者把 MCTS 写成未来工作。RAP 把节点收成预测的世界状态，搜法直接是 MCTS。LATS 后来才把真环境观察写进节点。三篇都是本题树，都不是 RSI。**不是** 改 \(\theta\)。**不是** 术语式 (2)。一手：Hao, Gu, Ma, Hong（并列一作），Wang, Wang, Hu，UC San Diego / University of Florida，[arXiv:2305.14992](https://arxiv.org/abs/2305.14992)，EMNLP 2023（ACL Anthology `2023.emnlp-main.507`）。代码进了后来的 [Ber666/llm-reasoners](https://github.com/Ber666/llm-reasoners)。数字以 HTML Table 1–6、§3–5、附录 A / E / F 为准。默认骨干 **LLaMA-33B**，温度 0.8，截断 2048 或换行。Table 4 才换 Llama-2 70B，不要拿 70B 的 0.65 去改 33B 的 64%。

## 1. 问题：自回归没有下一世界

CoT 一次吐完整条推理，步数一长就顺着编。作者拿积木规划当钉子：Valmeekam 等的早期数字里，GPT-3 在积木目标上成功率约 **1%**，人约 **78%**。缺的不是更长的独白，是脑子里那张能推演「搬完这块，桌上还剩什么」的图。人类规划会先在内部世界里试几条路、估后果、再改计划。语言模型默认不会。作者列三条病：没有内部世界模型去模拟状态（积木怎么摆、中间变量等于几）；没有奖励去评估这一步离目标还有多远；因此也不会在探索新路和榨已知好路之间做权衡。

RAP 的处方是把同一只冻结 LLM 复用两次。一次当 Agent：条件当前状态 \(s_t\) 和提示 \(c\)，采样动作 \(a_t\sim p(a\mid s_t,c)\)。一次当世界模型：另一份提示 \(c'\)，预测 \(s_{t+1}\sim p(s_{t+1}\mid s_t,a_t,c')\)。交错下去得到 \((s_0,a_0,s_1,\dots,s_T)\)。CoT 的链里往往只有动作，没有显式状态。积木上就是「pickup 红块，stack 到黄块上」，不问桌上现在到底怎样。RAP 强迫每一步都先写出新配置，再决定下一步。整条轨迹是模型在脑子里滚的，**不跟外部真环境交互**。作者拿这点去对 Inner Monologue / 真机器人规划：那些要墙外返回；这边是闭眼推演。

\(S\) 取「当前这道题的搜索树」。单轮 \(S'=I(S)\) 可以发生：多展开一个孩子，或多回传一次 \(Q\)。术语式 (2) 还要 \(I'\subseteq S'\)。下一道独立题仍用同一份 Agent 提示、同一份世界模型提示、同一个探索权重 \(w\)、同一个每步候选数 \(d\)、同一个迭代预算 \(N\)。树不进磁盘。混元 L0：改 \((\text{输出},\text{轨迹})\)，跨独立任务保留的 Agent 状态不变。可靠性专文把测时搜索放在 L0，本篇是「节点是模拟状态」的那一格。

和邻居先划线。ToT 并发（两边都是 2023-05 的 arXiv）。ToT 专文里作者写 RAP 的任务更简单、框架也不接别的树搜；RAP 专文写 ToT 是启发式 BFS / DFS，自己才把世界模型和奖励收进统一规划。花园两句都留，数字禁止横加：ToT 的 Game of 24 是 GPT-4 **74%** 对 CoT **4%**；本篇 64% 是 LLaMA-33B 在 2/4/6 步积木子集上 RAP(20) 的加权。ReAct 接真 API；本篇积木的「观察」是语言模型生成的下一句配置，合法动作空间倒是按域约束从当前朝向枚举的，不是模型自由发明动词。LATS 在 HotPotQA 上把 RAP 套进 ReAct 提示，得到 **0.54**，低于纯推理 RAP 的 **0.60**——那是 LATS 的表，不是 Hao 等的 GSM8K **48.6**。PromptAgent 的 MCTS 搜跨题提示；这边搜本题状态。LLM+P 把话翻成 PDDL 再跑经典规划器，作者写域窄；RAP 用自然语言状态覆盖数学和逻辑。

**图 1 解析**

## 2. 机制：状态、奖励、四拍 MCTS，配方冻着

状态和动作按任务换皮，马尔可夫骨架不动。积木：状态是块的朝向（自然语言），动作是一条合法搬法；世界模型只改相关块的条件，过期条件删掉。目标条件全满足，或树深到上限，节点终止。数学：状态是中间变量取值，动作是针对未知量提一个子问题；世界模型答子问题，把新值写进下一状态。逻辑：状态是当前盯着的那条事实，动作是从规则库里挑一条，世界模型做一跳演绎得到新事实。三种皮，同一套搜索。

奖励也是插件。动作似然：示范加当前状态下，该动作的对数概率，反映 Agent 的本能，近目标时比较准，目标还远时不可靠。状态置信：世界模型对同一子问题多采几次，众数占比当置信，数学上常用。自评：问「这一步对不对」，用下一词是 Yes 的概率。任务启发式：积木上把预测状态和目标比，满足的条件越多分越高；全满足就给一个特别大的分，保证这条计划会被选中。数学把自评有用性和状态置信做成加权几何平均 \(r_t=r_{t,1}^{\alpha}r_{t,2}^{1-\alpha}\)，鼓励子问题既相关又答得稳。\(Q\) 在数学和逻辑上取未来步平均奖励的最大值，论文式 (2)，不要和术语式 (2) 撞车。

MCTS 四拍。选择：从根走到叶子，论文式 (1)

\[
a^{\ast}=\arg\max_{a\in A(s)}\Bigl[Q(s,a)+w\sqrt{\frac{\ln N(s)}{N(c(s,a))}}\Bigr].
\]

\(N(s)\) 是访问次数，\(c(s,a)\) 是走 \(a\) 之后的孩子，\(w\) 是人钉的探索权重。没访问过的动作先用轻量局部奖励估 \(Q\)，再进 UCT——预算紧，需要先验。扩展：叶子上 Agent 采 \(d\) 个动作，世界模型写出 \(d\) 个下一状态。已经是终点就跳过。模拟：从当前节点按滚动策略走到终点；实验里为了少噪声，仍采 \(d\) 个再挑局部奖励最大的那个，并且丢掉贵的分量（比如状态置信要多次采样）。回传：把路径上的奖励聚合成沿途每条边的 \(Q\)。迭代次数到了就停。抽轨迹有三种：一直走最高 \(Q\)；直接拿奖励最高的那次迭代；拿访问最多的叶子。作者写第二种往往最好。

开放域动作枚不完，所以 \(d\) 是从模型采样来的，不是穷举。积木反而可以按域约束列出当前合法动作，非法「手里没块还 pickup」进不了候选。这是状态维护的好处：CoT 会吐非法计划，RAP 先看朝向再枚举。附录 E 还改了示范：每模拟出新状态，就把剩下的题收成一道「新题」，示范若仍是原来的最少步数，分布会对不齐。他们预先算好示范的中间状态，搜索加深时把示范轨迹从头截短，让示范的最少步数跟着当前节点走。作者写这招对更难的题尤其明显。那是人改 \(I\)，不是树改了下一题的示范库。

RAP-Aggregation 只服务只要终局答案的题。各次迭代可以交出不同答案，再集成。积木计划和逻辑证明要完整轨迹，不做这一步。Table 2 的 +aggr 从 48.6 到 51.6，大约三个点，分母是 GSM8K，不是积木。

## 3. 数字：64% 是 201 题加权；48.6 不是 48.8

Table 1，LLaMA-33B，Blocksworld 子集。CoT：0.17 / 0.02 / 0.00。CoT pass@10：0.23 / 0.07 / 0.00，六个步的题采十次仍是 0。GPT-4 CoT：0.50 / 0.63 / 0.40。RAP(10)：1.00 / 0.86 / 0.26。RAP(20)：1.00 / 0.88 / **0.42**。除 RAP 和 GPT-4 外都只交一条计划；pass@10 只给 CoT。2 步 30 题、4 步 57 题、6 步 114 题，每题最多 5 块。4-shot 示范。RAP 的 \(r_1\) 用同一份示范算动作似然。64% 是 RAP(20) 在这 201 题上的加权，不是 RAP(10)，也不是 Table 4 全库。六个步 0.42 对 GPT-4 的 0.40，海报上的「超过 GPT-4」主要吃的是 2 步全对和 4 步 0.88 对 0.63。

案例（Figure 4）：CoT 先去满足「橙在红上」，头两步做成了，第一个目标反而没了。RAP 第一轮也会犯同样的直觉错误，后面的迭代逼它改道。算 \(r_t\) 时可以只把当前状态当成「新题」的初始状态，把历史藏起来，让最后几步变容易，把迭代预算留给开头那些难决定。这是提示调度，不是权重里长出了规划技能。

Table 2，GSM8K，同一只 33B，4-shot。CoT **29.4**，加 10 次自洽 **46.8**。Least-to-Most **25.5**，加 10 次自洽 **42.5**。RAP(1) **40.0**，RAP(10) **48.6**，再聚合 **51.6**。正文有一处写成 48.8%，花园以表为准，48.8 当笔误。Least-to-Most 一次把子问题全列出来；RAP 每一步看当前中间量再问下一个。作者写：只按奖励抽一条轨迹，已经高过带自洽的两条基线；聚合再吃约三个点。Figure 5 扫迭代次数，花园不手抄柱高，只取方向——预算小时，带奖励的树比多采几条 CoT 更会找到能用的路。禁止用 51.6 去改 ToT 附录那 100 题 GPT-4 ToT **90**，骨干、切分、零样本协议都不同。

Table 3，PrOntoQA，真本体、规则随机序，3/4/5 跳混在一起，避免模型背「第几步该停」。生成脚本里抽 **500** 条。MCTS 20 次迭代，自洽也 20 次采样。CoT：预测 87.8，证明 64.8。CoT+SC：预测 89.8，证明不报。RAP：预测 **94.2**，证明 **78.8**。证明相对 CoT 高 14 个百分点；预测相对自洽高 4.4 个百分点。死路能回传，自评奖励帮着避开明显错步。聚合不适用：要交证明。

Table 4，Llama-2 70B，Valmeekam 2023 全库 **602** 题，按最少步数 2 到 12 分档。Easy：示范和测试最少步数同一档，每档留 10 条做示范池。Hard：全局抽 10 条示范，不管步数。RAP(10) 还叠了附录 E 的截示范。Easy 全库 CoT **0.08**、RAP **0.65**。Hard 全库 CoT **0.05**、RAP **0.51**。六步及以上 CoT 掉得狠，RAP 还剩一截。禁止用 0.65 替换 Table 1 的 64%，也不要用 64% 去盖 12 步 Hard 的 0.09。70B 证明的是「更强基座仍然吃规划」，不是 33B 的 64% 已经过时作废。

Table 5，积木奖励消融。\(R_1\) 动作似然，\(R_2\) 任务启发式，\(R_3\) 自评。主实验第一行 \(R_1+R_2\)，成功率 **0.88**，对得上 Table 1 四步 RAP(20)，不是 64% 那条加权。加上自评到 0.91。只留似然 0.46，只留启发式 0.21，只留自评 0.14，三个全关 **0.02**。似然在积木上值钱：一步短、句式死。Table 6，GSM8K 前 **300** 题，不是全表。主实验是状态置信加自评：RAP(1/10/aggr) 0.410 / 0.450 / 0.503。只留置信 0.350 / 0.447 / 0.490。置信加似然 0.373 / 0.423 / 0.443——似然在一步迭代上有点用，迭代一多反而拖后腿。数学步骤是整句，似然容易被无关词带跑。自评在数学上更像「事后认出算错」，积木上评估一个候选动作本身还要多步推理，自评就没那么香。两张消融表不要并进主表分母。

## 4. 这不是术语式 (2)，模拟也不是真环境

\(y\) 变好了，改进器没变。下一题的两份提示和 \(N\) 还是人写的。混元 L0：好处和危害都随本题丢掉。不要用 64% 给 [SEAL](../../../02-模型自改进与自训练/2.2-自适应与递归解题/2.2.1-SEAL-自适配语言模型/2.2.1-SEAL-自适配语言模型.md) 的 LoRA 或 [DGM](../../../09-自动研究与科学发现/9.1-自改代码与元智能体/9.1.3-DGM-达尔文哥德尔机/9.1.3-DGM-达尔文哥德尔机.md) 的自改 Python 背书，也不要用 51.6 去改 ToT 的 74%，更不要用 LATS 表上的 RAP（ReAct）0.54 来改本篇任何一格。

和 [ToT](../5.2.1-ToT-本题推理树/5.2.1-ToT-本题推理树.md) 钉死。那边节点是思维，Game of 24 要 GPT-4；这边节点是模拟世界，积木用 33B 就能把 CoT 从接近 0 拉到加权 64%。ToT 说 RAP 任务更简单，指的不是「RAP 没贡献」，是不要把积木 64% 写进 24 点那一列。和 [GoT](../5.2.5-GoT-思维图聚合/5.2.5-GoT-思维图聚合.md) 钉死：那边入度可以大于 1，但没有世界模型，走哪一步由人写死的操作图说了算。和 [LATS](../5.2.2-LATS-Agent树搜/5.2.2-LATS-Agent树搜.md) 钉死。那边必须有墙外观察才能打分，HumanEval 92.7；这边故意不碰真环境，作者写不必另训动力学——因为动力学就是同一只 LM 的另一份提示。和 [ReAct](../5.2.3-ReAct-推理与动作/5.2.3-ReAct-推理与动作.md) 钉死。ReAct 的想法不改环境，动作才改；RAP 的动作改的是模拟状态，真积木一次都没搬。AlfWorld 71% 和本篇 64% 不是一个厨房。和 [PromptAgent](../../5.1-提示与上下文优化/5.1.12-PromptAgent-MCTS提示规划/5.1.12-PromptAgent-MCTS提示规划.md) 钉死：UCT 的搜索空间一个是提示版本，一个是本题状态。和 [Self-Refine](../../../04-反思批评与反馈优化/4.1-Self-Refine-任务内迭代/4.1-Self-Refine-任务内迭代.md) 钉死：线性改稿没有世界状态节点。

对有大模型基础的读者，读完应能回答四句。改的是哪一层？本题模拟树，L0。权重动了没有？没有。64% 能不能当世界模型已经学会了？不能，\(c'\) 人写，题换了清空。还缺什么才叫花园 RSI？搜索配方或世界模型提示进入 \(S'\)，并且下一题的改进器用的就是升级后的那份。微调世界模型写在局限里，本实验没做。

## 5. 脑子里的世界，和墙上的世界

同一句「有世界模型」，至少分两段寿命。RAP 的世界是提示调出来的下一句描述，对错靠后来的目标检查或答案核对，中间每一步的状态可以是幻觉。ReAct / LATS 的世界是 API 或解释器返回的句子，错了至少是墙外的错。Dreamer 一类真正的学习世界模型会改 \(\theta\)。三段不要收成「都在用世界模型自我进化」。

积木上 RAP 能认出合法动作，是因为状态写在上下文里、动作空间按规则裁过。数学上没有这种硬规则，世界模型答子问题就是在猜中间量，置信奖励只是「自己跟自己的多数票」。PrOntoQA 的规则是题目给的，世界模型做的是一跳演绎，不是发明物理。把三套任务听成「已经学会了环境动力学」，缺的是：动力学若存在，也住在冻结权重和人写提示里，不会因为这题规划成功就升级。

few-shot 示范不会因为某题规划成功就多一条进仓库。人要改示范、改 \(N\)、打开聚合，都是改 \(I\)。这和 ACE 的 Merge、Voyager 的技能入库正好相反。CoRe 要微调生成器和验证器再接 MCTS，本篇冻着。并发的 ToT 不形式化世界模型。作者把 RAP 写成把状态、奖励、规划收进同一框架的一次演示，花园读成 2023 年这篇的定位，不读成规划算法或世界模型的发明权。

**读**：Table 1 加权 64% 来自 30/57/114 和 RAP(20)、6 步 0.42 对 GPT-4 0.40、相对 33% 的分母是 GPT-4 加权约 0.48、GSM8K 表 48.6 对正文 48.8、聚合 51.6、PrOntoQA 94.2 / 78.8、70B 全库 Easy 0.65 是另一张表、Table 5 的 0.88 是四步消融、没有真环境、L0。
**不读**：用 64% 改 ToT 的 74%、用 51.6 改 ToT 附录 GSM8K 90、用 LATS 的 RAP 0.54 改本表、用 0.65 替换 33B 的 64%、把 33% 听成六个步上的绝对差、说已经接了工具、把 RAP-Aggregation 写进积木、说已经 RSI。
