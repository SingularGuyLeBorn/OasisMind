# GrIPS：短语改完人看不懂，分数还能涨

综述把提示搜索拆成编辑派、生成派、文本梯度派、进化派。编辑派的样板是这篇：人已经写好一段给标注员看的说明书，算法只在短语边界上做四种手术，贪心留下分数集上更好的那条。InstructGPT 上八套二分类，相对无搜索最多均 **+4.30**（Table 1 的 babbage，300 条测试）。GPT-2 XL 同一张表 **+9.36**，curie **+2.36**。改完的句子有时不通，准确率仍涨。权重不动。

本篇是 Harness 里「提示还是那句人写的，只被改短、换位、换词」的样板。后面 [APE](../5.1.5-APE-自动提示工程师/5.1.5-APE-自动提示工程师.md) 从示范整段生成新指令，[ProTeGi](../5.1.7-ProTeGi-文本梯度束搜索/5.1.7-ProTeGi-文本梯度束搜索.md) 按错题批评改写，[EvoPrompt](../5.1.4-EvoPrompt-进化算子提示/5.1.4-EvoPrompt-进化算子提示.md) 把本方法写成偏利用。**不是** RSI。**不是** 软提示。**不是** 微调。一手：Prasad, Hase, Zhou, Bansal，UNC Chapel Hill，[arXiv:2203.07281](https://arxiv.org/abs/2203.07281)，EACL 2023（ACL Anthology `2023.eacl-main.277`，pp. 3845–3864）；代码 [archiki/GrIPS](https://github.com/archiki/GrIPS)。论文标题写 **GrIPS**（Gradient-free Instructional Prompt Search）。花园旧文和综述写成 GRIPS，同一篇。数字以 HTML Table 1–6、§3.2、§5、附录 Table 8 为准。主模型是 GPT-2 XL（1.5B）、`text-babbage-001`、`text-curie-001`。后两者官方不公布参数量，脚注估 1.3B / 6.7B。没有 davinci：学术配额不够。分类用标签 token 的对数概率取 argmax，**不是** Mishra 那种生成再算 ROUGE。

## 1. 问题：给人看的说明书，模型不一定照着做

少样本靠示范。指令式提示靠一段自然语言，讲清人要怎么做这道题。Mishra 等把标注员说明书直接喂给模型，后来又给了五条人工改写指南：少抽象、少冗余、写低层动作。人工改写贵，而且默认「人读得通的句子对模型更好」。Webson 和 Pavlick 已经提示过：人觉得误导的指令，有时分数更高。

软提示要梯度。大模型算梯度贵，API 根本不给权重。连续向量还对不回词表，无法检查模型到底在读哪几个词。GrIPS 的补丁：把指令当成离散字符串，在短语级做局部搜索。不碰 $\theta$，输出仍是人能读的字——哪怕读完觉得不通。

$S$ 取当前那条任务指令。单轮 $S'=I(S)$ 可以发生：四种手术写出 $m$ 条候选，分数集 $\mathcal{S}$ 上打分，更好就换底座。式 (2) 还要 $I'\subseteq S'$。切成短语的句法器、删换释义加回、$\mathrm{score}=\mathrm{BalancedAccuracy}+\alpha H$、每候选 $l=1$ 刀、$m=5$、$n=10$、耐心 $P=2$，下一场 Natural-Instructions 任务原样再走。混元台阶上这是薄 $H_t$。交卷是搜完的那条指令，可以单独用，也可以接到 $k$ 条示范前面。改进手续不交卷。

**图 1 解析**

- **底座 $p$**：本轮保留的指令。开局是数据集里给人看的那段，或一条故意写得很泛的任务无关句。
- **切分**：句法树收到短语块（NP / VP / S 一类），手术发生在块边界，不在单字、也不在整句。
- **四种手术**：删（del）、换（swap）、释义（par）、加回（add）。每条候选默认只抽 $l=1$ 刀，每轮抽 $m=5$ 条。
- **打分**：在分数集 $\mathcal{S}$ 上算平衡准确率，加上预测标签分布的熵。默认 $|\mathcal{S}|=100$，$\alpha=10$。
- **贪心**：最好的候选比底座高，就换底座；连续 $P=2$ 轮不涨，或走到 $n=10$，停。
- **交卷**：停下时的底座。测试集不当学习信号。

## 2. 机制：切成短语，四种手术，贪心留下

算法从一条底座指令开始，先在 $\mathcal{S}$ 上打分。每一轮对底座采样 $m$ 条候选。每条候选连续做 $l$ 次随机手术，主实验 $l=1$，所以每轮大约 $m$ 次手术，不是 $m\times l$ 种笛卡尔积穷举。候选打完分，只有「这一轮最好的那条」有资格替换底座。换成功，耐心拨回 $P$；换失败，耐心减一。这是爬山，不是种群。束搜索是附件：保留前 $B$ 名当底座，下一轮各自长候选，再取全局前 $B$。作者写评估量大约乘 $B$。主表贪心。束宽 $B=5$ 只在 GPT-2 XL 上跑过，InstructGPT 没跑，原因写在账单里。

分数集不是测试。默认 100 条，作者自己写这不算 Perez 意义上的真少样本，只是提示搜索文献里常见的量级。§5.6 把 $|\mathcal{S}|$ 降到 20 仍有约 1 个点。标签在原始任务上可以极偏，所以准确率用**平衡**准确率，让每个类一样重。再加熵：预测老是同一类，即使平衡准确率碰巧不差，也扣分。$H$ 是 $\mathcal{S}$ 上预测标签的经验分布熵，不是指令长度惩罚：

$$
H=\sum_{y\in\mathcal{Y}}-p_{y}\log(p_{y}),\qquad p_{y}=\frac{1}{|\mathcal{S}|}\sum_{i=1}^{|\mathcal{S}|}\mathbf{1}(\hat{y}_{i}=y)
$$

$$
\mathrm{score}=\mathrm{BalancedAccuracy}+\alpha H,\qquad \alpha=10
$$

平衡准确率按 0–100 记账，才能和 $\alpha=10$ 的熵加在一起。附录试过改成平衡交叉熵，测试略涨、搜索更久。主表仍用准确率加熵。Table 2 去掉熵，GPT-2 XL 掉 **1.48** 点。作者读成：同分候选时偏向预测更散的，少陷进「永远猜多数类」。

短语怎么来。词级太碎，句级太整。§3.2.1 写用 CRF 成分句法器，叶子收到互不重叠的短语块。图 1 里方括号就是这些块。参考文献条目 Zhang et al. 2020a 在 HTML 里对上的是另一篇生成论文，花园只认正文那句「按句法树切到短语」，不拿这条参考文献号去外推解析器排行榜。

四种手术都作用在**所有出现**的同一短语上，不是改一处留一处。

- **del**：整块删掉，放进回收池，给后面的 add 用。
- **swap**：两块对调，所有出现一起换。
- **par**：PEGASUS 释义模型换成近义块，HuggingFace 上的 `tuner007/pegasus_paraphrase`。
- **add**：从回收池抽一块，插到一个随机短语边界。

加回不能凭空造数据集里没有的新事实。局限节把这写成硬边界：算法会换说法、删细节、改结构，不会补上当初没写的任务知识。手术灵感来自句子简化。作者说这样能部分模拟 Mishra 的改写指南（少抽象、少细节），同时保留「有时细节还是有用」的回头路。Table 2 四种各删一种都掉分，删 del 最狠（**−2.56**），swap / par / add 大约掉 1.0–1.3。菜单四项都在干活，不是装饰。

提示有三种拼法。Instruction-Only：指令加测试题。Instruction + Examples：指令、示范、测试题。Examples-Only：只有示范。主表 Table 1 是第一种。示范搜索是对照，不是本方法的主路径：从分数集里随机抽 $k$ 条示范（塞进 1024 token，大约 8 到 28 条），在剩下的分数点上打分，查询预算和 GrIPS 对齐。Inst+Ex 主实验把 $k$ 钉成 **4**，两类标签各一半，种子从 3 加到 5，因为示范随种子变。

分类协议。OpenAI 的 completion 接口要标签 token 的对数概率，argmax。这和 Mishra 把分类收成自由生成、再用 ROUGE，不是同一把尺。作者因此只收二分类，不收问答生成、改写生成。分数函数没有现成替代品时，这套局部搜索会空转。生成任务写成未来工作，主实验没有。

## 3. 数字：4.30 是 babbage 的 300 条测试

Natural-Instructions 八套二分类。v1 四套原分布向一个标签偏到 90% 以上：019 判断时间推理类别，021 检查问句语法和逻辑，022 识别上下文里的不当内容，050 问句相对给定句子是否可答。v2 四套接近 50/50：069 给故事补中间，137 / 139 在两条续写里挑更不毒或更贴题，195 推特正负。实验从 2021 年 10 月开做，当时仓库还在天天改任务，作者只收至少一个月没动过的条目。测试抽样尽量平衡，少数类不够就全用上，再用多数类填满。Table 1 每套 **300** 条测试。§5 其余表每套 **100** 条。两套数禁止横加。多数类基线在 Table 1 是 **59.83**：把最常见标签派给所有测试题。GPT-2 XL 搜完 **58.90**，仍低于这一行。涨幅大，不等于已经超过「永远猜多数」。babbage **60.09**、curie **66.07** 才过线。

## 4. 短语搜索不是式 (2)

听成「模型在改自己怎么读说明书」几乎又是设计好的误会。改的是说明书。谁规定切到哪？人选定的句法器。谁规定能删能换？人写的四种手术。谁规定什么叫好？人写的平衡准确率加熵。谁规定几轮、几个候选、耐心几步？人。下一场推特情感原样再走。相关工作提到遗传算法：亲本变异、适应度上涨。本方法默认连种群都不留，只留一条底座。束搜索留下 $B$ 条，仍不是让变异算子自己进化。

和 [APE](../5.1.5-APE-自动提示工程师/5.1.5-APE-自动提示工程师.md) 钉死。APE 从输入输出对整段生成新指令，默认不迭代；本篇从已有说明书出发，默认迭代最多 10 步。APE 主表是指令归纳 24 项和 davinci-002 的 GSM8K 43.0，和本篇八套分类准确率不是一列。和 [ProTeGi](../5.1.7-ProTeGi-文本梯度束搜索/5.1.7-ProTeGi-文本梯度束搜索.md) 钉死。那边错题进 $\nabla$ 出批评，再按反方向改；这边手术没有「哪里错了」。ProTeGi 把短语级 RL 写成 GrIPS 的上界，Ethos / Sarcasm 上几乎贴着初始提示——那是 ProTeGi 的对照，不要写回本篇 Table 1。和 [EvoPrompt](../5.1.4-EvoPrompt-进化算子提示/5.1.4-EvoPrompt-进化算子提示.md) 钉死：那边冻交叉说明书、维护种群；本篇冻手术菜单、贪心一条。EvoPrompt 把编辑派写成偏利用，枚举派（APE）偏探索，进化折中。花园读成搜索策略，不读成 $I$ 进了 $S'$。和 [OPRO](../5.1.3-OPRO-元提示优化/5.1.3-OPRO-元提示优化.md)、[MIPROv2](../5.1.6-MIPROv2-贝叶斯联合优化/5.1.6-MIPROv2-贝叶斯联合优化.md) 钉死：历史分数进元提示、TPE 挑槽位，都不是短语手术。和 [TextGrad](../../../04-反思批评与反馈优化/4.3-TextGrad-文本梯度/4.3-TextGrad-文本梯度.md) 钉死：文本梯度有批评句；本篇只有增删换。TEMPERA 把同类编辑收成按查询的 RL，见 [5.1.9](../5.1.9-TEMPERA-测试时提示编辑/5.1.9-TEMPERA-测试时提示编辑.md)，不要把 Zhang 等的测试时策略写进 Prasad 等的贪心环。[RLPrompt](../5.1.10-RLPrompt-离散提示强化学习/5.1.10-RLPrompt-离散提示强化学习.md) 从词表生成离散串，常是乱码；本篇从人写说明书出发，改完仍是短语。RoBERTa 少样本那张邻居表不能回写本篇 InstructGPT 的 +4.29。

定性 Table 7。Task 021（问句是否合法）上，curie 把「语法或逻辑错误」收成「错误」，人还能读。GPT-2 XL 把「正确」换成反复出现的 “should be indicated as ‘no’”，说明书变成「对了就说 no」，人看是反的，分数仍涨。Task 137（哪段续写更不毒）上，GPT-2 XL 早停，退回原文；curie 把毒性定义整段删掉。Task 195（推特正负）上，GPT-2 XL 搜成 “In this task, you are given a text from tweets . There.” 标签词消失。作者接到 Webson 和 Pavlick：人觉得荒唐的指令可以赢。同时又要记住 Table 5：InstructGPT 仍是任务相关初稿更好。两件事同时成立——模型对语义有反应，但不等于「读得通」和「分数高」是同一件事。

对有大模型基础的读者，读完应能回答四句。改的是哪一层？一条分类指令。四种手术动了没有？没有，PEGASUS 也冻着。4.30 能不能当 RSI？不能。还缺什么？手术菜单或分数公式进入 $S'$，并且下一轮搜索器就是升级后的那份。作者把「让 add 长出全新相关句子」写成社区可做的下一步。主实验没做。

## 5. 4.30、9.36、56.50 不要收成一个故事

4.30 是摘要对 Table 1 babbage 的四舍五入。9.36 是同表 GPT-2 XL，测试 300 条，起点 49.54，仍低于多数类 59.83。56.50 是 Table 4 束搜索，GPT-2 XL，测试 100 条，和 58.90 不是同一列。把三个数收成「编辑派能涨九个点还超过微调」，分母已经换了三次。

账单也是机制的一部分。一轮搜索量级 $\mathcal{O}(m\times n\times|\mathcal{S}|\times B)$。八套任务跑完，babbage 每个种子约 20–25 美元，curie 约 125–175 美元。全文实验大约 2400 美元，测试集评估另外大约 150 美元。GPT-2 XL 评估用 A100 40GB，大约每任务 10 分钟，全部实验合计 GPU 五小时出头。束搜索乘 $B$，所以主 API 实验不用束。示范搜索比 Instruction-Only 更贵：1024 token 的示范比短指令烧得多。搜完之后，测试那一次前向相对便宜。这不是 RSI 的算力曲线，是 2022 年学术 API 配额下的搜索预算。

局限节四条，花园原样收。add 不能引入说明书里没有的新信息。生成任务缺少能替换准确率的分数。指令跟得越好的模型，越不需要这份搜索——提示工程的效用会随指令理解上升而下降。最大的 InstructGPT（davinci）没测。伦理节写：说明书能用来降有害输出，也能被恶意指令带着走；高风险场景（招聘、录取、分资源）不要靠指令搜索。本篇用的八套说明书作者核过没有恶意意图，不等于方法自带安全门。

**读**：四种短语手术、贪心 $m=5$ $n=10$ $P=2$、$|\mathcal{S}|=100$ 默认、score 是平衡准确率加 $10H$、Table 1 的 4.29 / 9.36 / 2.36、多数类 59.83、Table 3 人工改写与示范搜索、Table 4 束搜索 56.50、Table 5 任务无关、Table 6 开源约 6–7 点、FLAN-T5 可能见过 NI、20 条分数集 +1.0、不通的指令可以涨分、分类走对数概率、没有 davinci。
**不读**：把 4.30 写进 curie、用 9.36 改 56.50、用 Table 3 的 53.68 替换 Table 1 的 58.90、说已经超过 AutoPrompt、把 FLAN-T5 的 74.33 当没泄漏的泛化、把 Task 195 的残句当成功案例、用 ProTeGi 的 +15.3% 给短语编辑背书、把 TEMPERA 的 RL 写进本篇贪心环。
