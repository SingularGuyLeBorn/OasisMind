# GPTSwarm：边概率会学，REINFORCE 冻着

仓库 README 写 self-improving，摘要写 automatically improve。人把 improve 听成改进器在升级，再把 Table 1 最下一行 **90.2%** 听成准确率涨了九十个百分点。打开实验：GAIA 那张表是七只 TOT 加自洽投票，作者写明**既没有边优化也没有节点优化**，留给未来工作。均分 **18.45** 对 GPT-4-Turbo 的 **9.70**，相对涨幅 \((18.45-9.70)/9.70\)，约 90%。Level 2 的 260.2% 同一把尺：20.93 对 5.81。Level 1 的 47.3% 是 30.56 对 20.75。Level 3 两边都是 3.85，相对涨幅 0。人在 Level 1 上 94%。变的是通信边的概率 \(\theta\)，以及节点提示。REINFORCE、只许 DAG、Agent 内部拓扑、决策汇合节点，都还在墙外。

本篇夹在 [AFlow](../../8.1-工作流搜索与优化/8.1.1-AFlow-工作流MCTS/8.1.1-AFlow-工作流MCTS.md)、[ToT](../../../05-搜索规划与提示优化/5.2-推理搜索与规划/5.2.1-ToT-本题推理树/5.2.1-ToT-本题推理树.md)、[ReAct](../../../05-搜索规划与提示优化/5.2-推理搜索与规划/5.2.3-ReAct-推理与动作/5.2.3-ReAct-推理与动作.md) 和 [STOP](../../../09-自动研究与科学发现/9.1-自改代码与元智能体/9.1.4-STOP-自教优化器/9.1.4-STOP-自教优化器.md) 旁边。综述把拓扑优化分成代码级工作流和通信图。AFlow 用代码边写条件循环，树节点是整份工作流；这边节点集合人事先钉死，只学智能体之间连不连。ToT 的树、ReAct 的交错、Reflexion 的批评，在这篇里都被收成子图，再用边把它们拼成 swarm。STOP 把改进器程序对自己递归；这边改进器是 Alg. 2，不进 \(S'\)。OPRO 在节点优化里当 \(I\) 的一个例子，元提示配方仍冻着。四套数字禁止横加。**不是** RSI。**不是** 术语式 (2)。一手：Zhuge, Wang, Kirsch, Faccio, Khizbullin, Schmidhuber；KAUST / IDSIA；[arXiv:2402.16823](https://arxiv.org/abs/2402.16823)，**ICML 2024**，PMLR 235:62743–62767。代码 [metauto-ai/GPTSwarm](https://github.com/metauto-ai/GPTSwarm)，主页 [gptswarm.org](https://gptswarm.org)。数字以 HTML §2–§3、式 (1)(2)、Table 1–4、附录 D.1–D.2 / E / F / G 为准。禁止用 ToT 专文 Game of 24 的 74% 去改填字 0.675。禁止用 AFlow 的 HumanEval 94.7 去改这边的 0.88。Zhuge 后来也是 AFlow 作者，两篇不要收成同一张表。

## 1. 问题：提示方案各写一套代码

作者看到的现场是：CoT、ReAct、ToT、Reflexion、GoT 各有一份互不兼容的实现；多 Agent 框架再按角色把对话写死。每换一种编排，人就要重写工作流。他们借用 Minsky 的 Society of Mind：节点是一次运算（查 LLM、用工具、调 API），Agent 是这些节点组成的图，swarm 是多张 Agent 图再加跨图边。边在 Agent 内部决定执行拓扑，在 Agent 之间决定通信信道。复合图限制为 DAG，按拓扑序执行，见 Alg. 1。

\(S\) 取这次部署里学到的跨 Agent 边集合（连续松弛之后是 \(\theta\)），外加各节点提示 \(p_n\)。单轮 \(S'=I(S)\) 可以发生：REINFORCE 推一轮 \(\theta\)，或节点优化改一句提示。术语式 (2) 还要 \(I'\subseteq S'\)。下一轮仍用同一套采样（成环就丢边）、同一条 REINFORCE、同一份「只搜跨 Agent 边、Agent 内部拓扑冻着」的切口。混元台阶上这不是 L0：学到的 \(\theta\) 可以带到下一题。也到不了改改进器。和 ADAS / AFlow 同一档：留下脚手架，出脚手架的程序冻着。作者写 self-organize。附录 G 自己把内部节点拓扑、过百只 Agent 的通信效率写成未来工作。人没退出 \(I\)。

和邻居先划线。ToT 专文的 74% 是 Game of 24、GPT-4、本题树随题清空。本篇填字引用的 ToT 是 **0.675**（原论文 GPT-4）和作者重跑 GPT-4-Turbo 的 **0.668**，题集是 20 道 Mini Crosswords，和 24 点不是同一张表。ReAct 专文的 AlfWorld 71% 是交错想–做–看；这边 HumanEval 用 ReAct 风格节点，0.76→0.88 是提示优化，骨干是 `gpt-4-1106-preview`。Reflexion 专文 HumanEval 91.0 是窗口里的失败句；这边只把它当三只填字 Agent 之一。AFlow 的 80.3 是六列均分、Claude 优化器、GPT-4o-mini 执行；这边没有那六列。STOP 改改进器源码；这边 Alg. 2 的学习率、Adam 的 \(\beta\)、成环即丢，人换就要改代码。GoT 允许入度大于 1，图随题清空；这边复合图也可以入度大于 1，但边概率跨题还在。DSPy 先要人搭图，再在节点候选的笛卡尔积上搜；这边假设「一次只改一只节点的提示、其余钉死」。LangGraph 允许环；本实验禁止环。

## 2. 机制：连续松弛边，成环的边直接丢掉

形式对象。单只 Agent 是 \(G=(N,E,F,o)\)。\(N\) 节点，\(E\) 有向边，\(F=\{f_n\}\) 运算，\(o\) 输出节点。前驱 \(\mathrm{pre}(n)\) 的输出拼成语境 \(z_n\)，节点算 \(f_n(z_n,x)\)。无前驱时 \(z\) 空。输入输出在实现里是自然语言字符串。\(K\) 只 Agent 合成复合图时，新边 \(\mathcal{E}\) 只允许连不同 Agent 的节点。输出节点再加一个虚拟汇合 Agent，多数实验用多数票或提示版自洽。附录 E：潜在边是「不同 Agent 的节点对全集」，**不包括**连到复合图输出节点的边；Agent 之间默认通信也不经过这个虚拟节点。

边优化的离散问题是 \(\max_{\mathcal{E}} u_\tau(G_{\mathcal{E}})\)，\(2^d\) 种配置，还要保持 DAG。效用对 token 不可微。式 (1) 改成对分布求期望：

\[
\arg\max_{\theta\in\Theta}\mathbb{E}_{G'\sim D_\theta}[u_\tau(G')].
\]

每个候选边一个 \(\theta_i\in[0,1]\)。采样：从已有边出发，按顺序决定要不要加 \(e_i\)；加完成环就**不加**，否则以概率 \(\theta_i\) 加上。这不是可微的 DAG 松弛，只是给 REINFORCE 一条可采样的分布。式 (2) 用 \(M\) 个独立图估计

\[
\nabla_\theta\mathbb{E}[u_\tau]\approx\frac{1}{M}\sum_{i=1}^{M}\hat{u}_\tau(G_i)\nabla_\theta\log p_\theta(G_i).
\]

正文 Alg. 2 写成普通梯度上升。附录 E 改成 Adam，\(\beta_1=0.9\)、\(\beta_2=0.999\)，学习率按实验给。人换这条更新，等于人改 \(I\)。

节点优化是另一条环。每个节点自带提示 \(p_n\) 和功能描述 \(d_n\)（例如「Python 代码生成器」）。历史 \(h_n\) 记该节点的输入输出对。图跑完之后，改进器 \(I(h_n,p_n,d_n)\) 写出下一句提示。作者的假设是：图已经把职责切开，于是每一步可以假装其它提示冻着、只改当前节点。\(I\) 可以是 OPRO 那一类「看历史再写一句」，填字附录里实际落地成 UCB1：从 \(h_n\) 里挑一条示范塞进提示，或者保持原提示，一百轮，奖励是该节点在**先前输入**上多填对多少词。功能描述 \(d\) 在那次实验里被忽略。节点优化不会改边，边优化默认也不改提示。两套环可以串：先十步 REINFORCE，再在学到的分布上跑节点优化。假设「一次只改一只」省掉了 DSPy 那种笛卡尔积，也把节点之间的耦合推给人：图切得不干净，这个假设就假。作者没有在主表上消融「联合改所有提示」。内部拓扑仍然冻着。填字里 ToT 的八步链、Reflexion 的批评边、CoT 的三节点，都是人事先焊好的子图；REINFORCE 动的是子图之间的信道，不是把 ToT 改写成另一套搜索。附录 G 把「动态改内部拓扑」写成还没做，等于承认 \(N\) 和 Agent 内 \(E\) 都不在 \(S\) 里。

执行时按拓扑序。温度和模型版本写在附录 E：`gpt-4-1106-preview`、`gpt-3.5-turbo-1106`；GAIA 的视觉是 `gpt-4-1106-vision-preview`。框架宣称 41 种文件分析、网页搜索、基于索引的记忆。这些模块是人写进 `swarm.environment` 的运算节点，不是搜索长出来的。人加一种新运算，等于人改 \(N\) 和 \(F\)，也就是改 \(I\) 的搜索空间。

## 3. 数字：90.2% 不是准确率，0.800 不是 24 点

对抗 MMLU。\(k\) 只 IO 加 \(k\) 只故意答错的对手，最终答案多数票，中间不再让 LLM 纠偏。评价用验证集前 10%，153 题。优化 200 轮，每轮 4 张图，题来自 MMLU dev。GPT-4-Turbo，温度 0.2。目标是把分数拉回单只 IO 基线，不是超过它。作者把「拉回基线」写成成功：有害 Agent 的边被剪掉。协作设定换成 7 只不同角色的 IO，相对 3.1.1 的基线平均高 **2.1% ± 1.1%**（5 个训练种子）。论文写的是 2.1%，没有把这格改成百分点对照表；不要听成准确率到了 2.1 的两倍。附录 Table 6 给了二十个可抽角色，植物学家、数据科学家、社工、记者、飞行员一类，随机分给那 7 只 IO。角色提示是人写的 \(I\)，边优化只决定这些角色之间谁听谁。剪完之后，连不上汇合器的对手相当于被扔掉，Figure 11 的 2 真 2 假例子把虚线潜在边收成实线。附录 D.1 Table 3，同一套 3 真 3 假：Multiagent Debate 准确率 0.5751，成本 32.8 美元、8.36 小时；DyLAN 推理 0.8366，优化加推理约 121 美元、30 小时；GPTSwarm 推理 **0.8301**，优化 5.32 美元 / 0.9 小时，推理 1.82 美元 / 0.31 小时。DyLAN 高 0.0065，作者写成更复杂的辩论方案。Table 4 只给规模和时间：1+1 四条潜在边、9 分钟；3+3 三十六条、23 分钟；5+5 一百条、58 分钟；7+7 一百九十六条、95 分钟。#LLM inferences 在关剪枝时统计。不要把 0.8301 和协作设定的 2.1% 加在同一句里当「MMLU 涨了」。

Mini Crosswords。20 道题，**优化和评价用同一子集**，跟 Yao 等、Sel 等先前工作对齐。盘面是 5×5，每词五个字母。三只 Agent：ToT 按词分支；Reflexion 先贪心再听批评；CoT 三节点，每步在候选子集上做内部蛮力。ToT 并不把深度 8 的完全二叉树展开成 \(2^9-1\) 个图节点，而是一条八个分支节点的链，每个节点对每个输入解生成两个后继。每个节点对每个收到的解返回一或两个解，彼此在给定输入下条件独立。复合图输出节点原样转发收到的全部解。为了接得上汇合器，实验强制「任何 Agent 的输出节点都有边连到复合图输出」。候选词提示和剪枝提示改写自 Yao 等原文，见表 7。效用是图返回的所有解里、填对词数最好的那个（best state word accuracy）。评价对学到的分布采 20 张图。为了压 REINFORCE 的方差，效用要减常数 0.4：填满得 0.6，空盘得 −0.4。GPT-3.5-Turbo，温度 0，\(\theta\) 初值 10%，学习率 0.4，每步 \(M=20\)，十轮，三次运行。学完 **0.575 ± 0.0275**，初始分布 **0.465 ± 0.0509**。三只 Agent 各自交卷再按题取最好，只有 **0.320 ± 0.0415**，低于随机边。密度对照：学到的期望边数 32.76 ± 1.93，把所有 \(\theta\) 钉成 12.5% 得到 32.80 ± 0.11 条边、准确率 **0.510 ± 0.0552**。多出来的边数解释不了 0.575。再把其中一次学到的分布（随机抽一次）交给 GPT-4-Turbo：**0.800 ± 0.0616**。ToT 原论文 GPT-4 是 0.675；作者用 GPT-4-Turbo 重跑 ToT 得 0.668。0.800 不要改花园 ToT 专文的 24 点 74%，也不要写成「已经超过 GPT-4 的 ToT」却不报题集只有 20 道、且这 20 道进过优化。附录 D.2 在边优化之后做节点优化：UCB1 一百轮，历史就是这 20 道上的输入输出，准确率到 **0.668 ± 0.0060**（仍是 3.5）。这格不要和 0.800 横加。附录 F：3.5 边优化 77.42 美元；把学到的分布拿到 GPT-4 上评，377.54 美元。

HumanEval。ReAct 风格：先写程序，题面测例过了就交；否则带着执行反馈再写。每四个新题之后更新一次节点。题面测例过了，这一路上的节点输入输出算正例，否则算负例。每个节点最多留四条示范。优化一步时比较「保持旧示范」和「掺进最近四题的正例再随机抽最多四条」，用该节点在首次见到的题上最近十次输入谁过测更多来挑。前八轮每轮优化完都在**整个数据集**上评。三次运行，前五轮能看见涨。在线设定不停下来重开，从无优化的 0.76 到 **0.88 ± 0.007**。表 F 两行都没标 GPT-3.5T，按附录约定是 `gpt-4-1106-preview`。无优化 1.61 美元，有优化 28.46 美元。0.88 不要改 LATS 的 92.7，也不要改 AFlow Table 1 的 94.7：骨干、是否搜工作流、切分、pass@1 协议都不是同一句话。整集既当爬山信号又当报道分，可靠性专文要的墙外新题，这张表没有另备。

GAIA。Table 1 是七只 TOT、提示版自洽、五次运行的均值和标准差。Level 1 / 2 / 3 / 均分：GPT-3.5 为 7.55 / 4.65 / 0 / 4.85；GPT-4 为 15.09 / 2.33 / 0 / 6.06；GPT-4-Turbo 为 20.75 / 5.81 / 0 / 9.70；AutoGPT 为 13.21 / 0 / 3.85 / 4.85；GPTSwarm 为 **30.56 ± 3.25 / 20.93 ± 1.27 / 3.85 ± 2.43 / 18.45**。相对 GPT-4-Turbo 的 Improvement 行是 47.3% / 260.2% / 0.0% / 90.2%，全部是相对涨幅。GPT-4 with plugins 为 30.30 / 9.70 / 0 / 14.6，作者加星号：插件要人手选工具，和自动编排不是同一比较。Level 1 上 30.56 对插件 30.30，几乎持平；均分赢在 Level 2。Table 2 只报 Level 1 验证集。单只 IO 16.60 ± 3.02，最好一跑 20.75%，约 13 秒。单只 TOT 25.66 ± 3.50，最好 30.18%，约 71 秒。三只 TOT 选「最好」30.18 ± 4.30；七只 TOT 自洽 30.56 ± 3.25，最好 35.85%，约 415 秒。时间近似随 Agent 数线性涨。43.9% 的题需要浏览网页；实现只下载题面 URL 或走 SearchApi 的 Google 查询，不再点进站点。作者认为加强浏览还会再涨。这些实验用来证明框架能拼工具，**不是**用来证明式 (1) 的边优化。

## 4. 这不是术语式 (2)，GAIA 也没在学边

边概率变了，下一道同设定的题可以走新的通信图。改进器没变。Alg. 2、成环即丢、潜在边定义、虚拟汇合、Adam 的 \(\beta\)、只搜跨 Agent 边的切口都还在。混元 L0 装不下跨题保持的 \(\theta\)；L3 要改提议 / 选择程序。本篇停在留下状态、不改程序。摘要里的 automatically 指少写具体编排，不是 \(I\) 在改自己。相关工作点了 STOP：那篇把提示和推理结构收进改进器，再把自己当优化题。GPTSwarm 把结构收成给定节点上的边，改进器仍是人写的 REINFORCE。

验证集参与爬山。填字 20 道既优化又评价。HumanEval 每轮在全集上评。MMLU 对抗用验证集前 10% 报道，优化题来自 dev。GAIA 主表连优化都没有。换切分，0.575 / 0.88 / 0.8301 会动。90.2% 的分母是 GPT-4-Turbo 均分 9.70，不是人的 94%，也不是插件的 14.6。260.2% 的分母是 Level 2 的 5.81。禁止把相对涨幅听成百分点。

和 AFlow 钉死。那边代码边能写循环；这边 DAG 写不了。那边优化器是 Claude，20 轮 MCTS；这边是 REINFORCE 推 \(\theta\)。HumanEval 94.7 是 GPT-4o-mini 执行搜到的工作流；0.88 是 GPT-4 上改 ReAct 提示。和 ToT 钉死。24 点 74% 随题清空；填字 0.800 是把 3.5 上学到的边分布交给 4-Turbo，题还是那 20 道。和 ReAct / Reflexion 钉死。它们在这边是子图积木，不是主表列。和 OPRO 钉死。节点 \(I\) 可以调用那类写提示的函数，元提示不进 \(\theta\)。和 ADAS 钉死。MGSM 53.4 是另一张表；这边没有 MGSM。和 LATS 钉死。HumanEval 92.7 是本题 MCTS；这边 0.88 是跨题提示示范，树不在。

对有大模型基础的读者，读完应能回答四句。改的是哪一层？Harness 里跨 Agent 的边概率和节点提示。权重动了没有？没有。GAIA 的 90.2% 是不是准确率到了九成？不是，均分 18.45，相对 9.70。还缺什么才叫花园 RSI？REINFORCE 的更新规则或节点集合进入 \(S'\)，并且下一类新基准用的就是升级后的那份搜索手续。附录 G 把内部拓扑动态改写、Agent 过百，写成还没做的事。主实验能转起来，前提是 \(u_\tau\) 是标量。对抗 MMLU 的效用是对错；填字是填对词数；HumanEval 是题面测例。GAIA 没有把这套效用接进边优化。把 18.45 听成「已经在学通信图」，缺的是 Table 1 自己写的 future work。

**图 2 解析**

- **左列**：边概率可以多一轮修改，本题 \(y\) 可以变。节点提示走另一条环，也在墙左边。

同一句「自动编排多 Agent」，至少分三截。人手写 ToT / ReAct。GPTSwarm 在给定节点上学边。AFlow 用 MCTS 搜代码工作流。三截不要收成「都已经是 RSI」。[G-Designer](../8.2.3-G-Designer-任务自适应通信图/8.2.3-G-Designer-任务自适应通信图.md) 按题出图，MMLU 84.50。[AgentPrune](../8.2.4-AgentPrune-时空图剪边/8.2.4-AgentPrune-时空图剪边.md) 剪边省 token，均分 89.72，表上 27.2% 是保留比。[ScoreFlow](../../8.1-工作流搜索与优化/8.1.2-ScoreFlow-Score-DPO工作流/8.1.2-ScoreFlow-Score-DPO工作流.md) / [AutoFlow](../../8.1-工作流搜索与优化/8.1.4-AutoFlow-自然语言工作流RL/8.1.4-AutoFlow-自然语言工作流RL.md) / MAS-GPT 仍在代码级那一侧。

生成提示不会因为某次 0.800 就把成环即丢写进 \(\theta\)。人要允许环、把内部拓扑放进搜索、让模型改 Adam 的 \(\beta\)，都是改 \(I\)。这和 Gödel 改自己的决策函数、DGM 改自己的 Python 正好相反。作者把 GPTSwarm 写成用图统一已有 Agent、再用 RL 学通信。花园读成 2024 年这篇通信图边概率的定位，不读成已经闭合的递归，也不读成 ToT 的 24 点已经被 0.800 作废。无数值 \(u\) 的任务，式 (2) 没有分数可回传。GAIA 主表能报 18.45，靠的是人手写的七只 TOT 加自洽，不是靠 \(\theta\)。

**读**：GAIA 18.45 对 9.70 的 90.2% 是相对涨幅且未跑边优化，填字 0.575 / 0.800 / 0.668 分骨干和是否节点优化，HumanEval 0.88 在全集上爬，MMLU 对抗是拉回基线，不是式 (2)。
**不读**：把 90.2 / 260.2 / 0.800 / 0.88 听成同一把尺、用 24 点 74% 改填字、说 GAIA 已经在学边、说 REINFORCE 已经进了 \(S'\)、说已经 RSI。
