# 多智能体协作与工作流

多智能体系统可以优化工作流、提示、通信边或按任务生成团队结构。这里最容易发生的误判是：把“系统由多个 Agent 组成”直接写成“系统会自我改进”。

- [8.1 · 工作流搜索与优化](8.1-工作流搜索与优化/8.1-工作流搜索与优化.md)：AFlow、ScoreFlow、MASS、AutoFlow。
- [8.2 · 多智能体拓扑与协作](8.2-多智能体拓扑与协作/8.2-多智能体拓扑与协作.md)：GPTSwarm、MAS-GPT、G-Designer、AgentPrune、MaAS、ANN。

**事实**：原论文中的工作流、基础模型、成本和评测集必须一起引用。**推测**：若工作流搜索器能修改自己的搜索策略，才可能向递归靠近。**开放问题**：通信成本、角色同质化、共享错误、拓扑过拟合与独立验证。

通用多 Agent 框架和编排 API 留在 `llm-guide`；本章只比较“哪一层在更新”。
