# 3 · 脚手架层 (L2)

脚手架 $\Sigma$ 是模型外面那层可保留的运行结构. 这一层的改动不碰改进器 $U$ 和评判标准 $C$, 模型参数可以同时变, 但不是改得最深的那个. 综述按可改对象的范围从小到大分五层, 本部分两篇各讲一半.

| 篇 | 回答的问题 |
|---|---|
| [3.1 · L2: 提示, 程序与架构](3.1-提示程序与架构/3.1-提示程序与架构.md) | 提示优化, 程序发现, 架构搜索和通信拓扑怎么做, 搜出来的结构有没有被保留复用, 增益是否来自多花的算力 |
| [3.2 · L2: 技能, 记忆与 Harness](3.2-技能记忆与Harness/3.2-技能记忆与Harness.md) | 技能和记忆用什么门控制写入和删除, harness 怎么演化, 脚手架过拟合有哪几种, 为什么固定改进器是这一层的上限 |
