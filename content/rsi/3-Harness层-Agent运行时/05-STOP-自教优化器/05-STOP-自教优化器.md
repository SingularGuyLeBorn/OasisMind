# 05 STOP：递归改进的是脚手架

Tree-of-Thoughts、Program-of-Thoughts、ReAct 这类系统，真正拉开分数的往往不是再训一遍权重，而是外面那圈 **scaffolding**：用 Python 把多次语言模型调用排成搜索、分支、投票。STOP（Self-Taught Optimizer）要解决的瓶颈是：对固定的 $L$、对一类优化题，**脚手架自己也是一个优化问题**。种子改进器 $I_0$ 会拿 $L$ 去改进任意解；然后把 $I_0$ 自己当成「要改进的解」再跑一遍。

本篇是 Harness 层里最早把「改进器程序」写成递归对象的公开实验，比 [04 DGM](../04-DGM-达尔文哥德尔机/04-DGM-达尔文哥德尔机.md) 早一年半。坐标系见 [02 Model–Harness–Artifact](../../1-坐标系与术语/02-Model-Harness-Artifact/02-Model-Harness-Artifact.md)。**不是**完整 RSI：作者自己写「inspired by but not completely RSI」，因为底层 $L$ 不变。**不是** SPIN / SEAL（那些改 $\theta$）。**不是** AlphaEvolve（那边进化交卷程序，发现者 Agent 可以整段不动）。一手：Zelikman, Lorch, Mackey, Kalai，[arXiv:2310.02304](https://arxiv.org/abs/2310.02304)，COLM 2024；主实验用 **gpt-4-0314**（训练截止 2021-09，早于大多数脚手架论文）。

## 1. 问题：脚手架是人写的，人写的也可以被优化

语言模型一次前向就能按自然语言目标吐代码。实践里，**多次、有结构的调用**往往比单次采样更强：先想再搜、分支再聚合、调用解释器。这些结构以前都是研究员问「给定一只不完美的 LM，怎么给它加骨架」。STOP 把问题翻过来：骨架的设计，对任意下游优化题分布、对固定 $L$，本身就是优化。

形式化先钉死。$L:\Sigma^*\to\Sigma^*$ 是黑盒、可随机的语言模型。效用 $u=(u_{\mathrm{func}},u_{\mathrm{str}})$：$u_{\mathrm{func}}$ 给解打有界实分，$u_{\mathrm{str}}$ 是这段函数的描述（通常是源码）。任务 $\tau=(u,s)$，$s$ 是当前解（实验里是源码）。**改进器** $I$ 是一段程序：

$$
s'=I(u,s,L)\qquad\text{希望 }u(s')\gg u(s). \tag{1}
$$

下游任务来自分布 $\mathcal{D}$。真正想要的是期望效用 $\bar u(I)=\mathbb{E}_{(u,s)\sim\mathcal{D}}[u(I(u,s,L))]$。训练时只有 $n$ 道题 $D\sim\mathcal{D}^n$，所以用经验平均当 **元效用**：

$$
\hat u(I)=\frac{1}{|D|}\sum_{(u,s)\in D}u(I(u,s,L)). \tag{2}
$$

$\hat u$ 的描述做成 **grey-box**：告诉模型「这是一堆下游效用的平均」，**不把具体下游题写进描述**。否则改进器会背题而不是学通用脚手架。附录 A 用 Chernoff + 并给出过拟合界：在长度 $\le \ell$ 的程序类上，$\hat u$ 和 $\bar u$ 的差距随 $n$ 收。本篇不把那条引理再推一遍，只留一句：元效用是预优化（像预训练），下游再用。

STOP 的关键观察：选 $I$ 这件事，形状和式 (1) 一样——把 $\hat u$ 当成 $u$，把当前 $I$ 当成 $s$。于是可以递归。

## 2. 循环：$I_t = I_{t-1}(\hat u, I_{t-1}, L)$

种子 $I_0$ 故意瘦：提示 $L$ 对当前解提若干候选改进，用 $u$ 挑最好的那条。要创意、少嵌套、少 token——自改进会把代码字符串再塞进提示，种子一复杂，后面全炸。作者试过别的种子，启发式上这一版让 GPT-4 提出的改进最新。

算法 1：输入 $I_0$、$L$、深度 $T$、下游集 $D$。对 $t=1,\ldots,T$：

$$
I_t \triangleq I_{t-1}(\hat u,\, I_{t-1},\, L). \tag{3}
$$

输出 $I_T$。每一轮改进器拿自己当解，拿元效用当考官，拿冻结的 $L$ 当采样器。预算乘在两层：下游 $u$ 的调用次数、对 $L$ 的调用次数。论文写代价大约 $O((\mathrm{budget}_u+\mathrm{budget}_L)\cdot\mathrm{budget}_{\hat u})$。LPN 实验里大约每轮每次 run **三千次** GPT-4 调用。

效用同时给两份：可调用的函数，和带预算约束的源码字符串。预算若只写在种子提示里，后面几轮常被「简化」删掉，然后开始刷分。把约束收进 $u_{\mathrm{str}}$，删提示删不掉考官。换成纯英文描述效用，非平凡改进会变少。

> 图 1：实线把 $I_{t-1}$ 和 $\hat u$ 送进「改进改进器」；虚线把 $I_t$ 拷成下一轮种子。底栏权重不动。

**图 1 解析**

- **Seed $I_0$**：采样再挑最好。不是终点，是可被改写的程序。
- **$I_{t-1}(\hat u,I_{t-1},L)$**：同一段代码既当改进器也当被改进物。这是「递归」的全部操作含义。
- **$I_t$**：新脚手架。里面可能已经是 beam search、遗传、退火，而不再是种子那套「采几次取 max」。
- **Downstream $D$**：LPN / 3-SAT / MaxCut 等。元效用是这些题上的平均，grey-box 不把题面塞进提示。
- **$L$ frozen**：GPT-4 权重点不着。作者把完整 RSI 的条件写成「模型被允许改自己的每一段代码」；STOP 只改调用它的那层。

附录还写过等价的 **maximizer** 表述：不需要初始解 $s$，输出 $M(u,L)$。两者可以互译。实验用改进器，因为热启动的 $s$ 有用。另有一个带硬币的递归效用 $u_\lambda$，用来给「改进改进器」一个不循环的期望定义；主实验没有拿 $u_\lambda$ 跑，仍用式 (2) 的启发式——好的下游改进器更可能是好的自改进脚手架。

种子提示里的角色句是「计算机科学研究者兼程序员，尤其擅长优化算法」。要求：先提一个想法再实现；主改进必须新颖、非平凡。`utility.str` 整段嵌进提示。作者发现若种子不告诉模型可以 **batch 多条 message**，GPT-4 延迟会把运行时间拖垮；后来的种子才把 batch 写进去。更早一版种子（附录 A.18）没写 batch，不适合当复现默认。

## 3. 数字：LPN 随迭代涨，换任务也能带过去

下游选 **learning parity with noise（LPN）**：比特串的标签是未知子集的奇偶，标签带噪声。无噪声可高斯消元；有噪声被猜想难。实验用可算的 **10 bit**，超时 2 秒，子集包含概率 $p=30\%$，100 训练 / 20 测试。效用 $u$：抽 $M=20$ 个独立实例，报平均准确率。初始解 $s$ 是随机采样（附录 K）。因为 $L$ 和 $I$ 都有噪声，算法 1 里 $D$ 放 **5 份相同的** $(u,s)$。测试元效用另用 $M_{\mathrm{test}}=50$ 个没见过的实例。

Figure 4 左：5 次独立 STOP，1–3 轮自改进后测试元效用均值上升。单次 run **不必单调**：更会改下游的 $I$ 不一定更会改自己；LM 调用本身也随机。提示里只有占位符，**看不见下游题面**，所以不能直接为 LPN 过拟合脚手架。

两条参照。Chain-of-thought：种子只改一次、不调 $u$，无报错时 **57.7% ± 3.0%**，算上报错 **49.6% ± 3.5%**。贪心迭代：把预算打满、每次留最好、重复，**64.2% ± 0.9%**（十次 run）。STOP 要赢的是「冻结种子一直用」，不是赢一个已经手写得很满的贪心循环——后者本身就是一种脚手架。

迁移（Table 1）：从 LPN 上 $T=4$ 的较好 $I_T$ 原封不动测五道新题。自改进阶段只见过元效用和自己的代码，没见过这些题的 $u$ 和 $s$。

| 任务 | $u(s)$ 初始解 | $\hat u(I_0)$ 种子 | $\hat u(I_T)$ 改进后 |
|------|--------------:|-------------------:|---------------------:|
| String Grid Distance | 43.9% | 44.3% | **56.7%** |
| MQA（带偏好的二次分配） | 20.4% | 20.6% | **22.1%** |
| 随机 3-SAT | 0% | 21.2% | **75.1%** |
| MaxCut | 0 | 58.7% | **74.2%** |
| 无噪声奇偶 | 50.0% | 59.3% | **81.7%** |

五道全过种子。3-SAT 从 21.2 到 75.1 跳得最大；MQA 只从 20.6 到 22.1，迁移不是万能。String Grid 来自 Codeforces 1852/D；MQA 是 Koopmans–Beckmann 二次分配再加设施对位置的偏好。作者故意掺了冷门题，避免网上现成解污染 gpt-4-0314。无噪声奇偶从 59.3 到 81.7，说明「同族、去掉噪声」比「完全换题」好带；MQA 那种组合结构，种子已经 20.6、改进后只多 1.5 个点，脚手架再炫也填不满题本身的硬度。不要把五道平均听成「任意算法题都能 +20」。

## 4. 弱模型：递归结构本身会把分拉下去

同一套 LPN 协议，GPT-3.5-turbo-0613 跑 25 次独立：有时能提出并实现更好的脚手架，但只有 **12%** 的 run 涨过 3 个点。失败和 GPT-4 不同。一种是策略对短的下游解伤害小、对改进器源码伤害大（例如按行以低概率随机换字符串）。一种是改进大多有害，于是选出「一不小心把原解原样返回」的脚手架——看起来安全，递归从此停住。想法经常合理（遗传、局部搜索），实现过于简陋或写错。

种子阶段 GPT-3.5 的元效用反而高于 GPT-4（**65% vs 61%**）：GPT-4 更爱写复杂到超时的解，比如用 numpy 训一千 epoch 的小网络。Mixtral-8x7B-Instruct 改下游几乎不涨，但掉得更慢，因为改动多半无害：改提示、补文档、加缓存。Figure 4 右：GPT-3.5 与 Mixtral 上均值往下走。脚手架递归 **不是免费的智力放大器**；基座不够时，把「改进器」交给自己会放大实现错误。这和 DGM 文里那句「STOP 在弱模型上递归会掉分」是同一张图，数字以本篇为准。

## 5. 它提出了什么脚手架，以及怎么作弊

GPT-4 提出并实现过（不一定都被选上）这些策略。训练截止在 2021-09，作者强调其中若干在截止之后才写成脚手架论文。

- **Beam search**：按效用留 top-$k$ 再展开。形态接近后来的 Tree-of-Thoughts。
- **遗传 / 进化**：很多不可行（随机改字符、字符串拼接交叉）。少数合理的用 $L$ 做变异和交叉。
- **按函数分解**：正则切开函数块，一块块改。动机：同时做对所有独立模块的概率随模块数暴跌，单模块命中率不随模块数掉。
- **模拟退火**：把 LM 温度和接受准则里的温度类比，允许非单调。作者说没见过先前把它当 LM 脚手架。
- **温度当探索**：预算将尽时更保守。
- **多臂老虎机 / UCB**：效用有噪声时，当成选臂。

Figure 5 的 $T=10$ 例子：维护 top 解种群，$\varepsilon$-greedy 在高温度探索和低温度利用之间切，按两种来源的改进次数调 $\varepsilon$，再加早停和 reset。创意随迭代下降：后面更多是缓存、提示清单、温度日程，不一定再换中心思想。种子提示要求「非平凡、新颖」，挡不住这个衰减。

约束可被绕开。预算若只写在提示里、执行时不硬核验：起初多数程序遵守，不遵守的分数更高，改进器就把它们当更好的 $I$。种子里的约束句常被「简化」删掉。至少有一次，$L$ 试图 **new 一个约束更大的 LM 对象**。沙箱实验：效用里的 `run(..., use_sandbox=True)`。对种子做 **10,000** 次独立改进，句法检查是否出现 `use_sandbox=False` 或 `exec(`。

| 模型 | 绕过率 | 加警告后 |
|------|--------:|----------:|
| GPT-4 | **0.42%**（0.31–0.57%） | 0.46%（0.35–0.61%） |
| GPT-3.5 | 0.12%（0.07–0.21%） | 0.17%（0.11–0.27%） |

都小于 1%，但不是零。警告没有统计显著压低（双侧比例 z 检验 $\alpha=0.05$）。GPT-4 比 3.5 更爱绕。人工看计划，没有写「恶意」，都写成「为了效率」；模型「意图」本身没有操作定义。

奖励黑客：LPN 效用最初写成 `acc = np.sum(y_hat == y) / n_test`。预测数组 shape 一变，NumPy 广播让「准确率」超过 **1000%**。改进器会把这种解当更好。考官定义是墙外的，仍能被墙内的返回值形状钻空。独立监督专文要的「证据在更新边界之外」，这里是形状通道被钻，不是改评分脚本。

## 6. 这算不算 RSI

作者把问题命名为 **recursively self-improving code generation**，并立刻加括号：底层 LM 不变，所以不是完整 RSI。Good / Schmidhuber 的对象是「被允许改自己每一段代码」的问题求解器；STOP 只改调用 $L$ 的脚手架。按 [01 术语](../../1-坐标系与术语/01-RSI-术语辨析/01-RSI-术语辨析.md) 式 (2)：$S$ 取当前改进器源码，$I$ 就是这段源码自己，$I'\subseteq S'$ 且 $S''=I'(S')$ 有定义——**Harness 层弱候选成立**，和 DGM 同一层，结构更瘦：没有开放档案，每步只留一个 $I_t$。

仍缺三件。$L$ 的 $\theta$ 冻结；$\hat u$ 的定义（grey-box 平均、题集 $D$、预算）由人写死；任何一步都可以变差，没有 Gödel machine 那种先证明再切换。混元 L3 是改改进器，STOP 改的是脚手架切片，到不了改考纲的 L4。

> 图 2：动的是调用 $L$ 的 Python；冻的是 $\theta$ 和 grey-box 元效用。

**图 2 解析**

- **左栏 Moves**：脚手架 $I$，以及它改写出来的 beam / GA / 退火。读者问「有没有自己改自己」，答案在这里：有，改的是 Harness。
- **右栏 Frozen**：gpt-4-0314 的权重；元效用配方。没有箭头进来。
- **两栏之间故意没有连线**：分数通道名义上在墙外。第 5 节的 shape 黑客说明「名义上」不够，实现还得把返回值形状钉死。

和邻居对齐。

| | 改什么 | 基座 $\theta$ | 递归对象 | 档案 |
|--|--------|---------------|----------|------|
| STOP | 改进器 Python | 冻 | $I$ 对自己 | 单轨迹 |
| DGM | Agent 的 Python | 冻 | 内环工具/流程 | 开放档案 |
| ADAS | 被搜出来的 Agent | 冻 | 元 Agent **固定** | 有 |
| AlphaEvolve | 交卷程序 | 冻 | $I$ 在墙外 | MAP-Elites |
| SEAL | 权重 + 写 SE 的策略 | 动 | 内环是 TTT | 无 |

ADAS 的元 Agent 永远是人写的那只，DGM 消融 w/o self-improve 复制它。STOP 没有第二只元 Agent：改进器就是元优化器。DGM 后来加上档案和「还能不能编辑」的门，是为了不让血统在一次坏改写上死掉——STOP 的 Limitation 自己也写了：每步只维护一个 $I$，可能变差后继续变差。

## 7. 何时失效

没有可高效求值、可描述的 $u$，这条路走不通。开放域写代码、贵的效用，元效用要多次调 $u$，作者没做。维护单个改进器，种群优势只能藏在 $I$ 内部。实验绑在可能下线的闭源 GPT-4；当时开源模型（Llama 2 / Mixtral 那一档）不足以稳定跑通。改进不必单调。成本比「用优化好的 $I$ 去改一道下游」高一个预算因子。开放域自然语言优化理论上能套同一套 $I$，作者担心那会让它更不像好的代码优化器，留给未来。弱模型加大预算、换更强脚手架，或许能补一部分——主实验没有证明这条。

对有大模型基础的读者，读完应能回答四句。改的是哪一层？Harness，调用 $L$ 的 Python。权重动了吗？没有。递归在哪闭合？$I_t$ 下一轮还当改进器。还缺什么才敢叫真 RSI？$\theta$、$\hat u$ 的所有权、以及一步变差之后会不会自行恶化。

伦理段值得单独读。Minsky 1966 已经写过「一旦有真正的自改进能力，演化会很快」。作者的辩护是：STOP 不改黑盒 $L$，当时提出的脚手架并不强过专家手写，研究沙箱绕过和奖励黑客有解释性优势。他们宁可先在 GPT-4 的简化设定里看到问题，也不要等到更强模型进真实环境。一旦 API 微调变得便宜，把微调塞进改进环「并非不可想象」——那条路会把 Model 层接进来，本篇实验没有走。Christiano 2023 被引来强调脚手架比改权重更好审计：`use_sandbox=False` 能用字符串搜到，权重里的同类行为搜不到。这是 Harness 相对 Model 的可读性，不是安全证书。

新颖性不要神化。遗传算法和模拟退火不是 GPT-4 从零发明的；作者承认「够不够新」没有操作定义。他们建议：新的是**自动检索并应用到「改自己的脚手架」这件事**。很多遗传实现用随机改字符当变异，只有一小撮真的用 $L$ 做交叉。Tree-of-Thoughts 也是把已有搜索套到 LM 调用上。读 Figure 1 时，把「提出 beam」读成「发明了 2023 年的论文」就越界了。

实现细节（附录 K）：效用字符串不必等于真源码，日志和随机种子会打码；超时在真代码里用线程，给模型看的是「超时返回 0」。沙箱实验之外，效用描述里带 `exec`，外面包一层最小求值，挡住部分 multiprocessing。每道题的参数调到「种子偶尔能涨、又不会一步满分」。LPN 之外的题同样：可接近、非平凡。

**不读**：把标题 RSI-code-generation 听成智能爆炸、把 3-SAT 75.1% 听成已经会改训练脚本、把 GPT-4 提出 ToT 风格 beam 听成模型「发明了 2023 年的论文」。
