# 37 A-Mem：卡片会连，提示冻着

摘要写动态组织、记忆演化、相对现成 SOTA 全面更好。打开 Table 1：GPT-4o-mini 的多跳 F1，LoCoMo 全上下文 **25.02**，MemGPT **26.65**，A-Mem **27.02**。差 **0.37**。正文却写 GPT 模型上多跳「至少两倍」。两倍对得上的是时间题：同骨干 A-Mem **45.85**，MemGPT **25.52**。对抗题上全上下文 **69.23**，A-Mem 只有 **50.03**。人把「agentic memory / evolution」听成自我进化，缺的是：会改的是旧卡片上的关键词、标签和一句上下文，三份提示 \(P_{s1}/P_{s2}/P_{s3}\) 冻着，嵌入冻着，\(k\) 按骨干和题型人事先表好。

本篇夹在 [MemGPT](../36-MemGPT-操作系统式记忆/36-MemGPT-操作系统式记忆.md) 和 [Argus](../01-Argus-Verification-Gated/01-Argus-Verification-Gated.md) 旁边。Argus 点名 MemGPT / A-MEM 有分层记忆、没有角色提交。MemGPT 专文的 93.4 是 MSC 上的话题级裁判；本表 MemGPT 是 LoCoMo QA 的对照实现，4o-mini 多跳只有 26.65。两套数字禁止横加。[Dynamic Cheatsheet](../33-Dynamic-Cheatsheet-测试时备忘录/33-Dynamic-Cheatsheet-测试时备忘录.md) 整本改备忘录；[AWM](../35-AWM-工作流记忆/35-AWM-工作流记忆.md) 抽网页子程序。这边抽的是原子笔记加连边。**不是** RSI。**不是** 改 \(\theta\)。**不是** 术语式 (2)。一手：Xu, Liang, Mei, Gao, Tan, Zhang，Rutgers / AIOS Foundation，[arXiv:2502.12110](https://arxiv.org/abs/2502.12110)，NeurIPS 2025。评测代码 [WujiangXu/AgenticMemory](https://github.com/WujiangXu/AgenticMemory)，产品库 [WujiangXu/A-mem-sys](https://github.com/WujiangXu/A-mem-sys)。数字以 HTML Table 1–3、Table 8、§3–§4、§6 为准。禁止用手抄 Figure 3 / 4 柱高和 t-SNE 去改表。禁止和 MemGPT 专文的 DMR、ExpeL 的 HotpotQA、AWM 的 WebArena 横加。

## 1. 问题：记忆结构人写死，图数据库也还是预定义边

作者写现成 Agent 记忆多半要人先规定：存在哪、何时写、何时取。Mem0 一类把图数据库接进来，图式仍是预置 schema。数学题上新学到一种解法，也只能掉进已经画好的格子，长不出新的组织法。MemGPT 被写成偏缓存、偏近因。A-Mem 要的是卡片盒：一条互动写成一张原子笔记，笔记自己带关键词、标签、一句上下文，再用语言模型决定和哪些旧笔记连，并允许新笔记回头改旧笔记的属性。宣传句带上没有预定操作、长期交互。花园要钉的是：没有预定的是边的具体名单，预定的是三份提示和检索器。

\(S\) 取这次运行里的笔记库 \(\mathcal{M}\)：每张 \(m_i=\{c_i,t_i,K_i,G_i,X_i,e_i,L_i\}\)。单轮 \(S'=I(S)\) 可以发生：多一张笔记，旧笔记的 \(K,G,X\) 被改写。术语式 (2) 还要 \(I'\subseteq S'\)。下一轮仍用附录 B 的 \(P_{s1}/P_{s2}/P_{s3}\)，嵌入仍是 `all-minilm-l6-v2`，\(k\) 仍按 Table 8。混元台阶上这不是 L0：会话换了，卡片还在。也到不了改改进器。更像 MemGPT / DC：留下脚手架状态，出状态的程序冻着。作者把「agency」写成比 agentic RAG 更底层——RAG 只在取的时候自主，库本身静着；这边存储结构也会长。花园同意会变的是库，不同意变的是改进器。

和邻居先划线。LoCoMo 基线把整段对话塞进提示，大约 16,910 token，没有记忆模块。ReadAgent 分页再 gist。MemoryBank 按遗忘曲线更新。MemGPT 专文是操作系统换页。本表 MemGPT 行是同一套 LoCoMo 题上的对照，不要用 93.4 去改 26.65。ExpeL 的洞察来自训练池、评测一次；这边笔记在对话流上边写边改。ACE 的 playbook 有非 LLM 合并；这边连边和演化都还是 LLM。SCM 被相关工作写成记忆流加控制器，本篇主表没有它。

LoCoMo 对话均长约 9K token、最多 35 段，共 7,512 对问答，五类：单跳、多跳、时间、开放域、对抗（原文 Adversial）。DialSim 用美剧多角色对话，约 350,000 token，用来另报一张小表。

## 2. 机制：写卡片、连边、改旧卡片、再按查询取

卡片盒借 Ahrens 的原子笔记：一张卡片一件事，靠链接而不是靠事先画好的抽屉。A-Mem 把这件事交给语言模型。库 \(\mathcal{M}=\{m_1,\ldots,m_N\}\)，每张笔记写成

\[
m_i=\{c_i,t_i,K_i,G_i,X_i,e_i,L_i\}.
\tag{1}
\]

\(c_i\) 是这次互动原文，\(t_i\) 是时间戳。其余四项都是后写的：\(K_i\) 关键词，\(G_i\) 标签，\(X_i\) 一句上下文，\(L_i\) 连出去的邻居。新互动进来，附录 B.1 的 \(P_{s1}\) 要求吐 JSON：至少三个关键词、三个标签，不要把说话人名字和时间当关键词；上下文压成一句，覆盖主题、论点和对象。公式写成

\[
K_i,G_i,X_i\leftarrow\mathrm{LLM}(c_i\,\|\,t_i\,\|\,P_{s1}).
\tag{2}
\]

嵌入不是只编码原文。\(c_i,K_i,G_i,X_i\) 拼起来再过同一只 `all-minilm-l6-v2`：

\[
e_i=f_{\mathrm{enc}}[\mathrm{concat}(c_i,K_i,G_i,X_i)].
\tag{3}
\]

检索器和连边过滤器共用这只编码器。人换嵌入，等于人改 \(I\)。实验里六只骨干、所有对照方法都钉死这一只，花园不当「模型自己学会了组织法」。

连边不扫全库。新笔记 \(m_n\) 和每张旧笔记算余弦 \(s_{n,j}\)，取 rank 不超过 \(k\) 的近邻 \(\mathcal{M}_{\mathrm{near}}^{n}\)，再把近邻和 \(P_{s2}\) 一起交给语言模型，写出 \(L_i\)。附录 B.2 把角色写成 memory evolution agent，问的是这张新卡片该不该跟近邻发生关系。没有金标告诉「该不该连」。嵌入先砍候选，语言模型再看有没有共享属性。作者把它写成边从内容里长出来，不是人先画 schema。schema 其实在提示里：JSON 字段冻着，变的是这次填进去的 id。

演化发生在连边之后。对每个近邻 \(m_j\)，\(P_{s3}\) 看新卡片、其余近邻和 \(m_j\) 自己，决定要不要改它的上下文、关键词、标签。\(m_j^*\) 替换 \(m_j\)。附录 B.3 的 JSON 带 `should_evolve`，动作名单写成 strengthen / merge / prune，还可以改邻居的 tags 和 context。这就是摘要里的 memory evolution。改的是旧卡片上的字，不是 \(P_{s3}\) 自己。局限节承认：不同骨干会写出不一样的上下文和连边。质量跟着底层模型走，没有单独的准入角色。错上下文一旦写进近邻，后面检索会一起用歪。

查询 \(q\) 用同一只编码器得到 \(e_q\)，再按余弦取 top-\(k\)。图 2 还写：取到一张，同一「盒子」里连着的也会带上。盒子可以重叠，一张笔记可以同时在几个盒子里。这是卡片盒借喻，不是另一套可学习聚类。附录 B.4 给过一道题：Dave 2023 年 10 月新爱好是摄影。取回来的卡片带 keywords `photography / scenery / hobby`，邻居是 Calvin 谈音乐实验。花园当检索样例，不当另一张表。

默认 \(k=10\) 是正文的效率说法。Table 8 把 GPT-4o-mini / GPT-4o 的主表钉成：多跳和时间 **40**，开放域和单跳 **50**，对抗 **40**。Qwen2.5-1.5B / Llama 3.2-1B 五行都是 10。Qwen2.5-3B 只把开放域调到 50。Llama 3.2-3B 只把时间题调到 20。附录写已经 SOTA 的就不再调、保持 10。GPT 主表并没有在 10 上跑满。人按题型改 \(k\)，就是改检索预算，也是改 \(I\)。

实现细节写在 §4.2。对照方法和 A-Mem 共用同一份系统提示（附录 B）。Qwen 1.5B / 3B 和 Llama 3.2 1B / 3B 走本机 Ollama，结构化输出交给 LiteLLM。GPT 走官方 structured output。评测代码在 AgenticMemory；产品库 A-mem-sys 不进 Table 1。

**图 1 解析**

- **Construct**：\(P_{s1}\) 写出 \(K,G,X\)。附录要求至少三个关键词、三个标签，不要把说话人名字和时间当关键词。

## 4. 这不是术语式 (2)，演化也不是改进器

笔记库变了，下一问可能取到「连着的那几张时间卡片」。改进器没变。\(P_{s1}/P_{s2}/P_{s3}\)、`all-minilm-l6-v2`、Table 8 的 \(k\)、结构化输出协议都还在。混元 L0 装不下跨会话保持；L3 要改提议 / 选择程序。本篇停在留下状态、不改程序。摘要里的 continuously refine its understanding 指旧卡片的字被新经验改写，不是提示在改自己。

和 MemGPT 钉死。专文 DMR 93.4 是 MSC + 慷慨裁判；本表 26.65 是 LoCoMo 多跳 F1。token 16,977 对 2,520 是这张 QA 的窗口账单，不是换页论文的 8k 窗口。MemGPT 用函数换页，结构是 RAM / 磁盘；这边没有分页函数，有的是卡片属性和边。和 LoCoMo 全上下文钉死。对抗题和 GPT-4o 单跳上，把整段塞进去可以更高；A-Mem 赢在时间和小模型多跳，也赢在 token。和 ReadAgent / MemoryBank 钉死。gist 分页和遗忘曲线在 GPT 多跳上掉到个位数，不能拿它们的低 token 去证明「记忆越短越好」。和 DC / AWM 钉死。备忘录、网页子程序、卡片盒不是同一块 \(H_t\)。和 ACE 钉死。playbook 合并是非 LLM 代码；这边连边和演化都还是 LLM。和 Argus 钉死。没有提交人、没有合约，连不连、改不改旧卡片，都是同一只 LLM 说了算。

对有大模型基础的读者，读完应能回答四句。改的是哪一层？Harness 里的笔记库和连边。权重动了没有？没有。多跳是不是至少两倍？GPT-4o-mini 上不是，27.02 对 26.65。还缺什么才叫花园 RSI？写卡片或连边的提示进入 \(S'\)，并且下一轮组织器用的就是升级后的那份。作者把多模态、承认骨干会写出不同连边，写成还没做。没有墙外检查「这张卡片该不该改」。同一只模型既写卡片又改邻居，没有 ACE 那种拆开的 Reflector，也没有 Argus 那种提交人。错上下文一旦写进近邻，后面几轮会一起用歪，收不回来。

**图 2 解析**

- **会变**：\(\mathcal{M}\) 里的 \(K,G,X,L\)，本题答案。
- **冻 \(\theta\)**：六只骨干只当处理器；嵌入 `all-minilm-l6-v2`。
- **冻 \(I\)**：附录 B 三份提示、Table 8 的 \(k\)、结构化 JSON。
- **门**：F1 / BLEU 对金标短答。对抗题金标是「不可答」。没有 Argus 那种准入。
- **下一轮**：库携带。提示不携带「上次该怎么连边」的升级。

作者把 agency 写成比 agentic RAG 更底层：RAG 只在取的时候决定取什么，库本身静着；这边存储结构也会长。花园同意会变的是库。检索器、提示、\(k\) 表仍静着。Self-RAG / 主动检索那类工作，本篇相关工作点过，主表没有拿来对照。不要用它们的检索时自主去改 27.02。

## 5. 卡片盒能长边，长出来的不是改进器

同一句「记忆会自己组织」，至少分三截。MemGPT 用函数换页，结构是 RAM / 磁盘。图数据库用预置关系。A-Mem 用语言模型给每张卡片写属性再连。三截都还在 Harness。相关工作点了 SCM、Mem0、agentic RAG。本篇主表只有 LoCoMo 和 DialSim。HotpotQA 的 39.0 在 ExpeL 专文，不要搬过来垫 27.02。

「没有预定操作」要拆开。预定的是提示和 \(k\) 表；不预定的是这次会连哪几张。Table 8 把 GPT 的 \(k\) 调到 40/50，等于人按题型改检索预算。附录写已经 SOTA 的就不再调、保持 10——小模型那几行。人改 \(k\) 就是改 \(I\)。Figure 3 还显示 \(k\) 不是越大越好。这是 L2 脚手架在流内变厚的证据，也是配方冻着的证据：每张新卡片仍走同一份 \(P_{s1}\)。

对照四家要按附录 A.1 读。LoCoMo 没有记忆模块，整段对话进提示。ReadAgent 先分页、再 gist、再按需回看。MemoryBank 按艾宾浩斯曲线调强度，还建用户画像。MemGPT 是主上下文加外存。A-Mem 赢的是结构化笔记加连边，不是「又一种压缩」。HippoRAG、ChatDB 出现在综述记忆段，本篇主表没有它们，花园也不拿来垫 27.02。

对抗题是这张表的诚实格。全上下文 69.23，A-Mem 50.03。记忆系统更会把可答的时间题连起来，不一定更会拒绝不可答。开放域 GPT-4o-mini 上 12.14 对 12.04，几乎没动。把五类平均听成「全面更好」，缺的是对抗和开放域。排序 1.2 是五类名次平均，不是 F1 均分。正文把 GPT 上的多跳写成至少两倍，花园以表为准：4o-mini 27.02 对 26.65，4o 32.86 对 30.36。

产品库 `A-mem-sys` 不是 Table 1。花园只认 2025 年这篇 LoCoMo / DialSim。t-SNE 只说明嵌入更抱团，不改 27.02。附录另报 ROUGE / METEOR / SBERT 和 Claude / DeepSeek，正文把 GPT 与 Qwen / Llama 六只当主表；附录那句 Qwen2.5-15b 的六倍 ROUGE 不进主列，主表没有 15B 这一行。局限节只承认两件事：组织质量跟着骨干走，以及还没有多模态。没有墙外检查「这张卡片该不该改」。

生成提示不会因为某次连边成功就多一条规则进仓库。人要改 \(P_{s2}\)、换嵌入、把演化交给可训练模块，都是改 \(I\)。这和 DGM 改自己的 Python、STOP 改改进器源码正好相反。作者把 A-Mem 写成 agentic memory，花园读成 2025 年这篇的定位，不读成已经闭合的递归。

LoCoMo 均长约 9K token、最多 35 段，相对旧对话集大约 1K token、四五段。7,512 对问答里对抗题专门测「这题没法答」。记忆系统更会把可答的时间题连起来，不一定更会拒绝。开放域还要对话外知识，4o-mini 上几乎没动，说明卡片盒帮的是库内关系，不是外挂百科。这和 ExpeL 的 HotpotQA 多跳不是同一张卷：那边有维基搜索，这边只有对话记忆。

**读**：Table 1 的 27.02 / 45.85 / 50.03、全上下文对抗 69.23、GPT-4o 多跳 32.86 仍不是两倍、DialSim 3.45 的 35% / 192% 是相对涨幅、token 1,216 对 16,900、消融 9.65 / 21.35 / 27.02、Table 8 的 40/50、三份提示冻着、不是 93.4、不是式 (2)。  
**不读**：把多跳听成至少两倍、把 35% 听成百分点、用 93.4 改 26.65、用手抄 t-SNE 说已经自己会分类、说提示已经在优化自己、说已经 RSI。
