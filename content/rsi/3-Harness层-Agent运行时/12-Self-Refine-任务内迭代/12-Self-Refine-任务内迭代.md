# 12 Self-Refine：这轮改完就丢

同一只模型先写一稿，再骂自己，再按骂的改。摘要写七项任务平均绝对约 **+20%**，连 GPT-4 也能在测试时再抬一截。打开 Table 1 的数学行：GPT-4 **92.9 → 93.1（+0.2）**，ChatGPT **74.8 → 75.0**，GPT-3.5 **64.1 → 64.1**。对话偏好可以从 25.4 拉到 74.6，算术几乎不动。把 +20% 听成「模型会自我进化」，[01 术语](../../1-坐标系与术语/01-RSI-术语辨析/01-RSI-术语辨析.md) 已经标过的 L0 就被盖掉了。

本篇是 Harness / 推理时最浅的那一格：任务内迭代，独立下一题从干净状态开始。[Reflexion](../11-Reflexion-言语反思记忆/11-Reflexion-言语反思记忆.md) 把失败写成 `mem`，下一 trial 还能读；这里历史只拼在**这一题**的提示里，题换了就没了。[Gödel Agent](../06-Godel-Agent-自指运行时/06-Godel-Agent-自指运行时.md) 把手写 Self-Refine 写成「部署之后模块图不变」的对照，数字是另一套评测，不要和本篇 Table 1 横加。**不是** RSI：三份 few-shot 提示、$M$、停止规则都不进 $S'$。**不是** 微调、不是 RL。一手：Madaan, Tandon 等，CMU / AI2 / UW / NVIDIA / UCSD / Google Brain，[arXiv:2303.17651](https://arxiv.org/abs/2303.17651)，NeurIPS 2023；演示 [selfrefine.info](https://selfrefine.info/)。数字以 HTML Table 1–2、Table 9、Table 13、Fig. 4、§3.3 数学段为准。

## 1. 问题：第一稿不够好，又不想再训

对话、改代码、倒情感、塞 20–30 个关键词进一句话，目标是多方面的，第一稿常缺一块。以往做法是训一个专门的改写模型，或上奖励模型，都要数据。Self-Refine 只要一只 $M$ 和三份提示：初次生成 $p_{\mathrm{gen}}$、反馈 $p_{\mathrm{fb}}$、改写 $p_{\mathrm{refine}}$。反馈要 actionable 且 specific：指出该改哪句、建议什么动作。例如代码：「for 循环是暴力法，改用 $n(n+1)/2$」。笼统的「写高效一点」是消融里的 generic feedback，分数会掉。

$S$ 取「当前这道题的推理会话」：$M$ 冻着，提示冻着，变的是 $y_t$ 和拼进提示的历史 $\{(y_i,fb_i)\}$。单轮 $S'=I(S)$ 可以发生——$y$ 变好了。式 (2) 还要 $I'\subseteq S'$。下一道独立题仍用同一份 $p_{\mathrm{fb}}$，没有把这次教训写进磁盘或权重。混元 L0：改 $(\text{输出},\text{轨迹})$，保留的 Agent 状态跨独立任务不变。

和邻居先划线。Reflexion 相关工作表给 Self-Refine 的 Memory 打叉。差不是会不会自评，是自评的句子会不会成为**下一 trial / 下一题**的条件。Self-Refine 的历史只服务这一题的后续迭代，最多 4 轮。ACE 的 playbook、Voyager 的函数、SPIN 的 checkpoint 都比这活得长。可靠性专文把本方法放在 L0，和 ToT、链式验证一类。[01 术语](../../1-坐标系与术语/01-RSI-术语辨析/01-RSI-术语辨析.md) 判定表第一行就是本方法：自身跨任务不保持，$I$ 不升级。读完本篇应能把那一行从口号还原成 Table 1 的数学格。

约束生成是作者新加的硬版 CommonGen：关键词从 3–5 个加到 20–30 个。漏几个表面就能看见，所以改写有抓手。数学漏的是中间一步等式，表面上看着完整。同一套 $p_{\mathrm{fb}}$，可见缺口和不可见缺口不是一类题。这不是「Self-Refine 不会数学」，是「没有墙外对错时，它不知道该骂哪一行」。

![同一只 M：生成 y，写反馈 fb，再写出 y'；历史只留在本题提示里](./images/fig-selfrefine-loop.png)

> 图 1：实线是本题内的反馈–改写。虚线是把旧稿拼回提示。题换了，虚线断开。

**图 1 解析**

- **$M$ 一只**：生成、反馈、改写共用参数，few-shot 不同。
- **$p_{\mathrm{fb}}$**：要具体、可执行，不要「整体不错」。
- **停止**：步数帽，或从反馈里抽出 stop 分数。实践最多 4 轮。
- **历史**：本题的旧 $y$ 和 $fb$ 追加进提示，避免重复犯错。不是跨题 `mem`。

## 2. 机制：三份提示，没有训练

算法可以收成：用 $p_{\mathrm{gen}}$ 写出 $y_0$；for $t=0,1,\ldots$：用 $p_{\mathrm{fb}}$ 写出 $fb_t$，用 $p_{\mathrm{refine}}$ 写出 $y_{t+1}$，直到 stop。监督只在 few-shot 里。正文写 greedy decoding、温度 0.7。基座对照：GPT-3.5（text-davinci-003）、ChatGPT（gpt-3.5-turbo）、GPT-4；代码任务另试 Codex。主表对照是**同一只基座的单次生成**，不是另一个训练过的改写器。引言另写过 5–40% 的绝对区间；海报数字用 $\sim$20%。读哪句都要回到 Table 1 的分任务行。

引言里的邮件例子把 $I$ 讲成人话。第一稿「Send me the data ASAP」；同一只 $M$ 看出不礼貌，改成「could you please send me the data at your earliest convenience」。没有人在回路里点同意，也没有奖励模型打分。代码例子更硬：六层嵌套循环枚举硬币组合，反馈写出「该用动态规划」，改写后复杂度收到 $\mathcal{O}(\mathrm{amount}\times\mathrm{coins})$。基线那份「优化」几乎只改了读输入，逻辑还是慢的。反馈要能定位短语或循环，不能只说「再好一点」。

相关工作 Table 3 把来源拆开：人、标量奖励、编译器、维基编辑。作者的钉子是：用 LLM 对自己的输出写自然语言反馈，并且**同一只** LLM 接着改。Welleck 等的 Self-Correct 要训一个 corrector；附录对照同一 GPT-3、同一 GSM8K 设定，Self-Correct **45.9**，Self-Refine **55.7（+9.8）**。这格不是 Table 1 的 GPT-3.5 数学 64.1，不要并成一行。DrRepair 看编译器，CodeRL 看单测，都不是「自己骂自己」。花园要的差也在这里：执行器、编译器、金标一旦进门，循环就不再是纯 L0 的自我确认。

七项任务不要收成一张准确率榜。有任务指标的：数学（GSM8K 类解题率）、代码优化（程序被优化的百分比）、约束生成（覆盖率）。情感、对话、缩写主表用 GPT-4 偏好代理；人类盲选 A/B 另做。GPT-4 偏好与人类的一致率：情感反转 82%、缩写 68%、对话 71%。Table 13 把这句话写死：这三列报的是 GPT-4 选中的百分比，其余算平局。读 GPT-4 + Self-Refine 的对话 **74.6** 时，生成器和裁判可以是同一家。代码可读性让 GPT-4 数变量名起得是否像样（`x=[]` → `input_buffer=[]`），也不是 pass@1。

停止条件按任务定。多面任务（缩写）一轮可能一面变好、一面变差，作者让模型给发音、拼写、相关、正面内涵各打分再选。附录 Table 10 里同一个缩写从 11 分跳到 17，下一轮掉回 12，再回到 17。Fig. 4 把 $y_0$–$y_3$ 均分（三只基座平均）：代码优化 22.0 → 27.0 → 27.9 → 28.8；情感 33.9 → 34.9 → 36.1 → 36.8；约束生成 29.0 → 40.3 → 46.7 → 49.7。早轮涨得多，后面边际变小。不是单调保证。

消融 Table 2（ChatGPT 做代码优化 / 情感，GPT-3.5 做缩写）：具体反馈 vs 笼统反馈 vs 无反馈。代码优化 27.5 / 26.0 / 24.8；情感 43.2 / 31.2 / **0**（无反馈任务塌掉）；缩写 56.4 / 54.0 / 48.0。没有 $fb$，只让模型再写几遍，不够。1 vs $k$：ChatGPT 一次采 $k=4$ 个初稿，人仍更偏好 Self-Refine 的那一条。多采样替代不了「按自己的批评改」。另一次消融把反馈收成「something is wrong」：情感偏好从 85% 掉到 73%，dramatic response 从 80.09% 掉到 58.92%。定位比口号值钱。

数学是机制上的试金石。错误可能只在一行运算，看起来连贯的推理会骗过 $M$。ChatGPT 的反馈里 **94%** 写 everything looks good。附录 H.1 的 Oracle 设定：只有当前答案错了才进入改写，对错信息来自外部。Table 9：GPT-3.5 **64.06 → 68.9（+4.8）**，ChatGPT **74.8 → 76.2（+1.4）**，GPT-4 **92.9 → 93.8（+0.7）**。正文写过「5%+」，精确数以 Table 9 为准；GPT-4 在已经 92.9 的天花板上，oracle 也只再抬 0.7。墙外信号一接上，循环就不只是在自我确认。这和 [Reflexion](../11-Reflexion-言语反思记忆/11-Reflexion-言语反思记忆.md) 编程用自写单测、HotPotQA 用 EM 是同一类分叉：门在墙内还是墙外，决定分数能不能当真。

Vicuna-13B 单独跑 Self-Refine 时，反馈经常对不上格式；即便塞进 Oracle 或写死的反馈，改写也会重复原稿或编一段对话。作者猜它偏对话训练，测时 few-shot 改写推不动。换设定：Vicuna-13B 出初稿、ChatGPT 做反馈和改写，数学 **24.18% → 40.5%**。这是混尺寸，不是主表。它说明初稿可以更弱，批评仍要更强的 $M$——还是没改权重。弱基座上，「自己骂自己」加不成。Reflexion 的 starchat-beta 0.26=0.26 是同一类现象。

后续工作 Huang 等 [arXiv:2310.01798](https://arxiv.org/abs/2310.01798) 问：没有外部反馈时，LLM 能不能自我纠正推理。本篇不把他们的表并进 Table 1；综述转述的掉分见 [02 可靠性](../../6-评测与安全/02-可靠性与独立监督/02-可靠性与独立监督.md)。花园只借一句：Table 1 的数学行已经显示，内在自纠正在解题率上几乎不工作；把 +20% 听成「推理也会自我进化」，是把偏好任务的涨幅平均进了算术。

正文还写：即便 GPT-4 的单次生成低于 GPT-3.5，加上 Self-Refine 之后仍能反超。对话就是这样：基座 25.4 低于 GPT-3.5 的 36.4，改写后 74.6。作者把它听成更强模型把潜力解锁。花园读法：偏好裁判也是 GPT-4 时，解锁和「自己给自己打高分」不好分。数学上 GPT-4 基座已经 92.9，没有潜力可解锁，+0.2 留在噪声里。Table 13 还写：GPT-4 增益几乎都显著，ChatGPT 七项里四项显著，GPT-3.5 只有三项。数学三格都没有星号，和 +0.2 对得上。读「consistently improves across all model sizes」时，把数学从 consistently 里拿出来。闭源模型的预训练语料、尺寸和偏见，现有文献写不全，作者自己写在局限里。花园不把 GPT-4 偏好 74.6 外推到开源 7B。网站生成附录证明循环能改审美，证明不了循环能看见算术错误。

70 个样本的手工分析（代码优化 + 数学，成败各 35）。失败里：33% 反馈指错位置，61% 建议了不该用的修法，只有 6% 是改写器把好反馈执行坏。成功里：61% 被准确反馈领着走，33% 反馈只对了一部分仍能改对。作者把它写成对次优反馈有弹性。弹性救不了「everything looks good」——那一格连位置都没有。不要把 61% 听成主表。

对话附录另抽过错：错误反馈 25%、笼统反馈 30%、打分错 10%；改写阶段不稳健 10%、忽略反馈 25%、引入新问题 20%。60% 的时候改写器能扛住错误或笼统的反馈。这是定性，样本不是 Table 1。

数据集规模（附录任务表）：情感 1000 条评论、对话 372、代码优化 1000、可读性 300、数学 1319（Cobbe GSM8K）、缩写 250、约束 200。主表不是这 1319 上的 20 个点，是分任务分指标。[Gödel Agent](../06-Godel-Agent-自指运行时/06-Godel-Agent-自指运行时.md) / [ADAS](../07-ADAS-Meta-Agent-Search/07-ADAS-Meta-Agent-Search.md) 表里的 Self-Refine 59.2 / 31.6 是另一套下游实现、另一只骨干，用来衬「手写循环不会改自己」。不要回头改写本篇 Table 1。

## 4. 这不是式 (2)，也不是 Reflexion 的窗口

$y$ 变好了，改进器没变。下一题的 $p_{\mathrm{fb}}$ 还是人写的那份。混元 L0：好处和危害都随 episode 丢弃。不要用对话 +49.2 给 [SEAL](../../2-Model层-训练时自改进/04-SEAL-自适配语言模型/04-SEAL-自适配语言模型.md) 的 LoRA 或 [DGM](../04-DGM-达尔文哥德尔机/04-DGM-达尔文哥德尔机.md) 的自改 Python 背书。局限节自己写：实验用的是闭源 GPT 家族，预训练语料和尺寸不全公开，调用要花钱。代码和输出放出来了，改进器本身仍是人钉的三份提示。

和 [Reflexion](../11-Reflexion-言语反思记忆/11-Reflexion-言语反思记忆.md) 钉死。那边 Actor / Evaluator / Self-Reflection 三角色，`mem` 跨 trial，AlfWorld 重置房间但留句子。这边三角色塌成同一只 $M$ 的三份提示，历史不跨题。Reflexion 的数学不在主表；Self-Refine 的数学在主表上接近 0。两边都叫自我反馈，门完全不同。Reflexion 编程还有自写单测当 $M_e$；Self-Refine 的代码优化反馈是自然语言「太慢」，执行器不是主循环的必选零件。论文 Figure 5 的硬币 DP 是改完就交卷，没有把「下次遇到嵌套循环先写 DP」写进磁盘。

[ACE](../09-ACE-Agentic-Context-Engineering/09-ACE-Agentic-Context-Engineering.md) 把 Self-Refine / Reflexion / [TextGrad](../14-TextGrad-文本梯度/14-TextGrad-文本梯度.md) 写成「自然语言反馈会越改越吵」的前史。Self-Refine 用 4 轮帽限制变吵。吵完就丢，也存不下来。[SkillEvolver](../08-SkillEvolver-元技能/08-SkillEvolver-元技能.md) 要把教训写成另一只 Agent 的文件。本方法连文件都没有。[Voyager](../10-Voyager-Minecraft技能库/10-Voyager-Minecraft技能库.md) 过门的是 JavaScript；这里过门的是本题的 $y_{t+1}$。

[可靠性](../../6-评测与安全/02-可靠性与独立监督/02-可靠性与独立监督.md) 的 L0 原句可以当本篇判定：改变输出与轨迹，跨独立任务状态不变。数学 +0.2 是 L0 在「对错可验证」任务上的诚实结果；+20% 是把偏好任务平均进去之后的海报数字。两套都要会读。附录还做过网站生成：用户给高层目标，循环改 HTML / CSS / JS。那是演示，不是 Table 1，不要拿审美迭代给 GSM8K 背书。

对有大模型基础的读者，读完应能回答四句。改的是哪一层？本题输出，L0。权重动了没有？没有。+20% 能不能当推理自进化？不能，数学三项几乎是 0，Table 13 也没给数学星号。还缺什么才叫花园 RSI？三份提示或停止规则进入 $S'$，并且下一题的改进器用的就是升级后的那份——目前每题从同一份 few-shot 再开始。

## 5. 草稿的寿命，和句子、函数、权重不是一类

同一句话「模型在改自己」，至少有四段寿命。Self-Refine 的 $y_t$ 活过本题最多 4 轮，题换了提示历史清空。Reflexion 的 $sr$ 活过同一任务的若干 trial，窗口满了会滑掉。Voyager 的函数默认留在磁盘，换世界还能检索。SPIN / SEAL 的寿命在 checkpoint 或会回滚的 LoRA。四段不要收成「都在自我进化」。

Gödel Agent 把手写 Self-Refine 放进「部署之后模块图不变」。读法：循环可以在一次任务里把答案改漂亮，但下次怎么生成、怎么批评、何时停，仍是人写的 $p_{\mathrm{gen}}$ / $p_{\mathrm{fb}}$ / $p_{\mathrm{refine}}$。STOP 和 DGM 动的是改进器源码。本篇连源码都不动，只动字符串 $y$。浅不是没用。约束生成 GPT-4 从 15.0 到 45.0，漏概念这种表面缺口，自我批评补得上。GSM8K 那种「错在一行却看起来连贯」，同一套批评看不见。读新闻时先问留下的是草稿、句子、函数还是权重，再问门是自评、自写单测还是金标。

三份提示是人的 $I$。Agent 改不了「反馈要 actionable」这条规则，也改不了 4 轮帽。人把帽改成 8，只是人改了 $I$，不是系统改了自己。few-shot 里的 $\langle x,y,fb\rangle$ 三联组同样是人钉的示范，不会因为某道题改写成功就多一条示范进仓库。这和 ACE 的 Merge 追加条目、Voyager 的技能入库正好相反：那边 $H_t$ 变长；这边 $H_t$ 在题与题之间是空的。

附录把可读性循环拉到 $N=5$，批判温度 0.0 与 0.7 两条曲线：更高温度更爱改变量名和注释，贪心更爱拆函数。Table 14 在 $T=0.7$ 上，有意义变量名、注释、函数单元三项的均值可以高过人类改写员。那是可读性，不是 GSM8K。不要拿「比人还会起名」去盖 Table 1 的数学 +0.2。闭源模型、要付费、语料不公开，作者自己写在局限里；花园不把 selfrefine.info 的演示站听成可复现的开源基座实验。同一套 few-shot 不会因为这题改成功就多一条示范。人要加例子，得亲手改 $p_{\mathrm{fb}}$。那是改 $I$，不是 $I$ 进了 $S'$。

**读**：三份提示、最多 4 轮、Table 1 七行尤其是数学 +0.2、对话 GPT-4 +49.2 是 GPT-4 偏好、ChatGPT 数学反馈 94% everything looks good、Table 9 oracle 4.8 / 1.4 / 0.7、Table 2 无反馈情感变 0、Fig. 4 的 $y_0$–$y_3$、Vicuna 单独跑会垮、L0。  
**不读**：用 ~20% 盖数学行、把 Self-Refine 和 Reflexion 收成一篇、用 Gödel / ADAS 表里的 Self-Refine 分替换 Table 1、把 GPT-4 偏好 74.6 听成解题率、把 Vicuna 混尺寸 24.18→40.5 写进主表、把正文 5%+ 写成 GPT-4 的数学增益、说已经 RSI。
