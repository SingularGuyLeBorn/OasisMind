# 26 PromptAgent：MCTS 搜专家级提示，模型冻着

[APE](../19-APE-自动提示工程师/19-APE-自动提示工程师.md) 用蒙特卡洛提案再挑，默认不迭代。[ProTeGi](../21-ProTeGi-文本梯度束搜索/21-ProTeGi-文本梯度束搜索.md) 用错题出批评再束搜索。[AutoPrompt](../25-AutoPrompt-梯度引导触发词/25-AutoPrompt-梯度引导触发词.md) 要嵌入梯度换触发词。PromptAgent 把提示版本当成状态，把「看错题写出的反馈」当成动作，用 MCTS 在提示空间里选、扩、模拟、回传。默认被优化的基座是 GPT-3.5，优化器是 GPT-4。BBH 六套均 **0.802**，APE **0.690**，少样本 CoT **0.707**。作者写成相对 APE 提高 11.2%、相对 CoT 9.5%、相对人手零样本 28.9%。花园钉差：0.802−0.690=0.112，0.802−0.707=0.095，0.802−0.513=0.289，是**百分点**，不是相对涨幅（相对大约 16% / 13% / 56%）。Object Counting 上少样本 CoT **0.960** 高于本方法 **0.860**，六套不是全赢。

本篇是 Harness 里「规划算法搜自然语言提示、交卷是一条专家级说明书」的样板。[ToT](../27-ToT-本题推理树/27-ToT-本题推理树.md) / RAP 用树搜本题推理路径；这边树节点是提示版本，题做完留下的是 \(H_t\) 里那条指令。**不是** RSI。**不是** 改 \(\theta\)。**不是** 测试时还在长树。一手：Wang, Li, Wang, Bai, Luo, Zhang, Jojic, Xing, Hu，UC San Diego / Microsoft Research / Georgia Tech / MBZUAI，[arXiv:2310.16427](https://arxiv.org/abs/2310.16427)，ICLR 2024（OpenReview `22pyNMuIoa`）。代码 [XinyuanWangCS/PromptAgent](https://github.com/XinyuanWangCS/PromptAgent)。数字以 HTML Table 1–5、Figure 2 / 4、§3.1–3.2、§4 为准。前几作者并列。仓库 README 不要写进正文。

## 1. 问题：采样只在普通人提示附近转

软提示和梯度离散搜对不上只给 API 的 GPT-4。剩下的黑盒搜，APE、GrIPS、进化算子，多半在人写初稿附近释义、增删、再采样。作者写：这样很难爬到「专家级」——任务说明、术语澄清、解题指引、例外处理、格式约束叠在同一段里。人改提示的办法是看模型错在哪，把领域知识补进去。人贵，一次只能盯几条错。PromptAgent 把这件事收成规划：状态 \(s_t=\mathcal{P}_t\) 是当前那条提示，动作 \(a_t\) 是优化器根据基座在训练批上的错题写出来的错误反馈，转移是优化器按反馈写出下一条提示。奖励 \(r\) 是从训练集再切出来的保留集上的任务分，不是测试集。

\(S\) 取当前提示。单轮 \(S'=I(S)\) 可以发生：扩一个子节点。术语式 (2) 还要 \(I'\subseteq S'\)。MCTS 迭代次数、探索常数 \(c\)、深度上限、元提示 \(m_1/m_2\)、用 GPT-4 当优化器，下一场 NCBI 原样再走。混元台阶上这是薄 \(H_t\)。交卷是最高奖励路径上的那条提示。搜索树不交卷。

**图 1 解析**

- **error expand**：基座在训练批上出错，GPT-4 写成反馈，再写成新提示。

错例格式钉死在附录 Table 8：模型输入、回复、金标、预测。error_feedback 元提示要求逐步看每道错题，列出当前提示为什么会错，最后汇总「提示还能改哪几面」。state_transit 再要求新提示解决这些问题、顺着轨迹演化、用指定标签包起来。动作不是「换一个近义词」，是一段诊断。诊断写过头就会把这道题的专有名词写进任务提示，下一道题反而有害——作者拿 MCTS 的探来挡，没有单独的过拟合表。

相关工作把 ToT、CoRe、RAP 写成给**本题推理**长树；本篇长的是**提示版本树**。Reflexion / Self-Refine 的反思服务当前 episode。本篇反思写进下一条跨题指令。Promptbreeder 让突变提示 \(M\) 进种群，本篇 \(M\) 就是冻着的两条元提示，不进化。作者写「第一个把自我反思和规划接到提示优化」，花园读成相对 2023 年采样派的定位，不读成规划算法的首次应用。

## 2. 机制：错题当动作，UCT 平衡探和用

形式目标：

\[
\mathcal{P}^{*}=\arg\max_{\mathcal{P}}\sum_{i}\mathcal{R}\bigl(p_{\mathcal{B}}(a_{i}\mid q_{i},\mathcal{P})\bigr)
\]

提示空间不可枚举。作者把它写成 MDP \((\mathcal{S},\mathcal{A},T,r)\)。动作不是换词或释义，是错误反馈。两步：基座 \(\mathcal{B}\) 在训练样本上收集错；优化器 \(\mathcal{O}\) 用元提示 \(m_1\) 把错写成反馈 \(a_t\sim p_{\mathcal{O}}(a\mid s_t,m_1)\)。再用元提示 \(m_2\) 转移 \(s_{t+1}\sim p_{\mathcal{O}}(s_{t+1}\mid s_t,a_t,m_2)\)。默认 \(\mathcal{B}=\) GPT-3.5（预测温度 0），\(\mathcal{O}=\) GPT-4（其余温度 1.0）。任务提示本身不含训练示范，作者写成传统零样本设定。

选子节点用 UCT，论文式 (1)：

\[
a_{t}^{*}=\arg\max_{a_{t}'}\Bigl(Q(s_{t},a_{t}')+c\sqrt{\frac{\ln\mathcal{N}(s_{t})}{\mathcal{N}(\mathrm{ch}(s_{t},a_{t}'))}}\Bigr)
\tag{1}
\]

\(c=2.5\)。第一项用，第二项探。扩展：对叶子多次生成动作和下一状态，可从不同训练批取样，把奖励最高的子节点送去模拟。模拟为了省钱，不随机走子：继续做「生成多个动作、只留最高奖励」直到深度上限或早停。早停条件附录写成到达终端或预设停止态。回传论文式 (2)：把从该状态出发的未来轨迹奖励平均进 \(Q\)。迭代默认 **12** 次。输出：最高奖励路径上最好的那个节点，不是访问次数最多的叶子。伪代码 Algorithm 1 把选、扩、模拟写在同一层 \(t=0\ldots L-1\) 循环里：已有子节点就 UCT 选，没有就扩 \(d\) 个再按即时奖励挑。回传从实际步数 \(T\) 倒着走。这是实现折叠，不是少了模拟。

超参三档 Standard / Wide / Lite，按奖励挑，细节在附录 Table 7：深度上限 8 / 6 / 4，expand_width 都是 3，Wide 的 num_samples=2，其余为 1。每步扩展产生 expand_width × num_samples 条新提示。训练批大小 5。没有错就继续抽批，直到抽到错。state_transit 元提示里带着从根到当前节点的提示轨迹，让新提示在旧串上演化，不是凭空写。花园不把档位写成产品旋钮。输入拼法：Prompt（被搜）+ 可选 Task Prefix（企鹅题的背景表）+ Question + 可选选项后缀 + 答题格式。APE 对照按 Zhou 等建议只做一轮迭代：初提案约 100 条（Med QA 因账单改成 25），留 5 条再提案约 50 条，一共大约 **150** 条；Greedy-S / Greedy-L 是 34 / 72。Beam 消融也是 72 条、深度 8、束宽 3。作者用 Figure 4a 说本方法点在左上：分更高、探更少。不手抄柱高。

数据切分附录 Table 6。BBH 没有官方划分，作者自己切：Penguins 训练 70 / 测试 79，Geometry 150 / 200，Epistemic 500 / 500，Object Counting 与 Temporal 300 / 500，Causal Judgment 90 / 100。NCBI 2000 / 940，Biosses 只有 60 / 40，Med QA 2000 / 500。Subj 400 / 1000，TREC 400 / 500，CB 125 / 56。奖励默认从训练再切约 150 条；训练太小或太大时改成 60 到 200。测试集超过 1000 就抽样 1000。Biosses 和 CB 很小，分数抖动会大，主表没报标准差。

**图 2 解析**

## 4. MCTS 提示树不是术语式 (2)

听成「Agent 用规划改自己怎么说话」差在主语。改的是任务说明书。谁规定 12 次、\(c=2.5\)、GPT-4 当优化器？人。谁规定奖励是保留集任务分？人。下一场任务不会因为 NCBI 那条长提示好用就升级 UCT。留下的是 \(H_t\) 里一条离散指令。\(\mathcal{B}\) 原样。配方原样。

和 [APE](../19-APE-自动提示工程师/19-APE-自动提示工程师.md) 钉死。那边提案筛选、24/24 指令归纳、GSM8K 43.0；这边 MCTS、BBH 均 0.802 对同表 APE 0.690。禁止用 0.802 改 Zhou 等的 IQM 0.810。和 [ProTeGi](../21-ProTeGi-文本梯度束搜索/21-ProTeGi-文本梯度束搜索.md) 钉死：两边都看错题，那边束搜索改分类提示，相对 \(p_0\) +15.3%；这边树搜专家说明书，没有那张 F1 表。和 [OPRO](../17-OPRO-元提示优化/17-OPRO-元提示优化.md) 钉死：历史分数进元提示，没有 UCT。和 [EvoPrompt](../18-EvoPrompt-进化算子提示/18-EvoPrompt-进化算子提示.md) 钉死：GA/DE 说明书冻着；这边冻的是 MCTS。EvoPrompt 的 BBH +3.5 和本篇 0.802 不是一列。和 [AutoPrompt](../25-AutoPrompt-梯度引导触发词/25-AutoPrompt-梯度引导触发词.md) 钉死：要梯度、触发词常不通、全量 SST-2 91.4；这边 API 黑盒、人话长指令。和 [RLPrompt](../24-RLPrompt-离散提示强化学习/24-RLPrompt-离散提示强化学习.md) 钉死：生成短乱码、SQL、RoBERTa 少样本 92.5；这边从人手初稿长出段落。和 [TEMPERA](../23-TEMPERA-测试时提示编辑/23-TEMPERA-测试时提示编辑.md) 钉死：测试时按查询 PPO，题做完扔；这边训练时长树，测试时一条提示共用。和 [Self-Refine](../12-Self-Refine-任务内迭代/12-Self-Refine-任务内迭代.md)、[Reflexion](../11-Reflexion-言语反思记忆/11-Reflexion-言语反思记忆.md) 钉死：那边改本题答案或窗口反思；这边改跨题共用的任务提示。ToT 搜的是推理树，节点不是提示版本。

弱模型读不懂长专家提示，PaLM 2 均分掉到 0.441。作者自己写：更小的 GPT-2 / LLaMA 可能更糟。奖励会把实例细节写进提示，泛化靠 MCTS 去探别的错；探不够就会过拟合保留集。GPT Agent 插件基线弱，不能据此断言「所有 Agent 框架都不会改提示」。主实验没有开源 7B 表。测试时温度 0，搜的时候优化器温度 1，换种子分数会动，主表没报标准差。优化器是 GPT-4，账单按树节点数走：每扩一次要跑基座找错、优化器写反馈、再写新提示、再在保留集上打分。APE 一轮 150 条已经贵，本方法卖点是条数更少但每条更贵。没有公开把美元写进表。Standard 深度 8、每次扩 3 条，12 次迭代的上限远小于「每层全展开」；实际节点数被 UCT 和早停截断，所以 Figure 4a 才能画在 APE 左边。Lite 把深度降到 4，Wide 用 num_samples=2 换宽度。按保留集奖励挑档，测试集不参与选档——这是 \(I\) 的验证协议，不是模型改自己的早停。

和 [GEPA](../15-GEPA-遗传Pareto提示/15-GEPA-遗传Pareto提示.md)、[Promptbreeder](../16-Promptbreeder-自我指涉提示进化/16-Promptbreeder-自我指涉提示进化.md) 钉死：那边种群和突变；这边单树、UCT。GEPA 的 Qwen3 +12.44 和本篇 GPT-3.5 的 0.802 不是一列。和 [MIPROv2](../20-MIPROv2-贝叶斯联合优化/20-MIPROv2-贝叶斯联合优化.md) 钉死：TPE 挑槽位，没有错题反馈当动作。CB 测试只有 56 条，0.911 好看，分母小。Subj 测试 1000，0.806 更稳一些。作者把十二套方向当主结论，单列小样本不当独立发现。
