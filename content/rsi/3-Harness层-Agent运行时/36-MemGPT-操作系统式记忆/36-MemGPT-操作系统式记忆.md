# 36 MemGPT：窗口当内存，配方冻着

宣传句写无限上下文、对话智能体自己记得、自己演化。打开 Table 2：Deep Memory Retrieval 上，固定上下文的 GPT-4 Turbo **35.3%**，加上 MemGPT **93.4%**。GPT-4 是 **32.1 → 92.5**。GPT-3.5 Turbo 是 **38.7 → 66.9**。人把 93.4 听成「记忆系统已经接近满分」，缺的是：分数来自一只慷慨的 GPT-4 裁判，只要生成答案碰到金标同一话题就算对；会涨的是工作上下文和两块外存，换页政策、系统提示、函数表都冻着。权重不动。

本篇夹在 [Dynamic Cheatsheet](../33-Dynamic-Cheatsheet-测试时备忘录/33-Dynamic-Cheatsheet-测试时备忘录.md)、[AWM](../35-AWM-工作流记忆/35-AWM-工作流记忆.md) 和 [Argus](../01-Argus-Verification-Gated/01-Argus-Verification-Gated.md) 旁边。DC 改一块测试时文本备忘录。AWM 从网页轨迹抽子程序。Argus 点名 MemGPT / A-MEM 有分层记忆、没有角色提交。这边把窗口当成 RAM，把召回库和档案库当成磁盘，模型用函数把自己的上下文换进换出。[ReAct](../29-ReAct-推理与动作/29-ReAct-推理与动作.md) 的轨迹随题清空；[Reflexion](../11-Reflexion-言语反思记忆/11-Reflexion-言语反思记忆.md) 留下几句失败总结，窗口一滑就丢。MemGPT 的召回库按设计无限期留着。**不是** RSI。**不是** 改 \(\theta\)。**不是** 术语式 (2)。一手：Packer, Wooders, Lin, Fang, Patil, Stoica, Gonzalez，UC Berkeley，[arXiv:2310.08560](https://arxiv.org/abs/2310.08560)（2023-10-12）。HTML 页脚写过 ICML 关键词，花园不当会议接收。代码与数据当时挂 [research.memgpt.ai](https://research.memgpt.ai)；后续产品线收进 [letta-ai/letta](https://github.com/letta-ai/letta)。专文读 2023 年这篇实验，不读后来 Letta 控制台。数字以 HTML Table 2–3、§2–§3、附录裁判提示为准。禁止用手抄 Figure 5 / 7 柱高去改表。禁止和 AWM 的 35.5、DC 的 AIME、ExpeL 的 HotpotQA 横加。

## 1. 问题：窗口有限，加长也不等于会用

作者写开源模型当时只能撑几十轮对话或一篇短文。把 Transformer 上下文直接拉长，自注意力按平方涨。即便算力够，Liu 等 2023 的 Lost in the Middle 已经显示：长窗口里中间的 token 更难被用上。所以这篇不训更长的模型，要的是操作系统那套假象：物理内存不够，就在内存和磁盘之间换页。函数调用让 LLM 自己决定读什么、写什么、什么时候把控制权交回用户。

\(S\) 取这次部署里会留下的东西：工作上下文里的句子、召回库里的消息、档案库里的文档块，外加冻着的骨干和系统提示。单轮 \(S'=I(S)\) 可以发生：工作上下文被改写，召回库多一条。术语式 (2) 还要 \(I'\subseteq S'\)。下一轮警告阈值、驱逐比例、函数 schema、系统说明书都还在。混元台阶上这不是 L0：会话或文档换了，外存还在。也到不了改改进器。更像 DC / AWM：留下脚手架状态，出状态的程序冻着。

和邻居先划线。RAG 把检索器放在模型外面，一次取出 \(K\) 篇塞进窗口。MemGPT 的检索是模型自己分页调用档案库，理论上可以翻到检索器排到很后面的金文档；正文也写它常常没翻完就停。Generative Agents 用记忆做社交沙盒，作者点名过；本篇评的是跨会话一致性和文档问答，不收模拟市民。FLARE / 交错检索是生成过程中主动取证据；MemGPT 还要自己改工作上下文、自己在压力警告下把 FIFO 里的事实搬出去。ReAct 交错想和做，题换了空。DC 没有操作系统式的队列管理器。AWM 的工作流是网页子程序，不是换页。

主上下文（prompt tokens）切成三截。系统说明书只读：控制流、各层记忆干什么、函数怎么用。工作上下文固定大小、可读写，但只能经函数写；对话设定里用来存用户和人设的关键事实。FIFO 队列滚消息：用户、系统警告、函数入参出参。队列第 0 项是一条递归摘要，概括已经被挤出去的消息。外存两块：召回库存全部消息，档案库存任意长文本。不显式搬进主上下文，处理器推理时看不见。召回和档案不要收成同一块磁盘：DMR 走 conversation_search 进召回；文档 QA 和嵌套 KV 走档案检索。工作上下文更像一块可改的便签，FIFO 是近期对话，外存才是无限期的。压力警告催的是「快把便签写好」，不是「去改系统说明书」。

## 2. 机制：事件进窗口，函数换页，心跳串起来

队列管理器接新消息，拼 prompt，触发推理，把入站消息和模型输出都写入召回库。函数把召回结果取回来时，管理器把它们追加到队列尾，重新进窗口。溢出有两道坎。提示 token 过「警告计数」（正文举例窗口的 **70%**），插入一条内存压力系统消息，让模型赶在被冲掉之前，把 FIFO 里重要的东西写进工作上下文或档案库。过「冲刷计数」（举例 **100%**），管理器驱逐一批消息（举例窗口的 **50%**），用旧摘要加被驱逐的消息生成新递归摘要。被驱逐的立刻不在上下文里，但无限期留在召回库，还能用函数读回来。70% / 100% / 50% 正文都写成 e.g.，花园当默认举例，不当另一张消融表。

函数执行器解析 completion。校验参数，执行，运行时错误（工作上下文已满还硬写）喂回处理器。检索带分页，避免一次取爆窗口。事件不只是用户说话：系统警告、用户上线、文档上传完毕、定时中断都可以触发推理。定时中断让系统能在用户没说话时自己跑一轮：整理工作上下文、把 FIFO 里快被冲掉的事实搬走。这是控制流上的 OS 借喻，不是改进器给自己加了一条新政策。人把定时周期改短，等于人改 \(I\)。正文没有报「不开定时中断掉多少分」，花园也不补。事件解析成纯文本再进 FIFO，所以上线提醒和用户聊天在处理器看来是同一类消息，差别只在系统说明书怎么教它反应。函数可以带 `request_heartbeat=true`：执行完立刻把输出写回主上下文再推理，用来翻页或做多跳。不带这个标志就是 yield，等到下一个外部事件。心跳只是把控制权留在处理器里多走几步，不是新政策。图 1 只画换页回到 LLM，心跳串函数写在这里，不另画虚线。

## 3. 数字：93.4 是慷慨裁判，不是字符串全对

对话实验用 Xu 等 2021 的 Multi-Session Chat。每人设五段会话，每段大约十几条。作者另造第六段，只放一对问答，用来测一致性。Deep Memory Retrieval：问一件只能从旧会话里知道、人设摘要里没有的事。问答对由另一只 LLM 按附录提示生成，明确禁止用人设能答的题。对照固定窗口基线看的是前五段的有损递归摘要；MemGPT 看得到完整历史，但必须用分页搜索把召回库调进窗口。

Table 2 准确率是 LLM judge，不是精确匹配。附录把裁判写成：生成答案可以比金标啰嗦，只要碰到同一话题就算 CORRECT；只提了杯子没提贝壳项链才算 WRONG。ROUGE-L 用召回，就是为了对付这种啰嗦。GPT-4 Turbo：**35.3% / 0.359 → 93.4% / 0.827**。GPT-4：**32.1% / 0.296 → 92.5% / 0.814**。GPT-3.5 Turbo：**38.7% / 0.394 → 66.9% / 0.629**。基线 GPT-4 低于 GPT-3.5，窗口分别是 8k 和 16k，两边都只看见有损摘要；不要听成「更强模型更不会聊天」。MemGPT 侧 GPT-4 和 Turbo 都到九十以上，3.5 只到 66.9，函数调用把档次拉开。93.4 减去 35.3 是 **58.1** 个百分点，不是「相对提高 58%」那种摘要腔；这篇摘要没写相对涨幅，花园也不补一条。

Table 3 开场白任务测的是 MemGPT 各骨干，不是再和「无 MemGPT」比一列。Human 的 SIM-1 / SIM-3 都是 **0.800**，SIM-H 是 **1.000**（和自己比）。GPT-3.5 Turbo：**0.830 / 0.812 / 0.817**。GPT-4：**0.868 / 0.843 / 0.773**。GPT-4 Turbo：**0.857 / 0.828 / 0.767**。SIM-1 / SIM-3 对人设的覆盖可以高于人手写开场；SIM-H 低于 1，说明写得比金标开场更散、更长。正文把工作上下文里存下来的事实写成开场能写得下去的关键。不要把 0.868 读成裸 GPT-4。

文档问答改 Liu 等的 retriever-reader。问题从 NaturalQuestions-Open 抽 **50** 条。维基用 2018 年末转储。检索同一只 `text-embedding-ada-002`。固定窗口把 top-\(K\) 一次性塞进上下文；MemGPT 把整库放进档案，自己用函数分页。裁判还要看答案是不是从取回的文档里来的，避免只靠参数记忆。结果在 Figure 5：固定窗口被检索器上限卡住，截断文档会再掉。MemGPT 理论上能翻到金文档，正文观察它常常没翻完检索库就停。GPT-3.5 明显差，GPT-4 和 GPT-4 Turbo 在这张任务上正文写成等价。花园不手抄柱高，也不把 50 题听成 NaturalQuestions 全量。

嵌套键值检索改 Liu 等的 UUID 字典。固定 **140** 对，大约 8k token，对齐 GPT-4 基线窗口。嵌套 0 到 4 层，抽样 **30** 种键位置。原版 KV 上 GPT-3.5 / GPT-4 都不差；嵌套之后 GPT-3.5 在 **1** 层就掉到 **0**（常见失败是直接把第一跳的值当答案）。GPT-4 和 Turbo 到 **3** 层也是 **0**。MemGPT + GPT-4 正文写成不受层数影响，靠函数反复查档案。MemGPT + Turbo / 3.5 从 **2** 层开始掉，查得不够。Figure 7 同理不手抄。嵌套任务把「会换页」从「窗口塞得下 140 对」里拆出来：基线窗口够装整表，仍然不会多跳。

## 4. 这不是术语式 (2)，换页政策也不是改进器

外存变了，下一轮可能直接搜到「上周说去过 Pacifica」。改进器没变。系统说明书、函数表、警告 / 冲刷 / 驱逐比例、嵌入模型、队列管理器都还在。混元 L0 装不下跨会话保持；L3 要改提议 / 选择程序。本篇停在留下状态、不改程序。摘要里的 evolve dynamically 指工作上下文里的人设事实会改，不是 \(I\) 在改自己。

和 DC 钉死。DC 用策展提示整本重写 \(M\)；MemGPT 用函数改一块工作上下文，历史进召回库，驱逐靠队列管理器。和 AWM 钉死。AWM 的 35.5 是 WebArena 执行成功率；93.4 是 MSC 上的话题级裁判。和 Reflexion 钉死。反思句子默认活不过几次追加；召回库按设计不丢。和 Argus 钉死。没有角色提交、没有 campaign 合约，内存编辑是模型自己说了算。和 ACE 钉死。ACE 后来把 Reflector 拆出来、合并交给非 LLM 代码；MemGPT 的写内存和聊天挤在同一只嘴里，没有条目化 playbook，也没有计数去重。和 Lost in the Middle 钉死。长窗口不是这篇的对照主表，只是动机：加长窗口仍可能用不好中间，所以要换页。

对有大模型基础的读者，读完应能回答四句。改的是哪一层？Harness 里的分层记忆和队列。权重动了没有？没有。93.4 是不是精确匹配？不是，是慷慨的话题级 LLM judge。还缺什么才叫花园 RSI？换页政策或系统说明书进入 \(S'\)，并且下一轮内存管理员用的就是升级后的那份。作者把别的存储层、别的控制流、别的无界域写成还没做。错事实一旦写进工作上下文，后面的开场和回答会一起用歪；压力警告只催模型搬家，不检查搬对没有。

## 5. 分页能翻过窗口，翻过去的不是改进器

同一句「给模型记忆」，至少分四截。加长上下文是改模型或改位置编码。RAG 是墙外检索器一次塞 \(K\) 篇。Reflexion / ExpeL 留下自然语言教训。MemGPT 留下可分页的两级外存，加一块能被函数改写的工作上下文。四截不要收成「都在推理时自我进化」。相关工作还点了 WebGPT 的分页浏览器、Yao 等的 ReAct。本篇主表只有 MSC 派生任务和文档 / 嵌套 KV。AlfWorld 的 71% 在 ReAct 专文，不要搬过来垫 93.4。

文档 QA 上「理论上能翻完检索库」和「实际常提前停」要一起读。金文档经常排在十几名之后。固定窗口完全被这一刀卡住。MemGPT 多了翻页，也把「何时停」交给同一只冻着的处理器。嵌套 KV 上 GPT-4 自己查不够，MemGPT + GPT-4 才能反复查；换成 Turbo 又会在两层开始掉。骨干换了，换页政策没换，表现可以裂开。这是 L2 脚手架的证据，也是配方冻着的证据。

作者还公开了增强版 MSC、嵌套 KV，以及大约 2000 万篇维基的嵌入，方便别人复现档案库。公开嵌入不等于主实验把 2000 万篇一次性塞进窗口：档案在 PostgreSQL 里，窗口里一次只进一页检索结果。复现账单跟 2023 年底的 OpenAI 函数调用绑定。没有开源小模型主表、没有把换页政策写成可学习模块，局限就是这篇的形状，不是没写完的 RSI。

生成提示、警告文案、函数表都不会因为某次换页成功就改掉。人要改 70% 阈值、换嵌入、把队列管理器交给另一只可训练模块，都是改 \(I\)。这和 DGM 改自己的 Python、STOP 改改进器源码正好相反。作者把 MemGPT 写成 OS 启发的 LLM 系统，花园读成 2023 年这篇的定位，不读成已经闭合的递归，也不读成 2026 年的 Letta 产品说明。

**读**：Table 2 的 93.4 / 92.5 / 66.9 对 35.3 / 32.1 / 38.7、裁判是话题级 CORRECT、Table 3 是 MemGPT 对人设不是对裸模型、实验 GPT-4 是 8192 的 `0613`、嵌套 KV 基线三层到 0、MemGPT+GPT-4 不受层数、文档 QA 50 题不手抄柱、不是式 (2)。  
**不读**：把 93.4 当精确匹配、把 Table 3 的 0.868 当裸 GPT-4、用 Table 1 的 32k 改实验窗口、用 35.5 或 AIME 改 DMR、说换页政策已经在优化自己、说已经 RSI、把 Letta 控制台写进本表。
