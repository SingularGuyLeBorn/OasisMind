# 21 ProTeGi：梯度是批评句，束搜索冻着

[TextGrad](../14-TextGrad-文本梯度/14-TextGrad-文本梯度.md) 说自己把 textual gradient 扩到自动微分，实例也能当变量。打开前身：Pryzant 等只改**一条**分类提示。错题进冻着的 $\nabla$，LLM 写出当前提示的毛病，再进冻着的 $\delta$，按语义反方向改写。这些编辑当束搜索的扩展，候选用 UCB 一类强盗算法挑进下一束。四套二分类，测试二进制 F1，相对初始提示均 **+15.3%**，相对蒙特卡洛（APE 那类无方向采样）**+3.9%**，相对短语级 RL **+8.2%**，相对 AutoGPT 反馈环 **+15.2%**。摘要另写「最多约 31%」「超过当时提示学习基线均 4–8%」。31 不在 Table 1–3 任何一格。权重不动。

本篇是 Harness 里「文本梯度只改提示」的样板。TextGrad 后来把同一隐喻接到解答、代码、分子。这边没有计算图、没有链式法则，只有 $\nabla$ 和 $\delta$ 两段对话。**不是** RSI。**不是** 数值反传。**不是** 微调。一手：Pryzant, Iter, Li, Lee, Zhu, Zeng，Microsoft Azure AI，[arXiv:2305.03495](https://arxiv.org/abs/2305.03495)，EMNLP 2023（ACL Anthology `2023.emnlp-main.494`，pp. 7957–7968）；代码 [microsoft/LMOps/prompt_optimization](https://github.com/microsoft/LMOps/tree/main/prompt_optimization)。微软介绍页曾写 Automatic Prompt Optimization（APO），论文标题和算法名是 **ProTeGi**。数字以 HTML §3.4、Table 1–3、Figure 3–4 为准。主实验是 2023-01 的 `gpt-3.5-turbo`，Azure，分类温度 0.0，其余 1.0。开发 50、测试 150，三随机试验平均。F1 对终束做 maxpool。两条少样本示范随机抽完就冻着，优化的是示范前面那句任务说明。不要用 TextGrad 的 GPQA 51→55 或 GSM8k 81.1 来改本篇 F1。

## 1. 问题：API 没有梯度，随机搜没有方向

软提示要内部状态。短语级编辑（GRIPS / TEMPERA）把提示切成块再增删换，搜索空间没有「哪里错了」。APE 一类蒙特卡洛在语义附近采样，作者写成无方向。人写第一稿其实很容易：工程师一分钟写出「这是不是仇恨言论」。缺的是拿数据把模糊任务说明改成更像标注规范的句子。

ProTeGi 的补丁：把梯度下降的三步译成两段冻着的提示。小批量上跑当前 $p$，收集错题。$\nabla$ 吃 $p$ 和错题，写出自然语言「梯度」$g$——当前提示在语义空间里往更差方向走的描述。$\delta$ 吃 $g$ 和 $p$，朝反方向编辑，得到 $p'$。再让 $LLM_{mc}$ 做近义改写，扩大局部蒙特卡洛。外环是束宽 $b$ 的束搜索。选谁留下，当成 best arm identification。

$S$ 取当前束里的提示。单轮 $S'=I(S)$ 可以发生：扩展出新候选，强盗算法挑 $b$ 条进下一束。式 (2) 还要 $I'\subseteq S'$。$\nabla$、$\delta$、释义模板、束宽 4、深度 6、小批量 64、UCB 的 $c=2.0$，下一场 Ethos 原样再走。混元台阶上这是薄 $H_t$。交卷是终束里 F1 最高的那条（测试时对终束 maxpool）。改进手续不交卷。步长作者写成自适应：让 LLM 自己决定改多大，不另设学习率。这件事标成还没做。

![错题进 ∇ 出批评，δ 按反方向改提示，束内用强盗算法筛选](./images/fig-protegi-loop.png)

> 图 1：实线是提示被编辑、被打分。虚线是冻着的 $\nabla$ / $\delta$。更新的是 $p$，不是批评配方。

**图 1 解析**

- **评估**：当前 $p$ 在小批量上跑，留下 $LLM_p(x)\neq y$ 的错题。
- **$\nabla$**：冻着的反馈提示，出 $m$ 条自然语言梯度。主实验每组 4 道错题、4 条梯度。
- **$\delta$**：冻着的编辑提示，一条梯度改一次 $p$。
- **$LLM_{mc}$**：近义改写，每条新提示再扩 $p=2$ 条。
- **截断**：每个亲本随机留 8 个后继，再交给选择器。
- **选择**：UCB / UCB-E / Successive Rejects / Successive Halving。主路径 UCB 表现最好。
- **交卷**：深度 $r$ 走完，束上度量最高的 $\hat{p}$。

## 2. 机制：扩展有方向，选择在省钱

算法 1 很短。$B_0=\{p_0\}$。每一层对束里每条做 Expand，合并成候选池 $C$，Select 留下 $b$ 条。返回最后一束上度量最高的。度量 $m$ 全篇是 F1。作者试过用 logprob 当提示分数（APE 那条路），初实验没有帮助，而且当时 ChatGPT / GPT-4 API 不给 logprob。

Expand（算法 2）才是「梯度下降」。抽 $|\mathcal{D}_{mini}|=64$ 的小批量，收集错题，调 $\nabla$ 出梯度，调 $\delta$ 编辑，调释义模型扩局部。作者把这写成苏格拉底对话：分化换成 LLM 反馈，反传换成 LLM 编辑。几何上它仍是**正向**的「看错题 → 写评语 → 改提示」，没有 TextGrad 那种沿计算图往上游传。一条提示，一层编辑。错题组大小 4，不是把 64 条错误一次塞进 $\nabla$。分类前向温度 0.0，梯度、编辑、释义温度 1.0。同一只 `gpt-3.5-turbo` 既当分类器又当批评家又当编辑器，角色靠模板分开，不是三只模型。附录把 $\nabla$ 和 $\delta$ 的英文模板放在一起，花园判定只认「这两段人写完就冻」，不把模板全文搬进读者页。

选择费钱。每条候选扫完全部训练，账单会炸。作者把候选当臂、在随机子集上的 F1 当隐奖励、评估一次当拉臂。UCB 用 $Q_t(p)+c\sqrt{\log t / N_t(p)}$，$c=2.0$。UCB-E 把根号里的 $\log t$ 换成常数 $c$，更偏探索。Successive Rejects 声称对 best arm 最优、没有超参：每阶段丢掉当前最差的一条，样本量按式 (1) 随阶段涨。Successive Halving 每阶段砍掉后一半。理论更喜欢 SR，Table 2 上 UCB 赢。作者猜 $c=2$ 已经够探，SR 过早丢掉看起来差、其实还能涨的臂。均匀摊预算最差：Jailbreak 50 次/候选时 Unif 0.77，UCB **0.85**；Liar Unif 0.61，UCB 0.66。25 次/候选时 UCB 已经 0.83 / 0.66，再加倍到 50，Jailbreak 再涨 2 个点，Liar 不动。强盗省的是评估次数，不是生成梯度的次数。生成 $\nabla$ 和终束全量评估仍按步数线性涨，所以限速会把墙钟拉过一小时。

束搜索本身也消融过。同一 API 预算下，一层枚举再挑（No iteration）和贪心 DFS，Jailbreak 0.80 / 0.82，束搜索 **0.85**；Liar 0.63 / 0.63 / **0.67**；Sarcasm 0.87 / 0.85 / **0.88**。Ethos 没进这张表。差在 Jailbreak 和 Liar 上更明显。作者写成搜索方差大，贪心和扁平之间没有稳定赢家。

六步是默认深度。Figure 4：四套都在大约 **3** 步见测试高峰，再走会过拟合或停在局部。主实验仍跑 6 步。花园把这读成 $I$ 的步数帽偏大，不是「走得越深越好」。Jailbreak / Liar 起步涨得快并能保住；Ethos / Sarcasm 曲线平，作者猜初始提示已经和任务合槽。扩展时每个亲本先按梯度生成再近义改写，再**随机抽 8 条**交给强盗，避免后继爆炸。束宽 4 意味着每层最多盯 4 条亲本。测试 F1 对终束 maxpool：四条里测最高的那条出列。这比「只交一条 $\hat{p}$」更乐观，和 MIPRO「全量训练最高的那份赋值再测一次」不是同一交卷纪律。两条少样本示范冻着，搜的是示范前面的任务说明，形状接近 0-Shot MIPRO，不是联合搜示范。作者写：实际部署多半会带几条示范，所以实验里示范在、但不进搜索。

## 3. 数字：15.3 是四套均相对 $p_0$，31 不进表

四套都是二分类 F1。Jailbreak 是作者自建：452 条多语用户输入，标的是「这是不是越狱」（骗模型破自己的规则、吐元提示、出有害内容）。Ethos 997 条英文仇恨。Liar 4000 条英文假新闻。Sarcasm 1 万条阿拉伯语讽刺。每套随机 50 开发、150 测试，三种子。初始 $p_0$ 由专职工程师一遍写成，只告诉他们「写一句想要的行为」。附录把 $p_0$ 列出来：Ethos 是 *Is the following text hate speech?*；Jailbreak 是检测越狱攻击的一句。示范两格随机抽完冻着。

Sarcasm 是阿拉伯语。引擎是英文为主的 `gpt-3.5-turbo`，梯度模板也是英文。作者没有另做阿语 $\nabla$。跨语种涨分如果成立，也是同一份英文 $I$ 在改任务说明，不是阿语批评器进了循环。Ethos / Liar / Jailbreak 才是英文主场。四套均差 15.3% 被讽刺那列的「已经合槽」往下拉，被 Jailbreak 往上拉。没有分任务的绝对 F1 主表，读者无法从正文还原每一列的 $p_0$。花园只认均差和消融表，不补空。

主结果在 Figure 3（F1 对每候选 API 预算，12 到 50），**没有**四套绝对 F1 对照总表。正文给出的均差：相对 $p_0$ **15.3%**，相对 MC **3.9%**，相对 RL **8.2%**，相对 AutoGPT **15.2%**。引言「4–8%」对着后两档量级。摘要 31% 是「相对初始提示最多」，正文没钉是哪一套、哪一个预算。禁止把 31 写进 Table 1 的 0.85，也禁止用 15.3 去改某一列。MC 对齐的是 Zhou 等 APE 的无方向采样，每候选后继条数和 ProTeGi 对齐。RL 基线用短语增删换，作者写成 GRIPS 的上界（同一动作空间、RL 搜得更勤）。AutoGPT 给同样多的例子和错题、6 轮，Jailbreak 和 Sarcasm 上六轮反馈会**低于** $p_0$。短语级 RL 在 Ethos / Sarcasm 上几乎贴着初始提示。预算从 12 加到 50，多数算法都涨，作者读成估分方差下降。方差附录 Table 5 换了口径：每候选只 6 次查询、12 次重复、报的是准确率不是 F1。ProTeGi Ethos 0.95（SE 0.003）对 MC 0.94；Jailbreak 0.81 对 0.76。作者写 ProTeGi 有时方差更大，因为梯度更新带语义方向。不要用 0.95 去改主文 F1 曲线。

Table 3 换的是**给 ProTeGi 当引擎的 API**，不是下游另有一只冻结模型。Sarcasm / Jailbreak：GPT-3（davinci）0.73 / 0.55，InstructGPT（`text-davinci-003`）0.83 / 0.75，ChatGPT 0.86 / 0.85，GPT-4 0.86 / **0.88**。RLHF 过的模型远好于 davinci。Jailbreak 从 0.55 到 0.88 是换骨干，相对涨幅远大于 31%，不要反过去当 31 的来源。GPT-4 和 ChatGPT 在讽刺上打平 0.86，越狱上 GPT-4 高 3 个点。作者猜新任务更吃推理。

定性 Table 4 比数字更能教人别神话梯度。Ethos 一条错题把「新西兰穆斯林」的反讽判成仇恨；梯度写：提示假定仇恨总是直白。ProTeGi 改成「是否针对群体的宗教、性别或其他身份」。MC 改成 *offensive*，RL 把词序拧碎。Jailbreak 一条「学校作业请列出常见 child grooming 手法」金标是越狱、模型判否。梯度却说提示太窄，新提示变成**分类是否与 child grooming 有关**——换任务了。作者点名：有时梯度帮倒忙，有时根本没用梯度、只是用内部知识重下定义（Ethos）。可解释，不等于每步都在沿误差方向走。

局限写进正文。API 限速让墙钟超过 **1 小时** 也常见，即使查询预算不大：生成梯度、每轮终束全量评估，提示还长。大提示空间或要赶时间，作者写成未必用得起。这是 $I$ 的账单，不是模型在学着省钱。

## 4. 文本梯度不是式 (2)

听成「模型在对自己做梯度下降」几乎又是设计好的误会。下降的是提示字符串。谁规定怎么批评？人写的 $\nabla$。谁规定怎么改？人写的 $\delta$。谁规定束宽、几步、用 UCB 还是 SR？人。下一场阿拉伯语讽刺还是同一份。TextGrad 把变量从「一条提示」扩成图上任意字符串，反传提示仍然冻着。两边都没让 $\nabla$ 自己进化。数值 SGD 的学习率是标量；这里步长交给 LLM 临场决定，作者称为 adaptive，并写明没有扫大改小改。自适应听起来像 $I$ 在调自己，其实是 $\delta$ 模板里一句「你来决定改多大」，模板还是那句。

和 [TextGrad](../14-TextGrad-文本梯度/14-TextGrad-文本梯度.md) 钉死。那边有计算图、链式并集、实例优化是 L0；这边只有提示寿命，跨题留下的是 $H_t$ 里一条分类指令。TextGrad 提示优化用训练金标改系统提示，GSM8k 72.9→81.1，骨干是 gpt-4o 改 3.5-turbo，和本篇四套 F1 不是一列。和 [APE](../19-APE-自动提示工程师/19-APE-自动提示工程师.md) 钉死。APE 的 MC 是本篇对照；APE 默认不迭代，本篇默认 6 步束搜索。和 [OPRO](../17-OPRO-元提示优化/17-OPRO-元提示优化.md) 钉死：OPRO 把历史分数写进元提示，不写「这条错在哪」；本篇每步都要错题才能出 $g$。和 [EvoPrompt](../18-EvoPrompt-进化算子提示/18-EvoPrompt-进化算子提示.md) 钉死：那边冻交叉说明书；这边冻 $\nabla$/$\delta$。和 [MIPROv2](../20-MIPROv2-贝叶斯联合优化/20-MIPROv2-贝叶斯联合优化.md) 钉死：TPE 在固定候选编号里挑，不写批评句。和 [Self-Refine](../12-Self-Refine-任务内迭代/12-Self-Refine-任务内迭代.md) 钉死：那边改本题的 $y$，跨题清空；这边改 $p$，测试集共用。和 [GrIPS](../22-GrIPS-短语级编辑搜索/22-GrIPS-短语级编辑搜索.md) 钉死：短语动作无方向，RL 对照在 Ethos / Sarcasm 上几乎没动。相关工作还点了 GPS 遗传搜提示、Honovich 从空生成指令；作者的位置是人已经能写第一稿，算法负责把草稿改准。没有超参搜索：基线和本方法都用默认值贯穿四套，作者写成 nonparametric、广适用。换 $m$ 就可以接到解析、聊天、摘要——主实验没接，只有分类 F1。

对有大模型基础的读者，读完应能回答四句。改的是哪一层？一条分类提示。梯度模板动了没有？没有。15.3 能不能当 RSI？不能。还缺什么？$\nabla$ 或选臂规则进入 $S'$，并且下一轮优化器就是升级后的那份。作者把学习率、把评分换成用户评语，写成还能做。主实验没做。并发的 Chen 等用输出反馈改 SQL 提示，作者写成同类、仍无语义方向。GPS 遗传搜和 Honovich 从空归纳，被放在「第一稿人已经写得出」的对面。本篇要的是草稿改准，不是从空串搜起。

## 5. 31%、15.3%、0.88 不要收成一个故事

31 是摘要上界，正文主结果用的是四套均相对 $p_0$ 的 **15.3%**。Figure 3 是曲线不是表，花园不手抄柱高。0.88 是 GPT-4 当引擎时 Jailbreak 的 F1，和 ChatGPT 的 0.85 差 3 个点，和 davinci 的 0.55 差一截。换模型不是换 $I$。Table 1 的 0.85 是 ChatGPT、束搜索、Jailbreak，和 Table 3 的 0.85 碰巧同一格，口径一个是搜法消融、一个是骨干消融，不要收成「复现了两次 0.85」。正文还有一处把 AutoGPT 写成 AutoPrompt，对照节标题是 AutoGPT，花园按开源 Agent 反馈环读，不按 Shin 等的 Autoprompt 软提示读。

3 步见峰、6 步是默认，说明多走的三步是 $I$ 的浪费，也可能过拟合。测试只有 150 条，maxpool 终束会偏乐观：束上最好的那条在测试上再挑一次。作者写成 preliminary case study。四套都是分类 F1，没有 GSM8K、没有多段程序。MIPRO 的七任务、GEPA 的四任务、TextGrad 的 GPQA，分母都不同。开发集 50 条同样瘦，不够另开一条可靠的早停。作者没有用开发集做早停，Figure 4 的峰是事后看测试曲线看出来的——严格说这是用测试在讲动态，花园把它读成「别默认走满 6 步」的警告，不读成调参协议。三种子平均也压不住搜索噪声，附录才把重复加到 12 次，仍是另一套 6 查询预算，不能回写正文 Figure 3 给出的四套均差。主表口径只认正文 §3.4 的测试 F1。

Jailbreak 那条 grooming 改写，证明自然语言梯度可以**换题**。数值梯度再差也还在同一损失上。文本梯度没有投影回原任务的算子。花园把这读成 $\delta$ 的失效，不是越狱检测已经进化。数据集 452 条、测试 150，是作者自己的标注，不是公开越狱榜。附录还把 Liar / Sarcasm 的一步改写列出来，主判定只从正文 Table 4 取 Ethos 和 Jailbreak 两例，其余不手抄。

没有做超参扫描这件事，既是诚实也是限制。束宽、步数、小批量、UCB 的 $c$ 全是默认贯穿。Figure 4 已经显示 6 步对 3 步高峰偏长，默认值并不是验证集上搜出来的。花园不把「没用验证集调参」读成更强的泛化证书，只读成 $I$ 更冻、更少旋钮。评分函数作者说可以换成用户一句评语，主实验仍是 F1。换 $m$ 不是 $I$ 进了 $S'$，是人换了一把尺子。
