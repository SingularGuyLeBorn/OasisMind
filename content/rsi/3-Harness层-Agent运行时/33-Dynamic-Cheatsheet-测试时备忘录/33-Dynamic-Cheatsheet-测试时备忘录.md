# 33 Dynamic Cheatsheet：备忘录在长，权重不动

摘要写 Claude 3.5 Sonnet 在 AIME 上准确率翻倍以上，GPT-4o 的 Game of 24 从大约 **10%** 到 **99%**。打开 Table 1：Sonnet 的 AIME 2024 是 **23.3 → 50.0**（DC-Cu），差 **26.7** 个百分点，图注收成 27。AIME 2025 是 **6.7 → 36.7**，正好 30 个点。24 点那一跳是 GPT-4o 在 DC-RS 下 **10.0 → 99.0**；同一行 Claude 只从 **12.0** 到 **14.0**。人把「测试时学习」听成自我进化，缺的是：权重冻着，策展提示冻着，没有金标，备忘录里一旦写下 Python 暴力搜索，后面的题就在调同一段代码。

本篇夹在 [ACE](../09-ACE-Agentic-Context-Engineering/09-ACE-Agentic-Context-Engineering.md) 和 [ExpeL](../32-ExpeL-跨题经验洞察/32-ExpeL-跨题经验洞察.md) 旁边。ACE 把 AppWorld 上「整本重写备忘录」的塌缩个案挂在本方法上：第 60 步 18,282 token、准确率 66.7，下一步 122 token、57.1。那是 ACE 的实验，骨干是 DeepSeek-V3.1，不要写进本篇 Table 1。ExpeL 先在训练集上攒池，评测默认一次；这边没有训练 / 评测切分，测试流上题题改 \(M\)。[ToT](../27-ToT-本题推理树/27-ToT-本题推理树.md) 的 24 点是 GPT-4、合法等式门、**74%**；这边 99% 是 GPT-4o 把暴力搜索脚本存进备忘录。两张表禁止横加。**不是** RSI。**不是** 改 \(\theta\)。**不是** 术语式 (2)。一手：Suzgun, Yuksekgonul, Bianchi, Jurafsky, Zou，Stanford / Together AI，[arXiv:2504.07952](https://arxiv.org/abs/2504.07952)，EACL 2026（ACL Anthology [2026.eacl-long.333](https://aclanthology.org/2026.eacl-long.333/)）。代码 [suzgunmirac/dynamic-cheatsheet](https://github.com/suzgunmirac/dynamic-cheatsheet)。数字以 HTML Table 1–4、§4、脚注 13 为准。禁止用手抄 Figure 1 / 2 柱高去改表。

## 1. 问题：每道题从零开始

部署之后的模型通常不记得上一题。同一类代数技巧要重新推，同一类算术错误会再犯。微调要权重；静态 RAG 召回的是别人写好的库，不是这轮自己刚发现的解法。作者把 DC 写成给黑盒 API 一块会演化的外部记忆：存策略、解法草稿、代码片段。不需要金标，不需要人反馈。宣传句带上 test-time learning 和 meta-learning。花园要钉的是：学的是 \(H_t\) 里的文本，改进器仍是同一份策展提示。

\(S\) 取这次测试流上的备忘录 \(M\) 和历史 \((x,\tilde y)\) 库。单轮 \(S'=I(S)\) 显然发生：\(M\) 多了一段，或改了一段。术语式 (2) 还要 \(I'\subseteq S'\)。下一题的 Generator / Curator 提示不变，嵌入仍是 `text-embedding-3-small`，\(k=3\)。混元台阶上这不是 L0：同一条测试流里，后面的题读得到前面写下的句子。也到不了改改进器。更像 ACE / ExpeL 那一档：留下脚手架状态，出状态的程序冻着。

和邻居先划线。[Reflexion](../11-Reflexion-言语反思记忆/11-Reflexion-言语反思记忆.md) 的 `mem` 服务同一任务的 trial，窗口 1–3 条。ExpeL 的洞察来自训练集，评测一次交卷。ACE 把合并从 LLM 手里拿走，条目只追加或改计数。DC 的 Curator **整份**改 \(M\)：可以蒸馏新条目，也可以删、改、合并旧条目。这正是 ACE 后来诊断的结构风险。本篇自己的对照是 Full-History：把过去所有问答原文贴进提示。Table 2 上 GPT-4o 的 AIME 2024 从 BL **20.0** 掉到 FH **13.3**，AIME 2025 从 **6.7** 掉到 **3.3**。乱贴历史比不贴更糟。DC-Cu 同表到 **50.0** / **36.7**（Sonnet）。策展不是装饰。

> 图 1：实线是本题生成和策展。回到 Consult 的是下一道测试题读 \(M\)，不是改权重。

**图 1 解析**

- **Consult \(M\)**：DC-Cu 直接读当前备忘录；DC-RS 先检索再策展再生成。
- **Generate**：同一只黑盒模型，提示里带 \(M\)。答案要包进机器可读的标签，方便抽最终答。
- **Curate**：没有金标。自己判断 \(\tilde y\) 有没有用、旧条目要不要删、整份 \(M\) 够不够短。
- **this-task output \(y\)**：本题交卷。24 点上一旦存了脚本，后面几乎是在跑同一段 Python。

Python 解释器在墙外。作者把工具范围钉死成这一只。没有它，24 点和方程配平那两列近乎满分走不通。

## 2. 机制：先写后改，或先检索再写

DC-Cu 两步。生成 \(\tilde y_i=\mathrm{Gen}(x_i,M_i)\)。策展 \(M_{i+1}=\mathrm{Cur}(M_i,x_i,\tilde y_i)\)。Curator 看三件事：新答是否值得蒸馏、旧条目是否该删或改、整份记忆是否够紧。它**看不到**正确答案。实验里生成和策展是同一只模型，靠任务无关的提示分工。作者写实践上可以拆成多工具、多模型；主表没有走那条。附录 Figure 12 是 BL 的极简说明书，只要求答题。Figure 13 是 DR / FH / DC-\(\emptyset\) / Cu / RS 共用的生成提示：结构化解题、鼓励写 Python 并执行。Figure 14–15 是 DC-RS 的策展提示，要求留下可复用、可执行、尽量短的策略和代码，而不是整段思维链。早期实验把 cheatsheet 和 memory 混着用，正文统一成 \(M_i\)，作者声明没为改名重跑。

DC-RS 把顺序反过来，并加上检索。先用 `text-embedding-3-small` 对当前题嵌入，从已见过的 \((x,\tilde y)\) 里取 top-\(k\)，\(k=3\)。试过 5 和 7，增益不明显。Curator 拿 \(M_{i-1}\)、当前题和这 \(k\) 条历史，写出 \(M_i\)，再生成。写成三式：\(R_i=\mathrm{Retr}(x_i,\{(x_j,\tilde y_j)\}_{j<i},k)\)，\(M_i=\mathrm{Cur}(M_{i-1},x_i,R_i)\)，\(\tilde y_i=\mathrm{Gen}(x_i,M_i)\)。作者说 DC-Cu 的两个弱点：策展发生在答题之后，本题用不上刚抽出的新洞察；过去的问答对除非写进 \(M\)，否则不再被看见。GPQA 这种题型杂的集合更吃检索。Cu 在近年 AIME 两年上反而更高：2024 **50.0** 对 RS **46.7**，2025 **36.7** 对 **30.0**。同类竞赛题更吃「把刚写下的代数句子留下来」，不一定更吃近邻问答对。

对照四档。BL 是极简提示，一题一清。DC-\(\emptyset\) 用 DC-RS 那套生成提示，但备忘录位置写成 `(empty cheatsheet)`，用来把「会用工具的说明书」和「真的留下了记忆」拆开。FH 只在 AIME 2024 / 2025 上测，各 30 题，把全部历史原文塞进去。DR 只检索、不策展，把相似的旧问答对原文贴进提示。零样本 CoT 预实验没有涨，主表不收。最终答必须包进指定的 XML 风格标签，解析失败算错；这是评测协议，不是模型自己发明的输出格式。

任务故意避开已经饱和的 GSM8K / BBH / MGSM。AIME 2024、2025 各 30 题；AIME 2020–24 是 133 题，来源 HuggingFace 上的切分，不是把 1983 年以来的全部 AIME 灌进去。GPQA-Diamond 198 题。Game of 24 用 Suzgun 与 Kalai 2024《Meta-prompting》的 100 例，不是 ToT 那 100 局偏难 901–1000。方程配平 250 条，形如 `1 ? 2 ? 3 = 6`，合法填法可以是加也可以是乘。MMLU-Pro 工程 / 物理各抽 250 道选择题，原池子分别是 969 和 1,299。度量：选择题走 Soft Match；24 点、配平、AIME 走 Functionally Correct，格式差一点只要语义对。输入序列写成 \((x_1,\dots,x_n)\)，每题从未知的 \(\mathcal{D}_{\mathrm{test}}\) 抽样，这是在线学习的标准设定。\(M\) 只服务这条测试流，换一条独立流就从空备忘录再长。花园判定看的是流内跨查询，不是跨部署、跨模型快照。换一天的 API 快照，同一套提示会抖，这是闭源接口的老病，不是 \(M\) 自己在进化。作者把输入–输出对全部放进 GitHub，本篇数字仍以 HTML 表为准，不另手抄仓库日志。24 点的例子写在方法里：输入 `7 7 8 11`，合法式可以是 `8*(7+7-11)`。四个数各用一次，凑出 24。GPT-4o 后来几乎不再手写这种式子，改成对四个数做排列和四则穷举。Claude 没走这条，所以 12 到 14 几乎不动。配平数据集是作者自己攒的 250 条，不是公开竞赛卷；把它听成「小学算术已经解决」，缺的是：一旦脚本进了 \(M\)，后面 249 条都在复用同一段代码。

## 3. 数字：99% 是脚本入库，50.0 是 26.7 个百分点

Table 1 是主表。Sonnet AIME 2024：BL **23.3**，空记忆 **36.7**，DR **43.3**，DC-Cu **50.0**，DC-RS **46.7**。空记忆已经比 BL 高，因为提示里写了结构化解题和 Python；再把记忆打开，Cu 最高。AIME 2025：BL **6.7**，Cu **36.7**，RS **30.0**。AIME 2020–24：BL **6.7**，RS **40.6**，Cu **38.4**。图注「AIME 2024 涨 27、AIME 2025 涨 30」钉在 Cu 相对 BL 的百分点，不是相对准确率 27%。GPT-4o 同三行弱一截：2024 的 RS **40.0** 对 BL **20.0**；2025 的 RS **20.0** 对 **6.7**；2020–24 的 RS **24.8** 对 **9.8**，空记忆已经 **24.1**，检索加策展几乎没再涨。

Game of 24 不要和 ToT 专文收成一张表。GPT-4o：BL **10.0**，空记忆 **19.0**，DR **6.0**（比 BL 差），Cu **93.0**，RS **99.0**。空记忆 19 对 RS 99，差的是「把脚本留下」。Claude：**12.0 → 14.0**，几乎没把暴力搜索收进 \(M\)，继续手算。作者写 DC 只提供框架，能不能编码可复用策略取决于模型自己。Figure 5 是 GPT-4o 跑完 100 例之后 \(M\) 的摘录：前几题里发现暴力搜索，存进去，后面几乎原样取用。那是定性图，主数字仍是 Table 1 的 10 和 99。ToT 专文的 74% 是 GPT-4、合法等式门、偏难 901–1000；这边 99% 是 GPT-4o、Python 入库、另一份 100 例。分母、骨干、门都不同。方程配平：Sonnet BL **44.8**，Cu **100**，RS **97.8**；GPT-4o BL **50.0**，空记忆已经 **88.0**，DR / Cu 到 **100**，RS **99.2**。又是代码入库。Figure 6 是 Sonnet 在 AIME 2024 上跑 20 题后的 \(M\) 摘录，花园不把摘录里的某条代数技巧升级成准确率。

## 4. 这不是术语式 (2)，Curator 也不是改进器

\(M\) 变了，下一题读得到「用这段 Python」。改进器没变。下一题的 Gen / Cur 提示、嵌入模型、\(k=3\)、Python 解释器还是同一份。混元 L0 装不下跨题保持；L3 要改提议 / 选择程序。本篇停在留下状态、不改程序。不要用 99% 去改 ToT 的 74%，也不要用 50.0 给 [SEAL](../../2-Model层-训练时自改进/04-SEAL-自适配语言模型/04-SEAL-自适配语言模型.md) 的 LoRA 背书，更不要用 ACE 的 18,282→122 替换本表任何一格。

和 ACE 钉死。那边合并是非 LLM 代码，条目带计数；这边 Curator 整本重写 \(M\)。ACE 在 AppWorld 上把塌缩个案挂在本方法，花园承认那是整本重写的结构病，数字仍以 ACE 专文为准。和 ExpeL 钉死。那边洞察来自训练池，评测一次；这边测试流上题题改 \(M\)，没有 held-out 训练阶段。和 ToT 钉死。74% 是树搜加等式检查；99% 是脚本入库。和 [Self-Refine](../12-Self-Refine-任务内迭代/12-Self-Refine-任务内迭代.md) 钉死：改的是本题草稿，没有跨题 \(M\)。和 Reflexion 钉死：窗口服务同一任务重试，不是一条测试流上的全局备忘录。

对有大模型基础的读者，读完应能回答四句。改的是哪一层？Harness 里的文本备忘录。权重动了没有？没有。99% 能不能当模型学会了 24 点？不能，学会的是把暴力搜索留下来。还缺什么才叫花园 RSI？策展提示或检索配方进入 \(S'\)，并且下一轮改进器用的就是升级后的那份。Curator 没有金标：错策略一旦写进 \(M\)，同类题会一起错。作者自己写错误会在嵌入空间里成团放大。

ACE 的 AppWorld 表不要搬过来当本方法主结果。那边骨干是 DeepSeek-V3.1，环境是工具调用长轨迹；这边主表是 AIME、24 点、GPQA、配平、MMLU-Pro。塌缩个案（18,282 token 到 122 token，准确率 66.7 到 57.1，低于不适应的 63.7）证明整本重写会丢知识，不证明 Table 1 的 50.0 或 99.0 作废。两篇论文测的不是同一件事。摘要「相对选中强基线 +10.6」是 ACE 的均增益，里面可以含 DC 当对照，禁止用那一个数改本篇任何一格。

> 图 2：实线只更新 \(M\)。虚线是冻着的模型和工具。

**图 2 解析**

- **会变**：\(M\) 里的策略 / 代码片段、历史问答对、本题 \(y\)。
- **冻 \(\theta\)**：主表 GPT-4o、Claude 3.5 Sonnet；小模型另表。
- **冻 \(I\)**：Gen / Cur 提示、\(k=3\)、嵌入模型、答案标签格式。
- **门**：Functionally Correct 或 Soft Match。Curator 自己猜对错，门不在策展这一步。

## 5. 测试流上的句子，寿命仍短于改进器

同一句「测试时学习」，至少分四截。TTT / SEAL 改 \(\theta\)（SEAL 内环还会回滚）。DC 改文本 \(M\)。ToT 改本题树，题换了空。多数票改的是本题采样，Table 4 证明三票抬不动 AIME。四截不要收成「都在推理时自我进化」。附录把 dynamic evaluation、域适应、传统 RAG 写成对照：那些要么碰权重，要么检索一份部署前冻死的语料。DC 检索的是这轮自己刚写下的问答对和蒸馏过的句子。MemoryLLM、CAMEL 一类把记忆写进权重或关联槽，本篇不收：DC 明确不碰参数。

相关工作里点名的邻居，花园已经有落点的，不要再发明第四套分类。[Reflexion](../11-Reflexion-言语反思记忆/11-Reflexion-言语反思记忆.md) / [Self-Refine](../12-Self-Refine-任务内迭代/12-Self-Refine-任务内迭代.md) / [CRITIC](../13-CRITIC-工具交互批评/13-CRITIC-工具交互批评.md) 是本题或本任务上的反馈环；[TextGrad](../14-TextGrad-文本梯度/14-TextGrad-文本梯度.md) 用文本梯度改本题变量或一条薄指令。DC 要留下跨查询还能读的策略库。Thought-Retriever 存的是旧思维链原文；[Buffer of Thoughts](../34-BoT-思维模板缓冲/34-BoT-思维模板缓冲.md) 蒸馏高阶模板，作者写它更像预定义、偏实验里见过的题型。本花园钉死：六类和粗模板是人写的起点，buffer-manager 仍可追加；摘要 11% 是相对 ToT 的比例，Table 1 是 82.4 对 74.0。DC 强调选择性蒸馏，避免把整段 transcript 和一次性思维链堆爆窗口。Madaan 等 2022 的记忆编辑要用户反馈；Zhang 等 2024 的医学生双记忆要微调。DC 训练免费、黑盒、自策展。这些对照是定位，不是另一张准确率表。

24 点和配平能满分，因为解法是一段可执行代码，Python 解释器在墙外验算。AIME 没有这种硬脚本，涨的是代数 / 组合的句子，Curator 仍在自评。GPQA 上 GPT-4o 几乎不涨，说明杂题上检索会吵。MMLU-Pro 上 GPT-4o 会掉，说明「参考指南」写错了就污染后续选择题。小模型写不好 \(M\)，DC 放大弱点。R1 / o1 答太长，策展跟不上。这些是机制边界，不是没写完的 RSI。

题序会放大效果。同类题靠前，脚本早入库，后面坐享其成。作者写成课程学习的直觉，主实验没有另做一门课程表。长上下文生成弱于理解：策展时模型会写「前文保留」而不真的重抄，\(M\) 会悄悄丢段。作者建议以后用外部数据库，不必每次生成整份文本。那一步主实验没做。ACE 后来用非 LLM 合并，就是冲着整本重写会塌。附录还写可以按主题拆成分层记忆，主表仍是一份统一 \(M\)。工具范围钉死成 Python；未来可以接符号引擎或领域 API，主实验没有接。

生成提示、策展提示、\(k=3\)、嵌入模型都不会因为某题存成功就改掉。人要换嵌入、改 \(k\)、把 Curator 换成另一只模型，都是改 \(I\)。这和 DGM 改自己的 Python、STOP 改改进器源码正好相反。作者把 DC 写成在线学习味道的提示记忆，花园读成 2025 年这篇的定位，不读成已经闭合的递归。

**读**：Table 1 的 23.3→50.0、6.7→36.7、10→99、Claude 24 点几乎不涨、GPQA 9.1 个点只属于 Sonnet、GPT-4o 的 MMLU 会掉、FH 会伤 GPT-4o、多数票无效、空记忆 19 对 99 才是 24 点的因果、没有金标、ACE 的塌缩数字不进本表、不是 74%、不是式 (2)。  
**不读**：用 99 改 ToT 的 74、用 27% 听成准确率从某数涨到 27、把 18,282→122 写进本表、说小模型一样涨、说已经 RSI。
