# LLM 仍主要由模仿学习驱动，而非强化学习

> 原文作者：Steven Byrnes；原文发布：2026-07-24；本文为中文翻译版的要点整理（用户收藏截图）。

## 核心观点

可验证奖励强化学习（RLVR）是眼下 LLM 训练里最热的话题。但退后一步看，今天模型绝大多数能力的来源，可能仍然不是 RL，而是**预训练与监督微调（SFT）所构成的模仿学习**。

## 一、相关证据

1. **信息量差距**：RL 每消耗一个 GPU 人小时，传递的信息量比模仿学习低几个数量级。
2. **思维链仍受模仿学习影响**：CoT 能力明显带有模仿学习的痕迹。
3. **公司仍高度重视预训练与 SFT 数据**：数据投入没有因 RLVR 而减少。
4. **三篇论文**：非 RLVR 模型也可能逼近 RLVR 模型（说明 RLVR 收益未必来自「新的能力」）。
5. **RLVR 可能主要在学习「何时使用」已有推理策略**：即调度/触发已有能力，而非凭空产生能力。

## 二、作者到底在主张什么

- 不是「RL 无用」，而是「RL 当前贡献被高估」；
- 主流叙事（o1、R1 等 reasoning model 拉开差距靠 RL，pretraining 只是打底、SFT 只是过渡）与证据不符；
- 真实图景：**绝大多数能力来自模仿学习，RLVR 是在此基础上做选择性强化**。

## 三、为什么这件事重要

1. **思维链的可读性**：如果 CoT 主要是模仿学习的产物，其「推理」性质与可信度需要重新评估。
2. **LLM 能力的边界**：模仿学习的数据天花板直接决定能力边界；RL 的增益在于「整合与调度」而非「新知识」。
3. **LLM 对齐**：对齐信号主要靠 RL 注入（RLHF），若 RL 本身传递信息效率低，对齐的深层机制需要重新审视。
