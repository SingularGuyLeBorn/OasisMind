# 工具学习与程序编排

“会调工具”至少包含三种不同机制：训练模型生成调用、运行时创建或改写工具、按任务编排已有模块。它们的更新对象不同，证据也不能横向混算。

- [6.1 · 工具使用训练](6.1-工具使用训练/6.1-工具使用训练.md)：ReTool、ToolRL、ToRL、Gorilla、ToolLLM、Toolformer。
- [6.2 · 工具创建与文档优化](6.2-工具创建与文档优化/6.2-工具创建与文档优化.md)：LATM 与 EASYTOOL。
- [6.3 · 模块与程序编排](6.3-模块与程序编排/6.3-模块与程序编排.md)：HuggingGPT、RestGPT、Chameleon、ViperGPT、VisProg。

**事实**以原论文的 API 集、执行环境和评测协议为边界。**推测**：工具库持续扩张可能构成运行时自进化。**开放问题**：工具安全、权限隔离、错误回滚和文档漂移能否被独立验收。

产品级 MCP、沙箱和 IDE 集成只做跨库指针，不在本章重复通用实现教程。
