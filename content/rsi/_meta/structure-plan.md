# RSI 知识库结构与证据规则

## 目录与编号

- 根层公开章节固定为 `00`–`10`；内部材料只放 `_meta`、`_archive`。
- 目录同名首页共享编号；子项继承父编号，如 `5.1`、`5.1.1`。
- 最多四级编号，不建第五级；内容不足时不为凑号建空目录。
- 一夹一文同名；图片放同篇 `images/`，Markdown 链接显式写 `.md`。

## 公开章节职责

| 章节 | 唯一职责 |
|---|---|
| 00 | 导读、历史与证据标记 |
| 01 | 研究框架、术语与判定边界 |
| 02 | 模型权重、自训练与自奖励 |
| 03 | 可扩展监督、过程监督与弱到强 |
| 04 | 反思、批评与反馈优化 |
| 05 | 提示搜索、推理搜索与规划 |
| 06 | 工具调用训练、工具创建与程序编排 |
| 07 | 技能、跨任务经验与持久记忆 |
| 08 | 多智能体协作、工作流与拓扑 |
| 09 | 自改代码、自动研究与科学发现 |
| 10 | 评测、独立监督与安全边界 |

## 证据规则

1. 事实必须回到一手论文、正式技术报告、官方代码或带版本日期的官方文档。
2. 数字记录论文版本、表号、数据集、split、模型、judge、单位和绝对/相对变化。
3. 推测、情景和开放问题显式标记，不改写成作者结论。
4. 公司宣传、搜索摘要、二手融资/人事消息和无法核实的行业快照放 `_archive` 且 `published: false`。
5. 通用 Agent、提示工程、工具协议和产品教程只指向兄弟库；本库保留 RSI 更新边界。

## 验收

- 每篇恰好一个 H1，frontmatter 至少有 `title/category/tags/published/excerpt`。
- 所有公开相对链接存在；没有空链接、无扩展名 Markdown 链接或公开页指向 `_archive`。
- 图片引用有信息性中文 alt；图注说明自绘/解释图或一手图表来源。
- 公开章节首页说明职责、证据边界和阅读路径，不承担第二份论文正文。
