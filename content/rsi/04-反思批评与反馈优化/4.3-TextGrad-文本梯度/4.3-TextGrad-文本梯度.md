# TextGrad：梯度是句子，不是 θ

听到 automatic differentiation、backward、TGD.step，容易把它听成又在训模型。[ACE](../../07-记忆技能与经验/7.1-技能与跨任务经验/7.1.2-ACE-Agentic-Context-Engineering/7.1.2-ACE-Agentic-Context-Engineering.md) 把它和 Self-Refine / Reflexion 写成「自然语言反馈会越改越吵」的前史。打开表：gpt-4o 在 GPQA 上 CoT **51.0 → 55.0**，LeetCode-Hard 完成率 **0.26 → 0.36**（五种子、相对 Reflexion 的 0.31）。摘要写 **20% relative**，不是绝对 20 个点。(0.36−0.31)/0.31 ≈ 16%，和海报 20% 是同一档的约数。权重从头到尾没动。动的是计算图里的**变量字符串**：一道题的解答、一段代码、一条系统提示、一串 SMILES、一组放疗权重。

本篇是 Harness 里「把批评当梯度」的样板。实例优化（这道题的解、这段代码）跨题不留，混元 L0，和 [Self-Refine](../4.1-Self-Refine-任务内迭代/4.1-Self-Refine-任务内迭代.md) 同寿命，只是反传可以穿过多层 LLM / 工具。[CRITIC](../4.2-CRITIC-工具交互批评/4.2-CRITIC-工具交互批评.md) 的批评里要拼 API 返回；TextGrad 的 $\partial\mathcal{L}/\partial v$ 默认仍是 LLM 句子，代码任务才把本地单测结果写进 loss 提示。提示优化跨题：在一小份训练集上改系统提示，再拿到测试集用。那是 $H_t$ 里的指令，TGD 公式、反传提示、当梯度引擎的 gpt-4o 仍在墙外。**不是** RSI。**不是** 数值反传。一手：Yuksekgonul, Bianchi 等，Stanford / Chan Zuckerberg Biohub，[arXiv:2406.07496](https://arxiv.org/abs/2406.07496)；期刊 [Nature 639:609–616 (2025)](https://www.nature.com/articles/s41586-025-08661-4)，题目改成 *Optimizing generative AI by backpropagating language model feedback*；代码 [zou-group/textgrad](https://github.com/zou-group/textgrad)。数字以 HTML Table 1–3、§3.1–3.3 为准。分子 / 放疗是实例优化接到仿真器上的延伸，主判定不靠对接分数。作者自己把「用 TextGrad 再优化 TextGrad」写成未来工作，那句话比任何口号都清楚：$I$ 还没进 $S'$。

## 1. 问题：复合系统没有数值梯度

新系统常常是多只 LLM 加搜索、解释器、求解器。组件之间走自然语言，闭源 API 没有 $\partial L/\partial\theta$。过去十五年神经网络能训，是因为矩阵乘法可微，自动微分把反传做成常规操作。复合系统缺这一层。TextGrad 把隐喻用到底：变量 $v$ 是文本，前向是任意函数（LLM 调用、模拟器），损失 $\mathcal{L}$ 也是文本或由文本描述的评价，反向由 LLM 写出「$v$ 该怎么改」——这就是 textual gradient。更新规则叫 Textual Gradient Descent：

$$
v_{\mathrm{new}}=\mathrm{TGD.step}\Bigl(v,\;\frac{\partial\mathcal{L}}{\partial v}\Bigr). \tag{1}
$$

数值 SGD 是 $\theta-\partial\mathcal{L}/\partial\theta$。TGD.step 还是一次 LLM 调用：把对 $v$ 的批评喂进去，要求产出新变量。作者写 PyTorch 风 API：`loss.backward()` 填梯度，`optimizer.step()` 改字符串。用户原则上只给目标函数，不调框架内部提示。正文承认示范用的 TGD 提示和仓库里的不完全一样，为的是通用。

最简单的图是三条：Prompt → LLM → Prediction → LLM → Evaluation。先对 Prediction 收一句「这段预测可以这样改」，再把这句话连同 Prompt→Prediction 的调用上下文，交给 $\nabla_{\mathrm{LLM}}$，得到对 Prompt 的批评。链式法则在这里没有乘法，只有把下游句子当上下文再写一句。一般图里，对 $v$ 的梯度是所有后继上 $\nabla_f$ 的**并集**：变量在几处被用，就收几处批评。$n$ 条边，一轮优化最多再打 $n$ 次梯度调用。加法用 `tg.sum` 时，反传把各条损失上的句子**拼接**，对应数值反传里加法把梯度相加。

两类优化不要收成一张榜。**实例优化**：只改这一问的 Solution / Code / SMILES / 放疗权重。目标是这道题变好。下一问从零开始。**提示优化**：改一条系统提示，让它在许多问上好用。训练用带金标的小集，测试另切。寿命差一层：前者是 L0 的 $y$，后者是可能留下的 $H_t$。两边的 $I$——TGD、$\nabla_{\mathrm{LLM}}$ 的提示、当引擎的 gpt-4o——都不进 $S'$。

$S$ 取当前这张计算图里被标了 `requires_grad` 的变量。单轮 $S'=I(S)$ 可以发生：$v$ 被写成 $v_{\mathrm{new}}$。式 (2) 还要 $I'\subseteq S'$。下一道独立题，或下一次提示优化实验，仍用同一份 TGD 提示、同一只梯度引擎、同一个迭代帽。混元台阶上，实例优化是 L0：改 $(\text{输出},\text{轨迹})$，跨独立任务状态不变。提示优化留下一条指令，接近「脚手架变了」，改进手续本身仍在墙外。

和邻居先划线。[Self-Refine](../4.1-Self-Refine-任务内迭代/4.1-Self-Refine-任务内迭代.md) 是正向的生成–反馈–改写，历史只在本题。[Reflexion](../../07-记忆技能与经验/7.1-技能与跨任务经验/7.1.4-Reflexion-言语反思记忆/7.1.4-Reflexion-言语反思记忆.md) 把反思推进窗口。[CRITIC](../4.2-CRITIC-工具交互批评/4.2-CRITIC-工具交互批评.md) 要工具返回。TextGrad 多出来的是**计算图上的反传**：损失对下游变量的批评，可以传到上游提示或中间代码。ProTeGi 先在提示优化里用过 textual gradient，见 [5.1.7](../../05-搜索规划与提示优化/5.1-提示与上下文优化/5.1.7-ProTeGi-文本梯度束搜索/5.1.7-ProTeGi-文本梯度束搜索.md)。作者说自己把隐喻扩到自动微分，并且把实例本身（分子、计划、代码）也当成变量。DSPy 把 LLM 程序当可优化对象，主实验用 BootstrappedFewShotRandomSearch 加示范。作者说 DSPy 改示范，TextGrad 改指令，GSM8k 上拼在一起到 82.1%。ACE 的诊断仍然成立：自然语言梯度会吵。本方法用迭代帽（代码 5 轮、问答 3 轮、提示 12 轮 batch 3）限制变吵，没有 ACE 那种非 LLM Merge。变量整段被 TGD 写成新字符串，正是 ACE 担心的端到端重写。

## 2. 机制：backward 是请模型写批评

前向：把变量填进图，得到输出和损失。反向：从 $\mathcal{L}$ 开始，对每个需要梯度的 $v$，用 LLM 根据下游反馈写「这个 $v$ 哪里不好、该往哪改」。$\nabla_{\mathrm{LLM}}$ 的示范形态是：先贴 $x|y$ 这段对话，再贴对 $y$ 的批评，再问「解释怎么改 $x$」。梯度对象 = 变量出现的上下文 + 批评。这个算子不随应用域改写，代码、分子、提示走同一套。

问答实例优化的损失提示让模型当「苛刻的科学家」，用 Janusian Process 想对立答案，不给金标。循环：zero-shot 出初解 → 算 loss → backward → step，最多 3 轮，最后对轨迹做多数票。温度 0 的 CoT 当对照；官方 gpt-4o 文档 53.6% 用了温度 0.5，且写在 GPQA **diamond** 子集上。本篇另测温度 0。这是测时多算力，作者写成 test-time training / self-refinement。和 [SEAL](../../02-模型自改进与自训练/2.2-自适应与递归解题/2.2.1-SEAL-自适配语言模型/2.2.1-SEAL-自适配语言模型.md) 的内环 LoRA 不是一层：那边 $\theta$ 真改且会回滚，这边 $\theta$ 不动、改的是这道题的 Solution 字符串。

代码优化的损失看**本地**单测，并要求模型设想更难的隐藏测试，不要只迎合已见用例。完成后把代码交到 LeetCode 平台，隐藏测试才算完成率。和 Reflexion 一样：循环里的门是可见测试，证书看不可见测试。Reflexion 用 1 条示范、5 轮；TextGrad 零示范、5 轮。gpt-4 旧数：zero-shot 7%，Reflexion 15%。本实验换 gpt-4o。图 1e 的例子是「数组中位数等于 $k$ 的非空子数组个数」：gpt-4o 初稿不过本地测试，文本梯度指出边界，改完才过。那是演示，主表仍是五种子平均。

提示优化：用 gpt-4o 当梯度引擎，优化 gpt-3.5-turbo-0125 的系统提示。动机写得很白：付一笔固定的优化成本，以后用便宜模型推理。训练集前向 → 金标评价 → 反传到 Prompt → TGD。Object Counting / Word Sorting 从 BBH 随机切 50/100/100；GSM8k 用 DSPy 的切分。对照是零样本 CoT，以及 DSPy 的 BootstrappedFewShotRandomSearch（10 个候选程序、最多 8 条示范）。TextGrad 只改指令、不加示范。batch size 3、12 轮，带放回一共看见 **36** 条训练题。每轮结束后在验证集上走一遍，**只有比上一轮更好才更新 Prompt**。这是带验证门的指令搜索，不是无监督自进化。

分子：SMILES 当变量，Autodock Vina 的对接分数和 RDKit 的 QED 组成多目标。对接喜欢大分子、多官能团；QED 喜欢轻、简单。两把尺子对着拉。DOCKSTRING 58 个靶点，每个 3 个初始片段、10 轮。29 个靶有上市药当对照。图 2 用 PPARA 演示前三轮文本梯度。仿真器在墙外。这是 Artifact 实例优化：改的是分子字符串，不是发现环。作者写得很清楚：体外实验和临床评估不在本文范围。

放疗：人做外环，反复拧 PTV / 膀胱 / 直肠 / 股骨头 / 体的重要性权重，内环交给数值优化器。TextGrad 接管外环。$\theta$ 是一段字面量权重字符串，matRad 算出计划 $P(\theta)$，LLM 拿 $P$ 和临床目标 $g$ 写损失。TGD.step 更新时还可以看见历史对 $(P_i,\theta_i)$。图 3：剂量漏出 PTV 时，梯度建议加大 PTV 权重；膀胱直肠跟着吃亏，下一步再把它们的权重略抬。对照是五名前列腺癌患者的临床计划。作者称 TextGrad 计划在 PTV 均值和 $D_{95}$ 上更好，$D_{95}$ 正好落到处方剂量，膀胱直肠均值更低。数字画在图里，正文只说五例平均、括号里有标准差，没有另给一张可抄进主表的百分比。花园不把柱高估成点数，也不把图 3 写进判定。主判定只认前三张表里的完成率和准确率。同样是仿真器当 $\mathcal{L}$。

## 3. 数字：55.0 不是证书，0.36 也不是

Table 1，LeetCode Hard，gpt-4o，五种子平均。Zero-shot **0.26**，Reflexion **0.31 ± 0.012**，TextGrad **0.36 ± 0.018**。正文另写 gpt-4o zero-shot 23%、Reflexion 31%、TextGrad 36%——和表的 0.26 差 3 个点，读完成率以表为准。相对 Reflexion 绝对 +0.05，相对约 16%；摘要 20% relative 对着「当时最强方法」。旧 GPT-4 的 7% / 15% 是另一只模型，不要和 0.26 / 0.31 横加。隐藏测试在平台上，本地单测在墙内。[Reflexion](../../07-记忆技能与经验/7.1-技能与跨任务经验/7.1.4-Reflexion-言语反思记忆/7.1.4-Reflexion-言语反思记忆.md) 花园专文里 HumanEval 91.0 / MBPP 77.1 的假阳性，这里同样适用：完成率绑在平台测试，循环看不见那套测试。

Table 2，gpt-4o，零样本解答优化。GPQA：CoT **51.0**，文档最佳 **53.6**，TextGrad **55.0**。专家 81%，熟练非专家 22%。53.6 是 diamond、温度 0.5；51.0 是他们自己的温度 0 CoT。55.0 是 3 轮 + 多数票。三套数不要收成「比官方再高 1.4」。MMLU-ML **85.7 → 88.4**，College Physics **91.2 → 95.1**。损失不看金标，多数票看的是自己改出来的几份解答。+4 个 GPQA 点是测时算力，不是新权重。作者写 55% 当时所知最佳；后来的卡、后来的验证器，不并进本表。

## 4. 句子梯度不是式 (2)

实例优化：$y$ 变好，下一题的 $I$ 不变。L0。不要用 GPQA +4 给 SEAL 背书。提示优化：指令可以跨题，接近 ACE 的「留下上下文」，但薄得多——一条系统提示，不是带编号的 playbook。TGD 自己不会改「下次用几轮、用哪只引擎」。混元台阶上提示优化最多蹭 L2 的「留下脚手架」，改进器仍在墙外。Discussion 写得坦白：稳定性、自适应梯度、用 LLM 自验证，以及 **meta-learning：用 TextGrad 优化 TextGrad 自己**，都是未来工作。最后那句是花园判定的反面：他们知道 $I$ 可以成为被优化变量，主实验没做。

和 Self-Refine 钉死。那边同一只模型正向改写，数学 +0.2。这边问答损失也是 LLM 自批评，GPQA 从 51 到 55，基座已经是 gpt-4o。没有工具时，CRITIC 已经证明自评可以掉分；TextGrad 的 +4 发生在更强模型和多数票上，不是反例。和 CRITIC 钉死：代码任务 TextGrad 把本地测试写进 loss，接近 CRITIC 的解释器门；问答任务默认不加搜索。和 Reflexion 钉死：LeetCode-Hard 上 Reflexion 0.31、TextGrad 0.36，同一只 gpt-4o、都是 5 轮；Reflexion 有示范，TextGrad 没有。0.05 的差不是「反传打败了窗口」，是零样本加文本梯度对上有示范的反思。Reflexion 的 AlfWorld 130/134 不在这张表。

ACE 说自然语言反馈会越改越吵、整本重写会塌。TextGrad 没有 Merge 函数，变量整段被 TGD 写成新字符串。3 轮帽挡住无限吵。提示优化 12 轮仍可能把指令写长。那是指令变厚，不是 playbook 条目化。GEPA 在 ACE 主表里是短指令对照；本篇不报 ACE 的 AppWorld 数，两边骨干和协议都不同。

对有大模型基础的读者，读完应能回答四句。改的是哪一层？字符串变量：实例 L0，提示是薄 Harness。权重动了没有？没有。55.0 和 0.36 能不能当 RSI？不能。还缺什么才叫花园 RSI？TGD 的提示或选引擎的规则进入 $S'$，并且下一轮改进器就是升级后的那份——目前每张图都用同一套 `backward` 提示。论文把这件事标成还没做。

## 5. 梯度隐喻的寿命

同一句「在做反传」，数值 SGD 改 $\theta$，TGD 改文本。文本活多久，决定这是不是自进化。实例优化的 Solution 活过 3 轮，题换了清空。提示优化的系统提示可以活过整个测试集，换一个 GSM8k 切分就不保证。ACE 的 playbook 按条追加。Voyager 的函数留磁盘。SPIN 的寿命在 checkpoint。TextGrad 没有第六段寿命叫「优化器自己进化」：TGD.step 的提示人写完就冻着。

DSPy 加示范、TextGrad 改指令，GSM8k 82.1 是拼出来的，不是图自己搜出一种新 $I$。作者把组合写成未来方向。花园读法：两套 $I$ 都在墙外，拼在一起仍在墙外。分子和放疗证明模拟器可以当 $\mathcal{L}$，和 FunSearch 的评估器是同一类墙外尺子——改的是产物，不是发现环。白盒提示优化要数值梯度、要开源权重；闭源 API 走不通。TextGrad 的前提写在引言：当前最强 LLM 能对系统里单个组件讲出该怎么改。组件一多、几处批评互相打架，并集没有消冲突的算子，只能靠 TGD 那一次调用把几份句子揉进新变量。这是 ACE 说「越改越吵」的几何来源：没有 Merge 把条目拆开计数，只有整段重写。能用，不等于改进器进了循环。

LeetCode 完成率对隐藏测试。循环优化的是「本地测试 + LLM 对更难测试的想象」。想象不是平台。GPQA 的 55.0 对 51.0 用字符串匹配；温度 0 仍可能非确定。作者自己写 gpt-4 非确定来源说不清。读 55 先问是 diamond 还是全盘、温度多少、几轮多数票。约束写进自然语言，跟不住时没有数值投影把变量拉回可行域。动量是「更新时看见旧 $v$」，不是 Adam 的一阶矩。

**读**：两类优化、式 (1)、$n$ 边最多 $n$ 次梯度调用、Table 1 的 0.26/0.31/0.36 与摘要 20% relative、GPQA 51→55 对上文档 53.6 diamond、MMLU 两子集、Table 3 的 91.9/79.8/81.1、36 条训练题加验证门、DSPy 拼上 82.1、问答损失无金标 / 提示优化有金标、L0 与薄 $H_t$、meta-TextGrad 是未来工作。
**不读**：把 TGD 听成改权重、用 20% 当绝对点、用 55 盖 51 说已经专家级、把 0.36 和 Reflexion 的 HumanEval 91.0 横加、把分子对接听成 RSI、说已经式 (2)。
