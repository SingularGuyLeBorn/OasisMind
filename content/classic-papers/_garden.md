# 经典论文

大模型论文已经多到没有人能够按发布日期全部读完. 每周的新论文会换一批模型名和基准表, 但真正决定一个方向怎样思考的工作并没有同比增加. 注意力, 残差连接, 规模定律, 混合专家, 策略梯度和分布式训练都有少数奠基论文; 后面的研究往往是在其中一个假设, 模块或工程瓶颈上继续推进. 如果这些基础没有建立起来, 新论文读得越多, 脑子里的名词越多; 基础一旦稳定, 很多新工作只需判断它改了哪个量, 省了哪类成本, 又引入了什么限制.

Ilya Sutskever 给 John Carmack 的阅读清单提供了一个很有吸引力的起点. 本库采用社区根据公开线索重建的稳定版本, 共收录 27 项材料; 「30 papers」是后来更常见的概称. 这条路线从信息论, 神经网络训练和卷积网络一路走到 RNN, 注意力, 生成模型与规模化训练, 追踪现代深度学习所依赖的基本观念怎样形成.

周星星整理的 LLM Atlas 提供了另一种选篇标准: 一个领域的论文虽多, 真正建立坐标的工作通常只有少数几篇. 经典论文持续提供沿用至今的问题定义, 数学对象和实验方法. 原始版本给新论文的改动提供参照, 后续工作则标出早期结论的适用边界与修正结果.

## 三部分怎样使用

### 先建立读论文的方法

[阅读指南](1-阅读指南.md)从问题设定, 输入输出, 目标函数, 对照基线, 消融和实验条件六个方面组织论文. 数据量, 计算预算或评测协议发生变化时, 表格中的数字不能直接横向比较. 指南据此安排阅读顺序: 确认论文改变的对象, 核对公式与实验, 再界定尚未解决的问题.

每篇精读保留论文的符号和关键数字, 并按问题与机制重组材料. 公式展开到可以代入小规模例子, 实验注明数据集, 模型规模和比较对象, 历史影响由后续工作验证. 这些信息共同回答三个问题: 论文面对什么困难, 核心方法怎样计算, 证据能够支持多强的结论.

### 沿重建清单补齐基础

[Sutskever 阅读清单](2-sutskever阅读清单/2-sutskever阅读清单.md)是主体. 第一组从 Kolmogorov 复杂度, 最小描述长度和有限状态自动机开始, 建立「学习就是用有限表示压缩规律」的早期视角. 后面进入反向传播, 初始化, 卷积网络和残差连接, 再转向 RNN, LSTM, 注意力与 Transformer. 最终一组讨论结构化记忆, 生成模型, 流水线并行和规模定律. 这条顺序不是今天训练 LLM 的操作手册, 但能展示许多今天默认接受的设计在当时解决了什么问题.

清单中的博客,讲义和论文承担不同职责. 一篇历史文章可能没有正式定理, 却清楚记录了研究者怎样发现某种现象; 一篇理论论文可能与今天的工程实现相距很远, 但提供了仍在使用的目标函数. 本库不按发表场所给它们排等级, 只检查论证是否完整, 后续影响是否真实, 以及它能否帮助理解现代模型.

### 补上清单之后绕不开的工作

[补充经典](3-补充经典/3-补充经典.md)收录原清单没有覆盖, 但今天读模型架构时经常遇到的方向. 当前包括状态空间模型和稀疏混合专家. HiPPO 解释连续信号怎样压进有限状态, 这条线后来进入 S4, Mamba 和一批线性时间序列模型; Sparsely-Gated MoE 与 Switch Transformer 则建立条件计算的主要形式, 后来的大模型 MoE 仍在处理路由, 容量和负载均衡这些问题.

补充部分不会按热点无限增长. 一篇工作进入这里, 至少要满足两个条件: 它建立了后来反复复用的问题或机制, 并且只读后续改进无法完整理解这个起点. 普通的局部性能提升更适合放进对应专题库, 这里保留的是可以长期充当参照系的工作.

## 从经典论文提取可复用的坐标

### 从模型名回到可比较的对象

一篇论文的改动可以落在网络中的信息路径, 优化目标的估计方式, 参数的激活规则, 状态的存储方式或硬件执行顺序上. 两篇工作即使都宣称提高长上下文能力, 一篇可能减少注意力计算, 另一篇只是扩展位置编码; 它们解决的问题和代价并不相同. 经典论文提供的是这些可复用对象, 后续方法则在同一对象上改变约束或预算.

证据需要分成三层. 公式说明方法在给定假设下优化什么; 消融说明某个组件在当前训练配方中的边际作用; 跨数据集与跨规模复现才开始回答结论能否迁移. 训练损失下降不自动等于下游能力提高, 单一数据集上的增益也不能直接外推到所有任务. 规模, 数据, 训练时长和推理预算必须一起比较. 本库保留原始实验数字, 同时写明后来的复现或修正, 把结论限制在证据实际覆盖的条件内.

### 问题、方法与证据的对应关系

目标函数中的期望分布、架构图里的张量流、排行榜背后的训练预算与评测协议, 共同构成一篇论文的可核验部分. 论文直接验证的结论、作者给出的机制解释和后来工作补上的证据需要分开记录. **经典工作的作用是把新名词还原成已有的问题、变量和约束.**

同一闭环可以用于清单之外的新论文: 确定计算对象, 追踪证据, 比较代价, 再检查结论是否跨出了实验范围. RNN 到注意力、稀疏门控到现代 MoE 看似是两条不同路线, 都能用这四步还原. 小维度手算负责验证公式, 对照实验负责定位组件作用, 后续复现负责修正早期结论.

本库据此维护: 新文章需要补足一段长期有效的基础, 已有文章则随着更可靠的复现、历史材料和工程经验继续修正. 「经典」描述的是后续影响, 不授予结论免检权; 后续研究仍在使用它们的问题定义和假设, 因而更需要把适用条件写清楚.

几篇典型工作展示了这种对应关系. ResNet 先用更深 plain network 的训练误差上升定位优化退化, 再用恒等 shortcut 构造可达解, 最终通过 ImageNet 与 CIFAR 实验验证训练行为; 结论针对深层网络的优化, 不能自动推出残差结构解决泛化. Transformer 用固定的编码器—解码器结构、复杂度表和机器翻译实验说明 self-attention 的并行与路径长度优势, 后来的 decoder-only 大模型继承了其中一部分组件, 却改变了训练任务和生成协议.

规模定律又提供另一类证据. 幂律拟合描述特定数据分布、模型族和训练区间内的经验趋势, 计算最优结论还依赖参数量、token 数与预算的联合口径. Chinchilla 对早期配比的修正并没有否定缩放现象, 而是改变了固定计算量下参数与数据怎样分配. 因而「奠基工作」可以长期提供坐标, 其中的指数、最优比例和实现细节仍需随数据与硬件重新测量.
