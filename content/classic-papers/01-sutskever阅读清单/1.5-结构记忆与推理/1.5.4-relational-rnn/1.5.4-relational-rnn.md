# Relational Recurrent Neural Networks: 把 self-attention 塞进循环网络的记忆

> 本站学习路线 `1.5.4`
> Adam Santoro, Ryan Faulkner, David Raposo, Jack Rae, Mike Chrzanowski, Theophane Weber, Daan Wierstra, Oriol Vinyals, Razvan Pascanu, Timothy Lillicrap. DeepMind, 2018. [arXiv:1806.01822](https://arxiv.org/abs/1806.01822).

**全文符号表**

| 符号 | 含义 |

| $M$, $M_t$ | 记忆矩阵, $N$ 行 $F$ 列; 下标 $t$ 是时间步 |
| $N$ | 记忆 slot 数 (行数), 通常 4 到 16, 固定, 不随输入规模增长 |

| $Q, K, V$ | 投影后的 query, key, value 矩阵, 和路线 `1.4.2` 同义 |

| $f_{i,t}, i_{i,t}, o_{i,t}$ | 第 $i$ 条记忆在第 $t$ 步的遗忘门, 输入门, 输出门的未激活值 (logit), sigmoid 在使用处施加. **注意同名: 下标 $i$ 是记忆行号, $i_{i,t}$ 整体是输入门, 两个 $i$ 不是一个东西** |
| $W^f, U^f, b^f$ 等 | 各门的权重矩阵和偏置, 全部在 slot 之间共享 |
| $\tilde{b}_f$ | 遗忘门的额外可学习偏置, 与标准 LSTM 的唯一记号差别 |

| $g(\cdot)$ | 论文记号里的候选变换: 把第三阶段逐行 MLP 的输出 $\tilde{m}_{i,t}$ 变成写入候选 |

**读公式的方法**: 三组公式对应 §3 的三个阶段. 前两条是注意力交互, 与路线 `1.4.2` scaled dot-product attention 逐字相同, 唯一的变化是作用对象换成了记忆矩阵 $M$; 第二条 $[M; x]$ 拼接式读「query 只来自旧记忆, key 和 value 多看一个新输入」. §4 五条是 LSTM 门控, 和路线 `1.3.2` 同构, 读「旧记忆留多少, 提案写多少, 对外暴露多少」, 盯住下标 $i$: 每条记忆独立走同一套门, 参数全部共享.

## 1. 从路线 `1.5.3` 的局限说起

本站学习路线 `1.5.3` 是 Santoro 自己的 Relation Networks (RN). RN 的做法是把场景拆成对象, 对所有对象两两配对, 用一个共享的 MLP 计算每一对的关系, 再把所有关系加总. 它在 CLEVR 上把关系问答准确率刷到了 95.5%, 而当时最好的模型只有 68.5%. 这是 2017 年的结果, 证明「显式计算成对关系」这个归纳偏置本身值很多钱.

但 RN 有两个硬伤,  Santoro 团队自己比谁都清楚.

第一, 复杂度是 $O(n^2)$. $n$ 个对象产生 $n(n-1)/2$ 个配对, 每个配对过一次 MLP. 对象数量一上来, 计算量平方爆炸. 这不是工程问题, 是结构问题: RN 假设「任意两个对象都可能相关」, 这个假设在 100 个对象以内成立, 在真实世界不成立.

第二, 更致命的: RN 没有状态. 它处理的是一张静态图片或一个静态场景, 输入进来, 关系算完, 答案出去, 一切结束. 它没有记忆, 没有时间维度, 无法回答「三步之前看到的钥匙和眼前这把锁配不配」这类问题. 而真实世界的推理几乎全在时间里展开: 强化学习里的部分可观测环境, 程序执行里变量值的逐步更新, 语言里指代和前文实体的对应.

路线 `1.5.4` 就是来补这两个洞的. 思路一句话: 把关系推理从「一次性算完全部配对」改成「在时间步上持续维护一组记忆对象, 每一步让记忆之间做一次注意力气交流」. 这个模块叫 Relational Memory Core, 简称 RMC.

换句话说, RN 回答「静态场景里谁和谁有关系」, RMC 回答「随时间展开的事件流里, 记住的东西之间有什么关系」. 前者是照相机, 后者是工作记忆.

## 2. 问题的精确表述: 记忆存下了, 但记忆之间不说话

在 RMC 之前, 序列模型的记忆分两大流派, 各自有一个盲区.

LSTM 把所有信息压缩进一个隐向量 $h_t$ 和一个细胞状态 $c_t$. 两个向量, 维度固定, 无论序列多长都不增长. 优点是计算有界, 梯度能传很远. 缺点是所有信息被打散混在同一个向量里, 没有「对象」的概念. 你想让「第 3 个向量」和「参考向量 m」做一次比较, 先得从同一个向量的不同维度里把它们分离出来, 而网络没有任何结构上的偏置去做这种分离. 论文的原话是: LSTM 把所有信息装进一个公共的隐记忆向量, 这让分 compartment 化和关系推理都变得更难.

另一派是记忆增强网络, 代表是 Neural Turing Machines (本站学习路线 `1.5.6`, 2014 年) 和它的后继 DNC. 它们有一个外置记忆矩阵, 一行一个 slot, 控制器通过读写头操作. 对象级 compartment 化解决了, 但新问题出现了: slot 之间是隔离的. 信息写进 slot 之后就躺在那里, 直到被读出来. 两个 slot 之间没有任何机制可以交换信息, 比较内容, 计算关系. 所有的「推理」仍然发生在控制器的隐向量里, 记忆只是仓库, 不是讨论室.

RMC 的诊断是: 这两个流派一个缺对象, 一个缺交互. 人类的工作记忆两样都有, 你脑子里同时挂着几个独立的信息块, 并且它们之间可以互相对照. 把这两样同时给循环网络, 就是 RMC 的全部动机.

顺带一提, 同一时期还有第三条路线: 把所有历史状态存成一个不断增长的 buffer, 用注意力在全历史上检索, 也就是 Transformer 的做法. 这条路线捕获长程关系最强, 但计算和存储随时间步线性增长, 在步数无界的场景 (比如在线 RL, 模型要和真实环境交互几百万步) 直接不可行. 论文在 Discussion 里点了这个死穴, 还给了一个预言式的建议: 先无损地积累一段记忆, 再学一个循环核心把它压缩, 然后处理下一段. 一年后, 本文作者之一 Jack Rae 发表了 Compressive Transformer, 把这句话变成了论文. 这是后话.

## 3. RMC 的数学结构: 记忆即对象集合

RMC 的记忆是一个矩阵 $M$, 维度 $N \times F$. $N$ 是记忆 slot 数, 每行 $m_i$ 是一个独立的记忆对象, $F$ 是每个对象的特征维度. 这是关键的本体论转变: LSTM 的记忆是一个向量, RMC 的记忆是一组对象.

每一步, RMC 收到上一时刻的记忆 $M_t$ 和当前输入 $x_t$, 输出新记忆 $M_{t+1}$:

$$M_{t+1} = g_\theta(M_t, x_t)$$

这个 $g_\theta$ 内部是三个阶段的流水线.

**第一阶段, 多头点积注意力 (MHDPA), 也就是 self-attention.** 对记忆矩阵做三组线性投影, 得到 query, key, value:

$$Q = M W^q, \quad K = M W^k, \quad V = M W^v$$

然后计算缩放点积注意力:

$$A(M) = \text{softmax}\left(\frac{M W^q (M W^k)^T}{\sqrt{d_k}}\right) M W^v$$

拿上面刚定义的 $Q, K, V$ 代进去, 这条式子就是 $\text{softmax}(QK^T / \sqrt{d_k}) V$, 和路线 `1.4.2` 的缩放点积注意力逐字相同 (上标 $T$ 是转置, 本文上标 $T$ 只有这一个含义), 三步读法也一样: $QK^T$ 算出「哪条记忆找哪条记忆」的 $N \times N$ 匹配分矩阵, 除 $\sqrt{d_k}$ 再过 softmax 按行归一化成权重, 乘 $V$ 做加权混合. 唯一的区别是作用对象: 路线 `1.4.2` 作用于序列 token, 这里作用于记忆 slot.

输出 $\tilde{M}$ 和 $M$ 同维度, 可以理解为对 $M$ 的一次「提案更新」: 每个记忆 slot 的新内容, 是所有其他 slot 内容的加权混合, 权重由注意力决定. 一次注意力, 每条记忆都吸收了来自其他记忆的信息. 网络通过 $W^q, W^k, W^v$ 学会「什么信息该从哪条记忆搬运到哪条记忆」.

多头机制和 Transformer 完全一致: 用 $h$ 组独立的投影参数, 各算各的注意力, 每个头产出 $N \times F/h$ 的矩阵, 最后按列拼接回 $N \times F$. 不同头可以让同一条记忆向不同的目标发送不同的信息. 后面的实验会证明, 头不只是装饰, 单 slot 模型里加头能部分代偿 slot 的缺失.

**第二阶段, 把新输入写进来.** 论文的优雅之处在于: 写入操作和交互操作是同一个注意力算子, 只是改了 key 和 value 的拼接方式:

$$\tilde{M} = \text{softmax}\left(\frac{M W^q ([M; x] W^k)^T}{\sqrt{d_k}}\right) [M; x] W^v$$

和上一条式子逐字符对比, 只有两处改动, 都在 key 和 value 的输入上: $M$ 换成了 $[M; x]$, 即把当前输入 $x$ 作为新一行拼到记忆矩阵下面 (拼接记号同路线 `1.4.1`、`1.4.2`、`1.5.2`). 于是 key 和 value 各多出「当前输入」这一行, softmax 的匹配分矩阵变成 $N \times (N+1)$: 每条旧记忆除了和其他旧记忆互相打分, 还和当前输入打一次分. query 仍然只来自 $M$, 还是 $N$ 行, 所以输出还是 $N$ 行.

$[M; x]$ 表示把输入 $x$ 作为新一行拼接到记忆矩阵下面. query 只来自 $M$, key 和 value 来自 $M$ 加 $x$. 结果维度不变, 记忆条数守恒: 每条旧记忆去「看」所有旧记忆和当前输入, 决定自己更新成什么. 写入新信息, 读取旧信息, 记忆间交互, 三件事一个算子全包了.

**第三阶段, 逐行 MLP 加门控.** $\tilde{M}$ 的每一行独立过一个共享的 MLP (论文发现带 layer normalization 的逐行 MLP 效果最好), 然后进入门控机制, 这部分直接借自 LSTM.

## 4. 装进 LSTM: 门控, 以及记忆数与参数量的解耦

RMC 不打算发明新的循环骨架, 它把记忆矩阵 $M$ 直接解释成一个二维 LSTM 的细胞状态 $C$. 每一行 $m_i$ 走一套标准的 LSTM 门控方程:

$$f_{i,t} = W^f x_t + U^f h_{i,t-1} + b^f$$
$$i_{i,t} = W^i x_t + U^i h_{i,t-1} + b^i$$
$$o_{i,t} = W^o x_t + U^o h_{i,t-1} + b^o$$
$$m_{i,t} = \sigma(f_{i,t} + \tilde{b}_f) \odot m_{i,t-1} + \sigma(i_{i,t}) \odot g(\tilde{m}_{i,t})$$
$$h_{i,t} = \sigma(o_{i,t}) \odot \tanh(m_{i,t})$$

注意一个记号约定: 前三行的门变量是未激活值 (logit), 不带 $\sigma$; sigmoid 在使用处施加, 即第四行的 $\sigma(f_{i,t} + \tilde{b}_f)$, $\sigma(i_{i,t})$ 和第五行的 $\sigma(o_{i,t})$. 路线 `1.3.2` 把 $\sigma$ 写进门定义里, 使用处不再加, 两种写法等价, 本文采用原论文的形式, 这样遗忘门多加一个可学习偏置 $\tilde{b}_f$ 才写得出来.

逐行读. 前三行结构完全相同, 都是「当前输入 $x_t$ 过一次线性变换, 加上这条记忆上一步的暴露状态 $h_{i,t-1}$ 过另一次线性变换, 再加偏置」, 唯一差别是各用自己的权重, 下标 $i$ 是记忆行号: 每条记忆独立算自己的三个门, 但权重 $W, U, b$ 全部共享. 第四行是状态更新, 和路线 `1.3.2` $c_t = f_t * c_{t-1} + i_t * \tilde{c}_t$ 逐项对应: $\sigma(f_{i,t} + \tilde{b}_f) \odot m_{i,t-1}$ 是遗忘项, 决定旧记忆保留几成, $\tilde{b}_f$ 给遗忘门一个可学习的整体偏移; $\sigma(i_{i,t}) \odot g(\tilde{m}_{i,t})$ 是写入项, 决定注意力提案写进几成, $\odot$ 是逐元素乘. 第五行是暴露状态: 细胞内容过 $\tanh$ 压范围, 输出门 $\sigma(o_{i,t})$ 逐元素筛选. 还是路线 `1.3.2` 那组数: 某个分量旧记忆 $0.8$, 遗忘门读数 $0.1$, 写入候选 $0.5$, 输入门读数 $0.9$, 新分量就是 $0.1 \times 0.8 + 0.9 \times 0.5 = 0.08 + 0.45 = 0.53$, 旧记忆留一成, 提案写九成.

和标准 LSTM 唯一的区别是遗忘门里那个 $\tilde{b}_f$, 一个可学习的偏置. 遗忘门决定旧记忆保留多少, 输入门决定注意力提案写入多少, 输出门决定暴露多少给外部. 实践里作者发现输出门不必要, 去掉了.

门控的粒度有两种选择. unit gating 是逐元素标量门, 和标准 LSTM 一样, 权重 $W, U$ 是矩阵. memory gating 更粗: 每条记忆行只产出一个标量门, 权重矩阵退化成向量, 逐元素乘变成标量乘向量. 后者参数更省, 某些任务上反而更好.

这里藏着 RMC 最实用的一个工程性质: 所有权重 ($W^f, W^i, W^o, U^f, U^i, U^o$ 和注意力参数) 在 slot 之间共享. 所以改变记忆条数 $N$ 不改变参数量, 改变每条记忆的大小 $F$ 才改变参数量. 存储容量 (总单元数 $N \times F$) 和参数量 (正比于 $F$) 被解耦成了两个独立的旋钮. 论文后来发现, 不同任务需要不同的配比: Nth Farthest 要更多但不必更大的记忆 (8 或 16 条), 语言建模要更少但更大的记忆 (1 条, 2500 单元). 一个架构, 两种极端配置, 都能调到最优, 这在 LSTM 里做不到, LSTM 的隐层维度同时绑定了容量和参数量.

还有一点值得写清楚: RMC 每一步的注意力只发生在当前时刻的记忆之间, 不跨时间步检索历史. 这和 Bahdanau attention (本站学习路线 `1.4.1`) 以及 Transformer 的注意力是两种东西. 历史信息的压缩完全交给循环结构和门控, 注意力只负责「当下这几条记忆之间的即时对话」. 计算量因此与时间步数无关, 每步固定, 这正是在线场景能用的前提.

## 5. 血缘: 三个家族的混血

RMC 的结构可以拆成三个来源, 每个来源都在 本站学习路线里有对应条目.

从 LSTM (本站学习路线 `1.3.2`) 继承的是循环骨架和门控哲学: 有界的计算, 抗梯度消失的细胞状态, 用 sigmoid 门控制信息的保留和写入. RMC 的细胞状态从向量升级成矩阵, 门控从逐元素扩展出逐记忆行的选项, 但骨架没变.

从 NTM/DNC (本站学习路线 `1.5.6`) 继承的是 slot 化的外置记忆观: 记忆不是一个浆糊向量, 而是分 compartment 的对象集合, 每行一个对象. 但 RMC 扔掉了 NTM 那套复杂的可微读写头寻址机制 (content-based addressing, 位置插值, 分配权重), 换成注意力一步到位. NTM 的读写头一次只能操作一两个 slot, RMC 的注意力一步让所有 slot 两两交互. 仓库变成了讨论室.

从 Transformer (本站学习路线 `1.4.2`) 继承的是 MHDPA 本身, 连公式都一字不差: scaled dot-product attention, 多头, 逐位置 MLP. 区别是 Transformer 用注意力替代循环, RMC 用注意力增强循环. 2018 年的视角看, 这是两种对立世界观的第一次杂交: Transformer 说「注意力就够了, 循环可以扔」, RMC 说「循环的固定计算量有不可替代的价值, 但记忆内部需要注意力」. 后来的历史证明两边都对: 大规模预训练走了 Transformer 的路, 但「固定大小记忆 + 循环压缩」的思路在 Transformer-XL 和 Compressive Transformer 里复活, 今天长上下文研究里的 memory token, KV 压缩, 都可以追溯到这条线.

至于和路线 `1.5.3` RN 的关系: RN 的关系计算是无状态的 $O(n^2)$ 全配对, RMC 把它换成 $O(N^2)$ 的注意力, 其中 $N$ 是记忆条数, 通常 4 到 16, 且这个 $N$ 是固定的, 不随输入规模增长. 配对关系的归纳偏置保留了, 平方爆炸控制住了, 时间维度加上了. 路线 `1.5.3` 到路线 `1.5.4`, 是同一个研究团队把同一个思想从静态场景推进到序列的过程.

## 6. 实验一: Nth Farthest, 一个让 LSTM 全军覆没的玩具任务

论文先造了一个诊断性玩具任务, 精确打击「跨时间关系推理」这个能力点.

Nth Farthest 的输入是 8 个随机采样的向量, 每个 16 维, 从 $U(-1, 1)$ 均匀采样, 带一个 one-hot 的 ID 标签 (1 到 8, 随机分配, 与呈现顺序无关). 任务是回答: 「离向量 m 第 n 远的向量是哪个?」 $n$ 和 $m$ 每个序列随机采样, 作为任务说明编码进每个时间步的输入, 总输入维度 40.

这个任务的阴险之处在于: 光存储和检索没用. 模型必须计算所有向量与参考向量 m 的两两距离关系, 然后隐式地对这些距离排序. 而且 m 可能在序列的任何位置出现, 甚至模型得先记住一堆向量, 等 m 出现后再回头比较. 这强迫模型在记忆里维护对象, 并在对象之间算关系.

结果是一道断崖. LSTM 试了 64 到 4096 的隐层维度, DNC 试了 1/8/16 条记忆, 128 到 1024 的记忆尺寸, 1 到 4 个读写头, 全部失败, 最佳 batch 准确率过不了 30%. RMC 用 2048 总单元, 训练结束稳定达到 91%. 把向量维度加到 32 维 (对记忆保真度要求更高), RMC 仍然能做到类似水平, 只是种子间的稳定性下降.

超参扫描暴露了机制层面的规律. 固定总单元数, 8 条或 16 条记忆明显好于 1 条. 但只有一个 slot 时, 加注意力头 (8 头或 16 头) 能明显挽回性能. 这说明头可以在单一记忆内部提供某种软 compartment 化: 没有多 slot, 就用多头在同一个 slot 里切出子空间. 归纳偏置缺的部分, 容量能补一点, 但补不全.

论文还做了注意力可视化分析. m 出现之前, 模型把输入信息搬运进一两个记忆 slot (这些 slot 的 query 对输入 key 的注意力权重很高). m 出现之后, 所有 slot 的注意力集体转向写着 m 的那几条记忆. 这个行为模式和「先存草稿, 拿到参考点后集体对照」的人类解题策略几乎一致. 作者很诚实地加了限定: 一轮注意力之后记忆已经高度分布式, 对 compartment 化的解读不能过度.

## 7. 实验二: 程序评估, 符号操作的检验

第二个战场是 Zaremba 和 Sutskever 2014 年的 Learning to Execute (LTE) 数据集. 输入是伪代码片段, 图灵完备的迷你语言, 包含 for 循环, 变量赋值, 条件分支; 输出是程序执行结果的数字序列. 任务分三档: addition (纯加法), control (带循环), program (完整程序). 另有三个记忆任务 (copy, reverse, double) 作为对照. 符号算子就是定义在操作数上的关系, 学会执行程序约等于学会在符号之间做关系推理.

测试逐字符准确率, RMC 在每个任务上不差于任何基线, 在最难的 full program 上拉开差距:

| 模型 | Add | Control | Program | Copy | Reverse | Double |
|------|-----|---------|---------|------|---------|--------|
| LSTM | 99.8 | 97.4 | 66.1 | 99.8 | 99.7 | 99.7 |
| EntNet | 98.4 | 98.0 | 73.4 | 91.8 | 100.0 | 62.3 |
| DNC | 99.4 | 83.8 | 69.5 | 100.0 | 100.0 | 100.0 |
| RMC | 99.9 | 99.6 | 79.0 | 100.0 | 100.0 | 99.8 |

几个观察. DNC 在 control 任务上掉到 83.8, EntNet 在 copy 和 double 上崩了, 说明纯记忆增强或纯实体跟踪的路线各有偏科. RMC 是唯一全科及格的. 79.0 vs 66.1 这个 13 个点的差距出现在最需要关系推理的 program 任务上, 不是巧合.

两个工程细节值得记. 第一, 作者发现不用 teacher forcing, 训练时就用模型自己的预测喂回解码器 (非自回归训练), 结果反而更好, 推测是放松了对 ground truth 的依赖, 改善了泛化. 第二, 表现最好的 LSTM 基线参数量远多于表现最好的 RMC, RMC 用更少的参数拿到更高的分, 说明收益来自结构, 不是容量堆出来的.

## 8. 实验三: RL 战场, Mini-Pacman 与 BoxWorld

强化学习是检验「记忆推理」最硬的场景, 因为部分可观测性是天然的: 智能体看不全环境, 必须在记忆里重建世界状态并做规划.

Mini-Pacman 加了 viewport 限制: 智能体只能看到自己周围 5x5 的窗口. 它必须在记忆里追踪鬼的位置和动向, 记住哪些豆子吃过了, 规划路线. 结果: viewport 条件下 RMC 约 677 分, LSTM 约 550 分, 多出近 130 分. 给全观测条件, 差距拉得更大: RMC 1159, LSTM 598, 接近翻倍. 观测越完整, 需要维护的关系越多, LSTM 的向量记忆越装不下.

BoxWorld 更纯粹. 14x14 的像素网格, 散落着钥匙和锁, 锁打开后给出下一把钥匙, 一条唯一的钥匙-锁链通向宝石, 外加最多 5 条干扰岔路. 钥匙用一次就消失, 走错岔路直接死局, 所以智能体必须前瞻推理整条链. 位置全部随机化, 故意消灭空间偏置, 逼模型靠抽象关系而不是靠 CNN 的位置先验. 智能体同样只有 5x5 的 viewport.

难度由解路径长度 (1 到 5 个锁) 和干扰分支数控制. RMC 智能体在 1e9 步训练后解出 98% 的关卡. 换成 ConvLSTM 基线, 只有 73%. 论文说只有 RMC 解出了最难级别, 靠的就是在记忆空间里对钥匙-锁关系做推理, 而不是在像素空间里做模式匹配.

## 9. 实验四: 语言建模, 三个数据集刷 SOTA

前面三个战场都可以被质疑「任务是专门为 RMC 设计的」. 语言建模不能, 这是有大量调优基线的真实战场. 三个数据集: WikiText-103 (约 1 亿 token 的维基百科文章), Project Gutenberg (1.8 亿 token 的书籍), GigaWord v5 (40 亿 token 的新闻). 词表统一约 25 万, 大到能装下罕见词和数字.

困惑度结果 (越低越好):

| 模型 | WikiText-103 valid/test | Gutenberg valid/test | GigaWord test |
|------|------------------------|---------------------|---------------|
| LSTM (Grave et al.) | - / 48.7 | - | - |
| Temporal CNN | - / 45.2 | - | - |
| Gated CNN | - / 37.2 | - | - |
| LSTM (Rae et al.) | 34.1 / 34.3 | 41.8 / 45.5 | 43.7 |
| Quasi-RNN | 32 / 33 | - | - |
| RMC | 30.8 / 31.6 | 39.2 / 42.0 | 38.3 |

比当时已发表的最佳结果低 1.4 到 5.4 个困惑度, 相对提升 5% 到 12%, 三个规模三个风格的数据集一致成立.

配置上有意思的点: 语言建模的 RMC 只用 1 条记忆 slot, 2500 总单元, 4 个头, 5 层逐行 MLP, 1 个注意力 block. 选单 slot 不是因为它更好, 是因为语言建模需要巨量参数 ( embedding 和 softmax 层吃掉大部分预算), 而「参数多 + slot 多」的组合当时跑不动. 作者明确说不声称单 slot 对语言建模最优, 只是算力约束下的取舍. 这句话在今天读来像预言: 多头对单 slot 的代偿作用, 后来成了标准配置.

训练规模也交代一下: 6 张 Nvidia Tesla P100 同步训练, 每卡 batch 64, 总 batch 384, BPTT 截断到 100 步, Adam 学习率 0.001, 梯度裁剪到 L2 范数 0.1, 词向量 512 维加 0.5 dropout, 输入输出 embedding 权重共享.

分析层面有三个发现. 第一, RMC 的数据效率略好于 LSTM, 同样的验证困惑度用更少步数达到. 第二, 截断测试时的展开长度, RMC 在短上下文下性能衰减更小: 100 步展开时 RMC 困惑度只回退约 1, LSTM 回退约 5. 说明 RMC 更擅长抓短期关系, 不太依赖长上下文. 第三, 按词频拆开看, 提升几乎全部来自高频词: GigaWord 上出现超过 1 万次的词, LSTM 困惑度 39.4, 加 Hebbian Softmax 的 LSTM 33.2, RMC 28.3. 高频词的预测靠的是上下文里句法和语义的即时关系, 这正是记忆间交互能提供的. 罕见词靠的是长期记忆里的检索, RMC 没有优势.

## 10. 代价分析: 没有免费的关系推理

RMC 的收益有明确的价格.

第一是每步计算成本. LSTM 每步是几次矩阵乘, RMC 每步多了一套完整的 MHDPA (对 $N \times N$ 的注意力矩阵) 加逐行 MLP. 论文没有给出精确的慢几倍数字, 但留下了两条旁证: 超参扫描的图 4 是按 wall-clock 时间对齐的, 作者明确说「条数多但每条小的记忆比条数少但每条大的跑得快」; 语言建模被迫选单 slot 的直接原因就是「参数多且 slot 多的模型跑不快」. 每步常数更大, 这是固定计算量换关系能力的必然代价.

第二是超参敏感度上升. LSTM 在这个任务上「怎么调都一样」 (Nth Farthest 里怎么调都失败), RMC 则引入了记忆条数, 记忆尺寸, 头数, 注意力步数 (block 数), 门控粒度, 后处理 MLP 层数六个新旋钮. 论文附录列了每个任务的精确配置, 不同任务的最优配置差异很大: 程序评估 4 slot 4 头, BoxWorld 4 slot 4 头 1024 单元, 语言建模 1 slot 4 头 2500 单元. 通用架构, 任务特化配置, 调参成本是真实存在的.

第三是 scaling 前景的天花板. 2018 年的 RMC 赢的是「每步固定计算」这条赛道, 对手是 LSTM 和 DNC. 但同一年 Transformer 已经在另一条赛道上狂奔: 放弃固定计算, 用平方复杂度的全历史注意力换建模能力. 后来六年的历史是第二条赛道碾压式的胜利. RMC 语言建模的 31.6 困惑度在 2018 年是 SOTA, 但这个纪录的生命周期以月计. 这不否定 RMC 的价值, 它的价值在在线 RL, 流式处理, 步数无界这些 Transformer 原生处理不了的场景, 以及它留下的思想遗产.

## 11. 后续影响: RIMs, Compressive Transformer 与记忆增强的复兴

RMC 的直接后代有两条清晰的线.

第一条是 Recurrent Independent Mechanisms (RIMs, Goyal et al., 2019). 把 RMC 的「记忆 slot + 注意力交互」推广成「独立循环机制 + 稀疏通信」: 多个 RNN 模块各自独立演化, 每一步只有 top-k 个模块被激活, 模块间通过注意力稀疏交换信息. RIMs 显式引用了 RMC, 把「对象级 compartment 化 + 注意力通信」从记忆设计上升为模块化计算的通用原则.

第二条是 Compressive Transformer (Rae et al., 2019), 作者正是本文的 Jack Rae. 它实现了 RMC Discussion 里那句预言: 近期的历史无损保存, 超过窗口的旧历史用一个压缩函数 (包括训练成 autoencoder 或注意力重建) 压进固定大小的记忆. 循环的固定计算和注意力的长程检索被缝在了一起. 这条线再往后就是今天长上下文研究里的各种记忆压缩方案.

放到 2026 年看, RMC 更像一个路标而不是终点. 它指出的问题依然成立: 纯注意力的全历史检索在步数无界时不可行, 固定大小的状态必须学会主动管理信息. 它给出的解法里的两个成分, 对象化的记忆槽位和记忆间的注意力交互, 已经溶进了现代架构的血液里. 今天 agent 系统里的 memory 模块, 把检索到的记忆条目拼进上下文再做推理, 就是 RMC 思想在系统工程尺度的重放, 只是循环训练换成了 in-context 的近似.

## 12. 本站学习路线位置

本站 `1.5` 是“结构、记忆与推理”主题组：Pointer Networks 处理指向输入位置的输出，Order Matters 研究集合编码的顺序影响，Relation Networks 把成对关系计算做成模块，本篇把关系推理装进循环记忆，Neural Message Passing 把局部关系推广到图结构，Neural Turing Machines 则提供可微外部记忆方案。它们是互补视角，不应写成严格的单线继承。

Adam Santoro 同时参与了路线 `1.5.3` Relation Networks 与 `1.5.4` Relational RNN：前者验证静态场景中的关系推理模块，后者把关系计算装入循环记忆并用于序列任务。路线 `1.4.2` 的 Transformer 提供注意力零件，路线 `1.5.6` 的 NTM 提供可微记忆矩阵的参照，路线 `1.5.4` 则把这些思想与 LSTM 式门控结合起来。将 `1.4.2`、`1.5.3`、`1.5.4`、`1.5.6` 对照阅读，可以看到 2014 到 2018 年间「记忆与推理」研究的几种互补方案；这不是严格的单线继承关系。
