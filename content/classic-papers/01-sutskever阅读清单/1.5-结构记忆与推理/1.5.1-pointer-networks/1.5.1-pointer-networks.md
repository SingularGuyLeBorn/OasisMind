# Pointer Networks: 把 attention 从「加权混合」改成「指哪打哪」

> 原始论文: Oriol Vinyals, Meire Fortunato, Navdeep Jaitly, "Pointer Networks", arXiv:1506.03134, NIPS 2015.
> https://arxiv.org/abs/1506.03134
> 这是本站学习路线 `1.5.1`. 本站学习路线 `1.4.1` 是 Bahdanau 的 attention, 路线 `1.4.2`、`1.4.3`是 Transformer, 路线 `1.5.1` 回到 2015 年, 讲 attention 机制发表不到一年之后的第一个「歪用」: 不拿它加权混合信息, 拿它当指针. Vinyals 也是 seq2seq 论文的二作和本站学习路线 `1.5.2` Order Matters 的一作, 这两篇是「集合与排列」的姊妹篇.

全文四条公式, 记号和路线 `1.4.1` Bahdanau 论文高度同构, 符号表放在最前面, 公式旁边会再讲一遍.

**全文符号表**

| 符号 | 含义 |
|------|------|
| $\mathcal{P}$ | 输入点集 $\{P_1, \dots, P_n\}$, 三个几何任务里就是平面上点的坐标 |
| $P_j$ | 输入点集里第 $j$ 个点, 一个向量 |
| $n$ | 输入长度 (点数或城市数), **逐样本变化**, 这是全文一切设计的出发点 |
| $\mathcal{C}^{\mathcal{P}}$ | 输出序列 $\{C_1, \dots, C_{m(\mathcal{P})}\}$, 一串下标, 上标 $\mathcal{P}$ 表示它依赖输入 |
| $C_i$ | 输出第 $i$ 步的下标, 取值范围 $\{1, \dots, n\}$ |
| $m(\mathcal{P})$ | 输出序列的长度, 依赖输入, 比如凸包的顶点数 |
| $\theta$ | 模型的可训练参数, 写在分号后面表示「给定参数」 |
| $\mid$ | 条件坚线, 读作「在...的条件下」, 左边是打分对象, 右边是给定条件 |
| $e_j$ | 编码器在第 $j$ 个输入位置的隐状态 (对应路线 `1.4.1` 的注解 $h_j$) |
| $d_i$ | 解码器第 $i$ 步的隐状态; $d'_i$ 是加权混合出来的上下文向量 (对应路线 `1.4.1` 的 $c_i$) |
| $u^i_j$ | 第 $i$ 个输出步给第 $j$ 个输入位置打的匹配分 (对应路线 `1.4.1` 的 $e_{ij}$, 本文上标 $i$ 是输出步, 下标 $j$ 是输入位置) |
| $a^i_j$ | $u^i_j$ 过 softmax 后的注意力权重, 全部 $j$ 加起来等于 1 |
| $v, W_1, W_2$ | 对齐模型的三组可学习参数 (对应路线 `1.4.1` 的 $v_a, W_a, U_a$) |
| $\cdot$ | 点积: 两个等长向量对应分量相乘再求和 |
| $\tanh$ | 双曲正切, 把每个分量压到 $(-1, 1)$ |
| $\prod_{i=1}^{m}$ | 连乘: 把 $i$ 从 1 到 $m$ 的每一项乘起来 |
| $\mathrm{softmax}$ | 取 exp 再除以总和, 把一组分数变成加起来等于 1 的分布 |

**读公式的方法**: 四条公式讲一个「删掉一行」的故事. 第一条 (§2 链式分解) 和路线 `1.4.1` 相同, 读「整串输出的概率拆成逐位条件概率的连乘」. 第二条 (§3 对齐分数) 和路线 `1.4.1` 的 $e_{ij}$ 同构, 读「输入位置 $j$ 和输出步 $i$ 有多匹配」. 第三条 (§3 加权混合) 是 attention 的调酒步. 第四条 (§3 softmax 直接当输出) 是 Ptr-Net 的全部改动: 第三条被删, 分数归一化后直接交卷. 读这四条公式只需盯一个问题: softmax 出来的那组数, 拿去混合了 (attention) 还是直接当答案 (指针).

## 1. 背景: 2015 年的 seq2seq 帝国和它的一道裂缝

2014 到 2015 年是神经序列建模的好年景. Sutskever, Vinyals, Le 的 seq2seq 用一个 LSTM 把输入序列压成向量, 另一个 LSTM 从向量展开输出序列, 机器翻译第一次有了端到端的神经方案. Bahdanau, Cho, Bengio 随后补上 attention, 解码每一步都能回头「看」整个输入, 翻译质量再上一截. 同一时期, 这套范式还被搬到句法分析, 图像描述, 视频描述, 甚至「学习执行小程序」上, 看起来无所不能.

但论文引言里点名了一道裂缝: 所有这些方法都要求**输出词表的大小事先固定**. 翻译的词表是固定的 3 万个词, 句法分析的标签集是固定的几十个. 软最大层 (softmax) 的输出维度在模型建好的那一刻就焊死了.

有一类问题天生不满足这个条件. 给你一个点集求凸包, 输出是其中若干个点按逆时针排列的编号序列. 给你 n 个城市求最短回路, 输出是 1 到 n 的一个排列. 这些输出的「词表」就是输入本身, 输入有 n 个元素, 输出词表就有 n 个选项. n 变了, 词表大小跟着变. 普通 seq2seq 碰到这种问题只有一个笨办法: 每个 n 单独训一个模型. 输入长度换一换, 模型作废重来.

排序, 凸包, 旅行商问题 (TSP), Delaunay 三角剖分, 都属于这一类. 它们的共同特征是输出元素是「输入序列中的位置」, 是离散的下标, 不是从固定词典里挑的词. 论文把这类问题叫做输出字典大小依赖输入长度的问题, 整篇文章就是要拆掉这道墙.

值得一提的是论文的题目选择. 作者没有挑翻译或者摘要这种「软」任务, 而是挑了三个计算几何里的经典问题. 这些问题的精确解有成熟的算法, 凸包和 Delaunay 有 $O(n \log n)$ 的精确算法, TSP 有 $O(2^n n^2)$ 的 Held-Karp 精确算法和一堆近似算法. 选它们当考场的好处是答案可以机械地批量生成, 对就是对, 错就是错, 没有人工标注的含糊空间. 这是一个为「神经网络能不能学算法」这个问题量身定制的实验台.

## 2. 问题定义: 输出是输入的排列或子集

形式化一点. 训练样本是一对 $(\mathcal{P}, \mathcal{C}^{\mathcal{P}})$. 输入 $\mathcal{P} = \{P_1, \dots, P_n\}$ 是 n 个向量, 在三个几何任务里就是平面上均匀采样在 $[0,1] \times [0,1]$ 里的点的笛卡尔坐标. 输出 $\mathcal{C}^{\mathcal{P}} = \{C_1, \dots, C_{m(\mathcal{P})}\}$ 是一串下标, 每个 $C_i$ 是 1 到 n 之间的整数, 外加表示序列开始和结束的特殊符号.

模型要学的还是条件概率的链式分解:

$$
p(\mathcal{C}^{\mathcal{P}} \mid \mathcal{P}; \theta) = \prod_{i=1}^{m(\mathcal{P})} p(C_i \mid C_1, \dots, C_{i-1}, \mathcal{P}; \theta)
$$

和路线 `1.4.1` 的链式分解是同一个动作, 逐项读. 左边是「给定输入点集 $\mathcal{P}$ 和参数 $\theta$, 输出恰好是 $\mathcal{C}^{\mathcal{P}}$」的概率, 坚线 $\mid$ 读作「在...的条件下」, 分号后是模型参数. 右边把它拆成逐位条件概率的连乘, $i$ 从 1 乘到输出长度 $m(\mathcal{P})$: 第 $i$ 位的概率以「前 $i-1$ 位已经选出的下标」和「整个输入点集」为条件. 一个完整输出一个数, 训练时最大化这个数.

这个分解本身和 seq2seq 一模一样, 用 LSTM 做编码器和解码器, 训练目标是最大化训练集上的对数似然, 推理时用 beam search 找概率最高的输出序列. 困难全部藏在 $p(C_i \mid \cdot)$ 这个分布的支撑集上: 它的取值范围是 $\{1, \dots, n\}$, 而 n 逐样本变化.

三个任务把「输出是输入的函数」这件事展示了三种形态. 凸包的输出是输入点集的一个子序列, 选出的点按逆时针连成一个简单多边形. TSP 的输出是输入点集的一个全排列, 每个城市恰好出现一次. Delaunay 三角剖分的输出是一组三元组, 每个三元组是三个顶点的下标, 整体在置换意义下是一个集合而不是序列. 子集, 排列, 集合, 组合优化里输出结构的三种基本类型, 一篇论文全占了.

作者还顺手排除了一条「作弊」路线: 让 RNN 直接回归输出点的坐标. 这条路在推理时无法保证输出的点恰好落回输入点集, 序列越长预测越发散, 视频预测里的 seq2seq 已经演示过这种模糊化 (blurry) 的失败模式. 把输出约束成「指回输入」, 等于把解空间从连续平面压缩到 n 个离散位置, 问题的难度降了一个量级. 这个观察后来成了整个指针范式的设计哲学: 能选就别生成.

## 3. 模型: 从 Bahdanau attention 删掉一行

论文的模型部分写得极有教学价值, 三节递进: 先复习 vanilla seq2seq, 再复习 Bahdanau 的 content-based attention, 最后给出 Ptr-Net, 而 Ptr-Net 相对 attention 的改动只有一处.

Bahdanau attention (本站学习路线 `1.4.1`) 的计算是三步. 记编码器隐状态为 $(e_1, \dots, e_n)$, 解码器隐状态为 $(d_1, \dots, d_{m(\mathcal{P})})$. 第 i 个输出步先算对齐分数:

$$
u^i_j = v \cdot \tanh(W_1 e_j + W_2 d_i), \quad j \in \{1, \dots, n\}
$$

这条和路线 `1.4.1` 的 $e_{ij} = v_a \cdot \tanh(W_a s_{i-1} + U_a h_j)$ 是同一条公式, 只换了符号名字, 逐块读法也一样. $W_1 e_j$ 把编码器第 $j$ 个位置的隐状态映到一个公共打分空间, $W_2 d_i$ 把解码器第 $i$ 步的隐状态映到同一空间, 相加过 $\tanh$ 得到匹配向量, 最后和可学习向量 $v$ 做点积压成标量, 就是「输出步 $i$ 对输入位置 $j$」的匹配分 $u^i_j$ (原论文写作转置相乘 $v^T$, 和路线 `1.4.1` 一样, 这里统一用点积记号). 对固定的 $i$, 遍历全部 $n$ 个输入位置, 得到 $n$ 个分数.

然后归一化成注意力分布 $a^i = \mathrm{softmax}(u^i)$ (对固定的 $i$, 把 $n$ 个匹配分取 exp 再除以总和), 最后用这个分布对编码器隐状态做**加权混合**, 得到上下文向量:

$$
d'_i = \sum_{j=1}^{n} a^i_j e_j
$$

求和遍历全部 $n$ 个输入位置, 每个位置的隐状态 $e_j$ 乘上自己的权重 $a^i_j$ 再相加. 权重大的位置主导这杯「混合酒」的味道, 这就是路线 `1.4.1` $c_i = \sum_{j=1}^{T_x} \alpha_{ij} h_j$ 的同一个动作.

$d'_i$ 和 $d_i$ 拼接后用于预测下一个词. attention 在这里的角色是「调酒师」: 把输入各处隐状态按比例兑成一杯, 喂给解码器. 输出词来自固定词表上的另一个 softmax, 和输入位置毫无关系.

Ptr-Net 的改动是: **不要调酒那一步**. 对齐分数 $u^i$ 经过 softmax 之后, 直接当作输出分布用:

$$
p(C_i \mid C_1, \dots, C_{i-1}, \mathcal{P}) = \mathrm{softmax}(u^i)
$$

同一组分数, 两种用法, 代一组数看差别. 设输入只有 3 个点, 某一步的匹配分是 $u^i = (2, 1, 0)$. softmax 之后是 $(0.665, 0.245, 0.090)$ (和路线 `1.4.1` 同一组数, exp 之后 7.39, 2.72, 1.00, 总和 11.11). Bahdanau 的做法: 拿这三个数去加权混合, $d'_i = 0.665 e_1 + 0.245 e_2 + 0.090 e_3$, 喂给解码器预测下一个词, 输出还是来自固定词表. Ptr-Net 的做法: $(0.665, 0.245, 0.090)$ 本身就是答案, 意思是「第 $i$ 步选 1 号点的概率 66.5%, 选 2 号点 24.5%, 选 3 号点 9.0%」, 输出直接落在输入位置上. 公式一字未改, 语义从「配料比例」变成了「候选名单」.

这个分布定义在输入位置 $\{1, \dots, n\}$ 上, 词表大小等于输入长度, 天然变长. 为了让链式法则里的条件 $C_{i-1}$ 喂得回去, 解码器下一步的输入直接复制被指向的那个输入向量 $P_{C_{i-1}}$. attention 从「调酒师」变成了「指路人」: 不混合任何信息, 只指出下一个该选谁.

这个改动的代价是每步解码要对 n 个输入位置各算一次分数, 推理复杂度 $O(n^2)$, 论文明确记了这笔账. 收益是架构第一次能处理变长输出词表, 而且同一套权重可以服务任意 n. 论文还指出, 这个想法不只适用于 RNNSearch, Memory Networks 和 Neural Turing Machines 的 attention 机制同样可以改造成指针. 这句话像是对本站学习路线 `1.5.6` 的预告.

从今天的视角看, 这一步的思想含量远超它的代码量. 它确立了「attention 分数本身就是分布」的观念: softmax 之后的那组数不一定非要去加权求和, 它可以直接是答案. 两年后 Transformer 里的 copy 机制, pointer-generator 摘要模型里「从原文抄词」的开关, 都是这一观念的直系后代.

## 4. 实验一: 凸包, 从 1.9% 到 72.6%

凸包是作者选定的「指导性任务」 (guiding task), 用来摸清纯数据驱动方法相对精确算法能走多远. 精确算法 $O(n \log n)$, 答案基本唯一, 输出约定从编号最小的点出发逆时针走, 消除表示歧义. 评价用两个指标: accuracy, 输出序列表示的多边形和真凸包完全一致才算对; area coverage, 输出多边形与真凸包的交集面积占比, 只在输出是简单多边形 (无自交) 的样本上计算, 如果一个算法超过 1% 的样本画不出简单多边形, 直接记 FAIL.

第一组对比在固定长度 n=50 上做. vanilla LSTM 准确率 1.9%, area 指标 FAIL, 基本全军覆没. LSTM 加 attention 之后准确率 38.9%, area 99.7%, 起死回生. Ptr-Net 准确率 72.6%, area 99.9%. 同样的小规模对比, n=5 时 LSTM 有 87.7%, Ptr-Net 92.0%; n=10 时 LSTM 掉到 29.9% 且 FAIL, Ptr-Net 87.0%. 三个固定长度上, Ptr-Net 全部超过基线.

更有意思的是变长实验. 单个 Ptr-Net 在 5 到 50 的长度上均匀采样训练 (作者试过课程学习, 没效果, 均匀采样反而最好), 一个模型通吃所有训练过的长度. n=50 时准确率 69.6%, 相对只训 50 的专精模型略有退化, 这是通才的税.

然后是全文最有冲击力的数字: 外推. 同一个 5-50 训练的模型, 在从没见过的长度上测试. n=100 准确率 50.3%, n=200 有 22.1%, 连 n=500 都还有 1.3%, 而 area coverage 始终停在 99.2% 到 99.9%. 也就是说, 即使顶点序列不完全对, 画出来的多边形几乎盖满了真凸包, 错的只是几个共线点附近的细节. 作者检查了 n=500 的错误样例, 大部分来自近似共线的点, 这正是经典凸包算法也头疼的退化情形.

area 指标贴着 100% 而 accuracy 随 n 衰减, 这两条的组合值得读两遍. 它说明模型学到的不是查表, 是某种「把外围点按角度排出来」的几何策略, 这个策略的精度随点数变密而下降, 但形状感一直在线. 一个 $O(n^2)$ 推理预算的 LSTM, 从 100 万条训练样本里学到了 $O(n \log n)$ 算法的近似版, 还能外推到训练长度 10 倍的输入. 2015 年, 这是一个相当反常的结果.

## 5. 实验二: Delaunay 三角剖分, 集合输出的预处理税

第二个任务和凸包直接相关: 一个点集的 Delaunay 三角剖分恰好把它的凸包内部三角化, 要求每个三角形的外接圆内不含其他点. 精确算法同样是 $O(n \log n)$.

这个任务的输出结构和前两个有本质区别: 它本质上是一个集合. 三角形之间的顺序无所谓, 每个三角形内部三个顶点的顺序也无所谓. 但 seq2seq 框架只认序列, 同一个正确答案有成千上万种等价的序列写法. 如果让模型自己去猜该按什么顺序输出, 监督信号会被这种一对多稀释掉.

作者的处理是人为规定 canonical 顺序: 三角形按内心坐标的字典序排列, 每个三角形内部按下标递增写. 论文明确记录, 不做这个预处理, 模型学得明显更差; 找一种让 Ptr-Net 更好利用的顺序, 被列为 future work.

这句话是整篇论文里埋得最深的一颗种子. 「同一个集合, 输出顺序影响学习难度」, 正是 Vinyals 下一篇论文的主题: 本站学习路线 `1.5.2` Order Matters, 标题就是这个观察本身. 两篇论文是同一项研究的上下半场, 路线 `1.5.1` 解决「输出从输入里挑」, 路线 `1.5.2` 解决「输入和输出的顺序怎么摆」.

结果上, n=5 时准确率 80.7%, 三角形覆盖率 93.0%; n=10 时准确率掉到 22.6%, 覆盖率 81.3%; n=50 时一个完全正确的剖分都画不出来, 但覆盖率还有 52.8%. 规律与凸包一致: 精确匹配随规模快速衰减, 局部结构 (单个三角形对不对) 的保持能力好得多. 模型学到的是局部的空外接圆规则的近似, 不是全局一致的剖分算法.

## 6. 实验三: TSP, 学生超过了老师

第三个任务是平面欧几里得对称 TSP, NP-hard, 用来测模型的能力上限. 训练数据分两类: n 不超过 20 时用 Held-Karp 算法 ($O(2^n n^2)$) 算精确解; n 更大时精确解算不起, 用三个近似算法生成的解当标签: A1 和 A2 是 $O(n^2)$ 的启发式, A3 是 $O(n^3)$ 的 Christofides 算法, 有保证的 1.5 近似比.

先看固定长度的结果, 表中数字是回路长度, 越短越好. n=5 时精确解 2.12, Ptr-Net 也是 2.12. n=10 时精确解 2.87, Ptr-Net 2.88, 只差 0.01. n=50 时没有精确解可训, 只能模仿近似算法. 用 A1 的数据训出来的 Ptr-Net 给出 6.42, 而被模仿的 A1 自己是 6.46. 用 A3 的数据训, Ptr-Net 给出 6.09, A3 自己是 5.79.

第一行那个对比是全文最值得圈出来的现象: **用最差的老师 (A1) 的数据训练, 学生考出了比老师更好的成绩**. 一个纯模仿的模型超过了它模仿的对象. 这在 2015 年几乎是悖论, 今天已经见怪不怪: 蒸馏和模仿学习里, 学生去掉了老师输出里的噪声和不一致, 拟合出的是「老师行为的平滑期望」, 而期望值常常比单次抽样更好. 但把这个现象第一次在组合优化上展示出来, 是这篇论文的功劳.

再看变长外推. 一个模型在 5 到 20 个城市的精确解上训练, 然后测更大的 n. n=5 和 n=10 完全命中精确解, n=20 给出 3.88 (精确解 3.83, Christofides 3.85). 从没见过的 n=25 给出 4.30, Christofides 4.24, 作者的原话是 virtually perfect. n=30 给出 4.72, 开始明显落后于 A3 的 4.60. n=40 和 n=50 分别给出 5.91 和 7.66, 对照 A3 的 5.23 和 5.79, 外推断裂.

对比凸包外推 10 倍依然体面, TSP 外推 1.25 到 1.5 倍就到头. 作者的解释朴素而准确: 两个问题背后的算法复杂度不是一个量级. 凸包的精确算法是 $O(n \log n)$, 局部决策多, 全局耦合少; TSP 的最优解涉及全局约束, 没见过的大规模实例上的决策模式在训练分布里根本没有对应物. 模型外推的边界, 画在被学算法本身的复杂度上.

还有一个工程细节: TSP 的 beam search 必须加合法性约束, 只搜索不重复城市的回路. 不加约束时, n 大于 20 的实例里至少 10% 会输出非法回路, 重复访问或者漏掉城市. 指针机制保证输出落在输入集合里, 但不保证输出是一个合法排列, 结构化约束还得靠解码时的搜索来兜. 这个「模型给分布, 搜索给约束」的分工, 后来在神经组合优化里成了标配.

## 7. 超参数与训练细节: 刻意的简陋

论文 4.1 节有一段话值得做研究的人抄下来: 作者没有做任何像样的架构或超参数搜索, 所有任务, 所有数据集, 用的是同一套配置. 单层 LSTM, 隐层 256 或 512, SGD 学习率 1.0, batch size 128, 权重在 -0.08 到 0.08 之间均匀初始化, L2 梯度裁剪阈值 2.0. 每个任务生成 100 万训练对, 小 n 的简单任务上还观察到了过拟合.

作者给出的理由: 同一套超参数打三个问题, 论文的主信息会更强. 这是一个关于「说服力来源」的判断: 如果每个任务都调出一套专属配置, 读者会怀疑效果来自调参而不是架构. 用一套「能跑就行」的配置拿到这些数字, 反过来证明架构本身的鲁棒.

这种克制在 2015 年的 Google Brain 并不稀奇, 同一时期的 seq2seq 和「学习执行」也是这个风格: 模型简单到近乎草率, 让结果自己说话. 对比今天动辄几十页消融实验的论文, 这篇的实验部分只有四页, 但每个数字都指向一个明确的论点: 固定词表输给变长词表, 基线输给指针, 老师输给用老师数据训练的学生.

## 8. 局限: 三笔账

第一笔是复杂度账. Ptr-Net 每步解码要对全部 n 个输入位置打分, 输出长度又是 $O(n)$ 量级, 推理总复杂度 $O(n^2)$. 对照凸包 $O(n \log n)$ 的精确算法, 模型在渐近意义上更贵, 精度还更低. 纯从解这三个问题看, 神经网络没有任何实用价值, 论文也不假装有. 它的价值在别处: 证明「学算法」这条路走得通, 以及给出一类输出结构的通用建模范式.

第二笔是外推账. 凸包外推 10 倍, TSP 外推 1.5 倍不到, Delaunay 在 n=50 已经画不出一个完整正确的剖分. 模型学到的是统计意义上的近似策略, 不是可证明正确的算法, 分布外的行为没有任何保证. 这个局限不是这篇论文能解决的, 它指向一个至今活跃的问题: 神经网络的算法泛化 (algorithmic generalization) 边界在哪.

第三笔是结构账. 指针只保证输出是输入的下标, 不保证排列合法, 不保证集合的 canonical 顺序, 不保证三角形不自交. 每多一层输出结构, 就要多一层解码约束或者数据预处理. Delaunay 的字典序预处理是人工的, TSP 的合法性靠 beam search 过滤, 这些都是补丁. 把结构约束内嵌到模型里, 是后来注意力机制继续演进的动力之一.

## 9. 在本站学习路线中的位置: attention 家族的第二条分支

把本站学习路线路线 `1.4.1`–`1.5.2`连起来看, 是一条清晰的演化线. 路线 `1.4.1` Bahdanau 发明 content-based attention, 分数用来加权混合. 路线 `1.5.1` Vinyals 证明分数可以直接当指针, 混合那步可以删. 路线 `1.4.2`、`1.4.3` Transformer 把 attention 变成唯一的计算单元, query-key-value 三分天下. 路线 `1.5.2` Order Matters 处理集合输入输出的顺序问题, 用的正是路线 `1.5.1` 埋下的种子. 路线 `1.5.6` Neural Turing Machines 的寻址机制, 则是「用分布当指针」在读写记忆上的另一个化身.

这条线往本站学习路线外延伸得更远. 2017 年 See 等人的 pointer-generator 把指针和生成词表并在一起, 摘要模型学会了「这个词从原文抄, 那个词自己写」, 成为抽取式生成的标准件. Transformer 的 copy 机制让大模型可以原样复述输入里的片段, 今天代码模型和检索增强生成里的「照抄」行为, 血统都能追溯到这篇. 神经组合优化方向, Bello 等人 2017 年用强化学习训 Ptr-Net 解 TSP, Kool 等人 2019 年把 LSTM 换成 attention 做出 AM 模型, 解码约束加指针输出的框架沿用至今.

所以这篇论文在本站学习路线里的角色不是「一个解几何问题的模型」, 而是一个观念的奠基: **softmax 的输出不必总是词, 也可以是位置**. 一旦输出被允许「指回输入」, 神经网络就从「生成器」扩展成了「选择器」, 而几乎所有带结构的预测问题, 都同时需要这两种能力.

- Dzmitry Bahdanau, Kyunghyun Cho, Yoshua Bengio, "Neural Machine Translation by Jointly Learning to Align and Translate", ICLR 2015. 本站学习路线 `1.4.1`, Ptr-Net 公式的直接来源, 对比两者公式里的 $d'_i$ 项即可看清改动.
- Ilya Sutskever, Oriol Vinyals, Quoc V. Le, "Sequence to Sequence Learning with Neural Networks", NIPS 2014. 本文的基线和骨架.
- Oriol Vinyals, Samy Bengio, Manjunath Kudlur, "Order Matters: Sequence to Sequence for Sets", ICLR 2016. 本站学习路线 `1.5.2`, 解决本文 Delaunay 实验暴露的顺序敏感问题.
- Alex Graves, Greg Wayne, Ivo Danihelka, "Neural Turing Machines", arXiv:1410.5401. 本站学习路线 `1.5.6`, 本文结论部分点名「指针思想同样适用于 NTM」.
- Abigail See, Peter J. Liu, Christopher D. Manning, "Get To The Point: Summarization with Pointer-Generator Networks", ACL 2017. 指针机制进入 NLP 主流的关键一步.
- Irwan Bello, Hieu Pham, Quoc V. Le, Mohammad Norouzi, Samy Bengio, "Neural Combinatorial Optimization with Reinforcement Learning", ICLR 2017 workshop. 用 RL 替代监督学习训练 Ptr-Net, 摆脱对精确解标签的依赖.
- Wouter Kool, Herke van Hoof, Max Welling, "Attention, Learn to Solve Routing Problems!", ICLR 2019. 把 Ptr-Net 的 LSTM 骨架换成 Transformer, 神经组合优化的现代基线.
- Richard Bellman, "Dynamic Programming Treatment of the Travelling Salesman Problem", JACM 1962. 本文生成精确 TSP 标签用的 Held-Karp 算法的原始出处.
