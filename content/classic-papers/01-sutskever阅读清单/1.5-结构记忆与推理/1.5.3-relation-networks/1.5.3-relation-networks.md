# A Simple Neural Network Module for Relational Reasoning: 一个不到 20 行的模块, 如何把 CLEVR 刷到超人水平

> Santoro et al., DeepMind, 2017, [arXiv:1706.01427](https://arxiv.org/abs/1706.01427)
> 本站学习路线 `1.5.3`, 属于「结构, 记忆与推理」一组, 前接 Pointer Networks (路线 `1.5.1`) 和 Order Matters (路线 `1.5.2`), 后通 Relational RNN (路线 `1.5.4`) 和 Neural Message Passing (路线 `1.5.5`).

全文只有一条公式 (带两个版本), 符号表放在最前面.

**全文符号表**

| 符号 | 含义 |
|------|------|
| $O = \{o_1, \dots, o_n\}$ | 对象集合, 每个对象一个向量, 集合无序 |
| $o_i$ | 第 $i$ 个对象的向量表示 |
| $n$ | 对象数量, 逐样本可变 |
| $g_\theta$ | 关系函数, 一个 MLP, 参数是 $\theta$: 吃两个对象, 吐出一个「关系向量」 |
| $f_\phi$ | 聚合函数, 另一个 MLP, 参数是 $\phi$: 吃所有关系的总和, 吐出最终答案 |
| $\theta, \phi$ | 两个 MLP 各自的可训练参数, 下标只用来区分归属 |
| $\sum_{i=1}^{n} \sum_{j=1}^{n}$ | 双重求和: $i$ 和 $j$ 各自遍历全部 $n$ 个对象, 枚举全部 $n^2$ 个有序对, 包括 $(o_i, o_i)$ 自配对 |
| $q$ | 问题经过 LSTM 编码后的最终隐状态 |
| $a$ | 最终输出, 比如一个答案 |
| $RN(O)$ | Relation Network 整体: 输入对象集合, 输出答案 |
| $X^T$ | 矩阵转置, 只出现在 §7 引用的 attention 公式里. **本文上标 $T$ 只有转置这一个含义** |

**读公式的方法**: 一条公式读三层. 内层 $g_\theta$ 逐对打分, 回答「这两个对象怎么相关」; 中层双重求和把 $n^2$ 个关系向量加成一团, 顺序不变性就来自这个加法; 外层 $f_\phi$ 把这团东西翻译成答案. 第二个版本和第一个的唯一差别: $g$ 的输入里多了一个 $q$, 关系计算被问题牵着走.

## 1. 背景: CLEVR 横扫了谁

2017 年初, 视觉问答 (Visual Question Answering, VQA) 这个领域处在一个微妙的位置. 主流数据集比如 VQA v1 已经被各种带注意力机制的模型刷得很高, 但慢慢有人发现问题不在模型, 在数据: 这些数据集有强烈的语言偏置. 问题问「图片里有几个人?」, 模型不看图, 直接按训练集里答案的频率分布回答「2」, 正确率就不差. 模型学到的是答题技巧, 不是视觉理解.

CLEVR 就是 Johnson 等人造出来堵这个漏洞的诊断数据集. 图片是 3D 渲染的简单几何体: 球, 立方体, 圆柱, 颜色, 材质, 大小各异, 摆在平面上. 问题由程序自动生成, 分成几类: 查询属性 (「那个球是什么颜色?」), 比较属性 (「立方体和圆柱是同一种材质吗?」), 计数 (「有多少个和绿色物体形状相同的物体?」), 存在性判断. 语言偏置被程序生成的方式控制住了, 剩下的全是硬骨头: 要答对, 必须真的把图像里每个物体认出来, 再推理它们之间的关系.

结果很尴尬. CLEVR 原论文里, 当时最强的架构是 ResNet-101 图像特征加 LSTM 问题编码, 再叠上堆叠注意力模块 (stacked attention), 总体准确率 68.5%, 人类是 92.6%. 更致命的是分项: 在 compare attribute 和 count 这类重度依赖对象间关系的问题上, 这个「最强模型」的表现和最朴素的 Q-type baseline (不看图, 只按问题类型猜答案) 几乎打平. 换句话说, 这些模型在关系推理题上等于没学.

这就是 Santoro 这篇论文出场时的战场: 不是某个榜单差几个点, 而是一整类问题, 整个领域的标准架构全部失效. 作者的判断很直接: 失败的原因不在视觉处理, 也不在语言解析, 在于这些架构里根本没有一个「为关系推理而生」的组件. CNN 的归纳偏置是平移不变性, RNN 的归纳偏置是序列依赖, 注意力是软寻址, 但没有任何一个模块的函数形式天生就在计算「对象与对象之间的关系」. 于是他们自己造了一个.

## 2. RN 模块的数学形式

Relation Network 的全部内容, 就是一个复合函数:

$$RN(O) = f_\phi\left(\sum_{i=1}^{n} \sum_{j=1}^{n} g_\theta(o_i, o_j)\right)$$

输入是一个对象集合 $O = \{o_1, o_2, ..., o_n\}$, 每个对象 $o_i$ 是一个向量. $g_\theta$ 是一个 MLP, 吃两个对象, 吐出一个向量, 论文把这个输出叫做一个「关系」: 它推断这两个对象以什么方式相关, 或者到底相不相关. 双重求和 $\sum_{i=1}^{n} \sum_{j=1}^{n}$ 枚举所有有序对象对: $i$ 和 $j$ 各自从 1 跑到 $n$, 一共 $n^2$ 对, 包括 $(o_i, o_i)$ 这种自配对, 且 $(o_1, o_2)$ 和 $(o_2, o_1)$ 算两对, 各进一次 $g$. $f_\phi$ 是另一个 MLP, 把所有关系的总和映射成最终输出, 比如一个答案. 代个数: $n = 3$ 个对象, 双重求和展开就是 9 项, $g(o_1,o_1) + g(o_1,o_2) + g(o_1,o_3) + g(o_2,o_1) + \cdots + g(o_3,o_3)$, 9 个关系向量加成一团, 再交给 $f$. 对象翻一倍, 求和项翻四倍, 这就是后文 $O(n^2)$ 代价的出处.

在问答任务里, 问题本身要参与关系计算: 问「大球」的时候, 小立方体之间的关系大概率无关紧要. 所以 RN 被改造成以问题为条件:

$$a = f_\phi\left(\sum_{i=1}^{n} \sum_{j=1}^{n} g_\theta(o_i, o_j, q)\right)$$

其中 $q$ 是问题经过 LSTM 编码后的最终隐状态, 拼接到每一个对象对上. 三个可学习组件就是 $g$, $f$ 和问题编码 LSTM, 全部端到端可微, 用标准反向传播训练.

这个公式值得多看两眼, 因为它的设计哲学全部藏在形式里. 第一, 求和强制枚举所有对象对, 用图论的话说, 输入被当作一张完全有向图, 节点是对象, 边是所有待考察的关系. 模型事先不知道哪些关系真的存在, 也不知道某个关系的语义, 它只能从数据里学出 $g$ 该对什么样的对象对产生什么样的响应. 第二, 求和让输出对输入对象的顺序不变: 集合乱序输入, 结果不变. 对象集合是无序的, 这个性质被架构直接保证, 不需要学. 第三, $g$ 和 $f$ 都是普通 MLP, 没有任何新奇的算子, 整个模块用 PyTorch 写出来大约 10 到 20 行代码. 作者把 simple 这个词放进标题, 是字面意思.

## 3. 设计哲学: 把归纳偏置烤进架构

论文第二节有一段话是全文的思想核心: RN 的设计哲学是「约束神经网络的函数形式, 让它捕获关系推理的核心共性」. 也就是说, 计算关系的能力被烤进 (baked into) 架构里, 不需要从数据中学出来, 正如 CNN 把平移不变的空间推理能力烤进卷积, RNN 把序列依赖烤进递归.

这个观点和 2017 年的主流风向是相反的. 当时深度学习的主流叙事是「端到端, 少偏置, 让数据说话」: 给足够多的数据和足够大的模型, 通用架构 (MLP, 加上一点注意力) 能学会一切, 手工归纳偏置是旧时代的残留. RN 论文用行动反驳了这一点: 在 CLEVR 这类数据量有限, 关系稀疏但复杂的任务上, 没有合适偏置的通用架构不是学得慢, 是根本学不会. Sort-of-CLEVR 实验 (见第 5 节) 把这个断言变成了定量证据.

当然, 偏置不是免费的. 完全图枚举意味着 $O(n^2)$ 的计算量, 而且「所有对象对都可能相关」这个假设在很多任务里是浪费: 画面里相距很远的两个物体, 大多数问题下确实无关. 论文在结尾自己指出了这条路: 如果知道某些对象对不可能相关, 可以跳过计算; 甚至可以用注意力机制过滤不重要的关系, 把二次复杂度压下来. 写下这句话几个月后, Attention Is All You Need 发表, self-attention 恰恰就是「学习哪些对象对值得计算关系」的通用机制. 这不是巧合, 是同一批人在同一个问题上的两条路线, 第 7 节再展开.

## 4. 数据效率与顺序不变性: 三个被低估的性质

论文列举了 RN 的三个优点: 学会推断关系, 数据高效, 以顺序不变的方式操作对象集合. 后两个经常被读论文的人跳过, 其实它们是 RN 能赢的工程原因.

数据效率的论证靠一个对比. 假设用一个大 MLP 直接吃全部 $n$ 个对象的拼接向量, 它要输出同样的关系推理结果. 由于 MLP 的输入位置是固定的, 第 1 个槽位和第 3 个槽位的关系, 与第 2 个槽位和第 5 个槽位的关系, 在权重空间里是完全不同的参数区域. 要覆盖所有对象配对, MLP 必须在权重里「嵌入 $n^2$ 份相同功能的函数」. 对象一多, 这立刻不可行. RN 的做法反过来: 把「学 $n^2$ 次关系函数」换成「对 $n^2$ 个对象对分别前向一次, 但关系函数只学一次」. 同一个 $g$ 作用在每一对对象上, 相当于 $n^2$ 个样本共享一套参数, 这鼓励 $g$ 学出泛化的关系计算, 而不是过拟合某一对特定对象. 用论文的话说, 计算成本的增加换来了参数效率的质变.

顺序不变性由求和保证. 这看起来是个小细节, 但它消除了一个巨大的虚假学习信号: 对象在输入里的排列顺序是任意的, 如果架构对顺序敏感, 模型就要浪费容量去学「顺序无关」这件事, 或者更糟, 学到对顺序的错误依赖. 这一点和本站学习路线 `1.5.2` Order Matters 遥相呼应: Vinyals 等人证明, 即使理论上顺序不该影响结果, seq2seq 模型对输入顺序依然敏感, 需要 read-process-write 结构来缓解. RN 的做法更激进: 不求模型学会顺序不变, 直接用求和从结构上保证它. 同一个问题, 路线 `1.5.2` 用训练技巧缓解, 路线 `1.5.3` 用架构消除, 这两篇放在一起读, 能看出 DeepMind 和 Google Brain 对「集合输入」的两种解法.

## 5. 四个战场

论文的实验设计非常干脆: 同一个 RN 模块, 插进四个不同领域的任务, 不做任务特化的魔改. 视觉问答, 文本问答, 物理系统推理, 外加一个受控诊断数据集. 每个战场回答一个不同的问题.

### 5.1 CLEVR from pixels: 95.5%, 超人

主战场是 CLEVR 的像素版本. 架构是标准的三件套: 4 层 CNN (每层 24 个卷积核) 把 128x128 的图像卷成特征图, LSTM (128 单元) 编码问题, RN 做推理. 关键设计是「对象从哪来」: 作者刻意不指定什么是对象, 直接把 CNN 最后一层特征图里每个 $d \times d$ 空间位置的 $k$ 维特征向量, 拼上一个坐标 tag, 当成一个对象. 一个「对象」可能是背景, 可能是某个几何体, 可能是纹理, 可能是几个物体的合取, 语义完全交给学习过程自己决定. 这是全文最反直觉也最重要的一步: RN 不需要上游给出干净的对象分割, 它能诱导 (induce) 上游的 CNN 学出「对关系推理有用」的类对象表示.

训练细节: $g$ 是四层 MLP, 每层 256 单元; $f$ 是三层 MLP (256, 256 带 50% dropout, 29 输出); Adam 优化器, 学习率 2.5e-4, batch size 64, 10 个 worker 同步训练. 没有花哨的技巧.

结果: 总体 95.5%, 超过人类的 92.6%. 对比基线: CLEVR 原论文的最强模型 (ResNet-101 + LSTM + 堆叠注意力) 68.5%, 作者自己调优复现的版本 76.6%. 也就是说, 同一个 CNN 加 LSTM 的骨架, 只把后面的注意力换成 RN, 准确率从 76.6% 跳到 95.5%, 涨了将近 19 个点. 分项更能说明问题: compare attribute 97.1%, count 90.1%, 正是当年所有模型集体崩盘的两类题. 还有一个细节: 同期有工作 (Hu 等人的 FiLM 前身思路, 用 ground-truth 程序做额外监督) 报到 96.9%, 但那是用了生成问题的功能程序做监督信号; RN 不用任何特权信息, 且大幅超过对方不用特权信息的版本.

另一个实验常被忽略: 把输入换成 state description (直接给出每个物体的坐标, 颜色, 形状, 材质, 大小的矩阵, 跳过视觉处理), 准确率 96.4%. 这个数字证明 RN 对输入形式不敏感: 给它像素, 它从像素里诱导出对象; 直接给它对象, 它照样推理. 模块和前端是解耦的.

### 5.2 Sort-of-CLEVR: CNN+MLP 全面落败

CLEVR 的胜利有一个漏洞: 题目没有按「关系程度」分类, 没法直接证明瓶颈就是关系推理. 所以作者自己造了 Sort-of-CLEVR, 一个刻意简化的受控数据集: 每张图 6 个二维色块 (圆或方, 6 种颜色), 问题硬编码成定长二进制串, 排除语言解析的干扰. 每张图配 10 个关系问题 (「离灰色物体最远的物体是什么形状?」) 和 10 个非关系问题 (「灰色物体是什么形状?」).

结果干净利落: CNN+RN 在两类问题上都超过 94%. CNN+MLP (参数量可比) 在非关系问题上也能达标, 但在关系问题上封顶 63%, 怎么训都上不去. 最狠的一个子类: closest-to / furthest-from 类问题, 模型需要估计所有对象间的距离再两两比较, CNN+MLP 只有 52.3%, 接近乱猜.

这组实验把第 3 节的哲学判断变成了硬数据: 在视觉和语言都被简化到极致之后, 通用架构依然在「最简单的关系推理」上失效, 而加一个不到 20 行的模块就立刻解锁. 关系推理能力不是模型规模的函数, 是架构函数形式的函数. 论文原文的措辞值得引用: 缺少专用关系组件的模型 struggle, or may even be completely incapable of solving tasks that require very simple relational reasoning.

### 5.3 bAbI: 18/20, 没有一场惨败

bAbI 是纯文本推理基准, 20 个任务, 覆盖演绎, 归纳, 计数等推理类型, 每个任务 1 万样本, 联合训练, 单任务准确率过 95% 算通过. 当时的成绩单: Memory Networks 14/20, DNC 18/20, Sparse DNC 19/20 (但最好超参下波动超过 ±3 个任务), EntNet 联合训练 16/20.

RN 的做法是把「句子」当对象: 取问题之前的至多 20 个支持句, 每句过一个共享 LSTM, 最终隐状态就是一个对象, 问题编码拼进对象对, 交给 RN. 注意这相比此前的模型 (把所有句子所有词串成一条序列顺序处理) 注入了一点先验: 句子级切分. 结果是 18/20 通过, 与 DNC 持平, 但有两个额外亮点. 第一, basic induction 任务, RN 总错误率 2.1%, 而 Sparse DNC 54%, DNC 55.1%, EntNet 52.1%, 这个任务让记忆增强网络集体翻车, RN 几乎零失误. 第二, 稳定性: RN 没有任何灾难性失败, 未通过的两个任务 (two/three supporting facts) 分别只差 3.1% 和 11.5%, 而且是单种子单次训练的结果, 没有挑超参. Sparse DNC 的 19/20 是多次运行里挑出来的.

### 5.4 动态物理系统: 从 MuJoCo 到人体动捕

最后一个战场换了一个完全不同的模态. 用 MuJoCo 物理引擎模拟桌面上的 10 个彩色小球, 部分球之间用看不见的弹簧或刚性约束连接. 输入是 16 个时间步的状态矩阵 (每个球的颜色和坐标). 两个任务: 推断任意两球之间是否存在连接; 数出桌面上有几个连通系统.

两个任务都要求模型从相对位置和速度的历史里推断隐藏的关系结构, 比如两球距离持续稳定, 说明之间有约束. RN 在连接推断上 93% 的场景全部判断正确, 计数任务 95% 的场景报对. 参数量可比的 MLP 两个任务都停留在随机水平. 论文还顺手做了一个迁移实验: 在弹簧系统上学出的关系推断能力, 能迁移到没见过的动作捕捉数据上, 预测行走人体关节之间的连接. 这个实验规模不大, 但它暗示了 RN 学到的是某种与领域无关的「关系检测器」.

## 6. 为什么 CNN+MLP 学不会关系

把四个战场合起来看, 一个模式反复出现: CNN+MLP 在所有非关系任务上表现正常, 在所有关系任务上崩盘或接近随机. 原因可以拆成三层.

第一层是函数形式. 如第 4 节分析的, MLP 的固定输入槽位让「关系函数」必须在权重里复制 $n^2$ 份, 数据量撑不起这种参数需求. 这是容量和参数共享问题.

第二层是归纳偏置缺失. CNN 的卷积核只看局部感受野, 两个相距遥远的物体的关系, 要靠很多层堆叠才能进入同一个神经元的视野, 而「比较两个任意位置物体的属性」这种操作, 没有任何一层是为它设计的. 堆叠注意力试图补救, 但注意力是软的, 加权的, 它擅长「选一个区域看」, 不擅长「枚举所有对并做对称的比较运算」. CLEVR 上 CNN+LSTM+SA 在 compare attribute 上 53.0%, 和 Q-type baseline 的 51.3% 几乎一样, 就是证据.

第三层更微妙, 是论文 Discussion 里点出的: processing 和 reasoning 是两件事. ResNet 这类架构是强大的视觉处理器, 但处理能力强不代表推理结构对. 把 RN 插进去之后, CNN 被解放出来专注做局部空间特征提取, 关系计算全部交给 RN. 分工之后两边都轻松. 这个「感知-推理分工」的观点, 后来成了神经符号系统, 以及各类「感知前端 + 推理后端」架构的标准叙事.

## 7. 代价: O(n^2) 与 self-attention 的血缘

RN 不是万能药, 它的代价写在公式里: 完全图枚举, 对象数 $n$, 计算量 $O(n^2)$. CLEVR 里对象来自特征图格子, $d \times d$ 个, 平方之后还能扛; 但如果对象是长文本里的 token 或者高分辨率图像的 patch, 二次方就是硬伤.

论文结尾给出的方向非常具体: 如果预先知道某些对象对不可能相关, 跳过它们; 更一般地, 用 attentional mechanisms 过滤不重要的关系, 给二次复杂度设一个上界. 这句话值得停顿. RN 是全连接的, 无差别的对象对关系计算; self-attention 是带学习权重的对象对关系计算, $softmax(QK^T/\sqrt{d})V$ 就是学一个软的门控, 决定哪些对象对的关系值得聚合. 两者的计算图都是 $O(n^2)$ 的对象对打分加聚合, 区别只在于 RN 的门控是恒等的 (全部求和), attention 的门控是学出来的. 说 self-attention 是「可学习稀疏化的 RN」, 或者 RN 是「均匀权重的 attention」, 都不算牵强.

当然差异也真实存在. attention 的聚合是按 value 加权, RN 的聚合是对关系向量求和; attention 每对关系是一个标量权重, RN 的 $g$ 输出的是一个向量, 表达能力更富; RN 明确以问题为条件, attention 的条件化通过 query 实现. 但骨架是同一个: 对象集合, 两两交互, 聚合输出. 这也解释了为什么 RN 的思想没有消失: 它换了个名字活在 Transformer 里, 活在 GNN 的消息传递里, 活在路线 `1.5.5` Neural Message Passing 里.

血缘的另一头是 Interaction Networks (Battaglia et al., 2016). 论文明确承认 RN 与之相关, 区别是 Interaction Networks 需要显式给出哪些对象对有交互 (图的边列表), 用于物理模拟; RN 假设完全图, 不需要任何关系先验, 面向「哪些关系存在都要学」的推理任务. 一年后, 同一批人 (Santoro, Battaglia 都在作者列表里) 发表 Relational RNN, 把 RN 的思想和多 Head attention 缝进记忆矩阵, 这就是本站学习路线 `1.5.4`. 再往后, Battaglia 的 Graph Networks 综述把 RN, Interaction Networks, Message Passing 全部统一进一个框架. 路线 `1.5.3` 是这条线的枢纽.

## 8. 在 本站学习路线中的位置

本站把路线 `1.5.1` 到 `1.5.6` 归入「结构、记忆与推理」主题组. 这六篇讲同一个故事的不同章节: 神经网络如何从「统计拟合机器」长出「结构化推理」的能力.

路线 `1.5.1` Pointer Networks 用注意力当指针, 解决输出是输入子集的组合问题 (凸包, TSP), 是「结构化输出」的开端. 路线 `1.5.2` Order Matters 处理集合输入的顺序敏感性, 提出 read-process-write. 路线 `1.5.3` RN 直面推理本身: 对象集合上的关系计算该长什么样, 给出的答案是最小化的, 一个求和, 两个 MLP. 路线 `1.5.4` Relational RNN 把这种关系计算装进循环记忆, 让推理跨时间步持续进行. 路线 `1.5.5` Neural Message Passing 把对象-关系结构推广到任意图, 用在量子化学的分子性质预测上, 是 GNN 的奠基文献之一. 路线 `1.5.6` Neural Turing Machines 则是另一条路: 给网络外挂可微记忆.

RN 在这一组里的角色是「最少假设的那个」. Pointer Networks 假设问题是组合优化, NTM 假设需要外部记忆, MPNN 假设图结构已知. RN 只说一件事: 不管你的输入是什么, 只要能切成对象, 关系推理就是「枚举所有对, 共享一个函数, 求和聚合」. 这种极简主义是它能被插进 CNN, LSTM, 物理模拟器, 乃至后来被吸收进 Transformer 的原因. 模块越小, 寄生能力越强.

对今天的从业者, 这篇论文的价值不在复现 CLEVR (96.9% 的 FiLM 和后来一票模型早就超过了), 而在三个仍然成立的判断. 第一, 归纳偏置在数据有限, 结构稀疏的任务上依然决定成败, 「大模型加大数据解决一切」是有适用边界的. 第二, 感知和推理的模块化分工没有过时, 今天多模态模型里 vision encoder 加 LLM 的架构, 就是 CNN+RN 分工的放大版. 第三, 对象这个概念是可诱导的: 不需要手工分割, 模型能在监督信号下自己学出「对推理有用的对象表示」, 这和今天 object-centric learning, slot attention 一整条研究线直接相连.

## 9. 扩展阅读与后续影响

- Johnson et al., 2017, CLEVR: A Diagnostic Dataset for Compositional Language and Elementary Visual Reasoning. RN 的靶子, 理解 CLEVR 的偏置控制设计才能理解 RN 赢在哪.
- Battaglia et al., 2016, Interaction Networks for Learning about Objects, Relations and Physics. RN 的直接前身, 显式关系列表的物理模拟.
- Santoro et al., 2018, Relational Recurrent Neural Networks. 本站学习路线 `1.5.4`, RN 思想的时间序列化.
- Gilmer et al., 2017, Neural Message Passing for Quantum Chemistry. 本站学习路线 `1.5.5`, 关系计算在图上的推广.
- Battaglia et al., 2018, Relational inductive biases, deep learning, and graph networks. DeepMind 的立场文件, 把 RN 放进「关系归纳偏置」的完整谱系, 可当作本帖的加长版延伸阅读.
- Vaswani et al., 2017, Attention Is All You Need. 本站学习路线 `1.4.2`. 对照阅读: RN 的均匀全连接求和 vs self-attention 的学习权重聚合, 同一骨架的两种参数化.
- Hudson & Manning, 2018, Compositional Attention Networks (MAC). CLEVR 上另一类路线, 用循环的注意力单元逼近推理过程, 与 RN 的「一步到位求和」形成对照.
- Locatello et al., 2020, Object-Centric Learning with Slot Attention. 「对象可诱导」思想的现代延续.

一句话总结这篇论文: 它没有发明新的学习算法, 没有提出新的理论, 只是指出了一个被整个领域忽略的空白, 并用一个求和填上了它. 2017 年所有人都在争论注意力该怎么堆, 这篇论文说, 先把所有对象对枚举一遍再说. 有时暴力本身, 就是归纳偏置.
