# RNN 与序列建模

RNN 的核心问题是**怎么让网络记住历史**。LSTM 用门控机制解决了梯度消失,但代价是串行计算——每一步必须等上一步算完。Transformer 后来用 Attention 绕开了这个瓶颈,但**理解 RNN 的局限性是理解 Transformer 为什么必要的前提**。读完这三篇,应该能讲清楚:固定长度隐状态丢了什么信息,门控怎么缓解梯度消失,以及串行依赖为什么限制了训练吞吐。

三篇材料分别回答「循环网络能做什么」「LSTM 为什么更能记」「怎样正则化而不破坏记忆路径」.这是一条本站设计的现象—机制—训练路线.

## 序列模型保存的到底是什么

前馈网络把输入映射为输出,没有跨样本持续更新的状态.RNN 在时间步 $t$ 接收输入 $x_t$ 和上一状态 $h_{t-1}$,计算 $h_t=f(W_xx_t+W_hh_{t-1}+b)$.同一组参数沿时间复用,因此可以处理不同长度的序列.状态 $h_t$ 是截至当前位置的压缩摘要;生成时,输出分布又决定下一个符号,新符号随后作为输入回到循环中.

Karpathy 的字符级实验把这种机制展示得很直接.模型只优化下一个字符的交叉熵,却能逐渐学到括号配对,缩进,词形和局部语法.这些样本说明递归状态能够保存多尺度统计规律,但不能单独证明模型形成了人类式语法表示.同一模型在训练分布之外容易失去结构,采样温度也会显著改变输出.阅读生成样例时应同时看训练数据规模,隐藏维度和采样策略.

## 梯度为何难以跨越很多时间步

反向传播穿过时间展开图时,梯度包含许多 Jacobian 的连乘.若谱范数长期小于 1,早期输入的影响指数衰减;长期大于 1,梯度可能爆炸.梯度裁剪可以限制爆炸,却不能恢复已经消失的依赖.普通 RNN 因此更容易学习局部模式,很难稳定保存几十或几百步以前的一条信息.

LSTM 增加 cell state $C_t$ 和三类门.遗忘门 $f_t$ 决定旧状态保留多少,输入门 $i_t$ 与候选值 $\tilde C_t$ 决定写入什么,输出门 $o_t$ 决定当前暴露多少.核心更新

$$C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t$$

把状态传播从反复非线性变换改为带门控的加法路径.当 $f_t$ 接近 1 且写入较小时,梯度可以沿 cell state 近似恒等传播.门控缓解长程优化困难,但没有让记忆无限:状态维度仍固定,门值也可能在训练中饱和.

## 状态路径与计算路径

多层 LSTM 同时存在两类边.水平循环边从 $(h_{t-1},C_{t-1})$ 通向下一时间步,承担记忆;垂直边把当前时刻的表示送往更高层和输出,承担层间计算.把普通 dropout 独立施加到每条循环边会让同一信息在时间上反复乘随机掩码,有效信号随序列长度衰减.Zaremba 等人的方案只在非循环连接上加 dropout,让一条跨时间记忆路径受到的扰动次数取决于层数,而非序列长度.

这项设计展示了一种通用分析方法:先画展开后的计算图,再判断正则化作用在哪条边.「给 RNN 加 dropout」过于笼统;输入到隐藏,层间,隐藏到输出,循环状态和门参数受到的影响不同.后续 variational dropout 让时间步共享同一掩码,也正是在改变噪声沿时间传播的方式.

## 从循环状态走向动态读取

RNN 的训练和推理都具有严格的时间依赖:$h_t$ 未产生前不能计算 $h_{t+1}$.GPU 可以并行 batch 和矩阵内部运算,却不能同时完成同一序列的全部时间步.序列越长,关键路径越长.此外,编码器把整段输入压进固定维度状态,源序列增长时形成容量瓶颈.

下一组的 Bahdanau Attention 保留循环解码器,但让每一步重新读取全部编码器状态,先解决固定向量瓶颈.Transformer 再移除循环主干,把位置之间的交互改成可并行矩阵运算.因此 RNN,LSTM 和 Attention 之间不是简单的旧模型被新模型淘汰:前者定义了状态递推与门控记忆问题,后者改写了信息访问和计算调度方式.在线流式任务仍可能偏好固定状态递推,而需要任意位置交互的任务常选择注意力.

## 手算一条记忆路径

忽略输入写入项,设某个 cell 维度连续三步的遗忘门分别为 $0.9,0.8,0.95$.早期状态对三步后状态的直接贡献系数是 $0.9\times0.8\times0.95=0.684$.若十步遗忘门都为 0.9,系数约为 0.349;若都为 0.5,十步后只剩约 0.001.门控没有取消连乘,而是让模型能把关键维度的系数主动推近 1.这也解释了常见的遗忘门偏置初始化:训练初期先给长记忆路径更大的保留概率.

普通 tanh RNN 的对应系数还要乘权重矩阵和每一步 tanh 导数,后者最大为 1,饱和区接近 0.LSTM 的 cell state 把主要记忆路径从矩阵与非线性的反复连乘中分离出来,但 $h_t=o_t\odot\tanh(C_t)$ 仍控制状态如何暴露给下一层和输出.

## 训练与推理的不同瓶颈

训练时,长度相同的 batch 可以并行处理多个序列,每个时间步内部也能做大矩阵乘,但同一序列的时间步必须依次推进.反向传播还需保存或重算展开图,激活内存随长度增加.推理时若模型流式接收输入,只保留当前状态即可,内存固定;这恰好是 RNN 相对全历史 attention 的优势.

语言生成中,Transformer 也要逐 token 解码,因此「RNN 串行,Transformer 并行」主要描述训练和已知整段输入的编码过程.公平比较还要看 KV cache 的线性增长,RNN 固定状态的信息损失,每步 FLOPs 和硬件利用率.同一个复杂度符号可能掩盖完全不同的数据流.

## 实验应该证明哪一层结论

字符样本证明模型学到训练分布中的可生成规律;长依赖任务检验状态能否携带特定信息;语言模型困惑度衡量预测分布;消融 dropout 位置检验噪声进入哪条路径.四类证据回答不同问题.一段看起来像代码的生成文本很有展示效果,却不能替代困惑度和外推实验;困惑度改善也不能说明具体记忆维度对应某条人类可解释规则.

读这组材料时可画一张时间展开图,在每条边标出 shape,参数是否共享,是否加噪声,梯度要经过多少次.只要这张图清楚,LSTM 门控,循环 dropout 和 attention 的差别就会落到可计算路径上.

最后再检查状态的语义:训练损失只约束输出预测,并不保证某个隐藏维度稳定表示人类命名的概念.探针或可视化可以提出解释,扰动状态并观察输出才更接近因果证据.把性能,记忆能力和可解释性分开评测,能避免从漂亮样本直接跳到过强结论.

三个层面都清楚以后,再看 GRU,QRNN 或现代状态空间模型,就能准确比较它们保留了哪条递推路径,删掉了哪些门,训练时能并行到什么程度,以及固定状态对历史信息施加了怎样的压缩.
