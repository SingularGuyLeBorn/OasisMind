# 复杂度、信息论与智能

这一组先建立后续文章反复使用的语言：什么是结构，什么是随机，什么叫压缩，以及这些概念怎样进入学习与智能的定义。编号是本站教学顺序，不是社区重建版本的原始排列。

## 阅读顺序

1. [`1.1.1` The First Law of Complexodynamics](1.1.1-first-law-of-complexodynamics/1.1.1-first-law-of-complexodynamics.md)：提出“复杂度先升后降”的问题。
2. [`1.1.2` Coffee Automaton](1.1.2-coffee-automaton/1.1.2-coffee-automaton.md)：用封闭系统实验检验复杂度度量。
3. [`1.1.3` Minimum Description Length](1.1.3-minimum-description-length/1.1.3-minimum-description-length.md)：把“结构 + 残差”转成模型选择原则。
4. [`1.1.4` Machine Super Intelligence](1.1.4-machine-super-intelligence/1.1.4-machine-super-intelligence.md)：讨论机器智能的形式化边界。
5. [`1.1.5` Kolmogorov Complexity](1.1.5-kolmogorov-complexity/1.1.5-kolmogorov-complexity.md)：系统补全算法信息论基础。

读完后应能区分 Shannon 熵、Kolmogorov 复杂度、sophistication 与 MDL，避免把“更随机”误写成“更复杂”。
