# A Tutorial Introduction to the Minimum Description Length Principle: 把奥卡姆剃刀翻译成 bit

> 原始论文: Peter Grunwald, "A Tutorial Introduction to the Minimum Description Length Principle", arXiv:math/0406077 (2004), 收录于 Advances in Minimum Description Length: Theory and Applications (MIT Press, 2005), 是该书的前两章.
> https://arxiv.org/abs/math/0406077
> 这是本站学习路线 `1.1.3`. 前两篇 (Aaronson 的复杂度第一定律和 Coffee Automaton) 用 Kolmogorov 复杂度和 sophistication 回答「有趣的东西长什么样」, 答案是「结构加残差」的两段分解. 本篇把同一个思想工程化: 在统计学习里, 结构叫模型, 残差叫噪声, 两段分解的总长度就是选择模型的唯一准则. 它是 MDL 领域的标准入门教程, 也是理解「学习即压缩」这条线最系统的一份材料.

**全文符号表** (每个符号第一次出现时正文会再讲一遍, 这里先汇总):

| 符号 | 含义 |
|---|---|
| $D$ | 观测数据; 写成序列时是 $x^n = (x_1, x_2, \dots, x_n)$, 即 $n$ 个观测按顺序排成的串 |
| $\mathcal{X}^n$ | 所有长度为 $n$ 的可能序列组成的集合; $\sum_{x^n \in \mathcal{X}^n}$ 就是遍历每一条可能的数据 |
| $H$ | 假设: 单个概率分布或单个函数 (点假设) |
| $M$ | 模型: 同函数形式的一族分布 (复合假设), 比如「所有二次多项式」 |
| $P(\cdot)$, $\bar{P}(\cdot)$ | 概率分布; 顶上一横的 $\bar{P}$ 表示「通用码对应的分布」, 本身也是一个合法概率分布 |
| $\mid$ | 竖线读作「在...的条件下」: $P(D \mid H)$ 是假设 $H$ 之下数据 $D$ 的概率 (似然) |
| $L(\cdot)$ | 码长函数, 单位 bit; 核心等式是 $L(x) = -\log P(x)$, 概率越大码越短 |
| $\theta$ | 模型的参数; $\hat{\theta}(x^n)$ 是用数据 $x^n$ 算出来的最大似然估计, 注意它依赖于数据 |
| $k$ | 模型的参数个数 |
| $I(\theta)$ | Fisher 信息矩阵, 衡量参数在数据里「可分辨」的程度; $|I(\theta)|$ 是它的行列式 |
| $w(\theta)$, $W(\theta)$ | 先验密度; Jeffreys 先验是 $w(\theta) \propto \sqrt{|I(\theta)|}$ |
| $\mathrm{COMP}_n(M)$ | 参数复杂度: 样本量 $n$ 时模型 $M$ 的「富有程度」, 单位 bit |
| $\hat{P}_{nml}$  /  $\bar{P}_{nml}$ | 归一化最大似然 (NML) 分布, 本文统一写 $\bar{P}_{nml}$ |
| $\log$ | 全文以 2 为底 (码长按 bit 计), 个别地方注明 $\ln$ 才是自然对数 |
| $\lceil u \rceil$ | 向上取整: 不小于 $u$ 的最小整数 |
| $o(1)$ | 小 o 记号: 随 $n$ 增大趋于 0 的量 |
| $\min_{H} f(H)$ | 在所有候选 $H$ 里取 $f(H)$ 的最小值 |

**读公式的方法.** 本文的公式全是「码长」, 读每条只问两个问题: 编码的对象是什么 (假设本身, 还是给定假设后的数据), 用的码是哪一款 (两段码, 贝叶斯混合码, 还是 NML 码). 所有公式共享一个换算: 概率取负对数就是码长, 所以 $\log$ 一出现, 就把它当成「这件事要花多少 bit 说出来」.

## 1. 从 Solomonoff 到 Rissanen: 一条四十年的线

MDL 的思想源头是算法信息论. 1964 年 Solomonoff 发表 A Theory of Inductive Inference, 他是科学哲学家 Carnap 的学生, 目标很直接: 给归纳推理一个形式理论. 他的核心提议是, 一个数据序列的「终极模型」可以等同于打印这个序列的最短程序. 1965 年 Kolmogorov, 1969 年 Chaitin 独立提出了同一个复杂度概念, 并证明了不变性定理: 任何两种通用编程语言下, 最短程序长度只差一个不依赖于数据的常数.

把 Solomonoff 的方案直接拿来用, 叫理想 MDL (ideal MDL). 它有两个致命问题. 第一是不可计算: 不存在一个程序, 能对任意数据 D 返回打印 D 的最短程序, 这是停机问题的直接推论. 第二是句法任意性: 不变性定理只保证差一个常数, 而实践中面对的是小样本, 常数项就是全部, 选哪种编程语言会直接影响选出来的假设.

另一条平行的线在澳大利亚. Wallace 和 Boulton 1968 年提出 MML (Minimum Message Length), 比 Rissanen 的第一篇 MDL 早十年, 而且 Wallace 当时完全没听说过 Kolmogorov 复杂度. Rissanen 本人的灵感来自两个方向: Kolmogorov 1965 年的论文, 和 Akaike 1973 年的 AIC, 后者是第一个基于信息论的模型选择方法, 但哲学和做法都与后来的 MDL 差别很大.

Rissanen 的发展是一条漫长的工程化路线. 1978 年第一篇论文只有两段码. 1984 年引入 prequential 码, 1986 和 1987 年提出 stochastic complexity 并把贝叶斯混合码纳入 MDL. 关键的最后一步在 1996 年: 他把 stochastic complexity 接到 Shtarkov 1987 年提出的归一化最大似然 (NML) 码上, 参数复杂度 (parametric complexity) 的概念才真正成型. Barron 1985 年的博士论文证明了两段码 MDL 的频率派一致性, Barron 和 Cover 1991 年进一步给出码设计与收敛速率的精确关系, 并在很多情形下达到 minimax 最优. 1998 年 Barron, Rissanen, Yu 三人的综述把这套理论定型, 就是今天说的 refined MDL. Grunwald 这篇 2004 年的教程, 是这条四十年路线的标准入口.

## 2. 问题定义: 模型选择与过拟合

MDL 解决的核心问题是模型选择: 给定有限观测, 如何在相互竞争的解释之间做取舍. 教程用的例子是多项式拟合. 给平面上 n 个点, 想学习 y 对 x 的依赖关系. 直线回归欠拟合, 抓不住数据里的规律. 但数学上, 对任意 n 个点都存在一个 n-1 次多项式精确穿过所有点, 按「误差最小」选模型就会选中它. 这种多项式拟合的是随机涨落而不是底层模式, 换一批同源数据测试, 误差大到没法看. 这就是过拟合.

直觉上正确的选择介于两者之间: 一个相当简单但误差非零的多项式, 比如教程图里的三次曲线. 所有实用的模型选择方法都在显式或隐式地做这种权衡, MDL 提供的是一种特定的实现方式: 用 bit 给权衡的两端标同一个单位.

这里要先分清两个词. 点假设 (point hypothesis) 是单个概率分布或单个函数, 比如多项式 $5x^2 + 4x + 3$. 模型 (model) 是同函数形式的一族分布, 比如所有二次多项式的集合, 统计文献里也叫复合假设. 模型选择关心的是选族, 参数估计是族内挑点.

## 3. 学习就是压缩: 三条序列

教程的开篇例子是三条 10000 bit 的序列, 它们把整个 MDL 的直觉讲完了.

第一条是 0001 重复 2500 次. 一眼看出规律, 写一个 for 循环几十字节就打印出来, 压缩到 $O(\log n)$ bit. 第二条是公平硬币扔 10000 次的结果. 找不到任何规律, 最短程序就是把序列本身打印出来, 长度约等于序列本身, 不可压缩. 第三条里 0 的数量约是 1 的四倍. 规律是统计性的而非确定性的, 用一个偏向 0 的硬币模型编码, 可以压到 $\alpha n$ bit, 其中 $0 < \alpha < 1$, 省掉线性比例的 bit.

三条序列并排, 下方各标注压缩结果: $O(\log n)$, 不可压缩, $\alpha n$. 规律越多, 压缩越多.

这就是 MDL 的基本等式: 数据里的任何规律都可以用来压缩数据, 规律越多压缩越多. 把「学习」等同于「找规律」, 就得到 Rissanen 的核心主张: 学得越多 = 压得越短. 教程还给了三个佐证. $\pi$ 的前 n 位可以用一个常数大小的级数程序生成, 确定性规律意味着极致压缩. 物理实验里落体高度与时间表, 先描述牛顿定律的二次多项式系数, 再描述各点对多项式的偏离, 远比直接记录数据短. 自然语言文本, 先描述语法, 再在语法约束下描述文本, 同样能省大量 bit.

## 4. 概率就是码长: Kraft 不等式

要把「压缩」变成可计算的准则, 需要信息论的两块基石. 第一是码与概率的对应. MDL 只用前缀码 (prefix code), 即没有任何码字是另一个码字的前缀, 这样码字拼接后无需分隔符就能唯一解码. Kraft 不等式的直接推论是: 对任意概率分布 $P$, 存在码长为 $L(x) = -\log P(x)$ 的前缀码; 反过来, 任意前缀码的码长函数都对应一个 (可能亏损的) 概率分布. 大概率意味着短码长, 小概率意味着长码长. 由此 Shannon-Fano 码成为唯一合理的选择: 给定假设 $H$, 数据的码长就是负对数似然 $-\log P(D|H)$.

第二是计数论证, 它决定了压缩的极限. n bit 的序列有 $2^n$ 种, 长度不超过 m 的码字至多 $2^{m+1}$ 个, 所以能被压缩超过 k bit 的序列占比至多 $2^{-k}$, 随 k 指数衰减. 对公平硬币产生的数据, 能压缩超过 20 bit 的概率不到百万分之一. 注意一个陷阱: 数据到手之后, 总能设计一个码把这条序列编成 1 bit. 但在看到数据之前定好的码, 对随机数据几乎必然无能为力. 压缩等价于把数据识别为某个先验极小的特殊子集.

还有信息不等式: 若数据真的按分布 $P$ 产生, 码长 $-\log P$ 在所有码中期望最优, 大数定律保证大样本下实际码长也最优. 这条不等式说明, 用概率分布当编码工具不需要假设数据真的来自这个分布, 分布只是码长的载体.

## 5. 粗糙两段码 MDL 与它的死穴

最早的两段码 MDL 准则很直白: 在所有候选假设里, 选使下式最小的那个:

$$
\min_{H} \; L(H) + L(D \mid H)
$$

逐块拆解. $\min_{H}$ 读作「在所有候选假设 $H$ 里, 找出让后面这个总和最小的那个」. 总和分两段. $L(H)$ 是假设自身的描述长度: 模型越复杂, 把它的参数一个个说清楚需要的 bit 越多. $L(D \mid H)$ 是借助假设编码数据的长度: 假设拟合得越好, 数据里剩下需要额外交代的残差越少. 两段此消彼长, 最小值自动落在「相当简单, 拟合相当好」的位置. 这就是奥卡姆剃刀的 bit 版: 不是偏好简单, 是偏好「假设自己的说明书 + 数据的残差说明书」总长最短.

$L(D|H) = -\log P(D|H)$ 是唯一站得住的选择. 教程给了一个反证: 若用别的码长, 存在两个分布 $H, H'$ 使码长关系颠倒, 那么即使数据真的由 $H$ 产生, 大样本下 MDL 也会永远选 $H'$, 连有限模型这种最简单情形下的一致性都保不住.

死穴在 $L(H)$. 同一个假设, 换一套编码, 描述长度可以天差地别, 选出来的模型就跟着变, 准则沦为任意. 以 k 阶 Markov 链为例, 它有 $2^k$ 个参数. 一种直觉编码是: 先用整数标准码花 $2\log k + 1$ bit 描述阶数 k, 再对每个参数用 $\log(n+1)$ bit 记录计数, 总长 $2\log k + 1 + 2^k \log(n+1)$. Barron 和 Cover 1991 年指出可以更聪明: 相邻参数相距 $O(1/\sqrt{n})$ 时在数据上不可区分, 按这个精度离散化, 码长降到 $\frac{k}{2}\log n + c_k$.

好消息是, 只要假设的编码固定, 不随样本量 n 变化, 两段码 MDL 对相当广的模型类是一致的 (Barron 1985), 且巧妙设计的码能达到 minimax 最优收敛速率 (Barron-Cover 1991). 坏消息是, 小样本下怎么设计码没有原则, 而实际应用恰恰都是小样本. 出路是换工具: 通用码 (universal code).

## 6. 通用码与 NML: 把事后最优压成常数

通用码要解决的问题: 候选码集 $\mathcal{L}$ 里有一个码对数据压得最短, 但看数据之前不知道是谁. 天真的方案是看到数据后直接用最优的那个码, 可解码方不知道你用了哪个, 整个协议不构成合法码. 更根本的障碍是数学的: 不存在一个码对所有序列都达到 $\min_L L(x^n)$. 因为最大似然概率之和 $\sum_{x^n} P(x^n|\hat\theta(x^n)) > 1$, 而概率必须归一.

退而求其次, 用 regret 度量差距:

$$
\text{regret} = -\log \bar{P}(x^n) - \min_{P \in M} (-\log P(x^n))
$$

逐块拆解. 第一项 $-\log \bar{P}(x^n)$ 是你手里这个码对数据 $x^n$ 的实际码长. 第二项 $\min_{P \in M}(-\log P(x^n))$ 是「事后诸葛亮码」的码长: 看完数据之后, 在模型类 $M$ 里挑出对这个 $x^n$ 编码最短的那个分布, 它能做到的极限. 两项相减, 就是你的码比事后最优多花的 bit 数. 它的作用是给「没选对码」标价: regret 越小, 说明你的码越接近「开了天眼」的水平. 两段码对 M 个候选码的 regret 不超过 $\log M$. 贝叶斯混合码 $\bar{P}_{Bayes}(x^n) = \int P(x^n|\theta) W(\theta) d\theta$ 的 regret 不超过 $-\log W(\theta_0)$, 是与 n 无关的常数, 且处处不劣于两段码.

最优解由 Shtarkov 1987 年给出: 归一化最大似然分布

$$
\bar{P}_{nml}(x^n) = \frac{P(x^n \mid \hat{\theta}(x^n))}{\sum_{y^n \in \mathcal{X}^n} P(y^n \mid \hat{\theta}(y^n))}
$$

逐块拆解. 分子 $P(x^n \mid \hat{\theta}(x^n))$ 是「事后最优」的伪概率: $\hat{\theta}(x^n)$ 是用这条数据 $x^n$ 自己算出来的最大似然估计, 即模型类里最贴合这条数据的那个参数, 它给 $x^n$ 的概率是模型能做到的上限. 叫「伪概率」是因为把所有序列的分子加起来大于 1, 不是合法分布. 分母 $\sum_{y^n \in \mathcal{X}^n} P(y^n \mid \hat{\theta}(y^n))$ 遍历所有可能的长度 $n$ 序列, 把每条序列的伪概率加总, 作用就是把总和压回 1. 分子除以分母, 得到一个合法概率分布. 代入 regret 公式, 对任何序列 $x^n$, regret 恒等于

$$
\mathrm{COMP}_n(M) = \log \sum_{x^n \in \mathcal{X}^n} P(x^n \mid \hat{\theta}(x^n))
$$

逐块拆解. 求和就是上面那个分母, 取对数变成 bit 数. 它回答的问题是: 这个模型类里, 「事后最优伪概率」的总和超出 1 多少, 超出越多, 说明能被模型拟合好的数据模式越多, 模型越富有. 它不随数据变化 (求和遍历了所有可能的数据), 只依赖模型类 $M$ 和样本量 $n$, 且这是 minimax 意义下的最优值. 于是 refined MDL 的模型选择准则出炉: 选使随机复杂度 (stochastic complexity) 最小的模型,

$$
-\log \bar{P}_{nml}(D \mid M) = -\log P(D \mid \hat{\theta}(D)) + \mathrm{COMP}_n(M)
$$

逐块拆解. 等号左边是 NML 码对数据 $D$ 的总码长 (随机复杂度), 这是被最小化的对象. 右边第一项 $-\log P(D \mid \hat{\theta}(D))$ 是拟合项: 用模型里最贴合 $D$ 的参数编码数据要花多少 bit, 拟合越好越短. 第二项 $\mathrm{COMP}_n(M)$ 是复杂度项: 模型富有程度的固定标价, 与数据无关. 这条等式就是把 NML 定义式两边取负对数再移项得到的: $-\log \bar{P}_{nml} = -\log P(D \mid \hat{\theta}) + \log \sum_{y^n} P(y^n \mid \hat{\theta}(y^n))$, 最后一项正是 $\mathrm{COMP}_n(M)$ 的定义. 权衡还在, 但不再显式编码假设, 码的选择被 minimax 原则唯一确定, 任意性消失.

代入一个能手算到底的小例子. 取 Bernoulli 模型 (参数 $\theta$ = 出 1 的概率), 样本量 $n = 3$, 数据 $D = (0, 0, 1)$. 最大似然估计 $\hat{\theta} = 1/3$, 拟合项 $-\log_2 P(D \mid \hat{\theta}) = -\log_2[(2/3)^2 \cdot (1/3)] = -\log_2(4/27) \approx 2.75$ bit. 复杂度项要把全部 $2^3 = 8$ 条序列的伪概率加总, 按序列里 1 的个数分四组, 每行右侧给出数值:

$$\begin{aligned}
\sum_{y^3 \in \{0,1\}^3} P(y^3 \mid \hat{\theta}(y^3)) \;=\; & 1 && \text{(0,0,0): } \hat{\theta} = 0,\ P = 1^3 = 1 \\[4pt]
+\; & 3 \times \tfrac{4}{27} && \text{3 条恰含一个 1: } \hat{\theta} = \tfrac13,\ P = \tfrac13 \cdot (\tfrac23)^2 \\[4pt]
+\; & 3 \times \tfrac{4}{27} && \text{3 条恰含两个 1: } \hat{\theta} = \tfrac23,\ P = (\tfrac23)^2 \cdot \tfrac13 \\[4pt]
+\; & 1 && \text{(1,1,1): } \hat{\theta} = 1,\ P = 1^3 = 1
\end{aligned}$$

逐项看: 全 0 和全 1 的序列被模型完美拟合 (伪概率 1), 含一两个 1 的六条序列各贡献 $4/27$. 总和 $= 1 + 12/27 + 12/27 + 1 = 26/9 \approx 2.89$, 确实大于 1, 这就是「伪」字的来源. 于是 $\mathrm{COMP}_3 = \log_2(26/9) \approx 1.53$ bit, 总码长 $\approx 2.75 + 1.53 \approx 4.29$ bit. 反过来验证 NML 概率: $\bar{P}_{nml}(0,0,1) = (4/27) / (26/9) = 2/39 \approx 0.051$, $-\log_2(2/39) \approx 4.29$ bit, 两边对得上.

## 7. 参数复杂度: 复杂度是数出来的

$COMP_n(M)$ 凭什么叫模型复杂度? 一个求和里的每一项 $P(x^n|\hat\theta(x^n))$ 大, 意味着序列 $x^n$ 能被模型里某个分布拟合得好. 求和越大, 说明能被模型拟合好的数据模式越多, 模型越「富有」, 过拟合风险越大.

更精确的解读来自计数. 对有限模型, 把求和按最大似然估计的归属分组, 可以证明 $COMP_n(M)$ 等于模型中「可区分分布」数量的对数. 小样本时, 相邻分布产生的数据模式互相混淆, 可区分数量远小于实际数量; 大样本下大数定律起作用, 分布完美可分, $COMP_n(M) \to \log M$. 复杂度不是数参数, 是数「数据能分辨出几种不同的分布」.

参数模型的渐近展开由 Rissanen 1996 年给出 (Takeuchi 和 Barron 也有贡献):

$$
\mathrm{COMP}_n(M) = \frac{k}{2}\log\frac{n}{2\pi} + \log \int \sqrt{|I(\theta)|} \, d\theta + o(1)
$$

逐块拆解. 这是大样本下参数复杂度的近似公式, 三项分工明确. 第一项 $\frac{k}{2}\log\frac{n}{2\pi}$ 是量纲贡献: $k$ 是参数个数, 每个参数大约贡献半个 $\log n$——直觉是 $n$ 个样本能把每个参数定到 $1/\sqrt{n}$ 的精度, 描述这个精度需要 $\frac{1}{2}\log n$ 个 bit. 第二项 $\log \int \sqrt{|I(\theta)|} \, d\theta$ 是函数形式贡献: $I(\theta)$ 是 Fisher 信息矩阵 (衡量参数在数据里可分辨的程度), $|I(\theta)|$ 是它的行列式, 积分遍历整个参数空间, 这一项度量模型的几何「体积」, 不随 $n$ 增长, 大样本下可以忽略, 小样本下举足轻重. 第三项 $o(1)$ 是随 $n$ 增大消失的误差. Bernoulli 模型可以精确算出来: $COMP_n(B^{(0)}) = \frac{1}{2}\log n - 2.674 + o(1)$ (以 2 为底). Foster 和 Stine 警告, 这个展开只在 k 远小于 n 时可靠, 对混合模型这类非指数族可能根本失效.

## 8. 两个参数不等于同等复杂: Fechner 对 Stevens

这是全文最有说服力的一组实验, 来自心理物理学, Myung, Balasubramanian 和 Pitt 2000 年发表在 PNAS 上. 两个模型都描述物理刺激强度与心理感受的关系, 都只有两个自由参数: Stevens 模型 $y = ax^b + Z$, Fechner 模型 $y = a\ln(x+b) + Z$, Z 是高斯噪声.

按参数个数, 两者复杂度相同. 但实验讲出另一个故事. 研究者用 Fechner 模型生成大量大小为 4 的样本, 再把两个模型分别拟合上去. 结果 67% 的试验里, Stevens 模型拟合得更好, 尽管数据是 Fechner 生的. 换句话说, Stevens 模型富有到连对手生成的数据都能抢过来解释. 算渐近展开里的 Fisher 积分项, 两个模型相差 3.804, 对 4 个点的样本完全不可忽略. Townsend 早在 1975 年就猜测 Stevens 模型更灵活, 25 年后被 MDL 的复杂度度量证实.

这个例子是对「数参数」派的一记警告: 参数数量只是复杂度的量纲项, 函数形式决定的几何结构同样算数. 在两个模型拟合一样好时, refined MDL 选 Fechner, 而且选得对, 因为数据本来就来自 Fechner. 一个「幸运」地拟合得好的复杂模型, 和一个朴素但参数复杂度低的模型, MDL 给后者的分数更高. 数参数是偷懒, 数可区分的分布才是正事.

## 9. 一个准则, 四种解读

refined MDL 的准则可以从四个完全不同的角度推导出来, 这是它最反常的卖点.

压缩解读是原始动机: 选能最大压缩数据的模型. NML 码是唯一对所有序列 regret 相同的码, 不偏爱模型内任何分布, 从压缩第一原理出发它自然胜出.

计数解读如上节: 复杂度是可区分分布数量的对数, 随机复杂度可以重新理解为两段码, 先对离散化后的「极大可区分假设」用均匀码, 再编码数据.

贝叶斯解读: 对指数族模型做 Laplace 近似, 贝叶斯边际似然的 regret 是 $\frac{k}{2}\log n - \log w(\hat{\theta}) + \frac{1}{2}\log|I(\hat{\theta})| + o(1)$, 其中 $w(\theta)$ 是先验密度, 第二项就是「先验给最大似然点分配的概率密度换算成的 bit 数」. 取 Jeffreys 先验 $w(\theta) = \sqrt{|I(\theta)|} \,/\, \int \sqrt{|I(\theta)|} \, d\theta$ (分子是 Fisher 行列式的平方根, 分母把它归一成合法密度), 这个表达式与 $\mathrm{COMP}_n(M)$ 的渐近展开逐项重合. 也就是说, 带 Jeffreys 先验的贝叶斯模型选择, 大样本下与 refined MDL 不可区分. 先验就是编码长度, 这是两个范式最深的接口.

prequential 解读把分布看成序列预测策略. 链式法则给出 $-\log P(x^n) = \sum_{i=1}^{n} -\log P(x_i \mid x^{i-1})$, 其中 $x^{i-1} = (x_1, \dots, x_{i-1})$ 是前 $i-1$ 个观测: 整条数据的码长等于逐步预测的累计对数损失, 每一步只用「前 $i-1$ 步条件下第 $i$ 步的概率」. 用插入式预测器 $P(\cdot|\hat\theta(x^{i-1}))$ 逼近, 渐近也是通用码. 这里有个漂亮的细节: 直接用最大似然估计会翻车, 比如 Bernoulli 模型看到 (0,0,1), 前两步 ML 估计出 1 的概率为 0, 第三个观测的码长直接无穷大, 根本不是通用码. 改成加一平滑 $\hat\theta = (n_1+1)/(n+2)$, 恰好对应均匀先验的贝叶斯预测, 这是 Laplace 两百年前就主张的规则; 改成加半 $(n_1 + 1/2)/(n+1)$, 恰好对应 Jeffreys 先验, 渐近与 NML 不可区分. prequential 视角也让 MDL 与交叉验证接上头: 差别只在 MDL 严格按时间顺序预测, 且每个样本恰好被预测一次, 训练和测试天然分离, 过拟合无从发生.

## 10. 奥卡姆剃刀: 策略, 不是信仰

对 MDL 最常见的批评有两种, 都围绕奥卡姆剃刀. 第一种说描述长度是句法概念, 换编码换结论, 任意. 这个批评对粗糙两段码成立, 对 refined MDL 不成立: NML 码长, Jeffreys 先验的边际似然, 渐近展开, 都对参数的连续一一重参数化不变, 换「描述语言」不改变推断结果. 超出 NML 良定义的范围, 比如模型数量无限或 $COMP$ 发散 (正态位置模型就是例子), 确实要引入轻微的先验偏好, 但这种任意性比粗糙两段码轻微无穷倍, 而且所有模型选择方法都逃不掉.

第二种批评说奥卡姆剃刀是错的: 真实世界任意复杂, 凭什么偏好简单模型. Grunwald 的回答是, MDL 从不主张简单模型更可能为真, 它主张小样本下偏好简单模型是好策略. 策略没有真假, 只有聪明和愚蠢. 教程用 $g(x) = e^x$ 举例: 真实函数不是任何多项式, 但在有限区间上可以用越来越高次的多项式逼近, MDL 选出的次数随 n 增长, 且以高概率一致收敛到 $e^x$. 反过来, 小样本下直接在所有多项式里选拟合最好的, 选出的曲线与真实的 $g$ 几乎无关, 预测灾难.

这里有一个不对称性值得记住: 欠拟合时, 简单模型内的最佳拟合者大概率也是该模型内对未来数据的最佳预测者; 过拟合时, 即使复杂模型包含真假设, 最佳拟合者也会给出糟糕的预测. 一致性在 MDL 哲学里是体检而不是设计目标: 方法设计时不假设任何真分布存在, 但如果在「真分布恰好在模型里」的理想情形下都学不出来, 更一般的情形就没法信任了. Rissanen 1989 年那段原话是这套哲学的浓缩: 我们永远不要假设数据真的由某种分布 (比如高斯) 产生, 然后煞有介事地推导结论, 那些推导也许有趣, 但与手头的任务无关, 任务是从数据里学到有用的性质.

顺着这套哲学, 模型只是描述数据性质的语言, 噪声不是随机变量, 而是给定模型后编码数据还剩的残差 bit 数. 「这批数据很 noisy」在 MDL 里只意味着「用当前的模型压不动」, 原则上永远可能存在另一个模型把数据压得很短. Naive Bayes 垃圾邮件过滤, HMM 语音识别, 计量经济学的线性模型, 都是明知错但有用的模型, 基于「模型包含真分布」假设的传统方法在这些场景里地基是空的, MDL 不是.

## 11. 和邻居们划清界限

文献里流传「MDL 就是 BIC」的说法, 来自 Burnham 和 Anderson 的教材. 这是错的. BIC (Schwarz 1978) 的复杂度项是 $\frac{k}{2}\log n$, 恰好是渐近展开的第一项, 丢掉了 Fisher 积分的 $O(1)$ 项. Foster 和 Stine 2004 年指出, BIC 近似只在 k 固定而 n 趋于无穷时成立; 在嵌套模型族里 k 随 n 增长时, NML 和贝叶斯选出的模型与 BIC 明显不同, k 接近 n 时每个新增参数对 $COMP$ 的贡献远小于 $0.5\log n$. Fechner-Stevens 例子里两个模型参数数相同, BIC 对它们的复杂度评价一样, 直接错失 3.804 的差别. Rissanen 自己早年用过 MDL criterion 指称那个截断公式, 名字留了下来, 误传至今.

MML 与 MDL 表面相似, 都最小化消息长度, 但码不同: MML 永远用两段码, 优化主观先验下的期望绝对码长; MDL 用通用码, 优化最坏情形的相对码长 (regret). Wallace 一派强调自己是彻底的主观贝叶斯, 哲学与 Rissanen 相反, 实践中结果常常接近.

与贝叶斯的关系最微妙. 说「MDL 是贝叶斯的特例」不成立: NML 的局部化版本 (针对局部极大似然估计调整复杂度的那个公式) 在任何贝叶斯教科书里都不存在. 更准确的描述是, MDL 接受贝叶斯用分布表示不确定性的做法, 但不接受「一切推断必须通过先验后验」的教条, 先验在 MDL 里只是编码工具, 选用标准是 minimax regret. 这顺手解释了贝叶斯方法的一个尴尬: 对明知为错的模型放先验, 等于对明知不成立的事给置信度 1, 严格贝叶斯不该这么做, 但实践中偏偏 work. 用码长或序列预测去解读, 尴尬消失.

## 12. 理想 MDL 与结构函数: 回到 Kolmogorov

教程最后把线收回 Kolmogorov 复杂度. Barron 和 Cover 1991 年的理想化方案是: 在所有可计算分布里选使 $K(P) + \lceil -\log P(D) \rceil$ 最小的, $K(P)$ 是计算 $P$ 的最短程序长度, $\lceil \cdot \rceil$ 是向上取整 (码长必须是整数 bit). 数学上良定义, 实践上不可计算, 最小化者无法有效求得.

Kolmogorov 本人的变体更有意思: 在所有满足 $K(P) + (-\log P(D)) \approx K(D)$ 的分布里, 选 $K(P)$ 最小的那个. 这叫 Kolmogorov 结构函数 (structure function), 或最小充分统计量方法. 选出的假设榨干了数据里全部结构, 给定假设后, 数据与随机噪声不可区分. 这正是本站学习路线 `1.1.1` 里 sophistication 的统计学版本: 把对象分解成结构部分和随机部分, 只给结构计分. 本站学习路线前两篇讲这个分解在物理系统里的形态, 本篇讲它在统计学习里的工程化, 路线 `1.1.5` (Li 和 Vitanyi 的教材) 是整套理论的系统展开, 三篇构成一个递进.

结构函数还引出一条有损压缩的线: 只发送代表结构的假设, 接收方据此生成「典型」数据, 看起来与原始数据别无二致. Rissanen 晚年 (Rissanen-Tabus 2004) 试图把基于无损压缩的 MDL 与结构函数统一, 称之为 MDL 理论的新篇章.

## 13. 局限: MDL 不是万能药

Grunwald 自己很诚实地列了真实存在的问题. 第一是近似滥用: 渐近展开在小样本下不可靠 (Navarro 2004 给出反例), 参数范围被随意截断 (Lanterman 2004). 这类问题出在近似, 不出在思想, 教程的建议是能用精确 NML 或 Jeffreys 先验就别用展开式.

第二更深, 也更讽刺. MDL 的设计初衷是不依赖「真分布在模型里」的假设, 但 Grunwald 和 Langford 2004 年证明, 在真分布不在模型类里的分类问题上, MDL 可以持续过拟合, 无论样本多大都选过于复杂的模型. Barron 和 Yamanishi 的修改版没有这个问题, 却失去了自然的编码解读. 不依赖真分布假设设计的方法, 恰恰在假设不成立时翻车, 这是 MDL 理论至今的开放性伤口.

## 14. 在 本站学习路线中的位置

把`1.1` 主题组连起来看, 主题非常清楚. 路线 `1.1.1` 提猜想: 有趣 = 结构加随机, 用 sophistication 度量. 路线 `1.1.2` 做实验: 咖啡自动机里复杂度曲线确实是山峰. 路线 `1.1.3` (本篇) 给工具: 同一段「结构加残差」的分解, 在统计学习里变成可计算, 可证明, 一致的模型选择准则, 而且顺手把贝叶斯, 交叉验证, 预测损失统一进同一个框架. 路线 `1.1.5` Li-Vitanyi 教材是理论总库.

向后看, 路线 `1.6.1` Hinton 和 van Camp 1993 年的工作把两段码直接用在神经网络权重上: 先编码权重 (用混合高斯先验), 再编码权重下的数据误差, 总码长作为训练目标. 那是 MDL 进入神经网络的最早证据之一, 也是「压缩即泛化」思想的源头之一. 再往后, 2023 年 DeepMind 的 Language Modeling Is Compression 把这条线接到今天: 预测下一个 token 的累计对数损失, 就是 prequential 码长, 大模型训练就是在对互联网文本做通用压缩. 从 Solomonoff 1964 到今天的语言模型, 这条线走了六十年, 中间最结实的一座桥就是 MDL.
