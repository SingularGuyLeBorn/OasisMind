# CS231n：为什么经典论文书目里需要一门课

> 原始文本: Stanford CS231n 课程笔记, Convolutional Neural Networks for Visual Recognition, Fei-Fei Li, Andrej Karpathy, Justin Johnson 主讲, 2015 年起开课.
> https://cs231n.github.io/
> 本帖依据三组官方课程笔记: 卷积网络架构、优化与反向传播。CS231n 在社区重建版本中排第 27；本站将它编号为 `1.2.5`，作为 CNN 主题的系统训练入口。

**全文符号表**

本文是课程导读, 公式只有三条, 全是课程笔记里的原式. 先一次性登记, 正文第一次出现时还会再讲一遍.

| 符号 | 含义 |
|------|------|
| $x_i$ | 第 $i$ 张训练图像 (拉成向量后的像素值) |
| $N$ | 训练样本总数 |
| $y_i$ | 第 $i$ 张图的正确类别编号. 注意它不是预测值, 是标签, 出现在下标时表示「正确类别的分数」 |
| $W$ | 权重矩阵, 得分函数的全部参数 |
| $f(x_i; W)$ | 得分函数, 输入第 $i$ 张图, 输出每个类别一个分数. 分号左边是数据, 右边是参数 |
| $f(x_i; W)_j$ | 第 $j$ 个类别的分数, 下标 $j$ 取向量分量 |
| $\Delta$ | SVM 损失的间隔 (margin), 正确类别的分数要比其他类别高出这么多才不罚 |
| $\max(0, \cdot)$ | 合页 (hinge): 括号里是正就保留, 是负就归零, 即「没达到要求才计罚」 |
| $\alpha$ | 正则化强度, 控制正则项在总损失里的权重 |
| $R(W)$ | 正则项, 只和权重有关, 常用 L2 范数 (各权重平方和) |
| $L$ | 总损失 = 数据损失 + 正则项 |
| $\sigma(x)$ | sigmoid 函数, $\sigma(x) = 1/(1+e^{-x})$, 把任意实数压到 $(0,1)$ |
| $e^{-x}$ | 自然指数, $e \approx 2.718$ |
| $W_1, W_2$ | 卷积层的输入宽度和输出宽度 (§7 尺寸公式, 与权重 $W$ 靠下标和上下文区分) |
| $F$ | 滤波器 (卷积核) 的空间尺寸, 比如 3 表示 3x3 |
| $S$ | 步长 (stride), 滤波器每次移动几格 |
| $P$ | 零填充 (zero-padding), 每侧补几圈 0 |
| $X^T, W^T$ | 上标 $T$ 是矩阵转置: 行列互换. 本文没有「教师 (Teacher)」记号, $T$ 只有转置一个含义 |

**读公式的方法**: 三条公式各属一个部件. §2 SVM 损失读「谁在罚谁」: 双重求和外层遍历样本, 内层遍历非正确类别, 每个类别不够高出一个间隔就计一份罚. §4 sigmoid 导数读「为什么能化简」: 商形式 $(1-\sigma)\sigma$ 让五六个门合并成一个. §7 尺寸公式读「滤波器能放在几个位置」: 起点数加一就是输出边长.

## 1. 背景与历史: 本站学习路线里唯一的一门课

社区重建书目把论文、博客、教材与课程放在一起。本站将 CS231n 放在 CNN 主题的末尾，用来从单篇论文过渡到系统训练；这个位置是本站教学安排。

CS231n 的全名是 Convolutional Neural Networks for Visual Recognition. 2015 年由 Fei-Fei Li 和 Andrej Karpathy 开课, Justin Johnson 后来接手主讲. 三个人的履历本身就是深度学习这十年的缩影. Li 是 ImageNet 的发起人, 没有 ImageNet 就没有 2012 年的 AlexNet 时刻. Karpathy 是 2012 年之后第一批把卷积网络工程化的人, 后来去了 OpenAI 和 Tesla, 他的课程录像, 博客和作业构成了全球自学深度学习的事实标准之一. 课程的全部笔记, 作业, 讲义公开在 cs231n.github.io 上, 免费, 不需要任何权限.

本站学习路线 `1.2.1` AlexNet 的第二作者是 Ilya Sutskever，而 CS231n 系统讲解了这类卷积网络的训练方法。两者并读能把论文结论还原成可操作知识；不能据此推断私人清单的精确排序或推荐人的意图。

这门课最特别的地方不是讲了什么, 而是怎么教. 它不讲框架, 不要求 TensorFlow 或 PyTorch, 作业要求用纯 NumPy 从零写出 SVM, 两层网络, 卷积层的 forward 和 backward. 反向传播不许调 autograd, 自己推, 自己写, 再用数值梯度校验. 这种训练方式在今天看近乎残酷, 但 2015 年到 2018 年之间, 它就是进入这个行业的标准入场仪式. 后来无数大厂的视觉负责人, 简历上都写着刷过 CS231n 的作业.

## 2. 问题定义: 三件套

课程把图像分类问题拆成三个部件, 这套拆解本身就是教学贡献.

第一件是得分函数, 一个把原始像素映射到类别分数的参数化函数. 最简单的形式是线性函数 $f(x_i, W) = W x_i$. 第二件是损失函数, 衡量某组参数 $W$ 的好坏. 课程里用的是多分类 SVM 损失:

$$
L = \frac{1}{N} \sum_{i=1}^{N} \sum_{j \neq y_i} \max(0, f(x_i; W)_j - f(x_i; W)_{y_i} + \Delta) + \alpha R(W)
$$

逐块拆开. 外层 $\frac{1}{N} \sum_{i=1}^{N}$ 遍历全部 $N$ 个训练样本求平均, 每个样本贡献一个损失值. 内层 $\sum_{j \neq y_i}$ 遍历除正确类别 $y_i$ 之外的所有类别 $j$, 意思是「每个竞争对手类别都要单独检查一遍」. $\max(0, f(x_i; W)_j - f(x_i; W)_{y_i} + \Delta)$ 是单份惩罚: 正确类别的分数 $f(x_i; W)_{y_i}$ 必须比类别 $j$ 的分数高出间隔 $\Delta$, 差值不够就按差多少罚多少, 够了 (括号里为负) 就归零. 前一项是数据损失, 正确类别的分数要比其他类别高出一个间隔 $\Delta$, 否则计罚. 后一项 $\alpha R(W)$ 是正则, 只和权重有关, $\alpha$ 控制它占总损失的比重.

代课程笔记里的经典例子算一遍. 某个样本三个类别的分数是 $[3.2, 5.1, -1.7]$, 正确类别是第一个 (分数 3.2), 取 $\Delta = 1$. 内层求和两项: 对第二类, $\max(0, 5.1 - 3.2 + 1) = \max(0, 2.9) = 2.9$; 对第三类, $\max(0, -1.7 - 3.2 + 1) = \max(0, -3.9) = 0$. 这个样本的数据损失就是 $2.9 + 0 = 2.9$. 注意第三类虽然分数比正确类别低, 但低得不够多 (差 4.9, 远超间隔 1), 所以零惩罚; 第二类分数反超, 被罚 2.9. 合页的意义就在这: 不是「错了就罚」, 是「赢得不够痛快也罚」. 第三件是优化, 在损失景观里找最低点.

这套三件套的价值在于, 它把「换模型」和「换训练方法」解耦了. 得分函数可以从线性函数换成两层网络, 再换成 152 层的 ResNet, 损失函数和优化流程几乎不动. 课程原话: 后面会把第一个部件换成越来越复杂的函数, 损失和优化保持相对不变. 这句话是整个课程的结构预告, 也是今天 PyTorch 里换 model 不换 training loop 的思想源头.

损失景观在这里有了一个重要的区分. SVM 损失是凸的, 是高维空间里的一个碗, 课程用单样本和百样本的切片图展示了分段线性结构: 单样本的损失是若干条被 max(0, ·) 截断的直线之和, 带折点, 严格说折点处不可导, 用次梯度 (subgradient) 代替. 百样本平均之后, 折点被磨平, 碗形显现. 一旦得分函数换成神经网络, 目标变成非凸, 碗变成崎岖地形, 凸优化的全部工具箱就此作废. 深度学习训练的全部技巧, 都是在非凸地形上的工程妥协.

## 3. 核心骨架一: 反向传播是局部通信协议

课程对反向传播的讲法是它最大的原创贡献. 大多数教材从链式法则的公式开始, 这门课从计算图 (computational graph) 开始, 把反向传播讲成实数电路里的局部通信.

规则极简. 电路里每个门 (gate) 只需要会两件事: 算自己的输出, 算输出对输入的局部梯度. 加法门的局部梯度恒为 1, 乘法门把两个输入互换, max 门把梯度全给前向时的最大值那个输入, 另一个拿 0. 门与门之间不知道全局电路长什么样, 也不需要知道. 反向时, 链式法则就是一句话: 拿到下游传来的梯度, 乘上自己的局部梯度, 发给上游.

用一个具体例子. $f(x,y,z) = (x+y)z$, 拆成 $q = x+y$ 和 $f = qz$. 取 $x=-2, y=5, z=-4$, 前向得 $q=3, f=-12$. 反向时乘法门的局部梯度是 $z=-4$ 和 $q=3$, 加法门把 $-4$ 原样分给 $x$ 和 $y$. 最终梯度 $[-4, -4, 3]$, 每个数字的意思是: 这个输入增加一点点, 输出会按这个倍数变化. 梯度不是公式, 是灵敏度读数.

课程给了一个拟人化但精确的说法: 门与门之间通过梯度信号沟通, 告诉彼此希望自己的输出升高还是降低, 用多大力气. 整个网络没有中央控制器, 全靠这种局部通信收敛到全局最优方向. 这个视角后来被直接搬进了自动微分系统的设计, PyTorch 的 autograd 图, 本质就是课程里那张电路图.

## 4. 核心骨架一续: Sigmoid 示范与工程纪律

Sigmoid 的例子展示了这套方法的模块化能力. 一个二维神经元 $\sigma(w_0 x_0 + w_1 x_1 + w_2)$ 拆成电路, 要经过点积, 取负, 指数, 加一, 取倒数五六个门. 但 sigmoid 的导数有个优美的化简:

$$
\frac{d\sigma(x)}{dx} = \frac{e^{-x}}{(1+e^{-x})^2} = (1 - \sigma(x))\sigma(x)
$$

第二个等号不是变魔术, 一步就能验证: 由 $\sigma(x) = 1/(1+e^{-x})$, 得 $1 - \sigma(x) = e^{-x}/(1+e^{-x})$, 两个式子相乘正好等于中间那个分式. 所以化简是恒等变形, 不是近似. 输入 1.0 时输出 0.73, 局部梯度就是 $(1-0.73) \times 0.73 \approx 0.2$. 五六个门可以合并成一个门, 反向只需一次乘法. 这就是「staged computation」: 前向时把计算拆成有简单局部梯度的阶段, 缓存中间变量, 反向时按相反顺序逐个阶段回传.

两条工程纪律从这里长出来. 第一是变量分叉时梯度要累加, 代码里必须用 `+=` 而不是 `=`, 这是多元链式法则的直接推论, 写错就是静默 bug. 第二是梯度检验 (gradient check): 解析梯度快且精确但容易推错, 数值梯度慢且近似但不可能错. 实践中的标准流程是手写解析梯度, 再用中心差分 $[f(x+h) - f(x-h)] / 2h$ 的数值梯度对照, 相对误差够小才放行. 这门课的作业把这条纪律刻进了每个学生的习惯, 今天调试自定义 CUDA 算子的人还在用同一招.

向量化之后, 矩阵乘法的梯度 $dW = dD \cdot X^T$, $dX = W^T \cdot dD$ 不需要背, 靠维度分析就能唯一推出: 梯度必须和原变量同形状, 组合方式只有一种能让维度对上. 其中上标 $T$ 是矩阵转置 (行列互换), 加它的目的就是让乘法两边的维度对上; 本文 $T$ 只有转置这一个含义. 这是课程反复强调的调试技能, 写反向传播时第一检查项永远是形状.

## 5. 核心骨架二: 优化是一场蒙眼下山

优化这一章用一个比喻统一了全部内容: 蒙眼徒步者. 权重空间是山, CIFAR-10 的线性分类器有 30730 维, 蒙眼的人看不见地形, 只能感受脚下的坡度, 目标是走到谷底.

课程故意先写了两个笨办法, 再引出梯度, 这个教学顺序本身值得品味. 策略一是纯随机搜索, 随机生成 1000 组权重, 留最好的, 测试集准确率 15.5%, 随机猜是 10%. 策略二是随机局部搜索, 每次朝随机方向迈一小步, 下坡才落脚, 准确率提到 21.4%. 策略三是沿梯度走, 方向不再靠猜, 微积分保证梯度就是局部最陡方向. 三个策略准确率 10% 到 15.5% 到 21.4%, 这个阶梯把「为什么要算梯度」讲成了不需要数学也能理解的事.

梯度怎么算, 课程给了数值和解析两条路, 效率差距是数量级的. 数值梯度每个参数要两次前向, 30730 个参数就是 6 万多次损失评估, 才换来一次参数更新, 现代网络几千万参数, 这条路直接死刑. 解析梯度用链式法则一次反向传播全部拿到, 这才让训练成为可能. 反向传播不是理论装饰品, 是训练得以存在的工程前提.

然后是学习率, 课程原话: 训练神经网络最重要也最令人头疼的超参. 它给的演示至今是最好的学习率教材. 同一个损失 2.20, 步长 $10^{-6}$ 时新损失 1.65, 稳步下降. 步长 $10^{-5}$ 时损失反弹到 2.84, 步长 $10^{-4}$ 时 25.6, 步长 $10^{-1}$ 时 25392, 彻底发散. 方向对了, 步长错了, 照样完蛋. 梯度只告诉你哪边最陡, 不告诉你迈多远.

最后是 mini-batch. ImageNet 有 120 万张图, 全量算一次梯度才更新一次参数, 太慢. 实际用 256 张一批. 课程给了一个极端论证说明为什么小批量可行: 假如 120 万张图其实是 1000 张各复制 1200 份, 全量梯度和 1000 张子集的梯度完全一样. 真实数据不是复制品, 但样本间的相关性保证了小批量梯度是全量的良好近似. 向量化实现让一次算 100 个样本比算 100 次单样本快得多, 所以纯 SGD (batch=1) 反而少见, batch size 取 2 的幂, 32, 64, 128, 图的是硬件友好.

## 6. 核心骨架三: 卷积层的两个杠杆

卷积网络这一章的出发点是一个参数灾难. CIFAR-10 的图只有 32x32x3, 全连接第一层每个神经元 3072 个权重, 尚可. 换成 200x200x3 的正经图片, 每个神经元 12 万个权重, 一层几个神经元就参数爆炸, 必然过拟合. 全连接结构对图像是浪费, 因为图像有两个先验没有用上: 局部性和平移不变性.

第一个杠杆是局部连接. 每个神经元不再连接上一层全部, 只看一个局部空间区域, 这个区域的大小叫感受野 (receptive field), 比如 5x5. 但深度方向永远是全连接: 输入是 3 通道, 滤波器就是 5x5x3, 75 个权重. 空间局部, 深度全连, 这个不对称是卷积层的定义特征.

第二个杠杆是参数共享, 这是参数量的真正救星. AlexNet 第一层卷积, 输出体 55x55x96, 共 290400 个神经元, 每个 363 个权重, 不共享就是 105,705,600 个参数, 光第一层就上亿. 共享的假设只有一句话: 某个位置有用的特征, 换个位置同样有用. 水平边缘检测器在图像左上角有用, 在右下角也该有用. 于是同一个深度切片上 55x55 个神经元共享一套权重, 第一层只剩 96 套滤波器, 34,944 个参数. 一亿到三万, 压缩 3000 倍, 靠的就是这一条关于图像结构的假设. 反向传播时, 同一深度切片上各神经元的梯度相加, 共同更新那一套共享权重.

这门课没有把这种共享说成免费午餐. 它明确给了反例: 居中对齐的人脸, 左眼和右脸该学不同的特征, 平移不变性假设不成立, 此时该用局部连接层 (Locally-Connected Layer), 放弃共享. 先验是赌注, 赌赢了省参数, 赌错了伤性能, 这和膨胀卷积 (本站学习路线 `1.2.4`) 赌「上下文是局部的」是同一类判断.

工程实现上, 课程点破了卷积层的一个关键技巧: im2col. 卷积说到底就是滤波器和输入局部区域的点积, 把每个感受野区域的像素拉成一列, 输入就变成一个矩阵, 滤波器权重拉成另一个矩阵, 整个卷积层的前向就变成一次大矩阵乘法. 以 AlexNet 第一层为例, 输入 227x227x3, 每个 11x11x3 的感受野拉成 363 维列向量, 55x55 个位置共 3025 列, 权重矩阵 96x363, 一次 np.dot 得到 96x3025, 再 reshape 回 55x55x96. 代价是重叠的感受野让输入数值被复制多次, 内存变大, 收益是可以直接调用 BLAS 里优化了几十年的矩阵乘法. 这个取舍是后来 cuDNN 一切卷积实现的起点.

还有一个课程特别强调的变换: 全连接层可以等价改写成卷积层. 一个看着 7x7x512 输入, 输出 4096 的全连接层, 等价于滤波器尺寸 7, 步长 1, 无填充的卷积层, 输出 1x1x4096. 改写之后, 网络就能在大图上滑动: 384x384 的图前向一次, 得到 6x6x1000 的分数图, 等价于在原图上取 36 个 224 裁剪分别评估, 但共享了全部计算. 测试时放大图片, 滑动评估, 平均分数, 这个提分技巧在竞赛里被用了好几年, 靠的就是 FC 和 CONV 功能形式相同这一件事.

## 7. 核心骨架三续: 尺寸公式与 VGG 解剖

卷积层的输出尺寸由四个超参决定: 输入宽 $W$, 滤波器 $F$, 步长 $S$, 零填充 $P$. 公式:

$$
W_2 = \frac{W_1 - F + 2P}{S} + 1
$$

逐项拆开. $W_1 - F$ 是输入宽度减去滤波器宽度, 即滤波器在水平方向上还能滑动多少格. $2P$ 是两侧各补 $P$ 圈零后多出来的宽度, 总共多 $2P$. 分子 $W_1 - F + 2P$ 就是「滤波器所有可能的起点位置数减一」. 除以步长 $S$ 是把滑动换算成落脚点个数: 每 $S$ 格落一次脚. 最后 $+1$ 补上起点本身那个位置. 整个公式回答的问题是: 滤波器从左边一路滑到右边, 一共能放在几个位置, 这个数就是输出宽度. 顺便提醒一个工程用法: 公式算出不是整数, 说明超参组合不合法, 要调 $P$ 或 $S$, 这是搭网络时最先检查的一步.

7x7 输入, 3x3 滤波器, 步长 1 无填充, 输出 5x5. 步长 2, 输出 3x3. AlexNet 第一层, 输入 227x227x3, $F=11, S=4, P=0$, $(227-11)/4+1=55$, 输出 55x55x96. 课程在这里挖了一个历史彩蛋: AlexNet 论文写的是 224x224 输入, 但 $(224-11)/4+1$ 不是整数, 论文里的数字一定是错的, 作者猜实际用了 3 像素填充. 一个公式就能戳穿顶会论文的数字, 这就是课程要训练的手感.

零填充不只是方便. $P=(F-1)/2$ 配合步长 1 可以保持空间尺寸不变, 让卷积只管深度变换, 下采样全交给池化, 尺寸规划从此不再头疼. 不加填充, 每层边缘信息被「洗掉」一点, 边界像素参与计算的次数天然少于中心, 性能受损.

池化层没有参数, 只做下采样. 最常用 2x2 步长 2 的 max pooling, 一次丢掉 75% 的激活值. 反向时 max 门把梯度只路由给前向时的最大值位置, 所以前向要缓存 argmax 索引. 课程还记了一笔潮流判断: 越来越多人主张用大步长卷积取代池化, VAE 和 GAN 这类生成模型里丢掉池化已经被证明重要, 未来架构可能几乎没有池化层. 十年后的 ViT 应验了这个判断.

课程解剖 VGGNet 的方式是把每一层的激活内存和参数量全列出来, 这是全文最有工程味的部分. 224x224x3 输入, 三层 3x3 卷积后激活体 224x224x64, 单张图 3.2M 激活值. 全程 16 层, 总激活内存约 24M 个值, 乘 4 字节约 93MB, 只算前向, 反向翻倍. 参数量 138M, 其中第一个全连接层 $7 \times 7 \times 512 \times 4096 = 102,760,448$, 一层占 1 亿, 是全部参数的四分之三. 结论: 内存和算力花在前面的卷积层, 参数堆在后面的全连接层. 后来发现砍掉那些全连接层性能几乎不掉, 参数大减, GoogLeNet 用全局平均池化取代全连接就是这条路. 训练时参数还要存梯度和动量缓存, 显存按 3 倍估, 装不下就先砍 batch size, 因为大头是激活值.

## 8. 架构动物园: 从 LeNet 到 ResNet

课程的案例研究把卷积架构史讲成一条清晰的演化线, 每一年都在回答前一年留下的问题.

LeNet, LeCun 1990 年代, 读邮编和手写数字, 第一次证明卷积网络能干活. AlexNet, 2012 年 ILSVRC 冠军, top-5 错误率 16%, 第二名 26%, 十个点的差距震动了整个视觉社区. 结构和 LeNet 几乎一样, 只是更深, 更大, 卷积层开始堆叠而不是每个卷积后必跟池化. ZFNet 2013 年冠军, 改的是超参: 第一层滤波器变小, 步长变小, 中间层变宽, 调参就拿了冠军, 说明 2012 年的架构远没到极限.

GoogLeNet 2014 年冠军, Inception 模块把参数量压到 4M, 只有 AlexNet 60M 的十五分之一, 顶部用平均池化干掉全连接层. 同年的亚军 VGGNet 走了相反的路: 结构做到极端同质, 从头到尾只有 3x3 卷积和 2x2 池化, 用 16 层的深度证明深度本身是关键变量, 代价是 140M 参数. ResNet 2015 年冠军, 跳连接 (skip connection) 加批归一化, 深度推到 152 层。本站学习路线 `1.2.2`、`1.2.3` 分别是 ResNet 与恒等映射分析, 路线 `1.2.4` 空洞卷积则回答感受野与稠密预测问题。

课程还给了一个被后来 VGG 验证的论证: 三个 3x3 卷积堆叠, 感受野等于一个 7x7, 但前者有三次非线性, 表达力更强, 参数量 $27C^2$ 对 $49C^2$, 省近一半. 大滤波器从此退出舞台, 只在第一层偶尔出现.

在这些架构讨论之后, 课程写下了一句最不像教材的话, 后来被引用无数次: don't be a hero. 90% 以上的应用场景, 你不该自己设计架构, 更不该从零训练. 正确姿势是拿 ImageNet 上预训练好的模型, 在自己的数据上微调. 一个教你怎么从零写卷积层的课, 最后告诉你工程上别从零开始, 这个张力恰恰是对这个领域最诚实的总结: 从零实现是为了理解, 预训练微调是为了干活.

## 9. 局限与后续

这门课的笔记是 2016 年的快照, 写的时候 ResNet 刚拿冠军, 膨胀卷积刚发表, 批归一化还是新东西. 它没讲 BatchNorm 的细节, 没讲 ResNet 为什么能训 152 层 (那是本站学习路线 `1.2.3` 的主题), 也没讲优化器家族, 动量, RMSProp, Adam 都在另一章. 课程自己也承认归一化层在 AlexNet 时代流行过, 后来证明贡献极小, 被抛弃了, 虽然几年后批归一化以另一种形式复活, 这个判断的沉浮本身就是架构史的常态.

十年后再看, 课程的骨架几乎全部存活. 反向传播的电路视角是所有自动微分框架的设计语言. 三件套拆解依然是教学标准结构. 小滤波器堆叠, 参数共享, 尺寸公式, 依然是每个卷积网络的常识. 变化的是主角: 2017 年 Transformer 出现 (本站学习路线 `1.4.2`), 视觉领域后来也有了 ViT, 卷积不再是视觉的唯一答案. 但即便是 ViT, patch embedding 的第一层仍然是一个卷积, 课程里的公式照样适用.

作业文化也在变. 当年从零写 NumPy 反向传播是入场仪式, 今天 autograd 普及, 这种训练更像体能训练而不是生产技能. 但课程笔记至今仍在更新维护, 2025 年的版本还在被全球学生使用, 一门课活过十年, 靠的不是知识不过时, 而是它教的是知识底下的方法论.

## 10. 在本站学习路线中的位置

本站学习路线路线 `1.2.1`–`1.2.4`是 CNN 的四篇关键论文: AlexNet 点火, ResNet 解决深度, Identity Mappings 分析跳连接的本质, Dilated Conv 解决感受野. 路线 `1.2.5` 把这四篇串成可学的体系, 补上论文不写的东西: 反向传播怎么推, 梯度怎么验, 学习率怎么调, 尺寸怎么算, 显存怎么估. 论文给你结论, 课程给你手艺.

这门课的主讲 Karpathy, 也是本站学习路线 `1.3.1` (The Unreasonable Effectiveness of Recurrent Neural Networks) 的作者。本站把 `1.2.5` 作为系统训练入口，再用 `1.3.1` 展示序列模型能做什么，完成从“读懂单篇”到“动手训练”的节奏转换。

还有一个值得保留的联系: Ilya 本人是 AlexNet 的共同作者, 2012 年那篇论文里的网络正是这门课重点解剖的对象。论文与课程并读的价值，在于把结果还原成可以教学、复现和迁移的训练方法。
