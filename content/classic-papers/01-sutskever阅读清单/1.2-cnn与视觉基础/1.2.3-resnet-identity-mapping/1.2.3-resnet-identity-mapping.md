# Identity Mappings in Deep Residual Networks: 残差为什么有效, 以及还能不能更好

> 原始论文: Kaiming He, Xiangyu Zhang, Shaoqing Ren, Jian Sun, "Identity Mappings in Deep Residual Networks", ECCV 2016, arXiv:1603.05027.
> https://arxiv.org/abs/1603.05027
> 代码: https://github.com/KaimingHe/resnet-1k-layers
> 这是本站学习路线 `1.2.3`, 紧接路线 `1.2.2` ResNet 原文. 路线 `1.2.2` 提出残差连接并用 152 层网络横扫 ImageNet, 留下两个问题没回答: 残差为什么有效, 残差单元还能不能更好. 路线 `1.2.3` 就是同一作者团队对自己工作的拆解.

**全文符号表**

本文是 ResNet 的分析续作, 公式比路线 `1.2.2` 多, 但全部围绕一个残差单元展开. 记号沿用原论文, 和路线 `1.2.2` 的对应关系: 路线 `1.2.2` 的 $F(x, \{W_i\})$ 在这里写成 $F(x_l, W_l)$, 下标 $l$ 标记是第几个残差单元.

| 符号 | 含义 |
|------|------|
| $l$ | 残差单元的编号, 从输入侧往输出侧数, 第 $l$ 个单元 |
| $L$ | 一个比 $l$ 更深的单元编号, 用于「从第 $l$ 层看到第 $L$ 层」的跨层公式 |
| $x_l$ | 第 $l$ 个残差单元的输入特征, 也就是第 $l-1$ 个单元的输出 |
| $y_l$ | 第 $l$ 个单元里加法之后的信号, $y_l = h(x_l) + F(x_l, W_l)$, 再经过激活 $f$ 才成为下一个单元的输入 |
| $h$ | shortcut 路径上的变换. identity shortcut 就是 $h(x_l) = x_l$, 原样通过 |
| $F(x_l, W_l)$ | 第 $l$ 个单元的残差函数 (比如两个 3x3 卷积), $W_l$ 是它的权重 |
| $f$ | 逐元素加法之后的激活函数, ResNet 原文用 ReLU. 本文的核心动作就是把它也变成 identity |
| $E$ | 训练损失 (原文记号, 一个标量) |
| $\lambda_l$ | 第 $l$ 个单元 shortcut 上乘的标量系数, $\lambda_l = 1$ 时退回 identity |
| $\prod_{i=l}^{L-1}$ | 连乘: 把 $i$ 从 $l$ 到 $L-1$ 的每一项乘起来. 和求和 $\sum$ 相对, 本文的全部结论可以概括为「求和友好, 连乘致命」 |
| $\hat{F}$ | 吸收了缩放系数的残差函数, 读音「F 帽子」, 形状和 $F$ 一样, 只是数值上被 shortcut 的系数重新标定过 |
| $\hat{f}$ | 不对称激活, 只作用在残差路径 $F$ 的输入上, 不碰 shortcut 路径 |
| $\sigma$ | sigmoid 函数, 把任意实数压到 $(0, 1)$ 区间, 门控里用它当「开度」 |
| $W_g, b_g$ | 门函数的权重和偏置, 下标 $g$ 是 gate |
| $\dfrac{\partial E}{\partial x_l}$ | 损失对第 $l$ 层特征的梯度, 反向传播时第 $l$ 层实际收到的信号 |

**读公式的方法**: 全文七条公式只分两类. 前向公式 (特征怎么往上传) 和反向公式 (梯度怎么往下传), 而且每一条前向公式都对应一条反向结论. 读前向公式只看一件事: 深层特征是「浅层特征加一串残差」还是「浅层特征乘一串系数」, 加法还是乘法. 读反向公式只看一件事: 梯度表达式里有没有一个不经过任何权重、恒等于 1 的直达项. 有这个 1, 梯度就有下限; 没有, 梯度听天由命.

## 1. 背景: 一篇理论续作的自我修养

2015 年底 ResNet 原文 (本站学习路线 `1.2.2`) 用 152 层网络拿下 ImageNet, 同时报告了一个反常现象: 没有残差连接的 plain network 加深到几十层就开始退化, 训练误差反而升高, 而加上 shortcut 之后 152 层照训不误. 原文把这叫 degradation problem, 并用实验证明残差连接能解, 但「为什么能解」只留下一段直觉性的猜测: 让层去拟合残差比拟合完整映射更容易.

这个解释不能算错, 但它经不起追问. 如果残差学习是关键, 那 shortcut 上做点手脚应该无伤大雅, 比如乘个系数, 加个门控, 甚至塞一层 1x1 卷积增强表达. 直觉上这些改动只会让模型更灵活. 本文的价值就在于把这个「应该无伤大雅」逐个送上实验台, 然后看着它们一个个挂掉.

当时的背景值得补一笔. 2015 年的深网纪录是 ResNet 的 152 层, 再往前一年, VGG 的 19 层已经让人觉得深不可测. 和 ResNet 几乎同时出现的 Highway Networks 用门控机制训练了上百层网络, 思路同样来自 LSTM 的 forget gate. 但 ResNet 原文自己也留下一个尴尬数据: 1202 层的原版网络在 CIFAR-10 上误差 7.93%, 比自家 110 层的 6.61% 还差, 只能归因为过拟合. 也就是说, 「深」这条路到底是被优化堵死了, 还是被泛化堵死了, 在 2016 年初并没有答案. 本文给出的答案是: 都被堵过, 但堵法不同, 而且单元内部改个顺序, 两道墙都能拆掉一半.

论文的方法论比结论更值得学. 它不是提出一个全新架构再去刷榜, 而是把一个经验上的成功拆成一条可验证的假设链: 第一步, 对残差单元的传播公式做递推分析, 推出两个 identity 条件; 第二步, 做消融实验, 逐个破坏这两个条件, 观察训练行为; 第三步, 把分析结论反向翻译成一个新的残差单元设计, 再拿实验确认. 分析, 消融, 设计, 三段式走完, 每一步都有数字背书. 这种自我拆解的密度, 在深度学习论文里并不常见.

## 2. 分析框架: 两个 identity 条件

残差单元的一般形式只有两个式子:

$$y_l = h(x_l) + F(x_l, W_l), \quad x_{l+1} = f(y_l)$$

两式是一个单元的完整计算流程, 分两步. 第一式是合并: shortcut 支路算出 $h(x_l)$, 权重支路算出残差 $F(x_l, W_l)$, 逐元素相加得到 $y_l$. 第二式是激活: $y_l$ 经过逐元素函数 $f$, 才成为下一个单元的输入 $x_{l+1}$. 其中 $x_l$ 是第 $l$ 个单元的输入, $F$ 是残差函数 (比如两个 3x3 卷积), $h$ 是 shortcut 路径上的变换, $f$ 是逐元素加法之后的激活. ResNet 原文的选择是 $h(x_l) = x_l$ (identity shortcut), $f$ 为 ReLU. 这两个选择就是本文要审视的全部对象: $h$ 干不干净, $f$ 动不动信号.

如果 $f$ 也是 identity, 即 $x_{l+1} = y_l$, 两式合并成:

$$x_{l+1} = x_l + F(x_l, W_l)$$

对这个式子递归展开, 得到全文最重要的前向公式:

$$x_L = x_l + \sum_{i=l}^{L-1} F(x_i, W_i)$$

展开过程一步不跳. 由合并式, $x_{l+1} = x_l + F(x_l, W_l)$. 对第 $l+1$ 个单元再用一次同样的式子: $x_{l+2} = x_{l+1} + F(x_{l+1}, W_{l+1}) = x_l + F(x_l, W_l) + F(x_{l+1}, W_{l+1})$. 规律很清楚: 每往深走一个单元, 右边就多出一项残差, 而 $x_l$ 原样保留. 走到第 $L$ 层时, $x_l$ 后面跟了 $L - l$ 项残差, 求和下标 $i$ 从 $l$ 跑到 $L-1$, 正好 $L-l$ 项. 对任意深层单元 $L$ 和任意浅层单元 $l$ 成立. 它有两个直接推论. 第一, 任意深层的特征可以表示成任意浅层的特征加上一串残差之和, 模型在任意两个单元之间都保持残差形式, 而不只是相邻单元之间. 第二, 任意深层特征等于 $x_0$ 加上所有前置残差函数的输出之和. 对比一下 plain network: 忽略 BN 和 ReLU, 它的深层特征是一串矩阵连乘 $\prod_{i=0}^{L-1} W_i x_0$. 求和与连乘, 就是残差网络和普通网络全部差别的根源. 连乘对扰动是指数敏感的, 求和不是.

前向的求和结构直接带来反向的好性质. 记损失为 $E$, 对前向公式两边关于 $x_l$ 求导: 左边 $\partial x_L / \partial x_l$ 乘以深层传来的 $\partial E / \partial x_L$ 就是链式法则; 右边 $x_l$ 对自己的导数是 1, 求和项对 $x_l$ 的导数整体写在第二项里. 于是:

$$\frac{\partial E}{\partial x_l} = \frac{\partial E}{\partial x_L}\left(1 + \frac{\partial}{\partial x_l}\sum_{i=l}^{L-1} F(x_i, W_i)\right)$$

梯度被分解成两个加法项: 一项是 $\frac{\partial E}{\partial x_L}$ 本身, 不经过任何权重层, 直接从深层传回浅层; 另一项穿过权重层. 加法项里的那个 1 就是上一步求导时 $x_l$ 对自己的导数, 它保证了一个关键性质: 即使所有权重任意小, 梯度也不会消失. 因为要让梯度消失, 需要 $\frac{\partial}{\partial x_l}\sum F$ 对一个 mini-batch 里的所有样本恒等于 -1, 这在一般情况下不可能发生. 这一点和「深度网络靠初始化续命」的直觉正好相反: 在残差结构里, 梯度的下限由结构保证, 不由初始化保证.

把两个条件再强调一次. 前向公式成立需要 $h$ 是 identity (shortcut 干净), 也需要 $f$ 是 identity (加法之后不再动信号). 论文图里那些灰色箭头标的就是这条「干净路径」: 箭头上除了加法没有任何操作. 接下来两节分别破坏这两个条件, 看会发生什么.

还有一个经常被忽略的细节. 求和结构之所以稳健, 是因为单个残差函数的扰动只会以加法方式影响最终结果: 某一层 $F_i$ 输出偏了一点, $x_L$ 也只偏同样的量. 换成连乘结构, 任何一层的微小扰动都会被后面所有层依次放大或缩小, 深度越大, 累积效应越失控. 求和对扰动是线性的, 连乘对扰动是指数的, 这个差别和反向梯度里的加法项 1 是同一枚硬币的两面: 前向不放大信号, 反向不放大梯度.

需要说明推导的适用范围. 网络里还有少数几个降维增通道的单元, 那里 shortcut 必须做维度匹配, $h$ 不是 identity, 上面的递推不严格成立. 但这样的单元极少, CIFAR 上 2 个, ImageNet 上 3 个, 作者认为它们不构成指数级的影响, 可以把推导理解成「在同一个 feature map size 内部成立」.

## 3. 破坏 shortcut: 指数级的代价

先破坏 $h$. 考虑最简单的改动, 给 shortcut 乘一个标量: $h(x_l) = \lambda_l x_l$, 即

$$x_{l+1} = \lambda_l x_l + F(x_l, W_l)$$

递归展开后, 前向公式变成:

$$x_L = \left(\prod_{i=l}^{L-1}\lambda_i\right) x_l + \sum_{i=l}^{L-1}\hat{F}(x_i, W_i)$$

其中 $\hat{F}$ 把标量吸收进了残差函数. 展开逻辑和第 2 节一样, 只是这次每往深走一层, 浅层特征 $x_l$ 就要多乘一个 $\lambda_i$, 走 $L - l$ 层乘 $L - l$ 个, 于是 $x_l$ 前面出现连乘因子. 反向传播里, 原来那个干净的加法项 1 变成了连乘因子 $\prod_{i=l}^{L-1}\lambda_i$. 对一个极深的网络, 如果所有 $\lambda_i > 1$, 这个因子指数级变大, 梯度爆炸; 如果所有 $\lambda_i < 1$, 它指数级缩小, shortcut 路径上的梯度信号被掐死, 信息被迫全部走权重路径, 优化困难重新出现. 代两组数感受指数级的意思: 本节实验的 ResNet-110 有 54 个残差单元, 若每个 shortcut 都乘 $\lambda = 0.5$, 连乘因子是 $0.5^{54} \approx 5.6 \times 10^{-17}$, 干净路径上的梯度被压到近乎为零; 若每个都乘 $\lambda = 1.1$, 只比 1 大一点点, 连乘出来是 $1.1^{54} \approx 172$, 放大近三个数量级. 更复杂的 shortcut 变换 (门控, 1x1 卷积) 会让第一项变成 $\prod h'_i$, 其中 $h'$ 是 $h$ 的导数, 问题只会更糟.

理论说完了, 上实验. 基线是 CIFAR-10 上的 ResNet-110, 54 个两层残差单元, 测试误差 6.61%, 所有数字取 5 次运行的中位数. 五种破坏方式的结果:

**常数缩放.** 所有 shortcut 乘 $\lambda = 0.5$. 如果 $F$ 不缩放, 网络不收敛 (测试误差高于 20% 记为 fail). 如果 $F$ 也乘 $1-\lambda = 0.5$ (相当于冻结门控的 Highway), 能收敛, 但测试误差 12.35%, 接近基线的两倍, 而且训练误差也明显更高, 说明瓶颈在优化不在拟合.

**互斥门控 (exclusive gating).** 沿用 Highway Networks 的设计: 门函数 $g(x) = \sigma(W_g x + b_g)$ 由 1x1 卷积加 sigmoid 实现, $F$ 路径乘 $g(x)$, shortcut 路径乘 $1-g(x)$. 结果对偏置初始化极度敏感: 作者按 Highway 论文的指引, 把 $b_g$ 初值从 0 到 -10 以步长 -1 做网格搜索, 0 到 -5 全部 fail, 只有 -6 给出 8.70%, -7 给出 9.81%. 最好的结果仍然比 6.61% 的基线差两个百分点. 一个架构需要把偏置精确调到 -6 才能训得动, 这件事本身就是病灶.

**仅 shortcut 门控 (shortcut-only gating).** 为了隔离门控对 shortcut 的单独影响, 这次 $F$ 不缩放, 只有 shortcut 乘 $1-g(x)$. $b_g$ 初值为 0 时 (1-g 期望约 0.5) 误差 12.86%; 初值 -6 时, $1-g(x)$ 接近 1, shortcut 近似 identity, 误差回落到 6.91%, 几乎追平基线. 越接近 identity 越好, 这是对分析最直接的实验确认.

**1x1 卷积 shortcut.** 用 1x1 卷积替换 identity, 误差 12.22%. 这个结果有历史反讽意味: ResNet 原文在 34 层网络上试过同样方案 (option C), 当时效果不错, 还建议过它可能有用. 差别只在深度: 34 层只有 16 个残差单元, 110 层有 54 个. 单元堆多了, 连最短的传播路径都会变成障碍. ImageNet 上的 ResNet-101 也观察到同样现象.

**dropout shortcut.** 在 identity shortcut 的输出上加 dropout (比例 0.5), 直接 fail. 原因很干净: dropout 在统计上就是给 shortcut 乘了一个期望 0.5 的随机缩放, 和常数缩放 0.5 同一死因.

五种破坏, 无一例外, 全部比 identity 差. 训练曲线还透露了第二层信息: 常数缩放, 门控, 1x1 卷积三个方案的训练误差都比基线高, 也就是模型连训练集都拟合不动, 这是优化困难的直接证据, 而不是泛化问题. 互斥门控还有一个双重困境值得单独说: 当 $1-g(x)$ 接近 1 时, shortcut 接近 identity, 传播顺畅, 但此时 $g(x)$ 接近 0, 残差函数 $F$ 被压制, 网络退化成一条浅通路; 反过来 $g(x)$ 大了, shortcut 又被掐. 两个目标互相打架, 这就是为什么它需要把偏置精确调到 -6 才能勉强工作.

另外要注意, 这一节的所有实验里 $f$ 仍然是 ReLU, 和 ResNet 原文一致. 所以第 2 节的公式在这里只是近似成立, 消融结论的方向性可信, 但严格性要等下一节把 $f$ 也变成 identity 才算闭环.

论文的讨论部分点出了最关键的一层: 门控和 1x1 卷积引入了更多参数, 表达能力严格强于 identity shortcut, 它们的解空间甚至包含 identity (门控可以学成常开, 1x1 卷积可以学成单位阵). 但它们的训练误差比 identity 更高. 也就是说, 退化不是表达能力不够, 是优化器到不了那个更好的解. 这等于用受控消融把 ResNet 原文的 degradation problem 重新证明了一遍, 而且这次因果链是闭合的.

## 4. 激活函数搬家: pre-activation

第二刀砍 $f$. 第 3 节的实验里 $f$ 一直是 ReLU, 所以前面的分析只是近似成立. 这一节要让 $f$ 真正变成 identity, 办法是重新排列 BN 和 ReLU 的位置. 作者试了五种排列, 组件完全相同, 只有顺序不同:

- **original** (Conv-BN-ReLU-Conv-BN-加法-ReLU): ResNet-110 误差 6.61%, ResNet-164 误差 5.93%.
- **BN after addition**: 把 BN 挪到加法之后, 误差涨到 8.17% / 6.50%. BN 改变了从 shortcut 传过来的信号, 干净路径又被污染, 训练初期 loss 降不下去.
- **ReLU before addition**: 把最后一个 ReLU 挪到加法之前, 误差 7.84% / 6.14%. 这样 $f$ 确实是 identity 了, 但残差函数 $F$ 的输出被 ReLU 压成非负, 前向信号单调递增. 一个「残差」理应取遍 $(-\infty, +\infty)$, 表达能力受损.
- **ReLU-only pre-activation**: ReLU 挪到卷积之前, BN 留在卷积之后, 误差 6.71% / 5.91%, 和基线基本持平. 但这个 ReLU 没有和 BN 配对, 享受不到 BN 的好处.
- **full pre-activation** (BN-ReLU-Conv 顺序, BN 和 ReLU 都挪到卷积之前): 误差 6.37% / 5.46%, 全部最好.

为什么把激活挪到卷积前面是合法的? 论文给了一个等价性论证. 原设计里, 加法后的激活 $f$ 同时影响下一个单元的两条路径: $y_{l+1} = f(y_l) + F(f(y_l), W_{l+1})$. 现在改成不对称形式, 让激活 $\hat{f}$ 只作用于 $F$ 路径: $y_{l+1} = y_l + F(\hat{f}(y_l), W_{l+1})$. 重命名记号之后得到:

$$x_{l+1} = x_l + F(\hat{f}(x_l), W_l)$$

和 §2 的合并式 $x_{l+1} = x_l + F(x_l, W_l)$ 对照, 唯一的差别是残差函数的输入从 $x_l$ 变成了 $\hat{f}(x_l)$: 激活没有消失, 只是搬了家, 从「加法之后」搬到「卷积之前」. shortcut 项 $x_l$ 干干净净, 加法之后不再有任何操作. 这个式子和前向公式的形状一模一样, 新的 after-addition 激活变成了 identity, 第 2 节的干净推导全部复活. 换句话说, 「加法之后只做不对称激活」和「把激活挪到下一个单元的卷积之前」是同一件事的两种说法. 论文用一张三连图展示了这个变换过程: 先把加法后的激活改成只作用于权重路径, 再把这个激活重命名为下一个单元的 pre-activation, 两次操作都不改变网络计算的函数, 只改变看它的视角.

post-activation 和 pre-activation 的对立之所以存在, 完全是因为有逐元素加法在合并分支: 对一个没有分支的 plain network, $N$ 层有 $N-1$ 个激活, 说它们是 post 还是 pre 没有区别; 一旦有了 shortcut, 激活的位置就成了真问题. 还有一个次要的观察: ReLU-only pre-activation 之所以只能和基线打平, 是因为它把 ReLU 单独挪到了卷积前面, 脱离了 BN 的配对, 享受不到归一化带来的训练加速. BN 和 ReLU 一起搬, 收益才真正出现.

工程上有一个容易踩的坑: 用 pre-activation 单元搭完整网络时, 第一个和最后一个残差单元要特殊处理. 第一个单元之前, 在 conv1 之后, 分叉之前补一个激活; 最后一个单元之后, 在加法之后, 全局池化之前补一个激活. 这两处是从 post-activation 网络等价变换到 pre-activation 网络时的自然产物, 漏掉它们等于首尾两处的 $f$ 又没处理干净.

## 5. 1001 层: 深度红利还没吃完

把 full pre-activation 单元装上各种深度的网络, 和原版逐对对比 (CIFAR 测试误差, 5 次中位数):

- CIFAR-10: ResNet-110 从 6.61% 降到 6.37%; ResNet-164 从 5.93% 降到 5.46%; ResNet-1001 从 7.61% 降到 4.92%. 还有一个每个 shortcut 只跨 1 层的 ResNet-110 变体, 从 9.90% 降到 8.91%.
- CIFAR-100: ResNet-164 从 25.16% 降到 24.33%; ResNet-1001 从 27.82% 降到 22.71%, 五个点的差距.

最有说服力的对照藏在和旧结果的比较里. ResNet 原文当年试过 1202 层的原版网络 (19.4M 参数), CIFAR-10 误差 7.93%, 比 110 层的 6.61% 还差, 当时只能解释为过拟合, 结论是「这么深没必要」. 而本文 pre-activation 版的 ResNet-1001 只有 10.2M 参数, 误差 4.92% (batch size 64 时 4.62%). 深度从 1202 层的「太多」变成 1001 层的「正好」, 模型还更小, 区别只在残差单元内部的排列顺序.

和当时 SOTA 的横向对比也值得看. CIFAR-10 上, NIN 8.81%, FitNet 8.39%, Highway 7.72%, All-CNN 7.25%, ELU 6.55%, FitResNet 加 LSUV 初始化 5.84%. pre-activation 版 ResNet-164 用 1.7M 参数做到 5.46%, ResNet-1001 用 10.2M 参数做到 4.92%. 作者特意强调, 这些结果没有用 dropout, 没有针对小数据集调宽度和卷积核尺寸, 只用了翻转和平移这种温和的数据增强. 收益全部来自一个概念: 走得更深. CIFAR-100 上, 原版 ResNet-1001 的 27.82% 同样不如自家浅模型, pre-activation 版的 22.71% 则反超当时所有对照方法 (ELU 24.28%, FitNet+LSUV 27.66%).

表 3 里还有一组容易被略过的数字: 每个 shortcut 只跨 1 层的 ResNet-110 变体, 原版 9.90%, pre-activation 版 8.91%. 它说明 shortcut 跨几层不是关键变量, 单元内部的路径干不干净才是. 同样的层数, 同样的参数, 只是改变 BN 和 ReLU 的位置, 就能挤出一个点的误差.

pre-activation 为什么赢, 作者拆成两个机制. 第一是优化更容易, 这在 1001 层上最明显: 原版设计里 $f$ = ReLU 会截断负信号, 层数少时无所谓, 因为训练一段时间后权重会自适应, 让 $y_l$ 大多数时候为正 ($x_l$ 被前一个 ReLU 压成非负, $y_l$ 为负只发生在 $F$ 的负值特别大时); 但 1000 层堆起来, 截断频繁发生, 前向公式和反向公式的近似失效, 训练初期 loss 降得极慢. pre-activation 版的 ResNet-1001 训练 loss 快速下降, 而且达到了作者试过的所有模型里最低的训练 loss, 优化本身完全成功.

第二是正则变强. 一个反直觉的现象: pre-activation 版本收敛时的训练 loss 略高, 测试误差却更低, 在 ResNet-110, ResNet-110(1-layer), ResNet-164, CIFAR-10 和 CIFAR-100 上全部观察到. 作者的解释是 BN 的位置. 原版单元里, BN 归一化后的信号立刻被加回未归一化的 shortcut, 合并后的信号是未归一化的, 直接进了下一层卷积. pre-activation 版里, 所有卷积层的输入都先经过 BN 归一化. BN 顺带承担了正则化器的角色.

ImageNet 上的结果补完了最后一块. 作者先用 ResNet-101 试了第 3 节那几种 shortcut, 训练误差在第一个学习率阶段就明显更高, 因为算力有限直接中止. BN after addition 版本跑完了, single-crop 验证误差 24.6%/7.5%, 比原版 ResNet-101 的 23.6%/7.1% 差, 和 CIFAR 上的观察一致. 主结果在 320x320 single-crop 下: ResNet-152 从 21.3%/5.5% 微调到 21.1%/5.5%, 收益小, 因为 152 层本来就没有泛化困难. 原版 ResNet-200 是 21.8%/6.0%, 比 ResNet-152 还差, 但训练误差更低, 教科书式的过拟合. pre-activation 版 ResNet-200 降到 20.7%/5.3%, 比两个版本的 ResNet-152 都好; 加上 scale 和 aspect ratio 增强后达到 20.1%/4.8%, 超过 Inception v3 的 21.2%/5.6%. 同期的 Inception-ResNet-v2 报出 19.9%/4.9%, 作者大方承认并指出自己的残差单元可以帮到这类混合架构.

成本方面, 计算复杂度随深度线性增长, 1001 层就是 100 层的十倍. CIFAR 上 ResNet-1001 在 2 张 GPU 上训 27 小时; ImageNet 上 ResNet-200 在 8 张 GPU 上训约 3 周, 和当年的 VGG 同级. 训练细节里还有一个彩蛋: 原版 CIFAR 实验需要前 400 步用 0.01 的小学习率 warm-up 才能稳定, pre-activation 单元不需要这个 warm-up. 结构对了, 连训练技巧都可以省.

把第 5 节的结果放在一起看, 能得到一个比单个数字更有价值的判断: 深度本身从来不是敌人, 对深度的错误使用才是. 原版单元里, 深度放大的是 ReLU 截断和未归一化信号的累积效应, 所以 1202 层反而更差; pre-activation 单元里, 深度放大的只是残差函数的堆叠, 所以 1001 层还在涨点. 同一个变量, 放大什么, 取决于单元内部的路径设计. 这也是全文的总结论: 信息路径越干净, 深度这个维度的红利吃得越彻底.

## 6. 局限与后续影响

论文自己的局限说得相当诚实. 第一, 第 2 节的递推推导只对同一个 feature map size 内的残差单元严格成立; 降维增通道的地方用的是 projection shortcut, 那里的 $h$ 不是 identity. 好在这样的单元极少, CIFAR 上 2 个, ImageNet 上 3 个, 不构成指数级的影响. 第二, 全部实验都是 CNN 加图像分类, 没有验证检测, 分割, 或其他模态. 第三, 「干净路径有利于优化」是经验结论加启发式分析, 不是带泛化界的定理. 梯度不消失的论证也只是「不太可能对一个 mini-batch 恒为 -1」这种概率性陈述.

还有一个论文没有明说但值得点出的边界. pre-activation 的收益和深度强相关: ResNet-110 上只有 0.24 个点的提升, ResNet-152 上 0.2 个点, 真正的鸿沟出现在 1001 层和 200 层. 浅网络里 $f$ = ReLU 的截断效应会被权重自适应吸收, 双 identity 条件不成立也无所谓. 这意味着把 pre-activation 当万灵药是没有必要的, 它是一张深度越大越值钱的牌. 后来 LLM 的层数从几十层涨到上百层, pre-norm 的相对收益变大, 和这里是同一个规律.

后续影响远超论文本身的范围. pre-activation 残差单元以 ResNet v2 的名义成为后续视觉模型的标准件, 同年提出的 Wide ResNet 证明宽度方向同样有利可图, 用的正是这套 pre-activation 单元; Stochastic Depth 用随机丢弃整层的方式训练了 1202 层网络, 可以看作对「干净路径」的另一种保护. DenseNet 把加法换成拼接, 同样保证任意层到任意层的信息直达, 是同一思想的不同实现. 影响最深的一条线在 Transformer 里: 每个子层都有残差连接, LayerNorm 放在子层之前 (pre-norm) 还是之后 (post-norm), 就是本文 BN 位置问题的直接延续. 原始 Transformer 用 post-norm, 深层训练需要 warm-up; GPT-2 起 pre-norm 成为标配; Xiong et al. 2020 的分析证明 pre-norm 下梯度可以不依赖学习率 warm-up 直接回传, 说穿了, 就是把本文的反向公式搬到了 LayerNorm 上. 本文那句「warm-up 对 pre-activation 单元不是必须的」, 五年后在 Transformer 训练里完整重演了一遍.

## 7. 在本系列本站学习路线中的位置

本站学习路线 `1.2.1` AlexNet 打开了深度学习的时代, 路线 `1.2.2` ResNet 把网络深度推到 152 层, 路线 `1.2.3` 解释残差为什么有效并把深度推到 1001 层. 三篇构成一条完整的「深度」主线: 证明深有用, 解决深不了, 解释为什么解决了.

路线 `1.2.3` 更持久的遗产是那套分析框架本身. 双 identity 条件, 前向求和, 反向加法项 1, 干净路径, 这组概念后来成为理解一切残差架构的标准工具. 看到任何一个带 skip connection 的结构, 第一反应是问两个问题: shortcut 路径上有没有多余的操作, 加法之后有没有多余的激活. 从 ResNet v2 到 pre-norm Transformer, 再到各种去归一化的训练方案 (Fixup, SkipInit, ReZero), 全都在回答这两个问题的变体. 一篇 2016 年的消融实验论文, 把之后十年深度网络架构设计的检查本站学习路线提前写好了.

放在本站学习路线里看, 这篇还有一层方法论示范. 从复杂度、信息论一路读到 AlexNet 和 ResNet，持续追问的是“哪些结构让学习更容易”。路线 `1.2.3` 的核心证据是：保持捷径为恒等映射、改善信息与梯度传播，比给捷径增加复杂变换更有效。它与后续架构的简化思路可以比较，但不能据此写成直接因果谱系。
