# AlexNet: 两块 GTX 580, 6000 万参数, 深度学习革命的引爆点

> 原始论文: Alex Krizhevsky, Ilya Sutskever, Geoffrey E. Hinton, "ImageNet Classification with Deep Convolutional Neural Networks", NIPS 2012.
> https://papers.nips.cc/paper/4824-imagenet-classification-with-deep-convolutional-neural-networks
> 这是 Ilya 推荐 30 篇清单的第 6 篇, 也是清单的转折点. 前 5 篇全是理论: 复杂度, 随机性, 智能的定义. 从这篇开始, 清单一头扎进工程. 而且这是 30 篇里唯一一篇 Ilya 本人署名的工程论文, 他是二作.

**全文符号表**

本文只有三条公式, 全是工程公式 (归一化, 数据增强, 优化器), 记号沿用原论文. 先一次性登记, 正文第一次出现时还会再讲一遍.

| 符号 | 含义 |
|------|------|
| $(x, y)$ | 特征图上的空间位置坐标, 出现在 §4 LRN 公式里 |
| $f(x) = \max(0, x)$ | ReLU 激活函数, 这里的 $x$ 是标量输入, 与上面的位置坐标是两回事, 靠上下文区分 |
| $a^i_{x,y}$ | 第 $i$ 个卷积核 (即第 $i$ 张特征图) 在空间位置 $(x, y)$ 处经过 ReLU 后的激活值, 上标是特征图编号, 下标是空间位置 |
| $b^i_{x,y}$ | $a^i_{x,y}$ 经过局部响应归一化 (LRN) 之后的输出值 |
| $N$ | 该层的特征图总数 (卷积核个数) |
| $n$ | 参与归一化的相邻特征图个数, 论文取 $n=5$ |
| $\alpha$ (LRN) | LRN 的缩放超参数, 论文取 $\alpha = 10^{-4}$. **注意**: §5 PCA 公式里还有另一个 $\alpha_i$ (高斯随机变量), 两个 $\alpha$ 同名, 靠下标和章节区分, 这是原论文的记号 |
| $k, \beta$ | LRN 的另外两个超参数, 论文取 $k=2$, $\beta=0.75$. $\beta$ 是分母上的指数, 控制归一化的软硬程度 |
| $j$ | 求和下标, 遍历第 $i$ 张特征图前后各 $n/2$ 张相邻特征图的编号 |
| $p_1, p_2, p_3$ | 训练集 RGB 像素值协方差矩阵的三个特征向量 (主成分方向), 每个是 3 维向量 |
| $\lambda_1, \lambda_2, \lambda_3$ | 对应的三个特征值, 数值越大说明像素值沿该方向的波动越大 |
| $\alpha_1, \alpha_2, \alpha_3$ | 三个独立的高斯随机变量, 均值 0, 标准差 0.1, 每张图每次训练重抽一次 |
| $w_i$ | 第 $i$ 步迭代时的网络权重. **注意**: 这里的下标 $i$ 是迭代步数, 与 §4 特征图编号 $i$ 同名, 靠章节区分 |
| $v_i$ | 第 $i$ 步的动量项 (velocity), 记录历史梯度的指数滑动累积 |
| $\epsilon$ | 学习率, 初始 0.01 |
| $L$ | 训练损失 (多项逻辑回归损失) |
| $\left.\dfrac{\partial L}{\partial w}\right\vert_{w_i}$ | 损失对权重的梯度, 在 $w_i$ 处取值. 竖线加下标读作「在...处求值」 |
| $\langle \cdot \rangle_{D_i}$ | 对第 $i$ 步的 mini-batch $D_i$ (128 张图) 求平均. 尖括号表示平均, 下标是平均的范围 |
| $:=$ | 定义为, 在更新规则里读作「更新为」 |

**读公式的方法**: 三条公式各管一件事. §4 LRN 公式读「谁被谁归一化」: 分子是激活本身, 分母是邻居激活的平方和, 作用是同位置不同特征图互相压制. §5 PCA 公式读「沿哪个方向抖, 抖多大」: 特征向量给方向, 特征值给幅度, 高斯变量给随机性. §6 动量公式读「新速度由哪三部分组成」: 旧速度保留九成, 权重衰减往回拉, 梯度往外推.

## 1. 2012 年之前: 手工特征的旧世界

要理解 AlexNet 的冲击力, 先看它之前的世界长什么样. 2012 年以前的计算机视觉, 主流范式是手工特征加浅层分类器. 研究者花几年时间设计特征提取器, 比如 SIFT, 在图像里找关键点, 计算梯度方向直方图, 再把特征喂给 SVM 或 Fisher Vector 分类器. 整个流程里, 唯一被「学习」的部分是最后那个分类器, 前面所有表示都是人手工设计的.

这条路线在 2010 年前后撞上了天花板. ILSVRC-2010 的冠军成绩是 top-1 错误率 47.1%, top-5 错误率 28.2%, 用的是六个稀疏编码模型的集成. 之后发表的最好结果是 45.7% 和 25.7%, 用的是两种密集采样特征上的 Fisher Vector. 进步以每年一两个百分点的速度爬行, 而且每一点进步都靠更复杂的特征工程堆出来.

与此同时, 神经网络处在一个尴尬的位置. LeCun 的卷积网络 1989 年就能识别手写数字, 但二十多年来, 它始终没能在自然图像上证明自己. 主流观点有三条: 第一, 深层网络训练不动, 梯度会消失; 第二, 数据不够, 几百万张标注图片不存在; 第三, 算力不够, CPU 训不动大网络. 这三条在 2012 年同时被推翻了, 推翻它们的就是这篇论文.

还有一条暗线值得交代. Hinton 实验室从 2006 年起一直坚持深度信念网络和逐层预训练路线, 这是当时「深度能训动」的少数证据之一. 但 AlexNet 恰恰放弃了无监督预训练, 论文里明说: 为了简化实验, 没有使用任何无监督预训练. 纯监督, 纯反向传播, 从头训到尾. 这个选择本身也是一个信号: 预训练只是数据和算力不足时的拐杖, 拐杖可以扔掉了.

## 2. ImageNet: 一百万张图的问题定义

AlexNet 的战场是 ILSVRC, ImageNet Large-Scale Visual Recognition Challenge. ImageNet 全集有超过 1500 万张人工标注的高分辨率图片, 约 22000 个类别, 标注靠 Amazon Mechanical Turk 众包完成. ILSVRC 取其中一个子集: 1000 个类别, 每类约 1000 张图, 总共约 120 万张训练图, 5 万张验证图, 15 万张测试图.

这个规模在当时是断档的. 之前常用的 Caltech-101, CIFAR-10 都是几万张小图的量级. 论文里有一句很直接的判断: 简单任务用小数据集就能解决, MNIST 的最好错误率已经低于 0.3%, 逼近人类水平. 但真实世界里的物体变化太大, 光照, 姿态, 遮挡, 背景, 要认出它们必须用大得多的训练集. ImageNet 就是第一个大到够用的数据集.

评测指标有两个: top-1 和 top-5 错误率. top-5 指的是模型认为最可能的 5 个标签里没有正确标签的比例. 图片预处理被刻意做到极简: 把短边缩放到 256, 裁出中心 256x256, 再减去训练集上的像素均值, 仅此而已. 网络直接吃原始 RGB 像素值. 没有手工特征, 没有预处理流水线, 这是一切的起点, 也是一切的终点: 从像素到标签, 端到端.

这里有一个经常被人忽略的视角. 120 万张图, 每张图提供 1000 类里的一个标签, 信息量约 10 bit. 全部标签信息加起来约 1200 万 bit. 而网络有 6000 万个参数. 论文第 4 节开头自己点破了这个张力: 每张训练样本只对映射施加 10 bit 的约束, 这远远不够约束这么多参数, 过拟合是头号敌人. AlexNet 的一半技术贡献, 都是围绕这个矛盾展开的.

## 3. 网络结构: 八层, 6000 万参数

AlexNet 一共 8 个带权重的层: 5 个卷积层, 3 个全连接层. 全网络 6000 万参数, 65 万个神经元. 输入是 224x224x3 的图像, 即 150528 维. 各层神经元数量依次是 253440, 186624, 64896, 64896, 43264, 4096, 4096, 1000.

第一层卷积用 96 个 11x11x3 的卷积核, 步长 4, 这是全网络最激进的一步: 大步长意味着第一层就把空间分辨率砍掉四分之三, 换来后续层的计算量可控. 第二层 256 个 5x5x48 的核, 第三层 384 个 3x3x256, 第四层 384 个 3x3x192, 第五层 256 个 3x3x192. 注意第三, 四, 五层之间没有任何池化或归一化, 三个卷积层直接堆叠, 这是后来 VGG 把所有卷积核统一成 3x3 的先声.

池化只出现在三个位置: 第一, 二, 五个卷积层之后. 局部响应归一化只在第一, 二个卷积层之后. ReLU 作用在每一个卷积层和全连接层的输出上. 三个全连接层各有 4096 个神经元, 最后一层接 1000 路 softmax. 优化目标是多项逻辑回归, 等价于最大化正确标签的平均对数概率.

为什么选卷积网络而不是全连接网络? 论文给出的理由今天依然是 CNN 教科书的第一页: 卷积对图像性质做了两个强而基本正确的假设, 统计量的平稳性 (同一个特征检测器在任何位置都有用) 和像素依赖的局部性 (近处像素相关, 远处像素弱相关). 这两个假设让 CNN 在同等层大小下, 连接数和参数远少于全连接网络, 更容易训练, 而理论上的最佳性能只差一点. 换句话说, 卷积是一种「正确偏见」, 用先验知识换样本效率. 这个思想和清单前几篇一脉相承: 结构不是随机性的敌人, 是随机性的压缩.

深度有多重要, 论文做了一个干净的消融: 拿掉任何一个中间卷积层, top-1 性能损失约 2%. 而每个卷积层的参数量不到全模型的 1%. 占参数大头的全连接层动不得, 占参数零头的卷积层也动不得. 「深度真的重要」这句话, 在 2012 年是需要实验来证明的, 今天已经是空气一样的常识.

## 4. 四个工程选择: 让怪物跑得动

论文第 3 节按重要性排序, 列了四个架构上的「新或不寻常」的选择. 这四条里没有一条是数学上的新理论, 全是工程判断, 但缺了任何一条, 这个网络在当时都训不出来.

**第一条, ReLU.** 传统神经元用 tanh 或 sigmoid 这类饱和非线性, 输入一大梯度就趋于零. ReLU 用 $f(x) = \max(0, x)$, 正半轴梯度恒为 1, 不会饱和. 论文在 CIFAR-10 上做了对照: 一个四层卷积网络达到 25% 训练错误率, 用 ReLU 比用 tanh 快约 6 倍. 这个数字是整个深度学习的加速器: 训练时间从按月算变成按天算, 实验迭代速度直接决定了一个实验室能试多少个想法. 论文原话是, 如果用传统的饱和神经元, 就不可能用这么大的网络做这项工作的实验.

**第二条, 双 GPU 训练.** 一块 GTX 580 只有 3GB 显存, 装不下这个网络. 解决方案是把网络劈成两半, 每块 GPU 放一半的卷积核, 只在特定层通信. 具体来说, 第 3 层卷积核读取第 2 层的全部特征图, 但第 4 层只读同一块 GPU 上的第 3 层特征图. 通信量可以被精确调节到计算量的一个可接受比例. 这套方案不是免费的并行, 它带来了精度收益: 相比单 GPU 上核数减半的网络, top-1 和 top-5 错误率分别降了 1.7% 和 1.2%, 训练时间还略短. 两块显卡直连内存, 不经过主机内存, 这是当时 GTX 580 的一个硬件特性, 被他们用到了刀刃上.

**第三条, 局部响应归一化 (LRN).** 公式是:

$$b^i_{x,y} = \frac{a^i_{x,y}}{\left(k + \alpha \sum_{j=\max(0,\,i-n/2)}^{\min(N-1,\,i+n/2)} (a^j_{x,y})^2\right)^{\beta}}$$

逐块拆开. 分子 $a^i_{x,y}$ 是第 $i$ 张特征图在位置 $(x, y)$ 的激活值, 就是被归一化的对象本身. 分母里的求和遍历第 $i$ 张特征图前后各 $n/2$ 张相邻特征图, 取它们在同一个空间位置 $(x, y)$ 的激活值平方, 加起来. 求和上下限的 $\max(0, \cdot)$ 和 $\min(N-1, \cdot)$ 是边界截断: 靠近第 0 张或第 $N-1$ 张特征图时, 邻居不够 $n$ 张, 有几张算几张. 平方的作用是只看激活的大小不看正负, 避免正负激活互相抵消. $\alpha$ 把平方和缩放到合适的量级, $k$ 防止分母太小导致除法爆炸, 整个括号再取 $\beta$ 次方, $\beta < 1$ 让归一化比标准除法更软. 代一组数看求和范围: 该层 $N = 96$ 张特征图, $n = 5$, 对 $i = 10$ 的特征图, 求和范围是 $j = 8$ 到 $12$, 共 5 张邻居; 对边界上的 $i = 0$, 范围被截成 $j = 0$ 到 $2$, 只有 3 张.

其中 $a^i_{x,y}$ 是第 $i$ 个卷积核在位置 $(x,y)$ 处经过 ReLU 后的激活, 求和在空间同一位置的 $n$ 个相邻特征图上进行. 超参数取 $k=2$, $n=5$, $\alpha=10^{-4}$, $\beta=0.75$. 灵感来自真实神经元的侧抑制: 不同卷积核的输出在同一个空间位置上互相竞争, 大的激活被邻居压下去. 收益是 top-1 降 1.4%, top-5 降 1.2%. 在 CIFAR-10 上验证过: 四层 CNN 加 LRN, 测试错误率从 13% 降到 11%.

**第四条, 重叠池化 (overlapping pooling).** 传统池化的窗口不重叠, 比如步长 2, 窗口 2x2. AlexNet 用步长 2, 窗口 3x3, 相邻池化单元有重叠. 输出维度不变, top-1 和 top-5 分别降 0.4% 和 0.3%, 训练中过拟合也略有缓解. 收益最小的一条, 但几乎零成本.

把这四条放在一起看, 一个规律浮现出来: 收益和通用性成反比. ReLU 快 6 倍, 活到今天, 几乎是所有网络的默认激活. 双 GPU 是模型并行的雏形, 后来演变成整个分布式训练学科. LRN 收益 1.4%, 两年后被 BatchNorm 全面取代, 今天已经没人用了. 重叠池化收益 0.4%, 属于时代细节. 一篇论文里最被低估的部分, 往往预言了未来; 最精雕细琢的部分, 往往最先过期.

## 5. 对抗过拟合: 数据增强与 dropout

6000 万参数对 120 万张图, 过拟合是生死问题. 论文用了两类武器.

**第一类是数据增强, 两种形式, 都在 CPU 上用 Python 实时生成, GPU 在训上一个 batch, CPU 在造下一个 batch 的数据, 计算上等于免费.**

第一种形式是裁剪加翻转: 从 256x256 的图里随机裁 224x224 的块, 再做水平翻转. 理论裁切位置有 32x32=1024 种, 乘上翻转, 训练集等效扩大 2048 倍. 当然这些样本高度相关, 不是真的 2048 倍新数据. 但没有这招, 网络会严重过拟合, 被迫用小得多的网络. 测试时裁 5 个块 (四角加中心) 加各自翻转, 共 10 个块, softmax 预测取平均.

第二种形式更巧妙: PCA 颜色抖动. 对整个训练集的 RGB 像素值做 PCA, 得到 3x3 协方差矩阵的特征向量 $p_i$ 和特征值 $\lambda_i$. 每张训练图的每个像素加上:

$$[p_1, p_2, p_3] \begin{bmatrix} \alpha_1\lambda_1 \\ \alpha_2\lambda_2 \\ \alpha_3\lambda_3 \end{bmatrix} \;=\; \alpha_1\lambda_1 p_1 + \alpha_2\lambda_2 p_2 + \alpha_3\lambda_3 p_3$$

左边是原论文的矩阵写法: 行向量 $[p_1, p_2, p_3]$ 装三个特征向量, 列向量装三个随机系数, 矩阵乘法展开就是右边三个向量相加. 三项各自负责什么: $p_i$ 给出抖动方向 (第 $i$ 个主成分), $\lambda_i$ 给出该方向上的天然波动幅度 (特征值越大, 像素值沿这个方向变化越剧烈, 抖动就该越大), $\alpha_i$ 给出这次的随机程度. 每个像素加的是同一个 3 维 RGB 偏移向量, 效果是整幅图的颜色和亮度被随机推了一下, 方向限定在自然图像真实会发生的光照变化上.

其中 $\alpha_i$ 是均值为 0, 标准差 0.1 的高斯随机变量, 每张图每次训练时重抽一次. 这招抓住的是自然图像的一个重要性质: 物体身份不随光照强度和颜色的变化而改变. 沿主成分方向抖动, 就是模拟「换一个光源」. 收益是 top-1 降超过 1%. 一个 PCA, 三行公式, 换 1 个点, 这是全论文性价比最高的技巧之一.

**第二类武器是 dropout.** 模型集成是降低测试错误的标准做法, 但对一个要训五六天的网络, 集成太贵. dropout 是 Hinton 团队 2012 年刚提出的廉价版集成: 训练时以 0.5 的概率把每个隐藏神经元的输出置零, 被置零的神经元不参与前向也不参与反向. 每次前向都采样出一个不同的子网络, 所有子网络共享权重. 效果是神经元不能依赖特定同伴的存在, 被迫学习在任意随机子集配合下都有用的鲁棒特征, 论文称之为减少「复杂的协同适应」. 测试时所有神经元都启用, 输出乘 0.5, 近似于对指数多个子网络的预测分布取几何平均.

dropout 只用在前两个全连接层, 因为参数主要集中在那里. 代价是收敛所需迭代数大约翻倍. 没有 dropout, 网络表现出严重的过拟合. 把数据增强和 dropout 放在一起看: 一个从数据侧把 120 万张图变成 24 亿个「视图」, 一个从模型侧把 1 个网络变成指数个子网络的平均, 两边同时挤压过拟合的生存空间.

## 6. 训练细节: 90 个 epoch, 五到六天

优化器是带动量的随机梯度下降: batch 128, 动量 0.9, 权重衰减 0.0005. 更新规则是:

$$v_{i+1} := 0.9 \cdot v_i - 0.0005 \cdot \epsilon \cdot w_i - \epsilon \cdot \left\langle \frac{\partial L}{\partial w}\Big|_{w_i} \right\rangle_{D_i}, \qquad w_{i+1} := w_i + v_{i+1}$$

第一条式子算新速度, 由三项组成. $0.9 \cdot v_i$ 是动量: 保留旧速度的九成, 让更新方向有惯性, 不会被单个 batch 的噪声带偏. $0.0005 \cdot \epsilon \cdot w_i$ 是权重衰减: 把权重往零的方向拉一小步, 拉住权重不要无限变大. $\epsilon \cdot \langle \partial L / \partial w \rangle_{D_i}$ 是梯度步: $\partial L / \partial w$ 是损失对权重的梯度, 竖线下标 $w_i$ 表示在当前权重处求值, 尖括号 $\langle \cdot \rangle_{D_i}$ 表示对这一步的 mini-batch $D_i$ (128 张图) 求平均, 负号表示沿让损失减小的方向走, $\epsilon$ 控制步长. 第二条式子把新速度加到权重上, 完成一步更新. 注意权重是跟着速度走, 不是跟着梯度走, 这就是「动量」两个字的全部机制.

代一组数看三项的量级. 设当前 $v_i = 0$, $w_i = 1$, 学习率 $\epsilon = 0.01$, batch 平均梯度为 $0.5$. 动量项贡献 $0.9 \times 0 = 0$; 权重衰减项贡献 $-0.0005 \times 0.01 \times 1 = -0.000005$; 梯度项贡献 $-0.01 \times 0.5 = -0.005$. 新速度 $v_{i+1} = -0.005005$, 新权重 $w_{i+1} = 1 - 0.005005 \approx 0.995$. 权重衰减比梯度小三个数量级, 但每一步都在拉, 长程效果不可忽略, 这就是下面那个反常识细节的来源.

有一个细节反常识: 论文说这么小的权重衰减对模型学习很重要, 它在这里不只是正则项, 而是能降低训练误差. 权重衰减让训练集表现变好, 这句话在正则化教科书里找不到, 但在大规模训练里真实存在.

权重初始化是零均值, 标准差 0.01 的高斯. 第 2, 4, 5 个卷积层和两个全连接隐藏层的偏置初始化为常数 1, 其余层为 0. 偏置置 1 的目的是给 ReLU 正输入, 加速学习早期阶段. 这个 trick 后来也被更好的初始化方案取代, 但在 2012 年, 它是让深层 ReLU 网络点得着火的火柴之一.

学习率初始 0.01, 所有层相同, 全程手动调节: 验证错误率停滞就除以 10, 终止前共降了三次. 训练跑了约 90 个 epoch, 在两块 NVIDIA GTX 580 3GB 上耗时五到六天. 五到六天是什么概念? 一个博士生一周内可以完成一次完整的架构实验. 这个迭代速度, 加上 cuda-convnet 开源, 是 AlexNet 之后两年 CNN 论文爆炸的直接原因. 代码地址就印在论文第 2 页的脚注里.

## 7. 结果: 不是赢, 是碾压

ILSVRC-2010 测试集上, AlexNet 拿到 top-1 错误率 37.5%, top-5 错误率 17.0%. 对比项: 竞赛原冠军 47.1% 和 28.2%, 之后发表的最好结果 45.7% 和 25.7%. top-5 一口气降了 8.7 个百分点, 相对错误率砍掉三分之一.

真正载入史册的是 ILSVRC-2012. 单个 CNN, top-5 错误率 18.2%. 五个相似 CNN 取平均, 16.4%. 一个在整个 ImageNet 2011 秋季版 (1500 万图, 22000 类) 上预训练再加一层卷积微调的网络, 16.6%. 最终提交是 7 个网络的集成, top-5 测试错误率 15.3%. 第二名是 26.2%, 用的是 Fisher Vector 加多个分类器的集成, 代表了手工特征路线的最高水平.

10.9 个百分点的差距. 这不是「提升」, 这是代差. 视觉领域有个事后流传的说法: 2012 年 9 月 30 日结果公布那天, 计算机视觉的旧世界结束了. 此前 ILSVRC 最好成绩每年进步一两个点, 此后两年, 错误率一路掉到 10% 以下, 2015 年 ResNet 做到 3.57%, 低于人类的约 5%.

还有一个被低估的结果在 Fall 2009 数据集上: 10184 类, 890 万张图, 一半训练一半测试, AlexNet 加一层卷积后做到 top-1 67.4%, top-5 40.9%, 而此前最好发表结果是 78.1% 和 60.9%. top-5 降了 20 个百分点. 规模越大, 手工特征输得越惨.

论文结尾有一句当时读起来像客气话, 后来读起来像预言: 所有实验都表明, 只要等更快的 GPU 和更大的数据集出现, 结果就能继续变好. 这就是 scaling 思想的原始形态. 2012 年说出这句话需要勇气, 因为当时的共识是「这个网络只是恰好适合 ImageNet」. 十年后, GPT 系列把同一句话兑现到了语言上.

## 8. 定性分析: 网络到底学到了什么

数字之外, 论文用了两张图回答「这玩意儿真的在『看』图吗」.

第一张是第一层的 96 个 11x11x3 卷积核可视化. 网络自己学出了频率选择, 方向选择的滤波器, 以及各种颜色团块. 这些滤波器和手工设计的 Gabor 滤波器, SIFT 梯度直方图在功能上高度相似, 区别是它们是学出来的, 不是人画的. 手工特征时代二十年的视觉直觉, 被第一层卷积从数据里重新发现了.

更有趣的是两块 GPU 的分工. 由于受限连接, GPU 1 学出的核大多与颜色无关 (黑白边缘检测器), GPU 2 学出的核大多颜色相关. 这种分化在每次训练运行中都出现, 与随机初始化无关. 没有任何人设计过这个分工, 它自发涌现. 这是「结构从约束里长出来」的又一个实例, 和清单第 2 篇咖啡自动机的结论遥相呼应.

第二张图是 4096 维特征的语义检索. 取最后一个隐藏层的激活向量, 用欧氏距离在训练集里找最近的 6 张图. 像素层面, 检索到的图和查询图差得很远: 狗有各种各样的姿势, 大象出现在不同的背景里. 但在 4096 维空间里, 它们是邻居. 说明网络学到的是语义相似, 不是像素相似. 论文顺手指出一个应用方向: 用自编码器把 4096 维向量压成短二进制码, 可以做图像检索, 比直接对原始像素做自编码好得多, 因为后者只会检索边缘图案相似的图. 这个思路后来长成了整个表征学习和向量检索产业.

## 9. 局限与后续: LRN 死了, 深度活了

用今天的眼光清点这篇论文的遗产, 分三层.

第一层是活下来的. ReLU, dropout, 数据增强, GPU 训练, 端到端从像素到标签, 「深度重要」的消融实验, 「更大网络加更多数据会更好」的 scaling 信念. 这些构成了此后十年深度学习的基础设施. 清单第 7, 8 篇 ResNet 解决的是「深度到 152 层怎么训」, 第 9 篇空洞卷积解决的是「感受野怎么扩」, 全部站在 AlexNet 打开的这条路上.

第二层是过期的. LRN 被 BatchNorm (2015) 取代, 今天只在教科书里出现. 偏置置 1 的初始化被 He 初始化取代. 11x11 步长 4 的第一层被 VGG 的 3x3 堆叠证明是次优. 双 GPU 受限连接是显存不足逼出来的妥协, 显存一够就被放弃, 但它意外证明了模型并行的可行性, 这个思想在 GPipe (清单第 24 篇) 里以流水线并行的形式重生.

第三层是当时没做但指明了方向的. 论文明确说没有用无监督预训练, 但预期它会帮上忙, 尤其是在算力增速超过标注数据增速的时候. 这句话指向了后来的自监督学习和预训练加微调范式. 论文还说最终想用大而深的卷积网络处理视频序列, 因为时间结构提供了静态图像里没有的信息. 多模态和视频理解, 今天还在兑现这张支票.

也要诚实记录它没解决的问题. 6000 万参数的黑盒为什么能泛化, 论文没有理论, 只有工程. 为什么 SGD 在这么大的非凸问题里不陷进糟糕的局部极小, 当时没人知道, 今天也只有部分答案. AlexNet 是经验主义的胜利, 它的论文里没有一个定理. 而这恰恰是它在清单里的独特位置: 前 5 篇给理论, 这篇给证据.

## 10. 在 Ilya 清单中的位置

清单前 5 篇是一条完整的理论线. 复杂度第一定律说有趣的东西是「结构加随机」, MDL 说学习就是找最短描述, Kolmogorov 复杂度和算法随机性给出这套理论的数学基础, Machine Super-Intelligence 讨论智能的极限. 读完前 5 篇, 一个自然的问题是: 这套「压缩即理解」的理论, 在真实世界里有一次大规模的实证吗?

第 6 篇就是答案. AlexNet 做的事情, 用清单前 5 篇的语言翻译一遍: 用 6000 万个参数, 把 120 万张自然图像里的结构压缩进权重. 卷积是「正确偏见」换来的压缩率, 数据增强是告诉压缩器「哪些变化不算信息」, dropout 是防止压缩器死记硬背个别样本的随机噪声. 4096 维特征空间里语义相似性自发涌现, 说明压缩出来的表示抓住了结构, 而不只是记住了像素. 第一层学到的 Gabor 类滤波器, 是结构从数据里被榨出来的可视化证据.

这也是清单里唯一一篇 Ilya 自己署名的工程论文. 他把它放在第 6 的位置, 紧接在理论模块之后, 等于亲口说: 我做的这件事, 就是那套理论的第一次大规模落地. 从第 6 篇到第 10 篇 (ResNet, 恒等映射, 空洞卷积, CS231n), 是 CNN 谱系的连续深化, AlexNet 是这个谱系的起点. 再往后的 RNN, seq2seq, attention, 都是把「深度监督学习加 scaling」这个范式迁移到序列数据上.

还有一层现实层面的意义不该被跳过. AlexNet 的三要素: 大数据 (ImageNet), 大算力 (GPU), 端到端学习, 此后十年没有任何一个被推翻. 中间无数更精巧的架构来了又走, 留下的始终是这三条. 论文最后那句「等更快的 GPU 和更大的数据」不是谦逊, 是路线图. 看懂这句话的人, 2012 年之后就知道该押什么.
