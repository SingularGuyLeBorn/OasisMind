# Neural Turing Machines: 把图灵机搬进神经网络, 让程序可以被梯度下降学出来

> Graves, Wayne, Danihelka, Google DeepMind, 2014. arXiv:1410.5401. Ilya 推荐 30 篇第 22 篇.

全文公式分两组 (读写动作四条, 寻址流水线五条), 符号表放在最前面, 公式旁边会再讲一遍.

**全文符号表**

| 符号 | 含义 |
|------|------|
| $M_t$ | 记忆矩阵, $N$ 行 $M$ 列, 下标 $t$ 是时间步 |
| $N$ | 记忆位置数 (行数), 实验用 128 |
| $M$ | 每个记忆位置的向量宽度 (列数), 实验用 20. **和记忆矩阵 $M_t$ 同名, 靠下标区分: 带 $t$ 是矩阵, 单独出现是宽度** |

| $w_t(i)$ | 权重向量第 $i$ 个分量: 位置 $i$ 在这一步被读/写的程度 |
| $r_t$ | 读出向量: 所有记忆行的加权混合 |
| $e_t, a_t$ | 写头发出的 erase 向量和 add 向量, 各 $M$ 个分量, erase 分量在 $(0,1)$ |

| $k_t$ | key 向量: 控制器造出的「我要找的东西」, $M$ 维 |
| $K(u, v)$ | cosine 相似度: 两个向量的夹角余弦, 越同向越接近 1 |
| $\beta_t$ | key strength, 正标量, 控制内容寻址的锐利程度 |
| $w_t^c$ | 内容权重 (c = content): 纯按内容相似度算出的权重 |

**读公式的方法**: 全文公式只有一个主角, 权重向量 $w_t$. §2 四条回答「权重怎么用」: 读是拿它加权混合记忆, 写是拿它先擦后加. §3 五条回答「权重从哪来」, 按四步流水线读: 内容打分过 softmax, 和上一步的权重插值, 循环移位, 锐化. 每条公式都在算或者用这个 $w_t$, 盯住它就不会迷路.

# 1. 程序归纳与程序学习: 一条走了三十年的路

计算机程序靠三样东西运转: 基本运算, 逻辑流程控制 (分支跳转), 以及一块可读可写的外部记忆. Von Neumann 1945 年写 EDVAC 报告时就把这三样列清楚了. 机器学习发展到 2014 年, 第一样早就炉火纯青, 后两样基本缺席. 神经网络擅长拟合数据里的统计规律, 但你让它「把输入存下来, 过一百步再原样吐出来」, 它就开始犯难.

这不是能力上限问题, 是训练难度问题. Siegelmann 和 Sontag 早在 1995 年就证明了 RNN 是图灵完备的: 只要权重设置得当, 循环网络可以模拟任意程序. 但「原则上可行」和「实践中简单」是两回事. 用梯度下降在一个没有外部记忆的 RNN 里搜出一个能跑的程序, 搜索空间大到不现实. NTM 论文开篇就点了这句话: what is possible in principle is not always what is simple in practice.

更老的批评来自认知科学. 1988 年 Fodor 和 Pylyshyn 向连接主义发难, 两个罪名: 神经网络做不到「变量绑定」, 没法把一个数据项绑到一个槽位上; 固定长度输入的网络处理不了变长结构. 「Mary spoke to John」这种句子, 谁做主语谁做宾语必须绑定清楚, 连接主义模型当时给不出机制. 此后 Hinton, Smolensky, Touretzky, Kanerva 一干人陆续提出各种绑定方案, 但没有一个能做到「快速创建变量」: 像计算机把 3 和 4 放进两个寄存器再相加那样, 几毫秒内把新数据绑到新槽位. Hadley 2009 年把这个能力命名为 rapidly-created variables, 并指出这是人类工作记忆的核心特征之一.

NTM 的出发点就是把这条断了三十年的线接上. 思路类比图灵本人当年的做法: 图灵给有限状态机加了一条无限长的纸带, 得到了图灵机; NTM 给循环网络加一块可寻址的外部记忆, 得到一个可以用梯度下降训练的「可微计算机」. 论文摘要原话: NTM 可以从输入输出样例中推断出复制, 排序, 联想回忆这样的简单算法. 注意措辞, 是 infer, 不是 hand-code. 程序不是人写进去的, 是从数据里学出来的.

这里要区分两个概念. 程序归纳 (program induction) 是从样例中学出一个能执行算法的网络, 算法藏在权重和动力学里, 不输出可读代码. 程序合成 (program synthesis) 是直接生成程序文本. NTM 走的是前一条路, 这条路的尽头是今天的 LLM: 没有任何人给 GPT 写过「排序程序」, 但它在权重里学到了排序的能力. 2014 年看这个方向像玩具, 2026 年看它是主线.

# 2. 架构: 控制器, 记忆矩阵, 读写头

NTM 由两个基本组件构成: 一个神经网络控制器, 一个记忆库. 控制器像普通网络一样通过输入输出向量与外界交互, 特殊之处在于它同时通过一组并行的「读写头」与记忆矩阵交互. 类比数字计算机: 控制器是 CPU, 只不过指令不是预定义的而是学出来的; 记忆矩阵是 RAM; 循环控制器的隐状态相当于 CPU 里的寄存器, 允许它跨时间步混合信息.

记忆矩阵 $M_t$ 是 $N \times M$ 的二维结构, $N$ 是记忆位置数, $M$ 是每个位置的向量宽度. 论文所有实验都用 $128 \times 20$: 128 个位置, 每个位置一个 20 维向量. 这个数字值得记住, 后面泛化实验的天花板就是它.

读操作极其简单. 读头在时刻 $t$ 发出一个归一化的权重向量 $w_t$, 满足

$$\sum_{i=1}^{N} w_t(i) = 1, \quad 0 \le w_t(i) \le 1$$

求和遍历全部 $N$ 个记忆位置: 所有权重非负且加起来等于 1, 即一个合法的概率分布. 读出的向量是所有记忆行的凸组合:

$$r_t = \sum_{i=1}^{N} w_t(i) M_t(i)$$

每个记忆位置 $M_t(i)$ 乘上自己的权重 $w_t(i)$ 再相加, 权重大的位置主导读出内容. 还是那组熟悉的数 (和第 14, 17, 18 篇同一组): 三个记忆位置, 权重 $(0.665, 0.245, 0.090)$, 读出就是 $r_t = 0.665\,M_t(1) + 0.245\,M_t(2) + 0.090\,M_t(3)$, 读头基本上在读 1 号位置, 捎带一点 2 号. 对记忆和权重都可微, 这是后面一切的前提.

写操作借鉴 LSTM 的输入门和遗忘门, 拆成 erase 加 add 两步. 写头发出权重 $w_t$, 一个 erase 向量 $e_t$ (每个分量在 $(0,1)$ 区间), 先擦除:

$$\tilde{M}_t(i) = M_{t-1}(i) \left[ \mathbf{1} - w_t(i) e_t \right]$$

逐项读. $w_t(i) e_t$ 是标量乘向量: 位置 $i$ 的权重乘上 erase 向量, 得到一个 $M$ 维的「擦除力度」. $\mathbf{1}$ 是全 1 向量, 中括号里是逐分量相减, 得到「保留比例」: erase 分量为 1 的维度保留 0 (彻底擦掉), erase 分量为 0 的维度保留 1 (原样不动). 最后和旧记忆 $M_{t-1}(i)$ 逐分量相乘, 完成擦除. 只有权重和 erase 分量同时为 1 时, 该位置才被清零; 任一为 0, 记忆原样保留. 然后发出 add 向量 $a_t$, 写入:

$$M_t(i) = \tilde{M}_t(i) + w_t(i) a_t$$

标量 $w_t(i)$ 控制这个位置写入的强度, $a_t$ 是要写的内容, 逐分量加到擦完的记忆上. 擦除和写入用的是同一个权重 $w_t(i)$: 写头指到哪儿, 就在哪儿先擦后写.

erase 和 add 都有 $M$ 个独立分量, 可以细粒度控制每个位置内部的哪些维度被修改. 多个写头并存时, 擦除和添加的顺序都无所谓, 乘法和加法各自可交换.

控制器有两种选择, 各有代价. LSTM 控制器自带内部记忆, 隐状态像寄存器, 可以把上一步读到的向量存下来参与后续计算. 前馈控制器没有内部状态, 所有跨步信息必须走外部记忆, 但换来一个宝贵的性质: 透明. 前馈控制器的读写模式可以直接画出来读, RNN 的内部状态基本不可解释. 论文里大量的「学习到的算法」分析, 用的都是前馈控制器版本, 不是因为它性能更好, 而是因为看得懂.

前馈控制器有一个结构性瓶颈: 并发读写头的数量限制了每步能做的计算类型. 一个读头, 每步只能对单个记忆向量做一元变换; 两个读头, 可以做二元变换; 依此类推. 这个瓶颈在 Priority Sort 实验里真实咬了一口: 前馈版本需要 8 个并行读写头才能拿到最好成绩, 因为排序说白了就是反复比较两个向量.

# 3. 可微寻址: 全文最值得逐行读的数学

读写操作本身不难, 难的是权重 $w_t$ 从哪来. 普通计算机的寻址是离散的: 地址总线上给一个整数, 读那一个位置. 离散寻址不可微, 梯度传不回去, 控制器学不到「该读哪里」. NTM 的核心 trick 一句话: 每一步读写所有位置, 只是权重不同. 这就是论文所谓的 blurry read and write. 模糊是代价, 可微是收益. 再配一个注意力聚焦机制, 让权重在实践中高度稀疏, 模糊的成本就被压到很低.

寻址系统由两套互补机制拼成, 整个流程对应论文 Figure 2, 顺序如下.

第一步, 基于内容的寻址 (content-based addressing). 每个头发出一个长度 $M$ 的 key 向量 $k_t$, 与每个记忆行算相似度, 相似度函数取 cosine:

$$K(u, v) = \frac{u \cdot v}{\|u\| \cdot \|v\|}$$

分子是点积 (对应分量相乘再求和), 分母是两个向量各自的长度相乘, 一比得到夹角余弦: 完全同向为 1, 垂直为 0, 反向为 -1. 除以长度的作用是只看方向不看大小, 不会因为某个记忆行数值大就白捡相似度.

再配一个正的 key strength $\beta_t$, 控制聚焦的锐利程度, softmax 归一化得到内容权重:

$$w_t^c(i) = \frac{\exp\left(\beta_t K(k_t, M_t(i))\right)}{\sum_{j=1}^{N} \exp\left(\beta_t K(k_t, M_t(j))\right)}$$

分子是位置 $i$ 的相似度乘 $\beta_t$ 再取 exp, 分母遍历全部 $N$ 个位置做同样的运算再求和, 一比得到权重, 全部位置加起来等于 1. 这是本系列第五次出现的 softmax 加权和结构: 和第 14 篇 Bahdanau 的 $\alpha_{ij}$ 是同一个动作, 只是打分函数从加性网络换成了 cosine 相似度乘锐利度.

$\beta$ 大, 权重集中到最相似的一行; $\beta$ 小, 权重平摊. 内容寻址的好处是检索简单: 控制器只要造出存储数据的一个近似, 和记忆一比, 就能找回精确的原值. 这条线往上能追到 Hopfield 网络的内容寻址记忆.

第二步, 插值门控. 基于位置的寻址 (location-based addressing) 为什么必要? 因为有些任务里变量的内容是任意的, 但变量仍然需要一个可识别的「名字」. 算术就是典型: $x$ 和 $y$ 可以取任何值, 但 $f(x, y) = x \times y$ 这个程序必须对任意值成立. 控制器需要把 $x$ 和 $y$ 存到不同地址, 再按地址取出来做乘法. 这时寻址按位置, 不按内容. 理论上内容寻址严格更一般 (可以把位置信息编码进内容里), 但论文的实验表明, 把位置寻址作为原语提供, 对某些形式的泛化是必要的.

位置寻址的第一步是插值. 每个头发出一个标量门 $g_t \in (0,1)$, 在当前内容权重和上一步权重之间混合:

$$w_t^g = g_t w_t^c + (1 - g_t) w_{t-1}$$

又是一个凸组合 (和第 14 篇 GRU 的状态更新同构): $g_t$ 份内容权重 $w_t^c$ 加 $(1 - g_t)$ 份上一步的权重 $w_{t-1}$. 代个数: $g_t = 0.8$, 内容寻址给位置 3 的权重是 0.665, 上一步位置 3 的权重是 0.1, 插值后就是 $0.8 \times 0.665 + 0.2 \times 0.1 = 0.552$. $g_t = 1$ 完全听内容寻址的, $g_t = 0$ 完全沿用上一时刻的位置. 这个门让网络自己决定「这次是按内容跳, 还是接着上次的位置走」.

第三步, 循环移位. 每个头发出一个 shift weighting $s_t$, 是允许整数位移上的归一化分布. 比如允许 $-1, 0, 1$ 三档, $s_t$ 就有三个分量. 旋转用循环卷积实现, 索引对 $N$ 取模:

$$\tilde{w}_t(i) = \sum_{j=0}^{N-1} w_t^g(j) \, s_t(i - j \bmod N)$$

逐项读. 求和遍历全部 $N$ 个位置 $j$, 每项是「位置 $j$ 原有的权重」乘上「从 $j$ 移到 $i$ 需要的位移 $i - j$ 对应的 shift 分量」. 索引 $i - j$ 对 $N$ 取模, 意思是超出范围就绕回: 从最后一个位置再移一格回到第一个, 记忆位置排成一个环. 代个数看移位怎么搬权重. 设 $N = 4$, 权重全集中在位置 2: $w_t^g = (0, 1, 0, 0)$. $s_t$ 允许三档位移 $(-1, 0, 1)$, 取值 $(0.1, 0.8, 0.1)$, 意思是八成不动, 各一成向前向后. 代入公式, 只有 $j = 2$ 的项非零: $\tilde{w}_t(i) = s_t(i - 2)$, 于是 $\tilde{w}_t(1) = s_t(-1) = 0.1$, $\tilde{w}_t(2) = s_t(0) = 0.8$, $\tilde{w}_t(3) = s_t(1) = 0.1$. 单点焦点被搬成了一个以原位为中心的小山峰, 峰值 0.8 在原位, 两侧各泄漏 0.1.

当前权重聚焦在单个位置时, 移 +1 就把焦点挪到下一个位置, 负位移反向走. 这是「迭代器」的神经实现: for 循环里 i++ 那个动作.

第四步, 锐化. 循环卷积有个副作用: 如果 $s_t$ 本身不尖锐, 比如 $(0.1, 0.8, 0.1)$, 焦点会随时间泄漏, 单点权重慢慢糊成一片. 对策是每个头再发一个标量 $\gamma_t \ge 1$, 做最后的锐化:

$$w_t(i) = \frac{\tilde{w}_t(i)^{\gamma_t}}{\sum_{j=1}^{N} \tilde{w}_t(j)^{\gamma_t}}$$

每个分量取 $\gamma_t$ 次方再归一化 (分母遍历全部 $N$ 个位置). 取大于 1 的幂会放大差距: 大的更大, 小的更小. 接着上面的例子, 移位后的权重是 $(0.1, 0.8, 0.1)$ 加上一个 0 分量, 即 $(0.1, 0.8, 0.1, 0)$. $\gamma_t = 2$ 时各分量平方得 $(0.01, 0.64, 0.01, 0)$, 归一化后约 $(0.015, 0.970, 0.015, 0)$: 峰值从 0.8 拉到 0.97, 泄漏被压回去. $\gamma_t$ 越大压得越狠, $\gamma_t = 4$ 时峰值约 0.9995, 几乎回到单点. 注意取幂不改归一化结构, 权重仍然非负且和为 1.

四步走完, 组合系统支持三种工作模式. 模式一, 纯内容寻址, 位置系统不干预. 模式二, 内容寻址定位一个数据块, 再移位访问块内特定元素, 相当于「先找链表节点, 再读 next 指针指向的那个」. 模式三, 完全不理内容, 从上一时刻的位置做纯旋转, 每步前进固定距离, 这就是数组迭代. 后面 copy 任务的伪代码分析会证明, 学出来的算法确实混用了模式一和模式三.

整套机制里最值得品味的设计是: 每一步的计算都是稠密的, 所有记忆位置都参与读写, 但权重分布是稀疏的. 稠密保证可微, 稀疏保证记忆互不干扰. 三年后 Vaswani 等人把「对一组向量算归一化权重再加权求和」这个结构从记忆寻址里抽出来, 命名为 attention. NTM 的寻址机制就是 attention 的第一次完整登场, 只是当时它被称作 addressing.

# 4. 五个任务: 一张精心设计的课程表

实验部分的目标不是刷分. 论文原话: 目标不只是证明 NTM 能解这些问题, 而是证明它通过学习紧凑的内部程序来解, 这类解法的标志是泛化远超训练数据范围. 训练时只见过长度 20 的复制任务, 能不能直接复制长度 100? 这是整个实验设计的灵魂.

所有实验对比三个架构: 前馈控制器 NTM, LSTM 控制器 NTM, 标准 LSTM. 所有任务都是 episode 式, 每条序列开始时重置动态状态. 全部是监督学习, 二值目标, sigmoid 输出, 交叉熵损失, 误差按 bits-per-sequence 报告. 优化器 RMSProp, momentum 0.9, 梯度逐元素裁剪到 $(-10, 10)$. 所有 LSTM 基线都是三层堆叠. 一个关键的参数量事实: LSTM 参数量随隐层维度平方增长 (循环连接), NTM 参数量不随记忆位置数增长. 128 个位置的记忆矩阵是「免费」的容量.

## 4.1 Copy: 存储与召回的基本功

任务: 输入一串随机 8-bit 向量, 长度 1 到 20 随机, 后跟一个分隔符, 要求原样输出整串. 输出阶段没有任何输入提示, 必须全靠记忆.

学习曲线上, 两种 NTM 都比纯 LSTM 学得快得多, 收敛到更低的 cost. 论文评语是差距大到暗示「质的区别」而非量的区别, 两种模型在用不同方式解题. 泛化测试才是分水岭: 训练只到长度 20, 测试拉到 10, 20, 30, 50, NTM 全部高置信度近乎无误; 长度 120 时 NTM 只有少量局部错误加一个全局错误 (某处重复了一个向量, 导致后面全部错位一位, 损失很高但主观上仍像正确复制). LSTM 过 20 就迅速崩, 而且序列越长, 开头正确的前缀越短, 说明它长时间保持信息的能力在衰退.

120 的上限不是算法问题, 是记忆只有 128 个位置, 循环移位绕一圈回来就把先前的写入覆盖了. 容量是显式的, 瓶颈也是显式的, 这本身就是外部记忆架构的魅力: 系统的能力边界可以直接读出来.

## 4.2 Repeat Copy: 学一个 for 循环

任务升级: 复制指定次数, 然后输出结束标记. 序列长度和重复次数都在 1 到 10 随机, 重复次数通过单独的输入通道给一个归一化标量 (均值 0, 方差 1). 动机是看 NTM 能不能学出嵌套函数: 一个 for 循环包住已学会的 copy 子程序.

训练范围内, NTM 学得快得多, 但 LSTM 最终也能完美解决, 论文作者都承认有点意外 (可能因为这个任务序列更短, 且 LSTM 基线更大, 有 530 万参数). 泛化测试拉开差距, 这次是二维的: 序列长度翻倍, NTM 几乎完美, LSTM 崩; 重复次数超过 10, NTM 能继续正确复制内容, 但数不清自己复制了几轮, 结束标记的输出时间全错. 原因藏在表示里: 重复次数是一个数值标量, 数值表示天然不好外推到训练范围之外. 内容会复制, 计数不会泛化, 这个失败模式非常诚实.

## 4.3 Associative Recall: 间接寻址的第一课

前两个任务的数据结构是线性的. 下一个复杂度台阶是「间接」: 一个数据项指向另一个数据项. 任务构造: 一个 item 是 3 个 6-bit 向量 (共 18 bit), 左右有分隔符; 先喂入 2 到 6 个 item, 然后随机挑一个 item 作为 query, 要求输出它后面的那个 item. 这是链表 next 指针查询的神经版本.

结果: NTM 约 3 万个 episode 收敛到近零 cost, LSTM 跑了一百万个 episode 还没到零. 前馈控制器版本学得比 LSTM 控制器版本更快. 泛化到 12 个 item (训练上限的两倍), 前馈 NTM 近乎完美; 15 个 item 时平均 cost 仍低于 1 bit per sequence. LSTM 全线被碾压.

最有意思的是解出来的算法. 网络在每个 item 的分隔符出现时, 把前三个时间片的压缩表示写进一个记忆位置; query 到达后, 控制器重算 query 的压缩表示, 用内容寻址找到当初写入的位置, 然后移位一格, 读出下一个 item. 内容寻址加位置偏移, 两种寻址模式的组合被网络自己发现了. 这不是人类设计的算法, 是从注意力权重热图里读出来的.

## 4.4 Dynamic N-Grams: 记忆当计数表用

这个任务测试快速适应新分布的能力. 考虑所有二元序列上的 6-gram 分布, 每个分布是一张 32 个数的表 (5 bit 历史, $2^5 = 32$ 种上下文, 每个上下文一个下一 bit 为 1 的概率). 每条训练序列: 先从 $\mathrm{Beta}(\frac{1}{2}, \frac{1}{2})$ 独立采 32 个概率, 再用这张表采样 200 个 bit. 网络逐 bit 观察, 预测下一 bit. 每条序列的分布都是新的, 靠权重记住「通用规律」没用, 必须在序列内部在线统计.

最优贝叶斯估计器有解析形式:

$$P(B = 1 \mid N_1, N_0, c) = \frac{N_1 + \frac{1}{2}}{N_1 + N_0 + 1}$$

分子分母各加一个 1/2, 这是 Beta 先验的拉普拉斯平滑: 没观察到任何数据时 ($N_1 = N_0 = 0$), 估计为 $0.5/1 = 0.5$, 不偏不倚; 观察到 3 个 1 和 1 个 0 时, 估计为 $(3 + 0.5)/(3 + 1 + 1) = 3.5/5 = 0.7$, 比原始频率 $3/4 = 0.75$ 略微向 0.5 收缩, 样本越少收缩越强. 竖线 $\mid$ 右边是估计依据: 上下文 $c$ 后面见过几个 1, 几个 0.

其中 $c$ 是 5 bit 上下文, $N_0, N_1$ 是该上下文后观察到 0 和 1 的次数. 这给了实验一个金标准. 结果: NTM 比 LSTM 有小但显著的优势, 但始终没达到最优估计器. 记忆使用分析显示, 控制器把记忆当成可重写计数表: 同一个上下文重复出现时, 读头访问同一位置, 下一步写头跟上, add 向量在输入为 0 和 1 时明显负相关, 像一个分布式的「计数器」. 写权重随同一上下文重复出现而变淡, 推测记忆存的是 0/1 的比例而非绝对计数.

这个任务是五个里最接近真实语言建模的: 分布未知, 样本流式到达, 必须在线更新统计. NTM 用记忆模拟了 N-gram 模型的计数表, 而 N-gram 正是神经语言模型之前的统治者.

## 4.5 Priority Sort: 排序, 以及一次漂亮的假设检验

任务: 20 个随机二值向量, 各带一个从 $[-1, 1]$ 均匀采样的优先级标量, 要求按优先级输出最高的 16 个. 输出截断到 16 是故意的, 作者想看 NTM 会不会学出一个深度 4 的二叉堆排序.

观察记忆使用后, 作者提出假设: NTM 用优先级数值直接决定每个向量的写入位置. 检验方法非常干净: 对「优先级 → 写入位置」拟合一个线性函数, 拟合出来的位置和实际观察到的写入位置高度吻合. 读头则按位置递增顺序遍历, 自然读出排好序的序列. 优先级越高, 写入位置越靠后 (或靠前), 排序被转化成了「按值选址」, 一次写入就完成插入排序的核心动作.

这个任务上两种 NTM 都大幅优于 LSTM. 前面提到的前馈瓶颈在这里现身: 前馈控制器需要 8 个并行读写头才拿到最好成绩, 排序要反复做二元比较, 单读头的一元变换不够用. 配置表里的数字: 前馈版 512 控制器, 8 个头, 约 51 万参数; LSTM 基线三层 128 隐层, 约 33 万参数. 参数同量级, 性能不在一个量级.

# 5. 从注意力权重读出算法: 可解释性的免费午餐

NTM 论文最迷人的部分不是学习曲线, 是记忆使用热图. 因为读写权重是显式的, 训练好的网络每一步在「看哪里」可以直接画出来, 黑盒第一次有了白盒的内部.

Copy 任务里, 论文把观察到的操作序列总结成伪代码, 值得全文照抄:

```
initialise: move head to start location
while input delimiter not seen do
    receive input vector
    write input to head location
    increment head location by 1
end while
return head to start location
while true do
    read output vector from head location
    emit output
    increment head location by 1
end while
```

论文评语: 这就是人类程序员用低级语言完成同一任务的写法. 用数据结构的语言说, NTM 学会了创建并遍历数组. 热图细节逐条印证: 写入阶段权重尖锐聚焦单个位置, 焦点每步平移一格 (位置寻址的模式三); 输出阶段读位置与写位置精确重合, 读出的向量与当初写入的 add 向量一致; 「回到起点」那一步用的是内容寻址 (模式一). 论文还点出两个机制的必要性: 没有基于上一步权重的相对移位, 迭代无法泛化到长序列; 没有锐化机制, 权重会随时间丢失精度.

Repeat Copy 的热图里还有一个彩蛋: 读权重底部有一个白点, 对应一个中间位置, 用来把读写头重定向回序列起点. 论文原话: The NTM equivalent of a goto statement. 网络自己发明了 goto.

这套可解释性不是后加的, 是架构的副产品. 代价是前面说过的: 前馈控制器才足够透明, 而前馈控制器有头数瓶颈. 可解释性和表达能力在第一篇论文里就是 tradeoff, 不是后来才出现的矛盾.

# 6. 血缘: 外部记忆谱系上的关键一环

把 NTM 放进 Ilya 清单的坐标系, 它的位置非常清晰.

往前看, 它引用 Bahdanau 等人 2014 年的机器翻译注意力 (清单第 14 篇) 作为「可微注意力模型」的先驱, 两篇论文相隔不到两个月. 注意力机制在 2014 年秋天是空气里的东西, NTM 和 Bahdanau 各自独立把它落了地: 一个落在编码器-解码器对齐上, 一个落在记忆寻址上. 再往前, 论文致谢名单里有 Ilya Sutskever 本人, 还有 Hinton, Hassabis, Jeff Dean, 这解释了它为什么出现在这份清单里: Ilya 是看着这篇论文做出来的.

往旁边看, 清单第 17 篇 Pointer Networks 和第 18 篇 Order Matters 是同一族思想. Pointer Networks 用注意力当指针, 从输入序列里挑位置输出; Order Matters 的 glimpse 机制在每次出指针前先对记忆做一次注意力读出. NTM 的读头就是 glimpse 的更一般形式: 不只读, 还能写, 还能移位. 第 20 篇 RMC 会继承 NTM 的 slot 化记忆观, 然后扔掉整套可微寻址, 换成多头 self-attention 一步到位, 让记忆行之间互相交流. NTM 的读写头一次动一两个 slot, RMC 一步让所有 slot 两两交互. 从 NTM 到 RMC 的四年, 是「记忆即仓库」到「记忆即讨论室」的四年.

往后看, 嫡系后代是 DNC (Differentiable Neural Computer), Graves 原班人马 2016 年发在 Nature. DNC 修复了 NTM 的几个真实痛点: 记忆重用 (NTM 写过的地方不敢再写, 因为不知道哪里可以安全覆盖), 临时链接 (associative recall 里那种「item 之间相连」的关系需要显式链接矩阵), 以及内容寻址与位置寻址的更干净分离. DNC 在 bAbI 问答和图任务上做到了当时最好. 再往后, 这条线汇入今天的 agent memory 系统: 检索记忆条目, 拼进上下文, 再推理, 工程尺度的外部记忆.

还有一条更长的线. NTM 的可微寻址证明了「对一组向量算归一化权重再加权求和」可以被梯度下降端到端训练, 而且训练出来是稀疏尖锐的指针. 这个经验事实三年后变成 Transformer 的地基. NTM 没有赢, 但它提前彩排了赢家的核心动作.

# 7. 为什么 NTM 没有赢, 以及它留下了什么

先说没赢的原因, 不要替它粉饰.

任务太 toy. 复制 8-bit 向量, 排序 20 个向量, 数 6-gram 的 0 和 1. 2014 年的读者看完会想: 这些东西写十行 Python 就解决了, 为什么要训一个神经网络? 论文自己也只敢说 preliminary results. toy 任务证明的是「原理可行」, 不是「工程有用」, 而 2014 年的深度学习正在 ImageNet 和语音识别上拿真实战果, 对比之下 NTM 像实验室里的珍奇动物.

训练慢且不稳. 整个寻址流水线 (key, $\beta$, $g$, shift, $\gamma$) 每个头每步都要算, 记忆读写是稠密的 $N \times M$ 操作, 2014 年的硬件跑起来昂贵. 梯度要穿过循环卷积和 softmax 链条回传, 裁剪到 $(-10, 10)$ 都压不住所有不稳定. 后来 DNC 的论文间接承认了这一点, 用了大量工程手段才稳住训练. 同期 seq2seq 加注意力在翻译任务上直接出成果, 研究社区的注意力 (双关) 自然流走了.

还有一个结构性原因: NTM 把记忆放在网络外面, 规模上不去. 记忆矩阵 128x20 是手工设定的, 参数量和记忆容量解耦听起来美好, 但真要做语言建模级别的任务, 该把记忆开多大, 控制器怎么跟上, 论文没有答案. 2017 年之后历史选择了另一条路: 把所有信息塞进上下文窗口, 用注意力在上下文内部做寻址. 外部记忆让位给了长上下文.

再说它留下了什么, 这部分分量更重.

第一, 可微寻址这个思想本身. 「每步读写所有位置, 只是权重不同」, 这句话拆开就是 attention 的定义. NTM 第一次在记忆读写场景里证明了这个 trick 可训练, 可泛化, 可解释. 从 Bahdanau 到 NTM 到 Transformer, 同一个数学结构换了三次场景, 每次都比上次更一般.

第二, 「学出来的算法」这个研究范式. 从注意力权重热图里读出伪代码, 读出 goto, 读出「按优先级选址」的插入排序, 这是机制可解释性 (mechanistic interpretability) 的史前版本. 今天在 Transformer 里找 induction head, 找加法电路, 方法论上都是 NTM Figure 6 的后代: 先训出行为, 再逆向出算法.

第三, 课程表式实验设计. 五个任务从线性结构 (copy) 到嵌套控制流 (repeat copy) 到间接寻址 (associative recall) 到在线统计 (N-grams) 到排序 (priority sort), 复杂度逐级加码, 每个任务精确打击一种能力, 每个都有泛化到训练分布之外的测试. 这种「造一组玩具任务诊断架构能力」的方法, 后来变成 bAbI, 变成算法推理 benchmark, 变成今天测 LLM 推理能力的标准动作.

第四, 一个至今没解决的开放问题. NTM 想回答的是: 能不能让神经网络像计算机一样, 把数据和程序分开, 数据放在记忆里, 程序学在权重里? 2026 年的答案是: 部分可以. 上下文窗口就是那块外部记忆, in-context learning 就是模糊版的内容寻址, 但我们仍然没有一种架构, 能像 NTM 设想的那样干净地分离存储与计算, 还能在 10^11 参数规模上训练. 这个问题没有过期.
