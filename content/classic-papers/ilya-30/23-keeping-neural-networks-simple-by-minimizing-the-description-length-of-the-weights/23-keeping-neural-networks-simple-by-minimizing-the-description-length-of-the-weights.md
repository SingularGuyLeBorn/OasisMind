# Keeping Neural Networks Simple by Minimizing the Description Length of the Weights: MDL 两段码在神经网络权重上的第一次完整落地

> Geoffrey E. Hinton & Drew van Camp, COLT 1993, pp. 5-13. 全文 9 页, 没有 arXiv 版本, PDF 挂在 Hinton 个人主页 https://www.cs.toronto.edu/~hinton/absps/colt93.pdf. Ilya 推荐清单里年份最早的论文之一.

全文用到一套统一记号, 符号表放在最前面. 第一次读可以只扫一眼, 后面每条重要公式附近, 会把容易混淆的符号再单独讲一遍.

**全文符号表**

| 符号 | 含义 |
| ---- | ---- |
| $c$ | 训练样本编号, $c = 1, \dots, N$. 出现在上标, 如 $d_j^c$ 是第 $c$ 条样本的量 |
| $N$ | 训练样本总数. 实验里 $N = 105$ |
| $j$ | 输出单元编号. 注意 $j$ 在数据项里指输出单元, 在权重项 $w_{ij}$ 里和 $i$ 一起遍历所有连接, 靠上下文区分 |
| $d_j^c$ | 第 $c$ 条样本第 $j$ 个输出的目标值 (desired). 接收者不知道它, 要靠通信还原 |
| $y_j^c$ | 网络在第 $c$ 条样本上第 $j$ 个输出的实际值. 残差 = $d_j^c - y_j^c$ |
| $t$ | 量化宽度 (容差). 实数按宽度 $t$ 切成小区间, 概率质量 ≈ 高度 × 宽度 |
| $\sigma_j$ | 残差编码用的高斯标准差, 每个输出单元一个 |
| $\sigma_w$ | 权重编码用的高斯标准差, 第 3 节里事先固定 |
| $w_{ij}$ | 一个具体权重 (连接). $\mathcal{W}$ 是所有连接的集合, 实验里共 521 个 |
| $k$ | 编码常数, 吸收 $-\log t$, $\log\sqrt{2\pi}$ 等与数据无关的固定开销 |
| $\log$ | 自然对数 (底为 $e$). 码长单位是 nat, $1 \text{ nat} = 1/\ln 2 \approx 1.443$ bit. 论文退火终点 $10^{-6}$ 用的就是 nat |
| $P(w)$ | 权重的先验分布, 发送双方事先约定的编码分布 |
| $Q(w)$ | 权重的后验分布, 训练结束后发送者手里的对角高斯 |
| $\langle \cdot \rangle_Q$ | 对分布 $Q$ 取期望: 按 $Q$ 反复采样, 对括号里的量求平均 |
| $\mu_{y_j}$, $V_{y_j}$ | 权重带噪声时, 第 $j$ 个网络输出的均值和方差 (输出变成随机变量) |
| $G(P; Q)$ | 后验 $Q$ 相对先验 $P$ 的 KL 散度, 即一个 noisy 权重的净通信代价 |
| $J$ | 高斯混合先验的分量数, 实验里 $J = 5$ |
| $\pi_i$ | 混合先验里第 $i$ 个分量的混合比例. **和圆周率 $\pi$ 是两个完全不同的东西**, $\pi$ 只出现在 $\sqrt{2\pi}$ 里 |
| $P_i(w)$ | 混合先验里第 $i$ 个高斯分量 |
| $G_i$ | 后验 $Q$ 与第 $i$ 个分量 $P_i$ 之间的 KL |
| $r_i$ | Boltzmann 分布, $r_i \propto \pi_i e^{-G_i}$, 通信协议里「挑哪个分量」的概率 |
| $E_i$ | 状态 $i$ 的总能量, $E_i = G_i - \log \pi_i$ (选分量的码长加分量内的 KL) |
| $H(r)$ | 分布 $r$ 的熵, $H(r) = -\sum_{i=1}^{J} r_i \log r_i$, 对应 bits back 的退款 |
| $F$ | Helmholtz 自由能, $F = \sum_{i=1}^{J} r_i E_i - H(r)$ |

**读公式的方法.** 全文所有公式都是码长, 读每条公式只需要问两个问题: 在编什么 (残差, 权重, 还是分量编号), 用哪款码 (单高斯, 高斯混合, 还是先验-后验对). 代价函数 $C$ 永远 = 描述权重的 bit + 描述残差的 bit, 所有变形都在这两个账本之间挪东西. bits back 的公式多一步: 寄出去的随机数能退回来, 净代价 = 代价 - 退款.

## 1. 1993 年, 泛化是唯一被认真对待的问题

先把时间轴摆出来. 1986 年 Rumelhart, Hinton, Williams 的 backprop 让连接主义复活, 1989 年 LeCun 把 weight sharing 用在手写邮编识别上, 1990 年 Lang, Waibel 和 Hinton 用 TDNN 做孤立词识别. 表面上一片繁荣, 但到 1993 年, 神经网络研究已经走进第二轮低谷的尾声: 数据少, 算力弱, 稍微复杂一点的网络就把训练集背下来, 然后在新数据上崩掉. 统计学习理论那边, Vapnik 的 VC 维框架正在成形, SVM 两年后就要登场, 整个 90 年代后半段将是核方法的天下.

在这种气氛里, 「泛化」不是一个锦上添花的指标, 是神经网络的生死问题. 论文第一段把当时的应对方案列得很清楚, 一共三招: 限制连接数, 赌每个权重里信息不多; weight sharing, 按任务的对称性把连接分组, 组内强制相等, LeCun 1989 和 TDNN 都是这条路; 给所有权重量化, 每个量化值配上概率质量 p, 一个权重花 -log p bit. 第三招方向对了, 但搜索空间是离散的, 代价函数没有光滑导数, 没法和 backprop 配合.

Hinton 和 van Camp 要做的事, 就是把第三招救活: 保留「用 bit 给权重标价」的思想, 同时让代价函数处处可导. 工具是 Rissanen 1986 年的 Minimum Description Length 原则. 这正是 Ilya 清单第 3 篇 Grunwald 教程讲的那套理论, 而本篇比那篇教程早了 11 年, 是 MDL 在神经网络上的工程化第一例.

## 2. 两段码: 先寄权重, 再寄残差

MDL 的准则一句话: 最好的模型, 是「描述模型的 bit 数」加「描述模型与数据之间偏差的 bit 数」最小的那个. 对结构固定的监督神经网络, 模型就是权重, 偏差就是每个训练样本上的输出误差.

论文用了一个发送者-接收者的故事把这件事讲具体. 发送者能看到输入向量和正确输出, 接收者只能看到输入向量. 发送者先在全部训练集上把网络训好, 然后把权重寄给接收者; 接着对每个训练样本, 把网络输出和正确输出之间的残差也寄过去. 接收者拿着权重跑一遍网络, 加上残差, 就能精确还原所有正确输出. 总通信量 = 权重的描述长度 + 残差的描述长度, 这就是要最小化的东西.

第一步是给残差编码. 实数残差需要无穷多 bit, 所以先按固定宽度 t 细量化. 双方约定残差服从零均值高斯分布, 标准差 $\sigma_j$, 那么量化后某个残差落在小区间里的概率质量近似为「高度乘宽度」:

$$p(d_j^c - y_j^c) \approx \frac{t}{\sqrt{2\pi}\,\sigma_j}\exp\left(-\frac{(d_j^c - y_j^c)^2}{2\sigma_j^2}\right)$$

逐块看. $d_j^c$ 是第 $c$ 条样本第 $j$ 个输出的目标值, $y_j^c$ 是网络的实际输出, 括号里的差就是残差. 右边分母 $\sqrt{2\pi}\,\sigma_j$ 是高斯密度的高度归一化, 指数项决定残差越大概率越小, 乘上宽度 $t$ 就是「高度 × 宽度」: 残差落在宽度为 $t$ 的小区间里的概率质量. 这条式子回答的问题是「寄一个残差值要花多少钱」, 取负对数就是码长.

代入数字感受一下. $\sigma_j = 0.5$, $t = 0.01$, 残差恰好为 0 时: 高度 $= 1/(\sqrt{2\pi} \times 0.5) \approx 0.798$, 概率质量 $\approx 0.798 \times 0.01 = 0.00798$, 码长 $-\log 0.00798 = 4.83$ nat $\approx 6.97$ bit. 残差变成 1 (即 $2\sigma_j$) 时, 指数项多贡献 $1^2/(2 \times 0.5^2) = 2$ nat, 码长涨到 6.83 nat. 残差每偏离一个 $\sigma_j$, 码长按平方涨价, 这就是高斯码的计价方式.

取负对数, 描述长度是 $-\log t + \log\sqrt{2\pi} + \log\sigma_j + (d_j^c - y_j^c)^2 / 2\sigma_j^2$. 前两项是常数, 最优的 $\sigma_j$ 就是残差的均方根. 代回去, 全部 N 个样本的残差总代价是:

$$C_{\text{data-misfit}} = kN + \frac{N}{2}\log\left(\frac{1}{N}\sum_{c=1}^{N} (d_j^c - y_j^c)^2\right)$$

求和 $\sum_{c=1}^{N}$ 遍历全部 $N$ 条训练样本, 对数里面就是均方误差. 这条式子是「代入」出来的, 中间步值得看一眼: 把最优 $\sigma_j^2 = \frac{1}{N}\sum_{c=1}^{N}(d_j^c - y_j^c)^2$ 代回单样本码长, 每条样本的误差项 $(d_j^c - y_j^c)^2 / 2\sigma_j^2$ 对 $c$ 求和恰好等于 $N/2$ (分子分母是同一个量), 与残差大小无关; 剩下每条样本一个 $\log \sigma_j$, 合起来就是 $\frac{N}{2}\log(\text{均方误差})$; 所有与数据无关的常数 ($-\log t$, $\log\sqrt{2\pi}$ 等) 被收进 $k$, 每条样本一份, 共 $kN$. 所以这条式子真正在说的只有一件事: 残差码长 = 固定开销 + 随均方误差对数增长的部分.

对数里面就是均方误差. 这里有一个常被忽略的推论: 最小化残差描述长度, 等价于最小化平方误差. 换句话说, 平方误差这个损失函数不是拍脑袋选的, 它是「残差服从高斯分布」这个编码假设的 MDL 推论. 1993 年的论文顺手给出了平方损失的编码论证明, 这个视角今天仍然成立.

## 3. weight decay 就是单高斯先验的 MDL

权重可以用同样的方式编码. 假设训好的网络权重按宽度 t 细量化, 且服从零均值高斯分布, 标准差 $\sigma_w$ 事先固定, 那么权重的描述长度正比于权重平方和. 两段加起来:

$$C = \sum_{j=1}^{m} \frac{1}{2\sigma_j^2}\sum_{c=1}^{N} (d_j^c - y_j^c)^2 + \frac{1}{2\sigma_w^2}\sum_{(i,j) \in \mathcal{W}} w_{ij}^2$$

三个求和各管一段. $\sum_{c=1}^{N}$ 遍历训练样本, $\sum_{j=1}^{m}$ 遍历 $m$ 个输出单元 (实验里网络只有一个输出, $m = 1$), $\sum_{(i,j) \in \mathcal{W}}$ 遍历所有连接, $\mathcal{W}$ 是权重集合 (实验里 521 个). 注意这里的 $i, j$ 和上面数据项里的 $j$ 不是一回事: 数据项里 $j$ 编号输出单元, 权重项里 $(i,j)$ 编号第 $i$ 个输入到第 $j$ 个单元的那条连接, 这是原文的记号习惯.

两项各自的作用. 第一项是残差码, 系数 $1/2\sigma_j^2$ 是残差精度的价格: 残差要求越精确 ($\sigma_j$ 越小), 每个平方误差越贵. 第二项是权重码, 系数 $1/2\sigma_w^2$ 是权重精度的价格. 代入一组数: 3 个权重 $(0.1, 0.2, 0.3)$, $\sigma_w = 1$, 权重码 $= (0.01 + 0.04 + 0.09)/2 = 0.07$ nat; 把 $\sigma_w$ 缩到 0.5, 同一份权重立刻涨价 4 倍到 0.28 nat. 整个训练就是在这两个价格之间找平衡.

这就是标准的 weight decay. 一个正则项, 一项是数据拟合, 一项是权重平方和, 系数比由两个高斯的方差比决定. 论文原文说得很直白: weight decay 能改善泛化 (Hinton 1987), 可以看作这套粗糙 MDL 方案的一次 vindication. 说「粗糙」, 因为编码用的两个高斯标准差都事先定死了, 只有方差比起作用, 实践中这个比例还得靠验证集去试.

这里值得停顿一下. 今天每个训练框架里都有一个 weight decay 系数, 绝大多数使用者把它当成一个玄学超参数. 但从编码论看, 它的身份非常清楚: 它是「你愿意花多少 bit 描述权重」的价格标签. $\sigma_w$ 越小, 权重平方和的标价越高, 训练就越倾向于把权重压小, 模型的有效复杂度越低. 正则化强度不是一个工程 trick, 是码率分配.

更进一步, Nowlan 和 Hinton 1992 年的 soft weight sharing 把单个高斯换成自适应高斯混合, 均值, 方差, 混合比例都随训练调整, 某些任务上泛化明显更好, 尤其是权重只需要少数几个不同取值的时候. 但这个方案有个严重弱点, 也是本篇论文真正的切入点: 它假设所有权重按同样的容差量化, 且容差远小于高斯的标准差. 也就是说, 它只算了概率密度 (图里的高度), 没算精度 (图里的宽度). 论文的原话是: this is a terrible waste of bits.

## 4. 核心 trick: 给权重加噪声, 让精度自己定价

为什么忽略宽度是浪费? 回到量化概率质量的近似: 概率 = 高度 × 宽度, 码长 = -log 高度 - log 宽度. 宽度 t 越大, 即量化越粗, -log t 越小, 码越短. 一个对网络输出影响很小的权重, 完全可以用很粗的精度描述, 省下大量 bit; 一个敏感的权重, 才值得花 bit 记精确值. 固定容差的编码方案对所有权重收同样的精度税, 这是码率分配上的平均主义, 而平均主义在压缩里永远是错的.

限制一个数所含信息量的标准做法, 是给它加零均值高斯噪声. 直觉上这很反常识: 一个带噪声的权重看起来比一个精确权重更贵, 因为要传均值还要传方差, 两个数都得定精度. 但 MDL 框架给出一个相反的结论: 非常 noisy 的权重可以非常便宜地通信.

具体做法是把训练对象换掉. 标准 backprop 在权重空间里移动一个点; 这里改成维护一团权重向量: 每个权重一个均值, 一个方差, 各权重独立, 整个后验是一朵对角高斯云. 训练时同时调整所有均值和方差, 最小化的代价函数是权重和残差的期望总描述长度. 方差大的权重便宜, 但它会给网络输出注入额外方差, 让残差变贵; 方差小的权重残差便宜, 但自身描述变贵. 噪声水平在训练中被自适应地调节, 每个权重自己找到「精度换误差」的最优点. 这就是题目里「minimizing the description length of the weights」的全部含义: 不是把权重压小, 是把权重里需要被精确记住的信息量压小.

代价函数的误差项需要期望平方误差 $\langle (d_j - y_j)^2\rangle$: 尖括号 $\langle \cdot \rangle$ 表示对权重噪声求平均——权重是随机的, 输出 $y_j$ 跟着变成随机变量, 所以要问「平均来看平方误差多大」, 而不是某一次采样的误差. 论文给了一个干净分解 (论文 Eq. 12):

$$\langle E_j\rangle = (d_j - \mu_{y_j})^2 + V_{y_j}$$

左边 $\langle E_j\rangle$ 就是 $\langle (d_j - y_j)^2\rangle$ 的简写. 右边 $\mu_{y_j}$ 是噪声输出的均值, $V_{y_j}$ 是噪声输出的方差. 这个分解的证明只有一步: 在 $(d_j - y_j)$ 里加一项减一项 $\mu_{y_j}$, 平方展开后交叉项 $2(d_j - \mu_{y_j})\langle \mu_{y_j} - y_j\rangle$ 恒等于零 (均值的定义就是偏差平均为零), 剩下偏差平方加方差.

代入数字. 目标 $d_j = 1$, 权重噪声让输出在均值 $\mu_{y_j} = 0.6$ 附近抖动, 方差 $V_{y_j} = 0.04$: 期望平方误差 $= (1 - 0.6)^2 + 0.04 = 0.16 + 0.04 = 0.20$. 注意 0.04 这格税: 就算网络平均输出完全命中目标 ($\mu_{y_j} = 1$), 只要权重还有噪声, 误差项就不是零. 噪声从来不是免费的, 它只是便宜.

期望平方误差 = 系统性偏差的平方 + 权重噪声传导到输出的方差. 第一项是网络本身的错, 第二项是噪声的税. 这个分解今天在各种 Bayesian deep learning 教科书里反复出现, 源头之一就是这 9 页纸.

计算上有一个硬骨头: 非线性隐层会把高斯输入变成非高斯输出, 一般前馈网络的期望误差算不出解析解. 论文的限制是: 一层非线性隐单元, 输出单元线性. 此时每个隐单元的总输入仍是高斯 (独立高斯之和), 用一个二维查找表 (均值-方差索引, 300×300 加线性插值) 查出隐单元输出的均值和方差; 输出层是线性的, 各方差独立相加, 期望平方误差和它对全部均值, 方差的精确导数都能高效算出, 不需要耗时的 Monte Carlo. 论文还提到, 对 log variance 做优化保证方差非负且不塌缩到零. 1993 年的人就在操心方差塌缩, 这个问题 20 年后的变分推断文献里还在反复出现.

## 5. bits back: 寄出去的随机数还能要回来

整套方案里最漂亮的一步, 是说明「带噪声的权重到底花多少 bit」. 答案是 KL 散度, 但推导过程值得完整走一遍, 因为它是后来 bits-back coding 和 VAE 通信解释的源头.

通信协议如下. 发送者和接收者事先约定好一个先验分布 P (编码用的高斯). 训练结束后, 发送者手里有每个权重的后验分布 Q. 发送时, 发送者先用一串随机数把后验 Q「塌缩」成一个精确值 w (在某个极细容差 t 内), 塌缩时每个候选值被选中的概率由 Q 决定; 然后用先验 P 对这个精确值编码, 代价是 $C(w) = -\log t - \log P(w)$. 因为 t 远小于 P 的宽度, 这个代价很大. 看起来加噪声是个赔本买卖.

转折在接收端. 接收者收到精确权重和残差之后, 可以还原全部正确输出; 有了正确的输入输出对, 他可以重新跑一遍发送者用的同一个学习算法, 精确重建出发送者当时的后验分布 Q. 注意, 学习算法是确定的, 数据和初值都对得上, 重建是精确的. 既然接收者知道 Q, 又知道最终选中的精确值 w, 他就能反推出发送者塌缩时用的那串随机数. 这串随机数被成功传递了, 它是有价值的通信量, 必须从总代价里退回来. 塌缩一个权重耗费的随机 bit 数是 $R(w) = -\log t - \log Q(w)$.

把代价和退款在分布 Q 下取期望:

$$G(P; Q) = \langle C(w) - R(w)\rangle_Q = \int Q(w)\log\frac{Q(w)}{P(w)}\,dw$$

第一步的化简值得单独看一眼. $C(w) = -\log t - \log P(w)$, $R(w) = -\log t - \log Q(w)$, 相减时两个 $-\log t$ 精确抵消, 剩下 $\log Q(w) - \log P(w)$——这就是「精度税全退」的数学表达: 无论塌缩得多精确, 极细容差 $t$ 造成的开销最后都不计入账单. 然后对 $Q$ 取期望, $\langle \log Q(w) - \log P(w) \rangle_Q$ 按定义写出来就是右边的积分, 即从 Q 到 P 的 KL 散度.

两个高斯之间的 KL 有闭式 (论文 Eq. 9): 均值差的平方项加方差比的对数项. 代入数字看价格怎么随先验变化. 固定后验 $Q = \mathcal{N}(0, 1)$: 先验取 $\mathcal{N}(0, 1)$ 时 KL $= 0$, 后验和先验完全重合, 这个权重没学到任何需要额外通信的东西; 先验放宽到 $\mathcal{N}(0, 4)$ (标准差 2), KL $= \log 2 + 1/8 - 1/2 \approx 0.318$ nat; 先验收紧到 $\mathcal{N}(0, 0.25)$ (标准差 0.5), KL 涨到 $\approx 0.807$ nat. 规律是: 先验与后验重合时免费, 偏离哪个方向都加钱, 且收紧比放宽涨得更快 (0.807 对 0.318). 所以「方差大的权重便宜」有个前提: 先验也得跟着宽, 让两者保持重合, 这正是下一节自适应混合先验干的事.

这就是从 Q 到 P 的 KL 散度. 一个 noisy 权重的真实通信代价, 是后验相对先验的 KL. 方差大意味着 Q 宽, 只要 P 也宽, KL 就小, 权重就便宜, 和上一节的直觉完全对上. 两个高斯之间 KL 有闭式 (论文 Eq. 9): 均值差的平方项加方差比的对数项. 整个式子处处可导, 可以直接塞进梯度下降.

这个「bits back」论证的影响远超这篇论文本身. Frey 和 Hinton 后来把它发展成 free energy 视角下的 bits-back coding, Honkela 和 Valpola 2004 年系统化, 今天 VAE 的 ELBO 里那个 KL 项, 通信解释就来自这条线: 编码潜变量的净开销 = 后验与先验的 KL. 2015 年 Blundell 等人的 Bayes by Backprop 用重参数化 trick 把「训练一团高斯权重」做成可扩展算法, 代价函数同样是误差项加 KL 项. 把这篇 1993 年的论文和 Bayes by Backprop 并排读, 会发现前者已经是一个 mean-field 变分贝叶斯神经网络, 只是没有 Monte Carlo, 没有 reparameterization trick, 全靠一层隐层的解析结构硬算. 它比 VAE 早 20 年.

## 6. 高斯混合先验: 让权重自己聚类

单高斯先验有一个表达力缺陷. 假设任务需要少数权重接近 1, 其余接近 0, 而后验方差都很小 (避免噪声税). 没有任何一个单高斯能同时给 0 附近的尖峰和 1 附近的尖峰赋高概率, 于是每个权重的 KL 都很贵. 解决思路和 Nowlan-Hinton 1992 一样: 用自适应高斯混合当编码先验,

$$P(w) = \sum_{i=1}^{J} \pi_i P_i(w)$$

求和 $\sum_{i=1}^{J}$ 遍历 $J$ 个高斯分量 (实验里 $J = 5$). $\pi_i$ 是第 $i$ 个分量的混合比例, 全部 $\pi_i$ 加起来等于 1, 和圆周率 $\pi$ 没有任何关系, 只是原文用的字母撞了. $P_i(w)$ 是第 $i$ 个高斯, 有自己的均值和方差. 这条式子回答的问题是「先验长什么样」: 不再是一座钟形山, 而是几座钟形山的叠加, 权重落在任何一座山的山顶附近都便宜.

混合的均值, 方差, 混合比例在优化过程中自适应. 两个方向同时进行: 混合模型去拟合权重值的聚类结构, 权重又被拉向就近的高斯中心. 如果一个高斯均值 1 方差小, 另一个均值 0 方差小, 那么描述一个低方差, 取值接近 0 或 1 的权重就非常便宜.

混合先验带来一个积分困难: KL 里出现 $\log\sum_{i=1}^{J} \pi_i P_i(w)$, 对高斯 Q 没有解析解, 而优化过程要反复求值和求导. 论文用了一个上界替代 (论文 Eq. 17):

$$\hat{G} = -\log\sum_{i=1}^{J} \pi_i e^{-G_i}$$

求和 $\sum_{i=1}^{J}$ 遍历 $J$ 个高斯分量. $G_i$ 是后验 $Q$ 与第 $i$ 个分量 $P_i$ 之间的 KL, 即「假设用第 $i$ 座山编码, 这个权重花多少钱」; $\pi_i e^{-G_i}$ 是第 $i$ 个分量的「性价比得分」, 混合比例越高, KL 越小, 得分越高. 外面套 $-\log$, 把「先挑分量再编码」的加权和翻译成总码长. 注意 $\hat{G}$ 一定不小于 $\min_i G_i$ (最便宜那个分量的价格), 多出来的部分就是「还得说明挑了哪座山」的开销.

代入数字. $J = 2$, 混合比例 $\pi_1 = \pi_2 = 0.5$, 两个分量的 KL 分别是 $G_1 = 1$, $G_2 = 3$ nat: 得分 $0.5 e^{-1} = 0.184$, $0.5 e^{-3} = 0.025$, 求和 $Z = 0.209$, 上界 $\hat{G} = -\log 0.209 = 1.566$ nat. 最便宜的分量要价 1 nat, 上界比它贵 0.566 nat, 这 0.566 就是分量归属信息的净开销.

其中 $G_i$ 是后验 Q 与混合中第 i 个高斯 $P_i$ 之间的 KL. 这个上界怎么理解? 论文借统计力学给了答案. 设计一个通信协议: 发送者先按 $r_i \propto \pi_i e^{-G_i}$ 的 Boltzmann 分布随机挑一个高斯分量, 把「挑了哪个」用混合比例当先验编码寄出, 再用选中的高斯编码采样值; 接收者重建后验后能还原全部 $G_i$, 进而还原挑分量时用的随机数, 又一笔 bits back. 总码长减去退款, 恰好等于一个温度为 1 的物理系统的 Helmholtz 自由能 $F = \sum_{i=1}^{J} r_i E_i - H(r)$: 求和遍历 $J$ 个分量, 状态 $i$ 的总能量 $E_i = G_i - \log \pi_i$ (分量内的 KL 加上「挑了这座山」的码长), $H(r) = -\sum_{i=1}^{J} r_i \log r_i$ 是挑分量那串随机数的熵, 也就是 bits back 退回来的部分. 在 Boltzmann 分布下自由能等于配分函数的负对数 $-\log Z$, $Z = \sum_{i=1}^{J} e^{-E_i} = \sum_{i=1}^{J} \pi_i e^{-G_i}$, 就是上面那个上界. 接着上面的数字验证: $E_1 = 1 - \log 0.5 = 1.693$, $E_2 = 3.693$, Boltzmann 权重 $r_1 = 0.881$, $r_2 = 0.119$, 平均能量 $\sum_{i=1}^{J} r_i E_i = 1.932$, 熵 $H(r) = 0.365$, 相减 $1.932 - 0.365 = 1.566$, 和 $-\log Z$ 分毫不差. 每个高斯分量是一个「状态」, bits back 的退款精确对应 Boltzmann 分布的熵.

把这段翻译成人话: 一个权重属于哪个簇, 本身也要花 bit 说, 但说完之后, 这个簇归属信息又能被接收者推回来一部分, 净代价是自由能而不是能量和. Hinton 后来在 Boltzmann machine 和 Helmholtz machine 里反复使用统计力学类比, 这篇论文是这条思路在通信问题上的早期样板.

## 7. 肽分子实验: 105 个样本, 521 个权重

论文的实验只有一个, 但选得很有针对性: 一类肽分子的活性预测. 每个分子用 128 个参数描述, 输出是一个标量活性值. 训练集 105 个样本, 测试集 420 个. 故意选小训练集, 因为控制权重信息量在小数据场景最有用. 网络 4 个隐单元, 含 bias 共 521 个自适应权重. 521 个参数对 105 个样本, 不加控制必然严重过拟合.

编码先验是 5 个高斯的自适应混合, 初始均值在 -0.24 到 +0.24 之间均匀排开, 相邻间隔 2 个标准差. 权重后验均值初始化为均值 0, 标准差 0.15 的高斯采样, 后验标准差统一从 0.1 出发. 全部参数用共轭梯度同时优化, 混合比例用 softmax 参数化.

论文坦诚记录了一个陷阱, 这也是全文最有诚意的段落. 如果一上来就按权重的完整描述长度惩罚, 优化会迅速把所有权重压成相等的负数, 用输出单元的 bias 把输出固定在训练集目标均值上. 这个解的权重几乎不含信息, 描述长度极低, 总代价很难逃逸. 换句话说, 全局最优的描述长度解是一个「什么都不学」的退化网络, 相对误差约 1.0, 和瞎猜均值一样. 论文原话: 这对 MDL 原则或者我们的权重描述方法都是一个 serious embarrassment. 工程上的解法是退火: 权重代价乘一个系数, 从 0.05 起步, 按 0.05, 0.1, 0.15, ..., 1.0 的日程逐步升高, 每档做 100 次共轭梯度更新, 末档优化到代价变化小于 $10^{-6}$ nat. 先让网络学会拟合, 再逐步收紧码率预算. 这个日程和今天各种 KL annealing, β-VAE 调参, free bits 手法, 动机一模一样.

结果用相对误差衡量 (网络平方误差除以「猜测试集均值」的平方误差). 五次随机重启里总代价最低的那个网络, 相对误差 0.286. 对照组: 同样网络不加噪声, 不惩罚权重信息, 0.967, 基本没学到东西; 精心调过的简单 weight decay, 0.317, 注意这个系数需要在训练集上切出一块做验证, 反复试出来的; 如果允许用测试集挑 weight decay 系数, 能到 0.291, 但论文明确标注 this is cheating; 线性回归 35.6, 灾难级过拟合, 惩罚回归系数平方和并用测试集挑选后降到 0.291, 和最优 weight decay 打平, 原因是小权重下隐单元工作在近似线性区, 整个网络实际退化成线性.

两个定性结果同样重要. 第一, 训练结束后的权重形成三个相当尖锐的簇 (论文 Figure 2 的 Hinton 图, 521 个权重按隐单元分块画出), 混合先验的 5 个高斯自适应地落在了合适的编码位置上 (Figure 3). 权重自动聚类成少数几个层次, 不是设计出来的, 是码率压力压出来的. 第二, 这说明在样本数少于输入维度的情况下, 拟合相当复杂的非线性模型是可能的, 前提是严格控制权重携带的信息量.

## 8. 血缘: 从 MacKay 到 Bayes by Backprop

论文 Discussion 把当时贝叶斯神经网络的三条路摆得很清楚, 这个格局定义了后来二十年的研究方向.

第一条是理想贝叶斯: 在权重空间放先验, 用训练数据乘似然得到完整后验, 归一化, 用整个后验做预测. 正确但 intractable. 最接近的实用版本是 Monte Carlo 采样, Neal 1993 年 (和本篇同年) 展示如何用 backprop 提供的梯度信息高效采样, 这就是后来的 Hamiltonian Monte Carlo for neural networks, Radford Neal 这条线最后沉淀成今天 BNN 的黄金标准.

第二条是 MacKay 1992 的 evidence framework: 用标准训练找到权重空间里一个局部最优点, 在该点周围构造全协方差高斯近似. Laplace 近似路线, 训练后处理, 不改训练过程.

第三条就是本篇: 用更简单的对角高斯近似, 但在训练过程中就把这朵云考虑进去, 让学习算法显式操纵分布而不是点. 论文也如实记录了缺陷: 忽略协方差的非对角项损失多少不清楚, MacKay 私下交流过, 标准 backprop 收敛点周围权重间的相关性是显著的. 作者的辩护是, 当学习算法显式操纵高斯分布时, 代价函数会高估相关噪声所含的信息, 所以学习本身有压力把权重噪声压成独立. 这个「代价函数会惩罚相关性」的观察, 和后来 mean-field 变分推断里 KL 项鼓励独立性的机制, 是同一个东西.

还有一个容易被忽略的副产品. 标准 backprop 要求隐单元输出是输入的光滑函数, 所以必须用 sigmoid 而不是线性阈值单元. 但权重带噪声时, 阈值单元被激活的概率是输入的光滑函数, 噪声自带平滑效果, 于是可以在带线性阈值单元的网络里跑这套算法. 论文的判断是: 优化一整朵高斯云, 有时比优化单个权重向量更容易. 二十年后, 「给参数加噪声让优化景观变光滑」以 evolution strategies, 参数噪声探索, 乃至 SGD 噪声正则的身份反复返场, 源头都可以追到这里.

## 9. 今天的回声: 量化, QAT 与泛化界

把这篇论文放到今天的语境里, 至少有三条回声值得说.

第一条是量化. 论文的关键观察是「精度自适应的码率分配」: 不敏感的权重配粗精度, 敏感的权重配细精度, 用噪声方差当精度的连续松弛, 让梯度下降自己找分配方案. 今天的量化感知训练 (QAT) 在训练里注入量化噪声, 让网络适应低比特表示; 混合精度量化给不同层不同 bit 宽, 搜索分配方案. 形式不同, 思想是同一个: 用噪声换 bit, 用可导的松弛绕过离散的量化搜索空间. 1993 年论文第一节批评固定容差量化「代价函数没有光滑导数」, 整个 QAT 文献可以看作对这个问题的工程回答.

第二条是泛化理论. 「权重携带的信息量少于训练输出所含的信息量, 泛化才好」这句话, 是 PAC-Bayes 泛化界的直觉版本. Dziugaite 和 Roy 2017 年用 PAC-Bayes 给出深度网络第一个非平凡泛化界, 做法正是优化一个随机化权重分布, 复杂度项就是后验与先验的 KL, 和本篇的代价函数逐项对应. Blier 和 Ollivier 2018 年 The Description Length of Deep Learning Models 更直接: 用变分方法估计深度网络的描述长度, 发现泛化好的模型压缩得也好. 1993 年的工程方案, 二十多年后变成了可证明的理论工具.

第三条是 flat minima. Hochreiter 和 Schmidhuber 1997 年的 flat minima 论证: 平坦极小值意味着权重不需要高精度就能保持低误差, 所以描述长度短, 泛化好. 这正是本篇「高方差权重便宜」的几何翻版: 权重方差大 = 输出对该权重不敏感 = 该方向平坦. 今天关于 SGD 隐式偏好平坦解, SAM (sharpness-aware minimization) 显式寻找平坦极小值的整条研究线, 底层的码率直觉在 1993 年这 9 页纸里已经写完了.

## 10. 在 Ilya 清单里的位置

清单前三篇是一条信息论线: 第 1 篇 Aaronson 提猜想, 有趣 = 结构加随机; 第 2 篇 Coffee Automaton 做实验; 第 3 篇 Grunwald 教程给工具, 两段码, 通用码, NML, 把「学习即压缩」变成可计算可证明的准则. 本篇是这条线的第四个节点, 也是时间上的起点: 1993 年, 比 Grunwald 教程早 11 年, 比清单里绝大多数条目早 20 年以上. 它是清单里年份最早的论文之一, 没有 arXiv 版本, 9 页, COLT 会议论文, 引用它的多是贝叶斯神经网络和量化文献.

它在清单里的角色很明确: MDL 的工程化第一例. 第 3 篇告诉你两段码是模型选择的原则, 本篇告诉你这个原则可以直接变成神经网络的训练目标, 权重是第一段, 残差是第二段, 正则化强度是码率分配, 噪声水平是自适应精度. 从这篇出发, 一条线走到 MacKay, Neal 的贝叶斯神经网络, 走到 Graves 2011 和 Bayes by Backprop 2015, 走到 VAE 的 KL 项和 bits-back 通信解释; 另一条线走到 QAT 和混合精度量化, 走到 PAC-Bayes 泛化界和 flat minima. 一篇 1993 年的 9 页会议论文, 同时是这两条线的上游.

也要如实记录它的局限. 解析解只覆盖单隐层加线性输出; 全局最优是退化解, 需要退火日程才能避开, 说明这个训练目标有糟糕的局部结构; 实验只有一个, 作者自己承认 preliminary; 对角高斯假设丢掉的协方差信息, 到今天还是 mean-field 方法的已知伤口. 它不是一篇「解决了问题」的论文, 是一篇「把问题定义对了」的论文. 权重里该记多少信息, 用 bit 衡量, 用噪声控制, 用梯度下降优化, 这个框架 30 年没过时.
