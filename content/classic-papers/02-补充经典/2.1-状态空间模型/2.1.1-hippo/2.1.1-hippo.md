# HiPPO: 最优多项式投影记忆

> 原始论文：Gu et al., NeurIPS 2020, [arXiv:2008.07669](https://arxiv.org/abs/2008.07669)。

HiPPO 是 2020 年 NeurIPS 的一篇论文,
全名是 "Recurrent Memory with Optimal Polynomial Projections".
它回答了一个基础问题:循环神经网络应该如何压缩无限长的历史输入.
答案是把过去时刻的输入信号投影到一组正交多项式基上,
通过解一个连续时间的常微分方程来更新投影系数.
HiPPO 的投影构造被后续 S4 直接采用，也是理解现代结构化状态空间模型的重要理论入口。Mamba 继承了状态空间建模路线，但不能简单写成由 HiPPO 单篇论文“直接催生”。

## 1. RNN 记不住长序列,问题出在哪?

循环神经网络用一个隐藏状态 h_t 概括历史.
理论上 h_t 应该包含过去所有输入的信息,
实际上梯度反向传播几十步后就衰减到几乎为零.这个现象叫梯度消失,
也是 RNN 在长序列任务上失败的根本原因.

LSTM 和 GRU 用门控机制缓解这个问题,
但没有从数学上回答 "最优记忆" 应该长什么样.
如果我们把历史看作一个函数 f(t),
RNN 的学习目标是找到一个固定维度的向量,能最好地近似这个函数.
HiPPO 把这个近似问题形式化,并给出了闭式解.

一个简单 RNN 对历史输入的记忆曲线:
100 步之后信号衰减超过 99%.这不是训练不足导致的,
而是架构本身的信息压缩能力有限.

## 2. HiPPO 的核心思想:把历史投影到正交基

假设当前时刻是 t,过去所有输入构成一个时间函数 x(tau).
这个函数定义在区间 (-inf,t] 或 [0,t] 上.它的维度无限,无法直接存储.
HiPPO 的做法是:用一组基函数来逼近 x(tau),只保存基函数前面的系数.

基函数的选择很关键.如果基函数不正交,系数的更新会很复杂.
如果基的 "记忆窗口" 不合适,远处的信息要么丢失,要么和近处混淆.
HiPPO 选择了勒让德多项式作为基,原因有三点.第一,
勒让德多项式在固定区间上两两正交.第二,它们有成熟的递推关系,
适合数值计算.第三,通过调整测度可以控制记忆的时间尺度.

投影系数的个数等于隐藏状态的维度.一个 256 维的 HiPPO 隐藏状态,
相当于用 256 个勒让德多项式去拟合历史函数.

这条曲线代表过去的输入信号.它在每个时刻被投影到一组固定的基函数上,
得到的系数就是循环神经网络的隐藏状态.

## 3. 勒让德多项式作为基的优势

勒让德多项式 P_n(x) 定义在区间 [-1,1] 上,满足正交条件:
不同阶数的多项式在这个区间上的加权内积为零.前几阶分别是 P_0(x)=1,
P_1(x)=x,P_2(x)=(3x^2-1)/2,P_3(x)=(5x^3-3x)/2.

正交性带来一个好处:投影系数可以独立更新.如果基不正交,
更新一个系数会影响其他系数,导致循环动态耦合在一起.
勒让德多项式的递推关系也让矩阵构造变得简单.HiPPO 利用这个性质,
推导出隐藏状态应该满足的微分方程 dh/dt = A h + B x.

不同阶数的多项式捕捉历史函数的不同频率成分.低阶对应慢变趋势,
高阶对应快速波动.隐藏状态的每个维度因此有明确的语义.

## 4. 连续时间记忆的数学形式

HiPPO 把历史压缩问题写成一个最优投影.在当前时刻 t,
找一个 d 维系数向量 c(t),
使得用勒让德多项式重建的历史函数与真实历史之间的加权平方误差最小.
权重由一个测度决定,测度决定了不同历史时刻的重要性.

最常用的测度是 LegS,全称 Legendre Scale,它的权重随时间指数衰减.
这意味着越近的事件权重越高,越远的事件权重越低,符合直觉.
对应的投影叫做 "scaled Legendre measure".

优化问题的目标函数是:对过去每个时刻 tau,误差为 (x(tau) - 重建(tau))^2,
再乘以权重 w(tau).HiPPO 证明,
这个投影可以通过一个线性常微分方程来在线更新,而不需要每次重新计算积分.

输入 x(t) 进入 HiPPO 算子,输出隐藏状态 h(t).
h(t) 是对历史输入的最优投影系数,更新规则由一个线性 ODE 控制.

## 5. HiPPO 矩阵 A 的显式构造

HiPPO 最重要的理论结果是矩阵 A 的闭式表达式.对于 LegS 测度,
A 的每个元素可以写成:

A_{nk} = (2n+1)^{1/2} (2k+1)^{1/2} * 某个与 n,k 相关的有理函数

具体地,当 n > k 时,A_{nk} = - (2n+1)^{1/2} (2k+1)^{1/2}.当 n = k 时,
A_{nn} = -1/2.当 n < k 时,A_{nk} = 0.这个矩阵是下三角矩阵,
带有负对角线,保证系统稳定.

输入矩阵 B 也有闭式形式:B_n = (2n+1)^{1/2}.这些矩阵不依赖数据,
只依赖基的阶数和测度.
这意味着 HiPPO 层的前向传播可以写成标准的 SSM 形式,
然后用已有的数值方法离散化.

这是一个下三角矩阵,非零元素集中在对角线和左下角.
下三角结构保证了状态更新的因果性:高阶系数只受低阶系数影响.

## 6. 从连续到离散:HiPPO 与 SSM 的关系

HiPPO 的连续时间形式是 dh/dt = A h + B x,输出 y = C h.
这正是线性状态空间模型的标准写法.下一步是把连续系统离散化,
得到循环或卷积形式.

论文使用了一种叫做 bilinear transform 的离散化方法,
把步长 Delta 引入矩阵.
离散化后的递推关系为 h_k = A_bar h_{k-1} + B_bar x_k.
这个递推可以在序列上逐个元素执行,计算复杂度与序列长度成线性关系.

S4 的做法是把 HiPPO 矩阵 A 对角化,用 Cauchy 核做快速卷积.
Mamba 则在此基础上加入了输入自适应的选择机制.HiPPO 提供了理论基础,
S4 提供了工程实现,Mamba 提供了表达能力.

连续 ODE 经过离散化后,变成一个可以在 GPU 上逐 token 更新的循环单元.
这一步把数学构造变成了可训练的神经网络层.

## 7. 三种测度:LegS,LegT 和 LagT

论文提出了三种测度,对应不同的应用场景.LegS 使用指数衰减权重,
适合没有明确时间边界的流式数据.LegT 使用固定长度窗口,
适合已知序列长度的情况.LagT 使用伽马测度,适合有噪声或非平稳输入.

LegS 最受欢迎,因为它在时间上 "尺度不变":无论序列多长,
记忆窗口都会自动拉伸.
这个性质让基于 HiPPO-LegS 的模型在不同长度输入上表现稳定.
LegT 则更适合离线任务,比如固定长度的音频或文本分类.

三种测度对应的 A 矩阵结构略有不同,但都保持下三角和稳定.
LegS 的 A 矩阵所有特征值实部为负,保证任何初始扰动都会随时间衰减.

LegS 的记忆权重随时间指数衰减,LegT 只在固定窗口内有非零权重,
LagT 的权重分布更偏重于近期.选择哪种测度取决于任务的时间结构.

## 8. 实验:函数逼近与长程依赖

论文首先在合成任务上验证 HiPPO 的记忆能力.
任务是给定一个由低频和高频正弦波叠加的函数,
要求模型在只看到一个有限维隐藏状态的情况下重建整个历史.
HiPPO 在 256 维状态下达到了很高的重建精度,
而标准 RNN 需要大得多的状态维度.

在 TIMIT 语音识别任务上,把 LSTM 的初始状态或遗忘门用 HiPPO 矩阵初始化,
可以小幅提升帧分类准确率.虽然提升不大,
但证明了 HiPPO 构造在真实数据上的可用性.
这种初始化相当于给循环网络一个先验:隐藏状态应该按照正交投影的方式组织.

最有说服力的实验来自 Long Range Arena.
这个基准包含六个需要长程依赖的任务,
例如 Path-X 要求模型判断两张 128x128 图像中的路径是否连通,
序列长度达到 16384.
HiPPO 初始化帮助 S4 类模型在多个任务上取得当时最好的结果.

原始历史函数由多个频率成分叠加.
用 64 维 HiPPO 状态重建的曲线与真实曲线几乎重合,
说明投影保留了足够的信息.

## 9. 从 HiPPO 到 S4 再到 Mamba

HiPPO 论文发表两年后,同一组作者提出了 S4.
S4 的核心创新是把 HiPPO 矩阵 A 对角化,并设计了近似计算算法,
让线性 SSM 可以像卷积一样并行训练.这个突破让状态空间模型在图像,音频,
时间序列等多个领域取得 SOTA.

Mamba 进一步把 S4 从线性扩展到输入自适应.
它让每个输入 token 动态选择记住什么,忘记什么,同时保持线性复杂度.
HiPPO 的最优投影保证了即使状态维度固定,也能最大程度保留历史信息.
Mamba 的选择机制则决定哪些历史信息值得保留.

这条脉络说明,理论构造和工程创新是交替推进的.
HiPPO 回答了 "应该记住什么",S4 回答了 "如何快速计算",
Mamba 回答了 "如何根据输入选择".

HiPPO 提供连续时间记忆的理论基础,S4 把它变成可扩展的深度学习层,
Mamba 引入选择机制恢复 Transformer 式的表达能力.
三者共同构成状态空间模型的主线.

## 10. HiPPO 的局限与未解问题

HiPPO 最大的限制是它只适用于线性系统.当状态更新是非线性时,
最优投影的闭式解不再存在.现代序列模型中的激活函数,门控,
注意力都是非线性的,如何把 HiPPO 思想扩展到非线性设置仍是开放问题.

另一个限制是 HiPPO 假设历史函数足够光滑.如果输入包含突变或脉冲,
多项式基的逼近误差会很大.
实际语言数据中的罕见 token 和新词就属于这类情况.

此外,HiPPO 的矩阵构造基于特定测度.不同任务可能需要不同的测度,
但测度的选择缺乏系统指导.近期一些工作尝试学习测度或参数化 A 矩阵,
初步结果显示有提升空间.另一条思路是把 HiPPO 与注意力机制结合,
让模型在需要时显式访问压缩后的历史.
这条方向可能是连接理论与应用的关键桥梁.

理论假设历史函数光滑且有界,真实数据经常包含离群值和分布漂移.
这个差距限制了 HiPPO 在通用语言建模上的直接应用.

## 11. 结语:一篇被低估的奠基性工作

HiPPO 不是一篇给出惊艳实验结果的论文.
它的价值在于把 RNN 的记忆问题数学化,并给出了一个可计算的最优解.
在 Transformer 主导的时代,这类工作容易被忽视,
但它为后来的线性复杂度序列模型提供了关键的理论支点.

要理解 Mamba 如何在长序列上同时保持效率和精度,绕不开 HiPPO.
它证明了:好的记忆机制不是凭空设计出来的.
这种机制可以从连续时间逼近理论中推导出来.
这句话听起来抽象,但它意味着 RNN 的记忆方式可以有数学最优解.

三个关键词定义了 HiPPO:连续时间投影,勒让德多项式基,最优记忆.
它们共同把无限历史压缩成了有限维隐藏状态.
