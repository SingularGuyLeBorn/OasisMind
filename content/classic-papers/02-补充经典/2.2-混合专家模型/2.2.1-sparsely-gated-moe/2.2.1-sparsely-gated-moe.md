# MoE 经典（一）深度精读：《Outrageously Large Neural Networks: The Sparsely-Gated Mixture-of-Experts Layer》

> 原始论文：Noam Shazeer, Azalia Mirhoseini, Krzysztof Maziarz, Andy Davis, Quoc Le, Geoffrey Hinton, Jeff Dean（Google Brain），[arXiv:1701.06538](https://arxiv.org/abs/1701.06538)，2017。整理日：2026-08-24。

## 一、问题与动机

**容量瓶颈**：神经网络吸收信息的能力受参数数量限制——要学更多就得加参数，但加参数=加计算。当时训练数据（互联网语料）的规模远大于模型能消化的能力。

**条件计算的理论承诺**：Per-example 激活部分网络（conditional computation）理论上能"容量暴涨、计算不按比例涨"。但此前所有实践都失败，卡在三个工程难题：
1. **负载不均衡**：门控总把输入丢给少数几个专家，其余专家闲置
2. **通信开销**：专家分布在不同 GPU 上，跨设备激活成本高
3. **门控难训练**：稀疏不可微选择 + 批间不一致，梯度噪声大

## 二、方法：Sparsely-Gated MoE 层

### 结构
- **专家**：最多**数千个**前馈子网络（FFN），每个独立小网络
- **门控网络**：可训练的线性层 + softmax，为每个输入 token 输出对每个专家的得分
- **稀疏组合**：每个 token 只激活 top-k 个专家（k 通常取 2~4），其余不参与

### 门控机制（Noisy Top-k Gating）
门控得分公式（论文式 1）：

$$G(x) = \mathrm{softmax}\left(\mathrm{TopK}(H(x), k)\right),\quad H(x)_i = (x \cdot W_g)_i + \epsilon \cdot \mathrm{softplus}((x \cdot W_{\mathrm{noise}})_i)$$

- 训练时给门控得分加**可学习噪声**（第二项）：鼓励探索，让专家被更均匀地使用
- 测试时噪声置零，取确定性 top-k
- $W_g$ 是门控权重，$W_{\mathrm{noise}}$ 是噪声幅度权重（可训练）

### 负载均衡损失（辅助损失）
为了对抗"赢家通吃"，论文加了一个辅助损失：每个 batch 内，鼓励各专家被使用的概率均衡（importance loss）且每专家处理的 token 数均衡（load loss）。总损失 = 主任务损失 + 权重系数乘辅助损失。这是**第一个把负载均衡做进训练目标**的稀疏 MoE 方案。

### 应用方式
把 MoE 层**卷积式**插入堆叠 LSTM 层之间——在时间步和 batch 维度上共享同一套门控决策，降低计算、利于并行。

## 三、实验与数字

| 任务 | 模型 | 结果 |
|---|---|---|
| 语言建模（1B Word Benchmark） | 137B 参数 MoE-LSTM | 困惑度显著优于当时 SOTA（如 LSTM 集成） |
| 机器翻译（WMT En→Fr / En→De） | MoE 插入 encoder/decoder | 同等或更低计算成本下 BLEU 超过 SOTA |

- **容量提升大于 1000 倍**，GPU 集群上仅少量计算效率损失
- **137B 参数但每次推理只激活一小部分**——"outrageously large"的名字由此而来
- 关键发现：稀疏 MoE 的收益在**数据量大**时最明显（容量吸收知识），小数据下收益有限

## 四、局限（论文自述 + 后续发展印证）

- **通信仍是瓶颈**：专家跨设备，门控决策需要 all-to-all 通信
- **训练不稳定**：超参敏感（噪声、辅助损失系数、top-k）
- **专家塌缩**：极端情况下门控把所有输入给一个专家（后来叫 router collapse）
- 计算 vs 容量解耦，但**显存**不省——所有专家参数都要驻留内存

## 五、为什么是经典

1. **第一个工程可行的稀疏 MoE**：负载均衡损失 + noisy gating 的配方至今仍被沿用
2. **定义了"稀疏激活"范式**：参数可以远超计算——直接预演了 GPT-4 / Mixtral / DeepSeek-MoE 的架构选择
3. **Jeff Dean / Hinton / Quoc Le 署名** + ICLR 2017 时代背景：同一届最佳论文（神经程序递归泛化）通向"程序学习"，这篇通向"规模化的条件计算"——后者十年后统治 LLM

## 六、后续谱系

Shazeer 2017 → **Switch Transformer（2021，见下一篇）**：top-1 简化、进预训练主流 → GShard（分片并行）→ GLaM（万亿+效率）→ Mixtral（8 专家开源）→ DeepSeek-MoE（细粒度+共享专家）→ 2026 混合架构常态。
