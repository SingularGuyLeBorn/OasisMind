# Infini-gram 技术解析：用后缀数组复活无限阶 n-gram

Infini-gram 回答一个看似过时的问题：在神经大模型时代，统计 n-gram 还有没有价值？论文给出的答案建立在两个现代化改动上。第一，统计模型也使用与大模型相近的数据规模，索引Dolma、RedPajama、Pile和C4，总计约5万亿token。第二，不再把 $n$ 固定为5，而是对每个位置使用训练语料中出现过的最长上下文，得到“无限阶” $\infty$-gram。

传统实现需要预计算每个n-gram及其计数。随着 $n$ 增大，表规模迅速爆炸；论文指出，仅1.4万亿token语料的5-gram表就约需28TB。Infini-gram不保存所有子串，而是保存token数组及其后缀数组，在查询时二分定位任意字符串的出现区间。这样，同一索引既支持任意阶n-gram概率，也支持最长上下文、文档取回和组合查询。

## 1. 从固定阶 n-gram 到无限阶回退

**1.1. 经典计数概率.** 固定阶n-gram用最近 $n-1$ 个token预测 $w_i$：

$$
P_n(w_i\mid w_{i-n+1:i-1})=
\frac{\operatorname{cnt}(w_{i-n+1:i})}
{\operatorname{cnt}(w_{i-n+1:i-1})}.
$$

分子统计“上下文加目标token”，分母统计上下文本身。它透明、可精确检查，却有稀疏问题：长串可能从未出现，分子为零，整段困惑度变成无穷。传统backoff会逐步减小 $n$，直到分子为正，再配合Katz等折扣把概率重新归一化。 固定小 $n$ 的损失在于丢弃远距离信息。若语料中已经出现完整专名、代码片段或固定引文，5-gram只能使用末尾4个token，无法利用更长的精确上下文。过去限制主要来自计数表，而不是统计定义本身。 **1.2. Infini-gram 的有效阶数.** $\infty$-gram概念上从无限大 $n$ 开始回退，但停止条件与常见backoff不同：只要分母，即上下文计数，为正就停止，不要求分子为正。有效阶数定义为

$$
n=\max\{n'\in[1,i]\mid \operatorname{cnt}(w_{i-n'+1:i-1})>0\}.
$$

也就是找到当前提示在训练语料中出现过的最长后缀，其长度加一就是有效 $n$。随后用该上下文后各token的经验频率作为下一token分布。如果真实下一token从未接在该上下文后面，它的概率仍可为零。 这个停止方式保证分布天然归一化。有效 $n$ 只依赖已知上下文，不依赖待评分的候选 $w_i$；所有候选共用同一分母，而它们的分子之和恰好等于上下文计数。传统逐候选回退会让不同候选采用不同阶数，因而需要额外折扣。 **1.3. 稀疏估计意味着什么.** 论文把“给定上下文后训练数据只出现过一种下一token”称为sparse estimate。此时一个token概率为1，其余为0。稀疏不等同于上下文只出现一次；上下文可出现多次，只要每次后继相同，分布仍然退化。

长上下文更容易稀疏。它可能表示强模板、逐字记忆或确实确定的局部结构。论文发现稀疏估计比非稀疏估计更常命中真实token，但不能把命中直接解释为神经模型记忆：这是语料统计模型自身的预测，且测试文本可能与索引语料重叠或共享来源。 **1.4. 为什么不单独报告困惑度.** $\infty$-gram允许零概率，任何一个真实token为零都会使整段负对数似然无穷。因此作者不把它作为独立困惑度模型，而是与神经LM插值：

$$
P(y\mid x)=\lambda P_\infty(y\mid x)+(1-\lambda)P_{neural}(y\mid x).
$$

只要神经模型对词表给非零概率，混合分布就保持有限。插值把精确语料记忆与神经模型的平滑泛化结合；$\lambda$ 太大会放大统计模型的零概率和语料偏差，太小则收益有限，必须在验证集调节。 **1.5. 无限阶指每个位置自适应选择阶数.** 「无限阶」不表示一次显式建立包含无限历史的参数表。给定前缀 $x_{1:t}$, 系统寻找它在语料中出现过的最长后缀。设

$$
\ell^*(x_{1:t})=\max\{\ell\in[0,t]:
\operatorname{cnt}(x_{t-\ell+1:t})>0\},
$$

有效阶数为 $n^*=\ell^*+1$。随后用该后缀的所有训练出现位置统计下一 token。不同测试位置拥有不同 $n^*$, 同一位置对所有候选下一 token 使用同一个分母和上下文。 这一点与朴素逐候选回退不同。若对候选 $y$ 在长上下文分子为零时单独缩短上下文, 不同 $y$ 会采用不同阶数, 所有概率之和通常不为 1。Infini-gram 只在上下文分母为零时回退, 找到出现过的最长后缀后一次性计算该上下文的完整后继分布, 所以天然归一化。 举例说, 查询上下文 token 为 $(a,b,c)$。若训练语料从未出现 $(a,b,c)$, 出现过 $(b,c)$ 三次, 后继分别为 $d,d,e$, 则 $\ell^*=2,n^*=3$, 有 $P(d\mid b,c)=2/3$、$P(e\mid b,c)=1/3$。即使训练中存在 $(c,f)$, 候选 $f$ 也不能单独退到短上下文获得概率, 因为有效上下文已经统一确定为 $(b,c)$。

若连末项 token 都未出现, 算法继续退到空上下文, 得到 unigram 分布。文档边界 token 必须参与约束, 否则后缀可能从一篇文档尾部跨到下一篇开头, 产生语料中从未作为连续文本出现的上下文。 **1.6. 稀疏分布与单次出现不是同义词.** 论文把后继分布只有一个非零 token 称为 sparse estimate。上下文计数可以是 1, 也可以出现许多次但每次都接同一 token。前者可能是单次偶然, 后者是重复模式; 两者的条件概率都等于 1, 置信程度却不同。 设最长后缀出现 $c$ 次, 唯一后继 $y$ 也出现 $c$ 次。若用对称 Dirichlet 先验、词表大小 $V$、每类伪计数 $\alpha$, 后验均值为

$$
E[p(y)\mid c]=\frac{c+\alpha}{c+V\alpha}.
$$

$c=1$ 与 $c=100$ 的后验置信明显不同。Infini-gram 保留经验分布的尖锐性, 插值时再依赖神经分支处理零概率。因此有效 $n$、上下文计数 $c$ 与后继熵是三条不同轴。长后缀说明匹配具体, 大计数说明证据重复, 低熵说明后继集中。 **1.7. 最长匹配估计带有选择偏差.** 算法在许多候选后缀长度中选择最长的非零者。这个数据依赖选择倾向于找到支持样本最少、分布最尖锐的上下文。即使真实过程只依赖短上下文, 大语料中也可能偶然出现一条更长匹配, 使经验分布退化为单点。

可把它视为在 $t+1$ 个模型间选择: 空上下文、末尾 1 token、末尾 2 token, 直到完整前缀。最长非零规则不使用验证集惩罚复杂度。随着索引规模增加, 更长后缀更容易出现, 有效阶数上升; 这可以提升记忆性预测, 也会增加偶然匹配。 一个可证伪对照是设置最小上下文计数 $c_{min}$, 选择最长且计数至少为 $c_{min}$ 的后缀。$c_{min}=1$ 回到论文方法; 提高阈值会缩短有效 $n$, 降低单次记忆的权重。比较人类文本准确率、时移困惑度和逐字复制率, 可判断单次长匹配贡献多少收益与风险。 另一个对照是在一半索引中选择最长后缀, 用另一半估计后继分布。若准确率大幅下降, 原结果包含明显的同样本选择收益; 若仍稳定, 长上下文本身具有可迁移预测力。 **1.8. 经验概率的方差随上下文计数变化.**

固定上下文 $h$ 出现 $c$ 次, 后继 $y$ 出现 $k$ 次, 最大似然估计 $\hat p=k/c$。在独立二项近似下

$$
\operatorname{Var}(\hat p\mid c)=\frac{p(1-p)}{c}.
$$

上下文只出现一次时, 估计只能是 0 或 1; 出现次数增长后才稳定。长后缀通常 $c$ 更小, 所以「上下文更具体」和「统计估计更不稳定」同时发生。 训练语料并非独立样本。转载、模板和同一文档重复会让多个出现高度相关, 有效计数小于原始 $c$。若一句话被一百个镜像网页复制, 计数 100 并不等于一百次独立语言事件。索引语料的去重政策直接决定概率含义。 可以按文档而非出现位置计数: 每篇文档最多贡献一次后继, 或先对近重复簇归一。这样减少镜像权重, 也会削弱真实高频表达。Infini-gram 使用训练 token 多重集的精确出现次数, 最适合回答模型实际训练分布中的频率。 **1.9. 零概率解释了为何不单独算困惑度.**

只要参考文本某一步真实 token 在最长上下文后从未出现, $P_\infty(y\mid h)=0$, 该 token 的负对数似然为 $+\infty$。整段平均包含一个零概率就得到无限困惑度。扩大语料能减少零事件, 无法对开放词序列完全消除。 经典 n-gram 用加法平滑、Katz discounting 或 Kneser-Ney 给未见事件分配质量。Infini-gram 的重点是保留任意长精确计数, 没有为所有阶设计统一平滑。论文因此评估 token agreement, 再与全支持的神经分布插值。 插值后只要神经模型对每个 token 给正概率, 混合分布也为正。统计分支能在匹配时提高正确 token 概率, 错误尖峰则由神经分支的 $(1-\lambda)$ 保底。这个机制解释困惑度改善, 也说明 $\lambda=1$ 通常不可用。

## 2. 后缀数组怎样代替天文规模计数表

**2.1. 一个索引表示全部子串.** 长度为 $N$ 的token数组有 $N$ 个后缀。后缀数组存储这些后缀按字典序排列后的起始位置。任何查询串作为前缀出现的后缀在排序结果中形成一个连续区间，因此用两次二分查找找到左右边界，区间长度就是出现次数。长度为 $L$ 的查询复杂度为 $O(L+\log N)$。 后缀数组没有逐条存储n-gram。一个位置参与许多不同长度的查询，所有子串共享同一套排序指针。论文估计5万亿token索引隐式对应至少2000万亿个独特n-gram；若枚举全部可能长度的子串，理论条目甚至接近 $N^2/2$，物化不可行。 **2.2. 字节布局与7N空间.** 语料先token化，相邻文档以特殊的 `0xffff` token分隔，避免匹配跨越文档边界。词表小于 $2^{16}$ 时，每个token ID用2字节，所以token数组占 $2N$ 字节。后缀数组每个token保存一个指向token数组的字节偏移。

论文处理的分片为20亿到5000亿token。在这个范围，偏移可用5字节保存，后缀数组占 $5N$，两者合计约 $7N$ 字节。5000亿token分片原始索引约3.5TB；磁盘常驻而不是全载入内存，是系统能扩到万亿规模的关键。 **2.3. 构建成本与可加性.** 后缀数组可线性时间构建，但常数、内存和I/O很大。团队在单节点128 CPU、1TiB RAM上构建RedPajama 1.4万亿token索引约用48小时。论文还构建Dolma 3万亿、Pile 3800亿、C4 2000亿token索引。 这里的“可加”指查询时并行访问独立索引, 将计数相加、最长匹配取最大并汇总文档位置, 无需把多个后缀数组物理合并成全局排序。这样新增语料无需重建已有分片，也便于按数据源分析贡献。代价是查询fan-out随分片数增加，吞吐受磁盘并发限制。 **2.4. 磁盘驻留查询.**

索引保留在磁盘，只把少量搜索状态放入RAM，不使用GPU。字符串计数需要找到后缀数组区间边界；二分过程会产生随机读，因此SSD延迟和预取策略很重要。系统采用并行分片、hinted search、内存预取、快速有效阶查找与摊销查询等优化。 在RedPajama上，最优化引擎的单串计数平均低于20毫秒；固定阶n-gram概率与下一token分布约40毫秒；$\infty$-gram约200毫秒。后者要确定最长已见后缀并获取后继分布，查询比单次计数多。数字来自特定语料与硬件，不能直接外推到5万亿组合索引或高并发API。 **2.5. 后缀数组保存的是排序位置.** 设 token 数组为 $T[0:N)$。第 $i$ 个后缀是 $T[i:N)$, 后缀数组 $SA$ 是位置的排列, 满足

$$
T[SA[0]:] < T[SA[1]:] < \cdots < T[SA[N-1]:]
$$

的字典序。索引不复制每条后缀内容, 只保存每个起点在排序中的位置。查询时仍需回到 token 数组比较实际 token, 所以 token array 与 suffix array 缺一不可。 对查询串 $q$ 做 lower bound, 找到第一个不小于 $q$ 的后缀; 再找第一个不以 $q$ 为前缀的后缀作为 upper bound。区间长度 $r-l$ 就是精确出现次数。所有以 $q$ 开头的后缀连续, 这是字典序提供的关键不变量。 若 $q=(u,v)$, 区间中的每个 $SA[j]$ 指向一次 $(u,v)$ 出现。下一 token 位于 $T[SA[j]+2]$。扫描这些位置并聚合即可得到后继计数。上下文在文档尾部时, 后继是分隔符, 应按模型定义排除或作为 EOS 处理。 **2.6. 7N 字节来自两种数组.** 论文的词表小于 $2^{16}$, 每个 token ID 用 2 字节, token array 占 $2N$。分片规模在 2B 到 500B token, 指针字节偏移可用 5 字节表示, suffix array 占 $5N$。合计为 $7N$ 字节/token。

这里的指针存字节 offset, 合法 token 起点都是偶数。7N 是论文实现的核心数组量级, 不含文件系统、分片元数据、构建临时空间和缓存。5T token 若全部按 7 字节估计为 35TB。 系统把 Dolma、RedPajama、Pile 与 C4 分成多个索引, 查询时合并计数。组合不要求建立一个全局后缀数组, 因而「可加」指结果计数可求和, 不是排序数组可以直接首尾拼接。 **2.7. 分片加法成立的条件.** 语料拆成 $K$ 个不重叠分片 $D_k$, 某串 $q$ 的全局计数满足

$$
\operatorname{cnt}(q\mid D)=
\sum_{k=1}^{K}\operatorname{cnt}(q\mid D_k),
$$

前提是文档没有被切开造成跨分片连续串丢失, 或定义本来就禁止跨该边界。每个分片独立二分, 计数相加, 后继直方图也逐 token 相加。 最长后缀查询需要全局判断。某个长后缀可能只在第 7 个分片出现, 其他分片为零; 系统不能因前几个分片未命中就提前回退。应对所有可用分片求计数, 找到全局最长非零后缀。 部分分片故障会造成非单纯降采样。若长后缀唯一出现恰在离线分片, 有效 $n$ 直接缩短, 分布会换一套上下文。返回结果应带成功分片集合与索引版本, 避免把不完整统计伪装成精确全局值。 **2.8. 最长后缀可以复用单调性.**

若长度为 $\ell$ 的后缀出现, 它的所有更短后缀也必然出现; 若某后缀计数为零, 更长且以它为尾部的候选也为零。计数关于后缀长度具有单调的非零边界, 可以二分搜索 $\ell^*$, 无需从完整前缀逐 token 回退。 对连续生成还可复用前一步结果。上一步最长后缀为 $h$, 新 token $y$ 到来后, 新候选是 $(h,y)$; 若未出现, 再退掉 $h$ 的开头。论文提到 fast effective-n lookup 和 amortized query processing, 正是在利用相邻查询高度相关。 最坏复杂度与平均复杂度不同。非常长且常见的重复文本可能维持大 $n$, 后继区间却很小; 常见短上下文区间巨大, 枚举完整后继分布更贵。查询延迟取决于搜索长度、区间大小、分片数与磁盘缓存。 **2.9. 后继分布计算比单次计数更昂贵.**

计数一个指定 $q$ 只需找一个后缀区间。计算下一 token 分布还要读取区间中每个出现位置的后继并聚合。若上下文非常常见, 区间可能包含数百万位置, 扫描代价高于两次二分。 固定阶分布可以通过缓存、预取或对热点上下文预聚合加速。无限阶先要找有效 $n$, 再读取对应区间, 因而三项延迟依次增加。只求真实下一 token 概率时, 可以分别计数 $h$ 与 $(h,y)$, 不必枚举所有词表后继。 论文在人类文本分析中采用概率查询, 并以真实 token 概率大于 0.5 作为 agreement。因为一个分布不可能有两个 token 概率都超过 0.5, 该条件必然意味着真实 token 是唯一 argmax; 它是 top-1 正确率的下界。 **2.10. 字节编码把 tokenizer 固定进索引.**

token ID 以两字节编码, 字典序作用于编码后的 ID 序列。不同 tokenizer 会产生不同边界与 ID, 必须重建 token array 和 suffix array。论文为 GPT-2/GPT-Neo/J、Llama-2 与 SILO 的不同 tokenizer 分别建索引。 这不是格式转换问题: 同一句文字在三个词表中的 token 串不同, 有效 $n$、计数和概率都随之改变。跨 tokenizer 的 token 级 perplexity也不可直接比较。 分隔符 `0xffff` 要落在正常词表之外。若未来词表使用全部 16 位空间, 两字节假设与保留值都需修改。文档中还可能有 BOS/EOS 等特殊 token, 需要明确是否写入索引以及查询如何处理。 **2.11. 构建线性时间不等于资源很小.** 后缀数组存在理论线性时间算法, 运行时仍要对万亿 token 做大规模内存访问和排序式组织。RedPajama 的约 48 小时来自单节点 128 CPU 与 1TiB RAM, 是特定实现与硬件证据。

若内存装不下构建状态, 外排会增加磁盘读写; 若分片更小, 单片易构建但查询要访问更多分片。分片大小在构建峰值内存与在线并行开销之间取舍。 构建复现还要固定 tokenization、文档顺序、分隔符、分片边界和 suffix-array 实现。后缀排序结果在相同 token array 上是确定的, 输入顺序改变会改变位置与文档取回映射, 计数在不跨文档时可保持。

## 3. 查询与推理过程

**3.1. 计数区间如何得到.** 给定token串 $x_{1:L}$，系统在后缀数组中寻找第一个不小于它的后缀，以及第一个严格大于所有以它开头后缀的位置。两个边界相减就是计数。比较后缀与查询时最多读取 $L$ 个token，所以复杂度包含 $L$；二分数组位置产生 $\log N$ 项。 文档检索使用同一区间内的后缀位置，再根据token偏移映射到文档。合取范式查询可以要求多个n-gram同时存在，用于语料探索。统计概率、训练数据搜索与数据归因由同一底层索引支持。 **3.2. 最长后缀查询.** $\infty$-gram需要在提示的所有后缀中找到最长且计数非零者。朴素做法对长度逐一计数，长提示会产生许多随机I/O。优化实现利用相邻时间步上下文高度重叠：前一步已知匹配区间可以为下一步搜索提供hint，并把多项请求批量处理。

有效阶数本身是有意义的分析量。它表示当前文本尾部有多少token能在训练语料中找到精确先例。人类文本、模型文本、不同解码策略和不同模型规模可比较其分布，但tokenizer变化会改变长度，跨词表比较必须重新定义单位。 **3.3. 下一token分布的成本.** 找到上下文区间后，区间中每个匹配位置的下一个token构成计数分布。若区间巨大，逐个扫描会很慢；若上下文很长，区间通常很小。系统需在短高频上下文与长稀疏上下文之间处理不同访问模式。 返回完整词表分布比查询一个目标token成本更高。分析next-token accuracy只需选计数最多的后继，插值神经LM则需要把统计分布映射到相同tokenizer并合并概率。论文索引使用对应语料的token化版本，复现时必须保证词表与待插值模型兼容。

**3.4. 条件概率分母对应一个后缀区间.** 对有效上下文 $h$, 后缀数组区间 $I(h)=[l_h,r_h)$ 包含所有以 $h$ 开头的后缀。分母是 $|I(h)|$。加入候选 $y$ 后得到更窄区间 $I(hy)\subseteq I(h)$, 所以

$$
P_\infty(y\mid h)=\frac{|I(hy)|}{|I(h)|}.
$$

所有合法后继区间将 $I(h)$ 按下一 token 分割。忽略文档末尾或把分隔符作为 EOS 后, 区间大小之和等于分母, 因而概率归一化。实现若漏算某些分片或对分隔符处理不一致, 归一化会破坏。 概率查询可返回 count、effective $n$ 和 sparse 标志。三者共同描述证据: count 表示分母样本量, $n$ 表示上下文具体程度, sparse 表示经验支持只有一个后继。只返回概率 1.0 会丢掉前两项。 **3.5. 回退路径是一棵后缀链.** 前缀 $x_{1:t}$ 的候选上下文依次为完整前缀、去掉首 token 的后缀、继续去掉首 token, 直到空串。它们形成包含关系链, 不是任意子串集合。Infini-gram 只利用紧贴预测位置的连续历史, 不会检索前文任意位置的关键词。

这解释了它与 RAG 的差别。提示中早先出现一个实体、尾部换了表达后, 最长后缀可能不含该实体; 向量检索仍可凭语义召回相关文档。反过来, 尾部是一段长精确引文时, suffix 统计能直接找到全部出现位置, 无需学习 embedding。 后缀链还限制远距离依赖。若关键信息与预测位置之间夹有可变内容, 精确长串会断裂, 回退到短上下文。无限阶只表示没有预设长度上限, 不表示能跳过无关 token 建立非连续依赖。 **3.6. 完整分布与 top-k 查询的权衡.** 神经插值理论上需要每个词表 token 的统计概率。实际后继集合只包含在 $h$ 后出现过的 token, 通常远小于词表; 可以返回稀疏 map, 对其余 token 取零。神经分布是 dense, 合并时只需在统计支持集上增加 $\lambda p_\infty$, 再把全体神经概率乘 $1-\lambda$。

若只返回统计 top-k, 被截去后继仍有非零质量, 需要重新归一化或把剩余质量交还神经分支。直接丢弃会使混合概率和小于 1。稀疏支持全集与固定 top-k 不是同一种近似。 上下文很短时后继类型可能接近整个词表, 返回全集成本上升。这些位置统计分布通常也更平, 插值收益可能较小。动态门控可在低 $n$ 或高熵时跳过完整分布查询, 同时要用验证集证明不会损害困惑度。 **3.7. argmax 下界需要按定义解释.** 论文没有为每个位置计算完整 argmax, 而是查询真实下一 token 的概率, 若大于 0.5 就计为 agreement。因为总概率为 1, 条件成立时真实 token 必定是 argmax; 当真实 token 概率为 0.4 且其他每个 token 都更低时, argmax仍正确却不会被计入。因此 47% 是该规则下的下界。

下界缺口取决于分布熵。sparse estimate 只有概率 0 或 1, 下界与 argmax 完全一致; dense estimate 更可能出现正确 argmax低于 0.5。不同有效 $n$ 的 dense/sparse比例变化, 会让该指标与真实 top-1 差距变化。 若要精确比较模型, 可在抽样位置计算完整后继直方图, 估计下界漏掉多少正确 token。只用同一个 0.5 阈值跨语料比较时, 应同时报告 sparse 比例和后继熵。 **3.8. 查询结果可以按来源分解.** 多个独立索引的可加性允许返回每个来源的分子与分母。对来源 $s$ 记 $c_s(h)$ 与 $c_s(hy)$, 全局概率为

$$
P(y\mid h)=\frac{\sum_sc_s(hy)}{\sum_sc_s(h)}.
$$

它不是各来源条件概率的简单平均, 权重由上下文在各来源的计数决定。某个长串只在代码中出现时, 代码来源权重自动为 1; 常见短语则由大来源主导。 来源分解可判断预测来自 Dolma、Pile、C4 还是 RedPajama, 也能发现重复语料被多套索引重复计数。若相同文档同时存在于两个索引, 求和相当于增加权重。组合索引前需要说明跨语料去重是否执行。 对训练数据归因, 返回文档位置比来源计数更直接。长串只有一次命中时, 可以检查是否是评测题、模板、引用或隐私文本; 高频短串则不适合逐文档解释。 **3.9. 缓存会改变延迟分布.**

平均延迟混合了热查询与冷查询。热门短语的后缀区间边界和磁盘页容易驻留缓存, 首次查询罕见长串则可能触发多次随机读。均值无法表示 P95、P99 和冷启动。 连续生成具有强局部性, 相邻 step 共享大部分后缀, hinted search 能减少搜索。独立 API 用户提交随机字符串时复用较少。论文的优化证明引擎可行, 服务容量仍需按真实查询模式测量。 缓存还可能泄露成员信息的侧信道: 已查询过或高频内容响应更快。若索引含敏感内部数据, 权限控制之外还需考虑时间差与文档取回接口。

短上下文通常在语料中出现很多次，后继分布较密；上下文变长后，出现次数下降，最终可能只有唯一后继。论文分别分析dense与sparse $\infty$-gram估计，观察准确率随有效阶变化。长匹配有时来自引用、代码、专名和网页模板，也可能暴露评测污染。 有效 $n$ 不能单独判定污染。自然语言存在高度固定的惯用表达，开放网页也大量转载。更稳妥的方法是取回文档、核对来源与时间，并比较完整评测题和答案是否共同出现。 **4.3. 数据规模消融.** 扩大索引提高找到长上下文的概率，并增加罕见表达的计数稳定性。论文通过不同数据规模比较 $\infty$-gram表现，展示万亿token级数据仍带来收益。这种规模效应与神经缩放不同：参数量不变，主要成本转为磁盘容量、建索引时间与查询I/O。

多个语料简单相加还会把重复网页计为多次观察，改变经验概率。若目标是估计自然文本分布，去重策略很重要；若目标是忠实描述模型实际训练多重集，则应保留训练时重复权重。分析目的必须先明确。 **4.4. 机器生成文本暴露的规律.**

### 4.2. 模型与 $\infty$-gram 一致率

作者比较模型生成token与 $\infty$-gram最可能token是否一致，并按有效后缀长度分析。随着神经模型规模、解码温度和top-p变化，一致率会变化。贪心解码通常更靠近高概率模式，采样增加新组合，因此不能把不同解码策略的曲线直接归因于模型参数。 机器文本与语料统计高度一致可能来自学习语言规律，也可能来自训练片段复现。低一致也可能表示合理创新或神经模型错误。需要结合人类文本基线、有效阶和稀疏性，才能解释差异。

### 后缀长度上的不规则性。

论文观察到机器—$\infty$-gram一致率随后缀长度出现不规则变化，并把它作为神经LM预训练与Transformer位置编码缺陷的信号。直觉上，若模型平滑利用上下文，一致关系应随可用精确上下文长度更规律；局部突变可能表明模型对某些相对位置或上下文范围利用不足。 这是一种诊断相关性，不是因果定位。有效后缀长度同时关联文本类型、重复度、稀有token和语料成员关系。要证明位置编码导致曲线形状，还需控制文本分布并比较不同位置机制的同数据模型。

### 模型规模与数据记忆。

论文覆盖不同规模神经LM。更大模型可能更好拟合训练分布，与统计预测更一致；也可能更善于抽象，从而在未见组合上偏离逐字统计。单一一致率无法区分能力与记忆，按稀疏/非稀疏、有效阶和语料来源分层更有信息。 Infini-gram的优势是能返回精确计数和文档，而不是只给相似度。对异常高阶匹配，可以直接检查训练文本；这为成员分析提供证据，但仍不能由匹配证明神经模型生成时采用了该文档。 **4.5. 47% 混合了语言规律与语料重合.** 人类文本实验从 Pile validation 的每个域抽 50 篇文档, 每篇截到 1024 token, 索引建立在 360B-token Pile train 上。训练与验证属于同一数据集合的既定 split, 域和预处理高度一致。47% 说明同分布 held-out 文本中有大量可由最长精确后缀预测的结构。

该比例至少包含四类来源: 子词内部补全、常用搭配、实体或格式模板、跨 split 的重复或近重复。前两类更接近语言规律, 后两类更依赖语料成员关系。论文给出的定性例子包括多 token 单词、常用短语与实体名, 也指出模型不擅长仅凭短上下文召回事实实体开头。

要拆分贡献, 可按预测位置分类: 是否处于一个词的后续 token、是否含数字或标点、是否位于长文档模板、最长匹配是否来自同一来源或近重复文档。再对严格去重、跨域和时间后移文本重复测量。若准确率主要在词内补全保持, 说明统计规律较通用; 若长串部分显著下降, 原指标包含较多重合。 **4.6. 有效 n 的均值需要结合分布.** 论文报告超过 90% 的 token 有效 $n$ 至少为 5, 中位数为 7, 均值为 9.1。均值高于中位数说明右尾存在很长匹配。少量引用、代码或模板可把均值推高, 单个平均值看不到主体分布。

tokenizer 把常见词拆成不同数量的 token, 有效 $n$ 不是字符或词长度。一个 10-token 匹配可能只是几个长英文词, 也可能是一整句中文或代码片段。跨 tokenizer 应换成字符跨度、字节跨度或解码文本长度辅助比较。 有效 $n$ 还随位置增加受到上限约束。文档开头第 3 个 token 最多只能使用 2-token 上下文, 后部才有机会得到长匹配。比较文档类型时应按相对位置分层, 否则短文档天然拥有较小有效阶。 **4.7. sparse 覆盖率与命中率回答两件事.** 论文指出 sparse estimate 覆盖超过一半 token, 且在稀疏区域真实 token 往往就是唯一后继。覆盖率回答有多少位置遇到单一后继, 条件命中率回答这些位置中多少预测正确。总体贡献约为两者乘积, 还要加 dense 区域的贡献。

索引扩大时 sparse 覆盖率不一定单调上升。新语料可能为原本唯一的上下文增加第二种后继, 把 sparse 变为 dense; 也可能提供更长、只出现一次的后缀, 又恢复 sparse。有效 $n$ 与后继多样性共同变化。 去重同样影响 sparse。删除重复不会改变一个上下文只有哪几种后继, 但可能让更长后缀的唯一出现被移除或保留; 近重复清理还会减少模板长串。比较去重前后 sparse 比例能量化硬记忆路径受多少影响。 **4.8. 神经概率分桶揭示互补区域.** 论文把 Llama-2 给真实 token 的概率分桶, 再看 infini-gram 命中。当神经模型表现很差的低概率区域, infini-gram 仍有超过 20% agreement; 只看 sparse estimate 时可达约 50%。这说明统计分支在一部分神经盲点上提供独立信息。

互补不等于统计分支总是正确。低神经概率位置可能是罕见实体, 也可能是参考文本本身意外或索引中的单次噪声。插值能否改善取决于统计正确时加多少概率、错误时从神经真实 token 扣掉多少。 更完整的校准表应按 $(p_{neural},n,c,H)$ 分桶, 其中 $c$ 是上下文计数、$H$ 是后继熵。每桶估计统计命中率和最佳门控权重, 再到独立测试集验证。论文用 sparse/dense 两组 $\lambda$ 是这一路线的简单版本。 **4.9. 生成解码策略本身改变重合.** 贪心解码每步选神经 argmax, 容易沿高频模板继续, 有效 $n$ 与 infini-gram 一致率较高。提高温度或使用 nucleus sampling 会选择更多低概率 token, 一次偏离训练长串后, 后续最长精确后缀迅速缩短。解码随机性与索引匹配之间存在反馈。

论文观察 nucleus sampling 的有效 $n$ 分布最接近人类文本。这个相似只覆盖精确重合长度, 不等于所有质量维度接近。模型可拥有相似 $n$ 分布却事实错误、语义重复或风格单一。 对同一模型使用 greedy、temperature 与 top-p 是必要对照。若跨模型比较时解码参数不同, 一致率差异无法归因于模型规模。每种随机策略还需多个生成种子, 因为单次 continuation 方差较大。 **4.10. 更大模型的一致率不直接证明更多记忆.** 模型规模增大后, 与训练分布拟合更好, 常见语言模式预测更准, 即使没有逐字记忆也会提高与统计 argmax 的一致。要把记忆与能力分开, 应关注长、稀有、训练中少次出现且对照语料不常见的匹配。

可以构造三组提示: 训练文档的唯一长前缀、同域 held-out 前缀、语义相似但词面改写的前缀。若规模主要提高第一组逐字续写, 更接近成员记忆; 三组都提高则包含通用建模能力。 GPT-Neo/J 与 Pile 索引共享训练语料, 一致率高于训练数据不同的 Llama-2, 为数据成员关系提供证据。架构、tokenizer 和训练预算也不同, 所以仍然不是单因素因果实验。 **4.11. 统计检索、参数记忆与生成是三层事件.** 索引中存在文档是数据层事件; 神经模型参数因训练样本改变是参数影响事件; 生成时输出相同片段是行为事件。三者有关联, 不能相互等同。Infini-gram直接观测第一层和生成文本的词面重合, 对第二层只能提供间接证据。

证明参数记忆可做反事实训练: 从训练集移除目标文档, 保持其他条件训练对照模型, 比较生成概率。成本很高。较廉价的方法包括 exposure、成员推断、不同重复次数和 checkpoint 演化, 仍需要控制相似文档。 生成长匹配也可能由公共短语逐步延伸, 不要求模型存储某一文档地址。反过来, 模型可能记住事实或语义而采用不同措辞, infini-gram检测不到。它是精确词面记忆探针, 覆盖边界应保持清楚。 **4.12. 文档取回让污染诊断可核实.** 当评测 token 具有异常大有效 $n$, 可从后缀区间取回训练文档, 检查题干、选项、答案和解析是否共同出现。仅看计数无法分辨合法同源材料与直接泄漏。

诊断可按最长共同片段长度、出现次数、最早文档时间和来源排序。完整题目加答案且早于测试发布, 可能说明测试源自公开材料; 晚于测试发布的大量转载则是典型污染路径。时间元数据本身也可能缺失或不可靠。 对多个 benchmark 统一阈值会偏向 tokenization 更细或文本更模板化的任务。应同时报告 token 长度与字符长度, 并人工检查阈值附近样本。Infini-gram提供候选证据, 污染结论仍需来源判断。

## 5. 与神经语言模型插值

### 5.1. 困惑度为什么下降.

神经LM擅长平滑泛化，统计模型擅长精确复用长上下文。当测试文本包含训练语料中出现过的长模板时，$P_\infty$ 会把概率集中到少数后继，混合后提高正确token概率；当没有可靠匹配时，较小 $\lambda$ 保留神经分布。 插值收益取决于索引语料与神经模型训练语料、测试分布之间的关系。如果索引包含测试集，困惑度改善可能只是检索泄漏；若索引与模型实际训练数据不一致，混合评估的是外部非参数记忆增强，而非模型自身能力。 **5.2. 固定 $\lambda$ 的限制

所有位置使用同一权重没有利用统计估计置信度。稀疏长上下文可能非常可靠，也可能只是单次噪声；短上下文计数多但分布宽。更自然的门控可依据有效 $n$、上下文计数、熵或数据来源动态调整权重。 论文的固定插值提供清晰基线，避免额外门控模型混淆结论。进一步研究若学习门控，训练验证集必须与最终测试隔离，防止通过权重选择吸收测试信息。 **5.3. 时移与数据孤岛实验.** 非参数索引可以独立于神经权重更新。加入更新时期语料后，统计分支立即覆盖新实体和新措辞，不必重新训练大模型。数据silo实验则可只索引许可范围内的内部文档，以计数方式补充领域知识。

不过 $\infty$-gram只会延续训练文本中已有的token序列，不能像检索增强生成那样读取文档后综合回答。它更接近高速长前缀补全器。对事实问答，必须保证用户提示尾部与语料表达形成足够长的精确匹配，否则新知识不会自动进入分布。 **5.4. 线性插值怎样改变 token 损失.** 对真实 token $y$, 神经概率为 $p_N$, 统计概率为 $p_I$, 混合概率为

$$
p_M=(1-\lambda)p_N+\lambda p_I.
$$

该 token 的损失变化为

$$
\Delta\ell=-\log p_M+\log p_N
=-\log\left[(1-\lambda)+\lambda\frac{p_I}{p_N}\right].
$$

当 $p_I>p_N$ 时损失下降, 当 $p_I<p_N$ 时上升。收益由概率比 $p_I/p_N$ 决定, 不只取决于两者 argmax 是否一致。统计模型给正确 token 0.2、神经模型给 0.01 时增益很大; 两者分别 0.6 与 0.55 时增益有限。 若 $p_I=0$, 混合概率降为 $(1-\lambda)p_N$, 每次错误至少增加 $-\log(1-\lambda)$ 的损失。固定大 $\lambda$ 会在统计零概率位置持续受罚。这解释了为何需要验证集调权以及 sparse 错误必须谨慎。 **5.5. sparse 与 dense 使用两个权重的含义.** 论文为 sparse 和 non-sparse estimate 分别调 $\lambda_1,\lambda_2$。sparse 分布把全部质量放在一个 token 上, 若命中可大幅提升, 若失败则真实 token 获得零统计概率。dense 分布风险更平缓, 也可能只提供接近神经模型的常见频率。 两权重相当于一个一比特门控, 条件只看统计支持大小是否为 1。它忽略上下文计数、有效 $n$、来源与神经置信。简单门控便于解释, 减少在有限验证集上过拟合。

调参目标是验证困惑度, 因而权重针对平均 token 对数似然。生成质量、逐字复制风险和事实正确率可能偏好不同权重。论文明确提到初步开放生成有时无益甚至有害, 说明低困惑度不能自动转成更好采样。 **5.6. 困惑度相对改善使用特殊归一.** 论文将模型 $M$ 相对基线 $M_0$ 的改善定义为

$$
\left(1-\frac{\operatorname{PPL}(M)-1}
{\operatorname{PPL}(M_0)-1}\right)\times100\%.
$$

它测量从基线困惑度到理论完美值 1 的 gap 关闭比例, 不等于普通 $(PPL_0-PPL)/PPL_0$。当基线 PPL 接近 1 时分母很小, 指标敏感; 在常见语言模型区间, 两种比例仍有差异。 困惑度是平均负对数似然再指数化, 少量被统计分支大幅提升的长匹配 token 可以显著改变结果。应并列报告平均 loss 差、不同有效 $n$ 桶的 loss 差和零统计概率比例, 才能看出收益分布。 论文报告 Llama-2 13B 加统计分支可超过 Llama-2 70B 的 perplexity, 70B 插值后低于 4.0。该比较在指定 Pile 测试与对应 tokenizer内成立, 不意味着 13B 混合系统在生成、推理或延迟上全面超过 70B。 **5.7. tokenizer 不同使跨家族 PPL 不可比.** 一个字符序列在粗 tokenizer 下由较少 token 表示, 每 token perplexity与细 tokenizer 不在同一单位。论文明确指出 GPT-2/GPT-Neo/J 共享 tokenizer 可互比, Llama-2 与 SILO 使用不同 tokenizer, 不应跨组直接比 PPL。 字节归一化的 bits-per-byte 可提供跨 tokenizer 辅助量:

$$
\operatorname{BPB}=\frac{-\sum_t\log_2p(x_t\mid x_{<t})}
{\text{文本字节数}}.
$$

但统计索引仍需按各 tokenizer 构建, 混合发生在 token 空间。BPB只统一评测尺度, 不让索引本身跨词表复用。 **5.8. 时间后移实验区分更新与重复.** 索引加入神经模型训练截止后产生的语料, 可以立刻为新措辞和实体提供计数。若测试文本也来自更新时期, 改善可能说明非参数更新有效。严格实验要保证测试文档不在索引中, 只允许相关背景文档进入。 时间切分比随机 split 更难。新闻转载可能把未来测试文章同步进入抓取, 时间戳也可被回填; 新文章引用旧固定句又形成长匹配。应按文档哈希与近重复簇去污染, 再报告来源时间。

统计模型只能在提示尾部与新语料形成精确后缀时利用更新。问法改写后收益可能消失。对同一事实构造原句、释义和多跳问法, 能测量它是复制补全还是知识迁移。 **5.9. 数据 silo 实验的权限语义.** SILO 模型强调不同许可范围的数据使用。infini-gram 索引可以作为独立数据层, 只对当前用户允许的文档构建或查询。相比把受限内容训练进共享参数, 删除与权限撤销更直接。 权限必须在计数聚合前执行。若先合并公开与私有计数再只隐藏文档取回, 概率变化仍可能泄露私有成员。每个权限域需要独立索引或可验证的过滤, 查询结果标注参与的数据集合。

插值生成会把索引内容转成输出, 仍可能逐字泄漏。访问控制、审计日志和罕见长串保护不能因其被称为统计模型而省去。 **5.10. 开放生成中的错误会自我延续.** teacher-forced perplexity 每步使用真实历史。自由生成一旦统计分支选错 token, 下一步上下文变成模型自身错误输出; 如果这段错误恰好命中索引中的另一条长串, infini-gram 会继续沿无关文档补全, 造成跑题。 这解释论文所说的 odd mistakes 和 digression。单步平均 loss 改善没有测 exposure bias 下的级联。生成评测应记录首次统计分支主导的错误位置、之后有效 $n$ 是否升高、输出是否沿某训练文档继续。

安全门控可在神经与统计强烈冲突时降低 $\lambda$, 或只在两者 top-k 有交集时使用统计分支。这样会牺牲一部分神经盲点收益, 换取更少灾难性跳转。策略需要在独立生成任务上验证。 **5.11. 动态门控本身也会过拟合.** 令特征 $z=(n,c,H,p_N,source)$, 学习门控 $\lambda(z)$ 可以比两个固定权重细致。若训练门控的数据与最终测试共享文档或模板, 门控会记住哪些统计模式在该集合有效, 高估泛化。 可把数据分成神经训练、索引、门控训练、验证和最终测试五个角色, 并明确允许重叠关系。索引与神经训练重合用于增强模型自身训练记忆, 索引含更新数据用于外部记忆, 两者研究问题不同。

门控还应校准不确定性。相同 $n=20,c=1$ 在唯一引文与随机碰撞中风险不同; 来源、文档重复簇和字符类型可提供额外证据。特征越多, 验证样本需求越大。 **5.12. 与 kNN-LM 和 RAG 的可比轴.** kNN-LM 在神经隐藏空间检索相似训练位置, 后继可来自语义相似但词面不同的上下文; infini-gram 只认精确 token 后缀, 计数透明且无需神经 datastore。RAG通常检索文档片段, 再让生成模型阅读和综合, 能处理改写与非连续证据, 成本与行为更复杂。 三者应按索引单位、匹配函数、返回对象、更新方式、可解释性和生成延迟比较。infini-gram 的优势是精确计数和任意阶词面匹配, 局限是缺少语义不变性。论文在 SILO 上相对 kNN-LM 与 RIC-LM 获得更好 PPL 改善, 该结果绑定模型、数据与评测, 无法概括所有 RAG 任务。

混合方法也可串联: 先用语义检索缩小文档集合, 再在候选内做精确后缀统计; 或用 infini-gram 发现长重合, 对复制风险进行抑制。组合目标不同于单纯最低困惑度。

### 5.1. 统计边界、复现与可证伪实验

**6.1. 存储换参数的另一种路线.** 五万亿token索引以约7字节/token计算，原始量级约35TB，另有构建临时空间和元数据。它不需要GPU常驻，却需要高容量低延迟SSD。与神经LM相比，Infini-gram把训练计算转为一次索引构建，把推理矩阵乘转为随机磁盘读。 这条路线适合计数分析、数据审计和批量离线插值，不一定适合每token在线生成。若每个生成token都花约200毫秒查询，单用户吞吐会受限；缓存、批处理和局部索引可以缓解，但服务成本必须单独测量。 **6.2. tokenizer 和语料边界不可忽略.** 索引建立在token ID字节串上，不同tokenizer对同一文字产生不同边界。跨模型使用时，必须重建索引或可靠转换，不能把一个词表的ID当作另一词表。特殊文档分隔token还要保证不会出现在正常文本中，并且所有查询禁止跨边界。

Unicode规范化、空白、大小写和网页清洗都会改变精确计数。系统回答“这段token序列在处理后语料中出现几次”，不是原始网页字符的绝对计数。复现应发布数据版本、清洗代码、tokenizer哈希、分片清单和索引参数。 **6.3. 延迟数字的证据范围.** 低于20毫秒、40毫秒和200毫秒分别对应RedPajama上的计数、固定阶分布和 $\infty$-gram查询。组合5万亿token索引需要访问更多分片，云端API还包含排队与网络时间。平均延迟不表示P95，也不表示并发吞吐。 建索引的48小时来自128 CPU和1TiB RAM单节点。换用普通服务器可能因内存不足需要外排排序，时间显著增加。论文证明工程可行，但不能从该数字推断低成本个人硬件可轻易重建全部索引。 **6.4. 统计匹配与知识理解的边界.**

$\infty$-gram能以任意长精确上下文复制训练模式，却不表示组合推理、指令遵循或语义抽象。47%下一token命中说明自然文本重复结构丰富，也提醒神经LM评测要控制数据重叠。它与神经模型互补，而非简单替代。 Infini-gram最重要的贡献是把“任意字符串在万亿token语料中出现多少次、最长已见上下文多长、后面通常接什么”变成毫秒到百毫秒级可查询对象。这个基础设施让经典统计模型重新成为分析现代大模型数据、记忆与生成行为的工具。 **6.5. 隐私与成员查询风险.**

文档取回接口能精确回答某段文本是否存在于索引语料，并返回包含它的文档。对公开网络语料，这有助于审计来源和污染；对含个人信息、授权内容或内部数据的索引，同样能力会成为成员查询通道。攻击者可以批量提交候选电话号码、邮件或独特句子，观察计数是否为零。 服务部署应区分计数、概率与文档取回权限。公开API可以限制查询长度、频率和返回计数精度，对罕见且疑似敏感的匹配不返回原文上下文；内部研究接口再提供审计细节。仅删除网页链接不够，因为token片段本身可能已经泄露信息。 **6.6. 精确计数也需要正确的不变量.**

分片构建和并行汇总必须保持三个不变量：文档不得跨分片边界被切开，查询不得跨文档分隔token匹配，同一语料片段在合并计数时不得重复加入。若索引构建前做过去重，计数表示去重后的文档分布；若保留重复，计数表示训练多重集。两者都可能合理，但必须与用途一致。 概率查询还要求分母与分子来自同一组分片和同一tokenizer。若某个分片暂时不可用，只漏掉分子或只漏掉上下文计数会破坏分布归一化。在线系统应在分片故障时整体降级或显式标注不完整结果，而不是静默返回看似精确的概率。 **6.7. 适合怎样的后续研究.**

Infini-gram可以作为训练数据实验的测量层。研究者可比较去重前后有效阶分布，定位评测集与预训练集的长串重叠，或按语料来源分解某个预测的计数。结合模型logits，还能研究神经概率与经验频率在不同上下文长度、领域和训练阶段如何偏离。 另一条路线是把统计分支用于可控生成，而不是简单固定权重插值。例如仅在长上下文、高计数且低熵时提高权重，在疑似版权长匹配时反而抑制复制。此类门控必须同时评估困惑度、生成质量与逐字复现风险，避免只优化平均似然而增加不当记忆。 **6.8. 先把「出现次数」与「出现于多少文档」分开.**

后缀数组最自然地返回 occurrence frequency：一个 token 串在整个拼接语料中占据多少个位置。这个数适合还原训练流中的采样权重，却会被单一文档内的机械重复放大。网页导航栏、版权声明、代码生成文件和论坛签名可能在一页中重复数百次；计数很高，并不说明这种表达跨来源稳定。与之相对，document frequency 只问有多少篇不同文档含有该串。一段内容出现一万次，可能来自一万个独立页面，也可能来自同一模板被复制一万遍，两者对语言规律、污染和记忆的含义完全不同。 设上下文串为 $s$，出现位置集合为 $O(s)$，位置 $i$ 所属文档为 $d(i)$。位置频率与文档频率分别为

$$
\operatorname{OF}(s)=|O(s)|,\qquad
\operatorname{DF}(s)=|\{d(i):i\in O(s)\}|.
$$

进一步还可以按近重复簇计数。先把网页按文本指纹聚成簇 $g(d)$，再计算 $|\{g(d(i)):i\in O(s)\}|$，就能避免转载站和镜像仓库制造虚假的多来源支持。对于下一 token 分布，也可分别给出位置加权、文档等权和重复簇等权三套估计。若某个后继只在位置加权下占绝对优势，而在文档等权后迅速下降，它更像采样多重性造成的尖峰。若三套估计都稳定，才有理由把它视为跨文档规律。

这一区分还能解释神经模型到底在拟合什么。预训练通常按 token 流采样，因此参数更新更接近位置频率；数据审计更关心来源覆盖，常需要文档频率；评测污染则要定位具体文档与时间，近重复簇最有用。把三者压成一个 count，会让“训练权重很大”“来源很多”“测试题泄漏”三种结论混在一起。Infini-gram 的原始索引擅长第一种计数，后两种需要文档边界、来源元数据与去重映射协同。 **6.9. 计数是确定值，概率估计仍有不确定性.** 索引给出的 $c(s)$ 与 $c(sx)$ 对当前语料是精确整数，但 $c(sx)/c(s)$ 只是有限样本中的经验频率。若想把它用于未见文本的概率判断，仍需讨论抽样误差。最简单的二项近似中，给定上下文出现 $c$ 次、后继 $x$ 出现 $k$ 次，经验概率为 $\hat p=k/c$，标准误差约为

$$
\sqrt{\frac{\hat p(1-\hat p)}{c}}.
$$

当 $c$ 很小时，这个近似本身也不稳定。采用 Beta 先验可得到后验均值 $(k+\alpha)/(c+\alpha+\beta)$，并给出可信区间。对于多 token 后继，Dirichlet 后验承担同样作用。这样一来，$n$ 很长却只出现一次的确定性后继不会自动获得百分之百置信；它的经验分布虽是 one-hot，证据强度仍然很弱。 “出现一次的长串几乎不可能偶然碰撞”与“它的下一 token 可以可靠泛化”是两个问题。前者关心成员身份，长字符串确实有强辨识力；后者关心从一次观察预测未来，一次样本无法展示替代后继。若任务是找训练重合，$c=1,n=50$ 已很有价值；若任务是开放式生成，把全部权重压到唯一后继则风险很高。因此门控至少要同时看匹配长度和分母计数，不能只按 effective $n$ 排序。

还应警惕语料并非独立同分布抽样。转载、引用与模板让出现位置高度相关，朴素标准误差会过窄。可把文档或近重复簇作为抽样单元，使用簇级 bootstrap：每次重采样文档簇、重新汇总后继分布，观察概率和熵的波动。它比把每个 token 位置视为独立样本更接近真实来源不确定性。若不同重采样下 argmax 经常变化，统计分支即使有很长匹配，也不应以高权重接管生成。 **6.10. 一套能拆开因果来源的实验矩阵.**

要判断 infini-gram 的收益来自语言统计、训练重合还是测试污染，可以把索引和测试集设计成二维对照。索引侧至少准备四个版本：模型训练语料原样版、文档去重版、移除测试近重复后的净化版、与模型训练无关但领域相似的外部版。测试侧则分为训练文档续写、同源文档留出、时间后移文本、人工释义和真正跨领域文本。每个格子都报告 effective $n$、上下文计数、稀疏率、真实 token 概率与插值 loss 改善。

如果原样索引在训练文档续写上远胜净化索引，而时间后移和释义集几乎没有收益，主要信号是精确重合。若外部领域索引在同域新文本上仍能稳定降低 loss，说明统计分支捕捉了神经模型尚未充分利用的领域规律。若去重后收益明显下降但文档频率保持较高，可能是训练多重性推动了神经与统计双方；若只有含测试近重复的索引改善，结论应归入污染检测，不能包装成语言建模进步。

还可加入上下文破坏实验。对每个测试位置构造三种控制：保留语义但改写词面、保留局部词面但打乱更早上下文、保留全部前缀却替换实体。第一种测试精确匹配脆弱性，第二种判断最长后缀真正利用了多远的信息，第三种检验模型是否只是沿模板补全。若移除几十 token 之外的上下文毫无影响，那么报告的长 effective $n$ 可能只是后缀内部模板足够强，而非远距离依赖提供了额外预测信息。

所有比较必须固定 tokenizer、清洗流程与解码策略。索引规模变化时应使用嵌套语料：小索引是大索引的严格子集，并按文档而非任意 token 截断。否则“更大索引更好”会混入语域、时间、质量与去重策略差异。至少重复多个随机嵌套样本，给出均值和区间，才能区分规模效应与抽到某批高重合文档的偶然性。 **6.11. 从十亿到万亿，规模曲线要回答什么.**

索引扩展并不保证每项指标单调改善。语料越大，任意上下文被见过的概率提高，effective $n$ 通常变长；与此同时，某个上下文可能出现更多互相冲突的后继，分布熵反而升高。新增低质量镜像会放大模板，新增多语言数据会改变分词长度，新增时间更晚的数据还可能污染评测。只画总体 perplexity 对 token 数的曲线，很难知道收益由覆盖、计数稳定还是泄漏贡献。

更有解释力的规模曲线同时追踪五个量：非零覆盖率、effective $n$ 的分位数、上下文计数的分位数、后继熵以及插值后的 token loss。覆盖率上升而 loss 不降，说明新命中的上下文预测性不足；$n$ 上升且计数长期停在 1，说明新增语料主要制造唯一长匹配；熵降低并伴随跨文档频率上升，才更像稳定规律被补全。对每个量再按代码、学术、新闻、对话等领域分层，才能避免大类均值掩盖相反趋势。

可以用增长指数描述边际收益。令索引规模为 $N$，某指标为 $m(N)$，比较相邻规模下 $\Delta m/\Delta\log N$。若覆盖的边际增益逐渐饱和，而存储和查询分片数线性增长，继续扩大全量索引未必划算；可将预算转向目标领域或高质量数据。反之，若长尾实体与新时间段的覆盖仍快速增加，大索引的价值主要体现在知识更新，而非一般句法。

规模实验还应同时训练或选取不同规模的神经模型。小模型可能从统计分支得到更多常识性补偿，大模型可能只在稀有专名和逐字记忆上受益。若只对一个神经模型扩索引，无法判断统计收益是否会随参数规模消失。理想设计形成模型参数量与索引 token 数的二维曲面，在相同总存储、相同在线延迟或相同能耗约束下比较组合，而不是默认更多参数与更多索引可以无限叠加。 **6.12. 手算样例是索引实现最有效的验收.**

大规模吞吐测试之前，应先用几篇刻意构造的小文档验证语义。设文档一为“A B A B C”，文档二为“A B D”，每篇末尾插入不可匹配的边界 token。查询上下文“A B”时，分母应为 3，后继 C、A、D 各一次；若实现错误地只找到词典序相邻的一个区间，概率和不会为 1。查询“B C”只能命中文档一，继续查询“B C A”必须为零，因为不能跨过文档边界接到下一篇开头。

再加入一篇与文档一完全重复的文档。保留重复模式下“A B”的所有位置计数随之增加；文档去重模式下不应变化。若系统支持分片，将文档一与文档二放到不同分片，合并查询结果必须等于单索引结果。故意让一个分片离线时，接口应返回“不完整”状态，不能仍把剩余分子除以全量缓存分母。对 sparse 查询，可构造某上下文出现十次且后继始终相同的例子，以及只出现一次的例子，确认两者都被判为 sparse，却保留不同 count。

最长后缀也需要边界测试。给定查询“X A B”，若“X A B”未见而“A B”出现，effective $n$ 应退到 2；如果连“B”也未见，应继续退到零阶分布，而不是返回空概率。存在多个相同 token ID、特殊 token 或空查询时都要有定义。随机生成小语料后，可以用朴素扫描器枚举所有子串，将其计数与后缀数组查询逐项对拍。这类 property-based test 不依赖人工列完所有答案，特别容易发现区间端点差一、边界 token 泄漏和分片求和错误。

概率接口还要验证归一化：对任意上下文，所有可返回后继的计数和应等于上下文计数，除非上下文出现在文档末尾。若末尾出现不产生普通后继，分母必须明确选择“全部出现次数”还是“拥有后继的出现次数”。前者会让普通 token 概率和小于 1，后者才形成词表上的条件分布。论文中的语言模型解释要求后一种语义；实现若采用前者，应把结束符纳入词表或显式说明。 **6.13. 跨索引相加成立，需要先满足同一测量口径.**

Infini-gram 的计数具有可加性：对互不重叠的语料分片，$c(s)$ 与 $c(sx)$ 分别求和即可得到联合分布。这个性质让五万亿 token 不必放进一台机器。但“可以相加”不等于“任意公开索引都能直接混合”。两个索引必须使用完全相同的 tokenizer、规范化、边界 token 与查询语义。任何一项不同，token ID 串相同都可能不再代表同一文本事件。

语料交集是第二个条件。Dolma、RedPajama、Pile 与 C4 都来自大规模网络来源，可能共享网页、代码仓库或转载文章。若直接求和，交集文档被重复计算，联合结果代表多个采集流程形成的多重集，而非去重后的互联网。对研究训练采样权重，这或许正是所需定义；对估计“网络上有多少独立来源支持某后继”，它会造成偏差。跨索引合并应公布文档级去重策略，或至少用内容哈希抽样估计交集率。

第三个条件是版本一致。数据集名称相同也可能在抓取、清洗或撤稿后更新。一个可复现查询应携带索引标识、构建日期、数据快照、tokenizer哈希、分片集合和查询软件版本。返回结果最好包含参与求和的分片清单摘要。否则同一个 API 名称在半年后给出不同计数，研究者无法判断来自数据更新还是实现变化。 在概率层合并时，应先加计数再相除：

$$
P(x\mid s)=\frac{\sum_j c_j(sx)}{\sum_j c_j(s)}.
$$

直接平均各分片概率会让小分片与大分片拥有同等权重；按分片 token 总数加权也未必正确，因为当前上下文在各分片的出现次数不同。只有上下文计数天然给出该条件事件的权重。若出于数据治理需要让每个来源等权，那是另一种有意设计的估计量，应明确命名，不能仍称为合并语料的经验条件概率。

### 污染检测不能只设一个最长匹配阈值



用“最长公共 token 串超过某长度”判定污染很直观，却会在不同文本类型上产生完全不同的误报率。代码许可证、法律条款和数学定义天然拥有长固定表达；短问答的答案可能只有一个实体，即使整题泄漏，最长重合也不长。tokenizer又会让中文、英文和代码的同字符长度映射成不同 token 数。单一 $n$ 阈值无法覆盖这些情况。

更稳妥的污染分数应结合匹配长度、测试样本覆盖比例、索引计数、文档频率、来源时间与关键字段。对选择题，题干、选项和正确答案共同出现在早期文档中，比只有通用题干的证据强；对生成题，参考答案的独特片段比提示中的模板更关键；对代码，函数签名加隐藏测试说明比许可证头更有辨识力。报告时应保留命中文档，让人工审核能判断同源发布、合法公共材料与评测泄漏。

时间信息也要分层理解。命中文档早于评测集发布日期，只能说明文本可能从共同公开来源进入训练，不能证明模型训练时实际包含该快照；命中文档晚于发布日期，可能是评测被转载，也可能页面时间戳失真。若能取得模型训练截止时间、数据快照和最早可验证来源，证据链才较完整。对闭源模型，训练数据未知，infini-gram 只能展示某公开语料中的重合，不能据此断言模型一定见过。

污染分析最终应回答“若移除这些样本，结论改变多少”。在阈值从宽到严的多个版本下重算 benchmark 分数，得到敏感性曲线。若排名在合理阈值范围内稳定，污染存在但未改变主要比较；若少量长重合样本决定胜负，就应报告过滤后的结果。这样，索引查询从猎奇式寻找最长复读片段，变成评测可信度分析的一部分。 **6.15. 用校准曲线判断统计分支何时值得信任.**

门控不应只追求平均 perplexity 最低，还要检查统计概率是否校准。把测试位置按 $P_\infty(y\mid s)$、effective $n$、上下文计数和熵分桶，比较预测置信与实际命中频率。若声称 0.9 的位置只有 0.6 命中率，经验频率对目标分布过度自信；若稀疏分布的 1.0 置信只对应较低正确率，说明索引与测试之间存在分布转移、重复噪声或后缀选择偏差。

多分类校准可用负对数似然、Brier score 与 expected calibration error 辅助观察。由于词表很大，整体 ECE 容易被大量低概率 token 支配，更实用的是单独检查真实 token 概率、统计 argmax 正确率和选择性风险。让系统只在置信分数超过阈值时启用统计分支，画出覆盖率—错误率曲线：阈值升高后覆盖减少，如果错误率没有同步下降，所用置信特征并未真正识别可靠查询。

校准集必须与测试文档隔离，也要与索引重合关系相匹配。在重合严重的数据上学到的温度或门控阈值，迁移到时间后移文本会过度相信长匹配。可以分别拟合训练重合、同域留出与跨域三种校准器，并报告跨组迁移；也可以采用保守的最坏组阈值。这里要回答的是统计分支在哪些数据关系下可用，单个漂亮数字承载不了这种差异。

神经分支与统计分支的分歧本身也是信号。若两者都给真实 token 高概率，插值收益有限但风险小；统计分支尖锐、神经分支也支持时，可能是可靠长模板；统计分支尖锐而神经分支强烈反对时，需要检查单次匹配、文档噪声和话题跳转。按这三类分别画 loss 变化，比只按 sparse/non-sparse 二分更能指导门控。 **6.16. 版权复现风险与语言建模收益需要两套指标.**

长精确后缀恰好也是逐字复现的条件。若索引中某受保护文档的前缀具有唯一后继，统计分支会连续给出确定 token，直到遇到分叉。困惑度在这一段大幅下降，却可能增加输出长原文的风险。将低 loss 一概视为质量提升，会把复制能力与语言能力混为一谈。

可以定义连续统计主导长度：生成过程中，统计分支权重超过阈值且其 argmax 被采纳的最长连续区间。再记录该区间能否在单一来源文档中定位、其文档频率和字符长度。短的公共短语通常分散于许多来源；长而唯一、连续来自同一文档的片段风险更高。对代码还要区分许可证、通用样板和实质实现，对论文区分公式定义、参考文献与正文段落。

风险门控可利用来源授权和匹配形态。公开领域、许可兼容或用户自有文档可允许较长统计续写；来源不明且单文档唯一的长匹配应逐步衰减 $\lambda$，必要时阻止返回原文。衰减不必抹掉统计分支的全部价值：它仍可用于内部 loss 分析、污染定位和候选重排，只是不直接驱动逐 token 输出。

评测应并列报告 PPL 改善、任务正确率、最长原文复现长度、可定位单文档片段比例和拒绝误伤率。过强保护可能阻断事实名称、代码 API 与固定法律用语，过弱保护则在罕见前缀下复读。只有展示效用—风险曲线，才看得出某个门控点为何合理。论文已经提醒自由生成可能出现有害或跑题行为，后续系统还应把逐字复现作为独立风险轴，而非隐藏在总体生成质量中。 **6.17. 最小可复现记录应长什么样.**

一次 infini-gram 实验至少要冻结六类信息。第一类是语料：数据集版本、快照日期、文档数量、token 数、许可范围和去重方式。第二类是文本处理：解压、编码修复、Unicode规范化、网页抽取、空白处理与文档边界。第三类是 tokenizer：实现版本、词表与合并规则哈希、特殊 token ID。第四类是索引：构建程序提交号、指针宽度、分片规则、后缀排序实现和构建硬件。第五类是查询：有效阶定义、末尾上下文处理、跨分片合并、缓存和超时策略。第六类是评测：模型 checkpoint、解码参数、测试样本哈希、污染过滤与随机种子。

这些字段不是为了让附录变长。精确统计的优势就在于答案可核验；若语料和处理链不固定，精确到个位的 count 反而制造虚假的确定感。最实用的做法是为每套索引生成 manifest，包含所有分片的内容哈希、文档范围和构建参数。论文表格引用 manifest 标识，查询日志记录索引标识与参与分片。数据无法公开时，也可以公开哈希、统计摘要与查询代码，让有权限的研究者复算。

复现还分为三层。算法复现只需证明后缀数组查询与朴素计数一致；结果复现需要相同数据快照，重现论文中的有效阶与困惑度；结论复现则允许替换语料、模型和 tokenizer，观察“统计长匹配能解释一部分预测并改善插值”是否仍成立。三层失败的含义不同。算法失败是实现错误，结果偏差可能来自数据版本，结论不稳定则说明现象依赖特定生态。

末尾要保留负结果。哪些领域插值没有改善，哪些长匹配在人工检查后只是模板，哪些模型与统计分支冲突最严重，都比只列最佳平均值更有研究价值。Infini-gram 打开的核心能力是对万亿 token 语料提出可精确回答的问题；真正严谨的工作，是让问题定义、数据口径和可证伪条件同样精确。 **6.18. 47% 一致率到底测到了什么.**

论文在人类文本实验中取 Pile 验证集各领域 50 篇文档，每篇使用 1024 个 token，并在约 3600 亿 token 的 Pile 训练索引上查询。它把真实下一 token 的统计概率大于 0.5 记为一致。这个判据很严格：一个归一化分布不可能有两个 token 同时超过 0.5，因此真实 token 一旦过线，必然也是统计分布唯一的 argmax。不过反方向不成立。真实 token 可能以 0.4 排第一，其余概率分散在许多候选上，此时预测实际正确，却不计入 47%。所以这个数字是按该阈值定义的一致率，也是统计 top-1 命中率的下界。

下界与真实 top-1 的差距取决于分布形状。稀疏位置只有一个后继，真实 token 命中时概率为 1，两种判据一致；非稀疏位置中，第一名概率常低于 0.5，差距可能明显。论文同时观察到超过一半位置得到 sparse 分布，因而总体 47% 很大程度由确定性位置贡献。若换成去重索引、时间后移文本或更开放的文体，稀疏比例改变，下界的松紧也会改变。

完整报告应至少给出三个指标：真实 token 概率超过 0.5 的比例、统计 argmax 命中率、真实 token 的平均负对数概率。第一个便于复现论文叙述，第二个对应分类准确率，第三个使用整个概率分布。再按 sparse/non-sparse、effective $n$ 与上下文 count 分桶，就能知道高一致来自长唯一复读、短语法模板还是多次出现的稳定条件分布。只报 47%，读者很容易把“严格阈值下的下界”误读成普通 top-1 accuracy。 **6.19. effective $n$ 的选择会产生赢家偏差.**

Infini-gram 从最长后缀开始寻找，只要某阶分母非零便停下。这个规则保证每个位置得到尽可能长的已见上下文，却也在许多候选后缀中选择了最极端的一项。长后缀往往计数少、分布尖锐，最终选中的经验概率比预先固定某个 $n$ 更容易显得确定。这和观察很多随机变量后报告最大值类似：查询结果没有算错，但若把尖锐程度直接当成可泛化置信度，就忽略了选择过程。

一种校正办法是设最小支持数 $m$，选择满足 $c(s)\ge m$ 的最长后缀。随着 $m$ 从 1、2、5 增到 20，比较有效阶、覆盖率、top-1 与 loss。若 $m=1$ 带来很长上下文，却在独立文本上没有更低 loss，唯一匹配主要提供成员证据；若较高 $m$ 仍保持收益，说明长上下文后继具有重复支持。另一种办法是收缩估计，让低计数高阶分布向较短后缀回退，而非在阶数之间硬切换。 可写成递归插值：

$$
P_n(x\mid s_n)=\alpha(c_n)\hat P_n(x\mid s_n)
+[1-\alpha(c_n)]P_{n-1}(x\mid s_{n-1}),
$$

其中 $\alpha(c)$ 随上下文计数增长。这样保留长匹配信息，又承认一次观察不足以完全覆盖短阶统计。它与论文选择最长非零后缀的定义不同，不能继续称为原始 $\infty$-gram，但适合作为对照。若递归收缩在净化测试集上更稳，而原规则只在高度重合文本占优，就能更清楚地区分记忆检索与概率估计。 **6.20. 最终应得到怎样的能力地图.**

把前面的分析收拢起来，Infini-gram 至少承担四种互有关联但评价标准不同的角色。作为计数数据库，它追求查询正确、覆盖大、延迟稳定；作为数据显微镜，它追求能定位来源、区分重复簇并支持污染审计；作为语言模型，它追求校准的下一 token 概率与独立测试 loss；作为非参数记忆，它追求更新快、权限清楚，并控制逐字复现。一个系统可以在第一种角色上非常成功，却不一定适合直接开放生成。

因此阅读实验结果时，先问查询对象是什么，再问语料与测试是什么关系。看到 effective $n$ 很长，应检查 count 和文档频率；看到 sparse，应区分唯一观察与多次一致；看到 PPL 下降，应检查索引是否含模型训练语料或测试近重复；看到生成流畅，应观察是否沿单一文档复制；看到毫秒延迟，应确认索引规模、分片数与并发条件。每一步都能由额外统计或对照验证，不必依靠模糊印象。

这也是该工作的教学价值。经典 $n$-gram 并没有因神经网络出现而失去意义，它受限的是存储与检索，而不是条件频率这个观察视角。后缀数组把固定阶截断打开之后，我们第一次能在万亿 token 尺度连续观察：上下文增长时，候选集合怎样收缩，经验熵怎样变化，神经模型何时跟随数据众数，何时偏离，长匹配究竟来自普遍结构还是单篇记忆。答案未必都是“统计模型更好”，但这些可查询的量让模型行为多了一套具体坐标。

最稳妥的结论也正由此形成：Infini-gram 是一个极强的精确词面测量工具，也是一条有潜力的非参数补充分支。它对语义改写无能为力，对低计数长后缀容易过度自信，对数据重复和污染极其敏感；与此同时，它能把原本只能凭案例讨论的训练重合、条件频率和记忆现象变成规模化实验。用好它的关键，是克制住盲目追逐更长 $n$ 的冲动，始终把长度、计数、来源和测试关系放在同一张表里。 **6.21. 一张结果表至少应该保留哪些列.**

如果要把一次分析压缩成可复查的表格，每个测试位置至少保留文档标识、位置、真实 token、effective $n$、上下文计数、真实 token 计数、不同后继数、分布熵、是否 sparse、统计 argmax、神经概率、混合概率与命中文档簇数。涉及多个索引时，再按来源保存分子和分母，而不是只留合并概率。这样既能从整体 loss 下钻到具体样本，也能重新计算不同阈值、不同门控和不同去重口径，无需再次扫描全部索引。

汇总层应报告均值之外的分位数和覆盖率。effective $n$ 的中位数无法展示极少数超长匹配，平均值又容易被它们拉高；至少给出 P50、P90、P99 与最大值。上下文 count 和文档频率通常跨越多个数量级，宜在对数尺度分桶。loss 改善同时报告总均值、改善位置比例、最差分位数和按领域结果，防止大量微小收益掩盖少数灾难性错误。

样本表还应保留清洗后的可定位文本片段，但公开发布时对隐私与版权内容做访问控制。用于论文图表的聚合数据与用于内部审计的原文证据可以分层保存。前者支持外部复核统计结论，后者让授权研究者追踪异常来源。把这套字段固定下来，后续比较索引版本、模型规模和去重策略时就不会每次更换口径，也更容易发现某项提升究竟发生在哪类上下文。

若表格需要进一步压缩，可以把逐位置记录保存为机器可读附件，正文只展示预先声明的聚合视图。聚合脚本应从原始记录一次生成全部数字，避免不同图表各自过滤样本。缺失查询、超时与分片故障也要作为明确状态进入分母；悄悄丢弃失败位置，会让延迟较高或匹配较难的样本从评测中消失，最终指标便只代表成功返回的那部分文本。
