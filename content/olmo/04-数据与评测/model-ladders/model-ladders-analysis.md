# Model Ladders 深度解析: 用小规模训练预测大模型任务表现

大模型预训练最昂贵的决策往往发生在训练开始之前: 数据混合、模型尺寸、token 预算和配方一旦选错, 完整运行很难重来。传统语言建模缩放律可以预测平均验证损失, 却不能直接回答 MMLU、ARC 或 HellaSwag 等单项任务最终会得到多少准确率。Model Ladders 的核心目标, 是让一组便宜的小模型成为目标训练的测量仪器, 在投入 7B、13B 级完整预算前预测下游任务表现。

论文的关键设计是避免从计算量直接拟合准确率。准确率有随机猜测下限和饱和上限, 小模型还可能长期停留在机会水平, 直接外推既不平滑也不稳定。作者先用参数量和训练 token 预测任务特定的中间损失, 再学习中间损失到准确率的映射。第一步利用损失随规模变化的平滑结构, 第二步处理任务指标的非线性, 两者共同构成可以检查误差来源的预测链。

## 模型阶梯如何构造可外推的观测

### 两个轴组成十六个代理训练

阶梯不是简单训练一个缩小版模型。论文使用多个参数规模, 并让每个规模训练到不同数据预算, 从而同时观察模型容量与训练时长两个方向。公开仓库列出的阶梯包含约 190M、370M、760M 与 1B 级模型, 每个规模使用 1、2、5、10 倍 Chinchilla 参考 token 比例, 形成四乘四的网格。这样的设计让拟合不只依赖一条固定计算曲线。

若只改变模型尺寸而固定 token 数, 数据不足与容量不足会混在一起; 若只延长一个模型训练, 又无法判断更大容量是否改变极限。二维网格为 $N$ 与 $D$ 的指数项提供独立信息。论文以非嵌入参数量作为主要规模变量, 因为词嵌入参数随词表变化且不完全对应 Transformer 主干计算。复现时必须保持参数口径一致, 否则横轴会发生系统偏移。

所谓 Chinchilla 倍数用于组织训练预算, 并不表示目标模型处于经典计算最优点。现代模型常在固定参数规模上训练远超 $20N$ 的 token, 以降低推理成本。阶梯覆盖多个倍数, 正是为了在过训练区域收集信号。目标 7B-4T 与 13B-5T 远超小模型的常见最优 token 比, 因而单纯套用计算最优缩放律并不足够。

### 可比性依赖架构和数据路径一致

代理模型要预测目标模型, 除规模外的关键条件应尽量相同。架构比例、tokenizer、数据混合、训练目标、学习率选择和评测协议如果变化, 拟合曲线可能同时吸收配方差异。论文的阶梯与 OLMo 2 目标模型共享训练体系, 使外推主要回答“同一配方扩大后怎样”, 而不是“另一个模型家族会怎样”.

这也是模型阶梯与通用跨模型回归的区别。跨实验室收集公开模型虽然样本多, 但数据、优化器和实现差异难以控制; 同一实验室阶梯样本少, 却有更强实验一致性。它牺牲跨家族普适性, 换取对单个生产配方的因果解释。论文的局限部分明确指出方法主要在 OLMo 2 家族上开发和验证, 迁移到其他 Transformer 配方仍需重新校准。

超参数同样需要随规模合理变化。若小模型学习率不佳, 它的损失会偏离真实规模趋势, 回归便把优化失败当成容量规律。阶梯配置应使用预先规定的层数、宽度、batch 和学习率缩放规则, 并在少量锚点验证近似最优。若每个点在看到目标任务后单独调参, 又会产生选择偏差。

## 两阶段任务缩放律的数学含义

### 第一步从规模预测任务损失

第一阶段采用类似经典缩放律的形式, 把任务损失表示为模型项、数据项与不可约项之和. 可概括为

$$L(N,D)=A N^{-\alpha}+B D^{-\beta}+E.$$

其中 $N$ 是参数规模, $D$ 是训练 token, $A,B,\alpha,\beta,E$ 由阶梯点拟合。$E$ 表示在当前任务、数据与配方下继续扩大规模时的渐近损失。模型项和数据项分别描述容量不足与训练不足造成的额外损失。

这里使用的不是统一语料验证损失, 而是任务相关的损失特征。对于 ranked classification 形式, 每个答案候选作为续写计分, 正确候选的条件概率或相关交叉熵能在准确率开始显著上升前提供连续信号。一个小模型即使选错最多, 也可能逐渐提高正确选项概率; 0/1 准确率看不到这种变化, 损失却能看到。

任务损失也有噪声。测试集小、候选长度不同、概率归一化或提示格式变化都会改变观测。论文使用一致的 RC 评测设置, 让阶梯点可比较。拟合时应保存每个 checkpoint 的样本级对数概率, 不只保存任务平均值, 这样才能通过 bootstrap 估计观测噪声并发现异常题目。

### 第二步从损失映射到准确率

准确率必须落在随机基线与理论上限之间, 因而损失到准确率通常采用带边界的非线性映射。直观上, 损失很高时不同选项概率相近, 准确率接近随机; 损失跨过某个区间后, 正确候选更常排第一, 准确率快速上升; 再继续降低损失时, 指标逐渐饱和。S 形曲线比无界幂律更符合这一几何结构。

两阶段分解还允许诊断误差。如果目标模型的实测任务损失已被第一步准确预测, 但准确率预测错误, 问题主要在第二阶段映射或任务噪声; 若损失本身预测偏离, 则应检查规模外推、训练配方或目标模型异常。直接拟合计算到准确率只能看到最终误差, 无法区分这两类原因。

第二步的最大困难是小模型缺少动态范围。若所有阶梯模型都处于随机准确率附近, 即使损失持续下降, 也无法可靠确定 S 曲线何时转折。论文因此更适合 RC 形式, 因为 RC 的连续概率信号在小模型上更早出现。原始 multiple-choice 标签生成形式要求模型理解输出 A、B、C、D 的接口, 小模型可能完全没有信号, 作者把稳定预测 MC 留作后续方向。

### 为什么不直接用通用语言建模损失

平均验证损失聚合大量普通 token, 其中绝大部分与目标任务需要的知识和推理无关。两个模型可以有相近通用损失, 却因领域数据、选项判别或知识覆盖不同而产生不同任务准确率。用通用损失预测所有任务, 相当于假设每个任务以同一速度随平均语言能力改善, 这通常不成立。

任务损失把测量聚焦到目标样本, 但也更易受小测试集噪声影响。Model Ladders 选择的是偏差与方差之间的折中: 用任务特定特征降低系统偏差, 再用多个 checkpoint 和受控阶梯缓解方差。若任务只有几百题, 扩充评测集往往比增加更复杂的拟合函数更有价值。

## 实验结果应该如何解释

### 低于百分之一计算量的真实含义

论文报告完整阶梯训练成本不到目标模型预训练计算量的百分之一, 并能对 7B-4T 与 13B-5T 的多个任务给出较准确预测。这个比例说明代理实验相对生产训练便宜, 但并不等于绝对成本很低。十六个模型、多 checkpoint 推理和多任务拟合仍需要显著资源, 而且若每种数据混合都重跑完整阶梯, 总预算会快速累积。

计算比例也取决于目标规模。目标越大, 固定小阶梯占比越低; 对 1B 目标模型, 同一阶梯可能不再经济。团队应按决策价值设计阶梯, 先用少数尺寸和预算检查信号, 再在拟合不确定性过高的区域添加点。固定十六点不是方法的本质, 覆盖目标外推所需的两个轴才是。

预测准确不能只看跨任务平均绝对误差。某些任务落在两点以内, 不代表每项都可靠。ARC 等较小或噪声较高的数据集更难拟合, 任务处于随机基线附近时相对误差也会被放大。应用时应报告每项预测区间、阶梯拟合残差和目标点距观测区域的距离, 而不是只给一个平均数。

### 外推不是因果保证

曲线假设从小模型到目标模型的训练机制保持连续。如果大模型在某规模突然涌现标签遵循、长链推理或新记忆策略, 小阶梯无法预见结构断点。反过来, 目标训练遇到数据重复、数值不稳定或学习率异常, 也会偏离理想缩放曲线。预测区间只描述给定模型假设和观测噪声, 不包含所有工程事故。

数据和架构改变会破坏迁移。同一阶梯可以比较两个候选数据混合的早期排序, 但若目标训练动态随规模翻转, 小模型赢家未必是大模型赢家。DataDecide 等后续工作正是在研究这种跨规模决策。最稳妥的用法是把阶梯当作淘汰明显较差方案和估计大致收益的工具, 而不是取消目标规模验证。

论文只验证到 13B 级, 对 70B 及以上的外推距离更长。规模扩大还会改变并行策略、batch、上下文组成与优化稳定性。若要预测更大目标, 应增加中间规模锚点, 并在每次真实训练后把观测回填到阶梯模型。模型阶梯应是持续校准的测量系统, 不是一次拟合永久有效的公式。

## 工程复现与决策流程

### 从训练网格到冻结预测

复现首先应冻结目标问题: 模型架构、数据混合、目标参数量、token 预算和任务协议。随后生成阶梯配置, 明确每个点的非嵌入参数、层宽比例、全局 batch、学习率和训练 token。运行中按统一 token 间隔保存 checkpoint, 因为中间点能显著增加 $D$ 方向观测, 而不需要额外训练模型。

评测侧必须锁定数据 revision、提示、候选格式、归一化和分词处理。每个 checkpoint 保存任务准确率以及正确候选和全部候选的对数概率。若只保存准确率, 第一步所需的连续特征便无法重建。对被截断样本、空候选和并列分数也要记录, 不能静默丢弃。

拟合时应在预测目标结果揭晓前冻结模型形式、初始化和约束。可以用留一规模验证模拟外推: 隐藏最大阶梯尺寸, 用其余点预测它, 检查不同任务的误差和区间覆盖。若这种近距离外推都失败, 不应相信更远目标预测。选择模型形式后再揭晓目标点, 可避免针对最终答案事后调曲线。

### 不确定性应进入训练决策

预测值只有与成本和不确定性结合才有意义。假设两个数据配方预测只差 0.4 点, 而置信区间宽 1.5 点, 阶梯并不能支持确定排序。团队可以增加对差异最敏感的规模点或扩充评测样本, 也可以承认结果不确定并用其他指标决策。把点估计的小差距解释为赢家, 会重现排行榜过度解读。

不确定性至少有三层: 评测样本噪声、曲线参数拟合噪声和模型设定误差。bootstrap 能处理前两层的一部分, 却难以覆盖缩放关系在目标规模改变的风险。可同时拟合若干合理形式并比较预测分散度, 再用历史目标训练衡量区间是否校准。真正可靠的系统要记录预测和事后实测, 而不只保存成功案例。

当预测用于是否启动昂贵训练时, 决策阈值应预先声明。例如只有预计提升超过一点评测且下界仍为正才升级配方, 或以每单位额外 FLOPs 的预期收益排序。这样的规则将统计预测转成可审计决策, 避免管理压力在结果出来后改变解释标准。

### 与小规模消融和完整缩放律的关系

单点小模型消融便宜, 但无法知道结论是否随规模变化; 经典缩放律擅长预测语言建模损失, 却离具体任务较远; 完整目标训练最可信, 但成本最高。Model Ladders 位于三者之间, 用结构化小实验建立任务级外推。它最适合高成本、可重复且配方相对稳定的预训练决策。

对于后训练、工具调用或长推理, 任务表现还受采样和交互环境影响, 两阶段 RC 方法不能直接搬用。可以继承其思想, 寻找比最终成功率更连续的中间量, 例如测试通过比例、约束满足数或过程奖励, 再验证该中间量是否随规模平滑。没有实验证据时, “建立阶梯”只是比喻, 不是已经证明的预测器。

Model Ladders 最重要的方法论贡献, 是把大模型训练前的直觉判断转化为受控预测实验。小模型不再只是廉价演示, 而是按照规模和数据轴排列的观测装置; 任务损失不再只是评测副产品, 而是连接预训练计算与准确率的中间状态。它能显著降低决策成本, 但其可信度始终依赖配方一致、评测稳定、外推距离和诚实的不确定性报告。

## 失败模式与改进方向

### 随机基线和饱和区都会削弱辨识度

任务曲线两端的信息量都很低。在随机基线附近, 参数规模变化尚未让正确选项稳定超过干扰项, 准确率几乎不动; 在接近饱和时, 多数模型都答对容易题, 额外损失改善也难以转成准确率。只有转折区同时包含足够多模型点时, 第二阶段映射才能可靠确定斜率与阈值。阶梯设计因此应参考任务当前难度, 而不是所有任务机械复用同一尺寸网格。

若任务对全部小模型都太难, 可以增加稍大锚点、延长最高阶训练或扩充更细粒度的中间特征, 但不能用目标模型结果反向挑选最有利设置。若任务过易, 应采用更困难样本或报告损失而非准确率。动态调整评测集会改变测量对象, 所以新版本必须独立命名, 不能与旧预测直接混排。

准确率饱和还会导致看似很低的绝对误差。预测 94 与实测 95 只差一点, 并不证明方法能分辨两个强模型; 两者可能都被上限压缩。模型选择若关心高能力区差异, 应增加难题、校准指标或连续评分, 并检查预测是否保持正确排序。

### checkpoint 相关性不能当成独立样本

从同一次训练抽取多个 checkpoint 能便宜地增加数据轴覆盖, 但这些点共享初始化、数据顺序和优化轨迹, 误差高度相关。把每个 checkpoint 当独立样本会低估参数不确定性。更稳妥的验证按训练运行分组, 例如留出整个模型规模或完整随机种子, 而不是随机拆分 checkpoint。

训练过程中的相邻点也可能暂时偏离平滑趋势。学习率退火、数据阶段切换或短期损失尖峰会在 $D$ 轴留下结构, 简单幂律无法表达。如果目标模型使用与阶梯不同的调度阶段, 外推尤其危险。拟合前应把 token 位置与学习率阶段共同可视化, 并说明目标点是否处于相同训练制度。

重复种子有助于分离训练噪声和任务噪声, 但会增加预算。可以优先在少数关键尺度跑重复种子, 用它们估计方差, 再将方差传播到全网格。没有重复运行时, 至少不能把曲线穿过观测点的紧密程度解释成真实置信区间。

### 架构变化会改变规模变量的意义

当模型从 dense 变为 MoE, 总参数、激活参数和每 token FLOPs 不再成固定比例; 直接把总参数代入 dense 阶梯会产生错误横轴。长上下文、局部注意力、混合循环层或不同词表同样会改变参数与计算的关系。跨架构阶梯需要重新选择规模变量, 可能以训练 FLOPs、激活参数或分模块容量表示, 并用实际吞吐核对理论计算。

即使都是 dense Transformer, 深而窄与浅而宽也可能在任务上表现不同。论文保持架构比例, 因而预测的是该比例下的规模增长。若生产模型因硬件效率改变头数、维度或层数, 最好在阶梯中加入对应分支, 检查是否仍落在同一任务损失曲面。否则形式上相同的 $N$ 不能保证功能等价。

tokenizer 变化则同时作用于模型参数、训练 token 和任务损失。相同文本会产生不同 $D$, 候选答案也会有不同 token 长度。跨 tokenizer 比较应回到字节量或原始文本量作辅助归一化, 并重新验证 RC 计分。最安全的生产预测仍是在阶梯和目标间固定 tokenizer。

### 将预测纳入持续校准闭环

每次目标训练都是昂贵但宝贵的新观测。团队应在训练前冻结预测文件, 记录时间、代码版本、阶梯数据与置信区间; 目标完成后追加实测, 计算每任务残差并分析方向。如果预测持续高估某类任务, 可能是第二阶段上限错误; 如果所有任务的损失都高于预测, 更可能是训练实现或第一阶段缩放偏差。

多轮项目积累后, 可以建立残差数据库, 按任务大小、外推倍数、模型家族和数据变化分类。这样的经验校准比单篇论文平均误差更能回答当前预测是否可信。它还会暴露选择性报告: 只有同时保存成功和失败的预测, 才能估计真实覆盖率。

阶梯也可用于训练中风险监控。目标模型早期 checkpoint 应落在预期任务损失轨迹附近; 若系统性偏离, 团队可以在消耗全部预算前检查数据、学习率或数值稳定性。不过早停规则必须结合通用训练损失和基础设施指标, 不能因某个高噪声任务短期落后就终止运行。

### 数据决策需要比较差值而非两条绝对曲线

若目标是选择数据混合, 最关心的是两个配方在目标规模的性能差, 而不是各自绝对准确率。两套阶梯使用相同初始化、评测样本和训练网格时, 误差可能相关, 差值的不确定性小于两个独立区间之和。配对设计因而比各跑一套无关实验更有效。

但共享因素也可能制造共同偏差。两个混合都缺少目标领域时, 阶梯可以稳定预测相近结果, 却无法告诉团队存在第三个更好方案。代理实验只能在候选集合内排序, 候选的提出仍依赖数据分析与领域知识。将阶梯与域级语言建模损失、重复率和数据质量指标结合, 才能解释排序原因。

数据容量也是约束。小模型只消费较少 token, 可能看不到低权重来源的足够样本; 目标模型训练数万亿 token 时又可能重复稀缺来源。若混合的有效组成随 $D$ 变化, 固定比例的幂律会隐藏数据重复拐点。复现时应记录每个来源的去重后容量、实际采样 token 和重复次数, 并避免把超出容量的外推解释为自然缩放。
