# Model Ladders 深度解析: 用小规模训练预测大模型任务表现

大模型预训练最昂贵的决策往往发生在训练开始之前: 数据混合、模型尺寸、token 预算和配方一旦选错, 完整运行很难重来。传统语言建模缩放律可以预测平均验证损失, 却不能直接回答 MMLU、ARC 或 HellaSwag 等单项任务最终会得到多少准确率。Model Ladders 的核心目标, 是让一组便宜的小模型成为目标训练的测量仪器, 在投入 7B、13B 级完整预算前预测下游任务表现。

论文的关键设计是避免从计算量直接拟合准确率。准确率有随机猜测下限和饱和上限, 小模型还可能长期停留在机会水平, 直接外推既不平滑也不稳定。作者先用参数量和训练 token 预测任务特定的中间损失, 再学习中间损失到准确率的映射。第一步利用损失随规模变化的平滑结构, 第二步处理任务指标的非线性, 两者共同构成可以检查误差来源的预测链。

## 模型阶梯如何构造可外推的观测

**两个轴组成十六个代理训练.** 阶梯不是简单训练一个缩小版模型。论文使用多个参数规模, 并让每个规模训练到不同数据预算, 从而同时观察模型容量与训练时长两个方向。公开仓库列出的阶梯包含约 190M、370M、760M 与 1B 级模型, 每个规模使用 1、2、5、10 倍 Chinchilla 参考 token 比例, 形成四乘四的网格。这样的设计让拟合不只依赖一条固定计算曲线。

若只改变模型尺寸而固定 token 数, 数据不足与容量不足会混在一起; 若只延长一个模型训练, 又无法判断更大容量是否改变极限。二维网格为 $N$ 与 $D$ 的指数项提供独立信息。论文以非嵌入参数量作为主要规模变量, 因为词嵌入参数随词表变化且不完全对应 Transformer 主干计算。复现时必须保持参数口径一致, 否则横轴会发生系统偏移。

所谓 Chinchilla 倍数用于组织训练预算, 并不表示目标模型处于经典计算最优点。现代模型常在固定参数规模上训练远超 $20N$ 的 token, 以降低推理成本。阶梯覆盖多个倍数, 正是为了在过训练区域收集信号。目标 7B-4T 与 13B-5T 远超小模型的常见最优 token 比, 因而单纯套用计算最优缩放律并不足够。 **可比性依赖架构和数据路径一致.**

代理模型要预测目标模型, 除规模外的关键条件应尽量相同。架构比例、tokenizer、数据混合、训练目标、学习率选择和评测协议如果变化, 拟合曲线可能同时吸收配方差异。论文的阶梯与 OLMo 2 目标模型共享训练体系, 使外推主要回答“同一配方扩大后怎样”, 而不是“另一个模型家族会怎样”.

这也是模型阶梯与通用跨模型回归的区别。跨实验室收集公开模型虽然样本多, 但数据、优化器和实现差异难以控制; 同一实验室阶梯样本少, 却有更强实验一致性。它牺牲跨家族普适性, 换取对单个生产配方的因果解释。论文的局限部分明确指出方法主要在 OLMo 2 家族上开发和验证, 迁移到其他 Transformer 配方仍需重新校准。

超参数同样需要随规模合理变化。若小模型学习率不佳, 它的损失会偏离真实规模趋势, 回归便把优化失败当成容量规律。阶梯配置应使用预先规定的层数、宽度、batch 和学习率缩放规则, 并在少量锚点验证近似最优。若每个点在看到目标任务后单独调参, 又会产生选择偏差。

## 两阶段任务缩放律的数学含义

**第一步从规模预测任务损失.** 第一阶段采用类似经典缩放律的形式, 把任务损失表示为模型项、数据项与不可约项之和. 可概括为

$$L(N,D)=A N^{-\alpha}+B D^{-\beta}+E.$$

其中 $N$ 是参数规模, $D$ 是训练 token, $A,B,\alpha,\beta,E$ 由阶梯点拟合。$E$ 表示在当前任务、数据与配方下继续扩大规模时的渐近损失。模型项和数据项分别描述容量不足与训练不足造成的额外损失。 这里使用任务相关的损失特征, 不采用统一语料验证损失。对于 ranked classification 形式, 每个答案候选作为续写计分, 正确候选的条件概率或相关交叉熵能在准确率开始显著上升前提供连续信号。一个小模型即使选错最多, 也可能逐渐提高正确选项概率; 0/1 准确率看不到这种变化, 损失却能看到。

任务损失也有噪声。测试集小、候选长度不同、概率归一化或提示格式变化都会改变观测。论文使用一致的 RC 评测设置, 让阶梯点可比较。拟合时应保存每个 checkpoint 的样本级对数概率, 不只保存任务平均值, 这样才能通过 bootstrap 估计观测噪声并发现异常题目。 **第二步从损失映射到准确率.**

准确率必须落在随机基线与理论上限之间, 因而损失到准确率通常采用带边界的非线性映射。直观上, 损失很高时不同选项概率相近, 准确率接近随机; 损失跨过某个区间后, 正确候选更常排第一, 准确率快速上升; 再继续降低损失时, 指标逐渐饱和。S 形曲线比无界幂律更符合这一几何结构。

两阶段分解还允许诊断误差。如果目标模型的实测任务损失已被第一步准确预测, 但准确率预测错误, 问题主要在第二阶段映射或任务噪声; 若损失本身预测偏离, 则应检查规模外推、训练配方或目标模型异常。直接拟合计算到准确率只能看到最终误差, 无法区分这两类原因。

第二步的最大困难是小模型缺少动态范围。若所有阶梯模型都处于随机准确率附近, 即使损失持续下降, 也无法可靠确定 S 曲线何时转折。论文因此更适合 RC 形式, 因为 RC 的连续概率信号在小模型上更早出现。原始 multiple-choice 标签生成形式要求模型理解输出 A、B、C、D 的接口, 小模型可能完全没有信号, 作者把稳定预测 MC 留作后续方向。 **为什么不直接用通用语言建模损失.**

平均验证损失聚合大量普通 token, 其中绝大部分与目标任务需要的知识和推理无关。两个模型可以有相近通用损失, 却因领域数据、选项判别或知识覆盖不同而产生不同任务准确率。用通用损失预测所有任务, 相当于假设每个任务以同一速度随平均语言能力改善, 这通常不成立。 任务损失把测量聚焦到目标样本, 但也更易受小测试集噪声影响。Model Ladders 选择的是偏差与方差之间的折中: 用任务特定特征降低系统偏差, 再用多个 checkpoint 和受控阶梯缓解方差。若任务只有几百题, 扩充评测集往往比增加更复杂的拟合函数更有价值。

## 实验结果应该如何解释

**低于百分之一计算量的真实含义.** 论文报告完整阶梯训练成本不到目标模型预训练计算量的百分之一, 并能对 7B-4T 与 13B-5T 的多个任务给出较准确预测。这个比例说明代理实验相对生产训练便宜, 但并不等于绝对成本很低。十六个模型、多 checkpoint 推理和多任务拟合仍需要显著资源, 而且若每种数据混合都重跑完整阶梯, 总预算会快速累积。

计算比例也取决于目标规模。目标越大, 固定小阶梯占比越低; 对 1B 目标模型, 同一阶梯可能不再经济。团队应按决策价值设计阶梯, 先用少数尺寸和预算检查信号, 再在拟合不确定性过高的区域添加点。固定十六点不是方法的本质, 覆盖目标外推所需的两个轴才是。

预测准确不能只看跨任务平均绝对误差。某些任务落在两点以内, 不代表每项都可靠。ARC 等较小或噪声较高的数据集更难拟合, 任务处于随机基线附近时相对误差也会被放大。应用时应报告每项预测区间、阶梯拟合残差和目标点距观测区域的距离, 而不是只给一个平均数。 **外推不是因果保证.**

曲线假设从小模型到目标模型的训练机制保持连续。如果大模型在某规模突然涌现标签遵循、长链推理或新记忆策略, 小阶梯无法预见结构断点。反过来, 目标训练遇到数据重复、数值不稳定或学习率异常, 也会偏离理想缩放曲线。预测区间只描述给定模型假设和观测噪声, 不包含所有工程事故。

数据和架构改变会破坏迁移。同一阶梯可以比较两个候选数据混合的早期排序, 但若目标训练动态随规模翻转, 小模型赢家未必是大模型赢家。DataDecide 等后续工作正是在研究这种跨规模决策。最稳妥的用法是把阶梯当作淘汰明显较差方案和估计大致收益的工具, 而不是取消目标规模验证。

论文只验证到 13B 级, 对 70B 及以上的外推距离更长。规模扩大还会改变并行策略、batch、上下文组成与优化稳定性。若要预测更大目标, 应增加中间规模锚点, 并在每次真实训练后把观测回填到阶梯模型。模型阶梯应是持续校准的测量系统, 不是一次拟合永久有效的公式。

## 工程复现与决策流程

**从训练网格到冻结预测.** 复现应先冻结目标问题: 模型架构、数据混合、目标参数量、token 预算和任务协议。随后生成阶梯配置, 明确每个点的非嵌入参数、层宽比例、全局 batch、学习率和训练 token。运行中按统一 token 间隔保存 checkpoint, 因为中间点能显著增加 $D$ 方向观测, 而不需要额外训练模型。 评测侧必须锁定数据 revision、提示、候选格式、归一化和分词处理。每个 checkpoint 保存任务准确率以及正确候选和全部候选的对数概率。若只保存准确率, 第一步所需的连续特征便无法重建。对被截断样本、空候选和并列分数也要记录, 不能静默丢弃。

拟合时应在预测目标结果揭晓前冻结模型形式、初始化和约束。可以用留一规模验证模拟外推: 隐藏最大阶梯尺寸, 用其余点预测它, 检查不同任务的误差和区间覆盖。若这种近距离外推都失败, 不应相信更远目标预测。选择模型形式后再揭晓目标点, 可避免针对最终答案事后调曲线。 **不确定性应进入训练决策.**

预测值只有与成本和不确定性结合才有意义。假设两个数据配方预测只差 0.4 点, 而置信区间宽 1.5 点, 阶梯并不能支持确定排序。团队可以增加对差异最敏感的规模点或扩充评测样本, 也可以承认结果不确定并用其他指标决策。把点估计的小差距解释为赢家, 会重现排行榜过度解读。

不确定性至少有三层: 评测样本噪声、曲线参数拟合噪声和模型设定误差。bootstrap 能处理前两层的一部分, 却难以覆盖缩放关系在目标规模改变的风险。可同时拟合若干合理形式并比较预测分散度, 再用历史目标训练衡量区间是否校准。真正可靠的系统要记录预测和事后实测, 而不只保存成功案例。 当预测用于是否启动昂贵训练时, 决策阈值应预先声明。例如只有预计提升超过一点评测且下界仍为正才升级配方, 或以每单位额外 FLOPs 的预期收益排序。这样的规则将统计预测转成可审计决策, 避免管理压力在结果出来后改变解释标准。 **与小规模消融和完整缩放律的关系.**

单点小模型消融便宜, 但无法知道结论是否随规模变化; 经典缩放律擅长预测语言建模损失, 却离具体任务较远; 完整目标训练最可信, 但成本最高。Model Ladders 位于三者之间, 用结构化小实验建立任务级外推。它最适合高成本、可重复且配方相对稳定的预训练决策。

对于后训练、工具调用或长推理, 任务表现还受采样和交互环境影响, 两阶段 RC 方法不能直接搬用。可以继承其思想, 寻找比最终成功率更连续的中间量, 例如测试通过比例、约束满足数或过程奖励, 再验证该中间量是否随规模平滑。没有实验证据时, “建立阶梯”只是比喻, 不是已经证明的预测器。

Model Ladders 最重要的方法论贡献, 是把大模型训练前的直觉判断转化为受控预测实验。小模型不再只是廉价演示, 而是按照规模和数据轴排列的观测装置; 任务损失不再只是评测副产品, 而是连接预训练计算与准确率的中间状态。它能显著降低决策成本, 但其可信度始终依赖配方一致、评测稳定、外推距离和诚实的不确定性报告。

## 失败模式与改进方向

**随机基线和饱和区都会削弱辨识度.** 任务曲线两端的信息量都很低。在随机基线附近, 参数规模变化尚未让正确选项稳定超过干扰项, 准确率几乎不动; 在接近饱和时, 多数模型都答对容易题, 额外损失改善也难以转成准确率。只有转折区同时包含足够多模型点时, 第二阶段映射才能可靠确定斜率与阈值。阶梯设计因此应参考任务当前难度, 而不是所有任务机械复用同一尺寸网格。

若任务对全部小模型都太难, 可以增加稍大锚点、延长最高阶训练或扩充更细粒度的中间特征, 但不能用目标模型结果反向挑选最有利设置。若任务过易, 应采用更困难样本或报告损失而非准确率。动态调整评测集会改变测量对象, 所以新版本必须独立命名, 不能与旧预测直接混排。 准确率饱和还会导致看似很低的绝对误差。预测 94 与实测 95 只差一点, 并不证明方法能分辨两个强模型; 两者可能都被上限压缩。模型选择若关心高能力区差异, 应增加难题、校准指标或连续评分, 并检查预测是否保持正确排序。 **checkpoint 相关性不能当成独立样本.**

从同一次训练抽取多个 checkpoint 能便宜地增加数据轴覆盖, 但这些点共享初始化、数据顺序和优化轨迹, 误差高度相关。把每个 checkpoint 当独立样本会低估参数不确定性。更稳妥的验证按训练运行分组, 例如留出整个模型规模或完整随机种子, 而不是随机拆分 checkpoint。 训练过程中的相邻点也可能暂时偏离平滑趋势。学习率退火、数据阶段切换或短期损失尖峰会在 $D$ 轴留下结构, 简单幂律无法表达。如果目标模型使用与阶梯不同的调度阶段, 外推尤其危险。拟合前应把 token 位置与学习率阶段共同可视化, 并说明目标点是否处于相同训练制度。

重复种子有助于分离训练噪声和任务噪声, 但会增加预算。可以优先在少数关键尺度跑重复种子, 用它们估计方差, 再将方差传播到全网格。没有重复运行时, 至少不能把曲线穿过观测点的紧密程度解释成真实置信区间。 **架构变化会改变规模变量的意义.**

当模型从 dense 变为 MoE, 总参数、激活参数和每 token FLOPs 不再成固定比例; 直接把总参数代入 dense 阶梯会产生错误横轴。长上下文、局部注意力、混合循环层或不同词表同样会改变参数与计算的关系。跨架构阶梯需要重新选择规模变量, 可能以训练 FLOPs、激活参数或分模块容量表示, 并用实际吞吐核对理论计算。

即使都是 dense Transformer, 深而窄与浅而宽也可能在任务上表现不同。论文保持架构比例, 因而预测的是该比例下的规模增长。若生产模型因硬件效率改变头数、维度或层数, 最好在阶梯中加入对应分支, 检查是否仍落在同一任务损失曲面。否则形式上相同的 $N$ 不能保证功能等价。 tokenizer 变化则同时作用于模型参数、训练 token 和任务损失。相同文本会产生不同 $D$, 候选答案也会有不同 token 长度。跨 tokenizer 比较应回到字节量或原始文本量作辅助归一化, 并重新验证 RC 计分。最安全的生产预测仍是在阶梯和目标间固定 tokenizer。 **将预测纳入持续校准反馈循环.**

每次目标训练都是昂贵但宝贵的新观测。团队应在训练前冻结预测文件, 记录时间、代码版本、阶梯数据与置信区间; 目标完成后追加实测, 计算每任务残差并分析方向。如果预测持续高估某类任务, 可能是第二阶段上限错误; 如果所有任务的损失都高于预测, 更可能是训练实现或第一阶段缩放偏差。 多轮项目积累后, 可以建立残差数据库, 按任务大小、外推倍数、模型家族和数据变化分类。这样的经验校准比单篇论文平均误差更能回答当前预测是否可信。它还会暴露选择性报告: 只有同时保存成功和失败的预测, 才能估计真实覆盖率。

阶梯也可用于训练中风险监控。目标模型早期 checkpoint 应落在预期任务损失轨迹附近; 若系统性偏离, 团队可以在消耗全部预算前检查数据、学习率或数值稳定性。不过早停规则必须结合通用训练损失和基础设施指标, 不能因某个高噪声任务短期落后就终止运行。 **数据决策需要比较差值而非两条绝对曲线.**

若目标是选择数据混合, 最关心的是两个配方在目标规模的性能差, 而不是各自绝对准确率。两套阶梯使用相同初始化、评测样本和训练网格时, 误差可能相关, 差值的不确定性小于两个独立区间之和。配对设计因而比各跑一套无关实验更有效。

但共享因素也可能制造共同偏差。两个混合都缺少目标领域时, 阶梯可以稳定预测相近结果, 却无法告诉团队存在第三个更好方案。代理实验只能在候选集合内排序, 候选的提出仍依赖数据分析与领域知识。将阶梯与域级语言建模损失、重复率和数据质量指标结合, 才能解释排序原因。

数据容量也是约束。小模型只消费较少 token, 可能看不到低权重来源的足够样本; 目标模型训练数万亿 token 时又可能重复稀缺来源。若混合的有效组成随 $D$ 变化, 固定比例的幂律会隐藏数据重复拐点。复现时应记录每个来源的去重后容量、实际采样 token 和重复次数, 并避免把超出容量的外推解释为自然缩放。

## 缩放预测的统计假设、反例与决策边界

**规模变量的选择.** 模型规模可以用参数量 $N$、训练token $D$、计算量 $C$ 或三者组合表示。只用参数量会把训练不足的大模型与计算最优模型混为一类；只用token又忽略容量。若各阶梯点沿固定配方共同改变 $N,D$，单一规模变量能拟合路径，却无法外推到另一条配比路径。 因此阶梯首先定义的是一条实验轨迹。目标大模型必须位于该轨迹的延长线上：架构、优化器、数据混合和训练token与参数比保持可比。离开轨迹后，预测误差既来自规模外推，也来自配方变化，两者无法由原曲线区分。 **计算量的近似.**

稠密Transformer训练FLOPs常近似与 $ND$ 成正比，比例系数取决于前反向、激活重计算和架构细节。MoE只激活部分参数，嵌入、注意力和专家通信又使单一 $N$ 失真。模型阶梯若跨架构，必须选择能够反映实际有效计算的口径。 理论FLOPs适合算法比较，实测设备时间包含利用率与通信。预测能力通常更关心前者，预算决策还关心后者。二者并列能区分「相同计算学得更好」与「系统实现更快」。 **幂律损失曲线.** 常见形式为 $L(C)=A C^{-\alpha}+E$，其中 $E$ 是当前任务与模型族下的经验下界。取对数后若 $E$ 已知，$\log(L-E)=\log A-\alpha\log C$，形成直线。实际拟合中 $E$ 也未知，参数高度相关，少量规模点会产生多组近似等价解。

外推距离越远，指数 $\alpha$ 的微小误差影响越大。报告拟合点残差不足以证明远端准确，应留出一个较大阶梯点做伪外推：只用更小点预测它，再比较误差。滚动回测比全点拟合后的高 $R^2$ 更接近真实用途。 **参数—数据双变量律.** 更一般形式可写成 $L(N,D)=E+A N^{-\alpha}+B D^{-\beta}$。容量不足项与数据不足项分别衰减，给定计算预算可寻找较优 $N,D$ 配比。若所有阶梯点都沿同一比例增长，两个指数难以独立识别，需要在参数和token两个轴上布点。 十六个代理训练的价值正在形成二维网格，而非一条线。网格必须覆盖目标配方附近的方向，才能判断大模型是容量受限还是数据受限。只在小区域拟合后外推多个数量级，结构假设比样本数量更决定结果。 **任务损失的定义.**

语言建模loss可以在任务文本、答案token或完整提示上计算。若把提示也计入，长题干会淹没答案预测；只算答案更贴近任务，但依赖模板和答案位置。多项选择还可计算正确候选的条件loss或候选间margin，两者与准确率关系不同。 Model Ladders选用与目标任务更贴近的损失，是为了获得比0/1准确率更平滑的信号。定义必须在各规模一致，并避免包含测试标签之外的泄漏。损失平滑不表示它天然因果，只是更适合拟合连续曲线。 **正确答案loss与margin.** 正确候选负对数概率下降，未必提高准确率；若错误候选概率下降得更快，排序仍可能错误。定义margin $m=s_{correct}-\max_{wrong}s_{wrong}$，其符号直接决定选择题正确与否。margin分布比正确答案loss更接近准确率机制。

不过不同任务候选数量与长度改变margin尺度。概率归一化、标签先验和模板也会影响。可以同时拟合正确答案loss、margin和准确率，观察哪项在留出规模上预测更稳定。单一代理失效时，多信号能揭示原因。 **损失到准确率的S形映射.** 准确率有随机基线和上限，常用四参数Logistic：$A(L)=a+(b-a)/[1+\exp(k(L-L_0))]$。$a$ 可近似随机水平，$b$ 为饱和上限，$L_0$ 是转折损失，$k$ 控制陡峭程度。连续loss缓慢下降，穿过 $L_0$ 时准确率会快速上升，形成涌现表象。 若阶梯点全在随机区，$L_0,k$ 无法识别；全在饱和区也同样困难。阶梯设计需要让至少部分点跨越转折区。任务太难时，小模型全部随机，大模型预测主要由模型形式假设决定，不确定性应明显扩大。 **随机基线并非总是 $1/K$.**

K选一任务的均匀随机基线为 $1/K$，但标签偏置、候选长度和答案分布不均会让无能力模型高于它。一个只利用标签频率或模板启发式的基线，更接近实际下限。S形映射若把错误下限固定为 $1/K$，转折位置可能偏移。 可将下限作为参数，或用随机初始化和浅层基线估计。自由参数增加后需要更多点。下限与斜率相关，报告参数区间与敏感性比只给一条拟合线可靠。 **饱和上限.** 任务含歧义、标签错误和超出上下文的信息时，经验上限低于100%。把上限固定为1会迫使曲线以错误形状接近饱和，并可能高估大模型。强模型、人类复核和争议题审计可提供上限线索。

上限也可能随提示和工具条件改变。模型阶梯必须使用同一协议，否则小模型曲线与目标模型上限不一致。协议改进应作为新预测问题重新校准。 **准确率的离散噪声.** N道题准确率步长为 $1/N$，小测试集曲线呈台阶。模型真实概率缓慢变化，也只有翻转若干题时观测准确率才改变。二项噪声在中间区域最大，在接近0或1时较小，但题目相关会放大方差。 任务loss利用每题连续概率，样本效率更高。最终准确率预测仍需传播有限题目不确定性。文档或题型簇bootstrap比把所有题当独立Bernoulli更合理。 **从每题概率聚合.**

与先拟合任务平均loss再映射准确率相比，可为每道题拟合正确概率随规模变化，再平均。但单题数据点少、噪声大，参数难以稳定。层级模型可以让题目共享斜率分布，同时保留难度差异。 任务级模型简单稳健，题目级模型能解释哪些题在何种规模翻转。二者预测一致增强信心；差异大时，说明平均loss压缩了重要异质性。成本允许时可用题目难度分桶折中。 **拐点与涌现表象.** 0/1指标把连续概率阈值化。很多题的margin同时接近零时，规模增加会让大量题翻转，准确率看似突然涌现，而底层loss和margin可能平滑。换成部分分、概率或更密集题目，拐点常变缓。

这不表示所有涌现都是测量幻觉。模型可能学到新算法、上下文策略或表示，底层指标也出现结构变化。判断需要检查loss、margin、错误类型和中间规模，不能只凭准确率曲线命名机制。 **真正结构变化的线索.** 若新架构组件启用、数据阶段切换或优化动力学跨越临界点，损失曲线可能出现残差系统性转折。多个独立任务在相近计算点同步变化，也比单一小基准更值得关注。仍需排除评测解析和提示格式随规模变化。 分段幂律、样条和变点模型可以描述拐点，但自由度更高，容易追随噪声。用留出规模比较预测误差，决定复杂模型是否必要。解释结构变化还需要训练过程证据。 **外推距离.**

预测目标与最大阶梯点的计算比值是关键风险指标。从最大代理外推2倍与100倍，不确定性完全不同。即使同一函数形式，参数区间在远端会显著张开。报告目标位于训练点凸包之外多少，比笼统说「用小模型预测」更具体。 二维 $N,D$ 网格中，还要看目标方向。沿已观察的计算最优线外推较稳，向未覆盖的高参数低token区域外推风险更大。距离可在对数坐标和标准化设计空间中计算。 **参数不确定性传播.** 拟合得到参数协方差后，可通过Delta方法、bootstrap或贝叶斯后验生成目标预测分布。两阶段模型还要把规模到loss的不确定性传入loss到准确率映射，不能只给第二阶段条件区间。

最简单做法是在每次bootstrap中重采样题目和训练run，重新拟合两阶段并预测。所得区间同时包含评测抽样与拟合波动，但不包含模型形式错误。比较多种合理函数的预测范围可补充结构不确定性。 **模型形式不确定性.** 幂律、带下界幂律、对数线性和样条在观测区间可能拟合同样好，远端预测却不同。只选择训练误差最低者会偏爱复杂模型。留出回测、信息准则和模型平均能减少选择风险。 决策时可把不同函数视为情景，而非强行合成一个数字。若所有合理模型都预测方案A优于B，选择稳健；若结论随函数翻转，大规模投入前需要增加阶梯点。 **数据噪声与训练噪声.**

任务题目抽样造成评测噪声，训练seed和批次顺序造成run噪声。单个checkpoint序列无法估计后者，因为相邻点来自同一run且高度相关。至少在少量关键规模重复训练，才能校准曲线周围的真实散布。 把所有checkpoint当独立样本会让置信区间过窄。可以为run设置随机效应，并对时间相关残差建模。若预算有限，宁可减少同一run的密集检查点，也要增加独立run。 **检查点的作用.** 中间checkpoint提供同一模型在不同训练token下的纵向曲线，帮助识别学习率和数据阶段影响。它们扩展D轴覆盖，却不等价于独立训练不同token预算：较短预算模型若从头采用相应调度，轨迹可能不同。

用checkpoint拟合前，应把学习率位置、累计token和数据顺序纳入变量。目标大模型若采用不同调度，纵向外推会偏。独立短训练点可验证checkpoint是否代表相应预算。 **数据配方的平行曲线假设.** 用小模型比较两个数据配方并预测大模型差值，隐含两条缩放曲线形状可外推。若配方A在小规模更好、B在大规模利用复杂数据更强，曲线会交叉。仅比较最小模型可能选错。 至少在多个参数和token点估计配方×规模交互。差值曲线往往比两条绝对曲线更稳定，因为共享误差抵消；交叉存在时，仍需在目标附近增加点。预测数据决策比预测单模型绝对分数更贴近实际用途。 **架构保持的含义.**

保持架构家族不仅指层数按比例增加，还包括宽深比、头维、位置编码、归一化、词表和上下文长度。某组件在小模型中占比高、在大模型中占比低，会改变缩放曲线。MoE的总参数与激活参数更使规模含义分裂。 目标架构改变时，可重新建立小型阶梯或加入架构指示与交互项。直接把旧稠密曲线外推到新MoE，只能作粗略先验。架构创新收益需要独立验证。 **优化器超参数的缩放.** 学习率、batch、权重衰减和初始化若未按规模合理调整，小模型曲线可能包含优化不足。目标大模型使用更成熟配方后，会偏离预测。反过来，小模型过度调参、大模型沿用默认，也会产生相反偏差。

阶梯点应使用预先规定的规模化规则，并检查训练loss是否平滑、稳定。为每个点单独搜索最佳超参数虽然提高点性能，却把不同搜索预算混入曲线。两种策略需明确取舍。 **数据质量随规模交互.** 小模型可能无法利用长推理或专业文本，偏好简单高重复数据；大模型容量增加后，高质量复杂数据收益才出现。数据过滤阈值也可能改变多样性，规模越大越容易受覆盖不足限制。 因此小模型消融用于筛选时要保留若干风格差异大的候选，不宜只选当前最高分。多个阶梯规模能发现收益斜率。大模型目标若远离最大代理，保留探索预算是理性的。 **Tokenizer变化.**

更换tokenizer会改变训练token预算、任务loss分母和答案概率。即使原始字节数据相同，$D$ 轴含义与损失尺度都变化。旧阶梯不能直接预测新词表模型。 可用字节尺度loss建立部分桥接，但网络优化和序列长度仍不同。最可靠办法是为新tokenizer训练少量校准点，估计平移与斜率变化。只修正token数量不足以保证曲线等价。 **上下文长度变化.** 目标大模型若扩展上下文，训练序列长度、位置分布和任务提示都可能变化。小阶梯短上下文下的loss无法预测长程能力。即使任务文本短，长序列训练也会改变优化和数据packing。 阶梯应使用与目标一致的序列长度，或单独建模长度轴。对于长上下文任务，需要在不同长度上测量，而非从短任务loss间接外推。上下文扩展属于配方变化。

**训练数据时间变化.** 阶梯训练与目标训练之间若数据快照更新，新增网页、去重和过滤都会改变分布。目标分数偏离曲线可能来自数据，而非规模律失败。固定数据manifest最清楚；无法固定时，至少在旧新快照上训练桥接点。 时间更新有时正是目标改进，不能为了预测纯洁而放弃。此时预测应给旧配方基线，再把数据变化作为单独效应估计。多个不确定改动同时发生会让阶梯失去决策价值。 **任务协议稳定性.** 评测模板、few-shot、答案归一化或数据版本改变，会移动准确率映射。规模到任务loss或许仍稳定，第二阶段映射已经不同。冻结协议是最低要求，修正错误后需重跑阶梯点。

若目标模型需要新聊天模板，可在小点同时运行旧新协议，建立桥接。不能只在目标点采用最优模板，再与旧阶梯预测比较。协议选择本身会制造看似超越缩放律的结果。 **多任务联合拟合.** 多个任务可以共享规模指数或损失映射先验，让小数据任务借力。层级模型为每任务保留难度和转折点，同时估计共同分布。共享过强会把真正异质任务拉向平均，共享过弱则失去稳定作用。 留出整个任务评估层级先验能否迁移。若新任务属于完全不同形式，共享参数未必合理。联合拟合适合提供基线预测，任务特定点仍不可少。 **任务选择偏差.**

若只报告预测准确的任务，会高估方法。完整任务清单、预先定义纳入标准和失败案例必须公开。某些任务因小模型全随机而无法拟合，这本身就是方法边界，不应从平均误差中删除。 预测误差按任务难度、基线和转折覆盖分层，能说明何时可用。总体平均误差可能被大量平滑任务稀释，而决策最关心的任务恰好难预测。 **百分比误差的陷阱.** 准确率接近零时，相对误差巨大；接近随机基线时，绝对1点可能代表大量可提升空间。可报告绝对百分点、相对错误减少和相对随机基线以上增益。不同口径共同给出尺度。

对于loss预测，MAPE在真实值接近零时也不稳定，虽然语言模型loss通常不为零。对数误差与绝对误差各有意义。决策损失应与实际预算和门槛相连。 **预测区间的覆盖校准.** 声称90%预测区间，应在历史留出目标中约90%覆盖真实值。若只覆盖一半，区间低估结构误差；若总是极宽，虽覆盖却缺乏决策价值。滚动阶梯实验可以校准。 样本少时覆盖估计不精确，可按任务汇总并报告置信区间。共形预测在交换性假设下提供有限样本覆盖，但跨规模外推违反同分布，仍需谨慎。经验回测最直接。 **预测偏差的方向.** 平均绝对误差隐藏系统性高估或低估。若方法总高估大模型准确率，预算决策风险比对称噪声更大。报告有符号误差、校准斜率和按外推距离分层。

系统偏差可能来自饱和上限、优化不足或数据变化。误差诊断应回到两阶段：先看目标loss是否预测准，再看给定loss的准确率是否映射准。两段分开才能修正。 **决策阈值.** 实际问题常是目标模型是否能超过某分数门槛，而非精确预测到小数点。预测分布可计算超过阈值概率。若概率接近一半，追加一个阶梯点的价值很高；接近0或1时，现有证据可能足够。 门槛来自产品、研究或预算目标，应在预测前确定。根据预测均值临时移动门槛会破坏决策解释。多个关键任务可设联合约束，避免平均达标掩盖单项失败。 **信息价值.**

追加小模型实验的价值等于它可能改变决策所减少的预期损失，再减去实验成本。靠近方案分界、模型预测分歧大或区间宽时，信息价值高。若所有合理曲线都支持同一选择，继续补点意义小。 这把阶梯设计从均匀网格推进到顺序实验。每轮根据后验不确定性选下一个规模或token点，但选择规则和历史需要保存，防止事后只展示有利路径。 **阶梯点的最优位置.** 估计幂律斜率需要对数规模上有跨度，点全挤在一起无法支撑远端外推；估计S形转折又需要在准确率变化区密集采样。两阶段目标可能要求不同布点。

初始点可覆盖宽对数范围，看到任务loss与准确率后，在转折附近补点。最大代理尽量靠近目标，以限制外推距离。重复run用于估计噪声，不能全部预算都花在更多唯一点。 **训练失败点.** 某阶梯run发散或数据异常时，直接删除会造成幸存者偏差。失败可能说明目标规模更危险，也可能只是硬件故障。记录失败原因、最后有效checkpoint和重跑规则。 若只重跑失败点直到成功，成功曲线低估运行风险。能力预测与训练成功概率可以分别建模，预算决策同时考虑。大规模训练的风险不仅是终点分数不够。 **多seed分配.**

在每个点重复相同seed数简单，却未必高效。小模型便宜，可多重复估计训练噪声；大代理昂贵，至少保留两个独立run校准外推附近方差。若噪声随规模变化，不能只用小点方差。 自适应分配可在残差最大的点增加seed。报告所有run，不以最佳seed代表规模点。拟合使用run层级数据而非先挑选后平均。 **预算守恒的配方比较.** 比较数据或算法方案时，每条阶梯的训练FLOPs、token和超参数搜索预算应对齐。方案A若多训练20%，预测更好不能全归于数据质量。可分别做固定计算与固定token比较，回答效率和最佳性能。 评测成本也应计入，尤其多任务、多checkpoint时。阶梯总成本低于目标训练，不代表任意大的搜索免费。论文所称低于百分之一需要明确分母和包含项。 **搜索预算的赢家偏差.**

对十种配方各建小阶梯，再选预测最好者，最终赢家带有预测噪声的正偏。候选越多，偏差越大。保留独立确认阶梯或对选择过程做嵌套验证，可以减少。 最终大模型只训练赢家时，无法知道其他方案真实排名。历史多轮项目可积累校准，但选择偏差仍需报告。阶梯降低单次试错成本，也可能鼓励更大搜索空间。 **差值预测.** 若基线与候选共享架构、数据大部和训练随机性，直接拟合任务loss差 $\Delta L(C)$ 可消除共同系统误差。差值可能比绝对曲线更平滑，也更贴合选择问题。共享seed和数据顺序增强配对。 当两方案曲线交叉，差值模型必须允许符号变化。强行设常数增益会错过规模交互。报告绝对预测作为诊断，确认差值改善未掩盖两条曲线共同失配。

**排名预测.** 有时只需选最佳配方，可直接建模候选在目标规模的排序概率，无需精确预测分数。成对差值后验给出A胜B概率，组合成选择风险。排序正确但分数偏差较大，仍能支持决策。 若方案差距小于实际重要阈值，强行排序没有意义。定义等效区，把多方案视为并列，再结合成本、安全或实现复杂度选择。预测工具应服务决策，而非制造虚假精度。 **负迁移任务.** 目标配方可能提高主任务，却降低安全、常识或某领域。阶梯若只监控主任务，会错过。多目标预测至少包含关键回退项，并对每项设约束。

小模型上无回退不保证大模型安全，因为规模交互存在。对高风险任务保持独立评测和保守区间。综合效用必须公开权重，不能让平均掩盖严重负迁移。 **与完整缩放律的关系.** 经典缩放律关注预训练loss随参数、数据和计算变化；Model Ladders把任务特定loss与准确率映射加入，服务具体下游预测。前者提供全局训练规律，后者把规律接到离散任务决策。 任务映射依赖协议和题目，迁移性较弱。语言模型loss曲线稳定也不能保证每个任务可预测。两者结合时，先验证规模到任务loss，再验证任务loss到指标，避免把端到端误差藏在单一拟合中。 **与小规模消融的关系.**

单一小模型消融默认方案差值跨规模保持，成本最低、风险最高。阶梯增加多个规模和token点，能检测交互与交叉。完整目标规模实验给最终真值，但无法在训练前用于选择。 三者形成层级：便宜消融筛掉明显失败，模型阶梯估计候选与不确定性，少量大规模运行验证并更新校准。阶梯承担资源分配工具的角色，最终证据仍来自目标规模的实际运行。 **开放结果的复算资产.** 每个run需要配置、数据manifest、代码提交、checkpoint、训练token、FLOPs口径、任务逐题loss与答案。拟合脚本保存数据选择、函数形式、先验和优化初始化。目标预测在真实结果揭晓前冻结时间戳。

揭晓后发布误差与诊断，不能只更新成更漂亮的回归线。历史预测形成校准集，让后来项目知道区间覆盖和常见失败。开放方法的价值也在这些失败记录。 **结论层级.** 小阶梯拟合良好只说明观测区间可描述；留出较大代理预测准确支持有限外推；多个任务和配方回测支持方法稳健；真正目标模型命中区间才验证本次决策。每一层证据递进。 即使目标预测成功，也不能证明幂律参数具有永恒机制意义。下一代架构、数据或协议可能改变曲线。Model Ladders最可靠的定位是针对固定训练家族的经验预测系统，并通过持续回测管理风险。 **参考文献.** **任务loss的抽样单位.**

任务loss通常由许多题目的答案token平均得到。按token平均让长答案权重更高，按题平均则每道题同权。若任务准确率按题计数，而代理loss按token计数，两阶段映射中隐含权重不一致。长答案题的loss变化可能主导代理，却只贡献一个准确率单位。 可先在每题内平均答案token loss，再跨题平均，使代理与准确率单位对齐；也可保留token平均并将题长纳入映射。两种口径需在留出规模上比较。没有说明分母，任务loss无法复算。 **答案长度与规模交互.** 大模型可能在长答案上改善更快，导致token平均loss曲线斜率随答案长度组成变化。若小阶梯任务子集较短、目标评测包含长答案，外推会偏。按长度分桶拟合能检查这种交互。

多项选择标签虽短，完整候选打分仍受候选长度影响。固定标签空间减少混杂，却引入标签先验。模型阶梯应与最终协议完全一致，不能在小点用便宜近似、目标点换成另一打分方式。 **Prompt loss与答案loss.** 完整序列loss包含题干。题干文本通常在模型规模增大时平滑改善，可能让任务loss看起来可预测，却与答题正确关系很弱。只算答案token更贴近能力映射。若提示含few-shot示例，示例loss更不应混入目标。 仍可保留prompt loss作为域熟悉度诊断。模型对题干语言陌生时，答案映射可能失效。将两者作为不同特征进入回归，比混成一个平均更清楚。 **选项概率的归一化.**

选择题候选的总log概率偏向短选项，平均token log概率又可能偏向由许多容易token构成的长选项。PMI式校正去除候选无条件先验，却依赖参考上下文。规模变化时标签先验也可能变化，影响准确率拐点。 阶梯预测应固定一种经过验证的评分规则，并用候选margin作为补充。若不同规则在目标规模给出不同预测，协议不确定性应进入决策。选择最有利规则会引入额外乐观偏差。 **Logistic映射的可识别性.** 四参数Logistic同时估计下限、上限、斜率和中心，需要足够覆盖。若所有点只位于左尾，增大上限与改变斜率都能产生近似曲线，目标预测极不稳定。参数相关矩阵和轮廓似然能显示这种不可识别。

基于任务结构固定随机下限可减少自由度，基于人工或强模型估计上限也有帮助。但固定值错误会产生系统偏差。用多个合理上下限重拟合，观察目标区间，是简单敏感性分析。 **Probit与Logistic.** 若每题潜在margin带近似正态噪声，准确率随平均margin可能呈probit；Logistic尾部稍厚。观测区间内二者往往相似，远端饱和速度不同。只选择拟合误差略低者无法保证外推正确。 把二者纳入模型集合，比较留出预测并做模型平均，能反映形式不确定性。若决策在两种映射下相同，结论更稳；若翻转，应增加转折区数据。 **非参数单调映射.**

理论只要求loss下降时准确率大体不降，可用等距回归拟合单调关系，减少S形假设。它在观测范围内灵活，范围外只能保持边界或依赖额外外推规则，无法独自预测远端。 非参数曲线适合检查Logistic是否系统错配。若两者在观测区已明显不同，参数外推风险高。真正远端预测仍需结构假设，这种依赖应明确。 **每题阈值模型.** 将题目 $i$ 的潜在margin写成 $m_i(C)=g(C)-b_i$，当margin大于零时答对。题目难度阈值 $b_i$ 的分布决定总体准确率曲线。若 $b_i$ 服从Logistic分布，就得到S形映射。 这个视角解释拐点：规模能力 $g(C)$ 平滑上升，穿过题目密集阈值区时准确率快速变化。题库难度分布改变，拐点也改变，因此所谓涌现位置不是模型固有常数。 **题目难度分布漂移.**

评测版本新增更难题或删除争议题，会改变阈值分布，旧阶梯映射失效。即使模型loss尺度相同，准确率上限和转折点都会移动。协议版本必须绑定曲线。 共同题目可桥接新旧版本：在交集上保持旧映射，新题单独估计难度。样本少时不确定性较大，不能直接复用旧参数。动态基准需要持续校准阶梯。 **基础模型与指令模型.** 任务loss在基础模型上可通过续写形式测量，目标指令模型经过后训练后提示接口和概率分布改变。用预训练小阶梯预测后训练大模型，等于跨阶段外推。SFT、DPO和RL可能改变loss到准确率映射。

若目标是预训练决策，应在统一基础模型检查点上预测基础能力；后训练收益另建小阶梯或经验增量模型。把两者混在一条曲线，会将规模与后训练混杂。 **后训练增量的尺度变化.** 小模型从SFT获得的提升可能更大，因为基础遵循弱；大模型基础能力强，边际提升较小。也可能相反：大模型更能利用复杂偏好数据。后训练增量需要至少两个规模点估计交互。 若最终评价是指令模型，阶梯可以对每个预训练点应用相同后训练配方，但成本增加。用少量规模建立增量曲线，再与预训练预测相加，是可行近似，区间需传播两部分误差。 **多阶段数据的变化.**

大模型训练常在末期加入高质量数据或延长上下文，小代理若未经历同样阶段，终点不在同一配方族。为节省成本，可以让代理按比例经历阶段，保持每阶段token占比和学习率位置。 阶段效果可能依赖绝对token而非比例，尤其数据量有限时。代理重复高质量集的epoch数与大模型不同，会改变记忆。记录唯一数据量与曝光次数，检查缩放假设。 **优化未收敛.** 小模型某些点若学习率过高或训练过短，loss高于缩放趋势；拟合会误以为规模收益更陡。训练稳定性指标、梯度范数和邻近checkpoint曲线能识别。目标大模型若同样未收敛，理论最优曲线也会高估。

预测实际训练应使用实际可达到曲线，而非假设每点最优。若超参数搜索预算随规模变化，需把搜索策略纳入实验族。最佳可能性能与计划配方性能是两个目标。 **数据顺序噪声.** 固定数据顺序有助于方案配对，却可能让曲线依赖一个特殊顺序。多个seed能估计。大模型看到更长前缀，小模型或短token点只看到其中一部分，前缀内容分布若不均匀会制造规模趋势。 将数据流分块检查域比例，或为不同预算构造分布一致的子序列，可以减少。完全共享前缀与各预算独立混匀之间存在取舍：前者配对强，后者分布更一致。 **训练token测量误差.**

名义token预算可能包含padding、重复、被mask位置或数据加载丢弃。规模律需要使用真正参与loss的有效token。不同序列长度和packing效率会让名义 $D$ 与有效 $D$ 比例变化。 保存累计有效token计数和每来源贡献，目标点才能落在正确坐标。横轴测量误差会让幂律斜率衰减或扭曲，不能靠更多纵轴点弥补。 **计算量测量误差.** 用固定 $6ND$ 近似忽略注意力序列二次项、词表投影和激活稀疏。模型较小时非Transformer部分占比更高，目标大模型比例又变化，导致横轴非线性偏差。 可从实际算子形状估算前后向FLOPs，或至少对各规模使用同一细化公式。系统空闲与通信不进入算法FLOPs，却进入美元预算。能力拟合和成本决策分别使用合适横轴。 **小模型架构的不连续.**

为了满足头数、宽度和硬件整除，小规模点的宽深比可能跳变。某点突然多一层或改变头维，会偏离平滑规模路径。设计阶梯时优先保持关键比例，无法保持的离散变化要记录。 拟合中可加入架构指标或排除用于诊断的异常点，但排除规则需事前或基于明确结构。看到残差后随意删点会提高虚假拟合度。异常点也可能揭示架构规律。 **词表参数占比.** 小模型中嵌入和输出词表矩阵占参数比例较大，大模型中相对较小。用总参数 $N$ 作为规模变量，会让小点有效Transformer容量被高估。可用非嵌入参数或活跃参数作为替代。 哪个口径预测更好需留出验证。若目标词表固定，差异可系统校正；词表也改变时问题更复杂。报告两种参数数目让外部复算。

**共享嵌入的影响.** 输入输出权重绑定会减少参数，却改变训练动力学。阶梯小点绑定、目标大模型不绑定，等于架构变化；即使总参数校正，函数族也不同。所有点应保持绑定策略一致。 类似地，偏置、归一化和激活函数的细节可能在小模型上相对影响更大。规模预测要求配方纪律，不能把代理模型当任意缩小版本。 **MoE的两个规模轴.** MoE同时有总参数和每token激活参数。模型容量可能随总专家数增加，计算主要随激活专家增长。用单一N无法描述。阶梯至少需要固定路由和专家形状，分别记录总量与活跃量。 路由负载与专家利用率还会随规模变化，造成额外交互。稠密阶梯无法直接预测MoE目标；训练小型MoE阶梯或只做非常宽的先验更合适。

**数据并行规模的间接影响.** 大目标使用更多设备和更大全局batch，小代理batch较小。若学习率和梯度噪声尺度变化，优化路径不同。保持每token更新语义需要按batch调整学习率与累计，并验证loss曲线。 固定全局batch有利于算法对齐，却可能让大模型系统效率很差。实际配方若改变batch，就应在代理网格中加入batch轴或桥接实验。系统选择可能成为缩放假设的一部分。 **低精度训练.** 目标大模型可能使用FP8或新融合算子，小代理使用BF16。数值噪声、动态范围和稳定机制变化会影响训练loss。若低精度只带来微小同尺度偏移，可由桥接点校准；若改变发散率或收敛斜率，需要新阶梯。

性能收益与能力影响分开测量。低精度让同预算可训练更多token，最终可能更好，即使固定token下loss略差。预算决策应比较完整可行方案。 **误差分解.** 目标预测误差可分为第一阶段loss误差、第二阶段映射误差、训练随机性、评测抽样和协议/配方漂移。用真实目标loss代入第二阶段，可测映射误差；比较预测loss与真实loss，测第一阶段。两者分开比只看准确率差更能改进系统。 若loss预测准、准确率错，检查转折覆盖和任务协议；loss已错，检查规模律、优化和数据。误差分解应成为每次目标训练后的固定复盘。 **残差的结构.**

合格拟合的残差不应随规模、token或训练阶段呈系统趋势。小点全为正、大点全为负说明斜率错；某数据阶段后跳变说明单一曲线遗漏变量。残差自相关会让普通标准误过小。 绘制残差而非只报 $R^2$。高 $R^2$ 可由宽规模范围产生，即使目标附近偏差明显。外推最关心边界残差和留出误差。 **杠杆点.** 最大规模代理对斜率和下界估计具有高杠杆，一次异常训练会显著改变目标预测。删除一个点重拟合的jackknife能显示敏感性。若预测随删除某点大幅变化，区间应扩大或补充邻近点。 最小点也可能因架构比例异常成为杠杆。设计矩阵的杠杆值与实际残差结合，有助于决定下一个实验位置。点数多不等于信息均匀。 **异方差.**

小模型训练便宜可多seed，均值方差较小；大代理只有一次run，训练方差未知。准确率在随机区和转折区的方差也不同。普通最小二乘假设等方差可能给出不合理权重。 加权最小二乘、层级模型或显式方差函数能处理。权重来自独立seed和题目bootstrap，而非用残差事后随意设置。预测区间需包含目标处更大的方差。 **贝叶斯先验.** 历史项目可为缩放指数、下界和转折斜率提供先验，在当前点少时稳定拟合。先验必须与架构和任务相近，并报告其对结果影响。强先验可能让区间看似精确，实际只是继承旧假设。 用宽、历史和怀疑性三组先验做敏感性分析。若决策一致，先验依赖小；若翻转，追加数据比争论先验更有效。后验概率适合直接计算超过目标门槛的机会。

**后验预测检查.** 从后验采样参数，生成各阶梯点的模拟loss与准确率，比较模拟数据的残差、弯曲和方差是否像真实观测。参数区间合理不代表模型能复现数据特征。 检查尤其关注随机区全零、饱和区全一和转折题数。系统性不匹配提示换函数或增加层级。后验预测是模型批判工具，不只是生成漂亮置信带。 **频率学派区间.** 参数bootstrap可按独立run和题目两层重采样，每次完整重拟合。它少依赖正态近似，适合非线性两阶段模型。拟合失败次数本身反映不可识别，不应静默丢弃。 若许多bootstrap样本预测发散，报告有限分位数会掩盖风险。应说明失败比例、参数边界和采用的约束。增加转折区点通常比强行截断更可靠。 **模型平均.**

对多个合理缩放函数按留出预测权重平均，可以降低选错单一模型的风险。平均区间应包含模型内与模型间方差。若某个复杂模型在少量回测上偶然领先，权重也会不稳定。 保留每个模型的独立预测作为情景，尤其用于高成本决策。平均值可能落在任何单一机制都不支持的位置。稳健选择关注所有高权重模型是否同向。 **最坏情景决策.** 风险厌恶团队可在合理模型与参数集合中评估每个方案的最坏结果。它避免因乐观外推投入巨大预算，却可能过于保守。设置最大可接受后悔值是另一种折中。

合理集合由回测和科学约束定义，不能无限扩大。把风险偏好显式化，比用一个窄区间暗中采取乐观假设更透明。目标训练越昂贵，结构不确定性的权重越高。 **分阶段承诺预算.** 目标训练无需一次承诺全部预算。先训练到若干token检查点，用真实曲线更新预测，再决定继续、调整或停止。早期检查点必须预先设置，避免看到不利结果后任意改变判断。 大模型早期曲线与小阶梯可共同校准个体偏差。停止节省成本，但已投入计算不可回收；调整数据又会改变配方族。决策规则需要区分允许的动作。 **早停的机会成本.**

预测未达标而停止，可能错过后期转折；继续错误方案则浪费预算。根据后验达标概率、剩余成本和成功价值，可计算继续的期望价值。模型若对拐点高度不确定，保留一段观察预算有意义。 安全或稳定性失败属于硬约束，可覆盖期望分数决策。能力预测不能替代训练健康监控。预算模型应同时考虑故障概率。 **候选配方的淘汰.** 多候选阶梯可采用连续淘汰：当某方案在所有合理目标权重下都被另一方案支配，且区间分离，就停止其后续训练。相近方案保留到更大规模。规则类似多臂试验，但观测成本随规模增长。 共享基线和配对seed提高淘汰效率。过早淘汰会错过曲线交叉，因此规模交互强的方案需要保护。历史回测可校准淘汰阈值。

**成功概率与期望分数.** 两个方案预测均值相同，一个区间窄、一个有小概率极高但也可能失败。风险中性决策看期望，预算受限或发布期限固定时可能偏好成功概率高者。训练稳定性和能力不确定性共同决定。 分别报告完成训练概率、达标条件概率和无条件期望。把发散run删除后只拟合成功分数，会高估高风险方案。失败属于结果分布。 **系统吞吐与训练配方.** 方案A每FLOP能力更好，方案B硬件利用率更高，在固定日历时间或美元下B可能训练更多token而领先。模型阶梯的能力曲线应连接系统效率模型，才能支持真实预算。

吞吐测量随规模和并行布局变化，不能从小模型线性外推。目标附近的系统基准或模拟提供补充。算法与系统优势分别记录，最终在共同资源约束下比较。 **推理成本约束.** 大模型训练预测达标，部署推理成本可能超过预算。模型选择可同时预测能力与每token推理成本，寻找质量—成本前沿。更小模型通过更多推理token或采样也可能达到目标。 训练阶梯通常固定推理协议，若目标使用CoT、best-of-n或工具，需把额外预算纳入。权重能力与推理策略共同组成系统，不能只预测单次准确率。 **预测对数据采购的价值.**

采购或清洗新数据前，可用小阶梯估计其大规模边际收益。成本包括许可、处理和训练，收益分布来自差值外推。若区间跨越零，先扩充代理规模或做更多seed，可能比直接采购便宜。 数据权益与安全不能仅由性能收益决定。即使预测高收益，许可或隐私不满足也不可使用。阶梯解决资源判断，不取代治理约束。 **预测对架构实验的限制.** 架构改动可能在小模型表现良好，却因通信、优化或容量利用在大规模失效。阶梯仍可使用，但需要覆盖足够规模以观察系统和算法交互。只在参数匹配小模型上比较远远不够。

新架构目标曲线可与基线共享任务映射吗，取决于loss含义是否一致。规模到loss曲线通常需重建，loss到准确率映射也要验证。不要假设第二阶段天然架构无关。 **反例：全点拟合完美.** 四个点恰好落在直线上，可能因为共享训练run、同一数据前缀和测量误差相关。完美拟合并不代表外推可靠。增加独立seed或留出第五点，往往比继续提高曲线复杂度更有信息。 若参数数目接近数据点数，$R^2$ 更没有意义。自由度、条件数和预测区间必须报告。图形平滑容易制造确定感，原始点和误差条不可省略。 **反例：准确率突然上升.**

某任务从25%跳到50%，可能只有四道题中的一道翻转，或答案抽取在大模型上更稳定。检查题目数、逐题margin和解析失败率，才能判断。小基准的百分点曲线特别容易夸大涌现。 扩大题库或使用概率指标会平滑部分跳跃。若底层margin也突然改变，再研究机制。视觉拐点只是提出问题，不是答案。 **反例：总体误差很小.** 平均预测误差2点可能由多数简单任务误差0.5点和少数关键任务误差10点组成。总体平均无法支持关键任务预算。按随机区、转折区、饱和区和任务类型分层报告。 决策加权误差比无权平均更重要。若失败集中在会影响发布的任务，方法实用性有限。公开最差案例能帮助定义使用边界。 **反例：差值预测正确.**

预测A比B高2点且真实如此，可能两条绝对预测都偏10点。排序决策成功，但模型机制仍错。下一次门槛决策会失败。绝对与相对误差都要检查。 相反，绝对预测各自准确、微小差值符号错，可能因方案几乎等效。定义实际重要阈值，避免把无意义排序错误算成严重失败。评估指标需对应用途。 **反例：一次目标命中.** 一次大模型结果落入区间，可能因区间过宽或偶然。历史多次预测的覆盖率、宽度和决策后悔共同评价。每次揭晓后不能重新调整旧区间。 冻结预测、时间戳和版本哈希防止事后修饰。长期记录成功与失败，才知道方法在新项目上的可信度。单个案例适合展示流程，无法证明普遍准确。 **证据边界.**

Model Ladders能在固定模型族、数据路径、优化规则和评测协议下，用较小实验估计目标表现。留出回测、独立run和目标命中增强证据。它预测经验轨迹，不证明参数规模本身造成能力，也不保证配方改变后仍有效。 当目标超出设计空间、任务点未覆盖转折、架构或数据发生重大变化时，区间应扩大或重新建梯。最有价值的输出包括预测、风险和需要追加哪一个实验，而不只是一个看似精确的终点数字。 **预测分布的两层积分.** 两阶段模型的目标准确率分布可写成 $p(A_*|\mathcal D)=\int p(A_*|L_*,\phi)p(L_*|C_*,\psi)p(\phi,\psi|\mathcal D)dL_*d\phi d\psi$。其中 $\psi$ 是规模到loss参数，$\phi$ 是loss到准确率参数。只把预测loss均值代入第二阶段，会忽略非线性与方差。

蒙特卡洛实现很直接：每次抽一组两阶段参数和目标loss，再计算准确率，最终样本给出均值、分位数与达标概率。若两阶段使用同一题目与run，参数可能相关，独立拟合后简单相乘会低估或高估不确定性；联合bootstrap可保留依赖。 **非线性中的均值偏差.** 对非线性映射 $g$，一般有 $E[g(L)]\neq g(E[L])$。目标loss在Logistic转折区存在方差时，将均值直接代入可能产生明显偏差。二阶Delta展开给出近似 $E[g(L)]\approx g(\mu)+\frac12g''(\mu)\sigma^2$。 转折点两侧曲率符号不同，偏差方向也不同。使用完整预测分布自然处理；只报告点预测则至少进行曲率敏感性分析。这是两阶段误差传播中容易被忽略的一步。 **协方差的重要性.**

同一训练run上的多个任务loss共享优化噪声，任务预测之间相关。计算「所有关键任务同时达标」时，不能把边际概率相乘。正相关意味着共同好坏run更常见，负相关则反映能力权衡。 多任务bootstrap用同一次run和题目重采样生成联合预测，可估计协方差。决策者可以计算联合约束概率、最差任务分布和效用，而非分别看多个区间后凭直觉组合。 **题目抽样与目标固定.** 若目标是预测固定公开基准的最终分数，题目集合不随机，主要不确定性来自训练与模型拟合；若目标是泛化到同类未来题，题目抽样方差必须包含。两种预测区间含义不同。

固定基准预测适合资源规划，分布预测更适合能力声明。可以同时报告条件于当前题集的区间与对潜在题目总体的区间。后者通常更宽，也更诚实地反映部署不确定性。 **测量误差回归.** 阶梯横轴计算量和纵轴任务loss都可能有测量误差。普通回归把横轴当精确，误差会使斜率偏向零。若有效token或FLOPs估计误差不可忽略，可用errors-in-variables模型或为坐标设置分布。 更实际的做法是先改善计量：从训练日志获得有效token，用统一公式算FLOPs，逐题保存loss。测量误差模型无法补救含义不一致的横轴。高质量阶梯首先是一套计量纪律。 **约束拟合.**

规模增加时经验loss通常非增，准确率映射也期望随loss下降而非降。给参数施加符号和范围约束能避免小样本产生荒谬外推，如负下界或准确率超过1。约束来自问题结构，不等于任意裁剪。 如果无约束数据明显违反单调，先调查训练异常、协议和真实非单调，再决定模型。强行约束会掩盖负迁移或优化不稳。报告约束边界是否被触及，能看出数据对参数支持是否充分。 **训练曲线的暂态.** 同一run中loss可能因warmup、数据阶段切换和退火出现暂态。把所有checkpoint放入单一幂律，会将时间动力学当成规模规律。应只比较可对齐阶段，或加入学习率进度和阶段变量。

目标终点通常经过退火，小代理中间点若未退火，其loss系统偏高。可以为每个预算训练独立退火run，成本更高但语义一致；也可建立退火增量模型并验证。两种设置不可静默混用。 **冷启动与warm-start.** 较大阶梯点若从较小模型继续扩展或继承权重，而目标从头训练，优化路径不同。warm-start节省成本，却不再纯粹测同一训练配方。网络变形、优化器重置和数据重复都会影响。 可靠阶梯通常各规模独立初始化，或让目标采用同样的渐进训练路线。若使用warm-start，应至少与少量从头点对照，估计路径偏差。节省代理成本不能以破坏外推对象为代价。 **任务天花板的样本误差.**

强模型在小基准上满分，不表示真实上限为1。有限样本未包含足够难例，Logistic上限估计会贴边。新增困难题后映射可能整体改变。使用更宽题库或难度分层，能延缓饱和。 满分任务对继续缩放几乎没有信息，应从决策平均中区别处理。若产品要求保持满分，仍需未见变体检查。观测饱和与能力完备是两回事。 **随机区的假提升.** K选一任务中，小模型准确率略高于 $1/K$，可能来自标签频率、格式启发式或抽样波动。用任务loss和margin检查，若正确选项没有概率优势，准确率差不具备稳定信号。 标签置换与仅模板基线能测启发式。阶梯起点若由表面偏置支撑，S形映射会错误定位转折。随机区数据适合约束下限，不适合估计能力斜率。 **指标解析造成的伪拐点.**

小模型常输出冗长或无效格式，抽取器判错；规模增大后遵循格式，准确率突然上升。底层答案概率可能早已平滑改善。解析成功率和人工可恢复正确率应单独画曲线。 若研究目标是端到端使用，格式拐点仍是真实行为变化；若声称推理能力涌现，则需排除接口因素。任务loss提供连续线索，不能代替错误分类。 **规模外推与分布外推.** 目标规模更大属于设计变量外推，目标任务或数据也改变则叠加分布外推。两种风险相乘，旧区间不会自动覆盖。应分别做新任务小规模校准与旧任务目标规模预测。

若预算只允许一种，优先在最影响决策的维度靠近目标。新架构新数据新任务同时出现时，Model Ladders只能提供宽先验，不能承担精细预测。重新建梯往往更便宜于错误大训练。 **反事实预算比较.** 阶梯本身消耗计算，判断其价值要与替代方案比较：直接训练目标、只做单点小模型、或先训练中等模型。计算节省不仅看阶梯占目标百分比，还看它减少多少失败目标run。 若团队无论预测如何都必须训练目标，阶梯价值主要在配方选择和风险管理；若预测可取消项目，价值更高。成本效益依赖决策权限，不能用统一百分比概括。 **预测的可行动性.**

一个区间若太宽，可能仍能排除明显失败方案；一个点预测很准，却在所有候选间给不出区分，也无决策价值。评估应包含实际选择、节省成本与后悔值，而非只用均方误差。 每次预测前写下可能动作：继续、停止、换配方或补哪个点。结果揭晓后检查是否会改变正确决策。这样模型阶梯成为实验策略的一部分，而非训练完成后的拟合展示。 **数据决策中的多目标约束.** 数据配方可能同时影响知识、推理、安全和多语言。为每项目标建阶梯后，可求在关键能力不低于门槛下最大化主效用的方案。门槛区间应考虑预测不确定性，例如要求置信下界达标。

任务很多时联合概率可能很低，过度保守。按风险分级：安全硬约束用下界，普通能力用期望或软惩罚。权重和阈值由应用决定，预测系统负责给出透明分布。 **数据差值的归因边界.** 方案A与B仅数据混合不同且训练其余条件固定，差值外推支持配方关联。要进一步说某个具体来源造成提升，需要单来源消融，因为混合变化可能同时改变重复、质量与长度。 小阶梯帮助选择，不自动分解数据内部机制。来源级loss、梯度和样本审查提供假设，受控替换实验提供因果证据。决策正确与科学解释完整是两个标准。 **结果揭晓后的更新.**

目标大模型完成后，将真实loss、准确率与训练轨迹加入历史库。更新可修正先验、方差函数和常见结构误差，但不能修改已冻结预测再声称命中。原预测、更新后模型和差异原因同时保留。 下一项目若架构相近，可借用历史；差异大则降低权重。持续校准让系统随团队配方演进，又避免把一次成功固化成普遍定律。失败预测往往提供最有价值的模型修正信息。 **一份完整的冻结预测.** 冻结产物包含阶梯run与数据、规模变量、任务协议、两阶段函数、拟合代码、参数与协方差、结构情景、目标点预测区间、达标概率和决策规则。时间戳应早于目标结果访问。

图表之外保留逐题loss和检查点元数据，便于误差分解。若配方在目标训练中改变，记录变化并将预测标记为失配，而非把偏差归给方法。这样的预测即使未命中，也能被复盘。 **最终边界.** 阶梯能够压缩大规模决策的不确定性，前提是代理点与目标共享同一生成机制，且观测覆盖足以识别曲线。它无法消除未知架构交互、数据漂移和评测变化，也无法用统计拟合替代最终大模型证据。 把预测区间、外推距离、回测覆盖与可行动决策一起报告，才能判断一次模型阶梯是否值得信任。最危险的用法是只保留拟合均值，把宽区间和失败情景省略；最可靠的用法则允许结论是「现有代理不足，需要补一个更接近目标的点」。
