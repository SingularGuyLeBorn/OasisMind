# Olmo Hybrid: 把 SWA 换成 GDN, 从表达力一路推到 token 效率

Olmo Hybrid 的 70 页报告为 arXiv:2604.03444v4, 对照译稿见 `olmo-hybrid-bi.md`. 数字取自报告 Tab. 1–22, Fig. 1–21 与正文各节, 正文与表格不一致处采用表格口径并注明; 标为「心算」或「解读」的内容是估算或推断. 直接前作见 [Olmo 3 解读](../olmo-3/olmo-3-analysis.md).

## 1. 定位与机制

### 1.1. 谱系坐标: 同数据, 同配方, 只换一类层

Olmo 3 7B 本身已经是一种混合注意力: 3/4 的层是窗口 4096 的 SWA, 1/4 是全局注意力. Olmo Hybrid 的改动就落在这 3/4 上: 把每个 SWA 层整层换成 **Gated DeltaNet (GDN)** 层, 每个注意力头换成一个 GDN 头, 全局注意力层原样保留, 得到 GDN : 注意力 = 3:1 的交错结构. 旧分工是 「局部窗口 + 全局注意力」, 新分工变成 「循环状态 + 全局注意力」. 这里的 Hybrid 指层类型交错, 与 MoE 无关, Olmo Hybrid 是 7B 稠密模型, FFN 一层都没动.

它要回答的问题在 Introduction 里说得很直白. Mamba-2-Hybrid, Samba, Nemotron-H, Qwen3-Next, Kimi Linear, Qwen 3.5 等混合模型已经做到 9B 激活参数, 36T token 的规模, 但每一家的数据, 配方和评测都不同, 谁也说不清收益来自架构还是来自数据. Olmo Hybrid 的定位因此更接近一件实验器材: 架构之外尽量照抄 Olmo 3 7B, 让 「换层」 成为主要变量. 发布物包括权重, 与 Olmo 3 对照的训练日志, 以及 OLMo-core 里五个阶段的训练脚本.

三组数字概括了主要结果. Fig. 1 中, 达到 Olmo 3 7B 的 Common Crawl loss 少用 35% token, 达到相同 MMLU 准确率少用 49% token, FLOPs 同比例节省. Tab. 2 显示 midtraining 后 OlmoBaseEval 的五个聚合域全部超过 Olmo 3. Tab. 3 中, 长上下文扩展后的 RULER 64K 从 Olmo 3 的 70.9 升到 85.0. 论文把表达力证明, 受控 Scaling 实验和 7B 训练结果连成一条证据链, 再用理论模型解释数据效率差异.

「只换一类层」 是近似成立. 附录 A.1 列了三处偏离: 学习率从 Olmo 3 7B 的分段日程改为余弦衰减到峰值的 10%; 数据换成 Olmo 3 32B 的改进配比, 作者称早期用 7B 配比时趋势相近; 训练用 512 张 GPU, 前半段是 H100, 约一半时迁到 B200. GDN 与 3:1 的比例是在 1B 参数, 100B token 的早期实验里定下的, §5.1 的消融是事后按受控口径复现. midtraining 又把 batch 翻倍, 依据是 Merrill et al. (2025) 对学习率与 batch 关系的新理解. 读对照结论时, 这些偏离都要一起带上.

### 1.2. 一个 GDN 头在做什么: delta 规则, 衰减门与负特征值

Definition 1 给出状态更新: $\mathbf{S}_t = \mathbf{S}_{t-1}\alpha_t(\mathbf{I}-2\beta_t\mathbf{k}_t\mathbf{k}_t^\top)+\mathbf{v}_t\mathbf{k}_t^\top$, 输出 $\mathbf{y}_t=\mathbf{S}_t\mathbf{q}_t$, 其中 $\|\mathbf{k}_t\|=1$, $\alpha_t,\beta_t\in(0,1)$, value 与状态的行数是 key 维度的 2 倍. 可以把 $\mathbf{S}$ 看成一块以 key 为地址, value 为内容的联想记忆: 右乘 $(\mathbf{I}-2\beta_t\mathbf{k}_t\mathbf{k}_t^\top)$ 先改写旧记忆里沿 $\mathbf{k}_t$ 方向的那一份, 再加上 $\mathbf{v}_t\mathbf{k}_t^\top$ 写入新内容, $\alpha_t$ 让整块记忆按门控衰减. 普通线性注意力只会不断累加, 写满后新旧内容互相干扰, **delta 规则**的 「先擦后写」 缓解了这个问题. 线性注意力与 delta 规则的背景见 [2.5.1-线性注意力机制](../../../llm-guide/2-核心原理与架构/2.5-线性注意力与状态空间模型/2.5.1-线性注意力机制/2.5.1-线性注意力机制.md).

「先擦后写」 可以落到一次读出上. 由 $\|\mathbf{k}_t\|=1$ 得 $(\mathbf{I}-2\beta_t\mathbf{k}_t\mathbf{k}_t^\top)\mathbf{k}_t=(1-2\beta_t)\mathbf{k}_t$, 用当前 key 去读更新后的状态:

$$\mathbf{S}_t\mathbf{k}_t=\alpha_t(1-2\beta_t)\,\mathbf{S}_{t-1}\mathbf{k}_t+\mathbf{v}_t$$

而对任意与 $\mathbf{k}_t$ 正交的方向 $\mathbf{u}$, 有 $\mathbf{S}_t\mathbf{u}=\alpha_t\mathbf{S}_{t-1}\mathbf{u}$ (按 Definition 1 推). 第一式说, 在当前 key 这个地址上, 旧内容先乘 $\alpha_t(1-2\beta_t)$ 再叠上新 value; 第二式说, 其余地址只受衰减门影响, 这次写入碰不到它们. 普通线性注意力 $\mathbf{S}_t=\mathbf{S}_{t-1}+\mathbf{v}_t\mathbf{k}_t^\top$ 的读出是 $\mathbf{S}_{t-1}\mathbf{k}_t+\mathbf{v}_t$, 旧内容原样留着与新内容相加, 两者的差别就在 $\mathbf{S}_{t-1}\mathbf{k}_t$ 前面那个系数. 转移矩阵 $\alpha_t(\mathbf{I}-2\beta_t\mathbf{k}_t\mathbf{k}_t^\top)$ 的特征值因此只有两种: 沿 $\mathbf{k}_t$ 为 $\alpha_t(1-2\beta_t)$, 其余 $d-1$ 个方向为 $\alpha_t$. $\beta_t\in(0,1)$ 时 $1-2\beta_t\in(-1,1)$, **$\beta_t>1/2$ 就进入负半轴**; 原版 GDN 对应的是 $\alpha_t(1-\beta_t)$, 永远在 $(0,1)$ 里.

谱系上这是三步叠加. DeltaNet (Schlag et al., 2021) 提供 Householder 式的 delta 规则; GDN (Yang et al., 2025a) 加上**衰减门** $\alpha_t$; Grazzi et al. (2025) 把 $\beta_t$ 换成 $2\beta_t$, 让沿 key 方向的特征值从 (0, 1) 扩到 (-1, 1). 最后一步只改了一个系数. Definition 1 里 $\alpha_t,\beta_t$ 都在开区间, -1 只能逼近, Fig. 6 的交换矩阵对应 $\alpha_t=1$, $\beta_t=1$ 这个端点. 同属 DeltaNet 家族的 KDA 见 [01-Kimi-Delta-Attention-KDA](../../../llm-guide/2-核心原理与架构/2.5-线性注意力与状态空间模型/2.5.1-线性注意力机制/01-Kimi-Delta-Attention-KDA/01-Kimi-Delta-Attention-KDA.md).

Fig. 6 用一个二维例子说明**负特征值**的作用. 取 $\mathbf{k}_t=(1,-1)/\sqrt2$, 不扩展时 $\mathbf{I}-\mathbf{k}_t\mathbf{k}_t^\top$ 的特征值是 1 和 0, 状态只能保持或衰减; 扩展后 $\mathbf{I}-2\mathbf{k}_t\mathbf{k}_t^\top$ 恰好是**交换矩阵**, 特征值 1 和 -1, 能把状态在两个值之间来回翻转. 奇偶校验, 五元素换位这类问题都依赖这种翻转. 作者特别指出, Qwen3-Next, Kimi Linear, Qwen 3.5 用的 GDN 都没有这条扩展, Olmo Hybrid 在大规模训练里保留了它.

GDN 头接进 Transformer 几乎不需要额外结构: 输入仍是标准的 q / k / v 投影, 输出 $\mathbf{y}_t$ 当作单头输出按头拼回. 附录 A.1 补充, 实现用 Flash Linear Attention, q / k / v 上各有一个核长 4 的短深度卷积, 层内参数按 FLA 单层实例化的默认值初始化. 头尺寸按注意力头成比例折算: $d_k=3/4\cdot128=$ 96, $d_v=2d_k=$ 192, 这也是 FLA 里从注意力换到 GDN 的常用映射.

### 1.3. 形状配平, 推理状态与生成吞吐

GDN 的 value 更长, 计算 $\beta_t$ 还要少量额外参数, 同样超参下参数会变多. 作者在 128 张 H100 上逐个去头测参数与吞吐 (Tab. 9): Olmo 3 为 6.8B, 每卡 8.0K token/s; 混合模型 32 头时 7.7B / 7.7K, 31 头 7.4B / 7.7K, 30 头 ($d_{model}$ = 3840) 7.0B / 8.2K. 最终选 30 头, 参数多 0.2B, 吞吐略快, 两者在训练算力口径上基本持平.

Tab. 1 在 fp16 下比较单层推理状态. 32K 序列, 32 个 KV 头, $d_h=128$ 的 MHA 占 512 MiB, 是 GDN 的 485×; 8 个 KV 头的 GQA 占 128 MiB (121×); 窗口 4096, 8 个 KV 头的 GQA-SWA 占 16.0 MiB (15.2×); Olmo Hybrid 的 GDN 层 (30 头, $d_k$=96, $d_v$=192) 只有约 0.55M 个元素, 1.05 MiB, 且与序列长度无关. Olmo 3 7B 实际使用 MHA, 其 SWA 层按 32 个 KV 头计算约占 64 MiB, 大约是 GDN 的 61 倍 ($4096 \times 32 \times 128 \times 2 \times 2$ 字节). GQA 背景见 [03-GQA-在性能与缓存之间折中](../../../llm-guide/2-核心原理与架构/2.2-注意力机制/2.2.2-多头注意力变体/02-MQA与GQA-共享KeyValue头/02-MQA与GQA-共享KeyValue头.md).

放到整个模型上, 收益会被全局层稀释. 每四层里 Olmo 3 是一层全局加三层 SWA, Hybrid 是一层全局加三层 GDN; 全局层两者相同, 缓存都随序列线性增长. 按位置折算, 32K 时 Hybrid 的总推理状态约为 Olmo 3 7B 的 73%, 64K 时约 85% (心算: GDN 一层约合 67 个位置的 MHA 缓存). SWA 层的缓存本来就被窗口封顶, 换成 GDN 省下的是常数项, 长序列上占大头的仍是那 1/4 全局层. 报告没有给整模型显存的实测, 这组比例只按结构推算.

生成吞吐的实测在 Tab. 8 (8×A100, 2,048 token 提示, TP=2). 不开 eager 模式时, Hybrid 在 4K 为每节点 3,077 token/s, Olmo 3 为 2,164; 32K 为 1,422 对 1,247. 服务 1,024 条并发 rollout 所需的最少 GPU, 32K 时是 64 对 96, 4K 时是 16 对 48. 作者把优势归于 GDN 缓解了 MHA 的 KV 缓存压力. 按 1,684 步 (1,725,440 个 episode) 估算, 32K 下 Hybrid 需 44.2K GPU 小时, Olmo 3 需 73.8K.

问题出在数值稳定. 后训练模型在 vLLM 上必须开 `--enforce-eager` (关闭 torch 编译) 与 `--disable-cascade-attn`, 否则分数骤降. 作者推测编译带来的细微数值差会**沿 GDN 的循环状态逐步累积**, 注意力层没有这种累积; 佐证是保留编译, 但用 `--mamba_ssm_cache_dtype float32` 把 GDN 缓存存成 FP32, 分数就能恢复. 开 eager 后 Hybrid 在 32K 掉到 1,066 token/s, GPU 小时估算升到 58.9K, 仍低于 Olmo 3. 正文引用的吞吐 (如 4K 3,023, eager 32K 654) 与 Tab. 8 表内值不一致, 正文还把吞吐表误称为 Table 7; 脚注称后续 vLLM 改进已收回 eager 模式下的大部分差距.

## 2. 表达力理论

### 2.1. 为什么需要混合: 状态追踪与召回各缺一块

§3 的出发点是 Merrill (2025) 的 **Expressivity Thesis**: 在可训练, 可并行的前提下, 架构应尽量能表示更多自然出现的计算问题. 作者把它与 Bitter Lesson 并列, 并与经典的偏差-方差权衡对照, 理由是深度学习自带偏向简单解的隐式偏置, 表达力高不必然过拟合. 表达力也不能无限加: 要求表示 P 类全部问题, 在 $\mathsf{NC}\neq\mathsf{P}$ 的假设下就无法沿长序列并行. 目标因此是推进 「表达力-并行度」 的前沿.

Transformer 这一侧的上界是 $\mathsf{TC}^0$ (Merrill and Sabharwal, 2023; Chiang, 2025). 在 $\mathsf{TC}^0\neq\mathsf{NC}^1$ 的标准猜想下, 固定深度的 Transformer 无法对任意长度做状态追踪, 也就是把一串可结合的操作依次作用到有限状态上. 国际象棋走子, 五个物体反复换位都是例子, 最难的情形是 $\mathsf{NC}^1$ 完全. 直观原因是注意力对操作序列的聚合对顺序不够敏感, 想逐步施加更新, 层数就得随序列长度增长. Fig. 4 左把它写成代码: 连续执行 n 行 `a, c = c, e` 这类交换, 最后问 `a` 的值.

线性 RNN 这一侧恰好相反. 转移矩阵为对角或非负的模型 (线性注意力, S4, Mamba) 同样被压在 $\mathsf{TC}^0$; 非对角, 随输入变化且允许负特征值的转移矩阵可以表达 $\mathsf{NC}^1$ 完全的状态追踪, DeltaNet / GDN, RWKV-7, PD-SSM 都走这条路. Mamba 与 SSM 的背景见 [2.5.3-Mamba系列](../../../llm-guide/2-核心原理与架构/2.5-线性注意力与状态空间模型/2.5.3-Mamba系列/2.5.3-Mamba系列.md) 与 [2.5.2-状态空间模型SSM](../../../llm-guide/2-核心原理与架构/2.5-线性注意力与状态空间模型/2.5.2-状态空间模型SSM/2.5.2-状态空间模型SSM.md).

RNN 的代价是有界状态带来的**召回瓶颈**. Fig. 4 右的 `bits[a]` 查询要从上下文里取回任意一位, 状态大小固定的 RNN 在比特数 m 增长后必然失败 (Arora et al., 2024b; Jelassi et al., 2024); Arora et al. (2024a) 甚至认为线性 RNN 相对 Transformer 的大部分 loss 差距都来自上下文召回. 注意力擅长召回而不擅长状态追踪, 带负特征值的 GDN 正好相反, 混合是自然的选择. 更早的混合路线如 Griffin 见 [2.5.4-线性RNN与Griffin](../../../llm-guide/2-核心原理与架构/2.5-线性注意力与状态空间模型/2.5.4-线性RNN与Griffin/2.5.4-线性RNN与Griffin.md), 全景见 [2.5.5-混合架构](../../../llm-guide/2-核心原理与架构/2.5-线性注意力与状态空间模型/2.5.5-混合架构/2.5.5-混合架构.md).

### 2.2. 混合比两者之和多出什么: 状态召回与 padding 下的 NC¹

§3.3 要证明的是: 混合不只是把两边能力并在一起. Definition 2 定义**状态召回**任务: 输入比特串 $x$, 五个指针 $p_1..p_5$, 一串作用在 [1, 5] 上的换位 $\pi_1..\pi_n$, 输出 $x_{q_1}$, 其中 $q$ 是换位复合后的指针位置. Fig. 5 的代码版本是: 给五个变量赋下标, 做 n 行交换, 再用 `bits[a]` 取值. 这个任务同时需要状态追踪 (算出换位后 `a` 指向哪里) 与召回 (取出那一位).

**Theorem 1** 说, 一个带负特征值 GDN 与平均硬注意力的混合模型, 只需一次层类型交替, 顺序任意, 就能解状态召回; 而在标准猜想下, 任何 Transformer 或 RNN 都表示不了. 两种构造分别是 「先用 GDN 复合换位, 再用注意力取值」 与 「先用注意力取出五个指针处的比特, 再用 GDN 复合换位」. 后一种构造说明, 注意力放在 GDN 前面也行, 只要两类层都在.

两种构造各用到什么, 可以一步步写出来. GDN 在前时, 五个指针先读进残差流; 每个换位都能写成 「单位阵加秩 1」, 正是 GDN 转移矩阵的形状: 取 $\mathbf{k}=(\mathbf{e}_i-\mathbf{e}_j)/\sqrt2$, $\mathbf{I}-2\mathbf{k}\mathbf{k}^\top$ 就是交换第 $i$, $j$ 两个坐标的置换矩阵, Fig. 6 是 $i=1$, $j=2$ 的二维特例 (这一步按 Fig. 6 推广). 换位复合完, 注意力层用 layer norm 把 $p_1$ 投到单位球上得 $\phi(p_1)$, 每个比特位置用 NoPE 的标准技巧算出 $\phi(i)$, 再以 $\phi(p_1)$ 为 query, $\phi(i)$ 为 key, $x_i$ 为 value; 两个单位向量的点积恰在 $i=p_1$ 时最大, 取回的就是 $x_{p_1}$. 注意力在前时顺序反过来: 先用一个平均硬注意力块算出每个指针的 $\phi(p_k)$, 再用 5 个头分别取回 $x_{p_1},\dots,x_{p_5}$, 最后由 GDN 对这五个值而不是对指针做换位复合.

定理的条件要和结论一起读. 注意力一侧假设的是**平均硬注意力** (AHAT): 权重均匀分给所有使分数最大的位置, 不是 softmax. 注意力在前的构造依赖 AHAT, 并要求指针用一元编码; GDN 在前的构造对二进制编码的指针, 以及只看唯一最大位置的 UHAT 也成立, 所以多于一次交替时两种编码都能处理. 精度上默认对数精度, 即长度 $n$ 的输入, 内部算术只用 $O(\log n)$ 位, 脚注说 Theorem 1 在多项式精度下也成立. 反面结论分两半: Transformer 做不到依赖 $\mathsf{TC}^0\neq\mathsf{NC}^1$ (Lemma 1); 对数精度 RNN 做不到则无需猜想 (Lemma 2), 因为状态召回的通信复杂度是 $\Omega(n)$, 固定大小的状态在对数精度下只能带 $O(\log n)$ 位, 从中间把输入切开, 前半段传不过足够的信息. 定理只要求 「至少一次交替」, 对 3:1 这类比例, 注意力放在哪几层都没有说法; 比例与位置是第 4.2 节 Tab. 5 的经验结论, 不是从定理推出来的.

§3.4 把结论从单个任务推广到复杂度类. **padding token** 是追加在输入后的空白位置, 用来扩大计算图而不加参数. **Theorem 2** (Merrill and Sabharwal, 2025) 指出, 多项式 padding 下固定深度的平均硬注意力 Transformer 恰好识别 FO-uniform $\mathsf{TC}^0$; **Theorem 3** 给出混合模型的对应结果: 多项式 padding 下可以识别 FO-uniform $\mathsf{NC}^1$ 中的任意语言. 证明借用 Barrington (1986) 的经典结论: $\mathsf{NC}^1$ 中任意问题都能经一阶公式归约为五元素换位的复合, padding 后的注意力层负责一阶归约, GDN 负责换位复合.

**Corollary 3.1** 把 Theorem 3 落到一个具体问题上: 波兰式布尔公式求值是 $\mathsf{NC}^1$ 完全的 (Buss, 1987), padding 混合模型能解, padding Transformer 与 RNN 在猜想下都不能. 作者留下两个开放问题: 多次交替是否比一次交替买到更多表达力, 以及不加 padding 的混合模型能否求值布尔公式. 不可表示的结论都可以平移到有界精度. 这些定理说的是 「能否表示」, 能否学会要靠 §3.5 的合成实验.

### 2.3. 从能表示到能学会: 合成任务里的负特征值开关

§3.5 用代码模板在线生成三类任务, 训练 Transformer, 纯 GDN 与混合三种因果语言模型, 另加去掉负特征值的线性 RNN 与混合作为消融; 状态类任务在训练数据里插入 assert 形式的中间检查, 按 Siems et al. (2026) 的做法计入语言建模损失. 状态追踪上 (Tab. 15), GDN 与混合接近满分, Transformer 随更新步数快速掉点; 去掉负特征值后, 线性 RNN 在 n = 64 / 128 时降到 0.21484 / 0.22266, 混合在 n = 128 降到 0.36328.

召回任务上格局反过来 (Tab. 16). Transformer 在 m = 128 时仍有 0.96484, 混合保持 1.00000, 线性 RNN 在 m = 64 / 128 降到 0.83203 / 0.67578; 去掉负特征值只让线性 RNN 略差 (0.80078 / 0.67188), 对混合没有影响, 与 「负特征值管状态, 不管召回」 的理论预期一致. 状态召回任务上 (Tab. 17, m = n), 带负特征值的混合在 n 从 4 到 128 全部 1.00000; n = 128 时 Transformer 0.54297, 线性 RNN 0.63672, 无负特征值的混合 0.57031.

这组实验把定理从 「能表示」 推到 「能学会」, 同时把叙事收紧了一步: **混合的组合优势依赖循环块能否取到负特征值**, 缺了这条扩展, 混合在状态召回上退回到与 Transformer 相近的水平. 这里也埋下了全文最大的张力: 第 4.2 节会看到, 在自然语言预训练的 BPB 上, 去掉负特征值几乎看不出差别.

## 3. Scaling 与理论解释

### 3.1. Scaling Laws: 七个规模, 一个稳健的系数

§4.1 的实验设计值得照搬. 三种架构 (Olmo 3 式 Transformer, 纯 GDN, 3:1 混合) 在 7 个规模 (60M, 100M, 190M, 370M, 600M, 760M, 1B) 上各训一条长跑, 用与总 token 数无关的 **WSD-S 学习率日程**, 在 0.5× 到 8× Chinchilla 最优 token (每参数 20 token) 的五个点各做一次 5% 的衰减, 一条长跑换出五个 (N, D, L) 点, 每种架构共 35 个点. 数据统一用 Olmo 3 32B 配比, loss 取 11 个留出域交叉熵的平均, 用 Huber loss 在 log L 上按 Chinchilla Approach 3 拟合 $L(N,D)=E+A/N^\alpha+B/D^\beta$, 置信区间用 1,000 次 bootstrap.

自由拟合的曲线质量都很高, Tab. 18 的 $R^2$ 为 0.9976 (Olmo 3), 0.9993 (混合), 0.9994 (纯 GDN); 指数 α / β 分别约为 0.25 / 0.21, 0.23 / 0.22, 0.18 / 0.23, 区间大面积重叠. Tab. 4 做外推验证: 混合 7B / 5.5T 预测 loss 2.14, 实测 2.14, 误差 0.28%; Olmo 3 7B 误差同为 0.28%; 远超拟合范围的 Olmo 3 32B 误差 1.69%. 由于自由拟合里五个参数一起动, 单个系数的对比没有统计意义, 作者固定 α = β = 0.22 (约为自由拟合的平均), 只重拟 E, A, B. Scaling Laws 的一般背景见 [3.3.2-Scaling-Law](../../../llm-guide/3-预训练/3.3-模型配置与Scaling-Laws/3.3.2-Scaling-Laws/3.3.2-Scaling-Laws.md).

固定指数后**只剩一个稳健信号: 数据系数 B**. Tab. 18 里混合为 83.65 (区间 [79.9, 87.0]), Olmo 3 为 94.85 ([89.3, 101.4]), 区间不重叠; 正文写作 83.7 对 94.9, 区间 [80.2, 87.1] 与 [88.7, 102.0], 与表略有出入. A 为 65.09 对 66.63, 区间重叠; E 在固定指数下反而是 Transformer 更低 (1.55 对 1.58), 作者据此判断自由拟合里混合的 E 优势是拟合伪影. 正文给的 A (70.1 对 71.8) 与 E (1.597 对 1.569) 也与 Tab. 18 不一致, 引用时以表为准.

把拟合律反解到目标 loss 2.474 (所有观测训练 loss 的最小值), 同规模混合比 Transformer 少用的 token 从 7B 的 1.68× 升到 30B 的 1.82×, 70B 的 1.89×; 纯 GDN 在小规模反而更费 token, 到 70B 才到 1.70× (Tab. 20). 区间要一起记: 7B 的 1.68× 对应 [0.91, 3.47], 70B 的 1.89× 对应 [0.71, 5.81], 下界都跨过 1. 点估计一致偏向混合, 但单点上的节省倍数不确定性很大, 且拟合范围止于 1B, 30B / 70B 都是外推.

### 3.2. 把定理接到 loss 曲线上: quantization model

§4.2 要补上一个断层: §3 的表达力是形式语言上 「能或不能」 的二值差异, Scaling Laws 描述的却是自然语言上平滑下降的 loss. 作者借用 Michaud et al. (2023) 的 **quantization model**: 语言建模由大量离散子任务组成, 子任务频率服从 $p_k\propto k^{-(\alpha+1)}$ 的幂律, 每个子任务在见够 $T_k$ 个相关 token 后可学, 学会一个要花 $C_k$ 个参数; 许多离散任务按频率依次被学会, 叠加起来就是平滑的幂律.

在此之上加三条假设. Assumption 1: 每个子任务以概率 $1-\epsilon$ 可被该架构表示, 表达力越强 $\epsilon$ 越小. Assumption 2: 学会之后, 可表示任务的 loss 降低 $\Delta$, 不可表示任务只降低 $\Delta'\le\Delta$. Assumption 3: 可表示任务需要 $C$ 个参数, $T$ 个 token, 不可表示任务只能用更大的查表去近似, 需要 $C'\ge C$, $T'\ge T$. **Theorem 4** 推出参数律系数 $A_\epsilon=(L_0-L_\infty^\epsilon)(C+\epsilon(C'-C))^\alpha$, 数据律系数 $B_\epsilon=(1-\epsilon)\Delta T^{\alpha/(\alpha+1)}+\epsilon\Delta'T'^{\alpha/(\alpha+1)}$, 不可约 loss $L_\infty^\epsilon=L_0-(1-\epsilon)\Delta-\epsilon\Delta'$; 指数只由数据分布的 α 决定, 与架构无关.

数据律里的 $T^{\alpha/(\alpha+1)}$ 从哪来, 推导可以复述. 任务 $k$ 的频率是 $p_k=k^{-(\alpha+1)}/\zeta(\alpha+1)$, $D$ 个 token 里相关的约有 $p_kD$ 个, 达到 $T$ 才可学, 所以可表示任务能学到的最大序号 $k_e\approx\big(D/(\zeta(\alpha+1)T)\big)^{1/(\alpha+1)}$; 不可表示任务的门槛换成 $T'$, 对应 $k_i\approx\big(D/(\zeta(\alpha+1)T')\big)^{1/(\alpha+1)}\le k_e$. 任务于是分成三段: $k\le k_i$ 全部学会, 平均 loss 为 $L_\infty^\epsilon$; $k_i<k\le k_e$ 只有可表示的学会, 平均 loss 为 $L_0-(1-\epsilon)\Delta$; $k>k_e$ 都没学会, loss 为 $L_0$. 幂律尾部的概率质量按 $k^{-\alpha}$ 衰减, 两个截断点各贡献一项, 代回 $k_e$, $k_i$ 得到 $(1-\epsilon)\Delta(T/D)^{\alpha/(\alpha+1)}+\epsilon\Delta'(T'/D)^{\alpha/(\alpha+1)}$, 也就是 $B_\epsilon D^{-\alpha/(\alpha+1)}$ (省去常数 $Z=\alpha\zeta(\alpha+1)^{1/(\alpha+1)}$). 参数律同理: 每个任务平均占 $C+\epsilon(C'-C)$ 个参数, $N$ 个参数约能学 $N/(C+\epsilon(C'-C))$ 个任务, 尾部同样按 $-\alpha$ 次方衰减, $A_\epsilon$ 里那个括号就是这样来的.

对 $\epsilon$ 求导能看出哪组假设对应哪种曲线. $\Delta'=\Delta$ 时, $\partial L(D)/\partial\epsilon=\frac{\Delta}{Z}\big[(T'/D)^{\alpha/(\alpha+1)}-(T/D)^{\alpha/(\alpha+1)}\big]$, 只要 $T'>T$ 就严格为正, 不可约项 $L_0-\Delta$ 却与 $\epsilon$ 无关. 同一推导还给出两条律指数的关系: 参数律是 $\alpha$, 数据律是 $\alpha/(\alpha+1)$, 后者一定更小. 第 3.1 节的自由拟合里, Olmo 3 的 0.25 / 0.21 大致符合 (心算 0.25 / 1.25 = 0.20), 混合的 0.23 / 0.22 与纯 GDN 的 0.18 / 0.23 却是数据指数不小于参数指数, 固定 α = β = 0.22 也没有遵守这个比例 (按公式对照, 报告没有讨论). 所以理论与拟合只宜在 「系数谁变」 这一层对照, 不宜逐个比指数.

**Corollary 4.1** 说, 在任何非平凡设定下, $\epsilon$ 下降都会让 L(N) 与 L(D) 逐点严格下降; **Corollary 4.2** 说, 当且仅当 $\Delta'<\Delta$ 时不可约 loss 才会下降. 与第 3.1 节的实证对照: 指数不随架构变, 与理论吻合; E 没有稳健差异, 对应 $\Delta'=\Delta$; A 差异不显著, 对应 $C'=C$; B 显著下降, 对应 $T'>T$. 最贴合数据的解读是: **不可表示的子任务最终也能学到同样好, 只是更费 token**.

作者还指出一个不那么直观的推论: 表达力上升后, 原本就可表示的任务也会学得更快, 因为不再需要为近似不可表示任务而占用的参数和数据可以挪去学别的. 他们也提醒, 这是简化模型里的概念解释, 具体系数不要过度解读. 这层理论把 「混合能表示更多问题」 翻译成了 「混合在同样 token 下 loss 更低」, 与 Fig. 1 的 35% / 49% 在方向上一致.

## 4. 7B 实跑与消融

### 4.1. 6T 实跑: 预训练, midtraining 与训练稳定性

Tab. 2 把 7B 对照按阶段排开. 预训练结束时, Hybrid 在 Math (27.0 对 23.3), MC<sub>STEM</sub> (67.4 对 64.0), MC<sub>Non-STEM</sub> (75.5 对 71.9) 上领先, 在 Code (17.1 对 19.6) 与 GenQA (66.8 对 68.5) 上落后, 留出集 LBPP 为 2.9 对 6.3. midtraining 之后五域全部反超: Math 61.2 对 59.8, Code 32.9 对 32.1, MC<sub>STEM</sub> 70.9 对 67.3, MC<sub>Non-STEM</sub> 81.3 对 78.2, GenQA 73.6 对 71.3; 留出集 MMLU Pro 43.1 对 36.6, BBH 68.6 对 65.9, LBPP (17.7 对 17.8) 与 DM Math (23.7 对 23.8) 基本持平.

代码与生成式问答在预训练后落后, 经 midtraining 翻转, 一种解读是: 两者依赖精确复制与长程引用, 更吃召回, 而 3/4 层换成有界状态后召回能力被削弱; midtraining 集中投放代码与问答数据后, 模型学会更有效地利用剩下的全局层. 报告没有针对这一点的实验, 这只是按第 2.1 节的召回瓶颈做的推断. 长上下文扩展后 (Tab. 2 的 LC 行), 两者的 Math 都从 midtraining 的高点回落 (Hybrid 61.2 → 55.1, Olmo 3 59.8 → 54.6), 差距缩小, 其余各域的领先大体保留, 正文所说的 MMLU Pro +4.5 对应的就是 LC 行的 41.7 对 37.2.

midtraining 的做法基本照搬 Olmo 3 32B: 用轻度过滤后的 Dolma 3 Dolmino Mix, 在两份不同的 100B token 子集上各跑一次再合并权重, batch 翻倍. 附录 Fig. 15 另有六个下游基准的预训练效率曲线. Fig. 1 的 49% MMLU token 节省, 与 midtraining 后 MMLU Pro 的 6.5 分优势方向一致, 知识类任务是这次换层最稳定的受益者, 后训练阶段也会看到同样的模式.

训练稳定性是另一项副产品. 附录 A.1 定义 **spike score** 为梯度 L2 范数序列里偏离最近 128 步滚动均值超过 6 个标准差的点所占百分比. Fig. 13 显示 Olmo 3 的 spike score 随训练持续上升, Olmo Hybrid 则低而平. 作者只把它称为初步证据, 认为混合架构可能更耐大学习率与噪声数据; §4.3 也承认稳定性可能是性能收益的另一个来源, 不能全部记在表达力名下. 这削弱了 「收益全来自表达力」 的解释, 却让混合架构在工程上更有吸引力.

### 4.2. 消融: 选 GDN, 选交错, 选 3:1

§5.1 沿用第 3.1 节的受控设置, 七个规模都训到 8× Chinchilla, 用 OlmoBaseEval Easy 的 Math / Code / QA 平均 BPB 打分, 越低越好 (Tab. 5). 线性组件上, 1B 时 Transformer 0.682, 纯 GDN 0.677, 纯 Mamba2 0.718; 3:1 混合里 GDN 版 0.669, Mamba2 版 0.698. 纯 GDN 在各规模都优于 Transformer (760M 为 0.722 对 0.747), 混合 Mamba2 在多数规模超过 Transformer, 到 1B 反而落后. Mamba2 按 GLU 形式本不带 MLP, 但去掉 MLP 效果更差, 消融里给它保留了与 GDN 相同的逐位 MLP. 作者提醒同名规模下各架构实际参数量不同 (Tab. 22), 逐规模比较要谨慎.

注意力放在哪里, 放多少, 结论同样清楚. 同为 3:1, 每 4 层放一个注意力的交错式在 1B 为 0.669, 把注意力集中在中段 (末层再补一个) 的中置式为 0.672, 差距随规模拉大. 作者的解释有两条: 交错让每一段网络都能接触全局上下文, 中置则形成信息瓶颈; 交错也把层类型交替次数拉到最多, 对应 Theorem 1 暗示的多轮 「追踪-召回」 组合. 比例上, 7:1 在 60M–190M 最好或持平, 到 600M–1B 被 3:1 反超; 1:1 小规模相当, 大规模吃亏, 多出来的注意力算力换不回收益. 三种比例在大规模都明显好于 Transformer, **混不混比具体比例更关键**.

门控与特征值符号的消融和第 2.3 节形成张力. 纯 GDN 去掉输出门一致变差, 说明门是有用组件; 但正特征值加门在若干规模与负特征值加门持平甚至略好 (1B 为 0.674 对 0.677). 3:1 混合里四种组合差距都在约 0.01 BPB 以内, 1B 时负特征值无门 0.666, 正特征值有门 0.667, 都略低于选定配置的 0.669. 作者以 「整体略好」 保留负特征值加门的默认, §4.3 也承认去掉负特征值后的 Scaling 趋势与原版很接近, 「可能与理论不一致」. 合成任务上的开关效应, 在预训练 BPB 上几乎消失, **这是理论反馈循环里最薄的一环**.

一种可能的调和是: 自然语言里需要长程精确状态追踪的子任务频率很低, 按第 3.2 节的 quantization model, 它们对平均 loss 的贡献排在幂律尾部, 7B 与 6T 的尺度还没学到那里. 这个说法与 Theorem 4 相容, 但报告没有验证, 属于解读. 对使用者而言, 更稳妥的结论是: GDN 与交错式 3:1 的收益在消融里稳定可见, 负特征值的收益主要体现在合成任务上.

### 4.3. 长上下文: DroPE 为什么更适合混合模型

长上下文扩展在 100B token 的 Dolma 3 Longmino Mix 上进行, 比较两种位置策略. YaRN 沿用 Olmo 3: 按频率切分 RoPE 维度, 低频维度插值到目标长度, 高频维度保持, 再用注意力温度修正 logit 幅度的偏移. **DroPE** (Gelberg et al., 2025) 在 midtraining 之后整个去掉 RoPE, 只靠因果掩码和权重里已有的位置信号, 目的是摆脱短上下文下学到的旋转频率对外推的限制. YaRN 见 [03-长度外推：从PI到YaRN的频率扩展](../../../llm-guide/2-核心原理与架构/2.1-深度学习基础组件/2.1.4-位置编码/02-RoPE扩展-长上下文,多模态与工程实现/02-RoPE扩展-长上下文,多模态与工程实现.md), 长上下文总览见 [2.7-长上下文与外推技术](../../../llm-guide/2-核心原理与架构/2.7-长上下文与外推技术/2.7-长上下文与外推技术.md).

Tab. 3 的 RULER 读数把两种方法分开. Olmo 3 7B + YaRN 从 4K 到 64K 为 95.8 / 89.3 / 83.2 / 78.9 / 70.9; Olmo Hybrid + YaRN 为 92.8 / 91.3 / 90.0 / 84.7 / 76.9; Olmo Hybrid + DroPE 为 92.2 / 89.8 / 88.4 / 86.2 / 85.0. 4K 这种短长度上, 混合两版都比 Olmo 3 低约 3 分; 越往长走优势越大, 64K 时 DroPE 比 YaRN 高 8.1 分. 作者的解释是 GDN 的循环结构本身携带隐式位置信息, 注意力层对显式 RoPE 的依赖变小, 去掉 RoPE 损失不大, 外推约束却一并解除. 发布版因此选了 DroPE.

这和 Olmo 3 的经验可以连起来看. Olmo 3 发现 YaRN 只打在全局层上最好, 因为 SWA 层从不需要外推; 到了 Hybrid, 局部层已经换成没有位置外推问题的循环层, 剩下的全局层干脆连 RoPE 都去掉. 两代走的是同一个方向: 让负责长程依赖的层尽量不受训练长度的位置编码约束. 这是按两份报告的结论串起来的解读, Hybrid 报告没有做 「YaRN 只打全局层」 的对照.

工程上, 长序列训练需要把上下文并行接到 GDN 上. 作者实现了 **Ulysses 式上下文并行**: 用 all-to-all 把序列并行布局转成按头并行, 每张卡拿到部分头的完整序列; 注意力每个头独立, GDN 的状态更新也按头独立, 所以两类层都成立. 唯一要小心的是核长 4 的短卷积按通道沿序列作用, 卷积权重必须与头的切分一致. Tab. 11 显示 SFT 阶段也从 Olmo 3 的 Ring CP (度 8) 换成 Ulysses (度 2), 数据并行从 HSDP 换成 FSDP, 激活检查点改为预算制 0.1.

## 6. 把 GDN 递推拆开

### 6.1. 状态矩阵存的是什么

单头状态记作 $S_t\in\mathbb R^{d_v\times d_k}$, key 和 query 属于 $\mathbb R^{d_k}$, value 属于 $\mathbb R^{d_v}$. 外积 $v_tk_t^\top$ 是一个秩一矩阵. 把它写进 $S_t$ 后, 任意查询 $q$ 的读出包含

$$
(v_tk_t^\top)q=v_t(k_t^\top q). \tag{1}
$$

所以 key 与 query 的内积充当寻址权重,value 是被读出的内容. 普通线性注意力把历史所有外积相加,$S_t=\sum_{i\le t}v_ik_i^\top$,于是 $S_tq_t=\sum_i v_i(k_i^\top q_t)$. 它把 softmax 注意力的归一化权重换成核内积,并把整段历史压进固定大小的矩阵. 这带来线性时间与常数推理状态,也造成容量冲突:许多相似 key 会把 value 叠在同一方向.

GDN 在写入前对旧状态右乘

$$
H_t=\alpha_t(I-2\beta_tk_tk_t^\top). \tag{2}
$$

若 $k_t$ 已归一化,$P_t=k_tk_t^\top$ 是投影到 $k_t$ 方向的正交投影,$I-P_t$ 投影到其正交补. 因而

$$
I-2\beta_tP_t=(I-P_t)+(1-2\beta_t)P_t. \tag{3}
$$

式(3)把动作分成两个互不混合的子空间:正交方向保持,当前 key 方向乘 $1-2\beta_t$. 再乘 $\alpha_t$ 后,所有方向都衰减,当前地址额外接受一次擦除或翻转. 当 $\beta_t=0$ 时只有全局遗忘;当 $\beta_t=1/2$ 时旧状态在当前 key 方向被完全清零;当 $\beta_t=1$ 时该方向符号翻转. 训练得到的门可以在三种行为之间连续切换.

这里的「地址」只是几何方向,没有离散槽位. 若两个 key 的夹角很小,写第二个仍会改动第一个. 令 $c=k_i^\top k_t$,旧记忆 $v_i k_i^\top$ 经过一次转移后变为

$$
v_i k_i^\top(I-2\beta_tk_tk_t^\top)
=v_i(k_i^\top-2\beta_tc,k_t^\top). \tag{4}
$$

$c=0$ 时互不干扰,$|c|$ 越大干扰越强. 多头设计让不同头学习不同的地址几何,却没有取消固定状态容量. 这也是纯 GDN 在任意位置召回上输给注意力的根源:压缩发生以后,后层无法凭空恢复被相似 key 混合掉的细节.

### 6.2. 衰减门决定有效记忆长度

暂时忽略 delta 项,连续递推给出

$$
S_t=S_0\prod_{j=1}^{t}H_j+\sum_{i=1}^{t}v_ik_i^\top\prod_{j=i+1}^{t}H_j. \tag{5}
$$

每条历史写入都乘后续转移矩阵. 若只看与后续 key 近似正交的方向,其幅度大约乘 $\prod_{j=i+1}^t\alpha_j$. 当 $\alpha_j=\bar\alpha$ 时,经过$\tau$步保留比例为$\bar\alpha^\tau$. 以半衰期定义有效长度:

$$
\tau_{1/2}=\frac{\log(1/2)}{\log\bar\alpha}. \tag{6}
$$

$\bar\alpha=0.99$ 时约69步,$0.999$ 时约693步,$0.9999$ 时约6931步. 一个靠近1的小变化会把记忆尺度拉开一个数量级. GDN 让 $\alpha_t$ 随输入变化,同一头可在边界处快速遗忘、在连续段内长期保留;固定半衰期只用于建立量级直觉.

当前 key 方向的局部系数为 $\lambda_t=\alpha_t(1-2\beta_t)$. 其绝对值小于1,单步更新因而不会在该特征方向指数爆炸. 负号允许振荡,幅度仍由 $|\lambda_t|$ 控制. 长链相乘时又会遇到梯度消失:若所有 $|\lambda_t|$ 都明显小于1,早期状态对末端输出的导数按乘积缩小. 模型可以把某些 $\alpha_t$ 推近1,也可借残差连接、全局注意力层和逐层重新编码建立旁路. 「谱半径小于1」说明单个状态递推受控,没有自动保证任意长度都容易优化.

反例很简单. 让任务要求保存一个连续实数一百万步,期间 key 始终正交于该地址,且 $\alpha=0.9999$. 保留幅度约为$0.9999^{10^6}\approx e^{-100}$,实际上已经消失. GDN 的常数状态适合压缩的历史统计、有限状态变化与近期关联;逐字无损保留任意长随机串仍要依靠注意力或外部存储.

### 6.3. 负特征值为什么能做交换

取标准基 $e_i,e_j$,令 $k=(e_i-e_j)/\sqrt2$. Householder 矩阵

$$
R=I-2kk^\top \tag{7}
$$

作用在 $e_i$ 上:

$$
Re_i=e_i-(e_i-e_j)=e_j,\qquad Re_j=e_i. \tag{8}
$$

其余标准基与$k$正交,保持不变. 因而一次秩一更新精确交换两个坐标. 多个换位按时间相乘即可表示任意有限置换. 如果系数改为$I-\beta kk^\top$且$0<\beta<1$,沿$k$方向的特征值是$1-\beta>0$,它只能压缩坐标差,不能把差的符号翻转,于是无法精确交换.

端点同样要说清楚. 网络门由 sigmoid 一类映射得到时,$\alpha=1,\beta=1$只能逼近;长度固定的实验允许以足够高精度近似交换,任意长度的误差则会积累. 复杂度证明采用对数精度和适当构造,与浮点内核在数万 token 上的误差不是同一个命题. vLLM 中 FP32 状态缓存能恢复分数,恰好说明实际数值表示仍会限制递推.

## 7. 为什么保留四分之一全局注意力

### 7.1. 固定状态无法保存任意可索引历史

设输入前半段是$m$个随机比特,后半段给索引$a$,要求输出第$a$位. 一个状态含$B$比特时最多区分$2^B$种历史;所有$m$位串有$2^m$种. 当$B<m$时,抽屉原理保证至少两条不同历史映射到同一状态. 选择它们不同的位置作为查询,模型必须给出相同输出,至少一条答错. 这条通信复杂度直觉与状态矩阵用多少浮点数直接相关,也解释了增加精度只能把边界推远,不能让固定状态获得无界随机访问能力.

注意力保留每个位置的key/value,查询时才选择地址,因此空间随上下文增长. GDN先压缩再查询,空间固定. Hybrid 让三层GDN负责可压缩的状态演化,每四层用一次全局注意力重新访问原始token表征. 只要早期层仍把可查询线索留在残差流里,后续注意力便可取回具体位置,再交给下一组GDN继续计算.

这也说明全局层无法由更大的GDN状态无条件替代. 对最长上下文有上界$L$的系统,理论上可把状态扩到$O(L)$以保存全部历史,但状态交互成本随之增长,常数内存优势消失;而训练时还要学会稳定的编码与解码. 实际架构选择是在有限状态、注意力频率和计算预算之间取点.

### 7.2. 交错结构提供多轮「取回—更新」

把32层模型抽象为8组,每组含3个GDN层和1个注意力层. 第一组GDN可累计局部语法或程序状态,随后注意力按该状态从远处取证;下一组GDN把证据写进新状态,下一次注意力再根据新状态查询. 这种自适应查询需要多轮交替. 如果8个注意力层都挤在中间,前半网络只能压缩,中间一次完成多层召回,后半网络再也不能回看原文,形成结构瓶颈.

举一个两跳指针反例:输入给出「A指向位置p」,位置p又写着「去位置q」,位置q才有答案. 第一轮注意力取出p处内容,经过非线性层解析出q,第二轮注意力才能取q. 若所有注意力层连续堆叠且中间仍有MLP,理论上也可能完成多跳;但注意力组之前与之后的长段GDN不能各自发起新查询. 均匀交错为整网提供更多可用轮次. 论文的中置消融支持交错更好,却没有用探针证明模型真的按这套算法工作,这一解释仍属于机制假说.

强制末层为注意力层也有实际含义. 经过最后一组循环压缩后,末层还能依据最终问题表征直接回看全序列. 对复制代码标识符、引用人名或输出上下文中的随机值,这条路径比要求GDN一路保存字面细节更自然. 纯GDN不强制末层注意力,所以它的结果同时反映了缺少随机访问和缺少末端读取的影响.

### 7.3. 3:1 是经验折中,没有普适最优性

若总层数为$l$,注意力占比$r$,粗略的序列混合成本可写成

$$
C_{mix}\approx l\left[r(c_ad^2+c_sds)+(1-r)(c_gd^2+c_hd_kd_v)\right], \tag{9}
$$

其中$d$是模型宽度,$s$是序列长度;第一项含注意力投影和随长度增长的score/value乘法,第二项含GDN投影与状态交互. 系数取决于头数、chunk内核和硬件. $s$较大时降低$r$明显省算力,但召回带宽也下降. 1:1、3:1、7:1分别取$r=1/2,1/4,1/8$,覆盖了从频繁随机访问到强压缩三档.

小模型上7:1最好或持平,大模型上3:1反超,可以有两种互不排他的解释. 小模型的表示宽度有限,注意力层即使更多也缺少足够特征供查询,GDN的归纳偏置更划算;模型变宽后,复杂任务需要更高召回带宽,四分之一注意力开始体现价值. 另一种解释是同名规模并未严格同参数,架构公式与宽度取整改变了实际容量. 消融没有连续扫描$r$,也没覆盖超过1B的规模,所以3:1只是当前实验网格中的稳健选择.

领域也会改最优比例. 需要逐字复制、数据库式查找和长代码依赖的数据可能偏好更多注意力;语音流、时序控制或大量局部状态更新可能偏好更多GDN. 把Olmo Hybrid的3:1直接当成所有数据分布的标准配方,超出了论文证据.

## 8. 参数量、训练计算与推理内存

### 8.1. 为何 GDN 层并不天然更小

标准MHA在输入宽度$d$、Q/K/V/O都为$d$时,四个投影约$4d^2$个参数. GDN令总key宽度$k=hd_g$,value宽度$v=2k$,还需$q,k,v$投影、两个标量门投影、输出门和输出投影. 忽略偏置、卷积与归一化的小项,其序列混合部分近似

$$
N_{GDN,mix}\approx d(2k+v)+2hd+dv+vd. \tag{10}
$$

代入$v=2k$得到$N\approx8dk+2hd$. 7B配置中$h=30,d_g=96,k=2880,d=3840$,主项约$8\times3840\times2880=88.5$M;同宽注意力$4d^2\approx59.0$M. GDN省的是序列维计算和KV缓存,投影参数反而更多. 最终把32头、4096宽缩成30头、3840宽,正是为了把整模型参数与吞吐拉回Olmo 3附近.

两者都保留相同SwiGLU MLP,而大模型每层MLP通常占很大参数量. 因此换掉四分之三序列混合器只让总量从6.8B附近变到7.0B,没有按单个混合子层的比例放大. 比较时应使用实际非embedding参数和实测吞吐,不能凭「线性注意力」四个字推断参数更少.

### 8.2. 训练时线性复杂度仍有常数开销

因果MHA每token平均看$s/2$个历史位置,QK与加权V合计的MAC近似$ds$;全层还含$4d^2$投影与$3dd_{MLP}$前馈:

$$
M_{attn}\approx4d^2+ds+3dd_{MLP}. \tag{11}
$$

GDN递归每token状态交互为三次$d_k\times d_v$级运算,按头合计$3hd_g(2d_g)=6hd_g^2$,与$s$无关. 训练并不逐token串行跑递推,而使用chunk长度256的Extended WY表示. 附录把额外项写成

$$
M_{chunk}=L_c(3k+2v)+\frac{3kv}{h}. \tag{12}
$$

第一项构造块内核与局部注意力,第二项传播块间状态. 其复杂度对总序列长度仍是线性的,但$L_c=256$形成不小的常数. 在短序列或较窄模型上,投影、卷积、all-to-all与chunk准备可能盖过理论节省;Tab. 9的实测才显示30头版本略快于Olmo 3.

训练算力拟合使用$C=3FD$,其中$F$是解析前向FLOPs,$D$是token数,系数3粗略包含反向. 主文跨模型图又用$C=6ND$. 前者能区分attention、GDN和chunk开销,后者用参数量作统一启发式. 同一模型的两种估算不会完全相等;做架构消融应沿用附录细算,看跨项目量级才适合$6ND$.

### 8.3. KV cache 与 GDN state 的交叉点

一个MHA层、batch为1、上下文长度$s$、$h_{kv}$个KV头、头维$d_h$、每元素$b$字节时,

$$
M_{KV}=2sh_{kv}d_hb. \tag{13}
$$

GDN每头状态为$d_v\times d_k$,全层状态

$$
M_{state}=hd_vd_kb. \tag{14}
$$

令两者相等,交叉长度为

$$
s_*=\frac{hd_vd_k}{2h_{kv}d_h}. \tag{15}
$$

若两者头数对应,$d_k=96,d_v=192,d_h=128$,则$s_*=72$. 加上卷积缓存与门状态后会略增,量级仍只有几十到百余token. 超过这个长度,GDN状态比完整MHA缓存省;与窗口4096的SWA相比则按窗口上限比较,所以报告得到约61倍的单层差距.

整网还有四分之一全局层. 设全局注意力层数$l/4$,GDN层数$3l/4$,则上下文足够长时

$$
M_{Hybrid}\approx\frac l4M_{KV}(s)+\frac{3l}4M_{state}, \tag{16}
$$

而Olmo 3的全局与SWA组合为

$$
M_{Olmo3}\approx\frac l4M_{KV}(s)+\frac{3l}4M_{KV}(\min(s,w)). \tag{17}
$$

当$s\gg w$时,两式共同的全局项随$s$增长,比例最终趋近1. 因而Hybrid相对Olmo 3的缓存优势在中长上下文最明显,无限拉长以后反倒被共同的全局层稀释. 这与报告按结构估算的32K约73%、64K约85%方向一致.

### 8.4. Prefill 和 decode 获益不同

Attention prefill要对整段序列形成块状QK矩阵,全局层计算随$s^2$增长;GDN chunk算法随$s$线性增长. Decode阶段每次只有一个新token,attention读取不断变长的KV,GDN只更新固定状态. 两个阶段都受益,瓶颈却不同:prefill更看FLOPs与显存带宽,decode更看缓存容量、读取带宽和并发批量.

Olmo 3的SWA层decode只读取最近4096位置,本来已是常数;Hybrid把这块较大的常数换成约1MiB状态. 服务高并发rollout时,省出的缓存可容纳更多序列,吞吐增益可能主要来自batch变大,并非单条序列算术更快. Tab. 8中32K并发所需GPU从96降到64与这个机制一致. 若batch很小、上下文短,投影更宽和循环内核开销可能抵消收益.

## 9. 训练目标相同,优化路径已经改变

### 9.1. 自回归 loss 没变

预训练仍对token序列$x_{1:T}$最小化标准下一词损失:

$$
\mathcal L(\theta)=-\frac1T\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}). \tag{18}
$$

Hybrid没有额外的状态监督、重构项或路由损失. GDN状态如何分配地址、何时擦除、哪些信息交给注意力,全部由同一语言建模梯度间接学出. 合成状态任务插入assert中间检查,则是为了让优化更容易观察状态,不能当成6T自然语言训练也用了中间状态标签.

相同目标不代表相同样本对参数产生相同梯度. Transformer中位置$t$的loss可以通过注意力边直接作用到任意历史位置的key/value投影. GDN中梯度要穿过从写入时刻到$t$的转移乘积. 对某个早期状态$S_i$,

$$
\frac{\partial S_t}{\partial S_i}=\prod_{j=i+1}^{t}H_j. \tag{19}
$$

它同时编码遗忘、翻转和条件数. 全局注意力层提供较短的梯度路径,残差流又绕过序列混合器. 3:1架构因此既是前向能力组合,也是反向优化路径组合.

训练数据以固定长度打包时,文档边界尤其重要. 如果GDN状态跨两个无关文档连续传递,后一篇会继承前文压缩状态;模型只能靠边界token把$\alpha$压低或覆盖旧地址. 若实现显式reset状态,条件分布又改变. 论文沿用Olmo数据管线,正文没有把每种打包边界的状态处理单列成消融. 复现时需要从代码确认document mask、sequence packing与状态reset是否一致.

### 9.2. 头数缩减同时改变宽度和优化尺度

最终模型从32头、4096宽改到30头、3840宽. 这一步让参数与吞吐接近,也让残差宽度下降6.25%,MLP隐藏维度和每层归一化统计随之改变. 因而7B大跑并非在完全相同$d_{model}$上只替换SWA. 小规模Scaling消融按解析FLOPs拟合能缓解成本差异,实际7B对照仍混入宽度变化.

设残差向量各分量方差相近,其L2范数期望随$\sqrt d$增长. 从4096到3840会使未归一化范数约乘$\sqrt{3840/4096}=0.968$. RMSNorm消掉大部分尺度差,参数初始化、优化器二阶矩与梯度噪声仍会感受到形状变化. Tab. 9说明选择合理,没有把这项混杂因素消除.

每个GDN头的状态含$96\times192=18432$个标量,30头共552,960;头之间独立更新. MHA的每个头只缓存每个历史位置的128维K与128维V,容量随位置增长. 减少两个头对GDN状态容量是6.25%的直接削减,对注意力也减少投影子空间. 最终成绩包含「更少但更宽value状态的30头」这一具体设计,不能外推到任意头数.

### 9.3. Midtraining 的权重合并改变了比较对象

两条独立midtraining run各使用100B token子集,结束后合并checkpoint. 若简单参数平均,$\theta_m=(\theta_1+\theta_2)/2$,它依赖两条轨迹停留在相连的低loss盆地. 从同一预训练点出发、数据相近时通常比从不同初始化合并可靠. 参数平均近似抵消各自数据子集上的梯度噪声:

$$
\theta_1\approx\theta_0-\eta g_1,\quad
\theta_2\approx\theta_0-\eta g_2,\quad
\theta_m\approx\theta_0-\eta\frac{g_1+g_2}{2}. \tag{20}
$$

真实训练跨越许多步,式(20)只解释局部直觉. Hybrid与Olmo 3若都遵循相同合并流程,横向仍较公平;batch翻倍、数据用32B版轻过滤mix,则让midtraining后的领先无法纯归因于预训练架构. 最干净的架构证据仍是第4.1节的小规模受控曲线与预训练阶段的同口径指标.

长上下文扩展再训练100B token,会发生能力迁移. 表2中Math回落说明优化目标从短上下文知识任务转向Longmino以后存在代价. DroPE还直接改变全部注意力层的位置表征,短任务下降与长任务上升可以同时出现. 选择最终checkpoint时应根据目标上下文分布判断,不能把LC阶段视作无损升级.

## 10. 稳定性要分成三种问题

### 10.1. 优化尖峰

报告的spike score在梯度L2范数序列$g_t$上计算. 以此前128个值的滚动均值$\mu_t$和标准差$\sigma_t$为基准,可写成

$$
\mathrm{Spike}=\frac1T\sum_t\mathbf1\{|g_t-\mu_t|\ge6\sigma_t\}. \tag{21}
$$

六倍标准差对高斯噪声本应极罕见,深度网络梯度分布却有重尾、非平稳和数据批次变化. 滚动窗口会跟随慢趋势,主要标出瞬时异常. Olmo 3曲线上升、Hybrid低而平,说明按这个度量后者的梯度范数更平稳.

它没有测三个东西:loss是否突然升高,单层梯度是否溢出,以及同学习率下最终泛化是否更好. 全局L2范数可能掩盖少数层异常;滚动标准差在尖峰频繁后也会变大,反而降低后续命中率. 更完整的稳定性实验应同时报告loss spike、各层更新比$\|\Delta\theta_l\|/\|\theta_l\|$、梯度裁剪触发率和多随机种子崩溃率.

为何GDN可能减少优化尖峰? SWA在窗口边界突然丢掉一个位置,attention分布还会随极端logit锐化;GDN用连续门平滑更新状态,单步转移谱半径受控. 但这只是机制猜想. 模型宽度、学习率日程、数据mix与硬件迁移都不同,报告没有交换架构后逐项控制. 「Hybrid可能更耐噪」是合适强度,「GDN证明更稳定」则超过现有实验.

### 10.2. 递推数值误差

浮点实现中每步更新含舍入误差$E_t$:

$$
\widehat S_t=\widehat S_{t-1}H_t+v_tk_t^\top+E_t. \tag{22}
$$

与精确状态之差$\Delta_t$满足

$$
\Delta_t=\Delta_{t-1}H_t+E_t
=\sum_{i=1}^{t}E_i\prod_{j=i+1}^{t}H_j. \tag{23}
$$

若所有转移算子范数都严格小于$\rho<1$,误差上界约为$\max\|E_i\|/(1-\rho)$;当门长期接近1时,分母很小,许多步误差会累积. 负特征值改变符号,可能让部分误差抵消,也可能在不同融合顺序下产生不同结果. 编译器重排乘加、低精度缓存和cascade attention带来的微小差别,经过数万步递推后足以改变logit.

将mamba_ssm_cache_dtype改成FP32恢复成绩,直接指向状态存储精度. FP16单位舍入误差约$10^{-3}$量级,BF16尾数更短;FP32约$10^{-7}$. 实际误差受数值范围、累加方式和归一化控制,不能简单乘token数. 但状态越长寿,$\rho$越接近1,高精度缓存越有价值.

这类误差与训练梯度尖峰相互独立. 一个模型可以训练曲线平稳,部署递推却对内核敏感;也可以训练困难,推理确定性很好. 报告同时观察到Hybrid低spike score和vLLM精度问题,恰好说明「稳定」必须指明阶段与度量.

### 10.3. 并行算法与递归算法的一致性

训练用Extended WY chunk算法,decode用逐步递推. 实数精确算术下两者应计算同一函数,浮点下结合顺序不同. 最基本的验收是对同一短序列分别跑parallel、chunk和recurrent模式,比较每层输出与最终logit,再随长度画最大绝对误差:

$$
e(T)=\max_{t\le T}\|y_t^{parallel}-y_t^{recurrent}\|_\infty. \tag{24}
$$

测试还要跨chunk边界,尤其是255、256、257和511、512、513长度. 若误差在边界阶跃,状态传递或卷积halo可能有问题;若平滑随长度增长,更像累加精度. 开关负特征值、把状态提升FP32、固定$\alpha$接近1,可以分辨误差来源.

核长4的depthwise卷积需要前三个历史位置. 序列切块或Ulysses转置后,每个设备必须拿到正确halo;漏一位不会立刻崩溃,却会让并行训练与单步生成不一致. 论文说明卷积权重需随头切分,没有提供所有并行度下的误差曲线. 复现者应把数值一致性当成模型正确性测试,而非性能优化之后再看的细节.

## 11. 表达力结论究竟覆盖什么

### 11.1. TC⁰ 与 NC¹ 的直觉

$\mathsf{TC}^0$包含常数深度、多项式宽度、带阈值门的电路族;它能高度并行地做多数投票、加法等操作.$\mathsf{NC}^1$允许对数深度、有界扇入电路,能通过树形归约完成一般的结合运算复合. 通常猜想$\mathsf{TC}^0\ne\mathsf{NC}^1$,尚未证明. 固定深度Transformer落在前者、一般有限幺半群的状态追踪可达到后者,于是状态追踪构成条件性的分界.

「对数深度」并不意味着GDN实际展开只有$O(\log n)$层. 递推沿token顺序定义,训练通过结合律或WY表示并行扫描,把许多转移组成树形计算. 表达能力来自输入相关矩阵的复合;并行算法利用代数结构缩短关键路径. 如果状态更新包含无法结合的任意非线性,可能更强,也失去高效并行训练.

理论模型还使用硬注意力. Softmax在有限温度下给所有位置非零权重,不能精确等同UHAT/AHAT;增大logit尺度可逼近唯一最大选择,遇到并列最大时AHAT的均匀平均才自然. 定理证明「存在参数实现」,没有给出标准梯度下降从随机初始化找到这些参数的概率.

### 11.2. 状态召回为何把两种弱点绑在一起

状态召回先复合换位得到指针$q$,再从任意长比特串取$x_q$. Transformer能按地址取值,固定层数难以顺序复合任意多次非交换操作;RNN能逐步复合换位,固定状态装不下整条随机比特串. Hybrid把$q$留在小状态,把$x$留在attention可访问的序列,恰好分工.

如果比特串只有5位,纯RNN可把它全存进状态,任务不再分离两类架构;如果换位数固定,Transformer可用固定层逐次计算,同样不再分离. 难度来自两个量同时无界:随机可寻址内容$m$和状态更新长度$n$. 合成实验把$m=n$从4扩到128,正是在观察这个二维难度共同上升.

Theorem 1的一次交替是存在性结论. GDN在前时先求$q$再注意力取$x_q$;注意力在前时可先取出五个候选$x_{p_1},...,x_{p_5}$,再由GDN对候选做换位. 两种构造依赖任务只有五个指针. 若候选数随输入增长,「先全取回」会要求头数或表示宽度增长,GDN在前的构造更自然.

### 11.3. Padding 是计算时间,不只是补齐长度

定理里的polynomial padding向输入后追加多项式数量的空token. 固定深度网络仍只有固定层数,但每层能在更多位置并行放置中间结果. 注意力可把这些空位当作电路门的工作区,完成一阶归约;GDN再复合得到的五元素置换. 因此padding在复杂度证明中相当于额外空间与并行计算节点,和batch里为了对齐长度补PAD的工程习惯有本质差异.

真实语言模型通常mask掉padding,被mask位置既不参加attention也不产生状态更新,无法充当工作区. 若要实现定理构造,必须让附加token参与计算,且数量可能随输入呈高次多项式增长. Theorem 3说明架构上界至少覆盖$\mathsf{NC}^1$,没有说明标准推理提示会自动利用这种能力,也没有给出实用token开销.

Corollary关于波兰式布尔公式同样是表示性结论. 模型要学习括号-free前缀表达式的递归求值,还受训练长度、精度与优化影响. 若实验只在固定深度公式上训练测试,Transformer也可能靠模式拟合取得高分;要验证外推,公式深度必须超过训练范围,并控制词汇与局部统计.

### 11.4. 负特征值证据出现了明确分叉

合成状态追踪中,去掉负特征值后长长度准确率崩落,与交换矩阵推导吻合. 自然语言BPB里,正特征值版本与负特征值版本非常接近,个别尺度甚至更好. 两组结果可以同时成立:平均语言loss由高频、局部、易拟合模式主导,精确置换型任务的质量很小;合成集则把全部概率质量压在这类任务上.

还存在优化解释. 允许负特征值扩大函数类,门若初始化或正则化使$\beta$很少超过1/2,训练早期实际仍在正半轴;自然数据梯度也未必推动它越过阈值. 应统计各层各头$\alpha_t(1-2\beta_t)$的分布、负值频率与任务条件变化. 报告没有给这类激活分析,所以无法确认7B模型真正用了多少振荡动力学.

一个可证伪实验是冻结除$\beta$门外的模型,把负值裁成零,分别测置换、代码状态、长数学推理和普通困惑度. 若普通BPB不变而状态任务显著下降,能支持「尾部能力」解释;若都不变,7B权重可能没有使用负区间;若知识任务也下降,负特征值承担的功能就超出理论示例.

## 12. Scaling Law 的读法与陷阱

### 12.1. 五参数自由拟合存在相关性

Chinchilla形式

$$
L(N,D)=E+AN^{-\alpha}+BD^{-\beta} \tag{25}
$$

含$E,A,B,\alpha,\beta$五个参数. 在有限$N,D$范围内,$E$升一点可由$A$或$B$降一点补偿,指数也与系数强相关. 高$R^2$说明曲线能贴住观测点,没有保证每个参数都被唯一识别. 三种架构自由拟合的指数区间重叠,作者固定$\alpha=\beta=0.22$后再比较系数,实质上以共享形状换取更稳定的垂直差异估计.

固定指数后$B_{Hybrid}<B_{Transformer}$表示在同一$D$处数据有限项更小. 对固定$N$,两模型loss差近似

$$
\Delta L=(E_H-E_T)+(A_H-A_T)N^{-0.22}+(B_H-B_T)D^{-0.22}. \tag{26}
$$

只有最后一项的区间稳定分离. 当$D\to\infty$时该项趋零,曲线最终由$E$和参数项决定;实验没有证明Hybrid在无限数据极限仍更优. 「token效率更高」比「不可约能力更强」更符合拟合结果.

### 12.2. 达到同一 loss 少用多少 token

固定$N$和目标$L_*$,反解式(25):

$$
D=\left(\frac{B}{L_*-E-AN^{-\alpha}}\right)^{1/\beta}. \tag{27}
$$

由于$1/\beta\approx4.55$,分母的小误差会被高次幂放大. 当目标loss接近$E+AN^{-\alpha}$时,分母很小,token倍数极不稳定. 这解释了Tab. 20点估计为1.68到1.89倍,bootstrap区间却宽到跨过1. 外推模型越大,参数项越接近极限,倍数对$E$更敏感.

Fig. 1的35% Common Crawl token节省等价于用0.65倍token达到同loss,即效率比约$1/0.65=1.54$;MMLU少49%对应约1.96倍. 下游准确率曲线还受涌现阈值、评测噪声和训练阶段影响,不应要求它与loss拟合给出同一个倍数. 两个数字共同说明方向,没有建立所有任务统一的token折扣.

### 12.3. Compute-optimal 前沿需要按真实 FLOPs 比

对给定算力$C$,若近似$C\propto ND$,可把$D=C/(\kappa N)$代入式(25),再对$N$求导得到最优参数与数据分配. 当架构每token FLOPs不同,$\kappa$也不同;GDN的chunk常数、attention比例、序列长度都会改变它. 附录用解析$F$和$C=3FD$建立更公平的前沿,避免只按标称参数把更贵的层当免费.

训练吞吐还受硬件利用率影响,同FLOPs不等于同墙钟时间. GDN chunk矩阵乘可能比理论MAC更适合GPU,all-to-all或小模型kernel launch也可能降低效率. Tab. 9在128张H100上的8.2K对8.0K是最终7B配置的直接证据;从H100迁到B200以后,整段训练墙钟不能与Olmo 3旧run简单比较.

数据质量也进入曲线. Hybrid 7B使用Olmo 3 32B改进mix,Olmo 3 7B原模型使用自己的mix. 受控Scaling曲线统一数据,所以架构趋势可信度更高;大跑的35%与49%同时含数据mix和学习率日程差异. 作者报告早期旧mix趋势相近,但没有给完整6T配对曲线.

### 12.4. Quantization model 提供机制寓言,没有描述 SGD

理论把语言拆成按频率排序的离散任务,每个任务跨过token阈值$T_k$与参数成本$C_k$后突然学会. 真实神经网络共享表示,一个参数可服务多个任务,能力也常连续增长. 子任务是否可表示用独立概率$1-\epsilon$抽样,忽略了任务间相关性:状态追踪类任务可能成簇出现,与代码或数学数据频率相关.

Theorem 4的价值在于展示一条可能路径:架构表达力提升会降低近似某些任务所需的数据,从而主要改变$B$. 它没有从GDN门分布推导$\epsilon$,也没有从训练动态预测83.65这个系数. 实证中Mamba2 hybrid较弱、负特征值消融却接近,已经提示「表达力」之外还有归纳偏置、优化稳定性与内核效率.

如果要区分这些解释,至少需要三类实验. 第一类保持表达力近似相同,改变数值与优化性质,例如不同门参数化;第二类保持GDN实现相同,系统控制负特征值是否可达并加入状态任务占比;第三类跨数据mix重复Scaling拟合,观察$B$优势是否随代码、状态追踪数据比例变化. 当前报告完成了开端,没有穷尽因果链.

## 13. 消融表逐项能回答什么

### 13.1. GDN 对 Mamba2 同时比较了多处设计

消融保持数据、优化器、评测和逐位置MLP一致,序列混合器则整体替换. GDN使用矩阵状态、delta擦写、输入相关转移和输出门;Mamba2使用SSD状态空间、扩展因子2、状态大小128、单group与核长4卷积. 结果能回答「在这套Olmo block里选哪一个完整组件」,无法把差距只归给负特征值或delta规则.

Mamba2通常把门控非线性视作层内组成,这里又保留完整SwiGLU MLP. 作者试过去掉额外MLP,表现更差,于是选择较强版本参与对比. 但参数与计算分配仍不同:GDN把较多容量放进$d_v\times d_k$矩阵状态,Mamba2把容量放进扩展通道和128维状态. 同标称规模通过宽度取整匹配,每项实际参数见Tab. 22.

1B时纯Mamba2为0.718 BPB、Transformer 0.682、纯GDN 0.677;加入四分之一attention后Mamba2改善到0.698,GDN改善到0.669. 两种RNN都从attention召回获益,GDN仍领先. 这组结果支持GDN作为当前配方的组件,却不足以概括所有Mamba2实现. 改group数、状态维度、MLP比例或初始化后,排名可能变化.

### 13.2. 纯 GDN 胜过 Transformer 仍不等于召回问题消失

平均BPB由大量局部可预测token构成. 纯GDN可以凭更合适的状态归纳偏置降低这些token的loss,即便在随机访问任务上存在硬上限. 1B纯GDN比Transformer低0.005 BPB,与合成长召回在128位上只得约0.676并不矛盾. 两个指标对数据分布赋予完全不同的权重.

BPB按byte归一化,缓解不同tokenizer的比较;本消融本来就使用同tokenizer,主要作用是让Math、Code和QA聚合更可比. 平均差0.005看似小,累积到十亿token的负对数似然会很大;它是否转化成下游准确率,仍取决于任务阈值. Tab. 21分域显示GDN路线在Math、Code、QA总体一致,比单一平均更有说服力.

需要精确复制的测试会给出另一幅图. 例如上下文前端放随机128位串,末端随机查询一位;局部统计完全无助,纯GDN只能依赖有限状态编码. 增加状态宽度可延后失败点,attention层则可直接寻址. 因此Hybrid同时胜过纯GDN与Transformer,符合两类任务混合的数据图景.

### 13.3. 门控消融说明注意力能补偿部分选择性

输出门通常形如

$$
y_t=o_t\odot \mathrm{Norm}(S_tq_t),\qquad o_t=\sigma(W_ox_t). \tag{28}
$$

它按通道决定当前状态读出多少,相当于内容条件的输出过滤. 纯GDN去门后各规模一致变差,说明固定状态每步都暴露给残差流会带来干扰. Hybrid中差距缩小,attention层可重新选择历史证据,残差和MLP也能抑制无关状态,门的边际价值下降.

这项消融没有删除$\alpha,\beta$更新门,只删输出门. 「无门GDN」仍会选择性遗忘和擦写,不能当普通线性attention. 反过来,输出门有效也没有证明它提高表达力;逐点乘法主要改变可训练性与条件计算,复杂度类证明依赖的是状态转移.

1B hybrid中负特征值无门0.666、正特征值有门0.667、默认负特征值有门0.669,单点最优并非发布配置. 作者根据跨规模、跨域一致性选默认,避免追逐某个规模噪声. 若只摘1B数字宣称无门更强,会丢掉选择规则和全曲线信息.

### 13.4. 层位置消融还混有末层约束

交错配置每第四层attention;中置配置把attention集中在中间,并额外保证最后一层attention. 两者注意力数量相同或近似,参数量在760M为948M对932M,仍有约1.7%差异. 交错优势随规模增大,单靠这点参数差难以解释,却不能完全排除宽度取整与层索引差异.

更细的实验可比较四种放法:前置、后置、中置、均匀,每种严格保持attention层数和末层类型;再交换GDN-first与attention-first. 合成Theorem 1允许两种顺序,自然语言可能偏好先做局部状态再召回. 当前论文只比较两个布局,支持均匀交错,尚未找出每一个attention层的最佳索引.

## 14. DroPE 与循环位置感

### 14.1. 递推天然区分先后,未必知道绝对位置

GDN状态按$t=1,2,...$依次更新,调换两个输入通常得到不同矩阵乘积:

$$
H_1H_2\ne H_2H_1. \tag{29}
$$

因此它具有顺序敏感性,无需给token加显式位置向量. 可顺序敏感不等于能直接读出绝对索引. 若连续输入完全相同且门收敛到稳态,模型可能难以区分第10步与第10000步;短卷积、衰减幅度和边界token提供间接计时信号,精度与长度有关.

全局attention若去掉RoPE,score只由内容$q_i^\top k_j$决定,因果mask仍告诉位置$i$只能看$j\le i$. 它能分辨过去与未来,对历史内部的排列则缺少显式相对位置信号. 前面的GDN层已经把顺序编码进每个位置的隐藏状态,attention读到的key/value因顺序不同而变化,于是得到间接位置编码. 这就是DroPE在Hybrid上合理的机制.

反例是第一层恰好为无位置attention且所有重复token表征相同. 在因果mask下,每个位置看到的相同value数量不同,softmax平均后输出仍可能相同,难以知道重复次数. 先经过GDN便可让第$t$个重复token携带不同状态.Hybrid的具体层序决定DroPE依赖哪条路径,不能把「循环层有位置」简化成所有attention天然知道位置.

### 14.2. YaRN 与 DroPE 交换短程先验和长程自由

RoPE把query、key各二维对子旋转$t\omega_i$,内积包含相对位置差$(t-j)\omega_i$. 训练到长度$L_0$以后,低频维度还没覆盖足够相位,高频维度在更长距离可能出现未见过的组合. YaRN对低频插值,让目标长度$L_1$映射回训练范围,高频保持局部分辨率,再校正attention温度.

DroPE直接删除旋转. 已训练权重原本适应带RoPE的特征,所以还需100B长上下文token重新调整. 短距离上失去明确相对位置先验,RULER 4K从Olmo 3的95.8降到Hybrid DroPE的92.2;64K则达到85.0,高于Hybrid YaRN的76.9. 表中变化符合「牺牲部分短程定位,换取无频率外推边界」,没有证明所有短任务都会下降.

RULER混合了needle retrieval、变量追踪与聚合等合成任务. GDN可能直接帮助状态类子项,attention帮助needle类子项,总分没有展示每一机制的贡献. 若DroPE优势只集中在状态追踪,原因可能是GDN而非位置编码;若needle retrieval也提升,才更支持去RoPE改善全局层外推. 论文给总表,细分结论需要原始评测再验证.

### 14.3. 长上下文训练的并行约束

Ulysses先按序列切分,通过all-to-all转成按头切分,让每张设备持有完整序列的一部分头. 注意力头和GDN头都独立,因此主体计算成立. 通信量与激活大小相关,头数必须能被并行度合理切分;30头对某些设备数不整除,实际并行组需要选择兼容布局或处理不均匀分片.

GDN状态只在每个头内部传播,转置后可本地跑完整序列. 如果继续保持序列切分,则需在chunk边界传递状态,形成顺序依赖;Ulysses用通信换掉这条跨设备链. Attention也从每卡部分序列变为完整序列部分头,再转回残差布局. 长序列下all-to-all可能成为瓶颈,论文的目标是让两种层共享一种上下文并行框架,没有声称通信免费.

卷积核长4意味着每个位置依赖前三个token. 按头布局时每卡已有完整序列,卷积本地完成;权重按通道与头一致分片. 如果头与通道映射错误,主GDN递推形状仍正确,局部混合却串头,很难从loss立刻发现. 复现应比较并行度1与2在固定权重上的logit.

## 15. 后训练为什么出现知识强、长推理弱

### 15.1. SFT 数据与架构形成新的分布匹配

Think SFT含47.6B token、最长32K,工具调用样本被上采样3倍. 每个回答token仍用交叉熵训练,提示通常mask掉. 长推理轨迹要求状态在生成过程中持续更新,还要频繁回看题目与早期中间结果. Hybrid有四分之一全局attention,理论上能回看;训练配方却来自Olmo 3,示例长度、学习率和答案风格未针对递推状态调节.

知识选择题与PopQA多依赖预训练表征和较短答案,Hybrid在base阶段的token效率优势容易保留. AIME、Omega需要数千token推演,任何一次错误都会使最终答案失败;状态舍入误差、召回带宽或SFT轨迹适配不足都会放大. 表7只能观察合成结果,没有通过控制生成长度区分三者.

可以把准确率按生成长度分桶. 若同一任务中长度越长差距越大,支持长程状态或解码数值解释;若长度相同但数学差距仍大,更像数据与算法表征问题. 再用FP32状态、eager内核重复同一批题,可直接测数值贡献. 报告提到内核敏感,没有给表7的完整交叉实验.

### 15.2. DPO 会放大底座与参考模型的差异

DPO对偏好对$(y^+,y^-)$优化,典型目标为

$$
-\log\sigma\left(\beta\left[
\log\frac{\pi_\theta(y^+|x)}{\pi_{ref}(y^+|x)}-
\log\frac{\pi_\theta(y^-|x)}{\pi_{ref}(y^-|x)}
\right]\right). \tag{30}
$$

Hybrid使用DPO Norm、$\beta=5$,一轮259,922条. 若chosen/rejected由Olmo 3配方筛选,其中长度和推理风格的偏好未必适合Hybrid. 序列log概率是所有token之和,长回答的微小逐token偏差会累积;Norm版本用于调整长度尺度,仍不能保证两种架构得到相同有效更新.

DPO后两边AIME都大幅下降,Hybrid降得更多,说明问题不只来自预训练能力. MMLU、AlpacaEval和IFBench却提升或保持优势,目标可能把模型推向更符合偏好与指令、但较少长链计算的区域. 一套偏好数据很难同时优化简洁对话和数学探索,需要按任务观察Pareto变化.

RLVR尚未完成,所以无法判断可验证奖励能否弥补Hybrid长推理弱点. 如果瓶颈是训练轨迹不匹配,RL可能改善;若固定状态或低精度递推在超长生成中丢失信息,奖励训练只能学会规避一部分,架构与内核仍限制上限.

### 15.3. 安全与行为没有随架构自动继承

相同SFT/DPO数据并不保证拒答边界相同. Hybrid对长上下文的记忆方式改变,系统提示在很长对话中的保留、冲突指令覆盖、提示注入位置效应都可能变化. 报告明确未做安全评测. 发布模型可用于研究,部署前仍需单独测试越狱、隐私复述、危险能力与长上下文指令优先级.

状态压缩还会改变可解释的遗忘模式. SWA明确只看窗口内token,全局层再补远程访问;GDN可能选择性保留很早信息、忘掉较近信息,边界由学到的门决定. 对安全策略而言,「系统提示仍在上下文」不等于循环层仍保存其影响. 四分之一attention能回看原提示,是否实际取回取决于query和后训练.

## 16. 可复现性与证据分级

### 16.1. 最小结构验收

先核对层序:每四层三层GDN、一层全局attention,最后一层类型与配置一致;总头数30,$d_{model}=3840,d_k=96,d_v=192$. 对每个GDN头打印状态形状$192\times96$,全层标量数552,960. q/k/v三路depthwise卷积核长4,门与输出投影存在,MLP与attention block相同.

再做代数单测. 给二维key$(1,-1)/\sqrt2$和$\beta=1$,验证转移交换两个状态坐标;设$\beta=1/2$验证该方向清零;取正交query验证只受$\alpha$衰减. 随机短序列上比较显式逐步递推与chunk实现,FP64参考下误差应接近数值容差.

状态reset测试把两篇独立文档分别推理,再拼接后推理第二篇. 若配置要求边界reset,第二篇logit应与单独运行一致;若不reset,差异应可解释且训练、推理一致. 这项测试能抓住packing mask被attention正确处理、GDN却漏reset的隐蔽错误.

### 16.2. 能力验收要覆盖互补任务

只跑困惑度会漏掉召回上限,只跑needle又会漏掉状态更新. 至少包含四组:随机索引召回、置换/奇偶状态追踪、两者组合的状态召回、自然语言留出loss. 预期排序是Transformer擅长召回,GDN擅长状态,Hybrid在组合任务最强;若纯模型也全部满分,长度或状态空间太小,实验没有触到理论分界.

长度外推应固定任务生成规则,训练$n\le n_0$,测试$2n_0,4n_0,8n_0$. 同时报告exact match与中间状态准确率. 最终答案错可能只是一处早期状态错误,中间检查能定位随长度开始崩溃的位置. 自然语言部分则用相同token预算和相同数据顺序,避免mix掩盖架构效果.

负特征值验收除开关结构外,还应记录实际门. 对每层统计$P(\beta>0.5)$、$E[\alpha(1-2\beta)]$及分位数,按代码、数学、普通文本分组. 如果允许负值的模型从未使用负值,合成优势可能来自极少数提示触发;如果普通文本也频繁为负,振荡动力学可能承担更普遍功能.

### 16.3. 性能验收必须给出上下文与批量

训练TPS要标硬件、精度、序列长度、全局batch与并行策略. 推理吞吐要标prompt长度、生成长度、并发数、TP、eager/compile状态和state dtype. GDN优势强依赖批量与缓存压力,缺任一项的token/s几乎无法复现.

内存应拆成权重、激活、KV cache、GDN state和临时workspace. 公式(13)只算KV,服务框架还可能预分配分页缓存;公式(14)只算主状态,短卷积缓存和对齐也占空间. 实测峰值比解析值高是正常的,比例趋势应与上下文长度吻合.

同一权重要用至少两种内核配置跑固定评测子集. 若FP32状态恢复而eager本身无影响,问题集中在缓存精度;若FP32仍不恢复,编译融合或attention内核也可能改变结果. 报告已经暴露这类敏感性,后续复现不应只抄最快配置.

### 16.4. 四层证据不要混写

第一层是严格结果:在论文假设下,带负特征值GDN与硬attention的混合能表示状态召回,padding版本覆盖FO-uniform $\mathsf{NC}^1$. 第二层是受控实验:七个规模、相同数据和优化设置下,GDN 3:1交错的loss/BPB曲线最好. 第三层是7B近受控对照:Hybrid在多项base指标、token效率和RULER长长度领先,但mix、日程、宽度存在偏差. 第四层是机制解释:表达力、稳定性和位置感如何产生收益.

前两层最适合支撑「该架构值得研究」;第三层支撑「当前7B实现确实有竞争力」;第四层给出可检验假说. 把第四层写成已证实原因,会遮住负特征值自然语言消融接近、梯度稳定性未完全控制等反证. 反过来,因为因果链未闭合就否认实测收益,也会忽略受控Scaling的大量一致结果.

## 17. 最终判断

Olmo Hybrid最重要的成果不只是把SWA换成一种线性层. 它把三类此前分散的证据放到同一模型上:矩阵状态能够做attention困难的顺序计算;少量全局attention补上固定状态的随机召回;受控Scaling显示这种组合在相同训练预算下更省token. 3:1交错结构让两类能力多轮交换信息,30头配置把额外投影参数与吞吐重新配平,DroPE则利用循环层的顺序信号放松长上下文的位置约束.

证据最充分的收益是平均预训练loss、知识类评测与64K RULER. 仍有三处疑问:负特征值在自然语言BPB上的优势不明显;7B对照没有完全统一数据mix与学习率;后训练长数学推理明显落后且解码对数值设置敏感. 因此它目前更适合作为同时提供理论分析与大规模训练证据的研究模型,还没有成为所有任务都占优的通用替代品. 三项疑问都可以通过更严格的配对实验继续缩小范围.

若任务以长文档、知识获取、高并发rollout为主,Hybrid已经给出很强理由:大部分层的状态常数化,全局层保留召回,长上下文得分也没有因压缩崩掉. 若任务核心是超长精确复制、持续数万token的数学推演或对内核确定性要求极高,需要先做专门验证. 架构节省的缓存、训练数据效率与新增的递推数值风险必须放在一张表里权衡.

## 18. 三个反例帮助确定适用边界

第一个反例是高熵字典. 上下文由十万个随机键值对组成,末尾查询均匀随机键,键和值都没有可压缩结构. GDN状态的标量数固定,三层连续压缩无法无损保存不断增加的字典;每四层一次全局attention可以直接寻址,但只有四分之一层承担这类工作. 全attention模型每层都能回看原始键值,在相同宽度与足够缓存下可能更容易学习多轮检索. Hybrid的优势会变成缓存节省与召回带宽之间的交换.

第二个反例是有限状态流. 输入是一串事件,答案只依赖几十维隐状态,不需要复述任何历史token. 纯GDN已经能逐步更新状态,插入attention会增加平方计算和序列缓存,其随机访问能力没有用武之地. 7:1在小模型上优于或持平3:1,可能就包含这类分布的影响. 如果部署数据可证明接近有限状态过程,attention比例可以继续降低,不必拘泥四分之一.

第三个反例是短而密集的关系推理. 序列只有几百token,每一步都要比较许多实体;KV cache很小,attention矩阵也不贵. GDN更宽的投影和状态交互未必比直接全局attention高效. Tab. 9的8.2K对8.0K来自特定训练形状,无法保证所有短序列batch都领先. 这种场景应以墙钟与准确率实测,理论线性复杂度尚未进入主导区间.

三个反例还能解释为何不存在单一「最佳混合比」. 设数据中高熵召回、有限状态与短关系任务的权重分别为$w_r,w_s,w_d$,各架构在三类任务上的loss为$L_{a,r},L_{a,s},L_{a,d}$,总目标近似

$$
L_a=w_rL_{a,r}+w_sL_{a,s}+w_dL_{a,d}. \tag{31}
$$

改变数据mix就是改变$w$. Olmo的网页、论文、代码和数学混合使3:1胜出;工具日志、连续控制或检索语料的权重不同,最优点会移动. 这也是报告使用同一数据做架构消融的意义:先固定$w$,才能比较层类型.

最后还有模型规模这一维. 小模型受参数容量限制,更多attention层未必形成有效查询;大模型能学会更精细的key/query,召回层价值上升. 7:1到3:1的规模转折说明比例与宽度存在交互. 若未来扩到30B或70B,可以从3:1开始,仍需在目标token预算上重跑至少1:1、3:1、7:1三条短Scaling曲线,而非依赖1B外推直接定型.

评估新比例时还应固定总训练FLOPs,不能只固定token. 注意力占比上升会提高长序列每token计算,同样token已经花了更多算力;只固定墙钟又会混入内核利用率. 最稳妥的报告同时给出固定token、固定解析FLOPs和固定墙钟三种切面. 如果3:1在三种口径下都领先,比例结论才不依赖计费方式.

同理,缓存比较要固定并发与最大生成长度. 省下的显存若没有转化为更大batch,端到端吞吐未必提高;更大batch又会改变调度等待时间. 对在线低延迟和离线大批量rollout,同一Hybrid权重可能得出不同系统结论. 架构论文给出的状态量公式确定了上限趋势,最终服务收益仍由负载分布决定.

因此选型应先测任务中的召回熵、状态更新长度与典型上下文,再决定attention比例. 这三个量分别对应全局访问需求、递推深度与缓存压力,也比单看平均benchmark更能预测Hybrid是否合适.

任务分布变化后,这项判断也需要重新测量,不能永久沿用旧结论.
