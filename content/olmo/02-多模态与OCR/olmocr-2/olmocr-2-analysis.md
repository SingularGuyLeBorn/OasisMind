# olmOCR 2 技术解析：把文档识别变成可验证的单元测试

Allen Institute for AI 在 2025 年发布 olmOCR 2，模型仍以 Qwen2.5-VL-7B-Instruct 为视觉语言骨干，但训练目标从监督模仿扩展到带可验证奖励的强化学习。论文、模型、训练数据和推理代码都已公开。它要回答一个更贴近文档使用的问题：当同一页面允许多种等价 Markdown 表达时，怎样判断输出是否满足真正重要的约束，并把这种判断转成稳定的训练信号。

olmOCR 2 的答案由三部分闭合起来。第一部分是 olmOCR-Bench 的二元单元测试，每条测试只判断一个局部事实是否成立。第二部分是 HTML 合成流水线，它把真实页面的内容与版式重新渲染成可控页面，并自动派生大量测试。第三部分是 RLVR 训练，模型每次为同一页面生成一组候选，用测试通过率产生组内相对优势。最终模型在新版 olmOCR-Bench 上从第一版的 68.2 提高到 82.4，同时保留 7B 模型和开放推理栈的部署特点。

## 1. OCR 评分为何需要可执行约束

**1.1. 字符距离混合了内容错误与表示差异.** 传统 OCR 指标常把输出与一条参考字符串对齐，再统计插入、删除和替换。这个做法适合行级纯文本，却不适合结构复杂的 PDF。图、表和图注是浮动元素，图注可以放在相关段落之前，也可以放在之后；只要正文阅读顺序没有被打断，两种 Markdown 都可能正确。字符串指标只能选一条参考顺序，因此会把合法的另一种顺序判成大幅移动。

公式尤其能暴露字符指标的局限. 两个 LaTeX 字符串可能差异很大, 渲染结果却等价; 也可能只差几个字符, 最终的上标、分式或括号结构已经错误. olmOCR-Bench 转而检查渲染后的 DOM 元素与相对位置, 直接比较读者看到的数学结构. 论文示例中, 编辑距离更大的候选通过了视觉结构测试, 编辑距离较小的候选反而失败. 字面距离无法稳定表示公式是否正确.

二元测试把一个含混的总距离拆成若干可解释命题：指定文字是否出现，页眉页脚是否消失，两段正文是否按顺序出现，表格中的一个单元格是否位于另一个单元格上方，公式渲染是否匹配，以及输出是否出现重复片段或异语字符。每条测试只有通过和失败，页面得分是通过比例。它不要求页面只有一种合法序列化形式，却能对关键错误给出明确惩罚。 **1.2. 二元测试改变了误差权重.**

编辑距离让长文本天然拥有更大的权重。一个很长但次要的图注被移动，可能比短小却关键的表格数值错误贡献更多距离。单元测试由设计者决定检查什么，因此误差权重来自任务语义。若表格中的数值和相对位置重要，就为它们建立多条测试；若页码应删除，就建立文本不出现测试。页面上的像素面积和字符串长度不再替代业务优先级。

这种设计也有代价。测试没有覆盖的错误不会进入奖励，错误测试则会稳定地把模型推向错误方向。页面得分是离散测试的平均值，只有当候选输出跨过某条测试的判定边界时，奖励才变化。因此，测试数量、难度与覆盖范围决定了奖励分辨率。olmOCR 2 没有声称二元测试普遍优于所有连续指标，而是把二者的分歧列为后续研究方向：连续指标能提供更密的变化，二元测试则更容易表达等价答案和任务约束。 **1.3. 从评测复用为奖励.**

可执行测试的关键价值在于同一套规则既能评测，也能训练。对于一个页面，模型输出 Markdown 后，评测器逐条执行测试，得到 $r_{test}=k/n$，其中 $n$ 是测试数，$k$ 是通过数。该分数有清晰范围 $[0,1]$，不需要另一个模型在线判断好坏，也无需人工为每个候选排序。 这类奖励属于可验证奖励强化学习，即 RLVR。数学题可以用最终答案或程序执行验证，代码可以用测试套件验证，文档 OCR 则可以用页面级结构测试验证。与偏好模型相比，验证器的判定更可复现，训练时也不会引入一个持续变化的奖励模型。难点从训练奖励模型转移到构造足够多且足够准确的测试，而这正是合成数据流水线要解决的问题。

## 2. HTML 合成页怎样提供规模化监督

**2.1. 真实内容与可控渲染同时保留.** 人工编写 olmOCR-Bench 测试需要逐页阅读和核验，无法直接支持强化学习所需的数据规模。olmOCR 2 从真实 PDF 中抽取含公式、表格、多栏和页眉页脚的困难页面，再让通用 VLM 生成外观相近的语义化 HTML。真实页面提供内容分布和版式多样性，HTML 则提供可查询的结构真值。

生成过程分三轮。第一轮只分析版式，识别栏数、图片、表格、页眉和页脚等元素。第二轮结合版式分析与原图生成与页面尺寸一致的语义 HTML。第三轮把 HTML 渲染成图像，与原图并排交给 VLM，让它修正布局和内容。最终训练对由 HTML 渲染图和生成该图的 HTML 组成。输入图像和监督文本由同一份表示产生，二者在内部是一致的。

论文强调，这一反馈循环对通用 VLM 的 OCR 幻觉具有一定稳健性。若 VLM 把原页中的 `0.60` 抄成 `0.66`，渲染后的合成图里也会显示 `0.66`，从 HTML 派生的测试同样要求 `0.66`。该样本虽然没有忠实复刻原始页，却不会形成“图上是 A、标签要求 B”的矛盾监督。不过这种稳健性只保证合成图与测试一致，并不保证合成分布完全忠于真实文档；过多抄写错误仍会改变词汇与数值分布。 **2.2. 语义 HTML 是测试生成接口.**

HTML 不只是方便渲染，它还是自动生成测试的结构接口。`<header>` 和 `<footer>` 中的文本可以转成“不应出现在 OCR 正文”的测试；正文节点能产生文字出现和阅读顺序测试；表格 DOM 提供行列和单元格相对位置；KaTeX 节点给出公式真值。相比直接从页面像素推断这些约束，HTML 把元素类别、层级和顺序显式编码出来。

最终合成集 olmOCR2-synthmix-1025 只有 2,186 个 PDF 页面，却派生出 30,381 条测试，平均每页约 13.9 条。样本单位仍是页面，奖励的细粒度来自一页上的多条约束。生成所用的 Claude Sonnet 4 每页成本约 0.12 美元，由论文给出的页数和单价相乘可得模型调用成本约为 262 美元，未计渲染、筛选和计算资源。这个数量级说明高质量合成并非免费，但远低于逐条人工标注数万测试的工时。 **2.3. 监督微调数据先建立输出语言.** RL 数据不是从通用 Qwen2.5-VL-7B-Instruct 直接起步。团队先更新监督微调集 olmOCR-mix-1025，它包含 267,962 页，来自超过 10 万份 PDF，其中 9,828 页来自国家档案馆。与早期的 olmOCR-mix-0225 相比，新数据改用 GPT-4.1 处理，统一块级和行内公式格式，表格改为 HTML，并为图片加入基本 alt 文本。

两套 SFT 数据在总分上几乎相同，旧集为 $78.5\pm1.1$，新集为 $78.3\pm1.2$。分项却发生了明显迁移：表格从 72.9 提高到 77.9，多栏从 77.3 提高到 81.3；arXiv 从 78.6 降到 70.8，长小字从 81.2 降到 78.7。这组结果很重要，因为它说明数据格式更新并非所有分布都单调改善。新集的价值还包括与后续合成页、HTML 表格和输出协议对齐，为 RL 阶段建立稳定的可采样策略。

## 3. GRPO 如何使用页面单元测试

**3.1. 同页生成 28 个候选.** 强化学习从经过 olmOCR-mix-1025 微调的 Qwen2.5-VL-7B-Instruct 开始，在一台 8 张 H100 的节点上对 olmOCR2-synthmix-1025 训练一个 epoch。每个文档页面一次生成 28 个 completion。大量同题候选使训练器可以比较同一页面上的相对质量，避免把不同页面的固有难度混进优势估计。 GRPO 按组计算奖励中心和尺度。设同一页面候选奖励为 $r_1,\ldots,r_G$，组均值为 $\mu$，标准差为 $\sigma$，候选的相对优势可写成 $A_i=(r_i-\mu)/(\sigma+\epsilon)$。训练提高高于组均值的输出概率，降低低于组均值的输出概率。困难页面即使绝对得分低，只要某个候选相对更好，仍能贡献正向学习信号；容易页面若所有候选全对，组内没有差异，更新也会自然变弱。

论文给出 KL 系数 $\beta=0.01$，用于约束新策略不要过快偏离参考策略。这里的 KL 项与可验证奖励承担不同职责：测试奖励告诉模型哪些候选更符合页面约束，KL 约束限制为了追逐离散奖励而破坏已有语言和格式能力。一个 epoch 的短训练也减少了在小型合成集上过拟合的风险。 **3.2. 奖励不仅有测试通过率.**

训练实际有三类奖励。第一类是页面单元测试通过率。第二类检查输出是否以 EOS token 结束，是一个二元奖励。第三类检查回复顶部的文档元数据，包括主要语言、旋转校正、表格和图示等字段，取值在 0 到 1 之间。官方训练代码把各项注册为独立 reward function，再由 TRL 的 `reward_weights` 加权合成。

实际训练运行的各项奖励权重没有公开. 代码默认值为 1.0, 只能说明未另行指定时的行为. 若三项等权, 总奖励理论范围是 $[0,3]$; 同一页面的 28 个候选通常都能正常结束并生成元数据时, EOS 与元数据奖励在组内近似常数, 测试通过率承担主要区分作用. 训练早期或困难页面更常出现残缺输出, 此时格式奖励可以阻止少数偶然命中的测试主导更新.

元数据奖励还有一个边界：它把合成过程中的 Claude 原始输出当作字段参照。合成图与 HTML 能保证正文测试的内部一致性，却不能自动纠正主要语言或页面类型判断。若这些字段最初判断错误，格式奖励会继承错误标签。因此“对幻觉稳健”不能扩展成“所有奖励都不受教师错误影响”。 **3.3. 六个随机种子与模型汤.** 团队用六个随机种子重复 RL 训练，再对检查点做权重平均，即 model soup。三次训练采用 token 级重要性采样，三次采用序列级重要性采样。两种估计方式对长序列中策略比率的聚合不同，把它们纳入同一个权重平均，相当于把训练随机性和估计偏差一起做集成。

模型汤不增加推理时的模型数量。若六个模型参数分别为 $\theta_j$，最简单的平均是 $\bar{\theta}=\frac{1}{6}\sum_j\theta_j$，部署时只加载 $\bar{\theta}$。它成立的经验前提是各检查点从同一基座出发，位于可线性连接的相近参数区域。与输出投票相比，权重平均没有六倍推理成本；与只选单个最好种子相比，它降低了小数据 RL 对随机采样路径的敏感性。

## 4. 从训练到推理的工程改动

**4.1. 动态温度处理重复循环.** 第一版 olmOCR 默认温度为 0.8。团队发现较低温度通常带来更好的 OCR 输出，但也更容易陷入重复循环。olmOCR 2 先以低温生成，若没有正常生成 EOS 或输出过长，则提高温度重试。这个策略把确定性和逃离重复的随机性放在不同尝试中，而不是对每一页一开始就使用高温。 论文将温度概括为从 0.1 逐步升到 0.8。固定版本代码中的实际表为 `[0.1, 0.1, 0.2, 0.3, 0.5, 0.8, 0.9, 1.0]`，默认最多尝试 8 次。重试条件包括 `finish_reason` 不是 `stop`，或总 token 超过 16,384。全部失败后，页面回退到 `pdftotext` 的文本层。这一差异不改变机制方向，却影响复现：实际实现重复使用一次 0.1，并允许温度升至 1.0。

动态温度在基准上把总分从 68.2 提高到 72.8，是开发序列中第一个显著增益。它也说明 OCR 系统质量不仅由权重决定，解码失败率会直接落到最终评测。低温本身不是无条件更好；只有配合结束检测、有限重试和明确回退，才成为可部署策略。 **4.2. 提示顺序与缓存命中.** 团队还发现训练与推理提示中图像和文字顺序不一致。统一为文字在前后，总分从 72.8 提高到 75.8。反向顺序在单独实验中没有明显 OCR 差异，因此增益主要来自训练和推理协议对齐，而非“文字在前”具有固有识别优势。

固定文本放在前面还有服务系统上的好处：推理引擎更容易复用共同前缀的 prompt cache。图像内容每页不同，若图像排在固定说明之前，共享前缀会很短；把固定说明置前，可以让不同页面共享更长缓存。这项改动同时连接了模型分布对齐与吞吐优化。 **4.3. YAML、图像尺寸与空白页.** 第一版输出 JSON，olmOCR 2 改为 YAML。JSON 要求引号和括号完整闭合，长文档生成中任何截断都可能使整体无法解析；YAML 的顶层元数据更容易增量生成，正文结束后可以直接输出 EOS。论文没有观察到基准分数变化，但重试率明显下降，因而提升了推理效率。

输入图像最长边从 1024 像素提高到 1288 像素。小字、上下标和细线表格需要更高空间分辨率，代价是视觉 token 与计算量增加。1288 是团队在分数和速度之间扫参后的折中，并非一个与模型无关的最佳尺寸。基座也从 Qwen2-VL 换成 Qwen2.5-VL，配合新训练器、避免权重衰减等超参数调整，这组改动把总分推到 78.5。

空白页暴露了另一类数据问题：旧数据加载器跳过所有空白页，模型从未学习过“没有正文”也是合法答案，推理时便会凭先验编造内容。修复加载器并重训没有改变基准总分，却修正了真实批处理中的高风险行为。基准若缺少空白页，这类修复不会反映在总分上，部署质量仍然会改善。

## 5. 实验结果应如何解释

**5.1. 增益来自完整训练组合.** 开发表给出一条清晰路径：第一版 68.2，动态温度 72.8，提示对齐 75.8，新训练器、YAML、图像尺寸和 Qwen2.5-VL 合计达到 78.5，空白页修复后仍为 78.5，最后加入合成数据、RLVR 与模型汤达到 $82.4\pm1.1$。最后阶段相对前一阶段提高 3.9 分，相对第一版提高 14.2 分。 表格分项从最后一个 SFT 系统的 72.9 提高到 84.9，是 RL 阶段最突出的增益之一；arXiv 从 78.6 提到 83.0，多栏从 77.3 提到 83.7。旧扫描页只从 43.9 提到 47.7，仍是明显短板。基础类别达到 99.7，说明普通页面已接近饱和，继续提高总分更依赖困难扫描、复杂表格和版面。 最后一行同时加入合成数据、RLVR、六种子训练和权重平均, 论文没有逐项消融. 3.9 分对应的是完整组合, 表格无法分离 GRPO 与模型汤各自的边际贡献; 这需要额外的受控实验. **5.2. 基准与训练奖励共享测试体系.**

RL 奖励使用 olmOCR-Bench 兼容测试，最终评测也在最新版 olmOCR-Bench 上完成。训练页与基准页并非同一批页面，但奖励形式高度一致，这会让模型特别擅长测试体系显式表达的性质。阅读顺序、表格位置、公式渲染和页眉页脚因此获得直接优化；未被测试覆盖的视觉细节、语义忠实度或下游检索效果不一定同步增长。

这种一致性属于目标对齐，不等同于数据泄漏：训练优化的就是评测定义的能力。但评价模型泛化时，还需要不同标注体系、真实业务文档和人工检查。论文列出的其他 OCR 系统中，带星号的结果来自模型作者报告，其余由团队内部复现，推理配置和版本差异也会影响横向比较。 **5.3. 方法适合什么场景.**

单元测试奖励最适合能把质量拆成局部、可执行约束的文档任务。表格、公式、页眉页脚、段落顺序都有明确判定器，且允许多种等价序列化形式。对于手写批注、图像语义、模糊印章或需要世界知识才能判断的内容，自动测试更难生成，仍可能需要连续视觉指标或人工偏好。

工程上还要评估训练成本与推理需求。RL 阶段需要每页 28 个候选、8 张 H100、六个随机种子，计算量显著高于一次 SFT。模型汤把额外成本留在训练端，部署仍是单个 7B 模型；动态温度在多数页面第一次成功时开销较小，在重复严重的页面上则可能触发多次推理。系统应记录每页尝试次数、回退比例和失败类型，而不能只看平均基准分。

## 6. 方法的可迁移经验

**6.1. 先定义可接受答案集合.** olmOCR 2 把真值从“一条字符串”改成“一组必须满足的性质”，这一设计比具体采用哪种模型更重要。当输出存在多种等价表示时，先定义可接受答案集合，再设计验证器，比强迫所有输出模仿单一参考更合理。代码生成、网页复刻、图表转结构化数据和科学公式识别都可以采用类似思路。 验证器必须逐项可诊断。页面总分下降时，应能知道是文字缺失、顺序错误、表格关系错误还是重复输出。这样的反馈既方便训练，也方便定位推理系统问题。若只把所有规则压成一个不可解释的相似度，模型改进和回归分析都会变慢。 **6.2. 合成数据要建立自洽反馈循环.**

从 HTML 同时生成图像与测试，是减少教师抄写错误造成矛盾标签的关键。可迁移的原则是：尽量从同一潜在表示生成输入和可验证目标。例如程序任务可从可执行规格生成题目与测试，图表任务可从结构化数据生成图像与查询。反馈循环保证内部一致，却不能保证分布真实，因此仍需从真实样本采种、筛选版式，并用独立真实集评测。 合成流程也应保留来源和版本。olmOCR 2 给出所用模型、每页成本、页面数、测试数与代码链接，使复现者能检查提示、渲染和测试派生规则。对于奖励训练，数据生成代码与训练代码同样属于模型定义的一部分。 **6.3. 把协议错误视为模型问题的一部分.**

提示顺序、输出格式、空白页过滤和解码重试都曾显著影响 olmOCR。这些细节共同决定模型在生产系统里实际接收的分布与产生的行为。训练和推理消息顺序必须一致，结构化输出要选择易完成和易解析的协议，数据加载器必须覆盖零内容样本，解码失败要有上限明确的恢复路径。

olmOCR 2 因而展示了一条完整路线：用监督数据教会模型文档输出语言，用语义 HTML 生成自洽页面和测试，用 GRPO 从同页多候选中学习局部约束，再通过权重平均与受控重试得到可部署模型。它的性能提升来自评测定义、数据生成、训练目标和推理协议的共同对齐。 **6.4. 页面到文本是一种条件生成.** 给定页面图像 $I$，模型生成结构化序列 $y$，训练目标通常是最小化 $-\sum_t\log p_\theta(y_t|y_{<t},I)$。输出既包含可见字符，也包含段落、标题、表格、公式和阅读顺序的编码。任何序列化规则都会把二维页面压成一维目标，规则本身就是任务定义的一部分。

相同页面可以有多个合理输出：连字符是否合并、页眉是否保留、表格采用Markdown还是HTML、双栏先读哪一栏。若监督只给一个字符串，交叉熵会惩罚其他语义等价表示。olmOCR 2用可执行测试描述可接受集合，减少对唯一参考文本的依赖，但测试覆盖仍决定哪些差异被容许。 **6.5. 文本识别与文档解析.**

传统OCR常分为检测文本区域、识别字符和后处理；端到端视觉语言模型直接从页面生成结构化文本，将这些阶段隐藏在网络内部。优势是语言、布局和结构可以联合推断，代价是错误更难定位。一个漏字可能来自视觉编码、阅读顺序、语言解码或输出协议。 评测需保留多个层次：字符内容、区域覆盖、顺序关系和结构合法性。只看最终编辑距离，会把字符识别准确但布局错误，与布局正确但少量拼写错误混在一起。端到端模型仍需要分解诊断。 **6.6. 二维布局到线性顺序.**

页面元素可表示为带边界框的节点集合，阅读顺序是节点间的有向关系。单栏通常按上到下，双栏需要先完成左栏再到右栏，脚注、侧栏和跨栏标题又会打破简单坐标排序。目标序列隐式编码一个拓扑排序。 若页面关系存在歧义，可能有多个合法拓扑序。评测可以检查必要先后约束，而非要求完整序列逐字相同。例如标题必须先于正文、脚注引用先于脚注内容，同栏段落保持垂直顺序；无依赖的两个侧栏允许交换。部分序约束比唯一参考更贴近结构语义。 **6.7. 阅读顺序图.**

设块节点为 $v_i$，真实先后边集合为 $E$。模型输出序列诱导预测顺序，结构准确率可统计满足的边比例。对每对节点都建边会让相邻关系被大量传递边重复计权，使用Hasse图或只标关键邻接更合理。 图指标还能定位跨栏错误。字符全部正确但两个段落互换时，字符集合指标近乎满分，顺序边会失败。若块检测本身不同，需要先对预测块与真值块匹配，再比较关系，匹配阈值会影响结果。 **6.8. 行、段落与区域层级.** 页面结构具有层级：字符组成词和行，行组成段落，段落属于栏目、列表或表格。错误在不同层级传播。一行漏识别会影响字符召回，段落合并错误会破坏空行与标题，栏目交换则改变大段顺序。

层级评测可分别计算内容与父子关系。树编辑距离能统一表示，却难以解释单个分数。更实用的报告给字符、行匹配、块关系和文档结构分项，并保留失败页面示例。 **6.9. 标题层级.** 标题文字识别正确，却把一级标题写成普通段落，会破坏下游目录和检索。Markdown中的井号数量编码层级，但视觉字号、粗体、编号和留白共同提供证据。模型语言先验可能根据标题内容猜层级，在模板异常时出错。 测试可检查标题文本、层级和父级关系。绝对级别有时不确定，但相对层级必须一致。把所有标题统一降一级在渲染上或许相似，在结构语义上却有系统偏差。 **6.10. 列表结构.**

列表需要识别项目边界、序号、嵌套层级和连续性。换行可能属于同一项目，也可能开启下一项。编号缺失或重复时，语言模型容易自动修正，生成比视觉页面更整齐的列表，却不忠实于原件。 结构测试可从语义HTML知道真实列表树，检查项目数量、顺序与嵌套。项目内部文本再用局部字符指标。将树结构与内容分开，可发现模型究竟漏项还是只错了编号符号。 **6.11. 表格的二维约束.** 表格不仅是按行输出文字，还包含单元格、行列跨度、表头与数据对应。线性编辑距离无法发现列错位：所有数字都出现，归属列错误仍会造成严重数据问题。结构评测需要单元格匹配和行列关系。

语义HTML天然提供表格树与span属性，可生成测试：行列数、指定坐标内容、表头覆盖范围和关键对齐。输出为Markdown时，复杂合并单元格难以表达，测试必须按目标格式允许的能力定义，不能惩罚格式本身无法承载的信息。 **6.12. 公式识别.** 公式视觉上包含二维上下标、分式和矩阵，线性LaTeX是另一种序列化。许多LaTeX字符串渲染等价，例如括号、空格和命令别名。逐字匹配会把表示差异当错误，渲染比较或语法树规范化更合适。 语义等价更难：$a/b$ 与 $\frac{a}{b}$ 常等价，变量替换却可能改变含义。计算机代数系统只能覆盖部分公式。评测可分成可解析、渲染结构和关键符号三层，避免一个黑箱相似度掩盖错误。 **6.13. 图注与浮动对象.**

图表本身可能不转写，图注却应保留并与对应对象相邻。多栏排版中图注位置和阅读顺序可能与正文穿插。仅按坐标扫描容易把图注插入错误段落。 合成页面可保存图对象、图注和正文引用关系，生成配对测试。真实文档缺少结构标注时，可人工抽样。图中嵌入文字是否识别也需明确协议：装饰图、流程图和截图的要求不同。 **6.14. 页眉、页脚与页码.** 页眉页脚在每页重复，对文档内容价值低，却是可见文本。保留它们会污染连续正文，删除它们又可能误删章节标题或脚注。任务规范应定义哪些区域进入输出。

跨页处理可以利用重复性识别页眉页脚，单页模型只能靠位置和样式。合成数据若总在固定位置生成，模型可能学位置捷径，对真实异常布局失效。随机化位置、字体和内容能减少。 **6.15. 脚注与引用.** 脚注标记出现在正文，内容位于页底。线性输出可以在原位置插入、页末集中或保留标记链接，不同规范都合理。唯一字符串监督会造成冲突。结构化测试可检查标记与内容配对，以及正文顺序不被脚注打断。 语言模型可能根据常见短语补齐模糊脚注，这提高可读性却增加幻觉风险。关键编号、作者名和URL需要更强视觉约束。脚注字体小，还是检验分辨率与视觉编码的敏感区域。 **6.16. 多页连续性.**

单页独立OCR会在分页处断开句子、列表和表格。跨页模型需要判断上一页结尾与下一页开头是否连续，并处理重复页眉。文档级顺序比页面级指标多一层。 olmOCR 2若主要按页训练，其结果不能自动外推到整本文档。后处理可拼接页面，但跨页语义错误需单独评测。合成多页样本可以控制连续关系，真实文档则验证分布迁移。 **6.17. 渲染器定义视觉分布.** HTML内容经过浏览器、CSS、字体、纸张尺寸和截图参数生成图像。训练数据看似多样，若渲染器和字体集合固定，视觉分布仍很窄。模型可能学会特定浏览器的抗锯齿、行高和表格样式。

渲染随机化应覆盖字体、字号、边距、栏数、分辨率、缩放和压缩，同时保证语义标签保持正确。过度随机化会产生不自然页面。用真实文档统计校准参数范围，比任意噪声更有效。 **6.18. CSS作为生成语法.** 语义HTML提供内容树，CSS控制布局。两者分离使同一内容可渲染多种页面，也使同一布局可装入不同文本。通过正交采样，模型较难只记内容或模板。 某些CSS组合会导致遮挡、溢出或不可见文字。生成器必须检测渲染后页面，而非假设DOM正确。单元测试也应基于实际可见元素，隐藏DOM文本不应要求模型输出。 **6.19. 合成数据的标签精度.**

合成页最大的优势是结构真值自动可得。DOM知道元素层级、文本和位置，可生成确定测试。标签精确建立在渲染与提取映射正确上；浏览器换行、连字和字体回退可能让DOM字符串与可见字形不完全一致。 抽样保存截图、DOM框和目标输出叠加图，检查标签。生成规模越大，少量系统bug越会被重复放大。标签程序的单元测试与版本记录是数据质量的一部分。 **6.20. 内容来源与布局来源.** 使用真实文本填充合成布局，能保留语言和主题复杂性；布局仍由模板控制。若内容来源与评测重合，会产生文本记忆，哪怕视觉布局新颖。数据构建需对内容去重，并分开记录内容与模板ID。

评估也可交叉组合：训练见过内容未见布局、见过布局未见内容、两者都未见。四格设计能判断模型依赖语言记忆还是视觉结构泛化。只在随机划分页上测试容易让同模板和同文档泄漏。 **6.21. 模板泄漏.** 同一HTML模板换文字生成许多页面，随机按页面划分会让模板同时进入训练和测试。模型可凭固定坐标与样式取得高分。应按模板族、CSS参数或生成程序版本划分，测试真正新布局。 真实文档也有模板族，例如同一期刊或同一政府表格。按文档随机划分同样会泄漏。来源级和模板级分割比页面级更严格，结果通常更能反映迁移。 **6.22. 内容泄漏.**

同一文章被排成不同样式进入训练和测试，视觉不同却文本相同。语言模型能凭前几个词续写，掩盖视觉识别不足。段落级精确和近重复去重需要跨所有渲染版本执行。 对常见公共文本完全去重可能不现实，可按重合度分桶报告。用随机实体、数字和不可预测字符串构造压力测试，可以降低语言记忆帮助，直接测视觉证据。 **6.23. 合成到真实的域差距.** 真实扫描包含透视、阴影、污渍、折痕、纸张纹理、手写和拍照裁切，浏览器截图过于干净。添加噪声能覆盖部分低层变化，真实排版和内容结构仍可能不同。合成训练增益必须在来源独立的真实文档上验证。

域差距可按视觉质量、布局类型和文档年代分层。总体平均改善可能只来自数字原生PDF，对扫描档无效。失败分层指导下一轮合成参数，而非盲目增加页面数。 **6.24. 扫描退化模型.** 可模拟模糊、压缩、旋转、透视、颜色偏移和局部遮挡。每种退化有强度，组合后可能远离真实分布。根据真实样本估计强度分布，并保留无退化样本，避免模型只适应噪声。 退化不应改变标签，严重遮挡却可能让字符不可辨识。此时唯一真值要求模型猜测，训练会强化语言先验。设置可读性阈值或允许缺失标记，区分识别与恢复任务。 **6.25. 分辨率与小字.**

页面缩放到固定图像尺寸后，小字可能只剩数像素。模型无法恢复消失的视觉信息，语言解码器会猜测。评测应记录原始DPI、缩放和最小字符高度，按区间报告准确率。 提高分辨率增加视觉token与计算。裁块或多尺度输入能保留细节，却需要处理块间顺序。质量—计算曲线比单一最佳尺寸更有部署意义。 **6.26. 图像压缩.** JPEG在文字边缘产生振铃，PNG通常无损但文件大。训练与测试压缩分布不同会造成性能差。PDF渲染还受抗锯齿与hinting影响。 用多种编码和质量做配对测试，能测模型对低层表示的鲁棒性。同一页面内容保持不变，差值更容易归因视觉退化。协议必须固定解码库和颜色空间。 **6.27. 旋转与方向.**

页面可能整体旋转，表格单元格或侧栏文字又可能局部竖排。预处理自动校正整体方向无法处理局部方向。端到端模型可学习，但合成数据需包含合理分布。 方向评测分别测检测、校正和最终文本。模型若输出正确字符却逆序，字符集合指标仍高。阅读方向是结构的一部分，尤其多语言页面。 **6.28. 字体覆盖.** 训练字体集合决定字形变化。相同Unicode在不同字体差异显著，某些字符又容易混淆。测试未见字体能衡量字形泛化，按字体随机划分页不足，因为同字体泄漏。 字体许可证和真实使用频率也影响选择。只加入大量装饰字体不一定帮助常见扫描。建立字体族层级，按衬线、无衬线、等宽和历史字体分层更可解释。 **6.29. 多语言脚本.**

拉丁、汉字、阿拉伯和天城文的字符结构、书写方向与连写不同。共享视觉编码器可以迁移边缘和布局，识别头与tokenizer覆盖仍有差异。统一字符准确率不能直接比较语言难度。 按Unicode grapheme cluster或字符评测时需固定规范化。混合方向页面的阅读顺序更加复杂。语言宏平均防止高资源语言淹没，部署权重另行报告。 **6.30. 语言先验的两面性.** 视觉字符模糊时，语言模型利用上下文纠正拼写，提高自然文本准确率。对姓名、编号、化学式和随机串，强先验可能把罕见真值改成常见词。总体编辑距离改善会掩盖关键字段错误。

评测应包含自然文本与低可预测字段，并按类型报告。可通过上下文遮蔽或替换构造相同视觉难度的随机串，测量模型依赖先验程度。先验不是错误，未校准的覆盖才是风险。 **6.31. 视觉—语言冲突实验.** 将页面中的一个常见词替换为拼写相近的罕见词，同时保持上下文强烈暗示原词，可以测试模型是否遵循像素。若输出回常见词，说明语言先验压过视觉证据。反向把像素轻微扰动，也能画冲突强度曲线。 这种反事实样本必须保证替换后的字形清晰。多字体、多分辨率重复，避免结论依赖单一渲染。关键实体和数字可建立专门冲突集。 **6.32. 幻觉插入.**

模型可能生成页面上不存在但语言上合理的词句，例如补完整被截断段落、增加标题或修正语法。字符精确率会惩罚插入，但长文档中少量插入占比低。对事实使用而言，一句虚构内容风险很高。 分别统计插入、删除和替换，并按连续幻觉跨度分布。空白区域和截断页面是压力测试：可靠模型应停止或标记不可读，而非续写。奖励中需要明确惩罚无视觉依据内容。 **6.33. 删除错误.** 小字、边缘文本和低对比区域容易被漏掉。语言模型偏好连贯段落，可能自动跨过不可读句，输出看似完整。字符召回与区域覆盖能发现，单纯可读性人工评分可能忽略。

按页面坐标画召回热图，可以诊断边缘、页底和栏间问题。合成数据的元素框提供真值，真实数据则需人工区域标注。删除与插入风险不同，应分开报告。 **6.34. 重复循环.** 自回归解码可能重复行、段落或标记，尤其长页面与表格。动态温度尝试在检测重复时改变采样，却也可能增加字符错误。重复检测规则和温度变化是推理协议一部分。 评测统计重复n-gram、重复块和额外token比例，同时检查是否误把合法表格重复判错。训练奖励若强惩罚重复，模型可能通过过早停止规避。长度和召回需联合观察。 **6.35. 过早停止.**

输出合法结束标记却遗漏页面尾部，格式测试可能通过。奖励需要覆盖内容召回或关键区域测试，不能只看语法。页面长度与生成上限也会造成系统截断。 记录finish reason、输出token与页面文本量估计，按长页面分析。提高上限会增加循环风险，动态停止应基于页面覆盖而非仅语言结束概率。 **6.36. 输出语法.** 结构化文本需要合法Markdown、HTML或YAML。语法错误会使下游解析失败，哪怕文字正确。可执行解析器提供明确奖励，但模型可能生成最简单合法结构，牺牲真实层级。 语法合法性是必要条件，结构忠实度另行测试。奖励分项记录解析、内容、顺序与结构，防止一个容易指标主导。最终用户看到的是完整系统，两层都重要。 **6.37. 可执行测试的覆盖.**

每个页面的测试只检查有限属性。所有测试通过不表示输出完全正确，未被断言的段落仍可能错。测试生成器应覆盖关键元素，并记录覆盖率：多少文本、块和关系至少被一个断言触及。 随机选少量属性能扩展数据，却增加奖励噪声。根据结构风险分层抽样，确保表格、标题和罕见字段有最低覆盖。人工完整标注集用于估计测试通过率与真实质量的关联。 **6.38. 测试独立性.** 同一错误会导致多个断言失败，例如漏掉表格一行同时破坏行数、单元格与文本测试。把每项简单平均会重复惩罚。按结构组件分组，先组内聚合再组间加权，减少相关测试放大。

反过来，一个宽泛测试可能覆盖多个错误却只失败一次。奖励权重表达任务价值，不应由断言数量偶然决定。测试生成模板需要审计其隐式权重。 **6.39. 二元奖励的方差.** 二元测试给清晰信号，但接近阈值的输出可能因一个字符从满分变零，方差较大。部分信用如编辑相似度能平滑，容易被模型优化成近似输出。两者结合时需检查相关性。 GRPO组内候选若全通过或全失败，没有相对信号。页面难度和采样温度决定奖励方差。数据路由可优先选择成功率居中的页面，保留容易与困难页做回放和评测。 **6.40. 奖励黑客.**

模型可能输出测试所需关键词，却省略其余内容；用重复片段提高覆盖；或选择解析器宽松接受的结构。任何公开可执行测试都有被策略利用的可能。对抗样本和隐藏断言可以发现。 奖励训练后比较测试通过率与独立人工质量。二者相关下降时，说明策略找到了漏洞。更新测试后需要回放旧模型，确认提升来自覆盖修复而非难度改变。 **6.41. SFT与GRPO的分工.** SFT教会图像到目标语法的基本映射，让候选大多可解析；GRPO在当前分布中比较结构与内容质量，强化可测试属性。没有SFT，在线样本可能全是格式错误；只有SFT，模型只能模仿单一参考，难以利用多个可接受输出。

阶段消融需共享数据与评测，区分更多样本、在线采样和奖励本身。GRPO后若只提高测试指标，独立字符与结构分项不变，增益可能是协议适配。 **6.42. 组内优势.** 同页生成多个候选，奖励减去组均值形成相对优势。它控制页面难度：困难页整体低分，仍可比较较好候选。组内回答相似时方差低，采样过高温又产生大量无效格式。 28个候选增加找到高质量输出的概率，也提高训练成本。组大小消融应固定总生成token，区分更多探索与更多计算。候选相关性决定有效样本量，名义28不等于28个独立解。 **6.43. 模型汤的条件.**

多个seed权重平均希望保留共同能力并抵消噪声，前提是模型位于相近损失盆地且参数对齐。相同初始化和训练配方更可能满足。平均后无需额外推理成本，却可能损害少数seed独有结构能力。 比较单seed均值、最佳seed和权重汤，才能判断收益来自集成式稳定还是选择偏差。模型汤结果不应被归因给某一个训练run。优化器状态通常不随权重平均继续训练。 **6.44. 多seed证据.** 六个随机种子提供训练方差信息，但最终只展示汤模型会隐藏分布。应报告每个seed的主要指标、均值和范围，检查某些页面类型是否不稳定。若汤优于所有seed，说明线性插值产生额外收益；若仅接近最佳，可能只是稳定选择。

seed共享数据和合成模板，不能覆盖数据分布不确定性。模板、内容和渲染器留出实验提供另一维证据。随机性重复与域外泛化不可互换。 **6.45. 字符编辑距离.** CER通常为 $(S+D+I)/N$，其中替换、删除、插入相对真值字符数归一。Unicode字符、grapheme cluster和空白规范化选择会改变计数。长文档总体CER可能掩盖短关键字段的完全错误。 按页面平均与全字符微平均同样不同。前者每页同权，后者长页主导。报告两者、错误类型和结构分项，避免单一CER成为全部质量代理。 **6.46. 词错误率.** WER对空格分词语言直观，中文等语言需额外分词，跨语言不可直接比较。标点与大小写是否计入也影响。OCR下游若依赖精确实体，字符指标更细；若面向搜索，词级可能更相关。

规范化规则应与用途一致并固定。原始与规范化分数并列，可以区分视觉字符错误与表示差异。过强规范化会隐藏数字、标点和格式问题。 **6.47. 结构树编辑距离.** 把输出解析为标题、段落、列表、表格树，可用插入、删除和替换节点的最小代价衡量。成本设计决定指标偏好：删整个表格与错一个标题级别不应同价。通用树距离未必符合文档价值。 更透明做法是发布节点匹配、父子关系和顺序边准确率，再给加权总分。权重由下游需求决定。树解析失败单列，不让默认空树产生奇怪分数。 **6.48. 表格指标.**

TEDS等指标比较HTML树与单元格内容，兼顾结构和文本，但对等价序列化与复杂span仍可能敏感。数据抽取任务还关心单元格语义对应，可按行列坐标匹配后算内容准确率。 表格大小差异使微平均偏向大表，表级宏平均又让小表同权。按简单、合并单元格和多页表分层，能看模型能力边界。总体结构分数不足以说明关键财务表可靠。 **6.49. 阅读顺序指标.** 可用预测块顺序与真值的Kendall tau，统计成对逆序；块缺失和新增时需先匹配或扩展惩罚。长文档中少数栏交换会造成大量逆序，正好反映严重结构错位。 若真值是部分序，只有受约束块对参与。无关块顺序不惩罚。合成DOM能自动生成约束，真实页面标注则需允许歧义。唯一全序会高估错误。 **6.50. 块匹配.**

预测没有显式边界框时，可按文本相似和顺序将输出段落与真值块对齐。文本错误会影响结构评分，形成耦合。若模型输出坐标，可用IoU辅助，但目标协议可能不要求坐标。 对齐算法和阈值应在人工样本上验证。无法匹配的块分别记删除与插入。结构分数的可信度依赖对齐，而不只依赖后续关系公式。 **6.51. 关键字段加权.** 文档使用常关注发票金额、合同日期、论文公式等关键字段。总体字符准确率对这些字段权重很低。任务可预先标注关键字段，分别报告精确率与召回率。 关键字段集不能根据模型错误事后挑选。合成页面从语义HTML自动知道字段类型，真实评测需领域专家定义。字段加权体现应用价值，保持与通用OCR指标分开。 **6.52. OCR错误传播到检索.**

漏字和拼写错误会降低关键词命中，段落错序会破坏切块语义，标题层级错会影响索引元数据。下游检索效果取决于错误位置，不与CER线性对应。 将OCR输出送入固定检索管线，测召回和排序，可观察实际传播。为了归因，再用人工真值文本作上限。下游评测补充结构指标，不能反向替代OCR诊断。 **6.53. OCR错误传播到问答.** 问答模型可能用语言先验修复小拼写，却会被错误数字、否定词和表格列严重误导。构造相同问题在真值文本与OCR文本上的差值，能估计OCR造成的性能损失。 问答模型自身也有错误，使用多个模型或规则任务提高稳健性。差值只对该下游系统有效。它回答端到端影响，不说明OCR模块内部哪里失败。 **6.54. 错误级联与置信度.**

OCR若能给token或区域置信度，下游可在低置信位置回看图像、请求人工或保留不确定标记。自回归模型概率未必校准，常对语言上流畅的幻觉很自信。需要在视觉冲突集上校准。 覆盖率—准确率曲线衡量拒绝低置信区域是否有效。只给页面总置信会隐藏局部关键错误。区域级证据更适合交互式审校。 **6.55. 空白页与无文本页.** 空白页、纯图片和装饰页测试模型能否输出空结果。语言模型常倾向生成说明或猜测内容。负样本比例太低，平均指标看不出插入风险。 单列空白精确率和误生成长度。合成空白很简单，真实扫描可能含噪点、水印或背页透字，更难。任务规范需定义是否输出图像占位符。 **6.56. 手写与印刷混合.**

手写批注覆盖印刷文本时，识别目标可包含两者、只取正文或用标记区分。训练标签若不一致，模型会随机处理。合成手写字体不能完全代表真实笔迹。 混合页应单独评测，并明确层级和重叠处理。olmOCR 2在未覆盖此类分布时，不宜从数字原生页面结果外推。开放边界比模糊承诺更有用。 **6.57. 图像内文字.** 流程图、截图和照片中的文字可能对文档语义重要，却缺少自然阅读顺序。若目标只转正文，应忽略；若目标完整无障碍文本，需要图结构与说明。统一OCR协议难以同时满足。 评测按对象类型定义。模型在正文强并不意味着图中文字强，视觉分辨率和训练数据都不同。平均字符分数可能被正文数量淹没。 **6.58. 训练数据课程.**

先用干净合成页学习语法，再加入真实噪声和复杂布局，是自然课程。若始终合成比例过高，模型可能保留渲染器偏差；过早加入噪声又降低基础对齐。检查点分层评测可选择切换点。 课程收益需与总数据和训练步数对齐。随机混合对照判断顺序是否真正重要。不同页面类型学习速度不同，单一总分不足以选课程。 **6.59. 难例采样.** 训练后用失败页面增加采样权重，能聚焦布局和低质量图像。若难度由标签错误或不可读造成，重采样会强化猜测。先审计失败来源，再进入课程。 持续只采难例会遗忘常规页面，并改变输出稳定性。保留基础回放，按类型设上限。独立未见难例检查模型是否泛化，而非记住模板。 **6.60. 合成生成器的闭环风险.**

模型错误用于指导生成新模板，再用同一测试体系评估，系统可能越来越适配自身可表达的难例，忽略真实分布中未知错误。定期从真实文档抽样，更新错误分类但保留冻结测试。 生成器版本与训练run关联。新模板带来的增益在旧、新和真实集上分别报告。闭环需要外部锚点，否则自洽不等于有效。 **6.61. 真实文档的版权与隐私.** OCR训练文本可能含个人信息、合同和受版权保护内容。合成数据降低部分风险，但真实内容填充仍需许可。发布图片、文本与模型记忆风险分别评估。 去标识可能改变布局和语言分布，替换字段应保持长度与格式。隐私删除请求涉及数据、缓存和已训练模型，不能只从网页下线。透明数据谱系支撑处置。 **6.62. 基准污染.**

模型预训练可能见过评测PDF或其文本，语言先验能补全内容。视觉布局不同并不能完全防止。按文档标题、文本段落和图像哈希检查训练重合，并用未见内容模板评测。 随机串和反事实字段能削弱记忆，却不代表自然任务。完整报告原始、去重和合成压力集。污染影响需按文本覆盖率分层，不能只标二元清洁。 **6.63. 评测与奖励同源.** 训练奖励和测试若共享同一单元测试生成器，模型可能针对其覆盖习惯优化。即使具体页面不同，断言类型和宽松规则也可能泄漏。独立人工集或不同生成器测试能检查迁移。

论文结果仍能证明对该测试体系改善，但广泛OCR能力需要异源基准支持。测试同源是解释条件，不自动否定增益。关键是把协议适配和视觉泛化分开。 **6.64. 消融归因.** 完整方案同时改变SFT数据、GRPO奖励、采样、动态温度和模型汤时，终点提升无法归给单一组件。逐项消融需要固定训练token和生成预算，并报告分项指标。 组件可能交互：动态温度只在GRPO后模型易循环时有用，模型汤收益依赖多seed。二乘二关键组合比单独移除更能发现。昂贵实验至少在小规模验证交互，再确认最终模型。 **6.65. 计算预算.** 每页28个候选使在线训练生成成本很高，可执行测试和渲染也有成本。最终推理速度不代表训练效率。报告策略token、图像处理、测试执行和seed总量，才能比较方案。

候选数增加带来的收益应在固定总token下评估，否则更多计算与算法混杂。若较小组几乎同效，预算可用于更多页面和布局多样性。质量—成本曲线比单点更有价值。 **6.66. 推理时动态温度的比较.** 检测重复后升温或调整采样可能逃出循环，也可能破坏精确抄录。比较固定贪心、固定温度和动态策略，按重复、字符与结构分项。动态触发率也需报告。 若基准主要干净短页，触发很少，平均无差异不能说明长页有效。专门重复压力集更适合。触发规则是系统的一部分，应随模型版本校准。 **6.67. 确定性与可复现.**

OCR通常期望同页多次输出一致。采样策略引入方差，模型汤和动态温度又可能改变。对同页多seed推理，报告文本一致率和指标方差。高平均、低稳定可能增加审校成本。 确定性解码便于复现，但未必是最佳质量。若使用随机解码，固定seed只复现一次样本，不能代表分布。评测应按部署策略运行。 **6.68. 模型规模与视觉分辨率.** 更大语言模型可能更会补全文本，却不会恢复已经在下采样中消失的像素。规模提升若只在自然句子明显、随机字段无改善，收益主要来自先验。提高分辨率或视觉编码器可能更有效。 二维实验同时改变模型规模和图像token预算，能分离。固定总计算下，两者存在权衡。只扩语言参数可能让输出更流畅也更自信地错误。 **6.69. 视觉消融.**

给模型空白、模糊或打乱页面，观察输出与原图结果差异，可以测语言先验占比。若仍复现大量内容，可能存在文本泄漏或模型忽略视觉。遮挡特定区域则测试局部证据。 消融图像会落在分布外，结果不能量化正常使用中的精确贡献。它适合发现严重依赖问题。更自然的反事实是替换少数清晰字段并保持布局。 **6.70. 文本提示泄漏.** 提示若包含文件名、标题或元数据，模型可借此补全内容。训练和评测应检查除图像外的输入。缓存键、路径或OCR前处理文本也可能意外进入提示。 用匿名文件名和固定指令做对照。任何额外上下文都需记录，它可能是合法系统功能，也改变视觉到文本任务定义。声称纯视觉识别时尤其要控制。 **6.71. 可读性阈值.**

某些页面人类也无法识别。强制唯一答案会把模型猜测与视觉能力混合。人工可读性标注、多个标注者一致度和「不可辨」选项能定义上限。 按可读性分层报告，既不掩盖真实困难，也不把不可解样本当普通错误。合成数据可精确控制退化强度，寻找人类与模型性能曲线。部署时低可读页面需要升级处理。 **6.72. 结构等价类.** 同一文档可用不同Markdown空行、HTML标签或转义表达。评测先解析到规范结构，再比较，能形成等价类。解析失败仍是协议错误，解析成功后忽略无语义差异。 规范化不可删除有意义信息，如表格列、标题级别和代码缩进。每条规则附正反例，并在真实输出上回归。可接受集合越宽，越需要证明没有把实质错误也吞掉。 **6.73. 单元测试的假阴性.**

输出语义正确，却因另一种合法格式未通过测试，属于假阴性。它降低奖励有效样本并推动模型迎合实现细节。收集人工判对但测试失败的案例，扩充等价规则。 规则放宽后还要检查假阳性。测试集分成开发与冻结审计，避免每次看到模型输出就修改最终标准。版本变化需要重算历史模型。 **6.74. 单元测试的假阳性.** 测试只查表格包含某数字，模型把数字放错列也可能通过；只查标题文本，不查层级，也会误判。假阳性在RL中更危险，因为策略会主动寻找。对抗生成与人工抽查高奖励输出是必要步骤。

按测试类型计算与完整人工质量的精确率，决定权重。覆盖不足的测试可用于辅助，不应主导总奖励。隐藏测试降低直接适配，却不能替代设计完整性。 **6.75. 结构指标的相关性.** 字符、树、顺序和下游指标可能相关，但相关不表示冗余。模型更新后，相关结构会变化；某方法专门改善格式，会提高树分而不改善字符。长期监控相关矩阵，发现指标何时开始分离。 选择少量主指标时，保留对关键风险敏感的分项。平均相关高却在表格上独特的指标仍值得。基准压缩不能只优化总体模型排名。 **6.76. 置信区间.** 页面是自然重采样单位，同一文档多页则应按文档簇bootstrap。逐字符当独立会严重低估方差。模型比较使用同页配对抽样，保留难度相关。

按布局、语言和质量分层给区间。小子集点估计波动大，避免据此做精细排名。训练seed方差还需独立run，页面bootstrap无法覆盖。 **6.77. 排名的稳定性.** 模型总体差距小时，页面抽样、规范化或结构权重变化可能让排名翻转。对每次bootstrap和合理指标权重重新排名，给出成对胜率。强行单序会夸大确定性。 应用选择以关键字段、表格或扫描档为主时，应使用对应子集。通用平均仅作概览。OLMoOCR系统的优势需要绑定文档分布。 **6.78. 真实部署漂移.** 上线后扫描设备、文档模板和语言比例会变化。固定基准保持历史可比，滚动样本监控当前质量。新样本人工审校成本高，可按低置信、异常布局和用户反馈优先抽样。

漂移检测发现输入变化，不等于模型退化。用同一旧模型在新旧样本比较，区分。更新模型后又需固定重叠集，避免样本与模型同时变化无法归因。 **6.79. 人工审校接口.** 高风险文档不会完全自动化，模型应提供页面坐标、结构块和置信度，帮助人快速核对。纯文本输出丢失视觉定位，使错误难找。训练目标可包含引用区域或对齐信息，但会增加复杂度。 评测审校时间、关键错误发现率和修改量，能够衡量实际价值。自动指标相同的系统，交互设计可能差异很大。工程接口在这里服务证据核验。 **6.80. 文档解析的证据链.**

每个输出块若能链接到页面区域，字符和结构错误都可回看视觉证据。语言模型补全但无对应区域的内容更容易被发现。对齐不证明正确，却提升可审计性。 训练合成页有精确框，可监督这种链接；真实页对齐需OCR或人工，噪声更大。发布模型若不输出框，也可保留内部注意区域作为研究信号，但注意力本身不能直接当因果解释。 **6.81. 方法结论的层级.** 合成测试通过率提高，证明模型更符合该生成器定义；来源独立真实基准改善，支持文档迁移；多语言、扫描和复杂结构分项一致，支持更广覆盖；下游检索与问答改善，才说明结构化文本对应用有效。

每层都需独立数据和协议。完整组合取得高总分，不能自动证明每个组件贡献，也不能覆盖未测手写、图内文字或跨页场景。结论随证据层级展开。 **6.82. 一份可信的结果报告.** 报告模型、图像分辨率、提示、解码、输出规范、训练阶段与候选预算；指标包含字符插删替、结构、顺序、表格、关键字段、重复和空白页。数据按合成模板、真实来源、语言和质量分层，并给文档级区间。 同时披露训练奖励与测试是否同源、内容和模板去重、人工审计协议及失败案例。这样读者能判断提升来自视觉识别、结构建模、语言纠错还是协议适配，也知道结果尚未覆盖哪些文档。 **参考资料.** **6.83. 图像切块与视觉token.**

视觉编码器把页面分成patch，patch尺寸决定最小可分辨细节。字符笔画若小于patch内有效分辨率，后续语言模型无法凭视觉恢复。减小patch或提高输入尺寸会增加视觉token，注意力与显存成本随之上升。 同一页面用不同网格起点切块，字符可能落在patch边界，表示发生变化。轻微平移增强能提高鲁棒性。评测按最小字符高度和patch比例分层，比只报像素尺寸更能解释。 **6.84. 多尺度视觉.** 全页低分辨率保留布局，小块高分辨率保留文字。多尺度模型需要将局部块坐标映回全页，并处理块重叠与阅读顺序。若只拼接局部token，模型可能重复边缘文字或交换块序。

对照实验固定总视觉token，比较单尺度与多尺度，区分结构设计和额外计算。长表格、小脚注和大标题受益不同，分项结果能说明高分辨率用在何处。 **6.85. 裁块策略.** 规则网格简单，却会截断行与表格；内容感知裁块避免截断，但依赖前置检测器。检测漏掉区域后，生成模型永远看不到。两阶段系统的召回上限由裁块决定。 重叠裁块提高覆盖，带来重复合并问题。训练目标可标记每块负责的中心区域，推理只接受中心输出；也可让语言模型全局合并。评测需将裁块漏检与生成错误分开。 **6.86. 坐标编码.**

二维位置可以通过绝对坐标、相对位置或块序注入。绝对坐标易学固定模板，尺寸和裁切变化时泛化差；相对位置更适合关系，却可能丢失页眉页脚等全局区域信息。组合两者通常更稳健。 合成训练随机化纸张尺寸和边距，能防止坐标捷径。测试将同一内容整体平移或缩放，观察结构是否保持。若输出随无语义坐标变化，模型尚未学到布局关系。 **6.87. 视觉编码器与语言解码器的接口.** 视觉特征通过投影、交叉注意力或统一token序列进入语言模型。接口容量过小会压缩字符细节，过大则增加计算并允许语言模型依赖冗余视觉token。训练梯度是否充分到达视觉编码器也影响。

冻结视觉编码器只训练投影和语言模型，适合保留通用视觉能力，却可能不适应小字文档；全量训练能学习OCR特征，也可能遗忘其他视觉能力。阶段消融与线性探针可观察字符信息在哪一层丢失。 **6.88. 视觉特征的分辨率瓶颈.** 输入图像很大，不代表编码器中间特征仍高分辨率。卷积步幅或patch合并会快速下采样，小字信息在进入语言模型前消失。可在不同层训练字符位置探针，估计保留程度。 高分辨率分支、浅层特征融合或局部重编码能缓解。收益应在随机串和小字集验证；自然文本改善可能仍来自语言先验。模型规模增加无法逆转已丢失视觉信息。 **6.89. 交叉注意力的覆盖.**

生成每个token时，模型应从相应页面区域获取证据。交叉注意力分布可用于调试，但注意力权重不等于因果贡献。遮挡高权重区域并观察输出变化，能提供更强检查。 结构token如换行和标题标记可能依赖多个区域，不应期待单点对齐。字符、数字等局部token更适合对齐测试。训练显式区域监督可提高可审计性，标签成本也更高。 **6.90. 单调对齐假设.** 语音识别常利用单调序列对齐，文档阅读顺序在单栏内近似单调，在多栏、脚注和表格中会跳转。强制全页单调会把复杂布局错误线性化。局部单调加块级图顺序更符合。

合成DOM提供块关系，可监督先选下一块，再在块内生成字符。端到端自回归模型隐式完成两层决策，失败时难区分。层级评测能判断需要何种结构改进。 **6.91. CTC式目标与自回归目标.** CTC对输入位置与输出序列做单调边缘化，适合行级OCR；自回归目标能利用语言上下文并生成结构标记。页面级非单调布局限制CTC，但在已裁行上可作为辅助损失。 辅助CTC强化视觉字符证据，可能减少语言幻觉；它需要位置对齐且无法直接表达表格树。组合目标的权重影响，需同时看自然文本和随机字段。辅助loss下降不保证最终结构改善。 **6.92. 区域检测辅助目标.**

预测文本框、块类型和阅读边，为视觉编码器提供密集结构监督。合成页自动有框，真实页标签较少。检测目标与生成目标共享表示，可能提高布局泛化。 若最终输出不含坐标，辅助目标只在训练使用。其收益要在未见模板上验证，防止模型仅学合成框定义。框IoU高也不代表文字正确，分项仍需保留。 **6.93. 多任务梯度冲突.** 字符识别、结构解析和语言生成可能给共享参数不同梯度。语言loss占token多数时，结构辅助目标被淹没；结构权重过高又损害流畅文本。计算任务梯度夹角和范数可以诊断。 权重调节、分阶段训练或部分独立头都能处理，最终由分项迁移验证。梯度统计提供局部线索，不直接决定最佳权重。模型容量变化后冲突也会变化。 **6.94. Teacher forcing与自由生成.**

训练时每一步看到真实前缀，推理时看到自身输出。早期漏字或错结构会改变后续条件，导致段落整体偏移。页面越长，暴露偏差越明显。token loss良好仍可能自由生成循环。 序列级GRPO直接评价完整输出，能补充teacher forcing目标。也可用噪声前缀训练恢复，但人工扰动需接近真实错误。长页面自由生成评测不可由短片段loss替代。 **6.95. 长序列信用分配.** 页面末尾结构错误只影响少量奖励，策略梯度却作用于整条输出。二元测试若定位到某个组件，可以将奖励关联对应token区域，提高信用精度。错误定位不可靠时，过细分配会引入偏差。 块级生成和块级测试缩短信贷距离，随后文档级顺序整合。层级训练可能更高效，但需确保块之间关系仍被学习。最终整页指标保持验证。

**6.96. 奖励尺度与页面复杂度.** 简单页只有几个测试，复杂页有几十个。直接平均测试通过率让每页同权，按测试总数微平均则复杂页权重高。两种目标分别强调页面公平和结构覆盖。 可先在字符、表格、顺序等类别内归一，再按预设权重聚合。页面复杂度分层报告，检查模型是否通过简单页获得大部分奖励。测试数不应偶然决定训练权重。 **6.97. 奖励归一化.** GRPO在同页候选内标准化奖励，消除页面间平均难度，却让只有微小质量差的简单页与差距巨大的难页产生类似标准优势。奖励方差很小时，数值噪声还会被放大。

设置最小方差、保留原始奖励尺度或按置信度加权可以缓解。训练日志同时记录原始与标准化奖励，才能解释策略更新。归一化选择属于算法语义。 **6.98. 候选相关性.** 同一模型同一页面的28个候选共享高概率前缀，错误高度相关。有效探索数量远小于28。按候选编辑距离、结构树和错误类型聚类，可以测真正多样性。 提高温度增加多样性，也增加格式破坏。混合解码策略或在结构决策点增加探索可能更有效。候选数消融需控制相关性和总token，不只看名义数量。 **6.99. 在线分布漂移.** 策略更新后，旧候选来自先前分布。异步训练若使用过旧页面输出，优势估计偏离当前策略。长页面生成慢，复杂页延迟更大，可能被隐性降权。

记录生成策略版本和等待时间，按页面复杂度检查采样频率。限制策略延迟或重要性裁剪可以控制。系统吞吐选择可能改变有效训练数据分布。 **6.100. 合成难度控制.** 页面难度可由字符大小、栏数、表格复杂度、噪声和输出长度调节。若多个因素同时增强，无法知道模型缺陷。正交或分阶段设计能估计主效应与交互。 训练路由选择当前成功率居中的页面，容易页作回放，极难页先检查可读性。难度分数需要用模型表现校准，生成器参数本身不一定线性对应真实困难。 **6.101. 真实难度与合成难度映射.** 真实文档没有生成参数，可用可观察特征映射到合成空间：最小字高、布局块数、倾斜、噪声和表格span。若真实失败集中在合成未覆盖区域，生成器应扩展。

特征相近不保证语义和样式相近。最近邻可用于找候选，人工对照确认。合成数据服务假设实验，真实集始终是外部锚点。 **6.102. 结构单元测试的生成.** 从DOM遍历可生成断言：某标题存在、列表有几项、某单元格位于哪列、段落A先于B。随机抽断言能形成多样奖励，核心结构应强制覆盖，避免恰好未测试。 断言生成器自身需要测试，确认预期答案从渲染可见而非只存在DOM。CSS隐藏、裁切和重叠会破坏。保存断言与页面元素ID，便于失败回溯。 **6.103. 测试组合的逻辑.** 某些约束是合取：表格行数和单元格内容都正确才算表格可用；另一些可部分满足。简单平均隐含可替代性，一个错误可以被许多容易测试抵消。关键结构可设置门控或最低阈值。

门控奖励更稀疏，训练难度增加。早期用部分信用，后期提高完整约束，是一种课程。任何阶段变化都需记录，避免奖励曲线不可比较。 **6.104. 语义等价测试.** 输出结构解析后，可执行查询验证内容，例如表格某列求和、标题下包含指定段落。语义测试比字符串宽容，也可能漏掉未查询区域。查询集合的覆盖成为新边界。 随机生成查询并保留隐藏集，减少策略适配。自然语言查询评审又引入模型噪声，优先使用确定程序。无法程序化的结构交给人工或独立评审。 **6.105. 字符混淆矩阵.** 统计真实字符到预测字符的替换，可发现0/O、1/l、rn/m等视觉混淆，以及特定语言字形问题。频率需按真实字符归一，避免常见字主导。不同字体和分辨率分层更有诊断力。

语言先验会使混淆非对称：罕见词更常被改为常见词。随机串与自然文本矩阵对比，能分离视觉相似和语言纠错。数据增强针对真实高风险混淆。 **6.106. 数字与标点.** 数字占总体字符少，却在账单、表格和科学文档中关键。逗号、小数点、负号和千位分隔的错误可能改变数量级。通用CER权重不足。 单列数字串精确匹配、逐字符准确和上下文归属。公式中的减号与破折号视觉相似，Unicode规范化不能盲目合并。关键符号按文档类型定义。 **6.107. 空白与换行指标.** 忽略全部空白提高文本内容分数，却无法测段落、代码缩进和表格结构。原始空白编辑距离又会过度惩罚等价换行。将语义空白与排版空白分开处理。

解析为段落、列表和代码块后，在结构层检查换行；普通段落内部折行可归一化。规则依赖目标格式，必须公开。一个全局正则难以适合所有区域。 **6.108. 代码与缩进.** 文档中的代码块要求保留空格、换行和符号，语言纠错可能把合法罕见标识符改掉。代码区域应有独立协议和字符级严格指标，正文规范化不能套用。 语义执行测试可补充，但代码片段常不完整。语法解析率、缩进一致和标识符精确率更实用。合成HTML需正确标注pre/code区域。 **6.109. 引用与链接.** URL、DOI和参考文献编号字符密集，单个错误就失去可访问性。语言模型可能规范化URL或补全熟悉DOI，产生不存在链接。对这些字段使用完整串精确匹配与可解析检查。

访问链接不是稳定评测，网页会失效；字符串与校验规则更可复现。隐私场景可能需要遮盖，训练与评测协议保持一致。 **6.110. 幻觉修正的反例.** 原文故意包含拼写错误、旧式语法或矛盾数字，模型输出「正确」版本，对阅读更顺却不忠实。OCR目标通常要求转录，编辑目标才允许修正。两种任务不能混淆。 构造包含可见错误的页面，检查保真率。若系统面向无障碍阅读，可另加纠错层并保留原文链接。端到端直接修正会让证据不可追踪。 **6.111. 不可读区域的表示.** 当图像区域无法辨认，模型可输出特殊占位符，而非猜测。训练需要包含真实和合成不可读样本，并定义占位粒度。过度使用占位会提高保守性却降低召回。

覆盖率—关键错误曲线选择阈值。高风险字段宁可标不确定，普通正文可接受语言修复，策略由应用决定。单一准确率无法表达。 **6.112. 评测金标准的不确定性.** 真实文档人工转写也会错，复杂布局标注者可能不同意。双人独立标注、仲裁和一致度提供上限。把一个标注文件当无误真值，会将标注噪声计入模型错误。 对争议顺序可用部分序或多参考。字符争议保留图像裁片与标注分布。模型与单个标注不一致时，抽查高置信分歧能发现数据问题。 **6.113. 合成真值与真实真值.** 合成DOM真值精确，却只覆盖生成器表达空间；真实人工真值噪声更大，却代表真实页面。合成分数适合机制诊断，真实分数适合外部效度。二者不能用同一不确定性解释。

模型在合成接近满分、真实仍低，说明域差距；两者都低则基础建模或协议有问题。保持双轨评测比不断增加合成难度更清楚。 **6.114. 模板外推矩阵.** 按训练见过/未见内容与见过/未见模板构造四格。两者都见过测重现，两者都未见测最强泛化，交叉格分离语言与布局。再加入渲染器和字体是否见过，可扩展因素。 完整组合很多，可用分层采样。关键是分割单位在生成前确定，避免同一模板微调版本泄漏。模型平均分之外发布矩阵，才能知道泛化来源。 **6.115. 错误传播的非线性.** 一个标题层级错误可能使后续所有段落归入错误章节，单个字符错误却只影响一个词。下游损失对OCR错误不是线性的。结构与关键字段需要更高权重，权重取决于使用。

用固定下游管线测干预：人工注入某类错误，观察检索、问答或解析变化。剂量曲线帮助估计实际风险。自然模型错误常相关，单错误实验只是局部解释。 **6.116. 页面级与文档级聚合.** 页面微平均让长文档贡献更多页，文档宏平均让每本文档同权。某本大型扫描书的系统错误可能主导页面平均，也可能在文档平均只占一项。两者回答不同问题。 评测应保留文档ID，按文档簇bootstrap。多页表格和跨页段落只有文档级才能测。单页基准无法支持整文档结论。 **6.117. 来源级方差.** 同一出版社、扫描设备或模板的页面相关。把每页当独立会低估区间。按来源或文档簇重采样，区间更宽。来源数比页面数更接近泛化信息量。

若模型改善集中在一个大来源，宏平均可能高。来源留一法训练或评测能检查。未见来源表现是实际迁移的重要证据。 **6.118. 污染与语言先验的交互.** 评测文本进入预训练后，模型即使视觉模糊也能补全，污染收益在低质量图像上可能更大。仅在清晰页面比较污染组，会低估。按视觉质量与文本重合交叉分层。 反事实替换关键字段能检测记忆：相同模板和上下文中改一个清晰数字，若模型仍输出旧值，证据很强。训练重合分析与视觉冲突实验结合，才能解释。 **6.119. 尺度外推.** 训练多为单页短输出，部署可能是超长法律或财务文档。生成长度增加会放大循环、截断和顺序错误。单页准确率不能线性外推文档成功率；每页小错误会累积。

按页数和输出长度画文档完整通过率。若每页独立成功率为p，整本n页全对上界近似 $p^n$，很快下降，真实错误又相关。文档级审校仍必要。 **6.120. 模型容量与记忆.** 更大模型可能记住合成内容或真实训练文档，提升文本准确却弱化视觉依赖。模板外、内容外和随机字段评测随规模比较，能检测。只看总体分数会把记忆当泛化。 视觉遮挡下的输出概率也可作诊断。大模型若无图仍能复现评测段落，数据去重需加强。规模收益需要与独立内容绑定。 **6.121. 奖励与真实质量的校准.** 在冻结人工集上，将测试奖励分桶，计算每桶字符、结构和关键字段质量。理想情况下奖励越高，真实质量单调提高。若高奖励区仍含严重错误，测试覆盖不足。

校准随策略训练会漂移，需在多个checkpoint重复。奖励器未变，策略发现新漏洞后关联可能下降。监控相关性比只看训练奖励更早发现。 **6.122. 负结果的含义.** 某组件在总体分数无增益，可能对少数复杂表格有帮助，也可能因评测缺少该分布。先看目标子集和检测能力，再判断无效。反过来，小子集显著提升若样本少，也不能外推总体。 记录预算、seed、分项和区间，使负结果可复用。只保留最终组合会让组件贡献无法判断。开放研究的价值包含失败路径。 **6.123. 源文结果的外推边界.** 论文基准上的提升支持对应页面类型、分辨率、语言和输出协议。对手写、图内文字、跨页复杂表格和极低质量扫描，若未覆盖就保持未知。端到端得分也不能自动说明每个结构类别都改善。

方法层面最稳健的结论是：语义HTML可以规模化产生带结构测试的监督，可执行约束能够为在线优化提供比唯一字符串更灵活的反馈。效果大小仍依赖生成器覆盖、测试质量与真实域差距。 **6.124. 完整复现实验.** 复现先固定模型、渲染器、字体、页面尺寸、图像编码、提示与目标格式；验证少量DOM、截图、目标和测试一一对应。SFT后分别测内容、结构与协议，再运行固定预算GRPO，多seed保存检查点和候选。 最终在训练同源合成、未见模板合成、来源独立真实和压力集上评估。模型汤、动态温度分别消融。若各层趋势一致，才能把增益从测试适配扩展到真实文档解析。 **6.125. 交付物的可审计性.**

每个评测页面保存图像哈希、来源或模板ID、渲染参数、目标结构、单元测试、模型原始输出和解析结果。聚合表可由逐页记录重算，人工标签关联裁片和协议。 版本升级保留旧结果并发布桥接。这样研究者能定位某个提升来自模型、数据、渲染还是评分规则。结构化OCR本身追求把页面变成可用证据，评测也应保持同样的证据链。
