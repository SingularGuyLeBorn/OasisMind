# 为什么用扩散做语言生成

自回归语言模型把整句概率拆成从左到右的条件乘积.GPT,LLaMA,Qwen,Claude 都走这条路.训练时 teacher forcing 可以并行算损失,推理时却必须等第 $i-1$ 个 token 出来,才能算第 $i$ 个.扩散语言模型(Diffusion Language Model,DLM / dLLM)换了一种生成过程:先把整段序列弄成噪声或 `[MASK]`,再花若干步把它擦回可读文本,每一步可以同时改很多位置. 扩散语言模型的动机来自生成顺序与并行性的变化;转移矩阵和采样公式会把这种变化落实到具体概率过程.

## 1. 自回归卡住的三件事

自回归的联合分布是精确分解,没有变分近似:

$$
P_{\mathrm{AR}}(x)=\prod_{i=1}^{n}P_{\theta}(x_i\mid x_{<i}) \tag{1}
$$

这种分解把三个工程问题直接写进了生成结构.

### 1.1 解码是串行的

生成长度为 $n$ 的回答,至少要 $n$ 次前向.KV Cache 省掉了重复算历史 Key/Value,但省不掉「这一步必须等上一步」.投机解码,MTP,Medusa 都是在这个串行约束上打补丁:一次多猜几个,再验证.扩散走另一条路:时间维上的步数 $T$ 和序列长度 $n$ 解耦.$T$ 可以是 8,32,256,不必等于 $n$. 这不等于开箱即更快.开源的全双向扩散模型每一步都要对整段做注意力,没有原生 KV Cache;LLaDA 论文自己写明 8B 用 vanilla MHA 而不是 GQA,原因就是当时这套公式和 KV Cache 不兼容.商业侧的 Mercury Coder Mini 在 Artificial Analysis 的独立评测里到过单卡 H100 上 1109 tokens/s,相对当时的速度优化 AR 模型宣称最高约 10 倍吞吐.开源侧 LLaDA 2.0-flash 在作者自己的 dInfer 对照里,CAP 版 535 TPS,对照 SGLang 上的 AR 基线 256 / 237 TPS,大约 2.1 倍.速度是「可以并行」换来的潜力,并非每篇论文默认成立的倍数.

### 1.2 反转诅咒不只由因果掩码决定

式 (1) 要求位置 $i$ 只能看 $x_{<i}$.当训练语料主要以「A 是 B」的方向陈述事实时,从左到右目标不会直接训练「给定 B 预测 A」这个条件,因此测试时问「B 是谁」容易失败.因果掩码是结构因素之一,但反转诅咒还取决于语料陈述顺序,训练因式分解,以及共享参数能否把两个方向耦合起来;不能把它简化成"模型看不见右边"这一条原因. 双向掩码去噪移除了固定左到右的可见性限制:每个仍被盖住的位置都能读取两侧已揭开的上下文.LLaDA 在论文的诗歌反向补全任务上缩小了正反向差距,这是该设定下的实验证据,不是"双向注意力必然消除所有反转诅咒"的定理.

同一件事的正面用法是填空和改写.给定「床前______光」,自回归要么从左边硬续,要么把填空改成一套别扭的 prompt.扩散把要填的位置留成 `[MASK]`,其余位置当干净条件,一步里同时猜中间那几个 token.

### 1.3 软约束与全局约束更适合沿轨迹注入

自回归并非只能靠 RLHF 处理约束.关键词,正则表达式,JSON Schema,语法树等硬约束,可以用 trie / 有限状态机,token 屏蔽,beam search 或其他 constrained decoding 在解码时执行;提示与 logit processor 也能处理一部分格式要求.RLHF 更常用于偏好和行为分布,而不是每个硬约束的必经步骤. 扩散的优势在另一处:软属性,长程全局目标或可微奖励可以沿整条去噪轨迹反复注入.Diffusion-LM(NeurIPS 2022)把 token 映到连续嵌入空间,以便使用梯度引导;离散掩码扩散则发展出 CFG,能量校正和粒子转向.它们同样并非"任意约束免费满足":硬约束仍需专门的状态表示,掩码或采样器,并承担额外计算.

## 2. 图像扩散在干什么(只保留直觉)

图像扩散先约定一条前向过程:干净像素 $x_0$ 一步步加高斯噪声,直到几乎是纯噪声 $x_T$.反向过程学「从更噪的图退回更干净的图」.生成时从噪声出发,迭代 $T$ 步.每一步更新的是整张图,不是从左上角像素扫到右下角. 对已经会 LLM 的人,只需记住三句话. 第一,扩散模型通过一条去噪轨迹定义生成过程.联合分布写成隐变量积分,训练优化变分下界(ELBO);式 (1) 的自回归模型则用可精确求值的条件概率连乘. 第二,并行发生在「空间维」.图像是像素网格,语言是 token 序列.只要噪声定义在整段序列上,反向就能整段一起改.

第三,步数 $T$ 是测试时可以拧的旋钮.步数多,轨迹更接近训练时的反向过程,质量往往更好,更慢;步数少,快,但离散情况下容易出现位置之间互相打架.置信度揭示和 remask 都在处理这种少步冲突.

> 图 1:上行自回归每步只提交一个新 token;下行掩码扩散从全 `[MASK]` 出发,每步并行揭开若干位置.

### 图 1:逐 token 提交与并行揭示

- **上行 AR0→AR3**:条件一直是已经写出来的前缀.箭头上的 `+1 token` 是硬约束,不是实现偷懒.
- **下行 D0→D3**:一开始长度就定了(全掩码),每步 `unmask k` 可以 $k>1$.未揭开的位置继续当 `[MASK]`,已揭开的位置成为下一步的双向上下文.
- **两行不要对成「同样四步所以一样快」**.AR 的步数跟长度绑死;扩散的步数是超参.长度 128,步数 32 时,前向次数可以少于 128;长度 8,步数 256 时,反而更慢.
- **图里没画 KV Cache**.上行可以缓存历史;下行若用全双向注意力,每步都要重算整段.加速是另一些工作(块扩散,近似缓存)在补,不是掩码扩散免费附赠.

## 3. 语言为什么不能直接「加高斯」

像素是连续的,token 是词表上的离散 ID.`the` 和 `The` 的 ID 相邻,语义不必相邻;两个同义词的 ID 可以隔着一万号.高斯噪声假设的是欧氏空间里的小扰动,直接加在 ID 上没有物理意义. 于是出现两条路线.

| 路线 | 噪声定义在哪 | 反向结束时怎么回到 token | 代表 |
|---|---|---|---|
| 连续扩散 | token 嵌入向量,加高斯 | 去噪后再 rounding / argmax | Diffusion-LM,DiffuSeq,SSD-LM,CDCD |
| 离散扩散 | 词表上的马尔可夫转移 | 每步本来就在离散状态里 | D3PM,MDLM,SEDD,LLaDA,Dream |

![连续嵌入扩散与离散 token 转移两条语言扩散路线](images/fig-continuous-vs-discrete-dlm.png)

> 图 2:上行把离散 ID 抬到嵌入空间做高斯扩散,最终再量化回词表;下行用转移矩阵 $Q_t$ 直接在 token 上跳,主流实现是跳进吸收态 `[MASK]`.

### 图 2:连续扩散与离散扩散

- **上行 C1→C5**:embed → 加高斯 → 去噪 → rounding.中间态是向量,可以做梯度引导,这是 Diffusion-LM 可控生成的来源.代价是「向量空间里近」不等于「词表上合法」,rounding 会丢信息.
- **下行 D1→D4**:token 被 $Q_t$ 腐蚀成别的 token 或 `[MASK]`,Transformer 用双向注意力猜干净的 $x_0$,再按后验走一步到 $x_{t-1}$.没有二次量化.
- **2024 年以后的大模型几乎都走下行**.连续路线仍适合可微控制等场景;离散吸收态则与 BERT 式 MLM 共用交叉熵目标,扩展到 7B–100B 时更容易复用现有训练工具链.

D3PM(NeurIPS 2021)把转移矩阵写成三类:均匀跳到任意 token,吸收态 `[MASK]`,以及模仿高斯的近邻跳转.文本上吸收态最好用.MDLM(NeurIPS 2024,arXiv:2406.07524)再证明:吸收态加上合适的参数化,连续时间 ELBO 就是加权的 MLM 损失.LLaDA 把掩码比例 $t$ 从 0 到 1 随机抽,损失只在被掩位置上算交叉熵,并多一个 $1/t$ 权重.BERT 的固定 15% 掩码是这条公式在单步,固定噪声水平上的退化,不是扩散的全部.LLaDA 还把 1% 的预训练样本长度在 $[1,4096]$ 里随机抽,避免模型只会处理垫满的定长块.生成时长度仍是超参,短回答靠 `[EOS]` 截断,这和 AR 的「写到结束符就停」并非同一套动力学.

## 4. 2025 年之后为什么值得认真看

2021 到 2023 年的离散扩散大多停在 GPT-2 尺度,困惑度落后于同期 AR 模型.此后能否扩展为大模型,可以从参数规模、训练 token、下游任务和实际生成系统四项结果判断. **从头训到 8B.** LLaDA 8B Base 预训练 2.3T token,约 13 万 H800 GPU 小时.同一套评测协议下,MMLU 5-shot 为 65.9,对照 LLaMA3 8B Base 的 65.4;GSM8K 4-shot 为 70.3,对照 48.7;HumanEval 0-shot 为 35.4,对照 34.8.数据量是 LLaMA3 公开数字 15T 的约六分之一.Instruct 版只做了 450 万对 SFT,没有 RL,MMLU 65.5 对 LLaMA3 Instruct 的 68.4,GSM8K 69.4 对 78.3,HumanEval 49.4 对 59.8. **从 AR 权重改编.** Dream 7B 从 Qwen2.5 7B 初始化再做离散扩散.同协议 Base:MMLU 69.5 对 Qwen2.5 的 71.9,GSM8K 77.2 对 78.9,HumanEval 57.9 对 56.7;Sudoku 81.0 对 21.0.DiffuLLaMA 更早给出「改注意力掩码,用不到 200B token 把 GPT-2 / LLaMA 变成扩散」的配方.LLaDA 2.0 把这件事做到 16B(mini)和 100B(flash)的 MoE,用三阶段块级 WSD 把 AR 转成扩散,而不是从零堆 100B.flash 的 HumanEval 94.51,平均分 73.18,和 Qwen3-30B-A3B-Instruct-2507 的 73.60 同一档.

**吞吐被测到四位数.** Mercury Coder Mini 1109 tokens/s,Small 737 tokens/s(H100,Artificial Analysis).Google 的 Gemini Diffusion 是实验室演示,公开材料强调能边生成边改错,速度数字以官方页当时公布为准,不要和开源 LLaDA 的步数混成同一套基准.ByteDance 的 Seed Diffusion 走代码,H20 上报道过更高吞吐.这些数字的测试条件(批大小,长度,是否含 prefill)并不统一,只能当数量级,不能横着减. **块扩散把「必须定长,不能 KV Cache」这两条拆开.** BD3-LM(ICLR 2025 Oral)在块与块之间自回归,块内做离散扩散,于是长度可变,块间可以 KV Cache.Fast-dLLM v2 用大约 1B token 微调就把预训练 AR 改成块扩散,相对 Dream 那种数百 B token 的全注意力改编,数据量小两个数量级.

## 5. 不是替代,是另一种因式分解

扩散没有取消「建模 $P(x)$」这件事.它取消的是「必须按时间顺序一个一个乘出来」.代价也清楚:似然是界而不是精确值;长度要么预先垫 `[MASK]` / `[EOS]`,要么改成块扩散;生态(vLLM,投机解码,现成 RLHF 流水线)薄得多. 适合先建立的心理模型是下面这张表.数字只在有来源时出现,其余是机制判断. 读表时把「结构」和「2026 年测到的数」分开.填空,反转在结构上顺,不表示聊天总榜已经超过 GPT-4o.步数是超参,不表示开源权重默认比带 KV 的 AR 更快.ELBO 是界,不表示扩散的 PPL 可以拿来和 LLaMA 减.基础设施薄,不表示永远薄;Mercury 和 dInfer 已经在补,只是还没到 vLLM 那种「装上就能服务」.

一个具体的填空能把式 (1) 的结构差变成可感的.给定「床前______光」,自回归看见的条件只有「床前」.它随后可能写出「明月光」整串,也可能写出别的三字,空位对不齐时还需后处理.掩码扩散把中间两格留成 `[MASK]`,「床前」和「光」都是当前步的可见条件,双向注意力让「光」也能约束中间.优势来自因式分解允许右侧文本进入条件.同一机制在反向诗句上让下句约束上句;在数独上让整盘格子互相约束.

Mercury 的 10× 对应其公开运行时与测试协议.开源全双向模型每步重算整段注意力,缺少原生 KV;商业代码模型把并行解码和专用 runtime 一起做进产品,两者测量的是不同系统栈.更换因式分解会改变生成过程,吞吐、综合能力和对齐效果仍需在各自协议下分别测量.

连续路线和离散路线不能简化成「谁淘汰谁」.嵌入空间加高斯,换来的是可微约束;词表上引入 `[MASK]`,换来的是和 BERT 工具链兼容,以及 7B 以上的公开权重.2025 年的大模型主要采用离散路线,这反映了工程选择,并不表示连续方法的数学基础已经失效.需要对句法树施加可微约束、模型又只有几千万参数时,Diffusion-LM 仍有直接优势;目标若是与 LLaMA 比较 MMLU 等语言基准,掩码扩散更接近现有模型栈.图 2 给出了两条路线各自的状态空间与条件接口,连续论文中的 CFG 代码不能直接用于 LLaDA.

AR 能使用严格 KV Cache,因为已经写出的前缀保持不变;全双向扩散每揭开一些 token,其余位置的 Key 都可能变化.因此默认实现需要重算,而 DualCache 等近似方法和块间因果缓存会用额外约束换取复用. 图 1 的两行概括了结构差异:AR 每步增加一个 token,掩码扩散每步揭开 $k$ 个 token.$Q_t$ 和 ELBO 描述的正是下行过程如何定义噪声、训练反向条件并决定每轮更新.

反转诅咒有两类关键证据:Berglund 等人的反向查询失败,以及 LLaDA 诗句表中缩小的正反向落差.前者不能只归因于 causal mask,后者也不能只归功于双向注意力;数据顺序,目标因式分解和参数耦合共同作用.具体实验与机制见[双向注意力与反转问题](../4-联合依赖与结构设计/4.1-双向注意力与反转问题.md).

| 维度 | 自回归 | 扩散(当代掩码 / 块扩散) |
|---|---|---|
| 因式分解 | 精确连乘 | ELBO / 加权 MLM |
| 每步看见谁 | 左边前缀 | 当前未掩位置(双向) |
| 步数 | 等于新 token 数 | 超参 $T$ 或块数 × 块内步数 |
| 填空 / 反转 | 别扭 | 结构上顺 |
| 可控生成 | 提示或另训 | 轨迹上引导更直接 |
| 长文本 | 续写自然 | 全双向贵,块扩散在补 |
| 基础设施 | 极厚 | 2025–2026 才开始有专用框架 |

这一节形成三个结论.语言扩散要解决的是「token 上如何定义噪声」,不是把 Stable Diffusion 的 U-Net 套到句子上.主流大模型走吸收态掩码,因为目标函数长得像 BERT,但噪声水平从 0 到 1 随机抽,所以它是生成模型而并非固定 15% 的编码器.8B 以上能打,靠的是 LLaDA 这类从头训,Dream / LLaDA 2.0 这类改编,以及 Mercury 这类把并行解码推到产品吞吐的系统,而并非 2022 年那批小模型的故事.

这套知识库沿同一条机制链组织:02 处理 $Q_t$、加权 MLM 与采样后验,03 对照模型演进和规格,04–05 分析联合结构与训练迁移,06 进入缓存、调度和部署,07 区分机制能推出的结论与截至 2026 年的系统结果.不同材料的数字冲突时,应回到论文表与实验协议,不能把 27.6× 当成对 AR 的统一倍速,也不能把小模型句法实验外推到 8B.

Dream 7B 的同协议表把规划题上的结构差别画得很清楚:Sudoku 81.0 对 Qwen2.5 7B 的 21.0,Countdown 16.0 对 6.2.这不是吞吐卖点,是「多约束要同时改」时从左到右难以回头.诗歌反向则是另一把刀:LLaDA Instruct 42.4 对 GPT-4o 的 34.3,正向却是 48.8 对 82.7.两张表放在一起,扩散在规划和反向条件上的长处与常规生成上的差距都会显出来.词表转移矩阵 $Q_t$ 则给这些现象提供具体的概率过程.

结构上允许并行不等于现有实现已经获得更低延迟.串行是 AR 写进结构里的;更快还取决于硬件、调度器以及是否全双向计算.Mercury Mini 的 1109 和 2.0-flash 的 535 证明潜力存在,LLaDA 8B 原文没有速度表,因此不能把前两者的速度写成 8B 的规格.因式分解改变之后,步数 $T$ 不再必须等于 $n$,但这句话并不自动验证任何一张 tokens/s 表.

连续路线与离散路线解决不同问题,不能按单一先进程度排序.连续嵌入能把图像那边的梯度引导搬过来,Diffusion-LM 在 80M 上证明句法树约束可以写进轨迹.离散吸收态能把训练循环收成加权 MLM,所以 7B–100B 走这条.两条路回答的问题不同:一个问约束能不能变成梯度,一个问大词表上噪声如何可观测.2025 年能叫 LLM 的开放权重走离散,不是因为梯度过时了,是因为交叉熵和现成工具链对接成本更低.要注入句法树,连续那条河还在;要训 8B,离散那条河才有检查点. **训练目标相同不代表生成算法相同.** 许多掩码模型都使用交叉熵:

$$
\mathcal L=
\mathbb E_{t,x_0,x_t}
w(t)\sum_{i:x_t^i=m}
-\log p_\theta(x_0^i\mid x_t).
$$

差别藏在 $x_t$ 怎样采、$w(t)$ 如何选、网络是否输入时间、推理如何从 posterior 构造转移.BERT、MDLM、RADD 与 LLaDA 的表面 loss 接近,概率路径并不相同. 自回归交叉熵有精确 chain likelihood;扩散交叉熵通常来自 ELBO、score 风险或 endpoint prediction.将两个训练 loss 数值直接比较没有意义,常数项、权重与每 token reduction 都不同. 从研究角度,需要分开问三件事:网络能否预测被遮 token,这些预测能否构成正确反向动力学,有限步 sampler 能否接近该动力学.第一项做好仍可能在后两项失败. **速度的理论单位不是 tokens/s.** AR 生成 $n$ 个新 token 至少有 $n$ 个依赖层,扩散用 $T$ 个去噪轮,结构串行深度从 $n$ 变成 $T$.若 $T\ll n$,存在并行潜力. 每轮工作量不同.AR 有 KV Cache 后一步主要处理一个 query 与历史 cache;全双向扩散一步处理整段 $n$ 个位置.粗略注意力量级可写成

$$
C_{\mathrm{AR}}\sim n^2d,\qquad
C_{\mathrm{diff}}\sim Tn^2d
$$

在朴素实现下扩散总 FLOPs 反而更高,只是 $n$ 个位置能在矩阵运算中并行.硬件吞吐、batch 和内存带宽决定 wall time. 块扩散将块数、块长和块内步数组合,缓存已完成块.它在串行深度、并行矩阵尺寸和 KV 复用间取中间点.所以「步数比长度少」是必要证据之一,不是完整加速结论. 质量--延迟前沿应在同一硬件、相同长度、batch、精度和终点任务上测.tokens/s 还会受一次输出多少 token 的计数方式影响,需要同时给首 token 延迟与总完成时间.

**全局约束分成三类.** 第一类是可编译语法,如 JSON、括号与正则.有限状态机、grammar mask 或解析器可以严格执行,AR 与 diffusion 都能接.扩散的任意位置更新让约束传播更复杂,未必天然占优. 第二类是跨位置一致,如实体复用、数独行列或代码变量.这些约束需要多个位置协调,逐步左到右若早期承诺错会难回头;允许 remask 的画布有纠错空间.并行独立更新也可能同时制造冲突.

第三类是软语义,如风格、帮助性或全局 reward.它们通常只能由分类器、能量或 verifier 评分,可沿多步轨迹反复转向.搜索越强越可能利用 reward 漏洞. 「扩散适合全局约束」主要指后两类拥有整段状态和可修订轨迹.严格保证仍取决于约束表示与 sampler,不能从双向注意力直接推出.

**纠错能力需要可逆动作.** 全双向网络每步能看到整段,并不等于已经写出的 token 会被改.纯吸收反向链只从 MASK 到 token,提交后不可逆.这时 diffusion 只是选择提交顺序,错误仍会永久保留. remasking、uniform corruption 或显式 edit kernel 才提供回退边.加入回退后,过程可从错误完整草稿回到部分未知状态,再重采样.代价是更多事件、可能振荡和更难的终点分布分析. 商业演示中的「边生成边改错」应对应实际可逆 sampler 或块重写,不能只由训练目标推断.论文若只报最终文本,还需轨迹日志证明修改发生. 纠错也依赖检测.模型对错误 token 过度自信,低置信 remask 不会选中它.独立 verifier、ensemble 分歧或约束冲突能提供额外信号.

**并行性的真实来源.** 前向 corruption 按位置独立,让训练能一次构造整段噪声.Transformer 一次前向输出所有位置 logits,让计算图具备空间并行.采样器一次提交多个位置,才把这种并行变成更少 NFE. 第三步同时引入条件独立近似:

$$
p(x_B\mid x_S)
\approx\prod_{i\in B}p(x_i\mid x_S).
$$

若块内条件总相关高,少步质量下降.并行依靠共享上下文估计各位置边缘,同时接受有限的块独立误差;它从未假设 token 互不相关. 下一轮重算能把已提交 token 纳入上下文,逐步修复依赖.步数越多,每块越小,近似越接近逐个链式生成.速度--质量曲线本质上由块联合误差与 NFE 权衡形成. **五个仍未解决的研究问题.** 第一,怎样学到高质量联合 block transition,避免边缘乘积成为少步瓶颈.能量、AR copula、块内因果与 shared latent 都在探索. 第二,怎样选择 reveal/remask 顺序.局部置信度便宜,信息增益与长期 value 更合理却昂贵.训练顺序分布与部署 policy 还存在偏移.

第三,怎样在全双向更新中获得真正可用的 cache.块因果牺牲跨块修订,近似 cache 牺牲精确 hidden state,两者都需测质量损失. 第四,怎样做长文本与可变长度.固定画布、EOS、动态插删与层级块各有概率语义,还没有像 AR EOS hazard 那样统一的默认答案. 第五,怎样把后训练与推理控制接到 diffusion.偏好优化、RL、CFG、reward guidance 和粒子搜索都可用,训练稳定、成本与 reward hacking 边界仍需系统比较.

**反例决定动机能说多远.** 若数据 token 独立,一次并行生成已经精确,diffusion 多步没有优势;AR 串行只是选了不必要的分解.若序列所有位置由同一个 latent bit 决定,边缘并行会生成非法组合,逐步条件或联合 latent 必不可少. 若任务只能左到右获得外部环境反馈,如工具执行结果下一步才返回,双向预填未来位置没有真实条件.扩散可以在每轮环境之间优化块,不能消除交互轮次.

若硬约束能由 DFA 精确执行,AR constrained decoding 已足够,扩散的软轨迹不构成必然优势.若 reward 只在完整文本可见,早期 guidance 也未必比 best-of-n 更有信息. 这些反例让动机回到合适范围:扩散改变了因式分解和可修订画布,为并行、任意条件与轨迹控制提供新接口;具体优势由依赖结构、约束可见性和 solver 决定. **一条更准确的阅读主线.** 先问状态空间:连续 embedding、categorical token 还是 MASK 吸收态.再问前向路径如何破坏信息,网络预测 score、$x_0$ 还是 flow. 接着问反向一步能改哪些位置、是否可回退、块内是否独立.这三项直接决定并行和纠错语义.

然后看训练权重与推理路径是否对应,高 NFE 上限和低 NFE gap 各是多少.最终才读吞吐、缓存和产品数字. 沿这条线,扩散语言模型不再是「把图像扩散搬到文本」,而是一族在离散序列上重新选择概率路径、因式分解和求解器的方法.

### 6. 概率结构、速度边界与研究问题

### 6.1. 自回归的精确性来自链式法则

对任意联合分布:

$$
p(x_1,\ldots,x_L)
=\prod_{i=1}^Lp(x_i\mid x_{<i}).
$$

如果每个条件都精确,连乘就是精确联合,无需隐变量积分或变分界.自回归模型的概率语义清楚,代价是生成依赖深度等于长度. 训练时整句已知,causal mask 让所有位置的 next-token loss 一次并行计算.teacher forcing 的并行与自由生成的串行并不矛盾:前者给出真实前缀,后者必须先采出前缀. 扩散没有推翻链式法则.它引入中间噪声状态

$$
p_\theta(x_0)
=\sum_{x_{1:T}}
p(x_T)\prod_{t=1}^T
p_\theta(x_{t-1}\mid x_t),
$$

将生成依赖放到去噪时间.每个 $x_t$ 是整段画布,一步可更新多个位置.终点 likelihood 需要对中间路径求和,训练通常优化 ELBO.

### 6.2. 掩码扩散的独立性放在哪里

吸收式前向过程按位置独立:

$$
q_t(\bm x_t\mid\bm x_0)
=\prod_iq_t(x_t^i\mid x_0^i).
$$

这使加噪、采样训练 batch 与解析 posterior 可计算.它没有假设自然语言 token 独立.相关数据通过共享 Transformer 的条件预测进入反向模型. 网络一次输出每个 MASK 位置边缘:

$$
p_\theta(x_0^i\mid\bm x_t).
$$

当 sampler 同步提交集合 $B$,常进一步采用

$$
p(x_B\mid x_S)
\approx\prod_{i\in B}
p_\theta(x_i\mid x_S).
$$

真正的并行收益来自这一步:一轮前向后提交多个 token.它也是真实联合被近似的位置.只说「双向注意力并行」会漏掉最关键的概率代价. **条件总相关量化并行损失.** 真实块联合与边缘乘积的 KL 为

$$
D_{\mathrm{TC}}(X_B\mid X_S)
=D_{\mathrm{KL}}\left(
p(X_B\mid X_S)
\middle\|
\prod_{i\in B}p(X_i\mid X_S)
\right).
$$

$|B|=1$ 时为零.固定短语、变量复用和校验关系让它增大;条件在足够上下文后近似独立的 token 可安全并行. 少步意味着每步平均提交更多位置,块联合维度更大.质量下降并非「去噪网络没看懂语言」这一种原因,也可能是边缘都对、独立组合错. 增加步数使新 token 逐渐成为后续条件,降低每块总相关.联合 proposal、块内 AR、能量重排与 remask 则尝试在相同步数下减少这项误差. **一个两位反例.** 目标只含 00 与 11,各半.全 MASK 下两个位置边缘都是 Bernoulli$(1/2)$.独立并行采样得到 00、01、10、11 各四分之一,一半样本非法. 逐步生成先抽第一位,第二位条件在第一位上:

$$
p(X_2=X_1\mid X_1)=1,
$$

便精确恢复目标.网络边缘在第一步没有错误,错误来自同步随机数相互独立. 共享一个 latent bit 也能一步生成正确联合.所以「并行必然失败」也过强;需要能表达块联合的随机耦合.普通逐位置 softmax 没提供它.

### 6.5. 去噪轨迹为何提供纠错接口

AR token 一旦输出,标准解码不会回头修改.可以用编辑模型、搜索或回滚扩展,但不属于基本链式 sampler.扩散的画布天然保留未知位置,每轮能重新评估全局. 纯吸收反向过程已揭示 token 也可能固定,仍不自动纠错.remask 或可逆 categorical kernel 才允许撤销.因此纠错能力由状态表示与转移边决定,不只由双向 attention 决定. 允许回退后,错误局部可以重新变成 MASK,再条件在其他新信息上生成.若模型对错误过度自信,置信度 remask 仍可能漏掉;全局 verifier 或约束冲突提供额外检测. 回退增加路径活动量和 NFE,还可能反复振荡.速度、可逆性与稳定性形成新的权衡.

**全局约束何时真的受益.** 约束能在部分状态上提前判断时,多步轨迹可不断剪枝或引导.数独行列冲突、括号可达性、实体一致都能在中间画布提供信号. 约束直到完整文本才可判断时,早期 guidance 缺少信息.终点 rerank 或 best-of-n 可能同样有效.若能学习 value

$$
V_t(x_t)=
\mathbb E[r(X_0)\mid X_t=x_t],
$$

才可把终点 reward 提前到每一步. 硬语法适合自动机或解析器,直接将非法边概率置零.软语义适合 classifier、energy 或 particle weighting.混用二者会让有限强度 reward 留下硬违规尾部. **训练目标为何像 MLM 又不是 BERT.** BERT 固定约 15% mask,优化特定 corruption 下的条件交叉熵.扩散从近乎干净到全 MASK 覆盖完整噪声路径,时间权重来自 ELBO 或 score 风险. 线性吸收日程下常见

$$
\mathcal L=
\mathbb E_t
\frac1t
\mathbb E_{x_t\mid x_0}
\sum_{i:x_t^i=m}
-\log p_\theta(x_0^i\mid x_t).
$$

$1/t$ 配合 mask 事件概率,平衡不同生成阶段.实现若对 MASK 求平均、截断端点或换日程,权重需同步解释. 全 MASK 状态训练模型无条件起步;轻 mask 状态训练最终修补.固定 15% 不覆盖两端,所以编码器检查点直接自由生成会分布外.

**6.8. 任意顺序是扩散的另一种读法**

随机 mask 条件对应任意可见集合.逐个揭示时,模型可以先生成任何位置:

$$
p(\bm x)=
\prod_k
p(x_{\sigma_k}\mid x_{\sigma_{<k}}).
$$

真实联合下任何排列都相等.神经条件有限且可能不一致,实际生成分布会依赖顺序策略. 低 entropy 顺序、左到右、边界向内和 learned planner 都在选择路径.一次揭示多个位置又加入块独立近似.remask 后路径甚至不再是排列,而是在 mask set 上带回边的游走. 任意顺序解释填空和反向能力,不保证任意顺序都同样好.训练覆盖是能力基础,推理策略决定兑现方式. **ELBO 的含义与边界.** 引入前向路径 $q(x_{1:T}\mid x_0)$ 后:

$$
\log p_\theta(x_0)
\ge
\mathbb E_q
\left[
\log\frac{
p(x_T)\prod_tp_\theta(x_{t-1}\mid x_t)}
{q(x_{1:T}\mid x_0)}
\right].
$$

gap 是前向路径 posterior 与模型生成路径 posterior 的 KL.训练 bound 改善通常有利于 likelihood,不等于有限步 sampler 样本质量同比改善. 吸收参数化可将 bound 化成加权 MLM,计算方便.推理换成少步、置信度并行或 remask 后,部署过程可能不再严格等于训练反向链. AR exact NLL 与 diffusion NELBO 不能直接当同一口径数字相减.外部生成 PPL、MAUVE 和任务准确率又是另外对象.

**6.10. 步数是求解精度,也是联合预算**

时间连续模型定义理想反向率,有限 NFE 用 Euler、tau-leaping 或其他 solver 近似.步长过大漏掉区间内多次事件,形成数值误差. 语言序列中,减少步数还会增加每轮提交 token 数,形成并行联合误差.两种误差同时随 NFE 变化,不能只用 ODE solver 直觉解释. 高 NFE 曲线平台近似模型上限;低 NFE 与平台差是 solver 与并行 gap.若平台本身低,继续加步无用;若平台高而少步差,改 schedule、联合 sampler 或校正器更直接.

**6.11. 速度必须拆成串行深度和总工作量**

AR 串行深度约为输出长度 $n$;diffusion 为 $T$.这决定潜在并行性.总 FLOPs、显存访问和每步矩阵尺寸决定实际成本. 全双向模型每步重算 $n$ 个位置的 attention,AR KV Cache 每步只加入一个 query.扩散 $T<n$ 仍可能 FLOPs 更高,硬件并行使 wall time 更低. 块扩散将已完成块固定并缓存,降低重复计算;代价是跨块不能任意修改.近似 cache 保留更多自由,hidden state 过期会带来质量损失. 任何倍速都要写硬件、batch、长度、prefill、decode 和质量工作点.不同论文 tokens/s 不能直接相除. **长度为什么是结构问题.** AR 用 EOS hazard 自然决定停止时间.全 MASK diffusion 通常先设最大画布长度,再预测 EOS 与 padding.提前 EOS 和后方 token 的联合必须一致. 长度采样可以独立建模:

$$
p(\bm x)=p(L)\,p(x_{1:L}\mid L).
$$

也可以让 EOS 进入画布联合.前者清楚但需长度预测器,后者灵活却让任意顺序生成 EOS 变复杂. 块扩散按需增加块,恢复可变长度.它将长度决策放到块间 AR 过程,块内继续扩散. **连续嵌入路线的优势与误差.** 连续路线把 token 映到 $z_0=E(x_0)$,加高斯后学习连续 score.梯度 guidance 与图像方法容易复用. 终点要 rounding:

$$
\hat x_i=\arg\min_v
\|z_i-E(v)\|^2.
$$

潜空间小移动跨过 Voronoi 边界会突然换 token;平均向量可能不对应任何词.连续质量与离散文本质量之间多一层量化误差. 嵌入欧氏距离也并非语言天然几何.它由训练得到,近邻可能语义相似、句法不可换.连续控制的便利与 rounding 偏差同时存在.

**6.14. 离散路线为何更容易扩到大模型**

状态始终是 token 或 MASK,网络输出词表分类,能复用 tokenizer、Transformer 与交叉熵训练.没有最终量化层. 吸收前向核结构简单,只需随机 mask;clean posterior 可时间无关.这些性质降低了训练接口复杂度. 代价是离散跳转没有连续梯度,控制与少步 solver 需要概率比、CFG、能量或搜索;并行块联合也更显眼. 大模型采用离散路线是当前工具链与扩展证据的结果,不是数学上证明连续路线劣等.

**反转诅咒的三个因素.** 第一是训练数据方向.语料只写 A→B,反向证据少.第二是目标因式分解.左到右 loss 直接监督 $p(B\mid A)$,不直接监督 $p(A\mid B)$.第三是参数共享能否从语义表示迁移. 随机 mask 会直接产生 B 可见、A 被遮的样本,补上第二项.如果数据没有足够事实或模型容量不足,仍不会自动成功. 反向诗句、反向事实查询与反向推理难度不同.单个 benchmark 的提升只能支撑对应条件结构.

**6.16. 自回归也能填空和约束**

Fill-in-the-middle 将前缀、后缀和中间重排成 AR 可训练格式;编辑模型可迭代修改;constrained decoding 可执行 grammar.这些方法证明能力并非 diffusion 独占. diffusion 的区别是任意位置未知与多轮修改写进基础生成过程,无需为每种洞形重新线性化.是否更好取决于训练分布与系统成本. 公平比较要让 AR 使用合适的 FIM、搜索与约束基线,让 diffusion 计入全部 NFE 与 verifier 调用. **三个失败反例.** 第一个是 00/11 联合.准确边缘加一步并行仍失败,说明并行不是免费. 第二个是不可提前预测 reward.若属性只由最终一步随机位决定,中间 guidance 没有信息优势,只能增加终点样本数. 第三个是硬约束支持被剪掉.唯一合法 token 在 top-k 外,后续任何 remask 或 guidance 都无法恢复.支持问题优先于搜索强度.

**研究结果应怎样读.** 先看模型规模、训练 token、初始化与是否后训练.从头训和 AR 改编回答不同问题. 再看采样步数、块大小、remask、长度与 cache.同一 checkpoint 的成绩可因 sampler 大幅变化. 然后看速度协议和质量点.只比最快设置可能牺牲准确率;只比最高质量可能使用远多于长度的步数. 最终看指标归属.NELBO、外部 PPL、任务分数与人工偏好没有可互换的统一刻度. **一组可证伪的研究问题.** 给定相同参数与数据,任意顺序目标能否稳定提高 infill 而不损失 continuation?给定相同高 NFE 上限,哪种路径在少步下降最慢? 块内条件总相关能否预测某轮并行失败?基于该量的自适应块是否优于置信度?

可逆 remask 的收益来自纠正错误,还是额外 NFE?用相同调用数的不可逆基线可验证. 缓存近似误差在何种 mask 变化下可控?长文本时速度优势能否维持同质量前沿? 这些问题都能设计受控实验,比笼统争论「扩散是否取代 AR」更有信息. **两条概率分解的误差位置.** AR 近似误差进入每个条件 $p_\theta(x_i\mid x_{<i})$,自由生成后早期错误改变后续前缀,形成 exposure bias.概率连乘本身仍归一. Diffusion 误差进入反向 kernel,沿时间累积.若 kernel 按位置因子化,还包含真实联合到边缘乘积的结构误差.有限步 solver 再加入数值和并行误差. 因此两者都可能误差传播,传播图不同.AR 沿 token 位置,扩散沿噪声时间与空间块.比较「能否回头」时要看具体 kernel 是否允许回边. **反向 kernel 为什么一般不因子化.** 前向 corruption 虽按位置独立,数据 $p_0(\bm x)$ 含语言依赖.反向 posterior

$$
q(\bm x_{t-1}\mid\bm x_t)
\propto q(\bm x_t\mid\bm x_{t-1})p_{t-1}(\bm x_{t-1})
$$

继承 $p_{t-1}$ 的联合.两个 MASK 对应固定短语时,它们恢复值相关. 网络共享上下文能给准确单位置 marginal,不能让逐位置独立抽样等于 joint.多步条件更新可逐渐兑现依赖,少步要显式联合. 这是离散语言比连续图像更尖锐的一点:token 组合合法性常是离散的,不存在「半个正确短语」平滑过渡. **Forward corruption 的作用.** 前向过程用于构造可采样训练状态与有解析关系的路径,无需真实模拟语言变坏.好的 corruption 应连接数据和简单先验、让 posterior 可学、让 reverse solver 可执行. 吸收 MASK 明确标记未知,可见 token 可靠;uniform corruption 全支持且可逆,可见 token 可能是假;embedding Gaussian 提供连续梯度,需 rounding. 噪声核改变任务难度和归纳偏置.不存在只靠同一网络架构比较就能消掉的差异.

**6.23. Score、$x_0$ 与 flow 是三种接口**

离散 score 学状态概率比,与前向率相乘得到反向率.$x_0$ prediction 学干净 token posterior,通过解析公式转成反向转移.Flow matching 直接学实现指定概率路径的速度. 无限容量下某些参数化可互换,有限训练时动态范围、损失权重与一致性不同.看到相同词表 logits,还要问它在公式里代表哪一个对象. 参数化决定训练稳定和可解释性,solver 决定这些输出如何变成样本.二者不能合并成「都是去噪」. **为何大模型能力不只看 perplexity.** 外部生成 PPL 偏向流畅常见文本,可能奖励模式收缩.NELBO 衡量概率界,不直接等于有限步输出质量.任务准确率还受 prompt、长度和 verifier. 扩散的结构优势更容易在 infill、Sudoku、编辑与反向补全显示;通用聊天还依赖预训练数据、后训练和工具生态.

同一论文应同时给 likelihood 类指标、生成覆盖和任务结果.单一数字很难判断改进发生在哪层. **质量随步数并非必然单调.** 理论精确 kernel 用更细时间网格通常降低 solver error.实际模型在某些噪声层误差大,多走这些层可能累积偏差;remask 过多也会破坏正确 token. 采样温度、提交比例与步数常联动.步数增加若仍每轮大批提交,不等于更细近似.最终强制填充也可能让高步设置和低步设置共享一次粗跳. 应画完整 NFE 曲线并固定其他规则,不要用两个点推断单调定律.

**6.26. 速度—质量前沿如何公平构造**

每种方法扫步数、块长、并行度和 cache 设置,得到质量对延迟的 Pareto 前沿.在相同质量比较速度,或相同延迟比较质量. AR 基线应启用成熟 KV、continuous batching 与合适 speculative decoding;diffusion 应启用其官方 sampler 与 runtime.弱基线会夸大结构收益. 输出长度必须一致.扩散预分配 4096 画布却只返回 128 token,内部工作量不能按返回 token 数忽略. **可变计算是扩散的重要自由度.** 同一 checkpoint 可对简单 prompt 少步、困难 prompt 多步.可用 entropy、残留冲突或 verifier 决定停止. AR 也能用思考 token、搜索和投机改变计算,只是基本 next-token 链长度随输出固定.扩散将求解精度本身暴露为旋钮. 自适应停止依赖可靠难度信号.模型错误而自信时会过早结束;保守阈值则让大多数样本走满预算.

**画布提供非单调生成顺序.** 生成标题、结论或关键实体后再填过渡句,符合先骨架后细节的写作过程.任意顺序模型在概率上允许这样做. 是否真的采用这条顺序取决于 sampler.随机或低 entropy reveal 未必先生成语义骨架;显式 planner 或层级 latent 才能稳定实现. 「扩散会先规划再写」不能从模型类别推出,需要轨迹证据. **中间状态可见也可能带来风险.** 若系统流式展示去噪草稿,中间状态可能含错误、敏感或不完整内容.最终安全不代表路径安全. AR 流式同样会展示前缀,但已展示内容通常不撤回.扩散若修改已显示 token,用户界面需要处理闪烁与承诺变化. 路径安全可作为约束或只展示稳定区域.这会减少可逆自由或增加延迟.

**后训练为何更难直接复用.** AR SFT 与 preference learning 建立在 token logprob 连乘和 causal sampling 上.扩散的 log probability 可能是 ELBO,采样轨迹有多个顺序与步数. 序列 reward 要分配到哪些 denoising 步、如何计算 policy ratio、旧新 sampler 是否同路径,都需重新定义. 可以在 clean posterior 上做 SFT,用 reward guidance 避免改参数,或蒸馏 AR 对齐数据.各自只解决后训练的一部分. **数据效率的解释要谨慎.** 某扩散模型用更少 token 达到相近 benchmark,可能来自数据质量、初始化、评测协议和训练算力差异,不能全部归因于目标函数. 随机 mask 每条序列提供多个位置监督,AR teacher forcing 同样每条序列提供所有 next-token 监督.不能简单按「预测所有 MASK」宣称更多标签. 真正差异是条件集合分布和 loss weighting.受控 scaling law 才能比较数据效率.

**6.32. 从 AR 权重改编为何可行**

causal Transformer 已学到 token embedding、局部语法与知识.改成双向 mask 后继续训练,可以复用这些表示,再学习新条件形状与 diffusion 目标. 注意力掩码变化会让隐藏状态分布改变,不是零成本转换.模型还需适应全 MASK 起点、任意位置输出与多步自由生成. 转换所需 token 量取决于块结构、初始化和目标.不同工作数字不能脱离设置横比. **双向 attention 的收益与成本.** MASK 位置可读取左右所有已知 token,适合 infill 与反向条件.同一轮所有位置表示相互依赖,任一 token 更新都会改变整段 hidden state. 这破坏标准前缀 KV 的不可变性.重算成本随长度与步数增长.块因果、稀疏 attention 或近似 cache 在能力和复用间折中. 双向是条件接口选择,并非 diffusion 的唯一架构.因果网络也可训练 permutation objective,块内也可采用 AR.

**长上下文放大哪种瓶颈.** 长度增加时,全双向每步 attention 成本增长,同一步并行更新位置数也增加,联合误差更重.固定 T 的少步优势与这两项同时变化. 分块降低计算和联合维度,跨块依赖需通过缓存上下文或高层计划.块太小接近 AR,块太大接近全局 diffusion. 长文本评价应看实体一致、章节结构与完成时间,短 benchmark 不能覆盖这些失败. **Hard constraint 的支持问题.** 目标合法集合 $C$ 条件分布为

$$
p(x\mid x\in C)
=\frac{p(x)\mathbf1[x\in C]}{P(C)}.
$$

若基础模型对全部合法序列实际零支持,任何有限 guidance 都无法创造它.词表、top-k 和提前剪枝会造成这种零. 自动机约束可在每步保留仍有合法 completion 的边.掩码画布没有固定前缀,需对部分赋值做可达性传播. 硬约束与软 reward 的区别先于模型类型.

**6.36. Reward guidance 的收益与漏洞**

指数倾斜

$$
p_\lambda(x)\propto p(x)e^{\lambda r(x)}
$$

给推理控制统一概率解释.扩散可在多个噪声层估未来 reward 并转向. reward 不准时,更多步和搜索会更稳定地利用漏洞.属性分数上升、独立质量下降是典型信号. 独立 holdout reward、反事实样本和预算曲线必须随控制结果报告. **采样路径的可识别性.** 相同终点分布可由许多去噪路径实现.只观察最终文本,无法判断中间是否真的规划、纠错或绕圈. 若论点依赖轨迹机制,需记录 token 首次提交、重掩次数、顺序和约束分数变化.否则只能声称终点结果. Flow matching 中相同边缘路径也可有不同环流,活动量与 solver 难度不同.路径是额外建模选择. **一个小空间实验足以拆开四层.** 用两位二元序列枚举真实 joint、前向 corruption、反向 posterior 与有限步 sampler. 先用 oracle kernel 测 solver,再用模型 marginal 测联合误差,加入 remask 测纠错,最终加 reward 测控制.

每层状态只有少数几个,可精确算终点 KL.大模型结果之前先过这组测试,能避免将实现错误解释成规模效应.

**6.39. 为什么不会立刻替代 AR**

AR 有精确 likelihood、成熟训练、KV Cache、流式接口与后训练生态.其串行性也被 speculative decoding、MTP 和硬件优化持续缓解. Diffusion 提供新的能力面,同时背负多步全序列计算、长度、联合近似与生态成本.它更可能先在代码编辑、约束生成、填空和高吞吐 batch 中建立优势. 模型范式竞争最终看完整质量—成本—控制前沿,不是单个结构口号.

**6.40. 为什么仍值得投入**

并行解码是语言模型最重要的结构性难题之一.扩散让串行深度不再硬等于 token 数,即使当前总 FLOPs 仍高,研究空间已经打开. 任意位置条件与可修订状态也对应真实任务:代码补丁、文档编辑、规划填槽和受约束设计都不是纯续写. 从理论上,离散 score、flow、任意顺序和联合 sampler 把生成概率学中的新问题集中到一个平台,不仅是在现有 AR 上做运行时优化. **读论文时的五个追问.** 第一,前向噪声和状态空间是什么.第二,网络输出的概率对象是什么.第三,一次采样提交多少位置、是否可回退. 第四,训练目标与部署 sampler 是否同一过程.第五,速度数字在什么质量、长度、硬件和 cache 设置下得到. 这五问能过滤大部分含糊叙事,也能把不同工作放到同一坐标系.

**连续时间与离散步数不要混为一谈.** 训练可定义连续时间 $t\in[0,1]$,网络在任意噪声层预测反向对象.部署选择 $T$ 个网格点,只是数值近似. 论文说 continuous-time 不表示采样无需离散步骤;说 32 steps 也不表示训练只见 32 层.时间参数化和求解网格是两项配置. 改变 schedule 会把困难区间压缩或展开.相同 T 在不同时间坐标下不是同等精度,应比较实际路径误差. **为什么 mask ratio 已经透露时间.** 独立 masking 下,长度 $L$ 的 mask 数

$$
M\sim\mathrm{Binomial}(L,t).
$$

$M/L$ 在长序列上集中于 $t$,所以网络可从输入图案估计噪声层.这解释某些吸收模型不显式输入时间仍能工作. 短序列方差大,相同 mask 数也可能对应不同真实 $t$;位置相关 schedule 与 span mask 更让比例不足以描述噪声.是否加 time embedding 仍是可验证选择. RADD 更强的结论来自 clean posterior 解析上与 $t$ 无关,不只因为网络能猜时间. **终点 prior 必须足够简单.** 前向末端若达到全 MASK,先验是确定状态,生成起点容易.均匀 corruption 的先验可为词表均匀,也容易采. 前向时间有限而未完全混合时,$p_T$ 仍依赖数据.直接用简单 prior 会产生 initial gap.训练再好也无法完全弥补起点不匹配. 因此要检查 $\alpha_T$、残留干净 token 概率和实际初始化.全 MASK 是吸收路径的一个工程优势.

**反向时间的方向错误很隐蔽.** 前向从数据到噪声,生成从噪声到数据.有的论文令 $t=0$ 是数据,有的令 $t=0$ 是源.同一个 $\alpha_t$ 导数符号会相反. 代码 loss 正常下降不保证采样方向正确.两状态或单 token 解析例子应验证边缘从 prior 回到数据. 导论读公式时先标端点,再看 rate 和 step index,避免仅凭「reverse」名称理解. **低噪声与高噪声学习不同能力.** 高噪声时上下文少,模型学习词频、主题先验和全局计划;低噪声时上下文多,模型学习局部修补、语法一致与精确 token. 训练权重决定容量如何分配.高 mask loss 数值可能大但每个 token 信息少;低 mask 样本少却对最终细节关键. 按噪声层报告 conditional accuracy 与 calibration,比总体 masked accuracy 更能解释自由生成失败.

**生成长度与步数的四种比例.** $T=1$ 是一次 NAT 式生成,并行最大、联合误差最大.$T\approx L$ 且每步一 token 接近任意顺序 AR. $1<T<L$ 是扩散最关注区域:有限轮并行提交.$T>L$ 可能包含 remask、空时间步或可逆编辑,总调用超过 AR 长度. 所以「扩散步数可小于长度」是能力,不是定义.具体 checkpoint 可在不同区域工作. **每步更新数也应单独报告.** 相同 T 可采用均匀提交、前慢后快、前快后慢或置信度自适应.每步实际更新数

$$
k_t=|S_{t-1}\setminus S_t|
$$

决定并行程度和联合误差. 只写 32 steps 不足以复现.最终一步若一次填几十个位置,质量瓶颈可能集中在那里. 轨迹图应同时画 mask count、remask count 与 entropy,才能看 schedule 在做什么. **置信度揭示为何常有效.** 边缘尖锐的位置通常有较低单 token 错误率.先提交它们可给其他位置增加可靠上下文,形成 easy-to-hard curriculum. 若置信度校准差,错误高置信 token 会成为早期锚点.重复、固定模板和训练泄漏也会制造虚假高置信. 校准、ensemble disagreement 和约束检查可改善顺序信号,代价是额外前向或 verifier. **从后验采样还是取 argmax.** 每个位置按 posterior sampling 保留多样性,argmax 降低局部随机错误但趋向模式.温度控制只改变边缘,不修块联合. 早期高噪声 argmax 容易让所有样本走同一常见模板;后期 argmax 更像确定性修补.时间相关温度需要单独调.

比较模型时固定 sampling temperature 与 top-k,否则质量差可能来自解码策略. **Remask 的置信度来源.** 可用当前 token probability、margin、entropy、前后步一致性或 verifier score决定重掩.这些量回答不同问题. 高 token probability 只表示模型在当前上下文自信;上下文本身错误时仍可能自洽.前后步波动能发现不稳定,无法发现稳定错误. 外部约束能发现特定冲突,覆盖之外仍依赖模型.多信号组合应测各自贡献. **一致性约束与语言质量.** 全局一致包括实体、数值、时态、格式和论证结构.它们作用范围不同,单一「global score」会混合. 实体复制可精确测,事实一致需知识核验,论证质量需要更复杂 verifier.扩散在轨迹上反复读取全局,效果仍由评价信号决定. 展示成功案例之外,应报告约束数量增加时的成功率曲线.多个约束交集可能让基础支持迅速变小.

**扩散并不自动拥有规划变量.** 全 MASK 到文本的多步过程看起来像粗到细,网络训练却只预测干净 token,没有显式提纲监督. 早期 token 可能形成隐式计划,也可能只是高频词.要证明规划,可干预早期揭示 token,观察后续结构变化,或加入可解释 latent. 层级 diffusion、先 outline 后正文和 block planner 是把规划结构明确写进模型的方向.

**代码生成为何是重要试验场.** 代码有强语法、远程变量依赖、测试反馈与编辑需求,适合检验全局约束和纠错.同时 AR 代码模型、FIM 与 grammar decoding 已很强. 扩散可同时填多个 hole、根据测试 remask 片段;并行独立也容易生成变量不一致.代码成功率比文本流畅更能暴露联合问题. 比较时要固定 pass@k、采样数、测试调用和输出长度.吞吐快可在同时间生成更多候选,这是系统优势,应与单样本质量分开. **数学与逻辑任务的边界.** 中间步骤常有顺序依赖,先生成结论再补证明未必容易.任意顺序能力不等于任意推理顺序都有效. 可逆画布允许修改早期计算,对算术 carry、变量替换有潜力.若 verifier 只在终点给对错,搜索信号仍稀疏.

应分析轨迹是否纠正了具体步骤,而非只用最终准确率推断「全局推理」. **编辑任务与无条件生成不同.** 编辑给出大部分可靠文本,只需修改局部.初始状态已接近目标,低噪声 denoising 是模型强项,步数可少. 无条件生成从全 MASK 开始,早期 posterior 多峰,联合和规划更难.编辑上的成功不能直接外推到从零写长文. 训练要覆盖真实编辑噪声:删除、替换、移动与指令条件.纯随机 mask 只覆盖其中一部分. **多模态扩散的接口不同.** 图像和文本共同 diffusion 可共享时间路径或分别腐蚀.文本离散、图像连续,两边 score/rate 单位不同. 多模态条件可让图像作为固定上下文生成文本,也可双向共同更新.后者联合状态更大,同步依赖更难. 语言 diffusion 的动机不能直接用图像生成质量证明,状态空间和 decoder 不同.

**数据污染与 benchmark 仍然存在.** 换成 diffusion 不会消除训练集泄漏、答案模板和 benchmark contamination.双向填空甚至可能更容易利用题面固定格式. 反转测试要确保反向问法未在训练出现,否则无法隔离因式分解.代码测试要去重仓库. 模型范式研究仍需常规数据审计. **Scaling law 需要哪几条轴.** 至少扫描参数量、训练 token、序列长度与采样计算.扩散还有步数和 mask schedule 两条轴. 同训练 FLOPs 下,更多噪声层任务会不会降低样本效率?同推理 FLOPs 下,并行是否换来更高任务吞吐?这些需受控 scaling. 单个 8B 对 8B 结果只能给一个工作点,不能推出渐近趋势. **评估并行能力的合成任务.** 00/11 测最小联合,Shuffle 测全局排列,括号测 grammar,数独测多约束,复制测远程一致. 改变一次提交数,观察 exact success 与条件总相关关系.使用 oracle posterior 可隔离 solver,模型 posterior 可加入学习误差.

合成任务不能替代自然语言,能提供机制证据. **评估纠错的实验.** 在中间画布主动注入错误 token,记录模型是否识别、何时 remask、最终是否修复.分别注入低置信与高置信错误. 纯吸收 sampler 应无法修改已固定 token,可逆 sampler 才有恢复通道.这能验证「纠错」是否真实存在. 再控制额外 NFE,与从头重采样或 best-of-n 比较,判断纠错是否高效. **评估全局控制的实验.** 选择可精确判定约束和软属性各一组.硬约束测合法率与空支持,软属性测内部 reward、独立 reward、质量和多样性. 扫 guidance scale 与步数,画 Pareto.若内部分上升、独立分下降,是 reward hacking;若只有更多样本才提升,中间 guidance 价值有限. 记录约束何时首次满足、是否后来破坏,能看轨迹控制机制.

**概率校准为何重要.** 置信度 reveal、remask、early stop 都依赖概率可靠.过度自信会早提交和早停止,欠自信会反复重掩. 按噪声层和 mask shape 测 calibration,总体 ECE 会被容易状态主导.自由轨迹状态还可能偏离训练分布. 温度缩放改变 sampler 行为与终点分布,不是纯展示修正. **训练状态与自由轨迹的偏移.** 训练 $x_t$ 来自真实文本加噪,可见 token 总是彼此兼容.自由采样会拼出训练中罕见组合,网络在这些状态上外推. 少步并行一次制造的偏移更大.后续双向网络虽可看到冲突,未必知道怎样恢复. 可比较 teacher-forced noisy states 与 free-running states 的 loss、entropy 和 ensemble 分歧.

**On-policy 训练的代价.** 将模型生成中间状态加入训练可改善自由轨迹鲁棒性.标签从何而来是难点:原干净文本未必是该错误状态的唯一合理修复. 继续用原 $x_0$ 作目标会强迫模型返回特定样本,可能忽略其他合法 completion.使用 reward 或 verifier 又引入代理偏差. 混合真实前向状态与 on-policy 状态是折中,已改变原 ELBO. **蒸馏少步 sampler.** 多步 teacher 能产生高质量轨迹或终点,学生学习用更少步模仿.蒸馏将 solver 计算转移到训练. 学生可拟合 teacher 终点、跨步 transition 或 consistency map.目标不同,似然与模式覆盖不同. 蒸馏不会消除联合难题,它让学生从 teacher 样本学习某种联合近似.训练成本和 teacher 偏差也被继承.

**Diffusion 与 speculative decoding.** AR speculative 由 draft 提议多个 token,target 验证以保持 target 分布.加速依赖高接受率,仍沿前缀. Diffusion 并行更新无需同样接受拒绝,近似 sampler 可能改变模型分布.也可为 diffusion 设计 proposal/verification,目标与成本另算. 两者都用更多并行计算减少串行深度,概率保证与适用结构不同. **硬件会改变最优算法.** GPU/TPU 擅长大矩阵并行,所以一次处理整段可能 wall time 友好;batch 小、长度短时 kernel launch 与重算占比不同. 内存容量限制粒子、长画布和 KV cache.高带宽硬件可能偏好 cache-heavy AR,强算力硬件可能偏好 recompute diffusion. 算法前沿不是脱离设备的单一排序.理论串行深度仍是跨硬件的重要指标.

**能耗与成本也要计入.** 低延迟不一定低 FLOPs或低能耗.扩散把大量位置计算并行压进短时间,功耗和总算力可能更高. 服务成本取决于吞吐、batch 利用、显存与请求长度分布.单请求速度纪录不能代表每百万 token 成本. 未来部署比较应同时给 latency、throughput、energy 或 GPU-seconds. **开放权重与可复现性的意义.** 商业速度展示证明产品潜力,无法替代权重、sampler 和协议公开.开源模型便于检查中间轨迹、NFE 与质量边界. 大模型 diffusion 仍年轻,不同实现术语和计数不统一.保存配置、checkpoint、生成日志与硬件环境尤其重要. 研究结论优先落在可复现表格,宣传数字只作为存在性证据.

**一个统一的路径视角.** AR 可看成状态每步追加一个 token 的 Markov 链;mask diffusion 是状态在 mask set 格上移动的链;编辑模型允许 token 替换、删除和插入. 三者差别来自状态图和 transition,并非「有无概率」.固定前缀图是一棵树,任意 mask 图有多条路径到同一终点,可逆编辑图还有循环. 路径越多,控制与纠错选择越丰富,likelihood 边缘化和缓存越难.这是结构自由与计算复杂度的共同来源. **状态图决定可达性.** 若某种编辑不在图中,再强网络也不能执行.纯吸收反向不能改已揭示 token,固定长度图不能插入新位置,grammar pruning 可能断开合法路径. 设计 sampler 前应检查源到目标支持是否连通.小空间可枚举,大空间用构造性路径或约束求解验证. 「模型知道答案却生成不出」有时正是 transition graph 限制,不只解码温度问题.

**路径数量与 likelihood.** AR 每个终点对应唯一 token 顺序时,路径概率等于终点概率.任意顺序 diffusion 同一文本可由许多 reveal 顺序与 remask 轨迹得到. 终点概率是所有路径概率之和:

$$
p(x_0)=\sum_{\tau:\tau\to x_0}p(\tau).
$$

路径数指数甚至无界,精确求和困难.ELBO 用已知前向路径绕开,代价是界. **前向过程不是推理时真的先破坏文本.** 训练用前向 corruption 从数据构造监督;生成直接从 prior 运行反向,不会先拥有一篇正确文本再删掉. 将 diffusion 描述成「先写完整答案再逐步显示」会误导.网络在高噪声端只持有分布,没有隐藏的确定答案. 轨迹中 token 改动是随机生成过程,并非揭开预先存在的 ground truth. **$x_0$ prediction 的多峰问题.** 全 MASK 对应海量可能句子.逐位置 $x_0$ posterior 给每格 marginal,其组合均值可能不属于任何自然句子. 多步采样让早期随机选择形成模式,后续条件收缩.一步 argmax 易拼接不同模式的局部高频 token. 共享 latent、联合块或粒子保留多个全局模式,都在处理多峰而非普通分类误差.

**粒子方法为何适合全局目标.** 维护多条去噪轨迹,按中间 value 或终点 reward 重采样,可避免单轨迹早承诺. 粒子数增加搜索覆盖,也产生祖先贫化与 reward hacking.同一祖先复制很多次不等于多种语义方案. 与 AR beam 类似,粒子方法用推理计算换质量;扩散画布提供不同的分支动作. **Beam、MCTS 与 diffusion 的关系.** beam 在前缀树保留高分路径,diffusion 状态不是唯一前缀,不同动作顺序可能到达相同画布. MCTS 可选择先填位置、是否重掩和调用 verifier,高维状态很少重复,树复用有限. 只求最高 reward 时搜索可有偏;要从目标分布采样时需重要性校正.研究结论要先说明目标.

**为什么局部流畅不够.** 语言评估器常对 n-gram 与局部句法敏感.并行模型可生成每段都顺、实体互相矛盾的文本,外部 PPL仍不错. 长程复制、变量绑定、时间线和论证依赖需要专门指标.全局机制的证据也应来自全局任务. MAUVE 等分布指标补充覆盖,不能自动定位约束失败. **多样性与质量的交换.** 增加 guidance、降低温度、argmax reveal 常提高单项准确,减少模式.扩散多步并不自动更有多样性. 应分别测表面 distinct-n、语义簇、成功条件下覆盖和祖先多样性.只看一种指标容易被改写噪声抬高. 最优设置取决于交付一个答案还是候选集合.

**模型能力与 sampler 能力.** 高 NFE、逐 token 或强搜索结果接近模型能力上限;默认少步结果是 sampler 与模型共同产物. 同 checkpoint 的多 sampler 曲线可判断改模型还是改解码.只报默认点会把两者混合. 模型比较也要统一 sampler 强度,否则更高 NFE 可掩盖弱模型. **学习顺序与学习内容会互相影响.** 若 planner 总先选容易位置,token 模型收到的 on-policy 状态偏向这些路径,困难顺序能力退化. 联合训练时策略改变状态分布,token loss 改变策略置信,形成反馈.冻结一方可做机制消融. 均匀 mask replay 保留覆盖,代价是部分训练计算不服务默认 policy.

**约束交集可能为空.** 用户要求严格 JSON、固定长度、包含若干互斥内容时,合法集合可能为空.任何生成范式都只能违反部分约束. 采样前静态检查可编译约束;语义约束至少用候选探测交集.全零粒子权重或所有 token 被屏蔽是不可满足信号. 继续增大 guidance 不会创造合法交集. **Reward 与数据支持.** 倾斜分布

$$
p_\lambda(x)\propto p(x)e^{\lambda r(x)}
$$

只在 $p$ 的支持内重分配.基础模型从未学会正确代码结构时,推理控制难以创造能力. SFT 可先扩大目标区域概率,再用 guidance 精调.训练与推理控制解决不同层次. **先验长度错误会怎样.** 长度预测过短,目标内容没有位置;过长,模型需生成 EOS 与后缀一致,还浪费计算. 任务分数对 truncation 敏感时,不能只调 denoising steps.长度 oracle 可作为上界,分离内容模型与长度模型误差. 块扩散用逐块停止降低一次长度预测压力,仍要学何时结束. **Streaming 是独立产品要求.** AR token 生成即可展示,天然低首 token 延迟.全画布 diffusion 可能在若干步后才有稳定文本. 展示中间 token 会被修改,需要 UI 支持;只展示稳定块则引入块边界和等待. 总完成时间快不代表首屏体验好.报告吞吐时应补 TTFT 与稳定输出延迟.

**安全过滤发生在哪一层.** 输入过滤、训练对齐、中间 guidance、终点审核和服务策略是不同防线.扩散可在轨迹中介入,也多了中间状态攻击面. 硬禁词可屏蔽,语义安全需 classifier 或 verifier.中间暂时出现违规若不展示,与最终违规风险不同. 安全结论需要红队与独立评估,不能从可控生成公式直接推出. **训练算力与推理算力的搬运.** 更强 diffusion 训练可以让少步 posterior 更准,蒸馏把多步 teacher 计算搬到学生训练.搜索则在每个请求追加计算. 固定高频任务适合训练摊销,低频动态约束适合推理控制.成本应按生命周期计算. 「训练一次、推理更快」还要计转换与蒸馏数据生成.

**研究基线的最低要求.** 概率基线包括同尺寸 AR、同 checkpoint 高步 diffusion、一步 NAT 与逐 token任意顺序.系统基线包括 KV AR 和官方优化 runtime. 约束任务要有 grammar AR、best-of-n 和终点 rerank.纠错任务要有 AR 编辑或 self-refinement. 只有赢过对应强基线,才能把优势归到 diffusion 接口. **可复现日志应包含什么.** 保存初始 prior、每步 mask set、token posterior、提交/remask 动作、随机种子、终点裁剪与 verifier 分数. 这些日志可重放失败、测顺序与并行误差.只有最终字符串无法验证轨迹论点. 同时保存 NFE、模型调用、实际更新数和 wall time,防止成本漏记.

**对「并行推理」的准确表述.** 一次 Transformer 前向同时计算多个位置 logits,属于算子并行;一次 sampler 提交多个 token,属于生成并行;多个候选 batch 同时运行,属于请求并行.三者不能混用. AR 也有算子与请求并行,缺少的是同一序列新 token 间的生成并行.扩散真正改变的是第三项的依赖深度. 论文吞吐可能来自大 batch 请求并行,未必来自单序列少步.应给 batch=1 与多 batch 曲线. **对「全局建模」的准确表述.** Transformer 双向 receptive field 让每个 marginal 读取全局;joint 是否全局正确还取决于多位置随机耦合. 模型看见所有 token 不等于一次输出捕获它们的联合.00/11 反例在全局可见下仍成立. 更准确的说法是「提供全局条件边缘与迭代协调接口」,而非自动得到全局最优文本.

**对「可编辑」的准确表述.** MASK infill 允许在固定其余文本时生成空洞.修改已有非 MASK token 需要先把它纳入 editable set 或使用替换核. 局部编辑若影响全篇,固定其余 token 会阻止一致性修复;扩大 editable set 增加计算与意外改写风险. 编辑能力由用户指定保护区、可变区与约束传播共同定义. **对「更像人类写作」的证据要求.** 先大纲后正文、反复修改听起来像人类写作,但模型轨迹相似只是类比.证明需要中间状态的结构分析与干预. 若早期 token 被改动不影响最终结构,它们不是计划;若强制不同提纲导致系统性不同正文,才有更强证据. 机制类比可帮助理解,不能替代实验. **与能量模型的关系.** 联合能量

$$
p(x)\propto e^{-E_\theta(x)}
$$

同样能读完整序列并支持编辑,归一和采样困难.扩散用时间路径把复杂采样拆成多个局部 transition. 能量可作为 diffusion residual 或 guidance,修正独立 proposal 的联合.代价是每步额外打分与权重退化. 两者关系比「判别式和生成式」更紧:diffusion sampler 可视为某类时间依赖能量运输. **与 MaskGIT 一类迭代生成的关系.** MaskGIT 也从 mask 画布迭代填 token、按置信度保留.核心直觉与 masked diffusion 接近. diffusion 工作强调已定义的前向过程、反向概率和训练界;迭代 masked modeling 可能以启发式 schedule 训练/采样. 网络和可视化相似不表示 likelihood 语义相同.比较时看 corruption、权重和 transition. **与 denoising autoencoder 的关系.** 去噪自编码器从腐蚀样本恢复干净数据,单个噪声水平不一定定义完整生成链. 扩散把许多噪声层按 Markov 路径组织,并规定从 prior 反向到数据.这使 denoising 变成生成.

BERT 类比的边界也在这里:会修补局部不等于会从纯噪声生成. **选择连续还是离散路线.** 需要可微 latent reward、状态本来连续或小模型控制实验,连续路线方便.需要大词表、复用 MLM 与避免 rounding,离散路线直接. 任务可能混合:离散 token 主链加连续 hidden guidance,或连续 latent 产生草稿再离散校正. 选择取决于控制接口、规模、likelihood 与部署,不靠年份排序. **选择全局还是块扩散.** 全局双向画布拥有最强跨位置修订,每步成本和长度限制最重.块扩散恢复缓存和可变长度,跨块顺序固定. 任务以局部代码块、段落或流式输出为主时,块结构自然;全局 puzzle、短序列 infill 更适合全局画布. 块长应随依赖范围和硬件扫 Pareto,不存在通用最佳值.

**选择多少步.** 先测高步上限,再从低步逐渐增加.若质量很快平台,选拐点;若持续提升到高步,模型或联合 sampler尚未支持激进并行. 困难样本可自适应追加步,简单样本早停.要给平均与尾部 NFE,防止少数请求拖慢系统. 步数选择与温度、remask 和最终强制填充联动,应联合调参后固定协议. **一个端到端概率流程.** 训练先抽干净文本 $x_0$,抽时间 $t$,按前向核得到 $x_t$,网络预测 clean posterior 或 score.损失只看被腐蚀位置并乘时间权重. 生成从 $p_T$ 抽全 MASK 或噪声,网络输出反向对象,sampler 选择位置和 token,循环到 $x_0$.每个环节都可能有近似. 评测得到的是「checkpoint + sampler + runtime」的结果.只报 checkpoint 名称不足以定义模型行为.

**模型误差和求解误差的实验分离.** 固定 checkpoint 扫 NFE,高步平台反映模型与训练上限.使用 oracle posterior 的小任务扫 NFE,反映 solver 本身. 若 oracle 少步也差,先改联合/solver;若 oracle 好、模型差,改训练和参数化. 这种分离比同时换 architecture、schedule 和 sampler 更能产生可迁移结论. **全局约束与局部修补的冲突.** 局部概率最高的 token 可能让全局约束无解.逐位置 confidence 不能看到所有组合. 约束传播、联合搜索或保留多候选能避免早期死路.扩散的回退边提供修复机会,不保证发现死路. 硬约束优先时,合法性应进入 transition;软质量再在合法集合内优化.

**流式反馈下的 diffusion.** 工具或用户反馈在生成中途到来时,可将新信息写入画布并继续去噪.这比从头生成有潜力. 旧 token 是否允许修改、已展示内容是否撤回、缓存是否失效,都要定义.外部反馈轮次仍是串行. 交互式编辑可能是扩散比纯一次性生成更自然的使用形态. **不确定性可以驱动计算.** 位置 entropy、样本间分歧和 verifier variance 可指示哪里多花步数.低不确定区域冻结,高不确定区域继续更新. 不确定性要校准.分布外错误常高置信,只靠 entropy 会漏掉.ensemble 与约束残差更稳,计算更贵. 自适应计算的收益应与额外估计成本一起测.

**模式覆盖与轨迹覆盖.** 终点有许多文本模式,轨迹也有许多 reveal/remask 路径.不同路径可能汇入同一终点模式. 粒子数多、轨迹表面不同不表示语义覆盖高.记录终点语义簇与祖先谱系,才能知道搜索在探索什么. argmax 和强 guidance 常压缩两种覆盖,换来更稳定单答案. **少步训练是否必要.** 标准训练覆盖连续噪声层,少步推理是 solver 选择.若少步 gap 大,可对跨大时间间隔的 transition 蒸馏或 consistency training. 学生直接学习 $x_t\to x_s$ 大跳,绕过多次小步误差.大跳 posterior 更复杂、联合性更强. 少步专训改善默认速度,可能损害任意步数可调性.应保留 teacher 上限对照.

**评价研究问题的优先级.** 先解决概率正确性:状态、支持、反向公式与小空间测试.再解决模型能力:高步上限.随后压步数、加缓存和控制. 若高步模型仍弱,优化 runtime 只会更快地产生差答案;若 oracle solver 已暴露联合问题,继续扩大边缘网络收益有限. 按这一顺序推进能减少工程数字掩盖机制缺陷. **什么叫「同等计算」.** 一次 AR forward、一次全序列 diffusion forward 与一次 verifier 调用成本不同.NFE 只在单模型结构相近时可比. 更完整的预算包括去噪器 FLOPs、串行深度、额外 reward、候选数和通信.硬件 wall time 是最终结果,机制分析仍需这些分项. 训练计算也可能不同.从 AR 改编、从头预训练和少步蒸馏不能只按参数量对齐.

**什么叫「同等质量」.** 任务准确率相同不表示文本质量、格式合法和多样性相同.速度比较应选择多指标均可接受的工作点. 代码可用 pass@1 与 pass@k,问答可用 exact match 与人工质量,开放生成需覆盖和重复率.约束任务还要合法率. 若一个方法靠生成极短答案提高吞吐,长度与完成度必须纳入. **失败样本比平均分更能说明结构.** 扩散特有失败可能是多个位置各自合理、组合冲突;AR 常见失败是早期错误一路延续.二者都可能重复、幻觉和格式错. 按失败类型归类,再追踪中间状态,才能验证预期机制.只看平均 benchmark 很难区分. 展示成功的反向诗句之外,还应看模型在哪些条件方向仍失败.

**开源研究最值得保留的资产.** 除了权重,前向噪声代码、loss reduction、采样器、默认 schedule、速度脚本和生成轨迹同样关键. 同名 checkpoint 用不同 sampler 可差很多.只开放模型而缺解码配置,结果难复现. 离散 diffusion 正在形成生态,统一配置与指标会比再造术语更有价值. **一个务实的选型原则.** 纯续写、低延迟 streaming、成熟对齐与工具生态优先时,AR 仍是稳妥默认.任意位置编辑、强约束协调、批量吞吐或研究并行生成时,diffusion 值得尝试. 混合结构常比二选一现实:块间 AR 保长度和 cache,块内 diffusion 做并行与修订;AR 草稿配 diffusion editor;diffusion 提议配 verifier. 选型以任务依赖、延迟目标和约束接口为准,不以模型名称决定.

**从信息流看两种模型.** AR 的信息流随生成前缀单向增长,每个新 token 成为永久条件.扩散的可见集合可以从少到多、按任意位置增长,可逆 sampler 还可缩小. 信息流自由使模型能利用右侧条件和全局画布,也让缓存、终止和 joint 路径更复杂.这是一体两面,不能只取能力描述. 画出状态图比记住模型名更容易判断某个任务是否受益. **从优化看两种模型.** AR teacher forcing 的每个位置条件与部署前缀形状一致,内容可能因自由生成偏移.扩散训练覆盖多噪声状态,部署少步策略又可能产生训练未见的组合. 两者都有 train--test shift,来源不同.AR 是真实前缀与模型前缀,diffusion 还包含 mask shape、并行提交和 remask policy. 扩散训练更广的条件集合可能提高鲁棒,也把容量分散到更多任务.

**从控制看两种模型.** AR 控制可在每个前缀屏蔽 token、搜索或调用 verifier,概率接口成熟.扩散可在整段中间状态上反复评分,更适合不绑定前缀的属性. 约束可局部判定时 AR 很强;约束需要修改早期位置时可逆画布更自然.终点才可判定时二者都依赖搜索或 value. 控制优势来自可用状态与动作,不是「扩散」三个字. **从科学问题看价值.** 离散 diffusion 迫使我们重新问:语言 joint 能否被少量并行条件更新逼近,联合依赖集中在哪些位置,什么顺序最适合暴露条件结构. 这些问题即使最终服务于混合模型,仍会反哺 AR 的 speculative decoding、编辑和规划.研究价值不只取决于单榜胜负.

**一篇论文至少应回答什么.** 模型学的概率对象、训练路径、默认 sampler、步数质量曲线和真实速度协议是最低信息. 若声称纠错,给修改轨迹;声称全局一致,给依赖敏感任务;声称加速,给同质量 wall time;声称 likelihood,给界或估计口径. 缺少其中一项,结论应缩到现有证据支持的范围. **一个最小判断框架.** 任务若只需稳定续写,先用成熟 AR.若需要固定左右边界填空、反复编辑或多处约束,再检查 diffusion 的条件接口是否更自然. 接着用高步 sampler 确认模型能力,再压步数.高步都做不好时,少步优化没有可靠上限;低步掉得快时,测块总相关和 solver. 最终评估全成本与生态.模型可行、runtime 不可用,仍不适合上线;runtime 极快、质量工作点不够,也只是潜力.

**把动机落到可验证命题.** 「可以并行」应验证同质量下串行深度下降;「可以纠错」应验证已提交错误被识别并修改;「更适合全局约束」应验证约束数量增加时成功率下降更慢. 「任意顺序」应验证前缀、后缀与洞形条件;「更快」应给端到端时间;「大模型可用」应给公开任务与训练协议.每个口号都能改写成实验.

这样讨论 diffusion 时,既不会把结构潜力当成现成功能,也不会因当前 runtime 不成熟否定概率接口本身. 真正值得追踪的是这些命题随模型规模、序列长度和推理预算怎样变化.短序列上的并行收益能否延伸到长上下文,小模型的联合误差会不会随规模下降,可逆采样是否能在固定成本下稳定修复错误,都需要连续证据. 导论的任务就是把问题摆准:扩散提供新的生成图和计算路径,论文与实验负责说明这条路径在具体任务上是否值得走. 后续每一章都会沿这组问题继续拆解,而不是只比较模型名称. 这些记录也能直接复核每项结论的适用范围与证据强度.

**结论落在生成过程上.** 语言扩散值得研究,因为它把生成从固定前缀链改成整段状态上的迭代过程.这个变化带来空间并行、任意位置条件和可修订轨迹. 收益不自动成立.并行提交需要近似块联合,纠错需要可逆边,全局约束需要中间可预测信号,速度需要硬件与 cache 配合. 真正有意义的比较单位是完整的路径、训练目标、条件参数化、sampler 与运行时,模型标签的信息量反而有限.理解这五项以后,每一张榜单才知道在证明什么.
