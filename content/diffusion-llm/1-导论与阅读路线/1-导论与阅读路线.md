# 扩散语言模型:导论与阅读路线

语言生成长期由自回归条件链主导，因为 next-token prediction 的训练目标直接、似然可计算，因果注意力又能配合 KV Cache 增量解码。扩散语言模型保留 Transformer 的表示能力，却把生成改写为多轮去噪：多个未知位置可以在一次前向中同时得到候选，后续步骤继续修订。这个变化第一步是概率与状态定义的变化，速度、可控性和双向推理是需要分别验证的结果。

本章建立进入该领域所需的坐标：比较自回归与扩散各自提交答案的方式，区分连续嵌入扩散、离散词表扩散和掩码吸收态，并把机制承诺、论文实验和当前工程实现分开。这样阅读模型报告时，吞吐不会被误写成数学性质，某个采样器的失败也不会被扩大成整个范式的失败。

## 先建立三条边界

1. **机制边界**:自回归模型固定按条件链逐步提交;扩散语言模型在一条噪声—数据路径上反复修订多个位置.两者都能使用 Transformer,但概率因式分解,训练目标和缓存条件不同.
2. **证据边界**:论文表格只证明指定模型,采样器,长度,批量,硬件和实现下的结果.NFE,token/s,首 token 延迟和端到端延迟不是同一指标.
3. **版本边界**:2025–2026 年许多工作仍是预印本或单一代码库结果.正文会给出版本与核验日期,不把作者主张写成领域共识.

## 自回归参照系

自回归模型把联合概率分解为从左到右的条件概率乘积。第 $i$ 个 token 依赖前面已经提交的 $i-1$ 个 token，因此生成长度为 $L$ 的序列至少经历 $L$ 次顺序决策。KV Cache 避免重复计算旧位置的 key 和 value，使每一步只处理新增 token；成熟的 continuous batching、量化与投机解码又继续降低服务成本。这些能力构成扩散系统必须面对的工程基线。

顺序提交也带来明确边界。后面的证据无法修改前面已经输出的 token；固定全局约束往往要通过搜索、拒绝采样或外部校验实现；训练时常见的 teacher forcing 与推理时使用自身历史之间存在分布差异。这些边界并不说明自回归模型不能处理对应任务，而是说明额外能力通过何种机制获得。

### 去噪生成改变的状态

掩码扩散把序列状态写成干净 token 与未知标记的组合。前向过程按时间 $t$ 增加掩码比例，反向模型在给定 $x_t$ 与时间条件下预测原始 token。一次前向可以为多个掩码位置给出分布；采样器决定哪些预测在本步提交、哪些继续保持未知，以及是否把低置信位置重新掩码。生成顺序因此成为调度结果，而不是固定的从左到右规则。

并行位置通常由因子化输出头分别预测。若两个位置存在强联合约束，各自边缘概率很高的 token 组合起来仍可能冲突，这就是联合依赖问题。增加去噪步数可以逐步传递信息，块扩散可以限制同时生成的范围，能量修正或规划器可以直接建模位置间耦合。第 04 章集中处理这些结构选择。

### 三类结论分别核验

机制结论来自模型定义，例如吸收态把被腐蚀位置变成可观察事件，双向注意力允许同一步中的未知位置共享上下文。实验结论来自具体检查点和协议，例如某个 7B 模型在指定基准上的准确率。系统结论则依赖采样步数、内核、缓存、batch 与硬件。三类结论使用不同证据，不能从其中一类直接推出另外两类。

比较速度时至少记录 NFE、单次前向处理的序列长度、每步提交 token 数和端到端延迟。扩散模型即使每步提交多个 token，也可能因全序列重复计算而失去优势；自回归模型即使顺序生成，也可能凭借缓存和优化内核取得更高吞吐。比较质量时还要固定提示、解码预算与模型阶段，避免把训练数据差异解释为生成机制差异。

两篇入口承担不同任务。[为什么用扩散做语言生成](1.1-为什么用扩散做语言生成.md)从串行提交、反向任务与约束注入展开动机；[扩散与自回归的能力边界](1.2-扩散与自回归的能力边界.md)检查表示、似然、缓存与可变长度。读完后再进入公式，可以明确每个数学对象对应哪项生成行为。

主线为 01→02→04→06→07：建立问题，推导离散过程，理解联合依赖，再检查系统和选型。模型版本线在 02 之后进入 03；训练成本线进入 05。路线可以分叉，但每次引用性能数字都应返回原始协议。

另一个必要区分是“可修订”与“已经修正”。扩散轨迹允许位置在后续步骤改变，这只提供纠错通道；模型是否识别错误、调度器是否愿意重掩、剩余步数是否足够，仍由训练与采样共同决定。相同道理，双向注意力提供左右文可见性，却不自动消除反转任务或长程推理错误。机制给出可用的信息通路，实验才说明模型是否学会利用。

版本记录也属于阅读方法。同一家族可能从全双向扩散改为块扩散，从头训练改为自回归权重迁移，或替换采样器而保留检查点。名称相近不代表概率模型相同。页面引用模型时会同时写版本、训练起点与解码方式；若论文只公开接口或演示，正文会把未知参数留空，不从吞吐或基准分数反推隐藏结构。

版本记录把检查点、训练目标和采样器绑定在一起。后续复现若只复用模型名称而遗漏其中一项，得到的质量、步数和吞吐就不再对应原报告；页面更新也按这三个对象分别追踪。

### 先把「扩散」定义到可计算

对语言序列，扩散路线至少包含三个数学对象。第一个是前向过程 $q(x_t\mid x_{t-1})$，它把干净数据逐步推向简单终态；第二个是时间条件模型，用带噪状态估计干净 token、score、反向转移或速度场；第三个是从终态返回数据的采样算法。只看到多个 `[MASK]` 并行填充，还不足以确定这三个对象是否存在。

离散马尔可夫扩散使用转移矩阵 $Q_t$。若 token 用 one-hot 行向量表示，一步分布可写为 $q(x_t\mid x_{t-1})=\operatorname{Cat}(x_t;x_{t-1}Q_t)$，从干净状态直接跳到 $t$ 时刻使用累积矩阵 $\bar Q_t=Q_1Q_2\cdots Q_t$。均匀噪声会把质量分给整个词表，吸收噪声则把破坏质量送到一个特殊掩码状态。两者的反向条件、采样稀疏性和训练难度不同。

连续嵌入扩散先把 token 映射到实数向量，在向量空间加高斯噪声，最终还需要将去噪嵌入映射回离散词表。连续空间提供成熟的 score 和 ODE 工具，离散回译则可能产生舍入与嵌入坍缩。离散扩散直接在词表状态上建模，避开最终的连续到离散投影，却要处理大词表转移和离散后验。这是两条路线的计算差异，不是一个只靠名称能决定的优劣。

掩码扩散属于离散扩散中极具结构的一类。它让已破坏位置显式可见，可以把损失写成对掩码位置的加权交叉熵。训练代码因而很像 MLM，完整模型还包含时间采样、权重、反向后验和生成调度。若只使用一个固定掩码率做表示学习，却没有定义从终态到数据的概率路径，它更接近编码式 MLM，不直接构成生成扩散模型。

### 论文里的一个分数是怎样产生的

最终任务成绩可以拆成检查点、采样器和评测器三层。检查点由模型架构、数据、训练目标与优化预算决定；采样器决定噪声路径如何离散化、每步提交多少位置、是否重掩和何时停止；评测器再用答案抽取、代码执行或裁判模型把原始输出变成分数。三层中任意一层改变，最终数字都可以改变。

比较生成机制时，最难控制的是检查点差异。一个扩散模型与一个自回归模型使用不同训练 token、数据截止日期、后训练和参数量时，成品分数回答的是整个系统谁更强。要孤立机制，可以从同一自回归权重分叉出扩散改编，或者用相同数据、规模和计算从头训练两组模型。前者容易控制起点，可能保留自回归训练痕迹；后者更干净，成本也更高。

采样器对照则应共享检查点。固定模型后扫描 NFE、时间网格、每步提交比例、温度与重掩阈值，可以得到质量—成本前沿。只报最高质量会隐去所用步数，只报最快配置又可能落在不可用质量区间。每个点还要保留实际输出，检查速度改进是否集中损害公式、代码语法或长程依赖。

评测器差异可以用原始输出重算。数学答案的等价化、代码测试的超时与依赖环境、选择题的长度归一化、生成式裁判的模板和顺序偏置，都需要版本化。若新解析器修正了旧错误，同时重算两类模型，才能区分评测尺度改变与模型排名改变。

**怎样读「扩散更适合推理」这类主张**

可修订状态确实提供了与自回归提交不同的通路。例如填字游戏中，后来确定的交叉单词可以迫使早期字母改写；程序补洞中，函数前后文可以同时限制中间实现。这些任务的结构与掩码去噪直接匹配，能说明某种因式分解更自然。

开放式数学推理或代码生成则多一层。中间推理 token 不仅是最终答案的槽位，它们还承担计算过程。同时修改多个步骤可能恢复全局一致，也可能破坏原有的因果依赖。如果模型没有学会识别哪一步错了，重掩只会增加随机改写。所以需要测量中间错误检测、正确步骤保留率、错误步骤修正率与最终答案的关系。

反转任务也需要相同的克制。双向注意力允许每个未知位置看到左右语境，消除了「答案必须按提问顺序生成」的硬约束。能否学到反向关系仍取决于数据、目标和容量。若训练语料几乎只提供单方向表述，架构可见性无法自动创造缺失的统计证据。

因此「更适合」应该被拆成可证伪句子：在等数据和等计算训练下，扩散是否更快学到双侧约束；在等任务成功率下，它是否用更少墙钟时间；允许同等测试时计算时，重掩是否真的更多修正错误而不是换了一个随机答案。实验若只支持其中一条，结论就保留在那一条上。

**用四个小实验检查基本直觉**

第一个是「两位联合约束」。构造两个空位 $a,b$，只允许 $(0,0)$ 和 $(1,1)$ 两种答案，各占一半。两个位置的边缘分布都是均匀，独立采样会有一半概率得到非法组合。这个反例说明「每个位置都预测得很准」仍可能丢掉联合依赖。增加去噪步数、使用自条件或显式联合采样时，检查非法组合率如何下降。

第二个是「错误撤回」。在一组有唯一答案的序列上记录每个位置首次非掩码时的 token，再与最终输出比较。四个数字足以描述修订行为：首次就对且保留，首次错后改对，首次对后改错，以及始终错误。若增加步数只降低最终一类，说明多步提供了真实纠错；若第三类同时上升，调度器也在破坏已有正确信息。

第三个是「长度干预」。固定语义任务，分别给出恰好的画布、过短画布和过长画布。过短时检查是否截断关键步骤，过长时检查 EOS 后是否出现幽灵 token、重复或无效计算。若模型需要外部长度预测器，就同时报告预测误差和下游成功率，不把长度 oracle 当成免费输入。

第四个是「等质量速度曲线」。对同一检查点扫描不同 NFE 与重掩阈值，保留达到同一任务成功门槛的配置，再比较端到端延迟、吞吐和显存。自回归基线使用同一硬件、精度和批量，并记录 KV cache 与投机解码。这个实验不会给出永久的范式胜负，却能回答当前模型与系统在目标任务上是否兑现了并行承诺。

四个实验分别检查联合依赖、修订能力、长度机制和系统性能。它们不需要大规模榜单才能开始，用可控的小任务就能暴露定义、采样与实现是否对齐。当小反例都无法通过时，更大模型的高分也难以解释具体机制；反例通过后，大规模实验才负责检查这些性质能否在真实数据上扩展。
