# 掩码扩散：加权 MLM 为什么能当生成模型

转移矩阵那一篇已经选定吸收态：token 要么留下，要么变成 `[MASK]`，掩码出不去。本篇只写这一列怎样变成可训练的损失、和 BERT 差在哪、SFT 时掩哪里。采样的揭开顺序、remask、步数放下一篇，文末动画只建立「从全掩码逐步露出字」的画面。

> 从全 `[MASK]` 出发，每步并行揭开一批位置。这是生成，不是训练。训练见下面的图 1。

## 1. 前向：一个 $t$ 决定整句的掩码率

连续时间吸收态里，常把「该位置仍可见」的概率写成 $\alpha_t$，单调从 $1$ 降到 $0$。LLaDA 取最简单的线性日程 $\alpha_t=1-t$，并抽 $t\sim U[0,1]$。于是每个位置独立地以概率 $t$ 变成 `[MASK]`，以 $1-t$ 保持 $x_0$ 的原 token。$t=0$ 是干净句，$t=1$ 是全掩码。

位置之间前向独立，所以长度为 $L$ 的句子不必模拟 $T$ 步马尔可夫链：抛 $L$ 次硬币即可。这对应图像里「用 $\bar\alpha_t$ 闭式采样 $x_t$」，只是分布从高斯换成了「原词 / 掩码」两点。

1% 的 LLaDA 预训练样本会把长度在 $[1,4096]$ 里另抽一次，避免模型只会处理垫满 4096 的块。这与掩码率是两件超参，不要合成一个「噪声」。

用五个 token 的句子把硬币写明白。设 $x_0=(\text{床},\text{前},\text{明},\text{月},\text{光})$，$t=0.4$。每个位置独立以 0.4 的概率变成 `[MASK]`。一种实现是抽到 $x_t=(\text{床},\mathrm{M},\text{明},\mathrm{M},\text{光})$。损失只对第 2、4 位求 $-\log p_\theta$，再乘 $1/0.4=2.5$。同一句在另一个 batch 可能抽到 $t=0.9$，那时可能只剩一个明字可见，网络必须靠极少上下文猜整句，权重是 $1/0.9\approx 1.11$。两个 batch 都合法，这就是「对 $t$ 求期望」四个字的意思。

## 2. 损失：只在掩码位置上，再乘 $1/t$

LLaDA 的预训练目标（原文式 (3)）是

$$
\mathcal{L}(\theta)=-\mathbb{E}_{t,x_0,x_t}\left[\frac{1}{t}\sum_{i=1}^{L}\mathbf{1}[x_t^i=\mathrm{M}]\log p_\theta(x_0^i\mid x_t)\right] \tag{1}
$$

指示函数丢掉未掩位置：那些位置的答案已经写在输入里，再预测一次没有信息，还会让模型学「抄输入」。$1/t$ 来自连续时间 ELBO 在线性日程下的权重。$t$ 很小时，被掩的位置少，每个位置的梯度被放大，否则网络会偷懒只刷 $t$ 接近 1 的简单题（从全掩码猜边际）。$t$ 接近 1 时分母大，权重反而压低「几乎没上下文」的那种猜。

MDLM 把同一件事写成积分（他们的连续时间 NELBO）：

$$
\mathcal{L}^{\infty}_{\mathrm{NELBO}}=\mathbb{E}_q\int_0^1\frac{\alpha'_t}{1-\alpha_t}\sum_{\ell}\log\langle x_\theta^\ell(z_t,t),x^\ell\rangle\,\mathrm{d}t \tag{2}
$$

$\alpha_t=1-t$ 时 $\alpha'_t=-1$、$1-\alpha_t=t$，系数就是 $1/t$。式 (1) 和式 (2) 是同一条界的两种写法。LLaDA 还证明 $-\mathbb{E}\log p_\theta(x_0)\le\mathcal{L}(\theta)$，所以这不是启发式 MLM，是生成模型的似然上界。

> 图 1：抽 $t$，按概率 $t$ 掩码，双向 Transformer 只在 `[MASK]` 上算交叉熵，再乘 $1/t$。虚线表示未掩位置不进损失。

**图 1 解析**

- **B0→B1**：前向。$t$ 是随机变量，不是 BERT 那种固定 0.15。
- **B2**：没有 causal mask。每个位置的预测可以使用左右仍可见的 token。这是反转诅咒实验能成立的结构原因。
- **B3**：输出是对 $x_0$ 的分类 logits，不是对噪声 $\epsilon$ 的回归。
- **B4**：加权交叉熵。虚线从 B1 到 B4：未掩位置忽略。
- **图里没画 timestep 向量**。LLaDA 把 $t$ 编进数据（掩码率本身），是否另加 adaLN 以具体实现为准。

## 3. 和 BERT 差在日程，不差在骨架

BERT：掩码率固定约 15%，另有 10% 随机替换、10% 保持的细则，外加 NSP。目标是学双向上下文，用来填分类头。没有从全 `[MASK]` 出一篇文章的训练信号，因为几乎没见过 $t=1$。

掩码扩散：掩码率扫过 $[0,1]$。$t=0.15$ 的那些 batch 看起来很像 BERT；$t=0.9$ 的 batch 才教模型「几乎什么都看不见时怎样猜」。生成从 $t=1$ 走到 $t=0$，训练必须覆盖两端。MaskGIT 少了 $1/t$，LLaDA 把它视为与最大似然脱节的启发式。

骨干都可以是 Transformer。LLaDA 8B 用 decoder-only 形状、vanilla MHA（不是 GQA），去掉因果掩码，FFN 维度略小于 LLaMA3 8B 以抵消多出来的 KV 头参数。RoPE、SwiGLU、RMSNorm 仍在。不要把「BERT + timestep」理解成必须上 encoder-only 和 segment embedding。

对照表只保留机制差，不保留「谁更强」这种没尺度的话。

| | BERT MLM | 掩码扩散（MDLM / LLaDA） |
|---|---|---|
| 掩码率 | 固定约 15% | $t\sim U[0,1]$ |
| $1/t$ 权重 | 无 | 有，来自 ELBO |
| 随机替换 | 有（原文细则） | 默认没有，腐蚀就是 `[MASK]` |
| 训练任务 | 理解 / 分类头 | 生成（似然下界） |
| 推理 | 不从全掩码写长文 | 从 $t=1$ 反向到 $t=0$ |
| 注意力 | 双向 | 双向（块扩散除外） |

XLNet 的排列语言模型也是「任意顺序因式分解」，但每一步仍是对一个位置的因果预测，只是顺序随机。掩码扩散一步里对所有仍掩位置出边际，再选一个子集提交。任意顺序是共享的能力，算法不是同一个。Eso-LM 后来故意走「任意顺序 AR + 因果注意力」去换 KV Cache，那是第三条路，不要和式 (1) 混名。

## 4. SUBS：把吸收态的硬约束写进输出

MDLM 的 substitution 参数化做两件事。未掩位置的输出被替换成输入 token（carry-over）：反向过程不允许改已经干净的字。掩码类别的概率被置零：网络不许预测 `[MASK]` 当「答案」。两条都是吸收态反向后验里本来就该为零的项，写成替换之后，ELBO 里对应期望可以解析地拿掉，方差下降。他们把这叫 Rao-Blackwellization。

实现上就是 softmax 之前改 logits。没有新的网络模块。LLaDA 的采样还会做低置信 remask：已经揭开但分数低的位置，允许下一步再变成 `[MASK]`。那是推理启发式，和 SUBS 的「训练时未掩位置不许改」不是同一条规则。训练仍假设吸收：干净位保持干净。

## 5. SFT：提示不掩，回答按 $t$ 掩

条件生成 $p_\theta(r_0\mid p_0)$ 不必换骨架。LLaDA 把提示 $p_0$ 原样放着，只对回答 $r_0$ 做和预训练相同的独立掩码，得到 $r_t$。损失（原文式 (5)）仍是 $1/t$ 加权、只在回答里被掩的位置上：

$$
-\mathbb{E}_{t,p_0,r_0,r_t}\left[\frac{1}{t}\sum_{i=1}^{L'}\mathbf{1}[r_t^i=\mathrm{M}]\log p_\theta(r_0^i\mid p_0,r_t)\right] \tag{3}
$$

拼接起来看，这就是预训练的一个特例：被掩的 token 恰好都落在回答段。短样本在 batch 内用 `[EOS]` 垫齐，并把 `[EOS]` 当普通 token 训练，采样时丢掉结束符之后的内容，用来让模型自己决定回答长度。副作用是 Instruct 版在纯扩散采样里会过早堆 `[EOS]`；附录里对 Humaneval、GSM8K 等把 `[EOS]` 的置信度置零。评 Instruct 数字时要看他们用的是纯扩散还是块扩散式 remask：GSM8K 可以从 69.4 到 78.6，差的是采样，不是又训了一遍。

## 6. 条件似然怎么打分

MMLU 这类「四个选项哪个更像」的题，AR 用 $\log P(\text{选项}\mid\text{题干})$ 连乘即可。扩散没有精确连乘。LLaDA 用一个方差更小的等价形式：抽掩码个数 $l$，无放回地掩 $l$ 个回答 token，再把交叉熵乘 $L/l$。单 token 选项一次蒙特卡洛就够；更长选项用 128 次。所以 Table 1 里 Base 模型的 MMLU 和 HumanEval 不是同一种评测：前者是似然估计，后者是生成。不要把两列当成「同一个解码器的两个分数」。

生成时网络仍然只输出 $p_\theta(x_0\mid x_t)$。一步从 $t$ 走到 $s<t$，理论上应按后验随机把一部分预测掩回去，使得反向与前向共轭。实践里用低置信 remask：把预测里概率最低的那 $\frac{s}{t}$ 比例再盖上。置信度揭开是 MaskGIT 带到图像、LLaDA 带到语言的退火，不是 ELBO 的必选项。随机 remask 在 LLaDA 附录 Table 9 上明显更差（GSM8K 21.3 对 70.0，同长度设定）。训练式 (1) 不包含这条启发式；它只保证 $p_\theta$ 是好的掩码预测器。

## 7. 失效

$t$ 从不抽到接近 1：生成从全掩码起步会外推，开头几步胡猜。$t$ 从不抽到接近 0：轻度填空（只缺两三个字）变差。LLaDA 2.0 用 bandwidth 切掉两端，是承认极端 $t$ 梯度方差大、信息少。

损失若误加在未掩位置上：模型学会恒等映射，生成时揭不开。SUBS 的 carry-over 就是防止反向乱改已揭开的字；训练时若没有这条，采样策略再漂亮也补不回。

SFT 把提示也掩了：条件生成退化成「提示和回答一起去噪」，指令跟随会飘。式 (3) 的要点是提示作为干净条件。

评测把 ELBO 换算的 PPL 和 AR 的 PPL 直接减：界的松紧不同，减出来的「还差 20%」没有操作意义。看 GSM8K、HumanEval，或看同一代码库里重实现的 AR 对照（LLaDA 自己训过同数据 ARM baseline）。

## 8. 和均匀扩散、连续扩散的分工

均匀 $Q_t$ 没有 `[MASK]` 这个可观测的腐蚀标记，损失不能写成「只在掩码位置」。SEDD 可以在均匀或吸收上做 score entropy，目标更一般，工程更重。连续嵌入扩散要 rounding，引导方便、扩到 8B 的成功案例少。2025 年能叫 LLM 的开放权重，主路径是式 (1) 这一支。

读完应能默写式 (1)，并指出 BERT 缺了哪一个期望（对 $t$ 的期望和 $1/t$）。下一篇从这条训练好的 $p_\theta(\cdot\mid x_t)$ 出发，写怎样一步揭开 $k$ 个位置、何时把字掩回去、块扩散怎样让 KV Cache 重新合法。

补充一个训练时的数值直觉。设 $L=4096$，某个 $t=0.5$ 的样本大约 2048 个位置进损失。同一参数量的 AR 模型对 4096 个位置都有 next-token 项。表面上扩散每步监督更少，但每个被掩位置看见的是双向上下文，梯度里含的搭配信息更密。两边谁更「样例高效」没有与数据无关的定理。LLaDA 用 2.3T token 打到和 15T 的 LLaMA3 8B Base 相近的 MMLU，作者自己把优势归因于数据配比不可比，并在同数据 ARM baseline 上显示下游曲线可以跟上。讨论数据效率时用那条同数据曲线，不要用跨公司的 token 总数相除。

Classifier-free guidance 在 LLaDA 里是可选的推理技巧：同一反向步跑一次有条件、一次弱条件，再把 logits 做外推。附录 Table 6 报告 CFG 稳定加分。它不改式 (1)，只改采样分布。训练式仍是普通加权交叉熵。不要把 CFG 写进「掩码扩散的定义」。

LLaDA 2.0 的 complementary masking 则改训练：一对互补掩码保证每个位置在两次里恰好当一次干净上下文、一次预测目标，用来提高数据利用率。他们发现语料小于约 100B token 时有用，更大时优势消失，因而只留在 post-training。这是式 (1) 的抽样改进，不是新的 $Q_t$。

Dream 7B 在同一条吸收态损失上加了两处工程：用 AR 权重初始化并保持「位置 $i$ 的隐状态预测位置 $i+1$」的移位，以及按上下文信息量重标定每个掩码位的噪声水平。损失仍是掩码交叉熵，变的是初始化与日程。读 Dream 时不要以为他们换了 $Q_t$。把「初始化」和「噪声定义」分开，是读 2025 年改编论文时最省事的一刀。

五个 token 的句子把训练和生成的差别再钉一次。训练时 $x_0$ 全程可见，只是按 $t$ 随机盖住若干格，损失对盖住的格求 $-\log p_\theta$，乘 $1/t$。生成时没有 $x_0$，只有全 `[MASK]` 或提示加全掩回答。每一步网络仍输出 $p_\theta(x_0\mid x_t)$，但提交哪些格、盖回哪些格，由采样器决定，不在式 (1) 里。同一组训好的权重，随机 remask 可以把 GSM8K 打到 21.3，低置信 remask 拉回 70.0。把「训练好了就会生成」理解成 BERT 那种填空，会漏掉整篇采样文。

$1/t$ 的数值直觉不妨再算一遍。$t=0.1$ 时大约十分之一位置被掩，每个被掩位置的损失乘 10。没有这个系数，优化器会发现：多刷 $t$ 接近 1 的样本更轻松，因为全掩码时猜边际词频也能降损失，轻度掩码的难题被忽略。$t=0.9$ 时权重约 1.11，几乎不放大。于是「几乎没上下文」的题不会主导梯度，真正被放大的是「只缺一点点」的题。这和 BERT 固定 15% 完全相反：BERT 从来没有见过 $t=0.9$，也没有把 $t=0.1$ 的梯度放大十倍。少了这两头，编码器可以很强，生成模型起不来。

SFT 式 (3) 把提示当成永远干净的条件，回答按 $t$ 掩。多轮对话里，历史消息全部算提示，只有当前要写的那一轮按 $t$ 掩。这和 AR 的「整段对话都做 next-token」不同：用户说过的话不会被当成要预测的目标，模型没有动机去改写用户。若有人实现时把整段拼接后统一随机掩码，指令跟随会变成「用户问题和助手回答一起去噪」，用户的措辞可能被「擦」掉。这是训练 bug，不是扩散结构注定改写用户。评 Instruct 数字之前，先确认实现有没有把提示从损失里拿掉。

互补掩码（LLaDA 2.0 post-training）让每个位置在一对样本里当一次上下文、当一次目标，数据利用率提高。作者发现语料小于约 100B token 时有用，更大时优势消失。这解释了为什么 8B 从头训 2.3T 不必上互补掩码：数据已经够，抽样技巧的边际变小。小预算改编反而更需要这种技巧，因为每个 token 都贵。式 (1) 没变，变的是怎样抽 $x_t$。读论文时把「抽样改进」和「新噪声」分开，能少混很多名字。

条件似然打分（MMLU）和生成（HumanEval）不要合成「LLaDA 的分数」。前者抽掩码个数做蒙特卡洛，单 token 选项一次就够；后者要真正从掩码走反向过程。同一张 Table 1 上两列并排，读的人容易以为是同一个解码器打了两遍。不是。报数字时写「似然估计」还是「生成」，和写 shot 一样必要。采样器消融只影响生成列，不影响 MMLU 那种打分列。把 Table 8 的 GSM8K 变化抄到 MMLU 上，是把解码器应用到了没有解码器的任务。

SUBS 的 carry-over 在训练时禁止改已干净的字，采样时的低置信 remask 又允许把低分的字盖回去。两条规则看起来打架，其实分属训练约束和推理启发式。训练必须服从吸收态后验，否则 ELBO 推导断掉。推理可以不忠实于后验，Table 9 证明不忠实更好用。写实现的人若在训练里也做 remask，等于改了前向，法律变了，式 (1) 不再是原来的界。这是把采样器偷运进训练的常见事故。

$t\sim U[0,1]$ 在实现里就是 `t = torch.rand(batch)`，每个样本一个掩码率，再对每个位置抛硬币。不必先把 $[0,1]$ 切成 1000 档。连续时间写法看起来吓人，代码往往比 DDPM 的日程表更短。吓人的是采样器，不是这条训练循环。
