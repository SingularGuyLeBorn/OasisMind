# 多模态扩散：LLaDA-V、MMaDA、Dimple

前面专文把噪声、损失、采样钉在纯文本上。多模态问的是另一件事：图像进了序列，吸收态还作用在哪一类符号上。有人把像素也拿去加高斯，那是图像扩散，不是本篇。本篇三条线都还是离散语言扩散当语言塔：视觉特征投影进词嵌入，或把图像量化成离散码，再和文本一起做掩码去噪。

读完应能分开三种接法。LLaDA-V：SigLIP 加 MLP，噪声和损失仍在回答文本上。MMaDA：VQ 把图变成离散码，图和文共享同一套扩散。Dimple：先用自回归把视觉和语言对齐，再切回扩散，换稳定换吞吐。数字只引用 LLaDA-V 原文 Table 2–3 能逐格核对的那些；Dimple / MMaDA 的主表不在同一份 HTML 里完整展开，机制写清，分数不从二手综述抄。

## 1. 插槽：视觉进嵌入，噪声仍在字上

自回归多模态的默认接法是 LLaVA：视觉塔抽出图块特征，MLP 投进 LLM 的词嵌入空间，后面仍按从左到右写回答。LLaDA-V（You 等人，arXiv:2505.16933）把最后那一截换成掩码扩散。视觉塔用 SigLIP 2，投影用两层 MLP，语言塔就是 LLaDA 8B。训练目标仍是只掩回答、提示保持干净，只是提示里现在既有字，也有一串视觉嵌入。

![LLaDA-V 将视觉编码结果投影到语言槽位并参与掩码扩散去噪](./images/fig-llada-v-slot.png)

> 图 1：图像经视觉塔和 MLP 进入 LLaDA 的嵌入空间。虚线是干净的文本提示；实线是回答段上的迭代揭开。像素本身不进 $Q_t$。

**图 1 解析**

- **SigLIP2 vision tower**：把图切成 patch，得到连续特征。这一段和 Qwen-VL、LLaVA 同类，不是新的扩散前向。
- **MLP projector**：把视觉特征的维数拧到语言嵌入。第一阶段常常只训这一层，让两边说话。
- **LLaDA 8B language tower**：双向掩码扩散。图块和提示作为干净条件，回答位置按 $t$ 掩。
- **text prompt 虚线**：用户问题不进损失，和纯文本 SFT 式 (3) 同一纪律。
- **text answer tokens**：生成时从掩码走反向。噪声法律没改，改的是条件里多了一排看见过的图。

这句话值得单独钉死：LLaDA-V 没有在像素上定义 $Q_t$。吸收态仍作用在回答 token 上。双向注意力让回答格同时看见图块和已揭开的字，这是结构借口，不是新的噪声家族。把 LLaDA-V 写成「图像扩散接上了语言」，路线就焊错了。

高分辨率处理是作者自己写的局限。大图被切开、缩放、再拼特征，没有 Qwen2-VL 那种原生动态分辨率。效率与细表理解都会付税。Table 3 上图表、文档相对 LLaMA3-V 并不占优，和这条实现税对得上，不要先怪扩散目标。

## 2. 注意力图案：对话因果还是全双向

多轮图文对话里，可以给轮与轮之间加因果掩码，轮内双向；也可以整段不掩。LLaDA-V Table 4 在 LLaVA-NeXT 设定上扫过这两套。无掩码在多数格上略好：MMMU 44.67 对 42.89，MuirBench 33.88 对 28.69。主模型采用无掩码。注意这张消融不是 Table 2 的主评测设定，数字不能和 48.6 横减。

无掩码的代价仍是那条机制账单：视觉前缀的 Key 会随回答揭开而变，严格 KV 默认不成立。LaViDa 后来做 Prefix KV-Cache，把视觉和提示的键值先缓存，等于承认图块在生成中途不再改。那是加速论文的接法，不是 LLaDA-V 主文的默认实现。读「多模态扩散也能 KV」时，先问缓存的是视觉前缀还是去噪中的回答。

## 3. 和同数据 AR 对照：LLaMA3-V

公平对照要求同一套视觉指令数据、同一套训练阶段，只换语言塔。LLaDA-V 把这条基线叫做 LLaMA3-V。Table 2，多学科知识与数学推理：

| 任务 | LLaDA-V | LLaMA3-V | Qwen2-VL |
|---|---|---|---|
| 语言塔 | LLaDA 8B | LLaMA3 8B | Qwen2 7B |
| MMMU val | 48.6 | 45.4 | 54.1 |
| MMMU-Pro standard | 35.2 | 28.3 | 43.5 |
| MMMU-Pro vision | 18.6 | 14.5 | — |
| MMStar | 60.1 | 56.5 | 60.7 |
| MMB en-dev | 82.9 | 79.8 | — |
| MathVista testmini | 59.7 | 62.1 | 58.2 |
| MathVerse mini-vision | 28.5 | 29.0 | — |

作者写：尽管语言塔在纯文本上弱于 LLaMA3 8B，LLaDA-V 在 Table 2 的 9 格里有 6 格超过 LLaMA3-V。对 Qwen2-VL，多数格仍落后，MMStar 60.1 对 60.7 算接近。差距优先记在语言塔，不要记成「扩散看不懂图」。Qwen2-VL 的训练数据与动态分辨率都不是同一套协议。

|---|---|---|

多图和视频略高，场景理解略低，文档参差。作者把优势放到双向看见整段图文条件，把文档短板放到切图策略。这是机制假说，表只证明这些格上的差存在。不要把 MuirBench 48.3 对 47.4 写成「视频全面超过」，差 0.9 点，且两列训练协议相同、语言塔不同。

数据规模曲线写在 Fig. 3。同一套 MAmmoTH-VL 单图数据往上堆，LLaDA-V 在 MMMU、MMMU-Pro 上比 LLaMA3-V 更吃数据。作者写：MMMU-Pro 上，LLaDA-V 用约 1M 样本可以超过 LLaMA3-V 用 9M 的点。图表和真实场景理解没有同样的故事。缩放优势是任务相关的，不是多模态扩散的定理。

## 4. 另外两条河：统一离散码，以及先自回归再扩散

MMaDA（Yang 等人，arXiv:2505.15809）不走「视觉塔 + 语言塔」的 LLaVA 插槽。文本用 LLaDA 的分词器，图像用 Show-o 那套基于 MAGVIT-v2 的量化器，码本 8192，下采样 16，一张 512×512 的图变成 $32\times 32=1024$ 个离散码。图码和字进同一套 Transformer，目标仍是预测被掩的离散符号。理解、生图、文本推理可以共享前向。生图采样走低置信 remask 加余弦日程、50 步、CFG 3.5；文本采样走 LLaDA 那种块内扩散、块间从左到右，评测写过总长 1024、512 步、块长 64。两套调度器不要焊成一个 $T$。

后训练有混合长思维链，以及 UniGRPO。d1 把掩码率钉死，LLaDA 估似然要很多次蒙特卡洛。UniGRPO 对每个回答抽 $p_i\sim U[0,1]$ 再掩，让策略在几乎全掩到几乎干净的各阶段都见到梯度。这是对齐篇在多模态上的亲戚，不是新的 $Q_t$。MMaDA 主表跨理解、生图、文本三套基准，口径和 LLaDA-V Table 2 不是同一 harness。本篇不把综述里的 MMMU 30.2 一类二手数写进规格卡。要写分，打开原文对应表。

Dimple（Yu 等人，arXiv:2505.16990）走第三条河。视觉塔来自 Qwen2.5-VL，语言塔是 Dream 7B，投影随机初始化。作者发现纯离散扩散从一开始对齐视觉和语言，训练不稳、有严重长度偏差。配方改成两段：先把 Dream 的注意力改回因果，按 LLaVA-NEXT 的数据做自回归对齐和指令微调；再打开全双向，只掩回答，把并行解码接回来。Dream 本身从 Qwen2.5 改编而来，自回归损失不会把几何冲光，这是改编专文那条移位纪律在多模态上的回声。

Table 1 与 LLaVA-NEXT 同数据量级（约 1.3M 样本、0.8B token）。Dimple 平均 62.4，LLaVA-NEXT 58.5，高 3.9 个百分点。逐格：MMMU 45.2 对 35.8，MMBench 74.6 对 68.7，ChartQA 63.4 对 54.9，AI2D 74.4 对 65.4，MathVista 42.3 对 33.0。消融写明：先自回归再扩散（设定 F）MMMU 到 45.2；只做扩散或只做自回归都更差。45.2 和 LLaDA-V 的 48.6 不是同一协议，不要减。对 Qwen2.5-VL（数据量大一个数量级以上）仍落后，作者自己把缺口记在数据量，不记在「扩散不会看图」。

长度偏差的修法很具体：训练集里的 `[EOS]` 换成 Dream 词表里随机个数的 padding，让模型用垫片学「写到这儿可以停」，而不是靠结束符抢置信度。这和纯文本 Instruct 垫结束符是同一类病、相反的药。推理用置信度揭开：本步所有超过阈值的格子一起提交，一个都没有就只揭最尖的那一个。prefilling 把提示（含图块）的 KV 在第一步之后重用，复杂度从 $O((L_{\mathrm{prompt}}+L_{\mathrm{answer}})^2)$ 收到 $O(L_{\mathrm{answer}}^2)$。全双向下这不是无损：Key 理论上仍随回答揭开而变。Table 3 上多数集掉点平均约 0.8%，batch size 1 时加速约 1.79 倍。近似缓存那一刀在多模态里先砍视觉前缀，因为图块往往比回答长。

LaViDa（Li 等人，arXiv:2505.16839）补训练效率：掩码扩散平均大约一半位置进损失，视觉问答里关键回答 token 可能被漏掉。互补掩码做一对互斥的腐蚀，保证每个位置当一次目标。这和 LLaDA 2.0 文本后训练里的互补掩码是同一类抽样改进。推理上缓存视觉前缀。COCO caption 相对 Open-LLaVA-Next-Llama3-8B 报过 +4.1 CIDEr、约 1.92 倍速度；约束诗句补全报过 +59%。这些格不要和 LLaDA-V Table 2 横减。名字挂在这里，避免读者以为多模态只有一篇 LLaDA-V。

## 5. 和纯文本花园怎么接

语言塔的 $1/t$ 损失、低置信 remask、块扩散，在多模态里仍然成立。变的是条件：图块占序列前面很长一截，双向注意力的 $n$ 变大，每步 $O(n^2)$ 更疼。加速论文因此先打视觉前缀的缓存，再打回答段的并行揭开。27.6× 那一类倍数若出现在多模态仓库里，对照物仍要写清是原版循环还是 AR serving。

对齐也分开。LLaDA-V 主文是视觉指令微调，没有把 VRPO 或 UniGRPO 写进主表。MMaDA 的 UniGRPO 属于多模态后训练。不要把 1.5 的 GSM8K 83.3 抄到 MMMU 上。纯文本对齐专文管字；本篇管图怎么进条件。

统一生图理解的那条河，和 Diffusion-LM 的连续梯度不是一件事。VQ 码上的离散扩散可以双向出图出字；连续嵌入上的梯度引导是 2022 年小模型的可控生成。产品若要「既能看图问答又能出图」，问的是有没有共享离散状态；若只要看图答题，LLaVA 插槽够用，不必上 VQ。

## 6. 失效

把 LLaDA-V 的 48.6 和 Qwen2-VL 的 54.1 减成「扩散看图差 5.5 点」：语言塔、分辨率、数据都不同。同协议对照看 LLaMA3-V 那一列。

把 Table 4 的 44.67 抄进主规格：那是 LLaVA-NeXT 消融，不是 Table 2。

把切图策略的文档短板写成「掩码扩散不会读表」：作者把局限写在图像预处理，不是写在 $Q_t$。

把 MMaDA 的统一生图理解写成 LLaDA-V 的能力：LLaDA-V 主文是理解，不负责出图。

视觉 token 一长，全双向每步更贵。多模态加速的第一刀往往是缓存前缀，不是再降 $T$。把纯文本 Fast-dLLM 的倍数直接贴到带图对话上，分母里的 $n$ 已经换了。

读完应能指着图 1 说出：哪一块是视觉塔，哪一块是投影，噪声加在哪一类符号上。指不出「噪声在字上还是在像素上」，多模态扩散就还只是「LLaVA 换了个解码器」这句空话。换解码器是真的；空话里缺的是：条件变长之后，KV、切图、同数据对照这三笔账单要单独付。

LLaDA-V 的训练阶段按视觉指令微调的老路走。第一段只训 MLP，用 LLaVA-Pretrain 把视觉特征拧进词嵌入。随后把视觉塔、语言塔、投影一起打开，堆 MAmmoTH 的单图、OneVision、VisualWebInstruct 等。消融另用 LLaVA-NeXT 两阶段。主表 Table 2–3 不是跑在消融那条短课上。报 48.6 时默认它已经走完主课，不要把 Table 4 的 44.67 当成「最终模型」。

「语言塔更弱」不是客气话。LLaDA 8B Base 的 Hellaswag 70.5 对 LLaMA3 的 79.1，BBH 49.7 对 62.1。看图问答大量依赖语言塔里已经有的世界知识。LLaDA-V 能在同数据下于 MMMU 超过 LLaMA3-V，说明双向条件有时补得回这截；对 Qwen2-VL 仍落后，说明补不回数据量和动态分辨率一起造成的那截。多模态分数永远先拆成「塔有多强」和「接法换了什么」，再谈扩散。

视觉 token 把 $n$ 拉长是账单的另一面。一张图切成几百个 patch 时，提示长度可以压过回答。全双向每步注意力是整段平方。Dimple 因此把 prefilling 写成必选项而不是锦上添花：不缓存前缀，并行揭开省下的前向次数会被平方项吃掉。纯文本加速论文里 $n$ 往往是回答长度；多模态里 $n$ 先是图块。把 Fast-dLLM 的 27.6× 贴到带图对话上，分母已经换了。

三条河不要合成「2025 年扩散已经会看图」。LLaDA-V 证明 LLaVA 插槽可以换语言塔，同数据下部分格超过 LLaMA3-V。Dimple 证明不稳定时可以先借 AR 对齐，再把双向接回来，同数据下平均超过 LLaVA-NEXT 3.9 点。MMaDA 证明图也可以变成离散码，和字共享吸收态，从而兼做生图。三句话的主语不同。产品若只要看图答题，插槽够用；若还要出图，才需要统一码。若训练不收敛，Dimple 那条先因果后双向的连续路径比一把撕掉 mask 更像改编专文已经讲过的课。

生成长度在多模态里仍然是画布。Dimple 评 MMVet 时把所有回答钉在 64 token，因为真值从一词到五百词都有。钉短了，长回答被截；钉长了，短回答浪费前向。纯文本 Instruct 用结束符垫片制造过同样的病。块扩散「再开一块」在带图对话里同样值钱，只是公开主表还很少把块长写成多模态规格。看见某个 MLLM 仓库默认 128 步、回答长 64，把它抄进规格卡，和抄采样器一样必要。

多图和视频上 LLaDA-V 略高于同数据 LLaMA3-V，和双向能同时看见分散在序列里的多帧条件，是对得上的借口。单帧真实场景 RealworldQA 反而低 2.8 点，借口在这里用不上。结构优势出现在「条件空间上散开」的题，不出现在「认一张日常照片」的题。这和纯文本里诗歌反向强、正向弱是同一类读表法：优势格和劣势格要一起在。

D-DiT、Muddit 从 SD3 一类图像扩散骨干初始化，再接上文本。那是「图像扩散学会说话」，不是「语言扩散学会看图」。本篇三条河的语言塔都来自 LLaDA 或 Dream。把 SD3 初始化的统一模型写进 LLaDA-V 的对照总分，等于把连续像素扩散和离散吸收态焊在一起。LLaDA-V Table 2 把 D-DiT 标成 Diff. 且多项为「-」，本身就在提醒：骨干不同，格对不上。

InfoVQA 66.3 对 LLaMA3-V 的 58.9 是 Table 3 里差得比较大的一格，文档理解并非全面落后。AI2D 77.8 对 81.1、DocVQA 83.9 对 86.2 才是切图策略那条短板更可能出现的地方。读「图表不行」时看是哪一张表、哪一列。不要用 AI2D 一格代表全部 OCR。

投影层看起来像小事，却决定视觉几何能不能进语言塔。随机初始化的两层 MLP 若学不好，后面无论因果还是双向都在猜一套对不齐的图。LLaDA-V 第一段只训投影，Dimple 同样从随机投影起步。这和改编专文「换词表等于让嵌入从噪声开始」是同一类警告：接口没对齐，塔再强也接不上。多模态失败时，先看投影有没有单独训过，再怪扩散目标。

采样器在带图回答里同样能改分数。纯扩散一次揭开太多字，和图像里的空间关系对不齐，括号和坐标更容易错。低置信 remask 把还平的格子留到下一步，等于让图块多当几次条件。阈值解码同理。LLaDA-V 主表没有像 8B 文本附录那样扫三种解码器；把 48.6 当成与采样无关的常数，是把纯文本已经犯过的错搬到图上。报多模态分，能写采样器就写。

本花园把多模态放在模型层而不是再开一套机制，是因为 $Q_t$ 没有变。变的是条件里多了图，以及图要不要自己变成离散状态。机制文仍然够用：吸收态、加权交叉熵、揭开与 remask。新读者若跳过 02 直接读本篇，会把 MLP 和 MAGVIT 当成两种扩散。它们不是。一个是连续特征当条件，一个是离散码当状态。分清条件和状态，三条河才分得开。

LLaDA-V 项目页与代码在 https://ml-gsai.github.io/LLaDA-V-demo/。复现 Table 2 时用他们的评测脚本，不要用另一套 MMMU  harness 减出「退步了」。这和 Dream 表上的 LLaDA HumanEval 32.9 对 Nie Table 1 的 35.4 是同一类纪律。图文问答的 harness 比纯文本更多：图怎么切、是否多选、视频抽帧。抄分之前先抄协议。没有协议的截图，本花园不当规格。同数据对照永远优先于跨公司海报。没有同协议，就只写接法，不写总分。接法对了，分数以后可以补；接法错了，分数再高也是错句。
