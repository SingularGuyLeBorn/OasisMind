# 失效模式：定长、并行冲突、困惑度不可比

前面几篇把机制能做什么写清楚了。本篇把同样的公式会在哪里翻车集中放在一页，避免读者只记住 Mercury 的四位数吞吐和 LLaDA 的 GSM8K。失效分三类。结构上必然的：定长画布、因子分解、似然不可比。2026 年工程上仍在修的：近似缓存、结束符、对齐数据。和 AR 共有、扩散并不自动免疫的：幻觉、知识截止、评测污染。

![](./images/fig-dlm-failure-modes.png)

> 图 1：三列彼此独立。左列 `[EOS]` 垫满之后纯扩散会提前结束；中列一步两个 `[MASK]` 独立 argmax 会对不上括号；右列 AR 的精确 NLL 和 MDM 的 ELBO 不能横比。

**图 1 解析**

- **左列 L1→L3**：SFT 若把回答 pad 到固定长，结束符出现在许多位置上，纯扩散会学「到处写 EOS」。块采样能挡住传播，见采样专文 Table 7–8。
- **中列 P1→P3**：联合 $p(x^i,x^j\mid x_t)$ 被拆成两个边际。阈值和解码器是补丁，不是把联合建模回来。
- **右列 Q1→Q3**：虚线表示两条估计量不相等。LLaDA 附录写明不同 ELBO 写法要的蒙特卡洛次数差一个数量级。
- **三列不要合成一张「扩散 Triple 失败」的总分**。它们会单独出现，也会叠。

## 1. 画布长度和结束符

纯掩码扩散在 $t=1$ 时从长度为 $L$ 的全 `[MASK]` 出发。$L$ 是超参。短了，答案被截断，后面的推理写不下。长了，模型要决定哪些位置是正文、哪些是填充。LLaDA 预训练有 1% 样本把长度在 $[1,4096]$ 里另抽，减轻「只会处理满长度块」。Instruct 把回答 pad 到固定长时，`[EOS]` 变成高频监督。纯扩散一步能在很多位置同时写出结束符，生成表现为提前停。作者的补法是采样时把 EOS 置信度置零，或改用块采样让结束符不容易从块首传到整段。块长 8 时 Instruct GSM8K 到 78.6，纯扩散 69.4，差的就是这件事，不是「块更接近 AR 所以数学更好」这么简单。

AR 的结束是采样到 EOS 就停，长度是生成出来的。扩散的长度是租来的。产品若需要「写到自然结束」，块扩散或半自回归更顺；若需要「必须填满表格的 N 格」，定长反而是特性。把特性当缺陷、把缺陷当特性，都会选错采样器。

变长还有一个隐蔽坑：评测时生成长度设成 128、256、512，d1 的数独分数随长度单调下降。更长画布不是免费的思维链预算，空位多了，模型可以在无关位置胡写。报「加长就变强」之前看任务。GSM8K 和 MATH500 确实随长度涨，数独不是。

## 2. 并行揭开的搭配错误

反向过程在位置上因子分解。一步提交两个掩码位，等于假设它们在给定 $x_t$ 时条件独立。括号、引号、Markdown 的成对标记、代码里的标识符声明与使用，都是典型的负相关结构：一边确定了，另一边的分布应当立刻变尖。独立 argmax 可以同时选两套自洽但彼此冲突的局部最优。

缓解按代价排序。高阈值：只提交已经很尖的位置，让还平的位置等邻居变成明文。Fast-dLLM 0.9、LLaDA 2.0 0.95。remask：允许下一步把错字盖回去，吸收态默认不提供这个权利，要采样器显式做。块：把并行范围关进块内，块间因果。联合熵上界（EB-Sampler）：看的是一组位置能不能一起揭，而不只是边际最大值。训练侧 CAP、certainty-forcing：让对的位置更尖，等于给阈值更多可提交的候选。

没有一种方法把联合分布真正写进每一步。$T=L$、每步揭一个时，因子分解误差消失，吞吐也消失。并行诅咒和速度卖点是同一枚硬币。报 Humaneval 35.4 时 LLaDA Base 把步数和长度都设成 1024，等于几乎放弃并行。把这格和 Mercury 的 1109 tok/s 放在「扩散又快又好」同一句里，是把两个工作点焊在一起。

## 3. 困惑度不可比

AR 的 token NLL 在 teacher forcing 下是精确的 $-\sum_i\log P(x_i\mid x_{<i})$。掩码扩散报的是 ELBO 或加权交叉熵。ELBO 是下界，紧不紧取决于轨迹随机性和估计方法。LLaDA 附录比较两种蒙特卡洛：按前向过程随机掩，期望掩码率 $t$，短句上波动大，要 1000 次以上才稳；按确定比例 $\ell/L$ 去掩，128 次就能稳。同一个模型，两种估计能差出「看起来像另一篇论文」的 PPL。SEDD、MDLM 在 GPT-2 规模上声称 PPL 可比或优于 AR，用的是各自的估计器。把那些数字和 LLaMA3 的官方 PPL 减一减，没有共同的估计协议。

LLaDA 主表因此几乎不报 PPL，改报下游。这是诚实。读早期离散扩散论文时，看见 PPL 赢了，先问：词表是否相同、是否含 EOS、ELBO 抽了几次 $t$、是否把时间积分的常数算进去。问不清，就当不可比。

一个常用的错误换算是：把 $1/t$ 交叉熵的训练 loss 直接 $\mathrm{e}^{\mathrm{loss}}$ 当成 PPL。训练 loss 是对 $t\sim U[0,1]$ 的期望，位置还只在掩码上平均。它和「每个 token 的平均负对数概率」差一个由日程决定的常数因子，也差一个「没被掩的位置根本没进损失」。MDLM 的 SUBS 参数化把这个对应关系写清楚了，仍然不是 AR 的 NLL。跨论文抄 PPL，等于跨估计器抄。本花园的模型年表因此只写下游和吞吐，不写「PPL 已经打平 GPT」。

下游也有协议陷阱。Base Table 1 带星号的是同套评测脚本。Instruct Table 2 对照模型有 RL，LLaDA 当时没有。d1 的 0-shot 长度扫描，和原论文 4-shot 不是一张表。Fast-dLLM 的 GSM8K 79.3 是他们自己跑出来的 Instruct 加长生成，不必等于 78.6。本花园在模型篇里已经改过一次旧数字；本篇把「为什么会抄错」写成机制：格子里的数绑定采样器、shot、长度、是否 RL。

## 4. 近似缓存会过期

Fast-dLLM 和 dKV-Cache 的前提是相邻步 $K,V$ 很像。一块之内揭开很多字、或噪声允许已提交位置再改，这个前提会裂。Seed 的编辑腐蚀明确站在 DualCache「后缀一直是掩码」的对面。把 27.6× 贴到可编辑扩散上，没有论文支持。刷新间隔取太大，等于用过期邻居算注意力，错误会在后续步被双向放大：错的 Key 被所有 Query 看见。这和 AR 里 KV 算错只影响未来位置不同，双向让过去的位置也能被污染。

块间真缓存没有这个问题，代价是看不见未来块。任意位置填空、整段一起改写，块结构做不到，必须退回全双向，再重新付没有严格 KV 的账。

## 5. 幻觉、事实、BBH

扩散并不自动更诚实。LLaDA 8B Base 同协议 Table 1 的 BBH 49.7，LLaMA3 8B 为 62.1，这格扩散更差。TruthfulQA 46.1 对 44.0，略好，差在误差范围内能讲的那种。附录 Table 6 开 CFG 后 TruthfulQA 到 46.4；主表不开 CFG。并行生成有时被宣传成「全局可见所以前后更一致」。机制上，一步之内各位置并没有看见彼此的最终取值，一致性要靠多步才出现。步数少时，前后矛盾可以来自因子分解，而不是来自「模型不知道事实」。步数多时，幻觉仍可来自训练数据。对齐方面 AR 有多年 RLHF 积累，扩散的 VRPO / d1 才刚把梯度打稳。把「不太会幻觉」写成结构定理，证据不够。

反转诅咒缓解也不等于事实正确。反向诗句 42.4 超过 GPT-4o 的 34.3，正向 48.8 远低于 82.7。同一模型，方向一换，记忆强度完全不同。不要用反向赢了的任务去暗示正向知识也赢了。

## 6. 训练与系统

LLaDA 8B 预训练 2.3T token、约 13 万 H800 小时。LLaMA3 8B 是 15T。同数据 ARM baseline 才能谈样本效率；跨语料比「扩散更省数据」不成立。改编路线（Dream、LLaDA 2.0、Fast-dLLM v2）把账单转到「AR 预训练已经付过、再花 1B–580B 级 token 做扩散头」。1B 和 580B 差两个数量级，对应块扩散轻改编和全注意力深改编，质量与吞吐的落点不同。

系统栈：vLLM / SGLang 的 CUDA graph、连续 batch、speculative decoding 都围着 AR。开源扩散推理往往是论文仓库加 batch 1。测速时 AR 用了编译器和 paged attention，扩散用了 Python 循环，倍数会骗人。LLaDA 2.0 用 dInfer 对 SGLang，算是把对照拉回同一类系统问题。仍不要和 Artificial Analysis 上的 Mercury 混报。

评测污染、知识截止、工具使用、多模态，扩散没有豁免。本花园不把这些写成「扩散特有缺陷」，只提醒：换生成过程不会把 LLM 的老问题一笔勾销。

## 7. 读完应留下的检查清单

报速度：对照物、GPU、长度、shot、是否近似缓存、是否相对原版扩散。报质量：采样器、步数、生成长度、是否 RL。报 PPL：估计器。报可控：连续 80M 还是离散 8B。报反转：诗句表还是亲子检索，正向分有没有一起报。

缺任一项，格子里的数只描述了某个工作点。机制上，扩散换掉的是因式分解顺序，不是换掉语言模型要面对的数据、对齐和系统。

举一个会同时踩三列的配置。Instruct 模型、回答 pad 到 256、纯扩散、$T=8$、阈值 0.5、再开 DualCache 刷新间隔很大。左列：EOS 监督让模型想提前停。中列：每步揭几十个位置，括号配对靠独立 argmax。右列：若这时还用训练 loss 当 PPL 去和 LLaMA 比，估计器完全不是一回事。缓存列：块还没稳定就冻 KV，双向把过期 Key 广播到全句。单独看每一篇加速论文的主表，配置都比这个干净；产品把旋钮一起拧到「尽量快」，会把四篇论文各自避开的角落叠出来。本篇存在的理由就是把角落写在同一页。

Humaneval 上「步数=长度=1024」和 Mercury 的四位数吞吐，是轴的两端。中间没有免费午餐。选工作点时先写清任务：填空和反向诗句要全双向，不要为了 KV 把块开得很死；聊天要可变长，不要用纯扩散垫 EOS；代码补全可以阈值高一点，宁可慢，不要一步揭烂括号；要对齐风格走 VRPO，要对齐可验证答案走 d1。把这些写成默认配置表，比再发明一个 $Q_t$ 有用。

训练失败也有固定花样。文档打包不断开注意力，模型用下一篇的未来上下文去噪本篇，验证 PPL 好看、生成胡话。掩码率如果固定成 BERT 的 15%，似然下界对不上全掩码生成。SFT 若掩提示，模型学会改写用户问题。这些不是采样器问题，是训练把反向过程需要的条件弄脏了。失效清单里应当有「先看训练掩码，再看采样器」这一条。

长文本是另一处结构短板。全双向每步 $O(n^2)$，步数再乘 $T$。上下文 32k、生成再 2k 时，开源全双向几乎没有合格的公开延迟数字。块扩散把理解侧的长前缀变成可缓存的因果，生成侧的并行关在块内，是目前唯一能接上长上下文产品的结构。代价前面写过：块外未来不可见。检索增强、工具调用这些「先看长文档再写短答案」的任务，扩散没有自动优势；提示很长时 PrefixCache 只是在追 AR 已经拥有的东西。

幻觉和事实冲突时，扩散的采样随机性来自 $t$ 和揭开顺序，不只来自温度。同一条提示、固定种子，换 remask 策略可以改变是否胡编。这让「温度=0 就确定」的运维直觉失效：阈值、块长、步数都是静默温度。复现用户投诉的胡话，要把采样器超参一并锁死，否则会以为模型权重坏了。

BBH 49.7 对 62.1 值得当冷水。BBH 含不少要从左到右逐步消元的题。双向看得见右边，不等于会做多步符号操作。GSM8K 上 Base 反而领先，说明「数学」不是铁板一块：小学应用题和 BIG-Bench 硬题吃的上下文类型不同。用单一「推理」标签决定扩不扩散，会被这两格同时打脸。

复现事故时把采样器超参和权重写成同一份协议。阈值、块长、步数、是否置零 `[EOS]`、是否开 CFG，都会让同一检查点换一张脸。用户投诉「胡话」而实验室复现不出来，多半是协议没锁死，不是权重神秘衰减。失效模式专文要当运维清单读，不要当「扩散不行」的总判决。

投机解码、MTP、Medusa 是 AR 在串行约束上打的补丁：一次猜多个，再验证。扩散的并行揭开没有「验证器拒绝则回滚」这条默认路径，除非显式上自投机或 remask。把两者都叫「并行解码」会让人以为扩散已经包含了 AR 投机的安全网。没有。阈值是边际启发式，不是草稿-再校验。APD、SSD 那些带验证的工作要单独列，不能算进 Fast-dLLM 的 11× 里。

数值精度和采样器交互。离散扩散的实现里，有论文指出 categorical 采样在低精度下会偏。Zheng 等人写过 masked diffusion 会利用不精确的类别采样。这会让「同一权重、不同框架」的分数对不上，被误读成算法差异。复现 LLaDA 数字应当锁框架、锁 dtype、锁采样核。本花园不把那篇的具体偏差表抄过来，只把「采样核也是协议」写进失效清单。需要表时打开原文。

最后，读者页最常见的失效其实是预期管理。扩散换掉因式分解，不换掉「没有的知识变不出来」「没有的对齐变不出礼貌」「没有的系统变不出吞吐」。本花园前面写过的每一条优点，都有本篇一条对应的账单。两边一起读，表才不会被单独截图传播。

对照专文会把十个维度收成选型。本篇不重复那张表，只保证：读任何一格之前，先问采样器、长度、估计器、是否近似缓存。这四问能挡掉本花园旧稿里已经改过的那些错数字。

五 token 的 EOS 例子。真回答是三个字加结束符，SFT 把序列垫到五，于是监督是「字、字、字、EOS、EOS」。纯扩散在 $t$ 很大时看见一排掩码，预测器在后两格学会输出 EOS，前三格有时也跟着出 EOS，因为结束符在数据里太常见。采样若一步揭四个位置，可能四个都是 EOS，句子空。块长 2 时，第一块必须先写出字，EOS 传不到块外。这就是 69.4 和 78.6 之间差的那类东西，用玩具长度就能复现直觉，不必上 8B。

因子分解的玩具同样短。两个掩码要对成「左括号、右括号」，边际都是 0.6 的左和 0.6 的右，独立 argmax 得到两左或两右的概率不低。等一步只揭一个，揭开左之后右的边际会跳到 0.95。阈值 0.9 会拒绝第一步同时揭开这一对，等于自动退回「一次一个」在困难位置上。这不是超参玄学，是联合和边际的差。

把玩具放大到 Humaneval：函数签名已经揭开，函数体仍是掩码。一步把 return 和中间变量同时揭开，变量名可以对、return 用的却是另一个名字。阈值让 return 等变量名落盘；块采样让签名所在的块先结束。两种补丁修的是同一类搭配。旧笔记若写「扩散全局一致所以更少幻觉」，先用这个例子挡回去。全局可见的是当前明文，不是未来将要提交的那些边际。写进检查清单的最后一条：看见「并行」两个字，先问这一步提交的位置之间有没有看见彼此的最终取值。没有，就还在用边际乘积。有，才配谈联合。
