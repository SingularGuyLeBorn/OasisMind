# 对齐与强化学习

LLaDA 8B Instruct 的论文主表只有 SFT，没有 RL。和 LLaMA3 Instruct 比 GSM8K 69.4 对 78.3、HumanEval 49.4 对 59.8 时，作者自己写了对照侧有 RL。后面两篇工作把后训练补上。LLaDA 1.5 做偏好对齐，算法叫 VRPO，是 DPO 在 ELBO 上的降方差版。d1 做推理强化，算法叫 diffu-GRPO，是 GRPO 在掩码模型上的策略梯度。两者都先撞上同一堵墙：序列的 $\log\pi(y\mid x)$ 写不出来，只能估。

本篇假定已经知道 AR 的 DPO 和 GRPO 在干什么。不重推 Bradley-Terry。只写扩散这边估计似然时多出来的方差，以及两张主表上的点。

## 1. 墙：ELBO 不是 $\log p$

掩码扩散的模型分布由反向过程定义，精确似然要对整条掩码轨迹积分。训练用的 $1/t$ 交叉熵是变分下界的一项，用来更新预测器够了。偏好优化要的是两条完整回答的对数概率差

$$
s_\theta(y_w,y_l)=\beta\bigl(\log\pi_\theta(y_w)-\log\pi_{\mathrm{ref}}(y_w)-\log\pi_\theta(y_l)+\log\pi_{\mathrm{ref}}(y_l)\bigr)
$$

四个对数似然，每个都换成一次 ELBO 估计 $\widehat{\mathcal{B}}$，四个蒙特卡洛误差会加进 $s$ 里。LLaDA 1.5 证明：DPO 损失和梯度相对真值的偏差、方差，都能被这个分数估计量的方差界住。分数一吵，梯度符号都能反，模型会学成「讨厌本来更好的回答」。

直观上，同一个 $y$，抽一次 $t$、再抽一次掩码位置，ELBO 可以差很多。$t$ 接近 0 时几乎没掩码，这项接近 0；$t$ 接近 1 时几乎全掩，交叉熵很大。随机抽到哪一段，决定了今天这条偏好对的梯度有多大。AR 没有这个 $t$。

> 图 1：一对 $(y_w,y_l)$ 要估四条 ELBO；VRPO 让策略和参考模型共用同一组掩码时间步，再合成偏好分数。

**图 1 解析**

- **四个 ELBO 块**：$\pi$ 与 ref、赢与输，缺一块 DPO 的差就不对。
- **顶端 Shared masks**：对偶抽样。同一组 $t$ 和同一组掩码位置，分别喂给 $\pi$ 和 ref。两个估计量的噪声正相关，相减时对消。
- **虚线 antithetic**：不增加采样次数。预算 $n$ 固定时，这是免费的方差下降。
- **$\hat s$ → DPO loss**：后面仍是 $\log\sigma(\hat s)$，没有新的偏好模型。新的是 $\hat s$ 怎么来。
- **图里没画 GRPO**。策略梯度要的是同一条回答在 $\pi$ 和 $\pi_{\mathrm{old}}$ 上的概率比，方差问题同构，估法不同。

## 2. VRPO：把蒙特卡洛花在刀刃上

三条降方差，都不引入偏置。

加大预算 $n$。每条 ELBO 多抽几次再平均。默认 $n=8$，相对 $n=1$ 大约 8 倍前向。相对预训练，作者写这项开销仍低于 0.5%。

最优分配：固定 $n$ 时，不要在同一个 $t$ 上抽很多份掩码，而要把预算铺到不同时间步，每个 $t$ 只抽一份掩码。定理说，ELBO 的方差主要来自 $t$ 的积分，不来自同一 $t$ 下掩码的条件方差。Table 2：$n=8$ 且 $n_t/n_{y_t}=8/1$ 时，$\mathbb{V}\hat s_\theta=1.0$；同样 $n=4$ 但挤在一个 $t$ 上抽 4 份掩码，方差 7.3。

对偶抽样：$\pi$ 与 ref 共享随机源。关掉它，Table 2 里 $\mathbb{V}\hat s_\theta$ 从大约 1–4 跳到 2183.7，损失的偏好方差从 $10^{-3}$ 跳到 62。下游分数掉得没这么夸张，作者解释：VRPO 直接优化的是损失估计，不是测试集泛化；关掉对偶有时等于多看了一些不同掩码模式。即便如此，训练稳定性已经足够让人必须打开它。

数据：内部 35 万偏好对，覆盖写作、对话、知识、推理、数学、代码，过滤、去重、奖励模型排序，部分回答被更强模型替换。训一个 epoch，得到 LLaDA 1.5。评测时每个任务仍可选纯扩散、半自回归 remask、低置信 remask 里最好的那种，和原版 Instruct 公平比较时要记住采样器仍是超参。

Table 1（相对 LLaDA 8B Instruct）：GSM8K 78.6→83.3（+4.7），Math 42.2→42.6，GPQA 33.3→36.9，HumanEval 49.4→52.4，MBPP 41.0→42.8，IFEval 62.2→66.2，Arena-Hard 10.0→14.3，AlignBench 5.4→5.9，MTBench 7.2→7.3。数学和指令跟随的抬升比开放对话打分大。Arena-Hard 仍在 14 附近，和同期强 AR 对话模型不是一个量级。VRPO 证明 MDM 能吃 DPO，没有证明对齐已经打平 Claude。

离线偏好和在线可验证奖励不要焊成一种「扩散 RL」。VRPO 吃的是已经排好的赢输对，贵在每对要跑多次 ELBO；d1 吃的是对错标签，贵在每个梯度步要在线生成一组回答。写作风格没有二元标准答案，走前者；数学、代码、数独有对错，走后者。原版 Instruct 两头都没做，所以和 LLaMA3 Instruct 比缺口时，缺的是后训练深度，不一定是扩散结构。把 1.5 的 GSM8K 83.3 和 d1 的 82.1 减来减去没有意义：采样器、shot、生成长度都不锁死在同一格。

Instruct 原文 Table 2 的 GSM8K 78.6 用了块采样；1.5 的 78.6 基线写的是同一栏「LLaDA Instruct」。两篇是否锁死同一采样器，1.5 正文写「采用各任务上最好的扩散采样」。横比 83.3 和 LLaMA3 的 78.3 时，把采样器写上。

## 3. d1 与 diffu-GRPO：推理任务上的策略梯度

GRPO 用一组回答的奖励标准化当优势，不训 critic。搬到掩码模型，缺的是 $\pi(o_k\mid q)$。d1 的估法：对提示随机再掩一层（$p_{\mathrm{mask}}=0.15$），只跑一步预测器，用这一步的 token 对数概率当序列概率的代理。完整反向轨迹太贵，在线 RL 每步要生成一组回答，再估概率，套多层去噪会炸算力。一步估计有偏，但够拿来算概率比。

SFT 阶段用 s1K 的 1000 条带反思的推理轨迹，长度 4096，随机时间掩码，LoRA $r=8$。RL 阶段按任务分开训，在线生成长度锁 256，LoRA $r=128$，8×A100。GSM8K 7700 步，MATH500 6600 步，Countdown 5000，Sudoku 3800。奖励是格式加正确性，Countdown / Sudoku 用合成数据。

Table 1，0-shot，三个生成长度。LLaDA-8B-Instruct 的 GSM8K：68.7 / 76.7 / 78.2（128/256/512）。d1：73.2 / 81.1 / 82.1。MATH500：基线 26.0 / 32.4 / 36.2，d1 33.8 / 38.6 / 40.2。Countdown 在 512：基线 16.0，d1 42.2。Sudoku 在 128：基线 11.7，d1 22.1；长度再加，数独分数反而掉，作者认为这任务不吃长思维链。正文把增益概括成 GSM8K +3.9、MATH500 +4.0、Countdown +26.2、Sudoku +10.0 个百分点，对应各任务上「最好长度」那一格的差，不是三个长度的平均。

SFT 单独做、GRPO 单独做，都不如先 SFT 再 GRPO。12 个设定里 d1 有 11 个超过纯 GRPO。长度 512 时，SFT 和 d1 的轨迹里开始出现自检、回退，作者称为 aha moment，来自 s1K 里那种「算完再验」的写法。RL 之后没有出现 DeepSeek-R1 那种思维链越写越长：在线生成锁死 256，预训练本身最长 4096，再拉长目前算不起。不要把 d1 写成「扩散版 R1」。它证明策略梯度能打在掩码模型上，并且长度 128 和 512 也能沾 256 训练的光，说明学到的不全是「只在训练长度上有效的格式」。

基线 78.2 是 d1 自己的 0-shot、生成长度 512。LLaDA 原论文 Instruct 的 GSM8K 78.6 是 4-shot 加块采样。三套数字不能减来减去当消融。

## 4. 和 AR 后训练的差别

AR 的 $\log\pi(y\mid x)$ 一次前向、teacher forcing 就能精确到 token。扩散每次要对 $t$ 和掩码采样。VRPO 用预算和对偶把这件事做成「贵 8 倍但仍远小于预训练」。GRPO 用一步估计把这件事做成「有偏但能跑在线」。以后若有人把 ELBO 估进 PPO 的 KL 项，同一套降方差可以搬，1.5 文末已经把公式写出来了。

原版 Instruct 没有 RL，所以「LLaDA 指令跟随接近 LLaMA3」那句话必须带后训练状态。1.5 补上偏好，GSM8K 可以到 83.3，HumanEval 到 52.4，仍低于 Qwen2.5 Instruct 主表上的代码分。d1 补上推理 RL，数独和 Countdown 跳得更明显，因为基座在这些约束满足任务上更空。想要的能力决定走 VRPO 还是 diffu-GRPO：一般偏好对走前者，可验证奖励走后者。代码测试用例是第三条可验证线，估法换成一对互补掩码，见[代码向扩散](./code-dllm.md)的 coupled-GRPO。两者都还没公开和「同数据 AR 做完 DPO/GRPO」的严格配对。缺这张表，就不能说扩散对齐已经打平同配方的自回归。本篇只把方差问题和两张主表钉住。

PPO 在 AR 里还要估状态价值。GRPO 用组内相对奖励，省掉 critic，这是 d1 能在 8×A100 上跑起来的前提之一。即便如此，在线生成仍是瓶颈：每个梯度步要采一组完整回答，扩散每条回答还是多步去噪。他们把在线长度锁 256，不是因为 256 是最优思维链，是因为再长就训不起。VRPO 没有在线生成，吃的是离线偏好对，贵在每对要跑 $n$ 次 ELBO，不贵在和环境交互。离线偏好脏、在线奖励干净，两条路的数据假设不同。数学、代码、数独有对错，适合 d1；写作风格没有二元标签，适合 1.5。不要用 GSM8K 的 +4.7 去暗示 Arena-Hard 也能从 14 跳到 50。

LLaDA 原论文展望里写过：系统调查后训练，才能做 O1 一类系统。1.5 和 d1 是对这句话的两次部分兑现。O1 / R1 那种测试时还在长思维链上花算力的闭环，扩散这边还没有公开的同等物。生成长度是画布超参，不是 AR 那种「继续写下一个 token 直到不想写」。要把测试时计算做成连续旋钮，先得解决画布怎么动态加长。那是块扩散的领地，不是本篇的损失函数。

## 5. 失效

ELBO 预算 $n=1$ 时方差大到可以让 DPO 学反。Table 2 的 44.0 对 1.0 是这个警告的量化。省那 8 倍前向，等于把对齐做成噪声梯度。

一步概率估计忽略了反向过程的多步依赖。对「必须很多步才能自洽」的回答，优势函数会看错。d1 在数独上加长反而掉分，已经在提示：不是所有任务都该用更长画布硬套推理 RL。

在线生成长度锁 256，长 CoT 策略学不出来。这不是扩散做不到长思维，是这篇实验付不起。

偏好数据来自内部 35 万对，不可复现。VRPO 的算法可以复现，1.5 的绝对分不能当成开源配方的保证。

把 1.5 的 +4.7 GSM8K 和 d1 的 +3.9 加在同一个模型上，没有论文做过。两个后训练是否可叠加，未找到一手来源。

`[OM-FREEPLAY]` 上条叠加实验未找到。

把 DPO 的分数写成四条 ELBO 之后，加减号方向容易写反。赢的回答在 $\pi$ 上要大、在 ref 上要小；输的回答相反。对偶抽样共享掩码，不会改变这四个符号，只改变噪声。实现时若对 $y_w$ 和 $y_l$ 抽了不同的 $t$，对偶失效，Table 2 那列 2183 就是这种事故的量化。代码审查先看随机源是否共用，再看 $n_t$ 是不是铺在不同时间步。预算加到 8 却全挤在同一个 $t$，花了算力，方差定理不买账。

diffu-GRPO 的裁剪和 KL 项与 AR 相同，$\varepsilon$ 和 $\beta$ 仍在。真正换掉的是 $\phi_{\pi}(o_k\mid q')$：提示被再掩之后，预测器给出的 token 对数概率。$q'$ 而不是 $q$，等于每次更新都在稍有不同的提示噪声下估策略。作者把它当作数据增强，也能防止模型只在干净提示上过拟合。$p_{\mathrm{mask}}=0.15$ 太接近 0，估计退化成「只看干净提示的一步 MLM」，和生成时的高掩码率对不上；太大则提示信息丢失，优势函数变成噪声。0.15 是他们的工作点，换模型应当再扫。

s1K 只有一千条。扩散 SFT 对格式极度敏感：掩哪里、pad 什么、EOS 放哪，附录写了一串失败模式。直接把 AR 的 SFT 脚本改个 loss 往往训崩。d1 能做出 aha moment，很大程度是这 1000 条轨迹里已经写了「验算、回退」。RL 奖励只给格式和最终答案，中间过程没有逐步监督。这和 DeepSeek-R1「纯 RL 也能长出思维链」的叙事不同：扩散这边先用 SFT 把行为种上，GRPO 再在可验证任务上放大。纯 GRPO 也涨点，但 12 个格子里多数不如 d1。

用假数字把方差走一遍，符号就不再抽象。设真值 $\log\pi(y_w)= -80$，$\log\pi_{\mathrm{ref}}(y_w)=-82$，$\log\pi(y_l)=-90$，$\log\pi_{\mathrm{ref}}(y_l)=-88$。真分数 $s=\beta[( -80+82)-(-90+88)]=\beta(2-(-2))=4\beta$，DPO 会推 $\pi$ 再拉大这个差。ELBO 估计若在 $y_w$ 上偏了 $-10$、在 $y_l$ 上偏了 $+10$，分数符号可以翻掉，梯度朝着相反的偏好走。对偶抽样让两次偏差同号，相减后剩下的主要是偏好本身。$n=8$ 把每次偏差再除一个根号。Table 2 从 44.0 降到 1.0，对应的就是这种噪声被压到优化还能认路的程度。假数字不是论文表，只辅助看符号；真方差以 Table 2 为准。

1.5 评测写明每个任务可以在三种采样器里挑最好的。对齐改的是权重，采样器仍能把同一组权重变成三种模型。报 83.3 时若用了块采样，和 d1 的 0-shot 纯长度扫描仍不可减。后训练论文继承了前训练论文的老毛病：主表漂亮，协议写在脚注。读的人应当先翻采样器那一节，再看加分。

LoRA 在两篇里都是默认。1.5 全文没把全参数 VRPO 当主结果；d1 的 SFT 是 $r=8$，RL 是 $r=128$。扩散后训练显存紧，因为一次前向要对付双向注意力和可能的多次掩码。全参数能不能再涨点，未找到一手来源。工程上先把 LoRA 跑通，比争论该不该全参有用。

奖励黑客在扩散上有独特入口。EOS 置信一旦被奖励「短而正确」放大，纯扩散会更早停，看起来格式分很高、内容被截断。d1 的格式奖励若只检查标签是否出现，模型可以在画布任意位置堆标签。AR 的黑客通常是重复或空话；扩散还可以把正确碎片写在不相邻的掩码位上，中间一堆填充。评测抽取答案的脚本如果只搜 `\boxed{}`，会把这种碎片当成功。看 d1 附录的 case 时，应当看整段，不要只看抽出的数字。

组大小 $G$ 在 GRPO 里决定优势估计有多稳。扩散每条组员都是一次多步采样，把 $G$ 从 4 加到 16，在线成本线性涨。d1 正文没有把 $G$ 扫成主消融。实现时宁可先减小画布，不要先减小 $G$ 到 2：两组归一化的优势噪声极大，和 ELBO 方差会叠。VRPO 没有 $G$，它的「组」是蒙特卡洛的 $n$，花在同一对偏好的不同 $t$ 上，不是花在不同回答上。

离线 DPO 还有偏好对本身的噪声：标注员或奖励模型把输赢标反，VRPO 会很稳定地学反。降方差对标注噪声没有帮助，它只降估计噪声。1.5 用奖励模型排序和更强模型替换部分回答，是在修数据，不是修 ELBO。把 Table 1 的 +4.7 全部记在 antithetic sampling 名下，忽略了 35 万对是筛过的。消融 Table 2 在同一数据上变采样配置，那一列才是算法贡献。

读完两篇后训练，应当能回答：似然从哪估、方差怎么降、奖励从哪来、画布多长、有没有 LoRA。答不全，就把「扩散也能 RL」当成口号，不要写进模型卡。

和 LLaDA 专文的接法：那篇的 Instruct 表没有 RL；本篇的 1.5 和 d1 是后训练补丁。不要把 83.3 写回 2502.09992 的 Table 2。和失效专文的接法：EOS 黑客、画布长度、一步估计的偏，都在那边还有清单。

一次 diffu-GRPO 更新在机器上长这样。先用当前策略采 $G$ 条回答，每条最多 256 token，走完整反向。打格式分和正确性分，组内标准化得到优势。然后对提示再掩 15%，跑一步预测器，得到每条回答每个 token 的 $\phi$。代入裁剪后的代理目标，叠 KL 到参考策略，反传 LoRA。贵的是第一段在线生成，不是最后的 LoRA 反传。所以他们把生成长度锁死，而把 LoRA 秩放到 128。AR 的 GRPO 贵在生成长度；扩散还要乘步数。这就是「同样叫 GRPO，账单差一截」的全部内容。

VRPO 更新没有环境。抽一个偏好对，抽 $n$ 个时间步，共享掩码，跑四套 ELBO，合成 $\hat s$，过 $\log\sigma$，反传。贵的是 $n$ 次双向前向。$n=8$ 相对预训练仍然便宜，相对「我只想在笔记本上试 DPO」并不便宜。复制实验之前先按层数和序列长度估 FLOPs，不要看见「低于预训练 0.5%」就以为笔记本 overnight 能跑完 35 万对。

参考策略 $\pi_{\mathrm{ref}}$ 在两篇里都是 SFT 之后的冻结 LoRA 底。更新太猛会让 KL 项爆炸，更新太弱则 $\hat s$ 的信号被 $n=8$ 的残差噪声盖住。1.5 把 $\beta$ 和 $n$ 写在附录；复现时这两项要一起抄。只抄 antithetic、不抄 $\beta$，会出现「方差已经很小但偏好没学会」的假象：模型不敢离开 ref。AR 的 DPO 也有这个问题，扩散只是把「不敢离开」和「估计在抖」叠在同一条曲线上，更难调。调参顺序应当是：先把 $n$ 和对偶打开到方差表能看，再动 $\beta$，最后才动学习率。反过来先加大学习率，会把噪声梯度放大成一次把 ref 推飞。这不是新算法，是把 AR 调 DPO 的常识搬过来，只是噪声源多了一个 $t$。
