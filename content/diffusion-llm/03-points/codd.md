# CoDD：在冻住的 dLLM 上接一层可算联合

ParallelBench 把一步乘积的 KL 下界写成 $\mathcal{C}$。DCD 用 I-投影把 GPT-2 的依赖焊到 SEDD 的边缘上，尺度停在 GPT-2。APD 用同词表小 AR 截断从左到右的草稿。Li、Shao、Wang、Yu、Van den Broeck、Liu 的 Coupled Discrete Diffusion（arXiv:2603.00045）认为这件事在 8B 上还有第三条：不是网络表达力不够，是 Transformer 被规定只能吐一组互相独立的 logits。真要参数化成对相关，维数按词表平方涨，吐不出来。他们的补法是在冻住的骨干后面接一层可精确推断的概率回路，和因子化势能做乘积。仓库 [liuanji/CoDD](https://github.com/liuanji/CoDD)。

摘要三句数字必须拆开。+5.0 是 LLaDA-Instruct、**低置信**、MATH500、**256 步**：36.00 到 41.00。+10.8 是 Dream-Instruct、**熵**、GSM8K、**128 步**：56.18 到 67.02。34.0 到 56.4 是 Dream 熵、GSM8K、**64 步**（表上 33.97 到 56.41），不是 LLaDA。训练约 3 GPU 小时，对照 RL 基线不到 2%，测在 NVIDIA RTX PRO 6000 Blackwell。Dream 上 MATH500 逐步时延开销 3.81%–5.29%；LLaDA 128 步那格是 12.57%，不能写成「一律 4–5%」。零样本。生成长度在与 RL 对照的 Figure 3 上是 512。附录写所有任务最大生成长度都是 512，通常提前遇到结束符就停。LLaDA 主表用贪心，Dream 主表用温度 0.2 与 top-$p$ 0.95。+5.00 那一格没有采样噪声，+10.84 那一格有。两套解码器并排时，差的不只是骨干。

和 DCD 同一通讯作者。DCD 训练免费、copula 是 GPT-2、合成规则是 I-投影。CoDD 要训 PC、骨干是 7B/8B Instruct、合成规则是可归一化乘积。不要焊成一篇「外挂联合」的续集编号。

## 1. 因子化是输出规格，不是容量不够

离散扩散每步对仍掩着的位置给出词表分布，采样写成乘积。连续扩散可以每次只把所有坐标挪一点点，依赖慢慢长回来。离散一步要把若干格提交成确定的词，提交前它们只看见当前的 $x_t$，看不见彼此即将落下的字。San Diego 的两个词各自边际都可以高，乘积却允许 San York。

作者把这件事收成参数维数。条件分布被写成 $p(\bm{x}\mid\mathbf{c})=p_{\bm{\theta}}(\bm{x})\rvert_{\bm{\theta}=f(\mathbf{c})}$。$f$ 是 Transformer。若 $p_{\bm{\theta}}$ 要记住两两相关，$\bm{\theta}$ 的长度按 $V^2$ 走，8B 的词表撑不住。于是实现里 $p_{\bm{\theta}}$ 只能是各组独立 logits。哪怕 $f$ 有无穷容量，知识也必须挤过这根因子化管子。这叫结构误设，不是再加一层注意力能修好的。

Figure 1 左图在 MathInstruct 验证集上画 LLaDA 的困惑度对掩码率。顺序生成（每步揭一格、条件在已落盘的字上）当作「模型真正学会的联合」；一步生成把所有掩码格按乘积抽，困惑度高出一块，阴影叫 $\mathcal{L}_{\mathrm{gap}}$。CoDD 要在仍保持一步并行的前提下把这块阴影填回去。曲线点没有进主表，本篇不从阴影上读数。§6.2 训练写的是「固定的问答对」，没有把语料库点名为 MathInstruct。诊断图用 MathInstruct，主表用 MATH500 / GSM8K / GPQA / MBPP，三套不要焊成一份微调数据。

## 2. 乘积分布：结构先验乘因子化势能

他们把去噪分布写成

$$
\hat p_{\bm{\theta},\bm{\omega}}(\bm{x}_0\mid\bm{x}_t)=\frac{1}{Z}\,p_{\bm{\omega}}(\bm{x}_0\mid x_t)\,p_{\bm{\theta}}(\bm{x}_0).
\tag{5}
$$

$p_{\bm{\theta}}$ 仍是骨干给出的因子化势能，条件在 $x_t$ 里。$p_{\bm{\omega}}$ 是一层小的结构先验。乘积比混合更能让两个简单分布交出交叉后的尖峰（Grover 与 Ermon 2018 那套 boosted 生成模型的理由）。$Z$ 一般不可算。所以先验必须满足：乘上一组单变量势能之后，配分函数仍能精确求。

概率回路（Choi 等人 2020）是有和节点、积节点、输入节点的 DAG。积节点的孩子必须管不相交的变量（可分解），配分才能从叶子推到根。骨干的势能按位置拆开，对齐到回路叶子上的局部期望 $Z(n)=\sum_{x^i}g_n(x^i)p_{\bm{\theta}}(x^i)$，往上按式 (6) 走一遍，根节点的值就是 $Z$。采样也可以一次前向加一次后向，不必把指数大的联合展开。可分解保证没有变量在同一个积里乘自己，多项式才是多重线性，求和才能拆。词表 $V$、块长 32 时，叶子是 32 个分类分布，隐状态 1024 的 HMM 用前向算法把 $Z$ 算完，复杂度按块长线性，不按 $V^{32}$。这就是「可算」三个字的内容：不是近似归一化，是结构上允许精确求和。

实验里回路实例化成隐马尔可夫模型，隐状态 $N=1024$。HMM 是 PC 的一种：位置之间有链式依赖，边缘和条件都可以动态规划。不要把 $N=1024$ 读成 Transformer 隐层宽度，那是 PC 的隐状态数。Chiu 与 Rush 把 HMM 当语言模型 scale 过；这里 HMM 不负责独自做 LM，只负责在骨干势能上补跨格相关。词表仍由 8B 的 softmax 管。隐状态数加大，链式记忆变长，3 小时和 Table 3 开销都要重测，主表只钉 1024。再大的回路，这篇没有表。$N$ 不是扫过的超参。附录 Table 5 扫的是 $\gamma$ 和 $\tau$，没有扫隐状态数。

训练目标把扩散 ELBO 里的因子化对数似然换成 $\log\hat p_{\bm{\theta},\bm{\omega}}$。实现上冻住 $f_{\bm{\varphi}}$，预先算好所有训练样本的 logits，只优化 $\bm{\omega}$。优化器用 anemone（Liu 等人 2025，PC 专用）。数据是问答对，答案段按 $t\sim\mathcal{U}(0,1)$ 随机掩。骨干一行梯度都没有。这和 VRPO / d1 那种回传 8B 不是同一笔账。正文 3 GPU 小时写的是 PC 收敛。预计算 logits 的墙钟没有单独开列。

## 3. 掩码率高时先关掉 PC

结构先验是一份静态分布，要覆盖从全掩到几乎干净的所有噪声水平。Figure 2 在 MathInstruct 真值问答上画条件对数似然：掩码率低于约 0.8 时，CoDD 给真值的概率明显高于 Dream；到了 $\ge 0.8$，PC 帮倒忙。作者的解释是依赖形态在变：高噪声时是抽象、全局的搭配，低噪声时是局部、硬的搭配。一份静态 HMM 只能记平均值，高噪声段的信号被别的时段稀释。

于是推理时加门：当前块（或窗口）里掩码率 $r_m<\gamma$ 才调用 PC，否则退回骨干自己的因子化采样。$\gamma$ 是超参，附录 Table 5/6 扫过 0.3 到 0.8。主表没有把默认 $\gamma$ 写成单独一格，消融按任务选。高噪声步仍走原来的边际，低噪声步才把联合接上。这和「全程都用 copula」的 DCD 不同。

乘积上直接做温度缩放 $p^{1/\tau}$ 一般不可算，因为回路是混合。作者把 PC 看成深层隐变量模型：先抽一条和节点上的路由 $\bm{z}$，条件在 $\bm{z}$ 上联合塌成叶子的乘积，温度就可以打在这个条件上。这叫 latent variable sampling。AO 是另一条近似，温度打在单格条件上。两条都是为了让 $\tau<1$ 时联合还能尖，不是为了加速。附录 $\tau$ 扫 0.1 和 0.2。主表没有把默认 $\tau$ 写成单独一格。

LLaDA 走块扩散，PC 定义在块长 $L_b=32$ 上，块间仍半自回归。Dream 主表（Table 2）走整段扩散，PC 开在长度为 $W$ 的窗口上。附录 Table 7 另给了一份 Dream **块扩散**，熵、GSM8K、128 步只 +0.30（56.86 到 57.16）。+10.84 只活在整段扩散那张表上。几何一换，少步联合的增益可以几乎消失。报 Dream 必须写 Table 2 还是 Table 7。

采样可以从乘积联合里一次抽多格，也可以用任意顺序自回归近似：按骨干原来的置信度启发式决定下一格，条件分布由 PC 提供，温度 $\tau$ 打在单格条件上。后一种叫 AO。AO 要多次查 PC，PC 远小于 Transformer，Table 3 显示开销仍低于把骨干换成 RL 检查点。MATH500、LLaDA、64 步：AO 把准确率抬到 17.0，对照 LLaDA 低置信 12.6。这是少步 MATH500，不要抄到 GSM8K。

块内一步在代码里长什么样。当前块窗口 `[k L_b,(k+1)L_b)`，前面的块已经是明文。算块内掩码率 $r_m$。低于 $\gamma$ 时，骨干前向给出块内各格势能，PC 用这些势能做一次可分解前向得到 $Z$，再按 $\hat p$ 采样或按 AO 一格一格条件。提交哪些格仍由原来的低置信 / 熵 / Margin 启发式挑。PC 不改规划器，改的是候选分布。高于 $\gamma$ 时 PC 整段跳过，块内退回乘积。块填满，窗口右移。Dream 的整段版本把 PC 开在宽度 $W$ 的窗口上，窗口里掩码格多于 1 个才调用，避免单格还跑联合。Algorithm 1 / 2 在附录，主文只把门控和几何钉死。

## 7. 和 DCD、APD、RL、蒸馏怎么分

DCD：推理时 I-投影，两边冻住，GPT-2 × SEDD，32× 是 NFE。CoDD：训一层 HMM，7B/8B Instruct，主表是准确率不是步数倍数。DCD 的 copula 看不见后缀；CoDD 的 PC 在块内或窗口内对任意掩码图案做精确边缘。法律都是「骨干边际不够」，接口不是同一个。Figure 4 在 SEDD 尺度上已经把两家放在同一张条件似然图里，CoDD 更高、辅助模型更轻。换到 LLaDA 8B，DCD 没有主表，不能把 1 nat 抄成 MATH500 的 +5.00。

能量模型当 copula 是 DCD 结论里点过的同期路线（Guo / Xu 等人）。CoDD 相关工作把能量模型和 AR 辅助都算进「额外深度生成模型，开销大」那一筐，然后把自己放在可精确推断的轻量层。没有和能量模型打过同一张 8B 表。本篇也不编那一行。

APD：同词表 0.5B AR，从左到右截断，有损投机。CoDD 不要求同词表小模型，要求能训 PC 的问答对和预计算 logits。APD 没跑 LLaDA；CoDD 主表有 LLaDA 块扩散。APD 的联合发生在验证器拒绝草稿时；CoDD 的联合发生在候选分布里，规划器还是原来的低置信。两刀可以叠，没有联合实验。

d1 / diffu-GRPO 改 8B 权重，对齐数学对错。CoDD 不改骨干，3 小时换一层先验。作者写能打到 RL 那一档的 MATH500，前提是 Figure 3 那套长度 512、他们的复现。「CoDD 替代 RL」没有出处。风格偏好、指令跟随，PC 没接。

相关工作把低置信揭开算进「少并行时有效、少步时失效」：同时提交的格子一多，启发式挑不出足够多的尖格，乘积误差回来。能量模型和 AR 辅助（含 DCD）被写成额外深度生成模型、开销大。CoDD 认的根因是分布族写错，解法是轻量可精确推断层。Conditional SPN / Probabilistic Neural Circuits 让网络直接吐回路内部参数，词表一大就胀。CoDD 只让网络吐因子化势能，回路参数自己训，相乘。这条分工决定了 3 GPU 小时为什么够用：回传不进 8B。

少步蒸馏改学生每步的边际，让 32 步去拟合 1024 步。CoDD 不蒸骨干，少步增益来自联合不再是谎。64 步 Dream GSM8K 从 34 拉回 56，是「同样少步、联合更真」，不是「把老师多步蒸进来」。dParallel 压的是已经猜对的格的熵，改 LoRA；CoDD 不改骨干确定性地图，改候选的联合。可以叠，主表没有叠。

静态 PC 是限制。附录写了噪声条件化先验是后话。$\gamma$ 只是关掉帮倒忙的时段，不是让先验随 $t$ 变。多模态、置信度态，这篇没有。HMM 的链式依赖比全对相关穷，比因子化富。词表很大时叶子仍是单格分类，跨格相关靠隐状态传递，窗口一长就会淡。所以块长 32 和窗口 $W$ 不是随便取的实现细节，是先验能力的边界。把 PC 换成更大的回路，3 GPU 小时那句话要重测。

## 8. 读完应留下的判断

8B 掩码扩散的并行诅咒，有一部分写在输出头上：头只能吐因子。CoDD 用 HMM 回路把联合接回去，骨干冻住，约 3 GPU 小时。+5.00 在 LLaDA 低置信 MATH500 256 步。+10.84 在 Dream 熵 GSM8K 128 步、整段扩散。56.4 在 Dream 64 步 GSM8K。Dream 时延大约加 4–5%，LLaDA 128 步会到 12%。Table 7 块扩散 Dream 没有这十个点。不要和 DCD 的 32× NFE、APD 的 tok/s、d1 的 RL 小时焊。图 1 底栏把三句摘要拆开，正文就按拆开的读。权重还是原来的 Instruct，多出来的是 $N=1024$ 的 HMM、一道掩码率门、以及承认高噪声时先别开这层。结束符通常早于 512 出现，画布定长仍在；可变长闲聊不是这张主表的任务。
