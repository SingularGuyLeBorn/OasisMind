# 从自回归改编：DiffuLLaMA、Dream、LLaDA 2.0

LLaDA 8B 证明可以从噪声训到和 LLaMA3 同一张表。它没有证明每训一个扩散模型都应该付 13 万 H800 小时。开源 AR 权重已经把语言几何学进参数里。改编要解决的是两件结构冲突：因果掩码对双向去噪，以及「输入永远干净、预测下一个」对「输入是脏的、预测 $x_0$」。

四条工作走同一条河的不同河段。DiffuLLaMA 证明 7B 改得动。Dream 把移位和噪声日程做细，并交出和 Qwen2.5 7B 同协议的表。LLaDA 2.0 把块大小当课程接到 100B。Fast-dLLM v2 把 token 预算收到约 1B，代价是全双向填空被收进块内。没有一条改了吸收态 $Q_t$ 的定义。

## 1. 冲突在哪

AR：位置 $i$ 的隐状态 $h_i$ 用来预测 $x_{i+1}$，看不见右边。扩散：位置 $i$ 的隐状态通常用来还原 $x_i$ 自己，且要看见左右仍可见的 token。若直接把因果掩码撕掉、损失改成掩码交叉熵，作者观察到基座能力会掉光（DiffuLLaMA 文中引用的更早改编尝试）。

两套几何叠在同一组权重上。注意力掩码决定「这一格能看见谁」。预测头的移位决定「这一格的向量对哪个词负责」。噪声日程决定「输入有多脏」。三件事可以分开拧。早期失败往往是三件一起拧：掩码一步全开、损失改去预测当前格、所有位置共用一个很大的 $t$。AR 特征来不及搬家，梯度先把已经学好的下一词方向冲掉。

![](./images/fig-ar-shift-adapt.png)

> 图 1：改编保住 AR 已经学好的移位，$h_i$ 仍瞄准 $x_{i+1}$；改的是注意力掩码和输入上的噪声。

**图 1 解析**

- **上行 $h_i$ (AR) → predict $x_{i+1}$**：teacher forcing 的几何。每层隐状态的职责是下一个词，不是当前词。
- **下行 left / right visible tokens**：掩码退火之后，位置 $i$ 可以看见左右仍干净的上下文。这是扩散要的感知。
- **keep shift**：损失仍按 $h_i$ 对 $x_{i+1}$ 算。Dream 把这叫 Shift Operation。不加移位，等于让已经对齐的预测头去猜另一个位置，继续预训练要重新学位置几何。
- **图里没画噪声日程**。DiffuLLaMA 用掩码率退火；Dream 再给每个掩码位按周围可信上下文重标定有效 $t$。那是第二条旋钮。

dKV-Cache 的消融从反面证明移位不是装饰。Dream 主实验用 Un-Shift 对齐改编后的头；若推理时改成 Right-Shift，GSM8K 会被打到 32.68。缓存论文测的是解码几何，不是另训一个模型，但方向清楚：头和位置一旦对错，分数可以腰斩。细节见[推理加速](./inference-acceleration.md)。

## 2. DiffuLLaMA：退火掩码 + 保持移位

Gong 等人（ICLR 2025，arXiv:2410.17891）做三件事。

把 AR 目标与吸收态扩散目标写成可以衔接的形式。连续时间极限仍是掩码位置上的加权交叉熵，和 MDLM / LLaDA 的 $1/t$ 损失同族。改编不是换一种 $Q_t$，是让已经存在的 next-token 目标平滑接到这条 ELBO 上。

注意力掩码退火：训练过程中逐步把因果掩码放宽成双向，而不是第一步就全打开。左边始终可见，右边的可见范围随训练步变宽。直观上，模型先继续做它会的续写，再慢慢利用未来上下文去填空。

继承移位：损失仍按 $h_i$ 对 $x_{i+1}$ 算。扩散在感知上是还原信号，在「哪一格对齐哪一个词」上继续用 AR 已经学好的几何。

数据：不到 200B token，把 GPT-2（127M–355M）和 LLaMA2 7B 变成 DiffuGPT / DiffuLLaMA。能力上补了 infill（不必把填空改写成从左到右），速度上无条件生成 1024 token、256 步时与 AR 同级。这是「改编可行」的第一张 7B 成绩单，不是 2025 年最强开源 7B。词表、分词器、大部分层结构都沿用基座；新学的是「输入可以是 `[MASK]`」这件事。

## 3. Dream：同一套移位，加上按上下文改噪声

Dream 7B（港大 NLP + 华为诺亚，arXiv:2508.15487）从 Qwen2.5 7B 的权重起步，不是从噪声起步。继续预训练语料作者写成 580B token，Table 1 的 Training Tokens 一格写成 0.6T，同一数量级。Fast-dLLM v2 引用约 580B 来对照自己的 1B，出处要写清。

两条关键设计。AR 初始化加移位，使扩散训练不把 $h_i$ 的职责改去预测 $x_i$。context-adaptive token-level noise：每个掩码位的有效噪声水平按周围还有多少可信上下文重标定，避免所有格子共用同一个 $t$。周围已经很干净时，这一格不该再被当成「几乎全掩」来训；周围也全是掩码时，这一格的有效噪声应该更高。损失仍是吸收态加权交叉熵。

Table 1 带 $*$ 的四列（Dream、LLaDA 8B、Qwen2.5 7B、LLaMA3 8B）是作者同一套协议。Dream Base：MMLU 69.5（5）对 Qwen2.5 的 71.9；GSM8K 77.2（8）对 78.9；HumanEval 57.9（0）对 56.7。规划任务上差距拉大：Sudoku 81.0 对 21.0，Countdown 16.0 对 6.2，Trip planning 17.8 对 3.6。LLaDA 8B 在这张表上 GSM8K 是 70.9（8-shot）、HumanEval 是 32.9，和 LLaDA 原论文 Table 1 的 4-shot 70.3 / 0-shot 35.4 不是同一格。报「Dream 超过 LLaDA」时，用 Dream 的 $*$ 表，不要把两篇的 HumanEval 减着玩。

Table 2 是 SFT 之后。Dream Instruct 用 180 万对、3 个 epoch。MMLU 67.0、GSM8K 81.0、HumanEval 55.5、IFEval 62.5。对照 Qwen2.5 7B 的 SFT+RL：76.6 / 91.6 / 84.8 / 74.7。扩散这边仍只有 SFT。代码和数学的缺口在后训练，不在「7B 改编失败」。细表与吞吐对照见[Dream / Mercury / Seed](../03-models/dream-mercury-seed.md)。

学习率被作者单独点名。太大，会把基座里从左到右的知识冲掉，扩散阶段几乎从零再学；太小，扩散训不动。1B 尺度上他们扫过初始化、移位、噪声重标定，再把配方接到 7B。这不是「换个损失就能改」。

## 4. LLaDA 2.0：块大小当课程

2.0 不从 GPT-2 起步，从 Ling-mini / Ling-flash 的 AR MoE 起步，把 AR 看成 $B=1$ 的块扩散。WSD：warmup 加大块，stable 全序列，decay 收回部署块。这是改编与块扩散的乘积。100B 的知识主体仍是 AR 阶段，扩散阶段改生成过程。数字见[LLaDA 专文](../03-models/llada-frontier.md)。

和 Dream 的差别在「改编完成之后还剩多少双向」。Dream 仍是全序列掩码扩散，填空、任意顺序是结构能力。2.0 部署时块已经收小，块间因果、块内扩散，KV 能接上，任意跨块 infill 变弱。选型时问任务要不要任意位置填空，要不要接现有推理框架。

文档边界切断注意力，是改编预算变大之后才会爆出来的系统问题。把多篇文章拼成 32k 再做双向，模型会把下一篇的开头当成本篇的未来上下文。小模型、短序列上不容易看见；100B、32k 上会把去噪学脏。这和 $Q_t$ 无关，和「改编是不是从 AR 继承」有关：AR 阶段本来就按文档因果训练，突然给它跨文档的未来，捷径比从零训的扩散更诱人。

## 5. Fast-dLLM v2：数据再降两数量级

约 1B token 微调，块扩散加互补注意力掩码，分层缓存。相对 Dream 那种数百 B 的全注意力改编，卖点是接上现有 AR、接上 KV、接上吞吐，不是填空能力拉满。吞吐相对 Qwen2.5-7B-Instruct 报过 2.54 倍，且准确率不低于他们的 Fast-dLLM-LLaDA 基线。互补掩码要保证：同一套权重在这块图案下，仍能算出与 AR teacher forcing 兼容的项，改编才不会把已经学好的 next-token 几何拆掉。

| | 纯 AR | 块扩散改编 | 全双向改编 |
|---|---|---|---|
| 数据量级 | — | v2 ~1B | DiffuLLaMA &lt;200B；Dream ~580B |
| 起点 | — | 现成 AR | 现成 AR |
| 部署 KV | 真 | 块间真 | 默认无，后做近似 |
| 任意 infill | 弱 | 弱于全双向 | 强 |
| 代表 | Qwen / LLaMA | 2.0、v2 | Dream、DiffuLLaMA |

## 6. 失效

退火太快：双向一上来，AR 特征塌。移位不加：每层隐状态的预测对象错位，继续预训练要重新学位置几何。只改 mask 不改目标：模型仍在做 next-token，测试时按扩散采样会分布外。改编预算过小又想全双向 32k：2.0 用文档边界切断注意力，就是在防打包作弊；小预算改编更容易学到这种捷径。

学习率太大：基座被洗掉，等于用很贵的方式从零训了一个更差的扩散。学习率太小：掩码预测头动不了，推理时仍像 AR，却按扩散采样，两头不靠。

把 Dream Table 1 的 LLaDA 列和 Nie et al. Table 1 的 $*$ 列横减：shot、解码、是否同一 harness 都可能不同。HumanEval 32.9 对 35.4 就是这种假差值。

把 v2 的 1B 写成「Dream 白训了 580B」：两条路线交付物不同。580B 买的是全双向 7B；1B 买的是块扩散加缓存。填空产品走前者，续写吞吐走后者。

读完应能把四条工作放进同一句话：DiffuLLaMA 证明 7B 改得动；Dream 把移位和噪声日程做细；2.0 把块当课程接到 100B；v2 把 token 预算收到约 1B。没有一条改了 $Q_t$ 的吸收态定义。

改编的本质是迁移已经学好的位置几何，不是迁移「从左到右」这个禁令。因果掩码是禁令，移位是几何。禁令要拿掉，几何要保住。拿掉禁令却不保住几何，等于让每一层的向量去瞄一个它从未负责过的词；保住几何却不拿掉禁令，等于仍在训 AR，测试时却按扩散采样。四条工作的差别，在于拿掉禁令的速度（退火还是 WSD）、保住几何的方式（移位还是互补掩码）、以及拿掉之后双向范围有多大（全序列还是块内）。选哪一条，先问产品要填空还是要 KV，再问付得起多少 token。

从 AR 继承还带来一种新的作弊：文档打包。AR 阶段本来按文档因果训练，突然给双向窗口，下一篇的开头会变成「未来上下文」。从零训的扩散也会遇到打包问题，但改编模型更熟悉「左边是历史」这种统计，捷径更诱人。2.0 在边界切断注意力，并在张量并行组内广播同一份掩码，就是在堵这条捷径。小预算、短序列上不容易复现，100B、32k 上会把去噪学脏。看见「改编不收敛」，先查打包和掩码是否在并行组内一致，再查学习率是不是把基座洗掉了。

token 预算从 13 万 H800 小时的从头训，收到 DiffuLLaMA 的不到 200B，再收到 Dream 的约 580B，再收到 v2 的约 1B，看起来像一条单调下降的曲线。曲线是假的。横轴其实是「你要多少双向」。全双向 7B 目前仍要数百 B 量级的继续预训练；块扩散加互补掩码可以把预算打到 1B，因为大部分几何继续当 AR 用。2.0 的 100B 更不是 1B 乘一个系数：它继承的是已经训好的 MoE，WSD 花的是转换计算，不是从噪声堆 100B 的数据。把四条预算画在一张对数图上当「改编越来越便宜」，会让人以为 1B 也能训出 Dream 那种全双向填空。买不到。

词表和分词器通常沿用基座。这看起来像小事，却决定了改编能不能直接加载检查点。DiffuLLaMA 改 LLaMA2，Dream 改 Qwen2.5，2.0 改 Ling。换词表等于让嵌入层从噪声开始，便宜的改编立刻变贵。有人想把 LLaDA 8B 的扩散头接到 Qwen 词表上，那不是改编，是拼接两个不兼容的几何。本篇讨论的改编，默认嵌入和预测头与基座对齐，只改 mask 与目标。

学习率那一刀在 7B 上比在 1B 上更狠。基座里从左到右的知识存成方向，学习率大会把方向冲成各向同性的噪声，扩散阶段看起来在学，其实在重建已经被毁的特征。Dream 把它写成必须单独挑选的超参。没有公开「7B 上扫过的学习率表」的逐点数字，本篇不编。能写的只有：改编失败时，先把学习率降下来看基座能力还在不在，再怪扩散目标。
