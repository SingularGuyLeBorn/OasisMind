# Eso-LM:任意顺序损失,因果注意力换精确 KV

[任意顺序与概率因式分解](../../../02-数学与生成机制/2.4-任意顺序与概率因式分解/2.4-任意顺序与概率因式分解.md)区分了生成顺序与注意力结构.LLaDA / MDLM 都支持任意顺序,但每揭开一次就要重算整段 $K,V$.块扩散通过固定块间顺序恢复前缀缓存,块内仍使用双向注意力.Eso-LM(Sahoo 等人,arXiv:2506.01928)保留对排列求期望的训练目标,把注意力改为因果结构,从而在扩散阶段精确复用 KV.名字里的 Esoteric 指用于探索语言边界的深奥编程语言,与前向核 $Q_t$ 无关.

并行生成不必绑定双向注意力.Eso-LM 通过洗牌把生成顺序移到序列本身,再用因果注意力恢复 KV Cache.下文分别比较 A/B 两档,PPL 表以及 14× / 65× 的基线.实验骨架是 LM1B / OWT 上的 DiT 尺度,参数量没有达到 7B.

## 1. 损失任意,注意力不必双向

吸收态 $1/t$ 损失在期望上等于对生成顺序求自回归负对数似然.这个等价关系约束训练**目标**,并不规定 Transformer 中 Query 的可见范围.MDLM 用全双向注意力参数化任意顺序条件,当前所有可见 token 都可作为上下文.代价是 Key 依赖整句以及尚未揭开的占位符;新揭开一个 token 后,所有 $K,V$ 理论上都会变化.

任意顺序 AR 本来就允许因果注意力:把序列按某条排列 $\sigma$ 排好,再做下三角.Eso-LM 把这条老路接回掩码扩散.给定 $z_t$,把干净 token 聚到左边,MASK 聚到右边,**位置编码仍用原句的下标**(RoPE / 绝对位置都不跟洗牌走).然后走标准因果注意力.左边的干净前缀再也不会依赖右边尚未揭开的 MASK,KV 可以写进缓存.MASK 之间按洗牌后的次序因果可见:本步要揭的那些 MASK 能看见全部干净字,以及排在自己前面的其它 MASK.

![Eso-LM 通过随机顺序训练与原位置编码在因果注意力下实现任意顺序生成](../images/fig-eso-shuffle-causal.png)

> 图 1:左列按原序使用全双向注意力,无法精确复用 KV.右列先洗牌再使用因果注意力,已确定前缀的 KV 可以持续复用.任意顺序损失与双向解码并不绑定.

**图 1 解析**

- **左列 mixed clean and MASK**:LLaDA / MDLM 默认.位置 $i$ 的 Query 看见所有 $j$.
- **every token attends every other**:揭开任意一格,所有 Key 过期.
- **NFE times $L^2$**:步数乘全序列注意力.并行揭开减的是 NFE,减不掉每一次前向的 $L^2$.
- **右列 gather clean left**:洗的是计算图,不是语义顺序.RoPE id 仍是「这个词在句中第几号」.
- **causal attention; exact KV**:干净前缀单调变长,和 AR 的前缀同构,只是前缀里的词不一定是从左到右长出来的.
- **65× vs uncached MDLM**:Table 11 在 $L=8192$,最坏 $T\gg L$,禁 nucleus,A6000.对照物是无 KV 的 MDLM,不是 AR,不是 Fast-dLLM 的 27.6×.

例如原句为 $(A,B,C,D,E,F)$,当前 $z_t=(A,\mathrm{M},C,\mathrm{M},\mathrm{M},F)$.洗牌后的计算序列可以是 $(C,A,F,\mathrm{M},\mathrm{M},\mathrm{M})$,RoPE 仍分别使用原位置 3,1,6,2,4,5.在因果掩码下,第一个 MASK 看见 $C,A,F$,后面的 MASK 还可看见排在前面的 MASK.$A$ 的 Key 不依赖任何 MASK,下一步揭开新 token 时,只需把它的 KV 追加到干净前缀.全双向注意力则需要重新计算整段 KV.

洗牌时必须同时保留原位置 id.若把左侧三个干净 token 重新编号为 1,2,3,模型会把 $C,A,F$ 误认为句首.RoPE 的相对位置应描述 token 在原句中的距离,而非洗牌后计算序列中的次序.因此 token 表示随内容移动,RoPE 角度仍取原下标;缺少后一项会破坏句法与语义位置关系.

注意力偏置写成 $A\in\{-\infty,0\}^{L'\times L'}$,并加到 Softmax 前的 logits.训练使用两种 $A$:扩散样本采用洗牌后的下三角偏置;顺序样本把干净 token 放在左侧,MASK 保持原相对次序,并允许 MASK 看见 shift-by-one 对应的干净版本.两种偏置共用同一套权重.训练与推理都采用因果依赖,因此缓存的 KV 与实际计算图一致;仅在推理时把双向模型改为因果掩码无法获得这种性质.

## 2. A 档贴近似然,主方法换 KV

作者把「从 MDLM 走到可缓存」拆成两刀.

Eso-LMs (A):MASK 上因果,干净位之间仍双向.扩散阶段不能精确缓存干净字的 KV,因为干净字互相看见,也仍可能被尚未揭开的结构影响.附录 Table 9 / 10,$\alpha_0=1$ 全扩散时,A 档 LM1B NELBO PPL 30.96 对 MDLM 31.78,略好;OWT 26.21 对 25.19,略差.论文说 matches.他们不追求 A 档,因为它在扩散阶段仍没有他们要的 KV.

主方法(正文里的 Eso-LMs):干净位也因果.这才换来扩散阶段精确 KV.同一 $\alpha_0=1$,LM1B NELBO 36.12 对 MDLM 31.78,大约 +4 PPL;OWT 30.06 对 25.19.缺口来自「干净字不能互相看」.似然竞赛输了这一截,换的是缓存.

噪声日程还包含 $\alpha_0$:$\alpha_t=\alpha_0(1-t)$.$\alpha_0=1$ 接近纯扩散;$\alpha_0=0$ 回到 AR 精确似然(LM1B 21.86,与带 AdaLN 的 AR 相同).中间值在两套损失之间插值,batch 中一部分样本走扩散,另一部分走顺序填充.Table 1 同时报告 Exact 与 NELBO.$\alpha_0=0.125$ 时 LM1B Exact 为 23.02,接近 AR 的 22.83,同时保留一段可并行的扩散期.$\alpha_0$ 控制质量与速度的工作点,而非定义新的前向核.

主方法还声称第一次给 MDM 报**精确**似然(重要性加权,LM1B 用 $K=5000$,OWT 用 $K=1000$).MDLM 通常只报 NELBO.OWT 上 $\alpha_0=1$ 的 Exact 29.31,和 MDLM 的 NELBO 25.19 仍有缝.他们强调 $\alpha_0=1$ 尽管 NELBO 差一截,固定采样时间下生成质量仍优于 MDLM,因为每步便宜.似然表和速度表要一起读.

精确似然为什么现在才可算.双向 MDM 的潜变量是整条掩码轨迹,重要性加权要 $K\times L$ 次前向,一般不可行.任意顺序写法里,一条排列 $\sigma$ 已经串起这条轨迹上的所有潜变量,单样本估计方差更小.Table 2 用一条 OWT 句子,100 次试验:$\mathcal{L}_{\mathrm{MDM}}$ 抽 10 个 $(t,z_t)$,标准差 0.56;$\mathcal{L}_{\mathrm{AO}}$ 只抽 1 个 $\sigma$,标准差 0.03,均值几乎一样.这是工程动机,不只是论文审美.LM1B 句子短($L=128$),他们甚至给 MDLM 跑了 $K=1000$ 的 IW,精确似然仍落后 AR.扩散在似然竞赛上的缝,不全是估计器太松,也有模型族自己的缝.Eso-LM 用因果参数化,至少让「缝有多大」第一次能写在 Exact 列里.

## 3. 采样两阶段,一份 KV

生成先走扩散期:每步揭开一个或多个不必相邻的 MASK,前向只喂「已干净 ∪ 本步要揭的 MASK」,不是整段占位符.再走顺序期:剩下的 MASK 从左到右一个一个填.两期共用同一份 KV.第 $k$ 步把第 $k-1$ 步新干净字的 KV 写入,更早的前缀直接复用.原则上调度 $\mathcal{S}$ 可以在测试时改,不必等于训练时见过的那条.

和 BD3-LM 的差别不在「能不能插值 AR」,在缓存完不完整.块扩散:块间真 KV,块内双向,块内无精确 KV.少步时 BD3-LM 会出又差又没多样性的样本,作者写得很难听.Eso-LM 少 NFE 时仍和 MDM 竞争性,高 NFE 时贴近 AR.帕累托图(Fig. 4 / 17)是无条件生成,生成 PPL 与 MAUVE,不是 HumanEval.

相对 BD3-LM,长上下文延迟约 3–4×:Table 11,$L=8192$ 时相对块长 16 约 3.2×,相对块长 4 约 3.8×.相对无 KV 的 MDLM:$L=2048$ 约 14×,$L=8192$ 约 65×.测速在单卡 A6000,吞吐另在 H200.最坏设定 $T\gg L$,关掉 nucleus.长度越长,无缓存基线越亏,倍数越好看.短句,已经很快的 AR serving,看不到 65.

在相同 NFE 下,Eso-LM 比 AR 略慢,因为 KV 到倒数第二步才完全可复用:新 MASK 第一次出现时还不能作为历史.Eso-LM 的加速基线是每步执行 $L^2$ 双向注意力的 MDLM,不是经过成熟 serving 优化的 vLLM 因果模型.

MDLM 的一次去噪会对全部 $L$ 个位置计算注意力,即使其中大部分仍是占位符.Eso-LM 第 $k$ 步只把 $\cup_{i\le k}S_i$ 送入网络,其中包含已经干净的 token 和本步要揭开的 MASK.长序列的早期步骤只处理少量位置,激活长度因而远小于 $L$.65× 加速同时来自 KV 复用和前向集合缩减.若实现仍把全序列填充进 CUDA graph,后一部分收益会消失.论文的调度 $\mathcal{S}$ 与注意力偏置共同确定有效前向集合,仅实现 KV 缓存会低估完整方法的加速幅度.

## 4. 和 DualCache,块扩散,LLaDA 8B 分开

Fast-dLLM DualCache 是**近似**:承认 $K,V$ 会变,赌相邻步余弦相似度高.Eso-LM 是**精确**:注意力定义让干净前缀的 $K,V$ 不再依赖未来 MASK.近似可以贴在现成 LLaDA 权重上,训练免费;精确要按洗牌+因果重训(或从 MDLM 改注意力再训).27.6× 贴的是原版逐步揭开的 LLaDA;65× 贴的是无缓存 MDLM.两张卡,两种骨架,两种对照物.

块扩散把任意顺序限制在块内,以获得块间 KV 缓存.Eso-LM 仍可在全序列并行揭开不相邻的 MASK,不会受到未来块不可见的限制,代价是主方法中的干净 token 之间也采用因果依赖.A 档恢复干净 token 间的双向注意力,同时失去扩散阶段的精确 KV.跨句填空更适合全双向或 A 档,长序列无条件生成与缓存更适合主方法.目前还没有 8B 指令模型上的同规模对照.

LLaDA 8B 于 2025 年 2 月发布,论文明确指出全双向注意力与当时的 KV 缓存公式不兼容,因此采用 MHA 而非 GQA.Eso-LM 是同年 6 月沿 MDLM 路线发表的后续工作,实验停留在语言模型基准,下游任务留作未来工作.正文还提到 Sahoo 等人 2026 年把 $\alpha_0=1$ 扩展到 1.7B,在零样本似然任务上与 MDLM 具有竞争力.该结果的模型规模和任务都不同于 LLaDA 8B 的 GSM8K,因此 65× 不能直接作为 LLaDA 产品加速数据.

GQA 在因果前缀上重新具有明确收益.干净前缀的 KV 可以精确复用,减少 KV 头能够直接节省有效缓存内存.Eso-LM 实验没有采用 GQA,只证明了这种组合在依赖结构上可行.未来若出现因果洗牌的 7B 模型,GQA 与 KV 量化可以沿用 AR 系统的实现方式.这属于架构上的可能性,并非当前检查点的规格.若开放 8B 模型同时要求精确 KV 与双向填空能力,仍需在 A 档和块扩散之间取舍.65× 与 27.6× 分别使用不同模型和基线,不能放在同一协议下直接比较.

洗牌实现还要同步移动位置 id,否则 RoPE 会把所有干净 token 解释为句首.训练时 MASK 的因果次序来自 $\sigma$,测试时可以更换调度,前提是已预测 token 不再依赖未预测 token.若只洗牌 token 而未同步调整注意力偏置,计算图会偏离因果约束,缓存的 KV 也无法精确复用.

## 5. 插值,混合损失及其与 MTP 的区别

$\kappa=0.5$ 表示半个 batch 走扩散损失,半个走顺序损失.$\alpha_0=1$ 时他们关掉顺序项,并把扩散系数换成 $-1$ 以降低方差.消融 Table 4 扫过 $\kappa$.混合不是「两个模型蒸馏」,是同一套因果 Transformer 用两种注意力偏置.MTP / Medusa 一次猜未来几个 token,验证仍走左到右.Eso-LM 扩散期猜的是任意位置的 MASK,位置编码还是原下标.投机解码的草稿拒绝,这里没有对应物:提交策略仍是扩散自己的 $\mathcal{S}$.

附录还改进了少 NFE 下的启发式采样:优先揭开等间距且彼此远离的位置,而非集中处理相邻位置.并行度为 4、长度为 1024 时,首批位置是 0,255,511,767.近邻位置条件相关更强,同时揭开更容易放大因子化误差;远距离位置近似独立,少步时质量损失较小.这种规则与显式规划器的脏净预测头不同.Eso-LM 也可以均匀揭开 MASK,其主要速度收益来自 KV 复用与缩减前向集合,而非学习揭开顺序.

和 XLNet 的差别再写一遍.XLNet 每步仍对一个位置做因果预测,排列随机,没有并行揭开.Eso-LM 扩散期一步可以动多个不相邻 MASK,顺序期才退化成一次一个.共享的是「顺序不必从左到右」和「计算图可以因果」.不共享的是掩码扩散那套 $t$ 和并行提交.把 Eso-LM 写成「XLNet 换了个名字」,会丢掉 NFE 可以小于 $L$ 这件事,而这件事才是扩散还留在题目里的理由.

AdaLN 在这批实验里是参数公平问题.DiT 默认有时间条件,MDLM 把时间固定成 $t=0$,因为吸收态要学的是干净条件.AdaLN 仍占参数.作者给 AR 基线也训了带 AdaLN 的版本,LM1B 从 22.83 到 21.86.Eso-LM 的 $\alpha_0=0$ 对齐的是带 AdaLN 的 AR,不是更瘦的那只.抄 PPL 时连这一行一起抄.

## 6. 失效

因果干净位会伤害需要「已写字互相看」的条件.括号若两边都已是明文,主方法里后写的那个在计算图上可能看不见先写的那个,取决于洗牌次序.A 档或全双向没有这个问题.长文档里指代,表格对齐,双向仍更顺.Eso-LM 的帕累托赢在无条件生成的速度-质量曲线,赢不了「任意 infill 必须看见两边」.

65× 依赖 $L=8192$ 和无缓存基线.聊天平均 32 个 token 的回复,倍数接近 1.A6000 延迟卡和 H200 吞吐卡不是同一块硅.禁 nucleus 的最坏设定让基线更慢.产品对照应当用自己的长度和采样器重测.

NELBO 增加约 4 PPL,代价换来更低的有限时间生成延迟.精确似然和模型选择更适合参考 MDLM / A 档,长序列采样延迟则对应主方法.两个指标回答的问题不同,不能用其中一张表替另一条路线下结论.

论文没有提供 8B Instruct、HumanEval 主表或与 Fast-dLLM 的同卡对照.对现有 7B–8B 开放权重模型,可直接复用权重的方案仍是 DualCache 与 dKV-Cache.Eso-LM 证明的是一种架构可能性:精确 KV 可以与全序列并行生成同时存在.这一结论来自 2025 年 6 月的 DiT 实验,不能视为同年 2 月 LLaDA 8B 检查点已经具备的规格.

训练成本:OWT 250k 步,$\alpha_0=1$ 约 27 小时,$\alpha_0<1$ 约 37 小时,8×H200.预训相关合计约 9k H200 小时.这是小模型把注意力偏置扫清楚的计算代价,不是 13 万 H800 小时那一档.

BD3-LM 把并行范围限制在块内:块太小会接近 AR,块太大又会在低 NFE 时同时揭开过多位置.实验中,低采样步数使样本质量和多样性同时下降,结果甚至低于高 NFE 的 AR 与低 NFE 的其他扩散模型.Eso-LM 不使用固定块切分任意顺序,低 NFE 时更接近普通 MDM:质量会下降,但没有出现同等程度的多样性坍缩.因此帕累托图把 BD3-LM 作为主要相邻方案.块长 $B$ 在常规设置下控制质量与速度,到少步极限时会放大一次并行提交的误差.Eso-LM 用因果注意力换取 KV Cache,少步时退回 MDM 式行为,而非失效的半自回归采样.

零样本似然 Table 5:七个未见集里四个仍保持 AR < Eso-LM($\alpha_0=0.125$) < MDLM 的次序,和 OWT 验证集一致.插值不是只在训练分布上成立.它仍然是困惑度,不是 GSM8K.把 Table 5 写成「指令模型已经插值成功」,没有那张表.

## 7. 关键实验规格

- 任意顺序损失 ≠ 双向注意力.洗牌 + 原位置 RoPE + 因果,扩散阶段可以精确 KV.
- 主方法 $\alpha_0=1$:LM1B NELBO 36.12 对 MDLM 31.78(约 +4);A 档 30.96,贴近 MDLM,扩散阶段无精确 KV.
- $\alpha_0=0$ 收回 AR 似然.中间值插值.
- 相对无缓存 MDLM:L=2048 约 14×,L=8192 约 65×(A6000,$T\gg L$).相对 BD3-LM 约 3–4×.对照物不是 AR.
- 尺度:LM1B / OWT,DiT.不是 LLaDA 8B.

块扩散使用块内双向注意力,换取块间精确缓存;Eso-LM 使用全序列因果洗牌,换取扩散阶段的精确缓存.Fast-dLLM 的近似缓存可以直接用于现成权重,Eso-LM 的精确缓存则需要按相应注意力结构训练.任意顺序目标对排列求期望,计算图仍然可以保持下三角.

标题中的 hybrid 指损失与采样阶段的混合:同一套因果权重既能在扩散期并行揭开 MASK,也能在顺序期从左到右生成.网络层之间不会切换因果与双向注意力,变化的是注意力偏置 $A$ 和调度 $\mathcal{S}$.训练采用双向注意力、推理临时改成因果注意力时,缓存依赖与训练计算图不一致,会造成质量下降.实现精确 KV 需要同时满足两个条件:干净前缀的 Key 不依赖任何 MASK,RoPE 使用原序列下标.
