# 联合依赖与结构设计

一次预测多个 token 的真正难点不是“看不看右边”，而是多个待预测位置如何保持联合一致。因子化去噪头通常给每个位置一个条件边缘分布；当位置间依赖很强时，同时独立采样会把边缘上都合理、联合起来却冲突的 token 拼在一起。

## 四层结构

- [`4.1` 双向注意力与反转问题](4.1-双向注意力与反转问题.md)：注意力可见性、训练因式分解和数据方向的边界。
- [`4.2` 块扩散与混合因式分解](4.2-块扩散与混合因式分解.md)：块间因果、块内去噪，把并行度变成可调旋钮。
- [`4.3` 因子化障碍与联合建模](4.3-因子化障碍与联合建模/4.3-因子化障碍与联合建模.md)：copula、残差能量、可算联合层与连续草稿。
- [`4.4` 规划填槽与混合解码](4.4-规划填槽与混合解码/4.4-规划填槽与混合解码.md)：先定顺序、槽位或草稿，再局部生成。

## 证据规则

理论结论必须写清层数、位置编码、噪声过程和可表示分布的假设；论文系统结果必须写清骨干、步数、长度与比较协议。单篇 2025–2026 预印本不被写成已经解决联合依赖的通用答案。

基础来源：[BD3-LM](https://arxiv.org/abs/2407.10999)、[Energy-Based Diffusion Language Models](https://arxiv.org/abs/2410.21357)。
