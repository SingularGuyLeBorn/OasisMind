# 多模态扩散:LLaDA-V,MMaDA,Dimple

前面几篇已经在纯文本上推导了噪声,损失与采样.多模态要回答的是:图像进了序列以后,吸收态还作用在哪一类符号上.像素空间加高斯属于图像扩散;这里的三条路线都以离散语言扩散为语言塔,或者把视觉特征投影进词嵌入,或者把图像量化成离散码,再和文本一起做掩码去噪. 三种接法改动的层次不同.LLaDA-V 使用 SigLIP 加 MLP,噪声和损失仍只作用于回答文本.MMaDA 用 VQ 把图像变成离散码,图文共享同一套扩散过程.Dimple 先以自回归训练对齐视觉与语言,再切换为扩散生成.实验数字采用 LLaDA-V Table 2–3;Dimple / MMaDA 在当前材料中只比较机制,不转录二手综述分数.

## 1. 插槽:视觉进嵌入,噪声仍在字上

自回归多模态的默认接法是 LLaVA:视觉塔抽出图块特征,MLP 投进 LLM 的词嵌入空间,后面仍按从左到右写回答.LLaDA-V(You 等人,arXiv:2505.16933)把输出生成改成掩码扩散.视觉塔用 SigLIP 2,投影用两层 MLP,语言塔就是 LLaDA 8B.训练目标仍是只掩回答,提示保持干净,只是提示里现在既有字,也有一串视觉嵌入.

![LLaDA-V 将视觉编码结果投影到语言槽位并参与掩码扩散去噪](images/fig-llada-v-slot.png)

> 图 1:图像经视觉塔和 MLP 进入 LLaDA 的嵌入空间.虚线是干净的文本提示;实线是回答段上的迭代揭开.像素本身不进 $Q_t$. **图 1：跨模态状态与噪声路径.**

- **SigLIP2 vision tower**:把图切成 patch,得到连续特征.这一段和 Qwen-VL,LLaVA 同类,不是新的扩散前向.
- **MLP projector**:把视觉特征的维数拧到语言嵌入.第一阶段常常只训这一层,让两边说话.
- **LLaDA 8B language tower**:双向掩码扩散.图块和提示作为干净条件,回答位置按 $t$ 掩.
- **text prompt 虚线**:用户问题不进损失,和纯文本 SFT 式 (3) 同一纪律.
- **text answer tokens**:生成时从掩码走反向.噪声法律没改,改的是条件里多了一排看见过的图.

LLaDA-V 没有在像素上定义 $Q_t$,吸收态仍作用在回答 token 上.双向注意力让回答格同时看见图块和已揭开的字,改变的是条件信息,没有引入新的噪声家族.因此,LLaDA-V 是视觉条件下的语言扩散,不能归入「图像扩散接上语言」. 高分辨率处理是作者自己写的局限.大图被切开,缩放,再拼特征,没有 Qwen2-VL 那种原生动态分辨率.效率与细表理解都会付税.Table 3 上图表,文档相对 LLaMA3-V 并不占优,和这条实现税对得上,不要先怪扩散目标.

## 2. 注意力图案:对话因果还是全双向

多轮图文对话里,可以给轮与轮之间加因果掩码,轮内双向;也可以整段不掩.LLaDA-V Table 4 在 LLaVA-NeXT 设定上扫过这两套.无掩码在多数格上略好:MMMU 44.67 对 42.89,MuirBench 33.88 对 28.69.主模型采用无掩码.注意这张消融不是 Table 2 的主评测设定,数字不能和 48.6 横减. 无掩码也有明确代价:视觉前缀的 Key 会随回答揭开而变,严格 KV 默认不成立.LaViDa 后来做 Prefix KV-Cache,先缓存视觉和提示的键值,生成中途不再更新图块表示.这是后续加速论文的设计,LLaDA-V 主文并未默认使用.讨论「多模态扩散也能 KV」时,必须区分视觉前缀缓存和去噪回答的动态 KV.

公平对照要求同一套视觉指令数据,同一套训练阶段,只换语言塔.LLaDA-V 把这条基线叫做 LLaMA3-V.Table 2,多学科知识与数学推理:

| MMMU-Pro standard | 35.2 | 28.3 | 43.5 |
| MMMU-Pro vision | 18.6 | 14.5 | — |

## 4. 另外两条河:统一离散码,以及先自回归再扩散

MMaDA(Yang 等人,arXiv:2505.15809)不走「视觉塔 + 语言塔」的 LLaVA 插槽.文本用 LLaDA 的分词器,图像用 Show-o 那套基于 MAGVIT-v2 的量化器,码本 8192,下采样 16,一张 512×512 的图变成 $32\times 32=1024$ 个离散码.图码和字进同一套 Transformer,目标仍是预测被掩的离散符号.理解,生图,文本推理可以共享前向.生图采样走低置信 remask 加余弦日程,50 步,CFG 3.5;文本采样走 LLaDA 那种块内扩散,块间从左到右,评测写过总长 1024,512 步,块长 64.两套调度器使用各自的 $T$,不能混用.

后训练混入长思维链数据,UniGRPO.d1 则固定掩码率,因为 LLaDA 估计似然需要多次蒙特卡洛采样.UniGRPO 对每个回答抽 $p_i\sim U[0,1]$ 再掩,让策略在几乎全掩到几乎干净的各阶段都见到梯度.这属于多模态对齐方法,没有改变 $Q_t$.MMaDA 主表横跨理解,生图和文本三套基准,口径与 LLaDA-V Table 2 的 harness 不同.MMMU 30.2 等综述转述数字缺少同表协议,无法参与两者比较.

Dimple(Yu 等人,arXiv:2505.16990)走第三条河.视觉塔来自 Qwen2.5-VL,语言塔是 Dream 7B,投影随机初始化.作者发现纯离散扩散从一开始对齐视觉和语言,训练不稳,有严重长度偏差.配方改成两段:先把 Dream 的注意力改回因果,按 LLaVA-NEXT 的数据做自回归对齐和指令微调;再打开全双向,只掩回答,把并行解码接回来.Dream 本身从 Qwen2.5 改编而来,自回归损失不会把几何冲光,这是与 AR 权重改编时保留输入输出对齐的做法一致. Table 1 与 LLaVA-NEXT 同数据量级(约 1.3M 样本,0.8B token).Dimple 平均 62.4,LLaVA-NEXT 58.5,高 3.9 个百分点.逐格:MMMU 45.2 对 35.8,MMBench 74.6 对 68.7,ChartQA 63.4 对 54.9,AI2D 74.4 对 65.4,MathVista 42.3 对 33.0.消融写明:先自回归再扩散(设定 F)MMMU 到 45.2;只做扩散或只做自回归都更差.45.2 和 LLaDA-V 的 48.6 不是同一协议,不要减.对 Qwen2.5-VL(数据量大一个数量级以上)仍落后,作者自己把缺口记在数据量,不记在「扩散不会看图」.

长度偏差的修法很具体:训练集里的 `[EOS]` 换成 Dream 词表里随机个数的 padding,让模型用垫片学「写到这儿可以停」,而不是靠结束符抢置信度.这和纯文本 Instruct 垫结束符是同一类病,相反的药.推理用置信度揭开:本步所有超过阈值的格子一起提交,一个都没有就只揭最尖的那一个.prefilling 把提示(含图块)的 KV 在第一步之后重用,复杂度从 $O((L_{\mathrm{prompt}}+L_{\mathrm{answer}})^2)$ 收到 $O(L_{\mathrm{answer}}^2)$.全双向下这并非无损:Key 理论上仍随回答揭开而变.Table 3 上多数集掉点平均约 0.8%,batch size 1 时加速约 1.79 倍.近似缓存那一刀在多模态里先砍视觉前缀,因为图块往往比回答长.

LaViDa(Li 等人,arXiv:2505.16839)补训练效率:掩码扩散平均大约一半位置进损失,视觉问答里关键回答 token 可能被漏掉.互补掩码做一对互斥的腐蚀,保证每个位置当一次目标.这和 LLaDA 2.0 文本后训练里的互补掩码是同一类抽样改进.推理上缓存视觉前缀.COCO caption 相对 Open-LLaVA-Next-Llama3-8B 报过 +4.1 CIDEr,约 1.92 倍速度;约束诗句补全报过 +59%.这些格不能与 LLaDA-V Table 2 横减.名字挂在这里,避免使用者以为多模态只有一篇 LLaDA-V.

## 5. 与纯文本模型的关系

语言塔的 $1/t$ 损失,低置信 remask,块扩散,在多模态里仍然成立.变的是条件:图块占序列前面很长一截,双向注意力的 $n$ 变大,每步 $O(n^2)$ 更疼.加速论文因此先打视觉前缀的缓存,再打回答段的并行揭开.27.6× 那一类倍数若出现在多模态仓库里,对照物仍要写清是原版循环还是 AR serving. 对齐也分开.LLaDA-V 主文是视觉指令微调,没有把 VRPO 或 UniGRPO 写进主表.MMaDA 的 UniGRPO 属于多模态后训练.纯文本对齐优化文本输出,多模态对齐还需要决定视觉特征如何进入条件.

统一生图理解的那条河,和 Diffusion-LM 的连续梯度不是一件事.VQ 码上的离散扩散可以双向出图出字;连续嵌入上的梯度引导是 2022 年小模型的可控生成.产品若要「既能看图问答又能出图」,问的是有没有共享离散状态;若只要看图答题,LLaVA 插槽够用,不必上 VQ.

### 6. 失效

把 LLaDA-V 的 48.6 和 Qwen2-VL 的 54.1 减成「扩散看图差 5.5 点」:语言塔,分辨率,数据都不同.同协议对照看 LLaMA3-V 那一列. 把 Table 4 的 44.67 抄进主规格:那是 LLaVA-NeXT 消融,不是 Table 2. 把切图策略的文档短板写成「掩码扩散不会读表」:作者把局限写在图像预处理,并非写在 $Q_t$. 把 MMaDA 的统一生图理解写成 LLaDA-V 的能力:LLaDA-V 主文是理解,不负责出图. 视觉 token 一长,全双向每步更贵.多模态加速的第一刀往往是缓存前缀,并非再降 $T$.把纯文本 Fast-dLLM 的倍数直接贴到带图对话上,分母里的 $n$ 已经换了. 图 1 分别标出视觉塔,投影层以及施加噪声的符号类型.多模态扩散不仅替换 LLaVA 的解码器;条件长度,KV 复用方式和切图策略也会变化,需要在同数据协议下分别比较.

LLaDA-V 的训练阶段按视觉指令微调的老路走.第一段只训 MLP,用 LLaVA-Pretrain 把视觉特征拧进词嵌入.随后把视觉塔,语言塔,投影一起打开,堆 MAmmoTH 的单图,OneVision,VisualWebInstruct 等.消融另用 LLaVA-NeXT 两阶段.主表 Table 2–3 不是跑在消融那条短课上.报 48.6 时默认它已经走完主课. 「语言塔更弱」并非客气话.LLaDA 8B Base 的 Hellaswag 70.5 对 LLaMA3 的 79.1,BBH 49.7 对 62.1.看图问答大量依赖语言塔里已经有的世界知识.LLaDA-V 能在同数据下于 MMMU 超过 LLaMA3-V,说明双向条件有时补得回这截;对 Qwen2-VL 仍落后,说明补不回数据量和动态分辨率一起造成的那截.多模态分数永远先拆成「塔有多强」和「接法换了什么」,再谈扩散.

视觉 token 会直接增加序列长度 $n$.一张图切成几百个 patch 时,提示长度可以超过回答.全双向每步注意力按整段长度平方增长.Dimple 因此必须使用 prefilling:如果不缓存前缀,图块带来的平方计算会抵消并行揭开节省的前向次数.纯文本加速论文里的 $n$ 往往是回答长度,多模态场景的长度还包含图块,所以 Fast-dLLM 的 27.6× 不能直接代表带图对话吞吐.

三条河不要合成「2025 年扩散已经会看图」.LLaDA-V 证明 LLaVA 插槽可以换语言塔,同数据下部分格超过 LLaMA3-V.Dimple 证明不稳定时可以先借 AR 对齐,再把双向接回来,同数据下平均超过 LLaVA-NEXT 3.9 点.MMaDA 证明图也可以变成离散码,和字共享吸收态,从而兼做生图.三句话的主语不同.产品若只要看图答题,插槽够用;若还要出图,才需要统一码.若训练不收敛,Dimple 那条先因果后双向的连续路径比一把撕掉 mask 更像AR 权重改编中的渐进转换.

生成长度在多模态里仍然是画布.Dimple 评 MMVet 时把所有回答限制在 64 token,但真值长度从一词到五百词都有.上限太短会截断长回答,太长又会让短回答浪费前向.纯文本 Instruct 使用结束符垫片时也出现过同类问题.块扩散可以在需要时再开一块,这对带图对话同样有用,只是公开主表还很少把块长列入多模态规格.记录某个 MLLM 仓库的默认 128 步和 64 token 回答上限时,还应同时记录采样器.

多图和视频上 LLaDA-V 略高于同数据 LLaMA3-V,和双向能同时看见分散在序列里的多帧条件,是对得上的借口.单帧真实场景 RealworldQA 反而低 2.8 点,借口在这里用不上.结构优势出现在「条件空间上散开」的题,不出现在「认一张日常照片」的题.这和纯文本里诗歌反向强,正向弱是同一类读表法:优势格和劣势格要一起在.

D-DiT,Muddit 从 SD3 一类图像扩散骨干初始化,再接上文本.那是「图像扩散学会说话」,不是「语言扩散学会看图」.该研究三条河的语言塔都来自 LLaDA 或 Dream.把 SD3 初始化的统一模型写进 LLaDA-V 的对照总分,等于把连续像素扩散和离散吸收态混在一起.LLaDA-V Table 2 把 D-DiT 标成 Diff. 且多项为「-」,本身就在提醒:骨干不同,格对不上. InfoVQA 66.3 对 LLaMA3-V 的 58.9 是 Table 3 里差得比较大的一格,文档理解并非全面落后.AI2D 77.8 对 81.1,DocVQA 83.9 对 86.2 才是切图策略那条短板更可能出现的地方.读「图表不行」时看是哪一张表,哪一列.不要用 AI2D 一格代表全部 OCR.

投影层看起来像小事,却决定视觉几何能不能进语言塔.随机初始化的两层 MLP 若学不好,后面无论因果还是双向都在猜一套对不齐的图.LLaDA-V 第一段只训投影,Dimple 同样从随机投影起步.这和更换词表时重新初始化嵌入的问题相同:接口没对齐,塔再强也接不上.多模态失败时,先看投影有没有单独训过,再怪扩散目标.

采样器在带图回答里同样能改分数.纯扩散一次揭开太多字,和图像里的空间关系对不齐,括号和坐标更容易错.低置信 remask 把还平的格子留到下一步,等于让图块多当几次条件.阈值解码同理.LLaDA-V 主表没有像 8B 文本附录那样扫三种解码器;把 48.6 当成与采样无关的常数,是把纯文本已经犯过的错搬到图上.报多模态分,能写采样器就写.

多模态扩散仍沿用相同的 $Q_t$,变化发生在模型条件与状态表示上.变的是条件里多了图,以及图要不要自己变成离散状态.机制文仍然够用:吸收态,加权交叉熵,揭开与 remask.MLP 是连续视觉特征的投影器,MAGVIT 则把图像变成离散状态码,两者角色不同.它们不是.一个是连续特征当条件,一个是离散码当状态.分清条件和状态,三条河才分得开.

LLaDA-V 项目页与代码在 https://ml-gsai.github.io/LLaDA-V-demo/.复现 Table 2 时用他们的评测脚本,不同 MMMU harness 的结果不能直接相减.这和 Dream 表上的 LLaDA HumanEval 32.9 对 Nie Table 1 的 35.4 是同一类纪律.图文问答的 harness 比纯文本更多:图怎么切,是否多选,视频抽帧.抄分之前先抄协议.缺少协议的截图不能作为规格数据.同数据对照永远优先于跨公司海报.没有同协议,就只写接法,不写总分.接法对了,分数以后可以补;接法错了,分数再高也是错句. **图像进入序列后的计算链.** 以插槽式模型为例，视觉编码器先把图像变成 $N_v$ 个 patch 特征，投影层把通道维映射到语言模型隐藏维，再与 $N_t$ 个文本 token 拼接。若回答画布有 $N_y$ 个位置，一次全双向前向面对的长度约为 $N_v+N_t+N_y$。去噪执行 $T$ 步时，朴素注意力计算随

$$
T\,(N_v+N_t+N_y)^2
$$

增长。视觉前缀在所有步骤中保持不变，但文本画布持续变化。可复用的部分包括视觉塔输出、投影后的视觉 embedding，以及在注意力图允许时的前缀 KV；回答区域的表示不能直接沿用上一去噪步。切图数量翻倍时，代价不只来自视觉塔多处理的 patch，还会放大语言塔每一步的注意力矩阵。

统一离散码路线的账不同。图像 token 本身也是待生成状态，图文可以共享掩码日程，但图像通常需要远多于一句回答的离散位置。若同时生成文字和图像，两种模态的噪声率未必应相同：文字错一个 token 可能改变语义，图像错一个局部码可能只造成纹理扰动。共享 Transformer 不等于共享采样超参，训练时需要明确模态标记、损失权重与各自的终止条件。 **多模态评测中的三个干扰项.** 第一个是图像预处理。动态分辨率、固定方格切图和缩放到单张低分辨率，会给 OCR、图表与自然图像带来不同偏差。同一个语言塔配上更细的切图，DocVQA 可能明显提高，却增加视觉 token 和推理成本。比较 LLaDA-V、Dimple 与 AR 基线时，切图策略属于模型配置，不能藏在评测脚本里。

第二个是答案抽取。多选题可以从长回答里抽字母，开放问答可能使用规则匹配或判分模型。扩散生成容易在答案前后留下解释、重复片段或未清理的占位符，不同抽取器会给出不同得分。复现实验应保存原始输出，并报告解析失败率；否则分数变化可能来自后处理，而非视觉理解。

第三个是长度预算。固定 64 token 对短答题足够，对文档总结和视频描述则可能截断。扩大画布又会增加每一步计算，并提高过早生成结束符或尾部残留的风险。多模态规格至少应同时列出视觉 token 数、回答上限、去噪步数和是否使用块生成，才能把看图能力与画布配置拆开。

视频进一步放大了上述问题。均匀抽帧会漏掉短暂事件，密集抽帧又让视觉 token 成倍增长；模型分数同时受抽帧器和语言塔影响。若问题询问动作先后，帧的时间位置编码也必须保留，单纯把所有 patch 当成无序图像集合会损失顺序信息。报告视频结果时，帧数、抽帧间隔、单帧分辨率和总视觉 token 数应与准确率放在一起。扩散语言塔能并行填写答案，不会替前端补回已经漏采的关键帧。 音频输入同样遵循这条链路：前端窗口决定时间分辨率，投影器负责接入语言空间，去噪器只处理已经编码出的条件。识别长语音时还需记录窗口重叠与时间戳对齐。 **联合状态空间从哪里开始.**

多模态模型先要回答一个基础问题:文本token与视觉token是否属于同一个离散状态空间.若二者共享词表,状态可写成 $z=(z^{\text{text}},z^{\text{vision}})\in[V]^L$,同一输出头对所有位置预测.若词表分离,则文本位置属于 $[V_T]$,视觉位置属于 $[V_I]$,联合空间是直积

$$
\mathcal Z=[V_T]^{L_T}\times[V_I]^{L_I}.
\tag{4}
$$

共享空间的好处是形式统一,代价是token语义相差极大.文本token代表子词或字节片段,视觉token代表局部纹理、量化码或连续patch投影.编号相同没有共同语义,强行共享输出分布可能让高频文本类别挤压视觉码.分离空间保留各自词表与归一化,跨模态联系交给隐藏表示和注意力建立. 还要区分「视觉作为条件」与「视觉也是生成变量」.视觉问答通常固定图像表示,只对文本答案加噪并去噪;联合生成则让图像和文本都进入随机过程.前者的目标是条件分布 $p(y\mid i,x)$,后者要建模 $p(i,x,y)$ 或多个条件边际.同样叫多模态扩散,概率任务并不相同. **连续视觉特征与离散视觉码.**

图像编码器输出连续patch特征时,文本扩散只作用于答案token.视觉序列不经历离散替换,它更接近一段只读条件.模型通过投影层把视觉特征映射到语言隐藏维度,再由注意力供文本位置读取.这条路线无需训练图像解码器,适合理解任务,却不能由同一反向链生成像素.

离散视觉码来自VQ类编码器或离散视觉tokenizer.图像被压成二维码网格,每个码对应码本向量.此时可以对视觉码做掩码或均匀替换,与文本token共同去噪.码本的重建误差构成额外上限:扩散模型即使完美恢复码分布,解码图像仍可能丢失文字、细线和精确布局.

二维结构也没有因展平成序列而消失.相邻视觉码的依赖主要来自空间邻域,文本依赖来自句法与语义距离.统一Transformer可以学习两套关系,位置编码、噪声形状和确认顺序仍应保留模态结构.只用一维距离会把图像行尾与下一行行首误当成普通相邻位置. **联合分布的三种分解.** 给定图像 $I$、提示 $X$ 与答案 $Y$,理解模型直接学习 $p(Y\mid I,X)$.图像先生成再描述的流水线可写成 $p(I\mid X)p(Y\mid I,X)$.真正联合模型希望学习 $p(I,Y\mid X)$,允许两种模态在生成中互相修正.

三种分解对应不同能力.条件理解不要求模型知道自然图像先验,只需抽取与问题有关的信息.流水线中视觉错误会成为文本不可修改的条件.联合生成可以让文字约束反向改变视觉码,也会面对更大的状态空间和更复杂的归一化. 若训练数据只含图文对,联合似然无法自动区分图像信息与语言先验.模型可能仅凭问题模板猜答案,视觉token被忽略.需要图像替换、区域遮挡和反事实配对检验真实条件依赖. **跨模态条件的概率语义.** 视觉固定、文本去噪时,第 $i$ 个答案token的预测为

$$
p_\theta(y_0^i\mid y_t,I,X,t).
\tag{5}
$$

$I$ 通过编码器提供条件,不属于随机变量 $y_t$.联合扩散则需要

$$
p_\theta(i_0,y_0\mid i_t,y_t,X,t_I,t_T),
\tag{6}
$$

并允许视觉与文本拥有不同噪声时间 $t_I,t_T$.将二者强行设成同一个 $t$,意味着两种token在每个阶段拥有相同信噪比语义,这通常没有自然保证. 跨模态注意力给出计算连接,概率依赖还要由训练目标确认.某个文本位置能看见视觉特征,不代表模型实际使用它.干预图像区域、置换图文配对并测量文本分布变化,才能判断条件通道是否有效. **共享噪声过程.** 共享噪声日程对两种模态使用同一掩码率 $\alpha_t$.形式简洁,每个样本只需一个时间标量.当文本和视觉码的信息密度、序列长度与可恢复难度相近时,共享日程可能足够.

现实中视觉码数量常远多于文本token,局部冗余也更强.相同掩码率下,图像仍保留大量空间线索,短文本却可能丢掉全部关键实体.模型看到的条件强度因模态不同而严重失衡.共享 $t$ 只同步了删除比例,没有同步剩余信息. 可用条件互信息比较有效信噪比,例如观察 $I(I_0;I_t)$ 与 $I(Y_0;Y_t)$.若二者衰减曲线差异很大,同一时间坐标不具有共同语义.训练会偏向更容易恢复或token更多的模态. **分离噪声过程.** 分离日程允许视觉和文本各自拥有转移核 $Q_t^I,Q_t^T$ 与时间 $t_I,t_T$.训练可采样二维时间点,覆盖「清晰图像—噪声文本」「噪声图像—清晰文本」以及双方同时噪声.前两类状态直接支持跨模态条件生成,后一类支持联合恢复.

二维时间空间增加训练复杂度.均匀采样会把大量预算花在价值较低的组合上,例如双方都接近纯噪声时几乎没有条件信息.可以按目标任务偏置采样,同时保留少量全域覆盖防止模型只会单向生成. 分离日程还允许模态特定噪声.文本适合吸收掩码,视觉码可能使用掩码、均匀替换或局部结构噪声.两种反向核在共享骨干中相遇时,模型必须知道当前位置模态与时间,否则相同隐藏状态对应不同转移语义. **耦合噪声与共同遮挡.**

独立给两种模态加噪默认遮挡事件互不相关.但训练目标若要学习细粒度对齐,可以让图像区域与对应文本短语共同遮挡,迫使模型利用剩余跨模态证据.共同遮挡太强时,相关信息同时消失,任务反而无解. 另一种耦合是互补噪声:图像区域被遮时保留对应文字,文字被遮时保留图像.它强化双向条件恢复,却可能让模型依赖显式对应,对开放图文关系泛化较差.随机独立、共同与互补三类状态应混合,并分别做消融. 耦合规则隐含对齐标签.若区域—短语对应错误,噪声过程会系统性教错条件关系.弱标注数据更适合软耦合,按对齐概率采样而非硬绑定. **对齐目标不仅是一项损失.**

token恢复损失要求预测原始符号,未必让文本与视觉表示落入可比较空间.常见补充包括图文对比、匹配判断、区域—词对齐和循环一致性.每项目标解决不同粒度. 全局对比让配对图文靠近,容易依赖背景与主题,无法保证局部物体被正确引用.区域—词目标提供细粒度监督,标注噪声更大.循环一致性要求由图生成描述后仍能恢复图像信息,可能奖励表面可逆编码,不自动等于语义正确. 损失权重还受token数量影响.一张图可能有数百视觉码,答案只有几十token.直接求和会让视觉重建主导梯度;分别按模态平均又会让每个文本token获得更大权重.权重应根据任务、梯度尺度和验证指标选择,而非只按序列长度归一化. **条件丢弃与无分类器引导.**

训练时随机丢弃图像或文本条件,模型可同时学习有条件与无条件分布.推断时组合两者分数,提高条件一致性.引导过强会牺牲多样性,并放大条件编码器的偏差. 多模态存在多个可丢弃条件:图像、问题、历史对话、布局.分别丢弃能估计各条件边际贡献,组合数量随条件数指数增长.实践通常采样少量模式,因此某些条件组合在训练中很少出现. 引导强度也应按模态和时间变化.早期需要全局文本约束确定图像主题,后期视觉局部细节更重要;理解任务则可能全程固定图像.统一标量会把不同阶段的条件需求压成一个旋钮. **生成顺序的四种选择.**

文本先行时,模型先生成描述或计划,再据此恢复视觉码.语义结构清楚,视觉结果受文本瓶颈限制.图像先行适合描述与问答,视觉错误会固化为文本条件.交替生成让两种模态互相修正,调度与停止更复杂.完全并行则在同一轮更新双方,速度快,早期条件最不稳定. 顺序应与任务因果结构一致.图像描述中图像是观测条件,没有必要把它重新生成;文本到图像中提示应固定;图文共同创作才需要双向更新.统一模型可支持多种顺序,评测时必须说明哪些模态被固定、哪些可修改.

交替顺序还要决定步频.视觉序列长且局部冗余,一次可更新较多码;文本关键token少,每次更新影响大.一比一交替没有必然合理性.可按预期信息增益或剩余风险动态分配模态步骤. **任意顺序中的跨模态枢纽.** 某些位置是跨模态枢纽:图中的物体类别、文本中的实体名、坐标或计数.确定它们会同时降低两边不确定性.低熵优先可能先填大量背景视觉码和格式词,并未解决核心对应. 可估计候选位置对另一模态的熵降,优先选择跨模态信息增益高且错误风险可控的位置.精确计算昂贵,可用区域—词注意力、干预分布变化或多轨迹统计近似.

枢纽预测错误的传播也更严重.一旦错误实体同时约束图像和文本,两边会形成相互支持的高置信固定点.枢纽应使用更严格确认阈值和独立验证. **模态不平衡的四个来源.** 数量不平衡来自视觉码远多于文本token;熵不平衡来自视觉局部冗余与文本离散语义;损失不平衡来自不同归一化;数据不平衡来自图文对数量、描述长度和任务分布.四者会叠加. 模型可能成为「会说不会看」:语言先验足以应付大部分问题,视觉梯度被忽略.也可能成为「会重建不会推理」:大量视觉码损失下降,文本答案能力停滞.总损失持续改善无法排除任一退化.

诊断应分别报告模态损失、条件干预敏感度、图像替换后的答案变化和文本提示替换后的视觉变化.只看最终平均分,容易让高频任务掩盖弱模态. **梯度冲突与共享容量.** 共享骨干同时接收视觉重建、文本去噪和对齐梯度.若梯度方向冲突,增加某项权重会损害另一模态.可以测量梯度余弦、层间冲突与任务曲线,判断共享程度. 底层视觉特征与高层语言语义需要的表示不同.完全共享节省参数,也会争夺容量;完全分离减少干扰,跨模态交互变弱.分离前端、共享中层或使用模态适配器提供折中.

容量分配要与数据平衡一起看.视觉数据量大时,共享层可能被视觉重建主导;高质量文本监督少时,对齐头无法弥补语义能力下降.冻结强语言骨干可保护文本,同时限制视觉信息进入深层表示. **位置编码与二维几何.** 视觉码拥有行列坐标,文本拥有序列坐标.拼接后若共用一维位置,图像二维邻域被展平,文本位置又受巨大视觉前缀偏移.模态特定位置编码或二维旋转编码能保留几何. 跨模态位置没有天然共同尺度.文本中的「左边」要对应图像坐标,单靠位置编码不足,还需要对象与区域语义.布局数据、指代监督和区域扰动能验证这种关系.

分辨率变化会改变视觉网格长度.只在固定网格训练的模型可能把绝对位置当捷径.评测应包含缩放、裁剪和长宽比变化,检查对齐是否依赖固定模板. **注意力可见性与信息泄漏.** 全双向注意力让所有噪声位置互看,适合联合去噪.对话任务还需防止答案token看到未来真值或未加噪标签.不同段落的可见性掩码必须与训练目标一致. 视觉条件通常全可见,文本答案按噪声状态变化.若训练数据把答案文字直接出现在图像OCR区域,模型可能复制而非理解;某些任务这正是目标,另一些任务会形成泄漏.应按任务区分读取能力与推理能力.

联合生成时,清晰文本条件可能泄漏视觉描述,使图像恢复看似优秀.反向方向也一样.双向能力要在一侧信息不足或反事实冲突的条件下测试. **缺失模态与不完整条件.** 真实输入可能缺图、图像损坏、文本为空或一对多.模型若只见完整图文对,缺失模态时会把占位符当异常.条件丢弃训练提供基础鲁棒性,仍需覆盖不同缺失模式. 缺失模态不能总用零向量代替.零可能落在正常特征范围,模型无法区分「没有图」与「图像编码恰为零」.显式模态存在标记与独立无条件路径更清楚. 部分缺失还可作为生成请求:给文字补图、给图补描述、给局部图补全.同一接口下,固定与待生成位置必须明确标记,避免模型改写用户条件.

**对齐的反例一:语言先验取巧.** 问题「天空是什么颜色」在多数数据里可直接答蓝色.模型完全忽略图像也能得高分,遇到夕阳或灰度图就失败.常规准确率会高估视觉条件使用. 反事实评测保持问题不变,替换图像关键属性,观察答案是否随之改变.还可用同一图像配互斥问题,排除固定描述模板.图像置乱后性能几乎不变,说明模型主要依赖文本先验. **对齐的反例二:视觉重建压倒语义.** 大量背景码容易预测,它们贡献绝大多数token准确率.模型把容量用于纹理和颜色,小物体、文字与关系仍然错误.平均视觉码准确率提高,跨模态任务不升反降.

按区域重要性分桶,分别测前景、文字、关系区域和背景.对小区域可使用对象级指标或任务验证,避免面积加权把它们淹没.训练权重也可提高语义区域,需防止人工标注偏差. **对齐的反例三:错误互相强化.** 文本分支误判物体为猫,视觉分支据此把模糊区域恢复成猫形纹理;新视觉特征再提高「猫」的概率.两边置信度同时上升,联合一致性很好,与原图事实相反. 内部一致性无法发现共同偏差.保留原始观测的只读通道、对高影响枢纽做区域证据检查,或引入独立视觉模型可以打破反馈.联合生成中也应区分用户给定像素与模型生成区域,前者不能被随意改写. **对齐的反例四:共享日程失衡.**

在相同掩码率下,视觉剩余数百码,文本只剩一个功能词.模型几乎只能从图恢复文本;反方向训练信号很弱.换到文本生成图像时,能力远低于训练损失暗示. 二维时间消融可固定视觉噪声扫文本噪声,再反向扫描,绘制条件恢复矩阵.矩阵若高度不对称,共享日程没有实现双向平衡.分离日程与重加权应以这张矩阵为依据. **评测联合生成.** 图像质量、文本质量和图文一致性需要分别评价.高图像保真可能伴随描述错误,高文本分数也可能对应普通模板图.单一联合分数会隐藏权衡.

生成顺序与步数也要记录.文本先行、图像先行、交替和并行使用相同总前向预算比较,才能判断顺序收益.若某策略额外调用验证器或重编码图像,成本应计入. 随机生成需要多个种子.同一提示下只展示最佳样例会夸大能力.应报告分布统计、失败类型与条件敏感性,并保留等价输出的合理空间. **证据适用范围.** 条件视觉理解实验支持图像特征能改善文本任务,不能自动证明联合图文扩散成立.离散视觉码重建支持视觉生成,也不能证明模型理解对象关系.图文一致性指标依赖评分器,需要人工或任务验证补充.

小规模统一token实验展示共同状态空间可训练,迁移到高分辨率、长文本和开放对话仍受序列长度与模态不平衡限制.速度结论必须说明视觉编码、图像解码与验证是否计时. 可迁移的原理包括:明确固定与生成变量,分别校准两种模态,按有效信噪比设计日程,用反事实干预验证条件依赖.具体损失权重、噪声比例、顺序与步数需要目标模型实验. **最小复现矩阵.** 状态空间比较连续视觉条件、离散视觉码与共享词表.噪声比较共享日程、分离时间和耦合遮挡.顺序比较文本先行、视觉先行、交替与并行.每组固定模型容量和总计算预算.

指标包括文本任务分、视觉重建、图文一致性、条件干预敏感度、两模态校准、各自处理token数和墙钟.按图像分辨率、文本长度、对象大小和问题类型分桶. 消融应固定噪声只换对齐目标,固定目标只换顺序,固定顺序只换模态损失权重.随机图文配对与单模态基线用于检查取巧.没有这些对照,总体提升无法定位到联合扩散机制. **最终机制链.** 视觉编码决定状态是连续条件还是离散生成变量;词表与位置编码决定两种token如何进入共享骨干;噪声过程决定训练中谁向谁提供条件;对齐目标决定跨模态信息是否真正被使用;调度决定推断时先确认哪些模态和位置.

共享日程形式简单,有效信噪比可能失衡.分离日程提供双向条件状态,增加二维采样与校准负担.联合生成允许互相修正,也可能让错误跨模态自我强化. 可靠结果需要同时证明单模态质量、跨模态条件敏感性与联合一致性,并报告模态不平衡和计算成本.注意力连接只是通道,反事实变化和任务验证才说明模型使用了条件. **视觉tokenizer决定上限.**

离散视觉模型把连续图像压入有限码本.码本太小,颜色、纹理和文字细节丢失;码本太大,预测词表增大,视觉token分布更稀疏.扩散模型的生成误差与tokenizer重建误差必须分开测量.用真实码经过解码器得到的图像是重建上限,模型样本与该上限的差距才属于生成器. tokenizer还会改变语义局部性.某些码主要对应纹理,某些码隐含更大对象结构.若一个对象被拆到大量局部码,跨模态实体对齐需要整合很长区域.语义tokenizer能缩短依赖,可能牺牲像素保真.二者应按任务选择. **码本塌缩与长尾视觉码.**

少数视觉码频繁出现时,模型可靠高频背景获得低损失,罕见物体和文字码学习不足.码本利用率、频率熵和按码频率分桶的准确率能够发现塌缩.仅看平均重建指标会忽略长尾. 重加权罕见码可改善覆盖,也可能放大tokenizer量化噪声.较稳妥的方法是把重建误差、语义重要性与码频率结合,优先保护既稀有又影响任务的区域. **文本tokenizer同样影响对齐.** 实体可能被拆成多个子词,视觉区域却是一个对象.区域—token逐点对齐会重复计算或只对齐其中一片.可以把连续子词聚成词或实体后再计算对齐,同时保留token级生成损失.

多语言文本的切分长度差异会改变模态损失权重.同一描述在某种语言中token更多,其去噪损失与计算占比随之上升.跨语言评测应按语义单位与实际token成本同时报告. **双向条件并不保证双向能力.** 训练既有图到文也有文到图样本,共享参数仍可能偏向数据更多或更容易的一侧.图到文只需输出短答案,文到图要恢复数百码,难度与梯度规模不同.两方向平均损失不可直接比较. 应构造方向矩阵:固定一侧清晰度,扫描另一侧噪声,分别测恢复质量.矩阵非对称时,需要调整时间采样、损失权重或容量,不能凭接口统一宣称能力统一. **多轮对话中的视觉条件.**

对话历史包含模型先前关于图像的描述,后续回答可能依赖历史文字而绕过视觉.历史若有错误,语言自洽会把错误延续.每轮都保留视觉访问并不等于真正重新核对. 可在历史中注入与图像冲突的陈述,观察模型是服从历史还是回看视觉.调度器也可在检测到实体冲突时重新激活相关视觉区域,而非只重掩答案token. **多图输入的对应关系.** 多张图共享视觉词表,需要额外图像身份与空间边界.若位置编码连续拼接,模型可能把相邻两图区域混成同一场景.图像分隔标记与分层位置编码能减少混淆.

问题常要求跨图比较,此时每张图独立编码后只在文本层融合可能丢失细粒度对应.联合视觉注意力增强比较,计算随总视觉token平方增长.评测应包含图像顺序置换,检查模型是否靠固定槽位. **视频是多模态联合状态的延伸.** 视频增加时间轴,视觉token从二维变成时空网格.相邻帧高度冗余,共享噪声会把大量损失花在静态背景.动作与事件虽占token少,对文本回答更重要. 噪声可按时空块耦合,保留运动连续性;独立遮挡更易训练,可能产生闪烁.生成顺序还要决定先恢复关键帧、动作轨迹还是逐帧细节.图像结论不能直接外推到视频. **音频与视觉的差异.**

音频离散码带有严格时间顺序和多码本层级,视觉码强调空间邻域.统一序列骨干可以共享语义层,噪声过程与位置结构仍需模态化.把所有非文本token称作视觉式码会丢掉时间相位和层级依赖. 多模态统一的合理层次通常是条件接口、隐藏表示和调度原则,不必要求底层tokenizer与噪声核完全相同. **跨模态时间对齐.** 视频、音频和字幕需要时间戳对应.共同遮挡若忽略时间偏移,会把错误片段当正对齐.软时间窗可以容纳说话延迟,窗口太宽又会削弱精确事件定位. 对齐误差应与生成误差分开.先用已知时间戳的受控数据验证模型,再加入自动对齐数据,才能判断性能下降来自标注还是模型. **空间指代.**

「左边第二个」「杯子后面」要求对象、坐标与关系共同建模.全局图文对比只知道主题相同,无法提供关系监督.区域级掩码、关系问答与坐标token能增强几何条件. 坐标离散化过粗会丢掉小物体,过细则扩大词表与标注噪声.视觉patch分辨率决定坐标监督的有效精度,不能只增加坐标位数. **OCR与视觉文字.** 图中文字同时属于视觉纹理和语言符号.视觉tokenizer若无法重建细小笔画,后续语言模型再强也读不出.单独OCR编码器可提供文字条件,也会让统一模型依赖外部模块. 评测应区分清晰印刷体、弯曲文字、低分辨率和多语言.答案准确率还要与区域定位配对,防止模型凭常见词猜测. **数量与集合关系.**

计数任务需要视觉对象分离与文本数字对齐.模型可能从场景先验猜常见数量,或因patch重复计数.区域扰动、对象增删和位置置换能检验真实计数. 联合扩散中,文本先预测数量会反向迫使视觉生成对应对象,适合文生图;视觉理解任务里用户图像必须保持只读,不能让文本先验改写观测以获得一致. **可编辑区域与只读区域.** 图像编辑任务包含固定背景、用户掩码区和待生成文字.状态需要显式区分只读与可变位置.统一去噪若误改只读区域,即使整体图像质量高也违反任务. 边界区域需要与背景融合,完全隔离注意力会产生接缝.模型可以读取只读区域,更新权限仍受状态掩码约束.读权限与写权限应分开设计. **跨模态重掩.**

文本与视觉都可修改时,发现不一致后要决定重掩哪一侧.文生图应保护提示,重掩视觉;图像描述应保护观测,重掩文本;共同创作可根据用户锁定与置信度选择. 错误归因不清时,同时重掩两侧可能丢掉正确条件.可先做单侧反事实,比较另一侧验证改善,再决定撤销范围.高影响锚点应保存检查点. **联合停止规则.** 一侧完成不代表联合状态完成.文本已稳定时,视觉仍可能缺少提示实体;图像看似清晰时,描述可能遗漏关键关系.停止器需要单模态风险与跨模态一致性同时通过. 两侧收敛速度不同,可让已稳定模态进入只读状态,另一侧继续更新.若新证据破坏一致性再重新激活.这种分层停止减少重复计算,要求校准再激活条件.

### 6.1. 跨模态置信度需要分别校准

文本概率在词表上归一化,视觉码概率反映量化类别,两者置信值不能直接比较.选择下一模态时应先把概率映射到各自真实错误率或任务风险. 视觉局部码正确不保证对象正确,文本token正确也不保证语义完整.除token校准外,还需区域、实体和样本级可靠性.统一阈值通常偏向更易校准的模态. **联合校准.** 跨模态一致性概率需要估计「两边都正确且对应」.若单边错误相关,两项置信乘积会过度乐观.可在真实联合rollout上训练轻量风险头,输入两侧置信、对齐分数和任务类型. 风险头随生成顺序变化.文本先行产生的状态与并行生成不同,不能共用一套校准后假设不变.未见组合应回退保守步数. **数据配对噪声.**

网络图文对常含错误描述、缺失细节和宽泛标题.联合模型若把每对都当严格对应,会学习虚假关系.全局主题一致不等于每个词都有视觉证据. 可以估计配对置信,对高置信样本做细粒度对齐,低置信样本只做全局目标.过滤过强会丢掉长尾概念,需要保留多样性与噪声之间的权衡. **一图多文与一文多图.** 同一图像允许多种正确描述,同一提示也允许多张合理图.精确token目标只观察一个答案,会惩罚未标注的等价模式.扩散模型的多样性需要在语义正确集合内评价. 多参考描述、对象集合与关系图能提供更宽的真值.图像生成可用条件覆盖与多样性共同衡量,避免模型靠随机纹理制造表面差异. **负样本的难度.**

随机错配图文很容易区分,模型只需主题判断.真正细粒度对齐需要难负样本:对象相同但属性、数量或关系不同.难负样本过于相似时,标注本身可能含糊. 可按差异类型分组并人工抽查.若对齐收益只出现在随机负样本,模型学到的主要是全局主题,不足以支持区域级条件. **对齐与生成目标的冲突.** 对比目标希望同一语义表示靠近,会压缩样式和细节差异;生成目标需要保留这些差异以重建.共享表示若过度对齐,图像多样性可能下降. 可以让高层语义空间承担对齐,低层模态表示保留细节.跨层连接决定信息能否传递.消融不同层对齐位置,比单纯调损失权重更能解释冲突. **课程顺序.**

模型可先学单模态恢复,再加入跨模态条件,避免早期两侧都不稳定;也可从联合训练开始,让表示共同形成.前者稳定但可能形成难以改变的模态孤岛,后者对数据与优化要求高. 课程应通过零图像、错配图像和双向生成测试.单模态能力强而条件敏感度低,说明跨模态阶段不足;联合损失低而两边基础质量差,说明共享训练互相干扰. **模态丢弃率.** 丢弃率低时,无条件分支训练不足,引导估计噪声大;丢弃率高时,有条件学习被稀释.图像与文本条件的重要性不同,各自丢弃率应独立选择. 还要包含部分丢弃,如遮掉一个对象或一句描述.整模态丢弃只教模型有无条件切换,不能训练局部缺失恢复. **分辨率与文本长度的计算竞争.**

共享注意力中,视觉token增加会平方级放大计算,文本答案占比下降.提高分辨率可能提升小物体识别,也可能让语言推理获得更少容量.固定总token预算下,视觉压缩率与文本上下文长度直接竞争. 评测应报告分辨率—文本长度网格,而非各自单独最优.某个模型在短问题高分辨率上领先,不代表长对话仍保持优势. **稀疏跨模态连接.** 所有文本位置读取全部视觉码成本高,且引入无关噪声.区域路由让词只访问候选patch,提高效率与局部对齐.路由错误会彻底切断正确证据. 可保留少量全局token作为旁路,局部路由处理细节.路由召回与下游质量应同时报告,否则速度收益可能来自漏看困难区域. **因果关系与相关性.**

图文共现不能证明视觉内容导致文本答案.替换背景、保持对象,或替换对象、保持背景,能分离模型使用的线索.若答案随背景变化,对齐可能依赖数据偏见. 生成任务也可固定文本语义、改变样式条件,检查对象关系是否稳定.因果干预集规模可以小,但应覆盖模型声称掌握的关键关系. **多模态幻觉.** 文本生成视觉中不存在的对象,可能来自语言先验压过视觉证据.置信度往往仍高.对象级存在性检查、区域指向和反事实图像有助于诊断. 把描述写得更短能降低幻觉率,也可能漏掉真实内容.评价需同时看精确率与召回,防止模型用沉默获得低幻觉. **视觉生成中的文字错误.**

文生图模型常生成形似文字但不可读的纹理.离散视觉码擅长局部外观,精确字符序列要求强长程约束.加入文本token作为显式中间变量可改善拼写,仍需将字符与空间区域绑定. OCR分数、字符准确率和布局一致性应单独测.总体图像指标对小面积文字不敏感,无法说明这项能力. **安全与条件冲突.** 图像内容与文本指令可能冲突,模型需决定遵循观测事实、用户编辑请求或安全约束.核心在于条件优先级,普通置信度不足以做出决定.训练与推断应显式标记来源和权限. 安全过滤若只作用文本,视觉token可能绕过;只过滤图像又可能误伤医学或教育内容.多模态风险需要联合验证,其误报与漏报应独立报告. **数据泄漏与基准记忆.**

图像基准可能以截图、字幕或描述出现在预训练数据.模型凭记忆回答,图像干预敏感度很低.近重复检测要覆盖像素变换、裁剪和文字转录. 对已知图像做局部反事实编辑,再提同一问题,能区分记忆与观察.模型若坚持原答案,说明视觉条件没有覆盖记忆先验. **失败归因矩阵.** 错误可来自视觉编码、文本理解、跨模态对齐、联合调度、解码器或评测器.同一终局失败需要通过中间探针定位.真实视觉码恢复失败指向生成器,真实码也无法重建则指向tokenizer. 给模型正确区域标签后答案恢复,说明感知或路由有问题;给正确对象文本仍答错,说明语言推理有问题.这种逐层替换建立可解释归因. **复现中的控制变量.**

对比AR与扩散时需固定视觉编码器、语言骨干规模、训练数据和评测提示.扩散多次前向与AR逐token前向的成本口径要统一.视觉编码时间、图像解码时间与缓存策略分别报告. 联合模型若使用更多图文数据或更强tokenizer,性能差不能全归生成范式.模型卡应列出这些差异,表格避免只给最终分数. **长输出中的对齐漂移.** 短答案紧贴图像,长解释逐渐受语言先验支配,后段可能添加无视觉依据的细节.每个句子对视觉区域的敏感度可随位置测量,观察条件依赖是否衰减. 周期性重新读取视觉、在段落边界做事实核对,能够降低漂移,增加计算.若任务只需短答,这些机制没有必要;长报告与多轮对话更需要. **联合生成的风险预算.**

可把总风险分给视觉真实性、文本正确性和跨模态一致性.某一项改善不能抵消另一项严重失败.高风险枢纽占用更小错误预算,背景细节可放宽. 预算随任务改变.艺术生成容许视觉多样性,医学理解更重观测忠实.同一阈值不应跨场景复用.部署前需在目标损失下校准. **停止后的压力检查.** 联合状态满足停止条件后,可遮住少量高影响文本或视觉区域,观察是否恢复到同一语义.恢复分叉表明答案仍依赖脆弱局部.压力检查通过也只能说明局部稳定,外部事实仍需验证. 检查成本可按风险触发.低风险描述直接输出,关键计数、OCR和关系题执行额外检查.报告触发率与改善率,判断固定开销是否值得. **适用任务的判断.**

视觉固定、只生成文本的任务更适合条件扩散语言模型;图像编辑需要可写视觉区域与只读背景;图文共同创作才需要双方可逆更新.任务定义先于统一架构. 如果跨模态依赖集中在少数实体,枢纽优先与稀疏连接有效.依赖遍布高分辨率细节时,过度压缩和稀疏路由会漏证据.可用区域干预预先估计依赖密度. **完整实验清单.** 先测tokenizer重建上限,再测单模态去噪,随后加入条件生成与联合生成.每一级保留上一层权重和数据作为对照.图文错配、单侧置乱、局部反事实与缺失模态组成条件使用测试.

训练侧记录两模态损失、梯度冲突、码本利用与时间组合覆盖.推断侧记录每模态步数、确认顺序、联合停止、处理token和墙钟.质量侧记录单模态指标、对齐、条件敏感度与失败类型. **收束后的判断.** 多模态扩散的核心是联合状态与条件权限,并非把图像embedding拼在文本前面就完成统一.视觉只读时,问题仍是条件文本扩散;双方都进入噪声过程时,才需要处理联合转移、二维时间和双向停止. 共享词表、共享日程与共享骨干分别属于符号、随机过程和参数层面的共享,三者可以独立选择.任何一项共享都可能带来模态失衡,需要用方向矩阵、干预敏感度和分桶损失验证.

对齐目标能建立通道,生成顺序决定信息何时进入通道,校准与风险预算决定何时信任它.最终结论必须同时落在视觉、文本和二者对应关系上. **图像条件的压缩瓶颈.** 视觉编码器常把数千patch压成少量查询token.压缩降低计算,也可能在问题出现前丢掉细节.若查询由问题条件化,每个问题可选择相关区域;若图像只编码一次服务多轮对话,固定压缩更易遗漏后续所需信息.比较时应固定视觉token预算并测小物体、OCR与关系任务. **条件化查询的偏差.**

问题引导视觉编码会突出相关区域,也会受问题错误假设影响.诱导性问题提到不存在对象时,编码器可能在图像中寻找并制造对应特征.反事实问题与存在性检查可测这种偏差.保留少量问题无关的全局视觉token能提供校正通道. **模态边界标记.** 拼接序列需要区分图像、提示、答案与历史.边界标记让模型知道转移核和写权限,也可能成为数据集捷径.随机改变段落长度、顺序与模板可检查模型是否依赖固定边界位置. **共享掩码符号.** 文本和视觉共用一个掩码符号时,模型依靠位置判断模态.模态位置变化或混合区域会产生歧义.使用模态特定掩码能明确噪声来源,同时减少参数共享.消融应比较共享符号、分离符号与显式模态嵌入.

### 6.2. 损失尺度与时间条件必须对齐

两种词表大小不同,交叉熵基线也不同.直接相加会让大词表损失数值更高.可减去随机预测基线、按token平均或依据梯度尺度归一化.不同口径会改变模态权重,论文应公开公式. **时间嵌入的设计.** 分离日程需要模型知道 $t_I$ 与 $t_T$.简单相加会丢掉哪个模态更噪,拼接或模态专属投影保留方向.若只训练对角线 $t_I=t_T$,模型无法学习异步生成;二维覆盖必须体现在采样分布里. **跨模态后验.** 视觉位置的反向后验应条件在文本与其余视觉码,文本位置同理.因子化预测把同轮位置视为条件独立,可能组合出图文不一致状态.小规模联合头、分组采样或校正能处理部分依赖,成本随组大小上升. **同轮相关错误.**

一轮同时确认「两只狗」与只含一只狗的视觉区域,单点概率可能都高,组合却矛盾.序列级一致性指标和联合候选重排能发现.只报各模态token准确率会漏掉此类相关错误. **模态间错误传播.** 文本错误可诱导视觉生成错误对象,视觉错误可诱导答案幻觉.传播方向由生成顺序和写权限决定.在中间状态注入受控错误,测另一模态分布变化,可得到经验传播矩阵并识别高风险枢纽. **只读观测的重要性.** 理解任务中的用户图像属于证据,模型内部生成状态不能覆盖它.可以另建可修改的视觉解释变量,但原始编码保持只读.这样文本先验即使改变解释,验证器仍能回看原观测. **潜变量解释.**

视觉连续特征与文本答案之间可加入对象、布局或场景图潜变量.潜变量提供语义骨架,有利于任意顺序生成;错误骨架也会成为共同瓶颈.训练需检查潜变量是否真正对应可解释结构,而非隐藏编码. **场景图的作用.** 对象—关系图压缩视觉语义,适合计数和空间问答.它忽略纹理、文字与连续属性,不能替代原图.双通道让场景图负责结构、patch负责细节,调度器按问题选择证据. **多粒度视觉token.** 粗粒度token表达全局布局,细粒度token表达纹理.去噪可先恢复粗层再细化,类似层级生成.若文本条件关心小字或微小对象,完全粗到细会延迟关键证据.问题条件可提前激活相关细粒度区域. **多粒度文本条件.**

提示也有全局意图、实体与局部属性.把所有文本token等权注入视觉会让功能词占用注意力.短语聚合或语义层次能提供更稳定条件,但必须保留精确拼写与数字的token通道. **图像分块顺序.** 光栅顺序简单,空间远邻可能相隔很长.由中心到边缘适合主体构图,对象优先适合语义一致,自适应顺序可按不确定性选择区域.顺序比较需固定视觉tokenizer与总步数. **文本描述顺序.** 描述可以先列对象再写关系,也可按自然语序生成.对象先行给视觉生成清晰锚点,自然语序更符合语言模型训练.中间计划若不出现在最终文本,需要独立监督或潜变量目标. **双向迭代的收敛.**

图像更新文本、文本再更新图像类似交替优化.若两侧目标兼容,一致性可提高;若存在多个模式,轨迹可能在方案间振荡.记录跨轮语义状态与循环率,不能只看末轮. **阻尼与模态冻结.** 一侧置信度足够高时可暂时冻结,另一侧继续细化.冻结阈值要用模态特定校准.新证据导致一致性下降时允许解冻.永久冻结过早会把错误锚点传播到另一侧. **联合回滚.** 发现跨模态冲突后,只回滚低置信一侧成本低;根因位于高置信一侧时会反复失败.连续局部失败应升级到共同依赖簇回滚.回滚前保存双方检查点,比较修复是否减少总风险. **模态缺失的生成歧义.**

只有文本时生成图像是一对多问题,只有图像时生成描述也有多种粒度.模型置信度不能按唯一参考校准.应使用集合级正确性、语义覆盖与多样性,并区分合理变化与条件违背. **图像噪声与现实退化.** 扩散训练的掩码或码替换与模糊、压缩、遮挡等现实退化不同.模型擅长从人工噪声恢复,不代表能处理低质输入.训练与评测应加入现实退化,同时保留干净图像对照. **文本噪声与提示错误.** 拼写错误、歧义和错误前提会改变视觉条件.文本去噪可修复表面错误,却不应擅自改写用户意图.模型需要区分可纠正噪声与必须遵循的内容,来源标记和确认机制很重要. **数据增强的一致性.**

裁剪、翻转图像后,描述中的左右、数量与对象可能需要同步修改.若增强只作用图像,训练产生错误配对.颜色变化也会破坏属性词.多模态增强必须保持语义变换一致. **合成数据的偏差.** 用强模型生成描述能扩大数据,也会复制其语言风格、遗漏和幻觉.学生可能学会描述生成器偏好,而非视觉证据.合成数据应与人工数据分桶评测,并用图像条件敏感度过滤. **评测提示敏感性.** 同一视觉问题换一种问法,答案可能大幅变化.这反映文本条件解析与对齐稳定性.多提示模板和语义等价改写能够估计方差.只用训练风格提示会高估泛化. **输出长度控制.**

短答适合高精度事实,长解释需要维持视觉忠实.长度条件若与答案内容纠缠,模型可能通过缩短减少幻觉.评测固定或分层控制长度,同时检查事实覆盖. **拒答与不确定性.** 图像证据不足、分辨率太低或问题超出画面时,合理行为是表达不确定.强制每题输出会把视觉缺失转成语言猜测.训练需包含不可回答样本,评价拒答精确率与覆盖率. **对象不存在的处理.** 存在性问题是检验视觉条件的强反例.语言先验倾向补全常见对象,对齐模型也可能在背景纹理中找到伪证据.加入相似场景的正负配对,并要求区域证据,能减少幻觉. **关系组合泛化.**

训练见过对象和关系分别出现,测试要求新组合,可检验模型是否学到可组合对齐.整体相似度方法容易失败,对象—关系表示更有优势.生成任务中也要检查关系正确,不能只确认对象都出现. **数字与单位.** 视觉读数、图表和仪表盘需要精确数字及单位.子词概率高不代表数值关系正确.结构化解析、范围检查和区域绑定提供验证.小面积数字对全图重建损失贡献极低,需要专门加权. **图表与文档.** 文档图像包含布局、文字、表格与图形,单一patch序列依赖很长.层级布局token可先表示块结构,再读取局部文字.评测应覆盖跨单元格关系、脚注和多页引用,普通图像问答不能代表文档能力. **视觉推理轨迹.**

文本推理过程可能提到观察步骤,但语言链未必对应真实视觉访问.可记录每一步引用区域,检查结论变化是否由相关证据驱动.区域轨迹错而答案对,可能来自猜测;轨迹对而答案错,说明语言推理有问题. **隐式思考与可验证中间量.** 无需强制输出全部推理文本,仍可让模型预测对象集合、数量或关系等可验证中间量.这些中间目标提供跨模态桥接,同时减少冗长文字监督.中间量错误也会限制最终能力,需保留直接答案路径作对照. **共享参数的灾难性遗忘.** 加入视觉训练后,纯文本能力可能下降;继续文本训练又可能削弱视觉条件.按阶段评估两侧能力,使用混合回放或模态适配器缓解.只测多模态榜单无法发现语言基座退化.

### 6.3. 路由容量与学习率共同决定训练稳定性

MoE或适配器可按token模态分配容量,共享专家学习语义,专属专家处理纹理与词法.路由失衡会让某模态拥塞或缺少共享.报告专家负载和跨模态token的路由重叠有助于解释. **学习率与损失尺度.** 视觉前端、语言骨干和联合层的成熟度不同,统一学习率可能破坏预训练表示.分组学习率保护强基座,也会让跨模态融合学习太慢.训练曲线需分别看模态能力与对齐敏感度. **负迁移的诊断.** 加入某模态后另一模态下降,可能来自容量竞争、梯度冲突、数据噪声或位置长度变化.固定数据只增加适配器、固定架构只改变损失权重等消融可逐项定位.总体参数更多仍变差时,容量数量不是唯一原因. **不同生成范式的混合.**

模型可以自回归生成文本计划,再用扩散生成视觉;也可扩散恢复文本、AR生成视觉码.混合范式按各模态结构选择工具,不影响统一语义骨干.比较时应把收益归到顺序、模型和tokenizer三部分. **速度口径.** 文本token每秒与视觉token每秒不能直接相加,因为一个视觉码覆盖的像素与一个子词信息量不同.可报告每样本延迟、各模态处理token、模型FLOPs与输出分辨率.端到端计时还需包含编码和解码器. **内存口径.** 视觉长序列主要占注意力与激活,多轮去噪还重复保存缓存.峰值显存、累计读写和批大小会限制吞吐.算法步数相同,不同可见性图案与缓存策略仍有明显差异.系统数字要保持配置一致. **低分辨率成功的假象.**

低分辨率减少视觉token,任务也可能因细节消失而退化成场景分类.模型得分不错,不代表高分辨率细节理解.应在同一原图上扫分辨率,观察小对象与OCR何时失效. **高分辨率的局部遗漏.** 分辨率增加后,模型可能只路由少量显著区域,更多token没有转成更多证据.区域覆盖率与问题相关区域召回可以诊断.盲目增加视觉token会提高成本,未必改善任务. **最终判断的检查点.** 看到「统一」时先确认统一发生在输入接口、隐藏骨干、词表还是随机过程.看到「双向」时确认两侧是否都被加噪并实际生成.看到「对齐」时检查反事实条件敏感度.看到「更快」时核对编码、解码、步数与分辨率.

多模态扩散真正增加的自由度是两种状态何时可见、何时可写、以什么噪声演化.自由度越大,越需要用权限、校准和对照约束.否则联合模型很容易依赖强模态,再用内部一致性掩盖弱模态没有参与. **条件冲突实验.** 把图像与文字条件故意设置成冲突,可以观察模型的优先级.图像显示红车,提示却声称蓝车,理解任务应依据观测回答,编辑任务则可能按指令改变颜色.相同输入在不同任务标记下需要不同决策.缺少任务权限标记时,模型只能依赖数据频率猜测. 冲突实验应覆盖属性、数量、关系和文字,并记录输出跟随哪一侧.只测无冲突样本无法判断所谓跨模态融合究竟是证据整合还是强模态覆盖. **条件贡献的分解.**

可分别运行完整条件、去掉图像、去掉文本、打乱图像和打乱文本,比较输出风险.完整条件相对单侧条件的增益显示互补性,打乱条件造成的下降显示依赖强度.若去掉图像几乎不变,多模态接口没有转成有效信息. 贡献并非简单相加.图像与问题可能共同确定答案,单独任何一侧都无效.因此还要计算交互项,避免把真正的组合推理误判为两侧都弱. **区域证据的充分性.** 模型指向一个相关区域,仍可能没有用该区域得出答案.将区域替换成反事实内容后答案应相应变化,才能提供更强证据.只看注意力热图容易把相关位置误当因果来源.

区域证据也可能不充分,例如计数需要覆盖全部对象.评测可比较所选区域集合是否包含完成任务所需的信息,而非只检查命中一个显著对象. **模态间的条件熵.** $H(Y\mid I,X)$ 小表示图像与提示足以确定文本,$H(I\mid X)$ 通常很大,因为同一提示对应许多图像.双向生成难度天然不对称.用相同步数与损失期望两侧同样表现,忽略了条件熵差异. 估计绝对熵很难,可用多参考多样性、教师分布和重复标注近似.高条件熵方向更应评价覆盖与多样性,低条件熵方向更重准确性. **联合似然与任务得分.**

联合似然奖励完整数据分布,下游问答只关心少数语义.模型可能提高背景建模似然却不改善答案.反过来,任务微调可提高得分并扭曲生成分布.两类指标需要并列,不能互相替代. 若研究目标是统一生成,应保留无条件与多条件采样质量;若目标是理解,应重点报告条件干预和任务风险.目标不同,模型选择也会不同. **对齐误差的传播距离.** 局部区域与词错配后,影响可能局限于一个名词,也可能改变整段解释和生成构图.在不同层注入错配并测量下游token变化,可以估计传播距离.传播长的锚点需要更严格校准和回滚.

传播距离还受注意力图案影响.全双向连接扩散快,稀疏连接将错误限制在局部,同时可能阻断正确证据.结构设计需要在信息流与错误隔离之间取舍. **多模态停止的误判.** 两侧输出不再变化可能是共同错误固定点;一致性分高也可能来自一侧改写去迎合另一侧.停止前应检查只读证据、任务约束和反事实稳定性.至少一个独立信号没有通过时,内部一致不应触发结束. 晚停也会损害结果.图像已经满足提示后继续去噪可能丢掉小文字,文本已经正确后继续改写可能增加幻觉.保存历史最佳联合状态比固定取末轮更稳. **联合状态的检查点.**

回滚必须保存两种模态及其时间坐标.只回退文本而保留由旧文本诱导的视觉状态,条件仍然污染;只回退视觉也一样.局部回滚应明确哪些跨模态缓存和对齐表示失效. 检查点可在关键锚点通过验证时建立.频率太高增加内存,太低导致大范围重算.平均回退距离和检查点命中率属于联合调度成本. **评价器的模态偏差.** 视觉评分器可能偏爱真实纹理,语言评分器偏爱流畅描述,图文评分器偏爱常见概念.三者一起使用仍可能共享训练数据偏见.受控反例和人工抽查用于覆盖评分器盲点. 评价器参与引导时,偏差会直接改变生成分布.用于评测与用于推断的结果应分开,避免同一评分器既优化又裁判. **开放世界实体.**

视觉中可能出现词表罕见实体,文本模型会映射到常见近邻;文本提示也可能包含视觉训练未见概念.子词能拼出名字,视觉表示未必有对应语义.检索或外部知识可补充,同时引入来源与时效风险. 开放实体评测应使用时间切分与长尾类别,并检查区域证据.只在常见封闭类别上高分,不能证明开放多模态对齐. **端到端结论.** 从输入到输出依次经过模态编码、状态构造、加噪、联合去噪、调度、解码和评价.任何一层都可能成为瓶颈.视觉tokenizer上限低时继续扩大语言骨干收益有限;条件通道未被使用时增加去噪步数也没有帮助.

因此实验应先定位最弱环节,再解释整体结果.统一架构的价值在于允许信息双向流动,实际能力取决于数据是否提供对齐、目标是否奖励使用条件、调度是否保护观测事实.
