# Eso-LM:任意顺序损失,因果注意力换精确 KV

[任意顺序与概率因式分解](../../2-数学与生成机制/2.4-任意顺序与概率因式分解.md)区分了生成顺序与注意力结构.LLaDA / MDLM 都支持任意顺序,但每揭开一次就要重算整段 $K,V$.块扩散通过固定块间顺序恢复前缀缓存,块内仍使用双向注意力.Eso-LM(Sahoo 等人,arXiv:2506.01928)保留对排列求期望的训练目标,把注意力改为因果结构,从而在扩散阶段精确复用 KV.名字里的 Esoteric 指用于探索语言边界的深奥编程语言,与前向核 $Q_t$ 无关.

并行生成不必绑定双向注意力.Eso-LM 通过洗牌把生成顺序移到序列本身,再用因果注意力恢复 KV Cache.实验包含 A/B 两档注意力结构,PPL 对照以及相对无缓存 MDLM 的 14× / 65× 延迟结果.骨架是 LM1B / OWT 上的 DiT 尺度,参数量没有达到 7B.

## 1. 损失任意,注意力不必双向

吸收态 $1/t$ 损失在期望上等于对生成顺序求自回归负对数似然.这个等价关系约束训练**目标**,并不规定 Transformer 中 Query 的可见范围.MDLM 用全双向注意力参数化任意顺序条件,当前所有可见 token 都可作为上下文.代价是 Key 依赖整句以及尚未揭开的占位符;新揭开一个 token 后,所有 $K,V$ 理论上都会变化.

任意顺序 AR 本来就允许因果注意力:把序列按某条排列 $\sigma$ 排好,再做下三角.Eso-LM 把这条老路接回掩码扩散.给定 $z_t$,把干净 token 聚到左边,MASK 聚到右边,**位置编码仍用原句的下标**(RoPE / 绝对位置都不跟洗牌走).然后走标准因果注意力.左边的干净前缀再也不会依赖右边尚未揭开的 MASK,KV 可以写进缓存.MASK 之间按洗牌后的次序因果可见:本步要揭的那些 MASK 能看见全部干净字,以及排在自己前面的其它 MASK.

> 图 1:左列按原序使用全双向注意力,无法精确复用 KV.右列先洗牌再使用因果注意力,已确定前缀的 KV 可以持续复用.任意顺序损失与双向解码并不绑定.

### 1.1. 图 1 中的排列与计算图

- **左列 mixed clean and MASK**:LLaDA / MDLM 默认.位置 $i$ 的 Query 看见所有 $j$.
- **every token attends every other**:揭开任意一格,所有 Key 过期.
- **NFE times $L^2$**:步数乘全序列注意力.并行揭开减的是 NFE,减不掉每一次前向的 $L^2$.
- **右列 gather clean left**:洗的是计算图,不是语义顺序.RoPE id 仍是「这个词在句中第几号」.
- **causal attention; exact KV**:干净前缀单调变长,和 AR 的前缀同构,只是前缀里的词不一定是从左到右长出来的.
- **65× vs uncached MDLM**:Table 11 在 $L=8192$,最坏 $T\gg L$,禁 nucleus,A6000.对照物是无 KV 的 MDLM;AR 和 Fast-dLLM 的 27.6× 使用其他协议.

例如原句为 $(A,B,C,D,E,F)$,当前 $z_t=(A,\mathrm{M},C,\mathrm{M},\mathrm{M},F)$.洗牌后的计算序列可以是 $(C,A,F,\mathrm{M},\mathrm{M},\mathrm{M})$,RoPE 仍分别使用原位置 3,1,6,2,4,5.在因果掩码下,第一个 MASK 看见 $C,A,F$,后面的 MASK 还可看见排在前面的 MASK.$A$ 的 Key 不依赖任何 MASK,下一步揭开新 token 时,只需把它的 KV 追加到干净前缀.全双向注意力则需要重新计算整段 KV.

洗牌时必须同时保留原位置 id.若把左侧三个干净 token 重新编号为 1,2,3,模型会把 $C,A,F$ 误认为句首.RoPE 的相对位置应描述 token 在原句中的距离,而非洗牌后计算序列中的次序.因此 token 表示随内容移动,RoPE 角度仍取原下标;缺少后一项会破坏句法与语义位置关系.

图右有两种顺序同时存在.原位置 $i$ 表示 token 在最终句子中的语义坐标,排列位置 $k$ 表示它在当前因果计算图中的可见次序.注意力掩码按 $k$ 构造,位置编码按 $i$ 构造.将两者混用会产生两种不同错误:按 $i$ 做因果掩码会重新限制为左到右,按 $k$ 做位置编码会把洗牌后的临时顺序当成句法顺序.

设排列 $\sigma=(\sigma_1,\ldots,\sigma_L)$,第 $k$ 个计算位置装载原序列的第 $\sigma_k$ 个 token.输入表示可写为

$$
h_k^{(0)}=E(x_{\sigma_k})+P(\sigma_k)+T(t),
\tag{1}
$$

$E$ 是 token 嵌入,$P(\sigma_k)$ 表示原位置编码,$T(t)$ 是扩散时间条件.第 $k$ 个 Query 只能读取 $j\leq k$ 的 Key.因此因果关系由 $k$ 决定,空间关系由 $\sigma_k$ 决定.这正是任意顺序条件生成能够使用因果 Transformer 的关键分离.

缓存项也按计算顺序追加,每项仍携带原位置相位.若 RoPE 作用于 Query 和 Key,缓存中的第 $j$ 项使用 $P(\sigma_j)$ 对应的旋转.下一轮加入原位置 $i$ 的新 token 时,它的 Query 与历史 Key 的相对相位反映 $i-\sigma_j$,不会反映它被追加到缓存尾部这一事实.缓存物理地址可以单调增长,语义坐标无需单调.

### 1.2. 任意顺序联合概率的含义

注意力偏置写成 $A\in\{-\infty,0\}^{L'\times L'}$,并加到 Softmax 前的 logits.训练使用两种 $A$:扩散样本采用洗牌后的下三角偏置;顺序样本把干净 token 放在左侧,MASK 保持原相对次序,并允许 MASK 看见 shift-by-one 对应的干净版本.两种偏置共用同一套权重.训练与推理都采用因果依赖,因此缓存的 KV 与实际计算图一致;仅在推理时把双向模型改为因果掩码无法获得这种性质.

对固定排列 $\sigma$,联合概率由链式法则写成

$$
p_\theta(x\mid\sigma)=
\prod_{k=1}^{L}
p_\theta\!\left(x_{\sigma_k}mid x_{\sigma_{<k}},\sigma\right),
\tag{2}
$$

$x_{\sigma_{<k}}$ 是排列中较早生成的 token.若排列来自分布 $p(\sigma)$,表面序列概率为

$$
p_\theta(x)=\sum_{\sigma\in\mathcal S_L}
p(\sigma)p_\theta(x\mid\sigma).
\tag{3}
$$

式 (3) 是排列混合模型.同一个句子通过多条顺序路径获得概率质量,因此某条顺序下的乘积不能单独当作最终序列似然.训练对随机排列取期望,通常优化

$$
\mathcal L_{\mathrm{AO}}(x)
=\mathbb E_{\sigma\sim p(\sigma)}
\left[-\sum_{k=1}^{L}
\log p_\theta(x_{\sigma_k}\mid x_{\sigma_{<k}},\sigma)
\right].
\tag{4}
$$

式 (4) 平均每条路径的负对数似然,与式 (3) 的负对数混合似然并不相等.Jensen 不等式给出

$$
-\log p_\theta(x)
\leq \mathcal L_{\mathrm{AO}}(x)
\quad\text{当 }p(\sigma)\text{ 同时作为混合权重时}.
\tag{5}
$$

训练所有顺序都表现良好会压低上界,也可能把容量分散到推理时很少使用的排列.若推理固定采用某个调度,与训练均匀排列之间会存在路径分布差异.均匀训练带来顺序鲁棒性,不保证每条顺序同样容易.

链式法则本身对任意固定排列都成立,前提是各条件来自同一个联合分布.神经网络为不同可见集合分别输出条件,有限容量下未必严格兼容.例如两变量 $X,Y$ 的模型可能同时给出 $p(X=1)=0.9$、$p(Y=1\mid X=1)=0.9$、$p(Y=1)=0.1$ 和 $p(X=1\mid Y=1)=0.1$.两条顺序诱导的联合质量会不同,无法由单个精确联合同时满足.对排列求期望是在训练中压缩这类矛盾,不会自动使所有条件完全兼容.

### 1.3. 条件兼容与路径一致性

两变量情形最容易看清条件兼容.若存在联合分布 $p(x,y)$,则

$$
p(x)p(y\mid x)=p(y)p(x\mid y)
\tag{6}
$$

对所有 $x,y$ 都成立.神经网络分别在可见集合 $\varnothing$、$\{X\}$ 和 $\{Y\}$ 上预测时,式 (6) 没有结构保证.训练数据与共享参数让这些条件趋向一致,但损失只在采样到的掩码和排列上施加局部约束.模型容量、优化误差和状态覆盖不足都会留下闭环不一致.

长度为三时,同一个目标 token 可以经不同可见集合到达.例如 $p(C\mid A)$ 与先生成 $B$ 后得到的 $p(C\mid A,B)$ 都参与路径.路径一致不要求这两个条件相等,因为信息量不同;它要求沿所有完整排列得到的乘积对应同一联合.可以检查交换相邻生成动作前后的对数概率差:

$$
\Delta_{i,j}(S)=
\log p(x_i\mid x_S)
+\log p(x_j\mid x_S,x_i)
-\log p(x_j\mid x_S)
-\log p(x_i\mid x_S,x_j).
\tag{7}
$$

$S$ 是已经可见的位置集合.精确兼容时 $\Delta_{i,j}(S)=0$.它相当于在排列图的一条小闭环上比较两条路径.对训练或验证状态抽样计算 $|\Delta|$,可以诊断任意顺序模型的条件是否因顺序发生系统漂移.

闭环误差与最终生成误差不完全相同.某些低概率状态上 $|\Delta|$ 很大,实际采样很少访问;高概率轨迹上的小偏差则会在长序列中累积.因此诊断应按模型轨迹加权,同时报告最坏值用于发现结构问题.只比较不同顺序的最终 PPL 会把误差来源混在一起.

因果洗牌还引入可见次序信息.条件网络不仅知道可见 token 集合,还可能从缓存次序或注意力位置推断它们按什么顺序加入.若联合语义只应依赖集合,同一集合的不同排列应得到相同下一 token 分布:

$$
p_\theta(x_i\mid x_{\sigma_{1:k}})
=p_\theta(x_i\mid x_{\rho_{1:k}}),
\quad
\{\sigma_{1:k}\}=\{\rho_{1:k}\}.
\tag{8}
$$

原位置编码减少了临时次序进入空间语义的机会,因果层仍可能通过隐藏状态传播顺序痕迹.随机化已见 token 的排列、采用集合等变结构或增加一致性损失,都能压低式 (8) 的差异.严格消除次序信息可能限制缓存组织和表达能力,需要由任务结果判断是否值得.

## 2. A 档贴近似然,主方法换 KV

**2.1. 两种注意力结构对应两类条件族**

作者把「从 MDLM 走到可缓存」拆成两刀.

Eso-LMs (A):MASK 上因果,干净位之间仍双向.扩散阶段不能精确缓存干净字的 KV,因为干净字互相看见,也仍可能被尚未揭开的结构影响.附录 Table 9 / 10,$\alpha_0=1$ 全扩散时,A 档 LM1B NELBO PPL 30.96 对 MDLM 31.78,略好;OWT 26.21 对 25.19,略差.论文说 matches.他们不追求 A 档,因为它在扩散阶段仍没有他们要的 KV.

主方法(正文里的 Eso-LMs):干净位也因果.这才换来扩散阶段精确 KV.同一 $\alpha_0=1$,LM1B NELBO 36.12 对 MDLM 31.78,大约 +4 PPL;OWT 30.06 对 25.19.缺口来自「干净字不能互相看」.似然竞赛输了这一截,换的是缓存.

噪声日程还包含 $\alpha_0$:$\alpha_t=\alpha_0(1-t)$.$\alpha_0=1$ 接近纯扩散;$\alpha_0=0$ 回到 AR 精确似然(LM1B 21.86,与带 AdaLN 的 AR 相同).中间值在两套损失之间插值,batch 中一部分样本走扩散,另一部分走顺序填充.Table 1 同时报告 Exact 与 NELBO.$\alpha_0=0.125$ 时 LM1B Exact 为 23.02,接近 AR 的 22.83,同时保留一段可并行的扩散期.$\alpha_0$ 控制质量与速度的工作点,而非定义新的前向核.

主方法还声称第一次给 MDM 报**精确**似然(重要性加权,LM1B 用 $K=5000$,OWT 用 $K=1000$).MDLM 通常只报 NELBO.OWT 上 $\alpha_0=1$ 的 Exact 29.31,和 MDLM 的 NELBO 25.19 仍有缝.他们强调 $\alpha_0=1$ 尽管 NELBO 差一截,固定采样时间下生成质量仍优于 MDLM,因为每步便宜.似然表和速度表要一起读.

A 档在干净 token 之间允许双向交互.给定已见集合 $S$,每个 $x_i,i\in S$ 的隐藏表示可依赖集合中所有其他 token.新增一个 token 后,旧隐藏状态也可能改变,所以缓存失效.主方法要求旧 token 的表示只依赖它加入时更早的计算前缀,新增 token 不会反向影响旧 Key 与 Value.由此得到单调可追加缓存.

两类结构近似的条件分布不同.A 档更接近集合条件 $p(x_i\mid x_S)$,理想情况下对 $S$ 内排列不敏感;主方法实现的是顺序条件 $p(x_i\mid x_{\sigma_{1:k}};\sigma_{1:k})$,共享参数通过随机排列学习近似集合语义.当目标依赖可见 token 之间多轮交互时,A 档表达更直接.主方法仍可在深层因果网络中让后加入 token 汇总此前信息,旧 token 无法获得后加入 token 的反馈.

考虑已见位置 $A$ 和 $B$,下一位置 $C$ 需要比较 $A$ 与 $B$ 的关系.A 档可让 $A$ 的表示读取 $B$、$B$ 的表示读取 $A$,再由 $C$ 读取两个更新后的表示.主方法若顺序为 $A,B,C$,$B$ 可以汇总 $A$,$C$ 再读取 $B$,仍能完成比较;若某种计算要求 $A$ 在看到 $B$ 后更新并由多个后续位置复用,主方法只能让后续位置重复完成这项组合.这种差异解释了缓存与似然之间的代价,不意味着因果网络无法表示双向关系.

### 2.2. 精确似然仍然需要边缘化顺序

精确似然为什么现在才可算.双向 MDM 的潜变量是整条掩码轨迹,重要性加权要 $K\times L$ 次前向,一般不可行.任意顺序写法里,一条排列 $\sigma$ 已经串起这条轨迹上的所有潜变量,单样本估计方差更小.Table 2 用一条 OWT 句子,100 次试验:$\mathcal{L}_{\mathrm{MDM}}$ 抽 10 个 $(t,z_t)$,标准差 0.56;$\mathcal{L}_{\mathrm{AO}}$ 只抽 1 个 $\sigma$,标准差 0.03,均值几乎一样.这是工程动机,不仅是论文审美.LM1B 句子短($L=128$),他们甚至给 MDLM 跑了 $K=1000$ 的 IW,精确似然仍落后 AR.扩散在似然竞赛上的缝,不全是估计器太松,也有模型族自己的缝.Eso-LM 用因果参数化,至少让「缝有多大」第一次能写在 Exact 列里.

一条排列给出 $p_\theta(x\mid\sigma)$ 的可计算乘积,式 (3) 仍含 $L!$ 项.重要性采样从提议分布 $q(\sigma\mid x)$ 抽取 $K$ 条排列,估计

$$
\hat p_K(x)=\frac{1}{K}\sum_{k=1}^{K}
\frac{p(\sigma^{(k)})p_\theta(x\mid\sigma^{(k)})}
{q(\sigma^{(k)}\mid x)},
\quad \sigma^{(k)}\sim q.
\tag{9}
$$

若 $q=p(\sigma)$,权重退化为 $p_\theta(x\mid\sigma)$.不同排列的概率跨度很大时,少数权重会主导估计,有效样本数降低.因果任意顺序的优点是一次排列可在一条前向链上累计所有条件项,不代表排列边缘化已经免费.

对数似然常用 $\log\hat p_K(x)$,有限 $K$ 下仍有偏差.随着 $K$ 增大,重要性加权下界收紧.报告 Exact 一列时要同时读取 $K$、提议分布和序列长度;不同 $K$ 的数不能直接当作同精度估计.论文在 LM1B 与 OWT 使用不同 $K$,与句长和计算预算有关.

顺序分布若由模型学习,联合概率还要包含 $p_\phi(\sigma\mid x_{\sigma_{<k}})$ 的逐步选择概率.测试时用启发式调度而训练似然假定均匀 $p(\sigma)$,生成器对应的路径分布会变化.这不妨碍将调度当作搜索算法使用,但生成样本不再是式 (3) 下未经修正的精确采样.似然估计与有限步生成质量应分别报告.

### 2.3. $\alpha_0$ 如何改变概率分解

$\alpha_0=0$ 时模型沿固定左到右顺序应用链式法则,不存在扩散阶段的排列混合.$\alpha_0=1$ 时全部 token 进入任意顺序目标,每条样本训练可见多种掩码集合.中间 $\alpha_0$ 可理解为将序列的一部分概率质量交给任意顺序阶段,剩余部分交给顺序阶段.它改变训练样本中两类条件的比例,也改变推理时可并行处理的范围.

设切换点为随机变量 $m$,扩散阶段生成集合 $S_m$,顺序阶段按原位置完成补集.一种抽象分解是

$$
p(x)=\sum_{m,S_m,\sigma}
p(m,S_m,\sigma)
\left[\prod_{k\leq m}p_\theta(x_{\sigma_k}\mid x_{\sigma_{<k}})\right]
\left[\prod_{i\notin S_m}^{\text{原序}}p_\theta(x_i\mid x_{S_m},x_{<i}\cap S_m^c)\right].
\tag{10}
$$

第一项容许不相邻位置并行或任意排序,第二项恢复标准顺序.实际算法的 $\alpha_0$ 和 $\kappa$ 控制方式更具体,式 (10) 用于说明混合生成仍对应完整条件乘积,切换点前后的上下文集合不同.

切换太早时,大多数 token 由顺序阶段生成,质量接近 AR,扩散并行收益有限.切换太晚时,更多 token 使用有限容量的任意顺序条件,因果干净位的表达缺口和并行因子化误差增大.最佳点随长度、模型容量和 NFE 改变.单个 $\alpha_0$ 的验证集最优值不构成跨任务常数.

混合训练还提供共享参数正则.顺序样本教会模型稳定的左到右条件,扩散样本扩展可见集合与生成顺序.若两类梯度方向冲突,共享层需要折中;若互补,顺序任务可为早期训练提供较低方差信号.消融 $\kappa$ 的意义就在于观察两类梯度配比,不能只把它当成数据 batch 的实现参数.

## 3. 采样两阶段,一份 KV

### 3.1. 调度定义了生成路径

生成先走扩散期:每步揭开一个或多个不必相邻的 MASK,前向只喂「已干净 ∪ 本步要揭的 MASK」,不是整段占位符.再走顺序期:剩下的 MASK 从左到右一个一个填.两期共用同一份 KV.第 $k$ 步把第 $k-1$ 步新干净字的 KV 写入,更早的前缀直接复用.原则上调度 $\mathcal{S}$ 可以在测试时改,不必等于训练时见过的那条.

和 BD3-LM 的差别不在「能不能插值 AR」,在缓存完不完整.块扩散:块间真 KV,块内双向,块内无精确 KV.少步时 BD3-LM 会出又差又没多样性的样本,作者写得很难听.Eso-LM 少 NFE 时仍和 MDM 竞争性,高 NFE 时贴近 AR.帕累托图(Fig. 4 / 17)是无条件生成,生成 PPL 与 MAUVE,不是 HumanEval.

相对 BD3-LM,长上下文延迟约 3–4×:Table 11,$L=8192$ 时相对块长 16 约 3.2×,相对块长 4 约 3.8×.相对无 KV 的 MDLM:$L=2048$ 约 14×,$L=8192$ 约 65×.测速在单卡 A6000,吞吐另在 H200.最坏设定 $T\gg L$,关掉 nucleus.长度越长,无缓存基线越亏,倍数越好看.短句,已经很快的 AR serving,看不到 65.

在相同 NFE 下,Eso-LM 比 AR 略慢,因为 KV 到倒数第二步才完全可复用:新 MASK 第一次出现时还不能作为历史.Eso-LM 的加速基线是每步执行 $L^2$ 双向注意力的 MDLM,不是经过成熟 serving 优化的 vLLM 因果模型.

MDLM 的一次去噪会对全部 $L$ 个位置计算注意力,即使其中大部分仍是占位符.Eso-LM 第 $k$ 步只把 $\cup_{i\le k}S_i$ 送入网络,其中包含已经干净的 token 和本步要揭开的 MASK.长序列的早期步骤只处理少量位置,激活长度因而远小于 $L$.65× 加速同时来自 KV 复用和前向集合缩减.若实现仍把全序列填充进 CUDA graph,后一部分收益会消失.论文的调度 $\mathcal{S}$ 与注意力偏置共同确定有效前向集合,仅实现 KV 缓存会低估完整方法的加速幅度.

令 $S_k$ 是第 $k$ 轮提交的位置集合,$U_k=\bigcup_{j\leq k}S_j$ 是累计已提交集合.一条合法调度满足 $S_j\cap S_k=\varnothing$ 且最终 $U_K=\{1,\ldots,L\}$.每轮条件分布为

$$
p_\theta(x_{S_k}\mid x_{U_{k-1}},S_k),
\tag{11}
$$

若对 $S_k$ 内位置独立采样,进一步近似成 $\prod_{i\in S_k}p_\theta(x_i\mid x_{U_{k-1}})$.调度决定每轮条件集,集合大小决定并行程度.所有 $|S_k|=1$ 时得到任意顺序串行生成;单轮 $|S_1|=L$ 时近似无条件并行预测,联合一致性最弱.

Eso-LM 的因果计算可以让同一轮 MASK 按内部次序相互可见,但同时采样哪些 logits、哪些 token 已进入条件需要精确定义.若一轮中的后方 MASK 读取前方 MASK 的占位表示,它并未看到前方本轮新采样的词;若在同一轮内逐个写入并更新隐藏状态,该轮实际包含多个串行子步.报告 NFE 时应区分一次批量前向和轮内递归.

调度可以预先固定,也可以由当前分布自适应选择.固定等间距策略不读取 logits,路径概率容易复现;置信度策略依据去噪器输出改变 $S_k$,高置信位置先进入缓存;学习规划器可以结合错误概率和信息价值.后一类调度产生状态依赖路径,同一句话在不同采样随机数下可能走不同排列.

**3.2. 顺序策略与信息增益**

由易到难策略使用 $c_i=\max_v p_\theta(x_i=v\mid x_U)$ 排序.它降低单步提交错误,还会让可靠 token 成为后续上下文.等间距策略关注同批位置之间的依赖:空间距离较远时,在局部相关数据上更接近条件独立.两者优化不同代理量,一个测单点可靠性,一个减少批内耦合.

更直接的目标是选择能最大幅度降低剩余不确定性的集合.对候选集合 $S$,信息收益可写为

$$
G(S)=H(X_R\mid x_U)-
\mathbb E_{x_S\sim p_\theta}
H(X_{R\setminus S}\mid x_U,x_S),
\tag{12}
$$

$R$ 是未生成位置集合.精确计算需要枚举 $x_S$ 并重复评估剩余分布,成本远高于一次去噪.置信度、距离、注意力影响和小型规划头都可作为近似.当 $G(S)$ 近似次模时,逐个贪心选择有较好性质;语言依赖包含互补结构,次模性没有普遍保证.

计划与填槽在此分开.计划器选择 $S_k$ 和内部次序,填槽器给出 $x_{S_k}$.一个好计划可以让普通填槽器获得充分上下文,一个强填槽器也能缓解次优计划.评测计划器时应冻结填槽器,否则两者共同变化无法归因.Eso-LM 使用启发式 $\mathcal S$,没有训练独立脏净头.

顺序策略还会形成内容偏差.高频词和标点往往置信度高,会被优先提交;稀有实体与数字留到后面.这可能有利于先搭建句法,也可能让低信息 token 占用早期并行预算.距离策略与内容无关,避免频率偏差,却不能发现某个关键实体能约束整句.任务相关规划需在两者之间权衡.

### 3.3. 搜索、并行与束宽

任意顺序生成的搜索空间同时包含位置动作和 token 动作.串行时,每一步有约 $|R|V$ 个位置—词组合;批量大小为 $b$ 时,位置组合数为 $\binom{|R|}{b}$,token 组合达到 $V^b$.完整束搜索不可行,实用方法必须先压缩位置候选或对 token 作因子化.

两阶段搜索可先保留 $K_s$ 个位置集合,再为每个集合保留 $K_x$ 个 token 候选.路径评分为

$$
J=\sum_k\left[
\log p_\phi(S_k\mid x_{U_{k-1}})
+\log p_\theta(x_{S_k}\mid x_{U_{k-1}},S_k)
\right]-\lambda K,
\tag{13}
$$

$\lambda$ 惩罚轮数或计算.启发式调度没有显式 $p_\phi$,第一项可省去,这时搜索找到的是给定调度候选集中的高概率 token 路径.若把置信度排序分数当概率累加,需要先校准其归一化含义.

并行提交会减少搜索深度,增加单层分支相关性.串行束搜索能够在每个 token 后重新排序,批量搜索要在看到组内其他 token 前承诺多个选择.可使用候选重采样:一次并行生成多个完整批次,由序列评分器选择;它用宽度换深度,每个候选仍受组内独立近似限制.

另一种折中是树状调度.先并行生成相距较远的锚点,再把未填区间分裂成子区间,每层同时处理多个互不重叠区域.若序列局部依赖较强,树深约为 $O(\log L)$,每层位置之间相对独立.长距离语义依赖会穿过区间边界,树结构没有普遍正确性.等间距启发式可看作这种思想的第一层.

缓存约束影响搜索共享.不同位置顺序会形成不同 KV 前缀,束之间难以完全共享缓存;拥有相同已见集合但加入次序不同的束,隐藏状态也可能不同.限制搜索只改变下一批集合、保持已有前缀一致,可以共享历史 KV.更自由的顺序搜索带来更大质量空间,同时削弱 Eso-LM 的系统优势.

### 3.4. 一次小规模手算

考虑长度为 4 的二元序列,当前已知原位置 1 的值为 $A$,其余位置未填.候选调度甲先生成位置 3,再同时生成位置 2 和 4;调度乙按原序生成 2、3、4.假设模型给出的条件概率为

$$
\begin{aligned}
p(x_3=C\mid x_1=A)&=0.8,\\
p(x_2=B\mid x_1=A,x_3=C)&=0.9,\\
p(x_4=D\mid x_1=A,x_3=C)&=0.7.
\end{aligned}
\tag{22}
$$

调度甲若第二轮独立填 2 和 4,目标路径概率近似为 $0.8\times0.9\times0.7=0.504$.若位置 2、4 在给定 $A,C$ 后仍相关,这个乘积不是它们的真实联合.调度乙可能给出

$$
p(B\mid A)=0.6,
\quad p(C\mid A,B)=0.95,
\quad p(D\mid A,B,C)=0.95,
\tag{23}
$$

路径概率为 $0.5415$.虽然甲第一步置信度更高,完整路径反而略低.局部最高置信选择没有最大化完整联合乘积.

再设调度甲第二轮的真实联合 $p(B,D\mid A,C)=0.75$,高于边缘乘积 $0.63$,则甲的正确联合路径为 $0.8\times0.75=0.60$,反过来超过乙.判断顺序优劣需要联合条件,不能只根据三项边缘数字.这个例子也说明批内正相关时乘积会低估一致组合,负相关时会高估.

缓存状态在两条调度中不同.甲的追加顺序是原位置 $(1,3,2,4)$,乙是 $(1,2,3,4)$.每项 RoPE 仍用 $(1,3,2,4)$ 或 $(1,2,3,4)$ 中记录的原坐标,因果可见历史则按追加次序增长.即使两条路径最终得到相同表面序列,中间隐藏表示和路径概率也可能不同.

若模型条件完全兼容,把甲第二轮拆为先 2 后 4时应满足

$$
p(B,D\mid A,C)=p(B\mid A,C)p(D\mid A,B,C).
\tag{24}
$$

并行边缘乘积使用的是 $p(B\mid A,C)p(D\mid A,C)$,少了 $B$ 对 $D$ 的条件.这项缺失正是并行加速的概率代价.位置相距很远只是在某些数据上让两项接近,不构成恒等式.

**3.5. 调度的动态规划视角**

将已见集合 $U$ 视为状态,选择下一集合 $S\subseteq U^c$ 为动作,填槽后的新状态为 $U\cup S$.若代价同时考虑错误和计算,最优价值满足

$$
V(U,x_U)=\min_{S\subseteq U^c}
\left{c(S,U)+
\mathbb E_{x_S\sim p_\theta}
[V(U\cup S,x_{U\cup S})]
\right}.
\tag{25}
$$

$c$ 包含一次前向成本与本轮错误风险.状态数量为 $2^L$,还要考虑每个 $x_U$ 的取值,无法精确动态规划.置信度、距离和固定日程都是对价值函数的局部近似.

若只惩罚轮数,$c$ 会鼓励一次提交尽可能多的位置;若只惩罚 token 错误,最优策略可能退化成完全串行并进行大量搜索.实际目标用系数 $\lambda$ 平衡两者.不同部署延迟预算对应不同 $\lambda$,所以不存在脱离成本定义的全局最佳顺序.

可以训练价值网络 $V_\psi(U,x_U,b)$ 估计剩余预算 $b$ 下的最终质量.位置策略选择使价值最高的集合,填槽器提供转移.训练价值需要从真实或模拟轨迹得到回报,策略改变后状态分布也会变.若回报来自外部任务验证,样本效率通常低于 token 交叉熵.

滚动时域控制提供较便宜近似:枚举少量候选 $S$,向前模拟一两轮,用当前去噪损失或验证器给终端状态评分,只执行第一步.它比纯置信度看到更远,每个候选需要额外前向.候选数、模拟深度和质量之间形成新的计算曲线.

对于局部依赖序列,可以把状态压缩为若干未填区间及边界 token,动态规划复杂度下降.自然语言的远距离实体、格式和语义依赖破坏这一假设.块扩散隐含采用了区间分解,等间距调度隐含假设相远位置依赖较弱.Eso-LM 本身不要求这些假设,启发式调度的效果会受其影响.

**3.6. 并行度如何进入误差上界**

设本轮集合 $S$ 的真实联合为 $p_S$,边缘乘积近似为 $q_S=\prod_{i\in S}p_i$.二者的 KL 散度

$$
D_{\mathrm{KL}}(p_S\Vert q_S)
=\sum_{i\in S}H(X_i\mid x_U)-H(X_S\mid x_U)
\tag{26}
$$

称为总相关,衡量批内依赖.当位置条件独立时为零;集合扩大通常纳入更多依赖,总相关倾向增加.这给出动作大小与联合误差之间的直接联系.

Pinsker 不等式把 KL 与总变差联系起来:

$$
\operatorname{TV}(p_S,q_S)
\leq\sqrt{\frac12D_{\mathrm{KL}}(p_S\Vert q_S)}.
\tag{27}
$$

因此选择总相关较小的集合能控制单轮近似分布偏差.问题仍在于模型只有边缘条件,无法廉价得到真实 $p_S$.若训练一个成对依赖头,可以近似两两互信息,高阶约束仍可能遗漏.

多轮误差会累积.若第 $k$ 轮转移核近似误差为 $\epsilon_k$,粗略上最终总变差不超过 $\sum_k\epsilon_k$.该界通常很松,却说明减少 NFE 与增大单轮误差之间存在结构性折中.少步方法必须让每轮集合更大,除非使用能够直接表示块联合的去噪器.

位置选择还改变未来误差.当前提交一个高信息 token 可能降低后续集合总相关,即使它自身置信度不最高.动态规划式 (25) 需要考虑这种长期作用.等间距策略通过空间分散近似降低当前相关,由易到难策略通过增加可靠上下文近似降低未来相关,两者各抓住一部分.

## 4. 和 DualCache,块扩散,LLaDA 8B 分开

### 4.1. 精确缓存依赖一个单调不变量

Fast-dLLM DualCache 是**近似**:承认 $K,V$ 会变,赌相邻步余弦相似度高.Eso-LM 是**精确**:注意力定义让干净前缀的 $K,V$ 不再依赖未来 MASK.近似可以贴在现成 LLaDA 权重上,训练免费;精确要按洗牌+因果重训(或从 MDLM 改注意力再训).27.6× 贴的是原版逐步揭开的 LLaDA;65× 贴的是无缓存 MDLM.两张卡,两种骨架,两种对照物.

块扩散把任意顺序限制在块内,以获得块间 KV 缓存.Eso-LM 仍可在全序列并行揭开不相邻的 MASK,不会受到未来块不可见的限制,代价是主方法中的干净 token 之间也采用因果依赖.A 档恢复干净 token 间的双向注意力,同时失去扩散阶段的精确 KV.跨句填空更适合全双向或 A 档,长序列无条件生成与缓存更适合主方法.目前还没有 8B 指令模型上的同规模对照.

LLaDA 8B 于 2025 年 2 月发布,论文明确指出全双向注意力与当时的 KV 缓存公式不兼容,因此采用 MHA 而非 GQA.Eso-LM 是同年 6 月沿 MDLM 路线发表的后续工作,实验停留在语言模型基准,下游任务留作未来工作.正文还提到 Sahoo 等人 2026 年把 $\alpha_0=1$ 扩展到 1.7B,在零样本似然任务上与 MDLM 具有竞争力.该结果的模型规模和任务都不同于 LLaDA 8B 的 GSM8K,因此 65× 不能直接作为 LLaDA 产品加速数据.

GQA 在因果前缀上重新具有明确收益.干净前缀的 KV 可以精确复用,减少 KV 头能够直接节省有效缓存内存.Eso-LM 实验没有采用 GQA,只证明了这种组合在依赖结构上可行.未来若出现因果洗牌的 7B 模型,GQA 与 KV 量化可以沿用 AR 系统的实现方式.这属于架构上的可能性,并非当前检查点的规格.若开放 8B 模型同时要求精确 KV 与双向填空能力,仍需在 A 档和块扩散之间取舍.65× 与 27.6× 分别使用不同模型和基线,不能放在同一协议下直接比较.

洗牌实现还要同步移动位置 id,否则 RoPE 会把所有干净 token 解释为句首.训练时 MASK 的因果次序来自 $\sigma$,测试时可以更换调度,前提是已预测 token 不再依赖未预测 token.若只洗牌 token 而未同步调整注意力偏置,计算图会偏离因果约束,缓存的 KV 也无法精确复用.

精确 KV 的不变量可以写成:对任意已经提交的位置 $i\in U_k$,其第 $\ell$ 层缓存 $(K_i^{(\ell)},V_i^{(\ell)})$ 只依赖 $x_{U_j}$,其中 $j$ 是位置 $i$ 加入缓存的轮次,后来加入的 $U_k\setminus U_j$ 不改变它.形式上,

$$
(K_i^{(\ell)},V_i^{(\ell)})
=F_\ell(x_i,x_{U_{j-1}},\sigma_{\leq j}),
\quad i\in S_j,
\tag{14}
$$

且 $F_\ell$ 的输入不含 $S_{j+1},S_{j+2},\ldots$.因果注意力从结构上保证这一点.双向注意力即使数值变化很小,也不满足精确相等;DualCache 利用的是变化小这一经验事实.

层归一化、MLP 和残差都逐 token 计算,不会破坏单调不变量.会破坏它的组件包括跨 token 归一化、读取未来位置的卷积、双向注意力以及根据整句统计动态调整旧 token 表示的模块.因此精确缓存并非只由注意力 mask 决定,整条网络的数据依赖都必须保持因果.

位置重新洗牌后,物理缓存下标与原位置分离.系统需要保存原位置 id 以计算 RoPE,还需保存生成轮次或缓存序号以构造因果可见性.这两列元数据很小,语义却不可混淆.如果按原位置排序缓存以便连续访问,重排过程不能改变旧隐藏状态;如果按追加顺序保存,输出还原时再 scatter 回原坐标.

### 4.2. 三条缓存路线的概率代价

DualCache 保留全双向条件,以旧 KV 近似新状态下的 KV.设真实更新后缓存为 $K_t$,复用值为 $\tilde K_t$,注意力 logits 误差近似受

$$
\|Q_tK_t^\top-Q_t\tilde K_t^\top\|
\leq \|Q_t\|\,\|K_t-\tilde K_t\|
\tag{15}
$$

控制.相邻步表示变化小时误差小,重掩范围大或状态突变时误差增大.该路线不改变训练概率族,推理转移是近似计算.

块扩散将序列分成有序块.已完成块满足因果前缀不变量,当前块内部使用双向条件.它的联合分解可写为

$$
p(x)=\prod_{b=1}^{B}p(x_{G_b}\mid x_{G_{<b}}),
\tag{16}
$$

块内 $p(x_{G_b}\mid x_{G_{<b}})$ 再由扩散近似.缓存只在块边界精确,块顺序固定会限制全序列任意填槽.增大块能改善块内双向表达,同时减少缓存比例并加重并行因子化误差.

Eso-LM 将每个新 token 或新集合追加到因果计算前缀,精确缓存覆盖整个生成过程.它保留原位置上的任意选择,代价是条件网络受加入次序影响.三条路线分别承担数值近似、块顺序限制和因果表示限制.它们不能仅按速度倍数排序,因为生成分布并不相同.

A 档位于块扩散和主方法之间:已见干净集合内部双向,对 MASK 的预测采用因果安排.它改善似然,却使旧干净表示随集合扩张而变化.若每隔若干轮整体重算干净集合,中间轮复用近似缓存,可形成混合方案.这种方案的误差和成本取决于重算间隔,已不属于论文报告的精确缓存主方法.

**4.3. 填空任务为何更难共享缓存**

无条件生成从空状态逐步增加 token,因果加入顺序自然形成一条历史.填空任务一开始就有左右两侧的固定上下文.若把所有已知 token 洗到因果前缀,它们内部仍按某个顺序编码,后加入的已知 token 能看见较早者,较早者看不见较后者.预测空槽时可以读取全部已知 token 的最终缓存项,但这些缓存项没有经过完整双向交互.

一个简单例子是模板 `A [槽] B`,其中槽答案取决于 $A$ 与 $B$ 的配对关系.若前缀顺序为 $A,B$,预测槽的 Query 能直接同时注意两者,理论上可以在当前层组合信息;较深组合若要求 $A$ 的表示先吸收 $B$,只有 $B$ 的表示具备这项信息.足够深、足够宽的预测 token 可以自己完成组合,有限模型可能从双向编码获益.

多槽填空还涉及槽之间的关系.因果调度先填某个槽后,其 token 进入缓存并可约束其他槽;先填错误会传播.双向扩散每轮重新编码所有已知与暂填 token,允许各槽互相修正.Eso-LM 的单调缓存若不允许重算旧 token,纠错只能通过新增表示或重新生成位置实现,不能更新旧上下文对其他位置的表达.

条件输入通常不需要生成,可以单独用双向编码器得到固定 memory,解码 token 通过交叉注意力读取它.这样左右上下文内部双向,生成侧保持因果可缓存.联合模型变成 encoder-decoder,参数与计算不再等同于原 Eso-LM.对长固定提示、多 token 输出的任务,一次编码成本可摊薄;对无条件生成,额外编码器没有对象可编码.

**4.4. GQA、RoPE 与缓存压缩的组合边界**

GQA 让多个 Query 头共享较少的 Key/Value 头.只要历史 KV 不依赖未来 token,共享头不会破坏精确缓存.设 Query 头数为 $H$,KV 头数为 $G$,头维为 $d_h$,缓存元素数从每层 $2LHd_h$ 降到 $2LGd_h$.Eso-LM 的任意原位置 RoPE 仍逐 KV 头应用,共享只发生在头维,不改变位置相位.

缓存量化同样与依赖结构正交.将历史 KV 量化成 $\hat K=K+\epsilon_K$、$\hat V=V+\epsilon_V$,缓存依旧无需重算,但注意力输出包含量化误差.精确在此仅指「旧浮点 KV 按网络定义不应变化」,量化后的数值当然是近似.报告系统时应把结构精确性与数值精度分开.

RoPE 长度外推会受到原位置跨度影响.缓存追加顺序可能很短,原位置差仍可达到上下文上限.位置缩放必须按最终序列坐标设置,不能按已生成 token 数缩放.例如先生成原位置 8192,后生成位置 1,两者追加距离为 1,RoPE 相位差却接近 8191.这正是模型保持原句空间关系所需的信息.

分页缓存或块化内存管理可以按追加顺序分配物理页,输出 scatter 表记录原位置.注意力核读取的是缓存页和位置 id,无需把 KV 按原序连续排列.工程细节只影响吞吐,概率条件仍由因果可见集合和原位置编码定义.若内核假设缓存第 $k$ 项的位置 id 必为 $k$,直接套用会破坏任意顺序语义.

## 5. 插值,混合损失及其与 MTP 的区别

### 5.1. 混合目标中的梯度来源

$\kappa=0.5$ 表示半个 batch 走扩散损失,半个走顺序损失.$\alpha_0=1$ 时他们关掉顺序项,并把扩散系数换成 $-1$ 以降低方差.消融 Table 4 扫过 $\kappa$.混合不是「两个模型蒸馏」,是同一套因果 Transformer 用两种注意力偏置.MTP / Medusa 一次猜未来几个 token,验证仍走左到右.Eso-LM 扩散期猜的是任意位置的 MASK,位置编码还是原下标.投机解码的草稿拒绝,这里没有对应物:提交策略仍是扩散自己的 $\mathcal{S}$.

附录还改进了少 NFE 下的启发式采样:优先揭开等间距且彼此远离的位置,而非集中处理相邻位置.并行度为 4、长度为 1024 时,首批位置是 0,255,511,767.近邻位置条件相关更强,同时揭开更容易放大因子化误差;远距离位置近似独立,少步时质量损失较小.这种规则与显式规划器的脏净预测头不同.Eso-LM 也可以均匀揭开 MASK,其主要速度收益来自 KV 复用与缩减前向集合,而非学习揭开顺序.

和 XLNet 的差别再写一遍.XLNet 每步仍对一个位置做因果预测,排列随机,没有并行揭开.Eso-LM 扩散期一步可以动多个不相邻 MASK,顺序期才退化成一次一个.共享的是「顺序不必从左到右」和「计算图可以因果」.不共享的是掩码扩散那套 $t$ 和并行提交.把 Eso-LM 写成「XLNet 换了个名字」,会丢掉 NFE 可以小于 $L$ 这件事,而这件事才是扩散还留在题目里的理由.

AdaLN 在这批实验里是参数公平问题.DiT 默认有时间条件,MDLM 把时间固定成 $t=0$,因为吸收态要学的是干净条件.AdaLN 仍占参数.作者给 AR 基线也训了带 AdaLN 的版本,LM1B 从 22.83 到 21.86.Eso-LM 的 $\alpha_0=0$ 对齐的是带 AdaLN 的 AR,不是更瘦的那只.抄 PPL 时连这一行一起抄.

把顺序损失记为 $\mathcal L_{\mathrm{AR}}$,任意顺序扩散损失记为 $\mathcal L_{\mathrm{AO}}$,混合训练可概括为

$$
\mathcal L(\theta)=
(1-\kappa)\mathcal L_{\mathrm{AR}}(\theta)
+\kappa\mathcal L_{\mathrm{AO}}(\theta).
\tag{17}
$$

同一参数收到两类梯度 $g_{\mathrm{AR}}$ 和 $g_{\mathrm{AO}}$.若内积 $g_{\mathrm{AR}}^\top g_{\mathrm{AO}}>0$,更新方向互相促进;若小于零,共享表示出现冲突.冲突可能集中在早期层的注意力结构,也可能集中在输出头对不同可见集合的校准.只看总损失无法定位.

$\kappa$ 控制样本频率时,两项损失的数值尺度仍可能不同.扩散损失含时间权重和不同数量的掩码位置,顺序损失每个 token 恰好预测一次.要让式 (17) 的系数具有可解释性,需按 token 数或有效预测数规范化.否则相同 $\kappa$ 在不同日程下产生不同实际梯度占比.

训练早期可以让顺序项占比较高,先学习稳定局部语法;随后增加任意顺序样本,扩展条件覆盖.固定混合避免日程超参,可能让模型在尚未掌握基础分布时面对过多高噪声条件.公开消融支持的是论文所测固定或指定设置,更复杂课程学习的收益需要单独验证.

**5.2. 与 MTP、投机解码和掩码预测的概率差异**

多 token 预测(MTP)通常在同一前缀上预测未来多个偏移,辅助头的输出不一定直接构成联合生成路径.主 AR 头仍定义部署概率,附加头提供训练信号或投机候选.Eso-LM 的任意位置预测直接参与生成,其条件集合可以包含右侧原位置 token,生成顺序也不受原坐标单调限制.

若 MTP 一次预测 $x_{t+1},\ldots,x_{t+b}$ 并假设条件独立,其批内误差与扩散并行提交相似;投机验证随后用主模型逐 token 接受或拒绝,恢复目标 AR 分布.Eso-LM 没有独立主模型做这层验证,并行提交本身就是目标生成器的近似路径.加入 AR 验证器会改变系统为投机解码,接受率与额外前向需重新计算.

BERT 式掩码预测训练随机可见集合,通常没有归一化的生成似然或明确采样链.Eso-LM 将任意顺序条件组织进链式分解与混合似然,并约束计算图因果化.两者都预测 MASK,差别落在条件族是否组成生成概率、训练权重是否对应序列目标以及推理路径是否被定义.

Permutation LM 如 XLNet 对排列求期望,每个目标位置仍按排列顺序条件预测.它使用双流注意力避免目标 token 泄漏,重点是上下文建模和似然训练.Eso-LM 将相同任意顺序思想与掩码扩散的多位置提交、时间日程和有限 NFE 相连.两者共享数学祖先,采样动作与速度目标不同.

**5.3. 顺序偏差从训练分布进入模型**

均匀排列并不意味着每种可见集合等概率.长度为 $L$ 时,若先随机排列再随机选择切点 $k$,大小为 $k$ 的每个集合概率相同,不同 $k$ 的权重由切点分布决定.扩散时间日程会偏向某些掩码率,使模型更频繁训练在接近全掩码或接近全干净的状态.顺序偏差因此包含集合大小偏差和集合内容偏差两部分.

若调度训练总把高置信或特定位置放前面,模型会把这种顺序当作条件分布的一部分.测试换成不同策略时,新可见集合可能仍在训练支持内,加入次序却不同.因果隐藏状态携带历史次序,所以「集合相同」不足以保证状态分布相同.随机排列训练扩大次序覆盖,代价是模型容量分散.

原位置也可能产生偏差.自然语言训练中句首 token 对全句影响大,左到右 AR 对早期位置使用较少上下文.任意顺序目标让句首也能在右侧上下文已知时预测,减轻这一不对称;若推理调度仍频繁先生成句首,训练新增条件未被充分利用.反过来,总是先生成标点或句尾会形成另一种位置偏好.

内容自适应顺序会产生选择偏差.模型置信度决定哪些 token 进入上下文,高置信预测更常被保留,低置信位置只在丰富上下文下训练或生成.这类似自选择数据:观察到的后期条件不是随机子集.若训练掩码独立而推理按置信度选择,条件分布发生偏移.在训练中模拟采样轨迹可以减小偏移,但模型更新后轨迹分布也会变化.

顺序公平性在某些任务上还涉及实体和语言频率.高频表达更易先生成,后续内容会围绕它们条件化;低频专名晚生成,若早期上下文已经限制语义空间,正确候选可能被压低.按位置准确率、token 频率和实体类型分桶,可以发现平均 PPL 看不出的顺序偏差.

**5.4. 从局部填槽到全局计划**

Eso-LM 的调度 $\mathcal S$ 选择位置集合,没有显式生成句子级语义计划.如果先确定标题、关键实体、代码函数签名或证明骨架,这些锚点可作为早期填槽,后续 token 条件于它们生成.因此位置调度能够承载一部分计划作用,但计划内容仍由填槽器从词表采样.

令潜计划 $h$ 决定锚点集合 $A(h)$ 与顺序分布 $p(\sigma\mid h)$.层级联合可写为

$$
p(x)=\sum_h p(h)
\sum_\sigma p(\sigma\mid h)
\prod_k p_\theta(x_{\sigma_k}\mid x_{\sigma_{<k}},h).
\tag{18}
$$

如果 $h$ 只定义位置、不定义内容,它就是调度计划;若还包含语义变量,去噪器需要条件于 $h$.显式计划增加可控性,同时引入计划错误.锚点内容填错时,因果缓存会把错误长期保留,除非采样器支持回改或重启相关分支.

计划器与填槽器联合训练可能出现捷径:计划器选择填槽器容易预测的位置,却不一定选择对全局最有帮助的位置.序列级目标能够奖励最终质量,信用分配要跨越多轮填槽.用强化学习或可微近似训练位置策略时,动作空间随剩余位置变化,梯度方差较高.启发式等间距和置信度策略虽不最优,可复现性更强.

一个折中是先由独立模块提出少量锚点候选,再用 Eso-LM 条件概率为候选打分.候选位置和内容共同形成早期缓存,后续按同一因果机制生成.若多个锚点彼此冲突,需要联合评分或验证器;逐点高概率不保证组合一致.该方案属于在 Eso-LM 上增加搜索,不能从原论文实验直接推断效果.

**5.5. 条件兼容正则能做什么**

式 (7) 提供一种局部一致性正则.训练时采样已见集合 $S$ 和两个未见位置 $i,j$,分别沿 $i\to j$ 与 $j\to i$ 计算目标 token 的对数概率,加入

$$
\mathcal L_{\mathrm{cycle}}
=\mathbb E_{S,i,j}[\Delta_{i,j}(S)^2].
\tag{28}
$$

它鼓励相邻位置交换不改变完整两步概率.若所有相邻交换都一致,任意两个排列可由一串相邻交换连接,路径概率会更接近.计算每个样本的两条路径增加前向或需要复用中间表示,训练成本明显上升.

循环正则也可能与有限容量下的主任务冲突.模型在常见顺序上已有较好预测,为了匹配罕见逆序条件而改变参数,平均 PPL未必下降.可以按测试调度访问概率给 $\Delta$ 加权,重点约束部署常见闭环.这样得到的是策略相关兼容性,不再追求所有排列完全一致.

另一种正则针对同一可见集合的加入次序.采样两个排列前缀 $\sigma_{1:k}$、$\rho_{1:k}$,使它们包含相同位置集合,最小化下一 token 分布的 KL:

$$
\mathcal L_{\mathrm{set}}
=D_{\mathrm{KL}}\!\left(
p_\theta(\cdot\mid x_{\sigma_{1:k}})
\Vert
p_\theta(\cdot\mid x_{\rho_{1:k}})
\right).
\tag{29}
$$

该目标减少缓存顺序痕迹,使模型更接近集合条件.两个前缀的因果隐藏状态必须分别计算,开销接近翻倍.若加入次序本来携带计划信息,完全抹平也可能损失有用信号.

全局归一化能从结构上保证兼容,例如定义能量 $E_\theta(x)$ 并由同一联合导出所有条件.对大词表长序列,归一化常数和任意条件概率都难以计算.自回归因果分解选择一条固定顺序,以可计算性换取顺序不对称;Eso-LM 用共享网络覆盖多条顺序,兼容性主要依靠数据与参数共享.

判断正则是否有效不能只看 $\mathcal L_{\mathrm{cycle}}$ 自身.应同时检查精确或重要性似然、不同调度间性能方差以及固定 NFE 生成质量.循环误差降低但 PPL 上升,说明模型为一致性牺牲拟合;PPL不变且调度方差下降,才表明顺序鲁棒性真正改善.

### 5.6. 约束填槽与任意顺序

词法硬约束可在每个位置的 logits 上屏蔽非法 token.令 $A_i(x_U)$ 是当前允许集合,约束分布为

$$
\bar p_\theta(v\mid x_U,i)
=\frac{p_\theta(v\mid x_U,i)\mathbb 1[v\in A_i(x_U)]}
{\sum_{u\in A_i(x_U)}p_\theta(u\mid x_U,i)}.
\tag{30}
$$

如果约束只依赖已见 token,任意顺序下可直接计算.若约束依赖未见位置,过早生成可能缺少判断条件.调度器可以把决定约束的锚点提前,也可以保留多个候选直到相关位置出现.

成对约束如括号匹配、变量定义与使用,不能由独立 $A_i$ 完整表达.同时生成一对 token 可以用联合候选列表,组合数随词表增长.先生成定义再生成使用把联合转为条件,顺序本身承担约束传播.这说明适当顺序能够降低约束搜索复杂度.

全局约束如代码测试或数学答案只在完整序列上判定.可以生成多条排列与 token 路径,最终由验证器筛选;也可以在中间状态使用价值估计.前者消耗样本数,后者引入价值误差.Eso-LM 的精确 KV 能降低单条路径成本,分支越多,不同缓存前缀的共享越少.

约束还会改变模型原始分布.硬过滤后采样来自重归一化分布,如果允许集合错误地排除真值,概率无法恢复.软能量重加权保留所有候选,约束强度过小则无效.比较顺序策略时应固定约束器,防止验证收益被误记为任意顺序能力.

**5.7. 顺序策略的学习目标**

若把顺序策略参数化为 $\pi_\phi(S_k\mid x_{U_{k-1}},b_k)$,其中 $b_k$ 是剩余预算,最终奖励 $R(x)$ 可用于策略梯度:

$$
\nabla_\phi J
=\mathbb E\left[
(R(x)-c\,\mathrm{NFE}-b)
\sum_k\nabla_\phi\log\pi_\phi(S_k\mid x_{U_{k-1}},b_k)
\right].
\tag{31}
$$

$b$ 是降低方差的基线,$c$ 是计算价格.动作包含组合集合,直接采样方差很大.逐位置 Bernoulli 可以简化动作,难以精确控制每轮大小;先选大小再选位置可把动作分层.

监督式策略可从高预算搜索或启发式轨迹蒸馏.若教师用多轮验证找到较好顺序,学生学习每个状态的下一个集合.教师只探索少量路径,标签未必全局最优;学生至少能以一次前向近似昂贵搜索.训练状态要包含教师和学生自身轨迹,避免部署时偏移.

还可以预测每个位置的边际价值 $u_i$,用 top-$k$ 形成集合.这把组合策略降为排序,忽略交互.增加成对分数 $w_{ij}$ 后可表示同批协同与冲突,选择变成二次组合优化.限制 $w$ 为低秩或局部图,可以在表达与求解成本之间折中.

学习策略的证据必须与固定启发式对照.若新增策略网络与去噪器同规模,质量提升可能来自额外计算.同 FLOPs 下可让启发式基线增加采样步数或候选数.策略还应跨随机种子和任务报告,单个数据集上学到位置频率不等于掌握生成依赖.

## 6. 失效

### 6.1. 因果参数化的表达反例

因果干净位会伤害需要「已写字互相看」的条件.括号若两边都已是明文,主方法里后写的那个在计算图上可能看不见先写的那个,取决于洗牌次序.A 档或全双向没有这个问题.长文档里指代,表格对齐,双向仍更顺.Eso-LM 的帕累托赢在无条件生成的速度-质量曲线,赢不了「任意 infill 必须看见两边」.

65× 依赖 $L=8192$ 和无缓存基线.聊天平均 32 个 token 的回复,倍数接近 1.A6000 延迟卡和 H200 吞吐卡不是同一块硅.禁 nucleus 的最坏设定让基线更慢.产品对照应当用自己的长度和采样器重测.

NELBO 增加约 4 PPL,代价换来更低的有限时间生成延迟.精确似然和模型选择更适合参考 MDLM / A 档,长序列采样延迟则对应主方法.两个指标回答的问题不同,不能用其中一张表替另一条路线下结论.

论文没有提供 8B Instruct、HumanEval 主表或与 Fast-dLLM 的同卡对照.对现有 7B–8B 开放权重模型,可直接复用权重的方案仍是 DualCache 与 dKV-Cache.Eso-LM 证明的是一种架构可能性:精确 KV 可以与全序列并行生成同时存在.这一结论来自 2025 年 6 月的 DiT 实验,不能视为同年 2 月 LLaDA 8B 检查点已经具备的规格.

训练成本:OWT 250k 步,$\alpha_0=1$ 约 27 小时,$\alpha_0<1$ 约 37 小时,8×H200.预训相关合计约 9k H200 小时.这是小模型把注意力偏置扫清楚的计算代价,不是 13 万 H800 小时那一档.

BD3-LM 把并行范围限制在块内:块太小会接近 AR,块太大又会在低 NFE 时同时揭开过多位置.实验中,低采样步数使样本质量和多样性同时下降,结果甚至低于高 NFE 的 AR 与低 NFE 的其他扩散模型.Eso-LM 不使用固定块切分任意顺序,低 NFE 时更接近普通 MDM:质量会下降,但没有出现同等程度的多样性坍缩.因此帕累托图把 BD3-LM 作为主要相邻方案.块长 $B$ 在常规设置下控制质量与速度,到少步极限时会放大一次并行提交的误差.Eso-LM 用因果注意力换取 KV Cache,少步时退回 MDM 式行为,而非失效的半自回归采样.

零样本似然 Table 5:七个未见集里四个仍保持 AR < Eso-LM($\alpha_0=0.125$) < MDLM 的次序,和 OWT 验证集一致.插值关系延伸到了部分未见分布.该表的指标是困惑度,没有覆盖 GSM8K,也不能支持指令模型已经完成同类插值的结论.

构造一个需要对称汇总的简单任务.序列前三位 $A,B,C$ 已知,第四位等于三者多数值.若加入顺序为 $A,B,C$,最终 Query 可以读取全部原始 token,足够直接计算多数.若任务要求很多后续位置重复使用「$A,B,C$ 的多数」这一中间表示,双向编码可让每个已知 token 共同更新,因果表示只能在较晚 token 或每个后续 Query 中重新汇总.表达并非不可能,参数和深度利用效率可能不同.

再看关系依赖.已知 token 构成一个无向图,目标取决于多轮消息传递后的连通性.双向 Transformer 的每一层允许所有已知节点同步交换信息;因果洗牌只允许消息沿排列方向传播.若图边方向与排列相反,信息必须由后加入节点汇总后再传给目标,无法回到较早节点.足够晚的目标仍可读取汇总节点,但中间表示的复用受限.

这类反例说明 PPL 缺口可能来自信息流方向,不能简单归因于训练没调好.同时,自然语言是否经常需要这种对称多轮计算要靠实验判断.因果 AR 已经证明单向模型可以很好地建模语言;Eso-LM 的困难在于原位置与加入次序脱钩,同一语义关系会遇到多种方向安排.

排列随机化可让每对 token 在训练中都有机会沿两个方向出现,共享参数因而学习双向关系的统计对称性.单条推理轨迹仍只有一个方向.对路径敏感的结构任务,可以采样多条排列后集成,或选择与依赖图相符的顺序;前者增加计算,后者要求规划器识别依赖.

**6.2. 并行因子化的反例**

设两个未填位置 $(X_1,X_2)$ 只允许 `00` 与 `11`,概率各为一半.给定当前上下文,单位置边缘都是 Bernoulli$(0.5)$.若一次并行独立采样两位,四种组合概率均为 $0.25$,非法的 `01`、`10` 合计占一半.若先生成一位,第二位条件于第一位,合法率为 1.这个反例与注意力是否因果无关,来自同批 token 联合被边缘乘积替代.

增加置信度不能解决该例,因为两位边缘都同样不确定.等间距策略也没有帮助,两个位置的依赖是语义的,不由物理距离决定.需要减小批量、为批内建立联合分布,或在生成后验证并重采样.因此低 NFE 极限会遇到概率结构上不可消除的质量损失.

也存在并行完全无害的分布.若未填位置在给定上下文后条件独立,

$$
p(x_R\mid x_U)=\prod_{i\in R}p(x_i\mid x_U),
\tag{19}
$$

一次生成全部位置就是精确采样,串行只增加计算.实际语言位于两者之间,依赖强度随位置和内容变化.调度器的任务可以理解为寻找近似条件独立的集合,而非机械保持固定间距.

用条件互信息可刻画两位置的剩余依赖:

$$
I(X_i;X_j\mid X_U)
=\mathbb E\log\frac{p(X_i,X_j\mid X_U)}
{p(X_i\mid X_U)p(X_j\mid X_U)}.
\tag{20}
$$

互信息大时同时独立采样风险高.精确估计需要联合概率,普通填槽器只给边缘.注意力权重、隐藏相似度或成对预测头可以作代理,都需与真实并行错误相关性验证.

**6.3. 顺序搜索的反例与偏置**

贪心高置信顺序可能陷入自洽错误.设位置 $A$ 有错误候选概率 $0.55$、正确候选 $0.45$,位置 $B$ 在 $A$ 正确后可确定真值,在 $A$ 错误后也会高置信生成配套错误.若先提交 $A$,系统以 $0.55$ 进入错误但自洽的路径,随后所有置信度都很高.若先生成提供外部约束的 $B$,反过来可使 $A$ 的正确概率升高.局部容易程度未必对应全局风险最小.

随机顺序保留探索机会,方差更大.束搜索保留两条 $A$ 候选可避免早期承诺,成本随分支增长.验证器能在完整序列后识别错误时,可以回溯计划;单调 KV 前缀无法直接删除一条路径中的中间缓存并保留受其影响的后续项,通常需要从分叉点重放.

等间距策略也有结构反例.代码中同一变量的定义和使用可能距离很远,同时生成会丢掉绑定条件;相邻标点反而可能独立.物理距离只在局部相关占主导的数据上有效.长上下文的主题、实体和格式依赖跨越很远,固定间距的代理会变弱.

左到右顺序具有明确偏置:早期 token 上下文少,后期 token 上下文多.任意顺序把这种不对称平均到所有位置,却增加路径方差.如果任务的真实交互也是左到右,例如流式外部环境只按时间提供观察,任意顺序无法使用未来信息,随机排列训练中的某些条件不会在部署出现.模型容量投入这些条件可能没有收益.

### 6.4. 训练与推理的顺序分布偏移

训练令 $q_{\mathrm{train}}(\sigma)$ 接近均匀,推理策略诱导 $q_{\mathrm{test}}(\sigma\mid x)$.目标风险为

$$
\mathcal R_{\mathrm{test}}
=\mathbb E_{x,\sigma\sim q_{\mathrm{test}}}
[\ell_\theta(x,\sigma)].
\tag{21}
$$

训练优化的是 $q_{\mathrm{train}}$ 下的期望.如果测试分布的支持集包含训练几乎未见的次序,风险没有直接保证.重要性权重 $q_{\mathrm{test}}/q_{\mathrm{train}}$ 理论上可校正,内容自适应策略使 $q_{\mathrm{test}}$ 依赖模型预测,权重难以稳定估计.

在训练中展开当前模型的采样策略可以对齐状态.模型每次更新后置信度和顺序都会改变,数据分布也随之移动.交替收集轨迹与更新参数类似 on-policy 学习,成本远高于静态随机掩码.混合一部分随机顺序能保持覆盖,一部分策略轨迹用于缩小部署偏移.

偏移还发生在动作大小.训练若每个目标 token 逐个计算条件,推理一轮提交多个 token,批内 token 没有看到彼此的新值.训练可随机采样批量集合,让模型见到同样的条件缺失;输出头仍以边缘交叉熵训练,不会获得联合监督.加入成对或块级损失才能直接约束组合.

顺序期与扩散期的切换也产生边界状态.训练若按固定比例混合两个独立 batch,模型未必见过从任意顺序缓存切换到原序左到右的连续轨迹.论文的注意力偏置和排列构造用于保持两类计算兼容.更换切换规则时,应检查第一步顺序预测的上下文排列是否落在训练分布内.

**6.5. 长度、位置与停止的边界**

任意顺序模型通常预先知道输出长度 $L$,调度只对固定槽位排列.未知长度可由长度预测器、EOS 或最大长度截断处理.长度预测错误时,顺序再好也无法新增缺失槽位或删除多余槽位.EOS 在任意位置提前生成时,还需定义其后原位置是否全部失效.

若将 EOS 当普通 token 并高置信优先提交,模型可能过早确定结束边界.后续填入 EOS 右侧的 token 会与序列语义冲突.一种策略是把 EOS 延迟到顺序期,另一种是让长度变量先于 token 计划确定.二者减少任意顺序自由度,换取长度一致性.

超长序列中的原位置编码必须覆盖完整 $L$,即使早期前向只含少量 token.训练主要在短序列上随机洗牌,测试扩展到更长原坐标时,RoPE 外推与顺序泛化同时发生.速度曲线可以在 8192 长度测得,质量是否同样保持需独立长文本指标支持.

停止条件如果只是未填槽为空,固定长度下没有歧义.允许重掩或回改后,所有槽位都有明文不代表生成完成,还需规划器或验证器判定.原 Eso-LM 的单调提交避免了这项复杂性,也意味着早期错误不会被原机制撤销.将回改加入系统会破坏缓存前缀的单调增长,除非从被改位置之后重算或采用版本化缓存.

**6.6. 证据边界与可复算评测**

Eso-LM 的实验证据分为似然、生成质量和系统速度三组.似然表使用 LM1B、OWT 与给定重要性样本数;生成帕累托比较生成 PPL、MAUVE 和 NFE;延迟表使用特定 GPU、长度和关闭 nucleus 的设置.三组结果共同说明方法在所测规模上的折中,任何一组都不能代替另外两组.

验证联合概率语义时,可在短序列上枚举全部排列.对每个 $x$ 计算式 (2) 的路径概率,再按式 (3) 求和,与重要性估计比较.同时计算式 (7) 的相邻交换误差,观察路径不一致是否随训练下降.枚举长度很短,不反映大模型质量,却能检查实现是否真正使用原位置编码和正确条件.

验证顺序策略时,固定同一权重和 NFE,比较左到右、均匀随机、等间距、置信度和学习策略.每条策略报告最终指标、轨迹方差、批内错误相关性与墙钟.若策略使用额外模型,其前向也计入总成本.这样可以区分架构缓存收益与调度质量收益.

验证缓存精确性时,对同一轨迹分别运行全量重算和增量缓存,逐层比较已提交 token 的 KV 与最终 logits.浮点容差内一致才能称精确.若使用 FlashAttention、量化或不同归约顺序,数值差异需要单独给定容差;概率结构精确不保证位级相同.

验证并行误差时,按批量大小 $b$ 扫描从 1 到较大值,保持总位置数和采样温度一致.记录条件互信息代理高的 token 对是否更易同时出错.若等间距策略仅在局部数据有效,长距离关系任务会显示不同曲线.少数平均指标不足以判断调度是否学到了结构.

模型规模外推需要同结构训练.小 DiT 上的 PPL 缺口可能随容量缩小,也可能因长上下文依赖加剧而扩大.现有 LLaDA 8B 权重采用双向注意力,不能通过替换推理 mask 得到受训的 Eso-LM.因此架构可行性与现成模型可部署性是两项独立结论.

论文数字还不能证明指令跟随、数学推理或代码正确率上的优势.这些任务要求长程语义一致、可执行验证与后训练.因果洗牌能否保持后训练能力,需要在相同预训练 token、相同 SFT/RL 数据和同计算推理下比较.没有这类对照时,结论应停在语言建模与无条件生成范围.

**6.7. 如何把速度收益拆开**

Eso-LM 的延迟下降来自至少四项变化:历史 KV 不重算、早期前向的有效长度缩短、调度减少总 NFE、因果注意力可使用成熟 kernel.要判断每项贡献,可以建立逐级基线.第一条基线是全长双向 MDLM;第二条保留全长输入但使用因果洗牌,观察注意力结构变化;第三条加入 KV;第四条再裁掉当前轮不需要的 MASK 输入.每一级只改变一个因素.

设第 $k$ 轮累计已见长度为 $n_k=|U_k|$,新查询数为 $m_k=|S_k|$.无缓存全长注意力的粗略复杂度为

$$
C_{\mathrm{full}}\propto K L^2d.
\tag{32}
$$

增量因果注意力只为新查询读取历史 KV,粗略为

$$
C_{\mathrm{cache}}\propto
\sum_{k=1}^{K}m_k n_k d
+\sum_{k=1}^{K}m_k d^2,
\tag{33}
$$

第一项是注意力,第二项代表新 token 的投影与 MLP.旧 token 的 $d^2$ 子层不再重算.当早期 $n_k\ll L$ 且每个 token 只新增一次时,节省会随 $L$ 增大.

式 (33) 也解释了为什么相对 AR 未必更快.AR 每步 $m_k=1,n_k=k$,同样精确缓存;Eso-LM 通过 $m_k>1$ 减少轮数和串行启动,总注意力配对数量仍取决于调度.若每个新 Query 都读取全部历史,所有 token 对最终大致计算一次,与因果 AR 同阶.优势主要来自并行硬件利用和较少串行步骤,并行填槽误差是交换条件.

延迟测试还需区分 prefill 与 decode.Eso-LM 无条件生成没有传统长提示 prefill,已有条件 token 可以形成一次前缀编码.扩散阶段每轮加入一批 token,形态介于 AR decode 和分块 prefill.不同 GPU 对小批 Query 的利用率不同,理论 FLOPs 相同也会得到不同墙钟.

内存测量至少包含 KV、临时激活、logits 和调度元数据.词表 logits 对大批位置可能占显著空间;只保留候选位置或 top-$k$ 可以减少临时内存,会改变采样实现.峰值显存决定可用 batch,吞吐比较若使用不同 batch 需要同时报告单样本延迟.

CUDA graph、动态形状和 scatter/gather 会影响长序列收益.调度使 $m_k,n_k$ 随轮次变化,固定 shape 图可能填充到上限,抵消有效长度缩减.按若干尺寸分桶能减少填充,增加图管理.这些因素解释实测速率,不会改变式 (2) 的联合概率语义.

为了复算倍率,应给出绝对毫秒、序列长度、batch、NFE、数据类型、注意力实现和 GPU.单独报告 65× 无法迁移到另一套 serving 栈.同一机器上比较无缓存基线很有价值,它证明结构性节省;产品选择还要加入经过优化的 AR、块扩散和近似缓存基线.

### 6.8. 顺序稳健性的评测矩阵

第一条轴是排列类型:左到右、右到左、均匀随机、等间距、置信度和学习策略.第二条轴是动作大小:1、固定小批、随时间增长、随置信度自适应.第三条轴是任务结构:局部语言、远距离一致、代码绑定、数学约束和任意填空.矩阵不必穷举所有组合,至少覆盖训练常见与部署目标策略.

对每个组合应报告四组结果.概率组包含 NELBO、重要性似然和路径交换误差;生成组包含 PPL、MAUVE或任务正确率;轨迹组包含轮数、批内错误率和不同排列方差;系统组包含延迟、吞吐与峰值显存.概率好但有限步生成差,说明调度或并行近似有问题;生成好但似然差,可能是搜索弥补了模型分布.

顺序敏感度可以定义为固定样本在多条排列上的损失方差:

$$
V_{\mathrm{order}}(x)=
\operatorname{Var}_{\sigma\sim q}
[-\log p_\theta(x\mid\sigma)].
\tag{34}
$$

平均方差低表示不同路径较一致,不代表平均似然一定好.同时报告均值与方差,才能区分「所有顺序都差」和「大多数好、少数极差」.部署策略若避开极差排列,后者仍可取得好结果.

批内一致性可用联合约束成功率评估.构造具有明确组合规则的短任务,例如复制、配对、括号和变量引用,比较串行与不同批量.这些受控任务能定位因子化误差,自然语言基准则检验结果是否转化到真实分布.只做受控任务容易高估结构问题在自然文本中的频率,只做 PPL又难定位原因.

缓存正确性需要逐层单元测试.随机生成一条排列与 token 轨迹,一份实现每轮全量重算,另一份增量追加 KV;比较新 token logits 与历史 KV.再随机改变物理缓存排列,保持原位置 id 不变,输出应在容差内一致.若改变原位置 id 后输出仍不变,说明位置编码没有正确接入.

路径概率测试可以使用极小词表和短长度枚举.把所有排列概率求和,检查序列概率是否归一;对同一已见集合采用不同加入次序,测量式 (8) 的差异;对相邻交换计算式 (7).这些测试不会保证大模型训练成功,能够排除概率实现层面的错误.

训练分布偏移可通过轨迹来源分组.一组状态由随机掩码产生,一组由当前置信度策略滚动产生,一组由其他调度产生.分别计算 token 损失和顺序方差.策略轨迹显著更差时,说明任意顺序训练的覆盖仍不足;其他调度更差但部署策略稳定,结论应限定于目标调度.

同计算预算的帕累托曲线可作为汇总.横轴可以是绝对延迟或总 FLOPs,纵轴是任务质量,每个点同时标注 NFE 与动作大小.改变调度、$\alpha_0$、$\kappa$ 和批量都会移动曲线.只比较单个工作点容易把超参选择当作架构优势,完整曲线才能显示某方法在哪个预算区间有效.

**6.9. 内容上能确认到哪里**

联合概率方面,任意顺序链式分解、排列混合和重要性估计都有明确数学语义.因果洗牌通过原位置编码保留句子坐标,通过追加次序提供条件历史,精确 KV 来自网络依赖的单调性.这些结论不依赖某个特定速度数字.

训练结果方面,论文表格支持 A 档与 MDLM 的 PPL 接近、主方法以约 4 PPL 缺口换缓存、$\alpha_0$ 在 AR 与任意顺序之间形成工作点.它还支持特定长度与硬件下相对无缓存 MDLM、BD3-LM 的延迟改善.这些数字的模型规模、数据、NFE和设备口径必须一起保留.

机制推论方面,条件不兼容、批内因子化误差、顺序偏差和搜索分支是由概率分解能够推出的风险.它们解释为何不同调度可能产生差异,不等于论文已经逐项做过相应消融.将数学反例与实证结果并列时,前者说明可能性和边界,后者说明所测设置中实际发生了什么.

尚无证据把 65× 外推为 8B 指令模型相对成熟 AR serving 的通用倍率,也无同协议结果证明 Eso-LM 在 GSM8K、HumanEval或长文本指令跟随上优于双向扩散.因果任意顺序是一条值得继续扩大的架构路线,当前材料最扎实的结论仍是小规模语言建模中的质量—缓存折中.

### 6.10. 关键实验规格

- 任意顺序损失 ≠ 双向注意力.洗牌 + 原位置 RoPE + 因果,扩散阶段可以精确 KV.
- 主方法 $\alpha_0=1$:LM1B NELBO 36.12 对 MDLM 31.78(约 +4);A 档 30.96,贴近 MDLM,扩散阶段无精确 KV.
- $\alpha_0=0$ 收回 AR 似然.中间值插值.
- 相对无缓存 MDLM:L=2048 约 14×,L=8192 约 65×(A6000,$T\gg L$).相对 BD3-LM 约 3–4×.对照物不是 AR.
- 尺度:LM1B / OWT,DiT.不是 LLaDA 8B.

块扩散使用块内双向注意力,换取块间精确缓存;Eso-LM 使用全序列因果洗牌,换取扩散阶段的精确缓存.Fast-dLLM 的近似缓存可以直接用于现成权重,Eso-LM 的精确缓存则需要按相应注意力结构训练.任意顺序目标对排列求期望,计算图仍然可以保持下三角.

标题中的 hybrid 指损失与采样阶段的混合:同一套因果权重既能在扩散期并行揭开 MASK,也能在顺序期从左到右生成.网络层之间不会切换因果与双向注意力,变化的是注意力偏置 $A$ 和调度 $\mathcal{S}$.训练采用双向注意力、推理临时改成因果注意力时,缓存依赖与训练计算图不一致,会造成质量下降.实现精确 KV 需要同时满足两个条件:干净前缀的 Key 不依赖任何 MASK,RoPE 使用原序列下标.

**6.11. 最终应怎样理解 Eso-LM**

Eso-LM 把两个经常捆在一起的选择拆开:生成顺序可以任意,网络依赖仍可保持因果.任意顺序由原位置集合和排列 $\sigma$ 决定,因果性作用于加入缓存的计算次序.原位置编码让模型知道 token 最终属于哪里,下三角注意力让旧 KV 不受后来 token 影响.两个坐标系共同存在,少一个都无法复现主方法.

联合概率由排列条件链和排列混合构成.固定排列上的乘积可以准确计算,对所有排列边缘化仍需重要性采样或其他估计.随机排列训练降低特定顺序依赖,有限模型的条件未必完全兼容.相邻交换误差和同集合异序 KL 能直接测量这种不一致,它们比一句「支持任意顺序」提供更多信息.

并行性来自把多个位置放进同一轮,缓存来自历史表示单调不变.两项收益彼此独立:完全串行的任意顺序也能缓存,全双向模型也能并行却无法精确缓存.批量越大,NFE 越少,批内联合被边缘乘积近似得越粗.调度应寻找条件依赖较弱或能为后续提供高价值上下文的位置集合.

顺序策略可以固定、随机、置信度驱动或学习.固定等间距减少局部相关,置信度策略优先提交可靠 token,学习策略可纳入信息价值和预算.任何策略都可能形成偏差:高频 token 过早、关键低频实体过晚,或局部高置信路径进入全局自洽错误.同一权重、同 NFE、同动作大小的对照才能判断策略贡献.

计划与填槽的接口是 $S_k$ 和 $p_\theta(x_{S_k}\mid x_U)$.计划决定哪些槽位获得当前计算预算,填槽决定写入内容.显式高层计划还能指定锚点、结构或约束,它超出 Eso-LM 原始启发式调度.将外部规划器接入时,额外前向、计划错误和缓存分支都应计入代价.

精确 KV 的「精确」只描述网络定义下旧状态无需更新.它不涵盖低精度量化、近似 attention kernel 或并行 token 因子化.量化会产生数值误差,批量填槽会产生概率近似,二者与缓存依赖是不同层的问题.把它们分开后,系统结果才容易复现.

主方法的质量代价也有明确来源.干净 token 无法在后来 token 加入后重写隐藏表示,同一可见集合的表示可能受加入次序影响.随机训练和深层 Query 可以弥补一部分,无法从结构上恢复全双向同步消息传递.A 档改善集合条件表达,同时失去扩散阶段精确缓存,正好展示了这项交换.

$\alpha_0$ 与 $\kappa$ 让同一权重在顺序条件和任意顺序条件之间分配容量.靠近 AR 的工作点通常具有更好的似然与较少并行空间,靠近纯扩散的工作点增加并行路径并扩大条件覆盖.最佳值属于具体模型、数据和延迟预算,不能脱离实验协议单独推荐.

对长序列而言,相对无缓存双向扩散的结构优势会扩大,因为旧 token 不再重复运行投影、MLP 和注意力.相对成熟 AR,两者都使用因果 KV,Eso-LM 的机会来自批量 Query 和减少串行轮数,代价是并行一致性.因此 65× 说明无缓存 MDM 的长序列代价,不能解释成对所有语言模型都获得同倍率.

现有证据足以说明因果注意力并未取消任意顺序生成,并给出小模型上可观的速度—质量工作点.它还不足以确定大规模指令模型会选择同样折中.下一步真正有信息量的实验是同规模、同预训练数据、同后训练和同硬件下,把双向 MDM、块扩散、近似缓存与因果任意顺序画在一张帕累托曲线上.

阅读任何新的任意顺序系统时,可以沿四个问题定位它与 Eso-LM 的关系.第一,联合概率是对排列混合、固定顺序分解,还是仅提供未归一化的掩码条件.第二,同轮多个位置是否拥有联合模型,抑或采用边缘乘积.第三,旧 token 的隐藏状态在新 token 加入后会不会改变,这决定缓存属于精确复用还是数值近似.第四,位置策略由固定日程、置信度还是独立规划器产生,额外计算是否进入速度口径.

这四项也决定错误从哪里来.排列条件不兼容会让同一句子随路径得到不同概率;批内因子化会生成边缘合理、组合非法的 token;旧状态近似会累积缓存误差;位置策略失误会过早提交高影响 token.单个 PPL 或延迟数字无法区分它们,需要路径、集合和系统三级诊断.

Eso-LM 最有启发性的部分因此不限于一个倍率.它给出一种清楚的设计方法:先把语义位置与计算次序分开,再检查概率分解是否完整、缓存依赖是否单调、并行集合是否近似独立.后续方法即使更换噪声过程、规划器或联合层,仍可沿这三项分析质量与速度的来源.

若任务强调任意填空与双向一致,主方法的因果干净位可能成为主要限制;若任务强调长序列生成和低延迟,精确缓存更有吸引力;若已有双向权重无法重训,近似缓存的迁移成本更低;若输出天然分块,块扩散可能提供更直接的结构.选择取决于任务条件,不由「任意顺序」四个字单独决定.
