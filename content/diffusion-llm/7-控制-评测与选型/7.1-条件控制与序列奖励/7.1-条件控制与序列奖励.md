# 条件控制与序列奖励

「条件控制与序列奖励」关注的是一组彼此牵连的选择：状态如何表示，破坏过程怎样丢失信息，模型又凭什么把信息找回来。下面的文章分别落到这些选择的不同分支，比较时以共同概率对象和计算条件为坐标。

## 1. 共同起点

Diffusion-LM(Li 等人,NeurIPS 2022)把每个词映成可训练的嵌入向量,前向在这些向量上加高斯,反向用 Transformer 预测更干净的向量,最终 rounding 到最近词.模型大约 80M 参数,句子长度 64,扩散步数训练时 2000,E2E 数据上解码可降到 200 步.它与 LLaDA 这类 8B 掩码模型在规模和扩散空间上都有明显差异。2022 年的可控生成主要利用连续轨迹施加梯度.

Plug-and-play 的目标写成贝叶斯式:冻结的语言模型给流畅 $p_{\mathrm{lm}}(w)$,另训一个分类器 $p(c\mid w)$ 给约束,希望从 $p(w\mid c)\propto p_{\mathrm{lm}}(w)\,p(c\mid w)$ 里采样.PPLM 把梯度打在 AR 的隐状态上,只能从左到右修下一个 token,前面写错了不能回.FUDGE 用前缀判别器重加权下一个词的分布,结构约束上容易在前缀的第一处错误之后全军覆没.Diffusion-LM 把控制打在整段连续潜变量 $x_{0:T}$ 上.每一步对

长度和填空在 Diffusion-LM 里可以没有分类器.长度等于画布上有多少个向量.填空等于左右上下文的嵌入固定,只对中间噪声做反向,固定位置的梯度被挡住.这已经是后来掩码扩散「提示干净,回答全掩」的连续版.

词表上的状态是 one-hot 或类别 ID,欧氏梯度没有定义.NOS 一类方法曾把离散模型的隐状态再当连续量来爬,相当于把 PPLM 搬到扩散里.Schiff 等人(arXiv:2412.10193)给了一条不爬隐状态的公式.设条件模型 $p_\theta(z_s\mid z_t,y)$ 和无条件 $p_\theta(z_s\mid z_t)$ 都对位置因子分解,离散 classifier-free guidance(D-CFG)写成

$\gamma=1$ 是普通条件采样,$\gamma>1$ 放大条件与无条件的差.每个位置要自己的配分函数,因为这是离散分布上的加权,不是高斯均值平移.训练时随机把标签 $y$ 丢掉,换成空标签,同一个网络兼条件与无条件,和图像 CFG 的 dropout 是同一套路. 他们还做了分类器版 D-CBG,用一阶展开近似 $p(y\mid z)$ 对当前 token 的影响,接近 FUDGE 的离散扩散版.实证覆盖基因组,小分子和离散化图像.公开主文没有 8B 语言掩码模型的同协议对照表,因此这些实验只支持 D-CFG 公式及其对应任务上的结果.

## 2. 分岔来自哪里

毒性列需要先把任务讲清楚.他们把奖励设成现成毒性分类器对「有毒」类的 log-softmax,转向强度 $\lambda=10$,目的是看粒子算法能不能把极稀有的高奖励样本找出来.基础 MDLM 在这套提示上的毒性率只有 0.003.这是稀有事件仿真,用来比较采样器的统计效率.它不是教模型写有害内容,也并非安全产品的拒答评测,更并非 HarmBench 那张红队表.流畅任务用 GPT-2-XL 给中间重构打困惑度.毒性实验里困惑度只作旁证,不进优化.

RLHF 有效,但贵,而且把模型固定在一份奖励上.换目标就要再训.推理期转向的卖点是:同一份预训练权重,今天拧毒性分类器,明天拧流畅,后天拧别的标量 $r(x_0)$.图像扩散上,Wu,Trippe,Cardoso,Dou 已经把 SMC 当后验采样器使过.离散文本上,梯度往往要先做连续松弛.Ou 等人 2026 用奖励梯度改提案,离散域就踩这个近似.梯度免费的家族包括 best-of-$n$,拒绝采样,粒子稀有事件仿真.统计效率通常差.

对应的未归一路径 $\gamma_0$ 就是先验路径乘 $\exp(\lambda r(x_0))$.Feynman–Kac 用一组非负势 $G_{t-1}$ 把同一份倾斜拆到每一步上,连乘仍等于终端奖励.最简单的分解:只在 $t=0$ 放 $G_0=\exp(\lambda r(x_0))$,中间全是 1.粒子一路按基础动力学走,最终一步才看见奖励,权重方差会急剧增大，轨迹随之退化.中间势需要提前估计未来获得高奖励的可能性. 最优拧转函数是未来奖励的条件期望:

最优势是相邻拧转的比:$G_{t-1}^\star=\psi_{t-1}^\star/\psi_t^\star$.在最优提案下,增量重要性权重等于预测归一化常数 $\nu_{t-1}(x_t)$,不再依赖抽到的那个孩子.条件在父粒子上,增量方差是零.这是「提案对了」的全部好处. $\nu$ 要对 $|\mathcal{V}|^L$ 个下一状态求和,算不起.实践里用当前步的 $\hat x_0$ 重构当代理:每个粒子状态抽 $K$ 个单步预测,平均成 $\widehat\psi_t$.$t=0$ 的理论保证仍在,中间步是有噪声的lookahead.

默认续写 100 个 token,每一步反向都重采样,除非消融另说.扫奖励窗口时,续写会加长,保证窗口定义得清.毒性转向时奖励算在固定长度的续写后缀上,评测再把提示拼回去.流畅转向把奖励设成 $r(x_0)=-r_{\mathrm{ppl}}(x_0)$,惩罚高困惑度;GPT-2-XL 只在这条任务里给中间重构打分.两条任务共用同一套粒子算法,只换标量 $r$.100 个 token 是续写长度,不是扩散步数 $T=50$,也并非 LLaDA 主表上的最大生成长度 512. 中间势的实现写成

## 4. 控制信号怎样进入反向链

条件输入直接交给去噪网络，是训练期控制；在推理时组合条件与无条件分布，是 classifier-free guidance；用分类器、奖励模型或约束自动机重新加权候选，则属于外部引导。三者的计算位置不同。训练期条件可以改变整个条件分布，CFG 依赖两次或可复用的模型输出，外部引导还要承担奖励评估和归一化成本。

离散状态没有对 token ID 求梯度的自然定义。可以在连续隐状态上做梯度引导，但经过词表投影后，连续方向未必对应想要的类别变化；也可以直接修改类别概率、反向转移率或路径权重，此时必须保证概率非负、归一化，并尊重前向核的支持集。硬约束若把所有可达路径都裁掉，增加 guidance scale 也救不回来。

序列级奖励把难点推到路径上。同一终局可以由许多揭开顺序到达，早期动作对最终奖励的贡献并不唯一。SMC 用粒子和重采样近似受控路径分布，beam 与 MCTS 用搜索预算保留候选；它们都可能遭遇粒子退化、搜索偏置和奖励黑客。比较方法时应同时测约束满足率、无条件质量、多样性与额外模型调用，单独提高奖励分数可能只是把分布挤到少数模式。

控制强度也没有跨方法通用的刻度。CFG 的 scale、能量模型的温度、SMC 的粒子数和硬约束的接受集合分别改变不同对象。合理的比较方式是画出质量、约束满足率、有效样本数与计算量的曲线，再在相同预算上看 Pareto 边界。只挑一个最强 scale 的结果，会掩盖模式坍缩、低概率路径被剪光或奖励模型过拟合等代价。

长文本还会放大控制信号的时机问题：约束介入太晚，关键位置已经提交；介入太早，奖励只能在高度不确定的前缀上猜测最终结构。分阶段控制因而比固定强度更值得检验。
