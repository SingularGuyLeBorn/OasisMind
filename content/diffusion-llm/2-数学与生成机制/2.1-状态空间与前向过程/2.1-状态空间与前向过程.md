# 状态空间与前向过程

「状态空间与前向过程」关注的是一组彼此牵连的选择：状态如何表示，破坏过程怎样丢失信息，模型又凭什么把信息找回来。下面的文章分别落到这些选择的不同分支，比较时以共同概率对象和计算条件为坐标。

连续扩散与离散扩散的分界先钉在**随机变量的状态空间**上。连续路线令 $z_t\in\mathbb R^{L\times d}$，噪声直接作用于 embedding、latent 或其他连续表示；前向核通常是高斯核，反向网络预测噪声、score、velocity 或干净连续状态，训练目标可由高斯 ELBO、denoising score matching 等形式得到。最终若要生成 token，还要经过 rounding、分类头或解码器，连续空间里的小误差可能在这一步变成类别跳变。

离散路线令 $x_t\in\{1,\ldots,K\}^L$，或等价地用 $L\times K$ 的 one-hot 行向量表示。前向核是类别转移矩阵或连续时间速率矩阵，反向模型预测 $x_0$ 的类别分布、离散 score ratio 或反向转移率；损失来自离散 ELBO、加权 MLM、score entropy 或离散 flow matching。这里没有对 token ID 求欧氏梯度这回事。连续路线的高斯闭式不能直接套到离散词表，离散路线的吸收态后验也不能拿去描述 latent diffusion；二者共享的是「先规定破坏过程，再学习逆过程」的框架。

## 共同起点

会训 GPT 的人,第一次看扩散论文,容易被两样东西吓住:随机微分方程,以及 U-Net 里那堆跳跃连接.做语言模型这两样都可以先放下.真正要带进词表里的,只有四件事:前向过程怎么把干净数据弄脏,脏到第 $t$ 步时分布有没有闭式,反向过程网络在预测什么,训练目标为什么是变分下界而不是式 (1) 那种精确连乘.

这一节建立四个基础关系;高斯噪声到马尔可夫转移矩阵的替换见下一节.U-Net,latent diffusion 和 Stable Diffusion 的采样器不影响这些关系.

记干净样本为 $x_0$.图像里它是像素张量,语言里它将是 token 序列,记号先共用.DDPM 把前向写成马尔可夫链:每一步加一点各向同性高斯噪声.

$\beta_t\in(0,1)$ 是噪声日程,通常随 $t$ 缓慢变大.$t=1$ 时几乎还是原图,$t=T$ 时(常见 $T=1000$)$x_T$ 看起来像标准正态噪声.这条链是**约定**,不是学出来的.网络不参与前向.

对已经熟悉 teacher forcing 的人,这里有一个反直觉:自回归的「噪声」是还没生成的未来 token,因果掩码把它挡住;扩散的噪声是人为加进去的,时间下标明确的腐蚀.两个「不知道」不是一个意思.

日程不必记公式表.线性日程让 $\beta_t$ 从 $10^{-4}$ 量级慢慢升到 $2\times 10^{-2}$ 量级;cosine 日程把前半段加噪放更慢,后面再加快.语言吸收态后来常用更简单的东西:令「仍可见」的概率 $\alpha_t=1-t$,于是 $t=0.3$ 表示每个 token 独立地有 30% 概率已被掩.图像里 $\bar\alpha_t$ 要查表,语言里掩码率常常就是 $t$ 本身.

训练时随机抽一个 $t$,抽一个 $\epsilon$,立刻得到该噪声水平的 $x_t$.不需要真的走 $t$ 步链.语言里的吸收态扩散后来也有类似的「直接按比例掩码」:掩码率 $t$ 抽出来,每个 token 独立变成 `[MASK]`,不必真的模拟 $T$ 次转移.思想同源,分布族不同.

式 (5) 看起来像普通回归,它其实是变分下界里若干 KL 项在高斯假设下的简化.完整 ELBO 还包含 $t=T$ 时先验匹配,$t=1$ 时的重构项.工程上 $\mathcal{L}_{\mathrm{simple}}$ 够用,理论论文会把省略的项写回来.

对语言模型,这一节只需留下一个迁移规则:**网络看见的是当前噪声水平的样本,加上时间条件,输出对「干净数据」的某种预测**.图像里预测 $\epsilon$ 或 $x_0$ 或 $v$ 都能互相换算.离散里状态没有「减去一个高斯 $\epsilon$」这种算术,所以直接预测词表上的分布 $p_\theta(x_0^i\mid x_t)$.

时间条件在图像里是 timestep embedding 加到残差块.LLaDA 8B 的公开描述是 decoder-only Transformer 去掉 causal mask;掩码率 $t$ 作为前向采样的一部分进入数据,不一定要做成和 DiT 一模一样的 adaLN.读到具体模型再对架构表,不要默认「所有 DLM 都有一个 $t$ 向量加在每层」.

图像文献里还有一条平行语言:score $\nabla_{x_t}\log q(x_t)$.Tweedie 公式说明,高斯后验的均值可以用 score 写出来,于是「预测 $\epsilon$」和「预测 score」只差一个已知系数.SEDD 把这句话搬到离散状态,变成学习两个状态概率的比,而不是一个欧氏梯度.若暂时只关心掩码扩散,可以把 score 理解成「反向过程的另一种参数化」,不必先读 SDE.

右边就是负 ELBO.训练最小化右边,等于在推一个**似然上界**(对负对数似然而言).因此:

Nie 等人在 LLaDA 文中引用过「MDM 要 16 倍算力才能追上 AR 的似然」这类早期 scaling 观察,并指出似然是间接指标,扩散优化的是界,他们把 FLOPs 区间拉到 $10^{20}$–$10^{23}$ 后下游任务可以打平.读到「扩散样例效率差」时,问的是 PPL 还是 GSM8K.

训练可以把时间连续化,$t\sim U[0,1]$,不必先定死 $T=1000$.采样必须把反向过程切成有限步.切得越细,离散化误差越小,前向次数越多.

图像里常见 20–50 步的 ODE 求解器就能出好看的图,因为像素空间平滑,少步求解仍近似同一条概率流.离散词表没有这种平滑:两个 token 之间没有「半个 the」.少步意味着每一步要同时决定很多位置,位置之间的依赖会被一步内的因子分解削弱.早期离散扩散因此常需几百到上千步,后续工作才引入置信度揭示,remask,copula 和能量校正.**把图像里「20 步出图」的经验直接搬到语言上,会低估离散状态之间的耦合.**

## 分岔来自哪里

上一篇的高斯前向在像素上合法,在 token ID 上不合法.D3PM(Austin 等人,NeurIPS 2021)做的事很窄:把「加 $\epsilon$」换成「乘一个马尔可夫矩阵 $Q_t$」,其余结构(前向约定,反向学习,ELBO)保持不动.本路线统一采用 one-hot 行向量:类别概率是 $1\times |V|$,转移矩阵 $Q_t$ 是 $|V|\times |V|$ 的行随机矩阵,$Q_t[i,j]$ 表示 $i\to j$,所以一步分布写成 $x_{t-1}Q_t$.采用列向量的资料会把它写成 $Q_t^\top x_{t-1}^\top$;两式等价,但不能在同一段推导中混用.序列是 $L$ 个这样的向量,前向在每个位置上独立作用.$\mathrm{Cat}(\cdot;p)$ 表示参数为 $p$ 的分类分布. 先看一个三人词表 $\{A,B,M\}$,$M$ 是 `[MASK]`.吸收态在「还不是 $M$」的行上,对角放 $1-\beta$,通往 $M$ 的列放 $\beta$;$M$ 那一行是 $(0,0,1)$:

$A$ 不能直接变成 $B$.要变,只能先被吸收成 $M$,再在反向里被网络猜成 $B$.这和均匀矩阵「$A$ 一步可以变成 $B$」是两种噪声哲学:吸收态保存「我已经被腐蚀」这个可观测事件;均匀把腐蚀藏进另一个合法词里.

均匀和吸收态的 $\bar Q_t$ 有闭式,训练时和 DDPM 一样直接从 $x_0$ 采样 $x_t$,不必真走 $t$ 步.离散化高斯那一类往往要预计算或截断. 反向仍然用 $x_0$ 参数化:网络输出 $\tilde p_\theta(\tilde x_0\mid x_t)$,再代入后验

式 (3) 保证:若 $Q_t$ 规定「从 $a$ 到 $b$ 概率为零」,反向也不会无中生有地走这条边.吸收态里这意味着:**已经是 `[MASK]` 的位置,反向只能从掩码退回某个词表 token;还没被掩的位置,应保持原样.** MDLM 后来把这两条写成 SUBS 参数化的硬约束,而不是让网络自己学.

每个 token 以 $1-\beta_t$ 留在原地,以 $\beta_t$ 变成词表上均匀随机的一个.平稳分布是均匀分布.直觉像「把字打成错别字」,错成谁都一样常.词表 $10^4$–$10^5$ 时,一次均匀跳几乎不提供「还残留多少原信息」的可辨信号:被改过的位置看起来只是另一个合法 token,模型和「本来就是这个词」分不清.

增设特殊状态 `[MASK]`.每个真实 token 要么不动,要么变成 `[MASK]`;`[MASK]` 再转移只指向自己.平稳分布把质量全堆在掩码上.$t$ 足够大时整句变成全掩码.被腐蚀的位置**看得见**,因为 `[MASK]` 不在正常词表语义里.这和 BERT 的输入格式一致,也是后来 MDLM,LLaDA,Dream 的默认前向.

把 ID 或嵌入距离当成「相近」,相近状态之间转移概率更高,矩阵做成双随机,平稳分布仍均匀.对量化灰度图这种有序类别合理;对 WordPiece ID 不合理:相邻 ID 不必是同义词.D3PM 在 LM1B 上的 nearest-neighbor 变体,似然甚至不如均匀.不要在语言 DLM 里默认「噪声应该跳到近义词」.

D3PM 在 text8(27 字符,长度 256)上吸收态最好;在 LM1B(sentencepiece 8192,打包长度 128)上吸收态的困惑度上界约 76.9,均匀约 137.9(原文 Table 2,步数设定见论文,这里只取相对关系).数量级已经说明:文本不要用均匀跳当默认.

所以「BERT 就是扩散」这句话要加限定.固定 15%,只做理解任务的编码器,是单步,固定噪声水平的去噪自编码器.随机抽满 $[0,1]$ 掩码率,用 ELBO 权训练,从全掩码反向采样的,才是生成模型.差在日程和目标,不差在「是不是 Transformer」.

吸收态有一个实现上极便宜的性质:位置之间前向独立,一个位置要么还是 $x_0$ 的原 token,要么是 `[MASK]`.给定 $x_t$ 和 $x_0$,反向一步的后验可以解析写出来:未掩位置保持;掩码位置按日程决定是继续掩还是揭开成 $x_0$.网络只需要在掩码位置输出词表分布.MDLM 的 SUBS 把「未掩位置抄过来,不要预测 `[MASK]`」做成输出替换,再对 ELBO 做解析化简(他们称为 Rao-Blackwellization),连续时间极限是

$\alpha_t$ 是「该位置仍未被掩」的概率,单调降.线性日程 $\alpha_t=1-t$ 时,权重变成 $1/t$,与 LLaDA 式 (3) 同型.细节,SUBS 的两条替换,以及为何这是加权 MLM,下一篇写.这里只需看见:吸收态不仅是「好用的噪声」,它让 ELBO 从「对整个 $Q_t$ 算 KL」变成「只在掩码位置算交叉熵」.
