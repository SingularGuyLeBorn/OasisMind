# 为什么用扩散做语言生成

自回归语言模型把整句概率拆成从左到右的条件乘积。GPT、LLaMA、Qwen、Claude 都走这条路。训练时 teacher forcing 可以并行算损失，推理时却必须等第 $i-1$ 个 token 出来，才能算第 $i$ 个。扩散语言模型（Diffusion Language Model，DLM / dLLM）换了一种生成过程：先把整段序列弄成噪声或 `[MASK]`，再花若干步把它擦回可读文本，每一步可以同时改很多位置。

本篇只回答「为什么要动扩散」，不推转移矩阵。公式和采样在后面的机制文。读者假定已经会 next-token prediction、causal mask、KV Cache 这套词汇。

## 1. 自回归卡住的三件事

自回归的联合分布是精确分解，没有变分近似：

$$
P_{\mathrm{AR}}(x)=\prod_{i=1}^{n}P_{\theta}(x_i\mid x_{<i}) \tag{1}
$$

这个拆法不是错，它只是把三个工程问题写进了结构里。

### 1.1 解码是串行的

生成长度为 $n$ 的回答，至少要 $n$ 次前向。KV Cache 省掉了重复算历史 Key/Value，但省不掉「这一步必须等上一步」。投机解码、MTP、Medusa 都是在这个串行约束上打补丁：一次多猜几个，再验证。扩散走另一条路：时间维上的步数 $T$ 和序列长度 $n$ 解耦。$T$ 可以是 8、32、256，不必等于 $n$。

这不等于开箱即更快。开源的全双向扩散模型每一步都要对整段做注意力，没有原生 KV Cache；LLaDA 论文自己写明 8B 用 vanilla MHA 而不是 GQA，原因就是当时这套公式和 KV Cache 不兼容。商业侧的 Mercury Coder Mini 在 Artificial Analysis 的独立评测里到过单卡 H100 上 1109 tokens/s，相对当时的速度优化 AR 模型宣称最高约 10 倍吞吐。开源侧 LLaDA 2.0-flash 在作者自己的 dInfer 对照里，CAP 版 535 TPS，对照 SGLang 上的 AR 基线 256 / 237 TPS，大约 2.1 倍。速度是「可以并行」换来的潜力，不是每篇论文默认成立的倍数。

### 1.2 因果注意力看不见右边

式 (1) 要求位置 $i$ 只能看 $x_{<i}$。这带来反转诅咒：训练语料里见过「A 是 B」，测试时问「B 是谁」容易失败。Berglund 等人把这件事钉成结构性问题，不是提示词没写好。LLaDA 用双向注意力做掩码扩散，在诗歌补全的反向任务上超过 GPT-4o。机制很朴素：去噪时每个还盖着的位置都能看见已经揭开的左右上下文，没有「只能往下续」这条禁令。

同一件事的正面用法是填空和改写。给定「床前______光」，自回归要么从左边硬续，要么把填空改成一套别扭的 prompt。扩散把要填的位置留成 `[MASK]`，其余位置当干净条件，一步里同时猜中间那几个 token。

### 1.3 约束很难塞进生成过程

想让模型「必须出现五个关键词」或「第二段比第一段长」，自回归通常要靠提示、logit 后处理，或再开一轮 RLHF。图像扩散里常见的 classifier guidance / classifier-free guidance，走的是连续轨迹上的梯度。Diffusion-LM（NeurIPS 2022）把 token 先映到嵌入空间，就是为了把这类可微约束原样搬过来。离散掩码扩散后来用 CFG、能量校正、置信度阈值做类似的事，数学形式不同，目的一样：在去噪轨迹上改行为，不必为每个约束重训一遍。

## 2. 图像扩散在干什么（只保留直觉）

图像扩散先约定一条前向过程：干净像素 $x_0$ 一步步加高斯噪声，直到几乎是纯噪声 $x_T$。反向过程学「从更噪的图退回更干净的图」。生成时从噪声出发，迭代 $T$ 步。每一步更新的是整张图，不是从左上角像素扫到右下角。

对已经会 LLM 的人，只需记住三句话。

第一，扩散建模的是一条轨迹，不是下一个符号。联合分布写成隐变量积分，训练优化的是变分下界（ELBO），不是式 (1) 那种可精确求值的连乘。

第二，并行发生在「空间维」。图像是像素网格，语言是 token 序列。只要噪声定义在整段序列上，反向就能整段一起改。

第三，步数 $T$ 是测试时可以拧的旋钮。步数多，轨迹更接近训练时的反向过程，质量往往更好、更慢；步数少，快，但离散情况下容易出现位置之间互相打架。后面采样文会写置信度揭示和 remask 怎样缓解这件事。

![](./images/fig-ar-vs-mask-diffusion.png)

> 图 1：上行自回归每步只提交一个新 token；下行掩码扩散从全 `[MASK]` 出发，每步并行揭开若干位置。

**图 1 解析**

- **上行 AR0→AR3**：条件一直是已经写出来的前缀。箭头上的 `+1 token` 是硬约束，不是实现偷懒。
- **下行 D0→D3**：一开始长度就定了（全掩码），每步 `unmask k` 可以 $k>1$。未揭开的位置继续当 `[MASK]`，已揭开的位置成为下一步的双向上下文。
- **两行不要对成「同样四步所以一样快」**。AR 的步数跟长度绑死；扩散的步数是超参。长度 128、步数 32 时，前向次数可以少于 128；长度 8、步数 256 时，反而更慢。
- **图里没画 KV Cache**。上行可以缓存历史；下行若用全双向注意力，每步都要重算整段。加速是另一些工作（块扩散、近似缓存）在补，不是掩码扩散免费附赠。

## 3. 语言为什么不能直接「加高斯」

像素是连续的，token 是词表上的离散 ID。`the` 和 `The` 的 ID 相邻，语义不必相邻；两个同义词的 ID 可以隔着一万号。高斯噪声假设的是欧氏空间里的小扰动，直接加在 ID 上没有物理意义。

于是出现两条路线。

| 路线 | 噪声定义在哪 | 反向结束时怎么回到 token | 代表 |
|---|---|---|---|
| 连续扩散 | token 嵌入向量，加高斯 | 去噪后再 rounding / argmax | Diffusion-LM、DiffuSeq、SSD-LM、CDCD |
| 离散扩散 | 词表上的马尔可夫转移 | 每步本来就在离散状态里 | D3PM、MDLM、SEDD、LLaDA、Dream |

![](./images/fig-continuous-vs-discrete-dlm.png)

> 图 2：上行把离散 ID 抬到嵌入空间做高斯扩散，最后再量化回词表；下行用转移矩阵 $Q_t$ 直接在 token 上跳，主流实现是跳进吸收态 `[MASK]`。

**图 2 解析**

- **上行 C1→C5**：embed → 加高斯 → 去噪 → rounding。中间态是向量，可以做梯度引导，这是 Diffusion-LM 可控生成的来源。代价是「向量空间里近」不等于「词表上合法」，rounding 会丢信息。
- **下行 D1→D4**：token 被 $Q_t$ 腐蚀成别的 token 或 `[MASK]`，Transformer 用双向注意力猜干净的 $x_0$，再按后验走一步到 $x_{t-1}$。没有二次量化。
- **2024 年以后的大模型几乎都走下行**。不是连续路线「错了」，而是离散吸收态和 BERT 式 MLM 共用同一套交叉熵，扩到 7B–100B 时工程上更顺。

D3PM（NeurIPS 2021）把转移矩阵写成三类：均匀跳到任意 token、吸收态 `[MASK]`、以及模仿高斯的近邻跳转。文本上吸收态最好用。MDLM（NeurIPS 2024，arXiv:2406.07524）再证明：吸收态加上合适的参数化，连续时间 ELBO 就是加权的 MLM 损失。LLaDA 把掩码比例 $t$ 从 0 到 1 随机抽，损失只在被掩位置上算交叉熵，并多一个 $1/t$ 权重。BERT 的固定 15% 掩码是这条公式在单步、固定噪声水平上的退化，不是扩散的全部。LLaDA 还把 1% 的预训练样本长度在 $[1,4096]$ 里随机抽，避免模型只会处理垫满的定长块。生成时长度仍是超参，短回答靠 `[EOS]` 截断，这和 AR 的「写到结束符就停」不是同一套动力学。

## 4. 2025 年之后为什么值得认真看

2021 到 2023 的离散扩散大多停在 GPT-2 尺度、比 AR 差一截的困惑度。把「能当大模型用」钉住的是几件可核对的事实，不是口号。

**从头训到 8B。** LLaDA 8B Base 预训练 2.3T token、约 13 万 H800 GPU 小时。同一套评测协议下，MMLU 5-shot 为 65.9，对照 LLaMA3 8B Base 的 65.4；GSM8K 4-shot 为 70.3，对照 48.7；HumanEval 0-shot 为 35.4，对照 34.8。数据量是 LLaMA3 公开数字 15T 的约六分之一。Instruct 版只做了 450 万对 SFT、没有 RL，MMLU 65.5 对 LLaMA3 Instruct 的 68.4，GSM8K 69.4 对 78.3，HumanEval 49.4 对 59.8。旧笔记里那组「MMLU 62.3 / GSM8K 54.8」对不上论文 Table 1–2，以论文为准。

**从 AR 权重改编。** Dream 7B 从 Qwen2.5 7B 初始化再做离散扩散。同协议 Base：MMLU 69.5 对 Qwen2.5 的 71.9，GSM8K 77.2 对 78.9，HumanEval 57.9 对 56.7；Sudoku 81.0 对 21.0。DiffuLLaMA 更早给出「改注意力掩码、用不到 200B token 把 GPT-2 / LLaMA 变成扩散」的配方。LLaDA 2.0 把这件事做到 16B（mini）和 100B（flash）的 MoE，用三阶段块级 WSD 把 AR 转成扩散，而不是从零堆 100B。flash 的 HumanEval 94.51、平均分 73.18，和 Qwen3-30B-A3B-Instruct-2507 的 73.60 同一档。

**吞吐被测到四位数。** Mercury Coder Mini 1109 tokens/s、Small 737 tokens/s（H100，Artificial Analysis）。Google 的 Gemini Diffusion 是实验室演示，公开材料强调能边生成边改错，速度数字以官方页当时公布为准，不要和开源 LLaDA 的步数混成同一套基准。ByteDance 的 Seed Diffusion 走代码、H20 上报道过更高吞吐。这些数字的测试条件（批大小、长度、是否含 prefill）并不统一，只能当数量级，不能横着减。

**块扩散把「必须定长、不能 KV Cache」这两条拆开。** BD3-LM（ICLR 2025 Oral）在块与块之间自回归、块内做离散扩散，于是长度可变、块间可以 KV Cache。Fast-dLLM v2 用大约 1B token 微调就把预训练 AR 改成块扩散，相对 Dream 那种数百 B token 的全注意力改编，数据量小两个数量级。后面知识点文单独写。

## 5. 不是替代，是另一种因式分解

扩散没有取消「建模 $P(x)$」这件事。它取消的是「必须按时间顺序一个一个乘出来」。代价也清楚：似然是界而不是精确值；长度要么预先垫 `[MASK]` / `[EOS]`，要么改成块扩散；生态（vLLM、投机解码、现成 RLHF 流水线）薄得多。

适合先建立的心理模型是下面这张表。数字只在有来源时出现，其余是机制判断。

读表时把「结构」和「2026 年测到的数」分开。填空、反转在结构上顺，不表示聊天总榜已经超过 GPT-4o。步数是超参，不表示开源权重默认比带 KV 的 AR 更快。ELBO 是界，不表示扩散的 PPL 可以拿来和 LLaMA 减。基础设施薄，不表示永远薄；Mercury 和 dInfer 已经在补，只是还没到 vLLM 那种「装上就能服务」。

一个具体的填空能把式 (1) 的结构差变成可感的。给定「床前______光」，自回归看见的条件只有「床前」。它接下来最可能写出「明月光」整串，也可能写出别的三字，空位对不齐时你得后处理。掩码扩散把中间两格留成 `[MASK]`，「床前」和「光」都是当前步的可见条件，双向注意力让「光」也能约束中间。这不是提示词写得更聪明，是因式分解允许右边作为条件。同一机制在反向诗句上让下句约束上句；在数独上让整盘格子互相约束。任务换了，刀还是这一把。

本篇故意不把 Mercury 的 10× 写成「扩散已经更快」。开源全双向每步重算整段注意力，没有原生 KV；商业代码模型把并行和 runtime 做到产品里，测的是另一条栈。读者若只记住一句话，请记住：换因式分解，换的是生成过程，不是自动换吞吐、自动换总榜、自动换对齐。后面每一篇都在给这句加限定。限定看起来烦，但比口号耐用。

连续路线和离散路线不要在入门里打成「谁淘汰谁」。嵌入空间加高斯，换来的是可微约束；词表上进 `[MASK]`，换来的是和 BERT 工具链兼容、以及 7B 以上的公开权重。2025 年的大模型走离散，是工程收敛，不是连续数学被证伪。若你的任务是句法树必须长这样、而且模型只有几千万参数，Diffusion-LM 那条河仍然更直。若你的任务是和 LLaMA 比 MMLU，走掩码扩散。入门篇把两条河画在图 2 里，就是为了让后面读专文时知道自己在哪条河上，不要用连续论文的 CFG 代码去跑 LLaDA。

KV Cache 在入门里只需要一句：AR 能缓存是因为已经写出的前缀不再变；全双向每揭开一些字，所有 Key 都可能变。后面加速文再讲 DualCache 和块间真缓存。入门若展开缓存论文，读者会以为必须先会近似算法才能懂扩散。不必。先接受「默认没有严格 KV」，再决定要不要买近似。

读完入门，应能自己画出两行：上行 AR 每步 +1，下行掩码每步揭开 k 个。画不出这两行，后面的 $Q_t$ 和 ELBO 会变成符号游戏。图 1 已经画过一遍；合上屏幕再画一次，比再读一段「为什么重要」有用。

反转诅咒在入门里只需要记住 Berglund 的 0% 和 LLaDA 诗句表的正反向落差被压平。机制分析、注意力耦合、为什么目标函数本身推不出 $P(A\mid B)=P(B\mid A)$，都在双向注意力专文。入门若展开那些，读者会以为必须先读理论文才能懂扩散。不必。先懂「因果掩码禁止看右边」，再决定要不要读耦合那一层。

| 维度 | 自回归 | 扩散（当代掩码 / 块扩散） |
|---|---|---|
| 因式分解 | 精确连乘 | ELBO / 加权 MLM |
| 每步看见谁 | 左边前缀 | 当前未掩位置（双向） |
| 步数 | 等于新 token 数 | 超参 $T$ 或块数 × 块内步数 |
| 填空 / 反转 | 别扭 | 结构上顺 |
| 可控生成 | 提示或另训 | 轨迹上引导更直接 |
| 长文本 | 续写自然 | 全双向贵，块扩散在补 |
| 基础设施 | 极厚 | 2025–2026 才开始有专用框架 |

读完本篇，应能回答三句。语言扩散要解决的是「token 上如何定义噪声」，不是把 Stable Diffusion 的 U-Net 套到句子上。主流大模型走吸收态掩码，因为目标函数长得像 BERT，但噪声水平从 0 到 1 随机抽，所以它是生成模型而不是固定 15% 的编码器。8B 以上能打，靠的是 LLaDA 这类从头训、Dream / LLaDA 2.0 这类改编，以及 Mercury 这类把并行解码推到产品吞吐的系统，而不是 2022 年那批小模型的故事。

后面按编号读。02 把 $Q_t$、加权 MLM、采样揭开三件事写完，读完应能默写 $1/t$ 损失，并说出低置信 remask 在 LLaDA Table 9 上 21.3 对 70.0。03 把块扩散、改编、反转、缓存、引导、对齐、失效分开，避免把 27.6× 当成对 AR、把 80M 句法树当成 8B。04 是年表和规格卡。05 把十个维度里哪些是机制必然、哪些是 2026 年工程现状拆开。数字打架时，优先信论文表，其次信本花园已经改过的专文，不信旧笔记里的 62.3 / 54.8 和「LLaDA 8B 快 2–8 倍」。

Dream 7B 的同协议表把规划题上的结构差别画得很清楚：Sudoku 81.0 对 Qwen2.5 7B 的 21.0，Countdown 16.0 对 6.2。这不是吞吐卖点，是「多约束要同时改」时从左到右难以回头。诗歌反向则是另一把刀：LLaDA Instruct 42.4 对 GPT-4o 的 34.3，正向却是 48.8 对 82.7。两张表一起读，才不会把扩散听成全能。

下一篇从图像里的高斯噪声换成词表上的转移矩阵，把 $Q_t$ 写清楚。

读本篇时还有一个容易焊错的点：把「可以并行」听成「已经更快」。串行是 AR 写进结构里的；更快要硬件、调度器、是否全双向一起算。Mercury Mini 的 1109 和 2.0-flash 的 535 证明潜力存在，LLaDA 8B 原文没有速度表。把潜力写成 8B 的规格，是后面对照文专门挡住的那类旧稿。动机层只需要承认：因式分解换掉之后，步数 $T$ 不再必须等于 $n$。承认这一句，并不自动承认任何一张 tokens/s 表。

连续路线和离散路线也不要焊成「哪个更先进」。连续嵌入能把图像那边的梯度引导搬过来，Diffusion-LM 在 80M 上证明句法树约束可以写进轨迹。离散吸收态能把训练循环收成加权 MLM，所以 7B–100B 走这条。两条路回答的问题不同：一个问约束能不能变成梯度，一个问大词表上噪声如何可观测。2025 年能叫 LLM 的开放权重走离散，不是因为梯度过时了，是因为交叉熵和现成工具链对接成本更低。要注入句法树，连续那条河还在；要训 8B，离散那条河才有检查点。

- [Sahoo et al., MDLM, NeurIPS 2024](https://arxiv.org/abs/2406.07524) — 吸收态掩码扩散；连续时间目标化为加权 MLM。注意旧稿把本篇写成 ICML 2023 / arXiv:2306.08162，编号是错的。
- [Nie et al., LLaDA, 2025](https://arxiv.org/abs/2502.09992) — 8B 从头预训练；Table 1–2 的 MMLU / GSM8K / HumanEval；反转诗歌补全。
- [Khanna et al., Mercury, 2025](https://arxiv.org/abs/2506.17298) — Mercury Coder Mini 1109 tokens/s、Small 737 tokens/s（H100）。
- [Bie et al., LLaDA 2.0, 2025](https://arxiv.org/abs/2512.15745) — AR→扩散的三阶段块级 WSD；mini 16B / flash 100B；flash-CAP 535 TPS。
- [Li et al., A Survey on Diffusion Language Models, 2025](https://arxiv.org/abs/2508.10875) — 连续 / 离散 / 多模态分类与推理优化综述。
- [Arriola et al., Block Diffusion, ICLR 2025](https://arxiv.org/abs/2503.09573) — 块间自回归、块内扩散；可变长与 KV Cache。
