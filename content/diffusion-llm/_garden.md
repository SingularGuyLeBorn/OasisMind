# Diffusion LLM · 扩散语言模型

自回归把「一个接一个」写进了模型的结构里，扩散想换掉的就是这一步。本花园的目标是把 token 上的扩散讲到能独立读论文，而不是把图像扩散的名词搬过来。读者假定已经会 next-token prediction、causal mask 与 KV Cache——Transformer 本身请回 [LLM 指南](../llm-guide/_garden.md)。

## 怎么读

按层走，每层解决一个问题，不要跳着只记模型名。

| 层 | 读完应能回答 |
|---|---|
| 01 动机 | 自回归因式分解把什么写进了结构里，扩散换掉的是哪一步 |
| 02 机制 | $Q_t$、吸收态、ELBO 为何长得像加权 MLM、采样时如何揭开与 remask |
| 03 知识点 | 离散性的五刀：CART、边际陷阱、块扩散、并行诅咒之后仍容易混的概念 |
| 04 模型 | 从 D3PM 到 LLaDA 2.0 / Dream / Mercury，各自钉住哪件事 |
| 05 对照 | 十个维度里，哪些是机制必然，哪些只是 2026 年的工程现状 |

入口是[为什么用扩散做语言生成](./01-导论与阅读路线/1.1-为什么用扩散做语言生成.md)：AR 的串行解码、反转诅咒、约束难注入，与两条路线的分野，都在这一篇。
