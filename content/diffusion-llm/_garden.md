# Diffusion LLM · 扩散语言模型

当代语言模型主要采用自回归生成：训练时预测下一个 token，推理时按从左到右的条件链逐项提交。这个方案拥有成熟的训练、缓存和部署体系，也是理解扩散语言模型的参照。扩散路线重新定义生成过程：模型从带噪或带掩码的序列出发，在多轮网络计算中同时修订多个位置。它改变了概率分解、注意力可见性和推理状态，也把并行揭开、答案修订与约束注入带进同一研究问题。

我关注这条路线，是因为它把语言生成中长期绑定的三件事拆开了：token 的顺序、计算的顺序与内容确定的顺序。在自回归模型中三者大体一致；在掩码扩散中，位置顺序仍然存在，模型却可以先确定高置信位置，再回头处理依赖更强的位置。扩散与自回归并没有简单的替代关系：能力取决于生成机制，速度取决于采样器和实现，论文数字则受模型、长度与硬件共同约束。

这条技术路线从前向过程开始：离散转移矩阵或吸收态逐步破坏数据，训练目标学习在给定噪声时刻恢复干净 token，反向过程依据后验、置信度或调度逐轮揭开，并可把低置信预测重新掩码。联合依赖、块扩散、权重迁移、少步蒸馏、缓存与 serving 都由这组三段式过程继续分化。图像扩散提供数学起点，语言中的离散词表、强位置依赖和精确文本匹配决定了语言模型不能直接照搬图像配方。

扩散推理至少有三个不同的计量单位。输出长度 $L$ 表示要生成多少位置，去噪步数或 NFE 表示调用网络多少次，每次调用的有效序列长度和注意力图案决定单步成本。一次网络调用预测多个位置，不等于端到端一定更快；少步采样也可能以质量、可修订空间或额外验证为代价。速度数字只有连同模型、硬件、batch、输入输出长度、精度、缓存和质量门槛才有意义。

## 怎么读

按层走，每层解决一个问题，不要跳着只记模型名。

| 层 | 核心问题 |
|---|---|
| 01 动机 | 自回归因式分解把什么写进了结构里，扩散换掉的是哪一步 |
| 02 机制 | $Q_t$、吸收态、ELBO 为何长得像加权 MLM、采样时如何揭开与 remask |
| 03 模型谱系 | 从 D3PM 到 LLaDA 2.0、Dream 与 Mercury，分别改变噪声、目标、训练起点或系统实现 |
| 04 结构 | 联合依赖、块扩散与规划式生成怎样处理并行位置之间的一致性 |
| 05–07 工程与判断 | 训练迁移、推理系统、控制和评测如何把机制变成可比较的模型 |

入口是[为什么用扩散做语言生成](./01-导论与阅读路线/1.1-为什么用扩散做语言生成/1.1-为什么用扩散做语言生成.md)：AR 的串行解码、反转诅咒、约束难注入，与两条路线的分野，都在这一篇。

第 02 章给出公式骨架：区分单步转移 $Q_t$ 与累积转移 $\bar Q_t$，解释吸收态为何让腐蚀位置可观察，并把连续时间 ELBO 与加权 MLM 的关系推到损失实现。采样部分区分祖先采样、确定性揭开、低置信重掩和离散流。相同检查点采用不同调度，可能得到不同质量、步数和可修订行为。

第 03、04 章把公式放回模型。D3PM 建立词表上的马尔可夫语言；MDLM 把吸收态目标整理成便于大规模训练的形式；SEDD 改写离散 score 目标；LLaDA 把路线扩展到十亿参数级；块扩散在块间保留因果结构，在块内执行并行去噪。模型名称用于定位工作，噪声核、目标函数、训练起点、注意力图案和采样器才构成可比的技术轴。

第 05 至 07 章处理模型落地。自回归权重改编需要重新处理输入移位、可见性和位置编码；蒸馏减少 NFE，缓存和投机验证减少单步开销；控制方法把序列级约束写进采样过程；评测则固定质量、并行性和系统协议。最终选型不追求一张跨论文总榜，而是判断任务是否需要可修订生成、固定长度填槽、双向条件或高并发吞吐，并检查现有实现能否在目标硬件上兑现。

公开权重与代码、可复算表格和独立复现能够支持机制与数字核验；商业演示与作者自报吞吐可以证明系统已经运行，却不足以推导模型规模和训练机制。论文版本、模型卡与代码提交共同确定结论对应的具体版本，跨版本变化需要重新核对。

扩散语言模型目前仍有几项持续约束。全双向模型在每次去噪中重新处理整段序列，缺少自回归 KV Cache 那样稳定的增量边界；并行预测位置之间的联合分布常被因子化输出近似；固定长度生成便于并行，却需要额外机制处理提前结束和长度扩展；似然上界、生成质量与服务吞吐也使用不同评价口径。它们分别对应缓存、联合建模、长度控制和评测协议，也是后续方法持续改动的对象。

机制与系统之间存在直接对应关系。块大小同时改变概率分解和缓存可用性，重掩策略同时改变纠错机会和网络调用数，自回归权重迁移同时影响训练成本和模型原有能力。把这些变量放在一条链上，才能判断一项改进究竟来自模型、评测协议还是运行时。

「扩散语言模型」至少要给出语言状态、前向噪声或概率路径、训练目标与反向生成过程。只有并行填词、却没有扩散路径的非自回归模型属于邻近方法，不能因为同样支持多位置生成就并入主谱系。新方法也可以沿这四项定位：它究竟改了概率模型、训练估计、采样策略，还是运行时实现。

每篇论文都可用一张最小规格卡记录：状态空间是 token 还是嵌入，前向过程是吸收、均匀还是连续噪声，模型预测干净数据、score 还是 flow，训练从头开始还是继承检查点，推理采用全双向还是块内双向，以及结果能否由公开权重和代码复核。这张卡可以消除同名术语造成的大部分混淆。

一项新工作可以据此定位到概率模型、训练估计、采样策略或运行时，并列出它与自回归基线比较时需要固定的变量。这套坐标用于迁移到后续方法，不依赖某一时点的模型排名。

定义、实验协议与公开实现共同限定每项结论的适用范围。尤其是速度比较，必须同时核对 NFE、单次前向处理的序列长度、批大小、精度、硬件与质量门槛；只报「并行生成」或峰值 TPS，无法说明它在相同输出质量下是否比自回归系统更快。

同名模型若更换采样器、块长或服务实现, 规格卡也要随版本更新; 检查点名称相同, 不代表生成分布、网络调用数和墙钟吞吐保持不变。
