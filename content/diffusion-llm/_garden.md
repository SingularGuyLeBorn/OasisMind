# Diffusion LLM · 扩散语言模型

当代语言模型主要采用自回归生成：训练时预测下一个 token，推理时按从左到右的条件链逐项提交。这个方案拥有成熟的训练、缓存和部署体系，也是理解扩散语言模型的参照。扩散路线重新定义生成过程：模型从带噪或带掩码的序列出发，在多轮网络计算中同时修订多个位置。它改变了概率分解、注意力可见性和推理状态，也把并行揭开、答案修订与约束注入带进同一研究问题。

我关注这条路线，是因为它把语言生成中长期绑定的三件事拆开了：token 的顺序、计算的顺序与内容确定的顺序。在自回归模型中三者大体一致；在掩码扩散中，位置顺序仍然存在，模型却可以先确定高置信位置，再回头处理依赖更强的位置。扩散与自回归并没有简单的替代关系：能力取决于生成机制，速度取决于采样器和实现，论文数字则受模型、长度与硬件共同约束。

这条技术路线从前向过程开始：离散转移矩阵或吸收态逐步破坏数据，训练目标学习在给定噪声时刻恢复干净 token，反向过程依据后验、置信度或调度逐轮揭开，并可把低置信预测重新掩码。联合依赖、块扩散、权重迁移、少步蒸馏、缓存与 serving 都由这组三段式过程继续分化。图像扩散提供数学起点，语言中的离散词表、强位置依赖和精确文本匹配决定了语言模型不能直接照搬图像配方。

扩散推理至少有三个不同的计量单位。输出长度 $L$ 表示要生成多少位置，去噪步数或 NFE 表示调用网络多少次，每次调用的有效序列长度和注意力图案决定单步成本。一次网络调用预测多个位置，不等于端到端一定更快；少步采样也可能以质量、可修订空间或额外验证为代价。速度数字只有连同模型、硬件、batch、输入输出长度、精度、缓存和质量门槛才有意义。

## 怎么读

按层走，每层解决一个问题，不要跳着只记模型名。

| 层 | 核心问题 |
|---|---|
| 01 动机 | 自回归因式分解把什么写进了结构里，扩散换掉的是哪一步 |
| 02 机制 | $Q_t$、吸收态、ELBO 为何长得像加权 MLM、采样时如何揭开与 remask |
| 03 模型谱系 | 从 D3PM 到 LLaDA 2.0、Dream 与 Mercury，分别改变噪声、目标、训练起点或系统实现 |
| 04 结构 | 联合依赖、块扩散与规划式生成怎样处理并行位置之间的一致性 |
| 05–07 工程与判断 | 训练迁移、推理系统、控制和评测如何把机制变成可比较的模型 |

入口是[为什么用扩散做语言生成](./01-导论与阅读路线/1.1-为什么用扩散做语言生成/1.1-为什么用扩散做语言生成.md)：AR 的串行解码、反转诅咒、约束难注入，与两条路线的分野，都在这一篇。

第 02 章给出公式骨架：区分单步转移 $Q_t$ 与累积转移 $\bar Q_t$，解释吸收态为何让腐蚀位置可观察，并把连续时间 ELBO 与加权 MLM 的关系推到损失实现。采样部分区分祖先采样、确定性揭开、低置信重掩和离散流。相同检查点采用不同调度，可能得到不同质量、步数和可修订行为。

第 03、04 章把公式放回模型。D3PM 建立词表上的马尔可夫语言；MDLM 把吸收态目标整理成便于大规模训练的形式；SEDD 改写离散 score 目标；LLaDA 把路线扩展到十亿参数级；块扩散在块间保留因果结构，在块内执行并行去噪。模型名称用于定位工作，噪声核、目标函数、训练起点、注意力图案和采样器才构成可比的技术轴。

第 05 至 07 章处理模型落地。自回归权重改编需要重新处理输入移位、可见性和位置编码；蒸馏减少 NFE，缓存和投机验证减少单步开销；控制方法把序列级约束写进采样过程；评测则固定质量、并行性和系统协议。最终选型不追求一张跨论文总榜，而是判断任务是否需要可修订生成、固定长度填槽、双向条件或高并发吞吐，并检查现有实现能否在目标硬件上兑现。

公开权重与代码、可复算表格和独立复现能够支持机制与数字核验；商业演示与作者自报吞吐可以证明系统已经运行，却不足以推导模型规模和训练机制。论文版本、模型卡与代码提交共同确定结论对应的具体版本，跨版本变化需要重新核对。

扩散语言模型目前仍有几项持续约束。全双向模型在每次去噪中重新处理整段序列，缺少自回归 KV Cache 那样稳定的增量边界；并行预测位置之间的联合分布常被因子化输出近似；固定长度生成便于并行，却需要额外机制处理提前结束和长度扩展；似然上界、生成质量与服务吞吐也使用不同评价口径。它们分别对应缓存、联合建模、长度控制和评测协议，也是后续方法持续改动的对象。

机制与系统之间存在直接对应关系。块大小同时改变概率分解和缓存可用性，重掩策略同时改变纠错机会和网络调用数，自回归权重迁移同时影响训练成本和模型原有能力。把这些变量放在一条链上，才能判断一项改进究竟来自模型、评测协议还是运行时。

「扩散语言模型」至少要给出语言状态、前向噪声或概率路径、训练目标与反向生成过程。只有并行填词、却没有扩散路径的非自回归模型属于邻近方法，不能因为同样支持多位置生成就并入主谱系。新方法也可以沿这四项定位：它究竟改了概率模型、训练估计、采样策略，还是运行时实现。

每篇论文都可用一张最小规格卡记录：状态空间是 token 还是嵌入，前向过程是吸收、均匀还是连续噪声，模型预测干净数据、score 还是 flow，训练从头开始还是继承检查点，推理采用全双向还是块内双向，以及结果能否由公开权重和代码复核。这张卡可以消除同名术语造成的大部分混淆。

一项新工作可以据此定位到概率模型、训练估计、采样策略或运行时，并列出它与自回归基线比较时需要固定的变量。这套坐标用于迁移到后续方法，不依赖某一时点的模型排名。

定义、实验协议与公开实现共同限定每项结论的适用范围。尤其是速度比较，必须同时核对 NFE、单次前向处理的序列长度、批大小、精度、硬件与质量门槛；只报「并行生成」或峰值 TPS，无法说明它在相同输出质量下是否比自回归系统更快。

同名模型若更换采样器、块长或服务实现, 规格卡也要随版本更新; 检查点名称相同, 不代表生成分布、网络调用数和墙钟吞吐保持不变。

## 从概率分解看两条生成路线

自回归模型把序列联合概率写成

$$
p(x_{1:L})=\prod_{i=1}^{L}p(x_i\mid x_{<i}).
$$

这个分解是严格的，任意联合分布都能按链式法则展开。它同时规定了生成顺序：第 $i$ 个 token 在第 $i-1$ 个 token 确定后才有完整条件。训练时可以用 teacher forcing 并行计算所有位置，生成时则必须沿这条链提交。KV cache 恢复了已经计算的历史状态，无法把链式法则本身变成多个未知位置的同时提交。

离散扩散增加一条潜变量路径 $x^0,x^1,\ldots,x^T$。$x^0$ 是数据，$x^T$ 接近简单噪声或全掩码状态，前向核 $q(x^t\mid x^{t-1})$ 逐步破坏信息，模型学习反向核 $p_\theta(x^{t-1}\mid x^t)$。生成概率通过所有中间路径边缘化：

$$
p_\theta(x^0)=\sum_{x^{1:T}}p(x^T)
\prod_{t=T}^{1}p_\theta(x^{t-1}\mid x^t).
$$

并行性来自每一步可以更新多个位置，却不表示这些位置的真实条件联合分布容易计算。常见网络在给定 $x^t$ 后对各位置输出分类分布，采样器再独立选 token。同一步里的两个位置可能各自合理，合在一起却冲突。重掩、块内因果结构、能量校正和显式联合层，都在处理这个缺口。

吸收态掩码路径最容易建立直觉。在时刻 $t$，每个位置以某个概率保留原 token，否则变为 `[MASK]`。模型可以看到哪些位置已被破坏，对它们预测干净 token。若不同时刻按正确权重采样，目标会呈现为加权 masked language modeling。「像 MLM」说的是实现形式，权重、噪声日程与反向核使它成为完整的生成模型。

## 质量与速度是一条前沿，不是两个孤立数字

设扩散生成调用网络 $T$ 次，第 $t$ 次处理 $n_t$ 个有效位置，其粗略算术成本可写成 $\sum_t C(n_t)$。全双向注意力下 $C(n)$ 含有二次长度项；块扩散、稀疏注意力或缓存可改变这个函数。自回归解码调用网络 $L$ 次，KV cache 使每次只新增一个 query，长度成本的结构与全序列反复前向不同。因此 $T<L$ 是扩散获得延迟优势的必要线索，还需要结合每次前向的成本才能得到墙钟结论。

减少 $T$ 通常会改变生成分布。更少步数意味每次确定更多 token，错误位置获得的修订机会更少；若采用低置信重掩，又会增加网络调用或让某些位置迟迟不提交。正确比较应当在多个采样配置上绘制「质量—延迟—吞吐」前沿，而不是各自挑选一个最好数字。

质量门槛要与任务绑定。代码需要执行测试，数学需要答案验证与过程检查，开放问答需要事实性和引用支持。一个采样器在 perplexity 上差异很小，也可能因关键 token 同时冲突而使程序无法运行。速度前沿只有在相同任务成功门槛上才有意义。

批处理会再改变排名。扩散模型单个请求能够并行更新多个位置，自回归服务则擅长用 continuous batching 在不同请求之间填满 GPU。单请求延迟、高并发吞吐、首次提交时间和显存占用可能给出不同胜者。服务章会把这些量分开，避免用一个 TPS 覆盖整个系统。

## 一条从公式走到系统的阅读路径

先在第 02 章把四个对象分清：数据 $x^0$、噪声状态 $x^t$、前向核 $q$ 和学习到的反向核 $p_\theta$。再去看训练损失是预测 $x^0$、噪声、score 还是 flow，这些参数化可以描述相关过程，梯度权重与数值稳定性却不相同。不把这层理清，后面很容易把两种只是符号类似的目标当成同一算法。

然后进入第 03 章，用「状态空间、噪声路径、预测对象、训练起点、反向采样」五轴对齐模型。它们有的从头训练，有的由自回归权重改编；有的每轮处理全序列，有的保留块间因果性。模型大小和最终分数要放在这五轴之后阅读，否则「扩散」这一名字会遮住它们之间的实质差异。

第 04 章解决联合依赖。重点不在记住方法名，而在问一个具体问题：同一轮里多个位置依据什么保持一致？若答案是「下一轮再改」，就要核对重掩和步数；若使用块间条件，就要核对块边界与缓存；若加入联合能量或 copula，就要核对额外目标是否真的参与采样。

最后再读训练迁移、蒸馏、推理和评测。训练成本回答怎样得到检查点，NFE 和单步成本回答怎样使用它，任务指标则回答生成结果是否可用。三个问题串起来，才能判断一条路线的优势是来自概率模型、更多训练、更少网络调用，还是更好的运行时。

## 几组容易混在一起的概念

**并行预测与并行提交是两件事。** 扩散网络一次前向会为多个位置输出分布，采样器可以只提交其中高置信的一部分，并将其余位置保持掩码。一次预测 $L$ 个位置，不表示这一轮必须提交 $L$ 个 token。速度由前向次数、每次成本和每轮提交量共同决定，质量则受错误提交后是否允许撤回影响。

**双向可见与联合建模也不相同。** 每个掩码位置能看到左右上下文，可以利用双侧条件；若输出头对各位置分别 softmax 并独立采样，当轮仍使用了条件独立近似。网络隐状态中可能编码了位置关系，最后采样操作却可能破坏它。多轮去噪能通过重新条件化修正冲突，所需步数正是联合近似的一部分代价。

**可修订与一定会自我纠错也要分开。** 重掩策略只有在置信度能识别错误时才会选中它。高置信错误可能很早提交并一直保留，低置信的正确 token 反而被多次重写。因此除了最终正确率，还应测量首次提交的正确率、错误撤回率、正确 token 被误撤回的比例和各位置重写次数。

**固定长度画布与真实长度建模同样有差异。** 一些方法预先创建 $L$ 个掩码位置，再在其中生成 EOS 或空位；另一些方法使用块或动态扩展。若 EOS 后仍有普通 token，是否计入输出，是否参与后续注意力，会改变训练与采样。对变长任务报告预分配上限、最终有效长度和超长失败，才能判断固定画布带来的浪费和截断。

**似然、生成质量和判别式能力回答不同问题。** 变分上界或 score 目标可用于训练和比较概率拟合，其松紧受参数化与噪声路径影响。生成任务还受采样步数、调度和随机性影响。一个检查点用线性探针或分类题取得高分，也不证明自由生成能稳定保持这些知识。所以第 07 章会将损失、任务成功、并行性与服务指标分开，再观察它们在相同配置下的关系。

这些区分最终都要落到可复算记录：检查点、噪声日程、采样器、步数、随机种子、有效长度、硬件和原始输出必须同时保留。缺少任一层，结果变化都可能被错归给模型本身。
