# 从自回归改编:DiffuLLaMA,Dream,LLaDA 2.0

LLaDA 8B 证明可以从噪声训到和 LLaMA3 同一张表.它没有证明每训一个扩散模型都应该付 13 万 H800 小时.开源 AR 权重已经把语言几何学进参数里.改编要解决的是两件结构冲突:因果掩码对双向去噪,以及「输入永远干净,预测下一个」对「输入是脏的,预测 $x_0$」. 四条工作走同一条河的不同河段.DiffuLLaMA 证明 7B 改得动.Dream 把移位和噪声日程做细,并交出和 Qwen2.5 7B 同协议的表.LLaDA 2.0 把块大小当课程接到 100B.Fast-dLLM v2 把 token 预算收到约 1B,代价是全双向填空被收进块内.没有一条改了吸收态 $Q_t$ 的定义.

## 1. 冲突在哪

AR 模型用位置 $i$ 的隐状态 $h_i$ 预测 $x_{i+1}$,并且无法看见右侧上下文.扩散模型通常用位置 $i$ 的隐状态还原 $x_i$,同时利用左右两侧仍可见的 token.DiffuLLaMA 引用的早期改编实验表明,直接移除因果掩码并切换为掩码交叉熵会严重损害基座能力. 两套几何叠在同一组权重上.注意力掩码决定「这一格能看见谁」.预测头的移位决定「这一格的向量对哪个词负责」.噪声日程决定「输入有多脏」.三件事可以分开拧.早期失败往往是三件一起拧:掩码一步全开,损失改去预测当前格,所有位置共用一个很大的 $t$.AR 特征来不及搬家,梯度先把已经学好的下一词方向冲掉.

![自回归检查点通过输入移位,注意力掩码与噪声训练改编为扩散模型](../images/fig-ar-shift-adapt.png)

> 图 1:改编保住 AR 已经学好的移位,$h_i$ 仍瞄准 $x_{i+1}$;改的是注意力掩码和输入上的噪声. 图 1 解析:

- **上行 $h_i$ (AR) → predict $x_{i+1}$**:teacher forcing 的几何.每层隐状态的职责是下一个词,不是当前词.
- **下行 left / right visible tokens**:掩码退火之后,位置 $i$ 可以看见左右仍干净的上下文.这是扩散要的感知.
- **keep shift**:损失仍按 $h_i$ 对 $x_{i+1}$ 算.Dream 把这叫 Shift Operation.不加移位,等于让已经对齐的预测头去猜另一个位置,继续预训练要重新学位置几何.
- **图里没画噪声日程**.DiffuLLaMA 用掩码率退火;Dream 再给每个掩码位按周围可信上下文重标定有效 $t$.那是第二条旋钮.

dKV-Cache 的消融从反面证明移位不是装饰.Dream 主实验用 Un-Shift 对齐改编后的头;若推理时改成 Right-Shift,GSM8K 会被打到 32.68.缓存论文测的是解码几何,不是另训一个模型,但方向清楚:头和位置一旦对错,分数可以腰斩.细节见[推理加速](../../06-推理加速与系统/6.4-kv缓存与推理加速/6.4-kv缓存与推理加速.md).

### 1.1. AR 检查点究竟已经学会了什么

给定 token 序列 $x=(x^1,\ldots,x^L)$,标准 AR 目标为

$$
\mathcal L_{\mathrm{AR}}
=-\sum_{i=1}^{L-1}
\log p_\theta(x^{i+1}\mid x^{\leq i}).
$$

参数里存下来的信息至少分成三层.词嵌入与 MLP 学到词义、搭配和事实;注意力头学到在因果可见集里搬运信息;输出头与残差流形成「位置 $i$ 负责预测位置 $i+1$」的对齐.改编希望保留第一层,逐步改变第二层,并明确选择是否保留第三层. 这种分解不是严格的模块隔离.一个注意力头可能同时编码事实和方向,MLP 也会依赖当前位置的条件分布.所以打开双向注意力时无法只修改「方向开关」而不扰动知识.课程的意义在于让参数沿连续路径重新分工,避免一次梯度把多个层面同时推离原解. 可以用函数距离描述要保留的行为.令 $f_{\theta_0}^{\mathrm{AR}}(x^{\leq i})$ 为初始检查点 logits,$f_\theta^\mathcal M(\widetilde x)$ 为新注意力图案下 logits.改编早期希望在接近 AR 的输入上满足

$$
D_{\mathrm{KL}}
\left(
p_{\theta_0}^{\mathrm{AR}}(\cdot\mid x^{\leq i})
\,\middle\|
p_\theta^\mathcal M(\cdot\mid \widetilde x)
\right)
\text{ 较小},
$$

同时逐步降低掩码恢复损失.这两个目标可能冲突,课程、蒸馏或混合损失都在安排冲突出现的速度.

### 1.2. 目标错配不止一条轴

AR 与掩码扩散的差异可以写成四条轴.第一是目标位置:预测下一格或恢复当前/移位后的目标.第二是条件集合:左前缀或随机双向可见集合.第三是输入质量:teacher forcing 的 token 全部来自数据,扩散输入包含 `[MASK]`.第四是部署状态:AR 逐步增加前缀,扩散反复更新画布. 只改损失会留下条件错配.例如仍用因果注意力,却要求位置恢复同一格,当前位置输入若是 `[MASK]`,模型只能靠左侧猜,得到的是因果填空器.只打开双向注意力而保留纯 next-token 目标,位置 $i$ 可以偷看右侧的 $x^{i+1}$,损失会被直接泄漏.所以注意力、输入腐蚀与标签移位必须成套定义. 一种安全写法是先明确每个 query 位置 $i$ 的可见集合 $V_i$,输入 token $\widetilde x$,以及监督标签 $y_i$.训练项为

$$
-\log p_\theta(y_i\mid \widetilde x^{V_i},t).
$$

AR 对应 $V_i=\{1,\ldots,i\}$、$y_i=x^{i+1}$;无移位扩散对应双向 $V_i$、$y_i=x^i$ 且 $i$ 被掩;保留移位的改编则令隐藏状态与 $x^{i+1}$ 对齐,但条件图案允许右侧干净 token.三元组写清后,泄漏与错位更容易发现.

### 1.3. 预测头对齐为什么会形成路径依赖

AR 输出矩阵 $W_{mathrm{out}}$ 接收 $h_i$ 并把正确类别 $x^{i+1}$ 的 logit 推高.经过大规模训练,$h_i$ 的坐标系与 $W_{mathrm{out}}$ 共同适应这一职责.若改编第一步改成用 $h_i$ 预测 $x^i$,标签整体左移一格,同一表示立即收到不同方向的梯度. 设旧目标梯度为 $g_{mathrm{AR}}$,新目标梯度为 $g_{mathrm{diff}}$.两者余弦

$$
\rho=\frac{g_{mathrm{AR}}^\top g_{mathrm{diff}}}
{\lVert g_{mathrm{AR}}\rVert\lVert g_{mathrm{diff}}\rVert}
$$

若在早期大量参数上为负,一步切换会产生遗忘.保留 shift 让新目标在位置职责上接近旧目标,提高局部梯度一致性.它不会让两种任务完全相同,因为条件集合和输入噪声仍然改变. 移位也要与推理保持一致.训练时位置 $i$ 的输出对应 $x^{i+1}$,采样器读取 logits 时必须做同样索引映射.缓存实现若把 hidden state 当作预测当前格,会出现整体错一位的静默错误;张量 shape 全部正确,任务质量却大幅下降.

### 1.4. 新增双向边改变了什么

因果 attention mask 让第 $i$ 个 query 只能读取 $j\leq i$.打开双向后,新增的是 $j>i$ 的边.初始化权重虽然从未在这些边上训练,query 与 key 投影却已经能处理对应 token 表示.这些边沿用已有打分函数,变化发生在函数从未见过的位置对上,并没有额外引入一组随机 attention 参数. 这一点解释了改编为何可行:词义投影、RoPE 和注意力打分并非全部重学.也解释了为何直接全开危险:新增边数量从约 $L(L+1)/2$ 一次增至 $L^2$,每层残差统计都会变化.右侧 token 还可能直接包含标签,若腐蚀和 mask 配置不严,模型会走复制捷径. 可以定义训练进度 $u\in[0,1]$ 下的可见半径 $r(u)$,让 query $i$ 读取到 $i+r(u)$.另一种做法是随机开放一部分右向边,概率从 0 增到 1.前者控制依赖距离,后者控制边密度.两者都建立连续路径,归纳偏置不同.

AR teacher forcing 的每个输入位置都来自真实数据.掩码扩散输入为

$$
\widetilde x^i=
\begin{cases}
x^i,& b_i=0,\\
m,& b_i=1,
\end{cases}
\qquad b_i\sim\operatorname{Bernoulli}(t).
$$

特殊 token $m$ 的嵌入若是新增参数,它没有 AR 预训练历史.即使复用词表中已有 mask token,基座也未必在生成训练中频繁见到.高噪声时大量位置共享同一个 embedding,残差统计与 AR 自然文本差异很大. 改编课程通常先从小掩码率开始,让大部分输入仍落在基座熟悉的流形附近.随着模型学会从 $m$ 与双向锚点恢复 token,再提高噪声.若第一步就接近全掩码,所有层同时面对新 embedding 分布、弱语义条件和新目标,继承优势会迅速缩水. 输入错配还能用表示漂移测量.对同一干净样本与轻度掩码样本,比较各层隐藏状态的 centered kernel alignment、余弦或线性 probe.若浅层在极少掩码下已经完全漂移,mask embedding 或归一化统计可能需要单独处理.

### 1.5. 改编成功的最低证据

仅看扩散任务提升不足以证明继承成功.一个模型可能忘掉基座后重新学会较弱的去噪.至少需要三条曲线:原 AR 能力保留、masked-token 风险下降、自由生成质量上升.三者随训练 token 的变化能区分迁移与重训. 还应有从随机初始化训练的同结构对照.在相同继续训练预算下,AR 初始化若始终领先,说明预训练知识真正被利用;若很快收敛到同一点,初始化只提供短暂优化优势;若后期反而更差,AR 方向性可能成为负迁移. 第三条证据是参数距离与功能距离.权重 L2 很小不保证功能相近,因为 attention mask 已改变;权重变化大也不等于知识丢失.用保留任务、探针和输出 KL 共同判断,比只看参数范数可靠.

经过 SFT 或 RL 的 AR 模型不仅存有知识,还形成提示模板、拒答边界与输出风格.扩散转换改变生成状态,这些行为是否保留取决于继续训练数据与目标.若只用预训练文本转换,指令对齐可能逐渐淡化. 用 base 模型改编后再重新 SFT,证据最清楚:预训练知识迁移与指令对齐分开.直接从 instruct 模型改编可以省后训练,却把遗忘、模板适配与扩散目标混在一起.两条路线回答不同成本问题. RL 形成的序列级偏好尤其脆弱.掩码去噪每一步预测多个位置,原 AR 策略的 token 级条件分布不再对应同一轨迹.保留最终回答风格不等于保留原策略概率,后续偏好优化往往还要重新适配.

若位置 $i$ 的 hidden state 负责预测 $x^{i+1}$,同时双向 attention 允许它直接读取未掩的 $x^{i+1}$,模型可以复制答案.正确 mask 必须保证目标 token 在对应 query 的可见集中被遮住,或使用互补图案切断该边. 泄漏的症状是训练 loss 很快接近零,而从全掩码生成很差.局部填空测试若也把目标保持可见,还会虚假通过.最小测试应随机修改目标 token 输入,检查对应 logit 是否直接随输入复制. 多层网络里泄漏不只是一条直接 attention 边.目标 token 可能先写入邻居 hidden state,下一层再回流到 query.因此 mask 需要在所有层保持信息隔离,单层图示不够. 掩码率可以从输入中统计,长序列上 $\widehat t=N_m/L$ 接近真实 $t$.模型可能无需显式时间 embedding 也能判断噪声强度.短序列、固定掩码数或局部重标定时,同一图案对应多个时间,显式条件更有价值.

新增时间网络通常随机初始化,是转换中少数完全没有 AR 先验的模块.其输出若直接调制每层归一化,早期可能扰动全部残差流.零初始化调制或从弱幅度开始,能让起点更接近基座函数. 可通过打乱时间标签检验依赖.若输出几乎不变,模型主要从 mask 图案推断;若损失明显恶化,时间条件承担真实信息.上下文自适应 token 时间还需按位置做同样检验. 公开权重通常没有原预训练优化器状态.继续训练从新的 Adam 动量开始,即使参数继承,最初更新方向也与原训练不同.这会放大刚切目标时的梯度尖峰.

若能获得优化器状态,旧动量针对 AR 风险,直接继承也可能把参数推向旧方向.清零与继承各有风险.更稳妥的证据来自短 warmup、梯度统计与两种状态消融. 权重衰减同样影响知识保留.大规模继续训练中,即使任务梯度小,衰减也会让参数持续离开初始点.转换预算越长,这一累积越明显. 先用短序列、低噪声和简单填空,再进入长序列与高噪声,可以减少初期状态变化.但简单数据可能让模型过度适应局部模式,延迟全局能力学习.结构课程与数据课程需要共同设计. 混合 batch 中同时放 AR 视图与扩散视图,能让每个更新看到保留与适配信号.分阶段先 AR 后扩散则更容易产生遗忘.相同总样本的顺序不同,优化轨迹也会不同.

可随机打乱课程顺序作反例.若最终结果完全相同,所谓课程可能只增加训练量;若平滑路径稳定领先,它才提供超出数据数量的价值. 把 AR 最优点记为 $\theta_A$,扩散风险最优点集合记为 $\Theta_D$.转换难度与参数欧氏距离未必一致,更相关的是低损失路径是否存在.若存在连续曲线 $\theta(u)$,使两类风险沿途都不剧烈上升,课程可以低成本移动. 模式连通性只能作为视角,目前没有针对大规模 AR 到扩散给出普遍保证.注意力图案变化还会改变函数定义,参数空间连通不足以证明训练稳定. 实证课程是在寻找这样的低损失路径.DiffuLLaMA、Dream 与 WSD 分别控制不同结构变量,共同证据说明某些模型族存在可走路径,没有证明所有架构都存在.

## 2. DiffuLLaMA:退火掩码 + 保持移位

Gong 等人(ICLR 2025,arXiv:2410.17891)做三件事. 把 AR 目标与吸收态扩散目标写成可以衔接的形式.连续时间极限仍是掩码位置上的加权交叉熵,和 MDLM / LLaDA 的 $1/t$ 损失同族.改编不是换一种 $Q_t$,是让已经存在的 next-token 目标平滑接到这条 ELBO 上. 注意力掩码退火:训练过程中逐步把因果掩码放宽成双向,而不是第一步就全打开.左边始终可见,右边的可见范围随训练步变宽.直观上,模型先继续做它会的续写,再慢慢利用未来上下文去填空. 继承移位:损失仍按 $h_i$ 对 $x_{i+1}$ 算.扩散在感知上是还原信号,在「哪一格对齐哪一个词」上继续用 AR 已经学好的几何.

数据:不到 200B token,把 GPT-2(127M–355M)和 LLaMA2 7B 变成 DiffuGPT / DiffuLLaMA.能力上补了 infill(不必把填空改写成从左到右),速度上无条件生成 1024 token,256 步时与 AR 同级.这是「改编可行」的第一张 7B 成绩单,不是 2025 年最强开源 7B.词表,分词器,大部分层结构都沿用基座;新学的是「输入可以是 `[MASK]`」这件事.

### 2.1. 从 AR 风险连续走向扩散风险

可以把改编目标抽象成

$$
\mathcal L_u(\theta)
=(1-\lambda_u)\mathcal L_{\mathrm{AR}}(\theta;\mathcal M_u)
+\lambda_u\mathcal L_{\mathrm{diff}}(\theta;\mathcal M_u,q_u),
$$

其中 $u$ 是训练进度,$\mathcal M_u$ 表示注意力图案,$q_u$ 表示噪声分布,$\lambda_u$ 控制新旧风险混合.实际论文未必显式写成这一式,但退火的作用就是让三个对象避免同时跳变. 若 $\lambda_u$ 先升、注意力仍因果,模型先学因果掩码恢复;若右向边先开放、输入仍干净,next-token 标签可能被未来 token 泄漏.更稳妥的路径要让监督标签在新增可见边下仍不可直接读取,并让噪声强度与双向范围协同增加. 连续路径只提供局部稳定性,没有保证终点最优.课程太慢,大量预算仍花在 AR 附近;太快,继承表示来不及适配.应以固定总 token 比较不同课程,而非让慢课程顺便训练更多数据.

### 2.2. 掩码率课程与注意力课程不是同一件事

掩码率课程改变输入中 $m$ 的数量.注意力课程改变每个 query 的可见集合.两者可以独立:小掩码率加全双向会让模型容易利用右侧真值;高掩码率加因果注意力则接近困难的左到右缺词恢复. 把右向可见半径记为 $r$、掩码率记为 $t$.训练状态落在二维平面 $(r,t)$ 上.AR 起点近似 $(0,0)$,全双向扩散终点接近 $(L,t\sim U[0,1])$.一条课程是先沿 $t$ 轴增加噪声,再开右向边;另一条先扩大 $r$,同时保证标签位置被掩.路径不同,梯度和捷径也不同. 实验应画二维消融,至少包含「只退火噪声」「只退火注意力」「二者同步」.若只报告最终完整配方,无法判断主要收益来自避免泄漏、减少输入漂移还是保留位置几何.

### 2.3. 词嵌入与输出头如何继承

许多 LLM 绑定输入 embedding 与输出矩阵.新增 `[MASK]` 后,需要给它一个新行向量.随机初始化会在高掩码率时大量注入同一个随机方向;用已有特殊 token 均值或小范数初始化可以减轻分布冲击,但最优策略取决于基座. 若词表完全沿用,所有普通 token 的输入与输出参数可直接加载.这部分承载大量词义和频率信息.改换 tokenizer 会同时破坏 embedding、输出头、序列长度分布与位置统计,继续训练预算会显著上升.严格意义上的低成本改编通常默认 tokenizer 不变. 绑定权重还有一个张力:mask embedding 作为输入需要有表达力,输出分布通常不希望生成 `[MASK]`.可以在 softmax 前把 mask logit 置为负无穷,同时保留其输入行.若完全共享且不做输出约束,训练可能浪费概率质量给特殊状态.

### 2.4. RoPE 与双向可见性

RoPE 原本在因果模型中编码相对位移,数学形式可以计算正负方向.因果训练只使用 query 读取当前及左侧 key,所以右向相对位移虽可计算,权重未在同样分布上优化.开放右向注意力后,同一频率基底开始服务另一半方向. 这不要求重新初始化 RoPE,却会产生适配任务.短距离右向关系通常较易迁移,长距离右向关系更陌生.按可见半径逐步扩大课程,可以理解为先学习小正向位移,再扩展到长距离. 长上下文扩展还会与改编纠缠.若同时修改 RoPE scaling、上下文长度与注意力方向,性能变化无法归因.最好先在基座原长度上完成方向适配,再单独扩上下文,或提供完整二维消融.

RMSNorm 没有运行时均值统计,不会像 BatchNorm 那样积累旧分布,但残差幅度仍取决于 attention 输出.开放右向边后,softmax 候选数增加,注意力熵和 value 聚合都可能变化.大量 mask embedding 还会让输入 token 多样性下降. 设某层 AR 隐状态分布为 $h\sim P_0$,改编状态为 $h\sim P_u$.即便参数变化很小,$P_u$ 也会因输入和 mask 改变而移动.后续 MLP 在未见区域工作,可能放大漂移.低掩码率与小范围双向课程让 $P_u$ 缓慢移动. 监控每层残差 RMS、attention entropy 与 MLP 激活分位数,能定位最先失稳的层.若浅层因 mask embedding 爆开,优先处理输入;若深层随着右向范围增加才漂移,注意力课程更相关.

### 2.5. 小学习率为什么有用又不够

对预训练最优点 $\theta_0$,新目标梯度一般不为零.一步更新

$$
\theta_1=\theta_0-\eta g_{mathrm{diff}}
$$

中,较小学习率 $\eta$ 限制参数距离,减缓遗忘.但若新旧梯度长期冲突,再小的步长积累后仍会离开原函数.学习率只能控制速度,课程与目标设计决定方向. 还要区分层.Embedding、attention 与 MLP 对新任务的需求不同.冻结底层可能保留词义,却阻止 mask 状态适配;只训 attention 可能学会双向,输出头对齐仍旧.分层学习率可以控制变化,需要用消融证明没有把必要适配冻结掉. 最佳学习率通常随模型规模、batch 与 token 预算改变.从 1B 扫描直接搬到 7B 只能作为起点,不能代替大模型消融.没有公开逐点曲线时,正文应保留这一证据边界.

### 2.6. DiffuLLaMA 结果能支持哪些判断

论文覆盖 GPT-2 到 LLaMA2 7B,并用少于 200B token 继续训练,直接支持「AR 权重可以作为扩散模型有效初始化」.它还展示语言建模、推理、常识、infill 与指令能力,说明转换并未只得到玩具填空器. 这些结果没有证明任意 AR 检查点都能以相同比例预算转换.不同 tokenizer、架构、后训练程度与上下文长度会改变难度.也没有证明小于 200B 是理论下限;它是该配方和模型族的实证预算. 与 AR 竞争的速度结论同样依赖长度、采样步数与实现.1024 token、256 步的无条件生成是一个工作点,不能外推到短对话、批量 serving 或全双向长上下文.改编成功与部署最优是两项结论. 在扩散改编中加入 AR loss 能抑制遗忘.总目标为

$$
\mathcal L=\mathcal L_{\mathrm{diff}}+\beta_u\mathcal L_{\mathrm{AR}}.
$$

$\beta_u$ 较大时,模型继续优化旧任务,右向依赖和高噪声恢复学得慢;完全为零时,有限数据容易漂移.一种课程是早期较大、后期逐渐减小,让保护先强后弱. AR loss 的视图必须保持因果,扩散 loss 的视图使用腐蚀输入.若在同一双向前向上算 next-token,未来 token 会泄漏.通常需要两种 attention mask 或精心构造的互补 mask. 是否需要保留 loss 可以由遗忘曲线决定.若原能力在纯扩散训练中自然保持,额外 AR 项只浪费预算;若快速下跌,它提供直接锚点. 冻结 embedding 与底层层可以限制表示漂移,只让高层学习新条件.这种做法假设底层词法特征与方向无关.实际上浅层 attention 也受因果 mask 训练,mask embedding 更需要底层适配.

逐层解冻是一种课程:先训练输出头与高层,再向下开放.它减少初期自由度,也可能让高层先在错误底层特征上过拟合.相反,只冻结 MLP、训练 attention 更直接针对可见性变化,却可能限制知识重组. 最可靠的做法是结合梯度范数和线性 probe选择,而非默认「底层通用」.不同架构和规模的最佳冻结边界可能不同. LoRA 只在低秩子空间更新权重,转换成本低,但 AR 到全双向扩散涉及大量 attention 关系与输入状态变化,所需函数改变量可能不低秩.小块扩散或许更适合 PEFT,全序列转换证据更弱. 可以比较全参更新与不同 rank LoRA 的 masked NLL、基座保留和自由生成.若提高 rank 后持续逼近全参,转换主要受适配容量限制;若很早饱和,瓶颈在目标或数据.

即便 LoRA 能学会去噪,部署还要合并或加载 adapter,不会自动解决多步推理成本.PEFT 只回答训练参数更新量. 一条长度 $L$ 的文本在掩码率 $t$ 下平均产生 $Lt$ 个去噪目标.论文报告的原始 token 数没有直接等于目标 token 数.不同时间采样、序列长度和重复重掩会改变有效监督. 同一文本多次采不同 mask,提供多种条件视图.这可能提高数据利用,也让「200B token」包含大量重复原文访问.比较转换预算时需要说明计数的是输入 token、目标 token 还是唯一语料. FLOPs 更进一步包含全双向 attention 与双视图损失.小数据方法可能每 token 计算更多,数据减少不等于训练时间同比减少.

标准去噪训练只看真实文本腐蚀状态,推理会产生含模型错误 token 的状态.转换模型尤其容易把错误 token 当成可靠 AR 锚点.将模型采样中间状态加入训练,可以覆盖这类分布. 回放目标需要真实 $x_0$ 配对,可从训练样本启动模型轨迹并保存中间状态.成本是额外采样,且早期模型状态很差,可能把训练拖向无意义区域. 按课程逐步增加回放比例更稳.如果回放显著改善长轨迹、teacher-forced masked NLL 不变,说明瓶颈确实是状态分布偏移. 训练 loss 平台不代表转换完成.至少要看高噪声与低噪声各桶、右侧条件利用、全掩码生成、基座保留和目标采样器.任一项仍在明显改善,继续训练可能有价值.

还可测试对课程变量的鲁棒性.完成的模型应在邻近块长、掩码率和步数上平滑,而非只在训练终点图案有效.尖锐依赖表明过拟合课程. 停止点最终取决于质量—成本前沿.若继续训练只改善全双向填空,产品只做块续写,额外预算没有实际回报.

## 3. Dream:同一套移位,加上按上下文改噪声

Dream 7B(港大 NLP + 华为诺亚,arXiv:2508.15487)从 Qwen2.5 7B 的权重起步,不是从噪声起步.继续预训练语料作者写成 580B token,Table 1 的 Training Tokens 一格写成 0.6T,同一数量级.Fast-dLLM v2 引用约 580B 来对照自己的 1B,出处要写清. 两条关键设计.AR 初始化加移位,使扩散训练不把 $h_i$ 的职责改去预测 $x_i$.context-adaptive token-level noise:每个掩码位的有效噪声水平按周围还有多少可信上下文重标定,避免所有格子共用同一个 $t$.周围已经很干净时,这一格不该再被当成「几乎全掩」来训;周围也全是掩码时,这一格的有效噪声应该更高.损失仍是吸收态加权交叉熵. Table 1 带 $*$ 的四列(Dream,LLaDA 8B,Qwen2.5 7B,LLaMA3 8B)是作者同一套协议.Dream Base:MMLU 69.5(5)对 Qwen2.5 的 71.9;GSM8K 77.2(8)对 78.9;HumanEval 57.9(0)对 56.7.规划任务上差距拉大:Sudoku 81.0 对 21.0,Countdown 16.0 对 6.2,Trip planning 17.8 对 3.6.LLaDA 8B 在这张表上 GSM8K 是 70.9(8-shot),HumanEval 是 32.9,和 LLaDA 原论文 Table 1 的 4-shot 70.3 / 0-shot 35.4 不是同一格.报「Dream 超过 LLaDA」时,用 Dream 的 $*$ 表.

### 3.1. Shift Operation 保存的是职责映射

Dream 从 Qwen2.5 7B 初始化时,保留 AR hidden state 与下一 token 的职责关系.设 Transformer 对输入产生 $h^1,\ldots,h^L$,AR 头计算

$$
p_\theta(x^{i+1}\mid x^{\leq i})
=\operatorname{softmax}(W_{mathrm{out}}h^i).
$$

扩散输入中有随机掩码,但监督仍把 $h^i$ 对齐到 $x^{i+1}$.要预测某个被掩 token $x^j$,读取的是与该 token 约定对应的 hidden position.这让预训练输出头和残差坐标继续承担熟悉任务. 移位会使序列边界需要单独处理.最左或最右位置缺少对应 hidden state 时,要用 BOS、占位位置或裁剪定义.训练与推理必须使用同一映射,否则只在边界出现的错误会被长序列平均指标掩盖. 保留职责不等于保留因果性.同一个 $h^i$ 在双向 attention 下能读取右侧干净 token,条件信息已经改变.移位只减少标签坐标的跳变,没有把 Dream 变回 AR.

### 3.2. 上下文自适应 token 级噪声

全局时刻 $t$ 给整条序列同一个名义噪声率,各个掩码位置的实际信息却不同.位置 $i$ 周围若有大量干净 token,恢复任务较容易;若它落在连续 mask 区域中央,可用条件少得多.用一个 $t$ 作为所有位置的难度标签会产生错配. 可以把局部可见信息摘要记为 $c_i(x_t)$,再构造有效时间

$$
\widetilde t_i=\phi(t,c_i(x_t)).
$$

$\phi$ 应让上下文更少的位置对应更高噪声语义,上下文丰富的位置对应更低噪声语义.模型或损失使用 $\widetilde t_i$ 后,相同全局掩码率下的不同位置得到不同条件. 这种重标定不会凭空增加信息.它帮助网络区分任务难度,代价是时间条件与标准吸收态路径的对应更复杂.若 $\widetilde t_i$ 只用于网络条件,前向核仍由全局 $t$ 采样;若还进入损失权重或反向率,概率目标需要相应说明.

### 3.3. 局部信息量怎样测

最简单的代理是窗口内干净 token 比例.半径 $w$ 内可见数量为

$$
c_i=\frac{1}{2w}
\sum_{0<|j-i|\leq w}\mathbf 1[x_t^j\neq m].
$$

它便宜,却把所有 token 当作同等信息.函数名、数字与实体可能比标点提供更多约束;距离较远的配对符号也可能关键. 更丰富的代理可以来自 attention、条件熵或隐藏状态.但若用当前模型预测来定义噪声,训练目标会随参数变化,稳定性与计算成本都更复杂.固定的可见比例更容易复现,表达力有限. 可证伪实验是固定名义 $t$ 与掩码数量,构造「掩码集中成块」和「掩码均匀分散」两种图案.若重标定有效,两类状态的恢复损失差距应缩小.只看最终综合基准无法定位这一机制.

### 3.4. AR 初始化为何会形成负迁移

AR 模型擅长用左侧预测下一 token,可能对右侧信息利用不足.双向去噪训练早期,新增右向边的 attention 权重由同一 QK 投影计算,模型仍可能偏向熟悉的左侧.这是一种方向性惯性. 另一方面,AR 知识提供强语言先验.高噪声输入中右侧也大多是 mask,左侧已知 token 仍然有用.继承优势与方向惯性同时存在,净效果取决于任务和训练预算.填中间缺口需要主动利用右侧,前缀续写与原任务更接近. 可以用镜像任务测方向偏好.固定同一目标 token,分别只给等量左侧与右侧上下文,比较 NLL;再给两侧同时可见,测是否获得互补收益.随训练进度画曲线,能看到模型何时真正学会右向条件.

改编初期主要保留:小学习率、轻噪声和接近因果的条件让模型维持基座函数.中期主要重组:双向边、mask embedding 与新目标迫使 attention 和 residual stream 重新分工.后期主要专化:模型在目标采样分布上优化,原始 AR 能力可能继续下降. 若只在终点测一次,无法知道能力是短暂崩塌后恢复,还是持续保留.周期性保存检查点并测试 AR perplexity、双向填空与自由扩散生成,可以画出迁移轨迹.某个终点相同的课程,中间路径可能决定优化是否穿过不可恢复区域. 遗忘也有选择性.常识事实可能保留,精确 next-token 校准下降;数学和代码的逐步结构可能对方向更敏感.基准应覆盖知识、语言建模、infill、推理和长程一致性,单一 MMLU 无法代表全部继承.

每步参数位移约为 $\eta\lVert g_u\rVert$.课程越快,新旧任务梯度差越大;相同学习率造成更猛烈的功能变化.所以「较小学习率」和「缓慢退火」并非独立建议,二者共同控制单位训练 token 的漂移. 可以定义课程变量 $a(u)$,例如右向范围或块长.局部变化速度为 $|a'(u)|$.一个粗略稳定性量是

$$
R_u=\eta_u|a'(u)|\lVert g_u\rVert.
$$

$R_u$ 太大时,模型在来不及适配的情况下进入新任务区域.它不是严格收敛定理,却提示实验需要联合扫描学习率与课程,不能各自单变量调优后简单组合. warmup 还要区分优化器 warmup 与结构课程 warmup.前者提高学习率,后者改变任务.若两者同时快速上升,最脆弱阶段叠在一起;错开可能更稳.论文若只给最终配方,这类交互仍属于实证边界.

### 3.5. Dream 的表格能说明什么

Dream 7B 使用 AR 初始化与上下文自适应噪声,论文展示通用、数学、代码与规划任务.同协议表支持它相对早期扩散模型的整体提升,规划任务差距也支持双向迭代在特定结构任务上的潜力. 整包结果不能把每个提升分配给单一组件.初始化、shift、噪声重标定、数据和训练预算共同变化.小尺度消融说明方向,7B 终点表证明完整配方有效;两类证据之间仍有尺度外推. 与 Qwen2.5 的差距还混入后训练.若 Dream 侧只有 SFT,对照侧含 SFT 与 RL,代码和数学分数不能单独归因于生成范式.基础模型、后训练算法与采样器需要分别对齐.

数独、路径和 Countdown 需要多个位置满足全局约束.扩散画布允许先形成远端锚点再修订中间位置,AR 则按前缀承诺.这一结构差异提供合理机制假说,不等于所有规划提升都由可修订性造成. 验证方式是记录生成轨迹.若正确答案中远端关键位置在早期出现,随后中间逐步协调,支持全局画布解释;若模型仍近似左到右揭开,提升可能来自数据或基座. 再给 AR 基线显式草稿与修订机会.若差距消失,优势属于规划接口;若扩散仍在同计算下领先,生成结构贡献更可信. 标准扩散的时间 $t$ 对应全局前向核.若每个位置使用 $\widetilde t_i$,联合前向可以解释为位置异质核,前提是每个位置日程单调且反向后验一致.若 $\widetilde t_i$ 依赖当前上下文,路径可能随状态变化.

工程上可以只把 $\widetilde t_i$ 当网络条件或损失重权,不声称它定义新的严格前向链.这仍可能提高预测,似然解释需要保守.阅读论文时应分清它进入噪声采样、时间 embedding 还是 loss weight. 证据不足时,最稳妥的结论是「上下文重标定改善了完整配方」.不能从最终表推出新的核拥有更紧 ELBO. 若所有输入、标签、位置编码与输出读取一起平移,某些 shift 只是索引重命名.实际实现往往保留绝对位置与边界 token,缓存也按物理位置存储,几种方案不再严格等价. 边界处的 BOS/EOS、RoPE phase 与 block offset 都会破坏平移对称.因此「right-shift」「un-shift」不能只看名称,要写清隐藏位置 $i$ 对应哪个目标、读取哪些 key、缓存在哪个索引.

一个四 token 手算即可验证:列出每个 query 的输入 token、可见集合和标签.若某个标签直接出现在集合中,存在泄漏;若生成时读取不同位置,存在错位. 自然语言局部冗余高,周围干净 token 对恢复帮助大;代码中变量引用和括号依赖可能更远;数学推理的关键条件分布不均.同一个局部信息代理在不同语料上准确性不同. Dream 的配方在其训练混合上有效,迁到高代码比例模型时应重新测窗口、噪声桶与右侧利用.若直接复用重标定,可能把远程依赖位置误判为高噪声. 按领域报告 masked NLL 与采样轨迹,能判断自适应噪声是否跨域.总平均提升可能来自占比最大的自然语言.

### 3.6. 从 Dream 继续做后训练

预训练转换完成后,SFT 仍要使用与生成结构匹配的回答掩码目标.直接拿 AR SFT loss 会把模型重新推回左到右条件.保留 shift 时,标签映射也必须沿用. 偏好优化更复杂:响应概率由整条扩散轨迹或其界定义,无法直接套用逐 token AR logprob.若用近似 token 分数,优化对象与实际采样策略可能错位. 所以基础模型接近 AR 只证明预训练转换可行.后训练差距属于独立研究问题,不应从 base 表自动外推到 instruct 能力.

## 4. LLaDA 2.0:块大小当课程

2.0 从 Ling-mini / Ling-flash 的 AR MoE 起步,把 AR 看成 $B=1$ 的块扩散.WSD 在 warmup 阶段增大块,stable 阶段扩展到全序列,decay 阶段再收回部署块.100B 模型的知识主体来自 AR 阶段,扩散阶段主要改变生成过程.具体数字见[LLaDA 家族](../../03-模型谱系/3.1-llada家族/3.1-llada家族.md). 和 Dream 的差别在「改编完成之后还剩多少双向」.Dream 仍是全序列掩码扩散,填空,任意顺序是结构能力.2.0 部署时块已经收小,块间因果,块内扩散,KV 能接上,任意跨块 infill 变弱.选型时问任务要不要任意位置填空,要不要接现有推理框架.

文档边界切断注意力,是改编预算变大之后才会爆出来的系统问题.把多篇文章拼成 32k 再做双向,模型会把下一篇的开头当成当前文档的未来上下文.小模型,短序列上不容易看见;100B,32k 上会把去噪学脏.这和 $Q_t$ 无关,和「改编是不是从 AR 继承」有关:AR 阶段本来就按文档因果训练,突然给它跨文档的未来,捷径比从零训的扩散更诱人.

### 4.1. 块长把 AR 与全序列扩散放在同一轴上

将序列分成长度为 $B$ 的块.块间保持因果,块内允许双向去噪.当 $B=1$ 时,每块只有一个 token,结构接近 AR;当 $B=L$ 时,整段属于一个块,接近全序列扩散.块长因此提供连续的结构课程. 对应联合分解为

$$
p(x)=\prod_{k=1}^{K}
p_\theta(x^{(k)}\mid x^{(<k)}),
$$

其中块内条件分布由扩散过程参数化.增大 $B$ 会提高块内双向范围和并行空间,也增加一次需要协调的未知变量.减小 $B$ 恢复稳定前缀与 KV Cache,跨块修订能力随之降低. 这个轴比「AR/扩散」二元标签更适合描述转换.课程沿 $B$ 移动时,词表、权重和输出头都可保持,注意力图案与训练目标的局部范围逐渐变化.

### 4.2. 三阶段 WSD 在优化什么

LLaDA 2.0 的三阶段结构课程为 warm-up、stable、decay.warm-up 逐步增加块长,让模型从熟悉的 AR 邻域进入块内双向去噪.stable 使用大块或全序列扩散,强化最广的双向建模.decay 再缩到部署所需的紧凑块,恢复效率友好的结构. stable 阶段如果直接作为部署终点,全序列每步重算成本高;只做 warm-up 后立刻部署小块,模型又可能没有充分学到扩散能力.decay 的作用是把 stable 获得的能力投影回目标块结构,类似面向部署分布的再适配. 三阶段同名于学习率调度中的 warmup-stable-decay,这里的核心变量还包括块长.学习率与块课程可能同时变化,复现时要分别记录.只知道阶段名无法还原训练路径.

### 4.3. 从大块收回小块会丢什么

全序列阶段中,位置可以读取任意方向的干净锚点.收回小块后,未来块从条件集合消失.若某项能力依赖跨块右侧信息,decay 无法无损保留.模型可以把部分全局模式压进参数,却无法在推理时读取尚未生成的具体 token. 因此 decay 后仍保持的主要是块内规划、并行揭开与从 AR 继承的跨块因果建模.任意跨块 infill 会弱化.若评测填空缺口全部落在单块内,可能高估部署模型的全局编辑能力. 可证伪实验应移动缺口相对块边界.同一内容分别让左右条件位于块内、相邻块和远端块,比较恢复质量.若跨块结果与全序列一致,说明模型可能通过重排或外部条件获得信息;否则边界是实质限制.

### 4.4. 文档打包为何在双向训练中更危险

AR 打包多个文档时,若没有边界 attention mask,后一文档可以读前一文档,但前一文档不能读后一文档.双向注意力会让两侧互读.预测前一文档被掩 token 时,模型可能利用后一文档内容,形成训练中可用、部署中不存在的未来条件. 设一个训练块包含独立文档 $A,B$.正确联合应满足数据采样上的独立近似

$$
p(A,B)=p(A)p(B).
$$

若去噪器允许预测 $A^i$ 时读取 $B$,训练条件变成 $p(A^i\mid A^{\setminus i},B)$.有限样本中偶然相关或模板信息会成为捷径,损失下降却无法迁移. 解决办法是文档边界 attention mask,让每个 query 只读取同文档 token.在张量并行中,所有设备必须使用同一边界图案;否则不同分片计算的 attention 不对应同一个模型.这属于正确性约束,不只是性能优化.

### 4.5. MoE 继承增加了路由分布偏移

LLaDA 2.0 从 AR MoE 继承时,router 也带着旧输入分布的专业化.掩码 token、大量双向上下文和不同块长会改变隐藏状态,从而改变专家选择.某些专家可能在高噪声状态过载,另一些专家闲置. 设 router 概率为 $r_e(h)$,专家使用率为

$$
u_e(t,B)=\mathbb E_{h\sim P_{t,B}}[r_e(h)].
$$

噪声 $t$ 与块长 $B$ 改变状态分布 $P_{t,B}$.只报告全 batch 平均 $u_e$ 会掩盖高噪声或大块阶段的局部塌缩.应按课程阶段与噪声桶统计负载. 负载均衡损失能约束使用率,却可能与已有专家分工冲突.过强平衡会洗掉 AR 阶段专业化,过弱则在新状态上拥塞.知识继承不只发生在 dense 权重,router 与专家对应关系也需要保护. 模型越大,一次全序列双向训练的显存与通信成本越高,课程失败的代价也更大.100B 结果证明系统能扩展,没有给出规模无关的收敛定理.同一课程在 dense 7B、MoE 16B 与 100B 上可能需要不同学习率、块长速度和数据量. MoE 的总参数与激活参数要分开.转换预算与每 token FLOPs更接近激活规模,知识容量又受总参数影响.用总参数倍数推测需要多少转换 token 没有直接依据.

大模型实证还受基座质量影响.更强 AR 起点携带更多知识,也可能形成更牢固方向性.转换 token 减少可能来自基座更强、课程更好或目标更接近,需要同基座消融才能区分. 首先在每个阶段同时测 AR next-token 风险与块内去噪风险.若 warm-up 中 AR 风险暴涨,结构变化太快;若 stable 结束去噪仍未改善,大块阶段没有发挥作用;若 decay 后块内能力断崖,部署投影失败. 其次跨块长评估同一检查点.对每个 $B$ 测块内填空、前缀续写和实际采样.模型若只在训练块长有效,课程没有形成可迁移能力;若邻近块长平滑,结构适配更稳健. 最后检查边界位置.块首、块尾与块中 token 的条件集合不同,平均损失可能隐藏边界弱点.按相对块位置画 NLL,能够看出模型是否在块接口处退化.

固定长度块会切断句子、函数或证明步骤.一条强依赖若跨界,只能由块间因果方向处理;若方向相反,当前块无法读取未来信息.随机移动边界可以让同一依赖在不同样本中有时落入块内,形成数据增强. 内容自适应分块沿句法或代码结构放边界,可能减少切断.它需要额外边界预测,推理时预测错误会改变注意力图.使用真实结构边界的上限实验与预测边界的部署实验要分开. 块长课程若固定边界起点,某些绝对位置长期承担接口角色,模型可能过拟合.随机 offset 是简单对照. stable 阶段全序列模型可以作为 teacher,decay 阶段小块模型作为 student.在 student 可见条件下蒸馏 teacher logits,能传递部分全局统计,但 teacher 使用了 student 推理时看不到的未来信息.

这属于特权信息蒸馏.若 teacher 对未来依赖很强,student 无法逐样本复现,KL 会与真实标签冲突.蒸馏权重过大会让 student 学到条件平均,输出变得模糊. 可按 teacher 对未来遮挡的敏感度分桶.敏感度低的位置更适合蒸馏,高敏感位置保留硬标签.这能检验全序列能力有多少可压回小块. 大块加高噪声是最远离 AR 的状态:右向范围最大、干净锚点最少.若块长和掩码率同时快速增加,梯度冲击叠加.可以先在低噪声下扩大块,再提高噪声,或反过来先学因果掩码恢复. 将课程写成轨迹 $(B(u),t_{max}(u))$,通过网格实验比较路径.终点相同、总 token 相同,不同路径的保留与生成质量若不同,课程顺序具有真实作用.

最优路径可能随规模变化.大模型知识强、方向惯性也强;小模型更易适配,却缺少高噪声先验.不能只在小模型选路径后直接扩到 100B. MoE 在不同 $t$ 下可能选择不同专家.若高噪声状态偏向语言先验专家、低噪声偏向局部校对专家,这种分工有功能意义.也可能只是 mask embedding 触发固定路由,造成无语义的集中. 干预方法是保持上下文不变,只改变名义时间或局部 mask,观察路由变化;再交换专家或屏蔽高频专家,测各噪声桶损失.只有功能与路由共同变化,才支持分工解释. 负载均衡会压制极端分工.训练目标要在吞吐稳定与专业化之间取舍,不能由路由直方图单独判断好坏.

### 4.6. LLaDA 2.0 的证据范围

论文直接证明系统性 AR 转换可扩到 16B 与 100B MoE,三阶段块级 WSD 可以连接知识继承、全序列扩散训练和紧凑部署结构.这是一项规模证据. 它没有证明 100B 知识从扩散阶段独立学得.知识主体来自 Ling AR 基座.也没有让部署模型保留 stable 阶段全部全序列编辑自由度,因为 decay 改回紧凑块. 评价结果应同时注明基座、阶段与部署块结构.将最终分数表述成「从零全双向 100B 扩散」会改变方法性质.

## 5. Fast-dLLM v2:数据再降两数量级

约 1B token 微调,块扩散加互补注意力掩码,分层缓存.相对 Dream 那种数百 B 的全注意力改编,卖点是接上现有 AR,接上 KV,接上吞吐,不是填空能力拉满.吞吐相对 Qwen2.5-7B-Instruct 报过 2.54 倍,且准确率不低于他们的 Fast-dLLM-LLaDA 基线.互补掩码要保证:同一套权重在这块图案下,仍能算出与 AR teacher forcing 兼容的项,改编才不会把已经学好的 next-token 几何拆掉.

| | 纯 AR | 块扩散改编 | 全双向改编 |
|---|---|---|---|
| 数据量级 | — | v2 ~1B | DiffuLLaMA &lt;200B;Dream ~580B |
| 起点 | — | 现成 AR | 现成 AR |
| 部署 KV | 真 | 块间真 | 默认无,后做近似 |
| 任意 infill | 弱 | 弱于全双向 | 强 |
| 代表 | Qwen / LLaMA | 2.0,v2,[SDAR](../5.2-sdar与块扩散转换/5.2-sdar与块扩散转换.md) | Dream,DiffuLLaMA |

### 5.1. 一十亿 token 为什么可能够用

Fast-dLLM v2 的目标结构仍保留大量 AR 几何:块间因果、历史块稳定、输出职责与基座兼容.需要新学的主要是块内双向去噪与并行提交.相较全序列扩散,条件集合变化被限制在较小区域,函数距离更短. 可以把目标函数变化粗略分成块间与块内:

$$
\Delta\mathcal L
=\Delta\mathcal L_{\mathrm{inter}}
+\Delta\mathcal L_{\mathrm{intra}}.
$$

若块间目标几乎沿用 AR,$\Delta\mathcal L_{\mathrm{inter}}$ 较小,有限数据集中优化块内项就可能得到可用模型.这解释转换预算差异,不意味着同样 1B token 足以训练全双向 Dream 等价物. 「500 倍减少」来自约 1B 与 580B 的公开训练量对照,两者交付的模型结构不同.它准确描述数据数字的比例,不能单独证明算法在同目标上提高 500 倍样本效率.

### 5.2. 互补注意力掩码怎样保留 AR 监督

块内引入双向边时,若 next-token 标签可被直接看见,AR 损失发生泄漏.互补 attention mask 的核心是安排不同 query 或训练视图,让扩散条件与 AR 条件都能形成有效监督,同时阻止标签直接进入可见集. 可将两类损失写成

$$
\mathcal L
=\lambda\mathcal L_{\mathrm{block-diff}}
+(1-\lambda)\mathcal L_{\mathrm{AR-valid}}.
$$

$\mathcal L_{\mathrm{AR-valid}}$ 为基座熟悉的 next-token 几何提供持续锚点,$\mathcal L_{\mathrm{block-diff}}$ 学习块内掩码恢复.互补图案负责让同一前向或相邻训练视图中两者都可计算. 锚点太强,模型停留在 AR;太弱,小数据改编容易遗忘.最重要的消融不是只看最终平均分,还要看 $\lambda$ 对原 AR NLL、块内填空与并行生成的三条曲线.

### 5.3. 双层缓存对应两种稳定性

块级缓存保存已完成历史块.因果块间结构保证这些表示不读取未来块,因此后续生成时严格稳定.子块缓存尝试复用当前块内部分已稳定状态,其有效性取决于剩余 token 变化是否会影响缓存表示. 训练改编与缓存设计相互约束.若块内完全双向,一个新揭开的 token 可能改变同块所有隐藏状态,严格子块缓存困难;若互补 mask 或分层结构限制依赖,部分表示可以复用.模型的注意力图案决定缓存是不是数学上有效. 速度提升不能只归因于并行生成.历史块不重算、当前块少重算与一次提交多个 token 都贡献墙钟收益.要理解结构,应分别关闭块 cache、子块 cache 和并行 pipeline.

1B token 对 7B 模型属于有限继续训练预算.模型可能快速适应训练语料的块长、格式与回答长度,却没有学到通用扩散状态.随机化块边界、噪声率和任务类型能扩大覆盖,也会稀释每种状态的样本数. 过拟合不一定表现为验证 loss 上升.模型可能保留通用知识,采样器却只在训练块长和步数上稳定.应跨块长、跨采样步数测试,并加入训练中未见的 infill 图案. 另一个风险是后训练模板.若 1B token 主要由指令数据组成,模型学到短回答和固定角色边界,基础语言建模能力未必充分适配.公开结果需要结合数据组成理解.

### 5.4. 与全双向改编的公平对照

公平比较应固定基座、继续训练数据、token 预算和主要优化器,再改变目标结构.全双向方法每步计算可能更高,按 token 对齐仍不等于按 FLOPs 对齐.最好同时报告两种预算口径. 任务也要覆盖结构差异.前缀续写和短块代码生成偏向块扩散;跨位置填空与多处编辑偏向全双向.只用一类任务会把结构选择误写成普遍优劣. 部署比较需固定质量.块方法步数更少或 cache 更强,但若质量工作点不同,速度倍数不具可比性.画质量—延迟前沿比单个最高吞吐更可靠. 论文摘要与实验支持约 1B token 的块扩散转换,互补 attention mask,分层缓存以及相对标准 AR 解码最高约 2.5 倍加速.这些结论属于其模型、任务与硬件协议.

它没有证明全双向转换也只需 1B,没有证明所有请求长度都有 2.5 倍,也没有证明块内双向能替代任意位置编辑.「不损质量」要绑定论文使用的基准和容差. 最有价值的结构结论是:越多保留 AR 因果骨架,转换函数距离越短、严格缓存越容易;相应代价是双向自由度被限制.预算和能力沿同一轴交换. 块长为 $B$,去噪步数为 $T$,理想平均每次提交 $B/T$ 个 token.实际提交数受置信度、联合依赖与重掩影响.块越小,最大并行数越低;块越大,缓存收益下降且同轮冲突增加. Fast-dLLM v2 的速度来自选定工作点,不是块扩散必然达到固定倍数.不同任务长度、batch 和硬件会移动最优 $B,T$.部署应扫整条质量—延迟曲线.

若每个块只可靠提交一个 token,结构退回接近 AR,还多了去噪调度开销.有效提交率是判断转换是否值得的核心量. 构造一条序列,随机替换目标标签输入.若对应预测 logit 立即跟随替换值,mask 存在信息泄漏.测试应跨两层以上,排除间接路径. 再将互补视图分别运行,检查每个监督位置在至少一个视图中条件合法、在任何用于该标签的路径中都看不到真值.图案复杂时,程序化可达性分析比肉眼画 mask 可靠. loss 异常快速降到接近零,同时自由生成无提升,也是泄漏信号.但最终仍要用信息流测试确认. 历史块若在训练时读取未来块,推理缓存历史表示就会与训练行为不同.块间因果必须从训练开始保持,不能只在 serving 时临时加 mask.

当前块内若使用双向 attention,每次揭开 token 可能改变同块旧 hidden state.子块缓存若近似冻结,要测 logits KL 与质量.严格缓存和近似缓存应分开表述. 训练图案、采样顺序与缓存分区三者一致,速度收益才不会以隐蔽分布偏移换取. 原始训练 token、被预测 token 与模型处理 token 可能不同.同一序列若构造互补视图,模型计算两次,数据集 token 仍可只计一次.理解成本需要同时看 token 与 FLOPs. 论文摘要给出约 1B fine-tuning tokens,足以支持数据量级判断.若要比较训练时间,还需 batch、序列长度、视图数和硬件,不能从 1B 单独换算. 同理,相对 Dream 的 500 倍是原始 token 数比例,不自动等于 500 倍算力下降. 任务主要是前缀续写、输出长度开放、服务重视 KV 与流式响应时,小块转换更匹配.块内并行提供有限加速,历史前缀保持稳定.

任务需要任意位置编辑、同时利用缺口两侧或全局反复修订时,小块的结构边界会成为限制.增加块长可缓解,训练与部署成本随之上升. 产品可能采用混合策略:普通请求走 AR 或小块,编辑请求走大块或全双向.这比强迫一个固定块长覆盖所有任务更合理.

### 5.5. 与 speculative decoding 的关系

AR speculative decoding 也能一次提出多个 token,由大模型验证.块扩散直接让同一模型在块内并行恢复.两者都提高每次串行同步的有效提交数,概率接口不同. 比较时要给 AR 使用成熟 speculative baseline,否则块扩散速度优势可能来自较弱基线.反过来,块扩散也可加入验证或草稿模型,形成组合方法. 最终仍比较单位时间合格 token、额外模型内存与质量.范式名称不足以决定谁更快.

## 6. 失效

退火太快:双向一上来,AR 特征塌.移位不加:每层隐状态的预测对象错位,继续预训练要重新学位置几何.只改 mask 不改目标:模型仍在做 next-token,测试时按扩散采样会分布外.改编预算过小又想全双向 32k:2.0 用文档边界切断注意力,就是在防打包作弊;小预算改编更容易学到这种捷径. 学习率太大:基座被洗掉,等于用很贵的方式从零训了一个更差的扩散.学习率太小:掩码预测头动不了,推理时仍像 AR,却按扩散采样,两头不靠. 把 Dream Table 1 的 LLaDA 列和 Nie et al. Table 1 的 $*$ 列横减:shot,解码,是否同一 harness 都可能不同.HumanEval 32.9 对 35.4 就是这种假差值.

把 v2 的 1B 写成「Dream 白训了 580B」:两条路线交付物不同.580B 买的是全双向 7B;1B 买的是块扩散加缓存.填空产品走前者,续写吞吐走后者.SDAR 另付约 50B,转换不做移位,不做掩码退火,见[SDAR](../5.2-sdar与块扩散转换/5.2-sdar与块扩散转换.md).DiffuLLaMA 预算仍按 Gong 原文不到 200B,不要和 SDAR 文里的 65B 减出倍数. 四条工作分别解决改编的不同环节:DiffuLLaMA 验证 7B 权重可以转换;Dream 细化移位与噪声日程;LLaDA 2.0 用块课程扩展到 100B;Fast-dLLM v2 将转换预算降到约 1B token.它们都沿用吸收态噪声家族,差别集中在双向范围、课程与部署结构.

### 6.1. 遗忘应按功能而非参数距离定义

参数离初始点很远,模型仍可能保持同一知识;参数变化很小,attention mask 改变也会让函数明显变化.因此遗忘要用基座任务上的功能退化定义.设保留任务分布为 $D_{mathrm{retain}}$,初始风险为 $R_0$,改编后风险为 $R_u$,遗忘量可以写成

$$
F(u)=R_u(D_{\mathrm{retain}})-R_0(D_{\mathrm{retain}}).
$$

$D_{mathrm{retain}}$ 不应只含知识选择题.至少包括 next-token NLL、长程续写、代码补全和基座擅长的下游任务.某些能力下降、另一些保持时,单个平均分会遮住选择性遗忘. 还要区分暂时遗忘和终点遗忘.课程切换时风险可能先升后降,说明模型在重新组织表示;持续升高说明旧功能没有恢复.高频 checkpoint 能画出路径,只看最终点无法判断稳定性.

### 6.2. 梯度冲突如何直接测量

在同一个 batch 上分别计算 AR 保留损失与扩散损失梯度 $g_{mathrm{AR}},g_{mathrm{diff}}$.逐层余弦可显示冲突集中在哪里.若 embedding 梯度一致、attention 冲突、MLP 中性,课程应优先照顾 attention;全模型平均会把结构抹平. 还可以测投影后的冲突强度:

$$
C=\max\left(0,-g_{mathrm{AR}}^\top g_{mathrm{diff}}\right).
$$

$C$ 随掩码率、右向范围和块长变化.画出 $C(t,r,B)$,便能选择低冲突路径.课程不再只是经验线性退火,而是沿梯度兼容区域移动. 梯度兼容不保证最终能力.两个目标可能局部同向,却收敛到只擅长简单 token 的解.因此冲突指标用于定位优化风险,仍需任务与生成评测.

### 6.3. 蒸馏可以保护什么

冻结初始 AR 模型作为 teacher,在干净前缀上约束改编模型 logits:

$$
\mathcal L_{\mathrm{KD}}
=T^2D_{\mathrm{KL}}
\left(
p_{\theta_0}^{T}(\cdot\mid x^{\leq i})
\,\middle\|
p_\theta^{T}(\cdot\mid x^{\leq i})
\right).
$$

它能保留 next-token 分布中的暗知识与校准,比只混合硬标签更强.代价是每个 batch 需要 teacher 前向,且过强约束会阻止双向任务形成新行为. 蒸馏条件必须与 teacher 合法输入一致.让因果 teacher 对随机双向掩码状态给分布,得到的只是左侧条件预测,不能作为全双向去噪真值.更合理的是在干净因果视图上蒸馏,在掩码双向视图上学习扩散. 教师本身的错误也会被保留.若改编目标希望修正基座知识,强蒸馏形成上限.随课程逐渐降低 KD 权重,可以早期保护、后期释放. 遗忘还来自继续训练数据变化.若扩散改编语料与 AR 预训练分布不同,能力变化同时包含目标迁移和域迁移.加入代表性旧域数据回放可以稳定知识,却需要拿到原始语料或近似样本.

把新域比例记为 $\gamma$,训练分布为

$$
D_u=(1-\gamma)D_{mathrm{old}}+\gamma D_{mathrm{new}}.
$$

即使目标不变,$\gamma$ 也会影响遗忘.研究转换算法时应尽量固定数据,或明确报告语料差异.跨论文 token 数没有数据质量与领域信息,不能直接当样本效率. 回放还能分别使用 AR 视图与扩散视图.旧域 AR 视图保护基座行为,旧域扩散视图让新目标覆盖原分布.两者回答不同问题,混合比例需要消融.

### 6.4. 文档边界是统计边界

双向 attention 的文档 mask 要与数据样本边界一致.仅依赖 EOS 不足:模型仍能越过 EOS 读取后一文档,训练损失可能利用无关未来.硬 attention 边界才阻断信息流. 边界错误可以用干预检测.固定文档 $A$,替换同一 pack 中后续文档 $B$,比较 $A$ 内 masked-token logits.正确隔离时差异应为零或数值误差;若明显变化,存在跨文档泄漏. 分布式训练中还需检查各 rank 的 pack metadata.同一 attention 计算若边界不一致,聚合结果甚至不对应单一概率模型.这是规模化改编容易出现的隐蔽错误. 低成本继承假设 embedding 维度、层数、attention 头、RoPE 与 tokenizer 一致.若只增加 mask token,可以扩充 embedding 与输出矩阵一行.若更换 GQA 组数或 hidden width,需要投影或重新初始化,迁移问题已经改变.

架构修改越多,越难把结果归因于目标.例如把 MHA 改 GQA 同时做扩散转换,缓存和参数量改善,质量变化可能来自注意力容量.最干净的改编先保持骨架,再单独优化部署结构. RoPE scaling 也属于兼容性.在原上下文长度内适配双向后再扩展,证据更清楚;同时改变方向和长度会让长程右向能力缺乏参照. 超参数数值连续不代表函数连续.右向可见半径从 127 增到 128 只多一列边,变化小;块长从 127 增到 128 可能移动所有块边界,大量 token 的邻域同时改变.课程变量需要按实际 attention 图差异衡量. 可定义相邻阶段 mask 的归一化 Hamming 距离

$$
d(\mathcal M_u,\mathcal M_{u+1})
=\frac{1}{L^2}
\sum_{i,j}
\left|M_u^{ij}-M_{u+1}^{ij}\right|.
$$

控制 $d$ 比控制块长增量更直接.随机平移块边界也能避免固定位置反复成为边界,代价是缓存结构与训练图案更复杂. 课程还应覆盖部署终点.训练最后仍是全序列,部署突然切小块,终点存在离散跳变;WSD decay 正是为减少这一跳.

### 6.5. 反例:改编可能比从零训练更差

若目标语言、tokenizer 或任务与基座差异极大,AR 权重提供的先验可能成为负迁移.例如基座几乎没见过某种形式语言,方向性模式又强,有限预算可能一直在克服旧习惯.同规模从零扩散虽然起点差,最终更贴合目标分布. 另一个反例是强编辑噪声.若任务允许插入、删除和修改已可见 token,纯吸收 mask 改编只学会恢复缺口,AR 初始化带来的 carry-over 倾向会阻碍改写.需要编辑腐蚀或不同状态空间. 第三个反例是极短序列.双向与并行收益有限,转换成本和多步采样可能没有回报.AR 基座直接部署更合适.因此「有开放权重就应该改扩散」没有普遍成立.

终点分数无法给出最小转换 token.论文选择的预算只证明在该点可行,更少数据可能也够,更多数据可能继续提升.要找阈值需要完整 scaling curve. 单一模型规模无法给出预算随参数量的幂律.7B 用 200B、另一方法 100B 或 1B,目标结构与基座都不同.拟合一条线没有可比样本. 规划基准提升也无法证明双向 attention 是唯一原因.数据、噪声、采样步数与后训练都可能贡献.需要同检查点或同训练配方的结构消融.

### 6.6. 一组可证伪的转换实验

第一组固定基座与数据,扫描 attention 开放速度、掩码率课程和标签 shift.记录三类风险随 token 的曲线.这能定位连续路径的必要组件. 第二组按层测梯度冲突和表示漂移,再只对高冲突层使用小学习率或蒸馏.若遗忘改善且扩散学习不受损,分层保护假说成立. 第三组固定 FLOPs 比较全双向与块扩散.同时测跨块 infill、前缀续写和墙钟延迟.这能把低预算收益与能力范围放在同一图里. 第四组加入随机初始化同结构模型.若 AR 初始化在相同数据下始终领先,知识继承成立;若只在前期领先后期持平,它主要改善优化速度. 第五组替换 pack 中的其他文档,检验目标文档 logits 是否变化.这个干预直接验证边界隔离,比观察总 loss 更灵敏.

保留曲线用原基座协议测 AR NLL 与核心能力.适配曲线用按噪声桶的 masked-token NLL.生成曲线用不同步数与调度下的任务质量.效率曲线记录实际延迟、缓存命中与有效提交率. 四条曲线需要使用同一组 checkpoint.若保留能力先降后升,课程正在重组;若去噪好、生成差,采样器或状态偏移是瓶颈;若质量好、效率差,目标结构可能选成全双向而部署需要块模式. 只汇报终点综合分会丢失诊断信息.转换方法的价值正是在有限预算里安排路径,路径曲线本身就是证据. 任意位置编辑要求全双向范围,应优先评估 Dream 或 DiffuLLaMA 类路线.前缀续写与在线服务重视严格 KV,块扩散路线更接近需求.千亿 MoE 还要考虑路由稳定与通信,WSD 提供规模化路径.

训练预算不是唯一横轴.还要同时写目标双向跨度、基座强度、允许的推理步数与后训练栈.相同 1B token 在强基座短块任务上可能足够,在跨序列编辑上远远不足. 最终判断应落在可观察量:保留多少基座功能,新学会多少右向和掩码条件,部署时保留多大双向范围,质量—延迟前沿移动多少.方法名称无法替代这些量. 强基座提供更好的词义、事实与推理表示,高噪声恢复可以复用这些先验.它也可能形成更尖锐的左到右专化,开放右向边时梯度冲突更强.两种作用方向相反. 固定架构系列、改变 AR 预训练 token 数,再用相同转换预算,可以测转换收益随基座强度的关系.若强基座始终更好,知识收益占主导;若差距缩小或反转,方向惯性值得关注.

只比较不同家族模型会混入 tokenizer、数据和结构,无法回答这条因果问题. 对同一方法保存不同继续训练 token 的 checkpoint,横轴用累计 FLOPs或 token,纵轴同时画保留风险与扩散风险.早期通常去噪快速改善,后期收益递减,遗忘可能持续积累. 最优停止点可以定义为满足新能力阈值时遗忘最小,或满足遗忘上限时新能力最大.这比报告一个任意终点更能比较算法. 多个规模上重复曲线,才有资格讨论预算随参数量的规律.四篇不同目标论文的单点不能拼成 scaling law. 若转换语料包含评测题或近似答案,下游保持可能来自再次见过数据,并非基座知识未遗忘.尤其数百 B token 继续训练,污染概率不可忽略.

使用受控保留集、时间切分或合成规则任务,能降低解释歧义.还可以测基座独有而转换语料明确排除的知识,作为继承探针. 污染检查属于数据证据,与模型结构同样重要.没有语料清单时,对「知识完全继承」应保持谨慎. 双向 attention 权重非零不等于模型真正依赖右侧.固定左侧和目标,替换右侧为另一种一致或冲突上下文,观察目标 logits 变化,才能测功能依赖. 定义右侧影响

$$
I_R=D_{\mathrm{KL}}
\left(
p_\theta(y\mid L,R_1)
\,\middle\|
p_\theta(y\mid L,R_2)
\right).
$$

随课程进度与层深画 $I_R$,可以看到右向能力何时形成.若全双向终点 $I_R$ 仍接近零,模型可能保持 AR 习惯. 干预还要区分有用与误导右侧.模型应在真实一致右侧降低损失,在随机无关右侧保持鲁棒,在冲突右侧按任务规则处理. 轻度掩码可以靠局部语法完成,不证明事实知识迁移.高噪声状态只保留实体或关系的一部分,更依赖参数记忆.按噪声桶测事实恢复,能观察知识是否保留到扩散条件. 同时要避免把全掩码无条件生成当事实测试.没有查询条件时,模型无需输出特定事实.应保留问题或实体提示,只扩散答案区域. 若 AR 问答保持、扩散高噪声恢复差,知识仍在参数里,新接口尚未学会访问;若两者都差,遗忘更可能发生.

很小学习率能让保留任务几乎不变,也可能让 mask embedding、右向 attention 与时间条件始终未学会.表面上「无遗忘」,终点仍接近 AR. 因此每个保留指标都要配一个适配指标.若 $F(u)\approx0$ 且去噪风险不降,这不是成功转换.目标是在 Pareto 前沿上移动,而非冻结基座. 增加训练时间补偿小学习率会提高总预算,比较时固定累计更新量或 FLOPs.只固定 step 数会偏向大学习率. 大学习率可能让 masked loss 很快下降,因为模型迅速利用局部右侧和高频模式.同时长程知识、校准与 AR 能力被破坏.短训练窗口只看新 loss 会误判成功. 检查初期多个时间桶与保留任务,能发现这种分化.若高噪声恢复没有同步改善,快速下降主要来自容易的低噪声位置.

梯度裁剪限制异常步,不能替代合理学习率.长期平均更新仍可能过大. 权重侧记录基座版本、tokenizer、是否 tied embedding、新增 token 初始化与冻结策略.目标侧记录 shift、标签位置、前向噪声、时间条件、AR 保留项和蒸馏.结构侧记录 attention mask、块长、课程轨迹与文档边界. 优化侧记录学习率、warmup、优化器状态、数据顺序、每阶段 token 与 FLOPs.评估侧记录基座保留、按噪声桶恢复、右侧干预、自由生成、块边界与实际延迟. 这些量足够区分「权重没有继承」「接口没有适配」「采样器没有用好」三类失败.只给最终平均榜单无法完成诊断.

### 6.7. 一个最小四 token 对齐走查

设序列为 `(A,B,C,D)`.AR teacher forcing 输入 `(A,B,C)`,hidden states $(h_1,h_2,h_3)$ 分别监督 `(B,C,D)`.基座已让 $h_2$ 与标签 $C$ 对齐.若改成无移位恢复,第二个物理位置的 hidden state 要预测 $B$,原职责整体变化. 保留 shift 时,仍由 $h_2$ 预测 $C$.假设扩散输入为 `(A,B,M,D)`,目标 $C$ 被掩.为了让 $h_2$ 使用右侧 $D$ 又看不到 $C$,attention 图必须允许它读取位置 4,阻止读取位置 3 的真值,当前位置与物理标签的映射要按实现约定处理. 若输入张量把 `M` 放在位置 3,输出代码却读取位置 3 logits 预测 $C$,模型走的是 un-shift;若读取位置 2 logits,才延续上述 shift.两种都能训练,初始化优势与缓存索引不同.名字无法替代张量走查. 再考虑两层泄漏.即便 $h_2$ 第一层看不到位置 3,若位置 4 能读取位置 3,第二层 $h_2$ 又读取位置 4,答案仍可间接传回.安全 mask 需要保证信息流图上不存在从目标真值到预测 query 的路径.逐层可达性比检查单个 mask 元素更严格.

这个四 token 例子可以写成自动测试:改变位置 3 的输入 token,其余保持,预测位置 2 的 logits 应不变;改变合法右侧位置 4,logits 可以变化.它同时验证标签对齐、右侧利用和泄漏隔离.

### 6.8. 一个保留—适配 Pareto 手算

假设三种 checkpoint 的基座风险增量 $F$ 分别为 $0.02,0.10,0.30$,扩散风险下降 $G$ 分别为 $0.10,0.35,0.38$.第三个点比第二个只多获得 $0.03$ 适配收益,却多付出 $0.20$ 遗忘,在多数权重下不是好选择. 可以定义应用效用

$$
U=G-\lambda F,
$$

$\lambda$ 表示保留能力的重要性.$\lambda=1$ 时三个点效用为 $0.08,0.25,0.08$,第二点最佳;$\lambda=0.1$ 时效用为 $0.098,0.34,0.35$,第三点才略占优.最佳停止点依赖业务权重. 比加权和更稳妥的是保留全部非支配点.若另一个 checkpoint 同时拥有更小 $F$ 和更大 $G$,当前点被严格支配,无需讨论权重.课程方法应比较整条 Pareto 前沿是否外移,而非只挑一个最有利终点. 将 $G$ 再拆成全双向填空、块内生成和右侧利用,前沿会变成多维.这正是不同转换路线不能只按 token 预算排序的原因:它们购买的适配能力不相同. 现有一手论文已经支持从 127M 到 100B 的多种转换可行性,也给出全双向、块级课程与约 1B token 小数据路线.仍缺统一基座、统一数据、统一 FLOPs 下覆盖全部方法的对照,所以无法给出普遍最优课程.

学习率、shift 与上下文自适应噪声在小尺度有消融,大尺度终点更多是整包配方.组件收益是否随参数量保持,需要更完整 scaling study.转换后的后训练与 RL 也尚未达到 AR 生态同等成熟度. 理论上,AR 与扩散风险之间是否总存在低损失连续路径、块长课程的最优速度如何随模型规模变化、条件模型误差怎样转化为少步联合采样误差,都没有一般答案.这些缺口应通过受控曲线补足,不能用单张榜单推断.

### 6.9. 读新转换论文时先对齐五个问题

第一看起点.模型从 base AR、instruct AR 还是已有扩散模型开始,决定「继承」具体包含知识、格式还是偏好.若基座不同,终点分数首先反映起点差异. 第二看目标.检查标签是否 shift、当前目标 token 是否被遮、AR 保留损失是否存在、时间权重对应哪条噪声路径.一句「使用 diffusion objective」无法说明这些选择. 第三看可见性.全序列双向、块内双向、互补 mask 与随机右向窗口形成不同模型族.训练图案还要与部署缓存一致.若论文只画示意图,应沿一条四 token 样本手算可达路径. 第四看预算.同时记录原始 token、目标 token、视图数、序列长度和 FLOPs.数百倍数据缩减若伴随目标从全双向改成小块,它是结构—预算交换,仍然很有价值,但含义不同.

第五看证据.小模型单变量消融说明机制方向,大模型整包结果说明可扩展性,二者不能互相替代.若关键组件只在 1B 验证,7B 或 100B 上应写成配方的一部分,不要把全部提升精确分摊给它. 完成这五步后,转换路线可以落在一张清楚的坐标图:横轴是离 AR 函数的距离,纵轴是保留的双向自由度,第三轴是部署可缓存性.训练 token 是走到该点付出的实证成本,不是脱离结构的排名分数. 还可以增加一个统一的「零预算」基线:不更新任何权重,只修改 attention mask 或采样接口.如果零预算已经获得部分填空能力,后续收益要相对它计算;若零预算立即崩溃,继续训练确实承担了结构适配.这个基线能区分基座潜在能力与转换训练贡献.

另一个基线是保持训练 token 不变、继续做普通 AR 预训练.扩散终点若在通用任务提升,其中一部分可能来自额外数据,AR 继续训练基线可以扣除这部分.填空与并行能力仍需专门指标,但知识与语言质量会更公平. 最终实验表至少应包含四列:原始 AR、AR 继续训练、随机初始化扩散、AR 初始化扩散.前两列估计额外数据收益,后两列估计初始化收益,第一与第四列展示完整转换.缺一列,「继承」「继续训练」和「扩散目标」就容易混在同一个差值里. 这四列还要共享 tokenizer、语料顺序、更新 token 和评测 harness.随机初始化扩散若需要不同学习率,可以分别调优,但调参预算应相近.否则初始化方法顺便获得更多搜索,差值仍然不干净.

对大模型无法完整重跑时,至少在可承受的小尺度完成四列,再把大模型结论限定为整包可扩展性.小尺度因果消融和大尺度系统结果合在一起,证据链才闭合. 验收时还应冻结一套从转换前就确定的测试协议.若训练过程中不断根据结果替换任务、采样步数或提示模板,最终保留曲线会受到选择偏差.开发集可以调课程,终测集只在路线确定后运行. 随机性至少来自数据顺序、mask 图案和采样轨迹.小模型机制实验应跨多个种子,大模型若只能训练一次,也要对评测掩码与生成种子做重复测量.均值之外报告方差或置信区间,才能判断几个百分点是否稳定.

最难伪造的证据是干预:遮掉右侧时能力下降多少,换掉 pack 中另一文档时 logits 是否不变,错一位读取输出时质量怎样,把块长移出训练值时曲线是否平滑.这些实验直接对应机制,比更多综合榜单更能证明转换确实按预期工作. 最终模型若保留 AR 知识、学会双向条件,却在有限步采样中无法提交可靠 token,转换仍未完成.条件模型与生成算法要分别验收,然后在同一质量阈值下测延迟.这样得到的结论才同时覆盖原理、训练和部署边界. 函数继承还可以用同输入 KL 做一次更直接的检查.固定一批干净前缀,让转换前后的模型都运行严格因果 mask,比较每个位置的词表分布

$$
D_{\mathrm{KL}}\!\left(p_{\mathrm{AR}}(\cdot\mid x_{<i})\,\|\,p_{\theta}(\cdot\mid x_{<i},t=0)\right).
$$

初始化完成、尚未更新权重时,这项差异应接近数值误差;若差异已经很大,问题多半出在位置索引、RoPE、归一化、输出移位或新增时间分支的默认值.训练开始后,按层记录 hidden-state cosine 与输出 KL,就能看到漂移首先发生在哪里.只看最终困惑度会把接口错误、正常适配和灾难性遗忘压成同一个数.

双向能力则需要成对干预.先构造左右上下文都能唯一确定答案的样本,再分别替换左证据、右证据与无关 token.理想模型应对两侧有效证据敏感,对无关位置稳定;若右证据变化几乎不影响分布,双向 mask 可能名义开放却没有被学会.把该响应曲线按噪声率、块长和训练阶段展开,还能判断课程是在逐步增加右侧依赖,还是只提高了局部去噪熟练度.

最后把条件分布误差传到采样轨迹上.在相同初始 mask、相同随机数和相同提交规则下,逐步比较两个 checkpoint 的 token 置信度与提交集合.早期很小的分布偏差若反复改变提交顺序,最终序列差异会被放大;这解释了条件模型指标接近时,少步生成质量仍可能悬殊.因此转换验收需要同时保留单步分布、轨迹稳定性和终点质量三层证据.
