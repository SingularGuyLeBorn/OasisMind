# 训练、后训练与权重迁移

扩散语言模型既可以从头训练，也可以从自回归检查点改编。两条路线不能混用同一张“训练成本”表：前者学习完整噪声条件分布，后者还要处理输入移位、注意力掩码、位置编码、块大小和原有能力保持。

## 统一配方卡

每篇训练方法都应记录：起始检查点、是否改变 token shift、注意力可见性、噪声日程、训练 token、序列长度、优化目标、蒸馏教师、最终采样器、开放权重/代码状态和论文版本。没有这些字段，跨论文“训练更省”没有可比性。

强化学习章节只讨论扩散策略概率/变分目标如何进入优化；通用 DPO、PPO、GRPO 推导由 `llm-guide` 对齐章节与 `knowledge` 课程实验负责。
