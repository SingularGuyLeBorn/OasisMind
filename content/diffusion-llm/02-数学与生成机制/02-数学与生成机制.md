# 扩散语言模型的数学与生成机制

本章只建立可复用的数学骨架。模型产品、吞吐数字和训练配方分别放在第 03、05、06 章，避免用工程现象反推公式。

## 统一符号

| 符号 | 含义 | 易混点 |
|---|---|---|
| $x_0$ | 数据样本或干净 token 序列 | 有些论文把干净端记为 $x_1$ |
| $x_t$ | 噪声时刻 $t$ 的状态 | $t$ 可为离散步或连续时间 |
| $Q_t$ / $\bar Q_t$ | 单步 / 累积离散转移矩阵 | 行列约定须随论文确认 |
| $T$ | 训练或采样时间范围 | 不等于输出长度 $L$ |
| NFE | 网络函数评估次数 | 不等于 token/s 或端到端延迟 |
| remask | 将已预测位置重新置为未知 | 可能是精确随机转移，也可能是启发式低置信选择 |

## 公式使用规则

- 每个目标都注明连续/离散时间、噪声核和参数化。
- ELBO、NELBO、生成 PPL 与精确自回归 NLL 分开报告。
- 祖先采样、tau-leaping、低置信重掩和确定性揭开不使用同一个“反向采样”标签。
- BERT 的 15% 选择与 80/10/10 替换只作为局部教学类比，不等同于完整生成式扩散链。
