# LLaDA:8B 从头训到 100B 改编

LLaDA 要回答的问题很硬:LLM 的规模化,上下文学习,指令跟随,是不是必须绑在自回归连乘上.作者的答案是:这些能力来自「用似然(或其下界)拟合语言分布」,不来自「必须从左到右」.8B 从头训是把这句话做到和 LLaMA3 8B 同一张表上;2.0 是承认从头训 100B 太贵,改成继承 AR 权重.

机制公式见掩码扩散章节;这里比较架构选择,原表数字,采样器影响与 2.0 的转换课程.后训练(VRPO,diffu-GRPO)不在 8B 原论文主表里,文末只给指针和对照口径.

## 1. 8B 骨架:去掉因果掩码的 decoder-only

预训练 2.3T token,0.13 百万 H800 GPU 小时,序列长 4096.损失即掩码扩散篇式 (1):抽 $t\sim U[0,1]$,每个位置独立以概率 $t$ 变成 `[MASK]`,交叉熵只落在被掩位置上,再乘 $1/t$.SFT 用 450 万对,只掩回答,提示保持干净.没有 RL.

和 LLaMA3 8B 的对照写在附录 Table 5:都是 32 层,隐维 4096,32 个注意力头.LLaDA 用 32 个 KV 头(vanilla MHA),LLaMA3 用 8 个(GQA).作者写明原因:当时这套全双向公式和 KV Cache 不兼容,GQA 省 KV 的前提不成立.多出来的注意力参数靠减小 FFN(12288 对 14336)对齐到 8.02B / 8.03B.词表 126464 对 128000,分词器按他们的数据改编.

换掉的是 mask 和训练目标.RoPE,SwiGLU,RMSNorm 仍在.BERT 的 15% 固定掩码,NSP,10% 随机替换都不在.$t$ 要从 0 积到 1,生成要从全掩码走回来,这两件事才把编码器接上生成模型.

1% 的预训练样本会把长度在 $[1,4096]$ 里另抽一次,避免模型只会处理垫满 4096 的块.生成长度在纯扩散里仍是超参:一开始垫多少个 `[MASK]`.Instruct 数据若用 `[EOS]` 垫到固定长,纯扩散会学会到处写结束符,采样时要把 `[EOS]` 置信度置零.这不是 $Q_t$ 的问题,是定长垫片和结束符抢置信度.

训练一步长什么样.抽一条 4096 的文档,抽一个 $t$,抛硬币决定哪些位置变成 `[MASK]`.网络做一次全双向前向,词表 softmax 只在被掩位置上对原 token 算交叉熵,乘 $1/t$ 再反传.未掩位置的答案已经写在输入里,再预测一次没有信息,还会让模型学抄输入.这和 BERT 的差别不在「用了双向 Transformer」,而在 $t$ 覆盖 $[0,1]$ 全体:有的 batch 几乎没掩码,有的 batch 几乎全掩.似然下界是对这条日程求期望,所以可以从全掩码反向采样.固定 15% 的 MLM 没有这条反向过程.

SFT 把同一套损失收窄到回答段.提示位置永远可见,当作条件;回答位置按 $t$ 掩.模型学的是「在这段已经写好的指令旁边,把回答从噪声里擦出来」,不是「从左到右续写指令」.这解释了为什么同一组 Instruct 权重,用自回归采样(每步只揭最左边一个掩码)会和 `[EOS]` 垫片打架,而纯扩散,块扩散还能出分数.

同数据 ARM baseline 是作者用来挡「2.3T 对 15T」的那条曲线.语料配比,分词器,优化器尽量对齐,只换因式分解.下游在他们走到的 FLOPs 区间没有塌.这张图回答的是「扩散目标能不能 scale」,不是「LLaDA 的数据比 LLaMA3 更省」.跨公司主表上的 GSM8K 21 个点,混了数据,目标和双向,不能单独记在扩散名下.

## 2. 采样器能改分数

附录 Table 8,Instruct,块长 32:

| 采样 | GSM8K | MATH | HumanEval |
|---|---|---|---|
| 自回归 | 0 | 9.5 | 0 |
| 块扩散 | 24.6 | 23.5 | 17.1 |
| 块扩散 LLaDA(半自回归 remask) | 77.5 | 42.2 | 46.3 |
| 纯扩散 | 69.4 | 31.9 | 49.4 |

Table 2 的 69.4 / 31.9 / 49.4 是纯扩散.GSM8K 若改用块长 8 的块扩散 LLaDA,可到 78.6.报「LLaDA Instruct 的 GSM8K」而不写采样器,数字没有意义.自回归采样在 Instruct 上崩掉,和 `[EOS]` padding 有关,见采样篇.

Table 9 直接给出了 remask 的差距:随机 remask 的 GSM8K 是 21.3,低置信 remask 是 70.0,生成长度设定相同.随机策略会把已经很尖的位置盖回去,同时放过仍然平的位置.低置信策略把计算预算留给还没想清楚的格子.这是 MaskGIT 式启发式,不是 ELBO 推出来的.

Table 7 在 Base 上做同类消融.自回归采样:BBH 38.1,GSM8K 63.1,Math 23.6,HumanEval 18.3,MBPP 33.4.纯扩散把 HumanEval 拉回 35.4,整体最好.块扩散采样介于两者之间,块长 $L'$ 是旋钮.同一组 8B 权重,采样器可以把它变成三种不同的模型.Instruct 上自回归采样崩到 GSM8K=0,HumanEval=0,Base 上只是变差,没有归零:SFT 的 `[EOS]` 垫片是崩掉的主因,不是「扩散权重不会从左到右」.

低置信 remask 和随机 remask 的差,比换块长更刺眼.Table 9 在相同生成长度下,随机 21.3,低置信 70.0(GSM8K).随机策略忠实于前向后验,理论上更「对」,生成却差.原因是 $p_\theta$ 在不同位置上的校准不一样:有的格子上下文已经够,分布很尖;有的还在几个近义词之间平.随机盖回去会浪费已经尖的格子.采样篇用四格置信度把这件事画出来.

## 3. 诗歌反向:机制实验及其边界

给定后半句补前半句.因果模型必须把「后面」改写成提示里的条件,且生成方向仍朝结束符走.掩码扩散把要补的字留成 `[MASK]`,已给的字当干净上下文,方向不存在.评测跟 Allen-Zhu 与 Li 的协议,496 对著名中文诗句,zero-shot.

Table 3 / Table 4:GPT-4o(2024-08-06)正向 82.7,反向 34.3.Qwen2.5 7B Instruct 正向 75.9,反向 38.0.LLaDA 8B Instruct 正向 48.8,反向 42.4.正向弱,作者写在 2.3T 和约 13 万 H800 小时对不上闭源语料.反向超过两者.论文要强调的是正反向落差被压平,不是古诗全面超过 GPT-4o.

附录里 GPT-4o 写错上句的例子:问「但闻人语响」接到「无可奈何花落去」;问「夜静春山空」接到「空山新雨后」.方向反了之后,它仍按往后续的习惯找一个顺口的下句.注意力侧的解释见[双向注意力与反转诅咒](../../04-联合依赖与结构设计/4.1-双向注意力与反转问题/4.1-双向注意力与反转问题.md).Berglund 微调实验里虚构名人正向 96.7%,反向约 0%,测的是另一件事:参数里有没有反向边.诗句表不能外推成「扩散已经解决知识对称」.

## 4. 2.0:转换,不从头堆 100B

LLaDA 2.0 从 Ling-mini-2.0 / Ling-flash-2.0 出发,把 AR 看成块大小为 1 的块扩散,再用 Warmup–Stable–Decay 改块大小.

![LLaDA 2.0 从自回归权重经三阶段块级 WSD 改编为扩散模型](../images/fig-llada-wsd.png)

> 图 1:2.0 把现成 AR MoE 当成 $B=1$,warmup 加大块并打开双向,stable 做全序列扩散,decay 再收到适合部署,能接 KV 的块.

图 1 解析:

- **AR MoE (B=1)**:不是新训一个扩散骨架,是继承已经学好语言几何的权重.$B=1$ 在概率上就是 AR 连乘.
- **Warmup: grow block size**:块太一下子全打开,改编会把 AR 特征打乱.这一段让模型习惯块内出现 `[MASK]` 和右边上下文.
- **open bidirectional**:因果掩码在这里放宽.放宽速度是超参,对应 DiffuLLaMA 里的掩码退火.
- **Stable: full-sequence diffusion**:双向去噪能力拉满,数据利用率比小块 teacher forcing 高.主评测数字不是跑在这个设定上.
- **Decay: shrink block**:推理时太大的块又把 KV 和并行误差赔回去.flash 主结果跑在收小之后.
- **KV-friendly B**:块间前缀可以真缓存.这和 Fast-dLLM 那种跨去噪步的近似缓存不是一回事.

发布的是指令微调后的 MoE:mini 16B,flash 100B.

Table 1–2 的平均分:mini 64.34,对照 Ling-mini-2.0 的 65.77,Qwen3-8B (no_think) 的 63.42.flash 73.18,对照 Qwen3-30B-A3B-Instruct-2507 的 73.60,Ling-flash-2.0 的 72.15.flash 的 HumanEval 94.51,MBPP 88.29,AIME 2025 60.00,BFCL v3 75.43,作者强调编码与 agent 相对 AR 同级模型开始占优.

吞吐:作者用 dInfer,阈值 0.95.flash-CAP 535 TPS,普通 flash 383 TPS,SGLang 上的 AR 基线 256 与 237 TPS,最高约 2.1 倍.CAP 是在已经预测对的位置上再压熵,提高每步提交的 token 数(TPF),不是换 $Q_t$.

上下文:文内称 32k 内 flash 稳定.训练用 Megatron 的 DP/PP/TP/CP/EP,掩码在模型并行组内广播以保持一致.文档打包必须在边界切断注意力,否则后一篇文档的开头会变成当前文档的未来上下文,去噪时作弊.

100B 是改编不是从噪声训出来的扩散.知识来自 AR 阶段,扩散阶段负责改生成过程.讨论「扩散能否 scale」时要把「从头训的 8B」和「转换的 100B」分开.

## 5. 规模曲线和 CFG

原文 Fig. 3 用预训练 FLOPs 当横轴,六个下游任务上 LLaDA 与同数据 ARM 的曲线总体可并排.作者拒绝拟合定量幂律,理由是离群点会误导.能说的只有:在他们走到的 $10^{23}$ FLOPs 量级,扩散没有在下游上突然塌掉.早期「似然要 16 倍算力才追上 AR」的观察,被他们用「似然是间接指标,优化的是界,FLOPs 区间更宽」三句话挡回.该早期观察不能作为 2025 年模型的算力换算关系.

CFG 在附录 Table 6:有条件与无条件 logits 外推,多个任务稳定加分.这是推理技巧.8B Instruct 的主表没有把 CFG 当成默认必开项来报,读具体数字时看附录有没有开.Base,不开 CFG 的那一行:ARC-C 45.9,Hellaswag 70.5,TruthfulQA 46.1,WinoGrande 74.8,GPQA 25.2,PIQA 73.6.开 CFG 并在 $\{0.5,1,1.5,2\}$ 里按任务选最好的 $\gamma$ 之后:47.9,72.5,46.4,74.8,26.1,74.4.作者写明主表为了和 ARM 公平对照,不开 CFG.离散 CFG 的公式和基因组上的 γ 表见[可控生成](../../07-控制-评测与选型/7.1-可控生成与推理期转向/7.1-可控生成与推理期转向.md);8B 语言 CFG 没有与 Table 2 同口径,扫完整指令任务的公开细表.

读架构的人常问:8B 为什么不用 GQA.答案已经写在 Table 5 旁边:全双向下 Key 会随揭开而变,省 KV 头省的是一份每步都可能过期的缓存.后来 DualCache,延迟写入把「过期但有界」变成可卖的近似.那是 2025 年中的加速论文,不是 2 月这张 8B 检查点自带的能力.LLaDA 原检查点不具备严格 KV Cache;后续近似缓存不能反推原论文已经支持该能力.

SFT 的 450 万对只掩回答,看起来像普通指令微调.差别在损失仍是 $1/t$ 加权掩码交叉熵,不是 next-token.模型学的是「在干净提示旁边把回答从噪声里擦出来」.所以 Instruct 权重拿去当因果模型逐步揭最左边一个掩码时,会和垫进去的 `[EOS]` 打架,GSM8K 可以掉到 0.这不是权重坏了,是解码器和训练分布不一致.块采样把结束符的传播挡在块边界,分数立刻回来.换采样器比再收集 450 万对便宜,因此采样器必须作为模型评测协议的一部分报告.

## 6. 机制推导与可归因边界

### 6.1. 前向核从一枚硬币开始

设干净序列为 $x_0=(x_0^1,\ldots,x_0^L)$,词表外增加吸收符号 $M$.连续时间 $t\in[0,1]$ 下,每个位置独立保留原 token 的概率为 $\alpha_t$,变成 mask 的概率为 $1-\alpha_t$:

$$
q_t(x_t\mid x_0)=\prod_{i=1}^{L}
\left[\alpha_t\mathbf 1(x_t^i=x_0^i)+(1-\alpha_t)\mathbf 1(x_t^i=M)\right].
$$

LLaDA 常用线性日程 $\alpha_t=1-t$.当 $t=0$ 时序列干净,$t=1$ 时全部被遮.吸收意味着 token 一旦在前向过程中变成 $M$,更晚时刻不会恢复成别的词.反向生成沿相反方向,从全 mask 逐渐显露 token.

给定 $x_t$,已露出的 token 与 $x_0$ 完全相同,因此无需预测;网络只估计 mask 位置的干净 token 分布 $p_\theta(x_0^i\mid x_t,t)$.架构虽然沿用 decoder-only Transformer,attention mask 改成全双向.「decoder-only」在这里描述残差块、归一化和 FFN 形态,不再意味着因果可见性.

这个前向核没有随机替换成其他词,与 BERT 的 80/10/10 corruption 不同.输入中的非 mask token 始终可信,反向采样可把它们作为硬条件.做填空时,用户给出的任意位置原文直接放进 $x_t$,待生成区域放 $M$,无需把后缀搬到提示前面.诗歌反向与 FIM 都建立在这条条件结构上.

独立前向腐蚀不等于独立数据模型.真后验 $q(x_0\mid x_t)$ 仍包含语言中全部联合依赖;网络输出通常按位置因子化,这才产生并行采样的联合缺口.多步反向让已揭示 token 逐渐成为公共上下文,缓解一次性独立抽样错误.步数越少,每步同时提交越多位置,联合误差越明显.

对于条件生成,把提示位置集合记为 $C$,回答集合记为 $A$.SFT 只对 $A$ 应用前向 mask:

$$
q_t(x_{t,A}\mid x_{0,A})
=\prod_{i\in A}\left[(1-t)\mathbf 1(x_t^i=x_0^i)+t\mathbf 1(x_t^i=M)\right],
$$

$x_{t,C}=x_{0,C}$ 始终可见.这给出一个真正的条件扩散目标,不是先无条件生成再拼提示.提示 token 没有监督损失,但通过双向 attention 影响所有回答 mask.

长度仍需另行处理.自回归模型用 EOS 动作决定何时结束;固定画布扩散先分配若干回答位置,再预测内容与 EOS/pad.画布过短会截断,过长会给 EOS 和填充留下大量位置.SFT 数据的 padding 约定因此会进入采样行为,也是因果式逐格解码在 Instruct 权重上崩溃的重要背景.

### 6.2. 为什么损失带 $1/t$

线性吸收日程下,常用训练目标为

$$
\mathcal L(\theta)=
\mathbb E_{x_0,t,x_t}\left[
-\frac1t\sum_{i:x_t^i=M}\log p_\theta(x_0^i\mid x_t,t)
\right].
$$

mask 指示本身以概率 $t$ 出现.对单个位置取期望时,$1/t$ 与被 mask 概率相消,使不同 $t$ 都对干净 token 风险贡献可比.若没有权重,高噪声样本因为 mask 多而支配训练,模型会偏向全局猜词;低噪声的精细修补学得不足.

更深一层看,该目标来自连续时间吸收扩散的负 ELBO.一般日程下权重与 $-\alpha_t'/(1-\alpha_t)$ 有关;线性 $\alpha_t=1-t$ 化成 $1/t$.所以 $1/t$ 不是手工强调少 mask 样本,而是前向危险率进入反向似然界.换噪声日程后照搬 $1/t$ 会失去这一对应.

$t\to0$ 时权重发散,但 mask 出现概率同步趋零.理论期望有限,有限 batch 方差仍可能很大:偶尔抽到很小 $t$ 且恰有 mask,单 token 损失被放大.实现可对时间做截断、重要性采样或按有效 mask 归一,每种处理都改变方差甚至目标.论文主结论依赖其既定训练配方,不能把所有「加权 MLM」视为完全等价.

网络在未 mask 位置的输出不进损失,避免学习恒等复制.若对全部位置算交叉熵,大量干净 token 可直接从输入读取,训练 loss 很快下降,生成时全 mask 却没有对应捷径.只监督腐蚀位置让模型必须利用上下文恢复缺失内容.

逐位置交叉熵是因子化条件族的最大似然.共享 Transformer 可让每个边缘利用整段上下文,输出联合仍写成边缘乘积.训练期一次前向看见随机 mask 组合,采样期一次从多个边缘抽 token.两者在单位置风险上匹配,在同时抽样的联合上仍有空隙.低置信 remask、更多步骤、块化或能量校正分别从采样和结构侧处理这条缝.

SFT 沿用同一权重.对一条回答随机遮不同密度,模型同时学习几乎完整答案的局部修正、半成品补全和从全 mask 起草.普通 next-token SFT 每条样本提供唯一左到右因式分解;LLaDA SFT 对许多可见集合求期望.这给双向条件能力,也让同一训练 token 通过不同 mask 视图反复出现,计算口径不能简单按原始 token 与 AR 横比.

### 6.3. 从 $x_0$ 预测到一步反向核

网络直接预测干净 token,采样还需从当前 $x_t$ 得到更早时刻 $x_s$,其中 $s<t$.对已经显露的位置,吸收过程要求原样保留.对仍为 mask 的位置,先从 $p_\theta(x_0^i\mid x_t,t)$ 提出干净 token,再按解析 posterior 决定本步显露还是继续 mask.

线性日程下,条件于位置在 $t$ 仍为 mask,它在 $s$ 已经干净的概率与 $(t-s)/t$ 对应,继续 mask 的概率约为 $s/t$.因此一步可以理解为:每个 mask 位从模型分布抽一个候选,再按时间跨度提交一部分.离散 $T$ 步越少,$t-s$ 越大,每步提交比例越高.

随机 remask 忠实采用独立后验事件,却没有利用模型置信度.若两个位置一个概率 0.99、一个只有 0.3,随机规则可能保留后者、重遮前者.低置信策略把固定提交预算给最确定的位置,把模糊位置留给下一轮更多上下文.它改变理论反向核,引入启发式偏差,实测质量却大幅提高.这提醒我们:有限步采样器是在近似模型目标,严格遵循一个粗离散核未必最优.

用 $u_i=\max_v p_\theta(v\mid x_t,t)$ 排序,每步提交最高置信的一批,形成 coarse-to-fine 轨迹.置信度必须校准才有意义.模型若对错误 token 过度自信,错误会早早冻结;允许低置信重掩可修模糊位置,难以修高置信错觉.温度、CFG 和 SFT 都会改变置信度尺度,所以采样超参不能脱离 checkpoint 复用.

块扩散把序列切成若干块,块间从左到右、块内并行去噪.块大小 1 退化成 AR,块大小等于整段退化成纯扩散.中间值提供并行度、联合误差与 KV cache 的连续交换.块前缀一旦完成可缓存,当前块内部仍需多轮双向计算.

半自回归 remask 又在块结构内选择低置信 token重做.这解释 Table 8 的巨大差别:「块扩散」只规定可见图,具体 remask 决定计算是否花在难点上.采样器名称若没写块长、步数、提交规则、温度和长度,分数无法复现.

纯自回归采样每次只揭最左 mask,理论上也能使用同一网络.它制造的状态分布与 LLaDA SFT 不同:回答右侧长期全 mask,模型训练时见过随机散布的已知右侧 token;EOS padding 又可能在早期被预测并传播.因此 Base 权重只是下降,Instruct 权重可能崩到零.这属于训练—采样状态错配,无法据此断言双向权重缺乏因果生成能力.

### 6.4. 似然和下游评测用的不是同一把尺

预训练目标提供数据负对数似然的变分界.在离散时间可把各步 KL 累加,连续时间可对随机 $t$ 的加权交叉熵积分.论文报告的 perplexity 或 bound 要看是否为精确似然、ELBO 还是 Monte Carlo 上界.LLaDA 下游主表更多使用任务准确率,不直接展示模型似然已超过同规模 AR.

多选任务可比较候选答案的条件似然.扩散模型的完整回答概率通常要对时间和 mask 做 Monte Carlo 估计,同一候选多次加噪求平均.估计方差会改变选项排序,采样次数与共享随机数是评测协议的一部分.让所有选项共享时间和 mask 图案可消掉公共噪声,比各自独立抽样更稳.

生成任务走实际反向采样,分数同时依赖权重和采样器.GSM8K、HumanEval 的准确率不仅测语言分布,也测有限步轨迹能否把正确答案提交出来.同一 Instruct 权重的 69.4 与 78.6 差异主要来自采样方式,不能都当作模型参数的静态能力.

shot 数也是条件格式的一部分.Base GSM8K 4-shot、d1 的 0-shot、后续偏好工作的协议不能直接相减.扩散模型对提示长度、答案画布和 block boundary 敏感,少一个演示会同时改变任务信息与 mask 几何.家族表应在数字旁保留 shot、长度、步数和 sampler.

FIM 评测展示双向补全,AR 基线若接受专门 FIM 数据也能竞争.公平问题有两层:固定训练目标看原生能力,或允许各架构使用最合适的数据增强看产品能力.前者说明掩码扩散无需另造 FIM 格式,后者不能把 AR 的 FIM 训练排除后宣称架构胜利.

诗句反向属于机制压力测试.它让后缀证据成为硬条件,揭示因果模型默认方向偏置.LLaDA 正向较弱、反向更平衡,支持双向条件优势;样本只有 496 对,语言与闭源模型训练语料未知,无法推出通用知识检索全面更强.正确读法是看正反差值和错误类型.

规模曲线同样需要同数据 ARM.跨公司 2.3T 与 15T 包含语料质量、重复率、数学代码比例和 tokenizer 差异.同配方只换目标的曲线才接近因果对照.即便如此,训练 FLOPs 相同不等于推理成本相同,扩散需要多次全序列前向,AR 有 KV cache.

### 6.5. SFT 到偏好优化,概率接口发生了什么

LLaDA 原版 SFT 使用约 450 万指令对,提示保持干净、回答随机 mask.每个训练样本不要求固定生成顺序,因此同一答案可从多种局部可见状态恢复.格式模板、EOS 与 padding 成为干净条件分布的一部分,错误处理会直接改变采样.

SFT 只能模仿示范,不会显式比较好坏回答.原论文和有 RL 的 LLaMA3 Instruct 对照时,后训练深度不同.后续 LLaDA 1.5 用 VRPO 把 DPO 的完整回答概率比替换为扩散 ELBO 估计,核心困难是四个似然项的 Monte Carlo 方差.共享 mask 和跨时间分配样本用于抵消差分噪声.

d1 走在线验证奖励,用 masked SFT 先种入推理行为,再以 diffu-GRPO 放大组内高奖励回答.它用一步随机 mask 概率作为多步轨迹概率代理,计算便宜、存在偏差.两条路线说明扩散能接偏好和策略梯度,没有证明其目标与 AR 估计同样精确.

后训练数字必须绑定各自基线.LLaDA 1.5 的 78.6 基线、d1 的 78.2 和原论文纯扩散 69.4 来自不同 shot、长度或采样器.把提升相加没有意义.真正可归因的是同篇论文内固定协议的 before/after,以及算法消融中的方差或奖励曲线.

偏好更新还会改变置信度,进而改变低置信采样轨迹.即使 token argmax 少变,某些位置更早提交,实际生成分布也会变化.评估后训练不能只用固定终点重构损失,还要重新校准 sampler.在扩散模型里,权重与调度器耦合比 AR 的 greedy/temperature 更深.

CFG 从另一个方向重排 logits.有条件与无条件预测作外推,增强提示相关信号.它能提高部分 Base 任务,主表为公平没有默认开启.若后训练、CFG 与低置信提交一起调优,收益无法只归给某一项;应先固定 sampler 比权重,再固定权重比 guidance.

### 6.6. 从 8B 到 2.0,家族名称下换了训练问题

8B Base 从随机初始化用 2.3T token 学语言和反向生成.它回答「掩码扩散能否从头规模化」.LLaDA 2.0 从成熟 AR MoE 权重出发,用块级课程改变可见性和目标.它回答「能否把已有语言几何迁移到扩散式生成」.两者共享家族名,能力来源不同.

把块长记为 $B$.AR 是 $B=1$,整段双向扩散是 $B=L$.转换开始若直接从 1 跳到 $L$,每层 attention 突然看到未训练过的右侧边,输出头的标签关系也改变,优化可能遗忘.块级 WSD 让 $B$ 和可见图逐步变化,为新目标提供连续路径.

warmup 阶段增加块长、打开双向;stable 阶段强化大块或全序列去噪;decay 阶段缩回部署块长.这里的 decay 不是只降学习率,也包含结构课程收束.终点选择较小块,因为块前缀可缓存,块内并行仍保留部分速度优势.

MoE 路由也面临分布变化.AR token 的 hidden state 只看左前缀,双向块内状态看见未来与 mask.专家负载和路由语义会漂移.转换成功说明原权重可适应,不能推出 MoE 在两种目标下内部路由完全相同.公开主表是整包配方,组件归因需要专门消融.

2.0 的知识能力主要继承 Ling AR 阶段.扩散转换 token 和课程负责重塑条件分布、采样与 serving.将 flash 的 HumanEval 94.51 当作「100B 扩散从噪声学出代码」会错置来源;更准确的说法是 AR 预训练能力在扩散化后得以保留并通过新后训练发挥.

CAP 提高已预测正确位置的置信或降低熵,让每步提交更多 token.吞吐提升同时依赖模型置信度、阈值和 dInfer 实现.它属于采样/服务层,不改前向 corruption.535 TPS 与文内 AR 基线构成受控结果,跨硬件与 Mercury 数字没有直接比例.

2.0 把严格全序列双向改成部署友好块,也改变模型族.它无法同时声称所有位置任意互相条件和严格前缀 KV cache;块边界规定信息流.评测若主要是左到右回答,这种交换很划算;任意非连续 infilling 是否保留同等能力,需要单独验证.

### 6.7. 一条四 token 轨迹把公式落地

设干净回答为 `(A,B,C,D)`,某次训练抽到 $t=1/2$,mask 结果为 `(A,M,C,M)`.模型在位置 2 看到左右两侧 A、C,在位置 4 看到 A、C 与边界,分别预测 B、D.损失为

$$
\ell=2[-\log p_\theta(B\mid A,M,C,M)-\log p_\theta(D\mid A,M,C,M)].
$$

系数 2 来自 $1/t$.位置 A、C 不进监督,但参与 hidden states.另一次 mask 为 `(M,B,M,D)`,同一句话提供完全不同的条件切片.训练期遍历这些切片,模型才获得任意方向补全能力.

生成从 `(M,M,M,M)` 开始.假设第一步各位置最高置信度为 $(0.8,0.3,0.7,0.4)$,预算提交两个位置,低置信策略先写 1、3,状态变为 `(A,M,C,M)`.第二步条件正好接近上面的训练状态,再恢复 B、D.随机策略可能先写 2、4,若二者依赖 A、C 就更易出错.同一组边缘预测,提交顺序改变后续条件.

若第一步把错误的 $A'$ 以 0.9 高置信写入,后续所有位置都条件于它.纯吸收采样不再遮已提交 token,错误冻结.带 remask 的采样器可重新评估已填位置,把后来变低置信的 $A'$ 盖回去.代价是反向链偏离解析 posterior,并增加计算.实际质量来自这一偏差—修错交换.

块长 2 时,先生成 `(A,B)`,缓存完成块,再生成 `(C,D)`.第二块能看见干净前缀,块内 C、D 双向协作.它无法让第一块利用 D,因此任意双向条件弱于整段扩散,却能复用前缀 KV.块长从 1、2 到 4形成 AR、混合、纯扩散三种因式分解.

SFT 再加入提示 `(Q_1,Q_2)`.提示固定,回答四格走同样 corruption.如果训练数据把 EOS 放在 C、后面 D 为 padding,网络会学到「看到部分回答时,C 常是 EOS」.因果采样若过早在 C 写 EOS,裁剪器会丢掉之后内容;纯扩散可以在全局状态中同时协调正文与 EOS.结束符处理属于概率模型的一部分.

### 6.8. 采样调度的三种误差

第一种是离散化误差.理论连续反向过程包含无穷小事件,实际只走 $T$ 步.每步跨度大时,许多 token 同时从 mask 变干净,网络的因子化输出忽略它们的联合.增加 $T$ 会缩小单步提交集合,代价是更多全序列前向.

第二种是模型误差.$p_\theta(x_0^i\mid x_t,t)$ 没有等于真后验边缘.数据不足、模型容量、时间条件、SFT 域移都会造成偏差.增加步数只能让错误有更多机会被上下文修正,不能保证消失.若正确 token 从未有可见概率,调度无法救回.

第三种是策略误差.低置信排序把网络概率当作可靠的不确定性,校准失真时会先提交错误.随机后验在理论模型精确时有依据,在有限模型下浪费计算.块边界、CFG、温度和 EOS 规则都属于策略.论文表明策略误差可以大到让 GSM8K 从 70 附近降到 21 或 0.

三种误差可用不同实验分离.固定权重扫步数观察离散化;在相同 mask 状态测 token calibration 观察模型;固定步数与温度换随机/低置信/块策略观察调度.只看最终准确率,三者混在一起.一个新 sampler 提升分数也不代表预训练分布变好.

时间日程决定每步预算.均匀时间网格在线性 $\alpha_t$ 下近似均匀揭示;非线性日程会把更多步骤放在高噪声或低噪声区.语言生成的难度并不随 mask 比例线性:接近全 mask 时要决定主题,中段形成结构,末段修局部词.最优日程可能与任务、长度和后训练不同.

置信度提交通常规定每步保留多少 token,形成确定性数量曲线.若所有位置都不确定,它仍被迫提交一些;若全部很确定,固定预算又限制速度.阈值法按绝对置信度动态提交,需要良好校准且可能出现某步零进展.CAP 的方向是让更多正确位置越过阈值,提高 tokens per forward.

温度同时改变词选择与置信度排序.降温使分布尖锐,可让更多 token 提交,也会把错误放大成高置信.升温增加多样性,低置信调度可能不断重做.因此温度不能只按最终文本多样性调,还要看每步提交数、首次写对后保留率和错误冻结率.

CFG 把条件 logits 与无条件 logits 外推,同样会抬高某些位置置信度.若 guidance scale 按任务从集合里挑最好,主表等于含一个额外验证集超参.原论文主对照不开 CFG,保持与 ARM 的协议更干净.后续工作若默认开启,需要单列无 guidance 基线.

### 6.9. 似然估计的方差从哪里来

对于一条完整文本,随机抽 $t$ 与 mask $x_t$,单样本估计

$$
\widehat L(x_0)= -\frac1t\sum_{i:x_t^i=M}\log p_\theta(x_0^i\mid x_t,t)
$$

对训练目标无偏,方差来自时间和 mask 两层.高噪声时 mask 多、上下文少,损失大;低噪声时 mask 少、$1/t$ 大.同一文本两次估计可能相差很远.多选题若每个选项独立抽随机源,这种噪声会直接翻转排名.

用相同 $t$ 与对齐 mask 比较候选,公共难度可抵消.候选长度不同或 tokenization 不同时,mask 如何对齐需要定义.按 token 总和偏好短文本,按长度平均改变概率含义.论文的任务 harness 固定协议,复现数字必须沿用,不能把一种归一化结果当成模型固有分数.

似然界还受 Monte Carlo 样本数影响.少量样本足够训练随机梯度,评测要求稳定排序,通常需要更多重复.报告准确率而不报告估计样本数,别人可能得到不同多选结果.VRPO 后续专门处理四项 ELBO 差的方差,说明该问题在偏好训练里更加严重.

生成评测避开显式似然,引入 sampler 方差.同一提示换随机种子、初始 token 抽样或置信并列顺序,答案可能变化.pass@1 需要跨提示统计,pass@k 又受样本相关性影响.扩散不同轨迹可能共享大量早期高置信 token,不能假设 k 个样本完全独立.

对 MMLU 这类多选,似然评分与直接生成选项字母也不是同一任务.前者比较候选文本,后者要求模型遵守输出格式并经历去噪.Base 表使用哪种接口决定数字含义.将似然 MMLU 和生成 GSM8K 平均成一个总分,会把估计器与 sampler 两类误差混为一谈.

### 6.10. 版本变化应怎样归因

LLaDA 8B Base 建立从头预训练基线;Instruct 只加 SFT;1.5 加离线偏好;d1 加推理 SFT 与在线 RL;2.0 更换起点为 AR MoE 并加入块级转换、服务优化.这不是同一 checkpoint 逐次升级的简单版本号,每一步的数据、架构或训练起点都可能改变.

若比较 8B Instruct 与 1.5,可把同基座、同评测协议下的变化主要归给偏好训练配方,仍要考虑采样器选择.比较 8B 与 2.0 时,参数量、MoE、AR 预训练数据、转换和后训练全变,无法把分数提升归给 WSD 某一组件.

2.0 的 mini 与 flash 也不是只差参数规模.底座、活跃参数、训练和 serving 配置需要分别记录.MoE 总参数不等于每 token 计算量,拿 100B 总参数直接与 dense 8B 做 FLOPs 推断会误导.主表能证明成品竞争力,组件因果依赖消融.

后续缓存论文在原 LLaDA 权重上加近似推理,解决重复全序列计算.它们提高吞吐但可能改变 logits 或提交轨迹.缓存加速后的准确率—延迟曲线属于 sampler/system,不能回填成原模型训练成果.同理,dInfer 与 CAP 的吞吐属于 2.0 整体部署栈.

LLaDA-MoE 从零训练的稀疏路线又是另一分支.它可回答扩散目标与 MoE 共同从头学习是否可行,2.0 则回答 AR MoE 能否迁移.两条证据互补.若只看参数名里的 MoE,容易把知识来源混在一起.

最稳妥的家族表应列:起点、参数/激活参数、预训练 token、SFT/偏好/RL、注意力可见性、块长、默认 sampler、缓存方式、评测协议.版本号只是索引,这些字段才决定可比性.

### 6.11. 六个反例防止过度归因

反例一:某模型 GSM8K 高,不代表扩散目标更会数学.若训练数据含更多数学、提示 shot 不同或 sampler 更强,终点差值无法拆解.同数据 ARM 曲线才隔离一部分目标效应.

反例二:反向诗歌高,不代表知识天然双向存储完整.模型可能记住固定诗句并擅长 infilling,对新事实的逆关系仍失败.需要控制训练暴露与实体关系的反转实验.

反例三:纯扩散 HumanEval 高于因果 sampler,不证明一次并行计划代码.纯扩散仍走数百步,每步全序列计算;它只说明双向迭代轨迹更适合该权重.真实规划证据需分析 token 提交顺序与修订.

反例四:2.0 达到 100B,不证明 100B 扩散从头预训练成本已解决.它继承 AR 权重,把问题换成转换.从头路线的算力与稳定性仍由 8B/LLaDA-MoE 等证据支持.

反例五:吞吐超过文内 AR,不代表所有 batch、长度和硬件都更快.扩散并行收益依赖一次提交多个 token,全序列重复前向又昂贵.短回答、低并发或置信度差时工作点会移动.

反例六:加 RL 后分数提高,不证明扩散策略概率估计无偏.VRPO 降 ELBO 差方差,diffu-GRPO 使用一步代理,都是可运行近似.经验有效与概率等价是两层结论.

这些反例共同指向同一纪律:模型家族的「扩散」标签只固定部分结构.数据、起点、后训练、采样器和系统可各自产生大幅变化.结论应贴到最小可支持单元,例如「8B Base 在作者同数据曲线上未显著落后 ARM」,而非把整个家族概括成单一胜负.

### 6.12. 一套统一的评测矩阵

横轴先固定生成接口:纯扩散、块扩散、低置信 remask、严格左到右.纵轴固定模型阶段:Base、SFT、偏好优化、推理 RL、2.0 转换.每个格子再记录步数、块长、画布长度、温度与 CFG.这样才能看出某次提升来自权重还是接口.现有论文只填了矩阵的一部分,空格不能靠相邻数字推算.

Base 最适合检验预训练分布和双向补全.应同时给似然/ELBO、多选、自由生成、FIM 与反向条件.似然评估需要 Monte Carlo 次数,生成需要 sampler.Base 不受指令模板和奖励模型影响,适合与同数据 ARM 比目标,但用户体验不是它的任务.

SFT 阶段重点看提示条件、格式、EOS 和长度.同一题用不同画布长度,如果答案内容稳定而结束位置变化,长度控制尚可;若长画布诱发重复或短画布破坏推理,需要显式长度策略.再把回答区随机 mask 与真实 rollout 中间状态比较,判断训练 corruption 是否覆盖部署轨迹.

偏好和 RL 阶段要增加奖励、KL、概率估计方差与采样轨迹指标.终点准确率上升时,观察置信度是否变尖、平均提交 token 是否增加、生成顺序是否退化为左到右.扩散的结构优势可能在后训练中被奖励捷径压掉,终点榜单看不出来.

2.0 还需把质量与服务一起测.同一 checkpoint 在不同块长、阈值、batch 和上下文长度下画 Pareto.吞吐必须说明 prefill/decode 边界、硬件与并发.块越小越接近 AR 缓存,块越大越接近全局双向;最优点由任务和系统共同决定.

保留能力贯穿所有阶段.从 Base 到 SFT、偏好、RL、转换,固定一组通用知识、语言建模、双向填空和因果续写.某版本总分提高、反向填空下降,可能是后训练把模型推回常见左到右分布;某版本速度提高、长程一致性下降,可能是块边界限制.家族演进不应只保留最新一列.

统计上对生成任务采用配对提示与多随机种子.扩散随机性来自 token 抽样、并列置信位置和可能的 remask.小幅增益若落在种子方差内,无法归给版本机制.多选似然则共享时间与 mask,降低候选比较噪声.两类评测需要不同的方差控制.

### 6.13. 前向目标与后续版本之间没有被改变的核心

家族各版本仍围绕「部分 token 可见,恢复其余 token」组织条件分布.8B 从头训练把它用于完整语言学习;SFT 把可见区固定为提示;1.5 在完整回答概率估计上加偏好;d1 用 mask 代理支撑策略更新;2.0 将任意全序列可见性约束成块内双向.变化的是起点、可见图和优化层,核心接口仍是 mask 条件恢复.

这个接口带来方向灵活性.任意位置可作为条件,中间缺口、后缀条件和多洞补全无需重写输入顺序.它也带来概率难题:多个缺口同时恢复时,逐位置输出无法完整表达联合;完整回答似然比 AR 更难精确计算;有限步采样需要决定先相信哪些位置.

AR 连乘把联合问题转成唯一顺序的条件概率,精确似然和 KV cache 因此简单,方向被固定.LLaDA 把顺序推迟到采样器,训练覆盖许多可见集合,获得灵活性,也让 sampler 成为模型定义的一部分.两种范式的差异不宜缩成「并行快、串行慢」.

块扩散表明二者存在连续谱.块长 1 拥有 AR 的缓存和精确顺序,大块增加并行与右侧条件.转换课程沿这条谱移动权重,部署再选一个工作点.因此 LLaDA 2.0 的意义不只在 100B,还在于把模型族差异改写成可调结构参数.

后训练同样沿连续谱工作.偏好目标关心完整回答,可不指定生成顺序;在线 RL 若基于真实轨迹,会直接塑造顺序;一步 mask 代理则更像训练条件恢复器.选择哪种概率接口,决定奖励究竟落到终点分布还是实际去噪路径.

### 6.14. 仍缺哪些关键证据

从头训练仍缺更大规模的严格同数据对照.8B 和从零 MoE 提供起点,100B 2.0 继承 AR.要回答扩散预训练在百亿以上是否拥有相同 scaling efficiency,需要从随机初始化训练并给出 token、FLOPs、数据与 ARM 配对,成本极高.

联合建模缺口需要更直接测量.下游准确率混入知识和 sampler,可构造同时约束多个位置的 ParallelBench、成对一致性或可枚举任务,比较一次提交数与错误相关.若增大步数只修复联合冲突,机制会更清楚.

似然仍缺统一、低方差的公开 harness.不同论文用 ELBO、随机 mask 分数或生成评测,多选协议也不统一.共享随机、样本数与长度归一化应成为报告字段.没有统一接口,「扩散 PPL」容易跨界比较.

后训练缺同数据 AR 对照.相同 Base 能力、相同 SFT/偏好/验证器数据、相同 rollout 预算下,比较 AR DPO/GRPO 与扩散版本,才能判断额外概率估计方差换来了什么.现有结果主要证明可行,尚未形成架构优劣结论.

动态长度也是核心空位.固定画布适合基准,真实回答长度未知.模型应联合决定内容和结束,或采用可扩展块.若长度控制依赖外部预测器,整体模型多一个误差源;若用 EOS,又要处理并行位置间的结束一致性.

缓存与双向性的严格边界仍需量化.近似 cache 能加速多少、logits 偏差如何积累、哪些任务依赖跨块未来条件,需要同一权重的系统曲线.速度提升后只报 GSM8K 一项,不足以覆盖代码、长文和任意 infilling.

最后是开放复现.8B 给出了难得的训练 token、GPU 小时和架构细节,数据混合与完整训练资产仍决定复现门槛.2.0 的 MoE 转换涉及底座、并行栈与后训练.家族开放程度应按权重、数据、代码、超参和评测 harness 分项描述,不能由「开源模型」四字概括.

### 6.15. 时间离散误差不只由步数决定

连续反向过程描述无穷多个微小显露事件,实现选择网格 $1=t_T>t_{T-1}>\cdots>t_0=0$.若线性等距,每步时间跨度相同;模型面对的条件难度与 mask 数却随位置、内容和置信度变化.同样的 $\Delta t$,早期从几乎全 mask 中提交 token,和末期补最后几个洞不是同一种误差.

将一步反向核记为 $P_{s\leftarrow t}$,理想连续演化满足 Chapman–Kolmogorov 组合.神经近似核通常不满足

$$
P_{r\leftarrow t}=P_{r\leftarrow s}P_{s\leftarrow t}.
$$

走一个大步与走两个小步会得到不同分布.差异一部分来自数值离散,另一部分来自网络在中间状态重新条件化后修正预测.所以增加步数的收益并非单纯更精确地积分同一个向量场,还包含更多次「看见新 token 后重新思考」.

可用步长加倍实验估计局部误差.从同一 $x_t$ 出发,一条路径直接到 $x_{t-2\Delta}$,另一条经 $x_{t-\Delta}$ 两步到达,比较两者的 token 边缘、联合约束与终点质量.若差异集中在同时提交的相关位置,因子化是主因;若连单位置边缘都大幅变化,时间条件或模型校准也有问题.

等距网格不是唯一选择.按照累计保留率 $\alpha_t$ 等距,可让每步期望揭示量更平衡;按照模型熵或验证集误差自适应分配,可在困难区放更多步.自适应网格会让不同样本使用不同状态分布,批处理和复现更复杂.一张「T=128」表不说明这些 128 步落在哪里.

低置信提交把时间网格与位置预算拆开.名义时间从 $t$ 到 $s$,解析后验规定期望显露数,策略再把名额分给高置信位置.它保留数量、改变身份.阈值式 CAP 连数量也改变,实际时间不再由预设 $t$ 完全决定.此时用连续扩散的 $t$ 描述 sampler 只剩近似含义.

块扩散还有块边界误差.一个 token 若恰在当前块外,即便物理距离只有 1,当前块也看不到;同块内距离很远的 token 可以双向交互.改变块对齐会改变结果.公平评测可随机平移边界或比较重叠块,避免某个基准答案格式刚好契合固定块长.

### 6.16. 训练随机 mask 与真实重掩状态有多远

训练前向核独立遮每个位置.给定 mask 比例,剩余洞近似随机散布.真实低置信采样的后期状态却把简单位置先填完,留下专名、数字、约束交汇点和模型犹豫的位置.这些洞高度相关,也更难.二者即使 mask 数相同,条件分布仍不同.

把训练状态分布记为 $q_t(x_t\mid x_0)$,采样访问分布记为 $d_\theta(x_t)$.训练风险在 $q_t$ 下最小化,部署误差在 $d_\theta$ 下累积.当采样策略依赖模型置信度时,$d_\theta$ 又随参数变化.这类似 imitation learning 的 covariate shift:模型只在随机破坏的真文本上学习,生成时要处理自己早先写下的错误文本.

可以采集 rollout 中间状态,再与相同 mask 比例的随机状态配对.比较 masked-token NLL、置信校准、错误簇大小和 hidden representation.若 rollout NLL 明显更高,训练 corruption 覆盖不足.加入一部分 on-policy 重掩状态训练可缩小差距,标签仍用原始 $x_0$;但模型生成错误可能使状态远离前向扩散的理论支持,目标从 ELBO 转向经验纠错.

重掩还产生选择偏差.某位置被留下,往往因为它已经高置信;继续对这些位置计算训练损失会高估简单 token.只训练剩余 mask,样本集中到难点,梯度更有价值,也会让常见词校准漂移.混合随机 mask 与 rollout mask 可兼顾似然目标和部署状态,混合比例属于新超参.

错误 token 的处理更棘手.原始吸收链已显露位置被视为干净,网络训练时从未看到「可见但错误」的 token.实际启发式采样会产生这种状态,双向 attention 可能把错误当硬证据传播.允许把低置信已填 token 重新 mask 只是发现错误的一种办法;模型还需学会在含错误上下文时降低其置信度.

可构造 token corruption 增强:在少量可见位置放入模型常见错误,要求恢复 mask 并识别冲突.这接近纠错去噪,会破坏「非 mask token 绝对可信」的吸收假设.收益若只体现在启发式 sampler,不应再把训练目标完整解释为原始扩散 ELBO.理论纯度与部署鲁棒性在这里发生真实交换.

不同后训练阶段会重塑 $d_\theta$.SFT 让格式 token 更尖,RL 让答案槽更尖,CFG 放大提示相关 token,CAP 进一步压熵.原 Base 上调好的重掩阈值到了新 checkpoint 可能过快提交.每次权重更新后重新测状态分布,比沿用旧步数更可靠.

### 6.17. likelihood estimator 的方差可拆成三项

对固定文本 $x_0$,估计器随机抽时间 $T$、mask 图案 $M$ 和可能的模型采样.用全方差公式,

$$
\operatorname{Var}(\widehat L)=
\operatorname{Var}_T\!\left(\mathbb E[\widehat L\mid T]\right)
+\mathbb E_T\operatorname{Var}_M\!\left(\mathbb E[\widehat L\mid T,M]\right)
+\mathbb E_{T,M}\operatorname{Var}(\widehat L\mid T,M).
$$

最后一项在直接 teacher-forced 打分时可接近零,前两项分别是跨噪声层与同层 mask 方差.VRPO 的研究显示时间分配往往比在同一时间重复 mask 更重要,与这一分解一致.

时间重要性采样可令高方差区域多抽样,用密度比保持无偏.最优提议大致与被积函数绝对值或梯度范数成正比,真实分布未知,可用验证集分桶估计.若只按 loss 大小分配,极难样本会占满预算;按对候选排序的方差分配更贴近多选评测.

控制变量也能降方差.例如用一个便宜模型或同文本的平均 token loss 预测当前 mask 难度,从估计中减去零均值残差.比较两个候选时共享 $T,M$,等价于利用公共随机数.候选相似度越高,噪声相关越强,差分越稳定;长度与 tokenization 差异会削弱相关.

评测应报告估计标准误.若两个选项分数差小于 Monte Carlo 误差,硬选一个会制造不稳定准确率.可以增加样本直到置信区间分离,形成自适应评估:容易题少算,难题多算.这会让每题计算不同,总预算和停止规则必须公开.

生成任务的 likelihood 仍可作为诊断.对模型自己生成的答案重新加噪打分,高分不保证实际轨迹概率高,因为完整终点概率对多条去噪路径求和.它衡量的是条件恢复一致性.若 RL 后奖励上升、重构分数下降,策略可能利用 sampler 找到验证器高分但基础模型低密度的区域.

长度归一化再次出现.完整回答 loss 求和对应序列概率,天然惩罚长文本;按 token 平均便于跨长度比较,不再是同一个概率.多选答案长度差大时,应说明是否使用 length normalization.不同论文数字若一方求和、一方平均,不能直接并排.

### 6.18. 长度是一个隐藏的生成变量

固定画布把最大长度 $L$ 当外部条件.模型实际学习 $p(x_{1:L}\mid prompt,L)$,EOS 和 pad 决定可见文本.改变 $L$ 不只是多给计算空间,也改变条件分布:训练中长画布可能对应长回答类型,位置编码和 padding 比例都在泄漏长度先验.

一种方案先用长度预测器采样 $L$,再运行扩散.联合分布分解为

$$
p(y\mid x)=\sum_Lp_\psi(L\mid x)p_\theta(y\mid x,L).
$$

长度预测错短会截断,错长会增加重复与 EOS 管理.预测器可按监督长度训练,人类答案长度不等于任务所需最优长度;偏好训练后模型可能更简洁,旧预测器随即失配.

另一方案固定较长画布,让 EOS 成为普通 token,取最早 EOS 前内容.并行预测可能在多个位置产生 EOS,前部偶然 EOS 会裁掉后面正确推理.可以约束 EOS 后所有位置为 pad,形成跨位置联合规则;逐位置交叉熵没有显式保证这条单调结构.

块式动态扩展把长度决策推迟.先生成一个块,若未结束再追加块.它接近 AR 的逐步停止,长度粒度是块.前缀块可缓存,最后一块可能浪费空位.块越大并行越强,过度生成越多;块越小长度灵活,串行深度增加.

还可把「继续/停止」设为每轮全局动作,与 token 去噪分开.全局头观察当前草稿与不确定性,决定扩展画布或交卷.训练需要部分轨迹标签:在什么状态下答案已足够.只用最终长度监督无法告诉中途何时停止,RL 奖励又可能鼓励过早结束以减少出错.

长度评测至少扫多个 $L$,报告截断率、首 EOS 位置、EOS 后非 pad 比例、重复率和任务分数.某模型在 512 最佳、256 截断、1024 重复,不能用最佳一格代表稳定长度建模.d1 数独随长度增加下降就是具体提醒.

LLaDA 原训练让 1% 样本随机长度,缓解只会固定 4096 块的问题,尚未解决自由停止.它提供长度条件多样性,最终生成长度仍由用户或采样器指定.2.0 的块服务使动态追加更自然,是否训练过相应停止策略需另看实现.

### 6.19. Inpainting 的条件分布比 FIM 更一般

设已知位置集合为 $O$,未知集合为 $U$.条件生成目标是

$$
p(x_U\mid x_O)=\frac{p(x_U,x_O)}{\sum_{x'_U}p(x'_U,x_O)}.
$$

掩码扩散直接把 $O$ 放入输入、$U$ 初始化为 mask,反向过程只更新 $U$.已知位置可位于前缀、后缀、中间或多个不连续区域.网络的双向 attention 让每个未知位置读取所有已知证据.

AR FIM 将文本重排成 prefix、suffix、middle 的特殊模板,再从左到右生成 middle.对单个连续缺口,它同样能建模条件分布,且享受 KV cache.多个不连续缺口需要规定生成顺序、重复模板或一次生成带分隔符的所有片段.扩散用位置本身表达洞,接口更自然.

条件位置必须在每一步硬 clamping.若 sampler 允许已知 token 被重掩或覆盖,生成分布已不是所求 inpainting 后验.实现可在每轮网络输出后把 $O$ 恢复原值,attention mask 仍让未知读取它们.对文档编辑任务,用户原文是否允许修改应区分硬条件与软条件.

多个洞之间可能强相关.例如函数定义缺返回类型,调用处缺变量类型,两个位置要联合一致.逐位置同时采样仍会组合错误,多步条件化可缓解.先填哪个洞成为调度问题:置信度高的位置可提供新证据,信息增益大的位置未必置信度最高.最确定 token 与最有用 token 是两种标准.

可用条件熵描述信息价值.选择位置 $i$ 后,其他洞不确定性下降量为

$$
I(X_i;X_{U\setminus i}\mid X_O).
$$

高互信息位置像锚点,即使自身置信度中等,先提交可能帮助全局.普通低置信策略只看 $H(X_i\mid X_O)$,没有估计互信息.代码结构、表格约束和诗句格律中,锚点调度可能优于纯置信度.

inpainting 评测应控制缺口形状.随机 token mask偏局部语言恢复;连续 span 测 FIM;多洞测联合一致;后缀已知、前缀缺失测反向条件;大比例 mask 接近自由生成.只报一种 mask 率会把能力缩成局部补词.LLaDA 的诗歌反向属于后缀条件的窄例.

条件似然与生成准确率仍需分开.模型可能给正确补全较高似然,有限步 sampler 没抽到;也可能 sampler 靠启发式找到正确文本,ELBO 仍松.小空间任务可枚举候选验证条件概率,长文本用多次生成和约束通过率近似.

上下文污染是另一边界.若已知后缀本身错误,硬 clamping 会迫使模型构造与错误证据一致的前缀.双向条件能力越强,越可能合理化错误.产品编辑需允许标记不可信区域或给条件置信度,原始 LLaDA 条件接口把所有非 mask token 视为真.

### 6.20. 后训练目标怎样拉扯基础目标

基础扩散目标在数据分布的随机 mask 上最小化恢复风险.指令 SFT 把分布收窄到 prompt—response,并只腐蚀回答.参数更新同时改变通用文本恢复.若 SFT 数据格式单一,模型可能在自由 infilling 和无提示生成上遗忘,即使指令分数上升.

可混入预训练 replay:

$$
\mathcal L=\mathcal L_{\mathrm{SFT}}+\lambda\mathcal L_{\mathrm{base}}.
$$

$\lambda$ 控制指令适应与通用恢复.只看 MMLU 无法测完整保留,还要看不同 mask 比例、非连续洞与无条件生成.SFT 后 MMLU 小降可能来自数据质量,也可能是目标分布漂移,需要 replay 消融区分.

偏好目标关注完整回答间排序.它可以提高 chosen 相对 rejected 的 ELBO 差,同时让两者绝对似然都下降.基础重构项作为 anchor 能避免策略把概率质量移到未知区域.扩散 ELBO 估计有方差,anchor 还提供稳定逐 token 梯度.权重过大则偏好难以改变行为.

在线 RL 通过 sampler 生成回答,优化访问到的状态;基础目标在随机 mask 真文本上训练.二者状态分布互补.只做 RL 容易围绕少数验证任务收缩,只做基础 replay 又可能冲淡奖励.按 batch 交替或在同一回答上同时算代理策略 loss 和 denoising loss,会产生梯度冲突.

用梯度余弦可观察冲突:

$$
\cos(g_{\mathrm{RL}},g_{\mathrm{base}})=
\frac{g_{\mathrm{RL}}^\top g_{\mathrm{base}}}{\|g_{\mathrm{RL}}\|\|g_{\mathrm{base}}\|}.
$$

正值表示更新方向兼容,负值表示奖励在牺牲基础恢复.分时间桶计算还能看到 RL 主要改高噪声规划还是低噪声修词.单个总余弦会掩盖层与时间差异.

LoRA 限制更新子空间,常被当作保留机制.它降低全参数漂移,不能保证功能不忘;少数低秩方向也可大幅改变 logits 与置信排序.d1 的 SFT 与 RL 使用不同秩,说明容量本身是配方一部分.比较算法时需要固定 adapter 容量.

KL 正则通常在某种噪声条件分布上约束当前与参考模型.低噪声 KL 小,不代表全 mask 规划相同;逐 token KL 小,不代表提交顺序相同.按 $t$ 分桶并在真实 rollout 状态上测 KL,更接近 sampler 行为.参考模型若 sampler 不同,轨迹 KL 又没有直接可比性.

CFG 与奖励还可能方向冲突.偏好模型鼓励简洁,CFG 放大提示条件可能促成长回答;RL 让答案槽高置信,CAP 因而提前提交.最终变化是目标、置信与调度的合成.受控实验应先用统一 sampler 评价权重,再在每个权重上调 sampler,分别报告「模型增益」和「整包增益」.

### 6.21. 版本间受控归因的最小设计

要测从头扩散与 AR,使用同 tokenizer、数据顺序、参数/FLOPs、优化器和下游 harness.唯一改变 attention 可见性与目标.还需给 AR FIM 增强与扩散 infilling,区分通用语言建模和方向灵活性.同数据 ARM 曲线接近这一设计,但公开细节决定可重复程度.

要测 AR 转换课程,固定同一个 AR checkpoint,比较直接全双向、只改 attention、只改目标、渐增块长、完整 WSD.每条路线使用相同转换 token 与学习率搜索预算.终点同时测 AR 保留、全双向恢复和部署块性能.否则 WSD 整包胜出,无法知道哪阶段必要.

要测后训练,从同一个 SFT checkpoint 分叉:无更新、chosen-only SFT、VRPO、diffu-GRPO 或其他目标.使用同偏好/题目数据时,离线和在线数据形态仍不同,可先在可构造成对也可验证的数学任务上对齐.统一 sampler 评估,再允许各自最佳 sampler.

要测 sampler,冻结权重、随机种子与画布,只换时间网格、提交规则、块长和 remask.记录每步 token 正确率、提交数、修正数与终点分.同一终点正确率可能由完全不同轨迹得到,延迟和鲁棒性也不同.

要测服务系统,固定权重与目标质量,比较原版循环、近似 cache、块 cache、CAP 和并发调度.报告硬件、batch、prefill、输出长度与是否包含 tokenizer.质量等值线比单一 tok/s 更公平,近似缓存需要给误差与任务回退.

归因表还要标训练起点.8B Base 的起点是随机权重,1.5 起点是 Instruct,2.0 起点是 Ling AR,d1 起点与其 SFT 数据另有定义.若起点不同,后续 token 数不能代表总训练成本,成品分数也不能用来比较目标的数据效率.

对照失败时应保留负结果.例如直接全双向转换崩溃,它证明课程有必要;自回归 sampler 在 Instruct 崩溃,它揭示 EOS 与状态错配;随机 remask 大降,它证明有限模型下解析随机策略不够.这些失败比只列最佳数字更能界定机制.

### 6.22. 再看几组容易误导的数字

MMLU 65.9 对 65.4 差 0.5,只能说同量级.评测噪声、shot 模板和数据污染都可能覆盖这点.它足以反驳「扩散 8B 完全不能做知识题」,不足以证明架构领先.

GSM8K Base 70.3 对 48.7 差距大,数据混杂也大.数学语料比例、答案提取、生成长度与 sampler 都可能贡献.同数据 scaling 曲线提供方向证据,仍需最终 checkpoint 的严格 paired table 才能量化目标贡献.

Instruct GSM8K 69.4、77.5、78.6 分别对应不同采样设置.把最大值写成模型唯一分数会高估默认能力,只写纯扩散又会忽略可用上限.最佳做法是主数字后标 sampler,并列默认与调优值.

诗歌 42.4 对 GPT-4o 34.3 是反向一列,正向 48.8 对 82.7 同样重要.机制优势表现为方向差距小,成品语言能力仍有显著差距.省掉正向列会把一项针对性实验写成全面胜负.

2.0 flash 73.18 与若干 AR MoE 平均分接近,证明转换后的综合竞争力.平均分掩盖任务权重和协议,HumanEval 等单项又可能受污染或模板影响.它不能回答若保留 AR 解码同一底座会怎样,需要原 Ling 对照和逐项变化.

535 TPS 对 256/237 TPS 的约 2.1 倍属于文内系统设置.吞吐是批量 token 速率,用户单请求首 token 延迟、尾延迟可能不同.CAP 阈值 0.95 使提交更激进,任务质量应与速度一起看.跨论文 1109 tok/s 没有共同分母.

Fast-dLLM 的 27.6 倍常被误读为超过 AR 27.6 倍,实际对照是原始 LLaDA 循环.组合加速相对某些基线的 8.1 倍、相对 AR 的关系要看具体表.家族文章引用加速时必须保留分母.

训练成本 0.13M H800 GPU 小时提供数量级,硬件利用率、数据管线与重算策略影响实际 FLOPs.2.3T token 也不说明独立数据量.它是透明度很高的成本锚点,不宜换算成所有团队复现所需金额.

### 6.23. 一张机制地图

前向核决定训练状态来自哪里:随机时间、独立吸收 mask、非 mask token 可信.加权目标决定各噪声层如何贡献:线性日程给 $1/t$,只监督 mask.架构决定信息能往哪里流:8B 全双向,2.0 块内双向.这三层构成基础模型.

采样器决定有限计算怎样近似反向链:时间网格控制每步跨度,置信度控制先写哪里,remask 控制能否改错,块长控制缓存与双向范围,温度/CFG 控制分布尺度.同一权重因这层得到大幅不同分数.

后训练决定终点偏好:SFT 模仿回答,VRPO 比较偏好,diffu-GRPO 利用验证奖励.这些目标通过 logits 和置信度反过来改变 sampler 轨迹.基础目标 replay、KL 与 adapter 容量限制遗忘.

系统层把理论并行变成速度:无严格 cache 的全序列循环、近似 cache、块 KV、CAP 与 serving 调度.速度数字属于权重、sampler、实现和硬件的联合结果.只谈「扩散并行」无法预测吞吐.

评测层最后读取成品:ELBO/似然估计测数据密度,多选测候选排序,生成 benchmark 测权重加 sampler,inpainting 测任意条件,墙钟测系统.不同层的数字不能无标记混在一个排行榜.

沿这张地图定位一项结果,因果边界会清楚很多.8B 的 2.3T 主要证实基础层可规模化;诗歌反向证实条件可见性;Table 8/9 证实 sampler 重要;1.5/d1 证实后训练可接入;2.0 证实转换与系统层能扩到 MoE.家族价值由这些分开的证据组成,无需把每项都解释成同一个「扩散优势」.

### 6.24. 前向核变化会怎样传到目标和采样

线性吸收核只是一个选择.若把保留率改为余弦或分段日程,一般加权目标中的危险率随之变化,时间采样和反向 posterior 也要一起改.只换训练 mask 比例、不换权重,模型优化的是另一个风险;只换采样日程、不重新校准时间条件,网络会访问训练稀疏的区域.

设一般保留率为 $\alpha(t)$,单位置在 $t$ 前保持干净的概率为 $\alpha(t)$,瞬时被吸收的强度与 $-\alpha'(t)/\alpha(t)$ 有关.反向从 mask 恢复的危险率则与 $-\alpha'(t)/(1-\alpha(t))$ 相连.不同论文按时间方向定义 $t$,公式符号容易相反;最稳妥的检查是端点:数据端应全干净,噪声端应全 mask.

若前向允许随机替换成普通词,非 mask token 不再绝对可信.网络需区分原 token 和噪声 token,训练会监督更多位置,条件 inpainting 的硬 clamping 也要额外标记.这种核可能训练模型纠正可见错误,代价是失去吸收过程的简单 posterior.LLaDA 选择纯 mask,让生成和任意条件接口更清楚.

位置相关 corruption 也可注入结构.代码中标识符、自然语言中的内容词与标点采用不同 mask 率,能把预算放到难点;这会改变无偏似然权重,采样时还需匹配位置日程.若只为了 SFT 效果做启发式 mask,应将其描述为 denoising 训练,不要沿用原 ELBO 的全部解释.

块扩散可视为给前向核增加结构约束:过去块保持干净,当前块被腐蚀,未来块可能不可见.它不再是全序列 iid mask.训练目标与部署 cache 更匹配,任意双向条件范围缩小.2.0 的转换课程本质上让这个结构核从块长 1 移向大块再收回.

核、目标、采样必须作为三元组报告.同一权重用不同 sampler 可以运行,但理论对应已经改变;同一 sampler 接不同前向训练权重,状态分布也可能错配.许多「扩散模型」共享 mask token,三元组不同,不能只凭名称交换代码和超参.

### 6.25. 基础模型的校准为何影响整个家族

低置信 remask、CAP、动态停止和部分缓存策略都读取 token 概率.若基础模型校准良好,0.9 置信大致对应九成正确,阈值有稳定含义;若过度自信,错误先提交且难以重掩.准确率相同的两个 checkpoint,校准不同,有限步生成质量可相差很大.

可按噪声率画 reliability diagram.把 mask 位置按最大概率分桶,统计 argmax 正确率.高噪声全局规划与低噪声局部修补应分别画,因为同一置信值含义可能不同.SFT、CFG、温度缩放会移动曲线,全局一个 temperature 未必能校准所有 $t$.

序列级置信又不能由 token 概率简单相乘.多个位置错误相关,乘积会极小且假设独立.决定一次提交多少 token 时,更关心集合全对概率或预期错误数.若提交集合 $S$,边缘近似给预期错误 $\sum_{i\in S}(1-u_i)$,无法估计「至少一个错」的相关性.块越大,联合校准越重要.

后训练奖励常让正确答案 token 更尖,看起来有利于 CAP;它也可能让格式 token 过度自信、推理内容仍不确定.平均 TPF 上升不等于有效 token 上升.应把答案、解释、EOS 与 padding 分开统计首次提交正确率.

缓存方法若根据 token 是否稳定决定复用,同样依赖校准.某层 hidden state 看似变化小,后续 logits 可能在两个候选间翻转;置信 margin 比最大概率更能提示边界.缓存阈值、提交阈值和温度共同作用,分别调优会过拟合验证集.

校准评测还能连接版本归因.如果 1.5 相对 Instruct 的准确率提升主要来自更好排序,固定步数和 oracle sampler 下都应改善;如果主要来自置信变尖,低置信 sampler 提升更大,随机 sampler 变化较小.这种交叉实验能把概率质量和调度协同分开.

### 6.26. 最终应保留的因果链

LLaDA 8B 的第一层证据是从头训练.随机初始化、2.3T token、全双向 decoder-only 与吸收式加权目标共同得到可与开源 8B AR 同表比较的 Base.它说明规模化可行,没有隔离数据效率的绝对优势.

第二层是条件方向.任意位置 mask 让后缀、中间和多洞自然成为条件,诗歌反向展示了方向差值缩小.FIM AR 说明连续中间补全可由数据模板获得,所以优势应落在统一接口与多形状条件,不落在「只有扩散能填空」.

第三层是采样敏感性.纯扩散、块扩散、低置信 remask 与因果揭示在同权重上产生巨大分差.有限步模型由权重和 sampler 共同定义.理论 posterior 是起点,模型误差下的启发式策略可能更好.

第四层是后训练.LLaDA 原 Instruct 只有 SFT,后续 VRPO 与 d1 分别接入离线偏好和在线验证奖励.它们补足能力链,也引入 ELBO 方差与轨迹代理.可行性已经建立,同配方 AR 优劣仍待严格对照.

第五层是规模路径.2.0 没有把从头路线机械放大,而是从 AR MoE 继承知识,通过块级 WSD 改变生成接口.它把扩散化变成迁移问题,同时用块缓存与 CAP 接近服务需求.100B 成品证明转换可扩展,知识来源仍主要属于 AR 预训练.

第六层是证据边界.模型表、似然表、诗歌表、吞吐图各自回答不同问题.保留 shot、长度、sampler、起点、后训练和硬件后,数字才能被正确使用.去掉这些字段,同一家族内部都可能发生错误比较.

沿这条链读 LLaDA,它既不是「把 BERT 放大」这么简单,也没有凭一个 8B 主表改写自回归范式.它给出的更扎实结论是:全范围 mask 目标可以学出大型生成模型;生成顺序能从训练因式分解中释放出来;释放后的自由度必须由采样、后训练和系统重新管理.家族后续版本正是在逐层补这些代价.

### 6.27. 两个小型受控实验足以排掉很多误读

第一个实验只用合成括号与变量约束.序列左右两端给出变量定义,中间有多个洞,正确填法需要同时满足类型、括号闭合和重复变量一致.训练同尺寸 AR、AR-FIM 与 mask diffusion,数据完全相同.分别测试左到右续写、单洞、多洞和后缀条件,再扫扩散步数与块长.

这个实验可直接回答方向灵活性来自哪里.AR-FIM 若在单洞追平、在多洞需要额外序列化,说明模板覆盖边界;扩散若少步出现组合冲突、多步恢复,说明联合缺口;块长变化可画出缓存与条件范围交换.因为规则可执行,无需语言裁判,每种错误都能定位到边缘或联合.

第二个实验固定一个小 LLaDA checkpoint,从同一 SFT 权重分叉三条:继续基础 denoising、偏好优化、验证器 RL.所有路线用相同 token/FLOPs,评测随机 mask NLL、真实 rollout NLL、校准、任务奖励和不同 sampler.它能看见后训练收益是否以基础恢复、校准或方向能力为代价.

若偏好路线只在低置信 sampler 提升,随机 sampler 不变,收益可能依赖置信排序;若所有 sampler 都提升,权重本身更强.若 RL 奖励升而随机 mask NLL 恶化,说明目标向任务域收缩;加入 replay 后两者兼顾,可量化基础目标耦合.

两项小实验无法替代 8B 主表,却能提供主表缺少的因果结构.大模型证明现象可扩展,小模型严格控制变量.只做前者容易讲故事,只做后者又不知道规模化是否成立.LLaDA 家族最需要的是两类证据连接起来.

### 6.28. 写规格卡时别漏掉这些字段

训练字段包括起点、数据 token、序列长度、前向日程、时间采样、损失权重、mask 是否仅限回答、是否混入基础 replay.架构字段包括参数量、激活参数、MHA/GQA、attention 可见图、块长与 tokenizer.

采样字段包括总步数、时间网格、画布长度、提交数量或阈值、random/low-confidence remask、温度、CFG、EOS 规则和是否允许改写已填 token.后训练字段包括 SFT 数据量、偏好或奖励来源、概率估计器、KL/reference 与 adapter 容量.

评测字段包括 shot、候选似然或直接生成、Monte Carlo 次数、长度归一化、答案抽取、随机种子和 sampler.系统字段包括 cache 类型、近似误差、硬件、batch、prefill 是否计入、吞吐与单请求延迟.

这些字段看起来繁琐,因为扩散模型把原本藏在左到右顺序里的选择显式化了.AR 默认顺序同时规定状态、缓存、长度推进与概率分解;LLaDA 允许重新选择,每个选择就成为实验变量.规格卡写全以后,69.4、78.6、535 TPS 和 2.3T 才各自回到正确位置.

如果一篇后续论文只报最好任务分数,至少追问四件事:起点是不是同一模型,采样器是否变化,后训练数据是否增加,计算预算是否匹配.四项中任何一项不明,结论应停在成品比较.只有受控分叉与组件消融,才能把变化写成机制贡献.

LLaDA 家族由此提供了一套很好的阅读训练:看见「扩散」先找前向核与目标;看见榜单先找 sampler;看见新版本先找起点;看见加速先找分母.这四步比记住某个单项第一更耐用,也更接近论文真正留下的知识.

### 6.29. 一个最终的选择题

如果任务主要是标准左到右对话,已有成熟 AR 权重、严格延迟要求和长上下文 cache,LLaDA 式全序列扩散未必是最低成本选择.块转换可以继承权重并购买部分并行,实际收益取决于每步能可靠提交多少 token.当置信度不足、输出很短或 batch 很小,重复全序列计算可能抵消并行优势.

如果任务天然含后缀条件、多洞编辑、表格补全或代码约束,任意 mask 接口减少了把问题改写成左到右模板的成本.此时评测应直接覆盖这些条件形状,不能只用聊天榜单决定模型价值.扩散的优势首先是条件图灵活,速度是另一条需要系统验证的线.

如果目标是研究预训练范式,应看 8B Base 与同数据 ARM,不要让 2.0 的 AR 起点替代从头证据.如果目标是部署大模型,2.0 的转换路线反而更现实:重新支付百亿参数预训练只为改变生成接口,经济上很难成立.

如果目标是推理后训练,需先决定奖励落在完整答案还是实际轨迹.VRPO 更接近终点偏好分布,diffu-GRPO 用便宜代理支持在线探索.两者都要与 sampler 联合验收.只训练 reward、沿用旧置信阈值,可能把权重提升丢在错误调度里.

如果目标是比较架构,最重要的资源不是再加一张总榜,而是一套同数据、同计算、同后训练、双 sampler 的对照.让 AR 使用合理 FIM 与 cache,让扩散使用合理 remask 与块策略,再分别测试续写和任意条件.这样的结果可能没有一句「谁取代谁」痛快,却能告诉使用者在哪些任务、预算和条件图上选择哪条路线.

LLaDA 至今最可靠的贡献正在这里:它把原本看似绑定的几件事拆开了.语言规模化可以不依赖固定左到右因式分解;条件方向可以由 mask 集合指定;生成顺序可以在推理期选择;AR 权重又可以通过课程迁移过来.拆开之后没有免费午餐,似然估计、联合采样、长度、缓存和后训练都要重新回答.这套问题清单本身,比某一版模型的短期排名更有生命力.

后续版本若声称解决其中一项,也应检查代价有没有转移到另一项:更少步骤是否增加联合错误,更强缓存是否缩小双向范围,更高奖励是否损害基础恢复,更灵活长度是否增加停止方差.把收益和转移后的代价放在同一张表里,才算真正推进了这条路线.

8B Base 的 GSM8K 高于 LLaMA3 Base,推不出「扩散更会数学」.同数据 ARM baseline 才是公平对照;跨公司数据配比是混杂因素.作者自己写了这句.

没有 RL 的 Instruct 落后有 RL 的 LLaMA3 Instruct,推不出「扩散对齐不了」.只能推出:这篇论文没有做 RL.1.5 和 d1 后来补上了,口径仍要写采样器和 0-shot / 4-shot.

全双向 8B 推不出「扩散不能 KV Cache」.2.0 和 Fast-dLLM 已经走块扩散与近似缓存.8B 论文的架构选择是当时公式下的简化.Fast-dLLM 在 LLaDA-Instruct,GSM8K 5-shot,生成长度 256 上,从 6.7 tok/s 到组合加速 54.4 tok/s,约 8.1 倍;27.6 倍那一格的对照物是原版 LLaDA 循环,不是 AR.细节见[推理加速](../../06-推理加速与系统/6.4-kv缓存与推理加速/6.4-kv缓存与推理加速.md).

把诗歌反向 42.4 抄进产品总榜,推不出聊天,代码,代理全面超过 GPT-4o.正向 48.8 对 82.7 写在同一张表上.

把 2.0-flash 的 535 TPS 和 Mercury Mini 的 1109 tok/s 减出「谁快一倍」:硬件,是否含 prefill,batch,评测集都不同.两者只能并列报告.

### 6.1. 读完应留下的规格卡

- 8B Base:2.3T,MMLU 65.9,GSM8K 70.3,HumanEval 35.4(Table 1,$*$ 协议).BBH 49.7 对 62.1,Hellaswag 70.5 对 79.1.
- 8B Instruct:仅 SFT,Table 2 纯扩散 GSM8K 69.4;块长 8 的块扩散 LLaDA 可到 78.6.
- 不兼容当时的 KV Cache,故用 MHA 不是 GQA.
- 诗句:正向 48.8 / 反向 42.4,GPT-4o 为 82.7 / 34.3.
- 2.0-mini 16B / flash 100B MoE,平均分 64.34 / 73.18;flash-CAP 535 TPS,约 2.1× 于文内 AR 基线.
- 从零稀疏另一条河:LLaDA-MoE 非嵌入 7B,激活 1.4B,约 20T,见[LLaDA-MoE](../3.2-llada-moe/3.2-llada-moe.md).该从零训练路线与 2.0 的 AR 改编路线不同.

把 8B 和 2.0 放在同一条「LLaDA 家族」里读时,记得训练起点不同.8B 的语言几何是掩码扩散自己刷 2.3T 刷出来的;100B 的语言几何主要是 Ling AR 阶段刷出来的.评「扩散能不能从噪声长出知识」,只用 8B.评「扩散能不能接到现有 MoE serving」,用 2.0.flash 的 HumanEval 94.51 是转换课程的结果,不是从头训练的能力.

8B 的 13 万 H800 小时是公开数字里很少见的「从头训扩散 LLM 要多少钱」.改编路线存在,就是因为这个数字劝退了 100B 从头训.2.0 复用 AR 权重,避免重新支付 100B 从零预训练的算力;转换课程没有降低从零训练本身的成本.逃避得对不对,看 flash 平均分 73.18 对 Qwen3-30B-A3B 的 73.60 那一格,同档,不是碾压.

HumanEval-FIM 73.8 对 LLaMA3 的 73.3 说明填空可以被 AR 用数据增强买到.扩散买到的是不必另开 FIM 模板:任意一组位置同时是空位,不必是连续 middle.产品若只有「函数中间缺一块」,FIM 够用;若表格缺不相邻的几格,掩码扩散少一层改写.

规格卡再补一条读法.8B Base 的 GSM8K 70.3 是生成,MMLU 65.9 是似然估计,不要合成「综合分」.Instruct 的 69.4 是纯扩散,78.6 是块采样,不要合成「指令分」.2.0 的 535 TPS 对照文内 SGLang AR,不要对照 Mercury Mini.三条读法挡住了三类常见误读.

CFG 的 Table 6 还说明一件评测纪律.主表不开 CFG,是为了和 ARM 公平.开了之后 Hellaswag 从 70.5 到 72.5,仍低于 LLaMA3 的 79.1.引导能加分,加不回数据量和因式分解一起造成的那截常识续写差距.

8B 的同数据 ARM baseline 才是「扩散目标能不能 scale」的证据.跨公司的 2.3T 对 15T 混了语料.Fig. 3 用 FLOPs 当横轴,作者拒绝拟合幂律,只说走到 $10^{23}$ 量级下游没有突然塌掉.读规模故事时用这条曲线,不要用「LLaMA3 看了更多 token 所以应该全面领先」或「扩散用更少 token 所以更高效」.两句都缺同配比.Table 1 能说的是:在他们的数据和公式下,8B 扩散可以和当时的开源 8B AR 坐同一张下游表.坐上桌子,不等于每一格都赢.BBH 49.7 对 62.1,Hellaswag 70.5 对 79.1,同一张表上写着.

SFT 450 万对只掩回答,损失仍是 $1/t$ 加权掩码交叉熵.模型学的是「在干净提示旁边把回答从噪声里擦出来」.所以 Instruct 权重拿去当因果模型逐步揭最左边一个掩码时,会和垫进去的 `[EOS]` 打架,GSM8K 可以掉到 0.这不是权重坏了,是解码器和训练分布不一致.块采样把结束符的传播挡在块边界,分数立刻回来.换采样器比再收集 450 万对便宜.规格卡因此把采样器写成规格的一部分,而不是脚注.
