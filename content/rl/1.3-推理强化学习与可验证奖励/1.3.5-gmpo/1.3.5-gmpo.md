# GMPO:token 重要性比的几何均值策略优化

GMPO(Geometric-Mean Policy Optimization)是 GRPO 的稳定化变体.**GMPO 保留 GRPO 的组相对 advantage,改变的是一条 rollout 内 token-level importance-weighted terms 的聚合方式:从算术平均换成几何平均.**

## 1. 从 GRPO 的 token 聚合开始

对 rollout $o_i$ 的第 $t$ 个 token,重要性比为:

$$
\rho_{i,t}(\theta)=
\frac{\pi_\theta(o_{i,t}\mid q,o_{i,<t})}
{\pi_{\theta_{\mathrm{old}}}(o_{i,t}\mid q,o_{i,<t})}.

$$

这里的 $\pi_{\theta_{\mathrm{old}}}$（图中简记为 $\pi_{\mathrm{old}}$）是产生当前 rollout 的策略快照，在该批数据的更新中固定。$\pi_{\mathrm{ref}}$ 若用于 KL 正则，会出现在另一条计算路径；论文的 GMPO recipe 省略 KL 项，importance ratio 仍使用 old policy。两者的作用应分开理解，见[论文第 2.2 节](https://arxiv.org/html/2507.20673v3#S2.SS2)。

GRPO 的未裁剪主项对 token 做算术平均:

$$
\frac1{|o_i|}\sum_t \rho_{i,t}(\theta)\hat A_i.

$$

$\hat A_i$ 仍由同一 prompt 的 rollout 奖励归一化得到.GMPO 不要求奖励为正,也不计算 $\log R_i$.

**图 1 解析**

- reward group 只负责产生 $\hat A_i$;几何均值不作用于 $r_1,\ldots,r_G$.
- 每个 token 的 $\rho_{i,t}$ 仍由当前策略与 old policy 在同一 token 上的概率比得到.
- 未裁剪时,$\rho_{\mathrm{geo}}=\exp(\operatorname{mean}_t\log\rho_{i,t})$,因此可在 log space 稳定实现.

图 1 中 $r=(0,1,0,1)$ 使用总体标准差，得到 $\operatorname{mean}(r)=\operatorname{std}(r)=0.5$，所选 $o_2$ 的优势为 $+1$。$o_2$ 的三个有效 token ratio 为 $(0.5,1,8)$，因此算术平均为 $3.1667$，几何平均为 $4^{1/3}\approx1.5874$。灰色 padding 不进入聚合。奖励组的标准差为零时，需在 advantage 构造阶段明确处理，不能直接除零。

## 2. GMPO 目标

忽略裁剪时,GMPO 用绝对值的几何均值控制幅度,再用 advantage 符号恢复优化方向:

$$
\left(\prod_{t=1}^{|o_i|}|\rho_{i,t}(\theta)\hat A_i|\right)^{1/|o_i|}
\operatorname{sgn}(\hat A_i).

$$

因为同一 rollout 的 $\hat A_i$ 对所有 token 相同,其梯度权重可以看成:

$$
\left(\prod_t\rho_{i,t}(\theta)\right)^{1/|o_i|}\hat A_i,

$$

即**序列内 token 重要性比的几何均值**.单个极端 $\rho_{i,t}$ 不再独自决定一个 token 的梯度权重.

**图 2 解析**

- $g_{i,t}=\hat A_i\nabla_\theta\log\pi_\theta(o_{i,t}\mid q,o_{i,<t})$ 表示带 advantage 的 token 梯度向量。比较发生在相同样本与参数处；两种方法对同一个 $g_{i,t}$ 使用不同的正权重。
- GRPO 分别形成 $\rho_{i,t}g_{i,t}$;GMPO 分别形成 $\rho_{\mathrm{geo}}g_{i,t}$,随后再求平均.
- 对正 ratio,AM-GM 给出 $\rho_{\mathrm{geo}}\le T^{-1}\sum_t\rho_{i,t}$.图中省略 clipping,只比较基本梯度权重.

图 2 使用二维示意向量来展示加权的后果：令 $T=3$、$\hat A=1$，$\rho=(1,1,8)$，$g_1=(1,0)$、$g_2=(0,1)$、$g_3=(-1,0)$。那么 $\rho_{\mathrm{geo}}=2$，有

$$
\nabla J_{\mathrm{GRPO}}=\frac{(1,0)+(0,1)+(-8,0)}3=(-7/3,1/3),\qquad
\nabla J_{\mathrm{GMPO}}=\frac{(2,0)+(0,2)+(-2,0)}3=(0,2/3).
$$

每个 token 的向量方向保持，但相对权重改变后，**加权求和的合成方向可以改变**。图示的是最大化目标 $J$ 的梯度；实现中最小化 $L=-J$，其梯度符号相反。示例向量用于解释机制，并非实际训练测得的梯度。

AM-GM 比较的是正标量权重，不能直接用于比较合成梯度的范数。例如 $T=2$、$\rho=(2,1)$、$g_1=(1,0)$、$g_2=(-2,0)$ 时，GRPO 的两个加权项恰好抵消，GMPO 则得到 $(-\sqrt2/2,0)$。因此，判断稳定性还需要考虑向量抵消、裁剪、数据与优化过程。

完整目标先按 advantage 符号在 token 层做裁剪,再在 log space 求几何均值.作者采用 $\log\rho$ 空间的对称裁剪 $[-0.4,0.4]$,等价于比例范围 $[e^{-0.4},e^{0.4}]$;这个数值属于论文 recipe,不是通用默认.

**图 3 解析**

- advantage 的符号先统一“有利方向”,所以正负 $\hat A$ 可以复用同一组 token-level clipping 步骤.
- `old_logp` 停止梯度,padding token 不进入 log-space 平均.
- 论文 $\epsilon=0.4$ 对应 ratio 区间 $[e^{-0.4},e^{0.4}]$;这是实验 recipe,不是 GMPO 的普适常数.
- reward 不进入 `log()`;$\hat A_i$ 仍由 GRPO 的组相对奖励产生.

图中的 `min` 同时接收原始 $u_t$ 与裁剪值 $c_t$。由于 $\min(u_t,\operatorname{clamp}(u_t,-\epsilon,\epsilon))=\min(u_t,\epsilon)$，映射回 $d$ 空间后，正 advantage 对应 $d_{\mathrm{eff},t}=\min(d_t,\epsilon)$，负 advantage 对应 $d_{\mathrm{eff},t}=\max(d_t,-\epsilon)$。这说明最终生效的是随 advantage 方向变化的单侧截断，而不是将全部 $d_t$ 无条件压进双侧区间。

数值示例使用 $d=(-0.7,0.1,0.8)$ 与 $\epsilon=0.4$：正 advantage 得到 $(-0.7,0.1,0.4)$，负 advantage 得到 $(-0.4,0.1,0.8)$。有效位置取平均后，分别得到 $\log\rho_{\mathrm{geo}}=-1/15$ 与 $1/6$。padding 不参与均值；有效 token 数须大于零。$\hat A=0$ 时该 rollout 的主项为零。

## 3. 稳定性与实验边界

对于每条 rollout 的未裁剪主项，AM-GM 给出 $|\hat A_i|\rho_{\mathrm{geo}}\le |\hat A_i|\operatorname{mean}_t\rho_{i,t}$；跨样本正负项的抵消与梯度范数需要另外分析。论文进一步通过训练实验研究极端 token ratio 与稳定性的关系。实验覆盖数学推理的多种 1.5B/7B/32B 模型和 Geometry3K 多模态设置；作者报告 7B 设置在五个数学基准平均 Pass@1 上比对应 GRPO 高 4.1 个百分点，Geometry3K 高 1.4 个百分点。

这些数字只适用于论文给定模型,数据,rollout,clip 和评测协议.不能据此宣称 GMPO 对所有奖励分布或所有 GRPO 实现都更好.

## 4. 实现状态

本目录的 `implementation.py` 是对论文 Algorithm 1 的最小张量实现,只验证符号,mask,停止梯度和 log-space 聚合;没有复现作者训练系统或论文表格.
