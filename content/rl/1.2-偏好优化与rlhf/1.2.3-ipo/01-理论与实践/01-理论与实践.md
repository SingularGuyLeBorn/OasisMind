# IPO：理论与实践

这页说明如何把 IPO 的采样损失落实到四项 log-prob。原理、计算图与梯度曲线见 [IPO 主文](../1.2.3-ipo.md)。

## 1. 理论量与代码量

| 理论量 | 输入或计算 | 检查点 |
| --- | --- | --- |
| chosen 的相对 log-ratio | `policy_chosen_logps - ref_chosen_logps` | 同一回答、同一 mask、相同聚合口径 |
| rejected 的相对 log-ratio | `policy_rejected_logps - ref_rejected_logps` | 与 chosen 顺序对应 |
| gap $h$ | 两个 log-ratio 相减 | Policy=Reference 时为零 |
| 目标 $m$ | `1 / (2 * beta)` | `beta > 0` |
| 逐样本损失 | `(h - m) ** 2` | $h=m$ 时为零 |
| batch 损失 | 对有效样本取平均 | 区分逐样本输出与最终标量 |

IPO 的 Identity 指 $\Psi(p)=p$。采样平方损失来自总体目标的对称性与 $h$ 的可加结构。对同一偏好按正反两个方向展开后，配方得到有限目标：

$$
\tfrac12[(h-1/\beta)^2+h^2]=(h-1/(2\beta))^2+1/(4\beta^2).
$$

与参数无关的常数可去掉。具体条件与推导见主文第 4 节及[论文第 5.2 节](https://arxiv.org/html/2310.12036#S5.SS2)。

## 2. 损失片段

下面是损失计算示意；变量由调用方构造。

```python
## implementation.py
## IPO Loss: Just a simple Regression
## target is 1/(2*beta)
diff = log_ratios_w - log_ratios_l
loss = (diff - 1/(2*self.beta)) ** 2
```

本目录 [implementation.py](../implementation.py) 为教学骨架。这里只核对损失计算，不将它视为已经验证的完整训练复现。

## 3. 输入契约

- 每条记录包含同一个 prompt 的 chosen/rejected，四项打分顺序一致。
- Policy 与 Reference 使用相同的 tokenizer、截断和 response mask；prompt 与 padding 不计入回答 log-prob。
- 冻结 Reference，并在其打分路径关闭梯度；更新 Policy 参数。
- 先明确输入是完整回答的 log-prob 求和，还是各自按有效回答 token 数平均。四项必须遵循同一规则，且有效长度大于零。

以 [TRL v0.23.1](https://github.com/huggingface/trl/blob/v0.23.1/trl/trainer/dpo_trainer.py#L1469) 为例，IPO 的打分路径采用长度平均，目标仍为 $1/(2\beta)$。更换版本、聚合口径或组合其他 loss 后，应重新验证数值尺度与超参数。

## 4. 最小数值检查

取 $\beta=0.5$，目标为 $1$：

| 情况 | $h$ | 逐样本损失 | 对 $h$ 的导数 |
| --- | --- | --- | --- |
| Policy 与 Reference 相同 | $0$ | $1$ | $-2$ |
| 达到目标 | $1$ | $0$ | $0$ |
| 超过目标 | $2$ | $1$ | $2$ |
| 主文四项输入：$-2,-4,-2.5,-3$ | $1.5$ | $0.25$ | $1$ |

最后一行按 Policy chosen、Policy rejected、Reference chosen、Reference rejected 排列。梯度下降沿导数反方向更新；实际网络中还需乘 $\nabla_\theta h$，并汇总不同样本。

## 5. 看哪些训练信号

观察 $h$ 与 $h-m$ 的分布、验证偏好表现、回答长度、生成质量、Policy 相对 Reference 的变化和梯度范数。IPO 的有限目标会约束单样本 gap，但不能据此省略验证集、checkpoint 选择和数据质量检查。
