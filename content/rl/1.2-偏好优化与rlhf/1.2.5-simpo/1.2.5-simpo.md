# 简单偏好优化 (Simple Preference Optimization, SimPO)

**论文信息**:
- **标题**: SimPO: Simple Preference Optimization with a Reference-Free Reward
- **作者**: Yu Meng, Mengzhou Xia, Danqi Chen (Princeton University)
- **年份**: 2024
- **论文**: [arXiv:2405.14734](https://arxiv.org/abs/2405.14734)

**前置知识**: DPO(1.2.2 节),最大间隔损失 (Margin Loss)

---

## 0. 本章目标

SimPO 用策略模型自身的**序列平均 log-probability**构造隐式奖励，并在 Bradley–Terry 目标中加入 Target Margin。训练时只需要策略模型，不需要额外执行 reference model 前向。

> **核心思路**：先把不同长度回复转换为可比较的平均 token 分数，再要求 chosen response 与 rejected response 之间形成足够大的 reward gap。

本章将:

1. 说明 SimPO 如何用平均 log-probability 构造 reference-free reward
2. 解释长度归一化为什么能让不同长度的回复可比较
3. 解释 Target Margin 如何改变偏好损失与梯度强度
4. 给出可直接实现的 batch 计算流程

---

## 1. 动机: DPO真的需要参考模型吗?

### 1.1 DPO的回顾

DPO的隐式奖励:
$$r_{DPO}(x, y) = \beta \log \frac{\pi_\theta(y|x)}{\pi_{ref}(y|x)}$$

这个公式里有两项:
1. $\log \pi_\theta$: 当前策略的生成概率(越高越好)
2. $-\log \pi_{ref}$: 参考策略的生成概率(作为基线)

### 1.2 SimPO的洞察

SimPO 不再使用 $\log \pi_\theta-\log \pi_{ref}$ 作为 reward，而是直接使用策略模型的序列平均 log-probability。这样，训练 reward 与生成时用于比较候选序列的平均 likelihood 更一致。

省去 $\pi_{ref}$ 会减少 reference model 参数、激活和前向计算带来的额外开销。具体节省比例取决于 optimizer state、并行策略、是否预计算 reference log-probability 等实现细节，不能简单等同于“显存减半”。

## 2. SimPO算法详解

### 2.1 长度归一化奖励 (Length-Normalized Reward)

SimPO直接定义奖励为**序列的平均对数概率**:

$$r_{SimPO}(x, y) = \frac{\beta}{|y|} \log \pi_\theta(y|x) = \frac{\beta}{|y|} \sum_{t=1}^{|y|} \log \pi_\theta(y_t | y_{<t}, x)$$

**符号详解**:

| 符号 | 含义 | 说明 |
|------|------|------|
| $\beta$ | **缩放系数** | 控制奖励的量级,通常较大 (如2.0) |
| $|y|$ | **序列长度** | Token数量 |
| $\log \pi_\theta$ | **序列总Log概率** | 所有token log prob之和 |

**为什么要除以长度？**

Summed log-probability 会随着 token 数增加而积累更多负值。即使两条回复的平均 token 质量相同，较长回复的总分也会更低，因此不同长度的序列不能直接用总和公平比较。偏好训练还会根据 chosen/rejected 的长度组合反向调整概率，未归一化时容易把长度本身当成优化信号，形成 length exploitation。

除以 completion token 数后，reward 表示“平均每个 token 的 log-probability”。长度不同但平均 token 质量相同的回复会得到相同 reward；平均质量不同的回复则保留可比较的 reward gap。

![SimPO 长度归一化（离散数值卡）](./images/redrawn-length-normalization-v2.png)

### 2.2 目标间距 (Target Margin)

定义长度归一化 reward 后，记 reward gap 为：

$$\Delta r = r(y_w)-r(y_l)$$

Target Margin $\gamma$ 指定期望的最小 reward gap：

$$\Delta r \ge \gamma$$

SimPO 不是 hinge loss，也不会在 $\Delta r=\gamma$ 处突然停止更新。它把 Bradley–Terry logit 从 $\Delta r$ 平移为 $\Delta r-\gamma$：当 gap 较小时梯度更强；超过 margin 后，梯度仍存在，但会随 gap 增大而平滑衰减。

![SimPO Target Margin（离散数值卡）](./images/redrawn-target-margin-v2.png)

### 2.3 SimPO损失函数

将上述思想结合,SimPO使用带Margin的Sigmoid损失:

$$\mathcal{L}_{SimPO} = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}} \left[ \log \sigma \left( r_{SimPO}(y_w) - r_{SimPO}(y_l) - \gamma \right) \right]$$

展开后:

$$\mathcal{L}_{SimPO} = -\mathbb{E} \left[ \log \sigma \left( \frac{\beta}{|y_w|} \log \pi_\theta(y_w) - \frac{\beta}{|y_l|} \log \pi_\theta(y_l) - \gamma \right) \right]$$

**参数推荐**:
- $\beta$: 2.0 ~ 2.5 (比DPO的0.1大得多)
- $\gamma$: 0.5 ~ 1.5

## 3. SimPO vs DPO vs ORPO

| 维度 | DPO | ORPO | SimPO |
|------|-----|------|-------|
| **训练时模型前向** | policy + reference | policy | policy |
| **偏好分数** | policy/reference log-ratio | sequence odds ratio | 平均 token log-probability |
| **主要目标** | $-\log \sigma(\Delta r)$ | chosen NLL + odds-ratio loss | $-\log \sigma(\Delta r-\gamma)$ |
| **显式长度归一化** | 无 $1/|y|$ 项 | 使用平均 sequence probability | 使用平均 token log-probability |
| **主要超参数** | $\beta$ | $\lambda$ | $\beta,\gamma$ |

论文实验在其 Base/Instruct 设置和 AlpacaEval 2、Arena-Hard、MT-Bench 等评测上报告了 SimPO 相对 DPO 及其他偏好优化基线的改进。这里应理解为论文设置下的经验结果，而不是对所有模型、数据和训练配置的普遍保证。

---

## 4. 梯度分析

令 $\Delta r=r_w-r_l$。SimPO 对 reward gap 的梯度系数为：

$$\nabla_\theta \mathcal{L} = -\sigma(-\Delta r + \gamma) \cdot \nabla_\theta (r_w - r_l)$$

其中 $\sigma(\gamma-\Delta r)$ 决定更新强度：

- $\Delta r<\gamma$：系数较大，明显提高 chosen reward、降低 rejected reward。
- $\Delta r=\gamma$：系数为 $0.5$，仍然有更新信号。
- $\Delta r>\gamma$：系数继续减小，但不会在边界处变为零。

因此，Target Margin 的作用是平移损失曲线，让模型在更大的 reward gap 上才进入弱梯度区，而不是设置一个硬约束。

---

## 5. 本章总结

### 5.1 核心公式

$$r_{SimPO}(y) = \frac{\beta}{|y|} \log \pi_\theta(y|x)$$

$$\mathcal{L} = -\log \sigma(r(y_w) - r(y_l) - \gamma)$$

### 5.2 SimPO的贡献

1. **Reference-free reward**：直接使用策略模型的平均 log-probability，减少 reference model 前向与存储开销。
2. **长度归一化**：让不同长度回复的 reward 以平均 token 分数为基础进行比较，抑制 length exploitation。
3. **Target Margin**：将 Bradley–Terry logit 平移 $\gamma$，在 reward gap 较小时提供更强训练信号，并在超过 margin 后平滑衰减。
