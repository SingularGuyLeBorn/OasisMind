## 0. 本章目标

ORPO 于 2024 年提出,将语言建模目标与偏好对的 odds-ratio 损失结合在同一训练阶段.

> **设计动机**:PPO 式 RLHF 和 DPO 通常涉及参考策略;具体显存开销取决于是否预计算 reference log-prob,参数共享,量化与分布式策略,不能统一概括为"翻倍".

ORPO 将 chosen 回复的模仿学习与 chosen/rejected 的相对偏好优化放进同一个目标，由同一个模型计算两项损失。

本章将:
1. 解释**Odds Ratio (优势比)** 的概念及其为何适合偏好优化
2. 推导ORPO的单目标损失函数
3. 说明 ORPO 如何联合优化 SFT 与偏好损失
4. 提供ORPO的极简PyTorch实现

## 1. 理论基础:Odds Ratio

### 1.1 什么是Odds (几率/优势)?

在概率论中,一个事件发生的概率为 $p$,则其**Odds**定义为:

$$\text{odds}(p) = \frac{p}{1-p}$$

- 当 $p=0.5$ 时,$\text{odds}=1$
- 当 $p=0.9$ 时,$\text{odds}=9$
- 当 $p \to 1$ 时,$\text{odds} \to \infty$

### 1.2 为什么用Odds?

DPO使用的是对数概率比 $\log \frac{\pi}{\pi_{ref}}$.
ORPO 比较当前模型对 chosen 与 rejected 回复的 odds；变换 $\log p-\log(1-p)$ 同时依赖分数 $p$ 及其补数。

定义模型生成一个输出序列 $y$ 的Odds:

$$\text{odds}_\theta(y|x) = \frac{P_\theta(y|x)}{1 - P_\theta(y|x)}$$

这里沿用[原论文 §4.1](https://arxiv.org/html/2403.07691v2#S4.SS1) 的长度归一化定义。对包含 $T$ 个有效 response tokens 的回复，先计算平均 log probability，再取指数：

$$s_\theta(y|x)=\frac{1}{T}\sum_{t=1}^{T}\log\pi_\theta(y_t|x,y_{<t}),\qquad P_\theta(y|x)=\exp(s_\theta(y|x)).$$

$P_\theta$ 是 token 条件概率的几何平均分数，取值在 $(0,1)$；它不构成对所有完整序列归一化的概率分布。后文的 odds 均基于这个分数计算。

### 1.3 OR (Odds Ratio)

给定好回复 $y_w$ 和坏回复 $y_l$,**Odds Ratio** 定义为:

$$OR = \frac{\text{odds}_\theta(y_w|x)}{\text{odds}_\theta(y_l|x)}$$

偏好项促使 chosen 的 odds 相对 rejected 增大；chosen NLL 另外提供绝对的模仿目标。

## 2. ORPO损失函数

### 2.1 整体目标

ORPO将SFT(监督微调)和偏好对齐合并到一个损失函数中:

$$\mathcal{L}_{ORPO} = \mathcal{L}_{SFT} + \lambda \cdot \mathcal{L}_{OR}$$

**公式各项逐一详解**:

| 符号 | 含义 | 说明 |
|------|------|------|
| $\mathcal{L}_{SFT}$ | **监督微调损失** | 负对数似然 (NLL) |
| $\mathcal{L}_{OR}$ | **优势比损失** | 偏好优化的核心 |
| $\lambda$ | **权重系数** | 控制偏好项的相对权重，按数据与训练设置选择 |

---

### 2.2 SFT Loss (基础)

$$\mathcal{L}_{SFT} = -\frac{1}{T_w}\sum_{t=1}^{T_w}\log\pi_\theta(y_{w,t} | y_{w,<t}, x)=-s_\theta(y_w|x).$$

本图和下方教学实现采用单样本、仅 response tokens 的平均 NLL，排除 prompt 和 padding。它提高 chosen 回复中目标 token 的似然；批量训练再对样本取平均。实际实现需明确 token mask 与 reduction，权重 $\lambda$ 也应与该约定配套。

### 2.3 Odds Ratio Loss (对齐)

ORPO设计了一个对数Sigmoid损失来最大化Odds Ratio:

$$\mathcal{L}_{OR} = -\log \sigma (\log OR)$$

展开后:

$$\mathcal{L}_{OR} = -\log \sigma \left( \log \frac{\text{odds}_\theta(y_w)}{\text{odds}_\theta(y_l)} \right)$$

利用 $\log \frac{a}{b} = \log a - \log b$,以及 $\text{odds}(p) = \frac{p}{1-p}$:

$$\mathcal{L}_{OR} = -\log \sigma \left( \log \frac{P(y_w)}{1-P(y_w)} - \log \frac{P(y_l)}{1-P(y_l)} \right)$$

**梯度分析**:
令 $\Delta=\log\text{odds}_\theta(y_w|x)-\log\text{odds}_\theta(y_l|x)$，则

$$\frac{\partial\mathcal{L}_{OR}}{\partial\Delta}=-\sigma(-\Delta)=-\frac{1}{1+OR}.$$

当 chosen 相对 rejected 的 odds 较低时，这个因子的绝对值较大。参数梯度还要乘上 $\nabla_\theta\Delta$；其中 $\partial\log\text{odds}/\partial s=1/(1-\exp(s))$。实际更新由这两部分共同决定。

---

### 图解:ORPO如何工作

**图片详细说明**:
- 同一个可训练模型对 chosen 与 rejected 回复做 teacher forcing，分别计算 response tokens 的平均 log probability。
- 两个分数经 odds 变换得到差值 $\Delta$，再计算 $\mathcal{L}_{OR}=-\log\sigma(\Delta)$；chosen 分支同时提供平均 NLL。
- 总目标为 $\mathcal{L}_{SFT}+\lambda\mathcal{L}_{OR}$，所有模型梯度都作用于同一组参数 $\theta$。
- 图中的 $0.8$ 与 $0.2$ 是教学用几何平均分数。对应 odds 为 $4$ 与 $0.25$，$OR=16$，$\Delta\approx2.7726$，$\mathcal{L}_{OR}\approx0.0606$，$\mathcal{L}_{SFT}\approx0.2231$。
- ORPO 的训练目标无需参考模型；显存节省量取决于对照实现、模型精度、优化器状态和分布式策略。

## 3. 实现细节

### 3.1 概率计算技巧

对模型 logits 沿词表维计算 `log_softmax`，取出各位置真实 response token 的 log probability，使用 mask 排除 prompt 和 padding，再按有效 token 数取平均，得到 $s<0$。

$$\log\text{odds}(y|x)=s-\log(1-\exp(s)).$$

当 $s$ 接近 $0$ 时，直接计算 $1-\exp(s)$ 容易发生消减误差。可分段使用 `log1p(-exp(s))` 与 `log(-expm1(s))`。输入应至少使用 float32，且每条回复须有有效 token；$s=0$ 对应 odds 发散的边界。

### 3.2 教学实现

下例对应[官方实现](https://github.com/xfactlab/orpo/blob/main/src/orpo_trainer.py) 的 log-odds 差和加权损失逻辑，并采用 §2.2 的 response 平均 NLL 约定。两个输入均为形状 `[batch]` 的平均 log probability。

```python
import math
import torch
import torch.nn.functional as F

def log1mexp(s):
    # s 是有效 response tokens 的平均 log probability，必须严格小于 0。
    s = s.float() if s.dtype in (torch.float16, torch.bfloat16) else s
    if not torch.all(torch.isfinite(s) & (s < 0)):
        raise ValueError("平均 log probability 必须有限且小于 0")
    out = torch.empty_like(s)
    low = s < -math.log(2.0)
    out[low] = torch.log1p(-torch.exp(s[low]))
    out[~low] = torch.log(-torch.expm1(s[~low]))
    return out

def orpo_loss(lambda_or, chosen_logps, rejected_logps):
    log_odds_chosen = chosen_logps - log1mexp(chosen_logps)
    log_odds_rejected = rejected_logps - log1mexp(rejected_logps)
    delta = log_odds_chosen - log_odds_rejected
    preference_loss = -F.logsigmoid(delta)
    sft_loss = -chosen_logps
    return (sft_loss + lambda_or * preference_loss).mean()
```

`chosen_logps` 和 `rejected_logps` 由同一模型计算，保留梯度。`lambda_or` 在偏好项外乘入总目标。

## 4. ORPO vs DPO vs RLHF

| 特性 | RLHF (PPO) | DPO | ORPO |
|------|------------|-----|------|
| **阶段** | SFT -> RM -> PPO (3) | SFT -> DPO (2) | **ORPO (1)** |
| **参考模型** | 需要 | 需要 | **不需要** |
| **训练组成** | Policy、Value、Ref、Reward 等角色* | Policy 与参考 log-prob | 单个 Policy、chosen NLL 与偏好项 |
| **资源比较** | 取决于 rollout、模型共享与分布式设置 | 取决于参考分数预计算、精度与参数共享 | 无需参考模型前向，仍有 chosen/rejected 前向与反向 |

*这些是计算角色，参数可共享或分离；训练速度和显存应在相同模型、硬件与配置下测量。*

## 5. 本章总结

### 5.1 核心公式

$$\mathcal{L}_{ORPO} = \underbrace{\mathcal{L}_{SFT}}_{\text{学会说话}} + \lambda \cdot \underbrace{-\log \sigma(\log \text{odds}(y_w) - \log \text{odds}(y_l))}_{\text{学会偏好}}$$

### 5.2 ORPO的贡献

1. **Monolithic**：从预训练模型出发，在同一微调阶段联合优化 chosen NLL 和偏好损失，无需独立的 SFT warm-up。
2. **Reference-Free**：目标只使用当前模型对偏好对的分数，无需参考模型或显式 reference KL 项。
3. **联合目标**：chosen NLL 提供模仿信号，odds-ratio 项提高 chosen 相对 rejected 的分数，$\lambda$ 控制两者的权重。
