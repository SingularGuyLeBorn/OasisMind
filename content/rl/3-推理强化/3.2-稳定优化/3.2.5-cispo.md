# CISPO：裁剪重要性权重，保留越界 token 的梯度

PPO 的裁剪目标有一个容易被名字遮住的行为：当正优势 token 的概率比率越过上界，裁剪并不会把它的梯度缩小到一个安全值，而是让这项进入平台，梯度直接变成零。对普通短回答，这个取舍往往可以接受；一批长推理轨迹被重复训练十几轮时，最先越界的却可能正是那些原本概率很低、又决定推理是否转向的 token。MiniMax-M1 技术报告列出的例子是 `Wait`、`Recheck`、`However` 一类反思分叉词：旧策略很少生成它们，成功轨迹又要求提高它们的概率，因此一次更新就可能把比率推过上界，后续数据复用再也收不到这部分信号。

CISPO 的改动落在这个位置。它仍然计算新旧策略的重要性比率，也仍然给比率设置上界，但截断后的比率只作为一个停止梯度的系数乘在 $\log\pi_\theta$ 前。比率再大，权重不会继续放大；token 即使越界，$\log\pi_\theta$ 这一条梯度通路仍然存在。**PPO 约束的是越界动作是否继续更新，CISPO 约束的是它继续更新时最多带多大权重。**

MiniMax 在 Qwen2.5-32B-base、DAPO 数学数据和 AIME 2024 上做了受控对比。报告中的曲线显示，CISPO 用约一半训练步数达到 DAPO 的最终表现。这个结果说明它在该设置下提高了训练步效率；实验只有一个公开底座和一套主要任务，也没有给出多随机种子结果，不能把「两倍」外推成通用墙钟加速。

## 1. 先看 PPO 的平台怎样产生

设回答 $o_i=(o_{i,1},\ldots,o_{i,T_i})$ 由旧策略 $\pi_{\theta_{old}}$ 生成，当前策略为 $\pi_\theta$。第 $t$ 个 token 的重要性比率是

$$
r_{i,t}(\theta)=
\frac{\pi_\theta(o_{i,t}\mid q,o_{i,<t})}
{\pi_{\theta_{old}}(o_{i,t}\mid q,o_{i,<t})}.
$$

省去 KL、熵和 mask，PPO/GRPO 的单 token 代理目标可以写成

$$
\ell_{i,t}^{clip}(\theta)=
\min\left(
r_{i,t}(\theta)\hat A_i,
\operatorname{clip}(r_{i,t}(\theta),1-\epsilon,1+\epsilon)\hat A_i
\right).
$$

当 $\hat A_i>0$ 且 $r_{i,t}>1+\epsilon$ 时，`min` 选择 $(1+\epsilon)\hat A_i$。这个数不再依赖 $\theta$，于是

$$
\nabla_\theta\ell_{i,t}^{clip}=0.
$$

负优势的镜像情况发生在 $r_{i,t}<1-\epsilon$。因此，PPO 的裁剪平台承担的是硬门控：比率在允许区间内，梯度正常通过；越过对应边界，这个 token 暂时退出当前目标。

取一个具体数字。某个正优势 token 在旧策略下概率为 $0.02$，更新后升到 $0.05$，比率为 $2.5$。若 $\epsilon=0.2$，它远过 $1.2$ 的上界。即使这条回答会被同一个 learner batch 再训练十五轮，这个 token 只要仍在上界外，后续各轮都不会从 PPO surrogate 获得梯度。DAPO 的 Clip-Higher 把正侧上界放宽，例如从 $1.2$ 放到 $1.28$；它延后平台出现的时刻，但比率已经达到 $2.5$ 时仍然会退出。

平台并非 PPO 的实现事故。它以有偏的代理目标换取近端更新，避免少数样本把策略推得太远。问题出在任务和数据复用方式变化以后：长推理中低概率分叉很多，同一生成批次又要重复使用多轮，退出平台的 token 数可能快速增长。此时「稳定」与「保留稀有信号」发生了更明显的冲突。

## 2. CISPO 把比率变成停止梯度的权重

CISPO 从带分布校正的 REINFORCE 写法出发。先定义截断权重

$$
\hat r_{i,t}(\theta)=
\operatorname{clip}\left(
r_{i,t}(\theta),
1-\epsilon^{IS}_{low},
1+\epsilon^{IS}_{high}
\right),
$$

再把它放进对数似然目标：

$$
J_{CISPO}(\theta)=
\mathbb E\left[
\frac{1}{\sum_i T_i}
\sum_i\sum_{t=1}^{T_i}
\operatorname{sg}\!\left(\hat r_{i,t}(\theta)\right)
\hat A_i
\log\pi_\theta(o_{i,t}\mid q,o_{i,<t})
\right].
$$

$\operatorname{sg}$ 表示 stop-gradient。求导时，重要性权重被当作常数：

$$
\nabla_\theta J_{CISPO}
=\mathbb E\left[
\frac{1}{\sum_iT_i}
\sum_{i,t}
\hat r_{i,t}\hat A_i
\nabla_\theta\log\pi_\theta(o_{i,t}\mid q,o_{i,<t})
\right].
$$

设 $\hat A_i>0$，比率从 $1.1$ 增长到 $2.5$。在 $1.2$ 上界下，PPO 进入平台后梯度为零；CISPO 则先把权重封顶为 $1.2$，梯度仍为

$$
1.2\hat A_i\nabla_\theta\log\pi_\theta.
$$

它不会让大比率无限放大梯度，也不会把对应 token 从训练中删除。论文实际只调上界，并把 $\epsilon^{IS}_{low}$ 设得足够大，相当于不启用下界截断。技术报告没有公开 $\epsilon^{IS}_{high}$ 的最终数值，所以复现时不能从 PPO 或 DAPO 的边界直接猜一个数并称作论文配置。

### 2.1. 把两种目标的分段梯度写全

只看目标函数中的 `clip` 很容易误以为两者都在「把梯度裁小」。把单 token 的 log probability 记作 $z=\log\pi_\theta(a\mid s)$，旧策略的 $z_{old}$ 为常数，则 $r=e^{z-z_{old}}$，且

$$
\frac{\partial r}{\partial z}=r.
$$

先看 PPO。对正优势 $A>0$，目标及其对 $z$ 的导数为

$$
\ell_{PPO}^{+}(z)=
\begin{cases}
rA, & r\le 1+\epsilon,\\
(1+\epsilon)A, & r>1+\epsilon,
\end{cases}
\qquad
\frac{\partial\ell_{PPO}^{+}}{\partial z}=
\begin{cases}
rA, & r\le 1+\epsilon,\\
0, & r>1+\epsilon.
\end{cases}
$$

正优势动作若比旧策略概率更低，$r<1-\epsilon$，`min` 仍会选择更小的 $rA$，梯度会推动它回来。对负优势 $A<0$，平台方向相反：

$$
\ell_{PPO}^{-}(z)=
\begin{cases}
(1-\epsilon)A, & r<1-\epsilon,\\
rA, & r\ge 1-\epsilon,
\end{cases}
\qquad
\frac{\partial\ell_{PPO}^{-}}{\partial z}=
\begin{cases}
0, & r<1-\epsilon,\\
rA, & r\ge 1-\epsilon.
\end{cases}
$$

负优势动作已经被压得足够低后，PPO 停止继续压低它。所谓上下双侧裁剪，并不表示每个样本同时受到两侧限制；优势的正负决定哪一侧形成零梯度平台。

CISPO 若只设权重上界 $c=1+\epsilon^{IS}_{high}$，单 token 目标为

$$
\ell_{CISPO}(z)=\operatorname{sg}(\min(r,c))A z,
$$

因此

$$
\frac{\partial\ell_{CISPO}}{\partial z}=\min(r,c)A.
$$

正优势与负优势都使用同一个非负权重，方向由 $A$ 决定；越过上界后，梯度系数固定为 $cA$。正优势 token 的概率继续被提高，负优势 token 的概率也继续被压低。PPO 会在负优势 token 低于下界后停手，只有上界的 CISPO 没有这道硬门控。不过，当负优势动作已经很罕见时，$r$ 本身也很小，未触上界的梯度系数为 $rA$，会自然衰减。

### 2.2. stop-gradient 切断哪条路径

把 stop-gradient 去掉，目标变成 $\min(r,c)Az$。在 $r<c$ 的区域求导会得到

$$
\frac{\partial(rAz)}{\partial z}=rA(z+1),
$$

多出的 $rAz$ 来自权重本身对参数的依赖。它的方向还会受 $z$ 的绝对数值影响，而语言模型 token 的 $z$ 通常为负；这已经偏离常见的重要性加权策略梯度。`detach` 切断的是 $r$ 经过指数、截断再回到参数的路径，保留的则是 $z=\log\pi_\theta$ 自己的路径：

$$
\operatorname{sg}(w)A\,\nabla_\theta z
=wA\,\nabla_\theta\log\pi_\theta(a\mid s).
$$

所以「权重停止梯度」不会让整个 token 停止梯度。计算图里仍有一条从 loss 经 log probability、logits、网络层回到参数的完整路径。可以用自动微分做一个最小检查：令标量 $z=\log0.05$，$z_{old}=\log0.02$，则 $r=2.5$；设 $c=1.2,A=1$，正确 CISPO 对 $z$ 的导数为 $1.2$。若输出为零，代码用了 PPO mask 或把整项 detach；若输出接近 $1.2(z+1)$，权重没有 detach。

**一个可复算的四 token 例子。**

取四个 token，旧策略到当前策略的比率分别为

$$
r=[0.5,\ 1.1,\ 1.5,\ 3.0],
$$

优势为 $A=+2$，PPO 区间取 $[0.8,1.2]$，CISPO 权重上界也取 $1.2$。对 log probability 的梯度系数如下：

| token | $r$ | PPO 系数 | CISPO 系数 |
| --- | ---: | ---: | ---: |
| 1 | 0.5 | $1.0$ | $1.0$ |
| 2 | 1.1 | $2.2$ | $2.2$ |
| 3 | 1.5 | $0$ | $2.4$ |
| 4 | 3.0 | $0$ | $2.4$ |

前两个位置完全一致，差别只出现在正优势上界之外。PPO 保留的系数总和为 $3.2$，CISPO 为 $8.0$。这个数字不能解释成 CISPO 的实际梯度一定是 PPO 的 2.5 倍，因为不同 token 的 $\nabla_\theta\log\pi$ 是向量，可能同向也可能抵消；它准确说明了逐 token 标量权重中有多少项仍然进入反向传播。

再把优势改为 $A=-2$。PPO 在 $r=0.5$ 处命中负侧平台，系数为零，其余位置的系数为 $[-2.2,-3.0,-6.0]$。只有上界的 CISPO 得到 $[-1.0,-2.2,-2.4,-2.4]$：低比率负样本没有被硬删除，但影响因 $r=0.5$ 而减弱；高比率负样本被封顶，避免 $r=3$ 直接带来 $-6$ 的系数。CISPO 的上界同时保护正负优势更新，它限制的是当前策略相对行为策略过度偏爱某个采样动作时的最大权重。

这里还有一个常见实现错误：如果对 `ratio.clamp(...)` 不做 `detach`，权重本身也参与反向传播，梯度就不再是上式。`clamp` 之后必须切断权重的计算图，让截断权重只负责缩放，梯度只穿过 log probability。最小实现可以写成：

```python
logp = policy_log_probs(response_ids)            # [B, T]
ratio = torch.exp(logp - old_logp)               # [B, T]
weight = ratio.clamp(max=1 + eps_is_high).detach()
adv = group_advantage(rewards).unsqueeze(-1)     # [B, 1]
loss = -(weight * adv * logp * action_mask).sum()
loss = loss / action_mask.sum()
```

`old_logp`、优势和 reward 都不应连接当前策略的计算图；`action_mask` 只覆盖模型真正采样的回答 token，prompt、padding 和工具观察不能混入分母。自然结束时 EOS 是策略动作，应计入概率比；系统因最大长度强行截断时没有采样 EOS，不能补一个伪造的结束动作。

## 3. 三种裁剪其实在回答三个问题

DAPO、GSPO 和 CISPO 都会谈裁剪，但它们修改的对象不同。

| 方法 | 比率单位 | 越界以后 | 主要矛盾 |
| --- | --- | --- | --- |
| GRPO/PPO | token | 对应方向的梯度归零 | 单步策略漂移 |
| DAPO Clip-Higher | token | 仍归零，只把正侧平台推远 | 正优势过早截停 |
| GSPO | 长度归一后的序列比率 | 整条回答共同裁剪 | token 比率噪声与 MoE 路由波动 |
| CISPO | token | 权重封顶，梯度继续通过 | 多轮复用时稀有 token 退出训练 |

这张表也解释了为什么它们不能按最终分数互相替换。DAPO 还包括动态采样、token-level loss 和超长塑形；CISPO 在 MiniMax 的实验里沿用了其中多项配方，只替换重要性权重与更新的关系。GSPO 把约束提升到整条序列，换来更平滑的统计量，也会稀释局部关键 token。任务若已经定位到 MoE 路由造成的 token 比率尖峰，CISPO 保留逐 token 权重并不会自动解决路由噪声；任务若主要问题是大量稀有正优势 token 在深度数据复用中被裁掉，改成序列平均也未必保住这些局部信号。

REINFORCE++ 同样不依赖独立 critic，并吸收 PPO 的优势归一、重要性修正和 KL 等稳定组件。二者的边界要落回公式：REINFORCE++ 是一套围绕无 critic 策略梯度的完整配方，具体实现对 baseline、token return 和归一化口径可能不同；CISPO 的辨识点非常窄，就是截断且 stop-gradient 的重要性权重。看到代码里出现 `reinforce` 或 `clip` 都不足以判断实现了 CISPO。

### 3.1. 与 DAPO 的可组合边界

DAPO 的动态采样、超长 reward shaping 和 token-level loss 与 CISPO 作用在不同层，可以直接组合。动态采样决定哪些 prompt 进入 batch，长度塑形改变 reward，token-level loss 决定回答之间怎样归约；CISPO 决定当前策略和旧策略出现概率差异后，每个 token 获得什么权重。MiniMax 的受控实验正是在沿用 DAPO 多项设置的基础上比较裁剪目标。

Clip-Higher 与 CISPO 则改动同一个坐标。Clip-Higher 把 PPO 正优势零梯度平台从 $1+\epsilon$ 推到 $1+\epsilon_{high}$；CISPO 在 $1+\epsilon^{IS}_{high}$ 之后仍保留封顶梯度。若代码同时保留 PPO 的 `min` 或越界 mask，再把 ratio 截断后 detach，CISPO 想保留的 token 最终仍会被 mask 清掉，组合退回带新权重的 PPO。另一种组合是保留 CISPO 目标，只把较大的 Clip-Higher 数值借作权重上界；这在数学上可行，却是一套需要重新标定的新超参，不能沿用「DAPO + CISPO」这个名字掩盖目标变化。

### 3.2. 与 GSPO 的粒度冲突

GSPO 先把一条回答的 token log-ratio 求平均，再指数化为序列比率：

$$
s_i=\exp\left(\frac1{T_i}\sum_t\log r_{i,t}\right).
$$

若把 CISPO 的思想搬到这里，可以截断并 detach $s_i$，再让同一个序列权重乘到回答中所有 token 的 log probability 上。这会保留整条越界序列的梯度，但已经变成「序列级截断 IS 权重」，局部稀有 token 不再有自己的 $\min(r_{i,t},c)$。例如一条四 token 回答的比率为 $[4,1,1,1]$，token 级 CISPO 在第一个位置用封顶权重，其余位置权重为一；序列几何比率为 $4^{1/4}\approx1.414$，若序列上界为 $1.2$，四个位置都会得到 $1.2$ 的共同权重。两种目标更新的参数方向一般不同。

先做 token 级 CISPO、再做 GSPO 序列 mask 会出现更直接的冲突：局部权重虽保留了梯度，序列一旦越界仍被整体清零。若取消序列 mask，只保留序列权重，便舍弃了 CISPO 对局部低概率分叉的针对性。组合前要先判断故障来自 token 局部比率尖峰、整条轨迹共同漂移，还是多轮复用后的梯度退出；三个现象需要不同统计量，叠两层裁剪通常只会增加难以归因的超参。

**它换来的偏差和风险。**

截断重要性权重会引入偏差。理想的 off-policy 校正需要真实密度比；把 $r=5$ 改成 $1.2$，等于主动低估目标策略相对行为策略的变化。PPO 也通过裁剪引入偏差，只是偏差的形状不同：PPO 将越界样本的局部梯度置零，CISPO 保留方向并限制幅度。二者都不能把很旧的 rollout 重新变成 on-policy 数据。

CISPO 还放弃了 PPO 裁剪平台提供的硬门控。若验证器把错误轨迹标成高分，正优势会沿整条轨迹广播；这些 token 越界后仍持续获得梯度，奖励漏洞可能被更快放大。报告里用权重上界控制单 token 幅度，并依靠数据、验证器、精度修复和优化器配置共同维持训练。单独换一行 loss，不能继承整套训练的稳定性。

长序列会把这个风险放大。一条两万 token 的回答共享序列优势，其中只有几个 token 真正决定答案，其余 token 也会同向更新。CISPO 保住所有 token 的梯度，提高了样本利用率，也让错误的序列级归因更彻底。过程奖励、片段优势或价值估计解决的是信用分配；CISPO 没有提供新的 token 级因果信息。

策略新鲜度同样不能省。假设某 token 概率在每轮更新后乘 $1.05$，十轮后比率约为 $1.63$，二十轮后约为 $2.65$。CISPO 会把两者都封到同一上界并继续学习，但它无法区分「仍然有用的旧信号」与「当前策略已不再访问的旧前缀」。样本年龄增长时，应同时观察行为支持、生成结果和新鲜 batch 的梯度方向，不能只因有效梯度比例很高就继续加深复用。

**多 epoch 复用时 ratio 怎样移动。**

一个 rollout batch 刚生成时，producer 与 learner 权重若完全同步，首轮 ratio 应围绕一。每做一次 optimizer step，当前策略变化，固定轨迹上的 ratio 分布就会变宽。正优势动作倾向向右移动，负优势动作倾向向左移动；同一个 token 还会因共享参数受到其他样本更新影响，所以分布不会整齐分成两团。到了后续 epoch，PPO 的正侧与负侧平台命中率通常增加，实际参与 surrogate 的 token 越来越少。CISPO 的参与率仍为百分之百，但越来越多 token 共享上界权重，精细的密度比信息被压成同一个数。

这两种退化可以用不同指标看。PPO 记录正、负优势各自的零梯度比例；CISPO 记录权重命中上界的比例和截断前后的分布。设 batch 内有效 token 权重为 $w_j$，常用有效样本量为

$$
ESS=\frac{(\sum_j w_j)^2}{\sum_jw_j^2},
\qquad
ESS_{norm}=\frac{ESS}{N}.
$$

所有权重相等时 $ESS=N$；一个权重支配全部时接近一。截断会压低权重尾部，通常提高按权重数值计算的 ESS，但这个数只描述权重集中度，不描述轨迹是否还来自有用状态。把很多极旧 token 全部压成同一个上界，$ESS_{norm}$ 甚至可能很好看，样本分布仍与当前策略相差很远。因此 ESS 要和 producer lag、未截断 log-ratio 分位数及新鲜 rollout 对照一起读。

取权重 $[0.5,1,2,8]$。未截断时

$$
ESS=\frac{11.5^2}{0.5^2+1^2+2^2+8^2}
=\frac{132.25}{69.25}\approx1.91.
$$

在 $1.2$ 截断后，权重变成 $[0.5,1,1.2,1.2]$，

$$
ESS=\frac{3.9^2}{0.25+1+1.44+1.44}
=\frac{15.21}{4.13}\approx3.68.
$$

权重方差明显下降，代价是原来 $2$ 与 $8$ 的差别完全消失。若两者都来自高质量正优势分叉，这正是受控降方差；若 $8$ 来自训练—推理概率计算错误，截断只隐藏了错误的幅度。日志必须保留截断前的 ratio，不能只保存进入 loss 的权重。

按 epoch 记录这些量，可以直接检验「多轮复用是 CISPO 收益来源」这条解释。若首轮两种目标的能力曲线已经明显分开，而首轮几乎没有 token 越界，收益不可能来自保留越界梯度；应回头检查分母、优势、学习率或实现。若差异从第二轮开始，且 PPO 的零梯度比例上升、CISPO 的封顶比例同步上升，机制链才与观测相符。

**上界和下界分别改变什么。**

上界 $c_{high}$ 控制当前策略比行为策略更偏爱采样动作时的最大权重。它同时作用于正负优势：正优势下限制继续强化的幅度，负优势下限制纠正「当前过度偏爱坏动作」的幅度。上界太低，大量 token 得到相同系数，重要性校正退化成近似常权重 REINFORCE；上界太高，少数大 ratio 会支配 batch，梯度方差与错误标签风险上升。

若再设置下界 $c_{low}>0$，$r<c_{low}$ 的 token 权重被抬到 $c_{low}$。正优势下，它会更用力恢复被当前策略压低的好动作；负优势下，它也会继续压低已经很罕见的坏动作。后者正是 PPO 负侧平台原本会停止的区域。所以下界不只是数值保护，它会主动放大低 ratio 样本，并可能在概率已经很小时持续推 logits。

MiniMax 报告选择不设有效下界，让小 ratio 自然产生小梯度，只限制大 ratio 尾部。这个选择与「保护稀有反思 token」的动机一致：论文关心的是正优势 token 从很低旧概率快速上涨，表现为大 ratio；它不需要把当前策略已经降低概率的动作统一抬高权重。换到安全抑制或遗忘恢复任务后，低 ratio 区域可能同样重要，此时可以实验双侧截断，但要按优势符号分别报告效果。

一个 $2\times2$ 表格足以检查方向：横轴取 $r=0.1$ 与 $r=5$，纵轴取 $A=+1$ 与 $A=-1$。只设 $c_{high}=1.2$ 时四格系数为 $0.1,-0.1,1.2,-1.2$；再设 $c_{low}=0.8$ 后变为 $0.8,-0.8,1.2,-1.2$。下界只改变低 ratio 两格，而且不区分优势好坏。是否需要它，要由低 ratio 样本的语义和方差决定。

## 4. 怎样验证实现没有悄悄变回 PPO

第一组测试只需要一个 token。令 $\hat A=1$、$r=1.5$、上界为 $1.2$。PPO 分支对当前 log probability 的梯度应为零；CISPO 的梯度系数应为 $1.2$。再把 $r$ 改成 $1.1$，两者都应得到 $1.1$ 倍的策略梯度。这个用例可以抓住漏掉 `detach`、把 `min` 结构照搬过来或裁剪位置写错的问题。

第二组测试检查符号。令 $\hat A=-1$，论文配方不设有效下界。$r$ 从 $0.5$ 降到 $0.05$ 时，权重也随之减小，梯度方向仍应降低该动作概率；若实现擅自加上 PPO 的负侧 mask，低比率 token 会被清零，算法语义已经改变。若项目确实需要双侧权重截断，可以这样设计，但必须作为新配置记录，不能冒充报告设置。

第三组测试检查归约。构造一条 2 token 和一条 8 token 的回答，所有 token 的权重、优势和 log probability 相同。按论文的全 token 分母，两条回答对总梯度的贡献比应为 $2:8$；若得到 $1:1$，实现采用了先按回答长度平均、再按回答平均的序列等权口径。两种口径都能运行，优化目标并不相同。

训练日志至少保留以下量：

- `ratio` 与 `log-ratio` 的 P1、P50、P99，按正负优势和样本年龄分桶；
- 权重命中上界的 token 比例，以及这些 token 的优势绝对值占比；
- 未截断权重总和、截断后权重总和与有效样本量；
- 每个生成批次被复用的轮数，首轮到末轮的权重封顶比例；
- 回答长度、熵、自然结束率、重复率和真实验证通过率；
- rollout 端保存的 old log probability 与 trainer 复算值的误差。

只看平均 ratio 接近一没有用。一半 token 为 $0.1$、另一半为 $1.9$，平均仍是一，大量位置已经远离行为策略。只看封顶比例也不够：若封顶集中在低优势模板 token，影响有限；若集中在高优势分叉 token，它正是 CISPO 想保留的信号。按优势和 token 类型抽样下钻，才能知道算法是否作用在预期位置。

## 5. 论文实验应怎样读

MiniMax-M1 报告中的公开对照以 Qwen2.5-32B-base 为底座，采用 DAPO 数学推理数据，比较 GRPO、DAPO 与 CISPO，并在 AIME 2024 上报告 avg@32。CISPO 曲线在相同训练步数下更高，达到 DAPO 最终水平所需步数约为一半。这个实验较好地隔离了 MiniMax 混合注意力架构的影响，却没有同时隔离所有配方开关，也没有证明收益来自任意任务、任意数据复用深度。

完整 M1 训练还包含训练与推理概率精度对齐、LM head 使用 FP32、AdamW 参数调整、重复检测提前终止、课程数据和多类验证环境。技术报告明确记录过：训练与推理 kernel 的精度不一致会阻止 reward 增长，修正 LM head 精度后 token 概率相关性才改善。这件事与 CISPO 的联系很直接，因为比率由两端 log probability 相减再取指数；一个看似很小的数值误差会被指数放大，最终改变多少 token 命中权重上界。

因此，公平复现至少做三组消融：同一批 rollout 上只替换 PPO clip 与 CISPO 权重；固定训练 token 比较收敛效率；固定墙钟和生成成本比较系统效率。再扫描数据复用轮数。如果 CISPO 的优势确实来自保留后续 off-policy 轮次的梯度，它与 PPO/DAPO 的差距应随复用深度增加而扩大；若首轮就出现巨大差距，需要先排查目标、分母和精度是否一致。

### 5.1. 选用边界

CISPO 适合这样的故障：rollout 很贵，同一批数据必须复用多轮；长回答中有大量低概率但可能关键的 token；PPO 正侧裁剪比例随 minibatch 迅速升高；被裁掉的样例经过人工检查，确实包含正确的新推理分支。此时它直接处理「有价值 token 退出训练」的问题。

若主要故障是全对与全错组过多，先处理采样和课程；若 ratio 尖峰来自 MoE 路由或训练—推理 log probability 不一致，先修概率口径；若 reward 容易被利用，先修验证器；若长轨迹需要分辨早期决策和后期修正，问题落在信用分配。这几类故障都不会因 token 始终有梯度而消失。

最终判断不应停在 loss 是否更平。相同生成 token 和训练 token 下，封顶权重是否集中在有效推理分叉，固定探针集的正确率是否提高，长度增长是否伴随真实能力而非重复，训练外验证器是否保持一致，才构成完整证据。CISPO 给出的重要启发是：**裁剪的位置决定了你是在限制权重，还是在删除学习机会。**这一步选择要和数据新鲜度、奖励质量与信用分配一起看。
