## 1. 动机: 奖励的单位与优化的单位

### 1.1. GRPO 的 token 级 surrogate

GRPO 的 surrogate 在每个 token 上构造重要性比率 $\rho_{i,t}=\pi_\theta(y_{i,t}|y_{i,<t})/\pi_{old}(y_{i,t}|y_{i,<t})$, 再和广播到 token 的序列优势相乘, 逐 token clip. 1.3.1.1 节 §2.8 已经指出这个结构里藏着粒度不匹配: reward 是整条回答一个标量, 优化却是几百上千个位置各自为政. GRPO 用得好时这个不匹配被组内比较盖住, 但它从未消失——一旦单 token 的 log-prob 波动变大, 覆盖它的统计结构就撑不住了.

波动从哪来? 训练深入后 policy 每步更新都让 token 分布移动, 长链推理的单条样本几千个位置, 每个位置的 $\rho_{i,t}$ 偏离 1 一点, 整条链的 surrogate 方差按位置数累积. clip 能在每个位置截停大偏差, 但截停本身制造「零梯度区」, 有效信号密度随训练下降. 这是 GRPO 系在长链推理上的共有瓶颈, DAPO 从 clip 边界和归约分母两侧打了补丁, GSPO 选择了更根本的改法.

把三家的应对排在一起能看出问题层次: 方差累积是病, DAPO 的两处补丁是缓解症状 (截停更晚, 分配更匀), GSPO 改的是病灶本身 (让修正量回到序列粒度). 不是谁对谁错, 是改动成本与收益的组合不同: DAPO 的补丁不改变 GRPO 的任何接口, 现有基建零改动; GSPO 换 surrogate, 存储, 日志, 监控都要跟着变, 换来的是方差结构的根治.

### 1.2. MoE 崩溃: 压垮骆驼的那根稻草

Qwen 团队碰到的具体症状是 MoE 模型的训练崩溃: 在 Qwen3 级别的 MoE 上用 GRPO 训练, loss 周期性爆炸, 模型质量断崖下跌, 且重试 seed 也救不回来. 定位到的机制是**专家路由的放大效应**: MoE 的 router 对每个 token 决定送哪个专家, policy 参数的微小变化会让一大批 token 的路由集体翻转, 这些 token 的 log-prob 同时剧烈变化——逐 token 比率上同时出现大量离群值, 每个离群值都被 clip 单独处理, 但它们的**联合效应** (整条链的 likelihood 实际变了多少) 没有任何结构去约束. Dense 模型也有同样的物理, 只是幅度温和; MoE 把「参数扰动 → 概率扰动」的增益放大了一个量级, 于是 GRPO 的 token 级假设率先在 MoE 上破产.

Qwen 团队先观察到训练崩溃, 随后把问题定位到路由波动与逐 token clip 的相互作用, 「单位对齐」则是对这一现象的机制解释. 目前证据集中在路由敏感的 MoE 架构: token 级重要性采样比率会把路由造成的概率扰动直接带入梯度, 方差随之放大. 这说明 GRPO 的 token 级修正在该场景下容易失稳, 还不足以推出所有架构上的一般结论.

**单位对齐论点。**

GSPO 的核心主张一句话: **奖励的单位是序列, 优化的单位也应该是序列**. 序列级 reward 配序列级 surrogate, 粒度对齐后, off-policy 修正在和 reward 相同的抽象层上进行, 单 token 的噪声被长度归一平均掉, 路由翻转这类「集体事件」在序列比率上只表现为一个受 clip 约束的标量, 不会穿透成几百个独立的 clip 决策.

这个论点是对称的镜像: 批评者可以说「token 级信用分配更细」, 支持者可以说「细粒度在没有 token 级 reward 时只是噪声分配」. 双方都同意的事实是: 粒度错配存在, 且后果随架构敏感度放大. GSPO 是把粒度对齐到 reward 一侧, 另一条路 (token 级过程奖励) 是把 reward 细化到优化一侧, 1.3 节的后续篇目会回到这条路. GSPO 与过程奖励的组合空白 (§6.2), 本质就是「序列粒度上限」问题的另一种表现形式. 补充第三个条件的工程来源: 复用深度是被 rollout 成本逼出来的, 而 rollout 成本在长链 MoE 上恰恰最高——三个条件因此经常同时出现, 不是巧合. 这也是为什么「GSPO 只在 MoE 有用」的说法低估了它: 在 DeepSeek-V3 级别的稠密长链训练上, 深复用同样会把 GRPO 的 token 级方差问题推到台前.

反过来, 有一个条件反向放大 GRPO 的优势: 需要精细控制链内局部行为时 (例如「别在第 N 步用某种格式」), token 级 clip 能做外科手术, 序列级 clip 只能整体升降. 安全约束类任务里这类需求常见, 是 GSPO 适用域的明确边界.

## 2. 序列级重要性比率

**序列比率的定义。**

GSPO 把一条回答的全部 token log-ratio 做 masked mean, 再指数化, 得到长度归一的序列比率:

$$s_i^{GSPO}=\exp\left(\frac{1}{|y_i|}\sum_{t=1}^{|y_i|}\log\frac{\pi_\theta(y_{i,t}|x,y_{i,<t})}{\pi_{old}(y_{i,t}|x,y_{i,<t})}\right).$$

$|y_i|$ 是有效 token 数, mask 排除 prompt 和 padding. 统计直觉直接: 若单 token log-ratio 的方差是 $\sigma^2$ 且近似独立, 均值的方差约为 $\sigma^2/|y_i|$——几千 token 的链把方差压掉三个数量级. 独立性假设在真实模型里当然不成立 (相邻 token 高度相关), 但「平均降方差」的方向稳健, 这也是长度归一在 SimPO (1.2.5 节) 里扮演过同一角色的原因. 一个实现细节: mask 的分母是「有效 token 数」而不是序列维度的固定长度, 和 SimPO 的 $|y|$ 约定一致. 混用 padding 长度或 batch 最长长度做分母, 短回答的 $s_i$ 会被系统性压低, 这类 bug 在长度混合不均匀的早期训练里几乎不可见, 后期才显形, 用 §7.2 的不变量提前拦住.

长度归一的统计收益也随链长增长而放大: 200 token 的链把方差压 200 倍, 4000 token 压 4000 倍. 短链场景 (代码补全, 短问答) 里这个收益聊胜于无, 序列比率和逐 token 比率的方差差异不大, GSPO 的理由相应变弱——又回到 §4.2 的三条件判断.

### 2.2. 与「token 比率乘积」的区分

GSPO 使用平均 log-ratio 的指数, **没有**把 GRPO 的逐 token 比率直接相乘. 序列似然比 $\prod_t\rho_{i,t}$ 的对数是 log-ratio 之和, 不带 $1/|y_i|$; GSPO 则取对数的平均, 两者相差长度因子. 乘积形式随长度指数漂移 ($T$ 个 1.001 的乘积是 $e^{0.001T}$), 平均形式对长度不敏感. 因而「token 比率乘积的 clip」并不是 GSPO 的目标. RLHF 采用小步迭代, 每轮重新采样会继续修正前一轮的估计偏差; 方差过大却可能一次就把参数推得太远, 使后续校正追不上. PPO 选择 clip 而非无截断的 importance sampling 已经体现了这项权衡, GSPO 又在序列级采用了相同取舍.

sequence-level surrogate 在经典 RL 的选项框架和宏动作中早已有之. LLM 场景新增了「序列 = 自然语言回答」的语义绑定, 并通过长度归一比较不同长度的回答. 序列级修正的步幅较大, 通常要配合更保守的 clip 和学习率, GSPO 极小的 clip 正好符合这一特征. 它与 LLM 社区常见的 token 级数值看似差异很大, 主要原因是量纲已经改变. 迁移 clip、学习率或 KL 系数时, 应先写清数值对应的量纲, 例如「0.28 表示单位置对数概率的相对漂移上限」, 再判断能否沿用.

这个区分也说明 GSPO 与经典 importance sampling 的关系: 经典的序列级修正用乘积 (无偏但方差爆炸), GSPO 用平均 (方差小但修正有偏——它修正的不再是「整条链的似然比」而是「平均每 token 的似然漂移」). GSPO 论文没有回避这一点, 它的立场是: 有偏但方差可控的修正, 在训练价值上胜过无偏但方差爆炸的修正.

**手算: 数值对照。**

取一条 4 token 的回答, 逐 token log-ratio $d=[0.01,0.02,-0.01,0.00]$. 序列比率: 均值 $0.005$, $s=e^{0.005}\approx1.00501$. 逐 token 比率各自是 $[1.010,1.020,0.990,1.000]$, GRPO 的 surrogate 在这四个位置上分别 clip 后加权; GSPO 只在 $s=1.005$ 一个标量上做 clip 决策. 再看漂移场景: 假设 minibatch 复用让 policy 偏离 old, 每个 token 的 log-ratio 漂到 $0.01$ (同向), 序列比率变成 $e^{0.01}\approx1.010$. GRPO 里每个位置的 $\rho=1.010$, 均未触 1.2 的平台, 全部保留梯度; GSPO 里 $s=1.010$ 同样远在平台外. 两种情况梯度结构相同. 差异出现在**异向漂移**: token log-ratio 有正有负, 均值接近 0, GSPO 的 $s\approx1$ 表示「整条链平均没动」, 不做更新; 而 GRPO 逐位置处理, 正漂移的位置照常强化, 负漂移的位置照常压制——它在执行一条「平均意见为零但内部撕裂」的更新.

哪个更好没有先验答案, 但有一个可操作的判别: 异向漂移若来自路由翻转这类「集体伪影」, GSPO 的平均是对的; 若来自链内「前对后错」的真实结构, GRPO 的位置级处理保留了信息. 判别手段是探针分析——找一批 $s_i\approx1$ 但 GRPO 会大更新的样本, 人工检查它们是哪种形态, 占比决定取舍. 哪个更合理取决于任务, 这正是 §5 要展开的争论.

**手算二: 方差的对照。**

把 §2.3 的直觉量化. 设单 token log-ratio 方差 $\sigma^2=0.01$ (这是 minibatch 复用中期的常见量级), 链长 $T=2000$. 独立性近似下, 均值 $\bar\ell$ 的标准差是 $\sqrt{0.01/2000}\approx0.0022$, $s=e^{\bar\ell}$ 的相对波动约 $0.22\%$——远在 clip 区间 (±0.03%) 之外还是之内? $0.22\%$ 的波动已经把 $s$ 推过 1.0003 到 1.0004 的边界, 意味着这批样本接近半数次触发 clip. 这个算术说明 GSPO 的 clip 区间虽小, 和序列比率的天然波动是同量级的, clip 不是摆设, 它持续参与塑形.

对比 GRPO 的同一时刻: 单 token 标准差 $0.1$, clip 在 $\pm0.2$, 约 $95\%$ 的 token 落在平台外保留梯度, 但保留下来的梯度方向由逐 token 的随机漂移主导, 信噪比低. 两个算法的 clip 触发率可能接近, 但 GSPO 的每次触发是「整条链的判决」, GRPO 的触发是「几千次局部判决」, 前者的信息密度高几个量级. 这是「clip 次数压缩」在统计上的真实含义.

## 3. 序列级 clip 与损失

**Clip 粒度的改变。**

GSPO 的损失:

$$L^{GSPO}=-\mathbb{E}\left[\min\left(s_i\hat A_i,\ \operatorname{clip}(s_i,1-\epsilon_{low},1+\epsilon_{high})\hat A_i\right)\right].$$

结构和 PPO 相同, 只是 clip 的对象从每个 token 的 $\rho_{i,t}$ 换成每条回答一个的 $s_i$. 一条 4000 token 的链, GRPO 做 4000 次独立 clip 决策, GSPO 做一次. clip 决策数的压缩不是细节, 是方差来源的压缩: 4000 次决策里只要有百分之几的位置路由翻转, GRPO 的更新方向就被这些位置主导; GSPO 的单一决策只反映平均漂移, 路由翻转被平均进标量.

注意「一次决策」不等于「信息少」: 决策的输入是整个 $s_i$, 它由全部 4000 个位置的 log-ratio 共同决定, 信息没有丢, 丢的是「位置维度的独立性」. 如果某个任务真的需要位置级的重要性区分 (例如已知第 2000 个 token 是错误步骤的起点), 序列级 clip 会把这条信息抹平——粒度对齐的另一面是粒度上限.

### 3.2. 梯度结构的差别

把两边的有效梯度写开. GRPO: 未触平台的 token 贡献梯度 $\propto A_i\nabla\log\pi_\theta(y_{i,t})$, 每个 token 独立判断. GSPO: $s_i$ 对所有 token 的参数共享依赖 (它是全部 log-ratio 平均的指数), 链上每个 token 的梯度都通过 $s_i$ 耦合, 有效梯度 $\propto A_i\,s_i\nabla\bar\ell_i$, 其中 $\bar\ell_i$ 对各 token 的导数都带 $1/|y_i|$ 因子. 两个后果: 其一, 长链的每个 token 分到的梯度天然小 (除以长度), 和 token-level loss (DAPO §4) 的效果方向一致; 其二, 链内 token 的梯度方向完全一致 (同乘 $A_i$), 不再出现 GRPO 里「一部分 token 被强化一部分被压制」的内部撕裂. 这个「方向一致」的性质值得单独强调: 它让 GSPO 的更新更像 SFT 的形状 (整条序列同向加权), 只是权重由 reward 决定而非固定为 1. 工程上的好处是行为可预测——调试时看到的梯度异常更容易归因到数据或优势, 而不是 clip 触发模式的组合爆炸.

代价方面同样要记录: 方向一致意味着链内任何位置的参数变化都带同一个符号的梯度, 长链对参数的「拉力」比 GRPO 更整体化; 如果链的前半和后半需要相反方向的调整, GSPO 一次更新只能满足其一, 收敛路径会被拉长. 这类「链内冲突」的频率可以用探针集测出, 是评估 GSPO 适配度的第二个指标 (第一个是 §4.2 的三条件). 两个指标都不需要训练就能测 (探针集前向即可), 符合「先测后训」的调试纪律.

**clip 区间为什么那么小。**

论文实验设置的 clip 区间是 $[1-4\times10^{-4},\,1+3\times10^{-4}]$ 量级——比 GRPO 常见的 0.2 小了三个数量级, 这个数字经常被误读为「GSPO 更新极保守」, 其实根源是**比率的定义不同**. 序列比率 $s_i$ 是平均漂移的指数, 它的可接受范围由「平均每 token 漂移多少」决定: 平均每 token 漂 $4\times10^{-4}$, 4000 token 的链总漂移已达 $e^{1.6}\approx5$ 倍似然, 已经很激进. token 级 clip 的 0.2 是「单位置漂 20% 就算出格」, 两者量纲不同, 数值没有可比性. 复现 GSPO 时把 3e-4/4e-4 直接换成 0.2, 等于没有 clip; 反过来把 GRPO 的 0.2 换成 3e-4, 训练会慢到不动. 标定序列级 clip 的实用方法: 先跑若干步无 clip 的 pilot (或用极宽 clip), 记录 $s_i$ 的分布 (P50, P95, P99), 把 clip 边界设在 P95 附近, 让约 5% 的样本触发截停. 这个流程和 GRPO 调 $\epsilon$ 的「clip fraction 目标区间」思路一致, 只是分布的量纲不同, 必须先重新测.

## 4. 与 GRPO, DAPO 的并排

### 4.1. 三个损失并排

| 维度 | GRPO | DAPO | GSPO |
|------|------|------|------|
| **比率级别** | 逐 token $\rho_{i,t}$ | 逐 token (解耦 clip) | 序列级 $s_i$ |
| **clip 粒度** | token, 对称 | token, 正负异界 | 序列, 对称 |
| **clip 量级** | $\epsilon\sim0.2$ | $\epsilon_{high}=0.28,\ \epsilon_{low}=0.2$ | $\epsilon\sim3\times10^{-4}$ |
| **归约分母** | 每回答等权 (或 token 级, 见 DAPO) | 批内 token 统一分母 | 内建于比率 (长度归一) |
| **MoE 稳定性** | 崩溃 (Qwen 观察) | 缓解 | 解决 (Qwen 报告) |
| **来源** | DeepSeekMath | ByteDance Seed | Qwen Team |

三者的关系是「同一骨架上的三处补丁」: GRPO 是基线; DAPO 不动比率定义, 改 clip 边界, 采样过滤, 归约分母; GSPO 动比率定义本身, clip 和归约随之重写. 没有谁取代谁的问题——DAPO 的技巧 (动态采样, 长度塑形) 可以和 GSPO 的比率组合, Qwen 自己的训练系统里也保留了这些工程件. 这张表还揭示了一个命名学现象: 三个名字 (GRPO, DAPO, GSPO) 各自的论文都把自家版本写成「默认之上的修正」, 但修正的落点不同——采样端, clip 端, 比率端. 把它们当成同一坐标系里的三个点而不是三个竞争的「算法」, 讨论会清晰得多: 选 surrogate 坐标 (GRPO vs GSPO), 再选 clip 坐标 (对称 vs 解耦 vs 序列级), 再选采样坐标, 三轴独立. 这个坐标视角也解释了社区实现的分叉: verl, OpenRLHF, TRL 各自的「GRPO」其实是坐标系里的不同点, 报配置时按三轴展开, 比报一个名字信息量高一个量级.

### 4.2. GSPO 的优势什么时候显性化

按论点的机制推, 三个条件放大 GSPO 的收益. 第一, 模型是 MoE 或路由敏感的架构, token 概率的集体波动大. 第二, 链长, 位置数多, token 级决策的方差累积明显. 第三, minibatch 复用深, off-policy 程度大, 每位置漂移普遍. Dense 模型, 短链, 严格 on-policy 的场景, 三个条件都不满足, GSPO 相对 GRPO 的差距会缩到噪声以内——此时选 GSPO 的理由是基建统一 (Qwen 系), 不是算法收益. 反过来, 论文没有覆盖的场景也要列出: 过程奖励 (token 级 reward 出现时, 「单位对齐」论点反转, token 级优化反而成了对的粒度); 极短回答 (长度归一的统计收益消失); 多轮交互 (序列的边界模糊, 「一条回答」的定义要重新想).

**与 DAPO 技巧的组合。**

GSPO 可以组合 DAPO 中作用于采样与 reward 端的动态采样和长度塑形, 因为它们不改变 surrogate 的定义. Clip-Higher 与序列级 clip 则需要重新适配: 序列级只产生一次 clip 决策, 仍可按 $A_i$ 的正负在标量 $s_i$ 上分别使用 $\epsilon_{high}$ 和 $\epsilon_{low}$, 但 DAPO 的 0.28/0.2 属于 token 级量纲, 换到序列级后必须重新标定 (§3.3). 归约分母的差别在组合时自然消解: GSPO 的比率内建了 $1/|y_i|$, DAPO 的 token 统一分母作用在 token 粒度, 两者同时存在会双重计数长度因子. 用 GSPO 时, 损失分母回到「每条回答等权」即可, 不要再叠 DAPO 的分母. 这类「组合时只保留一层长度处理」的原则, 适用于所有跨方法拼接的场景.

## 5. 稳定性机制再分析

**MoE 路由与集体波动。**

把 §1.2 的机制说得更具体. MoE 的 router 是 $y_{i,<t}$ 的函数, 和 attention 共享输入但走独立的小 MLP; policy 更新改变 router 权重后, 一批历史 token 的路由决定集体改变, 它们的 FFN 输出从专家 A 换成专家 B, 两个专家对同一输入的 logits 差异直接变成 log-prob 跳跃. 在逐 token surrogate 里, 这批跳跃是几十个位置同时出现 $\rho$ 离群, 每个都触发 clip, clip 后的梯度仍保留方向 (min 结构下未触平台的另一侧), 几十个同方向的 clip 后梯度叠加, 参数被猛推, 下一步更多 token 路由翻转——正反馈. GSPO 里这批跳跃先被平均: 几十个 $+0.5$ 的 log-ratio 和其余几千个 $+0.001$ 混合, 均值可能只有 $0.01$, $s_i$ 落在 clip 区间内, 更新按平均意见大小进行, 不放大集体事件. 这是「平均抑制集体波动」的机制, 代价是集体波动里可能包含真实信号 (某个专家确实更该被用), 也被一并抑制了.

序列平均会同时压低信号和噪声, 因而用分辨率换取了较小方差. 路由敏感的 MoE 中噪声占主导时, 平均更有利; 步骤结构清晰、局部信用信号较强时, 逐 token 更新可能保留更多信息. 论文验证的是前一种场景, 后一种场景需要重新比较 (§6.3).

### 5.2. 长度归一的另一面

$s_i$ 对长度归一, 因而两条平均漂移相同但长度差十倍的链获得相同的 clip 处理; 若改用完整序列似然比, 长链的总偏移会大得多. GSPO 选择约束「平均每 token 漂移」. DAPO 的 token-level loss 则按 token 数加权, 长链得到更大权重. 两种方法针对的「长度问题」定义不同: reward 究竟评价整条行为, 还是平均 token 行为. 实践上这个分歧没有看起来大: GRPO 系的 token 级 clip 下, 长链内部的大漂移早被逐位置截停, 实际生效的更新也被压向「平均意见」; GSPO 只是把这个效果显式化. 真正的实验分歧出现在极端长度差的 batch 上, 日常混合 batch 里两者差距有限.

这个「日常差距有限」的判断可以量化验证: 取历史训练的 batch, 分别用两种分母重放梯度, 比较参数更新的余弦相似度. 相似度高于 0.99 就说明在你的数据上这个争论无关紧要, 低于 0.95 才值得专门消融——先测再争论, 是这类「哲学分歧」的标准化解法.

这个方法也适用于 5.1 的「平均抑制集体波动」之争: 与其论证平均对不对, 不如统计训练 batch 中集体波动的占比——占比低, 平均无害; 占比高, 该担心的不是平均, 是路由为什么如此敏感, 那是模型侧的问题. 顺着这个思路, MoE 训练稳定的另一条路线是 router 正则与负载均衡损失的调校, 和 surrogate 的选择正交, 值得并行排查. 工程上这两路的排查成本不同: surrogate 替换要动训练器, router 调校只动模型配置, 先排查成本低的一侧. 当然, 若两路排查完崩溃仍在, 就该回头怀疑「崩溃」的归因本身, 而不是继续叠加补丁.

**与 Dr. GRPO 之争的关系。**

1.3.1.1 节 §3 记录过 Dr. GRPO 对 GRPO 的两项批评: 组内标准差归一造成难度偏差, 按回答长度归约造成长度偏差. GSPO 和这组批评的关系微妙. 一方面, GSPO 的序列比率内建了长度归一, 长链的 token 梯度带 $1/|y_i|$ 因子, 和 Dr. GRPO 的方向一致; 另一方面, GSPO 论文保留组内标准差归一的优势构造, 没有采纳 Dr. GRPO 的去归一建议. 也就是说, Qwen 接受了「长度维度」的批评, 没接受「难度维度」的批评. 两类偏差作用的位置不同: 难度归一影响「不同题之间的梯度配比」, 在 Qwen 的生产设置里可能由课程和采样策略缓冲; 长度偏差影响「同题内长短链的判决」, 会直接扰动序列比率并触发训练崩溃. 因此工程修复的优先级取决于实际出现的崩溃模式.

相互矛盾的方法建议可以先还原到各自针对的失效模式. 若系统中没有出现对应症状, 直接叠加修正只会增加耦合; 若症状已经出现, 检查它的存在性通常也比完整的方法对照实验便宜.

## 6. 实验, 边界与选型

**论文报告的结果。**

论文报告 GSPO 在 Qwen3 系列 (Instruct, Coder, Thinking 及 MoE 变体) 的大规模 RL 中替代 GRPO, 训练稳定性显著改善, MoE 崩溃不再出现, 下游能力持平或更好. 作为方法学证据, 它的分量来自「生产管线全量替换」: 不是消融跑分, 是一个头部团队把主力算法的 surrogate 换掉并公开背书. 序列级实现也简化了工程记录: 每条回答只需存一个 $s_i$, 日志、监控和异常分析都从 token 矩阵降到标量向量, 调试成本随之降低. 这组生产证据没有公开同算力、同数据、只替换 surrogate 的严格对照组. 论文给出的是替换前后的稳定性变化和下游指标, 足以说明 GSPO 在 Qwen3 的规模与架构上可稳定运行, 还不足以推出它在所有模型和数据配方上都优于 GRPO.

论文还提供了生产实现所需的比率定义、裁剪范围和适用模型信息. 这些内容能支持复现, 但不能替代受控消融；方法的可实现性与跨设置的因果结论需要分别验证.

### 6.2. 批评与开放问题

第一, 平均 log-ratio 的指数不是真实似然比, off-policy 复用时的偏差缺少理论刻画, 现有依据主要来自实验. 第二, 「MoE 崩溃由 token 级优化导致」仍是机制假说; 换 surrogate 后崩溃消失也可能来自更保守的有效学习率. 第三, clip 值 3e-4/4e-4 与具体模型和步长绑定, 迁移时需要重新标定量纲 (§3.3). 另一个开放问题是和过程奖励的兼容性: 一旦 reward 信号细化到步骤级, 「单位对齐」的论点要求优化也细化, GSPO 的序列级比率反而成了错配. 论文没有涉及这个组合, 社区实践也还没给出标准答案——步骤级 reward 配 token 级优化, 序列级 reward 配序列级优化, 中间的混合形态是留给后续工作的空白.

「混合粒度 surrogate」正在探索这个空白: 有工作尝试步骤级比率与序列级比率的加权组合, 在保留步骤信号的同时控制方差. 该方向尚无定论, 开源框架 (verl, OpenRLHF) 的 recipe 变化通常比正式论文更早显露工程选择.

**选型。**

MoE 或路由敏感架构 + 长链推理 + 深复用, 三个条件占两个以上, GSPO 值得作为默认 surrogate 试跑. Dense 模型短链场景, 留在 GRPO/DAPO 生态更省事实验. 无论选哪个, §4.1 的六行对照表都是核对实现的清单, 尤其 clip 量级那一行——它和比率定义绑定, 迁移时必须先重标定. 生产报告还显示了一项论文指标之外的收益: GSPO 的日志从 token 矩阵降到标量后, 某个 prompt 的组内方差异常或单条链的 reward 离群更容易暴露. 团队若长期受 GRPO 调试复杂度影响, 这项可观测性改善本身就可能抵消迁移成本. 评估 surrogate 改动时, 可以把平均异常定位时间与下游指标一起记录; 基建收益常会在前一项上体现.

**实现。**

**7.1 教学实现.**

```python
import torch

def gspo_loss(new_logp, old_logp, advantages, mask, eps_low=4e-4, eps_high=3e-4):
    # new_logp, old_logp: [batch, seq]（有效 token 的 log π）
    # advantages: [batch]，序列级优势
    # mask: [batch, seq]，有效 token 为 1
    log_ratio = (new_logp - old_logp.detach()) * mask
    mean_log_ratio = log_ratio.sum(-1) / mask.sum(-1)   # [batch]
    s = torch.exp(mean_log_ratio)
    clipped = s.clamp(1 - eps_low, 1 + eps_high)
    surr = torch.min(s * advantages, clipped * advantages)
    return -surr.mean()
``` 和 GRPO 实现的 diff 只有三行: log-ratio 先 mask 求平均再 exp, clip 移到序列级, 逐 token 的 surrogate 循环消失. 注意 `old_logp.detach()` 和 GRPO 一样必须做; `advantages.detach()` 同理. 存储上 GSPO 更省: 每条回答只需留 old logp 的和与有效长度两个数, 不用留整段 old_logp 张量. 这个存储优势在长链场景的工程价值不小: 一次 rollout 存全部 old_logp 是 GB 级的 I/O, 只存标量后降两个数量级; 对异步 rollout-train 流水, 传输和序列化的瓶颈随之缓解. 算是 surrogate 选择附赠的基建红利. **7.2 验证清单.**

三个不变量. 第一, 归一正确性: 构造 mask 不规则的输入 (padding 穿插), 用朴素循环重算 $\sum_t m_t d_t/\sum_t m_t$ 对比向量化结果, 逐位一致. 第二, 长度不敏感性: 把同一条 log-ratio 序列复制成两倍长度 (均值不变), $s$ 必须不变; 这个不变量直接检验「平均而非求和」, 漏除长度是最常见的实现错误. 第三, clip 退化: $\epsilon\to\infty$ 时损失退化为 $-\mathbb{E}[s_i A_i]$, 与解析值对照. 另补一个集成检查: 全链 log-ratio 同号且均值超界时, clip 必须按 $s$ 的整体值触发一次, 而不是按 token 触发 (和 GRPO 实现交叉对比两者的触发计数). 存储上的另一个测试点: 只存 $\sum_t\ell^{old}_{i,t}$ 和 $|y_i|$ 两个标量的实现, 必须能在重新前向时还原 mean log-ratio 到 float32 精度; 半精度下先求和再相减会丢精度, 建议在 log 空间全程 float32 运算, 这一点和 ORPO (1.2.4 节) 的数值纪律相同. **7.3 从序列比率反推每个 token 的梯度.**

令 $d_t=\log\pi_\theta(y_t\mid x,y_{<t})-\log\pi_{old}(y_t\mid x,y_{<t})$，则 $s=\exp(\frac{1}{T}\sum_t d_t)$。在未触发裁剪且优势为 $A$ 时，单条样本损失为 $L=-sA$，对任一新策略对数概率的导数都是

$$
\frac{\partial L}{\partial\log\pi_\theta(y_t\mid x,y_{<t})}=-\frac{sA}{T}.
$$

因此 GSPO 虽然在序列级构造比率，梯度仍会回到每个有效 token；同一回答内各位置共享相同的序列系数 $sA/T$。mask 后的有效长度必须进入分母，否则 padding 会把长短回答的更新尺度改乱。若 $s$ 落到裁剪平台且被裁剪分支选中，该样本对应方向的梯度变为零，这也是 clip fraction 可以直接反映有效样本利用率的原因。

这个导数还给出一项简单的实现检查：构造长度分别为 4 和 8、平均 log-ratio 与优势都相同的两条回答，单 token 梯度应相差一倍，而整条回答的梯度绝对值之和应接近一致。若两条回答的梯度和也相差一倍，通常是遗漏了 $1/T$；若 padding 位置出现非零梯度，则 mask 在求和或分母处使用错误。

### 6.3. 轨迹概率与序列级裁剪

**8.1 真正的轨迹 importance ratio.** 自回归策略对完整回答的概率为

$$
\pi_\theta(y\mid x)=\prod_{t=1}^{T}\pi_\theta(y_t\mid x,y_{<t}).
$$

因此 current 相对 old 的轨迹概率比为

$$
\rho_{seq}=\frac{\pi_\theta(y\mid x)}{\pi_{old}(y\mid x)}
=\prod_{t=1}^{T}\rho_t,
\qquad
\rho_t=\frac{\pi_\theta(y_t\mid x,y_{<t})}
{\pi_{old}(y_t\mid x,y_{<t})}.
$$

在 log 空间中，$\log\rho_{seq}=\sum_t\log\rho_t$。这是标准轨迹级 importance sampling 的权重；只要行为策略覆盖目标策略支持集，它能把 old 策略下轨迹期望改写成 current 策略期望。问题在于乘积随长度迅速产生极端值。每个 token ratio 仅为 $1.01$，长度一千时乘积也约为 $2.1\times10^4$；每个 token ratio 为 $0.99$ 时则约为 $4.3\times10^{-5}$。 GSPO 定义的序列 ratio 为

$$
s(y)=\left(\rho_{seq}\right)^{1/T}
=\exp\left(\frac1T\sum_{t=1}^{T}\log\rho_t\right)
=\left(\prod_{t=1}^{T}\rho_t\right)^{1/T}.
$$

它是 token ratio 的几何平均，也是每 token 平均 log-ratio 的指数。$s$ 与真正轨迹 importance ratio 的关系为 $\rho_{seq}=s^T$。二者不能互换：$s$ 控制长度归一后的平均策略变化，$\rho_{seq}$ 才是严格的轨迹密度比。 **8.2 几何平均为何自然出现.** 算术平均 $T^{-1}\sum_t\rho_t$ 容易被少数巨大 ratio 主导，也无法保留概率乘法结构。几何平均先在 log 空间累加，再除以长度，描述一条序列上典型的乘性变化率。若每个 token 概率都乘同一个常数 $c$，则 $s=c$，与长度无关。 Jensen 不等式给出

$$
s=\exp\bigl(\mathbb E_t[\log\rho_t]\bigr)
\le \mathbb E_t[\rho_t].
$$

ratio 波动越大，算术平均与几何平均差距越大。例如两个 token ratio 为 $0.5$ 和 $2$，算术平均为 $1.25$，几何平均为一。GSPO 将这条序列视为平均概率尺度未变，但局部概率发生了四倍相对摆动。稳定的序列 ratio 可以与激烈的 token 变化并存。 几何平均还有重复制不变性：将同一 ratio 序列完整复制一遍，$s$ 不变。这个性质消除了单纯长度重复对 clip 的影响，也会掩盖重复模式。模型若把一段异常推理复制十次，局部 ratio 结构相同，$s$ 仍保持原值；reward、长度约束与重复检测仍需承担行为控制。 **8.3 GSPO ratio 并非严格 importance correction.** 用 $s$ 替代 $\rho_{seq}$ 后，目标一般无法严格等价于 current 策略下的轨迹期望。设 $f(y)$ 为任意函数，严格关系为

$$
\mathbb E_{y\sim\pi_{old}}[\rho_{seq}f(y)]
=\mathbb E_{y\sim\pi_\theta}[f(y)].
$$

把权重换成 $s=\rho_{seq}^{1/T}$，右侧不再成立。GSPO surrogate 因此是一种稳定的近端优化目标，通过序列单位与 reward 对齐来获得训练效果，代价是密度比修正的统计含义发生变化。 这一区分在 policy lag 增大时尤其重要。current 与 old 很接近时，令 $\delta_t=\log\rho_t$，则

$$
s=\exp(\bar\delta)\approx1+\bar\delta+\frac12\bar\delta^2.
$$

局部一阶变化由平均 log-ratio 控制，近端区域内可作为平滑代理。数据很旧时，$s$ 仍可能温和，而真实轨迹比 $s^T$ 已经极端，近似的行为解释随之变弱。

**序列级裁剪的梯度结构。**

**9.1 同一序列共享一个开关.** GSPO surrogate 可写成

$$
L=-\mathbb E_i\left[
\min\left(s_iA_i,
\operatorname{clip}(s_i,1-\epsilon,1+\epsilon)A_i\right)
\right].
$$

未触发裁剪时，$\partial s/\partial\log\pi_\theta(y_t)=s/T$，所以每个有效 token 获得相同的标量系数 $-sA/T$，再乘各自 log-prob 对参数的 Jacobian。序列 reward、序列 advantage、序列 ratio 和序列 clip 在统计单位上对齐。 一旦 $s$ 越过与优势方向对应的边界，整条序列进入平坦区。GRPO 的 token 级裁剪可能只屏蔽若干位置，其余 token 仍更新；GSPO 则共享一个开关。它降低了同一轨迹内部「一些 token 被裁、另一些继续走」造成的梯度碎片，也可能因单个序列均值越界而丢掉全部 token 信号。 **9.2 正负优势的分段导数.** 对 $A>0$，$s\le1+\epsilon_{high}$ 时

$$
\frac{\partial L}{\partial \log\pi_\theta(y_t)}=-\frac{sA}{T},
$$

$s>1+\epsilon_{high}$ 后导数为零。对 $A<0$，$s\ge1-\epsilon_{low}$ 时保持同一形式，$s<1-\epsilon_{low}$ 后归零。若结合 DAPO 的 clip-higher，可使用不同上下界；改变的是序列级开关位置，并未恢复 token 级局部裁剪。 序列内每个 log-prob 的标量导数相同，不代表每个 token 对参数更新相同。不同位置的 hidden state、词表分布和 Jacobian 不同，早期 token 还会通过后续条件状态影响整条生成。上式只描述 score-function 路径中的显式权重。 **9.3 与 token 级裁剪的反例.** 考虑长度四的正优势序列，token ratio 为 $(1.5,1.0,1.0,1.0)$。token 级 PPO 在上界 $1.2$ 时裁掉第一个 token，后三个继续更新。GSPO 的 $s=1.5^{1/4}\approx1.107$，整条序列未触发裁剪，异常 token 与其他 token 一起产生梯度。 再看 $(1.2,1.2,1.2,1.2)$。token 级实现都处在边界附近，GSPO 的 $s=1.2$ 同样临界。第一例说明几何平均会稀释局部尖峰，第二例说明一致偏移能够完整反映到序列 ratio。GSPO 主要抑制集体波动，不提供局部异常上限。

反方向例子为 $(1.5,1.5,0.8,0.8)$，几何平均约为 $1.095$。token 级裁掉两个高 ratio，并保留两个低 ratio；序列级全部保留。若四个 token 共同组成一个正确推理，序列更新更连贯；若前两个 token 是奖励攻击、后两个是普通结尾，聚合会隐藏危险前缀。

### 6.4. 长度效应、方差与策略滞后

**10.1 平均 log-ratio 的方差.** 令 $d_t=\log\rho_t$，均值为 $\mu$，方差为 $\sigma^2$。若不同位置独立同分布，则

$$
\operatorname{Var}(\bar d)=\frac{\sigma^2}{T}.
$$

长序列的平均 log-ratio 更集中，$s=\exp(\bar d)$ 也更稳定。实际 token 强相关，若任意两位置相关系数近似为 $\rho$，则

$$
\operatorname{Var}(\bar d)
=\frac{\sigma^2}{T}[1+(T-1)\rho].
$$

正相关使方差下降变慢；当整条序列受同一参数变化或 MoE 路由扰动影响时，$\rho$ 可显著大于零。GSPO 的稳定性来自平均化，但收益取决于相关结构。 **10.2 指数变换带来的偏移.** 即便 $\bar d$ 的均值为零，$s$ 的均值也可能大于一。若 $\bar d\sim\mathcal N(\mu,v)$，则

$$
\mathbb E[s]=\exp(\mu+v/2).
$$

因此仅看 mean log-ratio 为零，不能推出平均序列 ratio 为一。方差越大，指数变换的上偏越明显。监控应同时报告 $\bar d$ 的均值方差、$s$ 的分位数与双侧 clip fraction。 长度分桶中，短回答的 $v$ 通常更大，更容易撞到 clip 边界；长回答因平均化集中在一附近，可能获得更高有效样本率。这构成一种隐含长度偏好：长序列获得优势的原因来自更低的 ratio 裁剪率，与 loss 分母加权属于两条独立路径。 **10.3 极值稀释随长度增长.** 若只有一个 token 的 log-ratio 为 $a$，其余为零，则 $s=\exp(a/T)$。固定异常幅度 $a$ 时，长度越大，序列 ratio 越接近一。长度十、$a=\log4$ 时 $s\approx1.149$；长度一百时仅约 $1.014$。同一个四倍局部变化在长序列中几乎不可见。

可增加辅助约束，例如监控 $\max_t|d_t|$、高分位数或局部窗口均值。若把这些量直接加入裁剪目标，又会重新引入 token 或片段级开关，需要通过消融判断是否破坏 GSPO 的序列一致性。监控与优化约束应分开讨论。 **10.4 长度随机变量与目标权重.** 同一 prompt 可能生成不同长度。GSPO 对每条序列使用平均 log-ratio，再对回答取平均，序列作为基本单位等权；单 token 显式梯度含 $1/T$，整条序列的显式权重和约为 $sA$。这与 DAPO token-level loss 的按 token 聚合不同。 如果长推理确实包含更多必要决策，序列等权可能让单步学习信号过小；若长推理主要是冗余，等权能避免其因 token 多而支配 batch。GSPO 的长度归一解决 ratio 尺度问题，同时作出了序列等权选择。两个选择可以拆开实验，不应把所有收益都归于几何平均。

**Off-policy 与 Policy Lag。**

**11.1 几何平均会掩盖累计漂移.** 假设每个 token 平均 log-ratio 为 $0.01$。无论长度多少，$s=e^{0.01}\approx1.010$；真实轨迹 ratio 为 $e^{0.01T}$，长度两千时达到 $e^{20}$。序列 clip 认为变化很小，严格 importance sampling 却认为轨迹分布差异巨大。 因此 GSPO 仍依赖较小 policy lag。它稳定了 surrogate 的数值尺度，没有让旧数据变成新鲜数据。producer checkpoint、更新版本差、wall-clock 年龄和 PPO epoch 都需要记录。按 lag 分桶的外部收益比单一全局 clip fraction更能显示数据陈旧程度。 **11.2 多 epoch 复用.** 同一批轨迹重复更新时，$\bar d$ 逐步远离零。若序列内部正负变化抵消，$s$ 可能长期位于 clip 区间，允许继续拟合同一批 reward；token 级 ratio 已经出现长尾。训练 loss 稳定并不保证策略变化局部。 可在每个 epoch 计算 current 对 old 的平均 log-ratio、最大 token log-ratio、sequence clip fraction 和与新鲜 rollout 梯度的余弦。若序列 clip 很低而新鲜梯度方向已经分叉，几何抵消正在延长旧数据寿命，额外 epoch 未必可靠。 **11.3 温度与行为策略.**

采样温度、top-p、top-k 和语法约束共同定义 old 行为分布。保存基模型未调温 log-prob 作为分母，会得到错误 ratio。温度 $\tau$ 下的行为分布为

$$
q_{old}(a\mid s)=\frac{\exp(z_a/\tau)}{\sum_b\exp(z_b/\tau)}.
$$

分母应使用 $q_{old}$ 的真实 log-prob。动态调整温度时，每条轨迹绑定自己的解码配置。不同配置混合后，几何平均仍能计算，但统计分布不同，最好按 sampler 分桶监控。

### 6.5. MoE 路由与相邻方法边界

**12.1 路由变化进入概率比.** MoE 模型中，token hidden state 经 router 选择专家。参数更新、负载均衡和并行数值误差都可能改变边界附近 token 的专家组合，进而使某些位置 logits 突变。相邻 token 因内容不同进入不同专家，ratio 波动呈现位置依赖。 token 级裁剪逐点决定是否保留梯度，一条正优势序列可能留下零散 token 更新。它们继续改变路由边界，下一轮又产生新的 ratio 尖峰，形成不稳定反馈。GSPO 将整条回答的平均变化作为一个权重，使局部路由抖动在 log 空间平均，论文报告其对大规模 MoE 训练更稳定。 **12.2 集体变化仍会穿过聚合.** 若某一专家影响整段推理，多个 token 的 log-ratio 同号，平均后仍明显偏移，GSPO 会裁剪整条序列。平均只抑制局部零均值波动，无法消除一致漂移。这是合理性质：整条行为分布确实发生变化时，近端约束应触发。

可以把 $d_t$ 分解为序列公共项 $c$ 与局部扰动 $\eta_t$：

$$
d_t=c+\eta_t,\qquad \mathbb E_t[\eta_t]=0.
$$

GSPO 的 $\bar d=c$，局部扰动被平均掉；token 级方法同时响应 $c$ 和每个 $\eta_t$。若 $\eta_t$ 代表数值噪声，GSPO 有益；若它代表关键局部策略变化，被消除的正是有意义信号。需要通过路由日志与行为案例区分。 **12.3 Dense 模型同样可能受益.** 注意力、归一化、量化和长序列位置变化也会制造 token ratio 长尾，因此 GSPO 不局限于 MoE。MoE 只是让问题更突出。Dense 模型若 token ratio 平滑、policy lag 小，序列与 token 目标差距可能有限；这时替换 surrogate 的收益需要实验确认。

**与 GRPO、DAPO 的机制关系。**

**13.1 三者改动的坐标.** GRPO 用组内 reward 构造序列 advantage，常见实现却在 token 层计算 ratio、裁剪和归约。DAPO 保留 token ratio，加入非对称裁剪、动态采样、token-level loss 与超长塑形。GSPO 将 ratio 与裁剪提升到序列层，重新对齐 reward 与优化单位。 三者共享组相对估计，因而都面对全同组、reward 噪声与 prompt 选择问题。GSPO 并未自动提供 dynamic sampling，也未解决长度 reward 和验证器错误。DAPO 的数据与 reward 机制可与 GSPO 组合，但 token-level loss 与序列等权之间需要明确选择。 **13.2 GSPO 与 Clip-Higher.** 非对称边界可以直接作用于 $s$：正优势使用 $1+\epsilon_{high}$，负优势使用 $1-\epsilon_{low}$。由于 $s$ 的方差通常比单 token ratio 小，沿用 DAPO 的数值区间可能过宽。应根据 sequence ratio 分位数重新选择，而非复制 token 级超参数。 若正侧 sequence clip fraction 本来接近零，进一步放宽上界不会恢复多少样本，只会允许少数极端序列走得更远。有效性证据应包含边界附近的样本密度、解锁比例和对应外部收益。 **13.3 GSPO 与 Dynamic Sampling.**

Dynamic sampling 改变进入更新的 prompt 分布，GSPO 改变保留组的梯度权重。两者作用层不同，可以组合。全同组被过滤后，sequence ratio 的方差估计来自更窄的中等难度分布，clip 参数可能随课程变化失配。 训练期间按全对、全错和有效组分别记录 ratio，即便前两者不更新。若困难全错组具有更大 policy lag 或更长回答，过滤会让总体 ratio 看起来更稳定。监控仅覆盖训练组会低估真实生成分布的不稳定性。 **13.4 GSPO 与 Token-Level Loss.** GSPO 论文中的序列目标让每条回答贡献一个 surrogate。若把 $s_iA_i$ 再广播到 token 并按全 batch token 平均，长回答重新获得更大总权重，形成「序列 ratio、token 加权」的混合目标。它在数学上可定义，却不再保持序列等权。

混合目标可能适合长链任务，也可能让长回答支配。实验需分离两因素：固定 sequence ratio，比较序列平均与 token 平均；再固定归约，比较 token ratio 与 sequence ratio。四格实验比直接比较 GRPO 与 GSPO 更能定位收益。

### 6.6. 反例、统计比较与验收

**14.1 局部灾难被平均隐藏.** 设长度一百的正优势回答，九十九个 token ratio 为一，一个关键 token ratio 为 $10^{-6}$。序列 ratio 为

$$
s=(10^{-6})^{1/100}\approx0.871.
$$

它仍可能位于常用下界附近，且正优势方向不会因 ratio 偏低触发上侧裁剪。这个关键动作的概率下降百万倍，却只让序列平均变化约百分之十三。若该 token 决定是否调用安全工具或是否选择正确证明分支，局部突变具有实际后果。 反过来，一个 token ratio 为 $10^6$，其余为一，$s\approx1.148$，也可能留在上界内。长度一千时两种极端都被压到约 $0.986$ 与 $1.014$。长序列特别需要局部 ratio 分位、最大绝对 log-ratio 和关键动作监控。 **14.2 正负变化的几何抵消.** 两个 token ratio 为 $2$ 与 $0.5$ 时 $s=1$。GSPO surrogate 认为 current 与 old 在平均尺度上相同，实际轨迹概率乘积也恰好为一；然而动作分布结构已经重排。若第一个 token 是错误前缀、第二个只是常见标点，二者对行为的影响并不相等。

importance ratio 只关心 sampled 轨迹概率乘积，无法表达 token 的语义重要性。GSPO 进一步做长度归一，仍不会识别关键位置。过程 reward、状态价值或分段目标可以补充信用分配，但需要可靠监督。序列级终局 reward 下，语义重要性只能通过采样结果间接进入优势。 **14.3 极短回答与空响应.** 长度一的回答有 $s=\rho_1$，GSPO 退化为 token 级 ratio，方差与局部尖峰完全保留。空响应或生成零个有效 action token 时分母为零，不能用钳到一的方式静默处理；应标记为环境或模板失败，并明确 reward 与过滤规则。 极短错误答案往往 ratio 稳定且计算便宜，极长正确答案平均 ratio 更集中。若 reward 与长度处理不当，序列级 clip 可能让两类都保持高有效率，最终取舍由组优势决定。长度分桶的正确率和梯度范数必须共同报告。

**Reward、组估计与序列比率。**

**15.1 Advantage 的误差会整段广播.** GSPO 为每条回答计算一个序列 advantage，并用一个 $s$ 缩放整段梯度。验证器假阳性会使错误轨迹全体 token 获得正向更新，序列裁剪在 $s$ 未越界时无法隔离局部错误。相比 token 级裁剪，错误信号更一致，学习奖励漏洞也可能更快。 同组标准化在 reward 方差很小时会放大噪声。若分数为 $(0.501,0.500,0.500,0.500)$，唯一高分轨迹可能得到显著正优势。应根据验证器重复评分方差设置最小有效差异，或保留未标准化分数检查优势来源。 **15.2 全同组仍然空转.** GSPO 改变 ratio 与 clip 单位，不改变 $A_i=0$ 时梯度为零。全对、全错或 reward 量化后的全同组仍需由 dynamic sampling、过程信号或课程数据处理。序列 ratio 再稳定，也无法从没有相对差异的组产生学习方向。

加入连续长度罚可能让任务全同组产生差异，随后 GSPO 学习长短偏好。训练有效组率上升并不一定代表正确性信号增加。日志应同时按原始任务 reward 与总 reward 判断全同，报告长度塑形新增了多少更新组。 **15.3 Group size 与 ratio 估计.** 组大小不会直接进入 $s$，却影响优势排序和有效组概率。大组更容易出现 reward 尾部，也更容易包含异常 verifier 高分；该轨迹的错误优势通过序列一致梯度放大。增加组大小前要看最高分稳定性、重评分翻转率和候选相关性。 固定 rollout token 预算时，增大组会减少独立 prompt。GSPO 的序列等权使每条回答先成为一个单位，再在组和 batch 聚合。若不同 prompt 有不同有效候选数，按回答平均会偏向候选多的 prompt，按组平均则保持 prompt 等权。过滤后应明确归约层级。

### 数值精度与分布式归约

**16.1 Log 空间计算.** 直接相乘 token ratio 极易上溢或下溢。可靠实现先计算 float32 的 $d_t=\log p_t^{new}-\log p_t^{old}$，按有效 mask 求和，再除以有效长度并指数化。若最终只需裁剪，可先在 log 空间与 $\log(1\pm\epsilon)$ 比较，避免不必要的极端指数。 old 与 new log-prob 应使用相同 token id、上下文、位置编码和 mask。错一位 token 也可能产生合理数值，却完全失去 ratio 含义。保存输入 token 哈希、有效长度和首尾若干 token，可快速发现 rollout 与 trainer 的模板差异。 **16.2 只存 old log-prob 总和的边界.** 若 GSPO 只需要 $\sum_t\log p_t^{old}$，存一个序列标量可减少传输。但该压缩会失去 token 级审计，无法计算局部 ratio 分位、定位错位或切换回 token surrogate。训练可存总和，抽样轨迹保留完整 old log-prob 用于监控与回归。

old log-prob 总和必须在生成时基于真实行为分布得到。后来用 reference 或重新加载的 nominal checkpoint 计算，可能受量化、专家路由、服务实现和解码温度差异影响。标量压缩减少存储，也减少事后纠错能力。 **16.3 Sequence parallel 的正确分母.** 序列被切成长度 $T_1,\ldots,T_K$ 的分片时，各卡先计算局部和 $D_k=\sum d_t$ 与计数 $T_k$，全局结果为

$$
\bar d=\frac{\sum_kD_k}{\sum_kT_k}.
$$

直接平均各卡局部均值 $K^{-1}\sum_kD_k/T_k$ 只在分片等长时正确。padding、packed sequence 和负载均衡通常使有效长度不同，错误归约会给短分片过高权重。 分布式测试应把同一序列按多种不等长方案切分，结果与单卡逐位一致；再混合 padding 和空分片，确认计数归约无误。梯度累积跨 micro-batch 同样要明确按序列数还是 token 数加权。

**统计比较与方差分解。**

**17.1 序列内与序列间方差.** 令第 $i$ 条序列的 log-ratio 为 $d_{i,t}$，可分解总变异为序列间均值差异和序列内位置差异：

$$
\sum_{i,t}(d_{i,t}-\bar d)^2
=\sum_iT_i(\bar d_i-\bar d)^2
+\sum_{i,t}(d_{i,t}-\bar d_i)^2.
$$

GSPO 的 $s_i$ 直接使用第一部分的信息，第二部分被压缩进均值。若训练不稳定来自序列间集体漂移，GSPO clip 能直接限制；若来自序列内少数尖峰，平均化可能只让 loss 更平滑而未消除行为风险。 **17.2 公平的 GRPO 对照.** 比较 GSPO 与 GRPO 时固定模型、数据、行为策略、reward、group size、有效 token 预算和优化器。clip 区间不能机械设成同一数值，因为 token ratio 与几何平均的分布尺度不同；可以分别按初始分位数校准相近的有效样本率，再比较稳定性，也应保留同参数对照展示默认行为。 报告训练 reward、外部能力、序列与 token clip fraction、梯度范数、熵、KL、长度和成本。若 GSPO 仅减少 loss 波动，外部能力无改善，结论限于数值稳定；若吞吐提高来自 old log-prob 压缩，也要与纯存储优化分开。 **17.3 置信区间的独立单位.**

同组回答共享 prompt 和优势统计，同一回答的 token 共享 $sA/T$。token 不能作为独立样本计算置信区间。评估以 prompt 聚类 bootstrap，多种子训练再作为更高层变异来源。 稳定性事件如 loss spike、梯度爆炸和训练崩溃属于稀有事件，需要足够长运行或多个种子。一次成功长训无法证明尾部风险消失。可报告单位 token 的故障率、最大连续无故障区间和恢复成本。

### 可证伪验收与适用边界

**18.1 数学不变量.** 所有 token ratio 相等为 $c$ 时，$s=c$；完整复制序列后 $s$ 不变；连接两段序列时，新 log 均值为按长度加权的两段均值；长度一时退化为 token ratio。随机张量与手算循环应逐条满足这些关系。 current 等于 old 时 $s=1$，未裁剪 surrogate 等于 $A$。正数缩放优势只缩放 loss，不改变 clip 分支；候选置换不改变组结果。padding token 的 log-prob 任意扰动不应影响 $s$ 或梯度。 **18.2 反例套件.** 反例至少包含单个巨大 ratio、正负抵消、全体一致偏移、长度一、超长序列、空响应、token 错位和不等长分片。每例记录 token ratios、真实轨迹乘积、几何平均、裁剪分支与梯度。实现若只对普通随机输入做测试，很难覆盖这些结构性边界。

再加入 reward 假阳性和全同组。前者验证错误优势如何整段广播，后者确认 ratio 再异常也不会在零优势下产生更新。若全同组仍有梯度，通常是 advantage 广播、归一化或残留 KL 项错误。 **18.3 端到端判据.** GSPO 稳定性假说要求序列内局部噪声被平均后，梯度尖峰与崩溃率下降，同时外部能力不退化。若 loss 更平滑但局部 ratio 极值、生成异常或 reward hacking 增加，则稳定只存在于聚合指标。 长度假说要求不同长度桶的 sequence ratio 分布更可比。若短回答仍频繁裁剪、长回答几乎从不裁剪，需要按长度调整诊断，甚至重新考虑均值聚合。off-policy 假说则要求 policy lag 增大时性能按可预测方式下降，不能把几何平均当作无限复用数据的许可。

**训练记录与最终边界。**

**19.1 必需的版本字段.** 每条 rollout 绑定 producer、current 更新号、reference、tokenizer、服务精度、路由配置、温度、top-p、模板和 verifier。每次更新记录 group size、归约、clip 上下界、PPO epoch、有效长度与梯度缩放。序列标量只有配合这些上下文才可复算。 若 MoE expert parallel 拓扑变化会影响数值路由，应把拓扑和框架版本列入实验元数据。不同硬件上微小 logits 差异可能在 router 边界放大，复现时需要判断属于正常非确定性还是实现偏差。 **19.2 必需的联合指标.** 序列层报告 $\bar d$、$s$、双侧 clip、advantage 和长度；token 层报告 $d_t$ 分位数、极值、位置分布和局部 KL；组层报告 reward 方差、全同率与有效候选；模型层报告熵、固定 reference KL、外部能力和生成成本。

只有序列指标时，局部异常不可见；只有 token 指标时，无法判断一条回答整体是否漂移。两层同时出现异常，优先处理 policy lag 或学习率；token 异常而序列稳定时，重点检查路由、错位和关键动作。 **19.3 方法适用范围.** GSPO 适合序列 reward 明确、长回答和 MoE token 波动显著、训练主要处于近端区域的场景。过程 reward 很密、关键局部动作需要独立约束或数据高度 off-policy 时，纯序列聚合可能过粗。可以保留局部监控、分段 ratio 或混合目标，但每项扩展都要重新说明统计含义。 最终判断应落在行为和能力上。序列 loss 变稳、显存下降和吞吐提高都很有价值，却不能代替 reward 正确性、泛化能力与风险评估。GSPO 解决的是优化单位不一致带来的一个关键问题，并未包办探索、信用分配和数据质量。

**从一阶近似看目标差别。** 令 $d_t=\log\rho_t$ 很小，真正轨迹权重与 GSPO 权重分别展开为

$$
### 一阶近似与长度效应

\rho_{seq}=\exp\left(\sum_td_t\right)
\approx1+\sum_td_t+\frac12\left(\sum_td_t\right)^2,
$$

$$
s=\exp\left(\frac1T\sum_td_t\right)
\approx1+\frac1T\sum_td_t+\frac{1}{2T^2}\left(\sum_td_t\right)^2.
$$

一阶项相差 $T$ 倍，二阶项相差 $T^2$ 倍。GSPO 的长度归一不仅压低数值方差，也系统性缩小离策略修正强度。学习率可以补偿平均尺度，却无法恢复不同长度轨迹之间的严格密度权重，因为所需缩放随 $T$ 变化。 若所有序列等长，未裁剪的 GSPO 一阶梯度与轨迹比梯度可通过常数缩放接近；长度变化后，一个全局学习率无法同时对齐。由此可见，长度归一既是稳定化，也重新定义了经验目标。评估需要接受这个目标选择，而不能继续把 $s$ 称作完整 importance ratio。 **长度条件下的裁剪概率。** 假设 $d_t$ 独立且服从均值 $\mu$、方差 $\sigma^2$ 的分布，则 $\bar d$ 近似服从 $\mathcal N(\mu,\sigma^2/T)$。正侧越过上界的概率约为

$$
P(s>1+\epsilon)
=1-\Phi\left(
\frac{\log(1+\epsilon)-\mu}{\sigma/\sqrt T}
\right).
$$

在 $\mu$ 低于阈值时，$T$ 增大使概率快速下降；高于阈值时，概率反而趋近一。长序列因此更像确定性判断：平均漂移在边界内就几乎全部保留，在边界外就几乎全部裁掉。短序列围绕边界分散，clip fraction 更平滑。 token 正相关时把 $\sigma^2/T$ 替换为 $\sigma^2[1+(T-1)\rho]/T$。若 $\rho$ 接近一，长度带来的集中效应消失。实际数据可通过序列内自相关或分块均值估计有效相关长度，再与观察 clip fraction 对照。理论预测和实测严重不符时，优先检查 token 错位、混合采样配置或重尾分布。 **重尾下均值也会不稳。** MoE 路由突变可能让 $d_t$ 呈尖峰厚尾，中心极限定理在有限长度下收敛缓慢。少数极端值即便除以 $T$，仍可控制 $\bar d$。均值的稳健替代包括截尾均值、分块中位数和 Huber 聚合，但它们失去几何平均与概率乘积的直接关系。

采用稳健聚合前，应判断尖峰属于数值噪声还是关键策略改变。对明显错位或非有限 log-prob，数据应修复或丢弃；对真实低概率关键动作，截尾会隐藏有意义变化。GSPO 选择普通均值，保持定义简单，异常治理留给数据验证和监控。 **序列有效样本量。** 即使每条序列获得一个权重，batch 内轨迹可能由同一 prompt、同一解码前缀或同一模型版本生成，梯度存在相关。设归一化序列权重为 $w_i$，常用权重有效样本量为

$$
N_{eff}=\frac{(\sum_iw_i)^2}{\sum_iw_i^2}.
$$

裁剪使极端 $s$ 受限，通常提高权重 ESS；但组 advantage 可能仍有重尾，最终梯度权重应按 $|s_iA_i|$ 或其裁剪值计算。ESS 高只说明权重均匀，相关样本仍可能提供重复信息。 再考虑平均相关系数 $\rho_g$，粗略有效数可除以 $1+(N-1)\rho_g$。同 prompt 多候选的独立单位少于回答数。比较 GSPO 与 token 方法时，token 数量不代表统计样本量；序列和 prompt 层的 ESS 更接近真实证据量。 **组优势与序列 ratio 的协方差。** surrogate 的核心量为 $sA$。若高 advantage 轨迹恰好具有大 $s$，更新被放大；若二者负相关，importance 权重压低优秀样本。可分解

$$
\mathbb E[sA]=\mathbb E[s]\mathbb E[A]+\operatorname{Cov}(s,A).
$$

组中心化使组内 $\mathbb E[A]$ 接近零，更新很大程度取决于协方差。训练报告单独给 $s$ 均值和 advantage 均值无法说明有效信号，至少需要相关系数或按 advantage 分桶的 $s$ 分布。 当行为策略与 current 很接近，$s$ 约为一，协方差小；多 epoch 后，模型专门提高高 advantage 轨迹概率，正相关逐步增强，直到正侧裁剪截断。这个过程是近端更新的预期行为。若第一个 minibatch 就出现强相关，可能是 old log-prob 版本错误或 rollout 已过期。 **序列内符号冲突。** 终局 advantage 为正时，GSPO 显式推动整条 sampled 回答的所有动作概率上升；然而回答中可能含有绕路、错误尝试和自我修正。最终成功掩盖了中间低质量动作。负 advantage 回答也可能包含关键正确步骤，只因结尾算错而整体受罚。

这种信用分配粗糙来自序列 reward，并非 GSPO 独有。GSPO 的序列 ratio 与整体开关使序列一致性更强，优缺点也更集中。拥有可靠步骤验证器时，可把轨迹切成片段，为每段计算 reward-to-go 与片段 ratio；片段边界必须对应语义状态，机械固定窗口会把推理动作切断。 片段 GSPO 可定义

$$
s_k=\exp\left(\frac{1}{|C_k|}\sum_{t\in C_k}d_t\right),
$$

并配合片段优势 $A_k$。它在 token 与整序列之间选择粒度，但引入更多 reward 设计与相关性。若仍把同一个终局 $A$ 广播给所有片段，只改变裁剪粒度，并未改善信用分配。 **安全关键 token 的独立约束。** 工具权限、拒答边界、代码执行参数等少数动作具有高风险，长序列均值容易稀释其 ratio。可将它们作为监控集合，限制 $|d_t|$ 或对固定安全集测 KL。这个约束独立于主 GSPO loss，类似护栏。 护栏阈值过紧会阻止模型纠正旧策略的安全错误。应区分禁止变化的协议 token 与允许通过训练改进的决策 token，并在独立红队集上校准。训练目标稳定不能直接推出安全行为稳定。

**真实轨迹比可作诊断而非权重。** 虽然 $\rho_{seq}=s^T$ 常常极端，log 轨迹比 $T\log s$ 仍可稳定计算。其绝对值展示 current 与 old 在完整回答上的累计距离。按长度分桶报告该值，可以发现 sequence ratio 看似接近一、累计漂移却随长度扩大的情形。 不应直接将极端轨迹比重新乘回损失，否则会恢复高方差问题。可用它设置数据新鲜度阈值、减少 epoch 或触发重采。阈值也需随 reward 与任务校准，因为长序列天然累积更大 log-ratio。 **Policy lag 的二维描述。** 版本差只计算经过多少优化步，wall-clock 年龄反映系统排队，分布距离反映实际策略变化。三个量并不等价：学习率很小时版本差大但 ratio 仍近一；一次异常更新后版本差一也可能产生巨大漂移。记录三者可将调度问题与优化问题分开。

MoE 路由还使同版本重算存在差异。rollout 服务采用量化权重，trainer 使用高精度权重时，名义 checkpoint 相同，行为 log-prob 仍不同。可在固定轨迹上比较 producer 保存值与 trainer 重算值，建立系统误差基线。差异超过基线再归因于 policy 更新。 **Reference KL 与 old ratio 回答不同问题。** GSPO 的 $s$ 比较 current 和 producer old，用于近端更新；reference KL 比较 current 与固定 SFT 或安全锚点，用于累计漂移。rolling old 每轮变化，固定 reference 长期不变。把 reference log-prob 放进 $s$ 分母会把近端优化变成长程约束，clip fraction 很快饱和。 训练可以不在 loss 中加入 KL，仍保留 reference KL 监控。若序列 ratio 稳定而 reference KL 单调扩大，说明每步虽小但累计明显。能力回归若同步下降，需要收紧步长、减少复用或恢复 KL 正则；单纯缩小 GSPO clip 只能限制未来局部变化，无法撤销历史漂移。

**采样支持集与归一常数。** top-p 会根据当前状态选择最小高概率集合并重新归一，行为概率为截断后的分布。old log-prob 若记录截断前 softmax，遗漏了状态相关归一常数；每 token 误差进入平均后可能形成系统偏移。top-k、重复惩罚和语法掩码同样改变真实概率。 有些服务只返回基础模型 log-prob，无法表达全部采样变换。此时 ratio 属于近似值，需在小词表环境或离线采样器上量化误差。若近似误差随长度、语言或解码配置变化，GSPO 均值无法自动消除。 **完整四序列手算。** 某 prompt 生成四条长度均为二的回答，reward 为 $(1,1,0,0)$。不做标准差缩放时，中心优势为 $(0.5,0.5,-0.5,-0.5)$。四条 token ratio 分别为 $(1.44,1)$、$(1.2,1.2)$、$(0.64,1)$ 与 $(0.8,0.8)$，对应 $s$ 均为 $1.2,1.2,0.8,0.8$。

设边界为 $[0.9,1.1]$。两条正优势序列越过上界，两条负优势序列低于下界，GSPO 四条全部进入平坦区，当前 batch 梯度为零。token 级裁剪中，第一条第二个 token ratio 为一，第三条第二个 token ratio 也为一，它们仍保留局部梯度；另外两条全部临界或越界。两种目标在相同平均 ratio 下产生不同更新稀疏度。 将 GSPO 边界改为 $[0.8,1.2]$，所有序列落在边界，梯度按实现对等号的次梯度选择处理。为避免测试依赖边界不可导点，可将 ratio 改成 $1.19$ 与 $0.81$。未裁剪 surrogate 总和为 $1.19\times0.5\times2+0.81\times(-0.5)\times2=0.38$。组内优势和为零，但与 ratio 的正协方差产生正更新。 若四条长度改为 $(2,20,2,20)$，同时保持各自所有 token ratio 恒定，$s$ 不变，序列平均仍等权。token 全局平均会让两条长序列占据大部分分母。这个反例同时验证 ratio 聚合与 batch 归约必须分别说明。

**不等长拼接的手算。** 一段长度二，log-ratio 为 $(0.1,0.1)$；另一段长度八，均为零。第一段 $s_1=e^{0.1}$，第二段 $s_2=1$。拼接后

$$
s=\exp\left(\frac{2\times0.1+8\times0}{10}\right)=e^{0.02}.
$$

直接平均两个片段 ratio 得 $(e^{0.1}+1)/2$，对应给片段等权，结果更大。sequence parallel、packed sequence 或分段缓存若犯这个错误，短分片会被放大。测试应刻意使用极端不等长分片。 **公式与代码的对应关系。** `mask.sum(-1)` 对应 $T$，`((new-old)*mask).sum(-1)` 对应 $\sum_td_t$，两者相除得到 $\bar d$，指数得到 $s$，随后序列 advantage 与序列 clip 只执行一次。任何先 `exp` 再平均的实现计算的是 ratio 算术平均；任何先求和直接 `exp` 的实现计算的是真实轨迹比。 混合精度下，new 与 old log-prob 的差可能是两个接近负大数相减。各自在 fp16 量化后再相减会丢失小变化，长序列求和又累积误差。log-softmax、差值和归约宜在 float32 完成。可用 current=old 的长序列检查 $\bar d$ 是否围绕零且不随长度漂移。

**重复段落与模板泄漏也影响训练文档。** 同一结论若在不同章节以近似句式反复出现，读者难以分辨新增条件。这里把「序列稳定不等于局部稳定」落实到三个不同证据：几何抵消的解析反例、长度稀释的数量级、关键动作的行为风险。三者指向同一边界，却分别回答数学、尺度与应用问题。 **最终复现实验矩阵。** 第一轴选择 token ratio 或 sequence ratio，第二轴选择序列等权或 token 等权，第三轴选择对称或非对称 clip，第四轴选择新鲜 rollout 或多 epoch 复用。全因子成本高时，至少保留能分辨 ratio 与归约的四格，以及 sequence ratio 在两种 lag 下的对照。

每次运行固定生成 token 预算、prompt 流和 verifier 版本。行为策略因参数更新而分叉后，共同随机数无法维持完全相同，但初始 batch 可共享，便于比较第一步梯度。记录两方法梯度余弦、范数与局部尖峰，能在能力曲线分叉前看到机制差别。 **失败判定应提前写出。** 若 GSPO 降低梯度尖峰但外部正确率显著下降，稳定性代价过高；若 sequence clip 很低但 token 极值和生成故障增加，聚合掩盖局部异常；若长序列几乎永不裁剪且累计 log 轨迹比持续扩大，长度归一过度放松；若 policy lag 增大后收益反而只在训练 verifier 上提高，可能正在复用旧数据拟合评分器。

成功判定也要具体：在相同 token 和时间预算下，多个随机种子较少崩溃，外部能力至少持平，MoE 路由与 token ratio 尾部可解释，长度桶之间的有效样本率没有严重失衡，固定 reference 能力无额外退化。满足这些条件，才能将「loss 更平」提升为「优化更可靠」。 **适用条件。** 序列 reward 本身明确、回答内部动作共同服务于终局结果、token ratio 含大量局部噪声时，GSPO 的单位对齐具有清晰动机。任务依赖少数不可平均的关键动作、过程 reward 已能精确分段、或离线数据与 current 差距很大时，需要局部约束、片段目标或更严格的离策略方法。

几何平均提供了一个可解释的折中：保留乘性概率结构，用长度归一控制尺度，再用序列裁剪统一决定整条轨迹是否更新。它得到的稳定来自有意丢弃部分局部信息。只要把这份信息损失纳入监控与验收，GSPO 才能在长链和 MoE 训练中发挥优势，而不把平滑曲线误当成完整答案。 **几何平均的对称性。** 将 current 与 old 交换，token ratio 变为 $1/\rho_t$，GSPO ratio 也变成 $1/s$。这种倒数对称有助于检查实现：用同一轨迹交换两组 log-prob，两个 sequence ratio 的乘积应为一，允许浮点误差。若乘积随长度系统偏离，常见原因是 mask、温度或 log-prob 精度不一致。 上下 clip 区间在 ratio 空间对称为 $[1-\epsilon,1+\epsilon]$，在 log 空间却不对称，因为 $-\log(1-\epsilon)>\log(1+\epsilon)$。例如 $\epsilon=0.2$ 时边界约为 $[-0.223,0.182]$，负向允许的 log 距离更大。若希望 log 空间严格对称，应使用 $[e^{-c},e^c]$。两种边界都合理，但稳定性解释不同。

DAPO 式 clip-higher 进一步扩大正侧 ratio 边界。GSPO 的 $s$ 已经过平均，边界微调对应每 token 平均 log 变化；真实轨迹概率的允许倍率为 $(1+\epsilon_{high})^T$。在长度两千的回答上，即使 $1.01$ 的 sequence 上界也对应巨大的轨迹倍率。近端含义应限定为「每 token 平均近端」，不能解释为完整轨迹近端。 **不同长度的同一文本操作。** 给回答尾部附加一段 current 与 old 概率完全相同的无关文本，其 $d_t=0$。原回答平均 log-ratio 为 $\bar d$，附加 $K$ 个零变化 token 后变为 $T\bar d/(T+K)$，$s$ 更接近一。行为策略没有改变原有动作，却因新增无关尾部降低裁剪概率。

这提供了长度操纵反例：模型若学会在答案后生成稳定模板，能够稀释前文 ratio 漂移。模板是否带来 reward 取决于终止与格式规则，但优化器层面确有稀释效应。评估可计算去掉固定尾缀后的 sequence ratio，或只在语义有效 action 上聚合。后者需要可靠识别模板边界。 相反，删除一段零变化 token 会放大平均偏移，使短答案更易裁剪。长度变化因此影响更新机会，即便新增 token 自身 ratio 等于一。GSPO 的长度归一消除了完整复制的影响，却不对添加零变化片段保持不变；这正是均值分母的结果。

**前缀与后缀的条件影响。** 数学表达式把 $d_t$ 当作一串数，实际自回归模型中早期 token 改变会改变后续状态。固定同一 sampled 轨迹重算 log-prob 时，current 和 old 都条件于相同 token 前缀，因此 ratio 可逐位比较；它没有估计「若 current 自由生成，后续会走向哪里」。重要性修正只覆盖已采轨迹。 一个早期 token 在 current 下概率大降，后续 token 在这条旧轨迹上的 ratio 仍可能接近一，但 current 实际已很少访问这些状态。几何平均会把早期降幅摊入全长。新鲜 rollout 能直接暴露状态分布变化，因此控制 policy lag 比精细调整聚合器更根本。 **熵与 ratio 的联系。** ratio 描述两个策略对 sampled 动作的概率变化，熵描述单个策略整个词表分布。所有 sampled token ratio 接近一时，未采动作仍可能重排，熵也可能变化；sampled ratio 出现尖峰时，整体熵未必显著变化。二者需要分别测量。

MoE 路由导致某些 token logits 局部变化，若 sampled 动作仍处于概率平台，ratio 小而词表尾部分布可能大幅变动。全词表 KL 或熵抽样能补充 sampled ratio。为了控制成本，可在固定状态子集上周期性计算完整分布，并按序列位置与专家路由分桶。 **序列裁剪后的梯度利用率。** 以回答数统计 clip fraction 会让长短序列每条权重相同；以 token 数统计则让长序列贡献更多。GSPO 目标按序列等权，回答级 fraction 更贴近 loss 中被屏蔽的样本比例，但 token 级 fraction能表示被屏蔽的计算量。两者同时报告能发现长序列集中被裁的情况。 还可以定义优势加权利用率：未裁剪序列的 $|A|$ 总和占全部 $|A|$ 的比例。若 clip 主要发生在低优势样本，回答 fraction 很高但损失信号损失有限；若少数高优势样本被裁，普通 fraction 看起来不严重，关键学习机会却被挡住。

正负优势分开统计也很重要。正侧频繁裁剪表示优秀轨迹已被 current 提升很多，负侧频繁裁剪表示低分轨迹已被压低很多。两侧失衡可能来自非对称 clip、reward 分布或策略更新方向。一个总 fraction 会掩盖原因。 **多目标 reward 下的序列权重。** 回报若由正确性、格式、长度、安全和工具成本加权，单个 $A$ 把取舍压成标量。GSPO 会一致强化总分较高的整条轨迹，却无法说明哪一分量驱动更新。保存分量并计算每个分量与 $sA$ 的相关性，可以发现模型主要优化易钻的格式分。 组内中心化使常数 reward 分量消失，但不同 prompt 的分量尺度仍会改变优势。某题正确性分差为一，另一题工具成本分差为十，标准化后两组可能等权；不标准化时后者支配。GSPO 的 ratio 选择不解决 reward 标尺，需单独审计。

**全同组与非零 KL。** 某些实现即便组 advantage 为零，仍在 loss 中加入独立 KL 惩罚，于是全同组产生梯度。此时「全同组空转」只对任务 surrogate 成立，总 loss 仍会把策略拉向 reference。Dynamic sampling 丢弃这类组会同时减少 KL 覆盖，改变正则分布。 若 GSPO 训练移除 KL，全同组确实不更新；若保留 KL，应分别记录任务梯度与 KL 梯度。把两者合并后观察非零 loss，容易误判 advantage 计算错误。单元测试可以关闭 KL 验证严格零梯度，再打开 KL 检查解析方向。 **梯度范数与裁剪次序。** Sequence clip 作用于 surrogate，global gradient clipping 作用于聚合后的参数梯度。某条序列未被 ratio 裁剪，仍可能因巨大 advantage 造成全局裁剪，连带缩小其他序列更新。序列 ratio 稳定无法保证梯度范数稳定。

应报告 ratio clip 前后的样本权重、全局裁剪前后的梯度范数和触发率。若 GSPO 降低 ratio 尖峰但 global clip 仍频繁触发，根因可能在 reward 尾部、batch 相关性或优化器状态。继续收紧 sequence clip 会损失正常信号。 Adam 二阶矩会把一次异常的影响延续多步。GSPO 减少瞬时尖峰后，历史二阶矩仍可能让有效学习率偏低。切换算法的对照实验若沿用已经被异常污染的 optimizer state，对新目标不公平；从共同 checkpoint 和共同优化器状态启动更清楚。 **多轮与工具轨迹的长度定义。** 有效长度 $T$ 通常只计模型生成的 action token。用户消息、系统提示、工具返回和环境观察不属于策略采样动作，不进入概率比。若模型多轮生成，所有 action 段可合并为一条轨迹，也可按决策轮分段。

合并后终局 reward 与完整交互对齐，但早期与晚期动作共享一个 ratio；按轮分段能看到局部漂移，却需要轮级 advantage。工具返回很长时，不应因观察 token 增多而稀释模型 action 的平均 log-ratio。mask 错误会让使用工具的轨迹获得异常稳定的 $s$。 工具调用参数常由少量 token 决定，属于前述关键动作。主 GSPO loss 可以保持序列单位，额外在工具参数状态上监控 token KL 和执行成功率。若序列指标稳定而工具失败率升高，局部约束缺失已经产生行为后果。 **量化与推测解码。** rollout 服务若使用量化模型，trainer 的高精度 current log-prob 与行为分布存在实现差异。严格 ratio 分母应来自量化服务实际概率；服务只返回 token 而不返回概率时，用高精度 nominal 模型重算属于近似。固定提示上比较两端 token 分布，可估计基线误差。

推测解码在接受规则严格保持目标分布时不改变行为策略；自定义近似接受、缓存截断或不同精度可能改变分布。吞吐优化上线前，比较生成频率与保存 log-prob 的校准。GSPO 的平均会让小的系统误差形成稳定偏移，长期把 $s$ 推离一。 **检查公式编号与引用。** 文中公式主要通过上下文引用，避免同一编号指向多个表达式。若后续加入显式编号，应建立单调序列并在修改后扫描重复标签。链接文字需对应真正的一手论文或实现，评论性判断留在正文，参考资料列表只承担出处。

引用顺序优先放 GSPO 论文，再列用于机制对照的 GRPO、DAPO 与实现。论文提出的实验结论、本文给出的数学推论和工程诊断应在措辞上分开：前者受论文设置支持，后两者需要独立实验验证。这样既保留可读性，也避免把推导当成作者原结论。 **最终检查的最小样本。** 从真实 batch 随机抽一条短序列、一条长序列、一条被正侧裁剪、一条被负侧裁剪和一条局部 ratio 极端但 $s$ 正常的序列。逐条保存 reward、advantage、$d_t$、$s$、clip 分支、梯度范数与生成结果。五个样本覆盖长度、方向和聚合盲区。

再从训练外固定一组 prompt，每隔若干 checkpoint 使用相同解码预算生成，记录成功率、答案簇、长度、自然终止与安全行为。它不受 dynamic sampling 的训练分布变化影响，可以验证平滑 surrogate 是否转化为真实能力。训练日志与固定评估共同稳定时，GSPO 的收益才站得住。 **裁剪偏差可以直接估计。** 对同一 batch 同时计算未裁剪项 $s_iA_i$ 与裁剪项 $\tilde s_iA_i$，二者均值差

$$
### 裁剪偏差与上线审计

\widehat B_{clip}=\frac1N\sum_i(s_i-\tilde s_i)A_i
$$

给出当前样本上的裁剪影响。它不等于总体偏差，却能显示哪一侧、哪种长度和哪类任务损失最多 surrogate。将 $\widehat B_{clip}$ 按正负优势拆分，可以判断边界主要限制强化还是抑制。 由于 $s$ 并非严格轨迹密度比，未裁剪目标本身已经相对真实 off-policy 校正发生变化；$\widehat B_{clip}$ 只衡量第二层裁剪。分析应区分「长度根变换造成的目标偏移」与「边界截断造成的偏移」。前者在所有样本存在，后者只发生于越界样本。 若 clip fraction 很低，边界偏差小，但长度根变换仍可能很大。把低 clip fraction 当作近似 on-policy 证据并不充分，还要检查平均 log-ratio、累计 $T\bar d$ 与 producer lag。三者分别描述是否越界、每 token 漂移和完整轨迹漂移。

**Self-normalized 权重并不自动解决问题。** 一种直觉是将序列权重归一为 $w_i=s_i/\sum_js_j$，避免整体尺度漂移。这样得到的 self-normalized estimator 通常有有限样本偏差，并且组内某条 $s$ 增大时会压低其他轨迹权重。它还能让不同 batch 的归一常数依赖样本组成。 GSPO 使用近端 surrogate 与裁剪，不需要再做该归一。若实验采用 normalized weight，应单独列为算法变化，并报告 ESS、偏差和 batch size 敏感性。小 batch 中一个大 $s$ 会显著改变所有样本，大 batch 才较平滑。 **Group normalization 与 sequence weighting 的次序。** reward 优势先在同 prompt 内中心化，再乘各自 $s$。因此加权后的组和一般不再为零：

$$
\sum_i s_iA_i
=\sum_i(s_i-\bar s)A_i,
$$

其中使用了 $\sum_iA_i=0$。有效更新来自 sequence ratio 与优势的组内协方差。若实现先用 $s$ 加权 reward 再中心化，得到的是另一估计器，ratio 会参与 baseline，梯度性质也随之变化。 可用候选置换和 stop-gradient 测试确保优势不依赖 current ratio。若组均值计算图意外连接到 $s$，某条轨迹会通过 baseline 影响同组其他轨迹，偏离常见组相对目标。优势、old log-prob 与 reward 都应按配方明确 detach。 **序列概率随 tokenizer 改变。** 相同文本使用不同 tokenizer 会得到不同 $T$ 与条件概率分解，$s$ 也不具备跨 tokenizer 的直接可比性。更细粒度 tokenizer 通常增加长度，每 token 平均 log-ratio 的尺度可能变化。模型升级 tokenizer 后需要重新校准 clip 分布，不能沿用旧阈值解释。 即使 tokenizer 相同，Unicode 规范化、空格和模板 token 也会改变分解。rollout 与 trainer 必须共享完全一致的编码结果。保存 token ids 比保存文本后重新编码更可靠；文本用于审计，ids 用于复算。

**结束动作应计入概率比。** EOS 决定序列终止，是策略动作的一部分。漏掉 EOS 会忽略长度决策，模型从自然终止变为继续生成时 sequence ratio 监控可能看不见。达到最大长度而被系统截断的轨迹没有 sampled EOS，应记录删失状态，不能伪造 EOS 概率。 stop string 可能由多个 token 组成，服务在匹配后删除或保留尾部，trainer mask 若不同会产生长度和 log-prob 差异。对自然 EOS、stop string、工具终止与 max-length 分别构造复算用例，确保有效 action 集合一致。 **序列内重复的统计特征。** 重复循环常让相邻 token 的 $d_t$ 高度相关，前述独立方差缩减不再成立。虽然长度很长，平均 log-ratio 仍可能保持明显偏移；若循环在 old 与 current 中概率都高，$s$ 又可能接近一。ratio 只能描述策略变化，不能评价行为质量。

因此重复率、n-gram 多样性和自然终止属于行为指标，应与 $s$ 并排。GSPO 稳定地复现坏循环仍是坏策略。reward 或环境若不能惩罚循环，优化单位对齐不会自动修复。 **跨 checkpoint 的校准曲线。** 在固定轨迹池上，用连续 checkpoints 计算 $s$、token 极值和真实 log 轨迹比，可以观察策略距离随训练时间增长。固定池越来越 off-policy，只适合作诊断；新鲜轨迹池反映当前行为。两条曲线一起显示模型变化与采样分布变化。 若固定池 $s$ 漂移明显、新鲜池始终围绕一，说明 rollout 同步正常、策略持续进步；若新鲜池也系统偏离一，producer lag 或 log-prob 实现存在问题。若只有 token 极值扩大而 $s$ 稳定，局部波动被聚合掩盖，需要结合生成案例判断。

**最小审计表可以人工闭环。** 每行对应一条回答，包含 prompt id、长度、reward 各分量、组优势、old/new log-prob 总和、平均差、$s$、clip 分支、最大 token 差和梯度范数。组内行相邻排列，便于检查优势和为零及 $sA$ 协方差。 再从一行下钻到 token 表，记录位置、token、mask、old/new log-prob、$d_t$、路由专家和关键动作标签。序列表解释为何整条轨迹更新，token 表解释平均值由哪些位置组成。两张表足以定位大多数 ratio、mask、路由与裁剪问题。 **结论落在三个尺度。** token 尺度负责发现局部概率与路由异常，sequence 尺度负责让终局 reward、importance proxy 和裁剪单位一致，prompt group 尺度负责构造相对优势。GSPO 强化了中间尺度，却仍依赖上下两层提供可靠输入与风险监控。

只要这三个尺度都可观测，序列级几何聚合的取舍就清楚：它用更低方差和更连贯的轨迹更新，交换严格 importance correction 与局部敏感性。训练是否值得采用这笔交换，最终由长链能力、故障率、数据新鲜度和局部风险共同决定。 序列级概率比率降低了 token 级比率在 MoE 路由扰动下的聚合方差，也会把局部异常压进一个均值. 诊断需要同时保留序列比率和逐 token 对数比率分位数. 当序列比率仍在 clip 区间、个别 token 的对数比率却出现长尾时，后续新鲜采样可能沿局部变化进入另一条推理链，平滑的序列 loss 无法排除这种转移.

设回答含 $T$ 个有效 token，序列对数比率写作 $\bar r=T^{-1}\sum_t\log(\pi_\theta/\pi_{old})$. 平均聚合让阈值较少受长度影响，同时让单 token 异常贡献缩小为原来的 $1/T$. 长度分桶若显示局部极值随长度增大、序列均值却保持相近，需要结合尾部重复、模板化和关键动作检查稀释效应. Sequence parallel 或 context parallel 必须共同归约同一回答的 log-ratio 总和与有效 token 数，再执行除法. 各卡先求局部均值后简单平均，会让不等长分片获得相同权重。将同一序列切成二比八、三比七等多组分片，分布式结果均应与单卡计算一致.

**上线后的漂移检查。** 训练环境中的 old/current ratio 只能覆盖优化阶段，部署还会改变解码温度、并发批次、量化和工具模板。最终服务栈应在固定提示上重跑答案级指标，同时比较训练 trainer 与服务模型的 token 分布。若服务侧没有 log-prob，可通过多次采样估计答案簇频率和终止行为，至少确认策略没有因实现差异改变主要模式。

checkpoint 选择也要考虑部署成本。GSPO 可能稳定地产生更长或更复杂的答案，能力上升同时增加时延。按正确答案、错误答案和截断答案分别报告长度与计算量，避免平均成本被成功率组成变化误导。只有在目标流量分布上同时满足能力、风险和成本边界，训练收益才完成闭环。

**一条最终判断线。** 当 token ratio 的局部方差显著高于序列间公共漂移，reward 以完整回答判定，并且 rollout 足够新鲜时，几何聚合最符合问题结构。若观测到关键 token 突变、长答案利用率异常、累计轨迹漂移或 verifier 漏洞，处理对象分别位于局部约束、长度归约、数据新鲜度和 reward；继续调整一个 sequence clip 阈值无法同时解决四类问题。

最终报告还应展示被裁剪与未裁剪序列的真实样例。数字能说明分布，样例能回答被限制的是高质量新路径、重复模板还是评分漏洞。按正优势上界、负优势下界、局部极端但序列正常三类各抽取若干条，连同 reward 分量和长度公开，读者便能判断稳定性来自合理约束还是信息被平均。

当新模型、tokenizer 或解码配置上线后，上述分布需要重新校准。旧 clip 阈值只对应旧系统中每 token 平均 log-ratio 的尺度，不具备跨模型常数意义。以短程试跑获得分位数、检查关键反例、再进入长训，可以避免在数千步后才发现大部分序列始终位于平坦区或几乎从不触发约束。 GSPO 最值得保留的思想是让奖励、比率和裁剪共享序列尺度，同时明确几何平均舍弃了哪些局部信息。公式、统计和案例三者对得上时，这个折中可以被验证、被否定，也能在换任务后重新选择。 训练配方因此必须连同数据新鲜度、长度分布和局部异常统计一起解释，单独一个最终分数无法支撑机制结论。
