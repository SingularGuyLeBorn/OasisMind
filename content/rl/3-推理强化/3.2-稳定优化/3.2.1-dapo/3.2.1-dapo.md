## 1. 动机: GRPO 在推理 RL 中的三个裂缝

### 1.1. 熵坍缩与对称裁剪

推理 RL 训练到中后期, 一个普遍观察是策略熵快速塌缩: 采样越来越像贪心解码, 组内 $G$ 条回答趋于雷同, 探索消失, 之后再也采不到能改进的样本. DAPO 把矛头指向 PPO 系的对称裁剪: 标准 clip 用 $[1-\epsilon,1+\epsilon]$ 一视同仁地限制正负优势, 对正优势样本, 概率涨到 $1+\epsilon$ 就被截停. 问题在于, 正优势样本正是「这个行为该被强化」的方向, 截停它等于压低学习的上限; 反复截停后, 模型在最该保持多样性的方向上被迫收敛.

DAPO 的解法叫 Clip-Higher: 正优势的上界放宽到 $1+\epsilon_{high}$ ($\epsilon_{high}=0.28$), 负优势的下界保持 $1-\epsilon_{low}$ ($\epsilon_{low}=0.2$). 名字的意思是「把上界抬高」. 这一项单独的贡献在论文消融里很显著: 熵曲线不再单调下塌, AIME 分数上了一个台阶.

### 1.2. 全同组的空转

第二个裂缝在 1.3.1.1 节算过: 二值 reward 下, 组内全对或全错的概率是 $p^G+(1-p)^G$, 这类组的优势全零, 不贡献任何梯度, 但 rollout 成本一分不少. 难题太多或模型太弱时, 有效组占比低得惊人, 大量算力花在注定无用的采样上. 这个浪费不是实现问题, 是 GRPO 配方的一部分——它没有规定拿这些组怎么办.

DAPO 之前, 工程上的常见做法是把这些组留在 batch 里 (反正优势为零不影响梯度) 或简单丢弃. 留在 batch 里的问题是它们仍占 rollout 和显存, 丢弃的问题是不补采, 有效 batch 越训越小. 动态采样是第一种把这件事做成「保持产出恒定」的系统化处理.

**归约方式与长度的纠缠。**

第三个裂缝最隐蔽: GRPO 的损失先按每条回答的长度归一 ($\frac{1}{|y_i|}\sum_t$), 再对回答求平均. 这个「每回答等权」的约定, 和逐 token ratio 相乘之后, 长回答的每个 token 获得更小的梯度权重. Dr. GRPO (1.3.1.1 节 §3) 指出这引入长度偏差: 推理任务里正确链往往更长, 长度归一等价于压低正确答案的更新力度. DAPO 从工程侧独立走到同一个结论, 并直接改了归约.

三个裂缝合起来说明一件事: GRPO 的默认配方是为「reward 稠密, 长度均匀」的场景设计的, 推理 RL 的场景恰好相反——reward 二值稀疏, 长度方差巨大, 探索随时可能塌掉. DAPO 的四个技术逐一对应这三个裂缝, 没有一项是凭空的新算法.

DAPO 保留 GRPO 的主体, 但按推理任务的结构重新校准默认参数. 任务从数学推理迁到代码修复后, 四个现成数字很快会失去依据; 熵坍缩、全同组空转和长度权重错配都要在新数据上重新检查. 它提供的配方工程流程是先拆出默认配置的隐含假设, 再按任务结构逐项重校.

**Clip-Higher: 解耦裁剪。**

**裁剪曲线与梯度结构。**

写全 DAPO 的裁剪目标. 记 $r_t=\pi_\theta(y_t|y_{<t})/\pi_{old}(y_t|y_{<t})$, 序列优势 $A_i$ 广播到每个 token, 单 token 的损失是

$$u_t=\min\left(r_t A_i,\ \operatorname{clip}^{DAPO}(r_t,A_i)\,A_i\right),$$

其中

$$\operatorname{clip}^{DAPO}(r_t,A_i)=\begin{cases}\min(r_t,\,1+\epsilon_{high}), & A_i>0,\\ \max(r_t,\,1-\epsilon_{low}), & A_i<0.\end{cases}$$

注意这不是「$A>0$ 时只裁上界, 下界不管」的字面意思——PPO 的 min 结构天然保证取下界的那一支只在梯度层面生效, 改的是平台的位置. $A>0$ 时, 平台在 $r=1+\epsilon_{high}$ 形成, 之前 $rA$ 一路上涨, 之后截平; $A<0$ 时镜像, 平台在 $r=1-\epsilon_{low}$. 把 $\epsilon_{high}$ 从 $0.2$ 抬到 $0.28$, 等于把正优势的平台右移, 好动作的概率可以在更大的幅度内继续获得梯度.

**为什么放松上界能防熵坍缩。**

机制链条是这样: 推理 RL 的有效信号来自「同一题采到对和错两条链」, 它们的差异就是熵. 对称裁剪反复在 $1+\epsilon$ 处截停正优势, 正确链的概率提升受限, 模型学会「模棱两可的稳妥」——每种推理方向都保留一点概率, 但没有任何一个方向被推到位; 更糟的是负优势的截停同样对称生效, 错误链压不下去, 组内 reward 差异缩小, 下一步的信号更弱, 恶性循环. 放宽正侧上界打破这个循环: 正确的推理模式被允许大幅强化, 错误模式照旧压, 分布变尖的方向是「该尖的方向」, 熵的塌缩从「全面保守」变成「选择性收敛」, 同时保住了探索.

Clip-Higher 的目标中没有显式熵正则，它为正优势样本保留更宽的概率增长区间. 训练后期分布仍可收敛，论文曲线呈现熵避免骤然坍缩，同时保持缓慢下降. 因而它调节的是裁剪造成的梯度阻断，无法替代独立的熵控制目标.

和显式熵正则 (在 loss 里加 $\mathbb{E}[\log\pi]$ 项) 相比, Clip-Higher 不改变目标函数的形状, 只改变优化器到达目标的路径; 好处是不引入新的超参权衡, 坏处是它没有「熵下限」的保证. 这个不对称决定了排查顺序: 它改的是优化路径不是目标, 所以诊断熵问题时, 先查裁剪配置再查目标函数, 顺序反了会白调一轮熵系数.

监控上, 「熵不塌」的直接指标是组内唯一回答数和 n-gram 多样性, 比 token 级熵的数值曲线更可靠——后者受温度设置和分桶方式影响, 噪声大. 论文报告的熵曲线是按固定温度在探针集上测的, 复现时应沿用同一口径, 否则两条曲线不可比. 实践里两者可以共存, 但先上 Clip-Higher, 熵还是守不住再加显式正则, 顺序别反——先加正则会掩盖裁剪的问题.

**手算: 梯度权重对比。**

取 $\epsilon_{low}=0.2$, $\epsilon_{high}=0.28$, 看 $r_t$ 在不同位置的有效梯度. $A>0$: $r=1.10$ 时未触平台, 梯度权重 $\sigma$ 意义上的斜率就是 $A$; $r=1.25$ 时在平台内 (未到 $1.28$), min 结构下梯度为零; $r=1.30$ 越过平台, 梯度恢复. $A<0$: $r=0.85$ 未到 $0.8$ 平台? $0.85>0.8$, 未触平台, 梯度正常; $r=0.75$ 在平台内, 零梯度.

标准 PPO 与 DAPO 在 $r\in[1.20,1.28]$ 的正优势样本上产生差别：前者已经截停，后者仍在更新. minibatch 复用加深时 ratio 逐渐偏离一，正方向偏移可能集中在这一段，Clip-Higher 因而保留了边界附近的一部分密集信号.

顺带修正一个常见的画图误解: 把 PPO 和 DAPO 的 clip 曲线画在一起, 容易看成「DAPO 整体右移」. 实际只有 $A>0$ 的分支右移, $A<0$ 的分支纹丝不动; 画图时两条分支要分开画, 否则「对称区间」的直觉会回来, 误导后续的调参判断.

**手算二: ε 边界对有效更新区间的影响。**

把 clip 的数值结构再算透一点. 有效梯度区间 (平台之外) 的宽度, 正优势侧是 $r\in(0,1+\epsilon_{high})$, 负优势侧是 $r\in(1-\epsilon_{low},+\infty)$ 在 min 结构下实际生效的分支. 设 $\epsilon_{low}=0.2,\epsilon_{high}=0.28$: 好动作的更新空间比坏动作宽 40%. 再考虑 minibatch 复用导致的 ratio 分布: 复用 $K$ 次, ratio 的标准差大约随 $K$ 增长, 正侧平台右移意味着「前几个 minibatch 的正优势样本几乎全部保留梯度」, 而负侧在第二个 minibatch 就开始大量触平台.

由此得到一个调参方向: 如果监控里 clip fraction 显示负侧触发远多于正侧 (常见), 说明更新在「压错」上先饱和, 而「扶正」还有余量, 这正是 Clip-Higher 针对的失衡. 反过来, 如果两侧触发率接近, 说明 off-policy 程度不深, Clip-Higher 的收益空间有限, 优先排查别处.

**Dynamic Sampling: 动态采样。**

**过滤规则。**

规则本身一行: 组内 reward 全同的 prompt 丢弃, 其余保留. 实现上判据是 $\max_j R_j>\min_j R_j$, 和 reward 的编码无关——二值 $0/1$, 正负 $-1/1$, 连续分数都适用, 不要写成 `rewards.std() > 0` 之外的特定形态, 也不要把「全错组」和「解析失败组」混为一谈, 后者应进 verifier error 通道 (1.3.1.1 节 §5.2), 不该被动态采样默默吸收.

过滤改变了训练分布: 留下来的组偏向「难度适中」的 prompt. 这是有意为之——全对组没有新信息, 全错组在模型当前能力下也没有, 砍掉它们是按信息量重新配权, 不是偷懒. 但要知道代价: 已掌握的简单题和完全不会的难题都被移出梯度, policy 在两端的行为无人约束. DAPO 不显式保留 KL 项 (见 §6), 两端的漂移靠 clip 本身兜着, 这是它配方里最大胆的一处.

**补采策略与吞吐。**

过滤不是终点, 要保持有效 batch 大小恒定, 就得补采: 丢弃多少组, 就再拉多少新 prompt 进来重采, 直到凑满. 这改变了 rollout 流水的调度结构——采样变成「有条件的循环」, 每轮的采样量不再是固定值而是随机变量, 流水线的负载均衡要按最坏情况 (大量全错) 设计. 工程上常见的配套是预筛: 用上一轮的全对/全错记录预测当前 prompt 的有效概率, 优先采预计有效的, 补采只作兜底.

补采还带来一个监控陷阱: 报告「每组平均 rollout 成本」时, 忽略补采会低估真实成本, 合并计算又会掩盖动态调度的波动. 因此应分开报告首采成本、补采成本和有效组产出率. 单个平均数无法还原动态采样的资源消耗.

成本口径之外还有一个正确性问题: 补采的新 prompt 从哪个分布抽, 决定过滤后的训练分布是否还代表目标任务. 从原题库均匀补, 训练分布向「题库平均难度」收缩; 从难度分层的题库按层补, 保留人为控制的课程. DAPO 论文用后者 (SIA 数据集带难度标注), 复现时若题库没有难度结构, 补采分布就是隐形的超参. 给题库补难度标注的成本不高 (用当前模型小采样估 pass rate 即可), 回报是补采和课程都变得可控, 这笔投入在任何规模下都值.

**与难度分布的联动。**

动态采样把「选什么题」从数据侧的静态决定, 变成了训练过程的动态反馈: 模型变强, 昨天的中等题今天全对, 被过滤; 昨天的难题今天有对有错, 进入梯度. 题目难度分布随训练自动迁移, 这相当于一个隐式的课程学习. 好处是自适应, 坏处是不可控: 如果模型在某类题上突然塌掉 (比如长除法), 这类题会退化成全错组被过滤掉, 塌掉的事实从梯度里消失, 直到下游评测才发现.

防御手段还是监控: 记录每个 prompt 的历史通过率, 过滤组的比例按题目类别拆开报. 某类题的有效组占比持续走低, 是它正在掉出能力边界的信号, 此时应主动回灌该类题的 SFT 数据, 而不是任由动态采样把它移出视野.

这道防御的本质, 是给「自适应课程」装一个人工瞭望哨: 自动机制负责把算力分配到当前最有信息量的区域, 人工监控负责发现「信息量消失」本身可能就是事故. 两类职责不能都交给同一个自动机制.

**过滤的统计后果。**

动态采样让「进入训练的 prompt 分布」成为模型能力的函数, 这带来一些不直觉的统计性质. 有效组条件是「组内至少一对 reward 不同」, 对二值 reward 等价于「组内既有成功又有失败」, 即 pass rate $p$ 落在 $(0,1)$ 开区间. 过滤后的 prompt 分布密度正比于 $1-p^G-(1-p)^G$, 这个函数在 $p=0.5$ 附近最宽, 两端迅速收窄——所以动态采样天然把训练质量押在中等难度题上, 且 $G$ 越大押得越集中.

一个直接推论: 组大小和过滤强度耦合. $G=16$ 时, $p=0.1$ 的题几乎永远被过滤 (有效概率约 $1-0.9^{16}-0.1^{16}\approx81\%$ 尚可, 但 $p=0.05$ 时降到约 $56\%$), 模型如果要在难题上爬坡, 大 $G$ 反而拖慢. DAPO 的 $G$ 取 8 到 16 区间, 配合动态采样, 是在信号稳定和资源之间的折中, 不是越大越好.

## 2. Token-Level Policy Gradient Loss

### 2.1. 两种归约的代数差别

把 GRPO 和 DAPO 的归约并排. GRPO: 每条回答先按自身长度平均, 再对回答等权平均,

$$L^{GRPO}=-\frac1B\sum_{i=1}^B\frac{1}{|y_i|}\sum_t u_{i,t}.$$

DAPO: 批内所有有效 token 共享一个分母,

$$L^{DAPO}=-\frac{1}{\sum_i |y_i|}\sum_i\sum_t u_{i,t}.$$

两者给每条回答的权重不同：GRPO 中回答 $i$ 的权重为 $1/B$，DAPO 中为 $|y_i|/\sum_j|y_j|$. 长回答在批梯度中的占比由回答等权改为与 token 数成正比.

注意两个语义都没有变: 同一回答内的所有 token 仍共享序列优势, 序列 reward 并没有被拆成 token 级信用分配; 变的只是「回答之间」的相对权重. 把这个差别记成一句话: GRPO 按「条」投票, DAPO 按「token 数」投票.

按 token 数投票还有一个常被忽视的含义: batch 内各条回答的权重不再和采样顺序无关. 同一次 rollout 里, 先采完的回答和后采完的长度分布可能不同 (难度高的生成久), 分桶和调度策略会间接改变梯度构成. 想完全消掉这层影响, 只能按长度分组后再归约, 这又回到 §4.2 的分桶建议.

### 2.2. 与长度偏差的关系

按 token 数投票为什么更符合推理任务? 一条 2000 token 的正确链和一条 200 token 的正确链, 在 GRPO 里贡献相同的梯度预算, 但前者包含十倍的推理步骤, 它的正确性携带的信息量也更大; 更重要的是, 错误链也有长有短, 长度归一会让「长的正确链」相对「短的错误链」在梯度里被系统性压低估——恰好和 Dr. GRPO 分析的方向一致. DAPO 的消融显示 token-level loss 单项贡献约 2 到 3 个 AIME 点, 是四项技术里第二大的.

也要记下它的代价: 按 token 加权后, 批梯度的方差受长度分布影响更大. 长度方差大的 batch, 少数超长回答主导梯度, 学习率的有效尺度随 batch 构成漂移. 配套的做法是 length grouping (按长度分桶采样), 让 batch 内长度尽量齐, 把加权的影响限制在桶内.

长度分桶还有一个被动收益: 桶内序列长度相近, padding 浪费减少, rollout 和 training 的吞吐同时受益. 所以即便不关心长度偏差的团队, 也常把分桶当纯工程优化用——这是推理 RL 里少有的「正确性和效率同向」的技术.

**归约变体的全景。**

按「条」投票和按「token 数」投票之间, 还有中间态, 一并列出免得选型时漏看. 其一是按 $\sqrt{|y_i|}$ 加权, 折中两种极端, 部分缓解长度偏差又不让超长回答主导; 其二是按「有效步数」加权 (例如按换行或段落数), 对推理链这种结构化的输出, 步数比 token 数更接近「推理量」; 其三是 Dr. GRPO 的保留长度归一但修正 std 归一, 从优势侧而不是损失侧动手. 四者没有全面的公开对照, 选型依据只能是自己的长度分布和消融.

无论选哪种, 有一条不变: 归约方式必须和 clip 边界, 学习率, KL 系数当成一个整体调. 换分母改变梯度的有效尺度, 等效于动了学习率; 只换分母不动其他, 常见的结果是「改了但没完全改」——曲线有变化, 说不清变好变坏.

**Overlong Reward Shaping。**

**软惩罚的形状。**

推理链长度不断增长是推理 RL 的常态, 硬截断 (超了直接给 0 分或判错) 有一个恶果: 一条推理了 16000 token 即将答对的链, 因为超线前功尽弃, 且「超长」和「答错」在 reward 里不可区分, 模型收到的是混乱信号. DAPO 用三段线性软惩罚替代: 期望长度 $L_{max}-L_{cache}$ 以内不罚, 超过后每 token 线性扣分, 到 $L_{max}$ 扣满 $-1$, 再往上保持 $-1$ 直到生成上限.

论文的具体数字: 期望最大长度 16384, 软惩罚窗口 4096, 总生成上限 20480. 也就是说 16384 以下零惩罚, 16384 到 20480 之间线性从 0 降到 -1, 超 20480 的链惩罚封顶但 reward 仍来自验证器——「答对但超长」的链拿的是「正确答案 reward 减 1」, 而不是一刀切零分.

对比硬截断的账: 一条 16384 token 的临界链, 硬截断下 reward 从「即将到手的 +1」掉到 0 或解析失败, 负 advantage 落在整条链上, 惩罚的是「想得久」这个行为本身; 软惩罚下它拿 0 到 -1 之间的连续值, 且越接近上限罚越重, 模型学到的是「长度有边际成本」而不是「长度是灾难」. 两者的训练动态差异, 在长链任务上能差出几个点.

**与动态采样的配合。**

软惩罚和动态采样之间有直接的相互作用: 惩罚让超长组的 reward 出现连续值差异 (原来全对全错的组, 现在因长度不同产生分差), 一部分原本「全同被过滤」的组变成了有效组, 有效组占比上升. 这个红利在论文里没有单独量化, 但方向上明确:  shaping 不只是「保护长链」, 也顺手改善了采样效率. 想量化这个红利也不难: 对比开 shaping 前后的有效组占比曲线, 差值就是长度项创造的「新信号」. 这也是判断 shaping 强度是否合适的实用指标: 占比提升过小说明窗口太窄没在创造差异, 提升过大则说明惩罚在主导排序, 两者都不健康.

使用时有两个参数要按自己的任务重设: 期望长度和窗口. 窗口太小, 惩罚太陡, 长链任务被误伤; 期望长度定得保守, 等于提前给模型套上长度天花板, 和训练目标 (让链自然变长以解决难题) 直接冲突. 调参时看长度分布的 P90 和 P99 相对两个阈值的距离, 让 P99 落在窗口中段是常见的初始配置.

软惩罚需要匹配 reward 量纲：惩罚上限为负一时，与答错的常见编码同量级，答对但超长可能得到接近答错的总分. 连续任务分改变了负一的相对含义，需要按 reward 尺度重新标定惩罚幅度，或将长度惩罚作为独立维度进入优势.

**长度塑形的替代方案与组合。**

软惩罚不是处理超长的唯一手段, 列出两个常见替代及取舍. 其一是「长度进 reward 的乘法项」: 最终 reward 乘一个长度折扣因子 (例如 $R\cdot\exp(-\max(0,|y|-L_0)/tau)$), 答错的链长度无意义, 惩罚只作用在答对的链上, 语义比加法项更准, 但折扣因子引入新的尺度超参 $\tau$, 调参空间更大. 其二是「双 reward 通道」: 答案正确性和长度分别进两个优势, 加权合并, 相当于多目标 RL 的简化版, 可控性最好, 代价是实现复杂度.

软惩罚胜在简单和可解释, 且与二值 reward 的加法结构兼容; 任务 reward 本身连续或多维时, 再考虑乘法或双通道. 无论哪种, 处理超长的总原则和 §5.1 一致: 让「长」有边际成本, 而不是让「长」等于「错」.


---

**移除 KL 与其他细节。**

**KL 去哪了。**

DAPO 的目标函数里没有 KL 项, 靠 clip 承担全部的偏移约束. 这和 R1 时代的多数推理 RL 配方一致——推理任务的 reward 是规则验证, hacking 面小, KL 锚定的主要价值从「防 reward hacking」变成「防训练不稳」, 而 clip 加动态采样已经覆盖了大部分不稳来源. 代价是 §3.1 说的两端漂移无人约束, 以及对参考策略的依赖消失后, 训练日志里少了一个重要的健康指标 (KL 曲线), 监控体系要补上替代物 (熵, clip fraction, 长度分布).

这不是「KL 无用」的证据. 换成 reward model 打分或开放任务, hacking 面回来, KL 或等效约束就应回来. DAPO 的去 KL 是场景特定的设计决定, 搬配方时最容易被误抄的一项.

替代监控的具体做法: 把「policy 与初始 SFT checkpoint 的 KL」单独算出来记一条曲线, 训练里不加这项的梯度, 只观测. 它恢复了一部分 KL 曲线的预警功能, 又不改变 DAPO 的目标; 成本是每轮多一组 reference 前向, 和恢复 KL 项本身同价, 换来的是可观测性.

**完整算法流程。**

一个 DAPO 迭代周期: 对每个 prompt 采 $G$ 条, 验证器给分, 过滤全同组并补采至有效 batch 恒定; 组内做均值标准差归一得到优势 (保留 GRPO 的标准差归一, 没有用 Dr. GRPO 的修正); token 级 ratio 进解耦 clip, 批内有效 token 统一分母归约; 单轮 (或多 minibatch) 更新. 论文设置 $G$ 在 8 到 16 之间, $\epsilon_{high}=0.28$, $\epsilon_{low}=0.2$.

和 GRPO 的骨架差异至此全部列出: 采样端加过滤和补采, 损失端换 clip 边界和归约分母, reward 端加长度塑形, 正则端去掉 KL. 每个开关都独立, 这也是判断任一实现「是不是 DAPO」的清单: 四项缺一项, 就该改名.

这个「四项缺一即改名」的纪律, 对引用和对比都重要: 把「用了 Clip-Higher 的 GRPO」叫 DAPO, 等于把四项消融的结构信息抹掉, 后续读者的复现基线就歪了. 命名即契约, 尤其在 trick 密集的推理 RL 领域. 类似的命名漂移几乎每个季度都在发生, 养成核对「名字, 定义, 实现」三者的习惯, 比记住任何单项技术都保值.

**与开源实现的差异核对。**

verl 等框架的 DAPO 实现和论文配方之间存在已知差异, 复现时逐条核对. 标准差归一: 论文保留 GRPO 的组内 std 归一 (与 Dr. GRPO 的批评并存), 有些实现默认关掉, 这改变了优势尺度, 也改变了 Clip-Higher 生效区间的实际位置. 采样端: 论文是「补采到有效 batch 恒定」, 部分实现只做过滤不补采, 等效于动态 batch 大小, 学习率的实际含义不同. 长度塑形: 有的实现把惩罚加在 reward 上 (论文方式), 有的直接 mask 掉超长 token, 后者不改 reward 分布, 只改梯度覆盖, 效果不等价.

核对的方法沿用 1.3.1.1 节的五个开关拆分: advantage 怎么算, ratio 在 token 还是 sequence 级, clip 边界各是多少, 归约分母是什么, 采样怎么过滤和补. 把任意两个「DAPO 实现」的这五行对齐再比数字, 比争论谁的复现「更忠实」有效得多.

## 3. 实验, 边界与选型

### 3.1. 论文报告了什么

DAPO 在 Qwen2.5-32B 上报告 AIME 2024 达到 50 分, 超过同期的 DeepSeek-R1-Zero-Qwen-32B (47 分) 等开源复现, 且完整开源了代码和数据 (SIA 集). 方法层面可靠的结论是: 四项看似工程化的改动, 每一项都有独立消融支撑, 叠加后构成一个可复现的推理 RL 强基线; 推理 RL 的收益大头来自「把采样端和损失端的默认配置对准任务结构」, 而不是新算法. 论文的叙事重心在系统: 训练框架, 调度, 数据集全部公开, 这是它被大量复现的原因.

这组数字也要按口径读: AIME 是单任务竞赛数学, 50 分是在 32B 规模上的成绩, 不代表通用推理能力; 且对比的 R1-Zero-Qwen-32B 是社区复现而非 DeepSeek 官方 32B. 方法比较的公平性依赖「同基座, 同数据预算, 同评测协议」, 论文基本满足, 引用时保持这个限定即可.

**批评与边界。**

第一, 消融是在一个模型一个任务族上做的, 四项技术的相对贡献换个基座可能重排, Clip-Higher 的收益尤其依赖「熵是否真的在塌」——基座和采样温度不同, 熵动态不同. 第二, 去 KL 加动态过滤的组合让训练分布持续漂移, 论文对两端行为 (过易过难) 的约束方案语焉不详, 长训时这是风险点. 第三, token-level loss 和长度分桶的交互 (§4.2) 论文没有展开, 复现时这部分要自己补实验.

另一个未被充分讨论的点是四项技术的相互作用: 消融报告的是「从全有到全无」的单项贡献, 但 Clip-Higher 的收益部分来自动态采样改变了 ratio 分布, token-level loss 的收益部分来自长度塑形改变了长度分布——单项之和大于总收益是可能的. 全量配方作为基线没问题, 拆解归因时要留这个心眼.

**什么时候用哪一项。**

不必四项打包. 熵曲线在塌, 先上 Clip-Higher; 有效组占比低, 先上动态采样; 长度方差大且怀疑长度 bias, 换 token-level loss; 长链被硬截断误伤, 加长度塑形. 每项都可以单独嫁接到 GRPO 基建上, verl 等框架的开关式实现正是这么设计的. 反过来, 如果四项症状一个都没有, 保持 GRPO 原版, 别为升级而升级.

还有一个反向场景: 症状全有但只想验证一项时, 用「单项消融 + 固定其余三项」的结构, 而不是从 GRPO 只加这一项. 因为四项之间存在 §7.2 说的相互作用, 单项效果在三项齐全和三项缺席的上下文里不同; 想知道自己管线里哪项真正起效, 只能在自己的全量基线上做减法.

### 3.2. 实现

**教学实现。**

```python
import torch

def dapo_clip(ratio, advantages, eps_low=0.2, eps_high=0.28):
    # ratio, advantages: [batch, seq]，advantages 已广播到 token
    upper = torch.where(advantages > 0,
                        torch.full_like(ratio, 1 + eps_high),
                        torch.full_like(ratio, float('inf')))
    lower = torch.where(advantages < 0,
                        torch.full_like(ratio, 1 - eps_low),
                        torch.full_like(ratio, float('-inf')))
    clipped = ratio.clamp(lower, upper)
    return torch.min(ratio * advantages, clipped * advantages)

def dapo_loss(token_losses, mask):
    # token_losses: [batch, seq]（已含 -u_t），mask: 有效 token
    return -(token_losses * mask).sum() / mask.sum()
```

动态采样的过滤一行是 `group_rewards.max(dim=-1).values > group_rewards.min(dim=-1).values`, 配合外层补采循环. 长度塑形按 §5.1 的三段式实现, 注意惩罚作用在 reward 上 (进优势), 不要直接加在 loss 上——两者的梯度路径不同.

补采循环的骨架也值得写清: 它本质是「采样-过滤-再采样」的 rejection sampling, 在分布式 rollout 里要处理「部分 worker 已返回, 部分还在跑」的取消与合并; 最简单的正确实现是先全量采完再统一过滤, 代价是尾部延迟, 优化的空间在流水化而不在算法.

**验证清单。**

三个不变量. 第一, clip 退化: 设 $\epsilon_{high}=\epsilon_{low}=\epsilon$, DAPO 的 clip 应退化成标准 PPO 的 $\operatorname{clip}(r,1-\epsilon,1+\epsilon)$, 对随机 ratio 和优势向量逐点验证. 第二, 归约退化: 构造 batch 内所有回答等长的情形, token-level 与 response-level 两种归约应给出相同损失 (差常数因子 $B\cdot|y|/\sum|y_i|=1$). 第三, 过滤退化: 全同组 (全零, 全一, 全任意常数) 必须被过滤, 含一对差异的组必须保留, 覆盖 reward 编码的三种形态. 三条都能在合成张量上写成单测, 是这套实现的最小验收.

上线前再补一个集成级检查: 用固定种子跑 50 步, 对比 clip fraction 的左右侧触发比, 论文量级是正侧略多于负侧 (放宽上界的效果); 如果自己的实现负侧远多于正侧, 大概率是 clip 分支写反——这类 bug 不会报错, 损失还在降, 只是训练方向拧了.

同理, 归约不变量 (等长 batch 下两种分母等价) 能拦住「分母用错但大部分 batch 长度均匀」的隐蔽 bug——只有在刻意构造的极端长度差 batch 上才显形, 值得单独一个测试用例. 三个不变量加两个集成检查, 构成 DAPO 实现的最小验收套件, 全部不依赖训练就能跑.

---

**从 GRPO 目标到 DAPO 目标。**

**先固定比较对象。**

对 prompt $x$ 采样一组回答 $y_1,\ldots,y_G$，经验证器得到回报 $R_i$。GRPO 常用组内标准化优势

$$
A_i=\frac{R_i-\bar R}{s_R+\epsilon},\qquad
\bar R=\frac1G\sum_{j=1}^G R_j.
$$

旧策略生成 token，当前策略计算概率比

$$
r_{i,t}(\theta)=\frac{\pi_\theta(y_{i,t}\mid x,y_{i,<t})}
{\pi_{\text{old}}(y_{i,t}\mid x,y_{i,<t})}.
$$

标准 PPO 式 surrogate 为

$$
u_{i,t}=\min\left(r_{i,t}A_i,
\operatorname{clip}(r_{i,t},1-\epsilon,1+\epsilon)A_i\right).
$$

DAPO 没有换掉组相对优势这一核心，而是在样本进入损失前、概率比裁剪、token 归约和超长回报四个位置改动。因而比较时必须锁定行为策略、组大小、验证器、温度和 token 预算。若同时换数据与基础模型，曲线差异无法归到 DAPO 机制。

Dynamic sampling 作用于 prompt 与组的选择分布；clip-higher 作用于给定 token 的局部 surrogate；token-level loss 作用于样本聚合权重；overlong shaping 作用于回报定义。它们分别改变「看到什么」「一次更新允许走多远」「谁在 batch 里权重大」「什么行为得分高」。

这种分层解释了为何四项无法简单相加。长度塑形让超长失败减少，进而改变组内回报方差；动态采样据此保留不同 prompt；保留下来的长度分布又改变 token-level loss 的权重；策略变得更确定后，ratio 与熵分布继续改变 clip-higher 的命中率。消融需要同时报告中间统计量，最终 reward 一列不足以解释因果链。

**Clip-Higher 的完整推导。**

**正负优势为何对应不同边界。**

对 $A>0$，目标希望增大动作概率。未经裁剪的项 $rA$ 随 $r$ 上升，超过上界后被常数 $(1+\epsilon)A$ 截住；对 $A<0$，目标希望减小动作概率，当 $r<1-\epsilon$ 时，裁剪项阻止继续下降。标准 PPO 用同一个 $\epsilon$ 描述两侧距离。

DAPO 将上界改成 $1+\epsilon_{high}$，下界保持 $1-\epsilon_{low}$，且 $\epsilon_{high}>\epsilon_{low}$：

$$
u^{\text{DAPO}}=\min\left[rA,
\operatorname{clip}(r,1-\epsilon_{low},1+\epsilon_{high})A\right].
$$

分段写得更清楚。正优势时

$$
u^+(r)=
\begin{cases}
rA,&r\le 1+\epsilon_{high},\\
(1+\epsilon_{high})A,&r>1+\epsilon_{high},
\end{cases}
$$

负优势时

$$
u^-(r)=
\begin{cases}
(1-\epsilon_{low})A,&r<1-\epsilon_{low},\\
rA,&r\ge 1-\epsilon_{low}.
\end{cases}
$$

由于 $A<0$，取最小值的分支方向容易写反。单元测试应直接列出正负优势与高低 ratio 的四象限，而不是只检查平均 loss。

**熵坍缩为何与正侧裁剪有关。**

语言模型词表很大，某状态下被采到的正确 token 可能在旧策略中概率很低。它的 ratio 只需小幅绝对概率变化就能超过标准上界，随后正向梯度归零；高概率错误 token 的负优势更新仍可继续。大量状态重复这一不对称后，概率质量从许多低概率候选移走，却无法充分回流到新发现的正确候选，分布可能越来越尖。

放宽正侧上界给低概率正优势 token 更长的学习区间。例如旧概率 $0.01$，当前概率 $0.013$，ratio 为 $1.3$。$\epsilon=0.2$ 时它已经被裁剪，$\epsilon_{high}=0.28$ 时仍略超边界，$\epsilon_{high}=0.4$ 时保留梯度。这里决定更新的量是相对概率变化，并非绝对概率增加了多少。

clip-higher 也可能加速熵下降：若正优势集中在已经很高概率的单一模板，放宽上界会让模板获得更多概率。因此它的作用依赖优势与旧概率的联合分布。验收必须按旧概率分桶统计正优势 token 的上界命中率，同时画熵、top-1 概率和独特答案比例。只看到熵下降变慢，还不足以说明探索质量提高。

**裁剪带来的偏差与方差。**

importance sampling 在支持集覆盖且比率准确时可修正旧策略采样，但方差可能由极端 ratio 主导。裁剪用有偏换稳定：超过边界的样本不再按真实 ratio 增长。放宽上界减少正优势侧的裁剪偏差，同时允许更大的单样本梯度，方差和尾部风险上升。

可把正侧裁剪偏差写成

$$
B_+=\mathbb E\left[A(r-1-\epsilon_{high})
\mathbf 1\{A>0,r>1+\epsilon_{high}\}\right].
$$

$\epsilon_{high}$ 增大时该项通常减小，但二阶矩

$$
M_+=\mathbb E[(rA)^2\mathbf 1\{A>0,r\le1+\epsilon_{high}\}]
$$

可能增大。合理选择不能只追求低 clip fraction，而要比较有效梯度、梯度范数尾部、KL 增量和验证集收益。

**Clip-Higher 的手算反例。**

设两个 token 的优势分别为 $A_1=1,A_2=-1$，ratio 分别为 $1.25,0.75$。标准边界 $[0.8,1.2]$ 时，两项都进入平坦区，局部梯度为零；DAPO 边界 $[0.8,1.3]$ 时，正优势项恢复梯度，负优势项仍被限制。该例展示正侧解锁。

再令 $A_1=5$ 且它来自错误验证器，ratio 为 $1.29$。DAPO 会保留一条幅度约为标准设置所没有的错误梯度。若同一错误模式在多个 token 重复，放宽上界会放大奖励漏洞。clip-higher 依赖 reward 精度，不属于对所有训练崩溃都有效的保险丝。

## 4. Dynamic Sampling 的统计目标

### 4.1. 全同组为何没有组内梯度

若一组 reward 全为常数 $c$，则 $R_i-\bar R=0$，标准化优势全部为零。模型仍支付了 rollout 与验证成本，却不给组相对目标提供梯度。对二元 reward，单条成功率为 $p(x)$ 时，全同组概率为

$$
q_{flat}(x)=p(x)^G+[1-p(x)]^G.
$$

过易题的第一项占主导，过难题的第二项占主导。固定组大小下，最容易产生混合成败的 prompt 位于中等难度区域。

Dynamic sampling 持续采 prompt 和候选，过滤全同组，直到凑足预定数量的有效组。这样提升每个优化 batch 的非零优势密度，减少空转。它节省的是更新侧的无效 batch，并不保证减少总 rollout；当有效率很低时，为凑齐 batch 反而生成更多 token。

### 4.2. 条件分布与选择偏差

原 prompt 分布为 $p_0(x)$，有效事件记为 $E$。过滤后的训练分布满足

$$
p_{train}(x)=p_0(x\mid E)
=\frac{p_0(x)P(E\mid x)}{P(E)}.
$$

其中

$$
P(E\mid x)=1-p(x)^G-[1-p(x)]^G.
$$

该条件分布显式偏向当前策略成功率居中的题，与原分布目标存在选择偏差。能力变化后 $p(x)$ 改变，训练分布也随时间移动。课程效应可能贡献收益，同时意味着目标权重已经变化。

若想估计原分布目标，可以给有效组乘逆选择概率 $1/P(E\mid x)$。然而极易或极难题的选择概率接近零，权重爆炸，方差难以接受；而 $p(x)$ 还需估计。DAPO 选择条件训练而非严格逆概率修正，是稳定性与原目标之间的取舍。

**有效样本量与预算。**

设总共采了 $M$ 个 prompt 组，第 $m$ 组是否有效为 $I_m$，有效组数 $M_E=\sum_mI_m$。简单通过率为 $\hat q=M_E/M$。若各域通过率差异很大，还需按数据源、难度、语言和长度分桶；总通过率上升可能只是 sampler 转向了更容易产生差异的域。

同一 prompt 补采多轮会产生相关样本。若每轮共享模型版本和解码配置，组之间并非完全独立。以组梯度相关系数 $\rho$ 近似，有效样本量约为

$$
N_{eff}\approx\frac{N}{1+(N-1)\rho}.
$$

重复补采看似凑齐了数量，却可能只重复同一种模式。对失败 prompt 逐渐提高温度能增加差异，也会改变行为策略；对应 log-prob 必须使用实际温度分布计算。

**极难题消失的反例。**

设题域 A 占一半，单条成功率 $p_A=0.5$；题域 B 占一半，$p_B=0.001$；组大小为八。A 的有效概率约为 $0.992$，B 约为 $0.008$。过滤后，来自 B 的有效组只占约 $0.8\%$，远低于原始的一半。训练 reward 可能快速提升，因为主要在 A 上更新，B 的能力却停滞。

缓解方法包括为不同难度保留最低配额、给全失败组引入可靠的过程信号、使用更强初始化、或单独维护探索 batch。给全失败组强行制造排名不可取：验证器没有证据时，微小数值噪声会被标准化成完整优势。

**Token-Level Loss 的目标变化。**

**Response 平均与 Token 平均。**

设第 $i$ 条回答长度为 $T_i$，token surrogate 为 $u_{i,t}$。按回答平均的目标为

$$
L_{resp}=-\frac1B\sum_{i=1}^{B}\frac1{T_i}\sum_{t=1}^{T_i}u_{i,t},
$$

按 token 平均为

$$
L_{tok}=-\frac{1}{\sum_iT_i}\sum_{i=1}^{B}\sum_{t=1}^{T_i}u_{i,t}.
$$

前者每条回答总权重相同，单 token 权重为 $1/(BT_i)$；后者每个 token 权重相同，回答总权重为 $T_i/\sum_jT_j$。两者在所有回答等长时一致，长度不同便对应不同经验风险。

**长答案究竟被谁压低。**

组相对优势是序列级标量，广播到每个 token。response 平均会把同一个优势除以 $T_i$，因此长答案中每个决策得到更小权重。若关键推理需要许多连续动作，单步信号被稀释；token 平均取消这项长度倒数，使长轨迹按动作数量贡献。

这不意味着 token 平均天然无长度偏差。长答案拥有更多 token，整体权重更大；当冗余 token 与正确率相关时，它可能鼓励变长。DAPO 的 overlong shaping 与长度上限正是在回报层约束这种趋势。二者配合后，一个负责恢复长轨迹每步的学习强度，一个负责避免无限延长。

**两条轨迹的手算。**

一条回答长度十，另一条长度一百，二者每个 token 的 surrogate 均为一。$L_{resp}$ 中两条各贡献一，合计平均为一；$L_{tok}$ 仍为一，但参数梯度的样本组成不同：短回答十个 token 占 $9.1\%$，长回答一百个 token 占 $90.9\%$。若两条轨迹梯度方向相反，最终方向可能翻转。

令短回答每 token 梯度为 $+1$，长回答每 token 梯度为 $-0.2$。response 平均得到 $(1-0.2)/2=0.4$；token 平均得到 $(10-20)/110\approx-0.091$。损失标量相近并不保证更新方向相近。验收应直接比较参数梯度余弦，而非只比较两种 loss 数值。

**Batch 组成带来的波动。**

token 分母随 batch 总长度变化。同一条轨迹与一批短回答同训时权重大，与一批长回答同训时相对权重小。梯度累积跨 micro-batch 时，若每个 micro-batch 先除自己的 token 数再简单平均，会使小 micro-batch 获得过高权重。正确的全局 token 平均要先累加分子和有效 token 数，再做一次除法，分布式场景还要跨 worker 汇总分母。

padding、prompt token、工具返回与被截断尾部是否进入分母同样关键。DAPO 的生成 token 目标通常只统计 response 的有效 action token。把 prompt 或 padding 计入分母不会直接增加梯度，却会依长度结构缩放不同样本，形成隐蔽权重偏差。

**Overlong Reward Shaping 的连续边界。**

**硬截断为何污染学习信号。**

最大生成长度 $L_{max}$ 是系统约束。轨迹在边界处停止时，无法区分「模型本想继续并最终答对」与「模型已经陷入循环」。若所有截断回答直接得零分，接近完成的长推理与无意义重复被等同处理；若仍按可见前缀给过程分，模型又可能学会堆积局部得分而不完成答案。

DAPO 使用超长奖励塑形，在接近上限的缓冲区内平滑降低回报。设缓冲长度为 $L_{cache}$，起点 $L_s=L_{max}-L_{cache}$，可写成

$$
R_{len}(L)=
\begin{cases}
0,&L\le L_s,\\
-\lambda\dfrac{L-L_s}{L_{cache}},&L_s<L\le L_{max},\\
-\lambda,&L>L_{max}.
\end{cases}
$$

总回报为任务回报与该项之和。连续坡度避免长度刚越过某个点时 reward 突跳，但它仍属于人为定义的效用取舍。

**塑形如何进入组相对优势。**

长度惩罚先改变 $R_i$，再经组内中心化与标准化。它的绝对幅度并不会原样进入梯度：同组所有回答都位于相同长度区间且惩罚相近时，中心化后几乎消失；只有组内长度有差异时才形成相对信号。

例如两条都答错，任务回报均为零，长度分别位于缓冲区起点和上限，塑形回报为 $0$ 与 $-1$。组内标准化后短回答得到正优势，尽管它同样错误。模型学到的是「在失败答案之间偏好更短」，这可能减少空耗，也可能鼓励更早放弃。动态采样会保留这个原本全失败的组，因为塑形制造了差异，训练分布随之改变。

**正确长解被惩罚的反例。**

设短错误答案任务分为零、无长度罚；长正确答案任务分为一、长度罚为负一点二，总分负零点二。组相对排序把错误短答放在正确长答之上。问题不在优化器，而在 reward 标度。长度罚上限应低于关键任务奖励间隔，或采用正确性门控：通过任务验证后减弱长度罚，只惩罚可删冗余。

门控也有风险。若验证器存在假阳性，错误答案一旦误判正确便绕过长度约束，可能生成更长的奖励攻击。更稳妥的做法是同时报告任务分与塑形分，并对排序翻转比例设阈值。任何「正确性不同却被长度项反转」的样本都应单独抽检。

**截断是删失数据。**

统计上，达到 $L_{max}$ 的轨迹属于右删失：只知道其真实完成长度大于当前观察值。把观察长度直接当完整长度会低估长尾，把全部截断视为失败又把系统上限混入能力指标。评估应分别报告自然 EOS、工具终止、格式终止与上限截断率，并在更高上限的小样本复测中估计被截断轨迹的潜在成功率。

若提高 $L_{max}$ 后大量原截断轨迹很快正确结束，当前上限过紧；若继续长篇循环，塑形针对的确实是无效长尾。这个反事实实验比观察平均长度更能决定缓冲区位置。

## 5. 四项机制的相互作用

### 5.1. Dynamic sampling 与长度塑形

二元任务 reward 下，全失败组会被过滤。加入连续长度罚后，同样全失败的候选因长度不同产生非零方差，于是进入训练。Dynamic sampling 此时筛选的是「任务或长度存在差异」，而非「正确性存在差异」。若长短变化远比成败常见，优化 batch 可能主要学习长度。

验收时应分别计算只用任务 reward 的有效组率、加入塑形后的有效组率，以及新增有效组中任务结果全同的比例。第三项过高意味着动态采样预算被长度比较占据。可让有效事件要求任务 reward 有差异，长度塑形仍参与保留组的优势；也可为长度型有效组设置单独配额。

### 5.2. Token loss 与 Clip-Higher

长回答包含更多 ratio，token-level loss 提高其总体权重。若长回答中低概率正优势 token 较多，clip-higher 又为这些 token 解锁梯度，两项会乘法式增强长轨迹。反过来，长错误回答含大量负优势 token，下界裁剪可能让后半段大多进入平坦区，实际负向贡献未必随长度线性增长。

因此需要按序列位置统计正负优势的 clip fraction。只给全局比例会把「短答案正侧未裁剪」与「长答案后段全部裁剪」混在一起。长度分桶后的梯度范数和 KL 增量能直接检验两项是否造成长轨迹支配。

**去 KL 与放宽上界。**

显式 KL 惩罚会把偏离 reference 的 token 回报向下拉，抑制低概率新动作。移除 KL 后，clip 近端约束承担更多局部稳定作用；同时放宽正侧上界又允许受奖励动作走得更远。这套组合提高探索自由度，也把可靠性更多押在 on-policy 程度和 verifier 上。

clip 只约束 current 相对 old，连续多轮小步仍可远离最初的 SFT reference。每一步 ratio 都在边界内，不代表累计 KL 很小。即便训练目标不含 KL，也应离线监控 current 对固定 SFT reference 的 token KL、能力回归和输出风格漂移。发现累计漂移后，可降低 epoch、缩短 policy lag、收紧上界或恢复适量 KL。

**一张可证伪的交互矩阵。**

以四项开关构造分数实验虽有十六种组合，预算有限时至少保留 GRPO 基线、全量 DAPO、逐项删除四组和若干高风险二阶组合：dynamic sampling×长度塑形、token loss×clip-higher、去 KL×clip-higher。所有实验固定有效生成 token 预算，而非固定更新步数，因为动态采样改变每步所需 rollout。

每项假说都应能失败。clip-higher 的假说是恢复低概率正优势 token 的有效梯度；若这些 token 的命中率没下降且熵仍同速坍缩，机制未按预期工作。动态采样的假说是提高可学习组密度；若有效组增加但独立验证不升，新增信号可能来自塑形或噪声。token loss 的假说是缓解长轨迹逐 token 稀释；若长题梯度和成功率不变，瓶颈另有来源。长度塑形的假说是减少无效截断；若自然 EOS 不增、正确长解下降，它只是在压短输出。

**On-policy、旧策略与数据复用。**

**ratio 精确也不等于完全 on-policy。**

rollout 由 $\pi_{old}$ 生成，参数更新时使用 $\pi_\theta$，概率比负责修正二者差异。若同一批轨迹做多个 epoch，$\pi_\theta$ 持续变化，ratio 尾部逐渐变宽，裁剪样本比例上升。后几个 epoch 可能主要在平坦区计算，表面增加优化步，实际新增信号很少。

严格的 on-policy 更新会在每轮参数变化后重新采样，成本通常过高。DAPO 的工程现实仍是在有限 policy lag 下近似 on-policy。应记录轨迹的 producer checkpoint、生成温度、top-p、最大长度和工具版本，并用生成时保存的 old log-prob 计算 ratio。用更新后的模型重新计算所谓 old log-prob，会让 ratio 错误地接近一，裁剪监控失效。

温度也属于行为分布。若采样使用 $\pi^{1/\tau}/Z$，old log-prob 应对应这一温度后的分布。trainer 若拿未除温度的 logits 作分母，相当于对错误策略做 importance correction。温度越偏离一，误差越明显；动态补采若逐轮升温，还需要逐样本保存温度。

**Policy lag 与 Clip-Higher 的关系。**

放宽正侧上界允许更大的 current/old ratio，不会修复过旧数据。假设 producer 落后十个更新，正确 token 的 ratio 已到三，$1.28$ 与 $1.2$ 都会裁剪；错误 token 的 ratio 可能接近零，同样落在负侧平坦区。此时提高 $\epsilon_{high}$ 只改变少量边界附近样本，核心问题仍是更新与采样脱节。

可以按 lag 分桶报告 ratio 中位数、上下分位和双侧 clip fraction。若 lag 增加时验证收益单调下降，应限制队列深度或减少每批 epoch；若 ratio 仍集中在一附近但训练不稳，问题更可能来自 reward、归约或学习率。把所有异常都归因于 clip 参数会错过数据管线错误。

异步系统还会出现选择性延迟：长回答和复杂工具任务返回更慢，优化器先消费短轨迹。即使最终都纳入训练，早期更新的长度与难度分布已经偏移；等长轨迹到达时 producer 更旧。时间顺序同时制造长度偏差与 policy lag，需要比较按完成顺序消费和按 rollout 批次屏障聚合两种方案。

**多 epoch 更新的可证伪实验。**

固定同一批轨迹，从 epoch 一到 epoch 四逐次测量未裁剪目标、裁剪目标、有效 token 比例和与新鲜 rollout 的梯度余弦。若第三、四个 epoch 的有效 token 大幅下降，继续复用主要消耗算力；若梯度与新鲜数据方向转负，旧数据已经误导更新。

再做一个小规模严格 on-policy 对照：每一步只更新一次并立刻重采，保持总生成 token 一致。近似方案若取得相近外部能力且成本更低，数据复用合理；若训练 reward 高而外部能力落后，可能在反复拟合同批 verifier 偏好。

**KL、参考模型与累计漂移。**

**局部 ratio 约束不了长期距离。**

设每轮某 token 概率最多乘 $1+\epsilon$。经过 $n$ 轮后，累计倍率上界近似 $(1+\epsilon)^n$；即便每一步都满足局部裁剪，长期仍可离初始模型很远。裁剪约束 current 与相邻 old，固定 reference KL 衡量 current 与 SFT 锚点，两者回答不同问题。

DAPO 移除目标中的 KL 项，避免 KL 奖励与任务奖励纠缠，并减少对有益探索的压制。这不等于 KL 失去诊断价值。训练中至少保留 sampled KL、全分布近似 KL、reference 困惑度与若干通用能力集。若 task reward 上升同时固定 reference KL 激增，需判断是必要专业化、格式迁移还是能力遗忘。

**KL 估计器的差异。**

对 old 策略采样的 token，常见样本估计包括 $\log\pi_\theta-\log\pi_{ref}$，以及非负近似

$$
k_3=(r_{ref}-1)-\log r_{ref},\qquad
r_{ref}=\frac{\pi_{ref}}{\pi_\theta}.
$$

不同估计器方差与采样分布不同。只在当前生成 token 上估计 KL，会忽略未采词表区域；全词表 KL 更准确但计算昂贵。报告必须注明方向、采样策略和是否按 token 或序列平均，否则数值无法横向比较。

序列长度也影响 KL。token 平均 KL 反映每步偏移，序列求和 KL 反映整条轨迹累计偏移。模型生成变短时，序列 KL 可能下降，即便每 token 偏移上升；生成变长时相反。两者同时记录可避免把长度变化误判为策略更接近 reference。

**恢复 KL 的条件。**

若固定 reference 上的通用能力持续下降、输出出现单一模板、reward 攻击跨 checkpoint 累积，恢复小幅 KL 是合理干预。系数 $\beta$ 可通过目标 KL 自适应调整：观测 KL 高于目标便增大 $\beta$，低于目标便减小。更新速度需慢于策略变化，否则系数与策略相互追逐，形成振荡。

恢复 KL 后要重新评估 clip-higher。正优势 token 同时受到任务优势与负 KL shaping，净优势可能换符号；上界命中统计也随之改变。不能把无 KL 时选出的 $\epsilon_{high}$ 原封不动搬到含 KL 配方。

## 6. Reward 与验证器误差

### 6.1. 可验证不代表无噪声

数学答案可能受格式解析影响，代码任务受编译器、超时和隐藏测试影响，工具任务受环境状态影响。确定性程序也会因题面歧义、浮点容差或测试覆盖不足给错标签。DAPO 把更多训练压力集中到有组内差异的 prompt，恰好也可能集中到验证器边界案例。

应把 reward 拆成任务正确性、格式、过程、长度和环境状态，而不是只保存总分。对每个分量重复验证，估计同一轨迹的标签翻转率。组内分差小于重评分噪声时，标准化会把微小随机差放大，形成高方差伪监督。

**假阳性与假阴性的梯度方向。**

假阳性给错误轨迹正优势，clip-higher 允许它在更宽区间增加概率；token-level loss 又会按其 token 数累计影响。若错误轨迹较长，三项组合可迅速放大奖励漏洞。假阴性则压低真实正确轨迹，动态采样可能长期保留这个 prompt，因为模型反复产生被错判的差异。

二者危害并不对称。罕见假阳性可能成为组内唯一高分，标准化后获得很大正优势；大量同类假阴性有时让整组全失败，反而被过滤。抽检策略应优先看「组内唯一成功」「reward 突然跃升」「高优势且高 ratio」的轨迹。

**Reward hacking 的对抗集。**

为每种 verifier 构造最小对抗集：答案正确但格式变化、答案错误但包含目标字符串、代码通过公开样例却失败于边界、推理过程漂亮但结论错误、工具返回被模型伪造、超时前输出部分正确。每次 reward 或解析器升级都跑回归。

训练中保留一个不参与 reward 的独立验证器或人工小样本。若训练 verifier 分数上升而独立指标停滞，优先怀疑适配评分器。两个验证器共享同一规则或模型时，相关错误仍会穿透，因此独立性来自不同证据来源，而不只是换一个随机种子。

**Reward 版本也是实验变量。**

修改正则表达式、测试用例或过程模型都会改变目标。每条 rollout 应绑定 verifier 版本；旧轨迹若用新 verifier 重打分，得到的是新目标下的离线样本，需要重新考虑选择分布。混用版本会让同样答案在同组内因时间不同得分不同。

可在版本切换点同时运行新旧 verifier，统计混淆矩阵和排序翻转率。若翻转集中在某类任务，后续曲线需分段解释。把 reward 版本变化当作普通代码修复，会让能力跃升与评分变松混为一谈。

### 6.2. 统计估计与实验设计

### 6.3. Prompt 级统计与公平预算

同一回答的 token 共享序列优势，同一 prompt 的多条回答共享组均值，token 和轨迹都存在强相关。把数百万 token 当独立样本计算置信区间会严重低估不确定性。评估至少以 prompt 为聚类单位，重复训练还要以随机种子为更高层单位。

对固定测试集，可先在每个 prompt 内计算方法差异 $d_m$，再对 prompt 做 bootstrap。若题目来自多个数据源，采用分层 bootstrap 保持领域比例。训练曲线的多个 checkpoint 也相关，挑最高点报告会产生选择偏差；预先规定步数或报告曲线下面积更稳妥。

**固定更新步数为何不公平。**

Dynamic sampling 为凑有效组会额外生成，token-level loss 又使每步有效 token 数随长度变化。固定优化步数可能让 DAPO 消耗更多 rollout；固定 wall-clock 又会混入系统吞吐差异。至少同时给出生成 token、验证次数、更新 token、GPU 时和墙钟时间。

公平比较可以选固定总生成 token，观察谁把预算转成更多能力；也可选固定有效更新 token，观察样本质量，但此时动态采样的额外成本必须单列。两种问题都值得回答，不能只选对自己有利的分母。

### 6.4. 消融交互与联合监控

四个二元开关构成析因设计。以结果 $Y$ 表示，可拟合

$$
Y=\beta_0+\sum_j\beta_jz_j+
\sum_{j<k}\beta_{jk}z_jz_k+\varepsilon.
$$

$\beta_j$ 描述在编码中心附近的主效应，$\beta_{jk}$ 描述两项协同或抵消。只做「全量减一项」得到的是特定上下文中的边际效应，无法推出单项独立收益。预算有限时，高风险交互应优先保留，而不是平均删减所有组合。

多种子方差可能大于消融差异。此时诚实结论是当前预算无法区分，而不是挑最好种子。可以使用共同初始化与共同 prompt 流降低配对方差，但 rollout 随策略变化后无法保持完全相同；记录首次分叉点有助于解释后续差异。

**监控量的联合判读。**

训练 reward、外部正确率、自然 EOS、截断率、平均长度、熵、reference KL、正负 clip fraction、有效组率和 verifier 翻转率应放在同一时间轴。单指标上升可能由其他指标恶化换来。

例如 reward 上升、长度下降、截断率下降看似理想；若自然 EOS 没增加而错误短答变多，模型只是更早放弃。又如熵稳定、独特答案数下降，可能是 token 熵由无关措辞支撑，语义探索仍在收缩。联合判读要求指标与具体假说对应。

### 6.5. 从单元反例到训练验收

**数学层不变量。**

裁剪测试覆盖 $A$ 正负零与 ratio 位于下界内外、上界内外，比较解析值和自动微分。令 $\epsilon_{high}=\epsilon_{low}$ 时结果退化到对称 PPO；令 ratio 为一时 surrogate 等于优势。边界点左右各取一个很小扰动，检查函数连续且梯度按预期切换。

组优势测试覆盖常数平移、正数缩放、候选置换、全同组、单成功与单失败。未标准化中心优势之和应为零；标准化后均值接近零、方差依定义接近一。过滤或环境失败改变组大小后，均值与分母必须按实际有效候选重算。

token 归约测试构造等长与极端不等长回答。等长时两种归约一致；不等长且梯度方向相反时，应复现解析反转。跨 micro-batch 拆分与合并得到相同全局 token 平均，验证分布式分母无误。

**数据层反例。**

准备六类合成组：全对、全错、一对多错、一错多对、任务同分但长度不同、任务异分且长度排序相反。分别通过 dynamic sampling 和 reward shaping，记录保留原因与最终优势。这样能直接看出过滤到底由正确性还是长度触发。

再加入验证器翻转：把唯一成功改成假阳性，观察优势、clip 与梯度如何放大；重复评分后撤销标签，确认系统能隔离污染数据。若错误轨迹已经参与更新，回滚需要模型与优化器状态一起恢复，单独删数据无法撤销历史梯度。

**小模型机制实验。**

在可枚举动作的小环境中精确计算期望回报和真实 policy gradient，再分别加入组标准化、动态过滤、非对称裁剪、token 权重与长度罚。Monte Carlo 平均应收敛到各自重新定义后的目标梯度。该实验能区分代码错误与算法固有偏差。

用两个难度域验证动态采样的课程偏移，解析计算过滤后域比例并与采样频率比较。用两个长度动作验证 token loss 的方向反转。用含错误 verifier 的环境验证 clip-higher 是否更快放大奖励攻击。每项都有已知答案，远比直接在大模型曲线上猜原因可靠。

**训练级停止条件。**

训练前规定安全边界：固定 reference KL 上限、关键能力最大回退、截断率、reward 翻转率、梯度范数尾部和连续若干步的有效组下限。越界后暂停生成新数据，保留 producer、current、reference、verifier 与 optimizer 的完整版本。

回滚点不能只看 reward 峰值。最佳 checkpoint 应在独立能力、风险、成本与长度约束共同满足时选择。若不同指标峰值错开，说明训练沿 Pareto 前沿移动，需要明确产品取舍，而非用一个加权总分掩盖。

### 6.6. 可证伪结论与适用边界

声称 clip-higher 缓解熵坍缩，需要证明低概率正优势 token 的有效更新比例提高，语义多样性与外部能力同步保持；声称 dynamic sampling 提高效率，需要在相同生成预算下取得更多可靠梯度和更高外部收益；声称 token loss 修复长度偏差，需要长短任务的梯度与成功率变化符合预测；声称 overlong shaping 减少无效长尾，需要自然结束增加且正确长解不受显著伤害。

任何一条若只在训练 reward 上成立，就仍可能由评分器、样本组成或长度重加权解释。DAPO 的价值在于把几处具体失败模式变成可操作机制；它也因此适合接受逐项反证，而不应被当作一个无法拆开的配方名称。

**概率质量的变化。** 单个 sampled token 的概率上升时，词表中其他 token 的概率总和必然下降，但策略梯度只观察被采动作。设某状态只有三个动作，旧概率为 $(0.8,0.15,0.05)$，后两个动作都能得到正回报，却因采样频率不同，第二个动作更常获得更新。若一次更新后概率变成 $(0.75,0.18,0.07)$，两个正动作的 ratio 分别为 $1.2$ 与 $1.4$。标准上界 $1.2$ 同时卡住后续增长，DAPO 上界 $1.28$ 只给第二个动作留下有限余量，最稀有的第三个动作仍处于裁剪区。clip-higher 对不同尾部动作的影响取决于更新步长和初始概率。

继续把上界放到 $1.5$，第三个动作重新获得梯度，但总概率质量只能从第一个动作流出。若第一个动作其实也是正确的常用解法，模型会用稳定路径换取罕见路径，多样性上升却可能降低平均成功率。理想监控同时区分「正确模式之间的概率搬运」与「错误模式流向正确模式」。可将答案按语义或执行轨迹聚类，统计各簇成功率和概率份额；token 熵无法完成这种归因。

非对称边界还会与优势大小共同决定参数步。PPO surrogate 在未裁剪区对 ratio 的导数为 $A$，大优势样本依然占主导。组内标准化使优势尺度大致统一，却在组方差很小时容易产生大值。若一个组 reward 为 $(1,1,1,0.99)$，标准差很小，微弱差异经归一化后可接近普通成败差异。放宽上界会让这个可能由浮点误差产生的正信号走得更远。因此 clip-higher 的前置条件包含可靠的 advantage 尺度，而不只是合适的 ratio。

**全同组的三种含义。** 全对组说明当前 reward 在该 prompt 上饱和，未必说明答案完全等价；可以保留作能力回归与多样性评估，却无需进入组相对更新。全错组可能代表任务过难、验证器过严、探索不足或环境故障，这四种原因需要不同处理。reward 相同但过程不同的组则说明评分粒度不足。Dynamic sampling 把它们统一过滤有利于吞吐，但诊断日志应保留原因分类。

环境故障尤其容易被误认为全错。若代码沙箱宕机，一批 prompt 的所有候选同时得零，过滤会让训练继续运行，主曲线甚至不会突然下降，因为故障组没有进入更新。有效组率会下降，补采量和延迟会上升。把全同率按 verifier 状态拆分，并对异常同步失败设置告警，才能避免 dynamic sampling 掩盖基础设施故障。

全对组也可揭示数据污染。某批高难题突然全部答对，若答案模板高度一致或模型在题面中见过泄漏线索，过滤只会安静丢弃。训练效率看似提高，评估集却可能被污染。保存少量全对组进行去重和记忆检测，是使用过滤机制后必要的旁路审计。

有效组的定义若使用浮点 `max > min`，极小数值抖动也会保留。应以任务语义设容差或离散结果：代码通过数、最终答案等值、工具状态成功。连续 reward model 可用重复评分方差确定阈值。阈值改变选择概率，必须作为配方参数版本化。

**补采停止规则。** 假设目标需要 $B$ 个有效组，每轮采 $n$ 组，经验有效率为 $q$，期望轮数约为 $B/(nq)$。当 $q$ 很低时，尾部等待可能无限增长。系统需要最大补采轮数或总 token 上限；达到上限后可缩小 batch、切换数据桶或暂停更新。直接用不足 batch 继续训练，会改变有效 batch size 和优化器噪声。

补采过程中用当前观测估计 $q$，可以给剩余成本置信区间。若连续多轮零有效组，简单点估计为零，适合采用 Beta-Binomial 平滑。设先验 $q\sim\operatorname{Beta}(a,b)$，观察 $s$ 个有效、$f$ 个无效后，后验均值为 $(a+s)/(a+b+s+f)$。它不会让算法凭空获得信号，却能避免调度器在小样本下剧烈摆动。

多数据桶共享 batch 时，可按各桶有效率与目标权重分配候选预算。只按有效率最大化吞吐，会不断选择中等难度桶；加入最低覆盖约束能保住极难域。日志记录「原始抽样权重、尝试组数、有效组数、最终更新权重」，四列合起来才能重建实际课程。

**Token loss 的梯度尺度。** 假设每 token 梯度独立且方差为 $\sigma^2$。一条长度 $T$ 的回答在 response 平均下，均值梯度方差约为 $\sigma^2/T$；在未除序列长度的求和下，方差约为 $T\sigma^2$。实际 token 梯度正相关，方差下降或增长会更快。token-level 全局平均把多条轨迹混合，整体方差取决于长度分布与相关结构。

这解释了为何切换归约后通常还要重新调学习率和 clipping。若长轨迹占多数，token loss 的原始梯度范数可能变化；沿用原学习率后看到收益或崩溃，无法单独归因于长度权重。应先在相同 batch 上测两种损失的梯度范数分布，可用常数缩放对齐中位数，再比较训练方向与外部效果。常数缩放不消除样本权重差异，但能隔离纯粹的步长效应。

优势广播还涉及停止梯度。组均值和标准差由 reward 计算，通常不对策略求导；若 reward model 与策略共享参数或使用可微分软奖励，意外保留计算图会出现额外路径，目标不再是 policy gradient。验收可检查 advantage 张量不含梯度，并验证冻结 reward 后结果完全一致。

工具调用轨迹的 token 定义更复杂。模型 action token、工具返回 token、系统注入文本和观察 token 可能混在序列里。策略只能对自己采样的 action 求 score gradient，工具输出不应进入 surrogate 分子；它们是否进入长度罚则取决于成本目标。若工具返回很长，把其 token 计入 loss 分母会稀释模型动作梯度，把其计入 overlong 惩罚又可能惩罚不可控环境。

多轮轨迹还需要明确 credit 范围。终局 reward 广播到所有模型动作时，早期正确工具选择和后期格式失误共享同一优势。DAPO 的 token 归约没有解决时间信用分配，只改变各动作的总体权重。拥有中间可验证状态时可构造 reward-to-go；没有可靠过程信号时，序列优势虽粗糙，却比伪造精细标签更可控。

**长度塑形的尺度手算。** 设任务 reward 为答对一分、答错零分，长度缓冲从八千到一万 token，罚幅为负一。九千 token 的正确回答总分为零点五；七千 token 的错误回答为零。前者仍排在后者之上。若正确回答达到一万 token，总分归零，两者在组内没有差异；超过上限若仍为负一，则错误短答反而获正优势。这个边界清楚表明罚幅等于任务分差时会发生排序退化。

将罚幅降到负零点二能减少翻转，却可能不足以抑制循环。更细的做法依据自然结束概率与任务正确性分层：对已经可验证正确的答案，后续冗余 token 给边际惩罚；对尚未形成最终答案的轨迹，保留完成空间；对重复循环，使用重复检测单独终止。长度只是症状，重复、迟迟不提交和必要长推理的机制并不相同。

塑形函数在缓冲起点连续，但导数发生跳变。reward 不直接对长度求可微梯度，策略通过采样估计感受到的是跨轨迹分差，因此数学导数是否光滑影响有限；真正重要的是相邻长度的期望回报变化不能大于 verifier 噪声或任务分差。用更复杂的二次曲线未必更好，关键在其排序与阈值行为。

长度上限改变时，缓冲区用绝对 token 还是比例也会产生差别。固定两千 token 缓冲在八千上限占四分之一，在三万二上限只占十六分之一；固定百分比又会让长上下文任务受到更宽惩罚区。可以依据历史完成长度分位数设起点，例如从自然正确答案的九十五分位之后开始，随后用更高上限复测被罚样本。

Tokenizer 更新同样改变长度。相同文本在不同 tokenizer 下 token 数不同，若 reward 直接按 token 塑形，模型版本比较掺入分词效率。跨 tokenizer 对照可同时报告字符、词、模型 token 与实际推理成本；训练仍按实际 token 计费，但能力解释不能忽略表示变化。

**On-policy 的支持集。** importance ratio 的修正范围限于 old 策略具有正概率的动作。softmax 理论上覆盖整个词表，数值截断、top-k、top-p 或语法约束却会把一部分动作概率设为零。current 若要增加这些动作，旧数据中缺少相应样本，clip-higher 也无法提供梯度。sampler 支持集因此构成探索的外层限制。

若 dynamic sampling 对困难组提高温度或放宽 top-p，支持集发生改变。不同采样配置生成的轨迹可共同训练，但 old log-prob 必须基于各自实际分布；同时要防止高温轨迹主导异常行为。按 sampler 配置分桶比较 reward、ratio 和梯度，可以判断探索收益是否来自新增有效模式。

拒绝采样也改变最终行为分布。生成候选后因格式、长度或安全规则丢弃，再将剩余轨迹当普通 on-policy 数据，实际条件分布为 $\pi_{old}(y\mid y\in S)$。若 old log-prob 仍用未条件化的 $\pi_{old}(y)$，缺少归一化常数。该常数对同一 prompt 可能抵消部分 baseline，却会随策略和规则变化。最清楚的做法是把硬规则纳入生成过程，或承认训练使用经过选择的分布并用实验验证偏差。

**梯度冲突与任务覆盖。** 不同 prompt 的 DAPO 梯度可能相互抵消。某类题奖励简短直接，另一类题需要长链推导；token loss 与长度塑形对二者作用相反。总 reward 上升不能保证两个领域都改善。按领域计算梯度余弦，长期负相关提示共享参数中的取舍。

可采用分层 batch 保持任务比例，或在冲突严重时调整权重。梯度手术会引入新的优化目标，需与简单数据重加权对照。这里关注 DAPO 四项在多任务环境中的适用条件，不额外扩展训练配方。

罕见语言和长尾格式尤其容易被 dynamic sampling 稀释。若基础模型对它们几乎全错，组全部失败后消失；等主流语言能力提高，全对组也消失，训练最终聚焦少数中间区域。最低覆盖配额与独立评估能防止这种自适应课程把产品需求遗忘。

**完整手算批次。** 设两个 prompt，每组两条。第一组 reward 为 $(1,0)$，长度为 $(4,2)$；第二组 reward 为 $(1,1)$，长度为 $(3,3)$。组中心优势第一组为 $(0.5,-0.5)$，第二组为 $(0,0)$。Dynamic sampling 丢弃第二组，只留下第一组。若标准化到单位方差，优势变为 $(1,-1)$。

第一条四个 token 的 ratio 为 $(1.1,1.25,1.3,0.9)$，第二条两个 token 的 ratio 为 $(0.9,0.7)$。标准边界 $[0.8,1.2]$ 下，正轨迹第二、第三 token 被裁剪；DAPO 上界 $1.28$ 时第二 token 恢复、第三仍裁剪。负轨迹中 ratio 0.7 的 token 被下界裁剪。忽略常数，DAPO 有效 surrogate 总和为正轨迹 $1.1+1.25+1.28+0.9=4.53$，负轨迹为 $-0.9-0.8=-1.7$。

response 平均先得到正轨迹 $1.1325$、负轨迹 $-0.85$，再等权平均；token 平均则以六个 token 统一除法，总和为 $2.83/6$。二者数值分别约为 $0.141$ 与 $0.472$，梯度还会因各 token 方向而异。若第一条长度达到惩罚区使 reward 从一降到负零点二，它与第二条的排序翻转，整套更新方向随之翻转。这个小批次把过滤、裁剪、归约和塑形的先后顺序串在了一起。

实现应保存每个阶段的中间量：原始任务分、长度分、总分、组均值与标准差、优势、old/current log-prob、ratio、裁剪分支、有效 action mask、分子和分母。随机抽一组即可人工复算。只保存最终 loss，会让同一个异常在四个环节之间来回猜测。

过程表按步记录尝试组、有效组、全对、全错、环境失败、补采 token、自然 EOS、截断、长度分位、reward 分量、优势尺度、上下 clip fraction、ratio 分位、熵、reference KL、梯度范数和有效学习率。分桶维度至少包括任务域、难度、语言和长度。

结果表同时报告训练分布与固定外部集。固定集给 prompt 聚类置信区间和多种子结果，训练分布给实际课程变化。能力指标之外列出生成成本、验证成本、wall-clock 与失败重试。这样才能判断 DAPO 是用同样预算学得更多，还是投入更多 rollout 换得更高分。

失败档案保留反例原文与完整轨迹，覆盖唯一假阳性、正确长解被反转、全失败难题消失、环境故障被过滤、旧策略过期、token mask 错位、reference 漂移和多任务退化。每类至少有一个可重复输入和预期行为。随着实现修改，这些案例成为回归集。

最终验收不要求所有指标同时创纪录，而要求每项机制兑现自己的局部承诺，且代价透明。Clip-Higher 应减少可靠正优势的过早截断；dynamic sampling 应提高可靠非零组密度并报告分布移动；token loss 应给动作一致权重并呈现长度取舍；overlong shaping 应降低无效长尾而保住必要推理。四条分别通过后，全量配方的收益才具有可解释性。

**超参数敏感性需要沿机制坐标展开。** $\epsilon_{high}$ 至少覆盖对称值、论文配方附近和更宽上界，观察正侧 clip fraction 是否按预期下降。若 fraction 几乎不变，ratio 分布没有落在被修改的区间，最终分数差异多半来自随机波动；若 fraction 大降而 KL 与梯度尾部暴涨，上界已经放得太宽。$\epsilon_{low}$ 保持不变能隔离正侧效应，再单独扫描下界检验负优势更新。

组大小 $G$ 同时影响有效组概率、优势标准差和 rollout 成本。二元 reward 下可先用观测成功率预测全同率，再与实测比较。实测显著更高可能意味着候选相关、解码多样性不足或 reward 量化；显著更低可能来自长度塑形等连续分量。固定总 token 扫描 $G$，才能区分大组收益与额外预算。

Dynamic sampling 的最大补采次数决定课程强度。上限很低时，batch 中仍可能出现不足有效组；上限很高时，中间难度样本被反复搜寻，吞吐下降且原分布偏移更强。画出补采轮数的生存曲线：横轴为轮数，纵轴为尚未凑齐 batch 的比例。长尾由哪些数据桶贡献，可直接指导配额和过程奖励改进。

长度缓冲起点、惩罚幅度与最大长度构成三维参数。任务 reward 标尺给出不会翻转正确与错误排序的幅度范围，自然完成长度分布帮助确定缓冲起点，提高最大长度的删失复测则检验截断轨迹。三者一起盲扫可能找到高分组合，却难以说明模型变短源于合理约束还是推理被截断。

**解码策略会改变四项机制看到的数据。** 降低温度使候选更相似，全同组增加，dynamic sampling 补采更频繁；提高温度增加组内差异，也增加低质量长尾与极端 ratio。top-p 缩小支持集可能提高短期正确率，却让罕见正确路径难以出现。固定训练算法时扫描解码参数，能判断瓶颈位于探索还是优化。

组内候选若使用不同温度，reward 差异与采样分布绑定。高温候选可能更长、更有创造性，也更容易失败。直接组内标准化会让策略学习温度诱导的差异；importance ratio 只能修正动作概率，无法消除「哪个候选位置使用哪个温度」带来的设计效应。最简单的实验仍让同组共享配置，把跨配置比较放到不同组或不同 batch。

确定性解码不适合组相对训练：相同 prompt 往往生成完全相同答案，优势归零。即使通过 dropout 或分布式非确定性产生微小差异，也缺乏清晰行为策略。DAPO 需要可记录概率的随机采样，温度与过滤规则共同构成数据生成过程。

**熵指标也要拆开。** token entropy 对每个状态的词表分布求熵，sample entropy 观察实际采样频率，答案簇熵衡量语义路径多样性。模型可以在措辞 token 上保持高熵，同时所有答案遵循同一错误思路；也可以 token 熵下降，但正确解法簇增多。Clip-Higher 的机制直接作用于 token ratio，最终希望保留的却常是答案级探索，两层都要测。

按 token 位置画熵能发现前缀锁定。若开头几个推理 token 很快坍缩，后续即使保持高熵也只在同一路径内变化。低概率正优势 token 的解锁是否发生在早期决策点，决定其对语义多样性的贡献。可以通过干预早期 token 后重新采样，测量答案簇变化。

**模型容量决定同一梯度的外溢范围。** 小模型参数共享更紧，一类任务的更新容易影响其他能力；大模型可能用局部子空间吸收。因而同样的 reference KL 不代表同样的遗忘。外部能力回归、参数更新范数和表示变化应结合模型规模解释，不能直接从一个基座外推。

全参数训练与低秩适配也会改变 clip-higher 的作用。低秩子空间可能无法独立提高目标 token 而不扰动其他 token，ratio 分布呈现更强联动；全参数更新自由度高，但优化状态和通信成本更大。比较算法时保持参数化方式一致，或把它列为独立因素。

**从训练指标到能力判断还差一道泛化测试。** Dynamic sampling 会反复关注当前边界题，容易记住相似模板。固定 held-out 集需要在题面、答案形式和推理结构上去重；简单字符串去重抓不到同模板改数字。可按生成程序、来源文档或语义簇切分，避免有效组密度提升被模板记忆解释。

过程能力的迁移也值得单测。若数学训练后只在同类判题器上提升，换表达格式便下降，模型可能适配 verifier；若未见领域的多步计划也改善，才更支持推理策略迁移。DAPO 只规定优化方式，不保证奖励所教能力具有普适性。

**最终的停止判断采用趋势而非单点。** 连续多个评估窗口中，外部能力边际收益接近零，而 reference KL、生成长度或验证成本继续增长，说明当前配方已越过高收益区。此时继续训练可能只优化细小 reward 偏好。预先定义窗口长度和最小改进幅度，避免看到波动后临时挑选停止点。

若有效组率持续下降，需要分清全对增加还是全错增加。前者可能表示课程已学会，应补充更难数据；后者表示策略退化、数据变难或环境故障。相同的总有效率曲线对应相反动作，因此停止条件必须带全对与全错分解。

完整复现最终应能回答五个问题：数据为什么被选中，reward 为什么给出该排序，每个 token 为什么仍有或已经失去梯度，batch 为什么以当前权重聚合，模型为什么在这个 checkpoint 停止。DAPO 的四项改动恰好分布在这五个问题中。任何环节缺少中间记录，最终得分即使很高，也难以判断下一次换模型、换任务后该保留哪一项。

此外，复现实验应保存未进入训练的候选摘要。被过滤数据决定了训练分布的缺口；只有保留全对、全错、环境失败和超长轨迹的计数及小样本，才能在能力变化后解释课程为何转移。为了节省存储，可以保存分桶统计与经过脱敏的代表轨迹，但不能只留下最终有效 batch。训练数据的缺席同样是一种选择证据。

当外部指标出现回退时，这份记录允许沿顺序定位：检查数据桶占比是否移动，检查 reward 排序是否翻转，检查 ratio 与裁剪是否改变有效梯度，检查 token 分母是否被长度构成拉动，再检查累计 KL 与优化器状态。各层统计都稳定时，才把差异归到随机性或模型容量。这样的定位链比继续添加稳定化开关更节省实验预算。

DAPO 的几个开关应分开做消融, 因为它们作用在不同统计量上. dynamic sampling 改变进入更新的 prompt 分布, token-level loss 改变长短回答的权重, asymmetric clipping 改变概率比率的可行区间. 三者同时打开后只看最终奖励, 无法判断收益来自更有信息量的数据, 还是来自不同的梯度加权. 最小实验矩阵应保留共同随机种子和相同有效 token 预算, 逐次只切换一个开关, 同时报告被丢弃 prompt 比例、回答长度分位数与上下 clip 命中率.

动态采样还会造成训练分布随能力变化. 某类题一旦全部答对或全部答错便可能被过滤, 后续梯度转向剩余难度区间. 因此 checkpoint 比较要保留每步实际训练的难度直方图; 否则奖励上升可能部分来自样本组成变化, 不能全部归因于策略改善.
