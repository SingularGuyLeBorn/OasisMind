## 1. 动机: 训练目标和生成目标的一致性

### 1.1 一个观察

SimPO 的出发点是一个具体的不一致. DPO 训练时优化的隐式 reward 是 $\beta\log\frac{\pi_\theta(y|x)}{\pi_{ref}(y|x)}$, 而生成时 (无论是贪心解码, 采样, 还是 best-of-n 选择) 用来比较候选回复的量是 $\log\pi_\theta(y|x)$ 本身, 或者是它的长度归一化版本. 训练信号和部署时的选择信号不是同一个函数, 这是 DPO 设计里被默认接受的一个裂缝. SimPO 的作者问: 能不能让训练时的偏好 reward 直接就是生成时会用的那个分数?

答案是肯定的, 代价是放弃参考模型提供的基线. DPO 的 reward 有两项: $\log\pi_\theta(y|x)$ 推高当前模型的生成概率, $-\log\pi_{ref}(y|x)$ 提供一个「参考模型觉得这条回复值多少分」的基准, 两项相减构成相对量. SimPO 把基准项删掉, 只留第一项, 并补上长度归一化和一个显式 margin. 删掉的代价和补偿方式, 就是这篇论文的全部技术内容.

删基准项有一个直接的理论疑问: DPO 的参考模型不只是省显存的对象, 它还承担防作弊功能. 只优化 $\log\pi_\theta$ 的差, 模型可以通过同时压低两条回复的绝对分数来操纵差值 (例如把 rejected 的分数压到极低, chosen 不动, 差值照样变大). DPO 的参考项把这类「绝对尺度漂移」变成要付出 KL 代价的行为. SimPO 没有这层约束, 它的回答是: 长度归一化已经把最常用的尺度操纵通道 (长度) 堵住了, 剩余的尺度漂移靠训练时长和 early stopping 控制. 这个回答是否充分, 社区至今有分歧, 6.2 节的短回复倾向就是这个分歧的实证侧面.

「省一个参考模型」在 ORPO 一节 (1.2.4) 已经拆过一遍: 显存上约占训练常驻的一成上下 (取决于配置), 计算上省一组前向. SimPO 与 ORPO 在这个问题上立场相同, 不再重复. SimPO 真正的新主张不在「省」, 而在「一致」: reference-free 之后, reward 函数和生成时的候选比较函数是同一个东西, 训练就是在直接优化生成时会做出的选择. 这个论点后来被称为 alignment by generation, 后续有工作把 best-of-n 采样的选择函数也纳入同一框架分析.

### 1.2 时间线位置与本章结构

2024 年上半年是偏好优化方法密集出现的半年. 1 月 KTO 换掉成对信号, 3 月 ORPO 砍掉参考模型和 SFT 阶段, 5 月 SimPO 在 ORPO 的基础上再砍一步: odds ratio 也不要了, 用裸的长度归一化 log 概率加 margin. 每一步都在问同一个问题: 排序信号里哪些成分是真正必需的. SimPO 给出的答案是迄今为止最激进的: 只需要当前模型的平均 token 分数和一个常数间隔.

后面的推导按「奖励构造 → margin → 损失与梯度 → 超参 → 边界」的顺序展开. §2 把长度归一化奖励讲透, 包括它和 ORPO 的 odds 变换在排序上的定量差别. §3 专门分析 margin, 它是 SimPO 区别于「DPO 去掉参考模型」这种朴素变体的唯一结构件. §4 给出完整梯度和两组数值手算. §5 是超参与训练实践, 重点回答为什么不能搬 DPO 的超参. §6 收束到实验边界, 包括短回复倾向这个最重要的已知批评.

## 2. 奖励构造: 长度归一化的 log 概率

### 2.1 定义

SimPO 直接定义 reward 为序列的平均 log probability:

$$
r_{SimPO}(x, y) = \frac{\beta}{|y|} \log \pi_\theta(y|x) = \frac{\beta}{|y|} \sum_{t=1}^{|y|} \log \pi_\theta(y_t | y_{<t}, x).

$$

$\beta$ 是缩放系数, $|y|$ 是回复的 token 数. 求和只对 response tokens 进行, 与 DPO/ORPO 的约定一致. 这个 reward 取值恒为负 (每个 $\log\pi$ 都是负数), 它没有概率含义, 也不需要: 偏好损失只消费两个 reward 的差.

### 2.2 为什么必须除以长度

序列总 log 概率 $\sum_t\log\pi_\theta(y_t|y_{<t})$ 随长度线性累积负值. 两条平均 token 质量完全相同的回复, 长的那条总分一定更低. 如果直接用总分构造偏好信号, 模型学到的是「短的赢」而不是「好的赢」. 偏好标注数据里 chosen 通常比 rejected 长, 不消除长度通道, 损失就会被长度差主导, 这就是 length exploitation: 模型通过控制长度而不是内容来改变排序. 除以 $|y|$ 后 reward 变成「平均每个 token 的 log 概率」, 长度不同的回复在同一尺度上比较. 这个归一化在 ORPO 里已经出现 (几何平均分数取对数后正是平均 log 概率), SimPO 把它从 odds 的内部抽出来单独使用, 去掉了 $\log(1-P)$ 那一层变换.

长度归一化还有一个不那么显眼的后果: 它把 reward 的「自然单位」从序列变成了 token. 之后的所有分析——margin 的取值, $\beta$ 的尺度, 梯度权重的饱和区间——都要按 token 级分数来理解. 一个训练良好的 instruct 模型, 平均 token log 概率常见量级在 $-1$ 到 $-3$; 以 $\beta=10$ 计, reward 落在 $-10$ 到 $-30$, 两个 reward 的差在个位数. 这个量级决定了 $\gamma$ 取零点几到几才有意义, 也决定了 batch 里不同对子的 logit 差异主要由分数差决定而不是由 $\beta$ 决定. 量级感是调 SimPO 超参时最容易缺失的东西, 排查训练异常的第一步永远是打印几条样本的 $s$ 和 $\Delta r$ 看量级.

### 2.4 与 odds 的定量对照

同一个模型对两条回复的分数, 用 ORPO 的 odds ratio 和 SimPO 的原始分数差排序, 结果可能不同. 取 $s_w=-0.5$, $s_l=-2.0$: SimPO 的 logit 正比于 $s_w-s_l=1.5$. ORPO 的 log-odds 差是 $\Delta=(s_w-\log(1-e^{s_w}))-(s_l-\log(1-e^{s_l}))$. 逐项算: $\log\text{odds}(-0.5)=-0.5-\log(0.393)\approx-0.5+0.934=0.434$; $\log\text{odds}(-2.0)=-2.0-\log(0.865)\approx-2.0+0.145=-1.855$; $\Delta\approx 2.289$. odds 变换把低分端的差距压大了 $0.79$, 因为 rejected 分数越接近 $0$, 补数项贡献越大. 一般地, $d\,\log\text{odds}/ds=1/(1-e^s)>1$, 且随 $s\to 0$ 发散, 而 SimPO 的间距恒为 $1$. 两个函数对同一个分数差的解读在低分端差异最大. ORPO 的隐含立场是「低分端的对子更重要」 (被 rejected 明显更差的回复要被更强地推开), SimPO 的隐含立场是「所有分数差一视同仁, 重要性由数据决定」. 哪个更合理取决于偏好数据的噪声结构, 没有先验答案, 这正是 1.4.1 节选型实验里两种方法胜负随数据翻转的原因之一.

### 2.5 归一化的选择: 算术平均之外

长度归一化有多种做法. 实践中还会直接使用总分 (DPO 原版)、在对数空间取几何平均 (取对数后与算术平均相同), 或按「关键 token 数」归一化, 只统计答案实体部分. SimPO 采用算术平均, 因为它与生成时的 per-token likelihood 一致. 后续工作还尝试用对数长度等分母减轻长回复惩罚, 相当于在平均分数之外显式加入长度先验. 本文沿用算术平均这一实现约定; 偏好目标本身并未唯一确定归一化分母.

算术平均把「回复质量」压成一个标量, 会丢失位置和局部结构. 一条前半段精彩、后半段崩坏的回复, 可能和一条全程平庸的回复得到相同均值. 一种扩展方式是在归一化前截去最高和最低的一小部分 token 分数再求平均, 以降低局部异常值的影响; 这属于 SimPO 之外的鲁棒聚合改造.

把平均 log 概率当作随机变量看, 它的方差随长度按 $1/|y|$ 收缩: 单 token 的 log 概率方差 $\sigma_t^2$ 有限时, 平均值的方差约为 $\sigma_t^2/|y|$. 因此短回复的分数信号噪声更大, 梯度更新更容易在这类样本上形成一致的下降方向; 长回复中每个 token 的梯度贡献经过平均后则更平缓. 若要让长短偏好对获得相近的训练强度, 需要按长度加权或分桶, 等比例采样无法抵消这项方差差异.

## 3. Target Margin

### 3.1 margin 在损失里的位置

定义 reward gap $\Delta r=r(y_w)-r(y_l)$, SimPO 在 Bradley-Terry 的 logit 上平移一个常数 $\gamma$:

$$
\mathcal{L}_{SimPO} = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}} \left[ \log \sigma \left( \Delta r - \gamma \right) \right].

$$

这不是 hinge loss. hinge loss 在 $\Delta r=\gamma$ 处梯度陡降为零, SimPO 的损失在整个实数轴上光滑, 只是 $\Delta r=\gamma$ 处梯度权重恰好是 $0.5$. 平移的效果是把整个饱和曲线右移: DPO 在 $\Delta r=0$ (两回复分数相等) 处梯度最强, SimPO 把最强区域推到了 $\Delta r=\gamma$. 为什么需要这个平移? 没有 margin 时, 模型只要让 chosen 的分数略高就进入梯度衰减区, 排序正确但对子之间的间隔很小, 模型对相近质量的回复缺乏分辨能力. 生成时的 best-of-n 选择恰恰需要这种分辨能力: 候选之间往往只有细微差别. margin 强迫训练在排序正确之外继续拉开间隔, 间隔的大小由 $\gamma$ 直接控制.

### 3.2 手算: margin 对梯度权重的影响

梯度权重是 $\sigma(\gamma-\Delta r)$. 固定 $\gamma=0.5$, 看三个位置: $\Delta r=0$ 时权重 $\sigma(0.5)\approx 0.622$, 比无 margin 时 ($0.5$) 更强; $\Delta r=0.5$ 时权重 $0.5$; $\Delta r=2$ 时权重 $\sigma(-1.5)\approx 0.182$. 对比无 margin 的 DPO 在 $\Delta r=2$ 处权重已是 $\sigma(-2)\approx 0.119$. 同一个 gap, SimPO 保留的梯度大约是无 margin 版本的 $1.5$ 倍, 且这个倍数随 gap 增大还会变化. $\gamma$ 取多大是一个经验问题, 但它有一个可分析的约束: $\gamma$ 不能超过模型实际能拉开的间隔, 否则大量样本永远停在强梯度区, 训练等价于持续推高 chosen 和压低 rejected 而不收敛. 论文按模型分别调节 $\gamma$, 这与此分析一致.

margin 的设计和生成时的 best-of-n 选择有直接的数量关系. best-of-n 从 $n$ 个候选里选 reward 最高者, 选到真正最优候选的概率取决于候选间 reward 差的分布. 如果训练把任意一对相近候选的间隔都推到 $\gamma$ 以上, 选择函数出错 (把次优当最优) 的概率随间隔指数下降. 反过来说, $\gamma$ 的合理量级可以由「生成时希望区分的候选差距」反推: 两个候选的平均 token 分数差 $0.05$ (这是很典型的水平), $\beta=10$ 对应 logit 差 $0.5$, 所以 $\gamma$ 取零点几恰好让这类对子停在有效梯度区. 这把一个看似拍脑袋的超参和部署时的选择精度联系起来, 是 SimPO 设计里最「有出处」的部分.

### 3.3 与其他排序损失的并排

带间隔的排序损失在机器学习里有很长的历史, hinge loss (SVM), margin ranking loss, 到深度学习里的 contrastive loss 都属此类. 它们的共同点是间隔内强梯度, 间隔外零梯度; SimPO 的区别是间隔外不截断, 只是平滑衰减. 衰减和截断的训练行为差异显著: 截断型损失在间隔满足后彻底释放样本, 训练集的有效大小随训练收缩很快; 衰减型保留长尾梯度, 模型有机会继续微调已排序对子内部的间隔分布. 对偏好数据这种噪声不小的场景, 长尾梯度是双刃剑——它让训练更充分利用数据, 也把过拟合标注噪声的窗口开得更久.

偏好标注里的噪声 (标注者分歧, 反例质量参差) 会表现为「排反的对子」. 无 margin 时, 排反对子的梯度权重接近 $0.5$, 和正常对子几乎同权, 模型被迫拟合一部分噪声. 加入 margin 后, 梯度权重整体右移, 排反对子 ($\Delta r<0$) 的权重从 $0.5$ 升到 $\sigma(\gamma+|\Delta r|)$, 反而比无 margin 时更大. 这听起来更糟, 但结合饱和结构看: 噪声对子的 $\Delta r$ 一旦被纠正越过零点, 它们落入强梯度区的深度比正常对子浅 (因为噪声对子被纠正后通常间隔不大), 后续梯度自动减弱. 也就是说 margin 不改变「先重后轻」的分配, 只把整个分配曲线右移, 噪声对子在总预算中的占比实际上由数据清洗决定, 不由 $\gamma$ 决定. 期望靠调 $\gamma$ 消化标注噪声是不现实的.

KTO 使用逐样本「好/坏」效用项，不依赖 pair 内 rejected 的相对质量；SimPO 使用排序损失，rejected 质量直接决定 logit 尺度。数据只有单独好样本或坏样本时，KTO 仍可训练，SimPO 缺少成对输入。pair 齐全但质量参差时，两种目标又呈现不同敏感性。选型应先看数据形态与标签可靠度。

## 4. 完整损失与梯度推导

### 4.1 展开形式

把 reward 定义代入, 损失写成模型分数的形式:

$$
\mathcal{L}_{SimPO} = -\mathbb{E} \left[ \log \sigma \left( \frac{\beta}{|y_w|} \sum_{t=1}^{|y_w|}\log\pi_\theta(y_{w,t}|x,y_{w,<t}) - \frac{\beta}{|y_l|} \sum_{t=1}^{|y_l|}\log\pi_\theta(y_{l,t}|x,y_{l,<t}) - \gamma \right) \right].

$$

和 DPO 逐项对照: 没有 $\pi_{ref}$, 没有 odds 的 $\log(1-P)$ 项, 唯一的结构是平均, 缩放, 差, margin. 这是整个 DPO 家族里表达式最短的损失, 「Simple」名副其实.

### 4.2 梯度逐项

对参数 $\theta$ 的梯度:

$$
\nabla_\theta \mathcal{L} = -\sigma(\gamma-\Delta r)\cdot\nabla_\theta\Delta r = \sigma(\gamma-\Delta r)\cdot\left(-\frac{\beta}{|y_w|}\nabla_\theta\log\pi_\theta(y_w|x)+\frac{\beta}{|y_l|}\nabla_\theta\log\pi_\theta(y_l|x)\right).

$$

两个方向各有 $\beta/|y|$ 的尺度: 短回复的每个 token 获得的梯度更大. 这与 DPO 的梯度结构 ($\beta$ 无长度因子) 和 ORPO 的梯度结构 ($1/(1-e^s)$ 因子) 都不同, SimPO 的长度敏感度直接写在梯度里.

### 4.3 数值手算: batch 前向

取 $\beta=10$, $\gamma=0.5$, 三对样本:

| 样本 | $s_w$ (平均 log-prob) | $s_l$   | $\Delta r=10(s_w-s_l)$ | 权重$\sigma(0.5-\Delta r)$ |         |
| ------ | ----------------------- | --------- | ----------------------------------------------------- | --------- |
| A    | $-1.10$               | $-1.30$ | $2.0$                                               | $0.182$ |
| B    | $-0.90$               | $-1.00$ | $1.0$                                               | $0.378$ |
| C    | $-1.05$               | $-1.02$ | $-0.3$                                              | $0.690$ |

样本 C 排反了 ($\Delta r<0$), 梯度权重最大, 和 DPO/ORPO 的行为一致. 注意样本 A: 它排序正确且间隔 $2.0$ 已经超过 margin $0.5$, 但权重 $0.182$ 仍然不可忽略, margin 不是停止线. 把 $\gamma$ 从 $0.5$ 调到 $1.5$, A 的权重降到 $0.047$, B 降到 $0.182$, C 降到 $0.858$: margin 增大整体右移饱和曲线, 已排序样本加速失效, 训练预算进一步集中到难样本上. 这解释了实践中观察到的「$\gamma$ 越大训练越躁, 越小越温」的现象.

$\beta$ 只缩放 $\Delta r$, 不缩放 $\gamma$, 所以 $\beta$ 和 $\gamma$ 不是独立旋钮: 把 $\beta$ 翻倍等价于把有效 margin 减半 ($\gamma/\beta$ 才是 margin 在 logit 里的相对位置). 调参时固定一个扫另一个没有意义, 应该固定比值 $\gamma/\beta$ 扫尺度, 或反过来. 官方实现和论文按模型给出 $(\beta,\gamma)$ 组合, 复现时先在小数据上扫 $\gamma/\beta\in\{0.05,0.1,0.2\}$ 附近, 再微调绝对尺度, 比直接照抄单点超参稳.

§4.2 指出短回复的每个 token 获得 $\beta/|y|$ 的更大梯度, 这里把它和实际更新效果连起来. 参数更新是所有样本梯度的平均, 一对短对子 (各 20 token) 和一对长对子 (各 500 token), 前者的参数梯度大约是后者的 $25$ 倍 (按 $|y|$ 反比). 但长对子在序列维度的 token 多, 参数更新的「方向多样性」来自更多位置. 净效果取决于参数共享方式: 语言模型的参数在所有位置共享, 位置多样性不等于参数多样性, 短对子的梯度放大是真实的. 数据管线里如果长短对子混合不均, 有效 batch 会被短对子主导. 缓解办法是按长度桶采样, 或对不同长度桶记录分开的损失曲线.

---

把同一个对子在 DPO 和 SimPO 下的梯度权重并排, 能看出两个损失的「性格差」. 设模型当前对某对子的分数与参考模型相同 (DPO 的 logit 为 0), 两种损失的权重都是 $0.5$; 模型把 chosen 推高一个单位后, DPO 的 logit 是 $\beta$ (比如 $0.1$), 权重 $\sigma(-0.1)\approx 0.475$, 几乎没动; SimPO 的 logit 差取决于分数差的绝对尺度, 若 $s_w$ 上升了 $0.1$, logit 上升 $1.0$ (按 $\beta=10$), 权重 $\sigma(-1-\gamma)\approx 0.18$, 明显衰减. 同样的行为变化, SimPO 的梯度响应比 DPO 快一个数量级——这正是 $\beta$ 尺度差异的直接体现. 训练感受上, SimPO 对「已经推过的对子」更快放手, 对「还没推的」更用力, 曲线形态比 DPO 更陡.

## 5. 超参与训练实践

### 5.1 超参性格与训练动态

DPO 常用的 $\beta\approx 0.1$ 与 SimPO 的 $\beta$ 相差一到两个数量级, 根源在打分尺度. DPO 的 logit 是 $\beta\times$(两个总分的差), 总分会随长度累积, 较小的 $\beta$ 用来抑制尺度增长; SimPO 已经对长度归一化, $\beta$ 控制 token 级平均分的排序强度, 需要放大零点几的分数差才能在 logit 上拉开距离. 若直接把 DPO 的 $\beta=0.1$ 搬进 SimPO, logit 会挤在 $\pm 0.3$ 以内, $\gamma$ 几乎不起作用, 训练退化成接近不加权的最小二乘式排序.

SimPO 训练时值得单独记录的指标比 DPO 多两个. 第一是 $\Delta r$ 分布的分位数 (P10, P50, P90), 它直接显示 margin 的覆盖率: P50 落在 $\gamma$ 附近说明训练正常, P90 远超 $\gamma$ 而 P10 还在 0 以下, 说明模型在「放弃一部分难样本」; 第二是平均生成长度 (在固定 held-out prompt 集上周期解码), 它是短回复倾向的最直接报警器. 只记 training loss 会漏掉这两类退化, 因为 loss 可以在生成长度塌缩的同时继续下降.

SimPO 没有 SFT 项, 是纯偏好损失, 这带来一个和 DPO 相同的约束: 需要先做 SFT, 在格式稳定的模型上做偏好训练. 与 ORPO 不同, SimPO 论文的设定是标准的两阶段. 训练动态上和 DPO 类似: 初期排反对子多, 梯度权重大; 随训练推进, 权重向难样本集中. 额外的观察点是 $\Delta r$ 分布的右端: margin 的存在会把它推向 $\gamma$ 以上, 但如果右端持续右移远超 $\gamma$, 说明模型在用「极端化两端分数」的方式消化样本, 应回查是否 $\beta$ 过大.

### 5.2 数据构造

SimPO 对数据的敏感度与 DPO 同量级, 但有两个额外的构造建议. 第一是 rejected 的质量: SimPO 的 reward 没有参考基线, rejected 如果「差得离谱」 (乱码, 答非所问), 拉开它的分数几乎不消耗训练预算, 这类样本在早期失效; 构造数据时应让 rejected 是「有竞争力的次优答案」, hard negative 的占比直接决定训练后期还有没有用. 第二是多轮数据: 多轮对话的平均分数同时受历史质量影响, 一条高质量回复接在劣质历史上, 平均分数被拉低, 和单轮对子混合训练时会被系统性误判为弱 chosen. 多轮场景应单独归一化或单独看指标. 这条建议在 SimPO 下比在 DPO 下更重要, 因为 DPO 的对子内比较能部分抵消历史质量的影响, 而 SimPO 的绝对分数没有这个保护.

另一个实践细节: SimPO 的损失对 $s$ 的数值范围友好, 不需要 ORPO 的 `log1mexp` 那一套稳定化, 半精度下直接计算平均 log 概率即可. 这是表达式变短带来的工程红利, 复现 SimPO 的代码量比 ORPO 少一半左右.

### 5.3 length-control, 迭代训练与 on-policy 数据

针对 DPO 的 length exploitation, 同期有工作提出 length-controlled DPO (在 loss 里对长度差加惩罚项) 和长度归一化的 DPO 变体. SimPO 可以看作把这类补丁内化: 归一化从「附加修正」变成「reward 定义的一部分」, 不再需要单独的长度项. 这个差别在实验上表现为超参更少, 但也意味着长度行为的调节手段更少——DPO 系可以单独调长度惩罚强度, SimPO 只能动 $\gamma/\beta$ 比值和数据, 粒度更粗.

DPO 家族默认在离线偏好数据上训练, SimPO 也一样, 但参考自由让它和 on-policy 数据的组合更顺. 迭代式 DPO 每次要用当前模型重新采样回复构造新对子, 参考模型随之更换 (上一轮的策略变成这一轮的参考), 管线复杂; SimPO 没有参考模型, 迭代只需「采样, 标注/打分, 排序, 训练」四步, 参考角色天然缺席. 理论上 on-policy 数据能缓解离线分布偏移 (模型越训, 自己的输出离训练数据越远), 实践里迭代两轮以上收益递减明显, 第二轮的增益通常不到第一轮的一半. 是否迭代取决于采样和标注成本, 不取决于损失函数.

## 6. 实验边界与批评

### 6.1 结论适用范围

论文在 Llama-3-8B 等模型上报告 AlpacaEval 2, Arena-Hard 和 MT-Bench 相对 DPO 及同期基线的提升. 结果绑定特定基座, UltraFeedback 变体和评测组合. 在这些设置下, 长度归一化分数加 margin 的 reference-free 目标能够匹配或超过带参考模型的 DPO; 其他模型与数据需要重新验证. 这组实验还提示了一个对比口径问题. AlpacaEval 2 有原始胜率和长度控制胜率两个版本, Arena-Hard 用分类器判定, 对风格更敏感, MT-Bench 是人工双盲打分. 三个评测的敏感维度不同, 一个方法在 Arena-Hard 上大幅领先而在 MT-Bench 上领先很小, 通常意味着它主要优化了风格偏好而非实质质量. 读任何偏好方法的实验表, 先把三个评测的判定机制搞清楚, 再比较数字, 顺序不能反.

### 6.2 已知批评: 短回复倾向

后续社区复现普遍报告 SimPO 训出的模型回复偏短. 机制上有两条线索. 第一, §4.2 的梯度尺度: 短回复每个 token 的梯度权重是 $\beta/|y|$, 短样本在参数更新里被放大. 第二, 平均分数随长度增加方差变小, 长回复要整体维持高平均分数更难, 优化路径上「变短」是拉高 reward 的低阻力方向. margin 缓解的是排序间隔, 不直接约束长度分布. 实践中应在数据侧控制 chosen 的长度多样性, 在评测侧同时看长度控制变体和约束遵循指标, 避免单一胜率掩盖退化.

短回复是否算「退化」也取决于场景. 客服式问答和代码补全里, 简洁是优点; 开放式写作和教学场景里, 偏短直接损害体验. 评测 AlpacaEval 2 的 length-control 变体正是为了剥离长度因素, 引用 SimPO 胜率数字时注明是否长度控制, 是这篇论文之后社区形成的基本纪律.

SimPO 之后, 偏好优化沿着三条线继续演化. 第一条线是「生成目标即训练目标」的彻底化, 有工作直接用 best-of-n 的选择概率作为损失, 把 §1.1 的一致性论点推到极限. 第二条线是和其他信号的复合, 例如在 SimPO 之上叠加可验证奖励 (和 1.3 节 RLVR 汇合), 用规则校验替代部分人工偏好. 第三条线是理论修补, 有工作分析 reference-free 损失的识别性和隐式正则, 给「为什么删了参考模型还能 work」一个更严格的答案. 三条线都没有终结 reference-free 与 reference-based 的争论, 但共同把默认起点从 PPO 式 RLHF 移到了离线偏好损失.

### 6.3 什么时候选 SimPO

当管线已有 SFT checkpoint, 参考模型带来的显存或工程成本显著, 且偏好数据质量较高时, SimPO 是 DPO 的直接替代品, 实现成本最低. 当数据里长度差大或希望严格控长时, SimPO 的短回复倾向需要额外的数据工程对冲, DPO 或 KTO 可能更稳. 当想从预训练 checkpoint 单阶段出发时, SimPO 不含模仿项, 不适用, 应看 ORPO. 家族内选型 (1.4.1 节) 的系统对照表明, 没有一个方法在所有基座上稳定胜出, 但 SimPO 因其简洁, 已经成为很多团队的默认起点.

把 SimPO 放回本章的顺序看, 它处在「做减法」一端的极限: DPO 减掉了 reward model 和 PPO, ORPO 减掉了参考模型和 SFT 阶段, SimPO 把偏好目标本身减到只剩长度归一化分数差加一个常数. 减法做到这个程度, 再想进步就必须做加法了——加验证信号, 加在线成分, 加过程监督, 这正是 1.3 节推理强化学习的路线. 理解 SimPO 的价值, 一半在它本身的工作, 一半在它把离线偏好优化这条路的尽头标了出来.

SimPO 在本章四种方法中实现较短、数值稳定、超参数也少, 适合作为新管线的首个实验基线. 数据管线和评测管线跑通后, 再根据参考约束或单阶段训练的需求选择 DPO、ORPO. 从简洁基线逐项增加组件, 也更容易定位故障来源.

## 7. 实现

### 7.1 教学实现

```python
import torch
import torch.nn.functional as F

def simpo_loss(beta, gamma, chosen_logps, rejected_logps,
               chosen_lengths, rejected_lengths):
    # chosen_logps / rejected_logps: [batch]，各序列 token log-prob 之和（log 空间）
    # chosen_lengths / rejected_lengths: [batch]，有效 response token 数
    r_w = beta * chosen_logps / chosen_lengths
    r_l = beta * rejected_logps / rejected_lengths
    logits = r_w - r_l - gamma
    return -F.logsigmoid(logits).mean()
``` 输入约定与 ORPO 的实现不同: 这里传的是**总** log 概率和长度, 归一化在损失内完成, 而不是先在外部求平均. 两种约定等价, 但把总分数和长度分开传能保留更多信息 (例如按长度分组的日志), 复现论文配置时也方便核对.

两个实现并排放, 差异只有三行: ORPO 需要 `log1mexp` 把分数换算成 log-odds, SimPO 直接除长度; ORPO 多一个 SFT 项和 $\lambda$, SimPO 用 $\gamma$ 平移 logit; ORPO 要防 $s\ge 0$ 的 NaN, SimPO 没有这类数值陷阱. 如果团队要同时支持两种方法, 公共部分是 gather log-prob 和 mask 的管线, 差异收敛到损失函数本身, 值得抽成一个接口两种实现.

### 7.2 验证清单与配置映射

复现 SimPO 时先做三个数值检查。第一，$\gamma=0$ 时损失退化为无 margin 的 Bradley-Terry 形式，可以直接与手算对照。第二，固定分数并增大 $\gamma$，logit 变小，$-\log\sigma$ 严格增大；margin 提高了满足偏好的门槛。第三，交换 chosen 与 rejected 后，两个 logit 分别为 $\Delta r-\gamma$ 与 $-\Delta r-\gamma$；只有 $\gamma=0$ 时才有熟悉的 logistic 对称关系，非零 margin 下必须分别计算。

把论文超参映射到实现时有两处尺度问题。论文 reward 使用自然对数；若实现以其他底数累计，$\beta$ 和 $\gamma$ 都要换底重标。长度计数采用 tokenizer token，与字符数或 merge 前符号数含义不同；仅优化末轮时，$|y|$ 只覆盖当前 assistant 回复。任一尺度错位都足以让 margin 失效。排查训练停滞时，打印样本的 $s$、$\Delta r$ 和 logit，与 §4.3 手算量级对照。

### 7.3 常见实现错误

把复现中反复出现的三个实现错误列在这里. 第一, 归一化分母误用 batch 内最长序列长度而不是每条回复自己的 $|y|$, 结果是短回复的 reward 被系统性压低, 恰好把短回复倾向反转成长回复倾向, 症状隐蔽. 第二, logsigmoid 和长度归一化的顺序颠倒, 先除长度再算总 log 概率, 数学上变成对几何平均取对数后再除以长度, 梯度尺度整体错一个 $|y|$ 因子. 第三, 多轮样本的 $|y|$ 把历史轮次算了进去, 平均分数被历史稀释, 和单轮对子不可比. 三个错误单测都能拦住: 构造一条已知分数的短回复和一条长回复, 逐行核对 loss 的中间量.

排错时可以把 $\beta$ 临时设为 $0$。此时 SimPO 损失与模型分数无关，恒等于 $-\log\sigma(-\gamma)$，任何偏离都暴露了管线错误。再把 $\gamma$ 设为 $0$，可与“无 reference、使用同一长度归一化分数”的 logistic 基线重合；标准 DPO 还包含 reference log-ratio，不能仅靠对齐 $\beta$ 得到数值等价。这两个退化点适合写进 CI。

§7 的实现建议可以收束成一句话: SimPO 的简单是真实的, 但它把复杂度转移到了数据构造和超参扫描上, 这两处省不掉. 方法简单不等于管线简单, 这是从 DPO 到 SimPO 每一篇论文共同的经验: 损失函数省掉的每一个组件, 都会以另一种形式出现在数据清洗, 超参搜索或监控指标里. 读到再简的方法, 先问它把复杂性藏到了哪里, 再决定要不要采用.

长度归一的验证不能只看最终平均长度. 更有区分力的做法是把偏好对按 chosen 与 rejected 的长度差分桶, 分别统计 margin、正确排序率和梯度范数. 如果只在 chosen 明显更短的桶里获益, 模型可能学到的是长度线索; 如果等长桶和 chosen 更长的桶也稳定改善, 才能说明序列平均分数确实提取了内容偏好. 这个实验只需复用训练缓存的逐 token 对数概率, 不增加模型前向成本.

还应单列因截断而长度相同的样本. 两条回答都碰到最大长度时, 表面的等长并不代表完整内容等长, 末尾缺失可能改变偏好标签. 这类 pair 最好从核心评测中剔除或单独报告, 避免把截断器行为误判为 SimPO 的长度性质.

### 8. 长度归一化奖励的概率含义

**8.1 几何平均而非序列概率.** 令有效回答长度为 $T$，SimPO 使用

$$
s_\theta(x,y)=\frac1T\log\pi_\theta(y\mid x)
=\frac1T\sum_{t=1}^T\log p_\theta(y_t\mid x,y_{<t}).
$$

指数化后 $e^{s_\theta}$ 是各 token 条件概率的几何平均。它落在 $(0,1)$，却不是生成完整回答的概率。两条回答拥有相同几何平均时，SimPO 给出相同分数；完整序列概率则随长度呈指数差异。这个变化正是长度归一化的目的，也限定了 reward 的解释范围。

若每个 token 条件概率都是 $0.5$，十 token 回答的序列概率为 $2^{-10}$，一百 token 回答为 $2^{-100}$，平均 log probability均为 $\log0.5$。SimPO 对二者无差别，完整序列似然则极不相同。因此“训练 reward 与生成概率一致”应理解为与常见长度归一化候选分数一致，不能扩写成与整个生成分布完全一致。 **8.2 平均值保留了哪些长度影响.**

除以 $T$ 消除了总 log probability随长度线性累积的主效应，token 难度分布仍会随长度变化。长推理包含罕见符号、中间变量和低概率转折，平均分可能下降；短模板由高频词构成，平均分容易升高。模型依然可能通过选择易预测措辞提高 reward。

平均值的采样方差也依赖长度。若 token log probability弱相关且方差有限，均值方差大致随 $1/T$ 缩小；真实自回归 token 高度相关，下降速度会更慢。短回答的分数波动更大，hard pair 和异常梯度也更容易集中在短桶。按长度报告均值与方差，才能看见这一层效应。 **8.3 Token 梯度与回答级权重.**

对 chosen 第 $t$ 个 token 的 log probability，reward gap 导数为 $\beta/T_w$；rejected 对应 $-\beta/T_l$。每 token 梯度随长度反比，但一个长回答包含更多 token。若各位置梯度方向完全相同，求和后长度因子可抵消；语言模型中各位置方向不同，参数共享后的范数取决于相关性，不能简单断言短回答整体梯度一定是长回答的 $T_l/T_w$ 倍。 更准确的做法是记录回答级参数梯度范数，或用固定层的 per-sample gradient 近似。理论上的 $1/T$ 是每 token 系数，实际更新还包含每个 token 的 Jacobian 与方向相消。此前“20 token 对比 500 token 必然差 25 倍”的说法只在方向高度一致时成立。 **8.4 其他归一化会改变什么.** 用 $T^\alpha$ 作分母，可以在总分与平均分之间插值：$\alpha=0$ 是序列 sum，$\alpha=1$ 是 SimPO mean。$0<\alpha<1$ 保留一部分长度惩罚。对数长度、关键步骤数或字符数也能作为分母，但都会改变 reward 与梯度尺度。

这些变体无法沿用同一个 $\beta,\gamma$。分母变化后，gap 分布和每 token 梯度都变了。比较时应重新校准质量—长度—漂移前沿，并明确它已不是原论文的标准 SimPO。

### 9. Target margin 的精确几何

**9.1 γ 不是停止线.** 记 $z=\beta(s_w-s_l)-\gamma$，单样本损失为 $\ell(z)=\log(1+e^{-z})$。当未缩放分数差恰好为 $\gamma/\beta$ 时，$z=0$、loss 为 $\log2$、对 $z$ 的梯度为 $-1/2$。样本仍有明显更新，不会在 margin 处停止。 只有 $z\to+\infty$ 时梯度趋近零。margin 的作用是平移 logistic 曲线，让同一个分数差承受更大压力。它表达软间隔，而非 hinge loss 的硬约束。 **9.2 β 与 γ 的耦合.** 把 logit 写成

$$
z=\beta\left[(s_w-s_l)-\frac\gamma\beta\right]
$$

可见 $\gamma/\beta$ 是平均 log probability空间中的目标边界，$\beta$ 同时控制曲线斜率。固定比值并放大二者，会让边界位置不变、过渡区更陡；固定 $\gamma$ 增大 $\beta$，则同时缩小原始分数空间中的边界并放大梯度。 因此二者并非只有比值重要。比值决定 $z=0$ 的位置，绝对 $\beta$ 决定 logistic 温度与参数梯度尺度。调参可以先选可达的 $\gamma/\beta$，再通过 $\beta$ 调节边界附近的锐度，同时联合调整学习率。 **9.3 二阶曲率.** 对原始 gap $d=s_w-s_l$，

$$
\frac{\partial\ell}{\partial d}=-\beta\sigma(-z),
\qquad
\frac{\partial^2\ell}{\partial d^2}
=\beta^2\sigma(z)\sigma(-z).
$$

曲率在 $z=0$ 达到 $\beta^2/4$，远离边界后趋零。较大 $\beta$ 让边界更尖，学习率不变时更容易在附近振荡。Adam 会调整尺度，却无法消除梯度裁剪和局部曲率变化。 **9.4 可达 margin.** 共享参数、冲突标签和有限模型容量会让部分 pair 无法达到边界。若 $\gamma/\beta$ 高于实际可达 gap，大量样本长期停留在强梯度区，训练不断压低 rejected 或改变未观测概率质量。监控 gap 分位数与生成质量，比假定 margin 最终会满足更可靠。 同一 prompt 的候选图还可能产生互相冲突的间隔。若 A 胜 B、B 胜 C、A 胜 C，要求每条边都恰好达到相同 gap并不相容；前两条累加会让 A-C 更大。logistic loss会折中，不会把所有边固定在 $\gamma/\beta$。

### 10. 与 DPO、ORPO 的精确关系

**10.1 从 DPO 删除 reference 还不够.** DPO logit 为

$$
z_{DPO}=\beta\left[\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}
-\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right].
$$

SimPO logit 为

$$
z_{SimPO}=\beta\left[\frac{\log\pi_\theta(y_w|x)}{T_w}
-\frac{\log\pi_\theta(y_l|x)}{T_l}\right]-\gamma.
$$

二者同时改变了三件事：删去 reference、从序列 sum 换成各自长度 mean、加入 margin。将 DPO 的 reference 项设为零，只得到无 reference 的序列总分差；它仍然不是 SimPO。公平消融要逐项切换三个组件。 当 $T_w=T_l=T$、$\gamma=0$，SimPO logit 等于无 reference 总分差乘 $\beta/T$。即便此时，超参数也要按 $T$ 重标。长度不同后不存在单一常数能让两种 logit 对所有 pair 相等。 **10.2 Reference 提供了什么坐标.** DPO 比较 policy 相对 reference 对两项的重加权。若 reference 已经强烈偏爱 chosen，policy 不必仅凭绝对分数差重复表达全部优势；SimPO 只看当前 policy 分数，reference 的知识不进入训练坐标。 这并不表示 SimPO 没有先验。SFT 初始化、偏好数据和有限训练共同限制漂移，只是没有逐样本显式锚点。评估时仍可保留 SFT 起点，计算 KL、log-ratio 与能力回归。 **10.3 ORPO 的 odds 与 SFT 项.** ORPO 使用平均 log probability $s$，再变换为 $o(s)=s-\log(1-e^s)$，偏好 logit 为 $o(s_w)-o(s_l)$，并加入 chosen SFT。SimPO 直接使用 $\beta(s_w-s_l)-\gamma$，没有 SFT 项。

由于 $do/ds=1/(1-e^s)$，ORPO 在高置信区放大梯度，SimPO 对 $s$ 的导数恒为常数 $\beta$，再由 logistic 权重调节。两种方法排序 $s_w,s_l$ 时方向相同，因为 odds 单调，但对不同 pair 的相对权重不同。 ORPO 可以从较早 checkpoint 单阶段学习格式与偏好；SimPO 通常依赖已有 SFT 起点。若给 SimPO 加 chosen SFT，它成为新的混合目标，不能继续把收益全归给原始 SimPO。 **10.4 三种方法的共同不可识别部分.** pair loss只约束两个候选之间的关系。回答空间还有无数未观测序列，概率质量如何重分配由归一化、初始化与参数共享决定。固定 pair 排序改善时，生成可能流向第三种好答案，也可能流向模板捷径。

DPO 的 reference KL 提供整体约束，却不会让未观测行为完全可识别；ORPO 的 SFT 锚定 chosen；SimPO 两者都没有，更依赖短训练和数据覆盖。三种方法都必须用自由生成观察候选外行为。

### 11. 偏好噪声与比较图

**11.1 重复标签的总体最优.** 固定 canonical gap $d=s_a-s_b$。若 A 以概率 $q$ 获胜，期望损失为

$$
q\log(1+e^{-\beta d+\gamma})
+(1-q)\log(1+e^{\beta d+\gamma}).
$$

对 $d$ 求导并令零，可得到

$$
q\,\sigma(\gamma-\beta d)
=(1-q)\,\sigma(\gamma+\beta d).
$$

当 $\gamma=0$ 时解为 $\beta d=\log(q/(1-q))$。非零 margin 同时出现在正反方向，解不再是简单平移的 logit，需数值求根。多数票硬化会丢失 $q$，让六比四与十比零都成为同一硬标签。 **11.2 Margin 会放大错标压力.** 对错排 pair，$d<0$，权重 $\sigma(\gamma-\beta d)$ 接近 1。增大 $\gamma$ 会进一步提高所有样本的梯度压力，包括错标与主观冲突。margin 负责要求更大间隔，没有噪声过滤功能。 稳健训练要从数据与损失两侧处理。保留重复投票、tie 和标注理由，能识别不确定性；截断权重或稳健 loss 能限制异常影响。后者改变原始 SimPO，应给出公式与消融。 **11.3 循环偏好.** A 胜 B、B 胜 C、C 胜 A 无法由单一标量 $s$ 同时赋予正 gap。优化器按边权折中，训练 loss 存在由数据结构决定的下界。高 loss 不必然表示容量不足或代码错误。

对每个 prompt 构建候选图，统计三环、强连通分量和边置信度。高置信循环可能反映准确、简洁、安全等多目标取舍；低置信循环更像噪声。删除全部循环会人为制造传递性。 **11.4 Tie 与绝对质量门槛.** tie 可能表示同样好、同样差或无法判断。随机指定 winner 会制造强方向。两项同样好可使用零方向或分别作为 SFT 数据，两项同样差应重写候选，无法判断则复审。 SimPO 没有 chosen SFT 项，却仍会提高 winner 相对 loser 的分数。若 winner 只是两项错误答案中稍好的一条，训练不会创造集合外的正确答案。事实、代码和数学任务应先做绝对正确性筛选，再比较表达与策略。

### 12. EOS、模板与多轮边界

**12.1 EOS 属于回答决策.** 自然结束的 EOS 应进入 response token 与长度。漏掉 EOS 会让短回答少承担一次终止概率，强行给截断样本补 EOS 又把达到长度上限伪装成自然结束。数据需要区分自然结束、长度截断和源文本缺尾。 EOS 在短回答均值中占比更高，拒答与简短事实答案尤其敏感。按结束状态和长度分桶报告 gap，才能判断长度效应来自内容还是终止规则。 **12.2 两侧必须共享完整条件.** chosen/rejected 的 system prompt、用户消息、工具描述和历史必须相同。prompt token虽不计入均值，仍决定回答条件概率。仅靠 mask 无法抵消两侧不同的前缀。 assistant 起始标记归入 prompt 还是 response 可以有不同约定，训练、验证和所有 checkpoint 必须一致。模板升级后，旧 token 缓存与分数全部失效。 **12.3 多轮对话优化哪一段.**

仅优化末轮时，历史是条件，$T$ 只数末轮 assistant token；优化整条助手轨迹时，要覆盖每轮模型输出，并排除用户与环境 token。两种定义的长度与信用分配不同，不能在同一数据集中混用。 工具轨迹中，工具名与参数是策略动作，搜索结果和执行输出是环境观察。把观察计入平均分数会给模型无法控制的文本分配梯度。两个轨迹若收到不同观察，也不再是完全相同条件下的静态 pair。 **12.4 截断可能翻转标签.** winner 的关键结论位于末尾时，截断后的前缀未必仍优于 loser。预处理不能只保证张量合法，还要确认偏好依据仍保留。无法判断的 pair 应删除或重标。

两侧都达到最大长度看似等长，真实完整回答长度未知。核心长度评估应排除这类样本，另行报告截断率与生成继续趋势。

### 13. 离线覆盖决定学到哪条边界

**13.1 候选生成器就是比较分布.** 偏好数据只覆盖生成器能够产生的回答。弱模型低温采样多为明显好坏，适合基本排序，缺少高质量答案之间的细微差异；强模型高温采样覆盖更广，也产生更多难以判断的 pair。训练更多 epoch 不会补回从未出现的模式。 保存 producer policy、温度、top-p、stop rule 和生成时间，才能解释数据覆盖。若 chosen 总来自强模型、rejected 总来自弱模型，格式、措辞和自述会成为捷径。加入同源模型内部比较，并隐藏来源标记，可以减少这种偏差。 **13.2 Hard negative 有三种.**

两个高质量答案难分胜负，属于信息丰富但标签不确定；一个明确好、一个明确坏却被模型排反，属于真正难例；由模板错位、截断或错标形成的高 loss，则是数据故障。三者的 gap 都可能很小或为负，处理方式完全不同。 主动选样本前先做规则和人工抽查。真难例提高覆盖，主观难分样本保留投票比例，数据故障直接修复。机械追逐最高 loss 会把错误标签送回训练，并让 logistic 梯度长期接近最大。 **13.3 Pair 展开改变 prompt 权重.** 一个 prompt 有八个候选，可产生二十八条 pair；只有两个候选时仅一条。逐 pair mean 会让前者获得二十八倍权重。若目标是 prompt 等权，应先在组内平均，再跨 prompt 平均。

完整排序拆 pair 还重复使用同一回答。相邻名次与首尾名次的判断难度不同，全部等权会扭曲信息。保留原始候选列表、排序和 group ID，后续才能恢复权重或改用列表目标。 **13.4 数据切分与泄漏.** 训练验证按 pair 随机切分时，同一 prompt、候选甚至同一回答会跨集合。模型记住回答风格即可获得高验证排序。应按 prompt 或 candidate group 切分，模板高度重复时再按语义簇和来源隔离。 代码、数学和翻译数据还要检查结构级近重复。变量改名、数字替换或跨语言翻译不会被文本哈希发现。保存生成种子、题源和解题骨架，有助于更严格去重。 **13.5 迭代 SimPO.**

当前 policy 生成新候选、重新标注再训练，能够补充旧离线分布看不到的错误。SimPO 无需滚动 reference，流程较短，比较分布仍然每轮变化。固定锚点集衡量跨轮进步，并为每轮冻结挑战集，避免模型变化与题目变化混在一起。 只用最新轮会遗忘，累积所有历史会让早期简单 pair 占多数。按任务、轮次和难度重采样，关键安全样本永久保留。迭代收益递减是经验现象，具体轮数应由新增覆盖和外部评估决定。

### 14. 统计误差与优化误差

**14.1 样本相关性.** 同一 prompt 产生多条边，同一回答反复出现，同一标注者处理一批样本，pair 并非独立同分布。按 pair bootstrap 会给出过窄区间。评估至少以 prompt 或 candidate group 为 cluster 重采样，必要时按用户与来源提高层级。 加权样本的有效数量可用

$$
n_{eff}=\frac{(\sum_iw_i)^2}{\sum_iw_i^2}
$$

近似。少数大权重让有效样本量远低于行数。报告 pair、prompt、语义簇和独立来源数量，比单报数据行数更有意义。 **14.2 标签估计误差.** 单次 winner 是偏好概率的一次 Bernoulli 观测。没有重复标签时，网络依靠跨 pair 共享结构泛化，无法知道某条边是确定事实还是随机选择。保留多位标注者的原始投票，才能估计不确定性。 标注判断也可能相关：同一指南、同一参考答案或同一 judge model 的多次采样并非完全独立。按标注来源聚类，比较组间差异。十次同源 judge 投票不能当作十位独立专家。 **14.3 Minibatch 方差.**

单样本参数梯度为 logistic 权重乘 chosen/rejected token 梯度差。batch 中任务、长度和难度组成变化，会引起明显方差。分层采样可稳定关键小域，同时改变经验分布；必要时用权重恢复目标或明确采用新的业务配比。 大 batch 减少随机噪声，可能更快拟合经验风险；小 batch 的噪声有时形成隐式正则。比较时按处理 pair 和 token 对齐，而非只看 step。动态 token batch 还要记录每步实际 pair 数。 **14.4 参数化与优化不足.** 策略空间里存在更好排序，不代表有限参数模型能够逐 prompt 独立实现。LoRA rank、作用层和冻结范围限制可更新子空间。训练 loss 高可能来自数据冲突、容量不足或 optimizer 未收敛，需要分别验证。

小规模全参数对照、不同 rank 的 loss—生成前沿和固定图的自由 score 下界，可以拆开这些原因。只增加训练步数无法解决不可满足比较图或参数空间限制。 **14.5 多随机种子.** 早期 batch 顺序和极端 pair 会改变 Adam 状态，最终 checkpoint可能有明显差异。至少用多个随机种子报告均值与区间，并检查收益是否由一次幸运运行贡献。 固定数据顺序只隐藏方差。若种子敏感，先查高权 prompt、异常 gap、warmup 和裁剪，再考虑扩大样本。稳定的小幅收益通常比不可复现的峰值更适合作为配方。

### 15. 优化器与数值实现

**15.1 稳定计算.** 使用 `-logsigmoid(z)` 或 softplus $\log(1+e^{-z})$，不要先算 sigmoid 再取 log。长序列 token log probability用 FP32 累积，随后除以有效长度。低精度中先求巨大负和再相减，容易损失有效位。 长度必须大于零。空 response 应在数据层拒绝，不能用分母 clamp 静默产生零分数。NaN 或 infinity 出现时保存样本 ID、token、mask、长度、两侧 score 和 logit。 **15.2 Pair 与分布式归约.** 每个 pair 产生一个标量 loss，标准 batch mean 以 pair 为单位。不同 worker 的尾批数量不同时，聚合 loss sum 与 pair count；本地 mean 再等权平均会重权小批。 gradient accumulation 同理。复制全 batch 两次，mean loss 与梯度应不变；按 prompt 等权时，复制某 prompt 内所有边也应不变。这两个测试分别检查 pair 层与 group 层。 **15.3 Concatenated forward.** chosen/rejected 可在 batch 维拼接前向。两侧 attention 必须独立，position ids、response mask正确，输出按 pair ID 恢复。length sorting 与 packing 后不能依赖相邻位置配对。 逐条前向与拼接结果应数值一致。packing 使用 block-diagonal causal mask，禁止跨样本注意。prompt token虽不计 loss，也不能看到其他序列。 **15.4 Gradient clip 与 β.**

$\beta$ 同时放大 logit 差和边界附近的梯度。Adam 会归一化部分尺度，无法消除曲率、裁剪与饱和区域变化。学习率、$\beta,\gamma$ 需联合校准。 全局 clip 频繁触发时，难例的额外权重会连同普通样本一起缩小。记录裁剪前后范数与触发率。per-sample clip 则直接改变样本权重，属于稳健目标修改。 **15.5 恢复与 world size.** checkpoint 保存模型、optimizer、scheduler、scaler、随机状态、sampler 与 dataloader cursor。恢复后下一批 ID、loss 和一步更新应与不中断运行一致。只恢复模型会重复或跳过数据。 改变 world size 后浮点归约顺序变化，逐 bit 复现未必可行，仍应保持全局 pair batch、按已处理 pair 推进 scheduler，并用固定审计集核对 score 与梯度统计。

### 16. 反例：平均分排序会在哪里失灵

**16.1 高频套话战胜关键事实.** 回答 A 用常见句式流畅铺陈，末尾给出错误数字；回答 B 措辞罕见但计算正确。模型可能给 A 更高平均 token probability。偏好标签会推动 B 超过 A，训练覆盖有限时，已有流畅性先验仍会主导未见题。 可验证任务需要执行或规则指标，不能用模型平均分代替正确性。训练后构造格式漂亮但事实错误的反事实，检查排序是否翻转。 **16.2 删除必要推导提高均值.** 长答案包含低概率推理步骤，删去这些步骤后结论不变、平均分可能上升。若用户需要可审计过程，短版本并不更好。长度归一化消除总分惩罚，却没有奖励必要信息覆盖。

构造保留结论、逐步删除必要条件的系列，测 reward 与人评变化。若 reward 随删减单调升高，数据需要增加过程完整性偏好或可验证步骤信号。 **16.3 两项同时下降.** 训练可让 chosen 与 rejected 平均分都下降，只要 rejected 下降更多，gap 就改善。概率质量可能流向第三种答案。固定 pair 指标会上升，自由生成可能更好，也可能出现新坏模式。 同时记录 $s_w,s_l$，并从每个 checkpoint重新采样。chosen 绝对分数持续下降是诊断信号，不能由正 gap 自动解释为成功。 **16.4 共同后缀不会自动抵消.** 两条回答末尾都有“因此答案为 4”，前缀不同后，相同 token 的条件概率也不同。自回归分数不能只计算字符串差异片段。随意删除公共后缀会改变平均分母和条件状态。

最小编辑 pair 适合减少无关差异，但仍应对完整回答前向。逐 token 分解只能定位贡献，不能当因果信用。 **16.5 长度相同仍可利用格式.** 把两项裁成同长度，并不能消除标题、列表、礼貌语和拒答模板等旁路。模型可能利用易预测格式获得更高平均分。保持长度、交换格式与内容的二维反事实，才能定位捷径。 模板本身在某些任务有价值，因此按任务判断。指令格式遵循与开放写作的标准不同，一个全局“去格式化”指标也会误导。

### 17. 端到端数值验收

**17.1 一个完整 batch.** 设 $\beta=4,\gamma=0.8$。第一条 pair 的 chosen 有两个有效 token，log probability为 $(-0.8,-1.2)$，所以 $s_w=-1.0$；rejected 有四个 token，值为 $(-1.1,-1.3,-1.5,-1.7)$，$s_l=-1.4$。原始 gap 为 $0.4$，scaled gap 为 $1.6$，logit $z=0.8$，loss 为 $\log(1+e^{-0.8})\approx0.371$，权重 $\sigma(-0.8)\approx0.310$。 chosen 两个 token 对 logit 的系数各为 $4/2=2$，rejected 四个 token 各为 $-4/4=-1$。对 loss 求导后，chosen 每 token log probability梯度约为 $-0.620$，rejected 每 token约为 $0.310$。梯度下降会提高 chosen、降低 rejected。prompt 与 padding token 梯度应为零。 第二条 pair 取 $s_w=-1.3,s_l=-1.2$，scaled gap 为 $-0.4$，$z=-1.2$，loss 约 $1.463$，权重约 $0.769$。两条 pair 等权 mean 为约 $0.917$。若第二条业务权重为 $0.25$，正确加权 mean 是 $(0.371+0.25\times1.463)/1.25\approx0.590$，不能把普通 mean 再乘平均权重。 交换第一条的 chosen/rejected 后，新 logit 为 $-1.6-0.8=-2.4$，loss 约 $2.487$。它与原 loss 没有“加一个固定 gap”这种简单关系，因为 margin 在正反方向都以 $-\gamma$ 出现。这个数值例子应写入单元测试，防止沿用无 margin logistic 的恒等式。 将 $\gamma$ 从 $0.8$ 墦至 $1.2$，第一条 logit 从 $0.8$ 降到 $0.4$，loss 从约 $0.371$ 升到约 $0.513$，梯度权重也从 $0.310$ 升到 $0.401$。固定分数下，margin 越大，约束越严格，loss 必然上升。

将 $\beta$ 设为零，所有 pair 的 logit 都是 $-\gamma$，loss 恒为 softplus$(\gamma)$，对模型分数的梯度为零。若参数仍更新，说明还有额外 loss、权重衰减或实现错误。将 $\gamma$ 设为零，只能与使用相同 mean 分数、无 reference 的 logistic 基线比较。 逐 token 保存这一 batch 的 token IDs、mask、log probability、长度、均值、scaled gap、logit、loss 和梯度，独立脚本与训练框架分别计算。允许混合精度带来小误差，符号、mask 与分母必须完全一致。 复制 padding、切换左右 padding 后，有效 token 结果不变。给 chosen 末尾加入自然 EOS，长度与分子都增加；给截断样本增加 padding则均不变。这个对照可以抓住 EOS 与 attention mask 混用的问题。 把同一全局 batch 分成不同 microbatch，一步参数更新应在容差内相同。若 $3+1$ 与 $2+2$ 得到不同尺度，通常是本地 mean 或 accumulation 除数错误。多卡尾批也用相同方法检查。

对一个只有三个动作的 toy policy，可直接训练三个 logits。人为给出重复 pair 与已知胜率，$\gamma=0$ 时经验最优 gap 应接近偏好 logit 除以 $\beta$；加入 margin 后用数值求根得到基准。这个实验绕开 Transformer 与 tokenizer，验证目标、采样和 optimizer。 再加入 A 胜 B、B 胜 C、C 胜 A 的循环，预期所有边无法同时得到大正 gap。若日志仍显示每条边都满足 margin，pair ID、方向或统计代码有问题。测试的成功标准是呈现理论上的冲突，而非把 loss 强行降到零。 **17.2 逐层故障定位.** loss 从第一步就异常时，先查长度、mask、chosen 顺序、$\beta,\gamma$ 和 log 底数。loss 正常下降而生成变短，查长度桶、EOS 与模板捷径。固定 pair 改善但自由生成变差，查候选外概率质量与数据覆盖。

若 $s_w,s_l$ 同时下降且 rejected 更快，gap 改善来自共同下移；若两者都上升且 chosen 更快，概率也可能从未观测答案转来。两种现象都需要重新采样确认质量去向。 若 gap 长期达不到 margin，可能是冲突标签、容量不足、优化不充分或目标不可达。先看同 prompt 比较图与重复投票，再比较更大 rank、学习率和步数。没有结构诊断时，盲目加 epoch只会加深过拟合。 若大量 gap 远超 margin，说明 logistic 并未在边界停止。检查训练过长、$\beta$ 尺度、数据重复和共享参数外溢。外部质量不再提升时，应早停，而非等待所有 loss 接近零。

### 18. 生成评估与因果边界

固定 pair accuracy 只回答已有候选是否按标签排序。自由生成会出现第三种答案，必须在未见 prompt 上重新采样。对每个 checkpoint 使用相同解码预算，记录任务成功、独立偏好、长度、拒答、重复与语义多样性。 固定随机种子便于配对调试，多种子评估用于覆盖采样方差。温度、top-p、max tokens 和 stop rule 全部固定；另做解码敏感性扫描，检查收益是否只在某个设置存在。 judge model 与训练标注器同源时，可能奖励相同风格。可执行任务优先用测试与规则，开放任务加入独立人评，展示左右位置随机。judge 的版本、提示词、温度和解析代码都要保存。

长度控制不能只靠回归删除。长度可能承载必要推导，统计控制会把真实价值一并抹掉。更可靠的是内容反事实：保持结论与关键事实，增加或删除冗余；保持长度，替换一个决定性事实。按任务画长度—胜率曲线。 短回复倾向需要同时看平均值、分位数和任务完成度。平均长度下降可能是去冗余，也可能是遗漏约束。将样本分为简短事实、教学推导、代码解释和开放写作，分别定义足够长度与完整性。

语义多样性也不能只数不同字符串。格式符号和同义改写会制造表面差异。检查答案结论、推理路径、语义簇、跨样本短语重复和多次采样的一致性。胜率升高而语义簇骤减，提示模型集中到评价捷径。 能力回归采用硬门槛。事实、代码、数学、安全和多语言中任何关键项明显退化，都不能由大量闲聊胜率抵消。先筛掉越过门槛的 checkpoint，再比较剩余模型的偏好与成本。 评估区间以 prompt 为 cluster。相同 prompt 的多次采样、多个 pair 和多个 judge 判断相关，不能当独立样本。报告 win、loss、tie 及区间，tie 较多时不要只给折半胜率。

统计显著与实际价值分开。海量普通样本上的零点几百分点可能显著却无感；少量严重风险下降可能更重要。结果表同时给效应量、样本量、区间、成本和失败严重度。 验证集反复用于调 $\beta,\gamma$ 和 checkpoint，会产生开发过拟合。划分开发集与最终测试集，最终集尽量一次使用。关键结论用不同来源的数据复核。 若声称 margin 提高 best-of-n 选择，应直接测不同 $n$ 下的成功率、候选分数校准和选择 regret。pair gap 变大并不自动保证平均分数更接近真实质量。需要比较被选答案与候选集中可验证最优答案。 若声称 length normalization 消除长度偏差，应展示 chosen 更短、等长、chosen 更长三个桶，以及内容匹配反事实。收益只集中在短 chosen 桶时，结论更像长度捷径。

若声称 reference-free 更高效，报告峰值显存、tokens/s、总训练时长与超参搜索成本。省去 reference 前向是明确收益，额外扫描 $\beta,\gamma$ 也占算力。成本边界要与实际管线一致。 若声称优于 DPO，逐项对齐起点、数据、token 预算、解码、评估和策略漂移。三组件消融分别切换 reference、mean 与 margin。否则无法知道收益来自哪一项。

### 19. 迭代、部署与回滚

上线前保存完整 manifest：policy、SFT 起点、tokenizer、模板、数据版本、$\beta,\gamma$、解码和工具依赖。只回滚权重而保留新版模板，行为不会完全恢复。量化或合并后的发布物也要重新评估。 小流量发布监控任务成功、用户反馈、长度、拒答、重复、延迟和高风险事件。线上点赞、点击与投诉有选择偏差，受到位置、速度与用户群影响，不能直接当无偏 winner。保留曝光信息与随机抽样人评。

回流训练会改变下一轮候选分布。当前 policy 很少生成的模式逐渐离开数据，judge 偏好的格式反复入选。混入旧 checkpoint、其他生成器与随机探索候选，可以保留覆盖；每轮按任务统计语义簇数量、回答长度和短语重复率，发现变化后抽查对应输出。 每轮固定锚点集衡量长期变化，并保存当轮挑战集。历史数据全留会让简单旧 pair 占多数，只留新数据会遗忘旧约束。按任务、轮次与难度采样，关键安全集永久保留。 新增数据针对具体故障：知识缺失补正确答案，长度捷径补反事实，主观冲突补独立标注，候选覆盖不足提高探索，模板错误直接修预处理。把所有高 loss 样本回流会同时放大脏数据。

停止条件结合生成胜率、起点 KL、chosen/rejected 绝对分数、能力和安全。训练 loss 继续下降而生成平台或退化，就应停止。margin 不提供自然停止线，early stopping 是方法约束的一部分。 回滚门槛预先定义。硬安全失败、关键成功率跌破阈值或事实错误显著增加可立即回滚；普通偏好波动等待足够样本。看到结果后临时改标准，会让决策失去可复现性。 工具与环境变化要和模型变化分开。搜索索引、执行环境或 API 更新也会改变成功率。固定环境回归集与线上近期流量并列，判断问题来自 policy 还是外部状态。 部署量化可能改变边界 pair 排序。分别统计 $z$ 接近零的 sign flip、margin 残差变化与自由生成。平均 perplexity相近不足以保证偏好边界保持。

多 adapter 场景中，共享 base 更新会让旧 adapter 漂移。每个组合都需关键回归，路由规则与 adapter 版本一起记录。错误路由会表现为偏好退化，却与 SimPO 训练本身无关。 最终决策按层推进：先验证数值不变量，再检查离线结果与能力回归，随后检查独立生成与安全，满足这些条件后比较成本与用户偏好。基础故障存在时，后续汇总指标不具备发布意义。

### 20. 结论与参考资料

SimPO 把偏好 logit 写成当前策略两个回答的长度归一化 log probability差，再乘 $\beta$ 并减去 $\gamma$。这个目标短，核心选择却不少：用几何平均作为隐式 reward，去掉 reference 坐标，以软 margin延长边界附近的梯度，并依赖 SFT 起点与早停控制漂移。 长度归一化解决了序列总 log probability的直接长度累积，没有消除内容难度、tokenizer、EOS、模板和短回答方差。平均分是训练坐标，不是完整回答概率或真实偏好概率。任何超出这一边界的解释，都需要额外证据。 $\gamma/\beta$ 给出原始平均分空间的边界位置，$\beta$ 决定 logistic 温度与梯度尺度。二者共同调节，不能只扫一个。margin 也不在边界停止，更不会自动过滤噪声；它对错标 pair同样提高压力。

与 DPO 比较时，reference、sum/mean 和 margin 三项必须拆开；与 ORPO 比较时，还要考虑 odds 非线性与 chosen SFT。方法名相近不代表同一数值尺度。公平实验应在相同数据、起点、预算和实际漂移下比较。 最小可信证据链包括：逐 token 概率与 mask 可复算，完整 batch 与梯度手算一致，分布式切分等价，固定 pair 改善，未见 prompt 自由生成同步改善，长度反事实没有暴露捷径，关键能力与安全保持。任一环缺失，结论都应缩小范围。

多语言场景还要处理 tokenizer 造成的尺度差异。同一句含义在不同语言中可能对应完全不同的 token 数与切分粒度，平均 log probability虽然除以长度，token 本身却不是跨语言统一的信息单位。中文词组、英文子词、代码符号和数学公式的平均难度不同，同一组 $\beta,\gamma$ 未必给出相同强度。

评估时按语言报告 $s_w,s_l$、gap、有效 token长度与生成质量。若某语言 gap 普遍更小，可能来自偏好数据，也可能来自起点模型概率校准。直接为每种语言设置不同超参数会增加复杂度，应先检查数据质量、分词和 SFT 能力，再决定是否分域训练。

翻译 pair 不能默认保持偏好。原文中的简洁、礼貌、歧义和文化习惯经过翻译会变化，chosen 可能不再自然。保存原文与译文对应，抽查偏好翻转，并加入目标语言原生候选。只用机器翻译扩充数量，很容易让模型学习翻译腔。

代码回答的平均 token probability也受标识符与格式影响。常见库调用和样板代码容易获得高分，新颖但正确的算法可能包含低概率变量与结构。可执行测试必须先确定正确性，再在通过测试的集合中比较可读性、效率和解释。无法运行的流畅代码不能成为 chosen。

代码长度同样不等于复杂度。删掉错误处理与边界检查会让回答更短、更易预测，却降低可靠性。构造保留核心算法、逐步加入必要检查的反事实，观察 reward 是否错误惩罚完整实现。隐藏测试和资源限制负责验证实际价值。

数学推导中，最终答案正确不代表过程正确；语言模型也可能给常见结论很高分。应验证关键等式、前提与结论。把一个符号、否定词或约束条件改错而保持格式，检查 SimPO 模型能否降低该答案分数。若排序仍由流畅性决定，偏好数据需要更多内容敏感反例。

工具任务的平均分数混合了动作 token 与自然语言 token。工具名和参数往往格式固定、概率高，长解释含更多低概率内容。若全部一起平均，模型可能偏向快速调用工具，即使调用不必要。可以在评估中分别统计动作与文本分数；训练若改成分段加权，则属于目标变体，必须重新说明公式。

安全拒答通常短、模板稳定、平均概率高。偏好数据若总把拒答标为 chosen，SimPO 容易强化统一拒答。将恶意、良性敏感、边界和普通请求分开，构造只改变意图或权限的相邻反事实，检验模型是否依据风险条件，而非主题关键词。 安全硬门槛与帮助性需要同时评估。违规率下降但良性拒答激增，不是无条件改进。按风险等级报告拒答、正确帮助和解释质量，避免一个总安全分遮住过度防御。 概率校准也不能由 gap 代替。$s_w-s_l$ 大，只说明模型在自身平均 token 坐标中区分两项，不表示差值对应八成或九成的人类胜率。要研究校准，可在独立重复标注数据上把 gap 分桶，比较经验胜率，绘制 reliability curve。

margin 会改变这种曲线。训练倾向把边界附近 pair 推开，gap 的绝对值可能变大，却未必更接近人类概率。排序、margin 与概率校准是三个目标。需要可靠置信度时，应单独校准或使用概率建模目标，不能把 SimPO logit直接当选择概率。 best-of-n 场景关注排名最前端。整体 pair accuracy提高，可能主要来自容易样本，对 top candidates 的排序没有改善。评估应从同一候选集合计算 top-1 regret、选中可验证最优答案的比例，以及 $n$ 增大时收益曲线。

若 $n$ 增大后质量先升后降，说明 reward在尾部候选中存在可利用误差，搜索越多越容易找到高分坏答案。这是 reward overoptimization 的典型现象。SimPO 让训练分数与选择分数一致，会强化正确排序，也可能让模型更擅长利用自身分数漏洞；两面都要测。 候选由同一 policy 生成时，分数与样本相关。用 teacher forcing给外部候选打分，与从 policy 自身采样后排序的分布不同。分别评估自生成和跨模型候选，才能知道 reward是在识别一般质量，还是偏爱自身风格。 离线覆盖还影响 best-of-n。训练只见明显好坏，部署却从强 policy 产生一组质量接近的答案，pair 边界发生变化。迭代收集当前 policy 的 hard pairs 能缓解，但标注分歧也会上升。保留软投票比硬多数更能表达这种不确定性。

数据权重应对应部署目标，而非采集便利。聊天样本便宜、数量大，不能自然代表更高业务价值。先定义任务与风险权重，再设置 prompt group 采样。稀少关键任务可提高权重，同时保留权重上限与独立回归集。 若每条 pair 有权重 $w_i$，全局 loss 为

$$
L=\frac{\sum_iw_i\ell_i}{\sum_iw_i}.
$$

分布式训练聚合加权 sum 与权重和。直接除 batch size 会让权重总量改变梯度尺度；本地 mean 再平均会受 worker 组成影响。用手算 batch验证实现。 课程式训练也改变路径。先用清晰 pair 建立基本排序，再加入 hard pair，可能更稳定；先用困难冲突样本，早期大梯度会改变 Adam 状态。即使最终数据相同，有限学习率下也可能得到不同模型。 比较课程策略要对齐总 pair、token 与最终采样分布，并使用多个种子。早期收敛快不代表最终生成更好。若简单 pair 后期完全饱和，它们仍可作为格式与能力锚点，不一定全部删除。

训练恢复是复现的一部分。连续两步与“一步、保存、恢复、再一步”应读取相同样本，使用相同学习率和随机状态，并得到容差内相同更新。数据 cursor、shuffle 状态、scaler 或 scheduler 缺失都会破坏等价。 使用 dropout 与 activation checkpointing 时，重算前向必须复现随机 mask。否则保存的 forward 值与 backward 重算不一致。手算审计关闭随机性，大训练则记录 dropout 与随机状态。 FSDP、ZeRO 与词表并行需要验证 log-softmax。词表 shard 上必须聚合全局最大值和指数和，只做本地归一化会给目标 token错误概率，数值仍可能看似正常。抽取短样本与单卡全词表结果逐 token 对照。 混合精度 overflow 跳过 optimizer step时，scheduler 是否推进要明确。若学习率照常下降，实际更新预算减少。日志同时记录尝试 step、成功 update、处理 pair 与 token，跨实验按真实预算比较。

训练后的模型合并会改变 gap。两个 adapter 线性合并，logits 并不按相同比例线性变化，原本排序正确的边界 pair可能翻转。合并产物是新策略，必须重跑 fixed-pair、自由生成和安全评估。 量化误差对 $z\approx0$ 的样本尤其明显。统计 sign flip、loss 变化和长度分布，不能只看平均 perplexity。若部署使用量化模型，最终结论以部署精度为准，而非训练 checkpoint。 数据污染也会伪造收益。公开 benchmark 的题目、答案或改写可能进入偏好集，模型只需记住常见表达。按来源、时间、语义和解题结构去重。验证集反复用于超参选择同样形成开发泄漏，应保留一次性测试。

judge 泄漏更隐蔽。若同一模型生成标注、筛选数据并评估结果，SimPO 可能精确学习其偏好。加入另一 judge、人工评估或硬验证。只能使用同源评价时，结论限定为“更符合该评价器”。 标注位置偏差也要检查。随机交换左右展示并保存位置，估计相同内容的选择变化。若数据只存 chosen/rejected，原始位置丢失，无法事后校正。固定 anchor pair跨轮插入，还能检测标注尺度漂移。

多目标偏好不总能由一个标量表示。准确、简洁、安全和创造性可能冲突。保存分项理由与评分，报告各维度结果。业务若需要条件化风格，把用户意图放入 prompt，让模型在不同条件下学习不同排序；部署缺少该条件时仍只能得到混合平均。 非传递偏好可能是真实取舍，而非噪声。A 更准确、B 更简洁、C 更安全时，pair 比较会随关注点成环。删除环会抹掉多维结构。可以按 rubric 分图，或接受标量模型只能给出权重折中。 失败案例应从生成现象反查训练链。先确认 prompt 与解码，再寻找相似数据，检查标签、截断和模板，随后看 $s_w,s_l,z$ 与梯度。每一步都保留样本 ID 和版本，下一轮补数据才有针对性。

若模型生成过短，不能直接把最短训练 pair 删除。先看短 chosen 是否真的更好、EOS 是否正确、不同任务长度要求和短桶梯度。可能的修复包括补充完整长答案、长度匹配 pair、降低相关权重或改变目标；每种修复对应不同原因。 若生成过长，检查 chosen 数据是否普遍冗长、judge 是否偏爱详细、stop rule 是否变化，以及模型是否通过重复提高某些常见 token概率。长度归一化没有保证输出短，也没有保证输出长，数据和解码共同决定行为。 若事实性下降而风格胜率上升，说明评价信号偏向表达。提高事实验证权重、加入最小事实反例，并将硬正确率设为门槛。继续扩大 margin 只会更用力拟合现有标签，无法修正目标。

若不同基座上的方法排名翻转，按初始 gap、长度、SFT 能力和数据覆盖分桶。SimPO reward直接依赖当前模型分数，基座改变自然会改变梯度分布。算法没有脱离起点的固定排名。 完整实验记录最终应回答这些问题：回答分数如何聚合，EOS 与截断如何处理，$\beta,\gamma$ 对应什么尺度，pair 如何加权，标签冲突怎样保存，起点漂移多大，固定排序是否转化为新生成，长度与风格捷径是否被反例击穿，关键能力有没有回退。

理论结论、实验观察与部署外推要分开。loss 的梯度和 margin 几何可由公式证明；某个数据集胜率属于经验结果；未来用户分布的效果仍需线上验证。清楚区分三层，才能让 SimPO 的“简单”保持准确，而不变成过度承诺。

还可以从归一化常数的角度理解 reference-free 风险。自回归模型对每个位置都在词表上归一化，提高 chosen token 概率必然从其他 token取走质量，但 pair 数据没有说明应从哪里取。降低 rejected token也会把质量分给许多替代 token。局部 gap 改善并不唯一决定完整策略。

假设某个 prompt 只有 A、B、C 三个抽象答案，训练仅观察 A 胜 B。任何满足 $s_A-s_B$ 足够大的分布都可获得低 loss，C 的概率可能接近零，也可能占据大多数质量。真实语言模型的答案空间远大于三个，未观测自由度更多。SFT 初始化与有限更新选择其中一个解，却不提供理论唯一性。

这也解释了为何起点不同会改变结果。两个模型在训练 pair 上拥有相同 gap，候选外分布可能完全不同；经过相同 SimPO 更新后，自由生成仍会不同。算法比较要固定起点，跨基座结论只能说某种趋势，不能把最终胜率归因于 loss 单独决定。 策略漂移可以用多种量衡量。给定 policy 采样前缀，在每个位置对完整词表计算 token KL，再沿轨迹平均；也可用生成序列的 policy—SFT log-ratio估计正向 KL。两者采样分布与聚合不同，报告时写清前缀来自谁、按 token 还是序列。 使用数据集回答计算 log-ratio，并不等于 policy 分布下的 KL。它仍可作为固定坐标诊断 checkpoint，但不能声称精确测得理论 divergence。比较方法时所有模型采用同一估计口径即可，绝对解释要谨慎。

反向 KL 需要在 SFT 起点分布下取期望，关注 policy 丢失原有支持；正向 KL 在当前 policy 下，更关注新策略进入起点低概率区域。两者行为不同。SimPO 没有显式优化任一种 KL，评估可以同时观察，不能把其中一个当训练约束。 chosen 与 rejected 绝对分数还受模型整体校准影响。温度缩放 logits 会改变 token entropy 与平均 log probability，即使候选排序大体不变，SimPO gap 和最佳超参数也会变化。模型蒸馏、量化或 calibration 修改后，应重新查看 gap 分布。 若在训练前人为调整输出温度，$s_w-s_l$ 不会简单按同一常数缩放，因为 log-softmax 的归一化项依赖每个上下文。不能通过把 $\beta$ 反向缩放就保证目标等价。实际 token 分数重新计算最可靠。

position bias 与长度也可能耦合。长回答后部 token 的条件上下文更长，位置编码外推或 attention退化会降低概率；平均后仍体现为长答案较低分。按位置画 token NLL，检查差异是否主要集中在尾部。若超过训练上下文范围，问题属于模型能力与截断，不是简单长度偏差。 多轮历史很长时，即使只平均末轮 response，历史也会通过条件状态影响 token概率。chosen/rejected 共享历史可保证 pair 内公平，单轮与多轮样本之间的分数分布仍不同。按对话轮数分桶，避免某类数据长期处于高梯度区。 不同 prompt 难度也改变平均概率。SimPO 只比较同 prompt 的两项，难度公共成分部分抵消；参数梯度和 saturation仍受两侧绝对分数的 token Jacobian影响。不能跨 prompt拿 reward绝对值直接排名答案质量。

若做主动采样，优先使用同 prompt gap、重复投票不确定性和外部验证，而非单个答案的 $s$。低平均分可能只是专业术语或长上下文，并不等于低质量。用 $s$ 过滤会系统排斥模型不熟悉但正确的答案。 margin 选择可以从经验 gap 分布出发。训练前计算高质量 pair 的 $d=s_w-s_l$，查看正负比例和分位数；选择 $\gamma/\beta$ 使足够多样本处于有效梯度区，同时避免绝大多数永久错过边界。短程扫描再观察生成，而非只看训练 loss。 扫描时保持学习率与有效 batch合理。增大 $\beta$ 会增加边界曲率和初始梯度，若其他配置完全不变，数值稳定差异会混入目标比较。可以按初始梯度范数粗调学习率，再在相近漂移下选择。

曲线中 P50 超过 margin 不表示一半样本“完成”。logistic 梯度仍非零，共享参数也会让 gap来回移动。P10、P50、P90 与外部质量联合看，才能判断训练是否继续有价值。 样本 loss 的尾部要配合原因分类。高 loss 的事实真难例值得学习，高 loss 的主观 pair可能需要软标签，高 loss 的截断样本应清洗。统一 gradient clip只限制更新大小，不解决数据语义。 软标签可将 winner 概率 $q$ 写入交叉熵，而不是把多数票压成硬标签。对无 margin logistic，最优 logit是 $\log(q/(1-q))$；带 margin 时要明确正反标签各自如何放置 margin。若只在正类 logit减 $\gamma$，软标签公式需要重新推导，不能机械替换标签。

一种清楚方案是保留每次有序判断，正向样本用 $\beta d-\gamma$，反向样本用 $-\beta d-\gamma$，按投票频率平均。它正是前文期望损失，能忠实表达当前 margin 定义。直接写单个 soft BCE logit通常对应另一目标。 tie 若希望表达零 gap，也需要专门项，例如惩罚 $d^2$ 或同时加入正反记录。后者在非零 margin 下会把两向 loss都纳入，最优 gap为零，但最小 loss仍较高。这是预期的冲突成本，不应与普通 pair loss直接比较训练完成度。 绝对质量可以通过额外 SFT、可验证 reward 或拒绝采样加入。每一种都会改变纯 SimPO。组合目标报告各项未加权 loss、系数与梯度范数，防止某项因数值尺度占据全部更新。

加入 chosen SFT 后，模型更明确提高 winner 绝对似然，可能缓解两项共同下降，也会增强对错误 winner 的模仿。只有经过绝对门槛的数据才适合强 SFT。混合比例应通过消融确定。 加入 KL 到 SFT 起点后，reference-free 的训练优势部分消失，却获得显式漂移控制。是否值得取决于显存、缓存和风险要求。方法名称不重要，公式和约束才决定行为。 可验证 reward 与 pair preference可以分工。代码测试和数学答案提供硬结果，SimPO 处理多个正确方案间的表达。硬失败先淘汰，避免风格偏好覆盖正确性。若将 reward直接加进 logit，尺度也要校准。

评估失败案例时，最好保留模型完整采样分布，而不只看最终文本。重复生成、token entropy、stop概率与候选分数能解释过短、过度确定或模式收缩。只读一条输出很难判断系统性原因。 线上用户反馈还要考虑曝光策略。best-of-n 只展示最高分答案，其他候选永远没有反馈，训练数据条件于选择器。保留随机展示的小流量或离线盲评，才能估计被过滤候选的质量与选择偏差。 时间变化会让旧 pair 过期。软件版本、政策、事实与产品语气更新后，原 winner不再合适。保存时间与规范版本，固定原理样本长期保留，时效样本定期更新。冲突不总是标注噪声，也可能是目标演化。

隐私与许可属于数据边界。偏好 winner可能包含私人信息或受限文本，训练目标会提高其概率。进入训练前完成来源审计与脱敏，保留删除链路。loss 无法识别合法性。 最终复现包不必保存全部内部数据，也应提供 schema、预处理代码、手算样本、配置、版本指纹和聚合统计。无法公开的数据给出来源类别、长度、投票与过滤分布，让读者判断覆盖和偏差。 报告负结果同样重要。若某基座上 gap迅速增大而生成退化，说明自身分数不是可靠质量坐标；若长度反事实失败，说明 mean仍有捷径；若多种 $\gamma$ 都无收益，margin未解决当前瓶颈。这些边界能指导下一次选型。

因此，“简单”应落实为容易检查，而非省略检查。SimPO 公式只有几项，每一项都能手算、画分布、构造反例并在生成端验证。把这种可检查性用足，才是方法真正的工程和研究价值。 为了让结论能够跨实现复核，最终还应固定一组版本化探针。每条探针保存原始对话、token、mask、有效长度和期望中间量；覆盖长短反转、EOS、截断、多语言、工具观察、循环标签与高置信 pair。框架、kernel、tokenizer 或模板更新后，先跑探针，再比较大规模指标。 探针只负责数学语义一致，不替代真实任务。真实任务检验平均分是否抓住内容质量，反事实揭露长度与格式捷径，线上监控发现分布变化。三套证据分别回答“算得对”“学得对”和“上线后仍然对”。

若结果无法同时通过三层，报告应明确失败位置。例如 token 复算通过而长度反事实失败，说明实现正确、reward 偏置仍在；离线与反事实通过而线上退化，说明部署分布或反馈闭环发生变化。这样记录负结果，下一轮才能修改正确的层。

SimPO 最终提供的是一把直接的尺子：用当前模型对回答的平均 token log probability做相对比较，并要求 winner 超过 loser 一个软间隔。尺子越简单，数据与评价中的偏差越容易原样传入训练。把它当作可检验基线，而非自动成立的质量函数，才能用好这项方法。

复现验收可从 gap 分布的低、中、高三个区域各取样本。低 gap 样本检查错标、冲突和知识缺口，中间区域检查 margin 是否提供有效分辨率，高 gap 样本检查格式捷径与过度压低 rejected。同一批 prompt 再由目标 checkpoint 自由生成，用可见行为核对离线分数变化。

这一步还能防止平均指标掩盖两极分化：一部分简单 pair 被推得很远，另一部分关键任务仍然错排时，总体 loss 可能继续下降。按任务和风险查看三个区域，才能决定继续训练、补数据还是回滚。记录代表性失败及其修复方式，也让下一次模型升级不必重新猜测同一个问题。 SimPO 适合已有稳定 SFT 起点、偏好 pair质量高、希望减少 reference 成本并能严格监控长度的场景。数据充满双输、冲突和截断时，优先修数据；需要显式 trust region 时，reference-based 目标更直接；需要从预训练起点同时学格式时，带 chosen SFT 的目标更合适。 参考资料：
