# 偏好优化

## 补充视角 A：从比较数据到策略目标

偏好优化的原始观测通常以三元组 $(x,y_w,y_l)$ 出现：在提示 $x$ 下，回答 $y_w$ 胜过 $y_l$。它记录相对选择，没有直接给出标量奖励。Bradley–Terry 模型用潜在效用差解释比较概率：

$$
p(y_w\succ y_l\mid x)=\sigma\bigl(r(x,y_w)-r(x,y_l)\bigr).
$$

这个模型只能从差值识别奖励。给同一提示下所有回答的奖励加上任意常数，比较概率不变；数据若只包含局部比较，跨提示奖励尺度也没有被直接观测。因此，奖励模型输出的绝对数值不能跨数据集随意比较。训练真正使用的是排序和局部差值，标量刻度由模型参数化、正则与采样分布共同确定。

经典 RLHF 先拟合 $r_\phi(x,y)$，再求解带参考策略约束的优化问题：

$$
\max_\pi\ \mathbb E_{x\sim q,y\sim\pi}[r_\phi(x,y)]
-\beta\mathbb E_{x\sim q}D_{\mathrm{KL}}
\bigl(\pi(\cdot\mid x)\Vert\pi_{\rm ref}(\cdot\mid x)\bigr).
$$

对固定 $x$ 做变分优化，可得最优策略满足

$$
\pi^*(y\mid x)=\frac{1}{Z(x)}\pi_{\rm ref}(y\mid x)
\exp\left(\frac{r(x,y)}{\beta}\right).
$$

反解奖励差时，配分函数 $Z(x)$ 抵消。DPO 将这个差代回 Bradley–Terry 似然，用参数化策略直接拟合偏好。它消除了显式奖励模型与在线 RL 环节，参考策略、偏好模型假设和数据覆盖要求仍然存在。**直接偏好优化的「直接」，指从比较数据直接更新策略参数，中间的隐式奖励仍由策略相对参考模型的对数概率比表示。**

## 补充视角 B：参考策略与温度参数

参考策略提供相对坐标。策略提高某回答概率时，重要的量是相对参考模型增加了多少对数概率。若参考模型已强烈偏向某种回答，达到同一概率所需的隐式奖励差较小；若参考模型几乎不给某类回答概率，有限偏好数据很难把策略推到该区域。参考模型既是正则中心，也参与定义可学习的效用尺度。

$\beta$ 决定奖励单位和分布移动的交换率。较大 $\beta$ 使同样奖励差对应更小的对数概率变化，策略更贴近参考；较小 $\beta$ 放大偏好差，也放大奖励噪声。不同实验的 $\beta$ 还要结合损失是否对序列长度求和、参考 log probability 怎样计算以及数据中的胜负差异强度解读。

参考策略无法修复支持集之外的数据缺口。若数据里没有某种关键行为的正例，KL 正则只会把策略拉回已有模型分布。固定离线偏好优化尤其依赖数据采集策略：候选回答来自哪个模型、温度多高、同一提示有几个候选，决定训练能观察到哪些局部比较。

## 补充视角 C：序列概率与长度偏置

自回归回答的对数概率是 token 对数概率之和：

$$
\log\pi(y\mid x)=\sum_{t=1}^{|y|}\log\pi(y_t\mid x,y_{<t}).
$$

求和形式天然随长度累积。两个回答每个 token 的平均变化接近时，较长回答产生更大的序列 log-ratio。DPO、SimPO 与其他变体对长度归一化、margin 和参考项的不同处理，实质上改变了每个 token 对序列偏好的贡献。

设每个 token 的 log-ratio 均值为 $m$，长度为 $T$，则序列 log-ratio 约为 $Tm$。除以长度可降低线性放大，却会让短回答中单个关键 token 的影响更大。摘要、代码与开放问答对必要长度的要求不同，不存在脱离任务的统一归一化方式。判断长度偏置需要联合查看胜负回答长度分布、每 token log-ratio、生成长度和实际偏好胜率。

## 补充视角 D：成对似然的统计边界

Bradley–Terry 模型假设偏好可以由一维效用差表示，这会导出传递排序。真实偏好可能包含循环：回答 $a$ 更准确，$b$ 更简洁，$c$ 风格更好，不同标注者对维度权重不同，汇总后便可能出现 $a\succ b$、$b\succ c$、$c\succ a$。单一标量奖励只能寻找折中排序。

标签噪声也并非统一翻转概率。难例上的标注不一致更高，回答顺序、长度和格式会影响判断，群体之间还可能有系统差异。若把所有比较视为同等可靠，模型会过度拟合高噪声边界。软标签、多标注者模型与不确定性加权可以表达差异，但它们需要额外观测。

同一提示下的比较样本彼此相关。若从 $K$ 个候选构造 $K(K-1)/2$ 对，名义样本数平方增长，独立信息量却没有同步增长。训练和评测划分应按提示或候选集合切分，统计置信区间也应以提示为聚类单位，避免把高度相关的成对记录当作独立样本。

## 补充视角 E：离线目标与在线策略的距离

离线偏好数据由行为策略 $\mu$ 产生，训练后的策略为 $\pi_\theta$。当两者距离增大，策略会生成数据中从未比较过的回答，奖励或隐式偏好模型只能外推。训练对比准确率很高，也无法保证这些新区域的排序可靠。在线 RLHF 通过当前策略持续采样缓解分布陈旧，反馈回路也可能放大奖励漏洞。

迭代式偏好优化训练一轮策略，采样新候选，重新收集偏好，再更新策略。每轮数据更接近当前模型，同时需要防止只在局部做比较而丢失多样性。旧数据全部丢弃容易遗忘，全部等权则可能让早期弱策略样本占据过多权重；轮次加权本身就是目标设计的一部分。

评估偏好算法时，至少要分开看离线比较准确率、独立裁判胜率、人工偏好和能力基准。比较准确率衡量训练分布附近的排序拟合，生成胜率还受到解码与长度影响，能力基准检查偏好优化是否损害原有技能。单一指标无法覆盖这三个层面。

预训练语言模型学习语料中的 next-token distribution,这个目标不会自动区分“文本在人类数据中常见”和“回答符合用户意图”.同一个 prompt 可能对应事实准确、含糊、冗长、有害或拒绝回答的多种续写,预训练似然只反映数据分布中的出现方式.后训练因此引入另一类监督:人类或规则不必为每个 token 写出唯一正确目标,而可以比较若干完整回答,指出哪一个更符合帮助性、真实性、安全性或任务要求.

偏好反馈把问题从模仿单个示范改成调整回答之间的相对概率.经典 RLHF 先用比较数据训练奖励模型,再把语言模型视为策略,用 PPO 最大化奖励并通过 KL 惩罚限制其偏离参考策略.DPO 则从同一个 KL-regularized RL 目标出发,在特定偏好模型假设下消去显式奖励模型和在线 RL,直接对 chosen/rejected 的策略概率差做分类式优化.IPO、ORPO、SimPO 与 KTO 继续改变偏好建模、参考策略、margin、SFT 耦合方式或反馈形态.

本章沿着同一组偏好数据与分布约束的不同实现展开。“RLHF 被 DPO 取代”会掩盖真正的差异：不训练 reward model、不运行在线 rollout、不保存 reference model、不维护 value model，分别节省四种不同对象。**选算法前必须先定义反馈数据、策略对象、参考分布和训练期间是否重新采样。**

## 1. 数据和策略对象

### 1.1 Prompt、回答与偏好

用 $x$ 表示 prompt,$y=(y_1,\ldots,y_T)$ 表示完整回答,策略为自回归模型

$$
\pi_\theta(y\mid x)=\prod_{t=1}^{T}
\pi_\theta(y_t\mid x,y_{<t}).
$$

SFT 数据是 $(x,y^*)$,直接最大化示范回答的 token log-prob.成对偏好数据是 $(x,y_w,y_l)$,其中 $y_w\succ y_l$ 表示标注者在指定准则下选择 $y_w$.单回答二元反馈则是 $(x,y,z)$,$z$ 表示 desirable 或 undesirable.三种数据携带的信息不同:示范告诉模型“生成什么”,成对比较只给同一 prompt 下的相对次序,二元标签又缺少显式对照回答.

偏好不是回答的无条件属性.标注准则、prompt 分布、回答生成模型、采样温度和候选数量共同决定数据.如果两个候选都很差,chosen 只代表相对较好;如果两个候选几乎相同,标签噪声会变大.把不同来源数据混合时,应保留生成策略和标注协议,不能只存 chosen/rejected 文本.

### 1.2 四种策略角色

待训练策略记为 $\pi_\theta$.SFT 后的初始策略常记为 $\pi_{SFT}$.冻结参考策略记为 $\pi_{ref}$,用于定义 KL 或相对 log-ratio.在线 RL 中生成当前 rollout 的行为策略记为 $\pi_{old}$.它们可能从同一 checkpoint 初始化,功能却不同.

PPO 更新期间,$\pi_{old}$ 提供采样概率,重要性比修正新旧策略差异;$\pi_{ref}$ 则约束长期偏离.DPO 通常没有独立 rollout policy,训练数据已固定,但仍用 $\pi_{ref}$ 定义隐式奖励尺度.ORPO 与 SimPO 等方法可取消显式 reference forward,这只说明约束表达发生变化,不代表训练不再受 SFT 起点、固定数据或 margin 影响.

## 2. 从比较数据到奖励模型

### 2.1 Bradley–Terry 建模

奖励模型 $r_\phi(x,y)$ 把 prompt—回答映射为标量.常见成对模型写成

$$
P_\phi(y_w\succ y_l\mid x)
=\sigma\left(r_\phi(x,y_w)-r_\phi(x,y_l)\right),
$$

并最小化 chosen/rejected 的二元交叉熵.比较只约束奖励差,给所有回答奖励同时加常数不会改变概率.奖励数值不是客观效用单位,其尺度由数据、模型与训练过程决定.

Reward model 能为新采样回答打分,从而把有限人工比较扩展到大量在线 rollout.代价是模型会利用 reward model 的盲区.策略分布逐渐离开偏好数据覆盖区后,高预测奖励未必对应真实人类偏好.因此 RLHF 需要独立评测、KL 约束和对 reward hacking 的监控,而不能只追求训练 reward 上升.

### 2.2 标注与验证边界

偏好数据可以聚合多项标准,也可以分别训练帮助性或安全性信号.若标注者意见分歧,单一标签会丢掉不确定性.位置偏差、长度偏差、候选来源和标注模板都可能进入奖励模型.可靠实验应报告 agreement、数据过滤和 train/test prompt 分割.

可验证奖励与人类偏好也要区分.数学答案或代码测试能给出明确结果,却未必覆盖推理质量、表达与安全;人类偏好覆盖开放行为,但成本和噪声更高.本章重点是偏好优化,后续推理强化学习会处理验证器和组采样.

## 3. KL 正则化 RLHF

### 3.1 目标函数

给定奖励模型,典型策略目标可写为

$$
\max_\pi\;
\mathbb E_{x\sim\mathcal D,\,y\sim\pi(\cdot\mid x)}
\left[r_\phi(x,y)
-\beta\log\frac{\pi(y\mid x)}{\pi_{ref}(y\mid x)}\right].
$$

期望中的回答由当前策略采样,所以这是在线分布上的优化.$\beta$ 控制奖励改进与参考分布保持之间的交换.KL 项能抑制策略进入奖励模型缺少训练数据的区域,也会限制真实改进;它是正则项和分布锚点,不是安全保证.

语言模型奖励常在序列结束后给出,策略梯度却要更新每个生成 token.实现可把序列奖励与 token 级 KL 合成 shaped reward,再由 value model 估计 return 和 advantage.回答长度、EOS、padding mask 和 reward whitening 都会改变训练信号.相同公式在 token 求和与长度平均下不是相同目标.

### 3.2 PPO 流水线

[RLHF 训练流水线](./02.01-rlhf流水线/02.01-rlhf流水线.md)应先作为整体入口.一轮 PPO-based RLHF 至少包含 rollout policy 生成回答,reward model 打分,reference policy 计算 KL,value model 估计价值,GAE 构造优势,以及 policy/value minibatch 更新.训练器之外还有生成服务、权重同步和样本缓存.

PPO 使用新旧策略概率比与 clipped surrogate 限制单批数据上的过度更新,但 clip 不等同于 reference KL.前者控制 $\pi_\theta$ 相对 rollout policy $\pi_{old}$ 的局部更新,后者控制策略相对 $\pi_{ref}$ 的长期漂移.把两个 KL 角色混在一起,会误读超参数和诊断指标.

PPO 的主要代价来自多模型驻留和在线采样.优势是它能针对当前策略新产生的数据优化任意可计算奖励,并可持续探索;风险是 reward hacking、训练不稳定和系统复杂度.因此它仍是理解其他偏好方法的参照系.

## 4. DPO 如何消去显式 RL

### 4.1 从最优策略反解奖励

KL-regularized RL 目标的最优策略满足奖励与 policy/reference log-ratio 之间的关系.在 Bradley–Terry 模型中只使用奖励差,与 prompt 有关的配分函数会抵消.将奖励差替换为

$$
\beta\left[
\log\frac{\pi_\theta(y_w\mid x)}{\pi_{ref}(y_w\mid x)}
-
\log\frac{\pi_\theta(y_l\mid x)}{\pi_{ref}(y_l\mid x)}
\right]
$$

即可得到[DPO](./02.02-dpo/02.02-dpo.md)的偏好分类损失.训练只需固定比较数据和 policy/reference log-prob,不再单独拟合 reward model,也不在每步由当前策略 rollout.

DPO 的简洁建立在假设上:偏好遵循所用比较模型,数据能覆盖要改进的策略区域,reference 与 $\beta$ 给出合适锚点.离线数据可以多 epoch 复用,但过度优化会扩大 chosen/rejected gap,chosen 的绝对概率也不保证一直提高.DPO 仍受参考策略与偏好似然约束,其等价推导只覆盖满足相应假设的 KL 正则化 RL 目标.

### 4.2 概率口径

回答 log-prob 是有效 completion token 的和.有些实现按长度平均,会改变长短回答权重.$\beta$ 的数值只在相同求和或平均口径下可比较.聊天模板、EOS、padding mask 与 tokenizer 改变 token 序列后,预计算的 reference log-prob 也必须重新生成.

训练诊断应同时看 chosen 和 rejected 的 policy log-prob、相对 reference margin、准确率、长度分布与验证集行为.只看 loss 下降无法区分“提高 chosen”与“更快降低 rejected”.

## 5. DPO 之后的分叉

### 5.1 IPO 与有限 gap

[IPO](./02.03-ipo/02.03-ipo.md)从 $\Psi$-preference optimization 分析偏好目标,将 identity 作用于偏好概率,得到具有有限目标间隔的平方损失.它针对可分偏好数据上 DPO gap 持续扩大的问题.理解 IPO 时要核对目标常数中的 $\beta$,以及回答 log-prob 用求和还是平均.

IPO 仍使用成对数据和 reference-relative 差值.它改变偏好项的几何形状,不自动消除标签噪声、数据覆盖或 reference 选择问题.

### 5.2 ORPO 与 SimPO

[ORPO](./02.04-orpo/02.04-orpo.md)把 chosen 回答的 SFT loss 与 chosen/rejected odds-ratio loss 组合,在一个阶段同时维持示范似然和偏好分离,不需要冻结 reference model forward.其结果取决于 SFT 与 preference 项权重,odds 还会在概率接近边界时改变尺度.

[SimPO](./02.05-simpo/02.05-simpo.md)使用策略自身长度归一化的回答 log-prob,并设置目标 margin,同样取消显式 reference model.长度归一化适合控制长回答累积 log-prob 的尺度,也会改变对长度的偏好.选择 margin 与 $\beta$ 时必须与聚合口径一起调节.

### 5.3 KTO 与非成对反馈

[KTO](./02.06-kto/02.06-kto.md)面向 desirable/undesirable 单回答反馈,以 policy/reference log-ratio 构造隐式奖励,并用批次 KL 估计作为参考点.它不要求同一 prompt 同时拥有 chosen 与 rejected,适合反馈天然非成对的情况.

非成对数据仍需处理正负样本比例、权重、KL 估计和来源分布。KTO 与 DPO 的差别首先来自数据观测形式，不能只比较最终损失中的 sigmoid 写法。

## 6. 学习依赖与使用方式

先从[RLHF 训练流水线](./02.01-rlhf流水线/02.01-rlhf流水线.md)建立参照:明确 SFT policy、reward model、reference、value model 和 rollout policy 各自输入输出,并分开 PPO clip 与 reference KL.随后阅读[DPO](./02.02-dpo/02.02-dpo.md),沿 KL 正则目标、最优策略关系和 Bradley–Terry 模型完成推导,理解为什么显式 reward 与在线 rollout 能被离线分类损失替代.

在 DPO 基线上继续比较[IPO](./02.03-ipo/02.03-ipo.md)的有限 gap,[ORPO](./02.04-orpo/02.04-orpo.md)的 SFT 与 odds 耦合,[SimPO](./02.05-simpo/02.05-simpo.md)的 reference-free margin 与长度归一化,以及[KTO](./02.06-kto/02.06-kto.md)的非成对反馈.每次只改变一个设计轴:数据是成对还是单条,是否需要 reference,是否保留 SFT 项,log-prob 如何聚合,目标 gap 是否有界.

本章方法都依赖数据覆盖和评测.离线偏好优化成本较低,却不能从固定数据之外获得新行为证据;在线 RLHF 能随策略重新采样,却需要更复杂系统并暴露 reward hacking.可靠选择应绑定模型起点、偏好来源、序列长度、训练 token、reference 版本和独立评测,不能把某篇论文在特定 benchmark 上的胜负写成通用默认.
