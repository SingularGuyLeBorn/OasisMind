# Bellman 方程: 从回报递归到动态规划

MDP 定义 trajectory distribution，Bellman equation 利用 Markov property 把无限 future return 改写成 one-step reward 加 next-state value，并在相邻时刻之间建立同一个 value object 的 fixed-point relation。Environment model 已知且 state space 可枚举时，可以直接解线性方程或做 dynamic programming；model 未知时，Monte Carlo 与 Temporal Difference 用 sample 估计这些 expectation。 符号约定为 $n=|\mathcal S|$, $m=|\mathcal A|$, $V^\pi\in\mathbb R^n$, $Q^\pi\in\mathbb R^{n\times m}$. Reward 采用 $R(s,a)=\mathbb E[R_{t+1}\mid S_t=s,A_t=a]$, transition 为 $P(s'\mid s,a)$. 若 reward 显式依赖 $s'$, 只需把 $R(s,a)$ 改成 transition 内的 $R(s,a,s')$ 加权和.

## 1. 从 return 到 Bellman expectation

Bellman expectation equation 评估一个固定 policy. 它不选择更优 action, 只把当前 policy 在每个 state 上诱导的 future return 写成 one-step recursion. 推导中最重要的动作是连续两次使用全期望: 先按 policy 对 action 求和, 再按 environment 对 next state 与 reward 求和. 这一节同时保留 state value 与 action value. $V^\pi$ 适合写 matrix fixed point, $Q^\pi$ 则把第一步 action 固定下来, 后续 policy gradient,Actor-Critic 与 control algorithm 都会使用它. **1.1. Value,Q 与 advantage.** Return identity 为

$$
G_t=R_{t+1}+\gamma G_{t+1}.
\tag{1}
$$

固定 policy $\pi$, state value 与 action value 定义为

$$
V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s],
\tag{2}
$$

$$
Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].
\tag{3}
$$

Advantage 是

$$
A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s).
\tag{4}
$$

对固定 state, $V^\pi$ 是 action value 按 policy 的 expectation:

$$
V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a).
\tag{5}
$$

因此

$$
\sum_a\pi(a\mid s)A^\pi(s,a)=0.
$$

这个零均值关系后面会进入 policy gradient baseline 和 TRPO performance difference lemma. **1.2. Bellman expectation equation 逐步推导.** 从式 (2) 代入式 (1):

$$
V^\pi(s)
=\mathbb E_\pi[R_{t+1}+\gamma G_{t+1}\mid S_t=s].
\tag{6}
$$

先对 $A_t$ 使用全期望公式:

$$
V^\pi(s)
=\sum_a\pi(a\mid s)
\mathbb E[R_{t+1}+\gamma G_{t+1}
\mid S_t=s,A_t=a].
\tag{7}
$$

再对 next state $S_{t+1}$ 分层. Markov property 让 future return 在给定 $S_{t+1}=s'$ 后只由 $s'$ 与后续 policy 决定, 所以

$$
\mathbb E_\pi[G_{t+1}\mid S_t=s,A_t=a,S_{t+1}=s']
=V^\pi(s').
$$

代回式 (7):

$$
\boxed{
V^\pi(s)=\sum_a\pi(a\mid s)
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s')\right]
}.
\tag{8}
$$

括号内正是 $Q^\pi(s,a)$:

$$
\boxed{
Q^\pi(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s')
}.
\tag{9}
$$

再用式 (5) 消掉 $V^\pi(s')$:

$$
Q^\pi(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)
\sum_{a'}\pi(a'\mid s')Q^\pi(s',a').
\tag{10}
$$

式 (8)–(10) 是 expectation equation, 因为 action 按固定 policy 求 expectation. 它们做 policy evaluation, 没有在每个 state 选择最优 action. **1.3. 三层随机性怎样进入式 (8).** 式 (8) 外层的 $\pi(a\mid s)$ 来自 policy randomness, 内层的 $P(s'\mid s,a)$ 来自 transition randomness, $V^\pi(s')$ 又是从 next state 开始对所有 future trajectory 的 expectation. 如果 reward 本身在给定 $(s,a,s')$ 后仍随机, 更完整的形式是

$$
V^\pi(s)=\sum_a\pi(a\mid s)
\sum_{s',r}p(s',r\mid s,a)
\left[r+\gamma V^\pi(s')\right].
\tag{11}
$$

把 reward 先求条件期望, 才能得到正文使用的 $R(s,a)$ 形式. 两个公式描述同一个 expectation, 只是 joint kernel 版本保留了 reward distribution. Expected Bellman target 与 sampled target 也要区分. 已知 model 时, 式 (8) 枚举所有 $a,s'$ 得到精确 expectation. 与 environment 交互时只观察一个 $(a_t,r_{t+1},s_{t+1})$, target

$$
Y_t=r_{t+1}+\gamma V(s_{t+1})
$$

是对相应 Bellman quantity 的 sample estimate. 它可能高于或低于 expectation. Stochastic approximation 依靠许多 sample 和合适 update step 逼近 fixed point. **1.4. Reward 依赖 next state 时怎样写.** 有些 environment 的 reward 由到达哪里决定. 例如从同一 $(s,a)$ 出发, 到达 goal 给 $+5$, 滑回原地给 $-1$. 这时可以直接使用 joint kernel 形式式 (11), 也可以先定义

$$
R(s,a,s')=\mathbb E[R_{t+1}\mid s,a,s']
$$

再写

$$
Q^\pi(s,a)
=\sum_{s'}P(s'\mid s,a)
\left[R(s,a,s')+\gamma V^\pi(s')\right].
$$

如果改用 $R(s,a)=\sum_{s'}P(s'\mid s,a)R(s,a,s')$, 则

$$
Q^\pi(s,a)
=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s').
$$

两个口径等价, 前提是 expected reward 的 transition average 只做一次. 常见错误是在 transition sum 外写 $R(s,a,s')$, 让 $s'$ 在求和号外成为 free variable; 或者已经算出 $R(s,a)$ 后, 又给 reward 乘一次 transition probability. Reward timing 也要固定. 本文用 $R_{t+1}$ 表示执行 $A_t$ 并进入 $S_{t+1}$ 后收到的 reward. 有些 codebase 将它记为 $r_t$. Index 改名不会改变算法, 但 trajectory tuple,return 和 bootstrap target 必须同步, 否则很容易把 reward 与错误的 state transition 对齐. **1.5. Tower property 是递归成立的核心.** 令 $\mathcal F_t$ 表示时刻 $t$ 已知的信息，回报满足 $G_t=R_{t+1}+\gamma G_{t+1}$。条件期望的 tower property 给出

$$
\mathbb E[G_t\mid\mathcal F_t]
=\mathbb E[R_{t+1}+\gamma
\mathbb E[G_{t+1}\mid\mathcal F_{t+1}]mid\mathcal F_t].
$$

若 $S_t$ 是充分 Markov 状态，内层条件期望可写成 $V^\pi(S_{t+1})$，外层只需对当前状态动作诱导的下一步分布积分。Bellman 递归依赖的是条件充分性，不是时间序列天然拥有的代数性质。 状态遗漏时，$\mathbb E[G_{t+1}\mid\mathcal F_{t+1}]$ 不能缩成只依赖观测 $O_{t+1}$ 的函数。强行拟合 $V(O)$ 得到历史混合平均，写出的观测级 Bellman 方程通常不闭合。加入 belief、循环 hidden state 或必要历史，是为了恢复这个闭合条件。 tower property 还解释多步 backup。对 $n$ 步递归展开：

$$
V^\pi(S_t)=\mathbb E_\pi\left[
\sum_{k=0}^{n-1}\gamma^kR_{t+k+1}
+\gamma^nV^\pi(S_{t+n})\mid S_t
\right].
$$

一步、$n$ 步和完整 Monte Carlo 在真实价值下具有同一期望，有限样本方差和近似 bootstrap 偏差不同。若中途发生真终止，尾项消失；时间截断则保留条件价值。 **1.6. Reward timing 影响下标而非机制.** 有的教材把 $R_t$ 定义为进入 $S_t$ 时获得的奖励，有的使用 $R_{t+1}$ 表示从 $(S_t,A_t)$ 转移后的奖励。两种约定都可行，混用会产生一位偏移。应先写联合核 $p(s',r\mid s,a)$，再由它定义期望即时奖励。 若 reward 依赖转移三元组，

$$
r(s,a)=\sum_{s',r}p(s',r\mid s,a)r,
$$

Bellman 方程仍可写成 $r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')$。但当 reward 与 $S'$ 条件相关时，采样方差分析不能把二者当独立随机变量。联合采样 target $R+\gamma V(S')$ 自动保留协方差。 状态奖励 $r(s)$、动作奖励 $r(s,a)$ 和转移奖励 $r(s,a,s')$ 可以相互扩展状态表示，但参数共享与方差不同。将转移奖励提前成状态奖励，往往要把上一动作或上一状态并入当前状态。形式等价不代表学习难度和表示成本等价。

## 2. Linear system,fixed point 与 policy evaluation

固定 policy 后, Bellman expectation operator 是 affine map: reward 提供常数项, transition matrix 传播 next-state value. Finite MDP 因而可以直接解 linear system, 也可以从任意初值反复 backup. 两种方法求的是同一个 fixed point, 差别只在数值计算路径. 这一节先把 action dimension 按 policy average 掉, 得到 $P_\pi$ 与 $r_\pi$; 再证明 operator 是 contraction, 最后对三状态例子既做 linear solve 又做 iterative evaluation. Matrix shape 与逐 state equation 会逐项对齐. **2.1. Matrix form.** 对固定 policy 定义 expected reward vector $r_\pi\in\mathbb R^n$:

$$
r_\pi(s)=\sum_a\pi(a\mid s)R(s,a),
$$

以及 policy-induced transition matrix $P_\pi\in\mathbb R^{n\times n}$:

$$
P_\pi(s,s')=\sum_a\pi(a\mid s)P(s'\mid s,a).
$$

式 (8) 写成

$$
V^\pi=r_\pi+\gamma P_\pi V^\pi.
\tag{12}
$$

移项:

$$
(I-\gamma P_\pi)V^\pi=r_\pi.
$$

在 finite discounted MDP 中, $\gamma<1$ 保证 $I-\gamma P_\pi$ 可逆:

$$
V^\pi=(I-\gamma P_\pi)^{-1}r_\pi.
\tag{13}
$$

显式 inverse 适合小问题与推导, 大 state space 通常通过 iterative update 或 linear solver 求解. 定义 Bellman expectation operator

$$
(\mathcal T^\pi V)(s)=
\sum_a\pi(a\mid s)
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')\right].
$$

它在 sup norm 下是 $\gamma$-contraction:

$$
\|\mathcal T^\pi V-\mathcal T^\pi U\|_\infty
\le\gamma\|V-U\|_\infty.
\tag{14}
$$

原因是 probability weights 非负且和为 1, 加权差的绝对值不会超过最大的 component difference. 所以 fixed point 唯一, 从任意有限 $V_0$ 反复执行 $V_{k+1}=\mathcal T^\pi V_k$ 都收敛到 $V^\pi$. **2.2. Contraction inequality 展开.** 固定 state $s$, 定义 $\Delta=V-U$. Reward 项在两个 operator 中完全相同, 相减后抵消:

$$
\begin{aligned}
&|(\mathcal T^\pi V)(s)-(\mathcal T^\pi U)(s)|\\
={}&\gamma\left|
\sum_a\pi(a\mid s)\sum_{s'}P(s'\mid s,a)\Delta(s')
\right|.
\end{aligned}
$$

使用 triangle inequality:

$$
\le\gamma\sum_a\pi(a\mid s)
\sum_{s'}P(s'\mid s,a)|\Delta(s')|.
$$

每个 $|\Delta(s')|\le\|V-U\|_\infty$, 而 action probability 与 transition probability 的加权和为 1, 所以

$$
|(\mathcal T^\pi V)(s)-(\mathcal T^\pi U)(s)|
\le\gamma\|V-U\|_\infty.
$$

再对 $s$ 取 maximum 就得到式 (14). 这个证明同时解释了 reward 为什么不影响 contraction coefficient: 比较同一 MDP 上的两个 value input 时, reward 在 operator difference 中消失. $\gamma$ 决定误差从 next state 传回当前 state 时最多保留多少. 由 contraction 可直接得到 iteration error bound:

$$
\|V_k-V^\pi\|_\infty
\le\gamma^k\|V_0-V^\pi\|_\infty.
\tag{15}
$$

这是 worst-case upper bound, 实际收敛可以更快. 当 $\gamma$ 接近 1, bound 下降很慢, long-horizon reward 也更容易让 value error 传播很多步. **2.3. 同一个 MDP 的 policy evaluation.** 沿用上一节三状态环境, $\mathcal S=\{A,B,T\}$, $\gamma=0.5$. Policy 为

$$
\pi(\texttt{quit}\mid A)=0.25,
\quad
\pi(\texttt{go}\mid A)=0.75,
$$

$$
\pi(\texttt{cash}\mid B)=0.5,
\quad
\pi(\texttt{loop}\mid B)=0.5.
$$

Terminal value 为 0. 在 $B$ 上使用式 (8):

$$
\begin{aligned}
V^\pi(B)
&=0.5\times4
+0.5\times\left(1+0.5V^\pi(B)\right)\\
&=2.5+0.25V^\pi(B).
\end{aligned}
$$

所以

$$
0.75V^\pi(B)=2.5,
\qquad
V^\pi(B)=\frac{10}{3}\approx3.3333.
\tag{16}
$$

在 $A$ 上:

$$
\begin{aligned}
V^\pi(A)
&=0.25\times1.5
+0.75\times\left(0+0.5V^\pi(B)\right)\\
&=0.375+0.375\times\frac{10}{3}
=1.625.
\end{aligned}
\tag{17}
$$

这与枚举所有可能 loop 次数的 trajectory expectation 相同. Bellman recursion 把 infinite trajectory sum 收进了式 (16) 的 self-reference. 对应 matrix 为

$$
P_\pi=
\begin{bmatrix}
0&0.75&0.25\\
0&0.5&0.5\\
0&0&1
\end{bmatrix},
\qquad
r_\pi=
\begin{bmatrix}
0.375\\2.5\\0
\end{bmatrix}.
$$

$V^\pi=[1.625,10/3,0]^\top$ 代入式 (12) 可以逐行复核. 若直接用 matrix equation, 第二行是

$$
V(B)=2.5+0.5\times0.5V(B),
$$

第一行是

$$
V(A)=0.375+0.5\times0.75V(B)+0.5\times0.25V(T).
$$

这里 $P_\pi[A,B]=0.75$ 表示在 $A$ 按 policy 选择 `go` 后到达 $B$ 的 probability; `quit` 的 $0.25$ probability 进入 $T$. Reward vector 已经对 action 求过 expectation, 所以第一行不能再把 `quit` reward 重复加一次. **2.4. Linear system 完整手算.** 按 state 顺序 $(A,B,T)$, 有

$$
I-\gamma P_\pi
=\begin{bmatrix}
1&-0.375&-0.125\\
0&0.75&-0.25\\
0&0&0.5
\end{bmatrix}.
$$

Linear equation $(I-\gamma P_\pi)V=r_\pi$ 从最后一行向上解. 第三行给

$$
0.5V(T)=0\quad\Longrightarrow\quad V(T)=0.
$$

第二行给

$$
0.75V(B)-0.25V(T)=2.5
\quad\Longrightarrow\quad
V(B)=\frac{2.5}{0.75}=\frac{10}{3}.
$$

第一行给

$$
V(A)-0.375V(B)-0.125V(T)=0.375,
$$

所以

$$
V(A)=0.375+0.375\times\frac{10}{3}=1.625.
$$

每个 coefficient 都能回到 policy 与 transition. $-0.375=-\gamma P_\pi[A,B]=-0.5\times0.75$; $0.75=1-\gamma P_\pi[B,B]=1-0.5\times0.5$. Matrix solve 没有引入新的 RL 假设, 只是一次性联立所有 Bellman expectation equation. **2.5. Iterative policy evaluation 逐轮数值.** 不做 linear solve, 从 $V_0=(0,0,0)$ 同步更新也会到同一 fixed point. 第一轮:

$$
V_1(B)=2.5+0.25V_0(B)=2.5,
$$

$$
V_1(A)=0.375+0.375V_0(B)=0.375.
$$

第二轮:

$$
V_2(B)=2.5+0.25\times2.5=3.125,
$$

$$
V_2(A)=0.375+0.375\times2.5=1.3125.
$$

第三轮:

$$
V_3(B)=2.5+0.25\times3.125=3.28125,
$$

$$
V_3(A)=0.375+0.375\times3.125=1.546875.
$$

$B$ 的 scalar recursion 为 $V_{k+1}(B)=2.5+0.25V_k(B)$. Fixed point 是 $10/3$, error 每轮精确乘 $0.25$. $A$ 的更新读取上一轮 $B$, 因而慢一拍传播. General contraction bound 使用全局 $\gamma=0.5$, 给出较宽但对所有 MDP 都成立的 upper bound; 这个具体 policy 的有效 self-loop coefficient 更小, 所以实际收敛更快. **2.6. Inverse 的 Neumann series 解释.** 式 (13) 的 inverse 可以展开为

$$
(I-\gamma P_\pi)^{-1}
=I+\gamma P_\pi+\gamma^2P_\pi^2+\cdots.
$$

因为 stochastic matrix $P_\pi$ 的 spectral radius 不超过 1, $\gamma<1$ 时 series 收敛. 代入 reward vector:

$$
V^\pi
=r_\pi+\gamma P_\pi r_\pi
+\gamma^2P_\pi^2r_\pi+\cdots.
$$

第一项是当前 state 的 expected one-step reward; 第二项先按 policy transition 一步, 再取 next-state reward; 第 $k$ 项是 $k$ 步后的 expected reward. Matrix inverse 因而不是一个没有 RL 含义的代数技巧, 它把所有 future reward propagation 一次求和. 截断到前 $K$ 项就得到有限次 iterative evaluation 的展开. Tail norm 可由 geometric series 控制:

$$
\left\|\sum_{k=K}^{\infty}
\gamma^kP_\pi^kr_\pi\right\|_\infty
\le\frac{\gamma^K}{1-\gamma}\|r_\pi\|_\infty.
$$

这个 bound 使用 $\|P_\pi^k r\|_\infty\le\|r\|_\infty$. 当 $\gamma$ 接近 1, 要让 tail 很小需要更大的 $K$, 与 long effective horizon 的直觉一致. 条件数决定线性求解对误差的敏感度。
矩阵形式 $(I-\gamma P_\pi)V=r_\pi$ 给出了精确解，也暴露数值敏感性。令 $A=I-\gamma P_\pi$，若奖励向量存在扰动 $\Delta r$，解的变化满足

$$
A\Delta V=\Delta r,qquad
\frac{\lVert\Delta V\rVert}{\lVert V\rVert}
\le\kappa(A)
\frac{\lVert\Delta r\rVert}{\lVert r\rVert},
$$

其中 $\kappa(A)=\lVert A\rVert\lVert A^{-1}\rVert$ 是条件数。$\gamma$ 接近一、链存在缓慢混合模式时，$A$ 会接近奇异，奖励或转移的小误差被显著放大。求解器残差很小不等于价值相对误差一定小，还要结合条件数。 直接求逆通常不如解线性方程。显式形成 $A^{-1}$ 增加计算与舍入误差；稀疏 MDP 可以用迭代求解器只调用矩阵—向量乘。预条件器改变谱结构以加快收敛，却不改变原方程的解。比较「动态规划迭代」与「线性求解」时，应按矩阵稀疏度、精度目标和可利用结构计算成本。

转移矩阵的特征值解释收敛速度。$P_\pi$ 的特征值模不超过一，迭代误差满足 $e_{k+1}=\gamma P_\pi e_k$。最坏收缩率是 $\gamma$，具体初始误差若很少投影到慢特征方向，实际可能更快。只报告理论上界会过于悲观，只报告一个初值的快速曲线又可能隐藏慢模式。 加权范数与状态访问分布需要一起确定。
sup norm 给出与状态分布无关的最坏界，却可能由几乎不可达状态主导。实践中的回归 loss 常按采样分布 $\mu(s)$ 加权：

$$
\lVert f\rVert_\mu^2=\sum_s\mu(s)f(s)^2.
$$

Bellman 算子在该范数下不一定是收缩，尤其当 backup 把误差从低权重状态搬到高权重状态。On-policy 平稳分布、折扣占用与 replay 分布给出不同几何，训练 loss 相同并不代表控制性能相同。 若训练分布对目标占用有覆盖，$d^\pi(s)\le C\mu(s)$，则目标分布误差可以由训练误差乘 $C$ 控制。$C$ 很大时，平均回归误差几乎没有决策保证；某个在 replay 中罕见却位于最优路径上的状态，能支配最终性能。

优先级 replay 按 TD error 增加高残差样本概率，改变的正是这个加权范数。若用重要性权重完全校正，可以恢复原采样目标但增加方差；不完全校正则有意优化另一个加权投影。优先级不是纯粹的数据加载技巧，它参与定义近似固定点。 Krylov solver 只需要矩阵—向量乘。
求解 $(I-\gamma P_\pi)V=r$ 时，状态数大到无法存储稠密矩阵，但可以计算 $P_\pi v$，便可使用 Krylov 子空间方法。第 $k$ 轮在

$$
\mathcal K_k(A,r)=\operatorname{span}{r,Ar,A^2r,\ldots,A^{k-1}r}
$$

中寻找近似解。每个基向量对应更深一层的转移传播，与 Neumann series 的多步解释相呼应。 共轭梯度要求矩阵对称正定，而一般 $I-\gamma P_\pi$ 不对称，不能直接套用；GMRES 等方法适用于一般线性系统。把 normal equation $A^\top Ax=A^\top r$ 后再用共轭梯度，会把条件数平方，可能恶化数值精度。 预条件器 $M^{-1}$ 让 $M^{-1}A$ 的谱更集中。Jacobi 预条件只用对角项，便宜但忽略状态耦合；基于局部子图或多尺度状态聚合的预条件能捕捉慢传播结构，构造成本更高。预条件改变迭代路径，不改变精确固定点。

迭代求解停止时应同时看线性 residual $r-AV$ 与控制所需误差。条件数很大时，小 residual 仍可能对应较大解误差；另一方面，解误差若只集中在目标策略不访问的状态，对当前 $J(\pi)$ 影响可能很小。数值线性代数指标与决策分布指标应共同报告。 Fundamental matrix 统计访问次数。
折扣 fundamental matrix

$$
Z_\pi=(I-\gamma P_\pi)^{-1}
=\sum_{t=0}^{\infty}\gamma^tP_\pi^t
$$

的元素 $Z_{ij}$ 表示从状态 $i$ 出发，对状态 $j$ 的期望折扣访问次数。价值 $V=Zr$ 因而是每个状态奖励按未来访问次数加权。 奖励对价值的导数直接为

$$
\frac{\partial V(i)}{\partial r(j)}=Z_{ij}.
$$

某状态奖励的微小误差影响哪些起点，由可达性和访问频率决定。全局 reward scale 只给粗上界，fundamental matrix 能定位具体传播路径。 转移参数的灵敏度也可由隐函数求导。若 $P=P(\xi)$，

$$
\frac{\partial V}{\partial\xi}
=Z\left(\frac{\partial r}{\partial\xi}
+\gamma\frac{\partial P}{\partial\xi}V\right).
$$

括号内是局部模型变化，左乘 $Z$ 把它传播到所有前驱。这个公式用于模型校准、环境参数优化和影响分析，也清楚展示两次 horizon 放大的来源。 Successor representation 拆分动力学与奖励。
若奖励可写成特征线性形式 $r(s)=\phi(s)^\top w$，固定策略价值为

$$
V^\pi(s)=\mathbb E_\pi\left[
\sum_{t=0}^{\infty}\gamma^t\phi(S_t)\mid S_0=s
\right]^\top w.
$$

定义 successor feature

$$
\psi^\pi(s)=\mathbb E_\pi\left[
\sum_{t=0}^{\infty}\gamma^t\phi(S_t)\mid S_0=s
\right],
$$

便有 $V^\pi(s)=\psi^\pi(s)^\top w$。$\psi$ 编码策略与动力学造成的未来访问，$w$ 编码奖励偏好。环境和策略不变、奖励权重改变时，可以复用 successor feature 快速评估新任务。 $\psi$ 自身满足向量 Bellman 方程

$$
\psi^\pi(s)=\phi(s)+\gamma
\mathbb E_{S'\sim P_\pi}[\psi^\pi(S')].
$$

successor representation 把标量奖励替换为特征向量，每个特征维度传播其折扣访问次数。特征若无法线性表示新奖励，复用会产生表示误差；策略改变后，旧 $\psi^\pi$ 也不再对应新占用。 generalized policy improvement 同时保存多个旧策略的 successor feature，对新奖励计算各自 $Q$，再逐状态选择最高动作。即使没有重新训练完整模型，也能组合已有技能。保证依赖价值近似误差与新任务奖励确实位于共享特征空间。 语言模型中，可以把正确性、长度、格式和工具成本视为奖励特征，但这些特征可能依赖整条序列，不是当前状态的简单向量。把 history 或自动机状态扩入 MDP 后仍可使用相同思想，代价是 successor 表示需要覆盖更大状态。

## 3. Bellman optimality 与 policy improvement

Policy evaluation 回答「给定 $\pi$ 会得到多少 return」, optimality 则问「所有可选 policy 中哪一个最好」. 在 finite discounted MDP 中, one-step action 后的 future 可以再次按 optimal value 计算, 因而 global control problem 仍能写成 recursive equation. 从 expectation 到 max 不是一个排版替换. Operator,data requirement 与 error propagation 都随之改变. 本节先定义 optimal value, 再证明对 exact $Q^\pi$ 做 greedy improvement 不会降低任何 state 的 value. **3.1. Bellman optimality equation.** Optimal state value 定义为

$$
V^*(s)=\max_\pi V^\pi(s).
\tag{18}
$$

在 finite discounted MDP 中, 存在 deterministic stationary optimal policy. 若 next-state optimal value 已知, 当前 state 选择让 one-step return 最大的 action:

$$
\boxed{
V^*(s)=\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^*(s')\right]
}.
\tag{19}
$$

Optimal action value 为

$$
\boxed{
Q^*(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)
\max_{a'}Q^*(s',a')
}.
\tag{20}
$$

式 (19) 的 `max` 替换了式 (8) 中按 $\pi$ 的 action expectation. 这一步改变了 operator: $\mathcal T^\pi$ 评估固定 policy, $\mathcal T^*$ 寻找 optimal fixed point, 因而任务从 policy evaluation 转向 control. 是否属于 off-policy 还取决于采样行为: 当 data 由 behavior policy 生成、target 却按 greedy policy 的 action max 计算时, 才是 off-policy control, Q-learning 就是典型例子. 如果样本始终来自当前 target policy, 仅看到 `max` 还不能推出离策略. Optimal Bellman operator 同样是 $\gamma$-contraction:

$$
(\mathcal T^*V)(s)=\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')\right].
$$

利用 $|\max_a f_a-\max_a g_a|\le\max_a|f_a-g_a|$, 可得

$$
\|\mathcal T^*V-\mathcal T^*U\|_\infty
\le\gamma\|V-U\|_\infty.
\tag{21}
$$

因此 $V^*$ 是唯一 fixed point. **3.2. Policy improvement theorem.** 为什么对 $Q^\pi$ greedy 会得到不差于 $\pi$ 的 policy? 定义

$$
\pi'(s)\in\arg\max_aQ^\pi(s,a).
$$

由 maximum 不小于 policy average:

$$
Q^\pi(s,\pi'(s))
=\max_aQ^\pi(s,a)
\ge\sum_a\pi(a\mid s)Q^\pi(s,a)
=V^\pi(s).
\tag{22}
$$

左侧等于 $(\mathcal T^{\pi'}V^\pi)(s)$. 因而

$$
V^\pi\le\mathcal T^{\pi'}V^\pi.
$$

继续应用 monotone operator $\mathcal T^{\pi'}$:

$$
V^\pi
\le\mathcal T^{\pi'}V^\pi
\le(\mathcal T^{\pi'})^2V^\pi
\le\cdots.
$$

右侧收敛到 $\mathcal T^{\pi'}$ 的 unique fixed point $V^{\pi'}$, 所以

$$
V^{\pi'}(s)\ge V^\pi(s),\qquad\forall s.
\tag{23}
$$

若某个状态 $s$ 上 inequality 严格，且从所讨论的起点按 $\pi'$ 有正概率在有限时间到达 $s$，新 policy 在该起点才有严格改进；不可达状态上的严格优势不会改变这个起点的 value。若只讨论逐状态结论，则该状态自身作为起点已经满足可达条件。这条 theorem 支撑 policy iteration, 但依赖 exact $Q^\pi$. 用 noisy critic 做 approximate greedy 时, estimation error 可能选错 action, monotonic improvement 不再自动成立. **3.3. Action gap 决定 approximate greedy 是否稳.** 定义当前 policy value 下最优 action 与次优 action 的 gap:

$$
\Delta_\pi(s)=Q^\pi(s,a_{(1)})-Q^\pi(s,a_{(2)}).
$$

若 approximate critic 满足每个 action 的 absolute error 不超过 $\epsilon$, 两个 action 的 estimated difference 最多被扭曲 $2\epsilon$. 当 $\Delta_\pi(s)>2\epsilon$ 时, greedy ranking 在该 state 不会被这组误差翻转; gap 很小时, 很小 critic error 就能选到另一个 action. 例如 true action values 为 $(2.0,1.9)$, gap 为 $0.1$. 若第一项 estimate 偏低 $0.06$, 第二项偏高 $0.06$, estimates 变成 $(1.94,1.96)$, greedy action 被翻转. Policy improvement theorem 对 true $Q^\pi$ 仍成立, 但实现使用的是 wrong ranking. 这也是为什么只看 critic mean squared error 不够. 相同 MSE 若集中在 large-gap state, policy 可能不受影响; 若集中在 small-gap,high-occupancy state, 很多 action choice 会改变. Control evaluation 应同时观察 action agreement,advantage sign 与 state visitation weight. **3.4. Stochastic improvement 与 entropy.**

Exact greedy improvement 产生 deterministic policy, 在多个 action tie 时任取其一. 有些算法使用 soft improvement, 例如让新 policy 对较大 $Q$ 分配更高 probability, 同时保留 entropy. 这时求解的是加入 entropy regularization 的 objective, 对应 Bellman operator 会出现 log-sum-exp 或 policy entropy 项. Soft operator 仍可以有自己的 contraction 与 fixed point, 但 fixed point 不等于式 (19) 的 unregularized $V^*$. Temperature 趋近 0 时 softmax 才接近 hard max. 将 entropy bonus 加入训练而在论文公式里仍写普通 Bellman optimality, 会把两个 objective 混在一起. 大模型 RL 中 entropy,KL-to-reference 与 reward 经常同时存在. 它们都影响 optimal policy, 作用却不同: entropy 鼓励单个 state 下 action distribution 分散, reference KL 鼓励 policy 接近指定基座, environment reward 定义 task preference. Bellman target 若要容纳这些 regularizer, 必须明确它们按 token,sequence 还是 trajectory 聚合. **3.5. Approximate value 会带来多大 policy 损失.** 设 approximate value $\widetilde V$ 满足

$$
\|\widetilde V-V^*\|_\infty\le\epsilon,
$$

并令 $\widetilde\pi$ 对 $\widetilde V$ 做 one-step greedy. 对任一 state-action, next-state value error 经过 transition expectation 与 discount 后最多为 $\gamma\epsilon$. 比较两个 action 时, 最优 action 可能被低估 $\gamma\epsilon$, 被选 action 可能被高估 $\gamma\epsilon$, 所以 one-step optimality gap 最多为 $2\gamma\epsilon$. 这个局部 gap 在后续执行 $\widetilde\pi$ 时递归传播. Discounted sum 给出经典形式的 performance bound:

$$
\|V^*-V^{\widetilde\pi}\|_\infty
\le\frac{2\gamma}{1-\gamma}\epsilon.
$$

它是 worst-case bound, 不要求每个 state 都真的达到最大误差. 但系数 $1/(1-\gamma)$ 再次说明 long horizon 会放大 value approximation 对 policy 的影响. 只报告 critic loss, 不把它换算到 action gap 或 policy quality, 很难判断误差是否重要. 如果训练 data 只覆盖部分 state, uniform $\epsilon$ 往往无法成立. 可以在 occupancy-weighted distribution 下讨论平均误差, 结论会依赖 policy 访问哪些 state. Offline setting 中 target policy 走出 behavior coverage 后, 这种 weighted guarantee 也可能失效. 最优算子的不可微点来自动作并列。
最优 Bellman 算子含有 $\max_aQ(s,a)$。当唯一最优动作具有正 action gap 时，小价值扰动不会改变 argmax，算子局部表现为对应确定策略的线性 Bellman 算子。两个动作并列时，max 在交界处不可微，小扰动便可能切换贪心动作。

这解释了策略不稳定与价值稳定可以同时出现。两个动作价值只差 $10^{-5}$，价值误差很小，argmax 却在训练批次间反复切换；若两动作后续行为差异大，数据分布也会随之跳动。报告 value loss 时同步查看 action gap 与策略切换率，才能判断误差是否跨越决策边界。 softmax backup

$$
V_\alpha(s)=\alpha\log\sum_a\exp(Q(s,a)/\alpha)
$$

把不可微 max 平滑化，其与 max 的差满足 $0\le V_\alpha-\max_aQ_a\le\alpha\log|\mathcal A|$。平滑带来可控偏差，并让多个近优动作获得梯度。动作数很大时，$\log|\mathcal A|$ 仍会影响误差尺度。 Performance difference lemma 连接局部优势与总体改进。
任意两策略 $\pi,\pi'$ 的性能差可以写成

$$
J(\pi')-J(\pi)=\frac{1}{1-\gamma}
\mathbb E_{s\sim d^{\pi'},a\sim\pi'}[A^\pi(s,a)].
$$

若对所有状态都有 $\mathbb E_{a\sim\pi'}A^\pi(s,a)\ge0$，策略改进定理立即成立。实际算法只在旧策略占用 $d^\pi$ 下估计优势，右侧却需要新策略占用 $d^{\pi'}$。二者差距构成局部 surrogate 与真实改进之间的误差。 令 $\epsilon=\max_s|\mathbb E_{a\sim\pi'}A^\pi(s,a)|$，再用新旧策略总变差控制占用差，可以得到「代理收益减去策略移动惩罚」形式的下界。TRPO 的信任域思想来自这里。只提高旧分布上的优势而不限制策略变化，无法保证新分布进入的状态同样有正优势。 这个引理还揭示离线策略选择的困难。数据来自行为策略 $\mu$，若候选策略 $\pi'$ 会访问 $d^\mu$ 几乎没有质量的状态，优势估计没有支持。保守策略改进限制 occupancy 或动作 ratio，牺牲潜在收益以换取可评估性。

多个最优策略会引出 tie-breaking 问题。
最优价值函数唯一，不代表最优策略唯一。若多个动作在状态 $s$ 同时达到 $Q^*(s,a)=V^*(s)$，任意只在这些动作间随机化的策略都最优。实现中的 argmax 通常按索引选择第一个动作，因而引入无关但可复现的 tie-breaking。

数值误差会把理论并列变成微小差异。若下游关心公平性、负载或动作切换成本，应显式定义次级目标，而非依赖浮点顺序。词典序优化先保证主要回报最优，再在最优集合中优化成本；加一个很小的惩罚近似该目标，但惩罚多小才不改变主要最优集合取决于 action gap。 最优集合也影响模仿与蒸馏。教师始终选某个并列动作，学生选择另一个时，action mismatch 很高但 return 不变。用教师动作准确率评价会错误惩罚等价策略；应结合 $Q^*$ gap、环境结果和次级约束。 策略混合的价值具有非线性。
令 $\pi_\lambda=(1-\lambda)\pi_0+\lambda\pi_1$。即时奖励与转移核对 $\lambda$ 线性，但

$$
V^{\pi_\lambda}=(I-\gamma P_{\pi_\lambda})^{-1}r_{\pi_\lambda}
$$

含矩阵逆，因此通常不等于 $(1-\lambda)V^{\pi_0}+\lambda V^{\pi_1}$。每步随机混合策略会产生两策略都没有的交错轨迹，不能用整条 episode 先抛硬币选择一个策略的价值代替。 沿混合方向的导数可由 performance difference 或隐函数求导得到。它依赖当前混合策略的访问分布与动作优势，所以优势会随 $\lambda$ 改变。只在 $\lambda=0$ 处估计一阶改进，无法保证沿整个线段单调。 部署中的流量分配常是 episode 级 A/B，而策略优化中的随机策略是每个状态重新采样动作。二者边缘动作比例可能相同，轨迹相关结构不同。实验说明「混合比例」时必须指出混合发生在用户、episode、状态还是 token 层。 Conservative policy update 可以给出解析下界。
考虑混合更新 $\pi_\alpha=(1-\alpha)\pi+\alpha\pi'$。小 $\alpha$ 限制 occupancy 改变。若旧占用下代理优势

$$
L=\mathbb E_{s\sim d^\pi,a\sim\pi'}[A^\pi(s,a)]
$$

为正，而最大优势绝对值为 $\epsilon$，可推导真实改进至少是线性收益 $\alpha L/(1-\gamma)$ 减去与 $\alpha^2\epsilon$ 及 horizon 有关的分布漂移项。二次项来自策略改变后访问状态变化。 这个结构说明保守步长为何有效：在一阶收益可靠时，足够小的 $\alpha$ 可让线性项压过二次误差。优势估计有噪声时，还应为 $L$ 减去置信下界；若下界不为正，不应声称保证改进。 固定混合系数并非总合理。action gap 大且估计确定的状态可更大胆更新，gap 小或数据少的状态应保守。状态依赖步长会改变策略类与分析，但更贴合不确定性分布。 Potential shaping 在特定条件下保持最优动作。
定义塑形奖励

$$
F(s,a,s')=\gamma\Phi(s')-\Phi(s).
$$

一条轨迹上的折扣塑形和为

$$
\sum_{t=0}^{T-1}\gamma^tF_t
=-\Phi(S_0)+\gamma^T\Phi(S_T).
$$

无限时域且 $\Phi$ 有界、$\gamma<1$ 时，尾项趋零；给定起点后总回报只减去与动作选择无关的常数。于是

$$
Q_F^\pi(s,a)=Q^pi(s,a)-\Phi(s),
$$

所有动作同时平移，argmax 保持不变。有限 episode 需要处理终点势函数；若不同终点 $\Phi(S_T)$ 不同且尾项未消失，塑形可能改变策略排序。 塑形能够加速价值传播。例如稀疏迷宫只在终点给奖励，以到目标的启发式负距离作势函数，可以让中间转移立即获得方向信号。启发式即使不精确，只要严格采用势差形式，仍保持最优策略；随意给「靠近目标」加正分则未必具备该保证。 状态动作势函数和非平稳势也有推广，但必须相应修改策略提取或把时间并入状态。把任意过程奖励都称为 potential shaping，会误用不变性结论。最直接的检查是把整条折扣和展开，看中间项能否望远镜抵消。

## 4. Value iteration 与 policy iteration

Bellman optimality equation 给出 fixed point, dynamic programming 决定怎样求它. Value iteration 每轮做一次 optimal backup; policy iteration 则在完整 evaluation 与 greedy improvement 之间交替. 两者都假设 model 已知,state-action 可枚举, 只是把计算量放在不同位置. 三状态例子能够把每一轮完整列出. 它还展示一个重要现象: 改善下游 state 后, 上游 action 的优劣才会变化. Policy improvement 需要反复 evaluation, 因为 action 的长期价值取决于后续 policy. **4.1. Value iteration 手算.** Value iteration 直接反复应用 optimal Bellman backup:

$$
V_{k+1}(s)=\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V_k(s')\right].
\tag{24}
$$

令 $V_0(A)=V_0(B)=V_0(T)=0$. 第一轮:

$$
V_1(A)=\max(1.5,0+0.5V_0(B))=1.5,
$$

$$
V_1(B)=\max(4,1+0.5V_0(B))=4.
$$

第二轮:

$$
V_2(A)=\max(1.5,0+0.5\times4)=2,
$$

$$
V_2(B)=\max(4,1+0.5\times4)=4.
$$

第三轮仍得到 $(2,4,0)$, 所以这个小环境已经到 fixed point:

$$
V^*(A)=2,\qquad V^*(B)=4,\qquad V^*(T)=0.
$$

Greedy policy 在 $A$ 选 `go`, 在 $B$ 选 `cash`. `loop` 的持续 policy value 是 $1/(1-0.5)=2$, 低于立即 `cash` 的 4. 一般问题不会两轮精确结束. Contraction 给出误差持续按至多 $\gamma$ 缩小的依据, stopping criterion 可以观察 $\|V_{k+1}-V_k\|_\infty$, 再结合所需 value 或 policy 精度设置 threshold. **4.2. Residual 与 value error.** Bellman residual 定义为

$$
\varepsilon_k=\|\mathcal T^*V_k-V_k\|_\infty
=\|V_{k+1}-V_k\|_\infty.
$$

利用 contraction 与 triangle inequality:

$$
\begin{aligned}
\|V_k-V^*\|_\infty
&\le\|V_k-\mathcal T^*V_k\|_\infty
+\|\mathcal T^*V_k-\mathcal T^*V^*\|_\infty\\
&\le\varepsilon_k+\gamma\|V_k-V^*\|_\infty.
\end{aligned}
$$

移项得到

$$
\|V_k-V^*\|_\infty
\le\frac{\varepsilon_k}{1-\gamma}.
\tag{25}
$$

所以同样的 residual 在 $\gamma=0.99$ 时对应更宽的 value-error upper bound. 只报告 iteration 次数而不报告 $\gamma$ 与 stopping criterion, 无法比较两个 value iteration 实验的精度. **4.3. Policy iteration 手算.** Policy iteration 在两个操作之间交替:

1. **Policy evaluation**: 求当前 $\pi_k$ 的 $V^{\pi_k}$.
2. **Policy improvement**: 对每个 state 选择

$$
\pi_{k+1}(s)\in\arg\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^{\pi_k}(s')\right].
\tag{26}
$$

取初始 deterministic policy $\pi_0(A)=\texttt{quit}$, $\pi_0(B)=\texttt{loop}$. Evaluation 得到

$$
V^{\pi_0}(A)=1.5,
\qquad
V^{\pi_0}(B)=1+0.5V^{\pi_0}(B)=2.
$$

第一次 improvement:

$$
Q^{\pi_0}(A,\texttt{quit})=1.5,
\quad
Q^{\pi_0}(A,\texttt{go})=0.5\times2=1,
$$

所以 $A$ 暂时保持 `quit`. 在 $B$,

$$
Q^{\pi_0}(B,\texttt{cash})=4,
\quad
Q^{\pi_0}(B,\texttt{loop})=1+0.5\times2=2,
$$

所以改成 `cash`. 新 policy $\pi_1$ 的 evaluation 是 $V^{\pi_1}(A)=1.5$, $V^{\pi_1}(B)=4$. 第二次 improvement 在 $A$ 比较

$$
Q^{\pi_1}(A,\texttt{quit})=1.5,
\quad
Q^{\pi_1}(A,\texttt{go})=0.5\times4=2,
$$

于是改成 `go`. 得到 $\pi_2(A)=\texttt{go}$, $\pi_2(B)=\texttt{cash}$, 再 improvement 不变, algorithm 结束. 这个例子展示了 policy iteration 为什么可能需要多轮. 第一轮评价中 $B$ 仍由差 policy 控制, 所以从 $A$ 前往 $B$ 看起来不划算. 先改善 $B$ 后重新评价, `go` 的长期价值才显现出来. Policy iteration 在 finite MDP 中每次严格改进都会换到一个更好的 deterministic policy, 而 deterministic stationary policy 的数量有限, 所以 exact 版本会在有限次改进后停止. 这个结论不代表每次 evaluation 便宜. 解 linear system 的代价会随 state 数增长, sparse structure 与 iterative evaluation 在大问题中十分重要. Tie 也需要固定规则. 多个 action 的 $Q$ 完全相同时, improvement 若每轮任意切换 tie action, policy 表面上会变化但 value 不变. 实现可以保留当前 action 或使用 deterministic tie breaking, 让 termination detection 稳定. **4.4. 两种 iteration 的关系.**

Policy iteration 每轮把当前 policy 评估到 fixed point, 再做 greedy improvement. Value iteration 每次只做一次 optimal backup, 可以看作截断 policy evaluation 与 immediate improvement 的组合. 前者 iteration 较少但单轮 evaluation 更贵; 后者单轮便宜, 可能需要更多轮. Modified policy iteration 处于两者之间: 每次 improvement 前只执行有限轮 evaluation. 这说明它们不是彼此无关的算法, 区别在于每次 greedy update 前把当前 value 解到多精确. 二者在这里都要求完整 environment model $P,R$, 并遍历 state-action space. State 数量巨大或 continuous 时, exact table backup 不可行, 需要 sampling 与 function approximation. Monte Carlo 用完整 sample return 估计 value; TD 用 $R_{t+1}+\gamma V(S_{t+1})$ bootstrap; Q-learning 把式 (20) 的 max 放入 sample target. 它们共享 Bellman object, 估计方式和 data distribution 不同. **4.5. Finite-horizon backward induction.** 若 episode 最多剩 $H-t$ 步, value 还依赖 time:

$$
V_t^\pi(s)=\sum_a\pi_t(a\mid s)
\left[R_t(s,a)+\gamma\sum_{s'}P_t(s'\mid s,a)V_{t+1}^\pi(s')\right].
\tag{27}
$$

给定 terminal condition $V_H(s)$，可以从 $t=H-1$ 一直向前算到 0。Optimal recursion 将 action expectation 换成 max，在 time-indexed sequence 上做 backward induction。把剩余时间加入 augmented state 后，也能重新写成 Markov form。 Finite horizon 下, 同一个物理 state 在不同 $t$ 可能选择不同 action. 临近 episode 结束时, 一个需要多步才获得 reward 的 action 可能来不及兑现. 如果数据有 time limit, critic 输入却不含剩余时间, 它会把不同 future opportunity 的 sample 压成同一个 value. **4.6. Synchronous,asynchronous 与 in-place update.**

正文的 value iteration 使用 synchronous update: 先用完整旧 vector $V_k$ 计算所有 state 的 $V_{k+1}$, 再整体替换. In-place update 则在遍历 state 时立刻写回新值, 后面的 state 可能读取同一轮刚更新的结果. 两者的逐轮数值不同, 在适当访问条件下都可收敛到相同 fixed point. 三状态例子若先更新 $B$, 再更新 $A$, 第一轮 in-place update 得到 $V(B)=4$, 随后 $V(A)=\max(1.5,0.5\times4)=2$, 一次 sweep 就达到 optimal value. 若先更新 $A$ 再更新 $B$, 第一轮仍是 $(1.5,4)$. 因此报告 iteration 数时还要说明 update order 与 synchronous/in-place 口径. Prioritized sweeping 进一步优先更新 Bellman residual 大或影响很多 predecessor 的 state. 它不改变 Bellman equation, 只改变计算资源投向哪里. Sparse transition graph 中, 一个 state value 改变后只需通知实际 predecessor, 无需每轮扫描所有 state. Parallel accelerator 更适合 synchronous batch backup, CPU sparse solver 可能偏好 asynchronous update. 算法选择不仅由理论 iteration count 决定, 还取决于 state graph,memory layout 与可并行性. **4.7. 一轮 backup 的计算量.**

Dense tabular transition 中, 计算一个 $(s,a)$ 的 next-state expectation 要遍历 $n$ 个 state, 完整 optimal sweep 大约需要 $O(n^2m)$ 次标量运算. Transition graph 若每个 action 只有 $d$ 个非零 successor, sparse sweep 可降到 $O(nmd)$. 三状态例子里的 transition deterministic, 每个 action 只有一个 successor. Policy iteration 的 exact evaluation 若用通用 dense linear solver, 粗略代价随 $n^3$ 增长; iterative evaluation 每个 sweep 利用 sparse transition, 可以提前停止. 因此「policy iteration 轮数少」不等于 wall-clock 一定更低, 还要算每轮 evaluation 精度与 model sparsity. Memory 也可能成为瓶颈. Dense $P$ 的 shape 是 $[n,m,n]$, state 数大时无法存储. Simulator 能按需 sample next state, 却不能直接提供所有 successor probability, algorithm 就从 exact dynamic programming 进入 sample-based RL. Value iteration 的 stopping threshold 若设得过严, 可能花大量计算改善不会改变 greedy action 的小数位. Action gap 较大时, value 还有一定 error 也能得到正确 policy; gap 很小时则需要更精确 evaluation. 实际 solver 可以同时观察 Bellman residual 与 greedy policy 是否稳定. **4.8. Stochastic transition 的逐轮手算.** 再看一个只有 nonterminal state $U$ 与 terminal $T$ 的环境. 在 $U$ 可选 `stop` 或 `try`. `stop` 以 probability 1 进入 $T$, reward 为 0. `try` 有 $0.6$ probability 进入 $T$ 并得 3, 有 $0.4$ probability 留在 $U$ 并得 $-1$. 取 $\gamma=0.9$. 对任意 value estimate $V_k(U)$,

$$
Q_k(U,\texttt{stop})=0,
$$

$$
\begin{aligned}
Q_k(U,\texttt{try})
&=0.6\times(3+0.9V_k(T))\\
&\quad+0.4\times(-1+0.9V_k(U))\\
&=1.4+0.36V_k(U).
\end{aligned}
$$

Terminal value 为 0. 从 $V_0(U)=0$ 开始做 value iteration:

| $k$ | `stop` | `try` backup | $V_{k+1}(U)$ |
|---:|---:|---:|---:|
| 0 | 0 | 1.400000 | 1.400000 |
| 1 | 0 | 1.904000 | 1.904000 |
| 2 | 0 | 2.085440 | 2.085440 |
| 3 | 0 | 2.150758 | 2.150758 |

如果 `try` 保持最优, fixed point 满足

$$
V^*(U)=1.4+0.36V^*(U),
$$

所以

$$
V^*(U)=\frac{1.4}{0.64}=2.1875.
$$

该值为正, 因而确实高于 `stop` 的 0, 假设自洽. 这里 reward 与 next state 相关, 计算时必须在每个 transition branch 内先写 $r+\gamma V(s')$, 再按 probability 加权. 如果先把 reward 误写成无条件 3 或 $-1$, fixed point 会变成另一个问题. 从误差看, recursion coefficient 是 $0.36=0.4\times0.9$. 只有失败并留在 $U$ 的 branch 会把 old value 带回当前 state, 所以实际 error 每轮乘 $0.36$, 比 global contraction upper bound $0.9$ 紧得多. 这个例子说明 transition structure 会让局部收敛速度优于只看 $\gamma$ 的 worst-case 判断. 随机 horizon 可以用吸收概率解释。
有限时域通常显式把剩余时间写进状态。另一种构造是在每一步以概率 $1-\gamma$ 终止，以概率 $\gamma$ 继续，并对未折扣奖励求和。若终止事件与环境转移独立，则

$$
\mathbb E\left[\sum_{t=0}^{T-1}R_{t+1}\right]
=\mathbb E\left[\sum_{t=0}^{\infty}\gamma^tR_{t+1}\right].
$$

折扣回报因此可以解释为几何随机 horizon 下的未折扣回报。这个解释要求每步独立终止；业务会话的真实终止通常依赖状态和动作，不能简单等同于固定 $\gamma$。 状态依赖 survival probability $c(s,a,s')$ 会得到 transition-based discount：

$$
V(s)=\mathbb E[R_{t+1}+c(S_t,A_t,S_{t+1})V(S_{t+1})\mid S_t=s].
$$

只要沿任意长期路径的 continuation product 足够衰减，递归仍可能有唯一解。把所有 $c$ 压成单个 $\gamma$ 会丢掉不同终止风险，尤其在失败吸收和成功吸收概率差异很大的任务中。 Modified policy iteration 构成一条连续谱。
policy iteration 每轮把当前策略评估到收敛，再做一次贪心改进；value iteration 每次只做一步最优 backup。Modified policy iteration 在二者之间：对当前策略做 $m$ 次评估 sweep，再改进策略。$m=1$ 接近 value iteration，$m\to\infty$ 恢复精确 policy iteration。 增加 $m$ 能减少贪心时的评估误差，却使每轮策略改进更贵。早期策略离最优较远时，精确评估一个很差的策略可能浪费计算；后期 action gap 很小时，更精确评估可避免错误切换。动态调整 $m$ 比固定极端方案更符合误差结构。

广义策略迭代把 evaluation 与 improvement 看成两个并行过程。它们不必各自完成才交替：critic 朝当前策略价值移动，actor 同时朝 critic 的贪心策略移动。Actor-Critic 正是这种不完全交替。稳定性取决于两个过程时间尺度；actor 变化过快，critic 追逐移动目标，评估误差会进入改进步骤。

Gauss–Seidel、优先级 sweeping 都依赖更新顺序。
同步 value iteration 用上一轮完整向量计算下一轮。Gauss–Seidel 更新立即使用本轮已经写入的新值。在有向无环任务中，逆拓扑顺序一次 sweep 就能得到精确价值；相反顺序需要多轮传播。循环 MDP 中没有全局拓扑序，更新顺序仍能显著改变有限预算收敛速度。 prioritized sweeping 维护 predecessor 关系，把 Bellman residual 大的状态及其前驱优先入队。它利用「价值变化沿反向转移传播」的结构，避免均匀扫描大量无变化状态。优先级只说明当前模型下可能有大更新，若 transition model 漏掉前驱，关键信号不会进入队列。

异步收敛通常要求每个状态被无限次更新，使用的信息延迟有界，并保留压缩条件。实际分布式系统若热点状态频繁更新、冷门状态长期饥饿，训练 loss 可以下降但全局固定点条件未满足。记录每个状态族或任务桶的更新覆盖，比只看总 backup 数更可靠。 Stopping criterion 可以从 residual 推出 value bound。
value iteration 常在 $\lVert V_{k+1}-V_k\rVert_\infty<\epsilon$ 时停止。相邻迭代差和到固定点的误差不是同一个量。利用压缩性可得

$$
\lVert V_k-V^*\rVert_\infty
\le\frac{\lVert TV_k-V_k\rVert_\infty}{1-\gamma}.
$$

因此 $\gamma=0.99$ 时 residual $10^{-3}$ 只保证 value error 不超过约 $0.1$。目标 action gap 若更小，这个精度仍不足以保证贪心策略正确。 策略损失还会再经过一次放大。若 $\lVert V-V^*\rVert_\infty\le\delta$，对 $V$ 的贪心策略通常可得到与 $\delta/(1-\gamma)$ 同阶的性能界。长 horizon 任务要从策略容忍误差反推 residual 阈值，不能沿用短 horizon 的固定数字。 采样环境无法计算全状态 sup residual，只能估计样本分布下 residual。独立验证状态集、模型可用时的精确 backup，以及针对稀有高风险状态的覆盖测试应当并用。训练 TD loss 达到阈值，只是所采数据上的停止条件。

Finite horizon 策略通常依赖时间。
剩余一步时只关心即时奖励，剩余很多步时可以承担短期代价换长期收益。因此有限 horizon 的最优策略一般写成 $\pi_t(a\mid s)$。若只用平稳策略 $\pi(a\mid s)$，等于限制策略类，可能失去最优性。 把时间 $t$ 或剩余预算 $H-t$ 加入状态，可以把非平稳策略改写成扩展状态上的平稳策略。代价是状态数乘以 horizon，跨时间共享需要函数逼近。语言模型生成中的剩余 token 预算同样影响策略：靠近上限时应收束答案，预算充足时可以继续验证。 backward induction 从终点条件 $V_H(s)$ 开始：

$$
V_t(s)=\max_a\mathbb E[R_{t+1}+V_{t+1}(S_{t+1})\mid s,a].
$$

这里无需折扣也能良定义，因为递归只有有限层。终点价值若代表未完成任务的 salvage value，需要显式给出；一律设零相当于声明 horizon 后所有状态等价。 滚动时域控制每次只规划未来 $H$ 步，执行第一步后重新规划。它能利用新观测，却可能短视：目标收益始终位于窗口外时，策略永远不愿承担准备成本。terminal value approximation 用较长程价值补偿窗口边界，其误差会影响每次重规划。 Anderson acceleration 利用残差历史。
普通 fixed-point iteration 只用当前 $V_k$ 计算 $TV_k$。Anderson acceleration 保存最近若干残差 $F(V_i)=TV_i-V_i$，选择线性组合使组合残差尽量小，再生成下一迭代。对近线性问题，它能近似 Krylov 加速；对非线性最优算子，动作切换会让局部模型改变。

加速不自动保持 Bellman 单调性。线性组合系数可能为负，使价值越过上下界；max 算子的不可微点附近还可能振荡。damping、系数正则和残差回退用于保护稳定性。若加速候选 residual 变差，退回普通 backup 是可检查的安全条件。 多步 lookahead 是另一种加速：对动作树向前展开 $h$ 层，再用当前价值 bootstrap。模型准确时，它把奖励更快传播；分支因子使计算指数增长，近似搜索又引入选择偏差。MCTS 用选择性展开分配预算，得到的是搜索增强策略，不等同于完整 $T^hV$。

Multigrid 处理不同时间尺度。
局部 Bellman backup 很快消除高频误差，跨大区域缓慢变化的低频误差传播较慢。multigrid 把状态聚合到粗尺度，在粗图上快速传播全局修正，再插值回细尺度。这个思想适合网格控制与具有层级结构的状态空间。 粗状态必须近似保留奖励与转移。若把动力学截然不同的状态聚合，粗修正会把错误同时传播到许多细状态。restriction、coarse operator 和 prolongation 的选择决定加速是否保持原固定点。 层级价值与 option 也可看作时间尺度上的粗化：高层 backup 跨越多个底层步。它改善长程传播，但需要正确的持续时间折扣与 option 终止模型。少算几层并不免费，复杂度转移到了抽象构造。 单调上下界可以给出可认证停止。
若已知 $L_0\le V^*\le U_0$，最优 Bellman 算子的单调性保证

$$
T^kL_0\le V^*\le T^kU_0.
$$

奖励有界 $R_{\min}\le r\le R_{\max}$ 时，可以取常数界 $L_0=R_{\min}/(1-\gamma)$ 与 $U_0=R_{\max}/(1-\gamma)$。上下序列间距按压缩率收缩，提供直接 value 误差证书。 若某状态动作的下界已高于其他动作上界，该动作可以被认证为最优，无需等待所有 value 达到统一高精度。action gap 大的状态会较早确定，计算可集中到仍有歧义的状态。启发式搜索中的 admissible heuristic 与区间 value iteration 都利用这种结构。 浮点舍入可能破坏严格上下界。需要 outward rounding 或为数值误差留余量；否则打印出的「认证区间」可能并不包含真实值。采样 backup 也不能直接提供确定界，需结合置信区间，并为同时覆盖多状态动作做概率校正。 区间重叠只表示当前证据不足，不表示动作真实等价。反过来，区间分离依赖模型、奖励界与置信假设正确。认证结论应连同失败概率和覆盖范围报告。

## 5. Termination,sampling 与 approximation 边界

前四节的收敛结论建立在 finite state-action,stationary Markov dynamics,exact expectation 与 $\gamma<1$ 上. 实际任务会逐项放松这些条件: observation 可能不是 state, episode 可能被 time limit 截断, model 只能从 sample 学, value 还要由 neural network 近似. 这些变化不意味着 Bellman target 失效, 而是 fixed-point proof 不能原样搬过去. 需要区分目标 equation,sample estimator 与 function approximator 三层: equation 定义想求的对象, estimator 决定 bias/variance, approximator 决定可表示范围与 optimization error. **5.1. Markov,discount 与 termination.** 第一, Bellman fixed point 依赖 Markov state. Observation 丢失 history 时, 用 $V(o)$ 近似 value 可能出现 state aliasing, 同一个 observation 对应不同 hidden state 与 future return. 第二, $\gamma<1$ 的 contraction 是 discounted continuing case 的核心条件. Finite horizon 可以把剩余时间并入 state, 得到 time-dependent value $V_t(s)$ 并从终点 backward induction. Average-reward continuing task 则需要另一套 Bellman equation, 不能直接把 $\gamma$ 设成 1 后沿用全部结论. 第三, Bellman optimality equation 假设 reward 与 transition 已经定义. Reward misspecification 下, 求得的 policy 可能精确优化错误目标. Distribution shift 下, $P_{\mathrm{train}}$ 的 optimal value 也未必对应 deployment environment. **5.2. Termination 与 truncation 的 bootstrap mask.** 设 sample transition 包含 termination flag $d_t$ 与 truncation flag $u_t$. True termination 表示 MDP 进入 terminal, 标准 discounted target 为

$$
Y_t=R_{t+1}+\gamma(1-d_t)V(S_{t+1}).
$$

Time-limit truncation 只表示 collector 不再记录, environment 的 future 仍可能存在. 如果 objective 对应 continuing task, $u_t=1,d_t=0$ 时通常仍应 bootstrap. 把 `done = termination OR truncation` 直接乘成 0, 会系统性低估靠近 time limit 的 value. 另一种定义是把 time limit 本身当作 environment termination. 那么 remaining time 必须进入 state 或 task specification, terminal 后 future value 的确为 0. 两种处理都可成立, 取决于想解哪个 MDP; 错误来自训练 target 与 evaluation task 使用不同定义. Sequence generation 中 EOS 类似 true termination, max-length cutoff 更接近 truncation. 如果超过长度本身应受惩罚, cutoff 可以带 terminal penalty; 如果只是显存限制, critic 可能需要对 unfinished sequence bootstrap. 直接把两者都标成 EOS 会改变 length preference. **5.3. Sampling,max 与 function approximation.**

第四, function approximation, off-policy sampling 与 bootstrap 同时出现时可能不稳定. Tabular contraction proof 不会自动转移到 nonlinear neural network. DQN 使用 target network, replay 与其他稳定化机制, 正是在处理从 exact operator 到 approximate stochastic update 后出现的问题. 第五，action max 会产生 selection bias。用 noisy $Q$ estimate 同时选择和评价最大 action，最大值更容易挑中正噪声。Double Q-learning 一类方法将 action selection 与 evaluation 部分分开，以处理这项 overestimation mechanism。偏差发生在有限 noisy estimate 近似 max expectation 的过程中，Bellman optimality equation 使用真实期望时没有这项采样偏差。 第六, model-based backup 的误差会递归传播. 如果 learned transition model 在某类 state-action pair 上偏差很大, value iteration 可能反复利用这个虚假 transition, 产生 model exploitation. 增加 rollout depth 并不必然更准; horizon 越长, model error 能影响的后继越多. **5.4. Bellman error 的三种来源.** Neural critic 的 total error 可以按概念拆成三类. **Approximation error** 来自 function class 无法表示 true value; **estimation error** 来自 finite sample 与 distribution coverage; **optimization error** 来自 loss 没有被训练到当前 function class 中的最佳点. 增加 gradient step 只能直接减少第三类, 无法补上未访问 state 或缺失 feature. 常见 squared TD loss 为

$$
\mathcal L(\phi)=\mathbb E_{(s,a,r,s')\sim\mathcal D}
\left[V_\phi(s)-\left(r+\gamma V_{\bar\phi}(s')\right)\right]^2.
$$

Target parameter $\bar\phi$ 暂时冻结, 让 regression target 在若干 step 内较稳定. 即使 training loss 很小, 也只说明 dataset distribution $\mathcal D$ 上接近 frozen target, 不证明 $V_\phi$ 接近 true $V^\pi$ 或 $V^*$. Off-policy data 还改变 loss weighting. 高频 behavior state 对 gradient 贡献大, target policy 常访问但 behavior 少见的 state 贡献小. Tabular case 可以靠逐 state step-size 与 sufficient visitation 讨论收敛; neural case 中 parameter sharing 让一个 state 的 update 同时改变其他 state, 分析更复杂. **5.5. Average reward 不是把 $\gamma$ 直接设为 1.** Continuing task 若关心长期每步平均 reward, 可以定义

$$
g^\pi=\lim_{T\to\infty}\frac1T
\mathbb E_\pi\left[\sum_{t=0}^{T-1}R_{t+1}\right].
$$

Differential value $h^\pi(s)$ 衡量从 $s$ 出发相对 steady-state average 多获得多少 transient reward. 对应 equation 形如

$$
g^\pi+h^\pi(s)
=\sum_a\pi(a\mid s)
\left[R(s,a)+\sum_{s'}P(s'\mid s,a)h^\pi(s')\right].
$$

$h^\pi$ 只确定到 additive constant, 因为给所有 state 同加常数不会改变 equation. 这与 discounted case 的 unique $V^\pi$ 不同. Average-reward theory 还需要 chain ergodicity 等条件, 不能把正文 contraction proof 中的 $\gamma$ 删除后继续使用. 选择 discounted return 还是 average reward 会改变 policy preference. Discounted objective 更重视靠近当前时刻的 reward, average reward 忽略有限 transient 对无限期平均的影响. 部署 task 若有自然 episode, discounted/episodic 口径通常更直观; 持续控制或资源调度可能更关心 long-run rate. **5.6. TD(0),n-step 与 Monte Carlo target.** 对固定 policy, one-step TD target 是

$$
G_t^{(1)}=R_{t+1}+\gamma V(S_{t+1}).
$$

$n$-step target 展开更多真实 reward:

$$
G_t^{(n)}
=\sum_{k=0}^{n-1}\gamma^kR_{t+k+1}
+\gamma^nV(S_{t+n}).
$$

若 episode 在 $n$ 步前 true termination, bootstrap 项为 0, sum 截到 terminal. $n$ 增大时, target 对 current critic 的依赖减少, 对 sampled reward sequence 的依赖增加. 一般表现为 bias 降低而 variance 上升, 具体大小还取决于 reward stochasticity 与 critic error. Monte Carlo target 一直累积到 terminal, 不 bootstrap. Episodic environment 中它直接 sample $G_t$, 对 true $V^\pi$ unbiased 的前提是 trajectory 来自 $\pi$ 且 return 定义一致. Episode 很长或 continuing 时, 等待 terminal 成本高, return variance 也可能很大. $\lambda$-return 将不同 $n$-step target 做 geometric mixture. GAE 在 advantage 侧使用相近结构, 把 TD residual 按 $\gamma\lambda$ 累积. 这些方法没有改变 Bellman expectation object, 只是选择用多少真实 future reward 与多少 bootstrap 来估计它. 实现中必须明确 value target 是否 stop-gradient. 若 target 内的 $V(S_{t+n})$ 与 prediction 同时反向传播, loss 不再是通常的 semi-gradient TD update. Residual-gradient method 有另一套推导, 不能在无说明时混用. **5.7. Error 应该沿哪条链排查.**

当 critic prediction 错误时, 可以沿四层排查. 第一层是 task definition: reward,discount 与 termination 是否表达了想要的 objective. 第二层是 state: observation 是否满足 Markov 条件, remaining time 与 hidden variable 是否缺失. 第三层是 data: behavior coverage,sample correlation 与 importance ratio 是否可接受. 第四层才是 optimization: network capacity,learning rate 与 target update 是否合适. 这条顺序很重要. Reward timing 错一位时, 再大的 network 也只会更精确地拟合错误 target; terminal mask 把 truncation 当结束时, 增加 data 会稳定地产生 biased value; unseen action 没有 coverage 时, 降低 training loss 也无法验证它的 $Q$. 对 tabular toy MDP, 可以把 model enumeration,linear solve,iterative backup 与 Monte Carlo rollout 四个结果互相核对. 它们若不一致, 通常是 reward index,discount,terminal 或 transition probability 中至少一处实现错误. 对 large environment 无法精确求解时, 仍可构造小 state slice 或 deterministic fixture 保留这种交叉检查. **5.8. Replay distribution 与 Bellman loss weighting.**

Replay buffer 改变的是哪些 state-action error 被频繁优化. Uniform replay 对 buffer 中 transition 均匀抽样, 并不等于对 current policy occupancy 均匀, 也不等于对 state space 均匀. Old policy data 占比很大时, critic loss 主要在 old occupancy 上下降. Prioritized replay 按 TD error 提高某些 transition 的采样 probability. 这能更快处理当前 residual 大的样本, 也改变了 objective weighting. 若希望恢复 uniform-buffer expectation, 需要 importance weight 修正 sampling probability; clip 或不完全修正会留下 bias, 换取较低 variance 与更稳定 optimization. Rare state 还会遇到另一层问题: TD error 只有访问后才能计算. 从未进入 buffer 的 catastrophic state 不会因 priority mechanism 自动出现. Exploration,scenario generation 与 offline coverage 属于 data acquisition, replay scheduling 只在已有 data 内重新分配计算. 验证 critic 时应至少分开报告 replay-distribution loss,on-policy rollout error 与 task-level return. 第一项衡量 optimizer 是否拟合训练 target, 第二项衡量 current policy 常见 state, 第三项还包含 policy choice 与 environment feedback. 三者同时改善时证据更完整; 只有 replay loss 下降, 无法推出 control performance 提升. **5.9. Expected value 看不见 return distribution.**

标准 Bellman equation 传播 expected return. 两个 action 可以有相同 $Q$ mean, return risk 却完全不同. 例如 action `stable` 恒得 1, action `risky` 以相同 probability 得 0 或 2. 两者 expected reward 都是 1, risk-neutral Bellman backup 将它们视为 tie; variance 分别是 0 与 1. 如果任务关心 downside risk,tail probability 或安全约束, scalar $V$ 不足以表达目标. 可以增加 cost value 与 constraint, 使用 CVaR 等 risk measure, 或学习完整 return distribution. Distributional RL 传播的是 random return distribution 的 representation, 其 expectation 仍应与普通 value 在口径一致时对应. Risk-sensitive objective 往往不再满足简单的 expectation linearity. 例如 utility $\mathbb E[u(G)]$ 在 nonlinear $u$ 下, 不能只把 $\mathbb E[G]$ 送进 $u$. Bellman recursion 需要把足以计算 future utility 的 state 或 distribution 保留下来. 直接在普通 $V$ 上附加一句「考虑风险」不会产生正确 equation. 大模型后训练也有类似差别. 平均 verifier reward 相同的两个 policy, 一个可能稳定产出中等答案, 另一个偶尔满分,偶尔产生严重违规. 只优化 mean reward 会忽略 tail behavior. Safety evaluation 因而要报告 violation rate 与 severity distribution, 不能只给 average reward. 这一边界不否定 expected Bellman equation. 它精确解的是 risk-neutral discounted expectation. 当产品目标包含风险,约束或多目标权衡时, 应先修改 objective 与 state, 再推对应 operator; 不能要求原 equation 回答它没有编码的问题.

**5.10. 交付前怎样复核一个 Bellman 实现.** 先构造只有两三个 state 的 deterministic fixture, 手算每个 action 的 reward,next state 和 discount. 用 model enumeration,matrix solve,iterative evaluation 与大量 Monte Carlo rollout 分别计算同一个 $V^\pi$, 四者应在数值误差范围内一致. 再加入 stochastic branch, 检查 transition probability 是否只乘一次. 随后分别制造 true termination 与 time-limit truncation, 查看 target 中 bootstrap mask 是否符合 task definition. 把 policy action probability改成非均匀值, 检查 $P_\pi$ 与 $r_\pi$ 是否同时更新. 将 value 初值换成正数,负数和随机数, contraction case 应收敛到相同 fixed point. Control 路径还要验证 expectation 与 max 没有混写. 固定 policy evaluation 应按 $\pi$ 对 action 求和, value iteration 才使用 max. 对 tie action 设置 deterministic rule, 对 approximate critic 人为加入可控误差, 检查 action gap 小时是否出现预期的 ranking flip. 最后才跑 large environment. 记录 Bellman residual,value scale,termination rate,target/prediction distribution 与 greedy action change. 一旦指标异常, 先回到 fixture 定位 reward index,mask,transition 和 update order, 不要直接靠调 learning rate 掩盖定义错误. 这套复核顺序的目标是先证明数学对象与实现对齐, 再讨论 function approximation 的性能. Toy fixture 过不了时, 大规模训练曲线再平滑也不能证明 Bellman update 正确.
定义, 数据与更新必须逐项对应.

**Bellman equation 给出 value 必须满足的递归结构, 不替任何具体 estimator 保证收敛.** 读后续方法时要分别检查 target 来自 expectation 还是 max, data 由哪个 policy 采样, next-state value 是真实值, table estimate 还是 neural critic, 以及更新究竟在做 evaluation 还是 control. Double estimator 在误差相关性较弱时减少 max bias。
设两个动作真实价值都为零，估计为 $\hat Q_a=\epsilon_a$，噪声独立且零均值。虽然每个估计无偏，$\mathbb E[\max_a\hat Q_a]>0$，因为 max 更容易选择正噪声。动作越多、噪声越大，过估计通常越强。 Double Q 的核心是把「选择」与「评价」分给两套误差较弱相关的估计。用估计器 A 选动作

$$
a^*=\arg\max_aQ_A(s',a),
$$

再用 B 评价 $Q_B(s',a^*)$。A 的正噪声会影响选择，但若 B 的噪声独立，它不会因同一次 max 被系统挑高。完全独立是理想条件；共享数据、网络主干或同步 target 会增加误差相关性，降低去偏效果。 Double estimator 不保证无偏，可能产生低估。某个真实最优动作被 A 的负噪声错过，B 会诚实评价一个次优动作。过估计与低估之间的交换取决于 action gap、噪声相关与更新频率。只观察平均 Q 下降不能证明估计更准，应与 Monte Carlo return、策略回报和校准误差对照。 Distributional Bellman operator 保存回报分布。
期望价值把随机回报压成一个均值。Distributional RL 定义随机回报 $Z^\pi(s,a)$，满足分布等式

$$
Z^\pi(s,a)\overset D=
R(s,a,S')+\gamma Z^\pi(S',A'),
$$

其中 $S'\sim P$，$A'\sim\pi$。右侧是随机变量的平移与缩放，不是标量加法。对两边取期望才恢复普通 Bellman expectation equation。 固定策略的 distributional Bellman operator 在某些 Wasserstein 距离下是压缩；加入 control max 后性质更微妙，因为「按期望选择动作」与「比较回报分布」不是同一个序。风险中性控制通常仍按 $\mathbb E[Z]$ 选动作，分布用于改善表示与估计；风险敏感控制则需明确 CVaR、效用函数或随机支配准则。

离散原子或 quantile 近似会引入投影。C51 把平移缩放后的质量投影回固定支持，QR-DQN 用 quantile regression 近似分位点。投影误差与 Bellman 误差交织，均值看似正确时，尾部仍可能严重错位。评估应包含分位数校准与覆盖，而非只看期望回报。 Retrace 使用截断重要性权重。
Off-policy 多步 return 的完整重要性权重是逐步 ratio 连乘，方差会随长度快速增长。Retrace 使用

$$
c_t=\lambda\min\left(1,
\frac{\pi(A_t\mid S_t)}{\mu(A_t\mid S_t)}\right)
$$

衰减后续 TD error，构造

$$
Q^{\rm ret}_t=Q(S_t,A_t)+
\sum_{k\ge0}\gamma^k
\left(\prod_{j=1}^{k}c_{t+j}\right)\delta_{t+k}.
$$

截断控制方差，目标策略期望项负责修正截断带来的偏差。$\lambda$ 同时控制轨迹长度和权重衰减；行为策略远离目标时，乘积很快接近零，多步方法退化成短 backup。 支持集条件仍然存在。目标策略选择行为策略概率为零的动作时，任何 ratio 方法都无法从日志恢复该动作结果。Retrace 的安全收敛性质不能被解释成无需覆盖，它只处理已有支持内的 Off-policy 校正。 Robust Bellman backup 处理转移集合。
若真实转移只知道属于集合 $\mathcal P(s,a)$，最坏情况 control backup 为

$$
(T_{\rm rob}V)(s)=\max_a\left[
r(s,a)+\gamma\min_{P\in\mathcal P(s,a)}
\mathbb E_{S'\sim P}V(S')
\right].
$$

内层对手把概率质量移向低价值状态。总变差球、KL 球和 Wasserstein 球允许的移动方式不同：总变差只看质量差，KL 对零支持敏感，Wasserstein 利用状态间距离。选择距离等于声明哪些模型偏差算相近。 若不确定集合按状态动作 rectangular，内层最坏转移可以逐点选择，Bellman 递归保持时间一致。真实参数跨状态共享时，逐点对手可能组合出不可能同时发生的最坏模型，产生过度保守。非 rectangular uncertainty 需要在全局模型层做规划，状态价值未必满足简单逐点 backup。

鲁棒算子在有界函数上仍常保持 $\gamma$-压缩，因为对任意概率分布，期望差不超过 sup norm，min 与 max 也不放大该差异。收敛不表示集合正确：真实环境不在集合内时，最坏情况保证没有覆盖它。 Risk-sensitive Bellman 需要动态一致风险测度。
把总回报方差直接放进目标，通常无法只用当前状态价值递归，因为方差包含跨时间二阶项。指数效用

$$
J_\eta=\frac1\eta\log\mathbb E[\exp(\eta G)]
$$

在独立加法结构下具有乘法动态规划形式；$\eta>0$ 强调高回报尾部，损失记号下符号解释需相应转换。$\eta\to0$ 时通过 cumulant expansion 恢复期望并出现方差修正。 CVaR 若只在起点对总回报计算，后续重新评估可能选择与原计划不同的动作，造成时间不一致。动态风险测度把一步条件风险递归嵌套，能保持 Bellman principle，却定义了不同于静态 CVaR 的目标。 风险状态扩展是另一方案。例如约束累计成本超过预算的概率，可以把剩余预算加入状态；Bellman backup 同时更新环境状态和预算。状态空间变大，但目标语义清楚。用一个标量惩罚近似预算状态，可能把少量严重违规与大量轻微超支混为一谈。 **5.16. Bellman rank 与可压缩结构.**

大状态空间无法逐状态 backup，仍可能存在低维结构。线性 MDP 假设转移与奖励可由特征线性表示，使 Bellman backup 保持在有限维函数类附近。关键要求不只是当前价值可拟合，还包括对相关价值函数做 backup 后仍可表示。 Bellman completeness 表述函数类对算子的封闭性：对任意候选 $Q$，$TQ$ 仍在或接近函数类。仅有 realizability，即 $Q^*$ 在函数类中，不足以保证迭代中间 target 可学；算法可能在到达 $Q^*$ 前不断把函数投影出错。 低 Bellman rank 等复杂度概念试图刻画状态动作与价值残差之间的可分解结构。它们解释某些表面巨大环境为何可用少量交互学习，也提醒表示维度小不等于 Bellman 结构简单。经验论文引用样本效率时，应说明依赖的是哪类结构假设。 **5.17. 离线数据无法验证未覆盖动作的 Bellman residual.**

经验 Bellman loss 只在数据中的 $(s,a)$ 上计算。某动作从未出现时，模型可以给它任意 $Q$，训练 loss 完全不变；control backup 中的 max 却可能选中这个任意高值。于是，数据内 residual 很小与贪心策略可靠可以同时冲突。 设日志只有动作 $a_0$，模型对 $Q(s,a_0)$ 拟合正确，对未见 $a_1$ 输出 $100$。经验 loss 为零，部署策略选择 $a_1$，真实结果未知。这个两动作反例不依赖深度网络，任何离线 control 都需额外覆盖或保守假设。

conservative Q 方法对数据外动作价值施加下压，或提高数据动作相对价值。惩罚强度太小仍会外推，太大则错过真实更优但稀少的动作。独立行为策略密度、ensemble 不确定性与动作计数可以辅助校准，没有哪一个在一般函数逼近下给出完美支持判断。 Fitted Q Evaluation 评估固定目标策略时，避免了 max 直接挑选高估动作，但目标策略本身若选择数据外动作，问题仍存在。评估比控制容易，不代表无需 positivity。 **5.18. Doubly robust 把模型与权重误差相乘.** Off-policy evaluation 可以组合直接价值模型与重要性采样。简化的 contextual bandit 形式为

$$
\hat V_{DR}=\frac1N\sum_i\left[
\sum_a\pi(a\mid s_i)\hat r(s_i,a)
+\frac{\pi(a_i\mid s_i)}{\mu(a_i\mid s_i)}
(r_i-\hat r(s_i,a_i))
\right].
$$

若 reward model 正确，残差均值为零；若 propensity 正确，重要性项修正模型偏差。因此其中任一 nuisance model 一致即可得到一致估计，这就是 doubly robust 的含义。 「双重稳健」不表示任意两套错误模型也稳健。两者都错时，偏差大致由误差乘积控制；共享特征与同一数据过拟合还会破坏简单分析。cross-fitting 用不同折训练 nuisance 与评估，可以减少自适应偏差。 序列 MDP 中，doubly robust estimator 沿时间递归组合 value model 与逐步 ratio。horizon 增长仍带来权重方差，value error 也会递归传播。它改善两种信息源的组合，不消除覆盖边界。 **5.19. Average-reward Bellman equation 要减去增益.** continuing task 的长期平均奖励记为 $\rho^\pi$。相对价值 $h^\pi$ 满足

$$
\rho^\pi+h^\pi(s)=r_\pi(s)
+\sum_{s'}P_\pi(s'\mid s)h^\pi(s').
$$

与折扣方程相比，未来项前没有 $\gamma$，左侧多了平均增益 $\rho^\pi$。$h$ 只在加常数意义下确定：若 $h$ 是解，$h+c$ 也是解。必须固定参考状态 $h(s_{ref})=0$ 或要求平稳分布均值为零，才能得到唯一规范化表示。 最优方程为

$$
\rho^*+h^*(s)=
\max_a\left[r(s,a)+
\sum_{s'}P(s'\mid s,a)h^*(s')\right].
$$

relative value iteration 每轮做最优 backup，再减去某个参考状态值，防止整体常数漂移。这个减法不是 reward normalization，它只选择 $h$ 的规范，不改变动作差。 平均奖励理论常要求 unichain 或 communicating 条件。若不同策略能进入不同 recurrent class，平均增益可能依初态而变，单个标量 $\rho^\pi$ 无法描述全部状态。直接套用相对价值迭代可能收敛异常，需先检查链结构或使用更一般 multichain 方程。 折扣策略在 $\gamma$ 接近一时可以逼近平均奖励策略，但数值价值规模按 $1/(1-\gamma)$ 增长，状态间真正影响决策的是较小的差值。用相对价值直接学习能避免两个巨大数相减，也更贴合长期吞吐目标。 **5.20. 随机 shortest path 依赖 proper policy.** 随机最短路任务通常不折扣，存在终止目标状态，非终止每步付出成本。Bellman 方程

$$
J(s)=\min_a\left[c(s,a)+
\sum_{s'}P(s'\mid s,a)J(s')\right],\qquad J(s_{goal})=0
$$

没有 $\gamma$ 提供统一压缩。良定义性依赖 proper policy：从相关初态以概率一在有限期望时间内到达目标。若存在永不终止且不付成本的循环，最优值和迭代行为会失去常见保证。 实际 Agent 任务常接近随机最短路：成功完成后终止，每次工具调用有成本。允许模型无限思考且中间成本为零，会引入 improper policy；即使最终成功奖励很高，Bellman 方程也可能允许无代价拖延。每步时间成本、最大预算或 properness 假设需要明确。 把超时强行设为终止会使所有策略 proper，但也改变任务。超时失败成本的大小决定策略愿意冒多大长程风险。报告结果时应给超时率与条件成功时间，平均回报一个数字无法区分快速失败、缓慢成功和无限拖延。

## 6. 把 Bellman backup 写成可核对的张量运算

对 $n$ 个状态、$m$ 个动作的有限 MDP，令 transition tensor $P$ 的 shape 为 $[n,m,n]$，reward tensor $R$ 也取 $[n,m,n]$，policy matrix $\Pi$ 为 $[n,m]$，value vector $V$ 为 $[n]$。固定策略的一步 backup 可以逐项写成

$$
Q[s,a]=\sum_{s'=1}^{n}P[s,a,s']
\bigl(R[s,a,s']+\gamma V[s']\bigr),
$$

$$
(T^\pi V)[s]=\sum_{a=1}^{m}\Pi[s,a]Q[s,a].
$$

这里 $P$ 在最后一维求和，$\Pi$ 在动作维求和。若实现用广播，一种清楚的中间 shape 是：`target_sa_next = R + gamma * V[None,None,:]` 得到 $[n,m,n]$；与 $P$ 相乘并沿 next-state 维求和得到 $Q:[n,m]$；最后与 $\Pi$ 相乘并沿 action 维求和得到新 $V:[n]$。**先保留中间 $Q$ 再求和，通常比把所有维度塞进一个表达式更容易查错。** 若 reward 已经预先取成 $\bar R[s,a]=\sum_{s'}P[s,a,s']R[s,a,s']$，则

$$
Q[s,a]=\bar R[s,a]+\gamma\sum_{s'}P[s,a,s']V[s'].
$$

两种写法只能选一种。把 $\bar R$ 放进对 $s'$ 的求和仍能得到同样结果，因为概率和为 1；但若代码里的 `R` 实际是按 next state 变化的条件 reward，却误当作 $[n,m]$ 广播，就会丢掉 reward 与 transition outcome 的对应关系。 **6.1. 一个 $2\times2\times2$ 的逐元素 backup.** 设当前 $V=(4,1)$，$\gamma=0.5$。在状态 $s_0$，动作 $a_0$ 以概率 $(0.75,0.25)$ 转移到 $(s_0,s_1)$，两种结果的 reward 分别为 $(0,2)$。那么

$$
Q(s_0,a_0)
=0.75(0+0.5\times4)+0.25(2+0.5\times1)
=2.125.
$$

动作 $a_1$ 必到 $s_1$ 且 reward 为 3，故

$$
Q(s_0,a_1)=3+0.5\times1=3.5.
$$

若策略在 $s_0$ 以 $(0.6,0.4)$ 选动作，则 expectation backup 为

$$
(T^\pi V)(s_0)=0.6\times2.125+0.4\times3.5=2.675.
$$

Optimality backup 则是 $\max(2.125,3.5)=3.5$。同一组 $Q$，最后一步是按策略加权还是取最大值，区分了 evaluation 与 control。代码里把 `sum(policy * q)` 改成 `max(q)` 只差一行，求解的问题却已经变了。 **6.2. 广播错误会悄悄改变求和轴.** 设 batch 状态动作价值为 $Q\in\mathbb R^{B\times A}$，转移概率为 $P\in\mathbb R^{B\times A\times S}$，下一状态价值为 $V'\in\mathbb R^{B\times S}$。期望 backup 需要把 $V'$ 扩成 $[B,1,S]$，再沿最后一维求和：

$$
Y_{b,a}=R_{b,a}+\gamma
\sum_{s'}P_{b,a,s'}V'_{b,s'}.
$$

若把 batch 维误当状态维，广播仍可能通过，却让不同样本互相混合。shape assert 只能检查维数，无法检查轴语义；用每个 batch 元素具有不同易识别常数的小例子，才能发现跨样本串线。 terminal mask 的 shape 也常引发静默错误。序列级 done 为 $[B]$，token value 为 $[B,T]$ 时，应明确扩为 $[B,1]$ 或使用逐 token valid mask。直接广播可能把某条序列终止信号作用到错误轴。数值测试需要同时包含不同长度、真终止和时间截断。 稀疏转移不应物化完整 $[S,A,S]$ tensor。用邻接列表计算期望时，每个边的概率仍要按源状态动作归一化；重复下一状态需先合并或一起求和。稀疏实现与稠密实现应在小环境逐元素对齐，而非只比较最终策略。

## 7. Sampling backup 的噪声从哪里来

模型未知时，无法枚举所有 $s'$，只观察一个 transition $(s,a,r,s')$。TD(0) 用

$$
Y=r+\gamma(1-d)\widehat V(s')
$$

作为随机 target，其中 $d$ 表示真终止。若 $\widehat V$ 暂时固定，并且 transition 是从真实 kernel 采样的，则

$$
\mathbb E[Y\mid s,a]
=\sum_{s',r}p(s',r\mid s,a)
[r+\gamma(1-d)V(s')]
$$

正是一次 Bellman expectation backup。一个 sample target 会偏离这个期望，但这种 transition sampling noise 本身不构成 bias。Critic 不准确、截断 mask 错误、target clipping 或函数类无法表示真实 fixed point 会让实际更新偏离理想 backup。Off-policy 采样则更精确地说是改变了 Bellman error 被哪些状态动作加权；在 tabular、覆盖充分并对每个访问对独立更新的 policy evaluation 中，它未必改变 fixed point，但配合函数逼近、有限覆盖或 control target 时，可能得到不同的投影解或产生不稳定性。 用上一节的 $a_0$ 举例，sample target 只有两种：以 0.75 概率取 $0+0.5\times4=2$，以 0.25 概率取 $2+0.5\times1=2.5$。均值为 2.125，条件 variance 为

$$
0.75(2-2.125)^2+0.25(2.5-2.125)^2=0.046875.
$$

如果 reward 在每个分支内还随机，total variance 还要加入 $\mathbb E[\operatorname{Var}(R\mid s,a,s')]$。这正是全 variance 公式在 Bellman target 上的应用。用 $K$ 个独立 next-state sample 取平均可把这部分 variance 缩到约 $1/K$，代价是环境交互或模型查询增加。 **7.1. Max 带来的过估计不是 transition noise 本身.** 假设一个状态有两个动作，真实 action value 都是 0，但估计误差独立地以相同概率取 $-1$ 或 $+1$。单个动作估计仍然无偏：$\mathbb E[\widehat Q_a]=0$。然而

$$
\max(\widehat Q_1,\widehat Q_2)
$$

只有在两者同时为 $-1$ 时取 $-1$，其余三种组合都取 $+1$，所以期望为

$$
\frac14(-1)+\frac34(1)=0.5.
$$

**「每个动作估计无偏」并不能推出「最大值估计无偏」。** 选择与评估复用同一组噪声，会偏爱被高估的动作。Double Q 的核心思路是用一套估计选择动作、另一套较独立的估计评价它，降低这种选择偏差；它并不保证所有环境下完全没有低估或其他 approximation error。 **7.2. Expected SARSA 与 Q-learning 的噪声不同.** SARSA target 使用实际采到的下一动作：

$$
Y^{\rm SARSA}=R+\gamma Q(S',A'),\qquad A'\sim\pi.
$$

Expected SARSA 对动作解析求期望：

$$
Y^{\rm Exp}=R+\gamma\sum_{a'}\pi(a'\mid S')Q(S',a').
$$

在策略和 $Q$ 固定时，二者条件期望相同，Expected SARSA 消除了下一动作采样方差，仍保留环境转移和奖励噪声。动作空间很大时，精确求和成本可能超过多采样收益。 Q-learning 把期望换成 max，目标策略与行为策略分离。它没有下一动作采样噪声，却引入 max bias，并依赖行为数据覆盖贪心动作附近状态。三者差异应按 target 中哪个随机变量被采样、求和或最大化理解。 条件方差可以逐层分解：

$$
\operatorname{Var}(Y\mid s,a)=
\operatorname{Var}_{S',R}
(\mathbb E_{S',R}[\operatorname{Var}_{A'\mid S'}])
$$

只是简写思路，严格形式应使用全方差公式。把动作期望解析化只消除内层项，无法处理随机转移造成的外层方差。 **7.3. Control variate 不改变期望的条件.** 若随机变量 $C$ 的期望已知，估计 $Y$ 时可使用

$$
Y_\beta=Y-\beta(C-\mathbb E[C]).
$$

最优系数为 $\beta^*=\operatorname{Cov}(Y,C)/\operatorname{Var}(C)$，方差按相关程度降低。baseline、dueling 分解和某些模型辅助 return 都可以从 control variate 视角理解。 关键是 $\mathbb E[C]$ 必须正确，或用独立数据可靠估计。用同一批样本同时拟合 control variate 与评估均值，会引入有限样本依赖；cross-fitting 把拟合与评估折分，可以减轻过拟合偏差。 一个差的 control variate 会增大方差。固定 $\beta=1$ 只有在尺度匹配时合理；价值模型系统偏差大、与真实 return 相关性弱时，减 baseline 可能让信号更噪。应报告减前减后的经验方差与均值差，不能默认 critic 一定降方差。 **7.4. 随机逼近 ODE 解释步长与噪声.** 采样 Bellman 更新可写成

$$
\theta_{k+1}=\theta_k+\alpha_k
[h(\theta_k)+M_{k+1}],
$$

其中 $h$ 是给定历史后的平均漂移，$M_{k+1}$ 是 martingale-difference noise。步长足够小时，插值轨迹近似常微分方程 $\dot\theta=h(\theta)$。算法稳定性转化为 ODE 平衡点是否吸引。 Robbins–Monro 步长 $\sum_k\alpha_k=\infty$、$\sum_k\alpha_k^2<\infty$ 让信号累计无穷而噪声平方和有限。恒定步长不严格收敛，会在平衡点附近保持稳态波动；它也能持续适应非平稳目标。讨论「收敛」时需区分参数极限、平均参数和稳态分布。 Markov 数据让噪声不独立，但若链相对参数更新足够快地混合，可以通过 Poisson equation 把噪声分解为鞅项与可控余项。策略和价值同时更新时，数据核也随参数变化，分析需要额外时间尺度条件。 两时间尺度 Actor-Critic 常令 critic 步长相对更大，使 actor 看见近似完成的策略评估；target network 则常作为慢变量。多个「快慢」关系同时存在时，不能只比较名义学习率，还要考虑每个模块更新频率、batch 数和梯度尺度。

**7.5. $\lambda$-operator 连接一步与完整回报.** 固定策略下，定义 $n$ 步 Bellman 算子 $(T^\pi)^n$。$\lambda$-operator 用几何权重混合所有步数：

$$
T_\lambda^\pi V=(1-\lambda)
\sum_{n=1}^{\infty}\lambda^{n-1}(T^\pi)^nV.
$$

$\lambda=0$ 时只做一步 backup，$\lambda\uparrow1$ 时趋近完整策略价值，与初始 $V$ 的关系减弱。因为 $(T^\pi)^n$ 的收缩率为 $\gamma^n$，混合算子的收缩模可计算为

$$
\frac{\gamma(1-\lambda)}{1-\gamma\lambda}.
$$

$\lambda$ 增大时，精确 expectation 算子更快靠近固定点；sample return 却使用更长随机轨迹，方差通常增加。算子收敛快与样本估计稳定是两件事。 把无穷和化简可得 resolvent 形式

$$
T_\lambda^pi V
=V+(I-\gamma\lambda P_\pi)^{-1}(T^\pi V-V).
$$

它把一步 Bellman residual 经多步访问传播。eligibility trace 是在采样轨迹上递推实现这种传播，不必显式求逆。 状态依赖 $\lambda(s)$ 可以在 critic 可靠区域多 bootstrap，在长程稀疏区域用更长 return。此时简单几何混合公式改变，终止 mask 和 Off-policy trace 也需同步处理。只把标量 $\lambda$ 换成网络输出，并不自动保留固定点与收敛性质。 **7.6. Multi-step target 的重叠造成误差相关.**

从同一条轨迹构造相邻 $n$-step target，它们共享大部分奖励和 bootstrap 状态。把每个时间点当独立训练样本会高估有效样本量。episode 较长不等于提供同样数量的独立 return。 重叠也影响验证误差。随机拆分 transition 后，训练集 target 和验证集 target 可能共享后续奖励，产生泄漏。按完整 episode 或独立环境实例切分，更能测量未见轨迹上的价值泛化。 并行环境提供较独立的轨迹，但若共享同一任务模板、初始种子族或模型生成题目，仍存在高层相关。误差条的聚类单位应与数据生成中最上层共享随机因素一致。

## 8. 函数逼近求到的是哪个投影

Tabular setting 能给每个状态一个独立数值，神经网络或线性 critic 则把许多状态绑在同一组参数上。令线性 value 为 $V_w=\Phi w$，$\Phi\in\mathbb R^{n\times d}$ 且 $d<n$。真实 Bellman image $T^\pi V_w$ 通常不在 $\Phi$ 的列空间中，更新只能把它投回可表示集合：

$$
V_{w_{k+1}}\approx \Pi_D T^\pi V_{w_k},
$$

其中 $D$ 是训练分布对各状态的权重，$\Pi_D$ 表示按加权平方误差投影。Replay 或 behavior policy 改变 $D$，即使 target 的条件期望完全正确，也会改变有限容量 critic 优先拟合哪些状态。 做一个可见的例子。两个状态真实 value 为 $(0,10)$，critic 只能输出同一个常数 $w$。若训练权重为 $D=(0.9,0.1)$，最小化

$$
0.9(w-0)^2+0.1(w-10)^2
$$

得到 $w=1$；若权重换成 $(0.1,0.9)$，则得到 $w=9$。sample target 在两个例子里都没有条件偏差，变化来自表示约束：一个标量必须同时服务两个状态，distribution 决定它偏向哪个状态。笼统地说「off-policy 导致 bias」会漏掉这个投影过程；离策略数据改变的是投影范数，所得解未必适合目标策略最常访问的区域。

这也解释了为什么 replay loss 不能单独代表 value quality。上例在各自训练分布下都达到最优，却会在另一分布下产生很大误差。应另外在 current-policy occupancy、关键安全状态和统一评测集上计算 error；若能构造小环境真值，还可以直接画出每个状态的 signed error，看到共享参数究竟牺牲了谁。 线性投影本身可以继续算到底。令 $D=\operatorname{diag}(d_1,\ldots,d_n)$，给定一个暂时固定的 target vector $y$，加权回归目标为

$$
L(w)=(\Phi w-y)^\top D(\Phi w-y).
$$

对 $w$ 求导并令其为零，得到 normal equation

$$
\Phi^\top D\Phi w=\Phi^\top Dy.
$$

若 $\Phi^\top D\Phi$ 可逆，解为

$$
w=(\Phi^\top D\Phi)^{-1}\Phi^\top Dy.
$$

这条式子把数据分布的作用写得很直白：$D$ 同时出现在矩阵两侧。某状态权重为零时，它不对参数解施加直接约束；某组 feature 在已覆盖状态上近线性相关时，矩阵会病态，少量 target noise 就可能引起很大的参数变化。工程里加入 $\lambda\lVert w\rVert_2^2$，相当于把左侧改为 $\Phi^\top D\Phi+\lambda I$，能改善条件数，但又引入向零收缩的 regularization bias。 当 target 本身是 $T^\pi(\Phi w)$，问题不再是一次固定标签回归，而是寻找 projected Bellman equation 的 fixed point：

$$
\Phi w=\Pi_D T^\pi(\Phi w).
$$

投影与 Bellman operator 的组合未必继承原算子在 max norm 下的 contraction。特别是 off-policy data、bootstrapping 和 function approximation 同时出现时，训练可能发散；这就是常说的 deadly triad。三者单独出现并不必然失败，问题在于 tabular contraction proof 已经覆盖不了组合更新。诊断时应分别改变数据分布、bootstrap 深度和函数类，找出不稳定究竟在哪个耦合处出现。 **8.1. Approximate backup 的误差如何累计.** 设一次近似更新满足

$$
V_{k+1}=T^\pi V_k+e_k,
\qquad \lVert e_k\rVert_\infty\le\varepsilon.
$$

则

$$
\lVert V_{k+1}-V^\pi\rVert_\infty
\le\gamma\lVert V_k-V^\pi\rVert_\infty+\varepsilon.
$$

递推 $k$ 次，

$$
\lVert V_k-V^\pi\rVert_\infty
\le\gamma^k\lVert V_0-V^\pi\rVert_\infty
+\varepsilon\sum_{j=0}^{k-1}\gamma^j.
$$

当 $k\to\infty$，误差地板最多为 $\varepsilon/(1-\gamma)$。这解释了为什么每轮看似很小的系统性 target error，在 $\gamma$ 接近 1 时会形成明显 value bias。它也提示 debug 顺序：随机优化噪声可能随 batch 增大而下降，reward timing 或 terminal mask 造成的系统误差不会靠多训练几轮自动消失。 **8.2. Projected Bellman equation 与 MSPBE.** 线性价值函数写成 $V_\theta=\Phi\theta$，$\Pi_\mu$ 表示按采样分布 $\mu$ 的正交投影。TD 固定点满足

$$
\Phi\theta=\Pi_\mu T^\pi(\Phi\theta),
$$

不等同于直接最小化 Bellman residual $\lVert V_\theta-T^\pi V_\theta\rVert_\mu^2$。前者把 backup 投回函数空间后匹配，后者测量投影前残差；两者可以有不同解。 Mean Squared Projected Bellman Error 定义为

$$
\operatorname{MSPBE}(\theta)=
\lVert V_\theta-\Pi_\mu T^\pi V_\theta\rVert_\mu^2.
$$

投影算子依赖状态分布。换 replay 权重会同时改变投影几何和固定点，即使环境与策略不变，学到的参数也可能变化。 普通半梯度 TD 更新只对当前预测求导，把 target 当常数。它不是样本 squared TD error 的完整梯度；完整梯度需要处理下一状态价值导数，并会遇到 double-sampling problem：无偏估计期望乘积通常需要同一 $(s,a)$ 下两个独立下一状态样本。 GTD 类算法引入辅助变量，构造 MSPBE 的随机梯度，在线性 Off-policy 条件下获得更稳健理论。代价是双时间尺度、额外超参数与较高方差。深度网络中常用 target network 与经验技巧，理论对象又发生变化，不能把线性 GTD 收敛结论直接移植。 **8.3. Baird 反例暴露致命三角.**

Baird counterexample 使用线性函数逼近、Off-policy 数据和 bootstrap，TD(0) 参数即使在奖励全零时也会发散。真实价值显然为零，问题仍出现，说明发散并非奖励噪声或非线性网络造成。 三项各自可以工作：On-policy 线性 TD 有稳定结果；不 bootstrap 的 Monte Carlo 可做监督回归；表格表示下 Off-policy Q-learning在充分探索与合适步长下可收敛。把 Off-policy、函数逼近和 bootstrap 联合，投影 Bellman 算子可能不再收缩。 反例的价值在于区分 loss 与动力学。单步 TD error 可能暂时下降，参数范数却沿不稳定方向增长；有限训练区间看似正常，随后突然爆炸。监控参数谱、预测范围与独立 Monte Carlo target，能比只看训练 TD loss 更早发现问题。 target network、replay 和梯度裁剪可以延缓或稳定实际训练，却没有从一般情形消除致命三角。若声称某技巧「解决」发散，需要说明在哪个函数类、数据分布和更新算子下恢复了什么性质。 **8.4. LSTD 直接解 projected fixed point.**

线性价值 $V_\theta(s)=\phi(s)^\top\theta$ 下，stationary on-policy 数据的 projected Bellman equation 可写成

$$
A\theta=b,qquad
A=\mathbb E[\phi_t(\phi_t-\gamma\phi_{t+1})^\top],
\quad b=\mathbb E[\phi_tR_{t+1}].
$$

Least-Squares TD 用样本均值估计 $A,b$ 后解线性系统。与逐步 TD 相比，它充分复用一批数据并避免学习率选择；代价是形成和求解 $d\times d$ 系统，特征维度大时内存与计算昂贵。 $A$ 奇异或病态时，需要 ridge regularization 或伪逆。正则改变 fixed point，不能只当数值实现细节。特征共线、覆盖不足和 $\gamma$ 接近一都会恶化条件数。报告 LSTD 时应给特征维度、正则系数与条件数诊断。 LSTD 估计的是投影固定点，不等于 ordinary least squares 拟合 Monte Carlo return。前者通过相邻特征构造 moment equation，后者需要完整或截断回报。两者在有限样本的 bias、variance 与数据利用方式不同。 instrumental-variable 视角解释为何使用 $\phi_t$ 乘 TD 方程：下一状态特征噪声与 TD residual 相关，直接回归可能产生 errors-in-variables bias；当前特征在合适假设下充当 instrument。Off-policy 数据需要额外权重或不同 moment 条件。 **8.5. Emphatic weighting 修正 Off-policy 状态分布.**

Off-policy TD 的危险不只来自动作 ratio，还来自行为策略状态分布与目标策略不同。Emphatic TD 构造 follow-on trace，使经常作为目标策略前驱、却在行为分布中少见的状态获得更大权重。 简化形式中 follow-on trace 满足

$$
F_t=i(S_t)+\gamma_t\rho_{t-1}F_{t-1},
$$

其中 $i(s)$ 是用户指定的 interest，$\rho$ 是目标与行为动作概率比。emphasis 再结合 $F_t$ 与 bootstrapping 参数 $\lambda_t$，加权 TD 更新。它调整投影范数，使线性 Off-policy 更新恢复更好的稳定性质。 interest 与访问频率不同。$i(s)$ 表示哪些状态的预测任务重要，follow-on 部分传播这些状态对前驱的依赖。全部设为一并不等于均匀状态权重，因为动力学和目标策略会重新分配 emphasis。 代价是 trace 可能具有高方差，长串重要性比会制造尖峰。截断或归一化能稳定训练，也改变理论固定点。Emphatic 方法解决某类线性 Off-policy 发散，不自动保证深度非线性网络稳定。 **8.6. 非线性网络只能讨论局部算子.** 神经网络更新可写成参数空间动力系统

$$
\theta_{k+1}=\theta_k-\alpha\nabla_\theta
\ell(\theta_k;\bar\theta_k,D_k).
$$

即使值空间 Bellman 算子压缩，参数到函数的映射非线性、非单射，梯度一步也不是精确投影。两个很远的参数可表示相同函数，局部很小参数变化也可能在某些输入造成大输出变化。 在固定点附近线性化，扰动近似满足 $\Delta\theta_{k+1}=J\Delta\theta_k+\xi_k$。Jacobian $J$ 的谱半径小于一时局部稳定，大于一时扰动增长。学习率、target lag、数据权重和网络曲率共同进入 $J$；单看 Bellman 的 $\gamma$ 无法判断整个训练动力学。 Neural Tangent Kernel 近似在参数变化较小时把网络视作线性函数模型，可以分析早期训练或宽网络局部行为。策略持续改变数据、激活模式切换或参数远离初始化后，kernel 也会变化，近似边界需要实证检查。 **8.7. Deadly triad 之外还有 optimizer bias.**

minibatch SGD 在固定数据和固定 target 下，期望梯度对应经验 loss；数据优先级随 TD error 动态变化时，采样分布依赖参数，若忽略分布导数，更新不再是某个静态 loss 的标准梯度。实践中这可能是有意设计，但目标应明确。 Adam 的逐坐标缩放改变参数空间几何。同一函数在不同参数化下，Adam 路径可能不同；value scale 变化还会改变二阶矩与有效步长。所谓「Bellman 算法相同」并不足以保证优化动态可比。 梯度裁剪在大残差样本上截断贡献，等价于使用有界 influence 的更新规则。它保护数值稳定，也使高奖励罕见 transition 的有效权重下降。报告裁剪触发率与被裁样本类型，才能判断稳定收益是否以信用信号为代价。 **8.8. Ensemble disagreement 不是 Bellman error.**

多个 critic 对同一 $(s,a)$ 输出分歧，常被当作认知不确定性。分歧可以提示数据稀少或优化多解，却不等于真实误差：所有成员共享数据和架构时可能一致地有偏；不同初始化造成的函数差异也可能在高数据区长期保留。 若 ensemble 用 bootstrap 数据训练，每个成员看到的数据子集不同，分歧近似反映有限样本敏感性。时间相关轨迹需要按 episode bootstrap，逐 transition 重采样会破坏相关结构。成员数量有限时，极端分位数估计也很粗糙。 把不确定性直接减入 target

$$
Y=R+\gamma\left(\bar Q(S',a')
-\beta\operatorname{Std}_mQ_m(S',a')\right)
$$

得到悲观 backup。它能抑制数据外高估，也会压低真实高价值但成员分歧大的区域。$\beta$ 定义保守程度，应由校准覆盖或风险预算选择，不能只靠训练回报调到最好。 ensemble min 是更激进的 order statistic。成员越多，最小值在同一边缘分布下越低，因此改变成员数就改变隐含风险水平。比较算法时，ensemble size 属于目标参数，不只是算力配置。 **8.9. Representation drift 让旧 target 改变含义.**

深度 critic 常写成 $V(s)=w^\top\phi_\eta(s)$。target network 冻结的是 $(w,\eta)$ 的旧副本，online representation 更新后，同一状态在两套特征空间的位置不同。target lag 因而既是数值预测滞后，也是表示坐标滞后。 若只冻结输出头、不冻结 encoder，target 会随共享表示移动，稳定效果弱于完整 target；若完整冻结，旧表示可能不能解释新访问状态。两种方案交换耦合强度与适应速度，应明确网络共享边界。 辅助表征损失也会改变 Bellman 投影空间。加入 next-state prediction、对比学习或语言建模后，encoder 同时服务多个目标；即使 value head loss 不变，特征移动会改变过去状态的预测。replay 中保留原始观测允许重新编码，只缓存旧 embedding 则会产生不可修复的 representation staleness。 监控表示漂移可以在固定 probe set 上比较特征 CKA、余弦邻域和 target 输出。表示变化本身没有好坏；关键是 Bellman residual、策略性能与数据外校准是否随之改善。

## 9. Target network 改变的是优化动力学

神经网络 critic 常用一份延迟参数 $\bar\phi$ 构造 target：

$$
Y_i=r_i+\gamma(1-d_i)V_{\bar\phi}(s'_i),
\qquad
L(\phi)=\frac1B\sum_i(V_\phi(s_i)-Y_i)^2.
$$

计算这一轮梯度时，$Y_i$ 应视为常数，因而要停止通过 target network 反传。若 online 与 target 共用同一参数且不 detach，梯度会同时推动等式两边，得到的已不是通常的 semi-gradient TD。延迟副本可以每隔 $K$ 步硬更新，也可以用

$$
\bar\phi\leftarrow(1-\tau)\bar\phi+\tau\phi
$$

缓慢跟随。小 $\tau$ 降低 target 快速漂移，却增加陈旧程度；它没有把函数逼近重新变成严格 contraction，只是在实践中改变耦合系统的稳定性。 一个可观察的诊断是同时记录 online prediction、frozen target 和二者差值。如果 loss 很小只是因为 target 紧跟 online 一起移动，策略回报未必改善；若 target 长期落后，TD error 又可能主要反映参数时滞。比较不同 target-update 设置时，训练步数相同还不够，需报告环境样本数、gradient update 数和每条数据被复用多少次。 **9.1. Reward scaling 与 value 单位.**

将所有 reward 乘常数 $c$，真实 $V$ 与 $Q$ 也乘 $c$，最优策略在无其他正则项时通常不变。但 squared value loss 会乘约 $c^2$，gradient norm 和数值范围都会变化。若 actor loss、critic loss、entropy 与 KL 共用一组系数，reward scale 还会改变各分量的相对力量。 因此 reward normalization 不是完全无语义的预处理。按 batch 标准化 reward 会让同一个结果在不同 batch 得到不同单位；running normalization 又依赖历史数据分布。若要比较 value 与人工可解释的业务回报，应保留原始单位，并记录训练中使用的缩放变换及其反变换。测试 Bellman identity 时，也要在同一单位下比较 $r+\gamma V(s')$ 与 $V(s)$。

对稀疏终局奖励，大量 transition 的 immediate reward 为零，不能据此断言它们的 value 也接近零。应检查终局信号能否沿 backup 传播到早期状态：在确定性长度 $H$ 的链上，终局奖励 1 对起点的 value 是 $\gamma^{H-1}$。若实现只更新终点附近或 replay 很少抽到关键链路，早期 state 会长期看不到信用信号。这是数据传播问题，不是 Bellman 方程本身失效。

还可以用这条链检查 update order。同步更新每轮只让奖励向前传播一个状态，距离终点 $H$ 步的起点至少需要 $H$ 轮才第一次得到非零估计；若按从终点到起点的顺序做 in-place sweep，一轮就能传遍整条链。两者拥有相同 fixed point，有限计算预算下的收敛速度却不同。比较算法时应报告一次「iteration」到底包含多少 state backup，避免把更有利的遍历顺序误认成不同算子的优势。 在随机环境中，单次 sweep 的变化还混有 sampling noise。可以固定一个小模型先跑精确 expectation backup，再跑 sample backup，观察二者随样本量靠近。若样本量增加后仍存在稳定偏差，应检查 behavior coverage、reward preprocessing、terminal mask 与 target network；不要把系统性误差笼统归为随机性。 **9.2. 两时间尺度解释 target lag.** online 参数 $\theta$ 每步按 TD gradient 更新，target 参数 $\bar\theta$ 用 Polyak 平均

$$
\bar\theta_{k+1}=(1-\tau)\bar\theta_k+	au\theta_k.
$$

展开得到 target 是历史 online 参数的指数加权平均，距当前 $j$ 步的权重约为 $\tau(1-\tau)^j$。有效记忆长度约为 $1/\tau$。$\tau$ 很小使 target 平滑，也让它代表较旧策略与价值。 两时间尺度分析要求快变量在慢变量近似固定时接近其平衡，慢变量再跟随。若 online 学习率相对 $\tau$ 太大，target 尚未适应，online 已走到新区域；若 $\tau$ 太大，两套网络几乎同步，失去固定 target 的稳定作用。合理比例依梯度噪声、数据复用和函数敏感性。 hard update 每 $K$ 步复制一次，会产生锯齿动力学：周期内 target 固定，复制瞬间所有 TD target 同时跳变。Polyak 更新变化连续，两者不能仅用平均更新频率等同。比较时应查看复制前后 loss、Q scale 与梯度突变。 **9.3. Target network 与策略版本是两种陈旧.**

value target 陈旧指 bootstrap 网络落后于 online critic；policy lag 指数据由旧行为策略生成。前者改变监督标签，后者改变状态动作分布与重要性比。二者可能同时存在，却需要不同诊断。 减小 target 更新速度不能修复 rollout policy lag；提高 actor 同步频率也不能消除 critic target 的参数耦合。日志应分别记录 target age、behavior-policy age 和 replay sample age。把它们都称为 stale data 会掩盖责任层。 在 actor-critic 中，target critic、target actor、reference policy 和 behavior policy 还可能是四个版本。每个对象进入哪个公式必须明确：next action 谁生成，next Q 谁评价，ratio 分母来自谁，KL 相对谁计算。版本标识缺失时，数值正确也无法复现实验。 **9.4. EMA 带来的偏差可以手算.**

假设 online 参数沿一个方向以恒定速度变化，$\theta_k=vk$。稳定阶段下，EMA target 平均落后约 $(1-\tau)v/\tau$。因此减小 $\tau$ 会线性增加追踪偏差。若 online 参数在固定点附近只有零均值噪声，减小 $\tau$ 又能降低 target 方差。 这里存在明确的 bias–variance tradeoff：目标快速移动时需要大 $\tau$，噪声主导时小 $\tau$ 更平滑。训练早期与后期可能需要不同设置。固定 target 周期将交换关系固定下来，未必适合全过程。 可以记录 $\lVert Q_\theta-Q_{\bar\theta}\rVert$、target 自相关和同一验证 batch 上的 Bellman residual，估计当前处于追踪偏差还是噪声主导区。单看 online–target 参数距离意义有限，因为网络参数距离与函数距离不成固定比例。 **9.5. 联合固定点需要同时满足两套方程.** 把 online 与 target 更新写成平均动力学：

$$
\dot\theta=-\nabla_\theta L(\theta;\bar\theta),
\qquad
\dot{\bar\theta}=\tau(\theta-\bar\theta).
$$

联合平衡要求 $\theta=\bar\theta$，并且 $\nabla_\theta L(\theta;\theta)=0$。训练 loss 暂时很小只说明第一条梯度接近零，online 与 target 可能尚未相等；两网络相等也不说明 Bellman residual 为零。 局部稳定取决于块 Jacobian。online 对自身的 Hessian、target 对标签的敏感度以及 $\tau$ 共同决定特征值。减小 $\tau$ 往往降低快速正反馈，却会引入接近零的慢特征值，使收敛尾部变长。不存在脱离学习率与数据分布的统一最优 target 速度。 多个 critic 共用 target 时，误差相关也重要。双 Q 若 target 更新完全同步、数据完全相同，两者会逐渐相关，降低 double estimator 的去偏收益。不同初始化只能提供早期差异；bootstrap 数据、独立 dropout 或不同更新节奏能维持部分多样性，也可能增加方差。 **9.6. Bellman residual 为零仍要检查边界条件.**

在错误 terminal mask 下，模型可以精确满足另一套 Bellman 方程。若把时间截断当真终止，学到的是有限日志窗口价值；若在真实终止后仍 bootstrap，吸收态可能积累虚假未来奖励。训练 residual 都可能接近零，目标却已改变。 reward preprocessing 同样会定义另一算子。逐 batch 去均值、裁剪或归一化后，模型满足处理后奖励的固定点。若统计量随训练分布变化，算子本身也在移动。要验证业务单位下 Bellman identity，应把预测反变换后与原始 reward 对齐。

观测别名会使同一输入对应多个潜在 Bellman target。平方 loss 的最优预测是条件平均，经验 residual 不会归零，其剩余方差可能被误认为环境随机性。构造具有相同观测、不同历史的配对样本，可以区分状态遗漏与普通转移噪声。 因此完整验收包含四层：代数公式与 shape，采样分布与支持，终止及奖励边界，固定点与真实业务回报。任何一层错位，都可能产生一条数值稳定、loss 很低，却回答错误问题的训练曲线。 **9.7. 一套从解析解到大模型 critic 的分级测试.**

第一级使用一状态两动作环境。手算 $V,Q$、终止 mask 和最优动作，检查 reward timing、折扣与 max 轴。第二级使用三状态随机链，直接解 $(I-\gamma P)V=r$，再与迭代 evaluation、Monte Carlo 均值和 sample TD 比较。解析解负责发现系统偏差，重复采样负责验证方差是否按样本量下降。 第三级加入时间截断、真终止与随机长度。构造两条观测相同、termination flag 不同的 transition，确保 bootstrap mask 只在真终止时清零。再把 reward 全部乘常数，检查 value 同比例变化、贪心策略保持，并记录优化器是否因尺度变化出现不同动态。

第四级加入未覆盖动作。让行为策略永不选择 $a_1$，故意初始化 $Q(s,a_1)$ 很高，检查离线 control 是否会挑选它、保守项是否按设计下压，以及评估日志是否明确暴露 support violation。这个测试比普通 held-out TD loss 更直接。 第五级才进入神经网络与序列数据。在固定小 batch 上冻结 target，确认一次更新确实降低同一目标的 loss；随后解冻 target，分别记录 online loss、frozen-target residual、online–target gap 和 Monte Carlo 校准。若只看移动 target 的训练 loss，网络可以和标签一起漂移。 长回答 critic 还要验证 reduce 口径。复制同一语义轨迹并添加不计 reward 的 padding，序列等权目标应保持总权重，token 等权目标会改变 batch 权重。哪种行为正确取决于算法定义，测试的目的在于让实现与定义一致。

分布式 rollout 增加版本测试。每条样本记录 behavior policy、reward model、tokenizer、环境和 target critic 版本；人工制造一个过旧样本，检查系统是拒绝、校正还是按明确上限接收。静默混入旧版本会让 Bellman target 对应不同 MDP。 最终验收在独立任务集上同时报告 return、Bellman residual、value calibration、action gap、长度与失败分桶。return 低而 residual 低，优先检查奖励、覆盖与状态定义；return 高而 residual 大，可能是策略暂时有效但 critic 未校准。二者回答的问题不同，不应互相替代。 这套测试从可精确复算的最小环境逐步增加随机性、函数逼近和系统异步。每一级只新增一种困难，一旦结果分叉，责任层仍可定位。直接从完整训练曲线排查，多个误差源会彼此遮蔽。

测试还应保留数值精度维度。同一解析环境分别使用 float64、float32 与混合精度，比较 residual、value 和贪心动作。若动作 gap 小于舍入误差，策略差异可能只来自数值格式；若 float64 仍偏离解析解，问题更可能位于公式、轴或边界条件。混合精度下 loss scaling 保护梯度下溢，却不会提高 target 本身的表示精度。价值范围接近数据类型极限时，应先调整 reward 单位或采用更高精度累积。把精度实验放在小环境完成，可以在昂贵训练前确定误差来自算法还是算术。

同一测试还应改变状态编号与动作编号。重编号后，价值应按同一置换变化，回报保持不变；若策略随无语义编号改变，应检查 tie-breaking、广播轴、随机种子绑定和稀疏索引。再向模型插入不可达状态，原可达区域的解析价值应保持不变；若发生变化，通常意味着概率归一化跨错维度。最后交换两个完全对称动作，除显式 tie-breaking 外，所有统计结果都应对称。这类置换测试不需要新数据，却能发现普通数值对照遗漏的结构错误。
