# 演员-评论家算法 (Actor-Critic)

REINFORCE 用完整轨迹的 MC return 更新策略,公式直接,但一个早期 action 会背负之后所有环境随机性.Actor-Critic 同时学习策略 $\pi_\theta(a\mid s)$ 与价值函数 $V_\phi(s)$:Actor 决定 action,Critic 估计当前策略从状态 $s$ 出发的期望回报. Critic 提供的是相对基准和 bootstrap 终点. 它通常降低 estimator 方差,也把 value 预测误差带进 Actor. 这一章沿着 MC、TD、n-step 与 GAE 展开,并把采样版本、终止边界、detach 和更新顺序放进同一条训练链. 真正需要掌握的是每个 target 由哪些已观察 reward 和哪些预测 value 组成,以及这些量对应哪一个策略版本.

---

## 1. 从REINFORCE到Actor-Critic

Actor-Critic 保留 policy gradient 的 score-function 形式, 改变 $Q^\pi$ 或 advantage 的估计方式. REINFORCE 等到 episode 结束后使用 $G_t$; Actor-Critic 让学习中的 $V_\phi$ 提供 baseline, 并在 TD target 中预测尚未发生的未来. 这一步换来更及时、更低方差的更新,也增加了一个会犯错的估计器. 所以阅读 Actor-Critic 时需要同时追踪两条误差:Actor 的采样梯度噪声,以及 Critic 的 bootstrap 偏差.

### 1.1 回顾REINFORCE的痛点

在REINFORCE中,我们最大化目标函数:

$$ J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} [R(\tau)],\qquad R(\tau)=\sum_{t=0}^{\infty}\gamma^t r_t $$

其梯度为:

$$ \nabla_\theta J(\theta) = \mathbb{E}_{\tau}\left[\sum_{t=0}^{\infty}\gamma^t\nabla_\theta \log \pi_\theta(a_t|s_t) \cdot G_t\right] $$

其中 $G_t = \sum_{k=0}^\infty \gamma^k r_{t+k}$ 是从 $t$ 时刻开始的**实际累积回报**. 外部的 $\gamma^t$ 来自起点折扣目标; 如果将时间步按 discounted occupancy 采样, 它可以吸收到采样分布中. 实践里对 rollout 时间步做普通均值的 Actor loss 会重新加权各时刻, 是常用 surrogate, 不能在没有说明采样口径时直接称为上述 $J$ 的逐项无偏估计. **痛点**: $G_t$ 对路径极其敏感. 如果环境本身是随机的(例如在这个状态采取同一个动作,有时得100分,有时得-10分),或者策略本身是随机的,那么 $G_t$ 的波动会很大. 为了获得准确的梯度估计,我们需要采样成千上万条轨迹来平均掉这些噪声.

### 1.2 引入基线 (Baseline)

为了降低方差,我们可以引入一个基线 $b(s_t)$:

$$ \nabla_\theta J(\theta) = \mathbb{E}_{\tau}\left[\sum_{t=0}^{\infty}\gamma^t\nabla_\theta \log \pi_\theta(a_t|s_t) \cdot (G_t - b(s_t))\right] $$

只要 $b(s_t)$ 不依赖于动作 $a_t$,这个梯度就是无偏的(我们在1.1.4 节已经证明过).
工程上最常用的基线是状态价值 $V^\pi(s_t)$. 它只依赖状态,可以在不改变策略梯度期望的前提下消除不同状态本身的回报尺度差异.

### 1.3 评论家登场

如果我们将 $G_t$ 替换为一个**学习到的函数**,会发生什么?
我们定义一个参数为 $\phi$ 的神经网络 $V_\phi(s)$ 来拟合状态价值 $V^\pi(s)$. 这时,我们可以用 $Q^\pi(s_t, a_t)$ 的估计值来替代 $G_t$.
根据贝尔曼方程:
$$ Q^\pi(s_t, a_t) = \mathbb{E} [r_t + \gamma V^\pi(s_{t+1}) ] $$ 那么,梯度更新中的 $(G_t - b(s_t))$ 变为:
$$ \text{Target} - \text{Baseline} = (r_t + \gamma V_\phi(s_{t+1})) - V_\phi(s_t) $$ 这个量正是**TD误差 (TD Error)** ,通常记为 $\delta_t$. 这也是**优势函数 (Advantage Function)** 的一种估计:

$$ A(s_t, a_t) \approx r_t + \gamma V(s_{t+1}) - V(s_t) $$

**Actor-Critic的核心思想**:
- **Critic**: 负责学习 $V_\phi(s)$,目标是最小化TD误差的平方 (或其他Value Loss).
- **Actor**: 负责学习 $\pi_\theta(a|s)$,沿着Critic指出的优势方向更新,最大化 $A(s, a)$.

## 2. 偏差-方差权衡 (Bias-Variance Tradeoff)

MC 与 TD 不只是两种代码写法,它们使用的信息范围不同.MC 等待真实未来,不依赖末状态 value;TD 只观察短期 reward,把余下未来交给 Critic. n-step return 在两端之间选择 bootstrap 的位置. 偏差和方差也不是算法的固定标签.Critic 越准确,TD bias 越小;环境未来越随机,MC variance 越大;轨迹截断、终止 mask 和 value target 的实现又会改变两者. 因此需要在同一采样口径下比较 estimator. 这是理解RL算法设计的核心视角.

### 2.1 蒙特卡洛 (MC) vs. 时间差分 (TD)

| 方法 | 目标值 (Target) | 偏差 (Bias) | 方差 (Variance) | 依赖模型? |
|------|-----------------|-------------|-----------------|-----------|
| **MC (REINFORCE)** | $G_t$ (完整 on-policy 回报) | 边界与采样口径正确时对相应 value 无偏 | 通常较高,受整条路径随机性影响 | 否 |
| **TD (Actor-Critic)** | $r_t + \gamma V(s_{t+1})$ | 取决于 Critic; $V=V^\pi$ 时单步 target 的条件期望正确 | 通常较低,但仍受 reward、transition 与 value 误差影响 | 否 (Model-Free) |

- **REINFORCE**: 单条采样轨迹获得高回报时, 轨迹中的动作都会收到正向更新, 即使高分主要来自随机性. (High Variance)
- **Actor-Critic**: "我有了一个对未来的估计 $V$. 这次拿了 $r_t$,如果 $r_t + \gamma V_{next} > V_{curr}$,说明比预期好,我就鼓励这个动作. " (Low Variance, Biased if $V$ is wrong)

### 2.2 多步自举 (n-step Bootstrapping)

为了平衡偏差和方差,我们可以不仅仅看一步,而是看 $n$ 步:

- **1-step**: $G_t^{(1)} = r_t + \gamma V(s_{t+1})$ (通常方差较低;近似 Critic 会引入 bootstrap bias)
- **2-step**: $G_t^{(2)} = r_t + \gamma r_{t+1} + \gamma^2 V(s_{t+2})$
- ...
- **$\infty$-step**: $G_t^{(\infty)} = G_t$ (MC) (完整 on-policy 轨迹和正确边界下无 bootstrap bias,方差通常较高)

我们可以混合使用这些目标. 这引出了**Generalized Advantage Estimation (GAE)** .

### 2.3 MC、TD 与 advantage 怎样连起来

在策略 $\pi$ 下,状态价值和动作价值分别为:

$$
V^\pi(s_t)=\mathbb{E}_\pi[G_t\mid s_t],\qquad
Q^\pi(s_t,a_t)=\mathbb{E}_\pi[G_t\mid s_t,a_t].
$$

优势函数比较「指定动作」与「该状态下按策略随机行动」的期望差异:

$$
A^\pi(s_t,a_t)=Q^\pi(s_t,a_t)-V^\pi(s_t).
$$

REINFORCE 用采样回报 $G_t$ 估计 $Q^\pi(s_t,a_t)$,于是 $G_t-V_\phi(s_t)$ 是 MC advantage. Actor-Critic 再利用 Bellman 关系

$$
Q^\pi(s_t,a_t)=\mathbb{E}_\pi[r_t+\gamma V^\pi(s_{t+1})\mid s_t,a_t]
$$

把未知的完整未来替换成一步 reward 加下一状态的 value,得到 TD error:

$$
\delta_t=r_t+\gamma(1-d_t)V_\phi(s_{t+1})-V_\phi(s_t).
$$

$d_t=1$ 表示环境在这一步真正终止,此时没有后续回报,bootstrap 项必须归零. 若 rollout 只是因为固定长度、时间限制或 batch 边界而被**截断**,环境状态仍有未来,$d_t$ 不应直接设成 $1$;应额外计算末状态 value. 把截断误当终止会系统性低估边界附近的 return. MC target 在环境随机性下波动较大,但只要 episode 完整且采样、折扣处理正确,它不依赖一个学习中的 value 预测. TD target 只看一步随机结果,方差通常更低,却把 $V_\phi(s_{t+1})$ 的误差带进目标. 这里的偏差还会随训练变化:Critic 越准确,bootstrap 误差越小;Critic 很差时,Actor 会被一个错误基准持续引导.

### 2.4 手算一:同一轨迹上的 MC target 与 TD target

设一条三步轨迹的 reward 为 $r_0=1,r_1=0,r_2=2$,在 $t=2$ 后真正终止,折扣因子 $\gamma=0.9$. 完整 MC return 从后往前计算:

$$
G_2=2,
$$

$$
G_1=0+0.9\times2=1.8,
$$

$$
G_0=1+0.9\times1.8=2.62.
$$

假设 Critic 当前给出 $V(s_0)=2.0,V(s_1)=1.5,V(s_2)=1.0$. 对 $t=0$,一步 TD target 为

$$
y_0^{\mathrm{TD}}=1+0.9\times1.5=2.35,
$$

因此 $\delta_0=2.35-2.0=0.35$. MC advantage 则为 $G_0-V(s_0)=2.62-2.0=0.62$. 两者都认为 $a_0$ 比基准好,但强度不同.TD 没有等待后两步全部展开,代价是依赖 $V(s_1)=1.5$ 的准确性. 若 rollout 在 $s_1$ 处只是被采样长度截断,仍应用 $1+0.9V(s_1)$;只有 $s_1$ 是真实终止状态时,target 才退化为 $1$.

## 3. 广义优势估计 (GAE)

GAE 将相邻 TD error 按指数权重累加,用一个 $\lambda$ 控制多远的真实 reward 进入 advantage. 它不改变 policy-gradient 的形式,只构造更平滑的 $\hat A_t$. 推导的关键是 n-step advantage 可以拆成 TD error 的望远镜和. 实现的关键是从后向前递推,并在真实终止处切断、在时间截断处保留 bootstrap. **论文**: "High-Dimensional Continuous Control Using Generalized Advantage Estimation" (Schulman et al., 2015) GAE 是现代Policy Gradient算法(PPO, TRPO)的标配. 它通过加权平均不同步数的TD误差,巧妙地在偏差和方差之间取得平衡. 定义一步 TD error:
$$ \delta_t = r_t + \gamma V(s_{t+1}) - V(s_t) $$ 先看二步 return 对应的 advantage:

$$
\begin{aligned}
\hat A_t^{(2)}
&=r_t+\gamma r_{t+1}+\gamma^2V(s_{t+2})-V(s_t)\\
&=r_t+\gamma V(s_{t+1})-V(s_t)\\
&\quad+\gamma[r_{t+1}+\gamma V(s_{t+2})-V(s_{t+1})]\\
&=\delta_t+\gamma\delta_{t+1}.
\end{aligned}
$$

第二行人为加上再减去 $\gamma V(s_{t+1})$,两项恰好把二步 return 拆成相邻的 TD error. 同理,

$$
\hat A_t^{(k)}=\sum_{l=0}^{k-1}\gamma^l\delta_{t+l}.
$$

GAE定义为所有这些 $k$-step 优势的指数加权平均:

$$ A^{GAE(\gamma, \lambda)}_t = (1-\lambda) (A^{(1)}_t + \lambda A^{(2)}_t + \lambda^2 A^{(3)}_t + ...) $$

现在把同一个 $\delta$ 的系数逐项收集. $\delta_t$ 出现在所有 $k\ge1$ 的项里,系数是 $(1-\lambda)(1+\lambda+\lambda^2+\cdots)=1$. $\delta_{t+1}$ 从 $k=2$ 开始出现,系数为

$$
(1-\lambda)\gamma(\lambda+\lambda^2+\cdots)=\gamma\lambda.
$$

一般地,$\delta_{t+l}$ 的系数为 $(\gamma\lambda)^l$,于是:

$$ A^{GAE(\gamma, \lambda)}_t = \sum_{l=0}^\infty (\gamma \lambda)^l \delta_{t+l} $$

**参数 $\lambda$ 的作用**:
- $\lambda = 0$: $A_t = \delta_t = r_t + \gamma V_{t+1} - V_t$ (即普通的 Actor-Critic,通常方差较小;Critic 不准时会有 bootstrap bias)
- $\lambda = 1$: $A_t = \sum \gamma^l \delta_{t+l} = G_t - V_t$ (边界处理正确时接近 REINFORCE 基线法,通常方差较大;不能脱离轨迹与 Critic 条件宣称偏差必然更小) $\lambda$ 越小,估计越依赖近期 bootstrap,通常方差较低但更敏感于 Critic 偏差;$\lambda$ 越接近 $1$,越多真实 reward 进入估计,通常降低 bootstrap 偏差并提高轨迹方差. 在有限 rollout 中,$\lambda=1$ 只有在末端是真终止,或者截断边界使用了正确的 bootstrap value 时,才能对应相应的 MC 形式. **递归计算公式**(代码实现关键):
由于 $A_t = \delta_t + \gamma \lambda A_{t+1}$,我们可以从后往前递归计算GAE,很高效.

```python
last_gae = 0
advantages = []
for t in reversed(range(len(rewards))):
    delta = rewards[t] + gamma * values[t+1] * bootstrap_mask[t] - values[t]
    gae = delta + gamma * lambda * trace_mask[t] * last_gae
    advantages.insert(0, gae)
    last_gae = gae
```

这里必须区分两个 mask. `bootstrap_mask=1-terminated` 决定能否使用 terminal observation 的 value: 真终止取 0, time-limit truncation 仍可取 1. `trace_mask` 决定 $A_{t+1}$ 是否属于同一 episode; 遇到 termination、truncation 或 auto-reset 边界都取 0, 防止 reset 后新 episode 的 `last_gae` 串回旧 episode. 单纯到达 rollout buffer 尾部但环境未结束时, 可以用末状态 value bootstrap, 反向递推则在本批边界以 `last_gae=0` 截断.

### 3.1 手算二:从 TD error 到 GAE

沿用前面的三步轨迹,取 $\gamma=0.9,\lambda=0.8$,并补充终止状态 $V(s_3)=0$. 三个 TD error 为:

$$
\delta_0=1+0.9\times1.5-2.0=0.35,
$$

$$
\delta_1=0+0.9\times1.0-1.5=-0.60,
$$

$$
\delta_2=2+0-1.0=1.00.
$$

从后向前递推,$\gamma\lambda=0.72$:

$$
\hat A_2=1.00,
$$

$$
\hat A_1=-0.60+0.72\times1.00=0.12,
$$

$$
\hat A_0=0.35+0.72\times0.12=0.4364.
$$

也可以直接展开验证:$0.35+0.72(-0.60)+0.72^2(1.00)=0.4364$. 一步 TD 只给 $a_0$ 优势 $0.35$;GAE 把后续先坏后好的信息按指数衰减带回,得到 $0.4364$;完整 MC advantage 是 $0.62$. 三个数体现的正是不同 bootstrap 深度下的 bias/variance 选择,不能据单条轨迹断言哪一个更准确.

### 3.2 $\lambda$-return 与 Critic target

GAE 给 Actor 提供 advantage. Critic 可以使用与之匹配的 $\lambda$-return:

$$
\hat R_t^{\lambda}=\hat A_t^{\mathrm{GAE}}+V_{\phi_{\mathrm{old}}}(s_t).
$$

右侧 value 应来自采样时保存的旧预测,并作为固定 target. 若一边更新 $V_\phi$,一边让 target 随当前 $V_\phi(s_t)$ 反向传播,回归目标本身也跟着移动,梯度不再对应预期的 value fitting. 实现时应对 advantage、bootstrap value 和 $\lambda$-return target 做 `detach` 或在无梯度环境中构造.

## 4. 数据由谁采样,梯度更新给谁

Actor-Critic 的 loss 很短,数据依赖却很严格. Action 由行为策略采样,value 与 log-prob 对应特定参数版本,GAE 使用同一条轨迹上的 reward 和终止标记. 其中任一版本错位,都会让公式表面正确、实际 estimator 失去目标. 梯度边界同样重要.Advantage 作为 Actor 的固定权重,return 作为 Critic 的固定 target. Detach 在这里声明两个网络各自拟合的量,并直接决定计算图语义. 标准 A2C 是 on-policy 方法. rollout 中的动作由当前行为策略 $\pi_{\theta_{\mathrm{old}}}$ 采样:

$$
a_t\sim\pi_{\theta_{\mathrm{old}}}(\cdot\mid s_t).
$$

收集固定长度的 $s_t,a_t,r_t,d_t$ 后,冻结这批数据,计算旧 value、GAE 和 return target,再更新 Actor 与 Critic. 如果同一批轨迹被反复训练很多轮,新策略逐渐偏离采样策略,on-policy 梯度假设就不再成立.PPO 会显式使用概率比率并限制偏离;纯 A2C 通常采一批、更新一次或少数受控步骤,然后丢弃数据. Actor 的最小化目标为:

$$
L_{\mathrm{actor}}(\theta)
=-\frac{1}{N}\sum_t
\log\pi_\theta(a_t\mid s_t)\,\operatorname{stopgrad}(\hat A_t).
$$

当 $\hat A_t>0$ 时,梯度提高已采样动作的概率;当 $\hat A_t<0$ 时,梯度降低它.Critic 的目标为:

$$
L_{\mathrm{critic}}(\phi)
=\frac{1}{2N}\sum_t
\left(V_\phi(s_t)-\operatorname{stopgrad}(\hat R_t^\lambda)\right)^2.
$$

即使 Actor 与 Critic 共享 backbone,两项损失的语义也没有改变. advantage 对 Actor 必须 detach,避免策略损失沿着 $\hat A_t$ 反向推动 Critic 去制造更有利的权重;Critic target 也 detach,避免 bootstrap 两端一起追逐. 共享表示仍会同时接收 policy loss 与 value loss 的梯度,这属于多任务共享,需要用损失权重和梯度裁剪控制干扰. 一个稳妥的更新顺序是:

1. 用旧参数与环境交互,保存 reward、终止标记、动作 log-prob 和 value;
2. 对 rollout 末状态再算一次 value. 真终止取 $0$,时间截断或固定长度截断保留预测;
3. 在无梯度环境中从后向前计算 TD error、GAE 和 $\lambda$-return;
4. 用已冻结的 advantage 计算 Actor loss,用已冻结的 return target 计算 Critic loss;
5. 合并熵项与加权 value loss,清空梯度,反向传播,裁剪后更新参数;
6. 丢弃旧 rollout,再用更新后的策略采下一批数据.

若 Actor 与 Critic 是完全独立网络,可以分别 backward 和 step;若共享 backbone,通常合并损失后做一次 backward 更清楚. 无论采用哪种顺序,同一批 target 应保持固定,不能先更新 Critic 后重新计算 advantage,再把变动后的数交给 Actor.

### 4.1 手算三:baseline 怎样改变策略梯度方向

考虑某个状态下只有动作 $a_1,a_2$,策略概率分别为 $0.6,0.4$. 一次 batch 在该状态采到两条样本:

| 样本 | 动作 | MC return | value baseline | advantage |
|---|---|---:|---:|---:|
| 1 | $a_1$ | $5$ | $3$ | $2$ |
| 2 | $a_2$ | $1$ | $3$ | $-2$ |

忽略平均系数,Actor loss 是

$$
L_{\mathrm{actor}}
=-[2\log 0.6+(-2)\log 0.4]
=-2\log0.6+2\log0.4.
$$

最小化它会提高 $a_1$ 的概率并降低 $a_2$ 的概率. baseline 并没有要求「return 大于零就奖励」,而是在问动作结果是否高于该状态下的平均预期. 如果不减 baseline,两个 return 都为正,两次样本都会推动各自动作概率上升;batch 内仍可能通过归一化约束形成相对变化,但梯度噪声更大,也更难跨回报尺度不同的状态比较. Critic 对这两条样本若使用 MC target,在同一个状态看到 target $5$ 和 $1$,MSE 最优预测是均值 $3$. 这也解释了 value baseline 的含义:它预测条件期望,而不是复述某一条轨迹. 换成 TD 或 $\lambda$-return 后,target 的方差会变小,但其均值会受到 bootstrap 预测误差影响.

### 4.2 advantage 归一化不能修复错误 target

实现常把一批 advantage 标准化:

$$
\tilde A_t=\frac{\hat A_t-\mu_A}{\sigma_A+\epsilon}.
$$

它能控制不同 batch 的梯度尺度,通常也让优化更稳定,但不会让有偏 advantage 自动变成无偏. 若终止 mask 写错、末状态没有 bootstrap,整批边界样本都被低估;减均值只能重新居中,不能恢复丢失的未来价值. 同样,标准化范围也属于算法口径:按全 batch、按单条 episode 或按环境分别计算,会产生不同的相对权重. 熵正则的梯度则直接来自策略分布,不经过 advantage. 它鼓励策略在证据不足时保留探索,但系数过大也会抵消 Actor 已经学到的偏好. Value loss 权重、熵权重和梯度裁剪共同决定共享 backbone 收到的更新比例;它们是优化超参数,不能用来掩盖采样策略或 return 计算上的错误.

标准化还会改变不同轨迹在 batch 中的相对权重. 若一个 batch 混合多个 reward 尺度差异很大的环境,全局标准化可能让低方差环境的微小差异被放大,也可能压低高方差环境的重要事件. 更稳妥的做法是先明确训练目标是否真的允许这些环境共享尺度,再决定按全 batch、按任务或按环境统计. 当 batch 很小,$\mu_A$ 与 $\sigma_A$ 自身也有明显采样噪声. 训练日志应同时保存归一化前后的 advantage 分布,否则只看 policy loss 很难判断更新变小是 Critic 更准、reward 变窄,还是标准化统计发生变化.

### 4.3 为什么这批数据不能无限复用

设轨迹由行为策略 $\mu$ 采样,当前希望更新的策略是 $\pi_\theta$. 当二者不同,直接使用 $\nabla\log\pi_\theta(a_t\mid s_t)\hat A_t$ 会把 $\mu$ 访问到的状态—动作分布当成 $\pi_\theta$ 自己的分布. 最基本的动作概率修正是重要性比率:

$$
\rho_t=\frac{\pi_\theta(a_t\mid s_t)}{\mu(a_t\mid s_t)}.
$$

但长轨迹的完整分布修正涉及多个比率连乘,容易产生很高方差;Critic target 也可能对应旧策略的未来价值. 因此纯 A2C 不把 replay buffer 当作主要数据源. 采样后的短暂计算阶段允许参数保持不变,更新结束后就重新采样. PPO、IMPALA、SAC 等方法各自增加约束、截断修正或 off-policy 目标,正是在处理数据复用和策略漂移,不能只把 A2C 的 batch 多跑几遍就当成等价替代.

还有一个容易漏掉的边界:并行环境在同一轮采样时使用的必须是同一个可识别 policy 版本. 如果某些 worker 已拉取新参数,另一些仍在用旧参数,行为策略 $\mu$ 就变成混合分布. A3C 允许一定程度的异步和 stale gradient,这是它明确接受的系统折中;同步 A2C 的价值之一,正是让采样版本和更新边界更清楚. Critic 版本也要和 rollout 对齐. 轨迹末端的 bootstrap value、每一步保存的 value 与 GAE 递推若来自不同更新阶段,$\delta_t$ 会混合多个 value function. 同步实现通常在 rollout 完成后、参数更新前一次性计算这些量,并把 target 固定到本轮优化结束. 如果确实需要异步收集,数据结构应保存 policy version 和 value version,训练端按允许的 stale 范围过滤或修正. 把所有 worker 输出直接拼接,再靠更大的 batch 平均,无法消除系统性的版本偏移.

## 5. A2C vs A3C

A2C 与 A3C 共享 Actor-Critic 数学目标,主要差异在采样和参数更新的系统组织.A3C 允许 worker 异步推送梯度,A2C 等待并行环境组成同步 batch. 两者对 stale policy、吞吐和硬件利用的权衡不同. 无论采用同步还是异步,都必须知道数据由哪个策略版本生成. 系统并行可以降低样本相关性、提高吞吐,却不会自动修正 advantage 偏差或 off-policy drift. Mnih 等人在 2016 年的论文 *Asynchronous Methods for Deep Reinforcement Learning* 中系统化提出 **A3C (Asynchronous Advantage Actor-Critic)**. 随后工程实现广泛采用同步收集的 **A2C (Advantage Actor-Critic)**,以便把多个环境的数据组成规则 batch 并交给 GPU 处理.

### 5.1 A3C架构

- **异步 (Asynchronous)** : 多个Worker在CPU的多个线程中并行与多个环境交互.
- **参数更新**: 每个Worker计算出梯度后,异步地推送到全局参数服务器 (Parameter Server),并拉取最新参数.
- **优点**: 打破了训练数据的相关性(即使没有Replay Buffer),适合CPU集群.
- **缺点**: 难以利用GPU的大Batch并行能力; 异步更新导致梯度过时 (Stale Gradients).

### 5.2 A2C架构

- **同步 (Synchronous)** : 多个Environmental Workers并行采样,等待所有人都采集完一批数据.
- **批处理**: 将所有数据拼成一个大Batch,送入GPU进行一次前向和反向传播.
- **优点**: 极高地利用了GPU并行计算能力; 梯度更新确定性,收敛更稳.
- **工程位置**: 同步向量环境更容易组成规则 batch 并利用 GPU,A3C 的异步 worker 则适合另一类系统约束. PPO 的 rollout 收集也常采用同步或分批并行环境,但 PPO 还引入了概率比率和更新约束,不能与 A2C 画等号.

---

### 5.3 Actor、Critic 与熵的联合目标

Actor-Critic的总体损失函数通常由三部分组成:

$$ L_{total} = L_{policy} + c_1 L_{value} - c_2 L_{entropy} $$

#### 策略损失 (Actor)

$$ L_{policy} = - \frac{1}{N} \sum_{i=1}^N \log \pi_\theta(a_i|s_i) \cdot \hat{A}_i $$

其中 $\hat{A}_i$ 是 detach 过的优势值(不传梯度给 Critic).

#### 价值损失 (Critic)

Critic的预测 $V_\phi(s_t)$ 应接近真实的回报目标(通常使用 $R_t = A_t + V_{old}(s_t)$ 或 $\lambda$-return).

$$ L_{value} = \frac{1}{N} \sum_{i=1}^N (V_\phi(s_i) - R_i)^2 $$

这是一个回归问题,使用MSE Loss.

#### 熵正则化 (Entropy Bonus)

为了鼓励探索,防止策略过早收敛到局部最优(deterministically choosing suboptimal actions),我们加上策略分布的熵:

$$ H(\pi(\cdot|s_t)) = - \sum_a \pi(a|s_t) \log \pi(a|s_t) $$

我们在损失函数中**减去**熵(因为我们希望**最大化**熵,而优化器通常是**最小化**损失).

---

### 5.4 baseline 无偏性的另一种写法

这是一个关键的性质,也是AC成立的基础. 我们要证明:
$$ \mathbb{E}_{a \sim \pi} [ \nabla_\theta \log \pi_\theta(a|s) \cdot b(s) ] = 0 $$ 证明:
$$
\begin{aligned}
\text{LHS} &= \int \pi_\theta(a|s) \cdot \frac{\nabla_\theta \pi_\theta(a|s)}{\pi_\theta(a|s)} \cdot b(s) \, da \\
&= \int \nabla_\theta \pi_\theta(a|s) \cdot b(s) \, da \\
&= b(s) \int \nabla_\theta \pi_\theta(a|s) \, da \\
&= b(s) \nabla_\theta \int \pi_\theta(a|s) \, da \\
&= b(s) \nabla_\theta (1) \\
&= 0
\end{aligned}
$$ 只要基线 $b(s)$ 不依赖本次采样 action,减去它就不改变策略梯度期望. 它仍可能增加或降低有限样本方差;选择 $V(s)$ 的理由是状态价值通常能解释 return 中与 action 无关的大部分变化. 直接使用一个随 action 变化的普通函数作为 baseline,上面的归一化证明不再成立,通常会引入偏差. 这不等于自动变成 Q-learning.Q-learning 的关键是 Bellman optimality target 与离策略 value update,和「baseline 是否依赖 action」不是同一个分类轴.

### 5.5 网络共享、连续动作与 off-policy 边界

#### Critic是否一定要是独立网络?
深度 Actor-Critic 经常共享大部分卷积层或 Transformer 层作为特征提取器 (Backbone),再分叉为 Policy Head 与 Value Head；也可以使用两套独立网络,由任务和梯度冲突程度决定.
- **优点**: 特征共享,训练效率高.
- **缺点**: 两个任务 (Policy和Value) 的梯度可能会相互干扰. 有时需要精细调节 $c_1$ 权重.

共享 backbone 时,一次反向传播会把 policy loss、value loss 和 entropy loss 的梯度相加. Value 系数改变的不只是 Critic head 学习速度,也改变公共表示受到的监督比例. 工程上应分别监控 policy gradient norm 与 value gradient norm,避免某一项长期压过另一项. 完全独立网络避免表示梯度直接冲突,却需要两次前向和更多参数. 选择哪一种结构取决于观察模态、模型规模和算力预算,并不改变 Actor 与 Critic 的目标定义.

#### 连续动作为什么适合 Actor-Critic?
DQN虽然也可以用连续变体(如NAF),但其核心基于 $\max_a Q(s,a)$,这在连续空间很难求.
AC架构直接输出 $\mu(s), \sigma(s)$,天然支持采样连续动作,因此在机器人控制任务中占主导地位.

以对角 Gaussian policy 为例,Actor 输出每个动作维度的均值和 log 标准差,随后从分布采样并计算 log-prob. Policy gradient 直接通过 log-prob 回传,无需在连续空间枚举 action 或解析求解 $\arg\max_aQ(s,a)$. 动作若有上下界,常用 squashed Gaussian 或其他有界分布. Tanh 变换会改变概率密度,log-prob 需要加入 Jacobian 修正;只裁剪采样 action 而不修正密度,会让训练 loss 与真实行为策略不一致.

#### Off-policy Actor-Critic
本章讨论的 A2C 是 on-policy 的,因为 rollout 由当前策略采样,并在参数更新后丢弃.
如果想做 Off-policy,可以使用 **DDPG (Deep Deterministic Policy Gradient)** 或 **SAC (Soft Actor-Critic)** ,它们使用 Replay Buffer.

是否 on-policy 不由 loss 里有没有 $\log\pi$ 单独决定,而由数据分布和修正方式决定.A2C 的轨迹由当前策略采样,更新后丢弃;SAC 的数据来自 replay buffer,其 Bellman target 与策略目标按 off-policy 方式构造. 将 A2C rollout 直接放进 replay buffer 反复训练,会让状态—动作分布越来越偏离当前策略. Importance sampling、V-trace 或专门的 off-policy Actor-Critic 目标用于处理这种偏移,不能只靠 advantage 标准化补救.

### 5.6 一次 A2C 更新

一次更新从固定 policy version 收集 $n_{env}\times n_{step}$ 个 transition. 存储项至少包括 state、action、reward、真实终止标记、截断标记、采样 log-prob 与采样时 value. Rollout 末端若未真正终止,还要用同一版本 Critic 计算 bootstrap value. GAE 和 return target 在参数更新前一次性算好并 detach. 随后把环境维与时间维展平,计算 Actor、Critic 与 entropy 三项 loss. 更新完成后重新采样,避免新参数继续使用旧 batch 却仍声称是严格 on-policy.

```text
Initialize params theta, phi
Initialize vectorized environments E

Loop forever:
    # 1. Collect Data
    Reset gradients d_theta = 0, d_phi = 0
    Storage = [] For t = 0 to n_steps - 1:
        Get states S_t from all envs
        Run Policy: pi, v = Network(S_t)
        Sample actions A_t ~ pi
        Step Envs: S_{t+1}, R_t, Terminated, Truncated, FinalObservation
        Store (S_t, A_t, R_t, Terminated, Truncated, FinalObservation, v)

# 2. Compute Returns / Advantages
    Get last value v_next = Network(S_{n_steps})
    For truncated transitions, bootstrap from FinalObservation, not auto-reset observation
    Calculate GAE for each trajectory using v_next

# 3. Update Network
    Flatten the batch (n_steps * n_envs)

Loss_Policy = -mean(log_pi(a|s) * Advantage)
    Loss_Value = mse(V(s), Return)
    Entropy = mean(Entropy(pi)) Loss = Loss_Policy + 0.5 * Loss_Value - 0.01 * Entropy Optimize(Loss)
``` 伪代码中的 `0.5` 与 `0.01` 只是示意权重,不属于 A2C 定义. 真实实验需要报告 loss 系数、gradient clipping、advantage normalization 与 rollout 长度,这些量会共同改变更新尺度和 bias-variance 取舍. 验证实现时,可以在短轨迹上手算 TD error 与 GAE,再比较程序输出. 还应分别构造 terminal 与 truncated episode,确认 bootstrap mask 不同. 这两项测试比只看训练 reward 是否偶然上升更容易定位边界错误.

## 6. 联合网络里的张量、梯度边界与更新次序

设并行环境数为 $N$，rollout 长度为 $T$，离散动作数为 $K$。一次 A2C rollout 常见张量是 `obs[T,N,d_s]`、`action[T,N]`、`reward[T,N]`、`value[T,N]`、`logp[T,N]` 和若干 mask；网络前向输出 `logits[T,N,K]` 与 `value[T,N,1]`。value 的末维应显式 `squeeze(-1)` 或全程保留，并在运算前断言形状。例如 `[T,N,1] - [T,N]` 在部分框架里会广播成意外的三维张量，loss 仍是有限数，含义却已经改变。 共享主干时，总损失可写成

$$
L(\theta,\phi)=
-\frac1M\sum_{t,n}m_{t,n}\log\pi_\theta(a_{t,n}|s_{t,n})
\operatorname{sg}(\widehat A_{t,n})
+c_v\frac1M\sum_{t,n}m_{t,n}(V_\phi(s_{t,n})-\widehat R_{t,n})^2
-c_e\frac1M\sum_{t,n}m_{t,n}\mathcal H(\pi_\theta(\cdot|s_{t,n})),
$$

其中 $M=\sum m$，$\operatorname{sg}$ 表示停止梯度。优势通常由 value 计算，却应在 Actor loss 里 detach；否则 Actor loss 会推动 Critic 改写 advantage 本身，产生一条并非策略梯度定理给出的捷径。与此同时，共享主干会同时收到 policy、value 与 entropy 三路梯度，所以「detach advantage」并不等于 Actor 与 Critic 完全独立。 把三路梯度写成 $g_p,g_v,g_e$，共享参数实际得到 $g=g_p+c_vg_v-c_eg_e$。若 $g_p^\top g_v<0$，两项在共享特征上冲突；增大 value coefficient 可能降低 value loss，却损害策略。分离网络能消除共享主干上的直接冲突，代价是参数和前向计算增加。选择共享或分离不能只看最终 return，还应观察 policy gradient norm、value gradient norm 与表示层更新规模。

### 6.1 一个共享参数的手算

假设某个共享标量参数上，policy、value、entropy 三项导数分别为 $g_p=-0.30$、$g_v=0.80$、$g_e=0.10$，$c_v=0.5,c_e=0.01$。总导数为

$$
g=-0.30+0.5\times0.80-0.01\times0.10=0.099.
$$

梯度下降会减小该参数。若把 $c_v$ 从 $0.5$ 降至 $0.2$，则 $g=-0.141$，更新方向反转。这里没有哪一项计算错了，方向变化来自多任务目标的权衡。这也是为什么只抄「value coefficient 常用 0.5」并不够：网络尺度、reward 尺度与共享深度变化后，同一个系数代表的梯度比例完全不同。

### 7. GAE 的完整边界与偏差来源

对环境流 $n$，令 $u_{t,n}$ 表示真实终止后的 bootstrap mask，$c_{t,n}$ 表示 GAE 是否跨到下一采样位置。两者在普通中间步都为 $1$，但在 rollout 边界、自动 reset 与时间上限截断处未必相同：

$$
\delta_t=r_t+\gamma u_tV(s_{t+1})-V(s_t),
$$

$$
\widehat A_t=\delta_t+\gamma\lambda c_t\widehat A_{t+1}.
$$

时间上限截断如果只是采样器停止，$u_t$ 应为 $1$，需要从截断前的 final observation 取 value；但 $c_t$ 通常为 $0$，不能把 reset 后新 episode 的优势接回来。真实 terminal 则 $u_t=c_t=0$。这两个 mask 合并，会在截断点丢 bootstrap，或把两局游戏串成一条轨迹。 设 $gamma=0.9,\lambda=0.8$，截断前一步 reward 为 $1$，$V(s_t)=2$，截断状态 $V(s_{t+1})=3$。正确 TD error 是 $1+0.9\times3-2=1.7$。若误当 terminal，得到 $1-2=-1$；同一个 action 从明显正优势变成负优势。若自动 reset 返回的新状态 value 为 $0.5$，误用它则得到 $-0.55$。这不是小数值误差，而会直接翻转 Actor 梯度。 GAE 的偏差有两层来源。第一层是 bootstrap：$V_\phi$ 有误时，较小 $\lambda$ 更依赖 Critic。第二层是有限 rollout：尾部优势必须用边界 value 或明确截断，估计误差会向前按 $(\gamma\lambda)^k$ 衰减。较大 $\lambda$ 减少对 value 的依赖，却引入更多真实 reward 随机性；因此「$\lambda$ 越大越准确」只在特定 value 误差与采样预算下成立。

Critic target 常取 $\widehat R_t=\widehat A_t+V_{\text{old}}(s_t)$。这里的 old value 应是生成 GAE 时冻结的预测。若每个 optimizer step 后用新 value 重算 target，Critic 会追逐移动目标，Actor 的 advantage 也随 epoch 改变。A2C 通常一批数据只做一次或少量更新；若要多轮复用，必须像 PPO 那样显式处理 policy ratio，并仍然控制分布漂移。

### 8. 采样吞吐、相关性与实验公平性

A3C 的 worker 异步把梯度推向共享参数，worker 计算梯度时读到的策略与应用梯度时的策略可能不同，这叫 parameter staleness。A2C 同步收齐 $N$ 个环境的 $T$ 步再更新，没有这类异步延迟，但同一时刻的环境若使用相同 seed 或确定性 reset，样本仍可能高度相关。**并行环境数增加的是吞吐，不保证等比例增加有效样本数。**

比较 rollout 配置时，应区分每次更新样本数 $NT$ 与数据新鲜度。固定 $NT=2048$，取 $N=32,T=64$ 会得到较多独立起点、较短时间链；取 $N=2,T=1024$ 则覆盖更长的单轨迹依赖。二者计算量相近，GAE 尾部误差、样本相关性和可见稀疏 reward 却不同。若任务奖励需要数百步才出现，过短 rollout 会让大量早期状态只能依赖 Critic bootstrap。

on-policy 也不是指「每条数据只能计算一次」。在参数没有变化前，可以对同一 rollout 完成 return、GAE 和多个诊断；关键是用它做过更新后，行为策略与当前策略开始分离。裸 A2C loss 没有 importance ratio，多次 epoch 会逐渐变成未校正的离策略更新。小学习率下可能暂时有效，但这属于经验近似，需要报告 epoch 与策略 KL，不能因为 reward 上升就把它称作仍然严格 on-policy。

实验验收至少包含四类量：采样端的 episode return、长度和成功率；估计端的 advantage 均值/标准差、explained variance 与截断比例；优化端的三项 loss、各自梯度范数和 entropy；系统端的每秒环境步、策略版本延迟和无效 padding 比例。loss 不必单调下降，因为数据分布不断更新；Critic loss 很低也可能只是 reward 尺度小或短期过拟合。

单元测试可造两条轨迹：一条真实终止，一条在同一步时间截断，并令 final observation 的 value 非零。手算两条的 TD、GAE 与 return，确认仅截断轨迹保留 bootstrap。冻结 rollout 后分别反向 policy loss 与 value loss，检查 advantage、target 的梯度边界以及共享参数收到的梯度。改变 $N,T$ 并保持总样本数，还可确认损失归一化不随 padding 比例漂移。这组结果让 Actor-Critic 的每个递推量都能复算。

### 9. Critic 到底在拟合哪个分布

价值函数的训练样本来自当前或近期策略访问到的状态，因此 $V_\phi$ 只在该分布上被监督。策略更新后，状态分布改变，旧 Critic 在新区域可能外推失真。即使旧 rollout 上 explained variance 很高，也不代表新策略下仍准确。Actor-Critic 的交替过程可以理解成两条追逐链：Actor 根据当前 Critic 改策略，Critic 再追上新策略的价值分布。

以平方误差训练 Critic 时，理论目标是条件均值。若同一状态后续回报以一半概率为 $0$、一半概率为 $10$，最优预测是 $5$，最小不可约均方误差仍为 $25$。所以 value loss 长期不降到零并不表示实现失败；随机环境里它包含回报本身的条件方差。反过来，value loss 很小也可能只是 reward 被缩得很小。explained variance

$$
1-\frac{\operatorname{Var}(\widehat R-V)}{\operatorname{Var}(\widehat R)}
$$

消除了整体尺度的一部分影响，但当 target 方差接近零时会不稳定，也不能揭示系统性校准误差。 Critic 训练次数同样是偏差—过拟合取舍。同一 rollout 上做很多 epoch 会降低训练误差，却可能记住 Monte Carlo 噪声；做得太少则 GAE 持续依赖落后的 value。可以划分 rollout 内的训练/诊断切片，或至少观察下一批新数据上的 value error。对于稀疏奖励任务，还应按距离终点的时间位置画误差，因为整体均值容易被大量无奖励中间状态主导。 **9.1 Off-policy Actor-Critic 的分界.** 经验回放对 Critic 很诱人，因为 Bellman target 可以从旧 transition 构造；Actor 梯度却对应当前策略的状态—动作分布。DDPG、SAC 等算法用不同的 off-policy 目标和校正思路，并不是把 A2C rollout 原封不动塞进 replay buffer。若行为策略为 $\mu$，离散动作可用 $\pi(a|s)/\mu(a|s)$ 修正动作条件，但状态分布仍有差异，而且 ratio 会增大方差。

因此阅读「Actor-Critic」时要区分架构与估计器：有 Actor 和 Critic 只是网络角色；A2C 的 on-policy score-function、DDPG 的确定性策略梯度、SAC 的熵正则 off-policy 目标并不是同一算法。**Critic 的存在降低了优势估计方差，却没有自动赋予数据无限复用能力。**这条边界也解释了为什么 PPO 要保存 old log-prob，而基础 A2C 通常更新后立即丢弃 rollout。 部署前还应单独校准 Critic。把状态按预测 value 分桶，比较每桶平均预测与实际回报；若高 value 桶持续高估，Actor 会过度强化这些状态附近的动作。校准图不能替代策略评估，却能指出 advantage 偏差集中在哪里。对安全敏感任务，还应专门统计低频失败轨迹，而不是让大量普通状态的低误差稀释它们。 校准应使用未参与 Critic 拟合的新轨迹，否则训练集上的漂亮曲线仍可能只是记住了采样噪声。

### 10. Critic 的误差怎样进入 Actor

Actor-Critic 把完整回报换成学习得到的价值估计，梯度方差通常下降，代价是 critic 的误差会沿 advantage 进入策略更新。只看 value loss 很难判断这种误差是否伤害 actor，因为不同状态动作上的误差具有不同的策略梯度权重。 **10.1 advantage 误差的梯度投影.** 令真实优势为 $A^\pi(s,a)$，估计优势为

$$
\widehat A(s,a)=A^\pi(s,a)+e(s,a).
$$

actor 使用的期望方向与真实策略梯度之差为

$$
\Delta g=
\mathbb E_{d^\pi,\pi}
[\nabla_\theta\log\pi_\theta(A\mid S)e(S,A)].
$$

critic 误差均值为零并不足够；只有误差与 score 的加权协方差为零，actor 方向才不偏。一个 critic 可以拥有很低的整体均方误差，却在低概率、高 score 的动作上持续高估，最终给 actor 明显错误的方向。反过来，某些对所有动作近似相同的状态价值偏移会被 score 的零均值性质抵消，对 actor 影响很小。 因此 critic 评估至少有三层：return prediction error 衡量数值拟合，advantage 排序衡量同状态动作相对关系，$\|z\|^2e^2$ 或 $ze$ 的统计量衡量 actor 实际受到的扰动。三者回答不同问题。单独降低 validation value loss，不保证策略改善。 若 actor 与 critic 共享表示，critic 还有第二条影响路径：value loss 直接更新共享参数，从而改变策略 logits。联合目标

$$
L=L_{actor}+c_vL_{value}-c_eH
$$

中的 $c_v$ 不只是让 critic 学得快慢，也决定共享骨干接受多少监督信号。actor 梯度与 critic 梯度在共享层夹角为负时，增大 $c_v$ 可能让 value loss 更好、策略却退化。分层记录两个梯度的范数和余弦相似度，比只看总 loss 更能解释这种冲突。 **10.2 TD target 的移动与半梯度.** 一步 TD critic 常最小化

$$
L_V(\phi)=\frac12
[R_{t+1}+\gamma V_\phi(S_{t+1})-V_\phi(S_t)]^2.
$$

实际实现通常对 target 中的 $V_\phi(S_{t+1})$ stop-gradient，只对当前状态值求导。这称为 semi-gradient。若不停止，梯度还会推动下一状态价值配合当前预测，目标两端同时移动；在线性 On-policy 条件下，semi-gradient TD 有清楚的投影 Bellman 固定点解释，全梯度平方 TD error 优化的是另一个目标。 target network 把下一状态值改为较慢参数 $\bar\phi$，进一步降低同一步更新中的目标漂移。它引入滞后：策略和环境分布已经变化时，旧 target 可能系统偏离。更新周期、Polyak 系数和 actor 学习速度共同决定滞后大小，不能孤立调一个参数。 终止边界决定 target。真实吸收终态用零 bootstrap，时间限制截断用边界状态价值，丢失终止原因会让 critic 在所有最长轨迹末尾形成固定偏差。GAE 会把这些 TD error 向前传播，边界错误因而污染多个更早时刻。 **10.3 Critic 过拟合会怎样表现.**

同一批 rollout 上反复训练 critic，可以把训练 TD error 降得很低。若 value 网络记住轨迹噪声，训练 advantage 接近零，actor 收不到信号；换到新 rollout 时预测误差又恢复。这个现象与监督学习过拟合相似，但标签本身还随策略变化。 保留同策略生成、未用于 critic 更新的 holdout trajectory，可以测量当前分布泛化。由于策略每轮更新，holdout 很快过期，适合用于单轮早停而非长期模型选择。按状态或 prompt 分组切分，避免同一轨迹相邻时间步同时出现在训练与验证两侧，否则强相关会让误差过于乐观。

critic 容量过小则产生结构偏差。同一观测对应多个隐藏状态时，$V(o)$ 只能拟合条件平均；若 actor 使用历史而 critic 只看当前观测，baseline 没有利用 actor 已知的信息，方差会升高。若 critic 反过来看模拟器真实状态，可降低方差，但要检查其尖锐状态差异是否给同一 actor 历史带来额外噪声。 **10.4 Actor 真正需要哪一种 Critic 准确性.** 策略梯度只关心同一状态下动作之间的相对价值。给所有动作价值加同一个 $c(s)$ 不改变 advantage，因此也不改变理想 actor 梯度。若 critic 是 $Q_\phi(s,a)$，可以将误差分解为状态公共项与动作差异项：

$$
e(s,a)=\bar e(s)+e_\perp(s,a),
\qquad
\mathbb E_{a\sim\pi}[e_\perp(s,a)]=0.
$$

$\bar e(s)$ 与 score 相乘后期望消失，$e_\perp$ 才直接扭曲策略方向。Q critic 的总体 MSE 可能主要由公共项贡献，数值看起来很差，actor 却仍得到正确排序；也可能 MSE 很小，但少数动作差异项符号错误，使 actor 向反方向更新。 对 value critic，advantage 还包含采样 reward 与下一状态值。状态公共偏差不会总是抵消，因为 $V(S_{t+1})$ 的误差依赖当前动作诱导的下一状态。一个在所有当前状态统一低估的 value 网络，若低估幅度随下一状态类别变化，TD advantage 仍带动作相关偏差。判断时要看 Bellman difference 中误差的变化，而不是只看 $V(S_t)$ 的绝对平移。 排序指标也有局限。actor 梯度考虑动作概率与 score 大小，两个极低概率动作互换排名可能几乎无影响，高概率动作与关键探索动作的次序错误则影响很大。可按 $\pi(a\mid s)\|\nabla\log\pi(a\mid s)\|$ 加权比较 advantage 符号和排序，得到更贴近当前策略更新的 critic 指标。

语言模型无法枚举完整回答动作，但可对同一提示采多条回答，比较 critic advantage 与独立验证器或重复 rollout 的相对顺序。为了避免同一个奖励模型既生成 target 又充当评估，应使用独立规则、人工子集或不同来源的裁判。否则 critic 只是在复现裁判偏差，排序相关性再高也不能证明真实效用正确。 **10.5 Critic 的校准、排序与不确定性.** value 校准要求预测为 $v$ 的状态，其平均实际回报也接近 $v$。可将预测分桶，比较每桶均值与 Monte Carlo 回报均值；系统性高估和低估会直接暴露。回报噪声很大时，单样本残差无法代表校准，需要在大量同类状态上聚合。

排序只关心 $V(s_i)>V(s_j)$ 是否对应更高回报，校准则关心差值大小。actor advantage 使用数值差，因此两者都重要：排序正确、尺度夸大时策略步过大；尺度准确、关键动作排序错误时方向有误。Spearman 相关、pairwise accuracy 与 calibration curve 应和 MSE 一起看。 ensemble critic 的分歧可估计一部分 epistemic uncertainty。多个网络共享同一数据后误差高度相关，分歧往往低估真实不确定性；bootstrap 数据、不同初始化和结构差异能增加多样性。环境固有随机性造成的 aleatoric uncertainty 即使数据无限也存在，应由分布式 value 或回报方差模型描述。

不确定性可用于降低可疑 advantage 权重，例如除以预测标准差，或在策略更新前过滤极端外推状态。这会改变目标权重，并可能忽略真正高价值但数据少的状态。更积极的用法是把高不确定状态送去采样，再用新数据校准 critic；它将不确定性用于数据收集，而不是直接宣判动作好坏。 distributional critic 预测完整回报分布 $Z(s)$，可以提取均值、分位数与风险量。若 actor 目标仍是期望回报，应使用分布均值构造 advantage；若改用下分位数或 CVaR，策略目标已经变为风险敏感。分布预测更丰富，但原子投影或 quantile regression 也带来自己的逼近误差。

critic 还可能只在某些回报区间失准。普通 MSE 让大残差占主要权重，Huber loss 在尾部转为线性，可防止少数异常 target 支配更新，同时减弱对真正稀有高回报的拟合。分位数回归能观察尾部，却需要足够尾部样本。选择损失函数等于选择 critic 优先拟合哪部分误差，不能脱离 actor 对这些区域的梯度权重。 对称的 prediction interval 能报告不确定范围，但策略选择会使校准数据非独立同分布。actor 越偏向 critic 看好的动作，新数据越集中在预测高值区，旧校准曲线很快过期。按策略版本维护滚动校准，并保留随机探索样本，可观察误差是否随选择压力增大。

若 critic 同时服务多个用途，例如 actor baseline、搜索叶节点评分和上线风险门槛，一个平均准确的模型未必全部合格。baseline 重视梯度方差，搜索重视候选排序，风险门槛重视尾部校准。最好分开指标，必要时使用不同 head 或不同 critic，避免一个 loss 系数承担互相冲突的要求。

### 11. 两时间尺度随机逼近

Actor 与 critic 同时学习时，各自看到的目标由另一方决定。critic 追踪当前策略的价值，actor 又根据当前 critic 改变策略。两时间尺度分析用不同步长把这组耦合动态拆开。 **11.1 Critic 快、Actor 慢的含义.** 设 actor 参数为 $\theta_k$，critic 参数为 $\phi_k$：

$$
\phi_{k+1}=\phi_k+\beta_k\widehat h(\theta_k,\phi_k),
\qquad
\theta_{k+1}=\theta_k+\alpha_k\widehat g(\theta_k,\phi_k).
$$

经典条件要求 $\alpha_k/\beta_k\to0$，也就是从 critic 的时间尺度看，actor 近似固定；从 actor 的时间尺度看，critic 已接近当前策略对应的固定点。这不等于每轮必须做很多 critic epoch，核心是有效追踪速度。 深度 Actor-Critic 常用固定学习率，无法直接满足渐近条件，但时间尺度视角仍有诊断价值。actor KL 每轮很大而 critic validation error 持续滞后，说明策略移动速度超过价值追踪；critic 更新过强又可能在新数据上过拟合。可同时调整 actor 步长、critic 步数、网络容量和 rollout 批量，而不是把问题全部归给 value coefficient。 **11.2 非平稳目标与灾难性滞后.** 策略更新后，状态访问分布 $d^{\pi}$、动作概率和回报分布全部变化。critic 在旧策略数据上拟合得再精确，也只保证旧分布误差小。若新策略进入旧数据很少覆盖的状态，value 外推可能给出极端优势，推动 actor 进一步进入该区域，形成正反馈。

限制策略 KL、混入新 rollout、对 value 输出做合理范围约束，都能降低这种反馈。价值裁剪只限制单次预测变化，并不保证新状态准确；KL 也只约束平均策略变化，罕见状态仍可能改变很大。固定 probe states 上记录 value drift 与策略 KL，可观察两者是否同步失控。 reward scale 或奖励模型版本变化时，critic 的目标尺度突然移动。归一化层和 Adam 二阶矩保留旧统计量，追踪会暂时变慢。重新初始化 value head 能快速适应尺度，却丢失排序结构；仿射校准保留更多旧知识。选择取决于变化主要是尺度平移，还是奖励语义本身改变。 **11.3 三时间尺度：Actor、Critic 与约束乘子.** 带成本约束的 Actor-Critic 还会更新 Lagrange multiplier：

$$
\lambda_{k+1}=
[\lambda_k+\eta_k(J_C-d)]_+.
$$

critic 估计 reward value 与 cost value，actor 优化 $A_R-\lambda A_C$，乘子根据长期违规调整。三个学习过程速度不匹配时容易振荡：乘子太快会对单批成本噪声过度反应，太慢会让策略长期越界。 约束可行集合为空时，$\lambda$ 会不断增大，actor 梯度几乎只剩成本项。训练前用简单安全策略估计可行基线，能区分问题冲突与优化失败。期望成本满足约束也不保证每条轨迹安全；概率约束、CVaR 或屏蔽器对应不同目标，不能只靠增大平均成本惩罚替代。 **11.4 更新比率不等于时间尺度.** 每批做十次 critic step、一次 actor step，看起来像 critic 更快，实际速度还取决于学习率、梯度尺度、优化器状态和网络条件数。十个高度相关 minibatch step 可能只是在记忆同一批 target；一次大 batch critic step反而更接近稳定投影。时间尺度应通过“策略变化一个单位时 critic 误差恢复多快”来衡量。

可以冻结 actor，观察 critic 在新 rollout 分布上的学习曲线，估计追踪所需样本与 step；再恢复 actor，记录每次策略 KL 后 validation value error 增量。若 actor 每轮制造的误差大于 critic 一轮消除的误差，系统处于持续滞后状态。降低 actor KL 或增加独立 critic 数据比重复旧 batch 更有效。 两个优化器共享骨干时，所谓两时间尺度并不完全分离。critic step 会改变 actor 表示，即使 policy head 未更新，策略分布仍移动；actor step 也改变 value 特征。若希望真正控制速度，可以为两头使用独立骨干，或在某类更新中冻结共享层。前者增加参数和表示差异，后者限制共享学习，各有代价。 Polyak target 的有效时间尺度也与更新频率相乘。每个 minibatch 做 $\bar\phi\leftarrow(1-\tau)\bar\phi+\tau\phi$，一轮含许多 minibatch 时，整轮后的旧权重系数是 $(1-\tau)^m$。比较实现时只看 $\tau$ 会误判滞后，应换算到每环境步或每轮的有效衰减。

### 12. 兼容函数逼近与 Natural Actor-Critic

一般 critic 只提供低方差 advantage，并不保证其逼近误差与策略梯度方向协调。compatible function approximation 选择一种特殊形式，让 critic 参数直接对应自然梯度。 **12.1 兼容特征来自 policy score.** 定义特征

$$
\psi_\theta(s,a)=\nabla_\theta\log\pi_\theta(a\mid s),
$$

用线性形式逼近优势：

$$
A_w(s,a)=w^T\psi_\theta(s,a).
$$

在当前策略状态动作分布下最小化加权平方误差

$$
\mathbb E[(A^\pi-A_w)^2].
$$

一阶最优条件给出

$$
\mathbb E[\psi\psi^T]w
=\mathbb E[\psi A^\pi].
$$

左侧矩阵正是 Fisher $F$，右侧是真实策略梯度 $g$，因此 $Fw=g$，$w=F^{-1}g$。critic 权重成为自然梯度方向。这个结论依赖特征确实等于 score、拟合分布与策略梯度分布一致，并且优化到相应投影解。 **12.2 兼容条件为什么容易被破坏.** 深度 value 网络通常输入状态并输出 $V(s)$，并非 $w^T\psi(s,a)$，所以不能把其参数解释为自然梯度。共享骨干、正则化、有限 batch、非精确求解和 Off-policy 数据都会偏离兼容条件。Natural Actor-Critic 的结论属于特定构造，而不是任何 Actor-Critic 都自动拥有的性质。 Fisher 可能奇异，因为神经网络参数冗余、softmax logits 存在平移不变性。求解时使用 damping：

$$
(F+\lambda I)w=g.
$$

它改善数值条件，也让方向偏回普通梯度。共轭梯度截断、Fisher-vector product 噪声和经验分布选择都会进一步改变结果。报告“使用自然梯度”时，需要同时说明这些近似。 **12.3 Advantage Actor-Critic 的投影误差.** 普通 A2C 用神经 critic 估计 $V$，通过 TD 或 GAE 得到 advantage。即使 value 达到其函数类中的最优投影，Bellman residual 也不必为零。函数类无法表达的部分形成 approximation error，采样有限形成 estimation error，策略持续变化形成 tracking error。 可以把总误差粗略拆成

$$
\widehat A-A^\pi
=(\widehat A-A_{\phi^*})
+(A_{\phi^*}-A^\pi),
$$

第一项包含有限数据与优化误差，第二项是函数类偏差。增加 critic epoch 主要减少优化误差，无法消除表示偏差；扩大网络可能减少表示偏差，却增加有限数据过拟合。按数据规模画 train/holdout value error，才能判断下一步应增加容量还是增加样本。 **12.4 Fisher 度量与信赖域的连接.** 兼容 critic 得到的 $w=F^{-1}g$ 是 natural-gradient 方向。若限制局部策略 KL，二阶近似问题为

$$
\max_{\Delta\theta}g^T\Delta\theta
\quad\text{s.t.}\quad
\frac12\Delta\theta^TF\Delta\theta\le\delta.
$$

解的方向也是 $F^{-1}g$，尺度由 KL 半径决定。普通梯度把参数欧氏距离当作移动大小，自然梯度用策略分布变化衡量，因此对光滑可逆重参数化更稳定。 经验 Fisher 用采样动作的 score outer product 估计 $F$。batch 小时矩阵秩至多为样本数，神经网络维度远大于样本数，必须用 damping 和迭代求解。damping 太大时方向接近普通梯度，太小时共轭梯度会放大噪声特征。线性求解 residual 小，只表示解出了当前经验矩阵，不表示该矩阵接近真实 Fisher。 兼容 critic 与 TRPO 都使用 Fisher，但训练流程不同。前者通过 advantage 回归得到自然方向，后者可直接用策略梯度和 Fisher-vector product 求解。若 critic 拟合误差大，兼容方法的 $w$ 同时含梯度估计误差；若普通 advantage 已较可靠，直接求解可能更清楚。二者都还需要 line search 或尺度规则，方向正确不能保证有限步改善。

在共享网络中，Fisher 只描述策略输出曲率，value head 参数若不影响策略，属于零方向。对整个联合参数向量求逆会遇到大块奇异子空间。实现应明确 natural step 作用于 actor 参数、共享参数还是全部参数；value head 通常由自己的监督目标更新。

### 13. Off-policy Actor-Critic 的关键校正

Actor-Critic 很自然地希望复用 replay buffer，但 actor 和 critic 面临的分布偏移不同。critic 学 Bellman 固定点，actor 学当前策略的性能梯度；只修正其中一边通常不够。 **13.1 状态分布与动作分布是两层偏移.** 行为策略 $\mu$ 产生状态分布 $d^\mu$ 与动作分布 $\mu(a\mid s)$，目标梯度需要 $d^\pi\pi(a\mid s)$。单步 ratio

$$
\rho_t=\frac{\pi(A_t\mid S_t)}{\mu(A_t\mid S_t)}
$$

只校正给定已访问状态后的动作分布，并未把 $d^\mu$ 变成 $d^\pi$。完整轨迹比率能同时校正，方差随时域迅速增长。emphatic weighting、density ratio 与特殊 Off-policy policy-gradient theorem 尝试处理状态分布差异，各自需要额外估计与条件。 一些实践算法接受 $d^\mu$ 下的代理目标，希望小策略更新使状态分布差异有限。此时 ratio clip 和 KL 约束控制动作层偏移，不能宣称得到精确 On-policy 梯度。数据复用轮数增加后，这个近似会逐渐恶化。 **13.2 V-trace 的截断校正.** V-trace 为异步 actor 产生的滞后数据构造 value target。定义截断比率

$$
\rho_t=\min(\bar\rho,\pi_t/\mu_t),
\qquad
c_t=\min(\bar c,\pi_t/\mu_t),
$$

target 可写成

$$
v_s=V(S_s)+
\sum_{t=s}^{s+n-1}\gamma^{t-s}
\left(\prod_{i=s}^{t-1}c_i\right)
\rho_t\delta_tV.
$$

$\rho$ 控制 TD error 强度，$c$ 控制多步传播痕迹。截断降低方差并改变固定点对应的隐式策略；阈值越小，结果越靠近行为策略。actor advantage 通常也使用校正后的下一状态 target，保证 value 与 policy update 的时间结构一致。 异步系统必须记录行为 log-prob。若 actor 使用旧参数加温度或 top-p 采样，$\mu$ 是完整变换后的分布。learner 用当前网络重算旧策略概率会让分母错误；只用版本号而未保存实际解码设置，同样无法恢复 ratio。 **13.3 Deadly triad 的来源.** 函数逼近、bootstrap 与 Off-policy 数据同时出现时，TD 学习可能发散，这组三要素常称为 deadly triad。直觉上，critic 用自己的预测当标签，训练分布又不对应目标策略，函数逼近把一个状态的误差传播到其他状态，三者形成放大回路。

target network、较小步长、replay 分布控制和保守正则能够改善稳定性，却不是普遍证明。线性反例已经表明，即使 reward 有界，参数也可能发散。监控 value 绝对值、TD error 分位数和固定 probe state 的预测，比等待 actor reward 崩溃更早发现问题。 双 critic 取最小值常用于抑制连续控制中的过估计，但会引入低估；离散动作上的 expected backup 与 sampled backup 也有不同偏差。选择 critic 结构应围绕目标误差来源，不能把某个稳定技巧视作所有 Actor-Critic 的默认真理。 **13.4 Retrace 与截断乘积.** Retrace 使用系数

$$
c_t=\lambda\min\left(1,
\frac{\pi(A_t\mid S_t)}{\mu(A_t\mid S_t)}\right)
$$

构造多步 Q target。每一步截断避免巨大 ratio，乘积让远处 TD error 只有在前缀与目标策略足够一致时才传播。与完全 importance sampling 相比，它降低方差，并通过特定 operator 保持目标策略 Q 的固定点。 $c_t$ 控制 trace，不等于 actor loss 的 ratio。把同一截断系数机械复制到所有位置，可能改变策略目标。critic target、actor advantage 和状态分布校正各有职责，代码中变量都叫 `rho` 或 `weight` 时尤其容易混淆。 当目标策略与行为策略相同，ratio 为一，Retrace 退化为 $\lambda$ trace；策略差异增大时，有效 trace 变短，critic 更依赖一步 bootstrap。这说明离策略程度不仅增加权重方差，也改变实际信用传播时域。记录 $\prod c_i$ 的衰减或有效 trace 长度，比只看单步 ratio 分位数更完整。

replay buffer 混合多个行为版本时，每条 transition 的 ratio 需要对应自己的版本。若只保存动作、不保存行为概率，除非能精确恢复旧参数和采样变换，否则无法计算。将缺失概率默认设为一，会把最旧数据当成最新数据，偏差恰好在策略变化最大处最严重。 **13.5 支持覆盖与保守价值.** 离线或高度离策略数据中，critic 会为日志未覆盖动作输出数值。Bellman target 随后对这些值取最大、期望或由 actor 选择，actor 又倾向于寻找高估动作，形成 extrapolation error。即使每个已观测动作预测准确，未观测区域的一次高估也足以主导策略。

保守 Q 学习对数据外动作提高惩罚，使其价值低于数据内动作。惩罚强度太小无法阻止外推，太大则把真正更优但少见的动作压低。行为约束让 actor 靠近数据策略，是从策略侧控制同一问题；两者都在用偏差换取有限数据下的安全性。 支持不是简单的动作是否出现。连续空间中，邻近动作能否泛化取决于动力学和 Q 的平滑性；高维动作欧氏距离很近也可能语义完全不同。语言模型某 token 在前缀后出现过，不代表长回答组合得到覆盖，序列级支持随长度指数稀疏。

可用行为策略似然、ensemble 分歧和邻域密度共同标记数据外区域，但这些只是代理量。最直接的验证仍是收集目标策略的新 rollout。若环境不能再交互，结论必须限定在覆盖假设内，不应把 critic 的高分当作已观察回报。 Off-policy evaluation 也受同一限制。importance sampling 在覆盖成立时无偏却高方差，模型法低方差却依赖 critic，doubly robust 将二者结合；两部分都错且误差相关时仍会失败。多种估计器一致能增加信心，分歧则应阻止激进部署。

覆盖诊断可从离散小空间的计数开始：对每个状态比较行为动作频率与目标动作概率，标出目标质量落在零计数动作上的比例。连续或高维空间可训练行为密度模型，观察目标样本的似然分位数；密度模型自身也会外推，因此还要结合最近邻距离与 ensemble 分歧。三种信号共同异常时，critic 高值应被视为待验证假设。

收集少量新 On-policy 数据往往比继续打磨离线校正更有价值。它可以直接检验高值动作、更新行为覆盖，并校准离线评估。采样前设置安全约束与停止条件，先从 critic 分歧低、行为距离较近的候选开始，再逐步扩大范围。这样做改变的是信息条件，而不只是优化器超参数。 若完全无法交互，最终策略最好限制在数据支持的可信区域，并把性能结论写成相对于日志分布的估计区间。数据没有回答的反事实无法靠更深网络补出证据；模型输出只能表达所采用的平滑先验。

### 14. Bellman 投影决定 Critic 学到什么

表格型价值函数能够逐状态满足 Bellman 方程，函数逼近则只能在给定函数类和采样分布下寻找近似。critic 的答案既由环境决定，也由表示空间与投影权重决定。 **14.1 投影 Bellman 方程.** 对固定策略 $\pi$，Bellman operator 为

$$
(T^\pi V)(s)=r^\pi(s)+
\gamma\sum_{s'}P^\pi(s'\mid s)V(s').
$$

真实价值满足 $V^\pi=T^\pi V^\pi$。若近似空间为 $\mathcal F$，TD 学到的对象常接近

$$
V_\phi=\Pi_dT^\pi V_\phi,
$$

其中 $\Pi_d$ 按采样状态分布 $d$ 投影回函数类。改变 rollout 分布、replay 采样比例或状态权重，就会改变投影解，即使策略和环境完全相同。 监督回归 Monte Carlo return 则投影 $V^\pi$ 本身。线性 On-policy 条件下，TD 固定点与 MC 投影一般不同：TD 利用一步结构、方差低，却把近似误差通过 bootstrap 传播；MC 标签无 bootstrap 偏差，回报噪声更大。二者的 value MSE 不能脱离评估分布比较。 **14.2 Bellman residual 与 value error 不等价.** Bellman residual 是 $\|T^\pi V-V\|$，value error 是 $\|V-V^\pi\|$。折扣 Bellman operator 在 sup norm 下收缩，可给出

$$
\|V-V^\pi\|_\infty
\le\frac1{1-\gamma}
\|T^\pi V-V\|_\infty.
$$

$\gamma$ 接近一时，常数很大，小 residual 仍可能对应明显 value error。经验 residual 又只在访问状态上测量，未覆盖状态可以任意错误。反过来，近似函数可能 value error 较小却无法让每个一步 residual 都小，因为函数类不能闭合于 Bellman operator。 用同一个样本的 $R+\gamma V(S')$ 同时充当 target 与评估标签，会低估泛化误差。double sampling 问题表明，平方 Bellman residual 的无偏梯度通常需要同一 $(s,a)$ 下两个独立下一状态样本；普通环境往往只给一个。semi-gradient TD 绕开了直接优化完整平方 residual，也因此有不同目标。 **14.3 状态聚合的手算反例.** 设两个状态 $s_1,s_2$ 被 critic 强制共享一个标量 $v$。在策略下真实价值分别为 $0$ 与 $10$。若采样分布访问二者概率各半，MC 最小二乘解为 $v=5$；若访问概率为 $0.9$ 与 $0.1$，解为 $v=1$。函数类没有变化，仅状态权重变化就使预测大幅移动。

actor 若在 $s_2$ 的动作选择最关键，第二种 critic 虽然总体 MSE 可能更小，对策略梯度却更差。可为关键状态提高 critic loss 权重，代价是改变其他状态误差。更根本的办法是提供能区分状态的表示；加权只能重新分配有限容量，不能创造缺失信息。 共享 Transformer 中的“状态聚合”更隐蔽。不同前缀可能在 value head 所用位置产生相似隐藏向量，critic 只能给相近值；actor 的完整 token 分布却仍有差异。用表示探针检查高回报与低回报前缀是否可分，有助于判断瓶颈来自 value head 还是共享表示。 **14.4 分布权重与稀有状态误差.** 投影范数按访问分布加权，稀有状态即使误差巨大，对总体 critic loss 贡献也很小。若这些状态是灾难边界或高回报终点，actor 一旦偶然到达，错误 value 可能产生巨幅 advantage。均匀降低平均 loss 无法优先修复这种尾部。

优先级 replay 按 TD error 提高采样概率，能让异常转移更快被学习，随后必须用采样概率权重处理分布偏移。优先级本身由当前 critic 计算，噪声奖励和不可约随机性也会长期保持高 TD error，挤占容量。把 epistemic uncertainty 与环境固有噪声区分开，需要 ensemble、重复转移或结构假设。 安全任务可显式提高关键状态权重，相当于选择另一投影范数。这样得到的 critic 在部署常见状态上 MSE 可能变差，但对约束梯度更有用。应该分别汇报普通访问分布、风险条件分布与策略梯度加权分布上的误差，不能用一个混合平均值覆盖所有用途。

覆盖不足无法仅靠加权解决。某个状态从未出现时，没有监督标签可放大。模型先验或相邻状态泛化能给预测，但属于外推。actor 若依赖该预测进入新区域，应先用保守不确定性惩罚或主动采样验证，避免把表示平滑误当成 Bellman 证据。

### 15. GAE 是怎样过滤 TD 误差的

GAE 写成 TD error 的指数加权和：

$$
\widehat A_t^{GAE(\gamma,\lambda)}
=\sum_{l=0}^{\infty}(\gamma\lambda)^l\delta_{t+l}.
$$

它既是多步 advantage 的混合，也可看作沿时间轴的线性滤波器。这个视角能解释 value 误差怎样向前传播。 **15.1 value 误差的望远镜展开.** 设 $V_\phi=V^\pi+e$。估计 TD error 与使用真实价值的 TD error 之差为

$$
\widetilde\delta_t-\delta_t^pi
=\gamma e_{t+1}-e_t.
$$

代入 GAE 并展开：

$$
\sum_{l\ge0}(\gamma\lambda)^l
(\gamma e_{t+l+1}-e_{t+l}).
$$

当 $\lambda=1$ 且边界处理正确，中间 value error 大量望远镜抵消，只剩起点与远端边界；$\lambda<1$ 时抵消不完全，当前及附近 value error 更直接进入 advantage。降低 $\lambda$ 减少长程 reward 噪声，也提高对局部 critic 偏差的依赖。 若 value error 随时间缓慢变化，相邻项部分抵消；若误差高频振荡，TD difference 会放大变化。只看 value error 方差看不出这种时间结构。对固定 rollout 画 $e_t$ 的自相关与 GAE error，可判断当前 $\lambda$ 在过滤哪类误差。 **15.2 有限轨迹的矩阵写法.** 长度 $T$ 的 TD error 向量记为 $\delta$，GAE 可写作上三角矩阵乘法

$$
\widehat A=M_{\gamma\lambda}\delta,
$$

其中 $M_{ij}=(\gamma\lambda)^{j-i}$ 当 $j\ge i$，其余为零。mask 在终止处切断矩阵的跨 episode 元素。若 flatten batch 后反向递推而忘记 done mask，上一条轨迹末尾 reward 会渗入下一条轨迹开头。 矩阵形式还揭示条件数。$\gamma\lambda$ 接近一且轨迹长时，早期 advantage 累积许多 TD error；一个共同 reward 偏移会沿多行传播。使用反向递推计算在数值上高效，但应与小矩阵显式乘法做单元测试，特别检查变长 padding、终止和截断。 **15.3 GAE 参数不能脱离 Critic 比较.** 相同 $\lambda$ 在不同 critic 质量下产生不同偏差方差。critic 很准时，小 $\lambda$ 的一步估计已可靠；critic 很差时，大 $\lambda$ 更依赖真实回报。训练过程中 critic 质量变化，固定 $\lambda$ 未必始终合适。 可在冻结策略的 rollout 上，用更长 Monte Carlo return 近似参照，比较不同 $\lambda$ advantage 的均方误差与 actor 梯度方向。参照本身有噪声，需要足够样本或可枚举环境。选择标准应是最终梯度估计，而不只是 advantage 与 return 的相关系数。

自适应 $\lambda$ 可以依赖状态不确定性或预测误差，但一旦它由当前轨迹未来信息决定，目标和偏差分析会更复杂。简单做法是按训练阶段或全局验证误差调整，并保留固定设置对照，避免控制器本身成为新的不稳定源。 **15.4 $\gamma$ 与 $\lambda$ 控制不同对象.** $\gamma$ 定义回报随时间的权重，$\lambda$ 决定多步估计怎样混合。两者在 GAE 中以乘积出现，作用仍有区别。固定 $\gamma\lambda$，降低 $\gamma$、提高 $\lambda$ 会改变任务目标与 TD target；提高 $\gamma$、降低 $\lambda$ 保留更长期目标，却更依赖 critic bootstrap。 例如 $(\gamma,\lambda)=(0.9,1)$ 与 $(1,0.9)$ 的 GAE 衰减同为 $0.9^l$。前者的 reward 本身折扣，后者优化未折扣有限时域回报；即使 advantage 权重形式相近，value 固定点和策略偏好仍不同。调参搜索若只按乘积比较，会把目标差异当作估计器差异。

GAE 后常减均值、除标准差。中心化可去掉 batch 常数，有限样本下仍引入样本间依赖；缩放改变每批有效 actor 步长。若不同 $\lambda$ 导致 advantage 方差不同，标准化会抹掉尺度差异，使比较集中于方向；不标准化则同时比较方向与自然尺度。实验结论应注明这一选择。 对稀疏终局奖励，$\lambda$ 接近一让信号传到早期动作；critic 若已能预测中间成功概率，较小 $\lambda$ 可用局部 TD error 降方差。按位置观察 advantage 与最终结果的相关性，能看到信用传播范围。早期位置相关性始终接近零时，继续微调全局 $\lambda$ 未必够，需要更有信息的状态表示或过程反馈。 **15.5 部分轨迹与 burn-in.**

循环 Actor-Critic 从长 episode 切固定窗口训练时，窗口起点隐藏状态必须反映此前历史。将隐藏状态清零，critic 与 actor 都在一个人为初始条件下计算；直接加载采样时隐藏状态能匹配前向值，却无法向更早历史反传。 burn-in 先用窗口前若干步重建隐藏状态，不对这些步计算 loss，再对训练段反向。若 burn-in 前的隐藏状态仍清零，它只是减弱边界影响，并未完全恢复无限历史。保存更早 checkpoint hidden state、增大 burn-in 或使用可重置记忆状态，代表不同成本与精度折中。 GAE 也要跨窗口处理。窗口末尾若 episode 未终止，使用 $V(S_T)$ bootstrap；窗口开头的 advantage 则依赖窗口内未来 TD error，不需要前一窗口 reward。RNN 参数的梯度截断与回报递推边界是两回事：可以截断计算图，同时让数值 return 正确跨越采样段。

序列随机打乱会破坏隐藏状态连续性。若训练按完整序列 batch，padding mask 同时约束 RNN 更新、value loss、policy loss 和 GAE；其中任一处漏 mask，都可能让虚假状态进入后续真实 token。用两条不同 padding 长度但真实前缀相同的样本比较隐藏状态与 loss，是直接的回归测试。 **15.6 延迟奖励与资格迹的时间含义.** 资格迹把过去 score 或 value 特征保留，并在奖励到达时更新：

$$
e_t=\gamma\lambda e_{t-1}+\nabla V(S_t).
$$

它是在线实现多步信用传播的一种方式。$\lambda$ 决定痕迹衰减，环境奖励延迟决定信号隔多久到达；若延迟远大于有效痕迹长度，早期决策仍几乎收不到更新。 异步系统中还要区分事件时间与写回时间。任务在环境时刻 $T$ 完成，人工奖励在墙上时钟若干分钟后到达，信用应归属原轨迹的状态动作，而不是此时 learner 正处理的 batch。保存 trajectory id、policy version 和时间索引，是回接延迟反馈的基本条件。 奖励尚未返回的轨迹属于删失数据。把缺失填零会把“未知”当失败，使耗时长的行为系统性受罚。等待窗口固定时，可报告各任务的反馈覆盖率；若删失在给定状态动作后独立，可用逆观察概率加权，权重小时仍会产生与 importance sampling 类似的重尾。

critic 可以预测延迟结果，提前给 actor 较密信号，但它学习的是结果模型。早期预测误差可能让 actor 改变数据分布，继而强化错误关联。定期用已经完整返回的 cohort 校准 value，并按反馈成熟时间切分训练验证，避免未来泄漏。 过程奖励能缩短延迟，却可能重复计算终局价值。若每步给的是“从此前缀出发最终成功概率”，直接累加会偏爱长轨迹；相邻 potential 差更接近进展量。检查一条轨迹的过程分数总和是否随无意义步骤增长，是发现重复计价的简单方法。 延迟还会造成策略版本错配。reward 返回时，生成轨迹的 actor 可能已落后许多轮；critic 可以用旧轨迹学习结果模型，actor 更新则需要行为概率校正或限制版本差。仅按奖励到达时间把数据放进最新 batch，会让最慢任务天然拥有最大的 Off-policy lag。

不同任务的反馈时长差异会改变训练混合比例。快速任务在同一墙上时钟内反复进入更新，慢任务即使采样比例相同，也贡献更少梯度。可以按生成批次等待完整 cohort，或对到达率做重加权；前者降低吞吐，后者增加方差。日志需同时记录生成时间、完成时间和入训时间，才能区分任务难度与管线延迟。 actor 的状态若包含“已经等待多久”，等待本身也可能是决策的一部分。超时惩罚、取消动作和继续等待形成 semi-Markov 问题，每个动作持续时间不同。按环境步折扣和按真实时间折扣给出不同偏好；选择哪一种应由部署成本定义，而非由采样器默认 tick 决定。

### 16. 连续动作 Actor-Critic 的额外边界

连续控制常用高斯 actor 与 $V$ 或 $Q$ critic。动作密度、边界变换和 critic 对动作的导数，使连续版本出现离散策略没有的问题。 **16.1 随机策略与确定性策略的两条梯度.** 随机高斯 actor 可继续使用 score gradient：

$$
\nabla J=
\mathbb E[\nabla\log\pi_\theta(A\mid S)A^\pi(S,A)].
$$

确定性 actor $A=\mu_\theta(S)$ 则使用

$$
\nabla J=
\mathbb E[\nabla_\theta\mu_\theta(S)
\nabla_aQ^\mu(S,a)|_{a=\mu(S)}].
$$

后者沿 critic 的动作梯度更新，对 critic 局部形状非常敏感。Q 值数值误差不大，动作导数仍可能错误；过拟合 critic 会产生 actor 可利用的尖锐峰。对 actor 输出附近加入动作扰动，检查 Q 曲线平滑性与真实短 rollout 回报，是比总体 Q MSE 更直接的诊断。 **16.2 动作边界与 tanh 修正.** 机器人控制常要求 $a\in[-1,1]$，先采高斯变量 $u$，再令 $a=\tanh u$。变换后 log density 为

$$
\log\pi(a\mid s)=
\log\mathcal N(u;\mu,\sigma^2)
-\sum_j\log(1-\tanh^2u_j).
$$

靠近边界时 Jacobian 项很大，数值实现常用稳定恒等式而非直接算 $\log(1-a^2)$。若环境随后再次 clip 动作，多个 $u$ 映到同一边界动作，记录的密度与实际执行分布不再一致。最好由策略自身完成有界变换，避免环境静默裁剪。 **16.3 双 Critic 与最小值偏差.** 连续动作空间中 actor 会主动寻找 critic 高估区域。使用两个独立初始化的 Q 网络并取较小值，可减少共同高估：

$$
y=r+\gamma\min(Q_{\bar\phi_1}(s',a'),Q_{\bar\phi_2}(s',a')).
$$

最小值产生负偏差，两个 critic 误差高度相关时又无法有效抑制高估。独立初始化不保证长期独立，因为它们使用同一数据与 target。记录两个 Q 的差异、相关性及与真实 rollout 的校准，能判断 ensemble 是否仍提供有效不确定性。 随机选择 critic、取均值或取较低分位数代表不同风险偏好。actor 使用哪种聚合，critic target 使用哪种聚合，也不必相同；组合过多时应明确每一步对应的估计目标，防止稳定技巧叠加后无人知道偏差方向。 **16.4 Entropy temperature 的 Actor-Critic 耦合.** 最大熵目标在回报外加入 $\alpha\mathcal H(\pi(\cdot\mid s))$。soft value 的 Bellman target 也包含下一动作的熵项：

$$
V(s)=\mathbb E_{a\sim\pi}
[Q(s,a)-\alpha\log\pi(a\mid s)].
$$

若 actor 使用熵正则，critic 却拟合不含熵的普通 return，两者对应不同目标。某些算法有意让 critic 学环境回报、actor 额外加探索项，这可以运行，但不能直接套用 soft policy iteration 的改进结论。 自动温度调整把 $\alpha$ 作为对偶变量，使策略熵接近目标值。连续动作维度增加时，目标熵常按维度缩放；动作某些维度被 mask 或固定后，有效自由度变化，原目标会推动剩余维度过度随机。目标熵应依据实际可用动作空间解释。 $\alpha$、actor 与两个 Q critic 又构成多时间尺度系统。Q 高估使 actor 偏向尖峰动作，熵项试图扩散；温度更新过快会在 critic 尚未校准时剧烈改变策略分布。分别记录环境 reward、entropy reward、Q target 与 $\alpha$，才能判断性能变化来自任务收益还是随机性价格。

### 17. 多智能体与集中式 Critic

多智能体环境中，每个 actor 只看到局部观测，训练时 critic 可以看到全局状态和联合动作。这种 centralized training with decentralized execution 用额外信息降低方差，也带来联合动作空间与非平稳性问题。 **17.1 团队奖励下的反事实 baseline.** 共享团队奖励时，agent $i$ 的动作 score 乘同一个回报：

$$
g_i=\nabla\log\pi_i(a_i\mid o_i)G.
$$

它无法区分成功由谁贡献。固定其他 agent 动作，对 $a_i$ 边缘化得到 baseline

$$
b_i(s,a_{-i})=
\sum_{a_i'}\pi_i(a_i'\mid o_i)
Q(s,a_i',a_{-i}).
$$

$Q-b_i$ 衡量当前动作相对自身替代动作的贡献，并保持 score 期望不变。离散动作少时可精确求和，动作多时需要采样或近似。critic 误差会直接污染反事实差值，尤其当两个大 Q 相减得到小 advantage 时。 **17.2 其他 Actor 造成环境非平稳.** 从单个 agent 视角看，其他策略属于环境动力学的一部分。它们同时更新时，转移分布持续变化，旧 replay 数据很快失效。集中式 critic 输入其他 agent 动作与版本信息，可解释部分变化；固定对手、交替更新或降低步长也能减缓漂移。 自博弈中的策略评价必须注明对手分布。对当前最新对手胜率高，不代表对历史策略或未见对手稳健。维护对手池并按混合分布采样，把目标从追逐单一移动对手改成对策略集合的平均表现。池的采样权重随后成为训练目标的一部分。

**17.3 参数共享改变聚合权重.** 同质 agent 常共享 actor 参数。一条联合轨迹会产生多个 agent score，它们在共享权重上相加。若 episode 中 agent 数量可变，按全部 agent-time 样本平均会让大团队轨迹权重更高；先按 episode 平均再跨 episode 平均则保持任务等权。 agent 之间观测与奖励相关，有效样本量小于名义 agent 数。随机交换 agent 身份可检验网络是否学到不应存在的编号偏见；若角色本身不同，需要显式角色特征，而不能靠固定张量位置暗示。集中式 critic 可以使用全局身份，部署 actor 的输入边界仍应与执行条件一致。 **17.4 通信动作也需要信用分配.**

多智能体策略若生成消息再执行环境动作，消息本身是影响其他 agent 的动作。发送者的 score 应接收消息对团队未来回报的贡献；接收者根据消息行动的梯度则属于接收策略。把消息当普通观测会遗漏发送决策，把它当双方共同动作又会重复计分。 可微通信允许梯度直接穿过接收者回到发送者，这条 pathwise 路径假设训练时连续消息与部署机制一致。部署使用离散符号、带宽限制或随机丢包时，直接梯度可能训练出依赖微小连续差异的协议。离散采样可用 score estimator，或用带偏松弛并在真实信道上验证。

消息 critic 需要条件于发送前信息。若 baseline 看到了接收者执行后的结果，便可能泄漏当前消息的后果，抵消应有的 advantage。集中式 critic 可以看全局状态，并不表示能跨越决策时间读取未来。按事件顺序画出信息集合，比按网络模块名称划分输入更可靠。 通信成本、长度和频率也属于回报。固定每条消息惩罚会改变最优协作协议，过大时 agent 学会沉默，过小时可能发送冗余信息。单独报告任务回报与通信成本，观察 Pareto 曲线，比只报告加权和更容易判断协议是否真正提高协作效率。 **17.5 个体奖励与团队目标的冲突.**

多智能体系统可能同时有团队奖励 $G$ 和个体奖励 $r_i$。组合 $G+\alpha r_i$ 能改善个人信用，却会改变博弈均衡。个体 shaping 若鼓励抢占共享资源，短期学习更快，团队上限反而下降。权重 $\alpha$ 应作为任务效用的一部分报告。 difference reward

$$
D_i=G(z)-G(z_{-i},c_i)
$$

用移除 agent $i$ 或替换默认行为后的团队结果衡量边际贡献。若反事实环境可准确重放，它能保留团队目标的有用方向；若用学习模型估计第二项，模型误差成为新的 credit 偏差。默认行为 $c_i$ 的选择也影响归因，沉默、平均动作和安全动作对应不同问题。 Shapley value 对所有加入顺序平均边际贡献，满足对称性等公理，计算成本随 agent 数指数增长。Monte Carlo 排列能近似，但每个排列需要许多反事实评估。它更适合作为小规模审计或训练额外 critic，不适合在大团队每步精确计算。

奖励分解还要尊重可观测信息。训练时用未来全局轨迹估算每个 agent 贡献可以作为 advantage target，执行策略仍只能条件于局部历史。若训练把未来结果直接输入 actor，部署时缺失会造成分布断裂；集中式 critic 与信息泄漏的界线就在 actor 前向是否访问这些变量。

### 18. 可复现的 Actor-Critic 数值审计

Actor-Critic 同时包含采样、回报递推、value 拟合和 policy 更新，任何一处形状或时间边界错误都可能表现成“能训练但效果差”。审计应从可枚举小环境开始，逐层加入真实系统组件。 **18.1 两状态 MDP 的完整固定点.** 设状态 $s_0$ 有两个动作。动作 $a$ 立即得到奖励 $1$ 并终止；动作 $b$ 得到奖励 $0$，转移到 $s_1$。在 $s_1$ 只有一个动作，得到奖励 $2$ 后终止。折扣 $\gamma=0.9$，策略选择 $a$ 的概率为 $p$。 状态价值为

$$
V(s_1)=2,
\qquad
V(s_0)=p\cdot1+(1-p)\cdot(0+0.9\times2)
=1.8-0.8p.
$$

两个动作价值分别为 $Q(s_0,a)=1$、$Q(s_0,b)=1.8$，优势为

$$
A(s_0,a)=1-V(s_0)=-0.8(1-p),
$$

$$
A(s_0,b)=1.8-V(s_0)=0.8p.
$$

若 $p=0.25$，则 $V(s_0)=1.6$，两个优势为 $-0.6$ 与 $0.2$。Bernoulli logit 的 score 对动作 $a$ 是 $1-p=0.75$，对动作 $b$ 是 $-p=-0.25$。期望 actor 梯度为

$$
0.25(0.75)(-0.6)
+0.75(-0.25)(0.2)=-0.15.
$$

负方向降低 $p$，使策略更多选择价值更高的 $b$。直接求导 $V(s_0)=1.8-0.8\sigma(\theta)$ 也得到 $-0.8p(1-p)=-0.15$。这给 actor、critic 与解析目标三条可互相核对的路径。 若 critic 错把 $V(s_1)$ 估成 $0.5$，一步 TD 对动作 $b$ 的 target 只有 $0.45$，advantage 可能变负，actor 会错误提高 $a$。MC 回报仍观察到 $2$，不会产生这一 bootstrap 偏差。这个例子清楚展示 critic 追踪不足怎样直接反转 actor 方向。 **18.2 GAE 递推的逐项核验.** 取三步轨迹 reward 为 $(0,1,2)$，预测 value 为 $(1.0,1.2,0.8)$，终态 value 为零，$\gamma=0.9$。三个 TD error 为

$$
\delta_0=0+0.9(1.2)-1.0=0.08,
$$

$$
\delta_1=1+0.9(0.8)-1.2=0.52,
\qquad
\delta_2=2-0.8=1.2.
$$

令 $\lambda=0.8$，$\gamma\lambda=0.72$。反向递推得到

$$
\widehat A_2=1.2,
$$

$$
\widehat A_1=0.52+0.72(1.2)=1.384,
$$

$$
\widehat A_0=0.08+0.72(1.384)=1.07648.
$$

显式求和 $\delta_0+0.72\delta_1+0.72^2\delta_2$ 应得到同一结果。将第二步设为真实终止后，递推必须在该处切断，第三步数据属于下一条 episode；将其设为时间截断，则用 final observation 的 value bootstrap，再结束当前 buffer 段。两种 mask 可用同一组数字测试。 critic return 通常为 $\widehat A_t+V(S_t)$。若 advantage 随后做 batch 标准化，标准化后的量不能再加回 value 作为 critic target，因为中心和尺度已经改变。应在标准化前保存原始 GAE，actor 使用处理后的副本，critic 使用原始 return。 **18.3 Detach 与共享骨干的计算图.** 设共享表示 $h=f_\omega(s)$，policy head 参数为 $u$，value head 参数为 $v$：

$$
\pi=\pi_u(h),\qquad V=v^Th.
$$

actor loss 中的 advantage 若由 $V$ 构造且未 detach，$\nabla_vL_{actor}$ 与通过 $V$ 回到 $\omega$ 的梯度会出现。此时 critic 可以通过改变 baseline 本身降低 actor loss，而无需改善策略。标准策略梯度把 advantage 当作固定样本权重，因此应切断这条路径。 切断 advantage 不意味着共享骨干只收 actor 梯度。value loss 仍通过 $v^Th$ 更新 $\omega$，entropy loss 也通过 policy head 更新它。可分别对三个 loss 单独反向，保存共享层梯度 $g_p,g_v,g_e$，验证联合梯度等于加权和。若使用梯度累积，要在相同参数点计算各项；某项 step 后再算下一项，等式不再成立。 target value 通常应 detach。若 $R+\gamma V(S')$ 保留梯度，value loss 会同时调整当前与下一状态预测。residual-gradient 方法会有意保留这条路径，并采用相应的推导与收敛条件。`detach` 的取值直接选择 semi-gradient TD 或完整 residual 优化。 **18.4 损失归一化与变长 batch.** 设有效 mask 为 $m_{t,n}$。token 或时间步平均的 policy loss 为

$$
L_\pi=-
\frac{\sum_{t,n}m_{t,n}\log\pi(a_{t,n}\mid s_{t,n})
\widehat A_{t,n}}
{\sum_{t,n}m_{t,n}}.
$$

它让每个有效决策等权，长轨迹贡献更多。若先对每条轨迹除以自身长度，再对轨迹平均，则 episode 等权。两者对应不同状态访问加权；padding mask 正确也不意味着目标选择正确。 分布式 worker 的有效步数可能不同。每个 worker 先对本地有效步求均值，再 all-reduce 均值，会让短 worker 与长 worker 权重相同。正确的全局 step mean 需要 all-reduce loss sum 和有效计数，再相除。value loss、entropy 和 KL 都要使用一致或明确不同的分母。 advantage 标准化若在各 worker 本地进行，每个 worker 获得不同中心与尺度；全局标准化需聚合 sum、square sum 和 count。小本地 batch 会让标准差噪声很大，也会让同一条样本在不同并行切分下得到不同权重。固定全局 batch 后改变 worker 数，应成为回归测试的一部分。 **18.5 随机性与结果区间.**

A3C 的异步调度使更新顺序也成为随机源。同样种子与初始参数，在不同线程时序下会得到不同轨迹。A2C 同步聚合更易复现，但 GPU kernel、环境并行顺序和分布式规约仍可能带来差异。完全逐位确定通常牺牲吞吐，实验至少要通过多种子区间反映这种变化。 策略回报沿训练时间相关，不能把同一次运行的连续评估点当作独立样本计算显著性。独立训练种子是算法比较的基本单位；每个种子内部可用多个 episode 降低评估噪声。报告种子均值、离散程度和每个种子的完整曲线，避免只选峰值或最好种子。

两种算法使用相同初始化、任务序列与评估种子可形成配对比较，降低外部方差。训练策略不同后，动作随机数即使相同也不再代表完全相同轨迹，但环境起点与任务配对仍有价值。最终结论应同时看平均差、配对差分布和失败种子，而不只看最终均值的小数点。 **18.6 从梯度检查到学习曲线.** 小环境解析梯度通过后，还需要确认多次更新确实提高对应目标。选择很小学习率，固定一批可枚举状态，更新前后精确计算 $J$。一阶预测为

$$
J(\theta+\alpha\widehat g)-J(\theta)
\approx\alpha\nabla J^T\widehat g.
$$

若内积为正而真实目标下降，可能是步长过大、二阶曲率显著；逐步减小 $\alpha$ 后仍下降，则要检查估计分布、符号和目标定义。这个测试把梯度正确性与优化器有限步行为分开。 critic 更新也可做类似检查。冻结 target 与数据时，一小步应降低所声明的监督 loss；重新计算 bootstrap target 后 loss 上升不一定是错误，因为目标移动了。日志应同时保存更新前固定 target loss和更新后刷新 target loss，避免把两种量连成一条曲线。 端到端训练中，actor reward、critic error 与策略 KL 有典型时间关系。critic error 先升、随后恢复，可能是 actor 进入新状态后的正常追踪；error 持续升且 value 绝对值扩大，更像 bootstrap 不稳定；error 很低但 reward 不动，可能是 advantage 过小、策略梯度被裁剪或 critic 只拟合容易状态。

一次异常更新应能回溯到原始轨迹。保留少量高梯度样本的状态、动作、reward、value、advantage、ratio 和 mask，并记录模型与奖励版本。仅保存聚合统计无法判断极值来自真实稀有成功、错误终止边界还是数值溢出。隐私敏感数据可保存哈希、合成复现样本和充分统计量，但必须维持诊断链条。 **18.7 一套端到端故障定位顺序.** reward 异常时，先固定模型与一小批轨迹，重算 return、TD error 和 GAE，排除数据与边界问题。随后冻结 advantage，只检查 policy loss 对 logits 的梯度符号；再冻结 policy，只检查 value loss 是否朝固定 target 下降。两边单独正确后，才恢复共享骨干与联合优化。 策略 KL 突然增大时，将参数步拆成各层贡献。输出 head 变化大，常见原因是 advantage 尺度或学习率；共享骨干变化大，可能是 value coefficient、critic outlier 或优化器状态。比较 unclipped gradient、clipped gradient 和最终 optimizer update，能确定变化发生在估计、裁剪还是预条件阶段。

value 爆炸时，沿 target 递推向后找第一个异常状态。检查该处 reward、终止 mask、下一状态 value 与 replay ratio；若 target 正常而预测发散，再看学习率、归一化和函数逼近。只在最终 value 上加 clip 会遮住来源，异常 target 仍会反复撞击边界。 回报停滞且所有数值稳定时，确认 actor 确实改变了采样分布。固定 prompt 或状态上比较更新前后动作概率，若 KL 近零，检查 advantage 是否全零、detach 是否切错、loss 分母是否过大；若 KL 明显而 reward 不变，策略方向、探索覆盖或奖励可利用性更值得怀疑。 吞吐优化放在数值正确之后验证。更换 fused kernel、混合精度、梯度累积或异步 rollout 时，用同一固定 batch 比较 loss、梯度余弦和单步参数差。允许的浮点误差应预先设阈值；差异若随序列长度、worker 数或 padding 比例系统变化，通常是归一化语义被改变。

最终回归集应包含 bandit、两状态 MDP、真实终止、时间截断、变长 padding、旧策略数据和共享网络七类最小样本。它们分别覆盖 score 符号、bootstrap、mask、importance ratio 与梯度边界。复杂训练出现回归时，先让这组小测试指出哪条数学不变量被破坏，再回到大规模日志定位具体数据。 性能回归还要区分算法变化与评估噪声。固定 checkpoint 在同一评估集重复采样，可以估计解码随机性；固定解码并更换任务样本，可以估计任务抽样误差；重新训练多个种子则包含优化路径差异。三层方差混在一个误差条里时，很难决定增加评估 episode 还是增加训练种子。

比较吞吐时应使用相同的环境交互预算与近似相同的评估频率。A3C 按墙上时间可能领先，却使用更多环境步；样本效率与时间效率是两个坐标。critic 多做更新消耗算力但不增加交互，环境昂贵时可能划算，模拟器便宜时未必。报告 environment steps、optimizer steps、tokens 与 wall-clock，才能还原取舍。 保存配置仍不足以完全复现，环境版本、奖励模型、tokenizer、终止规则和数值库都会改变轨迹。给这些依赖记录内容哈希，并保留一批原始轨迹及其逐步派生量，可在实现升级后重放。重放结果一致而重新采样结果变化，问题多半位于环境或生成侧；重放本身已变化，则先检查数学管线。
