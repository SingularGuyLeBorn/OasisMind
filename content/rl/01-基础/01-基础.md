# 强化学习基础

强化学习研究的是序贯决策:Agent 在状态中选择动作,环境返回奖励并转移到新状态,而当前动作会改变未来能遇到的数据.这使它与固定数据集上的监督学习有一个根本差异:策略既是要优化的对象,也是采样分布的一部分.策略参数变化后,状态与动作出现的频率也会变化;同一条轨迹中的奖励还要跨时间分配给多个动作.本章用统一符号处理这两个问题,再把经典算法看成对价值估计、采样方式和更新幅度的不同选择.

七个直属节点构成一条连续依赖链.[概率与 MDP 基础](./01.01-概率与mdp/01.01-概率与mdp.md)定义环境和轨迹分布;[Bellman 方程](./01.02-贝尔曼方程/01.02-贝尔曼方程.md)把长期回报写成一步递归,由此连接 DP、MC 与 TD;[策略梯度](./01.03-策略梯度/01.03-策略梯度.md)直接对策略目标求导;[REINFORCE](./01.04-reinforce/01.04-reinforce.md)给出 Monte Carlo 策略梯度估计;[Actor-Critic](./01.05-actor-critic/01.05-actor-critic.md)用 critic 和 bootstrap 降低方差;[TRPO](./01.06-trpo/01.06-trpo.md)约束策略更新;[PPO](./01.07-ppo/01.07-ppo.md)再把信任区域思想改成更容易实现的一阶目标.

## 1. 统一对象与符号

### 1.1 MDP 与轨迹

用五元组 $(\mathcal S,\mathcal A,P,r,\gamma)$ 表示 Markov Decision Process.在时间 $t$,状态为 $S_t=s$,Agent 按策略 $\pi_\theta(a\mid s)$ 采样动作 $A_t=a$,环境按转移核 $P(s'\mid s,a)$ 产生 $S_{t+1}=s'$,并给出奖励 $R_{t+1}$.折扣因子 $\gamma\in[0,1)$ 控制远期奖励权重.一条轨迹写成 $\tau=(S_0,A_0,R_1,S_1,\ldots)$,其概率由初始状态分布、策略和环境转移共同决定.

从时刻 $t$ 开始的折扣回报定义为

$$
G_t=\sum_{k=0}^{\infty}\gamma^k R_{t+k+1}.
$$

有限 horizon 时求和在终止步停止.奖励 $R_{t+1}$ 是一次转移的即时反馈,回报 $G_t$ 是从当前位置向后的随机累计量.后文所说“最大化回报”指在策略诱导的轨迹分布下最大化期望,不能把单步 reward 与完整 return 混用.

### 1.2 价值、优势与占用分布

状态价值和动作价值分别定义为

$$
V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s],\qquad
Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].
$$

优势函数为 $A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$.它回答在状态 $s$ 选择动作 $a$,相对策略的平均选择好多少.从 $Q$ 减去只依赖状态的 baseline 不改变策略梯度期望,却能降低方差;Actor-Critic 与 PPO 中的优势估计由此进入更新.

折扣状态占用分布记为

$$
d^\pi_\gamma(s)=(1-\gamma)\sum_{t=0}^{\infty}\gamma^t\Pr_\pi(S_t=s).
$$

状态—动作占用分布为 $\rho^\pi_\gamma(s,a)=d^\pi_\gamma(s)\pi(a\mid s)$.占用分布明确了期望“对什么数据取平均”.On-policy 算法使用当前或足够接近当前的策略生成数据;Off-policy 算法使用其他行为策略的数据时,必须处理分布差异.

## 2. Bellman 递归把长期目标拆成一步

### 2.1 期望方程与最优方程

Markov 性允许把回报拆成即时奖励和下一状态的剩余回报:

$$
V^\pi(s)=\mathbb E_{a\sim\pi,,s'\sim P}
\left[r(s,a,s')+\gamma V^\pi(s')\right].
$$

对应的 $Q^\pi$ 方程还要对下一动作按 $\pi$ 取期望.最优价值则把策略期望替换为动作最大化,得到 Bellman optimality equation.前者评估固定策略,后者描述最优控制的不动点.二者的算子不同,不能把 policy evaluation 中的期望备份与 Q-learning 一类最大化备份混写.

Bellman 方程提供了可递归估计的结构,但没有规定用什么数据或怎样更新.DP、MC 与 TD 的差别由此出现:它们估计相同价值对象,却使用不同可用信息和 target.

### 2.2 DP、MC 与 TD

Dynamic Programming 假定转移和奖励模型已知,对所有状态执行期望备份.迭代策略评估计算 $V^\pi$,策略改进再选择对当前价值更优的动作;两者交替形成 policy iteration.价值迭代把评估与改进合并为最优 Bellman 备份.DP 的限制不是递归公式错误,而是需要环境模型并遍历状态空间.

Monte Carlo 不需要转移模型,等完整 episode 结束后用实际 $G_t$ 作为 $V$ 或 $Q$ 的 target.MC target 对真实回报无 bootstrap 偏差,但方差较大,且通常要等待终止.Temporal-Difference 用

$$
\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)
$$

形成一步 bootstrap target.TD 能在线更新且方差较低,代价是 target 依赖当前不准确的价值估计,会引入偏差.多步 return 与 $\lambda$-return 位于 MC 和一步 TD 之间;GAE 后来把同一偏差—方差轴用于优势估计.

**DP、MC、TD 不是三种互斥任务,而是计算 Bellman 对象时对模型、采样和 bootstrap 的三种选择.** 读后续算法时先定位 critic target 属于哪一类,再讨论收敛和方差.

## 3. 从价值估计到策略梯度

### 3.1 策略梯度定理

设目标 $J(\theta)=\mathbb E_{\tau\sim\pi_\theta}[G_0]$.Log-derivative trick 把不可直接对轨迹采样求导的问题变成

$$
\nabla_\theta J(\theta)
=\mathbb E_{s\sim d^{\pi_\theta},,a\sim\pi_\theta}
\left[\nabla_\theta\log\pi_\theta(a\mid s)Q^{\pi_\theta}(s,a)\right].
$$

策略梯度定理已经把状态占用分布随 $\theta$ 变化的影响收进结果,实现时不对环境转移求导.将 $Q$ 换成 $A$ 或减去 $V(s)$ baseline 仍保持期望方向.关键随机量是采到的状态、动作和用于权重的回报或优势.

### 3.2 REINFORCE 与 Actor-Critic

REINFORCE 用 episode return $G_t$ 替代未知的 $Q^\pi(S_t,A_t)$,得到无模型、On-policy 的 Monte Carlo 梯度估计.它简单且期望正确,但长轨迹回报噪声很大,一次采样通常只能更新有限次数.加入状态 baseline 能降方差,baseline 若由参数化价值函数学习,就进入 Actor-Critic.

Actor 更新策略 $\pi_\theta$,Critic 估计 $V_\phi$ 或 $Q_\phi$,优势可由 TD error、多步 return 或 GAE 构造.Critic 的 bootstrap 降低方差,同时引入估计偏差.若 Actor 与 Critic 共享主干,还需明确两个损失怎样加权,梯度是否共同更新共享参数.因此 Actor-Critic 不是单一损失公式,而是一种角色分工.

## 4. 从无约束更新到 TRPO 与 PPO

### 4.1 为什么要约束新旧策略

策略数据由旧策略 $\pi_{\theta_{old}}$ 采集,更新时却评估新策略 $\pi_\theta$.重要性比率

$$
r_t(\theta)=\frac{\pi_\theta(A_t\mid S_t)}
{\pi_{\theta_{old}}(A_t\mid S_t)}
$$

可以在旧策略样本上构造 surrogate objective,但比率偏离 1 太多时方差和近似误差会迅速增大.策略变化还会改变未来状态占用分布,单纯提高采样动作的概率不保证新策略整体性能单调改善.

TRPO 在 surrogate objective 外施加平均 KL constraint,用二阶近似、共轭梯度和 line search 寻找受限更新.它把“策略不要走太远”写成显式优化问题,实现成本较高.KL 方向、期望所用状态分布和近似求解步骤都属于算法定义的一部分.

### 4.2 PPO 的一阶近似

PPO-Clip 使用

$$
L^{clip}(\theta)=\mathbb E_t\left[
\min\left(r_t(\theta)\hat A_t,
\operatorname{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat A_t
\right)\right].
$$

当正优势动作概率被提高过多,或负优势动作概率被降低过多时,裁剪分支限制继续获益.`min` 的行为依赖 $\hat A_t$ 符号,不能把公式简化成“所有 ratio 都截到区间内”.PPO 还常联合 value loss、entropy bonus、优势标准化、梯度裁剪和多 epoch minibatch 更新.这些是完整训练器的一部分,但应与 clipped policy objective 分开说明.

PPO 没有继承 TRPO 的严格约束求解,clip 也不保证每次更新的实际 KL 一定很小.工程实现通常监控 approximate KL、clip fraction、entropy、value error 和 explained variance,必要时提前停止 epoch.**PPO 的稳定性来自目标、优势估计、优化超参数和诊断共同作用,不能归因于一个 `clip` 调用.**
