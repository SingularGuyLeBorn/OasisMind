# OREO: 基于 soft Bellman consistency 的离线推理优化

**论文信息**:
- **标题**: Offline Reinforcement Learning for LLM Multi-Step Reasoning
- **作者**: Huaijie Wang, Shibo Hao, Hanze Dong, Shenao Zhang, Yilin Bao, Ziran Yang, Yi Wu (UC San Diego, Tsinghua University, Salesforce Research, Northwestern University)
- **年份**: 2024 (v1 提交于 2024-12-20, v2 修订于 2024-12-25)
- **论文**: [arXiv:2412.16145](https://arxiv.org/abs/2412.16145); 官方代码: [github.com/jwhj/OREO](https://github.com/jwhj/OREO)

**前置知识**: GRPO(1.3.1.1 节), RLOO(1.3.1.2 节), DAPO(1.3.2.1 节), RLVR(1.3.4.1 节)

OREO (Offline REasoning Optimization) 处理的问题: 手里只有一批离线轨迹, 每条轨迹只带一个终局奖励 (答案对或错, 任务成或败), 想让模型从这些数据里学到更好的多步推理. 1.3.4.1 节的 RLVR 路线是在线方法: 每轮用当前策略采样, 用 verifier 给分, 再用 GRPO 一类的算法更新. OREO 走另一条路: 训练全程不与环境交互, 数据采一次, 之后只反复过数据. 代价是看不到当前策略的新错误, 收益是训练成本结构接近 SFT, 且对没有 rollout 基建的场景直接可用.

方法一句话: 对 KL-regularized RL 的 soft Bellman equation 做 telescoping, 把「轨迹的总奖励」摊成「每一步的 value 差分加当前步的 policy 偏移」, 再用平方残差同时拟合 value 网络与 policy 网络. 奖励信号是稀疏的, 残差约束是逐步的, 信用分配就来自这个「逐步」.

OREO 属于 RLHF 文献里常被混用的一组概念, 先划清边界: 它说的 offline 指训练阶段不采样, 与 DPO 这类离线偏好方法同侧; 它说的 RL 指目标来自序贯决策的 Bellman 结构, 不是指带 importance sampling 的策略梯度. 全文没有一个重要性权重, 这是它和经典离线 RL 在形态上最大的分野.

## 1. 动机: 离线推理数据的两个结构性缺口

### 1.1 成对偏好数据不是离线轨迹的天然形态

DPO 的输入是成对偏好: 同一 prompt 下一条 winner 和一条 loser. 多步推理任务的离线数据不长成这样: 通常是独立采的一批轨迹, 每条带一个终局奖励. 要用 DPO, 得先做一道数据加工, 按奖励把同一道题的轨迹两两配对. 这道加工不是中性的: 配对规则 (按最终答案配, 按长度配, 按步数配) 决定 DPO 看到什么, 而加工本身还浪费数据——一半轨迹只能当 loser 用.

更麻烦的是, 这道加工的收益存疑. OREO 论文引言引用的已有观察 (Yuan et al., 2024; Pang et al., 2024) 是: 在这类任务上 DPO 的提升很小, 有时甚至不如直接 SFT. 论文自己的实验复现了这一点 (§5.1). KTO 能摆脱成对结构, 用单条样本的「好/坏」标注, 但它和 DPO 共享同一个更深的前提: 把整条回答当作一个整体打分. 这个前提在偏好场景合理, 在稀疏奖励的推理场景恰好是问题本身.

OREO 的数据要求因此压到很低: 一批未配对的轨迹, 每条一个终局奖励, 一个参考策略 (通常就是 SFT checkpoint). 不需要配对, 不需要逐步标注, 不需要优势估计的额外采样. 数据里有什么, 目标就用什么; 失败轨迹不扔, 只是让它在残差里承担负的贡献.

### 1.2 稀疏终局奖励要求信用分配

推理任务的奖励几乎只出现在最后一步: 数学题答案对了整条链拿 1, 错了拿 0; ALFWorld 里 40 步内完成任务才给奖励. 一条 500 token 的推理链, 只有一个标量监督. 拒绝采样 (STaR, RAFT, REST 这一族) 的做法是只保留成功轨迹做 SFT: 简单, 常用, 但它把失败轨迹整个扔掉, 而失败轨迹通常占离线数据的大头. 更细的问题是: 即使一条链整体失败, 它的前 400 个 token 可能全对, 错只在某一步; 整体丢弃等于宣布这些信息无用, 整体保留又无从惩罚——SFT 对 token 的梯度没有奖励符号的概念.

这是第二个缺口: 稀疏奖励需要与 token 粒度对齐的信用分配机制, 整条链二选一的监督不够. OREO 引入显式 value 函数, 让恒等式 $V^*(s_t)-V^*(s_{t+1})=r-\beta\log\frac{\pi^*}{\pi_{ref}}$ 在每个位置约束它, 无需为每个 token 另估一份独立回报. 同一位置, value 差分大说明这一步关键, 差分接近零说明这一步可有可无, 奖励信号就这样摊到了 token 上.

这个机制对失败轨迹同样工作. 失败轨迹 $R=0$, 式 (7) 给出 $V^*(s_t)=-\beta\sum_{i\ge t}\log\frac{\pi^*}{\pi_{ref}}$, 残差不为零的位置就是 policy 当前偏移与「让这条失败链更可能」之间的张力所在. 拒绝采样对这些位置无话可说, OREO 的每个位置都有话可说——成败轨迹用的是同一套目标, 这是 §5.3 迭代实验里失败轨迹价值的来源.

### 1.3 在线方法的成本结构

1.3.1.1 节的 GRPO 和 1.3.2.1 节的 DAPO 解决同一个信用分配问题, 但它们是在线的: 每轮训练要现采数据, rollout 成本占训练成本的大头, 且要与验证器或环境实时交互. 对很多实际场景 (没有 rollout 基建, 只有别人采好的日志, 或环境交互太贵), 这个成本结构直接排除了在线方法. 离线方法的承诺是: 数据一次采好, 训练只过数据. OREO 的设定更苛刻一步: 它不要求轨迹来自当前策略, 也不要求能继续采样, 只要求每条轨迹带终局奖励.

代价要摆在明处: 离线方法的上界受数据覆盖范围限制, 策略改进到数据边缘就停. OREO 对此的回应是迭代扩展 (§5.3): 每轮训练后允许用更新后的策略补采一批新数据, 回到在线与离线之间的混合形态. 纯离线是它的最小配置, 不是它的上限. 这个结构与 1.3.1.2 节 RLOO 的取舍相映: RLOO 用多次采样摊销 baseline 的成本, OREO 用离线数据摊销采样的成本, 两者都在回答「交互太贵怎么办」.

## 2. Soft Bellman consistency: 从 KL 正则目标到逐步恒等式

### 2.1 KL-regularized 目标与 soft Bellman equation

记状态 $s_t$ 为 token 序列 (prompt 加已生成的部分), 动作 $a_t$ 是下一个 token. 纯推理任务的转移是确定性拼接 $s_{t+1}=f(s_t,a_t)=s_t\|a_t$, 随机性全部藏在初始 prompt 里; 具身任务略有不同, 若 $a_t$ 是 agent 一轮回复的结尾 token, 转移还要在序列后追加环境的下一条观测, 即 $s_{t+1}=s_t\|a_t\|\text{next observation}$. 两种设定下 OREO 的目标形式不变. 从带 KL 正则的目标出发 (论文式 (1)):

$$
\max_\pi\; \mathbb E_{(s_0,\dots,s_T)\sim\rho_\pi}\sum_{t=0}^{T}\left[r(s_t,a_t)-\beta\log\frac{\pi(a_t|s_t)}{\pi_{ref}(a_t|s_t)}\right].
$$

$\pi_{ref}$ 是参考策略, 通常是预训练加 SFT 的模型; $\beta$ 控制正则强度; 和 RLHF 的常规设定一样, 折扣因子省略. 这个目标的最优策略 $\pi^*$ 与最优价值函数 $V^*$ 满足 soft Bellman equation (论文式 (3), 理论源自 entropy-regularized RL, Nachum et al. 2017):

$$
V^*(s_t)-V^*(s_{t+1})=r(s_t,a_t)-\beta\log\frac{\pi^*(a_t|s_t)}{\pi_{ref}(a_t|s_t)}.
$$

这里的 $V^*$ 是 KL-regularized return: 从 $s_t$ 出发的「未来奖励减去逐 token log-ratio 惩罚」的期望. KL 散度可分解为交叉熵减熵, $D_{KL}(\pi\|\pi_{ref})=\mathbb E_\pi[-\log\pi_{ref}]-\mathbb E_\pi[-\log\pi]$, 所以「减 KL」等价于「加熵减交叉熵」, 上式就是 max-ent RL 的 Bellman 方程换参照系, $\beta=0$ 时退化为标准 Bellman equation. 论文 Theorem 2 给的充分条件更直接: 若某个策略 $\pi$ 和某个价值函数 $V$ 对所有状态—动作对都满足上式的一致性, 则 $\pi=\pi^*$ 且 $V=V^*$.

这条定理是 OREO 的方法论支点: 它把「解 Bellman 不动点」换成「拟合一致性残差」. 传统 value-based 方法要反复做 backup 迭代, 收敛依赖压缩映射; 一致性残差把最优性条件摊成每个位置一个监督信号, 监督学习直接可用, 不需要 bootstrap, 这是它能直接嫁接到 LLM 训练的原因.

### 2.2 稀疏奖励下的 telescoping

推理任务里 $r(s_t,a_t)$ 只在终点非零: 设终端步为 $T$, 终局奖励 $R\in\{0,1\}$, $t<T$ 时 $r=0$. 把上式从 $t$ 加到 $T$, 中间项全部抵消 (telescoping), 得到论文式 (7):

$$
V^*(s_t)=\underbrace{R_t}_{从 t 开始的剩余奖励}-\beta\sum_{i\ge t}\log\frac{\pi^*(a_i|s_i)}{\pi_{ref}(a_i|s_i)}.
$$

稀疏奖励下 $R_t=R$ 对一切 $t$ 成立, 每步的恒等式只剩三项: 该位置的 value, 整条轨迹的总奖励, 从该位置开始的 suffix log-ratio. 注意求和下标包含 $t$ 自己 ($i\ge t$). DPO 用的正是同一个 telescoping 在 $t=0$ 的特例 (论文式 (4)); OREO 的差别是把约束保持在每个 $t$ 上, 这是 §4.2 展开的对照.

式 (7) 保留了两处 response 级方法会丢掉的信息. 其一是 $V^*(s_t)$ 随 $t$ 变化的整体形状, 相邻位置的差分对应每步的即时量; 其二是 suffix log-ratio 的结构——早期 token 携带整条链的偏移信息, 晚期 token 只携带自己的.**信用分配的粒度就来自这个后缀结构, 而不是来自任何额外的标注.**

### 2.3 手算: 三步轨迹上验证恒等式

假设: 轨迹长 $T=3$, 只在终点给奖励 $R=1$, $\beta=0.1$, 最优策略相对参考策略在三个 token 上的 log-ratio 分别为 $\ell_0=0.2$, $\ell_1=-0.1$, $\ell_2=0.3$ (正值表示最优策略给该 token 的概率高于参考策略), 终态取值 $V^*(s_3)=0$. 数字是构造的, 用于验证代数, 不代表任何真实模型.

按论文式 (7) 从后往前算. $t=2$: suffix 只有 $\ell_2$, $V^*(s_2)=1-0.1\times0.3=0.97$. $t=1$: suffix 是 $\ell_1+\ell_2=0.2$, $V^*(s_1)=1-0.1\times0.2=0.98$. $t=0$: suffix 是 $\ell_0+\ell_1+\ell_2=0.4$, $V^*(s_0)=1-0.1\times0.4=0.96$.

再代回式 (3) 逐步验. $t=0$: $V^*(s_0)-V^*(s_1)=0.96-0.98=-0.02$, 右边 $r-\beta\ell_0=0-0.1\times0.2=-0.02$, 一致. $t=1$: $0.98-0.97=0.01$, 右边 $-\beta\ell_1=-0.1\times(-0.1)=0.01$, 一致. $t=2$: $0.97-0=0.97$, 右边 $1-0.1\times0.3=0.97$, 一致. telescoping 在这个数值例子里就是把三个差分加总: $-0.02+0.01+0.97=0.96=V^*(s_0)-V^*(s_3)$.

这组数字还说明一件事: $\ell_1=-0.1$ 的那一步, value 不降反升 ($V^*(s_1)>V^*(s_2)$), 因为「参考策略比最优策略更偏好这个 token」等价于「最优策略在此处收得更紧」, 该步对 KL 正则目标的贡献为正. 单看奖励信号, 三个 token 没有任何区别; 单看 value 差分, 每一步都有确定的符号和大小.

### 2.4 从 soft Q 的归一化得到一致性

论文附录 B 的证明可以展开成一条闭环。先把 reference 写进整形奖励：

$$
\widetilde r(s,a)=r_{task}(s,a)+\beta\log\pi_{ref}(a\mid s).
$$

最大熵 RL 的最优 soft Q 与 value 满足

$$
Q^*(s,a)=\widetilde r(s,a)+\mathbb E[V^*(s')\mid s,a],
$$

$$
V^*(s)=\beta\log\sum_a\exp\left(\frac{Q^*(s,a)}{\beta}\right),
\qquad
\pi^*(a\mid s)=\exp\left(\frac{Q^*(s,a)-V^*(s)}{\beta}\right).
$$

把 $\widetilde r$ 展开，并把 $\log\pi_{ref}$ 移到策略一侧，就得到

$$
V^*(s)-\mathbb E[V^*(s')\mid s,a]
=r_{task}(s,a)-\beta\log\frac{\pi^*(a\mid s)}{\pi_{ref}(a\mid s)}.
$$

语言生成的转移是确定性拼接，条件期望退化为单个 $V^*(s_{t+1})$，恰好得到论文式 (3)。这条推导说明 reference 并非外加的行为克隆项：它先进入整形奖励，再通过 softmax 归一化决定最优策略的相对密度。式 (9) 末尾的 $\alpha\mathcal L_{reg}$ 才是额外加入的稳定正则。

归一化也解释 Theorem 2 为什么要求所有动作满足一致性。若对固定状态的每个动作都有

$$
\pi(a\mid s)=\pi_{ref}(a\mid s)
\exp\left(\frac{r(s,a)+V(s')-V(s)}{\beta}\right),
$$

对动作求和并使用 $\sum_a\pi(a\mid s)=1$，$V(s)$ 必须等于对应的 soft log-partition，策略也被唯一确定。若方程只在数据动作上成立，未观测动作不参与归一化检验，经验低残差无法推出全动作最优性。这是 §9.1 中“定理条件强于训练条件”的代数原因。

交互环境的转移若有随机性，单条轨迹只给 $V(s')$ 的一次样本。期望形式仍成立，样本 residual 多出环境转移噪声；同一动作在不同随机种子下可能得到不同 observation 和终局奖励。ALFWorld 的文字环境相对可控，迁移到网页、代码执行或远程工具时，应固定环境版本并对同一状态动作重放，区分策略不一致与环境方差。

论文按 RLHF 常规省略折扣。若任务确实需要 $\gamma<1$，方程变为

$$
V^*(s_t)-\gamma V^*(s_{t+1})
=r_t-\beta\log\frac{\pi^*(a_t\mid s_t)}{\pi_{ref}(a_t\mid s_t)},
$$

telescoping 后的奖励和 log-ratio 都带 $\gamma^{i-t}$ 权重。直接在现有式 (7) 里只给终局奖励乘折扣，会破坏一致性；value target、policy residual 与 future suffix 必须同步修改。折扣能降低长后缀方差，也系统性偏向短路径，属于目标变化而非数值技巧。

## 3. 联合目标: value loss, policy loss 与 stop-gradient

### 3.1 两个损失的结构

OREO 同时训练两个网络: policy $\pi_\theta$ 就是语言模型本身, value $V_\phi$ 是独立参数化的标量函数, 输入 token 序列输出一个数. Value loss 直接拟合论文式 (7) 的右端:

$$
\mathcal L_V(\phi)=\frac1T\sum_{t=0}^{T-1}\left(V_\phi(s_t)-R_t+\beta\sum_{i\ge t}\log\frac{\pi_\theta(a_i|s_i)}{\pi_{ref}(a_i|s_i)}\right)^2.
$$

Policy loss 用同一个恒等式, 但当前步的 log-ratio 开梯度, 未来步的 suffix 停止梯度 (论文式 (9)):

$$
\mathcal L_\pi(\theta)=\frac1T\sum_{t=0}^{T-1}\left(V_\phi(s_t)-R_t+\beta\log\frac{\pi_\theta(a_t|s_t)}{\pi_{ref}(a_t|s_t)}+\operatorname{sg}\left[\beta\sum_{i>t}\log\frac{\pi_\theta(a_i|s_i)}{\pi_{ref}(a_i|s_i)}\right]\right)^2+\alpha\,\mathcal L_{reg}.
$$

$\operatorname{sg}[\cdot]$ 是 stop-gradient; $\mathcal L_{reg}$ 是 policy 相对参考策略的逐状态 KL, 系数 $\alpha$, 起稳定作用. 对照两式: value loss 的梯度只进 $V_\phi$ (实现上 $\pi_\theta$ 在式 (8) 中以 detach 形态进入, 否则 $\theta$ 会收到两份互相矛盾的梯度), policy loss 里只有 $i=t$ 那一项对 $\theta$ 可导. 两个网络各拿同一个恒等式的一半自由度, 这就是「联合训练」的确切含义.

工程形态上, 一个 batch 就是若干条定长 padding 的轨迹, 每个有效位置出一个残差, 两个 loss 用同一批前向的 logp 与同一组 value 读数. 参考策略的 logp 只依赖冻结模型, 可以预先算好缓存; value 网络每步都要读完整前缀, 实现上挂在 policy 旁边共用一个 tokenizer 与批处理管线即可, 不需要额外的采样或环境代码. 整个训练循环与 SFT 同构, 差别只在 loss.

### 3.2 stop-gradient 的职责

sg 出现的位置决定信用如何分配. 若 policy loss 里 suffix 也开梯度, $t$ 位置的更新会同时扰动 $i>t$ 位置的 log-ratio, 一步的残差经由未来步回流, 梯度尺度随轨迹长度累积, 长短轨迹的贡献不可比. sg 把 $t$ 位置的残差限制成只关于「$V_\phi(s_t)$ 对该位置的估价」和「该位置自身的 log-ratio」两件事, **每一步的梯度尺度只由残差和 $\beta$ 决定, 与轨迹长度无关**.

论文对 sg 的解释只有一句: 让每一步的梯度尺度相同. 顺着 §2.3 的数值看这句话: 残差对 $\ell_t$ 的偏导是 $2e\beta$; 若 suffix 可导, 还要叠上 suffix 对 $\theta$ 的雅可比, 其量级随 suffix 长度增长. sg 消掉这个量级差以后, 批内长短轨迹的 token 才是同一量纲的贡献. 这也解释了粒度变体的一个不对称: response-level 目标 (§4.1) 天然只有一个残差, 没有逐步尺度问题——它用放弃粒度来换尺度一致.

sg 还有一个容易被忽略的副作用: policy loss 的目标值里含 $\operatorname{sg}[\text{suffix}]$, 而 suffix 来自当前 policy 自己, 所以 policy loss 是一个移动目标, 目标随 policy 更新而漂移. 这一步漂移被 value loss 牵制: $V_\phi$ 同时在被拉向式 (7) 的右端, 两个 loss 收敛到同一个不动点. 单独训练 policy loss (冻结 value) 或单独训练 value loss (冻结 policy) 都不会到达 Theorem 2 的一致性, 联合优化由定理条件决定, 并非单纯的工程便利.

### 3.3 手算: 单步残差的数值与梯度方向

假设: $\beta=0.1$, 某位置 $t$ 上有 $V_\phi(s_t)=0.5$, $R_t=1$, 其后 suffix 的 log-ratio 和为 $\ell_{t+1}+\ell_{t+2}=0.2$, 故 sg 项的数值是 $0.1\times0.2=0.02$. Policy 残差是 $\ell_t$ 的一次函数: $e(\ell_t)=V_\phi(s_t)-R_t+\beta\ell_t+\operatorname{sg}[\cdots]=0.5-1+0.1\ell_t+0.02=0.1\ell_t-0.48$.

代三个值. $\ell_t=0$: $e=-0.48$, $e^2=0.2304$. $\ell_t=0.2$: $e=-0.46$, $e^2=0.2116$. $\ell_t=-0.2$: $e=-0.50$, $e^2=0.2500$. 损失对 $\ell_t$ 的导数 $\frac{d e^2}{d\ell_t}=2e\beta=0.2e$, 三个位置分别是 $-0.096$, $-0.092$, $-0.100$, 全为负. 梯度下降沿导数反方向走: 导数为负意味着增大 $\ell_t$ (提高 policy 对该 token 的相对 log 概率) 能减小损失. 本例残差恒负, 即「$V_\phi(s_t)$ 加 suffix 估值」系统性低于 $R_t$, 优化会把该位置的 log-ratio 往上推.

把 §2.3 的最优值代进来做终点检查: $V_\phi(s_0)=0.96$, $R_t=1$, suffix 去掉当前项后和为 $0.2$, sg 项 $0.02$, 则 $e=0.96-1+0.02+0.1\ell_0=0.1\ell_0-0.02$, 在 $\ell_0=0.2$ 处 $e=0$, 损失取最小值 0. 与 Theorem 2 一致: 当 $(V_\phi,\pi_\theta)=(V^*,\pi^*)$ 时, 每个位置的残差同时归零. 这组手算同时显出 sg 的数值后果: $e$ 对 suffix 里的 $\ell_{t+1},\ell_{t+2}$ 不可导, 无论 suffix 怎么变, 导数始终是 $0.2e$.

## 4. 粒度变体与相邻方法的对照

### 4.1 token, step, response 三种粒度

标准 OREO 是 token-level: 每个 token 一个残差. Step-level 把动作改成一个完整推理步 (一句算式, 论文用换行切分, MATH 上换行和句号都算), 步内概率取各 token 概率的乘积 $\pi(a|s)=\prod_i p(t_i|s_{<t_i})$, 恒等式形式不变, 只是 $T$ 变成步数. Response-level 走另一个极端: 只在初始状态放一个残差 (论文式 (10)), 整条轨迹一个平方项——这正是 DPO 的同款结构, §4.2 展开.

论文 Table 5 的消融: response-level 明显差于 token-level, 理由与论文批评 DPO 的理由相同, 整条轨迹一个残差, 无从把稀疏奖励摊到 token 上. Step-level 与 token-level 相当, 在 GSM8K 上还略好, 论文的归因是逐步 value 估计不准会给 policy 学习引入噪声; 最终选 token-level 作为标准目标, 理由只是实现简单, 省掉切分推理步的工序. 边界要写明: step-level 略优只在 1.5B 规模的数学任务上验证过, 粒度越粗是否越稳, 论文没有更宽规模的证据.

粒度选择还牵出一个语义差别: token-level 的「动作」是词表符号, 恒等式里每个位置都有确定的可导项; step-level 的「动作」是自然语言片段, 边界由分隔符决定, 分错边界 (该断不断, 不该断乱断) 会直接改变残差的语义. 论文对分界的处理是按数据集固定规则 (GSM8K 用换行, MATH 加句号), 没有做分界质量的消融, 这留给复现者一个自由度: 换成分模型学的分界器, step-level 的相对表现可能移动.

### 4.2 与 DPO 的推导关系

论文 §3.3 给了一个从 soft Bellman equation 推出 DPO 的两步构造. 第一步, telescoping 到 $t=0$, 丢掉中间所有位置的约束 (论文式 (4)). 第二步, 引入 Bradley-Terry 偏好模型, 把「轨迹的指数化奖励」解释成「winner 优于 loser 的概率」, 对数似然写出来就是 DPO 的损失 (论文式 (6)). 两步都是放松: 前者丢粒度, 后者引入一个人类偏好的概率假设. **DPO 的全部特殊性, 就来自这两步放松**; 推理任务有 verifier 给的确定奖励, 每一步的约束都被数据允许时, 这两步放松没有收益, 只有代价.

论文据此指出 DPO 在多步推理上的两个结构缺陷. 其一, BT 假设适用于「只有人类偏好, 没有 ground-truth reward」的对话场景; 推理任务的奖励可验证, 再套一层偏好模型是多余的数据加工, 还强迫数据集变成成对形态. 其二, telescoping 到首步丢掉了信用分配的全部粒度. 这个推导关系是读 OREO 的坐标之一: OREO 没有引入新原理, 它把 DPO 放松掉的那部分约束捡了回来, 有 verifier 就直接拟合奖励, 不再绕 BT 模型.

由此也能给 OREO 在 1.3 节的方法谱系里定位: 对 GRPO(1.3.1.1 节) 与 DAPO(1.3.2.1 节) 的在线 rollout 路线, OREO 是离线镜像, 同样的可验证奖励前提, 同样的信用分配目标, 采样环节整体砍掉. 对 RLOO(1.3.1.2 节) 的免 baseline 路线, 它选了相反的极端: RLOO 用采样平均消掉 critic, OREO 显式训练 critic 并让它在 TestingTime 二次上岗. 三条路线的分歧不在「要不要价值信号」, 而在价值信号用采样换还是用梯度拟合.

### 4.3 与离线 RL 家族其他成员的边界

OREO 的血统是 soft Q-learning 与 PCL (Nachum et al. 2017) 一脉: 用一致性残差同时拟合 policy 与 value, 这是 entropy-regularized RL 的标准方法嫁接到 LLM, 论文自己也将方法定位于此. 它不含 CQL 的 conservative penalty, 也不含 BCQ 的行为约束机制: 那两类方法针对「行为数据质量参差, 必须压制对未覆盖动作的估值外推」的通用离线 RL 问题; OREO 把「别离数据太远」整体交给参考策略锚定 ($\beta$ 项加 $\alpha\mathcal L_{reg}$), 不做逐动作的保守修正. 这个选择依赖 LLM 场景的强参考策略, 参考策略很弱或没有的通用离线 RL 设定不在它的适用范围内.

和 AWR 的区分值得单独写, 因为两者表面形似 (都有 value 和 policy 两个目标). AWR 的标准配方是: 用 Monte Carlo return 训 critic, 再用 $\exp(A/\alpha)$ 加权 behavior cloning. 关键差别在 target 的构造: AWR 的 critic target 是回报样本, 同一条轨迹上所有 token 拿到同一个数; OREO 的 value target 是「终局奖励减停止梯度的 suffix log-ratio」 (式 (8)), 随 $t$ 变化. 在稀疏奖励下, 前者让所有 token 共享整条链的功劳或过错, 后者让早期 token 背负整条链, 晚期 token 只背自己的——信用分配是否存在, 分界就在 target 是否随位置变化.

另一个参照是 ILQL (Implicit Language Q Learning): 它同样想在语言模型上做离线价值学习, 但选择避开显式策略改进, 用 expectile 回归隐式地提取价值信息再做解码时约束. OREO 走显式 policy 残差路线, 训练即改模型权重, 不需要解码侧的配合; 代价是政策更新幅度受 $\alpha\mathcal L_{reg}$ 约束, 不能像 ILQL 那样在解码时灵活调节强度. 论文附录给了更近的对照: DQO (Liu et al. 2024a) 与 OREO 算法结构相似, 其目标的某个特例 (去掉 importance sampling 与 $\lambda$-return) 等价于 OREO 的特例 (token-level, 去正则项, 去 sg); 论文用 Qwen2.5-Math-1.5B 复现并对比了 DQO (Table 3). 这一族方法的共同点值得留意: 都在把「离线 + 稀疏奖励」从偏好学习的框架里搬回 value-based RL 的框架.

## 5. 实验, TestingTime search 与迭代扩展

### 5.1 主结果与口径

设定先列清. 数学推理: GSM8K (7473 训练 / 1319 测试) 与 MATH (7500 训练 / 5000 测试), 用 DeepSeekMath 的评测脚本抽最终答案判对错. 具身控制: ALFWorld, 3119 条带逐步推理标注的训练轨迹 (标注来自 Song et al. 2024), 评测为 seen 环境 140 任务与 unseen 环境 134 任务, 限 40 步, 指标是成功率. 基座: Qwen2.5-Math-1.5B 与 DeepSeekMath-7B-Instruct (数学), MiniCPM-2B-dpo (ALFWorld). 基线: SFT, rejection sampling, DPO, KTO.

论文报告的提升全部是相对值 (Table 1, 2): Qwen2.5-Math-1.5B 上, OREO 相对 SFT 在 GSM8K 提升 5.2%, 在 MATH 提升 10.5%; DeepSeekMath-7B 上为 3.6% 与 5.1%, 而该模型的 SFT checkpoint 已在 776K 样本上训过, 余量本就有限. ALFWorld 上 OREO 在两种环境都超过全部基线, unseen 环境相对基线提升 17.7%. 口径提醒: 相对提升不等于绝对点数, 基数低的任务上同样的相对值对应的点数少; 消融, 迭代与 search 实验都用 1.5B 模型 (论文 Limitations 自述), 规模效应没有验证; 任务族只有数学与室内具身两类.

一个与 DPO 直接相关的观察: 实验里 DPO 对 SFT 初值的提升很小, 简单的 rejection sampling 反而常常更好, 与引言引用的已有观察一致. 这和 1.3.4.1 节 RLVR 的在线结论不矛盾: 在线每轮换新数据配对的 DPO 与离线一次性 DPO 是两回事, OREO 赢的是离线一次性这个设定. 把「DPO 在推理任务上不行」当普遍结论引用, 会越界.

### 5.2 value-guided search 的预算结构

训练之外, OREO 额外送一个打分器: value 网络可以直接给部分轨迹打分. 数学任务用 step-level beam search: 每步维护 $B$ 条候选部分轨迹, 每条续写 $B$ 个候选步, 从 $B^2$ 个组合里按 value 留 Top-$B$, 搜索 $H$ 步的代价约为 $H B^2$ 次 policy 前向加同量级的 value 前向. 环境动力学未知的 ALFWorld 用不了 beam search, 改为每步采 $K$ 个动作取 value 最大者 (best-of-K), $T$ 步约为 $T K$ 次双向前向. 论文给的数: $B=7$ 相对贪心解码, GSM8K 提升 11.4%, MATH (取 500 题的 MATH500 子集) 提升 17.9%; ALFWorld 的 best-of-K 在 $K=5$ 时趋于饱和.

「for free」只指 value 网络是训练的副产品, 不指搜索不花算力. 论文报告的是「提升随预算增长」的曲线 (Figure 3), 没有把搜索开销折算进成本口径, 训练收益与 TestingTime 预算两部分混在一起, 引用时应连同 $B$ 或 $K$ 一起引, 只引提升百分比会丢掉可复现性. 按 §1.2 的术语约定, 这属于 TestingTime 轴的投入, 与训练侧的 scaling 分开记.

论文还给了显式 value 与隐式 value 的直接对照. DPO 视角下 policy 本身就是隐式 value, 优势为 $A_\theta=\sum_t\beta\log\frac{\pi_\theta}{\pi_{ref}}$; OREO 的显式价值给出 $A_\phi=V_\phi(s_j)-V_\phi(s_i)$. Case study 的数值: 在错误步骤「Betty now has 50 美元加 30 美元等于 80 美元」上, $V_\phi$ 从 0.816 降到 0.385, $A_\phi=-0.431$, 而 $A_\theta$ 的模长小得多, 没能把错误步和正确步分开. 论文把差距归因于 softmax bottleneck: policy 对各动作的概率来自同一个 hidden state 的线性头加 softmax, value 网络直接读完整序列, 表示更富. 这是论文提出的解释, 不是验证过的因果结论, 引用时保持这个限定.

PRM 与 value 的输出语义不同. 已有 PRM 工作 (论文 §4.4 列举) 用 Monte Carlo rollout 训练过程打分器, 训练目标与式 (8) 本质相似, OREO 的表述省掉了大量启发式设计; 但 PRM 输出的是「这一步对不对」的判别分, value 输出的是「从这里到终点的期望回报」. 前者适合逐步纠错, 后者适合预算分配与提前放弃. 论文没有做 PRM 式评测 (逐步标注的准确率), 也没有在同一搜索框架下比较两种打分器.

### 5.3 迭代扩展与没有量化的部分

Iterative OREO: 每轮训练结束后用更新后的 policy 补采新轨迹, 与旧数据一起进下一轮. 论文报告三轮迭代里 OREO 稳步上升, rejection sampling 到第三轮饱和. 论文给的机制解释: rejection sampling 只用成功轨迹, 策略变强后新数据里它能利用的部分随之减少; OREO 同时从失败轨迹提取信息, 新出现的失败模式本身就是新的监督来源. 解释合理, 但「稳步上升」的曲线规模只有 1.5B, 三轮, 数学任务; 更大规模或更多轮后是否仍单调, 论文没有数据.

迭代细节论文同样没展开: 新旧数据的混合比例, value 网络每轮重训还是跨轮保留, 补采时的探索温度, 三个都直接影响复现, 都没有报告. 从方法结构推测, value 跨轮保留会有目标漂移 (旧 value 对应旧 policy 的 suffix 结构), 重训更干净但丢弃了历史估计; 这是复现者需要自己做消融的第一个岔路口.

论文 Table 1 给出绝对准确率的完整结果. search 与迭代没有联合实验; $\alpha$ 的敏感性只在变体选择时测试了 $\alpha\in\{0.01,0.1,0.3\}$ (step-level 取 0.1, response-level 取 0.3); token-level 主目标的超参细节位于附录 A; 数学与 ALFWorld 之外没有其它任务族验证. 复现计划必须为这些未覆盖组合另设实验.

## 6. 实现与验证

### 6.1 教学实现

假设输入是定长 padding 的批: 每个位置 $t$ 有 $V_\phi(s_t)$, 每条轨迹一个终局奖励 $R$, policy 与 reference 在每个 token 上的 log 概率. 核心是一次倒序累加得到 suffix 和, 两个 loss 共用同一组中间量:

```python
import torch

def oreo_losses(v, reward, logp, logp_ref, mask, beta=0.1, alpha=0.1):
    # v: [B, T]          每个前缀状态的 value V_phi(s_t)
    # reward: [B]        整条轨迹的终局奖励 R (稀疏, t<T 处 r=0)
    # logp, logp_ref: [B, T]  policy / reference 的逐 token log 概率
    # mask: [B, T]       有效 token, padding 为 0
    # 对应论文式 (7)-(9); alpha 只标注接口位置, L_reg 由调用方算
    ell = (logp - logp_ref) * mask              # [B, T] 逐 token log-ratio
    suffix = torch.flip(                        # suffix[t] = sum_{i>=t} ell[i]
        torch.cumsum(torch.flip(ell, [1]), 1), [1])
    # 式 (8): value target = R - beta * suffix, detach 后梯度只进 V_phi
    v_target = reward.unsqueeze(1) - beta * suffix.detach()
    value_resid = (v - v_target) * mask
    loss_v = (value_resid ** 2).sum() / mask.sum()
    # 式 (9): policy 残差中 suffix 去掉当前项后 stop-gradient
    future = (suffix - ell).detach()            # sg[beta * sum_{i>t}] 的未乘 beta 形态
    policy_resid = (v.detach() - reward.unsqueeze(1)
                    + beta * ell + beta * future) * mask
    loss_pi = (policy_resid ** 2).sum() / mask.sum()
    return loss_v, loss_pi
```

这段代码对应 §3.1 的两个式子, 有三处实现细节. 第一, suffix 用倒序 cumsum 一次算出, 二重循环是 $O(T^2)$, 长链上会成为瓶颈; 倒序 cumsum 与式 (7) 的求和顺序一致, 但后缀越长浮点累加误差越大, $T$ 到几千时可用 float64 累加再转回. 第二, $R_t$ 的实现形态是「终局奖励广播到每个位置」, 这依赖稀疏奖励假设 $R_t=R$; 换到带中间奖励的任务, $R_t$ 要换成后缀奖励的倒序累加, 代码结构与 suffix 完全同构. 第三, $\mathcal L_{reg}$ 需要 policy 在全词表上的 logits, 开销约等于一次额外前向的 softmax, 别用采样近似替代——KL 作为逐状态约束, 是这项正则的全部意义.

训练循环按联合优化写: 每个 step 先算两组 loss, 反向传播进两套参数, $\mathcal L_{reg}$ 乘 $\alpha$ 加在 policy 侧. 也可以按 step 交替更新两组参数, 论文两种都允许; 交替实现的收敛差异没有报告, 选联合版本的理由是 batch 统计量 (归一化分母) 两侧一致, 诊断时少一个变量.

### 6.2 不依赖模型的验证不变量

以下四条都在随机张量上跑, 不需要任何真实模型, 构成这套实现的最小验收.

第一, 解析解处残差为零: 令 $V_\phi$ 取式 (7) 的解析值 $R-\beta\cdot$suffix (由 detach 路径算出), value loss 必须恒等于 0. 这条拦住「value target 符号写反」的 bug: 这类 bug 不报错, 损失照样下降, 只是降的方向错.

第二, telescoping 可加性: 对任意随机 $V_\phi$ 与 mask, 逐位置差分满足 $\sum_t m_t[V_t-V_{t+1}]=V_{首}-V_{尾+1}$ (末位置之后约定为 0); 等价地, 倒序 cumsum 与差分互为逆运算, 用随机矩阵逐元素对照到 float32 的机器精度. **这条专抓 off-by-one**: $i\ge t$ 与 $i>t$ 只差一位, 两个 loss 却会全错且仍能收敛.

第三, mask 完整性: 把 padding 位置的 $v$, logp, logp_ref 换成 $\pm10^4$ 的随机大数, 两个 loss 必须与替换前逐位相等. padding 混入 suffix 累加是第二个高发 bug, 倒序 cumsum 之前必须先乘 mask.

第四, $\beta\to0$ 的梯度退化: 固定随机输入, 用 autograd 算 $\partial\mathcal L_\pi/\partial\logp$, $\beta=0$ 时必须恒为零. 这是式 (9) 结构的直接推论 ($\theta$ 只经由 $\beta\ell_t$ 进入残差), 能拦住「sg 加错位置, 梯度绕进 suffix」的 bug; 同时它标出一个使用边界: $\beta=0$ 时 policy loss 对 policy 完全无梯度, 把 $\beta$ 调没了等于关掉整个 policy 训练.

### 6.3 一手来源与阅读路径

OREO 的一手来源是 arXiv:2412.16145 (v1 提交于 2024-12-20, v2 修订于 2024-12-25, 差异很小), 官方代码仓库 jwhj/OREO 内含数学与 ALFWorld 的完整配置. 论文式 (3) 是 soft Bellman equation, 式 (7) 是稀疏奖励下的 telescoped 形式, 式 (8)(9) 是 value 与 policy 损失, 式 (10) 是 response-level 变体.

- [Offline Reinforcement Learning for LLM Multi-Step Reasoning](https://arxiv.org/abs/2412.16145)
- [arXiv HTML 版](https://arxiv.org/html/2412.16145)
- [本地论文 PDF](./papers/OREO_2412.16145.pdf)

§2 给出恒等式的来源, §3 将它拆成两个可优化的 loss, §4.2 再通过 DPO 推导关系确定 OREO 在「在线/离线」「有无显式 value」两个坐标上的位置. 对 GRPO(1.3.1.1 节) 与 DAPO(1.3.2.1 节), OREO 是离线镜像: 同样使用可验证奖励并处理信用分配, 但去掉在线 rollout. 对 RLOO(1.3.1.2 节) 的免 baseline 路线, 它选择显式训练 value 函数, 并让这个 value 在 TestingTime 承担 search 打分器的第二职责. §6.2 的四条不变量构成真实模型接入前的实现验收条件.

## 7. value 误差怎样进入搜索

### 7.1 排序误差比均方误差更贴近用途

OREO 的 value 在搜索阶段用于比较候选前缀, 因而均方误差低并不自动意味着搜索更好. 设三个候选的真实成功概率为 $[0.6,0.4,0.1]$, 预测为 $[0.45,0.50,0.15]$. 数值误差不算大, 但前两个候选顺序翻转后, beam search 会把更多预算给较差分支. 相反, 预测为 $[0.9,0.6,0.2]$ 虽然校准偏高, 排序却完全正确, 在固定扩展宽度下可能得到更好的最终答案.

因此验证 value 时至少需要三类指标: 校准误差回答数值能否当概率使用, pairwise ranking accuracy 回答两个前缀能否排对, top-$k$ recall 回答有限预算是否保留了真正有希望的分支. 这三者不能互相替代. 若 value 只参与排序, 应优先选择排序稳定的 checkpoint; 若还用它设置停止阈值, 才需要进一步校准绝对数值.

### 7.2 分布偏移来自搜索本身

训练 value 的前缀来自离线轨迹, 搜索运行后却会主动偏向高 value 区域. 一旦估计器在某类前缀上系统性高估, 搜索会反复访问该区域, 输入分布随之离开训练集. 这种反馈环路不会在静态验证集的平均误差中充分暴露. 可在每轮搜索后保存被扩展前缀, 比较其长度、熵、题型与训练前缀的分布, 再单独测这些高频区域的排序正确率.

更稳妥的部署方式是给 value 留一个保守边界: 当候选分差小于验证集上的排序噪声时, 不做确定性剪枝, 而是保留多个分支或混入 policy 分数. 这会增加少量搜索成本, 但能避免微小估计误差在早期剪枝后变成不可恢复的路径丢失. value-guided search 的收益取决于模型、估计器和预算三者共同作用, 不能只从 value loss 判断.

阈值应在独立任务集上选择, 并随搜索深度分别校准; 早期前缀信息少, 同样的分差通常比末段分差更不可靠.

## 8. value 学到的过程信号

### 8.1 value 的语义与终点锚

$V_\phi(s_t)$ 的语义是从前缀 $s_t$ 出发、继续按当前策略行动时的 KL 正则化未来回报。它包含任务奖励，也包含未来每一步偏离 reference 的代价。两个前缀最终成功概率相同，若其中一个只能沿 reference 极低概率的路径完成，它的正则化 value 仍可能更低。因此 OREO value 不能直接读成“答案正确概率”，更不能在未校准时把 $0.7$ 解释为七成成功率。

式 (7) 还隐含终点边界。有限时域轨迹在终止后取 $V(s_T)=0$，从而把 value 的加性自由度固定下来。若实现只拟合相邻差分而没有终点锚，给所有 $V(s)$ 同加常数不会改变差分，绝对值无法识别；OREO 用终局回报与完整 suffix 直接构造 target，等价于把每个前缀都连到终点，消除了这项自由度。截断轨迹没有真正终点时，贸然令尾部 value 为零会产生向下偏差：模型会把“窗口结束”当成“任务结束”。长任务应保留真实终止标记，或给截断尾部另设 bootstrap 估计并明确这已偏离论文的纯 Monte Carlo 目标。

同一状态可能出现在多条轨迹里。若从 $s_t$ 出发有的后续成功、有的失败，value target 不再是单个确定数，而是数据后续分布下的样本回报。平方损失的总体最优解是条件均值：

$$
V_\phi(s)=\mathbb E_\mu\left[R_t-\beta\sum_{i\ge t}\ell_i\mid s_t=s\right],
\qquad
\ell_i=\log\frac{\pi_\theta(a_i\mid s_i)}{\pi_{\mathrm{ref}}(a_i\mid s_i)},
$$

其中 $\mu$ 是离线数据的后续分布。定理里的 $V^\pi$ 对策略 $\pi$ 取期望，经验训练却先对行为分布 $\mu$ 取样；只有覆盖充分且一致性约束把策略推到正确不动点时，两者才重合。这个差别是理解离线偏差的入口。

### 8.2 从 value 差分恢复逐步量

soft Bellman equation 可重排为

$$
r(s_t,a_t)=V^*(s_t)-V^*(s_{t+1})+\beta\ell_t.
$$

右边给出一个可检查的逐步分解：value 的下降加上本步 KL 代价，应还原即时任务奖励。在纯终局奖励任务中，所有非终止位置的真实 $r_t$ 都为零，所以理想情况下 $V(s_t)-V(s_{t+1})\approx-\beta\ell_t$。这说明 value 曲线中的每次下降都不能自动叫作“推理错误”；有一部分只是策略在该 token 上相对 reference 提高概率所付的正则代价。论文 Figure 1 用 $A_\phi=V(s_j)-V(s_i)$ 比较完整推理步，适合排序候选，但它仍是正则化未来回报的变化量，不是逐步正确性的监督标签。

真正的过程诊断可以同时画两条曲线。第一条是裸 value 增量 $A^V_t=V(s_{t+1})-V(s_t)$，回答新步骤让未来回报升还是降；第二条是去掉 KL 后的任务增量

$$
\widehat r_t=V(s_t)-V(s_{t+1})+\beta\ell_t.
$$

在非终止位置，$\widehat r_t$ 应围绕零。若它长期偏正或偏负，value、policy 与 reference 三者没有满足一致性。错误步骤上 $A^V_t$ 显著为负而 $\widehat r_t$ 仍接近零并不矛盾：模型认为这一步降低了成功前景，同时 policy 对该动作的相对概率变化解释了对应差额。只有外部逐步标签存在时，才能把 value 增量与“步骤正确”做直接校准。

过程奖励模型常把每一步分类成正确或错误，OREO value 则估计从当前前缀继续完成任务的可达回报。一个局部算术错误若下一步容易修复，PRM 可以立即判错，value 下降可能很小；一个表面正确却把搜索带进死胡同的步骤，PRM 可能判对，value 会因未来无解而下降。两类信号回答的问题不同。把 OREO value 当 PRM 使用时，评测应包含“能否保留最终可成功分支”，而不只测逐步标签准确率。

### 8.3 长程信用来自多重后缀约束

长度为 $T$ 的轨迹为第 $j$ 个动作提供多少监督，可以从它出现在哪些 target 中看出。$ell_j$ 出现在 $t=0,1,\ldots,j$ 的 value target 里，越靠后的动作被更多前缀 target 包含；policy loss 经 stop-gradient 后只让第 $j$ 个残差直接更新 $ell_j$，但 value 网络仍通过所有后缀关系学习整条曲线。信用分配来自“一个终局奖励生成 $T$ 个相互耦合的前缀约束”，并非把终局奖励简单复制 $T$ 次。

这个结构对长程错误有两个作用。前缀 value 可以在真正错误发生前保持较高，错误动作之后骤降，使搜索有机会定位分叉点；失败轨迹的早期正确前缀若也出现在成功轨迹中，会收到来自两类后续的平均估计，不会因为一次失败被永久判死。反过来，若某前缀只在失败轨迹出现，数据无法判断失败由此前缀造成，还是由后续偶然动作造成，value 只能把两者混合。多条共享前缀、后续不同的轨迹对信用定位最有价值。

轨迹长度还改变样本权重。论文公式对单条轨迹使用 $T^{-1}\sum_t$，先在轨迹内部平均，再对 batch 平均时，每条轨迹总权重相同。§6.1 的教学代码用全 batch 的 `mask.sum()` 归约；当各轨迹长度不同，它等价于对所有 token 平均，长度 800 的轨迹总权重约是长度 100 轨迹的八倍。两种实现都合理，却优化不同的经验风险。复现论文时应按每条轨迹有效长度先求均值，再对轨迹求均值；若选择 token 平均，需要把长度加权作为显式改动报告。

超长轨迹还有相关性问题。同一条轨迹的 $T$ 个残差共享终局奖励，不能视作 $T$ 个独立样本。一个 1000-token 失败回答贡献 1000 个高度相关残差，统计有效样本量仍接近轨迹数。训练日志应同时报告按 token 平均的 loss 与按轨迹聚合后的残差分布，验证置信区间按 prompt 或轨迹做 cluster bootstrap，不能用 token 数当样本数。

### 8.4 失败轨迹提供什么信息

失败轨迹的价值在于提供“这条已访问路径最终失败”的证据。它不会自动告诉模型哪个步骤错，也不会覆盖没有访问过的替代动作。若一条失败链与成功链共享前 90% 前缀，只在一个关键动作处分叉，value 网络有条件把下降定位在分叉后；若两条轨迹从开头就完全不同，失败信号更容易被语言风格、长度或来源模型吸收。

可以把失败数据按可比较性分成三层。第一层是同 prompt、共享长前缀、局部动作不同，最适合信用定位；第二层是同 prompt 但推理路线不同，只能学习整条路线的相对前景；第三层是不同 prompt 的独立失败，主要帮助校准任务难度和通用错误表征。OREO 能消费三层数据，不表示三层信息量相同。数据构造应报告成功/失败共享前缀长度、首次分叉位置与错误类型，而非只报二元奖励比例。

失败轨迹也可能带来反向污染。verifier 只看最终答案时，一条推理全错却碰巧猜中答案的轨迹被记为成功；一条过程正确但答案抽取失败的轨迹被记为失败。OREO 会把这个终局标签传播到所有前缀，长链上的污染面比 response-level 训练更大。验证器应先做等价答案归一化、格式鲁棒性测试与人工抽检，再讨论细粒度信用。过程粒度提高了监督利用率，也同步放大标签错误的覆盖范围。

## 9. 离线数据决定可学习边界

### 9.1 定理条件与经验支持集

Theorem 2 的条件是所有状态—动作对都满足一致性。实际目标只在离线数据 $\mathcal D$ 上最小化

$$
\widehat L(\theta,\phi)=\frac1{|\mathcal D|}\sum_{\tau\in\mathcal D}
\frac1{|\tau|}\sum_{t\in\tau}e_t(\theta,\phi)^2.
$$

零训练残差只说明观测到的动作满足方程。某个前缀下词表里有十万个可能 token，数据通常只包含一两个；其余动作的值与概率由参数共享和 KL 正则间接决定。将定理中的“对所有状态动作成立”替换成“训练集残差很小”，正是离线泛化所需的额外假设。

记行为策略为 $\mu$，离线状态—动作占用分布为 $d_\mu(s,a)$。OREO 的经验梯度对 $d_\mu$ 取期望，目标策略的真实回报则对 $d_{\pi_\theta}$ 取期望。训练没有 importance ratio $d_{\pi_\theta}/d_\mu$，因此方差和工程复杂度下降，代价是策略离开数据支持后估计出现系统偏差。reference KL 与 $\mathcal L_{reg}$ 把策略留在熟悉区域，但无法创造缺失动作的奖励证据。

覆盖可以按前缀层级测量。对每个 prompt，统计独立轨迹数、每个推理步的分支数、成功与失败首次分叉深度，以及当前策略生成 token 在离线数据近邻中的密度。训练胜率上升而这些新前缀密度快速下降，说明策略改进已经走到数据边缘。此时继续重复 epoch 往往只会强化外推，补采数据比降低训练 loss 更有意义。

### 9.2 论文的数据构造如何影响结论

论文附录 A.1 对 1.5B 数学模型每题采样 10 条回答，正确终局记 1，错误记 0；DPO 再从同题正负轨迹中无放回取最多 6 对。7B 设置每题采 16 条，最多保留 4 条正例与 4 条负例，并限制正例数不超过负例数；ALFWorld 每个训练任务 rollout 5 次。OREO 直接使用单条轨迹，DPO 需要配对，这个数据效率差异属于方法设定的一部分。

每题固定采样数并不等于每题有效信息相同。简单题十条全对，只提供成功前缀，缺少反事实失败；难题十条全错，只提供失败路径，缺少成功锚。接近决策边界的题同时有正负轨迹，最能训练 value 的分叉结构。报告总体轨迹数会隐藏这种差别，更有用的统计是按每题成功数 $k\in\{0,ldots,n\}$ 分桶，并分别测更新前后准确率。

论文为 7B 数据主动平衡正负数量，说明原始行为分布没有被完整保留。平衡能防止高成功率题被正例淹没，也改变了条件期望中的类先验。若 value 要解释为部署成功率，训练时重采样后的先验必须校准回真实分布；若 value 只用于排序，同题内的相对顺序可能仍可用。训练目标、采样分布与部署解释应分开记录。

数据来源模型也是混杂变量。若成功轨迹主要来自强模型、失败轨迹主要来自弱模型，value 可能识别措辞、模板和长度。论文数据由同一 checkpoint 多次采样，降低了这类混杂，但迭代 OREO 会把不同轮次策略生成的数据混在一起。每条轨迹需保存行为策略版本和采样温度，验证集按来源版本分层，确认收益跨来源存在。

### 9.3 纯离线训练的选择偏差

可验证任务的数据通常经过前置过滤：解析器无法抽取答案的轨迹被丢弃，超长回答被截断，工具超时被当失败，安全过滤器又会删除某些动作。这些选择同时依赖回答特征与奖励，经验目标学到的是“进入数据集之后”的条件规律。特别是只保留能解析最终答案的轨迹，会让模型把固定答案格式当成成功捷径。

最小审计表应包括生成总数、解析成功数、被截断数、验证器异常数、正负奖励数和最终入库数，并按长度、题型与来源策略交叉统计。若某一类在验证前就大量流失，OREO 的 value 无法对它作可靠判断。可将解析失败单独作为缺失标签而非任务失败，或对一小批失败记录人工补标，估计过滤带来的方向性偏差。

重复训练同一批离线轨迹会产生两种不同的过拟合。policy 记住具体推理文本，训练 residual 降低但新采样不改善；value 记住前缀字符串，对训练前缀排序很好，稍作保义改写就失效。验证集应含同题新轨迹、未见题目和保义改写三层。只按轨迹随机切分会让同题共享前缀泄漏到训练与验证两侧，给出虚高结果。

### 9.4 迭代数据与 replay

第 $k$ 轮补采的数据来自 $\pi_k$，旧数据来自 $\pi_0,ldots,\pi_{k-1}$。全部等权混合能防遗忘，却让经验目标落后当前策略；只用新数据更接近 on-policy，样本少且容易遗忘旧能力。一个可检查的混合形式是

$$
\mathcal D_k=\lambda_k\mathcal D_{new}+(1-\lambda_k)\mathcal D_{replay},
$$

把 $\lambda_k$ 当作覆盖—新鲜度旋钮。每轮固定总轨迹数，扫描 $\lambda_k$，同时测当前策略新样本、旧轮样本和初始通用集，才能判断收益来自新鲜数据还是数据量增加。

value 跨轮继承时，旧参数拟合的是旧 policy 产生的 suffix log-ratio；policy 更新后 target 整体变化。可在新一轮开始前冻结 policy，只重拟合 value 若干步，再联合训练，减少两个移动目标同时漂移。另一种做法从头初始化 critic，用干净估计换掉跨轮知识。论文没有比较这两种路径，因此任何“继承更好”或“重置更稳”的结论都应由消融支持。

迭代 OREO 已经含在线数据收集，却仍以离线批次方式优化。它与逐步 on-policy RL 的差别在时间尺度：前者采一批、训一轮，再采下一批；后者几乎每个更新窗口都刷新 rollout。批次越小、刷新越频繁，OREO 的数据分布越接近当前策略，同时采样调度与环境成本也越接近在线 RL。是否迭代应由分布漂移指标和交互预算决定，不能只按方法名称划界。

## 10. 联合训练目标的优化几何

### 10.1 policy 残差等价于带符号权重

记式 (9) 中第 $t$ 个残差为

$$
e_t=V_\phi(s_t)-R_t+\beta\ell_t+
\operatorname{sg}\left[\beta\sum_{i>t}\ell_i\right].
$$

忽略正则项，对 policy 参数的梯度为

$$
\nabla_\theta\mathcal L_\pi=\frac{2\beta}{T}
\sum_t e_t\nabla_\theta\log\pi_\theta(a_t\mid s_t).
$$

与常见策略梯度 $-\widehat A_t\nabla\log\pi$ 对照，可定义 OREO 的局部伪优势 $\widehat A_t^{OREO}=-2\beta e_t$。$e_t<0$ 时伪优势为正，梯度下降提高数据动作概率；$e_t>0$ 时降低它。这个权重由 value、终局回报和 suffix log-ratio共同决定，每个 token 可以有不同符号。

平方残差使权重随不一致程度线性增长。极端错误的 value、缓存错位的 reference log-prob 或异常长 suffix 都会产生大梯度，没有 PPO clip 那样的硬截断。梯度裁剪只能限制 batch 总范数，无法阻止一个异常轨迹决定方向；应额外记录 residual 分位数、每条轨迹梯度权重和裁剪触发率。若使用 Huber loss 限制尾部，鲁棒性会改变，同时已经不再是论文式 (8)(9) 的原目标。

局部伪优势也解释了 OREO 与加权行为克隆的相似处：更新只作用于数据中实际出现的动作，提高或降低其 log 概率。这里的权重由 policy log-ratio 和 value 联合产生，会随训练变化，无法预先固化成回报或 advantage。训练数据相同，critic 初始化或更新速度不同，policy 看到的权重轨迹也会不同。

### 10.2 两个网络的时间尺度

value 更新太慢时，$e_t$ 主要反映陈旧 critic 误差，policy 会追逐错误权重；value 更新太快时，它可能迅速吸收当前 policy 的 suffix 变化，使 residual 接近零，policy 梯度消失。论文为 7B critic 使用 rank 64 的 LoRA、critic 学习率 $10^{-4}$，policy 学习率 $5\times10^{-6}$，体现出两侧不同时间尺度，但没有系统扫描这个比例。

可以用无量纲比值监控耦合：每若干步记录 value target 漂移 $\|Y^{k+1}-Y^k\|$、critic 预测变化 $\|V^{k+1}-V^k\|$ 与 policy log-ratio 变化 $\|\ell^{k+1}-\ell^k\|$。critic 变化远小于 target 漂移说明跟不上；critic 几乎完全追上而 policy residual 长期接近零，说明 policy 得不到足够更新。交替优化时可按这些量自适应 critic 步数，联合优化时至少分别裁剪两套梯度。

定理描述共同固定点，有限数据下却可能存在许多低残差解。value 容量足够大时，可以记住每个训练前缀并吸收大部分误差，让 policy 几乎不动；policy 容量大、critic 受限时，policy 可能通过改变 log-ratio 配合错误 value。独立验证 value 排序与 policy 新采样性能，是排除这种“共同拟合训练残差”解的必要条件。

### 10.3 reference 与显式 KL 的双重约束

reference 在 OREO 里出现两次。第一处是 Bellman 残差中的 $\ell_t=\log\pi_\theta-\log\pi_{ref}$，决定 value target 和伪优势；第二处是 $\alpha\mathcal L_{reg}$，对每个离线状态的完整动作分布施加 reverse KL。前者来自理论恒等式，后者是论文为稳定训练增加的正则。删掉显式 KL 后，残差里仍有 reference，并不等于变成 reference-free 方法。

$\beta$ 与 $\alpha$ 的职责也不同。$\beta$ 同时缩放 target 中的 suffix、policy 的直接梯度和最优策略相对 reference 的温度；$\alpha$ 只调显式 KL 对总 policy loss 的权重。把 $\alpha$ 增大十倍不能等价替代更大的 $\beta$。粒度从 token 换到 step 或 response 后，平方残差的数值尺度改变，论文因此为 step-level 选 $\alpha=0.1$、response-level 选 $0.3$，而标准 token-level 使用 $0.01$。

reference 缓存要求 tokenizer、prompt 模板、截断与 EOS 处理完全一致。任一差异都会被当成 policy 改进量进入 suffix，并被传播到全部前缀。随机抽样在线重算 log-prob，比较逐 token 最大误差与 suffix 累积误差；只检查序列总和可能让正负 token 误差相互抵消。reference 版本还要写入 checkpoint 元数据，避免迭代训练时缓存与模型错配。

### 10.4 归约、mask 与工具观测

纯文本推理的每个 response token 都由 policy 控制。具身或工具轨迹还包含环境 observation、系统模板和工具返回，这些 token 进入后续状态，却不属于 policy 动作。log-ratio、policy loss 与 KL 只能在模型动作 mask 上计算；把 observation 计入会让模型为环境文本承担梯度，并使长工具返回主导 suffix。

step-level 动作由多个 token 组成，其 log 概率是 token log-prob 之和。一个 30-token 步骤的 log-ratio 通常比 5-token 步骤绝对值大，平方残差进一步放大长度差。若改成步内平均 log-prob，尺度更稳，却改变论文定义的动作概率。更干净的控制是按步长分桶报告 residual，或构造语义相同、措辞长度不同的步骤检验长度敏感性。

终止 token 的处理同样关键。若 EOS 属于 policy 动作，它的 log-ratio应进入 suffix；漏掉 EOS 会削弱对停止时机的学习。超长轨迹被上限截断却仍广播终局奖励，相当于给不完整前缀贴上完整轨迹标签。数据预处理应区分真实终止、环境强制终止、超时与长度截断，后两类不能无条件复用二元成功奖励。

### 10.5 从症状定位实现故障

| 观测症状 | 优先检查 | 冻结实验 |
| :--- | :--- | :--- |
| value loss 能降，解析 target 对不上 | suffix 下标或符号 | 三 token 手算，逐位置导出 $S_t$、$Y_t$ 与 residual |
| 长轨迹梯度随长度爆炸 | sg 或归约 | 复制同一 token 到不同长度，比较首尾位置梯度 |
| padding 长度改变 loss | mask 顺序 | 将 padding 的 log-prob 改成 $\pm10^4$，结果应不变 |
| policy 几乎不更新 | $\beta$、critic 过快或 detach 过度 | 固定 critic，检查 $\partial L_\pi/\partial\log p_t=2\beta e_t/T$ |
| KL 正常，生成突然变短 | EOS、截断与长度权重 | 单独画 EOS log-ratio、长度桶 residual 和真实终止率 |
| 离线 residual 降，在线成功率降 | 数据覆盖或行为版本 | 同题比较旧轨迹、新策略轨迹与 reference 轨迹 |
| 回放搜索有效，真实环境无效 | observation mask 或环境漂移 | 固定动作重放多个环境种子，核对工具返回哈希 |

排障顺序分三层。第一层固定张量，只验证公式、mask、sg 和归约；第二层用几十条轨迹过拟合，要求 residual、value target 与 token 概率沿手算方向变化；第三层才开放当前策略采样与环境，检查分布漂移。第一层失败时扩大模型和数据不会提供新信息，第三层失败却回头盲调符号也会浪费时间。

双网络需要分别保存诊断状态。每个 checkpoint 除 policy 与 critic 参数外，还应记录 reference 哈希、tokenizer 和模板版本、优化器状态、数据游标、$\alpha/\beta$、归约口径与行为策略版本。恢复训练后首步 residual 跳变，先核对这些状态；policy 连续而 value target 突变，通常是 reference 缓存或 critic 恢复错误。

每条轨迹保留可追溯主键也很重要。出现极端 residual 时，应能回到 prompt、完整动作、终局验证结果、截断状态与来源轮次。只保存 batch 均值会把一个错标长轨迹造成的尖峰伪装成优化器不稳。按累计绝对伪优势抽样人工检查，是定位 verifier 错误、模板泄漏和环境异常的高收益路径。

## 11. 与 PPO、GRPO 的关系

### 11.1 共同目标与不同估计量

在理想条件下，OREO、带 KL 的 PPO 与用于可验证奖励的 GRPO 都希望提高任务回报，同时限制策略偏离参考模型。分歧集中在如何估计更新方向。PPO 从当前或近邻策略 rollout，构造 advantage，并用概率比裁剪：

$$
L_{PPO}=-\mathbb E\left[min\left(\rho_t\widehat A_t,
\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\widehat A_t\right)\right],
\qquad
\rho_t=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{old}(a_t\mid s_t)}.
$$

OREO 没有 $\pi_{old}$ 概率比，也没有 clip；它在固定离线动作上最小化 Bellman 一致性残差，以 $-2\beta e_t$ 充当局部权重。PPO 的 on-policy 性来自频繁更新 rollout，OREO 的稳定性来自复用固定数据和 reference 约束。两者目标相近，不代表有限样本梯度相同。

GRPO 通常对同一 prompt 采一组回答，用组内奖励均值和标准差归一化得到相对 advantage，再把该序列优势分配给序列 token。它免去独立 critic，方差控制依赖同题多次采样。OREO 显式训练 value，并让不同位置拥有不同 residual；代价是 critic 误差会进入 policy，收益是训练完的 value 可用于搜索。

若同一 prompt 的组内奖励全相同，GRPO 的标准差接近零，组相对信号消失或需要特殊处理；OREO 仍可通过不同 suffix log-ratio 与跨轨迹 value 拟合产生残差。然而全成功或全失败的题缺少局部反事实，OREO 的信号也可能主要来自 KL 一致性，不能据此宣称获得了可靠任务信用。两种方法都受采样覆盖限制，只是暴露方式不同。

### 11.2 advantage 的粒度与方差来源

PPO 配 GAE 时，$\widehat A_t$ 由逐步 TD 残差的指数加权和构成，$\lambda$ 在 bias 与 variance 间调节；GRPO 的组相对 advantage 通常是序列级，组大小决定 baseline 方差；OREO 用完整终局回报和 suffix log-ratio构造 Monte Carlo consistency target，没有 $\gamma$ 或 $\lambda$。它避免 bootstrapping 偏差，长后缀噪声直接进入 target。

三者的 critic 角色也不同。PPO critic 主要用于训练时降低策略梯度方差，可在部署时丢弃；GRPO 常不训练 critic；OREO critic 既参与训练权重，又在 TestingTime 搜索中排序前缀。OREO 对 critic 的要求更高：训练期只需 residual 有用，搜索期还要求跨候选排序稳定，并在搜索诱导的新分布上泛化。

把 OREO 伪优势与 PPO advantage 放在同一冻结 rollout 上比较，是很有信息量的诊断。记录二者的符号一致率、Spearman 相关、按深度的方差以及对最终成功的预测力。若 OREO residual 与 on-policy advantage 大量反号，可能来自离线分布偏移、critic 滞后或 reference 项；若符号接近而 OREO 训练更稳，离线一致性确实在用较低方差逼近相似方向。

### 11.3 何时应转向在线更新

当前策略生成的前缀仍落在离线支持内、验证器昂贵且数据质量高时，OREO 的复用优势最明显。随着策略胜率提高，新错误类型和新推理路线出现，旧数据 residual 继续下降而新采样胜率停滞，覆盖成为瓶颈；此时补采迭代 OREO或切换 PPO/GRPO 比增加 epoch 更合理。

一种连续过渡是先用 OREO 从历史数据获得 policy 与 value，再以该 value 初始化 PPO critic，随后用在线 rollout 校正。另一条路径保留 OREO loss 作为 replay 项，在线批次用 PPO/GRPO，旧数据批次用 consistency loss。混合目标需要分别记录在线与离线梯度夹角；两者持续冲突时，简单相加会互相抵消，应缩短 replay 年龄或降低旧数据权重。

公平比较必须固定总成本。OREO 的离线轨迹生成与 verifier 成本要计入，PPO/GRPO 的 rollout、critic 或组采样成本也要计入；TestingTime search 另列推理预算。只比较训练器每秒 token 会把 OREO 的前置数据成本藏掉，只比较最终分数又会把 value 搜索的额外前向藏掉。可报告达到同一准确率所需的总生成 token、训练 FLOPs 与测试前向数。

## 12. 偏差—方差分解

### 12.1 Monte Carlo target 的方差

令 value target 为 $Y_t=R_t-\beta S_t$，其中 $S_t=\sum_{i\ge t}\ell_i$。在状态 $s_t$ 条件下，

$$
\operatorname{Var}(Y_t\mid s_t)=\operatorname{Var}(R_t\mid s_t)
+\beta^2\operatorname{Var}(S_t\mid s_t)
-2\beta\operatorname{Cov}(R_t,S_t\mid s_t).
$$

二元成功奖励满足 $\operatorname{Var}(R_t\mid s_t)=p_t(1-p_t)$，在 $p_t=0.5$ 附近最大。后缀 log-ratio 的方差随剩余长度增长；若每 token 方差近似 $\sigma^2$ 且独立，约为 $(T-t)\sigma^2$，实际 token 相关会使增长更快或更慢。早期 value target 通常比末段更嘈杂，这与搜索中早期前缀更难排序一致。

$R_t$ 与 $S_t$ 的协方差不能忽略。成功轨迹若通常得到 policy 更高的相对概率，二者正相关，$-2\beta\operatorname{Cov}$ 会降低 target 方差；策略若错误地偏爱失败轨迹，协方差为负，target 方差上升。按成功/失败分别画 suffix 分布，可以直接判断 reference 项在充当控制变量，还是在放大噪声。

增加同一状态的后续 rollout 能降低条件均值估计方差。若同一前缀有 $n$ 条近似独立续写，样本均值方差约降为原来的 $1/n$。论文每题多次采样，但随机轨迹很少共享完全相同的长前缀，深层状态仍接近单样本监督。step-level 合并状态或前缀聚类能增加重复数，同时引入状态聚合偏差。

### 12.2 无重要性采样的偏差收益

经典离线策略评估用 importance ratio 校正行为策略与目标策略差异，长轨迹的比率乘积容易产生巨大方差。OREO省去比率，避免了这类爆炸；经验 residual 始终在数据动作上计算，梯度稳定得多。相应代价是无法无偏估计目标策略占用分布下的回报。

可用一个二动作例子看清。行为策略在状态 $s$ 上以 $0.99$ 选择动作 A、$0.01$ 选择 B，数据中恰好没有 B；目标策略想把 B 提到 $0.4$。OREO 只能约束 A 和 reference KL，对 B 的任务价值没有直接样本。importance sampling 也无法从零观测恢复 B，只会在偶尔出现 B 时给它约 $40$ 的权重并产生高方差。覆盖缺失是两者共同的不可识别问题，是否加权只改变已有稀有样本的偏差—方差。

因此应把离线偏差随策略漂移画成曲线。按当前策略与行为策略的平均 token KL 或前缀密度比分桶，测 value 排序准确率和新采样成功率。低漂移桶准确、高漂移桶快速恶化，说明 reference 约束正接近覆盖边界；所有桶同样差，更可能是 value 容量、奖励或实现问题。

### 12.3 critic 误差怎样污染 policy

设 value 误差为 $\delta_t=V_\phi(s_t)-V^*(s_t)$。在其余项正确时，policy residual 多出 $\delta_t$，伪优势偏差为 $-2\beta\delta_t$。value 高估会使 residual 偏正，压低数据动作概率；低估会提高动作概率。这个方向与直觉容易相反：critic 认为状态已经很好时，Bellman 等式要求当前动作不必再获得过高相对概率。

若 value 误差在同类状态上系统相关，policy 会学习结构性偏差。例如 critic 对长前缀普遍低估，后段 token 获得持续正伪优势，模型可能拖长回答；对包含特殊模板的前缀高估，相关 token 会被压低。按深度、长度、题型与模板分桶残差均值，比只看全局 value MSE 更能预测 policy 偏移。

value 与 policy 共用底座时还可能有梯度串扰。论文表述为 separate value network，7B critic 用 LoRA；若实现为了省显存共享 transformer，只分两个 head，value loss 会修改 policy 表示，即使 policy loss 中 `v.detach()` 也挡不住共享参数路径。此时“只让 value loss 更新 $\phi$”不成立。共享版可以作为工程变体，但要与完全独立网络对照，并检查 value-only step 是否改变 policy logits。

### 12.4 搜索中的最大化偏差

搜索从 $K$ 个候选里选预测 value 最大者，会把估计噪声的正尾部系统性放大。即使每个候选的 value 误差均值为零，$\max_k\widehat V_k$ 的误差均值通常为正；$K$ 越大，过估计越明显。best-of-K 在论文 Figure 4 到 $K=5$ 后趋于饱和，可能同时受到策略候选质量上限与选择偏差影响，单凭曲线无法区分。

可以用双估计器诊断：critic A 选候选，独立 critic B 或额外 rollout 评估被选项。A 的预测与 B 的实现回报之差随 $K$ 增长，说明最大化偏差存在。也可对 value 做深度分层校准，或在分差小于噪声区间时随机保留多个分支。扩大 beam 只有在排序质量随候选难度保持稳定时才保证收益。

搜索还改变数据分布，形成“估计误差—访问频率—更强选择”的闭环。静态均方误差对普通前缀加权，部署损失却应对搜索访问分布加权。记录每个被扩展前缀的访问概率，用离线日志重加权评测，能更接近真实风险；最可靠的证据仍是冻结预算下的端到端成功率与独立重复实验。

### 12.5 校准、排序与不确定性

若 value 只用于 beam 内排序，单调变换不会改变选择，Spearman 相关与 pairwise accuracy 比均方误差更相关；若 value 用来提前终止、分配动态预算或跨题比较，绝对校准才成为硬要求。两种用途应选不同 checkpoint，不能用同一个综合分掩盖取舍。

校准可以按深度分层。把预测 value 分成十分位，在每个深度桶内比较平均预测与实际 KL 正则回报；再做 isotonic 或温度缩放时，只在独立校准集拟合。早期前缀信息少、方差大，一条全局映射常会过度自信；末段映射若套到前段，会让搜索过早剪枝。

pairwise 排序准确率也需要置信区间。同一 prompt 下的候选对共享前缀，边之间高度相关，应按 prompt 整组 bootstrap。比较显式与隐式 value 时，在同一候选对上计算胜负差，再对 prompt 聚类抽样；使用配对差能消除题目难度方差。若两者区间大量重叠且效应很小，Figure 1 式案例不足以支持普遍优势。

不确定性本身可进入搜索。对 value 做多 seed ensemble 或 dropout 重复前向，估计候选均值与标准差；用下置信界 $\widehat V-c\widehat\sigma$ 排序可减少高方差分支的乐观偏差，也可能错过新路线。扫描 $c$ 时固定候选树，报告成功率、多样性和 oracle regret，验证保守选择的真实代价。

最终成功率的区间同样按 prompt 计算。GSM8K 的 1319 题上，胜率接近 $0.75$ 时单次二项标准误约为 $\sqrt{0.75\times0.25/1319}\approx0.012$，两个百分点差异未必稳定；训练 seed 方差还要另算。论文主表提供点估计，复现实验应补多 seed 与 prompt bootstrap，尤其避免把小幅基线差距解释成确定排序。

## 13. 完整手算：成功、失败与 stop-gradient

### 13.1 成功轨迹的 value target

取四步成功轨迹，$R=1$、$\beta=0.2$，逐 token log-ratio 为

$$
\ell=[0.1,-0.2,0.4,0.2].
$$

倒序 suffix 为 $S=[0.5,0.4,0.6,0.2]$，所以四个 value target 是

$$
Y=R-\beta S=[0.90,0.92,0.88,0.96].
$$

设当前 critic 输出 $V=[0.82,0.95,0.70,1.02]$，残差 $e=V-Y=[-0.08,0.03,-0.18,0.06]$。按每条轨迹平均，

$$
\mathcal L_V=\frac{0.08^2+0.03^2+0.18^2+0.06^2}{4}
=0.010825.
$$

最大误差在第三个位置，critic 把该前缀低估了 $0.18$。仅看终局奖励四个位置完全相同，加入 suffix 后 target 已呈现 $0.88$ 到 $0.96$ 的差异。

### 13.2 policy 梯度逐位置计算

在同一批数值上，policy residual 与 $e$ 数值相同，但未来 suffix 已 detach。对每个 $\ell_t$ 的直接导数为

$$
\frac{\partial\mathcal L_\pi}{\partial\ell_t}
=\frac{2\beta}{T}e_t=0.1e_t,
$$

得到 $[-0.008,0.003,-0.018,0.006]$。梯度下降会提高第 1、3 个数据 token 的相对概率，降低第 2、4 个。成功轨迹没有让所有 token 同向提高；critic 与一致性结构把四个位置分成两种方向。这正是 response-level 奖励复制无法提供的粒度。

把第 3 个位置展开到 logit。若数据 token 当前概率为 $p=0.2$，$\partial\log p(a)/\partial z_a=1-p=0.8$。该位置 loss 对目标 logit 的梯度约为 $-0.018\times0.8=-0.0144$，梯度下降提高 $z_a$；其他词 logit 按其概率得到反向变化。这里还未加入 $\alpha\mathcal L_{reg}$，若 KL 梯度方向相反，最终步长会缩小。

### 13.3 失败轨迹不会被整条压低

再取四步失败轨迹，$R=0$，$\ell=[0.2,0.1,-0.3,0.1]$。suffix 为 $[0.1,-0.1,-0.2,0.1]$，value target 为

$$
Y=[-0.02,0.02,0.04,-0.02].
$$

设 critic 输出 $V=[0.05,0,0.10,-0.05]$，残差为 $[0.07,-0.02,0.06,-0.03]$，policy 对 $\ell$ 的梯度为 $[0.007,-0.002,0.006,-0.003]$。第 1、3 个动作会被压低，第 2、4 个动作反而被提高。失败标签约束整条轨迹的回报，局部方向仍由 value 与 suffix 决定；这说明“OREO 从失败中学习”并不等于逐 token 负向 SFT。

这组失败 target 可以出现负值，因为 value 是奖励减 KL 的正则化回报，不受二元奖励 $[0,1]$ 限制。给 critic 输出层套 sigmoid 会错误地禁止负 value，也限制大于一的可能值。论文公式使用无界标量回归，部署若想解释为成功概率，需要另做校准映射，不能在训练阶段随手夹到 $[0,1]$。

### 13.4 stop-gradient 防止后段重复背责

回到成功轨迹。若去掉 stop-gradient，$\ell_3$ 同时出现在 $t=0,1,2,3$ 四个 residual 中，其梯度为

$$
\frac{2\beta}{T}\sum_{t=0}^{3}e_t
=0.1(-0.08+0.03-0.18+0.06)=-0.017.
$$

保留 stop-gradient 时，该位置梯度是 $0.006$，两者连符号都相反。无 sg 的末 token 被所有早期 residual 重复归因，长轨迹里这种累积可达 $O(T)$；有 sg 时只响应自己的局部残差。这个手算比“梯度尺度相同”的文字描述更直接地说明论文为什么在式 (9) 中截断未来项。

value loss 仍需要完整 suffix 的数值，因为它要学习每个前缀到终点的回报；stop-gradient 只控制参数从哪条路径接收梯度，不删除前瞻信息。若实现把 future suffix 从 policy residual 数值中也删掉，目标就变成一步式 $V-R+\beta\ell_t$，与论文式 (9) 不同。单元测试要分别检查 forward 数值包含 future、backward 梯度不经过 future。

### 13.5 从单轨迹到 batch

假设 batch 还有一条两步轨迹，内部均方 residual 为 $0.04$。按论文式的逐轨迹平均，batch loss 为 $(0.010825+0.04)/2=0.0254125$。若直接按六个 token 平均，第一条的平方残差和为 $0.0433$，第二条为 $0.08$，结果是 $0.1233/6=0.02055$。两者相差约 19%，只因归约口径不同。

分布式训练若每张卡先按本地 token 数平均再做卡间平均，还会受长短轨迹在各卡的分布影响。正确做法是 all-reduce 全局分子与分母，或先生成逐轨迹均值再按全局轨迹数平均。用相同全局 batch 在单卡和多卡各跑一步，参数更新应在浮点误差内一致。

## 14. 消融：已有证据与待验证假设

### 14.1 论文真正做了哪些消融

论文 Figure 5 比较 token、step、response 三种粒度。response-level 明显较差，支持逐步一致性对信用分配有贡献；step-level 与 token-level 接近，并在 GSM8K 略优。这个结果同时改变了动作粒度、样本数、log-ratio 尺度和正则系数，不能单独归因于“步骤语义更好”或“token 噪声更大”。

Figure 1 以两个案例比较显式 $A_\phi$ 与隐式 $A_\theta$，显示显式 value 在示例中更能区分正确步骤。它是案例证据，不是大样本消融；论文没有报告逐步排序准确率、校准误差或替换 critic 后的端到端变化。Figure 2 展示三轮迭代 OREO 持续上升、rejection sampling 趋于饱和，但新旧数据比例等细节不足，机制归因仍需控制实验。

Figure 3 与 Figure 4 验证 value-guided search 随预算提升，说明 critic 具有部署价值。搜索同时增加 policy 采样数与 value 前向数，不能把全部增益记为训练算法本身。论文主表比较 SFT、rejection sampling、DPO、KTO 与 OREO，属于端到端基线对照；它没有逐项删除 OREO 的 value loss、policy loss、sg 与显式 KL。

### 14.2 最小机制消融矩阵

| 假设 | 只改变的组件 | 必须固定 | 关键读数 | 推翻条件 |
| :--- | :--- | :--- | :--- | :--- |
| 逐步约束提供信用 | token / step / response 粒度 | 数据、有效 token、更新次数、搜索关闭 | 新轨迹成功率、错误定位、深度分桶 residual | response 与 token 在多 seed 下等价 |
| stop-gradient 稳定长链 | 开/关 future sg | 初始化、batch 长度分布、学习率 | 按长度梯度范数、尾 token 权重、发散率 | 无 sg 在长链上同样稳定且更优 |
| 失败轨迹有额外信息 | 全数据 / 仅成功 / 成功数匹配 | 总训练 token 与 prompt 覆盖 | 困难题、新错误类型、共享前缀切片 | 去掉失败后无显著下降 |
| 显式 critic 优于隐式 value | $V_\phi$ / policy log-ratio 排序 | 同一候选树与预算 | pair 排序、top-$k$ recall、最终成功率 | 隐式 value 全部指标不低 |
| 显式 KL 必要 | $\alpha=0$ 与正值扫描 | $\beta$、数据、训练步 | 当前/域外成功率、相对 reference KL | 去 KL 后无漂移且性能更高 |
| critic 容量影响 policy | LoRA rank、全参、小 critic | policy 与数据 | value 泛化、伪优势符号、policy 成功率 | 容量变化只改训练 MSE |
| 迭代收益来自新鲜度 | 新数据、旧 replay、等量重复旧数据 | 总轨迹数与训练 token | 当前策略样本胜率、旧能力 | 重复旧数据获得同等收益 |
| search 收益来自排序 | value 排序、随机排序、policy 分数 | 候选集合、$B/K$、解码温度 | 固定候选 oracle regret | 随机或 policy 排序同样好 |

“必须固定”列决定消融是否可解释。token-level 每条轨迹产生更多 residual，若仍按同 epoch 比 step-level，优化事件数不同；只成功数据条数较少，若不匹配 token 预算，结果混入训练量；value search 若每种打分器生成不同候选，差异混入 proposal 质量。先冻结候选和预算，再比较排序器，才能定位 value 的贡献。

### 14.3 $\beta$、$\alpha$ 与粒度的联合扫描

单独扫描 $\beta$ 会同时改变 target、policy 梯度尺度和最优策略温度。若学习率固定，观察到的最优 $\beta$ 可能只是梯度量级合适。更稳妥的设计同时记录首步梯度范数，并增加一组按 $\beta$ 反向缩放 policy 学习率的对照；两组趋势一致，才更像目标几何效应。

$\alpha$ 的合理值依赖 residual 归约。token、step、response 的平方项量纲不同，论文已经为后两者分别挑选 $0.1$ 与 $0.3$。比较粒度时应让 KL 项与 consistency 项的初始梯度范数比大致对齐，另报告未经对齐的论文默认值。若只给每个变体挑最佳 $\alpha$，要把调参预算计入并使用独立选择集。

二维网格至少报告四类结果：任务成功率、相对 reference KL、value 排序和训练稳定性。高 $\beta$、低 $\alpha$ 可能让 consistency 项强而显式分布约束弱；低 $\beta$、高 $\alpha$ 可能几乎冻结 policy，仅训练 critic。只看最终准确率无法区分这些退化解。

### 14.4 数据与 critic 的因果消融

失败轨迹消融应保留 prompt 覆盖。直接删掉失败会让困难 prompt 消失，性能下降可能来自题目覆盖减少。可为每个 prompt 保留相同数量轨迹：全数据组含成功与失败，控制组用成功轨迹重采样；对没有成功轨迹的 prompt，另设“保留失败”与“完全删除”两个子组。这样能分离失败内容价值与 prompt 覆盖价值。

critic 消融也需防止参数量混杂。显式 critic 带来额外参数和前向，若对照只用 policy 隐式 value，差异可能来自容量。可增加同参数量但随机初始化后冻结的旁路网络，或让 policy 基线拥有等量 adapter；最终仍以排序和 policy 改进是否同时出现判断机制。

共享底座与独立 critic 的对照应记录显存、吞吐和梯度干扰。共享版若同等性能且成本低，工程上更有吸引力；独立版若显著更稳，说明论文的 separate network 设计承担了隔离作用。value-only 更新前后 policy logits 的最大变化是最直接的串扰测试。

## 15. 可证伪实验

### 15.1 植入单点错误的信用定位

从正确推理链构造局部反事实：只替换一个算术符号、变量绑定或工具参数，保持前后模板和长度尽量一致，再分别保留“错误后继续”与“下一步纠正”两种后续。错误位置已知，可以测 value 最大下降点到真实错误点的距离、前后 residual 符号和 policy 更新集中度。

若 OREO 真能做长程信用，错误发生前的 value 不应系统下降，错误点附近应出现显著变化，纠正后 value 应部分恢复。若整条错误链从开头均匀降低，模型主要利用终局标签或全局风格；若只在最终答案处变化，逐步一致性没有形成有效过程信号。对 token、step、response 三种粒度重复，可直接检验论文的机制解释。

再把错误位置从前段、中段、后段移动，固定错误类型。理想定位性能不应仅在末段好；早段明显更差可以由 target 方差随 suffix 长度增长解释。报告按剩余长度分桶的定位误差，比一个平均分更能验证长程信用。

### 15.2 覆盖受控的离线树

构造深度四、每层两个动作的可枚举推理树，终点奖励已知。先让行为策略覆盖全部 16 条路径，再逐步删除包含某个高奖励动作的轨迹。OREO 在全覆盖时应恢复正确 value 排序；覆盖减少后，未观测分支表现应依赖 reference，且误差随删除比例增加。

这个实验能区分优化失败与不可识别。训练 residual 接近零、观测边排序正确、未观测边错误，说明算法达到了经验目标但数据不支持外推；观测边也错，才优先检查目标实现、容量或优化。加入 CQL 式保守项可作机制对照，但主结论仍围绕 OREO 的 coverage 边界。

把行为策略从接近 reference 改成强烈偏向错误动作，再保持轨迹总数相同。若无 importance correction 的偏差显著扩大，离线占用分布解释得到支持；若结果不变，检查共享参数是否从其它状态补足了信息。

### 15.3 与 PPO、GRPO 的同轨迹对照

固定一批由当前策略生成的轨迹，同时计算 OREO 伪优势、PPO 的 GAE 和 GRPO 组相对优势。所有方法使用同一奖励、reference、prompt 与有效 token，先不真正更新模型，只比较估计量。按深度报告均值、方差、符号一致率、与最终成功的相关性及重复采样稳定性。

第二阶段各走一个小更新，控制 policy 参数变化的 KL 相同，再重新采样评测。若 OREO 估计方差更低且同 KL 下收益相当，离线一致性具有样本复用优势；若 OREO 在离线指标好、在线新样本差，分布偏差占主导；若 PPO/GRPO 方差高但持续发现新路线，在线探索价值被验证。

计算预算按生成 token、policy/value 前向、反向和 verifier 调用拆开。OREO 可复用轨迹多个 epoch，PPO/GRPO 每轮需要新 rollout；可以画性能对累计成本曲线，而非只比较同一步数终点。曲线交叉点比“某方法最好”更有决策价值。

### 15.4 偏差—方差的直接测量

选择一批前缀，各自独立采样大量续写，用经验成功率和平均 KL 正则回报近似高预算真值。再从这些续写中抽 $n=1,2,4,8,16$ 条训练或估值，测 OREO target 的偏差、方差与均方误差。按前缀深度重复，检验早期 target 方差更大的推导。

对同一前缀同时训练 token-level 与 step-level value。若 step 聚合降低方差但产生系统偏差，表现应为方差下降、均值偏离真值；若二者均改善，原 token 状态表示可能不足。论文 Figure 5 的“step 略优”可以由这组量化拆成可检验机制。

critic 误差传播实验可人为给 value 加常数偏差、长度相关偏差和局部噪声，再冻结 critic 做短程 policy 更新。式 $\widehat A^{OREO}=-2\beta e$ 预测了更新方向；观察生成长度、错误类型和 token 概率是否按预测变化。若不一致，说明共享参数、KL 或优化器效应主导，需要更新更完整的因果图。

### 15.5 value-guided search 的闭环验证

先冻结候选树：对每个前缀预生成相同的 $B$ 个后续，分别用显式 value、隐式 value、policy 平均 log-prob、随机分数和 oracle 回报排序。候选固定后，最终成功差异只来自排序。记录 top-$1$ accuracy、top-$B$ recall 与 oracle regret，定位显式 value 的净贡献。

再开放在线生成，逐层记录候选来源和剪枝原因。若冻结树上显式 value 优势明显、开放搜索后消失，问题在搜索诱导分布或 proposal；若两者都无优势，critic 排序能力不足；若排序指标提升却最终成功不升，可能是早期错误不可恢复或 beam 缺乏多样性。

对 $B=1,2,4,7,10$ 扫描时，同时估计最大化偏差。用独立 rollout 评价被选前缀，比较预测 value 与实现回报的差。随着 $B$ 增大，预测继续升而实现回报停滞，说明搜索正在利用 critic 误差。这个结果会直接限定论文“扩大测试预算”的有效范围。

### 15.6 验证器噪声与伪成功

对数学答案做三类受控扰动：正确推理加格式异常、错误推理加正确最终答案、正确答案加等价表达。分别通过 verifier，得到误拒、伪接受与等价性漏判率。再按这些噪声率向干净训练集注入标签翻转，比较 OREO、rejection sampling 与 response-level 变体。

预期 OREO 对单个错标的影响覆盖整条轨迹多个 residual，训练 loss 尾部与梯度集中度会上升；rejection sampling 对伪成功尤其敏感，因为整条错误链被正向模仿。若 OREO 在噪声下仍稳，应能在 residual 分桶和人工复核中看到 critic 把异常吸收或 KL 抑制了更新，不能只凭最终准确率推断鲁棒机制。

具身任务还要拆分环境随机失败。把相同动作序列在固定环境种子和多个随机种子下重放，区分策略错误与环境噪声。服务超时、解析器崩溃和不可达状态应单列，不宜直接记任务失败。否则 value 会学习回避正确但偶尔失败的工具动作。

### 15.7 统计设计与失败判据

数学评测按 prompt 聚类，ALFWorld 按任务与环境种子聚类。每个训练配置运行多个 seed，报告 seed 点、均值或中位数和 prompt-level bootstrap 区间。同题多条轨迹共享难度，不能把轨迹条数当独立样本。超参选择集与最终测试集分开，避免从多组 $\alpha,\beta$ 和 checkpoint 中挑峰值后仍使用朴素区间。

每项机制实验在开跑前写下推翻条件。信用定位若不优于终点距离基线，逐步机制未得到支持；去掉失败轨迹在等预算、等覆盖下无损，失败数据价值不足；显式 value 排序不优于隐式 value，搜索收益不能归因于独立 critic；当前策略离线 residual 下降而在线回报不升，训练目标已与部署分布脱节。

还应报告失败运行比例。平方 residual、双网络耦合和长 suffix 都可能导致少数 seed 发散；只展示成功 seed 会夸大稳定性。将 NaN、KL 超限、reward 崩塌和 value 饱和定义为明确失败，并纳入总体结果。一个平均分略高但三成运行失败的配置，工程价值可能低于均值略低却稳定的基线。

### 15.8 复现实验台账与判读顺序

论文默认配置应原样建立第一条基线：batch size 128；OREO policy 学习率 $5\times10^{-6}$，$\beta=0.03$、$\alpha=0.01$；1.5B 训练一轮，7B 为匹配样本数训练两轮，ALFWorld 模型训练三轮；7B critic 使用 rank 64、alpha 64 的 LoRA，学习率 $10^{-4}$。这组数值只负责复现论文，不应直接当成新模型和新数据的最优配置。

每次运行的台账至少分四块。数据块记录 prompt 数、每题采样数、正负比例、行为策略、温度、最大长度、解析与截断数量；目标块记录粒度、$\alpha$、$\beta$、reward 范围、trajectory/token 归约和 mask；优化块记录两网络参数化、学习率、梯度裁剪、精度、累积步数和随机种子；评测块记录解码参数、search 的 $B/K$、最大步骤、verifier 版本与 bootstrap 单元。缺少任一块，跨运行差异都可能被误归因于 OREO 目标。

结果按三层判读。第一层是实现一致性：解析 target、梯度方向、sg、mask 与分布式归约通过；第二层是训练机制：离线 residual 下降、value 排序改善、KL 与长度受控；第三层是部署结果：当前策略新采样、域外任务和搜索闭环提升。上层通过不能替代下层，例如训练 residual 为零只证明拟合观测等式，无法证明新轨迹回报增加。

对论文主结果的复现先关闭 TestingTime search，用贪心或论文相同解码比较纯训练收益；随后冻结 policy，逐档增加 $B/K$，测 value 的推理收益。训练和搜索同时打开会把两种增益合并。迭代实验再作为第三轴单独加入，并固定每轮新增轨迹数；这样能把一次离线优化、额外交互和额外测试计算三笔预算分别核算。

出现与论文方向相反的结果时，先核对数据成功率分布。基座太强会让多数题全成功，基座太弱会让多数题全失败，两者都缺少同题正负分叉；论文在 7B 数据构造中主动限制正例数量，正是为缓解这一问题。若边界题比例远低于论文设置，OREO 相对 rejection sampling 的优势可能缩小，不能先归咎于超参。

最终报告保留所有 checkpoint 的原始指标，而非只列峰值。DPO 类目标常见 loss 继续下降、生成先升后降，OREO 还多一条 critic 曲线；最佳 policy 与最佳 value 可能出现在不同时间。若部署需要搜索，可按 policy 成功率设硬下限，再在满足下限的 checkpoint 中选择 value 排序最优者，或分别保存 policy 与 critic，但跨 checkpoint 拼接必须重新验证 residual 一致性。

## 16. 结论

OREO 的核心是把 KL 正则化最优策略满足的 soft Bellman consistency 变成离线监督目标。完整轨迹的终局奖励与逐 token policy/reference log-ratio共同构造每个前缀的 value target，policy 再以局部 residual 形成带符号更新。stop-gradient 保留 future suffix 的数值信息，同时阻断后段 token 从所有早期 residual 重复接收梯度。

这套结构在论文的数学推理与 ALFWorld 实验中优于 SFT、rejection sampling、DPO 和 KTO，并产出可用于搜索的显式 value。证据边界同样清楚：主要消融集中在粒度，显式 value 的机制证据以案例和搜索结果为主，迭代混合、critic 时间尺度、stop-gradient、失败轨迹与离线覆盖仍缺少完整因果对照。

实践判断应围绕三件事。第一，离线轨迹是否同时覆盖成功、失败及共享前缀的局部分叉；第二，验证器能否可靠给终局奖励，截断与环境异常是否被正确区分；第三，当前策略是否仍处在数据支持与 reference 约束范围内。三项成立时，OREO 能用接近监督学习的训练形态获得过程价值和策略改进；覆盖耗尽后，应补采迭代或转向在线 PPO/GRPO，而非继续压低旧数据 residual。

复现验收不能停在 loss 下降。解析解残差、suffix 下标、mask、单卡/多卡归约和 stop-gradient 要先通过手算；训练中记录 residual、value target 漂移、policy/reference KL 与长度分桶；训练后同时测新轨迹成功率、value 排序、搜索闭环、域外能力和多 seed 稳定性。只有这些量共同改善，才能把收益归因于长程信用分配，而非数据捷径、critic 记忆或额外测试预算。
