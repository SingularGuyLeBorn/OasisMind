- **年份**: 2025（arXiv v3）
- **论文**: [arXiv:2507.20673](https://arxiv.org/abs/2507.20673)

**前置知识**: GRPO(1.3.1.1 节), GSPO(1.3.2.2 节)

## 1. 动机: 算术平均放大了什么

### 1.1 单 token 离群权重的来源

GRPO 的 surrogate 对一条 rollout 内的 token 做算术平均: $\frac{1}{|o_i|}\sum_t\rho_{i,t}\hat A_i$. 算术平均对离群值敏感——一个 token 的 $\rho_{i,t}=8$, 其余都是 $1$, 平均立刻被拉到 $3$ 以上, 而这条 rollout 的「平均似然漂移」远没有这么大. 离群从哪来? 和 GSPO (1.3.2.2 节) 分析的同一源头: policy 更新让某些位置的 log-prob 大幅移动, 路由敏感的架构里集体翻转更常见. 逐 token clip 是 GRPO 的应对, 但 clip 是逐位置独立的硬截断, 截完之后整条链的权重结构仍然由算术平均决定, 离群值的「余波」还在.

一个量化锚点: rollout 内比率分布的「撕裂度」可以用 max/mean 衡量, 正常更新下这个比值在 1.5 到 3 之间, 路由翻转时刻能冲到 10 以上. 算术平均的合成权重随撕裂度线性涨, 几何均值按开方压, 撕裂度 10 时两者差出三倍——稳定性收益全部来自这个区间, 监控撕裂度分布就能预判 GMPO 在自己管线里的收益空间.

撕裂度还有一个近亲指标: 组内 reward 的标准差 (GRPO 优势归一的分母). 两者常一起涨——模型在难题上输出方差大, 路由也更容易翻转. 区分它们的方法: 分别画「高撕裂度低 reward 方差」和「低撕裂度高 reward 方差」的 batch 占比, 前者多说明病灶在优化侧 (GMPO/GSPO 的适用区), 后者多在数据侧 (该调难度筛选).

GMPO 的切入点在聚合函数：先按优势符号对每个 token 的 log-ratio 做裁剪，再把整条回答的 clipped importance-weighted reward 从算术均值改成几何均值。GSPO 对序列 ratio 做一次整体裁剪；GMPO 保留 token 级裁剪，却在裁剪后使用回答级几何聚合。两者会得到相近的未裁剪几何 ratio，裁剪位置与梯度开关不同。

### 1.2 算术平均的另一个问题: 向量抵消失效

原论文用一个小例子说明算术平均在「向量层面」的麻烦. 设 $T=3$, $\hat A=1$, 三个 token 的比率 $\rho=(1,1,8)$, 梯度向量 $g_1=(1,0)$, $g_2=(0,1)$, $g_3=(-1,0)$. GRPO 的合成梯度是 $\frac{1}{3}[(1,0)+(0,1)+(-8,0)]=(-7/3,\,1/3)$: 第三个 token 的离群权重不仅自己方向占主导, 还把前两个 token 的贡献几乎全部抵消. 一次更新被单个位置绑架.

换成几何均值, 权重变成 $\rho_{geo}=(1\cdot1\cdot8)^{1/3}=2$, 合成梯度是 $\frac{1}{3}[(2,0)+(0,2)+(-2,0)]=(0,\,2/3)$: 离群值被压缩到 $2$, 三个 token 的贡献按接近相等的权重合成, 方向由多数意见决定. 这个例子是机制演示, 不是实测梯度, 但它准确指出了算术平均的失败模式: **权重离群会同时破坏合成的方向和幅度**.

值得补一句: 向量抵消在真实训练里不一定是坏事——两个方向相反的 token 梯度相互抵消, 可能正是「模型在两个候选行为间犹豫」的忠实反映. GMPO 的问题不在抵消本身, 而在**抵消由离群权重主导**: 一个 $\rho=8$ 的 token 强迫其余 token 陪它抵消, 多数意见被绑架. 几何压缩后权重接近, 抵消重新反映多数意见, 这才是它想要的修正.

## 2. 几何均值聚合

### 2.1 定义与 log space 实现

GMPO 的主项写成

$$\left(\prod_{t=1}^{|o_i|}|\rho_{i,t}(\theta)\hat A_i|\right)^{1/|o_i|}\operatorname{sgn}(\hat A_i).$$

忽略裁剪时，同一 rollout 的 $\hat A_i$ 对所有 token 相同，可以拆出来，梯度权重等价于

$$\rho_{geo}=\left(\prod_t\rho_{i,t}(\theta)\right)^{1/|o_i|},$$

即序列内 token 重要性比的几何均值，方向由 $\hat A_i$ 的符号恢复。实现上直接算乘积会下溢或上溢，标准做法是在 log space 运算：$\log\rho_{geo}=\frac{1}{|o_i|}\sum_t\log\rho_{i,t}$。未裁剪时它与 GSPO 的长度归一序列 ratio 是同一个表达式。完整 GMPO 会先依据优势符号逐 token 裁剪 log-ratio，再对裁剪结果求均值；最终每条回答仍产生一个几何聚合标量。

这个「表达式相同, 用法不同」的观察值得记住一半: 几何均值和长度归一似然比是同一个数学对象, 争议从来不在它是什么, 在它在哪个粒度上服务什么目标.

从估计理论看, 几何均值对应「对数空间的平均漂移」. 它无偏估计的是 $\mathbb{E}[\log \rho]$——一个和 KL 散度直接相关的量. 这让 GMPO 的修正有清晰的信息论含义: 它按「平均对数似然变化」加权, 和 GSPO 一样是有偏但方差可控的选择, 偏差的结构同样写在 log 空间.

### 2.2 AM-GM 与权重重塑

正数范围内, 算术平均不小于几何均值: $\rho_{geo}\le\frac{1}{T}\sum_t\rho_{i,t}$. 等号当且仅当所有 $\rho_{i,t}$ 相等. 含义: GMPO 的合成权重永远不大于 GRPO 的, 且**比率分布越不均匀, 两者差距越大**——均匀时两者相等, 一个离群时 GMPO 相对 GRPO 压缩得最多. 这正是想要的结构: 对「正常」的 rollout, GMPO 和 GRPO 行为接近; 对「撕裂」的 rollout, GMPO 自动压低合成幅度. 稳定性收益集中在最需要的地方.

注意 AM-GM 比的是标量权重的幅度, 不能直接推出合成梯度范数的关系. 反例: $T=2$, $\rho=(2,1)$, $g_1=(1,0)$, $g_2=(-2,0)$, GRPO 两项恰好抵消 (范数 $0$), GMPO 得 $(-\sqrt2/2,0)$ (范数 $0.707$). 算术抵消反而更小的情形确实存在. 几何均值的优势应落在**避免单点主导合成方向**上; 上一节的 $(-7/3,1/3)$ 例子里, GMPO 的方向明显更可信, 却不能由此宣称梯度范数总会更小.

「更可信」三个字需要落地: 可信与否最终由下游指标裁决, 但至少有一个先验标准——合成方向应该主要由「多数 token 的意见」决定, 而不是由「最极端的 token」决定. 几何均值按乘积计票, 一个离群 token 需要其余所有 token 反向才能扳回, 满足这个标准; 算术平均按加和计票, 一个足够大的离群可以单挑全组, 不满足.

这个「计票」视角还能解释为什么不选更激进的稳健统计量 (中位数, 截尾均值): 中位数完全丢弃幅度信息, 几何均值保留了「每个 token 投多少」的连续权重, 只是按乘票压缩. 在「保留信号」和「压制离群」的谱系上, 算术和几何分别靠两端, 中位数在几何之外, 选择上先动几何, 不够再考虑更激进的方案.

### 2.3 手算: 权重对照

取图 1 的设定: 组内 reward $r=(0,1,0,1)$, 总体标准差下 $\operatorname{mean}=\operatorname{std}=0.5$, $o_2$ 的优势 $\hat A_2=(1-0.5)/0.5=+1$. $o_2$ 有三个有效 token, 比率 $(0.5,1,8)$. 算术平均: $(0.5+1+8)/3=3.1667$. 几何均值: $(0.5\times1\times8)^{1/3}=4^{1/3}\approx1.5874$. GRPO 的合成权重是 $3.17$, GMPO 是 $1.59$, 压缩近一半, 且压缩量主要来自那个 $8$.

再看 log space 的稳定性: $\log\rho=(-0.693,0,2.079)$, 均值 $0.462$, 指数化回 $1.587$, 与直接开立方一致. 每一步的量级都温和 (最大 $2.08$), 没有乘积形式的 $0.5\times1\times8=4$ 之外的中间量爆炸——其实乘积本身也不大, 但几千 token 时乘积的指数增长会失控, log space 是必须而非风格. padding 不进平均, 有效 token 数大于零, $\hat A=0$ 时主项为零, 这三条和 GRPO 的约定一致.

再补一个数值细节: 几何均值对接近零的比率格外敏感——$\rho=10^{-6}$ 的 token 把乘积拉低六个数量级, 开方后仍有 $10^{-6/T}$ 的痕迹. 实现里通常给 $\log\rho$ 设下限 (例如 $-20$), 防的是极端位置把整个 rollout 的权重归零; 这个下限和 clip 的下界 ($-0.4$) 是两道独立的闸, 一道管数值存活, 一道管训练语义, 别合并.

下限的取值随精度变: float32 下 $-20$ 绰绰有余, bf16 下 log 空间的有效位数少, 建议全程 float32 算 log-ratio 再转回, 和 ORPO (1.2.4 节 §4.1) 的精度纪律同一来源.

把这条纪律推广: 凡是「先求和/求积再取对数」的环节, 都在 log 空间用 float32 完成中间运算, 这已经是 RL 实现的通用约定, 写新损失时默认遵守即可.

### 2.4 手算二: 均匀与撕裂的对照

固定 $T=4$, 看两种比率形态. 形态一「均匀微漂」: $\rho=(1.05,0.97,1.01,0.99)$, 算术平均 $1.005$, 几何均值 $(1.05\times0.97\times1.01\times0.99)^{1/4}\approx1.0049$. 两者几乎重合——均匀场景下 GMPO 不改变任何行为, 这是设计的一部分: 不动正常的更新.

形态二「单点离群」: $\rho=(1,1,1,4)$, 算术平均 $1.75$, 几何均值 $4^{1/4}\approx1.414$. 压缩 $19\%$. 形态三「双点对冲」: $\rho=(2,0.5,1,1)$, 算术平均 $1.25$, 几何均值 $(2\times0.5)^{1/4}=1$. 算术平均被两个方向的离群同时推高, 几何均值识别出「乘积没变」——这条链的平均似然漂移其实是零. 三个形态合起来说明几何均值的工作方式: 它回答的问题是「这条链的 likelihood 乘积漂移多少」, 而不是「这条链的比率加起来多少」, 前者才是 off-policy 修正理论真正关心的量.

形态三还纠正一个直觉: 「离群对冲」 (一个大正配一个大负) 在算术平均下完全隐形——加和 $2+0.5=2.5$ 看着温和, 实际链上发生了剧烈的此消彼长. 几何均值靠乘积结构 ($2\times0.5=1$) 识别出净漂移为零. 如果任务里这类对冲常见 (例如长链推理中间改道), 几何均值的信号质量优势明显.

## 3. 裁剪与方向恢复

### 3.1 符号-裁剪-聚合的顺序

GMPO 的完整目标分三步. 第一, 用 $\hat A_i$ 的符号统一「有利方向」, 使正负 advantage 复用同一套 token 级裁剪. 第二, 在 $\log\rho_{i,t}$ 空间做对称裁剪 $[-\epsilon,\epsilon]$, 论文取 $\epsilon=0.4$, 对应比率区间 $[e^{-0.4},e^{0.4}]\approx[0.67,1.49]$. 第三, 对裁剪后的 log-ratio 求平均, 连同符号一起进损失.

这个顺序和 GRPO 不同: GRPO 先逐 token 构造 $\rho A$ 再 clip  surrogate, GMPO 先在 log space 裁 $\log\rho$ 再聚合. 差异看似细微, 后果不小: log space 的裁剪是**对称的加法截断**, ratio 空间的 clip 是不对称的乘法截断; 前者对大小离群一视同仁 ($\pm0.4$ 对应 $0.67$ 和 $1.49$, 相对幅度不同), 后者按相对幅度截停. 哪个更合理取决于你关心「对数漂移」还是「相对漂移」——和 GSPO §3.3 的量纲之争同源.

选择量纲有一个可操作的判别: 看你想让 clip 在「概率翻倍」处如何动作. log 空间对翻倍 ($d=0.69$) 和腰斩 ($d=-0.69$) 给对称处理; ratio 空间的 $\epsilon=0.2$ 在翻倍前就截停了. 如果训练经验是「翻倍常常是合理的强化」, log 空间顺眼; 如果「翻倍几乎总是失控」, ratio 空间顺眼. 论文选 log 空间, 和它对「正向强化放宽」的目标 (§3.3) 一致.

### 3.2 单侧截断的解读

论文的裁剪和 min 组合有一个精妙的化简. 记 $d_t=\log\rho_{i,t}$, 裁剪值 $c_t=\operatorname{clamp}(d_t,-\epsilon,\epsilon)$, 目标里的 $\min$ 取 $u_t=d_t$ 与 $c_t$ 的较小者. 因为 $\min(d_t,\operatorname{clamp}(d_t,-\epsilon,\epsilon))=\min(d_t,\epsilon)$, 映射回有效 log-ratio: **正 advantage 对应 $d_{eff,t}=\min(d_t,\epsilon)$, 负 advantage 对应 $d_{eff,t}=\max(d_t,-\epsilon)$**——单侧截断, 截的方向和 advantage 符号一致.

这和 PPO 的 clip 语义完全对齐: 好动作只截上端 (概率涨太多才停), 坏动作只截下端. GMPO 在 log space 里用对称 clamp 加 min, 实现了 ratio 空间里 Direction-aware 的单侧截停, 而且正负分支共享同一行代码. 手算验证: $d=(-0.7,0.1,0.8)$, $\epsilon=0.4$, 正 advantage 得 $(-0.7,0.1,0.4)$, 负 advantage 得 $(-0.4,0.1,0.8)$, 平均后分别是 $-1/15$ 和 $1/6$——负的 log-ratio 在正 advantage 下原样保留 (概率降的位置继续降), 正的 log-ratio 被截到 $0.4$; 负 advantage 镜像. 逐条语义都可解释.

这个单侧化简还有一个工程红利: 实现不需要按 advantage 符号写两套 clip 分支, 一行 `torch.min` 加一行 `clamp` 就够了, 符号分流由 min 的数学结构自动完成. 减少了分支就减少了测试面, §7.2 的第一个不变量验证的正是这个化简.

负 advantage 分支里的 `max(d, -eps)` 来自 `min` 结构在负号下的镜像. 两个方向共享同一个 $\epsilon$，配置由此保持正负 log 边界一致.

### 3.3 log clip 与 ratio clip 的手算对照

把两种裁剪并排算一遍, 看清量纲差异. 取 $d=\log\rho=0.4$ (即 $\rho=e^{0.4}\approx1.49$) 和 $d=-0.4$ ($\rho\approx0.67$): log clip ($\pm0.4$) 两端都恰好放行, ratio clip 若用 GRPO 式的 $[0.8,1.2]$, 两个都越界被截. 同一边界在两种量纲下宽差一倍. 再看 $d=2.0$ ($\rho=7.4$): log clip 截到 $0.4$, 相对压缩 $e^{-1.6}\approx20\%$; ratio clip ($\epsilon=0.2$) 截到 $1.2$, 相对压缩 $84\%$. log clip 对大幅正漂移温和得多, 对小幅负漂移严格得多.

这个不对称是特性: 训练里最需要压制的是「负向滑移」 (概率不该降的位置降了), 它对应负的 $d$, log clip 用 $-0.4$ 的紧边界盯着它; 「正向强化」 (对的 token 概率涨) 对应正的 $d$, 宽边界 ($0.4$ 对应 $49\%$ 涨幅) 放行. 和 Clip-Higher (1.3.2.1 节) 的哲学一致, 实现路径不同: Clip-Higher 在 ratio 空间调不对称边界, GMPO 在 log 空间用对称边界天然获得不对称效果——$\pm0.4$ 对 $e^x$ 就是 $+49\%$ 与 $-33\%$.

把三个方法的「正向放宽」并排收个尾: Clip-Higher 调 ratio 上界 ($1.2\to1.28$), GSPO 把 clip 整体搬到序列级并缩小量纲, GMPO 用 log 对称边界获得隐式不对称. 目标相同, 手段的量纲不同, 复用时最容易出错的就是把一家的数值搬到另一家的量纲里.

## 4. 与 GRPO, GSPO 的并排

### 4.1 三种聚合的坐标

| 维度 | GRPO | GSPO | GMPO |
|------|------|------|------|
| **比率级别** | 逐 token $\rho_{i,t}$ | 序列级 $s_i$ | 逐 token, 几何聚合 |
| **聚合函数** | 算术平均 | log-ratio 平均后指数化 | log-ratio 裁剪后平均 (即几何均值) |
| **clip 位置** | ratio 空间, 逐 token | 序列级, ratio 空间 | log 空间, 逐 token |
| **clip 语义** | 双侧, min 结构 | 双侧, min 结构 | 对称 clamp + min ⇒ 单侧 |
| **离群处理** | 逐点截停, 算术放大 | 平均消解 | 几何压缩 + log 截停 |
| **KL** | 通常保留 | 视配方 | 论文 recipe 省略 |

三个方法是一条轴上的三个点: **聚合粒度** (token 级 → 序列级) 和 **聚合函数** (算术 → 几何) 两个坐标. GRPO 是 (token, 算术), GSPO 是 (序列, 几何), GMPO 是 (token, 几何). 这个坐标系比「谁更好」的问题更有用: 每个坐标的选择各有独立的理由, 组合出新变体的空间也一目了然.

坐标视角还解释了这三个方法的发布顺序: GRPO (2024.02) 定下坐标原点; DAPO (2025.03) 在 clip 坐标上调参; GSPO (2025.07) 和 GMPO (2025.07, 同期) 分别探索两个聚合坐标的另一端. 半年内三个团队独立地往同一坐标系填点, 说明这个坐标系不是事后整理, 是社区正在共同摸出来的结构.

这个坐标系对未来变体也有预测力: 剩下的空格 (序列级 × 算术) 没有方法占据, 因为序列级比率天然在 log 空间定义, 算术平均对它没有意义; (token 级 × 其他稳健统计量, 如截尾均值) 是下一个可能被填的格子. 读者若在文献里见到新变体, 先在这个坐标系里找它的位置, 比从动机叙事读起快得多.

### 4.2 GMPO 与 GSPO 的近亲关系

§2.1 已经指出 $\rho_{geo}$ 和 $s_i$ 是同一表达式. 两个方法的分歧在裁剪和粒度: GSPO 把平均后的标量当「这条链的似然漂移」, 做一次序列级判决; GMPO 把平均当「压缩离群后的 token 级权重」, 保留逐 token 的梯度贡献 (每个 token 的梯度方向仍由各自的 $g_{i,t}$ 决定, 只是权重被几何压缩统一). 用 §1.2 的例子: GMPO 的合成梯度是 $(0,2/3)$, 三个 token 的贡献都还在; GSPO 的序列级 clip 只产生一个标量决策, token 间的方向差异在比率层面不再可见.

哪个更合理, 取决于离群的性质: 若离群是「集体伪影」 (路由翻转), GSPO 的平均更彻底; 若离群里混着「个别位置的真实信号」, GMPO 的几何压缩保留了位置的存在感, 只压幅度. GMPO 论文的定位是前者场景的轻量替代: 不改粒度, 不换基建, 只换聚合函数, 拿到大部分稳定性收益.

这段关系也提示一个组合可能: GMPO 的几何聚合和 GSPO 的序列级 clip 并不互斥——先逐 token 做 log 裁剪和几何平均, 再对 $\rho_{geo}$ 做一次序列级 clip, 两个粒度的防护叠在一起. 没有公开实现验证这种组合, 代价是增加两个 clip 边界的联合标定, 收益与稳定性均未知, 因而目前不能作为训练建议.

## 5. 稳定性机制与边界

### 5.1 几何压缩的稳态效果

把 §2.2 的 AM-GM 结构放进训练动态里看. 训练深入后, rollout 内比率分布的离散度随 off-policy 程度增长, 算术平均的合成权重被离群 token 持续推高, 有效学习率随 batch 构成漂移; 几何均值的合成权重被同一批离群压缩, 有效学习率更平. 论文的稳定性实验 (极端 token ratio 下 GRPO loss 爆炸, GMPO 平滑) 正是这个机制的直接证据. 附带收益: 合成幅度低意味着 clip 触发率也低, 有效梯度占比高.

这套机制有一个可证伪的预测: 如果 GMPO 的收益来自几何压缩, 那么把 GRPO 的 clip 边界大幅收紧 (让 clip 代替压缩) 应该复现一部分收益, 但不能全部复现——因为 clip 截的是单点, 算术平均的结构没变. 论文没有做这组对照, 读者在自己的管线上可以用它检验「聚合函数是独立故障源」这个归因.

这组对照还有一个副作用: 若「收紧 clip」复现了大部分收益, 说明问题主要在单点离群, 聚合函数是次要的; 若复现不了, 算术平均的结构本身在作妖, GMPO 的替换才是对因治疗. 一组对照实验同时回答「该不该上」和「上了管不管用」两个问题.

### 5.2 AM-GM 不能推出的结论

边界也要写明. 第一, AM-GM 只给幅度关系, 不给方向关系, §2.2 的抵消反例说明「GMPO 梯度范数一定更小」不成立. 第二, 几何均值对**均匀分布的离群不敏感, 对系统性偏移敏感**: 所有 token 的 $\rho$ 同时涨到 $1.5$, 几何均值一样到 $1.5$, 压缩无从发挥——它治的是「撕裂」, 不是「整体漂移」, 后者靠 clip 和 KL. 第三, log space 的加法裁剪按对数尺度截停, 对已经很大的正漂移 ($d=2$, 上限 $0.4$) 截得狠, 对很小的负漂移 ($d=-0.5$, 下限 $-0.4$) 截得轻, 这个不对称是按设计来的, 移植时若想换成 ratio 空间的对称 clip, 语义已经不同.

顺带点出一个表述陷阱: 描述 GMPO 时别说「它对每个 token 的几何平均做 clip」——clip 发生在平均之前, 平均的是 clip 后的量. 顺序反过来的版本 (先几何平均再 clip 标量) 是另一个算法, 语义接近 GSPO 的序列级 clip. 两个版本在 $\epsilon$ 很小时趋同, $\epsilon$ 大时分叉, 写配置和读论文时先确认顺序.

### 5.3 与 DAPO 补丁的叠加关系

GMPO 和 DAPO (1.3.2.1 节) 的 token-level loss 名字相近, 作用点不同, 值得拆开. DAPO 的 token-level loss 改的是**回答之间**的归约分母 (按条等权改成按 token 数加权), GMPO 改的是**回答内部**的聚合函数 (算术改几何), 两者正交, 可以同时用. clip-higher 和 GMPO 的 log clip 都动 clip, 语义相容 (§3.3 已说明两者都偏向「正向强化放宽」), 数值要重新标定. 动态采样, 长度塑形, 优势归一完全不受影响.

叠加时有一个隐藏的次序问题: 若同时用 GMPO 的几何聚合和 DAPO 的 token 统一分母, 分母把长回答的 token 权重放大, 几何均值把离群压缩, 两个效应在梯度上相乘, 有效权重结构变得更难直觉把握. 不是不能用, 是调试时每个现象都要归因到两层中的哪一层——这正是 §4.1 坐标系的价值, 报配置时把每个坐标的选择写明.

叠加的验证成本也随层数增长: 单层 clip 的调试是单因子扫描, 两层 clip 的交互是二维扫描, 每层还要配自己的标定流程.

调试预算的分配反过来也指导选型: 若团队只有一个 RL 工程师的调试带宽, 与其维护两层 clip 的组合, 不如选单层方案把边界情况跑全, 稳定性差距往往小于调试事故的损失. 团队规模小或调试带宽紧时, 先把单层方案吃透, 叠加留给有明确证据需要的场景.

## 6. 实验, 边界与选型

### 6.1 论文报告了什么

论文在数学推理的 1.5B/7B/32B 模型和 Geometry3K 多模态设置上做实验, 报告 7B 设置在五个数学基准的平均 Pass@1 上比对应 GRPO 高 $4.1$ 个百分点, Geometry3K 高 $1.4$ 个百分点, 同时训练曲线更稳. 方法层面可靠的结论是: token 级算术平均是 GRPO 稳定性的一个可分离的故障源, 只换聚合函数 (不动采样, 不动优势, 不动粒度) 就能拿到可观的稳定性收益. 作为独立作者的工作被 ICLR 2026 接收, 也说明评审认可这个归因的干净.

也要指出实验设置的边界: 对照的 GRPO 是「教科书版」 (算术平均, 对称 clip, 无 DAPO 补丁), 和 1.3.2.1/1.3.2.2 节反复强调的社区现状有距离. 4.1 分应读作「GMPO 对 vanilla GRPO 的提升」, 不是「GMPO 对当代最佳实现的提升」; 后者需要把 DAPO 补丁逐个加回对照组再测.

五个数学基准的 Pass@1 平均是常见口径，但 Pass@1 对采样温度敏感，对比需要使用一致的解码配置。引用实验数字时，同时标明表格、模型规模与评估设置，避免把不同配置的结果并排解释.

### 6.2 批评与边界

第一, 4.1 分绑定特定模型, 数据和评测协议, 且对照的 GRPO 未必带 DAPO 系的补丁 (Clip-Higher, token-level loss 本身就在改聚合)——在带补丁的 GRPO 上 GMPO 的边际收益没有公开数据. 第二, $\epsilon=0.4$ 的量纲绑定 log space, 迁移时和 GSPO 的 clip 一样要重新标定 (§3.1). 第三, 几何均值在零值处发散: 某个 token 的 $\pi_\theta$ 降到零 (mask 外的极端情况), log-ratio 是 $-\infty$, 实现里要靠有效 token 过滤和数值下限兜住, 这个工程细节论文着墨不多.

第四个批评关于归因粒度: 论文把稳定性提升归给几何均值, 但 log clip 的引入是同时的, 两个改变没有独立消融 (只有「两者一起 vs GRPO」的对照). 「聚合函数」和「log 空间 clip」哪个贡献更大, 现有证据分不开. 复现者若想验证, 做一个「算术平均 + log clip」的中间变体就能拆开, 成本不高.

第五个边界: 论文没有覆盖多模态之外的任务类型, 代码修复, 工具调用等结构化输出的 reward 稀疏性和长度分布都不同, 几何压缩的收益曲线未必平移. 跨任务推广前, 先用 §7.2 的重放检查在自己的 batch 上测适配度, 这一步比任何论文数字都接近真相. 这条纪律对 GMPO 尤其重要, 因为它的收益结构 (治撕裂) 和任务的数据结构强相关.

### 6.3 什么时候试 GMPO

已有 GRPO 基建, 不想动粒度 (保留 token 级日志和监控), 但被离群 token 的 loss 尖峰折磨时, GMPO 是最小改动: 聚合函数一行, clip 搬去 log space 几行. 三个判断信号和 §4.2 一致: 离群里含真实信号选 GMPO, 纯伪影选 GSPO, 想先零成本验证则按 §7.2 的不变量在历史 batch 上重放两种聚合的合成梯度, 看方向差异有多大.

还有一类场景不建议上 GMPO: 优势本身噪声大 (reward 方差高或组大小小) 时, 几何压缩稳定的是比率维度, 稳定不了优势维度, 两个噪声源叠加, 收益被稀释. 先把采样侧 (组大小, 难度筛选) 调好, 再动聚合函数, 顺序和 DAPO §7.3 的建议一致: 按症状下药, 不按流行升级.

GMPO 的症状清单再列一遍: rollout 内比率撕裂度高, loss 尖峰与个别 token 同步, 收紧 clip 治不住. 三条全中再动手; 只中一条, 先查更便宜的解释 (数据噪声, 学习率, 参考策略版本).

训练崩溃前若干步的指标快照、参考策略版本和近期数据变更，可以区分 ratio 聚合异常、版本错配与数据分布突变，减少无效的算法归因.

### 6.4 实现生态与复现路径

GMPO 的官方实现 (callsys/GMPO) 是单作者仓库, 规模和维护力度不能和 verl 这类框架比, 复现路径有两条. 一是直接在官方代码上跑小规模验证: 仓库自带最小训练脚本, 适合确认机制和论文曲线的大形状; 生产使用要自己补监控, 日志和容错. 二是在已有 GRPO 基建上按 §7.1 自实现: 改动集中在损失函数, 其余 (采样, 优势, 调度) 全部复用, 多数团队一天内能完成. 两条路的共同前提是先跑 §7.2 的不变量测试.

社区采用度方面, GMPO 作为 ICLR 2026 的新工作, 主流框架 (verl, OpenRLHF, TRL) 的集成还在早期, 搜配置时注意区分「官方 recipe」和「框架默认改造版」, 后者常把 log clip 的数值按框架习惯重标定, 和论文的 $\epsilon=0.4$ 不是一回事. 这个区分和 1.3.1.1 节「五个开关」的核对清单是同一套动作: 名字相同, 坐标不同.

GMPO 与 GSPO 都出现于 2025 年 7 月: 前者改聚合函数, 后者改约束粒度; 一个月后的 Dr. GRPO 又继续讨论归一化问题. 比较这组工作时, GRPO 原版提供共同坐标, 三个变体则分别对应不同训练症状. 方法选择应按被修改的坐标进行, 不能只比较论文名称和单项分数.

按名字选型的风险在本家族已经兑现过: 「都叫 GRPO」的实现可能差了 clip, 归约, 采样三个坐标, 「都叫稳定化」的论文动的是完全不同的量. 坐标系是防这类事故的疫苗. 这套防法不增加任何运行时成本, 只要求报配置时多写两行. 对单人团队, 这两行可以固化成配置模板里的固定字段, 让坐标报告成为提交训练配置的强制项. 模板化之后, 回看历史 run 时也能直接读出当时的选择, 省去翻代码的工夫. 这也是配置即文档原则在 RL 训练里的具体落地. 1.3 节的各篇实现清单都可照此模板归档.

## 7. 实现

### 7.1 教学实现

```python
import torch

def gmpo_loss(new_logp, old_logp, advantages, mask, eps=0.4):
    # new_logp, old_logp: [batch, seq]；advantages: [batch]；mask: [batch, seq]
    d = (new_logp - old_logp.detach()) * mask          # log ρ，padding 为 0
    d_eff = torch.min(d, torch.full_like(d, eps))      # 正 advantage 分支
    # 负 advantage：max(d, -eps) = -min(-d, eps)，按符号分流
    neg = advantages < 0
    d_eff = torch.where(neg.unsqueeze(-1),
                        torch.max(d, torch.full_like(d, -eps)), d_eff)
    lengths = mask.sum(-1, keepdim=True).clamp(min=1)
    log_geo = d_eff.sum(-1, keepdim=True) / lengths    # [batch, 1]
    weights = torch.exp(log_geo).squeeze(-1)           # ρ_geo
    adv = advantages.detach()
    surr = weights * adv
    # min 结构的另一半 (权重偏大时取裁剪值) 已在 d_eff 的单侧截断中体现
    return -surr.mean()
```

对应论文 Algorithm 1 的核心: log space 裁剪, 单侧化简, masked 几何平均. `advantages.detach()` 和 `old_logp.detach()` 不可省. $\hat A=0$ 的 rollout 主项为零, 可在损失前过滤.

这段代码省略了论文 Algorithm 1 的两个外围步骤: 优势的标准差归一 (沿用 GRPO 的组内归一, 在进损失前完成) 和无效组的过滤 (全同 reward 组主项天然为零, 是否显式丢弃看吞吐策略). 省略它们不影响核心机制, 完整的训练循环按 1.3.1.1 节的流程图拼装.

### 7.2 验证清单

三个不变量. 第一, 单侧化简: 对随机 $d$ 和两种符号, 验证 `min(d, clamp(d,-eps,eps))` 等于 `min(d,eps)` (正) / `max(d,-eps)` (负), 这是 §3.2 的代码级重述. 第二, 等价性: 短序列 (如 $T=3$) 上, log-space 几何平均与直接乘积开方在 float32 内一致; 长序列 (如 $T=4096$) 上直接乘积溢出而 log 版本正常——这个对照本身就是 log space 必要性的演示. 第三, 退化: 全等比率 $(c,c,\ldots)$ 下 $\rho_{geo}=c$, 几何平均退化为常数; 全零 mask 的 rollout 被过滤或主项为零. 另补一个历史 batch 重放检查: 对同一批 (log-ratio, 优势), 分别用算术和几何聚合算合成梯度, 报告方向余弦和范数比, 作为迁移前的适配度测量.

这组不变量同样可以离线跑在历史 batch 上, 不依赖训练: 第一个验证代码正确性, 第二个验证数值稳定性, 第三个验证退化语义, 重放检查测适配度. 四步都不需要 GPU 训练循环, 符合「先测后训」的调试纪律, 也是这套实现可以进 CI 的原因.

## 8. 从 GRPO 到 GMPO 的目标函数

### 8.1 GRPO 聚合的对象

给定问题 $q$，old policy 生成 $G$ 条回答 $o_1,\ldots,o_G$，组内 reward 标准化得到

$$
\hat A_i=\frac{r_i-\operatorname{mean}(r_1,\ldots,r_G)}
{\operatorname{std}(r_1,\ldots,r_G)}.
$$

第 $i$ 条回答中第 $t$ 个 token 的 importance ratio 为

$$
\rho_{i,t}(\theta)=
\frac{\pi_\theta(o_{i,t}\mid q,o_{i,<t})}
{\pi_{old}(o_{i,t}\mid q,o_{i,<t})}.
$$

暂时略去裁剪，GRPO 对一条回答优化

$$
J_i^{\text{GRPO}}=\frac1{T_i}\sum_{t=1}^{T_i}\rho_{i,t}\hat A_i.
$$

因此算术平均的对象是 token 级 importance-weighted reward $\rho_{i,t}\hat A_i$。优势在同一回答内共享，ratio 随 token 变化。某个极端 ratio 会单独放大对应 token 的参数梯度。

### 8.2 GMPO 聚合的对象

GMPO 将同一组正负同号的 token reward 取绝对值后做几何均值，再用优势符号恢复方向：

$$
J_i^{\text{GMPO}}
=\left(\prod_{t=1}^{T_i}|\rho_{i,t}\hat A_i|\right)^{1/T_i}
\operatorname{sgn}(\hat A_i).
$$

因为 $\rho_{i,t}>0$ 且 $\hat A_i$ 在序列内为常数，未裁剪时可化简为

$$
J_i^{\text{GMPO}}=hat A_i
\left(\prod_{t=1}^{T_i}\rho_{i,t}\right)^{1/T_i}.
$$

这里的聚合结果属于回答级标量，内部原料来自 token 级 ratio 与序列级 advantage。用「token 方法」或「sequence 方法」单独概括都容易丢掉一半信息：GMPO 的裁剪发生在 token 级，几何聚合和最终 surrogate 发生在回答级。

### 8.3 完整的 token 级裁剪

论文算法在 log 空间按优势符号裁剪。令

$$
d_{i,t}=\log\rho_{i,t},\qquad z_{i,t}=\operatorname{sgn}(\hat A_i)d_{i,t}.
$$

对称 log 边界 $[-\epsilon,\epsilon]$ 下，先计算

$$
\tilde z_{i,t}=\min\left(z_{i,t},
\operatorname{clip}(z_{i,t},-\epsilon,\epsilon)\right),
$$

恢复方向 $\tilde d_{i,t}=\operatorname{sgn}(\hat A_i)\tilde z_{i,t}$，得到

$$
\tilde\rho_{geo,i}
=\exp\left(\frac1{T_i}\sum_t\tilde d_{i,t}\right),
\qquad
J_i=\hat A_i\tilde\rho_{geo,i}.
$$

正优势时，上方过大的 $d_t$ 被截住；负优势时，过小的 $d_t$ 被截住。另一侧保留梯度，与 PPO 的 min surrogate 方向一致。这个符号变换比直接把所有 $d_t$ 钳到双侧区间更准确，后者会多裁一侧本应保留的更新。

## 9. 梯度推导与共享权重

### 9.1 未裁剪梯度

定义几何 ratio

$$
g_i=\left(\prod_{k=1}^{T_i}\rho_{i,k}\right)^{1/T_i}.
$$

对参数求导：

$$
\nabla_\theta g_i
=g_i\nabla_\theta\left(\frac1{T_i}\sum_k\log\rho_{i,k}\right)
=\frac{g_i}{T_i}\sum_k\nabla_\theta\log\pi_\theta(o_{i,k}\mid q,o_{i,<k}).
$$

于是

$$
\nabla_\theta J_i^{\text{GMPO}}
=\frac{g_i\hat A_i}{T_i}\sum_k\nabla_\theta\log\pi_\theta(o_{i,k}\mid q,o_{i,<k}).
$$

同一回答内所有 token 共享 $g_i\hat A_i/T_i$ 这一标量系数。GRPO 则给第 $k$ 个 token 权重 $\rho_{i,k}\hat A_i/T_i$。GMPO 把位置相关 ratio 换成回答共享的几何 ratio，极端 token 不再单独扩大自己的梯度。

### 9.2 裁剪后的梯度 mask

完整 GMPO 中，每个 $\tilde d_{i,t}$ 对原 $d_{i,t}$ 的导数为零或一。记未被方向性裁剪的位置集合为 $U_i$，则

$$
\nabla_\theta J_i
=\frac{\tilde\rho_{geo,i}\hat A_i}{T_i}
\sum_{t\in U_i}\nabla_\theta\log\pi_\theta(o_{i,t}\mid q,o_{i,<t}).
$$

被裁 token 不贡献直接梯度，未裁 token 共享同一个几何权重。GSPO 的序列级裁剪一旦触发，会让整条回答的梯度归零；GMPO 只移除越过方向边界的位置，其余 token 继续更新。论文把这一点作为 token-level clipping 的主要动机。

### 9.3 一个必须修正的直觉

几何均值并非给每个 token 分配各自压缩后的权重。最终梯度中，未裁位置全部乘同一个 $\tilde\rho_{geo}$。离群 token 的 ratio 通过平均 log-ratio 影响共享尺度；若它本身被裁，其直接 score gradient 被 mask 掉，但裁剪值仍进入几何平均。

因此「多数 token 投票」只是帮助理解共享尺度，无法推出梯度方向必然服从多数。方向由各 token score gradient 的向量和决定。即使权重相同，一个 Jacobian 范数特别大的位置仍可主导参数更新。

## 10. 算术均值、几何均值与离群值

### 10.1 AM-GM 能证明什么

对正数 $x_t=|\rho_t\hat A|$，有

$$
\left(\prod_tx_t\right)^{1/T}
\le\frac1T\sum_tx_t.
$$

这说明同一条回答、同一组 token 数值下，几何聚合的绝对目标不超过绝对值的算术聚合。等号仅在所有 $x_t$ 相等时成立。ratio 越不均匀，两者差距通常越大。

它无法证明 GMPO 的梯度范数总小于 GRPO。GRPO 不同 token 梯度可能抵消，GMPO 改为共享权重后抵消结构也改变。目标值范围较窄提供稳定性的线索，训练稳定仍需梯度范数、KL、熵与外部能力实验支持。

### 10.2 对大离群与小离群的敏感性

长度 $T$ 的序列中，$T-1$ 个 ratio 为一，一个为 $M$，几何均值为 $M^{1/T}$，算术均值为 $(T-1+M)/T$。$M$ 很大时，算术均值近似 $M/T$，几何均值按 $T$ 次根增长。

若离群值为很小的 $m$，几何均值为 $m^{1/T}$，算术均值约为 $(T-1)/T$。几何均值对接近零的值更敏感，会把整条回答共享权重向下拉。方向性 token clipping 给 log-ratio 设置边界，可避免单个极小概率变化把负或正优势序列压得过低。

### 10.3 方差近似

令 $d_t=\log\rho_t$，均值 $\mu$、方差 $\sigma^2$。若位置近似独立，则

$$
\log g=\bar d,qquad
\operatorname{Var}(\bar d)=\frac{\sigma^2}{T}.
$$

token 相关系数近似为 $c$ 时，

$$
\operatorname{Var}(\bar d)
=\frac{\sigma^2}{T}[1+(T-1)c].
$$

局部零均值波动会随长度平均，共同漂移则保留。MoE 路由若只让少数位置尖峰，几何聚合明显受益；若整段 token 同方向变化，平均无法消除。

## 11. Token 裁剪与序列几何聚合

### 11.1 为什么先裁剪再聚合

若先算 $g=\exp(T^{-1}\sum d_t)$ 再裁剪，整条回答共享一个 clip 开关。均值越界时全部 token 梯度归零，均值未越界时局部极端仍保留直接梯度。GMPO 先逐 token 做方向性裁剪，局部极端位置归零，其余位置继续学习。

顺序不可交换。设正优势、两个 log-ratio 为 $(0.8,-0.2)$，边界为 $0.4$。先 token 裁剪得到 $(0.4,-0.2)$，均值 $0.1$，几何 ratio $e^{0.1}$；先平均得到 $0.3$，序列裁剪不触发，ratio 为 $e^{0.3}$。前者同时压低共享尺度并屏蔽第一个 token 的直接梯度。

### 11.2 Log 边界与 ratio 边界

论文采用 $e^{-0.4}$ 到 $e^{0.4}$ 的 ratio 范围，对应对称 log 边界 $[-0.4,0.4]$，数值约为 $[0.670,1.492]$。这比 GRPO 常见 $[0.8,1.2]$ 宽，并且在 log 空间倒数对称。

ratio 空间 $[1-\epsilon,1+\epsilon]$ 在 log 空间不对称。例如 $[0.8,1.2]$ 对应约 $[-0.223,0.182]$。对数对称更符合乘性变化的倒数关系：概率乘 $e^{0.4}$ 与除 $e^{0.4}$ 距离相等。

### 11.3 Clip 更宽为何仍可能稳定

GMPO 先压制 ratio 离群对共享权重的影响，再允许更宽 token 边界，以换取探索空间。更宽 clip 单独用于 GRPO 可能放大单点梯度；与几何聚合结合后，某个大 ratio 对共享尺度仅通过平均 log 值进入。

这不是无条件保证。多个 token 同时接近宽边界时，几何均值也会接近边界；reward 假阳性还可能让整条错误轨迹获得更强更新。论文实验支持特定模型与任务上的稳定性，换数据后仍要扫 clip 范围。

## 12. 长度效应

### 12.1 单离群随长度稀释

一个 token 的 log-ratio 异常为 $a$，其余为零，几何 ratio 为 $e^{a/T}$。长度越长，异常对共享尺度影响越小。$a=\log8$ 时，$T=3$ 得二，$T=100$ 只约为一点零二一。

若异常 token 未被裁，它的直接 score gradient 仍在集合 $U$ 中，且共享系数含 $1/T$；长序列进一步减小单位置显式权重。关键局部动作可能因长度被稀释，必须用 token ratio 极值、位置分桶与行为案例补充监控。

### 12.2 序列等权与 token 等权

GMPO 每条回答产生一个几何 surrogate，再在组和 batch 中平均，典型形式保持回答等权。梯度中的 $1/T$ 让一条回答的 token score 总和按长度平均。DAPO 的 token-level loss 则让长回答按 token 数获得更大 batch 权重。

二者可以组合成「GMPO ratio + token batch 归约」，但这会改变论文目标。长回答的几何 ratio 仍由内部平均 log-ratio决定，最终总权重却随长度增加。组合实验必须与原始序列等权版本并列。

### 12.3 添加零变化尾缀

原回答平均 log-ratio 为 $\bar d$，附加 $K$ 个 $d_t=0$ 的稳定模板后，新均值为 $T\bar d/(T+K)$。几何 ratio 更接近一，裁剪后的异常也被分母稀释。模型可能通过冗余尾缀降低共享权重波动。

长度 reward、EOS 与重复检测负责约束行为；GMPO 自身不区分必要推理和冗余。评估按自然结束、截断、正确长解和重复长解分桶，才能判断长度稳定来自推理改善还是模板稀释。

## 13. Off-policy 与 Policy Lag

### 13.1 几何 ratio 的统计含义

严格轨迹 importance ratio 为

$$
\rho_{seq}=\prod_t\rho_t.
$$

GMPO 使用的未裁几何 ratio 为 $g=\rho_{seq}^{1/T}$。$\rho_{seq}$ 能在支持集覆盖时完成轨迹分布的 importance correction，$T$ 次根后的 $g$ 一般不具备该无偏关系。GMPO 选择更稳定的近端 surrogate，并非严格离策略估计器。

current 与 old 很接近时，$d_t$ 都小，$g\approx1+T^{-1}\sum_td_t$，可作为每 token 平均变化的平滑代理。policy lag 很大时，$g$ 仍可能温和，真实轨迹比已随 $T$ 指数增长。

### 13.2 多 epoch 复用

论文设置中 old policy 生成 rollout 后，current 进行多次更新。epoch 增加时 token ratio 分布逐步展开，方向性 clip mask 增多，几何共享权重也发生变化。后期 epoch 可能主要复用少量未裁 token。

每个 epoch 应记录正负优势的 token clip fraction、回答中未裁 token 比例、几何 ratio 分位和与新鲜 rollout 梯度的余弦。若未裁比例很低，继续复用的计算收益有限；若新鲜梯度方向已经分叉，旧数据会误导更新。

### 13.3 行为分布必须真实

old log-prob 应对应生成时的温度、top-p、top-k、重复惩罚与语法 mask。服务若只保存基础 softmax log-prob，ratio 分母与实际采样分布不一致。误差在 log 空间被整段平均，可能形成稳定偏移。

每条 rollout 绑定 producer checkpoint、解码配置、tokenizer 和服务精度。GMPO 缓解 ratio 离群，无法纠正错误 ratio。实现差异被平均后曲线可能更平，反而更难从 loss 发现。

## 14. 与 GRPO、DAPO、GSPO 的关系

### 14.1 GRPO 提供组优势，GMPO 改聚合

GMPO 保留 GRPO 的 group sampling、reward normalization 和无 critic 结构。它替换同一回答内 token importance-weighted reward 的算术平均，并调整裁剪到 log 空间。全同组、reward 噪声和 prompt 分布问题仍然存在。

当所有 token ratio 相等时，算术均值与几何均值相同，GMPO 退化到 GRPO 的共享 ratio 情形。收益集中在 ratio 不均匀、离群明显的 rollout。监控算术均值与几何均值之比，可以估计可用空间。

### 14.2 DAPO 中可组合的部分

Dynamic sampling 处理全同组，overlong shaping 改变 reward，二者与 GMPO 的 ratio 聚合处于不同层级，可以组合。Clip-higher 与 GMPO 的 wide log clip 都扩大探索范围，但参数化不同；不能同时机械叠加两套数值。

DAPO token-level loss 改变 batch 中长短回答权重，GMPO 原目标为序列等权。组合后应明确分母，并重新评估长度偏好。四项开关同时打开的最终收益无法直接归给几何均值。

### 14.3 GSPO 中不可替代的部分

忽略裁剪时，GMPO 几何 ratio 与 GSPO 长度归一序列 ratio 形式相同。差异集中在裁剪：GSPO 对聚合后的 sequence ratio 一次裁剪，GMPO 对每个 token 方向性裁剪后再聚合。

GMPO 能保留回答中未越界 token 的梯度，GSPO 提供整条回答一致开关。前者更局部，后者更严格地让序列共同进退。两者不能通过换一个 clip 数字互相替代，应以局部异常、整段漂移和有效梯度利用率选择。

## 15. Reward、优势与全同组

### 15.1 优势符号决定裁剪方向

GMPO 的 `sgn(A)` 不只是恢复几何均值的正负，还决定哪一侧 ratio 变化属于过度更新。正优势希望增大 sampled action 概率，过大的正 log-ratio 被截；负优势希望降低概率，过大的负向变化被截。

优势接近零时，几何 ratio 仍可计算，但 surrogate 幅度接近零。实现若通过 `sign(0)` 得零，随后裁剪路径也应保持零梯度。给 $A$ 加微小 epsilon 以避免符号零，会给全同组制造虚假方向。

### 15.2 Reward 噪声的整段影响

假阳性让错误回答获得正优势，未被裁的位置全部沿正向更新，并共享几何 ratio。几何聚合降低单个 ratio 离群的主导，却无法判断 reward 是否正确。宽 clip 还可能让错误轨迹探索得更远。

对同一回答重复运行 verifier，估计标签翻转与分数方差。组内分差低于噪声地板时，标准化会放大随机差异。唯一高分、极端 advantage 与高几何 ratio 的轨迹应优先抽检。

### 15.3 全同组仍无任务梯度

组内 reward 全相等时 $\hat A_i=0$，GMPO 任务项为零。几何聚合不能从空信号中产生方向。Dynamic sampling、可靠过程奖励或更合适难度数据仍然必要。

若总 loss 包含独立 KL，零优势组可能产生 KL 梯度；应分别记录任务项与 KL 项。过滤全同组也会改变 KL 施加的 prompt 分布，这属于组合配方的额外变化。

### 15.4 多目标 reward 的标尺

正确性、格式、长度和工具成本加权成一个标量后，优势符号控制整条回答方向。几何均值不会保留各 reward 分量的 Pareto 结构。长度分压过正确性时，算法会稳定地优化错误目标。

日志保存每个 reward 分量、总分与排序翻转。增加某一分量前后，统计同组 winner 改变比例；高翻转率意味着训练目标已实质变化，不能把后续差异归给 GMPO。

## 16. 手算反例

### 16.1 一个 token 离群

正优势 $A=1$，ratio 为 $(1,1,8)$。无裁剪 GRPO 回答 surrogate 为 $10/3\approx3.333$，GMPO 为二。两者梯度权重分别是 $(1/3,1/3,8/3)$ 与 $(2/3,2/3,2/3)$。GMPO 把第三个 token 的独立大权重改成共享尺度。

若 log clip 上界为 $0.4$，第三个 ratio 从八裁到 $e^{0.4}\approx1.492$，几何 ratio 为 $1.492^{1/3}\approx1.143$。第三个 token 直接梯度归零，前两个 token 各获约 $1.143/3$ 的系数。裁剪与几何聚合同时发挥作用。

### 16.2 一个 token 接近零

ratio 为 $(1,1,10^{-6})$，无裁几何均值为 $0.01$，整条回答的共享梯度缩小百倍。对正优势而言，概率大幅下降并不属于「沿奖励方向过度增加」，标准 PPO min 目标通常仍希望把它拉回，因此下侧可能不裁。

这说明几何均值会让一个极小 ratio 压低其他 token 的共享尺度。论文的方向性 log clip 具体如何处理该侧必须按公式实现，不能简单双侧 clamp。辅助下限若用于数值稳定，也会改变目标，需要单独记录。

### 16.3 正负抵消的 ratio

ratio 为 $(2,0.5)$ 时几何均值为一，算术均值为一点二五。GMPO 共享权重接近 old/current 平均无变化，GRPO 更强调 ratio 为二的位置。真实轨迹 ratio 的乘积也为一，但两个动作概率已经大幅重排。

若第一个 token 决定推理分支，第二个只是标点，几何抵消会隐藏语义重要性。token 极值、关键动作 KL 与新鲜 rollout 用于揭示这种局部变化。

### 16.4 序列裁剪与 token 裁剪

正优势，log-ratio 为 $(0.8,-0.2,0,0)$，边界为零点四。GMPO 裁第一项后均值为零点零五，几何 ratio 约一点零五一，第一项无直接梯度，后三项保留。GSPO 先平均得到零点一五，若序列边界为零点四则整条保留，包括局部大变化。

另一例 $(0.5,0.5,0.5,0.5)$：GMPO 四项全部裁掉直接梯度，GSPO 平均为零点五后整条裁掉，二者都归零。局部尖峰与集体漂移的区别决定两种裁剪是否产生不同结果。

## 17. 数值实现与分布式归约

### 17.1 Log 空间的正确顺序

先计算 float32 的 new 与 old log-prob 差，按优势符号变换并做方向性裁剪，再恢复符号、mask 求和、除有效 token 数、指数化。直接相乘 clipped reward 会在长序列上下溢。

`exp(mean(clipped_log_ratio))` 与 `mean(exp(clipped_log_ratio))` 分别是几何与算术均值，代码只差运算顺序，含义完全不同。合成张量测试应给出解析结果，避免重构时误换。

### 17.2 Mask 与结束动作

分母只计模型实际生成的 action token。prompt、padding、工具返回和环境观察不进入 ratio 聚合。EOS 属于 sampled action，应在自然终止时计入；max-length 截断没有 EOS，需保留删失状态。

mask 错位会让 padding 的零值稀释 log-ratio，或让工具观察稀释模型动作。构造不规则 padding、空工具返回、多轮 action 的测试，逐 token 循环与向量化结果必须一致。

### 17.3 Sequence parallel

同一回答分到多张卡时，各卡返回裁剪后 log-ratio 和与有效计数，最终计算

$$
\bar d=\frac{\sum_kD_k}{\sum_kT_k}.
$$

先算各卡均值再等权平均会给短分片过高权重。用二比八、三比七等不等长切分验证单卡与多卡一致；空分片不能贡献分母。

### 17.4 Log-prob 版本一致

rollout 与 trainer 的 tokenizer、模板、位置、温度、top-p、量化和 MoE 路由都可能改变 old log-prob。保存 token ids、producer checkpoint、解码参数和服务精度。只保存文本后重新编码无法保证同一行为序列。

GMPO 曲线稳定时，系统性 log-prob 偏差也可能被平均得很平。固定轨迹上比较生成服务保存值与 trainer 重算值，先建立实现误差基线，再解释 policy 更新。

## 18. 统计与可证伪实验

### 18.1 聚合差异指标

对每条回答计算算术 ratio 均值 $a_i$、几何 ratio $g_i$ 与差值

$$
\Delta_i=\log a_i-\log g_i\ge0.
$$

$\Delta_i$ 衡量 ratio 不均匀程度。若训练数据中它长期接近零，GMPO 与 GRPO 的聚合差异有限；若尾部很大，几何压缩具有明确作用空间。按长度、reward、任务和 MoE 专家分桶更有解释力。

### 18.2 梯度方向实验

在同一 batch、同一参数点分别计算 GRPO 与 GMPO 梯度，报告范数、余弦、分层参数差异和单序列贡献。若差异集中在高 $\Delta$ 轨迹，符合机制；若均匀出现，可能是归约、mask 或 clip 实现不一致。

再移除 ratio 离群轨迹重复计算。两方法差异若显著缩小，支持离群解释；若外部能力收益仍来自普通轨迹，需要寻找其他机制。

### 18.3 长度与方差实验

将回答按长度分桶，报告 $\operatorname{Var}(d_t)$、$\operatorname{Var}(\bar d)$、$\Delta$、clip fraction、梯度范数和正确率。独立波动假说预测平均 log-ratio 方差随长度下降；相关路由漂移会让下降变慢。

复制同一 log-ratio 序列后，几何均值应不变；添加零变化尾缀后应向一收缩。这两个合成实验分别验证重复制不变性与分母稀释，帮助解释真实长度曲线。

### 18.4 Off-policy 实验

按 producer lag 或 PPO epoch 分桶，测几何 ratio、token 极值、未裁比例和与新鲜 rollout 梯度余弦。GMPO 若在 lag 增大后仍保持平稳 loss，却与新鲜梯度分叉，说明聚合掩盖数据陈旧。

固定 token 预算比较单 epoch 新鲜采样与多 epoch 复用。外部能力、采样成本和训练成本一起报告，避免只从优化吞吐判断优劣。

## 19. 失效边界与验收

### 19.1 局部关键动作

长回答中少数动作决定工具权限、证明分支或安全边界，几何均值会按 $1/T$ 稀释其 ratio。主目标可保留 GMPO，同时独立监控关键状态 token KL、执行成功率与局部极值。

局部约束若加入 loss，会形成混合目标，需要消融。监控不改变优化，适合先判断问题是否真实存在。关键动作行为回退时，稳定的回答级曲线不能作为通过依据。

### 19.2 Reward 攻击

错误长轨迹若骗过 verifier 获得高 advantage，GMPO 会给所有未裁 token 一致正向系数。几何压缩只能限制 ratio 离群，无法限制错误 reward 的覆盖范围。独立验证器、对抗样本与人工抽检仍然必要。

若 GMPO 相比 GRPO 更稳定地提高训练分、独立指标却停滞，可能只是更稳定地拟合 verifier。稳定性与正确目标必须同时成立。

### 19.3 训练停止与回滚

预先设置固定 reference KL、关键能力回退、reward 翻转率、局部 ratio 极值、梯度范数与有效 token 比例边界。越界时保存 producer、current、optimizer、verifier 和数据版本。

回滚不能只恢复模型；optimizer 二阶矩可能被异常梯度污染。最终 checkpoint 由外部能力、风险、长度和成本共同选择，训练 reward 峰值仅是其中一项。

### 19.4 最终判据

GMPO 的机制假说要求高离群轨迹的共享权重更稳、梯度尖峰减少、KL 与熵曲线改善，同时外部推理能力至少不退化。若只有目标数值范围变窄，结论限于聚合统计。

可迁移性要求换基础模型、长度和任务后，收益仍与 $\Delta$、token ratio 尾部和梯度方向变化对应。指标不对应时，不能把结果自动归因于几何均值。

**完整裁剪偏导。** 令 $d_t=\log\rho_t$。正优势时保留 $d_t\le\epsilon$ 的直接梯度，并把 $d_t>\epsilon$ 替换为常数 $\epsilon$；负优势时保留 $d_t\ge-\epsilon$，把更小的值替换为 $-\epsilon$。记方向性有效 mask 为

$$
m_t(A)=
\begin{cases}
\mathbf 1[d_t\le\epsilon],&A>0,\\
\mathbf 1[d_t\ge-\epsilon],&A<0.
\end{cases}
$$

单条回答的梯度可写成

$$
\nabla J_i=\frac{A_i\tilde g_i}{T_i}
\sum_tm_t(A_i)\nabla\log\pi_\theta(o_{i,t}\mid q,o_{i,<t}).
$$

$m_t$ 屏蔽越界 token 的直接梯度，$\tilde g_i$ 用所有裁剪后 log-ratio 的平均调节其余 token 的共享尺度。被屏蔽 token 仍以边界常数参与 $\tilde g_i$，因此会间接影响整条回答权重。

实现中不能把被裁 token 从平均分母删除。论文目标仍以完整有效长度 $T_i$ 求均值；裁剪把数值换成边界，并未把位置移出序列。删除后，越界越多，分母越小，几何 ratio 的含义随 clip fraction 改变。padding mask 与 clip mask承担不同职责。

**归一因子控制两种尺度。** 几何均值中的 $1/T$ 同时控制 ratio 的长度尺度与每 token 显式梯度。去掉归一因子后目标变成 ratio 乘积，长度增长产生指数尺度；改成 $1/\sqrt T$ 时，长序列仍比短序列更容易极端。

长度三与长度三千的回答若每 token 平均 $d_t$ 相同，$\tilde g$ 相同，真实轨迹 ratio 却分别为 $\tilde g^3$ 与 $\tilde g^{3000}$。GMPO 选择「平均每步变化」作为近端尺度，提高了长度间可比性，同时放弃严格轨迹密度修正。

DAPO 式 token batch 平均无法抵消内部 $1/T$。前者改变回答在 batch 中的权重，后者改变回答内部概率变化尺度。混合配方必须分别写出两处分母。

**优势幅度仍线性进入。** 因为 $|A|$ 在序列内重复 $T$ 次后开 $T$ 次方，结果仍为 $|A|$，最终乘符号得到 $A$。几何均值只压缩 token ratio 的聚合，不压缩跨回答 advantage 离群。某条 reward 异常导致 $|A|$ 很大时，梯度仍可被它主导。

组内标准化限制典型 advantage 尺度，但小组、重尾 reward 与极小标准差仍会产生异常。报告 $|A|$ 分位、组标准差和 $|A\tilde g|$ 分位，才能区分 ratio 离群与 reward 离群。前者由 GMPO 处理，后者需要 reward 校准或稳健优势估计。

**算术与几何差距的二阶展开。** 写成 $\rho_t=\bar\rho(1+u_t)$，其中 $\sum_tu_t=0$ 且 $u_t$ 较小，则

$$
\log g=\log\bar\rho+\frac1T\sum_t\log(1+u_t)
\approx\log\bar\rho-\frac1{2T}\sum_tu_t^2,
$$

从而

$$
g\approx\bar\rho\exp\left(-\frac12\operatorname{Var}(u)\right).
$$

ratio 相对方差越大，几何权重相对算术均值越小。GMPO 的压缩强度近似由序列内离散程度决定。重尾情形下二阶近似不够准确，直接使用 $\Delta=\log a-\log g$ 更可靠。

当 ratio 全体一致时 $u_t=0$，两种聚合没有差别。GMPO 处理序列内部不均匀，无法替代对整条回答共同漂移的约束。所有 ratio 都为一点四时，几何均值仍为一点四。

**梯度方向差异来自协方差。** 设 score gradients 为 $v_t=\nabla\log\pi_t$。GRPO 梯度与 $\sum_t\rho_tv_t$ 成正比，GMPO 与 $g\sum_tv_t$ 成正比。算术项可分解为

$$
\frac1T\sum_t\rho_tv_t
=\bar\rho\bar v+\operatorname{Cov}_t(\rho,v).
$$

GMPO 去掉 token-specific covariance 权重。若 covariance 主要来自路由或数值噪声，删除有益；若高 ratio 集中在真正关键 token，该项含有有效信用信息。真实 batch 中按 $\Delta$ 分桶比较两种梯度余弦，可以看到算法实际舍弃了什么。

裁剪后方向由 $\sum_{t\in U}v_t$ 决定。若被裁位置恰好拥有异常大 Jacobian，稳定性明显改善；若它是唯一正确决策，剩余 token 可能带来错误方向。被裁 token 的位置、语义类型和 score-gradient 范数比单一 clip fraction 更有解释力。

**长度与离群概率同时变化。** 假设每个 token 独立以概率 $p$ 成为离群，一条长度 $T$ 的回答至少含一个离群的概率为 $1-(1-p)^T$。长回答更容易遇到离群，但单个离群对平均 log-ratio 的贡献又按 $1/T$ 稀释。

两种效应造成独特统计：clip mask 中越界数量随长度增加，共享几何权重却可能更集中。若离群成簇出现，例如 MoE 路由变化影响连续片段，独立近似会低估尾部风险。日志记录离群数量、最长连续段和位置分布。

定义回答直接梯度利用率

$$
u_i=\frac{|U_i|}{T_i}.
$$

$u_i$ 接近一表示大部分 token 保留，接近零表示回答几乎进入平坦区。再定义 advantage 加权利用率

$$
U_A=\frac{\sum_i|A_i|u_i}{\sum_i|A_i|}.
$$

若高 advantage 样本集中被裁，普通 token clip fraction 看似不高，$U_A$ 仍会显著下降。

**更宽 clip 需要统一坐标。** GRPO 常见 ratio 边界 $[0.8,1.2]$，GMPO 论文使用 log 对称边界，对应约 $[0.67,1.49]$。前者在 log 空间约为 $[-0.223,0.182]$，后者为 $[-0.4,0.4]$。比较宽度时还要按优势符号看有效侧。

DAPO 的 $[0.8,1.28]$ 主要放宽正侧，GMPO 上下两侧都更宽。组合时直接写出正负 log 边界，避免 `eps_low` 与 `eps_high` 在不同实现中含义错位。沿用同一个数值名称并不代表同一种约束。

**GSPO 公平对照。** 未裁状态下，两者核心标量均为 $g=\exp(T^{-1}\sum d_t)$。公平实验保持 advantage、序列归约与边界坐标一致，只改变逐 token 方向裁剪和聚合后序列裁剪，才能把差异归到裁剪粒度。

最小四格比较 token clip、sequence clip 与窄、宽边界。每格报告回答完全归零比例、token 利用率、局部极值和外部能力。若同时更换 batch 归约或 KL，实验会混入新的长度与正则效应。

**DAPO 组合拆成独立轴。** Dynamic sampling 改样本选择，token-level loss 改长度权重，overlong shaping 改 reward，clip-higher 改 ratio 边界。GMPO 直接替换聚合和裁剪表示。逐轴添加才能回答哪些部分互补。

Dynamic sampling 会过滤全同组，提高非零 advantage 密度；GMPO 在保留组内压制 ratio 离群。过滤后的难度与长度分布可能改变 ratio 尾部，组合收益无法由单项收益直接相加。

**第一次 on-policy 梯度应一致。** current 等于 old 时所有 $\rho_t=1$，算术与几何聚合均为一，clip 不触发，GMPO 与 GRPO 的首次梯度应接近一致。若共同 checkpoint、同一 batch 的第一步就明显不同，检查优势、mask、归约或 KL。

差异从参数更新后继续复用同一批数据、或 producer lag 出现时产生。严格每一步重采并同步 old 会让 ratio 总在一附近，GMPO 对离群的重要性降低。论文式 PPO 更新通常在一个 rollout batch 上执行多次更新，因此能观察到差异。

**Policy lag 需要三个量。** checkpoint 版本差表示优化步数，wall-clock 年龄表示排队，平均 log-ratio 与 token 极值表示真实策略距离。学习率小时版本差大但距离小，一次异常更新后版本差一也可能距离大。

按三类量联合分桶可区分异步滞后与优化跳变。GMPO 若真正减少跳变，token 极值、梯度范数和外部故障率应一起改善；若只是平均掩盖，局部极值仍随 lag 扩大。

**固定评估与训练分布分开。** 课程和模型能力会改变训练 prompt 组成，训练 reward 上升可能来自样本更换。固定 benchmark 用于观察泛化，保持解码温度、样本数和判题器一致。Pass@1 给出多种子或足够采样的置信区间，各 benchmark 单项也应保留。

论文在数学推理、多模态几何和附录 MoE 设置中报告收益，并观察到更稳的梯度范数、较低 KL 或较高熵。这些证据支持相应实验配置，不自动覆盖所有 reward、规模与工具环境。复现应先看 ratio 范围、梯度尖峰和 KL/熵是否沿机制变化。

**完整四回答手算。** 一个组 reward 为 $(1,1,0,0)$，未标准化中心优势为 $(0.5,0.5,-0.5,-0.5)$。四条回答均长二，ratio 分别为 $(4,1)$、$(2,2)$、$(0.25,1)$、$(0.5,0.5)$。

无裁几何 ratio 为 $(2,2,0.5,0.5)$，GMPO surrogate 为 $(1,1,-0.25,-0.25)$，组平均为零点三七五。GRPO 算术 ratio 均值为 $(2.5,2,0.625,0.5)$，surrogate 为 $(1.25,1,-0.3125,-0.25)$，组平均约零点四二二。差异集中在第一与第三条内部不均匀的回答。

若 log 边界为 $\pm0.4$，第一条正优势的 ratio 四被上裁，第二条两个 ratio 二也被上裁；第三条负优势的 ratio 零点二五被下裁，第四条两个零点五也低于 $e^{-0.4}$。四条直接梯度都可能大幅减少。要纯粹比较聚合，应另建所有 ratio 位于边界内的例子。

**Verifier 与长度的联合反例。** 正确长回答任务分一、长度扣零点六，总分零点四；错误短回答任务分零、无长度罚，正确回答仍为 winner。若长度扣一点二，排序翻转，GMPO 会稳定强化错误短答。

这里 ratio 聚合再稳也无效。每个 reward 分量都要检查排序翻转，确保长度、安全或格式项没有压过核心正确性。Dynamic sampling 若依据总 reward，还会把原本任务全同的组变成长度有效组。

**数值下限与语义 clip 分离。** 防止 `log(0)` 的概率下限、避免非有限值的数值保护、PPO 语义 clip 处在不同位置。数值阈值若接近 $\pm\epsilon$，就会实质改变训练目标。

log-softmax、差值、裁剪后求和应使用 float32。current=old 的长序列应得到均值接近零，误差不随长度单调积累。交换 new 与 old 后，无裁几何 ratio 的乘积应接近一。

**重复与模板形成相关结构。** 长回答尾部重复相同短句时，$d_t$ 高度相关，独立方差缩减不再成立。若模板在 old 与 current 中概率都高，ratio 接近一，GMPO 不会惩罚模板质量。重复率、自然 EOS 和长度仍需 reward 与行为监控。

**Global gradient clip 位于下游。** GMPO token clip 约束 importance surrogate，global clip 限制所有样本聚合后的参数梯度。异常 advantage、巨大 Jacobian 或多任务同向叠加仍可触发后者。

同时报告 token clip、回答共享权重和 global clip 触发率。若 ratio 尾部改善而 global clip 不变，根因更可能位于 reward 或模型 Jacobian，继续调整几何均值无法解决。

**最终实验矩阵。** 第一轴为算术或几何聚合，第二轴为 token 或 sequence clip，第三轴为窄或宽边界，第四轴为序列等权或 token 等权。预算有限时，优先保留能分离聚合与裁剪的四格，以及几何聚合下两种归约。

所有运行固定 base/SFT checkpoint、prompt 流、group size、reward、rollout token、producer lag 和优化器。结果同时报告生成与更新 token、wall-clock、梯度故障、固定 benchmark 与长度成本。稳定性若依赖更多预算，应明确列出。

**可证伪承诺。** 几何聚合承诺高 $\Delta$ 回答不再由单个 ratio 独占梯度；token clip 承诺越界位置归零而同序列其他位置保留；宽边界承诺在几何稳定基础上增加有效探索；长度归一承诺相同每 token 平均漂移在不同长度上获得可比权重。

失败条件也对应清楚：高 $\Delta$ 桶梯度仍频繁爆炸，token clip 后整条梯度归零，宽边界只增加 reward hacking，或长短桶有效率严重失衡。出现哪一条，就回到对应机制定位。

**最终记录格式。** 每条回答保存 reward 分量、advantage、长度、token log-ratio 分位与极值、算术均值、几何均值、$\Delta$、裁剪数量、$\tilde g$ 和梯度范数。每组保存全同状态和 winner；每步保存 policy lag、KL、熵、global clip 与成本。

从每次运行抽取高 $\Delta$、高 advantage、高 clip、长序列和局部关键动作五类案例人工复算。数学指标解释权重，案例解释行为，固定 benchmark 解释泛化。三类证据一致时，GMPO 的稳定收益才具有完整机制链。

**论文算法与运算的对应。** `sgn_A * (new_logp - old_logp)` 将正负优势统一成「沿优化方向的 log 概率变化」；`clamp` 与 `min` 形成 PPO 式单侧平台；乘回 `sgn_A` 后恢复原 log-ratio 方向；有效 token 的均值经过指数化得到裁剪后的几何 ratio。loss 为 `-A * ratio`。

这里没有对每个 token 分别形成 loss 再平均。所有 token 先贡献到一个平均 log-ratio，指数化后与序列 advantage 相乘。描述实现时应说「token 级裁剪、回答级几何聚合」，两种粒度同时存在。

若代码先计算每个 token 的 `exp(clipped_d) * A`，然后取几何均值，在数学上与先平均 clipped log-ratio 再指数化等价；若取算术均值则回到另一目标。优势绝对值在 log 空间处理时还要避免 $A=0$ 的 `log(0)`，更简洁的实现是将 $A$ 留在指数外。

**方向性裁剪的四象限。** 正优势、$d>epsilon$ 时概率已经增加过多，直接梯度归零；正优势、$d<-epsilon$ 时 sampled 动作概率大降，仍保留拉回梯度。负优势、$d<-epsilon$ 时概率已经降低过多，梯度归零；负优势、$d>epsilon$ 时错误动作概率反而升高，仍保留抑制梯度。

四象限测试比只检查 `clamp` 输出更重要。简单双侧 clamp 会让正优势的过低 ratio 和负优势的过高 ratio 也进入常数区，恰好屏蔽最需要纠正的方向。损失仍可下降，bug 却会显著降低恢复能力。

边界点不可导，自动微分会选择实现定义的次梯度。单元测试不要只取恰好 $\pm\epsilon$，应在边界两侧各放一个小扰动，检查平台与非平台区域。多精度训练下边界舍入也可能改变少量 token mask，属于可接受数值差异，但触发比例不应系统偏向一侧。

**几何均值与调和均值的区别。** 三种常见均值满足调和均值不大于几何均值、不大于算术均值。调和均值对小 ratio 更敏感，会让一个接近零的 token 强烈压低整条回答；算术均值对大 ratio 更敏感；几何均值在 log 空间对乘性变化对称。

选择几何均值对应「概率比是乘性量」这一结构。它并非所有稳健统计中的唯一答案。中位数会完全忽略幅度排序之外的信息，截尾均值需要人为比例，幂均值可连续调节敏感性。论文证据针对几何均值，其他聚合需单独证明与实验。

**对数对称带来的尺度直觉。** ratio 二与零点五在 log 空间分别为 $+\log2$ 与 $-\log2$，距离相等；算术空间到一的差分别为一与负零点五。GMPO 聚合 log-ratio，更自然地表达概率翻倍和减半的对称性。

但训练方向仍由 advantage 符号控制。正优势序列中二与零点五可以在几何均值里抵消为一，却代表两个 token 朝相反方向移动。对数对称处理尺度，不解决语义信用分配。

**目标值变窄与方差降低之间还有条件。** AM-GM 给出单样本绝对目标的上界关系，不直接给随机变量方差排序。一个分布的取值范围更窄通常有助于控制方差，但均值、相关性和梯度 Jacobian 都会影响最终训练方差。

最直接证据来自同一 batch 的 per-sample surrogate 方差、per-sample gradient norm 和聚合梯度跨 minibatch 波动。若目标方差降低而梯度方差不降，可能是 score gradient 与几何权重相关，或少数 Jacobian 仍主导。

论文报告更稳的 gradient norm、KL 或 entropy 曲线，为稳定性提供经验支持。复现应使用未平滑原始曲线和尾部分位；过度平滑会隐藏瞬时尖峰，而训练崩溃往往由尾部事件触发。

**MoE 中的两类离群。** 第一类来自某个 token 路由跨过专家边界，形成孤立 ratio 尖峰；第二类来自一段 token 共同改变专家组合，形成连续同向偏移。GMPO 对第一类的几何稀释与 token clip更有效，对第二类只能依靠方向性边界限制每个位置。

记录 router logits、选中专家和负载均衡指标，可以把 ratio 尖峰与路由变化关联。若 Dense 模型也出现同类尖峰，来源可能是 attention 状态、量化或数据陈旧。算法不依赖 MoE，但故障解释随架构变化。

**专家共享使局部梯度仍可外溢。** 某个被裁 token 自身没有直接 score gradient，却参与同序列共享几何权重，并且其他 token 可能路由到相同专家。参数共享让「裁掉一个位置」不等于该位置行为完全冻结。下一次更新后其概率仍可能因其他 token 梯度改变。

因此 token clip mask 描述当前样本的直接贡献，不能当作逐位置硬约束。若必须限制关键行为，需要固定状态 KL 或独立安全损失。GMPO 的裁剪属于优化稳定器，不提供行为不变保证。

**组大小影响优势而非几何 ratio。** $G$ 增大时组均值和标准差估计更稳定，也更容易出现 reward 尾部。几何 ratio 只看单条回答内部 token，但最终权重 $A_i\tilde g_i$ 受组组成影响。

同一回答放入不同候选组可能得到不同 advantage 符号，进而改变裁剪方向。正优势组里上侧被裁，换到更强候选组后它可能成为负优势，转而裁下侧。复现实验必须固定 group construction，不能缓存脱离组上下文的 clipped ratio。

候选相关性还会降低组统计有效样本量。相同前缀、相近随机种子或搜索分叉产生的回答 reward 高度相关，大 $G$ 未必带来等比例新信息。报告答案簇与有效组多样性。

**全同组处理的数值细节。** reward 标准差为零时直接除法产生 NaN。常见实现加 epsilon 得到零 advantage；若浮点 reward 存在极小差异，结果可能被 epsilon 比例放大。语义相等的二元 reward 应先离散判断全同，再决定过滤或零更新。

连续 reward model 可通过重复评分噪声设阈值。组内范围低于阈值时，标记为无可靠差异。否则几何聚合会稳定传播由测量噪声制造的优势。

**KL 项的位置。** 论文为简化与节省内存忽略显式 KL 项，但训练仍报告相对参考模型的 KL 变化。若实现加入 KL，可以作为 token reward 分量进入几何聚合，也可作为独立加性正则；两者目标不同。

把可能为负的 KL shaping 与任务 advantage 合在 token reward 中，会改变几何均值符号结构，尤其当序列内每 token 总 reward 符号不同。GMPO 原式依赖同一序列共享 advantage 符号。更稳妥的扩展通常保留任务几何 surrogate，再单独加 KL 正则，并明确其归约。

独立 KL 会让全同组也产生梯度，也改变 GMPO 与 GRPO 第一步梯度一致性。单元测试关闭 KL 验证核心目标，再开启 KL 验证其解析方向。

**序列内 reward 若不共享，原化简失效。** GMPO 论文使用序列级 advantage，在 token 间相同，才能把 $|A|$ 从几何乘积提出。若过程 reward 给每个 token 不同 $A_t$，目标变为

$$
\left(\prod_t|\rho_tA_t|\right)^{1/T}
\operatorname{sgn}(\cdot),
$$

而多个 $A_t$ 可能异号，单一符号恢复不再明确。直接套用论文公式会丢掉局部方向。

过程 reward 场景可以先构造每步 reward-to-go 并按片段分组，使片段内符号一致；也可保留 token 级算术目标。GMPO 的即插即用范围限于共享序列 advantage 的 GRPO 类目标。

**多轮工具轨迹同样需要定义聚合单位。** 若整场交互只有终局 reward，可以把所有模型 action token 合成一条轨迹做几何聚合；工具观察不进入 mask。若每轮有独立 verifier，按轮聚合更贴近 reward 单位。

跨轮合并会让长工具观察后的模型动作与早期决策共享权重，局部信用粗糙。按轮拆分则需要轮级 advantage，且同一轨迹多个片段相关。选择应由 reward 语义决定，不能只按张量布局。

**截断轨迹属于删失样本。** max-length 停止时没有 EOS，终局正确性可能尚未可见。将其统一判错会让长推理获负 advantage，GMPO 再稳定也只是强化早停。应报告自然 EOS、stop string、工具终止与上限截断。

提高最大长度对一小批截断轨迹复测，估计潜在完成率。若大多很快正确结束，长度上限过紧；若继续循环，负 reward 更合理。GMPO 不解决系统截断与能力失败的混淆。

**算术/几何差距可定位训练阶段。** 初始 current=old 时 $a=g=1$，$\Delta=0$。随着同批数据复用，ratio 离散度上升，$\Delta$ 增大。下一批新鲜 rollout 又回到接近零。按 PPO epoch 画 $\Delta$ 可直接观察 GMPO 在第几次复用开始区别于 GRPO。

第一 epoch 的 $\Delta$ 很大时，producer lag、服务/trainer log-prob 差异或学习率异常更可疑。整个训练期间 $\Delta$ 都接近零时，几何聚合与算术聚合差异有限，性能变化更可能来自 clip 参数或其他实现。

**梯度累积的分母。** GMPO 每条回答产生一个 surrogate，跨 micro-batch 按回答数加权。样本更少的末尾 micro-batch 若与其他 micro-batch 等权，会获得过高贡献；分布式 worker 回答数不等时同样使用全局计数。

若采用 token-level batch 归约，则分母改为有效 token 总数；这已离开论文默认序列等权。日志明确 sequence count 与 token count，拆分合并后的梯度应与整批一次计算一致。

**样本选择可能与 ratio 离群相关。** 过滤格式错误、超长或环境失败会改变训练数据。若这些轨迹恰好有大 ratio 尾部，过滤本身就能降低梯度波动，容易误归因于 GMPO。对被过滤集合也统计 $\Delta$ 与极值。

Dynamic sampling 根据 reward 方差保留组，可能偏向 ratio 更不稳定的中等难度题，也可能排除全错长尾。组合实验记录采样前后 ratio 分布，区分数据选择与聚合效果。

**独立样本单位是 prompt。** 同一回答 token 共享 advantage 与几何 ratio，同一 prompt 多回答共享组统计。用 token 数计算置信区间会严重低估不确定性。固定评估按 prompt bootstrap，多次训练再纳入随机种子差异。

梯度尖峰和崩溃属于稀有事件，需要长运行或多个种子。报告单位 rollout token 的故障率、最大连续无故障区间和恢复成本。一次未崩溃只能说明该次运行成功。

**参考实现与论文公式交叉检查。** 代码仓库用于确认实际 mask、epsilon 和 reduction，论文公式用于确认算法含义。若版本不同，以明确 commit 与论文版本配对。arXiv v3 相对早期版本可能修改实验或表述，引用年份与版本应保持可追踪。

**一个端到端验收批次。** 构造四组：正常 ratio、单大离群、单小离群、全体同向漂移。每组包含正负 advantage 与两种长度。手算 $d_t$、方向 clip、$\tilde g$、有效 mask、surrogate 和梯度系数，再与实现逐项比对。

加入 padding、EOS、max-length 与一个全同 reward 组。padding 不影响分母，EOS 进入自然结束序列，截断无 EOS，全同组任务梯度为零。跨两张卡不等长切分后结果保持一致。

小模型机制实验从共同初始 batch 启动。第一步 GMPO/GRPO 梯度一致，第二次复用开始出现差异；高 $\Delta$ 轨迹中 GMPO 梯度较少受单 ratio 主导。解析结果、自动微分与采样统计应在各自误差范围内吻合。

**采用 GMPO 的条件。** ratio 尾部明显、序列内不均匀度高、共享序列 advantage 合理、训练依赖有限次数据复用时，几何聚合直接针对主要故障。ratio 本来平滑、过程 reward 需要局部异号信用、或数据高度离策略时，收益有限并可能掩盖问题。

决定采用前先测 $\Delta$、token 极值、梯度方向差与 policy lag。它们能回答「离群是否存在」「离群是否改变方向」「数据是否仍近端」。三个问题都有证据后，再用固定预算训练验证外部能力。

**最终边界。** GMPO 将序列内各 token 的个体 ratio 权重改成裁剪后几何共享权重，降低孤立离群控制梯度的能力。它保留 GRPO 的 group advantage，也继承 reward、全同组和信用分配局限；它能与 DAPO 的采样和 reward 机制组合，却不能替代那些机制；它与 GSPO 共享未裁几何 ratio，却采用不同裁剪开关。

这组边界说清后，训练曲线更平只是一项证据。ratio 尾部、梯度方向、外部能力、长度、KL、熵与案例共同符合预测，才足以说明几何均值在当前任务上发挥了作用。

**KL 与熵要按同一批状态比较。** current 相对固定 reference 的 KL 衡量累计漂移，token entropy 衡量当前分布的不确定性。模型生成的状态分布也随训练变化，直接在各自 rollout 上计算会混入「访问了不同状态」的影响。固定一批 prompt 与前缀重算分布，才能更干净地比较策略本身。

采样 KL 只观察 chosen token，完整词表 KL 成本更高却信息更全。至少注明估计方向、采样来源和归约方式。序列 KL 求和随长度增长，token 平均 KL 更适合比较局部漂移；两者同时报告可以避免把输出变短误解为策略更接近 reference。

更高 entropy 也不必然代表更好的推理探索。熵可能来自措辞、标点或错误分支。将答案按语义、执行轨迹或最终结果聚类，报告簇熵与成功簇覆盖率。GMPO 若维持 token 熵却没有增加有效答案模式，探索收益有限。

**梯度稳定的尾部指标。** 平均 gradient norm 会被平滑，真正导致崩溃的是高分位与连续异常。报告中位数、九十五与九十九分位、最大值、global clip 触发率和 non-finite 次数。按参数模块拆分可看到异常集中在 router、embedding、attention 还是输出层。

同一 batch 的 per-sample gradient 代价较高，可以对小子集周期性计算。更便宜的代理包括 $|A\tilde g|$、未裁 token 比例与 score-gradient 范数抽样。代理与真实梯度尾部需要先在小规模实验中建立相关性。

一次极端梯度会抬高 Adam 二阶矩，使后续有效学习率长期降低。比较 GMPO 与 GRPO 时记录 optimizer 二阶矩与更新范数。即使后续 raw gradient 已恢复，历史状态仍可能解释能力曲线分叉。

**量化 rollout 的额外偏差。** 生成服务可能使用低精度或量化权重，trainer 使用高精度 current。名义 checkpoint 一致，token 概率仍不同。old log-prob 最可靠来源是实际 producer；用高精度模型重算属于近似。

在固定提示上比较量化与高精度的 token log-prob 差、路由选择和答案频率，建立系统误差基线。若该误差本身呈重尾，GMPO 可能看似特别有效，实际是在缓解服务与训练实现不一致。算法收益与系统误差修复应分开报告。

推测解码在接受规则严格保持目标分布时不改变行为策略，自定义近似接受或缓存截断可能改变分布。任何吞吐优化上线后，都应重新验证 old log-prob 与采样频率的校准。

**采样支持集限制。** top-k、top-p 与语法 mask 会把部分动作概率设为零。importance ratio 无法从 old 数据学习从未采到的动作，几何均值也无法恢复支持集外信息。扩大 clip 只允许已采动作移动更远，不等于扩大 sampler 支持集。

提高温度或 top-p 能增加候选多样性，也改变行为分布与 ratio 尾部。探索对照应分别扫描 sampler 与 clip，避免把采样支持扩大带来的收益归给 GMPO wide clip。

同组候选使用不同温度时，reward 差异与 sampler 配置绑定。更清楚的设计让同组共享配置，跨组比较不同温度；若必须混合，每条轨迹保存实际行为 log-prob，并按配置分桶评估。

**正确率之外的代价。** GMPO 可能维持更高熵，生成长度与多样性也可能变化。固定 Pass@1 提升若伴随显著更多 token，部署收益取决于成本约束。正确、错误和截断回答分别报告长度与延迟，避免均值受成功率组成影响。

训练成本包括额外 rollout、verifier、更新 token 与通信。几何均值本身计算开销很小，但更宽 clip 可能改变收敛步数。固定优化步与固定 token 预算回答不同问题，两种口径都应呈现。

**跨模型迁移的预检。** 在完整长训前，用若干真实 batch 计算 $\Delta$、token ratio 尾部、优势分布和 GMPO/GRPO 梯度余弦。如果 $\Delta$ 极小且余弦接近一，当前模型几乎没有聚合问题；如果尾部大但来自 log-prob 错位，先修实现。

MoE、Dense、视觉语言模型的 ratio 结构可能不同。论文在多种设置上给出经验结果，具体收益仍应由预检与小规模对照确认。模型越长、路由越敏感，局部离群出现机会通常越多，但相关性也更强。

**Checkpoint 选择的联合条件。** 外部能力上升、KL 可接受、熵未骤降、梯度尾部稳定、局部关键行为不退化，才构成候选 checkpoint。某一指标峰值与其他指标错开时，模型沿 Pareto 前沿移动，需要明确任务取舍。

训练停止采用多个窗口的趋势，减少单点波动影响。若外部能力边际收益接近零，而 KL、长度或成本继续上升，应结束或调整配方。GMPO 延缓崩溃不意味着训练越久越好。

**审计表的人工复算。** 回答表包含 prompt id、reward 分量、advantage、长度、算术 ratio、几何 ratio、$\Delta$、裁剪数量、利用率、$\tilde g$ 与梯度范数。token 表包含位置、token、mask、old/new log-prob、方向性 clip、专家与关键动作标记。

组内相邻展示回答，可以检查 advantage 和为零与 winner 排序；从一条高 $\Delta$ 回答下钻 token 表，可以确认共享权重由哪些离群产生。两张表覆盖公式、数据和行为三层。

**参考实现与论文版本。** 论文元数据以 arXiv v3 为准，作者为 Yuzhong Zhao 等，官方代码链接用于核对实现。引用性能时标明模型、任务与表格。仓库更新可能晚于论文，复现记录具体 commit。

几何平均从对数域计算。对有效 token 集合 $M$，使用 $\bar\ell=|M|^{-1}\sum_{t\in M}\log r_t$ 与 $\exp(\bar\ell)$；padding 不进入集合。全一 ratio、统一缩放与不同 padding 长度构成基础测试。

几何平均约束乘积尺度，无法保证每个 token 温和变化。一半 ratio 为二、另一半为零点五时，聚合恰为一，局部策略已经明显重排。逐 token log-ratio 的方差、极值与长度分桶用于区分整体守恒和局部抵消。

**结论所需的证据。** 公式与实现一致、高离群 batch 的共享权重和梯度尾部改善、训练稳定性与固定外部能力同步、长度成本和局部风险可接受，共同构成机制链。其中任何一层失败，都会限制结论范围。

GMPO 的核心贡献很集中：用 token 级方向裁剪保留局部有效更新，用回答内几何均值替换算术均值，避免单个 importance ratio 独占梯度。它的力量也来自这份集中；超出 ratio 离群的问题，需要数据、reward、采样或信用分配机制各自处理。

**一次参数扫描怎样读。** 固定同一批 rollout，依次使用 log 边界零点二、零点四、零点六，记录 token 利用率、几何 ratio 分位、梯度范数与 GRPO 梯度余弦。边界变宽时，利用率应单调增加；几何 ratio 尾部通常展开；梯度方向可能逐渐接近未裁 GMPO。若这些关系不成立，优先检查符号分支和 mask。

换到新鲜 rollout 后重复扫描，再在短程训练中观察外部能力。离线 batch 只能展示当下梯度，策略更新会改变后续数据分布。最优边界由探索收益和累计稳定性共同决定，无法从一次静态分位数直接选定。

对正负优势分别扫描也有必要。reward 分布偏斜时，两侧样本数量与幅度差异很大；一个对称 log 边界可能让正侧利用率高、负侧几乎全裁，或反过来。论文配方提供起点，真实数据的两侧统计决定是否需要非对称扩展。

**Loss 数值与梯度不能混为一谈。** 被裁 token 的边界值仍进入几何 ratio，因而 loss 会随其他未裁 token 改变；它自身对参数的直接导数为零。只观察 loss 曲线无法知道多少 token 仍在学习。有效 mask 与梯度范数是必要补充。

同样，GMPO loss 小于 GRPO loss 不能解释为性能更差或更新更保守。两者目标尺度不同，优化器学习率与梯度方向更重要。公平对照可先匹配初始梯度范数，再保留原始超参数结果，分别回答机制与默认配方问题。

**多任务冲突仍然存在。** 数学题偏好长推理，格式任务偏好短输出，工具任务依赖少数关键动作。GMPO 在每条回答内部平衡 token ratio，无法解决不同 prompt 梯度互相抵消。按任务域计算梯度余弦与能力曲线，避免总体平均掩盖小域退化。

若某域 ratio 离群明显，GMPO 对它压缩更强，等价于改变域间有效权重。原数据采样相同，参数更新贡献也可能重新分配。每个域的 $|A\tilde g|$、利用率和梯度范数可以揭示这种隐式重加权。

**发布前回归集。** 保留单大 ratio、单小 ratio、正负抵消、全体同向、全同 reward、正确长解、错误短答、工具关键动作、padding 错位和 policy lag 十类样本。每次实现或框架升级复算 surrogate、mask 与梯度方向。

这些反例覆盖 GMPO 最容易出错的三个位置：优势符号决定裁剪侧，裁剪值与导数 mask 的区别，几何均值分母的有效长度。随机测试适合抓数值错误，结构化反例负责抓语义错误。

**一句话归纳。** GRPO 让每个 token 以自己的 ratio 加权，GMPO 先限制沿优势方向走得过远的 token，再让保留位置共享整条回答的几何 ratio。由此换来更低的离群敏感性，也付出局部权重信息被压缩、严格 off-policy 解释减弱的代价。是否值得，取决于数据中 ratio 离群究竟是噪声还是有效信用。

在实际训练里，这个判断可以落到三个数字：$\Delta$ 描述序列内部 ratio 的不均匀，梯度余弦描述聚合变化是否改写更新方向，新鲜 rollout 上的外部收益描述这种改写是否有用。三者缺一时，平滑的 loss 仍可能来自尺度缩小、数据陈旧或奖励偏差。

同时保留被 GMPO 明显压缩的回答与几乎不受影响的回答。前者用于检查离群究竟来自路由噪声、错位还是关键动作，后者验证普通样本没有被无谓改写。两类样例共同构成解释算法行为的对照组。

当模型、最大长度或 sampler 改变后，ratio 尾部和 $\Delta$ 分布也会变化。旧训练选出的 clip 区间需要重新校准，不能视为跨系统常数。短程机制实验通过后再进入长训，能够在较低成本下发现符号、mask 与尺度问题。

最终的复现报告还应公开失败种子和崩溃前的分布快照。稳定算法的价值体现在尾部风险下降，隐藏失败运行会让平均分失去判断意义，也无法验证几何聚合是否真正改变了训练可靠性。
