## 1. 动机: 同一设计轴上的相反结论

### 1.1 冲突来自配方, 不来自机制

2025 年推理 RL 的 recipe 迅速堆积, 同一个设计问题在不同论文里给出相反答案. 归一化: GRPO(1.3.1.1 节) 对组内奖励做均值标准差归一化, REINFORCE++ 主张批级归一化, 理由是只在单一 prompt 内比较会诱发 reward hacking, 妨碍泛化; Dr. GRPO (1.3.1.1 节 §3) 又要求整个删掉标准差项, 以消除难度偏差. baseline 设计: RLOO(1.3.1.2 节) 用 leave-one-out 均值做基线, 与 GRPO 的组均值基线争同一个位置. 损失聚合: GRPO 按 response 粒度平均, DAPO(1.3.2.1 节) 改按 token 粒度求和, 1.3.2.2 节的 GSPO 把重要性比提升到序列粒度, 1.3.2.3 节的 GMPO 留在 token 级但把算术平均换成几何平均. 每个改动都有独立的动机与论文背书, 但没有一份工作在同一个框架里把它们摆在一起逐项测过.

Tricks or Traps 将冲突归因于实验设置、训练数据与模型初始化的差异: 同一个 trick 换到另一套条件下, 效果方向可能反转. 因而论文不做统一排名, 而是在固定框架里隔离评估主流技巧, 给出各自的适用场景, 并组合出只含两项技巧的 Lite PPO.

这种方法延续了经典 RL 的机制分析传统. Engstrom 等人 2020 年对 PPO 实现的拆解, 以及 Andrychowicz 等人 2020 年对 on-policy RL 超参的系统研究, 都表明实现细节足以翻转算法结论. Tricks or Traps 把同一流程用于推理 RL: 固定框架与协议, 每次只动一个设计轴, 再用多难度数据和多种模型初始化交叉验证. 其结论都受这套实验协议约束, 不能直接外推到协议之外.

论文把常见技巧归为七类: baseline 设计, 裁剪, 归一化, 过滤, 损失聚合粒度, 辅助损失 (KL, SFT), reward 设计 (长度惩罚, 格式奖励). 受篇幅所限, 正文只深挖前四类里的归一化, 裁剪, overlong filtering 与损失聚合, 辅助损失与 reward 设计只作背景. 这个取舍本身值得注意: 被跳过的两类恰恰是「与任务 reward 形态耦合最强」的两类, 它们的结论迁移成本最高, 留给后续工作.

### 1.2 统一协议与两条基线事实

所有实验在 ROLL 框架上运行. 训练目标是 vanilla PPO loss, 优势用 REINFORCE 估计, 全程无 critic. 全局采样 batch 为 1024: 每轮 128 个 prompt, 每个 prompt 采 8 条回复; 最大回复长度 8192 token; 学习率 $10^{-6}$; 采样 top_p = 0.99, top_k = 100, 温度 0.99. 策略模型取 Qwen3-4B 与 Qwen3-8B 各两个变体: base 与 aligned, 共四个. 训练数据只用开源集, 按难度分三档: easy 档从 SimpleRL-Zoo-Data-Easy 随机抽 5000 题 (GSM8K 与 MATH-500 level 1 难度), medium 档取 DeepMath-103K 中难度标注最容易的 5000 题, hard 档按难度标注加权采样 5000 题.

数据侧还有一处容易被忽略的清洗: 两类数据集里都剔除了真值仅为 True/False 的样本, 因为模型可能从错误的推理链凑出正确的二值答案, 构成噪声监督 (案例见论文附录 B.2). 这个决定和结论无关却直接影响可比性——别的复现若不排除这类样本, 同一技巧的评分会被噪声监督拉偏. 评测在六个数学 benchmark 上取平均: MATH-500, OlympiadBench, MinervaMath, AIME24, AIME25, AMC23, 覆盖从基础算术到竞赛数学的难度谱. 平均分的口径与 DAPO (1.3.2.1 节 §7) 的报告方式一致, 跨论文引用时可以直接对齐.

基线实验先给出两条后文反复用到的事实. 第一, aligned 模型起点准确率显著更高, 初始回复也更长, 但 RL 只能再带来约 2% 的准确率提升; base 模型起点低, 提升空间反而大得多. 第二, 训练准确率曲线对数据难度敏感: 难题上模型倾向生成更多 token 来拟合复杂推理, 长度与难度纠缠在一起. **任何 trick 的结论都必须绑定模型类型与数据难度来读, 脱离语境的「普遍更好」在这套协议里站不住.**

这两条事实直接改变了读法. aligned 模型上 2% 的提升空间意味着: 评测 aligned 模型的 trick 收益, 噪声容限极小, 需要多 seed 与置信区间才分得开 1 到 2 个点的差异. base 模型上提升空间大, trick 之间的排序更可靠, 但 base 的训练动态更不稳定, 又要求报告训练曲线而非只报终局分. 论文的图表同时给出两者, 复现时只抄终局分会丢掉一半信息: 收敛速度, 振荡幅度与是否中途崩溃, 都在曲线里.

读曲线还有两个口径细节. 论文的训练曲线统一用 11 步滑动窗口加指数平滑 (系数 0.8) 处理, 阴影带是平滑后均值加减若干倍标准差, 用来展示振荡幅度. 平滑让曲线可读, 但也把短期崩溃藏了进去: 一条「平滑后缓慢上升」的曲线, 原始曲线可能在中段剧烈震荡. 对比两条 trick 的收敛速度时, 要看未平滑的步进值, 或至少把平滑参数对齐, 否则平滑口径本身就能制造「谁收敛快」的假差异. aligned 模型上 2% 量级的差异尤其脆弱, 这类比较更应回到原始数据.

## 2. 归一化: 均值与标准差可以分开选

### 2.1 组级与批级的失效条件

记一个 prompt 采 $K$ 条回复, 奖励 $\{r_k\}_{k=1}^K$. 组级归一化:

$$A_k^{group}=\frac{r_k-\mathrm{mean}(\{r_j\}_{j=1}^{K})}{\mathrm{std}(\{r_j\}_{j=1}^{K})}.$$

批级归一化把统计量换到整个 rollout batch ($N$ 个 prompt, 共 $N\times K$ 条回复):

$$A_i^{batch}=\frac{r_i-\mathrm{mean}(\{r_j\}_{j=1}^{N\times K})}{\mathrm{std}(\{r_j\}_{j=1}^{N\times K})}.$$

默认二值 reward ($r\in\{0,1\}$, 答对 1 答错 0) 下, 组级归一化在两个模型尺寸上都比批级和无归一化收敛更稳, 终局性能更高; 批级归一化对 batch 内奖励分布的倾斜高度敏感, 不平衡时少数离群样本主导优势估计, 训练可能中途崩掉. 把 reward 编码改成 $r\in\{-1,1\}$ (答错 -1) 后, 批级归一化恢复有效性.

同一个技巧, 只改 reward 尺度, 结论反转, 这就是「技巧必须绑定场景」的第一个实例. 无归一化的对照组则提供了尺度的另一极: 优势直接取原始 reward, 梯度幅度由 reward 编码本身决定, 换任务就要重调学习率, 论文里没有把它作为推荐项, 只作为消融参照.

### 2.2 手算: 倾斜 batch 下的优势放大

假设用总体标准差 (除以 $n$, 不除以 $n-1$), $K=8$, $N=128$. 情形 A: 全 batch 通过率 $p=0.5$, 批均值 0.5, 批标准差 $\sqrt{0.5\times0.5}=0.5$. 答对样本的批级优势 $(1-0.5)/0.5=1$, 答错样本 $(0-0.5)/0.5=-1$, 正负对称. 情形 B: 训练后期整体通过率升到 $p=0.9$, 批均值 0.9, 批标准差 $\sqrt{0.9\times0.1}\approx0.3$. 答对样本优势 $(1-0.9)/0.3\approx0.333$, 答错样本 $(0-0.9)/0.3=-3$. 负方向更新强度变成正方向的 9 倍, 而答错样本在 batch 里只占 10%: 梯度被极少数样本主导, 单步更新方向由离群样本说了算.

这就是「倾斜 batch 下批级归一化崩溃」的数值形态, 和二值 reward 的尺度直接相关: $r\in\{0,1\}$ 时批标准差的上界只有 0.5, 通过率一高, 分母先塌, 少数负样本的优势被放大到支配地位. 换成 $r\in\{-1,1\}$, 批标准差上界变为 1, 同样的通过率下分母大一倍, 离群放大被压住——批级归一化在 reward 尺度改变后「恢复有效」的原因就在这里.

组级归一化对全局难度不敏感. 取某个 prompt 的组内 8 条回复 3 对 5 错: 组均值 0.375, 组标准差 $\sqrt{0.375\times0.625}\approx0.484$, 答对样本的组级优势 $(1-0.375)/0.484\approx1.291$, 答错样本 $(0-0.375)/0.484\approx-0.775$. 优势尺度只反映这组内部的相对表现, 不随全局通过率漂移. 代价同样清楚: 组内全对或全错时标准差为零, 优势没有定义; 且 8 个样本估两个统计量, 噪声大. RLOO(1.3.1.2 节) 的 leave-one-out 基线缓解的是组均值基线自身的耦合问题, 但标准差尺度带来的放大, leave-one-out 同样没有碰.

### 2.3 标准差项与混合归一化

批级归一化的不稳定是否由标准差项引起? 消融把标准差从批级归一化中删掉, 只减均值, $A_k^{\neg std}=r_k-\mathrm{mean}(\{r_j\})$. 结果分两种数据形态: easy 数据上训练迅速收敛到行为高度一致, 奖励分布集中, 标准差曲线快速跌到低值, 此时除以标准差得到极小的分母, 异常放大优势, 引发梯度爆炸; 删掉标准差后训练恢复稳定. hard 数据上奖励方差天然较大, 标准差维持高位, 删不删差别不大.

std 缩放的力度可以手算: 组内 8 条 7 对 1 错, 组均值 0.875, 总体标准差 $\sqrt{(7\times0.125^2+0.875^2)/8}=\sqrt{0.875/8}\approx0.331$. 那条错答的优势带标准差是 $(0-0.875)/0.331\approx-2.646$, 只减均值是 $-0.875$, 放大 3.02 倍; 若该组 8 条全对, 标准差直接为零, 除零. 也就是说, 标准差项把「组内个别样本的差异」按组内一致性的倒数加权: 一致性越高, 越小的差异获得越大的更新. easy 数据上模型快速全员答对, 一致性顶到天花板, 这正是灾难的来源.

最终方案把两个统计量拆开选: 均值取组级, 标准差取批级, $A_k=(r_k-\mu_{group})/(\sigma_{batch}+\epsilon)$. 组均值保留 prompt 内的相对比较, 批标准差提供跨 prompt 稳定的全局尺度, 两个模型尺寸上这套混合归一化都最稳. 论文给出的机制解释: 批级标准差压住了梯度幅度, 防止过大更新, 与稀疏 reward 下粗粒度优势估计的偏置更匹配; REINFORCE++ 报告的批级归一化收益, 在这个混合形态下也部分复现.

这个结论对 1.3.1.1 节 §3 的「删 std」争论是一个有条件的回应: Dr. GRPO 担心的难度偏差来自「组内 std 把过难样本的微小差异放大」, 论文没有否认这个机制, 而是把分母挪到全局, 让放大因子由整个 batch 的奖励离散度决定, 不再被单一组内的一致性绑架. **组内竞争靠组均值, 全局尺度靠批标准差, 两者分工不同, 可以独立选择**——这是 Lite PPO 的第一根支柱. 实现时 $\epsilon$ 只负责防除零, 不应大到改变尺度; 若发现训练对 $\epsilon$ 敏感, 多半是分母本身已经塌到 $\epsilon$ 的量级, 该回到数据侧查 reward 分布.

### 2.4 归一化的监控口径

无论选哪种归一化, 有三条曲线要进默认监控. 一是批标准差与组标准差的分布曲线: std 快速下塌是「马上要有麻烦」的先行指标, 比损失曲线更早. 二是按难度分桶的梯度范数: 「std 归一化在 easy 上炸」的机制判断, 最终要落到「easy 桶的梯度范数是否系统性高于 hard 桶」这个可测的量上. 三是全同组占比: 组内全对或全错的比例上升, 组级归一化的有效样本随之减少, 优势估计的噪声放大.

这三条曲线还有一个共同用途: 判断自己的任务像论文的哪一档. 批标准差长期高于 0.3, 全同组占比低, 说明任务落在 hard 档的形态, 归一化风格的选择空间很大; 批标准差压到 0.1 以下, 全同组占比过半, 则落在 easy 档的形态, 标准差项是头号风险源. 用曲线给任务画像, 再决定抄哪个配方, 比按模型规模对号入座可靠.

监控之外还有诊断顺序. std 下塌时, 先查数据难度构成, 再查归一化实现: 难度构成漂移 (easy 样本占比上升) 是数据侧原因, 换一批数据就恢复; 实现侧原因 (std 算错轴, 把批级写成了组级) 则任何数据下都在. 用一个全对 batch 和一个半对 batch 分别喂进去, 比较输出优势的分布, 两种原因立刻分开, 这比逐行核对实现快.

## 3. 裁剪: Clip-Higher 的收益绑定模型类型

### 3.1 base 模型为什么无感

Clip-Higher 把 ratio 上界从 $1+\epsilon$ 抬高到 $1+\epsilon_{high}$, 下界不动 (DAPO, 1.3.2.1 节 §2). 这篇论文复现后给出使用边界: base 模型上抬高上界收益微小, 甚至低于标准裁剪; aligned 模型上抬高上界明显减缓熵坍缩, 中等难度与复杂推理任务上的评测准确率随之上行. 两侧的机制证据都落在 clip fraction (被裁剪样本占比) 上: base 模型只有约 0.003, 相邻两轮策略的 ratio 极少越过 0.2 边界, 抬高上界改的是一个几乎不被触发的约束; aligned 模型初始 token 分布更平坦, 高概率 token 少, ratio 更容易在训练初期冲出边界, 上界抬高直接扩大了可更新区域.

换个角度, Clip-Higher 松绑的对象是「被压制的强化」. base 策略表达力有限, 采不出高奖励轨迹, 松绑没有对象; aligned 策略已有能力, 对称裁剪反复在 $1+\epsilon$ 处截停正优势, 正确的推理模式推不到位, 才需要松绑. 这个结论与 DAPO 的原始场景 (32B 强模型) 自洽, 也把适用范围标清: 在小尺寸 base 模型上做消融时, Clip-Higher 不该作为默认收益项计入配方, 否则消融表里的正收益可能是别的改动借来的. **Clip-Higher 的收益前提是策略已经训出了可松绑的探索, 这个前提在 base 模型上不成立.**

还要注意, 论文测量的 clip fraction 是「off-policy 程度」的代理指标, 而 off-policy 程度由 rollout 复用次数决定. 复用越多, ratio 偏离 1 越远, clip 触发越多, Clip-Higher 的潜在收益空间越大. 自己的管线若 rollout 与更新严格交替 (复用次数为 1), 则连 aligned 模型上的 Clip-Higher 收益也要打折扣——这个条件论文没有单独扫描, 属于引用时需要自己补的空白.

### 3.2 上界取值与连接词证据

上界不是越高越好. 小尺寸模型 (4B aligned) 上性能随 clip 上界单调上升, 到 0.32 见顶; 更大的模型 (8B aligned) 最优上界是 0.28, 继续抬高没有增益. 论文把这个现象称作裁剪上界的 scaling law, 但报告范围止于这两个规模, 没有给出跨尺寸的拟合公式; 迁移到 32B 以上属于外推, 论文没有报告相应实验, 引用时只能引用 0.28 与 0.32 两个点.

语言学层面的 token 分析解释了严格裁剪为什么伤推理. 上界取 0.2 时, 被裁剪压制最多的是 discourse connectives (因此, 如果, 但是一类连接词): 这些词常出现在句首, 标记推理的转折与分叉, 新旧策略在它们身上的概率比最容易越过阈值, PPO 的 min 结构对它们施加最强压制. 推理链的分叉点恰好被压在更新范围之外, 生成多样推理结构的能力随之受限. 上界放宽后, 裁剪的落点转移到高频功能词上, 连接词的更新空间被释放, 结构稳定性与推理多样性同时保住.

这与 1.3.2.2 节 GSPO 的观察指向同一病灶: 粒度过细的逐 token 约束在长链推理上会截停关键位置的更新, 两家分别从 clip 边界与重要性比粒度两侧动手. GMPO(1.3.2.3 节) 留在 token 级, 改的是聚合统计量对离群比率的敏感度. 三条路线并存说明「裁剪该卡在哪」仍是开放问题, 共同点是都承认: 把每个 token 一视同仁地限制在小位移内, 和让推理链保持分叉能力, 这两个目标在训练深入后是冲突的.

下界 $1-\epsilon_{low}$ 在论文的扫描里全程未动, 所有实验只在上界一侧做文章. 这个不对称值得在监控里对应: clip fraction 要按正优势与负优势分开统计. 若负侧触发远多于正侧, 说明「压错」先饱和而「扶正」还有余量, 正是 Clip-Higher 针对的失衡; 若两侧接近, 说明 off-policy 程度不深, 抬上界的收益空间有限, 优先排查别处. 论文没有给出这个分流指标, 属于实现侧需要自己补的监控.

### 3.3 熵监控的口径

「熵坍缩」在这篇论文里不是修辞, 有可操作的测量口径: 熵曲线按固定温度在一个探针集上测, 而不是训练采样温度的顺手记录. 这个区别要紧——训练采样温度随课程和阶段变化, 直接记录采样分布的熵, 会把温度调度本身的信号混进策略熵. 复现论文的熵曲线要沿用同一口径, 否则两条曲线不可比.

组内唯一回答数是另一个比 token 级熵更稳健的代理指标: 组内 $G$ 条回复去重后的数量下降, 直接说明探索在收缩, 且不受温度口径影响. 两个指标配合使用: 熵曲线看趋势, 唯一回答数看阈值. 唯一回答数掉到 1 附近时, 组内优势恒为零, 训练实质已经停摆, 这时再调 clip 上界属于事后补救, 应提前在该指标上设告警.

## 4. 过滤与损失聚合

### 4.1 overlong filtering 的有效区间

overlong filtering 把超过预设生成长度的回复的奖励掩掉, 不让超长截断的样本以「答错」的名义惩罚一条本来正确的推理链. 结论按任务长度分野: 短中程推理任务上过滤提升准确率, 输出更清晰; 长尾推理任务上收益变薄, 因为超长样本里混着大量有效但漫长的正确解, 一并掩掉等于丢弃真实信号. 论文还用 repeat ratio (重复率) 佐证: 过滤顺带抑制了退化生成, 但重复抑制对准确率的独立贡献没有单独量化, 引用时只能说到「方向上明确」.

和 DAPO 的 overlong reward shaping 区分开 (1.3.2.1 节 §5): shaping 是改 reward 数值 (三段线性惩罚), 超长链仍参与梯度, 拿的是「正确答案减去长度代价」; filtering 是 mask, 超长链直接退出梯度, 也不提供「长度有边际成本」的信号. 两者处理同一个痛点, 作用方式相反, 长尾任务上的取舍也相反. 选型依据是任务的长度分布: 回复长度集中在阈值以下的任务, 用 filtering 干净利落地去掉截断噪声; 长链本身就是交付物的任务, 应该用 shaping 或干脆放宽阈值.

论文还扫了最大生成长度本身的影响: 上限收紧会同时改变准确率与回复长度, 收紧过头把「能解的题」变成「截断的题」. 这个扫描提醒我们, filtering 的有效区间不是固定的, 它随生成上限, 任务难度和训练阶段移动. 实操上先画训练集回复长度的分位数曲线, 让过滤阈值落在 P95 到 P99 之间, 再按评测表现微调, 比在论文默认值上硬套稳.

### 4.2 token-level 还是 sequence-level

sequence-level 聚合先把每条回复的损失按自身长度平均, 再对回复等权平均 (GRPO 方式); token-level 用整个 batch 的有效 token 总数做分母 (DAPO 方式). 结论再次分模型: base 模型上 token-level 收敛更快更稳, hard 数据上差距最明显; aligned 模型上 sequence-level 更优, token-level 提升有限. 论文归因: aligned 模型的输出结构已被后训练塑形, 按回复等权有助于维持结构一致性; base 模型长度方差大, 每条等权让长回复的每个 token 被系统性稀释, 恰好是 Dr. GRPO 分析的长度偏差方向 (1.3.1.1 节 §3).

权重差别可以手算. 一个 batch 两条回复, 200 token 与 2000 token, 共 2200 个有效 token. 序列级下两条回复各分一半梯度预算, 长回复的每个 token 权重是 $0.5/2000=2.5\times10^{-4}$, 短回复是 $2.5\times10^{-3}$, 相差 10 倍. token 级下每个 token 等权, 一律是 $1/2200\approx4.5\times10^{-4}$, 长回复的单 token 权重被放大 1.8 倍, 短回复被压到 1/5.5. 两种分母没有谁绝对正确, 改的是长回复在批梯度中的占比, 而这个占比的合理性取决于任务与模型, 论文的「base 用 token 级, aligned 用 sequence 级」就是这个依赖的经验形态.

还要注意两个语义都没变: 同一回复内所有 token 仍共享序列级优势, reward 仍是整条回答一个标量, 没有发生 token 级信用分配; 变的是回复之间的相对权重. 记成一句话: **GRPO 按「条」投票, token-level 按「token 数」投票** (1.3.2.1 节 §4.1 的同一句结论, 这里从消融侧独立复现). 实现上归约分母要和 clip 边界, 学习率当成一个整体调: 换分母改变梯度的有效尺度, 等效于动学习率, 只换分母不动其余, 常见结果是曲线有变化但说不清变好变坏.

### 4.3 过滤与归一化的联动

动态采样与过滤改写的不是 batch 的大小, 而是 batch 的奖励分布, 而奖励分布正是归一化的分母. 过滤掉全对组后, batch 内剩余样本的通过率整体下移, 批均值下降, 批标准差先升后降; 这个变化直接进入批级归一化的尺度. 换句话说, 开不开过滤, 改的是归一化面对的数据形态, 两篇论文若一篇带过滤一篇不带, 归一化消融的数值自然对不上.

一个可算的极端情形: batch 内 prompt 通过率两极分化, 一半 prompt 通过率 0.9, 一半 0.1, 每组 $G=8$. 不过滤时批均值 0.5, 两极分布把批标准差拉满. 过滤后, 0.9 那侧约 $0.9^8\approx0.43$ 比例的组全对被移除, 0.1 那侧约同样比例的全错组被移除, 留下的 batch 集中于中间难度, 批标准差显著收窄, 归一化的放大因子随之整体上调: 同样的原始奖励差异, 在过滤后的 batch 里获得更大的优势幅度. 过滤与归一化不是两个独立开关, 通过 batch 构成耦合在一起. 做联合消融时, 两个开关要同时列入变量列表, 先跑单开关再跑组合, 顺序不能省, 否则组合组里的收益分不清是谁的贡献.

实操建议沿用 1.3.2.1 节 §3.4 的口径: 有效组占比, 过滤比例, 补采成本分开报; 归一化消融要注明是否带过滤, 否则「批级归一化稳不稳」的结论无法跨实现比较.

与动态采样联动时, 聚合粒度的选择还多一层考虑: 过滤与补采改变了 batch 的长度构成, token 级分母把这部分变化直接写进梯度尺度, sequence 级分母则只按「条」均摊, 对长度构成的变化不敏感. DAPO(1.3.2.1 节 §3) 把过滤, 补采与 token 级 loss 打包使用, 二者在同一个 batch 构成剧烈波动的系统里互相放大; 只抄其中一半的团队, 应预期到另一半的缺席会改变效果排序.

## 5. Lite PPO 与复现清单

### 5.1 两技巧组合的准确定位

Lite PPO 把消融中两个在其设置下最稳的选择组合起来: 组级均值加批级标准差的混合归一化, token-level 损失聚合, 配合 vanilla PPO loss 与 REINFORCE 优势, 无 critic, 无 KL 项, 无动态采样. 在 base 模型设置下, 这个两技巧组合在六个数学 benchmark 的平均分上稳定超过 GRPO 与 DAPO 两个多技巧 recipe. 作者将其解读为: 复合 recipe 里多出的组件在 base 模型语境里引入了干扰, 而非技巧堆叠存在普遍溢价.

两根支柱在 base 语境里是互相成全的. base 模型训练初期几乎全员答错, 组内差异微弱, 批标准差给所有组一个不会塌掉的全局尺度, 避免 std 坍缩引发的梯度爆炸; 随着训练推进, 长度方差拉大, token 级分母防止长回复的正确链被稀释, 保住难题上的梯度信号. 换一个语境, 支柱的作用随之变化: aligned 模型奖励分布不塌, 混合归一化的第一项收益消失; 输出结构稳定, 第二项的收益也变薄. 这解释了 Lite PPO 的结论为什么绑定 base 模型.

没有 KL 项也值得一提. GRPO 在损失里保留对参考策略的 KL 正则, DAPO(1.3.2.1 节 §6) 与 Lite PPO 都把它去掉, 靠 clip 承担偏移约束; REINFORCE++ 则保留 KL. 论文没有在去 KL 这件事上做独立消融, 去 KL 是 Lite PPO 继承自 PPO 基线的默认形态, 不是论文验证过的收益项. 引用时把它说成「Lite PPO 的第三个技巧」属于过度归因.

边界同样要划清. 第一, aligned 模型上 token-level 聚合本身提升有限, 论文没有把 Lite PPO 推荐为 aligned 模型的默认. 第二, Lite PPO 是消融结果的组态, 不是新算法, 名字里没有隐含的显存, 学习率或吞吐结论, 论文也没有报告这类数字. 第三, 「两技巧胜过复合 recipe」不能被读成「技巧越少越好」的普遍命题: 换一个语境, 被删掉的组件 (Clip-Higher 之于 aligned 模型, 动态采样之于低有效组占比的管线) 可能正是收益来源.

与 GRPO, DAPO 对比时还有一个口径细节: 论文报告的是六个 benchmark 的平均分, 每个设置只覆盖 Qwen3 两个尺寸. 单 benchmark 上的胜负分布, 平均分内部的方差, 以及 Qwen3 之外的模型族, 论文都没有报告. 「稳定超过」的读法是平均分意义上的稳定, 不是每个 benchmark, 每个种子都赢. 引用这组对比时保持这个限定, 不要把平均分领先复述成全面占优.

### 5.2 教学实现

```python
import torch

def lite_ppo_advantage(rewards, eps=1e-8):
    """对应式: A = (r - mean_group(r)) / (std_batch(r) + eps)
    rewards: [N, G], N 个 prompt, 每组 G 条回复"""
    group_mean = rewards.mean(dim=-1, keepdim=True)   # [N, 1], 组级均值
    batch_std = rewards.std()                         # 标量, 批级标准差
    return (rewards - group_mean) / (batch_std + eps) # [N, G]

def lite_ppo_loss(ratio, advantage, mask, eps=0.2):
    """对应 PPO 式: L = -sum(min(ratio*A, clip(ratio)*A)) / mask.sum()
    ratio, advantage, mask: [N*G, T], advantage 已广播到 token"""
    clipped = ratio.clamp(1 - eps, 1 + eps)
    token_obj = torch.min(ratio * advantage, clipped * advantage)
    return -(token_obj * mask).sum() / mask.sum()     # token-level 分母
```

这段代码说明两件事. 第一, 混合归一化的均值与标准差来自两个统计轴, 实现里两者必须分别可开关, 否则后续消融无法逐项拆掉. 第二, 分母是 `mask.sum()` 而不是回复条数或每条回复的长度, 这是 token-level 与 sequence-level 的全部实现差别, 与 1.3.2.1 节 §4 的 DAPO 分母同款. old log-prob 必须作为采样策略的常数保存, ratio 的分母不能进计算图, 这是 1.3.1.1 节 §2 强调过的同一纪律.

### 5.3 不依赖训练的验证清单

四条不变量, 全部在合成张量上可测. 其一, 全同组: 构造组内奖励全等的 batch (全 1, 全 0, 全任意常数), 组级 std 归一化在此处除零, 混合归一化下优势应精确为零, 不得出现 NaN 或 Inf. 其二, 组大小退化: $G=1$ 时组均值等于样本自身, 优势恒为零, 梯度为零; 实现若允许 $G=1$, 应显式给出这个退化行为的告警, 而不是静默产出零梯度假装在训练. 其三, 聚合等价: batch 内所有回复等长时, token-level 与 sequence-level 损失只差常数因子 $B|y|/\sum_i|y_i|=1$, 逐点对比可拦住分母写错. 其四, 裁剪退化: $\epsilon_{high}=\epsilon_{low}=\epsilon$ 时, Lite PPO 的 clip 应逐点退化为标准 PPO 的 $\mathrm{clip}(r,1-\epsilon,1+\epsilon)$.

上线前再补一个集成级检查: 固定种子跑 50 步, 记录 clip fraction. 按论文报告, base 模型的 clip fraction 量级约 0.003; 若自己的 base 模型实现报出 0.1 以上, 大概率是 old log-prob 没作为常数保存 (ratio 分母被反向传播污染), 或 clip 分支写反. 这类 bug 不报错, 损失照常下降, 只在指标曲线上留痕迹, 所以要把 clip fraction, 组内标准差分布, 有效 token 数三条曲线纳入默认监控, 而不是等训练崩了再回查. 这套清单与 1.3.2.1 节 §8.2 的 DAPO 验收套件是同一思路: 先在不依赖模型的不变量上拦住实现错误, 再用集成检查兜住时序与分布式带来的第二类错误.

最后一条清单针对消融本身. 切换归一化或聚合粒度的开关时, 用同一个合成 batch 把所有配置先跑一遍, 记录各配置输出的损失与优势. 这些数值作为回归基线存档: 之后的任何重构 (性能优化, 分布式改造, 精度换速度) 完成后重跑同一合成 batch, 数值对不上就说明改动动了语义, 而不是只动了效率. 消融研究的敌人一半是技巧之间的耦合, 另一半是实现对不齐, 这条清单管的是后一半.
