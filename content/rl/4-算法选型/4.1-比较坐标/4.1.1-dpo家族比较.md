# DPO Family: 偏好优化算法大比拼

DPO 家族五个方法共享三个条件: 用模型的 token log probability 构造偏好信号, 在固定数据上离线训练, 不需要在线 rollout. 差别集中在信号形式 (成对比较或二元反馈), 归一化基准 (有无参考模型, 用概率比还是优势比) 和目标形状 (sigmoid 饱和, 有限目标或显式 margin). 方法选择可以据此拆成条件判断, 具体推导、手算与实现约定见 1.2.2 节到 1.2.6 节.

选型前先立一个参照判断: 五个方法之间的差距, 远小于「做不做偏好对齐」之间的差距, 也远小于偏好数据质量好与差之间的差距, 这个判断在 ORPO 一篇的时间线讨论中已经给出 (1.2.4 节). 因此下面的决策树只做方法内部的细分, 不回答「要不要做对齐」. 数据管线的优先级永远高于损失函数的优先级, 损失选型留在数据管好之后.

## 1. 三个入口条件: 数据形态, 参考模型, 起点模型

五个候选方法先被三个可观察的条件过滤, 再谈损失性格. 这三个条件都不是超参层面的事: 数据形态由标注管线决定, 参考模型约束由硬件与工程预算决定, 起点模型由上游流程决定. 三个条件的检查顺序也有讲究: 先数据形态, 再起点模型, 最终参考模型. 前两个条件否定的候选直接出局, 没有回旋空间; 参考模型条件只改变维护成本, 不构成硬约束. 按这个顺序过滤, 多数项目在第一关之后只剩两到三个候选, 后面决策树的工作量被压到最小.
数据形态：成对还是二元。 第一个问题是标注产物的形态. 成对偏好数据每条样本是 $(x, y_w, y_l)$, 同一 prompt 下标注者比较两条回答; 二元反馈每条样本是 $(x, y, k)$, $k\in\{+1,-1\}$ 只说明这条回答好不好 (1.2.6 节). DPO, IPO, ORPO, SimPO 四个方法全部消费成对数据, 因为它们的损失都要对 chosen 与 rejected 的分数做差; KTO 是家族中唯一接受二元数据的方法, 它的损失按单条样本相对 KL 参考点的位置给梯度 (1.2.6 节).

这个条件可以直接从数据源判断. 点赞, 点踩, 审核通过或拒绝, 代码采纳记录属于二元反馈, KTO 可以直接使用. 如果管线本来就生产成对标注 (两个候选并排展示, 标注者二选一), 把对子拆成两条二元样本交给 KTO 会丢失对子内的比较关系, 只换来数据量翻倍与逐条过滤的灵活性 (1.2.6 节).

### 1.2. 参考模型: 显存约束还是工程复杂度

第二个条件是训练配置里愿不愿意养一个冻结的参考模型. DPO, IPO, KTO 的损失都含 $\log\pi_\theta-\log\pi_{\mathrm{ref}}$ 结构的相对量, 必须加载参考模型 (1.2.2 节, 1.2.6 节); ORPO 与 SimPO 不需要, 这是它们最大的工程优势.

参考模型的真实成本要按口径拆开, 不能引用「显存减半」这类宣传数字. 按 ORPO 一篇的显存分解 (1.2.4 节), 训练常驻显存里约 $16N$ 字节属于参数, 梯度与 AdamW 优化器状态, 参考模型只占其中约 $2N$, 占比约一成; 如果参考 log-prob 是预计算缓存的, 参考模型甚至可以不进显存. 所以「只有一张卡」本身不构成选 ORPO 或 SimPO 的理由, 真正的可观察条件是: 参考模型对应的那组代码路径与分布式切分配置, 在你的管线里是否构成维护成本, 以及你是否有迭代式训练计划. 迭代训练里参考角色每轮都要更换, SimPO 省去这一步的管线收益是实质性的 (1.2.5 节).
起点模型: Base 还是 SFT checkpoint。 第三个条件是偏好训练从哪里出发. DPO, IPO, SimPO, KTO 都是纯偏好损失, 不含模仿项, 要求先有 SFT checkpoint: 格式没学会之前, 偏好信号里混着大量格式噪声. KTO 对此的约束比 SimPO 更硬, 因为 KTO 的隐式 reward 是相对参考策略的偏离, 参考点估计会被格式噪声直接污染 (1.2.6 节). ORPO 是唯一能从预训练 checkpoint 单阶段出发的方法: 它的损失是 $\mathcal{L}_{\mathrm{SFT}}+\lambda\mathcal{L}_{\mathrm{OR}}$, SFT 项直接模仿 chosen, 偏好项同时拉开 odds ratio (1.2.4 节). 可观察条件是上游产物: 手里只有预训练或 mid-training checkpoint, 想省掉单独的 SFT 阶段, 且偏好数据里的 chosen 质量足够高 (chosen 是模型唯一的模仿对象), ORPO 才进入候选. 已有可靠 SFT checkpoint 时, 单阶段优势消失, 选型退化为其余四个方法之间的比较.

## 2. 决策树与条件对照

三个入口条件过完, 剩下的候选一般不超过两个, 决策树只需处理末层: 损失性格与超参成本. 这一层的问题都是二选一, 每个分叉给出可观察的判据. 决策树给出的是带判据的默认选项, 并不排除其它可行方案. 每一层分叉都对应可观察条件与可复算依据, 因而「换方法」可以回溯到具体监控读数. 条件表把这些判断压缩成速查项, 依据列标出各选择成立的原因与出处.

### 2.1. 决策树

按顺序回答四个问题:

1. 数据是二元反馈吗? 是 → KTO, 结束 (1.2.6 节). 否 → 2.
2. 手里只有预训练 checkpoint 且 chosen 质量高吗? 是 → ORPO, 结束 (1.2.4 节). 否 → 3.
3. 成对数据噪声大, 或训练后期已经观察到 policy-reference divergence 失控吗? 是 → IPO (1.2.3 节). 否 → 4.
4. 参考模型的维护成本在迭代计划里显著, 或以 best-of-n 选择精度为主要评测目标吗? 是 → SimPO (1.2.5 节). 否 → DPO 作为默认基线 (1.2.2 节).

这个顺序不是随意的. 前两问处理的是结构性约束 (信号形式, 起点模型), 答错没有补救; 后两问处理的是偏好层面的选择 (稳定性优先还是简洁优先), 答错的影响限于超参调优成本. 四问全部落到可观察条件上: 数据源形态, 上游 checkpoint 类型, 噪声与 divergence 的监控读数, 迭代计划是否存在.

四问之外还有两类常见输入不进入决策树. 一类是评测指标的偏好 (刷榜或生产), 它影响的是 checkpoint 选择与评测组合, 不造成方法排除; ORPO 一篇建议任何偏好方法同时报 AlpacaEval 2 与 IFEval 两组数字, 单一胜率不足以支撑选型 (1.2.4 节). 另一类是团队熟悉度: 同样的候选里优先选实现链路最熟的那个, 调试成本常常大于方法之间的差距 (1.2.5 节).

### 2.2. 条件-方法对照表

| 可观察条件 | 方法 | 关键依据 |
| :--- | :--- | :--- |
| 二元反馈流 (点赞/审核/采纳) | KTO | 家族中唯一不消费成对数据的损失 (1.2.6 节) |
| 仅预训练 checkpoint + 高质量 chosen | ORPO | 损失内置 SFT 项, 单阶段 (1.2.4 节) |
| 噪声大 / divergence 失控 | IPO | 有限目标 gap $m=1/(2\beta)$, 超过目标反向拉回 (1.2.3 节) |
| 迭代训练 / 显式 margin 需求 | SimPO | 无参考模型, logit 平移 $\gamma$ (1.2.5 节) |
| 其余全部场景 | DPO | 推导最完整, 基线地位 (1.2.2 节) |

对照表应自上而下逐行匹配, 不用于打分. 命中第一行就不需要看后面的行; 没有任何一行命中时落在 DPO, 原因是剩余场景里它的理论对应最完整, 调试时最少意外, 并不意味着 DPO 在每个维度都最好. 「其余全部场景」这一行兜底的是最常见的组合: 成对数据, 可靠 SFT checkpoint, 参考模型成本不敏感, 无特殊评测约束. 依据列记录每项选择的验证成本: 方法条目指向对应章节的推导与手算, 方便复核条件是否成立. 这张表筛选的是特定条件下可行的方法及其证据, 不提供脱离场景的总排名.
选错代价最大的三个位置。 有三个分叉点, 选错的代价不对称地大, 值得单独标出. 第一, 数据源是二元反馈流却按成对方法设计标注管线. 代价是标注预算的整体重做: 把流式判断改造成对比较界面, 标注速度变慢, 一致性变差, 而 KTO 已经证明二元信号经过参考点饱和结构设计后, 能达到成对偏好的大部分效果 (1.2.6 节). 判据很简单: 反馈流接进来之前, 先确认它不是对子的伪装形态.

第二, 用 SimPO 从预训练模型直接起训. SimPO 不含模仿项, 是纯偏好损失, 预训练模型没见过对话模板时输出格式会退化; ORPO 一篇列出的格式退化失败模式在 SimPO 下同样存在, 且没有任何损失内的机制兜住 (1.2.4 节, 1.2.5 节). 判据: 起点模型是否通过固定 prompt 集上的模板稳定性检查, 没通过就不能跳过 SFT 阶段.

第三, 在 KTO 下直接沿用默认类别权重处理高度不平衡的二元数据. 配比约束 $\lambda_D n_D/(\lambda_U n_U)\in[1,3/2]$ 被违反时, 少数类梯度主导训练, 单条坏样本的标注噪声被同步放大: 类别比 9:1 时按约束反解需要 $\lambda_U\approx 6\lambda_D$ (1.2.6 节的配比手算). 判据: 数据侧的类别比与权重反解, 在配置训练之前完成, 且调完权重后回看梯度推导确认两类梯度尺度比与预期一致.

## 3. 相邻方法的边际差别

选型的末层是损失形状. 五个方法各自改变一个主要公式项, 每对相邻方法都可以在同一对偏好样本上做定量对照, 同时保持数据形态与 reference 条件不变. 对照的排法按差异来源分组: 3.1 与 3.2 处理共享参考模型与否的两对 (DPO-IPO 共用一个参考模型, ORPO-SimPO 都不要), 3.3 处理信号形式的分界, 3.4 处理同名超参的口径差异, 3.5 处理有限目标的两种实现. 每组对照给出一组可复算的数字, 数字全部来自姊妹篇已有的手算或按公式直接推导.

### 3.1. DPO 与 IPO: 同一 margin 下的梯度对照

把网络暂时压缩成单个标量 gap $h$ (policy 与 reference 的序列 log-ratio 差), 两种损失写作 $L_{\mathrm{DPO}}(h)=-\log\sigma(\beta h)$ 与 $L_{\mathrm{IPO}}(h)=(h-1/(2\beta))^2$ (1.2.3 节). 取 $\beta=0.5$, IPO 目标 $m=1$, 同一组 $h$ 位置上:

| $h$ | $L_{\mathrm{DPO}}$ | $\partial L_{\mathrm{DPO}}/\partial h$ | $L_{\mathrm{IPO}}$ | $\partial L_{\mathrm{IPO}}/\partial h$ |
| ---: | ---: | ---: | ---: | ---: |
| $-1$ | $0.974$ | $-0.311$ | $4$ | $-4$ |
| $0$ | $0.693$ | $-0.250$ | $1$ | $-2$ |
| $1$ | $0.474$ | $-0.189$ | $0$ | $0$ |
| $2$ | $0.313$ | $-0.134$ | $1$ | $2$ |

DPO 的导数在所有有限 $h$ 处都为负: 排序正确的 pair 只要还没把 margin 推到无穷, 损失就在持续下降, 这就是 DPO 训练久了 KL 散度激增, 生成分布退化的动力来源 (1.2.2 节, 1.2.3 节). **IPO 在 $h=m$ 处导数为零, 超过后导数变正, 梯度下降把 gap 往回拉**, 相当于给优化装了一个有限停止点, 这是「数据噪声大选 IPO」这条决策依据的机制面.

注意这张表的读法边界. 它揭示的是单 pair 的监督几何, 不能直接用来断言 IPO 的网络更新一定比 DPO 大或小: 真实梯度还要乘 $\nabla_\theta h$, learning rate 与 batch reduction 也不同 (1.2.3 节的告诫). 更不能据此认为 IPO 自动更稳: 平方损失对异常残差没有界, $h=-20$, 目标为 $1$ 时单样本导数为 $-42$, 同位置 DPO 的标量导数幅度最多接近 $\beta=0.5$. 选 IPO 的真正判据是数据噪声水平与残差尾部是否可控, 不是稳定性直觉.

### 3.2. ORPO 与 SimPO: 同一分数对的 logit 对照

ORPO 与 SimPO 都不需要参考模型, 差别集中在分数变换: ORPO 用优势比, $\log\mathrm{odds}(y)=\log P(y)-\log(1-P(y))$; SimPO 用裸的长度归一化平均分数 (1.2.4 节, 1.2.5 节). 取同一对偏好样本, 模型给出的几何平均分数 $s_w=-0.5$, $s_l=-2.0$: SimPO 的 logit (平移 $\gamma$ 之前) 正比于 $s_w-s_l=1.5$; ORPO 的 log-odds 差逐项算, $\log\mathrm{odds}(-0.5)=-0.5-\log(1-e^{-0.5})\approx-0.5+0.934=0.434$, $\log\mathrm{odds}(-2.0)=-2.0-\log(1-e^{-2})\approx-2.0+0.145=-1.855$, 所以 $\Delta\approx2.289$ (1.2.5 节的同一算例). 同一对样本, ORPO 的 logit 比 SimPO 大 $0.79$, 因为 odds 变换的导数 $d\log\mathrm{odds}/ds=1/(1-e^s)$ 恒大于 $1$ 且随 $s\to0$ 发散: 在 $s=-0.5$ 处因子约 $1/(1-0.607)\approx2.54$, 在 $s=-2.0$ 处约 $1/(1-0.135)\approx1.16$, 而 SimPO 对单位分数差的响应恒为 $1$ (1.2.4 节). 两个方法对低分端对子的解读不同: ORPO 认为被 rejected 明显更差的回答要被更强地推开, SimPO 对所有分数差一视同仁. 这个分歧没有先验答案, 实践上表现为两种方法的胜负随偏好数据的噪声结构翻转.

工程侧的对照同样具体. ORPO 要处理 $\log(1-e^s)$ 在 $s$ 接近 $0$ 时的灾难性消减, 官方实现用分段 `log1mexp` 稳定化, 且 $s$ 至少要按 float32 计算 (1.2.4 节); SimPO 的表达式里没有这一项, 半精度下直接算平均 log 概率即可, 复现代码量大约是 ORPO 的一半 (1.2.5 节). ORPO 还多一个 SFT 项和权重 $\lambda$, 官方实现与其他复现普遍报告 $\lambda$ 敏感 (1.2.4 节), 这构成 SimPO 在超参维度上的一笔真实优势.
DPO 与 KTO: 信号形式与梯度权重形状。 DPO 与 KTO 共享隐式 reward 定义 $r_\theta(x,y)=\log[\pi_\theta(y|x)/\pi_{\mathrm{ref}}(y|x)]$ 与参考模型, 差别在信号形式: DPO 用对子内的相对比较, KTO 用单样本相对 KL 参考点 $z_0$ 的绝对判断, $z_0$ 在实现里带 stopgrad (1.2.6 节). 梯度权重形状因此完全不同: DPO 的权重 $\sigma(-z)$ 随 logit 单调下降, 排序越正确的 pair 权重越接近零; KTO 的权重 $\beta\sigma(\beta\delta)(1-\sigma(\beta\delta))$ 是以参考点为中心的钟形, $\delta=0$ 处取峰值 $\beta/4$, 两端同时衰减 (1.2.6 节).

用数字把形状差异压实. KTO 取 $\beta=0.5$, $z_0=1.0$, 三条 desirable 样本的 $r_\theta$ 分别为 $0.2,1.0,3.0$, 梯度因子依次约为 $0.120,0.125,0.098$, 最大与最小只差 $30\%$ (1.2.6 节的手算). 同一尺度的对照下, DPO 的权重从 logit $0$ 处的 $0.5$ 降到 logit $4$ 处的 $0.018$, 相差约 $28$ 倍. KTO 把训练预算分给「离参考点最近」的样本, DPO 分给「排序错误」的样本, 两种分配对数据的利用策略不同, 对噪声数据的耐受也不同.

选择判据回到数据. 有现成对子时 DPO 的信号更强, 比较判断比绝对判断信息量大, KTO 一篇给出的用法是: 只有二元信号, 或对子构造成本不可接受时, KTO 才是默认选项 (1.2.6 节). 反过来, 对子可以拆解成二元样本喂 KTO, 换来数据量翻倍, 但要接受比较信息的损失, 且同一 prompt 的两条样本必须按 group 打散, 否则等于给该 prompt 双倍权重 (1.2.6 节). 不少「KTO 不如 DPO」的复现结论, 追溯到最终都是这个打散没做.
DPO 与 SimPO: β 量级与梯度响应。 DPO 与 SimPO 的损失同形, 都是 $-\log\sigma$ 套一个分数差, 但 $\beta$ 的量级差一到两个数量级: DPO 常用 $\beta\approx0.1$, SimPO 用 $\beta=10$ 搭配 $\gamma=0.5$ (1.2.5 节). 这不是笔误, 是归一化口径的结构差异: DPO 的 logit 是 $\beta$ 乘两个序列总分的差, 总分随长度累积, $\beta$ 负责压住长度; SimPO 的 logit 基于平均每 token 分数, $\beta$ 的任务变成给零点几的平均分数差赋予区分度.

量级差异直接改变训练手感. 同一对子, 模型把 chosen 的平均分数推高 $0.1$: DPO 的 logit 相应只移动约 $\beta\times0.1\approx0.01$ 量级 (总分口径下的同比例移动), 权重几乎不动; SimPO 的 logit 移动 $1.0$, 权重从 $0.5$ 降到约 $0.18$, 响应快一个数量级 (1.2.5 节末尾的对照). SimPO 对「已经推过的对子」更快放手, 对「还没推的」更用力, 曲线形态比 DPO 更陡.

由此得到一个可执行的调参约束: $\beta$ 与 $\gamma$ 不独立. $\beta$ 只缩放 $\Delta r$ 不缩放 $\gamma$, 把 $\beta$ 翻倍等价于把有效 margin 减半, 调参时应固定比值 $\gamma/\beta$ 扫尺度, 复现论文配置先在 $\gamma/\beta\in\{0.05,0.1,0.2\}$ 附近扫 (1.2.5 节). 反过来, 把 DPO 的 $\beta=0.1$ 直接搬进 SimPO, 所有 logit 挤在 $\pm0.3$ 以内, $\gamma$ 几乎不起作用, 训练退化成接近不加权的排序回归 (1.2.5 节). 同名超参背后的尺度口径, 是跨方法复现时最容易踩的错位.
IPO 与 SimPO: 有限目标的两种实现。 IPO 与 SimPO 都给偏好 gap 设了有限目标, 实现方式不同. IPO 的目标藏在损失形状里: $(h-m)^2$ 在 $h=m$ 两侧对称, 超过目标的 gap 会被导数为正的部分拉回, 拉回强度随残差线性增长 (1.2.3 节). SimPO 的目标藏在 logit 平移里: $-\log\sigma(\Delta r-\gamma)$ 在 $\Delta r=\gamma$ 处梯度权重恰好是 $0.5$, 超过后权重平滑衰减, 但不衰减到零, 也不回拉. 同一个「别停在排序正确」的意图, 一个用回归的拉回实现, 一个用饱和曲线的右移实现.

这个差别在训练手感上表现为: IPO 对超过目标的样本施加反向梯度, 多 epoch 复用已见 pair 时, margin 被主动压回目标附近; SimPO 只是让已排序样本的权重变小, 长尾梯度仍在, 已排序对子内部的间隔分布还有机会被继续微调 (1.2.5 节). 选型判据: 数据噪声大, 担心模型把已见 pair 的 margin 推过头, 选 IPO 的硬拉回; 数据干净, 希望训练后期仍利用已排序对子做精修, 选 SimPO 的软衰减. 两组的共同约束是目标尺度 ($m$ 或 $\gamma$) 不能超过模型实际能拉开的间隔, 否则大量样本永远停在强梯度区, 训练不收敛 (1.2.3 节, 1.2.5 节).

## 4. 超参与实现约定对照

选定方法之后, 落地前还要对齐三个口径: $\beta$ 与 $\gamma$ 的尺度, 数值稳定的实现约定, 训练监控指标. 每个方法的默认约定不同, 混用会产生表面同名, 尺度不同的结果 (1.2.3 节的告诫). 这三个口径的对齐是一次性工作, 应该在第一次训练之前完成并记录: 求和还是平均, 参考缓存绑定的版本指纹, 每条指标的数据来源与归约方式. 口径没对齐之前跑出来的跨方法对比数字, 后面要花几倍的时间排查是不是尺度错位造成的假象, 排查成本远高于事前核对.

### 4.1. β 与 γ 的口径对照

DPO 的 $\beta$ 源自 KL 正则目标, 表示偏离参考策略的代价, 常用量级 $0.1$; 改 $\beta$ 同时改变 logit 尺度与单步梯度, 但训练后的 policy 随之改变, 不能只凭单步梯度断言较大 $\beta$ 一定产生更强偏离 (1.2.2 节). IPO 的目标 $m=1/(2\beta)$, $\beta=0.1,0.5,1$ 分别对应 $m=5,1,0.5$, 序列口径下 $h=5$ 约等于 chosen/rejected 概率比相对参考的 $148.4$ 倍 (1.2.3 节); 同名 $\beta$ 从 DPO 搬来, 目标 gap 差出几十倍, 所以 DPO 的最佳 $\beta$ 不能凭参数名直接复用.

SimPO 的 $\beta=10$ 配 $\gamma$ 按模型调节, $\gamma$ 的上界是模型实际能拉开的间隔, 超过后大量样本永远停在强梯度区不收敛 (1.2.5 节). KTO 的 $\beta$ 决定钟形权重带的宽度, 半峰值带宽约 $4.4/\beta$: $\beta=0.5$ 时带宽约 $8.8$, 几乎覆盖 reward 分布的常见宽度, 这解释了 KTO 手算里权重差异小的现象; $\beta$ 翻倍带宽减半, 训练对参考点位置更敏感 (1.2.6 节). 调 $\beta$ 时可以用 $4.4/\beta\gtrsim w$ 缩小搜索范围, $w$ 是 pilot run 里测得的 reward 分布半宽, 下界通常取上界的 $1/4$ 到 $1/2$ 起步扫 (1.2.6 节).

### 4.2. 数值稳定与实现约定

ORPO 的实现要处理 $\log(1-e^s)$ 在 $s\to0$ 时的消减: 分段算法在 $s<-\log 2$ 用 `log1p(-e^s)`, 否则用 $\log(-\texttt{expm1}(s))$, 分界点 $-\log 2\approx-0.693$ 保证两个分支都有足够有效数字; 半精度下 $1-e^s$ 在 $s>-0.01$ 就没有足够有效位数, 所以 $s$ 至少要按 float32 计算 (1.2.4 节). 出现 $s\ge0$ 时 `log1mexp` 返回 NaN, 空回复应在数据清洗阶段剔除, 不留给损失函数处理. KTO 的实现约定是 stopgrad: 参考点 $\hat z_0$ 参与决定每条样本落在 S 形的哪个位置, 但不接收梯度, 否则「移动参考点本身」会成为一条隐蔽的优化通道, 模型可以让所有样本的 log-ratio 一起上升来抬高 $\hat z_0$, 绕开逐样本监督 (1.2.6 节). 漏掉 stopgrad 不会报错, 只会悄悄训歪, 而日志表面一切正常. $\hat z_0$ 本身由循环移位错配对估计, 带 $\max(0,\cdot)$ 的正偏, 是工程近似不是精确 KL, 解读日志时不应当精确 KL 对待 (1.2.6 节).

SimPO 与 IPO 的实现约定在长度归一化的位置. SimPO 传总 log 概率与长度, 归一化在损失内完成; 分母误用 batch 内最长序列长度是最常见的实现错误, 会把短回复倾向反转成长回复倾向, 症状隐蔽 (1.2.5 节). IPO 在 TRL v0.23.1 的实现里把回答 log-prob 除以有效 token 数, 与论文的序列求和口径不同, $\beta$ 的合理值随之改变, 长度平均口径下 $e^{\bar h}$ 也不能直接当成完整序列概率比的相对变化 (1.2.3 节). 同一方法换框架复现时, 先核对求和还是平均, 再谈超参.
监控指标的选择。 每个方法至少要盯的指标不同, 抄同一套监控表会漏掉各自的退化信号. DPO 与 IPO 共享的基础集: 训练与 held-out 的 preference log loss (不只看 accuracy), policy-reference divergence 的估计, 生成回答的盲评胜率与长度分布 (1.2.2 节, 1.2.3 节). DPO 特有的观察点是隐式 reward margin 在多 epoch 下的持续右移: pair accuracy 饱和后继续训练, 只是把已见 margin 推得更大, checkpoint 选择在 accuracy 饱和处附近收 (1.2.2 节).

SimPO 需要额外记录 $\Delta r$ 分布的分位数和固定 prompt 集上的平均生成长度. P50 落在 $\gamma$ 附近通常表示 margin 匹配, P10 长期为负表示模型持续放弃一部分难样本; 平均长度则能发现 loss 下降同时发生的短回复退化 (1.2.5 节). ORPO 应按训练阶段观察 $\Delta$ 分布, 因为同一个 $\lambda$ 在早期与晚期的实际强度不同 (1.2.4 节). KTO 要单独记录 $\hat z_0$: 它不接收梯度但会随训练漂移 (1.2.6 节).

这些指标还要配停止条件, 不以 training loss 最小作为停止线. 更合适的联合条件是: held-out pair loss 不再改善, 固定 prompt 上的独立生成胜率达到平台, policy-reference divergence 仍在可接受范围, 通用能力与安全切片没有明显回退 (1.2.3 节的停止条件). 训练 loss 继续下降而生成胜率下降时, 优先怀疑离线过拟合, 分布漂移或评测口径, 而不是继续训练等待反弹.
数据侧的配套要求。 损失选完, 数据侧还有三个配套要求与选型结论绑定. 第一, rejected 的质量: SimPO 与 ORPO 的分数没有参考基线, rejected 如果差得离谱, 拉开它的分数几乎不消耗训练预算, 这类样本在早期失效; 构造数据时应让 rejected 是有竞争力的次优答案, hard negative 的占比直接决定训练后期还有没有用 (1.2.5 节). 第二, 长度分桶: SimPO 的梯度里写着 $\beta/|y|$, 长短对子混合不均时有效 batch 被短对子主导, 缓解办法是按长度桶采样或分桶记录损失曲线 (1.2.5 节); KTO 不做长度归一化, 长回复天然有更大的 $|r_\theta|$, 长度差大的数据要先在数据侧配平 (1.2.6 节).

第三, 训练/验证的切分粒度: 按 pair 随机切分最容易泄漏, 同一 prompt 的候选组产生的多条边同时出现在训练与验证中, 模型只需记住回答特征就能得到很高的验证分; 应按 prompt 或完整 candidate group 切分, 验证集再分固定离线 pair, 固定 prompt 重新生成, 反事实切片三层 (1.2.3 节). 这三个要求不进决策树, 但任何一个没做, 方法差异都可能被数据问题盖掉. 数据管线的优先级仍然高于损失函数.

## 5. 训练失效与串行组合

末层是风险管理: 每种方法在各自的高危条件下以可预测的方式失效, 失效症状与报警指标都有出处. 选型时把「谁先失效」作为小规模扫描的验收标准, 比直接复用论文超参稳 (1.2.4 节的建议). 这一层的内容在选型之前读一遍即可, 真正使用时它是一份验收清单: 小规模扫描每个候选方法, 观察各失效模式里谁先出现, 出现的位置就是该方法在你的数据与基座下的真实边界, 也回答了「要不要为它付出对应的超参与监控成本」.
各方法的失效模式与报警指标。 DPO 最常见的失效是 KL 激增与生成分布退化, 原因是 sigmoid 损失在有限 margin 处仍可继续下降 (1.2.3 节). 应联合监控 policy-reference divergence 与生成多样性. IPO 则会放大极端残差: 平方损失对异常样本没有界, 错标 pair 或 mask 错误产生的巨大负残差会主导整个 batch (1.2.3 节). 需要检查残差 $h-m$ 的直方图与尾部; 均值接近零不代表方差小. 梯度裁剪与样本检查可以缓解异常, 换成 Huber 类损失后则不再是原始 IPO 目标.

ORPO 列出三种失败模式: 格式退化 (偏好数据覆盖不全对话模板时), 过度自信 (odds 梯度因子在高置信区放大, 生成长度塌缩或多样性骤降), 已排序样本空转 (梯度权重饱和后继续训练只是空转, 按 loss plateau 定 epoch 会严重过度训练) (1.2.4 节). SimPO 的已知批评是短回复倾向, 机制有二: 短回复每个 token 的梯度被 $\beta/|y|$ 放大, 平均分数随长度方差收缩使「变短」成为低阻力优化方向 (1.2.5 节). KTO 的弱点是参考点估计的方差直接进梯度, batch 小时训练曲线比 DPO 毛糙, 缓解是调大 microbatch 或对 $\hat z_0$ 做滑动平均 (1.2.6 节).

### 5.2. KTO 打底, DPO 收尾的串行用法

五个方法不是互斥选项, 实践中可以串行. KTO 一篇给出的组合是: 先用海量的二元信号 (点赞, 采纳) 做 KTO 打底, 再用少量精标对子做 DPO 收尾 (1.2.6 节). 依据是信号强度排序: 比较判断的信息量大于绝对判断, 把信息密度高的数据放在训练后期, 模型先获得广覆盖的粗略偏好, 再学习精排.

工程上两类损失共享 policy 与 reference 的前向管线, 按 step 交替或按样本路由, 把已有 DPO 训练器改造成 KTO 训练器的工作量大约一个工作日, 其中参考点 stopgrad 的核对占一半 (1.2.6 节). 数据侧的衔接点有两个: 从对子拆二元样本时按 prompt group 打散, 避免同 prompt 双倍权重; 第二轮 DPO 的参考模型可以沿用 KTO 阶段的参考, 也可以把 KTO 产出的策略设为新参考, 两者不是同一目标, 更换后所有参考缓存必须重算 (1.2.2 节).

迭代轮数是不取决于损失函数的独立决策. on-policy 数据能缓解离线分布偏移, 但实践里迭代两轮以上收益递减明显, 第二轮的增益通常不到第一轮的一半 (1.2.5 节). 是否迭代取决于采样与标注成本: 采样与标注便宜就多迭代几轮, 贵就停在两轮以内, 这个判断与选哪个方法无关. 另一条新管线路线是把 SimPO 作为首个实验对象: 五个方法里它的实现最短, 数值最稳, 超参最少, 先用它把数据管线与评测管线跑通, 再决定是否有必要为 DPO 的参考约束或 ORPO 的单阶段能力付出复杂度 (1.2.5 节). 从一个已知能 work 的最简基线出发加组件, 比从复杂基线出发删组件, 调试成本低得多.

选型实验还应固定数据预算而非只固定 epoch. 不同方法对单条样本的使用方式不同: DPO、IPO、SimPO 与 ORPO 消费成对样本, KTO 消费单标签样本. 把一个偏好对拆成两个 KTO 样本后, 若仍按相同 epoch 比较, KTO 实际经历的优化样本数会改变. 公平口径可以固定有效回答条数、模型前向 token 或总 GPU 时, 并把另一种口径作为补充. 只有训练预算对齐, 方法之间的收益和成本才可同时比较. 报告中还应给出每种方法达到最佳 checkpoint 前消费的预算. 最终分数相同但收敛速度不同, 对需要频繁更新数据的业务会产生完全不同的迭代成本; 只比末步会漏掉这一差异.

串行训练还要处理参考分布的切换. 若 DPO 阶段继续使用最初的 SFT reference, KTO 与 DPO 的 KL 坐标保持一致, 但第二阶段策略可能已经离 reference 较远; 若改用 KTO checkpoint 作为新 reference, DPO 比较的是第二阶段的局部变化, 所有缓存 log-prob 都必须重算. 两种方案没有可互换的 $\beta$ 数值. 对照实验应分别记录起点 KL、训练后 KL 与生成长度, 才能判断收益来自偏好信号还是参考模型重置.

## 6. DPO 怎样从 KL 约束强化学习中出现

### 6.1. 带参考策略的最优策略

对提示 $x$，经典 RLHF 目标可写为
$$
\max_{\pi}\;\mathbb E_{y\sim\pi(\cdot\mid x)}[r(x,y)]
-\beta D_{\mathrm{KL}}\!\left(\pi(\cdot\mid x)\|\pi_{\mathrm{ref}}(\cdot\mid x)\right).
$$
第一项推动高奖励回答，第二项限制策略远离参考模型。对每个 $x$，再加概率归一约束 $\sum_y\pi(y\mid x)=1$。拉格朗日函数为

$$
\mathcal L=\sum_y\pi(y\mid x)r(x,y)
-\beta\sum_y\pi(y\mid x)\log\frac{\pi(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}
+\lambda\left(\sum_y\pi(y\mid x)-1\right).
$$
对 $\pi(y\mid x)$ 求导并令其为零：

$$
r(x,y)-\beta\left(\log\frac{\pi(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}+1\right)+\lambda=0.
$$
整理得到

$$
\pi^*(y\mid x)=\frac{1}{Z(x)}\pi_{\mathrm{ref}}(y\mid x)
\exp\left(\frac{r(x,y)}{\beta}\right),
$$
其中 $Z(x)$ 吸收归一化常数。反解奖励：

$$
r(x,y)=\beta\log\frac{\pi^*(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}
+\beta\log Z(x).
$$
对同一提示的两个回答做差时，$\beta\log Z(x)$ 消失。DPO 的关键就在这里：偏好模型只需要奖励差，归一化常数无需显式求解，策略与参考策略的对数概率比可以直接充当隐式奖励。

### 6.2. 从 Bradley–Terry 到 DPO 损失

Bradley–Terry 假设偏好概率由奖励差的 logistic 函数决定：
$$
P(y_w\succ y_l\mid x)=
\sigma\left(r(x,y_w)-r(x,y_l)\right).
$$
把上节反解的奖励代入，得到

$$
P(y_w\succ y_l\mid x)=\sigma\left(\beta\left[
\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\mathrm{ref}}(y_w\mid x)}
-\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\mathrm{ref}}(y_l\mid x)}
\right]\right).
$$
记策略相对参考的偏好 margin 为

$$
h_\theta=\log\pi_\theta(y_w\mid x)-\log\pi_\theta(y_l\mid x)
-\log\pi_{\mathrm{ref}}(y_w\mid x)+\log\pi_{\mathrm{ref}}(y_l\mid x),
$$
对偏好标签做最大似然便得到

$$
L_{\mathrm{DPO}}=-\log\sigma(\beta h_\theta).
$$
这条推导包含几项强假设：偏好可由单一标量效用表示；不同 pair 的判断噪声服从相同 logistic 尺度；数据对在给定提示后可以按该模型解释；训练策略的最优形式仍围绕固定 reference。现实标注者可能偏好不可传递，安全性与帮助性也未必能压成同一个标量。
β 到底控制什么。 在 RL 目标里，$\beta$ 是 KL 惩罚系数，越大越不愿偏离 reference。进入 DPO logistic 后，$\beta$ 又缩放 margin。固定当前 $h$ 时，更大的 $\beta$ 让 sigmoid 更快饱和；固定数据与充分优化后的隐式奖励关系时，它仍对应更强的参考约束。只看单步梯度容易得出相反直觉，必须区分局部优化尺度与最终策略几何。 梯度对 margin 为
$$
\frac{\partial L}{\partial h}=-\beta\sigma(-\beta h).
$$
$h=0$ 时梯度为 $-\beta/2$；$h\gg0$ 时趋近零；$h\ll0$ 时接近 $-\beta$。因此错排 pair 获得近似最大推力，已正确拉开的 pair 逐渐退出训练。$\beta$ 同时改变最大梯度与饱和速度，调它时学习率往往需要联动。

### 6.3. Bradley–Terry 假设与参考策略

不可传递偏好. 标量奖励要求偏好大体可传递：若 A 胜 B、B 胜 C，A 应倾向胜 C。真实数据可能存在循环。回答 A 简洁，B 更完整，C 更安全；不同标注者按不同维度选择，汇总后可能得到 A 胜 B、B 胜 C、C 胜 A。任何单一 reward 都无法同时满足三条严格不等式。 DPO 面对循环时会寻找折中 margin。loss 可以下降，却不会得到所有 pair 都正确的策略。若训练集 pair accuracy 长期卡住，先按 prompt 与评价维度寻找偏好环，不要立刻增加模型容量。 一个可操作检验是在同一 prompt 的候选图上找三角循环，报告循环率，并按标注者拆分。单个标注者循环少、合并后循环多，说明人群偏好异质；同一标注者也大量循环，可能是准则含混或候选差异太小。

循环给出了单标量模型无法消除的损失下界。令三个候选的效用为 $u_A,u_B,u_C$，三条硬标签依次为 $A\succ B$、$B\succ C$、$C\succ A$。对应 margin 为
$$
m_1=u_A-u_B,\qquad m_2=u_B-u_C,\qquad m_3=u_C-u_A,
$$
因此恒有 $m_1+m_2+m_3=0$。三条边不可能同时为正。若三条边同权，损失
$$
L=\log(1+e^{-m_1})+\log(1+e^{-m_2})+\log(1+e^{-m_3})
$$
在约束 $m_1+m_2+m_3=0$ 下于 $m_1=m_2=m_3=0$ 取最小值 $3\log2$。模型给三场比较都报 $0.5$，原因是标量效用无法表示这组循环数据，与模型容量无关。把三条标签各复制十次，只会把最小损失放大十倍，不会让最优排序更明确。 有投票比例时可以直接检查循环的 log-odds。若三条边的胜率都为 $0.8$，每条边要求的效用差都是 $\log(0.8/0.2)\approx1.386$，绕环求和应为零，观测和却是 $4.159$。这个“环流残差”不会被任何候选的加性分数解释。实际数据可先按 prompt 构图，把每条边的 log-odds 投影到候选分数差，再把剩余残差按三角环或强连通分量汇总。残差集中在安全与帮助冲突的边，适合改成带评价维度的条件偏好；残差集中在少数标注者，适合建标注者随机效应；全局均匀出现才更像准则本身含混。

循环率也不能只用“存在循环的三角形数/全部三角形数”。候选数一多，绝大多数三元组没有完整标注，缺边会把循环率机械压低。更稳妥的报告同时列出：完整三角形中的循环比例、参与至少一个循环的边比例、删除最少多少总权重才能得到无环图。最终一项直接估计“必须牺牲多少偏好证据才能形成全序”，比单个 pair accuracy 更接近标量奖励假设的破裂程度。 同质噪声假设. Bradley–Terry 把所有 pair 的判断噪声放在同一温度里。实际 easy pair 的偏好几乎确定，两个近似答案的偏好接近抛硬币。用同一个 logistic 尺度训练，会给模糊 pair 过高置信度。 若有多标注者票数，可把软标签 $q=P(y_wwins)$ 直接用于交叉熵：
$$
L=-q\log\sigma(\beta h)-(1-q)\log\sigma(-\beta h).
$$
其最优有限 margin 满足 $\sigma(\beta h)=q$，即
$$
h^*=\frac1\beta\log\frac{q}{1-q}.
$$
$q=0.6$ 时目标 margin 很小；硬化成 $q=1$ 会要求 margin 无限增长。保留标注分歧能减少过度自信。 位置与长度混淆. 若 chosen 总放在左侧，标注者存在位置偏好，模型会把位置造成的标签差当内容效用。数据收集时交换显示顺序，并保存顺序字段，便能估计位置效应。训练数据只保留最终 chosen/rejected 而删掉展示顺序，后续无法校正。 长度也会与偏好相关。标注者可能偏爱更详细的回答，或因阅读疲劳偏爱短回答。DPO 使用整序列 log-prob 总和，长度本身还进入模型 margin。数据偏好与目标几何叠加后，长度效应可能很强。
reference policy 的四重作用。 坐标原点. DPO 学习的量是 chosen 相对 reference 的改善超过 rejected 的幅度：
$$
\Delta_\theta=\left(\log\pi_\theta(y_w)-\log\pi_{\mathrm{ref}}(y_w)\right)
-\left(\log\pi_\theta(y_l)-\log\pi_{\mathrm{ref}}(y_l)\right).
$$
若 reference 本来就强烈偏好 chosen，策略只需维持这一差距，$\Delta$ 未必大。若 reference 错得很深，策略必须跨过更大相对 margin。换 reference 会改变每条 pair 的训练难度，旧的 $\beta$ 与缓存 log-prob 都不再可比。 隐式先验与覆盖边界. reference 给低概率的回答，策略若要提高它，log-ratio 会很大。KL 正则下，策略更容易在 reference 已有覆盖的区域重新排序，很难凭离线偏好学出 reference 几乎不会生成的新行为。DPO 的稳定性部分来自这种保守性，也意味着 base 模型覆盖不足时先做 SFT 往往必要。 从 base 直接 DPO，chosen 回答可能处于极低概率区，序列 log-prob 数值很差，梯度集中于少数 token。SFT 起点先把数据支持移到偏好回答附近，DPO 再做相对排序，通常更符合推导里的局部策略改进。 固定 reference 与刷新 reference.

固定 reference 让整个训练过程使用同一坐标，便于缓存 log-prob。多轮迭代若把上一轮策略设为新 reference，每轮只约束局部变化，总体偏移可以逐轮累积。它类似多次小步信赖域更新，却不能保证最终仍接近初始 SFT。 刷新后应重新计算所有 reference log-prob。沿用旧缓存会让 chosen 与 rejected margin 混合两个 reference，目标失去清晰含义。对照实验应同时报告相对当前 reference 与相对最初 SFT 的 KL。 局部约束无法自动推出全程约束。设第 $k$ 轮策略为 $\pi_k$，并令 $\pi_{k-1}$ 成为新 reference，则任一回答的累计 log-ratio 满足望远镜恒等式
$$
\log\frac{\pi_K(y\mid x)}{\pi_0(y\mid x)}
=\sum_{k=1}^{K}\log\frac{\pi_k(y\mid x)}{\pi_{k-1}(y\mid x)}.
$$
每轮变化虽小，方向一致时仍会累积。二元回答的玩具例子中，初始概率为 $(0.5,0.5)$，每轮把第一项的 odds 乘 $e^{0.4}$。五轮后第一项概率从 $0.5$ 变成 $\sigma(2)\approx0.881$；每轮只移动约 $0.05$ 到 $0.10$，最终相对初始分布已经明显偏斜。KL 本身没有同样的简单可加性，所以不能把五个局部 KL 相加冒充总 KL；应从固定锚点重新计算 $D_{\mathrm{KL}}(\pi_K\|\pi_0)$。

reference 漂移还会改变样本难度的构成。旧 reference 下的 hard pair 在新 reference 下可能已经是 easy pair，另一些边则从正 margin 变成负 margin。每轮开训前应在同一冻结诊断集上同时计算 $h^{(k-1)}$ 与 $h^{(0)}$，画二维分桶：横轴是相对当前 reference 的 margin，纵轴是相对初始 SFT 的 margin。横轴改善而纵轴持续恶化，说明局部训练在移动坐标中看似稳定，累计方向却偏离锚点。 奖励能识别到什么程度. 偏好数据只识别同一 prompt 内的奖励差。对任意函数 $c(x)$，令
$$
r'(x,y)=r(x,y)+c(x),
$$
则 $r'(x,y_w)-r'(x,y_l)=r(x,y_w)-r(x,y_l)$，Bradley–Terry 概率完全不变。在 KL 正则最优策略中，$c(x)$ 只把归一化常数 $Z(x)$ 乘上 $e^{c(x)/\beta}$，策略也不变。因此“回答在提示 A 上奖励为 8、提示 B 上为 5”没有跨提示含义；可识别对象是提示内差值与排序。 尺度也与温度纠缠。把奖励和 $\beta$ 同时乘正数 $a$，指数倾斜中的 $r/\beta$ 不变；Bradley–Terry 若另有噪声温度 $\tau$，数据只识别 $r/\tau$。论文或代码中的 reward 数值翻倍，若温度口径也变了，策略几何可能一毫米都没动。比较实验必须固定温度约定，或报告无量纲的偏好 logit，而不能把隐式奖励绝对值当作可跨实现指标。

比较图不连通时，不可识别性更强。假设同一 prompt 有候选集合 $\{A,B\}$ 与 $\{C,D\}$，数据只比较 A/B 和 C/D，从未跨组比较。两组效用各自都可加不同常数，A 与 C 谁更好没有证据。即使图连通，数据也只约束观测边附近；模型对未出现回答的分数来自参数共享和 reference 先验，不是偏好似然直接识别的结论。报告 reward calibration 时应先给比较图的连通分量、节点度数和外推候选比例。

这一区分也解释了“隐式 reward 能否复用”的边界。同一 prompt 的候选重排可以使用 $\beta\log(\pi_\theta/\pi_{\mathrm{ref}})$；跨 prompt 阈值筛选、把不同 reference 训练出的 reward 混在一起、用绝对分数触发安全动作，都额外假设了坐标可比。若业务确需跨提示分数，要引入带锚点的独立 reward model 或可验证标尺，并用共享校准样本连接各提示与各 reference 版本。
