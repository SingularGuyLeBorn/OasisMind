# Bellman 方程: 从回报递归到动态规划

MDP 定义了 trajectory distribution, Bellman equation 则利用 Markov property 把无限 future return 改写成 one-step reward 加 next-state value. 它的作用不是凭空预测未来, 而是把同一个 value object 在相邻时刻之间建立 fixed-point relation. Environment model 已知且 state space 可枚举时, 可以直接解线性方程或做 dynamic programming; model 未知时, Monte Carlo 与 Temporal Difference 再用 sample 估计这些 expectation.

本篇继续使用上一节的符号. $n=|\mathcal S|$, $m=|\mathcal A|$, $V^\pi\in\mathbb R^n$, $Q^\pi\in\mathbb R^{n\times m}$. Reward 采用 $R(s,a)=\mathbb E[R_{t+1}\mid S_t=s,A_t=a]$, transition 为 $P(s'\mid s,a)$. 若 reward 显式依赖 $s'$, 只需把 $R(s,a)$ 改成 transition 内的 $R(s,a,s')$ 加权和.

## 1. 从 return 到 Bellman expectation

Bellman expectation equation 评估一个固定 policy. 它不选择更优 action, 只把当前 policy 在每个 state 上诱导的 future return 写成 one-step recursion. 推导中最重要的动作是连续两次使用全期望: 先按 policy 对 action 求和, 再按 environment 对 next state 与 reward 求和.

这一节同时保留 state value 与 action value. $V^\pi$ 适合写 matrix fixed point, $Q^\pi$ 则把第一步 action 固定下来, 后续 policy gradient,Actor-Critic 与 control algorithm 都会使用它.

### 1.1. Value,Q 与 advantage

Return identity 为

$$
G_t=R_{t+1}+\gamma G_{t+1}.
\tag{1}
$$

固定 policy $\pi$, state value 与 action value 定义为

$$
V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s],
\tag{2}
$$

$$
Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].
\tag{3}
$$

Advantage 是

$$
A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s).
\tag{4}
$$

对固定 state, $V^\pi$ 是 action value 按 policy 的 expectation:

$$
V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a).
\tag{5}
$$

因此

$$
\sum_a\pi(a\mid s)A^\pi(s,a)=0.
$$

这个零均值关系后面会进入 policy gradient baseline 和 TRPO performance difference lemma.

### 1.2. Bellman expectation equation 逐步推导

从式 (2) 代入式 (1):

$$
V^\pi(s)
=\mathbb E_\pi[R_{t+1}+\gamma G_{t+1}\mid S_t=s].
\tag{6}
$$

先对 $A_t$ 使用全期望公式:

$$
V^\pi(s)
=\sum_a\pi(a\mid s)
\mathbb E[R_{t+1}+\gamma G_{t+1}
\mid S_t=s,A_t=a].
\tag{7}
$$

再对 next state $S_{t+1}$ 分层. Markov property 让 future return 在给定 $S_{t+1}=s'$ 后只由 $s'$ 与后续 policy 决定, 所以

$$
\mathbb E_\pi[G_{t+1}\mid S_t=s,A_t=a,S_{t+1}=s']
=V^\pi(s').
$$

代回式 (7):

$$
\boxed{
V^\pi(s)=\sum_a\pi(a\mid s)
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s')\right]
}.
\tag{8}
$$

括号内正是 $Q^\pi(s,a)$:

$$
\boxed{
Q^\pi(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s')
}.
\tag{9}
$$

再用式 (5) 消掉 $V^\pi(s')$:

$$
Q^\pi(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)
\sum_{a'}\pi(a'\mid s')Q^\pi(s',a').
\tag{10}
$$

式 (8)–(10) 是 expectation equation, 因为 action 按固定 policy 求 expectation. 它们做 policy evaluation, 没有在每个 state 选择最优 action.

### 1.3. 三层随机性怎样进入式 (8)

式 (8) 外层的 $\pi(a\mid s)$ 来自 policy randomness, 内层的 $P(s'\mid s,a)$ 来自 transition randomness, $V^\pi(s')$ 又是从 next state 开始对所有 future trajectory 的 expectation. 如果 reward 本身在给定 $(s,a,s')$ 后仍随机, 更完整的形式是

$$
V^\pi(s)=\sum_a\pi(a\mid s)
\sum_{s',r}p(s',r\mid s,a)
\left[r+\gamma V^\pi(s')\right].
\tag{11}
$$

把 reward 先求条件期望, 才能得到正文使用的 $R(s,a)$ 形式. 两个公式描述同一个 expectation, 只是 joint kernel 版本保留了 reward distribution.

Expected Bellman target 与 sampled target 也要区分. 已知 model 时, 式 (8) 枚举所有 $a,s'$ 得到精确 expectation. 与 environment 交互时只观察一个 $(a_t,r_{t+1},s_{t+1})$, target

$$
Y_t=r_{t+1}+\gamma V(s_{t+1})
$$

是对相应 Bellman quantity 的 sample estimate. 它可能高于或低于 expectation. Stochastic approximation 依靠许多 sample 和合适 update step 逼近 fixed point.

### 1.4. Reward 依赖 next state 时怎样写

有些 environment 的 reward 由到达哪里决定. 例如从同一 $(s,a)$ 出发, 到达 goal 给 $+5$, 滑回原地给 $-1$. 这时可以直接使用 joint kernel 形式式 (11), 也可以先定义

$$
R(s,a,s')=\mathbb E[R_{t+1}\mid s,a,s']
$$

再写

$$
Q^\pi(s,a)
=\sum_{s'}P(s'\mid s,a)
\left[R(s,a,s')+\gamma V^\pi(s')\right].
$$

如果改用 $R(s,a)=\sum_{s'}P(s'\mid s,a)R(s,a,s')$, 则

$$
Q^\pi(s,a)
=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s').
$$

两个口径等价, 前提是 expected reward 的 transition average 只做一次. 常见错误是在 transition sum 外写 $R(s,a,s')$, 让 $s'$ 在求和号外成为 free variable; 或者已经算出 $R(s,a)$ 后, 又给 reward 乘一次 transition probability.

Reward timing 也要固定. 本文用 $R_{t+1}$ 表示执行 $A_t$ 并进入 $S_{t+1}$ 后收到的 reward. 有些 codebase 将它记为 $r_t$. Index 改名不会改变算法, 但 trajectory tuple,return 和 bootstrap target 必须同步, 否则很容易把 reward 与错误的 state transition 对齐.

## 2. Linear system,fixed point 与 policy evaluation

固定 policy 后, Bellman expectation operator 是 affine map: reward 提供常数项, transition matrix 传播 next-state value. Finite MDP 因而可以直接解 linear system, 也可以从任意初值反复 backup. 两种方法求的是同一个 fixed point, 差别只在数值计算路径.

这一节先把 action dimension 按 policy average 掉, 得到 $P_\pi$ 与 $r_\pi$; 再证明 operator 是 contraction, 最后对三状态例子既做 linear solve 又做 iterative evaluation. Matrix shape 与逐 state equation 会逐项对齐.

### 2.1. Matrix form

对固定 policy 定义 expected reward vector $r_\pi\in\mathbb R^n$:

$$
r_\pi(s)=\sum_a\pi(a\mid s)R(s,a),
$$

以及 policy-induced transition matrix $P_\pi\in\mathbb R^{n\times n}$:

$$
P_\pi(s,s')=\sum_a\pi(a\mid s)P(s'\mid s,a).
$$

式 (8) 写成

$$
V^\pi=r_\pi+\gamma P_\pi V^\pi.
\tag{12}
$$

移项:

$$
(I-\gamma P_\pi)V^\pi=r_\pi.
$$

在 finite discounted MDP 中, $\gamma<1$ 保证 $I-\gamma P_\pi$ 可逆:

$$
V^\pi=(I-\gamma P_\pi)^{-1}r_\pi.
\tag{13}
$$

显式 inverse 适合小问题与推导, 大 state space 通常通过 iterative update 或 linear solver 求解. 定义 Bellman expectation operator

$$
(\mathcal T^\pi V)(s)=
\sum_a\pi(a\mid s)
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')\right].
$$

它在 sup norm 下是 $\gamma$-contraction:

$$
\|\mathcal T^\pi V-\mathcal T^\pi U\|_\infty
\le\gamma\|V-U\|_\infty.
\tag{14}
$$

原因是 probability weights 非负且和为 1, 加权差的绝对值不会超过最大的 component difference. 所以 fixed point 唯一, 从任意有限 $V_0$ 反复执行 $V_{k+1}=\mathcal T^\pi V_k$ 都收敛到 $V^\pi$.

### 2.2. Contraction inequality 展开

固定 state $s$, 定义 $\Delta=V-U$. Reward 项在两个 operator 中完全相同, 相减后抵消:

$$
\begin{aligned}
&|(\mathcal T^\pi V)(s)-(\mathcal T^\pi U)(s)|\\
={}&\gamma\left|
\sum_a\pi(a\mid s)\sum_{s'}P(s'\mid s,a)\Delta(s')
\right|.
\end{aligned}
$$

使用 triangle inequality:

$$
\le\gamma\sum_a\pi(a\mid s)
\sum_{s'}P(s'\mid s,a)|\Delta(s')|.
$$

每个 $|\Delta(s')|\le\|V-U\|_\infty$, 而 action probability 与 transition probability 的加权和为 1, 所以

$$
|(\mathcal T^\pi V)(s)-(\mathcal T^\pi U)(s)|
\le\gamma\|V-U\|_\infty.
$$

再对 $s$ 取 maximum 就得到式 (14). 这个证明同时解释了 reward 为什么不影响 contraction coefficient: 比较同一 MDP 上的两个 value input 时, reward 在 operator difference 中消失. $\gamma$ 决定误差从 next state 传回当前 state 时最多保留多少.

由 contraction 可直接得到 iteration error bound:

$$
\|V_k-V^\pi\|_\infty
\le\gamma^k\|V_0-V^\pi\|_\infty.
\tag{15}
$$

这是 worst-case upper bound, 实际收敛可以更快. 当 $\gamma$ 接近 1, bound 下降很慢, long-horizon reward 也更容易让 value error 传播很多步.

### 2.3. 同一个 MDP 的 policy evaluation

沿用上一节三状态环境, $\mathcal S=\{A,B,T\}$, $\gamma=0.5$. Policy 为

$$
\pi(\texttt{quit}\mid A)=0.25,
\quad
\pi(\texttt{go}\mid A)=0.75,
$$

$$
\pi(\texttt{cash}\mid B)=0.5,
\quad
\pi(\texttt{loop}\mid B)=0.5.
$$

Terminal value 为 0. 在 $B$ 上使用式 (8):

$$
\begin{aligned}
V^\pi(B)
&=0.5\times4
+0.5\times\left(1+0.5V^\pi(B)\right)\\
&=2.5+0.25V^\pi(B).
\end{aligned}
$$

所以

$$
0.75V^\pi(B)=2.5,
\qquad
V^\pi(B)=\frac{10}{3}\approx3.3333.
\tag{16}
$$

在 $A$ 上:

$$
\begin{aligned}
V^\pi(A)
&=0.25\times1.5
+0.75\times\left(0+0.5V^\pi(B)\right)\\
&=0.375+0.375\times\frac{10}{3}
=1.625.
\end{aligned}
\tag{17}
$$

这与枚举所有可能 loop 次数的 trajectory expectation 相同. Bellman recursion 把 infinite trajectory sum 收进了式 (16) 的 self-reference.

对应 matrix 为

$$
P_\pi=
\begin{bmatrix}
0&0.75&0.25\\
0&0.5&0.5\\
0&0&1
\end{bmatrix},
\qquad
r_\pi=
\begin{bmatrix}
0.375\\2.5\\0
\end{bmatrix}.
$$

$V^\pi=[1.625,10/3,0]^\top$ 代入式 (12) 可以逐行复核.

若直接用 matrix equation, 第二行是

$$
V(B)=2.5+0.5\times0.5V(B),
$$

第一行是

$$
V(A)=0.375+0.5\times0.75V(B)+0.5\times0.25V(T).
$$

这里 $P_\pi[A,B]=0.75$ 表示在 $A$ 按 policy 选择 `go` 后到达 $B$ 的 probability; `quit` 的 $0.25$ probability 进入 $T$. Reward vector 已经对 action 求过 expectation, 所以第一行不能再把 `quit` reward 重复加一次.

### 2.4. Linear system 完整手算

按 state 顺序 $(A,B,T)$, 有

$$
I-\gamma P_\pi
=\begin{bmatrix}
1&-0.375&-0.125\\
0&0.75&-0.25\\
0&0&0.5
\end{bmatrix}.
$$

Linear equation $(I-\gamma P_\pi)V=r_\pi$ 从最后一行向上解. 第三行给

$$
0.5V(T)=0\quad\Longrightarrow\quad V(T)=0.
$$

第二行给

$$
0.75V(B)-0.25V(T)=2.5
\quad\Longrightarrow\quad
V(B)=\frac{2.5}{0.75}=\frac{10}{3}.
$$

第一行给

$$
V(A)-0.375V(B)-0.125V(T)=0.375,
$$

所以

$$
V(A)=0.375+0.375\times\frac{10}{3}=1.625.
$$

每个 coefficient 都能回到 policy 与 transition. $-0.375=-\gamma P_\pi[A,B]=-0.5\times0.75$; $0.75=1-\gamma P_\pi[B,B]=1-0.5\times0.5$. Matrix solve 没有引入新的 RL 假设, 只是一次性联立所有 Bellman expectation equation.

### 2.5. Iterative policy evaluation 逐轮数值

不做 linear solve, 从 $V_0=(0,0,0)$ 同步更新也会到同一 fixed point. 第一轮:

$$
V_1(B)=2.5+0.25V_0(B)=2.5,
$$

$$
V_1(A)=0.375+0.375V_0(B)=0.375.
$$

第二轮:

$$
V_2(B)=2.5+0.25\times2.5=3.125,
$$

$$
V_2(A)=0.375+0.375\times2.5=1.3125.
$$

第三轮:

$$
V_3(B)=2.5+0.25\times3.125=3.28125,
$$

$$
V_3(A)=0.375+0.375\times3.125=1.546875.
$$

$B$ 的 scalar recursion 为 $V_{k+1}(B)=2.5+0.25V_k(B)$. Fixed point 是 $10/3$, error 每轮精确乘 $0.25$. $A$ 的更新读取上一轮 $B$, 因而慢一拍传播. General contraction bound 使用全局 $\gamma=0.5$, 给出较宽但对所有 MDP 都成立的 upper bound; 这个具体 policy 的有效 self-loop coefficient 更小, 所以实际收敛更快.

### 2.6. Inverse 的 Neumann series 解释

式 (13) 的 inverse 可以展开为

$$
(I-\gamma P_\pi)^{-1}
=I+\gamma P_\pi+\gamma^2P_\pi^2+\cdots.
$$

因为 stochastic matrix $P_\pi$ 的 spectral radius 不超过 1, $\gamma<1$ 时 series 收敛. 代入 reward vector:

$$
V^\pi
=r_\pi+\gamma P_\pi r_\pi
+\gamma^2P_\pi^2r_\pi+\cdots.
$$

第一项是当前 state 的 expected one-step reward; 第二项先按 policy transition 一步, 再取 next-state reward; 第 $k$ 项是 $k$ 步后的 expected reward. Matrix inverse 因而不是一个没有 RL 含义的代数技巧, 它把所有 future reward propagation 一次求和.

截断到前 $K$ 项就得到有限次 iterative evaluation 的展开. Tail norm 可由 geometric series 控制:

$$
\left\|\sum_{k=K}^{\infty}
\gamma^kP_\pi^kr_\pi\right\|_\infty
\le\frac{\gamma^K}{1-\gamma}\|r_\pi\|_\infty.
$$

这个 bound 使用 $\|P_\pi^k r\|_\infty\le\|r\|_\infty$. 当 $\gamma$ 接近 1, 要让 tail 很小需要更大的 $K$, 与 long effective horizon 的直觉一致.

## 3. Bellman optimality 与 policy improvement

Policy evaluation 回答「给定 $\pi$ 会得到多少 return」, optimality 则问「所有可选 policy 中哪一个最好」. 在 finite discounted MDP 中, one-step action 后的 future 可以再次按 optimal value 计算, 因而 global control problem 仍能写成 recursive equation.

从 expectation 到 max 不是一个排版替换. Operator,data requirement 与 error propagation 都随之改变. 本节先定义 optimal value, 再证明对 exact $Q^\pi$ 做 greedy improvement 不会降低任何 state 的 value.

### 3.1. Bellman optimality equation

Optimal state value 定义为

$$
V^*(s)=\max_\pi V^\pi(s).
\tag{18}
$$

在 finite discounted MDP 中, 存在 deterministic stationary optimal policy. 若 next-state optimal value 已知, 当前 state 选择让 one-step return 最大的 action:

$$
\boxed{
V^*(s)=\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^*(s')\right]
}.
\tag{19}
$$

Optimal action value 为

$$
\boxed{
Q^*(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)
\max_{a'}Q^*(s',a')
}.
\tag{20}
$$

式 (19) 的 `max` 替换了式 (8) 中按 $\pi$ 的 action expectation. 这一步改变了 operator: $\mathcal T^\pi$ 评估固定 policy, $\mathcal T^*$ 寻找 optimal fixed point, 因而任务从 policy evaluation 转向 control. 是否属于 off-policy 还取决于采样行为: 当 data 由 behavior policy 生成、target 却按 greedy policy 的 action max 计算时, 才是 off-policy control, Q-learning 就是典型例子. 如果样本始终来自当前 target policy, 仅看到 `max` 还不能推出离策略.

Optimal Bellman operator 同样是 $\gamma$-contraction:

$$
(\mathcal T^*V)(s)=\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')\right].
$$

利用 $|\max_a f_a-\max_a g_a|\le\max_a|f_a-g_a|$, 可得

$$
\|\mathcal T^*V-\mathcal T^*U\|_\infty
\le\gamma\|V-U\|_\infty.
\tag{21}
$$

因此 $V^*$ 是唯一 fixed point.

### 3.2. Policy improvement theorem

为什么对 $Q^\pi$ greedy 会得到不差于 $\pi$ 的 policy? 定义

$$
\pi'(s)\in\arg\max_aQ^\pi(s,a).
$$

由 maximum 不小于 policy average:

$$
Q^\pi(s,\pi'(s))
=\max_aQ^\pi(s,a)
\ge\sum_a\pi(a\mid s)Q^\pi(s,a)
=V^\pi(s).
\tag{22}
$$

左侧等于 $(\mathcal T^{\pi'}V^\pi)(s)$. 因而

$$
V^\pi\le\mathcal T^{\pi'}V^\pi.
$$

继续应用 monotone operator $\mathcal T^{\pi'}$:

$$
V^\pi
\le\mathcal T^{\pi'}V^\pi
\le(\mathcal T^{\pi'})^2V^\pi
\le\cdots.
$$

右侧收敛到 $\mathcal T^{\pi'}$ 的 unique fixed point $V^{\pi'}$, 所以

$$
V^{\pi'}(s)\ge V^\pi(s),\qquad\forall s.
\tag{23}
$$

若某个状态 $s$ 上 inequality 严格，且从所讨论的起点按 $\pi'$ 有正概率在有限时间到达 $s$，新 policy 在该起点才有严格改进；不可达状态上的严格优势不会改变这个起点的 value。若只讨论逐状态结论，则该状态自身作为起点已经满足可达条件。这条 theorem 支撑 policy iteration, 但依赖 exact $Q^\pi$. 用 noisy critic 做 approximate greedy 时, estimation error 可能选错 action, monotonic improvement 不再自动成立.

### 3.3. Action gap 决定 approximate greedy 是否稳

定义当前 policy value 下最优 action 与次优 action 的 gap:

$$
\Delta_\pi(s)=Q^\pi(s,a_{(1)})-Q^\pi(s,a_{(2)}).
$$

若 approximate critic 满足每个 action 的 absolute error 不超过 $\epsilon$, 两个 action 的 estimated difference 最多被扭曲 $2\epsilon$. 当 $\Delta_\pi(s)>2\epsilon$ 时, greedy ranking 在该 state 不会被这组误差翻转; gap 很小时, 很小 critic error 就能选到另一个 action.

例如 true action values 为 $(2.0,1.9)$, gap 为 $0.1$. 若第一项 estimate 偏低 $0.06$, 第二项偏高 $0.06$, estimates 变成 $(1.94,1.96)$, greedy action 被翻转. Policy improvement theorem 对 true $Q^\pi$ 仍成立, 但实现使用的是 wrong ranking.

这也是为什么只看 critic mean squared error 不够. 相同 MSE 若集中在 large-gap state, policy 可能不受影响; 若集中在 small-gap,high-occupancy state, 很多 action choice 会改变. Control evaluation 应同时观察 action agreement,advantage sign 与 state visitation weight.

### 3.4. Stochastic improvement 与 entropy

Exact greedy improvement 产生 deterministic policy, 在多个 action tie 时任取其一. 有些算法使用 soft improvement, 例如让新 policy 对较大 $Q$ 分配更高 probability, 同时保留 entropy. 这时求解的是加入 entropy regularization 的 objective, 对应 Bellman operator 会出现 log-sum-exp 或 policy entropy 项.

Soft operator 仍可以有自己的 contraction 与 fixed point, 但 fixed point 不等于式 (19) 的 unregularized $V^*$. Temperature 趋近 0 时 softmax 才接近 hard max. 将 entropy bonus 加入训练而在论文公式里仍写普通 Bellman optimality, 会把两个 objective 混在一起.

大模型 RL 中 entropy,KL-to-reference 与 reward 经常同时存在. 它们都影响 optimal policy, 作用却不同: entropy 鼓励单个 state 下 action distribution 分散, reference KL 鼓励 policy 接近指定基座, environment reward 定义 task preference. Bellman target 若要容纳这些 regularizer, 必须明确它们按 token,sequence 还是 trajectory 聚合.

### 3.5. Approximate value 会带来多大 policy 损失

设 approximate value $\widetilde V$ 满足

$$
\|\widetilde V-V^*\|_\infty\le\epsilon,
$$

并令 $\widetilde\pi$ 对 $\widetilde V$ 做 one-step greedy. 对任一 state-action, next-state value error 经过 transition expectation 与 discount 后最多为 $\gamma\epsilon$. 比较两个 action 时, 最优 action 可能被低估 $\gamma\epsilon$, 被选 action 可能被高估 $\gamma\epsilon$, 所以 one-step optimality gap 最多为 $2\gamma\epsilon$.

这个局部 gap 在后续执行 $\widetilde\pi$ 时递归传播. Discounted sum 给出经典形式的 performance bound:

$$
\|V^*-V^{\widetilde\pi}\|_\infty
\le\frac{2\gamma}{1-\gamma}\epsilon.
$$

它是 worst-case bound, 不要求每个 state 都真的达到最大误差. 但系数 $1/(1-\gamma)$ 再次说明 long horizon 会放大 value approximation 对 policy 的影响. 只报告 critic loss, 不把它换算到 action gap 或 policy quality, 很难判断误差是否重要.

如果训练 data 只覆盖部分 state, uniform $\epsilon$ 往往无法成立. 可以在 occupancy-weighted distribution 下讨论平均误差, 结论会依赖 policy 访问哪些 state. Offline setting 中 target policy 走出 behavior coverage 后, 这种 weighted guarantee 也可能失效.

## 4. Value iteration 与 policy iteration

Bellman optimality equation 给出 fixed point, dynamic programming 决定怎样求它. Value iteration 每轮做一次 optimal backup; policy iteration 则在完整 evaluation 与 greedy improvement 之间交替. 两者都假设 model 已知,state-action 可枚举, 只是把计算量放在不同位置.

三状态例子能够把每一轮完整列出. 它还展示一个重要现象: 改善下游 state 后, 上游 action 的优劣才会变化. Policy improvement 需要反复 evaluation, 因为 action 的长期价值取决于后续 policy.

### 4.1. Value iteration 手算

Value iteration 直接反复应用 optimal Bellman backup:

$$
V_{k+1}(s)=\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V_k(s')\right].
\tag{24}
$$

令 $V_0(A)=V_0(B)=V_0(T)=0$. 第一轮:

$$
V_1(A)=\max(1.5,0+0.5V_0(B))=1.5,
$$

$$
V_1(B)=\max(4,1+0.5V_0(B))=4.
$$

第二轮:

$$
V_2(A)=\max(1.5,0+0.5\times4)=2,
$$

$$
V_2(B)=\max(4,1+0.5\times4)=4.
$$

第三轮仍得到 $(2,4,0)$, 所以这个小环境已经到 fixed point:

$$
V^*(A)=2,\qquad V^*(B)=4,\qquad V^*(T)=0.
$$

Greedy policy 在 $A$ 选 `go`, 在 $B$ 选 `cash`. `loop` 的持续 policy value 是 $1/(1-0.5)=2$, 低于立即 `cash` 的 4.

一般问题不会两轮精确结束. Contraction 给出误差持续按至多 $\gamma$ 缩小的依据, stopping criterion 可以观察 $\|V_{k+1}-V_k\|_\infty$, 再结合所需 value 或 policy 精度设置 threshold.

### 4.2. Residual 与 value error

Bellman residual 定义为

$$
\varepsilon_k=\|\mathcal T^*V_k-V_k\|_\infty
=\|V_{k+1}-V_k\|_\infty.
$$

利用 contraction 与 triangle inequality:

$$
\begin{aligned}
\|V_k-V^*\|_\infty
&\le\|V_k-\mathcal T^*V_k\|_\infty
+\|\mathcal T^*V_k-\mathcal T^*V^*\|_\infty\\
&\le\varepsilon_k+\gamma\|V_k-V^*\|_\infty.
\end{aligned}
$$

移项得到

$$
\|V_k-V^*\|_\infty
\le\frac{\varepsilon_k}{1-\gamma}.
\tag{25}
$$

所以同样的 residual 在 $\gamma=0.99$ 时对应更宽的 value-error upper bound. 只报告 iteration 次数而不报告 $\gamma$ 与 stopping criterion, 无法比较两个 value iteration 实验的精度.

### 4.3. Policy iteration 手算

Policy iteration 在两个操作之间交替:

1. **Policy evaluation**: 求当前 $\pi_k$ 的 $V^{\pi_k}$.
2. **Policy improvement**: 对每个 state 选择

$$
\pi_{k+1}(s)\in\arg\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^{\pi_k}(s')\right].
\tag{26}
$$

取初始 deterministic policy $\pi_0(A)=\texttt{quit}$, $\pi_0(B)=\texttt{loop}$. Evaluation 得到

$$
V^{\pi_0}(A)=1.5,
\qquad
V^{\pi_0}(B)=1+0.5V^{\pi_0}(B)=2.
$$

第一次 improvement:

$$
Q^{\pi_0}(A,\texttt{quit})=1.5,
\quad
Q^{\pi_0}(A,\texttt{go})=0.5\times2=1,
$$

所以 $A$ 暂时保持 `quit`. 在 $B$,

$$
Q^{\pi_0}(B,\texttt{cash})=4,
\quad
Q^{\pi_0}(B,\texttt{loop})=1+0.5\times2=2,
$$

所以改成 `cash`. 新 policy $\pi_1$ 的 evaluation 是 $V^{\pi_1}(A)=1.5$, $V^{\pi_1}(B)=4$. 第二次 improvement 在 $A$ 比较

$$
Q^{\pi_1}(A,\texttt{quit})=1.5,
\quad
Q^{\pi_1}(A,\texttt{go})=0.5\times4=2,
$$

于是改成 `go`. 得到 $\pi_2(A)=\texttt{go}$, $\pi_2(B)=\texttt{cash}$, 再 improvement 不变, algorithm 结束.

这个例子展示了 policy iteration 为什么可能需要多轮. 第一轮评价中 $B$ 仍由差 policy 控制, 所以从 $A$ 前往 $B$ 看起来不划算. 先改善 $B$ 后重新评价, `go` 的长期价值才显现出来.

Policy iteration 在 finite MDP 中每次严格改进都会换到一个更好的 deterministic policy, 而 deterministic stationary policy 的数量有限, 所以 exact 版本会在有限次改进后停止. 这个结论不代表每次 evaluation 便宜. 解 linear system 的代价会随 state 数增长, sparse structure 与 iterative evaluation 在大问题中十分重要.

Tie 也需要固定规则. 多个 action 的 $Q$ 完全相同时, improvement 若每轮任意切换 tie action, policy 表面上会变化但 value 不变. 实现可以保留当前 action 或使用 deterministic tie breaking, 让 termination detection 稳定.

### 4.4. 两种 iteration 的关系

Policy iteration 每轮把当前 policy 评估到 fixed point, 再做 greedy improvement. Value iteration 每次只做一次 optimal backup, 可以看作截断 policy evaluation 与 immediate improvement 的组合. 前者 iteration 较少但单轮 evaluation 更贵; 后者单轮便宜, 可能需要更多轮.

Modified policy iteration 处于两者之间: 每次 improvement 前只执行有限轮 evaluation. 这说明它们不是彼此无关的算法, 区别在于每次 greedy update 前把当前 value 解到多精确.

二者在这里都要求完整 environment model $P,R$, 并遍历 state-action space. State 数量巨大或 continuous 时, exact table backup 不可行, 需要 sampling 与 function approximation. Monte Carlo 用完整 sample return 估计 value; TD 用 $R_{t+1}+\gamma V(S_{t+1})$ bootstrap; Q-learning 把式 (20) 的 max 放入 sample target. 它们共享 Bellman object, 估计方式和 data distribution 不同.

### 4.5. Finite-horizon backward induction

若 episode 最多剩 $H-t$ 步, value 还依赖 time:

$$
V_t^\pi(s)=\sum_a\pi_t(a\mid s)
\left[R_t(s,a)+\gamma\sum_{s'}P_t(s'\mid s,a)V_{t+1}^\pi(s')\right].
\tag{27}
$$

给定 terminal condition $V_H(s)$, 可以从 $t=H-1$ 一直向前算到 0. Optimal recursion 将 action expectation 换成 max. 这不是寻找 stationary fixed point, 而是在 time-indexed sequence 上做 backward induction. 把剩余时间加入 augmented state 后, 也能重新写成 Markov form.

Finite horizon 下, 同一个物理 state 在不同 $t$ 可能选择不同 action. 临近 episode 结束时, 一个需要多步才获得 reward 的 action 可能来不及兑现. 如果数据有 time limit, critic 输入却不含剩余时间, 它会把不同 future opportunity 的 sample 压成同一个 value.

### 4.6. Synchronous,asynchronous 与 in-place update

正文的 value iteration 使用 synchronous update: 先用完整旧 vector $V_k$ 计算所有 state 的 $V_{k+1}$, 再整体替换. In-place update 则在遍历 state 时立刻写回新值, 后面的 state 可能读取同一轮刚更新的结果. 两者的逐轮数值不同, 在适当访问条件下都可收敛到相同 fixed point.

三状态例子若先更新 $B$, 再更新 $A$, 第一轮 in-place update 得到 $V(B)=4$, 随后 $V(A)=\max(1.5,0.5\times4)=2$, 一次 sweep 就达到 optimal value. 若先更新 $A$ 再更新 $B$, 第一轮仍是 $(1.5,4)$. 因此报告 iteration 数时还要说明 update order 与 synchronous/in-place 口径.

Prioritized sweeping 进一步优先更新 Bellman residual 大或影响很多 predecessor 的 state. 它不改变 Bellman equation, 只改变计算资源投向哪里. Sparse transition graph 中, 一个 state value 改变后只需通知实际 predecessor, 无需每轮扫描所有 state.

Parallel accelerator 更适合 synchronous batch backup, CPU sparse solver 可能偏好 asynchronous update. 算法选择不仅由理论 iteration count 决定, 还取决于 state graph,memory layout 与可并行性.

### 4.7. 一轮 backup 的计算量

Dense tabular transition 中, 计算一个 $(s,a)$ 的 next-state expectation 要遍历 $n$ 个 state, 完整 optimal sweep 大约需要 $O(n^2m)$ 次标量运算. Transition graph 若每个 action 只有 $d$ 个非零 successor, sparse sweep 可降到 $O(nmd)$. 三状态例子里的 transition deterministic, 每个 action 只有一个 successor.

Policy iteration 的 exact evaluation 若用通用 dense linear solver, 粗略代价随 $n^3$ 增长; iterative evaluation 每个 sweep 利用 sparse transition, 可以提前停止. 因此「policy iteration 轮数少」不等于 wall-clock 一定更低, 还要算每轮 evaluation 精度与 model sparsity.

Memory 也可能成为瓶颈. Dense $P$ 的 shape 是 $[n,m,n]$, state 数大时无法存储. Simulator 能按需 sample next state, 却不能直接提供所有 successor probability, algorithm 就从 exact dynamic programming 进入 sample-based RL.

Value iteration 的 stopping threshold 若设得过严, 可能花大量计算改善不会改变 greedy action 的小数位. Action gap 较大时, value 还有一定 error 也能得到正确 policy; gap 很小时则需要更精确 evaluation. 实际 solver 可以同时观察 Bellman residual 与 greedy policy 是否稳定.

### 4.8. Stochastic transition 的逐轮手算

再看一个只有 nonterminal state $U$ 与 terminal $T$ 的环境. 在 $U$ 可选 `stop` 或 `try`. `stop` 以 probability 1 进入 $T$, reward 为 0. `try` 有 $0.6$ probability 进入 $T$ 并得 3, 有 $0.4$ probability 留在 $U$ 并得 $-1$. 取 $\gamma=0.9$.

对任意 value estimate $V_k(U)$,

$$
Q_k(U,\texttt{stop})=0,
$$

$$
\begin{aligned}
Q_k(U,\texttt{try})
&=0.6\times(3+0.9V_k(T))\\
&\quad+0.4\times(-1+0.9V_k(U))\\
&=1.4+0.36V_k(U).
\end{aligned}
$$

Terminal value 为 0. 从 $V_0(U)=0$ 开始做 value iteration:

| $k$ | `stop` | `try` backup | $V_{k+1}(U)$ |
|---:|---:|---:|---:|
| 0 | 0 | 1.400000 | 1.400000 |
| 1 | 0 | 1.904000 | 1.904000 |
| 2 | 0 | 2.085440 | 2.085440 |
| 3 | 0 | 2.150758 | 2.150758 |

如果 `try` 保持最优, fixed point 满足

$$
V^*(U)=1.4+0.36V^*(U),
$$

所以

$$
V^*(U)=\frac{1.4}{0.64}=2.1875.
$$

该值为正, 因而确实高于 `stop` 的 0, 假设自洽. 这里 reward 与 next state 相关, 计算时必须在每个 transition branch 内先写 $r+\gamma V(s')$, 再按 probability 加权. 如果先把 reward 误写成无条件 3 或 $-1$, fixed point 会变成另一个问题.

从误差看, recursion coefficient 是 $0.36=0.4\times0.9$. 只有失败并留在 $U$ 的 branch 会把 old value 带回当前 state, 所以实际 error 每轮乘 $0.36$, 比 global contraction upper bound $0.9$ 紧得多. 这个例子说明 transition structure 会让局部收敛速度优于只看 $\gamma$ 的 worst-case 判断.

## 5. Termination,sampling 与 approximation 边界

前四节的收敛结论建立在 finite state-action,stationary Markov dynamics,exact expectation 与 $\gamma<1$ 上. 实际任务会逐项放松这些条件: observation 可能不是 state, episode 可能被 time limit 截断, model 只能从 sample 学, value 还要由 neural network 近似.

这些变化不意味着 Bellman target 失效, 而是 fixed-point proof 不能原样搬过去. 需要区分目标 equation,sample estimator 与 function approximator 三层: equation 定义想求的对象, estimator 决定 bias/variance, approximator 决定可表示范围与 optimization error.

### 5.1. Markov,discount 与 termination

第一, Bellman fixed point 依赖 Markov state. Observation 丢失 history 时, 用 $V(o)$ 近似 value 可能出现 state aliasing, 同一个 observation 对应不同 hidden state 与 future return.

第二, $\gamma<1$ 的 contraction 是 discounted continuing case 的核心条件. Finite horizon 可以把剩余时间并入 state, 得到 time-dependent value $V_t(s)$ 并从终点 backward induction. Average-reward continuing task 则需要另一套 Bellman equation, 不能直接把 $\gamma$ 设成 1 后沿用全部结论.

第三, Bellman optimality equation 假设 reward 与 transition 已经定义. Reward misspecification 下, 求得的 policy 可能精确优化错误目标. Distribution shift 下, $P_{\mathrm{train}}$ 的 optimal value 也未必对应 deployment environment.

### 5.2. Termination 与 truncation 的 bootstrap mask

设 sample transition 包含 termination flag $d_t$ 与 truncation flag $u_t$. True termination 表示 MDP 进入 terminal, 标准 discounted target 为

$$
Y_t=R_{t+1}+\gamma(1-d_t)V(S_{t+1}).
$$

Time-limit truncation 只表示 collector 不再记录, environment 的 future 仍可能存在. 如果 objective 对应 continuing task, $u_t=1,d_t=0$ 时通常仍应 bootstrap. 把 `done = termination OR truncation` 直接乘成 0, 会系统性低估靠近 time limit 的 value.

另一种定义是把 time limit 本身当作 environment termination. 那么 remaining time 必须进入 state 或 task specification, terminal 后 future value 的确为 0. 两种处理都可成立, 取决于想解哪个 MDP; 错误来自训练 target 与 evaluation task 使用不同定义.

Sequence generation 中 EOS 类似 true termination, max-length cutoff 更接近 truncation. 如果超过长度本身应受惩罚, cutoff 可以带 terminal penalty; 如果只是显存限制, critic 可能需要对 unfinished sequence bootstrap. 直接把两者都标成 EOS 会改变 length preference.

### 5.3. Sampling,max 与 function approximation

第四, function approximation, off-policy sampling 与 bootstrap 同时出现时可能不稳定. Tabular contraction proof 不会自动转移到 nonlinear neural network. DQN 使用 target network, replay 与其他稳定化机制, 正是在处理从 exact operator 到 approximate stochastic update 后出现的问题.

第五, action max 会产生 selection bias. 用 noisy $Q$ estimate 同时选择和评价最大 action, 最大值更容易挑中正噪声. Double Q-learning 一类方法将 action selection 与 evaluation 部分分开, 处理的就是这项 overestimation mechanism. 这不是 Bellman optimality equation 本身的错误, 而是用有限 noisy estimate 近似 max expectation 时出现的问题.

第六, model-based backup 的误差会递归传播. 如果 learned transition model 在某类 state-action pair 上偏差很大, value iteration 可能反复利用这个虚假 transition, 产生 model exploitation. 增加 rollout depth 并不必然更准; horizon 越长, model error 能影响的后继越多.

### 5.4. Bellman error 的三种来源

Neural critic 的 total error 可以按概念拆成三类. **Approximation error** 来自 function class 无法表示 true value; **estimation error** 来自 finite sample 与 distribution coverage; **optimization error** 来自 loss 没有被训练到当前 function class 中的最佳点. 增加 gradient step 只能直接减少第三类, 无法补上未访问 state 或缺失 feature.

常见 squared TD loss 为

$$
\mathcal L(\phi)=\mathbb E_{(s,a,r,s')\sim\mathcal D}
\left[V_\phi(s)-\left(r+\gamma V_{\bar\phi}(s')\right)\right]^2.
$$

Target parameter $\bar\phi$ 暂时冻结, 让 regression target 在若干 step 内较稳定. 即使 training loss 很小, 也只说明 dataset distribution $\mathcal D$ 上接近 frozen target, 不证明 $V_\phi$ 接近 true $V^\pi$ 或 $V^*$.

Off-policy data 还改变 loss weighting. 高频 behavior state 对 gradient 贡献大, target policy 常访问但 behavior 少见的 state 贡献小. Tabular case 可以靠逐 state step-size 与 sufficient visitation 讨论收敛; neural case 中 parameter sharing 让一个 state 的 update 同时改变其他 state, 分析更复杂.

### 5.5. Average reward 不是把 $\gamma$ 直接设为 1

Continuing task 若关心长期每步平均 reward, 可以定义

$$
g^\pi=\lim_{T\to\infty}\frac1T
\mathbb E_\pi\left[\sum_{t=0}^{T-1}R_{t+1}\right].
$$

Differential value $h^\pi(s)$ 衡量从 $s$ 出发相对 steady-state average 多获得多少 transient reward. 对应 equation 形如

$$
g^\pi+h^\pi(s)
=\sum_a\pi(a\mid s)
\left[R(s,a)+\sum_{s'}P(s'\mid s,a)h^\pi(s')\right].
$$

$h^\pi$ 只确定到 additive constant, 因为给所有 state 同加常数不会改变 equation. 这与 discounted case 的 unique $V^\pi$ 不同. Average-reward theory 还需要 chain ergodicity 等条件, 不能把正文 contraction proof 中的 $\gamma$ 删除后继续使用.

选择 discounted return 还是 average reward 会改变 policy preference. Discounted objective 更重视靠近当前时刻的 reward, average reward 忽略有限 transient 对无限期平均的影响. 部署 task 若有自然 episode, discounted/episodic 口径通常更直观; 持续控制或资源调度可能更关心 long-run rate.

### 5.6. TD(0),n-step 与 Monte Carlo target

对固定 policy, one-step TD target 是

$$
G_t^{(1)}=R_{t+1}+\gamma V(S_{t+1}).
$$

$n$-step target 展开更多真实 reward:

$$
G_t^{(n)}
=\sum_{k=0}^{n-1}\gamma^kR_{t+k+1}
+\gamma^nV(S_{t+n}).
$$

若 episode 在 $n$ 步前 true termination, bootstrap 项为 0, sum 截到 terminal. $n$ 增大时, target 对 current critic 的依赖减少, 对 sampled reward sequence 的依赖增加. 一般表现为 bias 降低而 variance 上升, 具体大小还取决于 reward stochasticity 与 critic error.

Monte Carlo target 一直累积到 terminal, 不 bootstrap. Episodic environment 中它直接 sample $G_t$, 对 true $V^\pi$ unbiased 的前提是 trajectory 来自 $\pi$ 且 return 定义一致. Episode 很长或 continuing 时, 等待 terminal 成本高, return variance 也可能很大.

$\lambda$-return 将不同 $n$-step target 做 geometric mixture. GAE 在 advantage 侧使用相近结构, 把 TD residual 按 $\gamma\lambda$ 累积. 这些方法没有改变 Bellman expectation object, 只是选择用多少真实 future reward 与多少 bootstrap 来估计它.

实现中必须明确 value target 是否 stop-gradient. 若 target 内的 $V(S_{t+n})$ 与 prediction 同时反向传播, loss 不再是通常的 semi-gradient TD update. Residual-gradient method 有另一套推导, 不能在无说明时混用.

### 5.7. Error 应该沿哪条链排查

当 critic prediction 错误时, 可以沿四层排查. 第一层是 task definition: reward,discount 与 termination 是否表达了想要的 objective. 第二层是 state: observation 是否满足 Markov 条件, remaining time 与 hidden variable 是否缺失. 第三层是 data: behavior coverage,sample correlation 与 importance ratio 是否可接受. 第四层才是 optimization: network capacity,learning rate 与 target update 是否合适.

这条顺序很重要. Reward timing 错一位时, 再大的 network 也只会更精确地拟合错误 target; terminal mask 把 truncation 当结束时, 增加 data 会稳定地产生 biased value; unseen action 没有 coverage 时, 降低 training loss 也无法验证它的 $Q$.

对 tabular toy MDP, 可以把 model enumeration,linear solve,iterative backup 与 Monte Carlo rollout 四个结果互相核对. 它们若不一致, 通常是 reward index,discount,terminal 或 transition probability 中至少一处实现错误. 对 large environment 无法精确求解时, 仍可构造小 state slice 或 deterministic fixture 保留这种交叉检查.

### 5.8. Replay distribution 与 Bellman loss weighting

Replay buffer 改变的是哪些 state-action error 被频繁优化. Uniform replay 对 buffer 中 transition 均匀抽样, 并不等于对 current policy occupancy 均匀, 也不等于对 state space 均匀. Old policy data 占比很大时, critic loss 主要在 old occupancy 上下降.

Prioritized replay 按 TD error 提高某些 transition 的采样 probability. 这能更快处理当前 residual 大的样本, 也改变了 objective weighting. 若希望恢复 uniform-buffer expectation, 需要 importance weight 修正 sampling probability; clip 或不完全修正会留下 bias, 换取较低 variance 与更稳定 optimization.

Rare state 还会遇到另一层问题: TD error 只有访问后才能计算. 从未进入 buffer 的 catastrophic state 不会因 priority mechanism 自动出现. Exploration,scenario generation 与 offline coverage 属于 data acquisition, replay scheduling 只在已有 data 内重新分配计算.

验证 critic 时应至少分开报告 replay-distribution loss,on-policy rollout error 与 task-level return. 第一项衡量 optimizer 是否拟合训练 target, 第二项衡量 current policy 常见 state, 第三项还包含 policy choice 与 environment feedback. 三者同时改善时证据更完整; 只有 replay loss 下降, 无法推出 control performance 提升.

### 5.9. Expected value 看不见 return distribution

标准 Bellman equation 传播 expected return. 两个 action 可以有相同 $Q$ mean, return risk 却完全不同. 例如 action `stable` 恒得 1, action `risky` 以相同 probability 得 0 或 2. 两者 expected reward 都是 1, risk-neutral Bellman backup 将它们视为 tie; variance 分别是 0 与 1.

如果任务关心 downside risk,tail probability 或安全约束, scalar $V$ 不足以表达目标. 可以增加 cost value 与 constraint, 使用 CVaR 等 risk measure, 或学习完整 return distribution. Distributional RL 传播的是 random return distribution 的 representation, 其 expectation 仍应与普通 value 在口径一致时对应.

Risk-sensitive objective 往往不再满足简单的 expectation linearity. 例如 utility $\mathbb E[u(G)]$ 在 nonlinear $u$ 下, 不能只把 $\mathbb E[G]$ 送进 $u$. Bellman recursion 需要把足以计算 future utility 的 state 或 distribution 保留下来. 直接在普通 $V$ 上附加一句「考虑风险」不会产生正确 equation.

大模型后训练也有类似差别. 平均 verifier reward 相同的两个 policy, 一个可能稳定产出中等答案, 另一个偶尔满分,偶尔产生严重违规. 只优化 mean reward 会忽略 tail behavior. Safety evaluation 因而要报告 violation rate 与 severity distribution, 不能只给 average reward.

这一边界不否定 expected Bellman equation. 它精确解的是 risk-neutral discounted expectation. 当产品目标包含风险,约束或多目标权衡时, 应先修改 objective 与 state, 再推对应 operator; 不能要求原 equation 回答它没有编码的问题.

### 5.10. 交付前怎样复核一个 Bellman 实现

先构造只有两三个 state 的 deterministic fixture, 手算每个 action 的 reward,next state 和 discount. 用 model enumeration,matrix solve,iterative evaluation 与大量 Monte Carlo rollout 分别计算同一个 $V^\pi$, 四者应在数值误差范围内一致. 再加入 stochastic branch, 检查 transition probability 是否只乘一次.

随后分别制造 true termination 与 time-limit truncation, 查看 target 中 bootstrap mask 是否符合 task definition. 把 policy action probability改成非均匀值, 检查 $P_\pi$ 与 $r_\pi$ 是否同时更新. 将 value 初值换成正数,负数和随机数, contraction case 应收敛到相同 fixed point.

Control 路径还要验证 expectation 与 max 没有混写. 固定 policy evaluation 应按 $\pi$ 对 action 求和, value iteration 才使用 max. 对 tie action 设置 deterministic rule, 对 approximate critic 人为加入可控误差, 检查 action gap 小时是否出现预期的 ranking flip.

最后才跑 large environment. 记录 Bellman residual,value scale,termination rate,target/prediction distribution 与 greedy action change. 一旦指标异常, 先回到 fixture 定位 reward index,mask,transition 和 update order, 不要直接靠调 learning rate 掩盖定义错误.

这套复核顺序的目标是先证明数学对象与实现对齐, 再讨论 function approximation 的性能. Toy fixture 过不了时, 大规模训练曲线再平滑也不能证明 Bellman update 正确.
定义, 数据与更新必须逐项对应.

**Bellman equation 给出 value 必须满足的递归结构, 不替任何具体 estimator 保证收敛.** 读后续方法时要分别检查 target 来自 expectation 还是 max, data 由哪个 policy 采样, next-state value 是真实值, table estimate 还是 neural critic, 以及更新究竟在做 evaluation 还是 control.

## 6. 把 Bellman backup 写成可核对的张量运算

对 $n$ 个状态、$m$ 个动作的有限 MDP，令 transition tensor $P$ 的 shape 为 $[n,m,n]$，reward tensor $R$ 也取 $[n,m,n]$，policy matrix $\Pi$ 为 $[n,m]$，value vector $V$ 为 $[n]$。固定策略的一步 backup 可以逐项写成

$$
Q[s,a]=\sum_{s'=1}^{n}P[s,a,s']
\bigl(R[s,a,s']+\gamma V[s']\bigr),
$$

$$
(T^\pi V)[s]=\sum_{a=1}^{m}\Pi[s,a]Q[s,a].
$$

这里 $P$ 在最后一维求和，$\Pi$ 在动作维求和。若实现用广播，一种清楚的中间 shape 是：`target_sa_next = R + gamma * V[None,None,:]` 得到 $[n,m,n]$；与 $P$ 相乘并沿 next-state 维求和得到 $Q:[n,m]$；最后与 $\Pi$ 相乘并沿 action 维求和得到新 $V:[n]$。**先保留中间 $Q$ 再求和，通常比把所有维度塞进一个表达式更容易查错。**

若 reward 已经预先取成 $\bar R[s,a]=\sum_{s'}P[s,a,s']R[s,a,s']$，则

$$
Q[s,a]=\bar R[s,a]+\gamma\sum_{s'}P[s,a,s']V[s'].
$$

两种写法只能选一种。把 $\bar R$ 放进对 $s'$ 的求和仍能得到同样结果，因为概率和为 1；但若代码里的 `R` 实际是按 next state 变化的条件 reward，却误当作 $[n,m]$ 广播，就会丢掉 reward 与 transition outcome 的对应关系。

### 6.1. 一个 $2\times2\times2$ 的逐元素 backup

设当前 $V=(4,1)$，$\gamma=0.5$。在状态 $s_0$，动作 $a_0$ 以概率 $(0.75,0.25)$ 转移到 $(s_0,s_1)$，两种结果的 reward 分别为 $(0,2)$。那么

$$
Q(s_0,a_0)
=0.75(0+0.5\times4)+0.25(2+0.5\times1)
=2.125.
$$

动作 $a_1$ 必到 $s_1$ 且 reward 为 3，故

$$
Q(s_0,a_1)=3+0.5\times1=3.5.
$$

若策略在 $s_0$ 以 $(0.6,0.4)$ 选动作，则 expectation backup 为

$$
(T^\pi V)(s_0)=0.6\times2.125+0.4\times3.5=2.675.
$$

Optimality backup 则是 $\max(2.125,3.5)=3.5$。同一组 $Q$，最后一步是按策略加权还是取最大值，区分了 evaluation 与 control。代码里把 `sum(policy * q)` 改成 `max(q)` 只差一行，求解的问题却已经变了。

## 7. Sampling backup 的噪声从哪里来

模型未知时，无法枚举所有 $s'$，只观察一个 transition $(s,a,r,s')$。TD(0) 用

$$
Y=r+\gamma(1-d)\widehat V(s')
$$

作为随机 target，其中 $d$ 表示真终止。若 $\widehat V$ 暂时固定，并且 transition 是从真实 kernel 采样的，则

$$
\mathbb E[Y\mid s,a]
=\sum_{s',r}p(s',r\mid s,a)
[r+\gamma(1-d)V(s')]
$$

正是一次 Bellman expectation backup。一个 sample target 会偏离这个期望，但这种 transition sampling noise 本身不构成 bias。Critic 不准确、截断 mask 错误、target clipping 或函数类无法表示真实 fixed point 会让实际更新偏离理想 backup。Off-policy 采样则更精确地说是改变了 Bellman error 被哪些状态动作加权；在 tabular、覆盖充分并对每个访问对独立更新的 policy evaluation 中，它未必改变 fixed point，但配合函数逼近、有限覆盖或 control target 时，可能得到不同的投影解或产生不稳定性。

用上一节的 $a_0$ 举例，sample target 只有两种：以 0.75 概率取 $0+0.5\times4=2$，以 0.25 概率取 $2+0.5\times1=2.5$。均值为 2.125，条件 variance 为

$$
0.75(2-2.125)^2+0.25(2.5-2.125)^2=0.046875.
$$

如果 reward 在每个分支内还随机，total variance 还要加入 $\mathbb E[\operatorname{Var}(R\mid s,a,s')]$。这正是全 variance 公式在 Bellman target 上的应用。用 $K$ 个独立 next-state sample 取平均可把这部分 variance 缩到约 $1/K$，代价是环境交互或模型查询增加。

### 7.1. Max 带来的过估计不是 transition noise 本身

假设一个状态有两个动作，真实 action value 都是 0，但估计误差独立地以相同概率取 $-1$ 或 $+1$。单个动作估计仍然无偏：$\mathbb E[\widehat Q_a]=0$。然而

$$
\max(\widehat Q_1,\widehat Q_2)
$$

只有在两者同时为 $-1$ 时取 $-1$，其余三种组合都取 $+1$，所以期望为

$$
\frac14(-1)+\frac34(1)=0.5.
$$

**「每个动作估计无偏」并不能推出「最大值估计无偏」。** 选择与评估复用同一组噪声，会偏爱被高估的动作。Double Q 的核心思路是用一套估计选择动作、另一套较独立的估计评价它，降低这种选择偏差；它并不保证所有环境下完全没有低估或其他 approximation error。

## 8. 函数逼近求到的是哪个投影

Tabular setting 能给每个状态一个独立数值，神经网络或线性 critic 则把许多状态绑在同一组参数上。令线性 value 为 $V_w=\Phi w$，$\Phi\in\mathbb R^{n\times d}$ 且 $d<n$。真实 Bellman image $T^\pi V_w$ 通常不在 $\Phi$ 的列空间中，更新只能把它投回可表示集合：

$$
V_{w_{k+1}}\approx \Pi_D T^\pi V_{w_k},
$$

其中 $D$ 是训练分布对各状态的权重，$\Pi_D$ 表示按加权平方误差投影。Replay 或 behavior policy 改变 $D$，即使 target 的条件期望完全正确，也会改变有限容量 critic 优先拟合哪些状态。

做一个可见的例子。两个状态真实 value 为 $(0,10)$，critic 只能输出同一个常数 $w$。若训练权重为 $D=(0.9,0.1)$，最小化


$$
0.9(w-0)^2+0.1(w-10)^2
$$

得到 $w=1$；若权重换成 $(0.1,0.9)$，则得到 $w=9$。两个解都不是因为 sample target 有条件偏差，而是表示类只能用一个数同时服务两个状态，distribution 决定妥协点。此时说「off-policy 导致 bias」过于粗糙，更准确的说法是：离策略数据改变了投影范数，而投影解未必适合目标策略最常访问的区域。

这也解释了为什么 replay loss 不能单独代表 value quality。上例在各自训练分布下都达到最优，却会在另一分布下产生很大误差。应另外在 current-policy occupancy、关键安全状态和统一评测集上计算 error；若能构造小环境真值，还可以直接画出每个状态的 signed error，看到共享参数究竟牺牲了谁。

线性投影本身可以继续算到底。令 $D=\operatorname{diag}(d_1,\ldots,d_n)$，给定一个暂时固定的 target vector $y$，加权回归目标为

$$
L(w)=(\Phi w-y)^\top D(\Phi w-y).
$$

对 $w$ 求导并令其为零，得到 normal equation

$$
\Phi^\top D\Phi w=\Phi^\top Dy.
$$

若 $\Phi^\top D\Phi$ 可逆，解为

$$
w=(\Phi^\top D\Phi)^{-1}\Phi^\top Dy.
$$

这条式子把数据分布的作用写得很直白：$D$ 同时出现在矩阵两侧。某状态权重为零时，它不对参数解施加直接约束；某组 feature 在已覆盖状态上近线性相关时，矩阵会病态，少量 target noise 就可能引起很大的参数变化。工程里加入 $\lambda\lVert w\rVert_2^2$，相当于把左侧改为 $\Phi^\top D\Phi+\lambda I$，能改善条件数，但又引入向零收缩的 regularization bias。

当 target 本身是 $T^\pi(\Phi w)$，问题不再是一次固定标签回归，而是寻找 projected Bellman equation 的 fixed point：

$$
\Phi w=\Pi_D T^\pi(\Phi w).
$$

投影与 Bellman operator 的组合未必继承原算子在 max norm 下的 contraction。特别是 off-policy data、bootstrapping 和 function approximation 同时出现时，训练可能发散；这就是常说的 deadly triad。这个术语不是说三者任一个单独出现必然失败，而是 tabular contraction proof 已不足以保证组合更新稳定。诊断时应分别改变数据分布、bootstrap 深度和函数类，找出不稳定究竟在哪个耦合处出现。

### 8.1. Approximate backup 的误差如何累计

设一次近似更新满足

$$
V_{k+1}=T^\pi V_k+e_k,
\qquad \lVert e_k\rVert_\infty\le\varepsilon.
$$

则

$$
\lVert V_{k+1}-V^\pi\rVert_\infty
\le\gamma\lVert V_k-V^\pi\rVert_\infty+\varepsilon.
$$

递推 $k$ 次，

$$
\lVert V_k-V^\pi\rVert_\infty
\le\gamma^k\lVert V_0-V^\pi\rVert_\infty
+\varepsilon\sum_{j=0}^{k-1}\gamma^j.
$$

当 $k\to\infty$，误差地板最多为 $\varepsilon/(1-\gamma)$。这解释了为什么每轮看似很小的系统性 target error，在 $\gamma$ 接近 1 时会形成明显 value bias。它也提示 debug 顺序：随机优化噪声可能随 batch 增大而下降，reward timing 或 terminal mask 造成的系统误差不会靠多训练几轮自动消失。

## 9. Target network 改变的是优化动力学

神经网络 critic 常用一份延迟参数 $\bar\phi$ 构造 target：

$$
Y_i=r_i+\gamma(1-d_i)V_{\bar\phi}(s'_i),
\qquad
L(\phi)=\frac1B\sum_i(V_\phi(s_i)-Y_i)^2.
$$

计算这一轮梯度时，$Y_i$ 应视为常数，因而要停止通过 target network 反传。若 online 与 target 共用同一参数且不 detach，梯度会同时推动等式两边，得到的已不是通常的 semi-gradient TD。延迟副本可以每隔 $K$ 步硬更新，也可以用

$$
\bar\phi\leftarrow(1-\tau)\bar\phi+\tau\phi
$$

缓慢跟随。小 $\tau$ 降低 target 快速漂移，却增加陈旧程度；它没有把函数逼近重新变成严格 contraction，只是在实践中改变耦合系统的稳定性。

一个可观察的诊断是同时记录 online prediction、frozen target 和二者差值。如果 loss 很小只是因为 target 紧跟 online 一起移动，策略回报未必改善；若 target 长期落后，TD error 又可能主要反映参数时滞。比较不同 target-update 设置时，训练步数相同还不够，需报告环境样本数、gradient update 数和每条数据被复用多少次。

### 9.1. Reward scaling 与 value 单位

将所有 reward 乘常数 $c$，真实 $V$ 与 $Q$ 也乘 $c$，最优策略在无其他正则项时通常不变。但 squared value loss 会乘约 $c^2$，gradient norm 和数值范围都会变化。若 actor loss、critic loss、entropy 与 KL 共用一组系数，reward scale 还会改变各分量的相对力量。

因此 reward normalization 不是完全无语义的预处理。按 batch 标准化 reward 会让同一个结果在不同 batch 得到不同单位；running normalization 又依赖历史数据分布。若要比较 value 与人工可解释的业务回报，应保留原始单位，并记录训练中使用的缩放变换及其反变换。测试 Bellman identity 时，也要在同一单位下比较 $r+\gamma V(s')$ 与 $V(s)$。

对稀疏终局奖励，大量 transition 的 immediate reward 为零，不能据此断言它们的 value 也接近零。应检查终局信号能否沿 backup 传播到早期状态：在确定性长度 $H$ 的链上，终局奖励 1 对起点的 value 是 $\gamma^{H-1}$。若实现只更新终点附近或 replay 很少抽到关键链路，早期 state 会长期看不到信用信号。这是数据传播问题，不是 Bellman 方程本身失效。

还可以用这条链检查 update order。同步更新每轮只让奖励向前传播一个状态，距离终点 $H$ 步的起点至少需要 $H$ 轮才第一次得到非零估计；若按从终点到起点的顺序做 in-place sweep，一轮就能传遍整条链。两者拥有相同 fixed point，有限计算预算下的收敛速度却不同。比较算法时应报告一次「iteration」到底包含多少 state backup，避免把更有利的遍历顺序误认成不同算子的优势。

在随机环境中，单次 sweep 的变化还混有 sampling noise。可以固定一个小模型先跑精确 expectation backup，再跑 sample backup，观察二者随样本量靠近。若样本量增加后仍存在稳定偏差，应检查 behavior coverage、reward preprocessing、terminal mask 与 target network；不要把系统性误差笼统归为随机性。
