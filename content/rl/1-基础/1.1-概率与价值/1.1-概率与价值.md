# 概率、轨迹与价值

强化学习研究随机轨迹上的长期决策。初始状态、策略与环境转移共同决定轨迹概率；奖励沿轨迹累积成 return；value 则是在指定状态或动作条件下，对未来 return 取期望。分清这些对象，后面才能说明估计误差究竟来自采样、状态表示还是价值近似。

[概率、轨迹与 MDP](./1.1.1-概率轨迹与mdp.md)先确定样本空间和状态边界。语言模型的完整前缀通常可以作为状态，工具任务还需纳入外部环境与剩余预算。文章给出轨迹概率、占用测度、重要性采样和有限 MDP 手算，帮助读者检查一批日志究竟来自哪个分布。

[Bellman 递归与动态规划](./1.1.2-贝尔曼递归与动态规划.md)随后利用时间结构，把长期回报拆成一步奖励与下一状态价值。精确条件期望、动态规划 backup、采样 TD target 和函数逼近投影在这里依次出现。它们共享 Bellman 形式，却有不同误差来源。

阅读顺序不能反过来：先确认状态、奖励、终止与折扣定义，再讨论求解器。状态遗漏隐藏变量时，Bellman residual 降低也未必意味着真实任务价值更准；数据没有覆盖某个动作时，离线拟合也不能验证它的 $Q$。这一章建立的对象会被策略梯度、critic 和 GAE 原样复用。
