# 概率, 轨迹与 MDP 基础

强化学习里的随机性来自多个位置: 初始状态可能随机, policy 可能随机选动作, environment 也可能把同一个动作送到不同后继状态. 一条 trajectory 的概率由这些条件分布相乘得到, return 则是这条 trajectory 上 reward 的折扣和. Value function 再对 trajectory distribution 取条件期望. Bellman equation 后面能够成立, 依赖的就是这组对象和 Markov property. 强化学习推导需要三类概率工具: 随机变量的依赖关系、条件分布的组合方式, 以及每个期望对应的求和对象. 这些工具足以区分 on-policy 与 off-policy、state distribution 与 action distribution、sample return 与 expected value, 无需展开完整的测度论体系.

## 1. 概率空间怎样落到 trajectory

强化学习算法最终处理的是 sample, 公式却描述 distribution 上的 expectation. 这一节先把两层对象分开: 一条 trajectory 是 probability space 中的一次 realization, value 与 objective 则是对许多可能 trajectory 的加权平均. 同一个符号若在 sample 与 expectation 之间来回切换, 后面的 gradient estimator 和 Bellman target 都会失去口径. 第二个关键是条件化. State value 固定当前 state, action value再固定当前 action, importance sampling 则比较同一事件在两个 distribution 下的 density. 它们都依赖 conditional probability, 并不只是把若干概率数字相乘. **1.1. Random variable 与 expectation.** 概率空间写成 $(\Omega,\mathcal F,\mathbb P)$. $\Omega$ 是所有可能结果, $\mathcal F$ 是允许讨论概率的 event 集合, $\mathbb P$ 给 event 赋予 $[0,1]$ 中的概率. 在 episodic RL 中, 一个 sample point 可以是一条完整 trajectory:

$$
\tau=(s_0,a_0,r_1,s_1,a_1,r_2,\ldots,s_T).
\tag{1}
$$

随机变量是从 $\Omega$ 到数值空间的可测函数. 例如 trajectory length $T(\tau)$, 第一个 reward $R_1(\tau)$, discounted return $G_0(\tau)$ 都是随机变量. 大写 $S_t,A_t,R_{t+1}$ 表示随机变量, 小写 $s_t,a_t,r_{t+1}$ 表示一次 realization 中的取值. 对离散随机变量 $X$, 期望为

$$
\mathbb E[X]=\sum_x p_X(x)x.
\tag{2}
$$

条件期望 $\mathbb E[X\mid Y=y]$ 固定了 $Y=y$, 再对剩余随机性取平均. Value function

$$
V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]
$$

条件 $S_t=s$ 只固定当前 state, 后续 action、state transition 与 reward 仍然随机. $V^\pi(s)$ 对所有符合条件的 trajectory 按概率加权求平均; 单条 trajectory 上观测到的 $G_t$ 只是其中一次样本. **1.2. 条件概率与全期望.** 若 $p(y)>0$, 条件概率定义为

$$
p(x\mid y)=\frac{p(x,y)}{p(y)}.
\tag{3}
$$

乘法规则随即得到

$$
p(x,y)=p(x\mid y)p(y).
$$

对 sequence 反复使用乘法规则:

$$
p(x_{0:T})=p(x_0)\prod_{t=0}^{T-1}
p(x_{t+1}\mid x_{0:t}).
\tag{4}
$$

式 (4) 仍然保留完整 history. Markov property 后面会把 transition 的条件从整段 history 缩到当前 state-action pair. 全期望公式负责把一个随机量按中间变量分层求平均:

$$
\mathbb E[X]=\mathbb E_Y[\mathbb E[X\mid Y]].
\tag{5}
$$

离散情况下,

$$
\mathbb E[X]=\sum_y p(y)\sum_x p(x\mid y)x.
$$

Bellman expectation equation 正是在下一步 action 与 next state 上反复使用式 (5). 先对 policy 的 action distribution 求期望, 再对 environment transition 求期望, 最终接上 next-state value. **1.3. 一个两层期望手算.** 设 state $s$ 下有两个 action. Policy 以 $0.7$ 选择 $a_1$, 以 $0.3$ 选择 $a_2$. 执行 $a_1$ 后, reward 以相同概率取 $2$ 或 $0$; 执行 $a_2$ 后 reward 恒为 $1.5$. 先固定 action:

$$
\mathbb E[R\mid s,a_1]=0.5\times2+0.5\times0=1,
$$

$$
\mathbb E[R\mid s,a_2]=1.5.
$$

再对 policy action 求期望:

$$
\mathbb E_\pi[R\mid s]
=0.7\times1+0.3\times1.5=1.15.
$$

如果只拿到一次 sample, 观察值可能是 $0$, $1.5$ 或 $2$, 它们都不是 expected reward $1.15$. 多次 sample average 才是在估计这个条件期望. 强化学习中的很多混淆都来自把一次 realized target 与它所估计的 expectation 写成同一个符号. **1.4. Independence 要看条件.** $S_{t+1}$ 与更早 history 通常不是无条件独立. 它们会通过 $S_t$ 相关. Markov property 声明的是 conditional independence:

$$
S_{t+1}\perp(S_0,A_0,\ldots,S_{t-1},A_{t-1})
\mid(S_t,A_t).
$$

这一区别决定能否删掉 history. 未给定当前 state 时, 早期 state 当然能帮助预测 $S_{t+1}$; 给定一个充分 state 后, 早期信息才不再增加一步预测能力. **1.5. Importance sampling 是换 distribution.** 设我们想计算 target distribution $p(x)$ 下的 expectation, 手中 sample 却来自 behavior distribution $q(x)$. 只要 $p(x)>0$ 的位置都有 $q(x)>0$, 就可以写

$$
\mathbb E_{x\sim p}[f(x)]
=\sum_x p(x)f(x)
=\sum_x q(x)\frac{p(x)}{q(x)}f(x)
=\mathbb E_{x\sim q}[w(x)f(x)],
$$

其中 $w(x)=p(x)/q(x)$ 是 importance weight. 第一处等号定义 target expectation, 第二处乘除同一个 $q(x)$, 第三处才把求和识别成 behavior expectation. 如果某个 target event 在 behavior 下 probability 为 0, ratio 无法定义, 数据也没有提供该区域的信息. 做一个两点手算. Target distribution 为 $p=(0.5,0.5)$, behavior 为 $q=(0.8,0.2)$, 函数值为 $f=(2,0)$. 直接计算 target expectation:

$$
\mathbb E_p[f]=0.5\times2+0.5\times0=1.
$$

两个 weight 是 $w_1=0.5/0.8=0.625$, $w_2=0.5/0.2=2.5$. 在 behavior 下:

$$
\mathbb E_q[wf]
=0.8\times0.625\times2
+0.2\times2.5\times0=1.
$$

Expectation 相同, sample variance 却可能增大. 第二个 event 在 behavior 中少见, 一旦出现就带 weight $2.5$. 多步 RL 的 trajectory ratio 是许多 action ratio 的乘积, rare trajectory 会得到很大 weight, variance 随 horizon 迅速恶化. 给 $N$ 个 behavior sample $x_i$, ordinary estimator 是

$$
\widehat\mu_{\mathrm{IS}}=\frac1N\sum_{i=1}^{N}w(x_i)f(x_i).
$$

在 support 与可积条件满足时它 unbiased. Self-normalized estimator

$$
\widehat\mu_{\mathrm{SNIS}}
=\frac{\sum_iw(x_i)f(x_i)}{\sum_iw(x_i)}
$$

常能减轻 weight 总量波动, 但有限 sample 下通常带 bias. 截断或 clip weight 也在 bias 与 variance 之间交换. 所以后续算法写「使用 importance sampling」还不够, 必须继续问 ratio 覆盖哪些随机变量,是否归一化,有没有 clip, data support 是否足够. **1.6. Variance,covariance 与条件分解.** Expectation 告诉我们平均位置, variance 描述 sample 围绕均值的 dispersion:

$$
\operatorname{Var}(X)
=\mathbb E[(X-\mathbb E[X])^2]
=\mathbb E[X^2]-\mathbb E[X]^2.
$$

两个随机变量的 covariance 为

$$
\operatorname{Cov}(X,Y)
=\mathbb E[(X-\mathbb E[X])(Y-\mathbb E[Y])].
$$

对和求 variance 时 cross term 不会消失:

$$
\operatorname{Var}(X+Y)
=\operatorname{Var}(X)+\operatorname{Var}(Y)
+2\operatorname{Cov}(X,Y).
$$

Return 是许多 reward 的折扣和, 相邻 reward 往往相关. 只把每步 reward variance 相加会漏掉 covariance. Early action 同时影响多个 future reward 时, positive covariance 能让 return variance 放大. 全 variance 公式把随机性拆成组内 variance 与组间 variance:

$$
\operatorname{Var}(X)
=\mathbb E_Y[\operatorname{Var}(X\mid Y)]
+\operatorname{Var}_Y(\mathbb E[X\mid Y]).
$$

令 $Y=S_t$, 第一项表示固定 state 后 transition,action 与 reward 仍有多少随机性, 第二项表示不同 state 的 expected return 差异. Baseline 若能解释第二项的一部分, policy gradient estimator 的 variance 就会下降; baseline 不能改变 environment 内在的第一项随机性. 设 state 有两类, 各以 $0.5$ 出现. 第一类 return 恒为 0, 第二类 return 以相同概率为 2 或 4. Overall mean 是 $1.5$. Conditional variance 分别为 0 和 1, 所以第一项为 $0.5$. Conditional mean 分别为 0 和 3, 第二项 variance 为 $2.25$. Total variance 为 $2.75$. 直接枚举 return distribution 也会得到同一结果. **1.7. Bayes rule 与 hidden state inference.** Bayes rule 把 likelihood 与 prior 合成 posterior:

$$
p(z\mid o)=\frac{p(o\mid z)p(z)}
{\sum_{z'} p(o\mid z')p(z')}.
$$

$z$ 可以是不可直接观察的 environment state, $o$ 是 observation. Prior $p(z)$ 描述观察前的 belief, likelihood $p(o\mid z)$ 描述每个 hidden state 产生 observation 的概率, 分母对所有 hidden state 求和以完成归一化. 设 hidden state 是 `safe` 或 `danger`, prior 分别为 $0.8$ 与 $0.2$. Sensor 发出 `alarm` 的 probability 在两种 state 下分别为 $0.1$ 与 $0.9$. 观察到 alarm 后:

$$
p(\texttt{danger}\mid\texttt{alarm})
=\frac{0.9\times0.2}
{0.1\times0.8+0.9\times0.2}
=\frac{0.18}{0.26}\approx0.6923.
$$

Alarm 本身没有让 danger 变成确定事实, 它把 belief 从 $0.2$ 更新到约 $0.6923$. POMDP policy 应根据 posterior 或其 approximation 决策. 如果系统把 noisy observation 直接当作 true state, 就会忽略 sensor false positive 与 false negative. Sequential setting 中, 上一步 posterior 经过 transition prediction 成为下一步 prior, 再用新 observation 更新. 设 action 后 hidden-state transition 为 $P(z'\mid z,a)$, prediction 是

$$
\bar b_{t+1}(z')=\sum_zP(z'\mid z,a_t)b_t(z),
$$

correction 是

$$
b_{t+1}(z')
\propto O(o_{t+1}\mid z')\bar b_{t+1}(z').
$$

这两步解释了 belief state 为什么能承载 history: 过去 observation 已经被压进 $b_t$, 新 action 与 observation 只需在它上面递推. Model 未知时, recurrent network 学到的 hidden state是在近似这类 filtering computation, 但未必具有 calibrated posterior 含义.

## 2. MDP 的组成与 state 边界

MDP 把可控制的随机过程压缩成当前 state, action 与 one-step kernel. 这个抽象的价值是让 future distribution 可以递归计算; 代价是建模者必须承担 state 是否充分,reward 放在哪一步,terminal 怎样表示等选择. 算法只能求解给定 MDP, 不会替建模者补上遗漏变量. Finite table 最适合展开 shape 与求和维度, 但定义不只服务 tabular problem. Continuous control,token generation 和 tool-using Agent 都可以用同一组对象描述, 只是 table 会换成 density 或 function approximator. 一个 discounted finite MDP 可以写成

$$
\mathcal M=(\mathcal S,\mathcal A,p,\gamma,\mu).
\tag{6}
$$

$\mathcal S$ 是 state set, $\mathcal A$ 是 action set, $\mu(s)=\Pr(S_0=s)$ 是 initial-state distribution, $\gamma\in[0,1)$ 是 discount factor. Environment kernel

$$
p(s',r\mid s,a)
=\Pr(S_{t+1}=s',R_{t+1}=r\mid S_t=s,A_t=a)
\tag{7}
$$

同时描述 next state 与 immediate reward. 对每个 $(s,a)$,

$$
\sum_{s'\in\mathcal S}\sum_r p(s',r\mid s,a)=1.
$$

若只关心 transition 与 expected reward, 可以由 joint kernel 得到

$$
P(s'\mid s,a)=\sum_r p(s',r\mid s,a),
\tag{8}
$$

$$
R(s,a)=\sum_{s',r} p(s',r\mid s,a)r.
\tag{9}
$$

还可以保留依赖 next state 的期望 reward $R(s,a,s')=\mathbb E[R_{t+1}\mid s,a,s']$. 写 Bellman equation 时必须选定一种 reward 口径. 如果 reward 随 next state 变化, 却只在 transition 外写一个未经期望的 $R(s,a,s')$, 求和会漏掉或重复 transition probability. **2.1. Shape.** 设离散 state 数为 $n=|\mathcal S|$, action 数为 $m=|\mathcal A|$. 统一 action set 时:

- State index $s$ 是 scalar, one-hot state 可以写成 $e_s\in\mathbb R^n$.
- Policy matrix $\Pi$ 的 shape 是 $[n,m]$, 第 $s$ 行为 $\pi(\cdot\mid s)$.
- Transition tensor $P$ 的 shape 是 $[n,m,n]$, $P[s,a,s']$ 沿末维和为 1.
- Expected reward table $R$ 的 shape 是 $[n,m]$; 若保留 next state, $R'$ 的 shape 是 $[n,m,n]$.
- State value $V\in\mathbb R^n$, action value $Q\in\mathbb R^{n\times m}$.

Continuous state 或 action 下, 这些 table 变成 probability density, kernel 或 function approximator. Sum 改成 integral, Bellman structure 不变, 但不能再通过遍历所有 state-action pair 精确计算. **2.2. Joint kernel 为什么比两张 table 更基础.** Reward 可能和 next state 相关. 例如 action `push` 有 $0.8$ probability 到达目标 state 并获得 reward $+1$, 有 $0.2$ probability 滑回原 state 并获得 reward $-2$. Joint kernel 是

$$
p(s_{\mathrm{goal}},1\mid s,\texttt{push})=0.8,
$$

$$
p(s,-2\mid s,\texttt{push})=0.2.
$$

由式 (8), transition probability 分别为 $0.8$ 与 $0.2$. Expected reward 是

$$
R(s,\texttt{push})=0.8\times1+0.2\times(-2)=0.4.
$$

只保存 $P$ 和 $R(s,a)$ 足以计算 expected return, 但会丢掉 reward 与 next state 的 correlation. 如果算法要估计 return variance, 风险或 reward distribution, joint kernel 中的更多信息仍然有用. MDP 文献也常把模型写成 $(\mathcal S,\mathcal A,P,R,\gamma)$. 这种写法没有错, 但要检查 $R$ 到底表示 expected reward $R(s,a)$, conditional reward $R(s,a,s')$, 还是 reward distribution. 同一个字母在不同资料里口径不同, 代入 Bellman equation 前必须先读定义. **2.3. Terminal state 的两种表示.** Episodic task 可以在进入 terminal 后停止 trajectory, 也可以把 terminal 写成 absorbing state:

$$
P(T\mid T,\texttt{stop})=1,
\qquad R(T,\texttt{stop})=0.
$$

第二种表示让所有 trajectory 在形式上继续无限延伸, terminal 之后 reward 永远为 0, return 不变. 实现中还要区分 true termination 与 time-limit truncation. 前者的 future value 通常为 0; 后者只是采样器在固定长度切断, environment 可能尚未结束, 是否 bootstrap 要看具体目标定义. **2.4. Markov property 是 state 表示的要求.** Controlled Markov property 为

$$
\Pr(S_{t+1},R_{t+1}\mid S_0,A_0,\ldots,S_t,A_t)
=p(S_{t+1},R_{t+1}\mid S_t,A_t).
\tag{10}
$$

它说的是: 给定当前 state 与 action 后, 更早 history 对下一步分布不再提供额外信息. 这不等于 environment 没有 memory. 如果温度控制系统的下一步还依赖过去一小时的累计热量, 当前温度本身就不是 Markov state; 把累计热量加入 state 后, 扩充表示才可能满足式 (10). Observation 也不一定是 state. 在 partially observable environment 中, Agent 看到 $O_t$ 却无法由 $O_t,A_t$ 决定下一步 distribution. 这时需要 belief state, history encoder 或 recurrent memory. 直接把 observation 当作 Markov state 套 Bellman tabular derivation, 得到的对象仍可训练, 但经典 MDP 的充分状态假设已经不成立. **2.5. 怎样检查 state 是否漏了变量.** 实务中无法靠一眼确认 Markov property, 可以从 conditional prediction 入手. 如果在固定 $(S_t,A_t)$ 后, 加入更早 history 仍显著改善对 $(S_{t+1},R_{t+1})$ 的预测, 当前 state 表示就可能遗漏信息. 例如库存系统只记录现有库存, 未记录已经下单但尚未到货的数量, 同样库存和补货 action 会因在途订单不同而产生不同 next state.

补 state 也有代价. 把完整 history 全部当 state 在理论上可能恢复 Markov 性, state space 却随时间增长, 相同局面难以共享统计量. 一个好的 state representation 要在 sufficiency 与 compactness 之间选择: 对 future prediction 足够, 又不携带与 future 无关的全部过去. Policy 若使用 recurrent hidden state, environment state 与 Agent internal state 还要分开. Environment transition 由真实 state 和 action 决定; hidden state 是 policy 根据 observation history 计算的 memory. 把两者统称为 state 会让 transition kernel 的定义含糊. **2.6. Stationary 与 time-dependent MDP.** 正文默认 kernel $p(s',r\mid s,a)$ 不随 $t$ 变化, 这叫 time-homogeneous dynamics. 如果电价,流量或对手策略随时段变化, 更准确的 kernel 是 $p_t(s',r\mid s,a)$. 一种处理方式是把 time 或 regime 加入 state, 令 augmented state 为 $(s,t)$ 或 $(s,z_t)$, 再恢复 stationary notation. 把 time 加入 state 会增大 state space, 却能避免把不同时段的 transition 混成一张 average table. 如果 deployment regime 会发生训练时未见过的变化, 单纯增广 time index 仍不够, 因为 kernel 本身发生 distribution shift. Reward 也可能 nonstationary. 用户偏好更新,任务阶段切换或 verifier 版本变化都会改变同一 outcome 的 score. 旧数据的 state dynamics 也许仍可复用, 旧 reward label 却不再对应当前 objective. 将 dynamics learning 与 reward modeling 分开, 能让两类变化分别接受检查.

### 2.1. Policy,trajectory 与 occupancy

Environment kernel 规定 action 的后果, policy 规定每个 state 怎样选择 action. 二者与 initial distribution 相乘, 才得到训练数据真正来自的 trajectory distribution. 只写 policy probability 而忽略 state 如何被访问, 会高估 action-level importance ratio 能修正的范围. Occupancy 把整条 trajectory 压缩成 state 或 state-action 的访问权重. Policy gradient,performance difference lemma 和 offline RL 都使用它, 但不同资料会在 normalized 与 unnormalized 版本之间切换. 本节把两种口径和采样修正放在一起. **3.1. Policy 与 trajectory probability.** Stochastic policy 是 action conditional distribution:

$$
\pi(a\mid s)=\Pr(A_t=a\mid S_t=s),
\qquad
\sum_a\pi(a\mid s)=1.
\tag{11}
$$

给定 $\mu$, $\pi$ 与 environment kernel, trajectory probability 为

$$
p_\pi(\tau)
=\mu(s_0)\prod_{t=0}^{T-1}
\pi(a_t\mid s_t)p(s_{t+1},r_{t+1}\mid s_t,a_t).
\tag{12}
$$

式 (12) 把两类随机性分开. Policy 决定 action probability, environment 决定 action 之后的 state-reward probability. On-policy expectation $\mathbb E_{\tau\sim p_\pi}$ 同时对两者取平均. 若 data 由另一 policy $b$ 生成, trajectory distribution 是 $p_b$, 不能只因当前模型叫 $\pi$ 就把样本写成来自 $p_\pi$. **3.2. State occupancy distribution.** Discounted state occupancy 把 trajectory distribution 投影到每个时刻访问 state 的频率. 下面先采用 continuing 口径; episodic task 则把 terminal state 延伸成 self-loop absorbing state, 因而每个 $t\ge 0$ 都有一个 $S_t$:

$$
\rho_\pi(s)=\sum_{t=0}^{\infty}\gamma^t
\Pr(S_t=s\mid\pi),
\tag{13}
$$

归一化版本为

$$
d_\pi(s)=(1-\gamma)\rho_\pi(s).
\tag{14}
$$

因为每个时刻的 state probability 和为 1,

$$
\sum_s d_\pi(s)
=(1-\gamma)\sum_{t=0}^{\infty}\gamma^t=1.
$$

$d_\pi$ 是一个 probability distribution, $\rho_\pi$ 的总质量则是 $1/(1-\gamma)$. 这里的质量包含 terminal 后反复访问 absorbing state 的部分. 如果研究对象只包含终止前仍需决策的 state, 应另定义

$$
\rho_\pi^{\mathrm{dec}}(s)
=\mathbb E_\pi\left[\sum_{t=0}^{T-1}\gamma^t
\mathbf1\{S_t=s\}\right].
$$

此时 $\sum_s\rho_\pi^{\mathrm{dec}}(s)=\mathbb E[(1-\gamma^T)/(1-\gamma)]$, 一般小于 $1/(1-\gamma)$; 若要把它变成 probability distribution, 归一化常数也应使用这项期望, 不能直接乘 $1-\gamma$. 策略改变 action distribution 后, future state occupancy 也会改变. Importance sampling 只修正某个已观察 state 上的 action probability, 不能自动补出 behavior policy 从未访问的 state. 这条边界在 TRPO, PPO 和 offline RL 中都会再次出现. State-action occupancy 可以写成 $d_\pi(s,a)=d_\pi(s)\pi(a\mid s)$. 对任意函数 $f(s,a)$,

$$
\mathbb E_{s\sim d_\pi,a\sim\pi}[f(s,a)]
=\sum_{s,a}d_\pi(s)\pi(a\mid s)f(s,a).
$$

Policy gradient objective 和 performance difference lemma 经常用这个记号缩短 trajectory expectation, 但归一化与未归一化版本会相差 $1-\gamma$. **3.3. Trajectory ratio 与 per-decision ratio.** 假设 behavior policy 为 $b$, target policy 为 $\pi$, 两者在同一个 environment kernel 和 initial distribution 中运行. 由式 (12), trajectory density ratio 为

$$
\frac{p_\pi(\tau)}{p_b(\tau)}
=\prod_{t=0}^{T-1}
\frac{\pi(a_t\mid s_t)}{b(a_t\mid s_t)}.
$$

Initial distribution 与 transition kernel 在分子分母相同, 所以抵消; ratio 只剩 policy action probability. 这不表示 state distribution 没有改变. State shift 已经通过前面 action ratio 的连乘隐式进入 trajectory weight. 若只给当前 action 乘一个 ratio, 则没有修正此前 action 导致的 state visitation 差异. 用完整 trajectory ratio 乘 $G_0$ 可以得到 off-policy return estimator. Horizon 较长时, ratio product 可能接近 0 或非常大. Per-decision importance sampling 利用第 $t$ 个 reward 只受此前 action 影响, 对 $R_{t+1}$ 只乘到时刻 $t$ 的 cumulative ratio:

$$
W_{0:t}=\prod_{i=0}^{t}
\frac{\pi(a_i\mid s_i)}{b(a_i\mid s_i)}.
$$

Estimator 写成 $\sum_t\gamma^tW_{0:t}R_{t+1}$. 它避免让很晚 action 的 ratio 影响很早 reward, 通常比整条 trajectory 共用一个 weight 更细. 但 cumulative product 仍会随 $t$ 增长, support 缺口也仍然存在. **3.4. 从 sample 估计 occupancy.** 给定 $M$ 条 target-policy episodic trajectory, 终止前 decision-state occupancy $\rho_\pi^{\mathrm{dec}}$ 的 empirical estimator 可以写成

$$
\widehat\rho_\pi^{\mathrm{dec}}(s)=\frac1M\sum_{i=1}^{M}
\sum_{t=0}^{T_i-1}\gamma^t\mathbf1\{s_t^{(i)}=s\}.
$$

$\mathbf1$ 是 indicator. 每访问一次 $s$ 就按 $\gamma^t$ 加权. 真正 termination 后不再有决策, 因而这正对应上面的 decision-state occupancy 定义; 若只是 data collector 在 $T_i$ truncation, 尾部仍可能存在的 decision-state visit 被截掉, estimator 对 $\rho_\pi^{\mathrm{dec}}$ 仍会少算. 如果目标是式 (13) 的 absorbing-state occupancy, 则还要把每条已终止轨迹余下的折扣质量记到对应 terminal state 上. Behavior data 下可以乘 cumulative ratio 估计 target occupancy, 但 variance 与上一节相同. 更根本的问题是 coverage: behavior 从未进入的 state 没有 indicator, 再大的 ratio 也无法凭空生成 sample. Offline RL 的 conservative objective,uncertainty penalty 和 behavior regularization 都在不同程度上回应这一边界, 但不能把缺失区域变成已知区域.

## 3. Return,value 与三状态手算

Return 是一条 trajectory 上从当前时刻开始累积的随机量, value 是在给定 state 或 state-action 条件下对 return 求 expectation. 二者由 $G_t=R_{t+1}+\gamma G_{t+1}$ 接起来, 这条 sample identity 经过条件期望后才成为下一篇的 Bellman equation. 为了让定义能够复算, 本节使用一个只有三个 state 的 MDP. 它同时包含 terminal action 与 self-loop, 足以展示有限 trajectory,无限 trajectory,discount 与 stochastic policy 怎样共同决定 value. 从时刻 $t$ 开始的 discounted return 定义为

$$
G_t=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}.
\tag{15}
$$

把第一项拆出:

$$
G_t=R_{t+1}+\gamma G_{t+1}.
\tag{16}
$$

式 (16) 是 sample-level identity, 对每条 trajectory 都成立. Bellman equation 对它取条件期望. 若 reward 有界 $|R_t|\le R_{\max}$ 且 $\gamma<1$, 则

$$
|G_t|\le\frac{R_{\max}}{1-\gamma},
$$

所以 infinite-horizon return 收敛. Episodic finite-horizon task 可以允许 $\gamma=1$, 前提是 episode 以适当条件结束且 return 有定义. Continuing task 中直接取 $\gamma=1$ 需要改用 average reward 等其他口径. 常见 policy objective 为

$$
J(\pi)=\mathbb E_{S_0\sim\mu,\tau\sim\pi}[G_0]
=\sum_s\mu(s)V^\pi(s).
\tag{17}
$$

$J(\pi)$ 是 initial distribution 加权的 scalar, $V^\pi$ 是每个 state 一个值的 vector. 两个 policy 可能在某些 state 上各有优劣; 比较 $J$ 时还要看 $\mu$ 把质量放在哪里. **4.1. Discount factor 改变的不是一个普通权重.** $\gamma$ 同时改变 effective horizon 与 optimal policy. Reward 在 $k$ 步后出现时, 对 $G_t$ 的权重为 $\gamma^k$. 当 $\gamma=0.5$, 十步后的权重约为 $0.001$; 当 $\gamma=0.99$, 同一 reward 的权重约为 $0.904$. 因此两个实验使用不同 $\gamma$, 即使 environment reward 完全相同, 优化的 objective 也不同. Discount 还可解释成每一步以 probability $1-\gamma$ 终止的随机 horizon. 在这个解释下, normalized occupancy $d_\pi$ 正是随机终止前访问 state 的 distribution. 这能帮助理解为什么 $1-\gamma$ 会出现在归一化公式里, 但具体 task 的 termination 与数学 discount 仍是两个独立机制. Finite horizon $H$ 的 return 为

$$
G_t^{(H)}=\sum_{k=0}^{H-t-1}\gamma^kR_{t+k+1}.
$$

剩余时间会影响 future opportunity, 所以严格 state 可以包含 time index. 同一个物理位置在离终点 1 步与 100 步时价值不同, 用一个 stationary $V(s)$ 合并它们会丢信息. **4.2. 三状态 MDP.** 后续 Bellman 篇继续使用下面的 environment. State set 是 $\{A,B,T\}$, $T$ 为 terminal state, discount $\gamma=0.5$. Transition 全部 deterministic:

| State | Action | Next state | Reward |
|---|---|---|---:|
| $A$ | `quit` | $T$ | $1.5$ |
| $A$ | `go` | $B$ | $0$ |
| $B$ | `cash` | $T$ | $4$ |
| $B$ | `loop` | $B$ | $1$ |
| $T$ | `stop` | $T$ | $0$ |

取 stochastic policy

$$
\pi(\texttt{quit}\mid A)=0.25,
\quad
\pi(\texttt{go}\mid A)=0.75,
$$

$$
\pi(\texttt{cash}\mid B)=0.5,
\quad
\pi(\texttt{loop}\mid B)=0.5.
\tag{18}
$$

初始状态固定为 $A$. Trajectory

$$
\tau_1=(A,\texttt{go},0,B,\texttt{cash},4,T)
$$

的 probability 是

$$
p_\pi(\tau_1)=1\times0.75\times1\times0.5\times1=0.375.
$$

它的 return 为

$$
G_0=0+0.5\times4=2.
$$

另一条 trajectory 先 `go`, 在 $B$ 连续两次 `loop`, 再 `cash`:

$$
p_\pi(\tau_2)=0.75\times0.5\times0.5\times0.5=0.09375,
$$

$$
G_0=0+0.5\times1+0.5^2\times1+0.5^3\times4=1.25.
$$

单条 sample return 不等于 $V^\pi(A)$. 后者还要把立即 `quit`, 不同 loop 次数等全部 trajectory 按式 (12) 加权. 下一篇会用 Bellman recursion 在不枚举无限条 trajectory 的情况下求得 $V^\pi(A)=1.625$. **4.3. 直接枚举无限条 trajectory.** 也可以用 geometric series 验证这个答案. 从 $B$ 开始, 先执行 $k\ge0$ 次 `loop` 再 `cash` 的 probability 是 $0.5^{k+1}$. 对应 return 是

$$
G_B(k)=\sum_{j=0}^{k-1}0.5^j+4\times0.5^k
=2(1-0.5^k)+4\times0.5^k.
$$

因此

$$
\begin{aligned}
V^\pi(B)
&=\sum_{k=0}^{\infty}0.5^{k+1}G_B(k)\\
&=2\sum_{k=0}^{\infty}0.5^{k+1}
+2\sum_{k=0}^{\infty}0.5^{2k+1}\\
&=2+\frac{1}{1-0.25}
=\frac{10}{3}.
\end{aligned}
$$

从 $A$ 立即 `quit` 的 contribution 是 $0.25\times1.5=0.375$. 选择 `go` 后 reward 为 0, $B$ 的 value 还要乘一次 discount:

$$
V^\pi(A)=0.375+0.75\times0.5\times\frac{10}{3}
=1.625.
$$

枚举法与下一篇 Bellman solution 一致. 前者把每一种 loop length 展开, 后者把它们压进一个 recursive equation; Bellman 的计算优势会随 horizon 和 branching factor 增长而更加明显. **4.4. 同一个例子的 Q 与 advantage.** 已知 $V^\pi(B)=10/3$, 两个 action value 是

$$
Q^\pi(B,\texttt{cash})=4,
$$

$$
Q^\pi(B,\texttt{loop})=1+0.5\times\frac{10}{3}
=\frac83.
$$

按 policy 各取 $0.5$ 的 expectation:

$$
V^\pi(B)=0.5\times4+0.5\times\frac83
=\frac{10}{3}.
$$

所以两个 advantage 分别为 $2/3$ 与 $-2/3$. 它们按 policy average 后为 0. Advantage 为正表示该 action 比当前 policy 在同一 state 的平均选择好, 不表示 immediate reward 必然为正. 在 $A$ 上,

$$
Q^\pi(A,\texttt{quit})=1.5,
\qquad
Q^\pi(A,\texttt{go})=0.5\times\frac{10}{3}=\frac53.
$$

$V^\pi(A)=1.625=13/8$, 因而 advantage 是 $-1/8$ 与 $1/24$. Policy 以 $0.25$ 和 $0.75$ 加权后仍为 0. 这个数值检查能发现常见的 discount 错位: `go` 后到达 $B$, $V(B)$ 必须乘一次 $\gamma$, 不能直接把 $10/3$ 当作 $Q(A,\texttt{go})$.

### 3.1. Observation,采样估计与适用边界

MDP 的数学对象通常不可直接完整读取. Agent 看到 observation, dataset 只记录有限 trajectory, transition 与 reward 也可能随部署环境变化. 因而理论定义进入实现时, 要分别检查 information,coverage 与 estimation 三个缺口. 这些缺口不会让 MDP 失去价值. 它们告诉我们具体是哪项假设被放松: observation 不充分对应 partial observability, 行为数据覆盖不足对应 distribution shift, finite sample 对 expectation 的误差则属于统计估计. 把三者混成一句「环境复杂」无法指导算法选择. **5.1. POMDP 与 belief state.** POMDP 在 hidden state $S_t$ 之外增加 observation kernel $O(o_t\mid s_t)$. Agent 看到 $O_t$, 没直接看到 $S_t$. 同一个 observation 可能由多个 hidden state 产生, 它们对应不同 transition 与 reward. 此时仅用 reactive policy $\pi(a\mid o)$ 会把不同 future distribution 混在一起. History $h_t=(o_0,a_0,\ldots,o_t)$ 总能保存已见信息, 但长度持续增长. Belief state

$$
b_t(s)=\Pr(S_t=s\mid h_t)
$$

把 history 压成 hidden state 的 posterior distribution. 在已知 model 下, action 和新 observation 到来后可以用 Bayes rule 更新 $b_t$. Belief 本身是 Markov state, 代价是它通常位于 continuous simplex 中, 即使原 hidden state finite, 精确规划也会很贵. Recurrent neural policy 用 hidden vector 近似 history summary. 这个 vector 是否充分由训练决定, 不会因使用 RNN 就自动成为 belief state. 评测时可以构造 observation aliasing case: 当前 observation 相同, 只有早期线索不同, 检查 policy 是否仍选择对应 action. **5.2. Finite sample 怎样估计 expectation.** 给定独立 sample return $G^{(1)},\ldots,G^{(N)}$, Monte Carlo mean

$$
\widehat V_N(s)=\frac1N\sum_{i=1}^{N}G^{(i)}
$$

在 trajectory 确实从同一 $(s,\pi)$ 条件生成时估计 $V^\pi(s)$. Sample variance

$$
\widehat\sigma^2=\frac{1}{N-1}
\sum_i(G^{(i)}-\widehat V_N)^2
$$

刻画 return dispersion, mean 的 standard error 约随 $1/\sqrt N$ 下降. Return 高方差时, 只增加少量 trajectory 不会让 estimate 稳定. 同一条 trajectory 上相邻 time step 的 return 高度相关, 不能把它们机械当成独立 sample 计算 standard error. Vectorized environment 之间也可能共享随机种子或初始 scenario. 报告 sample 数时要说明是 trajectory 数,transition 数还是独立 environment seed 数. Bootstrapping estimator 用 current value estimate 替代 future sample return, 例如 $R_{t+1}+\gamma V(S_{t+1})$. 它降低等待完整 trajectory 的成本与部分 variance, 同时引入 current value error. Monte Carlo 与 TD 的区别因此不只是代码里是否读取 next state, 而是 target 中有多少 future 来自真实 sample, 多少来自估计器自身. **5.3. 大模型后训练中的 state 与 action 粒度.** 把 language model 写成 MDP 时, 最细粒度做法令 state 为 prompt 加已生成 prefix, action 为 next token. Transition 把 action append 到 prefix, environment dynamics 几乎 deterministic, terminal 由 EOS 或 length limit 触发. Sequence-level reward 通常只在末尾出现, credit assignment 要把它传回此前 token action. 也可以把一整段 response 当作单个 action. State 是 prompt 或 interaction history, policy probability 是整个 sequence probability. 这使 horizon 变短, action space 却变成所有可能 sequence. DPO 常在这种 sequence-action 视角下写偏好; token-level policy gradient 则在求导时重新展开 autoregressive factorization. 两种视角可以互相转换, 但 reward,KL 与 occupancy 的聚合维度必须一致.

Tool-using Agent 的 state 还要包含 environment observation,已验证事实与工具副作用. 只把 chat transcript 当 state, 却不读取外部文件或数据库当前值, state 可能已经过期. Long-Horizon task 中这种 nonstationarity 尤其明显: environment 会因 Agent action 和外部进程共同变化, 固定 transition kernel 只是局部近似. **5.4. Coverage 与 estimator 诊断.** 只汇报 sample mean 不能判断 estimator 是否可靠. On-policy evaluation 至少同时记录 trajectory 数,return standard deviation,episode length distribution,termination/truncation 比例和独立 seed. 若 initial state 难度相差很大, 还应按 $S_0$ 或 task bucket 分层报告, 防止 easy state 的数量掩盖 hard state 的高 variance. Importance sampling 可以计算一个经验 effective sample size:

$$
N_{\mathrm{eff}}
=\frac{(\sum_iw_i)^2}{\sum_iw_i^2}.
$$

所有 weight 相同时, $N_{\mathrm{eff}}=N$; 少数 sample 占据绝大 weight 时, 它会远小于 $N$. 这个量不是严格 error guarantee, 但能暴露「名义上有很多数据, estimate 实际由少量 trajectory 决定」. Maximum weight,weight quantile 与 unsupported event 也应一起报告. Off-policy estimate 还应与 small on-policy rollout 交叉检查. 两者差异可能来自 weight variance,behavior coverage 或 environment drift. 如果只在已有 log 上调整 estimator, 无法区分算法 bias 与 log 本身缺失的 action. MDP 建模完成后可以做一组可执行检查. 固定 state-action 后重复 environment step, 核对 next-state/reward empirical distribution; 重放相同 random seed, 检查 simulator 是否可复现; 对 terminal transition 验证 future reward 为 0; 对 truncation case 检查 bootstrap mask; 改变 history 中理论上无关的字段, 看 one-step distribution 是否保持不变. 统计诊断仍只覆盖已观测区域. Rare catastrophic state 可能在有限 rollout 中一次也没出现. Safety-critical task 还需要 adversarial scenario,formal constraint 或外部 risk model, 不能把 sample average 当成完整安全证明. **5.5. Action,observation 与因果干预.** Transition kernel $P(s'\mid s,a)$ 描述 environment 在 Agent **执行** action $a$ 后的分布. Offline log 中的 conditional frequency $p(s'\mid s,A=a)$ 只有在行为策略的 action assignment 没有遗漏 confounder 时, 才能直接当作 intervention effect. 若 operator 会根据未记录的风险信号选择 action, 同一个 observed state 下 action group 的 hidden risk 不同, frequency difference 会同时包含 action effect 与 selection bias.

MDP 通常假设 state 已包含决定 action consequence 的相关信息. State 漏掉 confounder 时, 即使 one-step prediction 在训练 log 上表现很好, 用 learned model 比较 counterfactual action 仍可能出错. Randomized exploration 能改善 action coverage, 但 high-risk environment 常无法任意试错, 需要 domain assumption 或 causal model 补充. 这一区别也解释了 behavior cloning 与 control 的距离. Behavior cloning 学 $b(a\mid s)$, 回答 expert 在 log state 上做了什么; control 需要比较若在同一 state 改做其他 action 会发生什么. 后一个问题依赖 transition 与 reward 的 counterfactual, 不能只靠 action label frequency 回答. Tool Agent 中也存在同样问题. 历史数据显示「调用测试工具」常与最终成功相关, 不代表无条件多调用测试就能提高成功率; Agent 往往在改动已经接近正确时才运行某些检查. 可靠 harness 要记录 action 前 state 和 action 后可验证变化, 才能把工具存在于成功 trajectory 与工具造成成功区分开.

因此, 一份可复现的 MDP 描述至少要给出 state 与 observation 的区别,action 的执行语义,joint transition-reward kernel,initial distribution,termination/truncation 规则和 discount. 只列 state/action 名称无法唯一确定同一个优化问题.
这些字段也应进入实验配置, 让训练与评测确实运行在同一任务定义上. Finite tabular MDP 让定义最清楚, 但大模型后训练常处在更复杂的状态表示中. Prompt, 已生成 token, tool observation 和 verifier state 共同构成 environment state; action 可能是下一个 token, 也可能是一整段 response. 选哪种时间粒度会改变 transition, reward placement 与 horizon, 不应在同一推导里来回切换. MDP 只规定 environment 与 policy 怎样生成 trajectory, 没有规定 reward 是否表达了真实目标, 也没有保证 state 可以从 observation 恢复. Reward hacking 属于 objective specification 问题, partial observability 属于 state information 问题, distribution shift 则让训练时 kernel 与部署时 kernel 不同. Bellman equation 在给定 MDP 内仍然成立, 但它不会修复 MDP 本身的建模错误.

建立一个 MDP 时可以依次核对: state 是否足以预测下一步; action 粒度是否与决策频率一致; reward 在哪个 transition 上发出; terminal 与 truncation 是否分开; initial distribution 是否对应真实入口; discount 与实际 horizon 是否匹配. 这些选择共同定义优化问题. 算法在这个模型上收敛, 只说明它解出了所定义的问题. 下一篇将从式 (16) 对条件期望, 得到 Bellman expectation equation; 再把固定 policy 的 action expectation 换成 maximization, 得到 Bellman optimality equation. Value iteration 与 policy iteration 都是在有限, 已知模型条件下求这些 fixed point 的方法.

## 4. 从一批 transition 还原公式中的对象

定义看懂以后，最容易出错的地方反而是 batch。设一次收集 $B=32$ 条轨迹，每条最多 $L=128$ 步；离散状态数为 $n$，动作数为 $m$。补齐后的张量通常写成：

- `states`: $[B,L]$，每个位置保存状态编号；若已经编码成向量，则是 $[B,L,d_s]$；
- `actions`: $[B,L]$，连续动作则为 $[B,L,d_a]$；
- `rewards`: $[B,L]$，其中 `rewards[b,t]` 对应 $R_{t+1}$；
- `terminated` 与 `truncated`: 都是 $[B,L]$，但语义不同；
- `valid_mask`: $[B,L]$，只负责排除 padding；
- `log_probs`: $[B,L]$，保存采样时行为策略对实际动作给出的对数概率。

这里有三个 mask，不能因为 shape 相同就合成一个。`valid_mask=0` 表示那个位置根本没有 transition；`terminated=1` 表示环境语义上的未来回报结束；`truncated=1` 只表示采样器不再继续记录。若将长度为 83 的轨迹补齐到 128，后 45 个位置既不能进入 return mean，也不能进入 occupancy count。若第 83 步是时间上限截断，critic target 是否 bootstrap 还要由任务定义决定。 对第 $b$ 条轨迹，relative return 可以反向扫描：

$$
G_{b,t}=R_{b,t+1}+\gamma(1-D_{b,t})G_{b,t+1},
$$

其中 $D$ 是「真正终止」的 mask，而不是 `valid_mask`。Padding 需要在写入结果或计算 loss 时另外乘掉。**「终止 future value」与「排除不存在的样本」是两件事。** 把二者混成 `done`，常会让 time-limit state 被错误地当作零价值，也可能让 padding 中的零奖励参与 batch average。 **6.1. 一条四步轨迹的反向手算.** 假设观测到奖励 $(1,0,2,-1)$，$\gamma=0.9$，末步是真终止。则

$$
G_3=-1,
$$

$$
G_2=2+0.9(-1)=1.1,
$$

$$
G_1=0+0.9(1.1)=0.99,
$$

$$
G_0=1+0.9(0.99)=1.891.
$$

如果第四步只是日志在时间上限处截断，而且 critic 估计下一状态价值为 $V(s_4)=5$，末步 target 应先写成

$$
G_3^{\text{boot}}=-1+0.9\times5=3.5,
$$

然后向前递推得到 $G_2=5.15,G_1=4.635,G_0=5.1715$。同一段已观测 reward，因为终止语义不同，训练 target 差了很多。实现评审不能只问数组里有没有 `done`，要问它究竟编码了哪一种事件。 **6.2. 从计数得到经验 transition kernel.** 在 tabular 环境中，可用计数

$$
N(s,a,s')=\sum_{i,t}
\mathbf 1\{S_t^{(i)}=s,A_t^{(i)}=a,S_{t+1}^{(i)}=s'\}
$$

估计 transition：

$$
\widehat P(s'\mid s,a)=
\frac{N(s,a,s')}{N(s,a)},\qquad
N(s,a)=\sum_{s'}N(s,a,s').
$$

若 $(s,a)$ 从未出现，分母为零。这时没有一个由数据推出的 transition distribution；把整行填成均匀分布或全零都是额外约定。加 Dirichlet 伪计数可写成

$$
\widehat P_\alpha(s'\mid s,a)=
\frac{N(s,a,s')+\alpha_{s'}}
{N(s,a)+\sum_j\alpha_j},
$$

它改善小样本数值稳定性，同时把 prior 引入估计。报告模型误差时，应把真实计数和伪计数分开保存，否则一个平滑后的「全覆盖」矩阵会掩盖数据其实从未执行过某些动作。 设 `push` 被执行 10 次，8 次到 goal 并得 $+1$，2 次留在原地并得 $-2$。经验概率是 $(0.8,0.2)$，经验 expected reward 为 $0.4$。若把这十次观测形成的经验分布本身当作分布，即方差分母取 $N=10$，plug-in variance 为

$$
0.8(1-0.4)^2+0.2(-2-0.4)^2=1.44.
$$

若目标是由样本估计总体方差，无偏样本方差应使用分母 $N-1$，得到 $1.44\times10/9=1.6$；据此估计均值标准误为 $\sqrt{1.6/10}=0.4$。所以「估计 reward 是 0.4」不等于这个数字已经精确；若两个动作的 expected reward 只差 0.1，这批数据远不足以稳定排序。这里特意区分了经验分布的描述量与总体方差的无偏估计，避免把两个分母混用。

### 4.1. 有限样本下的 bias、variance 与置信区间

独立同分布回报 $G_1,\ldots,G_N$ 的 Monte Carlo 均值

$$
\widehat V_N(s)=\frac1N\sum_{i=1}^NG_i
$$

在轨迹确实从目标策略、并且都从同一个条件 $S_0=s$ 开始时，是 $V^\pi(s)$ 的无偏估计；其 variance 为 $\operatorname{Var}(G\mid s)/N$。这里的条件很强。若只从长轨迹中搜集访问 $s$ 的片段，这些 return 可能相关；若 episode 难度不同，简单把所有时间步视为独立样本还会低估不确定性。 以回报样本 $(0,1,1,2)$ 为例，均值为 1。采用无偏样本方差，

$$
s_G^2=\frac{(0-1)^2+(1-1)^2+(1-1)^2+(2-1)^2}{4-1}
=\frac23.
$$

均值标准误为 $\sqrt{(2/3)/4}\approx0.408$。四条轨迹的结果只能说明中心大约在哪，远不足以支持精细的算法差异。若这些样本其实来自同一个 episode 的相邻起点，相关性还会让上述独立假设失效。实践中更稳妥的统计单位通常是独立 episode、独立 task 或独立 seed，而不是把每个 token 都当作一张新的彩票。 Bootstrap target 则主动引入另一种交换。用

$$
Y_t=R_{t+1}+\gamma\widehat V(S_{t+1})
$$

替代完整 $G_t$，能少等待许多未来随机奖励，因此往往 variance 更低；只要 $\widehat V$ 不等于真实 $V^\pi$，target expectation 就带有 approximation bias。它的条件偏差是

$$
\mathbb E[Y_t\mid S_t=s]-V^\pi(s)
=\gamma\,\mathbb E[\widehat V(S_{t+1})-V^\pi(S_{t+1})\mid S_t=s].
$$

这条式子把一句常见口号变成了可检查对象：critic 在哪些 next state 上错、这些 state 被当前 transition 访问多少、误差又被 $\gamma$ 缩放多少。$n$-step return 位于完整 Monte Carlo 与一步 bootstrap 之间，它调整的是 bias、variance 与计算延迟的配比，精度仍取决于具体数据和价值误差。 **7.1. 数据相关性为什么会骗过误差条.** 并行环境产生 $B$ 条轨迹，不代表有 $B\times L$ 个独立样本。同一轨迹里相邻 state 共享大量历史，语言模型同一 prompt 下的多条 response 也共享 task difficulty。若一个困难 prompt 采 64 条答案，另一个简单 prompt 只采 1 条，把 65 条答案直接平均会让困难 prompt 获得几乎全部权重。

应先根据 estimand 决定聚合层级。若目标是「prompt 均匀」的平均能力，先在每个 prompt 内平均，再对 prompt 平均；若目标就是线上请求分布，则按请求出现概率加权。误差条也应在独立的顶层单位上计算，或使用 cluster bootstrap：每次重采样 prompt，再保留该 prompt 下成组的 responses。**采样单位、优化单位和汇报单位可以不同，但必须写清楚。**

## 5. 一份最小但完整的 MDP 实验记录

可复现性并不是只给随机种子。一个最小实验记录至少应固定：初始状态分布的版本、环境 kernel 或 simulator 版本、action space 与非法动作处理、reward 代码版本、discount、最大步数、termination/truncation 规则、行为策略 checkpoint、采样温度以及统计聚合方式。 然后保留三层结果。第一层是原始 transition，至少包含 $(s_t,a_t,r_{t+1},s_{t+1})$ 与两种结束标志；第二层是派生量，如 return、importance ratio 和 occupancy count，并记录生成它们的配置；第三层才是平均回报、成功率和置信区间。派生量若算错，可以由第一层重建；只保存最终均值，就无法再判断 reward index 是否错位。

一个很实用的验收 fixture 是两状态、两动作的小环境。先写出完整 $P[s,a,s']$ 与 $R[s,a,s']$，检查每个 $(s,a)$ 的概率和为 1；再枚举所有短轨迹，验证轨迹概率和；随后比较解析期望、批量模拟均值和 Bellman 解。随后故意制造一次截断、一次真终止与一个未覆盖动作，确保三个分支都触发预期逻辑。这个小测试比直接盯着百万步训练曲线更容易发现定义错误。 读完这一篇真正应该建立的是一套对象感：**「trajectory 是样本，kernel 是条件分布，value 是条件期望，occupancy 是访问权重」**。它们可以从同一批日志计算，却绝不是同一个数组的不同名字。后续 Bellman、策略梯度与离策略修正，都是在这四类对象之间做严格变换。 **8.1. Discount 的选择也需要实验边界.**

$\gamma$ 经常被当作固定超参数，其实它同时改变优化目标、有效时域和估计难度。权重降到初始值一半所需的步数满足 $\gamma^h=0.5$，即

$$
h_{1/2}=\frac{\log0.5}{\log\gamma}.
$$

当 $\gamma=0.9$ 时，半衰期约为 6.58 步；$\gamma=0.99$ 时约为 68.97 步；$\gamma=0.999$ 时约为 692.8 步。提高 $\gamma$ 会让更远奖励进入目标，也会放大 return 的数值范围和长程随机性。若 $|R_t|\le R_{\max}$，无限时域 value 满足

$$
|V^\pi(s)|\le\frac{R_{\max}}{1-\gamma}.
$$

$R_{\max}=1$ 时，上界会从 $\gamma=0.9$ 的 10 增长到 $\gamma=0.999$ 的 1000。学习率、value initialization 和数值精度若保持不变，训练行为未必还能比较。 因此比较不同 discount 的算法时，不能只说「其他设置相同」。应同时观察 effective horizon、return scale、episode length 和 reward placement，并说明业务目标是否真的对远期结果采用指数折扣。有限任务有时选择 $\gamma=1$ 完全合理，但这依赖 episode 必然结束且 return 有界；continuing task 直接这样做，则需要平均奖励或其他收敛定义。 **8.2. 随机种子不能替代分布说明.**

固定 seed 只能重现某次伪随机数序列，不能定义实验抽样分布。一个训练 seed 可能同时控制网络初始化、环境初态、动作采样与数据 shuffle；把它们绑在一起，偶然容易的初态可能又恰好配上某种初始化。更清楚的做法是分别记录模型 seed、环境 seed、采样 seed，并在多个独立 run 上汇总。

汇报 `mean ± std` 时也要说明 std 跨什么计算。跨 episode 的标准差描述任务随机性，跨训练 seed 的标准差描述训练过程稳定性，均值的标准误则描述均值估计精度。三者回答不同问题。若只写一个没有层级的误差条，读者无法判断算法是在同一模型上偶尔失败，还是不同训练运行会收敛到不同结果。

末尾检查数据切分是否沿正确单位进行。相邻 trajectory 若来自同一个用户、同一个 prompt 模板或同一个环境地图，把它们随机打散到训练集和测试集会泄漏结构。应按用户、任务族或地图做 group split，再在测试分布上估计 value 与 success rate。这样得到的泛化误差，才对应「进入一个未见任务」而不是「重看同一任务的另一条随机轨迹」。

### 5.1. 从轨迹测度重新检查 MDP

前面的离散公式足以完成多数手算，但长轨迹、连续状态和策略切换会暴露一些被求和符号隐藏的条件。本节把轨迹视为概率空间上的随机元素，再讨论占用测度、停止时间、平均奖励和风险目标。这些工具分别回答无限乘积何时定义、随机终止是否造成选择偏差，以及「两个策略很接近」究竟要在哪个分布下成立。 **9.1. 有限维分布怎样生成整条轨迹.** 给定初始分布 $\rho_0$、策略核 $\pi(da\mid s)$ 与环境核 $P(ds',dr\mid s,a)$，长度 $T$ 的轨迹柱集合概率由迭代积分给出：

$$
\Pr(S_0\in B_0,A_0\in C_0,\ldots,S_T\in B_T)
=\int_{B_0}\rho_0(ds_0)
\prod_{t=0}^{T-1}
\left[\int_{C_t}\pi(da_t\mid s_t)
P(B_{t+1}\mid s_t,a_t)\right].
$$

离散状态下，积分退化成连乘与求和。连续状态下，$P(B\mid s,a)$ 表示落入可测集合 $B$ 的概率，不要求一定存在概率密度。确定性环境也是概率核的特例：若 $s'=f(s,a)$，转移核是集中在 $f(s,a)$ 的 Dirac measure。把确定性转移写成普通密度，容易在变量变换时漏掉奇异部分。 这些相容的有限维分布决定无限轨迹上的概率测度。实际算法很少直接调用这个定理，但它解释了为何「先采初态，再反复按策略和环境采样」能定义一个统一期望。策略梯度、价值函数和重要性采样都在同一个轨迹测度上比较随机变量。

历史依赖策略也能写成核 $\pi(da_t\mid h_t)$，其中 $h_t=(s_0,a_0,\ldots,s_t)$。若状态确实满足 Markov 性，则对任意历史策略，都可以构造只依赖当前状态与时间的 Markov 策略，使每个时刻的状态—动作边缘分布相同。这个结果支持在完全可观测 MDP 中研究 Markov policy；它不表示单个样本路径会相同，也不适用于状态表示遗漏历史信息的情况。 **9.2. 条件期望是价值函数的统一定义.** 价值函数可以写成条件期望

$$
V_t^\pi=\mathbb E_\pi[G_t\mid\mathcal F_t],
$$

其中 $\mathcal F_t$ 表示时刻 $t$ 已知的信息。若状态 $S_t$ 对未来充分，则存在函数 $V^\pi$ 使 $V_t^\pi=V^\pi(S_t)$。这一步正是 Markov 性带来的压缩：整段历史的条件期望能由当前状态表示。 若两个不同历史映射到同一观测 $o_t$，它们对未来回报的条件分布却不同，就不存在只依赖 $o_t$ 的精确价值函数。用神经网络拟合 $V(o_t)$ 时，最小平方解会给出混合条件均值。这个均值可能在训练分布上误差很小，却无法在需要区分两种隐藏状态时指导正确动作。 条件期望还有投影解释。平方可积随机变量构成内积空间，$\mathbb E[G\mid S]$ 是把 $G$ 投影到由 $S$ 可测函数构成的子空间。对任意可测函数 $f(S)$，有正交关系

$$
\mathbb E[(G-\mathbb E[G\mid S])f(S)]=0.
$$

价值回归的不可约误差来自给定状态后仍存在的回报随机性。增加网络容量只能减小函数逼近误差，无法消除条件方差 $\operatorname{Var}(G\mid S)$。判断 critic 是否值得扩大，应先区分这两种误差。 全方差公式给出

$$
\operatorname{Var}(G)=
\operatorname{Var}(\mathbb E[G\mid S])
+\mathbb E[\operatorname{Var}(G\mid S)].
$$

第一项是状态之间可解释的回报差异，第二项是状态内部噪声。一个好的 state representation 会把有预测力的历史压入第一项；环境固有随机性仍留在第二项。组内 baseline 主要消除提示之间的差异，价值函数还可以利用生成前缀解释组内差异。 **9.3. 折扣占用测度满足流量守恒.** 归一化折扣占用测度定义为

$$
d_\gamma^\pi(s,a)=(1-\gamma)
\sum_{t=0}^{\infty}\gamma^t
\Pr_\pi(S_t=s,A_t=a).
$$

它的总质量为一，因此可视为概率分布。状态边缘满足折扣流量方程

$$
d_\gamma^\pi(s)=(1-\gamma)\rho_0(s)
+\gamma\sum_{\bar s,\bar a}
d_\gamma^\pi(\bar s,\bar a)P(s\mid\bar s,\bar a).
$$

左侧是流入状态 $s$ 的总折扣质量；右侧第一项是初始注入，第二项是前一状态经转移进入的质量。策略一致性还要求 $d(s,a)=d(s)\pi(a\mid s)$。因此，一个非负数组要成为某策略的占用测度，必须同时满足流量守恒和动作条件分解。 期望折扣回报可直接写成占用测度上的线性函数：

$$
J(\pi)=\frac{1}{1-\gamma}
\sum_{s,a}d_\gamma^\pi(s,a)r(s,a).
$$

有限 MDP 的最优控制由此可以写成线性规划：在所有满足流量约束的非负 $d(s,a)$ 中最大化奖励内积。求得最优占用后，对 $d(s)>0$ 的状态令 $\pi(a\mid s)=d(s,a)/d(s)$ 即可恢复策略。这个视角把「策略优化」变成「可行流量优化」，也解释了约束强化学习为何常在占用空间中表达成本上限。 若某状态在 $d^\pi$ 下质量为零，数据无法识别策略在该状态的动作分布。两套策略可以在已访问区域完全相同，在零占用区域任意不同。离线评估只比较数据支持集上的行为时，不能据此断言全状态空间策略相同。 **9.4. 平稳分布与折扣占用不是一个对象.** 固定策略诱导状态转移核

$$
P_\pi(s'\mid s)=\sum_a\pi(a\mid s)P(s'\mid s,a).
$$

平稳分布 $\mu_\pi$ 满足 $\mu_\pi^\top P_\pi=\mu_\pi^\top$。它描述链运行很久后的边缘分布，存在性、唯一性与是否从初态收敛需要不可约性、正常返或遍历性等条件。折扣占用 $d_\gamma^\pi$ 总是保留初始分布影响，而且用几何权重强调早期状态。 当链遍历且 $\gamma\uparrow1$ 时，折扣占用在适当条件下趋向平稳分布。有限 $\gamma$ 时二者可能差别很大。设初态总在罕见启动区，系统十步后进入稳定循环；平稳分布几乎看不到启动区，$\gamma=0.9$ 的折扣占用仍给前十步很大质量。用稳态采样估计折扣目标会低估启动行为，用短 episode 数据估计平均奖励又会高估初态瞬态。

周期链也可能有平稳分布，却不从任意初态按时刻边缘收敛。例如两个状态确定性交替，平稳分布是 $(1/2,1/2)$，从状态 0 出发的边缘分布永远在两个点之间振荡。时间平均可以收敛，单时刻分布不收敛。评估 continuing task 时，必须说明使用时间平均、随机截面还是独立稳态样本。 **9.5. 随机终止与停止时间.** 停止时间 $\tau$ 满足事件 $\{\tau\le t\}$ 只依赖时刻 $t$ 前已知信息。首次到达目标、首次失败和预算耗尽都是典型停止时间；「回看完整轨迹后选择奖励最高的时刻」通常不是。这个区别影响能否安全使用条件期望与鞅工具。 对有限停止时间，随机和

$$
G_0^\tau=\sum_{t=0}^{\tau-1}\gamma^tR_{t+1}
$$

可以通过指示变量写成 $\sum_{t\ge0}\gamma^tR_{t+1}\mathbf 1\{\tau>t\}$。交换期望与无限求和需要绝对可积或非负等条件。奖励有界且 $\gamma<1$ 时可由支配收敛保证；$\gamma=1$ 且 episode 可能无限时，期望回报可能不存在。 随机截断会造成生存者偏差。假设困难轨迹更容易超时，训练只保留完成轨迹，那么观测回报条件在「按时完成」事件上，估计的是

$$
\mathbb E[G\mid\tau\le H]
$$

而非原任务的 $\mathbb E[G]$。把超时明确记为失败、为截断状态 bootstrap，或建模 censoring，分别对应不同任务假设。不能删除未完成轨迹后仍把样本均值称为总体成功率。 可选停止也提醒我们谨慎读取训练曲线。若在多个评测点中挑最高分 checkpoint，报告的最大值具有选择偏差；评测噪声越大、检查次数越多，偏差越明显。预先规定停止规则，或用独立测试集只评一次，可以避免把噪声峰值当成策略改进。 **9.6. 平均奖励与 Poisson 方程.** continuing task 不一定适合指数折扣。平均奖励定义为

$$
\rho(\pi)=\lim_{T\to\infty}\frac1T
\mathbb E_\pi\left[\sum_{t=0}^{T-1}R_{t+1}\right].
$$

在遍历条件下，它等于平稳分布下的单步期望奖励。相对价值或 bias function 定义某状态相对长期平均的暂态优势，并满足 Poisson 方程

$$
h^\pi(s)=r_\pi(s)-\rho(\pi)
+\sum_{s'}P_\pi(s'\mid s)h^\pi(s').
$$

$h^\pi$ 加任意常数仍是解，需要固定一个参考状态或令平稳均值为零。这里的「bias」是平均奖励理论中的相对价值名称，与统计估计偏差不是同一概念。 折扣最优策略在 $\gamma$ 接近一时不一定自动等于平均奖励最优策略，尤其在多重 recurrent class 或暂态奖励很大时。折扣目标偏爱更早获得奖励，平均奖励忽略有限启动成本。若生产系统长期运行，启动阶段只发生一次，平均奖励更贴近吞吐；若用户会话短且每次重置，折扣或有限时域目标更合适。 **9.7. 风险中性期望会隐藏尾部.**

最大化 $\mathbb E[G]$ 允许用小概率灾难交换高概率收益。两种策略平均回报相同，回报分布可以完全不同：策略 A 恒得 $1$；策略 B 以 $0.99$ 概率得 $2$，以 $0.01$ 概率得 $-98$，两者期望都为 $1$。安全性、延迟或成本有硬边界时，只比较期望无法表达偏好。 方差惩罚目标 $\mathbb E[G]-\lambda\operatorname{Var}(G)$ 简单，却不满足平移与尺度下的一些直觉，而且动态规划通常需要扩展状态。CVaR 关注最差 $\alpha$ 比例结果。对损失 $L=-G$，

$$
\operatorname{CVaR}_\alpha(L)=
\min_\eta\left[\eta+\frac1\alpha
\mathbb E[(L-\eta)_+]\right].
$$

$\eta$ 在最优时对应分位点。该表示把尾部风险转成可采样目标，但小 $\alpha$ 意味着只依赖少量极端样本，估计方差很高。若数据从未覆盖灾难区域，CVaR 估计同样会过度乐观。 约束 MDP 用期望成本限制表达安全预算：

$$
\max_\pi J_R(\pi)\quad
\text{s.t.}\quad J_C(\pi)\le d.
$$

拉格朗日方法优化 $J_R-\lambda(J_C-d)$，乘子 $\lambda$ 表示放宽约束一单位的边际价值。有限步训练中，固定 $\lambda$ 只是软惩罚，不能保证每次策略都可行；乘子更新太慢会长期违规，太快则与策略更新振荡。真正不可违反的约束还需要动作屏蔽、安全层或可行策略参数化。 **9.8. 模型误差怎样累积.** 若学习得到近似转移核 $\hat P$，单步总变差误差很小也可能沿 horizon 累积。设奖励有界，固定策略下模拟引理给出一类典型界：价值误差随奖励误差按 $1/(1-\gamma)$ 放大，转移误差还会再乘一个有效 horizon，形成约 $1/(1-\gamma)^2$ 的尺度。$\gamma$ 接近一时，微小动力学偏差可能造成很大长期价值误差。

更危险的是策略会主动寻找模型错误。模型在行为数据附近准确，规划器却可能选择模型预测高回报、现实中从未验证的动作。限制策略离数据分布的距离、对模型不确定性施加惩罚或使用保守价值估计，都在减少这种分布外利用。它们牺牲潜在改进，换取模型外推下的可靠性。

一个简单反例是「虚假捷径」状态。数据中动作 $a_1$ 经常出现并得到回报 $1$，动作 $a_2$ 从未出现。近似模型因初始化误把 $a_2$ 预测为回报 $10$，精确规划会立即选择 $a_2$；在真实环境里它可能进入失败吸收态。规划更充分反而让结果更差，根因是优化放大了模型支持集之外的误差。 **9.9. 状态聚合保留了什么.** 大状态空间常用映射 $\phi:S\to Z$ 聚合。若两个原状态映射到同一抽象状态，希望它们对每个动作具有相同即时奖励，并且转移到每个抽象块的概率相同：

$$
r(s,a)=r(s',a),\qquad
\sum_{u:\phi(u)=z}P(u\mid s,a)
=\sum_{u:\phi(u)=z}P(u\mid s',a).
$$

这类 bisimulation 条件保证抽象过程仍能保留控制相关结构。只让观测外观相似、嵌入距离接近，不能保证价值相似；一个视觉差异很小的按钮可能触发完全不同转移。 近似聚合允许奖励与转移有小误差，其价值误差仍受 horizon 放大。表示学习若只优化重建或对比损失，可能丢弃奖励预测所需变量。反过来，把每段历史都当独立状态能保留信息，却失去共享和泛化。状态表示的目标是在可预测未来回报与统计效率之间选择，而不是追求最小或最大的状态维度。

语言模型的上下文表示也是状态聚合。有限窗口删除早期工具结果，摘要会压缩细节，外部记忆检索只返回部分记录。检查 Markov 性的实用办法，是寻找两段得到相同模型输入、但对同一后续动作产生不同结果的历史。找到这样的反例，就说明当前状态接口遗漏了决策相关变量。 **9.10. 压缩映射给出的误差传播界.** 固定策略 Bellman 算子定义为

$$
(T^\pi V)(s)=\sum_a\pi(a\mid s)
\sum_{s'}P(s'\mid s,a)[r(s,a,s')+\gamma V(s')].
$$

对任意两个有界函数 $V,W$，在 sup norm 下有

$$
\lVert T^\pi V-T^\pi W\rVert_\infty
\le\gamma\lVert V-W\rVert_\infty.
$$

证明只需把奖励相消，再利用概率加权平均不超过最大绝对差。Banach 不动点定理因此保证唯一固定点 $V^\pi$，从任意初值反复应用 $T^\pi$ 都以几何速度收敛。迭代 $k$ 次后的误差上界为 $\gamma^k\lVert V_0-V^\pi\rVert_\infty$。 近似更新会在每一步加入误差。若 $V_{k+1}=T^\pi V_k+e_k$ 且 $\lVert e_k\rVert_\infty\le\epsilon$，递推展开得到

$$
\lVert V_k-V^\pi\rVert_\infty
\le\gamma^k\lVert V_0-V^\pi\rVert_\infty
+\frac{1-\gamma^k}{1-\gamma}\epsilon.
$$

单步误差会被放大到约 $\epsilon/(1-\gamma)$。这解释了为何接近一的折扣因子既延长规划范围，也提高价值逼近精度要求。若误差只在数据分布平均意义下很小，sup norm 界不能直接使用；策略可能访问训练分布少见、误差很大的状态。 最优 Bellman 算子把策略期望换成动作最大值，同样在有界函数空间中是 $\gamma$-压缩。最大值运算不会放大 sup norm 差异，因为 $|\max_a x_a-\max_a y_a|\le\max_a|x_a-y_a|$。不过，函数逼近后的投影算子未必保持压缩；神经网络训练也不是精确应用 Bellman 算子。引用表格型收敛结论时必须保留这个边界。 **9.11. 耦合把分布距离变成相遇时间.**

耦合是在同一概率空间上构造两个边缘分布指定的随机变量。对两条从不同初态出发、使用同一策略的 Markov 链，可以设计共享随机数，使它们相遇后永远一起演化。若相遇时间为 $T_c$，则时刻 $t$ 两个状态分布的总变差满足

$$
\lVert P^t(s,\cdot)-P^t(s',\cdot)\rVert_{\rm TV}
\le\Pr(T_c>t).
$$

右侧是尚未相遇的概率。这个不等式把抽象分布距离转成可解释的随机时间：环境忘记初态的速度，取决于两条链多久能够汇合。快速混合任务中，长轨迹后段近似稳态；慢混合或多吸收类任务会长期保留初态影响。 耦合也能比较两个策略。让环境转移尽量共享随机性，只在动作采样不同时分叉；每一步策略总变差越小，短 horizon 内轨迹分叉概率越低。随着时间累积，即使单步差异很小，至少一次分叉的概率也会增长。这正是局部策略约束无法无限期保证整条轨迹接近的原因。 共享随机数还是方差缩减工具。比较策略 A、B 时，若让二者在相同环境种子与初态上运行，回报差 $G_A-G_B$ 的方差为

$$
\operatorname{Var}(G_A)+\operatorname{Var}(G_B)
-2\operatorname{Cov}(G_A,G_B).
$$

正协方差会降低差值方差。前提是共享随机性不会改变各自边缘分布，并且配对单位在统计分析中保留；把配对轨迹拆散后按独立样本计算误差条，会丢失这一收益。 **9.12. 相关轨迹下的有效样本量.** 从同一条 Markov 链连续采集状态，样本不独立。对平稳序列 $X_t$，样本均值方差近似为

$$
\operatorname{Var}(\bar X_T)
\approx\frac{\sigma^2}{T}
\left(1+2\sum_{k=1}^{\infty}\rho_k\right),
$$

其中 $\rho_k$ 是 lag-$k$ 自相关。括号内称为积分自相关时间，等效样本量为 $T_{\rm eff}=T/\tau_{\rm int}$。若状态变化缓慢，采集一百万步也可能只相当于少量独立样本。 把每个 transition 随机打散进 replay buffer 可以降低 minibatch 内的短程相关，却不能增加数据本身覆盖的独立环境模式。来自同一条长 episode 的样本仍共享初态、任务与策略版本。置信区间应按 episode、环境实例或更高层任务做聚类，而非把每个 token 或 transition 当作独立观测。

经典独立样本 Hoeffding 界对有界变量给出指数尾界。Markov 样本需要加入混合条件，界中的有效样本数会由 mixing time 缩小。若链几乎不离开一个 metastable 区域，短期数据可能给出极窄却错误的误差条，因为它根本没有观察到另一个区域。多初态、多条独立链和跨环境实例重复，通常比单纯延长一条链更可靠。 **9.13. 重要性权重的矩决定可估计性.** 从行为分布 $q$ 估计目标分布 $p$ 下的期望，权重为 $w(x)=p(x)/q(x)$。无偏估计

$$
\hat\mu=\frac1N\sum_{i=1}^Nw(X_i)f(X_i),\qquad X_i\sim q
$$

要求 $p$ 对 $q$ 绝对连续。即使支持集条件满足，方差仍可能无限；需要 $\mathbb E_q[w^2f^2]<\infty$。权重二阶矩与 Rényi divergence 有关，$\mathbb E_q[w^2]=\exp(D_2(p\Vert q))$。分布差异增大时，样本复杂度可以指数增长。 经验有效样本量常写成

$$
N_{\rm eff}=\frac{(\sum_iw_i)^2}{\sum_iw_i^2}.
$$

它是诊断量，并不保证有限样本误差。一个尚未采到的极端权重无法出现在分母中，导致 $N_{\rm eff}$ 反而显得乐观。应同时查看权重最大值、分位数、目标与行为策略散度，以及关键动作是否实际出现。 自归一化重要性采样

$$
\hat\mu_{\rm SN}=\frac{\sum_iw_if(X_i)}{\sum_iw_i}
$$

通常方差较低且对未知归一化常数有用，但有限样本有偏。权重裁剪进一步降低方差，偏差来自被截掉的尾部质量。报告结果时应给裁剪阈值与被裁权重比例；只写「使用重要性采样」无法判断估计对象。 轨迹权重是逐步 ratio 的乘积。若每步 log-ratio 具有非零方差，其和的方差随 horizon 增长，权重分布趋向重尾。per-decision IS 只用到奖励时刻之前的比率，marginalized IS 则尝试估计状态占用比，二者都在减少不必要的乘积，却引入新的密度比估计问题。 **9.14. 数据中的动作不是随机干预.** MDP 转移核 $P(s'\mid s,a)$ 描述在状态 $s$ 采取动作 $a$ 后的结果。离线数据给出的条件分布 $P(s'\mid S=s,A=a)$ 只有在状态包含全部影响动作选择与结果的混杂变量时，才能解释成干预分布 $P(s'\mid S=s,do(A=a))$。

设医生根据未记录的病情严重度 $U$ 选择治疗 $A$，严重度又影响康复 $Y$。即使观测状态 $S$ 相同，接受治疗的人可能更严重，数据中治疗组康复率更低。直接把条件相关当作动作效果，会错误得出治疗有害。强化学习把这个错误转移核用于规划后，会系统选择错误动作。 序列决策需要 sequential ignorability：给定记录历史后，行为动作与未来潜在结果条件独立。随机化行为策略可以保证这一点；观察性日志则需要充分状态、工具变量或显式因果假设。隐藏用户意图、人工接管规则和安全过滤器都可能成为混杂来源。

positivity 是另一条件：每种相关状态下，行为策略必须给目标动作正概率。严重患者从未接受某治疗时，数据无法识别该状态下治疗效果；模型外推不是因果证据。离线策略评估的支持集问题因此同时具有统计和因果含义。 **9.15. 非平稳环境需要把时间写进状态.**

标准 MDP 通常假设转移核和奖励不随绝对时间改变。用户分布、工具版本或其他参与者策略变化时，固定 $P$ 不再成立。若变化规律可观测，把时间、版本或上下文变量加入状态可恢复扩展状态上的 Markov 性；若变化由未知外部过程驱动，只能建模为非平稳或部分可观测环境。

训练数据混合多个环境版本时，经验核是加权平均。这个平均环境可能从未真实存在。版本 A 中动作 $a$ 成功、版本 B 中动作 $b$ 成功，混合模型可能认为二者都以中等概率成功，实际部署到任一版本都会次优。日志必须记录环境版本，并按部署目标选择权重。

多智能体环境中，其他智能体的策略属于转移的一部分。当它们也在学习，单个智能体看到的核持续变化；过去 replay 的 transition 不再来自当前环境。集中训练、对手建模或较短数据窗口都在处理这种变化。把训练不稳定全部归因于优化器，会漏掉数据生成过程正在移动这一事实。 概念漂移还改变评测含义。随机切分时间混合数据，会让训练集看到未来版本的模式。按时间向前切分、保留版本外测试，并报告性能随时间衰减，才能回答部署后的泛化问题。 **9.16. 半马尔可夫过程处理持续时间不同的动作.**

工具调用、技能和 option 会持续不同时间。若高层把整个子过程视作一个动作，决策间隔不再固定，适合用 Semi-Markov Decision Process。动作在状态 $s$ 启动，持续 $\tau$ 个底层步后到达 $s'$，期间累积折扣奖励

$$
R^{(\tau)}=\sum_{k=0}^{\tau-1}\gamma^kR_{t+k+1}.
$$

高层 Bellman 方程为

$$
Q(s,o)=\mathbb E[R^{(\tau)}+\gamma^\tau V(S_{t+\tau})\mid s,o].
$$

关键是 bootstrap 使用 $\gamma^\tau$。把所有 option 都当一个时间步并统一乘 $\gamma$，会高估持续时间长的动作未来价值。若目标按真实时间折扣，工具延迟与思考步数必须进入持续时间。 平均奖励口径下，还要区分每次决策收益和单位时间收益。一个 option 每次获得奖励 $10$ 但耗时一百秒，另一个每次奖励 $2$ 只耗时一秒；按决策平均前者更好，按时间平均后者更好。服务延迟、计算 token 与外部等待应使用与业务目标一致的时钟。 option 的内部策略和终止规则共同决定半马尔可夫核。只记录高层选择与最终结果，无法判断收益来自内部执行改善还是终止时机改变。层级算法比较需要报告 option 持续时间分布、内部失败和提前终止比例。 **9.17. 鲁棒 MDP 把模型不确定性放进优化.**

当转移核未知，可以为每个状态动作对定义不确定集合 $\mathcal P(s,a)$。鲁棒 Bellman 算子采用最坏情况转移：

$$
(T_{\rm rob}V)(s)=\max_a
\min_{P\in\mathcal P(s,a)}
\left[r(s,a)+\gamma\mathbb E_{s'\sim P}V(s')\right].
$$

若集合具有 rectangularity，即不同状态动作的转移选择可独立组合，动态规划仍然成立。真实不确定性若跨状态耦合，逐状态最坏情况可能过度保守，也可能组合出一个不可能同时出现的虚构环境。 不确定集合可以由总变差球、KL 球、Wasserstein 球或参数置信域构造。集合太小，真实环境落在外面，鲁棒保证失效；集合太大，策略会为极端情形牺牲大量正常性能。置信水平、数据量和距离度量共同决定这个交换。

分布鲁棒目标与风险目标有关，却不等同。CVaR 在固定回报分布上关注尾部，鲁棒 MDP 对一族可能环境取最坏值。前者担心同一环境中的随机坏结果，后者担心环境模型本身错了。工具版本变化更接近模型不确定性，随机执行失败更接近回报尾部；实际任务可能同时包含两者。 一个常见反例是把训练数据稀少直接解释为高风险。罕见状态可能完全安全，只是行为策略很少访问；高频状态也可能存在未记录的系统性偏差。不确定性应来自可校准的统计区间、模型分歧和版本证据，不能只由访问次数机械决定。 **9.18. 熵正则改变 Bellman 算子的形状.** 最大熵控制在奖励中加入策略熵。对温度 $\alpha>0$，目标可写成

$$
J_\alpha(\pi)=\mathbb E_\pi\left[
\sum_{t\ge0}\gamma^t
\bigl(r(S_t,A_t)+\alpha\mathcal H(\pi(\cdot\mid S_t))\bigr)
\right].
$$

固定状态动作价值 $Q$ 时，最大化

$$
\sum_a\pi(a\mid s)Q(s,a)+\alpha\mathcal H(\pi(\cdot\mid s))
$$

得到 Gibbs 策略 $\pi^*(a\mid s)\propto\exp(Q(s,a)/\alpha)$。代回后，硬最大值变为

$$
V(s)=\alpha\log\sum_a\exp(Q(s,a)/\alpha).
$$

$\alpha\downarrow0$ 时恢复 $\max_aQ(s,a)$；温度较大时，次优动作仍保留概率。这个推导说明 entropy bonus 改变优化目标，不只是帮助数值稳定。训练后移除熵项，得到的最优策略也可能改变。 若以参考策略 $\pi_0$ 为基准加入相对熵，状态目标为

$$
\mathbb E_{a\sim\pi}[Q(s,a)]
-\alpha D_{\mathrm{KL}}(\pi(\cdot\mid s)\Vert\pi_0(\cdot\mid s)),
$$

最优策略变成 $\pi^*(a\mid s)\propto\pi_0(a\mid s)\exp(Q(s,a)/\alpha)$。参考策略在这里相当于动作先验：相同 $Q$ 增量会在原本概率更高的动作上留下更多质量。这与语言模型 KL 正则化目标的变分解完全对应。 前向与反向 KL 不能互换。$D_{\mathrm{KL}}(\pi\Vert\pi_0)$ 在新策略把质量放到参考策略低概率区域时惩罚很强，倾向保留参考支持；$D_{\mathrm{KL}}(\pi_0\Vert\pi)$ 强烈惩罚新策略漏掉参考的高概率动作，更强调覆盖。动作空间大时，两者对模式寻找与模式覆盖的偏好差异会直接反映到生成多样性。 **9.19. 再生结构把长链切成近似独立周期.** 若 Markov 链反复回到某个再生状态 $s_0$，两次回访之间的片段可视为 cycle。设第 $k$ 个周期长度为 $\tau_k$，累计奖励为 $Y_k$。在适当正常返条件下，长期平均奖励满足 renewal-reward relation：

$$
\rho=\frac{\mathbb E[Y_k]}{\mathbb E[\tau_k]}.
$$

这个比值不是「每周期平均奖励」；周期长短随机时，必须用期望奖励除以期望长度。先计算每个周期的 $Y_k/\tau_k$ 再平均，会给短周期过高权重。 再生周期提供独立或条件独立的统计单位。连续 transition 高度相关时，以周期为单位做 bootstrap 和置信区间更合理。真实任务未必有单一回访状态，也可以用小集合或人为 reset 构造 regeneration。若 reset 规则依赖近期失败，周期分布会被选择机制改变，需要把规则纳入环境定义。 episode 数据就是特殊再生结构：每次终止后从 $\rho_0$ 重启。若训练系统在失败后更换初态分布、在成功后保留同一任务，episode 便不再同分布。简单地跨 episode 平均会混合课程策略和环境表现。 **9.20. 策略只在访问区域内可识别.**

给定占用测度 $d^\pi(s,a)$，在 $d^\pi(s)>0$ 的状态可以恢复动作条件概率 $\pi(a\mid s)=d(s,a)/d(s)$。零占用状态上的策略无法从轨迹识别。即使无限数据也只能知道实际访问区域，不能推断反事实状态上的动作。 这种不可识别性会影响策略蒸馏。学生模型在教师 rollout 上完美匹配，仍可能在教师从未访问的状态任意输出；部署时一次小误差进入新状态，后续行为便缺乏约束。DAgger 一类交互式模仿通过让学生诱导状态、再查询教师，逐步扩大覆盖。固定离线蒸馏没有这个修正通道。

策略等价还取决于目标。两个策略可以产生相同状态占用，却在动作层不同；若奖励只依赖状态，它们回报相同，若动作有隐藏成本则不同。也可以产生相同单步状态—动作边缘，却有不同时间相关结构，导致 hitting time 和尾部风险不同。只比较平均 occupancy 无法证明轨迹分布相同。 语言模型评测常只看最终答案分布。两种策略最终答案相同，生成过程可能在工具调用、隐私泄露或中间错误上完全不同。若这些过程行为重要，它们必须进入状态、动作或成本定义，不能期待终局准确率自动识别。 **9.21. 模型选择误差和规划误差要分开.** 基于模型的方法先估计 $\hat P,\hat r$，再近似求解规划问题。最终策略次优性可粗略分成模型误差和规划误差：

$$
J_P(\pi^*)-J_P(\hat\pi)
=\bigl[J_P(\pi^*)-J_{\hat P}(\pi^*)\bigr]
+\bigl[J_{\hat P}(\pi^*)-J_{\hat P}(\hat\pi)\bigr]
+\bigl[J_{\hat P}(\hat\pi)-J_P(\hat\pi)\bigr].
$$

中间项是近似规划没有找到模型内最优策略；两侧是固定策略跨真实与学习模型的价值差。把规划器运行更久只能减少中间项，无法改善模型误差，反而可能更彻底利用模型漏洞。 数据增加主要缩小已覆盖状态动作上的模型置信区间。规划策略访问分布与数据分布不同，平均预测误差不能直接控制策略价值。需要 concentrability coefficient 描述目标占用相对数据占用的密度比；该系数无界时，离线数据无法给出统一保证。

保守算法限制目标策略占用，或对低支持动作降低价值。它们的保证依赖不确定性估计是否校准。模型 ensemble 一致不代表正确：成员共享架构、数据和训练偏差时，可能一起自信地犯错。保留环境外验证与真正在线小流量试验，仍是识别共同偏差的重要手段。 **9.22. 有限 MDP 的估计误差可以逐格计算.** 有限状态动作环境中，若 $(s,a)$ 被观察 $n(s,a)$ 次，经验转移频率为 $\hat P(\cdot\mid s,a)$。对单个下一状态，Bernoulli Hoeffding 界给出误差随 $1/\sqrt{n(s,a)}$ 下降；同时控制全部状态动作下一状态，需要 union bound，引入状态与动作数量的对数项。 真正瓶颈是最小访问次数，而非总 transition 数。数据集中一百万步都落在一个动作上，其他动作的转移误差仍无法控制。探索算法用 optimistic bonus 鼓励低计数动作，离线数据则只能承认这些格子缺乏证据。

经验奖励和转移误差进入价值后会按 horizon 放大。设奖励误差上界为 $\epsilon_r$，转移总变差误差为 $\epsilon_P$，固定策略价值差的一类上界具有

$$
\lVert V_P^\pi-V_{\hat P}^\pi\rVert_\infty
\lesssim\frac{\epsilon_r}{1-\gamma}
+\frac{\gamma R_{\max}\epsilon_P}{(1-\gamma)^2}.
$$

精确常数依距离定义而变，两个 horizon 因子值得保留：转移误差先改变下一状态价值，再沿未来递归累积。长 horizon 下，模型学习需要远高于单步预测看起来所需的精度。 自适应数据会让简单独立界失效。策略根据过去观测选择下一动作，计数 $n(s,a)$ 和误差相关。鞅浓缩不等式可以处理这种历史适应性，但仍需有界增量或条件方差控制。把自适应探索数据当成预先固定的 iid 样本，会低估选择带来的不确定性。 **9.23. Bayesian MDP 区分已知随机性与认知不确定性.** 环境随机性指即使知道真实 $P$，下一状态仍随机；认知不确定性来自不知道 $P$。Bayesian 方法对模型参数维护 posterior $p(P\mid D)$，新数据通过 Bayes rule 更新。预测分布

$$
p(s'\mid s,a,D)=\int P(s'\mid s,a)p(P\mid D)dP
$$

同时混合两类不确定性，但决策价值不同：环境随机性无法靠更多同类数据消除，认知不确定性可以。 把 posterior 当成状态的一部分，得到 Bayes-adaptive MDP。动作不仅获得外部奖励，还改变对环境的认识；探索的价值由未来决策改善自然产生。其状态包含完整 posterior，计算通常很难，Thompson sampling 和信息增益 bonus 是近似方案。 posterior sampling 每轮从 posterior 抽一个模型，按该模型最优策略行动。某个不确定动作在部分 plausible 模型中很好，便有机会被探索。若先对模型平均再规划，平均核可能抹掉这种价值，产生在任何真实模型中都不理想的折中策略。

Bayesian 置信度高度依赖先验和模型类。真实转移不在假设族内时，posterior 仍可能随数据集中到错误模型，并表现得极其自信。posterior predictive check、模型扩展和频率学覆盖测试，可以检查这种错设；概率数值本身不能证明模型类正确。 **9.24. Distribution shift 不只有 covariate shift.** 状态分布变化而条件转移不变，接近 covariate shift；奖励定义变化属于 concept shift；环境核变化则是 dynamics shift。三种变化需要不同修正。状态重加权可以校正第一种，无法修复验证器标准或工具语义已经改变的问题。 令训练占用为 $d_b$，部署占用为 $d_e$。对有界误差函数 $\ell(s,a)$，部署误差为

$$
\mathbb E_{d_e}[\ell]
=\mathbb E_{d_b}\left[\frac{d_e(s,a)}{d_b(s,a)}\ell(s,a)\right].
$$

密度比大的区域主导迁移风险。训练平均误差很低，只说明 $d_b$ 高频区域表现好；部署策略主动改变状态分布后，低频区域可能成为主路径。 闭环系统还会产生 performative shift：模型决策改变用户与环境，新的数据分布再影响下一轮模型。推荐系统改变用户兴趣，Agent 修改代码后改变后续错误分布，安全策略改变攻击者行为。把每轮数据视作固定外生分布，会错过这个反馈。 稳健评测应按可预见变化维度构造切片，并保留时间外、环境版本外和策略诱导分布外测试。极端压力测试不必代表日常平均，它用于寻找支持集断裂与不连续失败。一旦发现失败，应回到状态和转移定义定位原因，而非只增加一个总分。 **9.25. 从概率对象到可复现实验.**

一份完整实验记录可以沿概率图逐项展开。先声明初始分布与 reset 规则，再声明策略版本、采样温度和动作掩码；环境部分记录转移版本、随机源、终止与截断；反馈部分记录奖励函数、验证器版本和缺失值处理；估计部分记录基线、权重、reduce 口径与置信区间单位。 每个均值都应能回答分母是谁。平均 reward 是按 token、序列、提示还是 episode；成功率是否把超时算失败；KL 是对采样动作的近似还是完整词表期望；长度平均是否先按任务聚合。分母不同的曲线可以同时正确，却描述不同目标。

反例测试比大规模曲线更适合验证定义。确定性两状态环境检查转移与终止，随机吸收链检查 hitting probability，周期链检查稳态与时间平均，隐藏变量环境检查 Markov 性，零支持动作检查离线评估，重尾奖励检查置信区间。每个例子都应有可手算答案，再与实现输出对照。

还要区分三类结论：关于定义的恒等式、依赖假设的定理和来自有限实验的经验观察。恒等式可以代数验证；定理需要逐条列出有界性、覆盖、遍历或函数类条件；经验结论需要数据版本、随机种子与不确定区间。三类证据写在同一篇文章里没有问题，前提是读者能看出每句话依赖哪种证据。 **9.26. 占用线性规划的对偶就是 Bellman 不等式.** 有限折扣 MDP 的占用测度原问题可以写成

$$
\max_{d\ge0}\ \frac1{1-\gamma}\sum_{s,a}d(s,a)r(s,a)
$$

并满足每个状态的流量约束

$$
\sum_a d(s,a)-\gamma\sum_{\bar s,\bar a}
d(\bar s,\bar a)P(s\mid\bar s,\bar a)
=(1-\gamma)\rho_0(s).
$$

为每个流量约束引入对偶变量 $V(s)$，整理 Lagrangian 后，要使对 $d(s,a)\ge0$ 的上确界有限，必须满足

$$
V(s)\ge r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')
$$

对所有 $(s,a)$ 成立。对偶问题是在这些 Bellman 不等式下最小化 $\sum_s\rho_0(s)V(s)$。因此，价值函数并非与占用视角平行出现的另一套公式；它正是流量优化的对偶证书。 互补松弛进一步给出

$$
d^*(s,a)left[V^*(s)-r(s,a)
-\gamma\mathbb E[V^*(S')\mid s,a]ight]=0.
$$

最优占用为正的动作必须让 Bellman 不等式取等号。一个动作若严格次优，对偶 slack 为正，它在任何对应最优占用中质量为零。多个动作同时取等号时，最优策略可以在它们之间随机化。 约束 MDP 在原问题中再加入成本流量 $\sum d(s,a)c(s,a)\le(1-\gamma)b$。它的对偶乘子 $\lambda\ge0$ 会把奖励改成 $r-\lambda c$。互补松弛说明：若最优策略没有用满预算，$\lambda=0$；若约束紧，乘子可以为正。把固定惩罚系数当成任意调参值，会丢掉它作为约束影子价格的含义。 线性规划还揭示随机策略何时必要。无约束有限折扣 MDP 存在确定性平稳最优策略；加入多个期望约束后，满足预算边界的最优占用可能需要混合若干确定性策略。此时强行输出单一确定动作，会从可行边界跳到违规或过度保守的一侧。

函数逼近破坏了这一精确对偶。若价值函数族无法表达满足所有 Bellman 不等式的证书，经验对偶残差很小也不保证全状态可行；若占用模型无法表达真实流量，原问题同样有逼近误差。primal residual、dual residual 与互补间隙应分开观察，单一 value loss 无法覆盖三者。 **9.27. TD error 可以分成鞅噪声与系统误差.** 对真实价值函数 $V^\pi$，一步 TD error 为

$$
\delta_t=R_{t+1}+\gamma V^\pi(S_{t+1})-V^\pi(S_t).
$$

Bellman 方程保证 $\mathbb E[\delta_t\mid\mathcal F_t]=0$，所以 $\delta_t$ 是相对于历史 filtration 的 martingale difference。它单次通常不为零，却在给定当前信息后均值为零。把每个非零 TD error 都解释成 critic 错误是不对的；环境转移和奖励随机性本来就产生不可约波动。 使用近似价值 $V_\phi$ 时，

$$
\mathbb E[\delta_t^\phi\mid S_t=s]
=(T^\pi V_\phi)(s)-V_\phi(s)
$$

等于 Bellman residual。观测 TD error 同时包含这个系统项和零均值鞅噪声。增加样本可以压低噪声估计误差，扩大模型或改变特征才可能降低逼近 residual。训练曲线抖动与长期有偏需要不同处理。 多步 TD error 可以望远镜展开：

$$
\sum_{k=0}^{n-1}\gamma^k\delta_{t+k}
=\sum_{k=0}^{n-1}\gamma^kR_{t+k+1}
+\gamma^nV(S_{t+n})-V(S_t).
$$

左侧把局部创新累积成 $n$ 步 return 与当前价值之差。GAE 再对不同 $n$ 的这类和加权。资格迹由此表现为不同时间跨度 TD innovation 的重新组合，其监督仍来自奖励与 bootstrap 价值。 随机逼近收敛还依赖步长。经典 Robbins–Monro 条件要求 $\sum_t\alpha_t=\infty$ 且 $\sum_t\alpha_t^2<\infty$：第一条保证能够走到固定点，第二条让累计噪声方差有限。深度 RL 常用恒定或分段学习率，不满足渐近条件，因此实践目标通常是稳定在固定点附近的噪声球，而非严格几乎处处收敛。 Off-policy、函数逼近和 bootstrap 同时出现时，更新方向未必对应某个收缩算子的随机近似。即使每步 TD error 数值很小，也可能收敛到投影固定点或发生发散。诊断时需观察参数范数、Bellman residual、目标网络滞后与数据分布，不能仅凭训练 TD loss 下降断言价值正确。 **9.28. 谱隙决定均值误差收缩速度.**

有限可逆 Markov 链的转移矩阵在合适内积下有实特征值

$$
1=\lambda_1>\lambda_2\ge\cdots\ge\lambda_n\ge-1.
$$

谱隙 $1-\max(|\lambda_2|,|\lambda_n|)$ 控制忘记初态的速度。第二特征值绝对值接近一时，链存在缓慢模式：状态看似不断变化，跨区域转移却很少，样本均值长期保留相关性。 对平稳链上的函数 $f(S_t)$，中心极限定理在遍历条件下给出

$$
\sqrt{T}(\bar f_T-\mu_f)
\Rightarrow\mathcal N(0,\sigma_f^2),
$$

渐近方差为

$$
\sigma_f^2=\operatorname{Var}_\mu(f)
+2\sum_{k=1}^{\infty}
\operatorname{Cov}_\mu(f(S_0),f(S_k)).
$$

它与此前的积分自相关时间一致。iid 标准误只保留第一项，会在正相关链上过窄；负相关采样则可能比 iid 更有效。batch means 方法把长链分成大块，以块均值之间的波动估计渐近方差，块长度需要超过主要相关时间尺度。 从任意初态开始时还存在 burn-in bias。丢弃固定前缀只有在已知 mixing time 时才有依据；慢混合链中，常用 burn-in 可能远远不够。多条过度分散初态的独立链、状态统计的链间对比与随时间稳定性，比单条链「看起来平稳」更可信。

强化学习数据更加复杂，因为策略在训练中变化，序列并非固定核下的平稳 Markov 链。短窗口内近似平稳需要策略更新慢于环境混合；更新太快时，状态分布还未追上当前策略又发生变化。两时间尺度分析把这种要求写成步长条件，异步 rollout 中的 policy lag 则直接违反近似同策略采样。 谱隙还影响探索。瓶颈状态连接两个区域时，局部随机策略可能需要指数级时间跨越；提高单步动作熵不一定增加跨瓶颈概率。分层动作、reset 分布或目标导向探索能够改变宏观转移结构，比统一温度更直接地改善混合。 **9.29. 多目标回报没有天然的单一排序.**

真实系统常同时关心正确率、延迟、成本、安全和用户偏好。令回报向量为 $J(\pi)=(J_1(\pi),\ldots,J_K(\pi))$。若一个策略在所有维度不差且至少一维更好，它 Pareto 支配另一个策略；未被支配的集合形成 Pareto frontier。没有额外偏好时，frontier 上策略之间不存在由数据自动给出的唯一排序。 线性标量化 $\sum_kw_kJ_k$ 选择一个权重方向。占用可行集凸时，它能找到 convex frontier 上的支持点；非凸参数化或离散策略限制下，某些 Pareto 点无法由任何固定线性权重得到。更重要的是，权重数值依赖每个目标的量纲。延迟用秒还是毫秒，会在不改变实际偏好的情况下改变数值最优解。

约束形式通常更可解释：最大化主要能力，同时要求成本不超过预算、安全违规率不超过阈值。可行性必须先检查。若不存在同时满足全部约束的策略，乘子会持续增长，训练可能震荡或牺牲所有软目标。报告约束算法时应同时给原始约束残差和目标值，惩罚后的合成 reward 不能显示是否真的可行。 概率约束

$$
\Pr_pi(C(\tau)>c)\le\delta
$$

控制违规事件频率，与期望成本 $\mathbb E[C]\le b$ 不同。小概率巨大损失可能满足较宽的期望约束，却违反尾部概率要求。估计很小的 $\delta$ 需要大量独立轨迹；训练集中零次违规只给出上界，不能证明真实概率为零。 奖励模型把多维人类偏好压成标量时，也隐含一个聚合规则。不同用户群体权重不同，平均奖励最优策略可能对任何群体都不是最佳。按群体报告 Pareto 变化、允许条件化偏好，或对最差群体施加下界，能显式表达这种异质性。把所有冲突藏进一个 reward 数字，只会让策略替系统做未经声明的价值选择。 **9.30. Abel 极限连接折扣与平均奖励.** 对奖励序列 $r_t$，归一化折扣和为

$$
(1-\gamma)\sum_{t=0}^{\infty}\gamma^tr_t.
$$

若时间平均 $T^{-1}\sum_{t<T}r_t$ 收敛到 $\rho$，在适当有界条件下，$\gamma\uparrow1$ 时归一化折扣和也趋向 $\rho$。这类 Abelian relation 解释了为什么接近一的折扣目标可以近似平均奖励；归一化因子 $(1-\gamma)$ 不能省略，否则价值本身通常发散。 逆命题需要更强条件。折扣平均存在，不必保证普通时间平均对每条序列收敛；多 recurrent class、周期性和非平稳奖励都会制造差异。在策略比较中，某个策略对所有足够接近一的 $\gamma$ 都最优，称为 Blackwell optimal。有限 MDP 在一定条件下存在这类策略，但具体阈值依环境而定。 折扣因子趋近一时，价值可以分解为

$$
V_\gamma^\pi(s)\approx
\frac{\rho(\pi)}{1-\gamma}+h^\pi(s),
$$

第一项是与状态无关的长期平均贡献，$h^\pi$ 是相对价值。直接比较巨大 $V_\gamma$ 容易遭受数值消减；减去参考状态价值或使用 differential value 更稳定。 这个分解也说明短会话与长期服务为何需要不同目标。会话频繁 reset 时，初态与暂态 bias 反复出现，$h(s)$ 对体验重要；持续服务运行很久后，平均收益 $\rho$ 主导。用同一个接近一的 $\gamma$ 模糊两者，会让目标解释和数值尺度同时变差。 **9.31. 检验很多指标会制造偶然胜利.** 强化学习实验常同时尝试多个 seed、checkpoint、任务、超参数和评测器。若每项在零效应下都有 $5\%$ 假阳性率，挑选最好的结果会显著提高至少一次偶然胜出的概率。只汇报最佳配置，再对该配置计算普通置信区间，忽略了选择过程。

预注册主要指标、保留最终测试集和报告完整搜索预算可以降低选择偏差。多任务比较可使用 family-wise error 或 false discovery rate 控制，但统计校正不能替代效应量。一个极小却显著的均值提升，可能没有实际价值；平均提升较大但跨 seed 极不稳定，也不适合作为默认配方。 配对评测通常更有力。同一提示、环境种子下比较两个策略，分析差值 $D_i=G_i^A-G_i^B$，能消除任务难度共同波动。配对关系必须在 bootstrap 或置换检验中保留。若策略生成会改变后续环境，使二者无法共享随机结果，则应声明只能做独立比较。

重复使用测试集调参会使其逐渐变成训练信号。即便参数更新没有反向传播，研究者根据测试结果选择算法也构成适应性过拟合。保留隐藏评测、轮换任务族和记录所有尝试，有助于判断新方法是在学习一般机制，还是适应一套熟悉 benchmark。 最终结论应把统计不确定性与环境外推分开。窄置信区间只说明当前抽样分布上的均值估得准，不能证明换用户、版本或工具后仍成立。前者靠更多独立重复缩小，后者需要改变评测分布与机制分析。 **9.32. belief state 如何恢复充分统计量.** POMDP 中隐藏状态为 $S_t$，智能体只观察 $O_t$。完整历史持续增长，但在已知模型下，可以用 posterior belief

$$
b_t(s)=\Pr(S_t=s\mid O_{0:t},A_{0:t-1})
$$

压缩历史。执行动作 $a_t$ 并观察 $o_{t+1}$ 后，先做转移预测

$$
\tilde b_{t+1}(s')=\sum_sP(s'\mid s,a_t)b_t(s),
$$

再用观测似然更新

$$
b_{t+1}(s')=
\frac{P(o_{t+1}\mid s',a_t)\tilde b_{t+1}(s')}
{\sum_uP(o_{t+1}\mid u,a_t)\tilde b_{t+1}(u)}.
$$

belief 是原状态单纯形上的连续变量。给定 $b_t$ 和动作，下一 belief 的分布不再依赖更早历史，所以 POMDP 转化为 belief MDP。这个结果没有让问题变简单：状态从有限集合变成连续概率分布，精确过滤还要求已知转移与观测模型。 分母是观测的预测概率。若模型给实际观测零概率，Bayes 更新无定义，说明模型支持集与现实冲突；添加任意小平滑虽能继续计算，也改变了环境假设。工具返回新错误码、网页结构更新和传感器异常都可能触发这类问题。 价值函数在 belief 上定义。即时期望奖励为 $r(b,a)=\sum_sb(s)r(s,a)$，Bellman 方程对下一观测取期望。有限 horizon、有限状态动作观测的最优价值具有分段线性凸结构，可以由若干 $\alpha$-vector 表示；vector 数量随 horizon 快速增长，这也是精确 POMDP 规划困难的来源。

循环网络的 hidden state 可以学习近似 belief，却没有自动校准保证。两个 hidden vector 接近，不代表对应 posterior 接近；训练任务若只监督最终动作，网络可能忽略罕见但决策关键的隐藏变量。可以用 next-observation prediction、状态探针和反事实轨迹检查表示是否保留所需信息。 语言模型 Agent 的上下文更像外显 history，摘要和记忆模块则执行近似过滤。摘要若删除某次工具失败，后续策略会把「尚未尝试」与「尝试失败」混为同一状态。检验方法是构造两段表面目标相同、隐藏历史不同的任务，观察记忆表示能否支持不同最优动作。 **9.33. 奖励本身存在不可识别等价类.**

仅观察最优策略通常不能唯一恢复奖励。给所有奖励乘正数不会改变动作排序；potential-based shaping 在适当条件下也保持最优策略。逆强化学习因此面对等价类：许多奖励函数都能解释同一行为。 更强的歧义来自未访问区域。专家从不进入某状态，那里任何奖励都与观测行为相容。若学习到的奖励在该区域任意外推，再用更强规划器优化，策略可能主动进入专家没访问的高预测奖励区域。奖励学习必须和行为覆盖、正则先验或环境查询结合。 最大熵逆强化学习用轨迹概率

$$
p_\theta(\tau)\propto
\exp\left(\sum_t r_\theta(s_t,a_t)\right)
$$

在匹配特征期望的同时保留随机性。配分函数需要对所有轨迹求和，有限 MDP 可用动态规划，复杂环境只能近似。温度、特征表示和轨迹基准测度都会影响恢复出的奖励尺度。 偏好数据比单条示范多提供相对排序，但仍只识别比较覆盖范围内的效用差。若全部候选都来自同一窄策略，奖励模型无法知道分布外回答好坏。主动查询应选择能区分候选奖励假设的比较，而非反复标注已经一致的容易样本。

奖励不可识别并不妨碍预测已覆盖区域的选择，却限制机制解释。模型给某回答高分，不能自动解释成人类拥有同一个标量效用；它只是某个在当前数据上等价的表示。跨群体、跨任务迁移前，需要重新检查等价关系是否仍保持所关心行为。 **9.34. 一组贯穿全文的反例.** 状态遗漏可用「同一观测、不同剩余电量」构造：两个历史显示相同位置，电量不同，最优动作分别是继续和充电。任何只看位置的 Markov 策略都必须在至少一个历史上出错。加入电量后，转移与奖励才由当前状态动作充分决定。

覆盖失败可用两动作 bandit 构造：日志策略永远选择 $a_0$，观测回报恒为零；环境一中 $a_1$ 回报为一，环境二中为负一。两环境产生完全相同日志，却要求相反最优动作。没有对 $a_1$ 的数据，任何离线算法都无法区分它们。 平均值误导可用稀有灾难构造：策略 A 恒定小收益，策略 B 多数时候稍高、极少时候巨大损失。有限测试很可能完全看不到灾难，使 B 的经验均值、方差和 CVaR 都显得优秀。风险估计需要足够尾部样本或结构性安全约束。

非平稳混合可用两个版本构造：旧版本动作左成功，新版本动作右成功。随机混合日志得到左右各半成功，经验 MDP 建议二者相同；部署到确定版本后，版本标识策略可以满分，无版本策略只能折中。时间或版本遗漏会造成状态定义错误，重复采样无法像消除普通噪声那样修复它。 停止偏差可用超时构造：困难任务失败前运行很久，容易任务很快成功。只保留规定时间内结束的 episode，样本成功率会高估总体；把超时都算失败可能低估本可继续成功的策略。两种口径对应不同业务问题，必须在任务定义阶段决定。

这组反例覆盖充分状态、positivity、尾部覆盖、stationarity 和 censoring。面对新算法时，先让它通过这些最小环境，再扩到大型模型。若连两状态反例都无法给出正确对象，规模只会让错误更难定位。
