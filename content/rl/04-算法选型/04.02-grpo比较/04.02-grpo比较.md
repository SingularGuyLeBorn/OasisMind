# GRPO 家族:按症状与基建选型

GRPO 家族的五个方法共享同一训练结构: 同一 prompt 采样一组回答, 用组内 reward 统计量构造优势, 用旧策略比率修正离策略漂移 (1.3.1.1 节). 分歧集中在三个坐标: 聚合粒度 (token 级还是序列级), 聚合函数 (算术还是几何), clip 的量纲与位置 (ratio 空间还是 log 空间, 逐 token 还是逐回答). 加上优势构造与采样侧的一组正交开关, 每个变体都可以写成这组坐标上的一个点.

选型的实际问题因此可以重述为: 监控里出现的症状对应哪个坐标, 哪种方法改变这个坐标, 以及错误选择会产生什么代价. 五个症状及其度量口径确定观测量, 坐标系与条件表确定候选范围, 两组手算比较同一个 batch 在不同变体下的行为, 三类高代价场景则给出组合迁移的边界.

## 1. 五个可观察症状

### 1.1 采样与优势侧: 全同组, 长度, 难度

选型从症状出发, 症状从监控曲线定义, 每个症状给一个可计算的度量. 第一个是**全同组占比**: 组内 reward 全相同的组数占采样组数的比例, 判定条件是 $\max_j R_j=\min_j R_j$, 与 reward 编码无关. 二值 reward 下它等于 $p^G+(1-p)^G$ 的样本均值 (1.3.1.1 节 §5.2). 比例持续偏高说明大量 rollout 在空转, 是采样预算与题目难度分布不匹配的直接信号.

第二个是**长度偏差**: 正确回答与错误回答的平均长度差随训练的变化, 配合 reward 与 $|y_i|$ 的相关系数按训练阶段分段画出. GRPO 的归约先在每条回答内按长度平均, 再对回答等权平均, 长回答的每个 token 获得更小的梯度权重 (1.3.1.1 节 §2.5); 推理任务里正确链往往更长, 这个结构会系统性压低正确答案的更新力度 (1.3.2.1 节 §1.3). 第三个是难度权重异常: 按预估 pass rate 分桶后, 各难度段贡献的梯度量与桶内组数明显不成比例. 组内标准差归一让难题与易题的优势尺度被拉平, 一道几乎全错的题一旦偶然采到单个成功回答, 该回答获得远大于常规的正优势 (1.3.1.1 节 §3.4).

### 1.2 优化侧: 熵坍缩与 token 级离群

第四个症状是**熵坍缩**: 策略熵快速下降, 组内 $G$ 条回答趋于雷同, 探索消失. 可靠的度量是组内唯一回答数与 n-gram 多样性, 而不是 token 级熵的数值曲线, 后者受温度设置与分桶方式影响, 噪声大 (1.3.2.1 节 §2.2). 若探针集上按固定温度测得的熵单调下塌, 且 clip fraction 的正侧触发集中在 $1+\epsilon$ 附近, 指向对称裁剪对正优势的过早截停.

第五个症状是**token 级离群**: rollout 内重要性比分布的撕裂, 用 max/mean 衡量, 正常更新下这个比值在 1.5 到 3 之间, 路由翻转时刻能冲到 10 以上 (1.3.2.3 节 §1.1). 与之配套的现象是 loss 尖峰与个别 token 的比率尖峰同步出现, 且收紧 clip 边界治不住. 这两个症状都作用在优化侧, 但一个指向 clip 边界的结构, 一个指向聚合粒度与聚合函数, 对应的变体不同.

### 1.3 症状与坐标的对应

五个症状各自指向不同的坐标, 这是决策树的底层结构. 全同组占比指向采样侧: 它不改变任何损失公式, 改的是哪些组进入 batch, 对应 DAPO 的动态采样 (1.3.2.1 节 §3). 长度偏差指向归约分母与长度塑形, 对应 DAPO 的 Token-Level Policy Gradient Loss 与 Overlong Reward Shaping, 也部分对应 GSPO 内建于序列比率的长度归一 (1.3.2.2 节 §5.2). 难度权重异常指向优势构造, 对应 Dr. GRPO 去掉组内标准差归一 (1.3.1.1 节 §3). 熵坍缩指向 clip 边界的结构, 对应 DAPO 的 Clip-Higher. token 级离群指向聚合粒度与聚合函数, 对应 GSPO 的序列级比率和 GMPO 的几何聚合 (1.3.2.2 节 §1, 1.3.2.3 节 §1).

两组症状容易互相伪装, 需要区分. 熵坍缩与全同组占比都会表现为有效信号减少: 前者是策略本身变尖, 组内回答雷同但 reward 仍有差异; 后者是策略没变, 只是组内 reward 全同. 区分手段是看组内唯一回答数, 不看 reward 方差. 长度偏差与难度权重异常都会表现为某些回答的梯度被压低: 前者按长度分布分层就能看见, 后者按难度分桶才能看见, 两个维度要分别画.

## 2. 坐标系: 每个变体动的是哪个坐标

### 2.1 聚合粒度, 聚合函数, clip 三坐标

沿用 (1.3.2.3 节 §4.1) 建立的坐标系. 第一轴是**聚合粒度**: token 级保留每个位置的独立梯度贡献, 序列级把整条回答压成一个标量比率. 第二轴是**聚合函数**: 算术平均对离群值线性敏感, 几何平均在 log 空间运算, 乘积开方天然压缩大数. 第三轴是 clip: ratio 空间的乘法截断, 还是 log 空间的加法截断, 作用于逐 token 的比率还是逐回答的标量.

![GRPO 家族五方法在三坐标系中的位置图](../images/grpo-family-five-axes.png)

> 图 1: GRPO 家族五个方法在「聚合粒度 × 聚合函数 × clip」坐标概念图, 右侧五组彩色节点表示各方法在三个坐标上的组合差异, 依据 1.3 节五篇原论文整理, 是教学概念图, 不代表论文中的性能排序.

图 1 解析: 节点的横纵位置对应聚合粒度与聚合函数两个坐标, 颜色区分 clip 的量纲与作用位置. (序列, 算术) 的位置是空的, 因为序列级比率天然在 log 空间定义, 算术平均对它没有意义 (1.3.2.3 节 §4.1). 图没有画出采样侧与优势构造的开关, 它们与三个坐标正交, 不能从这张图上读出.

三个变体在坐标系里的位置: GRPO 是 (token, 算术, ratio clip), 逐 token 比率 $\rho_{i,t}$ 配 $[1-\epsilon,1+\epsilon]$ 的对称裁剪, 社区的常见量级是 $\epsilon\approx0.2$ (1.3.1.1 节 §2.5). GSPO 是 (序列, 几何, 序列级 clip): 序列比率 $s_i=\exp(\frac{1}{|y_i|}\sum_t\log\rho_{i,t})$ 先做长度归一的 log space 平均再指数化, clip 作用于 $s_i$ 本身, 论文实验的 clip 区间是 $[1-4\times10^{-4},1+3\times10^{-4}]$ 量级 (1.3.2.2 节 §3.3). GMPO 是 (token, 几何, log clip): 保留 token 级结构, 在 log 空间对 $\log\rho_{i,t}$ 做对称裁剪 $[-0.4,0.4]$, 对应比率区间 $[e^{-0.4},e^{0.4}]\approx[0.67,1.49]$, 再对裁剪后的 log-ratio 取几何平均, 方向由 $\operatorname{sgn}(\hat A_i)$ 恢复 (1.3.2.3 节 §3.1). DAPO 不动坐标系, 它在 GRPO 的点上调 clip 边界的参数: 正优势上界放宽到 $1+\epsilon_{high}=1.28$, 负优势下界保持 $1-\epsilon_{low}=0.8$ (1.3.2.1 节 §2).

坐标系的实用价值在于空格的位置. (token, 其他稳健统计量) 是下一个可能被填的格子, 例如截尾均值与中位数; 几何均值在「保留信号」与「压制离群」的谱系上位于算术与中位数之间, 选择上先动几何, 不够再考虑更激进的方案 (1.3.2.3 节 §2.2). 在文献里见到新变体时, 先在这个坐标系里定位, 比从动机叙事读起快得多.

### 2.2 优势构造与采样侧的正交开关

坐标系之外还有一组不在三个坐标上的开关, 它们与 surrogate 的选择正交, 可以独立叠加. 第一是优势构造: 原始 GRPO 做组内标准差归一 $A_i=(R_i-\bar R)/(\sigma_R+\epsilon)$, Dr. GRPO 只保留中心化 $A_i=R_i-\bar R$, 同时把按回答长度归约的分母换成固定生成预算等常数 (1.3.1.1 节 §3.2). 第二是归约分母: GRPO 每回答等权, DAPO 把批内所有有效 token 放在同一分母下, 回答之间的权重从 $1/B$ 变成 $|y_i|/\sum_j|y_j|$ (1.3.2.1 节 §4.1). 第三是采样侧: DAPO 的动态采样丢弃全同组并补采至有效 batch 恒定, Overlong Reward Shaping 用三段线性软惩罚替代硬截断, 论文的期望长度 16384, 窗口 4096, 生成上限 20480 (1.3.2.1 节 §5.1). 第四是正则: DAPO 移除了 KL 项, 靠 clip 承担全部偏移约束 (1.3.2.1 节 §6.1); 换成 reward model 打分或开放任务时 hacking 面回来, KL 或等效约束需要恢复.

**报配置时按坐标逐项写明, 比报一个方法名信息量高一个量级** (1.3.2.2 节 §4.1). 社区里「都叫 GRPO」的实现可能差了 clip, 归约, 采样三个坐标; 「都叫 DAPO」的实现可能只做过滤不补采, 等效于动态 batch 大小, 学习率的实际含义不同 (1.3.2.1 节 §6.3). 这组开关清单同时是核对他人的实现与归档自己 run 的模板.

## 3. 决策树

### 3.1 按症状分支

决策树的根是五个症状在监控里的状态, 每个分支给出一个开关级动作, 而不是一个方法名. 分支顺序按修复成本从低到高排列, 先排除便宜的解释再动算法 (1.3.2.3 节 §6.3).

第一个分支: 全同组占比高. 先查采样预算与难度分布, 确认不是题目难度两极化之后, 上动态采样与补采. 这一步不改任何损失公式, 基建改动集中在 rollout 调度. 补采的新 prompt 从哪个分布抽是隐形超参, 从难度分层题库补采才能保留人为课程 (1.3.2.1 节 §3.2). 如果全对组占比高且 KL 项被保留, 注意全对组贡献 KL 约束, 整体丢弃会静默削弱正则, 过滤策略要和 KL 系数一起重调 (1.3.1.1 节 §5.3).

第二个分支: 长度偏差显著且 reward 与长度正相关. 先确认截断规则没有把「答对但超长」判成零分, 若是, 上 Overlong Reward Shaping 并按期重设期望长度与窗口. 然后评估归约分母: 换 DAPO 的批内 token 统一分母, 长回答按 token 数获得与其推理量成正比的权重. 若同时换 GSPO, 比率内建长度归一, 损失分母回到每条回答等权, 两个长度处理只保留一层 (1.3.2.2 节 §4.3).

第三个分支: 探针集熵单调下塌, 组内唯一回答数下降. 先查 clip fraction 的正负触发比, 若负侧触发远多于正侧, 说明更新在「压错」上先饱和而「扶正」有余量, 上 Clip-Higher, 把正优势上界从 $1.2$ 抬到 $1.28$. 熵还是守不住, 再加显式熵正则, 顺序不要反: 先加正则会掩盖裁剪的问题 (1.3.2.1 节 §2.2).

第四个分支: 按难度分桶后梯度贡献与 pass rate 明显不成比例, 偶然成功的难题回答获得异常大的更新. 去掉组内标准差归一, 保留中心化, 即 Dr. GRPO 的优势构造. 去掉归一后梯度尺度系统性变化, KL 系数与学习率要跟着重标定, 具体倍数见第 4 节的手算.

第五个分支: 撕裂度分布的尾部冲高, loss 尖峰与个别 token 的比率尖峰同步, 收紧 clip 边界无效. 此时才在 GSPO 与 GMPO 之间选择: 离群是路由翻转这类集体伪影, 且模型是 MoE 或路由敏感架构, 选 GSPO, 粒度提到序列级; 离群里混着个别位置的真实信号, 或想保留 token 级日志与监控, 选 GMPO, 只换聚合函数 (1.3.2.3 节 §6.3). MoE 架构, 长链, minibatch 深复用三个条件占两个以上, GSPO 优先 (1.3.2.2 节 §6.3).

### 3.2 条件对照表与默认选择

| 可观察条件 | 推荐动作 | 依据 |
|---|---|---|
| 全同组占比持续走高且难度两极化 | 动态采样 + 难度分层补采 | (1.3.2.1 节 §3) |
| 正确链平均长度持续大于错误链, reward-长度相关为正 | Token-Level Loss + 长度塑形 | (1.3.2.1 节 §4, §5) |
| 探针熵下塌, 负侧 clip 触发多于正侧 | Clip-Higher $\epsilon_{high}=0.28$ | (1.3.2.1 节 §2) |
| 难题偶然成功的梯度贡献异常 | 去标准差归一 (Dr. GRPO 优势) | (1.3.1.1 节 §3) |
| MoE + 长链 + 深复用占两条以上 | GSPO 序列级比率 | (1.3.2.2 节 §6.3) |
| 撕裂度 max/mean 尾部冲高, 需保留 token 级监控 | GMPO 几何聚合 | (1.3.2.3 节 §6.3) |
| 新建管线, 输出短, rollout 便宜, 追求可审计 | RLOO 留一基线 | (1.3.1.2 节 §6.3) |

表中的阈值是经验量级, 不是论文数字, 用法是与自己历史 run 的曲线对比, 不与绝对值对比. 默认选择同样有明确答案: 五个症状一个都不显著时, 留在原始 GRPO 配方, 别为升级而升级 (1.3.2.1 节 §7.3). 第一次复现时只跑原始配方拿基线, 每次只改一个开关, 这是五个开关拆分的直接用途 (1.3.1.1 节 §4.3).

RLOO 与 GRPO 的优势只差常数因子 $G/(G-1)$ ($G=8$ 时为 $1.14$); 不做标准差归一时, 两者的组内排序与符号完全一致, 训练动态也很接近 (1.3.1.2 节 §2.2). RLOO 的代码路径短, 全部状态量可手算验证, 纯 on-policy 语义没有版本漂移. 代价在样本利用率: 推理 RL 的主要耗时来自 rollout, 每组数据只更新一次会浪费昂贵样本; clip 与多次 minibatch 更新允许有限复用 (1.3.1.2 节 §4.3). 输出短且 rollout 便宜的新管线适合先用 RLOO; 已有 PPO 系统、异步 rollout 与复用监控时, GRPO 更容易接入 (1.3.1.2 节 §4.2).

## 4. 手算对照: 同一个 batch 在各变体下

### 4.1 合成权重对照: 归约分母与聚合函数

以下手算省略 KL 项, mask 与 padding 细节, 只比较权重结构; 数字均可复算. 第一组对比两条回答在归约分母变化下的权重. 设批内只有两条正确回答, $y_1$ 长 200 token, $y_2$ 长 2000 token, 优势同为正. GRPO 的归约先按长度平均再对回答等权, 每条回答在批梯度中的权重是 $1/2$. DAPO 的批内 token 统一分母下, 权重是 $|y_i|/\sum_j|y_j|$: $y_1$ 得 $200/2200\approx0.091$, $y_2$ 得 $2000/2200\approx0.909$. 同一个 batch, 两条回答的权重比从 $1:1$ 变成 $1:10$. 这不是一个无关紧要的常数: 批梯度的方向在长回答主导的意义上已经改变, 这正是「GRPO 按条投票, DAPO 按 token 数投票」的算术形式 (1.3.2.1 节 §4.1). 配套的长度分桶让 batch 内长度尽量齐, 就是把这个效应限制在桶内 (1.3.2.1 节 §4.2).

第二组对比聚合函数. 取一条优势为正的 rollout, 比率向量 $\rho=(0.5,1,8)$ (与 1.3.2.3 节 §2.3 同一设定). 算术平均: $(0.5+1+8)/3=3.167$. 几何平均: $(0.5\times1\times8)^{1/3}=4^{1/3}\approx1.587$. 合成权重被压缩近一半, 压缩量几乎全部来自 $\rho=8$ 的离群 token. 在 log space 验证: $\log\rho=(-0.693,0,2.079)$, 均值 $0.462$, 指数化回 $e^{0.462}\approx1.587$, 与直接开立方一致. 再看均匀形态 $\rho=(1.05,0.97,1.01,0.99)$: 算术平均 $1.005$, 几何均值约 $1.0049$, 两者几乎重合. 几何聚合对均匀 rollout 不改变行为, 收益集中在撕裂 rollout 上, 这是 AM-GM 不等式的直接结构: 分布越不均匀, 两个均值的差距越大 (1.3.2.3 节 §2.2).

### 4.2 clip 生效区间对照: 同一漂移模式下的判决

第一组 clip 对照用单 token 漂移. 设某正优势回答的一个 token 比率漂到 $r=1.25$. GRPO 的 clip 上界 $1+\epsilon=1.2$: 未裁剪项 $1.25A$, 裁剪项 $1.2A$, min 取 $1.2A$, 平台形成, 梯度为零. DAPO 的上界 $1+\epsilon_{high}=1.28$: $1.25$ 仍在平台外, 梯度保留, 斜率就是 $A$. 区间 $r\in[1.20,1.28]$ 正是 minibatch 复用中 off-policy 程度加深后正优势样本最常见的位置, Clip-Higher 放松的恰好是信号最密集的地带 (1.3.2.1 节 §2.3).

第二组对照用整条链的同向漂移, 看序列级判决. 设链长 $T=2000$, 每个 token 的 log-ratio 同向漂 $0.005$, 序列比率 $s=\exp(0.005)\approx1.005$. GRPO 与 DAPO 的逐 token 比率都是 $e^{0.005}\approx1.005$, 远在 1.2 的平台外, 全部保留梯度. GSPO 的 clip 上界是 $1+3\times10^{-4}=1.0003$, $s=1.005$ 远超上界, 整条链被截停. 这个反差的原因在量纲: $s$ 是平均漂移的指数, 平均每个 token 漂 $3\times10^{-4}$, 4000 token 的链总似然已漂移 $e^{1.6}\approx5$ 倍 (1.3.2.2 节 §3.3). 更精细的算术: 单 token log-ratio 方差 $\sigma^2=0.01$ 时, 均值的标准差是 $\sqrt{0.01/2000}\approx0.0022$, $s$ 的相对波动约 $0.22\%$, 已经超过 $3\times10^{-4}$ 的 clip 边界, 接近半数样本触发 clip, clip 持续参与塑形 (1.3.2.2 节 §2.4).

第三组对照看 GMPO 的 log 裁剪. 取 $d=\log\rho=0.4$, 恰好在 GMPO 的边界上, 对应比率 $e^{0.4}\approx1.49$; GRPO 式的 ratio clip ($\epsilon=0.2$) 在 $1.2$ 处早把它截停, log clip 到 $0.4$ 才停, 对正向强化温和. 反向取 $d=-0.4$, 比率约 $0.67$: log clip 在此截停, 而 ratio clip 的 $0.8$ 下界反而更宽松. **同一个 $\epsilon$ 数值在两种量纲下宽度差一倍, 盯防的方向相反**: log clip 紧盯着负向滑移, 放行正向强化, 和 Clip-Higher 的目标一致, 实现路径不同 (1.3.2.3 节 §3.3).

## 5. 选错代价最大的三个场景

### 5.1 量纲误迁: 把一家的 clip 数值搬进另一家的量纲

代价最高的错误是跨量纲搬数值. GSPO 的 clip 区间 $[1-4\times10^{-4},1+3\times10^{-4}]$ 比 GRPO 的 $0.2$ 小三个数量级, 根源是比率定义不同: token 级 clip 的 $0.2$ 是「单位置漂 20% 就算出格」, 序列级 clip 的 $3\times10^{-4}$ 是「平均每 token 漂 $0.03\%$ 就算出格」. 复现 GSPO 时把 $3\times10^{-4}$ 换成 $0.2$, 等于没有 clip; 把 GRPO 的 $0.2$ 换成 $3\times10^{-4}$, 训练会慢到不动 (1.3.2.2 节 §3.3). GMPO 的 $\epsilon=0.4$ 绑定 log 空间, 对应比率区间 $[0.67,1.49]$, 把它当 ratio 空间的 $0.4$ 用, 上界变成 $1.4$, 与论文语义完全不同. 跨论文移植任何 clip 数值前, 先写出它的量纲推导, 量纲写不出来就不许搬 (1.3.2.2 节 §2.2).

标定序列级 clip 有现成流程: 先跑若干步无 clip 的 pilot, 记录 $s_i$ 的 P50, P95, P99, 把 clip 边界设在 P95 附近, 让约 5% 的样本触发截停 (1.3.2.2 节 §3.3). 这条流程和 GRPO 调 $\epsilon$ 的「clip fraction 目标区间」思路一致, 只是分布的量纲不同, 必须先重新测. 跳过 pilot 直接抄论文数值, 等于把别人家的策略漂移水平当成自己的, 多数时候不成立.

### 5.2 架构错配: 在 MoE 上保留逐 token clip

第二个高代价场景是架构与 surrogate 粒度错配. Qwen 团队在 Qwen3 级别的 MoE 上用 GRPO 训练, 观察到 loss 周期性爆炸, 模型质量断崖下跌, 重试 seed 也救不回来. 定位到的机制是专家路由的放大效应: policy 参数的微小变化让一批 token 的路由集体翻转, 逐 token 比率上同时出现大量离群值, 几十个同方向的 clip 后梯度叠加, 参数被猛推, 下一步更多 token 路由翻转, 形成正反馈 (1.3.2.2 节 §1.2, §5.1). 在已经观测到这类崩溃的管线上坚持逐 token clip, 等于保留正反馈环路.

对应的修法按改动成本排序. GSPO 把路由翻转的平均进标量, $s_i$ 只反映平均漂移, 集体事件不再穿透成几百个独立的 clip 决策, 但存储, 日志, 监控都要跟着换到序列级. 若崩溃症状已出现而 GSPO 的基建改动太大, GMPO 是留在 token 级的最小替代: 几何压缩把离群从算术的线性放大改成开方压制, 撕裂度 10 时两种聚合的合成权重差出三倍 (1.3.2.3 节 §1.1). 还有一条并行路线是 router 正则与负载均衡损失的调校, 它只动模型配置, 不动训练器, 排查成本低, 应与 surrogate 的改动并行进行 (1.3.2.2 节 §5.2).

### 5.3 归一化开关错配: 去标准差归一却不重标定其余超参

第三个场景是改动孤立, 不同时调整耦合量. 去掉组内标准差归一, 优势尺度立刻变化. 用 (1.3.1.1 节 §2.3) 的手算: 组内 reward $R=[1,1,0,0]$, 组均值 $0.5$, 总体标准差 $0.5$, 归一化优势是 $[1,1,-1,-1]$; 去掉归一后是 $[0.5,0.5,-0.5,-0.5]$, 符号相同, 梯度尺度相差两倍. 若优化器, KL 系数与 clip 范围保持不变, policy loss 相对 KL 与其他损失的权重已经改变, 等效学习率翻倍. RLOO 的缩放关系给出同方向的警告: 优势绝对值系统性偏大 $33\%$ ($G=4$ 时), 直接搬学习率会放大更新步长 (1.3.1.2 节 §2.3).

同理, 换 DAPO 的 token 统一分母改变梯度的有效尺度, 等效于动了学习率; 只换分母不动其他, 常见的结果是曲线有变化但方向难以判断 (1.3.2.1 节 §4.3). **任何归约或归一化的改动都必须与学习率, KL 系数当成一个整体重调**, 改动后先用手算的重放确定尺度倍数, 再决定其他超参的补偿量, 顺序反过来就是盲调.

## 6. 组合与迁移路径

### 6.1 正交组合的规则

组合的规则由作用点决定. 作用于采样与 reward 端的技巧, 动态采样与长度塑形, 与任何 surrogate 正交, 组合无障碍, 事实上任何 GRPO 系实现都应默认评估这两项 (1.3.2.2 节 §4.3). 作用于 clip 的改动要小心层数: Clip-Higher 与 GSPO 的序列级 clip 结构上相容, 正优势用 $\epsilon_{high}$, 负优势用 $\epsilon_{low}$ 的语义在标量 $s_i$ 上仍可定义, 只是数值必须在序列级量纲重新标定 (1.3.2.2 节 §4.3). GMPO 的 log clip 与 Clip-Higher 语义相容, 数值同样要重标定.

长度处理只保留一层. GSPO 的比率内建了 $1/|y_i|$, DAPO 的 token 统一分母作用在 token 粒度, 两者叠加会双重计数长度因子; 用 GSPO 时损失分母回到每条回答等权 (1.3.2.2 节 §4.3). GMPO 的几何聚合与 DAPO 的 token 统一分母作用点不同, 前者改回答内部的聚合函数, 后者改回答之间的权重, 两者可以同时用, 但两个效应在梯度上相乘, 有效权重结构更难直觉把握, 调试时每个现象都要归因到两层中的哪一层 (1.3.2.3 节 §5.3). 调试预算随层数增长: 单层 clip 是单因子扫描, 两层 clip 是二维扫描, 每层配自己的标定流程. 调试带宽紧时, 先把单层方案的边界情况跑全, 稳定性差距往往小于调试事故的损失 (1.3.2.3 节 §5.3).

### 6.2 迁移路线: 从基线出发的单开关改动

推荐的迁移路线固定为四步. 第一步, 用原始 GRPO 配方跑通基线, 逐项核对五个开关: 优势怎么算, ratio 在 token 还是序列级, clip 边界各是多少, 归约分母是什么, 采样怎么过滤和补采 (1.3.2.1 节 §6.3). 没有这个基线, 后续每个变体的收益都无处归因. 第二步, 按第 3 节决策树找到最显著的症状, 只改对应的那个开关, 其余保持不动; 想验证某开关在自己管线里的真实贡献, 在全量基线上做减法, 而不是从基线做加法, 因为各开关之间存在相互作用, 单项效果在其余开关齐全与缺席的上下文里不同 (1.3.2.1 节 §7.3).

第三步, 每次改动后在历史 batch 上重放: 分别用新旧两种配置算合成梯度, 比较参数更新的方向余弦, 相似度高于 0.99 说明这个改动在自己的数据上无关紧要, 低于 0.95 才值得专门消融 (1.3.2.2 节 §5.2). 第四步, 把每个 run 的坐标选择固化进配置模板, 让坐标报告成为提交训练配置的固定字段, 回看历史 run 时直接读出当时的选择 (1.3.2.3 节 §6.4).

路线之外还有两条支线. 一是 GMPO 与 GSPO 的开放组合: 先逐 token 做 log 裁剪与几何平均, 再对 $\rho_{geo}$ 做一次序列级 clip, 两个粒度的防护叠加. 没有公开实现这么做, 代价是多一层超参标定, 收益未知, 列为开放组合而非建议 (1.3.2.3 节 §4.2). 二是过程奖励方向的兼容性: 一旦 reward 细化到步骤级, 「奖励单位与优化单位对齐」的论点要求优化也细化, GSPO 的序列级比率反而成了错配, 中间的混合形态尚无标准答案 (1.3.2.2 节 §6.2). 选型最终要交付按症状触发开关的操作顺序, 以及每步对应的监控口径；只给一个所谓最优变体的名字没有多少用处.

## 8. 用同一批张量走查四种目标

### 8.1 固定样本与共同参照

为了避免比较停在方法名称上, 取同一 prompt 的两条回答, 每条三个有效 token. 旧策略到新策略的逐 token 概率比率分别为 $[1.30,1.10,0.90]$ 与 $[0.80,1.00,1.20]$, 组内优势分别为 $+1$ 与 $-1$. 这里省略熵奖励与 KL 惩罚, clip 下界和上界先取 $0.8$ 与 $1.2$. 普通 GRPO 对每个 token 独立计算 $\min(r_tA,\operatorname{clip}(r_t)A)$, 因而第一条回答的首 token 命中上界, 其余 token 保留原比率; 第二条回答在负优势下按对应方向裁剪.

这个例子先固定三个共同量: 样本、优势和旧策略. DAPO、GSPO、GMPO 改动的是损失聚合或稳定机制, 不是凭空得到另一批奖励. 对比实现时也应复用同一份缓存 logits 和 mask, 否则采样差异会盖过目标函数差异, 最终无法解释 loss 为什么不同.

### 8.2 DAPO 改变权重与采样入口

DAPO 的 token-level loss 让所有有效 token 进入同一个分母. 在示例中两条回答等长, 它与先按序列平均再按 batch 平均一致; 若第一条有六个 token、第二条只有两个 token, token-level 聚合会让第一条获得三倍权重. 这不是纯实现细节, 它决定长回答贡献多少梯度. 因而测试 DAPO 时必须加入不等长样本, 只测等长 batch 无法发现聚合轴写错.

动态采样发生在计算上述损失之前. 如果一个 prompt 的所有回答奖励相同, 该组不能提供相对优势, DAPO 会倾向于过滤并补采新的 prompt. 所以 DAPO 的有效数据分布与普通 GRPO 不同. 公平比较应固定总 rollout token 并记录补采比例, 不能只固定保留下来的 batch 数.

### 8.3 GSPO 把裁剪单位提升到序列

GSPO 先把逐 token 对数比率聚合成序列统计量. 对第一条回答, 平均对数比率为

$$
\bar\ell_1=\frac{\log1.30+\log1.10+\log0.90}{3}\approx0.084,
$$

对应序列比率约为 $e^{0.084}\approx1.088$. 普通 GRPO 已裁掉首 token 的 $1.30$, GSPO 的聚合比率仍在区间内, 因而整条序列不触发相同的裁剪. 这正是两种方法行为不同的地方: token 级异常是否足以阻断该 token 的梯度, 还是由整条序列的平均变化决定.

序列聚合在 MoE 场景可减少路由微扰造成的局部比率尖峰, 代价是局部变化可能互相抵消. 所以 GSPO 的日志除序列 clip 命中率外, 仍应保留逐 token 对数比率的最大值和方差. 聚合稳定只说明更新单位稳定, 不说明每个位置都没有异常.

### 8.4 GMPO 用几何平均连接两个层次

GMPO 同样从对数域聚合, 第一条回答的几何平均比率也是约 $1.088$. 几何平均使长序列的连乘转为平均对数概率差, 避免乘积随长度指数放大. 但几何平均为 $1$ 时, 逐 token 比率仍可能是 $[2,1/2]$ 这样的强烈抵消. 因此 GMPO 回答的是整条回答相对旧策略改变了多少倍, 不是每个 token 是否都处于安全区间.

实现时先按 mask 对 `log_ratio` 求平均, 再指数化; 不应先指数化后做算术平均. 两者分别是几何平均与算术平均, 在比率分散时差异明显. 可用 $[2,1/2]$ 做测试: 几何平均为 $1$, 算术平均为 $1.25$. 这个小测试能直接发现聚合顺序写反.

## 9. 比较实验怎样排除假收益

### 9.1 对齐计算预算和样本分布

四种方法的每步成本看似接近, 实际 rollout 利用率并不相同. DAPO 的动态采样可能丢弃无差异组并补采, GSPO 与 GMPO 可能因更少 clip 保留更多梯度 token. 如果只比较 optimizer step, 每个 checkpoint 已消费的生成 token 和有效梯度 token 都可能不同. 实验表应同时列出生成 token、保留 token、更新步数和 GPU 时.

prompt 难度也要对齐. 动态过滤会把训练分布推向中等难度题, 而静态 GRPO 仍看到大量全对或全错组. 可以在公共验证集外, 另按初始通过率分桶报告提升. 若收益只出现在某一难度桶, 说明方法改善的是数据利用方式, 不宜概括成所有推理任务都更强.

### 9.2 同时观察收益与稳定代价

最终准确率相同的两次训练, 稳定性可能差很多. 需要并列记录崩溃次数、clip 命中率、优势标准差、策略 KL、回答长度和每 token 奖励. 某个方法若以更高 rollout 成本换来更平滑曲线, 是否采用取决于集群空闲度与失败恢复成本; 某个方法峰值更高但方差也高, 则应报告多随机种子区间, 不能只挑最好 checkpoint.

最有信息量的选型顺序是从可复现的普通 GRPO 开始, 每次只改变一个统计单位. 先把序列平均换成 token 聚合, 检查长度权重; 再把 token 比率换成序列比率, 检查 MoE 稳定性; 最后比较几何平均的聚合方式. 这样每次差异都能落回一项张量运算, 出现退化时也知道该检查 mask、clip 还是采样器.

### 9.3 部署前的最小验收矩阵

部署候选至少经过四类 batch: 等长且奖励有差异、不等长且奖励有差异、全同奖励、含极端概率比率. 第一类核对基本梯度方向, 第二类核对聚合分母, 第三类核对标准差下界和动态过滤, 第四类核对 clip 与数值稳定. 每类 batch 都保存逐 token loss、序列 loss 和最终梯度范数, 便于不同实现逐项比对.

然后再进入小规模真实训练. 先用固定 prompt 集生成, 避免数据分布变化; 确认各目标的 loss 与离线走查一致后, 才打开动态采样和分布式并行. 这个顺序把公式实现、采样策略与系统通信分开验证, 能减少多种误差同时出现时的定位成本.

## 10. 从同一个策略梯度写出 PPO、GRPO 与 REINFORCE++

### 10.1 共同起点

设提示为 $x$，模型生成回答 $y=(a_1,\ldots,a_T)$，终局奖励为 $R(x,y)$。最基础的 REINFORCE 梯度是

$$
\nabla_\theta J(\theta)
=\mathbb E_{x,y\sim\pi_\theta}
\left[(R-b(x))\sum_{t=1}^{T}\nabla_\theta\log\pi_\theta(a_t\mid x,a_{<t})\right].
$$

基线 $b(x)$ 只要不依赖当前采样动作，就不会改变梯度期望，却能降低方差。PPO、GRPO 与 REINFORCE++ 的分歧，主要落在四处：基线从哪里来，回报怎样分配到 token，旧策略样本怎样修正，策略漂移怎样约束。

PPO 训练一个价值函数 $V_\phi(s_t)$，用 GAE 或多步回报形成 token 级优势 $\hat A_t$。其裁剪代理目标为

$$
L_{\mathrm{PPO}}
=\mathbb E_t\left[
\min\left(ho_t\hat A_t,
\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t\right)
\right],
$$

其中 $\rho_t=\pi_\theta(a_t\mid s_t)/\pi_{\mathrm{old}}(a_t\mid s_t)$。critic 增加显存与训练复杂度，也让不同时间位置获得不同优势。长程环境中，哪一步使状态改善可以进入 $V(s_{t+1})-V(s_t)$；终局奖励无需原样广播给所有 token。

GRPO 不训练 critic。对同一提示采样 $G$ 个回答，奖励为 $R_1,\ldots,R_G$，典型优势是

$$
\hat A_i=\frac{R_i-\bar R}{s_R+\varepsilon},\qquad
\bar R=\frac1G\sum_{j=1}^{G}R_j.
$$

同一回答里的 token 通常共享 $\hat A_i$。它省掉 value model，却把“同提示其他回答”当作基线，并把信用粒度从状态动作降到回答级。数学题终局可验证、轨迹较短时，这个交换很划算；工具轨迹很长、同一回答里好坏动作交织时，代价会逐渐显露。

REINFORCE++ 同样避免独立 critic，但保留 PPO 训练中的若干稳定化组件，例如优势归一、重要性采样裁剪、KL 约束与更细的回报处理。不同实现对基线、归一范围和 token 回报的定义并不完全一致，比较时应直接写出目标张量。方法名不能替代“优势在哪个维度归一、loss 用什么分母、KL 放进奖励还是 loss”这三个配置。

### 10.2 critic 基线与采样基线的区别

PPO 的 $V_\phi(s_t)$ 试图估计从当前状态继续执行策略的期望回报。GRPO 的 $\bar R$ 只估计同一提示下这一小组回答的平均结果。前者可以跨样本共享统计强度，也可能产生函数逼近偏差；后者无需拟合，噪声随组大小与奖励分布变化。

假设某提示的真实平均成功率为 $p$，奖励是零或一。用 $G$ 个样本的组均值估计 $p$，方差为 $p(1-p)/G$。当 $p=0.5,G=8$ 时方差为 $0.03125$，标准差约 $0.177$；当 $G=2$ 时标准差约 $0.354$。组小一倍，不只是有效答案少，基线本身也更抖。

critic 则可能在相似提示间泛化。若它校准良好，单个提示无需八条 rollout 也能得到稳定基线；若训练分布变化或状态表示缺失，它会把系统误差传播给大量样本。组均值误差多为局部采样噪声，critic 误差可能在一个任务族上同方向偏移。这是两类基线最重要的风险差别。

### 10.3 REINFORCE++ 的位置

把策略梯度训练拆成“采样、回报、优势、离策略修正、约束、归约”六层，REINFORCE++ 位于无 critic 的序列策略梯度一侧，却吸收 PPO 的工程稳定性。它说明省掉 critic 并不等于放弃旧策略比率、裁剪和 KL，也不意味着只能做组内相对奖励。

若数据包含跨提示可比的标量奖励，可以在 batch 内做回报标准化，再把归一后的序列回报分给 token；若奖励只在同一提示内有意义，组内中心化更自然。前一种方式保留提示间绝对难度信息，后一种方式消除提示级平移，却会让每组的相对名次主导梯度。

选型时可问一个具体问题：当前瓶颈来自 critic 成本，还是来自序列级信用过粗？若 critic 成本是主要矛盾，REINFORCE++ 或 GRPO 都可能合适；若长轨迹里需要辨别早期决策与后期修复，换成另一种无 critic 方法不会自动补回 token 级价值信息。

## 11. 组内基线的偏差与方差

### 11.1 把自己放进均值会发生什么

GRPO 常用包含当前样本的组均值。对第 $i$ 个回答，未标准化优势为

$$
A_i=R_i-\frac1G\sum_{j=1}^{G}R_j.
$$

将均值拆开：

$$
A_i=\frac{G-1}{G}
\left(R_i-\frac1{G-1}\sum_{j\ne i}R_j\right).
$$

括号内是 leave-one-out 基线得到的优势，外面多了 $(G-1)/G$。包含自身的基线让优势整体缩小。固定提示并假设各回答独立同分布，$R_i$ 与其他样本均值独立，leave-one-out 形式保持标准 score-function 基线的条件；包含自身时，基线依赖 $a_i$，严格说会引入有限组偏差。

对未标准化、无裁剪的情形，这个偏差表现为梯度缩放。因为组内对称性，期望梯度约乘 $(G-1)/G$。$G=2$ 时只剩一半，$G=8$ 时为八分之七。学习率可以吸收部分尺度差，但加入标准差归一、裁剪和动态过滤后，变化不再是简单常数。

leave-one-out 优势写为

$$
A_i^{\mathrm{LOO}}=R_i-\bar R_{-i}.
$$

它去掉自包含偏差，代价是基线只用 $G-1$ 个样本，方差略高。对于 $G=2$，优势就是两条奖励之差，两个样本互为相反数；二值奖励下只有一对一错时有信号。

### 11.2 标准差归一改变了什么

除以组内标准差会让奖励尺度近似一致，但分母也来自当前动作集合。优势不再只是中心化回报的固定倍数，低方差组会被放大。取奖励 $[1,0,0,0]$，均值 $0.25$。若用总体标准差，$s=\sqrt{3}/4\approx0.433$，优势约为

$$
(1.732,-0.577,-0.577,-0.577).
$$

取连续奖励 $[0.51,0.50,0.50,0.49]$，均值仍是 $0.50$，标准差约 $0.00707$，归一后得到约

$$
(1.414,0,0,-1.414).
$$

第二组原始差距只有 $0.02$，归一后更新幅度却与第一组同量级。如果细小差距来自 verifier 噪声，策略会把噪声当成强偏好；如果不同提示的奖励量纲确实无法比较，归一又能避免高方差提示垄断梯度。是否除标准差取决于奖励差距的可信度，不能只凭训练稳定性判断。

Dr. GRPO 去掉组内标准差归一，正是为了避免题目难度与组方差改变权重。去掉后，高奖励跨度的组贡献更大，奖励标定必须跨提示可比。若一个 verifier 输出 $0$ 到 $1$，另一个输出 $-10$ 到 $10$，直接中心化会让后者控制训练。先统一奖励量纲，再比较是否需要标准差归一。

### 11.3 二值奖励下的零方差概率

成功概率为 $p$，组大小为 $G$，全同组概率为

$$
P_{0}=p^G+(1-p)^G.
$$

$p=0.5,G=8$ 时 $P_0=2/256\approx0.78\%$；$p=0.1,G=8$ 时约为 $43.05\%$；$p=0.01$ 时超过 $92\%$。极难任务上盲目增加训练步数，大部分生成预算仍落在零优势组。增加组大小能降低全错概率，但计算量线性上升，而且在 $p$ 极小时改善有限。

动态采样筛掉全同组可提升有效梯度比例，也改变了 prompt 分布。某提示被保留的概率为

$$
q(p)=1-p^G-(1-p)^G.
$$

$q(p)$ 在 $p=0.5$ 附近最大，在两端趋近零。筛选后的训练集天然偏向中等难度。若目标分布包含大量极难问题，模型会越来越少看到它们；若课程目标正是把算力集中到学习边界，这种偏移又可能符合预期。报告动态采样时应给出筛选前后的难度分布。

### 11.4 零方差组并非完全无信息

全错组说明当前策略在该提示附近没有找到成功动作，全对组说明任务可能已经掌握。对纯组内相对优势而言，它们确实没有策略梯度信号；若目标还含 KL、熵奖励或长度惩罚，这些组仍会产生梯度。直接整组丢弃会同时删掉这些约束。

全错组还能用于课程调度和探索诊断。连续多轮全错且回答高度相似，问题可能是探索坍缩；回答多样但全错，可能是任务超出能力或 verifier 过严。两种情况都显示零奖励方差，处理方法分别是恢复多样性与调整任务阶梯。

可做一个对照：A 组只丢弃全同组，B 组保留全同组的 KL 与熵项但屏蔽奖励梯度，C 组完全保留。若 A 的策略 KL 明显更快增长，收益不能只归因于有效样本增加；它还削弱了约束。这个实验能把采样收益与正则变化拆开。

## 12. 重要性采样：逐 token 比率并不等于整条序列修正

### 12.1 从轨迹比率到 token 代理目标

旧策略生成整条回答时，严格的轨迹重要性比率为

$$
w(y)=\frac{\pi_\theta(y\mid x)}{\pi_{\mathrm{old}}(y\mid x)}
=\prod_{t=1}^{T}\rho_t.
$$

它能修正整条轨迹的分布差异，却随长度指数波动。若每个 $\log\rho_t$ 方差为 $\sigma^2$ 且弱相关，$\log w$ 的方差约为 $T\sigma^2$。长度达到数千 token 后，即使单步变化很小，轨迹权重也可能跨越多个数量级。

PPO 与常见 GRPO 实现用逐 token 比率配共享序列优势：

$$
L_i=\frac1{T_i}\sum_{t=1}^{T_i}
\min\left(\rho_{i,t}A_i,
\operatorname{clip}(\rho_{i,t},1-\epsilon,1+\epsilon)A_i\right).
$$

这不是完整轨迹重要性采样的无偏替代，它是限制更新幅度的代理目标。优势来自旧策略样本，逐 token 比率让每个已采样动作按新旧概率变化调整。裁剪主动引入偏差，换取有限方差和更稳定的多轮更新。

### 12.2 正负优势的裁剪方向

取 $A=2,epsilon=0.2$。当 $\rho=1.3$ 时，未裁剪项为 $2.6$，裁剪项为 $2.4$，取较小值 $2.4$，继续提高好动作概率不再增加目标。当 $\rho=0.7$ 时，未裁剪项 $1.4$ 小于裁剪项 $1.6$，梯度仍推动比率上升。

取 $A=-2$。当 $\rho=0.7$ 时，未裁剪项 $-1.4$，裁剪项 $-1.6$，取较小值 $-1.6$，继续降低坏动作概率不再改善目标；当 $\rho=1.3$ 时取 $-2.6$，仍会推动比率下降。`min` 与优势符号共同形成两侧不同的平坦区，实现时不能先对比率统一截断再乘优势，否则目标的梯度结构会变化。

DAPO 的 Clip-Higher 把正侧上界放宽。其动机是正优势动作提升概率的空间常被较早截断，而负优势动作仍受到下界保护。非对称边界能让罕见正确答案获得更长的强化区间。若 reward 有误标，放宽正侧也会更用力地强化假阳性，因此必须结合 verifier 精度看。

### 12.3 多个 epoch 后的分布错位

rollout 由 $\pi_{\mathrm{old}}$ 生成，同一批数据被复用多个 minibatch epoch 后，当前策略逐渐远离行为策略。clip fraction 上升，越来越多 token 落入平坦区，有效梯度减少。继续增加 epoch 可能只让未被裁剪的少量 token 主导更新。

离线数据的行为策略更旧，甚至拿不到精确 token 概率。此时把比率设为一，相当于忽略分布差异；用当前参考模型重算旧文本概率，也不能恢复生成它的真实策略。可以把这些样本用于监督学习、奖励模型或保守离线目标，直接塞进 GRPO/PPO batch 需要清楚标注近似。

验证分布错位可固定一批 rollout，随训练步记录其逐 token KL、比率分位数与可用梯度比例。若收益在比率尾部扩张后停止，减少 epoch 或缩短 rollout 到更新的延迟，比继续调学习率更直接。

## 13. KL：约束放在哪里会改变梯度

### 13.1 reward KL 与 loss KL

KL 可以作为每 token 奖励惩罚：

$$
r_t'=r_t-\beta\left(\log\pi_\theta(a_t\mid s_t)-
\log\pi_{\mathrm{ref}}(a_t\mid s_t)\right),
$$

也可以作为 loss 中独立的正则项。放进奖励后，它进入回报和优势，前面 token 可能承接后续 KL；放进 loss 时，每个位置直接获得局部约束梯度。两种写法在有限样本、裁剪和优势归一存在时并不等价。

常见的采样 KL 估计只观察策略实际生成的 token。若策略已经把某些参考动作概率压得很低，它们很少被采到，估计可能漏掉分布尾部。全分布 KL 需要词表概率，计算更贵，却能看到未采样动作的质量移动。至少应说明日志里的 KL 是 sampled log-ratio 还是完整分布求和。

### 13.2 自适应 KL 系数

设目标 KL 为 $d_*$，观察值为 $d$。简单控制器可按

$$
\beta\leftarrow\beta\exp\left(\eta_\beta(d/d_*-1)\right)
$$

更新系数。$d>d_*$ 时增强约束，$d<d_*$ 时减弱。长回答的总 KL 通常随长度增加，若控制器使用序列总和，长度分布变化会被误解为策略突然漂移；用每 token 平均又可能掩盖少数关键位置的大变化。最好同时记录两者，控制口径与目标一致。

DAPO 在可验证数学任务中移除显式 KL，依靠 clip 控制更新。这里有两个条件：奖励可靠，并且训练目标允许策略明显偏离参考模型。开放式偏好任务的 reward model 存在漏洞，KL 还承担防止语言质量和通用能力漂移的作用。照搬“去 KL”前应对隐藏评测、格式质量与分布外提示做对照。

### 13.3 clip 与 KL 互不替代

clip 限制采样动作的局部概率比，KL 衡量整个动作分布的距离。一个 token 上，采样动作比率保持在 $1.1$，未采样词的概率仍可能大幅重排；逐 token clip 看不到这种变化。反过来，平均 KL 很小也可能包含少数 token 的巨大比率尖峰。

构造一个三动作分布即可看到差别。参考分布为 $(0.98,0.01,0.01)$，新分布为 $(0.98,0.019,0.001)$。若采样到第一项，比率等于一，PPO 对这个 token 看不到漂移；后两项内部已经重排近十倍。完整 KL 虽仍不大，却能捕捉变化。实际词表更大，尾部分布的移动更隐蔽。

实验中应交叉画 clip fraction、sampled KL、full-distribution KL 探针和最大 log-ratio。只用一条曲线很难判断约束是否真的生效。

## 14. 长度偏差来自三处

### 14.1 loss 分母

GRPO 常先对每条回答的 token loss 求平均，再对回答求平均：

$$
L_{\mathrm{seqavg}}=\frac1B\sum_i\frac1{T_i}\sum_t\ell_{i,t}.
$$

长度为二十和二百的回答总权重相同，后者每个 token 的权重只有前者十分之一。DAPO 的 token-level loss 写为

$$
L_{\mathrm{tokavg}}=\frac1{\sum_iT_i}\sum_i\sum_t\ell_{i,t},
$$

每个 token 等权，长回答总权重更大。两种目标回答不同问题：前者让每条采样回答贡献相同，后者让每个生成决策贡献相同。

手算两条回答，长度分别为二和八，所有 token 的代理项都为一。序列平均下每条权重各为 $0.5$；token 平均下权重为 $0.2$ 与 $0.8$。若长回答往往正确，token 平均增强正信号；若长回答是反复试错，token 平均会奖励冗长。需要联合观察长度、正确性与每步信息增益。

### 14.2 奖励与截断

生成上限会把“本来能答对但尚未结束”的回答记成失败。长度越接近上限，reward 越混合任务质量与系统截断。硬性把超长回答置零，会在边界制造不连续：只多一个 token，回报从一跳到零。

Overlong Reward Shaping 在期望长度后逐渐惩罚，到最大长度再达到完整惩罚，让梯度提前感知预算。其风险是模型学会抢在边界前给答案，可能牺牲验证步骤。应分别评测答案正确率、截断率、提前终止率和隐藏错误，不能只看平均长度下降。

### 14.3 优势复制

序列优势复制给全部 token 时，长回答携带更多同号标签。即便 loss 在序列内平均，参数共享使不同位置的梯度方向可能累积出结构影响。回答后半段常包含结论、格式与自检，前半段包含探索；统一优势无法区分这些角色。

一个可证伪实验把成功回答的无效尾注删除，保持 verifier 结果不变。若两条语义等价轨迹产生明显不同的更新范数，目标存在长度敏感。再把关键推理步骤重复两次，检查模型是否因 token 数增加而获得额外信用。理想目标至少应对纯重复保持近似不变。

长度研究还要控制采样温度。高温会同时增加多样性、错误率和平均长度，看到“长回答更差”未必是 loss 偏差。固定提示与随机种子，在同一策略上通过停止规则或受控续写改变长度，才能更接近因果比较。

## 15. DAPO 的四个改动应分开检验

### 15.1 Clip-Higher

非对称裁剪主要改变正优势动作的概率提升上限。若训练初期正确答案罕见，正样本比率容易快速越过 $1+\epsilon$，随后不再贡献梯度。抬高正侧边界能延长学习窗口。

对照时固定采样数据，只替换裁剪边界，统计正负优势各自的 clip fraction 与有效梯度 token。若正侧有效比例上升，成功率却没有改善，可能是正优势标签噪声大，或瓶颈在采样不到成功答案。Clip-Higher 无法创造缺失的正样本。

### 15.2 动态采样

动态采样把生成预算从全同组移到有奖励差异的组。公平比较必须固定总生成 token，不应只固定进入优化器的 batch。补采会额外消耗 rollout，若只比较相同步数，DAPO 实际看过更多候选。

补采策略还决定课程分布。从原 prompt 分布独立补采，保留条件分布但提高成本；优先抽取历史中等难度 prompt，提高有效率却强化选择偏差。日志要保存 prompt 被抽取、被过滤和最终入 batch 的概率，才能解释收益来源。

### 15.3 Token-Level Policy Gradient Loss

统一 token 分母改变长短回答权重，不改变单个 token 的代理项。实现最容易错在分布式归约：每张卡先按本地 token 数平均再做设备平均，会让 token 少的卡权重过大。正确做法是全局汇总有效 token 总数，或者对本地 loss 按全局分母缩放。

用两张卡做单元测试：卡一有十个有效 token，卡二有九十个，所有 loss 分别为一和二。全局 token 平均应为 $1.9$；先做卡内平均再平均得到 $1.5$，差异很大。这个错误在变长序列训练中会随 batch 排布波动，表现成难以解释的梯度噪声。

### 15.4 Overlong shaping 与去 KL

长度塑形改变奖励，去 KL 改变约束，两者与裁剪和采样属于不同层。一次全开后准确率提升，无法知道是有效样本增加、正优势放宽、长度分布变化还是约束减弱。

最小消融从基线出发，每次只加一个开关，再测必要的二阶交互：动态采样与 Clip-Higher 可能相互增强，因为前者提供更多正负混合组；token loss 与长度塑形可能相互抵消，因为一个提高长回答权重，另一个惩罚过长。四个组件全排列成本过高时，至少覆盖这两组交互。

## 16. 一组完整手算

### 16.1 两个提示、六条回答

提示 A 有三条回答，奖励为 $(1,0,0)$，长度为 $(4,2,2)$；提示 B 奖励为 $(0.6,0.5,0.4)$，长度均为二。先不除标准差。A 的均值为 $1/3$，优势为 $(2/3,-1/3,-1/3)$；B 的均值为 $0.5$，优势为 $(0.1,0,-0.1)$。

组内标准差归一后，两组优势都会被拉到相近尺度。使用总体标准差，A 约为 $(1.414,-0.707,-0.707)$，B 约为 $(1.225,0,-1.225)$。B 的奖励总跨度只有 $0.2$，更新却几乎和成败分明的 A 一样强。若 B 的差异来自评分噪声，标准化不利；若 B 的 $0.1$ 差距可靠，它帮助模型学习细粒度偏好。

### 16.2 加入比率与裁剪

令 A 的正确回答四个 token 比率为 $(1.30,1.10,0.95,0.90)$，优势取 $2/3$，$\epsilon=0.2$。代理项依次为

$$
(1.2,1.1,0.95,0.90)\times\frac23
=(0.800,0.733,0.633,0.600),
$$

其中第一项被裁剪。序列内平均约 $0.692$。若用完整轨迹比率，乘积为 $1.22265$，也会越过常见上界，但它把四个位置绑成一个权重；逐 token 目标只截第一项。

取 A 的一条错误回答，比率 $(0.7,1.1)$，优势 $-1/3$。第一个位置进入负优势下侧平坦区，目标取 $0.8\times(-1/3)=-0.267$；第二个取 $1.1\times(-1/3)=-0.367$。两个 token 平均约 $-0.317$。

### 16.3 序列平均与 token 平均

假设六条回答的序列平均代理值分别为

$$
(0.692,-0.317,-0.300,0.110,0,-0.105).
$$

序列等权平均为约 $0.0133$。若按 token 统一平均，第一条长度四，其余长度二，总 token 为十四，结果为

$$
\frac{4(0.692)+2(-0.317-0.300+0.110+0-0.105)}{14}
\approx0.110.
$$

目标从接近零变成明显为正，原因只是正确长回答权重上升。这个例子说明“同一批样本、同一优势、同一 clip”仍可能因归约分母产生完全不同的更新尺度。

### 16.4 加入 leave-one-out 基线

提示 A 中，正确回答的 LOO 基线为零，优势为一；两条错误回答的 LOO 基线均为 $0.5$，优势为 $-0.5$。与包含自身的 $(2/3,-1/3,-1/3)$ 相比，全部放大 $3/2$。提示 B 的 LOO 优势为 $(0.15,0,-0.15)$，同样放大。

无裁剪时学习率缩放可以对齐二者；第一条正确回答已有比率 $1.30$ 被裁剪，放大优势会放大裁剪后的目标，却不会恢复该 token 的梯度。两种基线与 clipping 联合后，不能仅凭全局学习率互相转换。

## 17. 在线、近在线与离线分布

### 17.1 在线 GRPO 的闭环

在线训练不断用当前或近当前策略生成回答、验证、更新。组内比较对应当前策略实际能产生的候选，奖励差异直接服务于下一轮。代价是 rollout 昂贵，且生成、验证、训练之间存在版本延迟。

若某组八条回答来自两个策略版本，组均值混合了不同生成分布。新策略恰好更强时，旧策略样本更容易拿负优势，训练目标同时比较回答质量与策略版本。最干净的组内基线要求同组来自同一行为策略；做不到时至少按版本记录，并检查版本与优势的相关。

### 17.2 离线偏好数据的错位

离线数据往往每个提示只有一个或少数回答，无法构成当前策略的组。把不同模型生成的答案拼成一组，会把模型身份、采样温度与奖励混入组内差异。重要性比率需要真实行为概率，闭源或旧日志通常没有。

离线场景更适合直接偏好优化、监督微调或带保守约束的离线 RL。若仍要使用 GRPO 形式，可以让当前策略对离线 prompt 重新采样，离线答案只作为额外参照或 verifier 样本。这样组内候选仍来自可追踪的行为策略。

### 17.3 难度分布随策略移动

同一 prompt 的成功率会随训练提高，原本中等难度的题逐渐变成全对组。动态采样若持续寻找有方差组，会自动把训练推向更难题，形成隐式课程。总体 reward 上升可能因此变慢：题目越来越难，而能力仍在提高。

评估时固定 prompt 集，并按初始难度与当前难度各分一次桶。只按当前难度分桶会发生样本迁移，难以看出同一批题的学习过程。固定集衡量能力，动态训练集衡量算力利用，两套曲线不能混用。

## 18. 可证伪对照

### 18.1 基线偏差实验

固定一批 prompt，为每个 prompt 采样足够多回答，用大样本均值近似真实基线。再从中反复抽取小组，比较包含自身均值、leave-one-out、critic 和 batch 基线的梯度估计。测相对大样本梯度的偏差、方差与余弦相似度，组大小取 $2,4,8,16$。

若包含自身均值的误差随 $1/G$ 下降，符合有限组缩放；若标准差归一后方向仍大幅变化，问题来自随机分母。critic 若平均方差低但某类 prompt 持续同向偏移，说明函数逼近产生结构误差。

### 18.2 长度偏差实验

构造语义等价的短回答、带无效重复的长回答、包含必要长推理的回答。保持终局 reward 相同，比较序列平均与 token 平均下的梯度范数和后续策略偏好。无效重复不应获得额外优势，必要推理也不应因每 token 权重稀释而消失。

再把生成上限分成宽松与紧张两组。若长度塑形只在紧张上限下有效，在宽松上限下损伤正确率，说明它修复的是截断而非普遍的推理冗长。

### 18.3 clip 与 KL 实验

固定 rollout，扫描对称 clip、Clip-Higher、无 clip 三种目标，记录正负优势的有效梯度比例。另设有无 KL 两组，测隐藏任务质量与参考分布距离。若 Clip-Higher 只提高训练 reward，隐藏正确率不升，应排查 verifier 假阳性。

对 MoE 模型还要按 expert 路由变化分桶。若 token 比率尖峰集中在路由翻转位置，序列级目标改善稳定性有明确证据；若尖峰来自少数关键答案 token，序列聚合可能把应保留的信号平均掉。

### 18.4 动态采样实验

三组分别采用原始采样、过滤不补采、过滤并补采。固定总生成 token 与墙钟时间各做一套比较。过滤不补采能分离“删掉零梯度组”与“增加有效 batch”两种作用；固定墙钟则回答真实系统收益。

按 prompt 初始成功率报告保留概率。若性能提升伴随极难题覆盖率快速下降，动态采样是在缩窄目标分布。可以给极难桶保留最低配额，再看总体与尾部表现能否兼得。

### 18.5 方法选择的推翻条件

声称 GRPO 比 PPO 更合适，至少应在相同生成 token、训练 FLOPs 与验证预算下获得相近或更高性能，并证明 critic 节省抵消了组采样开销。若 GRPO 每个 prompt 需要十六条回答，PPO 只需两条，单看训练显存不能说明总成本更低。

声称 DAPO 组件改善训练，需要单组件消融和关键交互；只比较全套 DAPO 与基础 GRPO，结论只能落在整套配置。声称 GSPO 解决 MoE 不稳定，需要展示不稳定与路由翻转相关，并证明收益不只来自更小的有效更新幅度。

声称 REINFORCE++ 兼具简单与稳定，需要同时报告无 critic 的资源收益、优势估计方差与策略漂移。若为了稳定加入复杂的回报模型、多个参考策略和离线校正，系统复杂度可能只是从 critic 转移到了别处。

### 18.6 组内中心化的期望梯度

把有限组偏差再推一步。固定提示 $x$，记第 $i$ 条回答的 score 为

$$
g_i=\nabla_\theta\log\pi_\theta(y_i\mid x),
$$

原始策略梯度为 $\mathbb E[R_i g_i]$，因为 $\mathbb E[g_i]=0$。使用包含自身的组均值后，单样本项为

$$
\left(R_i-\frac1G\sum_{j=1}^{G}R_j\right)g_i.
$$

对其取期望。$j\ne i$ 时，独立采样使 $R_j$ 与 $g_i$ 独立，故 $\mathbb E[R_jg_i]=\mathbb E[R_j]\mathbb E[g_i]=0$；$j=i$ 时保留 $\mathbb E[R_ig_i]$。于是

$$
\mathbb E\left[(R_i-\bar R)g_i\right]
=\left(1-\frac1G\right)\mathbb E[R_ig_i].
$$

结论成立依赖同组回答条件独立、同分布、没有标准差随机分母，也没有后续裁剪。采样器若做去重、拒绝采样或按前一条回答调整温度，组内样本不再独立，交叉项未必为零。很多实现为了增加多样性会禁止重复答案，这个看似无害的采样策略已经改变上面的推导条件。

leave-one-out 基线满足

$$
\mathbb E\left[(R_i-\bar R_{-i})g_i\right]
=\mathbb E[R_ig_i],
$$

因为基线完全由其他回答构成。若只考虑无裁剪的一阶梯度，它消除了 $(G-1)/G$ 缩放。方差是否更低则没有统一答案：包含自身的均值与 $R_i$ 正相关，会压缩优势；LOO 无偏却让小组基线更抖。

以 $G=2$ 为例，包含自身时两个优势为 $((R_1-R_2)/2,(R_2-R_1)/2)$；LOO 时为 $(R_1-R_2,R_2-R_1)$。方向完全一致，幅度差一倍。加入固定 clip 后，优势幅度不决定哪些比率越界，但决定未裁剪区的 loss 尺度；加入优势 batch 标准化后，两者可能再次被缩到相似尺度。配置层层叠加，单看某一公式很容易误判实际差异。

标准差归一更难解析，因为

$$
\mathbb E\left[\frac{(R_i-\bar R)g_i}{s_R+\varepsilon}\right]
$$

不能拆成期望分子除以期望分母。$s_R$ 与 $R_i,g_i$ 相关，小方差组权重大。$\varepsilon$ 还创造了两个区域：$s_R\gg\varepsilon$ 时近似尺度不变，$s_R\ll\varepsilon$ 时退化为除以常数。修改 epsilon 会改变哪些组被放大，不能只把它视为防止除零的数值细节。

一个简单模拟足以验证实现。选只有两个动作的策略，动作一奖励一、动作二奖励零，策略成功概率为 $p$。真实梯度对 logit 的方向可解析计算。枚举所有 $2^G$ 个组，分别计算包含自身、LOO、标准差归一和零方差丢弃后的期望更新，再与解析梯度比较。这个测试不依赖大模型，能在几秒内抓出基线、分母和 mask 的错误。

### 18.7 组内样本相关会怎样

实际生成常共享 prefix cache、随机数流、批处理调度，或者通过多轮 self-consistency 互相参考。若同组奖励相关，组均值方差变为

$$
\operatorname{Var}(\bar R)
=\frac{\sigma^2}{G}\left[1+(G-1)\rho_c\right],
$$

其中 $\rho_c$ 是任意两条奖励的共同相关系数。独立时 $ho_c=0$；若 $ho_c=0.2,G=8$，方差系数从 $1/8$ 变为 $2.4/8=0.3$，有效样本量只约 $3.33$，并非八条。

相关性也影响零方差组。模型用低温采样时，八条回答可能只是措辞不同、推理路径相同，奖励高度相关。表面组大小为八，基线精度和探索覆盖都接近一两条。监控应统计语义路径或关键步骤多样性，不能只数不同字符串。

若用 best-of-$N$ 先筛一批候选，再从中组成 GRPO 组，奖励分布已被条件选择。组均值估计的是“入选候选”的平均，不是当前策略的平均；高分尾部被过度代表。训练可能有效，却不再对应原始 on-policy 梯度。报告时要把预筛选写进采样分布，别把收益解释成纯粹的优化器改进。

可以设计温度对照：保持每个 prompt 的生成 token 数不变，分别用低、中、高温度采样，测奖励相关、语义路径数、零方差率和最终学习效率。高温降低相关性，也可能降低平均质量；若中温达到最好效果，组采样在探索覆盖与可用答案之间存在明确折中。

采样相关还会来自同一个外部环境。例如工具任务的多条 rollout 共用搜索缓存，第一条请求改变了后续返回；后采样的回答条件已经不同。组内比较要求环境初态一致，应为每条 rollout 克隆状态或至少随机化执行顺序。顺序与优势相关时，问题来自环境污染，不应归因于 GRPO 方差。

### 18.8 reward 噪声怎样穿过组内排序

设观测奖励为 $\tilde R_i=R_i^*+\epsilon_i$，其中 $R_i^*$ 是真实任务效用，$\epsilon_i$ 是 verifier 误差。中心化后噪声变成 $\epsilon_i-\bar\epsilon$。独立同方差噪声会被部分抵消，但每个样本仍含方差

$$
\operatorname{Var}(\epsilon_i-\bar\epsilon)
=\sigma_\epsilon^2\left(1-\frac1G\right).
$$

增加组大小不会让单样本噪声消失，它只让组均值更稳。标准差归一还可能把真实差异很小、噪声占主导的组放大到单位尺度。

若 verifier 对某种风格有共同偏好，误差写成提示级项 $c_x$ 与回答级项 $e_i$。组内中心化会完全消掉对同组所有回答相同的 $c_x$，这是 GRPO 的优势；若偏好随回答长度、格式或措辞变化，它留在 $e_i$ 中，策略仍会学习。

考虑真实效用 $(0.8,0.7,0.6,0.5)$，verifier 给带标题的回答统一加 $0.3$。若后两条恰有标题，观测奖励变成 $(0.8,0.7,0.9,0.8)$，真实最差的第三条反而得到最高正优势。增加组大小只会更稳定地学习标题偏好，无法修复系统误差。

验证方法是制作“保义变换”样本：不改变答案、证据和推理，只改标题、礼貌语、长度或格式。若 reward 与优势排序显著变化，verifier 含风格漏洞。再训练一个短周期，检查策略是否迅速增加对应表面特征。这个实验比只看 reward model 的静态准确率更接近训练中的放大效应。

二值规则 verifier 也会误判。假阳性率 $\alpha$、假阴性率 $\beta$ 会改变组内成功概率。极难任务真实 $p$ 很低时，观测到的“成功”可能主要是假阳性；Clip-Higher 会强化这些罕见正样本。应在正优势样本中人工或用更强验证器复核一部分，估计精度随训练阶段是否下降。

### 18.9 优势归一范围的选择

优势可以在每个 prompt 组内、整个 minibatch、一个数据并行全局或滑动历史窗口归一。组内归一强调相对名次，消掉提示级奖励尺度；batch 归一保留提示间差异，却受 batch 组成影响；全局归一在设备间一致，但通信与统计延迟更大。

假设 prompt A 奖励 $(1,0)$，prompt B 奖励 $(100,99)$。组内中心化后两组差异都为正负 $0.5$，认为两者同等重要；batch 全局中心化会让 B 的两个回答都远高于均值，A 都为负，几乎只学提示间尺度。若两个 verifier 的量纲不同，batch 方案显然错误；若奖励就是可比较收益，组内方案又丢掉绝对水平。

难度信息也藏在绝对成功率里。全对组与全错组都归零，组内方法只学习决策边界附近的 prompt。PPO critic 可通过跨状态估值保留“这个状态整体很差”的信息，但策略梯度仍依赖动作相对优势。无 critic 方法若想利用全错组，需要探索奖励、过程信号或跨样本基线，单纯换归一范围会引入提示难度混淆。

分布式训练还有一个常见差错：每张卡独立标准化优势。若数据分片按任务类型聚集，不同卡得到不同均值方差，相同原始奖励在各卡变成不同标签。全局同步统计可以修复，但动态 padding、无效 token 与零方差组必须使用同一 mask。单元测试应把同一 batch 用单卡和多卡各跑一次，对比 loss 与梯度。

历史滑动统计适合奖励尺度缓慢变化，却会在课程切换时滞后。新任务奖励普遍较低，旧均值会让整批优势偏负，策略可能全面压低已采样动作。切换任务族时重置统计，或者按 verifier 与任务族维护独立统计，更容易解释。

### 18.10 负奖励、平移与尺度

纯策略梯度加一个与动作无关的常数基线不改变期望梯度，有限样本和裁剪训练却可能对奖励平移敏感。组内中心化天然消除同组常数：$R_i+c-(\bar R+c)=R_i-\bar R$。REINFORCE++ 若用全局基线，提示特定的平移不会完全消失。

奖励缩放 $R'_i=aR_i$ 在只中心化时把优势乘 $a$，可用学习率近似吸收；再除标准差时，$a>0$ 基本被抵消。这个尺度不变性看似方便，也会隐藏 verifier 置信度。一个只有千分之一可靠差距的组，与差距十分明确的组被拉到同样尺度。

当 $a<0$，奖励顺序反转，优势符号改变。实现中若把成本写成 reward 却忘记取负，loss 仍可能平滑下降，模型稳定地学向错误方向。最小测试应人工构造一个已知好答案和坏答案，检查一次更新后好答案 log-prob 上升、坏答案下降。

奖励裁剪也会改变排序信息。把所有正奖励截到一，能抑制离群 verifier，却让高质量和刚及格回答相同。组内只有两档信号后，全对概率上升，动态采样会丢弃更多组。稳健处理可采用分位数裁剪或对极端值做温和变换，同时保留中部差异。

多个奖励项相加时，应先看每项在组内的方差与相关。总奖励

$$
R=w_1R_{\mathrm{correct}}+w_2R_{\mathrm{format}}-w_3R_{\mathrm{length}}
$$

中，权重小的格式项若方差远大于正确性项，仍可能主导优势。报告平均贡献不够，应计算每项对中心化优势方差的贡献，以及它与最终任务成功的条件相关。

### 18.11 梯度贡献如何审计

平均 reward 上升只能说明采样结果变化，无法告诉哪个组件产生更新。每个 batch 可以记录按 prompt、回答和 token 分解的未裁剪代理项、裁剪后代理项、KL 项与最终梯度权重。再按奖励符号、长度、难度和策略版本聚合。

定义有效梯度比例为未落入平坦裁剪区且 mask 有效的 token 数占比。它比 clip fraction 更直接，因为某些实现统计比率越界，却没有结合优势符号；正优势低于下界仍有梯度，不能算被裁停。正负优势应分别统计。

定义梯度集中度可用前百分之一 token 的绝对代理项占总绝对值比例。集中度突然升高，常对应少量极端优势、ratio 尖峰或错误的长度分母。再查看这些 token 属于哪些 prompt 和位置，能快速区分 reward 离群与策略离群。

组级别可记录

$$
C_i=\sum_t|w_{i,t}A_i|,
$$

其中 $w_{i,t}$ 包含比率、裁剪状态和归约系数。比较 $C_i$ 与长度、奖励方差、pass rate 的关系，就能看到训练究竟把算力花在哪类组。只看优势直方图会漏掉 ratio 与分母的共同作用。

审计日志无需永久保存全部 token，可固定探针 prompt 和周期性抽样 batch。关键是保持统计定义稳定；训练中途把序列平均换成 token 平均后，历史曲线必须标出断点，否则梯度集中度变化会被误读为模型状态变化。

### 18.12 一套逐层定位流程

reward 不升时，先测组内可学习信号：零方差率、语义多样性与 verifier 重测一致性。这里没有信号，调整优化目标收效有限。若信号充足，再查优势的符号和尺度，确认基线、标准差与 mask 正确。

优势正常而 loss 不动，查看有效梯度比例、正负侧 clip 与策略版本延迟。大部分 token 已裁停时，减少数据复用或缩短延迟；仅正侧裁停时，再评估 Clip-Higher。比率正常而梯度尖峰，检查长度分母、设备归约和少数异常奖励。

训练 reward 上升、固定验证不升时，先攻击 verifier 与采样分布。保义变换能找到格式漏洞，难度分桶能找到动态采样偏移，隐藏测试能找到规则覆盖不足。此时继续加强正优势只会加速投机。

固定验证上升、通用能力下降时，检查 KL、数据覆盖和回答长度。去 KL 可能让策略远离参考分布，动态采样可能过度集中在中等难度数学题，token loss 可能推动长链扩张。每一种退化都有对应观测，不必用“RL 不稳定”概括。

最后才比较算法名称。若故障定位在组基线方差，可增加组大小、换 LOO 或 critic；定位在长程信用，可上 PPO 的状态价值；定位在有效样本稀少，可改采样课程；定位在 token ratio 离群，再考虑序列级聚合。这样得到的选择能被后续实验推翻，也能在任务变化后重新评估。

### 18.13 三种容易误判的训练曲线

第一种曲线是训练 reward 快速上升，同时平均回答变短、隐藏测试下降。它可能被解释成模型学会了简洁推理，实际原因也可能是长度惩罚压掉验证步骤，或者 verifier 只检查最终格式。把同一回答在公开与隐藏验证器上重评，再按长度分桶，才能判断缩短发生在冗余部分还是必要计算。

若短回答在公开集上提升、隐藏集上退化，而且错误集中于缺少中间校验，长度塑形过强的证据较充分。若两套验证都提升，截断率也下降，缩短更可能是真实效率改进。只展示平均长度与公开 reward 会把两种相反结果画成同一条好看曲线。

第二种曲线是 KL 很低、clip fraction 很高。低 KL 容易让人以为策略变化温和，高 clip 却说明许多已采样动作的局部比率越界。平均 KL 被大量普通 token 稀释，少数答案关键位置仍发生强更新。按位置功能和优势符号统计最大 log-ratio，才能看到局部变化。

第三种曲线是零方差率下降、有效 batch 增加，固定验证却不升。动态采样可能确实找到更多混合组，但这些组集中在 verifier 边界或含噪题目。有效梯度数量增加，不代表梯度方向正确。抽样复核新进入 batch 的 prompt，比较其奖励重测一致性和隐藏正确率，能判断新增信号质量。

还有一种相反情况：训练 reward 停滞，固定验证继续上升。动态课程不断换入更难题会压低训练均值，模型却在固定分布变强。此时按 prompt 身份追踪成功率，或者使用固定锚点集，能避免过早停止训练。在线采样的 reward 曲线没有固定难度基准，本身不适合单独做早停指标。

### 18.14 PPO critic 是否真的提供了更细信用

给模型加 value head，并不保证它学到 token 级贡献。若 critic 的训练标签仍是把终局奖励复制到所有位置，且没有 bootstrap 或状态变化信息，它可能只按回答前缀预测最终成败。前缀越靠后，泄漏的答案信息越多，value loss 会下降，却未必帮助早期决策。

可准备一组成对前缀：两条轨迹在某状态前完全相同，随后采取不同动作并产生不同结果。critic 在分叉前的预测应接近两种后续策略的条件均值，在分叉后才拉开。若它在分叉前已经根据 padding、长度预算或数据顺序预测出结果，存在标签泄漏；若分叉后长时间不分离，状态表示或训练目标不够敏感。

另一个检查是将后续结果随机置换。真正使用状态动作关系的 critic 在置换标签上无法保持原校准；若 loss 变化很小，它可能只拟合 prompt 难度。按 prompt 采样多条不同后续，并在同一前缀处比较 value，能把任务难度预测与动作信用区分开。

PPO 还可能出现 actor 与 critic 更新速度错配。critic 太慢，优势长期使用旧估值，接近高方差 Monte Carlo；critic 太快，会过拟合当前 batch 的回报，把优势压向零。记录 explained variance 不够，还要在留出的新 rollout 上测校准，并比较更新前后优势符号翻转比例。

设 actor 每轮变化较大，critic 用十轮旧数据训练。旧状态分布上的 value loss 继续下降，当前策略却访问了新状态。表面 critic 指标良好，在线优势已经失真。按策略版本切分 critic 验证集，可以看到这种时间错位。

若 PPO 相对 GRPO 的收益只来自更大网络或更多优化步，应在等总参数、等 FLOPs 对照中剥离。可以给 GRPO 配同规模但不参与推理的辅助网络，或把 PPO critic 成本折算成额外 rollout。公平问题不只关乎论文排名，它直接决定生产选型：省下的显存是否会被更多组采样吃回去。

### 18.15 组大小不是越大越好

增大 $G$ 能降低组均值方差和零方差概率，也会增加生成成本、降低 prompt 覆盖。固定总 rollout 数 $N$ 时，prompt 数量为 $N/G$。更大的组让每个提示比较得更准，却让训练看到的任务更少。

假设任务间梯度方差为 $\sigma_x^2$，同任务回答间方差为 $\sigma_y^2$。忽略复杂相关后，batch 梯度方差同时受 prompt 数和每 prompt 样本数控制。若 $sigma_x^2$ 很大，应该覆盖更多 prompt；若 $sigma_y^2$ 很大，增加组大小更有价值。只按零方差率选 $G$ 会漏掉任务多样性。

可以在固定 $N=64$ 下比较 $(64,1)$、$(32,2)$、$(16,4)$、$(8,8)$ 四种“prompt 数 × 每组回答数”。$G=1$ 无法做组内基线，但可配 batch 基线或 critic 作为参照。报告梯度方差、独立 prompt 覆盖、有效混合组数和最终泛化。

二值奖励下，还能按估计成功率自适应分配组大小。$p$ 接近零或一时需要更大组才容易见到差异，$p$ 接近一半时小组足够。不过把大量预算投向极端难题未必划算，可以同时设最大组大小与难度课程门槛。自适应策略应使用历史或独立探测得到的 $p$，不能先看当前组奖励再决定追加多少而不记录选择概率，否则采样分布被结果依赖地改变。

序贯采样是一种折中：先生成少量回答，若已经出现正负奖励就停止；全同时继续追加到上限。它节省中等难度题的预算，却使组大小与奖励相关。优势计算若仍按普通固定组公式，梯度估计包含停止规则偏差。可将它视为有意的课程采样，并通过固定组对照衡量实际收益，而非宣称保持原目标无偏。

### 18.16 从小张量到真实训练的验收顺序

第一层是解析张量。手工给定奖励、长度、mask、旧新 log-prob，逐项核对优势、ratio、clip 分支、KL 与归约分母。正优势和负优势各要覆盖比率低于、位于和高于裁剪区间三种情况。零长度 padding、全同奖励和只有一个有效回答也要有预期输出。

第二层是微型策略。用两三个动作的 softmax 模型和可枚举奖励，计算真实期望梯度，与蒙特卡洛估计比较。这里能测自包含基线缩放、LOO 无偏性、标准差随机分母以及动态过滤的条件分布。复杂语言模型上的 loss 曲线无法替代这一层，因为没有解析真值。

第三层是冻结 rollout。所有候选算法读取同一批 prompt、回答、奖励和行为 log-prob，只改变目标函数。比较一次更新后的参数差、目标 token 概率、KL 与梯度范数。它隔离优化公式，不让采样随机性混入。

第四层打开在线采样，但固定 prompt 序列和 verifier 版本。此时比较策略改变怎样反馈到回答分布，重点看零方差率、长度和奖励投机。随机种子至少覆盖能估计方差的数量，单次最好结果不能用于稳定性结论。

第五层才接入动态采样、异步生成和分布式训练。每加一层，都保留上一层的探针测试。若大规模训练异常，先在冻结 batch 重放相同张量；冻结重放正常，问题在数据或通信；重放也异常，问题在目标实现或数值精度。

混合精度需要单独检查。log-prob 差值很小时，低精度减法会损失有效位；指数化后 ratio 可能被量化成一。极端差值又会让指数溢出。通常在较高精度计算 log-ratio，并在合理范围内截断后指数化。测试输入要包含 $\log\rho$ 接近零与绝对值很大的两端。

mask 错误同样常见。padding token 若进入序列平均，会让短回答分母被统一长度稀释；EOS 是否计入 loss 也会改变停止行为。每条回答的有效 token 数应与 tokenizer 解码和 attention mask 逐项比对，再用全一代理项验证归约结果等于预期常数。

### 18.17 总成本的统一口径

算法成本至少包括生成、验证、前向、反向、通信与失败重跑。GRPO 没有 critic 前向和反向，却需要同提示多采样；PPO 增加 value 计算，但可能用较少 rollout 获得可用优势。DAPO 动态补采提高有效 batch，也增加被丢弃回答的生成与验证。

设每个 prompt 生成 $G$ 条、平均长度 $T$，生成单位成本为 $c_g$，验证单位成本为 $c_v$，一次 actor 更新成本为 $c_a$，critic 更新成本为 $c_c$。粗略成本可写为

$$
C_{\mathrm{GRPO}}=GT(c_g+c_v)+c_a,
$$

$$
C_{\mathrm{PPO}}=G'T(c_g+c_v)+c_a+c_c.
$$

这个式子很粗，却能阻止“少一个 critic 必然更便宜”的跳跃。若 GRPO 的 $G$ 远大于 PPO 的 $G'$，生成侧可能占据全部节省；若 verifier 是昂贵编译或人工判定，补采成本更突出。

动态采样设组被保留概率为 $q$。为了凑齐 $B$ 个有效组，期望要生成约 $B/q$ 组，采样成本放大 $1/q$。极难任务上 $q$ 很低，动态过滤能让优化器每步都有信号，也可能把生成队列拖垮。应同时汇报“每优化步有效 token”和“每百万生成 token 的验证提升”，两者分别衡量训练端利用率与端到端效率。

通信成本也随目标改变。token-level 全局分母需要同步有效 token 数；全局优势标准化需要同步和、平方和与计数；序列级统计可能减少部分逐 token 聚合，却仍需保留行为 log-prob。单机小实验看不出这些差异，大规模时通信等待可能抵消公式上的简化。

失败重跑是容易遗漏的一项。某目标峰值吞吐高，却每隔几百步因 ratio 尖峰崩溃，恢复 checkpoint、丢弃 rollout 和重新预热都会增加实际成本。可用“达到固定验证分数所消耗的总 GPU 时”作为综合指标，并报告多随机种子的失败率。只计算成功 run 的耗时会产生幸存者偏差。

显存预算决定并行布局。critic 可能迫使 actor 减小 batch 或降低上下文长度，GRPO 则可能把节省的显存换成更大的组。比较时记录实际 microbatch、梯度累积、最大生成长度和并行策略。名义上相同的模型与 token 预算，在不同布局下硬件利用率可能差很多。

验证器吞吐低于生成器时，增加 $G$ 只会扩大待验证队列。可以先用便宜规则筛选，再对边界样本运行昂贵 verifier，但筛选本身改变奖励可见分布。成本优化必须与统计目标一同记录，免得系统捷径被包装成算法收益。

最终选型可用两条前沿衡量：固定总成本下的最高可靠成功率，以及达到目标成功率的最低总成本。某方法在无限预算下峰值更高，另一方法在中等预算更快，二者服务的场景不同。把成本拆开后，团队才能知道下一笔预算该投给更多 rollout、更强 verifier，还是状态价值模型。

成本曲线还应带置信区间。训练方差较大的方法可能偶尔很快达到目标，也可能多次失败；只比较平均值会掩盖资源排期风险。可同时报告中位达到时间、九成分位达到时间和未达到目标的运行比例。线上项目更关心可预测交付时，九成分位往往比单次峰值更有决策价值。

若训练目标尚在探索阶段，可先用小模型测各组件的相对趋势，再在目标规模复核关键结论。缩放会改变生成占比、通信瓶颈和 critic 容量，绝对成本不能直接外推；零方差率、裁剪方向与归约权重这类机制现象则应在不同规模保持一致。机制不复现时，应先解释差异，再决定是否继续投入大规模运行。

## 19. 选型结论

短程、终局可验证、同一提示容易采到正负混合回答时，GRPO 的组内基线用额外 rollout 换掉 critic，结构简洁。组方差频繁为零时，先处理任务难度和采样；奖励微小差异不可信时，谨慎使用标准差归一；正确轨迹更长时，检查归约分母与截断规则。

PPO 的价值在于状态级优势。任务进入长程交互、早期动作与最终成败相隔很远，critic 虽然昂贵，却能表达“哪个状态变好”。REINFORCE++ 适合希望保留无 critic 路线、又需要重要性采样、裁剪和 KL 稳定器的场景。DAPO 提供的是四个可拆开的修正，应按观察到的故障逐项启用。

真正需要归档的是目标函数及其张量口径：基线是否包含自身，优势在哪个维度归一，ratio 属于 token 还是序列，clip 对正负优势怎样生效，KL 用哪种估计，loss 除以回答数还是 token 数，全同组怎样处理。写清这些细节，同名实现才有可比性，训练异常也能落回具体环节。
