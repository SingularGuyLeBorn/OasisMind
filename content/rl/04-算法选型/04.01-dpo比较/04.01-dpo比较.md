# DPO Family: 偏好优化算法大比拼

DPO 家族五个方法共享三个条件: 用模型的 token log probability 构造偏好信号, 在固定数据上离线训练, 不需要在线 rollout. 差别集中在信号形式 (成对比较或二元反馈), 归一化基准 (有无参考模型, 用概率比还是优势比) 和目标形状 (sigmoid 饱和, 有限目标或显式 margin). 方法选择可以据此拆成条件判断, 具体推导、手算与实现约定见 1.2.2 节到 1.2.6 节.

选型前先立一个参照判断: 五个方法之间的差距, 远小于「做不做偏好对齐」之间的差距, 也远小于偏好数据质量好与差之间的差距, 这个判断在 ORPO 一篇的时间线讨论中已经给出 (1.2.4 节). 因此下面的决策树只做方法内部的细分, 不回答「要不要做对齐」. 数据管线的优先级永远高于损失函数的优先级, 损失选型留在数据管好之后.

## 1. 三个入口条件: 数据形态, 参考模型, 起点模型

五个候选方法先被三个可观察的条件过滤, 再谈损失性格. 这三个条件都不是超参层面的事: 数据形态由标注管线决定, 参考模型约束由硬件与工程预算决定, 起点模型由上游流程决定.

三个条件的检查顺序也有讲究: 先数据形态, 再起点模型, 最后参考模型. 前两个条件否定的候选直接出局, 没有回旋空间; 参考模型条件只改变维护成本, 不构成硬约束. 按这个顺序过滤, 多数项目在第一关之后只剩两到三个候选, 后面决策树的工作量被压到最小.

### 1.1 数据形态: 成对还是二元

第一个问题是标注产物的形态. 成对偏好数据每条样本是 $(x, y_w, y_l)$, 同一 prompt 下标注者比较两条回答; 二元反馈每条样本是 $(x, y, k)$, $k\in\{+1,-1\}$ 只说明这条回答好不好 (1.2.6 节). DPO, IPO, ORPO, SimPO 四个方法全部消费成对数据, 因为它们的损失都要对 chosen 与 rejected 的分数做差; KTO 是家族中唯一接受二元数据的方法, 它的损失按单条样本相对 KL 参考点的位置给梯度 (1.2.6 节).

这个条件可以直接从数据源判断. 点赞, 点踩, 审核通过或拒绝, 代码采纳记录属于二元反馈, KTO 可以直接使用. 如果管线本来就生产成对标注 (两个候选并排展示, 标注者二选一), 把对子拆成两条二元样本交给 KTO 会丢失对子内的比较关系, 只换来数据量翻倍与逐条过滤的灵活性 (1.2.6 节).

### 1.2 参考模型: 显存约束还是工程复杂度

第二个条件是训练配置里愿不愿意养一个冻结的参考模型. DPO, IPO, KTO 的损失都含 $\log\pi_\theta-\log\pi_{\mathrm{ref}}$ 结构的相对量, 必须加载参考模型 (1.2.2 节, 1.2.6 节); ORPO 与 SimPO 不需要, 这是它们最大的工程优势.

参考模型的真实成本要按口径拆开, 不能引用「显存减半」这类宣传数字. 按 ORPO 一篇的显存分解 (1.2.4 节), 训练常驻显存里约 $16N$ 字节属于参数, 梯度与 AdamW 优化器状态, 参考模型只占其中约 $2N$, 占比约一成; 如果参考 log-prob 是预计算缓存的, 参考模型甚至可以不进显存. 所以「只有一张卡」本身不构成选 ORPO 或 SimPO 的理由, 真正的可观察条件是: 参考模型对应的那组代码路径与分布式切分配置, 在你的管线里是否构成维护成本, 以及你是否有迭代式训练计划. 迭代训练里参考角色每轮都要更换, SimPO 省去这一步的管线收益是实质性的 (1.2.5 节).

### 1.3 起点模型: Base 还是 SFT checkpoint

第三个条件是偏好训练从哪里出发. DPO, IPO, SimPO, KTO 都是纯偏好损失, 不含模仿项, 要求先有 SFT checkpoint: 格式没学会之前, 偏好信号里混着大量格式噪声. KTO 对此的约束比 SimPO 更硬, 因为 KTO 的隐式 reward 是相对参考策略的偏离, 参考点估计会被格式噪声直接污染 (1.2.6 节).

ORPO 是唯一能从预训练 checkpoint 单阶段出发的方法: 它的损失是 $\mathcal{L}_{\mathrm{SFT}}+\lambda\mathcal{L}_{\mathrm{OR}}$, SFT 项直接模仿 chosen, 偏好项同时拉开 odds ratio (1.2.4 节). 可观察条件是上游产物: 手里只有预训练或 mid-training checkpoint, 想省掉单独的 SFT 阶段, 且偏好数据里的 chosen 质量足够高 (chosen 是模型唯一的模仿对象), ORPO 才进入候选. 已有可靠 SFT checkpoint 时, 单阶段优势消失, 选型退化为其余四个方法之间的比较.

## 2. 决策树与条件对照

三个入口条件过完, 剩下的候选一般不超过两个, 决策树只需处理最后一层: 损失性格与超参成本. 这一层的问题都是二选一, 每个分叉给出可观察的判据.

决策树给出的是带判据的默认选项, 并不排除其它可行方案. 每一层分叉都对应可观察条件与可复算依据, 因而「换方法」可以回溯到具体监控读数. 条件表把这些判断压缩成速查项, 依据列标出各选择成立的原因与出处.

### 2.1 决策树

按顺序回答四个问题:

1. 数据是二元反馈吗? 是 → KTO, 结束 (1.2.6 节). 否 → 2.
2. 手里只有预训练 checkpoint 且 chosen 质量高吗? 是 → ORPO, 结束 (1.2.4 节). 否 → 3.
3. 成对数据噪声大, 或训练后期已经观察到 policy-reference divergence 失控吗? 是 → IPO (1.2.3 节). 否 → 4.
4. 参考模型的维护成本在迭代计划里显著, 或以 best-of-n 选择精度为主要评测目标吗? 是 → SimPO (1.2.5 节). 否 → DPO 作为默认基线 (1.2.2 节).

这个顺序不是随意的. 前两问处理的是结构性约束 (信号形式, 起点模型), 答错没有补救; 后两问处理的是偏好层面的选择 (稳定性优先还是简洁优先), 答错的影响限于超参调优成本. 四问全部落到可观察条件上: 数据源形态, 上游 checkpoint 类型, 噪声与 divergence 的监控读数, 迭代计划是否存在.

四问之外还有两类常见输入不进入决策树. 一类是评测指标的偏好 (刷榜或生产), 它影响的是 checkpoint 选择与评测组合, 不造成方法排除; ORPO 一篇建议任何偏好方法同时报 AlpacaEval 2 与 IFEval 两组数字, 单一胜率不足以支撑选型 (1.2.4 节). 另一类是团队熟悉度: 同样的候选里优先选实现链路最熟的那个, 调试成本常常大于方法之间的差距 (1.2.5 节).

### 2.2 条件-方法对照表

| 可观察条件 | 方法 | 关键依据 |
| :--- | :--- | :--- |
| 二元反馈流 (点赞/审核/采纳) | KTO | 家族中唯一不消费成对数据的损失 (1.2.6 节) |
| 仅预训练 checkpoint + 高质量 chosen | ORPO | 损失内置 SFT 项, 单阶段 (1.2.4 节) |
| 噪声大 / divergence 失控 | IPO | 有限目标 gap $m=1/(2\beta)$, 超过目标反向拉回 (1.2.3 节) |
| 迭代训练 / 显式 margin 需求 | SimPO | 无参考模型, logit 平移 $\gamma$ (1.2.5 节) |
| 其余全部场景 | DPO | 推导最完整, 基线地位 (1.2.2 节) |

对照表应自上而下逐行匹配, 不用于打分. 命中第一行就不需要看后面的行; 没有任何一行命中时落在 DPO, 原因是剩余场景里它的理论对应最完整, 调试时最少意外, 并不意味着 DPO 在每个维度都最好. 「其余全部场景」这一行兜底的是最常见的组合: 成对数据, 可靠 SFT checkpoint, 参考模型成本不敏感, 无特殊评测约束.

依据列记录每项选择的验证成本: 方法条目指向对应章节的推导与手算, 方便复核条件是否成立. 这张表筛选的是特定条件下可行的方法及其证据, 不提供脱离场景的总排名.

### 2.3 选错代价最大的三个位置

有三个分叉点, 选错的代价不对称地大, 值得单独标出. 第一, 数据源是二元反馈流却按成对方法设计标注管线. 代价是标注预算的整体重做: 把流式判断改造成对比较界面, 标注速度变慢, 一致性变差, 而 KTO 已经证明二元信号经过参考点饱和结构设计后, 能达到成对偏好的大部分效果 (1.2.6 节). 判据很简单: 反馈流接进来之前, 先确认它不是对子的伪装形态.

第二, 用 SimPO 从预训练模型直接起训. SimPO 不含模仿项, 是纯偏好损失, 预训练模型没见过对话模板时输出格式会退化; ORPO 一篇列出的格式退化失败模式在 SimPO 下同样存在, 且没有任何损失内的机制兜住 (1.2.4 节, 1.2.5 节). 判据: 起点模型是否通过固定 prompt 集上的模板稳定性检查, 没通过就不能跳过 SFT 阶段.

第三, 在 KTO 下直接沿用默认类别权重处理高度不平衡的二元数据. 配比约束 $\lambda_D n_D/(\lambda_U n_U)\in[1,3/2]$ 被违反时, 少数类梯度主导训练, 单条坏样本的标注噪声被同步放大: 类别比 9:1 时按约束反解需要 $\lambda_U\approx 6\lambda_D$ (1.2.6 节的配比手算). 判据: 数据侧的类别比与权重反解, 在配置训练之前完成, 且调完权重后回看梯度推导确认两类梯度尺度比与预期一致.

## 3. 相邻方法的边际差别

选型的最后一层是损失形状. 五个方法各自改变一个主要公式项, 每对相邻方法都可以在同一对偏好样本上做定量对照, 同时保持数据形态与 reference 条件不变.

对照的排法按差异来源分组: 3.1 与 3.2 处理共享参考模型与否的两对 (DPO-IPO 共用一个参考模型, ORPO-SimPO 都不要), 3.3 处理信号形式的分界, 3.4 处理同名超参的口径差异, 3.5 处理有限目标的两种实现. 每组对照给出一组可复算的数字, 数字全部来自姊妹篇已有的手算或按公式直接推导.

### 3.1 DPO 与 IPO: 同一 margin 下的梯度对照

把网络暂时压缩成单个标量 gap $h$ (policy 与 reference 的序列 log-ratio 差), 两种损失写作 $L_{\mathrm{DPO}}(h)=-\log\sigma(\beta h)$ 与 $L_{\mathrm{IPO}}(h)=(h-1/(2\beta))^2$ (1.2.3 节). 取 $\beta=0.5$, IPO 目标 $m=1$, 同一组 $h$ 位置上:

| $h$ | $L_{\mathrm{DPO}}$ | $\partial L_{\mathrm{DPO}}/\partial h$ | $L_{\mathrm{IPO}}$ | $\partial L_{\mathrm{IPO}}/\partial h$ |
| ---: | ---: | ---: | ---: | ---: |
| $-1$ | $0.974$ | $-0.311$ | $4$ | $-4$ |
| $0$ | $0.693$ | $-0.250$ | $1$ | $-2$ |
| $1$ | $0.474$ | $-0.189$ | $0$ | $0$ |
| $2$ | $0.313$ | $-0.134$ | $1$ | $2$ |

DPO 的导数在所有有限 $h$ 处都为负: 排序正确的 pair 只要还没把 margin 推到无穷, 损失就在持续下降, 这就是 DPO 训练久了 KL 散度激增, 生成分布退化的动力来源 (1.2.2 节, 1.2.3 节). **IPO 在 $h=m$ 处导数为零, 超过后导数变正, 梯度下降把 gap 往回拉**, 相当于给优化装了一个有限停止点, 这是「数据噪声大选 IPO」这条决策依据的机制面.

注意这张表的读法边界. 它揭示的是单 pair 的监督几何, 不能直接用来断言 IPO 的网络更新一定比 DPO 大或小: 真实梯度还要乘 $\nabla_\theta h$, learning rate 与 batch reduction 也不同 (1.2.3 节的告诫). 更不能据此认为 IPO 自动更稳: 平方损失对异常残差没有界, $h=-20$, 目标为 $1$ 时单样本导数为 $-42$, 同位置 DPO 的标量导数幅度最多接近 $\beta=0.5$. 选 IPO 的真正判据是数据噪声水平与残差尾部是否可控, 不是稳定性直觉.

### 3.2 ORPO 与 SimPO: 同一分数对的 logit 对照

ORPO 与 SimPO 都不需要参考模型, 差别集中在分数变换: ORPO 用优势比, $\log\mathrm{odds}(y)=\log P(y)-\log(1-P(y))$; SimPO 用裸的长度归一化平均分数 (1.2.4 节, 1.2.5 节). 取同一对偏好样本, 模型给出的几何平均分数 $s_w=-0.5$, $s_l=-2.0$: SimPO 的 logit (平移 $\gamma$ 之前) 正比于 $s_w-s_l=1.5$; ORPO 的 log-odds 差逐项算, $\log\mathrm{odds}(-0.5)=-0.5-\log(1-e^{-0.5})\approx-0.5+0.934=0.434$, $\log\mathrm{odds}(-2.0)=-2.0-\log(1-e^{-2})\approx-2.0+0.145=-1.855$, 所以 $\Delta\approx2.289$ (1.2.5 节的同一算例).

同一对样本, ORPO 的 logit 比 SimPO 大 $0.79$, 因为 odds 变换的导数 $d\log\mathrm{odds}/ds=1/(1-e^s)$ 恒大于 $1$ 且随 $s\to0$ 发散: 在 $s=-0.5$ 处因子约 $1/(1-0.607)\approx2.54$, 在 $s=-2.0$ 处约 $1/(1-0.135)\approx1.16$, 而 SimPO 对单位分数差的响应恒为 $1$ (1.2.4 节). 两个方法对低分端对子的解读不同: ORPO 认为被 rejected 明显更差的回答要被更强地推开, SimPO 对所有分数差一视同仁. 这个分歧没有先验答案, 实践上表现为两种方法的胜负随偏好数据的噪声结构翻转.

工程侧的对照同样具体. ORPO 要处理 $\log(1-e^s)$ 在 $s$ 接近 $0$ 时的灾难性消减, 官方实现用分段 `log1mexp` 稳定化, 且 $s$ 至少要按 float32 计算 (1.2.4 节); SimPO 的表达式里没有这一项, 半精度下直接算平均 log 概率即可, 复现代码量大约是 ORPO 的一半 (1.2.5 节). ORPO 还多一个 SFT 项和权重 $\lambda$, 官方实现与其他复现普遍报告 $\lambda$ 敏感 (1.2.4 节), 这构成 SimPO 在超参维度上的一笔真实优势.

### 3.3 DPO 与 KTO: 信号形式与梯度权重形状

DPO 与 KTO 共享隐式 reward 定义 $r_\theta(x,y)=\log[\pi_\theta(y|x)/\pi_{\mathrm{ref}}(y|x)]$ 与参考模型, 差别在信号形式: DPO 用对子内的相对比较, KTO 用单样本相对 KL 参考点 $z_0$ 的绝对判断, $z_0$ 在实现里带 stopgrad (1.2.6 节). 梯度权重形状因此完全不同: DPO 的权重 $\sigma(-z)$ 随 logit 单调下降, 排序越正确的 pair 权重越接近零; KTO 的权重 $\beta\sigma(\beta\delta)(1-\sigma(\beta\delta))$ 是以参考点为中心的钟形, $\delta=0$ 处取峰值 $\beta/4$, 两端同时衰减 (1.2.6 节).

用数字把形状差异压实. KTO 取 $\beta=0.5$, $z_0=1.0$, 三条 desirable 样本的 $r_\theta$ 分别为 $0.2,1.0,3.0$, 梯度因子依次约为 $0.120,0.125,0.098$, 最大与最小只差 $30\%$ (1.2.6 节的手算). 同一尺度的对照下, DPO 的权重从 logit $0$ 处的 $0.5$ 降到 logit $4$ 处的 $0.018$, 相差约 $28$ 倍. KTO 把训练预算分给「离参考点最近」的样本, DPO 分给「排序错误」的样本, 两种分配对数据的利用策略不同, 对噪声数据的耐受也不同.

选择判据回到数据. 有现成对子时 DPO 的信号更强, 比较判断比绝对判断信息量大, KTO 一篇给出的用法是: 只有二元信号, 或对子构造成本不可接受时, KTO 才是默认选项 (1.2.6 节). 反过来, 对子可以拆解成二元样本喂 KTO, 换来数据量翻倍, 但要接受比较信息的损失, 且同一 prompt 的两条样本必须按 group 打散, 否则等于给该 prompt 双倍权重 (1.2.6 节). 不少「KTO 不如 DPO」的复现结论, 追溯到最后都是这个打散没做.

### 3.4 DPO 与 SimPO: β 量级与梯度响应

DPO 与 SimPO 的损失同形, 都是 $-\log\sigma$ 套一个分数差, 但 $\beta$ 的量级差一到两个数量级: DPO 常用 $\beta\approx0.1$, SimPO 用 $\beta=10$ 搭配 $\gamma=0.5$ (1.2.5 节). 这不是笔误, 是归一化口径的结构差异: DPO 的 logit 是 $\beta$ 乘两个序列总分的差, 总分随长度累积, $\beta$ 负责压住长度; SimPO 的 logit 基于平均每 token 分数, $\beta$ 的任务变成给零点几的平均分数差赋予区分度.

量级差异直接改变训练手感. 同一对子, 模型把 chosen 的平均分数推高 $0.1$: DPO 的 logit 相应只移动约 $\beta\times0.1\approx0.01$ 量级 (总分口径下的同比例移动), 权重几乎不动; SimPO 的 logit 移动 $1.0$, 权重从 $0.5$ 降到约 $0.18$, 响应快一个数量级 (1.2.5 节末尾的对照). SimPO 对「已经推过的对子」更快放手, 对「还没推的」更用力, 曲线形态比 DPO 更陡.

由此得到一个可执行的调参约束: $\beta$ 与 $\gamma$ 不独立. $\beta$ 只缩放 $\Delta r$ 不缩放 $\gamma$, 把 $\beta$ 翻倍等价于把有效 margin 减半, 调参时应固定比值 $\gamma/\beta$ 扫尺度, 复现论文配置先在 $\gamma/\beta\in\{0.05,0.1,0.2\}$ 附近扫 (1.2.5 节). 反过来, 把 DPO 的 $\beta=0.1$ 直接搬进 SimPO, 所有 logit 挤在 $\pm0.3$ 以内, $\gamma$ 几乎不起作用, 训练退化成接近不加权的排序回归 (1.2.5 节). 同名超参背后的尺度口径, 是跨方法复现时最容易踩的错位.

### 3.5 IPO 与 SimPO: 有限目标的两种实现

IPO 与 SimPO 都给偏好 gap 设了有限目标, 实现方式不同. IPO 的目标藏在损失形状里: $(h-m)^2$ 在 $h=m$ 两侧对称, 超过目标的 gap 会被导数为正的部分拉回, 拉回强度随残差线性增长 (1.2.3 节). SimPO 的目标藏在 logit 平移里: $-\log\sigma(\Delta r-\gamma)$ 在 $\Delta r=\gamma$ 处梯度权重恰好是 $0.5$, 超过后权重平滑衰减, 但不衰减到零, 也不回拉. 同一个「别停在排序正确」的意图, 一个用回归的拉回实现, 一个用饱和曲线的右移实现.

这个差别在训练手感上表现为: IPO 对超过目标的样本施加反向梯度, 多 epoch 复用已见 pair 时, margin 被主动压回目标附近; SimPO 只是让已排序样本的权重变小, 长尾梯度仍在, 已排序对子内部的间隔分布还有机会被继续微调 (1.2.5 节). 选型判据: 数据噪声大, 担心模型把已见 pair 的 margin 推过头, 选 IPO 的硬拉回; 数据干净, 希望训练后期仍利用已排序对子做精修, 选 SimPO 的软衰减. 两组的共同约束是目标尺度 ($m$ 或 $\gamma$) 不能超过模型实际能拉开的间隔, 否则大量样本永远停在强梯度区, 训练不收敛 (1.2.3 节, 1.2.5 节).

## 4. 超参与实现约定对照

选定方法之后, 落地前还要对齐三个口径: $\beta$ 与 $\gamma$ 的尺度, 数值稳定的实现约定, 训练监控指标. 每个方法的默认约定不同, 混用会产生表面同名, 尺度不同的结果 (1.2.3 节的告诫).

这三个口径的对齐是一次性工作, 应该在第一次训练之前完成并记录: 求和还是平均, 参考缓存绑定的版本指纹, 每条指标的数据来源与归约方式. 口径没对齐之前跑出来的跨方法对比数字, 后面要花几倍的时间排查是不是尺度错位造成的假象, 排查成本远高于事前核对.

### 4.1 β 与 γ 的口径对照

DPO 的 $\beta$ 源自 KL 正则目标, 表示偏离参考策略的代价, 常用量级 $0.1$; 改 $\beta$ 同时改变 logit 尺度与单步梯度, 但训练后的 policy 随之改变, 不能只凭单步梯度断言较大 $\beta$ 一定产生更强偏离 (1.2.2 节). IPO 的目标 $m=1/(2\beta)$, $\beta=0.1,0.5,1$ 分别对应 $m=5,1,0.5$, 序列口径下 $h=5$ 约等于 chosen/rejected 概率比相对参考的 $148.4$ 倍 (1.2.3 节); 同名 $\beta$ 从 DPO 搬来, 目标 gap 差出几十倍, 所以 DPO 的最佳 $\beta$ 不能凭参数名直接复用.

SimPO 的 $\beta=10$ 配 $\gamma$ 按模型调节, $\gamma$ 的上界是模型实际能拉开的间隔, 超过后大量样本永远停在强梯度区不收敛 (1.2.5 节). KTO 的 $\beta$ 决定钟形权重带的宽度, 半峰值带宽约 $4.4/\beta$: $\beta=0.5$ 时带宽约 $8.8$, 几乎覆盖 reward 分布的常见宽度, 这解释了 KTO 手算里权重差异小的现象; $\beta$ 翻倍带宽减半, 训练对参考点位置更敏感 (1.2.6 节). 调 $\beta$ 时可以用 $4.4/\beta\gtrsim w$ 缩小搜索范围, $w$ 是 pilot run 里测得的 reward 分布半宽, 下界通常取上界的 $1/4$ 到 $1/2$ 起步扫 (1.2.6 节).

### 4.2 数值稳定与实现约定

ORPO 的实现要处理 $\log(1-e^s)$ 在 $s\to0$ 时的消减: 分段算法在 $s<-\log 2$ 用 `log1p(-e^s)`, 否则用 $\log(-\texttt{expm1}(s))$, 分界点 $-\log 2\approx-0.693$ 保证两个分支都有足够有效数字; 半精度下 $1-e^s$ 在 $s>-0.01$ 就没有足够有效位数, 所以 $s$ 至少要按 float32 计算 (1.2.4 节). 出现 $s\ge0$ 时 `log1mexp` 返回 NaN, 空回复应在数据清洗阶段剔除, 不留给损失函数处理.

KTO 的实现约定是 stopgrad: 参考点 $\hat z_0$ 参与决定每条样本落在 S 形的哪个位置, 但不接收梯度, 否则「移动参考点本身」会成为一条隐蔽的优化通道, 模型可以让所有样本的 log-ratio 一起上升来抬高 $\hat z_0$, 绕开逐样本监督 (1.2.6 节). 漏掉 stopgrad 不会报错, 只会悄悄训歪, 而日志表面一切正常. $\hat z_0$ 本身由循环移位错配对估计, 带 $\max(0,\cdot)$ 的正偏, 是工程近似不是精确 KL, 解读日志时不应当精确 KL 对待 (1.2.6 节).

SimPO 与 IPO 的实现约定在长度归一化的位置. SimPO 传总 log 概率与长度, 归一化在损失内完成; 分母误用 batch 内最长序列长度是最常见的实现错误, 会把短回复倾向反转成长回复倾向, 症状隐蔽 (1.2.5 节). IPO 在 TRL v0.23.1 的实现里把回答 log-prob 除以有效 token 数, 与论文的序列求和口径不同, $\beta$ 的合理值随之改变, 长度平均口径下 $e^{\bar h}$ 也不能直接当成完整序列概率比的相对变化 (1.2.3 节). 同一方法换框架复现时, 先核对求和还是平均, 再谈超参.

### 4.3 监控指标的选择

每个方法至少要盯的指标不同, 抄同一套监控表会漏掉各自的退化信号. DPO 与 IPO 共享的基础集: 训练与 held-out 的 preference log loss (不只看 accuracy), policy-reference divergence 的估计, 生成回答的盲评胜率与长度分布 (1.2.2 节, 1.2.3 节). DPO 特有的观察点是隐式 reward margin 在多 epoch 下的持续右移: pair accuracy 饱和后继续训练, 只是把已见 margin 推得更大, checkpoint 选择在 accuracy 饱和处附近收 (1.2.2 节).

SimPO 需要额外记录 $\Delta r$ 分布的分位数和固定 prompt 集上的平均生成长度. P50 落在 $\gamma$ 附近通常表示 margin 匹配, P10 长期为负表示模型持续放弃一部分难样本; 平均长度则能发现 loss 下降同时发生的短回复退化 (1.2.5 节). ORPO 应按训练阶段观察 $\Delta$ 分布, 因为同一个 $\lambda$ 在早期与晚期的实际强度不同 (1.2.4 节). KTO 要单独记录 $\hat z_0$: 它不接收梯度但会随训练漂移 (1.2.6 节).

这些指标还要配停止条件, 不以 training loss 最小作为停止线. 更合适的联合条件是: held-out pair loss 不再改善, 固定 prompt 上的独立生成胜率达到平台, policy-reference divergence 仍在可接受范围, 通用能力与安全切片没有明显回退 (1.2.3 节的停止条件). 训练 loss 继续下降而生成胜率下降时, 优先怀疑离线过拟合, 分布漂移或评测口径, 而不是继续训练等待反弹.

### 4.4 数据侧的配套要求

损失选完, 数据侧还有三个配套要求与选型结论绑定. 第一, rejected 的质量: SimPO 与 ORPO 的分数没有参考基线, rejected 如果差得离谱, 拉开它的分数几乎不消耗训练预算, 这类样本在早期失效; 构造数据时应让 rejected 是有竞争力的次优答案, hard negative 的占比直接决定训练后期还有没有用 (1.2.5 节). 第二, 长度分桶: SimPO 的梯度里写着 $\beta/|y|$, 长短对子混合不均时有效 batch 被短对子主导, 缓解办法是按长度桶采样或分桶记录损失曲线 (1.2.5 节); KTO 不做长度归一化, 长回复天然有更大的 $|r_\theta|$, 长度差大的数据要先在数据侧配平 (1.2.6 节).

第三, 训练/验证的切分粒度: 按 pair 随机切分最容易泄漏, 同一 prompt 的候选组产生的多条边同时出现在训练与验证中, 模型只需记住回答特征就能得到很高的验证分; 应按 prompt 或完整 candidate group 切分, 验证集再分固定离线 pair, 固定 prompt 重新生成, 反事实切片三层 (1.2.3 节). 这三个要求不进决策树, 但任何一个没做, 方法差异都可能被数据问题盖掉. 数据管线的优先级仍然高于损失函数.

## 5. 训练失效与串行组合

最后一层是风险管理: 每种方法在各自的高危条件下以可预测的方式失效, 失效症状与报警指标都有出处. 选型时把「谁先失效」作为小规模扫描的验收标准, 比直接复用论文超参稳 (1.2.4 节的建议).

这一层的内容在选型之前读一遍即可, 真正使用时它是一份验收清单: 小规模扫描每个候选方法, 观察各失效模式里谁先出现, 出现的位置就是该方法在你的数据与基座下的真实边界, 也回答了「要不要为它付出对应的超参与监控成本」.

### 5.1 各方法的失效模式与报警指标

DPO 最常见的失效是 KL 激增与生成分布退化, 原因是 sigmoid 损失在有限 margin 处仍可继续下降 (1.2.3 节). 应联合监控 policy-reference divergence 与生成多样性. IPO 则会放大极端残差: 平方损失对异常样本没有界, 错标 pair 或 mask 错误产生的巨大负残差会主导整个 batch (1.2.3 节). 需要检查残差 $h-m$ 的直方图与尾部; 均值接近零不代表方差小. 梯度裁剪与样本检查可以缓解异常, 换成 Huber 类损失后则不再是原始 IPO 目标.

ORPO 列出三种失败模式: 格式退化 (偏好数据覆盖不全对话模板时), 过度自信 (odds 梯度因子在高置信区放大, 生成长度塌缩或多样性骤降), 已排序样本空转 (梯度权重饱和后继续训练只是空转, 按 loss plateau 定 epoch 会严重过度训练) (1.2.4 节). SimPO 的已知批评是短回复倾向, 机制有二: 短回复每个 token 的梯度被 $\beta/|y|$ 放大, 平均分数随长度方差收缩使「变短」成为低阻力优化方向 (1.2.5 节). KTO 的弱点是参考点估计的方差直接进梯度, batch 小时训练曲线比 DPO 毛糙, 缓解是调大 microbatch 或对 $\hat z_0$ 做滑动平均 (1.2.6 节).

### 5.2 KTO 打底, DPO 收尾的串行用法

五个方法不是互斥选项, 实践中可以串行. KTO 一篇给出的组合是: 先用海量的二元信号 (点赞, 采纳) 做 KTO 打底, 再用少量精标对子做 DPO 收尾 (1.2.6 节). 依据是信号强度排序: 比较判断的信息量大于绝对判断, 把信息密度高的数据放在训练后期, 模型先获得广覆盖的粗略偏好, 再学习精排.

工程上两类损失共享 policy 与 reference 的前向管线, 按 step 交替或按样本路由, 把已有 DPO 训练器改造成 KTO 训练器的工作量大约一个工作日, 其中参考点 stopgrad 的核对占一半 (1.2.6 节). 数据侧的衔接点有两个: 从对子拆二元样本时按 prompt group 打散, 避免同 prompt 双倍权重; 第二轮 DPO 的参考模型可以沿用 KTO 阶段的参考, 也可以把 KTO 产出的策略设为新参考, 两者不是同一目标, 更换后所有参考缓存必须重算 (1.2.2 节).

迭代轮数是不取决于损失函数的独立决策. on-policy 数据能缓解离线分布偏移, 但实践里迭代两轮以上收益递减明显, 第二轮的增益通常不到第一轮的一半 (1.2.5 节). 是否迭代取决于采样与标注成本: 采样与标注便宜就多迭代几轮, 贵就停在两轮以内, 这个判断与选哪个方法无关. 另一条新管线路线是把 SimPO 作为首个实验对象: 五个方法里它的实现最短, 数值最稳, 超参最少, 先用它把数据管线与评测管线跑通, 再决定是否有必要为 DPO 的参考约束或 ORPO 的单阶段能力付出复杂度 (1.2.5 节). 从一个已知能 work 的最简基线出发加组件, 比从复杂基线出发删组件, 调试成本低得多.

选型实验还应固定数据预算而非只固定 epoch. 不同方法对单条样本的使用方式不同: DPO、IPO、SimPO 与 ORPO 消费成对样本, KTO 消费单标签样本. 把一个偏好对拆成两个 KTO 样本后, 若仍按相同 epoch 比较, KTO 实际经历的优化样本数会改变. 公平口径可以固定有效回答条数、模型前向 token 或总 GPU 时, 并把另一种口径作为补充. 只有训练预算对齐, 方法之间的收益和成本才可同时比较.

报告中还应给出每种方法达到最佳 checkpoint 前消费的预算. 最终分数相同但收敛速度不同, 对需要频繁更新数据的业务会产生完全不同的迭代成本; 只比最后一步会漏掉这一差异.

串行训练还要处理参考分布的切换. 若 DPO 阶段继续使用最初的 SFT reference, KTO 与 DPO 的 KL 坐标保持一致, 但第二阶段策略可能已经离 reference 较远; 若改用 KTO checkpoint 作为新 reference, DPO 比较的是第二阶段的局部变化, 所有缓存 log-prob 都必须重算. 两种方案没有可互换的 $\beta$ 数值. 对照实验应分别记录起点 KL、训练后 KL 与生成长度, 才能判断收益来自偏好信号还是参考模型重置.

## 6. DPO 怎样从 KL 约束强化学习中出现

### 6.1 带参考策略的最优策略

对提示 $x$，经典 RLHF 目标可写为

$$
\max_{\pi}\;\mathbb E_{y\sim\pi(\cdot\mid x)}[r(x,y)]
-\beta D_{\mathrm{KL}}\!\left(\pi(\cdot\mid x)\|\pi_{\mathrm{ref}}(\cdot\mid x)\right).
$$

第一项推动高奖励回答，第二项限制策略远离参考模型。对每个 $x$，再加概率归一约束 $\sum_y\pi(y\mid x)=1$。拉格朗日函数为

$$
\mathcal L=\sum_y\pi(y\mid x)r(x,y)
-\beta\sum_y\pi(y\mid x)\log\frac{\pi(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}
+\lambda\left(\sum_y\pi(y\mid x)-1\right).
$$

对 $\pi(y\mid x)$ 求导并令其为零：

$$
r(x,y)-\beta\left(\log\frac{\pi(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}+1\right)+\lambda=0.
$$

整理得到

$$
\pi^*(y\mid x)=\frac{1}{Z(x)}\pi_{\mathrm{ref}}(y\mid x)
\exp\left(\frac{r(x,y)}{\beta}\right),
$$

其中 $Z(x)$ 吸收归一化常数。反解奖励：

$$
r(x,y)=\beta\log\frac{\pi^*(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}
+\beta\log Z(x).
$$

对同一提示的两个回答做差时，$\beta\log Z(x)$ 消失。DPO 的关键就在这里：偏好模型只需要奖励差，归一化常数无需显式求解，策略与参考策略的对数概率比可以直接充当隐式奖励。

### 6.2 从 Bradley–Terry 到 DPO 损失

Bradley–Terry 假设偏好概率由奖励差的 logistic 函数决定：

$$
P(y_w\succ y_l\mid x)=
\sigma\left(r(x,y_w)-r(x,y_l)\right).
$$

把上节反解的奖励代入，得到

$$
P(y_w\succ y_l\mid x)=\sigma\left(\beta\left[
\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\mathrm{ref}}(y_w\mid x)}
-\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\mathrm{ref}}(y_l\mid x)}
\right]\right).
$$

记策略相对参考的偏好 margin 为

$$
h_\theta=\log\pi_\theta(y_w\mid x)-\log\pi_\theta(y_l\mid x)
-\log\pi_{\mathrm{ref}}(y_w\mid x)+\log\pi_{\mathrm{ref}}(y_l\mid x),
$$

对偏好标签做最大似然便得到

$$
L_{\mathrm{DPO}}=-\log\sigma(\beta h_\theta).
$$

这条推导包含几项强假设：偏好可由单一标量效用表示；不同 pair 的判断噪声服从相同 logistic 尺度；数据对在给定提示后可以按该模型解释；训练策略的最优形式仍围绕固定 reference。现实标注者可能偏好不可传递，安全性与帮助性也未必能压成同一个标量。

### 6.3 β 到底控制什么

在 RL 目标里，$\beta$ 是 KL 惩罚系数，越大越不愿偏离 reference。进入 DPO logistic 后，$\beta$ 又缩放 margin。固定当前 $h$ 时，更大的 $\beta$ 让 sigmoid 更快饱和；固定数据与充分优化后的隐式奖励关系时，它仍对应更强的参考约束。只看单步梯度容易得出相反直觉，必须区分局部优化尺度与最终策略几何。

梯度对 margin 为

$$
\frac{\partial L}{\partial h}=-\beta\sigma(-\beta h).
$$

$h=0$ 时梯度为 $-\beta/2$；$h\gg0$ 时趋近零；$h\ll0$ 时接近 $-\beta$。因此错排 pair 获得近似最大推力，已正确拉开的 pair 逐渐退出训练。$\beta$ 同时改变最大梯度与饱和速度，调它时学习率往往需要联动。

## 7. Bradley–Terry 假设在哪里会裂开

### 7.1 不可传递偏好

标量奖励要求偏好大体可传递：若 A 胜 B、B 胜 C，A 应倾向胜 C。真实数据可能存在循环。回答 A 简洁，B 更完整，C 更安全；不同标注者按不同维度选择，汇总后可能得到 A 胜 B、B 胜 C、C 胜 A。任何单一 reward 都无法同时满足三条严格不等式。

DPO 面对循环时会寻找折中 margin。loss 可以下降，却不会得到所有 pair 都正确的策略。若训练集 pair accuracy 长期卡住，先按 prompt 与评价维度寻找偏好环，不要立刻增加模型容量。

一个可操作检验是在同一 prompt 的候选图上找三角循环，报告循环率，并按标注者拆分。单个标注者循环少、合并后循环多，说明人群偏好异质；同一标注者也大量循环，可能是准则含混或候选差异太小。

循环给出了单标量模型无法消除的损失下界。令三个候选的效用为 $u_A,u_B,u_C$，三条硬标签依次为 $A\succ B$、$B\succ C$、$C\succ A$。对应 margin 为

$$
m_1=u_A-u_B,\qquad m_2=u_B-u_C,\qquad m_3=u_C-u_A,
$$

因此恒有 $m_1+m_2+m_3=0$。三条边不可能同时为正。若三条边同权，损失

$$
L=\log(1+e^{-m_1})+\log(1+e^{-m_2})+\log(1+e^{-m_3})
$$

在约束 $m_1+m_2+m_3=0$ 下于 $m_1=m_2=m_3=0$ 取最小值 $3\log2$。模型给三场比较都报 $0.5$，并非容量不足，而是标量效用对这个数据无解。把三条标签各复制十次，只会把最小损失放大十倍，不会让最优排序更明确。

有投票比例时可以直接检查循环的 log-odds。若三条边的胜率都为 $0.8$，每条边要求的效用差都是 $\log(0.8/0.2)\approx1.386$，绕环求和应为零，观测和却是 $4.159$。这个“环流残差”不会被任何候选的加性分数解释。实际数据可先按 prompt 构图，把每条边的 log-odds 投影到候选分数差，再把剩余残差按三角环或强连通分量汇总。残差集中在安全与帮助冲突的边，适合改成带评价维度的条件偏好；残差集中在少数标注者，适合建标注者随机效应；全局均匀出现才更像准则本身含混。

循环率也不能只用“存在循环的三角形数/全部三角形数”。候选数一多，绝大多数三元组没有完整标注，缺边会把循环率机械压低。更稳妥的报告同时列出：完整三角形中的循环比例、参与至少一个循环的边比例、删除最少多少总权重才能得到无环图。最后一项直接估计“必须牺牲多少偏好证据才能形成全序”，比单个 pair accuracy 更接近标量奖励假设的破裂程度。

### 7.2 同质噪声假设

Bradley–Terry 把所有 pair 的判断噪声放在同一温度里。实际 easy pair 的偏好几乎确定，两个近似答案的偏好接近抛硬币。用同一个 logistic 尺度训练，会给模糊 pair 过高置信度。

若有多标注者票数，可把软标签 $q=P(y_wwins)$ 直接用于交叉熵：

$$
L=-q\log\sigma(\beta h)-(1-q)\log\sigma(-\beta h).
$$

其最优有限 margin 满足 $\sigma(\beta h)=q$，即

$$
h^*=\frac1\beta\log\frac{q}{1-q}.
$$

$q=0.6$ 时目标 margin 很小；硬化成 $q=1$ 会要求 margin 无限增长。保留标注分歧能减少过度自信。

### 7.3 位置与长度混淆

若 chosen 总放在左侧，标注者存在位置偏好，模型会把位置造成的标签差当内容效用。数据收集时交换显示顺序，并保存顺序字段，便能估计位置效应。训练数据只保留最终 chosen/rejected 而删掉展示顺序，后续无法校正。

长度也会与偏好相关。标注者可能偏爱更详细的回答，或因阅读疲劳偏爱短回答。DPO 使用整序列 log-prob 总和，长度本身还进入模型 margin。数据偏好与目标几何叠加后，长度效应可能很强。

## 8. reference policy 的四重作用

### 8.1 坐标原点

DPO 学习的量是 chosen 相对 reference 的改善超过 rejected 的幅度：

$$
\Delta_\theta=\left(\log\pi_\theta(y_w)-\log\pi_{\mathrm{ref}}(y_w)\right)
-\left(\log\pi_\theta(y_l)-\log\pi_{\mathrm{ref}}(y_l)\right).
$$

若 reference 本来就强烈偏好 chosen，策略只需维持这一差距，$\Delta$ 未必大。若 reference 错得很深，策略必须跨过更大相对 margin。换 reference 会改变每条 pair 的训练难度，旧的 $\beta$ 与缓存 log-prob 都不再可比。

### 8.2 隐式先验与覆盖边界

reference 给低概率的回答，策略若要提高它，log-ratio 会很大。KL 正则下，策略更容易在 reference 已有覆盖的区域重新排序，很难凭离线偏好学出 reference 几乎不会生成的新行为。DPO 的稳定性部分来自这种保守性，也意味着 base 模型覆盖不足时先做 SFT 往往必要。

从 base 直接 DPO，chosen 回答可能处于极低概率区，序列 log-prob 数值很差，梯度集中于少数 token。SFT 起点先把数据支持移到偏好回答附近，DPO 再做相对排序，通常更符合推导里的局部策略改进。

### 8.3 固定 reference 与刷新 reference

固定 reference 让整个训练过程使用同一坐标，便于缓存 log-prob。多轮迭代若把上一轮策略设为新 reference，每轮只约束局部变化，总体偏移可以逐轮累积。它类似多次小步信赖域更新，却不能保证最终仍接近初始 SFT。

刷新后应重新计算所有 reference log-prob。沿用旧缓存会让 chosen 与 rejected margin 混合两个 reference，目标失去清晰含义。对照实验应同时报告相对当前 reference 与相对最初 SFT 的 KL。

局部约束无法自动推出全程约束。设第 $k$ 轮策略为 $\pi_k$，并令 $\pi_{k-1}$ 成为新 reference，则任一回答的累计 log-ratio 满足望远镜恒等式

$$
\log\frac{\pi_K(y\mid x)}{\pi_0(y\mid x)}
=\sum_{k=1}^{K}\log\frac{\pi_k(y\mid x)}{\pi_{k-1}(y\mid x)}.
$$

每轮变化虽小，方向一致时仍会累积。二元回答的玩具例子中，初始概率为 $(0.5,0.5)$，每轮把第一项的 odds 乘 $e^{0.4}$。五轮后第一项概率从 $0.5$ 变成 $\sigma(2)\approx0.881$；每轮只移动约 $0.05$ 到 $0.10$，最终相对初始分布已经明显偏斜。KL 本身没有同样的简单可加性，所以不能把五个局部 KL 相加冒充总 KL；应从固定锚点重新计算 $D_{\mathrm{KL}}(\pi_K\|\pi_0)$。

reference 漂移还会改变样本难度的构成。旧 reference 下的 hard pair 在新 reference 下可能已经是 easy pair，另一些边则从正 margin 变成负 margin。每轮开训前应在同一冻结诊断集上同时计算 $h^{(k-1)}$ 与 $h^{(0)}$，画二维分桶：横轴是相对当前 reference 的 margin，纵轴是相对初始 SFT 的 margin。横轴改善而纵轴持续恶化，说明局部训练在移动坐标中看似稳定，累计方向却偏离锚点。

### 8.4 奖励能识别到什么程度

偏好数据只识别同一 prompt 内的奖励差。对任意函数 $c(x)$，令

$$
r'(x,y)=r(x,y)+c(x),
$$

则 $r'(x,y_w)-r'(x,y_l)=r(x,y_w)-r(x,y_l)$，Bradley–Terry 概率完全不变。在 KL 正则最优策略中，$c(x)$ 只把归一化常数 $Z(x)$ 乘上 $e^{c(x)/\beta}$，策略也不变。因此“回答在提示 A 上奖励为 8、提示 B 上为 5”没有跨提示含义；可识别对象是提示内差值与排序。

尺度也与温度纠缠。把奖励和 $\beta$ 同时乘正数 $a$，指数倾斜中的 $r/\beta$ 不变；Bradley–Terry 若另有噪声温度 $\tau$，数据只识别 $r/\tau$。论文或代码中的 reward 数值翻倍，若温度口径也变了，策略几何可能一毫米都没动。比较实验必须固定温度约定，或报告无量纲的偏好 logit，而不能把隐式奖励绝对值当作可跨实现指标。

比较图不连通时，不可识别性更强。假设同一 prompt 有候选集合 $\{A,B\}$ 与 $\{C,D\}$，数据只比较 A/B 和 C/D，从未跨组比较。两组效用各自都可加不同常数，A 与 C 谁更好没有证据。即使图连通，数据也只约束观测边附近；模型对未出现回答的分数来自参数共享和 reference 先验，不是偏好似然直接识别的结论。报告 reward calibration 时应先给比较图的连通分量、节点度数和外推候选比例。

这一区分也解释了“隐式 reward 能否复用”的边界。同一 prompt 的候选重排可以使用 $\beta\log(\pi_\theta/\pi_{\mathrm{ref}})$；跨 prompt 阈值筛选、把不同 reference 训练出的 reward 混在一起、用绝对分数触发安全动作，都额外假设了坐标可比。若业务确需跨提示分数，要引入带锚点的独立 reward model 或可验证标尺，并用共享校准样本连接各提示与各 reference 版本。

## 9. 梯度饱和与错标样本

### 9.1 四个 margin 的手算

取 $\beta=0.1$，margin $h\in\{-20,0,10,40\}$，对应 $z=\beta h\in\{-2,0,1,4\}$。损失与梯度绝对值约为：

| $h$ | $-\log\sigma(\beta h)$ | $|\partial L/\partial h|$ |
|---:|---:|---:|
| -20 | 2.127 | 0.0881 |
| 0 | 0.693 | 0.0500 |
| 10 | 0.313 | 0.0269 |
| 40 | 0.018 | 0.0018 |

严重错排 pair 接近最大梯度，正确 margin 很大的 pair 几乎停止贡献。这个自适应权重有利于专注困难样本，也会让错标 pair 长期主导。数据中只要少量高置信反向标签，训练后期的梯度可能主要来自它们。

### 9.2 标签平滑的有限目标

把硬标签一改为 $1-\epsilon$，反向标签概率设为 $\epsilon$，损失为

$$
L=-(1-\epsilon)\log\sigma(\beta h)-\epsilon\log\sigma(-\beta h).
$$

最优点满足

$$
h^*=\frac1\beta\log\frac{1-\epsilon}{\epsilon}.
$$

取 $\epsilon=0.1,\beta=0.1$，目标 margin 约为 $21.97$，不再追求无穷大。它适合标签存在不可消除噪声的情形，代价是限制极高置信偏好。

### 9.3 饱和不等于训练完成

训练 loss 变平可能来自大多数 pair 已饱和，也可能来自梯度被少数冲突 pair 抵消。应画 margin 分布、错排率和每个 margin 桶的梯度质量。若 easy pair 已退出、hard pair 仍有一致方向，继续训练可能有收益；若剩余梯度主要来自低一致率数据，应先清洗或降权。

## 10. 长度偏差的来源

### 10.1 序列 log-prob 是 token 和

语言模型的序列对数概率为

$$
\log\pi(y\mid x)=\sum_{t=1}^{|y|}\log\pi(y_t\mid x,y_{<t}).
$$

每项通常为负，长度增加会让总和更负。DPO 用 policy-reference 的差，若两模型每 token 差异均值为 $d$，序列 log-ratio 期望约为 $|y|d$。长回答因此更容易获得大绝对 margin，也承受更多 token 的梯度。

设 chosen 长四个 token，每 token policy-reference 差为 $0.05$，其 log-ratio 为 $0.20$；rejected 长两个 token，每 token 差为 $0.08$，log-ratio 为 $0.16$。DPO margin 为 $0.04$，认为 chosen 相对改善略多。若按每 token 平均，chosen 为 $0.05$、rejected 为 $0.08$，排序反转。总和与均值代表不同目标。

### 10.2 数据长度相关与模型长度几何

若 chosen 本来更长，总和目标可能奖励增加 chosen token 的相对概率；若 rejected 更长，模型可通过降低长回答后缀概率扩大 margin。训练后出现短回答倾向时，要区分偏好数据本身偏短、EOS 概率变化和序列目标的长度效应。

最有辨识力的实验是长度匹配：在训练或评估子集中，让 chosen/rejected 长度差接近零，再与原数据比较。若长度偏差显著减弱，数据相关是主因；匹配后仍存在，目标或解码策略贡献更大。

### 10.3 长度归一也会改目标

SimPO 等方法使用平均 log-prob，减少序列长度的线性尺度。平均并非免费的校正。某个关键事实只占长回答少数 token，平均后其梯度被整段长度稀释；短回答每个 token 权重更高，也可能形成短回复偏好。

可以用同义冗余测试：给回答追加不改变语义的重复句，分别计算总和 margin 与平均 margin。理想训练应对纯冗余不敏感，但两种目标通常都会变化，只是方向不同。实际选择要看任务是否重视简洁、完整推导或固定格式。

### 10.4 把长度、格式与内容拆开

长度匹配只能消除一阶相关，格式仍可能与长度和标签共同变化。更有辨识力的是对同一语义答案构造 $2\times2$ 反事实：短文本/长文本与纯文本/目标模板交叉，共四个版本。长版本只增加可删除的解释，模板版本只改变标题、列表、代码围栏或工具调用包装。用冻结模型分别计算四个分数后，可以估计长度主效应、格式主效应及交互项：

$$
\alpha_{len}=\tfrac12[(s_{long,plain}-s_{short,plain})+(s_{long,fmt}-s_{short,fmt})],
$$

$$
\alpha_{fmt}=\tfrac12[(s_{short,fmt}-s_{short,plain})+(s_{long,fmt}-s_{long,plain})].
$$

若 $\alpha_{fmt}$ 很大而人工内容评分不变，模型主要学了包装；若只有长且带格式时得分上升，交互项暴露了“长回答更像规范答案”的组合捷径。训练前、训练后都做一次，变化量才能说明 DPO 新学到什么，单看训练后的相关性会把 SFT 既有偏好算进来。

数据层可以再做配对回归。令标签 log-odds 近似为 $b_0+b_1\Delta q+b_2\Delta |y|+b_3\Delta f$，其中 $q$ 是独立内容分，$f$ 是格式特征。这条线性模型只承担诊断作用，用来检查长度和格式单独能解释多少标签。若去掉 $\Delta q$ 后仍有很高预测率，先平衡或重写数据；直接在 loss 中扣掉 $b_2\Delta|y|$ 容易过校正，因为真实任务可能确实要求完整长度。

格式 token 的 mask 也要谨慎。只把 Markdown 标记、JSON 键或工具协议 token 从序列和中删除，看似能消除格式影响，却会改变条件概率链：后续内容 token 的概率仍以这些格式 token 为上下文。更可靠的消融是保留完整前向，只在成对数据中交换等价模板，或分别报告“协议是否合法”和“内容是否正确”。工具调用场景尤其需要两条指标；一个 JSON 完美但参数错误的调用，不应凭格式胜过语义正确但可修复的调用。

最终评测至少保留四个切片：等长同格式、等长异格式、异长同格式、异长异格式。若总体胜率上升只来自最后一格，结果很可能依赖混淆；前两格仍上升，才有更强证据说明模型学到了内容偏好。长度分布与格式通过率要作为并列结果，不能用一个“综合质量分”再次把它们混回去。

## 11. IPO、KTO 与 ORPO 的必要对照

### 11.1 IPO 给 margin 一个有限终点

DPO 对硬标签的最优 margin 趋向无穷。IPO 用平方目标把隐式偏好差拉向有限常数，可写成类似

$$
L_{\mathrm{IPO}}=(h_\theta-m)^2,
$$

其中 $m$ 由具体温度约定决定。梯度为 $2(h-m)$：margin 小于目标时推高，超过目标时拉回。DPO 的已正确 pair 只是梯度趋零，不会主动把过大 margin 拉回。

取目标 $m=2$。$h=-2,0,2,5$ 时 IPO 梯度分别为 $-8,-4,0,6$。错标离群会产生无界大梯度，DPO 梯度则有 $\beta$ 上界。IPO 控制过度优化的同时，对异常 margin 更敏感，需要更仔细的数据与梯度裁剪。

### 11.2 KTO 处理单条好坏标签

KTO 不要求同一 prompt 下的 chosen/rejected 对，而是消费“好”或“坏”的单条反馈，并用参考点衡量 policy-reference 的相对收益。它适合点赞、点踩、采纳、撤销等天然二元日志。

成对偏好包含局部比较信息：“在同一问题上 A 胜 B”。单条标签把回答与一个总体参考点比较，方差更依赖参考估计和 batch 构成。若日志标签受用户群、任务难度影响，必须分层估计基准，否则困难任务的合格答案可能总被当坏样本。

KTO 的价值在数据形态，不在于它必然优于 DPO。已有高质量 pair 时，拆成两个独立标签会丢掉同 prompt 比较；只有海量单反馈时，强行配对可能引入不可比样本。

### 11.3 ORPO 把监督与偏好合在一阶段

ORPO 在 chosen 上保留监督似然，同时用 chosen 与 rejected 的 odds ratio 做偏好约束。它省去独立 reference 前向，适合从 base 或较弱起点做单阶段训练。监督项确保 chosen 的绝对概率上升，偏好项拉开相对差距。

这里的代价是目标耦合。chosen 数据的文风、长度和模板会同时受 SFT 与偏好项强化；若数据覆盖窄，模型更容易过拟合格式。DPO 围绕 reference 做相对更新，通常更适合已有稳定 SFT 基座、希望控制漂移的场景。

### 11.4 三个问题决定对照方法

先看反馈单位：pair 完整时优先比较 DPO/IPO，只有单标签时比较 KTO。再看是否需要 reference：显存与缓存紧张、起点仍需大量 SFT 时，ORPO 值得试；已有成熟 SFT 且通用能力保护重要，reference 约束更有价值。最后看标签噪声：硬 pair 可靠可用 DPO，偏好分歧明显则保留软标签或采用有限 margin 目标。

## 12. DPO 与 PPO、GRPO 的边界

### 12.1 离线偏好与在线探索

DPO 直接学习现有 pair，训练期间无需生成和奖励模型调用。它高效、稳定，也只能在数据覆盖附近重新分配概率。若关键高奖励行为从未出现在 chosen 中，离线目标没有证据把它找出来。

PPO/GRPO 通过当前策略 rollout，能探索新回答并适应策略分布。代价是生成昂贵、verifier 或 reward model 会被策略主动寻找漏洞。任务奖励可自动验证、在线采样便宜时，RL 路线通常能继续突破离线 pair 上限。

### 12.2 信用粒度

标准 DPO 对整条 chosen/rejected 序列给一个相对标签，所有 chosen token 朝提高概率方向更新，所有 rejected token 朝降低方向更新。若 rejected 只有末尾事实错误，前面正确推理也受负梯度。PPO 配过程奖励或 critic 可以提供更细的 token/状态优势，GRPO 通常仍是序列级优势。

对短回答和整体风格偏好，序列标签足够；对长程 Agent 轨迹、局部工具错误和可恢复失败，pair 监督过粗。可以构造局部编辑 pair，只让两个回答在关键片段不同，减少无关 token 被共同更新。

### 12.3 稳定性与目标真实性

DPO 避免在线 RL 的高方差，却把风险前移到数据收集。pair 由旧策略产生、标注规则固定，训练稳定不代表目标正确。PPO/GRPO 的曲线更嘈杂，却能不断用当前策略暴露新型错误。

实践中常见组合是先 DPO 获得稳定偏好，再用可验证 RL 提升推理。顺序反过来也可行：先 RL 学能力，再用 DPO 校准风格和安全。每次阶段切换都要重新测能力、长度、KL 和隐藏约束，防止后一阶段覆盖前一阶段收益。

### 12.4 多轮对话与工具轨迹

多轮样本应先明确概率由谁产生。一条工具轨迹可写成

$$
\tau=(a_1,o_1,a_2,o_2,\ldots,a_T),
$$

其中 $a_t$ 是模型动作，$o_t$ 是环境或工具返回。策略概率只能包含模型控制的动作：$\log\pi_\theta(\tau)=\sum_t\log\pi_\theta(a_t\mid h_t)$。把搜索结果、数据库响应或用户下一轮话语也计入 policy log-prob，会让模型为不可控 token 承担梯度；不同工具输出长度还会伪装成策略长度效应。实现上要对 observation token、系统注入与执行器错误文本严格置零 mask，并做一次逐段 log-prob 手算。

整轨迹偏好仍有粗粒度信用问题。设 chosen 与 rejected 各有四个动作，只在第二步的工具参数不同：chosen 传正确日期并成功，rejected 传错日期，第三步自行纠正后也得到正确结果。轨迹级硬标签会提高 chosen 的四个动作、压低 rejected 的四个动作，连 rejected 的“发现错误并恢复”也受罚。若只比较第二步的 fork，梯度才落在真正决策；若产品还关心恢复能力，应另建“发生错误后能否修复”的 pair，避免成功率目标吞掉恢复性目标。

最干净的数据单位是同一历史状态 $h_t$ 下的动作对 $(a_t^w,a_t^l)$，随后用同一环境快照执行。两条轨迹若在早期已经观察到不同搜索结果，后续动作面对的状态不同，直接比较相当于把环境运气写入偏好。无法复现环境时，至少记录工具版本、参数、响应哈希、延迟与失败码，并按结果可比性分层；“一个调用成功、另一个因服务超时失败”的 pair 不应教模型回避原本正确的动作。

多轮用户偏好还存在策略诱导。模型第一轮说法会改变用户第二轮问题，最终满意度是整段交互的结果。把最后的点赞回填到所有轮次，会奖励早期偶然措辞。可用前缀固定实验定位：冻结到第 $t$ 轮的共同历史，只替换一个候选动作，再由相同用户模拟器或人工继续；每个分叉点得到局部 pair。若局部标注成本太高，可以给整轨迹训练，但评测必须分解为任务成功、工具预算、无效调用、恢复次数和最终答复质量，不能只看一个总胜率。

工具轨迹的 reference 也需要版本化。policy 更新后会改变调用分布，工具后端更新后会改变 observation 分布；两者同时变化时，第二轮 DPO 的提升无法归因。冻结回放可以固定 observation，只比较动作选择；在线沙箱则测闭环结果。二者差距扩大通常意味着环境交互而非语言偏好出了问题，也是离线 DPO 应切换到在线 RL 或数据再采样的信号。

## 13. 一组完整手算

### 13.1 从 token 概率到 DPO margin

某 pair 的 chosen 有三个 token，policy log-prob 为 $(-0.2,-0.4,-0.6)$，reference 为 $(-0.3,-0.5,-0.5)$。chosen 序列 log-ratio 为

$$
(-1.2)-(-1.3)=0.1.
$$

rejected 有两个 token，policy 为 $(-0.3,-0.8)$，reference 为 $(-0.4,-0.5)$，序列 log-ratio 为

$$
(-1.1)-(-0.9)=-0.2.
$$

所以 $h=0.1-(-0.2)=0.3$。取 $\beta=0.2$，logit 为 $0.06$，偏好概率 $\sigma(0.06)\approx0.515$，loss 约 $0.664$，对 margin 的梯度约

$$
-0.2\sigma(-0.06)\approx-0.097.
$$

负号表示梯度下降会提高 $h$：增大 chosen 相对 reference 的 log-ratio，降低 rejected 的相对 log-ratio。

### 13.2 梯度怎样分到 token

在没有长度归一时，$h$ 对每个 chosen policy log-prob 的导数为一，对每个 rejected policy log-prob 的导数为负一。因此同一标量权重施加到所有有效 token。chosen 的三个 token 各收到约 $-0.097$ 的 loss 对 log-prob 梯度，rejected 两个 token 各收到约 $+0.097$。

chosen 总梯度质量约是 rejected 的 $3/2$，只因长度不同。若改用平均 log-prob，chosen 每 token 系数为 $1/3$，rejected 为 $-1/2$，短回答单 token 权重更大。长度处理改变的远不止数值稳定。

### 13.3 reference 换掉后的变化

假设新 reference 就是某个中间策略，对 chosen 与 rejected 的 log-prob 分别为 $-1.15$ 和 $-1.05$。当前 policy 不变时，chosen ratio 为 $-0.05$，rejected ratio 为 $-0.05$，$h$ 变为零，loss 回到 $0.693$。同一策略、同一 pair，仅刷新 reference 就改变梯度。

这解释了多轮 DPO 必须报告 reference 版本。看到第二轮 loss 重新升高，不代表模型遗忘偏好，可能只是坐标原点移动。

### 13.4 错标 pair 的长期作用

若真实应选 rejected，却被标成 chosen，随着模型按正确规律学习，$h$ 会越来越负。这条错标的梯度绝对值趋近 $\beta$，而正常 pair 逐渐饱和退出。训练后期错标占梯度比例持续上升。

可记录每条 pair 的累计梯度权重或按 margin 桶抽样复核。若最负 margin 桶的人工翻转率显著更高，采用降权、软标签或清洗比继续训练更有效。

## 14. 可证伪实验

### 14.1 推导假设实验

对同一 prompt 收集至少四个候选和多标注者排序，测三角循环率、标注一致率与 Bradley–Terry 拟合残差。若残差集中在安全与帮助冲突的 pair，单标量效用不足，应拆维度或按场景建模。

保留投票比例训练软标签 DPO，与多数票硬标签对照。若软标签降低极端 margin、提高留出标注者一致率且不损伤任务表现，硬标签过度自信得到证实。

### 14.2 reference 实验

固定 policy 起点与 pair，分别使用 base、SFT 和较新 checkpoint 作 reference，扫描各自合理的 $\beta$。报告相对各 reference 与相对同一初始 SFT 的 KL。若只看各自局部 KL，刷新 reference 的累计漂移会被隐藏。

另做 reference-free 消融，将参考 log-ratio 置零。若偏好准确率上升、通用与生成质量下降，reference 的保护作用有直接证据；若各项均不变，当前数据或训练步数可能尚未触及约束边界。

### 14.3 噪声实验

在干净 pair 中受控翻转 $1\%,5\%,10\%$ 标签，比较 DPO、标签平滑 DPO 与 IPO。观察最佳 checkpoint、尾部 margin、梯度集中度和留出集表现。理论预期是硬 DPO 后期越来越受错标驱动，平滑版本更稳，IPO 对极端残差更敏感。

真实数据上可双重标注低 margin 与大负 margin 两桶。前者可能是天然模糊，后者可能是错标或模型盲点。若大负 margin 桶一致率反而很高，模型确有系统缺陷，不应把困难样本一概清洗。

### 14.4 长度实验

构造内容相同、长度不同的 pair：添加冗余解释、压缩措辞、保留或删除必要证明。分别计算总和与平均 log-prob 目标的 margin，再进行短训练。测回答长度、事实正确率、完整性与 EOS 概率。

若平均目标明显偏短，且删除必要证明的比例上升，长度归一伤害了完整性；若总和目标不断扩写无信息内容，序列和在奖励 token 数。还应对原数据做长度匹配，分离数据偏好与损失几何。

### 14.5 与 PPO、GRPO 的公平对照

固定初始模型、提示池与总生成/标注预算。DPO 的 pair 生成和标注成本必须计入，PPO/GRPO 的在线 rollout 与 verifier 成本也计入。比较达到固定隐藏分数所需总 GPU 时，而非只看训练阶段速度。

对短程风格任务、可验证数学任务、长程工具任务分别报告。若 DPO 在风格上领先、RL 在可验证推理上领先，这支持数据形态边界；若一种方法横跨三类都领先，再检查模型规模、数据新鲜度与预算是否真正对齐。

### 14.6 失败条件

声称 DPO 更稳定，需要多随机种子下更低方差，并同时维持隐藏质量；loss 平滑不算充分证据。声称 IPO 抑制过度优化，需要看到 margin 有限、KL 受控且偏好泛化改善。声称 KTO 适合弱反馈，需要在同等回答条数下胜过把单标签勉强配对的基线。

声称 ORPO 省去 SFT+DPO 两阶段成本，应把达到同一质量的总 token 与显存峰值列出。若单阶段需要更多 epoch 或更严格清洗，省下的 reference 前向未必转化为端到端收益。

### 14.7 pair 是怎样生成的

偏好数据的生成策略决定 DPO 能学到哪条边界。同一 policy 低温采样出的候选彼此相似，标注稳定却缺少有意义差异；高温采样覆盖更广，错误类型和长度也随之变化，pair 可能退化为一眼可见的质量差。前者梯度弱，后者只教模型识别简单错误。

较有信息量的 pair 应在总体质量接近时，只在少数关键维度上有差异。可以先按规则或 reward 粗分层，再在相邻分数层内配对。这样能减少“正确答案总是更长、错误答案总是格式坏掉”的捷径。配对后仍要报告长度差、来源模型、采样温度与基础分数差。

若 chosen 来自强模型、rejected 来自弱模型，模型身份会和偏好完全绑定。强模型特有的措辞、段落和自称都可能成为标签线索。更稳妥的设计让同一来源模型同时贡献 chosen 与 rejected，或在统计上平衡来源。

在线迭代 DPO 会让 pair 分布逐轮变难。第一轮 rejected 可能有明显事实错误，第二轮只剩细微表达差异。沿用相同 $\beta$ 与训练轮数，会在后期模糊 pair 上过度拉 margin。每轮都应重估标注一致率、初始 margin 和长度差，再决定噪声处理。

### 14.8 隐式奖励能否当普通 reward 使用

DPO 隐式奖励常写成

$$
r_\theta(x,y)=\beta\log\frac{\pi_\theta(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}.
$$

它缺少提示相关常数 $\beta\log Z(x)$，所以同一提示内做差没有问题，跨提示比较绝对值则没有依据。提示 A 的隐式奖励二与提示 B 的一，不能推出 A 的回答更好。

隐式奖励还随 policy 更新。昨天 checkpoint 给某回答的分数与今天的分数不在同一固定 reward 坐标中。把它用于数据筛选时，应冻结打分 checkpoint；边训练边用当前隐式奖励选样，会形成反馈环，策略偏好的样本更容易再次进入训练。

校准实验可在每个 prompt 内采样多个候选，比较隐式奖励排序与独立人工排序，再按长度和来源分桶。若总体相关高、长度匹配后相关骤降，模型主要利用了长度。若训练 pair 内相关高、当前策略新样本上低，出现了分布外失效。

### 14.9 批内 token 与序列归约

DPO 通常先把每条回答 token log-prob 求和，再形成每个 pair 的 loss，最后对 pair 平均。padding mask 若多算一个 token，chosen/rejected 长度不同就产生方向性误差。EOS 是否计入也会改变停止概率的训练。

梯度累积时，应按 pair 数还是 token 数归约取决于目标定义。按 pair 平均让长短 pair 总权重相同，但长回答内部有更多 token 承接相同标量梯度；按 token 平均进一步降低长 pair 总权重。不同代码库即使都叫 DPO，也可能在这里不同。

构造两个 pair：第一对总有效 token 为十，loss 为一；第二对总 token 为九十，loss 为二。pair 平均为 $1.5$；若按 token 加权为 $1.9$。分布式环境中，各卡先局部平均再全局平均还会受数据排布影响。单卡与多卡同 batch 梯度应作为回归测试。

缓存 reference log-prob 可以省前向，但 tokenizer、chat template、截断长度与 padding side 必须完全一致。缓存由旧模板生成，policy 用新模板训练时，差值混入格式变化。随机抽样在线重算缓存值，是比只看文件版本更可靠的检查。

### 14.10 截断会制造假 pair

若 chosen 较长并在最大长度处被截断，缓存 log-prob 只覆盖前缀，标签却来自完整回答。模型训练看到的 chosen 可能缺少真正获胜的结论。rejected 若较短且完整，DPO 会比较一个不完整前缀与完整答案。

数据预处理应在截断后重新验证 pair：获胜依据是否仍存在、结论是否完整、EOS 是否保留。简单地丢弃所有超长 pair 会改变任务分布，可以提高上限或采用按语义边界截断，但不能默默保留错位标签。

做一个上限扫描，把最大长度取多个值，统计保留 pair 数、chosen/rejected 截断率、初始 margin 与训练后长度。若性能改善主要来自更少 chosen 被截断，收益属于数据完整性，并非目标函数。

### 14.11 泛化到当前策略样本

离线 pair 常由旧模型生成。DPO 更新后，策略会产生训练集中没有的新回答，其中可能出现新的 reward hacking、格式和错误类型。pair 留出集若也来自旧模型，只能测旧分布排序。

每隔若干 checkpoint 从当前策略采样固定 prompt，做独立盲评，形成 on-policy 评测。比较离线 pair accuracy 与当前样本胜率：前者继续升、后者下降时，模型正在过拟合旧候选边界。

还可以做交叉来源矩阵。用模型 A、B、C 各自产生 pair，分别训练后在三类来源上评估。只在自身来源领先，说明方法学到了生成器特征；跨来源都提升，偏好规律更可能具有泛化性。

分布外提示应覆盖训练中少见的语言、领域、长度和安全边界。reference 的作用是在这些区域提供保守先验。若去 reference 方法在域内更强、域外明显退化，成本收益需要把这部分质量损失算进去。

### 14.12 多目标偏好怎样处理

帮助性、安全性、真实性与风格可能冲突。把所有 pair 混在一起相当于假设存在固定权重的单标量奖励。用户群或场景变化时，这个权重并不固定。

最简单的诊断是给 pair 标注偏好理由，按维度分别报告准确率和 margin。总体提升可能掩盖安全维度退化。若同一回答对在不同维度标签相反，可以保留条件标签，让策略看到当前优化目标，而非强行投票成一个 chosen。

条件偏好模型可把场景 $c$ 加入输入，学习 $P(y_w\succ y_l\mid x,c)$。部署时明确选择场景。没有场景条件时，数据配比就隐式决定价值权重，调整采样比例等同于修改产品目标。

多目标也影响 reference 选择。通用 SFT reference 保护整体语言能力，却未必具备安全覆盖；安全模型作 reference 会更强地约束相关行为。比较 reference 时除了平均 KL，还应按目标维度测行为变化。

### 14.13 数据泄漏与模板捷径

chosen 和 rejected 若使用不同模板、结束标记或系统提示，模型无需理解内容就能分类。常见泄漏包括 chosen 总有完整句号、rejected 带截断标记、某来源模型固定使用 Markdown 标题。训练 loss 会下降得很快，生成质量却不升。

可训练一个只看长度、标点、模板和来源字段的轻量分类器。若它已能高准确预测标签，主模型很可能利用同样捷径。再做模板统一与保义改写，观察标签可预测性是否下降。

token 级归因也有帮助。计算 chosen/rejected 哪些位置贡献最大梯度，若集中于固定开头、签名或 EOS，先清数据。真正内容偏好通常分布在事实、推理或指令遵循相关片段。

### 14.14 checkpoint 选择

DPO 训练 loss 往往持续下降，生成质量可能先升后降。pair accuracy 接近饱和后，模型仍能继续扩大 margin，导致 KL、长度或多样性漂移。最佳 checkpoint 不能按最低训练 loss 选择。

验证集至少包含独立 pair 胜率、当前策略盲评、通用能力、长度和相对初始 SFT 的 KL。可设硬约束：通用分下降不超过阈值，在满足约束的 checkpoint 中选偏好胜率最高者。

若多指标互相冲突，应展示 Pareto 前沿。一个 checkpoint 偏好胜率高两点却通用能力低五点，是否值得取决于场景；压成单一加权分会隐藏权重选择。训练报告保留各 checkpoint 原始指标，后续目标变化时无需重训才能重新选择。

### 14.15 从 margin 梯度展开到模型参数

令 $z=\beta h_\theta$，单个 pair 的 DPO 梯度为

$$
\nabla_\theta L=-\beta\sigma(-z)\left[\nabla_\theta\log\pi_\theta(y_w\mid x)-\nabla_\theta\log\pi_\theta(y_l\mid x)\right].
$$

再把序列展开，括号内等于 chosen 各 token score 之和减去 rejected 各 token score 之和。标量 $\beta\sigma(-z)$ 对整对回答共享，决定 pair 权重；token 之间的区别来自各自 softmax score。对某位置的目标 token logit $u_k$，$\partial\log p(a)/\partial u_k=\mathbf1[k=a]-p(k)$。提高 chosen 目标 token 的同时，会按当前概率压低同位置其他词；降低 rejected 目标 token 时，概率质量也会流向其他词。

这说明“chosen token 全部被奖励”仍是简写。共享标量相同，参数梯度却受上下文、词概率与表示方向影响。一个极低概率 chosen token 的 logit 梯度接近一，高概率 token 接近零；模型会优先修补自己最意外的位置。若意外位置只是罕见专名，梯度可能集中于记忆专名，而非学习偏好理由。

两条回答共享长前缀时，共享 token 的上下文相同，chosen 与 rejected score 可部分抵消；分叉后的 token 才贡献主要差异。若数据管线分别截断或模板不同，共享前缀无法抵消，格式噪声进入梯度。可按最长公共前缀分桶，测梯度范数是否主要随真正差异片段变化。

参数共享还造成跨 token 干扰。提高某处“拒绝”一词的概率，可能改变其他提示下同词与相近表示。pair loss 只观察当前回答，无法保证旁侧行为不退化。通用评测与 KL 约束承担的正是这部分外部性。

梯度范数由 pair 权重、长度和 token score 三者共同决定。日志只记录 margin 会漏掉表示层放大；只记录全局梯度范数又无法定位 pair。应抽样保存每对回答的标量权重、有效 token 数和未裁剪 per-example 梯度代理，例如最后一层 score 范数。

### 14.16 forward、reverse 与 JS KL 的几何

DPO 推导中的正则是 reverse KL：

$$
D_{\mathrm{KL}}(\pi\|\pi_{ref})=\sum_y\pi(y)\log\frac{\pi(y)}{\pi_{ref}(y)}.
$$

期望由当前策略取，策略把质量放到 reference 极低概率区域会受到强惩罚；reference 有质量、策略遗漏的区域只因策略权重小而贡献有限。它倾向选取 reference 支持中的高奖励模态，具有 mode-seeking 性格。

forward KL 为

$$
D_{\mathrm{KL}}(\pi_{ref}\|\pi)=\sum_y\pi_{ref}(y)\log\frac{\pi_{ref}(y)}{\pi(y)}.
$$

reference 覆盖的模态若被策略压到接近零，惩罚会很大，因此更偏向覆盖。它不会同样强烈阻止策略在 reference 罕见区域增加质量。二者方向互换，最优策略的指数倾斜推导也随之改变，不能把 DPO 公式原样套用。

以两回答分布为例，reference 为 $(0.9,0.1)$。策略 A 为 $(0.99,0.01)$，策略 B 为 $(0.7,0.3)$。A 丢掉小模态，forward KL 对该遗漏更敏感；B 向小模态增加质量，reverse KL 会强调策略落在 reference 低概率处的代价。扩展到语言空间时，“模态”对应不同回答风格、语言或策略路线。

JS divergence 用混合分布 $m=(\pi+\pi_{ref})/2$：

$$
D_{JS}=\tfrac12D_{KL}(\pi\|m)+\tfrac12D_{KL}(\pi_{ref}\|m).
$$

它对称且有界，在两分布支持差异大时比 KL 温和。代价是失去 DPO 那个可直接反解奖励的简单指数族关系。若训练目标改成 JS 正则，需要重新推导或使用相应变体，不能只在监控里把 KL 换名。

序列级 sampled KL 还不等于完整分布 KL。它只沿已生成路径累加 log-ratio，适合估计 reverse KL；forward KL 需要从 reference 采样或访问其分布。报告“KL”时必须写明方向、采样策略、按 token 平均还是序列求和。

可证伪对照是在多模态玩具任务中让 reference 覆盖两条正确路线，偏好数据只强调其一。reverse-KL DPO 若明显压低未标注路线，forward/JS 约束若保留更多覆盖，几何预期得到支持。真实任务可用多语言回答或多种正确证明路线重复此实验。

### 14.17 偏好数据的选择偏差

进入标注池的回答通常不是随机样本。系统会过滤违规、去重、按 reward 预筛或只送审用户投诉。DPO 学到的是“被选择进入池后”的条件偏好。若送审概率同时依赖回答特征和标签，普通经验风险会偏离部署分布。

记回答对进入数据集的概率为 $s(x,y_w,y_l)$。理想风险对部署分布取期望，观测风险对条件分布取期望。若 $s$ 已知，可用逆概率权重 $1/s$ 校正；小概率样本权重会爆炸，通常需要截断并报告残余偏差。

只保留 reward 差大的 pair 会让训练容易，却删掉决策边界。模型能学会明显好坏，遇到两个高质量回答时仍不会选。只保留难 pair 又使标签噪声升高。合理数据应分层覆盖大、中、小差距，并分别报告一致率。

用户反馈也有曝光偏差：只有实际展示的回答才可能获赞，未展示候选没有标签。展示策略倾向高分答案时，正反馈集中于旧策略已喜欢的区域。把不同用户、位置和策略版本混合，会把曝光机制写进偏好。

可通过随机探索流量估计倾向分数，或至少保留展示概率。离线回放比较加权与未加权训练；若加权后总体离线准确率下降、随机流量上的胜率上升，原模型利用了曝光偏差。

拒绝采样同样制造偏差。先生成许多候选、选最高分作 chosen、最低分作 rejected，pair 的极端性随候选数增加。训练模型面对普通两样本比较时，margin 标度不再匹配。数据元信息应保存候选池大小和选择规则。

### 14.18 soft label 与鲁棒损失手算

取标注投票为六比四，软标签 $q=0.6$，$\beta=0.2$。有限最优 margin 为

$$
h^*=\frac{1}{0.2}\log\frac{0.6}{0.4}\approx2.027.
$$

在 $h=0$ 时，soft-label loss 对 margin 的梯度为 $\beta(0.5-q)=-0.02$；硬标签梯度为 $-0.1$，大五倍。模糊 pair 不应获得与十比零一致 pair 相同的推力。

当 $h=5$ 时，$\sigma(1)\approx0.731$，soft 梯度为 $0.2(0.731-0.6)=0.0262$，开始把 margin 拉回；硬标签梯度仍为 $-0.0538$，继续推高。软标签同时编码方向与置信度。

若投票只有一人，$q$ 的估计方差很大。可用 Beta 先验平滑：正票 $k$、总票 $n$，先验 $\operatorname{Beta}(a,b)$，后验均值 $(k+a)/(n+a+b)$。取均匀先验，一票赞成得到 $2/3$ 而非一；十票全赞得到 $11/12$，置信度随样本数增长。

标签平滑假设所有 pair 同一噪声率，投票软标签允许逐 pair 变化。没有多票数据时，可按标注一致率、自动规则可靠度或 pair 差距分桶设平滑强度，但这些置信度模型也要在留出复标集校准。

鲁棒损失可截断极端负 margin 的权重，避免疑似错标无限主导。例如把 logistic 权重 $\sigma(-\beta h)$ 上限设为 $c<1$，会降低最困难 pair 的影响。代价是模型真正的系统盲点也被降权。应对极端桶复标后再决定，而非按模型不认同程度自动删样本。

另一方案是混合噪声模型：假设标签以概率 $1-\eta$ 正确、以 $\eta$ 翻转，则观测偏好概率为

$$
p_{obs}=(1-\eta)\sigma(\beta h)+\eta\sigma(-\beta h).
$$

当 $h\to\infty$，$p_{obs}$ 只趋近 $1-\eta$，损失不会要求无限置信。取 $\eta=0.1,z=2$，真实偏好概率约 $0.881$，观测概率约 $0.805$，比硬模型保守。

实验应同时注入随机翻转和系统翻转。随机翻转检验鲁棒性，系统翻转模拟某种风格被稳定误标。统一标签平滑能缓解前者，却可能仍学习后者；保义变换与分桶复标才针对系统偏差。

### 14.19 端到端实验矩阵

矩阵第一轴是数据：干净硬标签、软投票、受控随机噪声、长度匹配、来源平衡、当前策略新样本。第二轴是目标：DPO、平滑 DPO、IPO、KTO 或 ORPO 中与数据形态匹配的最小集合。第三轴是 reference：初始 SFT、刷新 checkpoint、无 reference 对照。

每个单元固定有效回答 token、优化步和模型起点。训练前记录初始 margin、长度差和 reference 覆盖；训练中记录梯度权重分桶、KL、EOS 概率和 loss；训练后测旧分布 pair、新策略盲评、通用能力、长度与多样性。

第一阶段只用小模型和少量数据扫描 $\beta$ 与学习率，筛掉明显发散配置。第二阶段固定超参，在多个种子上比较目标。第三阶段才扩大模型，并复核小模型的机制结论是否仍成立。不能在每种方法上分别挑最有利数据清洗，再把结果归因于损失。

关键交互至少包括：标签噪声×损失、长度差×归约方式、reference×β、数据来源×泛化评测。四项全因子过大时，可先做每个二阶交互，主效应不足的组件不进入大规模组合。

预注册失败条件：若软标签只降低 margin 却不提高复标一致率，它没有解决噪声；若刷新 reference 提高局部胜率却使相对初始 SFT 的 KL 累积失控，局部约束不足；若 IPO 控制 margin 但异常 pair 梯度爆炸，有限目标的收益被平方尾部抵消。

结果表不能只列最佳分。应列中位数与置信区间、达到最佳点的预算、训练后退化斜率、未成功运行比例。DPO 类方法常在早期 checkpoint 最好，最终 checkpoint 更差；只报最终或只挑峰值都会隐藏训练窗口。

最后用冻结 pair 做实现一致性测试。不同训练器读取完全相同的 policy/reference log-prob，输出 loss 和梯度权重必须与手算一致。再开放模型前向，确认缓存误差；再开放在线采样，确认分布变化。三层分开，实验矩阵才有解释力。

### 14.20 置信区间与有效样本量

pair 胜率是二项比例，但普通 Wald 区间在样本少或胜率靠近零、一时很差。对 $n$ 个近似独立 pair、胜出 $k$ 次，令 $\hat p=k/n$，可用 Wilson 区间：

$$
\frac{\hat p+z^2/(2n)\ \pm\ z\sqrt{\hat p(1-\hat p)/n+z^2/(4n^2)}}{1+z^2/n}.
$$

取 $k=540,n=1000,z=1.96$，点估计为 $0.54$，95% 区间约为 $[0.509,0.571]$。它刚刚排除 $0.5$，统计证据存在，产品收益却只有四个百分点；显著性不能替代效应大小与成本判断。

真实 pair 往往不独立。同一 prompt 的十个候选比较共享上下文，同一标注者的判断共享偏好，来自同一生成种子的样本也相关。把一千条边当一千次独立试验会得到过窄区间。评测时应按生成单位做 cluster bootstrap：若产品面对新 prompt，就整组重采样 prompt；若要外推到新用户，再在外层重采样用户。一个 prompt 内抽中后保留其全部 pair，不能把边拆散。

比较两种方法时，优先计算逐 prompt 的配对差 $d_i=s_i^A-s_i^B$，对 $\bar d$ 做区间，而非看两条独立区间是否重叠。同一难题会同时拉低 A、B，配对能消掉这部分方差。自动 judge 的结果还应在人工复核子集上校准；judge 偏好某种长度或格式时，样本再多也只会把有偏估计的区间收得更窄。

训练随机性与评测抽样是两层不确定性。至少多个训练种子分别得到 checkpoint，再在每个 checkpoint 上按 prompt bootstrap。只把所有 seed 的回答池混起来会掩盖“某个 seed 完全失败”。报告可列 seed 中位数、种子间范围、每个 seed 的评测区间和失败运行比例。种子很少时，正态近似的均值区间不可靠，展示所有点通常比一条误导性的误差棒更诚实。

反复查看验证集并挑最高 checkpoint 会引入选择偏差：二十个 checkpoint 中的峰值包含噪声上浮。选择集用于 early stopping，最终只在未参与选择的锁定测试集评一次；或对完整选择流程做外层 bootstrap。扫描多个 $\beta$、多种损失和多个数据版本时也一样，不能把最优单元的朴素区间当作预先指定实验的区间。

样本量应从希望分辨的最小效应倒推。胜率接近 $0.5$ 时，95% 区间半宽近似为 $1.96\sqrt{0.25/n}$。若希望半宽不超过两个百分点，需要

$$
n\gtrsim\frac{1.96^2\times0.25}{0.02^2}\approx2401
$$

个独立 prompt。这里的关键词是独立。每个 prompt 做十次相近比较，组内相关系数若为 $\rho=0.2$，设计效应为 $1+(10-1)\rho=2.8$；名义上一千条判断只有约 $1000/2.8\approx357$ 条独立判断的信息量。继续给同一批 prompt 增加候选，往往不如扩大 prompt 覆盖有效。

胜率以外的连续指标也应报告分布。回答长度、KL 和工具调用数常有长尾，中位数区间比均值加减标准差更稳；任务得分大量为零时，可同时给成功率与成功条件下的成本。若一个方法只通过让少数样本产生极大收益抬高均值，分位数会立即暴露。统计单元始终跟部署问题一致：面向新问题就按 prompt 聚合，面向新会话就按会话聚合，不能拿 token 当样本量。

### 14.21 从症状定位失败层

排障应按数据、分数、优化、生成、评测五层逐级开放。每次只开放一层，上一层先用固定输入通过回归测试。下面的症状矩阵把“训练没效果”拆成可证伪假设：

| 观测组合 | 优先检查层 | 最小定位实验 |
| :--- | :--- | :--- |
| 手算 loss 与训练器首步不符 | 分数/实现 | 固定两条短序列，导出每 token mask、policy/reference log-prob、归约前 loss |
| 首步一致，单卡与多卡更新不同 | 优化/归约 | 固定全局 batch，比对 all-reduce 前后的 pair 数、token 数与梯度累积除数 |
| 离线 pair accuracy 升，当前策略盲评降 | 数据分布 | 在同一 prompt 上同时评旧候选与新采样，检查来源、长度和错误类型迁移 |
| loss 降、KL 暴涨、通用能力降 | reference/步长 | 冻结数据扫描学习率与 $\beta$，同时对当前与初始 reference 计算 KL |
| 内容正确率不变，胜率随长度或模板升 | 数据捷径/评测 | 做等长同格式切片及 $2\times2$ 反事实，人工盲评去除包装 |
| 回放工具轨迹提升，在线执行不提升 | 环境交互 | 固定 action 比较 observation 差异，核对工具版本、超时和状态污染 |
| 多 seed 只有一个成功 | 优化稳定性 | 对齐首批次与初始化，报告失败率，检查极端负 margin 与梯度裁剪触发率 |

具体顺序可以压成三道闸门。第一道是“静态算术”：reference 缓存、模板、mask、截断、求和/平均和 loss 符号必须与手算一致。第二道是“短程动力学”：在几十个可背诵 pair 上过拟合，确认 chosen margin 上升、rejected margin 下降且更新量符合预期；若这一步失败，扩大数据和模型只会放大噪声。第三道才是“分布泛化”：固定旧 pair、当前策略新样本和域外提示三套评测，区分记住训练边界、适应当前分布与保持通用能力。

失败定位还需要保存可串联的主键。每条 pair 至少关联 prompt、候选、来源模型、reference 版本、tokenizer/模板版本、截断状态、标注者或 judge 版本、训练批次与 checkpoint。只有聚合曲线时，“某个时间点 KL 突增”无法回到具体数据；保留主键后可以抽出贡献最大的一百个 pair，判断是错标、缓存错位、超长样本还是新任务簇进入批次。

修复后的验收要针对原假设。若怀疑缓存错位，验收是在线重算误差归零，不是最终胜率偶然回升；若怀疑长度捷径，验收是等长切片改善且长度系数下降；若怀疑 reference 累计漂移，验收是相对初始锚点的 KL 受控。用同一聚合指标既发现问题又宣告修复，容易把故障从一个切片搬到另一个切片。

时间顺序还能缩小故障范围。若异常从 step 0 就存在，优先看数据预处理、reference 缓存和损失口径；若在一次恢复训练后突然出现，核对优化器状态、随机数状态、数据游标与 reference 版本；若训练指标平滑而生成指标在某个 checkpoint 后才恶化，检查 margin 饱和、EOS 与解码参数；若离线与在线结果只在工具后端升级后分叉，先复现环境版本。把关键配置哈希与数据版本写入每个 checkpoint，能把“最近某处改过”变成可二分的时间边界。

定位过程本身也要避免同时改多项。一次只修复一个候选原因，用同一冻结小样本复跑首步与短程过拟合，再回到完整训练。若同时清洗数据、换 reference、改 $\beta$ 和升级训练器，即使结果变好也无法知道哪项有效，下一轮同类故障仍要从头排查。对高成本训练，保留一个十到百条 pair 的金丝雀集和预期 loss、margin、梯度摘要，是最便宜的回归保险。

## 15. 结论

DPO 将 KL 约束 RL 的最优策略关系代入 Bradley–Terry 偏好模型，把显式 reward 与在线采样换成 pair 上的分类损失。简洁来自一组明确前提：reference 有足够覆盖，pair 能表达稳定标量偏好，数据接近策略需要学习的区域，序列级标签足以提供信用。

前提不满足时，应按故障选择方法。硬标签噪声让极端错排 pair 主导梯度，可保留软偏好或采用有限 margin；只有单条好坏反馈时，KTO 比人为配对更自然；起点仍需监督学习且 reference 成本突出时，ORPO 值得对照；任务需要在线探索或长程状态信用时，PPO/GRPO 更符合信号结构。

实验记录应落到可复现的量：chosen/rejected 长度、policy 与 reference 的序列及每 token log-ratio、margin 分布、各桶梯度质量、相对初始模型的 KL、标注一致率和隐藏评测。方法名只描述大致家族，这些量才决定实际训练的目标。
