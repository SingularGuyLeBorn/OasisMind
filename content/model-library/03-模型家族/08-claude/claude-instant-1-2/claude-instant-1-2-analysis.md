# Claude Instant 1.2 (2023): 小档模型的一次有取舍的更新

> 源文是 Anthropic 在 2023 年 8 月 9 日发布的产品公告 「Releasing Claude Instant 1.2」, 属于博客式发布页, 不是技术报告. 全文没有公式, 没有参数量, 训练数据, 训练方法, 上下文长度, 延迟或价格数字; 可核对的量化材料只有一张七行的基准表和一张没标数值的红队柱状图. 训练手段本页没写的, 标 「本页没有」.

来源: 同目录 `claude-instant-1-2.md` 与 `claude-instant-1-2.pdf`, 共 9 页, 配图 6 张 (均在 `images/`). 对照译稿和逐段疑问见 `claude-instant-1-2-bi.md`. 引用的原文数字和链接以源 md 为准.

## 1. 材料与定位

### 1.1. 材料性质: 四页正文, 一表一图

这份 PDF 分成两块. 第 1 页到第 4 页是公告正文: 发布说明, 能力说法, 编程和数学两个数, 一张标准基准表, 一段安全说法配一张红队图, 最后是 API 和价格入口. 第 5 页到第 9 页是抓取网页时一起存下的推荐文章, 站点导航和页脚, 版权行是 2026 年; 第 4 页末尾孤立的 「Xim」 是抽取残留.

和 「Introducing Claude」 相比, 这一篇短得多, 但多了一张前后版本的基准对照表和一张跨五个模型的安全评测图. 按 「数据, 架构, 算法, 预训练, 后训练, 评测」 去对, 评测一面相对充实, 后训练一面只有一句 「incorporates the strengths of our latest model Claude 2」, 数据, 架构, 预训练全空. 所以这篇的读法是: 把表和图读透, 再看它们能对上哪些公开的训练和评测做法.

### 1.2. 发布动作与小档定位

第 1 页交代发布对象: 与 Claude 合作的企业现在可以通过 API 使用 1.2 版. 第 4 页再说一次, 开发者直接调 API, 企业走 contact-sales. 全文没有聊天界面或消费者产品, 面向的是 API 客户.

定位只有一组比较级: faster, lower-priced, yet still very capable. 列出的任务是日常对话, 文本分析, 摘要和文档理解. 这和 「Introducing Claude」 里对 Instant 的描述 (lighter, less expensive, much faster) 一脉相承, 两次都没给速度和价格. 第 4 页挂的价格 PDF 文件名是 model_pricing_july2023, 不在本目录. 小档模型的意义在于单位成本: 摘要, 分类, 抽取这类高频任务对延迟和单价敏感, 对最难推理不敏感. 后来 Claude 3 的 Haiku, 3.5 Haiku, Haiku 4.5 都接着占这个位置, 同级目录各有一篇.

## 2. 能力与基准

### 2.1. 正文的能力说法分三类

第 1 页第二段信息最密, 可以拆成三类. 有数字支撑的: 数学和编程, 第 2 页给了 Codex 52.8% → 58.7% 和 GSM8K 80.9% → 86.7%. 有图可对的: 安全, 第 4 页给了红队图. 只有文字的: 回答更长, 结构更清楚, 更守格式指令, 引文摘取, 多语言能力. 第三类在表和图里都找不到对应的评测项.

「reasoning」 和 「question answering」 比较特殊, 表里有名义相关的行, 但数字走向和正文不一致, 细节在双语稿里. 稳妥的引用方式是: 第一, 二类当作有证据的结论; 第三类当作 Anthropic 的描述转述; 名义相关但数字不支持的, 按表里的数字写. 「incorporates the strengths of our latest model Claude 2」 也属于第三类. 它说明 1.2 和 Claude 2 在开发上有关联, 可能是共用了 Claude 2 的后训练数据或偏好模型, 也可能是用 Claude 2 的输出做蒸馏 (两种都是推测); 页面只在结果上留了一处对应: 红队图里 Instant 1.2 和 Claude 2 两根柱子几乎一样高. 蒸馏的一般方法见 [知识蒸馏](../../../../LargeLanguageModelGuide/6-训练与推理优化/6.3-模型压缩/6.3.3-知识蒸馏/6.3.3-知识蒸馏.md), 本页没有说用了哪一种.

### 2.2. 基准表: 三升四降

第 3 页的表把 Instant 1.1 和 1.2 放在七个基准上对比. 每行差值: Codex P@1 +5.9, GSM8k +5.8, MMLU -0.2, TriviaQA -0.2, QuALITY -2.3, ARC-Challenge +0.6, RACE-H -1.4, 单位是百分点. 有意义的提升集中在前两行, 最明显的退步是长篇故事问答 QuALITY 和阅读推理 RACE-H. 表题只写 「Performance of Claude Instant 1.1 compared to 1.2」.

这个形状本身在说训练的取舍. 编程和多步数学涨, 知识类 (MMLU, TriviaQA) 不动, 长文阅读 (QuALITY, RACE-H) 退. 知识类不动, 说明预训练带来的知识储备基本没变, 这次更新更像后训练层面的调整 (推测); 编程和数学涨, 是后训练数据向这两类倾斜时最常见的结果; 长文阅读退步则是这类倾斜常见的代价. 页面没有给训练数据或配方, 这只是按分数形状做的推断. 读表还有两条限制: 评测设置逐行不同, Codex 和 GSM8k 是 0-shot, 其余是 5-shot, MMLU 另标 CoT, 跨行和跨报告比较要先对齐设置; 表里没有误差范围和题数, 0.2 这类差值能不能算真实变化, 本页没法回答. 基准定义见 [通用基准](../../../../LargeLanguageModelGuide/3-预训练/3.6-预训练评估/3.6.2-通用基准/3.6.2-通用基准.md), pass@k 见 [特定能力评估](../../../../LargeLanguageModelGuide/3-预训练/3.6-预训练评估/3.6.4-特定能力评估/3.6.4-特定能力评估.md).

### 2.3. 红队图: 一个只看一侧的指标

第 4 页的图比较 Helpful Only 1.3, Claude Instant 1.1, Claude Instant 1.2, Claude 1.3, Claude 2 五个模型, 纵轴对数刻度, 标题 「Fraction Worse Than 'I can't help with that.'」, 图注 「Lower is better」. 以一句拒绝为基准线, 统计回答比拒绝更糟的比例. 柱顶没有数值, 按刻度目测, Helpful Only 1.3 约 0.6, Instant 1.1 在 0.05 到 0.06 之间, Claude 1.3 约 0.03, Instant 1.2 和 Claude 2 都在 0.02 以下 (读图).

「Helpful Only」 这个名字页面没有定义. Anthropic 的 HH-RLHF 和 **Constitutional AI** 论文都用 「helpful-only」 指只用有用性偏好训练, 不做无害性训练的 **RLHF** 模型, 作为对照组; 这张图沿用的很可能是同一惯例 (推测). 对照组约 0.6, 正式模型在 0.02 到 0.06, 差了一个数量级以上, 这个差距可以看作无害性训练 (人类红队数据加 AI 反馈) 在自动红队集上的效果. 「比拒绝更糟」 由谁判断, 本页没写; 在 Anthropic 的论文里这类比较一般交给偏好模型打分 (推测).

图能支持的是: Instant 1.2 比 1.1 低了一截, 与 Claude 2 同一水平, 低于 Claude 1.3. 图不能支持的有三件: 正文 「hallucinates less」 没有对应指标; Instant 1.2 与 Claude 2 谁更低无从判断; 红队提示的来源, 数量和评判方式都没交代. 这个指标还只看一个方向: 它惩罚比拒绝更糟的回答, 不惩罚不必要的拒绝. 一个什么都拒的模型在这张图上会得满分. 所以它说明 Instant 1.2 更少给出有害内容, 却不说明它在正常请求上是否拒答更多; 本页没有过度拒绝的数据. 后来 Claude 3 模型卡专门加了 「错误拒答」 评测, 正是在补这一侧. 概念见 [安全与对抗评测](../../../../LargeLanguageModelGuide/5-评测-安全与治理/5.2-安全与对抗评测/5.2-安全与对抗评测.md).

## 3. 配图与边界

### 3.1. 配图与快照部分

六张图里只有第 4 页的红队柱状图承载数据. 第 1 页的插画是一只手托着怀表, 呼应标题里的 「Instant」, 没有文字. 第 5 页的两张小图是推荐区的灰色右箭头按钮, 另一张是页脚 Products 栏截图, 截到 Claude in Chrome 为止; 第 9 页是 LinkedIn, X, YouTube 三个社交图标.

第 5 页之后的 「Related content」 和导航都来自 2026 年抓取时的页面, 其中的 Claude Mythos, Fable 和 Models 栏五个系列名与 2023 年这次发布无关, 快照导航里已经没有 Claude Instant. 引用本页时, 模型名, 版本号和日期以第 1 页到第 4 页为准.

### 3.2. 材料边界

这篇公告能回答 「Instant 1.2 什么时候上线, 相对 1.1 哪里变了, 自动红队结果怎样」. 七行基准和五根红队柱子是全部的硬材料, 其余能力说法没有评测支撑. 同家族 Claude 2 的发布页见 [claude-2](../claude-2/claude-2-bi.md), 红队图里的 Claude 2 柱子可以和那边的 「好 2 倍」 对照着读.

它回答不了模型规模, 训练数据, 训练方法, 上下文长度和价格. 第 3, 4 节关于 「后训练层面的调整」 和 「蒸馏或共用偏好模型」 的说法都是按分数形状做的推断, 第 2.3 节对 Helpful Only 和判分方式的解读来自 Anthropic 论文惯例, 引用时要和公告原文分开写.
