# Claude 2 (2023): 四组分数, 100K 上下文和三篇安全研究

> 源文是 Anthropic 在 2023 年 7 月 11 日发布的产品公告 「Claude 2」, 属于博客式发布页, 不是技术报告. 全文没有公式, 没有表格, 没有参数量, 架构, 训练数据规模或训练流程. 页面给了几组评测分数, 上下文长度, 一项内部红队结果和三个研究链接, 但没有评测设置.

来源: 同目录 `claude-2.md` 与 `claude-2.pdf`, 共 8 页, 配图 3 张 (均在 `images/`). 对照译稿和逐段疑问见 `claude-2-bi.md`. 引用的原文数字和链接以源 md 为准.

## 1. 材料与分数

### 1.1. 材料性质: 十段正文加一段 2026 年页脚

这份 PDF 分成两块. 第 1 页到第 4 页开头是 2023 年 7 月 11 日的公告正文, 截止在 「business who would like to start working with Claude」 那句; 之后是抓取网页时一并存下的 「Related content」 推荐, 站点导航和页脚, 版权行是 2026 年. 后半部分出现的 Mythos, Fable 等模型名和 Claude Code 等产品名, 都不属于 Claude 2 的发布内容.

正文大约十段: 发布说明和考试成绩, 定位与价格, 上下文长度, 编程和数学成绩, 安全评测, 开放地区, 两家企业客户的引语, 使用边界和反馈入口. 和 Claude 1 的公告相比, 这一篇在评测一面有了数字, 在数据一面有了一句 「trained on more recent data」, 在后训练一面有了三个研究链接; 架构和预训练仍然是空的. 第 1 页 「Claude 2」 链接指向 Model-Card-Claude-2.pdf, 模型卡不在本目录, 本文不替它报数.

### 1.2. 相对 Claude 1.3 的四组分数

页面的能力数字全部以 Claude 1.3 为对照. 律师资格考试选择题部分从 73.0% 到 76.5%, Codex HumanEval 从 56.0% 到 71.2%, GSM8k 从 85.2% 到 88.0%. 另有一组没有前后对比的 GRE 成绩: 与申请研究生院的大学生相比, 阅读和写作在第 90 百分位以上, 定量推理与中位数申请者相当. 编程涨了 15.2 个百分点, 律师考试和小学数学分别涨 3.5 和 2.8 个百分点.

这几组数字缺的东西比它给的多. HumanEval 是 164 道 Python 函数题, 按单元测试判对错, 71.2% 大约对应 117 道; GSM8k 测试集 1319 道, 88.0% 约对应 1161 道. 公告没说 HumanEval 是 pass@1 还是多次采样, 没说 GSM8k 用几个 few-shot 示例, 有没有让模型先写推理步骤, 也没讨论这两个公开集是否进了训练语料. 当年社区对 HumanEval 的主要疑虑就是题目在 GitHub 上广泛流传, 分数里可能混进了记忆. 评测口径的一般问题见 [评测科学与证据](../../../../llm-guide/5-评测、安全与治理/5.1-评测科学与证据.md). 能从这组数读出的只有方向: 编程明显变强, 数学和推理小幅提升; Claude 2 在行业里的位置, 页面除了引用 Jasper 的 「go head to head with other state of the art models」 以外没有数据.

## 2. 上下文与安全

### 2.1. 100K 输入, 几千 token 输出和更新的数据

公告把输入和输出长度放在一起讲: 每个 prompt 最多 100K tokens, 能容纳几百页技术文档或一本书; 输出一次能写到几千个 token, 例子是备忘录, 信件和故事. 100K 这个数链接到 Anthropic 更早的一篇博客, 说明 100K 窗口在 Claude 2 之前已经在 Claude 1.x 上推出过, Claude 2 是沿用. 行文把这条和 「improve both the performance and safety」 放在同一句开头, 没解释长度和安全有什么关系.

长上下文靠什么撑起来, 本页没有: 位置编码, 注意力结构, 训练时序列长度是否分阶段拉长, 显存开销都没涉及. 通用路线见 [长上下文与外推技术](../../../../llm-guide/2-核心原理与架构/2.5-长上下文与外推技术/2.5-长上下文与外推技术.md). 数据一面唯一的信息藏在 Sourcegraph 段落: Claude 2 「was trained on more recent data」, 所以知道更新的框架和库; Jasper 的引语也提到 「up-to-date knowledge training」. 截止到哪一天, 语料来源和配比, 公告都没给. 更新预训练语料意味着至少重新做了一轮或续做了预训练, 不只是在 Claude 1.3 上加后训练 (推测), 但 Claude 2 是不是从头训练的新模型, 本页没有.

### 2.2. 安全: 红队评测和三篇研究

安全部分是 Anthropic 自己陈述最多的一段. 内部红队评测的做法是: 一大批有代表性的有害 prompt, 自动化打分, 定期人工核查. 结论是 Claude 2 在给出无害回答上比 Claude 1.3 好 2 倍. 紧接着承认没有模型能免疫越狱. 「好 2 倍」 的分母是什么, 有害率从多少降到多少, 自动打分器是规则还是另一个模型, 页面都没交代; 能肯定的是这套评测已经是 「自动为主, 人工抽检」 的结构, 和后来系统卡里的做法一脉相承.

三个链接按路径分别是 **Constitutional AI**, 大模型道德自我纠正能力, 以及红队测试方法与 Scaling 行为. 把三篇论文的公开内容对上: Constitutional AI 先让模型按书面原则自我批评并改写回答, 用改写结果做 SFT, 再让 AI 按原则比较两个回答, 训练偏好模型后做 RL, 即 RLAIF; 道德自我纠正那篇发现, 经过 **RLHF** 的大模型在被明确要求避免偏见时能减少有偏输出, 这个能力随规模和 RLHF 步数增强; 红队论文比较了不同规模和不同训练方式的模型被攻破的难度, 发现 RLHF 模型随规模变大更难红队, 并公开了约 38,961 条红队攻击记录. 三篇一起指向的训练线是 「人类偏好做 helpful, AI 反馈做 harmless, 红队数据既当评测也当训练素材」. 这是论文层面的对应, 公告没说这些技术在 Claude 2 的流程里各占多少, 也没提 SFT, PPO 或偏好模型的规模. 方法细节见 [Constitutional AI 宪法对齐](../../../../llm-guide/4-后训练/4.4-对齐技术/4.4.3-RLAIF/01-Constitutional-AI-宪法对齐/01-Constitutional-AI-宪法对齐.md), [RLAIF](../../../../llm-guide/4-后训练/4.4-对齐技术/4.4.3-RLAIF/4.4.3-RLAIF.md), [PPO](../../../../llm-guide/4-后训练/4.4-对齐技术/4.4.1-基于奖励模型的RL-RLHF-PPO/04-PPO/04-PPO.md) 和 [安全与对抗评测](../../../../llm-guide/5-评测、安全与治理/5.2-安全与对抗评测.md).

## 3. 开放方式与边界

### 3.1. 开放方式, 价格和使用边界

Claude 2 同时走两条渠道. API 面向企业, 价格与 Claude 1.3 相同, 页面说已有数千家企业在用; 新网站 claude.ai 上的公开 beta 面向普通用户, 美国和英国的任何人都能注册, 其他地区填表申请. 对比 Claude 1 那次 「从伙伴扩大到申请制」, 这次是普通用户第一次能直接注册. 同价换代意味着 Anthropic 把 Claude 2 放在 Claude 1.3 原来的档位上, 轻量档仍由 Claude Instant 占着, 同级目录的 Claude Instant 1.2 一篇接着讲.

公告的使用提醒有三条: 和 AI 助手对话需要摸索, 附一份 prompt 设计技巧; Claude 和所有现有模型一样可能生成不当回答; 最适合总结, 整理信息这类日常场景, 不应用于涉及身心健康的场合. 这属于面向大众开放时的免责说明. 公开 beta 本身也是一种大规模评测: 数以万计的真实对话会暴露内部红队覆盖不到的失败方式, 但公告没说 claude.ai 的对话是否用于训练.

### 3.2. 两家客户引语和三张配图

Jasper 是生成式 AI 内容平台. Anthropic 转述他们的发现: Claude 2 在多种用例上能和其他领先模型正面较量, 长文本, 低延迟场景尤其强; 工程副总裁 Greg Larson 列了四点好处: 语义理解更强, 知识更新, 复杂 prompt 推理更好, 上下文窗口大 3 倍. Sourcegraph 的编程助手 Cody 靠 100K 窗口传入更多代码库上下文, 并受益于更新的训练数据. 两段引语一个偏写作, 一个偏编程, 正好对应长输出和 HumanEval 两项主打能力, 都没有延迟, 准确率或用户量数字.

三张配图里只有一张属于正文: 第 1 页的装饰插画, 陶土橙底色上黑色弧线勾出朝右的人头侧影, 中心白点向外放射出八根带圆点的连线, 不含数据. 另外两张是网页小图标: 第 4 页 `p04-ai.png` 是 「Read more」 旁的向右箭头, 第 8 页 `p08-image.png` 是页脚的 LinkedIn 图标. 和 Claude 1 公告里的 Poe 截图, 合同截图不同, 这一次没有产品界面, 能力说明全靠分数和引语.

### 3.3. 材料边界

这篇公告能回答 「Claude 2 比 Claude 1.3 强在哪, 怎么用, 多少钱, 谁在用」. 引用它的数字时要注明对照对象是 Claude 1.3, 评测口径以公告原句为限. 它回答不了 Claude 2 的规模, 架构, 训练数据截止与配比, 长上下文的实现, 以及完整评测设置.

后训练一面, 能说的是 Anthropic 把 Constitutional AI, 道德自我纠正和红队研究列为用过的安全技术, 第 2.2 节给出了这三篇论文各自的机制; 不能进一步写成 「Claude 2 的训练配方是 X 步 SFT 加 Y 步 RLAIF」. 想看更完整的评测和训练说明, 下一站是公告链接的 Claude 2 模型卡, 以及同级目录的 Claude 2.1 和 Claude 3 两篇.
