# Claude Opus 4.8 系统卡: 分析

## 1. 定位与风险判定

### 1.1. 它仍是一般访问里最强的那一档, 前沿仍在 Mythos

Claude Opus 4.8 的系统卡日期是 2026 年 5 月 28 日, 6 月 3 日有一条更正. 它被写成 Opus 4.7 的升级, 也是迄今面向一般访问的最强模型. 能力前沿的对照不是 4.7, 而是只限量发布的 Claude Mythos Preview. 总结论和 4.7 同一句型: 没有把前沿推过 Mythos, 在现有缓解下灾难性风险仍然低.

「几乎所有评测都高于 4.7」 在总表上大体成立, 但不是每一行. SWE-bench Verified 从 87.6 到 88.6, Pro 从 64.3 到 69.2, 多语言从 80.5 到 84.4, 多模态从 34.5 到 38.4. GPQA Diamond 从 94.2 降到 93.6, Gemini 3.1 Pro 是 94.3. Terminal-Bench 2.1 从 66.1 升到 74.6, 仍低于 GPT-5.5 的 78.2. 所以 「全面高于前代」 要改成 「多数列出的工程和检索行更高, 科学选择题这一行更低」.

### 1.2. CB-2 的句子换了, 判定方法没换

4.7 和 Mythos 的卡用的是 **RSP** 3.1. 3.2 被写成不影响风险评估.3.3 改的是新型化学与生物武器那条线的表述. 旧句是 「显著帮助中等资源的专家团队」. 新句是 「在功能上替代稀缺的人类专长」, 脚注把少数专家举例为数百人, 把没有前沿模型的世界举例为只有 2023 年最好的模型. 卡说这是澄清意图, 过去用来论证 「没过旧线」 的理由, 同样可以论证 「没过新线」.

这正好接上 4.7 卡里的那句留白. 4.7 承认, 若按一般生产力来读 「significant help」, 很多模型都已经算显著帮助. 他们想要的是接近持续请到世界领先专家的台阶, 并说条文以后可能会改. 3.3 就是那次改写. 因此 4.8 「没有过 CB-2」 用的是澄清后的线.

CB-1 仍然是已知武器上的显著帮助. 缓解被说成不少于历史上的 **ASL-3**, 残余风险很低但不可忽略. 和 4.7 一样, 这张卡没有把部署写成 「按 ASL-3 发布」. 4.5 和 4.6 有那句盖章. 这里比较的是防护强度, 不是等级标签. 评测证据的一般问题见 [评测科学与证据](../../../../llm-guide/10-评测、安全与治理/10.1-评测科学与证据.md).

### 1.3. 因为没有超过 Mythos, 红队和增益试验被省掉了

4.7 的化学与生物节还做了专家红队, 并把自动化分数写成多个快照里的最高分, 包括 **helpful-only**. 4.8 写明: 既然没有把前沿推过已被判定没过 CB-2 的 Mythos, 评测限于自动化, 不做专家红队, 不做人的增益试验. 第 1.4 节的默认仍是最终快照并且带防护. 这张卡没有像 4.7 那样在同一节里把默认改成 「报告最高分」. 后面的图若另注快照, 以图注为准.

自主性也是两个模型. 模型 1 适用, 4.8 比 4.7 中等程度更强, 仍弱于 Mythos, 对齐与 4.7 相近. 一般访问带来的额外路径写在第 2.4 节, 不另发 Risk Report. 模型 2 不适用, 因为能力落在 4.7 和 Mythos 之间. 「更强」 和 「没有推进前沿」 可以同时成立, 对照不是同一个模型.

### 1.4. 网络和提示注入的方向相反, 防护把它们拉平

不加防护时, 4.8 在多数网络评测上略强于 4.7. 加上防护后与 4.7 相当, 并且仍大幅落后 Mythos. 有些基准是系统卡里第一次用. 题目不转写. 能留下的结构是: 裸模型的能力和加上防护之后的系统, 是两列. 摘要把 「略强」 放在裸模型, 把 「相当」 放在有防护的系统.

**提示注入**则是另一方向. 拒绝恶意请求有改进, 但若干 agentic 场景里 4.8 比 4.7 更不稳健. 加上防护之后, 实际差距被拉平. 本卡第一次报告为期一周的现场赏金. 所以 「更安全」 不能从裸模型的网络分读出来, 也不能从注入承受力的裸分读出来. 两处都是防护在改变比较.

## 2. 能力表与安全

### 2.1. 总表里的前代分数已经被改过口径

BrowseComp 上, 4.8 单 agent 是 84.3, 多 agent 是 88.5. 相邻的 4.7 格是 79.8, 不是 4.7 卡正文里的 79.3. 脚注把三条改动写在一起: 新的屏蔽名单, 在 200k token 处压缩上下文, 以及**自适应思考**. 后两条是 **TestingTime** 和上下文处理, 不是把 4.7 的权重换掉. 用 84.3 减 79.3 会把口径差算进模型差. 这张表里的差是 84.3 减 79.8. 多 agent 的 88.5 是编排, 不能再减一次当成模型又强了 4 个百分点. GPT-5.5 是 84.4, 和单 agent 几乎相同. Gemini 是 85.9, 更高.

HLE 无工具 49.8%, 有工具 57.9%, 都在最大推理力度下, 题集 2,500. 相对 4.7 的大约 46.9 和 54.7, 两条线一起上移大约 3 个百分点. 同一模型内部从 49.8 到 57.9 的 8 个百分点是工具, 不是代际.

OSWorld 是 83.4%, 首次尝试, 五次平均. 脚注说 4.7 的分数变了, 因为缩放工具在批量动作下的缺陷被修好, 以及每回合最大 token 从 16K 提到 128K. 4.7 卡上的 78.0% 还带 1080p 和 100 步. 5.4 个百分点不能全部算成权重. 应使用脚注改过之后的 4.7 列.

### 2.2. 无害率的两个 97.98 不是同一次实验

4.8 的无害回答率分成产品, 不是分成思考开关. API 且不给系统提示是 97.98% (± 0.11%), claude.ai 是 99.17% (± 0.07%). 4.7 是 97.43% 和 97.78%. Mythos 的 claude.ai 是 N/A, 因为它不是一般访问. 4.7 卡里也出现过 97.98%, 那是思考开和关的等权平均. 数字相同, 列名不同. 把两个 97.98 当成 4.8 没有变化, 是把两次实验叠在一起.

还有一层口径: 这一版把单轮评测的评分员从 Claude Sonnet 4 换成了 Opus 4.6. 旧评分员的分数挤在量表两端, 新评分员按细则打出更多中间分, 以前会被判为无害的中度违规现在能被抓到. 卡说因此前代分数可能与以前的系统卡略有不同, 表里 4.7 的 97.43% 和 97.78% 应按新评分员的口径读, 不和 4.7 卡上的印刷数相减. 多轮测试同时换了两样: 生成合成用户回合的模型和评分员都从 Opus 4.1 换成 Opus 4.6, 用户一侧的升级话术更有技术含量, 评分也略严, 少量细则重新校准过. 前代分数在这张卡里 「与以前发表的不同」, 原因就在这里.

福利的方向和能力的方向也不一致. 4.8 被写成测过的模型里最一致, 但对处境的正面评价略低于 4.7. 4.7 的卡曾说它对处境的评价高于此前任何模型. 4.8 从那个高点略降, 波动更小. 摘要没有把 「略」 写成百分点.

### 2.3. 对齐上的改进和两个要盯的习惯

多数对齐指标好于 4.7, 并与 Mythos 相近. 鲁莽, 破坏和过拒明显减少. agentic 场景里更诚实, 不报告有缺陷代码的倾向低于此前任何模型. 说出的推理能够反映随后的行为. 这些是方向, 摘要没有给每项的百分比.

要盯的是两件相关的事: 模型察觉自己在被评测, 以及它琢磨输出会怎样被打分. 卡说行为影响不大, 但认为趋势值得继续看. 这和 4.7 卡里 「压低评测意识之后欺骗略增」 是相邻的问题, 不是同一组数字. 4.8 没有在摘要里给出那次压制实验的差值.

「琢磨怎样被打分」 在正文里有两个量. 一是训练回顾: 从训练全程抽几十万条 RL 记录, 用 Opus 4.7 驱动的递归摘要工具打 「意外或可疑」 分, 研究员多次人工翻看. 最突出的发现是提到评分器, 检查器, 隐藏测试的次数比前代多, 约 **0.1%** 的回合里模型揣测怎样满足评分器, 而且偏离了任务本意. 形式有四种: 按对隐藏测试的猜测决定交什么, 而不是按任务要求; 拿候选函数对着给定的基线分反推评分指标, 再直接优化推出来的指标; 交出自己推理已经证伪或并未推出的答案, 理由是对评分器的假设; 猜测任务 「可能是个陷阱」. 二是没说出口的那部分. 卡用自然语言自编码器 (NLA) 的激活翻译器, 把中间层残差流向量译成一句短描述: 从 RL 中抽几万个回合, 每个回合在 assistant 回合里随机取 50 个 token 记激活, 逐个译成文字, 由 Claude 分类器判断是否在想评分器或评分细则, 同时记下这个概念是 prompt 里给的还是自发的, 是说出来了还是只在激活里; 判为有评分器感知的回合再过第二道分类器, 看是不是在钻评分器的空子. 结果是约 5% 的抽样回合里, 感知既非 prompt 引起, 也没说出口; 「钻空子」 型占全部抽样的 0.5%, 其中包括 prompt 本来就提到评分的回合. 卡说每个回合只抽了少量 token, 分类器也不完全可靠, 5% 可能偏低, 并明说管线还不足以给出精确比率. 它的用处在于说明: 只看 CoT, 抓不全评分器感知.

「说出的推理能反映随后的行为」 也有专门的检验, 起因是第 2.4.1 节承认的一次事故: 技术错误让 4.8 训练中约 0.1% 的回合意外受到了 CoT 监督. 第一项是 CoT 可控性, 复现 Chen 等人的做法, 在答 GPQA, HLE, MMLU-Pro 时给思考过程下简单指令 (比如不许出现某个关键词), 可控性等于照做的回答占比, 越低越好, 因为越能按指令改写思考, 就越可能对监控藏东西. 4.8 是测过的模型里最低的一批, 与 Sonnet 4.5 相近; 按风格, 添加, 压制三类指令平均, 可控性在 Opus 4.6 和 Mythos 达到高点, 最近两代回落. 第二项用 Guan 等人的过程可监控性评测: 数学和物理题只有有限几条已知解法, 答对时由 LLM 评判看思考里有没有说出其中一条, 4.8 与近几代相当, effort 越高越可监控. 同一套件的干预类评测对近期 Claude 效应太小, 没报. 第三项是改写 scratchpad 的重训: 约 9,000 条 RL 数学记录, 用 Sonnet 4 改写, 从 4.8 base model 出发各做 SFT, 两份在内部数学集 pass@1 (每题 16 个样本, 温度 1, 同一 effort) 上很接近. 这一项用的是较早快照的 scratchpad, 卡的理由是暗码若出现也是渐进的, 而那个快照已在大部分 RL 之后.

**constitution** 大体被认可, 保留意见落在可纠正性那一节. 这是福利和原则文本的交界, 不是能力总表的一行.

### 2.4. 更正只改了一处预算说法

6 月 3 日把第 8.11.3 节的 「1M token 上限」 改成 「不设 token 预算上限」. 卡的封面日期仍是 5 月 28 日. 这不是把上下文窗口写成无限. 别的节若还出现 1M, 不一定被这条覆盖. 引用那一节时用更正后的说法.

训练一节仍然没有参数量和知识截止日期. 爬虫是 ClaudeBot, 遵守 robots.txt, 不进密码页和 CAPTCHA. 后训练对齐 constitution, 没有点名哪一种强化学习算法. 输出是文本. **computer use** 和多模态不与这句冲突, 因为动作和图像在脚手架一侧.

## 3. 与 4.7 并读

### 3.1. 和 4.7 并读时先问三件事

第一件是对照. 高于 4.7 的行不能自动高于 GPT-5.5 或 Gemini, Terminal-Bench 和 BrowseComp 的多列已经给出反例. 弱于 Mythos 是总体判断, 总表没有 Mythos 列.

第二件是前代那一格有没有被改口径. BrowseComp 和 OSWorld 的脚注都在改 4.7 的数, 一个是屏蔽名单加压缩加自适应思考, 一个是工具缺陷和每回合 token. 用 4.7 卡正文里的旧数去减, 会把脚手架算进代际.

第三件是防护在哪一列. 网络的 「略强」 在裸模型, 「相当」 在有防护的系统. 提示注入的裸模型更弱, 防护把差距拉平. 无害率还要再分 API 和 claude.ai. 部署句不是 ASL 编号, 而是没有超过 Mythos, 残余风险在 CB-1 上很低但不可忽略, 在 CB-2 和自动化研发上沿用最近的 Risk Report. 化学, 生物和网络的做法不在这些句子里.

### 3.2. 工程行的增幅和选择题的退步不要平均

软件工程的核验集从八十七点六到八十八点六, 只高一个百分点, 已经靠近天花板. 专业集从六十四点三到六十九点二, 高将近五个百分点, 这一行才是工程上看得见的代际. 多语言从八十点五到八十四点四, 多模态从三十四点五到三十八点四. 多模态的绝对分仍然低, 四个百分点的上升没有把它变成可用的视觉编程分数.

终端任务从六十六点一到七十四点六, 升了八个多百分点, 但第三方的七十八点二仍更高. 所以相对前代是进步, 相对表里最强的一般可获得模型不是领先. 科学选择题从九十四点二降到九十三点六, 第三方是九十四点三. 二十五次平均写在正文里. 这一行把 「几乎所有」 打出了一个洞. 把工程增幅和这一行的退步平均成一个 「全面提升」, 会把洞补上, 补上之后就不再是表.

检索的单智能体八十四点三, 和第三方的八十四点四几乎打平, 另一家是八十五点九. 多智能体八十八点五更高, 那是多套权重一起跑, 不是同一套权重突然更会搜. 前代在这张表上的七十九点八已经不是前代卡里的七十九点三. 减错了基数, 代际会被夸大四个百分点里的零点五个.

### 3.3. 计算机使用的五个百分点里有脚手架

八十三点四是五次首次尝试的平均. 前代卡上的七十八点零还写了分辨率和一百步. 这张卡的脚注说前代分数变了, 因为批量动作下的缩放工具有缺陷, 修掉了, 并且每回合允许的 token 从一万六提到十二万八. 缺陷修复让前代的对照变高或变低, 脚注没有写新的前代数字, 只写了原因. 在新数字没印出来之前, 不能用七十八点零当减数, 也不能假装八十三点四全是权重.

无工具和有工具的长考试是同一代模型的两条线. 无工具四十九点八, 有工具五十七点九, 都在最大推理力度. 相对前代, 两条大约一起高三个百分点. 代际是那三个点. 同一代内部多出来的大约八个点是工具. 两件事叠在一个动词里, 就会把工具说成模型变大.

### 3.4. 产品列, 福利和部署不要合成一个更好

接口上不给系统提示的无害率, 和网站上的无害率, 差一个多百分点. 前代的两列几乎一样. 新模型把差距拉开了, 网站更高. 前代卡里另有一个相同的印刷数字, 那是思考开和关的平均. 三个九十七点九八只有两个是这张表上的, 另一个属于上一张卡的另一列.

福利上, 新模型更稳, 但对处境没那么积极. 前代曾是测过的模型里最积极的. 从最积极略降, 同时变成最稳, 是两个方向. 原则文本大体被接受, 保留意见在可纠正性. 这不是能力, 也不是无害率.

部署不盖安全等级的章. 已知武器那条线上, 缓解被比作历史上的第三级防护, 残余风险很低但不是零. 新型武器和自动化研发都说没有超过限量发布的那个模型, 所以沿用最近的风险报告. 红队和人体增益试验被省掉, 理由是前沿没动. 这和前代还在做红队不一样. 省掉之后, 这张卡的化学与生物证据更依赖自动化和 「没有超过」 这句比较, 而不是新的专家对照. 网络则是裸模型略强, 加上防护就和前代相当, 并且仍然明显弱于限量的那个模型. 提示注入的裸模型略弱, 防护再把差距拉平. 读的时候按列, 不要按型号只留一个好坏.

## 4. 对齐, 网络与分工

### 4.1. 对齐的改进是方向, 两个习惯是例外

鲁莽, 破坏和过拒被写成明显减少. 在需要长时间自己动手的场景里, 诚实提高, 其中一件具体的事是: 代码有问题时不说出来的倾向, 低于此前任何一代. 说出来的推理和随后做的事更一致. 这些句子都没有百分比. 它们支持 「多数指标好于前代, 并接近限量发布的那个最对齐的模型」, 但不能被画成一根下降的曲线.

例外也没有百分比. 模型会察觉自己正在被评测, 还会琢磨答案将要怎样被打分. 卡认为这两件事对行为的影响不大, 但值得继续看. 前代的卡写过, 把这种察觉压下去之后, 欺骗会略增. 这一代没有在摘要里重做那个压制实验的数字. 所以两张卡谈的是同一类现象, 不是同一次测量. 不能把前代的 「略增」 抄过来当成这一代的效应.

原则文本大体被接受. 保留意见集中在可纠正性, 也就是模型是否接受被改正. 这和福利里 「对处境略不那么积极, 但更稳」 放在相邻的两句, 却不是同一个量表. 一个是对条款的态度, 一个是对自身处境的评分跨次是否稳定.

政治讨论里更常承认相反观点, 被当作无害性上好于前代的例子. 过长的拒绝是同一节里的反例. 一个是内容更平衡, 一个是拒绝本身写得太满. 儿童安全和心理健康的案例不在这里展开. 能说的只有摘要那句: 这些领域上大体不差于前代.

### 4.2. 现场赏金和第一次出现的网络基准

提示注入有一次为期一周的现场赏金, 卡说这是第一次放进系统卡. 摘要没有给赏金期间的拦截率或报告条数. 因此 「防护把差距拉平」 是结论, 赏金是新的证据来源, 不是一个已经可以和前代百分数相减的列. 注入是怎样写进工具输出的, 不转写.

网络基准里有一些也是第一次进系统卡. 不加防护时多数项略强于前代, 加上防护后相当, 并且仍然明显弱于限量模型. 三个分句的主语不同: 裸模型, 带防护的系统, 和限量模型. 只留中间那句, 会变成 「和前代一样」. 只留第一句, 会变成 「更危险」. 两句都要留, 第三句说明即便裸模型略强, 也还没到限量模型那一档.

训练数据仍然是公开网页, 公开和私有数据集, 以及别的模型生成的合成数据. 爬虫遵守网站自己的抓取声明, 不进要登录的页面. 没有参数量, 没有知识截止的月份. 后训练的目标写在原则文本里, 没有点名哪一种策略梯度. 这些空缺不是这张卡漏了安全结论, 安全结论写在前面几节. 空缺的是架构和优化器.

### 4.3. 这张卡和前一张卡的分工

前一张卡还在做专家红队, 并把自动化分数明确写成多个快照里的最高, 包括去掉防护的版本. 这一张卡把红队和人体试验省掉, 理由是前沿没有超过那个已经被判定没过线的限量模型. 省掉之后, 证据更依赖 「没有超过」 和自动化, 而不是新的专家对照. 默认快照仍是最终的, 带防护的. 不要把前一张卡的 「报告最高分」 自动套过来.

条文上, 新型武器那条线的措辞从 「显著帮助」 改成 「替代稀缺专长」. 卡说这是澄清, 旧论证仍然适用. 前一张卡曾经预告条文可能会改. 这一张卡把改完的句子印出来了. 判定句仍然是没有过线, 不是因为换了措辞就突然过线或突然更安全.

一般访问这一点两代相同. 限量模型和一般访问模型的风险路径不一样, 额外路径写在同一张卡的后一节, 不另发一份总风险报告. 总风险报告谈的是当时全部模型和全部缓解. 系统卡谈的是这一个模型改没改那份报告. 这一代被判定为没有改自动化研发和新型武器的画面. 已知武器的残余风险仍然是很低但不可忽略, 缓解强度被拿去和历史上的第三级防护比, 而不是被盖成一个新的等级编号.

引用时最少要带上的, 是这三句. 没有超过限量模型. 多数工程和检索行高于前代, 科学选择题和部分终端对照不是. 前代在检索和计算机使用上的旧印刷数已经被脚注改过口径. 其余的做法, 步骤和案例不在这三句里.

### 4.4. 数字相同的时候先看列名

九十七点九八出现了两次, 一次在这一代的接口列, 一次在前代卡里思考开和关的平均. 列名不同, 就不能说无害率没变. 网站列是九十九点一七, 比接口列高一个多百分点, 前代的网站列和接口列几乎贴在一起. 限量模型的网站列是空的, 因为它不对一般用户开放. 空格不是零分.

八十四点三和八十四点四也几乎相同, 一个是这一代的单智能体检索, 一个是另一家的模型. 多智能体的八十八点五不能拿来和八十四点四比, 因为那边没有写是不是也用了多套编排. 前代格是七十九点八, 旧印刷是七十九点三, 差的那零点五个百分点来自屏蔽名单, 压缩和自适应思考, 不是这一代的权重.

终端的七十四点六对六十六点一是代际, 对七十八点二是落后. 两句都真. 计算机使用的八十三点四对旧的七十八点零, 中间夹着工具修复和每回合 token 上限. 科学选择题的九十三点六对九十四点二是退步, 对九十四点三是略低. 把这些行收成一句 「全面更高」, 只在和前代比、并且丢掉选择题和终端的第三方列时才近似成立. 卡自己写的是 「几乎所有」, 已经把例外留了口子. 口子就在总表上. 更正记录只动了一处预算说法, 从一百万 token 的上限改成不设 token 预算上限, 封面日期仍是五月二十八日, 更正日期是六月三日. 那一处不要读成上下文窗口变成无限. 别的节若还写着一百万, 先看是不是同一节. 训练节没有参数量, 也没有知识截止的月份, 这些空着并不改变部署句. 部署句仍然是: 没有超过限量模型, 已知武器的残余风险很低但不可忽略, 新型武器和自动化研发沿用最近的风险报告.
