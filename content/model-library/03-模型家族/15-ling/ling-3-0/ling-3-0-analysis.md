这是 Hugging Face 上 Ling-3.0-flash 的模型卡, 不是技术报告.

## 1. 127B 和 124B 不是一格

侧栏模型大小是 127B, 张量类型 **F32 · BF16**, 下载量 16,399. 导语和规格表写总参数 124B, 激活参数 5.1B. 127 减 124 等于 3. 卡上没有解释这 3B.

5.1B 是激活参数, 和 124B, 127B 都不是同一个数. 表的 Size 行把本模型写成 **124B-A5.1B**.

## 2. 12.4% 和 8.1% 各除一个数

导语说 124B 和 5.1B 大约是 Ring-2.6-1T 的 12.4% 和 8.1%. 表里 Ring-2.6-1T 写成 **1T-A63B**. 124/1000 等于 0.124. 5.1/63 约 0.081. 前一个除总参数, 后一个除激活参数.

这页没有出现 Ring-1T 的约 50B. 不能用那一篇的激活参数来代这里的 63B.

## 3. 1/64 是专家计数, 不是 5.1/124

规格表: 路由专家 512, 共享专家 1, 激活专家 8. 8/512 正好是 1/64, 和导语的 sparse MoE 一致. 共享专家不在这 512 里, 每个 token 还会用到它.

5.1/124 约 4.1%. 这是算出来的参数占比, 卡上没有印. 它也不等于 1/64.

层数写成 35 个 KDA 加 7 个 Gated MLA, 35:7 正好是 5:1. 稠密层另有一行 2. 表没有写这 2 层是否已经算进 42 层. 隐藏维 2560, 头数 32. 专家中间维 768, 稠密中间维 6144, 词表 157184.

## 4. 窗口和思考模式是两件事

上下文训练日程是 8K 到 32K 再到 256K. 部署段印的上下文长度是 262144, 等于 256×1024. 这是窗口长度, 属于部署前把窗口拉长.

思考模式默认打开. 推荐温度被印成 「0. 6」, top_p 被印成 「0. 95」, top_k 是 20. 小数点后的空格是抓取拆开, 不是两个推荐值. 默认打开思考模式是推理时多算, 也就是 TestingTime.

## 5. 组件和表对得上的三格, 对不上的两格

组件上 SWE-Bench Pro 56.6, AIME 2026 93.2, SWE-Bench Multilingual 72.4, 和大表同名格一致. HMMT Feb 2026 的 87 和 HLE 的 22.7 在大表里没有同名行.

大表里 flash 不是每一行第一. SWE-Bench Multilingual 72.4 低于 MiniMax-M2.7 的 76.5. Terminal-Bench 2.1 57.0 低于 Deepseek-V4-Flash 的 62.0. AIME26 93.2 低于 Ring-2.6-1T xhigh 的 95.8. MCP-Atlas 65.5 低于 69.0. SkillsBench 44.8 低于 53.5. IFBench 74.5 低于 79.2.

## 6. 合集, 衍生和这张卡的边界

Ling 3.0 Collection 写 20 items, 更新时间是 about 20 hours ago. 这张卡是其中的 flash. 模型树是 4 个微调和 44 个量化, Space 21 个. 20, 4, 44, 21 是四种计数, 不能加在一起当成一个名单.
