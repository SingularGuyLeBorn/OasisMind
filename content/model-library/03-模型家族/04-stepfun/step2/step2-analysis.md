# Step-2: WAIC 2024 上的万亿 MoE 正式版, 连同 Step-1.5V 和 Step-1X 一起发布

> 公开材料是阶跃星辰官方微信通稿抓取 `step2.md`(约 7 页, 6 图, WAIC 2024), 不是带式号的技术报告. 正文只写 Step-2 万亿 MoE 正式版, Step-1.5V 千亿多模态, Step-1X DiT 三档, 一张对照评测表, C 端产品与行业合作名单. 没有层宽, 专家池, 路由公式, 预训练 token 量, 后训练课表或消融. 架构细节通稿没有写.

来源: 同目录 `step2.md`(页标记 `page 1 of 7`–`page 7 of 7`). 对照译稿见 `step2-bi.md`. 原文链接 https://mp.weixin.qq.com/s/zgm745w_Gk3oBngPDdLb3w. 数字与型号名回源 md; 页 3–5 现场配图不 OCR 造分.

这篇通稿要回答的产品问题很窄: WAIC 当天 Step 家族公开了哪三款; Step-2 相对 GPT-4-1106 / Claude 3 Opus / Llama3 70B Chat 表内高低如何; C 端「跃问」「冒泡鸭」与金融 / 影视 / 游戏合作落在哪. 它不重讲稀疏路由或扩散去噪公式. MoE 一般讨论见 [MoE 总览](../../../../llm-guide/2-核心原理与架构/2.6-MoE/2.6-MoE.md); DiT 背景见 [01-视频生成与DiT架构](../../../../llm-guide/8-多模态/8.6-视频生成模型/01-视频生成与DiT架构/01-视频生成与DiT架构.md); 多模态总览见 [8-多模态](../../../../llm-guide/8-多模态/8-多模态.md); 视频理解入口见 [8.4-视频理解模型](../../../../llm-guide/8-多模态/8.4-视频理解模型/8.4-视频理解模型.md).

## 1. 三款新品

### 1.1. 谱系位置: 三月亮相后约 100 天的三产品同发

页 1 把时间放在 WAIC 2024 揭幕现场, 并回溯「今年三月」首次公布 Step 系列. 同段给出跨度口号: 约 100 天内从千亿参数到万亿参数, 从语言模型到多模态, 从理解到生成. 三款同日首发物写得很清楚: Step-2 万亿参数语言大模型正式版; Step-1.5V 多模态大模型; Step-1X 图像生成大模型. **读法应落在「同一发布日的产品矩阵」, 别把三款糊成一个 checkpoint.**

通稿后半转向 C 端与生态, 不再补充中间版本号或训练阶段名. 开放平台入口是 https://platform.stepfun.com; 消费面是跃问 https://yuewen.cn 与冒泡鸭 https://maopaoya.com. 选型时合理动作是: 把语言底座能力锚在 Step-2 与页 2 表, 把多模态理解锚在 Step-1.5V 的定性句, 把文生图锚在 Step-1X 三档, 三套不要混成「一个万亿模型包办一切」.

### 1.2. Step-2: 万亿 MoE 口号与表内对照怎么读

页 1–2 对 Step-2 的架构披露极短: 源文写「创新的 MoE」架构(专名保留 MoE), 万亿参数, 系统能力抬训练效率, 体感在数学 / 逻辑 / 编程 / 知识 / 创作 / 多轮对话上「全面逼近 GPT-4」. 可申请体验的通道写到开放平台. 没有专家数, 没有每 token 激活规模, 没有共享专家或负载均衡损失. **MoE 的总参和每 token 激活是两个数**, 前者决定要放下多少权重, 后者决定每步算多少; 这篇通稿只给了前者, 只能记下公开口号是万亿级 MoE 语言模型. 稀疏激活的一般读法见上文 MoE 单独成篇, 不要把单独成篇里的 DeepSeek / Mixtral 拓扑安到 Step-2 头上.

页 2 表是全文唯一可复制的评测块. Step-2 一行: LIVEBENCH 44.1, ARENA_HARD 68.1, MTBENCH 8.9, VICUNA(v.s. gpt-4o) 48.3, AGIEVAL 69.5, BBH 89.4, DROP 86.0, GSMBK 94.0, MATH 68.4, MMLU_PRO 63.0, MMLU_TEST 82.9, HUMANEVAL 84.1. 相对 GPT-4-1106, 综合三项与知识 / 编程若干格并未全胜; 对战胜率, 考试, 逻辑与数学若干格更高. 相对 Claude 3 Opus, LIVEBENCH 51.0 与 GSMBK 95.0 仍高于 Step-2. 标题「全面逼近国际主流模型」**应读成多能力面接近, 不要改写成逐格碾压**. 表头 `GSMBK` 全篇未改正或加脚注, 引用须保留源文拼写.

### 1.3. Step-1.5V 与 Step-1X: 理解侧升级, 生成侧 DiT 三档

Step-1.5V 写成千亿参数多模态, 图像感知理解全面提升, 并具备视频理解: 识别物体 / 人物 / 环境, 把握氛围与情绪. 推理增强句绑在「Step-2 万亿参数大模型的加持下」, 举例是看图解题, 写代码, 作诗. 另强调从图像理解到视频理解的短周期跨越. **这些是能力菜单, 不是接口图**: 视觉编码器名, 帧采样, 与语言骨干是否同干, 通稿都没写. 视频理解的一般问题意识见 [8.4-视频理解模型](../../../../llm-guide/8-多模态/8.4-视频理解模型/8.4-视频理解模型.md); VLM 接口形状见 [8.2-视觉语言模型](../../../../llm-guide/8-多模态/8.2-视觉语言模型/8.2-视觉语言模型.md).

Step-1X 写成推动「多模态理解和生成统一」路线上的进展, 架构标签是全链路自研 **DiT**(Diffusion Models with transformer), 参数档 600M, 2B, 8B. 卖点是更强语义对齐与指令跟随, 以及中国元素 / 文化优化; 另有中国动画 IP 的视频生成展示. 三档没有默认推荐, 没有 patch size / 采样步数 / 条件注入细节. DiT 用 Transformer 替换扩散 U-Net 骨干的背景见 [01-视频生成与DiT架构](../../../../llm-guide/8-多模态/8.6-视频生成模型/01-视频生成与DiT架构/01-视频生成与DiT架构.md); 本通稿只借用名称与三档规模, 不提供可复现配方.

## 2. 产品生态与材料边界

### 2.1. 产品与生态: 跃问, 冒泡鸭, 垂直合作, 繁星计划

页 5 起进入应用面. 跃问主打图内文字 / 数据 / 图表理解, 以及创作, 逻辑推理, 数据分析. 冒泡鸭主打开世界叙事: 探索故事, 创作角色. 金融侧与界面财联社合作 AIGC 资讯 / 投研 / 投顾, 并联合国泰君安推出「君弘灵犀」, 通稿自称业内首个千亿级参数多模态证券垂直模型, 强调融入客户智能化服务体系. 内容侧与上海电影做《大闹天宫》互动体验与《葫芦兄弟》视频生成展示, 并点名中文在线, 中国知网. 消费娱乐侧与 YAHAHA Studios 探索 AI+3D 无代码 / UGC 引擎.

页 6 收束到开放平台「繁星计划」: 扶持多模态初创与独立开发者. 页 3 CEO 姜大昕原句把万亿参数规模说成 AGI「基础门槛」, 把多模融合说成「必经之路」, 并提「十倍每个人的可能」. **这是管理层叙事, 页 2 评测表并不证明该门槛.** 页 3–5 四张现场图占视觉主篇幅, 正文未把图内分数转录成表; 读的时候以文字段与页 2 表为准.

### 2.2. 材料边界: 这篇通稿能回答什么, 不能回答什么

它能稳定回答的问题很短: WAIC 2024 同日三款新品名称与公开规模口号; Step-2 页 2 表相对三家对照的格内高低; Step-1.5V 的视频理解与「Step-2 加持」定性; Step-1X 的 DiT 标签与 600M / 2B / 8B; 跃问 / 冒泡鸭入口; 金融, 影视, 游戏合作点名; 繁星计划与开放平台 URL; 三月到约 100 天的公关时间线. 页数 7, 图数 6, 都在源 md 页标记与 `images/` 文件名里可核对.

它不能回答的同样清楚: Step-2 的层数, 专家池, 每 token 激活, 路由与训练效率的可复现定义; Step-1.5V 与 Step-2 是否共享语言骨干; Step-1X 默认档与扩散超参; 君弘灵犀相对通用多模态的独立评测; GSMBK 是否笔误; VICUNA 对战胜率的样本与平局规则. 那些要么从未公开在这篇微信稿里, 要么需要另开技术报告目录. **把 7 页通稿当完整架构论文读, 会把展台口号误当成可部署的稀疏拓扑规格.** 家族后来的 [Step-3](../step3/step3-bi.md) 报告回溯说, 阶跃从 2023 年末开始做 MoE, 产物就是 Step-2; Step-3 用带 shared expert 的 MoE, 可以看作这条线的延续, 但 Step-2 本身的结构至今没有公开.
