## 1. 公司亮相与命名

### 1.1. 谱系: 一年积淀后的公司见面帖

标题是 「It's time to meet! 以阶跃之力, 赴星辰大海」. 发布方是公众号阶跃星辰 / 阶跃StepFun, 时间 2024年3月23日 10:23, 文末 「修改于2024年3月23日」. 开篇第一句是公司正式见面, 不是某一张基准表的发布说明.

公司成立于 2023 年 4 月, 叙事动机绑在当时 ChatGPT 震动科技圈, 以及创始团队对 AGI 的探索欲. 读法应落在 「公司 + 系列模型首次公开亮相」, **别把四页通告误当成 Step-1 的层宽说明书**. 同目录若后续有 Step-2 等材料, 那些才可能补预览之后的技术面; 本篇本身停在见面与成绩单口号.

### 1.2. 命名: Step Function 与 Scaling Laws 口号

名字灵感写明来自阶跃函数 (Step Function): 神经网络最早的激活函数之一, 图像对应 logo 阶梯. 双关两句并列: 阶跃意味着跳变, 跃迁, 超线性增长; 同时 step by step, 扎实做手上的工作. p1 配图就是蓝底 「阶跃星辰」 logo, 不是结构图.

信仰句直接挂大模型 **Scaling Laws**, 并给出英文口号 「Scale-up Possibilities for Everyone」. 这里的 Scaling 指部署前把模型、数据、算力做大的公司路线, 与推理时多花算力的 TestingTime 无关. 读的时候把 Scaling Laws 当成价值观和攀登对象即可, 不要从口号反推幂律拟合或最优算力分配公式; 那些属于单独成篇, 不属于这封见面信.

## 2. 成绩单与路线

### 2.1. 成绩单: Step-1, Step-1V, Step-2 预览

一年积淀后的交付清单只有三档. **Step-1** 是千亿参数语言大模型; **Step-1V** 是千亿参数多模态大模型; **Step-2** 是万亿参数 MoE 语言大模型的预览版, 并 「提供 API 接口给部分合作伙伴试用」. 三者合称 Step 系列通用大模型, 被写成阶段性成绩单.

可核对的边界同样清楚. 「千亿 / 万亿」 是量级词, 不是精确总参或激活参; MoE 只出现在 Step-2 与后文算法准备里, 没有专家数, top-k, 共享专家或负载均衡损失. API 仅限部分合作伙伴, 不是全面开源权重说明. 选型时合理动作是: 把 Step-1 / Step-1V 记为当时公开的千亿语言与多模态双线, 把 Step-2 记为万亿 MoE 预览与受限试用, 其余结构细节留空.

### 2.2. 铁人四项: 算力, 系统, 数据, 算法

Why Us 段先用行业观察铺垫: 过去一年国内 「不下 10 个」 模型达到 GPT-3.5 水平, 于是有人觉得追赶 OpenAI 不难; 通告立刻反驳, GPT-3.5 已是千亿参数, 要到 GPT-4 的万亿规模, 各维要求上一个台阶. 这句话没有点名那 10 个模型, 也没有评测协议.

随后把攀登 Scaling Laws 写成 「**铁人四项**」 超级工程: 算力, 系统, 数据, 算法. 总述里并列四句条件: 等效 A800 万卡单一集群; 高效稳定训练; 十万亿 tokens 高质量数据; 驾驭新颖 MoE 架构. 任一带短板就攀不上去, 并据此判断 GPT-3.5 之后只有极少数团队还能继续爬. 分条准备口径是: 算力走自建机房 + 租用储备; 系统侧团队实践过单集群万卡以上建设与管理, 训练千亿模型 **MFU** (有效算力输出) 达 57%; 数据核心骨干来自必应, 曾支持全球 100 多种语言, 200 多个国家和地区, 并建立数据处理与知识图谱流水线; 算法侧能驾驭含万亿参数 MoE 在内的多种架构, 并对大模型认知与路线有洞察.

**这些句子是准备与能力叙事, 不是实验记录.** 「十万亿 tokens」 落在四要素门槛清单, 不是 「Step-1 已消费 X tokens」 的结果句; MFU 57% 明确说的是千亿模型训练, 不能直接抄到 Step-2 万亿预览上; 万卡句与自建 / 租用句也没有合并成可审计的库存表. 通告末句回到 Step by Step: 通往 AGI 需要准备, 信念, 勇气和更长久的耐心.

### 2.3. 多模路径: 理解与生成统一, 以及两张图

Why Now 的核心命题一句说完: **多模理解和生成的统一是通往 AGI 的必经之路**. 演化三阶段写成 **单模 -> 多模 -> 世界模型**. 早期各模态独立表征; 当前多模可映射到同一空间, 但理解模型与生成模型仍分开发展, 举例是 GPT-4V 理解强生成弱, Sora 生成强理解弱. 这是路径举例, 通告未附评测分.

统一动机用类比句 「人创造不出自己不理解的东西」 接到 AI, 并称年初 Sora 发布已拉开帷幕. 未来阶段: 理解与生成统一后再接具身智能, 形成世界模型; 再叠加复杂任务规划与抽象概念归纳, 才到 AGI. p3 大图标题为 「通往 AGI 的路径方向」, 横轴是模型能力, 早期列 GPT-4 / 视觉 / Whisper, 当前框内写 GPT-4V 与 DALLE3 / Sora 的理解-生成张力并指向 「多模态模型统一理解和生成 GPT-5?」, 未来经世界模型 (接 figure.ai 具身智能 / 环境交互) 再到 AGI (旁注超对齐, Q*, System2). 正文把 OpenAI 的频繁动作 (Sora, Q*, Figure01, GPT-5) 读成 「一条主线, 两条支线」 的路径思考; 阶跃自己则写 「一开始就沿着这条演化路径扎扎实实的做好每一个节点」, 并称在万亿参数与多模融合新战场上 「来得刚刚好」. 第二张 p3 图是灰阶斜条装饰, 不含可抄分数.

## 3. 产品入口与材料边界

消费面开放句很具体: 基于 **Step-1** 和 **Step-1V** 千亿参数大模型的效率工具 **跃问**, 以及 AI 开放世界平台 **冒泡鸭**, 「已经全面开放」, 欢迎体验和反馈. Step-2 不在这句底座名单里; 它仍停在成绩单预览与部分伙伴 API. 通告没有给两款产品的上下文窗口, 定价, 工具协议或评测表.

能稳定回答的很少: 公司于 2023年4月 成立, 2024年3月23日 见面; 名字来自 Step Function 与 step by step; 公开三档为 Step-1 / Step-1V 千亿与 Step-2 万亿 MoE 预览; 攀登 Scaling Laws 被拆成算力 / 系统 / 数据 / 算法, 并给出万卡, 十万亿 tokens, MFU 57%, 必应背景数据团队等准备口径; 多模主线是理解与生成统一, 再走向世界模型与 AGI; 产品入口是跃问与冒泡鸭. 不能回答的同样清楚: 精确参数量与激活量, MoE 专家拓扑, 实际训练用了多少 token, 数据配比, 后训练算法名, 任何基准分数, 以及图中 GPT-5? / Q* / figure.ai 是否为阶跃已交付物. **把这封见面通告读成 Step-1 技术报告, 会把口号和路径示意误当成机制披露.** 这些空白要到一年多以后的 [Step-3](../step3/step3-bi.md) 报告, 家族才第一次把层数、头数和专家布局写成表格.
