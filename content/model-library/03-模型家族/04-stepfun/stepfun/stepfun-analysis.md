# StepFun 开放平台文档中心：当前在售的文本、语音和图像模型一览

> 公开材料是 StepFun 开放平台文档中心落地页抓取 `stepfun.md`（约 7 页，1 图，源文体积很小），不是架构论文或评测报告。正文是快捷入口，模型能力分类条，以及 Step 5 Preview / Step 3.7 Flash / Step 3.5 Flash 2603 / StepAudio 系列 / Step TTS Mini / Step Image Edit 2 的产品卡。几乎没有层宽，训练配方或榜单分表；唯一带参数量与架构专名的句子在 StepAudio 2.5 ASR 的 4B MTP。架构细节页面没有写。

来源：同目录 `stepfun.md`（页标记 `page 1 of 7`–`page 7 of 7`）。对照译稿见 `stepfun-bi.md`。配图一张：`images/p01-03-https-platform-stepfun-com-docs-zh-api-reference.png`。数字与型号名回源 md；抓取断句（如 Step 3.7 Flash 段末 「支持」）不臆补。

这篇材料要回答的问题很窄：开放平台首页把用户往哪几类入口送；当前推荐卡各自的上下文上限，模态与场景口号是什么；语音与图像线怎样并列。它撑不起底座技术报告，也不给可复制的评测协议。

## 1. 首页与模型卡

### 1.1. 谱系：文档中心首页，不是单模型技术卡

标题与壳层写的是 StepFun 开放平台文档中心。快捷入口六条：快速开始（5 分钟首次 API），控制台（API Key 与用量），API 文档，AI Coding 工具配置，定价与计费，常见问题。「模型能力总览」 再声明共 5 个分类入口：官方推荐模型，全部模型，推理，视觉，语音。

**读法应落在 「平台目录页」。** 它把多条产品线摊在同一张推荐墙上，不是 Step 5 或某张 ASR 的单独成篇。材料没有公司年表，没有预训练 token 量，也没有把各卡收成一张总参数对照表。选型时合理动作是：先按能力标签进对应模型页 / API，再另开那些子页的源文，别在本首页上假装已读完全族技术细节。

### 1.2. 文本与多模态旗舰卡：Step 5 Preview，3.7 Flash，3.5 Flash 线

Step 5 Preview 自称新一代旗舰基模，最大上下文 1M, API ID `step-5-preview`。卖点是真实任务，编程与知识工作，原生文本 / 图片 / 视频，工具与文档推进多步骤，标签含知识工作，编程，Agent，图片与视频理解。Step 3.7 Flash 是多模态推理旗舰，上下文 256K，明确写在 step-3.5-flash 的高速推理与工具调用之上新增原生多模态输入，无需视觉 MCP 或额外模型；源文在 「支持」 处截断，宾语缺失。

Step 3.5 Flash 2603 写 Agent 优化，同为 256K，保留旗舰推理与工具调用，提升 Token 效率与推理速度，可切换低推理模式降消耗，并对 Coding 与 Agent 框架做专项优化。后文另有一张无副标题的 「旗舰推理」 卡，相关入口仍指向 Step 3.5 Flash，文案强调智能体构建，推理深度比肩顶尖闭源，极速响应与工具调用，以及复杂项目规划与长程执行。两段都挂 Step 3.5 Flash，但源文没有声明 2603 与该卡是否同一 API ID。**引用时应分开抄，用入口名串，不要自制合并规格表。**

### 1.3. 语音线：Realtime, Chat, TTS, ASR, Mini

StepAudio 3 Realtime 是**全双工**实时语音旗舰：实时音频理解，自然打断，话权协调，自适应推理，边想边说，Voice Agent 工具调用；简单问题快回，复杂任务边想边说；场景点到座舱，终端，客服，情感陪伴。「自适应推理 / 边想边说」 是产品并列能力，没有 TestingTime 预算或采样协议，不能读成已公开的推理时算力表。

StepAudio 2.5 Chat 放在语音对话推荐位，却写输出模态仅文本，强调活人感，副语言感知与千万人设自定义。p5 紧接的音色 / 气口 / 笑声咂嘴段没有新的 `##` 标题，相关入口却指向 StepAudio 3 TTS 与语音合成开发指南；**应把该段归到 TTS**，不要算进 「仅文本」 的 Chat 卡。StepAudio 2.5 ASR 是全文几乎唯一带规模句的卡：4B 参数 + **Multi-Token Prediction (MTP)**，单步并行预测多个 Token，5 分钟音频 1 秒内转写，并称保持 SOTA 精度，面向 Voice Agent，批量转写，实时字幕 / 直播。Step TTS Mini 是高表现力 TTS：单次输入上限 1000 字符，中英日粤川，19 种官方音色，中英日复刻，场景偏外呼与陪伴。

## 2. 图像卡与材料边界

Step Image Edit 2 分组旁标 「即将下线」，正文仍称最新轻量编辑模型，文生图与图像编辑一体，单次响应 1-2 秒，在 6B 以下参数规模内自称同量级标杆，并可跨量级对标 12B-20B 开源大模型。源文没有下线日期，没有替代型号，也没有给出可复制的对照榜。**应同时保留 「仍列出」 与 「即将下线」。**

它能稳定回答的很少：这是开放平台文档首页；五类能力入口；各推荐卡的显示名，上下文或响应规格，模态与场景口号；ASR 的 4B MTP 与 5 分钟 / 1 秒；Image Edit 2 的即将下线标记；一张 API 文档区截图。它不能回答的同样清楚：Step 5 为何到 1M，各 Flash 的层宽与路由，Chat 与 TTS 断标题归属以外的训练细节，SOTA / 比肩闭源的评测表，以及 2603 与旗舰推理卡是否同一权重。

把这张推荐墙和同目录的技术材料对起来看，家族的主线很清楚。[Step 3.5 Flash](../step3-5-flash/step3-5-flash-bi.md) 的技术报告交代了 196B / 11B 的混合注意力 MoE 和它的训练方法，平台上的 2603 版本在此基础上主打 token 效率和低推理模式；[Step 3.7 Flash](../step3-7-flash/step3-7-flash-bi.md) 在同一底座上加原生多模态输入；[Step 5 Preview](../step5-preview/step5-preview-bi.md) 是下一代旗舰，上下文到 1M. 语音线里 ASR 用 MTP 做并行预测，和 3.5 Flash 用 MTP 给投机解码出草稿，是同一个技术在不同模态上的用法，但页面没有说明两者是否共用实现。
