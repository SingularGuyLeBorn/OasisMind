# ERNIE-3.5-8K

Last updated: 2025-09-05.

更新时间: 2025-09-05.

ERNIE 3.5 is Baidu's in-house flagship large language model. It was trained on a huge Chinese and English corpus, has strong general ability, and covers most needs in dialogue Q&A, creative writing and plugin use; it can hook into the Baidu Search plugin automatically, so answers stay current. ERNIE-3.5-8K is one version of that model, and this page documents its API and how to use it.

ERNIE 3.5 是百度自研的旗舰级大规模大语言模型, 覆盖海量中英文语料, 具有强大的通用能力, 可满足绝大部分对话问答, 创作生成, 插件应用场景要求; 支持自动对接百度搜索插件, 保障问答信息时效. ERNIE-3.5-8K 是模型的一个版本, 本文介绍了相关 API 及应用. (源文 「大语言」 里的 「大」 和 「言」 是康熙部首形近字 ⼤ 与 ⾔, 不是常用汉字.)

> **问:** 型号叫 8K, 一次请求到底能放进多少输入?
> 表里看得到的输入上限是 5120 tokens: functions 一行写 「message 中的 content 总长度, functions 和 s(ystem)... 5120 tokens」, 第 3 页 system 一行又写了一遍 5120, messages 第 (4) 条讲的是同一件事, 却在 「字段总」 处截断. 输出另有上限, max_output_tokens 最大 2048, 两者相加是 7168; 页面没解释 「8K」 指什么, 也没说 5120 和 2048 是否共用一个窗口. 按表来: content, functions, system 三样合计不超过 5120, 不要按 8K 去估输入.

> **核对:** temperature 和 top_p 默认都是 0.8, 取值范围也一样吗?
> 不一样. temperature 是 (0, 1.0], 左端开, 表里还专门写了 「不能为0」; top_p 是 [0, 1.0], 两端都闭, 可以取 0. penalty_score 默认 1.0, 范围 [1.0, 2.0], 默认值就是下限, 只能往重调, 不能比默认更轻. 想把 temperature 设成 0 求稳定输出, 按这张表是非法值.
