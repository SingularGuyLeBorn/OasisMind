# Grok 4.3 模型页: 一张几乎全是价格的规格卡

来源: 同目录 `grok-4-3.md` (页标记 `page 1 of 4` 到 `page 4 of 4`), 对照译稿 `grok-4-3-bi.md`. md 有两处丢失, 回查 `grok-4-3.pdf` 文字层补齐: 第 3 页 Details 的 Model name 值是 `grok-4.3`, 同页还有 Region (us-east-1), Batch API (Supported) 和 Reasoning efforts (none, low, medium, high, xhigh, DEFAULT low) 三行, md 都没抽到. 配图 9 张没有一张是技术图: 4 张是 X 形站标, 2 张是关着的开关, 书, 锤子, 小方框图标各 1 张. 数字一律回源 md 与 PDF 文字层.

这份材料能回答的问题是: 在 xAI 的 API 里, Grok 4.3 叫什么名字, 收多少钱, 窗口多大, 推理有几档, 一分钟能调多少. 它回答不了模型怎么搭, 怎么训, 也回答不了 fast 和 strong 这些评价靠什么支撑.

## 1. 页面性质: 规格卡, 和同家族 4.20 同一个模子

版面从上到下是: 面包屑和模型 id `grok-4.3`, 一句产品描述, 概览 (模态, 上下文窗口, 定价), 三个能力标签, 定价表, 两个默认关闭的开关, 详情 (模型名, 别名, 速率限制, PDF 文字层里还有区域, 批量和推理档位), 最后是三张文档入口卡片. 没有日期, 没有作者, 没有正文段落. 它和同家族 [Grok 4.20 专页](../grok-4-20/grok-4-20-bi.md) 用的是同一个模板, 窗口, 三档单价, 200K 门槛, 两个限额完全一样, 区别集中在描述句, 推理档位和别名表.

有两处和同家族不一样值得注意. 一是描述句换了: 4.20 写的是 industry-leading speed 加 lowest hallucination rate, 本页写的是 fast, reliable, strong tool calling and instruction following, 幻觉率不再提. 二是 Details 的行数不同: 4.20 有 Region 和 Batch API 两行 (us-east-1, us-west-2), 本页 PDF 文字层也有这两行但区域只剩 us-east-1, md 则整段丢失. 抓取时间戳是 2026/9/25, 页眉已挂 SpaceXAI, 说明这页的记录晚于 2026 年 2 月的收购.

## 2. 描述句与能力标签: 三个形容词, 一个可调的推理

描述句一共一句, 卖点是 fast, reliable, strong tool calling, strong instruction following. 全部是评价, 没有一个数: 没有速度指标, 没有工具调用基准的分数, 也没有指令遵循基准的分数, 整页没有一张基准表. 同家族 4.20 好歹有「lowest hallucination rate on the market」这种可以找对照的宣称, 本页连宣称对象都没点名. 读法是定位性的: 这是一个偏快, 偏稳, 把工具调用放在首位的档位, 不是性能结论.

三个能力标签是 **Function calling**, **Structured outputs** 和 **Configurable reasoning**. 前两项和页尾入口卡对应 (Tool use 卡, Structured outputs 卡), 原理和常见调用格式见 [FunctionCalling](../../../../LargeLanguageModelGuide/7-LLM应用开发/7.4-FunctionCalling/7.4-FunctionCalling.md) 和 [结构化输出](../../../../LargeLanguageModelGuide/13-Agent/13.1-Agent核心组件/13.1.5-结构化输出/13.1.5-结构化输出.md). 第三项是本页和同家族 4.20 最大的分歧点: 4.20 只有一句「can think before responding」, 本页把推理写成请求参数, 页面文案列了 none, low, medium, high 四档, PDF 文字层的 Details 里还多出一档 **xhigh** 和一行 **DEFAULT low**. 默认档是 low 意味着不带参数调用时模型也在做轻度推理, 推理花掉的 token 怎么计费本页没有写. 推理能力一般怎么训出来, 见 [推理与思考能力](../../../../LargeLanguageModelGuide/4-后训练/4.8-推理与Agent能力/4.8-推理与Agent能力.md), 那是通用背景, 本页没有提 Grok 4.3 的任何训练信息.

## 3. 价格: 三档单价加一个藏在开关后的 cliff

页面给了三个单价, 都按每 1M token 计: 输入 \$1.25, 输出 \$2.50, 缓存输入 \$0.20. 输出是输入的 2 倍, 缓存输入是普通输入的 16%, 命中缓存省 84%. 三个数和同家族 4.20 完全相同, 连同 1,000,000 的窗口和 200K 的换价门槛都一样, 说明这是 xAI 这一档模型的家族统一计费, 不是 4.3 独有的定价策略. 缓存价对应服务端复用已算过的前缀, 省掉重复的预填充计算, 一般机制见 [KV 缓存与内存优化](../../../../LargeLanguageModelGuide/6-训练与推理优化/6.4-KV缓存与内存优化/6.4-KV缓存与内存优化.md); 缓存最短多长, 保留多久, 怎样算命中, 本页都没写, 实际省多少取决于命中率.

**200K cliff** 是这套价格里唯一有结构的地方: 请求超过 200K 上下文就换一套费率, 200K 只占 1,000,000 窗口的 20%, 剩下 80% 的区间价格未知. 费率藏在「Higher context pricing」的开关后面, 抓取时开关是关着的; 页面也没说 200K 按输入算还是按输入加输出算, 超过后是整次请求改价还是只有超出部分改价. 第二个开关是 Batch API 定价, PDF 文字层显示批量支持 (Supported), 价格同样看不到. 长上下文的一般代价见 [长上下文与外推技术](../../../../LargeLanguageModelGuide/2-核心原理与架构/2.7-长上下文与外推技术/2.7-长上下文与外推技术.md).

## 4. 模型名与别名: 裸名加一个 latest

正式模型名是 `grok-4.3`, 别名只有 `grok-4.3-latest` 一个. 同家族 4.20 的正式名是 `grok-4.20-0309-reasoning`, 带月日码和形态后缀, 名下挂 15 个别名, 能拼出一条 experimental beta, beta, 正式的版本线. 本页什么都没有: 没有日期码, 没有 beta, 没有 reasoning 后缀. 可能是 4.3 上线时没走公开 beta, 也可能 beta 别名后来清理了, 报告里没写.

latest 是浮动别名, 指向当前最新权重, 供应商可能在不改名字的情况下换掉它背后的权重. 生产环境要复现行为应该固定正式名而不是用 latest, 这个规则本页没有写, 别名会不会随换权重而漂移, 本页也没有承诺. 版本号本身按 4.2 → 4.3 → 4.5 读和同家族新闻页里 Grok 4.5 的记录不冲突, 但 4.3 的发布日期本页没有一点信息, 只有四页页眉同一个抓取时间 2026/9/25.

## 5. 速率限制与部署: 一组和 4.20 一模一样的数

速率限制是每秒 37 次请求, 每分钟 10,000,000 个 token. 两个上限单位不同, 卡的是两种场景: 37 次每秒折成每分钟 2,220 次, 同时顶满时平均每次请求只能用约 4,505 个 token; 一次用满 1,000,000 窗口的请求吃掉每分钟额度的十分之一, 一分钟最多 10 次. 短请求先撞请求数上限, 长请求先撞 token 上限. token 数只算输入还是输入加输出, 缓存命中的 token 算不算, 本页没写.

部署信息只有两句: 「available on multiple clusters」和 PDF 文字层里的 Region us-east-1. 「full regional based pricing below」下面没有任何分区价格, 多个集群和这一个区域是什么关系本页也没说. 4.20 页列了 us-east-1 和 us-west-2 两个区域, 本页只剩一个, 是部署收缩了还是页面没更新, 报告里没写. 这组限额和价格一样, 更像账户默认档而不是 4.3 的专属配置.

## 6. 本页对不上的数字

缺失集中在这几处. 描述句的 fast, reliable, strong 没有任何数值支撑, 也没有基准表. 概览的「\$1.25 \$2.50」没标名目, 要对照下面的定价表; 1,000,000 的窗口配 200K 的换价门槛, 超过门槛的费率, 批量价和分区价全都藏在关着的开关后面. 模型名的值在 md 里被页眉顶替, 靠 PDF 文字层补回 `grok-4.3`; Details 的 Region, Batch API, Reasoning efforts (含 xhigh 和 DEFAULT low) 三行 md 整段丢失. 每秒 37 次和每分钟 10,000,000 个 token 单位不同, 同时顶满时平均每次只有约 4,505 个 token. 页面文案写推理四档, PDF 文字层写五档, 两处对不齐.

和同家族对照时唯一要小心的是: 本页所有与 4.20 相同的数字, 都不能当 4.3 的独有信息引用, 那是家族统一配置. 除此之外, 页面上的单价, 窗口, 档位和限额彼此没有矛盾. 想知道 Grok 4.3 的参数量, 结构, 训练数据和评测表现, 本页没有, 同家族也只有 [Grok 4 公告](../grok-4/grok-4-bi.md) 级别的训练叙述, 套不到这页上.
