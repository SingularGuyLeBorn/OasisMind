# Grok 4.20 模型页: 一张 API 规格卡能读出什么

来源: 同目录 `grok-4-20.md` (页标记 `page 1 of 4` 到 `page 4 of 4`), 对照译稿 `grok-4-20-bi.md`, 版面按同目录 PDF 核对. 配图 7 张, 没有一张是技术图: `images/p01-...png` 是模型名旁边的复制按钮, `images/p02-we-charge-...png` 和 `images/p02-details.png` 是两个关着的开关, `images/p03-...-tutorial.png` 是书本图标, `images/p03-...-function-calling.png` 是锤子图标, `images/p02-you-are-charged-...png` 和 `images/p04-gr-ok-...png` 是叠在页面左上角的 X 形站标. 数字一律回源 md.

这份材料能回答的问题是: 在 xAI 的 API 里, Grok 4.20 叫什么名字, 收多少钱, 窗口多大, 部署在哪, 一分钟能调多少. 它回答不了模型怎么搭, 怎么训, 以及「最快」「幻觉最低」这些说法有什么数据支撑.

## 1. 页面性质: 规格卡, 不是发布稿

版面从上到下是: 面包屑和模型名 `grok-4.20-0309-reasoning`, 一句产品描述, 概览 (模态, 上下文窗口, 定价), 三个能力标签, 定价表, 两个默认关闭的开关, 详情 (模型名, 15 个别名, 区域, Batch API, 速率限制), 最后是三张文档入口卡片. 没有日期, 没有作者, 没有正文段落. 它和同家族 [Grok 4.3 专页](../grok-4-3/grok-4-3-bi.md) 用的是同一个模板, 连价格和限额都一样, 区别主要在描述句, 推理选项和别名表.

抓取留下了几处干扰. 源 md 第一行的「Q」是页面右上角的搜索图标. 左上角的 X 形站标在打印时每页都叠了一次, 第 3 页它压住了一个别名的开头, 于是出现 `[grok-4](https://docs.x.ai/).20-experimental-beta-latest` 这种半截带链接的写法; 第 4 页它压住了「Let」的前两个字母, 源 md 变成了「Gr[ok generate structured outputs.]」. 第 1 页末尾的「Cached tokens」和它的价格 \$0.20 被分页拆开, 价格在第 2 页还被识别成了二级标题. 这些都**只影响阅读, 不改变数字**.

## 2. 产品描述: 三个最高级, 没有一个数

描述句一共两句, 里面有四个卖点: industry-leading speed, agentic tool calling, the lowest hallucination rate on the market, strict prompt adherence. 前三个都是比较级或最高级, 本页没有给出任何一个数. 速度没有每秒 token 数, 也没有首个 token 的延迟; 幻觉率没有百分比, 没有评测集, 也没说比的是哪些模型. 「strict prompt adherence」同样没有 IFEval 之类的分数.

同家族能找到的参照只有 [Grok 4.1 专页](../grok-4-1/grok-4-1-bi.md). 那一页把幻觉率定义为回答里有错误的原子陈述占比的宏平均, 在生产流量分层抽样的信息查询上测, Grok 4.1 (Non-Reasoning) 是 4.22%, 另外还测了 FActScore. 这说明 xAI 手里有一套现成的幻觉口径, 但 Grok 4.20 这页没有沿用, 也没有给数. 何况 4.1 那组数测的是非推理模式加搜索工具, 而 Grok 4.20 的模型名本身就带 reasoning, **两者不能直接对比**.

## 3. 能力标签: 三项能力, 三张入口卡, 只重合两项

Capabilities 列了 Function calling, Structured outputs, Reasoning 三项, 页尾的入口卡片是 Quickstart, Tool use, Structured outputs 三张. Function calling 和 Tool use 链到同一个 `function-calling` 指南, Structured outputs 两边都有. Reasoning 没有入口卡, Quickstart 是通用教程. 描述句里的「agentic tool calling」在页面上能落到的就是 Function calling 这一项, 原理和常见的调用格式可以看 [FunctionCalling](../../../../llm-guide/7-LLM应用开发/7.4-FunctionCalling/7.4-FunctionCalling.md), 结构化输出的做法见 [结构化输出](../../../../llm-guide/13-Agent/13.1-Agent核心组件/13.1.5-结构化输出.md).

Reasoning 这一项只写了「The model can think before responding.」. 本页没说推理能不能关, 有没有强度档位, 推理过程产生的 token 怎么计费. 对比一下 Grok 4.3 专页, 那里写的是 Configurable reasoning, 支持 none, low, medium, high 四档. Grok 4.20 这里没有档位, 结合下面别名表的情况, 它看起来只有推理这一种形态, 但页面没有明说. 推理能力一般怎么训出来, 见 [推理与思考能力](../../../../llm-guide/4-后训练/4.5-推理与思考能力/4.5-推理与思考能力.md).

## 4. 价格: 三档单价, 两个没展开的开关

页面给了三个单价, 都按每 1M token 计: 输入 \$1.25, 输出 \$2.50, 缓存输入 \$0.20. 输出是输入的 2 倍, 缓存输入是普通输入的 16%. 举个按页面单价算的例子 (请求规模是假设的): 一次输入 100K, 输出 10K 的请求, 不命中缓存时是 \$0.125 加 \$0.025, 共 \$0.15; 如果 100K 输入里有 90K 命中缓存, 输入部分降到 \$0.018 加 \$0.0125, 总价约 \$0.056, 不到原来的四成. 缓存价通常对应服务端复用已经算过的前缀, 省掉重复的预填充计算, 一般机制见 [KV 缓存与内存优化](../../../../llm-guide/6-训练与推理优化/6.4-KV缓存与内存优化/6.4-KV缓存与内存优化.md). 至于 xAI 的缓存最短多长, 保留多久, 怎样算命中, 本页都没写.

另外两套价格在页面上看不到. 一是长上下文定价: 超过 200K 的请求换一套费率, 可开关是关着的, 抓下来的页面没有显示. 上下文窗口是 1,000,000, 200K 只占 20%, 也就是说**窗口后 80% 的区间价格未知**, 上面那个例子一旦超过 200K 就不再成立. 页面也没说 200K 按输入算还是按输入加输出算, 超过后是整次改价还是超出部分改价. 二是 Batch API 定价, 详情里写了「Supported」, 价格同样藏在关着的开关后面. 第 2 页还说「full regional based pricing below」, 往下只看到 us-east-1 和 us-west-2 两个区域名, 没有分区价格. 长上下文的一般代价可以对照 [长上下文与外推技术](../../../../llm-guide/2-核心原理与架构/2.5-长上下文与外推技术/2.5-长上下文与外推技术.md).

## 5. 模型名与 15 个别名: 能拼出的版本线

正式模型名是 `grok-4.20-0309-reasoning`, 别名 15 个, 第 2 页 12 个, 第 3 页 3 个. 按名字里的标记可以分成几组: 带 experimental-beta 的 4 个, 其中 2 个带 0304; 带 beta 但不带 experimental 的 6 个, 其中 2 个带 0309; 不带 beta 的 5 个, 包括 `grok-4.20`, `grok-4.20-0309`, `grok-4.20-reasoning`, `grok-4.20-reasoning-latest` 和 `grok-4.20-reasoning-gv2`. 如果 0304 和 0309 是月日, 可以拼出 experimental beta, beta, 正式名依次出现的顺序, 正式名和 beta 共用 0309. 但本页没有年份, 也没说日期码的含义, 更没说 beta 到正式之间权重有没有变. `gv2` 没有 gv1 可对, 也没有日期码, 排不进这条线.

版本号本身也有歧义. 4.20 按小数等于 4.2, 夹在 4.1 和 4.3 之间. 同家族 [xAI 新闻页分析](../xai/xai-analysis.md) 记录了 Grok 4.1 在 2025 年 11 月 17 日发布, Grok 4.5 在 2026 年 7 月 16 日发布, 新闻列表在 2026 年 2 月 2 日到 4 月 17 日之间是空白, 列表里也找不到 Grok 4.20. 如果 0309 是 2026 年 3 月 9 日, 它正好落在这段空白里. 这只是把两页信息拼在一起的推测, 本页自己**给不出发布日期**.

## 6. 部署与速率限制: 和 Grok 4.3 一模一样的一组数

详情里写了两个区域 us-east-1, us-west-2, Batch API 支持, 速率限制是每秒 37 次请求, 每分钟 10,000,000 个 token. 两个限额单位不同, 换算后能看出它们卡的是不同场景: 37 次每秒等于每分钟 2,220 次, 两个上限同时顶满时, 平均每次请求只能用约 4,505 个 token. 一次用满 1,000,000 窗口的请求要吃掉每分钟额度的十分之一, 一分钟最多 10 次. 也就是说, 短请求先撞上请求数上限, 长请求先撞上 token 上限. 本页没说 token 额度只算输入还是输入加输出, 缓存命中的 token 算不算, 也没说这是单个账户的默认值还是可以按模型单独申请.

把 Grok 4.3 专页放在旁边看: 1,000,000 的窗口, \$1.25, \$2.50, \$0.20 三档单价, 200K 的长上下文门槛, 37 和 10,000,000 两个限额, 全都一样. 两个型号的差别在页面上只剩描述句, 推理是否可调和别名表. 4.3 那页的抓取里没有区域和 Batch API 两行, 看不出两者在这两项上是否也相同. 所以这组限额和价格更像 xAI 这一档模型的统一配置, 不能拿来说明 Grok 4.20 在速度或规模上有什么特别之处.

## 7. 本页对不上的数字

对不上或缺失的地方集中在这几处. 一是描述句里的「industry-leading speed」和「the lowest hallucination rate」没有任何数值, 同家族 Grok 4.1 的 4.22% 是另一个型号, 另一种模式. 二是概览的「\$1.25 \$2.50」没标名目, 缓存价 \$0.20 不在概览里, 还被分页拆到第 2 页当成标题. 三是 1,000,000 的窗口配 200K 的换价门槛, 超过门槛后的价格没显示; Batch API 写了支持, 价格也没显示; 「full regional based pricing below」下面只有区域名. 四是 37 次每秒和 10,000,000 每分钟两个限额单位不同, 同时顶满时平均每次只有约 4,505 个 token, 满窗口请求一分钟最多 10 次.

别名和版本号上的问题: 15 个别名里 8 个带 reasoning, 7 个不带, 全都指向同一个推理模型名; 0304 和 0309 没有年份; gv2 没有 gv1 和日期码; `[grok-4](https://docs.x.ai/).20-...` 是站标链接把版本号拆成两截的抓取痕迹. 能力标签 3 项和入口卡片 3 张只重合 2 项. 除此之外, 页面上的单价, 窗口和限额彼此没有矛盾, 和 Grok 4.3 专页能对照的各项都一致. 想知道 Grok 4.20 的参数量, 结构和训练细节, 本页没有.
