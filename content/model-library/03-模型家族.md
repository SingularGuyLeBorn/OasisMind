# 模型家族

21 个家族。DeepSeek、Kimi、Qwen、StepFun、MiMo、OLMo 在前，其余按名字排在后面。每个家族的模型名单在各自的 `_index.md`。

每个模型目录四份文件：

| 文件 | 内容 |
|---|---|
| `<slug>.pdf` | 技术报告或模型卡原文。没有论文就用官方博客或模型卡 |
| `<slug>.md` | MinerU 转出的 Markdown，图留在原文位置 |
| `<slug>-bi.md` | 逐段意译。段落不合并、不删。没有稳定中文名的术语保留英文。难懂的句子后面用一两句讲清楚 |
| `<slug>-analysis.md` | 把这份报告写成一篇完整笔记 |

MinerU 环境在 `D:\python-envs\mineru`。
