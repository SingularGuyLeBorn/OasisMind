# 4.9 OPD

OPD (On-Policy Distillation) 的做法可以拆成两句. 前缀由学生自己采样, 和推理时学生会走到的前缀同分布; 每个前缀上的监督由教师的下一 token 分布提供, 比 RL 那种整条轨迹一个标量稠密得多. 这两句话各自都不新: 前一句是 RL 的数据来源, 后一句是 Hinton 式蒸馏的监督形式, 在模仿学习里两者的组合叫 DAgger. 2023 年 MiniLLM 和 GKD 把它用到 LLM 上, 2025 年之后它进入了 Qwen3, DeepSeek-V4, Kimi K3, MiMo-V2-Flash, GLM-5 等模型的后训练流水线, 文献也从几篇涨到上百篇.

## 1. SFT 与 RL 各缺的一半

### 1.1 两种训练的缺口

SFT 和传统的 token 级蒸馏用固定数据集里的前缀, 可能是人写的标准答案, 也可能是教师生成的序列. 推理时学生只能从自己的输出续写, 早期一个 token 偏离训练分布, 后面的前缀就越来越陌生. Ross 等 (2011) 在模仿学习里给出量级: 单步错误率为 $\epsilon$ 时, 只在专家状态上训练的策略在长度 $T$ 的任务上总误差可达 $O(\epsilon T^2)$, 在学习者自己访问的状态上向专家要标注, 可以降到 $O(\epsilon T)$. LLM 文献里这个问题叫暴露偏差.

RL 的前缀来自学生, 没有这个错配, 缺的是信号密度. RLVR 里一条几千 token 的回答通常只拿到一个 0 或 1, 每个 token 分到相同的优势, 模型分不清哪一步该改; 全组都错时连这个信号也没有. OPD 同时补上两处: 学生采样, 教师在每个学生前缀上给分布. 代价是每一步都要让教师在新样本上前向一次, 教师的输出不能提前离线生成.

### 1.2 为什么单独成一节

最常被引用的数字来自 Qwen3 技术报告的 Table 21. 同一个经过 off-policy 蒸馏的 Qwen3-8B 起点, 只用数学和代码查询, 一支继续 RL 花了 17,920 GPU 小时, AIME'24 到 67.6; 另一支做 on-policy 蒸馏花了 1,800 GPU 小时, AIME'24 到 74.4. RL 之后 AIME'24 的 pass@64 停在 90.0 没动, OPD 之后升到 93.3. 这个对比的条件很具体: 8B 学生, 教师是更大的 Qwen3, 表里只有一个尺寸.

工业报告里 OPD 的用法分三类, [10 OPD 报告落地对照](./4.9.1-OPD方法与落地/10-OPD-报告落地对照/10-OPD-报告落地对照.md) 逐家列出. 第一类是大教小, Qwen3 用 32B 和 235B-A22B 教轻量档; 第二类是分域专家合版, DeepSeek-V4, Kimi K3, MiMo-V2-Flash, ERNIE 5.1 等从同一个 SFT 检查点分域训出 RL 专家, 再让学生在自己的 rollout 上按题目接受对应专家的监督; 第三类是跨阶段恢复, GLM-5 在顺序 RL 之后用前面各阶段的检查点当教师, 找回被后面阶段冲掉的能力. 三类共用同一个骨架, 期待的结果不同.

## 2. 共用的记号

### 2.1 学生前缀上的散度

全节记学生为 $\pi_\theta$, 教师为 $\pi_T$, 提示为 $x$, 学生采样的回答为 $y$, 第 $t$ 步的前缀为 $y_{<t}$. 最常见的 OPD 目标是在学生轨迹上对每个前缀的下一 token 分布求散度再求和: $\mathbb{E}_{y\sim\pi_\theta}\sum_t D(\pi_T(\cdot\mid x,y_{<t}),\pi_\theta(\cdot\mid x,y_{<t}))$. [01 OPD 基础原理](4.9.1-OPD方法与落地/01-OPD基础原理/01-OPD基础原理.md) 第 1.2 节指出这个式子有三处可以独立选: 采样分布 (纯学生, 还是混入教师或固定数据), 教师 (外部大模型, 还是同一模型加额外上下文), 散度 $D$.

散度方向是文献里争论最多的一处. forward KL $\mathrm{KL}(\pi_T\Vert\pi_\theta)$ 要求学生覆盖教师的全部支撑, 容量不够时概率会摊到教师认为不太可能的 token 上; reverse KL $\mathrm{KL}(\pi_\theta\Vert\pi_T)$ 以学生概率为权重, 学生会集中到教师的主要模式上. MiniLLM 主张生成任务用 reverse KL. 后来的证据并不一边倒: SDFT 在实践中改用 forward KL, OPSD 的消融里 forward KL 训到第 100 步仍高于 Base, reverse KL 则跌到 Base 以下, 4.9.3 引用的 2605.16826 发现长序列下 reverse KL 会把熵压到接近坍缩, 接 GRPO 之后反而不如 forward KL.

### 2.2 单样本奖励与三种计算粒度

学生在第 $t$ 步采到 $a_t$, reverse KL 的单样本估计取负号就是逐 token 奖励 $r_t=\log\pi_T(a_t\mid x,y_{<t})-\log\pi_\theta(a_t\mid x,y_{<t})$. 把折扣因子设为 0, 第 $t$ 个 token 的优势就是 $r_t$ 本身, OPD 可以直接复用现成的 RL 框架, 只把优势换掉. Thinking Machines 的 OPD 博客, MiMo-V2-Flash 报告和 G-OPD 都采用这个形式; GLM-5 的跨阶段蒸馏把组大小设成 1, 因为优势来自教师, 不需要组内基线.

散度在实现上有三种粒度. full-vocab 在完整词表上精确计算, 一条 16384 token 的序列配上 15 万词表, 每个模型的 logits 在 bf16 下约 4.9GB; top-$k$ 只在概率最高的 $k$ 个 token 上算, 其余并成尾部桶; sampled-token 只用采到的那一个 token, 开销最小, 方差最大. 各家在这里分歧明显: DeepSeek-V4 以梯度方差高为由反对 sampled-token, 改用全词表并缓存教师 hidden state; Kimi K3 和 Ma 等的 MOPD 论文则报告 top-$k$ 没有明显好处.

## 3. 三个小节怎么分工

### 3.1 方法, 综述与机制

[4.9.1 方法与落地](./4.9.1-OPD方法与落地/4.9.1-OPD方法与落地.md) 是主体, 共 11 篇. 01 讲 MiniLLM 和 GKD 两篇奠基工作与 RL 读法; 02 到 04 去掉外部教师, 让同一个模型借参考解, 示范或环境反馈给自己当教师; 05 和 06 改目标与反馈; 07 收三篇诊断论文; 08 把 OPD 搬到机器人策略上; 09 和 10 讲多教师合版与各家技术报告; 11 处理多轮 agent 场景下的前缀回放.

[4.9.2 OPD 综述](./4.9.2-OPD综述/4.9.2-OPD综述.md) 只有一篇, 读 Song 与 Zheng 的综述 (arXiv:2604.00626). 它把上百篇方法放进同一个 $f$-散度统一式, 再按目标, 信号, 训练动态三条轴归类, 并给出何时用 on-policy 的决策规则. [4.9.3 状态分布视角](./4.9.3-状态分布视角/4.9.3-状态分布视角.md) 有两篇, 不讲具体算法, 讨论的是监督施加在哪些前缀上会带来什么后果: 为什么 RL 和 OPD 比 SFT 忘得少, 从退化教师蒸出的学生为什么能超过教师.

### 3.2 前缀来源与监督的对照

| 做法 | 前缀来源 | 每个前缀上的监督 | 推理时的前缀是否同分布 | 主要代价 |
|---|---|---|---|---|
| SFT | 人工答案 | 答案的下一个 token | 否 | 标注数据 |
| SeqKD / 离线蒸馏 | 教师生成的序列 | 教师序列的 token 或分布 | 否 | 教师采样 |
| RL (如 GRPO) | 学生采样 | 整条轨迹共享的标量优势 | 是 | 奖励稀疏, 需要验证器 |
| OPD | 学生采样 | 教师的下一 token 分布或单样本估计 | 是 | 每步一次教师前向 |
| ReOPD (11) | 教师轨迹前缀, 学生只生成被监督的一步 | 教师在该步的分布 | 部分 | 前缀池离学生分布有偏 |

前四行是 01 第 1.1 节的整理. 只有 RL 和 OPD 的前缀与推理一致, 只有后两类蒸馏的监督落到 token 级分布上, OPD 是两条同时满足的那一行. 4.9.3 的两篇把这一列单独拿出来研究: 在 Nie 的 Qwen3-0.6B-Base 对照里, 高压 SFT 和从它蒸出的 OPD 学生最终都由同一份退化的教师行为塑形, 区别只在 OPD 把监督施加在学生前缀上, 结果 OPD 学生在 GSM8K, TruthfulQA, MMLU 三项上都超过教师.

最终一行说明前缀来源不是只有两档. 多轮 agent 任务里完全在线的 OPD 每次更新都要让学生重新和环境交互, [11 ReOPD](./4.9.1-OPD方法与落地/11-ReOPD-多轮OPD与Prefix-Replay/11-ReOPD-多轮OPD与Prefix-Replay.md) 改为从教师 RL 时落盘的轨迹里取前缀, 学生只在被监督的那一步自己生成, 训练中不调用工具. 它用 $p_t\propto\kappa^t$ ($\kappa=0.6$) 偏向早期前缀, 理由是前缀越靠后, 学生 occupancy 的偏移和教师可靠性的偏移都越大.

### 3.3 小节之间的交叉

11 ReOPD 讨论的「prefix trap」和 4.9.3 处理的是同一个问题的两个侧面. ReOPD 把多轮 OPD 的难点写成两侧偏移: 前缀越贴近学生, 训练与推理越相关; 前缀越偏离教师熟悉的区域, 教师给的条件分布越不可信. 4.9.3 第二篇引用的 2605.16826 把前缀来源与 KL 方向拆成四个目标, 其中「教师前缀加 reverse KL」一格就是 ReOPD 这类离线回放的位置. 07 第 2.2 节 Fu 等讨论的漂移前缀上的教师失准, 是这一侧面在单轮任务上的表现.

综述和 4.9.1 也互相指向. 综述的成功条件采用 Li 等的两条 (师生思维模式兼容, 教师有学生没有的能力), 实验细节在 07 第 4 节; 综述的工业部署一节对应 09 和 10; 综述引用 DeepSeek-R1 的蒸馏数字作 off-policy 够用的反例, 那组数在 [4.8.1 推理模型训练](../4.8-推理与Agent能力/4.8.1-推理模型训练/4.8.1-推理模型训练.md) 第 3.6 节.

## 4. 从哪里读起

### 4.1 第一次接触 OPD

先读 [01 OPD 基础原理](4.9.1-OPD方法与落地/01-OPD基础原理/01-OPD基础原理.md). 它从 MiniLLM 的序列级 reverse KL 和 GKD 的 token 级分布匹配讲到单样本估计与零折扣, 后面各篇都默认读者知道这两条梯度的区别. 再读 [4.9.2 综述](./4.9.2-OPD综述/4.9.2-OPD综述.md), 用三条分类轴把 4.9.1 剩下的十篇放到坐标里, 决定先读哪几篇.

已经熟悉 RL 的读者可以从 RL 一侧进入: [4.8.2 Agentic 能力训练](../4.8-推理与Agent能力/4.8.2-Agentic能力训练/4.8.2-Agentic能力训练.md) 第 4.1 节写了 GLM-5 怎样把 GRPO 的优势换成教师与学生的对数概率差, [4.8.3 SFT 与 RL 的融合策略](../4.8-推理与Agent能力/4.8.3-SFT与RL的融合策略/4.8.3-SFT与RL的融合策略.md) 讨论示范进入 RL 梯度的另外几种形式, 两篇都可以和 01 第 3.2 节对照着读.

### 4.2 手上有具体问题

要把几个领域专家合成一个发布模型, 读 [09 MOPD](./4.9.1-OPD方法与落地/09-MOPD-多教师蒸馏/09-MOPD-多教师蒸馏.md) 和 [10 报告落地对照](./4.9.1-OPD方法与落地/10-OPD-报告落地对照/10-OPD-报告落地对照.md), 前者有 Ma 等在 Qwen3-30B-A3B 上的受控对照 (MOPD 归一化分 0.937, Mix-RL 0.882, 参数平均 0.328), 后者逐条标出各家数字的成立条件. OPD 训着训着长度暴涨或不涨分, 先读 [07 失败模式](4.9.1-OPD方法与落地/07-OPD-失败模式/07-OPD-失败模式.md) 第 5.1 节的症状表.

关心遗忘和持续学习的读者, 读 [4.9.3 状态分布视角](./4.9.3-状态分布视角/4.9.3-状态分布视角.md), 再接 [4.10 持续学习](../4.10-持续学习/4.10-持续学习.md) 里的 RL's Razor. 两处的共同结论是: 决定遗忘程度的主要是训练前缀从哪来, 损失函数和教师是谁的影响比通常以为的小.
