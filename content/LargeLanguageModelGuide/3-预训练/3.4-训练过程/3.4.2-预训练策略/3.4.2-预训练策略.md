## 学习率日程: 余弦与 warmup

### 日程决定什么

结构和并行定好之后, 训练还要回答四个问题:

1. 学习率怎么随步数变化, 衰减在什么时候开始.
2. warmup 多长.
3. batch 多大, 要不要随训练增大.
4. 数据配比和上下文长度要不要分阶段切换.

这四件事都影响最终 loss, 也影响训练的灵活性: 能不能在中途延长训练, 能不能从中间 checkpoint 分叉出不同的末段, 能不能用一次训练得到多个训练长度的结果. 后两项对 Scaling Laws 实验和继续预训练 ([3.5.1](../../3.5-继续预训练与长上下文训练/3.5.1-继续预训练/3.5.1-继续预训练.md)) 的成本有直接影响.

优化器几乎都是 AdamW: Llama 3, DeepSeek LLM, DeepSeek-V3 都是 $\beta_1=0.9$, $\beta_2=0.95$, weight decay 0.1, 梯度裁剪 1.0. PaLM 用不做因子分解的 Adafactor. 优化器本身的推导见 [6.5.1](../../../6-训练与推理优化/6.5-优化器/6.5.1-优化器综述-从SGD到AdamW/6.5.1-优化器综述-从SGD到AdamW.md).

**余弦日程的公式**

线性 warmup 接余弦退火 (Ibrahim 等人 2024 式 1-2 的写法):

$$
\eta_t=\eta_{\max}\cdot\frac{t}{T_{\mathrm{warmup}}},\qquad t\le T_{\mathrm{warmup}} \tag{1}
$$

$$
\eta_t=\eta_{\min}+\frac{\eta_{\max}-\eta_{\min}}{2}\Bigl(\cos\Bigl(\pi\cdot\frac{t-t_{\mathrm{ann}}}{t_{\mathrm{end}}-t_{\mathrm{ann}}}\Bigr)+1\Bigr),\qquad t_{\mathrm{ann}}<t\le t_{\mathrm{end}} \tag{2}
$$

$t_{\mathrm{ann}}=T_{\mathrm{warmup}}$ 是退火开始的步, $t_{\mathrm{end}}$ 是余弦周期结束的步. $t=t_{\mathrm{ann}}$ 时余弦项为 1, 学习率为 $\eta_{\max}$; $t=t_{\mathrm{end}}$ 时为 $-1$, 学习率为 $\eta_{\min}$.

### 余弦日程在公开配置里的终点

| 模型 | $\eta_{\max}$ | $\eta_{\min}$ | 比值 | warmup |
|------|------|------|------|------|
| Kaplan 等人 2020 实验 | 随模型 | 0 | 0 | 3000 步 |
| Chinchilla / Gopher (按 Ibrahim 引述) | 未列出 | $\eta_{\max}/10$ | 10% | 未列出 |
| Llama 3 405B | $8\times10^{-5}$ | $8\times10^{-7}$ | 1% | 8000 步 |
| Llama 3 Scaling Laws 实验 | $2\times10^{-4}$ 至 $4\times10^{-4}$ | $0.1\eta_{\max}$ | 10% | 2000 步 |
| Gupta 等人 2023 (Pythia 410M) | 多档 | $0.1\eta_{\max}$ | 10% | 多档 |
| Code Llama | 沿用 Llama 2 | $\eta_{\max}/30$ | 3.3% | 1000 步 |

Llama 3 405B 的余弦周期是 1,200,000 步, 学习率最终降到峰值的 1%. 它的 Scaling Laws 小模型实验 (40M 到 16B 参数, $6\times10^{18}$ 到 $10^{22}$ FLOPs) 也用余弦: 2000 步线性 warmup, 峰值按模型大小取 $2\times10^{-4}$ 到 $4\times10^{-4}$, 衰减到峰值的 10%, weight decay 取当前学习率的 0.1 倍, batch 按模型大小在 250K 到 4M token 之间. 小实验与正式训练的日程终点不同 (10% 对 1%), 这也是外推时误差的来源之一.

**余弦周期必须对齐训练长度**

Hoffmann 等人 (2022) 在 Chinchilla 论文里指出, 余弦周期设得比实际训练长 25% 以上时性能明显下降; 周期与训练长度相等最好. 这是他们与 Kaplan 结论不同的原因之一: Kaplan 的实验固定了一个较长的余弦周期 (对应 130B token), 中途截取的 loss 是在学习率还没降下来时读到的, 高估了训练不足的模型的 loss.

MiniCPM 在 0.036B 模型上复现: 以模型参数量 $N$ 为单位记训练 token 数, 训练长度 $S$ 取 $20N, 40N, 60N, 80N$ 时, 最低 loss 都由周期 $T=S$ 的余弦取得, $T<S$ 和 $T>S$ 都不是最优. 他们给出的解释有两条: $T=S$ 比 $T<S$ 保持高学习率的时间更长, 比 $T>S$ 的衰减更充分.

这条性质的代价是: 要得到 $k$ 个训练长度的结果就要跑 $k$ 次完整训练, 中途无法延长 (延长就意味着周期变了). Chinchilla 的 Approach 1 对每个模型尺寸跑了 4 个不同周期, 原因就在这里.

### Warmup

各家的 warmup 步数: Kaplan 3000 步, Llama 3 405B 8000 步, Llama 3 Scaling Laws 实验 2000 步, DeepSeek LLM 2000 步, DeepSeek-V3 2K 步, Code Llama 1000 步. Ibrahim 等人引用的综述数字是多数工作的 warmup 占训练步数 0.1% 到 0.5%. Llama 3 405B 的 8000 步占 120 万步的 0.67%.

warmup 的作用是防发散. Wortsman 等人 (2023) 在小模型上测「学习率敏感度」(学习率在三个数量级内变化时最终 loss 偏离最优的程度), 发现 warmup 越长, 敏感度越低, 大模型上最明显: 他们的较大模型不加长 warmup 时无法在学习率 0.3 下稳定训练. 实验固定总步数 $10^5$, 所有模型带 qk-layernorm.

继续预训练的情况不同. Gupta 等人 (2023) 在 Pythia 410M 上从 Pile 继续训练到 SlimPajama, 比较 0%, 0.5%, 1%, 2% 的 warmup, 发现 warmup 长短在他们的设置里影响不大; 直接从最大学习率开始会在初期产生一个大的 loss 尖峰, 但对后续没有影响. 从已训练的权重出发, warmup 防发散的作用小于从随机初始化出发.

## WSD 与多段日程

### 多段阶梯: DeepSeek LLM

DeepSeek LLM (2024) 用多段阶梯日程: 2000 步 warmup 到峰值, 训练到 80% token 时降到峰值的 31.6%, 90% 时再降到 10%. 报告说明它的最终表现与余弦相当, 并且前 80% 的训练可以复用: 要训练更长时, 从 80% 之前的 checkpoint 继续, 不需要从头再跑.

31.6% 约等于 $10^{-1/2}$, 两段阶梯在对数尺度上把学习率各降半个数量级, 总共降到 1/10, 与余弦的常见终点一致.

**WSD: MiniCPM**

MiniCPM 把训练显式分成 warmup, 恒定 (stable), 衰减 (decay) 三段 (原文式 1):

$$
\mathrm{WSD}(T;s)=\begin{cases}\dfrac{s}{W}\eta, & s<W\\[4pt] \eta, & W<s<T\\[4pt] f(s-T)\,\eta, & T<s<S\end{cases} \tag{3}
$$

$W$ 是 warmup 结束步, $T$ 是恒定阶段结束步, $S$ 是总步数, $\eta$ 是最大学习率, $0<f(s-T)\le1$ 是递减函数. 实验结论:

- **衰减阶段 loss 急剧下降**, 很快降到与 $T=S$ 的余弦持平或更低.
- **衰减前的 checkpoint 可复用**: 从恒定阶段的任一 checkpoint 继续用高学习率训练, 再在任意 $S'$ 处衰减, 都能达到 $\mathrm{Cosine}(S')$ 的 loss.
- **衰减 10% 就够**: 从 $40N, 60N, 80N$ 三个恒定阶段 checkpoint 出发, 衰减占总 token 的 10% 能达到最好结果, 2.5% 不够.

MiniCPM 还在 0.2B 模型上统计了衰减阶段的梯度: 指数衰减从第 8000 步开始后, 损失函数的曲率增大一个数量级, 他们认为这说明参数进入了局部最优附近. 恒定阶段的高学习率负责在大范围内移动, 衰减阶段负责收敛到附近的低点, 这是把两段分开的依据.

MiniCPM 的正式训练用指数衰减 $f(s-T)=0.5^{(s-S)/T}$, 其中 $T$ 取 5000 步 (20B token); 指数衰减让学习率降到峰值的 10% 以下后 loss 仍在下降. 他们还观察到 MiniCPM-1.2B 训练曲线上第一次 loss 下降来自增大 batch, 认为它与降低学习率的效果相似.

**恒定加冷却: Hägele 等人**

Hägele 等人 (2024) 系统比较了恒定学习率加冷却 (即 WSD 的另一种叫法) 与余弦:

- **与余弦一致**: 210M 模型在 SlimPajama 上, 余弦换成恒定学习率加 20% 步数的线性冷却到 0, 在不同训练长度下最好的余弦和最好的冷却几乎完全重合, 冷却对学习率的敏感度还略低.
- **冷却长度**: 124M 模型上, 冷却占 10% 到 20% 步数时超过余弦, 冷却收益在约 20% 处趋于平稳, 冷却占大半训练时不再改善.
- **长训练需要的冷却更短**: 200K 步 (约 20B token) 的训练中, 只用 10K 步冷却就几乎完全追平余弦; 用 $(1-\sqrt{\cdot})$ 形状时 5% 的冷却也接近余弦.
- **冷却形状**: 提出

$$
f(n,N,N_{\mathrm{decay}})=1-\sqrt{\frac{n-(N-N_{\mathrm{decay}})}{N_{\mathrm{decay}}}} \tag{4}
$$

$n$ 是当前步, $N$ 是总步数, $N_{\mathrm{decay}}$ 是冷却步数. 冷却开始时 $f=1$, 结束时 $f=0$; 平方根使下降先快后慢. 训练越长, 线性冷却输给 $(1-\sqrt{\cdot})$ 越多.

- **下游指标**: 1B 模型在 FineWeb 上训练 100B token, batch 1.8M, 学习率 $8\times10^{-4}$ (按 DeepSeek LLM 的 Scaling Laws 设定). 综合分: 余弦到 10% 为 46.26, 余弦到 0 为 45.88, 20% 线性冷却 46.20, 20% $(1-\sqrt{\cdot})$ 冷却 46.23. 两种日程在下游任务上也一致. 8B (Llama 3 结构) 只做了一次 12B token 的短训练验证.
- **权重平均**: 随机权重平均 (SWA) 把训练按固定窗口分段, 窗口内平均, 窗口取 500 步, 不超过 2500 步 (256M token) 的窗口最好. SWA 能在不冷却的情况下改善沿途的模型, 但没有完全追平冷却. EMA 的效果比 SWA 差.

两种日程的最优峰值学习率不同. Hägele 等人报告恒定加冷却的最优学习率略低于余弦最优峰值的一半. 这与平均学习率的计算一致: 余弦从 $\eta_{\max}$ 降到接近 0, 全程平均约 $\eta_{\max}/2$; 20% 线性冷却的日程平均为 $0.8\eta+0.2\times\eta/2=0.9\eta$. 要让两者的平均学习率相当, $\eta$ 取余弦峰值的一半略多. 从余弦换到 WSD 时直接沿用余弦的峰值, 等于把全程平均学习率提高近一倍. 1B 实验中余弦降到 10% 比降到 0 的综合分高 0.38, 他们据此建议最大学习率和最终学习率分开扫描.

Hägele 等人的主要用途是降低 Scaling Laws 实验成本: 每个模型尺寸跑一次恒定学习率, 在不同点分叉冷却, 就得到多个训练长度的结果. 他们估算 Chinchilla 的实验套件若改用 10% 冷却, FLOPs 从 $5.59\times10^{23}$ 降到 $2.36\times10^{23}$, 为原来的 42% (见 [3.3.2](../../3.3-模型配置与Scaling-Laws/3.3.2-Scaling-Laws/3.3.2-Scaling-Laws.md) 第 6.1 节).

**DeepSeek-V3: 混合形状**

DeepSeek-V3 的日程把几种形状接在一起:

1. 前 2K 步线性升到 $2.2\times10^{-4}$.
2. 恒定 $2.2\times10^{-4}$ 到 10T token.
3. 4.3T token 内余弦降到 $2.2\times10^{-5}$.
4. 最终 500B token: 前 333B 保持 $2.2\times10^{-5}$, 后 167B 用 $7.3\times10^{-6}$.

总计 14.8T token. 前 10T 是 WSD 的恒定阶段, 中间是余弦形状的衰减, 末尾是两段阶梯. 长上下文扩展阶段的学习率沿用 $7.3\times10^{-6}$. 同一时间点还切换了其他超参数: MTP 损失权重前 10T 为 0.3, 之后为 0.1; 负载均衡偏置的更新速度前 14.3T 为 0.001, 之后为 0.

**几种日程的对照**

| 日程 | 衰减何时开始 | 中途延长 | 分叉多个长度 | 代表 |
|------|------|------|------|------|
| 余弦 | warmup 后立即 | 不行 | 不行 | Llama 3, Code Llama |
| 多段阶梯 | 80% 处 | 从 80% 前继续 | 有限 | DeepSeek LLM |
| WSD / 恒定加冷却 | 末段 10% 到 20% | 从恒定段继续 | 可以 | MiniCPM, Hägele 等人 |
| 混合 | 10T token 后 | 从恒定段继续 | 可以 | DeepSeek-V3 |

后两列是这几种日程的主要分界. 余弦的周期绑定总步数 (第 1.4 节), 中途想多训就要重新开始; 多段阶梯在 80% 之前的 checkpoint 上还能接着训, 但分叉次数受阶梯位置限制. WSD 和恒定加冷却把衰减推到最终 10% 到 20%, 恒定段的任一 checkpoint 都能接一段冷却得到一个可用模型, 所以同一次训练可以产出多个长度的结果, 这也是第 4 节用短衰减评估数据的前提. DeepSeek-V3 的混合日程在 10T token 前同样是恒定段, 后面接余弦和阶梯, 继承了这一性质.

### Batch size

**梯度噪声尺度**

McCandlish 等人 (2018) 用梯度噪声尺度描述 batch 的收益. 设真实梯度 $G$, Hessian $H$, 单样本梯度协方差 $\Sigma$. 用 batch $B$ 的 SGD, 最优步长和每步 loss 改善为:

$$
\epsilon_{\mathrm{opt}}(B)=\frac{\epsilon_{\max}}{1+B_{\mathrm{noise}}/B},\qquad \Delta L_{\mathrm{opt}}(B)=\frac{\Delta L_{\max}}{1+B_{\mathrm{noise}}/B} \tag{5}
$$

其中 $\Delta L_{\max}=\frac{1}{2}\frac{|G|^4}{G^\top HG}$ 是无噪声梯度下一步的最大改善, 噪声尺度:

$$
B_{\mathrm{noise}}=\frac{\mathrm{tr}(H\Sigma)}{G^\top HG}\approx B_{\mathrm{simple}}=\frac{\mathrm{tr}(\Sigma)}{|G|^2} \tag{6}
$$

$B_{\mathrm{simple}}$ 在 Hessian 近似为单位阵倍数时成立, 只需梯度的均值和方差就能估计. 读式 (5): $B\ll B_{\mathrm{noise}}$ 时每步改善正比于 $B$, 加倍 batch 几乎加倍进度; $B\gg B_{\mathrm{noise}}$ 时每步改善趋于饱和, 加倍 batch 只是浪费样本. $B=B_{\mathrm{noise}}$ 时每步改善是最大值的一半.

$B_{\mathrm{simple}}$ 不需要单独计算协方差矩阵. 用 batch $B$ 估计的梯度记为 $G_B$, 它的平方范数期望是 $\mathbb{E}|G_B|^2=|G|^2+\mathrm{tr}(\Sigma)/B$. 在两档 batch $B_{\mathrm{small}}<B_{\mathrm{big}}$ 上各测一次, 两个方程解出两个未知量:

$$
|G|^2\approx\frac{B_{\mathrm{big}}|G_{B_{\mathrm{big}}}|^2-B_{\mathrm{small}}|G_{B_{\mathrm{small}}}|^2}{B_{\mathrm{big}}-B_{\mathrm{small}}},\qquad \mathrm{tr}(\Sigma)\approx\frac{|G_{B_{\mathrm{small}}}|^2-|G_{B_{\mathrm{big}}}|^2}{1/B_{\mathrm{small}}-1/B_{\mathrm{big}}}
$$

数据并行训练里, 单卡的局部梯度和 all-reduce 之后的全局梯度就是现成的两档 batch, 训练中可以顺带估计. 单步估计的方差很大, McCandlish 等人对两个量分别做指数滑动平均, 衰减系数调到估计值稳定为止, 再相除得到 $B_{\mathrm{simple}}$.

**步数与样本的交换**

对整个训练, 达到同一 loss 所需的步数 $S$ 和样本数 $E$ 满足:

$$
\Bigl(\frac{S}{S_{\min}}-1\Bigr)\Bigl(\frac{E}{E_{\min}}-1\Bigr)=1 \tag{7}
$$

$S_{\min}$ 是 batch 无穷大时的最少步数, $E_{\min}$ 是 batch 极小时的最少样本数. 临界 batch 定义为:

$$
B_{\mathrm{crit}}=\frac{E_{\min}}{S_{\min}} \tag{8}
$$

式 (7) 的一组解是:

$$
S=S_{\min}\Bigl(1+\frac{B_{\mathrm{crit}}}{B}\Bigr),\qquad E=E_{\min}\Bigl(1+\frac{B}{B_{\mathrm{crit}}}\Bigr) \tag{10}
$$

代回式 (7), 两个括号减 1 后的乘积为 $\frac{B_{\mathrm{crit}}}{B}\cdot\frac{B}{B_{\mathrm{crit}}}=1$. 代入几档 batch:

| $B/B_{\mathrm{crit}}$ | $S/S_{\min}$ | $E/E_{\min}$ |
|------|------|------|
| 1/4 | 5 | 1.25 |
| 1 | 2 | 2 |
| 4 | 1.25 | 5 |

batch 比临界值小 4 倍, 样本只多 25%, 步数却是最少步数的 5 倍, 训练时间被拉长; batch 比临界值大 4 倍, 步数接近最少, 样本 (也就是算力) 多用 4 倍.

取 $B=B_{\mathrm{crit}}$ 时 $S=2S_{\min}$, $E=2E_{\min}$, 步数和样本都只多用一倍; 超过它, 训练效率 (相对 $E_{\min}$) 降到 50% 以下. 论文还发现临界 batch 在训练过程中会增长一个数量级以上: loss 越低, 梯度信号越弱, 需要越大的 batch 才能把噪声平均掉.

论文在 ImageNet, CIFAR-10, SVHN, MNIST, BillionWord, Atari, Dota, 图像 VAE 共 8 个任务上验证, 临界 batch 从 ImageNet 的数万张图到 Dota 智能体的数百万帧, $B_{\mathrm{simple}}$ 在量级上都能预测它. 两者的比值在任务间能差约一个数量级, 原因是 $B_{\mathrm{simple}}$ 不考虑 Hessian 的条件数. 学习率日程会改变噪声尺度: ImageNet 实验的学习率降了三次, 每一档学习率都要单独测.

Kaplan 等人把临界 batch 写成 loss 的函数 $B_{\mathrm{crit}}(L)=B_*/L^{1/\alpha_B}$, $B_*\approx2\times10^8$ token, $\alpha_B\approx0.21$, 即 $1/\alpha_B\approx4.8$. 代入几个 loss (Kaplan 在 WebText2 上的 nats): $L=3$ 时约 $1.1$M token, $L=2.5$ 时约 $2.5$M token. loss 降 0.5, 临界 batch 增大约 2.4 倍, 这就是第 3.3 节 batch 递增的依据. MiniCPM 拟合的最优 batch 也是 loss 的幂律: $bs=1.21\times10^9/L^{6.24}$ (token).

**batch 递增**

临界 batch 随训练增长, 于是公开配方都在训练早期用较小的 batch:

| 模型 | batch 递增 |
|------|------|
| Llama 3 405B | 4M token (序列 4096), 252M token 后 8M (序列 8192), 2.87T token 后 16M |
| DeepSeek-V3 | 前 469B token 从 3072 条增到 15360 条 (序列 4K) |
| PaLM 540B | 1M token 到第 50k 步, 2M 到第 115k 步, 4M 到第 255k 步 (序列 2048) |

Llama 3 报告说明这套配方 loss spike 很少, 训练中不需要干预来纠正发散. 递增 batch 的另一个效果是早期步数更多: 同样的 token 数, batch 小一半, 参数更新次数多一倍. 按 Llama 3 的切换点换算: 前 252M token 用 4M batch, 约 60 步; 到 2.87T token 之前用 8M batch, 约 34 万步; 其余约 12.7T token 用 16M batch, 约 76 万步. 前 18% 的 token 占了约 31% 的步数.

式 (10) 解释了为什么早期用小 batch 不吃亏: 早期 loss 高, $B_{\mathrm{crit}}$ 小, 小 batch 已经接近或超过临界值, 再大只是多耗样本; 后期 $B_{\mathrm{crit}}$ 增大, 同样的小 batch 会让步数膨胀, 这时再加大 batch.

### 从预算外推 batch 和学习率

DeepSeek LLM 把最优 batch 和学习率直接拟合成计算预算 $C$ 的幂律:

$$
\eta_{\mathrm{opt}}=0.3118\cdot C^{-0.1250},\qquad B_{\mathrm{opt}}=0.2920\cdot C^{0.3271} \tag{9}
$$

$C=10^{22}$ 时 $\eta_{\mathrm{opt}}=5.5\times10^{-4}$, $B_{\mathrm{opt}}=4.6$M token; $C=10^{24}$ 时 $3.1\times10^{-4}$ 和 20.7M token. 他们在 $10^{17}$ 和 $10^{20}$ FLOPs 上扫描 batch 和学习率, 发现泛化误差在相当宽的取值范围内保持稳定, 近优区域很宽. 拟合用的模型 (预算 $10^{17}$ 到 $2\times10^{19}$) 正是靠多段阶梯日程复用第一阶段训练出来的. Qwen3 报告也用 Scaling Laws 为每个模型预测学习率日程和 batch, 未给出系数.

## 退火, 数据课程与长上下文

### Llama 3 的退火

Llama 3 §3.1.3 的「退火」指学习率降到很低的末段, 同时上采样高质量数据.

- **效果随规模递减**: 在 Llama 3 8B 上退火时上采样高质量代码和数学数据, GSM8k 验证集提升 24.0%, MATH 验证集提升 6.4%; 在 405B 上提升可以忽略. 报告的解释是旗舰模型的上下文学习和推理能力已经很强, 不需要领域内的训练样本.
- **用退火评估数据**: 取训练到 50% 的 8B 模型, 在 40B token 内把学习率线性降到 0, 数据中 30% 是待评估的新数据, 70% 是默认配比. 比较退火后的效果来判断新数据的价值, 比做完整的 Scaling Laws 实验便宜. 报告说明这一做法与 Blakeney 等人 (2024) 类似, 适合判断小规模领域数据集的价值. 30% 的新数据权重配合学习率降到 0, 让新数据在模型收敛的那一段集中起作用, 一次 40B token 的退火就能得到可比较的评测结果.
- **正式训练的末段**: §3.4.3 在最终 40M token 内把学习率线性降到 0, 此时上下文长度为 128K, 数据配比上调高质量来源; 最终对退火阶段的 checkpoint 做 Polyak 平均, 得到最终的预训练模型.

退火之前, 配比在训练中途也在变. Llama 3 §3.4.1 列出训练中途对数据配比的调整: 增加非英语数据以改善多语言表现, 上采样数学数据, 后期加入更新的网页数据以推进知识截止时间, 下采样后来被判定为低质量的子集. 最终配比为通用知识 50%, 数学与推理 25%, 代码 17%, 多语言 8%.

### 分阶段配比与数据重复

Qwen3 的预训练共 36T token, 覆盖 119 种语言, 分三段:

1. **S1 通用阶段**: 超过 30T token, 序列 4096.
2. **S2 推理阶段**: 约 5T 更高质量的 STEM, 代码, 推理数据, 序列 4096, 加快学习率衰减.
3. **S3 长上下文阶段**: 见第 4.3 节.

MiniCPM 在衰减阶段把高质量 SFT 类数据 (UltraChat, SlimOrca, OssInstruct, EvolInstruct 和自有的 LeetCode, K12 题库) 混入预训练数据. 报告说明之后仍需单独的 SFT 阶段, 用约 6B token, 学习率对齐退火末端, 同样用指数衰减的 WSD.

这几种做法的共同点: 高质量数据放在学习率低的末段. 第 2 节的 WSD 让这一点变得方便, 衰减段可以从恒定段的任一 checkpoint 分叉, 换不同的数据配比各跑一次再比较.

高质量数据放到末段, 数量往往不够, 就要重复训练. Muennighoff 等人 (2023) 发现重复最多 4 个 epoch 与使用全新数据相比 loss 几乎没有差别, 超过约 16 个 epoch 后再加重复几乎没有价值 (见 [3.3.2](../../3.3-模型配置与Scaling-Laws/3.3.2-Scaling-Laws/3.3.2-Scaling-Laws.md) 第 4.1 节). Code Llama 对代码数据训练了 2.03 个 epoch, Code Llama - Python 对 Python 数据训练了 3.69 个 epoch, 都在 4 个 epoch 以内.

### 长上下文阶段

注意力的计算和激活都随序列长度增长 (见 [3.3.1](../../3.3-模型配置与Scaling-Laws/3.3.1-确定模型结构与参数/3.3.1-确定模型结构与参数.md) 第 3.2 节), 长上下文能力在训练末段单独训练. Llama 3 §3.4.2 给出的理由就是自注意力的计算随序列长度平方增长, 所以不在早期训练长序列; 长度按阶段递增, 每一段训练到模型适应了当前长度再进入下一段.

| 模型 | 起点 | 终点 | 做法 | 规模 |
|------|------|------|------|------|
| Llama 3 405B | 8K | 128K | 6 个阶段逐步加长 | 约 800B token |
| DeepSeek-V3 | 4K | 32K, 128K | YaRN, 两个阶段各 1000 步, batch 1920 和 480 条, 学习率 $7.3\times10^{-6}$ | |
| Qwen3 | 4096 | 32768 | ABF 把 RoPE 基频从 10,000 提到 1,000,000; 75% 数据长 16K 到 32K, 25% 长 4K 到 16K | 数千亿 token |
| Code Llama (LCFT) | 4096 | 16384 | RoPE 基频改为 $10^6$, 学习率 $2\times10^{-5}$ | 默认 10,000 步 |

Llama 3 判断每个阶段是否完成的标准有两条: 短上下文评测完全恢复, 大海捞针在当前长度上全部正确 (见 [3.6.3](../../3.6-预训练评估/3.6.3-大海捞针测试/3.6.3-大海捞针测试.md)). Qwen3 在推理阶段再用 YaRN 和 DCA 把可用长度扩到训练长度的 4 倍.

长上下文阶段使用的并行配置也不同: Llama 3 在 128K 阶段加入 16 路上下文并行, 数据并行从 64 降到 8, 每步仍是 16M token, MFU 从 43% 降到 38% (见 [3.4.1](../3.4.1-训练框架选择/3.4.1-训练框架选择.md) 第 5.5 节). 数据构造与外推方法见 [3.5.2](../../3.5-继续预训练与长上下文训练/3.5.2-长上下文训练与数据/3.5.2-长上下文训练与数据.md).

## 稳定性与边界

### 与稳定性有关的设置

几项设置的主要目的是防发散, 在日程设计时一并确定:

- **梯度裁剪**: Llama 3, DeepSeek LLM, DeepSeek-V3, PaLM 都是 1.0. OPT 在训练中途把裁剪阈值从 1.0 降到 0.3 以应对发散.
- **z-loss**: PaLM 加辅助损失 $10^{-4}\cdot\log^2Z$, $Z$ 是 softmax 的归一化项, 促使 $\log Z$ 接近 0. Wortsman 等人在小模型上复现了输出 logit 发散: 不加 weight decay 时无论规模都会出现, z-loss 能消除它, weight decay 对较大模型也有缓解作用.
- **qk-layernorm**: 对 Q 和 K 做归一化, 抑制注意力 logit 增长. Wortsman 等人发现这一不稳定性在小模型高学习率下也会出现, qk-layernorm 让训练在三个数量级的学习率范围内保持稳定. Qwen3 采用 QK-Norm.
- **AdamW 的 $\epsilon$ 与 weight decay**: Wortsman 等人发现梯度范数随规模和学习率增大而减小, 默认 $\epsilon$ 相对变大, 更新被压小; 把学习率和 weight decay 独立缩放 (改学习率时不连带改变实际衰减强度) 能降低学习率敏感度. 换规模重扫学习率时, 这两个常数要一起检查. Llama 3 小实验里 weight decay 随学习率按 0.1 倍变化, 是相反的耦合写法.
- **PaLM 的其他选择**: 学习率前 10k 步恒定 $10^{-2}$, 之后按 $1/\sqrt{k}$ 衰减 ($k$ 为步数); $\beta_2=1-k^{-0.8}$, 让二阶矩在早期更快更新; weight decay 取 $\mathrm{lr}^2$; 不用 dropout.

发散后的处理 (回滚, 跳过 batch, 降学习率) 和监控指标见 [3.4.3](../3.4.3-训练容灾与监控/3.4.3-训练容灾与监控.md).

### 边界

前面的结论大多来自中小规模的实验:

- MiniCPM 的 WSD 实验在 0.036B 到 2.4B 的模型上; Hägele 等人的系统实验在 33M 到 360M, 另有 1B (100B 和 460B token) 和一次 8B 短训练的验证; Gupta 等人在 410M. DeepSeek-V3 的混合日程是 671B 规模上的公开证据, 但没有给出与余弦的对照.
- Llama 3 的退火收益在 8B 上很大, 在 405B 上可以忽略. 末段上采样的收益要在目标规模上重新验证.
- McCandlish 的理论假设二次近似和平稳的噪声结构, 给出的是量级, 实际 batch 还要服从并行配置 (每个 DP 组的 batch 要足够大以压低流水线气泡).

日程还会影响评测. WSD 恒定阶段的 checkpoint loss 偏高, 衰减后才反映真实水平. 用恒定阶段的 checkpoint 做中途评测或判断数据好坏时, 要先做一次短衰减. Llama 3 用 40B token 退火评估数据, MiniCPM 用 10% 衰减比较不同恒定段 checkpoint, 都是这个思路.

「退火」「冷却」「衰减段」在不同报告里指的东西不完全一样: Llama 3 的退火同时改数据配比, Hägele 等人的冷却只指学习率形状. 下表把这几个词和另外几个易混的概念放在一起:

| 名字 | 指什么 | 区别 |
|------|------|------|
| 退火 (annealing, Llama 3) | 学习率降到很低的末段, 同时上采样高质量数据 | 不仅是学习率形状, 还包括数据配比 |
| 冷却 (cooldown, Hägele) | WSD 的衰减段 | 只指学习率形状 |
| decay stage (MiniCPM) | 同上 | MiniCPM 在这一段混入 SFT 数据 |
| 课程学习 | 按难度或质量排序数据 | 预训练里常见的是按阶段切换配比, 不是逐样本排序 |
| 临界 batch | 步数与样本数折中的拐点, 式 (8) | 不是显存允许的最大 batch |
| Polyak 平均 | 对末段若干 checkpoint 的权重取平均 | SWA 是按窗口平均, EMA 是指数滑动平均 |
