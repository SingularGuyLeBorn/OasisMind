# 第11讲:把 Scaling Law 用进真实训练

上一讲建立了一个很诱人的想法:先训练一批便宜的小模型,拟合损失随参数、数据和计算量的变化,再预测真正昂贵的大模型.然而,一旦把它放进训练计划,问题马上具体起来.每个规模都完整训练一遍吗?学习率和 batch 是否需要重新搜索?在什么时刻读取损失才算公平?如果最后的 decay 会显著改善损失,处于稳定学习率阶段的 checkpoint 又该怎样比较?**Scaling law 真正困难的部分,经常不是拟合公式,而是设计一组能够代表未来大训练的实验.**

这一讲讨论的正是这段从曲线到决策的距离.Cerebras-GPT、MiniCPM、DeepSeek LLM、Llama 3、Hunyuan 与 MiniMax 给出了不同规模、预算和公开程度下的案例;WSD 调度让一条长训练轨迹可以在多个位置分叉并完成衰减;μP 则尝试让小模型搜索出的超参数跨宽度迁移.它们共同回答一个工程问题:怎样把原本要在最大规模上支付的试错成本,尽量移到小规模和训练早期.

## 先规定「可比较」是什么意思

设一组实验的计算预算近似满足 $C\approx6ND$.IsoFLOP 分析会在同一 $C$ 下选择多组参数量 $N$ 和 token 数 $D$,观察哪一组最终验证损失最低.这个设计只有在架构族、数据分布、tokenizer、优化器和损失计算口径相近时才有解释力.若一个点使用更干净的数据,另一个点多做了一段退火,曲线差异就混入了规模以外的变量.

真实团队还要处理训练失败和有限试验数.小模型可能受固定词表或 embedding 参数占比影响,大模型可能遇到此前没有出现的通信、数值稳定性和数据吞吐瓶颈.拟合时因此不应只保留一条回归线,还要查看残差、不同规模区间的稳定性,以及目标点距离观测区间有多远.外推十倍和外推一千倍承担的风险完全不同.

Cerebras-GPT 的价值在于用一族公开模型展示了 compute-optimal 训练如何落实为尺寸系列.MiniCPM 更进一步,把 μP、较长训练数据和 WSD 放到同一套方法中.DeepSeek LLM 公开了学习率与 batch 的网格探索、IsoFLOP 拟合和预测验证,使人能够看到最终公式之前经历了哪些控制变量.后续案例则提醒我们,各团队对部署成本、数据上限和下游能力的重视不同,因此不会从同一条曲线导出完全相同的训练方案.

## WSD:在一条长轨迹上建立多个观察窗

常见 cosine schedule 从峰值学习率一路缓慢下降.若想比较 100B、200B 和 400B token 的训练终点,直接截取 cosine 中途的 checkpoint 并不公平:早期点仍处在按更长总预算设计的学习率上,还没有得到终点的衰减收益.为每个预算重新训练一遍又很昂贵.

WSD(Warmup–Stable–Decay)把调度拆成三个阶段.Warmup 让优化从初始状态平稳进入工作区;Stable 在较长区间保持近似恒定的学习率;Decay 在选定终点前完成退火.研究者可以从 stable 阶段的不同 checkpoint 分叉,各自运行一段 decay,于是一次主干训练产生多个「如果在这里结束」的可比终点.这种 rewind-and-decay 方法大幅降低绘制 token scaling 曲线的成本,也让团队能在训练途中依据新预算选择结束位置.

WSD 没有免费制造样本.每个分叉仍需支付 decay 的额外计算,而且 stable 阶段的状态、优化器动量和数据顺序都会进入结果.比较 WSD 与 cosine 时,也应区分相同 token 预算、相同峰值学习率和相同最终学习率等口径.它提供的是更灵活的实验基础设施,不保证任意任务上的最终损失都更低.

## μP:把超参数搜索搬到代理模型

宽度从 $n$ 增大到 $kn$ 时,标准参数化可能改变激活与更新的尺度.此时,小模型上最优的学习率放到大模型上会发生漂移,scaling 实验不得不为每个尺寸重新调参.μP 为输入层、隐藏层、输出层和偏置规定不同的初始化、学习率或乘子缩放,使宽度增长时,前向信号保持稳定,参数更新对特征的影响也维持在有限且非零的量级.

「maximal update」的含义是:在不让激活或输出爆炸的前提下,允许特征学习保持尽可能大的阶.它依赖 tensor program 对宽度极限的分析,落地时则表现为一张参数类型与缩放规则的表.若改变深度、残差结构、优化器或宽度定义,迁移条件需要重新核对.SP(standard parametrization)和 μP 的差异也不能靠在代码里统一乘一个系数解决.

Lingle 等工作对 μTransfer 做了更大范围的实证检查:学习率的迁移通常最受关注,但 batch size、初始化尺度、权重衰减以及 Adam 的逐参数统计都有各自边界.**μP 提高了代理实验的含金量,却不会让代理模型自动包含大模型才出现的数据、系统与能力现象.**

## 从预测数字回到训练决策

一套可用的 scaling 研究要在正式训练前写出决策规则.例如,团队可以先给定候选预算,拟合每个预算下的最优 $N,D$,再加入部署侧的权重容量与推理量,得到若干可执行方案.随后为预测保留区间而非只报单点:参数量、token 数和预期损失都应带上由拟合残差和设定变化产生的不确定性.预算只允许训练一次时,选择落在宽阔低谷附近的配置,通常比追逐一个尖锐的理论最低点更稳.

正式训练也需要在线校验.早期 loss、梯度范数、学习率响应和吞吐应与代理实验按相同坐标对齐;偏离预测时,要判断是随机波动、数据版本差异、超参数迁移失败,还是系统错误.若只等训练结束再解释曲线,scaling law 就失去了风险控制的价值.WSD 的 stable 区间尤其适合持续更新估计,并在预算变化时选择新的 decay 分叉.

最后一次验证应同时覆盖拟合量与业务目标.损失命中预测,说明计算规划大体成立;目标 benchmark、鲁棒性和推理成本仍需单独检验.某个数据配比可能以很小的平均 loss 代价换来显著代码能力,另一种配置可能拥有更低 loss 却不适合部署.案例研究真正教会我们的,是怎样把统计规律嵌入一连串可撤销、可观察的工程决定.
