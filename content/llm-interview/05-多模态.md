# 多模态：视觉、语音与视频模型

多模态面试的核心不是背模型名，而是追踪信息怎样经过系统：**原始模态如何编码、怎样压缩成 token、怎样与语言模型交互、用什么目标训练、最后如何证明模型真的在看输入而不是依赖语言先验**。

## 1. 先定义任务与输入契约

“多模态模型”可能指完全不同的系统：

| 任务 | 输入与输出 | 核心难点 |
|---|---|---|
| 图文检索/分类 | 图像与文本 → 相似度或类别 | 全局语义对齐、负样本、校准 |
| 图像问答/描述 | 图像 + 文本 → 文本 | 细粒度 grounding、幻觉、OCR |
| 文档理解 | 页面、版面、文字 → 结构化输出 | 高分辨率、版面、表格与坐标 |
| 视频理解 | 帧/片段 + 文本 → 文本或时间段 | 时间采样、长序列、动作与因果 |
| 语音对话 | 音频 + 文本 → 文本或音频 | 流式延迟、打断、韵律、说话人与噪声 |
| 生成模型 | 文本/图像/音频 → 新模态 | 生成目标、可控性、一致性与安全 |

回答架构前先问：是否要生成像素/音频，还是只把非文本输入作为语言模型条件；是否要求实时、坐标输出、多图、多轮或长视频。

## 2. 通用数据流

```text
原始图像/音频/视频
  → 预处理与采样
  → 模态编码器
  → 连接器或重采样器
  → 与文本 token 交互
  → 语言头、检索头或生成解码器
```

每个箭头都可能丢失信息。图像缩放会损失小字，固定帧采样会漏掉短暂事件，连接器压缩会丢局部细节，语言模型还可能用常识补齐不存在的内容。

### 2.1 视觉 token 数为什么重要

若视觉 token 直接进入 self-attention，上下文长度和计算会随视觉 token 增长。高分辨率常见方案包括切块、动态分辨率、局部到全局聚合、token pruning、resampler 或多尺度编码。比较模型时不能只报“支持 4K 图片”，还应问预处理后的 patch/token 数、是否裁切、坐标如何映射回原图。

## 3. 四种代表性范式

| 范式 | 模态交互 | 代表工作 | 更适合回答的问题 |
|---|---|---|---|
| 双编码器 | 图像与文本独立编码，在共享空间比较 | CLIP | 检索、零样本分类、全局对齐 |
| 插入式 cross-attention | 语言层周期性读取视觉特征 | Flamingo | 交错图文、few-shot、多图/视频条件 |
| 查询压缩器 | 学习 query 从冻结视觉特征抽取固定数量表示 | BLIP-2 | 冻结编码器与 LLM 的高效桥接 |
| projector + LLM | 将视觉特征投到语言嵌入空间 | LLaVA 系列 | 简洁的视觉指令微调基线 |

这张表是论文原始设计的抽象，不应把模型家族后续版本的所有实现压成一个标签。尤其是 Qwen-VL 等快速迭代家族，其视觉编码器、位置表示、分辨率和训练配方会随版本变化；面试时要先说具体版本与官方技术报告。

## 4. CLIP：对称图文对比学习

CLIP 使用图像编码器 $f_I$ 和文本编码器 $f_T$，对归一化表示计算批内相似度：

$$
s_{ij}=\frac{f_I(I_i)^\top f_T(T_j)}{\tau}.
$$

训练损失不是只有单向 image-to-text，而是两个交叉熵的平均：

$$
\mathcal{L}_{CLIP}=\frac{1}{2}\left(
\mathcal{L}_{I\rightarrow T}+\mathcal{L}_{T\rightarrow I}
\right).
$$

批内其他样本作为负例，因此 batch 构成、重复 caption、温度和分布式特征聚合都会影响训练。零样本分类通过把类别写成文本提示并比较相似度实现；提示模板、类别集合和校准会显著影响结果。

CLIP 的双塔适合检索和全局语义，但不会直接生成长文本，也不天然保留像素级坐标。给它接语言模型前还需要定义视觉信息如何被读取。

## 5. 连接器：MLP、Q-Former 与 cross-attention

### 5.1 Projector

线性层或 MLP 将视觉特征映射到 LLM 的嵌入维度。原始 LLaVA 使用简单线性投影；LLaVA 1.5 等后续版本采用两层 MLP projector，因此不能笼统说“LLaVA 都只用一个线性层”。

优点是接口简单、易复用预训练视觉塔和 LLM；代价是视觉 token 数可能较多，而且“维度对齐”不等于语义和空间关系已经充分对齐。

### 5.2 BLIP-2 的 Q-Former

Q-Former 包含可学习 query，通过 cross-attention 读取冻结图像编码器输出。它把可变数量的视觉特征压缩成固定数量的 query 表示，再连接冻结 LLM。

关键纠错：query 并非只靠 Language Modeling Loss 学习。BLIP-2 分两个预训练阶段：

1. **视觉—语言表示学习**：使用图文对比（ITC）、图文匹配（ITM）和以图像为条件的文本生成（ITG）等目标；
2. **视觉到语言的生成学习**：把 Q-Former 输出通过投影接入冻结 LLM，用生成目标学习让 LLM 使用视觉条件。

Q-Former 的价值是可学习的信息瓶颈和冻结模块桥接；代价包括 query 容量上限、训练复杂度和对细粒度视觉信息的潜在丢失。

### 5.3 Flamingo 的插入式 cross-attention

Flamingo 先用 Perceiver Resampler 把可变视觉特征压缩为固定数量 token，再在冻结语言模型层之间插入 gated cross-attention，让文本位置读取对应图像或视频条件。它面向交错图文序列和 few-shot 提示，不只是“一层普通 cross-attention”。

## 6. LLaVA 的两阶段训练应按版本回答

原始 LLaVA 的基本思路是：

1. 用图文对训练 projector，使视觉特征能进入语言空间；
2. 用生成的视觉指令数据进行端到端视觉指令微调。

后续版本改变了视觉塔、projector、分辨率、训练数据和微调范围。生产选型不能仅因 projector 简单就默认选它，还要比较 OCR、grounding、多图、长上下文、吞吐、许可和本领域评测。

## 7. 多模态训练不是固定“三阶段”

常见目标可按能力分组：

| 目标 | 学到什么 | 典型风险 |
|---|---|---|
| 对比学习 | 全局图文对齐 | 假负例、细粒度信息不足 |
| 匹配/排序 | 判断图文是否对应 | 容易学习数据捷径 |
| 条件语言建模 | 用模态输入生成文本 | 语言先验掩盖视觉缺失 |
| 多模态 SFT | 指令遵循和输出格式 | 合成指令偏差、模板化 |
| 偏好优化/RL | 选择更有用或可验证的回答 | 奖励偏差、视觉证据未被使用 |

不同论文可能冻结视觉塔、冻结 LLM、只训练连接器，或分阶段解冻。不能把“对齐 → SFT → RLHF-V”写成所有系统的统一流程。应逐项说明哪些参数可训练、数据来自哪里、损失落在哪些 token 上。

## 8. 视频模型：空间正确不等于时间正确

视频理解至少多出四个选择：

1. **采样**：均匀采帧、镜头检测、事件驱动或学习式选择；
2. **时间位置**：模型如何知道顺序、间隔和真实时间戳；
3. **压缩**：逐帧 token、tubelet、时空编码器或分层摘要；
4. **评测**：事件定位、顺序、计数、长程一致性和音画对齐。

只在抽取的若干帧上做图像问答，可能答对场景却答错“先后”“持续多久”“谁导致了什么”。面试方案应包含时间扰动对照：打乱帧、删除关键帧、改变采样率，观察答案是否按预期变化。

## 9. 语音系统：级联与端到端

| 方案 | 路径 | 优点 | 风险 |
|---|---|---|---|
| 级联 | ASR → LLM → TTS | 模块可替换、文本可审计、工程成熟 | 错误级联、韵律与情感信息损失 |
| 端到端/统一 token | 音频编码或离散 token → 模型 → 音频 token | 低延迟潜力、保留非文本线索 | 数据和训练复杂、可控性与安全审计更难 |

实时语音还必须讨论首包延迟、流式分块、端点检测、打断与续说、回声消除、说话人混淆和有害声音生成。文本 benchmark 不能替代真实通话评测。

## 10. 评测：证明模型使用了模态证据

至少包含：

- **任务质量**：VQA、OCR、文档、grounding、视频时间任务、ASR/TTS 等分项；
- **反事实对照**：替换图片、遮挡区域、打乱视频、静音音频，答案应随证据变化；
- **幻觉**：对象、属性、关系、文字、计数和时间事件分别统计；
- **鲁棒性**：分辨率、压缩、噪声、语言、肤色/口音、长输入；
- **系统指标**：视觉 token 数、TTFT、显存、吞吐、长视频成本；
- **安全**：图中文字提示注入、隐写、对抗 patch、隐私、肖像与深伪滥用。

“模型答对”仍可能来自题目先验。应加入 image-agnostic baseline、空白图和错配图，验证模型是否真的读取视觉或音频。

## 11. 高频追问

### 为什么不总选最复杂的连接器？

连接器容量只是系统的一部分。瓶颈可能在视觉分辨率、数据质量、LLM 能力或上下文成本。应通过固定骨干和数据的消融，比较 projector、resampler、query 和 cross-attention，而不是按结构复杂度猜效果。

### 多模态幻觉怎样定位？

先区分感知失败、连接器压缩、语言解码偏置和数据标注错误；再用区域遮挡、反事实图片、logit/attention 探针和可验证 OCR/检测器定位。最后按错误类型设计数据和损失，而不是统一加一句“请仔细看图”。

### 如何评估多图或长视频能力？

固定总 token 预算，控制图像数量和位置；测试跨图实体绑定、顺序、遗漏和干扰项；报告采样策略与实际进入模型的 token，不能只报原始视频时长。
