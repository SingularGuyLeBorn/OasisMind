# 量化 dLLM:掩码态和去噪步都要管

加速相关章节让每一步更便宜或更少步.Serving 相关章节换调度器.两边默认权重仍是 FP16.Yan,Wang,Wan,Yu,Tsang 的 STaR-Quant(arXiv:2606.04945)问的是下一档:权重量化到 4 bit,激活也量化到 4 bit 之后,掩码去噪还能否用.直接把 RTN,AWQ,QuaRot 复制过来,九项均分会从 LLaDA 的 58.99 掉到 44 至 51.他们认了两件扩散特有的事:同一步里 `[MASK]` 和明文的激活不是同一张分布;这一步的量化误差会变成下一步的输入,沿轨迹叠起来.

摘要「最多 1.69× 加速,3.14× 省显存」对照的是 **FP16 部署**,表是 Table 4 的 Dream 行:吞吐 23.27 到 39.33 tok/s,峰值显存 13.95GB 到 4.44GB.正文里还有另一个 1.69:Dream 上 STaR-Quant 均分相对 DLLMQuant++ 高 1.69 **分**.一个是倍数,一个是百分点.写错对照物,1.69 会变成一句无依据结论.主表硬件是 NVIDIA A40,校准 128 段 WinoGrande,无需微调.测的是 LLaDA-8B,LLaDA-1.5-8B,Dream 7B.NPU 上的 DART,视频扩散的 KV 量化,不是这张表.

DLLMQuant(Xu 与 Yang,arXiv:2508.14090)是作者当强基线用的扩散专用 PTQ;DLLMQuant+ 接 AWQ,DLLMQuant++ 接 QuaRot.Lin 等人「Quantization meets dLLMs」(arXiv:2508.14896)提供的判断是:AR 向 PTQ 直接搬到 dLLM,权重量化加激活量化时掉得更狠.STaR-Quant 站在这两篇后面,主结果是 Table 1 的 W4A4.

## 1. 同一步两种激活,下一步还要接着用

自回归模型的 prefill 会处理整段输入, 常规逐 token decode 则处理当前新位置;量化方法可以使用静态校准尺度, 也可以在运行时计算激活尺度. STaR-Quant 针对的是掩码扩散中同时存在的两种 token 状态. 掩码位置等待预测, 明文位置提供可见上下文. 作者 Figure 1 中, 两态的激活范围和离群点分布不同. 即使逐 token 各自计算量化尺度, 同一套共享变换也未必能同时平滑两态的离群点. 这就是论文所说的「状态相关激活差异」.

量化误差还会通过生成状态影响后续步骤. 某步的注意力误差改变 logits, 可能改变选出的 token 或提交集合;这些离散决策进入下一步输入, 再影响下一次预测. 全量重算时, 上一步的隐藏激活并不直接送给下一步 Query. 跨步传播依赖采样状态与缓存策略, 不等于把隐藏表示逐步相加. 论文将这一问题称为 **temporal error accumulation**.

STaR-Quant 用状态相关的激活变换处理两态差异, 再在注意力输出投影前做仿射校正. PTQ 冻结原模型参数, 仍需计算校准激活并优化变换基;校准完成后, 权重侧变换预先折入量化权重, TAC 参数固定复用.

一步在实现里长什么样.输入序列带着当前掩码图案.线性层先按态切成两行块 $X^m_t$,$X^u_t$,各自乘门控后的 $P$,量化,再乘同一份 $W_f$,按原下标写回.注意力仍按整段(或当前块)算 $Q,K,V$,Softmax–$V$ 之后的 $\hat Z$ 进 TAC,再进量化的输出投影.下一步掩码图案变了,同一位置可能从 $m$ 变成 $u$,SGAT 会换门,权重 $W_f$ 不变.这就是「态在 token 上变,权重在层上静」.AR 的 PTQ 没有这道切分:因果解码里当前步通常只有一个新位置,没有一大片 `[MASK]` 和一大片明文共享一次前向.

评测九项跟 LLaDA 论文的任务清单走:TruthfulQA-MC2,ARC-Challenge,HellaSwag,WinoGrande,PIQA,MMLU,C-EVAL,HumanEval,GSM8K.均分是这九个数的算术平均.作者写「跟随 LLaDA 评测设定」,**Table 1 的 FP 列不是 Nie Table 1**.本表 LLaDA FP:MMLU 65.85,GSM8K 67.48,HumanEval 32.92,均分 58.99.Nie 的 8B Base 是 MMLU 65.9,GSM8K 70.3,HumanEval 35.4.协议一换,GSM8K 就能差两点以上.量化掉分只能相对**同一张表的 FP 列**谈.

### 1.1. 图 1 解析

位置1从掩码态变为明文态后, 下一步重新确定它所属的激活分支. 当前步的行1、3经过掩码态门控与量化, 行2、4经过明文态门控与量化. 两路读取同一份 $W_f$, 乘法结果按原位置写回, 保持 token 顺序.

## 2. SGAT:两态不同变换,权重仍一份

线性层 $Y=XW^\top$. 变换量化把计算改写成 $Y=(XP)(P^{-1}W^\top)$, 激活在更平滑的空间里量化, 逆变换折进权重. 使用共享变换时, $P$ 对所有 token 共用. 扩散里同一份 $W$ 要同时处理掩码激活和明文激活. 若为两态分别选择变换 $P_m,P_u$, 并分别保存 $P_m^{-1}W^\top$ 和 $P_u^{-1}W^\top$ 的量化结果, 就需要两份权重存储. 两份 4 bit 权重的主体约占一份 4 bit 权重的两倍, 虽仍小于一份 FP16 权重, 却削弱了压缩收益.

SGAT 把隐层维拆成共享加两态专属:

$$
d=d_{\mathrm{sh}}+d_m+d_u,\qquad P=[U_{\mathrm{sh}},\,U_m,\,U_u].
\tag{1}
$$

掩码态门 $G_m=\mathrm{diag}(1_{d_{\mathrm{sh}}},1_{d_m},0_{d_u})$,明文态门 $G_u=\mathrm{diag}(1_{d_{\mathrm{sh}}},0_{d_m},1_{d_u})$.掩码 token 走 $P G_m$,明文走 $P G_u$.共享方向两边都看见,专属方向互不干扰.权重侧只保留与完整 $P$ 对应的一份变换 $\tilde P$,正交时 $\tilde P=P^\top$.量化权重

$$
W_f=Q_w(\tilde P W^\top)
\tag{2}
$$

只算一次.两态激活分别 $Q_a(\Phi_s(X^s_t))$ 再乘同一份 $W_f$,再按原位置拼回.FreeAct(Liu 等人 2026)提供「激活变换可以按状态条件化,权重仍静态」的先例;SGAT 把状态定义成掩码 / 明文,而不是 AR 里的层或通道组.

**门控后是否严格等价, 取决于被关闭坐标对输出的贡献是否为零.** 对正交 $P$, 令 $G_s^\perp=I-G_s$. 暂不量化时, 原始输出与门控输出的差为

$$
\begin{aligned}
\Delta_s&=X^sW^\top-X^sPG_sP^\top W^\top\\
&=X^sPG_s^\perp P^\top W^\top.
\end{aligned}
$$

其中 $X^s$ 是状态 $s$ 对应的激活行, $G_s^\perp$ 选出被关闭的坐标. 严格等价要求 $\Delta_s=0$. [附录 A](https://arxiv.org/html/2606.04945v2#A1)使用更强的 $X^sPG_s^\perp=0$ 作为充分条件:被关闭的坐标本来就没有激活, 自然不会改变输出. 反过来, 非零坐标也可能落在权重映射的零空间中. 取 $P=I$, $G_s=\operatorname{diag}(1,0)$, $X^s=(1,3)$, $W^\top=(2,0)^\top$, 被关闭的坐标为3, 原输出和门控输出却都为2.

若取 $P=I$, $G_s=\operatorname{diag}(1,1,0)$, $X^s=(1,2,3)$, $W^\top=(1,1,1)^\top$, 原输出为6, 门控输出为3. 权重共享仍然成立, 计算却已经产生误差. 校准目标因此同时约束子空间分配误差和量化误差.

目标是层输出相对 FP 的 Frobenius 误差,对去噪步 $t$ 取期望,掩码,明文两块加起来.校准结束,$\tilde P$ 折进 $W_f$,推理只做按态切分,激活变换,量化矩阵乘,写回.没有第二份 8B 权重.

激活按 token 量化, 权重按通道量化. 主设定为 W4A4. Table 5 的 W8A8 九项均分相对 FP 分别下降 0.74、0.92、1.59 分, 三个模型的任务敏感程度不同.

逐 token 量化让每一行激活拥有自己的尺度, 但一行内部的离群通道仍可能拉宽量化范围. 例如教学用的 4 bit 非对称量化, 若一行取值范围为 $[0,15]$, 尺度为 $15/(2^4-1)=1$, 许多小幅度差异就会舍入到同一个整数. SGAT 在量化前调整坐标系, 用共享方向承载两态共性, 用状态专属方向处理各自的离群模式. **共享的是校准得到的变换基与量化权重, 逐 token 尺度并不因此变成两态的平均值.** 权重按通道量化, 校准结束后固定;激活按当前状态分流, 每步重新计算.

## 3. TAC:校正注意力表示,不改注意力公式

SGAT 管线性层.注意力里 Softmax$(QK^\top/\sqrt{d_h})V$ 仍脆.TAC 不改这条公式,只在量化后的 $Z$ 进入输出投影之前,做一块块对角仿射:

$$
Z^{\mathrm{tac}}_{t,b}=\hat Z_{t,b}M_b^\top+\mathbf{1}d_b^\top,\qquad b=1,\ldots,B.
\tag{3}
$$

注意力输出的通道维被切为 $B$ 个宽度为 $g$ 的块. $M_b\in\mathbb R^{g\times g}$, $d_b\in\mathbb R^g$, $\mathbf1$ 沿 token 行广播偏置. 矩阵允许块内通道相互校正, 同时限制参数规模. [附录 C](https://arxiv.org/html/2606.04945v2#A3)在 SGAT 校准后估计 TAC, 使用至多64个校准样本;FP 参考路径关闭量化器, 但保留已学习的变换模块. 两条路径使用相同样本, 据其均值和协方差得到初始仿射矩阵, 再做奇异值平滑与单位阵收缩. 因此式(3)的 $M_b$ 表示这些处理完成后的矩阵, 偏置也根据最终矩阵重新计算.

Table 3 的 $g\in\{4,8,16,32,64\}$ 对应均分52.48 / 54.66 / 57.07 / 56.39 / 56.03. $g=16$ 在当前校准设置中最好. 小块表达的通道相关较少, 大块增加协方差估计参数;块宽扩大后的掉分与估计稳定性有关, 但该表本身没有单独测出各项误差来源.

## 5. 消融:TAC 和 SGAT 都不是装饰

Table 2,LLaDA-8B W4A4,九项均分:

| 方法 | 均分 | 相对 FP 掉分 |
|---|---|---|
| FP | 58.99 | 0.00 |
| 去掉 TAC | 55.43 | 3.56 |
| 去掉 SGAT | 56.39 | 2.60 |
| 完整 STaR-Quant | 57.07 | 1.92 |

相对完整方法, 去掉 TAC 下降1.64分, 去掉 SGAT 下降0.68分, 两者同时使用得到最高均分. 这是当前校准和评测协议下的组件贡献, 两个模块作用在不同插入点, 不能把差值直接当成两类误差的大小. 校准使用128段 WinoGrande;WinoGrande也参与评测, 任务类型有所重合, 但是否存在样本重合需要检查实际划分. 对其他任务的校准覆盖需要结合激活分布和状态比例判断.

TAC 从校准激活估计块内协方差. 小块参数少, 但只能校正局部的通道关系;大块覆盖更广, 协方差参数也随块宽的平方增加. 奇异值收缩与单位阵收缩限制估计噪声的放大. [Table 3](https://arxiv.org/html/2606.04945v2#S4.SS3)的最优块宽依赖当前模型和校准数据, 换到更长画布或不同任务时仍需验证.

### 5.1. Table 4:1.69× 是 Dream 吞吐,3.14× 是 Dream 显存

内核实现跟 QuaRot 文的 W4A4 测量协议走(Ashkboos 等人 2024).对照 FP16.

| 模型 | FP tok/s | Quant tok/s | 加速 | FP GB | Quant GB | 省显存 |
|---|---|---|---|---|---|---|
| LLaDA | 34.59 | 57.07 | 1.65× | 15.89 | 5.20 | 3.05× |
| LLaDA-1.5 | 35.55 | 58.30 | 1.64× | 15.88 | 5.20 | 3.05× |
| Dream | 23.27 | 39.33 | 1.69× | 13.95 | 4.44 | 3.14× |

三个模型的吞吐提升约为1.64–1.69倍, 峰值显存缩减比约为3.05–3.14. 显存缩减比定义为 FP 峰值占用除以量化后的峰值占用, 与节省的百分比不同. 例如 LLaDA 从15.89GB到5.20GB, 节省约67.3%.

量化降低每步运算的位宽, 采样器决定去噪步骤和提交顺序, 服务调度决定请求怎样组成批次. 三者共同影响吞吐. 不同硬件、模型和基线下得到的加速倍数, 需要在固定这些条件后才能比较.

**缓存减少重复计算, 量化减少数值存储和低精度算子的开销.** 峰值显存包括权重、临时激活、缓存和算子工作区. 缓存需要额外保存可复用的状态, 刷新时还可能同时存在旧缓存和新计算结果, 因而减少重算不保证峰值显存下降. STaR-Quant 的 Table 4 测量整体峰值 GPU 占用, LLaDA 从 15.89GB 降到 5.20GB;这个结果不能单独归因于 KV 压缩. 仅计 8B 参数的存储, FP16 约为 16GB, 4 bit 约为 4GB, 实际部署还需量化尺度、校正参数和运行时张量.

W8A8 的 Table 5 中, LLaDA、LLaDA-1.5 和 Dream 的均分分别下降 0.74、0.92 和 1.59 分, 比 W4A4 更接近 FP. 精度选择需要比较目标任务的变化和实际显存需求. Table 4 的 1.65× 已经是 LLaDA 的实测吞吐提升, 不能再把它当成矩阵乘内核的加速倍数扣减一次. batch 大于 1 时能否增加并发、增加多少, 还取决于激活、缓存和调度占用.

若要从某类算子的加速推算端到端收益, 可以固定序列长度、去噪步数和硬件, 设基线耗时中比例 $f$ 的部分加速 $r$ 倍, 其余部分不变. 以基线耗时为 1, 新耗时为 $(1-f)+f/r$, 总加速为

$$
S=\frac{1}{(1-f)+f/r}.
$$

教学示例中, $f=0.8$, $r=2$, 得到 $S=1/0.6\approx1.67$. 把相同计算重复 $T$ 步, 基线和优化后的耗时都乘以 $T$, 比值仍是 1.67. **限制总加速的是未加速部分的占比, 不是重复步数本身.** 如果不同步的画布、缓存命中率或校正开销变化, 则应分别累计各步耗时, 再计算总比值.

### 5.2. 量化与缓存、少步采样的组合

缓存策略首先需要判断旧状态是否仍然有效. 因果前缀的历史表示不依赖后来生成的 token 时, 可以精确复用历史 $K,V$. 双向去噪中, 某个 token 即使没有改变, 它的上下文化表示仍可能随着其他位置变化;跨步读取旧 $K,V$ 通常需要近似复用和刷新策略. 两种缓存的有效条件不同. 量化则改变这些张量的数值表示精度, 联合使用时需要同时检查状态陈旧误差与量化误差.

少步蒸馏和联合建模改变采样步骤及一步内多个位置的概率关系. 量化保留采样规则, 但数值误差会改变模型预测的概率, 继而影响选择与提交. 联合部署时, 可以分别测量每步耗时、总步数和最终任务质量, 判断收益来自哪一项改动.

验证式采样还需要检查数值误差是否改变接受决定. 草稿分布和验证分布参与概率比或阈值判断时, 量化可能改变一次接受的 token 数量, 让总步数也随之变化. 因而联合加速需要直接测量完整系统, 不能仅把独立实验的倍数相乘.

STaR-Quant 的实验对象是掩码去噪语言模型. 视频扩散和其他硬件上的量化涉及不同张量与算子, 需要各自的校准与性能测量.

当前 SGAT 使用预定义的掩码态与明文态, TAC 使用固定校准参数. 更低的 3 bit 或 2 bit 精度、置信度驱动的状态划分和多模态输入, 会改变量化误差与校准分布. 融合校正与后续算子可以减少额外张量读写, 但具体收益取决于内核实现, 需要实测.

重掩采样允许同一位置从明文态回到掩码态, SGAT 会按新的状态选择门控. TAC 的参数固定, 对新状态分布的校正效果取决于校准覆盖. 改变提交阈值或缓存策略后, 应重新测量质量与端到端时延.

### 5.3. 精度选择与校准覆盖

低比特部署需要同时处理当前激活的状态差异与多步生成的误差传播. SGAT 通过状态门控分配变换子空间, TAC 在注意力输出投影前校正通道块统计. 门控的近似误差、量化误差和校准域变化共同影响结果. LLaDA-8B 的平均掉分为 1.92, GSM8K 掉分为 10.19;采用哪档精度应围绕目标任务、显存和实测吞吐判断.
