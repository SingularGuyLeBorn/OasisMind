# 开放路线与多模态

「开放路线与多模态」关注的是一组彼此牵连的选择：状态如何表示，破坏过程怎样丢失信息，模型又凭什么把信息找回来。下面的文章分别落到这些选择的不同分支，比较时以共同概率对象和计算条件为坐标。

## 1. 共同起点

LLaDA 用学术评测回答了 8B 掩码扩散能做到什么程度.产品与实验室另外几条线要回答的是:开源 7B 怎么从 AR 初始化;代码补全能不能到四位数 tokens/s;前沿实验室愿不愿意公开一张扩散对照表.四条工作的目标不同,共同出现并不能推出「2025 年扩散已经全面超过 AR」.

移位,退火和 WSD 等改编方法见[从自回归改编](../../5-训练-后训练与迁移/5.1-权重迁移与范式转换/5.1.1-从自回归权重改编.md).各家的吞吐数字只在自身协议内成立.开源代码模型 [DiffuCoder](../../5-训练-后训练与迁移/5.3-后训练与任务评测/5.3.2-代码模型的训练与评测.md) 使用单独的检查点,不属于这四种交付形态.

港大 NLP 与华为诺亚,arXiv:2508.15487.离散吸收态.权重从 Qwen2.5 7B 初始化,保持移位,按上下文重标定每个掩码位的噪声.继续预训练作者写成 580B token,Table 1 写作 0.6T.发布 Base 与 Instruct,推理接口是 `diffusion_generate()`.1B 尺度上扫过初始化,移位,噪声重标定,再接到 7B.学习率太大冲掉从左到右的知识,太小扩散训不动.

通用任务上 Dream 贴近 Qwen2.5,MMLU 差 2.4 点,GSM8K 差 1.7 点,HumanEval 略高.规划任务上,论文报告扩散模型在数独等任务中的优势.双向上下文允许尚未确定的位置读取已经确定的线索,多个位置的候选也能在同次前向中得到预测.**双向预测与撤回已提交 token 是两项不同能力.** 是否能够改写先前结果取决于采样器的状态转移,不能从注意力方向直接推出.

LLaDA 原论文 Table 1 的 GSM8K 是 4-shot 的 70.3,HumanEval 是 35.4.Dream 这张 $*$ 表把 LLaDA 写成 8-shot 70.9 和 HumanEval 32.9.两套 harness 不要减出「LLaDA 退步了」.讨论 Dream 对 LLaDA 用本表;讨论 LLaDA 对 LLaMA3 用 Nie et al. 的 $*$ 表.

Dream Instruct 的 GSM8K 81.0 高于 LLaMA3 Instruct 的 78.3,仍低于有 RL 的 Qwen2.5.HumanEval 55.5 对 84.8,代码缺口大.LLaDA 1.5 的 VRPO 把 Instruct 的 HumanEval 从 49.4 拉到 52.4,仍到不了 84.8.后训练深度不同.

Countdown 上调扩散步数,作者给出质量和速度的折中:步数设在 5–20 时,可以同时比 Qwen2.5 7B 更快更好.这是规划题上的曲线,不是 HumanEval 的默认.步数旋钮见[采样](../../2-数学与生成机制/2.3-生成因式分解与采样/2.3.2-采样后验调度与重掩.md).

Dream 的开放权重和训练方法适合分析自回归初始化、噪声重标定与任务能力的关系.Mercury 的产品评测还涉及专用推理实现.两者的吞吐需要在硬件、并发、回答长度和质量要求一致时比较,单看 tokens/s 无法隔离训练方法的贡献.

Dream 会按上下文调整每个位置的有效噪声.全局一个 $t$ 时,句子里有的格子左右都是可读词,有的格子陷在一片掩码里.前者几乎是轻度填空,后者几乎是从边际乱猜.共用同一个时间权重,梯度会在两种难度之间折中,容易把已经有足够上下文的格子仍当难题来训,或者反过来.Dream 按周围可信上下文重标定每个掩码位的有效噪声,承认「时间」在序列上并不均匀.这和图像里按空间位置改日程不是同一套公式,目的同类:一个标量 $t$ 无法代表所有格子的难度.

移位则是改编能否保住基座的开关.Qwen2.5 的每一层 $h_i$ 已经对准 $x_{i+1}$.若扩散损失改去让 $h_i$ 预测 $x_i$,等于把预测头的靶子挪一格,继续预训练要重新学位置几何.DiffuLLaMA 和 Dream 都选择保住移位.dKV-Cache 后来从解码侧证明:推理时若把移位搞反,Dream 的 GSM8K 可以掉到 32.68.那不是 Dream 原文的主表,但是同一几何的反面教材.

数独与 Countdown 都有可检查的约束,任务正确率可以直接检验生成结果是否满足这些约束.论文的规划优势属于对应任务与采样预算,写作和解释任务还需要各自的评价.在分析原因时,应分别比较初始化、噪声重标定、双向条件与提交顺序,因为这些改动会共同影响最终结果.相关训练机制和消融进入[Dream 等模型的详细解析](3.2.1-dream-mercury-gemini与seed.md).

Instruct 只有 SFT,代码缺口对着有 RL 的 Qwen2.5.这和 LLaDA Instruct 落后 LLaMA3 Instruct 是同一类口径问题.Dream 的 180 万对比 LLaDA 的 450 万对更少,GSM8K 81.0 仍高于 LLaMA3 的 78.3,说明改编基座(Qwen2.5)本身数学就不弱.HumanEval 55.5 对 84.8 则说明:基座会写代码,不等于扩散 SFT 能把代码能力完整接过来.后训练深度不同.

Inception Labs,技术报告 arXiv:2506.17298.Transformer 骨干,扩散训练与生成,代码向.Mini 与 Small 两档.Artificial Analysis 在 NVIDIA H100 上测到 Mini 1109 tokens/s,Small 737 tokens/s,相对当时速度优化的前沿 AR 最高约 10 倍吞吐,质量落在同类快速代码模型区间.Copilot Arena 上作者称质量第二,速度第一.上下文官方写 32k,可扩到 128k.

## 2. 分岔来自哪里

自回归多模态的默认接法是 LLaVA:视觉塔抽出图块特征,MLP 投进 LLM 的词嵌入空间,后面仍按从左到右写回答.LLaDA-V(You 等人,arXiv:2505.16933)把输出生成改成掩码扩散.视觉塔用 SigLIP 2,投影用两层 MLP,语言塔就是 LLaDA 8B.训练目标仍是只掩回答,提示保持干净,只是提示里现在既有字,也有一串视觉嵌入.

LLaDA-V 的吸收态作用在回答 token 上,图像特征提供条件,没有在像素上定义同一个 $Q_t$.双向注意力让待预测位置读取图像特征和可见文字.高分辨率图像的切分、缩放与特征拼接会改变视觉信息和计算量;图表、文档任务中的差距需要结合视觉处理与语言塔共同分析,仅凭最终分数无法隔离扩散目标的影响.

LLaDA-V 使用相同的视觉指令数据和训练流程构造 LLaMA3-V baseline,比较不同语言塔的多模态能力.Table 2 对应多学科知识与数学推理,Table 3 对应图表、场景、多图与视频任务.这类比较比直接对照不同训练来源的产品更接近语言塔的作用,但底座预训练和网络差异仍需保留.

作者写:尽管语言塔在纯文本上弱于 LLaMA3 8B,LLaDA-V 在 Table 2 的 9 格里有 6 格超过 LLaMA3-V.对 Qwen2-VL,多数格仍落后,MMStar 60.1 对 60.7 算接近.差距优先记在语言塔,不要记成「扩散看不懂图」.Qwen2-VL 的训练数据与动态分辨率都不是同一套协议. Table 3,图表,场景,多图与视频:

多图和视频略高,场景理解略低,文档参差.作者把优势放到双向看见整段图文条件,把文档短板放到切图策略.这是机制假说,表只证明这些格上的差存在. 数据规模曲线写在 Fig. 3.同一套 MAmmoTH-VL 单图数据往上堆,LLaDA-V 在 MMMU,MMMU-Pro 上比 LLaMA3-V 更吃数据.作者写:MMMU-Pro 上,LLaDA-V 用约 1M 样本可以超过 LLaMA3-V 用 9M 的点.图表和真实场景理解没有同样的故事.缩放优势是任务相关的,不是多模态扩散的定理.

后训练混入长思维链数据,UniGRPO.d1 则固定掩码率,因为 LLaDA 估计似然需要多次蒙特卡洛采样.UniGRPO 对每个回答抽 $p_i\sim U[0,1]$ 再掩,让策略在几乎全掩到几乎干净的各阶段都见到梯度.这属于多模态对齐方法,没有改变 $Q_t$.MMaDA 主表横跨理解,生图和文本三套基准,口径与 LLaDA-V Table 2 的 harness 不同.MMMU 30.2 等综述转述数字缺少同表协议,无法参与两者比较.

## 3. 生成对象与比较条件

Dream、Mercury、Gemini Diffusion 与 Seed 系列经常被放进同一张「扩散语言模型」时间线，但公开程度和技术对象并不一致。有的工作公布训练目标与权重，有的只给服务形态或演示，有的使用块扩散，有的把扩散放在连续隐空间。能从论文和代码核实的内容应与产品宣传分开：参数规模、前向核、反向参数化、采样步数和评测协议缺一项，就很难把两个吞吐数字直接比较。

多模态模型还多了一次状态空间选择。图像可以在像素或 VAE latent 上做连续扩散，文本可以在 token 上做离散扩散；统一模型既可能让两种模态各走自己的噪声过程，也可能先把它们映到共享连续表示。前者保留了 token 的精确类别语义，却要协调两个时间轴；后者方便使用统一网络，但文本最终仍要经过离散解码，rounding 误差不会因为共享 latent 而消失。

因此这条路线不按公司名罗列产品。状态空间与训练目标决定模型在生成什么，反向过程决定它能否双向修订，并行去噪、块式提交、蒸馏与专用系统则分别解释速度来自哪里。新的闭源模型即使只公开一部分细节，也能据此划清可核查结论与尚不可比的部分。
