# 吸收态模型家族

「吸收态模型家族」关注的是一组彼此牵连的选择：状态如何表示，破坏过程怎样丢失信息，模型又凭什么把信息找回来。下面的文章分别落到这些选择的不同分支，比较时以共同概率对象和计算条件为坐标。

## 1. 共同起点

LLaDA 从一个具体问题出发:规模化、上下文学习和指令跟随,是否只能通过自回归训练获得?它将掩码扩散从头训练到 8B,在多项任务上与自回归模型比较,提供了另一种生成范式的实验依据.随机掩码重构目标与似然下界相连,但任务能力仍取决于模型容量、数据与优化,不能仅由目标函数推出.后续 LLaDA 2.0 继承自回归权重,进一步把问题转向如何转换已有大模型,而非每次都重新预训练.

这条路线的共同概率对象是部分可见的文本.训练通过随机掩码组合学习恢复条件,生成通过多轮提交改变可见集合.具体加权目标见[掩码扩散与加权 MLM](../../2-数学与生成机制/2.2-训练目标与离散分数/2.2.1-掩码扩散与加权mlm.md);模型家族的差别则体现在网络容量、训练来源和生成时的块边界.

预训练 2.3T token,0.13 百万 H800 GPU 小时,序列长 4096.损失即掩码扩散篇式 (1):抽 $t\sim U[0,1]$,每个位置独立以概率 $t$ 变成 `[MASK]`,交叉熵只落在被掩位置上,再乘 $1/t$.SFT 用 450 万对,只掩回答,提示保持干净.没有 RL.

和 LLaMA3 8B 的对照写在 [LLaDA v3 附录 Table 5](https://arxiv.org/html/2502.09992v3):都是 32 层,隐维 4096,32 个注意力头.LLaDA 用 32 个 KV 头(MHA),LLaMA3 用 8 个(GQA).全双向去噪中,输入变化可能影响全部位置的隐状态,历史 KV 因而不能直接沿用自回归解码的缓存方式.这削弱了 GQA 在持久 KV cache 上的节省,但 GQA 仍可减少 K/V 投影参数和单次前向的 KV 张量大小.多出来的注意力参数靠减小 FFN(12288 对 14336)对齐到 8.02B / 8.03B.词表 126464 对 128000,分词器按他们的数据改编.

换掉的是 mask 和训练目标.RoPE,SwiGLU,RMSNorm 仍在.BERT 的 15% 固定掩码,NSP,10% 随机替换都不在.$t$ 要从 0 积到 1,生成要从全掩码走回来,这两件事才把编码器接上生成模型.

1% 的预训练样本另外从 $[1,4096]$ 均匀抽取长度,其余采用 4096.纯扩散生成预先分配回答画布,长度决定一开始放置多少个 `[MASK]`.SFT 则采用批内动态长度,用 EOS 将较短的提示与回答对补到该批最长样本,填充区域作为回答的一部分参与掩码训练.训练输入的补齐长度与推理画布长度是两项不同设置.

[LLaDA v3 附录 B.4](https://arxiv.org/html/2502.09992v3#A2.SS4) 观察到 Instruct 在纯扩散采样下产生过多 EOS,回答过短.针对 HumanEval、MBPP、GSM8K、Math 和 GPQA,作者将 EOS 候选的提交置信度设为零.**这改变的是提交位置的排序,没有把 EOS 从模型词表分布中删除.** 该规则属于这组评测的采样配置,不能推广为所有模型和任务的固定要求.

一次预训练更新抽取文档和掩码概率 $t$,独立决定各位置是否变成 `[MASK]`,再执行全双向前向.被掩位置的预测与原始 token 计算交叉熵,乘 $1/t$ 后反传.可见位置参与上下文计算,重构目标仅评价被掩位置.随机掩码率使训练覆盖从几乎完整到几乎全掩的状态,加权目标与生成过程的似然下界相连.固定 15% 的 MLM 目标本身没有指定从全掩码恢复文本的完整生成过程.

SFT 将重构目标收窄到回答段,提示始终可见,回答按 $t$ 随机掩码.推理时的输入状态还取决于采样器:逐位增长的输入、逐块增长的输入和预先分配的完整画布提供不同的长度与可见上下文.原论文的 Instruct 逐位采样表现很差,作者将其联系到完整回答的 SFT 数据与输入长度条件;因此需要同时考察训练样本的结束符处理、推理输入范围和结束规则.

论文 Figure 3 使用同数据 ARM baseline 比较预训练计算量与下游成绩.小规模比较对齐了架构、数据与其余配置;大规模受资源限制,比较的是 8B LLaDA 与 7B ARM,其 batch size 和学习率设置也有差别.这组结果支持掩码扩散能随训练计算扩大而改善任务表现,不能把全部差距归因于因式分解.跨团队模型还存在语料和训练预算差异,2.3T 与 15T 的 token 数之比并不直接给出样本效率之比.

LLaDA 8B Base 在数学和中文任务上表现较强,部分通用任务仍落后于 LLaMA3 8B.作者将数据质量与分布差异列为可能原因.同数据实验覆盖约 $10^{20}$–$10^{23}$ FLOPs,展示了多个任务的增长趋势;论文没有拟合定量 scaling 曲线,因而不宜从图中再推导精确斜率或普遍的计算优势.

Base 的 MMLU 类任务走条件似然蒙特卡洛,HumanEval 走生成.两列不是同一种解码.HumanEval-FIM 在 Table 1 上是 73.8 对 LLaMA3 的 73.3:填空并非扩散独有的魔法,FIM 训过的 AR 也能做;扩散这边不必另开一条 FIM 目标.

附录 Table 10 同时把生成长度和采样步数设为 256、512、1024,每轮提交一个 token.Base 的 GSM8K 为 70.0–70.8,MATH 为 30.3–31.4,HumanEval 为 32.9–35.4.这组实验比较的是「长度与步数一起增加」的配置,没有单独隔离长度效应.主表 MATH 31.4、HumanEval 35.4 对应长度与步数均为 1024 的一行.

整体略落后有 RL 的 LLaMA3 Instruct,缺口在代码和 GSM8K 更明显.ARC-C 反而更高.作者把若干指标相对 Base 下降(如 MMLU)归因于 SFT 数据质量,并明确把 RL 对齐留到后续.

Table 2 的 GSM8K 69.4、MATH 31.9、HumanEval 49.4 来自纯扩散采样.附录 Table 8 的固定画布块扩散 LLaDA,也称 semi-autoregressive remasking,在块长 8 时得到 GSM8K 78.6.固定画布中,后续尚未处理的块仍以 mask 留在输入里;传统块扩散则随生成增长输入长度.同一权重的成绩需要绑定画布、块长、步数与结束规则,具体计算过程可继续读[生成与采样专题](../../2-数学与生成机制/2.3-生成因式分解与采样/2.3.2-采样后验调度与重掩.md).

## 2. 分岔来自哪里

LLaDA-MoE 保留双向 Transformer,把 FFN 换为稀疏专家层.[论文 v1 Table 2](https://arxiv.org/html/2509.24389v1) 给出的配置是 16 层,隐维 2048,16 个注意力头,每层 64 个专家,每个 token 选择 8 个,专家中间维 1024,RoPE base 50,000.非嵌入参数 7B,激活参数 1.4B.主表使用 1B 的简写,RMSNorm、SwiGLU、RoPE 与注意力中的 QK-LayerNorm 共同构成主模型.Figure 2 使用 Top-2 展示路由连接,实际模型使用 Top-8.

**扩散目标与专家选择作用于不同环节.** 在每一层,token 的隐状态进入线性路由器,得到 64 维 logits;softmax 后选择 Top-8 专家,按被选中的原始 softmax 权重加权其输出.路由决定本次 FFN 使用哪些参数,采样器决定哪些位置的预测进入下一轮序列.两种选择分别发生在模型内部与模型调用之间.

同一层中,干净位置与被掩位置经过双向注意力后,使用同一套路由器和专家.输入可见集合随去噪变化,同一位置的隐状态与专家选择也可能变化.负载均衡项约束专家使用分布,Z-loss 约束路由 logits 的 log-sum-exp.Figure 4 展示前 1T token 的两项辅助损失变化,反映这段训练的优化动态;专家是否形成数学、代码等语义分工,还需要任务条件下的路由统计和消融.

与稠密 LLaDA 8B 相比,这套配置同时改变了深度、注意力宽度和 FFN 组织方式.每层专家的选择比例为 $8/64=12.5\%$,但注意力、路由器和归一化等模块仍参与计算,这个比例不能当作整个模型的计算比例.比较两种模型的成绩时,还要考虑训练数据和预算;参数表本身无法证明某一项结构变化带来了多少收益.

训练的概率对象仍是被部分掩码的序列.抽 $t\sim U[0,1]$,每个位置独立以概率 $t$ 变成掩码 $\mathbf{M}$.网络预测各位置的原始 token,被掩位置的交叉熵乘 $1/t$ 后进入重构损失;专家负载均衡与 router Z-loss 另作为辅助项加入.

预训练以 4k 序列为主,另以 1% 的概率从 $[8,4096]$ 抽取长度并截断,增加对短输入的覆盖.生成评测采用长度 1024、块长 64 的半自回归采样和低置信度选择.其他已有 MDM 的成绩直接引用公开数字,并未全部按这套配置重新评测;因此同表的差距同时包含模型与评测协议差别.

一次训练前向中,干净位置与被掩位置都会经过注意力和逐层 Top-8 路由.干净位置为被掩位置提供上下文,虽然不直接承担重构交叉熵,仍可通过注意力依赖收到梯度.因此,**损失只计被掩位置,不等于模型只计算被掩位置.** 推理时输入随采样更新,下一轮需要重新评估受影响的隐状态和专家选择;上一轮的选择不能仅因 token 位置相同就直接复用.

## 3. 家族内部的连续性

LLaDA 家族的共同底座是吸收态掩码、双向条件建模和对随机掩码率加权的重构目标。版本变化主要发生在规模、块化方式、训练数据、后训练协议与推理调度上。读模型表时应先确认它是从头预训练还是由自回归权重改编，再看报告的是全序列扩散、块扩散还是带因果边界的混合形式；这些差异会直接改变可用上下文、缓存方式和并行度。

MoE 并没有改变扩散的概率对象。路由器仍在每个 token 的隐藏状态上选择专家，噪声时间与可见集合却会改变隐藏状态分布：同一个语义位置在高掩码率和低掩码率下可能被送往不同专家。于是专家负载、路由稳定性与去噪难度发生耦合。只比较总参数量会漏掉激活参数、每步前向成本以及扩散多次调用主模型产生的总成本。

模型能力也要和采样协议绑定。某个基础模型在高步数、低并行提交下得到的数学或代码成绩，不能直接与同一家族在少步高速配置下的吞吐拼成一项结论。家族页负责说明共同训练范式；具体文章分别保留基础模型与 MoE 的配置、实验口径和失败条件。
