# LLaDA:8B 从头训到 100B 改编

LLaDA 研究一个基础问题:大模型的规模化、上下文学习和指令跟随,能否通过从任意位置补全文本学出来?8B 模型从头训练掩码扩散,把不同噪声比例下的重构接成生成过程,并与自回归模型比较.LLaDA 2.0 走另一条路线,继承已有 AR 权重,再通过块长课程转换生成方式.前者检验训练目标,后者研究已有能力的迁移.

两条路线都需要回答三个问题:网络如何读取已知 token,训练如何恢复被遮住的位置,采样如何把候选逐步写入文本.下面先看架构与任务结果,再展开训练目标、四 token 手算和后训练.同一组权重可以配合不同采样器,因此模型成绩需要连同生成方式一起理解.

## 1. 8B 骨架:去掉因果掩码的 decoder-only

预训练 2.3T token,0.13 百万 H800 GPU 小时,序列长 4096.损失即掩码扩散篇式 (1):抽 $t\sim U[0,1]$,每个位置独立以概率 $t$ 变成 `[MASK]`,交叉熵只落在被掩位置上,再乘 $1/t$.SFT 用 450 万对,只掩回答,提示保持干净.没有 RL.

[LLaDA v3 Table 5](https://arxiv.org/html/2502.09992v3#A2.T5) 对照 8B 架构:二者都是 32 层、隐维 4096 与 32 个 Query head.LLaDA 使用 32 个 KV head 的 MHA,LLaMA3 使用 8 个 KV head 的 GQA.作者为简化设计选择 MHA,并减小 FFN 宽度(12288 对 14336),使参数量接近 8.02B 与 8.03B.词表分别为 126464 与 128000. **head 共享与跨步缓存是两条独立轴.** 全双向状态会随去噪改变,不支持一般的严格历史缓存;但即使每轮重算,GQA 仍能减少 KV 投影维度、参数及临时存储,并非必须先有稳定缓存才有作用.

网络沿用 RoPE、SwiGLU 与 RMSNorm,将 attention 改为全双向,训练时只用吸收态 mask 腐蚀.BERT 选中 15% 的位置作为预测目标,其中 80% 换成 mask、10% 换成随机词、10% 保持原词,实际 mask 比例约为 12%.LLaDA 则随机抽取 $t$,让噪声范围覆盖几乎干净到几乎全 mask 的状态,并使用与扩散似然界对应的加权重构目标.

1% 的预训练样本另外从 $[1,4096]$ 抽取长度,其余采用 4096.纯扩散生成预先分配回答画布,画布长度仍是超参.SFT 在 minibatch 内用 EOS 将较短的提示与回答对补到该批最长样本长度,填充区域也参与回答训练.作者观察到 Instruct 纯扩散生成过多 EOS、回答过短,因此在 HumanEval、MBPP、GSM8K、Math 和 GPQA 的该采样设置下将 EOS 的提交置信度设为零.这项处理改变位置选择,并不等于从词表分布中删除 EOS.

训练一步长什么样.抽一条 4096 的文档,抽一个 $t$,抛硬币决定哪些位置变成 `[MASK]`.网络做一次全双向前向,词表 softmax 只在被掩位置上对原 token 算交叉熵,乘 $1/t$ 再反传.未掩位置的答案已经写在输入里,再预测一次没有信息,还会让模型学抄输入.这和 BERT 的差别不在「用了双向 Transformer」,而在 $t$ 覆盖 $[0,1]$ 全体:有的 batch 几乎没掩码,有的 batch 几乎全掩.似然下界是对这条日程求期望,所以可以从全掩码反向采样.固定 15% 的 MLM 没有这条反向过程.

SFT 把同一套损失收窄到回答段.提示位置永远可见,当作条件;回答位置按 $t$ 掩.模型学的是「在这段已经写好的指令旁边,把回答从噪声里擦出来」,不是「从左到右续写指令」.这解释了为什么同一组 Instruct 权重,用自回归采样(每步只揭最左边一个掩码)会和 `[EOS]` 垫片打架,而纯扩散,块扩散还能出分数.

同数据 ARM baseline 是作者用来挡「2.3T 对 15T」的那条曲线.语料配比,分词器,优化器尽量对齐,只换因式分解.下游在他们走到的 FLOPs 区间没有塌.这张图回答的是「扩散目标能不能 scale」,不是「LLaDA 的数据比 LLaMA3 更省」.跨公司主表上的 GSM8K 21 个点,混了数据,目标和双向,不能单独记在扩散名下.

## 2. 采样器能改分数

附录 Table 8,Instruct,块长 32:

| 采样 | GSM8K | MATH | HumanEval |
|---|---|---|---|
| 自回归 | 0 | 9.5 | 0 |
| 块扩散 | 24.6 | 23.5 | 17.1 |
| 块扩散 LLaDA(半自回归 remask) | 77.5 | 42.2 | 46.3 |
| 纯扩散 | 69.4 | 31.9 | 49.4 |

Table 2 的 69.4 / 31.9 / 49.4 是纯扩散.GSM8K 若改用块长 8 的块扩散 LLaDA,可到 78.6.报「LLaDA Instruct 的 GSM8K」而不写采样器,数字没有意义.自回归采样在 Instruct 上崩掉,和 `[EOS]` padding 有关,见采样篇.

低置信选择在每轮预测后优先写入较确定的候选,把其余位置保留为 mask,让它们在下一轮读取新增上下文.这里重新遮住的是本轮尚未提交的候选,已经提交的 token 保持不变.概率排序的作用是决定提交顺序,并不自动赋予模型撤回错误的能力.

Table 7 在 Base 上做同类消融.自回归采样:BBH 38.1,GSM8K 63.1,Math 23.6,HumanEval 18.3,MBPP 33.4.纯扩散把 HumanEval 拉回 35.4,整体最好.块扩散采样介于两者之间,块长 $L'$ 是旋钮.同一组 8B 权重,采样器可以把它变成三种不同的模型.Instruct 上自回归采样崩到 GSM8K=0,HumanEval=0,Base 上只是变差,没有归零:SFT 的 `[EOS]` 垫片是崩掉的主因,不是「扩散权重不会从左到右」.

Table 9 在 8B Base、长度与步数均为 256 时比较随机与低置信 remask,GSM8K 为 21.3 与 70.0.随机位置选择不会读取候选置信度,低置信选择则优先提交较确定的候选.候选取 argmax、固定提交数量与按解析事件独立抽样是不同规则;不能仅凭方法名中的「随机」就宣布它是真实联合后验采样.四位置图与有限步核的区别见[采样与调度](../../2-数学与生成机制/2.3-生成因式分解与采样/2.3.2-采样后验调度与重掩.md).

## 3. 诗歌反向:机制实验及其边界

给定后半句补前半句.因果模型必须把「后面」改写成提示里的条件,且生成方向仍朝结束符走.掩码扩散把要补的字留成 `[MASK]`,已给的字当干净上下文,方向不存在.评测跟 Allen-Zhu 与 Li 的协议,496 对著名中文诗句,zero-shot.

Table 3 / Table 4:GPT-4o(2024-08-06)正向 82.7,反向 34.3.Qwen2.5 7B Instruct 正向 75.9,反向 38.0.LLaDA 8B Instruct 正向 48.8,反向 42.4.正向弱,作者写在 2.3T 和约 13 万 H800 小时对不上闭源语料.反向超过两者.论文要强调的是正反向落差被压平,不是古诗全面超过 GPT-4o.

附录里 GPT-4o 写错上句的例子:问「但闻人语响」接到「无可奈何花落去」;问「夜静春山空」接到「空山新雨后」.方向反了之后,它仍按往后续的习惯找一个顺口的下句.注意力侧的解释见[双向注意力与反转诅咒](../../4-联合依赖与结构设计/4.1-因式分解与块扩散/4.1.1-双向注意力与反转问题.md).Berglund 微调实验里虚构名人正向 96.7%,反向约 0%,测的是另一件事:参数里有没有反向边.诗句表不能外推成「扩散已经解决知识对称」.

## 4. 从 AR 权重转换到块扩散

LLaDA 2.0 从 Ling-mini-2.0 / Ling-flash-2.0 出发,把 AR 看成块大小为 1 的块扩散,再用 Warmup–Stable–Decay (WSD) 改块大小.记块长为 $B$,单篇文档长度为 $L$.转换时逐步扩大块长,随后训练全序列去噪,最后缩回适合部署的块长.

![LLaDA 2.0 从自回归权重经三阶段块级 WSD 改编为扩散模型](../images/fig-llada-wsd.png)

> 图 1:块长课程、单篇文档内的可见性与部署缓存.课程依据 [LLaDA 2.0 v2 Figure 2 与 §4.1](https://arxiv.org/html/2512.15745v2),缓存关系见该文 §7.3.$8\times8$ 矩阵与部署块长 $B=4$ 是教学示例,不代表论文的实际部署配置.矩阵行表示查询位置,列表示被读取位置;深色格表示允许读取.打包多篇文档时还要施加文档边界限制.

图 1 解析:

**块长改变的是条件范围.** $B=1$ 时,因果矩阵中位置 $i$ 只能读取截至 $i$ 的状态;扩大块长后,同一块里的位置可以相互读取,同时仍能读取此前块.当 $B=L$ 时,单篇文档内所有位置都可见.在 $B=4$ 的部署示例中,第 2 块不能影响第 1 块的表示,当前块内部保持双向连接;全序列阶段则只有一个完整文档块,所有位置互相可见.

WSD 先逐步扩大这个双向范围,减少直接切换目标带来的分布变化;稳定阶段用全序列去噪训练,再把块长缩小,使部署时可以按块推进.图中曲线表示课程方向,不表示连续变化的真实调度函数.

**缓存成立的条件是前缀不再改变,也不读取后续块.** 当前块尚在去噪时,其 token 状态会变化,每轮需要重新计算;已完成的前缀则提供固定的 KV.第 2 块完成后,用最终 token 状态计算并追加该块的 KV,第 3 块读取更新后的前缀缓存.这两个阶段之间可能经过多轮去噪,不能把一次块推进当作一次去噪步.这种固定前缀的复用与 Fast-dLLM 跨去噪步暂存双向状态的近似缓存有不同的成立条件.

训练时还需要同时提供带噪序列和干净序列.记原文长度为 $L$,拼接输入为 $[x_t,x_0]$,总长 $2L$.带噪块读取自己的带噪状态与此前干净块,干净分支块内双向、块间因果,并且不读取带噪分支.这样一次前向可以训练多个块,同时防止网络直接读取同块的干净答案.全序列稳定阶段则只需带噪输入,取消额外干净分支.

![块扩散训练的两路输入、四象限可见性与重构损失](../images/fig-llada-training-inputs.png)

> 图 2:块扩散训练的输入与读取关系,依据 [LLaDA 2.0 v2 Figure 2、§4.2 与式 (3)](https://arxiv.org/html/2512.15745v2#S4.SS2). $L=4,B=2$ 与四个字母 token 为教学示例;矩阵行是查询,列是被读取位置,蓝色为允许读取.多文档打包还需额外隔离文档边界.

图中位置 3 是 mask,它用本块的带噪状态 $(M,D)$ 与干净前缀 $(A,B)$ 预测 C 的分布,随后与目标 C 计算重构损失.同块干净答案 $(C,D)$ 虽然存在于拼接输入中,却不能被这个查询读取.位置 1 没有此前干净块,只读取本块带噪状态 $(M,B)$.干净分支生成各块的前缀表示,其自身不承担图示的掩码重构损失.训练中各块共享一次带边界约束的计算;部署时依次完成块并写入 KV,不能把两路训练输入理解成两份部署缓存.

发布的是指令微调后的 MoE:mini 16B,flash 100B.

Table 1–2 的平均分:mini 64.34,对照 Ling-mini-2.0 的 65.77,Qwen3-8B (no_think) 的 63.42.flash 73.18,对照 Qwen3-30B-A3B-Instruct-2507 的 73.60,Ling-flash-2.0 的 72.15.flash 的 HumanEval 94.51,MBPP 88.29,AIME 2025 60.00,BFCL v3 75.43,作者强调编码与 agent 相对 AR 同级模型开始占优.

[LLaDA 2.0 v2 Figure 3 与 §7.3](https://arxiv.org/html/2512.15745v2#S7.SS3) 比较 HumanEval、MBPP、GSM8K 与 CRUXEval 四项任务的平均吞吐,TPS 定义为生成 token 数除以总耗时.扩散模型用 dInfer 的阈值解码,阈值为 0.95;AR 基线使用 SGLang.flash-CAP 为 535 TPS,普通 flash 为 383 TPS,Ling-flash-2.0 与 Qwen3-30B-A3B-Instruct-2507 分别为 256 与 237 TPS.这些是模型、采样规则与服务实现共同产生的结果.主能力评测采用温度 0、块长 32 与阈值 0.95,其任务分数和吞吐需分别按对应实验解读.

CAP 在 SFT 中对当前预测正确的位置压低输出熵,帮助更多正确候选越过推理阈值.每次网络前向提交的 token 数(TPF)描述并行提交效率,TPS 则还包含每轮前向、缓存操作与服务调度的时间.同样的 TPF 在不同模型和运行环境上可以对应不同 TPS,二者不能直接互换.

上下文:文内称 32k 内 flash 稳定.训练用 Megatron 的 DP/PP/TP/CP/EP,掩码在模型并行组内广播以保持一致.文档打包必须在边界切断注意力,否则后一篇文档的开头会变成当前文档的未来上下文,去噪时作弊.

100B 是改编不是从噪声训出来的扩散.知识来自 AR 阶段,扩散阶段负责改生成过程.讨论「扩散能否 scale」时要把「从头训的 8B」和「转换的 100B」分开.

## 5. 规模曲线和 CFG

原文 Fig. 3 用预训练 FLOPs 当横轴,六个下游任务上 LLaDA 与同数据 ARM 的曲线总体可并排.作者拒绝拟合定量幂律,理由是离群点会误导.能说的只有:在他们走到的 $10^{23}$ FLOPs 量级,扩散没有在下游上突然塌掉.早期「似然要 16 倍算力才追上 AR」的观察,被他们用「似然是间接指标,优化的是界,FLOPs 区间更宽」三句话挡回.该早期观察不能作为 2025 年模型的算力换算关系.

CFG 在附录 Table 6:有条件与无条件 logits 外推,多个任务稳定加分.这是推理技巧.8B Instruct 的主表没有把 CFG 当成默认必开项来报,读具体数字时看附录有没有开.Base,不开 CFG 的那一行:ARC-C 45.9,Hellaswag 70.5,TruthfulQA 46.1,WinoGrande 74.8,GPQA 25.2,PIQA 73.6.开 CFG 并在 $\{0.5,1,1.5,2\}$ 里按任务选最好的 $\gamma$ 之后:47.9,72.5,46.4,74.8,26.1,74.4.作者写明主表为了和 ARM 公平对照,不开 CFG.离散 CFG 的公式和基因组上的 γ 表见[可控生成](../../7-控制-评测与选型/7.1-条件控制与序列奖励/7.1.1-可控生成与推理期转向.md);8B 语言 CFG 没有与 Table 2 同口径,扫完整指令任务的公开细表.

8B 的 MHA 选择不能当成双向扩散的架构限制.同一张 Table 5 中,LLaDA 1B 使用 32 个 Query head 与 4 个 KV head,已经采用 GQA.后续缓存方法处理的是跨去噪步的状态变化,与同轮 head 共享不同.原始全双向模型的深层 KV 可能因其他位置揭开而改变,近似复用需要刷新策略与质量评测.

SFT 的约 450 万指令对只掩回答,损失仍是加权掩码交叉熵.回答完整性和 EOS 填充影响输出长度,不同采样器又让网络看到不同的输入范围.[LLaDA v3 Figure 4 与附录 B.4](https://arxiv.org/html/2502.09992v3#A2.SS4) 区分逐位扩展、变长块扩展、定长画布内逐块提交与纯扩散.两个块设置的 GSM8K 分别为 24.6 与 77.5,不能统一解释成「块边界挡住 EOS」.定长设置与纯扩散预先建立完整画布,动态设置逐步增加输入;结束条件与可见上下文需要一起比较.

## 6. 掩码重建如何成为训练目标

### 6.1. 前向核从一枚硬币开始

设干净序列为 $x_0=(x_0^1,\ldots,x_0^L)$,词表外增加吸收符号 $M$.连续时间 $t\in[0,1]$ 下,每个位置独立保留原 token 的概率为 $\alpha_t$,变成 mask 的概率为 $1-\alpha_t$:

$$
q_t(x_t\mid x_0)=\prod_{i=1}^{L}
\left[\alpha_t\mathbf 1(x_t^i=x_0^i)+(1-\alpha_t)\mathbf 1(x_t^i=M)\right].
\tag{1}
$$

LLaDA 常用线性日程 $\alpha_t=1-t$.当 $t=0$ 时序列干净,$t=1$ 时全部被遮.吸收意味着 token 一旦在前向过程中变成 $M$,更晚时刻不会恢复成别的词.反向生成沿相反方向,从全 mask 逐渐显露 token.

给定 $x_t$,已露出的 token 与 $x_0$ 完全相同,因此无需预测;网络只估计 mask 位置的干净 token 分布 $p_\theta(x_0^i\mid x_t,t)$.架构虽然沿用 decoder-only Transformer,attention mask 改成全双向.「decoder-only」在这里描述残差块、归一化和 FFN 形态,不再意味着因果可见性.

这个前向核没有随机替换成其他词,与 BERT 的 80/10/10 corruption 不同.输入中的非 mask token 始终可信,反向采样可把它们作为硬条件.做填空时,用户给出的任意位置原文直接放进 $x_t$,待生成区域放 $M$,无需把后缀搬到提示前面.诗歌反向与 FIM 都建立在这条条件结构上.

独立前向腐蚀不等于独立数据模型.真后验 $q(x_0\mid x_t)$ 仍包含语言中全部联合依赖;网络输出通常按位置因子化,这才产生并行采样的联合缺口.多步反向让已揭示 token 逐渐成为公共上下文,缓解一次性独立抽样错误.步数越少,每步同时提交越多位置,联合误差越明显.

对于条件生成,把提示位置集合记为 $C$,回答集合记为 $A$.SFT 只对 $A$ 应用前向 mask:

$$
q_t(x_{t,A}\mid x_{0,A})
=\prod_{i\in A}\left[(1-t)\mathbf 1(x_t^i=x_0^i)+t\mathbf 1(x_t^i=M)\right],
\tag{2}
$$

$x_{t,C}=x_{0,C}$ 始终可见.这给出一个真正的条件扩散目标,不是先无条件生成再拼提示.提示 token 没有监督损失,但通过双向 attention 影响所有回答 mask.

长度仍需另行处理.自回归模型用 EOS 动作决定何时结束;固定画布扩散先分配若干回答位置,再预测内容与 EOS/pad.画布过短会截断,过长会给 EOS 和填充留下大量位置.SFT 数据的 padding 约定因此会进入采样行为,也是因果式逐格解码在 Instruct 权重上崩溃的重要背景.

### 6.2. 为什么损失带 $1/t$

线性吸收日程下,常用训练目标为

$$
\mathcal L(\theta)=
\mathbb E_{x_0,t,x_t}\left[
-\frac1t\sum_{i:x_t^i=M}\log p_\theta(x_0^i\mid x_t,t)
\right].
\tag{3}
$$

记位置 $i$ 的重构损失为 $h_i(x_t)=-\log p_\theta(x_0^i\mid x_t,t)$.固定 $t>0$ 时,$\mathbb E[\mathbf 1(x_t^i=M)h_i(x_t)/t\mid t]=\mathbb E[h_i(x_t)\mid x_t^i=M,t]$,因为该位置被 mask 的概率为 $t$.权重抵消了位置被选中的频率,但右侧仍随 $t$ 改变:其他位置提供多少上下文,决定这次重构有多难.例如同一位置在 $t=0.1$ 时通常能看到更多原文,在 $t=0.9$ 时则主要依靠少量条件和语言先验.去掉权重后,每个噪声强度的期望贡献还会多乘一个 $t$,得到不同训练目标.

更深一层看,该目标来自连续时间吸收扩散的负 ELBO.一般日程下权重与 $-\alpha_t'/(1-\alpha_t)$ 有关;线性 $\alpha_t=1-t$ 化成 $1/t$.$1/t$ 因此前向危险率进入反向似然界的结果,并非人为强调少 mask 样本.换噪声日程后照搬 $1/t$ 会失去这一对应.

$t\to0$ 时权重增大,而 mask 出现概率减小.若条件重构损失可积,一阶期望仍可有限;二阶矩还含额外的 $1/t$,方差需要单独检查.有限 batch 偶尔抽到很小 $t$ 且恰有 mask,可能产生较大的单次贡献.改变时间采样密度为 $g(t)>0$ 时,乘上相应的 $1/g(t)$ 重要性权重可以保持原积分目标,并改变方差;直接截断时间区间或改为按实际 mask 数平均,则通常会改变目标.这些处理需要分别说明采样分布、权重和归一化.

网络在未 mask 位置的输出不进损失,避免学习恒等复制.若对全部位置算交叉熵,大量干净 token 可直接从输入读取,训练 loss 很快下降,生成时全 mask 却没有对应捷径.只监督腐蚀位置让模型必须利用上下文恢复缺失内容.

逐位置交叉熵是因子化条件族的最大似然.共享 Transformer 可让每个边缘利用整段上下文,输出联合仍写成边缘乘积.训练期一次前向看见随机 mask 组合,采样期一次从多个边缘抽 token.两者在单位置风险上匹配,在同时抽样的联合上仍有空隙.低置信 remask、更多步骤、块化或能量校正分别从采样和结构侧处理这条缝.

SFT 沿用同一权重.对一条回答随机遮不同密度,模型同时学习几乎完整答案的局部修正、半成品补全和从全 mask 起草.普通 next-token SFT 每条样本提供唯一左到右因式分解;LLaDA SFT 对许多可见集合求期望.这给双向条件能力,也让同一训练 token 通过不同 mask 视图反复出现,计算口径不能简单按原始 token 与 AR 横比.

### 6.3. 从干净 token 预测到生成轨迹

网络直接预测干净 token,采样还需从当前 $x_t$ 得到更早时刻 $x_s$,其中 $s<t$.对已经显露的位置,吸收过程要求原样保留.对仍为 mask 的位置,先从 $p_\theta(x_0^i\mid x_t,t)$ 提出干净 token,再按解析 posterior 决定本步显露还是继续 mask.

线性日程下,条件于位置在 $t$ 仍为 mask,它在 $s$ 已经干净的概率与 $(t-s)/t$ 对应,继续 mask 的概率约为 $s/t$.因此一步可以理解为:每个 mask 位从模型分布抽一个候选,再按时间跨度提交一部分.离散 $T$ 步越少,$t-s$ 越大,每步提交比例越高.

解析后验给出单个 mask 位置本步揭开的概率,而 [Algorithm 4–5](https://arxiv.org/html/2502.09992v3#A1) 使用逐位置 argmax 候选与固定数量的位置选择.随机策略从尚未提交的位置中随机选取;低置信策略优先提交候选概率较高的位置.固定数量选择在位置之间引入约束,逐位置 argmax 也不同于从真实联合后验抽样,因此不能把随机版本直接当成精确反向采样.若两个候选概率分别为 0.99 与 0.3,随机选择可能先提交后者;置信度排序则把更不确定的位置留到下一轮,让它利用新增上下文.

候选取 argmax 时,其概率可写为 $u_i=\max_v p_\theta(v\mid x_t,t)$,每轮按它排序提交一批位置.相对排序较好就可能帮助生成,即使这些数值尚未准确校准为正确率;使用绝对阈值时,概率尺度则更重要.模型对错误候选过度自信会导致错误提前冻结,原始 LLaDA 的后续步骤只能继续预测尚未提交的位置.温度、CFG 和 SFT 都可能改变概率尺度与排序,采样设置需要随 checkpoint 重新评估.

块扩散把序列切成若干块,块间从左到右、块内并行去噪.块大小 1 对应逐位置提交,块大小等于整段对应全画布去噪.缩小块长会减少同时预测的位置,也改变每轮可见上下文. **缓存还取决于训练与推理采用的可见性.** 原始 LLaDA 使用全双向 attention,已完成前缀的深层状态仍可能读取变化中的后续位置,不能仅凭前缀 token 不再改变就永久缓存其 KV.采用块因果可见性、使完成块不读取未来块时,才有严格复用前缀 KV 的结构条件;当前块仍随去噪重新计算.

原文的 semi-autoregressive remasking 指 **固定完整画布、逐块提交** 的 block diffusion LLaDA.尚未进入的后续块以 mask 保留在网络输入里,与随生成增长输入长度的 block diffusion 不同.两者在块内都使用低置信度选择,已经提交的 token 原样保留,并不默认撤回重做.Table 8 的差别因此不能归因于「只有一种使用低置信 remask」.比较时需要同时保留输入长度、结束条件、块长与提交规则,四种输入范围可对照[生成与采样专题](../../2-数学与生成机制/2.3-生成因式分解与采样/2.3.2-采样后验调度与重掩.md).

纯自回归采样每次只揭最左 mask,理论上也能使用同一网络.它制造的状态分布与 LLaDA SFT 不同:回答右侧长期全 mask,模型训练时见过随机散布的已知右侧 token;EOS padding 又可能在早期被预测并传播.因此 Base 权重只是下降,Instruct 权重可能崩到零.这属于训练—采样状态错配,无法据此断言双向权重缺乏因果生成能力.

### 6.4. 似然与实际生成的两种评测

预训练目标提供数据负对数似然的变分界.在离散时间可把各步 KL 累加,连续时间可对随机 $t$ 的加权交叉熵积分.论文报告的 perplexity 或 bound 要看是否为精确似然、ELBO 还是 Monte Carlo 上界.LLaDA 下游主表更多使用任务准确率,不直接展示模型似然已超过同规模 AR.

多选任务可以通过候选答案的条件似然评分来选择答案.LLaDA 用时间与 mask 的 Monte Carlo 采样估计相应变分评分,得到的是似然界的估计,而非精确计算完整生成概率.估计噪声可能改变选项排序,重复次数因此属于评测协议.共同随机数如何影响候选差值的方差,见下文手算后的方差分析.

[原论文附录 B.6](https://arxiv.org/html/2502.09992v3#A2.SS6) 的接口与预算如下.「长度=步数」表示每轮提交一个回答位置,不表示模型只计算该位置.

| 设置 | 评分或生成接口 | 主表预算 |
|---|---|---|
| Base: MMLU、CMMLU、C-Eval | 单 token 候选的条件评分 | 一次 Monte Carlo 估计 |
| Base: ARC-C、HellaSwag、TruthfulQA、WinoGrande、PIQA、GPQA | 候选条件评分 | 128 次 Monte Carlo 估计 |
| Base: 生成任务 | 低置信选择的纯扩散 | 回答长度与步数均为 1024 |
| Instruct: 全部任务 | 条件生成 | MMLU、HellaSwag 为 3;GPQA 为 64;MBPP、MMLU-Pro 为 256;HumanEval、GSM8K、Math、ARC-C 为 512, 长度与步数相等 |

Instruct 的 HumanEval、MBPP、GSM8K、Math 与 GPQA 还将 EOS 候选的提交置信度设为零.所以同名任务在 Base 与 Instruct 上可能使用不同接口,生成步数和估计次数也不能互换.

生成任务走实际反向采样,分数同时依赖权重和采样器.GSM8K、HumanEval 的准确率不仅测语言分布,也测有限步轨迹能否把正确答案提交出来.同一 Instruct 权重的 69.4 与 78.6 差异主要来自采样方式,不能都当作模型参数的静态能力.

shot 数也是条件格式的一部分.Base GSM8K 4-shot、d1 的 0-shot、后续偏好工作的协议不能直接相减.扩散模型对提示长度、答案画布和 block boundary 敏感,少一个演示会同时改变任务信息与 mask 几何.家族表应在数字旁保留 shot、长度、步数和 sampler.

FIM 评测展示双向补全,AR 基线若接受专门 FIM 数据也能竞争.公平问题有两层:固定训练目标看原生能力,或允许各架构使用最合适的数据增强看产品能力.前者说明掩码扩散无需另造 FIM 格式,后者不能把 AR 的 FIM 训练排除后宣称架构胜利.

诗句反向属于机制压力测试.它让后缀证据成为硬条件,揭示因果模型默认方向偏置.LLaDA 正向较弱、反向更平衡,支持双向条件优势;样本只有 496 对,语言与闭源模型训练语料未知,无法推出通用知识检索全面更强.合理的判断方式是看正反差值和错误类型.

规模曲线同样需要同数据 ARM.跨公司 2.3T 与 15T 包含语料质量、重复率、数学代码比例和 tokenizer 差异.同配方只换目标的曲线才接近因果对照.即便如此,训练 FLOPs 相同不等于推理成本相同,扩散需要多次全序列前向,AR 有 KV cache.

### 6.5. 后训练与家族演进

LLaDA 原版 SFT 使用约 450 万指令对,提示保持干净、回答随机 mask.每个训练样本不要求固定生成顺序,因此同一答案可从多种局部可见状态恢复.格式模板、EOS 与 padding 成为干净条件分布的一部分,错误处理会直接改变采样.

SFT 只能模仿示范,不会显式比较好坏回答.原论文和有 RL 的 LLaMA3 Instruct 对照时,后训练深度不同.后续 LLaDA 1.5 用 VRPO 把 DPO 的完整回答概率比替换为扩散 ELBO 估计,核心困难是四个似然项的 Monte Carlo 方差.共享 mask 和跨时间分配样本用于抵消差分噪声.

d1 走在线验证奖励,用 masked SFT 先种入推理行为,再以 diffu-GRPO 放大组内高奖励回答.它用一步随机 mask 概率作为多步轨迹概率代理,计算便宜、存在偏差.两条路线说明扩散能接偏好和策略梯度,没有证明其目标与 AR 估计同样精确.

后训练数字必须绑定各自基线.LLaDA 1.5 的 78.6 基线、d1 的 78.2 和原论文纯扩散 69.4 来自不同 shot、长度或采样器.把提升相加没有意义.真正可归因的是同篇论文内固定协议的 before/after,以及算法消融中的方差或奖励曲线.

偏好更新还会改变置信度,进而改变低置信采样轨迹.即使 token argmax 少变,某些位置更早提交,实际生成分布也会变化.评估后训练不能只用固定终点重构损失,还要重新校准 sampler.在扩散模型里,权重与调度器耦合比 AR 的 greedy/temperature 更深.

CFG 从另一个方向重排 logits.有条件与无条件预测作外推,增强提示相关信号.它能提高部分 Base 任务,主表为公平没有默认开启.若后训练、CFG 与低置信提交一起调优,收益无法只归给某一项;应先固定 sampler 比权重,再固定权重比 guidance.

### 6.6. 从 8B 到 2.0 的训练起点变化

8B Base 从随机初始化用 2.3T token 学语言和反向生成.它回答「掩码扩散能否从头规模化」.LLaDA 2.0 从成熟 AR MoE 权重出发,用块级课程改变可见性和目标.它回答「能否把已有语言几何迁移到扩散式生成」.两者共享家族名,能力来源不同.

把块长记为 $B$.AR 是 $B=1$,整段双向扩散是 $B=L$.转换开始若直接从 1 跳到 $L$,每层 attention 突然看到未训练过的右侧边,输出头的标签关系也改变,优化可能遗忘.块级 WSD 让 $B$ 和可见图逐步变化,为新目标提供连续路径.

warmup 阶段增加块长、打开双向;stable 阶段强化大块或全序列去噪;decay 阶段缩回部署块长.这里的 decay 不是只降学习率,也包含结构课程收束.终点选择较小块,因为块前缀可缓存,块内并行仍保留部分速度优势.

MoE 路由也面临分布变化.AR token 的 hidden state 只看左前缀,双向块内状态看见未来与 mask.专家负载和路由语义会漂移.转换成功说明原权重可适应,不能推出 MoE 在两种目标下内部路由完全相同.公开主表是整包配方,组件归因需要专门消融.

2.0 的知识能力主要继承 Ling AR 阶段.扩散转换 token 和课程负责重塑条件分布、采样与 serving.将 flash 的 HumanEval 94.51 当作「100B 扩散从噪声学出代码」会错置来源;更准确的说法是 AR 预训练能力在扩散化后得以保留并通过新后训练发挥.

CAP 在 SFT 阶段对当前预测正确的位置加入降低预测熵的辅助训练项,配合推理时的置信阈值,使更多正确候选能在同一轮提交.它是训练目标与推理规则的配合,前向腐蚀过程保持不变.吞吐同时受候选置信度、阈值、任务与 dInfer 实现影响,535 TPS 属于该论文的具体评测设置.

2.0 把严格全序列双向改成部署友好块,也改变模型族.它无法同时声称所有位置任意互相条件和严格前缀 KV cache;块边界规定信息流.评测若主要是左到右回答,这种交换很划算;任意非连续 infilling 是否保留同等能力,需要单独验证.

### 6.7. 四 token 手算与误差分析

设干净回答为 `(A,B,C,D)`,某次训练抽到 $t=1/2$,mask 结果为 `(A,M,C,M)`.模型在位置 2 看到左右两侧 A、C,在位置 4 看到 A、C 与边界,分别预测 B、D.损失为

$$
\ell=2[-\log p_\theta(B\mid A,M,C,M)-\log p_\theta(D\mid A,M,C,M)].
\tag{4}
$$

系数 2 来自 $1/t$.位置 A、C 不进监督,但参与 hidden states.另一次 mask 为 `(M,B,M,D)`,同一句话提供完全不同的条件切片.训练期遍历这些切片,模型才获得任意方向补全能力.

生成从 `(M,M,M,M)` 开始.假设第一步各位置最高置信度为 $(0.8,0.3,0.7,0.4)$,预算提交两个位置,低置信策略先写 1、3,状态变为 `(A,M,C,M)`.第二步条件正好接近上面的训练状态,再恢复 B、D.随机策略可能先写 2、4,若二者依赖 A、C 就更易出错.同一组边缘预测,提交顺序改变后续条件.

若第一步把错误的 $A'$ 以 0.9 高置信写入,后续预测就会读取这个错误条件.原始 LLaDA 的随机与低置信 remasking 都保留已提交 token,错误因此不能在后续步骤直接撤回.真正支持撤回的过程需要另外定义状态转移.重新评估 $A'$ 时也不能只看它在完整输入上的重构概率,因为网络可能直接复制可见 token;可以先遮住该位置,再检查其余上下文给出的预测.撤回的概率构造与候选选择可对照[采样后验调度与重掩](../../2-数学与生成机制/2.3-生成因式分解与采样/2.3.2-采样后验调度与重掩.md).

块长 2 且采用块因果可见性时,先生成 `(A,B)`,完成第一块各层计算并写入 KV,再生成 `(C,D)`.第二块每轮读取第一块的固定 KV,同时重算变化中的 C、D;第一块不读取第二块,因此不受后续揭开动作影响.它付出的代价是生成第一块时不能利用 D 的内容.原始全双向 LLaDA 若仅改变逐块提交顺序,不具备这里的严格缓存条件.块长 1、2、4 分别展示逐位置、块内并行与全段并行三种提交范围.

SFT 再加入提示 `(Q_1,Q_2)`.提示固定,回答四格走同样 corruption.如果训练数据把 EOS 放在 C、后面 D 为 padding,网络会学到「看到部分回答时,C 常是 EOS」.因果采样若过早在 C 写 EOS,裁剪器会丢掉之后内容;纯扩散可以在全局状态中同时协调正文与 EOS.结束符处理属于概率模型的一部分.

**采样调度的三种误差**

第一种是离散化误差.理论连续反向过程包含无穷小事件,实际只走 $T$ 步.每步跨度大时,许多 token 同时从 mask 变干净,网络的因子化输出忽略它们的联合.增加 $T$ 会缩小单步提交集合,代价是更多全序列前向.

第二种是模型误差.$p_\theta(x_0^i\mid x_t,t)$ 与真后验边缘存在偏差,数据、模型容量和 SFT 域移都会影响预测.增加步数可以让尚未提交的位置读取更多已揭开的上下文,但原始吸收采样不会因此修改已提交的错误.更多步骤也不保证任务质量单调提高;逐位置 argmax、词表截断及位置排序仍可能排除正确候选.

第三种是策略带来的差异.低置信排序依赖候选概率,模型对错误候选过度自信时仍会提前提交.块边界、CFG、温度和 EOS 规则也会改变生成轨迹.原论文 Table 9 在 Base 的长度与步数均为 256 时比较随机选择与低置信选择,GSM8K 分别为 21.3 与 70.0;Table 8 的 Instruct 自回归采样则为 0.这两组实验的权重与协议不同,不能合成同一模型只改一个开关的下降曲线.

这些实验可以帮助定位误差,但不能直接将三者完全分离.固定权重扫描步数,同时改变每步提交集合和模型遇到的上下文;固定步数切换位置选择,也会改变后续状态分布.可以另在相同 mask 输入上比较重构概率、校准程度及并行输出的联合约束,再结合生成轨迹检查错误第一次出现的位置.采样器提高任务分数,说明该权重在对应协议下更好用,不直接证明训练得到的似然更高.

时间日程决定每步预算.均匀时间网格在线性 $\alpha_t$ 下近似均匀揭示;非线性日程会把更多步骤放在高噪声或低噪声区.语言生成的难度并不随 mask 比例线性:接近全 mask 时要决定主题,中段形成结构,末段修局部词.最优日程可能与任务、长度和后训练不同.

置信度提交通常规定每步保留多少 token,形成确定性数量曲线.若所有位置都不确定,它仍被迫提交一些;若全部很确定,固定预算又限制速度.阈值法按绝对置信度动态提交,需要良好校准且可能出现某步零进展.CAP 的方向是让更多正确位置越过阈值,提高 tokens per forward.

温度会改变词采样及用于排序或阈值判断的概率.固定提交数量时,降温不会自动增加本步写入数,但可能改变跨位置排序;采用绝对概率阈值时,分布变尖才可能让更多候选过线,也可能让错误候选提前提交.升温同样不意味着已经提交的位置会被重做,这取决于采样器是否允许撤回.比较温度设置时,应同时检查候选分布、每步提交数量与错误首次写入的位置.

CFG 把条件 logits 与无条件 logits 外推,同样会抬高某些位置置信度.若 guidance scale 按任务从集合里挑最好,主表等于含一个额外验证集超参.原论文主对照不开 CFG,保持与 ARM 的协议更干净.后续工作若默认开启,需要单列无 guidance 基线.

**似然估计的方差从哪里来**

对于一条完整文本,随机抽 $t$ 与 mask $x_t$,单样本估计

$$
\widehat L(x_0)= -\frac1t\sum_{i:x_t^i=M}\log p_\theta(x_0^i\mid x_t,t)
\tag{5}
$$

对训练目标无偏,方差来自时间和 mask 两层.高噪声时 mask 多、上下文少,损失大;低噪声时 mask 少、$1/t$ 大.同一文本两次估计可能相差很远.多选题若每个选项独立抽随机源,这种噪声会直接翻转排名.

用相同 $t$ 与对齐 mask 比较候选,可以引入共同随机数.若两个估计分别为 $U,V$,差值方差为 $\operatorname{Var}(U-V)=\operatorname{Var}(U)+\operatorname{Var}(V)-2\operatorname{Cov}(U,V)$.正协方差才能降低差值方差,共享随机源本身不保证这一条件.候选长度不同或 tokenization 不同时,还需要定义 mask 如何对齐.按 token 总和与按长度平均是不同评分口径,后者不再是完整序列的总对数概率.

Monte Carlo 样本数影响界的估计精度,不会改变同一模型和同一目标定义下的理论界.独立重复且方差有限时,$n$ 次估计的均值方差为单次方差的 $1/n$.训练用随机梯度更新,多选评测则需要稳定比较候选,两者对估计精度的要求不同.VRPO 的四项 ELBO 差同样需要控制估计噪声.

生成评测避开显式似然,引入 sampler 方差.同一提示换随机种子、初始 token 抽样或置信并列顺序,答案可能变化.pass@1 需要跨提示统计,pass@k 又受样本相关性影响.扩散不同轨迹可能共享大量早期高置信 token,不能假设 k 个样本完全独立.

对 MMLU 这类多选,似然评分与直接生成选项字母也并非同一任务.前者比较候选文本,后者要求模型遵守输出格式并经历去噪.Base 表使用哪种接口决定数字含义.将似然 MMLU 和生成 GSM8K 平均成一个总分,会把估计器与 sampler 两类误差混为一谈.

## 7. 如何比较家族中的不同模型

LLaDA 8B Base 建立从头预训练基线;Instruct 只加 SFT;1.5 加离线偏好;d1 加推理 SFT 与在线 RL;2.0 更换起点为 AR MoE 并加入块级转换、服务优化.这不是同一 checkpoint 逐次升级的简单版本号,每一步的数据、架构或训练起点都可能改变.

若比较 8B Instruct 与 1.5,可把同基座、同评测协议下的变化主要归给偏好训练配方,仍要考虑采样器选择.比较 8B 与 2.0 时,参数量、MoE、AR 预训练数据、转换和后训练全变,无法把分数提升归给 WSD 某一组件.

2.0 的 mini 与 flash 也并非只差参数规模.底座、活跃参数、训练和 serving 配置需要分别记录.MoE 总参数不等于每 token 计算量,拿 100B 总参数直接与 dense 8B 做 FLOPs 推断会误导.主表能证明成品竞争力,组件因果依赖消融.

后续缓存论文在原 LLaDA 权重上加近似推理,解决重复全序列计算.它们提高吞吐但可能改变 logits 或提交轨迹.缓存加速后的准确率—延迟曲线属于 sampler/system,不能回填成原模型训练成果.同理,dInfer 与 CAP 的吞吐属于 2.0 整体部署栈.

LLaDA-MoE 从零训练的稀疏路线又是另一分支.它可回答扩散目标与 MoE 共同从头学习是否可行,2.0 则回答 AR MoE 能否迁移.两条证据互补.若只看参数名里的 MoE,容易把知识来源混在一起.

最稳妥的家族表应列:起点、参数/激活参数、预训练 token、SFT/偏好/RL、注意力可见性、块长、默认 sampler、缓存方式、评测协议.版本号只是索引,这些字段才决定可比性.

### 7.1. 数据、采样与计算条件

GSM8K 分数同时受到数学数据比例、提示示例与采样器影响.研究训练目标的作用时,需要在同数据与相近计算条件下比较 ARM 和扩散模型;研究成品能力时,则保留各自训练与采样配方,比较完整系统的任务表现.

诗歌反向补全测试的是给定后句恢复前句的能力.固定诗句的记忆与双向填空都可能贡献成绩.进一步研究新事实的逆向关系,需要控制训练中出现过哪些实体关系,并分别测试正向与反向查询.

HumanEval 的采样比较反映该权重在不同生成轨迹下的代码质量.纯扩散可以经过数百次全序列计算,并行预测与多轮迭代共同产生最终代码.分析它如何形成程序结构,还需观察关键位置的提交顺序、尚未提交候选的变化及最终依赖关系.

LLaDA 2.0 的 100B 路线继承 AR 权重,研究如何将已有能力转换到块扩散.原始 8B 与 LLaDA-MoE 则研究扩散目标从头训练.两条路线的起点和计算投入不同,应分别讨论转换成本与完整预训练成本.

吞吐比较需要绑定硬件、并发、输入与输出长度及质量要求.扩散通过一次提交多个 token 获得并行收益,同时承担重复前向的成本.短回答、低并发或低置信候选较多时,每轮提交数和设备利用率都会变化,速度应在对应条件下测量.

偏好与 RL 实验评估更新配方能否改善回答.概率估计则需要单独分析:VRPO 控制 ELBO 差的估计噪声,diffu-GRPO 使用随机掩码概率代理.估计量对其代理目标的性质,与该目标是否等于完整生成轨迹的概率,是两个不同问题.

家族比较因此要同时看训练起点、数据、后训练、采样器和系统.同配方对照帮助理解某个组件的作用,完整系统比较回答它在实际任务上表现如何;两种比较各有用途.
