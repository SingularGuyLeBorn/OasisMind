# 扩散 vs 自回归:全面对比

自回归把 $P(x)$ 写成逐位置条件概率的乘积,离散扩散对可能的去噪轨迹求和,得到最终文本的概率.两者对应不同的概率分解和计算路径.选择模型时,需要分别看注意力能读取哪些位置、哪些状态可以缓存,以及任务质量与实际推理成本.同一个扩散目标也可以搭配全双向或块因果结构,因此不能只看模型属于哪个家族.

## 1. 数学定义

自回归将联合分布分解为条件概率的链式乘积:

$$P_{\text{AR}}(x)=\prod_{i=1}^{n}P_\theta(x_i\mid x_{<i})\tag{1}$$

扩散通过隐变量从噪声逐步生成:

$$P_{\text{Diff}}(x_0)=\sum_{x_{1:T}}p(x_T)\prod_{t=1}^{T}p_\theta(x_{t-1}\mid x_t)\tag{2}$$

式 (2) 采用离散 token 状态, 因而对中间状态求和;连续潜变量模型才使用积分. **生成分布的定义与训练时使用的似然界是不同对象.** 每个转移核归一化时, 上式定义归一化生成分布, ELBO 则为其对数似然提供可优化的下界.

| 方面 | 自回归 | 扩散 |
|---|---|---|
| 联合概率 | 条件概率链式乘积 | 对隐含去噪轨迹边缘化 |
| 可见方向 | 标准因果网络只读取当前及左侧输入位置 | 全双向网络读取当前带噪序列, 包括掩码位置;块因果网络另受块边界限制 |
| 似然能不能横比 | 精确 PPL | 常常是界,不能直接减 |

标准归一化 AR 的 $\log P$ 可以精确求值;掩码扩散通常使用变分训练和蒙特卡洛条件评分. LLaDA 的 MMLU 评分与 HumanEval 生成对应不同评测过程. NLL 和 PPL 的上界应与精确值分别标记, 界的松紧也不直接决定下游任务成绩.

块扩散将序列概率分解为条件块概率的乘积, 每个块概率再对块内去噪轨迹边缘化. ELBO 是块内对数似然的训练下界, 不是可以直接乘入概率定义的因子. $B=1$ 时条件块分解退化为逐 token 分解, 具体训练估计器仍可能使用带噪采样, 见[块扩散](../../4-联合依赖与结构设计/4.1-因式分解与块扩散/4.1.2-块扩散与混合因式分解.md).

## 2. 推理效率

动画左侧采用普通逐 token 解码, 右侧每步可以揭开多个位置. $T$ 与 $n$ 解耦允许一次提交多个 token, 但全双向注意力在长度为 $n$ 的序列上, 每轮注意力分数与加权计算仍具有关于长度的二次复杂度. 当前状态变化后, 受其影响的历史表示需要重新计算.

| 场景 | 自回归 | 扩散 |
|---|---|---|
| 生成 $n$ 个 token | 普通逐 token 解码需要约 $n$ 次串行预测;推测解码可批量验证候选 | $T$ 次去噪前向,每轮可提交多个位置 |
| 吞吐实例 | LLaDA 2.0 对照实验的两个 AR 基线为 256、237 TPS | LLaDA 2.0-flash-CAP 为 535 TPS;相对 256 TPS 基线约 2.09× |
| KV Cache | 固定权重与位置设置下, 因果前缀可精确复用;缓存是加速选项 | 全双向状态变化通常使旧表示失效;块间因果边界允许历史缓存 |

**自回归的概率分解不要求目标模型每次只计算一个位置.** [推测解码](https://arxiv.org/abs/2211.17192v2) 先用较便宜的草稿模型提出多个 token, 再由目标模型在一次前向中并行计算这些候选前缀上的条件概率. 验证从前到后进行, 遇到拒绝位置后丢弃后续草稿, 并按修正分布采样. 使用论文的接受规则和修正分布时, 输出仍服从目标模型的自回归分布. 一轮能接受多少 token 取决于草稿与目标分布的匹配程度;加速还要扣除草稿生成、验证和缓存处理的成本.

上述吞吐来自 [LLaDA 2.0 v1 §7.3、Figure 3](https://arxiv.org/html/2512.15745v1#S7.SS3), 使用 HumanEval、MBPP、GSM8K 和 CRUXEval 四个任务, TPS 定义为生成 token 数除以总耗时. 两个 AR 基线是 Ling-flash-2.0 与 Qwen3-30B-A3B-Instruct-2507, 使用 SGLang;扩散模型使用 dInfer, 揭开阈值为 0.95. **535/256≈2.09, 535/237≈2.26**, 比较时必须保留具体分母. 这个结果同时包含模型、解码与推理实现的影响.

短样本,$T\ll n$ 时扩散可以少跑前向.极长续写,AR 已有 KV 时,全双向每步重算整段反而更贵.

[Fast-dLLM v1 Table 1](https://arxiv.org/html/2505.22618v1#S4) 在 LLaDA-Instruct、GSM8K 5-shot、生成长度 256 上, 吞吐从 6.7 提升到 54.4 token/s, 约 8.1×;同一行准确率从 79.3 降到 78.5, 相差 0.8 个百分点. 实验使用 NVIDIA A100 80GB, 默认前缀缓存块长 32、置信度阈值 0.9;吞吐统计直到 EOS 的端到端解码. 27.6× 那一格对照的是原版 LLaDA 循环,不是 AR.见[推理加速](../../6-推理加速与系统/6.3-缓存部署与服务/6.3.1-缓存与服务调度.md).

[Eso-LM (B)](../../4-联合依赖与结构设计/4.3-规划与任意顺序/4.3.2-eso-lm任意顺序生成.md)按生成顺序重排输入, 并限制后生成的位置影响已生成位置, 从而支持精确缓存. [原论文 v1 §5.2、Table 3](https://arxiv.org/html/2506.01928v1#S5.SS2)在长度8192、批量1、A6000上测得无缓存MDLM耗时5438.3秒, Eso-LM (B)耗时82.1秒;作者概括为约65×. 实验关闭 nucleus 采样, 用极细时间网格使各方法的网络调用次数约等于序列长度. 这项结果展示长序列、频繁调用时的缓存收益, 对照模型未达到8B规模. 同表 AR Oracle 耗时54.0秒, 仍快于Eso-LM (B);65×的分母是无缓存MDLM.

[SDTT v2 §4.4](https://arxiv.org/html/2410.21035v2#S4.SS4) 将采样步数减少32–64倍. 32步约4×、16步约8×的延迟结果使用约1.3B参数的未训练模型测量, 对照带KV缓存的GPT-2结构;实验为单张A100 80GB、批量8, 预热一次后计时10次, 均使用FlashAttention. 这项测量比较计算路径的成本, 并未同时比较这些未训练模型的生成质量. 见[少步蒸馏](../../5-训练-后训练与迁移/5.2-少步与轨迹蒸馏/5.2.1-sdtt少步蒸馏.md).

[DCD v2 §6.1](https://arxiv.org/html/2410.01949v2#S6.SS1)将SEDD-M提供的各位置边际与GPT-2 small提供的联合依赖结合. 在无条件生成128 token、每组10,000个样本、GPT-2 large评测生成困惑度的实验中, DCD的4次去噪达到与SEDD-M的128次去噪相近的质量. 32倍指去噪轮数缩减, 实际耗时还包括联合采样和GPT-2计算. 论文附录E的高效实现顺序揭开位置, 用KV缓存保存GPT-2已生成前缀;少步时这部分计算可能占主要成本. 具体概率构造与采样流程见[离散copula](../../4-联合依赖与结构设计/4.2-联合依赖建模/4.2.1-离散copula.md).

[EDLM v2 Table 3](https://arxiv.org/html/2410.21357v2#S5) 的49%是生成困惑度的相对降幅:无条件生成、2048步、GPT-2评测器下, MDLM为34.9, EDLM-NCE为17.7. 生成困惑度用另一个语言模型给生成样本评分, 与在固定测试文本上计算模型自身的困惑度不同. 同表熵从7.5降到6.9, 质量比较还要结合多样性. 速度结果来自Figure 1(a):生成单条1024 token文本, 达到约35.7的生成困惑度时, EDLM约13秒、MDLM约17秒, 约1.3×. 这两组数字分别固定步数比较质量、固定质量比较时间, 见[EDLM详细解析](../../4-联合依赖与结构设计/4.2-联合依赖建模/4.2.2-edlm残差能量.md).

自适应采样理论研究的是目标分布的依赖结构如何影响离散化步数. [Dmitriev等人 v1](https://arxiv.org/html/2608.23554v1#S1.SS2)使用对偶总相关 $\mathrm{DTC}(X)=H(X)-\sum_i H(X^i\mid X^{-i})$, 其中 $X^{-i}$ 表示除第 $i$ 个坐标以外的全部坐标, $H$ 为熵. 对论文定义的均匀与重掩过程及留一坐标去噪采样器, 达到离散化误差 $\varepsilon$ 所需步数具有 $\widetilde O(\mathrm{DTC}(X_0)/\varepsilon)$ 的保证;对数因子省略在记号中, 估分误差另计. 高维分布也可能具有很小的DTC, 因而该界可以优于随维数 $d$ 增长的最坏情况界. 数值实验使用结构化合成分布与精确条件概率, 没有给出自然语言模型的测速, 见[自适应采样推导](../../6-推理加速与系统/6.1-采样调度与纠错/6.1.1-采样顺序与自适应步数.md).

[SlowFast v3 Figure 2、Table 4](https://arxiv.org/html/2506.10848v3#S4) 在RTX 4090、LLaDA-8B Base、GPQA 8-shot、长度1024的设定下, 吞吐从1.60提高到25.00 token/s, 约15.63×, 两行准确率均为31.47. 叠加缓存还可以提高吞吐, 但最激进配置的准确率降到28.79. 动态选择提交位置与缓存减少重算是两种操作, 对应机制见[快慢动态采样](../../6-推理加速与系统/6.2-验证投机与流水线/6.2.2-规划与快慢动态采样.md).

[dParallel v1 Table 1](https://arxiv.org/html/2509.26488v1#S5) 的8.5×是LLaDA-8B-Instruct在GSM8K-CoT零样本上的时延比:18.6秒降到2.2秒, 平均去噪步数从256降到30, 准确率75.7%变为76.1%. 它通过训练使正确位置更快达到高置信度, 与SlowFast不更新权重的采样调整不同, 见[dParallel确定性蒸馏](../../5-训练-后训练与迁移/5.2-少步与轨迹蒸馏/5.2.2-dparallel确定性蒸馏.md).

[ReFusion v1 Table 1](https://arxiv.org/html/2512.13586v1#S5)使用单张A100、批量1, 比较七项任务的吞吐与准确率或pass@1. 摘要的“超过18×”概括跨任务相对既有掩码扩散模型的加速, 具体任务的倍数差别很大. GSM8K上ReFusion为81.24 token/s, LLaDA-Instruct为27.35, 约2.97×;相应准确率为84.91%和76.35%. ReFusion先规划固定长度的连续片段, 再并行补全片段, 完成后的KV拼接供后续轮次读取. 片段并行补全时没有相互条件化, 直接拼接缓存属于其实现采用的近似;论文§5.5另与全量重算比较. 这项结构改变不能只概括为减少去噪轮数, 见[规划与片段补全](../../6-推理加速与系统/6.2-验证投机与流水线/6.2.2-规划与快慢动态采样.md).

[STaR-Quant v2 Table 4](https://arxiv.org/html/2606.04945v2#S4.SS4) 的 W4A4 配置将 Dream 吞吐从23.27提高到39.33 token/s, 相对FP16约1.69×;峰值GPU显存从13.95GB降到4.44GB. 3.14是两次峰值占用的比值, 对应节省约68.2%的显存, 包括运行时占用而非只计权重. 同论文Table 1中, LLaDA-8B的GSM8K从FP的67.48降到W4A4的57.29, 相差10.19个百分点. 量化同时改变速度、内存和预测误差, 需要按目标任务选精度, 见[量化](../../6-推理加速与系统/6.3-缓存部署与服务/6.3.2-量化与低精度部署.md).

Dream 和 Mercury 的公开速度结果采用不同模型与测量设置. 输出长度、批量、是否计入提示预填充, 以及解码约束都会影响 token/s. 比较时需要同一套任务与测量过程, 仅有两个吞吐数字无法判断生成范式的贡献.

## 3. 生成质量

[LLaDA v1 Table 1](https://arxiv.org/html/2502.09992v1#S3), $*$ 标记表示作者在同一协议下重新评测的 Base 模型;指标后的括号表示 shot 数:

| 指标 | LLaMA3 8B | LLaDA 8B |
|---|---|---|
| MMLU (5) | 65.4 | 65.9 |
| GSM8K (4) | 53.1 | 70.7 |
| HumanEval (0) | 34.2 | 33.5 |
| BBH (3) | 57.6 | 49.8 |
| Hellaswag (0) | 79.1 | 72.5 |

同版本 Table 2 的 Instruct 对照中, LLaDA 只有 SFT, LLaMA3 有 SFT+RL. GSM8K 为 78.6 对 78.3, 均为 4-shot;HumanEval 为 47.6 对 59.8, 均为 0-shot. Base 与 Instruct 的训练阶段不同, Base 的 GSM8K 结果不代表 Instruct. 论文主表没有精确 perplexity 对照.

Dream Table 1 另有一套 $*$:Dream 7B 对 Qwen2.5 7B,MMLU 69.5 对 71.9,Sudoku 81.0 对 21.0.那张表上的 LLaDA HumanEval 是 32.9,与这里 LLaDA v1 的 33.5 属于不同评测记录.见[Dream 章节](../../3-模型谱系/3.2-开放路线与多模态/3.2.1-dream-mercury-gemini与seed.md).

研究扩散训练目标如何随规模增长, 需要同时控制数据与计算预算, 再比较相应的自回归基线. LLaDA的2.3T与LLaMA3的15T还包含语料组成和训练配方差异, 两个总token数不能直接给出样本效率排序.

LLaDA v1 Table 1 的 HumanEval-FIM 使用 2-shot, LLaDA 8B Base 为 73.8, LLaMA3 8B Base 为 73.3. 两数相差 0.5 个百分点, 这张表没有给出足以判断显著差异的不确定性统计. FIM 评价给定两侧代码后补全中间缺口的能力. AR 可以把后缀移到提示中, 让模型在预测缺口时读取左右上下文;掩码模型可以直接保留已知位置并恢复缺口. 这两种输入组织方式与普通续写不同, 单个 FIM 成绩也不能代替完整代码任务的比较.

质量表中的任务差异需要同时检查模型、数据与训练配方. LLaDA Base 在同协议下的 GSM8K 较高, BBH 和 Hellaswag 较低;这些结果没有单独控制注意力方向, 不能从成绩反推某类任务天然适合双向或因果模型. Dream 的数独与代码成绩也分别对应不同阶段和对照模型, 应保留完整表格条件.

## 4. 训练效率

| 维度 | 自回归 | 扩散 |
|---|---|---|
| 单步目标 | next-token | 抽 $t$ 与 mask,加权交叉熵 |
| 序列内并行 | causal mask 内并行 | 双向 + 随机 mask |
| 公开 8B 数据量 | LLaMA3:15T | LLaDA:2.3T |
| 沿用已有 AR 权重的追加训练预算 | — | DiffuLLaMA &lt;200B;Dream ~580B;Fast-dLLM v2 7B ~1.31B;[SDAR](../../5-训练-后训练与迁移/5.1-权重迁移与范式转换/5.1.2-sdar与块扩散转换.md) ~50B |

[Fast-dLLM v2 v1 附录A.1](https://arxiv.org/html/2509.26328v1#A1.SS1)从Qwen2.5-Instruct权重出发, 使用LLaMA-Nemotron后训练数据的子集进行块扩散转换. 7B模型训练2500步, 每步处理256条长度2048的序列, 因而处理的token数为 $2500\times256\times2048=1{,}310{,}720{,}000$, 约1.31B;1.5B模型训练6000步, 对应约3.15B. 这是追加阶段处理的序列token数, 已有模型的预训练与后训练投入另计;补齐位置不参与损失. **转换预算与从头预训练预算不能直接比较.** 不同转换路线还使用不同起点、语料和训练目标, 表中的token数也不能单独衡量样本效率.

掩码扩散通常只在被掩位置计算损失, 时间权重与掩码概率共同决定总体训练目标. 双向可见范围改变了预测所用的条件, 但不能直接推出梯度更大或样本效率更高. 比较训练效率需要固定模型规模、数据和计算预算. 改编路线则复用 AR 权重中已有的能力, 再训练新的生成过程, 见[从自回归改编](../../5-训练-后训练与迁移/5.1-权重迁移与范式转换/5.1.1-从自回归权重改编.md).

训练时,teacher forcing让AR一次前向计算多个位置的next-token损失;掩码扩散一次前向也处理多个位置,通常只在被掩位置计算预测损失.两者都支持位置并行,实际GPU利用率还取决于序列长度、批量和实现.训练计算预算与推理吞吐属于不同指标,不能用从头训练的GPU小时数和推理tokens/s相除来判断哪种生成路线更便宜.

## 5. 任务能力与选型

### 5.1. 控制生成与后训练

连续扩散的中间状态是实值向量, 因而可对控制目标求梯度, 调整当前潜变量后继续去噪. Diffusion-LM把离散词映射到连续嵌入, 在潜变量上结合语言模型与控制分类器的信号, 最后映回离散文本. [原论文Table 2、§6.2](https://arxiv.org/pdf/2205.14217)中, 80M参数模型的Syntax Tree指标为86.0, FUDGE为17.9;该指标是生成文本解析树相对目标树的F1.

离散模型的控制接口不同:填空可以固定已知位置, 定长任务可以设置待生成位置;无分类器引导（CFG）则组合带条件与去条件的模型预测, 改变采样分布. 这些操作分别控制输入结构和概率权重, 不等同于对连续潜变量求梯度. 具体公式与相应实验见[可控生成](../7.1-条件控制与序列奖励/7.1.1-可控生成与推理期转向.md).

无需更新权重的粒子转向在反向轨迹上保存多个候选状态, 根据序列奖励调整提案与重采样. [嵌套SMC v1 §4、Table 1](https://arxiv.org/html/2608.20123v1#S4)使用12层、隐层768的MDLM, 默认50次去噪. 毒性转向把分类器对有毒类别的对数概率作为奖励, 检验采样器能否找到基础模型下罕见的目标样本. 外层粒子数 $N=4$、内层提案数 $M=8$、中间重构数 $K=4$、奖励强度 $\lambda=10$ 时, 基础模型、best-of-$n$、bootstrap SMC、NSMC与FA-NSMC的毒性率依次为0.003、0.022、0.25、0.39、0.40. 此处提高毒性率表示更强地转向指定奖励, 安全性判断需要另设目标和评测. 计算预算按扩散网络调用数匹配, 奖励计算与重采样仍有额外成本;算法权重与粒子流向见[嵌套SMC解析](../7.1-条件控制与序列奖励/7.1.2-嵌套smc与序列级奖励.md).

提示和固定位置约束改变模型收到的条件, logit调整与粒子转向改变推理时的采样过程, SFT和偏好优化则改变模型权重. 这些层面可以组合, 自回归与扩散都需要按实际接口选择方法. 离散扩散的偏好优化与奖励训练还需定义去噪轨迹的概率或估计量, 具体推导见[对齐](../../5-训练-后训练与迁移/5.3-后训练与任务评测/5.3.1-偏好优化与强化学习.md).

对齐成绩需要连同后训练配方比较.原版LLaDA Instruct只有SFT,与经过RL的LLaMA3 Instruct对照时,差异包含后训练投入.LLaDA 1.5的GSM8K结果也对应具体采样器和评测协议.比较PPO、DPO、GRPO与扩散后训练方法时,需要检查轨迹概率和梯度估计如何定义,具体推导见前面的对齐章节.

### 5.2. 反转诅咒

LLaDA原论文§3.3使用496对中文诗句,分别给出上一句预测下一句,或给出下一句预测上一句,不再针对诗句任务微调.Table 3中LLaDA Instruct的正向/反向成绩为48.8/42.4,GPT-4o为82.7/34.3.反向查询时,已知的下一句放在提示前缀中,自回归模型也能读取它.**因果掩码限制序列位置的可见方向,并不禁止回答语义上的反向问题.** 随机掩码训练会让两侧内容都成为恢复缺失位置的条件,这改变了模型学习关联的方式;实际成绩还取决于训练覆盖、模型能力与解码策略.详见[双向注意力](../../4-联合依赖与结构设计/4.1-因式分解与块扩散/4.1.1-双向注意力与反转问题.md).

块采样会把全局双向收进块内.报反转分数时写清是纯扩散还是块解码.

这组诗句结果中,GPT-4o的正向成绩更高,LLaDA的反向成绩更高.两个方向共同描述了各模型在该任务中的表现,无法分别当作知识量、文风或注意力结构的独立测量.虚构人物关系的微调实验则研究另一种训练分布,与无额外微调的诗句补全应分开阅读.

### 5.3. 长文本

| 方面 | 自回归 | 扩散 |
|---|---|---|
| 生成长文本 | 逐 token 续写,不淘汰历史时 KV 存储随长度线性增长 | 全双向密集注意力每轮为 $O(n^2)$, $T$ 轮合计 $O(Tn^2)$;块扩散按块续写 |
| 上下文读取 | 每个输入位置读取自身和左侧;末尾位置可以读取整个输入前缀 | 全双向网络读取两侧当前输入, 掩码位置仍参与计算;预测时未知的真实 token 不作为输入 |
| 可变长 | 天然 | 全双向靠 `[EOS]` / 预垫;块扩散可再开一块 |

表中的复杂度只计密集注意力的分数与加权运算, 固定层数和隐藏维度;前馈层、投影与缓存读写仍有额外成本. 块扩散把当前块的去噪与已完成历史的读取分开, 但当前块仍需读取允许访问的历史, 块内并行不会消除长前缀成本.

[LLaDA 2.0 v1 Figure 5](https://arxiv.org/html/2512.15745v1#S6) 报告的是 RULER 长上下文评测:flash 在 4k–32k 的成绩均高于93, mini 在32k为83.94. 上下文窗口长度与一次生成的文本长度是两个量;这组成绩没有证明模型能在全双向模式下一次去噪生成32k文本. 其部署结构使用块扩散, 历史块与当前块之间保留因果边界.

训练时还要区分文档边界与块边界. LLaDA 2.0 的[文档级注意力掩码](https://arxiv.org/html/2512.15745v1#S4.SS2)阻止打包到同一序列的无关文档互相读取, 减少人为拼接带来的错误依赖. 防止答案泄漏则要检查带噪位置能否读取自己对应的干净标签;文档隔离本身并不能替代这一检查.

### 5.4. 幻觉,一致,事实

**同轮预测共享上下文, 不等于同轮采样拥有完整联合分布.** 当各位置独立抽样或取 argmax 后一起提交时, 分别合理的候选可能组合成不一致输出. [ParallelBench](7.2.1-并行性评测与失效诊断.md)研究这一类局限, [联合依赖](../../4-联合依赖与结构设计/4.2-联合依赖建模/4.2-联合依赖建模.md)给出具体概率例子.

不同方法改变依赖的表示或提交过程. [CRoCoDiL](../../4-联合依赖与结构设计/4.2-联合依赖建模/4.2.4-crocodil连续草稿.md)通过连续草稿引入潜在联合结构;[DCD](../../4-联合依赖与结构设计/4.2-联合依赖建模/4.2.1-离散copula.md)、[EDLM](../../4-联合依赖与结构设计/4.2-联合依赖建模/4.2.2-edlm残差能量.md)与[CoDD](../../4-联合依赖与结构设计/4.2-联合依赖建模/4.2.3-codd可算联合层.md)分别使用 copula、残差能量和可算联合层. 重新掩码提供修改已提交位置的机会, 验证式采样则检查候选的接受条件. 方法有效性要在对应任务和预算下测量;这些结构本身都不能保证事实正确.

### 5.5. 基础设施

| 维度 | 自回归 | 扩散 |
|---|---|---|
| 推理实现 | 使用支持目标模型的因果解码框架 | 需要支持对应去噪循环、注意力掩码和缓存更新;LLaDA 2.0实验使用dInfer |
| 权重量化 | GPTQ / AWQ 生态默认 | AR 向 PTQ 直接搬会掉;STaR-Quant 管掩码态和跨步误差,见[量化](../../6-推理加速与系统/6.3-缓存部署与服务/6.3.2-量化与低精度部署.md) |
| 开源权重 | LLaMA / Qwen / 等 | LLaDA,Dream |
| KV 复用 | 因果前缀在固定计算条件下可复用 | 全双向去噪需检查状态变化;块因果结构可复用已完成块 |
| GQA | 多个查询头共享较少的 KV 头 | 同样是头之间的共享设计,是否跨去噪步复用需另外判断 |

**GQA 解决头之间的共享,KV Cache 解决时间上的复用.** 较少的 KV 头可以降低单次前向中的 KV 存储量,但不会让变化中的双向表示自动保持不变.反过来,使用 MHA 的因果网络也可以缓存历史 KV.判断缓存是否精确,应逐层追踪同一历史位置的输入和可见范围:权重、位置设置与历史前缀固定,且新位置不能反向影响历史表示时,历史 KV 才保持不变.新 token 的前向读取这份缓存,计算本位置的新 KV,再追加供后续位置使用.

因果前缀缓存的服务流程可以处理已完成块, 但块内仍需增加去噪循环、并行提交与停止条件. 全双向填空直接保留两侧已知内容, 跨步缓存则要处理输入改变后的失效. 混合结构可以同时使用多种组件, 具体收益取决于哪些位置被允许相互读取以及实现怎样维护这些状态.

### 5.6. 选型

任意位置填空与不相邻的表格缺格适合考察掩码扩散,它可以直接把保留内容作为可见条件.自回归模型也能通过 FIM 训练、重排输入或任务提示完成填空和反向查询,最终选择还要看对应任务的训练覆盖与质量.可变长对话、超长续写则需要重点检查停止条件与缓存成本.比较吞吐时保留硬件、批量、输出长度和基线实现;比较可控性时先确定约束能否直接写入输入与解码规则,再评估额外评分或后训练的收益.

质量、速度和缓存是不同维度. 同协议的任务表衡量输出能力, 计算图确定哪些状态可复用, 实际服务测量给出吞吐与延迟. 选型应把三者结合, 而不从一个加速倍数或单项成绩推出整体优势.

缓存是否能够复用,可以沿一次生成过程看清楚.图中A、B、C代表依次出现的token,$h_B$、$h_C$分别是相应位置的最终网络输出;K、V是各注意力层保存的键和值.图中的缓存表用一层示意,实际网络逐层保存.因果掩码保证后来的C不会反向改变A/B的表示,因此在权重、位置设置和历史前缀固定时,已有缓存可以保留.

### 5.7. 图 1 解析

- **预测与输入分开**:第一面板的$h_B$经输出投影与softmax产生下一token分布,采样得到C后,C才进入第二面板的网络计算.预测C时还没有C的KV.
- **读取与追加分开**:第二面板逐层读取第一面板的历史KV,计算C的新KV和$h_C$.第三面板保留原来的A/B缓存并追加C;后续位置读取的是扩展后的历史.分面中的①、②指向同一批对象的来源.
- **缓存与输出分开**:$h_C$用于预测下一个token,各层的新KV用于后续注意力读取.两者来自同一次前向,承担不同职责.矩阵的行是查询、列是键,三行分别表示A读取A、B读取A/B、C读取A/B/C.

全双向掩码扩散中,新揭开的位置可能改变其他位置的表示,跨去噪步直接读取旧KV就需要额外条件或近似处理.块因果结构把已完成块与当前去噪块隔开,历史缓存保持固定,当前块随去噪状态重新计算.相应缓存流程见[SDAR](../../5-训练-后训练与迁移/5.1-权重迁移与范式转换/5.1.2-sdar与块扩散转换.md).

### 5.8. 从任务约束选择生成方式

双向可见范围、并行提交和似然训练界分别描述不同对象.双向网络能直接读取输入中已可见的两侧内容;并行提交减少顺序依赖,但每轮前向的计算量仍要计算.ELBO是生成模型对数似然的下界,其松紧影响似然估计的解释,不会直接给出下游任务排序.选择具体模型时,还需结合对应任务成绩与实际资源成本.

用动画中的提示「床前明月」观察一次生成. 普通 AR 解码先预测「光」, 将它加入前缀后再预测后续位置;后面生成的「霜」不会改变已提交的「光」. 掩码扩散先建立待生成位置, 提示保持固定, 采样器可以先揭开末尾的「霜」, 再让它作为恢复中间位置的条件. 此处采用揭开后固定的采样方式;允许重掩的采样器还会重新修改已提交位置.

缓存失效沿网络层传播. 一个位置从掩码变成 token 后, 该位置的输入表示与相应 K、V 改变;其他位置若读取它, 注意力输出也可能变化, 进而影响后续层的 K、V. 所以即使某个位置的 token 没变, 深层缓存也未必仍然有效. 固定提示的首层输入投影可以保持不变, 但提示位置若能读取变化中的生成区, 更深层表示仍可能变化. 块因果结构则禁止历史块读取当前块, 使已完成块的表示不受当前去噪状态影响;代价是当前块不能读取尚未生成的未来块. 若「霜」位于后面的块, 前面的块就无法用它辅助恢复.

代码补全需要区分连续缺口和多个不相邻缺口. 连续缺口可以用 FIM 把左右上下文组织成提示;多个缺口则需要检查模型如何接收固定位置、保持已知内容并表达缺口之间的依赖. 对话、工具调用和长日志还涉及输出长度变化、停止条件与跨请求缓存. 块长同时改变可见范围和每轮计算量, 应在对应任务上比较质量与延迟, 不能仅由「代码」或「对话」这一任务名称确定.

后训练目标也要随反馈来源选择. 风格偏好提供文本比较或评分, 数学任务可能提供答案验证, 句法约束则可能在生成时直接检查. 能否取得 token 概率、怎样计算轨迹概率、奖励落在 token 还是整条输出上, 决定哪些目标与估计器可以实现. VRPO、d1 和连续 Diffusion-LM 分别展示偏好优化、推理训练和梯度控制的具体路线, 不构成三类任务各自唯一的选择. 推导与实验见[后训练](../../5-训练-后训练与迁移/5.3-后训练与任务评测/5.3.1-偏好优化与强化学习.md)和[可控生成](../7.1-条件控制与序列奖励/7.1.1-可控生成与推理期转向.md).

服务实现需要匹配生成状态. 自回归解码增加一个前缀 token, 扩散解码可能一次提交一组位置, 允许重掩的采样器还会撤回部分提交. 块扩散则同时管理块间因果边界和块内去噪循环. 评估部署兼容性时, 应检查当前实现的调度、注意力掩码、KV 生命周期和输出长度处理, 不能仅由模型名称判断.

GSM8K的成绩需要连同提示与训练阶段阅读:

| 来源 | 提示与生成设置 | 对照结果 |
|---|---|---|
| [LLaDA v1 Table 2](https://arxiv.org/html/2502.09992v1#S3) | 4-shot, Instruct模型 | LLaDA 78.6;LLaMA3 78.3 |
| [d1 v1 Table 1](https://arxiv.org/html/2504.12216v1#S4) | 0-shot, 生成长度512 | LLaDA-Instruct 78.2;追加SFT后81.1;SFT与diffu-GRPO后82.1 |
| [LLaDA 1.5 v1 Table 1与§4.1](https://arxiv.org/html/2505.19223v1#S4) | 4-shot, 偏好优化前后比较 | LLaDA-Instruct 78.6;LLaDA 1.5 83.3 |

d1的82.1对应SFT与diffu-GRPO的组合, 单独追加diffu-GRPO在同一长度下为81.9. 其基线与SFT模型使用最终checkpoint, RL模型则从第600步起每100步评测并报告最佳结果. 因而78.2到82.1的差值同时涉及训练配方与checkpoint选择, 不能全部归为单个算法的独立贡献. 跨论文比较还要匹配采样器、输出预算和shot数, 仅凭83.3与82.1无法判断两种后训练方法的优劣.
