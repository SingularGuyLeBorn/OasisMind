# Eso-LM:任意顺序损失,因果注意力换精确 KV

[任意顺序与概率因式分解](../../2-数学与生成机制/2.3-生成因式分解与采样/2.3.1-任意顺序与概率因式分解.md)区分了生成顺序与注意力结构.LLaDA / MDLM 都支持任意顺序,但每揭开一次就要重算整段 $K,V$.块扩散通过固定块间顺序恢复前缀缓存,块内仍使用双向注意力.Eso-LM(Sahoo 等人,arXiv:2506.01928)保留对排列求期望的训练目标,把注意力改为因果结构,从而在扩散阶段精确复用 KV.名字里的 Esoteric 指用于探索语言边界的深奥编程语言,与前向核 $Q_t$ 无关.

并行生成不必绑定双向注意力.Eso-LM 通过洗牌把生成顺序移到序列本身,再用因果注意力恢复 KV Cache.实验包含 A/B 两档注意力结构,PPL 对照以及相对无缓存 MDLM 的 14× / 65× 延迟结果.骨架是 LM1B / OWT 上的 DiT 尺度,参数量没有达到 7B.

## 1. 损失任意,注意力不必双向

吸收态 $1/t$ 损失在期望上等于对生成顺序求自回归负对数似然.这个等价关系约束训练**目标**,并不规定 Transformer 中 Query 的可见范围.MDLM 用全双向注意力参数化任意顺序条件,当前所有可见 token 都可作为上下文.代价是 Key 依赖整句以及尚未揭开的占位符;新揭开一个 token 后,所有 $K,V$ 理论上都会变化.

任意顺序 AR 本来就允许因果注意力:把序列按某条排列 $\sigma$ 排好,再做下三角.Eso-LM 把这条老路接回掩码扩散.给定 $z_t$,把干净 token 聚到左边,MASK 聚到右边,**位置编码仍用原句的下标**(RoPE / 绝对位置都不跟洗牌走).然后走标准因果注意力.左边的干净前缀再也不会依赖右边尚未揭开的 MASK,KV 可以写进缓存.MASK 之间按洗牌后的次序因果可见:本步要揭的那些 MASK 能看见全部干净字,以及排在自己前面的其它 MASK.

![Eso-LM 通过随机顺序训练与原位置编码在因果注意力下实现任意顺序生成](images/fig-eso-shuffle-causal.png)

> 图 1:左列按原序使用全双向注意力,无法精确复用 KV.右列先洗牌再使用因果注意力,已确定前缀的 KV 可以持续复用.任意顺序损失与双向解码并不绑定.

### 1.1. 图 1 中的排列与计算图

- **左列 mixed clean and MASK**:LLaDA / MDLM 默认.位置 $i$ 的 Query 看见所有 $j$.
- **every token attends every other**:揭开任意一格,所有 Key 过期.
- **NFE times $L^2$**:步数乘全序列注意力.并行揭开减的是 NFE,减不掉每一次前向的 $L^2$.
- **右列 gather clean left**:洗的是计算图,不是语义顺序.RoPE id 仍是「这个词在句中第几号」.
- **causal attention; exact KV**:干净前缀单调变长,和 AR 的前缀同构,只是前缀里的词不一定是从左到右长出来的.
- **65× vs uncached MDLM**:Table 11 在 $L=8192$,最坏 $T\gg L$,禁 nucleus,A6000.对照物是无 KV 的 MDLM;AR 和 Fast-dLLM 的 27.6× 使用其他协议.

例如原句为 $(A,B,C,D,E,F)$,当前 $z_t=(A,\mathrm{M},C,\mathrm{M},\mathrm{M},F)$.洗牌后的计算序列可以是 $(C,A,F,\mathrm{M},\mathrm{M},\mathrm{M})$,RoPE 仍分别使用原位置 3,1,6,2,4,5.在因果掩码下,第一个 MASK 看见 $C,A,F$,后面的 MASK 还可看见排在前面的 MASK.$A$ 的 Key 不依赖任何 MASK,下一步揭开新 token 时,只需把它的 KV 追加到干净前缀.全双向注意力则需要重新计算整段 KV.

洗牌时必须同时保留原位置 id.若把左侧三个干净 token 重新编号为 1,2,3,模型会把 $C,A,F$ 误认为句首.RoPE 的相对位置应描述 token 在原句中的距离,而非洗牌后计算序列中的次序.因此 token 表示随内容移动,RoPE 角度仍取原下标;缺少后一项会破坏句法与语义位置关系.

图右有两种顺序同时存在.原位置 $i$ 表示 token 在最终句子中的语义坐标,排列位置 $k$ 表示它在当前因果计算图中的可见次序.注意力掩码按 $k$ 构造,位置编码按 $i$ 构造.将两者混用会产生两种不同错误:按 $i$ 做因果掩码会重新限制为左到右,按 $k$ 做位置编码会把洗牌后的临时顺序当成句法顺序.

设排列 $\sigma=(\sigma_1,\ldots,\sigma_L)$,第 $k$ 个计算位置装载原序列的第 $\sigma_k$ 个 token.输入表示可写为

$$
h_k^{(0)}=E(x_{\sigma_k})+P(\sigma_k)+T(t),
\tag{1}
$$

$E$ 是 token 嵌入,$P(\sigma_k)$ 表示原位置编码,$T(t)$ 是扩散时间条件.第 $k$ 个 Query 只能读取 $j\leq k$ 的 Key.因此因果关系由 $k$ 决定,空间关系由 $\sigma_k$ 决定.这正是任意顺序条件生成能够使用因果 Transformer 的关键分离.

缓存项也按计算顺序追加,每项仍携带原位置相位.若 RoPE 作用于 Query 和 Key,缓存中的第 $j$ 项使用 $P(\sigma_j)$ 对应的旋转.下一轮加入原位置 $i$ 的新 token 时,它的 Query 与历史 Key 的相对相位反映 $i-\sigma_j$,不会反映它被追加到缓存尾部这一事实.缓存物理地址可以单调增长,语义坐标无需单调.

### 1.2. 任意顺序联合概率的含义

注意力偏置写成 $A\in\{-\infty,0\}^{L'\times L'}$,并加到 Softmax 前的 logits.训练使用两种 $A$:扩散样本采用洗牌后的下三角偏置;顺序样本把干净 token 放在左侧,MASK 保持原相对次序,并允许 MASK 看见 shift-by-one 对应的干净版本.两种偏置共用同一套权重.训练与推理都采用因果依赖,因此缓存的 KV 与实际计算图一致;仅在推理时把双向模型改为因果掩码无法获得这种性质.

对固定排列 $\sigma$,联合概率由链式法则写成

$$
p_\theta(x\mid\sigma)=
\prod_{k=1}^{L}
p_\theta\!\left(x_{\sigma_k}mid x_{\sigma_{<k}},\sigma\right),
\tag{2}
$$

$x_{\sigma_{<k}}$ 是排列中较早生成的 token.若排列来自分布 $p(\sigma)$,表面序列概率为

$$
p_\theta(x)=\sum_{\sigma\in\mathcal S_L}
p(\sigma)p_\theta(x\mid\sigma).
\tag{3}
$$

式 (3) 是排列混合模型.同一个句子通过多条顺序路径获得概率质量,因此某条顺序下的乘积不能单独当作最终序列似然.训练对随机排列取期望,通常优化

$$
\mathcal L_{\mathrm{AO}}(x)
=\mathbb E_{\sigma\sim p(\sigma)}
\left[-\sum_{k=1}^{L}
\log p_\theta(x_{\sigma_k}\mid x_{\sigma_{<k}},\sigma)
\right].
\tag{4}
$$

式 (4) 平均每条路径的负对数似然,与式 (3) 的负对数混合似然并不相等.Jensen 不等式给出

$$
-\log p_\theta(x)
\leq \mathcal L_{\mathrm{AO}}(x)
\quad\text{当 }p(\sigma)\text{ 同时作为混合权重时}.
\tag{5}
$$

训练所有顺序都表现良好会压低上界,也可能把容量分散到推理时很少使用的排列.若推理固定采用某个调度,与训练均匀排列之间会存在路径分布差异.均匀训练带来顺序鲁棒性,不保证每条顺序同样容易.

链式法则本身对任意固定排列都成立,前提是各条件来自同一个联合分布.神经网络为不同可见集合分别输出条件,有限容量下未必严格兼容.例如两变量 $X,Y$ 的模型可能同时给出 $p(X=1)=0.9$、$p(Y=1\mid X=1)=0.9$、$p(Y=1)=0.1$ 和 $p(X=1\mid Y=1)=0.1$.两条顺序诱导的联合质量会不同,无法由单个精确联合同时满足.对排列求期望是在训练中压缩这类矛盾,不会自动使所有条件完全兼容.

### 1.3. 条件兼容与路径一致性

两变量情形最容易看清条件兼容.若存在联合分布 $p(x,y)$,则

$$
p(x)p(y\mid x)=p(y)p(x\mid y)
\tag{6}
$$

对所有 $x,y$ 都成立.神经网络分别在可见集合 $\varnothing$、$\{X\}$ 和 $\{Y\}$ 上预测时,式 (6) 没有结构保证.训练数据与共享参数让这些条件趋向一致,但损失只在采样到的掩码和排列上施加局部约束.模型容量、优化误差和状态覆盖不足都会留下闭环不一致.

长度为三时,同一个目标 token 可以经不同可见集合到达.例如 $p(C\mid A)$ 与先生成 $B$ 后得到的 $p(C\mid A,B)$ 都参与路径.路径一致不要求这两个条件相等,因为信息量不同;它要求沿所有完整排列得到的乘积对应同一联合.可以检查交换相邻生成动作前后的对数概率差:

$$
\Delta_{i,j}(S)=
\log p(x_i\mid x_S)
+\log p(x_j\mid x_S,x_i)
-\log p(x_j\mid x_S)
-\log p(x_i\mid x_S,x_j).
\tag{7}
$$

$S$ 是已经可见的位置集合.精确兼容时 $\Delta_{i,j}(S)=0$.它相当于在排列图的一条小闭环上比较两条路径.对训练或验证状态抽样计算 $|\Delta|$,可以诊断任意顺序模型的条件是否因顺序发生系统漂移.

闭环误差与最终生成误差不完全相同.某些低概率状态上 $|\Delta|$ 很大,实际采样很少访问;高概率轨迹上的小偏差则会在长序列中累积.因此诊断应按模型轨迹加权,同时报告最坏值用于发现结构问题.只比较不同顺序的最终 PPL 会把误差来源混在一起.

因果洗牌还引入可见次序信息.条件网络不仅知道可见 token 集合,还可能从缓存次序或注意力位置推断它们按什么顺序加入.若联合语义只应依赖集合,同一集合的不同排列应得到相同下一 token 分布:

$$
p_\theta(x_i\mid x_{\sigma_{1:k}})
=p_\theta(x_i\mid x_{\rho_{1:k}}),
\quad
\{\sigma_{1:k}\}=\{\rho_{1:k}\}.
\tag{8}
$$

原位置编码减少了临时次序进入空间语义的机会,因果层仍可能通过隐藏状态传播顺序痕迹.随机化已见 token 的排列、采用集合等变结构或增加一致性损失,都能压低式 (8) 的差异.严格消除次序信息可能限制缓存组织和表达能力,需要由任务结果判断是否值得.

## 2. A 档贴近似然,主方法换 KV

### 2.1. 两种注意力结构对应两类条件族

作者把「从 MDLM 走到可缓存」拆成两刀.

Eso-LMs (A):MASK 上因果,干净位之间仍双向.扩散阶段不能精确缓存干净字的 KV,因为干净字互相看见,也仍可能被尚未揭开的结构影响.附录 Table 9 / 10,$\alpha_0=1$ 全扩散时,A 档 LM1B NELBO PPL 30.96 对 MDLM 31.78,略好;OWT 26.21 对 25.19,略差.论文说 matches.他们不追求 A 档,因为它在扩散阶段仍没有他们要的 KV.

主方法(正文里的 Eso-LMs):干净位也因果.这才换来扩散阶段精确 KV.同一 $\alpha_0=1$,LM1B NELBO 36.12 对 MDLM 31.78,大约 +4 PPL;OWT 30.06 对 25.19.缺口来自「干净字不能互相看」.似然竞赛输了这一截,换的是缓存.

噪声日程还包含 $\alpha_0$:$\alpha_t=\alpha_0(1-t)$.$\alpha_0=1$ 接近纯扩散;$\alpha_0=0$ 回到 AR 精确似然(LM1B 21.86,与带 AdaLN 的 AR 相同).中间值在两套损失之间插值,batch 中一部分样本走扩散,另一部分走顺序填充.Table 1 同时报告 Exact 与 NELBO.$\alpha_0=0.125$ 时 LM1B Exact 为 23.02,接近 AR 的 22.83,同时保留一段可并行的扩散期.$\alpha_0$ 控制质量与速度的工作点,而非定义新的前向核.

主方法还声称第一次给 MDM 报**精确**似然(重要性加权,LM1B 用 $K=5000$,OWT 用 $K=1000$).MDLM 通常只报 NELBO.OWT 上 $\alpha_0=1$ 的 Exact 29.31,和 MDLM 的 NELBO 25.19 仍有缝.他们强调 $\alpha_0=1$ 尽管 NELBO 差一截,固定采样时间下生成质量仍优于 MDLM,因为每步便宜.似然表和速度表要一起读.

A 档在干净 token 之间允许双向交互.给定已见集合 $S$,每个 $x_i,i\in S$ 的隐藏表示可依赖集合中所有其他 token.新增一个 token 后,旧隐藏状态也可能改变,所以缓存失效.主方法要求旧 token 的表示只依赖它加入时更早的计算前缀,新增 token 不会反向影响旧 Key 与 Value.由此得到单调可追加缓存.

两类结构近似的条件分布不同.A 档更接近集合条件 $p(x_i\mid x_S)$,理想情况下对 $S$ 内排列不敏感;主方法实现的是顺序条件 $p(x_i\mid x_{\sigma_{1:k}};\sigma_{1:k})$,共享参数通过随机排列学习近似集合语义.当目标依赖可见 token 之间多轮交互时,A 档表达更直接.主方法仍可在深层因果网络中让后加入 token 汇总此前信息,旧 token 无法获得后加入 token 的反馈.

考虑已见位置 $A$ 和 $B$,下一位置 $C$ 需要比较 $A$ 与 $B$ 的关系.A 档可让 $A$ 的表示读取 $B$、$B$ 的表示读取 $A$,再由 $C$ 读取两个更新后的表示.主方法若顺序为 $A,B,C$,$B$ 可以汇总 $A$,$C$ 再读取 $B$,仍能完成比较;若某种计算要求 $A$ 在看到 $B$ 后更新并由多个后续位置复用,主方法只能让后续位置重复完成这项组合.这种差异解释了缓存与似然之间的代价,不意味着因果网络无法表示双向关系.

### 2.2. 精确似然仍然需要边缘化顺序

精确似然为什么现在才可算.双向 MDM 的潜变量是整条掩码轨迹,重要性加权要 $K\times L$ 次前向,一般不可行.任意顺序写法里,一条排列 $\sigma$ 已经串起这条轨迹上的所有潜变量,单样本估计方差更小.Table 2 用一条 OWT 句子,100 次试验:$\mathcal{L}_{\mathrm{MDM}}$ 抽 10 个 $(t,z_t)$,标准差 0.56;$\mathcal{L}_{\mathrm{AO}}$ 只抽 1 个 $\sigma$,标准差 0.03,均值几乎一样.这是工程动机,不仅是论文审美.LM1B 句子短($L=128$),他们甚至给 MDLM 跑了 $K=1000$ 的 IW,精确似然仍落后 AR.扩散在似然竞赛上的缝,不全是估计器太松,也有模型族自己的缝.Eso-LM 用因果参数化,至少让「缝有多大」第一次能写在 Exact 列里.

一条排列给出 $p_\theta(x\mid\sigma)$ 的可计算乘积,式 (3) 仍含 $L!$ 项.重要性采样从提议分布 $q(\sigma\mid x)$ 抽取 $K$ 条排列,估计

$$
\hat p_K(x)=\frac{1}{K}\sum_{k=1}^{K}
\frac{p(\sigma^{(k)})p_\theta(x\mid\sigma^{(k)})}
{q(\sigma^{(k)}\mid x)},
\quad \sigma^{(k)}\sim q.
\tag{9}
$$

若 $q=p(\sigma)$,权重退化为 $p_\theta(x\mid\sigma)$.不同排列的概率跨度很大时,少数权重会主导估计,有效样本数降低.因果任意顺序的优点是一次排列可在一条前向链上累计所有条件项,不代表排列边缘化已经免费.

对数似然常用 $\log\hat p_K(x)$,有限 $K$ 下仍有偏差.随着 $K$ 增大,重要性加权下界收紧.报告 Exact 一列时要同时读取 $K$、提议分布和序列长度;不同 $K$ 的数不能直接当作同精度估计.论文在 LM1B 与 OWT 使用不同 $K$,与句长和计算预算有关.

顺序分布若由模型学习,联合概率还要包含 $p_\phi(\sigma\mid x_{\sigma_{<k}})$ 的逐步选择概率.测试时用启发式调度而训练似然假定均匀 $p(\sigma)$,生成器对应的路径分布会变化.这不妨碍将调度当作搜索算法使用,但生成样本不再是式 (3) 下未经修正的精确采样.似然估计与有限步生成质量应分别报告.

### 2.3. $\alpha_0$ 如何改变概率分解

$\alpha_0=0$ 时模型沿固定左到右顺序应用链式法则,不存在扩散阶段的排列混合.$\alpha_0=1$ 时全部 token 进入任意顺序目标,每条样本训练可见多种掩码集合.中间 $\alpha_0$ 可理解为将序列的一部分概率质量交给任意顺序阶段,剩余部分交给顺序阶段.它改变训练样本中两类条件的比例,也改变推理时可并行处理的范围.

设切换点为随机变量 $m$,扩散阶段生成集合 $S_m$,顺序阶段按原位置完成补集.一种抽象分解是

$$
p(x)=\sum_{m,S_m,\sigma}
p(m,S_m,\sigma)
\left[\prod_{k\leq m}p_\theta(x_{\sigma_k}\mid x_{\sigma_{<k}})\right]
\left[\prod_{i\notin S_m}^{\text{原序}}p_\theta(x_i\mid x_{S_m},x_{<i}\cap S_m^c)\right].
\tag{10}
$$

第一项容许不相邻位置并行或任意排序,第二项恢复标准顺序.实际算法的 $\alpha_0$ 和 $\kappa$ 控制方式更具体,式 (10) 用于说明混合生成仍对应完整条件乘积,切换点前后的上下文集合不同.

切换太早时,大多数 token 由顺序阶段生成,质量接近 AR,扩散并行收益有限.切换太晚时,更多 token 使用有限容量的任意顺序条件,因果干净位的表达缺口和并行因子化误差增大.最佳点随长度、模型容量和 NFE 改变.单个 $\alpha_0$ 的验证集最优值不构成跨任务常数.

混合训练还提供共享参数正则.顺序样本教会模型稳定的左到右条件,扩散样本扩展可见集合与生成顺序.若两类梯度方向冲突,共享层需要折中;若互补,顺序任务可为早期训练提供较低方差信号.消融 $\kappa$ 的意义就在于观察两类梯度配比,不能只把它当成数据 batch 的实现参数.

## 3. 采样两阶段,一份 KV

### 3.1. 调度定义了生成路径

生成先走扩散期:每步揭开一个或多个不必相邻的 MASK,前向只喂「已干净 ∪ 本步要揭的 MASK」,不是整段占位符.再走顺序期:剩下的 MASK 从左到右一个一个填.两期共用同一份 KV.第 $k$ 步把第 $k-1$ 步新干净字的 KV 写入,更早的前缀直接复用.原则上调度 $\mathcal{S}$ 可以在测试时改,不必等于训练时见过的那条.

和 BD3-LM 的差别不在「能不能插值 AR」,在缓存完不完整.块扩散:块间真 KV,块内双向,块内无精确 KV.少步时 BD3-LM 会出又差又没多样性的样本,作者写得很难听.Eso-LM 少 NFE 时仍和 MDM 竞争性,高 NFE 时贴近 AR.帕累托图(Fig. 4 / 17)是无条件生成,生成 PPL 与 MAUVE,不是 HumanEval.

相对 BD3-LM,长上下文延迟约 3–4×:Table 11,$L=8192$ 时相对块长 16 约 3.2×,相对块长 4 约 3.8×.相对无 KV 的 MDLM:$L=2048$ 约 14×,$L=8192$ 约 65×.测速在单卡 A6000,吞吐另在 H200.最坏设定 $T\gg L$,关掉 nucleus.长度越长,无缓存基线越亏,倍数越好看.短句,已经很快的 AR serving,看不到 65.

在相同 NFE 下,Eso-LM 比 AR 略慢,因为 KV 到倒数第二步才完全可复用:新 MASK 第一次出现时还不能作为历史.Eso-LM 的加速基线是每步执行 $L^2$ 双向注意力的 MDLM,不是经过成熟 serving 优化的 vLLM 因果模型.

MDLM 的一次去噪会对全部 $L$ 个位置计算注意力,即使其中大部分仍是占位符.Eso-LM 第 $k$ 步只把 $\cup_{i\le k}S_i$ 送入网络,其中包含已经干净的 token 和本步要揭开的 MASK.长序列的早期步骤只处理少量位置,激活长度因而远小于 $L$.65× 加速同时来自 KV 复用和前向集合缩减.若实现仍把全序列填充进 CUDA graph,后一部分收益会消失.论文的调度 $\mathcal{S}$ 与注意力偏置共同确定有效前向集合,仅实现 KV 缓存会低估完整方法的加速幅度.

令 $S_k$ 是第 $k$ 轮提交的位置集合,$U_k=\bigcup_{j\leq k}S_j$ 是累计已提交集合.一条合法调度满足 $S_j\cap S_k=\varnothing$ 且最终 $U_K=\{1,\ldots,L\}$.每轮条件分布为

$$
p_\theta(x_{S_k}\mid x_{U_{k-1}},S_k),
\tag{11}
$$

若对 $S_k$ 内位置独立采样,进一步近似成 $\prod_{i\in S_k}p_\theta(x_i\mid x_{U_{k-1}})$.调度决定每轮条件集,集合大小决定并行程度.所有 $|S_k|=1$ 时得到任意顺序串行生成;单轮 $|S_1|=L$ 时近似无条件并行预测,联合一致性最弱.

Eso-LM 的因果计算可以让同一轮 MASK 按内部次序相互可见,但同时采样哪些 logits、哪些 token 已进入条件需要精确定义.若一轮中的后方 MASK 读取前方 MASK 的占位表示,它并未看到前方本轮新采样的词;若在同一轮内逐个写入并更新隐藏状态,该轮实际包含多个串行子步.报告 NFE 时应区分一次批量前向和轮内递归.

调度可以预先固定,也可以由当前分布自适应选择.固定等间距策略不读取 logits,路径概率容易复现;置信度策略依据去噪器输出改变 $S_k$,高置信位置先进入缓存;学习规划器可以结合错误概率和信息价值.后一类调度产生状态依赖路径,同一句话在不同采样随机数下可能走不同排列.

### 3.2. 顺序策略与信息增益

由易到难策略使用 $c_i=\max_v p_\theta(x_i=v\mid x_U)$ 排序.它降低单步提交错误,还会让可靠 token 成为后续上下文.等间距策略关注同批位置之间的依赖:空间距离较远时,在局部相关数据上更接近条件独立.两者优化不同代理量,一个测单点可靠性,一个减少批内耦合.

更直接的目标是选择能最大幅度降低剩余不确定性的集合.对候选集合 $S$,信息收益可写为

$$
G(S)=H(X_R\mid x_U)-
\mathbb E_{x_S\sim p_\theta}
H(X_{R\setminus S}\mid x_U,x_S),
\tag{12}
$$

$R$ 是未生成位置集合.精确计算需要枚举 $x_S$ 并重复评估剩余分布,成本远高于一次去噪.置信度、距离、注意力影响和小型规划头都可作为近似.当 $G(S)$ 近似次模时,逐个贪心选择有较好性质;语言依赖包含互补结构,次模性没有普遍保证.

计划与填槽在此分开.计划器选择 $S_k$ 和内部次序,填槽器给出 $x_{S_k}$.一个好计划可以让普通填槽器获得充分上下文,一个强填槽器也能缓解次优计划.评测计划器时应冻结填槽器,否则两者共同变化无法归因.Eso-LM 使用启发式 $\mathcal S$,没有训练独立脏净头.

顺序策略还会形成内容偏差.高频词和标点往往置信度高,会被优先提交;稀有实体与数字留到后面.这可能有利于先搭建句法,也可能让低信息 token 占用早期并行预算.距离策略与内容无关,避免频率偏差,却不能发现某个关键实体能约束整句.任务相关规划需在两者之间权衡.

### 3.3. 搜索、并行与束宽

任意顺序生成的搜索空间同时包含位置动作和 token 动作.串行时,每一步有约 $|R|V$ 个位置—词组合;批量大小为 $b$ 时,位置组合数为 $\binom{|R|}{b}$,token 组合达到 $V^b$.完整束搜索不可行,实用方法必须先压缩位置候选或对 token 作因子化.

两阶段搜索可先保留 $K_s$ 个位置集合,再为每个集合保留 $K_x$ 个 token 候选.路径评分为

$$
J=\sum_k\left[
\log p_\phi(S_k\mid x_{U_{k-1}})
+\log p_\theta(x_{S_k}\mid x_{U_{k-1}},S_k)
\right]-\lambda K,
\tag{13}
$$

$\lambda$ 惩罚轮数或计算.启发式调度没有显式 $p_\phi$,第一项可省去,这时搜索找到的是给定调度候选集中的高概率 token 路径.若把置信度排序分数当概率累加,需要先校准其归一化含义.

并行提交会减少搜索深度,增加单层分支相关性.串行束搜索能够在每个 token 后重新排序,批量搜索要在看到组内其他 token 前承诺多个选择.可使用候选重采样:一次并行生成多个完整批次,由序列评分器选择;它用宽度换深度,每个候选仍受组内独立近似限制.

另一种折中是树状调度.先并行生成相距较远的锚点,再把未填区间分裂成子区间,每层同时处理多个互不重叠区域.若序列局部依赖较强,树深约为 $O(\log L)$,每层位置之间相对独立.长距离语义依赖会穿过区间边界,树结构没有普遍正确性.等间距启发式可看作这种思想的第一层.

缓存约束影响搜索共享.不同位置顺序会形成不同 KV 前缀,束之间难以完全共享缓存;拥有相同已见集合但加入次序不同的束,隐藏状态也可能不同.限制搜索只改变下一批集合、保持已有前缀一致,可以共享历史 KV.更自由的顺序搜索带来更大质量空间,同时削弱 Eso-LM 的系统优势.

### 3.4. 一次小规模手算

考虑长度为 4 的二元序列,当前已知原位置 1 的值为 $A$,其余位置未填.候选调度甲先生成位置 3,再同时生成位置 2 和 4;调度乙按原序生成 2、3、4.假设模型给出的条件概率为

$$
\begin{aligned}
p(x_3=C\mid x_1=A)&=0.8,\\
p(x_2=B\mid x_1=A,x_3=C)&=0.9,\\
p(x_4=D\mid x_1=A,x_3=C)&=0.7.
\end{aligned}
\tag{22}
$$

调度甲若第二轮独立填 2 和 4,目标路径概率近似为 $0.8\times0.9\times0.7=0.504$.若位置 2、4 在给定 $A,C$ 后仍相关,这个乘积不是它们的真实联合.调度乙可能给出

$$
p(B\mid A)=0.6,
\quad p(C\mid A,B)=0.95,
\quad p(D\mid A,B,C)=0.95,
\tag{23}
$$

路径概率为 $0.5415$.虽然甲第一步置信度更高,完整路径反而略低.局部最高置信选择没有最大化完整联合乘积.

再设调度甲第二轮的真实联合 $p(B,D\mid A,C)=0.75$,高于边缘乘积 $0.63$,则甲的正确联合路径为 $0.8\times0.75=0.60$,反过来超过乙.判断顺序优劣需要联合条件,不能只根据三项边缘数字.这个例子也说明批内正相关时乘积会低估一致组合,负相关时会高估.

缓存状态在两条调度中不同.甲的追加顺序是原位置 $(1,3,2,4)$,乙是 $(1,2,3,4)$.每项 RoPE 仍用 $(1,3,2,4)$ 或 $(1,2,3,4)$ 中记录的原坐标,因果可见历史则按追加次序增长.即使两条路径最终得到相同表面序列,中间隐藏表示和路径概率也可能不同.

若模型条件完全兼容,把甲第二轮拆为先 2 后 4时应满足

$$
p(B,D\mid A,C)=p(B\mid A,C)p(D\mid A,B,C).
\tag{24}
$$

并行边缘乘积使用的是 $p(B\mid A,C)p(D\mid A,C)$,少了 $B$ 对 $D$ 的条件.这项缺失正是并行加速的概率代价.位置相距很远只是在某些数据上让两项接近,不构成恒等式.

### 3.5. 调度的动态规划视角

将已见集合 $U$ 视为状态,选择下一集合 $S\subseteq U^c$ 为动作,填槽后的新状态为 $U\cup S$.若代价同时考虑错误和计算,最优价值满足

$$
V(U,x_U)=\min_{S\subseteq U^c}
\left\{c(S,U)+
\mathbb E_{x_S\sim p_\theta}
[V(U\cup S,x_{U\cup S})]
\right\}.
\tag{25}
$$

$c$ 包含一次前向成本与本轮错误风险.状态数量为 $2^L$,还要考虑每个 $x_U$ 的取值,无法精确动态规划.置信度、距离和固定日程都是对价值函数的局部近似.

若只惩罚轮数,$c$ 会鼓励一次提交尽可能多的位置;若只惩罚 token 错误,最优策略可能退化成完全串行并进行大量搜索.实际目标用系数 $\lambda$ 平衡两者.不同部署延迟预算对应不同 $\lambda$,所以不存在脱离成本定义的全局最佳顺序.

可以训练价值网络 $V_\psi(U,x_U,b)$ 估计剩余预算 $b$ 下的最终质量.位置策略选择使价值最高的集合,填槽器提供转移.训练价值需要从真实或模拟轨迹得到回报,策略改变后状态分布也会变.若回报来自外部任务验证,样本效率通常低于 token 交叉熵.

滚动时域控制提供较便宜近似:枚举少量候选 $S$,向前模拟一两轮,用当前去噪损失或验证器给终端状态评分,只执行第一步.它比纯置信度看到更远,每个候选需要额外前向.候选数、模拟深度和质量之间形成新的计算曲线.

对于局部依赖序列,可以把状态压缩为若干未填区间及边界 token,动态规划复杂度下降.自然语言的远距离实体、格式和语义依赖破坏这一假设.块扩散隐含采用了区间分解,等间距调度隐含假设相远位置依赖较弱.Eso-LM 本身不要求这些假设,启发式调度的效果会受其影响.

### 3.6. 并行度如何进入误差上界

设本轮集合 $S$ 的真实联合为 $p_S$,边缘乘积近似为 $q_S=\prod_{i\in S}p_i$.二者的 KL 散度

$$
D_{\mathrm{KL}}(p_S\Vert q_S)
=\sum_{i\in S}H(X_i\mid x_U)-H(X_S\mid x_U)
\tag{26}
$$

称为总相关,衡量批内依赖.当位置条件独立时为零;集合扩大通常纳入更多依赖,总相关倾向增加.这给出动作大小与联合误差之间的直接联系.

Pinsker 不等式把 KL 与总变差联系起来:

$$
\operatorname{TV}(p_S,q_S)
\leq\sqrt{\frac12D_{\mathrm{KL}}(p_S\Vert q_S)}.
\tag{27}
$$

因此选择总相关较小的集合能控制单轮近似分布偏差.问题仍在于模型只有边缘条件,无法廉价得到真实 $p_S$.若训练一个成对依赖头,可以近似两两互信息,高阶约束仍可能遗漏.

多轮误差会累积.若第 $k$ 轮转移核近似误差为 $\epsilon_k$,粗略上最终总变差不超过 $\sum_k\epsilon_k$.该界通常很松,却说明减少 NFE 与增大单轮误差之间存在结构性折中.少步方法必须让每轮集合更大,除非使用能够直接表示块联合的去噪器.

位置选择还改变未来误差.当前提交一个高信息 token 可能降低后续集合总相关,即使它自身置信度不最高.动态规划式 (25) 需要考虑这种长期作用.等间距策略通过空间分散近似降低当前相关,由易到难策略通过增加可靠上下文近似降低未来相关,两者各抓住一部分.

## 4. 和 DualCache,块扩散,LLaDA 8B 分开

### 4.1. 精确缓存依赖一个单调不变量

Fast-dLLM DualCache 是**近似**:承认 $K,V$ 会变,赌相邻步余弦相似度高.Eso-LM 是**精确**:注意力定义让干净前缀的 $K,V$ 不再依赖未来 MASK.近似可以贴在现成 LLaDA 权重上,训练免费;精确要按洗牌+因果重训(或从 MDLM 改注意力再训).27.6× 贴的是原版逐步揭开的 LLaDA;65× 贴的是无缓存 MDLM.两张卡,两种骨架,两种对照物.

块扩散把任意顺序限制在块内,以获得块间 KV 缓存.Eso-LM 仍可在全序列并行揭开不相邻的 MASK,不会受到未来块不可见的限制,代价是主方法中的干净 token 之间也采用因果依赖.A 档恢复干净 token 间的双向注意力,同时失去扩散阶段的精确 KV.跨句填空更适合全双向或 A 档,长序列无条件生成与缓存更适合主方法.目前还没有 8B 指令模型上的同规模对照.

LLaDA 8B 于 2025 年 2 月发布,论文明确指出全双向注意力与当时的 KV 缓存公式不兼容,因此采用 MHA 而非 GQA.Eso-LM 是同年 6 月沿 MDLM 路线发表的后续工作,实验停留在语言模型基准,下游任务留作未来工作.正文还提到 Sahoo 等人 2026 年把 $\alpha_0=1$ 扩展到 1.7B,在零样本似然任务上与 MDLM 具有竞争力.该结果的模型规模和任务都不同于 LLaDA 8B 的 GSM8K,因此 65× 不能直接作为 LLaDA 产品加速数据.

GQA 在因果前缀上重新具有明确收益.干净前缀的 KV 可以精确复用,减少 KV 头能够直接节省有效缓存内存.Eso-LM 实验没有采用 GQA,只证明了这种组合在依赖结构上可行.未来若出现因果洗牌的 7B 模型,GQA 与 KV 量化可以沿用 AR 系统的实现方式.这属于架构上的可能性,并非当前检查点的规格.若开放 8B 模型同时要求精确 KV 与双向填空能力,仍需在 A 档和块扩散之间取舍.65× 与 27.6× 分别使用不同模型和基线,不能放在同一协议下直接比较.

洗牌实现还要同步移动位置 id,否则 RoPE 会把所有干净 token 解释为句首.训练时 MASK 的因果次序来自 $\sigma$,测试时可以更换调度,前提是已预测 token 不再依赖未预测 token.若只洗牌 token 而未同步调整注意力偏置,计算图会偏离因果约束,缓存的 KV 也无法精确复用.

精确 KV 的不变量可以写成:对任意已经提交的位置 $i\in U_k$,其第 $\ell$ 层缓存 $(K_i^{(\ell)},V_i^{(\ell)})$ 只依赖 $x_{U_j}$,其中 $j$ 是位置 $i$ 加入缓存的轮次,后来加入的 $U_k\setminus U_j$ 不改变它.形式上,

$$
(K_i^{(\ell)},V_i^{(\ell)})
=F_\ell(x_i,x_{U_{j-1}},\sigma_{\leq j}),
\quad i\in S_j,
\tag{14}
$$

且 $F_\ell$ 的输入不含 $S_{j+1},S_{j+2},\ldots$.因果注意力从结构上保证这一点.双向注意力即使数值变化很小,也不满足精确相等;DualCache 利用的是变化小这一经验事实.

层归一化、MLP 和残差都逐 token 计算,不会破坏单调不变量.会破坏它的组件包括跨 token 归一化、读取未来位置的卷积、双向注意力以及根据整句统计动态调整旧 token 表示的模块.因此精确缓存并非只由注意力 mask 决定,整条网络的数据依赖都必须保持因果.

位置重新洗牌后,物理缓存下标与原位置分离.系统需要保存原位置 id 以计算 RoPE,还需保存生成轮次或缓存序号以构造因果可见性.这两列元数据很小,语义却不可混淆.如果按原位置排序缓存以便连续访问,重排过程不能改变旧隐藏状态;如果按追加顺序保存,输出还原时再 scatter 回原坐标.

### 4.2. 三条缓存路线的概率代价

DualCache 保留全双向条件,以旧 KV 近似新状态下的 KV.设真实更新后缓存为 $K_t$,复用值为 $\tilde K_t$,注意力 logits 误差近似受

$$
\|A_t^{(q)}K_t^\top-A_t^{(q)}\tilde K_t^\top\|
\leq \|A_t^{(q)}\|\,\|K_t-\tilde K_t\|
\tag{15}
$$

控制.相邻步表示变化小时误差小,重掩范围大或状态突变时误差增大.该路线不改变训练概率族,推理转移是近似计算.

块扩散将序列分成有序块.已完成块满足因果前缀不变量,当前块内部使用双向条件.它的联合分解可写为

$$
p(x)=\prod_{b=1}^{B}p(x_{G_b}\mid x_{G_{<b}}),
\tag{16}
$$

块内 $p(x_{G_b}\mid x_{G_{<b}})$ 再由扩散近似.缓存只在块边界精确,块顺序固定会限制全序列任意填槽.增大块能改善块内双向表达,同时减少缓存比例并加重并行因子化误差.

Eso-LM 将每个新 token 或新集合追加到因果计算前缀,精确缓存覆盖整个生成过程.它保留原位置上的任意选择,代价是条件网络受加入次序影响.三条路线分别承担数值近似、块顺序限制和因果表示限制.它们不能仅按速度倍数排序,因为生成分布并不相同.

A 档位于块扩散和主方法之间:已见干净集合内部双向,对 MASK 的预测采用因果安排.它改善似然,却使旧干净表示随集合扩张而变化.若每隔若干轮整体重算干净集合,中间轮复用近似缓存,可形成混合方案.这种方案的误差和成本取决于重算间隔,已不属于论文报告的精确缓存主方法.

### 4.3. 填空任务为何更难共享缓存

无条件生成从空状态逐步增加 token,因果加入顺序自然形成一条历史.填空任务一开始就有左右两侧的固定上下文.若把所有已知 token 洗到因果前缀,它们内部仍按某个顺序编码,后加入的已知 token 能看见较早者,较早者看不见较后者.预测空槽时可以读取全部已知 token 的最终缓存项,但这些缓存项没有经过完整双向交互.

一个简单例子是模板 `A [槽] B`,其中槽答案取决于 $A$ 与 $B$ 的配对关系.若前缀顺序为 $A,B$,预测槽的 Query 能直接同时注意两者,理论上可以在当前层组合信息;较深组合若要求 $A$ 的表示先吸收 $B$,只有 $B$ 的表示具备这项信息.足够深、足够宽的预测 token 可以自己完成组合,有限模型可能从双向编码获益.

多槽填空还涉及槽之间的关系.因果调度先填某个槽后,其 token 进入缓存并可约束其他槽;先填错误会传播.双向扩散每轮重新编码所有已知与暂填 token,允许各槽互相修正.Eso-LM 的单调缓存若不允许重算旧 token,纠错只能通过新增表示或重新生成位置实现,不能更新旧上下文对其他位置的表达.

条件输入通常不需要生成,可以单独用双向编码器得到固定 memory,解码 token 通过交叉注意力读取它.这样左右上下文内部双向,生成侧保持因果可缓存.联合模型变成 encoder-decoder,参数与计算不再等同于原 Eso-LM.对长固定提示、多 token 输出的任务,一次编码成本可摊薄;对无条件生成,额外编码器没有对象可编码.

### 4.4. GQA、RoPE 与缓存压缩的组合边界

GQA 让多个 Query 头共享较少的 Key/Value 头.只要历史 KV 不依赖未来 token,共享头不会破坏精确缓存.设 Query 头数为 $H$,KV 头数为 $G$,头维为 $d_h$,缓存元素数从每层 $2LHd_h$ 降到 $2LGd_h$.Eso-LM 的任意原位置 RoPE 仍逐 KV 头应用,共享只发生在头维,不改变位置相位.
