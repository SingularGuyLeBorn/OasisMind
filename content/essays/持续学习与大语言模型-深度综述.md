## 1. 引言与动机

### 1.1 从静态训练到终身学习

传统机器学习范式通常假设：训练数据服从独立同分布（Independent and Identically Distributed, IID），模型在固定数据集上充分训练后部署，之后便不再更新。这一假设在学术界的大多数基准测试中是合理的，但在现实世界中却很少成立。真实数据往往以流的形式出现：新闻每天都在更新，法律法规会修订，编程语言和框架不断迭代，科学发现持续涌现，用户偏好也会随之变化。如果模型在部署后不能继续学习，它的知识就会迅速过时，性能也会随时间退化。因此，研究如何使模型在非平稳环境中持续学习，成为人工智能走向长期自主部署的关键问题。

持续学习（Continual Learning，CL），又称终身学习（Lifelong Learning）或增量学习（Incremental Learning），旨在让模型从一系列按时间到达的任务或数据分布中学习，同时保留之前获得的知识。与迁移学习（Transfer Learning）强调一次性跨域迁移不同，持续学习关注序列学习场景中的知识累积与遗忘控制；与在线学习（Online Learning）强调每个样本只处理一次不同，持续学习通常允许对任务数据进行多次遍历，但更关注任务间知识的长期保存；与元学习（Meta-Learning）强调快速适应新任务不同，持续学习更强调在生命周期中保持稳定与可塑性的平衡。

### 1.2 灾难性遗忘：核心障碍

持续学习面临的最大障碍是灾难性遗忘（Catastrophic Forgetting）。McCloskey 与 Cohen[^1] 在 1989 年研究连接主义网络时发现，当神经网络学习新任务后，其在旧任务上的表现会急剧下降。这一现象的根源在于神经网络的参数被后续优化过程覆盖：深度模型的参数空间是高度共享的，新任务的梯度更新会改变对旧任务同样重要的权重，导致旧任务的最优解被破坏。法国心理学家在其后的认知科学讨论中也使用了“灾难性干扰”这一术语，描述人类记忆中新学习对旧记忆的破坏。虽然人类大脑通过海马体与新皮层之间的记忆重放（replay）和系统巩固（systems consolidation）在一定程度上缓解了这一问题，但人工神经网络仍缺乏同等级别的机制。

在计算机视觉的早期研究中，灾难性遗忘主要表现为：一个 initially 训练好的图像分类器，在只见过新类别的数据后，会把旧类别错分为新类别。在 NLP 中，一个语言模型在持续微调于某一领域后，可能在通用语言能力、语法、事实知识和指令遵循上退化。在强化学习中，智能体学会新策略后，可能忘记如何在旧环境中行动。随着模型规模变大，遗忘不仅发生在最后的分类层，也发生在深层表示中，且涉及更复杂的输出分布、安全对齐和世界知识。

### 1.3 大语言模型为何需要持续学习

大语言模型（LLM）的训练通常分为三个阶段：预训练（Pre-training）、监督微调（SFT）和对齐（Alignment，如 RLHF/DPO）。每个阶段都耗资巨大：预训练需要数千张 GPU/TPU 运行数周，微调和对齐也需要大量计算与人工标注。因此，不可能每次有新数据或新知识出现就从头训练整个模型。持续学习成为更新 LLM 的必然选择，具体动机包括：

- **知识更新**：世界知识不断变化，新事实、新事件、新术语需要被纳入模型。例如，2024 年后出现的模型需要知道新的政治人物、科技产品、流行文化和社会事件。
- **领域适配**：医疗、法律、金融、科学等领域有大量专有知识和动态规范。通用 LLM 需要持续吸收这些领域数据，以提供专业服务。
- **能力扩展**：新任务、新工具、新 API、新编程语言不断出现。模型需要持续学习新的指令分布和工具使用模式。
- **个性化与反馈**：用户交互会产生大量反馈，模型需要根据用户偏好和安全策略持续调整，而不破坏通用能力。
- **多模态与具身扩展**：LLM 正在被扩展为视觉-语言模型、具身智能体、机器人控制模型。这些模态和行为空间也需要持续学习。

### 1.4 持续学习对 LLM 的特殊挑战

将经典持续学习方法直接应用于 LLM 会面临若干独特挑战：

1. **规模与成本**：LLM 通常有数十亿到数千亿参数，全量微调成本极高，因此需要参数高效（PEFT）和模块化的方法。
2. **通用能力的脆弱性**：LLM 经过大规模预训练和对齐，获得了通用语言理解、推理、代码生成和安全拒绝能力。持续微调很容易破坏这些通用能力，造成“对齐税[^2]”（alignment tax）。
3. **复杂遗忘面**：LLM 的遗忘不仅发生在特定任务准确率上，还可能表现为事实一致性下降、幻觉增加、安全边界模糊、输出格式变化、指令遵循能力退化等。
4. **无任务边界**：现实世界数据通常没有明确的任务划分，而是连续流或弱结构化的领域流。因此 Task-IL、Class-IL 等强假设不再成立，需要 task-free 或 streaming 设定。
5. **数据隐私与合规**：持续学习往往需要存储用户数据或历史数据，涉及隐私、安全、合规（如 GDPR[^3]、可遗忘权[^4]）等问题。
6. **评估困难**：LLM 能力是多维的，单一准确率或遗忘率不足以刻画持续学习效果，需要通用基准、安全评估、长程记忆测试和人工评估相结合。

## 2. 核心概念与基础理论

### 2.1 问题形式化

持续学习的最基本形式可以形式化为一个序列优化问题。假设模型参数为 $\theta$，在时间 $t$ 到来的是任务或数据分布 $D_t = \{ (x_i^{(t)}, y_i^{(t)}) \}_{i=1}^{N_t}$，其中 $N_t$ 可能很大或未知。模型依次在每个 $D_t$ 上训练，目标是最终参数 $\theta_T$ 在所有已见分布 $D_1, \dots, D_T$ 上都表现良好。用损失函数 $L_t$ 表示第 $t$ 个任务的风险，则理想目标是：

$$\min_{\theta_T} \sum_{t=1}^{T} L_t(\theta_T; D_t)$$

然而，在训练时刻 $t$，模型只能访问 $D_t$（或少量历史数据），因此实际训练的是：

$$\min_{\theta_t} L_t(\theta_t; D_t) + \Omega(\theta_t, \theta_{t-1}, \dots, \theta_1)$$

其中 $\Omega$ 是某种正则化或约束项，用来防止模型偏离旧知识太远。如果 $\Omega = 0$，就是朴素的顺序微调（Sequential Fine-tuning，SeqFT），通常会导致灾难性遗忘。持续学习方法的本质就是设计合理的 $\Omega$、数据回放、参数隔离或外部记忆，使序列训练后的模型近似接近联合训练（joint training）的下界。

在概率视角下，持续学习可以看作序列贝叶斯推断：在观察到 $D_t$ 后，更新后验 $p(\theta | D_{1:t})$。如果后验能够近似保留，就不会遗忘。EWC 等方法正是用拉普拉斯近似对后验进行高斯近似，并通过 Fisher 信息矩阵估计后验精度。

### 2.2 持续学习场景划分

根据任务边界是否已知、标签空间是否变化，传统持续学习通常划分为三类：

- **任务增量学习（Task-Incremental Learning, Task-IL）**：在训练和测试时都知道当前样本属于哪个任务，模型可以使用任务特定的输出头或任务嵌入。这种设定最容易，但最不现实。
- **领域增量学习（Domain-Incremental Learning, Domain-IL）**：任务身份未知，但所有任务共享相同的标签空间。主要挑战是输入分布的漂移，例如同一组类别在不同视觉风格下的图像。
- **类增量学习（Class-Incremental Learning, Class-IL）**：任务按类别逐步到来，测试时无任务身份，模型必须对所有已见类别进行分类。这是最具挑战性的传统设定之一，因为分类器的输出头必须不断扩展，且新类别容易主导决策。

在 LLM 中，这些强假设往往不成立。指令微调数据没有明确的“任务标签”，而是由领域、能力、语言、工具等弱结构化因素组成。因此，LLM 持续学习更常采用以下设定：

- **任务自由（Task-Free）**：数据流没有任务边界，模型需要自动检测分布变化或持续适应。
- **流式学习（Streaming/Online Learning）**：每个样本只出现一次或少数几次，要求低内存和快速更新。
- **领域持续学习（Domain Continual Learning）**：数据按领域或时间顺序到来，目标是在新领域上表现好，同时保持旧领域能力。
- **能力持续学习（Capability Continual Learning）**：每个阶段侧重不同能力（如推理、代码、多语言、工具使用），需要保持综合能力。
- **纵向持续学习（Vertical Continuity）**：从通用预训练到领域预训练再到任务微调，模型在不同阶段持续学习。
- **横向持续学习（Horizontal Continuity）**：在部署后，模型不断吸收新数据、新反馈，沿时间轴持续演化。

### 2.3 灾难性遗忘的机理分析

灾难性遗忘可以从多个角度理解：

**（1）参数空间的干扰**：神经网络的表示由大量共享参数共同决定。当新任务优化损失 $L_t$ 时，参数会朝 $L_t$ 的梯度方向移动。如果某个参数对旧任务 $L_{t'}$ 也很重要，这种移动就会破坏旧任务的决策边界。理论分析表明，在 overparameterized 网络中，参数更新的干扰程度与任务的相似度、优化步长、网络深度和激活函数有关。

**（2）表示漂移（Representation Drift）**：即使最终分类器保持不变，中间层的特征表示也会随新任务漂移。旧任务的分类器假设输入特征来自旧分布，当表示空间改变后，旧分类器就不再适用。很多持续学习方法通过约束中间表示漂移来缓解遗忘，例如 LwF 通过蒸馏保持旧模型输出与新模型输出一致，间接约束表示。

**（3）输出分布偏移（Output Bias）**：在 Class-IL 中，分类器对见过的旧类别和新类别输出不平衡。由于新类别数据更多，模型倾向于预测新类别。这被称为“新类别偏见”（new-class bias）或“分类器偏见”。iCaRL[^6] 通过 nearest-mean-of-exemplars 分类器、BiC 通过偏置校正、EEIL 通过平衡微调来缓解这一问题。

**（4）优化与损失景观**：损失函数的多任务景观通常不是凸的，不同任务的最小值可能相距很远。如果两个任务的最优解在参数空间中冲突，任何单一参数都无法同时达到两者最优。这解释了为什么参数隔离和模块化方法有效：通过为不同任务分配独立子空间，可以避免冲突。

**（5）LLM 的复杂遗忘面**：在 LLM 中，遗忘不仅是分类错误，还可能表现为：事实知识丢失（如忘记了某国首都）、推理能力退化（如数学或代码能力下降）、指令遵循格式变化（如输出不再按要求 JSON）、安全性降低（如更容易生成有害内容）、语言分布偏移（如多语言模型偏向最后训练的语言）以及世界知识一致性破坏（如新旧事实冲突）。这些多维遗忘面使得 LLM 的评估和缓解都比传统 CV 更复杂。

### 2.4 稳定性–可塑性困境

持续学习必须在两个目标之间取得平衡：

- **可塑性（Plasticity）**：模型能够快速学习新知识、适应新分布。可塑性不足会导致模型“僵化”，无法吸收新信息。
- **稳定性（Stability）**：模型保持旧知识的能力。稳定性不足会导致灾难性遗忘。

这一对矛盾被称为稳定性–可塑性困境（Stability-Plasticity Dilemma）。它借鉴自认知科学：人类大脑需要在保持长期记忆（稳定性）和形成新记忆（可塑性）之间取得平衡。在人工系统中，这一困境表现为：

- 大学习率、大容量、低正则化 → 高可塑性、低稳定性。
- 小学习率、强正则化、冻结参数 → 高稳定性、低可塑性。

理想的持续学习方法应该根据任务相似度、重要性、遗忘风险动态调整稳定性和可塑性。例如，当新任务与旧任务高度相关时，可以共享参数并促进迁移；当新任务与旧任务冲突时，应分配独立参数或强正则化。

近年来的研究还发现，除了稳定性–可塑性，还存在**可塑性损失[^7]（Plasticity Loss）**问题：即使在没有明显遗忘的情况下，持续训练的神经网络也可能逐渐失去学习新复杂函数的能力。Kumar 等人提出的 Regenerative Regularization 等方法试图通过保持参数接近初始化来缓解这一问题。在 LLM 持续学习中，可塑性损失意味着模型经过多次更新后，可能难以学习全新的能力或复杂的新任务。

### 2.5 遗忘度量与性能边界

为了量化持续学习效果，研究者提出了多种度量指标。最基本的指标包括：

- **平均准确率（Average Accuracy, Avg.Acc）**：最终模型在所有已见任务上的平均性能。它综合了学习新任务和保持旧任务的能力。
- **遗忘率（Forgetting Rate）**：旧任务在训练新任务后性能下降的平均幅度。定义为 $F_t = \max_{\tau \in [1, t]} a_{\tau, t} - a_{t, T}$，其中 $a_{\tau, t}$ 表示在时刻 $t$ 训练后模型在任务 $\tau$ 上的准确率，$a_{t, T}$ 是最终时刻的准确率。对所有旧任务平均得到总体遗忘率。
- **后向迁移（Backward Transfer, BWT）**：学习新任务后对旧任务性能的影响。BWT 为负表示遗忘，为正表示复习效应。
- **前向迁移（Forward Transfer, FWT）**：旧任务学习对新任务初始性能的促进。高 FWT 表示模型能够利用已有知识加速新任务学习。
- **新任务准确率（New Task Accuracy）**：模型在最新任务上的性能，衡量可塑性。

理论研究表明，在某些严格设定下，不存在同时达到最优稳定性和可塑性的“免费午餐”。例如，在 Class-IL 的强约束下，如果无法存储旧数据或扩展参数，灾难性遗忘是不可避免的。这一理论结果促使研究者通过回放、参数隔离、外部记忆或元学习来绕过这些下界。

### 2.6 知识分解：事实、技能与元能力

为了更精细地理解遗忘，研究者尝试将模型知识分解为不同层次：

- **事实知识（Factual Knowledge）**：具体实体、关系、事件，如“巴黎是法国首都”。这类知识容易被新知识覆盖或冲突。
- **程序性知识 / 技能（Procedural Knowledge / Skills）**：如何完成某类任务，如代码生成、翻译、摘要。技能通常需要大量练习和泛化。
- **元能力（Meta-Capabilities）**：推理、规划、指令遵循、安全性、多语言理解等通用能力。这些能力通常在大规模预训练和对齐中获得，持续学习中最容易受到破坏。
- **分布知识（Distributional Knowledge）**：语言模型对词分布、语法结构、风格的统计知识。持续学习可能改变输出风格或语言分布。

不同知识层次的遗忘机制和缓解策略不同。事实知识可以通过知识编辑或 RAG 更新；技能可以通过 PEFT 模块学习；元能力需要通过回放通用数据或约束关键参数来维持；分布知识则需要 careful 的数据混合和正则化。这种分解为 LLM 持续学习的混合架构提供了理论依据：将不同层次的知识放在不同“存储层”中，分别管理。


## 3. 经典持续学习方法

在进入 LLM 之前，持续学习已在计算机视觉、强化学习和机器人领域形成了一套相对成熟的方法体系。这些方法大致可分为正则化、回放、架构隔离、元学习、贝叶斯方法和压缩蒸馏等。理解它们，对于把握 LLM 持续学习的发展脉络至关重要，因为许多 LLM 方法本质上是对这些经典思想的扩展或重新实现。

### 3.1 正则化方法

正则化方法（Regularization-based Methods）通过修改损失函数或优化目标，约束参数更新，使其不破坏旧知识。其优点是不需要存储旧数据，也不改变模型架构，易于实现；缺点是在强任务冲突或长序列下稳定性有限。

#### 3.1.1 弹性权重巩固（EWC）

Kirkpatrick 等人 2017 年提出的 EWC[^8] 是持续学习中最具影响力的方法之一。它假设每个任务的后验 $p(\theta | D_t)$ 可以用高斯分布近似，均值为训练完该任务后的参数 $\theta_t^*$，精度矩阵为 Fisher 信息矩阵 $F_t$。在第 $t+1$ 个任务训练时，EWC 在损失中加入二次惩罚项：

$$L_{EWC}(\theta) = L_{t+1}(\theta) + \frac{\lambda}{2} \sum_i F_{t,i} (\theta_i - \theta_{t,i}^*)^2$$

其中 $F_{t,i}$ 衡量参数 $i$ 对旧任务的重要性。重要性高的参数被强烈约束，重要性低的参数可以自由更新。Fisher 信息可以通过旧任务数据上梯度的二阶矩估计，无需显式海森矩阵。EWC 的理论基础是拉普拉斯近似下的序列贝叶斯推断。

EWC 的局限在于：高斯后验近似对深度网络较粗糙；Fisher 估计需要旧任务数据计算；当任务数量增多时，二次惩罚项会累积，导致优化困难；对于复杂任务冲突，单一二次约束不足以保持性能。

#### 3.1.2 Synaptic Intelligence（SI）

Zenke 等人提出的 SI[^9] 同样基于参数重要性，但不需要二阶信息。它通过追踪每个参数在训练过程中对损失下降的贡献，估计其重要性。重要性估计在训练过程中在线累积，因此比 EWC 更节省计算。SI 在路径积分框架下为每个参数分配“突触强度”，损失惩罚形式与 EWC 类似，但重要性计算更简单。它在中小规模网络上表现良好，但在 LLM 中由于参数众多、贡献复杂，重要性估计仍面临挑战。

#### 3.1.3 学习不遗忘（LwF）

Li 与 Hoiem 提出的 Learning without Forgetting[^10]（LwF）不存储旧数据，也不使用参数重要性。它在新任务训练时，对旧任务输入的新任务数据，通过知识蒸馏保留旧模型输出。损失函数为：

$$L_{LwF}(\theta) = L_{t+1}(\theta) + \lambda \sum_{k} - p_{t,k}(x) \log p_{\theta,k}(x)$$

其中 $p_t$ 是旧模型输出，$p_{\theta}$ 是当前模型输出。LwF 的核心思想是：即使新任务数据与旧任务不同，也可以在新任务输入上蒸馏旧模型的输出分布，从而保持旧任务的决策边界。LwF 不需要旧任务数据，但要求旧模型可用；且当新旧任务输入分布差异较大时，蒸馏信号可能不足。

#### 3.1.4 其他正则化方法

- **Less-Forgetful Learning（LFL）**：通过约束中间层特征不变来缓解表示漂移。
- **Aljundi 等人的 A-GEM[^11] 前身**：通过梯度投影约束更新方向不增加旧任务损失（GEM 属于回放方法，但思想与正则化相关）。
- **Friedlander 等人、Nguyen 等人的变分正则化**：从贝叶斯角度引入更多正则化项。
- **Dropout-based / Plasticity Loss**：通过 dropout 或再生正则化维持可塑性。

正则化方法在 LLM 中常被用作辅助组件，例如与 PEFT 结合形成 CLoRA，或在数据混合中作为轻量约束。

### 3.2 回放方法

回放方法（Replay-based Methods）通过保留或生成旧任务数据，在新任务训练时混合旧数据，从而直接缓解遗忘。它是目前工业应用中最实用的方法之一，因为简单、有效且易于理解。主要缺点是存储成本、隐私风险和合规问题。

#### 3.2.1 经验回放（Experience Replay）

经验回放是最直接的回放方法：维护一个固定大小的记忆缓冲区（memory buffer），保存旧任务的代表性样本。训练新任务时，从缓冲区中采样一定比例样本与当前数据混合。Rolnick 等人 2019 年的工作[^12]从理论上和经验上证明，即使是很小的缓冲区，也能显著缓解灾难性遗忘。缓冲区的样本选择策略包括：

- **随机采样**：简单，但可能错过重要样本。
- **herding 选择**：iCaRL 中使用的贪心选择，使样本均值接近真实类别均值。
- **困难样本选择**：选择旧模型目前预测最差的样本（maximally interfered retrieval）。
- **多样性选择**：选择覆盖特征空间不同区域的样本。
- **最近样本选择**：选择接近当前任务边界的样本，以缓解分布冲突。

在 LLM 中，经验回放通常表现为“通用能力保持数据”的混合：在领域持续预训练或指令微调时，混入一定比例的高质量通用数据、对齐数据或安全数据，防止通用能力退化。

#### 3.2.2 生成回放（Generative Replay）

当无法存储旧数据时，可以使用生成模型合成旧任务样本。Shin 等人 2017 年提出的 Deep Generative Replay[^13] 使用生成对抗网络（GAN）或变分自编码器（VAE）学习每个任务的数据分布，然后生成伪样本供新任务训练。生成回放避免了隐私问题，但生成模型本身也需要持续学习，可能随任务增多而退化。在 LLM 中，生成回放可以通过大模型自己生成旧任务风格的指令-输出对，或用“自我指导”（Self-Instruct[^14]）方式合成数据。然而，生成数据的质量和多样性直接影响回放效果，低质量生成可能引入错误信号。

#### 3.2.3 特征回放与嵌入回放

为了降低存储成本，可以只存储旧样本的隐藏特征（feature replay）而不是原始数据。特征回放压缩了信息量，但失去了重新编码、数据增强和错误分析的能力。在视觉中，特征回放需要存储旧模型某一层的激活，并在新训练时作为旧任务监督信号。在 LLM 中，可以存储旧样本的 key-value 缓存、注意力模式或嵌入向量，作为回放或蒸馏的基础。特征回放与“知识蒸馏”和“记忆增强网络”密切相关。

#### 3.2.4 梯度 episodic 记忆（GEM / A-GEM）

Lopez-Paz 与 Ranzato 提出的 Gradient Episodic Memory[^15]（GEM）存储少量旧任务样本，并在优化时约束梯度方向不增加这些旧样本的损失。其优化问题为：

$$\min_{g} \frac{1}{2} \| g - g_{new} \|^2 \quad \text{s.t.} \quad g^T g_{old,k} \geq 0 \quad \forall k$$

即新梯度 $g$ 在所有旧任务样本梯度 $g_{old,k}$ 上的投影非负。A-GEM（Average GEM）是其高效版本，只使用一个平均梯度约束，计算更简单。GEM/A-GEM 被证明在 Class-IL 中非常有效，但需要存储旧样本，且梯度投影在长序列中可能变得保守，限制可塑性。

### 3.3 架构隔离与参数隔离方法

架构方法（Architecture-based Methods）通过为不同任务分配独立参数或子网络，从根本上避免参数冲突。优点是稳定性强，缺点是可能随任务数量增长参数量，部署复杂。

#### 3.3.1 Progressive Neural Networks[^16]（PNN）

Rusu 等人 2016 年提出的 Progressive Neural Networks 为每个任务新增一列网络，并通过侧向连接（lateral connections）复用之前任务列的特征。新任务列使用旧列的固定输出作为输入，从而在学习新任务时不会破坏旧任务参数。PNN 的稳定性极佳，但每新增一个任务就要增加一列，参数量随任务线性增长，不适合长序列或 LLM。

#### 3.3.2 PackNet 与 HAT[^17]

PackNet 通过网络剪枝为每个任务分配固定网络中的不同子集，实现“在固定容量内隔离”。HAT（Hard Attention to Task）为每个任务学习一个神经元掩码，训练时只更新被掩码激活的参数，测试时根据任务身份应用对应掩码。这些方法在固定网络容量下实现参数隔离，但通常需要任务身份。

#### 3.3.3 动态可扩展网络

Yoon 等人提出的 Dynamically Expandable Networks[^18]（DEN）根据任务需要动态扩展网络容量，并允许通过稀疏正则化控制增长。类似的还有 Reinforced Continual Learning（RCL）等。这些方法试图在稳定性与参数效率之间取得平衡，但动态扩展的决策和容量分配仍是难点。

#### 3.3.4 在 LLM 中的延伸

在 LLM 中，参数隔离的思路发展为：为每个任务或领域添加 PEFT 模块（如 LoRA 适配器），并可能通过路由机制选择模块。由于 PEFT 模块参数量小，线性增长带来的开销可控。模块化与 MoE 方法也继承了参数隔离的思想，但扩展为更动态、更稀疏的架构。

### 3.4 元学习与动态优化方法

元学习（Meta-Learning）方法试图让模型“学会学习”，即找到一组初始参数，使得在序列任务上微调时既能快速适应又能减少遗忘。

#### 3.4.1 MAML[^19] 与 FOMAML 在持续学习中的应用

Model-Agnostic Meta-Learning（MAML）通过二阶梯度优化初始参数，使模型在少量梯度步内适应新任务。在持续学习中，可以将每个任务视为元学习的一个 episode，目标是使模型在序列任务上都能快速适应。然而，MAML 本身并不直接解决遗忘问题，需要结合正则化或记忆机制。Javed 与 White 的 Meta-Consolidation[^20]（MC-SGD）等方法通过元学习优化学习率或更新方向，以控制遗忘。

#### 3.4.2 动态学习率与方法级优化

一些方法根据任务相似度、梯度冲突或损失曲率动态调整优化参数。例如，通过梯度对齐度量判断新任务与哪些旧任务冲突，从而调整学习率或正则化强度。动态优化方法在任务边界清晰时有效，但在无任务边界设定中面临挑战。

#### 3.4.3 优化器级别的可塑性保持

近期研究关注持续学习中的“可塑性损失”问题：即使没有明显遗忘，模型长期训练后学习复杂新函数的能力也会下降。Kumar 等人提出的 Regenerative Regularization 通过正则化参数保持接近初始化，来维持可塑性。L2Init 等变体约束参数接近初始值而非零。在 LLM 中，保持可塑性对于持续学习新能力（如新的推理技巧、新的工具模式）至关重要。

### 3.5 贝叶斯持续学习

贝叶斯方法将持续学习视为序列后验推断。通过维护参数分布而不是点估计，贝叶斯方法天然能够表示不确定性并缓解遗忘。

#### 3.5.1 变分持续学习（VCL）

Nguyen 等人提出的 Variational Continual Learning[^21]（VCL）使用变分推断近似后验 $q_t(\theta)$。在每个新任务后，通过证据下界（ELBO）更新后验。VCL 可以结合核心集（core-set）提高性能。其优点是有清晰概率解释，能估计不确定性；缺点是变分近似在深度网络中计算复杂，难以扩展到 LLM。

#### 3.5.2 在线拉普拉斯近似

Ritter 等人提出的 Online Laplace Approximation[^22] 通过在线更新 Fisher 信息矩阵或 Kronecker 分解近似（如 KFAC）来维护参数后验。这些方法比 VCL 计算更高效，是 EWC 的贝叶斯扩展。在 LLM 中，由于参数规模巨大，精确拉普拉斯近似仍然困难，但低秩近似或子集参数近似可能是可行方向。

#### 3.5.3 功能正则化与贝叶斯神经网络

功能正则化（Functional Regularization）直接在函数空间而不是参数空间约束模型，例如通过高斯过程后验或神经正切核[^23]（NTK）分析。这些理论工具帮助理解遗忘的极限：在无限宽网络中，神经正切核近似可以显式计算持续学习的最优解和遗忘程度，为方法设计提供指导。

### 3.6 压缩、蒸馏与知识转移

除了直接约束参数或回放数据，知识转移（Knowledge Transfer）通过在不同模型或不同任务之间传递信息来缓解遗忘。

#### 3.6.1 知识蒸馏

知识蒸馏通过让新模型模仿旧模型的输出分布，将旧知识迁移到新模型。在持续学习中，LwF 就是一种蒸馏。更一般地，可以蒸馏旧模型在中间层的特征、注意力分布或关系知识。多教师蒸馏（Multi-Teacher Distillation）在多个旧模型上蒸馏，适用于长序列。

#### 3.6.2 模型压缩与剪枝

PackNet 等压缩方法在持续学习中为任务分配稀疏子网络。剪枝不仅为任务隔离参数，还能减少模型规模。在 LLM 中，压缩与量化技术也用于降低持续学习后的部署成本，但压缩本身可能加剧遗忘，需要谨慎结合。

#### 3.6.3 模型合并与权重插值

模型合并（Model Merging）通过平均或插值多个任务微调的模型权重来组合知识。Simple Averaging、Task Arithmetic、TIES-Merging、DARE 等方法在 LLM 中越来越受到关注，因为它们无需训练就能合并多个 specialist 模型。然而，模型合并对冲突任务效果有限，且合并后的模型可能无法继续学习。它更多用于多任务组合而非长序列持续学习。

### 3.7 经典方法的局限与向 LLM 的过渡

经典方法在小规模 CV 任务上取得了显著进展，但在 LLM 时代面临共同局限：

- **规模**：全参数正则化、拉普拉斯近似、PNN 等难以扩展到数十亿参数。
- **无任务边界**：大多数方法假设任务身份已知，难以直接用于 task-free LLM 数据流。
- **通用能力保持**：传统方法只关注任务准确率，不关注 LLM 的通用推理、安全、对齐等能力。
- **数据隐私**：回放方法需要存储旧数据，与隐私合规冲突。
- **评估单一**：传统评估以分类准确率为主，不足以刻画 LLM 多维能力。

因此，LLM 时代的持续学习需要新的方法：参数高效微调、模块化专家、数据混合与回放、知识编辑、RAG、遗忘诊断、多模态扩展等。这些新方法在后续章节中详细展开。


## 4. 大语言模型的持续预训练

持续预训练（Continual Pre-training, CPT）指在已有基础模型之上，继续使用新的无标注或弱标注文本语料进行下一个 token 预测训练。它是 LLM 生命周期中最早出现的持续学习形式之一，主要用于领域适应和知识更新。

### 4.1 持续预训练的目标与应用场景

持续预训练通常有几个目标：

- **领域适应**：让通用预训练模型吸收医学、法律、科学、金融等专业领域的语料，形成领域基础模型（Domain Foundation Models）。例如，PubMedBERT、BioBERT、SciBERT、Galactica 等都是领域预训练的代表。
- **时间适应**：让模型知识保持最新。新闻、社交媒体、科学论文、代码仓库等数据随时间不断更新，持续预训练可以使模型吸收最新语言用法、新实体和新事实。
- **语言扩展**：扩展模型对新语言或低资源语言的支持。例如，在通用多语言模型基础上持续预训练特定语言的维基百科和社交媒体数据。
- **能力预训练**：为后续特定能力（如长上下文、代码、推理）做数据准备。

### 4.2 数据构建与选择

持续预训练的效果高度依赖于数据质量和选择策略。Xie 等人 2024 年的工作[^24]强调，构建领域专用 LLM 时，数据选择、去重、清洗和混合比例比简单增加训练步数更重要。关键问题包括：

- **领域相关性**：应优先选择与目标领域高度相关的数据，避免无关数据稀释模型能力。
- **新旧数据比例**：为防止通用能力遗忘，通常需要混合一定比例的高质量通用数据。这一比例称为“回放比例”或“混合比例”。
- **数据去重与质量过滤**：新语料可能与预训练语料重复，需要去重以避免过拟合；低质量、有毒或偏见数据需要过滤。
- **数据顺序**：当多个领域按顺序到来时，学习顺序会影响最终性能。相似领域连续学习通常比差异大的领域交替学习更容易。

### 4.3 学习率调度和优化策略

持续预训练的学习率调度是一个关键但常被忽视的问题。Gupta 等人研究了如何为持续预训练“重新预热”（rewarm）学习率调度，以避免模型陷入局部最优或破坏已有知识。常见策略包括：

- **线性预热 + 余弦衰减**：与预训练类似，但需要根据数据规模调整峰值学习率。
- **低学习率微调**：使用比预训练低 1-2 个数量级的学习率，减少对通用知识的破坏。
- **分层学习率**：对底层（语法、通用表示）使用更低学习率，对上层（语义、领域知识）使用更高学习率。
- **Curriculum Learning**：按难度或时间顺序组织数据，使模型逐步适应新领域。

### 4.4 遗忘现象与缓解

Yıldız 等人 2024 年的研究[^25]发现，不同模型族在持续预训练中的遗忘行为差异显著：一些模型在持续预训练后持续改进，另一些则出现通用能力退化。Li 与 Lee[^26] 的工作进一步指出，在已对齐 LLM 上进行持续预训练可能破坏对齐行为和安全边界。缓解策略包括：

- **通用数据回放**：在领域数据中混入通用预训练语料，维持通用能力。
- **对齐数据回放**：对于已对齐模型，混入 SFT/RLHF 数据以保持指令遵循和安全性。
- **正则化约束**：对关键参数施加 EWC 或 L2 约束，减少偏离。
- **早停与验证**：在通用基准上监控性能，及时停止训练。

### 4.5 预训练与后训练的边界

持续预训练通常发生在后训练之前，但现代 LLM 开发流程中，预训练、SFT、对齐之间的边界越来越模糊。一些实践者在 SFT 阶段继续使用无标注领域数据，或在 RLHF 阶段混入领域语料。理解持续预训练如何影响后续 SFT 和对齐，是一个重要研究方向。例如，过度领域化的预训练可能导致模型输出风格偏离人类偏好，从而增加后续对齐难度。

### 4.6 大规模持续预训练的系统挑战

持续预训练需要大量计算资源。系统层面需要考虑：

- **分布式训练**：数据并行、模型并行、流水线并行的组合。
- **检查点与恢复**：频繁保存检查点，以便在训练失败或效果不佳时回滚。
- **数据管道**：高效的数据加载、预处理、去重和 shuffle。
- **混合精度与显存优化**：使用 BF16/FP8、梯度检查点、ZeRO 优化器等。
- **评估基础设施**：在训练过程中定期评估通用基准、领域基准和安全基准。

## 5. 持续指令微调与对齐

持续指令微调（Continual Instruction Tuning, CIT）是 LLM 持续学习中最活跃的研究方向。与持续预训练不同，CIT 面对的是指令-输出对数据，目标是让模型学会遵循新指令，同时保持旧指令能力、通用推理和安全对齐。

### 5.1 持续指令微调的问题设定

在 CIT 中，模型依次接收来自不同领域、能力或任务的指令数据集 $D_1, D_2, \dots, D_T$。每个数据集包含指令 $x$、输入上下文（可选）和期望输出 $y$。训练目标通常是监督学习下的交叉熵损失：

$$L_{SFT}(\theta) = - \sum_{(x,y) \in D_t} \sum_{j} \log p_{\theta}(y_j | x, y_{<j})$$

朴素的顺序 SFT 会导致严重遗忘。例如，TRACE[^27] 基准显示，在持续指令微调后，Llama-2-Chat-13B 在 GSM8K 上的准确率从 28.8% 降到 2%，展示了通用能力崩溃的风险。

### 5.2 对齐税与安全性遗忘

经过 RLHF 或 DPO 对齐的 LLM 具有安全拒绝、帮助性和真实性。持续微调可能破坏这些对齐属性，称为“对齐税”。Fernando 等人 2024 年的工作[^28]发现，顺序进行 SFT 和 DPO 会导致通用能力和旧偏好的双重遗忘。安全能力的遗忘尤其危险：模型可能在吸收新领域数据后更容易生成有害内容、越狱或偏见输出。因此，CIT 不仅要维持任务性能，还要维持对齐行为。

### 5.3 数据混合与回放策略

与持续预训练类似，CIT 中最实用的方法是数据混合和回放：

- **领域数据 + 通用指令数据混合**：在每个新任务训练中，混合一定比例的高质量通用指令数据（如 Alpaca、Dolly、FLAN、Self-Instruct）。
- **安全数据回放**：混入安全对齐数据，维持拒绝有害请求的能力。
- **多任务联合训练（Multi-task Joint Training）**：如果所有任务数据可同时获得，联合训练通常是最好的上界。CIT 方法试图接近这一上界。
- **任务排序**：相似任务连续学习、冲突任务分散学习，可以减少干扰。
- **数据重采样**：对旧任务数据按重要性或遗忘程度加权采样。

### 5.4 持续对齐：RLHF 与 DPO 序列

在持续对齐中，模型需要根据新的偏好数据更新奖励模型和策略。DPO 由于其简单性，在持续对齐中越来越受到关注。然而，DPO 序列训练也会遗忘旧偏好。缓解方法包括：

- **偏好数据回放**：存储旧偏好对，与新偏好数据混合。
- **约束策略更新**：使用 TRPO/PPO 的 KL 约束，限制新策略偏离旧策略太远。
- **正则化奖励模型**：在奖励模型更新中加入正则化，保持对旧偏好的识别能力。
- **多目标优化**：同时优化帮助性、安全性、真实性和旧偏好，使用多目标 RL。

### 5.5 持续指令微调的代表性基准

CIBT[^29] 基准（Zhang 等人，EMNLP 2023 Findings）是面向持续指令微调的代表性基准，包含多个按顺序到来的指令任务，用于评估遗忘和迁移。TRACE 基准虽然也涉及指令微调，但更强调对齐后 LLM 的综合能力保持。Long Sequence Benchmarks 和 Continual-News 也可用于评估指令级持续学习。

### 5.6 持续微调与涌现能力

一个有趣的问题是：持续指令微调能否让 LLM 获得全新的涌现能力？理论上，如果新指令数据覆盖以前未见过的复杂推理模式或工具使用，模型可以逐步习得。然而，实证研究表明，新能力的获得往往伴随着旧能力的退化，除非有 careful 的数据混合和参数隔离。因此，CIT 的设计需要在“能力扩展”和“能力保持”之间精细权衡。


## 6. 参数高效持续学习

由于 LLM 全量微调成本极高，参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）成为持续学习的主流基座。PEFT 只更新少量参数（如低秩矩阵、适配器、提示嵌入），同时保持大部分预训练参数冻结。在持续学习中，PEFT 不仅降低成本，还能通过隔离不同任务的参数更新来缓解遗忘。

### 6.1 LoRA 与持续学习

LoRA（Low-Rank Adaptation）由 Hu 等人 2022 年提出[^30]，通过在冻结权重旁注入低秩矩阵 $A$ 和 $B$ 来近似权重更新 $W' = W_0 + BA$。在持续学习中，每个任务可以学习独立的 LoRA 模块，实现参数隔离。常见策略包括：

- **每任务 LoRA（Per-Task LoRA）**：为每个任务训练一个 LoRA 模块，推理时根据任务身份选择。
- **LoRA 回放（LoRA Replay）**：在训练新 LoRA 时，同时加载旧 LoRA 模块并混合输出。
- **正交 LoRA 子空间（O-LoRA）**：Wang 等人 2023 年提出的 Orthogonal Subspace Learning[^31] 为每个任务学习正交低秩子空间，减少任务间参数干扰。
- **双 LoRA 记忆（I-LoRA[^32]）**：Li 等人 2025 年提出的 I-LoRA 维护快慢两个 LoRA 适配器，分别对应短期可塑性和长期记忆。
- **对抗 MoE-CL[^33]**：Kang 等人 2025 年的 MoE-CL 使用专用 LoRA 专家保存任务知识，共享 LoRA 专家促进迁移，并通过对抗判别器选择信息路径。

### 6.2 Adapter 与 Prefix/Prompt Tuning

- **Adapter**：在 Transformer 子层之间插入小型瓶颈网络（下投影 + 上投影）。每个任务可以训练独立 Adapter，推理时切换。AdapterCL 等早期工作就将 Adapter 用于持续学习。
- **Prefix Tuning / Prompt Tuning**：在输入前添加可学习的连续 token 嵌入（soft prompts）。不同任务使用不同前缀，实现参数隔离。Prompt Tuning 参数更少，但能力也较弱，对于复杂任务可能不足。
- **P-Tuning v2 / L2P / DualPrompt[^34]**：在多层添加可学习提示，并通过提示池或键值匹配自动选择。Wang 等人 2022 年提出的 Learning to Prompt[^35]（L2P）和 DualPrompt 通过实例级提示选择实现 task-free 持续学习。Progressive Prompts[^36] 进一步扩展为渐进式提示序列。

### 6.3 参数选择与子空间方法

- **SATP**：Zhao 等人 2024 年提出的 SAPT[^37] 通过共享注意力模块学习并选择参数高效块，实现跨任务共享注意力。
- **LoRAMoE[^38]**：Dou 等人 2024 年提出在冻结主干上引入 MoE 风格的 LoRA 适配器，通过路由选择专家，以缓解世界知识遗忘。
- **Subspace-based CL**：一些方法在固定参数子空间内学习，确保新任务更新不干扰旧任务。正交约束、Grassmann 流形优化、稀疏子空间选择等都属于此类。

### 6.4 PEFT 持续学习的优势与局限

优势：
- 计算和存储成本低，可训练参数量通常不到总参数的 1%。
- 不同任务可以拥有独立参数，天然支持参数隔离。
- 原始模型被冻结，通用能力相对安全。
- 易于部署：可以只加载当前任务需要的 LoRA/Adapter。

局限：
- 容量有限，对于需要大规模新知识注入的场景可能不足。
- 当任务数量很多时，管理大量 LoRA 模块变得复杂。
- 任务选择需要任务身份或路由机制，在 task-free 设定中不易实现。
- 不同 PEFT 模块之间可能冲突，需要 careful 的正则化或路由。

### 6.5 PEFT 与全参数更新的混合策略

实践中，往往会混合使用 PEFT 和全参数更新：
- 对于领域知识更新，使用全参数或较大秩 LoRA。
- 对于特定技能学习，使用小秩 LoRA 或 Adapter。
- 对于通用能力保持，冻结主干，仅通过数据回放维持。
- 对于关键能力（如安全、推理），使用强正则化或专用模块保护。

## 7. 记忆与回放机制

记忆（Memory）和回放（Replay）是持续学习中最直接、最广泛使用的策略。在 LLM 中，回放不仅涉及原始数据，还可以是特征、嵌入、关键值缓存、生成样本等多种形式。

### 7.1 经验回放的组织形式

经验回放（Experience Replay）维护一个记忆缓冲区，存储历史样本。在 LLM 持续学习中，缓冲区的组织形式包括：

- **原始样本缓冲**：存储原始指令-输出对。最直观，但存储和隐私成本高。
- **压缩样本缓冲**：存储压缩后的文本或摘要，减少存储。
- **特征缓冲**：存储样本在模型某一层的隐藏表示。
- **嵌入缓冲**：存储文本嵌入向量，用于相似度检索。
- **KV 缓存缓冲**：存储 Transformer 的 key-value 缓存，用于快速回忆。

### 7.2 样本选择策略

选择哪些样本放入缓冲区对回放效果至关重要：

- **随机选择**：基线，简单但可能遗漏关键信息。
- **herding 选择**：iCaRL 使用贪心算法，选择使缓冲区样本均值接近真实类别均值的样本。
- **最大化干扰检索（Maximally Interfered Retrieval）**：选择那些新模型预测最差或损失最高的旧样本，优先复习易忘样本。
- **多样性选择**：使用聚类或覆盖算法，确保缓冲区覆盖不同子分布。
- **不确定性选择**：选择模型最不确定的样本，以提高信息增益。
- **时间加权选择**：越近的样本越重要，适用于时间漂移场景。

### 7.3 生成回放与自我指导

当无法存储旧数据时，可以用生成模型合成样本。在 LLM 中，常用方法包括：

- **Self-Instruct**：模型根据种子指令生成新的指令-输出对，扩展指令数据。
- **逆向生成（Back-translation / Inverse Prompting）**：从输出生成输入指令，增加多样性。
- **记忆激发生成**：使用旧任务的关键词或提示，引导模型生成旧任务风格的样本。
- **蒸馏生成**：用旧模型在新输入上生成软标签，作为回放信号。

生成回放的质量取决于生成模型的能力。LLM 本身可以生成高质量数据，但也可能产生幻觉、偏见或重复，需要过滤和验证。

### 7.4 特征回放与表示保持

特征回放只存储旧样本的中间特征，而不是原始数据。其优点包括：
- 隐私保护：原始输入不可见。
- 存储高效：特征向量通常比原始文本更紧凑。
- 可直接用于蒸馏或正则化。

挑战在于：
- 模型表示会随训练漂移，旧特征与新模型的特征空间可能不一致。
- 无法利用数据增强，因为原始数据不可见。
- 难以用于生成任务，因为缺少原始文本。

### 7.5 记忆增强网络

记忆增强网络（Memory-Augmented Networks）在模型外部维护可读写记忆模块，如 Neural Turing Machine、Memory Networks、Differentiable Neural Computer 等。在持续学习中，这些结构可以存储和检索旧任务信息，但训练难度较大。近年来，基于 key-value 记忆、可学习检索索引和外部向量数据库的工作重新受到关注，尤其是在 LLM + RAG 的框架下。

### 7.6 回放的比例、调度与理论

回放的效果与混合比例密切相关。比例过低无法缓解遗忘，比例过高会减慢新任务学习。常见做法：
- **固定比例**：如新旧数据 1:1 或 1:3。
- **动态比例**：根据遗忘程度或任务难度调整。
- **课程调度**：先多回放旧数据，再逐渐减少。
- **重要性采样**：对旧样本按遗忘风险或信息增益加权。

理论分析表明，经验回放可以被视为对联合训练目标的近似：通过有限样本估计历史分布的期望。缓冲区大小与遗忘率之间存在权衡：更大的缓冲区通常带来更低的遗忘，但成本更高。

### 7.7 回放与隐私、合规

在 LLM 部署中，回放面临隐私和合规挑战：
- **数据最小化**：不应长期存储不必要的用户数据。
- **可遗忘权（Right to be Forgotten）**：用户要求删除数据时，模型需要“取消学习”相关影响。
- **差分隐私[^39]**：对回放数据添加噪声或限制查询，保护隐私。
- **合规审计**：需要记录哪些数据被用于训练，以便审计。

这些约束推动了特征回放、生成回放、差分隐私持续学习和机器遗忘[^40]（Machine Unlearning）等方向的研究。


## 8. 模块化、专家模型与混合专家系统

模块化和混合专家（Mixture-of-Experts, MoE）方法通过将模型能力分解为多个可独立更新和选择的组件，从根本上避免参数冲突。在 LLM 中，这一思路尤为重要，因为它既支持持续学习，又支持高效推理和可解释性。

### 8.1 模块化神经网络的动机

模块化神经网络（Modular Neural Networks）的动机来自认知科学：人脑由功能相对独立的模块组成，不同模块负责不同功能，模块之间通过路由机制协同。模块化系统的优点包括：
- **可扩展性**：新增能力只需添加新模块，不必重写整个网络。
- **可解释性**：可以追踪哪个模块被激活，理解模型决策。
- **鲁棒性**：一个模块的损坏或退化不一定影响其他模块。
- **组合性**：不同模块可以组合，形成新的能力。
- **持续学习友好**：可以隔离新旧知识，减少灾难性遗忘。

### 8.2 混合专家（MoE）基础

MoE 由门控网络（gating network）和多个专家网络（experts）组成。输入 $x$ 经过门控网络得到专家权重，输出为专家输出的加权组合：

$$y = \sum_{i=1}^{N} g_i(x) f_i(x)$$

其中 $g_i(x)$ 是门控权重，$f_i$ 是专家。稀疏 MoE（如 Switch Transformer、GShard）只激活少量专家，从而在扩大模型容量的同时保持计算成本可控。Shazeer 等人 2017 年的稀疏门控 MoE 是这一方向的开创性工作。

### 8.3 MoE 在持续学习中的应用

在持续学习中，MoE 可以通过以下方式应用：
- **每个任务一个专家**：为每个新任务添加新专家，旧专家冻结。这类似于 Progressive Neural Networks，但专家更稀疏。
- **基于梯度的专家分配**：根据任务梯度或损失自动决定是否需要新专家。
- **终身 MoE**：专家数量随时间动态增长，并通过合并或剪枝控制规模。
- **MoE + LoRA**：每个专家是一个 LoRA 模块，门控网络选择激活哪些 LoRA。

代表性工作包括：
- **LIMoE[^41]**：Mustafa 等人 2022 年的多模态 MoE，为视觉-语言任务设计。
- **MoLE-CIE[^42]**：Liu 等人 2025 年的面向信息抽取的持续学习 LoRA 专家系统。
- **MoE-CL**：Kang 等人 2025 年用于工业级持续指令微调，结合专用专家、共享专家和对抗判别器。
- **Mixtures of SubExperts[^43]（MoSE）**：将能力分解为可复用、可组合的子专家，实现模块化持续学习。

### 8.4 路由机制的设计

路由机制是 MoE 持续学习的核心。常见路由策略：
- **任务身份路由**：已知任务时直接选择对应专家。最简单，但不适合 task-free。
- **输入依赖路由**：门控网络根据输入动态选择专家。更灵活，但需要门控网络学到合理的分配。
- **双层路由**：先选“模块族”，再选具体专家，提高组合性。
- **记忆辅助路由**：结合外部记忆检索，决定哪些专家应该参与。
- **硬路由与软路由**：硬路由只激活一个专家，效率高但梯度稀疏；软路由激活多个专家，训练更稳定但计算成本高。

路由机制的可学习性直接影响持续学习效果。如果新任务与旧任务分布差异大，门控网络可能需要调整；但调整门控网络又可能破坏旧任务的路由模式。

### 8.5 专家增长、合并与剪枝

长序列持续学习中，专家数量会无限增长。需要机制控制规模：
- **专家增长**：当新任务与现有专家分布差异足够大时，添加新专家。
- **专家合并**：将相似专家合并，减少数量。合并方法包括权重平均、聚类、任务相似度度量。
- **专家剪枝**：移除使用频率低或贡献小的专家。
- **分层专家组织**：将专家组织成树或图结构，支持高效检索和组合。

### 8.6 模块化与可解释性

模块化系统的可解释性是其重要优势。通过分析哪些专家被激活、专家之间的共现关系、专家随时间的演化，可以诊断模型的遗忘、偏见和知识组织。例如，可以发现某个专家专门负责代码、某个负责医学、某个负责多语言。在持续学习中，这种结构化的知识表示有助于审计、调试和知识管理。

### 8.7 模块化系统的局限

- **路由稀疏性与负载均衡**：稀疏 MoE 需要 careful 设计负载均衡损失，避免少数专家过载。
- **专家碎片化**：专家可能过度特化，导致泛化能力下降。
- **训练不稳定性**：门控网络和专家网络联合训练容易不稳定。
- **任务身份依赖**：许多方法仍需要任务身份或提示来选择专家，限制了 task-free 应用。
- **部署复杂性**：需要动态加载和路由专家，增加服务架构复杂度。

## 9. 知识编辑与终身知识编辑

知识编辑（Knowledge Editing, KE）是一种局部更新模型中特定知识的技术，与持续学习密切相关。虽然传统持续学习关注能力分布的保持，知识编辑关注具体事实的修改，但两者在实践中日益融合：LLM 需要持续更新大量事实，而事实更新可以被视为持续学习的一个特例。

### 9.1 知识编辑的问题设定

知识编辑的目标是：给定一个事实三元组（主体、关系、客体）或一个事实陈述，修改模型使其在相关查询上输出更新后的知识，同时不影响无关知识。例如：
- 旧知识：“英国首相是鲍里斯·约翰逊。”
- 新事实：“英国首相是里希·苏纳克。”
- 编辑后：模型回答相关问题时输出新首相，且对“法国总统是谁”等无关问题不受影响。

### 9.2 知识编辑方法分类

Wang 等人 2024 年的综述将知识编辑方法分为三类：

- **基于外部记忆的方法**：在模型外维护一个编辑记录或补丁，推理时检索并应用。例如 SERAC、IKE 等。优点是模型权重不变，可撤销；缺点是推理时需要额外检索开销。
- **基于元学习的方法**：学习一个编辑网络或 hypernetwork，将事实编辑映射为模型参数更新。例如 MEND、KE 等。训练编辑网络需要大量编辑数据。
- **基于定位-编辑的方法**：定位存储事实的特定神经元或层，然后进行局部修改。例如 ROME[^44]、MEMIT[^45]、Transformer-Patcher[^46]、GRACE[^47]、DAFNet[^48] 等。

### 9.3 定位-编辑方法

定位-编辑方法的核心假设是：事实知识主要存储在 Transformer 的前馈网络（FFN）层的特定神经元中，尤其是中间层。

- **ROME（Rank-One Model Editing）**：通过秩一更新修改特定 FFN 层的键值，编辑事实关系。它假设 FFN 层可解释为 key-value 记忆。
- **MEMIT**：ROME 的多事实扩展，支持批量编辑。
- **Transformer-Patcher**：为每个错误添加一个专用神经元，仅在检测到相似输入时激活。
- **GRACE**：使用可学习的 key-value codebook，根据输入与历史错误的相似度替换激活。
- **DAFNet**：通过注意力流融合多次编辑，防止编辑冲突和遗忘。

### 9.4 终身知识编辑的挑战

终身知识编辑（Lifelong Knowledge Editing）要求模型能够持续接受大量顺序编辑，而不破坏之前编辑的效果和无关知识。Zhang 等人 2025 年的 WikiBigEdit[^49] 研究发现，现有编辑方法在大量连续编辑下面临稳定性与泛化限制。主要挑战包括：
- **编辑冲突**：多个事实编辑可能涉及共享参数或概念，产生冲突。
- **编辑传播**：修改一个事实可能意外影响相关事实（如“英国首相”的编辑可能影响“英国政府”相关问题）。
- **编辑遗忘**：后续编辑可能覆盖之前的编辑。
- **泛化不足**：编辑只在训练查询上有效，对措辞变化或推理链查询无效。
- **副作用**：编辑可能破坏模型的语言流畅性、安全性或通用知识。

### 9.5 WISE[^50] 与知识记忆

Wang 等人 2024 年提出的 WISE 通过重新设计“知识记忆”机制，试图在支持新编辑的同时保留旧知识。其核心思想是将模型知识分为“预训练知识”（应保护）和“编辑知识”（可更新），并通过双层存储或门控机制实现区分。类似地，一些方法尝试将编辑存储为 LoRA 模块或 Adapter，保持主干预训练模型不变。

### 9.6 知识编辑与持续学习的融合

未来 LLM 可能同时维护三层知识：
- **冻结主干**：通用语言和世界知识。
- **可编辑模块**：LoRA/Adapter/专家模块，用于技能和领域知识。
- **外部记忆/编辑记录**：实时事实、用户特定信息、合规要求。

知识编辑提供了一种局部、可撤销、可审计的更新机制，与持续学习的数据驱动方法形成互补。研究如何自动判断某条新知识应该写入参数、写入模块还是写入外部记忆，以及如何处理三层之间的一致性和冲突，是该领域的重要方向。


## 10. 非参数路径：上下文学习与检索增强

除了修改模型参数，另一条持续学习路径是保持参数冻结，通过上下文学习（In-Context Learning, ICL）或检索增强生成（Retrieval-Augmented Generation, RAG）引入新信息。这些方法不修改模型权重，因此不存在传统意义上的灾难性遗忘，但受限于上下文长度、检索质量和知识粒度。

### 10.1 上下文学习作为持续学习

上下文学习指模型通过输入上下文中的示例或指令，无需梯度更新即可适应新任务。从持续学习角度看，ICL 是一种“零遗忘”的学习方式：因为模型权重不变，旧知识不会丢失。然而，ICL 的容量受上下文长度限制，无法承载大量新知识。对于复杂任务，少量示例可能不足以让模型学会稳定的技能。

### 10.2 检索增强生成（RAG）

RAG 将外部知识库作为模型的“外部记忆”。在推理时，根据输入检索相关文档，将文档与输入一起送入模型。RAG 的持续学习能力来自知识库的更新：新增、修改或删除文档即可改变模型输出。RAG 的优势包括：
- **实时更新**：无需重新训练模型，知识库可频繁更新。
- **可溯源**：模型输出可以附带引用来源，提高可信度和可审计性。
- **无遗忘**：模型权重不变，不存在参数层面的遗忘。
- **隐私友好**：用户特定数据可以放在私有知识库中。

RAG 的挑战包括：
- **检索质量**：检索失败或检索到不相关文档会导致错误输出。
- **知识整合**：模型需要将检索文档与自身知识整合，处理冲突信息。
- **长上下文**：多个文档拼接可能超过上下文限制，需要摘要或压缩。
- **能力更新**：RAG 适合事实更新，但无法让模型获得新的推理技能或行为模式。

### 10.3 记忆增强 LLM

记忆增强 LLM 在 RAG 基础上，增加了可学习的读写记忆机制。例如：
- **Long-term Memory**：模型可以将对话历史、用户偏好、重要事实写入外部记忆，后续推理时检索。
- **Memory Transformer / Memory Layers**：在 Transformer 中显式添加记忆层，支持读写操作。
- **Key-Value Memory**：用 key-value 结构存储知识，支持快速检索和更新。
- **Vector Database + Embedding**：将文本编码为向量，存储在向量数据库中，检索时做相似度搜索。

记忆增强 LLM 的参数可以冻结，但记忆内容可以持续更新。这相当于把“学习”外化为“记忆更新”，既避免遗忘，又支持个性化和实时知识。

### 10.4 参数更新与非参数记忆的融合

参数更新和非参数记忆不是相互替代，而是互补：
- **事实更新**：频繁变化的事实应放在 RAG/记忆库中，如新闻、股价、产品信息。
- **技能习得**：需要泛化的能力应通过参数更新（如 LoRA/Adapter）学习，如代码生成、工具调用、推理风格。
- **领域知识**：介于事实和技能之间的领域知识，可以通过参数高效模块或外部记忆共同管理。
- **元能力**：通用语言、推理、安全对齐等元能力应谨慎保护，尽量通过回放和约束维持。

未来的 LLM 系统可能同时维护三层记忆：参数中的通用知识、可更新模块中的技能与领域知识、外部记忆中的实时事实。研究如何自动决定新知识应写入哪一层，以及如何处理层间冲突和一致性，是持续学习的重要方向。

### 10.5 上下文学习、RAG 与持续学习的评估

评估非参数持续学习需要关注：
- **检索准确率**：检索系统能否找到相关文档。
- **答案忠实性**：模型输出是否基于检索文档，而非自身知识或幻觉。
- **知识冲突处理**：当检索文档与模型内部知识冲突时，模型如何行为（如遵循用户指令、相信更新文档、或明确说明不确定性）。
- **上下文利用效率**：模型能否从长上下文或少量示例中有效学习。
- **长程一致性**：在多次交互中，记忆更新是否被正确保持和检索。

## 11. 多模态与具身持续学习

持续学习不仅限于文本。随着多模态大模型（MLLM）、视觉-语言-动作模型（VLA）和机器人学习的发展，持续学习正扩展到图像、视频、音频、3D、动作和传感器数据。

### 11.1 多模态持续学习的问题

多模态持续学习面临文本持续学习之外的新挑战：
- **模态对齐**：视觉编码器、音频编码器、文本解码器需要在持续学习中保持跨模态对齐。
- **跨模态遗忘**：在一个模态上训练可能导致另一个模态能力下降。例如，持续学习视觉问答后，纯文本推理能力可能退化。
- **模态异构性**：不同模态的数据格式、分辨率、采样率和语义粒度差异巨大。
- **数据稀缺性**：某些模态（如机器人动作、3D 点云）数据收集成本高，难以大量回放。

### 11.2 多模态持续预训练与指令微调

与文本 LLM 类似，MLLM 的持续学习也分为持续预训练和持续指令微调：
- **持续预训练**：在已有视觉-语言模型上继续预训练新的图像-文本对、视频-文本对或音频-文本对。例如，持续学习新的视觉概念或新的视觉-语言对齐。
- **持续指令微调**：按顺序学习不同多模态任务，如视觉问答、图像描述、视觉推理、多模态对话。Guo 等人 2025 年的综述[^51]系统梳理了 MLLM、VLA 和扩散模型中的持续学习方法。

### 11.3 多模态参数高效方法

PEFT 方法在多模态持续学习中同样适用：
- **视觉编码器 LoRA**：只更新视觉编码器的低秩适配器。
- **投影层/连接器 Adapter**：只更新连接视觉编码器和 LLM 的投影层。
- **LLM 端 LoRA**：冻结视觉编码器，只更新 LLM 中的 LoRA。
- **多模态专家**：为不同模态或任务添加不同专家，通过路由选择。

代表性工作包括：
- **LLaVA-Continual**：在 LLaVA 基础上持续学习新视觉任务。
- **MoE-based MLLM CL**：结合 MoE 和 LoRA 的多模态持续学习方法。
- **InduceKV[^52]**：通过诱导 KV 记忆实现多模态 LLM 的持续适应。

### 11.4 具身学习与机器人持续学习

具身智能体需要在真实或模拟环境中持续学习新技能、新环境和新任务。机器人持续学习面临：
- **高维动作空间**：动作可以是关节角度、末端执行器位姿、力矩等，连续且高维。
- **样本效率**：真实机器人数据收集昂贵，需要高度样本高效的学习。
- **安全约束**：机器人动作不能随意探索，需要安全保证。
- **环境与任务序列**：机器人可能依次面对不同环境（家庭、工厂、户外）和任务（抓取、导航、装配）。

持续学习在机器人中的应用包括：
- **视觉-语言-动作模型（VLA）的持续学习**：如 pi0、GR00T 等模型在新任务上的持续微调。
- **技能库与任务规划**：将新技能存入模块库，通过任务规划组合旧技能完成新任务。
- **仿真到现实迁移**：在仿真中持续学习，再迁移到现实。
- **终身 SLAM 与导航**：机器人需要在不断探索新环境的同时保持旧环境地图。

### 11.5 多模态与具身持续学习的基准

代表性基准包括：
- **CLiMB[^53]**：面向视觉-语言模型的持续学习基准，评估多模态任务序列上的遗忘与迁移。
- **MLLM-CTBench[^54]**：面向多模态大模型持续指令微调的基准，联合评估最终答案准确率和推理过程质量。
- **机器人持续学习基准**：通常基于 MuJoCo、Habitat、ALFRED 等仿真环境，定义任务序列和评估指标。

### 11.6 挑战与方向

多模态与具身持续学习的关键方向包括：
- **跨模态回放**：如何有效回放多模态数据，尤其是视频、动作轨迹等高维数据。
- **模态解耦**：在更新一个模态时，尽量不破坏其他模态的表示。
- **仿真-现实联合持续学习**：如何利用仿真数据加速真实机器人学习，同时避免仿真到现实的鸿沟。
- **安全与可验证性**：确保机器人持续学习后的动作安全、可预测、可验证。


## 12. 智能体与工具持续学习

大语言模型正从对话系统演变为能够使用工具、调用 API、执行代码和与环境交互的智能体（Agent）。智能体持续学习涉及工具接入、工具使用模式更新、长期记忆管理和多轮规划策略演进。

### 12.1 智能体持续学习的场景

智能体持续学习的典型场景包括：
- **新工具接入**：API 不断更新，新工具不断出现，智能体需要学习新工具的调用模式、参数格式和输出解析。
- **环境动态变化**：智能体部署在不同环境中，环境规则和可用动作可能变化。
- **用户反馈与偏好**：用户可能对智能体的行为给出反馈，智能体需要根据反馈调整策略。
- **多轮任务规划**：复杂任务需要分解为多个步骤，智能体需要持续学习更好的规划策略。
- **协作与通信**：多智能体系统中，智能体需要学习如何与其他智能体或人类协作。

### 12.2 工具学习与持续适应

工具学习（Tool Learning）指 LLM 学会使用外部工具（如搜索引擎、计算器、代码解释器、数据库、日历、邮件等）。工具持续学习的关键问题：
- **工具注册与发现**：当新工具可用时，如何向模型描述工具功能，使其学会使用。
- **工具调用格式**：不同工具可能有不同输入输出格式（JSON、XML、函数签名、自然语言）。
- **工具组合**：智能体需要学会组合多个工具完成复杂任务。
- **错误恢复**：工具调用失败时，智能体需要学会重试、调整参数或换用其他工具。
- **工具遗忘**：学习了新工具后，可能忘记旧工具的调用方式或参数细节。

### 12.3 智能体记忆与长期上下文

智能体通常需要在长对话或长任务中保持记忆。持续学习要求记忆系统：
- **选择性存储**：决定哪些信息值得长期记忆（如用户偏好、重要事实、失败经验）。
- **检索与整合**：在后续任务中正确检索相关记忆，并整合到当前上下文中。
- **记忆更新**：当信息变化时更新记忆（如用户地址变更、任务状态变化）。
- **记忆遗忘**：在合规或用户要求下，删除或“取消学习”特定记忆。

### 12.4 基于反馈的持续学习

智能体从环境反馈中学习是强化学习的核心。在 LLM 智能体中，反馈可以来自：
- **环境奖励**：任务成功/失败信号。
- **用户评分**：用户对回答质量的打分。
- **自我评估**：模型自己评估输出质量。
- **比较偏好**：用户选择更好的输出。

基于反馈的持续学习通常涉及：
- **在线 RLHF/DPO**：根据新反馈持续更新策略和奖励模型。
- **经验回放**：存储成功和失败轨迹，用于后续训练。
- **课程学习**：从简单任务到复杂任务逐步学习。
- **安全约束**：确保反馈驱动的学习不会导致有害行为。

### 12.5 多智能体持续学习

在多智能体系统中，每个智能体可能持续学习：
- **角色与分工**：智能体学习承担不同角色（规划者、执行者、验证者）。
- **通信协议**：智能体学习如何有效通信，包括自然语言、结构化消息或共享记忆。
- **协作策略**：在动态环境中调整协作方式。
- **对抗与竞争**：在竞争环境中持续学习对抗策略。

多智能体持续学习面临非平稳环境、通信开销、信用分配和涌现行为等挑战。

### 12.6 代表性工作

- **A-Evolve[^55] / Adaptive Auto-Harness**：通过执行反馈持续演化智能体 Harness，使其在开放任务流中自我改进。
- **Self-Evolving LLMs**：通过自生成监督和持续指令微调，使 LLM 自主适应新任务。
- **Toolformer[^56] / Gorilla[^57] / APIBench[^58]**：面向工具使用的 LLM 训练和数据集。
- **KnowPilot / OasisMind 的 Agent 系统**：本项目中的多层级智能体系统，通过 AgentMessage、Skill、Memory、Trigger 等机制支持持续学习和任务调度。

## 13. 评估基准与指标体系

评估是持续学习的核心问题之一。由于持续学习涉及多个任务、多个时间点和多种能力，单一指标远远不够。本节系统梳理持续学习的评估基准和指标体系。

### 13.1 评估设计原则

好的持续学习评估应满足：
- **多维度**：不仅看任务准确率，还要看遗忘、迁移、通用能力、安全、效率等。
- **长序列**：任务数量足够多，能体现累积遗忘。
- **现实性**：任务边界可能模糊，数据分布可能漂移。
- **可复现**：基准定义清晰，实验设置固定。
- **低偏差**：避免数据泄漏、预训练阶段见过测试数据等。

### 13.2 代表性基准

#### 13.2.1 文本与 LLM 基准

- **TRACE**（Wang 等人，2023）：面向对齐后 LLM 的综合持续学习基准，包含 8 个数据集，覆盖领域任务、多语言、代码生成和数学推理。它强调通用能力保持，并提出了 RCL 缓解策略。
- **CIBT**（Zhang 等人，EMNLP 2023）：面向持续指令微调的基准，提供多样化的指令任务序列。
- **Continual-News**（ECNU-SII，2025）：按时间顺序组织的新闻数据集，评估时间漂移和领域演进。
- **CLiMB**（Lin 等人，2023）：面向视觉-语言模型的持续学习基准，也可扩展到多模态 LLM。
- **WikiBigEdit**（Zhang 等人，2025）：面向终身知识编辑的基准，通过大规模连续事实编辑评估编辑稳定性。
- **Long Sequence Benchmarks**：如基于 Wikidata 时间线、HotpotQA 变体的长程事实问答基准。

#### 13.2.2 经典视觉基准

- **Split CIFAR-100 / Split ImageNet**：将图像分类数据集按类别分割为多个任务，是最常用的 Class-IL 基准。
- **Permuted MNIST / Rotated MNIST**：通过像素排列或旋转构造任务序列，常用于任务增量学习。
- **CORe50 / OpenLORIS**：面向机器人视觉的持续学习基准，包含物体识别、场景变化等。

#### 13.2.3 多模态与机器人基准

- **MLLM-CTBench**：多模态大模型持续指令微调基准，评估最终答案和推理过程。
- **Habitat / ALFRED / Meta-World / MuJoCo**：机器人持续学习与视觉-语言-动作基准。

### 13.3 评估指标体系

#### 13.3.1 性能指标

- **平均准确率（Average Accuracy, Avg.Acc）**：最终模型在所有已见任务上的平均性能。最综合的指标。
- **最终准确率（Final Accuracy）**：训练结束后在最后一个任务上的性能。
- **最佳准确率（Best Accuracy）**：训练过程中达到的峰值平均准确率。

#### 13.3.2 遗忘指标

- **遗忘率（Forgetting Rate）**：旧任务性能下降的平均幅度。
- **后向迁移（Backward Transfer, BWT）**：学习新任务后对旧任务性能的影响。
- **遗忘面积（Forgetting Area）**：在训练过程中累积遗忘的积分度量。

#### 13.3.3 迁移指标

- **前向迁移（Forward Transfer, FWT）**：旧任务学习对新任务初始性能的帮助。
- **零样本迁移（Zero-shot Transfer）**：模型在没有见过新任务数据时的性能，衡量预训练或旧任务带来的迁移。

#### 13.3.4 LLM 专用指标

- **通用能力保持率（General Capability Retention）**：在 MMLU、GSM8K、HumanEval、BBH、MATH 等通用基准上的保持程度。
- **指令遵循保持率（Instruction Following Retention）**：模型是否仍能遵循各种指令格式和要求。
- **安全性保持率（Safety Retention）**：模型拒绝有害请求的能力是否退化。
- **知识一致性（Knowledge Consistency）**：更新事实后，模型在不同问法下是否一致回答。
- **幻觉率（Hallucination Rate）**：持续学习后模型是否更容易产生幻觉。
- **输出分布稳定性**：输出风格、语言分布、格式是否稳定。

#### 13.3.5 效率与系统指标

- **可训练参数量（Trainable Parameters）**：如 LoRA rank、Adapter 数量、专家数量。
- **存储开销（Memory Overhead）**：记忆缓冲区、生成模型、外部记忆的大小。
- **训练时间 / FLOPs**：每次更新所需的计算量。
- **推理延迟（Inference Latency）**：路由、检索、专家加载等引入的延迟。
- **能耗（Energy Consumption）**：持续学习的碳 footprint。

#### 13.3.6 稳定性-可塑性综合指标

- **稳定性-可塑性曲线（Stability-Plasticity Curve）**：在不同超参数下绘制遗忘率和新任务准确率，观察帕累托前沿。
- **面积指标（Area Under Curve）**：如 AUC of stability-plasticity trade-off。
- **联合训练上界差距（Joint Training Gap）**：持续学习性能与所有数据联合训练上界的差距。

### 13.4 统计显著性与鲁棒性

持续学习评估还需要考虑：
- **随机种子**：不同初始化、数据顺序、任务顺序可能导致结果差异大。
- **任务顺序敏感性**：不同任务顺序可能显著改变最终性能。
- **超参数敏感性**：回放比例、学习率、正则化强度对结果影响大。
- **长序列外推**：基准可能只有 5-20 个任务，而真实场景可能有数百个任务，需要评估方法在长序列下的可扩展性。

### 13.5 评估协议的标准化

目前持续学习评估尚未完全标准化。不同论文使用不同基准、指标和任务顺序，导致难以横向比较。未来需要：
- 统一基准套件（如包含文本、多模态、智能体任务的统一套件）。
- 统一任务顺序和划分。
- 统一报告指标（至少报告 Avg.Acc、Forgetting Rate、BWT、FWT 和通用能力保持率）。
- 统一计算预算（如训练步数、可训练参数上限）。
- 统一统计报告（多次运行均值和方差）。


## 14. 应用案例

持续学习和大语言模型的结合正在多个垂直领域落地。本节选取代码、科学、医疗、法律、推荐和个性化助手等典型场景，分析各自的特点、方法选择和挑战。

### 14.1 代码与软件开发

代码领域是 LLM 持续学习的天然应用场景：
- **新语言与新框架**：编程语言、库、框架不断更新。例如，从 Python 3.10 到 3.12、从 React 到新的前端框架、从 PyTorch 到新的推理引擎。
- **代码仓库持续学习**：在特定组织的代码库上持续微调，使模型学会内部 API、编码规范、架构模式。
- ** bug 修复与代码审查**：根据历史 bug 修复和审查反馈持续学习，提高代码质量建议。
- **工具调用**：学习新的开发工具（如新的 Linter、测试框架、部署脚本）。

挑战包括：代码数据通常包含敏感信息，需要隐私保护；新代码与旧代码可能存在冲突（如 API 变更）；代码评估需要可执行验证，不能仅靠文本相似度。

代表性工作：Yadav 等人 2023 年探索了代码生成模型的持续学习，发现代码模型同样存在灾难性遗忘，且回放和正则化策略与 NLP 有相似之处但也有代码特有的结构。

### 14.2 科学与学术研究

科学领域知识更新迅速，LLM 需要持续吸收最新论文、实验数据和发现：
- **文献综述**：持续阅读新论文，更新对某一领域的理解。
- **假设生成**：基于最新实验数据生成新假设。
- **实验设计**：学习新的实验方法和技术。
- **分子与材料发现**：在化学、材料科学中持续学习新分子结构和性质关系。

挑战：科学知识高度结构化，需要与符号推理、知识图谱结合；事实冲突和假阳性发现需要谨慎处理；科学评估需要同行评议和实验验证。

代表性工作：Mocl 等分子指纹持续学习方法，将知识图谱和持续学习结合用于分子发现。

### 14.3 医疗与健康

医疗是持续学习高风险、高价值的应用领域：
- **医学知识更新**：新疾病、新药物、新诊疗指南不断涌现。
- **电子病历学习**：在保护隐私前提下，从医院病历中学习疾病模式和治疗效果。
- **个性化治疗建议**：根据患者历史反馈持续调整建议。
- **医学影像持续学习**：新病种、新设备、新影像协议需要模型持续适应。

挑战：医疗数据隐私和合规要求极高（HIPAA、GDPR）；错误更新的代价极大；需要可解释性和不确定性估计[^59]；不同医院数据分布差异大（domain shift）。

方法选择：通常会使用联邦持续学习[^60]、差分隐私、模型合并、PEFT 模块和外部医学知识库相结合。

### 14.4 法律与合规

法律领域需要持续学习新法规、判例和合同模板：
- **法规更新**：新法律、修订案、司法解释不断发布。
- **判例学习**：新法院判决需要纳入模型知识。
- **合同审查**：持续学习特定行业的合同风险和审查模式。
- **跨境合规**：不同司法管辖区的法律差异需要分别维护。

挑战：法律解释具有主观性和时效性；不同法域冲突需要明确处理；模型输出需要引用来源；法律领域对准确性和一致性要求极高。

方法选择：RAG + 外部法律数据库 + 知识编辑 + 领域 LoRA 是常见组合。

### 14.5 推荐与信息检索

推荐系统天然是持续学习问题：用户兴趣、商品库、内容趋势都在不断变化。
- **用户兴趣漂移**：用户偏好随时间变化，模型需要持续适应。
- **新商品/内容冷启动**：新加入的商品没有历史交互，需要快速学习。
- **序列推荐**：根据用户实时交互序列更新推荐。
- **多任务推荐**：同时优化点击、收藏、购买、停留时长等多个目标。

挑战：数据分布漂移剧烈；用户反馈稀疏且有偏；需要在线学习和低延迟更新；冷启动与持续学习需要平衡。

方法选择：在线学习、增量嵌入更新、记忆网络、回放、元学习在推荐中广泛应用。

### 14.6 个性化助手与对话系统

个性化助手需要根据用户交互持续学习：
- **用户偏好记忆**：喜欢的风格、常用工具、关注话题。
- **对话历史摘要**：长期保持对话上下文和用户背景。
- **任务习惯学习**：学习用户常用任务流程和参数设置。
- **安全与隐私边界**：学习每个用户的安全和隐私偏好。

挑战：个性化数据隐私敏感；过度个性化可能导致回音室效应；不同用户需要隔离记忆；需要支持“遗忘”特定用户数据。

方法选择：外部记忆系统、用户特定 LoRA/Adapter、RAG、联邦学习[^61]是主要方向。

## 15. 系统实现与工程部署

持续学习的研究方法需要在真实系统中落地。本节讨论工程实现、部署架构和运维实践。

### 15.1 持续学习流水线

一个典型的 LLM 持续学习流水线包括：
1. **数据收集**：从用户交互、日志、外部数据源收集新数据。
2. **数据清洗与过滤**：去重、去毒、去隐私、质量筛选。
3. **数据标注/合成**：对数据进行标注或通过模型生成训练数据。
4. **任务划分/无任务流处理**：决定是否划分任务，或直接按流处理。
5. **模型更新**：选择全参数、PEFT、知识编辑或 RAG 更新策略。
6. **验证与评估**：在新任务、旧任务、通用基准、安全基准上评估。
7. **部署与回滚**：将更新后的模型部署到生产环境，保留旧版本以便回滚。
8. **监控与反馈**：监控模型性能、用户反馈、安全事件，触发下一轮学习。

### 15.2 数据基础设施

- **数据湖/数据仓库**：存储历史数据、用户交互、领域语料。
- **特征存储**：存储提取的特征、嵌入、KV 缓存。
- **向量数据库**：用于 RAG 和记忆检索，如 FAISS、Milvus、Pinecone、Weaviate。
- **数据版本管理**：追踪训练数据版本，支持审计和复现。
- **数据隐私与合规工具**：去标识化、差分隐私、访问控制。

### 15.3 训练基础设施

- **分布式训练框架**：DeepSpeed、FSDP、Megatron-LM、vLLM 等。
- **PEFT 库**：HuggingFace PEFT、LoRA、Adapter、Prefix Tuning 实现。
- **实验跟踪**：Weights & Biases、MLflow、TensorBoard，用于记录超参数、指标和模型版本。
- **超参数优化**：Optuna、Ray Tune，用于搜索回放比例、学习率、LoRA rank 等。
- **模型版本与注册**：MLflow Model Registry、HuggingFace Hub、自研模型仓库。

### 15.4 部署架构

- **模型服务**：vLLM、TGI、TensorRT-LLM 等高效推理框架。
- **动态 LoRA 加载**：根据请求动态加载不同任务的 LoRA 模块。
- **专家路由服务**：在 MoE 系统中，路由请求到对应专家或专家组合。
- **RAG 服务**：独立的检索服务，与模型服务解耦。
- **记忆服务**：外部记忆读写服务，支持长短期记忆管理。
- **A/B 测试[^62]与金丝雀部署**：逐步推送新模型版本，监控风险。
- **回滚机制**：保留旧版本检查点，一旦新模型出现问题快速回滚。

### 15.5 监控与可观测性

持续学习系统需要监控：
- **性能漂移**：在新旧任务上的准确率、困惑度、BLEU/ROUGE 等。
- **通用能力漂移**：在 MMLU、GSM8K、HumanEval 等基准上的表现。
- **安全与对齐漂移**：有害请求通过率、越狱成功率、偏见指标。
- **输出分布变化**：语言分布、风格、格式、长度分布。
- **用户反馈**：满意度、错误报告、修正请求。
- **系统指标**：延迟、吞吐、错误率、资源使用。

### 15.6 工程权衡

在实际部署中，需要权衡：
- **更新频率**：实时更新、小时级、天级还是周级？频率越高，风险和成本越大。
- **更新方式**：全量重训、增量微调、LoRA 更新、知识编辑、RAG 更新？
- **内存与计算预算**：可训练参数量、缓冲区大小、专家数量、检索索引规模。
- **延迟与质量**：是否需要牺牲一点质量换取更快响应或更低成本？
- **隐私与效用**：更严格的隐私保护可能降低学习效果。
- **自动化与人工审核**：哪些更新可以自动部署，哪些需要人工审批？

### 15.7 与 MLOps 的融合

持续学习系统是 MLOps（Machine Learning Operations）的高级形态。它需要：
- **自动化再训练（Auto-Retraining）**：当数据积累到一定量或性能下降到阈值时触发训练。
- **持续集成/持续部署（CI/CD）**：模型训练、评估、部署全流程自动化。
- **数据与模型血缘追踪**：记录每个模型版本使用的数据、代码和超参数。
- **治理与审计**：确保模型更新符合组织政策和法规。
- **灾难恢复**：检查点、备份、回滚策略。

## 16. 未来方向、挑战与结论

### 16.1 未来方向

持续学习与大语言模型的结合仍在快速发展。未来方向包括：

**（1）自演化与自主学习**：LLM 应能主动识别学习需求、生成训练数据、评估自身不足并更新。Self-Evolving LLMs、A-Evolve 等方向探索了自我演进路径，但安全性和可控性仍是挑战。

**（2）多模态与具身持续学习**：从文本扩展到图像、视频、音频、3D、动作和传感器数据。需要新的模态对齐、回放和评估方法。

**（3）智能体与工具持续学习**：智能体需要持续学习新工具、新环境、新协作策略。这要求持续学习系统与工具注册、记忆检索、任务规划和反馈回路深度集成。

**（4）遗忘诊断与可解释性**：理解哪些参数、哪些层、哪些概念在持续学习中发生变化，有助于设计更精确的缓解策略。机械可解释性（Mechanistic Interpretability）和神经正切核（NTK）分析是潜在工具。

**（5）轻量化、隐私与合规部署**：开发低计算成本、低存储开销、隐私保护的持续学习方法。差分隐私、联邦持续学习、机器遗忘、可审计更新是重要方向。

**（6）知识编辑、RAG 与参数更新的统一框架**：构建三层知识管理系统，自动决定新知识应写入参数、模块还是外部记忆，并处理层间冲突。

**（7）长序列与终身评估**：现有基准通常只有 5-20 个任务，未来需要数百甚至数千个任务的评估协议，以及终身学习性能的理论边界。

**（8）标准化与开源生态**：建立统一的基准、指标、协议和开源工具，降低研究门槛，促进工业落地。

### 16.2 核心挑战

持续学习在 LLM 时代仍面临以下核心挑战：
- **通用能力保持**：如何在学习新领域和新技能时不破坏预训练和对齐获得的通用能力。
- **无任务边界**：现实世界数据没有明确的任务划分，需要 task-free 方法。
- **长序列可扩展性**：方法能否在数百个任务序列上保持有效。
- **可解释性与可控性**：模型知识如何组织、如何更新、如何遗忘需要透明可控。
- **安全与对齐**：持续学习不能引入偏见、毒性、越狱或价值观漂移。
- **数据隐私与合规**：如何在保护隐私和合规前提下进行有效学习。
- **经济与碳成本**：持续学习的计算成本和环境影响需要优化。
- **人与机器协同**：持续学习系统应支持人类监督、干预和反馈，而不是完全自主。

### 16.3 结论

持续学习是使大语言模型从“一次性训练”走向“终身可用”的核心能力。从经典深度学习中的灾难性遗忘、稳定性–可塑性困境，到 LLM 时代的持续预训练、持续指令微调、参数高效适应、模块化专家、知识编辑、RAG 和智能体持续学习，研究范式已经发生了深刻转变。LLM 的庞大规模、昂贵训练成本与复杂对齐状态，使得传统全量微调与简单正则化不再适用，低成本、可扩展、可审计的混合方法成为主流。

本文系统梳理了持续学习的基础理论、经典方法、LLM 新方法、多模态与智能体扩展、评估基准、应用案例、工程部署和未来方向。我们强调：持续学习不仅是算法问题，更是系统设计问题。未来的 LLM 需要同时维护参数中的通用知识、可更新模块中的技能与领域知识、外部记忆中的实时事实，并在三层之间实现一致性、可解释性和可控性。只有在性能、效率、安全、隐私和合规之间取得平衡，持续学习才能真正成为大语言模型长期服务现实世界的基础设施。

## 17. 机器遗忘与可遗忘权

在持续学习的工业部署中，一个无法回避的问题是：当用户要求删除其数据，或当组织需要移除某些受版权保护、有害或错误的数据时，如何确保模型不再受其影响？这被称为机器遗忘（Machine Unlearning）或可遗忘权（Right to be Forgotten）。机器遗忘不仅是隐私合规的要求，也是持续学习系统可信度和可审计性的重要组成部分。

### 17.1 可遗忘权的法律与伦理背景

可遗忘权最早源于欧盟《通用数据保护条例》（GDPR）中的相关规定，要求数据控制者在特定情况下删除个人数据。随着机器学习模型被训练在大量数据上，模型参数可能间接记住个人敏感信息，即使原始数据被删除，模型仍可能泄露这些信息。因此，研究如何让模型“遗忘”特定数据成为热点问题。在持续学习系统中，由于模型不断吸收新数据，遗忘需求更加频繁：用户可能撤回数据授权、错误或过时的信息需要被移除、模型可能学到受版权保护的内容或有害示例。

### 17.2 机器遗忘的形式化定义

机器遗忘的目标是：给定一个训练好的模型 $M$，以及一个需要被遗忘的数据子集 $D_{forget}$，产生一个新模型 $M'$，使得 $M'$ 在统计上等价于一个从未在 $D_{forget}$ 上训练过的模型。形式化地说：

$$M' = \text{Unlearn}(M, D_{forget}, D_{remain}) \approx M_{\text{retrain}}$$

其中 $M_{\text{retrain}}$ 表示只在 $D_{remain}$ 上重新训练的模型。完全重新训练通常成本过高，因此机器遗忘算法需要在计算效率和遗忘效果之间取得平衡。

### 17.3 机器遗忘方法分类

机器遗忘方法大致可分为以下几类：

**（1）重训练法**：将 $D_{forget}$ 从训练数据中移除后重新训练模型。这是最彻底的遗忘方法，但成本最高。对于 LLM，完全重训练几乎不可行。

**（2）影响移除法**：通过影响函数（Influence Function）估计 $D_{forget}$ 对模型参数的影响，然后反向更新参数以抵消这种影响。这类方法在凸问题和小模型上有效，但在深度非凸网络中，影响函数估计可能不准确，且可能破坏无关知识。

**（3）隔离与切片法**：在训练或持续学习时，将数据切片并与特定参数或模块关联。遗忘时，只需删除或重置对应的参数/模块。例如，PNN 或模块化系统中，如果每个数据切片对应一个专家，遗忘该切片只需移除对应专家。

**（4）梯度上升/损失最大化法**：在 $D_{forget}$ 上执行梯度上升，使模型在该数据上的损失最大化，从而“忘记”这些数据。但简单梯度上升可能导致模型不稳定或产生 adversarial 记忆，需要 careful 正则化。

**（5）知识蒸馏与教师-学生法**：使用一个“干净教师”模型（在 $D_{remain}$ 上训练）来指导学生模型，使学生模型不学习 $D_{forget}$。在 LLM 中，可以用原始模型作为教师，但只蒸馏与 $D_{forget}$ 无关的知识。

**（6）差分隐私法**：在训练过程中引入差分隐私机制，使得任何单个数据点的影响有限。虽然差分隐私能提供理论上可证明的遗忘保证，但会牺牲模型性能，且对于 LLM 来说计算开销很大。

### 17.4 机器遗忘与持续学习的结合

在持续学习中，机器遗忘可以按不同层级实现：
- **数据层遗忘**：从训练数据集中删除数据，并重新训练或更新相关模型切片。这适用于数据还未被深度整合进模型。
- **参数层遗忘**：定位并修改受影响的参数。对于 PEFT 系统，可以只删除或重新训练受影响的 LoRA/Adapter。
- **记忆层遗忘**：从外部记忆、RAG 索引、向量数据库中删除相关条目。这是最简单和最常用的 LLM 遗忘方式，因为模型参数本身未受影响。
- **知识编辑层遗忘**：通过知识编辑将错误事实覆盖为“我不知道”或“该信息已被删除”。

### 17.5 机器遗忘的评估

评估机器遗忘需要：
- **成员推断攻击抵抗力**：攻击者无法判断 $D_{forget}$ 中的样本是否被用于训练。
- **模型效用保持**：遗忘后模型在 $D_{remain}$ 上的性能不应显著下降。
- **遗忘彻底性**：模型在 $D_{forget}$ 上的表现应接近随机或从未见过。
- **稳定性**：多次遗忘操作不应导致模型崩溃或性能退化。
- **效率**：遗忘操作的成本应远低于完全重训练。

对于 LLM，评估还包括：模型在 $D_{forget}$ 相关查询上是否输出中性回答、是否不再泄露隐私信息、是否保持通用能力。

### 17.6 挑战与未来方向

机器遗忘仍然面临许多挑战：
- **非凸性与参数纠缠**：深度学习模型的参数高度纠缠，很难精确隔离某个数据的影响。
- **连锁遗忘**：遗忘一个数据可能意外影响模型对相关知识的学习。
- **幻觉与虚构**：遗忘后模型可能为了填补知识空白而 hallucinate。
- **大规模可扩展性**：LLM 规模巨大，需要高效的遗忘算法。
- **审计与验证**：如何向监管者证明模型确实遗忘了特定数据？需要可审计的遗忘日志和评估报告。

未来方向包括：发展可证明的遗忘方法、结合模块化/PEFT 的切片遗忘、开发 LLM 专用遗忘基准、以及将遗忘机制纳入 MLOps 和治理流程。

## 18. 联邦持续学习

联邦学习（Federated Learning, FL）允许多个参与方在不共享原始数据的情况下协同训练模型。联邦持续学习（Federated Continual Learning, FCL）将联邦学习与持续学习结合，处理多个客户端、多个时间点的数据流。它适用于医疗、金融、物联网、移动设备等场景。

### 18.1 FCL 的问题设定

在 FCL 中，有多个客户端，每个客户端都有自己的数据流。在每个通信轮次，客户端在本地持续学习新任务，服务器聚合客户端更新，形成全局模型。挑战包括：
- **数据异构性**：不同客户端的数据分布、任务序列、标签空间可能不同。
- **通信限制**：客户端只能与服务器进行有限通信，不能频繁上传大量梯度或模型。
- **本地遗忘**：客户端在本地顺序学习时本身会发生遗忘。
- **全局-本地冲突**：全局模型需要适应所有客户端，但本地模型又需要个性化。
- **隐私安全**：即使不共享原始数据，模型更新也可能泄露敏感信息。

### 18.2 联邦回放与记忆共享

在联邦学习中，直接共享原始数据违反隐私原则。因此需要联邦回放机制：
- **本地回放**：每个客户端维护自己的本地记忆缓冲区，存储本地历史样本。
- **全局记忆（Global Memory）**：服务器维护一个全局记忆缓冲区，由客户端上传的匿名化或合成样本组成。需要隐私保护技术。
- **生成回放**：客户端训练本地生成模型，上传生成模型参数或合成样本，而不是原始数据。
- **特征回放**：客户端上传旧任务的代表性特征，而不是原始数据。
- **梯度聚合回放**：在聚合阶段，通过控制梯度方向来缓解全局遗忘。

### 18.3 联邦参数隔离与个性化

联邦持续学习常结合参数隔离和个性化：
- **本地专家/LoRA**：每个客户端维护本地 LoRA 或专家，服务器聚合共享主干。这样本地知识不会互相干扰。
- **分层聚合**：底层参数共享，顶层参数个性化。
- **元学习初始化**：服务器训练一个元模型，使每个客户端能快速适应本地任务序列。
- **联邦模型合并**：每个客户端持续学习后，服务器通过模型合并或平均聚合多个客户端模型。

### 18.4 联邦持续学习中的隐私保护

隐私保护技术包括：
- **差分隐私**：在客户端上传梯度前添加噪声。
- **安全聚合**：使用密码学技术聚合客户端更新，服务器无法看到单个客户端的更新。
- **同态加密**：在加密状态下计算梯度聚合。
- **知识蒸馏**：客户端用本地数据蒸馏全局模型，不上传原始数据。
- **遗忘机制**：当客户端退出或数据授权被撤销时，需要移除该客户端对全局模型的贡献。

### 18.5 代表性工作与基准

FCL 的研究仍处于早期阶段。代表性方向包括：联邦类增量学习（Federated Class-Incremental Learning）、联邦任务增量学习、联邦持续学习在医疗和移动设备中的应用。基准通常基于联邦学习框架（如 LEAF[^63]、FedML[^64]）和持续学习基准的组合。

### 18.6 挑战与方向

FCL 的核心挑战：
- **通信效率**：如何在不频繁通信的情况下保持全局模型和本地模型的知识。
- **任务边界未知**：客户端可能没有明确的任务标签，需要 task-free 方法。
- **系统异构性**：客户端计算能力、存储、网络条件差异大。
- **公平性**：如何确保小客户端或数据稀疏客户端也能受益。
- **动态客户端**：客户端可能随时加入或离开，数据分布会随时间变化。

未来方向包括：联邦模块化专家、联邦知识编辑、联邦 RAG、联邦机器遗忘、以及联邦持续学习的理论与隐私保证。

## 19. 理论下界、可塑性损失与神经正切核分析

持续学习不仅需要实用方法，还需要理论理解。本节讨论灾难性遗忘的理论下界、可塑性损失和神经正切核（NTK）等分析工具。

### 19.1 灾难性遗忘的理论下界

理论研究表明，在某些严格设定下，灾难性遗忘是不可避免的。例如，在没有回放、没有参数扩展、任务冲突的情况下，任何单一模型都无法在所有任务上同时达到联合训练的性能。这些下界通常基于覆盖数、VC维、Rademacher 复杂度或信息论论证。虽然这些下界多基于简化假设（如线性模型、二分类、固定网络结构），但它们揭示了为什么回放、参数隔离或外部记忆是必要的。

### 19.2 稳定性-可塑性权衡的数学刻画

稳定性-可塑性权衡可以通过多任务优化几何来刻画。假设每个任务 $t$ 有一个损失景观 $L_t$ 和最优参数区域 $\theta_t^*$。两个任务兼容当且仅当它们的损失景观存在共享低值区域；冲突当两个最优区域相距很远。持续学习的目标是找到一个参数区域，在所有任务上同时具有较低损失。如果任务冲突，必须牺牲某些任务上的性能，或通过参数隔离、数据混合来缓解。

### 19.3 可塑性损失

除了遗忘，持续学习还面临可塑性损失（Plasticity Loss）：即使模型没有明显遗忘旧任务，它也可能逐渐失去学习新复杂函数的能力。Kumar 等人 2023 年提出 Regenerative Regularization，通过正则化参数保持接近初始化来维持可塑性。可塑性损失的原因可能包括：
- 参数远离初始化区域，使模型进入损失景观的平坦或低曲率区域。
- 激活模式变得稀疏或固定，减少了有效网络容量。
- 优化器（如 Adam）的动量积累了旧任务的梯度方向。

在 LLM 中，可塑性损失意味着经过多次持续学习后，模型可能难以学习全新的能力或复杂的新任务。这对长期部署至关重要。

### 19.4 神经正切核（NTK）与持续学习

神经正切核（NTK）理论为无限宽神经网络提供了训练动态和泛化的解析工具。在 NTK 框架下，神经网络在训练过程中核函数近似不变，训练可以视为核回归。对于持续学习，NTK 可以：
- 显式计算顺序学习后模型在每个任务上的性能。
- 分析任务相似度和冲突对遗忘的影响。
- 指导数据选择、回放比例和正则化强度。
- 比较不同架构（如全连接、卷积、Transformer）的持续学习能力。

然而，NTK 假设网络无限宽，且训练步长很小，对于实际有限宽 LLM 只能提供定性指导。

### 19.5 信息论视角

从信息论角度看，持续学习可以看作一个信道问题：模型需要从数据流中提取和保存相关信息，同时丢弃不相关或冲突的信息。互信息、压缩、率失真理论等工具可以帮助理解：
- 模型应该记住多少旧任务信息？
- 回放数据量与遗忘率之间的关系。
- 参数数量与可存储任务数量之间的关系。
- 最优编码策略（如特征回放、压缩记忆）。

### 19.6 学习理论与泛化边界

持续学习的泛化边界研究关注：在有限样本和任务序列下，最终模型的泛化误差如何受任务数量、样本数量、模型复杂度、遗忘机制影响。这些边界通常比 IID 学习的边界更松散，因为数据非平稳且存在分布漂移。理解这些边界有助于设计更 robust 的持续学习算法和评估协议。

### 19.7 理论指导实践

理论研究的最终目标是指导实践：
- 根据任务冲突程度选择正则化强度或参数隔离程度。
- 根据模型容量和任务数量决定回放缓冲区大小。
- 根据任务相似度设计课程学习顺序。
- 根据理论下界判断是否需要外部记忆或模块化架构。

虽然理论与实际 LLM 仍有差距，但 NTK、信息论、优化几何等工具正在缩小这一差距。

## 20. 持续学习的安全、对齐与价值对齐

随着 LLM 持续学习走向实际应用，安全性、对齐和价值对齐问题变得至关重要。持续学习不仅是能力扩展，也是价值观和行为的持续塑造。如果不加以控制，持续学习可能引入偏见、毒性、越狱、错误信息和社会危害。

### 20.1 对齐税与持续学习

对齐税（Alignment Tax）指模型在优化新目标或适应新数据时，原有对齐属性（如安全性、真实性、帮助性）退化。在持续学习中，对齐税表现为：
- 学习了新的领域数据后，模型更容易生成有害内容。
- 持续指令微调后，模型的拒绝能力变弱。
- 吸收了新用户偏好后，模型输出可能变得偏见或误导。
- 持续预训练改变了模型的世界知识分布，导致安全相关事实判断变化。

Fernando 等人 2024 年的工作发现，顺序 SFT 和 DPO 会导致通用能力和旧偏好同时退化。因此，持续学习必须将对齐保持作为核心目标之一。

### 20.2 安全数据的回放与约束

缓解对齐税的最直接方法是：在持续学习中混入安全对齐数据。例如：
- **安全数据回放**：在每次训练中加入有害请求-拒绝示例，保持安全边界。
- **价值数据回放**：加入体现目标价值观（如诚实、公平、尊重）的示例。
- **偏好数据回放**：在 RLHF/DPO 中保留旧偏好对，防止偏好漂移。
- **约束优化**：将安全目标作为约束，优化主目标时不超过安全阈值。

### 20.3 价值对齐的持续学习

价值对齐（Value Alignment）指确保模型行为符合人类价值观和社会规范。在持续学习中，价值对齐需要：
- **明确价值目标**：定义模型应遵循的核心价值观（如诚实、无害、有用、公平、透明）。
- **价值观动态更新**：随着社会规范变化，某些价值观可能需要调整，但需经过审慎治理。
- **多元价值观平衡**：不同用户、文化、场景可能有不同价值观，需要平衡和可配置。
- **冲突解决**：当不同价值观冲突时，模型需要有一套明确的优先级和决策机制。

### 20.4 偏见与公平性

持续学习可能放大或引入偏见：
- 如果新数据来自某个特定群体或文化，模型可能对其他群体产生偏见。
- 如果回放数据选择不当，可能过度代表某些观点。
- 如果领域数据包含有毒或刻板印象内容，模型会学习并放大这些偏见。

缓解方法包括：数据去偏、公平性约束、多样性回放、对抗去偏和偏见审计。

### 20.5 错误信息与幻觉

持续学习过程中，模型可能吸收错误信息或产生幻觉：
- 新训练数据可能包含错误事实或过时信息。
- 生成回放可能产生并传播幻觉。
- 知识编辑不当可能导致知识冲突和虚假输出。
- 模型在遗忘旧知识后，可能为填补空白而虚构内容。

缓解方法包括：来源验证、事实核查、RAG 引用、不确定性估计、人机协同审核。

### 20.6 越狱与对抗攻击

持续学习可能削弱模型对越狱和对抗攻击的抵抗力：
- 新数据可能包含对抗性提示，使模型学会绕过安全边界。
- 持续微调可能降低模型对新颖越狱模式的识别能力。
- 个性化学习可能被恶意利用，诱导模型生成有害内容。

需要在持续学习中持续进行红队测试[^65]（Red Teaming）、对抗训练和越狱检测。

### 20.7 可解释性与可审计性

安全和对齐需要可解释性和可审计性：
- 模型应能解释其行为和知识来源。
- 训练数据、更新操作、模型版本应被记录和审计。
- 持续学习系统应支持回滚和撤销。
- 专家激活、记忆检索、知识编辑等操作应可追踪。

### 20.8 治理与监管

持续学习系统的部署需要治理框架：
- **更新审批流程**：哪些更新可以自动部署，哪些需要人工审核。
- **影响评估**：在部署前评估更新对安全、偏见、隐私、准确性的影响。
- **合规审查**：确保符合 GDPR、AI Act[^66] 等法规。
- **用户告知**：告知用户模型正在持续学习，以及其数据如何被使用。
- **退出机制**：允许用户选择不参与持续学习，或要求删除其数据影响。

### 20.9 未来方向：可信持续学习

未来的持续学习研究应朝“可信持续学习”（Trustworthy Continual Learning）方向发展：
- 将安全、对齐、隐私、公平、可解释性作为一等公民，而非事后补丁。
- 开发能够自我监控和自我修正的持续学习系统。
- 建立跨学科合作，结合机器学习、伦理学、法学、社会科学。
- 推动开源基准、治理工具和审计框架。
- 探索人与 AI 协同的持续学习，使人类始终保持在回路中。

## 21. 生成式 AI 与扩散模型的持续学习

除了大语言模型和多模态大模型，生成式 AI 还包括扩散模型（Diffusion Models）、生成对抗网络（GAN）、变分自编码器（VAE）和流模型（Flow-based Models）。这些模型在图像生成、视频合成、音频生成、3D 内容生成和科学计算中发挥着重要作用。与 LLM 类似，扩散模型也需要持续学习新风格、新概念和新领域，同时避免遗忘旧能力。

### 21.1 扩散模型持续学习的特殊性

扩散模型的持续学习与 LLM 有显著不同：
- **数据表示**：扩散模型通常处理连续高维数据（图像像素、音频波形、潜变量），而 LLM 处理离散 token。
- **训练目标**：扩散模型通过去噪目标训练，损失函数涉及噪声水平和时间步；LLM 通过下一个 token 预测训练。
- **生成过程**：扩散模型需要多步去噪，持续学习可能影响生成质量、样本多样性和概念组合能力。
- **概念编辑**：扩散模型中的概念通常以文本条件嵌入或交叉注意力层的 key-value 对形式存在，类似于 LLM 中的知识编辑。

### 21.2 持续学习在扩散模型中的应用

- **新风格学习**：艺术家风格、品牌视觉风格、时代审美风格不断更新。
- **新概念学习**：新对象、新角色、新场景需要被纳入模型。
- **领域适应**：从通用图像生成适应到医学影像、卫星图像、工业设计图。
- **个性化生成**：学习特定用户或角色的视觉特征，用于头像、虚拟形象等。
- **安全与审查**：持续更新模型以拒绝生成有害、侵权或敏感内容。

### 21.3 扩散模型持续学习方法

**（1）文本嵌入调优**：通过微调文本编码器或新增 token embedding 来学习新概念，如 Textual Inversion[^67]、DreamBooth[^68]、Custom Diffusion[^69]。这些方法只修改少量嵌入，保持 U-Net 不变，因此遗忘较少。

**（2）LoRA / Adapter**：在扩散模型的 U-Net 或 Transformer 骨干中注入 LoRA 或 Adapter，学习新风格或概念。这与 LLM 中的 PEFT 持续学习类似。

**（3）经验回放与数据混合**：在训练新概念时混合旧概念样本，防止遗忘旧风格。

**（4）概念隔离与路由**：为不同概念或领域训练独立的低秩模块，推理时根据文本条件路由到对应模块。

**（5）无数据蒸馏**：利用现有模型生成旧概念样本，作为回放数据。

### 21.4 多模态生成模型的持续学习

随着视频生成模型（如 Sora、CogVideo）、音频生成模型（如 MusicLM、AudioLDM）和 3D 生成模型的发展，持续学习需求进一步扩展。多模态生成模型需要同时处理文本、图像、视频、音频等多种条件，并持续学习新的生成能力。挑战包括跨模态遗忘、模态对齐保持、长序列视频一致性等。

### 21.5 扩散模型持续学习的评估

评估指标包括：
- **生成质量**：FID、IS、CLIP Score、人类偏好。
- **概念保持**：旧概念生成质量是否下降。
- **概念组合**：模型能否组合新旧概念生成新样本。
- **风格一致性**：风格学习是否稳定。
- **安全性**：是否拒绝生成有害内容。

### 21.6 与 LLM 持续学习的联系

扩散模型的持续学习方法（嵌入调优、LoRA、回放、概念隔离）与 LLM 中的方法高度相似。未来，统一的多模态生成模型（如 GPT-4o、FLAME 等）将需要同时支持文本、图像、视频、音频的持续学习，方法也将进一步融合。

## 22. 持续学习中的神经架构搜索与小样本学习

### 22.1 神经架构搜索（NAS）与持续学习

神经架构搜索（Neural Architecture Search, NAS）旨在自动发现适合特定任务的网络结构。在持续学习中，NAS 可以帮助：
- **动态容量分配**：根据任务复杂度自动决定网络应扩展多少容量。
- **模块化结构发现**：自动发现适合模块化持续学习的子网络或专家结构。
- **高效搜索**：在有限计算预算下搜索最优的持续学习架构。
- **终身 NAS**：在任务序列中持续演化模型架构，而不是固定架构。

代表性方向包括：Differentiable Architecture Search（DARTS[^70]）与持续学习的结合、基于进化算法的终身架构搜索、以及针对 LLM 的参数高效架构搜索。

### 22.2 小样本持续学习

小样本持续学习（Few-Shot Continual Learning）假设每个新任务只有少量标注样本。这在真实场景中非常常见，因为新任务数据收集昂贵。挑战包括：
- **过拟合**：少量样本容易导致模型过拟合新任务。
- **快速遗忘**：少量新样本可能迅速覆盖旧知识。
- **元学习能力**：模型需要利用旧任务学到的先验，快速泛化到新任务。

方法包括：
- **元学习初始化**：如 MAML，使模型能够快速适应少量样本。
- **原型网络（Prototype Networks[^71]）**：为每个类别维护原型向量，新样本更新原型。
- **记忆增强**：使用外部记忆存储关键样本或原型。
- **数据增强与合成**：通过生成模型扩充小样本数据。

### 22.3 零样本持续学习

零样本持续学习（Zero-Shot Continual Learning）要求模型在没有见过新任务样本的情况下识别新类别，通常通过语义嵌入或属性描述实现。例如，新类别由文本描述定义，模型利用语义空间对齐进行泛化。这在开放世界持续学习（Open-World Continual Learning）中尤为重要。

### 22.4 开放世界持续学习

开放世界持续学习不仅要求模型学习新类别，还要识别未知类别（open-set recognition）并动态扩展类别空间。关键问题包括：
- **未知类别检测**：判断输入是否属于已知类别。
- **新类别发现**：在未标注数据中发现新类别。
- **动态类别空间**：类别数量随时间增长，分类器需要动态扩展。
- **无任务边界**：没有任务身份提示。

### 22.5 与 LLM 的联系

LLM 的上下文学习和 RAG 使其天然适合小样本和零样本场景。通过 prompt 提供少量示例或语义描述，LLM 可以快速适应新任务。然而，这种适应通常是瞬时的，不会持久化到模型参数中。将小样本学习与参数高效持续学习结合，可以在保持参数更新的同时减少对大量数据的依赖。

## 24. 持续学习与因果推断[^77]、世界模型

### 24.1 因果推断视角下的持续学习

传统持续学习主要关注相关性和分布的保持，但现实世界中的知识往往具有因果结构。因果推断（Causal Inference）为持续学习提供了更深刻的视角：模型不仅要记住“X 和 Y 同时出现”，还要理解“X 是否导致 Y”。这种理解对于知识的稳健迁移、干预和反事实推理至关重要。

在持续学习中引入因果推断的好处包括：
- **稳健性**：基于因果关系的知识对分布变化更具鲁棒性。
- **可解释性**：因果图或结构方程模型可以解释模型为何做出某些决策。
- **干预能力**：模型可以预测对系统施加干预后的结果，而不仅仅是观察结果。
- **知识整合**：当新知识与旧知识冲突时，因果结构有助于判断哪部分知识需要更新。

### 24.2 因果持续学习方法

因果持续学习的研究仍处于早期阶段。一些方向包括：
- **因果表示学习**：学习解耦的因果变量表示，使模型能够独立更新不同因果机制。
- **因果发现持续学习**：在数据流中持续发现和更新因果图。
- **反事实回放**：生成反事实样本作为回放数据，增强模型对因果关系的理解。
- **不变风险最小化[^78]（IRM[^79]）**：学习在多个环境中都保持不变的风险最小化预测器，这本质上与因果推断中的不变性原则一致。

### 24.3 世界模型与持续学习

世界模型（World Models[^80]）指模型对环境动态的内部表示。在强化学习和具身智能中，世界模型使智能体能够进行规划、预测和想象。持续学习在世界模型中的应用包括：
- **环境动态更新**：当环境规则变化时，更新世界模型。
- **记忆与想象**：利用世界模型生成未来情景，作为回放或规划数据。
- **模型预测控制（MPC）**：基于持续学习的世界模型进行长期决策。

Ha 与 Schmidhuber[^81] 2018 年的 World Models 工作展示了如何训练一个低维世界模型来学习环境动态。在持续学习中，这种世界模型需要不断更新以反映环境变化，同时保持对旧环境动态的记忆。

### 24.4 因果与世界模型在 LLM 中的应用

对于 LLM，因果推断和世界模型可以帮助：
- **事实推理**：区分相关性和因果性，避免错误因果推断。
- **科学发现**：在持续吸收科学文献时，识别因果关系而非表面相关。
- **安全评估**：通过因果干预评估模型输出的敏感性。
- **反事实解释**：解释如果输入中的某些因素改变，输出会如何变化。

### 24.5 挑战与未来方向

- **因果识别**：从观测数据中学习因果结构本身困难，在持续学习中更难。
- **计算成本**：因果推断和世界模型训练计算开销大。
- **与 LLM 结合**：如何将符号化的因果知识与神经语言模型结合仍开放。
- **评估基准**：缺乏标准的因果持续学习基准。

## 25. 持续学习中的不确定性、校准与可靠性

### 25.1 不确定性估计的重要性

在持续学习中，模型需要知道自己知道什么、不知道什么。不确定性估计（Uncertainty Estimation）对于安全部署至关重要：
- **检测分布外样本**：判断输入是否来自未学习的任务或领域。
- **避免幻觉**：当模型不确定时，选择拒绝回答或请求更多信息。
- **决策支持**：在高风险领域（医疗、法律），不确定性可以帮助人类决策者判断何时需要人工审核。
- **主动学习**：选择不确定性高的样本进行标注，提高样本效率。

### 25.2 不确定性类型

- **偶然不确定性（Aleatoric Uncertainty）**：数据本身固有的噪声。
- **认知不确定性（Epistemic Uncertainty）**：模型由于训练数据不足而产生的知识缺口。
- **分布不确定性（Distributional Uncertainty）**：输入来自训练分布之外。

在持续学习中，认知不确定性尤为重要，因为模型在不断遇到新任务时，需要估计自己对新任务的知识缺口。

### 25.3 校准（Calibration）

模型校准指模型预测概率与实际正确率一致。例如，如果模型预测某类概率为 0.8，那么该类样本中应有约 80% 确实属于该类。持续学习可能导致模型校准变差：新任务训练后，模型可能对旧任务过度自信或自信不足。

校准方法包括：
- **温度缩放[^82]（Temperature Scaling）**：在推理时调整 softmax 温度。
- **Platt Scaling / Isotonic Regression**：用验证集拟合概率映射。
- **贝叶斯方法**：通过后验分布估计不确定性。
- **集成方法**：多个模型或检查点的集成提供更可靠的不确定性。

Guo 等人 2017[^83] 年的工作 On Calibration of Modern Neural Networks 系统研究了现代神经网络的校准问题，并提出了温度缩放等简单有效的方法。

### 25.4 可靠性工程

持续学习系统的可靠性涉及：
- **监控漂移**：检测输入分布、输出分布和性能指标的变化。
- **回滚机制**：当更新导致性能下降时自动回滚。
- **安全护栏**：在模型输出前进行过滤和验证。
- **人机回环**：在关键决策中引入人类审核。
- **测试覆盖**：对新任务、旧任务、边界案例和对抗案例进行全面测试。

### 25.5 LLM 中的不确定性与校准

LLM 的不确定性估计具有挑战性，因为：
- 输出空间巨大，难以直接估计概率校准。
- 自回归生成引入了累积不确定性。
- 模型可能通过高置信度表达错误信息（幻觉）。

方法包括：
- **语义不确定性（Semantic Uncertainty[^84]）**：基于生成文本的含义而非 token 概率估计不确定性。Kuhn 等人[^85] 2023 年提出了针对自然语言生成的语义不确定性方法。
- **自问自答（Self-Consistency）**：多次采样并检查一致性。
- **检索验证**：用外部知识库验证模型输出。
- **Token 级与序列级不确定性**：结合 token 概率和序列级一致性。

## 26. 持续学习的经济、环境与社会影响

### 26.1 经济影响

持续学习有望显著降低 AI 系统的总拥有成本（TCO）：
- **减少重新训练成本**：通过增量更新避免从头训练大模型。
- **延长模型生命周期**：模型可以随时间演进，保持竞争力。
- **个性化服务**：为不同用户和场景提供定制化模型，创造新的商业模式。
- **知识沉淀**：组织可以通过持续学习将经验和数据转化为模型能力。

然而，也需要考虑：
- **基础设施投资**：持续学习系统需要数据管道、训练平台、监控系统。
- **人才成本**：需要具备 MLOps、持续学习、安全对齐等复合技能的团队。
- **风险成本**：如果持续学习引入错误或偏见，可能造成经济损失或声誉损害。

### 26.2 环境影响

大模型的训练和推理消耗大量能源。持续学习的环境影响包括：
- **正向影响**：避免频繁全量重训练，可能减少总体能耗。
- **负面影响**：持续的小规模更新累积起来也可能消耗大量能源；复杂回放、检索和专家系统可能增加推理能耗。
- **绿色 AI[^86]**：需要优化训练效率、使用可再生能源、减少不必要的更新和实验。Schwartz 等人[^87] 2020 年提出的 Green AI 理念强调，在追求性能的同时必须考虑环境影响。

### 26.3 社会影响

持续学习对社会的影响是深远的：
- **信息更新**：新闻媒体、教育内容、科学知识可以更快地反映在 AI 系统中。
- **公平与包容**：如果设计得当，持续学习可以帮助模型适应多元文化和语言。
- **权力集中**：能够持续训练和更新大模型的组织可能获得更大技术优势。
- **劳动市场**：自动化能力的持续扩展可能影响就业结构。
- **民主与信息生态**：模型的持续更新如何影响公共 discourse、选举和信息可信度，需要谨慎治理。

### 26.4 负责任创新[^88]与治理

为了最大化持续学习的正面影响并最小化风险，需要：
- **多学科合作**：技术、伦理、法律、社会科学共同参与。
- **透明报告**：公开模型训练数据、更新历史、能力边界和已知风险。
- **公众参与**：让受影响群体参与决策，特别是涉及价值观和偏好的更新。
- **国际协调**：在全球化背景下，持续学习系统的治理需要跨国合作。

负责任创新（Responsible Innovation）框架由 Stilgoe 等人[^89] 2013 年提出，强调在创新过程中考虑预期、反思、包容和响应性。这一框架对于持续学习系统尤为重要，因为其长期演化特性使得治理必须贯穿整个生命周期。

## 27. 持续学习研究的方法论与实验设计建议

### 27.1 实验设计原则

好的持续学习实验应遵循以下原则：
- **明确问题设定**：是 Task-IL、Class-IL、Domain-IL 还是 task-free？是否已知任务边界？
- **选择合适基准**：根据研究问题选择视觉、NLP、多模态或机器人基准。
- **控制变量**：固定模型架构、优化器、训练步数、批次大小等，只改变持续学习方法。
- **多次随机种子**：报告均值和标准差。
- **任务顺序敏感性**：测试不同任务顺序，避免结果依赖特定顺序。
- **联合训练上界**：报告所有数据联合训练的上界，作为持续学习方法的目标。

### 27.2 超参数调优

持续学习方法对超参数敏感，包括：
- 回放比例/缓冲区大小。
- 正则化强度（如 EWC 的 lambda）。
- 学习率和学习率调度。
- LoRA rank / Adapter 维度。
- 专家数量和路由温度。

建议使用验证集或单独的开发任务进行超参数搜索，避免在测试任务上过拟合。

### 27.3 报告规范

论文和报告应至少包含：
- 平均准确率（Avg.Acc）和遗忘率（Forgetting Rate）。
- 后向迁移（BWT）和前向迁移（FWT）。
- 新任务准确率和旧任务准确率随时间的变化曲线。
- 通用能力保持率（对于 LLM）。
- 计算和存储开销。
- 定性分析：失败案例、可视化、专家激活模式等。

### 27.4 可复现性

为了提高可复现性：
- 开源代码和训练脚本。
- 提供随机种子、超参数和硬件环境。
- 发布训练后的检查点和评估日志。
- 使用标准化库（如 Avalanche、PyCIL、HuggingFace PEFT）。

### 27.5 从研究到产品

将持续学习研究转化为产品需要考虑：
- **数据管道**：如何高效、合规地收集和清洗数据。
- **更新频率**：实时、小时级、天级还是周级？
- **A/B 测试**：在小流量上验证更新效果。Kohavi 等人[^90] 2020 年的 A/B 测试专著系统讨论了在线实验设计与可信决策。
- **监控与告警**：持续跟踪性能、安全性和用户反馈。
- **回滚与恢复**：确保可以快速恢复到稳定版本。
- **治理流程**：明确谁有权触发更新、审批更新和处理事故。

### 27.6 培养持续学习思维

对于工程师和研究人员，持续学习不仅是技术栈，更是一种系统思维：
- 承认世界是动态和非平稳的，模型需要不断演进。
- 在设计和训练时就考虑未来的更新和遗忘。
- 将对齐、安全、隐私和可解释性作为一等公民。
- 建立反馈回路，使模型能够从实际部署中学习。
- 保持谦逊：持续学习系统永远无法完美，需要人类监督和干预。



## 28. 总结与读者指南

经过前面二十七章的系统性梳理，我们已经看到，持续学习（Continual Learning, CL）已经从早期连接主义网络中的“灾难性遗忘”问题，演变为支撑大语言模型（LLM）终身进化的核心范式之一。McCloskey 与 Cohen 在 1989 年揭示的序列学习干扰现象，到今天仍在以新的形式困扰着千亿参数模型的持续预训练、指令微调、对齐、工具学习与多模态扩展。理解持续学习，不仅有助于缓解遗忘，更是通往可靠、可扩展、可问责的人工智能系统的必经之路。

### 28.1 从灾难性遗忘到终身智能：核心脉络回顾

持续学习的核心矛盾可以概括为“稳定性—可塑性困境”：模型既要保留旧知识，又要快速吸收新信息。传统深度学习通过独立同分布假设下的经验风险最小化（ERM）获得优异性能，但在非平稳数据流中，参数更新会覆盖先前任务的关键权重，造成灾难性遗忘。Kirkpatrick 等人提出的 EWC、Zenke 等人的 SI、Li 与 Hoiem 的 LwF 等正则化方法，通过约束重要参数或蒸馏旧输出来缓解遗忘；iCaRL、GEM、A-GEM 等则引入经验回放与梯度投影，用显式记忆换取稳定性。这些方法奠定了经典持续学习的理论基础，并被 De Lange 等人、Parisi 等人系统总结。

进入大模型时代，问题规模与形式发生了质变。首先，LLM 的参数规模使得全量微调成本高昂，催生了 LoRA、Adapter、Prefix Tuning、Prompt Tuning、IA³ 等参数高效持续学习方法。其次，LLM 的训练流程被拆分为预训练、指令微调、人类反馈强化学习（RLHF）/DPO 等阶段，每个阶段都可能引入新的数据分布、价值观与能力，要求我们在每个阶段都考虑遗忘与对齐税。TRACE、CIBT 等基准正是为了量化和比较这些能力而设计。再者，LLM 不仅是文本模型，还逐步扩展为多模态模型、具身智能体和工具使用者，持续学习必须同时处理视觉、音频、视频、传感器信号、API 调用与外部记忆。

### 28.2 方法选型的决策树

面对如此繁多的方法，研究者和工程师需要根据具体场景做出选择。一条简化的决策路径如下：

1. 是否有充足的新任务数据与计算资源？
   - 是，且任务数量较少：可直接全量微调并结合经验回放（如 iCaRL、DER[^91]）。
   - 否，或任务序列很长：优先选择参数高效方法（LoRA、Adapter、Prompt Tuning）或基于 Replay 的轻量方案。

2. 旧数据是否可保存？
   - 可保存：使用真实回放（Experience Replay）或特征回放（Feature Replay），配合 FOSTER[^92]、MEMO[^93] 等特征压缩技术。
   - 不可保存：使用生成回放（如 Deep Generative Replay、合成数据生成）或正则化方法（EWC、SI、LwF）。

3. 模型是封闭 API 还是可修改权重？
   - 可修改权重：PEFT、知识编辑（ROME、MEMIT、WISE）或模块化/MoE 方法（LoRAMoE、LIMoE）。
   - 封闭 API：依赖 RAG、上下文学习（ICL）、Chain-of-Thought[^94]、长期记忆模块等非参数路径。

4. 是否需要处理多模态、工具或智能体能力？
   - 是：考虑 FuseMoE[^95]、Flex-MoE[^96]、MERGE[^97] 等多模态持续学习方法，以及 Reflexion[^98]、Generative Agents[^99] 等 Agent 自反思机制，并配套 MLLM-CTBench 等评估基准。

5. 对安全、隐私、可解释性有无硬性要求？
   - 有：引入机器遗忘、差分隐私、联邦持续学习、不确定性估计、红队测试与因果推断等方法，并通过 A/B 测试评估真实影响。

### 28.3 面向研究者的开放问题清单

尽管近五年持续学习与大模型交叉领域取得了长足进展，以下问题仍然开放：

- 可塑性损失的深层机制：Lyle 等人[^100]指出，深度网络在长期训练后会出现可塑性损失（Loss of Plasticity），即使未见灾难性遗忘，模型学习新分布的能力也会下降。如何在 LLM 中通过优化器状态、激活函数、归一化策略与学习率调度维持可塑性，仍是未解之谜。
- 知识表示的几何结构：不同任务的知识在权重空间、激活空间与注意力模式中如何组织？模块化网络（如 Progressive Neural Networks、MoE）能在多大程度上实现可解释的知识分区？
- 多阶段训练中的遗忘链：预训练、指令微调、对齐、工具学习、多模态对齐的串联会放大误差与价值观漂移。如何建模并量化跨阶段的“复合遗忘”？
- 评估指标的一致性：现有指标（BWT、FWT、Average Accuracy、Final Accuracy、Forgetting Rate 等）在不同基准上定义不一，且难以同时衡量稳定性、可塑性、泛化、安全与效率。Wu 等人与 Shi 等人的综述呼吁建立更统一的评估框架。
- 社会—技术反馈回路：模型持续学习会引入人类反馈、社会互动与新数据源，可能放大偏见、错误信息与权力不对称。Stilgoe 等人提出的负责任创新框架提醒我们，技术评估必须与社会影响评估并行。

### 28.4 面向工程师的落地 checklist

将持续学习系统部署到生产环境时，建议遵循以下 checklist：

- 数据管道：建立任务边界检测、数据质量过滤、去重、毒性检测与版本控制机制；新任务上线前进行分布偏移检测。
- 模型版本：每次持续学习迭代后保存模型快照、LoRA 适配器或知识编辑补丁，并记录训练数据、超参数与评估结果。
- 回放与记忆：根据存储预算选择固定缓冲、环形缓冲、特征回放或生成回放；定期使用旧任务验证集监控遗忘曲线。
- 监控与告警：部署 BWT/FWT、Average Accuracy、Perplexity、ECE、毒性检测、输出一致性等指标的持续监控；设置漂移阈值与回滚策略。
- 安全与合规：对欧盟 GDPR、AI Act、中国《生成式人工智能服务管理暂行办法》等法规保持敏感；对需要删除的数据实施机器遗忘或差分隐私训练。
- 成本与碳足迹：使用 Schwartz 等人提出的 Green AI 原则，记录训练 FLOPs、能耗与碳排放，优先选择参数高效方法与小规模实验。

### 28.5 可复现性、伦理与长期影响

持续学习系统的可复现性面临多重挑战：任务序列顺序、数据增强策略、随机种子、硬件差异、checkpoint 选择甚至评估脚本版本都会影响结果。研究者应当公开任务顺序、代码、模型权重与训练日志，并尽可能在 TRACE、CLiMB、CIBT 等公共基准上报告结果。同时，需警惕“进展性偏置”（progressive bias）：模型在持续学习中不断暴露于新数据，可能强化近期流行的观点，稀释少数群体与历史知识。

伦理层面，持续学习放大了几个经典风险：隐私泄露（通过回放数据或模型参数推断训练样本）、模型篡改（通过持续更新注入后门或偏见）、价值观漂移（对齐税）与不可解释决策（尤其是 MoE 与知识编辑的局部修改）。Kohavi 等人强调，在线实验与 A/B 测试必须以用户福祉为核心指标，而非仅优化短期 engagement。

长期来看，持续学习是通向“终身智能体”的必由之路。一个能够持续阅读、反思、工具调用、社会交互并自我更新的 AI，将在科学研究、教育、医疗与创意产业中扮演重要角色。然而，这种能力也意味着更大的责任：我们需要在技术架构中内建可审计性、可撤销性与人类监督机制，确保智能系统的演化方向符合公共利益。

### 28.6 进一步阅读路线图

对于不同背景的读者，我们建议以下阅读路径：

- 初学者：先阅读 Parisi 等人与 De Lange 等人的综述，理解灾难性遗忘、正则化与回放的基本概念；再阅读 Brown 等人[^101]的 GPT-3 论文，理解大模型的 few-shot 学习能力。
- LLM 持续学习：Wu 等人与 Shi 等人的两篇综述提供了 2024—2025 年的全景；TRACE 与 CIBT 是必读的基准论文。
- 参数高效与模块化方法：精读 Hu 等人的 LoRA、Shazeer 等人的 MoE，以及 Wang 等人的 Learning to Prompt。
- 知识编辑与 RAG：Wang 等人的知识编辑综述、Lewis 等人的 RAG、Borgeaud 等人的 RETRO[^102] 是核心文献。
- 多模态与具身学习：CLiMB、FuseMoE、MERGE 与 MLLM-CTBench 提供了前沿视角。
- 安全与伦理：Ganguli 等人的红队测试、Bourtoule 等人[^103]的机器遗忘、Voigt 与 von dem Bussche 的 GDPR 指南、Stilgoe 等人的负责任创新框架。

持续学习与大语言模型的交叉研究仍处于快速演化之中。本文试图在理论、方法、评估与应用之间架起一座桥梁，帮助读者在复杂的技术丛林中找到方向。无论未来的 LLM 变得多么庞大与复杂，一个根本问题不会改变：如何在时间的河流中既记住过去，又不断学习未来。对这一问题的回答，将定义下一代人工智能系统的边界与可能性。





## 29. 持续学习研究的实验设计与跨学科影响

前面的综述主要聚焦于算法、模型与工程实现。然而，持续学习研究的最终价值不仅取决于方法本身，还取决于实验设计是否严谨、问题定义是否清晰、评估是否公正，以及研究成果能否跨学科迁移。本章从方法论、跨学科影响与未来研究伦理三个角度，为读者提供进一步的思考框架。

### 29.1 实验设计中的关键变量

持续学习实验通常比传统单任务实验复杂一个数量级。首先，任务序列的定义直接决定结论：任务边界是清晰的类别划分，还是连续的时间窗口？不同任务之间是否共享类别？类别增量（class-incremental）、任务增量（task-incremental）与领域增量（domain-incremental）三种设置下的最优方法往往截然不同。其次，任务顺序会显著影响遗忘曲线与迁移效果：将困难任务放在前面可能为后续任务提供良好初始化，也可能因早期过拟合导致后续适应困难。研究社区逐渐意识到，报告单一任务顺序的平均结果远远不够，应同时报告多个随机顺序、反转顺序以及“最坏情况”顺序的结果。

超参数的选择同样是实验偏差的温床。回放方法依赖缓冲大小；正则化方法依赖权重系数；PEFT 方法依赖秩、学习率与适配器数量；知识编辑方法依赖编辑层位置与键值对配置。由于持续学习在不同任务上存在强耦合，对每个方法使用单独 tuned 的超参数可能夸大优势，而固定统一超参数则可能低估某些方法。一种折中方案是：为每个方法提供一个小验证集进行轻量调参，但公开所有调参过程与随机种子，避免“隐式过拟合”。

数据增强与预处理策略也需要统一。例如，在视觉持续学习中，对旧任务图像使用强增强可能人为提升回放数据多样性，但会改变分布；在 NLP 中，对旧文本做 paraphrase 生成回放可能引入语义漂移。实验报告应明确说明数据增强、分词方式、上下文长度、截断策略与批大小，因为这些细节在跨论文比较时往往被忽略。

### 29.2 基准、指标与统计显著性

 TRACE 与 CIBT 等基准为 LLM 持续学习提供了统一任务集合，但它们主要覆盖语言理解与推理。若研究面向多模态或具身智能，应补充 CLiMB、MLLM-CTBench 等视觉—语言基准，或自建基于真实环境交互的任务流。评估指标应至少包括：平均准确率（Average Accuracy）、最终准确率（Final Accuracy）、遗忘率（Forgetting Rate）、正向迁移（Forward Transfer）、反向迁移（Backward Transfer）以及学习曲线面积（Learning Curve Area）。对于 LLM，还需报告通用能力保持率（如 MMLU、GSM8K、TruthfulQA 等）与任务特定能力增益，以量化通用性与专用性的 trade-off。

统计显著性方面，持续学习实验涉及多个任务与多个随机顺序，简单的 t-test 可能不够。建议采用混合效应模型（mixed-effects model）将任务顺序与随机种子作为随机效应，方法作为固定效应，从而分离“方法效应”与“顺序噪声”。此外，报告置信区间比单纯报告均值更能反映稳定性，因为某些方法在个别顺序上表现极差，可能暴露潜在脆弱性。

### 29.3 从机器学习到认知科学与神经科学

持续学习的研究灵感部分来自人类认知：人类能够在一生中不断学习新技能，同时保留旧知识，且不会像神经网络那样发生灾难性遗忘。神经科学中的“系统巩固”理论认为，海马体负责快速学习新经历，而皮层负责缓慢整合与长期存储；睡眠过程中的重放（replay）有助于将海马体表征转移到皮层。这启发了深度学习中的双记忆系统、生成回放与经验重放机制。然而，人工神经网络的持续学习仍与人脑有本质差距：大脑通过结构可塑性、神经发生（neurogenesis）、突触缩放（synaptic scaling）与多尺度巩固实现灵活稳定的记忆，而当前模型主要依赖参数优化与外部存储。

认知科学中的“迁移学习”与“元认知”概念也为持续学习提供了隐喻。人类能够判断自己知道什么、不知道什么，并据此选择学习策略；这对应于持续学习中的不确定性估计、选择性学习与主动学习。未来研究可以借鉴认知科学，开发能够自主决定是否学习、何时复习、何时寻求外部帮助的“元持续学习”系统。

### 29.4 持续学习的社会—技术系统视角

持续学习模型往往不是孤立运行，而是嵌入搜索引擎、推荐系统、对话助手、编程工具与科学发现平台中。在这些社会—技术系统中，模型的持续更新会改变用户行为、内容生态与权力结构。例如，推荐系统的持续学习可能放大“过滤气泡”：模型越学习用户当前偏好，越难推荐多元内容；对话助手的持续学习可能吸收网络上新兴的偏见或错误信息，并迅速影响大量用户。因此，持续学习的研究必须与传播学、社会学、法学与伦理学对话。

从法学视角，持续学习挑战了“被遗忘权”与“算法问责”的实现。如果模型已经通过持续学习吸收了用户数据，删除原始数据未必能消除模型中的对应知识；机器遗忘  提供了部分技术解，但其可证明性、审计性与法律认可度仍处于早期阶段。从经济学视角，持续学习可以降低模型训练成本、延长模型生命周期，但也可能导致模型更新频率过高、市场垄断加剧（只有大公司能承担高频持续学习），并引发就业与知识产权问题。研究者应在技术论文中增加对这些社会影响的简要讨论，避免把技术从社会语境中剥离。

### 29.5 可复现性、开放科学与社区治理

持续学习研究的开放科学面临特殊挑战：许多方法依赖特定任务顺序、私有数据或大规模计算资源。为了提高可复现性，作者应至少提供：任务序列生成脚本、训练与评估代码、最终模型 checkpoint（若条件允许）、超参数配置文件、随机种子列表以及原始结果表格。基准维护者应建立版本控制机制，因为任务顺序或提示词模板的小改动可能显著改变排名。社区治理方面，持续学习涉及多个子领域（计算机视觉、自然语言处理、强化学习、机器人、推荐系统），需要跨会议、跨组织的协作。Avalanche、FedML、Flower 等开源库已经在降低研究门槛，但跨库、跨基准的元研究仍较少。

### 29.6 面向未来十年的研究议程

展望未来十年，持续学习与大语言模型领域有若干高影响力研究方向：

1. **终身预训练（lifelong pre-training）**：构建能够从互联网持续流式数据中学习、不断扩展知识边界的大型模型，同时保持事实一致性、价值观稳定与推理能力。这需要新的优化目标、记忆架构与评估协议。
2. **可遗忘的终身学习（forgettable lifelong learning）**：在持续学习的同时，支持精确、可审计、可验证的知识删除，以符合隐私法规与伦理要求。机器遗忘与差分隐私需要从大语言模型的尺度与动态性出发重新设计。
3. **物理世界中的持续学习**：将 LLM 与机器人、传感器、可穿戴设备结合，使模型在真实物理环境中持续适应。挑战包括非平稳奖励、安全约束、样本稀缺与实时性要求。
4. **社会学习（social learning）**：让模型通过多智能体交互、人类反馈、工具使用与网络信息持续进化，而不是仅依赖静态数据集。这涉及信息可信度、群体偏见、意见动态与激励机制。
5. **可解释的持续学习**：理解模型在持续学习过程中具体记住了什么、忘记了什么、哪些参数负责哪些知识。知识编辑、神经激活分析与模块化网络为这一目标提供了工具，但距离可解释还有很远。
6. **绿色与公平的持续学习**：在降低计算与碳成本的同时，确保持续学习系统不会加剧数字鸿沟、文化偏见或知识垄断。Green AI 原则应贯穿数据选择、模型架构、训练策略与部署决策。

### 29.7 结论：技术、科学与社会责任的交汇

持续学习不仅是一个机器学习子领域，它触及智能系统如何与时间、数据、社会互动的根本问题。大语言模型的兴起让持续学习从“分类任务中的抗遗忘技巧”跃升为“构建终身智能体的核心能力”。从正则化、回放到参数高效适配，从知识编辑到 RAG，从模块化架构到多模态与智能体系统，我们已经积累了丰富的方法论。然而，真正可靠的终身智能体还需要解决可塑性损失、复合遗忘、社会反馈、价值漂移、可审计性与可遗忘性等深层问题。

最终，持续学习的研究者、工程师与决策者需要共同承担起责任：不仅要追求更高的准确率与更低的遗忘率，还要确保这些系统尊重用户隐私、维护社会公平、支持科学诚信，并在长期演化中保持人类监督。只有当技术进步与社会责任同频共振时，持续学习才能真正实现其愿景——让机器像人类一样，在时间中不断学习、成长，并明智地记住过去。





## 30. 给研究者与研究团队的实践建议

持续学习是一个既需要深厚理论功底、又需要大量工程调试的领域。对于刚进入该方向的研究者，以及希望将持续学习落地到产品的团队，以下几点经验可能有所帮助。

### 30.1 如何选择研究切入点

初学者应从经典基准入手，例如 Permuted MNIST、Split CIFAR、CIFAR-100 或 SeqMNIST，因为这些任务数据小、训练快、现象清晰，便于观察灾难性遗忘与不同方法的效果。理解 EWC、LwF、iCaRL、GEM、A-GEM 等方法后，再进入大模型方向。对于已有深度学习经验的研究者，建议直接瞄准 LLM 持续学习中的具体问题，如“指令微调后的通用能力保持”“新知识编辑与旧知识冲突”“多模态模态间的遗忘传递”等。问题驱动比方法驱动更容易产生有意义的研究成果。

### 30.2 代码与工程习惯

持续学习实验极易因数据顺序、随机种子、checkpoint 保存方式与评估脚本差异而难以复现。建议从项目第一天起就使用版本控制记录任务序列、超参数与评估脚本，每次实验保存完整的配置快照。不要依赖 Jupyter Notebook 做最终实验，因为难以追踪执行顺序与随机状态。Replay 缓冲应保存为独立文件并记录元信息，以便后续分析哪些样本对遗忘控制最关键。对于 LLM，建议使用参数高效微调而非全量微调，除非计算预算特别充足；同时保留多个 LoRA 或适配器版本，便于快速对比与回滚。

### 30.3 与社区协作

持续学习社区分散在 CV、NLP、RL、机器人与推荐系统等多个领域。积极关注 CVPR、ICML、NeurIPS、ICLR、ACL、EMNLP 等会议上的相关 workshop，如 Continual Learning Workshop、Lifelong Learning Workshop、Causal Representation Learning Workshop 等。开源贡献是快速建立影响力的有效途径：为 Avalanche、PyCIL、 continual-learning-benchmarks 等库修复 bug、补充新基准或实现新论文，不仅能加深理解，也能获得同行反馈。跨学科合作方面，可与认知科学、伦理学、法学与社会科学研究者交流，把持续学习放在更广阔的社会语境中思考。

### 30.4 产品落地的务实心态

在工业场景中，持续学习往往不是“训练一次就上线”的终点，而是长期运维的起点。团队应建立“数据版本—模型版本—评估指标”三位一体的监控闭环。新数据到来时，先在小流量环境中做 A/B 测试，再逐步扩大；若发现旧指标显著下降，应立即回滚到上一稳定版本。对于高风险场景（医疗、法律、金融、自动驾驶），持续学习更新应经过人工审批与红队测试，避免模型因单批问题数据而退化。还要明确“持续学习”的边界：并非所有任务都适合在线持续更新，某些时候定期全量重训练反而更可控、更经济。最终，选择持续学习方案时应综合考虑准确率、遗忘率、延迟、成本、可解释性与合规风险，而不是单纯追求最低遗忘率。

### 30.5 结语

持续学习的研究旅程既充满挑战，也充满机遇。随着大语言模型与多模态智能体的发展，我们正站在从“一次性训练模型”向“终身演化系统”转型的关键节点。愿本章与前面各章的系统性梳理，能为读者在这一领域提供可靠的导航图。





## 31. 资源索引与延伸阅读建议

为了帮助读者在实践中快速定位信息，本章整理关键资源、课程、代码库与前沿论文，作为全文的补充导航。

### 31.1 经典课程与教程

对于希望系统学习持续学习的读者，推荐以下课程与教程。Stanford CS330 “Multi-Task and Meta-Learning” 涵盖元学习与多任务学习的理论基础，其中多个主题与持续学习直接相关。DeepMind 与 UCL 合作的“Advanced Deep Learning and Reinforcement Learning”课程讨论了神经网络的记忆、可塑性与回放机制。国内高校如清华大学、北京大学、上海交通大学也开设了面向 NLP 与多模态大模型的前沿课程，其中持续学习与模型编辑是常见专题。在线平台如 YouTube、Bilibili 上的 ACL、NeurIPS、ICML 官方录播与知名研究者讲座，也是跟进最新进展的宝贵来源。

### 31.2 关键代码库与工具

实现持续学习离不开高质量工具。Avalanche 是视觉持续学习领域最全面的 Python 库，支持 iCaRL、EWC、GEM、A-GEM、LwF 等经典方法，并提供统一基准与评估指标。PyCIL 专注于类增量学习，代码简洁、适合快速实验与复现。Hugging Face Transformers、PEFT 与 TRL 库为 LLM 持续学习与指令微调提供了基础设施；配合 DeepSpeed、FSDP 与 vLLM 可实现大规模训练与推理。对于多模态持续学习，OpenCLIP、LLaVA 与 Qwen-VL 的代码库是重要起点。工具学习方面，Gorilla、ToolLLM[^104] 与 LangChain 提供了 API 调用与智能体编排能力。联邦持续学习可关注 Flower、FedML 与 PySyft。

### 31.3 推荐阅读顺序

初学者建议按“经典综述 → 经典方法 → 大模型持续学习 → 特定子领域”的顺序推进。先阅读 Parisi 等人 2019 与 De Lange 等人 2021 的综述，建立概念框架；再精读 EWC、SI、LwF、iCaRL、GEM 与 A-GEM 的原始论文。进入 LLM 阶段后，阅读 Wu 等人 2024 与 Shi 等人 2025 的综述，配合 TRACE、CIBT 基准论文。若关注参数高效方法，LoRA 与 O-LoRA 不可错过；若关注知识编辑，ROME、MEMIT、WISE 与 DAFNet 是核心文献；若关注多模态与工具，CLiMB、FuseMoE、ToolLLM 与 Reflexion 值得深入。

### 31.4 关注未来会议与社区动态

持续学习相关研究主要发表在 NeurIPS、ICML、ICLR、CVPR、ICCV、ECCV、ACL、EMNLP、NAACL、WWW、KDD 等顶级会议。专门的 workshop 包括 CVPR 的 Continual Learning Workshop、NeurIPS 的 Lifelong Learning Workshop 以及 ACL 的 Lifelong Language Learning Workshop。Twitter/X、Reddit、知乎、微信公众号与 arXiv 每日更新是获取前沿动态的常用渠道。中文社区如“PaperWeekly”“机器之心”“AINLP”也会持续翻译与解读重要论文。建议研究者关注几个关键研究团队：DeepMind、FAIR、Google Research、Anthropic、OpenAI、Mila、UT Austin、清华智能产业研究院、北大 AI 研究院等。

### 31.5 最后的提醒

持续学习领域发展迅速，今天的前沿方法可能很快会被新的发现取代。因此，阅读论文时要关注“问题定义”与“实验设计”，而不仅仅是“最高准确率”。同时，保持对伦理、安全与社会影响的敏感，避免陷入“技术至上”的单一视角。愿本综述成为你探索持续学习与大语言模型交叉领域的可靠起点，也希望更多研究者加入这一方向，共同推动真正可信、可用、可持续的终身智能系统。
