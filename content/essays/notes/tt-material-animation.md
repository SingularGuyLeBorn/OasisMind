# tt-material-animation：材质动画 Prompt 技能

> 整理自用户收藏的 GitHub README 截图（DCSkills/pwWheel/t-design 相关）。

## 它是什么

把用户指定的**实体材质或传统物理媒介**，转成「已确认的具体工艺 + 视觉隐喻 + 可直接复制的首尾帧图片 Prompt 与视频 Prompt」，并在可用时按确认直接生成端点图片。

- 以 **Prompt 设计**为主
- 当前会话存在 image_gen 且明确同意时，可生成端点图片
- 不生成视频，不创建项目目录、contact sheet 或 QA 文件

## 输入

- 一个创意概念、口播或观点；或已锁定的材质族 / 具体工艺 / 视觉命题 / 首尾状态 / 时长 / 画幅 / 参考素材

## 输出（三段式确认流程）

1. **材质工艺**：从 7 个材质族 / 9 种工艺中推荐最匹配的候选（跨材质推荐 3 个；指定材质族则只在族内推荐），并说明理由、材质特征、色彩方向、运动语言与取舍
2. **视觉隐喻**：2-3 个方向，每个含核心意思、开场状态、结尾状态与核心变化动作
3. **可直接复制的 Prompt**：自包含的「图片 Prompt + 视频 Prompt + 建议上传的图片清单」，**模型无关**，不依赖具体工具

## 设计要点

- **三段式确认**：先确认材质工艺 → 再确认视觉隐喻 → 最后才交付 Prompt，每一步都等用户点头，不一股脑堆给用户
- **自包含**：每个 Prompt 内置全部视觉信息（色彩、光影、构图、Avoid 清单），直接粘进任意图像/视频工具

## 材质方向举例

软陶定格、半调纸拼贴、孔版印刷、水墨晕染、毛毡、沙画……（7 材质族 / 9 工艺）

## 适用场景

做创意小视频时的材质风格探索：给定概念 → 逐步确认 → 拿到可直接用的 Prompt。
