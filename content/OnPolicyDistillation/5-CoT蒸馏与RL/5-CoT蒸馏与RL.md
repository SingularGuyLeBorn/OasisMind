# CoT 蒸馏与 RL：从模仿推理到探索策略

推理模型既需要一条能工作的初始路径，也需要在错误状态上恢复，还要有机会发现教师没有展示的新策略。离线 CoT、OPD 与 RL 分别对应这三类需求。把它们混成“多阶段训练配方”很容易记住顺序，却不知道外部条件变化后该保留哪一段。

## 1. 离线 CoT 建立可探索的起点

基础模型直接在长推理任务上做 RL，常因成功轨迹太少而得不到有效梯度。高质量 CoT 通过 SFT 教会问题分解、步骤表达和答案格式，使学生进入验证器能够偶尔给出正反馈的区域。它稳定、便于并行，缺点是只覆盖教师写下的固定路径。

冷启动是否足够，可以看学生的单样本成功率和首次错误位置。若大部分回答在开头就失去方向，继续 RL 只会消耗采样；若学生已经能频繁得到正确答案，新增离线示范的边际收益下降，探索开始有意义。

## 2. OPD 修补学生自己的中间状态

学生独立生成时会走入示范没有覆盖的前缀。OPD 在这些前缀上查询教师或条件化自教师，提供下一步分布、续写或反馈。它比终局零奖励更容易指出局部纠正方向，也比继续堆固定 CoT 更贴近部署分布。

[推理冷启动与在线校正](5.1-推理冷启动与在线校正/5.1-推理冷启动与在线校正.md)讨论两阶段之间为何衔接；[CoT 训练链](5.1-推理冷启动与在线校正/5.1.1-CoT训练链.md)给出离线 CoT、参考解条件化和 OPD 的完整比较。在线并非目的，只有教师在学生错误状态上仍有优势时，额外查询才值得。

## 3. RL 负责教师之外的探索

蒸馏以教师行为为方向，通常受教师支持集限制。数学验证器、代码测试或规则环境能直接判断任务结果，RLVR 因而可以提高教师不偏好的成功策略。[探索与奖励接口](5.2-探索与奖励接口/5.2-探索与奖励接口.md)解释结果奖励、过程反馈和教师信号的分工；[蒸馏信号与 RL 奖励](5.2-探索与奖励接口/5.2.1-蒸馏信号与RL奖励.md)继续推导组合目标及冲突。

RL 的优势来自目标直接和策略搜索，代价是方差、奖励漏洞与大量 rollout。教师信号可用作局部引导或 KL 锚点，但权重过大时会压制探索。组合训练要看教师优势和任务优势是否同向，而不只是把两个 loss 相加。

## 4. self-play 提供新信息的方式

模型生成多个候选，验证器筛出成功轨迹，再把这些轨迹作为示范或教师条件，这条闭环常被称为 self-play 或自蒸馏。新信息并非模型凭空创造，而来自环境对候选的选择。候选越多，发现概率越高，计算预算也越大。

评估要区分搜索收益和参数收益。训练期间用大量候选找到成功案例是数据生成成本；训练后单次采样更强，才说明知识写入了参数。只报告 pass@k 很容易把二者混在一起。

## 5. 长 CoT 改变了训练难点

轨迹越长，固定示范与学生状态的偏移越大，终局奖励的信用路径也越长。生成吞吐、权重广播延迟和截断开始影响算法语义。旧轨迹在短任务上可安全复用，在长推理窄分叉处可能迅速陈旧。

长度本身也可能成为捷径。教师偏好详尽回答，判别器喜欢特定格式，答案抽取器又可能奖励冗长模板。实验应控制最大长度，报告有效推理 token 和首次错误位置，避免把“写得更长”当成“推理更强”。

## 6. 如何选择训练顺序

没有固定的 SFT→OPD→RL 三段模板。成功率接近零时先冷启动；学生错误状态丰富、教师可恢复时增加 OPD；验证器可靠且学生已能探索成功时提高 RL 比重。随着学生接近教师，蒸馏优势下降，应让任务回报承担更多选择。

这套判断也允许跳过阶段。短任务和高覆盖数据可能只需 SFT；教师不可用但验证器强，可以直接做 RL；没有可靠结果奖励却有强白盒教师时，OPD 可能成为主线。训练流程应由瓶颈决定，而不是由方法流行顺序决定。

## 7. 证据链

一条可信推理训练链会分别证明：CoT 冷启动提高了探索成功率；OPD 把首次错误向后推并改善错误状态 continuation；RL 找到教师之外的高回报策略；最终提升在相同解码和计算口径下保留。每阶段都有自己的机制指标，最终 benchmark 不能替代它们。

面对一种新推理训练算法，应判断它增加的是示范、状态覆盖、教师信息还是环境探索，再核对新增代价。这样才能解释算法为什么在某个模型规模和任务长度上成立，也能预判外部条件改变后哪一段会失效。

### 8. 推理过程不等于越长越好

CoT 的价值是把隐藏计算展开，使模型能在中间状态继续推理并接受反馈。长度只是副产物。训练若持续奖励教师式长答案，模型可能把简单题也展开成冗余步骤，增加错误机会和推理成本。应按题目难度比较所需长度，而不是把平均 token 数当作能力指标。

压缩推理与长 CoT 也不是互斥路线。训练期可借助详细教师过程提供信用，部署时再蒸馏成更短策略；压缩后中间状态减少，原先的过程监督却不再直接适用，必须重新验证短轨迹是否保留成功率。

### 9. 参考答案与验证器的覆盖差异

参考答案提供一条可行路径，验证器通常能接受一组等价解。SFT 和教师条件化擅长传递已知路径，RL 更适合在等价解空间中选择。验证器不完整时，探索可能转向漏洞；参考答案错误或单一时，蒸馏也会继承偏差。

因此训练链需要两类质量检查：示范是否正确且多样，验证器是否覆盖真实目标。二者分别决定知识转移和探索的上限。增加算法复杂度无法补偿错误的数据与奖励定义。

### 10. 与相邻章节衔接

白盒教师章节给出逐 token 与序列目标，自蒸馏章节解释参考解和环境反馈怎样构造教师，本章把这些信号放回完整推理训练链。有效性验证章节随后拆分教师预算、rollout 数和解码差异，使公式、数据来源与结果落到同一条因果链。

还要注意基础模型已经带有多少推理能力。同一套 CoT 数据对弱模型可能是必要冷启动，对强模型可能只是在固定表达风格；同一 RL 预算对前者没有成功样本，对后者却足以探索。训练阶段的价值必须相对于起点测量。

教师与学生是否共享模型家族也会影响结果。共享 tokenizer 和表达习惯能降低蒸馏难度，却可能高估方法面对异构教师时的稳定性。至少说明共享条件，并将结论限制在已验证范围。
