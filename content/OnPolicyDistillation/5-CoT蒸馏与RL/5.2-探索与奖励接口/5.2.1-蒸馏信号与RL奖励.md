# 蒸馏信号与 RL 奖励：长推理训练怎样分工

推理训练里最常见的争论是“应该蒸馏强教师，还是让模型自己做 RL”。这个二选一从一开始就把问题说窄了。蒸馏回答学生在当前状态可以向谁学，RL 回答哪些完整行为值得增加概率。教师分布稠密、方差低，却受教师支持集限制；任务奖励直接、允许探索，却在长轨迹上稀疏且高方差。真正的问题是两类信号分别解决什么缺口，以及何时会互相抵消。

## 1. 从两个目标开始

设学生策略为 $\pi_\theta$，教师为 $\pi_T$。局部 OPD 可写成学生状态上的条件分布匹配：

$$
\mathcal L_T(\theta)=\mathbb E_{s\sim d_\theta}
D_{\mathrm{KL}}\!\left(\pi_T(\cdot\mid s)\Vert\pi_\theta(\cdot\mid s)\right).
$$

RLVR 则最大化学生完整轨迹的可验证回报：

$$
J_R(\theta)=\mathbb E_{y\sim\pi_\theta(\cdot\mid x)}[R(x,y)].
$$

二者都使用学生 rollout，并不意味着学习信号相同。蒸馏目标在每个被查询前缀上告诉学生教师如何分配动作概率；结果奖励只告诉整条轨迹是否成功。前者能纠正大量没有到达终局的状态，后者能选择教师从未偏好的成功策略。

### 2. 为什么只做蒸馏会碰到上限

若学生有足够容量、状态覆盖充分且优化理想，持续匹配教师会让学生逼近教师条件分布。这个目标不会主动奖励教师低概率、但环境确认正确的新策略。教师存在固定思维模式、采样不充分或特定题型弱点时，模仿上限会直接传给学生。

reverse KL 和外推目标可能让学生比教师更尖锐，甚至沿教师相对 reference 的偏好继续推进，但这仍建立在教师概率提供的方向上。若教师没有给某个策略任何支持，单纯分布匹配很难发现它。环境探索的作用就是提供教师之外的信息。

蒸馏也可能把教师风格当能力。教师喜欢长解释、固定模板或某种步骤顺序，学生的局部 KL 会同时吸收这些特征。只看“更像教师”的评价无法判断任务能力，必须用独立验证器和一致解码测量。

### 3. 为什么只做 RL 又会很慢

长 CoT 的成功奖励可能在数千 token 后才出现。策略梯度把终局优势乘到整条序列的 log-prob 梯度上，早期正确步骤和后期错误步骤共享一个回报。多次采样与 baseline 能降低方差，却不告诉模型具体哪一步需要修改。

学生初始成功率接近零时，组内相对优势也缺少有效排序。增加候选数可以偶然找到成功轨迹，但计算量迅速增长。CoT SFT 与 OPD 的价值就在这里：先把策略带到有成功概率的区域，再让环境奖励挑选更好的完整行为。

奖励漏洞是另一条限制。答案抽取器、代码测试覆盖或格式规则都可能不完整，策略会优化验证器真正实现的函数，而不是研究者想象的任务。教师信号可以提供语义约束，却不能替代修复错误奖励。

## 4. 三种组合方式

第一种是分阶段：用 CoT SFT 冷启动，再用 OPD 校正学生错误状态，最终逐步增加 RLVR。它最容易解释，每阶段都有明确瓶颈；缺点是阶段边界人为，后期 RL 可能遗忘教师提供的细粒度行为。

第二种是联合损失：

$$
\mathcal L(\theta)=\alpha\mathcal L_T(\theta)-\beta J_R(\theta).
$$

实现简单，但 $\alpha$ 与 $\beta$ 的数值不能直接比较。蒸馏 loss 按 token 平均，任务回报按序列计算，长度和 batch 组成都会改变相对尺度。固定系数只在特定数据分布上有意义。

第三种是状态或轨迹门控。失败轨迹接受教师纠正，成功轨迹用 RL 或 MLE 巩固；教师置信度高时采用蒸馏，环境验证可靠且教师分歧大时偏向回报。这种方式更贴合信号质量，却把门控器本身变成新的估计器，需要单独验证。

### 5. 用优势形式观察冲突

sampled-token 蒸馏可以构造教师优势 $A_T(s,a)$，RL 有任务优势 $A_R(s,a)$。联合更新近似使用

$$
A(s,a)=\alpha A_T(s,a)+\beta A_R(s,a).
$$

在教师推荐动作也提高任务成功率时，两项同向，组合能降低方差。学生发现教师低概率但验证器认可的策略时，两项相反。平均相关系数会掩盖关键分叉，应统计梯度或优势夹角、冲突 token 比例，以及冲突样本最终由哪类信号主导。

若冲突主要出现在教师本身错误的题型，应该降低蒸馏权重或筛选教师；若冲突来自奖励漏洞，应修复验证器，而不是让学生“相信 RL”。两类现象在总 loss 上看起来一样，处理方向相反。

## 6. 过程奖励放在哪一层

过程奖励可以来自步骤验证器、教师批改或环境中间状态。规则验证器确认代数等式、代码执行或工具调用，信号较硬；教师批评覆盖广，却可能受风格和幻觉影响；学习型过程奖励模型又会继承标注分布。

过程奖励缩短信号路径，但不自动等于因果贡献。一条局部正确步骤可能把后续带入死路，另一条非标准步骤可能最终成功。最有说服力的评估是从被标高分的中间状态继续采样，观察成功概率是否真的更高。

把过程分数加到每个 token 时，还要明确潜在函数与奖励塑形。若塑形项不是保策略的差分形式，最优策略可能改变。这未必错误，但论文应承认优化目标已变化，而不是声称只降低方差。

### 7. self-play 如何产生训练增量

学生对同一题生成多个候选，验证器选出成功答案，再将其作为 SFT 数据、教师条件或偏好正样本。信息增量来自“候选经过环境选择”，不是参数自己教自己。候选多样性和验证器可靠性共同决定新数据质量。

只保留成功轨迹容易收缩多样性，模型会反复强化早期发现的策略。保留部分高质量失败轨迹并让教师诊断，可以维持对困难状态的覆盖。失败数据不是天然有害，关键在于它进入什么目标：直接 MLE 会复制错误，作为 OPD 状态则能产生纠正信号。

训练数据的生成策略要记录。若候选由更高温度、更多工具调用或额外搜索产生，蒸馏后单样本提升需要与这些成本分开报告。否则 self-play 的收益只是把推理时计算搬到了训练时。

## 8. 长轨迹中的归一化

按 token 平均蒸馏 loss 会让长答案贡献更多位置，按序列平均又让短答案单 token 权重更大。RL 优势若复制到每个 token，长序列总梯度也可能更大。两类信号联合时，长度偏差会互相叠加。

可分别对蒸馏和 RL 做序列内归一化，再控制 batch 中不同长度样本的权重。任何归一化都会改变“一个回答”和“一个 token”的相对价值，应通过长度分桶报告效果。只给整体平均分，很难发现模型只是学会生成更长答案。

截断同样改变目标。答案被最大长度截断后，结果奖励可能记为失败，教师局部分布却仍在前半段提供正向信号。训练器要区分真正失败与系统截断，否则会给合理前缀冲突监督。

### 9. off-policy 与轨迹复用

RL 系统常复用 rollout 做多轮更新，OPD 又可能缓存教师概率。行为策略与当前 learner 分离后，任务优势和蒸馏目标受到不同影响。sampled-token 两者都依赖行为动作概率，full-vocab KL 在已有状态上更稳定，却仍有状态分布偏移。

重要性比可修正动作采样，不会补回当前策略新访问的状态。组合训练若对 RL 使用 clipped ratio、对蒸馏直接使用缓存 logits，需要明确两部分实际优化的分布不同。可按轨迹年龄分别测量收益，找到复用窗口，而不是用一个 replay 次数覆盖所有阶段。

学生更新剧烈的 RL 早期通常更需要新鲜轨迹；后期策略稳定，适量复用更划算。教师优势也会随学生接近而下降，缓存窗口和蒸馏权重应跟随训练阶段变化。

### 10. reference 的双重身份

RL 中 reference 常用于 KL 约束，防止策略偏离初始模型；广义 OPD 中 reference 还可定义教师相对基础策略的隐式奖励坐标。两者使用相同模型时容易混淆。前者限制当前策略，后者参与构造目标方向，梯度语义不同。

若把教师 log-ratio 当作奖励，再额外加入对同一 reference 的 KL penalty，某些项可能抵消或重复。应从完整目标推导实际 token 系数，而不是把多个熟悉 loss 直接相加。系数变化后的最优分布也要说明。

reference 太弱时，教师相对优势巨大，外推容易产生极端值；reference 太接近教师，信号又很小。它的选择同时决定奖励尺度与策略空间，已经超出 checkpoint 管理问题。

## 11. 教师优势何时消失

训练早期，教师在大部分学生状态上更强，蒸馏提供稳定方向。随着学生改善，简单状态上的师生分布接近，剩余差异集中到少数困难题或风格。继续统一蒸馏可能让无关位置占据计算，还限制学生通过环境探索超越教师。

可周期性抽取当前学生前缀，比较教师与学生 continuation 成功率。优势下降到噪声范围时，降低对应状态的教师查询；困难分桶仍有优势，则保留局部蒸馏。动态分配比按固定训练步切换更符合因果链。

若学生在任务回报上已经超过教师，教师仍可能在表达、稳定性或安全约束上有价值。此时应把各维度拆开，不要用一个总胜率决定完全停止或继续模仿。

### 12. 公平比较需要哪些基线

至少包括相同 CoT 数据的 SFT、增加更多离线教师 CoT、学生状态上的教师蒸馏、相同 rollout 上只做 RLVR，以及蒸馏与 RL 组合。这样才能分离额外教师数据、状态来源和任务回报。

预算应同时报告学生生成 token、教师输入输出 token、验证器调用、更新 token 与总训练时间。等训练步不等于等计算，等样本数也不等于等教师信息。若完整 logits 和黑盒续写成本差异大，给出性能—成本曲线比单点更有用。

评测统一温度、候选数、最大长度和工具预算，并同时报告 pass@1 与更高采样预算。训练后单样本提升说明参数能力，pass@k 提升可能来自多样性或搜索，两者都重要但含义不同。

### 13. 一组可诊断的指标

最终正确率之外，记录首次错误位置、学生错误状态上的教师 continuation 优势、每位置师生 KL、成功轨迹比例、优势冲突率、答案长度和截断率。组合训练出现退化时，这些量能定位问题。

蒸馏 loss 降而正确率不升，通常是状态选择或长程信用问题；成功率升但多样性骤降，可能是结果奖励或反向 KL 过强；训练奖励升而独立验证下降，要检查奖励漏洞；教师优势下降但查询量不变，则计算分配已经过时。

指标不必全部塞进主表，但训练日志应保留，使论文结论可以被证伪。只展示最终最好 checkpoint，会隐藏阶段性崩溃和选择偏差。

## 14. 外部条件改变时旧路线为何复活

过去长 CoT 的在线蒸馏昂贵，固定教师数据更实际；并行推理、快速 rollout 和可验证奖励普及后，学生状态上的查询与 self-play 变得可行。RL 算法本身未必全新，变化的是成功样本供给、教师可访问性和系统吞吐。

模型能力也改变最优训练。弱学生没有可用探索，SFT 更重要；中等学生能产生有意义但常出错的轨迹，OPD 价值最大；强学生已有较高成功率，RL 可以利用验证器寻找教师之外的策略。这是连续变化，不是三个严格时代。

### 15. 实际决策顺序

先测基础学生成功率。接近零则补冷启动；再测教师在学生错误状态上的优势，明显则加入 OPD；随后检查验证器可靠性和学生探索成功率，足够时加入 RL。联合训练前先做分阶段 baseline，确认每类信号单独解决对应瓶颈。

组合后持续观察优势冲突和教师优势。冲突来自教师错误，就让环境主导；来自验证器漏洞，就修奖励；来自尺度失衡，就校准归一化。不能把所有冲突都交给一个全局系数搜索。

最终目标是让学生在有限计算下获得可靠的能力增量，无需给蒸馏或 RL 排出唯一胜负。教师分布负责把已有知识传得更细，环境回报告诉模型什么真正成功，探索寻找训练数据没有覆盖的路径。三者职责清楚，训练链才能随任务和规模变化，摆脱固定配方。

### 16. 用一个分叉任务手算冲突

设第一步有 $A$、$B$ 两个动作。教师给 $A$ 的概率为 $0.9$，给 $B$ 为 $0.1$；环境中 $A$ 路径成功率 $0.6$，$B$ 路径成功率 $0.8$；学生当前各取 $0.5$。教师优势会提高 $A$，任务优势长期看应提高 $B$，两者方向相反。

训练早期每条路径只采少量样本，$B$ 偶然失败时，RL 可能错误降低它，教师信号反而提供稳定性。随着采样增多，$B$ 的真实回报优势显现，继续强蒸馏会阻止学生超过教师。混合系数因此应随回报估计置信度变化，而不是由教师总体强弱一次决定。

### 17. 奖励延迟与环境状态

工具调用和 Agent 任务中，一个动作的结果可能在许多轮后出现。结果奖励需要跨环境状态回传，教师却可在每一步评估计划和调用选择。若教师只看文本、不知道工具真实返回，它的局部判断可能与最终结果冲突。

训练数据应把可见环境状态同时提供给学生与教师，或者明确教师只提供语言先验。过程奖励要区分调用格式正确、工具返回有效和最终任务完成三个层级，避免格式分数支配真实结果。

可按环境事件切分 return：工具返回后更新相关片段，其他位置保留教师指导。片段边界应由任务事件决定，而不是机械按固定 token 数切割。

### 18. 失败轨迹不是一种数据

失败可能来自早期方向错误、局部计算错误、工具故障、长度截断或验证器误判。统一给零奖励再统一查询教师，会把不同问题混在一起。应先判断可恢复性：早期错误需要回溯，局部错误适合 OPD，工具故障可能不应更新模型，截断则要调整系统预算。

成功轨迹也可能含有偶然猜测。用结果奖励做 MLE 前，可检查中间一致性或在扰动后重跑。self-play 数据的价值来自被验证的策略，不只是末尾出现正确字符串。

### 19. 蒸馏权重不应机械退火

线性降低蒸馏系数、提高 RL 系数，隐含教师优势单调下降、奖励估计单调改善。课程切换、任务分布变化或上下文变长都可能让教师优势重新上升。

更直接的控制量是当前状态上的教师 continuation 优势与回报估计置信度。前者高、后者低时偏向蒸馏；前者低、后者高时偏向 RL。估计有额外成本，可周期性抽样，而非每批控制。

复杂日程还要与简单分阶段 baseline 比较。若只带来很小提升，却增加大量教师调用和不稳定性，实际并不划算。

### 20. 跨任务泛化

教师蒸馏可能让学生记住题型，RL 可能让学生适应特定验证器。跨模板、跨难度和跨工具环境测试能区分通用推理与局部适配。改变答案格式和无关表面特征，也能暴露验证器习惯。

若组合训练改善了问题分解，首次错误位置和 continuation 成功率应在新题上同步变化；若只提高训练域总分，结论就应收窄为域内优化。最终还要在没有教师、没有额外候选的标准条件下运行，证明能力已经写入参数。

## 21. 同一条轨迹上的反事实比较

要判断教师信号与任务奖励分别改变什么，可以冻结一批学生轨迹，在关键前缀枚举少量候选动作。教师给出动作概率，验证器通过多次 continuation 估计每个动作的成功率。二者排序一致的状态适合低方差蒸馏，排序冲突的状态则暴露教师上限或回报估计噪声。

枚举无法覆盖完整词表，却能在代表性状态上提供直接证据。若教师高概率动作普遍拥有更高 continuation value，蒸馏是合理代理；若相关只在简单位置存在，教师权重就应按状态调整。

这种反事实实验也能检验过程奖励。对被过程模型判为“好”的动作继续生成，若成功率没有提高，稠密分数只是表面相关。相比最终平均分，它更接近信用分配本身。

### 22. 多目标不能压成一个模糊奖励

推理模型除了正确率，还可能要求简洁、可读、遵循格式和安全。教师分布与环境验证器对这些维度的覆盖不同。直接线性压成一个标量会隐藏冲突，也让系数变成未经说明的价值判断。

训练和评估可以保留分维度指标，再选择满足硬约束的策略。例如先要求答案正确与工具调用合法，再在可行集合中优化长度和风格。教师负责软质量时，要防止软目标压过硬结果。

不同应用的权重不同，知识库应保留变量关系而非唯一最佳系数。教师优势、验证器可靠性、延迟和推理成本共同决定工作区间。

### 23. 最小实验闭环

固定相同 rollout 可比较教师分布与结果奖励；加入组合后统计优势冲突；改变教师和生成预算得到成本曲线；在新题、统一解码、无教师辅助下复测参数泛化。四组实验分别回答信号方向、组合机制、资源效率和参数迁移。

如果组合只在更大预算下领先，应把结论写成系统收益；如果相同预算下仍领先且冲突率下降，才说明两类信号真正互补。这样的证据链比再增加一个总榜单更能解释方法。
