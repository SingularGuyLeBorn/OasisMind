# 白盒教师怎样指导学生

OPD 文献最容易混淆的地方, 是把「学生生成轨迹」和「使用 reverse KL」绑定成一个概念. 两者并不绑定. 轨迹来源决定外层期望在哪些状态上取值; 散度方向决定同一个状态上如何比较师生下一 token 分布; 是否对采样分布求导又决定当前动作是否承担未来状态的影响. 三条轴分别改变算法, 应当逐项记录.

设输入为 $x$, 回答为 $y$, 状态为 $s_t=(x,y_{<t})$. 对任意采样策略 $\mu$, 状态访问分布记为 $d_\mu(s)$. 一个统一目标是

$$
\mathcal J(\theta;\mu)=\mathbb E_{s\sim d_\mu}
\left[D_f\!\left(\pi_T(\cdot\mid s),\pi_\theta(\cdot\mid s)\right)\right]. \tag{1}
$$

当 $\mu$ 是固定数据生成策略时, 式 (1) 是 off-policy 蒸馏; 当 $\mu=\pi_{\theta_k}$ 且每轮刷新时, 式 (1) 是 stop-gradient OPD. 若让 $\mu=\pi_\theta$ 并对其参数依赖求导, 目标会多出 score-function 梯度. [GKD](2.1-局部分布匹配/2.1.1-GKD.md) 主要研究前两种之间的混合与 $D_f$ 的选择; [MiniLLM](2.2-序列目标与轨迹/2.2.1-MiniLLM.md) 从序列 reverse KL 推导后一种.

## 1. 状态分布先决定学生会在哪里犯错

### 1.1. 前缀来源改变学习位置

固定参考答案给出的前缀通常语法正确、推理连贯. 学生自由生成后的前缀可能包含错误变量、重复句段、格式破损或已经走错的中间结论. 在固定前缀上学会预测教师, 不保证学生能从自身错误状态恢复. 自回归依赖使单步误差改变后续输入, 这正是模仿学习中状态分布偏移的来源.

DAgger 的做法是让学习者执行, 再让专家标注学习者访问的状态. OPD 把专家动作扩展为下一 token 分布. 但教师分布只描述局部下一步, 并不自动提供长程信用分配. 如果学生已经走到一个无解前缀, 教师仍必须在该前缀后分配概率; 局部最合理的 token 不一定能恢复全局任务. 因而学生状态覆盖部署分布是必要改进, 不是教师监督正确性的保证.

混合 roll-in 可以在两种风险之间折中. 教师或数据前缀比例高, 状态更规整, 训练初期稳定, 但学生错误区域覆盖不足. 学生比例高, 分布匹配更直接, 但弱学生会产生大量低质量状态. 混合比例应和学生冷启动质量一起报告; 只写「使用 on-policy 数据」不足以复现实验.

### 1.2. 散度方向改变局部压力

在一个固定状态 $s$ 上, 令教师分布为 $p(v)$, 学生分布为 $q(v)$. forward KL 与 reverse KL 分别为

$$
D_{\mathrm{KL}}(p\|q)=\sum_v p(v)\log\frac{p(v)}{q(v)}, \tag{2}
$$

$$
D_{\mathrm{KL}}(q\|p)=\sum_v q(v)\log\frac{q(v)}{p(v)}. \tag{3}
$$

式 (2) 由教师概率加权. 教师认为可能而学生漏掉的 token 会产生强梯度, 因而倾向覆盖教师支持. 式 (3) 由学生概率加权. 学生已经放高概率、教师却不支持的 token 会被重点压低, 学生没有探索到的教师模式贡献很小. 两者都可以在学生前缀上计算, 所以两者都可以是 OPD.

散度方向还决定需要谁的完整分布. 精确 forward KL 的梯度可以由教师全词表概率监督学生; 精确 reverse KL 也需要学生全词表概率以及相应教师 log-prob. sampled-token 估计天然适合以学生为采样分布的量, 但一个样本无法同时重建教师低概率尾部的结构. top-$k$ 介于两者之间, 且必须说明 $k$ 由教师还是学生选择、尾部概率是否聚合.

从局部散度走到序列目标：采样梯度决定信用分配：式 (1) 若把 $d_{\pi_\theta}$ 当作常数, 梯度只更新每个已访问状态上的条件分布. 当前 token 改变未来前缀的路径被停止. 这种估计计算稳定, 可以像普通 token 级监督一样反向传播. GKD 明确采用学生生成序列, 再在序列上计算平均 token 散度;工程实现常把 rollout 与 learner 解耦, 正是这一估计的系统表达.

若目标本身是两个序列分布的 reverse KL, 轨迹概率也依赖 $\theta$. 对数导数技巧会把后续 log-ratio 汇成 reward-to-go, 当前动作因而承担未来差异. MiniLLM 的推导保留了这项, 再用单步分解、教师混合采样和长度归一化降低方差. **是否有未来回报, 取决于对哪个数学目标求导, 不能只看损失名称里有没有 reverse KL.**

有些 RL 框架把逐 token 的 $\log\pi_T-\log\pi_\theta$ 当作奖励, 并令折扣为 0. 这种实现只保留当前 token 的局部比值, 便于复用 policy-gradient 基础设施, 但没有 MiniLLM 的完整未来项. 训练日志中应区分「逐 token KL 监督」「零折扣 sampled-token reward」与「序列 reverse-KL policy gradient」.

一个三 token 走查：考虑词表只有 $\{A,B,C\}$, 某个学生前缀上教师分布为 $p=(0.7,0.2,0.1)$, 学生分布为 $q=(0.4,0.4,0.2)$. forward KL 为

$$
0.7\log\frac{0.7}{0.4}+0.2\log\frac{0.2}{0.4}+0.1\log\frac{0.1}{0.2}\approx0.184. \tag{4}
$$

reverse KL 为

$$
0.4\log\frac{0.4}{0.7}+0.4\log\frac{0.4}{0.2}+0.2\log\frac{0.2}{0.1}\approx0.192. \tag{5}
$$

两个数接近, 梯度来源却不同. 式 (4) 的最大权重落在教师的 $A$ 上; 式 (5) 对学生过量分配的 $B,C$ 更敏感. 若学生只采到 $B$, sampled-token reverse-KL 样本是 $\log0.4-\log0.2=\log2$. 该样本完全没有告诉训练器 $A$ 应从 $0.4$ 升到 $0.7$, 只有多次采样的期望才恢复式 (5).

状态再向前走一步时, 差异会扩大. 若采到 $B$ 后教师进入一个低置信状态, 下一步教师分布可能接近均匀. stop-gradient 局部训练只处理两个已观察状态; 序列目标还会把第二步的 log-ratio 归因给第一步动作 $B$. 这正是局部监督与序列信用分配的分界.

## 2. 估计器、数据接口与训练稳定性

### 2.1. 训练前检查与失效模式

第一项检查是学生起点. 如果大部分 rollout 无法通过格式解析, 教师监督会集中在格式修复, 很少进入任务核心状态. 第二项是教师兼容性. 教师在自身答案上强, 不代表在学生前缀上稳定; 应测教师对学生轨迹的 token NLL、top-token 重合和优势分布. 第三项是支持重合. 师生 tokenizer、特殊 token 或聊天模板不一致时, 逐 token 对齐可能从输入端已经失效.

训练中常见的表面成功是 KL 降低而任务分数不升. 原因可能是回答缩短、熵下降、重复增多或 rollout 版本过旧. 另一种失败是教师过强且风格不兼容: 学生访问的状态在教师分布下极低概率, 教师每个位置都给出尖锐但互不连贯的局部修正. 混入教师前缀可以缓解分布断裂, 但会削弱严格 on-policy 覆盖.

### 2.2. 路线选择

需要一个稳定、容易并入监督训练栈的起点时, 先读 GKD. 它把 rollout 当作数据, 允许混合固定序列, 并用任务实验比较不同散度. 需要理解序列级 reverse KL、采样梯度和方差来源时, 读 MiniLLM. 两篇不是替代关系: GKD 给出可组合的训练接口, MiniLLM 给出更完整但更难估计的序列目标.

工程团队还应先确定教师接口. 能访问完整 logits 时, 两条路线都可精确实现局部分布项;只能访问已采 token log-prob 时, GKD 的 forward KL 与 MiniLLM 的解析单步项都无法原样计算. 接口能力会先于公式偏好缩小选择范围. [DistiLLM 与 DistiLLM-2](2.1-局部分布匹配/2.1.2-DistiLLM.md) 在这套坐标上继续处理 skew KL、历史学生样本复用,以及教师/学生两路回答应否采用不同目标. [逐 token 信号](2.1-局部分布匹配/2.1.3-逐token信号.md) 继续比较完整词表、top-$k$ 和已采 token 三种接口;[旧轨迹](2.2-序列目标与轨迹/2.2.2-旧轨迹复用.md) 则处理 rollout 快照与 learner 分离后的状态偏移.

选择完成后, 用同一批冻结轨迹对不同损失做离线梯度比较. 观察梯度余弦、位置分布和极端值, 可以在投入在线 rollout 成本前发现方向写反、mask 错位和尾部截断问题.

如果目标是压缩部署模型, 应优先比较同一算力预算下的监督 KD、GKD 与 MiniLLM, 而不是给三者相同步数. OPD 每步包含 rollout 与教师评分, 单步成本不同;公平口径可以是总训练 FLOPs、GPU 小时或教师 token 数. 如果目标是提升推理能力, 还应区分 pass@1 与 pass@k, 因为散度与采样可能分别改变主模式质量和分布覆盖.

路线中的公式都默认教师冻结且师生共享输出空间. 一旦教师随学生更新、教师带特权上下文或动作空间不是 token, 状态分布框架仍可使用, 但教师目标的非平稳性与对齐映射需要单独进入定义. 这些扩展不能只更换教师名称后沿用同一结论.

状态分布偏移怎样累积：设学生在每个训练分布状态上的错误概率至多为 $\epsilon$. 若一次错误会把后续状态带到训练集没有覆盖的区域, 长度 $T$ 的序列损失可能按 $O(T^2\epsilon)$ 增长. 直觉是第 $t$ 步犯错后, 剩余 $T-t$ 步都可能受影响;对所有 $t$ 求和便出现二次项. DAgger 通过反复收集学习者状态并由专家标注, 把保证改善到与 $T$ 线性相关的量级.

语言模型中的「状态」就是完整 token 前缀. 学生写错一个数字、调用错误工具或选择错误证明分支, 后续条件分布都会改变. 固定答案训练只能教会模型沿正确路径继续;OPD 还能询问教师如何处理学生自己造成的局面. 但教师若无法从错误前缀恢复, 数据聚合本身不会自动解决问题.

四种外层分布：固定人工回答对应经验分布 $d_{\mathcal B}$. 教师自由生成对应 $d_T$. 当前学生生成对应 $d_{\theta_k}$. 教师与学生逐步混合 roll-in 则产生 $d_{\mathrm{mix}}$. 它们可以搭配相同的局部 KL, 得到完全不同的训练样本. 一个准确的方法描述至少给出外层分布、局部损失和参数更新时谁被 stop-gradient.

严格 on-policy 要求生成策略与被更新策略一致. 分布式训练通常只能做到近似: rollout worker 持有 $\theta_k$, learner 已到 $\theta_j$. 可以用版本差 $j-k$ 做粗指标, 再用已采 token 上 $D_{\mathrm{KL}}(\pi_{\theta_k}\|\pi_{\theta_j})$ 衡量真实移动. 只要明确滞后并控制偏移, near-policy 数据仍可训练;把旧轨迹无限复用则失去 on-policy 的主要意义.

信号轴不止一种 KL：硬标签只告诉学生一个 token. 教师 sampled-token log-prob 告诉学生已采动作在教师处的相对支持度. top-$k$ 给出若干主要竞争动作, 完整 logits 给出整个词表. 信息越完整, 计算和通信越重;同时也越能看见「学生应把概率从哪个错误 token 移向哪个候选」.

任务奖励属于另一条信号轴. 终局正确性可以鼓励学生超过教师, 却不提供细粒度信用分配. 过程奖励给中间步骤打分, 粒度介于终局奖励与逐 token 教师分布之间. 选择信号时应先问任务的可验证性: 数学答案可自动判定, 开放式写作很难得到可靠终局标量, 后者更依赖教师分布或偏好比较.

一次更新的概率对象：rollout 阶段从行为策略 $b$ 采出 $y$. 教师在每个 $s_t$ 上给 $p_T(\cdot\mid s_t)$. learner 用当前 $q_\theta(\cdot\mid s_t)$ 计算损失. 若 $b=q_\theta$, 样本严格 on-policy;若二者不同, 需要接受偏差或使用重要性比率 $q_\theta(y_t\mid s_t)/b(y_t\mid s_t)$.

序列重要性比率是各步比率连乘. 即便单步偏移很小, 长序列乘积也会迅速趋近零或出现极端值. 所以实际方法常做逐 token 裁剪、只修正局部动作或完全停梯度. 每种处理都改变估计器, 其价值在于可控方差, 不能笼统写成「仍然无偏」.

## 3. 与 SFT、DPO、RL 的关系

SFT 的状态通常来自数据, 信号是硬 token, 更新是监督梯度. DPO 的状态与成对回答也通常离线给定, 信号是偏好差, 通过参考策略构造分类式目标. RL 的状态来自学生, 信号是环境或奖励模型给出的标量, 更新包含采样分布影响. OPD 的状态来自学生, 信号是教师的稠密动作分布;具体更新可以是停梯度局部匹配, 也可以像 MiniLLM 一样估计序列分布梯度.

这张坐标解释了方法组合. SFT 可以先扩大支持集, OPD 在学生状态上校正行为, RL 再搜索教师之外的高回报策略, DPO 则利用已有偏好对调整相对排序. 组合顺序没有普适答案, 但每次切换都改变状态分布或信号来源, 应分别做消融.

### 3.1. 教师可靠性的条件化评测

比较教师和学生各自独立答题不足以判断 OPD 是否适用. 应从学生 rollout 中截取不同深度的前缀, 标记前缀是否仍可恢复, 再测教师续写成功率、正确动作 margin 与熵. 若教师优势随错误深度迅速消失, 纯学生轨迹会产生大量低质量监督, 混入教师前缀或加入回溯机制更合理.

还要区分知识缺失与策略错误. 教师若知道事实但不能在学生混乱前缀下调用, 特权上下文可能改善教师;学生若根本没有相关 token 模式, reverse-KL OPD 又难以从零创造支持. 前者需要改教师条件, 后者需要 SFT、领域中训或更强探索.

### 3.2. 长度、EOS 与截断

EOS 是控制状态分布的关键动作. 教师比学生更偏好 EOS 时, reverse KL 会增加结束概率;教师偏好继续时则相反. 按序列求和会让长回答拥有更多损失项, 按 token 平均会改变每条样本权重. 最大长度截断又把「没有生成 EOS」与「正常结束」混在一起. 长度现象必须结合这三项解释.

可复算的诊断是按位置绘制教师与学生的 EOS log-odds 差, 再按最终长度和正确性分桶. 只看平均回答长度会掩盖两种相反变化: 一部分样本更早正确结束, 另一部分样本因重复而撞到截断上限.

## 4. 目标选择与适用边界

先确认动作空间能否比较, 再确认教师在学生状态上是否可靠, 然后选择外层状态分布. 只有这三项成立, 才值得讨论 forward KL、reverse KL 或 JSD. 散度无法补救 tokenizer 错位, 也无法把不可靠教师变成正确监督.

学生容量与初始化也会改变选择. 小学生无法覆盖教师多模态分布时, reverse KL 或 JSD 往往更现实;学生需要保留多种答案时, forward KL 的覆盖倾向更合适. 确定这些条件以后, 再选择 full-vocab、top-$k$ 或 sampled-token 估计器, 并用同一冻结 batch 比较梯度方向、方差和显存.

**状态来源决定模型会在哪些问题上被纠正, 目标分布决定纠正方向, 估计器决定这份方向还能保留多少.** 三者共同构成 OPD, 少写任何一层都会让同名实验无法复现.

### 4.1. 从占用测度看 on-policy

对有限时域生成, 可把各时刻状态分布平均成占用测度

$$
d_\pi(s)=\frac{1}{T}\sum_{t=1}^{T}\Pr_\pi(s_t=s).
$$

固定数据 KD 优化 $d_{\mathcal B}$ 上的误差, OPD 优化 $d_{\pi}$ 上的误差. 两个局部损失完全相同时, 占用测度仍会让梯度关注不同区域. 这也是「加入学生生成文本」产生收益的最小理论解释: 训练预算被移到部署策略真正访问的前缀.

混合轨迹对应 $d=(1-\lambda)d_{\mathcal B}+\lambda d_\pi$ 的近似. 注意, 逐序列混合、逐 token 混合与先采两类 batch 再拼接并不产生同一个占用测度. 序列越长, 早期一个教师动作对后续状态的影响越大. 实验报告需要写明混合粒度.

### 4.2. 状态覆盖的盲区

纯 on-policy 只看学生当前能访问的区域. 如果正确策略需要穿过学生概率极低的动作, 训练几乎不会看到那个分支. 教师在已访问状态上给再精确的分布, 也可能无法克服探索瓶颈. SFT 轨迹、教师 roll-in 或环境搜索的价值, 就是把训练状态带到学生尚未覆盖但值得学习的区域.

另一方面, 过多教师 roll-in 会隐藏学生真实错误. 合适的混合比例取决于学生成熟度: 冷启动阶段需要更多可学前缀, 后期应逐渐增加学生状态. 这一日程可由 rollout 成功率和教师在错误状态上的恢复率驱动, 比按固定步数切换更有解释力.

### 4.3. 把生成过程写成有限时域决策过程

要继续推导, 先把语言生成里的随机对象分开. 提示 $x$ 从任务分布 $p(x)$ 采样, 初始状态是 $s_1=x$. 第 $t$ 步, 策略从词表 $\mathcal V$ 选择动作 $a_t=y_t$, 环境以确定性转移 $s_{t+1}=(s_t,a_t)$ 更新前缀. EOS 动作或最大长度 $T$ 结束轨迹. 对自回归语言模型而言, 随机性只来自提示和动作采样;转移函数本身并不需要学习. 一条完整轨迹的概率是

$$
q_\theta(y\mid x)=\prod_{t=1}^{|y|}q_\theta(y_t\mid x,y_{<t}). \tag{6}
$$

教师对应 $p_T(y\mid x)$, 行为策略对应 $b(y\mid x)$. 三者可能恰好相同, 也可能由三个不同版本的模型给出. 训练记录里若只出现「student」, 很容易漏掉生成学生、正在更新的学生和损失中的旧策略其实不是同一份参数. 式 (6) 中每一个条件概率属于谁, 会直接改变梯度估计的目标.

有限时域写法还能容纳 EOS. 可以把 EOS 后的状态设为吸收态, 其后损失为零;也可以让每条序列拥有随机终止时刻 $\tau$. 第二种写法更贴近实现:

$$
J(\theta)=\mathbb E_{x\sim p(x),\,y\sim q_\theta(\cdot\mid x)}
\left[\sum_{t=1}^{\tau(y)}\ell_\theta(s_t)\right]. \tag{7}
$$

这里 $\ell_\theta(s_t)$ 可以是词表上的 KL, 也可以是采样动作的 log-ratio. 随机上限 $\tau$ 会让长度成为目标的一部分. 若直接除以 $\tau$, 优化对象又变成每条回答平均损失;长答案和短答案的相对权重随之改变. 因而「token 平均」不是无害的日志归一化, 它会改变最优策略偏好的长度分布.

状态 $s_t$ 包含完整前缀, 理论上满足马尔可夫性. 实际模型有上下文窗口, 超出窗口的早期 token 被截断, 两条不同历史可能映射到同一个可见输入. 此时 learner 面对的是部分可观测问题: 可见前缀不足以唯一确定完整生成历史. 如果任务需要早期约束, 长度截断会让教师和学生即使共享可见状态也拥有不同的隐含信息. 这类偏差不能靠改变 KL 方向消除, 只能通过保留状态、压缩记忆或重新定义任务观测处理.

占用测度怎样把单步误差放大：设策略 $\pi$ 在时刻 $t$ 的状态分布为 $d_\pi^t$. 对一个有界局部代价 $c(s,a)\in[0,1]$, 总代价是

$$
J(\pi)=\sum_{t=1}^{T}\mathbb E_{s\sim d_\pi^t,\,a\sim\pi(\cdot\mid s)}[c(s,a)]. \tag{8}
$$

行为克隆只在专家分布 $d_{\pi_T}^t$ 上控制分类误差. 假设每一步在专家状态上犯错的概率为 $\epsilon$. 到时刻 $t$ 之前至少犯过一次错的概率由并集界上界为 $(t-1)\epsilon$. 一旦偏离专家轨迹, 最坏情况下后续每步都付出单位代价. 对 $t$ 求和:

$$
J(\pi)-J(\pi_T)
\leq \sum_{t=1}^{T}(t-1)\epsilon
=\frac{T(T-1)}{2}\epsilon
=O(T^2\epsilon). \tag{9}
$$

式 (9) 是最坏情况界, 不表示真实语言模型误差一定二次增长. 它揭示的是训练分布没有约束偏离后的状态. 如果错误 token 对后续没有影响, 或模型能在下一步恢复, 实际累积远小于上界. 反过来, 数学证明中的一个符号错误可能让所有后续推导失去意义, 此时二次上界的悲观性就有现实对应.

DAgger 每轮用当前学习者收集状态, 再请专家给这些状态提供动作. 若在线分类器的平均遗憾趋近零, 聚合数据中至少存在一轮策略在自身诱导分布上具有低损失. 语言模型 OPD 与这条思路相似, 但有两个差别. 第一, 教师通常给出一整个 token 分布, 监督比单个专家动作更密. 第二, 自然语言中的错误前缀未必存在唯一恢复动作, 教师也可能在分布外状态失灵. 因此 DAgger 的分布匹配动机可以迁移, 专家可靠性假设不能原封不动照搬.

从性能差异引理还能看见局部优势的作用. 令 $A_{\pi_T}(s,a)$ 表示在状态 $s$ 采取 $a$ 后继续执行教师, 相对直接执行教师的额外代价. 则有限时域下可以写成

$$
J(\pi)-J(\pi_T)
=\sum_{t=1}^{T}\mathbb E_{s\sim d_\pi^t,\,a\sim\pi(\cdot\mid s)}
[A_{\pi_T}(s,a)]. \tag{10}
$$

这说明最匹配部署目标的权重应当同时考虑学生访问概率和动作对未来的影响. 普通 token KL 只约束动作分布距离, 默认所有 token 的局部差异具有相近价值. 在格式符号、推理分支和无关措辞混在同一词表时, 这个默认并不成立. 序列级目标或任务奖励试图补上价值差异, 代价是估计方差和奖励误差都会进入训练.

roll-in 混合不是一个单独的比例：「教师占比 $\beta$」至少有三种实现. 第一种按整条序列选择策略: 以概率 $\beta$ 让教师生成完整回答, 否则由学生生成. 此时占用测度近似为两种轨迹分布的凸组合. 第二种在每个 token 独立选择教师或学生动作. 早期选择会改变后续状态, 所以最终状态分布不是 $\beta d_T+(1-\beta)d_\theta$ 的简单形式. 第三种先由教师生成一段前缀, 在随机切换点交给学生;它有意让学生学习从正确中间状态继续, 却很少覆盖学生早期错误造成的区域.

以两步生成作手算. 初态 $s_1$ 上教师选择 $A$ 的概率为 $0.9$, 学生为 $0.4$. 若逐 token 以 $\beta=0.5$ 混合, 第一步选到 $A$ 的概率是 $0.65$. 第二步状态为 $s_2^A$ 的概率因而也是 $0.65$. 若按整条序列混合, 边际上仍得到 $0.65$, 但策略身份与状态相关: 到达 $s_2^A$ 后, 继续动作来自同一个先前选中的策略. 逐 token 混合会在 $s_2^A$ 再抛一次硬币. 两者第一步边际相同, 二步联合分布不同. 长序列里这种相关性会不断积累.

教师强制的另一个常见变体是 scheduled sampling: 训练时逐渐把真实前一 token 替换为模型样本. 其出发点也是暴露偏差, 但局部条件目标在混合前缀上并不必然对应任何一致的序列似然. 如果训练状态由一个策略产生, 标签却假设另一条未发生的历史, 条件分布可能互相矛盾. OPD 至少让教师真正读取当前前缀后再给分布, 因而标签与可见状态相配;教师是否懂得修复该状态仍需另外验证.

混合日程可以由两个可测量量控制. 一个是「可恢复率」: 从学生前缀交给教师继续生成, 最终任务成功的比例. 另一个是「覆盖增益」: 加入学生状态后, 相比固定数据多覆盖了多少会在部署时出现的错误类型. 可恢复率低时继续提高学生 roll-in, 只会大量采集教师也无能为力的状态;覆盖增益低时继续保留高教师比例, 又会把训练预算耗在已有正确轨迹上.

混合也会改变提示条件. 如果教师答案采用一种固定模板, 学生答案采用另一种聊天模板或推理格式, roll-in 来源可能被模型从表面标记识别出来. learner 随后学到「看到教师格式时模仿教师, 看到学生格式时做另一件事」. 在比较分布前应统一系统提示、角色 token、停止符与可见工具返回, 否则所谓状态差异掺入了协议差异.

## 5. 散度方向、支持集与容量约束

### 5.1. forward KL 与 reverse KL 的梯度到底压在哪里

在固定状态上, 令教师 logits 为 $u_i$, 学生 logits 为 $z_i$, 对应概率为 $p_i$ 与 $q_i$. forward KL 对学生 logit 的梯度很简洁:

$$
\frac{\partial D_{\mathrm{KL}}(p\|q)}{\partial z_j}=q_j-p_j. \tag{11}
$$

推导从交叉熵开始. 与 $z$ 有关的部分为 $-\sum_i p_i\log q_i$, 而 softmax 满足 $\partial\log q_i/\partial z_j=\mathbf 1[i=j]-q_j$. 代入后得到 $-p_j+q_j\sum_i p_i=q_j-p_j$. 因此教师头部 token 若被学生低估, 会产生接近 $-p_j$ 的明显梯度;教师尾部每项很小, 但词表很大时总质量仍可能可观.

reverse KL 的梯度为

$$
\frac{\partial D_{\mathrm{KL}}(q\|p)}{\partial z_j}
=q_j\left(\log\frac{q_j}{p_j}-D_{\mathrm{KL}}(q\|p)\right). \tag{12}
$$

式 (12) 的 $q_j$ 因子意味着学生几乎不访问的 token 梯度也很小. 括号里的中心化项来自 softmax 各分量相互竞争, 它保证所有 logit 梯度之和为零. 学生把较大质量放到教师低概率 token 时, $\log(q_j/p_j)$ 为正且可能很大, 该 logit 会被压低. 这解释了 reverse KL 训练早期为什么常表现出强烈的「清理学生错误尾部」倾向.

不过「forward KL 一定覆盖模式、reverse KL 一定丢模式」不能当作无条件定理. 当学生族能够精确表达教师且优化充分时, 两个 KL 的唯一全局零点都是 $q=p$. [Wu et al. (2024)](https://arxiv.org/abs/2404.02657) 进一步分析了 LLM 蒸馏中的梯度动态, 指出两者最终目标一致, 训练初期关注区域不同. 容量受限、训练轮数有限、估计器截断和优化路径共同决定最终表现. 模式说法在受限分布族的投影问题里有直觉价值, 离开这些条件就容易误导.

用三分类再算一次梯度. 取 $p=(0.8,0.15,0.05)$, $q=(0.5,0.25,0.25)$. forward KL 对三个学生 logit 的梯度由式 (11) 得到 $(-0.3,0.1,0.2)$. 它明确提升第一个 token, 同时压低后两个. reverse KL 先算

$$
D_{\mathrm{KL}}(q\|p)
=0.5\log0.625+0.25\log\frac{5}{3}+0.25\log5
\approx0.311. \tag{13}
$$

再代入式 (12), 三个梯度约为 $(-0.391,0.050,0.341)$. reverse KL 对第三个严重过量的尾部 token 压力更强, 第一项也因 softmax 守恒得到更大提升. 这个例子展示的是当前点的梯度, 不能推出整个训练过程始终保持相同比例. 当 $q$ 接近 $p$ 时, 两者的局部二阶近似都会趋向 Fisher 几何下的同一形式.

> 图 1: 前向 KL 的 logit 梯度直接比较 $q-p$, 反向 KL 的压力还会被学生当前概率 $q$ 加权.

图 1 解析: 两侧使用相同的教师分布与学生分布, 因而差异只来自散度方向. 向上的蓝色箭头表示梯度下降会提高对应 token 的 logit, 向下的橙色箭头表示会压低 logit. 前向 KL 直接响应教师放置的概率质量;反向 KL 对学生已经赋予较高概率的错误 token 施加更强压力, 对学生几乎不访问的候选则可能缺少足够梯度.

支持集不重合时会发生什么：数学 KL 对零概率很敏感. 如果存在 $p_i>0,q_i=0$, forward KL 为无穷;如果存在 $q_i>0,p_i=0$, reverse KL 为无穷. 标准 softmax 在有限 logits 下给每个词表项正概率, 理论上不会精确为零. 实际训练却会用低精度、top-$k$ 截断、词表裁剪或黑盒接口, 数值支持集可以真的缺项. 此时「完整 KL」和「截断后 KL」是不同目标.

设教师只返回 top-$k$ 集合 $K_T$, 返回的概率总和为 $m<1$. 一种做法是重新归一化 $\tilde p_i=p_i/m$, $i\in K_T$. 这样得到的是教师条件在头部集合内的分布, 尾部总质量消失. 另一种做法把所有尾部并成一个 OTHER 类, 保留质量 $1-m$. 前者会人为增强头部间竞争, 后者保留「尾部整体有多少」却不知道尾部内部结构. 如果学生词表里某个错误 token 落在教师 top-$k$ 外, 只有 OTHER 类时无法单独惩罚它.

温度也会改变支持权重. 设温度为 $\tau$, 则 $p_i^{(\tau)}\propto\exp(u_i/\tau)$. $\tau>1$ 拉平教师分布, 暴露更多次优 token 的相对关系;同时让很低概率的候选获得更大总质量. 经典 KD 常给损失乘 $\tau^2$, 用于抵消 softmax 梯度随温度缩小的尺度. 对自回归 OPD, 温度还会影响 rollout 时的状态分布. 只在教师打分时升温和在学生采样时升温回答的是两个问题, 不能共用一个「temperature」字段含混记录.

tokenizer 不同会造成更根本的支持错位. 教师把「北京」编码成一个 token, 学生可能拆成两个;逐位置 KL 没有一一对应的动作. 可以让教师在学生前缀对应的文本上打分学生候选字符串, 也可以退回序列级概率或采样文本监督. 前一种方案需要计算每个学生 token 字符串在教师 tokenizer 下的若干步概率, 成本明显增加;后一种方案丢掉词表级软分布. 因此共享 tokenizer 是多数白盒 OPD 方法隐含但很强的前提.

当教师和学生容量接近、任务只接受一种答案时, 两种 KL 的差异可能很小;学生容量受限或输出存在多个有效模式时, 差异才会被放大. 因而散度实验应固定状态 batch、教师、学生起点和解码方式, 同时观察任务质量、学生熵、教师模式覆盖与梯度范数. 只比较最终分数, 无法判断收益来自散度几何还是状态来源变化.

外部教师路线最终需要回答四个量: 训练状态由谁生成, 教师在这些状态上是否可靠, 局部目标使用哪种分布差异, 教师接口保留了多少候选动作信息. GKD 主要改变状态来源与局部散度, MiniLLM 继续把序列采样分布的参数依赖纳入梯度. 两者都依赖白盒概率接口, 黑盒教师只能返回文本时应转向序列蒸馏、偏好或结果反馈.

### 5.2. 从行为克隆到访问学生状态

传统行为克隆在专家轨迹上学习动作, 部署时却由学习者自己产生后续状态. 早期一次小偏差会把系统带离专家轨迹, 之后每一步都在训练未覆盖的状态上决策. DAgger 的回应是反复让当前学习者运行, 在它访问的状态上查询专家, 再把新标注并回训练集. GKD 与它共享「学习者暴露状态」的主线, 只是专家标注从单个动作扩成了下一 token 的概率分布.

这个类比不能直接搬来 DAgger 的任务代价保证. 经典分析依赖专家在已访问状态上提供与未来任务代价相关的动作, 语言模型 OPD 往往只有局部 token 分布. 教师更喜欢某个下一 token, 并不自动说明这个 token 能降低整条轨迹的任务代价. 教师在错误前缀上的恢复能力、局部 margin 与终局成功率之间的联系, 仍需要实验验证.

这条历史线还解释了为什么轨迹越旧, on-policy 的含义越弱. 第 $k$ 轮由学生 $q_{\theta_k}$ 生成前缀, 多次更新后 learner 已变为 $q_{\theta_j}$. 版本差 $j-k$ 只告诉我们间隔了多少次更新, 不能表示策略移动大小. 更直接的量是在已采样动作上计算新旧 log-prob 差, 或在已访问状态上计算两个学生的完整 KL. 长期复用不一定让数据无效, 却会把训练对象从当前学生占用测度改成历史策略混合.

因此「在学生轨迹上训练」是一个起点, 还需要写出轨迹由哪个版本生成、复用几次、教师是否能从这些前缀恢复、目标只含局部匹配还是包含未来信用. GKD 用低方差的局部投影完成第一步; MiniLLM 保留未来 log-ratio, 以更高方差换取序列信用. 这一分叉比简单区分「在线」与「离线」更接近算法本身.

教师接口会进一步限制算法选择. API 只返回一段文本时, 训练器只能把教师样本当硬目标, 或从多次采样构造偏好与结果统计;返回已采 token 的 log-prob 时, 可以计算行为动作上的教师支持度, 仍无法恢复教师没有输出的候选排序;返回 top-$k$ 与尾部总质量时, 可以在粗化事件空间计算散度;只有完整 logits 才能精确实现每个状态上的 full-vocab forward KL 与解析 reverse KL. 这些接口对应不同统计对象, 不能把返回字段更少的实现仍记作同一精确目标.

跨 tokenizer 会把接口问题进一步放大. 教师的一个 token 可能对应学生的多个 token, 相同位置不再代表同一动作事件. 直接截齐两边 logits 属于错误监督. 可行路线是把候选映射到字节或字符串事件后重新计算概率, 代价很高;也可以退回教师文本、序列概率或结果反馈, 接受监督粒度下降. 这也是共享 tokenizer 的白盒模型长期占据 OPD 实验主流的原因之一.
