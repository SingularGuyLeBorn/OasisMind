# 自蒸馏：特权信息怎样变成教师优势

自蒸馏看似违反常识: 如果教师和学生来自同一组参数, 教师还能教什么? 差异不一定来自参数规模, 也可以来自输入信息. 学生只看题目并自行生成;教师额外看到参考解、专家示范、验证器反馈或同题成功轨迹, 再对学生已经走到的前缀计算下一 token 分布. 额外上下文把模型已有的理解能力转成即时监督, 学生通过训练把这部分条件行为吸收到无特权输入的参数中.

这条路线源于 context distillation, 但训练状态不同. 传统 context distillation 常在教师生成或固定数据上训练;on-policy 自蒸馏让当前学生产生轨迹, 教师在学生错误真正出现的位置提供反馈. 前者解决「如何内化上下文」, 后者再处理「监督落在哪些状态」. 只有学生轨迹与特权教师同时存在, 才是这里讨论的 on-policy self-distillation.

## 1. 统一结构

### 1.1. 两个视图, 一组参数来源

输入为 $x$, 学生回答为 $y$, 第 $t$ 步状态为 $s_t=(x,y_{<t})$. 学生条件分布是 $\pi_\theta(\cdot\mid s_t)$, 教师额外读取 $c$:

$$
q_t(\cdot)=\pi_{\bar\theta}(\cdot\mid s_t,c),\qquad
p_t(\cdot)=\pi_\theta(\cdot\mid s_t). \tag{1}
$$

$c$ 决定教师获得哪种特权, $\bar\theta$ 决定教师参数从哪里来. 两项必须分开记录. OPSD 用参考解作为 $c$, 教师通常固定在初始策略;SDFT 用专家示范作为 $c$, 并以学生 EMA 形成 $\bar\theta$;SDPO 把环境反馈或组内成功解放进 $c$, 教师可用 EMA 或与初始策略插值.

教师前向需要 stop-gradient. 如果 $q_t$ 与 $p_t$ 同时接受散度梯度, 教师会向学生靠拢, 特权信息产生的差距被主动抹平. 共享参数不等于共享计算图: 同一权重可以先以教师模式无梯度前向, 再以学生模式保留梯度前向.

### 1.2. 一次更新的状态

学生 rollout 前, 系统持有 prompt、学生快照、教师快照与特权上下文. rollout 后新增学生 token、行为 log-prob、EOS 位置和任务结果. 教师评分后新增完整 logits、top-$k$ 分布或已采 token 的 log-prob. learner 更新后学生参数改变;冻结教师保持不变, EMA 教师在更新后缓慢跟随. 不同反馈粒度丢失的信息不同. full-vocab KL 保留教师对所有替代 token 的排序;top-$k$ 看不到尾部内部结构;sampled-token 只知道学生已经选中的动作是否被教师支持. 特权上下文很强但反馈接口过窄时, 大量「教师更愿意选什么」不会进入梯度.

三种特权信息：参考解与示范：OPSD 的教师看到题目参考解, 学生看不到. 教师在学生前缀上结合参考解重新分配下一 token 概率, 并不沿参考解前缀预测. 因而参考解只进入教师条件, 训练状态仍来自学生. 参考解错误、风格不兼容或题目太难时, 教师优势会减弱.

SDFT 把更一般的专家示范放进教师上下文, 目标是从少量示范学习新任务并减轻旧能力遗忘. EMA 教师让目标随学生缓慢进步, 但也引入非平稳性. EMA 系数过小, 教师追得太快, 师生差距迅速消失;系数过大, 教师长期停留在旧能力.

环境反馈与成功轨迹：SDPO 面向只能得到结果奖励或文本反馈的任务. 对答错轨迹, 教师可以看到验证器反馈以及同一题组中答对的解;对答对轨迹, 教师可看到确认信息或自身成功解. 教师在这些信息条件下对原学生轨迹逐 token 评分, 把序列级反馈转成稠密分布信号.

成功轨迹不是拿来做 SFT 的固定标签. 学生仍在自己的前缀上受监督, 成功轨迹只进入教师上下文. 如果直接把成功轨迹作为目标序列训练, 方法会变成筛选式自训练;两者在状态覆盖与信用分配上不同.

## 2. 三条轴决定方法落在哪里

自蒸馏可以按特权信息来源分岔。逐题参考解提供答案型信息, 少量示范提供任务规则, 环境反馈与同题成功轨迹提供在线纠错信息, 历史经验和系统提示词则提供可跨样本复用的上下文。特权信息决定教师比学生多知道什么, 也决定训练收益能否迁移到部署时不可见的新样本。

第二条轴是教师与学生的参数关系。两者可以完全同源, 也可以让教师取学生的 EMA, 还可以使用更大模型。这里的“自”描述信息构造与训练循环, 不保证两次前向使用完全相同的权重。无论采用哪种关系, 教师侧都要停止梯度, 否则目标会随着学生一起移动, 特权信息形成的差距反而被损失函数抹平。

第三条轴是目标校准。参考解、示范或反馈只负责构造更好的教师分布, 还没有回答教师相对 reference 的偏好应该推进多远, 也没有回答正确轨迹与错误轨迹应占多大权重。[G-OPD](4.2-富反馈与目标校准/4.2.2-G-OPD.md) 在 token 目标内部引入 reference 与强度系数,[SCOPE](4.2-富反馈与目标校准/4.2.3-SCOPE.md) 则在轨迹外层按 verifier 和困惑度分流、加权。它们和特权信息路线处在不同维度, 因而可以组合, 但组合后的稳定性需要单独验证。

沿这三条轴再看具体方法, 位置就很清楚：[OPSD](4.1-参考解与上下文经验/4.1.1-OPSD.md) 用逐题参考解构造固定教师,[SDFT](4.1-参考解与上下文经验/4.1.2-SDFT.md) 用示范与 EMA 教师处理顺序学习,[SDPO](4.2-富反馈与目标校准/4.2.1-SDPO.md) 把环境反馈或成功尝试转成稠密信号,[OPCD](4.1-参考解与上下文经验/4.1.3-OPCD.md) 把长期上下文与经验压回参数。前四种方法主要改变教师知道什么, 后两种主要改变已经得到的教师信号怎样进入优化。

### 2.1. 特权信息路线的选择

| 方法 | 学生前缀 | 特权信息 | 教师参数 | 主要用途 |
| --- | --- | --- | --- | --- |
| OPSD | 当前学生 rollout | 已验证参考解或推理轨迹 | 通常冻结起点 | 数学与可验证推理 |
| SDFT | 当前学生 rollout | 专家示范 | 固定、在线或 EMA | 从示范持续学习 |
| SDPO | 当前学生 rollout | 环境文本反馈或同题成功轨迹 | EMA 或受约束教师 | 富反馈训练与测试时适应 |
| OPCD | 当前学生 rollout | 历史经验、规则或系统提示词 | 同源或跨尺寸教师 | 把可复用上下文压入参数 |

三种方法最稳定的比较轴是特权信息、教师参数、分布损失和任务假设. OPSD 依赖每题参考解;SDFT 依赖少量专家示范以及模型的 in-context learning;SDPO 依赖在线反馈或同组成功样本. OPSD 与 SDFT 更像把已有高质量信息内化, SDPO 更强调在训练中把新反馈转成教师条件分布.

散度结论不能互相照搬. OPSD 的实验偏向 full-vocab forward KL 与逐点裁剪;SDFT 的理论表达与实际最佳配置并不完全相同;SDPO 常用 reverse KL 或 JSD, 并以 top-$k$ 加尾部桶控制成本. 这些差异来自任务、教师条件与估计器, 不能缩成「自蒸馏统一使用某一种 KL」.

选择顺序：有可靠逐题参考解时, OPSD 给出最直接的固定教师. 只有少量示范、希望连续学习时, SDFT 的 EMA 教师更贴近问题. 环境能返回验证结果或富反馈, 且同题能采到成功轨迹时, SDPO 可以把在线反馈转成 token 信号. 如果三类信息都没有, 同源教师没有新增条件, 自蒸馏很可能只做分布自匹配. 选择之后先做教师增益测试: 固定学生 rollout, 比较有无特权上下文时正确下一步的概率、已采错误 token 的概率和最终续写成功率. 只有教师在学生状态上确实更好, 才进入训练器与超参数比较.

还要确定特权信息的取得成本. 人工参考解适合小规模高质量任务, 自动验证器适合可判定结果, 文本反馈适合错误可描述但难写标准答案的任务. 信息成本应按有效训练样本计算: 如果多数 rollout 没有成功同伴或反馈无法解析, 名义上的在线自蒸馏 batch 会大幅缩水.

不同信息可以组合, 但组合时要保留来源标记. 教师同时看到参考解与验证反馈后变强, 不能判断是哪项提供增益;先做单来源对照, 再验证组合是否互补. 推理部署仍只给学生普通输入, 这是所有比较不变的条件.

一个最小批次就能排掉许多实现错误。取一道题和两条 rollout, 一条成功, 一条在中途出现可定位错误。固定学生前缀与 response mask, 分别构造参考解、示范、环境反馈三种教师视图, 再比较教师 top-$k$、局部优势和 KL。更换特权信息时, 学生 token 与待求导 logits 不应变化。去掉特权信息以后, 同参数教师与学生的损失应接近零;若仍有明显差异, 应检查 dropout、权重版本、位置编码、模板和 tokenizer。若训练 loss 很快下降而无特权验证集不动, 最先要查的是参考解或反馈是否泄漏进学生输入。

OPCD 把第四种信息加进了同一坐标: 历史经验、操作规则或经过优化的系统提示词放在教师上下文中, 学生只看普通输入并生成 rollout. 它与传统 context distillation 的差别在训练状态: 目标前缀来自学生当前策略, 而非固定教师文本. 教师在学生真正会访问的前缀上利用长期上下文, 再把差异压回无上下文学生.

OPCD 的边界与其他三条路线一样来自可辨识性. 历史上下文若揭示了多个样本共享的稳定规律, 学生可以把规律写入参数; 若它只包含当前用户的动态权限、实时数据或单次会话秘密, 参数化既无法泛化, 还会损害可更新性和审计性. 适合写入参数的是稳定经验与行为倾向; 易变规则仍应留在外部上下文或工具中.

四条路线因此形成一条按信息来源区分的光谱. OPSD 平均每题需要一条可验证参考; SDFT 用少量跨样本示范揭示任务规则; SDPO 的条件信息来自当前轨迹触发的环境; OPCD 则处理可跨轮复用的经验与长期上下文. 它们可以共享 rollout、教师 Prefill 和 learner 反向传播, 但数据成本、时效性和可泄漏信息不同. 只看“同源教师”这个共同点, 会丢掉选型时最关键的差异.

最小比较可以共用一批学生 rollout, 分别构造参考解、示范、环境反馈和历史经验四种教师视图. 固定教师参数与解码预算后, 比较四种条件对关键动作 margin、错误前缀续写成功率与学生可达性的改变. 某类特权条件只让教师写得更长, 却不改善关键决策, 就没有进入长程训练的必要.

OPCD 还允许教师与学生采用不同模型尺寸, 但跨尺寸不等于可以忽略动作空间. 两边 tokenizer 或聊天模板不一致时, 逐 token KL 仍需事件对齐;无法可靠对齐就改用教师序列与结果信号. 真正可迁移的是上下文提供的稳定规律, 不是某个模型专有的 token 切分.

跨尺寸还应把教师额外算力单列, 不能把更大教师带来的收益全部记到蒸馏目标名下.

## 3. 工程与失败边界

一次更新的成本至少包含学生顺序 Decode、教师无梯度 Prefill、学生 teacher-forcing 前反向与权重同步。教师和学生同尺寸, 不代表成本简单翻倍: 长回答时 Decode 可能支配延迟, 大词表时 logits 投影与传输又会成为瓶颈。报告吞吐时应分别列出四段墙钟、教师评分 token、学生生成 token 与峰值显存。top-$k$ 可以压缩反馈张量, 但若输出层仍计算完整词表, 它并没有自动省掉教师投影成本。

同一批轨迹训练多个 epoch 能摊薄生成与教师评分, 也会把严格 on-policy 变成 near-policy。设轨迹由 $\pi_{\theta_k}$ 生成, learner 已变为 $\pi_\theta$, 已采 token 的重要性比为

$$
w_t=\frac{\pi_\theta(y_t\mid x,y_{<t})}{\pi_{\theta_k}(y_t\mid x,y_{<t})}. \tag{3}
$$

整条长序列的比率乘积很容易产生高方差, 因而工程实现常做逐 token 裁剪、拒绝过旧轨迹或限制复用轮数。无论采用哪种处理, 日志都要保存 rollout 版本、learner 版本、轨迹年龄与裁剪比例。“每轮都在生成”不能替代这些观测量。

### 3.1. 上下文不能泄漏

学生输入与教师输入必须分别构造. 共享 batch 时, 最容易出现 attention mask 复用错误, 让学生看见参考解或反馈 token. 泄漏后的训练 loss 会快速下降, 评测时移除特权信息便失效. 测试应检查学生每个位置的可见 token, 不能只比较两侧解码文本.

教师模板也会改变信号. 参考解放在 system、user 还是独立消息中, 模型的利用能力可能不同;长反馈被截断后, 教师只看到结尾或只看到题目, 都会改变目标. 模板、截断侧与最大长度应和散度一起进入实验配置.

### 3.2. 同源不保证更强

小模型可能无法从示范或反馈中提取正确规律. 教师上下文更长还会增加困惑, 使教师在学生前缀上反而更差. 应按模型规模、题目难度和轨迹对错分桶测教师优势, 不能用全局平均掩盖困难样本上的负迁移.

另一个边界是信号耗尽. 学生逐渐吸收特权行为后, 师生 KL 会下降. 此时继续训练可能只压低熵或放大模板偏好. EMA 教师可以随学生变化, 但 EMA 本身不会创造新信息;需要新的反馈、示范或更强上下文才能继续提供能力增量.

## 4. 条件信息怎样变成策略差

设基础模型为 $f_\theta$, 学生输入为状态 $s$, 教师额外获得特权变量 $z$. 两个策略分别为

$$
\pi_S(a\mid s)=f_\theta(a\mid s),\qquad
\pi_T(a\mid s,z)=f_{\bar\theta}(a\mid s,z).
$$

即便 $\bar\theta=\theta$, $z$ 也会改变注意力上下文与下一 token 分布. 蒸馏训练把 $\pi_T$ 在学生状态上的偏好压回不含 $z$ 的 $\pi_S$. 能否成功取决于 $s$ 是否包含足够线索: 若教师答案完全依赖部署时不可见的秘密信息, 学生最多学到数据集中的相关性, 无法在新样本上恢复秘密.

特权信息可分为三类. 「答案型」信息给最终结果或参考推理;「反馈型」信息指出学生轨迹哪里出错;「经验型」信息给成功历史、工具观察或旧模型行为. 答案型信号容易构造强教师, 也最容易让教师跳过学生需要掌握的中间过程. 反馈型更贴近纠错, 质量受批评准确性影响. 经验型适合多轮决策, 但状态与动作对齐最复杂.

### 4.1. 教师看到参考解时发生了什么

参考解放入上下文后, 教师可能逐字复制, 也可能只利用其中结论重新组织回答. 若目标是让学生学推理, 需要区分这两种行为. 可遮掉参考解的一部分, 检查教师是否仍能在学生错误前缀上给出合理续写;也可比较教师 top token 与参考解下一个 token 的重合率. 完全复制提供的是强序列模仿信号, 未必产生错误恢复能力. 参考解长度还会影响位置对齐. 教师上下文包含额外 token, 学生上下文没有, 但两者预测的是同一学生 response 位置;不能直接按绝对序号切 logits. 正确做法是在各自模板中定位 response span, 再按学生动作逐位置取教师分布.

### 4.2. 环境反馈怎样进入教师

环境反馈可以是正确/错误标记、编译器报错、单元测试、工具返回或自然语言批评. 一个标量反馈本身信息很少, 把它加入教师上下文后, 教师利用自身知识解释失败原因并生成稠密分布. 这相当于用教师完成信用分配.

风险也随之集中到教师. 错误反馈、奖励漏洞或提示注入会改变每个 token 的监督. 若环境文本由外部工具返回, 教师模板应明确数据边界, 避免把工具内容当指令. 对可验证任务, 还应抽查教师建议是否提高后续成功率, 而非只让解释更流畅.

### 4.3. 成功轨迹作为特权视图

多轮任务中, 教师可以看到一条成功轨迹, 学生仍从自身状态行动. 成功轨迹提供高层策略, 但当前学生状态可能已偏离示范. 教师需要把示范原则映射到当前状态, 不能机械输出示范中的下一动作. 状态差距越大, 这种映射越不可靠. 可用状态相似度或可恢复性筛选教师监督. 对距离成功轨迹太远的前缀, 先回退到环境重置、搜索或终局奖励;对仍可恢复的前缀再做逐 token 蒸馏. 这比让教师对所有坏状态保持高置信更稳健.

为什么同源教师不等于循环论证：同一个模型在不同条件下可表现出显著能力差. chain-of-thought 提示、工具结果和参考答案改变了可用计算与信息. 自蒸馏试图把条件化表现转成无特权条件下的参数行为. 这一过程类似 context distillation: 上下文中暂时提供的信息被梯度吸收.

但参数吸收有容量限制. 教师依赖很长参考资料时, 少量更新可能只学到答案模式;大量更新又可能遗忘通用能力. 训练结果应在未见问题上评估, 并设置没有特权信息的同源教师对照, 才能确认增益来自 $z$ 而非额外训练 token.

教师更新速度：固定教师的目标易解释. 学生超过教师后, 固定目标会限制进一步探索. EMA 教师能跟随学生的新能力, 其滞后又能抑制瞬时噪声. 令更新间隔为 $K$, 衰减为 $\tau$, 教师的有效时间尺度同时受二者影响;只报告 $\tau$ 不能完整描述教师响应速度.

在线教师若还读取新反馈, 教师改进与学生改进会耦合. 此时应保留一份固定锚点教师或参考策略, 监控移动教师是否整体漂移. 两个模型 KL 很小可能表示一致收敛, 也可能表示共同塌缩, 需要外部任务指标判断.

特权泄漏与公平比较：训练时的教师可以看参考答案, 评测时学生不能看. 若评测 prompt 意外保留答案字段、工具缓存或模板标记, 得分会虚高. 数据管道应在 token 级检查学生输入, 而不是只看原始 JSON 字段. 同一 batch 同时打印 teacher input 与 student input, 能直接暴露泄漏.

比较特权教师与外部大教师时, 还要计入信息预算. 一个小自教师看到标准答案, 与大教师只看问题并非同等条件. 公平问题取决于研究目的: 若目标是利用已有答案压缩行为, 特权条件合理;若要比较模型本身的指导能力, 就必须统一可见信息.

可学习性的三个必要条件：第一, 特权变量确实改善教师在学生状态上的动作分布. 第二, 学生可观察状态包含推断目标动作所需的信息. 第三, 学生模型和初始化对目标行为有足够表示与支持. 缺第一项, 教师没有增益;缺第二项, 问题不可辨识;缺第三项, reverse-KL 学习难以访问目标模式. 可以为三项分别做测试. 教师增益用前缀续写成功率测;可辨识性用移除或打乱 $z$ 后的条件差测;学生支持用教师高概率 token 在学生分布中的累计质量测. 三项通过后, 再调 EMA、top-$k$ 或学习率才有意义.

特权教师是同一个模型在更多信息下形成的条件策略. 蒸馏的任务是把其中可由学生状态预测的部分留下, 把只依赖训练期秘密的部分挡在部署边界之外.

信息论边界：若特权变量 $z$ 与正确动作 $a^*$ 在给定学生状态 $s$ 后仍有条件互信息 $I(a^*;z\mid s)>0$, 教师可以利用学生看不到的信息提高预测. 蒸馏只能把训练分布中可由 $s$ 统计预测的部分压入参数. 对每个新样本都独立变化、且不在 $s$ 留下线索的那部分信息无法被恢复.

这给出了一个清楚的反例. 若教师看到随机生成的密码, 学生只看见「请输入密码」, 再多蒸馏也无法让学生预测新密码. 若教师看到的是解题示范, 而题目结构与示范步骤之间存在规律, 学生则可能把规律学进参数. 两种情形在训练 loss 上都能下降, 泛化结果完全不同.

反事实测试：把特权信息随机打乱是一项有效对照. 若教师仍保持高分, $z$ 可能没有真正被使用;若教师输出随打乱显著变化, 再观察学生能否从非特权状态预测这些变化. 还可以只保留答案、只保留错误说明或只保留工具观察, 分解哪类信息贡献最大.

另一个测试是交换前缀. 给教师正确答案, 同时提供另一条学生错误轨迹, 检查教师能否针对当前错误而非复述标准解. 这能区分「条件化纠错教师」和「带答案的文本生成器」, 对长推理任务尤其重要.

多教师情形：不同特权视图可以产生多个教师. 一个看参考解, 一个看环境反馈, 一个保留旧模型能力. 简单平均概率会把相互冲突的模式混在一起;按状态选择教师则需要可靠路由. 多教师目标可写成 $\sum_i w_i(s)D(p_i\|q)$, 权重既可由教师置信度给出, 也可由外部验证器确定.

置信度路由有自信错误风险. 更稳妥的信号是教师建议经过环境验证后的成功率. 若没有验证器, 应保留教师分歧并降低冲突状态权重, 避免平均分布把学生推向各教师都不会真正选择的中间模式.

条件蒸馏的风险分解：设数据来自联合分布 $p(s,z,a)$，教师给出 $p_T(a\mid s,z)$，学生只能表示 $q_\theta(a\mid s)$。以 forward KL 为例，理想目标为

$$
\mathcal L(\theta)=
\mathbb E_{s,z}\left[D_{KL}
\big(p_T(\cdot\mid s,z)\|q_\theta(\cdot\mid s)\big)\right].
$$

对固定 $s$，最优无限容量学生是对特权变量边缘化后的混合：

$$
q^*(a\mid s)=\mathbb E_{z\sim p(z\mid s)}[p_T(a\mid s,z)].
$$

如果同一学生状态对应多个互相冲突的 $z$，学生只能学习混合。一个简单例子：同一题面 $s$ 的隐藏答案由独立硬币 $z$ 决定，教师分别给 A 或 B，学生最优只能各给 0.5。训练 loss 可以稳定收敛，部署准确率仍只有随机水平。这是不可辨识性，不是优化器没有调好。

真实任务中，$z$ 往往与 $s$ 有统计联系。参考解由题目推导，编译错误由当前代码造成，成功轨迹受环境状态限制。学生能够从 $s$ 预测一部分教师行为。可把风险拆成三个项：教师相对真值的误差、特权边缘化造成的不可辨识误差、学生有限容量与优化误差。只看最终蒸馏 loss，三者混在一起。

令真实最优策略为 $p^*(a\mid s)$，边缘教师为 $\bar p_T(a\mid s)$，则可用一组比较量区分：教师在带 $z$ 条件下的任务成功率；$\bar p_T$ 的任务成功率；学生与 $\bar p_T$ 的 KL；学生真实成功率。教师很强、$\bar p_T$ 很弱，问题在特权不可预测；两者都强、学生 KL 大，问题在容量或优化；学生 KL 小但任务差，教师目标本身有偏。

蒸馏方向改变模式行为：Forward KL $D_{KL}(p_T\|q)$ 要求学生覆盖教师有质量的模式，容易得到较宽分布。Reverse KL $D_{KL}(q\|p_T)$ 更偏向选择教师高峰，可能丢掉次要模式。对多解推理，forward KL 有利于保留多个有效动作；对生成阶段需要一条连贯轨迹时，过宽分布又可能在不同模式间拼接。 Token 级 forward KL 常用教师 logits直接训练。若教师看到答案后对某个 token极度自信，学生在没有答案时被迫拟合这个尖峰；多个 $z$ 对应不同尖峰，平均后可能形成不自然分布。温度可以软化目标：

$$
p_T^{(\tau)}(a)=\frac{\exp(l_a/\tau)}
{\sum_b\exp(l_b/\tau)}.
$$

$\tau$ 增大保留更多替代动作，也会把教师噪声扩散到长尾。温度需要按教师校准与学生支持选择，不能固定套用分类蒸馏经验。 截断 top-k 教师分布降低存储和计算，却会删除教师尾部。若学生当前高概率动作不在教师 top-k，reverse 方向或 off-policy更新可能缺少梯度支持。应报告截断前质量、被保留 token的教师累计概率，以及学生动作落在截断外的比例。教师极尖时小 $k$ 足够，开放式语言状态可能需要更宽支持。

序列级蒸馏只采一条教师轨迹，绕开完整 logits存储，目标变成行为克隆。采样温度和拒绝规则决定留下的模式，少量轨迹容易模式坍缩。多采样加验证保留多条成功路径，覆盖提高，成本也上升。Token KL 与序列 SFT 可以组合：先用验证轨迹提供状态覆盖，再在这些状态上使用教师分布。

教师信息的充分性与最小性：特权变量太弱，教师没有增益；太强，教师可能跳过学生要学的过程。最有用的 $z$ 通常提供「足以纠错但仍要求完成任务」的信息。例如只给最终答案，教师可以围绕答案反向编造推理；给失败测试与局部提示，教师仍要定位修改。两者产生的 token监督密度和可迁移性不同。

可以从教师增益和学生可预测性画二维图。横轴是 $z$ 带来的教师成功提升 $\Delta_T$，纵轴是学生从 $s$ 预测教师动作的能力。左下角没有信号，右下角是强但不可学秘密，左上角是可学却无额外价值，右上角才适合蒸馏。实验应寻找右上区域，而非一味增加教师信息。

最小特权集可通过逐字段消融寻找。参考解包含答案、步骤、引用和格式；工具反馈包含退出码、stderr、diff和测试。每次删除一类字段，测教师续写、学生蒸馏与未见任务表现。若删除答案后教师略降、学生泛化上升，说明答案诱导了捷径。若删除错误位置后两者都降，定位信息是真正有效条件。

信息顺序也会改变教师。先展示学生错误再给参考解，教师更可能针对失败；先给完整答案再展示学生前缀，注意力可能主要复制答案。两个 prompt包含相同字段，条件策略仍不同。模板属于方法，应版本化并做顺序消融。

特权信息还可能污染输出格式。教师在分析中引用「参考答案显示」「根据测试反馈」，学生部署时没有这些对象，蒸馏会学到元话语。训练可要求教师输出部署可执行的动作，隐藏或清理来源措辞；清理不能删除真实推理。更稳妥的做法是让教师内部使用 $z$，输出仍遵循学生协议。

答案型教师的因果反例：设数学题训练集中某种表面模板总对应答案 42，教师看到标准解后输出正确推理。学生可通过模板捷径预测 42，在同分布验证上表现好；模板与答案关系在新题族中改变，学生失败。蒸馏成功吸收了 $p(a\mid s)$ 的训练相关性，却没有获得参考解中的因果算法。

要检验算法迁移，可构造保持推理结构、改变数字与表面的反事实题；也可打乱不影响解法的叙述顺序，观察学生是否稳定。只对原题改写，可能仍保留模板线索。对形式证明，改变变量名、前提顺序与等价 statement，更能检查学生是否学到证明结构。

教师本身也可能利用答案倒推一条错误但结论一致的链。最终 answer verifier无法发现中间错误。过程验证、逐步执行或隐藏反例能够过滤；没有可靠过程验证时，学生应降低对教师链的置信，保留最终正确与推理可信两种标签。

轨迹教师与状态分布：成功轨迹 $\tau^*=(s_0^*,a_0^*,\ldots)$ 来自教师或旧策略的状态分布 $d_T(s)$，学生部署访问 $d_S(s)$。行为克隆在 $d_T$ 上学习，学生小错误会进入轨迹中未覆盖的状态，产生 covariate shift。让教师看成功轨迹并在学生状态上给动作，是把示范知识投影到 $d_S$，前提是教师能理解偏离状态。 可以定义学生状态与示范最近状态的距离 $D(s,s_j^*)$，但文本、代码和网页没有统一度量。更直接的可恢复性测试是从当前状态执行教师建议，再由环境验证是否提高完成概率。少量分支 rollout可估计：

$$
\hat Q_T(s,a)=\frac1K\sum_{k=1}^KR(\tau_k\mid s,a).
$$

教师语言置信度高而 $\hat Q$ 低，说明它在错位状态上产生了似是而非建议。 状态偏离有不同类型。目标未变、只多了无关探索时，成功轨迹仍可参考；文件或页面已被部分修改，需要先诊断与回滚；不可逆外部动作发生后，原示范可能不再可达。教师输入应包含当前环境事实，不能只给聊天历史。训练数据标记可恢复、需重置与不可恢复三类，避免把重置后的动作硬接到受损状态。

在线采集可用学生 rollout产生真实错误状态，再让特权教师纠错，类似 dataset aggregation。随着学生变强，状态分布移动，教师数据也更新。若只保留教师成功续写，困难状态可能反复被过滤掉；应记录教师失败率与状态类型，确认课程没有悄悄退回简单样本。

轨迹特权还可能泄漏未来。教师看到整条成功轨迹时，知道后续工具结果与环境变化；它在早期状态给出的动作可能依赖尚未发生的信息。学生无法预测这种反事实未来。可以只给截至当前时间可合法获得的示范摘要，或将未来信息限制为高层目标，再用因果遮罩测试教师动作是否依赖未来 token。

EMA 教师作为双时间尺度系统：在线自蒸馏常令教师参数

$$
\bar\theta_{n+1}=\tau\bar\theta_n+(1-\tau)\theta_n.
$$

展开可见教师是历史学生的指数加权平均，样本年龄约为 $1/(1-\tau)$ 个更新单位。若每 $K$ 步才同步一次，有效墙钟滞后还乘 $K$。大滞后提供稳定目标，也可能跟不上学生发现的新策略；小滞后让教师迅速共享学生噪声，失去锚点。

双时间尺度要求学生更新快、教师变化慢，但二者梯度尺度和数据刷新也会影响。可以监控 $D_{KL}(\pi_T\|\pi_S)$、教师与固定锚点 KL、两者任务成功率。师生 KL下降同时成功率上升是良性收敛；KL下降而成功率一起下降是共同坍缩；KL持续增大可能是教师过旧或学生不稳定。

EMA 权重平均未必等于策略平均，神经网络参数空间非线性。两个功能良好的 checkpoint平均后可能性能下降，尤其跨越不同 basin。较短时间尺度和连续训练通常更安全。可以直接比较 EMA教师、周期 checkpoint教师与 logits ensemble，判断稳定来自参数平滑还是预测集成。

教师读取特权 $z$，学生不读，两个 forward的上下文长度与激活分布不同。即使共享参数，EMA只同步权重，无法保证无特权路径也同步改善。训练中应分别评估教师带 $z$、教师去掉 $z$、学生无 $z$ 三种条件；第二项能看见教师参数本身是否增长，第一与第二差值是条件增益。

教师优势只有在学生可见状态上可预测时才可能被压回参数. 参考解、示范和环境反馈都能让同一模型暂时更强, 但额外信息若包含每个样本独立变化的秘密, 无特权学生只能拟合条件平均. 训练前应固定学生部署状态, 再用打乱特权信息、替换模板和未见题族测试教师增益是否来自可迁移规律.

支持集同样限制自蒸馏. 教师偏好的动作在学生分布中接近零时, sampled-token 反馈很难发现该动作;错误前缀已经不可恢复时, 后续 token 的精确 KL 也无法修正早期决策. 前者需要 SFT、搜索或 full-vocab 目标扩展支持, 后者需要回溯到关键分叉或使用序列信用. EMA、裁剪和学习率只能稳定已有信号, 不能补出缺失状态与缺失信息.

因此三条路线应按信息来源和训练位置区分. OPSD 用参考或验证后的推理形成特权教师, SDFT 用示范条件教师把上下文能力写回参数, SDPO 用环境反馈与成功轨迹形成稠密分布信号. 同源参数保证词表和表示兼容, 能力增量仍来自教师额外看到的信息.
