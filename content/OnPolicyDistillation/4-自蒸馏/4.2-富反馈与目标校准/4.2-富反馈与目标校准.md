# 富反馈与目标校准：教师信号应该怎样进入优化

得到一个更强的条件化教师以后，训练仍有三个未决问题：环境反馈怎样变成 token 级指导，教师相对基础策略的偏好应该推进多远，以及正确、错误、容易、困难轨迹各占多少权重。SDPO、G-OPD 与 SCOPE 分别处理这三处，三者位于可组合的正交轴，并无时间升级关系。

## 1. 从稀疏结果到富反馈

结果奖励只告诉模型整条回答成功或失败。最朴素的 RLVR 用这个标量估计策略梯度，优点是评价目标直接，难点是长轨迹信用分配。若同源教师能读取环境结果、成功尝试或批评文本，它可以在学生每个前缀上生成更稠密的条件分布。

[SDPO](4.2.1-SDPO.md)沿这条路线工作：学生先探索，环境提供可验证反馈，教师视图读取反馈后重新判断局部动作，学生再蒸馏这份分布。信息增量来自环境，教师负责解释，OPD 负责把解释落到学生访问的状态。若没有环境反馈，它会退化为普通自蒸馏；若教师无法正确利用反馈，稠密信号只会放大错误。

## 2. reference 决定奖励坐标

标准分布匹配通常把教师当作终点。[G-OPD](4.2.2-G-OPD.md)从带 KL 正则的优化闭式解出发，将教师、reference 与强度系数放在同一坐标中。reference 不再只是防止策略漂移的实现项，而定义“相对哪一个基础策略，这个教师偏好意味着奖励”。

当强度处于插值区间，学生被推向教师；进入外推区间后，目标可能比教师更偏好教师相对 reference 提升最大的动作。这给出了超越模仿的可能，也放大极端 log-ratio、教师误校准和支持集缺口。外推是否有效不是代数式自动保证的，需要受控实验观察收益与崩溃边界。

## 3. 轨迹权重决定算力花在哪里

即便每条轨迹都有 token 级信号，均匀训练也可能浪费样本。正确轨迹包含学生自身已经找到的成功模式，错误轨迹则更需要教师纠正；同为错误轨迹，教师很确定的局部修复与近乎不可恢复的路径价值也不同。

[SCOPE](4.2.3-SCOPE.md)先用 verifier 分流，再用困惑度构造方向不同的权重：正确轨迹可用 MLE 巩固学生成功，错误轨迹接受教师蒸馏；权重用于决定哪些样本更值得更新。PPL 只是代理量，它反映模型对序列的熟悉程度，不等于任务难度或因果价值，因此必须与均匀权重、仅 verifier 分流等 baseline 比较。

## 4. 三层组合时的风险

把 SDPO、G-OPD 与 SCOPE 组合，可形成“反馈构造教师—reference 校准 token 方向—轨迹权重分配样本”的完整链条。但每层都可能放大上一层误差。教师错误解释反馈时，外推会把偏差推得更远；极端 log-ratio 再乘高轨迹权重，梯度会集中到少数样本。

稳定化不能只靠统一 clipping。应分别监控教师优势、reference log-ratio 分布、轨迹权重有效样本量和最终回报。若出现退化，先定位是哪一层失真，再选择限制外推、平滑权重或回退到局部分布匹配。把所有异常归为学习率问题，只会掩盖目标设计错误。

## 5. 公平实验怎样拆

最小实验矩阵从一个普通 on-policy 蒸馏 baseline 开始，依次加入反馈条件、reference 校准和轨迹加权，每次只改变一个变量。教师调用量、rollout 数、更新 token 数与解码设置保持一致。除了最终准确率，还要报告正确/错误轨迹比例、教师在两类状态上的优势、权重分布与策略离 reference 的距离。

若组合方法提高最终结果，却没有显示中间信号怎样变化，读者无法判断它是否可迁移。相反，即使平均分提升不大，若某一部件稳定改善了困难状态的 continuation，也能说明机制成立，只是计算预算或下游瓶颈尚未匹配。

## 6. 选择路线

任务有可靠环境验证器而奖励过稀疏时，先考虑富反馈；教师明显强于 reference、且希望控制模仿与外推强度时，研究目标校准；轨迹质量差异大、教师成本高时，样本分配更重要。三者同时存在并不意味着应一次全部启用。最稳妥的做法是从可解释 baseline 出发，用机制指标确认每一步确实解决了对应问题。

## 7. 校准不能只看平均值

教师相对 reference 的 log-ratio 常呈长尾分布。平均 KL 看似温和，少数 token 却可能获得极端外推权重。训练应同时观察分位数、最大值、有效样本量和梯度范数，并按正确/错误轨迹分开统计。统一裁剪能控制爆炸，但也可能恰好删掉最有价值的强偏好位置。

轨迹权重同样会改变实际 batch 分布。若少数低困惑度错误轨迹获得大权重，名义 batch 很大，梯度却接近由几条样本决定。有效样本量

$$
N_{\mathrm{eff}}=\frac{(\sum_i w_i)^2}{\sum_i w_i^2}
$$

能直接显示权重集中程度。它不判断权重语义是否正确，却能提醒优化已经进入高方差区域。

### 8. 反馈噪声怎样逐层传播

环境验证器可能误判，教师可能错误解释反馈，reference 可能与任务域不匹配，PPL 也可能偏好短而熟悉的轨迹。四类噪声经过组合后不会自动抵消。最有效的诊断是保存同一批锚点轨迹，在各组件更新后重新计算反馈、教师分布、log-ratio 和最终权重，观察误差在哪一步放大。

若验证器噪声可估计，可对正负轨迹做置信度校准；教师解释不稳定时，可增加独立教师或一致性采样；reference 不合适时，应重新定义奖励坐标，而不是继续调大裁剪。不同故障需要不同修复，统一降低学习率只能缓和表面波动。

### 9. 与 RL 奖励塑形的边界

将教师 log-ratio 作为 token 奖励，与在损失中直接做分布匹配，可能在特定假设下得到相近梯度，但采样分布、baseline 和 stop-gradient 处理会造成差异。写作和实现都应给出实际计算图，不能只凭“等价于奖励”跳过推导。

富反馈若由环境生成，它带入的是任务信息；若由教师根据自身偏好生成，它主要传递教师行为。前者有机会超越教师，后者更接近模仿。SDPO 等方法的价值在于把环境信息交给教师解释，再以稠密分布传给学生；证据链应分别证明环境增量和教师解释都有效。

### 10. 组合后的停止条件

随着学生变强，正确轨迹比例上升，教师优势下降，原有分流与权重可能不再合适。训练应根据机制量调整，而不是固定跑满步数。可观察教师 continuation 优势、外推 token 比例、有效样本量和验证回报；当教师优势接近零或权重高度集中时，继续蒸馏可能只增加漂移。

目标校准要在教师知识、环境探索与学生稳定性之间找到可验证的工作区间，一味放大所有信号会破坏稳定性。这也是这一二级路线与具体算法文章之间的关系：算法给出不同控制旋钮，路线首页说明这些旋钮为何存在、何时会互相放大。
