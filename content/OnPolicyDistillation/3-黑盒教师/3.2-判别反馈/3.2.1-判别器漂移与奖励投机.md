# 判别器漂移与奖励投机：黑盒蒸馏为何会失稳

黑盒教师不给 logits，只能返回文本。生成式对抗蒸馏因此训练一个判别器，区分教师回答与学生回答，再把判别分数当作学生奖励。这个转换很诱人：教师只需常规生成接口，学生仍能在自己的 rollout 上优化。问题也集中到了判别器身上。它既是师生分布差异的估计器，又是学生主动攻击的奖励函数；学生一更新，判别任务本身就变了。

## 1. 从理想密度比开始

固定提示 $x$，教师和学生的序列分布分别为 $p_T(y\mid x)$ 与 $p_\theta(y\mid x)$。用相同类别先验训练二分类器，交叉熵目标为

$$
\max_D\;\mathbb E_{y\sim p_T}\log D(x,y)
+\mathbb E_{y\sim p_\theta}\log(1-D(x,y)).
$$

逐点求最优解得到

$$
D^*(x,y)=\frac{p_T(y\mid x)}{p_T(y\mid x)+p_\theta(y\mid x)},
$$

于是

$$
\operatorname{logit}D^*(x,y)
=\log p_T(y\mid x)-\log p_\theta(y\mid x).
$$

若判别器真能达到 $D^*$，它的 logit 就是序列密度比，学生最大化该奖励会朝教师分布移动。这个结论依赖四项条件：教师和学生样本覆盖充分，类别先验已知，判别器容量足够且优化到位，训练判别器时的学生分布与执行策略更新时一致。现实系统通常四项都不满足。

最先破裂的是有限样本。语言序列空间巨大，同一道题的教师与学生往往各只有少数回答。判别器不能估计完整密度，只能寻找训练样本中最稳定的可分特征。长度、格式、固定开头、标点、代码块数量和自我纠正用语都比“推理是否正确”容易学习。分类准确率越高，未必越接近理想密度比，也可能只是捷径越明显。

### 2. 学生为什么会追逐捷径

普通分类器部署时面对被动数据，奖励判别器面对的是一个主动优化其输出的策略。只要某个表面特征能稳定提高分数，策略梯度就会增加这个特征的概率。学生可能重复教师常用句式、无效延长答案、添加固定总结，甚至生成判别器喜欢但任务验证器拒绝的结构。

这种“模型作弊”由目标函数直接产生。训练器要求最大化 $r_D(x,y)$，学生没有义务理解研究者心中的“像教师应该意味着高质量”。判别分数只有在学生可到达区域内与目标质量一致，才具有正确奖励语义。

一个简单例子是长度。教师默认生成 800 token，学生初始只生成 300 token，判别器仅凭长度就能取得高准确率。学生优化后把答案延长到 800 token，奖励上涨，正确率不变。下一轮重新训练判别器，长度不再可分，它又转向某种格式特征。表面看是判别器和学生共同进步，实际只是捷径轮换。

## 3. 动态漂移的三种时间尺度

判别系统至少有三个版本：产生负样本的行为学生、当前 learner、以及当前判别器。rollout 与更新异步时，负样本来自滞后策略 $p_{\mu}$，学生梯度却作用于 $p_\theta$。判别器学习的是 $p_T/p_\mu$，不再是当前需要的 $p_T/p_\theta$。策略变化越快，奖励越陈旧。

教师数据也可能漂移。若为节约成本长期缓存教师回答，教师分布固定而学生逐渐逼近这些有限样本，判别器开始记忆缓存文本。若教师采样温度、系统提示或模型版本变化，正样本含义又会改变。系统必须给教师输出和判别器 checkpoint 记录版本，不能把所有“教师样本”视为同一分布。

第三种漂移来自提示分布。训练中按学生失败率重采样困难题，会改变 $x$ 的边缘分布；判别器可能把题目类型与类别关联起来，而不是比较同题回答。正负样本必须在提示层配对或重加权，否则密度比公式中的共同条件 $x$ 不成立。

### 4. 饱和为何让奖励失去梯度

当教师与学生差距很大，判别器能把两类样本近乎完美分开，$D(y_T)\approx1$、$D(y_S)\approx0$。若直接使用 $\log D$ 或概率作为奖励，学生样本之间的分数差异很小，策略看不到哪个方向更接近教师。使用 logit 能扩大低概率区间，却也会放大校准误差和极端样本。

降低判别器更新次数、标签平滑、加入梯度惩罚或混合较旧学生样本，可以避免过快饱和。它们共同降低分类边界的锐度，却解决不了语义捷径。一个平滑的长度分类器仍然只奖励长度。正则化必须与反事实诊断一起使用。

反过来，判别器太弱时，奖励接近随机噪声。学生在有限 batch 上仍可能找到偶然高分模式，把噪声放大成稳定行为。因而判别准确率既不能太高也不能太低，但“中等准确率”本身也不是充分条件，必须看它是否对语义变化敏感。

## 5. 构造反事实诊断集

主动改变单个因素比继续看训练准确率更能揭示判别器学到什么。对同一答案制作长度截断与无意义扩写，若分数随长度而非正确性变化，说明存在长度捷径；统一教师和学生的格式模板，观察分数差是否消失；把教师答案做语义等价改写，检查判别器是否把风格变化当成质量下降。

还可以构造四象限：教师风格且正确、教师风格但错误、学生风格且正确、学生风格且错误。理想任务奖励应优先正确性，纯教师密度比则可能优先来源风格。实验必须先说明自己要模仿分布还是提高任务成功，再选择评价标准。若目标是蒸馏教师整体行为，风格并非完全无关；若论文声称提升推理，正确性必须独立测量。

对于代码和数学任务，环境验证器提供了稀疏但可靠的锚点。可计算判别分数与测试通过率、最终答案正确性、首次错误位置之间的相关性。相关性只说明统计联系，仍不足以证明因果，但能及时发现判别器完全偏离任务。

### 6. 锚点集怎样监控漂移

保留一组跨训练阶段不变的回答，其中包括不同质量、长度、格式和模型来源。每次判别器更新后重新打分，记录排序相关、分数均值和校准曲线。若同一锚点在没有内容变化时奖励大幅跳动，学生面对的是非平稳目标。

锚点不能只来自初始学生。随着策略变强，应加入新的边界样本，但旧锚点仍要保留，用于观察长期遗忘。可以将锚点分成语义质量轴与表面风格轴：前者期望排序稳定，后者期望在内容相同时分数接近。

独立判别器也是常用检查。训练奖励使用判别器 $D_1$，评估另用不同架构、不同数据切分的 $D_2$。学生只在 $D_1$ 上上涨而 $D_2$ 不动，是奖励投机信号。不过两个判别器可能共享相同数据偏差，因此环境指标和人工抽检仍不可少。

### 7. 数据配平比模型调参更先

教师与学生样本应使用相同提示、相近采样温度、最大长度与停止规则。若教师天然更长，可按长度分桶配对，或在判别器输入中遮蔽容易泄漏来源的模板。把所有差异留给模型再靠正则化解决，往往事倍功半。

负样本需要覆盖当前学生，而不是长期依赖旧缓存。可以保留多版本学生样本提高边界覆盖，但训练时应标记版本并控制比例。过多早期弱样本会让分类过于容易，当前学生的细微差异反而没有权重。

正样本也不应只有单一教师解码。适量改变温度与表达风格，能迫使判别器关注教师分布的共同结构，而非某个模板。多样性过大又会模糊边界，因此应通过消融观察教师采样数与奖励质量，而不是默认越多越好。

## 8. 奖励形式改变优化行为

可以使用 $\log D$、$-\log(1-D)$、logit 或经过归一化的分数。它们在最优判别器附近关联同一密度比，在有限模型和极端概率下梯度尺度不同。$-\log(1-D)$ 对高分区域更敏感，logit 在两端都可能产生大值，概率奖励则容易饱和。

batch 内标准化降低尺度漂移，却让奖励含义依赖同批其他样本。若 batch 难度变化，绝对相同的回答会得到不同优势。移动均值或按题目分组的 baseline 可以缓解，但也需要记录。选择奖励形式时应展示分布和尾部，而不只报告均值。

加入环境奖励后，组合优势可写为 $A=\alpha A_D+\beta A_R$。两项尺度不同且随训练变化，固定系数可能让判别奖励在某阶段完全压过任务回报。监控梯度范数、优势相关和冲突样本比例，比只看两个 loss 的数值更可靠。

### 9. 过程判别器能否解决信用分配

完整序列判别器只在末尾给分，长 CoT 的早期动作承担高方差信号。训练前缀或步骤判别器可以给出稠密奖励，但需要定义“这个前缀像教师”的标签。教师前缀未必总能通向正确答案，学生的不同推理风格也可能有效。

若用教师完整轨迹中的前缀作正样本、学生前缀作负样本，判别器仍容易根据位置、长度和模板分类。更强的设计是在同一题、同一步数上配对，并用 continuation 成功率辅助标注。代价是需要更多教师生成或验证器调用。

过程反馈的价值应通过首次错误位置和从中间状态继续生成的成功率验证。若中间奖励变密却没有改善 continuation，它可能只是把序列风格分数拆到每一步。

### 10. 交替更新的控制变量

一次循环包含采样多少学生轨迹、生成多少教师回答、判别器训练几步、学生更新几步，以及何时广播新权重。每个比例都会改变动态。判别器步数太多导致饱和，学生步数太多导致奖励陈旧；频繁刷新最稳，却增加生成成本。

可以用锚点稳定性和当前样本分类间隔决定何时更新，而不是固定每 $N$ 步。若当前学生与教师已难区分，继续加强判别器可能只会挖掘捷径；此时转向环境回报或降低蒸馏权重更合理。

历史判别器集成能平滑奖励，但会保留旧偏差；目标网络式慢更新能降低跳动，却增加滞后。它们都属于偏差—稳定性折中，应与单判别器基线在相同计算下比较。

## 11. 怎样证明不是奖励投机

最弱的证据是训练判别分数上涨。更强一层是在冻结的独立判别器上上涨；再强一层是任务验证器、人工偏好和跨分布测试同时改善。若学生确实接近教师分布，还应看到来源分类越来越困难，而非学生只在奖励模型上得高分。

可做“奖励移除”实验：训练结束后不使用判别器，以标准解码评测学生。若能力只在带奖励 rerank 时出现，改进属于推理搜索而非参数学习。还可将学生输出交给新的教师盲评，避免原判别器循环自证。

失败案例要按机制分类。表面模仿说明数据配平或判别捷径；正确率下降说明教师风格与任务目标冲突；训练振荡说明更新时标或奖励尺度；多样性坍缩说明密度比目标或策略约束过强。不同原因对应不同修复。

### 12. 与白盒 OPD 的选择

能访问教师 logits 时，局部分布匹配通常信息更直接、信用路径更短。黑盒判别路线的优势是接口通用，并能处理教师与学生 tokenizer 不同、只提供完整文本的情况。它付出的代价是额外中介模型和动态博弈。

教师调用昂贵但可缓存时，离线序列蒸馏可能比持续判别更新更实用；学生状态偏移严重、教师文本 API 能针对性响应时，黑盒 on-policy 查询才显示价值。任务有可靠验证器时，判别奖励最好作为教师风格与过程指导，最终方向仍由任务回报约束。

判别器方法的验收不应停在“模型更像教师”。它需要证明来源分类对应有用的密度差信息，更新后的奖励保持稳定，学生没有利用表面捷径，并且在移除所有训练期中介后仍提升目标能力。只有这条链完整，黑盒蒸馏才真正把教师文本转成了可泛化知识。

## 13. 最小可复现实验

一个规模不大的实验就能暴露大部分问题。选择带自动验证器的任务，固定一批提示，让教师和学生采用相同长度与温度生成。先训练判别器，报告普通分类准确率；再加入长度匹配、模板统一和语义等价改写，观察准确率变化。若轻微格式处理就让性能坍塌，原判别器主要依赖捷径。

随后冻结判别器做少量策略更新，同时跟踪训练奖励、独立判别器分数和任务通过率。三者同向才说明奖励具有基本可用性。接着允许判别器交替更新，加入跨版本锚点，测量奖励漂移。最终在相同教师 token 和 rollout 预算下，与教师续写 SFT、偏好训练和结果奖励比较。

这个实验矩阵把接口、奖励语义和动态稳定性依次拆开。即使最终方法没有超过简单 baseline，也能准确知道问题落在哪一层，而不是把所有失败归结为黑盒教师不够强。

### 14. 外部条件变化后的判断

随着长上下文和推理 API 变便宜，教师可以返回多次批改或步骤级反馈，判别器不再是唯一压缩文本的办法；随着可验证任务增加，环境奖励能提供更硬的锚点。判别路线的相对价值会从“唯一可用信号”转为“补充稠密语义”。

另一方面，学生能力接近教师后，判别任务更难，表面捷径反而更有吸引力。此时需要更严格的配对数据和独立评价。旧的 GAN 稳定性问题不会因为模型规模变大而自动消失，只是以语言风格、长程推理和异步采样的新形式出现。

理解这条脉络后，遇到新的黑盒蒸馏算法，可以依次检查：它估计哪一种密度差，如何防止来源捷径，怎样跟踪策略与奖励漂移，最终用什么独立目标验收。四个问题比方法名字更能预测它是否可靠。

## 15. 校准误差为何会改变策略梯度

两个判别器可以有相同分类准确率，却给出完全不同的概率尺度。一个对所有学生样本输出 $0.49$，另一个在少数样本上输出 $0.01$ 与 $0.99$；若概率或 logit 直接作为奖励，后者产生更大的优势尾部。分类指标看不见这种差异，策略更新却高度敏感。

可以在冻结验证集上画可靠性曲线，或用温度缩放校准来源概率。但来源概率校准不等于任务质量校准，因此还要按环境正确性分桶观察。训练中每次更新判别器后重新校准，会改变奖励尺度；若不重校准，则跨版本分数不可直接比较。

优势归一化能消除全局缩放，保留样本排序，却无法修复错误排序。它还让同一回答的有效奖励依赖 batch 中其他样本。诊断时应同时保存原始 logit、归一化优势和最终梯度权重，才能判断问题来自判别器还是训练器。

### 16. 多判别器并不自动消除偏差

使用多个随机初始化判别器取平均，可以降低估计方差；若它们共享同一训练数据和模板差异，所有模型会学到相同捷径。真正有用的多样性来自数据视角、架构与特征限制，例如一部分隐藏长度，一部分使用语义嵌入，一部分在格式统一后训练。

判别器分歧可以当作不确定性，只在一致样本上给强奖励。不过学生可能学会落入所有判别器共同的盲区。分歧低只说明模型一致，不证明判断正确，仍需环境或人工锚点。

教师本身也可以作为独立裁判，但若生成教师与评价教师相同，偏好会自洽地奖励自身风格。换模型家族、改变提示并加入可验证指标，能减少循环论证。

### 17. 分布外状态上的行为

策略优化会把学生推向训练数据边界，恰好是判别器最不可靠的区域。常规验证集与训练分布相似，无法暴露这种问题。可以主动搜索高判别分、低任务回报的样本，建立 adversarial buffer，再观察新判别器是否真正修复语义，还是换了另一条捷径。

对分布外分数做保守惩罚、限制每轮策略 KL 或拒绝过高不确定样本，可以降低灾难更新。这些手段限制学生探索，也可能阻止发现教师之外的好策略。选择强度要根据独立任务回报，而非只追求判别器稳定。

最稳妥的边界是让判别奖励负责局部引导，让可验证结果负责最终选择。没有硬验证器时，应承认结论主要是教师分布模仿，而非已经证明的任务能力提升。

提示扰动后的策略行为也需检查。若只更换题目措辞、顺序或输出模板，判别奖励便大幅变化，说明它依赖表面分布；若任务成功与奖励排序仍稳定，才有理由相信信号抓住了更可迁移的教师特征。这类扰动成本低，却能补足普通同分布验证集最容易遗漏的证据。

扰动后的差值还应与教师自身波动比较，避免把采样噪声误判为判别器脆弱性。
