# 熵最小化与持续测试时适应

## TENT：以预测熵作为测试时目标

TENT 在测试时最小化模型对目标批次预测分布的熵，并更新归一化统计量及归一化层的通道级仿射参数，而不是无约束更新整个网络。对类别分布 $p_\theta(y\mid x)$，目标为：

$$
\mathcal{L}_{ent}(x)=-\sum_c p_\theta(c\mid x)\log p_\theta(c\mid x).
$$

低熵意味着模型更确定，但“更确定”不保证“更正确”。当源模型预测系统性错误、类别严重不平衡或批次过小时，熵最小化可能强化错误。

## 从单域适应到持续目标流

持续测试时适应（Continual Test-Time Adaptation, CTTA）让目标分布随时间变化，并保留适应后的模型状态。此时需要同时处理：

- 当前分布上的快速适应。
- 过去目标域与源域能力的遗忘。
- 伪标签或低熵错误被后续更新放大。
- 域切换未知时的恢复与重置。

CoTTA 使用权重平均的教师与多增强预测来提高伪标签稳定性，并随机把部分参数恢复到源模型值，以抑制长期漂移。它代表一种“慢教师 + 一致性 + 随机恢复”的组合，而不是证明随机恢复适合所有目标流。

## 比较时必须对齐

| 项目 | 容易造成的偏差 |
| --- | --- |
| 是否打乱目标流 | 打乱会破坏真实时间相关性 |
| 批次大小 | 影响归一化统计和梯度稳定性 |
| 重置频率 | 每域重置通常比永不重置容易 |
| 适应后再预测或先预测 | 使用当前样本更新后再评当前样本可能更有利 |
| 可训练参数 | 全模型更新与仅归一化层成本、风险不同 |
| 增强次数 | 多视图提高计算量，也可能改善伪标签 |
