# 测试时适应

测试时适应（Test-Time Adaptation, TTA）关注模型部署后遇到源训练分布之外的数据时，如何利用目标输入本身更新统计量、参数或预测。目标数据通常无标签，因此适应信号来自自监督任务、预测熵、一致性或教师模型。

## 本章边界

本章中的 Test-Time Training 指 Sun 等人在 ICML 2020 系统化提出的经典路线：训练时联合主任务和自监督辅助任务，测试时用目标样本的自监督损失更新共享特征。它与 [TTT Layers](../05-测试时训练与长上下文/5.1-ttt-layers与fast-weights.md) 不是同一种架构。

测试时适应也不自动等于持续学习。若每个样本后都重置到源模型，它更接近独立适应；若状态沿非平稳目标流持续更新，才会同时出现遗忘、漂移和顺序效应。

## 协议轴

| 维度 | 需要明确的选择 |
| --- | --- |
| 目标流 | 固定单域、逐渐变化、突然切换或混合域 |
| 状态 | 每样本重置、每域重置、永不重置 |
| 可更新部分 | BN 统计、归一化仿射参数、特征提取器、全模型 |
| 监督信号 | 自监督、熵、一致性、伪标签、教师预测 |
| 批处理 | 单样本、固定批次、动态批次；是否允许打乱 |
| 评价 | 适应前或适应后预测；是否在线即时评价 |

## 最低基线

- 不适应的源模型。
- 只更新归一化统计量。
- 每个域重置与持续不重置两种协议。
- 与所提方法相同更新步数和可训练参数的简单熵最小化基线。
