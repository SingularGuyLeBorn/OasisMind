# 大模型持续预训练与参数高效适配

> 相关阅读: [1.1 持续学习的场景与术语](../../01-基础与问题定义/1.1-持续学习的场景与术语/1.1-持续学习的场景与术语.md) · [2.2 回放与外部记忆](../2.2-回放与外部记忆/2.2-回放与外部记忆.md) · [2.3 参数隔离与动态架构](../2.3-参数隔离与动态架构/2.3-参数隔离与动态架构.md) · [3.5.1 继续预训练](../../../llm-guide/3-预训练/3.5-继续预训练与长上下文训练/3.5.1-继续预训练/3.5.1-继续预训练.md)

预训练大模型上的持续学习主要有三条线: 继续预训练, 在指令与对齐数据上的持续微调, 冻结骨干的参数高效适配 (L2P, O-LoRA, InfLoRA). 另有一类做法不做顺序训练, 直接合并独立微调的模型.

第 1.1 篇第 4.2 节算过显存: 70B 模型仅 BF16 权重就是 140 GB, 混合精度 Adam 全量训练每参数约 16 字节. 资源之外, 大模型上的持续学习还有三点与传统设定不同.

- **起点是一个已经学了大量知识的模型**. 传统设定从随机初始化出发, 遗忘的对象是前几个任务; 大模型还可能遗忘预训练阶段获得的通用能力. 评测要覆盖通用能力, 不能只看序列里的任务.
- **任务边界模糊**. 继续预训练是连续的语料流, 指令微调的「任务」划分常常是人为的. 很多需要任务边界的方法 (第 2.1 篇的 EWC, SI) 不能直接使用.
- **旧数据通常拿不到**. 开源模型一般不公开预训练语料, 回放只能用分布相近的公开数据代替.

后面的讨论按更新范围分三层：继续预训练更新全部参数，数据是无标签语料；指令和任务的持续微调更新全部或部分参数，数据是有标签的指令；参数高效方法冻结骨干，只训练提示或低秩矩阵。三条路线汇合到模型合并与版本管理问题。

## 1 继续预训练

### 1.1 学习率

预训练的学习率通常衰减到峰值的一小部分. 在衰减后的学习率上继续训练, 模型几乎学不动新分布. Gupta et al. (2023) 用 Pythia 410M 研究这个问题: 先在 Pile 上训练 300B token, 再在 SlimPajama 上继续训练 297B token. 学习率先线性升温, 再余弦衰减, 峰值取 $1.5\times10^{-4}$, $3\times10^{-4}$, $6\times10^{-4}$ 三档. 主要发现:

- **重新升温先让 loss 上升**. 升温阶段上游 (Pile) 和下游 (SlimPajama) 的 loss 都会先上升. 长期看, 升温后的模型在下游上超过从头训练的模型.
- **warmup 长度不重要**. 对 297B token 的日程比较 0%, 0.5%, 1%, 2% 四种 warmup 比例, 结果差别很小.
- **峰值决定适应与遗忘**. 峰值越高, 下游适应越多, 上游遗忘也越多. 提高峰值会一致地抬高 Pile 上的最终 loss.
- **从最新的 checkpoint 出发最好**.

困惑度和 loss 是连续量, 比较时用「降低多少」或比值, 不用百分点.

Code Llama (Rozière et al., 2023) 从 Llama 2 出发继续训练, 发现沿用 Llama 2 的原学习率效果最好: 7B 和 13B 为 $3\times10^{-4}$, 34B 和 70B 为 $1.5\times10^{-4}$. 这与微调阶段降学习率的惯例相反. Code Llama 初始阶段训练 500B token, 是 Llama 2 预训练 2T token 的四分之一, 更接近第二次预训练.

第二次预训练改动参数的幅度也接近预训练的量级. DARE 论文 (Yu et al., 2024) 给出了一个可以量化的差别: SFT 前后的参数差 (delta) 通常在 0.002 以内, 而经过继续预训练后可以很快达到 0.03 左右. 这时随机丢掉 delta 的 DARE 不再可用; 只丢掉 10% 的微调后参数 (预训练参数加 delta), 性能就会崩溃到接近零. 继续预训练对参数的改动比微调大一个数量级, 第 4 节的模型合并方法大多以「增量很小」为前提, 不能直接用在继续预训练得到的模型上.

### 1.2 回放与数据配比

Ibrahim et al. (2024) 用 405M 模型先在 Pile 上训练 300B token, 再分别继续训练 SlimPajama (300B token, 弱分布偏移) 和德语 Common Crawl (200B token, 强分布偏移). 每次继续训练都重置优化器状态. 回放采用算力等价的方式: 回放的旧数据 token 从新数据预算中扣除, 总 token 数不变. 设新数据预算为 $N_1$ 个 token, 回放比例为 $\rho$, 则实际看到的新数据为 $(1-\rho)N_1$, 旧数据为 $\rho N_1$.

强分布偏移下的最终验证 loss (论文 Table 2):

| 设置 | Pile loss | 德语 loss | 平均 |
|------|------|------|------|
| 无回放 | 3.56 | 1.11 | 2.34 |
| 1% 回放 | 2.83 | 1.12 | 1.97 |
| 5% 回放 | 2.57 | 1.12 | 1.85 |
| 25% 回放 | 2.33 | 1.16 | 1.75 |
| 50% 回放 | 2.24 | 1.22 | 1.73 |
| 并集从头训练 (500B) | 2.26 | 1.25 | 1.75 |

1% 回放就把 Pile loss 从 3.56 降到 2.83, 德语 loss 只从 1.11 升到 1.12. 回放到 25% 时平均 loss 与并集从头训练持平. 弱分布偏移下, 0.5% 回放把 Pile loss 从 2.44 降到 2.27, 5% 回放的平均 loss 为 2.37, 并集从头训练为 2.35. 论文据此给弱偏移选 5% 回放, 强偏移选 25%. 在已有 Pile 模型的基础上, 这样做的额外算力只有从头训练的一半 (弱偏移 300B 对 600B) 或 40% (强偏移 200B 对 500B).

这些数字的前提是回放的确实是原始的 Pile. 用替代语料时效果会打折扣, 需要自己测.

公开的继续预训练配方里也混着旧数据. Code Llama 初始阶段的数据中, 代码占 85%, 与代码相关的自然语言占 8%, 一般自然语言占 7%. 后两部分的作用之一就是回放, 保住自然语言能力. Code Llama - Python 在此基础上再训练 100B token, 配比为 Python 75%, 其他代码 10%, 与代码相关的自然语言 10%, 一般自然语言 5%: 每往专门方向走一步, 前一阶段的数据都以一定比例留在新阶段里. Instruct 阶段又混入 6% 的代码数据和 2% 的自然语言数据作为 rehearsal. 这些比例没有系统的消融, 与 Ibrahim et al. 的「强偏移约 25% 回放」处在同一量级.

回放的反面是新数据取多少. 知识随时间变化时, 继续预训练要处理的是「新事实替换旧事实」, 未变的那部分知识要不要再训一遍, 就是这里的回放问题. Jang et al. (2022) 的 TemporalWiki 比较相邻的英文 Wikipedia 快照, 只取变化的部分作为训练语料 (TWiki-Diffsets), 用对应的 Wikidata 快照构造评测集 (TWiki-Probes), 把事实分为未变和已变两类. 论文报告, 只在差异数据上做持续学习, 困惑度与在整个快照上训练相当或更好, 计算量少 12 倍. 数据规模可以说明这个差距从哪来: 论文用 2021 年 8 月到 12 月的月度快照, 每个 Wikipedia 快照约 630 万篇文章, 46 亿到 47 亿 token; 相邻两月的差分集约 30 万篇文章, 3.5 亿到 3.8 亿 token, 不到完整快照的十分之一. 第 3.2 篇在基准部分给出了探针的构造细节.

### 1.3 目标函数、token 混合与梯度冲突

继续预训练仍然优化下一个 token 的负对数似然. 设语料域为 $d$, 域采样权重为 $\alpha_d$, 有效 token 掩码为 $m_t$, 混合目标可以写成

$$
\mathcal L_{\mathrm{mix}}(\theta)=\sum_d\alpha_d\,\mathbb E_{x\sim\mathcal D_d}\left[-\sum_t m_t\log p_\theta(x_t\mid x_{<t})\right],\qquad \sum_d\alpha_d=1. \tag{1a}
$$

$\alpha_d$ 应对应实际进入损失的 token 比例, 不一定等于文档或样本的抽样比例. 长文档、截断、padding 和损失掩码都会改变有效贡献. 若按样本数混合而不核对有效 token, 标称的 5% 回放可能并不是梯度里的 5%.

**算例一: 从 token 预算反推样本数.** 一个训练步预算 1,000,000 个有效 token, 回放比例 $\rho=5\%$, 则旧域应提供 50,000 token, 新域提供 950,000 token. 若旧样本平均有 500 个有效 token, 新样本平均有 1,000 个, 这一批约需 100 个旧样本与 950 个新样本. 此时旧样本占样本总数的 $100/1050\approx9.52\%$, 却只占 token 的 5%. 反过来若机械地抽 5% 旧样本, 旧 token 占比会低于 5%. 所以配比记录至少要同时报告样本数、原始 token、有效 token 与总训练 token.

遗忘也可以从梯度局部解释. 记旧域和新域在当前位置的梯度为 $g_{\mathrm{old}}$、$g_{\mathrm{new}}$, 混合梯度为

$$
g_{\mathrm{mix}}=\rho g_{\mathrm{old}}+(1-\rho)g_{\mathrm{new}}. \tag{1b}
$$

若 $g_{\mathrm{old}}^\top g_{\mathrm{new}}<0$, 沿新域梯度下降会在一阶近似下抬高旧域损失. 新语料很少出现旧域稀有 token 或旧上下文时, 它们没有校正梯度; 与新域共用的词表、注意力和前馈参数却仍被更新, 因而条件分布会漂移. 这比把遗忘描述成「旧知识被删掉」更准确.

取一个二维玩具例子, $g_{\mathrm{old}}=(1,0)$, $g_{\mathrm{new}}=(-0.6,0.8)$. 则 $g_{\mathrm{old}}^\top g_{\mathrm{mix}}=-0.6+1.6\rho$. $\rho=25\%$ 时结果为 $-0.2$, 局部冲突仍在; 只有 $\rho>37.5\%$ 才变为正. 这个计算只说明回放比例取决于梯度几何, 不能用它推出真实模型需要 37.5% 回放. 同样, 旧域验证 loss 上升能证明分布拟合变差, 不能单独定位哪些事实丢失; loss 不变也不能证明问答、安全或指令遵循没有退化.

## 2 指令与任务的持续微调

### 2.1 TRACE

Wang et al. (2023) 的 TRACE 是为对齐后的大模型设计的持续学习基准, 由 8 个数据集组成: 领域任务 ScienceQA, FOMC, MeetingBank; 多语言任务 C-STANCE (中文立场检测) 和 20Minuten (德语文本简化); 代码补全 Py150; 数学推理 NumGLUE 的两个子集. 每个任务采样 5000 条, 分类任务按类别均衡. 除了传统的持续学习指标, TRACE 增加了三个指标: General Ability Delta (通用能力的变化), Instruction Following Delta (指令遵循能力的变化), Safety Delta (安全性的变化).

论文的主要发现:

- 在 TRACE 上依次训练后, 通用能力明显下降, 数学和推理最严重. Llama-2-Chat 13B 的 GSM8K 准确率从 28.8% 降到 2%.
- 多语言能力反而普遍提高. Llama-2-Chat 7B 的 TydiQA F1 从 23.47 升到 33.23.
- 全参数训练比 LoRA 更容易拟合目标任务, 通用能力的下降也更明显.
- 指令遵循能力在持续学习后显著下降.

论文还提出 Reasoning-augmented Continual Learning (RCL): 训练时让模型先生成任务分析和推理过程. 论文报告这样做既提高了目标任务的表现, 也更好地保住了模型原有的能力.

TRACE 的数据说明, 在大模型上只看序列内任务的平均准确率是不够的. 序列任务都学会了, GSM8K 却从 28.8% 掉到 2%, 这种遗忘只有在序列外的通用基准上才能看到.

### 2.2 Continual-T0

Scialom et al. (2022) 从 T0 3B 出发. T0 已经在 50 个数据集上做过多任务指令微调, 在 12 个未见数据集上有零样本能力. 他们在 T0 上依次学习 8 个新的生成任务 (连同之前的数据集共 70 个), 用回放防止遗忘: 每个旧训练任务取 100,000 条样本, 回放比例 $r$ 取 0, 0.25%, 1%, 1% 对应每个任务 1,000 条. 结果是在 1% 回放下, 模型几乎保持了旧数据集上的全部表现, 未见数据集上的零样本能力也得以保持. 论文还观察到, 模型能把学过的指令以训练中从未出现的方式组合起来.

论文把成功归因于自监督预训练. 这个结论与 Ibrahim et al. 的继续预训练实验一致: 对一个已经在大量数据上训练过的模型, 很少的回放就够了.

### 2.3 微调与安全对齐

Qi et al. (2023) 研究了微调对安全对齐的影响, 把风险分为三级:

1. **显式有害样本**: 用 10 条对抗设计的有害样本微调 GPT-3.5 Turbo, 通过 OpenAI 的接口花费不到 0.20 美元, 模型就会响应几乎所有有害指令.
2. **身份转换数据**: 微调数据不含有害内容, 但让模型总以肯定的前缀开头回答.
3. **良性数据**: 只用 Alpaca, Dolly, LLaVA-Visual-Instruct 这类常用的良性数据集微调, 安全对齐也会被削弱, 程度较轻.

论文认为第三种情况可能来自对初始对齐的灾难性遗忘, 也可能来自有用性与无害性之间的固有张力. 从持续学习的角度看, 安全对齐是模型的一项「旧能力」, 每次微调后都应当和其他能力一起评测. TRACE 的 Safety Delta 就是为此设计的.

### 2.4 SFT 与继续预训练的边界

两者都可能更新同一组参数, 两者的监督信号不同. 继续预训练对完整文档做因果语言建模, 主要改变领域词汇、事实、文体与条件分布; SFT 把输入组织成指令和回答, 通常只让回答 token 计入损失, 主要学习「收到这种请求时怎样作答」. 因而领域文档上的 loss 下降不能直接推出指令遵循提高, SFT 基准提高也不能证明模型已系统吸收领域知识.

常见流水线是先用领域原文继续预训练, 再用少量领域指令做 SFT. 前一阶段解决覆盖面, 后一阶段建立调用知识的交互格式. 若只有结构化问答而没有大规模原文, 任务更接近 SFT; 若训练数据是新闻、论文或代码仓库的连续文本, 即使最终服务某个任务, 仍属于继续预训练. 两阶段都可能损害旧能力和安全对齐, 不能因为第二阶段数据「良性」就省掉安全回归测试. 比较两者时还要固定 tokenizer、模板、有效 token 数与更新参数范围, 否则无法把收益归因于目标函数本身.

## 3 冻结骨干的参数高效方法

### 3.1 记号与思路

LoRA (Hu et al., 2022) 冻结预训练权重 $W_0\in\mathbb{R}^{d\times k}$, 只训练一个低秩增量:

$$
W = W_0 + BA, \qquad B\in\mathbb{R}^{d\times r},\ A\in\mathbb{R}^{r\times k},\ r\ll\min(d,k) \tag{1}
$$

本文统一用这套记号: $A$ 是降维矩阵 (把输入从 $k$ 维投到 $r$ 维), $B$ 是升维矩阵. 注意 O-LoRA 和 InfLoRA 两篇论文的记号与此不同, 下文会逐一对应.

每个任务训练一组独立的 LoRA 或提示, 推理时按任务切换, 就是第 2.3 篇参数隔离在大模型上的形式. 每个任务的增量只有 $r(d+k)$ 个参数, 存储不是问题. 问题回到两处: 推理阶段如何知道用哪一组 (路由), 以及如果多组同时生效, 它们之间如何不干扰. L2P 处理前者, O-LoRA 和 InfLoRA 处理后者.

### 3.2 L2P: 提示池

Wang et al. (2022) 的 Learning to Prompt 冻结 ImageNet 预训练的 ViT-B/16, 维护一个提示池 $\mathbf{P} = \{P_1, \dots, P_M\}$, 每个提示 $P_i\in\mathbb{R}^{L_p\times D}$ 配一个可学习的键 $k_i$. 对输入 $x$, 先用冻结的 ViT 算出查询特征 $q(x)$ (取 [CLS] 的输出), 再按匹配函数 $\gamma$ (余弦距离) 选出最近的 $N$ 个键:

$$
\mathbf{K}_x = \operatorname*{arg\,min}_{\{s_i\}_{i=1}^{N}\subseteq[1,M]}\ \sum_{i=1}^{N}\gamma\big(q(x), k_{s_i}\big) \tag{2}
$$

对应的 $N$ 个提示拼在输入嵌入前面, 送入 ViT, 取提示位置输出的平均做分类. 训练目标是

$$
\min_{\mathbf{P}, \mathbf{K}, \phi}\ \mathcal{L}\big(g_\phi(f_r^{\text{avg}}(x_p)), y\big) + \lambda\sum_{s_i\in\mathbf{K}_x}\gamma\big(q(x), k_{s_i}\big) \tag{3}
$$

第一项是分类损失, $g_\phi$ 是分类头; 第二项把被选中的键拉向查询特征, 使相似的输入选中相同的提示. 论文还可以加一个选择频率的惩罚, 让不同任务倾向于使用不同的提示.

L2P 不需要任务标识, 路由由键和查询的匹配决定. Split CIFAR-100 (10 个任务, 每个任务 10 类, Class-IL) 上取 $M=10$, $N=5$, $L_p=5$, 新增参数 46,080 个, 约为骨干的 0.05%. 论文 Table 1 的结果 (平均准确率 / 遗忘, %):

| 方法 | 缓冲区 | 平均准确率 | 遗忘 |
|------|------|------|------|
| FT-seq-frozen | 0 | 17.72 | 59.09 |
| FT-seq | 0 | 33.61 | 86.87 |
| EWC | 0 | 47.01 | 33.27 |
| LwF | 0 | 60.69 | 27.77 |
| L2P | 0 | 83.83 | 7.63 |
| ER | 每类 10 | 67.87 | - |
| DER++ | 每类 10 | 61.06 | - |
| L2P-R | 每类 10 | 84.21 | - |
| ER | 每类 50 | 82.53 | - |
| DER++ | 每类 50 | 83.94 | - |
| L2P-R | 每类 50 | 86.31 | 5.83 |
| 上界 (联合训练) | - | 90.85 | - |

### 3.3 O-LoRA

Wang et al. (2023) 的 O-LoRA 为第 $t$ 个任务新建一组 LoRA, 之前各组冻结. 论文的 LoRA 记号是 $\Delta W = AB$, 其中 $A\in\mathbb{R}^{d\times r}$ 是升维的一侧, 对应式 (1) 里的 $B$. 论文假设 LoRA 的列空间能刻画任务的梯度子空间, 要求新旧任务的子空间正交:

$$
O_{i,t} = A_i^\top A_t = 0 \tag{4}
$$

用式 (1) 的记号, 就是 $B_i^\top B_t = 0$. 训练目标在任务损失上加正交惩罚:

$$
\mathcal{L} = -\sum_{(x,y)\in\mathcal{D}_t}\log p_\Theta(y\mid x) + \lambda_1\sum_{i=1}^{t-1}\sum_{j,k}\big\|O_{i,t}[j,k]\big\|^2 \tag{5}
$$

LoRA 只加在注意力的 $W_q$ 和 $W_v$ 上. 推理阶段所有 LoRA 组同时生效, 不需要任务标识.

实验用 T5-large, 两个基准: 标准 CL 基准 (AG News, Amazon, Yelp, DBpedia, Yahoo 五个文本分类任务, 3 种顺序) 和 15 任务的长序列 (再加 GLUE 的 4 个, SuperGLUE 的 5 个和 IMDB, 每个任务 1000 条训练样本), 结果取 3 次运行均值. 论文 Table 2 的平均准确率 (%):

| SeqFT (顺序全量微调) | 28.5 | 7.4 |
| SeqLoRA (一组 LoRA 顺序训练) | 43.7 | 1.6 |

### 3.4 InfLoRA

Liang & Li (2024) 的 InfLoRA 全称 Interference-Free Low-Rank Adaptation. 它的记号是 $W_t = W_{t-1} + A_tB_t$, 其中 $B_t\in\mathbb{R}^{r\times d_I}$ 是降维矩阵, $A_t\in\mathbb{R}^{d_O\times r}$ 是升维矩阵, 对应式 (1) 的 $A$ 和 $B$.

InfLoRA 与 LoRA 的区别在于降维矩阵不训练. 学第 $t$ 个任务前, 先设计好 $B_t$ 并冻结, 只训练 $A_t$ (初始化为零). 论文证明, 只训练 $A_t$ 等价于在 $B_t$ 的行空间 $\mathrm{span}\{b_1^t, \dots, b_r^t\}$ 内微调预训练权重. 只要让这个子空间与旧任务的梯度正交, 新任务的更新就不会干扰旧任务.

这个等价关系可以直接推出来. 层的输出为 $e = W_{t-1}h + A_tB_th$, 由链式法则, $A_t$ 的梯度为

$$
\frac{\partial\mathcal{L}}{\partial A_t} = \frac{\partial\mathcal{L}}{\partial e}\, h^\top B_t^\top \tag{5a}
$$

学习率为 $\eta$ 时 $A_t$ 走一步, 等效权重的变化是

$$
\Delta W = -\eta\,\frac{\partial\mathcal{L}}{\partial e}\,h^\top B_t^\top B_t = -\eta\,\frac{\partial\mathcal{L}}{\partial W}\,B_t^\top B_t \tag{5b}
$$

其中 $\frac{\partial\mathcal{L}}{\partial W} = \frac{\partial\mathcal{L}}{\partial e}h^\top$ 正是直接微调 $W$ 时的梯度. $B_t$ 的行正交归一时, $B_t^\top B_t$ 是投影到其行空间的投影矩阵, 所以 $\Delta W$ 的每一行都被投影进 $\mathrm{span}\{b_1^t,\dots,b_r^t\}$.

由式 (5b) 还能看出为什么正交就不干扰. 设 $h_{\text{old}}$ 是旧任务在这一层的某个输入, 如果 $B_t$ 的每一行都与 $h_{\text{old}}$ 正交, 那么 $\Delta W\,h_{\text{old}} = -\eta\,\frac{\partial\mathcal{L}}{\partial W}B_t^\top (B_t h_{\text{old}}) = 0$. 新任务的更新完全不改变这一层在旧任务输入上的输出. 线性层的梯度可以写成「输出误差乘以输入」, 所以旧任务梯度张成的空间就是旧任务输入张成的空间, DualGPM 维护的正是这组输入的基.

$B_t$ 的设计分三步. 记新任务的输入矩阵为 $H_t = [h_1^t, \dots, h_n^t]$, 用它的列空间近似新任务的梯度空间 $\mathcal{N}_t$. 旧任务的梯度空间 $\mathcal{M}_t$ 用 DualGPM 维护一组正交基 $M_t$. 先去掉 $H_t$ 在 $\mathcal{M}_t$ 上的分量:

$$
\hat H_t = H_t - M_t M_t^\top H_t \tag{6}
$$

$\hat H_t$ 的每一列都落在 $\mathcal{N}_t \cap \mathcal{M}_t^\perp$ 里. 再对 $\hat H_t^\top$ 做 SVD, $\hat H_t^\top = V_t\Sigma_t U_t$, 取最大的 $r$ 个奇异值对应的行:

$$
B_t = (U_t)_r \tag{7}
$$

这样 $B_t$ 的行既在新任务的输入空间里 (可塑性), 又与旧任务的梯度空间正交 (稳定性). 随着任务增多, $\mathcal{M}_t$ 扩大, 留给新任务的空间缩小; 论文通过调节 DualGPM 对旧任务梯度的近似误差, 让 $\mathcal{M}_t$ 慢慢扩大.

实验用 ImageNet-R (200 类, 分成 5, 10, 20 个任务), CIFAR100 和 DomainNet, Class-IL 设定, 结果取 5 次运行均值. ImageNet-R 上学完全部任务后的准确率 (论文 Table 1, %):

两者约束的位置也不同. 用式 (1) 的记号, O-LoRA 约束的是升维矩阵 $B$ 的列空间, 即增量 $\Delta W$ 写入输出的方向: 新任务的增量只往旧任务增量没有用过的输出方向写. 但新任务的 LoRA 对旧任务的输入依然生效, 旧任务样本经过这一层时, 输出会多出一个与旧增量正交的分量, 这个分量经过后续层仍可能改变预测. InfLoRA 约束的是降维矩阵的行空间, 即增量读取输入的方向: 只要旧任务的输入落在旧梯度子空间里, 新增量对它们的输出就是零. 后者的「不干扰」在单层上是精确的, 代价是可用的子空间随任务增多而缩小.

### 3.5 参数与优化器显存构成

参数高效指的是可训练参数少, 不等于训练总显存或计算按同样比例下降. 对 $W_0\in\mathbb R^{d\times k}$, LoRA 有 $r(d+k)$ 个参数; 宽度为 $d$、瓶颈为 $b$ 的串联 adapter 约有 $2db$ 个参数; 长度为 $\ell$ 的 soft prompt 有 $\ell d$ 个参数. 若提示池有 $M$ 个长度为 $\ell$ 的提示, 每个提示另配一个 $d$ 维键, 总数为 $M\ell d+Md$.

混合精度 Adam 的常见账本是每个可训练参数保存 2 字节 BF16 权重、2 字节梯度、4 字节 FP32 主副本和两个各 4 字节的一二阶矩, 合计约 16 字节. 具体实现可能分片、量化或省去主副本, 所以 16 字节是预算模型, 不是硬件定律. 冻结骨干无需梯度和优化器状态, 但仍需存放权重并完成前向、反向的激活传播; 激活、临时张量和注意力开销不会随可训练参数同比缩小.

形状也决定实现能否成立. 输入激活 $X\in\mathbb R^{B\times L\times k}$ 先乘 $A\in\mathbb R^{r\times k}$ 的转置得到 $B\times L\times r$, 再乘 $B\in\mathbb R^{d\times r}$ 的转置回到 $B\times L\times d$. 这里第一个 $B$ 是批量大小, 与 LoRA 矩阵 $B$ 同名但含义不同. 单层 LoRA 额外乘加量与 $BLr(k+d)$ 同阶, 全量投影与 $BLkd$ 同阶; $r\ll d,k$ 时增量较小, 但骨干的 $BLkd$ 并未消失. soft prompt 把序列从 $L$ 拉长到 $L+\ell$, 自注意力分数矩阵从 $L\times L$ 变为 $(L+\ell)\times(L+\ell)$, 因而长提示的代价不能只按 $\ell d$ 个参数估算.

**算例二: 同一投影上的几种适配器.** 对 $4096\times4096$ 投影使用秩 $r=8$ 的 LoRA, 可训练参数为 $8(4096+4096)=65,536$, 是全矩阵 16,777,216 个参数的 $0.390625\%$. 按每参数 16 字节, 训练状态约为 1 MiB; 原 BF16 投影本身仍占 32 MiB. 若用 $b=64$ 的 adapter, 参数约为 $2\times4096\times64=524,288$, 训练状态约 8 MiB. 长度 20 的单个 soft prompt 有 81,920 个参数, 约 1.25 MiB; 若池中有 20 个提示并为每个提示保存 4096 维键, 则共有 1,720,320 个参数, 训练状态约 26.25 MiB. 这些数只比较参数账本: adapter 还增加层内计算, prompt 会拉长序列并增加注意力计算, LoRA 也没有消除骨干矩阵乘法, 因而不能由参数比例直接推断吞吐提升比例.

## 4 模型合并与评测

### 4.1 Task Arithmetic

Ilharco et al. (2023) 把微调后与预训练的参数差定义为任务向量 $\tau_t = \theta_t - \theta_{\text{pre}}$. 多个任务的合并为

$$
\theta_{\text{merged}} = \theta_{\text{pre}} + \lambda\sum_t \tau_t \tag{8}
$$

$\lambda$ 在验证集上选. 各任务独立微调, 合并时不需要任何训练数据. 从持续学习的角度看, 每来一个任务就独立微调一次, 再把任务向量加进去, 不存在顺序训练带来的遗忘; 代价换成了任务向量之间的干扰.

### 4.2 TIES-Merging

Yadav et al. (2023) 指出干扰有两个来源: 冗余的小幅值参数, 以及不同任务在同一参数上的符号冲突. TIES-Merging 分三步:

1. **Trim**: 每个任务向量只保留幅值最大的 top-$k\%$ 参数, 其余置零. 论文的实验显示, 只保留 top-20% 的参数, 性能不下降.
2. **Elect Sign**: 对每个参数, 把各任务修剪后的值求和, 取和的符号作为合并后的符号 $\gamma_m = \mathrm{sgn}\big(\sum_t \hat\tau_t\big)$.
3. **Disjoint Merge**: 对每个参数, 只对符号与 $\gamma_m$ 一致的任务取平均:

$$
\tau_m^p = \frac{1}{|\mathcal{A}^p|}\sum_{t\in\mathcal{A}^p}\hat\tau_t^p, \qquad \mathcal{A}^p = \{t : \hat\gamma_t^p = \gamma_m^p\} \tag{9}
$$

合并结果为 $\theta_{\text{pre}} + \lambda\tau_m$.

### 4.3 DARE

Yu et al. (2024) 的 DARE 对每个 SFT 模型的 delta 随机丢弃比例 $p$, 剩下的乘以 $1/(1-p)$:

$$
\tilde\delta = \frac{m\odot\delta}{1-p}, \qquad m_i\sim\mathrm{Bernoulli}(1-p) \tag{10}
$$

缩放保证了 delta 的期望不变. 论文报告 DARE 能去掉 90% 甚至 99% 的 delta 而性能基本不变, 但缩放是关键: 不缩放时只丢 30% 或 40% 就会明显变差. DARE 作为预处理, 可以接在 Task Arithmetic 或 TIES 前面, 先稀疏化再合并, 减少参数干扰. 论文合并 WizardLM-13B, WizardMath-13B 和 llama-2-13b-code-alpaca, 论文报告用 DARE 加 Task Arithmetic 合并后, LM 与 Code 合并模型的 MBPP 比单独的 Code 模型提高 19.57%. 第 1.1 节已经提到, 继续预训练后 delta 可达 0.03 左右, DARE 不再适用.

### 4.4 与顺序训练的比较

| 维度 | 顺序训练的持续学习 | 模型合并 |
|------|------|------|
| 训练方式 | 按顺序逐个任务训练 | 各任务从同一基座独立微调 |
| 是否需要旧数据 | 视方法而定 | 不需要 |
| 对任务顺序是否敏感 | 敏感 | 不敏感 |
| 失败方式 | 遗忘, 或可塑性不足 | 任务向量冲突, 合并后各任务都变差 |
| 前提 | 无 | 各任务从同一基座出发, 增量较小 |

模型合并要求所有任务都从同一个基座微调. 如果第二个任务必须建立在第一个任务的结果上 (例如先做领域继续预训练, 再在该领域上做指令微调), 合并就无从谈起. 它适合的是「同一个基座, 若干互相独立的下游能力」这类场景.

### 4.5 合并干扰的向量视角

任务向量相加不保证功能相加. 在局部线性近似下, 向量 $\tau_j$ 对任务 $i$ 损失的影响主要取决于 $g_i^\top\tau_j$; 更远处还受 Hessian 曲率和网络非线性影响. 两个向量余弦接近零, 只能说明参数空间里一阶方向近似正交, 不能证明输出互不干扰. 同一坐标符号相反会直接抵消, 这正是 TIES 要处理的情形.

例如 $\tau_1=(1,0)$, $\tau_2=(-1,1)$, 直接相加得到 $(0,1)$: 第二维能力被保留, 第一维更新完全抵消. 这只是二维示意, 不能据此预测真实任务准确率, 但说明合并前必须逐任务回测, 不能只看合并向量的范数.

LoRA 合并还要区分「合并增量」与「平均因子」. 两组增量是 $B_1A_1$、$B_2A_2$, 正确的线性合并为 $\alpha_1B_1A_1+\alpha_2B_2A_2$. 直接平均因子会得到 $\tfrac14(B_1+B_2)(A_1+A_2)$, 额外产生 $B_1A_2$ 和 $B_2A_1$ 两个交叉项, 一般不等价. 拼接因子可以精确保留增量和, 但秩随任务数增长; 再用截断 SVD 压回固定秩会引入近似误差. 所以「每个 adapter 单独有效」不能推出合并后仍有效, 「压缩误差小」也不能推出每个任务的功能误差都小.

### 4.6 评测应增加什么

无论用顺序训练还是合并, 大模型的持续学习评测在第 3.1 篇的准确率矩阵指标之外, 还要覆盖三类能力. 第一类是通用能力, 即序列之外的通用基准, 例如 TRACE 的 General Ability Delta; GSM8K 从 28.8% 掉到 2% 这种退化只有在这里才看得到. 第二类是指令遵循与安全, 每次更新后都要评测, 良性数据微调之后也不例外. 第三类是上游 loss: 继续预训练时报告旧语料上的验证 loss. 它与下游能力不完全一致, 两者都要看.

另外三项属于实验记录. 资源方面, 报告每个阶段的 token 数, 回放比例, 可训练参数, 以及学完全部任务后的总参数 (含全部 LoRA, 提示和路由). 数据污染方面, 检查训练语料与评测集是否重叠. 任务顺序方面, O-LoRA 在标准基准上报告了 3 种顺序, 只跑一种顺序的结果不够.

## 5 可回滚训练与评测协议

汇总值必须与逐任务明细一起保存, 才能复核结论究竟来自哪些能力变化, 也便于下一轮训练定位回归来源.

持续更新必须能够还原. 每一阶段固定基座 checkpoint、tokenizer、数据清单及哈希、混合权重、随机种子、优化器与学习率日程; 保存阶段入口和候选出口 checkpoint. 对 LoRA 或提示方法, 基座保持只读, 适配器使用版本化目录, 上线切换只改变版本指针. 这样退回上一适配器是原子操作; 若已把增量永久写回骨干而没有保留基座, 就失去了低成本回滚的优势.

评测应形成一张「阶段 × 能力」矩阵. 每完成一个数据段, 同时测新域 loss/任务指标、旧域 loss/旧任务、序列外通用能力、指令遵循和安全集, 并记录每域有效 token 与训练成本. 继续预训练至少保留「不回放」与若干回放比例作为算力等价对照, 总 token 预算必须相同; 参数高效方法要同时报告当前阶段可训练参数和累计保存参数. 有多种任务顺序时应重复实验, 随机性显著时报告多次运行而不是挑最好一次.

矩阵还应保存逐项结果, 不只保存宏平均. 宏平均把每个任务等权, token 加权平均则让大语料主导, 两者回答的问题不同. 若一个候选在九个常见任务上各提高一点、却让一个关键安全任务大幅下降, 单个平均数可能仍然好看. 因此发布门槛应包含不能被平均抵消的硬约束, 同时保留基线与候选的原始生成供人工抽查. 对生成任务要固定解码参数和提示模板; 温度、采样种子或聊天模板变化都可能制造看似由训练带来的差异. 对路由型方法还要单列「已知任务标识」和「自动路由」两种结果, 前者衡量适配器本身, 后者才衡量完整系统.

上线门槛在训练前确定, 不能看到结果后移动. 一个实用流程是: 先在固定旧能力集上保存基线; 再用小规模训练验证 loss 曲线、数据管线和回放计数; 随后训练候选 checkpoint; 候选只有在新域收益达标且旧能力、安全退化没有越过预设阈值时才进入影子或小流量验证; 任一硬门槛失败便回到上一 checkpoint, 调整数据配比后重新训练. 回滚后仍要保存失败版本的配置与评测, 否则下一轮会重复同一实验.

比例消融还要避免预算偷换. 假设每个候选都训练 10 亿有效 token, 0%、5%、25% 回放分别意味着新域 token 为 10 亿、9.5 亿、7.5 亿, 旧域 token 为 0、0.5 亿、2.5 亿. 这样比较回答的是「固定总算力下如何分配」; 若在 10 亿新域 token 之外再追加回放, 回放越多总算力越高, 得到的是另一问题. 两种实验都可以做, 但必须分开命名和报告. 评测集本身也要版本化: 新旧语料若泄漏进测试集, loss 改善可能只是记忆; 时间型知识则要把已变化事实与未变化事实分开, 否则平均分会掩盖更新成功但旧知识受损的情况.

还要区分可观察结论的边界. 旧域困惑度恶化提示分布遗忘, 不能精确说明哪个事实错了; 问答准确率保持不能证明生成分布未漂移; 冻结骨干只能说明骨干参数没变, 若路由选错提示或多个 adapter 同时干扰, 旧任务仍会失败; 合并前各模型单独通过也不能替代合并后的全套回归. 可回滚协议无法保证更新永不失败, 但能让失败被发现、定位并安全撤销.
