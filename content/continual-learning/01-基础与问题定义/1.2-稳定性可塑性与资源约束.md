# 1.2 稳定性—可塑性与资源约束

持续学习同时要求模型对新数据足够可塑，又对旧知识足够稳定。二者不是单个超参数能永久解决的对立面：数据相似度、任务顺序、模型容量和可用记忆都会改变最优权衡。

## 灾难性遗忘不是唯一问题

若只抑制参数变化，模型可能保住旧任务却学不动新任务；若只追求当前经验损失，又可能覆盖旧表示。完整评测至少区分：

- **最终性能**：学完整个流后，各已见任务表现如何。
- **遗忘**：某任务历史最佳表现与最终表现的差距。
- **前向迁移**：旧知识是否帮助尚未训练的新任务。
- **后向迁移**：学习新任务是否改善或损害旧任务。
- **适应效率**：达到目标性能需要多少样本、步数与时间。

具体定义见 [3.1 评测协议、指标与任务顺序](../03-评测与实践/3.1-评测协议指标与任务顺序.md)。

## 资源账本

任何“无需旧数据”或“内存高效”的结论，都应把以下成本一起计算：

| 资源 | 需要报告的内容 |
| --- | --- |
| 原始样本 | 样本数、字节数、采样策略、隐私限制 |
| 中间表示 | 特征维度、精度、是否可逆或泄漏原数据 |
| 参数与掩码 | 随任务增长量、任务专属模块数量 |
| 统计量 | Fisher、梯度、原型、BN 统计等的尺寸 |
| 计算 | 每个经验训练步数、反向传播次数、峰值显存 |
| 时间 | 训练吞吐、适应延迟、恢复或重置成本 |

例如，参数隔离方法可能不保存样本，却让参数量随任务增长；回放方法的参数固定，却需要数据内存。二者不能只按“是否存样本”判断优劣。

## 方法如何处理权衡

- [正则化方法](../02-方法体系/2.1-正则化方法/2.1-正则化方法.md)：限制关键参数或输出变化。
- [回放与外部记忆](../02-方法体系/2.2-回放与外部记忆/2.2-回放与外部记忆.md)：让旧分布持续进入优化过程。
- [参数隔离与动态架构](../02-方法体系/2.3-参数隔离与动态架构.md)：给不同任务分配不同容量或掩码。
- [基础模型持续适配](../02-方法体系/2.4-大模型持续预训练与参数高效适配.md)：结合预训练表征、提示、适配器、回放和模型编辑等手段。

## 决策顺序

1. 写明最终部署场景与允许状态。
2. 固定内存、参数和计算预算。
3. 选择与场景匹配的基线。
4. 在多个任务顺序或数据流上报告均值与方差。
5. 对最佳方法做资源—性能联合比较，而不是只比一个平均准确率。
