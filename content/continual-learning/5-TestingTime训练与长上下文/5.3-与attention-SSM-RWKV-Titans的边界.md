# 5.3 · 与 attention, SSM, RWKV, Titans 的边界

## 1. 问题与统一记号

**问题: 名字太多, 边界不清**

长上下文方法的命名来自不同的社区. 状态空间模型 (SSM) 来自控制和信号处理, 线性注意力来自 Transformer 的近似, fast weights 和 delta rule 来自 1990 年代的神经网络研究, TTT 来自视觉里的分布偏移, RWKV 来自开源社区对 RNN 的重新设计. 同一个数学对象常被不同论文叫成不同名字, 不同的对象又常被放在同一个名字下.

例如「线性注意力」既可以指 [Katharopoulos 等 (2020)](https://arxiv.org/abs/2006.16236) 带特征映射和归一化的版本, 也可以指去掉这两项的最简版本, 还常被用来泛指所有矩阵状态的线性 RNN. 「TTT」在第 4 章指在测试样本上做自监督更新, 在本章指一种序列层或一种长上下文方法. 「Titans」有时被说成 Transformer 的替代, 它的主架构 MAC 里其实有注意力.

这些方法可以沿四个问题比较: 状态是什么, 写入时擦掉什么、写入什么, 读出时如何查询, 以及状态的生命周期有多长.

**统一记号**

设第 $t$ 个 token 投影出 query $q_t$, key $k_t$, value $v_t$, 维度都取 $d$. 状态记 $S_t$, 输出记 $o_t$. 矩阵状态的方法用列向量约定, $S_t \in \mathbb{R}^{d \times d}$, 读出 $o_t = S_t q_t$.

一个方法由三件事确定: $S_t$ 的形状 (随长度增长还是固定), 写入 $S_t = \text{write}(S_{t-1}, k_t, v_t)$, 读出 $o_t = \text{read}(S_t, q_t)$. [TTT layer](https://arxiv.org/abs/2407.04620) 的论文把所有序列层拆成初始状态, 更新规则, 输出规则三部分, 这里沿用的就是这个拆法.

**从不压缩到先擦后写**

**全注意力: 不压缩的状态**

全注意力的状态是到目前为止所有的 $(k_s, v_s)$, 即 KV cache. 写入是追加, 读出是

$$
o_t = \sum_{s=1}^{t} \frac{\exp(k_s^\top q_t / \sqrt{d})}{\sum_{s'=1}^{t} \exp(k_{s'}^\top q_t / \sqrt{d})}\, v_s
\tag{1}
$$

每个历史 token 都原样保留, 读出时用 softmax 权重从中检索. 它什么都不丢, 所以精确检索强. 代价是状态大小和每个 token 的读出开销都随 $t$ 线性增长, prefill 总计算 $O(T^2)$.

手算 KV cache 的大小. 设一个 32 层, 隐维 4096, 不用 GQA 的模型, FP16 存储. 每个 token 每层存 $k$ 和 $v$ 两个 4096 维向量:

$$
2 \times 32 \times 4096 \times 2\ \text{字节} = 524{,}288\ \text{字节} = 0.5\ \text{MB}
$$

128K token 的上下文就是 $0.5\ \text{MB} \times 131{,}072 = 64\ \text{GB}$, 而且这只是一条序列. GQA, MLA 一类方法压缩的是这个数, 不改变它随长度线性增长的性质.

FlashAttention 经常被误归到「高效注意力」里和线性方法并列. 它是精确注意力的一种实现: 通过分块和重计算, 避免把 $T \times T$ 的注意力矩阵写到显存, 额外显存从 $O(T^2)$ 降到 $O(T)$, 显存读写次数也大幅减少, 计算量仍是 $O(T^2)$, 输出与式 (1) 完全一致. 它不压缩状态, 不改变模型.

**滑动窗口: 截断的状态**

[Longformer](https://arxiv.org/abs/2004.05150) 等使用的滑动窗口注意力只保留最近 $k$ 个 token 的 KV. 状态大小固定为 $k$ 个 token, 每个 token 的开销 $O(k)$, prefill 总计算 $O(Tk)$, 对 $T$ 是线性的. 写入是追加加淘汰最旧的一个, 丢掉的是窗口外的全部信息, 一点不剩. 多层堆叠时感受野可以超过 $k$, 但信息要逐层传递.

滑动窗口在本章出现了很多次: LaCT 和 TTT-E2E 都用它处理块内依赖, Gated DeltaNet 和 Mamba-2 的混合版本也用它. 原因是它在局部精确, 在远程完全缺失, 正好和压缩类状态的特性互补.

**线性注意力: 只写不擦**

去掉 softmax, 式 (1) 变成 $o_t = \sum_s v_s (k_s^\top q_t)$. 交换求和与乘法的顺序:

$$
o_t = \Big(\sum_{s=1}^{t} v_s k_s^\top\Big) q_t = S_t q_t, \qquad S_t = S_{t-1} + v_t k_t^\top
\tag{2}
$$

历史被压成一个 $d \times d$ 的矩阵, 写入是加一个外积, 读出是一次矩阵乘. 每个 token 的开销 $O(d^2)$, 与长度无关. 5.1 的定理 1 证明了 TTT-Linear 用 batch GD 时就是式 (2).

式 (2) 是最简版本. Katharopoulos 等的原始写法保留了核函数和归一化: 把 $\exp(k^\top q)$ 换成特征映射的内积 $\phi(k)^\top \phi(q)$, 取 $\phi(x) = \text{elu}(x) + 1$ 保证非负, 输出是

$$
o_t = \frac{\Big(\sum_{s=1}^{t} v_s \phi(k_s)^\top\Big) \phi(q_t)}{\Big(\sum_{s=1}^{t} \phi(k_s)\Big)^\top \phi(q_t)}
\tag{2'}
$$

分子是式 (2) 的矩阵状态, 分母多维护一个 $d$ 维向量 $z_t = z_{t-1} + \phi(k_t)$, 作用是 softmax 分母的替代, 让各个 value 的权重之和为 1. 状态从一个矩阵变成一个矩阵加一个向量, 写入和读出仍是 $O(d^2)$. 论文报告在很长序列的自回归预测上比 softmax 注意力快到 4000 倍. 后来的 GLA, DeltaNet 等工作大多去掉了 $\phi$ 和分母, 改用对 $q, k$ 做归一化来控制数值范围, 所以下文都从式 (2) 出发.

[Schlag, Irie & Schmidhuber (2021)](https://arxiv.org/abs/2102.11174) 指出式 (2) 就是 fast weight programmer: $S_t$ 是 fast weights, 外积是写入. 他们同时分析了容量. 若所有 key 两两正交且单位长度, $S_t q$ 在 $q = k_s$ 时恰好返回 $v_s$, 但 $d$ 维空间里最多只有 $d$ 个两两正交的向量. 写入超过 $d$ 对关联后, key 之间必然有非零内积, 读出就会混入其他 value. 5.1 的手算里同一个 key 写两次, 读出 $(1, 1)^\top$, 就是这种干扰的最极端情况.

### 1.1. 固定状态有多大

和前面 KV cache 的手算对照. 仍取 32 层, 隐维 4096 的模型, 实际实现里矩阵状态按 head 分开: 设 32 个 head, 每个 head 维度 $d_h = 128$, 每个 head 的状态是 $128 \times 128 = 16{,}384$ 个数. 每层 32 个 head 共 $524{,}288$ 个数, FP16 下 1 MB; 32 层合计 32 MB. 这个数与上下文长度无关.

KV cache 每个 token 0.5 MB, 所以长度到 $32\ \text{MB} / 0.5\ \text{MB} = 64$ 个 token 时两者一样大; 到 128K 时, KV cache 是矩阵状态的 2048 倍. 反过来看, 128K 个 token 的全部信息要挤进 32 MB, 平均每个 token 只分到 256 字节, 约 128 个 FP16 数, 远小于一个 4096 维的隐向量. 有损是必然的, 问题只在丢什么.

按 head 切分还有一个容量上的后果: 每个 head 的 key 只有 $d_h = 128$ 维, 上一段说的「最多 $d$ 对无干扰关联」在这里是每个 head 128 对. 这也是 5.2 里 LaCT 强调状态大小 (每块最大 $12d^2$, 占参数 40%), TTT-E2E 选择更新完整 MLP 而不是多头小 MLP 的原因之一.

再算 decode 时每个 token 在这一层上的计算. 全注意力: 算 $t$ 个分数 $k_s^\top q_t$ 要 $t \cdot d$ 次乘加, 加权求和 $\sum_s \alpha_s v_s$ 又是 $t \cdot d$ 次, 合计约 $2td$ 次乘加. 按 head 切分的线性注意力: 每个 head 写入一个外积 $v k^\top$ 是 $d_h^2$ 次乘加, 读出 $S q$ 又是 $d_h^2$ 次, $H$ 个 head 合计 $2 H d_h^2 = 2 d\, d_h$ 次. 两者相等时 $t = d_h = 128$. 也就是说, 只看这一层, 上下文超过 128 个 token 后线性注意力每个 token 就更省, 到 128K 时省 1000 倍. 投影矩阵和 MLP 的计算两者相同, 不随 $t$ 变, 所以整个网络的差距比这一层小. TTT-MLP 和 TTT-E2E 的写入是一次反向传播, 常数比 $2 d\, d_h$ 大得多, 交叉点相应后移.

**门控: 先衰减再写**

给旧状态乘一个衰减, 让早期信息逐渐淡出, 为新信息腾出容量. [Gated DeltaNet](https://arxiv.org/abs/2412.06464) 论文 Table 1 把几种方法的写入规则列在一起 (这里统一成列向量约定):

| 方法 | 写入规则 |
| --- | --- |
| 线性注意力 | $S_t = S_{t-1} + v_t k_t^\top$ |
| Mamba-2 | $S_t = \alpha_t S_{t-1} + v_t k_t^\top$ |
| DeltaNet | $S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$ |
| Gated DeltaNet | $S_t = S_{t-1}\big(\alpha_t (I - \beta_t k_t k_t^\top)\big) + \beta_t v_t k_t^\top$ |

$\alpha_t \in (0, 1)$ 是由输入决定的衰减 (门), $\beta_t$ 是由输入决定的写入强度.

[Mamba-2](https://arxiv.org/abs/2405.21060) 的 $\alpha_t$ 是每个 head 一个标量; [GLA](https://arxiv.org/abs/2312.06635) 的衰减是对角矩阵 $\text{Diag}(\alpha_t)$, 每个维度一个衰减率 (5.2 的 LaCT 对照表里列了它的写入规则). [RetNet](https://arxiv.org/abs/2307.08621) 用的是与输入无关的固定衰减: 每个 head 一个常数 $\gamma$, 按 $\gamma = 1 - 2^{-5-i}$ ($i$ 是 head 编号) 取值, 编号小的 head 衰减快, 只看近处, 编号大的 head 衰减慢, 能看得更远. 因为 $\gamma$ 不依赖输入, 一个 token 进来时状态被衰减多少是预先定好的, 与它的内容无关. 门控解决了「状态被写满」的问题, 代价是衰减对所有旧信息一视同仁: 一个重要的早期关联和一个无关的早期关联以同样速率淡出.

**Mamba: 从 SSM 出发**

[Mamba (Gu & Dao, 2023)](https://arxiv.org/abs/2312.00752) 的出发点是状态空间模型. 它对每个输入通道维护一个 $N$ 维状态 (默认 $N = 16$), 离散化后的递推是 $h_t = \bar{A}_t h_{t-1} + \bar{B}_t x_t$, 输出 $y_t = C_t h_t$, 其中 $\bar{A}_t = \exp(\Delta_t A)$, 步长 $\Delta_t$ 和 $B_t, C_t$ 都由当前输入决定, 这就是「选择性」. $A$ 是对角的, 所以 $\bar{A}_t$ 是逐元素的衰减. 把所有通道的状态并起来, 它也是一个矩阵状态, 写入是「衰减加外积」的形式, 只是 key 和 query 的角色由 $B_t$ 和 $C_t$ 扮演. Mamba-2 把 $A$ 限制成标量乘单位阵, 证明了这种 SSM 与一类带掩码的线性注意力等价 (structured state space duality), 于是得到上表里的形式.

选择性有一个工程代价. $\bar{A}_t, \bar{B}_t$ 随输入变化后, 原先 S4 一类 SSM 可以把递推展开成一个固定卷积核做 FFT 的办法用不了, 只能按时间递推. Mamba 的做法是写一个硬件感知的并行扫描: 把 $\Delta, A, B, C$ 读进 GPU 的片上 SRAM, 在 SRAM 里完成离散化和扫描, 只把输出 $y$ 写回显存, 中间状态 $h_t$ 不落显存, 反向时重算. 论文报告推理吞吐是同规模 Transformer 的 5 倍, Mamba-3B 在语言建模上好于同规模 Transformer, 与两倍规模的 Transformer 相当. 这些数字的口径是论文里的预训练困惑度和零样本常识类下游任务, 长文检索类任务不在其中.

5.1 里 TTT layer 论文对照的就是 Mamba: 在 Books 上 16k 之后 Mamba 的逐位置困惑度变平. 门控衰减让早期信息淡出是一个可能的原因, 下一节 Gated DeltaNet 论文对 Mamba-2 检索结果的解释也是「衰减历史太快」.

**delta rule: 先擦后写**

DeltaNet 的写入规则可以展开成

$$
S_t = S_{t-1} - \beta_t (S_{t-1} k_t - v_t) k_t^\top
\tag{3}
$$

$S_{t-1} k_t$ 是当前状态对 $k_t$ 的预测, $S_{t-1} k_t - v_t$ 是预测误差. 写入量与误差成正比: 状态已经存了正确的 $v_t$, 就不写; 存了错的, 就按误差修正. 5.1 的式 (5) 已经说明, 式 (3) 就是 TTT-Linear 在 $\ell = \lVert S k - v \rVert^2$ 上走一步梯度, $\beta_t = 2\eta$. DeltaNet 的并行训练算法见 [Yang 等 (2024)](https://arxiv.org/abs/2406.06484).

Gated DeltaNet 把衰减和 delta rule 合在一起. 论文给出的理由是两者互补: 门控能快速整体清空记忆, delta rule 能针对单个关联精确修改. 论文用 RULER 的 S-NIAH 做了一个 1.3B 的案例分析 (Table 2), 三个观察:

- S-NIAH-1 (重复的合成上下文, 考长期保持): DeltaNet 在所有长度上接近满分; Mamba-2 在 2K 之后明显下降, 因为它衰减历史太快; Gated DeltaNet 下降较少.
- S-NIAH-2/3 (真实文章做上下文, 要存很多可能有用的信息): DeltaNet 在长序列上大幅下降, 原因是不会清空, 固定状态里的信息互相叠加, 难以区分; Mamba-2 和 Gated DeltaNet 好得多.
- S-NIAH-3 (value 从数字换成 UUID, 考复杂模式的记忆): Mamba-2 下降快, Gated DeltaNet 更好, 说明 delta rule 记忆能力更强.

这三条把写入规则的差别落到了可测的现象上: 只衰减, 记不久; 只擦写不衰减, 装满后互相干扰; 两者都有, 在两类任务上都不差.

**在线学习的视角**

Gated DeltaNet 论文还按 Liu 等 (2024, Longhorn) 的框架, 把每条写入规则写成对某个在线学习目标的一步最优化. 例如 DeltaNet 的目标是 $\lVert S_t - S_{t-1} \rVert_F^2 - 2\langle S_t k_t, \beta_t (v_t - S_{t-1} k_t) \rangle$, 前一项要求新状态别离旧状态太远, 后一项要求新状态对 $k_t$ 的输出往误差方向移动. 线性注意力的目标里第二项是 $-2\langle S_t k_t, v_t \rangle$, 不含误差, 所以只写不擦. 论文还指出, Gated DeltaNet 的 $\alpha_t$ 相当于在 SGD 更新里加了一个自适应的权重衰减, 并提到同期的 Titans 在 RNN 的推理阶段 SGD 更新里加了权重衰减.

这个视角把「门控 RNN」和「推理阶段做梯度下降」放进了同一个框架. 下一节的 TTT 和 Titans 就是把这里的 $S$ 换成非线性模型.

**RWKV: 从按通道衰减到广义 delta rule**

RWKV 的几个版本跨越了上面好几类. [RWKV-4 (Peng 等, 2023)](https://arxiv.org/abs/2305.13048) 的时间混合是按通道指数衰减的加权平均, 状态是每个通道上的累积量, 属于向量状态加固定衰减. [RWKV-5/6 (Eagle 和 Finch)](https://arxiv.org/abs/2404.05892) 改成矩阵状态, RWKV-6 的衰减由输入决定, 与 GLA 同属门控一类.

[RWKV-7 (Peng 等, 2025)](https://arxiv.org/abs/2503.14456) 的写入规则是 (论文的行向量约定)

$$
S_t = S_{t-1}\big(\text{diag}(w_t) + z_t^\top b_t\big) + v_t^\top k_t
\tag{4}
$$

$w_t$ 是由输入决定的向量衰减 (比 Gated DeltaNet 的标量更细), $z_t^\top b_t$ 是一个秩一的修正项, 承担 delta rule 里擦除旧值的作用. 论文把它称为广义 delta rule: 衰减按通道, 学习率按通道 (向量值的 in-context learning rate), 擦除用的 key 与写入用的 key 可以不同. 转移矩阵仍是「对角加秩一」, 所以可以沿用 DeltaNet 的并行算法. 论文证明 RWKV-7 能做状态追踪, 能识别所有正则语言, 在标准复杂度猜想下超过了 Transformer 所属的 $\mathsf{TC}^0$ 类. 模型规模 0.19B 到 2.9B, 训练语料 3.1T token. 论文报告 2.9B 模型在多语言任务上取得 3B 规模的新最好成绩, 英文下游任务与当时 3B 最好水平持平, 而训练用的 token 明显少于对照模型.

所以「RWKV」指的机制随版本变化, 讨论时要说是哪一版.

**梯度下降写入: TTT, Titans, LaCT, TTT-E2E**

### 1.2. TTT-Linear 与 TTT-MLP

5.1 已经说明: $f$ 是线性的, 不加 LN 和残差, 块大小 1, 就是 DeltaNet. TTT-Linear 在此基础上加了 LN 和残差 (让 $f$ 变成非线性), 块大小 16, 可学习的初始化和学习率. TTT-MLP 把 $f$ 换成两层 MLP, 状态不再是一个矩阵, 而是一个小网络的全部权重. 到这里, 写入规则不再能写成「对角加低秩」的矩阵递推, 上面那些线性 RNN 的并行算法不再适用, 只能靠 mini-batch 和 dual form.

两个变体的状态大小可以直接算. TTT-MLP 的隐层是输入的 4 倍, 每个头的状态是 $d\times4d$ 和 $4d\times d$ 两个矩阵, 共 $8d^2$ 个元素 (不计偏置), 是 TTT-Linear 的 $d\times d$ 的 8 倍. 5.1 的实验里, 在匹配训练 FLOPs 的条件下, TTT-MLP 在短上下文比 TTT-Linear 差, 在长上下文更好; 但 MLP 结构让墙钟时间比 FLOPs 涨得快, Sun 等把内存 I/O 列为 TTT-MLP 的主要问题. 状态变大换来的容量, 只有在上下文足够长时才用得上.

**Titans**

[Titans (Behrouz, Zhong & Mirrokni, 2024)](https://arxiv.org/abs/2501.00663) 来自 Google Research. 它的长期记忆模块 $\mathcal{M}$ 是一个 $L_\mathcal{M} \ge 1$ 层的 MLP, 在推理阶段学习 key-value 关联, 损失是

$$
\ell(\mathcal{M}_{t-1}; x_t) = \big\lVert \mathcal{M}_{t-1}(k_t) - v_t \big\rVert_2^2, \qquad k_t = x_t W_K,\ v_t = x_t W_V
\tag{5}
$$

最朴素的写入是 $\mathcal{M}_t = \mathcal{M}_{t-1} - \theta_t \nabla \ell$, 论文把梯度叫做「惊讶度」: 输入与过去越不同, 梯度越大, 越值得记. 只用当前梯度有一个问题: 连续几个惊讶的 token 之后梯度可能变得很小, 紧随其后的重要信息会被错过. Titans 把惊讶度拆成「过去的惊讶」和「此刻的惊讶」, 再加遗忘:

$$
\mathcal{M}_t = (1 - \alpha_t)\, \mathcal{M}_{t-1} + S_t, \qquad S_t = \eta_t S_{t-1} - \theta_t \nabla \ell(\mathcal{M}_{t-1}; x_t)
\tag{6}
$$

$S_t$ 就是带动量的梯度下降里的动量项, $\eta_t$ 控制过去惊讶的衰减, $\theta_t$ 控制此刻惊讶的比重, $\alpha_t \in [0, 1]$ 是遗忘门 ($\alpha_t \to 0$ 不遗忘, $\alpha_t \to 1$ 清空), 三者都由输入决定. 读出不更新权重, 只做前向: $y_t = \mathcal{M}^*(q_t)$, $q_t = x_t W_Q$. 并行训练的做法与 TTT 的 mini-batch 相同: 块内梯度都相对块开始时的权重求, 动量项是以块内梯度为输入的线性递推, 可以用并行扫描算.

把式 (6) 退化到矩阵记忆 $\mathcal{M} = W$, 不用动量 ($\eta_t = 0$), 对照 Gated DeltaNet. 代入式 (5) 的梯度 $2(W k_t - v_t) k_t^\top$:

$$
W_t = (1 - \alpha_t) W_{t-1} - 2\theta_t (W_{t-1} k_t - v_t) k_t^\top = W_{t-1}\big((1 - \alpha_t) I - 2\theta_t k_t k_t^\top\big) + 2\theta_t v_t k_t^\top
\tag{7}
$$

Gated DeltaNet 是 $S_{t-1}(\alpha I - \alpha\beta\, k k^\top) + \beta v k^\top$ (这里 $\alpha$ 是保留率). 令 $1 - \alpha_t^{\text{Titans}} = \alpha^{\text{GDN}}$, $2\theta_t = \alpha^{\text{GDN}} \beta$, 两者的擦除项对上了, 写入项差一个系数 $\alpha^{\text{GDN}}$: Gated DeltaNet 的衰减只作用在旧状态上, 新写入的 $\beta v k^\top$ 不衰减; 式 (7) 的写入强度 $2\theta_t$ 与擦除强度绑在一起. 所以矩阵版, 无动量的 Titans 与 Gated DeltaNet 是同一族写入规则, 参数化略有不同. Titans 多出来的是动量和深层 MLP 记忆, 论文认为矩阵记忆等价于在线线性回归, 只能拟合线性依赖, 深层记忆 ($L_\mathcal{M} \ge 2$) 表达力更强.

Titans 在长期记忆之外还有 persistent memory: 一组与输入无关的可学习向量, 拼在序列开头, 推理阶段固定, 存的是任务相关的知识. 长期记忆怎么接进架构, 论文给了三种:

- MAC (memory as context): 序列分段, 每段内用全因果注意力; 用当前段的 query 从长期记忆里读出历史信息, 和 persistent memory 一起拼在段前作为注意力的上下文. 注意力再决定哪些信息写进长期记忆.
- MAG (memory as gate): 滑动窗口注意力当短期记忆, 神经记忆当长期记忆, 两路用门控合并.
- MAL (memory as layer): 把记忆模块当作一层, 与注意力层串联.

论文报告 Titans 在语言建模, 常识推理, 需要回忆的任务, needle-in-a-haystack, 时间序列和 DNA 建模上好于 Transformer 和现代线性 RNN 及其混合版本, 并能扩展到超过 2M 的上下文. TTT-E2E 论文把 Titans 归入与 TTT-KVB 相同的构造: 每层一个以 KV 重建为损失的可更新模块, 加滑动窗口注意力.

**LaCT 与 TTT-E2E**

LaCT 的写入是在 2K 到 1M 个 token 的大块上对 SwiGLU-MLP 求一次梯度, 再做 Muon 和 L2 归一化 (5.2 式 (2) 到 (6)). 块内的 token 对状态的贡献只取决于它们在块里的总和, 与顺序无关, 块内依赖交给窗口注意力.

TTT-E2E 的状态是网络后 1/4 块的 MLP 权重 (760M 模型 88M 参数, 5.2), 写入是对整个网络末端的下一个 token 预测损失走一步梯度, 读出就是网络本身的前向. 它没有单独的「记忆层」, 也没有 key 和 value 投影. 按三件事的拆法, TTT-E2E 是一个只有一层 RNN 的网络: 整个网络在一次反向里被更新.

**一次 delta 写入到底改了什么**

式 (3) 可以完整手算一次. 设状态, key 和 value 都是二维的, 省略归一化, 门控和多头拆分. 写入前的状态与当前样本为

$$
S_{t-1}=\begin{bmatrix}1&0\\0&1\end{bmatrix},\qquad
k_t=\begin{bmatrix}1\\1\end{bmatrix},\qquad
v_t=\begin{bmatrix}2\\0\end{bmatrix},\qquad
\beta_t=\frac14.
\tag{8}
$$

输入假设很简单: $S_{t-1}$ 已经是单位映射, 当前 key 在两个坐标上都为 $1$, 希望同一个 key 读出 $(2,0)^\top$. 第一步先读旧状态:

$$
\hat v_t=S_{t-1}k_t=
\begin{bmatrix}1&0\\0&1\end{bmatrix}
\begin{bmatrix}1\\1\end{bmatrix}
=\begin{bmatrix}1\\1\end{bmatrix}.
\tag{9}
$$

第二步求预测误差. 式 (3) 使用的是「预测减目标」, 因而

$$
e_t=\hat v_t-v_t=
\begin{bmatrix}1\\1\end{bmatrix}-
\begin{bmatrix}2\\0\end{bmatrix}
=\begin{bmatrix}-1\\1\end{bmatrix}.
\tag{10}
$$

第三步把误差沿 $k_t$ 的方向写回矩阵. 外积与乘上学习率后的修正量分别是

$$
e_tk_t^\top=
\begin{bmatrix}-1\\1\end{bmatrix}
\begin{bmatrix}1&1\end{bmatrix}
=\begin{bmatrix}-1&-1\\1&1\end{bmatrix},\qquad
\beta_t e_tk_t^\top=
\begin{bmatrix}-0.25&-0.25\\0.25&0.25\end{bmatrix}.
\tag{11}
$$

接着从旧状态中减去式 (11):

$$
S_t=S_{t-1}-\beta_t e_tk_t^\top=
\begin{bmatrix}1.25&0.25\\-0.25&0.75\end{bmatrix}.
\tag{12}
$$

用同一个 key 再读一次, 得到 $S_tk_t=(1.5,0.5)^\top$. 它从旧输出 $(1,1)^\top$ 朝目标 $(2,0)^\top$ 各移动了一半. 原因可以直接由式 (3) 推出: 更新后的误差为

$$
S_tk_t-v_t=\big(1-\beta_t\lVert k_t\rVert_2^2\big)(S_{t-1}k_t-v_t).
\tag{13}
$$

这里 $\lVert k_t\rVert_2^2=2$, 所以误差缩成原来的一半. 若 $k_t$ 已归一化到单位长度, $\beta_t=1$ 会让当前 key 的误差一步归零. 若不归一化而仍取 $\beta_t=1$, 式 (13) 的系数变成 $-1$, 误差只会反向, 不会变小. **delta rule 的稳定性取决于学习率与 key 范数的乘积, 「会擦除」不等于「一定稳定」.** 实际模型学习 $\beta_t$, 还会归一化 $k_t$, 正是在控制这个乘积.

这次写入也会影响别的 key. 对任意查询 $q$, 更新前后读出的差为

$$
(S_t-S_{t-1})q=-\beta_t e_t(k_t^\top q).
\tag{14}
$$

当 $q$ 与 $k_t$ 正交时, $k_t^\top q=0$, 读出完全不变; 两者越接近, 改动越大. 式 (14) 给出了「定向擦写」的精确含义, 也给出了容量限制: 很多 key 不可能在低维空间里都近似正交, 修正一个关联时就会碰到其他关联. 这个推导不能证明自然语言 token 的 key 会彼此正交, 也不能证明某个模型能记住多少事实; 容量还取决于训练得到的表示, 门控, head 数和数据分布.

**机制图: 一个 token 在状态层里走过的路径**

```text
x_t
 |-- W_Q --> q_t --------------------------|
 |-- W_K --> k_t --> read old state -------|--> loss / error
 |-- W_V --> v_t --------------------------|        |
                                                    v
S_(t-1) --> decay --> erase along k_t --> write v_t --> S_t
   |                                                     |
   |---------------- read with q_t -----------------------|--> o_t
```

图中的上半段产生当前 token 的读写地址和目标, 下半段改变序列状态. 全注意力把「改变状态」实现成向 KV cache 追加一行; Mamba-2 先整体衰减再加外积; DeltaNet 用误差沿 $k_t$ 擦写; Titans 和 TTT-MLP 则把下半段换成对一个小网络做反向传播. 读出可以发生在写入前或写入后, 这会决定当前 token 能否读到自己. 比较实现时必须固定这一点, 否则看似相同的递推式会产生一位偏移.

图里没有画投影归一化, 卷积, 残差和局部注意力. 这些模块在实际模型中会改变 $q_t,k_t,v_t$ 的统计量, 也会给输出提供绕过压缩状态的路径. 因此, 从一张状态更新图不能推出整个 block 的计算量, 更不能把混合架构的成绩全部归因于某一条写入规则.

**对照: 总表, 压缩与状态的生命周期**

**一张总表**

| 方法 | 状态 | 写入规则 | 读出 | 每 token 开销 | 信息限制 |
| --- | --- | --- | --- | --- | --- |
| 全注意力 | 全部 KV, 随长度增长 | 追加 | softmax 检索 | $O(t)$ | 无 |
| 滑动窗口 | 最近 $k$ 个 KV | 追加, 淘汰最旧 | softmax 检索 | $O(k)$ | 窗口外全部 |
| 线性注意力 | $d \times d$ 矩阵 | 加外积 | 矩阵乘 | $O(d^2)$ | 超过 $d$ 对关联后互相干扰 |
| Mamba-2, GLA, RetNet | 矩阵 | 衰减后加外积 | 矩阵乘 | $O(d^2)$ | 早期信息按衰减率淡出 |
| DeltaNet | 矩阵 | 按误差擦后写 | 矩阵乘 | $O(d^2)$ | 不清空, 装满后叠加 |
| Gated DeltaNet | 矩阵 | 衰减加擦写 | 矩阵乘 | $O(d^2)$ | 有损, 衰减和擦写共同决定 |
| RWKV-7 | 矩阵 | 按通道衰减加广义擦写 | 矩阵乘 | $O(d^2)$ | 有损 |
| TTT-Linear / TTT-MLP | 线性模型或 MLP 的权重 | 每 16 token 一步重建梯度 | 模型前向 | 常数 | 有损 |
| Titans 长期记忆 | MLP 权重 | 梯度加动量加权重衰减 | 模型前向 | 常数 | 有损, 主架构另有注意力 |
| LaCT | SwiGLU 权重, 可达参数 40% | 大块梯度, Muon, L2 归一化 | 模型前向 | 常数 (摊到块) | 块内顺序, 交给窗口注意力 |
| TTT-E2E | 后 1/4 块 MLP 权重 | 每 1K token 一步 NTP 梯度 | 网络前向 | 常数 (摊到块) | 有损, S-NIAH 弱于全注意力 |

「常数」一栏指不随上下文长度增长, 绝对值差别很大: TTT-MLP 和 TTT-E2E 每个 token 的常数远大于 DeltaNet.

表中从上到下, 写入规则越来越强: 能不能擦, 擦得准不准, 状态是线性的还是非线性的, 更新是一步闭式还是一步梯度. 写入规则越强, 状态在固定大小下能区分的关联越多; 但从第三行起, 所有方法都是有损压缩, 能存多少取决于状态大小和写入规则, 不取决于名字.

## 2. 压缩与检索

把上下文压进固定状态, 和保留全部上下文, 在任务上各有输赢. 本章引用的实验里有三组直接证据:

- TTT-E2E 的语言建模损失随长度与全注意力保持相同的差距 (5.2), 但 S-NIAH 上全注意力大幅领先.
- Gated DeltaNet 的 S-NIAH 案例: 不同写入规则在「长期保持」和「装满后的区分」上表现不同, 但都是固定状态内部的比较.
- 5.1 的 TTT layer 实验只测困惑度, Mamba 在 16k 后困惑度变平.

结论是: 平均预测质量 (困惑度, 损失) 和精确检索是两个能力. 压缩类状态可以在前者上与全注意力相当, 在后者上目前仍明显落后. 需要精确引用前文的任务 (检索, 复制, 长文问答里定位原句), 还是要有能精确回看的机制.

这也是混合架构普遍的原因. TTT-E2E 论文列出的基线里, Mamba-2 和 Gated DeltaNet 都以「与滑动窗口注意力混合」的形式出现, 并分别在 Nemotron-H 和 Kimi Linear 中做了大规模验证; 另一个基线是 Gemma 风格的「5 层滑动窗口加 1 层全注意力」. LaCT 自己就是窗口注意力加 TTT 的混合. Gated DeltaNet 论文也给出了与滑动窗口注意力或 Mamba-2 层交替堆叠的混合版本, 报告训练效率和任务表现都比纯 Gated DeltaNet 更好. 这些设计都把精确回看留给注意力 (窗口内或少量全局层), 把远程压缩交给固定状态.

**状态的生命周期**

状态能保留多久, 决定了它和持续学习的关系.

| 层级 | 生命周期 | 例子 |
| --- | --- | --- |
| 网络权重 | 训练结束后固定 | 所有方法的 slow weights, Titans 的 persistent memory, TTT-E2E 的元学习初始化 |
| 序列内状态 | 一条序列内, 结束丢弃 | KV cache, 线性 RNN 的矩阵, TTT 的 $W$, Titans 的长期记忆, TTT-E2E 被更新的 MLP |
| 跨样本适应状态 | 跨样本延续 | 第 4 章的 TENT online, CoTTA, EATA 的 BN 参数 |

本章所有方法的「推理阶段学习」都在第二层. Titans 叫它「长期记忆」, 长期是相对注意力窗口而言, 不是跨请求. TTT-E2E 说「持续学习」, 指的也是序列内. 第 4 章的方法在第三层, 跨样本延续, 所以有误差积累, 遗忘和跨用户影响的问题; 本章的方法因为序列结束就复位, 天然没有这些问题, 也天然不会把一次对话里学到的东西带到下一次.

把第二层的状态延长到跨请求, 就会同时得到第三层的收益和第三层的全部风险. 第 4 章讨论过的重置策略, 泄漏和隔离, 届时都要重新处理.

**怎么做一组能区分机制的实验**

只跑长文本困惑度不足以区分上表中的方法. 一组最小实验应同时包含语言建模, 精确检索和状态干扰, 并让所有方法使用相同 tokenizer, 训练 token 数, 参数量区间与数据顺序. 长度至少取 $2\text{K},8\text{K},32\text{K},128\text{K}$ 四档; 对固定状态方法, 还要跨过单头状态维度 $d_h$ 和训练时最大长度两个位置. 每档至少用三个训练种子, 推理基准固定样本和随机种子. 报告平均值与标准差, 不从最好的一次挑数.

语言建模报告逐位置 loss, 而非只报整段平均 loss. 若某方法在 16K 后逐位置 loss 变平, 能看到它停止从更远上下文获益; 整段平均会被前面的短位置冲淡. 精确检索使用 value 长度, 干扰项数量和查询距离分开的合成任务. key-value 对固定时逐步增加无关段落, 可以测「保持」; key 重复而 value 更新, 可以测「擦写」; UUID 比数字更难压缩, 可以测复杂 value. 这三个变量不要一次全变, 否则失败后无法判断是哪一项超过容量.

状态干扰实验直接记录写入前后的读出变化. 对每个时刻保存一组探针 key $q_j$, 计算 $\lVert S_tq_j-v_j\rVert_2$ 与相邻两次写入的差. 同时记录门值 $\alpha_t$, 写入强度 $\beta_t$, key 范数和 key 之间的余弦相似度. 若误差随着 key 相似度上升, 对应式 (14) 的串扰; 若所有旧探针按时间一起恶化, 更像门控衰减; 若训练 loss 正常而状态范数突然增大, 先查 $\beta_t\lVert k_t\rVert^2$ 是否越过稳定区间.

性能口径要把 prefill 与 decode 分开. Prefill 报 token/s, 峰值显存和端到端延迟; decode 报 batch size 为 1 及服务常用 batch 下的 token/s, 每条序列状态字节数和读写带宽. TTT-MLP 的 FLOPs 即使与线性注意力接近, 反向传播产生的中间量和 kernel 启动仍可能让墙钟时间落后. 若只报理论复杂度 $O(T)$, 看不到这层差别. 所有状态都要注明用 FP32, BF16 还是 FP16 保存, 因为递推状态累计数万步后的数值误差与 KV cache 的误差行为不同.

**公平对照的单位应是端到端模型, 同时另做只替换状态层的消融.** 前者回答部署时谁更好, 后者回答写入规则贡献了什么. 混合模型要单列局部注意力窗口, 全注意力层比例与状态大小; 否则「固定状态胜过注意力」可能只是额外局部注意力或更多参数带来的结果.

训练长度外推要再单独做一轮. 假设模型只在 8K 内训练, 评测时扩到 16K, 32K 和 64K. 每个长度既测自然文本, 也测把同一批 key-value 对放到不同绝对位置的控制集. 若自然文本 loss 尚可而远端检索骤降, 说明局部统计外推成功, 状态容量或写入保留没有跟上. 若状态范数随长度单调增大, 再把每步写入强度整体乘 $0.5,1,2$ 做消融; 若缩小写入能延迟崩溃却降低短序列学习速度, 就能看见稳定性与适应速度之间的实际交换.

并行训练与串行推理也要对齐验证. 线性递推常用 chunkwise parallel 算法训练, TTT 和 Titans 用 mini-batch 近似把块内多个梯度并行化. 对随机生成的小维张量, 应同时跑逐 token 参考实现与并行实现, 比较每个边界位置的状态和输出. 误差阈值按 dtype 分开设定, FP32 先验证代数等价, BF16 再测累计误差. 若近似算法本来就改变了块内更新顺序, 不能只做数值相等检查, 而要把块大小作为实验变量, 报告块大小从 1 增到 16, 64, 1024 后质量和吞吐怎样变化.

一份可复跑的记录至少包含模型提交版本, kernel 版本, GPU 型号, dtype, batch size, 序列长度, 状态初始化, 是否跨文档重置, chunk 大小和解码策略. 固定状态模型对「文档边界在哪里」很敏感: 把多个互不相关文档拼成一条流而不重置, 测到的是跨文档污染; 每段都重置, 又测不到长程保持. 两种都应报告, 并把主要口径与目标部署对齐.

**代数等价不能推出任务等价**

Mamba-2 可以写成带结构掩码的线性注意力, DeltaNet 可以写成在线梯度下降, 矩阵版 Titans 又能退化到近似 Gated DeltaNet 的形式. 这些等价关系很有用, 因为它们允许复用并行扫描和稳定性分析. 但等价成立时带着一串条件: 状态维度相同, 激活和归一化相同, 读写时序相同, 参数化能一一对应. 实际模型一旦增加短卷积, 门控投影, LayerNorm, 残差或局部注意力, 端到端函数就不再由那一条递推式决定.

以式 (7) 为例, 它只把 Titans 的记忆限制为单个线性矩阵, 去掉动量, 再比较一次 SGD 更新. 深层 MLP 的梯度包含各层激活的 Jacobian, 同一个 key 对不同输入区域产生不同的局部更新方向; 矩阵状态没有这部分非线性. 反过来, Gated DeltaNet 的专用递推可以用结合律并行扫描, 深层 MLP 更新通常不能获得同样的 kernel. 因而式 (7) 证明的是两条简化写入规则属于同一族, 不能证明 Titans 与 Gated DeltaNet 在容量, 速度或任务成绩上相同.

状态大小相等也不代表信息容量相等. 一个 $d\times d$ 的 FP16 矩阵有固定字节数, 可区分的关联却受 key 几何结构和数值噪声控制. 深层 MLP 参数更多, 但梯度更新只探索初始化附近的一部分函数空间; KV cache 虽然字节数大, 却保存了逐 token 可寻址的记录. 所以容量实验不能只横轴画参数数或状态字节, 还要画随干扰项数量增长的检索曲线, 并分别测试重复 key, 近邻 key 与随机正交 key.

**复杂度相同只描述增长阶, 不描述硬件上的交叉点.** 两个方法都是 $O(T)$, 一个可能由大矩阵乘组成, 另一个可能需要逐步扫描和许多小 kernel. 前者 FLOPs 更多却能把 GPU 吃满, 后者 FLOPs 少但受启动和带宽限制. 论文中的吞吐数字必须连同长度, batch, dtype 和硬件阅读; 换一张 GPU 或把 batch 从 1 提到 32, 排名可能变化.

**失败模式与大模型场景边界**

固定状态最常见的失败是「平均 loss 还好, 必须逐字取回的信息已经丢了」. 摘要, 主题延续和局部语法允许有损压缩, 文件中的精确数字, API 参数, 引文位置和长代码变量名不允许. 对检索增强生成也是如此: 外部检索找到了原文, 但状态层在生成若干段后把证据压混, 最终回答仍会改掉数字. 这类任务需要窗口注意力, 少量全局注意力或再次访问外部原文.

第二类失败来自写入目标与用户目标不一致. TTT layer 的重建损失要求从变换后的 token 预测原 token, TTT-E2E 用 next-token loss, Titans 学 key-value 关联. 这些目标能产生有用状态, 却不保证事实正确, 指令优先级稳定或拒答边界不变. 一段重复很多次的错误陈述可能得到更强写入; 提示注入也可能利用序列内更新改变后续行为. 序列结束时重置可以限制影响范围, 不能保证单次长会话内部安全.

第三类失败是状态污染没有可见的定位点. KV cache 可以按 token 截断, 重算或查看注意力输入; 一个 MLP 状态由上万个 token 的梯度叠加后, 很难指出某个权重变化来自哪一句. 工程上至少要保留分块 checkpoint, 更新范数, 门值分布与异常回滚条件. 回滚单位若是一整个 1K token 块, 块尾那句话触发异常时, 前面 999 个 token 的有效适应也会一起丢失. 更细的 checkpoint 能减少损失, 会增加显存和写带宽.

跨用户或跨请求保留状态会把序列模型变成在线学习系统. 此时必须把租户隔离, 删除请求, 数据授权期限, 更新审计和灾难恢复纳入设计. 用户要求删除一条消息时, 从非线性权重里精确减掉那次梯度通常做不到; 可执行的方案是回到该消息前的 checkpoint 并重放获准保留的数据. 如果系统没有原始数据或合法的重放权限, 就不能承诺精确遗忘.

还有一条容易越界的推论: 语言建模 loss 随上下文继续下降, 只能说明额外 token 帮助了平均预测. 它不能证明模型建立了长期计划, 不能证明状态中保存了可验证事实, 也不能证明超过训练长度后仍可靠. 这些能力要分别用跨段约束执行, 精确引用, 状态恢复和长度外推实验来测. **「能处理 2M token」描述输入可运行, 不自动等于 2M 范围内的信息都能被准确使用.**

**用状态算子统一六条路线**

**四个算子足以描述一次读写**

把任意序列层在时刻 $t$ 的持久状态记为 $S_t$，当前输入为 $x_t$。一次状态计算可以拆成地址、写入、遗忘与读取：

$$
k_t=K(x_t),\quad v_t=V(x_t),\quad
S_t=\mathcal F_t(S_{t-1})+\mathcal W_t(S_{t-1},k_t,v_t),\quad
y_t=\mathcal R(S_t,q_t).
\tag{15}
$$

$K,V,Q$ 决定内容怎样进入地址空间；$\mathcal F_t$ 决定旧状态保留多少；$\mathcal W_t$ 决定新信息以外积、梯度或门控递推的方式进入；$\mathcal R$ 决定查询时还能否重新访问单条历史。六类方法真正的分界大多落在这四个算子上。复杂度、容量和精确检索只是算子选择后的结果。

全 attention 的 $S_t$ 是不断增长的键值列表，$\mathcal F$ 原样保留旧槽位，$\mathcal W$ 追加一条记录，读取时由当前 query 对全部历史重新加权。线性 attention 把列表提前汇总成外积矩阵，读取只剩矩阵乘。SSM 与早期 RWKV 使用向量或按通道状态，由数据依赖衰减控制遗忘。现代矩阵状态路线把 SSM、线性 attention 与 delta rule 拉到接近的代数形式。TTT 和 Titans 进一步让状态本身成为可训练模型参数，写入由某个内损失的梯度产生。

统一式也暴露出一个常被忽略的差别：状态大小固定，不代表状态语义相同。一个 $d\times d$ 外积矩阵、一个 $d$ 维 SSM 向量和一个含 $d^2$ 参数的 MLP 都是「常数状态」，能表达的地址结构、更新成本和可逆性完全不同。比较时要列出状态形状与精度，不能只写 $O(1)$。

### 2.1. 状态增长与信息选择发生在不同时间

显式 KV cache 推迟压缩。写入时几乎不决定哪条历史重要，查询到来后再根据 $q_t$ 选择。固定状态方法在写入时就必须决定怎样合并，后续 query 只能读取已经压缩的结果。这个时间差决定了双方各自擅长的任务：未来查询不可预知、细节彼此独立时，延迟选择更稳；历史高度冗余、查询依赖稳定统计时，提前压缩更省。

线性 attention 的选择依据是当前 key 与固定特征映射，SSM 的选择还包括衰减和输入门，TTT 的选择依据当前预测误差，Titans 再把惊讶度、动量和遗忘放进记忆更新。它们都试图在写入时估计未来价值，只是代理信号不同。某种代理在平均语言建模上有效，并不能保证它在事后指定的随机细节检索上有效。

可以用「查询揭示时间」刻画任务。若 token 出现时已知它会被查询，门控和梯度可强写；若直到数万 token 后的提问才知道哪条细节重要，固定状态必须保存大量候选，容量压力骤增。长上下文 benchmark 若查询模板总能从写入格式被预测，就会高估提前选择方法。

**遗忘有三种来源**

第一种是显式衰减，例如 $S_t=\alpha_tS_{t-1}+\cdots$。早期信息的系数包含 $\prod_{j>s}\alpha_j$，可直接计算半衰期。第二种是干扰覆盖：delta rule 或梯度更新虽无显式衰减，新梯度沿旧地址方向移动状态，旧关联仍会损坏。第三种是读出失配：信息可能还在参数里，后续更新改变了地址表示或查询网络，原 query 已无法找到它。

只测状态范数无法区分三者。显式衰减会让旧贡献幅度下降，覆盖体现为固定探针输出被新关联替换，读出失配则可能在保存旧读出头后恢复。分别冻结写入、冻结地址投影、保存历史 query 读出，可以定位遗忘发生在哪个算子。

**Attention：增长状态换取查询时自由**

**softmax 读取保留了哪些能力**

标准单头因果 attention 在位置 $t$ 的输出为

$$
y_t=\sum_{s\le t}\frac{\exp(q_t^\top k_s/\sqrt d)}
{\sum_{j\le t}\exp(q_t^\top k_j/\sqrt d)}v_s.
\tag{16}
$$

状态是所有 $(k_s,v_s)$。两个键即便很相似，仍占两个槽位；查询可利用极小的 logit 差选择其中一条。softmax 归一化还让输出尺度不随序列长度线性增长。只要键值仍在缓存中，写入后没有状态覆盖；失败更多来自地址不可分、位置外推、有限精度或注意力被大量干扰项稀释。

把正确键 logit 记为 $a$，其余 $n-1$ 个干扰键 logit 上界为 $b$，正确项权重下界为

$$
w_*\ge\frac{1}{1+(n-1)e^{b-a}}.
\tag{17}
$$

序列变长时，即便每个干扰项都略低，大量项的总质量仍会压低正确权重。要保持固定 $w_*$，logit 间隔需随 $\log n$ 增长。全 attention 没有压缩碰撞，却仍有检索拥挤；「缓存中存在」与「能稳定取出」不是同一件事。

多头 attention 提供多套地址子空间，不同头可处理位置、语义、句法或复制。头数增加不改变缓存随长度增长的事实，也不能保证每条信息都有专属头。KV 量化、GQA 和 MQA 共享键值投影会进一步改变可分性与带宽，应与序列状态机制分开讨论。

**窗口与稀疏 attention 改变的是可达图**

局部窗口将状态限制为最近 $w$ 条 KV，超出窗口的信息需要通过层间传播或全局 token 中转。稀疏 attention 保留部分历史槽位，用预设或学习索引决定连边。它们仍在查询时选择显式槽位，只是可见集合缩小。固定状态方法则把许多历史先合成一个槽位集合，两者的误差结构不同。

构造一个跨窗口精确复制任务，局部 attention 在没有中转路径时会骤降；加入全局索引即可恢复。构造大量相似键的随机查询，稀疏索引若漏掉目标会彻底失败，压缩状态则可能输出混合值。错误类型能反推机制：漏检常产生无关答案，碰撞更容易产生相似值或条件均值。

混合架构把窗口 attention 与固定状态并用时，近期信息享受延迟选择，远期信息接受压缩。窗口长度决定何时发生这次转换。把同一 needle 放在窗口内、刚越界与远距离三处，可以看到能力是否在边界处突变。

**KV cache 的容量是显式且可审计的**

每个 token 的 KV 字节近似与层数、KV 头数、头维和精度成正比。它会随长度增长，但单条记录可以按位置删除、截断、量化或重算。状态污染的来源相对清楚：哪个 token 在哪个槽位。固定参数记忆把大量写入叠进权重，定位与删除某条贡献更难。

显式增长也让容量边界直观。只要显存与带宽允许，增加 token 不会迫使旧值在写入时合并。代价转移到读取：每次 query 要处理更多键，训练 attention 矩阵随长度平方增长，自回归 decode 每步读取缓存随长度线性增长。FlashAttention 改善 IO 与中间存储，没有改变精确 attention 的语义或总配对数。

**线性 Attention：外积统计的能力与碰撞**

### 2.2. 从核分解得到固定矩阵状态

若相似度可写为 $\phi(q)^\top\phi(k)$，未归一化状态可以递推为

$$
S_t=S_{t-1}+\phi(k_t)v_t^\top,\qquad
y_t=\phi(q_t)^\top S_t.
\tag{18}
$$

带归一化的版本另存 $z_t=\sum_{s\le t}\phi(k_s)$，输出除以 $\phi(q_t)^\top z_t$。历史长度从状态形状中消失，所有 token 被压成一阶特征和外积和。读取复杂度不再依赖 $t$，不同历史产生同一个 $(S_t,z_t)$ 时，任何未来 query 都无法区分它们。

外积相加没有检查旧状态在当前键上的预测。重复写入同一键同一值会让对应方向持续增长；归一化分母能抵消一部分次数效应，冲突值则被平均。若同一键先关联 A 后关联 B，状态保留的是加权和，无法天然表达「最新值覆盖旧值」。门控衰减与 delta rule 正是针对这个缺口。

**两键碰撞的闭式结果**

取单位键 $k_1,k_2$，内积为 $\rho$，写入标量值 $v_1,v_2$。状态 $S=v_1k_1+v_2k_2$，用 $k_1$ 查询得到

$$
\hat v_1=k_1^\top S=v_1+\rho v_2.
\tag{19}
$$

第二条关联以 $\rho v_2$ 污染第一条。加入更多键后，误差为所有交叉项之和。随机高维键的单个内积虽小，数量增长后总方差仍上升。键维度固定时，不能让无限多关联两两正交。

若使用归一化读取，输出成为相似度加权平均。它适合核回归式平滑：相似键本就应有相似值时，碰撞提供泛化；随机键值绑定要求精确分离时，碰撞就是错误。评价线性 attention 的「容量」必须说明值是否具有共享结构。

**归一化无法恢复已合并的槽位**

分母解决尺度，不增加状态自由度。两个历史只要产生相同的 $S,z$，归一化后仍不可区分。可以构造 $v_1k_1^\top+v_2k_2^\top=v'_1{k'_1}^\top+v'_2{k'_2}^\top$ 的不同序列，它们对所有 query 输出一致。显式 attention 仍保存四个原始向量，可在适当 query 下区分。

核特征维度增大能减少碰撞，状态与计算也随之增大。随机特征近似 softmax 时，误差取决于特征数、键范数和序列长度。所谓线性复杂度来自固定特征预算；若为了更长序列持续增加特征数，状态不再真正与长度无关。

**SSM：状态转移控制时间尺度**

**线性状态空间的卷积与递推两种视角**

离散线性 SSM 写成

$$
h_t=Ah_{t-1}+Bx_t,\qquad y_t=Ch_t+Dx_t.
\tag{20}
$$

展开后 $h_t=\sum_{s\le t}A^{t-s}Bx_s$。同一模型既可看成递推，也可看成卷积核 $CA^kB$。矩阵 $A$ 的谱控制时间尺度：特征值模小于一时旧信息衰减，接近一时记忆更长，超过一则可能不稳定。经典线性 SSM 的转移与输入无关，同一通道对不同内容使用相同时间规律。

选择性 SSM 让离散化步长或 $B_t,C_t$ 依赖输入，状态方程变成 $h_t=A_t h_{t-1}+B_tx_t$。模型能让重要 token 写得更强、保留更久，也能快速跳过无关输入。选择发生在写入和遗忘阶段；一旦信息被 $A_t$ 压掉，未来 query 不能像 attention 那样回到原槽位。

SSM 的容量不应只用状态维度判断。若多个模态对应不同衰减率，它可以高效保存一组指数加权统计；要精确保存任意位置值，则需足够多可分离模态和稳定读出。长时间尺度要求特征值接近单位圆，有限精度下又更容易累积误差或让状态饱和。

**选择门的记忆半衰期**

对标量递推 $h_t=a_t h_{t-1}+b_tx_t$，位置 $s$ 的贡献到 $t$ 时为

$$
b_sx_s\prod_{j=s+1}^{t}a_j.
\tag{21}
$$

若 $a_j=a\in(0,1)$，半衰期为 $\log(1/2)/\log a$。数据依赖门使半衰期沿序列变化，某次很小的 $a_j$ 会同时抹掉此前所有内容。模型获得了快速复位能力，也引入单点遗忘风险。

可以固定写入一个探针，随后控制每个 token 的门值，测其读出随乘积衰减是否一致。若理论贡献仍大而输出消失，问题在读出或非线性混合；若乘积本身骤降，遗忘由状态转移直接造成。对多维状态，可沿特征方向估计传播增益。

**SSM 与 attention 的对偶有条件**

结构化状态空间对偶表明，一类半可分离矩阵可同时用注意力式矩阵乘和递推算法计算。这个结果统一了计算结构，不代表任意 softmax attention 都能压成固定状态，也不代表所有 SSM 都具有显式 KV 的检索能力。对偶成立的矩阵结构、状态维度与参数化决定可表达的交互集合。

训练时使用矩阵形式、推理时使用递推形式，数学等价要求相同精度和边界条件。分块 scan、状态初始化或离散化实现不一致，会在长序列累积误差。小序列逐元素对齐只是起点，还要测长度增长后的误差曲线。

## 3. RWKV：从标量衰减走向矩阵状态

**WKV 聚合的时间偏置**

早期 RWKV 的 time-mix 可理解为带指数时间衰减的键值聚合。每个通道维护分子与分母统计，当前 query 读取经过时间权重的值。它保留线性时间递推和固定状态，用可学习衰减控制不同通道的记忆长度。相比普通线性 attention，时间衰减阻止旧外积无限累积；相比全 attention，历史仍被聚合成通道统计。

按通道衰减意味着每个通道拥有一个主要时间尺度。内容可以通过 receptance 和 key 强度改变当下读写，却难以在同一通道中同时保存许多独立、无衰减的关联。多层与宽度提供更多时间尺度，精确随机访问仍受固定状态约束。

**矩阵状态增加地址表达力**

RWKV-5/6 引入矩阵值状态与更动态的递推，状态从通道标量统计扩成更丰富的键值映射。一般形式可写为

$$
S_t=D_t\odot S_{t-1}+u_t v_t^\top,\qquad
y_t=S_t^	op r_t,
\tag{22}
$$

其中 $D_t$ 控制元素或通道衰减，$r_t$ 是读取向量。矩阵状态能表达更多并行关联，代价是状态字节与矩阵运算增加。若更新仍是无条件外积，重复和冲突问题依旧存在，只是容量上限推迟。

RWKV-7 的状态演化进一步接近广义 delta rule，引入数据依赖擦除方向。写入前根据当前地址削弱旧响应，可以把「累加统计」变成「误差修正」。这使 RWKV、Gated DeltaNet 和 fast-weight 线性模型在方程层面靠近，差别转移到门如何产生、是否由显式内损失训练、状态在哪些层部署。

**名称连续，状态机制已经变化**

把所有 RWKV 版本只写成「带衰减的线性 attention」会丢掉矩阵状态与动态擦除的演进。比较论文结果时要标出具体版本。早期通道状态的容量结论不能直接套到矩阵版本，矩阵版本的结果也不能证明旧状态同样具备 delta 式纠错。

一个版本无关的测试是重复写、冲突写和延迟查询。无条件累加在重复写时响应随次数变化；delta 写入在预测已正确时更新趋小；显式衰减让旧响应按门乘积下降。三条曲线足以从行为上分辨主要状态机制。

**TTT：梯度把内模型变成状态**

**状态方程由损失的几何决定**

TTT 将 $S_t$ 具体化为快速模型参数 $W_t$：

$$
W_t=W_{t-1}-\eta_t\nabla_W\ell(W_{t-1};k_t,v_t),\qquad
y_t=f_{W_t}(q_t).
\tag{23}
$$

选择平方误差与线性 $f$，可得到 delta rule；换成 MLP，写入方向由网络 Jacobian 与残差共同决定；换成交叉熵或对比损失，记忆几何也随之变化。因此 TTT 是一族状态构造原则，具体容量与遗忘不能脱离内模型、损失和优化器讨论。

与 SSM 的前向门控相比，TTT 要先计算预测误差再写入。状态已经能解释当前训练对时，梯度趋近零；出现违背状态的新内容时，更新增强。误差是内容选择信号，也会偏爱底座不熟悉的 token。未来重要但当前容易预测的信息可能写得很弱。

TTT-MLP 的非线性状态能学习更复杂的地址核，读写也更贵。一次更新只沿当前梯度方向移动，参数个数给出潜在容量，实际可达子空间受更新步数与梯度多样性限制。将 MLP 参数总数直接等同于可保存事实数没有依据。

**与 delta 网络的边界在训练语义**

线性 TTT 使用平方误差时，梯度更新可代数化为 delta rule；Gated DeltaNet 直接参数化门控 delta 更新。前向状态方程可能相同，训练解释不同：TTT 从内任务推出更新并让外循环塑造任务，delta 网络将更新作为序列层结构端到端训练。

当最终实现已经融合成同一矩阵递推时，运行时不一定还能区分它源自「优化」还是「架构」。有意义的差异落在可扩展性：TTT 可把内模型换成 MLP、改变 loss 或优化器；直接 delta 结构通常围绕特定矩阵状态获得更高效 scan。前者提供状态设计自由，后者利用代数结构换取并行。

### 3.1. 测试时更新与跨样本适应的边界

TTT layer 的状态通常在序列边界复位，服务当前上下文。若 $W$ 跨请求保留，它便成为持续测试时适应，开始面对数据顺序、用户隔离、错误累积与回滚。相同更新公式在不同生命周期下属于不同系统。

判断方法边界可询问三个量：状态由谁拥有、何时复位、损失标签从哪里来。序列私有且结束复位属于情节式上下文状态；全局共享且长期保留属于在线学习；周期性离线汇总又接近普通训练。名称中的 test-time 无法替代这三个定义。

**Titans：惊讶度、动量与参数记忆**

**神经记忆模块的写入**

Titans 使用可更新神经网络作为长期记忆，将当前输入构造成自监督关联，梯度大小表达「惊讶」。其核心状态不只包含记忆参数，还包含优化器动量。抽象写成

$$
g_t=\nabla_M\ell_t(M_{t-1}),\qquad
m_t=\beta_t m_{t-1}+(1-\beta_t)g_t,
\tag{24}
$$

$$
M_t=(1-\alpha_t)M_{t-1}-\eta_t m_t.
\tag{25}
$$

$\alpha_t$ 提供显式遗忘，$m_t$ 汇总一段时间内一致的惊讶方向，$\eta_t$ 控制写入。具体实现的符号与组合可以变化，这个抽象说明 Titans 相比基础 TTT 多出两类持久动力学：旧参数的主动衰减，以及梯度方向的时间积分。

动量让一次写入在后续继续施力。若连续 token 支持相同模式，方向累积能压过噪声；主题突然切换时，旧动量会造成滞后。遗忘项收缩参数，却不一定同步清除动量；只衰减 $M$ 而保留 $m$，旧模式可能被重新写回。分析或恢复状态时两者必须一起处理。

**三种架构位置对应不同记忆分工**

Titans 讨论把神经记忆置于 attention 前后或并行的不同方式。记忆在 attention 前可先用长期状态改写当前表示，再交给局部精确交互；放在后面则从局部上下文化表示中提炼长期内容；并行结构让两条支路独立读入，再由门控融合。架构位置改变写入输入与读取 query，不能只用同一个「参数记忆」标签概括。

并行分支便于做因果消融：关闭记忆读出但保留更新，可测状态是否写入却未使用；冻结更新但保留已有状态，可测历史读出；交换另一序列的记忆，可测内容特异性。串联结构中，关闭一支会改变下游输入分布，解释更需谨慎。

**惊讶度不是未来价值的同义词**

梯度大的 token 表示当前记忆预测得差。随机噪声、拼写错误与分布外字符串都可能很惊讶，却未必值得长期保存；常见约定当前预测容易，未来任务却可能要求精确引用。动量过滤孤立噪声，持续重复的无用模式仍可能占据状态。

可固定未来查询价值，扫描支持 token 的初始 loss；再固定初始 loss，扫描未来是否查询。理想记忆应同时受当前新颖性和未来效用影响。若写入强度只跟前者相关，Titans 展示的是自适应压缩，不足以证明学会了任务相关重要性。外循环能通过长期查询损失改善这种对齐，效果取决于信用能传播多远。

**容量：槽位数、秩与可达子空间**

## 4. 三类容量不能混成一个数字

显式槽位容量回答能保留多少条独立记录；压缩状态容量回答多少历史能映射到可区分状态；函数容量回答快速模型能表示多复杂的输入输出关系。全 attention 主要受槽位数和读取拥挤限制，线性 attention 与矩阵 RWKV 受状态秩和键几何限制，TTT-MLP 与 Titans 还受优化轨迹可达性限制。

对 $d_k$ 维线性地址，要求任意 $n$ 个独立键都能映射到任意值，最坏情况下需要 $n\le d_k$ 且键矩阵满列秩。参数矩阵含 $d_kd_v$ 个标量，不代表能精确寻址同样数量的随机事实。值结构共享能压缩更多，最坏情况边界仍在。

对含 $P$ 个参数的非线性记忆，执行 $K$ 步 SGD 后，若在局部线性区，参数位移落在至多 $K$ 个梯度方向张成的子空间。$P$ 很大而 $K$ 很小时，大部分潜在自由度没有被访问。曲率会让后续梯度方向变化，扩大可达集合，同时增加稳定性难题。

**有效秩比标称维度更接近现实**

真实语言键高度相关。将归一化键堆成 $K$，Gram 矩阵 $G=K^\top K$ 的有效秩

$$
r_{eff}(G)=\frac{(\operatorname{tr}G)^2}{\operatorname{tr}(G^2)}
\tag{26}
$$

衡量地址实际铺开的方向数。标称维度很大，若键集中在几个语义簇，有效秩仍低。线性 attention 会在簇内混合，delta rule 会在簇内覆盖，SSM 门控则把簇信息投进共享时间模态。MLP 可以重塑地址核，但也受训练数据与外循环信用约束。

测容量时应同时使用随机正交键、相关键和自然文本键。随机键展示理想几何上限，相关合成键控制碰撞强度，自然文本反映模型实际表示。只报随机 needle 容易忽略语义簇干扰，只报自然文本又难定位失败原因。

**有限精度形成更早的实用上限**

长序列反复更新时，小贡献可能低于 BF16 状态的分辨率，大状态上的细微写入直接舍入消失。显式 KV 量化也有误差，但每条槽位独立，误差不经递推反复累积。SSM、RWKV、TTT 与 Titans 的状态更新会让舍入沿时间传播。

以 FP32 保留状态、BF16 做矩阵乘，再与全 BF16 状态比较，能估计递推精度成本。若只改善长距离尾部，瓶颈来自累计舍入；短距离也改善，则当前读写本身对精度敏感。状态精度增加的字节要计入容量比较。

**写入、读取与遗忘的反例组**

**重复写入测试**

连续写入同一个 $(k,v)$，每次查询 $k$。无门线性 attention 的未归一化响应随次数增长；归一化线性 attention 趋向稳定均值；delta rule 在预测达到 $v$ 后更新趋近零；带衰减 SSM 或 RWKV 收敛到由写入和遗忘平衡决定的定点；带动量参数记忆可能越过定点后振荡。

这组实验不需要复杂数据，能直接识别更新方程。将 $v$ 在中途翻转符号，还可测适应速度与旧值残留。只看最终是否答对会丢掉不同机制的瞬态轨迹。

**相似键冲突测试**

构造 $k_1^\top k_2=\rho$，值 $v_1,v_2$ 正交，先写第一对再写第二对。扫描 $\rho$，记录对 $k_1$ 的输出。显式 attention 只要 softmax 能区分键，两个槽位仍在；外积状态误差近似随 $\rho$ 增长；delta 状态覆盖量还取决于第二次写入前对 $k_2$ 的预测；MLP 记忆的干扰由 Jacobian 核而非原始键内积决定。

把原始键内积固定、改变慢网络表示，可以测地址学习是否真正减少冲突。若训练后原空间仍相似，Jacobian 空间已分离，非线性记忆发挥作用；两处都未分离而任务仍成功，模型可能依赖窗口 attention 或位置捷径。

**查询后指定目标测试**

长前缀包含许多格式相同的随机事实，查询目标从中均匀抽样，写入阶段看不到抽样结果。全 attention 保留槽位，主要受检索拥挤影响；固定状态要同时保存所有候选，随事实数增加更早出现碰撞。查询格式若提前暴露目标，门控方法会获得额外线索。

改变候选数量而保持总长度相同，可以分离距离与容量；改变总长度而保持候选数量相同，可以测无关 token 干扰。两个轴都扫描，才能判断曲线下降源于时间衰减还是独立事实过多。

### 4.1. 顺序覆盖测试

同一键在不同时间关联 A、B、C，查询可以要求最新值、最早值或指定时间版本。delta rule 与强遗忘门天然偏向最新值；无衰减外积趋向平均；显式 attention 若位置进入地址，可选择特定版本。固定状态要回答所有版本，必须把时间编码为键的一部分或扩大状态。

「最新值」表现好不能推导出历史记忆强，「最早值」表现差也不一定是一般遗忘，可能是合理覆盖策略。三种查询一起报告，才能看到方法选择了哪种状态语义。

**读出失配测试**

保存某时刻状态 $S_s$ 与当时 query 网络。继续更新后，用新旧读出分别查询旧状态和新状态，形成四种组合。旧状态加旧读出成功、新状态加旧读出失败，说明写入覆盖；新状态加新读出失败、但新状态加旧读出成功，说明查询表示漂移；两种读出都无法从新状态恢复，信息很可能已从状态中消失。

对于参数记忆，旧读出可能包含后续层慢参数与归一化统计；对于 SSM，读出是 $C_t$；对于 attention，可保存原 query。这个干预比单看隐藏状态相似度更接近可用信息。

**复杂度：长度阶数之外还有状态更新成本**

**训练与自回归读取分开**

全 attention 训练对长度的算术量近似二次，自回归 decode 每 token 读取全部 KV，缓存线性增长。线性 attention、SSM 和 RWKV 的递推前向对长度线性，持久状态固定。TTT 与 Titans 也能保持固定状态，但每步或每块包含内模型反向与优化器更新，常数项明显更大。

若快速模型参数为 $P_f$，一次梯度写入至少需要一次内前向、一次内反向和状态写回。动量增加一个 $P_f$ 状态，Adam 类更新再增加二阶矩。把它们与一个 $d$ 维 SSM 状态都记作 $O(1)$，会掩盖几个数量级的字节差异。

固定状态方法在长序列上的优势通常来自缓存不增长；短序列时，全 attention 的大矩阵乘并行度很高，反向式写入未必更快。速度交叉点随硬件、批量、窗口、精度和更新频率移动。理论长度阶数只能说明趋势，不能给出交叉点。

**并行扫描要求结合律或可组合结构**

线性递推若能表示为关联算子，可用 parallel scan 训练。SSM、门控线性 attention 与部分 delta 规则围绕这一点设计。一般 TTT-MLP 梯度在更新后的参数上计算，后一步依赖前一步的非线性状态，很难直接组合；mini-batch 或 chunk 近似把多个梯度固定在共同起点，才换得矩阵并行。

因此，计算效率与状态语义绑在一起。把严格在线更新改成大块同起点更新，丢失块内优化路径；把 MLP 状态限制成可扫描矩阵更新，降低函数自由度。比较吞吐时应写明使用的是原方程还是近似协议。

**读取带宽与写入带宽**

KV attention 每步读取随长度增长的缓存，主要压力在读；参数记忆每次更新要读写整块快速权重，压力在状态写回；SSM 与 RWKV 读写较小递推状态。相同 FLOPs 下，三者可能受完全不同的硬件瓶颈限制。

状态量化对读取型方法节省带宽，对频繁原地更新的状态还需考虑累积误差与量化写回。只量化静态模型权重、保留 fast state 高精度，与全部低精度是两套内存账目。公平比较至少列静态权重、持久序列状态和临时激活三项。

**状态干预：证明模型真的使用了哪条通道**

### 4.2. 清空、冻结、替换与重放

清空状态测历史总体贡献；冻结更新保留已有记忆，测后续写入是否需要；替换成另一序列状态测内容特异性；从某个 checkpoint 重放测递推确定性。四个操作作用不同，组合后能定位读、写与状态生命周期。

全 attention 清空等于删除 KV；SSM/RWKV 清空递推张量；TTT/Titans 还要复位优化器状态与步数。只恢复参数、不恢复动量会产生一条不存在于原运行的轨迹。干预定义必须覆盖完整状态。

替换实验尤其有力。把含实体 Alice 的状态换入询问 Bob 的序列，若输出系统性偏向 Alice，状态携带具体内容；若只降低一般困惑度，状态更像领域统计；几乎无影响则可能未被读出。状态替换前要匹配位置与归一化尺度，避免纯数值异常。

**删除单条写入的反事实**

显式 attention 可删除一个 KV 槽位，再看查询变化。递推状态不能直接减去某条贡献时，可以从写入前 checkpoint 重放并跳过该 token。线性无门状态允许代数减外积，带衰减要乘上后续转移，非线性梯度记忆通常只能重放。

比较真实运行与删除反事实，得到单条 token 对最终输出的因果贡献。它比梯度热图更接近「这条信息是否被使用」。代价随重放长度增长，可在评测样本上离线完成。

**交换读取与写入组件**

混合模型常同时有窗口 attention 与压缩状态。关闭写入但保留状态读出，观察已有历史还能服务多久；关闭读出但继续写入，随后重新打开，检查信息是否确实存下。若关闭读出期间的 token 在重新打开后可被查询，写入通道独立工作；若不能，写入可能依赖读出反馈。

对 TTT/Titans，还可固定内损失、随机化 query 投影，或保留 query、打乱训练 target。前者破坏读取地址，后者破坏写入内容。性能下降模式能把「学会写」与「学会读」拆开。

**谱视角下的记忆时间与干扰**

**线性递推的记忆由传播矩阵决定**

对一般线性时变状态 $h_t=A_th_{t-1}+b_t$，位置 $s$ 的写入传播到 $t$ 的系数为 $A_tA_{t-1}\cdots A_{s+1}$。该乘积的奇异值描述不同方向保存或放大的程度。所有奇异值都快速衰减，模型只有短记忆；少数方向接近一，状态保留低维长期摘要；方向大于一，微小误差与噪声也会被放大。

特征值只适合固定且正规矩阵。数据依赖 $A_t$ 一般不对易，逐步特征值都小于一也可能出现瞬态放大。长序列稳定性更应估计实际矩阵乘积的最大奇异值，或用随机向量连续乘 Jacobian。SSM、RWKV 与门控 delta 网络都能放在这个传播框架下；TTT/Titans 则把 $A_t$ 换成优化更新对参数状态的 Jacobian。

多个时间尺度对应多组衰减接近一的方向。若任务要求同时保存句内、段落与文档级信息，单一标量衰减很难兼顾。通道化衰减、复数模态和输入选择门提供更丰富的谱。时间尺度丰富仍不等于随机访问：模型知道某个方向保留很久，不代表能从同一方向分离许多相似事实。

**delta 擦除是方向选择性遗忘**

线性 delta 更新可写成 $S_t=S_{t-1}(I-\beta_tk_tk_t^\top)+\beta_tv_tk_t^\top$。旧状态右乘 $I-\beta kk^\top$，只削弱键方向，正交方向保持不变。与全局标量衰减相比，它能在更新某个地址时少伤害无关地址。

若键归一化且 $\beta=1$，$k$ 方向的旧预测被完全擦除，再写入新值；$0<\beta<1$ 只做部分替换。键相关时，擦除方向也覆盖其他关联。连续键 $k_1,\ldots,k_t$ 形成一串投影乘积，顺序会影响最终状态，因为这些投影一般不对易。

这条式子解释了 Gated DeltaNet、现代 RWKV 矩阵状态和 TTT-Linear 的共同核心，也指出它们的差别来源。门控 delta 直接生成 $\beta,k,v$；TTT 用损失梯度得到等价项；带额外衰减的方法还在方向擦除外施加全局遗忘。对比实验若没有匹配这些门与衰减，只匹配矩阵大小，机制仍未对齐。

**动量引入第二个传播系统**

Titans 或带动量 TTT 的状态包含 $(M_t,m_t)$。线性化后，它是一个分块递推系统：

$$
\begin{bmatrix}\delta M_t\\\delta m_t\end{bmatrix}
=
\begin{bmatrix}
(1-\alpha_t)I-\eta_t(1-\beta_t)H_t & -\eta_t\beta_t I\\
(1-\beta_t)H_t & \beta_t I
\end{bmatrix}
\begin{bmatrix}\delta M_{t-1}\\\delta m_{t-1}\end{bmatrix}.
\tag{27}
$$

参数记忆与动量互相耦合，稳定性由整个分块矩阵决定。$\beta$ 大会延长梯度方向的寿命，也可能形成复特征值和振荡；$\alpha$ 拉回参数，却未直接消除动量。只分析 $M$ 的范数会漏掉一半动力学。

可对固定小网络显式计算局部 Jacobian 谱，再用长序列实测验证。若谱预测稳定而实际爆炸，非线性轨迹已离开局部区域；若局部就存在大于一的方向，降低学习率、动量或增加遗忘具有直接依据。

## 5. 信息可辨识性与状态碰撞

**固定精度状态必然合并历史**

假设持久状态有 $B$ 比特，而可能出现的历史集合大于 $2^B$，抽屉原理保证至少两段历史映射到同一状态。此后无论读出多强，任何查询都无法区分这两段历史。全 KV cache 的 $B$ 随长度增长，固定状态的 $B$ 保持常数，所以足够长、足够多样的历史上碰撞不可避免。

这个论证给出最坏情况，不预测自然语言上的实际长度。自然语言冗余很高，许多历史对未来预测等价，可以安全合并。任务若要求精确回忆随机串，等价类迅速变小，碰撞更早显现。模型的成功取决于把有限状态分给与未来有关的历史差异。

状态维度、数值精度和读出噪声共同决定实用比特数。一个 BF16 标量理论上有有限编码数，递推稳定范围、归一化和容错要求会进一步减少可用状态。用参数个数乘位宽得到的只是宽松上界，无法直接当成事实容量。

**查询集合决定哪些碰撞重要**

若两个历史对任务允许的所有未来 query 都给出相同答案，把它们压成同一状态没有损失。容量应相对查询族定义。语言建模 query 是后续前缀表示，精确数据库检索 query 则可能指定任意键；后者要求更细的等价类。

可先规定查询集合 $\mathcal Q$，再用最大读出差定义历史距离：

$$
d(H,H')=\sup_{q\in\mathcal Q}
\lVert R(S(H),q)-R(S(H'),q)\rVert.
\tag{28}
$$

若状态碰撞但 $d$ 很小，压缩对当前任务可接受；加入新的查询类型后，原来安全的碰撞可能暴露。benchmark 覆盖哪些 query，直接决定测到的是哪种容量。

平均 next-token loss 偏重常见查询，罕见精确查询权重很小。一个状态可以在平均 loss 上近乎最优，同时完全丢掉随机标识符。困惑度刻画自然查询分布，受控检索刻意提高罕见查询权重，两项结果会显露不同的状态碰撞。

**外部检索改变容量边界**

若压缩状态只负责生成检索键，原文由外部存储保留，状态无需容纳全部事实，只需保存路由信息。此时系统容量由内部状态、索引召回率与外部存储共同决定。把 RAG 的成功归给序列层记忆会混淆通道。

反过来，固定状态可以帮助检索：积累主题与用户意图，形成更好的 query；检索结果再进入局部 attention 做精确读取。这种组合把平滑长期统计与可审计事实分开，适合同时需要个性化和准确引用的任务。

**归一化、门控与状态尺度**

**归一化解决尺度，不自动解决内容冲突**

线性 attention 的分母、RMSNorm、状态范数裁剪和归一化梯度都能控制幅度。它们防止长度增加时输出无界增长，却不会增加独立地址数量。两个冲突值已在同一方向相加，除以总权重只能给出平均，无法恢复原条目。

归一化还可能隐藏饱和。状态范数保持恒定，内部方向却被最近内容不断旋转，旧信息照样消失。应同时监控固定探针读出、状态主子空间夹角与范数。只有范数稳定不足以证明长期记忆稳定。

对 TTT/Titans，LayerNorm 改变内损失梯度的几何。输入尺度被固定后，学习率更易共享；通道耦合使简单外积分析不再精确。归一化位置在快速模型内部、写入前或读出后，会形成不同状态方程。

**写门和读门承担不同职责**

写门决定当前内容对未来状态的影响，读门决定当前输出使用多少历史。一个 token 可以少写但强读，也可以强写而当前不读。把两者合成单个门，参数更少，却限制了这种非对称行为。

干预时固定写门、扫描读门，可测已有状态价值；固定读门、打乱写门，可测内容选择。若写门热图与人类直觉一致，但打乱后性能不变，热图只是相关现象。若关闭读门后模型仍表现相同，状态分支可能被残差绕过。

遗忘门又是第三个量。写门为零时，旧状态仍可通过遗忘门衰减；读门为零时，状态仍可继续积累。SSM、RWKV 与 Titans 对三个门的参数化不同，统一比较表应把它们拆开，而非统称 gate。

### 5.1. 门饱和会切断外循环信用

sigmoid 门接近零或一时导数很小，外层 loss 难以再调整写入和遗忘决策。训练早期若门过快饱和，模型可能固定在「几乎不记」或「什么都记」的局部解。初始化偏置、温度与正则都会改变这一过程。

记录门值分布还不够，需要记录 loss 对门 logit 的梯度。门值极端但梯度也小，可能是真正收敛，也可能是 sigmoid 饱和；将门临时拉回中间区域并观察性能，能区分两者。长度外推时，大量略小于一的遗忘门连乘会产生训练长度内看不出的衰减。

**一套跨机制的实验矩阵**

**控制状态预算**

为每种方法设定相同持久状态字节，再分别报告静态参数与临时激活。attention 在给定字节下可保留固定数量 KV，超出后需滑窗或压缩；SSM/RWKV 分配状态宽度；TTT/Titans 分配快速参数与优化器状态。等字节比较回答「同样记忆预算下谁更有效」。

再做等每 token FLOPs 与等延迟比较。某方法在等字节下更强，可能计算昂贵；在等 FLOPs 下缩小状态后结论可能翻转。三种口径并列，避免把容量、算力和实现质量混为一谈。

训练数据、token 数、窗口和静态 backbone 也要一致。混合模型保留局部 attention 时，对照组应拥有同样窗口。否则远程收益可能来自一方多出的显式缓存。

**控制信息结构**

实验轴包括事实数、键相似度、值相似度、写入到查询距离、主题切换频率和查询揭示时间。事实数测容量，键相似度测地址碰撞，值相似度区分有益泛化与有害覆盖，距离测衰减，主题切换测门与动量，查询揭示时间测提前压缩风险。

每次只改变一个轴，结果按错误类型分解。返回最近值指向覆盖偏置，返回相似键的值指向地址碰撞，输出条件均值指向外积聚合，完全无关答案可能来自检索失败或状态未读。准确率相同的两个模型可能有完全不同的失效机制。

自然文本评测放在合成矩阵之后。合成结果提供可控诊断，自然文本检验结论能否迁移。只做合成容易高估规则化数据，只做自然文本难以归因。

**控制状态生命周期**

同一模型分别在每段复位、每文档复位、跨文档保留三种设置运行。每段复位测局部情节记忆，每文档复位测长上下文，跨文档保留进入持续适应。性能提升若只出现在跨文档设置，要同时检查数据泄漏与顺序依赖。

在边界交换两个样本的状态，是检验隔离的强测试。输出随错误状态中的内容偏移，说明状态携带信息；系统若原本声称样本独立，这也证明实现存在串扰。优化器矩、位置计数和缓存都属于需要交换或复位的状态。

**控制读取通道**

混合架构对窗口、压缩状态和外部检索做组合开关。完整模型的增益若等于某一单分支，其他分支没有边际贡献；组合超过各自增益之和，可能存在互补；组合更差则存在冲突或融合门问题。

将查询距离推到窗口之外，再关闭外部检索，才能单独测试压缩状态。将状态冻结在写入前，能给出静态 backbone 基线。将正确状态换成随机状态，能判断模型是否对任何额外激活都同样受益。

**读取置信度与失败检测**

压缩状态通常会在容量饱和后平滑退化，模型仍能给出流畅且高置信的答案。系统若只看生成概率，很难知道某条事实已经被覆盖。显式 KV 也可能检索错误，但还能检查注意力候选或回到原文；参数记忆缺少天然的来源指针。

可为读出增加状态置信信号。线性矩阵状态可利用 query 在键子空间中的投影、归一化分母与局部条件数；SSM/RWKV 可利用累计门乘积与状态饱和指标；TTT/Titans 可利用当前 query 的内模型残差、更新历史和 Jacobian 范数。这些量只提供候选信号，必须用正确与错误检索样本校准，不能直接解释为事实概率。

校准集按距离、事实数和键相似度分桶。若同一个置信阈值只在短距离有效，说明信号主要反映时间衰减；若对碰撞强度敏感，则更接近地址可靠性。将置信度用于回退策略时，可在低置信状态转向外部检索或保留原文，形成有损记忆与精确通道之间的动态选择。

错误检测还可利用状态一致性。对同一 query 施加轻微改写，稳定记忆应给出相容答案；碰撞边界附近可能随措辞跳变。用多个等价 query 的输出方差作为报警信号，成本高于单次读取，但适合高风险请求。它检测的是局部稳定，无法证明答案真实，仍需来源核验。

### 5.2. 状态预算变化时的校准漂移

模型在某一状态宽度、窗口长度和训练上下文上学到的置信信号，换到更长序列后可能失准。干扰项数量增加，attention 的最大权重会下降；递推状态经历更多次舍入与遗忘；参数记忆离初始化更远，局部残差的尺度也变化。长度外推评测需要同时重画准确率与置信度曲线。

扩大状态维度也不保证原阈值可沿用。更宽状态可能降低碰撞，却改变范数和分母分布。按目标长度重新校准可以改善部署表现，但会掩盖模型自身是否具备外推稳定性。论文报告中保留训练长度阈值与重新校准阈值两组结果，能够区分结构能力和后处理收益。

**失败后的恢复粒度**

KV cache 可删除一段槽位并从对应位置重算；SSM/RWKV 需要从较早状态 checkpoint 重放；TTT/Titans 还需恢复优化器状态。checkpoint 间隔决定恢复成本和污染范围。间隔很长时，一条异常写入会迫使系统重算大量 token；间隔很短时，状态快照占用抵消固定内存优势。

恢复评测可在随机块注入异常，检测后回滚到最近 checkpoint，再与从头无异常运行比较。输出差异揭示状态恢复是否完整。动量、随机数状态、位置计数或归一化缓存漏存，都会让重放轨迹分叉。对声称可持续更新的系统，这项检查与平均任务指标同样重要。

**如何选择状态机制**

**精确引用优先时**

法律条款、代码片段和数据库记录经常要求按位置精确引用，查询目标又可能很晚才确定。显式 attention、检索系统或保留原文的分层缓存能够维持独立槽位。固定状态适合承担主题摘要与路由，可核查事实仍由原文通道提供。

若显存不允许全量 KV，可采用局部窗口加稀疏全局槽、压缩旧段同时保留关键原文索引。选择的核心是哪些信息允许有损压缩，而非强行让一种层覆盖所有时标。

**平滑统计与持续主题优先时**

语言风格、说话人特征、视频运动趋势与长期主题具有冗余，SSM、RWKV 和线性状态擅长以固定预算累计。显式衰减提供可控时间尺度，选择门让状态跳过部分噪声。任务关注平均预测时，条件均值式压缩可能比保存每条槽位更有效。

写入规则无需反向计算时，SSM/RWKV 在延迟与实现上更直接。矩阵状态和 delta 擦除增加关联容量，仍保留结构化递推优势。

**内容依赖纠错优先时**

上下文不断提出新约定，旧状态能否预测当前训练对本身就是重要信号。TTT 的误差驱动写入适合这种场景：预测正确少改，出现残差再修正。需要非线性地址时可用 TTT-MLP，能接受更高更新成本与稳定性压力。

Titans 的动量和遗忘适合证据需要跨若干 token 积累、主题又会切换的情况。动量时间尺度、遗忘率和文档结构若不匹配，也会造成滞后或过快清除。选择参数记忆前，应确认未来收益足以覆盖内反向成本。

**混合结构通常对应多种信息形态**

近期 token 需要精确访问，长期背景允许压缩，少数关键事实还需外部检索。窗口 attention、递推状态与检索索引分别承担这些角色，比要求单一状态同时做到精确、恒定内存和低延迟更现实。混合后最重要的实验是分支干预，确认每条通道确实承担预期时标。

分工并不会自动出现。训练 loss 可能让最强分支包办任务，其他分支成为昂贵摆设。限制窗口、随机丢弃分支、设置互补任务或直接测边际贡献，才能观察状态机制是否形成了真实互补。
