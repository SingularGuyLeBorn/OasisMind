# 5.1 · TTT layers 与 fast weights

## 问题与 TTT layer 的三个组件

**问题: 固定大小的状态装不下长上下文.** 序列层可以按「状态」来分. 自注意力的状态是 KV cache, 每读一个 token 追加一对 $(k_t, v_t)$, 状态随 $t$ 线性增长, 生成第 $t$ 个 token 要扫描 $t$ 对 KV, 每个 token 的开销是 $O(t)$. RNN 的状态大小固定, 每个 token 的开销是 $O(1)$, 代价是要把整个历史压进固定大小的状态.

[Kaplan 等 (2020)](https://arxiv.org/abs/2001.08361) 的 Scaling Laws 论文里已经观察到, LSTM 既不能像 Transformer 那样随规模扩展, 也不能有效利用长上下文. 提出 TTT layer 的 [Sun, Li, Dalal 等 (2024)](https://arxiv.org/abs/2407.04620) 用 [Mamba](https://arxiv.org/abs/2312.00752) 重做了这个检查 (论文图 2): Mamba 在规模上的 Scaling Laws 已经和 Transformer 接近, 但在 Books 数据上按 token 位置画平均困惑度, Transformer 的曲线在 32k 内一直下降, Mamba 在 16k 之后变平. 后面的 token 能看到的历史更多, 理应更容易预测, 曲线变平说明 Mamba 的状态没能装下更多有用的信息.

RNN 相对 Transformer 的优势是线性复杂度, 这个优势只在长上下文里才兑现 (论文测得 8k 之后); 偏偏在长上下文里, 现有 RNN 用不上多出来的信息. 这是 TTT layer 要处理的矛盾. 论文的切入点是: 自监督学习本来就是一种把大量数据压进模型权重的方法, LLM 的预训练就是例子. 那么把 RNN 的状态更新本身写成一次自监督学习, 状态的压缩能力就来自学习算法, 而不是一个手写的门控公式. TTT layer 的机制可以拆成几个相互连接的问题:

1. 状态是一个模型的权重, 更新规则是一步梯度下降, 这个层具体怎么算?
2. 内循环学什么, 由谁决定?
3. 它和线性注意力, DeltaNet, 自注意力是什么关系?
4. 逐 token 的梯度下降是串行的, 怎么在 GPU/TPU 上跑快?
5. 实验在多大规模, 多长上下文下成立, 成本在哪?

**三个组件: 初始状态, 更新规则, 输出规则.** 论文把所有序列层拆成三个组件. 设输入 token 为 $x_t$, 输出为 $z_t$, 状态为 $s_t$:

| 层 | 初始状态 | 更新规则 | 输出规则 | 每 token 开销 |
| --- | --- | --- | --- | --- |
| 朴素 RNN | $s_0 = $ 零向量 | $s_t = \sigma(\theta_{ss}s_{t-1} + \theta_{sx}x_t)$ | $z_t = \theta_{zs}s_t + \theta_{zx}x_t$ | $O(1)$ |
| 自注意力 | $s_0 = $ 空列表 | $s_t = s_{t-1}.\text{append}(k_t, v_t)$ | $z_t = V_t\,\text{softmax}(K_t^\top q_t)$ | $O(t)$ |
| 朴素 TTT | $W_0 = f$ 的初始参数 | $W_t = W_{t-1} - \eta \nabla \ell(W_{t-1}; x_t)$ | $z_t = f(x_t; W_t)$ | $O(1)$ |

自注意力一行里 $K_t, V_t$ 是前 $t$ 个 key, value 按列拼成的矩阵. TTT 一行的状态是 $f$ 的参数 $W_t$, 大小固定, 所以它属于 RNN; 区别在更新规则, 它是对损失 $\ell$ 的一步梯度下降, 没有手写的门控或非线性映射:

$$
W_t = W_{t-1} - \eta\, \nabla \ell(W_{t-1}; x_t)
\tag{1}
$$

$\eta$ 是内循环学习率. 从压缩的角度看, 式 (1) 决定了记住什么: 梯度大的 token (让 $W$ 学到很多的 token) 对状态的改动大. **内循环损失.** 最简单的 $\ell$ 是重建: 把 $x_t$ 加噪或投影成 $\tilde{x}_t$, 让 $f$ 从 $\tilde{x}_t$ 重建 $x_t$, 损失 $\lVert f(\tilde{x}_t; W) - x_t \rVert^2$. 论文图 4 在 125M 模型上画了这个损失: 每走一步, $\ell(W_t; x_t)$ 比 $\ell(W_{t-1}; x_t)$ 低; 沿着序列往后, $\ell(W_t; x_t)$ 也比用初始权重的 $\ell(W_0; x_t)$ 越来越低, 说明 $W$ 确实在积累关于这条序列的信息. 手工设计加噪方式不一定对下游任务有用. 论文把重建任务本身参数化, 交给外循环学. 训练视图 $\theta_K x_t$ 是一个可学习的低秩投影, 重建目标 (标签视图) 是另一个可学习投影 $\theta_V x_t$:

$$
\ell(W; x_t) = \big\lVert f(\theta_K x_t; W) - \theta_V x_t \big\rVert^2
\tag{2}
$$

训练视图的维度比 $x_t$ 低, 输出不能再直接用 $f(x_t; W_t)$, 于是再加一个测试视图 $\theta_Q x_t$:

$$
z_t = f(\theta_Q x_t; W_t)
\tag{3}
$$

下标 $K, V, Q$ 是有意的: 它们在形式上对应自注意力的 key, value, query 投影. 式 (2) 决定 $x_t$ 的哪部分信息被压进 $W_t$ 并沿时间往后传; 式 (3) 决定从 $W_t$ 里读出什么, 送到当前位置的下一层. $z_t$ 是这一层的输出向量, 送进网络后续层; 它本身不是下一个 token 的预测. 下一个 token 的预测由整个网络的输出头给出, 训练目标是标准的下一个 token 预测. **内循环与外循环.**

| | 内循环 (TTT) | 外循环 (正常训练) |
| --- | --- | --- |
| 一条数据 | 一个 token $x_t$ | 一条序列 $x_1, \dots, x_T$ |
| 训练集 | 一条序列 | 序列的数据集, 如 Books |
| 目标 | 重建, 式 (2) | 下一个 token 预测 |
| 被优化的参数 | $W$ ($f$ 的权重) | 网络其余参数 $\theta_{\text{rest}}$; $\theta_K, \theta_Q, \theta_V$; 初始值 $\theta_{\text{init}} = W_0$; 学习率参数 $\theta_{\text{lr}}$ |

这张表 (论文 Table 2) 里最重要的一点是: 在外循环看来, $W$ 只是隐状态, 不是参数; 外循环的参数是内循环损失和优化器的「超参数」. 外循环对 $\theta_K$ 等求梯度时, 要穿过式 (1) 里的梯度算子, 也就是对梯度求梯度. 这和 MAML 一类元学习的二阶梯度是同一种计算.

和常见的元学习相比, 这里的层级关系是反过来的. MAML 一类方法的内循环在一整个数据集 (一个任务) 上学习, 外循环要在很多个数据集上平均, 所以外循环比常规训练「高一级」, 需要收集成千上万个任务, 很难扩大规模. TTT layer 的内循环把一条序列当作一个数据集, 一个 token 当作一条数据, 内循环比常规训练「低一级」; 外循环面对的就是普通的序列数据集和普通的下一个 token 预测目标, 和训练一个 Transformer 没有区别. 论文认为这是这套外循环容易扩展的原因. 论文还试过在 $f$ 后面再接一个解码器 $g$, 用 $g \circ f$ 做重建. 效果略好, 但外循环训练变得不稳, 计算也明显增加, 最终只用编码器式的 $f$. TTT layer 在序列内维护的状态可以具体写成:

| 问题 | TTT layer |
| --- | --- |
| 更新对象 | 内循环模型 $f$ 的权重 $W$, 每个 token 或每个 mini-batch 更新一次 |
| 损失与读出 | 当前 token 的训练视图 $\theta_K x_t$ 和标签视图 $\theta_V x_t$ 计算损失; 输出时输入测试视图 $\theta_Q x_t$ |
| 状态生命周期 | $W_t$ 由式 (1) 从 $W_{t-1}$ 得到, 每条序列从 $W_0$ 开始, 序列结束丢弃 |
| 信息限制 | $W_t$ 保存对重建损失有用的统计结构, 无法精确复现任一历史 token |

### 手算, mini-batch 与 dual form

**手算: TTT-Linear 一步就是 delta rule.** 取 $f(k) = Wk$ (不加 LN 和残差), 记 $k_t = \theta_K x_t$, $v_t = \theta_V x_t$, 式 (2) 变成 $\ell = \lVert W k_t - v_t \rVert^2$. 对 $W$ 求梯度:

$$
\nabla_W \ell = 2(W k_t - v_t) k_t^\top
\tag{4}
$$

代入式 (1), 整理:

$$
W_t = W_{t-1} - 2\eta (W_{t-1} k_t - v_t) k_t^\top = W_{t-1}(I - 2\eta\, k_t k_t^\top) + 2\eta\, v_t k_t^\top
\tag{5}
$$

[DeltaNet](https://arxiv.org/abs/2406.06484) 的状态更新是 $S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$. 取 $\beta_t = 2\eta$, 两者相同. 论文在 related work 里也给了这个结论: DeltaNet 等价于内循环 mini-batch 大小为 1, 去掉 LN 和残差的 TTT-Linear. 式 (5) 的两项各有含义. 第二项 $2\eta\, v_t k_t^\top$ 把新的 key-value 关联写进去; 第一项 $W_{t-1}(I - 2\eta\, k_t k_t^\top)$ 先把旧状态在 $k_t$ 方向上的分量擦掉一部分. 先擦后写, 所以同一个 key 再次出现时, 新 value 会替换旧 value. 代入数字. 二维, $W_0 = 0$, $\eta = 0.5$ (所以 $2\eta = 1$). 第 1 个 token: $k_1 = (1, 0)^\top$, $v_1 = (0, 1)^\top$. $W_0 k_1 = 0$, 误差 $W_0 k_1 - v_1 = (0, -1)^\top$, 按式 (5):

$$
W_1 = 0 - (0, -1)^\top (1, 0) = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}
$$

查询 $q = (1, 0)^\top$: $W_1 q = (0, 1)^\top = v_1$, 读回了刚写入的 value. 第 2 个 token 用同一个 key, 换一个 value: $k_2 = (1, 0)^\top$, $v_2 = (1, 0)^\top$. 先算当前状态对 $k_2$ 的输出 $W_1 k_2 = (0, 1)^\top$, 误差 $(0, 1)^\top - (1, 0)^\top = (-1, 1)^\top$:

$$
W_2 = W_1 - (-1, 1)^\top (1, 0) = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix} - \begin{pmatrix} -1 & 0 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}
$$

查询 $q = (1, 0)^\top$: $W_2 q = (1, 0)^\top = v_2$, 旧 value 被完整替换. 同样两个 token 交给不带归一化的线性注意力, 状态是外积的累加 $S_2 = v_1 k_1^\top + v_2 k_2^\top = \begin{pmatrix} 1 & 0 \\ 1 & 0 \end{pmatrix}$, 查询得到 $(1, 1)^\top$, 是 $v_1$ 和 $v_2$ 的叠加. 线性注意力只写不擦, 同一个 key 上的多个 value 会混在一起; delta rule 用当前预测误差决定写多少, 能覆盖. 这里 $\lVert k \rVert = 1$, $2\eta = 1$, 覆盖是完全的; $2\eta < 1$ 时是部分覆盖. **让它跑起来: mini-batch TTT.** 式 (1) 不能并行: $W_t$ 依赖 $W_{t-1}$, 依赖出现在两处, 减号前面和梯度里面. 梯度是主要计算量, 论文从这里下手. 把梯度下降写成通式:

$$
W_t = W_{t-1} - \eta\, G_t = W_0 - \eta \sum_{s=1}^{t} G_s
\tag{6}
$$

$G_t$ 是下降方向. 只要所有 $G_t$ 都算出来, 所有 $W_t$ 就是一次累加 (cumsum). 三种选择:

- 在线 GD: $G_t = \nabla \ell(W_{t-1}; x_t)$, 每个梯度依赖上一步, 完全串行. $W_t$ 离 $W_0$ 有 $t$ 步.
- batch GD: $G_t = \nabla \ell(W_0; x_t)$, 全部相对 $W_0$ 求, 完全并行. 但 $W_t$ 实际上离 $W_0$ 只有一步, 搜索空间小, 语言建模效果差.
- mini-batch GD: $G_t = \nabla \ell(W_{t'}; x_t)$, 其中 $t' = t - \text{mod}(t, b)$ 是上一个 mini-batch 结束时. 同一块内的 $b$ 个梯度相对同一个基点求, 可以并行; 块与块之间串行.

论文所有实验取 $b = 16$. 图 7 的消融显示 $b$ 越小困惑度越好 (梯度步数越多), 但并行度越低. 信息在 $W_s$ 到 $W_t$ ($s < t$) 之间有两条传播通道: 累加 (式 (6) 的求和, 始终在) 和梯度算子 (只在 $W_s$ 来自之前的块时才在). 不同的 GD 变体只改变梯度通道.

用前面的手算例子看 mini-batch 的代价. 取 $b = 2$, 两个 token 在同一块里, 梯度都相对 $W_0 = 0$ 求: $G_1 = -2 v_1 k_1^\top$, $G_2 = -2 v_2 k_2^\top$. 块结束时 $W_2 = W_0 - 0.5(G_1 + G_2) = v_1 k_1^\top + v_2 k_2^\top$, 和线性注意力的结果一样, 查询得到 $(1, 1)^\top$. 块内的 token 之间没有擦除, 只有块与块之间才有 delta rule 的覆盖. $b$ 越大, TTT 越接近线性注意力; $b = T$ (整条序列一块) 就是下一节的定理 1. **dual form: 把外积换成矩阵乘.** mini-batch 解决了并行, 没解决硬件利用率. 现代加速器的算力集中在矩阵乘单元 (A100 的 TensorCore 一次做 $16 \times 16$ 的矩阵乘), 而 mini-batch TTT 的每个 $G_t$ 是一个 $d \times d$ 的外积, $b$ 个外积要一个个算, 每个都要写回显存, 内存 I/O 远大于 $x_t$ 本身. 论文的观察是, 块内的 $G_t$ 和中间的 $W_t$ 都不需要显式生成, 只要算出块末的 $W_b$ 和块内所有输出 $z_1, \dots, z_b$. 以最简单的情况推导: $\theta_K = \theta_V = \theta_Q = I$, $f(x) = Wx$, 第一个块. 记 $X = [x_1, \dots, x_b]$. 块末权重:

$$
W_b = W_0 - \eta \sum_{t=1}^{b} G_t = W_0 - 2\eta \sum_{t=1}^{b} (W_0 x_t - x_t) x_t^\top = W_0 - 2\eta (W_0 X - X) X^\top
\tag{7}
$$

一次矩阵乘. 块内输出:

$$
z_t = W_t x_t = W_0 x_t - 2\eta \sum_{s=1}^{t} (W_0 x_s - x_s) x_s^\top x_t
\tag{8}
$$

记 $\delta_t = \sum_{s=1}^{t} (W_0 x_s - x_s) x_s^\top x_t$, $\Delta = [\delta_1, \dots, \delta_b]$. 交换求和顺序, 把 $x_s^\top x_t$ 收成一个 Gram 矩阵:

$$
\Delta = (W_0 X - X)\, \text{mask}(X^\top X)
\tag{9}
$$

mask 是上三角掩码, 被掩掉的位置填 0 (自注意力的因果掩码填 $-\infty$, 这里填 0). 于是 $Z = W_0 X - 2\eta \Delta$, 全是矩阵乘. $W_0 X - X$ 在式 (7) 和式 (9) 里共用. 两种形式输出相同, 代价不同. primal form (显式生成 $G$ 和 $W$) 块内复杂度 $O(b d^2)$; dual form 算 $W_b$ 是 $O(b d^2)$, 算 $z_1, \dots, z_b$ 另加 $O(b^2 d)$. 理论复杂度变高了, 换来的是硬件利用率. 代入 $d = 256$, $b = 16$: $b d^2 = 16 \times 65536 = 1{,}048{,}576$, $b^2 d = 256 \times 256 = 65{,}536$, 额外开销约 6%. 论文的 JAX 实现里, 用 dual form 训练比 primal form 快 5 倍以上. 附录 A 说明 $f$ 含非线性层时 dual form 同样成立. 推理时两种形式分工: prefill 和训练的前向一样可以并行, 用 dual form; decode 逐 token 生成, 本身就串行, 用 primal form.

### 更新稳定性与外循环梯度手推

**单个 key 上的收敛区间.** 式 (5) 说明 TTT-Linear 在每个 token 上做一次最小二乘。若同一个单位范数 key $k$ 反复出现，目标 value 固定为 $v$，只看状态在 $k$ 方向上的输出 $u_t=W_tk$，更新可化成

$$
u_t=u_{t-1}-2\eta(u_{t-1}-v)
=(1-2\eta)u_{t-1}+2\eta v.
\tag{10}
$$

令误差 $e_t=u_t-v$，得到

$$
e_t=(1-2\eta)e_{t-1}
=(1-2\eta)^t e_0.
\tag{11}
$$

因此 $|1-2\eta|<1$，也就是 $0<\eta<1$ 时误差才收敛。$\eta=0.5$ 时一步写准；$0<\eta<0.5$ 时单调靠近；$0.5<\eta<1$ 时在目标两侧振荡但幅度衰减；$\eta>1$ 则发散。 取初始 $u_0=0$、目标 $v=1$。当 $\eta=0.25$，序列为 $0,0.5,0.75,0.875$；当 $\eta=0.75$，序列为 $0,1.5,0.75,1.125$；当 $\eta=1.2$，序列为 $0,2.4,-0.96,3.744$。三组都在优化同一平方误差，区别只来自更新谱半径。可学习学习率必须受到适当参数化约束，否则外循环可能为了短期训练损失选择过大的写入强度，让长序列状态在训练长度之外爆炸。 key 不归一化时，式 (11) 的系数变成 $1-2\eta\lVert k\rVert^2$，稳定条件为

$$
0<\eta<\frac{1}{\lVert k\rVert_2^2}.
\tag{12}
$$

这解释了内模型中的归一化为何不只是常规网络组件：它还控制 fast-weight 更新的有效步长。同一个 $\eta$ 遇到范数为 1 和范数为 10 的 key，后者的安全上界小 100 倍。输入依赖的 $\eta(x)$ 可以降低异常 token 的写入强度，但门控本身由外循环学得，仍要在比训练更长的序列和异常激活上检查。 **两个不正交 key 如何互相干扰.** 状态写入容量不能只用矩阵元素个数判断。设两个单位 key 满足 $k_1^Tk_2=\rho$，先以 $2\eta=1$ 写入 $(k_1,v_1)$，再写入 $(k_2,v_2)$。第一步后 $W_1k_1=v_1$。第二步使用 delta rule：

$$
W_2=W_1+(v_2-W_1k_2)k_2^T.
\tag{13}
$$

重新读取第一个 key：

$$
W_2k_1
=v_1+\rho(v_2-W_1k_2).
\tag{14}
$$

当 $k_1,k_2$ 正交时 $\rho=0$，第二次写入完全不影响第一条记忆；二者相似时，新残差会按 $\rho$ 泄漏进旧查询。取 $k_1=(1,0)^T$、$k_2=(0.8,0.6)^T$，所以 $\rho=0.8$；令 $v_1=(1,0)^T$、$v_2=(0,1)^T$。第一步 $W_1=v_1k_1^T$，于是 $W_1k_2=(0.8,0)^T$。第二步残差为 $(-0.8,1)^T$，再读 $k_1$ 得

$$
W_2k_1=(1,0)^T+0.8(-0.8,1)^T=(0.36,0.8)^T.
$$

旧 value 已明显改变。固定状态把相似 key 写进同一子空间, 干扰由此产生, 与优化器的偶然失误无关。学习 $\theta_K$ 的作用之一，就是把以后需要分别取回的信息映射到较少冲突的方向；但 $d$ 维空间最多容纳 $d$ 个互相正交方向，序列无限增长后仍要压缩或覆盖。 **外循环为什么包含二阶项.** 用标量例子把“对梯度求梯度”算一遍。内模型为 $f(k;w)=wk$，内损失

$$
\ell_{in}(w;a)=\frac12(wa-v)^2,
$$

其中 $a$ 类似可学习的 key 投影。一步内更新为

$$
w_1=w_0-\eta( w_0a-v)a.
\tag{15}
$$

外损失设为 $\ell_{out}=\frac12(w_1q-y)^2$。外循环对投影参数 $a$ 的梯度经链式法则为

$$
\frac{\partial\ell_{out}}{\partial a}
=(w_1q-y)q\frac{\partial w_1}{\partial a},
$$

$$
\frac{\partial w_1}{\partial a}
=-\eta(2w_0a-v).
\tag{16}
$$

取 $w_0=1,a=2,v=3,\eta=0.1,q=1,y=2$。内梯度为 $(2-3)\times2=-2$，所以 $w_1=1.2$；外残差为 $-0.8$；$\partial w_1/\partial a=-0.1(4-3)=-0.1$，最终 $\partial\ell_{out}/\partial a=0.08$。外循环会减小 $a$，因为它响应的是这次内更新造成的最终预测误差, 而非当前重建误差。 若在实现中对内梯度 `stop_gradient`，式 (16) 对 $a$ 的通路会被切断，$\theta_K$ 无法学习“怎样构造一个有用的内任务”。一阶近似可以省显存和计算，却改变了可学习对象。完整 TTT layer 训练需要为内更新保留高阶自动微分所需的信息；序列越长、内模型越大，这部分激活与重计算就越昂贵。 **mini-batch 近似到底丢了哪一项.** 设一个块含两个样本，在线更新为

$$
W_1=W_0-\eta g_1(W_0),\qquad
W_2=W_1-\eta g_2(W_1).
$$

在 $W_0$ 附近对第二个梯度做一阶展开：

$$
g_2(W_1)\approx g_2(W_0)
-\eta H_2(W_0)g_1(W_0),
\tag{17}
$$

其中 $H_2$ 是第二个内损失对 $W$ 的 Hessian。代回后

$$
W_2\approx W_0-\eta[g_1(W_0)+g_2(W_0)]
+\eta^2H_2(W_0)g_1(W_0).
\tag{18}
$$

mini-batch TTT 在同一基点并行求两个梯度，只保留前两项，丢掉 $\eta^2H_2g_1$。这项表达“第一个 token 改变状态以后，第二个 token 的梯度也随之改变”。步长小、块内曲率低或梯度相互作用弱时，省略项较小；块大以后，被省略的跨 token 高阶作用不断累积。因而 $b$ 同时是硬件并行参数和学习算法近似精度参数，不能只按吞吐选择。

## 状态、参数与缓存的资源构成

设 TTT-Linear 的状态矩阵 $W\in\mathbb R^{d\times d}$。每层每条独立序列需要 $d^2$ 个状态元素；FP16 下是 $2d^2$ 字节。$d=256$ 时约 128 KiB，$d=1024$ 时约 2 MiB。若批中有 32 条互不相干的序列，状态不能混用，单层分别约为 4 MiB 和 64 MiB。多层模型还要按 TTT 层数相乘。 TTT-MLP 若隐层为 $4d$，两块主要权重分别为 $[4d,d]$ 与 $[d,4d]$，fast-weight 状态约 $8d^2$，比线性状态大八倍。它仍然对序列长度保持常数，却未必比短上下文 KV cache 小。以每层 attention 的 KV cache 为例，忽略 GQA 等细节，单序列长度 $T$ 的两块缓存约有 $2Td$ 个元素。令 $d^2=2Td$，TTT-Linear 与 KV 的元素数在 $T=d/2$ 处相交；TTT-MLP 的 $8d^2$ 则在 $T=4d$ 才相交。固定状态的优势要到足够长上下文才兑现。

训练状态还包括慢参数、fast-weight 轨迹和外循环优化器。fast weights 是运行态，不代表无需存梯度。完整反向需要穿过每个块的更新；可以保存块边界状态并在反向时重算块内过程，以计算换显存。报告“状态大小 $O(d^2)$”只描述在线前向持有的压缩状态，不能直接当作训练峰值显存。

服务端还面临状态归属。不同会话必须持有各自的 $W_t$；请求迁移到另一张 GPU 时，fast weights 与必要的优化器状态要一起搬运；会话被换出后，恢复点必须包含当前 token 位置、状态矩阵和数值精度。若只保存原模型 checkpoint，长上下文已经写入的内容全部消失。它与 KV cache 一样是会话状态，只是表示形式从 token 列表换成模型参数。

### 怎样验证它真的在使用长上下文

平均困惑度只能说明下一 token 预测整体改善，不能定位状态记住了什么。一个更有解释力的协议同时放入四类任务。第一类是局部语言建模，答案主要取决于最近几十个 token，用来检查卷积和短程 backbone；第二类是关联回忆，在开头写入若干随机 key-value，远处查询指定 key；第三类是统计估计，例如要求根据整段出现频率判断多数符号；第四类是自然长文档的下一 token 预测。四类任务分别考查局部模式、精确检索、压缩统计量和真实分布，不能用一个分数互相代替。

关联回忆还应控制 key 冲突。构造 $N$ 对单位向量 $(k_i,v_i)$，分别设置 key 两两近似正交与高余弦相似，查询距离取 $D\in\{1\text{k},8\text{k},32\text{k},128\text{k}\}$。根据式 (14)，相似 key 更容易覆盖旧 value。如果模型在正交 key 上能记住 32k，却在相似 key 上迅速下降，瓶颈指向状态干扰；若两者都在固定距离同时下降，则还要检查训练长度、数值精度与学习率门控。

消融至少包括冻结内更新（始终使用 $W_0$）、随机打乱 $v_t$、将 $\eta$ 置零、把 mini-batch 大小从 1 扫到整段，以及用同参数量线性注意力替换 TTT 层。冻结或置零给出 backbone 自身能力；打乱 value 检查收益是否真的来自可学习写入目标；块大小曲线则检验式 (18) 中丢失的跨 token 作用。所有设置要锁定训练 token、慢参数量、上下文长度和数据顺序。

记录指标时，除了准确率和困惑度，还要保存内损失、$\lVert W_t-W_0\rVert_F$、最大奇异值、学习率门控分布以及状态重置后的性能。若内损失持续下降而外任务变差，说明自监督写入目标与语言建模目标失配；若最大奇异值随长度增长，可能接近式 (12) 的不稳定区；若状态位移很快饱和，后续 token 可能已无法写入新信息。

吞吐比较需分成 prefill 与 decode。对每种上下文长度报告首 token 延迟、decode 每 token 延迟、峰值显存和批大小上限，并固定硬件、精度与 kernel 成熟度。TTT 的理论每 token 常数复杂度不保证短序列墙钟更快；dual form 的矩阵乘优势主要发生在 prefill，逐 token decode 仍要执行内模型前向、梯度构造和状态写回。只有在质量相当且端到端服务指标更好时，才能把线性复杂度转成工程优势。

还应做长度外推。模型只在 8k 训练时，分别评估 8k、16k、32k、64k，并检查状态数值与任务性能，而不是只把位置编码允许的长度当作“支持长度”。固定大小状态理论上可以继续运行，但学习率门控、归一化和外循环只见过有限步数，超出训练长度后的稳定性没有自动保证。实验覆盖到哪里，结论就写到哪里。

结果表还要给出按距离和写入数量分桶的曲线。假设 32k 序列中写入 128 个 key，整体关联回忆准确率为 80%；若前 32 个 key 只有 55%，后 32 个达到 98%，模型表现的其实是强烈近因偏置。再把查询按 key 最近邻余弦相似度分成 $[0,0.2)$、$[0.2,0.5)$、$[0.5,1]$ 三档，就能检查式 (14) 预测的冲突是否出现。平均分数会把距离衰减与方向冲突揉成一个数，无法指导状态维度或写入规则的改动。

对 mini-batch 大小也不能只报困惑度。以长度 4096 为例，$b=16$ 有 256 个串行块，$b=64$ 有 64 个，$b=4096$ 只剩 1 个。三者的理论主项可能接近，但 kernel 启动、矩阵形状和跨块状态依赖完全不同。应同时报告每秒 token、设备利用率和质量，并画出 Pareto 前沿。若 $b=16$ 质量最好却吞吐只有 $b=64$ 的一半，选择取决于服务延迟预算；不存在脱离硬件与应用约束的统一最佳块大小。

状态 checkpoint 也应接受恢复测试：处理前半段后序列化 $W_t$，迁移设备或进程，恢复后继续处理后半段；输出要与不中断执行在规定精度内一致。混合精度下若只保存 FP16 状态而原执行维护 FP32 累加，恢复误差会随剩余长度扩大。这个测试验证的是长任务真正需要的可恢复状态，而不仅是一次完整 benchmark 能跑完。

参数量也要分口径。论文表中的 125M 或 1.3B 通常指可训练慢参数，运行时每条序列持有的 fast weights 不会按普通模型参数重复计入，却会真实占用设备内存。比较 Transformer、Mamba 与 TTT 时应同时列出静态参数、单会话动态状态和批量服务总状态。只对齐静态参数可能让 TTT 获得更大的运行态容量；只对齐总字节又可能改变网络宽度。两种口径都值得报告，并说明主要结论在哪一种口径下仍成立。

## 和注意力的等价关系

**线性注意力与自注意力的等价关系.** 定理 1 取 $f(x) = Wx$, batch GD, $\eta = 1/2$, $W_0 = 0$. 对同样的输入序列, 式 (3) 的输出与线性注意力相同. 证明只有两步. 由式 (2), $\nabla \ell(W_0; x_t) = -2(\theta_V x_t)(\theta_K x_t)^\top$ ($W_0 = 0$ 时第一项消失). 代入 batch GD 的式 (6):

$$
W_t = W_0 - \eta \sum_{s=1}^{t} \nabla \ell(W_0; x_s) = \sum_{s=1}^{t} (\theta_V x_s)(\theta_K x_s)^\top
\tag{19}
$$

代入式 (3):

$$
z_t = \sum_{s=1}^{t} (\theta_V x_s)(\theta_K x_s)^\top (\theta_Q x_t)
\tag{20}
$$

式 (20) 就是不带 softmax 的注意力 $z_t = \sum_s v_s k_s^\top q_t$, 即 [Katharopoulos 等 (2020)](https://arxiv.org/abs/2006.16236) 线性注意力的最简形式 (原式还有一个归一化分母和特征映射, 论文和前人都发现这两项会伤效果, 所以只对最简形式建立等价). **定理 2.** 把参数模型换成非参数的 Nadaraya-Watson 核回归:

$$
f(x; x_1, \dots, x_t) = \frac{\sum_{s=1}^{t} \kappa(x, x_s)\, y_s}{\sum_{s=1}^{t} \kappa(x, x_s)}, \qquad \kappa(x, x') \propto e^{(\theta_K x)^\top \theta_Q x'}
\tag{21}
$$

$y_s = \theta_V x_s$ 是标签视图. 代入式 (3) 就是 softmax 自注意力. 这种 learner 没有参数 $W$, 状态是训练数据本身的列表, 更新规则是追加, 输出规则是用核扫描列表, 和本文开头那张表里自注意力一行一致. 两个定理把三种层放在一条轴上: 线性模型 + batch GD 是线性注意力; 线性模型 + 在线 GD 是 DeltaNet; 线性模型 + mini-batch GD + LN 与残差是 TTT-Linear; 非参数核回归是自注意力. 论文借此定义了更一般的 learner 抽象 (实现 train 和 predict 两个方法), 状态也可以包括优化器状态, 例如 Adam 的动量. **从线性注意力一步步改到 TTT-Linear.** 论文 Table 1 在 125M 规模上从线性注意力出发, 每行加一个改动 (困惑度):

| 配置 | 困惑度 | 变化 |
| --- | --- | --- |
| 线性注意力 (原式) | 15.91 | |
| 线性注意力 (改进版) | 15.23 | $-0.68$ |
| TTT 等价实现 | 15.23 | 0 |
| + 可学习 $W_0$ | 15.27 | $+0.04$ |
| + $f$ 内 LN 与残差 | 14.05 | $-1.22$ |
| + mini-batch TTT | 12.35 | $-1.70$ |
| + 可学习 $\eta$ | 11.99 | $-0.36$ |
| + Mamba backbone | 11.09 | $-0.90$ |

前三行是对照. 「TTT 等价实现」与改进版线性注意力完全一样, 验证了定理 1. 可学习 $W_0$ 略伤困惑度, 但论文报告不加它下面几行都训不稳. 第四行加的是 LN 与残差: $f(x) = x + \text{LN}(f_{\text{res}}(x))$. 这一改动让 $f$ 本身不再是线性的, 即使 $f_{\text{res}}$ 是线性的, 内循环的梯度也不再是简单的外积, 式 (5) 的 delta rule 形式不再精确成立.

mini-batch TTT 从 $b = T = 2048$ (batch GD, 即线性注意力) 改到 $b = 16$, 贡献最大. 前面手算里看到的块内无擦除, 块间有覆盖, 这个差别在语言建模上值 1.7 个困惑度. 可学习 $\eta$ 写成 $\eta(x) = \eta_{\text{base}}\, \sigma(\theta_{\text{lr}} \cdot x)$, $\sigma$ 是 sigmoid, $\eta_{\text{base}}$ 在 TTT-Linear 取 1, TTT-MLP 取 0.1; 学习率随 token 变化, 也可以看成对梯度的门控. 表格末行换成 Mamba backbone: Mamba 和 Griffin 的 backbone 在序列层之前有时间卷积, 能收集局部信息, 换上它之后又降 0.9. 论文指出, 最大的两项 (mini-batch 和 LN 加残差) 都是从 TTT 的视角自然想到的, 从线性注意力的视角不容易想到. 这几步改完, 内模型 $f$ 有两个取法. TTT-Linear: $f_{\text{lin}}(x) = Wx$, $W$ 为方阵. TTT-MLP: $f_{\text{MLP}}$ 是两层 MLP, 隐层维度是输入的 4 倍, 激活 GELU. 两者外面都套 $x + \text{LN}(\cdot)$. TTT-MLP 的状态更大, 表达力更强, 每个 token 的计算也更多.

### 实验: 规模, 数据和上下文长度

**协议.** 对照 Transformer (Llama 结构) 和 Mamba, 严格沿用 Mamba 论文的评测协议. 四个规模 125M, 350M, 760M, 1.3B (Mamba 对应 130M, 370M, 790M, 1.4B). 全部按 Mamba 论文复现的 Chinchilla 配方训练. 分词器统一用 Llama 的. 不做混合架构. 数据有两套. [Pile](https://arxiv.org/abs/2101.00027) 上做 2k 和 8k 两种上下文, 这是标准的短上下文实验; Pile 里长于 8k 的序列很少, 所以长上下文实验改用其子集 Books3, 上下文从 1k 到 32k 每次翻倍. 每个训练批固定 0.5M token, 上下文为 $T$ 时每批 $0.5\text{M}/T$ 条序列. **Pile: 短上下文.**

- 2k: TTT-Linear (Mamba backbone), Mamba, Transformer 三者曲线基本重合. TTT-MLP 在大 FLOPs 预算下略差: 它在每个规模上的困惑度都比 TTT-Linear 好, 但额外的 FLOPs 抵消了优势.
- 8k: TTT-Linear 和 TTT-MLP (Mamba backbone) 都明显好于 Mamba. 即使 Transformer backbone 的 TTT-MLP 在 1.3B 附近也略好于 Mamba. Transformer 在每个规模上困惑度都不差, 但 FLOPs 太高, 在 FLOPs 对困惑度的图上没有竞争力.

论文把这条规律概括为: 上下文越长, TTT 相对 Mamba 的优势越大. **Books: 长上下文.**

- 2k: 结论与 Pile 2k 基本相同, 只是这里 Mamba 略好于 TTT-Linear.
- 32k: TTT-Linear 和 TTT-MLP (Mamba backbone) 都好于 Mamba, Transformer backbone 的 TTT-MLP 也略好于 Mamba.
- backbone 的作用: Mamba backbone 下 TTT-MLP 最多与 TTT-Linear 持平; Transformer backbone 下 TTT-MLP 明显更好. 论文的假设是时间卷积对表达力弱的状态帮助更大, 线性模型比 MLP 弱, 所以从卷积中受益更多. 1.3B 上 Transformer backbone 的 TTT-MLP 只比 Mamba backbone 略差, 论文据此推测更大模型, 更长上下文时 Transformer backbone 可能更合适, 但没有实验证实.

真实场景里, 长上下文 Transformer 通常先在短上下文训练, 再在长上下文微调. 论文为此加了 TF finetune 基线: 从 Books 2k 的模型出发, 再用 20% 的 token 在目标长度微调. 图 2 右侧的 Transformer 就是这个更强的基线; 该图里所有方法的训练 FLOPs 与 Mamba 1.4B 对齐. 在匹配 FLOPs 的条件下, TTT-MLP 在短上下文比 TTT-Linear 差, 在长上下文更好, 符合「状态更大的模型在长上下文里才用得上它的容量」的预期. 论文没有得到干净的 Scaling Laws 直线拟合, 连 Transformer 也没有, 所以图中只把点连起来, 没有做回归. 这意味着这些结论只在实验覆盖的 FLOPs 区间内成立, 不能外推. **墙钟时间.**

TPU v5e-256 上, 2k 上下文训练一步, Transformer 0.30 秒, TTT-Linear 0.27 秒, 没有系统优化就快了 10%. Mamba 的实现只能跑在 GPU 上, 论文为公平比较另写了 GPU 推理 kernel (只写了推理, 训练 kernel 工作量大且 TPU 用不上). A100 上 1.3B 模型的测量 (图 12): Transformer 每 token 的时间随上下文线性增长, TTT 和 Mamba 大致恒定. Transformer 基线用的是 vLLM, 比 Mamba 论文里用 HuggingFace 实现的基线快得多. TTT-MLP 在 FLOPs 上划算 (图 2), 但 MLP 结构让墙钟时间的增长比 FLOPs 快得多 (图 12). 论文把内存 I/O 列为 TTT-MLP 的主要挑战, 并承认即使用了 mini-batch 和 dual form, 这个框架的实例化仍可能需要可观的墙钟时间.

### 来历, 旁支与限制

**fast weights 的来历.** 把一部分权重放到推理阶段, 按当前输入快速更新, 这个想法比 TTT layer 早得多. fast weights 指只在最相关的数据 (通常就是当前输入) 上更新的权重, 与在全部数据上训练的 slow weights 相对, 1980 年代就有. [Hinton & Plaut (1987)](https://www.cs.toronto.edu/~hinton/absps/fastweights87.pdf) 给每个连接配两份权重, 一份变化慢, 存长期知识; 一份变化快并向零衰减, 存最近学到的东西, 用来在学新任务后快速恢复被干扰的旧记忆. [Ba, Hinton, Mnih, Leibo & Ionescu (2016)](https://arxiv.org/abs/1610.06258) 把 fast weights 接进 RNN, 用来关注最近的过去. 每一步用隐状态 $h_t$ 的外积更新一个 fast weight 矩阵 $A_t$:

$$
A_t = \lambda A_{t-1} + \eta\, h_t h_t^\top
\tag{22}
$$

$\lambda < 1$ 是衰减率, $\eta$ 是写入强度. 读出时用 $A_t$ 乘当前的中间隐状态, 迭代几步, 相当于从最近存过的隐状态里取出与当前相似的那些. 式 (22) 与 5.3 里 Mamba-2 的「衰减后加外积」是同一种写入, 区别在 key 和 value 都是 $h_t$ 本身 (自联想), 衰减是固定常数, 没有擦除.

[Schmidhuber (1992)](https://doi.org/10.1162/neco.1992.4.1.131) 提出 fast weight programmer: 一个 slow 网络在每一步生成对 fast 网络权重的修改, fast 网络作为可写的记忆. [Schlag, Irie & Schmidhuber (2021)](https://arxiv.org/abs/2102.11174) 证明线性注意力在数学上就是一种 fast weight programmer, 状态矩阵就是 fast weights, 外积累加就是写入规则; 他们同时指出纯外积累加的容量问题, 引入了 delta rule 的写入方式. 这一支后来发展成 DeltaNet 及其并行化 ([Yang 等, 2024](https://arxiv.org/abs/2406.06484)).

按这个谱系, TTT layer 里内循环的 $W$ 是 fast weights, 外循环的 $\theta$ 是 slow weights, 带 TTT layer 的网络是 fast weight programmer 的一个特例. TTT 视角多出来的东西有两点: 写入规则被明确写成一个学习问题 (有损失, 有优化器, 测试输入就是泛化目标), 以及由此可以换任意模型和优化器. 论文也注明, 把 fast weights 做成 MLP 在 Irie 等人的工作里已经出现过, 早于 TTT-MLP; [Clark 等 (2022)](https://arxiv.org/abs/2212.02475) 给 Transformer 的输出端加了一层 fast weights, 其初始化作为 slow weights 训练; 后来的 TTT-E2E 论文说自己与这篇的高层思路相同. 论文对自己贡献的定位是: 一个可以把任意神经网络实例化为隐状态的实用框架. 它承认线性 (矩阵) 隐状态的路线在 DeltaNet 之后又有 Mamba 2 和 Gated DeltaNet 的推进, 这些在 [5.3](../5.3-与attention-SSM-RWKV-Titans的边界/5.3-与attention-SSM-RWKV-Titans的边界.md) 里统一对照. **推理阶段学习的另几条老路.**

TTT layer 的论文把自己放在更长的历史里. 在测试输入上做学习, 最早的版本之一是 Bottou 和 Vapnik 1992 年的 local learning: 对每个测试输入, 先在它的近邻训练样本上训练, 再做预测. 另一条是 Vapnik 的直推学习 (transductive learning), 原则是「只求你真正需要的那个答案, 不求更一般的」, 具体实现是用测试样本给 SVM 的间隔加约束; 它通常要很多个测试样本一起才有效, TTT 则只需要一个测试实例 (一张图, 一段视频, 一条序列).

语言模型里最接近的做法是动态评估 (dynamic evaluation, [Krause 等, 2018](https://arxiv.org/abs/1709.07432)): 直接在测试序列上微调语言模型, 读到哪里就用已经读过的部分更新参数. 它和 TTT layer 的差别在两点. 第一, 动态评估更新的是整个模型 (或其中一部分) 的普通参数, 用的是下一个 token 预测损失; TTT layer 更新的是专门设计的内层状态 $W$, 用的是可学习的重建损失. 第二, 动态评估的模型在训练阶段并不知道自己推理时会被更新, 训练目标和推理时的实际行为不一致; TTT layer 在外循环里就包含了内循环, 训练和推理时的计算完全相同. 第二点在 5.2 的 TTT-E2E 里被进一步推到整个网络上.

在视觉里, 4.1 的 Sun 2020 是 TTT 这个名字的来源. 那篇里自监督任务 (旋转预测) 是人定的; TTT layer 的论文认为自己与那条线最大的概念差别, 就是重建任务的视图 $\theta_K, \theta_V, \theta_Q$ 由外循环学出来. 视频流上的自回归 TTT (在过去的帧上训练, 再处理当前帧) 是论文点名最相关的前作, 因为它和序列建模一样, 状态从前往后传. **状态容量, 块大小与墙钟时间的限制.**

**状态容量.** TTT layer 的状态大小固定, 和所有 RNN 一样无法精确回忆任意历史 token. 论文的主要指标是困惑度, 衡量的是平均预测质量, 不直接衡量 needle-in-a-haystack 一类精确检索. 精确检索是固定状态模型的普遍弱项, 5.2 的 TTT-E2E 会给出这方面的数据.

**块大小的两难.** $b$ 小, 梯度步多, 效果好, 但并行度低, 硬件利用率低; $b$ 大, 并行度高, 但块内退化成线性注意力. $b = 16$ 是这篇论文在这个两难上取的点. [5.2](../5.2-LaCT与TTT-E2E/5.2-LaCT与TTT-E2E.md) 的 LaCT 反过来把 $b$ 取到几千甚至上百万, 用块内的窗口注意力补回局部依赖. **墙钟时间.** dual form 降低了 TTT-Linear 的开销, 但 TTT-MLP 的 I/O 仍是瓶颈. 训练要对梯度求梯度, 比普通前向反向贵. **对 backbone 的依赖.** 最好的结果用的是带时间卷积的 Mamba backbone. 换成 Transformer backbone, TTT-Linear 的困惑度变差. 结论里有一部分收益来自 backbone, 不全来自 TTT layer 本身. **规模和外推.** 最大 1.3B, 最长 32k, 没有干净的 Scaling Laws 拟合. 这些数字支持「在这个区间内 TTT 比 Mamba 更会用长上下文」, 不支持对更大规模的预测. **与第 4 章的区别.** 这里的「推理阶段更新」每条序列从 $W_0$ 开始, 序列结束丢弃, 不存在第 4 章那种跨样本的误差积累和遗忘. 代价是它也不会跨序列积累任何东西, 这一点到 5.2 的 TTT-E2E 依然成立.

## 内循环目标究竟写入什么

**键值重建不是普通辅助任务.** TTT layer 在序列内部接收 token 表示 $x_t$，通过外循环学到的投影得到 $k_t,v_t,q_t$. 快速模型 $f_{W}$ 先用 $(k_t,v_t)$ 产生自监督误差，再由更新后的 $W_t$ 回答 $q_t$. 训练信号不来自人工标签，而来自同一 token 的两个视角. 外循环必须学会让「能从键预测值」同时意味着「未来查询能从状态读到有用信息」.

若 $k_t$ 和 $v_t$ 取同一表示，内循环退化成自编码；若值携带未来任务需要的信息而键可由查询匹配，状态才像可寻址记忆. 投影矩阵决定写入地址、写入内容和读取请求，远比内循环 loss 的名称更重要. 固定随机投影与可学习投影的消融能测外循环是否真正组织了记忆空间. **因果次序与信息泄漏.**

当前 token 既能生成训练对，又要产生输出. 若先用包含目标信息的 $v_t$ 更新，再预测同一位置，模型可能获得不符合因果语言建模的信息. 合法设计要让内循环目标只使用当前及过去可见量，或让本次写入服务后续位置. 论文公式里的索引、shift 和块边界必须与实现一致. 可用一个反例检查：将未来 token 随机打乱，但保持当前输入不变. 若当前位置预测仍受未来 $v$ 影响，说明计算图泄漏. 训练 loss 极低、生成时性能骤降也常是读写次序错误的信号. **代理目标和 next-token 目标.**

键值重建容易并行和局部计算，却与语言模型损失存在间接关系. 它可能学会恢复表面特征，而没有保留实体、顺序或可推理关系. 外循环通过最终 next-token loss 调整投影与初始化，使局部重建变成有用写入；这条元梯度是目标对齐的关键.

如果停止外循环穿过内循环，只训练重建头，快速权重可能把重建做得很好，语言模型却没有收益. 可以比较截断元梯度、只训练投影、只训练初始化和完整端到端版本，判断性能来自普通额外层还是「学会如何学习」. **多种损失对应不同记忆.**

平方误差对应欧氏空间中的条件均值；交叉熵适合离散 token；对比损失强调区分；masked reconstruction 强调局部结构. 损失决定哪些信息被压入状态，也决定干扰几何. 一个模型在困惑度上好，不一定在精确复制、needle 检索或键值绑定上好. 可以让相同快速模型分别使用重建、对比和 next-token 目标，匹配更新次数与参数量，测语言损失、检索和状态稳定性. 若某目标只在一种指标占优，结论应限定到相应记忆语义.

### 快速权重的初始化与学习率

**初始状态也是模型知识.** $W_0$ 并非一定为零. 外循环学习 $W_0$，相当于为每条序列提供共享先验. 序列内更新在先验附近写入上下文. 若 $W_0$ 已能预测常见关联，梯度只记录偏离先验的部分；若初始化差，早期 token 要先修正模型本身. 比较零初始化、随机固定、普通训练得到和端到端元学习的 $W_0$，可以拆出先验贡献. 只报告完整模型无法知道收益来自更强静态参数还是序列内学习. **可学习学习率是写门.** 学习率可以是全局标量、按层、按通道、按 token 或由输入生成. 它既控制优化稳定，也充当数据依赖写门. $\eta_t\approx0$ 表示跳过当前 token，较大值表示强写入. 若学习率网络只看当前 token，它可学习标点、停用词少写，实体或惊讶 token 多写. 这种解释需用相关性与干预验证：固定内容打乱 $\eta_t$，观察检索和语言 loss 是否下降；仅画学习率热图不足以证明门控语义.

可学习 $\eta$ 必须受到稳定约束. 对线性单键，安全范围与 $\lVert k\rVert$ 相关；可以输出 sigmoid 门再除以键范数，或裁剪有效步长. 若训练长度短，外循环可能学到在短序列有效、长序列逐渐爆炸的学习率. **动量和优化器状态.** SGD 快速权重只保存 $W$；加入动量还要保存速度 $m_t$，Adam 还需二阶矩. 状态容量与更新成本随之增加. 动量能累积一致梯度，也会让错误写入留下更长尾巴. Titans 等方法将动量视为长期记忆机制的一部分. 比较时要把 optimizer state 算入状态大小，不能只数快速模型参数. 序列复位也要清除动量，否则历史跨序列泄漏. **元学习学习率与初始化.** 外循环目标是整条序列语言 loss $L_{outer}(W_T,\psi)$，其中 $W_t$ 由内循环递推. 对初始化的梯度包含所有更新 Jacobian 的乘积：

$$
\frac{\partial L_{outer}}{\partial W_0}
=\frac{\partial L_{outer}}{\partial W_T}
\prod_{t=1}^{T}\frac{\partial W_t}{\partial W_{t-1}}.
\tag{23}
$$

这和训练 RNN 的 BPTT 相似，可能梯度消失或爆炸. 内循环含梯度算子时，$\partial W_t/\partial W_{t-1}$ 又包含 Hessian，完整外循环需要二阶信息. 截断、first-order 近似和重计算在内存与精度间取舍.

### 复杂度、并行性与状态生命周期

**理论复杂度和墙钟.** 全 attention 每层计算随 $T^2$ 增长，KV cache 随 $T$ 增长；递推与 TTT 状态大小固定，逐 token 计算近似线性. 但 TTT 内循环包含前向、反向和权重写入，常数大、串行依赖强. 短上下文上全 attention 的高并行可能更快. 速度曲线应覆盖多个长度，报告训练与解码、prefill 与逐 token、吞吐与延迟. 只报某个交叉点不能代表全部工作负载. 编译、kernel 与硬件代际也会移动交叉点. **状态带宽与 kernel 利用.** 快速权重每块要读写，状态大时显存带宽成为瓶颈. 小块频繁启动 kernel，FLOPs 利用低；大块提高 GEMM 效率. dual form、fused kernel 和 LaCT 都在改变计算排布，算法与系统共同决定结果. 报告状态驻留层级、是否跨设备通信、块间同步与精度. 多 GPU 张量并行下，快速权重分片更新可能需要额外 collective，单卡速度不能直接外推. **序列复位语义.** 独立文档、batch 样本和用户会话各自需要状态边界. EOS 后是否复位、拼接语料的 document mask、生成中断后状态怎样恢复，都会改变信息传播. 不复位可能降低连续语料 loss，却造成样本泄漏.

状态快照用于生成续跑时，要和 token 位置、模型版本及随机状态绑定. 加载错误会话的 fast weights 比加载错误 KV cache 更隐蔽，因为它仍是合法参数 shape，却包含别人的上下文. **与部署 TTA 的严格边界.** 本节快速权重服务单序列预测，序列结束复位；第 4 章 TENT、CoTTA 等让部署模型状态跨样本或请求延续，用来适应分布偏移. 两者都在推理时更新，监督目标、状态所有者与风险范围不同. 若 TTT layer 状态被跨会话保留，它就进入 continual TTA 的污染、遗忘、权限和回滚问题；若 TENT 每个样本完整复位，它更接近 episodic 内循环，但目标仍是分布适应. 方法归类应依据实际生命周期，不能只看名称. **完整验收.** 结果至少包括语言 loss、精确检索、状态大小、训练与推理计算、长序列稳定、块边界敏感和因果干预. 外循环消融包含初始化、学习率、二阶梯度和更新层位；内循环消融包含损失、步数、块大小与优化器.

公式实现通过小矩阵手算、因果前缀测试和 dual/逐步版本对齐. 重复标题、公式编号和裸 LaTeX 命令在构建前扫描. 只有算法语义与系统实现都核对，速度和能力结论才可复算.

## 更细的优化动力学

**多步更新与闭式解.** 对同一组键值反复做线性最小二乘，若学习率满足稳定条件，$W$ 会趋向使 $WK\approx V$ 的解. 在满秩且无正则时，最小范数解可写为 $W^*=VK^+$，其中 $K^+$ 是伪逆. TTT 的有限步在线梯度没有直接求解伪逆，而是用数据顺序与步数形成隐式正则.

键矩阵条件数大时，沿大奇异值方向快速收敛，小奇异值方向学习慢；相似键对应的冲突值会让解敏感. 这解释了键归一化仍不能解决全部干扰，方向相关比单个范数更重要. 监控块内 $K^\top K$ 的谱与检索误差，可以判断失败是否来自病态地址空间. 加入权重衰减相当于不断忘记旧状态. 单步近似为 $W_t=(1-\eta\lambda)W_{t-1}-\eta g_t$，较早写入按时间指数衰减. 它能防止范数增长，也会让远距离检索系统下降. 扫描衰减与距离曲线，区分数值稳定收益和长期记忆损失. **多 token batch 的精确梯度.** 块损失取平均

$$
L(W)=\frac{1}{2b}\lVert WK-V\rVert_F^2,\qquad
\nabla_WL=\frac1b(WK-V)K^\top.
\tag{24}
$$

一次 batch GD 只得到块末共同状态，prefix 输出还需要每个位置之前的梯度和. 下三角 mask 把 token 贡献限制到因果前缀. 若学习率按 token 变化，可将其放入对角矩阵，再进行 masked 矩阵乘. batch GD 与逐 token SGD 的差异不仅来自梯度评估点. batch 平均还改变更新尺度与顺序，两个相反梯度可能在同一步抵消，而在线 SGD 会先移动再计算下一梯度. 对合成冲突键逐项手算，能验证实现对应哪种语义. **非线性快速模型的局部线性化.** 对 TTT-MLP，参数更新后的输出可在当前点一阶展开：

$$
f_{W-\eta g}(q)\approx f_W(q)-\eta J_W(q)g.
\tag{25}
$$

$J_W(q)$ 将参数梯度映射到 query 输出. 写入是否影响某个 query，由写入梯度与 query Jacobian 的对齐决定. 这推广了线性键内积：线性模型中干扰由 $k_i^\top k_j$ 控制，MLP 中由神经切线核 $J_W(q)J_W(k)^\top$ 控制. 外循环可以塑造这个核，让相关 token 共享更新、无关 token 尽量正交. MLP 容量优势来自可学习非线性相似度，也增加曲率和训练成本. 在初始化附近的短内循环，NTK 近似较好；长序列状态走远后，核本身改变，线性分析失效. **学习率门的信用分配.** 设 $\eta_t=\sigma(a_t)$，$a_t$ 由 token 表示产生. 外层梯度

$$
\frac{\partial L}{\partial a_t}
=\frac{\partial L}{\partial W_t}:(-g_t)\,sigma(a_t)(1-\sigma(a_t)).
\tag{26}
$$

它衡量「多写一点当前梯度」对未来 loss 的影响. sigmoid 饱和时门接近零或一，梯度也变小，早期决策可能固化. 初始化门在中间区域、加入熵或稀疏正则，会改变写入频率. 可将学习率门与 attention gate 比较. attention gate 控制当前读取多少历史，学习率门控制当前内容写多少进未来. 两者同时存在时可能冗余或互补. 交换、冻结或打乱门值能识别各自贡献. **梯度裁剪与归一化.** 快速梯度范数随 token 难度变化. 全局裁剪将极端写入限制到阈值，防止单 token 破坏状态，也会削弱真正重要的惊讶事件. 按层、按矩阵行或按 token 归一化对应不同写入几何. Muon、Adam、SGD 与 normalized gradient 的状态和不变性不同. 比较优化器时将动量、二阶矩计入 fast state，并对齐总 FLOPs. 一个优化器效果好可能来自更大状态容量，而非更聪明梯度.

### TTT-MLP 的曲率与局部稳定性

**从键内积推广到切线核.** 线性快速模型里，一个写入是否会影响另一个查询，最终落在两个键的内积上。TTT-MLP 把这个关系换成参数空间中的梯度对齐。设快速网络输出为 $f_W(x)$，在样本 $k$ 上的平方误差为 $\ell_k=\frac12\lVert f_W(k)-v\rVert^2$。对查询 $q$ 做一步更新后，一阶展开得到

$$
f_{W-\eta\nabla\ell_k}(q)-f_W(q)
\approx-\eta J_W(q)J_W(k)^\top[f_W(k)-v].
\tag{27}
$$

其中 $J_W(x)$ 是输出对快速参数的 Jacobian，$J_W(q)J_W(k)^\top$ 是由当前快速网络定义的切线核。线性模型的 $q^\top k$ 只是它的特例。这个式子给出了 TTT-MLP 容量增加的具体来源：模型不再只能沿固定输入坐标判断相似性，而能用慢参数塑造一套数据依赖的局部度量。两个表面相似的 token 可以在 Jacobian 空间分开，两个字面不同但承担相同语义角色的 token 也可以共享更新。

这种自由度并非白送。Jacobian 随 $W$ 改变，写入越多，后续 token 看到的核越偏离序列起点。短内循环可以用固定核近似，长内循环则同时改变「记忆内容」和「寻址规则」。若模型先写入一个事实，后续更新不仅可能覆盖事实对应的输出，还可能改变查询该事实所走的方向。线性分析只会看到值发生漂移，非线性网络还存在地址本身漂移。

一个直接的诊断是，在若干时间点冻结状态，计算同一组探针 token 的 Jacobian Gram 矩阵。若输出尚未明显恶化，而 Gram 矩阵的主子空间已经快速旋转，说明模型正在消耗寻址稳定性；若 Gram 基本不变但旧关联丢失，问题更接近线性干扰。这里不需要把完整 Jacobian 显式存下，可以用 Jacobian-vector product 估计谱和子空间夹角。 **二阶余项决定一步近似能走多远.**

式 (27) 省略了关于参数位移的二阶余项。若在更新路径附近，输出 Hessian 的算子范数不超过 $M$，梯度范数为 $G$，则一步线性化误差可由 $\frac12M\eta^2G^2$ 控制。这个界虽然粗，却说明三个容易混在一起的因素：学习率变大会以平方速度放大近似误差，异常 token 的大梯度同样危险，MLP 激活区间中的高曲率会让相同更新在不同位置表现不同。

残差连接在这里有明确作用。若快速网络写成 $f_W(x)=x+r_W(x)$，即使残差分支的局部核发生漂移，恒等通道仍保留当前 token 的基础表示。LayerNorm 则限制进入残差分支的尺度，使学习率不必同时适应跨数量级的激活范数。不过 LayerNorm 的 Jacobian 会耦合通道，误差驱动的写入不再是简单秩一外积；把 TTT-Linear 的稳定区间原样搬到带归一化的 TTT-MLP 上并不成立。

ReLU 类分段线性网络还有一种特殊边界：只要更新没有让激活越过分段边界，输出关于参数的局部模型较稳定；一旦大量神经元翻转开关，切线核会突然变化。GELU 没有硬边界，但在高曲率区仍会出现类似的快速旋转。可以记录连续更新之间激活符号翻转率、Jacobian 余弦相似度和实际输出变化相对一阶预测的误差。三条曲线一起看，才能分清是优化步过大，还是快速网络真的在利用非线性重组记忆。 **多步更新的收缩条件.**

把一次快速更新记作映射 $F_t(W)=W-\eta_t\nabla\ell_t(W)$。它对状态的 Jacobian 为 $I-\eta_tH_t$。若局部 Hessian 为半正定，最大特征值为 $L_t$，并且 $0<\eta_t<2/L_t$，单步在有曲率的方向上不会放大扰动；无曲率方向仍原样保留。不同 token 的 Hessian 一般不对易，多步稳定性取决于这些 Jacobian 的乘积，不能只逐步检查谱半径。某一步略有放大，后续可能收回；多个方向轮流放大，也可能在每一步单独看似安全时积累出很大的非正规增长。

因此，更可靠的长序列诊断还要估计从 $W_s$ 到 $W_t$ 的切向传播增益，单独画 $\lVert W_t\rVert$ 不够。随机向量经过连续 Jacobian-vector product 后的范数，可以近似揭示状态扰动会消失还是爆炸。这个量也连接外循环信用：前向状态扰动衰减得很快，远处写入难以影响当前输出；反向乘积爆炸，则早期 token 的元梯度会被少数方向主导。快速状态的记忆长度与外循环可训练长度由同一串 Jacobian 的不同方向共同决定。

### 状态容量的可计算边界

**秩、有效秩与可分离关联.** 对线性快速矩阵 $W\in\mathbb{R}^{d_v\times d_k}$，写入 $n$ 个键值对相当于寻找满足 $WK\approx V$ 的映射。若要求对任意值矩阵都精确恢复，键矩阵 $K$ 至少要有列满秩，因此 $n\le d_k$。这不是说矩阵只能存 $d_k$ 个 token：当值之间共享结构、允许误差或只查询少数方向时，可以压缩更多；它说的是任意独立关联的最坏情况上界。把 $d_vd_k$ 个参数直接解释成同样数量的独立事实，会忽略一次查询只通过 $d_k$ 维地址进入矩阵。

真实键很少正交。令归一化键的 Gram 矩阵为 $G=K^\top K$，其有效秩可以写成 $r_{eff}=(\operatorname{tr}G)^2/\operatorname{tr}(G^2)$。键全部正交时它接近键数；大量键聚成相似方向时，它会远小于键数。有效秩给出的不是严格事实容量，却比参数量更贴近当前序列真正使用了多少独立地址方向。配合 $G$ 的最小非零奇异值，可以区分「地址维度不够」和「地址虽然够，却病态到无法稳定分离」。

若存在两个归一化键满足 $|k_i^\top k_j|\le\mu$，$\mu$ 是字典的互相干系数。$\mu$ 越大，写一个键对其他键的最大直接扰动越强。Welch bound 又说明，当键数超过维度时，最大相关性不可能一直压到零。外循环可以把常见语义安排到更合适的位置，却无法在固定维度中为无限关联创造两两正交的地址。这条几何限制解释了为什么长度增加后，精确随机绑定通常比语言困惑度更早恶化。 **值结构决定干扰是泛化还是覆盖.**

只看键相关还不够。若相似键对应相似值，一次共享更新可能同时降低两处误差；若对应相反值，同样的键相关就形成冲突。可把值矩阵在键 Gram 特征向量上的投影分解开：集中在大特征值方向的平滑部分容易由低秩映射表示，落在小特征值方向的高频差异需要很大的权重才能分开，对噪声和低精度也更敏感。

这给合成实验提供了比「随机 needle 越多越难」更细的控制轴。固定键集合，分别让值随键空间平滑变化、完全随机、或专门沿 Gram 的小特征值方向变化；再比较写入误差、权重范数和远距读取。若模型只在第三种设置失败，瓶颈是条件数；三种都随 token 数同步下降，则可能是学习率、数值累计或门控没有跳过无关写入。

TTT-MLP 能通过非线性特征提高有效秩，也可能只是把冲突推到更高维参数空间。衡量它时，应在相同 fast-state 字节下比较，而非只匹配隐藏宽度。一个两层 MLP 的参数状态、梯度状态和优化器状态往往远大于单矩阵；若增加的可分离关联与状态字节近似同比增长，收益主要来自容量扩张。只有单位状态容量明显提高，才能说明非线性寻址本身带来了更强压缩。 **有限精度把几何上限提前.**

即使数学上可逆，病态键矩阵在 BF16 中也可能无法区分。若两个读出结果的间隔小于累计舍入误差和后续层噪声，模型在实际计算中已经失去这对关联。状态反复原地更新还会产生吸收效应：小更新相对大权重低于可表示精度时，写入在数值上直接消失；大更新虽能写入，又会粗暴改变旧方向。

可以把快速权重保留为 FP32、矩阵乘使用 BF16，与全 BF16 状态做对照。若前者主要改善长距离尾部而短距离相同，数值累积确实在提前消耗容量。随机舍入可减轻系统性偏差，却增加方差；周期性重定标能扩大有效动态范围，却必须同步调整读出，否则改变函数。这里的精度不是单纯工程选项，它直接决定状态能区分多少细小方向。

### 优化器本身也是快速状态

**动量改变记忆核.** 使用动量时，内循环不再只有 $W_t$：

$$
m_t=\beta m_{t-1}+(1-\beta)g_t,\qquad
W_t=W_{t-1}-\eta m_t.
\tag{28}
$$

展开可见，过去梯度以 $\beta^{t-s}$ 的权重继续影响当前更新。SGD 对一个 token 的作用主要通过写入后的 $W$ 留下，动量还让该 token 的梯度在未来重复施力。方向一致的多次证据会累积，孤立噪声也会拖出指数尾巴。于是 $\beta$ 同时决定优化平滑和第二条时间尺度：接近一时能整合更长证据，也使错误写入更难立即纠正。

把动量称为额外记忆不能停在比喻。清空 $W$ 而保留 $m$，下一步会重新把历史方向写回；保留 $W$ 而清空 $m$，当前读出不变，未来轨迹却改变。分别进行这两个干预，可以测出内容究竟存在哪个状态分量。若评测只快照 $W$，恢复生成后会与原轨迹分叉，说明检查点语义不完整。 **Adam 的坐标自适应与不变性.** Adam 再增加二阶矩 $v_t$，更新近似为

$$
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2,\qquad
W_t=W_{t-1}-\eta\frac{m_t}{\sqrt{v_t}+\epsilon}.
\tag{29}
$$

$v_t$ 记录各坐标近期梯度尺度，使频繁出现的大梯度方向被归一化，稀有方向获得相对更大的步长。对长上下文而言，这可能保护常见语法方向不被每个 token 反复改写，同时让稀有实体留下足够痕迹；也可能把一次异常小方差方向过度放大。$\epsilon$ 在快速状态里会实际改变记忆动力学，并非只为避免除零。

Adam 对梯度逐坐标缩放较不敏感，却依赖参数化坐标。旋转快速参数空间后，SGD 的欧氏更新保持等价，Adam 的逐坐标二阶矩一般不会。若外循环能自由旋转表示，它可能反过来为优化器寻找有利坐标系。此时「键空间学到了什么」与「优化器偏好什么坐标」纠缠在一起，需要用旋转或白化消融判断收益来自语义寻址还是坐标预条件。 **状态预算下的公平比较.**

对 $P$ 个快速参数，SGD 需要约 $P$ 个状态标量；带动量需要 $2P$；Adam 若保存权重、一阶矩和二阶矩则接近 $3P$。在固定显存下，Adam 版本可能只能使用更窄的快速网络。反过来，若固定网络宽度，Adam 天然拥有更大的动态状态。两种比较回答不同问题：等模型结构看优化规则能否提升效果，等总状态看每字节能保存多少可用历史。

优化器状态的复位也要与文档边界一致。只清空 $W$ 而保留矩，会把上一文档的更新倾向带入下一文档；只清空矩而保留 $W$，则保留内容却丢掉其后续演化速度。训练中若拼接文档而未同步复位三者，较低 loss 可能来自跨样本泄漏。把复位位置随机移动，再检查性能变化，可以识别模型是否把文档分隔符当成真正的状态边界。

### 与递推序列模型的机制坐标

**SSM 与 RWKV：更新规则由前向网络直接给出.** 选择性 SSM 通常把状态写成 $h_t=A_t h_{t-1}+B_t x_t$，读出为 $y_t=C_t h_t$。RWKV 一类模型也用数据依赖衰减和加权累积构造固定状态。它们的写入系数由前向网络产生，不需要在 token 到来时计算某个内损失的梯度。TTT 则先定义预测任务，再让误差决定写入方向。两者都把历史压缩进固定状态，差别在「写什么」由门控公式直接决定，还是由当前状态犯下的错误决定。

这个区别会在重复信息上显现。误差驱动更新在已经预测正确时趋近零，天然避免重复写同一关联；普通加权累积仍会按门值加入新项，除非门控网络另外学会识别重复。反过来，SSM 的状态转移可被设计成易于并行扫描，TTT-MLP 的梯度更新包含随状态变化的非线性优化路径，更难获得同样的结合律。比较两者时，不能只列线性复杂度，还要看状态更新是否需要反向计算，以及并行化是否改变了原始递推语义。 **Titans：记忆损失、动量与遗忘门.**

Titans 同样把测试时可更新网络作为长期记忆，并把「惊讶度」与优化器状态放进写入机制。它与 TTT layers 的共同点是参数本身承担序列状态，更新来自自监督损失；差别落在模块组合、记忆目标、门控与持久性设计上。把二者简单归为「推理时训练」会漏掉最关键的状态方程：是否有显式衰减，动量如何参与，短期 attention 与长期参数记忆怎样分工，以及状态在哪个边界复位。

一个统一比较表应沿四项展开：状态载体、写入信号、遗忘算子和读出方式。TTT-Linear 的载体是矩阵参数，信号是重建梯度，遗忘主要来自误差修正和后续干扰，读出是快速模型前向；选择性 SSM 的载体是向量状态，信号由投影和门控生成，遗忘由 $A_t$ 显式控制，读出是线性或门控投影；Titans 的参数记忆还包含动量与可学习遗忘。坐标统一后，名称相似与否就不重要了，真正差别都能落回方程。 **显式 KV 与压缩状态的不可互换处.**

全 attention 保存每个 token 的 KV，查询时重新计算权重。只要缓存还在，两个极其相似的键仍保有独立槽位，softmax 可以借微小差异选择；固定状态方法必须在写入时决定怎样合并，后来查询无法恢复已经被压掉的区别。核心差异在于决策发生的时间：KV cache 把选择推迟到查询时，快速权重在看到 token 时就完成压缩。

## 训练、评测与可证伪证据

**从短序列到长度外推.** 训练长度决定外循环见过多少连续更新. 在 8K 上稳定不代表 128K 或百万 token 稳定. 长度外推同时考验状态范数、优化器矩、键碰撞、块边界累计和截断元梯度. 评测按几何级数扩展长度，记录 loss、needle、状态谱、更新范数和吞吐. 若 loss 平稳而状态范数持续增长，未来仍可能崩溃；若 needle 先下降而 loss 不变，精确记忆容量已经饱和. 使用重复同一段文本的压力测试可检测周期性漂移. 理想状态在第二遍可能因已记住而减少更新；若每遍仍持续增大范数，误差驱动写入没有收敛. 改变段落顺序再测，区分记忆与位置模式. **基线需要对齐什么.** 与 Transformer 比较时对齐参数、训练 token、数据、优化器和尽可能接近的训练 FLOPs；与线性 attention、Mamba、RWKV 比较时还要对齐状态字节和局部 attention. TTT 多出内循环反向，参数量相同不代表计算相同.

混合模型应与相同窗口 attention 加简单 recurrent state 比，而非只与纯 attention 比. 若窗口已经承担大多数语言建模，fast weights 的边际收益要通过关闭分支看到. 搜索预算也需对齐. TTT 有块大小、内循环学习率、更新层数和优化器等额外维度，更多调参本身能带来优势. 报告候选数、失败配置与选择数据. **状态利用的因果干预.**

在推理中保存某时刻状态，分别执行正常继续、清空、替换成另一序列状态、打乱参数行列和冻结更新. 正常与清空差衡量历史贡献，跨序列替换揭示内容特异性，打乱检验结构，冻结区分继续写入与已有记忆.

若替换另一序列状态几乎不影响输出，快速权重可能没有被读；若任何状态都同样改善，收益可能来自额外静态层. 若错误序列状态显著诱导相应答案，说明状态确实携带内容，也提示跨会话泄漏风险. 对单个 needle，可删除它的写入梯度，保持其余 token 不变. 查询性能随之下降，是比相关热图更直接的因果证据. 删除无关 token 梯度不应有同等影响. **外循环消融.** 冻结 $W_0$、冻结键值查询投影、停止二阶梯度、固定学习率、去掉快速模型残差，逐项测试. 每项对应一个主张：先验、地址学习、学会更新、写门与静态通道. 结果配合中间量，避免只看终点 loss. 停止二阶梯度后若性能不变，昂贵元学习路径可能没有实际贡献；固定学习率不降，token 门控解释就不成立；随机投影不降，外循环没有学到地址. 这些反例应直接收缩机制结论.

消融需匹配参数与计算. 去掉 TTT 分支后可增加等参数 MLP，去掉反向后可增加等 FLOPs 前向层. 这样才能区分训练式状态与普通容量. **检索评测的污染与捷径.** needle 内容应随机生成，避免预训练记忆；位置、格式和提示不能唯一暴露答案. 同一模板多次使用会让模型学会格式捷径. 随机化实体、值、查询措辞与插入位置，并保留程序验证. 模型可能从局部窗口看到 needle，必须确保距离超过窗口并关闭其他全局分支. 多 needle 任务要防答案恰好是最近一个的简单策略，随机查询任意早期键. 报告 exact match 之外的错误类型：返回最近值、相似键值、部分复制或格式失败. 它们对应衰减、碰撞、容量与解码问题，帮助定位 fast state 的限制. 失败运行与数值复现。 二阶训练、长序列重计算和自定义 kernel 容易 OOM、NaN 或编译失败. 失败配置不能从平均中静默删除. 记录长度、块、精度、硬件与首次异常位置.

小模型用逐 token 原始实现作为参考，dual/fused 版本在相同输入上比较输出、梯度和状态. 容差随精度预先规定. 速度实现若改变因果或 prefix 语义，即使 loss 接近也不算等价. 不同并行度改变归约次序和块划分，长轨迹会放大末位差异. 科学结论采用多 seed 统计复现，内核正确性采用短轨迹数值对齐，两种标准分开. fast weights 的边界与接受条件。 快速参数和慢参数。 慢参数 $\psi$ 跨数据与训练保存，快速参数 $W_t$ 在序列内变化. 训练 checkpoint 保存 $W_0$ 与生成更新规则的参数；推理快照若要续写，还要保存当前 $W_t$、优化器状态、块位置和本序列缓存. 把某序列末 $W_T$ 写回慢参数会改变算法，形成跨序列持续学习. 此时数据权限、遗忘和回滚问题进入系统. 本文的默认结论不覆盖这种部署. 与传统 fast weight 的关系。

早期 fast weight 方法也用外积、Hebbian 或可塑连接在序列内写状态. TTT 的特点是把写入明确表示为对自监督损失的优化，并让外循环端到端学习目标、初始化与步长. fast weights 是更大概念，TTT layer 是其中一类参数化. 线性 attention 可解释为无误差项的外积 fast weight；DeltaNet 加入误差修正；TTT-MLP 将记忆扩成非线性模型；Titans 再加入动量和遗忘. 这是一条写入规则谱系，不代表后者在所有任务单调更好. 何时 attention 仍不可替代。 需要逐 token 精确回看、可解释引用或任意键值分离时，显式 KV 有明显优势. 固定状态适合统计压缩、重复模式和容量允许的关联. 混合架构让 attention 处理精确近邻或稀疏全局，fast weights 处理压缩背景. 随着存储分层和稀疏检索发展，比较不能只在纯架构之间进行. 相同显存预算下，较小 KV cache 加 fast state 与全 fast state 哪个更好，是更实用的问题. 何时 SSM 或门控递推更合适。

SSM 和 RWKV 状态更新只需前向递推，没有内循环反向，延迟与实现更简单. 当任务主要需要平滑统计和有限时标，复杂 TTT 更新未必值得. TTT 的优势应出现在需要内容依赖纠错、更大非线性记忆或端到端学习写入的场景. 等状态、等 FLOPs、等局部窗口下比较，再用碰撞与检索反例观察差异. 只比较参数相近而忽略反向成本会高估 TTT 效率. 发布前验收条件。 算法层通过小矩阵手算、因果次序、梯度与 dual 对齐；能力层同时通过语言 loss、检索、冲突键与长度外推；系统层报告吞吐、延迟、显存、状态带宽和失败率；生命周期层保证文档与用户边界完整复位.

主张写成可证伪条件. 「学会写入」要求打乱投影或停止元梯度会降；「使用长上下文」要求清空状态与删除关键写入会降；「优于线性 attention」要求等状态和计算下在预定任务占优；「可扩展」要求更长序列中状态与性能保持稳定.

公式编号、标题与 LaTeX 在发布前机械扫描，参考文献置于文末. 这些格式检查无法证明理论正确，却能阻止转义错误、重复编号和渲染缺失破坏推导. 原始实验状态与逐长度结果一起保存，使新 kernel 或硬件上能重新验证.

还可以从在线回归的遗憾界理解 fast weights. 对每步平方损失，在线梯度下降相对固定最优 $W^*$ 的累积遗憾受梯度范数、可行域直径和学习率控制. 这类界说明更新不会无限落后于同一序列上的最佳固定线性映射，却没有保证 next-token 风险、精确检索或非平稳最优. 外循环学到的表示若让块内关系接近固定线性映射，理论条件才更贴近实际.

序列中的最优映射本身可能变化. 人物指代、主题和局部规则随章节切换，一份全局 $W$ 会平均互相冲突的阶段. 门控衰减、分块重置或混合多个 fast model 可处理分段平稳性. 代价是需要识别切换与路由，错误分段会提前忘记仍有用信息.

多记忆槽可以把状态写成 $W^{(1)},\ldots,W^{(m)}$，由路由权重选择更新和读出. 它缓解冲突，也让状态随槽数增长. 与增加矩阵维度相比，槽路由提供离散分工；与 attention 相比，每槽仍压缩多个 token. 比较等总字节下的单大状态和多槽状态，才能判断路由价值.

快速权重也可能记住训练提示中的恶意指令. 单序列内 prompt injection 若修改状态，后文即使不再包含攻击文本仍受影响. 序列结束复位阻止跨会话传播，却不能保护同一长会话. 对不可信文档设置只读段、降低写门或隔离记忆槽，是生命周期内部的权限控制.

可构造「可信查询—不可信文档—可信查询」序列，测攻击段前后输出与状态差. 删除攻击写入、冻结不可信段和普通全写三组对照，判断影响是否经 fast weights 传播. 如果窗口 attention 已足以携带攻击，还要将查询距离拉出窗口，隔离长期状态通道.

信息删除同样困难. KV cache 可按位置删除一项，压缩进矩阵或 MLP 后，单个 token 的贡献与其他更新混合. 若应用要求撤回某段上下文，最可靠方式是从删除点前的状态快照重放后续合法 token. 保存快照增加内存，重放增加延迟，这是压缩状态的系统代价.

可逆更新在特定线性条件下可能近似撤销，但后续梯度在被污染状态上计算，简单减去原外积无法恢复真实轨迹. 因此状态 provenance 仍重要：每个快照对应哪个 token prefix、模型版本和更新配置. 删除语义不能只靠参数差.

生成时 beam search 或多分支采样也改变状态管理. 每个候选分支需要自己的 fast weights，复制完整 MLP 状态成本高；共享状态则让一个分支的 token 污染其他分支. 可采用 copy-on-write、低秩增量或在分支阶段冻结更新. 推理吞吐比较若只用 greedy decoding，漏掉这一实际开销. speculative decoding 中，草稿 token 可能被验证模型拒绝. 若 fast weights 已根据被拒 token 更新，必须回滚到接受 prefix 的状态. KV cache 有明确截断位置，优化器式状态需要保存中间快照或可重放更新. 这再次说明 fast state 不只是矩阵大小，还带有事务成本.

连续批处理服务把不同长度序列动态拼接，每个 batch 行对应不同 $W_t$. 若用一个合并大矩阵计算，需要正确的 sequence mask 和状态 gather/scatter. 序列结束的槽位被新请求复用时必须初始化 $W_0$，任何遗漏都会跨用户泄漏. 随机压力测试频繁加入、结束和重排请求，能验证生命周期实现. 量化 fast weights 比量化慢参数更敏感. 慢参数离线校准一次，fast weights 分布随序列变化，尺度可能漂移. 固定量化范围会饱和，动态范围增加每步开销. 对不同长度记录饱和率、量化误差和检索，避免只在短 prefix 测精度. 低秩 fast weights 能降低状态和更新成本，设 $W=W_0+AB^\top$. 更新因子比更新完整矩阵更受秩限制，且分解尺度不唯一. rank 决定可写方向，长序列可能更快饱和. 扫描 rank、状态字节和检索容量，与同字节完整小矩阵比较.

稀疏更新也是一种选择. 每个 token 只更新部分通道或专家，减少干扰和计算；路由失误会把相关信息分散或写错专家. 路由负载、专家碰撞与未命中率应和语言 loss 一起报告. 若专家数随上下文增长，固定状态优势会逐渐消失.

在多模态序列中，图像 patch、音频帧和文本 token 的数量与统计不同. 共用 fast state 时，高频模态可能占满容量；分模态状态又削弱跨模态绑定. 学习率门可按模态归一化，或为跨模态关系保留专门槽. 文本上的长度外推结论不能直接覆盖视频百万 token. 值的尺度也会影响写入. 平方误差梯度与 $v-Wk$ 成正比，某模态或层的值范数大，会主导状态. 对键值做 LayerNorm、L2 归一化或学习尺度能平衡更新，也改变相似度与表达. 报告归一化位置是复现 delta rule 的必要条件.

残差通道可能绕开 fast state. 若输出为静态路径加 TTT 路径，训练初期外循环可能偏爱更容易优化的静态路径，让快速分支接近零. 增大 fast 分支、drop-path 静态通道或加状态利用辅助目标能迫使使用，但可能损害稳定. 因果清空实验最能判断是否发生绕行.

状态读出也可以多步迭代. 单次 $f_W(q)$ 只执行一次映射，多跳问题可能需要把读出结果再次查询状态. 增加迭代提升推理能力和延迟，也可能产生固定点或振荡. 与普通深层 MLP、recurrent depth 对齐计算，才能归因于记忆反复访问.

精确检索失败未必意味着状态毫无长程价值. 语言模型可通过压缩主题、实体频率、文体和局部规则降低 loss，这些统计无需逐 token 回看. 反过来，needle 成功也可能靠特殊键或训练模板，不能证明一般压缩质量. 多指标共同定义状态用途.

对于事实问答，可以把答案依赖分成局部复制、单跳键值、多跳组合和全局统计. fast weights 可能在全局统计与重复模式强，在随机单跳碰撞上弱. 每类单独报告随长度和负载的曲线，避免一个 RULER 平均隐藏能力形状.

状态容量的实验应固定写入次数与查询次数. 某些模型在每个写入后立即查询，容易；全部写完后随机查询早期项，更难；边写边查询又会让查询自身更新状态. 明确查询是否参与写入，防止测试过程改变被测记忆.

查询 token 若也执行重建更新，它可能覆盖即将读取的方向. 可以先读后写、对查询禁写或使用独立 query 投影. 三种语义需要与语言建模因果顺序一致. 合成检索中禁写常更干净，真实生成则每个 token 通常兼具读写角色. 多步内循环的计算图还会受到梯度 checkpointing. 为省显存重算前向时，dropout 或随机增强必须恢复 RNG，否则重算梯度对应另一条轨迹. 数值检查在 dropout 关闭和开启两种模式运行，验证重计算一致性. 优化器状态跨块延续会增加长程记忆，即使 $W$ 在某些边界重置，动量仍可能携带过去. 生命周期清单必须包含全部 optimizer buffer. 做复位消融时分别清 $W$、清动量和全清，找出实际信息载体.

如果每层学习率由外循环学成常数，它也会编码层的时间尺度. 大学习率层快速写快忘，小学习率层缓慢积累，可形成多尺度记忆. 分析各层有效半衰期与任务贡献，比把全部层统称 TTT 更有解释力. 输入依赖学习率进一步让时间尺度随内容变化. 罕见实体强写、普通词弱写是合理模式；模型也可能因频率偏差让低资源语言总是弱写. 按语言、token 类型和实体类别统计门值，检查容量分配公平性.

外循环数据分布决定写入策略. 在重复结构多的训练语料上学到的门控，面对代码、表格或数学证明可能失效. 留出整种文档类型做迁移测试，观察状态利用而非只看静态模型能力. 若需要按域重新训练外循环，所谓通用可学习记忆范围有限.

对代码任务，变量定义与调用形成精确绑定，适合检验覆盖和作用域. 在不同函数复用变量名、嵌套作用域与重新赋值，测试快速状态能否按上下文区分. 线性相似键更容易碰撞，MLP 或注意力混合可能改善. 数学证明需要保留假设并多步组合，平均 next-token loss可能偏爱局部模板. 将早期假设替换为矛盾版本，后续结论应改变；清空 fast state 后差异消失，才支持状态参与推理. 仅在原证明上续写流畅不足以证明长程使用.

最终的系统选择通常不是「attention 或 TTT」二选一. 给定显存、延迟和精度预算，可以分配局部 KV、稀疏全局 KV、SSM 状态和 TTT fast weights. 各组件解决不同记忆需求. 研究 TTT layer 的价值，是提供一种误差驱动、可学习且固定大小的写入机制，并清楚标出它付出的反向计算、近似并行和压缩干扰.

发布结论时，应将数学等价、经验优势和工程速度分成三层. 等价定理只在指定线性模型与优化规则成立；经验优势只覆盖数据、长度与指标；工程速度依赖 kernel 和硬件. 三层都成立的范围可能交集很小，逐层写清比一句「用训练替代注意力」更准确. 如果某个新 kernel 改变块大小、数值精度或 prefix 计算，它已经可能改变算法. 性能优化前后同时跑小规模状态逐步对齐、长程能力和吞吐，不能只验证终点 loss. 对 fast weights 而言，系统排布就是状态更新语义的一部分.

接受条件也应包含负收益边界. 在短上下文、精确检索、低延迟单 token 与多分支解码上，TTT 可能不如 attention 或简单递推. 明确这些场景能指导混合路由：短请求走静态路径，长文档启用 fast state，敏感检索保留显式 KV. 有选择地使用比强求单一架构覆盖全部任务更合理.

一个端到端手算可把内外循环连接起来. 假设标量快速权重 $w_0$、键 $k=1$、值 $v=2$、学习率 $\eta$，内循环后 $w_1=(1-\eta)w_0+2\eta$. 若外层希望 query $q=1$ 的输出接近目标 $y=3$，外损失为 $\frac12(w_1-3)^2$. 对 $w_0$ 的梯度是 $(w_1-3)(1-\eta)$，对学习率的梯度是 $(w_1-3)(2-w_0)$. 外循环会同时移动初始化和写入速度，使一步更新后的状态更适合最终任务. 若 $w_0=0,\eta=1$，内循环精确重建值 2，外层目标 3 仍有误差；外循环可能让 $w_0$ 或 $\eta$ 偏离重建最优，以服务外层预测. 这说明内循环 loss 最低不一定是语言模型最优. 元学习允许「怎样学」服从最终任务，而非把重建当绝对目标.

多 token 时，外层对早期学习率的梯度要穿过后续所有更新. 早期 token 若为后面大量预测提供主题信息，外循环会提高其写门；若它随后被证明是噪声，梯度会降低写入. 截断 BPTT 后，超出截断范围的收益无法直接回传，学习率门可能偏爱短期信号.

可以构造延迟奖励实验：第一个 token 给随机键，答案只在远处查询，中间 token 与任务无关. 随着查询距离超过元梯度截断，写门是否仍学会保存该键，直接检验归纳偏置能否弥补信用范围. attention 有显式路径，TTT 依赖状态保持和训练分布. 对 dual form，还应检验 forward 等价与 backward 等价. 两种实现输出接近，不代表对慢参数的梯度也接近；mask、转置或广播错误可能只在外循环梯度暴露. 小块用 double precision 运行逐 token 与 dual，实现参数梯度、学习率梯度和 $W_0$ 梯度逐项比较.

二阶梯度检查可以用有限差分. 对一个慢参数 $\psi$ 加减小扰动，重跑完整内循环，比较外损失差分与自动微分. 状态维度很小时成本可控，能发现 stop-gradient、in-place 更新和 checkpoint 重算错误. 数值步长过小受浮点误差影响，使用多尺度扰动观察收敛. in-place 更新 fast weights 容易破坏自动微分需要的旧值. 为速度使用自定义 kernel 时，要证明反向保存或重算了正确状态. 推理只需 forward 的 kernel 与训练需 meta-gradient 的 kernel可能不同，分别验证. 论文报告训练速度时应说明是否包含完整二阶反向.

状态初始化还与 batch 中的序列对齐有关. 不同序列长度导致 padding，padding token 不能写入状态；序列结束后该行状态重置，新序列的第一个 token从 $W_0$ 出发. mask 错一位会把 padding 或前一个用户尾部写入. 随机长度、频繁复用 batch 行的测试能暴露问题.

文档拼接训练常为提高利用率把多个文档接在固定长度块里. 如果只用 attention mask 阻止跨文档读取，却忘记重置 fast weights，后文仍可通过状态看到前文. 这既造成训练泄漏，也让模型学到部署时不存在的跨文档信号. 状态 reset mask 必须与文档边界同步. 反过来，某些应用希望跨段落保留状态. 这时边界由同一文档或会话决定，而不是固定训练 block. 将 block 边界当 reset 会丢失跨块记忆. 数据管线需要携带语义 sequence ID，不能仅凭张量切块决定生命周期.

checkpoint 恢复长生成时，保存 $W_t$ 之外还要保存当前块起点、块内已处理位置、学习率/动量状态和窗口 KV. 若在块中部只保存块末近似状态，恢复后重复或跳过写入. 简化方案只允许块边界 checkpoint，恢复粒度与最大重算成本一并报告.

状态序列化的带宽可能超过生成 token 带宽. 对大量并发会话做迁移或休眠，保存大 MLP fast weights成本高. 低秩压缩、量化和只保存增量可降低空间，恢复后必须测行为差异. 系统是否能经济地持久化状态，决定「长上下文」能否跨服务调度维持.

状态缓存淘汰也有语义. KV cache 可按 token 位置裁剪，fast weights 已压缩整个前缀，无法只删最老一段. 固定状态看似解决缓存增长，却失去精确时间选择. 门控衰减提供软遗忘，不能保证删除指定内容. 对合规删除或可引用记忆，仍可能需要显式存储.

学习到的键空间可以用谱分析诊断. 收集长序列键的协方差，查看有效秩与头间冗余. 有效秩远低于维度时容量未充分利用；高秩但条件数极大时碰撞仍严重. 对比静态表示与外循环训练后的表示，判断 TTT 是否主动展开地址空间. 值空间同样重要. 如果多个不同 token 映射到相似值，状态无需精确区分；若相似键对应差异很大的值，冲突最大. 联合统计键相似度与值差，按象限报告写后查询误差，能比总体 loss 更直接验证 delta rule 的行为.

多头状态提供子空间分工. 不同 head 可学习语法、实体或局部模式，也可能全部重复. 逐头清空、交换和测有效秩，观察哪个能力下降. 若只有少数头承载长程记忆，可以缩减其他状态或为关键头提高精度. 模型规模扩大时，状态维度、层数和快参数比例可能同时增长. 性能随规模提升无法归因于哪一项. 固定慢参数规模扫描 fast state，固定 state 扫描 backbone，再做联合 scaling，才能估计容量瓶颈. 仅比较不同总参数的系列不够.

训练 token 也影响结论. 更复杂 TTT 模型可能需要更多数据学会稳定写入，固定训练 token下显得欠训；给更多 token 又增加预算. scaling 曲线应按训练 FLOPs和数据量对齐，展示交叉点. 系统声称的长序列推理节省可能被昂贵预训练抵消.

能耗与硬件利用不能只用峰值 FLOPs. 内循环反向增加内存访问、同步和临时激活，功率和时间共同决定能量. 在目标硬件测端到端 prefill、decode 与状态保存，才有部署意义. TPU、GPU 和专用加速器对小矩阵与反向支持不同，速度结论注明平台.

可证伪的最终结论应形如：在给定状态字节、窗口、块大小、训练预算与序列边界下，TTT 在指定长度的语言 loss 或记忆任务上超过基线，同时通过因果状态干预和数值实现检查. 去掉这些限定，「线性复杂度」「等价 attention」「学会长期记忆」都容易超出证据.

读者进入后续两篇时，可以继续沿四个量追踪：状态是什么、写入损失是什么、一次更新跨多少 token、外循环信用穿过多远. LaCT 主要改变第三项与系统排布，TTT-E2E 主要改变第二项和外循环位置，5.3 则用同一组量比较 attention、SSM、RWKV 与 Titans. 这样方法名字变化，分析坐标仍保持一致.
