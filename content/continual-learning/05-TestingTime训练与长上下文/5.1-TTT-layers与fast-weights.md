# 5.1 · TTT layers 与 fast weights

## 问题与 TTT layer 的三个组件

### 问题: 固定大小的状态装不下长上下文

序列层可以按「状态」来分. 自注意力的状态是 KV cache, 每读一个 token 追加一对 $(k_t, v_t)$, 状态随 $t$ 线性增长, 生成第 $t$ 个 token 要扫描 $t$ 对 KV, 每个 token 的开销是 $O(t)$. RNN 的状态大小固定, 每个 token 的开销是 $O(1)$, 代价是要把整个历史压进固定大小的状态.

[Kaplan 等 (2020)](https://arxiv.org/abs/2001.08361) 的 Scaling Laws 论文里已经观察到, LSTM 既不能像 Transformer 那样随规模扩展, 也不能有效利用长上下文. 提出 TTT layer 的 [Sun, Li, Dalal 等 (2024)](https://arxiv.org/abs/2407.04620) 用 [Mamba](https://arxiv.org/abs/2312.00752) 重做了这个检查 (论文图 2): Mamba 在规模上的 Scaling Laws 已经和 Transformer 接近, 但在 Books 数据上按 token 位置画平均困惑度, Transformer 的曲线在 32k 内一直下降, Mamba 在 16k 之后变平. 后面的 token 能看到的历史更多, 理应更容易预测, 曲线变平说明 Mamba 的状态没能装下更多有用的信息.

RNN 相对 Transformer 的优势是线性复杂度, 这个优势只在长上下文里才兑现 (论文测得 8k 之后); 偏偏在长上下文里, 现有 RNN 用不上多出来的信息. 这是 TTT layer 要处理的矛盾. 论文的切入点是: 自监督学习本来就是一种把大量数据压进模型权重的方法, LLM 的预训练就是例子. 那么把 RNN 的状态更新本身写成一次自监督学习, 状态的压缩能力就来自学习算法, 而不是一个手写的门控公式.

本文按下面几个问题展开:

1. 状态是一个模型的权重, 更新规则是一步梯度下降, 这个层具体怎么算?
2. 内循环学什么, 由谁决定?
3. 它和线性注意力, DeltaNet, 自注意力是什么关系?
4. 逐 token 的梯度下降是串行的, 怎么在 GPU/TPU 上跑快?
5. 实验在多大规模, 多长上下文下成立, 成本在哪?

### 三个组件: 初始状态, 更新规则, 输出规则

论文把所有序列层拆成三个组件. 设输入 token 为 $x_t$, 输出为 $z_t$, 状态为 $s_t$:

| 层 | 初始状态 | 更新规则 | 输出规则 | 每 token 开销 |
| --- | --- | --- | --- | --- |
| 朴素 RNN | $s_0 = $ 零向量 | $s_t = \sigma(\theta_{ss}s_{t-1} + \theta_{sx}x_t)$ | $z_t = \theta_{zs}s_t + \theta_{zx}x_t$ | $O(1)$ |
| 自注意力 | $s_0 = $ 空列表 | $s_t = s_{t-1}.\text{append}(k_t, v_t)$ | $z_t = V_t\,\text{softmax}(K_t^\top q_t)$ | $O(t)$ |
| 朴素 TTT | $W_0 = f$ 的初始参数 | $W_t = W_{t-1} - \eta \nabla \ell(W_{t-1}; x_t)$ | $z_t = f(x_t; W_t)$ | $O(1)$ |

自注意力一行里 $K_t, V_t$ 是前 $t$ 个 key, value 按列拼成的矩阵. TTT 一行的状态是 $f$ 的参数 $W_t$, 大小固定, 所以它属于 RNN; 区别在更新规则, 它是对损失 $\ell$ 的一步梯度下降, 没有手写的门控或非线性映射:

$$
W_t = W_{t-1} - \eta\, \nabla \ell(W_{t-1}; x_t)
\tag{1}
$$

$\eta$ 是内循环学习率. 从压缩的角度看, 式 (1) 决定了记住什么: 梯度大的 token (让 $W$ 学到很多的 token) 对状态的改动大.

### 内循环损失

最简单的 $\ell$ 是重建: 把 $x_t$ 加噪或投影成 $\tilde{x}_t$, 让 $f$ 从 $\tilde{x}_t$ 重建 $x_t$, 损失 $\lVert f(\tilde{x}_t; W) - x_t \rVert^2$. 论文图 4 在 125M 模型上画了这个损失: 每走一步, $\ell(W_t; x_t)$ 比 $\ell(W_{t-1}; x_t)$ 低; 沿着序列往后, $\ell(W_t; x_t)$ 也比用初始权重的 $\ell(W_0; x_t)$ 越来越低, 说明 $W$ 确实在积累关于这条序列的信息.

手工设计加噪方式不一定对下游任务有用. 论文把重建任务本身参数化, 交给外循环学. 训练视图 $\theta_K x_t$ 是一个可学习的低秩投影, 重建目标 (标签视图) 是另一个可学习投影 $\theta_V x_t$:

$$
\ell(W; x_t) = \big\lVert f(\theta_K x_t; W) - \theta_V x_t \big\rVert^2
\tag{2}
$$

训练视图的维度比 $x_t$ 低, 输出不能再直接用 $f(x_t; W_t)$, 于是再加一个测试视图 $\theta_Q x_t$:

$$
z_t = f(\theta_Q x_t; W_t)
\tag{3}
$$

下标 $K, V, Q$ 是有意的: 它们在形式上对应自注意力的 key, value, query 投影. 式 (2) 决定 $x_t$ 的哪部分信息被压进 $W_t$ 并沿时间往后传; 式 (3) 决定从 $W_t$ 里读出什么, 送到当前位置的下一层.

$z_t$ 是这一层的输出向量, 送进网络后续层; 它本身不是下一个 token 的预测. 下一个 token 的预测由整个网络最后的输出头给出, 训练目标是标准的下一个 token 预测.

### 内循环与外循环

| | 内循环 (TTT) | 外循环 (正常训练) |
| --- | --- | --- |
| 一条数据 | 一个 token $x_t$ | 一条序列 $x_1, \dots, x_T$ |
| 训练集 | 一条序列 | 序列的数据集, 如 Books |
| 目标 | 重建, 式 (2) | 下一个 token 预测 |
| 被优化的参数 | $W$ ($f$ 的权重) | 网络其余参数 $\theta_{\text{rest}}$; $\theta_K, \theta_Q, \theta_V$; 初始值 $\theta_{\text{init}} = W_0$; 学习率参数 $\theta_{\text{lr}}$ |

这张表 (论文 Table 2) 里最重要的一点是: 在外循环看来, $W$ 只是隐状态, 不是参数; 外循环的参数是内循环损失和优化器的「超参数」. 外循环对 $\theta_K$ 等求梯度时, 要穿过式 (1) 里的梯度算子, 也就是对梯度求梯度. 这和 MAML 一类元学习的二阶梯度是同一种计算.

和常见的元学习相比, 这里的层级关系是反过来的. MAML 一类方法的内循环在一整个数据集 (一个任务) 上学习, 外循环要在很多个数据集上平均, 所以外循环比常规训练「高一级」, 需要收集成千上万个任务, 很难扩大规模. TTT layer 的内循环把一条序列当作一个数据集, 一个 token 当作一条数据, 内循环比常规训练「低一级」; 外循环面对的就是普通的序列数据集和普通的下一个 token 预测目标, 和训练一个 Transformer 没有区别. 论文认为这是这套外循环容易扩展的原因.

论文还试过在 $f$ 后面再接一个解码器 $g$, 用 $g \circ f$ 做重建. 效果略好, 但外循环训练变得不稳, 计算也明显增加, 最终只用编码器式的 $f$.

按四件事拆开:

| 问题 | TTT layer |
| --- | --- |
| 谁算 | 内循环模型 $f$, 权重 $W$ 每个 token (或每个 mini-batch) 更新一次 |
| 和谁算 | 当前 token 的训练视图 $\theta_K x_t$ 和标签视图 $\theta_V x_t$; 输出时用测试视图 $\theta_Q x_t$ |
| 状态怎么变 | $W_t$ 由式 (1) 从 $W_{t-1}$ 得到, 每条序列从 $W_0$ 开始, 序列结束丢弃 |
| 丢了什么 | 无法精确复现任一历史 token; 只保留对重建损失有用的统计结构 |

## 手算, mini-batch 与 dual form

### 手算: TTT-Linear 一步就是 delta rule

取 $f(k) = Wk$ (不加 LN 和残差), 记 $k_t = \theta_K x_t$, $v_t = \theta_V x_t$, 式 (2) 变成 $\ell = \lVert W k_t - v_t \rVert^2$. 对 $W$ 求梯度:

$$
\nabla_W \ell = 2(W k_t - v_t) k_t^\top
\tag{4}
$$

代入式 (1), 整理:

$$
W_t = W_{t-1} - 2\eta (W_{t-1} k_t - v_t) k_t^\top = W_{t-1}(I - 2\eta\, k_t k_t^\top) + 2\eta\, v_t k_t^\top
\tag{5}
$$

[DeltaNet](https://arxiv.org/abs/2406.06484) 的状态更新是 $S_t = S_{t-1}(I - \beta_t k_t k_t^\top) + \beta_t v_t k_t^\top$. 取 $\beta_t = 2\eta$, 两者相同. 论文在 related work 里也给了这个结论: DeltaNet 等价于内循环 mini-batch 大小为 1, 去掉 LN 和残差的 TTT-Linear.

式 (5) 的两项各有含义. 第二项 $2\eta\, v_t k_t^\top$ 把新的 key-value 关联写进去; 第一项 $W_{t-1}(I - 2\eta\, k_t k_t^\top)$ 先把旧状态在 $k_t$ 方向上的分量擦掉一部分. 先擦后写, 所以同一个 key 再次出现时, 新 value 会替换旧 value.

代入数字. 二维, $W_0 = 0$, $\eta = 0.5$ (所以 $2\eta = 1$).

第 1 个 token: $k_1 = (1, 0)^\top$, $v_1 = (0, 1)^\top$. $W_0 k_1 = 0$, 误差 $W_0 k_1 - v_1 = (0, -1)^\top$, 按式 (5):

$$
W_1 = 0 - (0, -1)^\top (1, 0) = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}
$$

查询 $q = (1, 0)^\top$: $W_1 q = (0, 1)^\top = v_1$, 读回了刚写入的 value.

第 2 个 token 用同一个 key, 换一个 value: $k_2 = (1, 0)^\top$, $v_2 = (1, 0)^\top$. 先算当前状态对 $k_2$ 的输出 $W_1 k_2 = (0, 1)^\top$, 误差 $(0, 1)^\top - (1, 0)^\top = (-1, 1)^\top$:

$$
W_2 = W_1 - (-1, 1)^\top (1, 0) = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix} - \begin{pmatrix} -1 & 0 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}
$$

查询 $q = (1, 0)^\top$: $W_2 q = (1, 0)^\top = v_2$, 旧 value 被完整替换.

同样两个 token 交给不带归一化的线性注意力, 状态是外积的累加 $S_2 = v_1 k_1^\top + v_2 k_2^\top = \begin{pmatrix} 1 & 0 \\ 1 & 0 \end{pmatrix}$, 查询得到 $(1, 1)^\top$, 是 $v_1$ 和 $v_2$ 的叠加. 线性注意力只写不擦, 同一个 key 上的多个 value 会混在一起; delta rule 用当前预测误差决定写多少, 能覆盖. 这里 $\lVert k \rVert = 1$, $2\eta = 1$, 覆盖是完全的; $2\eta < 1$ 时是部分覆盖.

### 让它跑起来: mini-batch TTT

式 (1) 不能并行: $W_t$ 依赖 $W_{t-1}$, 依赖出现在两处, 减号前面和梯度里面. 梯度是主要计算量, 论文从这里下手. 把梯度下降写成通式:

$$
W_t = W_{t-1} - \eta\, G_t = W_0 - \eta \sum_{s=1}^{t} G_s
\tag{6}
$$

$G_t$ 是下降方向. 只要所有 $G_t$ 都算出来, 所有 $W_t$ 就是一次累加 (cumsum). 三种选择:

- 在线 GD: $G_t = \nabla \ell(W_{t-1}; x_t)$, 每个梯度依赖上一步, 完全串行. $W_t$ 离 $W_0$ 有 $t$ 步.
- batch GD: $G_t = \nabla \ell(W_0; x_t)$, 全部相对 $W_0$ 求, 完全并行. 但 $W_t$ 实际上离 $W_0$ 只有一步, 搜索空间小, 语言建模效果差.
- mini-batch GD: $G_t = \nabla \ell(W_{t'}; x_t)$, 其中 $t' = t - \text{mod}(t, b)$ 是上一个 mini-batch 的最后时刻. 同一块内的 $b$ 个梯度相对同一个基点求, 可以并行; 块与块之间串行.

论文所有实验取 $b = 16$. 图 7 的消融显示 $b$ 越小困惑度越好 (梯度步数越多), 但并行度越低.

信息在 $W_s$ 到 $W_t$ ($s < t$) 之间有两条传播通道: 累加 (式 (6) 的求和, 始终在) 和梯度算子 (只在 $W_s$ 来自之前的块时才在). 不同的 GD 变体只改变梯度通道.

用前面的手算例子看 mini-batch 的代价. 取 $b = 2$, 两个 token 在同一块里, 梯度都相对 $W_0 = 0$ 求: $G_1 = -2 v_1 k_1^\top$, $G_2 = -2 v_2 k_2^\top$. 块结束时 $W_2 = W_0 - 0.5(G_1 + G_2) = v_1 k_1^\top + v_2 k_2^\top$, 和线性注意力的结果一样, 查询得到 $(1, 1)^\top$. 块内的 token 之间没有擦除, 只有块与块之间才有 delta rule 的覆盖. $b$ 越大, TTT 越接近线性注意力; $b = T$ (整条序列一块) 就是下一节的定理 1.

### dual form: 把外积换成矩阵乘

mini-batch 解决了并行, 没解决硬件利用率. 现代加速器的算力集中在矩阵乘单元 (A100 的 TensorCore 一次做 $16 \times 16$ 的矩阵乘), 而 mini-batch TTT 的每个 $G_t$ 是一个 $d \times d$ 的外积, $b$ 个外积要一个个算, 每个都要写回显存, 内存 I/O 远大于 $x_t$ 本身.

论文的观察是, 块内的 $G_t$ 和中间的 $W_t$ 都不需要显式生成, 只要算出块末的 $W_b$ 和块内所有输出 $z_1, \dots, z_b$. 以最简单的情况推导: $\theta_K = \theta_V = \theta_Q = I$, $f(x) = Wx$, 第一个块. 记 $X = [x_1, \dots, x_b]$. 块末权重:

$$
W_b = W_0 - \eta \sum_{t=1}^{b} G_t = W_0 - 2\eta \sum_{t=1}^{b} (W_0 x_t - x_t) x_t^\top = W_0 - 2\eta (W_0 X - X) X^\top
\tag{7}
$$

一次矩阵乘. 块内输出:

$$
z_t = W_t x_t = W_0 x_t - 2\eta \sum_{s=1}^{t} (W_0 x_s - x_s) x_s^\top x_t
\tag{8}
$$

记 $\delta_t = \sum_{s=1}^{t} (W_0 x_s - x_s) x_s^\top x_t$, $\Delta = [\delta_1, \dots, \delta_b]$. 交换求和顺序, 把 $x_s^\top x_t$ 收成一个 Gram 矩阵:

$$
\Delta = (W_0 X - X)\, \text{mask}(X^\top X)
\tag{9}
$$

mask 是上三角掩码, 被掩掉的位置填 0 (自注意力的因果掩码填 $-\infty$, 这里填 0). 于是 $Z = W_0 X - 2\eta \Delta$, 全是矩阵乘. $W_0 X - X$ 在式 (7) 和式 (9) 里共用.

两种形式输出相同, 代价不同. primal form (显式生成 $G$ 和 $W$) 块内复杂度 $O(b d^2)$; dual form 算 $W_b$ 是 $O(b d^2)$, 算 $z_1, \dots, z_b$ 另加 $O(b^2 d)$. 理论复杂度变高了, 换来的是硬件利用率. 代入 $d = 256$, $b = 16$: $b d^2 = 16 \times 65536 = 1{,}048{,}576$, $b^2 d = 256 \times 256 = 65{,}536$, 额外开销约 6%. 论文的 JAX 实现里, 用 dual form 训练比 primal form 快 5 倍以上. 附录 A 说明 $f$ 含非线性层时 dual form 同样成立.

推理时两种形式分工: prefill 和训练的前向一样可以并行, 用 dual form; decode 逐 token 生成, 本身就串行, 用 primal form.

## 和注意力的等价关系

### 等价关系: 线性注意力与自注意力

**定理 1.** 取 $f(x) = Wx$, batch GD, $\eta = 1/2$, $W_0 = 0$. 对同样的输入序列, 式 (3) 的输出与线性注意力相同.

证明只有两步. 由式 (2), $\nabla \ell(W_0; x_t) = -2(\theta_V x_t)(\theta_K x_t)^\top$ ($W_0 = 0$ 时第一项消失). 代入 batch GD 的式 (6):

$$
W_t = W_0 - \eta \sum_{s=1}^{t} \nabla \ell(W_0; x_s) = \sum_{s=1}^{t} (\theta_V x_s)(\theta_K x_s)^\top
\tag{10}
$$

代入式 (3):

$$
z_t = \sum_{s=1}^{t} (\theta_V x_s)(\theta_K x_s)^\top (\theta_Q x_t)
\tag{11}
$$

式 (11) 就是不带 softmax 的注意力 $z_t = \sum_s v_s k_s^\top q_t$, 即 [Katharopoulos 等 (2020)](https://arxiv.org/abs/2006.16236) 线性注意力的最简形式 (原式还有一个归一化分母和特征映射, 论文和前人都发现这两项会伤效果, 所以只对最简形式建立等价).

**定理 2.** 把参数模型换成非参数的 Nadaraya-Watson 核回归:

$$
f(x; x_1, \dots, x_t) = \frac{\sum_{s=1}^{t} \kappa(x, x_s)\, y_s}{\sum_{s=1}^{t} \kappa(x, x_s)}, \qquad \kappa(x, x') \propto e^{(\theta_K x)^\top \theta_Q x'}
\tag{12}
$$

$y_s = \theta_V x_s$ 是标签视图. 代入式 (3) 就是 softmax 自注意力. 这种 learner 没有参数 $W$, 状态是训练数据本身的列表, 更新规则是追加, 输出规则是用核扫描列表, 和本文开头那张表里自注意力一行一致.

两个定理把三种层放在一条轴上: 线性模型 + batch GD 是线性注意力; 线性模型 + 在线 GD 是 DeltaNet; 线性模型 + mini-batch GD + LN 与残差是 TTT-Linear; 非参数核回归是自注意力. 论文借此定义了更一般的 learner 抽象 (实现 train 和 predict 两个方法), 状态也可以包括优化器状态, 例如 Adam 的动量.

### 从线性注意力一步步改到 TTT-Linear

论文 Table 1 在 125M 规模上从线性注意力出发, 每行加一个改动 (困惑度):

| 配置 | 困惑度 | 变化 |
| --- | --- | --- |
| 线性注意力 (原式) | 15.91 | |
| 线性注意力 (改进版) | 15.23 | $-0.68$ |
| TTT 等价实现 | 15.23 | 0 |
| + 可学习 $W_0$ | 15.27 | $+0.04$ |
| + $f$ 内 LN 与残差 | 14.05 | $-1.22$ |
| + mini-batch TTT | 12.35 | $-1.70$ |
| + 可学习 $\eta$ | 11.99 | $-0.36$ |
| + Mamba backbone | 11.09 | $-0.90$ |

前三行是对照. 「TTT 等价实现」与改进版线性注意力完全一样, 验证了定理 1. 可学习 $W_0$ 略伤困惑度, 但论文报告不加它下面几行都训不稳. 第四行加的是 LN 与残差: $f(x) = x + \text{LN}(f_{\text{res}}(x))$. 这一改动让 $f$ 本身不再是线性的, 即使 $f_{\text{res}}$ 是线性的, 内循环的梯度也不再是简单的外积, 式 (5) 的 delta rule 形式不再精确成立.

mini-batch TTT 从 $b = T = 2048$ (batch GD, 即线性注意力) 改到 $b = 16$, 贡献最大. 前面手算里看到的块内无擦除, 块间有覆盖, 这个差别在语言建模上值 1.7 个困惑度. 可学习 $\eta$ 写成 $\eta(x) = \eta_{\text{base}}\, \sigma(\theta_{\text{lr}} \cdot x)$, $\sigma$ 是 sigmoid, $\eta_{\text{base}}$ 在 TTT-Linear 取 1, TTT-MLP 取 0.1; 学习率随 token 变化, 也可以看成对梯度的门控. 最后一行换成 Mamba backbone: Mamba 和 Griffin 的 backbone 在序列层之前有时间卷积, 能收集局部信息, 换上它之后又降 0.9.

论文指出, 最大的两项 (mini-batch 和 LN 加残差) 都是从 TTT 的视角自然想到的, 从线性注意力的视角不容易想到.

这几步改完, 内模型 $f$ 有两个取法. TTT-Linear: $f_{\text{lin}}(x) = Wx$, $W$ 为方阵. TTT-MLP: $f_{\text{MLP}}$ 是两层 MLP, 隐层维度是输入的 4 倍, 激活 GELU. 两者外面都套 $x + \text{LN}(\cdot)$. TTT-MLP 的状态更大, 表达力更强, 每个 token 的计算也更多.

## 实验: 规模, 数据和上下文长度

### 协议

对照 Transformer (Llama 结构) 和 Mamba, 严格沿用 Mamba 论文的评测协议. 四个规模 125M, 350M, 760M, 1.3B (Mamba 对应 130M, 370M, 790M, 1.4B). 全部按 Mamba 论文复现的 Chinchilla 配方训练. 分词器统一用 Llama 的. 不做混合架构.

数据有两套. [Pile](https://arxiv.org/abs/2101.00027) 上做 2k 和 8k 两种上下文, 这是标准的短上下文实验; Pile 里长于 8k 的序列很少, 所以长上下文实验改用其子集 Books3, 上下文从 1k 到 32k 每次翻倍. 每个训练批固定 0.5M token, 上下文为 $T$ 时每批 $0.5\text{M}/T$ 条序列.

### Pile: 短上下文

- 2k: TTT-Linear (Mamba backbone), Mamba, Transformer 三者曲线基本重合. TTT-MLP 在大 FLOPs 预算下略差: 它在每个规模上的困惑度都比 TTT-Linear 好, 但额外的 FLOPs 抵消了优势.
- 8k: TTT-Linear 和 TTT-MLP (Mamba backbone) 都明显好于 Mamba. 即使 Transformer backbone 的 TTT-MLP 在 1.3B 附近也略好于 Mamba. Transformer 在每个规模上困惑度都不差, 但 FLOPs 太高, 在 FLOPs 对困惑度的图上没有竞争力.

论文把这条规律概括为: 上下文越长, TTT 相对 Mamba 的优势越大.

### Books: 长上下文

- 2k: 结论与 Pile 2k 基本相同, 只是这里 Mamba 略好于 TTT-Linear.
- 32k: TTT-Linear 和 TTT-MLP (Mamba backbone) 都好于 Mamba, Transformer backbone 的 TTT-MLP 也略好于 Mamba.
- backbone 的作用: Mamba backbone 下 TTT-MLP 最多与 TTT-Linear 持平; Transformer backbone 下 TTT-MLP 明显更好. 论文的假设是时间卷积对表达力弱的状态帮助更大, 线性模型比 MLP 弱, 所以从卷积中受益更多. 1.3B 上 Transformer backbone 的 TTT-MLP 只比 Mamba backbone 略差, 论文据此推测更大模型, 更长上下文时 Transformer backbone 可能更合适, 但没有实验证实.

真实场景里, 长上下文 Transformer 通常先在短上下文训练, 再在长上下文微调. 论文为此加了 TF finetune 基线: 从 Books 2k 的模型出发, 再用 20% 的 token 在目标长度微调. 图 2 右侧的 Transformer 就是这个更强的基线; 该图里所有方法的训练 FLOPs 与 Mamba 1.4B 对齐. 在匹配 FLOPs 的条件下, TTT-MLP 在短上下文比 TTT-Linear 差, 在长上下文更好, 符合「状态更大的模型在长上下文里才用得上它的容量」的预期.

论文没有得到干净的 Scaling Laws 直线拟合, 连 Transformer 也没有, 所以图中只把点连起来, 没有做回归. 这意味着这些结论只在实验覆盖的 FLOPs 区间内成立, 不能外推.

### 墙钟时间

TPU v5e-256 上, 2k 上下文训练一步, Transformer 0.30 秒, TTT-Linear 0.27 秒, 没有系统优化就快了 10%. Mamba 的实现只能跑在 GPU 上, 论文为公平比较另写了 GPU 推理 kernel (只写了推理, 训练 kernel 工作量大且 TPU 用不上). A100 上 1.3B 模型的测量 (图 12): Transformer 每 token 的时间随上下文线性增长, TTT 和 Mamba 大致恒定. Transformer 基线用的是 vLLM, 比 Mamba 论文里用 HuggingFace 实现的基线快得多.

TTT-MLP 在 FLOPs 上划算 (图 2), 但 MLP 结构让墙钟时间的增长比 FLOPs 快得多 (图 12). 论文把内存 I/O 列为 TTT-MLP 的主要挑战, 并承认即使用了 mini-batch 和 dual form, 这个框架的实例化仍可能需要可观的墙钟时间.

## 来历, 旁支与限制

### fast weights 的来历

把一部分权重放到推理阶段, 按当前输入快速更新, 这个想法比 TTT layer 早得多. fast weights 指只在最相关的数据 (通常就是当前输入) 上更新的权重, 与在全部数据上训练的 slow weights 相对, 1980 年代就有. [Hinton & Plaut (1987)](https://www.cs.toronto.edu/~hinton/absps/fastweights87.pdf) 给每个连接配两份权重, 一份变化慢, 存长期知识; 一份变化快并向零衰减, 存最近学到的东西, 用来在学新任务后快速恢复被干扰的旧记忆.

[Ba, Hinton, Mnih, Leibo & Ionescu (2016)](https://arxiv.org/abs/1610.06258) 把 fast weights 接进 RNN, 用来关注最近的过去. 每一步用隐状态 $h_t$ 的外积更新一个 fast weight 矩阵 $A_t$:

$$
A_t = \lambda A_{t-1} + \eta\, h_t h_t^\top
\tag{13}
$$

$\lambda < 1$ 是衰减率, $\eta$ 是写入强度. 读出时用 $A_t$ 乘当前的中间隐状态, 迭代几步, 相当于从最近存过的隐状态里取出与当前相似的那些. 式 (13) 与 5.3 里 Mamba-2 的「衰减后加外积」是同一种写入, 区别在 key 和 value 都是 $h_t$ 本身 (自联想), 衰减是固定常数, 没有擦除.

[Schmidhuber (1992)](https://doi.org/10.1162/neco.1992.4.1.131) 提出 fast weight programmer: 一个 slow 网络在每一步生成对 fast 网络权重的修改, fast 网络作为可写的记忆. [Schlag, Irie & Schmidhuber (2021)](https://arxiv.org/abs/2102.11174) 证明线性注意力在数学上就是一种 fast weight programmer, 状态矩阵就是 fast weights, 外积累加就是写入规则; 他们同时指出纯外积累加的容量问题, 引入了 delta rule 的写入方式. 这一支后来发展成 DeltaNet 及其并行化 ([Yang 等, 2024](https://arxiv.org/abs/2406.06484)).

按这个谱系, TTT layer 里内循环的 $W$ 是 fast weights, 外循环的 $\theta$ 是 slow weights, 带 TTT layer 的网络是 fast weight programmer 的一个特例. TTT 视角多出来的东西有两点: 写入规则被明确写成一个学习问题 (有损失, 有优化器, 测试输入就是泛化目标), 以及由此可以换任意模型和优化器. 论文也注明, 把 fast weights 做成 MLP 在 Irie 等人的工作里已经出现过, 早于 TTT-MLP; [Clark 等 (2022)](https://arxiv.org/abs/2212.02475) 给 Transformer 的最后加了一层 fast weights, 其初始化作为 slow weights 训练; 后来的 TTT-E2E 论文说自己与这篇的高层思路相同.

论文对自己贡献的定位是: 一个可以把任意神经网络实例化为隐状态的实用框架. 它承认线性 (矩阵) 隐状态的路线在 DeltaNet 之后又有 Mamba 2 和 Gated DeltaNet 的推进, 这些在 [5.3](./5.3-与attention-SSM-RWKV-Titans的边界.md) 里统一对照.

### 推理阶段学习的另几条老路

TTT layer 的论文把自己放在更长的历史里. 在测试输入上做学习, 最早的版本之一是 Bottou 和 Vapnik 1992 年的 local learning: 对每个测试输入, 先在它的近邻训练样本上训练, 再做预测. 另一条是 Vapnik 的直推学习 (transductive learning), 原则是「只求你真正需要的那个答案, 不求更一般的」, 具体实现是用测试样本给 SVM 的间隔加约束; 它通常要很多个测试样本一起才有效, TTT 则只需要一个测试实例 (一张图, 一段视频, 一条序列).

语言模型里最接近的做法是动态评估 (dynamic evaluation, [Krause 等, 2018](https://arxiv.org/abs/1709.07432)): 直接在测试序列上微调语言模型, 读到哪里就用已经读过的部分更新参数. 它和 TTT layer 的差别在两点. 第一, 动态评估更新的是整个模型 (或其中一部分) 的普通参数, 用的是下一个 token 预测损失; TTT layer 更新的是专门设计的内层状态 $W$, 用的是可学习的重建损失. 第二, 动态评估的模型在训练阶段并不知道自己推理时会被更新, 训练目标和推理时的实际行为不一致; TTT layer 在外循环里就包含了内循环, 训练和推理时的计算完全相同. 第二点在 5.2 的 TTT-E2E 里被进一步推到整个网络上.

在视觉里, 4.1 的 Sun 2020 是 TTT 这个名字的来源. 那篇里自监督任务 (旋转预测) 是人定的; TTT layer 的论文认为自己与那条线最大的概念差别, 就是重建任务的视图 $\theta_K, \theta_V, \theta_Q$ 由外循环学出来. 视频流上的自回归 TTT (在过去的帧上训练, 再处理当前帧) 是论文点名最相关的前作, 因为它和序列建模一样, 状态从前往后传.

### 状态容量, 块大小与墙钟时间的限制

**状态容量.** TTT layer 的状态大小固定, 和所有 RNN 一样无法精确回忆任意历史 token. 论文的主要指标是困惑度, 衡量的是平均预测质量, 不直接衡量 needle-in-a-haystack 一类精确检索. 精确检索是固定状态模型的普遍弱项, 5.2 的 TTT-E2E 会给出这方面的数据.

**块大小的两难.** $b$ 小, 梯度步多, 效果好, 但并行度低, 硬件利用率低; $b$ 大, 并行度高, 但块内退化成线性注意力. $b = 16$ 是这篇论文在这个两难上取的点. [5.2](./5.2-LaCT与TTT-E2E.md) 的 LaCT 反过来把 $b$ 取到几千甚至上百万, 用块内的窗口注意力补回局部依赖.

**墙钟时间.** dual form 降低了 TTT-Linear 的开销, 但 TTT-MLP 的 I/O 仍是瓶颈. 训练要对梯度求梯度, 比普通前向反向贵.

**对 backbone 的依赖.** 最好的结果用的是带时间卷积的 Mamba backbone. 换成 Transformer backbone, TTT-Linear 的困惑度变差. 结论里有一部分收益来自 backbone, 不全来自 TTT layer 本身.

**规模和外推.** 最大 1.3B, 最长 32k, 没有干净的 Scaling Laws 拟合. 这些数字支持「在这个区间内 TTT 比 Mamba 更会用长上下文」, 不支持对更大规模的预测.

**与第 4 章的区别.** 这里的「推理阶段更新」每条序列从 $W_0$ 开始, 序列结束丢弃, 不存在第 4 章那种跨样本的误差积累和遗忘. 代价是它也不会跨序列积累任何东西, 这一点到 5.2 的 TTT-E2E 依然成立.
