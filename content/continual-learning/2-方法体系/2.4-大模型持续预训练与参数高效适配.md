# 大模型持续预训练与参数高效适配

> 相关阅读: [1.1 持续学习的场景与术语](../1-基础与问题定义/1.1-持续学习的场景与术语.md) · [2.2 回放与外部记忆](./2.2-回放与外部记忆.md) · [2.3 参数隔离与动态架构](./2.3-参数隔离与动态架构.md) · [3.5.1 继续预训练](../../llm-guide/3-预训练/3.5-继续预训练与长上下文训练/3.5.1-继续预训练/3.5.1-继续预训练.md)

预训练大模型上的持续学习主要有三条线: 继续预训练, 在指令与对齐数据上的持续微调, 冻结骨干的参数高效适配 (L2P, O-LoRA, InfLoRA). 另有一类做法不做顺序训练, 直接合并独立微调的模型. 第 1.1 篇第 4.2 节算过显存: 70B 模型仅 BF16 权重就是 140 GB, 混合精度 Adam 全量训练每参数约 16 字节. 资源之外, 大模型上的持续学习还有三点与传统设定不同.

- **起点是一个已经学了大量知识的模型**. 传统设定从随机初始化出发, 遗忘的对象是前几个任务; 大模型还可能遗忘预训练阶段获得的通用能力. 评测要覆盖通用能力, 不能只看序列里的任务.
- **任务边界模糊**. 继续预训练是连续的语料流, 指令微调的「任务」划分常常是人为的. 很多需要任务边界的方法 (第 2.1 篇的 EWC, SI) 不能直接使用.
- **旧数据通常拿不到**. 开源模型一般不公开预训练语料, 回放只能用分布相近的公开数据代替.

后面的讨论按更新范围分三层：继续预训练更新全部参数，数据是无标签语料；指令和任务的持续微调更新全部或部分参数，数据是有标签的指令；参数高效方法冻结骨干，只训练提示或低秩矩阵。三条路线汇合到模型合并与版本管理问题。

## 1 继续预训练

**学习率.** 预训练的学习率通常衰减到峰值的一小部分. 在衰减后的学习率上继续训练, 模型几乎学不动新分布. Gupta et al. (2023) 用 Pythia 410M 研究这个问题: 先在 Pile 上训练 300B token, 再在 SlimPajama 上继续训练 297B token. 学习率先线性升温, 再余弦衰减, 峰值取 $1.5\times10^{-4}$, $3\times10^{-4}$, $6\times10^{-4}$ 三档. 主要发现:

- **重新升温先让 loss 上升**. 升温阶段上游 (Pile) 和下游 (SlimPajama) 的 loss 都会先上升. 长期看, 升温后的模型在下游上超过从头训练的模型.
- **warmup 长度不重要**. 对 297B token 的日程比较 0%, 0.5%, 1%, 2% 四种 warmup 比例, 结果差别很小.
- **峰值决定适应与遗忘**. 峰值越高, 下游适应越多, 上游遗忘也越多. 提高峰值会一致地抬高 Pile 上的最终 loss.
- **从最新的 checkpoint 出发最好**.

困惑度和 loss 是连续量, 比较时用「降低多少」或比值, 不用百分点. Code Llama (Rozière et al., 2023) 从 Llama 2 出发继续训练, 发现沿用 Llama 2 的原学习率效果最好: 7B 和 13B 为 $3\times10^{-4}$, 34B 和 70B 为 $1.5\times10^{-4}$. 这与微调阶段降学习率的惯例相反. Code Llama 初始阶段训练 500B token, 是 Llama 2 预训练 2T token 的四分之一, 更接近第二次预训练.

第二次预训练改动参数的幅度也接近预训练的量级. DARE 论文 (Yu et al., 2024) 给出了一个可以量化的差别: SFT 前后的参数差 (delta) 通常在 0.002 以内, 而经过继续预训练后可以很快达到 0.03 左右. 这时随机丢掉 delta 的 DARE 不再可用; 只丢掉 10% 的微调后参数 (预训练参数加 delta), 性能就会崩溃到接近零. 继续预训练对参数的改动比微调大一个数量级, 第 4 节的模型合并方法大多以「增量很小」为前提, 不能直接用在继续预训练得到的模型上. **回放与数据配比.**

Ibrahim et al. (2024) 用 405M 模型先在 Pile 上训练 300B token, 再分别继续训练 SlimPajama (300B token, 弱分布偏移) 和德语 Common Crawl (200B token, 强分布偏移). 每次继续训练都重置优化器状态. 回放采用算力等价的方式: 回放的旧数据 token 从新数据预算中扣除, 总 token 数不变. 设新数据预算为 $N_1$ 个 token, 回放比例为 $\rho$, 则实际看到的新数据为 $(1-\rho)N_1$, 旧数据为 $\rho N_1$. 强分布偏移下的最终验证 loss (论文 Table 2):

| 设置 | Pile loss | 德语 loss | 平均 |
|------|------|------|------|
| 无回放 | 3.56 | 1.11 | 2.34 |
| 1% 回放 | 2.83 | 1.12 | 1.97 |
| 5% 回放 | 2.57 | 1.12 | 1.85 |
| 25% 回放 | 2.33 | 1.16 | 1.75 |
| 50% 回放 | 2.24 | 1.22 | 1.73 |
| 并集从头训练 (500B) | 2.26 | 1.25 | 1.75 |

1% 回放就把 Pile loss 从 3.56 降到 2.83, 德语 loss 只从 1.11 升到 1.12. 回放到 25% 时平均 loss 与并集从头训练持平. 弱分布偏移下, 0.5% 回放把 Pile loss 从 2.44 降到 2.27, 5% 回放的平均 loss 为 2.37, 并集从头训练为 2.35. 论文据此给弱偏移选 5% 回放, 强偏移选 25%. 在已有 Pile 模型的基础上, 这样做的额外算力只有从头训练的一半 (弱偏移 300B 对 600B) 或 40% (强偏移 200B 对 500B). 这些数字的前提是回放的确实是原始的 Pile. 用替代语料时效果会打折扣, 需要自己测.

公开的继续预训练配方里也混着旧数据. Code Llama 初始阶段的数据中, 代码占 85%, 与代码相关的自然语言占 8%, 一般自然语言占 7%. 后两部分的作用之一就是回放, 保住自然语言能力. Code Llama - Python 在此基础上再训练 100B token, 配比为 Python 75%, 其他代码 10%, 与代码相关的自然语言 10%, 一般自然语言 5%: 每往专门方向走一步, 前一阶段的数据都以一定比例留在新阶段里. Instruct 阶段又混入 6% 的代码数据和 2% 的自然语言数据作为 rehearsal. 这些比例没有系统的消融, 与 Ibrahim et al. 的「强偏移约 25% 回放」处在同一量级.

回放的反面是新数据取多少. 知识随时间变化时, 继续预训练要处理的是「新事实替换旧事实」, 未变的那部分知识要不要再训一遍, 就是这里的回放问题. Jang et al. (2022) 的 TemporalWiki 比较相邻的英文 Wikipedia 快照, 只取变化的部分作为训练语料 (TWiki-Diffsets), 用对应的 Wikidata 快照构造评测集 (TWiki-Probes), 把事实分为未变和已变两类. 论文报告, 只在差异数据上做持续学习, 困惑度与在整个快照上训练相当或更好, 计算量少 12 倍. 数据规模可以说明这个差距从哪来: 论文用 2021 年 8 月到 12 月的月度快照, 每个 Wikipedia 快照约 630 万篇文章, 46 亿到 47 亿 token; 相邻两月的差分集约 30 万篇文章, 3.5 亿到 3.8 亿 token, 不到完整快照的十分之一. 第 3.2 篇在基准部分给出了探针的构造细节. **目标函数、token 混合与梯度冲突.** 继续预训练仍然优化下一个 token 的负对数似然. 设语料域为 $d$, 域采样权重为 $\alpha_d$, 有效 token 掩码为 $m_t$, 混合目标可以写成

$$
\mathcal L_{\mathrm{mix}}(\theta)=\sum_d\alpha_d\,\mathbb E_{x\sim\mathcal D_d}\left[-\sum_t m_t\log p_\theta(x_t\mid x_{<t})\right],\qquad \sum_d\alpha_d=1. \tag{1a}
$$

$\alpha_d$ 应对应实际进入损失的 token 比例, 不一定等于文档或样本的抽样比例. 长文档、截断、padding 和损失掩码都会改变有效贡献. 若按样本数混合而不核对有效 token, 标称的 5% 回放可能并不是梯度里的 5%. **算例一: 从 token 预算反推样本数.** 一个训练步预算 1,000,000 个有效 token, 回放比例 $\rho=5\%$, 则旧域应提供 50,000 token, 新域提供 950,000 token. 若旧样本平均有 500 个有效 token, 新样本平均有 1,000 个, 这一批约需 100 个旧样本与 950 个新样本. 此时旧样本占样本总数的 $100/1050\approx9.52\%$, 却只占 token 的 5%. 反过来若机械地抽 5% 旧样本, 旧 token 占比会低于 5%. 所以配比记录至少要同时报告样本数、原始 token、有效 token 与总训练 token. 遗忘也可以从梯度局部解释. 记旧域和新域在当前位置的梯度为 $g_{\mathrm{old}}$、$g_{\mathrm{new}}$, 混合梯度为

$$
g_{\mathrm{mix}}=\rho g_{\mathrm{old}}+(1-\rho)g_{\mathrm{new}}. \tag{1b}
$$

若 $g_{\mathrm{old}}^\top g_{\mathrm{new}}<0$, 沿新域梯度下降会在一阶近似下抬高旧域损失. 新语料很少出现旧域稀有 token 或旧上下文时, 它们没有校正梯度; 与新域共用的词表、注意力和前馈参数却仍被更新, 因而条件分布会漂移. 这比把遗忘描述成「旧知识被删掉」更准确.

取一个二维玩具例子, $g_{\mathrm{old}}=(1,0)$, $g_{\mathrm{new}}=(-0.6,0.8)$. 则 $g_{\mathrm{old}}^\top g_{\mathrm{mix}}=-0.6+1.6\rho$. $\rho=25\%$ 时结果为 $-0.2$, 局部冲突仍在; 只有 $\rho>37.5\%$ 才变为正. 这个计算只说明回放比例取决于梯度几何, 不能用它推出真实模型需要 37.5% 回放. 同样, 旧域验证 loss 上升能证明分布拟合变差, 不能单独定位哪些事实丢失; loss 不变也不能证明问答、安全或指令遵循没有退化.

### 2 指令与任务的持续微调

**TRACE.** Wang et al. (2023) 的 TRACE 是为对齐后的大模型设计的持续学习基准, 由 8 个数据集组成: 领域任务 ScienceQA, FOMC, MeetingBank; 多语言任务 C-STANCE (中文立场检测) 和 20Minuten (德语文本简化); 代码补全 Py150; 数学推理 NumGLUE 的两个子集. 每个任务采样 5000 条, 分类任务按类别均衡. 除了传统的持续学习指标, TRACE 增加了三个指标: General Ability Delta (通用能力的变化), Instruction Following Delta (指令遵循能力的变化), Safety Delta (安全性的变化). 论文的主要发现:

- 在 TRACE 上依次训练后, 通用能力明显下降, 数学和推理最严重. Llama-2-Chat 13B 的 GSM8K 准确率从 28.8% 降到 2%.
- 多语言能力反而普遍提高. Llama-2-Chat 7B 的 TydiQA F1 从 23.47 升到 33.23.
- 全参数训练比 LoRA 更容易拟合目标任务, 通用能力的下降也更明显.
- 指令遵循能力在持续学习后显著下降.

论文还提出 Reasoning-augmented Continual Learning (RCL): 训练时让模型先生成任务分析和推理过程. 论文报告这样做既提高了目标任务的表现, 也更好地保住了模型原有的能力. TRACE 的数据说明, 在大模型上只看序列内任务的平均准确率是不够的. 序列任务都学会了, GSM8K 却从 28.8% 掉到 2%, 这种遗忘只有在序列外的通用基准上才能看到. **Continual-T0.**

Scialom et al. (2022) 从 T0 3B 出发. T0 已经在 50 个数据集上做过多任务指令微调, 在 12 个未见数据集上有零样本能力. 他们在 T0 上依次学习 8 个新的生成任务 (连同之前的数据集共 70 个), 用回放防止遗忘: 每个旧训练任务取 100,000 条样本, 回放比例 $r$ 取 0, 0.25%, 1%, 1% 对应每个任务 1,000 条. 结果是在 1% 回放下, 模型几乎保持了旧数据集上的全部表现, 未见数据集上的零样本能力也得以保持. 论文还观察到, 模型能把学过的指令以训练中从未出现的方式组合起来. 论文把成功归因于自监督预训练. 这个结论与 Ibrahim et al. 的继续预训练实验一致: 对一个已经在大量数据上训练过的模型, 很少的回放就够了. **微调与安全对齐.** Qi et al. (2023) 研究了微调对安全对齐的影响, 把风险分为三级:

1. **显式有害样本**: 用 10 条对抗设计的有害样本微调 GPT-3.5 Turbo, 通过 OpenAI 的接口花费不到 0.20 美元, 模型就会响应几乎所有有害指令.
2. **身份转换数据**: 微调数据不含有害内容, 但让模型总以肯定的前缀开头回答.
3. **良性数据**: 只用 Alpaca, Dolly, LLaVA-Visual-Instruct 这类常用的良性数据集微调, 安全对齐也会被削弱, 程度较轻.

论文认为第三种情况可能来自对初始对齐的灾难性遗忘, 也可能来自有用性与无害性之间的固有张力. 从持续学习的角度看, 安全对齐是模型的一项「旧能力」, 每次微调后都应当和其他能力一起评测. TRACE 的 Safety Delta 就是为此设计的. **SFT 与继续预训练的边界.**

两者都可能更新同一组参数, 两者的监督信号不同. 继续预训练对完整文档做因果语言建模, 主要改变领域词汇、事实、文体与条件分布; SFT 把输入组织成指令和回答, 通常只让回答 token 计入损失, 主要学习「收到这种请求时怎样作答」. 因而领域文档上的 loss 下降不能直接推出指令遵循提高, SFT 基准提高也不能证明模型已系统吸收领域知识.

常见流水线是先用领域原文继续预训练, 再用少量领域指令做 SFT. 前一阶段解决覆盖面, 后一阶段建立调用知识的交互格式. 若只有结构化问答而没有大规模原文, 任务更接近 SFT; 若训练数据是新闻、论文或代码仓库的连续文本, 即使最终服务某个任务, 仍属于继续预训练. 两阶段都可能损害旧能力和安全对齐, 不能因为第二阶段数据「良性」就省掉安全回归测试. 比较两者时还要固定 tokenizer、模板、有效 token 数与更新参数范围, 否则无法把收益归因于目标函数本身.

## 3 冻结骨干的参数高效方法

**记号与思路.** LoRA (Hu et al., 2022) 冻结预训练权重 $W_0\in\mathbb{R}^{d\times k}$, 只训练一个低秩增量:

$$
W = W_0 + BA, \qquad B\in\mathbb{R}^{d\times r},\ A\in\mathbb{R}^{r\times k},\ r\ll\min(d,k) \tag{1}
$$

本文统一用这套记号: $A$ 是降维矩阵 (把输入从 $k$ 维投到 $r$ 维), $B$ 是升维矩阵. 注意 O-LoRA 和 InfLoRA 两篇论文的记号与此不同, 下文会逐一对应. 每个任务训练一组独立的 LoRA 或提示, 推理时按任务切换, 就是第 2.3 篇参数隔离在大模型上的形式. 每个任务的增量只有 $r(d+k)$ 个参数, 存储不是问题. 问题回到两处: 推理阶段如何知道用哪一组 (路由), 以及如果多组同时生效, 它们之间如何不干扰. L2P 处理前者, O-LoRA 和 InfLoRA 处理后者. **L2P: 提示池.** Wang et al. (2022) 的 Learning to Prompt 冻结 ImageNet 预训练的 ViT-B/16, 维护一个提示池 $\mathbf{P} = \{P_1, \dots, P_M\}$, 每个提示 $P_i\in\mathbb{R}^{L_p\times D}$ 配一个可学习的键 $k_i$. 对输入 $x$, 先用冻结的 ViT 算出查询特征 $q(x)$ (取 [CLS] 的输出), 再按匹配函数 $\gamma$ (余弦距离) 选出最近的 $N$ 个键:

$$
\mathbf{K}_x = \operatorname*{arg\,min}_{\{s_i\}_{i=1}^{N}\subseteq[1,M]}\ \sum_{i=1}^{N}\gamma\big(q(x), k_{s_i}\big) \tag{2}
$$

对应的 $N$ 个提示拼在输入嵌入前面, 送入 ViT, 取提示位置输出的平均做分类. 训练目标是

$$
\min_{\mathbf{P}, \mathbf{K}, \phi}\ \mathcal{L}\big(g_\phi(f_r^{\text{avg}}(x_p)), y\big) + \lambda\sum_{s_i\in\mathbf{K}_x}\gamma\big(q(x), k_{s_i}\big) \tag{3}
$$

第一项是分类损失, $g_\phi$ 是分类头; 第二项把被选中的键拉向查询特征, 使相似的输入选中相同的提示. 论文还可以加一个选择频率的惩罚, 让不同任务倾向于使用不同的提示. L2P 不需要任务标识, 路由由键和查询的匹配决定. Split CIFAR-100 (10 个任务, 每个任务 10 类, Class-IL) 上取 $M=10$, $N=5$, $L_p=5$, 新增参数 46,080 个, 约为骨干的 0.05%. 论文 Table 1 的结果 (平均准确率 / 遗忘, %):

| 方法 | 缓冲区 | 平均准确率 | 遗忘 |
|------|------|------|------|
| FT-seq-frozen | 0 | 17.72 | 59.09 |
| FT-seq | 0 | 33.61 | 86.87 |
| EWC | 0 | 47.01 | 33.27 |
| LwF | 0 | 60.69 | 27.77 |
| L2P | 0 | 83.83 | 7.63 |
| ER | 每类 10 | 67.87 | - |
| DER++ | 每类 10 | 61.06 | - |
| L2P-R | 每类 10 | 84.21 | - |
| ER | 每类 50 | 82.53 | - |
| DER++ | 每类 50 | 83.94 | - |
| L2P-R | 每类 50 | 86.31 | 5.83 |
| 上界 (联合训练) | - | 90.85 | - |

论文称对比方法在同一环境下实现. 不存样本的 L2P 与每类存 50 个样本的 ER 相当. 5-datasets 基准上 L2P 为 81.14%. 在 CORe50 的 Domain-IL 设定下, 不存样本的 L2P 为 78.33%, 低于每类存 50 个样本的 ER (80.10%), 上界为 82.15%; 在类别分布随时间平滑变化的 Gaussian scheduled CIFAR-100 (任务无关设定) 上, L2P 为 88.34%, 高于同设定下存样本的 ER (82.63%). **O-LoRA.** Wang et al. (2023) 的 O-LoRA 为第 $t$ 个任务新建一组 LoRA, 之前各组冻结. 论文的 LoRA 记号是 $\Delta W = AB$, 其中 $A\in\mathbb{R}^{d\times r}$ 是升维的一侧, 对应式 (1) 里的 $B$. 论文假设 LoRA 的列空间能刻画任务的梯度子空间, 要求新旧任务的子空间正交:

$$
O_{i,t} = A_i^\top A_t = 0 \tag{4}
$$

用式 (1) 的记号, 就是 $B_i^\top B_t = 0$. 训练目标在任务损失上加正交惩罚:

$$
\mathcal{L} = -\sum_{(x,y)\in\mathcal{D}_t}\log p_\Theta(y\mid x) + \lambda_1\sum_{i=1}^{t-1}\sum_{j,k}\big\|O_{i,t}[j,k]\big\|^2 \tag{5}
$$

LoRA 只加在注意力的 $W_q$ 和 $W_v$ 上. 推理阶段所有 LoRA 组同时生效, 不需要任务标识. 实验用 T5-large, 两个基准: 标准 CL 基准 (AG News, Amazon, Yelp, DBpedia, Yahoo 五个文本分类任务, 3 种顺序) 和 15 任务的长序列 (再加 GLUE 的 4 个, SuperGLUE 的 5 个和 IMDB, 每个任务 1000 条训练样本), 结果取 3 次运行均值. 论文 Table 2 的平均准确率 (%):

ProgPrompt 在 15 任务上更高, 但它为每个任务存一个提示, 推理时用任务标识选择, 与 PerTaskFT 一样依赖任务标识. **InfLoRA.** Liang & Li (2024) 的 InfLoRA 全称 Interference-Free Low-Rank Adaptation. 它的记号是 $W_t = W_{t-1} + A_tB_t$, 其中 $B_t\in\mathbb{R}^{r\times d_I}$ 是降维矩阵, $A_t\in\mathbb{R}^{d_O\times r}$ 是升维矩阵, 对应式 (1) 的 $A$ 和 $B$.

InfLoRA 与 LoRA 的区别在于降维矩阵不训练. 学第 $t$ 个任务前, 先设计好 $B_t$ 并冻结, 只训练 $A_t$ (初始化为零). 论文证明, 只训练 $A_t$ 等价于在 $B_t$ 的行空间 $\mathrm{span}\{b_1^t, \dots, b_r^t\}$ 内微调预训练权重. 只要让这个子空间与旧任务的梯度正交, 新任务的更新就不会干扰旧任务. 这个等价关系可以直接推出来. 层的输出为 $e = W_{t-1}h + A_tB_th$, 由链式法则, $A_t$ 的梯度为

$$
\frac{\partial\mathcal{L}}{\partial A_t} = \frac{\partial\mathcal{L}}{\partial e}\, h^\top B_t^\top \tag{5a}
$$

学习率为 $\eta$ 时 $A_t$ 走一步, 等效权重的变化是

$$
\Delta W = -\eta\,\frac{\partial\mathcal{L}}{\partial e}\,h^\top B_t^\top B_t = -\eta\,\frac{\partial\mathcal{L}}{\partial W}\,B_t^\top B_t \tag{5b}
$$

其中 $\frac{\partial\mathcal{L}}{\partial W} = \frac{\partial\mathcal{L}}{\partial e}h^\top$ 正是直接微调 $W$ 时的梯度. $B_t$ 的行正交归一时, $B_t^\top B_t$ 是投影到其行空间的投影矩阵, 所以 $\Delta W$ 的每一行都被投影进 $\mathrm{span}\{b_1^t,\dots,b_r^t\}$. 由式 (5b) 还能看出为什么正交就不干扰. 设 $h_{\text{old}}$ 是旧任务在这一层的某个输入, 如果 $B_t$ 的每一行都与 $h_{\text{old}}$ 正交, 那么 $\Delta W\,h_{\text{old}} = -\eta\,\frac{\partial\mathcal{L}}{\partial W}B_t^\top (B_t h_{\text{old}}) = 0$. 新任务的更新完全不改变这一层在旧任务输入上的输出. 线性层的梯度可以写成「输出误差乘以输入」, 所以旧任务梯度张成的空间就是旧任务输入张成的空间, DualGPM 维护的正是这组输入的基. $B_t$ 的设计分三步. 记新任务的输入矩阵为 $H_t = [h_1^t, \dots, h_n^t]$, 用它的列空间近似新任务的梯度空间 $\mathcal{N}_t$. 旧任务的梯度空间 $\mathcal{M}_t$ 用 DualGPM 维护一组正交基 $M_t$. 先去掉 $H_t$ 在 $\mathcal{M}_t$ 上的分量:

$$
\hat H_t = H_t - M_t M_t^\top H_t \tag{6}
$$

$\hat H_t$ 的每一列都落在 $\mathcal{N}_t \cap \mathcal{M}_t^\perp$ 里. 再对 $\hat H_t^\top$ 做 SVD, $\hat H_t^\top = V_t\Sigma_t U_t$, 取最大的 $r$ 个奇异值对应的行:

$$
B_t = (U_t)_r \tag{7}
$$

这样 $B_t$ 的行既在新任务的输入空间里 (可塑性), 又与旧任务的梯度空间正交 (稳定性). 随着任务增多, $\mathcal{M}_t$ 扩大, 留给新任务的空间缩小; 论文通过调节 DualGPM 对旧任务梯度的近似误差, 让 $\mathcal{M}_t$ 慢慢扩大. 实验用 ImageNet-R (200 类, 分成 5, 10, 20 个任务), CIFAR100 和 DomainNet, Class-IL 设定, 结果取 5 次运行均值. ImageNet-R 上学完全部任务后的准确率 (论文 Table 1, %):

O-LoRA 用惩罚项鼓励正交, 正交程度取决于 $\lambda_1$; InfLoRA 在训练前就把可更新的子空间限定在旧任务梯度的正交补里, 是硬约束. 两者都不需要回放旧数据.

两者约束的位置也不同. 用式 (1) 的记号, O-LoRA 约束的是升维矩阵 $B$ 的列空间, 即增量 $\Delta W$ 写入输出的方向: 新任务的增量只往旧任务增量没有用过的输出方向写. 但新任务的 LoRA 对旧任务的输入依然生效, 旧任务样本经过这一层时, 输出会多出一个与旧增量正交的分量, 这个分量经过后续层仍可能改变预测. InfLoRA 约束的是降维矩阵的行空间, 即增量读取输入的方向: 只要旧任务的输入落在旧梯度子空间里, 新增量对它们的输出就是零. 后者的「不干扰」在单层上是精确的, 代价是可用的子空间随任务增多而缩小. **参数与优化器显存构成.**

参数高效指的是可训练参数少, 不等于训练总显存或计算按同样比例下降. 对 $W_0\in\mathbb R^{d\times k}$, LoRA 有 $r(d+k)$ 个参数; 宽度为 $d$、瓶颈为 $b$ 的串联 adapter 约有 $2db$ 个参数; 长度为 $\ell$ 的 soft prompt 有 $\ell d$ 个参数. 若提示池有 $M$ 个长度为 $\ell$ 的提示, 每个提示另配一个 $d$ 维键, 总数为 $M\ell d+Md$.

混合精度 Adam 通常为每个可训练参数保存 2 字节 BF16 权重、2 字节梯度、4 字节 FP32 主副本和两个各 4 字节的一二阶矩, 合计约 16 字节. 具体实现可能分片、量化或省去主副本, 所以 16 字节是预算模型, 不是硬件定律. 冻结骨干无需梯度和优化器状态, 但仍需存放权重并完成前向、反向的激活传播; 激活、临时张量和注意力开销不会随可训练参数同比缩小.

形状也决定实现能否成立. 输入激活 $X\in\mathbb R^{B\times L\times k}$ 先乘 $A\in\mathbb R^{r\times k}$ 的转置得到 $B\times L\times r$, 再乘 $B\in\mathbb R^{d\times r}$ 的转置回到 $B\times L\times d$. 这里第一个 $B$ 是批量大小, 与 LoRA 矩阵 $B$ 同名但含义不同. 单层 LoRA 额外乘加量与 $BLr(k+d)$ 同阶, 全量投影与 $BLkd$ 同阶; $r\ll d,k$ 时增量较小, 但骨干的 $BLkd$ 并未消失. soft prompt 把序列从 $L$ 拉长到 $L+\ell$, 自注意力分数矩阵从 $L\times L$ 变为 $(L+\ell)\times(L+\ell)$, 因而长提示的代价不能只按 $\ell d$ 个参数估算.

**算例二: 同一投影上的几种适配器.** 对 $4096\times4096$ 投影使用秩 $r=8$ 的 LoRA, 可训练参数为 $8(4096+4096)=65,536$, 是全矩阵 16,777,216 个参数的 $0.390625\%$. 按每参数 16 字节, 训练状态约为 1 MiB; 原 BF16 投影本身仍占 32 MiB. 若用 $b=64$ 的 adapter, 参数约为 $2\times4096\times64=524,288$, 训练状态约 8 MiB. 长度 20 的单个 soft prompt 有 81,920 个参数, 约 1.25 MiB; 若池中有 20 个提示并为每个提示保存 4096 维键, 则共有 1,720,320 个参数, 训练状态约 26.25 MiB. 这些数只比较参数状态容量: adapter 还增加层内计算, prompt 会拉长序列并增加注意力计算, LoRA 也没有消除骨干矩阵乘法, 因而不能由参数比例直接推断吞吐提升比例.

### 4 模型合并与评测

**Task Arithmetic.** Ilharco et al. (2023) 把微调后与预训练的参数差定义为任务向量 $\tau_t = \theta_t - \theta_{\text{pre}}$. 多个任务的合并为

$$
\theta_{\text{merged}} = \theta_{\text{pre}} + \lambda\sum_t \tau_t \tag{8}
$$

$\lambda$ 在验证集上选. 各任务独立微调, 合并时不需要任何训练数据. 从持续学习的角度看, 每来一个任务就独立微调一次, 再把任务向量加进去, 不存在顺序训练带来的遗忘; 代价换成了任务向量之间的干扰. **TIES-Merging.** Yadav et al. (2023) 指出干扰有两个来源: 冗余的小幅值参数, 以及不同任务在同一参数上的符号冲突. TIES-Merging 分三步:

1. **Trim**: 每个任务向量只保留幅值最大的 top-$k\%$ 参数, 其余置零. 论文的实验显示, 只保留 top-20% 的参数, 性能不下降.
2. **Elect Sign**: 对每个参数, 把各任务修剪后的值求和, 取和的符号作为合并后的符号 $\gamma_m = \mathrm{sgn}\big(\sum_t \hat\tau_t\big)$.
3. **Disjoint Merge**: 对每个参数, 只对符号与 $\gamma_m$ 一致的任务取平均:

$$
\tau_m^p = \frac{1}{|\mathcal{A}^p|}\sum_{t\in\mathcal{A}^p}\hat\tau_t^p, \qquad \mathcal{A}^p = \{t : \hat\gamma_t^p = \gamma_m^p\} \tag{9}
$$

合并结果为 $\theta_{\text{pre}} + \lambda\tau_m$. **DARE.** Yu et al. (2024) 的 DARE 对每个 SFT 模型的 delta 随机丢弃比例 $p$, 剩下的乘以 $1/(1-p)$:

$$
\tilde\delta = \frac{m\odot\delta}{1-p}, \qquad m_i\sim\mathrm{Bernoulli}(1-p) \tag{10}
$$

缩放保证了 delta 的期望不变. 论文报告 DARE 能去掉 90% 甚至 99% 的 delta 而性能基本不变, 但缩放是关键: 不缩放时只丢 30% 或 40% 就会明显变差. DARE 作为预处理, 可以接在 Task Arithmetic 或 TIES 前面, 先稀疏化再合并, 减少参数干扰. 论文合并 WizardLM-13B, WizardMath-13B 和 llama-2-13b-code-alpaca, 论文报告用 DARE 加 Task Arithmetic 合并后, LM 与 Code 合并模型的 MBPP 比单独的 Code 模型提高 19.57%. 第 1.1 节已经提到, 继续预训练后 delta 可达 0.03 左右, DARE 不再适用. **与顺序训练的比较.**

| 维度 | 顺序训练的持续学习 | 模型合并 |
|------|------|------|
| 训练方式 | 按顺序逐个任务训练 | 各任务从同一基座独立微调 |
| 是否需要旧数据 | 视方法而定 | 不需要 |
| 对任务顺序是否敏感 | 敏感 | 不敏感 |
| 失败方式 | 遗忘, 或可塑性不足 | 任务向量冲突, 合并后各任务都变差 |
| 前提 | 无 | 各任务从同一基座出发, 增量较小 |

模型合并要求所有任务都从同一个基座微调. 如果第二个任务必须建立在第一个任务的结果上 (例如先做领域继续预训练, 再在该领域上做指令微调), 合并就无从谈起. 它适合的是「同一个基座, 若干互相独立的下游能力」这类场景. **合并干扰的向量视角.**

任务向量相加不保证功能相加. 在局部线性近似下, 向量 $\tau_j$ 对任务 $i$ 损失的影响主要取决于 $g_i^\top\tau_j$; 更远处还受 Hessian 曲率和网络非线性影响. 两个向量余弦接近零, 只能说明参数空间里一阶方向近似正交, 不能证明输出互不干扰. 同一坐标符号相反会直接抵消, 这正是 TIES 要处理的情形. 例如 $\tau_1=(1,0)$, $\tau_2=(-1,1)$, 直接相加得到 $(0,1)$: 第二维能力被保留, 第一维更新完全抵消. 这只是二维示意, 不能据此预测真实任务准确率, 但说明合并前必须逐任务回测, 不能只看合并向量的范数.

LoRA 合并还要区分「合并增量」与「平均因子」. 两组增量是 $B_1A_1$、$B_2A_2$, 正确的线性合并为 $\alpha_1B_1A_1+\alpha_2B_2A_2$. 直接平均因子会得到 $\tfrac14(B_1+B_2)(A_1+A_2)$, 额外产生 $B_1A_2$ 和 $B_2A_1$ 两个交叉项, 一般不等价. 拼接因子可以精确保留增量和, 但秩随任务数增长; 再用截断 SVD 压回固定秩会引入近似误差. 所以「每个 adapter 单独有效」不能推出合并后仍有效, 「压缩误差小」也不能推出每个任务的功能误差都小. **评测应增加什么.**

无论用顺序训练还是合并, 大模型的持续学习评测在第 3.1 篇的准确率矩阵指标之外, 还要覆盖三类能力. 第一类是通用能力, 即序列之外的通用基准, 例如 TRACE 的 General Ability Delta; GSM8K 从 28.8% 掉到 2% 这种退化只有在这里才看得到. 第二类是指令遵循与安全, 每次更新后都要评测, 良性数据微调之后也不例外. 第三类是上游 loss: 继续预训练时报告旧语料上的验证 loss. 它与下游能力不完全一致, 两者都要看.

另外三项属于实验记录. 资源方面, 报告每个阶段的 token 数, 回放比例, 可训练参数, 以及学完全部任务后的总参数 (含全部 LoRA, 提示和路由). 数据污染方面, 检查训练语料与评测集是否重叠. 任务顺序方面, O-LoRA 在标准基准上报告了 3 种顺序, 只跑一种顺序的结果不够.

### 5 可回滚训练与评测协议

汇总值必须与逐任务明细一起保存, 才能复核结论究竟来自哪些能力变化, 也便于下一轮训练定位回归来源. 持续更新必须能够还原. 每一阶段固定基座 checkpoint、tokenizer、数据清单及哈希、混合权重、随机种子、优化器与学习率日程; 保存阶段入口和候选出口 checkpoint. 对 LoRA 或提示方法, 基座保持只读, 适配器使用版本化目录, 上线切换只改变版本指针. 这样退回上一适配器是原子操作; 若已把增量永久写回骨干而没有保留基座, 就失去了低成本回滚的优势.

评测应形成一张「阶段 × 能力」矩阵. 每完成一个数据段, 同时测新域 loss/任务指标、旧域 loss/旧任务、序列外通用能力、指令遵循和安全集, 并记录每域有效 token 与训练成本. 继续预训练至少保留「不回放」与若干回放比例作为算力等价对照, 总 token 预算必须相同; 参数高效方法要同时报告当前阶段可训练参数和累计保存参数. 有多种任务顺序时应重复实验, 随机性显著时报告多次运行而不是挑最好一次.

矩阵还应保存逐项结果, 不只保存宏平均. 宏平均把每个任务等权, token 加权平均则让大语料主导, 两者回答的问题不同. 若一个候选在九个常见任务上各提高一点、却让一个关键安全任务大幅下降, 单个平均数可能仍然好看. 因此发布门槛应包含不能被平均抵消的硬约束, 同时保留基线与候选的原始生成供人工抽查. 对生成任务要固定解码参数和提示模板; 温度、采样种子或聊天模板变化都可能制造看似由训练带来的差异. 对路由型方法还要单列「已知任务标识」和「自动路由」两种结果, 前者衡量适配器本身, 后者才衡量完整系统.

上线门槛在训练前确定, 不能看到结果后移动. 一个实用流程是: 先在固定旧能力集上保存基线; 再用小规模训练验证 loss 曲线、数据管线和回放计数; 随后训练候选 checkpoint; 候选只有在新域收益达标且旧能力、安全退化没有越过预设阈值时才进入影子或小流量验证; 任一硬门槛失败便回到上一 checkpoint, 调整数据配比后重新训练. 回滚后仍要保存失败版本的配置与评测, 否则下一轮会重复同一实验.

比例消融还要避免预算偷换. 假设每个候选都训练 10 亿有效 token, 0%、5%、25% 回放分别意味着新域 token 为 10 亿、9.5 亿、7.5 亿, 旧域 token 为 0、0.5 亿、2.5 亿. 这样比较回答的是「固定总算力下如何分配」; 若在 10 亿新域 token 之外再追加回放, 回放越多总算力越高, 得到的是另一问题. 两种实验都可以做, 但必须分开命名和报告. 评测集本身也要版本化: 新旧语料若泄漏进测试集, loss 改善可能只是记忆; 时间型知识则要把已变化事实与未变化事实分开, 否则平均分会掩盖更新成功但旧知识受损的情况.

还要区分可观察结论的边界. 旧域困惑度恶化提示分布遗忘, 不能精确说明哪个事实错了; 问答准确率保持不能证明生成分布未漂移; 冻结骨干只能说明骨干参数没变, 若路由选错提示或多个 adapter 同时干扰, 旧任务仍会失败; 合并前各模型单独通过也不能替代合并后的全套回归. 可回滚协议无法保证更新永不失败, 但能让失败被发现、定位并安全撤销.

## 6 数据混合决定训练目标

**文档比例、token 比例与梯度比例.** 设旧语料与新领域语料的 token 风险为 $L_o,L_n$, 以 token 比例 $\rho$ 混合时目标为

$$
L_\rho(\theta)=\rho L_o(\theta)+(1-\rho)L_n(\theta). \tag{11}
$$

文档等量不等于 token 等量. 新领域文档更长, 按文档采样会让它贡献更多损失 token; 序列打包、截断与 loss mask 又会改变有效梯度比例. 报告 replay 比例时必须说明采样单位和损失归一化. 训练数据比例也不直接等于梯度贡献. 某域损失更高、梯度范数更大, 少量 token 也可能主导更新. 可记录每域梯度范数与余弦, 得到实际冲突. 只看语料配比无法解释能力退化. **混合比例的闭式反例.** 用一维二次近似表示旧域与新域:

$$
L_o(\theta)=\frac{a}{2}(\theta-\theta_o)^2,
\qquad L_n(\theta)=\frac{b}{2}(\theta-\theta_n)^2. \tag{12}
$$

混合目标最优点为

$$
\theta_\rho^*=\frac{\rho a\theta_o+(1-\rho)b\theta_n}
{\rho a+(1-\rho)b}. \tag{13}
$$

即使旧 token 占 90%, 若新域曲率 $b$ 是旧域 $a$ 的 100 倍, 新域仍可主导最优点. 数据比例与保护强度之间隔着损失曲率. 多维情况下每个方向都有不同有效比例. **重采样改变部署权重.** 过采样新领域等于声明部署更重视新域. 如果最终用户流量仍以通用域为主, 训练目标与部署风险错位; 若新领域价值高, 过采样合理. “避免遗忘”的参照必须由部署分布给出.

长尾能力需要最低配额. 安全数据、低资源语言和少见工具调用在自然 token 流中比例极低, 均匀回放无法稳定保持. 分层采样提高它们权重, 可能改变普通回答风格或增加过度拒答. 多维保持集必须与混合曲线一起评估.

### 7 学习率、步数与参数位移

**重新预热为何有用.** 继续预训练从已收敛 checkpoint 开始, 原训练末期学习率通常很低. 直接沿用可能无法适应新域; 突然恢复过大学习率又会离开旧解盆地. 学习率重新预热让优化器矩与梯度尺度逐步适应, 其作用是控制早期参数位移, 没有直接保存旧知识. 小步近似下, $K$ 步位移为 $\Delta\theta\approx-\sum_{k=1}^K\eta_kg_k$. 遗忘取决于旧损失梯度与位移方向、累计步长和曲率. 相同峰值学习率, 不同 warmup 与总步数可以产生完全不同位移. **优化器状态的影响.** 保留 Adam 状态时, 新域梯度会被旧二阶矩缩放; 清空状态时, 早期有效步长可能变大. 只比较名义学习率会误判. 应报告是否继承动量、二阶矩与 scheduler 步数. 手算单参数 Adam: 旧二阶矩 $v=100$, 新梯度 $g=1$, 更新约为 $\eta/10$; 清空后 $v\approx1$, 更新约为 $\eta$. 同一学习率产生十倍位移. 优化器状态是持续预训练的隐藏记忆. **将遗忘归因给学习率.** 设计等位移对照: 不同学习率与步数组合达到相近 $\|\Delta\theta\|$, 比较旧能力. 若结果相近, 主要由位移规模决定; 若不同, 路径与梯度顺序有额外作用. 再按层测位移, 总范数相同也可能集中在关键层.

早停与回放交互. 回放降低旧梯度偏移, 大学习率仍可能越过局部稳定区域; 极小学习率让任何方法看起来稳定, 新领域尚未学会. 稳定性必须在匹配新域性能或收敛程度下比较.

### 8 领域适配与知识写入

**领域语言建模不等于任务能力.** 新域困惑度下降说明模型更会预测领域 token, 不保证问答、推理或工具使用提高. 模型可能只学到术语频率和格式. 需要闭卷任务、组合任务和反事实提示区分表面适配与可用知识. 一条新事实在训练文本出现, 模型可能记住句子, 也可能只在相似前缀下复述. 改写实体、查询方向和上下文位置, 检查是否形成可迁移表示. 训练损失不能单独证明知识内化. **开卷、闭卷与检索.** 开卷给文档时答对, 说明模型能在上下文使用信息; 关闭文档仍答对, 才支持参数内化. RAG 索引保存知识, 参数只学检索与阅读策略. 两种系统能力都重要, 更新位置不同.

可做四格: 更新前/后参数乘检索开/关. 检索开启提高、闭卷不变, 收益在外部记忆; 闭卷提高, 知识进入参数; 两者都提高, 联合系统与模型同时变化. 若更新后必须检索原训练文档才能答对, 不宜称为内化. **内化的副作用.** 写入参数会与旧事实冲突, 来源和时间难追踪. 新版本事实覆盖旧版本后, 历史问答可能退化. 将时间或版本放进条件, 或把易变事实留在检索库, 能降低冲突. 参数记忆无法单条删除. 对隐私、授权或频繁更新知识, 外部存储更易治理. 持续预训练适合稳定、广泛复用的规律, RAG适合可引用、可撤回的具体事实. 选择依据是生命周期, 不只是准确率.

## 9 PEFT 的统一子空间视角

**低维参数化.** 令全参数更新为 $\Delta\theta=J_\phi\Delta\phi$, 其中 $\phi$ 是 adapter、prompt 或 LoRA 参数, $J_\phi$ 将低维更新映射到模型参数或激活空间. PEFT限制可达更新子空间, 降低全局漂移, 同时可能排除新任务所需方向. LoRA 对单矩阵限制 $\mathrm{rank}(\Delta W)\le r$; adapter在层间插入瓶颈非线性; prompt改变注意力输入而不直接改权重. 相同参数量的三者可达函数集合不同, 不能只按可训练参数百分比比较. **低秩冲突的手算.** 二维矩阵两个任务分别需要

$$
\Delta W_1=\begin{bmatrix}1&0\\0&0\end{bmatrix},\qquad
\Delta W_2=\begin{bmatrix}-1&0\\0&1\end{bmatrix}. \tag{14}
$$

两个更新在 $(1,1)$ 坐标冲突. 简单相加保留第二任务右下角能力, 抵消第一任务左上角能力. 为任务独立路由可同时保存; 强制正交子空间可能把第二任务的共享有用方向也删除. **rank 与表达瓶颈.** 增加 rank 提高可达维数, 参数和优化器状态线性增加. 实际 $BA$ 的奇异值可能集中, 名义 rank 不等于有效 rank. 报告谱与 rank 消融, 判断性能饱和来自数据、优化还是子空间容量. 新任务需要改变多个层时, 只在注意力投影加 LoRA 可能不足; 全层 LoRA提高能力和干扰面. 层选择同样是容量分配, 应与相同参数量的均匀分配比较.

### 10 Prompt 与 Adapter 的路由

**prompt pool 的选择误差.** L2P 用输入查询选择提示. oracle 提示与真实检索差距分开衡量提示能力和路由. 查询表征来自冻结底座, 若新域超出预训练分布, 相似度可能按风格而非任务语义聚类. 提示池容量固定时, 多任务争用 key; 增长提示池时, 检索成本和存储随任务增加. key坍缩让多个提示集中到相似区域, 负载均衡可提高利用, 也可能阻止合理共享. **adapter 组合.** 每任务 adapter 提供清晰隔离, 需要任务身份. AdapterFusion 或加权组合允许技能复用, 融合权重必须用跨任务数据训练. 未见技能组合上的泛化是关键测试. 底座升级后 adapter 输入表示改变. 参数文件不变, 功能仍会漂移. 在新旧底座上交叉评测, 区分底座收益、模块兼容性与重训成本. **prompt 是否真的学到知识.** prompt 参数容量小, 可存任务线索与输出格式, 也可能记住有限事实. 将 prompt 换到同底座的新查询、改写任务描述和实体, 测知识迁移. 若只在训练模板有效, 它更像路由或格式适配.

拿掉 prompt 后底座闭卷能力不变, 说明知识没有进入基础参数. 这不构成失败, 但知识生命周期属于外接模块. 删除 prompt 可撤回, 合并进底座后则需要重新验证.

### 11 正交低秩子空间的边界

**参数正交与函数正交.** $B_i^\top B_j=0$ 限制两个 LoRA 输出子空间正交, 实际函数变化还乘输入激活与下游 Jacobian. 参数正交不能保证输出变化内积为零. 更直接的量是在输入分布上测

$$
\mathbb E_x\left\langle J(x)\Delta\theta_i,
J(x)\Delta\theta_j\right\rangle. \tag{15}
$$

这个量依赖数据与当前模型, 估计需要代表性输入. O-LoRA 用参数几何换取无回放约束, 近似边界应通过行为干预验证. **正交会阻止正迁移.** 两个任务共享一个有用方向时, 强制新更新与旧子空间正交, 新任务必须用效率更低的替代表示. 任务越相关, 正交代价可能越大. 比较无约束、软正交与硬正交的稳定—可塑性曲线, 不能只看遗忘. 软惩罚系数决定共享程度. 系数过小产生干扰, 过大产生顽固性. 超参数不能用未来任务选择, 应在独立任务序列或已见验证集固定. **子空间估计误差.** InfLoRA 从激活或梯度协方差估计重要子空间. 样本有限时主方向有方差, 特征值接近时特征向量不稳定. 估计错的正交补会删除有用方向或放过冲突方向.

增加样本降低方差, 任务分布漂移仍会使旧子空间过时. 报告谱间隙、不同样本子集的子空间角度与最终行为, 能判断几何估计是否可信.

### 12 模型合并的线性假设

**任务向量为何可能相加.** 各任务从共同基座 $\theta_0$ 微调得到 $\theta_t=\theta_0+\tau_t$. 若所有解位于同一近似线性盆地, 函数变化可一阶写为 $J_{\theta_0}\tau_t$, 相加任务向量近似相加函数变化. 更新过大、激活模式改变或分支进入不同盆地时, 一阶近似失效. 继续预训练的参数位移通常大于轻量 SFT, 合并风险更高. “共同基座”只保证起点相同, 没有保证终点可线性连接. **符号冲突与裁剪.** TIES先裁剪小增量, 再按坐标多数符号合并. 小增量可能是噪声, 也可能由大量坐标共同实现重要功能; 多数符号反映任务数量, 不反映任务价值. 方法把冲突从连续值简化成坐标投票. 构造三个任务, 两个低价值任务在某坐标为 $+1$, 一个高价值任务为 $-2$. 多数投票选正, 加权部署目标可能应选负. 合并权重需要与任务价值对应. **DARE 的无偏性与方差.** DARE 对增量随机置零并除以 $1-p$, 单坐标期望保持:

$$
\mathbb E\left[\frac{m_i\delta_i}{1-p}\right]=\delta_i. \tag{16}
$$

方差为 $\delta_i^2p/(1-p)$, $p$ 越高噪声越大. 无偏只针对参数增量, 非线性网络输出的期望不等于原输出. 小增量和冗余参数使近似成立, 大更新时随机丢弃会破坏功能.

## 13 底座升级与模块漂移

**adapter 绑定底座坐标.** adapter 或 LoRA 在底座 $W_0$ 的激活与 Jacobian 上训练. 将同一增量加载到 $W_1$ 后, 输出变化从 $J_{W_0}\Delta\phi$ 变成 $J_{W_1}\Delta\phi$. 即使矩阵 shape 相同, 功能也可能改变. 交叉矩阵评测包括旧模块配旧底座、旧模块配新底座、新模块配旧底座和新模块配新底座. 新底座单独能力上升、旧模块组合退化, 说明接口漂移; 新旧模块都退化, 可能是任务或评测变化. **迁移模块的方法.** 可在新底座上用旧模块输出蒸馏新模块, 需要代表性查询数据; 也可学习坐标映射, 假设两底座表示可对齐; 最可靠的是用原任务数据重训, 数据可能不可得. 每种迁移都重新引入历史证据需求. 保持底座永久冻结避免漂移, 通用能力无法随时间更新. 实际系统可周期性升级底座, 将模块库迁移并经过密封回归. 升级成本要摊入持续学习预算. **tokenizer 与接口变化.** tokenizer、位置编码、系统提示和工具 schema 都是模块接口. 新 tokenizer 改变 token 序列, prompt 与 adapter 所见激活随之变化. 仅复制权重不能保证兼容.

版本元数据应记录底座、tokenizer、模板和依赖. 兼容测试包含原输入、格式改写和长上下文. 接口变化造成的退化应与参数遗忘分开报告.

### 14 知识内化的判别

**闭卷迁移.** 训练阶段提供新文档, 测试阶段移除文档、检索与同义缓存. 在改写问题、反向查询和组合推理上成功, 支持知识进入可调用参数路径. 只复述训练句子说明记忆, 尚未证明组合使用. 加入未训练但结构相同的控制事实, 检查提升是否来自一般领域适配. 若所有题都提高, 可能学到格式或术语; 只有目标事实提高, 更接近具体写入. **反事实更新.** 给模型一个与预训练知识冲突的合成事实, 例如“实体 A 的属性从红改为蓝”, 测新事实、旧事实、无关事实和时间条件. 模型若两种答案随机混合, 写入不稳定; 始终新答但历史问题也新答, 缺少时间条件化. 反事实数据应明确是实验世界, 避免与现实真值混淆. 它的价值在于知道正确更新是什么, 能精确测覆盖与副作用. **参数、模块与检索三种载体.** 分别关闭 LoRA/prompt、关闭 RAG、回滚底座, 构造载体开关. 性能随哪个开关消失, 说明能力依赖哪个状态. 多载体同时存在时, 可测冗余与冲突.

删除某条外部记忆后闭卷仍答对, 可能已经内化; 回滚 adapter 后消失, 知识在模块. 这些因果开关比模型自述“记住了”更可靠.

### 15 持续预训练的统计实验

**多个数据顺序与混合种子.** 语料 shard 顺序影响梯度路径, 混合采样影响每域暴露. 多个随机种子应覆盖初始化相同情况下的 shard 顺序、混合器和 dropout. 只换推理采样种子无法估计训练方差. 领域到达顺序作为更高层随机变量. 相似域相邻与冲突域相邻可能产生不同遗忘. 报告每个顺序的配对差与总体区间, 不把所有 checkpoint 当独立样本. **学习曲线与面积.** 每隔固定 token 测新域、旧域、通用能力和安全保持. 最终分数相同的两种方法, 一个前期严重退化后恢复, 另一个平稳, 部署风险不同. 曲线面积与最差点补充终点指标. 评测频率应按 token 而非 step 对齐, 不同 batch 与序列长度的 step 不可比. 高频评测若用于早停, 评测集已经参与训练选择, 查询次数需要记录. **因果消融.** 比较新域纯训练、数据混合、同 token 的低学习率、同位移的短训练和 PEFT. 数据混合优于同位移对照, 才支持 replay 信号; PEFT 优于全量等位移, 才支持子空间限制.

将旧语料替换为等 token 的无关语料, 检查收益来自旧知识还是一般正则. 打乱文档时间与来源, 测版本信息是否重要. 每个消融对应一个机制假设.

### 16 合并方法的可证伪验收

**单任务、联合与保持集.** 合并后分别测每个源任务、未参与合并的通用保持集和组合任务. 单任务保持说明没有明显覆盖, 组合任务测试能力能否共同调用. 平均分会掩盖某个任务完全消失. 与多 adapter 路由上限、联合训练和简单权重平均比较. 路由高、合并低, 冲突发生在参数叠加; 联合训练也低, 任务本身或模型容量冲突. **插值路径.** 在两个 checkpoint 之间取 $\theta(\alpha)=(1-\alpha)\theta_1+\alpha\theta_2$, 画各任务损失. 中间损失低支持同一盆地线性连接, 高障碍提示直接平均风险. 多任务合并可沿不同顺序插值, 顺序差异暴露非线性. 参数距离小不保证路径低损失, 距离大也可能存在低损失曲线. 插值是实际行为测试, 比只报余弦更直接. **冲突坐标干预.** 识别任务向量符号冲突坐标, 分别采用任务 1、任务 2、均值与置零, 测每任务变化. 若选择多数符号没有带来预期任务收益, 坐标冲突解释不足. 对随机同数量坐标做对照.

再将冲突分析从参数扩展到代表性输入上的输出变化. 参数冲突高、函数冲突低时, 裁剪可能删除无害自由度; 参数冲突低、函数冲突高时, 几何指标漏掉下游放大.

## 17 安全、隐私与可回滚性

**更新前的接受门槛.** 候选模型先在新域、通用保持、安全和隐私集上评测. 高风险指标采用约束门槛, 新域收益不能抵消越权或泄漏. 置信上界超过阈值时继续评估或拒绝更新. 保持集自身会被多轮选择适应, 定期引入密封变体. 查询日志与模型版本绑定, 防止同一集被无限调参. **checkpoint 与数据谱系.** 每次持续预训练记录基座、数据 shard、混合比例、优化器状态与代码版本. 回滚参数时也要回滚 tokenizer、adapter、索引和路由元数据. 只恢复权重可能留下不一致系统. 数据谱系支持定位错误事实与删除请求. 某 shard 污染后, 找到受影响 checkpoint 和派生模块, 决定局部遗忘或重训. 无谱系时只能整轮回滚. **PEFT 的撤回边界.** 独立 adapter 易删除, 若训练同时更新 LayerNorm、embedding 或共享 prompt, 影响留在底座. 报告实际可训练参数集合, 不以方法名称推断可撤回性.

多个 adapter 合并进底座后, 若不保留源增量与配方, 无法准确拆出. 可逆合并需要版本化任务向量, 额外存储换回滚能力.

### 18 多目标选择与资源前沿

**新域、旧域与通用能力.** 更新选择至少包含新域收益 $G_n$、旧域保持 $G_o$、通用能力 $G_g$ 和安全约束 $C_s$. 简单加权和需要人为权重, 允许大幅新域收益抵消安全退化. 高风险项更适合硬门槛, 其余指标画帕累托前沿. 同一方法改变混合比例、学习率、rank 和训练步数会得到一族点. 只报告最佳点隐藏了权衡. 使用者根据部署流量与风险选择, 研究者比较前沿是否整体外移. **计算与存储摊销.** 全量继续预训练成本高, 推理不增加模块; adapter训练便宜, 每任务增加存储和加载; RAG写入便宜, 每次推理增加检索与上下文. 比较总拥有成本需要预期请求数. 设更新成本 $C_u$, 每次推理额外成本 $c$, 使用 $N$ 次的总成本为 $C_u+Nc$. 全量训练可能在大 $N$ 时回本, 低频知识更适合外部模块. 成本结论必须附带使用规模. **数据权利与更新位置.** 允许用于上下文的数据未必允许训练参数, 允许短期缓存的数据未必允许跨用户保存. 数据许可直接限制 replay、RAG和内化路线. 技术上性能最高的写入位置可能不可用.

将数据权利作为约束字段: 可训练、可索引、可共享、保留期限与删除要求. 评测在合法可用方案之间比较, 避免用更宽松权限换分数. **频繁更新与批量更新.** 每来一批数据就训练, 适应延迟低, 固定开销与评测次数高; 积累后批量训练更稳定, 新知识上线慢. 更新频率还决定每次梯度规模和回滚粒度. 画数据到达后能力随时间的曲线, 包含等待、训练、验证与部署. 只报训练完成 checkpoint 忽略知识陈旧期. 频繁变化事实可能由 RAG即时更新, 稳定规律定期蒸馏. **何时停止继续训练.** 新域验证损失仍下降, 旧域和安全指标可能已越过可接受边界. 停止规则应联合多指标, 并使用不参与梯度的数据. 达到新域目标后继续训练只增加内化强度与遗忘风险.

训练曲线噪声会造成误停. 用置信区间、连续多次触发和最小改进阈值, 比单点阈值稳定. 停止规则在实验前固定, 避免事后选择最好 checkpoint.

### 19 完整的可证伪验收

**数据与版本固定.** 保存基座、tokenizer、优化器、语料快照、混合器和随机种子. 数据按来源、时间、语言、领域与许可分层. 最终测试密封, 开发查询次数记录. 对 replay 数据做近重复与谱系检查, 防止测试泄漏. 新事实集选择预训练截止后或合成随机映射, 确认基础模型零样本不会. **四组因果开关.** 参数更新开/关、PEFT模块开/关、检索开/关、文档上下文开/关形成因果组合. 每组使用相同问题, 分离底座内化、模块记忆、外部检索和临时阅读. 再做底座交换与模块交换. 模块只在原底座有效, 说明坐标绑定; 多底座可迁移, 支持更通用接口. 检索器交换分离索引覆盖和生成器使用能力. **学习率与数据混合网格.** 在若干学习率、总 token、旧数据比例上画三维前沿. 固定总 token时比较比例, 固定新域 token时比较额外 replay成本. 两种口径分别回答资源竞争和保持上限.

每个点报告参数位移、每层位移、域梯度夹角与优化器状态. 相同结果由不同机制得到时, 这些量帮助解释. **知识与能力分层.** 新域评测分为术语识别、闭卷事实、改写查询、组合推理、工具使用和分布外迁移. 逐层成功才能说明从表面适配走向可用知识. 同时测旧事实、旧推理和安全行为. 样本级记录获得、保持、覆盖和冲突. 新事实学会但相邻旧事实被改写, 属于局部副作用; 平均准确率可能看不到. **接受、回滚与复现.** 候选只有在主指标置信下界超过最低收益、风险指标上界低于阈值时接受. 边界情况增加评测, 不由点估计决定. 接受后保留前一版本与数据谱系. 独立运行重复训练, 再由另一环境复现关键结果. PEFT、全量训练与合并分别报告训练方差、推理方差和任务顺序方差. 失败运行也进入统计, 不只挑最佳 checkpoint.

一套能落地的验收表要把「训练了多少」说清楚. 设新域、回放与通用校准语料分别消耗 $T_n,T_r,T_c$ 个 token, 总预算为 $T=T_n+T_r+T_c$. 回放比例既可以写成 $T_r/T$, 也可以写成相对于新域的 $T_r/T_n$, 两者数值不同, 实验记录必须注明分母. 若新域有一百亿 token, 方案甲训练一遍新域并混入十亿旧域, 方案乙训练两遍新域并混入二十亿旧域, 二者的回放占比相同, 旧知识暴露次数也相同, 但新域梯度累计量相差一倍. 只按比例比较会误把训练时长的效果归给数据配方. 更稳妥的表格同时列出各域 token、独立文档数、重复轮数、有效 batch token 与参数更新次数.

固定混合比例也未必是最好的日程. 训练初期模型离新域较远, 可以让新域占比较高, 迅速降低明显的分布差异; 中后期再逐步提高回放比例, 限制继续漂移. 另一种次序是在开头先用少量通用数据恢复优化器统计, 再进入新域, 结束前用短暂的通用校准阶段收尾. 三种策略即使总 token 完全相同, 梯度路径仍然不同. 验收时应把恒定混合、前高后低、前低后高和分段校准放在同一预算下比较, 并记录每个阶段的旧域最差点. 若某种日程最终分数很好, 却在中途出现无法接受的安全退化, 它便不适合需要频繁发布中间 checkpoint 的系统.

回放样本如何抽取与回放多少同样重要. 均匀抽取会让高频网页和短文档主导批次; 按来源均衡会提高小来源权重, 却可能反复看到同一批材料. 可以先在来源内按文档长度或质量分层, 再在来源之间分配配额. 对于包含公式、代码和多语言文本的旧域, 保持 token 比例并不等于保持能力比例: 代码单元通常更长, 低资源语言在 tokenizer 下又可能产生更多 token. 应另外统计文档数、字符数、语言覆盖和任务覆盖. 若中文回放占 token 的百分之十, 但因为切词效率较低只覆盖了很少文档, 旧知识保持可能被高估或低估, 取决于评测更依赖词法熟悉度还是文档多样性.

近重复数据会同时污染「学会」与「没忘」两侧. 新域文档若是旧域材料的改版, 旧域分数保持并不能证明回放有效; 评测题若能在训练语料中找到模板化答案, 新域提升也不代表模型形成了可迁移能力. 去重需要在原始文档、规范化文本和语义片段三个尺度进行. 原始哈希能找到完全重复, 去标点和模板后的指纹能发现轻微改写, 语义近邻能找到结构相同但措辞变化的样本. 阈值过严会删除同一主题下真正独立的证据, 阈值过松又留下泄漏, 因此应抽样复核边界样本, 并把去重前后的训练量和评测变化一起报告.

文档时间也是持续预训练中的隐藏变量. 若新域语料来自较晚时间, 旧域语料来自较早时间, 模型可能把来源风格当成时间线索. 对更新事实的评测要区分「截至某日的答案」与「无时间限定的答案」, 否则旧事实仍然正确的历史问题会被算成错误. 针对同一实体, 可设计四类题: 询问旧时间点、询问新时间点、明确给出时间条件、故意省略时间条件. 理想模型在前三类题上遵守条件, 在第四类题上表达不确定性或采用约定的最新口径. 若训练只让模型无条件输出新答案, 它完成的是覆盖, 没有学会带版本的知识更新.

优化器状态要和参数一起成为实验对象. Adam 的一阶矩保存近期梯度方向, 二阶矩控制每个坐标的有效步长. 直接继承旧状态时, 新域第一批梯度可能被较大的历史二阶矩压小; 完全清零时, 某些坐标又会因二阶矩尚未建立而出现过大的有效更新. 可以比较保留全部状态、只清零一阶矩、只清零二阶矩、全部清零以及短暂重热身. 为了分离状态影响, 五组实验应从同一参数 checkpoint 出发, 看到相同的批次顺序, 并按实际参数位移而非训练步数对齐. 若清零状态组在相同位移下仍更快遗忘, 原因才更可能来自更新方向, 而非单纯走得更远.

学习率不能只记录峰值. 持续预训练通常从已经收敛的模型出发, 原训练末期的学习率可能很低, 直接重新使用大峰值会越过原有低损失盆地; 沿用极低学习率又可能只改变表层统计, 难以吸收新规律. 完整记录应包含初始学习率、重热身长度、峰值、衰减曲线、最小值、梯度裁剪和权重衰减. 一个有用的手算量是累计步长近似 $S=\sum_t\eta_t$, 另一个是带梯度范数的路径长度 $P=\sum_t\eta_t\lVert g_t\rVert$. 两条曲线峰值相同, 若重热身长度不同, $S$ 和 $P$ 可能相差数倍. 把结果画在 $P$ 而非 step 轴上, 可以初步判断收益究竟来自日程形状还是总更新强度.

有效 batch size 也会改变新旧域之间的竞争. 小 batch 保留更多梯度噪声, 有时能帮助模型离开狭窄解, 但会让稀有旧域样本的影响波动很大; 大 batch 使混合比例更稳定, 却可能让每一步都呈现相似的平均方向. 若总 token 固定而 batch 扩大, 更新次数随之减少, 优化轨迹不可直接相比. 应至少给出每次更新中新旧域样本数量的分布, 并检查某些 batch 是否完全没有回放数据. 分层组批可保证每步都有旧域证据, 但它改变了自然采样的协方差结构; 随机混合更忠于语料分布, 却可能连续多步只见新域. 两种组批方式需要单独做消融.

参数高效方法的比较必须先对齐可训练容量. LoRA 的 rank 从 8 增到 64, 可训练参数、表达子空间和优化难度都改变; adapter 的瓶颈宽度、插入层数与非线性同样决定容量; 软提示长度则影响可用的连续控制向量数量. 只写「LoRA 对 adapter」没有意义. 可以固定总可训练参数, 再比较不同放置位置; 也可以固定放置位置, 扫描容量曲线. 前者回答哪种结构更会利用预算, 后者回答各方法随预算如何扩展. 若某方法只在参数更多时占优, 结论应归因于容量, 而非名称.

LoRA 中 $\Delta W=sBA$, rank 给出代数上限, 实际有效秩还取决于奇异值谱. 两个 rank 都是 64 的模块, 一个可能只有前六个奇异值显著, 另一个则均匀使用几十个方向. 训练后应报告奇异值累计能量、稳定秩和不同层的谱形状. 若不断到来的任务把能量挤进少数方向, 后续更新更容易发生干扰; 若强制正交使每个任务占据独立方向, 容量会随任务数快速耗尽. 正交约束的价值不能只看当前任务保持率, 还要观察第十个、第二十个任务到来时是否已经没有足够的新方向.

低秩模块放在哪一层往往比 rank 本身更关键. 注意力投影影响信息路由, MLP 投影影响特征变换, embedding 与输出头直接牵涉词形和词频. 领域术语主要变化时, 靠近输入与输出的层可能更敏感; 需要新推理过程时, 中高层的注意力与 MLP 更重要. 可以用逐层冻结、逐层单独注入和成组注入来估计边际贡献. 若只在输出投影训练就能提升闭卷事实题, 却不能改善改写与组合题, 说明模块可能在调答案偏置; 若中层模块能在多种表达下稳定提升, 更像是形成了可复用表征.

LoRA 的缩放系数与初始化也会改变比较. 由于 $BA=(cB)(A/c)$, 矩阵分解存在尺度不唯一, 但优化器对两个因子的更新并不尺度不变. 一个因子零初始化、另一个随机初始化可让初始函数保持不变, 却使第一步只有一个因子获得有效梯度. 持续任务中若每次新建模块, 早期学习速度会被这种不对称影响; 若复用旧模块, 初始化问题又变成旧方向偏置. 验收应记录因子初始化、缩放规则、是否合并进底座和合并后的数值精度, 避免把实现细节造成的差异解释成持续学习规律.

adapter 的瓶颈不是免费的隔离层. 串行 adapter 改变每层残差路径, 即使底座冻结, 也会让所有输入经过新增变换; 并行 adapter 将增量加到原输出, 关闭模块时更容易恢复底座. 多任务共享同一个 adapter 会发生参数干扰, 为每个任务单独保存又需要路由器识别输入属于哪个域. 路由错误时, 模块本身再优秀也无法使用. 应分别报告理想路由、学习路由和无路由混合三种结果, 并给出错路由代价矩阵: 把法律请求送到医学模块、把通用对话送到代码模块, 各自损失多少. 平均路由准确率无法显示少数高风险错配.

软提示与前缀方法把更新放入输入侧, 参数量小, 却会占用上下文或注意力缓存. 提示长度为 $m$ 时, 每层前缀键值会增加与 $m$ 成正比的缓存和注意力计算. 训练比较若忽略这部分推理成本, 会得到不完整的资源前沿. 更重要的是, 提示依赖底座对提示向量的解释方式; 底座升级后, 即使隐藏维度没有改变, 同一向量也可能触发不同特征. 可用固定探针输入比较升级前后的中间激活、输出分布与注意力模式, 再决定是否只做线性映射、重新蒸馏提示, 或彻底重训.

模块迁移应以功能等价为目标, 不能只最小化参数距离. 设旧底座与模块组成教师 $f_{0,+}$, 新底座与待迁移模块组成学生 $f_{1,+}$. 在代表性输入 $x$ 上, 可以联合匹配输出分布、选定层表征和行为约束. 输出蒸馏保留可观察功能, 表征对齐帮助重建接口, 行为约束防止学生复制教师的错误. 数据必须覆盖模块擅长区、边界区和普通输入; 若只采擅长区, 迁移后可能对所有请求都过度调用专项行为. 还要保留一组教师本来不会的题, 确认学生的新增能力来自新底座, 迁移目标没有把它压回旧水平.

底座升级的四格实验可以进一步拆出责任. 旧底座加旧模块给出历史系统, 旧底座加新模块估计模块训练收益, 新底座加旧模块测接口漂移, 新底座加新模块给出最终系统. 若第四格优于第一格而第三格严重下降, 说明新模块确实修复了接口; 若第三格已经很好, 重新训练模块可能没有必要; 若第二格也下降, 则训练数据或模块目标发生了问题. 对每项能力计算四格差值, 还能区分底座主效应、模块主效应与二者交互项, 不必用一句「升级后效果更好」掩盖来源.

密封测试集与合并系数的选择过程保持隔离. 在开发集扫描 $\alpha$, 找到多个任务加权分数最高的点, 再在同一批题上报告结果, 会把测试信息泄漏到配方. 数据预先分为合并开发集、门槛验证集和密封测试集. 开发集用于选系数与裁剪率, 验证集只判断是否越过接受门槛, 测试集在配方冻结后打开一次. 若任务很少而无法再切分, 可以使用嵌套交叉验证: 外层留出任务或数据切片, 内层选择合并参数, 汇总外层结果. 所有尝试次数也要记录, 因为扫描一千组系数与只试十组具有不同的过拟合机会.

任务向量合并还受底座一致性限制. 两个模型即使架构相同, 只要起始 checkpoint、词表顺序或权重重参数化不同, 坐标相加就可能失效. 合并前要校验每个张量的来源哈希、shape、参数名与 tokenizer; 对采用旋转或置换等价的网络, 必要时先做神经元匹配. 模型输出相近并不意味着参数坐标天然对齐. 尤其当一个分支经历全量持续预训练, 另一个只做轻量 SFT, 二者位移尺度差距很大, 直接平均容易让大位移支配. 按整体范数归一化也可能放大原本微弱但噪声很高的分支, 因而需要层级尺度与功能验证共同决定权重.

合并后的校准变化常被准确率遮住. 分类或选择题准确率相同, 置信度可能显著变高; 生成任务的答案仍对, 拒答边界却可能移动. 需要检查负对数似然、期望校准误差、选择性回答曲线和安全拒答率. 若合并提升了新域正确率, 却让错误答案更自信, 部署时的风险可能上升. 温度缩放只能修正整体置信度, 无法恢复被破坏的知识, 因此校准后还要看分组误差: 旧域、新域、冲突事实和分布外输入是否得到一致改善.

知识内化与检索增强应按信息生命周期分工. 稳定、频繁调用且允许写入参数的规律适合内化; 变化快、需要出处或有删除要求的事实更适合外部检索; 介于两者之间的能力可以先由模块承载, 积累足够证据后再蒸馏进底座. 一个简单决策量是单位请求的摊销成本: 参数更新有一次性训练与验证成本, 检索有持续的索引、查询和上下文成本, 模块还有版本与路由成本. 成本之外还要加入错误恢复时间. 外部文档写错可以替换索引, 合并进参数的错误往往需要反向编辑或重新训练, 这一差异在高变动领域比单次推理费用更重要.

闭卷测试也不能直接证明知识已经进入底座. 训练资料可能残留在提示模板、缓存、工具返回或评测预处理里. 应在无网络、无索引、清空会话状态的环境运行, 并检查请求日志中没有隐藏上下文. 随后做表达变换: 实体别名、问题倒置、多跳组合、否定条件和不同语言. 若模型只在原句附近成功, 得到的是表面记忆; 能把事实用于新的约束推理, 才说明知识具有一定可调用性. 即便如此, 也只能说在测试分布内观察到内化迹象, 不能推出任意场景都会稳定调用.

冲突知识需要测概率质量如何迁移. 对新旧两个答案分别计算条件概率或成对偏好, 在训练过程中观察质量从旧答案向新答案转移的曲线. 理想更新不会把与该实体相关的全部答案一起扰动. 可以加入邻近实体、同关系实体和同词形实体作为控制组, 估计影响半径. 如果只更新「甲公司的负责人」, 却连其他公司的负责人问题都发生系统偏移, 说明模型学到了过宽的词法关联. 对时间变化事实, 还应允许旧答案在历史条件下保留较高概率, 这比无条件压低旧答案更符合版本化知识.

删除与遗忘请求要区分「不再输出」和「内部不可恢复」. 通过提示约束压制答案, 只能改变表面行为; 移除 adapter 只删除模块中的增量; 从检索库删除文档也不影响已经写入底座的内容. 若目标是参数层遗忘, 应设计成员推断、提示绕过、改写查询和相关表征探针, 并与从未见过该数据的模型比较. 严格证明某条信息完全不存在通常做不到, 报告应改为在给定攻击集合与置信水平下没有检测到显著残留, 同时明确攻击能力边界.

统计判定要以独立训练运行为单位. 一次训练里的一万道题不是一万个独立的训练样本, 它们共享同一个 checkpoint. 题级 bootstrap 可估计评测抽样误差, 却不能代替跨随机种子的训练方差. 至少应同时给出种子间均值与区间、每个种子内部的题级区间, 并使用配对设计: 不同方法尽量共享初始模型、数据顺序和评测样本. 配对差值通常比两个独立均值更灵敏, 也能减少某个种子本来就容易的影响. 任务顺序是研究对象时, 则应把顺序作为更高层随机因素, 不能把同一顺序下的多个 checkpoint 当成独立重复.

多指标门槛还会带来多重选择问题. 若研究者查看几十个旧域、新域和安全指标, 再挑出有利的几个, 偶然波动很容易被包装成提升. 实验前应指定主指标、关键风险指标和探索指标. 主指标决定收益是否成立, 风险指标拥有否决权, 探索指标用于解释机制. 对大量子任务可报告经过校正的区间, 或先按能力族聚合再检验. 统计程序最终要让「接受该更新」对应一个事先可执行的判据, 形式显著却无法支持决策的结果没有多少价值.

可以把最终门槛写成可计算规则. 比如新域主指标相对基线至少提升三点, 百分之九十五置信下界仍大于一点; 旧域宏平均下降不超过一点, 任何高风险子集下降不超过两点; 安全违规率的置信上界不得高于既定阈值; 跨三个训练种子均保持方向一致. 候选若只满足平均条件而某一高风险域越界, 直接拒绝; 若区间过宽, 增加种子或样本, 而非取最有利的点估计. 门槛数值由业务风险决定, 但确定以后不能因某次候选「看起来很有希望」临时放宽.

回滚演练要在发布前真的执行一次. 全量更新需要恢复旧 checkpoint、优化器无关的推理配置、tokenizer 与服务路由; PEFT 更新要验证卸载模块后输出确实回到底座基线; 模型合并要能重新定位所有源向量和系数; 检索更新要恢复索引快照与文档权限. 回滚后的系统用固定金丝雀请求比对输出哈希或容差范围. 若参数已经合并而源增量没有保留, 所谓回滚只能加载整份旧模型, 存储与切换时间需要计入恢复目标.

每个发布候选应留下足以复算结论的最小档案: 基础模型与 tokenizer 哈希, 训练代码版本, 数据清单与许可状态, 各来源 token 和文档计数, 去重规则, 采样日程, 学习率与优化器状态处理, 随机种子, PEFT 插入位置与容量, 合并公式与系数搜索范围, 逐 checkpoint 指标, 失败运行, 统计脚本和回滚结果. 它让下一轮更新能够回答一个很具体的问题: 能力变化究竟来自新数据、训练路径、模块容量、合并选择还是评测波动. 持续学习的难处就在这里——每一轮都继承此前的选择; 只有证据链也随版本一起保存, 后来的改进才不会建立在无法解释的偶然结果上.

遗忘还应沿训练深度拆开观察. 对同一批旧域探针, 记录各层隐藏状态与原模型的中心核对齐度、线性探针可分性和最终输出变化. 底层表征相近而输出变差, 干扰可能集中在后部读出与决策边界; 中层已经明显漂移, 再靠输出校准通常救不回来. 这类诊断要使用与训练目标无关的探针, 并设置随机投影和未更新模型作为参照. 表征指标本身不能替代行为结果, 但能指导下一轮将回放放到哪些层、是否冻结 embedding、是否给某些投影单独降低学习率.

梯度冲突也可以在训练前小规模估计. 从新域与若干旧域各抽一批样本, 在相同参数点计算梯度余弦与范数比. 余弦长期为负的旧域是重点回放对象; 余弦接近零但范数远小于新域时, 它虽然方向不冲突, 仍会被新域更新淹没. 只看全模型余弦会抵消层间差异, 因此还要按注意力、MLP、归一化与输出头分组. 若冲突主要集中在少数层, 全局降低学习率会牺牲新域学习速度, 分层学习率、局部冻结或在这些层增加旧域批次更有针对性. 训练后的实际遗忘若与预估冲突完全无关, 说明一阶梯度几何不足以解释路径, 需要检查曲率与数据顺序.

曲率影响可以用局部损失切片理解. 沿新域更新方向 $u$ 和旧域敏感方向 $v$ 构造二维平面 $\theta+a u+b v$, 测量新旧损失随 $a,b$ 的变化. 若新域下降方向立即让旧域损失陡升, 两个目标在当前位置存在尖锐权衡; 若附近有一条弯曲低损路径, 优化器与日程可能尚未找到它. 这种切片只覆盖局部平面, 不能证明高维空间没有更好的路径, 却能比较不同 replay 比例是否把模型带入更平坦的交汇区. 与参数范数相比, 损失切片直接展示位移的功能代价.

对参数模块还要测容量饱和的早期信号. 每轮任务后计算新增方向相对既有子空间的投影比例、模块输出范数和有效秩. 新方向几乎全部落入旧子空间, 同时新任务损失降不下去, 说明当前容量不够; 有效秩持续增长而保持率稳定, 说明模块仍在利用空余方向; 输出范数不断增大但有效秩不变, 则可能只是用幅度覆盖旧模块. 此时盲目增加训练步数会强化竞争, 更合理的选择是扩 rank、拆分路由模块或把稳定能力蒸馏回底座后释放模块容量.

线上灰度可以验证离线门槛没有覆盖的分布, 但灰度指标也需要因果对照. 将用户或请求稳定随机到旧版与候选版, 保持检索索引、解码参数和安全策略一致; 对长会话按会话而非单轮请求分桶, 防止同一上下文跨版本. 观察人工纠错率、任务完成率、拒答变化和严重事件, 同时按新域、旧域与未知域分层. 若候选版触发更多工具调用, 延迟和成功率变化可能来自工具链, 应进一步做模型版本与工具开关的二乘二对照. 灰度发现越界就按预演路径回滚, 而非继续收集到结果显著.

一轮更新结束后还应保留「没有采用的方案」. 失败方案记录预算、关键超参、失败指标和原因判断, 后续数据分布改变时可以重新检验, 也能避免团队反复踩同一个坑. 原因判断要和观察分开: 「旧域下降三点」是结果, 「回放不足」只是待验证解释. 下一轮通过提高回放、保持其他条件不变来验证; 若下降仍在, 再检查学习率、优化器状态和容量冲突. 这种逐轮排除让持续预训练从一次配方搜索变成可积累的研究过程.
