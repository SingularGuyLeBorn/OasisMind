## 最小应用判断

在开始写循环前，先回答四个问题：

1. 如果步骤固定，普通工作流是否已经足够？
2. 模型输出只是动作提议，宿主是否会再次校验、授权和执行？
3. 成功能否由测试、状态差异或人工量表验证，而不是由模型自述？
4. 最大步骤、成本、无进展、不可逆动作和人工升级怎样处理？

ReAct 的独立教学价值已经收进正本：环境观察进入下一次决策；生产审计记录计划摘要、工具调用、授权、结果和验证证据，不要求公开模型私有推理。

Function Calling 和 MCP 的应用接口仍可分别参阅 [7.4 Function Calling](../7.4-FunctionCalling/7.4-FunctionCalling.md) 与 [7.5 MCP](../7.5-MCP/7.5-MCP.md)，但 Agent 系统责任以本页所指正本为准。
