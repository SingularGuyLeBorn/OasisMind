# 章节结构规划

读者感觉「每章内部乱」，主要不是缺文章，而是 **同一概念多处展开、编号撞车、第 5 章和第 14 章各写一套模型**。

本文件管两件事：

1. **从现在起新文落在哪、文件/文件夹叫什么**（监工派工前必读）。
2. **整理波次**（地图优先，改名是后手）。

不是对照某门课重铺目录。课程不当金科玉律。

## 死命令

- **禁止 Delete** 既有文件。**例外**：第 10 / 11 / 12 章整章按用户拍板删除。
- **第 5 章与第 14 章融为一章两面**：5 = 叙事/时间线入口，14 = 家族精读夹（物理迁入 5 之前先共用一张地图）。公式仍在 2/6/9，不要在型号夹再推 MLA。
- **成文，不是勘误贴条。** 读者只读一版完整正文。禁止新写 `> **2026-08 修订（不删上文）`。碰一篇就把该篇里的修订块折进主叙述，删掉错句与双轨。不要用 HTML 注释存档旧错段。git 留历史。存量不今晚全库扫。
- **禁止**为「看起来整齐」一次性 `git mv` 半座库。5+14 物理合并另立租约，不跟 1234 过文抢。
- 新文 **一概念一本体**。别处只链 + 一两句「这章只关心哪一面」。
- 章首页 / 节首页是 **地图**，不是第二份专文。`2.3.4` 这类综述只保留导航、「不是」关系、链到专文；推导和图放专文。
- **新路径必须过「文件名规范」**。旧路径不今晚全改；整理波次里 `git mv`，不删。

## 读者怎么走（目标形态）

```
章首页（与夹同名.md）
  → 节首页（与夹同名.md）= 本地图 + 「不是」谁 + 链到唯一正文
    → 专文（一夹一文同名）= 问题 → 旧法差在哪 → 公式/图 → 边界 → 来源
      → 需要看「这次发布怎么捆、报告原文怎么说」时，链到第 14 章对应家族
      → 体系专文必须已写清该组件在整机里的插槽与作用；禁止用链接代替展开。两边允许重复。
```

四层各做一件事。章首页：职责表。节首页：家族内「不是」+ 专文列表。专文：一篇一个主问题。第 14 章：某次发布的捆法。禁止在第 5 章再开一套 `01-型号` 精读。

第 5 章只做 **厂商叙事 / 对比 / 时间线**，不再给每个版本开 `01-GPT-x` 扁平行。旧扁平行不删，首页写「精读见第 14 章」。

金样本叶子：**`2.2.2/01-MHA-多头注意力的标准形式/`**（三层点分号 + 第四层 `01`）。`2.3.2/11-H2O-…` 深度对，但 `11` 已经超过「一层最多约 10」——存量不今晚拆，新文不要再往 2.3.2 加 `18`。章地图样本：`2-核心原理与架构.md` 文首「本章职责」表。

## ID 命名空间（新文强制）

同一父目录下，只允许一种编号语法；一种语法只表达一种意思。

### 四层，点分号只占前三层

```
{N}          第 1 层  章          例：4-
{N.N}        第 2 层  节          例：4.1-     同级最多约 10（4.1…4.10，禁止 4.22）
{N.N.N}      第 3 层  小节        例：4.1.1-   同级最多约 10（4.1.1…4.1.10，禁止 4.1.15）
{NN}         第 4 层  专文        例：01-      只允许挂在 {N.N.N} 下面；同级最多约 10
```

禁止第四段点分号：不要 `4.1.1.1`，不要 `6.3.1.2` 这种新路径（旧的 `6.3.1.2-KV缓存与向量量化.md` 不删，新文改挂 `6.3.1/02-…`）。
禁止在第 2 层或第 3 层用 `01`/`02`：`4.6/01-OPD-学生前缀蒸馏`、第 5 章根 `01-GPT-1`、`2.3.1/01-FlashAttention/02-v1`（第五层）都是旧形态。

同层要超过约 10 篇：**拆上一层**，不要把序号拉长。2.3.2 已经有 01–17 → 新驱逐类专文开 `2.3.6`（或该章未占用的 `2.3.x`），不要 `18-`。4.6 根上已有 `01`–`10` → 新 OPD 专文先有 `4.6.1` 篮子再 `01`，不要在 4.6 根加 `11`。

| 代号 | 语法 | 表达什么 | 唯一范围 | 用在哪 |
|------|------|----------|----------|--------|
| **C** | `{N}` / `{N.N}` / `{N.N.N}` | 14 章职责树上的节点 | **同一父目录下点分号不重复**；**最多三层** | 章夹、节夹、小节夹；稳定课程叶子 B 可以停在 `{N.N.N}.md` |
| **A** | `{NN}` 两位整数 | 该小节下专文的阅读/写作顺序 | **同一 `{N.N.N}` 夹内 NN 不重复，且 ≤10** | **只**在 1–13 章的第四层（`4.1.1/01-…`） |
| **D** | 第 14 章版本夹里的 `01`/`03`/`05` | 精译 / mineru / 专题等交付物种类 | 只在第 14 章版本夹内 | **禁止推荐到第 1–13 章** |

点分号 = 树坐标；两位数字 = 篮子里的序号。`2.2.2/01-MHA` 的 `01` **不是**「第 2.2.2.01 课」，也不是第 14 章的 D5。不要把专文写成 `2.2.2.1-MHA`。

**禁止的混法：** 在 `{N.N}` 节根同时铺 `{N.N.N}`（C）和 `01-…/`（A）。`4.6` 现在就是：`4.6-OPD.md` + `Self-Distillation-条件增强.md` + `01`–`10` 夹。理想前进线：

```
4.6-OPD/
  4.6-OPD.md                 # 节地图（C，两层）
  4.6.1-On-Policy-Distillation/
    4.6.1-On-Policy-Distillation.md
    01-OPD-学生前缀蒸馏/          # A，第四层
    …
```

旧 `Self-Distillation-条件增强.md` 先改成无号历史入口，再把 `4.6.1` 号给篮子（S8，不今晚搬 10 个夹）。**不要**把 `01`–`10` 改成 `4.6.1`–`4.6.10`。

两种合法叶子，同一父目录不要混：

- **叶子 A**（论文还会长出来）：必须先有 `{N.N.N}`，再在下面放 `01`…`10`。满了就新开 `{N.N.N+1}`，不要 `11`。
- **叶子 B**（几年内不会变成二十篇论文）：停在课程序号，`13.1.1-记忆系统.md` 这种。不要在旁边再放 `01-记忆系统/`。

发号前 `ls`。第四层专文取 `max(NN)+1`，两位补零，**且 max+1 ≤ 10**；否则先拆小节。不要预留空洞「以后插 4.6.3」。

第 4 章撞号拍板（S1 已 `git mv` 前三条，不删旧文）：

- `4.1-后训练数据/` 保持 **C = 4.1**（前进线）。
- `4.1-后训练概述/` → **`4.0-后训练概述/`**（已改）。`4.0` 仍是两层 C，合法。
- `尺度定律的再发现-ScaleRL/` → **`4.8-ScaleRL-尺度定律的再发现/`**（已改）。
- `4.7-持续学习/` 已占用，SDFT 专文仍在 `4.6/03`（存量）；持续学习节首页只链。

第 8 章两个 `8.2`：VLM 夹孩子多，**保持 8.2**；`8.2-CLIP与视觉编码器/` → **`8.8-CLIP与视觉编码器/`**（已改）。`8.8` 仍小于一层 10 篇的上限。

章夹真名以磁盘为准：第 13 章是 `13-Agent/`，不是 `13-Agent系统/`。

## 文件名规范（只约束新路径；旧的 git mv 不删）

路径是给人和侧栏看的。乱名 = 结构乱。

### 字符

- 只用：数字、字母、`-`、中文。
- **禁止**：空格、括号、`&`、`/`、`:`、`：`、`、`、`+`、逗号、全角标点、emoji。
- 中英之间用 `-`：`10-StreamingLLM-Attention-Sink`，不要 `10-StreamingLLM与Attention-Sink`（新文）；旧名不删。
- 专有名词在同一家族内拼写锁定：`Llama` 不要再开 `LLaMA`；`Ernie` 不要再开 `Erine`。

### 层级与同名

```
{章}/{节}/{小节 N.N.N}/{NN}-{英文惯例}-{中文短名}/{NN}-{英文惯例}-{中文短名}.md
{章}/{节}/{小节 N.N.N}/{NN}-{英文惯例}-{中文短名}/images/fig-{kebab}.png
```

| 层级 | 文件夹 | 首页 md |
|------|--------|---------|
| 章 | 已有 `2-核心原理与架构/` 不要改 | 必须与文件夹**同名**。禁止再新增 `index.md` |
| 节 | `{N.N}-{中文短名}/` | 同名 md。同级最多约 10 |
| 小节 | `{N.N.N}-{中文短名}/` | 同名 md。同级最多约 10。**专文篮子在这里** |
| 专文 | `{NN}-…/`（两位，01–10） | **只**出现在 `{N.N.N}` 里面。夹名 = 主 md 名 |
| 第 14 章版本 | `{NN}-{官方产品名}/` | D 码只在 14；文件夹 `{NN}` 在该家族内必须唯一 |

- **新专文一律进 `{N.N.N}/{NN}-…/`**，不要在 `{N.N}` 节根丢 `01-…` 或 `2.4.6-短名.md`。
- 同一 `{N.N.N}` 下 `{NN}` **不得重复**，且不要发到 `11`。满 10 就新开小节。
- `{N.N.N}` 与 `{NN}` 不要混用同一层。
- 配图新文件：`images/fig-{kebab-english}.png`。
