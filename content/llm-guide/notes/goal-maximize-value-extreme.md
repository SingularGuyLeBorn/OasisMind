# Goal：把 2025 年写的个人读书笔记接到 2026 年 8 月，并把知识体系补完整

把下面整份 brief **原样当作 Goal 的 objective**。用户会把本文件 **反复粘贴** 到新会话。聊天记录会被压缩、会丢。**以磁盘上的活文档为准，不要靠「我记得上次做到哪」。**

## 重复投喂时的第一条动作（写任何笔记之前）

按顺序 Read，禁止跳过：

1. `content/llm-guide/notes/live/GOAL.md`

## 0. 这是什么、不是什么

这是作者 **2025 年写下、一直在长的个人大模型读书笔记**（花园 `content/llm-guide/`）。现在是 **2026-08-30**。一年多里模型、论文、工程常识都变了；当年写的提纲有一批还没写成正文；有些图只留了 prompt，图本身没生成。

成功标准有五件，必须同时成立：

1. **补写**：作者已经写了「要写什么」（六段提纲、空壳 D2/D5、`状态: 待完善`、目录承诺的专文），正文按提纲写满。不要另起炉灶改结构。
2. **配图（必须自绘、禁止水印）**：文里的 prompt / `IMAGE PLACEHOLDER` / `图片占位建议` 全部用 Cursor `GenerateImage` **重新生成**并嵌入。禁止把网页/论文/公众号带水印、带 Logo、带「来源」角标的图直接下下来当配图。已有图若带水印：保留旧文件（不删），新生成一张无水印的替换正文引用。prompt 改成 HTML 注释留着。
3. **校正并接到 2026-08**：过时的全景、时间线、默认假设、已被后文打脸的断言，用 **2026-08 修订节 / 勘误** 补上。保留 2025 原文当历史快照。数字与代际（GPU 型号、带宽、框架版本）必须先 `WebSearch` / 官方页，禁止用 2025 记忆硬写。
4. **知识体系完整（含 GPU / Infra，尽可能不遗漏）**：骨干不断档 + 概念住在体系章 + 每章真地图 + 2026-08 的轴都有落点。**第 9 章 GPU 与基础设施和第 6 章训练/推理优化是体系的硬轴，不是附录。** 防遗漏清单见第 0.2 节。
5. **内容来自一手阅读，不是预训练**：补全体系 = 去读该模型发布时的原论文/技术报告、官方 model card、官方 blog/system card、顶会顶刊版本（ICLR / ICML / NeurIPS / EMNLP / ACL 等）、以及中英文互联网上的靠谱解析。预训练知识只允许用来 **决定搜什么**，不准用来 **填写数字、架构、日期、基准**。纪律见第 0.4 节。

**这不是商品。不要做售卖包装。** 不要写 `COMMERCIAL-SLICE`、付费切片、上架方案、君子协定产品化、12 周训练营、面试课大纲。`致读者` 里已有的君子协定原文 **一个字都不要删**，但也不要顺着它去设计商业闭环。

也 **不要** 把这次 Goal 做成「准备发 GitHub」：不写 PUBLIC-SLICE、如何贡献、如何引用、整库 LICENSE。来源可追溯、日期清楚、索引不把空壳算完成——那是笔记对自己诚实，不是开源立项。

**不要提交 git，除非用户后来说提交。** 不要 `git add -A`。不要改 `git config`。

### 0.4 一手阅读纪律（违反 = 这篇笔记不合格）

| 优先级 | 读什么 | 怎么找 |
|--------|--------|--------|

| 3 | **官方 blog / system card / 技术解读** | 公司官网、Anthropic/OpenAI/Google/DeepSeek/Qwen/Kimi 等发布帖 |
| 4 | **顶会顶刊版本** | ICLR、ICML、NeurIPS、EMNLP、ACL、TMLR；注意会议版与 arXiv 初稿的差异 |
| 5 | **中英文解析** | 苏剑林、Lilian Weng、Raschka、SemiAnalysis、可核对原文的中文精读；当 **二次文献**，有冲突以 1–3 为准 |
