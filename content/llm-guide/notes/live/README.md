# 活文档：目标 / 计划 / 过程

用户会把 `notes/goal-maximize-value-extreme.md` **反复粘贴**给新会话。聊天记录不可靠。以本目录三份文件为准。

| 文件 | 职责 | 谁改 |
|------|------|------|
| [GOAL.md](./GOAL.md) | 现在要达成什么、本轮焦点 | 波次切换时改「本轮焦点」 |
| [PLAN.md](./PLAN.md) | 下一步 3 件事 + 队列 | 每做完一件就改 |
| [PROCESS.md](./PROCESS.md) | 正在读/写/卡点 + 来源台账 | 每读一篇源、每写完一节就追加 |

**每轮对话第一条动作（在写任何笔记之前）：**

1. Read `GOAL.md`
2. Read `PLAN.md`
3. Read `PROCESS.md`（至少「此刻」和来源台账）
4. 需要细则时再读 `../goal-maximize-value-extreme.md`
5. 从 `PLAN.md` 的「下一步 3 件」继续，禁止从 P0 重新开始（除非 PLAN 写着还没盘点）

历史流水可追加到 `../2026-08-enrichment-log.md`。活文档保持短，才能每次都读完。
