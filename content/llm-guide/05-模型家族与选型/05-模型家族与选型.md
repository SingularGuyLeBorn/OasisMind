# 模型家族与选型

> 核验日期：2026-09-01。本章不做“谁最强”的永久榜单，而是给出可复查的选型方法、稳定家族身份和一手材料入口。

![研发家族、产品体验与 API checkpoint 三层身份，以及任务、证据、部署、风险四步选型流程](./images/model-identity-selection.png)

> 图像来源：本知识库使用 OpenAI 图像生成模型自制概念图（2026-09-01）。图中只表达身份分层与选型顺序；模型版本、参数、许可和服务规格以正文所列一手来源为准。

## 本章回答什么

1. 如何先定义任务、风险和预算，再选择候选模型；
2. 如何判断模型卡、厂商 benchmark 与第三方评测是否可比；
3. 如何在开放权重、API、模态、上下文、工具、许可和部署成本之间做取舍。

## 边界

- 模型版本页只写该版本如何组合公开机制；注意力、MoE、激活函数等公式回第 02 章。
- 训练/推理优化回第 06 章，多模态机制回第 08 章，服务基础设施回第 09 章。
- 闭源模型严格分开“官方披露、可靠外部研究、未披露”；没有证据时不补参数表。

## 证据规则

事实优先级为：原始技术报告/论文与官方仓库、官方模型卡/系统卡、官方发布/API 文档、可复现第三方研究、其他二手材料。价格、窗口、模型 ID 和可用区必须带 `as_of`；厂商自报评测明确标注，不与不同 harness 的数字直接相减。
