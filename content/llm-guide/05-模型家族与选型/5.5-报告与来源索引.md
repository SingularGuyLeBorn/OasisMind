## 证据使用规则

- API 价格、区域、窗口、alias 与 deprecation 标 `as_of`；滚动 alias 不作历史 checkpoint。
- “开放权重”后继续读许可证：Apache 2.0、Research、Non-Production、Modified MIT 和社区许可不能混写。
- `_sources/model-reports/` 是来源快照，`_archive/model-knowledge/` 是历史归档；两者不属于公共课程导航，归档断链不维护。
