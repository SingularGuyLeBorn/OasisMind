# Kimi K2：万亿参数 MoE 与 MuonClip

> 核验日期：2026-09-01。本页讨论 2025-07-11 发布的初始 Kimi K2 Base / Instruct；0905、Thinking、K2.5 以后版本另页记录，不能把后续 256K 或视觉能力倒填给初版。

## 定位

Kimi K2 是 Moonshot AI 首个大规模开放权重 Agent 模型主线。它以约一万亿总参数的 MoE 获得约 320 亿参数的每 token 激活规模，并把代码、工具调用和自主任务执行作为后训练重点。官方同时发布 Base 与 Instruct：Base 便于继续训练和研究，Instruct 才是经过指令、工具与 Agent 后训练的对话检查点。

## 身份卡

| 字段 | 官方口径 |
|---|---|
| 发布日期 | 2025-07-11 |
| 检查点 | `Kimi-K2-Base`、`Kimi-K2-Instruct` |
| 总参数 / 激活参数 | 报告表格 1.04T / 32.6B；模型卡常用约 1T / 32B |
| 层数 | 61；包含 1 个稠密层 |
| 注意力 | Multi-head Latent Attention（MLA），64 个注意力头 |
| MoE | 384 个路由专家，每 token 选择 8 个，并有共享专家 |
| 预训练数据 | 15.5T token |
| 公开模型上下文 | 128K |
| 输入输出 | 文本 → 文本、代码、工具调用 |
| 权重许可 | Modified MIT License |

参数精确值来自技术报告，约数来自模型卡，二者不是冲突。激活参数是一次前向的计算口径，不是权重存储量。

## 架构为什么这样设计

### MoE：把容量与单 token 计算拆开

路由器为每个 token 选择少量专家，因此模型可以拥有很大的总容量，同时避免每一步都运行全部前馈参数。共享专家用于承载更普遍的模式，路由专家形成一定分工。代价是部署需要保存完整权重，还要处理专家负载、跨设备通信和路由不均衡；“32B 激活”不能简化成“按 32B 稠密模型部署”。

### MLA：压缩注意力缓存

MLA 将键和值映射到较小的潜在表示，以降低长上下文推理中的 KV 缓存压力。它不消除上下文长度带来的计算和内存成本，也不自动保证 128K 任意位置的有效召回。部署框架必须明确支持该模型实现和聊天模板。

## MuonClip 的贡献

K2 报告把超大规模训练稳定性作为核心问题。Muon 通过对矩阵参数更新进行特定归一化来改善优化效率，但扩到万亿参数 MoE 时仍可能出现注意力 logits 失控。MuonClip 在 Muon 体系上加入对 query/key 投影的控制：监测注意力相关尺度，在超过阈值时对相应权重做重缩放，从而抑制训练后期的爆炸风险。

正确理解它需要保留边界：

- 这是 K2 报告披露的训练方案，不等于所有 Moonshot 模型都采用相同实现。
- 稳定训练不是只靠一个“clip”操作，还涉及初始化、精度、路由、数据和分布式系统。
- 论文给出的规模训练结果是该配方的证据，不是对任意代码复刻的稳定性保证。

## 训练与 Agent 后训练

K2 在 15.5T token 上预训练。报告从较短窗口训练出发，再为长上下文能力扩展；模型卡给出的公开服务窗口是 128K，不能把预训练某阶段的序列长度与最终窗口混为一谈。

Instruct 版本的后训练不仅覆盖通用对话，还特别组织代码和工具调用数据，使模型学习工具模式、调用参数、观察结果和后续决策。一个模型在函数调用格式上合格，不代表它能可靠完成长轨迹：生产评测应单独测工具选择、参数正确率、异常恢复、重复调用、停止条件和结果验证。

## 使用与部署

1. **先锁检查点**：Base 没有 Instruct 的对话行为保证；初始 Instruct 也不是 0905 或 Thinking。
2. **遵循模型卡模板**：聊天模板、工具定义格式、停止 token 和采样参数会明显影响结果。
3. **规划完整权重**：即使量化，1T 总权重也需要多机/多卡存储与高效专家并行；激活量只描述计算的一部分。
4. **长上下文实测**：同时记录长度、并发、KV 缓存、首 token 延迟、生成吞吐与有效召回。
5. **核对许可**：仓库使用 Modified MIT，不要在清单中误标为 Apache-2.0 或标准 MIT。

## 版本边界

- K2 初版：128K，文本模型。
- K2-Instruct-0905：更新的指令检查点，256K。
- K2 Thinking：推理与长工具轨迹检查点，256K，官方原生 INT4。
- K2.5：加入原生视觉和新的后训练；不是初版 K2 的同义词。
