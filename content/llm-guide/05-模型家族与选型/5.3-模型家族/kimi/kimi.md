# Kimi 模型家族

> 核验日期：2026-09-01。本文只采用 Moonshot AI（月之暗面）的官方页面、模型卡、论文和仓库确认硬事实；“Kimi”产品、API 路由、研究模型与可下载检查点不是同一层身份。

## 家族定位

Kimi 最早以长文本智能助手进入公众视野，随后形成了多条相互关联但不能混为一谈的路线：面向用户的 **Kimi 产品**、面向开发者的 **Moonshot/Kimi API**、探索强化学习与多模态的研究模型，以及从 Kimi K2 开始的开放权重 Agent 模型。K2 系列用大规模 MoE 降低每 token 的激活计算；K2.5 引入原生多模态，K2.6 强化 Agent 与并行协作，K2.7 Code 聚焦软件工程；K3 则换成新的超大规模原生多模态 MoE 基座。

这条谱系中，近似名称不等于可互换：

- `moonshot-v1-*` 是 API 产品路由，不能据此反推历史 Kimi Chat 的内部权重或架构。
- K2、K2-0905、K2 Thinking、K2.5、K2.6、K2.7 Code 是不同检查点或版本身份。
- K2.5、K2.6、K2.7 Code 的模型卡给出相同的主体架构，但后训练目标、能力和使用方式不同。
- K3 是新基座，不是把 K2.x 换一个产品名；其架构、上下文和许可都发生了变化。

## 一张表看懂技术代际

| 代际 | 主体规模 | 关键结构 | 视觉 | 许可 |
|---|---|---|---|---|
| K2 / 0905 / Thinking | 约 1T 总参数、约 32B 激活 | 61 层，MLA，384 个路由专家、每 token 选 8 个，另有共享专家 | 无原生视觉编码器 | Modified MIT |
| K2.5 / K2.6 / K2.7 Code | 约 1T / 32B 激活 | 主体沿用 K2 家族 MoE；模型卡均列 61 层、384/8/1 专家口径 | MoonViT，约 400M 参数 | Modified MIT |
| K3 | 约 2.8T / 104B 激活 | 93 层；69 层 KDA、24 层 Gated MLA；896 个专家，选 16 个并含 2 个共享专家 | MoonViT-V2，约 401M 参数 | Kimi K3 License（自定义） |

MoE 的“激活参数”只表示一次前向主要参与计算的参数量，**不等于部署只需存放这些参数**。自托管仍要考虑完整权重、量化格式、专家并行、KV 缓存、通信和推理框架支持。

## 能力演进的正确读法

1. **长上下文**：早期产品用“汉字数”做用户口径；K2 初始公开权重是 128K，0905 起为 256K，K3 才提升到 1M。字符、token、窗口上限和有效任务长度不能互换。
2. **Agent 化**：K2 以工具调用和代码为重要后训练目标；Thinking 强调推理与连续工具使用；K2.5/K2.6 引入并行子 Agent 产品能力；K2.7 Code 把训练重点进一步收窄到真实软件工程。
3. **多模态**：k1.5 是多模态强化学习研究；K2.5 才在 K2 开放权重主线中加入原生视觉编码；K2.6 与 K2.7 Code 沿用该结构；K3 再换用 MoonViT-V2。
4. **训练稳定性**：K2 报告的 MuonClip 是重要贡献，但其优化器、路由和训练配方不能倒推到未公开细节的 Kimi Chat，也不能自动视为 K3 完全相同。

## 研究支线

Moonshot AI 还公开过若干与主谱系互补的研究模型：Kimi-VL 探索 128K 多模态 MoE；Kimi-Audio 研究音频理解与生成；Kimi-Dev-72B 面向软件工程，并建立在 Qwen2.5-72B 之上。这些项目说明研究版图，但不是 K2/K3 的别名，也不据此推断主线模型继承了全部实现。

## 选型建议

- 要通用文本或工具调用，先比较 K2 0905、K2 Thinking 与当前托管 API；不要仅凭“K2”三个字符锁版本。
- 要图像、视频或视觉编程，选择 K2.5 以后明确带 MoonViT 的检查点；原始 K2 不是原生视觉模型。
- 要代码 Agent，K2.7 Code 是更明确的专项权重；通用问答是否更好需要用自己的任务集验证。
- 要 1M 窗口、更高激活规模或 K3 新架构，可评估 K3，但应先核算完整权重与并行成本。
- 每次部署都固定模型仓库 revision、聊天模板、推理模式、量化格式和许可证副本；托管服务的同名模型可能独立更新。

## 许可与“开放”边界

K2 主线公开检查点使用 **Modified MIT License**，不是未修改的 MIT，更不是 Apache-2.0。K3 改用 **Kimi K3 License**：它允许广泛使用，但对特定商业 MaaS 收入以及大型商业产品/服务的品牌展示设有额外条款。本文因此统一写“开放权重”，不把整个家族不加限定地称为“开源”。生产使用须核对所选仓库当时随附的许可证；本文不是法律意见。
