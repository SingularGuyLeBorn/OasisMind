# GLM-4.6

## 身份

GLM-4.6 于 2025 年 9 月 30 日发布，是 GLM-4.5 技术路线上的文本模型迭代，重点改进编码、长上下文和工具型 Agent。官方模型卡引用 GLM-4.5 技术报告，说明它属于同一架构家族；这不等于所有训练数据和后训练配方完全相同。

| 字段 | 官方口径 |
|---|---|
| 输入/输出 | 文本 → 文本 |
| 上下文 | 200K，从 GLM-4.5 的 128K 扩展 |
| 公开形态 | 开放权重、FP8 变体、托管 API |
| 权重许可 | MIT |
| 主要定位 | 代码、推理、工具调用、长上下文 Agent |

## 与服务参数的区别

模型上下文是输入与输出共享的 token 预算，API 的最大输出另有上限并可随平台文档更新。200K 不表示建议每次填满，也不保证在窗口末端保持短上下文同等准确率。长仓库任务应测跨文件定位、目标保持、错误恢复、缓存成本和多轮轨迹压缩。

GLM-4.6 的“思考模式”由具体 chat template 或 API 参数控制；官方服务还可能提供函数调用、上下文缓存和结构化输出。这些接口能力不应写入裸权重架构定义。

## 选型

相较 GLM-4.5，GLM-4.6 更适合需要 200K 上下文的文本编码/Agent；相较后续 GLM-4.7/5.x，它可作为较成熟且 MIT 许可的基线。最终取舍仍要用同一推理框架、量化精度和任务预算复测。
