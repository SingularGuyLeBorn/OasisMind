# Doubao Lite

> 核验日期：2026-09-01。本文只写可回到一手材料的事实；服务规格、价格与可用区以使用当天的官方文档为准。

## 结论卡

| 字段 | 结论 |
|---|---|
| 官方名称 | 豆包通用模型 lite / Doubao-1.5-lite |
| 发布日期 | 2024-05-15（产品线）；Doubao 1.5 于 2025-01 发布 |
| 获取方式 | 火山方舟 API，闭源服务 |
| 证据级别 | 火山引擎官方发布页 |

## 发布与证据

Lite 是火山方舟提供的轻量服务档位。旧稿把“轻量、低成本”推导成“端侧部署”，官方材料没有支持这一结论。

## 相对上代变化

相对 Pro 以较低时延和 token 成本为主要取舍；1.5 Lite 是后续快照，不应与 2024 首发规格混成一张静态参数表。

## 已披露的技术事实

- 2024 官方发布将 Lite 定义为较低成本、较低延迟的通用模型。
- Doubao 1.5 官方发布继续提供 1.5-lite，并给出发布方 benchmark。

## 未披露与不应推断

- 总参数、激活参数、路由规则、训练数据明细和端侧权重均未披露。
- “手机端本地运行”“量化到某个位宽”等旧稿描述没有一手证据。

## 评测协议

- 1.5 发布页结果属于发布方评测，部分对比值来自其他厂商公开结果或内部平台。
- 选型应在同一 API 快照上测准确率、首 token 延迟、吞吐与真实账单。

## 适用边界

- 适合成本和延迟敏感的 API 场景；不能据“Lite”名称推断可离线或端侧部署。
- 价格、上下文、限流与区域均为易变项，本页不固化；以调用当天官方文档为准。
