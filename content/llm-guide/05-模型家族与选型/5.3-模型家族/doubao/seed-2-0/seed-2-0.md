## 发布与证据

Seed 是字节跳动的技术研发/模型家族；豆包是面向用户的产品与品牌；火山引擎/火山方舟是 API 渠道。`Doubao Seed 2.0` 或具体 API ID 是服务映射，不自动等于一份可下载 checkpoint。

## 相对上代变化

相对 Seed 1.x，官方强调复杂文档/图表/视频理解、长时程 agent 与复杂指令执行，并以 Pro、Lite、Mini 和 Code 覆盖不同部署需求。

## 已披露的技术事实

- Pro/Lite/Mini 三档通用 agent 模型与 Code 专用模型。
- Pro 与 Code 进入豆包 App / TRAE；全系列 API 通过火山引擎提供。
- 2026-04 的 Lite 更新是官方所称 Seed 家族首个统一全模态理解模型。

## 未披露与不应推断

- 参数量、激活参数、注意力/MoE 结构、训练数据比例与统一上下文上限未披露。
- 产品展示名、控制台 endpoint 与底层快照的精确一一映射若无官方表格则标为未知。

## 评测协议

官方发布包含 Arena 与多模态/agent 评测；引用时保留榜单日期、子型号、是否工具调用、输入模态和官方/第三方评分来源。

## 适用边界

适合通过豆包产品、TRAE 或火山 API 使用；本地部署、权重微调和离线合规不能从服务可用性推导。
