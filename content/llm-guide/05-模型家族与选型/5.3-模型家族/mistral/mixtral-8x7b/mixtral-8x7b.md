## 发布与证据

Mixtral 8x7B 是稀疏 MoE 模型；“8×7B”不是总参数的算术表达。

## 相对上代变化

相对 Mistral 7B，把 FFN 替换为每层 8 个专家、每 token 选 2 个专家的 sparse MoE，并保持稠密 32K 注意力。

## 已披露的技术事实

- 论文报告 46.7B 总参数、每 token 12.9B 激活参数。
- 每层 8 个 FFN 专家，路由器为每 token 选择 2 个。
- 论文分析没有发现简单的“数学专家/代码专家”语义分工。
- 注意力是稠密 32K；不能把 Mistral 7B 的 SWA 套到本模型。

## 未披露与不应推断

- 训练数据配比和全部基础设施配置未公开。
- 路由专业化不能靠少量可视化命名专家。

## 评测协议

- 论文将 base 与 instruction 模型、不同任务表分开；MATH 与 HumanEval 不可互换。
- 引用发布方结果时保留模型变体、prompt 和采样。

## 适用边界

- 适合研究稀疏 MoE 与开放部署。
- 总权重显存和 token 激活计算是不同预算；服务还受专家并行与通信影响。
