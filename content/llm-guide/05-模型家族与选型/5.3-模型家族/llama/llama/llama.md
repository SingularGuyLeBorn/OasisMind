# LLaMA

> 核验日期：2026-09-01。初代论文和公告写作 `LLaMA`；后续品牌通常写作 `Llama`。本页不把后代许可或能力倒灌给初代模型。

## 结论卡

| 字段 | 已核实信息 |
|---|---|
| 发布 | 2023-02-24；论文 arXiv:2302.13971 |
| 参数 | 7B、13B、33B、65B（论文精确近似值为 6.7B、13.0B、32.5B、65.2B） |
| 上下文 | 2,048 token |
| 模态 | 文本输入 → 文本输出；仅预训练基座，不是官方聊天助手 |
| 架构 | decoder-only 稠密 Transformer；RMSNorm、SwiGLU、RoPE；多头注意力 |
| 训练量 | 7B/13B 约 1T token，33B/65B 约 1.4T token；官方称数据来自公开来源 |
| 许可 | 受控申请、非商业研究许可；不是 Llama 2 Community License |

## 重要贡献

- 证明在固定推理预算视角下，小于当时超大模型但训练更充分的基座可以保持竞争力；这不等于论文证明了所有规模都达到“计算最优”。
- 公开了四个尺寸、架构与主要数据配比，为后来 Alpaca、Vicuna 等研究生态提供了共同基座；这些衍生模型的训练与许可不能反向算作 Meta 官方能力。
- 架构并非从零发明：预归一化、SwiGLU、RoPE 等来自既有工作，贡献主要在组合、训练规模和公开研究访问。

## 证据边界

- 初代没有 Meta 官方 Chat/Instruct 检查点；“会对话”“会工具调用”通常来自社区微调。
- 论文只披露数据类别和配比，没有提供可完整复现的训练语料清单与全套训练流水线。
- 官方公告明确说明按个案向研究人员等主体提供访问，并采用非商业研究许可；不能因为权重后来在互联网上流传就称为可自由商用。
- 2K 是训练序列/模型口径。第三方 RoPE 扩展不改变原始检查点身份，应另记方法、微调和评测条件。

## 部署与选型

今天选择初代 LLaMA，通常是为了历史复现、架构教学或研究基线，而不是新生产系统。若确需使用，先确认权重来源、原始许可授权、精确尺寸与 tokenizer；不要把 `Llama` 同名社区转换权重当作 Meta 官方发行。
