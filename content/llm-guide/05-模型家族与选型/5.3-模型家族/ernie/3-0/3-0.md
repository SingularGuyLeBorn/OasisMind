## 发布与证据

ERNIE 3.0 是知识增强预训练研究版本，不等同于后来的 ERNIE Bot API 产品快照。

## 相对上代变化

相对早期 ERNIE 将自回归、去噪自编码等多种预训练范式纳入统一框架，并继续利用知识图谱信号。

## 已披露的技术事实

- 论文描述统一多范式预训练框架及知识增强任务。
- 论文评测覆盖自然语言理解与生成任务；具体规模按论文模型表读取。

## 未披露与不应推断

- 把后续 ERNIE 3.0 Titan 的系统规模、产品 SLA 或应用数据回写到论文模型会混淆对象。
- 产业部署与超算细节只有在可追溯到原始报告时才可作为技术事实。

## 评测协议

- 以论文表格为发布方结果，保留数据集、模型尺寸、fine-tuning/few-shot 设置。
- 不能把论文 NLU 结果与 ERNIE Bot 在线产品体验直接比较。

## 适用边界

- 适合研究统一预训练目标与知识增强路线。
- 版本名包含研究模型、Titan 扩展与产品服务时必须逐项注明身份。
