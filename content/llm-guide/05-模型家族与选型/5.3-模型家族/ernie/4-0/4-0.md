## 发布与证据

ERNIE 4.0 是闭源产品模型。旧“架构精译”没有对应公开技术报告，因此公开页只保留官方产品层信息。

## 相对上代变化

官方将其作为 4.0 代际更新，强调理解、生成、逻辑与记忆能力；这些是产品分类，不是公开网络配置。

## 已披露的技术事实

- 百度千帆提供 ERNIE 4.0 的服务型号与更新记录。
- 官方公开材料包含产品能力与训练系统概述，但没有足够信息复现模型。

## 未披露与不应推断

- 参数量、层数、注意力、MoE/稠密结构、训练数据和并行度未披露。
- 旧稿中的知识增强注入位置若不能回到官方材料，应标为未知。

## 评测协议

- 发布方能力对比不等于独立复现；必须保留测试任务与服务快照。
- API 评测记录 model ID、日期、采样、系统提示和是否使用工具。

## 适用边界

- 适合百度千帆 API 生产场景；架构研究不能把产品宣传当技术报告。
- 与 4.0 Turbo、不同窗口型号分开记录。
