# Claude Computer Use

> 核验日期：2026-09-01。Computer Use 是模型、屏幕截图和输入工具共同组成的代理能力，不是名为“Claude Computer Use”的独立基础模型。

## 它如何工作

1. 应用向模型提供当前屏幕截图、任务和可用的 computer 工具定义。
2. 模型返回移动鼠标、点击、输入、滚动或再次截图等结构化动作。
3. 受控执行器在真实或虚拟环境中执行动作，并把新屏幕回传。
4. 循环直到任务完成、需要人类确认或触发安全终止条件。

2024-10-22 的公开测试首先使用升级版 Claude 3.5 Sonnet。Anthropic 描述的训练方式包括让模型在简单软件环境中学习屏幕操作；这并不证明模型拥有某个公开的专用视觉网络结构。

## 发布时的评测

Anthropic 报告模型在 OSWorld 截图式设置下为 14.9%，加入更多交互步骤后为 22.0%，高于其引用的当时其他模型基线，但远低于人类水平。后续模型成绩不能回填到 2024 年首发模型。

## 核心风险

| 风险 | 典型场景 | 防护 |
|---|---|---|
| 提示注入 | 网页、邮件或文档诱导代理泄密或改目标 | 把外部内容视为不可信数据；策略层隔离指令与内容 |
| 越权操作 | 删除、转账、发送、授权、修改生产系统 | 最小权限、动作白名单、敏感动作二次确认 |
| 视觉误判 | 点击相邻按钮、遮罩层、滚动位置错误 | 动作前后截图、坐标校验、可逆操作与回滚 |
| 凭据泄露 | 截图或剪贴板含密钥、Cookie、个人数据 | 专用账号、脱敏、隔离浏览器、禁止读取主机秘密 |
| 循环失控 | 重复点击、不断重试、成本膨胀 | 步数、时间、费用上限和人工接管 |

## 工程落地清单

- 在沙箱或一次性虚拟机运行，不把个人桌面直接交给模型。
- 工具执行层校验动作，而不是相信自然语言“我不会删除”。
- 对登录、购买、发布、发送消息和权限变更设置人类确认点。
- 记录截图哈希、动作、工具结果、模型快照和策略判定，敏感日志要加密与限期保留。
- 用真实工作流评测端到端完成率、错误动作率、恢复率、人工介入率、注入攻击成功率和总成本。
