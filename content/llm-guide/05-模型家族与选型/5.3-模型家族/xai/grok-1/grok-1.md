# Grok-1

> 核验日期：2026-09-01。本文只写可回到一手材料的事实；服务规格、价格与可用区以使用当天的官方文档为准。

## 结论卡

| 字段 | 结论 |
|---|---|
| 官方名称 | Grok-1（产品）/ Grok-1 open-weights base model |
| 发布日期 | 2023-11-03（产品）；2024-03-17（权重） |
| 获取方式 | 开放基座权重；Apache 2.0 |
| 证据级别 | xAI 官方公告、model card 与仓库 |

## 发布与证据

2023 产品 Grok-1 与 2024 开放的 base checkpoint 相关但不是同一“完整产品”。

## 相对上代变化

首代产品后，xAI 开放 314B MoE 基座权重和实现入口。

## 已披露的技术事实

- 开放基座总参数 314B，MoE 每 token 激活 2 个专家。
- 官方仓库提供 JAX 实现与权重说明；发布的是原始 base model，不含完整对话产品后训练。

## 未披露与不应推断

- 训练数据、完整后训练、搜索工具与线上 Grok 产品编排没有随权重开放。
- “全开源”不准确：开放权重/代码不等于开放数据和训练过程。

## 评测协议

- model card 和公告结果只适用于声明的 checkpoint。
- 开放基座与产品对话模型不得混表。

## 适用边界

- 适合 MoE 权重与 JAX 推理研究；权重大、部署成本高。
- 线上实时搜索能力不在开放 checkpoint 内。
