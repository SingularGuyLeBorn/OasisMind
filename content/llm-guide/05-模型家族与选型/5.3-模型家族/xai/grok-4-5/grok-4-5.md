## 发布与证据

xAI 将 Grok 4.5 定位为面向 agent、编码与知识工作的旗舰版本。模型文档给出固定模型 ID 与滚动别名，生产环境应固定快照而不是默认追随 `latest`。

## 相对上代变化

相对 Grok 4.3/4.20，官方发布重点转向更长时程的 agent 工作、编码与交互式产物；这不是参数或内部架构披露。

## 已披露的技术事实

- 500K context，支持图像输入与可配置 reasoning effort。
- 支持工具调用等 API 能力；可用端点与限制须按当日文档核验。

## 未披露与不应推断

- 参数量、稀疏/稠密结构、训练数据、视觉编码器和后训练配方未公开。
- 不把合作平台的产品说明反推为底层 checkpoint 架构。

## 评测协议

复现官方或第三方榜单时记录模型 ID、reasoning effort、agent harness、工具集、token 预算与评测日期；不同脚手架成绩不可直接横比。

## 适用边界

适合闭源 API 的长时程 agent、编码和知识工作。500K 是接口上限，不保证所有位置检索或超长推理稳定。
