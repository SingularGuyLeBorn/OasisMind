# 上下文、工具与模态能力

- 标称窗口只表示接口上限；另测长文检索、位置鲁棒性、输出预算、延迟和成本。
- Function calling 需测 schema 遵循、参数正确性、拒绝非法动作和失败恢复。
- 搜索/代码执行/多智能体是系统条件；裸模型与带工具结果分开。
- 图像、音频、视频的输入与输出能力分别记录，不以“原生多模态”概括全部。

每项测试保存模型版本、服务日期、工具版本、模态预处理和完整请求参数。
