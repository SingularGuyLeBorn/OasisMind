# 部署成本与风险

## 自托管

测权重存储、显存、KV cache、量化误差、prefill/decode 吞吐、并行通信、冷启动和故障恢复。MoE 的激活参数不等于只加载激活权重。

## API

测输入/输出/缓存/工具费用、长上下文阶梯价、限流、区域、数据保留、SLA 和模型漂移。所有价格带 `as_of`，不做永久表。

## 风险

建立隐私、安全、许可证、供应商锁定、版本下线、质量漂移和回滚清单。上线评测必须包含真实失败样本与人工升级路径。
