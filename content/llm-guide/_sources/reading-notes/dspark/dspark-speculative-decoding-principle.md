# DSpark 旧散落笔记：来源与勘误记录

> 这是隐藏来源材料，不是公开教程。公开唯一正本为 [DSpark：半自回归草稿与置信度调度](../../../6-训练与推理优化/6.6-推理框架与高级优化/6.6.2-投机解码/6.6.2.4-DSpark原理解析.md)。

## 原始笔记为何下线

旧稿混合了论文公式、作者线上部署报告、V4 产品新闻和作者以外的推导，导致证据层级不清。审计后确认以下内容必须以正本为准：

- 目标模型保持冻结，但 DSpark 的并行草稿主干、顺序模块和置信度头需要训练或适配；共享 embedding 与 LM head 同样冻结。
- 置信度软监督目标是 $c_k^*=1-\tfrac12\|p_k^d-p_k^t\|_1$，不是单次采样产生的二元接受标签。
- 联合损失包含位置加权的 CE、L1/TV 分布匹配和置信度 BCE；论文默认权重为 $0.1/0.9/1.0$。
- 半自回归模块是在并行主干 logits 上加入轻量因果偏置；默认实现是秩 256 的 Markov head，RNN head 是可选方案。
- 置信度调度只选择验证前缀，不能代替标准的接受概率与首次拒绝后的修正分布。
- 分布恢复要求 $p$ 是所需目标分布、$q$ 是实际提议分布，并在接受/修正中准确使用二者；两侧不必采用相同采样变换，但不同模型或变换通常降低分布重叠与效率。首次拒绝截断和不预见未来的调度决策同样不可省略。
- 同步贪心算法的首次下降早停同时服务于因果性；全局最优还要求沿贪心路径的吞吐目标单峰。
- 真实硬件的 SPS 曲线可能阶梯化。论文的 V4 异步方案使用历史容量预测和内部 kernel 改造，不是开源仓库中的通用即插即用调度器。
- V4 Preview 的发布日期与产品状态只引用官方新闻；生产替换与速度区间只归因于 DSpark 论文的特定线上遥测，不自行推算日期，也不外推成普遍保证。
