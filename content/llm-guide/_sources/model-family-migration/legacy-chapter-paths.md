# 模型家族旧章节路径映射台账

本文件只服务于迁移追溯，不参与公共知识树导航。公共版本页只保留稳定的模型身份、事实与证据边界；旧目录编号、失效路径和文件搬迁过程统一在这里记录。

## 记录原则

- “公开正本”是当前供读者学习与引用的唯一身份页。
- 报告精译、MinerU/OCR 文本、PDF、HTML 与原图属于核对材料，不自动构成独立证据。
- 未逐项核证的架构解读、重复索引和预测稿只保存在隐藏归档，不回流为模型事实。
- 同一旧稿可能被错误地同时用于多个版本；台账保留这种一对多关系，但各正本只接收能够由一手来源确认的事实。

## 身份纠错说明

- OLMo 旧目录把 OLMoE 报告标成 “OLMo-3”。OLMoE 与 2025 年正式发布的 Olmo 3 已拆成两个身份；逐文件去向见 OLMo 详细账本。
- Muse Spark 是 Meta 的独立产品线，不是 Llama 版本；相关材料仅在 Llama 隐藏归档中保全。
- Ling 2.6 已有正式技术报告，“无公开报告”是过时判断；1T 与 flash 仍按不同成本/能力档记录。
- Step 3.7 Flash 没有从更早的 3.5 材料外推；其公开页直接以官方模型页、仓库和模型卡重建。
- DeepSeek 官方身份是 V3.1-Terminus，发布日期为 2025-09-22；“V3.2-Terminus”和 2025-06 均不是官方发布记录。
- Kimi K2.7 Code 的官方更新日志日期是 2026-06-12，不是 2026-08-12。
- Ling 2.0 的正式发布日期不是 2024-10；Lite、Plus、2.0、2.5 与 2.6 仍按官方身份分别建档。
- Gemini 2.0 Pro 只以 experimental 形式发布，不能与 Gemini 2.0 Flash 的首发或 GA 状态合并。
- Gemma 4 是具有 Dense/MoE 多档、可配置 thinking、system role 与更广模态的正式代际，不是 2025 年的单一端侧迭代。
- Qwen2.5-Math 的对应报告是 arXiv:2409.12122；arXiv:2407.04078 属于 Qwen2-Math。
- MiniCPM-S 的官方检查点身份是 MiniCPM-S-1B；1.2B 是论文中的非嵌入参数规模描述，不能替代模型 ID。
- GLM-4 开放 9B 权重使用 GLM-4 自定义模型许可，代码仓库使用 Apache-2.0；不能把整个系列统一写成 MIT。
- GLM-5.3 的初始发布/API、发布记录登记与权重仓库是三个事件：官方发布文章为 2026-08-14，统一发布记录登记为 2026-08-18，官方模型仓库 initial commit 为 2026-08-28。最后一项是仓库提交记录推定，不反写成产品发布日期。
- Meta 没有发布名为“Llama 4 技术报告”的独立论文；Llama 4 应以官方公告、模型卡、参考实现和许可证为证据。

## 被排除断言

下表记录从公共模型身份页退出的断言类别。它只说明为什么不能把这些说法当成事实，不代表相反结论已经成立。

| 类别 | 典型断言 | 排除原因 |
|---|---|---|
| 闭源模型精确架构 | Claude 的参数量、Dense/MoE、GQA/RoPE 变体；Grok 的 MoE+MLA、专家辩论网络；ERNIE 的知识注入位置 | 官方未披露；产品档位、上下文或工具能力不能反推出内部网络 |
| 产品身份混合 | Hunyuan Pro 等同 Hunyuan-Large；MiniMax M2 等同 Text-01；Step 云端 SKU 等同开放权重检查点 | 产品名、API 型号与 checkpoint 没有官方一一映射 |
| 精确训练配方 | 训练阶段比例、学习率、数据集规模、专家数、激活参数、GPU 数与固定数据比例 | 缺少技术报告、模型卡或可复验配置支持 |
| 第三方机制类比 | 用 Grok-1 或外部多智能体论文证明 Grok-4 内部结构；用通用注意力教程证明某个模型采用该机制 | 机制相似不构成目标模型的一手证据 |
| 跨版本成绩回填 | 把后续 Claude Computer Use、Step-3.5 稳定性经验或 Preview 基准回填到更早版本 | 模型快照、日期、提示、工具链与评测协议不同 |
| 服务上限反写训练规格 | 把 API 的 204,800 token 上限写成原生训练长度；把托管服务 GA 日写成模型首发日 | 服务合同字段不等于训练或发布身份字段 |
| 瞬时价格与榜单固化 | 把 API 价格、竞品榜单、“最强”措辞或无协议部署速度写成模型固有属性 | 随时间、地区、硬件、后端与评测设置变化 |
| 许可层级混淆 | 用代码仓库许可证代替模型权重许可，或把单一开放版本的许可扩展到整个系列 | 代码、权重、数据和商业服务分别受不同条款约束 |
| 预测稿进入事实层 | Qwen4 未发布结构预测、MiniMax/Claude/xAI 的自造组件名和精确规模 | 没有可核验的一手发布材料 |
