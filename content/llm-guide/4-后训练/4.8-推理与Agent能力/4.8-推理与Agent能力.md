# 4.8 推理与思考能力

SFT 和偏好对齐主要决定模型以什么格式, 什么风格回答. 本节讨论另一类目标: 多步推导要算对, 代码要跑通, 在真实环境里调用工具要把事情做完. 这类任务的共同点是结果大多可以自动验证 (答案比对, 单元测试, 环境状态), 所以训练可以直接用结果做奖励.

两篇按轨迹形态划分. 推理 RL 的一条轨迹是一段连续生成, 问题进去, 推理和答案出来; Agent RL 的一条轨迹是模型生成与环境反馈交替的多轮交互, 由此带来异步训练, 环境构造和上下文管理三类新问题.

## 阅读顺序

先读 4.5.1. 它从 STaR 的式 (2) 出发, 说明 「只保留答对的推理再微调」 就是二元奖励下的策略梯度, 然后到 R1 的 GRPO; 4.5.2 的推理 RL 和 Agent RL 都建在这套组内优势之上. 4.5.2 第 6 节的跨阶段蒸馏与 [4.6 OPD](../4.9-OPD/4.9-OPD.md) 和 [4.7 持续学习](../4.10-持续学习/4.10-持续学习.md) 第 9 节相互对照.
