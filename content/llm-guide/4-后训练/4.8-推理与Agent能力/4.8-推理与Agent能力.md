# 4.8 推理与 Agent 能力

SFT 和偏好对齐主要决定模型用什么格式, 什么口吻回答. 4.8 讨论的目标更硬: 多步推导要算对, 代码要跑通测试, 在真实环境里调工具要把任务做完. 这类任务的共同点是结果大多能自动判: 答案和标准比对, 单元测试过没过, 环境状态对不对. 训练因此可以绕开学出来的奖励模型, 直接用结果做奖励. DeepSeek-R1 报告放弃神经奖励模型的理由就是大规模 RL 中它会被钻空子, 而规则判分器只适用于答案可验证的任务, 这个限制也决定了 4.8 讨论的范围.

## 1. 从一段推理到一串交互

### 1.1 推理能力怎样进入权重

[4.8.1 推理模型训练](./4.8.1-推理模型训练/4.8.1-推理模型训练.md) 按时间顺序走一遍. 起点是提示: few-shot CoT 让 PaLM-540B 在 GSM8K 上从 17.9% 到 56.9%, zero-shot 的「Let's think step by step」让 text-davinci-002 从 10.4% 到 40.7%, 小模型加触发句反而略降. Self-Consistency 在宽度上采多条推理再投票, GSM8K 再加 17.9 个百分点. 这些方法都不改模型.

STaR 把「先写推理」训进权重: 只保留答对的推理去微调, 答不出的题用正确答案提示模型补一条推理. 4.8.1 的式 (2) 说明这正是二元结果奖励下的策略梯度, 指示函数把错误样本的梯度清零. DeepSeek-R1-Zero 保留了这个结构, 把过滤换成规则判分器, 优化器换成 GRPO: 在 V3-Base 上不做 SFT 直接 RL, AIME 2024 pass@1 从 15.6% 升到 71.0%, 回答长度随训练自己变长. R1 再加冷启动, 语言一致性奖励, 拒绝采样 SFT 和全场景 RL 四段, pass@1 到 79.8%.

### 1.2 环境进入轨迹之后

推理 RL 的一条轨迹是一段连续生成, 问题进去, 推理和答案出来. [4.8.2 Agentic 能力训练](./4.8.2-Agentic能力训练/4.8.2-Agentic能力训练.md) 处理的轨迹是 $(q,r_1,a_1,o_1,\dots,r_n,a_n,o_n)$, 其中 $r_i$ 是推理, $a_i$ 是动作, $o_i$ 是环境返回的观察. 观察 token 由环境返回, 只能作条件不能算梯度; 一次 SWE 任务几十轮, 每轮要等测试跑完, 同步 RL 会被最慢的轨迹拖住; 搜索结果和日志很快撑满上下文.

这三点各自对应一类新工作. GLM-5 用全异步的 slime 框架, 每次权重同步后重置优化器, 用 TITO 网关让训练端直接拿推理端的 token 序列, 避免重分词错位. 环境构造成了数据工作的主体: 从真实 Issue-PR 对搭出 1 万多个可验证的 SWE 环境, 覆盖 9 种语言. 上下文用 keep-recent-$k$ 折叠旧的工具观察, $k=5$ 时 BrowseComp 从 55.3% 到 62.0%, 加上超阈值后整段丢弃的分层管理到 75.9%.

## 2. 三篇共用的记号

### 2.1 组内优势与空组

三篇的优化器都是 GRPO 或它的变体. 对一道题采 $G$ 条回答, 第 $i$ 条的优势是 $\hat A_i=(R_i-\mathrm{mean})/\mathrm{std}$, 不需要价值网络. 4.8.1 手算过: 奖励 $\{1,0,0,0\}$ 时答对的那条优势约 $+1.73$, 组里答对的越少, 推力越大. 全对或全错时标准差为 0, 这一组没有学习信号. GLM-5 的 Agent RL 只减均值不除标准差, 跨阶段蒸馏干脆把组大小设成 1, 优势改由教师和学生的对数概率差给出.

空组是 [4.8.3 SFT 与 RL 的融合策略](./4.8.3-SFT与RL的融合策略/4.8.3-SFT与RL的融合策略.md) 的出发点. 基座一次都采不对的题, RL 拿不到任何梯度; 往组里放一条正确示范, 取 $G=8$, 1 对 7 错, 示范的优势约 $+2.65$, 空组有了信号. 难度分层也从这里来: GLM-5 的推理 RL 只保留 GLM-4.7 很少答对但更强教师能解的题, Snell 等按基座自己 2048 次采样的 pass@1 把题分成 5 档.

### 2.2 两个分布之间的比率

三篇都会遇到「采样的分布不是正在训练的分布」. 在 4.8.2 里, 推理引擎和训练引擎的算子与精度不同, 同一个 token 的概率比 $\rho=\pi^{\mathrm{train}}/\pi^{\mathrm{infer}}$ 不等于 1, MoE 路由和长 CoT 会放大这个偏差. GLM-5 用 IcePop 式的掩码把 $\rho$ 落在 $[0.5,2]$ 之外的 token 梯度直接置 0; 异步之后轨迹由多个版本的模型生成, 就用推理时记录的对数概率直接算比率并双边截断, 不保存历史检查点.

4.8.3 的比率问题来自示范. 示范由 DeepSeek-R1 生成, 学生对它的概率 $\pi_\theta$ 很低, 梯度可能压过 on-policy 部分. LUFFY 把行为策略概率取 1 并去掉 clip, 再用 $f(x)=x/(x+0.1)$ 整形; SRFT 用熵加权调节示范的 SFT 项; Prefix-RFT 保留 PPO 的比率和 clip, 只让高熵的前缀 token 参与. 评测口径也要对齐: 4.8.1 第 3.4 节区分了 pass@1 (每题采 $k$ 个取平均正确率) 和 cons@64 (64 个答案投票), R1-Zero 的两个数是 71.0% 和 86.7%, 比较不同报告时要先确认用的是哪一个.

## 3. 分工, 交叉与分歧

### 3.1 三篇的关键差别

| | 4.8.1 推理模型训练 | 4.8.2 Agentic 能力训练 | 4.8.3 SFT 与 RL 融合 |
|---|---|---|---|
| 轨迹 | 单段生成 | 推理, 动作, 观察交替的多轮 | 单段生成 |
| 奖励 | 规则判分 (答案, 测试) | 环境结果, 加通用 RL 的 ORM 与 GRM | 答案验证 |
| 主要材料 | CoT, STaR, PRM800K, R1, Snell 等 | GLM-5, Ring-1T 的 IcePop, Kimi K2.5 | ReLIFT, LUFFY, SRFT, Prefix-RFT |
| 示范的位置 | R1 冷启动与蒸馏, 都在 RL 之外 | SFT 数据, 通用 RL 的专家回答 | 进入 RL 的梯度 |
| 主要难点 | 奖励可验证, PRM 与 MCTS 没走通 | 训推不一致, 异步, 环境, 上下文 | 示范压掉探索, 分布离基座太远 |

三篇的前两列可以看成同一条路线的两个阶段. 推理 RL 的问题是怎样让模型愿意多算并算对, 一旦规则奖励和 GRPO 走通, 剩下的困难主要在系统上. Agent RL 把系统困难放大了: 轨迹长度极不均衡, 环境会崩溃, 工具结果把上下文撑满. 4.8.2 的失效模式一节几乎全在训练系统和环境上, 例如 DSA indexer 用非确定性 top-k 会在几步内让熵骤降, 容器崩溃的轨迹若记 0 分会惩罚无辜的动作.

第三列处理的是另一个维度: 外部示范要不要进入 RL. 4.8.1 里 R1 的做法是把示范放在 RL 前后, 冷启动用数千条长 CoT, 收敛后再拒绝采样出约 60 万条推理样本; 4.8.3 的四种方法把示范直接接进 GRPO 的梯度. SRFT 的 Table 1 给出接法顺序的影响: SFT 后接 RL 平均 52.5, RL 后接 SFT 只有 37.4, 加 KL 约束也只有 38.3. 论文用熵解释: RL 之后策略熵很低, 再做 SFT 时熵迅速上升, 性能随之骤降.

### 3.2 蒸馏在三篇里各出现一次

R1 的蒸馏是 off-policy 的 SFT. 用 RL 收敛后拒绝采样出的 80 万条样本直接微调开源小模型, R1-Distill-Qwen-32B 在 AIME 2024 上 72.6%, 同一底座做一万多步大规模 RL 的 R1-Zero-Qwen-32B 只有 47.0%. 4.8.1 记下了报告的两点结论: 把强模型的推理蒸馏到小模型效果很好; 要突破能力边界, 仍需要更强的底座和更大规模的 RL.

GLM-5 的蒸馏是 on-policy 的. 多阶段 RL 依次优化不同目标, 前面获得的能力会退化, 所以最后一个阶段用前面各阶段的最终检查点当教师, 学生在自己采样的 token 上按教师与学生的对数概率差得到优势. 4.8.3 的方法介于两者之间: 示范来自教师, 进入的却是学生自己的 GRPO 组. 三种用法的系统讨论在 [4.9 OPD](../4.9-OPD/4.9-OPD.md), on-policy 为什么忘得少见 [4.10 持续学习](../4.10-持续学习/4.10-持续学习.md).

### 3.3 证据的口径和缺口

4.8.3 的四篇论文都用 Qwen2.5-Math-7B 和同一份约 46k 题的 OpenR1-Math 子集, 成绩仍不能直接相减. 基准组合不同, 评测协议也不同, 同一个 ReLIFT 在自己的表里是 52.6, 在 SRFT 的表里是 54.0, 在 Prefix-RFT 的表里是 47.8. 四篇中只有 Prefix-RFT 报告了 $n=2048$ 的 pass@$k$: AIME24 上 96.67, 基座 86.67, SFT 76.67, 这是融合方法扩大覆盖面的唯一直接证据.

覆盖面的问题和 [RLVR 的局限性与探索边界](../4.5-GRPO家族与RLVR/09-RLVR的局限性与探索边界/09-RLVR的局限性与探索边界.md) 一文相连: Yue 等的测量说明现有 RLVR 主要在基座已经能解的题上提高采样效率. 4.8.1 最后一节从推理阶段算力的角度给了同样方向的结论: Snell 等发现最难的一档题上加推理阶段算力几乎没有回报, 应该换更强的底座. 这一点在三篇里是一致的: RL 擅长把已有的能力用得更稳, 新能力要靠示范, 蒸馏或预训练带进来.

## 4. 读法

### 4.1 按背景进入

对 RL 算法不熟的读者, 先读 [4.8.1](./4.8.1-推理模型训练/4.8.1-推理模型训练.md) 第 2.1 节的 STaR 和第 3.2 节的 GRPO, 两处都有手算, 能把「只保留答对的推理再微调」和策略梯度对上. 算法细节和变体在 [GRPO](../4.5-GRPO家族与RLVR/01-GRPO/01-GRPO.md) 一文, RL 算力能否预测见 [ScaleRL](../4.5-GRPO家族与RLVR/10-ScaleRL-尺度定律的再发现/10-ScaleRL-尺度定律的再发现.md). 4.8.1 第 1.1 节的深度轴另有结构上的讨论, 见 [2.8.4 循环 Transformer](../../2-核心原理与架构/2.8-其他架构方向/2.8.4-循环Transformer/2.8.4-循环Transformer.md).

做训练系统或基础设施的读者, 直接读 [4.8.2](./4.8.2-Agentic能力训练/4.8.2-Agentic能力训练.md) 第 2 和第 3 节. 训推不一致, DSA indexer 的确定性, 异步 RL 的优化器重置, 双边重要性采样和陈旧样本丢弃, 都是可以单独拿去对照自己框架的检查项. 环境构造和奖励黑客在第 4 节, 幻灯片 RL 的硬截断和间距操纵是规则奖励被钻空子的具体例子.

### 4.2 按问题选篇

手上有强模型的示范, 想知道该先 SFT 还是混进 RL, 读 [4.8.3](./4.8.3-SFT与RL的融合策略/4.8.3-SFT与RL的融合策略.md). 它第 1 节用空组, SFT 的梯度形式和难度分层三个观察说明两阶段训练的问题, 第 6 节把四种方法的成绩口径逐一对齐. 想了解 SFT 本身的 RL 视角, 可以对照 [4.2.3 DFT 与 SFT 的 RL 视角](../4.2-SFT/4.2.3-DFT与SFT的RL视角/4.2.3-DFT与SFT的RL视角.md).

想知道推理阶段的算力该怎么花, 读 4.8.1 第 4.3 到 4.5 节. Snell 等在 PaLM 2-S* 上按难度选择搜索或修改策略, 达到 best-of-N 同样效果最多可少用约 4 倍生成次数; 推理负载与预训练量之比 $R$ 越大, 小模型加推理算力相对 14 倍大模型的优势越小. 想知道并行 agent 怎样训练, 读 4.8.2 第 5.2 到 5.4 节的 Kimi K2.5 PARL, 它只训 orchestrator, 用关键路径步数衡量延迟.
