# 4 后训练: SFT, 对齐, 蒸馏与持续学习

预训练的目标是 next-token 预测, 数据量大, 来源杂. 后训练在预训练之后接上一串阶段: SFT 教会指令格式和领域行为; 基于奖励模型或偏好数据的方法把输出对齐到人的偏好; 可验证奖励 RL 训练推理和 Agent 能力; on-policy 蒸馏把教师的能力迁到学生, 也用来找回多阶段训练中丢掉的能力; 持续学习处理部署后的更新与遗忘.

注意力, MoE 和推理优化在 [第 2 章](../2-核心原理与架构/2-核心原理与架构.md); 预训练流程在 [第 3 章](../3-预训练/3-预训练.md); 各家模型如何组合这些方法见 [主流模型知识库](../../model-library/_garden.md); Agent 系统见 [第 13 章 Agent](../13-Agent/13-Agent.md).

## 各节之间的关系

**从 SFT 到 RL.** 4.2 的 SFT 在给定示范上做最大似然; 4.2.3 从 RL 的角度重新解释这个目标. 4.4 的方法分两路: 4.4.1 先训练奖励模型 (或用可验证奖励) 再做策略梯度, 从 PPO 到 GRPO 去掉价值网络, 用组内均值作基线; 4.4.2 的 DPO 一路把奖励模型写成策略与参考策略的对数比, 直接在偏好对上优化. 4.4.0 给出这些方法共用的马尔可夫决策过程和策略梯度推导.

**推理与 Agent.** 4.5.1 从 CoT 提示讲到 DeepSeek-R1 的可验证奖励 RL; 4.5.2 把同一套组内优势放进多轮环境交互, 处理异步训练, 训推不一致和环境构造. 4.4.7 讨论这类 RL 能把模型推到多远, 4.8 讨论 RL 算力投入的回报能否提前预测.

**蒸馏与遗忘.** 4.6 的 on-policy 蒸馏让学生在自己采样的前缀上接受教师的逐 token 监督. 4.7 用精度矩阵量化遗忘, 并说明为什么 on-policy 训练 (RL 或 OPD) 比 SFT 忘得少; GLM-5 在多阶段 RL 之后加一轮跨阶段 on-policy 蒸馏 (4.5.2 第 6 节), 是这两节在同一条流水线里的结合.
