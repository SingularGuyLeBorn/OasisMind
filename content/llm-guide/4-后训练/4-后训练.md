# 4 后训练: SFT, 对齐, 蒸馏与持续学习

预训练的目标是在网页, 书籍和代码上预测下一个 token. 这个目标和「按用户意图办事」之间有一段距离: InstructGPT 在 API 提示分布上测得, 1.3B 的 InstructGPT 输出比 175B 的 GPT-3 更受标注员偏好, 两者架构相同, 区别只在后训练. 训练 175B 的 PPO-ptx 模型用了约 60 petaflops/s-days, GPT-3 预训练是 3,640. 用不到预训练 2% 的算力换来这种行为变化, 是后训练单独成章的原因. 这一章讲的方法都作用在预训练之后: 用什么信号, 以什么损失, 在谁的样本上更新模型, 以及更新之后旧能力会不会丢.

注意力, MoE 和推理优化在 [第 2 章](../2-核心原理与架构/2-核心原理与架构.md); 预训练流程和 Scaling Laws 在 [第 3 章](../3-预训练/3-预训练.md); 各家模型怎样组合这些方法见 [主流模型知识库](../../model-library/_garden.md); Agent 系统本身见 [第 13 章 Agent](../13-Agent/13-Agent.md).

## 1. 三种信号与一组共用记号

### 1.1 基座缺的是行为

[4.0 后训练概述](./4.0-后训练概述/4.0-后训练概述.md) 用 InstructGPT, Llama 2, Tülu 3, DeepSeekMath 和 DeepSeek-R1 的原文对照了后训练能补多少. InstructGPT 的闭域任务编造率从 41% 降到 21%, TruthfulQA 上真实且有信息的回答约为 GPT-3 的两倍; 但只用 PPO 时 SQuAD, DROP, HellaSwag 和翻译会退步, 要混入预训练梯度才能补回大部分. 这组数字给出了后训练的作用范围: 它改的是格式, 语气, 拒绝编造和安全边界, 知识主要来自预训练.

底座决定上限这一点在 SFT 阶段就能看到. Tülu 3 用同一份 SFT 数据训不同底座, Qwen 2.5 7B 的 MATH 比 Llama 3.1 8B 高 17.9 分, 加过数学预训练的 Qwen 2.5 Math 7B 又高 7.0 分. LIMA 据 1000 条数据的结果提出「表面对齐假说」: 对齐教的是与用户交互时用哪种格式的子分布. 后面各节的方法, 无论 SFT 还是 RL, 都在这个上限之内调整模型, 只有 4.5 节讨论的长时间 RL 和 4.9 节的蒸馏在少数任务上给出了扩大覆盖的证据.

### 1.2 示范, 偏好, 可验证奖励

后训练的信号分三种. 示范是 (prompt, 标准回答), 直接告诉模型该输出什么, 对应 SFT; 偏好是同一 prompt 下的较好和较差回答, 只说哪个更好, 对应奖励模型加 PPO 或 DPO 一族; 可验证奖励是一个判定函数, 数学比对答案, 代码跑测试, 对应 RLVR. 三种数据的来源, 标注协议和公开数据集的真实规模在 [4.1 后训练数据](./4.1-后训练数据/4.1-后训练数据.md).

| 信号 | 典型损失 | 是否在训练中采样 | 主要章节 | 主要代价 |
|---|---|---|---|---|
| 示范 | 交叉熵, 只对回答计损失 | 否 | 4.2, 4.3 | 写完整回答贵, 上限是示范本身 |
| 偏好 (离线) | DPO 及其变体 | 否 | 4.6.1 | 数据来自别的模型, 训练中分布偏移 |
| 偏好 (在线) | 奖励模型加 PPO, 在线 DAP 损失 | 是 | 4.4, 4.6.2, 4.7 | 要驻留奖励模型或标注器, 会被过优化 |
| 可验证奖励 | GRPO 一族 | 是 | 4.5, 4.8 | 只适用于能被程序判对错的任务 |
| 教师分布 | 学生前缀上的逐 token KL | 是 | 4.9 | 要一个教师, 教师与学生要兼容 |

表里最终一行是第四种信号: 教师模型在学生自己生成的前缀上给出完整的下一个 token 分布. 它比示范稠密, 每个 token 都有监督; 又和 RL 一样在学生自己的分布上采样. 4.9 节的 OPD 和 4.10 节讨论的遗忘问题都围绕这一行展开.

### 1.3 共用的目标和记号

全章反复出现的目标是 KL 正则的期望奖励:

$$
\max_{\pi_\theta}\ \mathbb{E}_{x\sim\mathcal D,\ y\sim\pi_\theta(\cdot\mid x)}\bigl[r(x,y)\bigr]-\beta\,D_{\mathrm{KL}}\bigl(\pi_\theta(\cdot\mid x)\,\|\,\pi_{\mathrm{ref}}(\cdot\mid x)\bigr). \tag{1}
$$

$x$ 是 prompt, $y$ 是整段回答, $\pi_\theta$ 是正在训练的策略, $\pi_{\mathrm{ref}}$ 是冻结的参考模型 (通常是 SFT 模型), $r$ 是奖励, 来自奖励模型或判定函数, $\beta$ 控制策略离参考多远. 用旧策略 $\pi_{\mathrm{old}}$ 的样本做多步更新时, token 级重要性比率记为 $r_t(\theta)=\pi_\theta(y_t\mid x,y_{<t})/\pi_{\mathrm{old}}(y_t\mid x,y_{<t})$, 优势记为 $\hat A$. 4.4 到 4.6 节的方法都可以看作式 (1) 的不同解法: PPO 用价值网络估优势, GRPO 用同组样本的奖励均值当基线, DPO 用式 (1) 最优解的闭式形式把奖励写成 $\beta\log(\pi_\theta/\pi_{\mathrm{ref}})$, 不再需要显式的 $r$. 推导在 [4.4 节 01 篇](4.4-强化学习基础/01-强化学习的数学原理/01-强化学习的数学原理.md).

DeepSeekMath §5.2.1 把 SFT, 拒绝采样微调, DPO, PPO, GRPO 的梯度写成同一个形式, 差别只在三项: 数据从哪来 (人工数据还是当前策略的采样), 奖励函数是什么, 每个样本的梯度系数是多少. SFT 的系数恒为 1, PPO 的系数是优势. 这个统一写法是对照全章方法最省事的坐标: 读到一个新方法, 先问它改的是数据源, 奖励还是系数.

## 2. 各节在流水线上的位置

### 2.1 数据, SFT 与 PEFT

[4.1](./4.1-后训练数据/4.1-后训练数据.md) 讲三类数据从哪来, [4.2 SFT](./4.2-SFT/4.2-SFT.md) 讲示范信号怎样进入损失. SFT 的细节比公式看上去多: 损失按 token 平均还是按样本平均, 梯度累积切几份, 模板末尾有没有换行, 都会改变结果, Tülu 3 因此改用 sum loss, 模板变体之间平均分差 1.4. 4.2.3 再从策略梯度的角度把 SFT 梯度拆成奖励 $\mathbf 1[y=y^*]$ 和权重 $1/\pi_\theta$, DFT 一族由此修改 token 权重.

[4.3 PEFT](./4.3-PEFT/4.3-PEFT.md) 不改训练目标, 只改哪些参数可训练. 混合精度 Adam 每参数约 16 字节, 7B 模型的模型状态约 108GB, LoRA 和 QLoRA 把可训练参数压到 1% 以下, 65B 的微调能放进 48GB. 它和后面各节是正交的: SFT, DPO 和 RL 都可以挂 LoRA 跑. 代价是 LoRA 在代码和数学的继续预训练上学得比全参数少, 同时忘得也少.

### 2.2 在线 RL: 从 PPO 到 GRPO

[4.4 强化学习基础](./4.4-强化学习基础/4.4-强化学习基础.md) 从 MDP, 策略梯度和信任域讲到 TRPO, PPO, 再到不建价值网络的 REINFORCE, RLOO 和 ReMax. InstructGPT 的 RLHF 要同时驻留策略, 价值网络, 奖励模型和参考模型四份模型; Ahmadian 等发现在 RLHF 里把整段回答当一个动作, 用留一法基线, 胜率反而高于 PPO.

[4.5 GRPO 家族与 RLVR](./4.5-GRPO家族与RLVR/4.5-GRPO家族与RLVR.md) 接着讲 DeepSeekMath 的 GRPO 和它之后的改法. GRPO 用同一道题 $G$ 条回答的奖励均值和标准差做优势, 去掉价值网络; Dr.GRPO, GSPO, GMPO, CISPO, SAPO, DAPO 分别改归一化, 比率粒度和裁剪方式. 这一节还收了两个大问题: RLVR 提高的是采样效率还是覆盖, 以及 RL 算力的回报能否用一条 sigmoid 曲线提前预测.

### 2.3 偏好优化与 AI 反馈

[4.6 偏好优化](./4.6-偏好优化/4.6-偏好优化.md) 处理只有偏好, 没有标量奖励的情形. 4.6.1 的 DPO 一族在固定的偏好对上训练, 不训奖励模型, 不在训练中采样; 4.6.2 让当前策略在线生成回答, 胜负由 LLM 标注器, 偏好模型或人写的示范判定, 并把偏好看成博弈求 Nash 均衡. 离线一路省算力, 在线一路解决离线数据与当前策略不匹配的问题.

[4.7 AI 反馈与奖励过优化](./4.7-AI反馈与奖励过优化/4.7-AI反馈与奖励过优化.md) 讲偏好标签由谁给, 以及打分器被优化过头时会怎样. Constitutional AI 和 RLAIF 把人工偏好换成模型按原则给出的偏好; Gao 等用 6B 的金标奖励模型测出 Best-of-$n$ 和 PPO 优化代理奖励时, 金标分随 KL 先升后降. RAFT, BOND, WARP 是在训练里逼近 Best-of-$N$ 或用权重平均控制过优化的几种做法.

### 2.4 推理, Agent, 蒸馏与遗忘

[4.8 推理与 Agent 能力](./4.8-推理与Agent能力/4.8-推理与Agent能力.md) 把前面的算法放进具体的训练流程. 4.8.1 从 CoT 提示走到 DeepSeek-R1 的可验证奖励 RL 和蒸馏; 4.8.2 以 GLM-5 为主线讲 Agent RL 的异步框架, 训推不一致和上万个可验证环境的构造; 4.8.3 比较 ReLIFT, LUFFY, SRFT, Prefix-RFT 四种把示范接进 GRPO 的方式.

[4.9 OPD](./4.9-OPD/4.9-OPD.md) 讲 on-policy 蒸馏: 学生自己采样, 教师在学生前缀上逐 token 给分布. 它在各家流水线里占的位置不同, Qwen3 用它让大模型教小模型, DeepSeek-V4, Kimi K3, MiMo 用它把分域专家合成一份权重. [4.10 持续学习](./4.10-持续学习/4.10-持续学习.md) 从精度矩阵, EWC 和回放讲到 RL's Razor: 遗忘量可以用新任务上相对基座的 KL 预测, on-policy 训练偏向 KL 小的解, 所以 RL 和 OPD 比 SFT 忘得少. GLM-5 在多阶段 RL 之后加一轮跨阶段 on-policy 蒸馏, 用前面各阶段的检查点当教师找回被冲掉的能力 ([4.8.2 第 4.1 节](./4.8-推理与Agent能力/4.8.2-Agentic能力训练/4.8.2-Agentic能力训练.md); 原理见 [4.10 第 5 节](./4.10-持续学习/4.10-持续学习.md)), 这是 4.9 和 4.10 在同一条流水线里的结合.

## 3. 哪些方法可以互相替代

### 3.1 替代关系对照

很多方法之间的选择, 实际是在同一个目标下换一种代价. 下表按「拿掉了什么, 换来了什么」排列:

| 方法 | 相对谁 | 拿掉的东西 | 新增的代价 | 依据 |
|---|---|---|---|---|
| GRPO, RLOO, ReMax | PPO | 价值网络 | 每题多采几条回答 | ReMax 显存约为 PPO 的 54% |
| DPO | PPO + 奖励模型 | 奖励模型, 在线采样 | 只能从固定偏好对学 | TL;DR 胜率 61% 对 57% |
| SimPO, ORPO, CPO | DPO | 冻结参考模型 | 要用长度平均或 SFT 项补正则 | Mistral-Base 上 SimPO LC 比 DPO 高 6.4 |
| OAIF, Online IPO | DPO | 离线数据的分布偏移 | 每步要一次标注或偏好模型前向 | 在线对离线人评胜率约 66% |
| RLAIF | RLHF | 人工偏好标注 | AI 标签与人工标签一致率 68% 到 78% | 摘要上 RLAIF 对 RLHF 胜率 50% |
| OPD | SFT 蒸馏 | 学生前缀与教师前缀的错位 | 每步要教师前向 | Qwen3 Table 21 的算力对比 |

表的读法是看第三, 四列. 去掉价值网络的方法用多采样换显存; 去掉奖励模型的方法用离线数据换算力, 结果是失去在线探索; 去掉参考模型的方法省一份前向, 但要另找东西把策略留在合理范围内. 在线偏好方法把 DPO 拿掉的那部分在线性加了回来, 只是打分器换成了 LLM 或偏好模型.

替代并不对称. GRPO 替代 PPO 的前提是奖励只在终点给出, 转移是确定的, 这两条在 LLM 上成立, 所以 4.4 节的几篇都能在胜率上追平或超过 PPO; DPO 替代 PPO 的前提是任务不需要试错, 这一条在数学和代码推理上不成立, 那里仍是 GRPO 一族的地盘.

### 3.2 替代的边界

有三类问题不能靠换算法解决. 第一是覆盖: Yue 等在 AIME24 上取 $k=1024$, 只有 RL 模型能解的题占 0.0%, 只有基座能解的占 13.3%, 数学上的 RLVR 主要在基座已会的题上提高采样效率; ProRL 在更长训练, 更杂任务和蒸馏起点上给出了覆盖扩大的反例. 第二是打分器本身: 奖励模型, 偏好模型和 LLM 标注器都只是人类偏好的近似, 优化压力加大后总会被利用, 4.7 节的过优化曲线和 4.6.2 节 Nash-MD 实验里的 preference hacking 是同一个现象. 第三是遗忘: SFT 的目标分布可能离基座任意远, on-policy 方法只在基座有概率的地方移动, 这个差别由 4.10 节的 KL 定律刻画.

示范和 RL 也不是二选一. DeepSeek-R1-Zero 证明不做 SFT 也能靠 RL 学出推理, 但可读性差, R1 又把冷启动 SFT 加了回来; 4.8.3 的四种方法把示范放进 GRPO 的组内或前缀里, 给 RL 采不到的难题提供一条正确轨迹. 4.2.3 的 DFT, ASFT, PSFT 则从另一侧出发, 在 SFT 损失里引入 RL 的权重或裁剪.

## 4. 读法

### 4.1 按问题进入

想先建立全局, 从 [4.0](./4.0-后训练概述/4.0-后训练概述.md) 读起, 它用五份技术报告把三种信号和八类失效对照了一遍, 再读 [4.1](./4.1-后训练数据/4.1-后训练数据.md) 看数据. 要自己跑 SFT 的, 读 [4.2](./4.2-SFT/4.2-SFT.md) 的 4.2.1 和 4.2.2, 显存不够时接 [4.3](./4.3-PEFT/4.3-PEFT.md) 的 LoRA 一篇.

做数学, 代码一类可验证任务的 RL, 路线是 [4.4](./4.4-强化学习基础/4.4-强化学习基础.md) 的 01 和 04 篇打底, 然后读 [4.5](./4.5-GRPO家族与RLVR/4.5-GRPO家族与RLVR.md) 的 GRPO 与结构扩展, 再读 RLVR 局限性和 ScaleRL 两篇判断收益. 只有偏好数据, 不想在训练中采样时, 读 [4.6.1](./4.6-偏好优化/4.6.1-离线偏好优化/4.6.1-离线偏好优化.md); 担心离线数据和当前模型对不上, 接 [4.6.2](./4.6-偏好优化/4.6.2-在线偏好与自对弈/4.6.2-在线偏好与自对弈.md).

### 4.2 按背景进入

熟悉深度学习但没碰过 RL 的读者, 先读 [4.4 节 01 篇](4.4-强化学习基础/01-强化学习的数学原理/01-强化学习的数学原理.md) 的策略梯度, 基线和 KL 正则闭式解三部分, 这三样是后面所有方法的公共底座. 熟悉经典 RL 的读者可以跳过它, 直接看 [4.4 节 02 篇 REINFORCE](4.4-强化学习基础/02-REINFORCE-序列级策略梯度/02-REINFORCE-序列级策略梯度.md) 里 LLM 场景与 Deep-RL 基准的差别, 那里解释了为什么 PPO 的很多设计在 RLHF 里用处不大.

关心训练流水线如何搭的读者, 读 [4.8](./4.8-推理与Agent能力/4.8-推理与Agent能力.md) 的 GLM-5 一篇和 [4.9](./4.9-OPD/4.9-OPD.md) 里各家报告的对照, 再看 [4.10](./4.10-持续学习/4.10-持续学习.md) 理解多阶段训练为什么会回退. 关心对齐安全与打分器可靠性的读者, 重点读 [4.7](./4.7-AI反馈与奖励过优化/4.7-AI反馈与奖励过优化.md) 和 4.6.2 的 Nash-MD 一篇.
