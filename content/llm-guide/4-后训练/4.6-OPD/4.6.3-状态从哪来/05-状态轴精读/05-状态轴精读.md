# 后训练看状态不看 token

后训练常被写成换损失函数：SFT 是交叉熵，RL 是策略梯度，蒸馏是 KL。卡住的地方是：同一套 token 级损失，打在不同前缀上，可以走出完全不同的模型。nrehiew 的博客把这件事叫分布透镜；Dong Nie 的小规模对照实验把它收成两根轴：状态从哪来，信号从哪来。本篇读这两份一手，再对照网上讲法。名字、Table 21 分母、MiniLLM / GKD 两条梯度仍以 [01](../../01-OPD-学生前缀蒸馏/01-OPD-学生前缀蒸馏.md) 为准。**不是** Online Preference，也不是把 OPD 定义成 Reverse KL。

## 1. 两份原文，一根轴

中文圈最近传的那篇「从分布视角看 SFT / RL / OPD」，英文原题是 *SFT, RL, and On-Policy Distillation Through a Distributional Lens*，作者 nrehiew，站点 wh.。[01](../01-分布视角-英文/01-分布视角-英文.md) 是站点 HTML 誊录，[02](../02-分布视角-中译/02-分布视角-中译.md) 是中译。博客自己的实验是 Minimal Code Editing：SFT 教师 LiveCodeBench v6 掉到 0.286，RL 教师 0.320；两边的 OPD 学生却长得很像，从 SFT 教师蒸出来的学生 Pass@1 0.800，还略高于 RL 教师的 0.792。

Dong Nie 的 [arXiv:2605.22731](https://arxiv.org/abs/2605.22731)（2026-05-21）把同一根轴写成论文。状态 $s_t=(x,y_{<t})$，SFT 在 $d_{\mathrm{data}}$ 上拟合，RL / OPD 在学习器自己的 $d^{\pi}$ 上更新。[03](../03-Nie-状态轴-英文/03-Nie-状态轴-英文.md) / [04](../04-Nie-状态轴-中译/04-Nie-状态轴-中译.md) 是论文原文和中译。实验是 Qwen3-0.6B-Base + LoRA、单卡 3090、GSM8K 做目标、TruthfulQA / MMLU 做保持。论文给的代码仓 https://github.com/ginobilinie/unifyPostTraining 在 2026-08-30 访问为 404。

两份材料互为对方缺的那一半。博客有代码编辑任务上的教师对照，和「最近最优策略」那张几何；论文有受控的加压 SFT、一步 KL 崩盘、以及 MMD 几乎相等但保持差一截。网上的专栏大多从博客起笔，再引用论文 Table 2。知乎不当事实源，数字以博客表和论文表为准。

## 2. 状态不是一个 token

自回归策略是

$$
\pi_{\theta}(y_{t}\mid x,y_{<t}). \tag{1}

$$

Nie 把条件上下文写成状态

$$
s_{t}=(x,y_{<t}). \tag{2}

$$

同一个数字，接在正确推理链后面和接在自相矛盾的链后面，是两次不同的更新，因为碰到的 $s$ 不同。策略一变，未来会访问的前缀集合 $d^{\pi}$ 也变。后训练不只改固定上下文上的 token 概率，还改模型下一步会走到哪里。

nrehiew 把模型直接说成「序列上的一个分布」。两种说法差一个粒度：博客谈的是轨迹分布怎么被拉；论文把轨迹再拆成逐步状态。精读里两套记号并用：谈到「拉向数据集」时跟博客，谈到「这个前缀上查教师」时跟论文。

## 3. 拆开两根轴

一个后训练步骤，Nie 写成三件事：从 $q_k$ 抽状态，从 $\mathcal{S}(s)$ 拿信号，再对 $\pi_{\theta}(\cdot\mid s)$ 做一步更新。许多争论把这两根轴压进算法名。SFT 被说成交叉熵，RL 被说成奖励，蒸馏被说成 KL。拆开之后，同一教师、两种前缀，是两个问题：教师轨迹上的 KL 是离线模仿；学生轨迹上查询同一教师，是 on-policy 校正。

![SFT uses dataset prefixes and gold tokens; OPD uses student prefixes and teacher continuations; RL uses student prefixes and sparse reward](./images/fig-state-signal-two-axes.png)

> 图 1：三列从左到右是 SFT、OPD、RL。上格是状态从哪来，下格是信号从哪来。竖箭只在同一列里从上格底边进到下格顶边。红标：不是同一套交叉熵打在不同前缀上就还是同一个学习问题。

**图 1 解析**

- **左列，冰蓝色上格**：状态来自数据集 / 教师轨迹 $d_{\mathrm{data}}$。下格是黄金 token。监督密，但前缀不是学生推理时会走到的那些。
- **中列，桃色上格**：状态来自学生 $d^{\pi_S}$。下格是教师的 logits 或短续写。信号仍密，前缀换成学生自己的。
- **右列，桃色上格**：状态同样来自学生。下格是稀疏奖励。前缀对了，密度没了。
- **红标**：把 SFT 的交叉熵搬到学生前缀上（Iterative-SFT / DAgger / 论文里成功的 continuation-OPD），学习问题已经变了，不要仍叫「还是 SFT」。

nrehiew 的 Minimal Editing 表和 Nie 的 Table 1 是同一张图的两种画法。博客强调目标分布离起始策略有多远；论文强调 $q_k$ 是否依赖当前 $\theta$。

Ross et al. 的 DAgger 界说仍然是这条轴的资格条件：训练分布上每步误差 $\epsilon$，学习者自己走状态时，轨迹总偏差按 $O(\epsilon T^{2})$ 复合，而不是独立误差的 $O(\epsilon T)$。推理链一长，一步偏后面全是没练过的 $s$。$O(\epsilon T)$ 是资格条件，不是免费定理：学生前缀严重 OOD 时，教师条件分布自己会坏。Nie 的「学生超过退化教师」依赖的是另一头——教师的局部条件在学生可达的 $s$ 上仍有用，全局轨迹已经坏了。两边都成立时，OPD 才是校正而不是抄一份更差的轨迹。

## 4. SFT 可以温和，也可以加压到废

Nie 的阴性对照必须先读：温和 SFT 把 GSM8K 从 0.448 提到 0.512，TruthfulQA 0.295、MMLU 0.444，平均保持比 1.0008。SFT 不是天生破坏。加压 SFT（5 epoch，学习率 $5\times 10^{-4}$，LoRA rank 64 / alpha 128）把 GSM8K 打到 0.420，TruthfulQA 0.245，MMLU 0.364，保持比 0.8258。目标任务也掉了。遗忘在这里不是「学新的就会丢旧的」这么一句，而是稠密 off-policy 更新把策略推到自己 rollout 到不了、也修不回来的区域。

nrehiew 那边，SFT 教师在最小编辑上 Pass@1 0.775，但 LiveCodeBench v6 只有 0.286；RL 教师 Pass@1 0.792，LCB 0.320。专项能力两边都学会了，通用代码生成只在 SFT 教师上明显掉。博客把原因写成：交叉熵从峰和谷一齐施压，分不清任务关键 token 和数据集里偶然带上的词。

Chen et al. 的 *Retaining by Doing*（[arXiv:2510.18874](https://arxiv.org/abs/2510.18874)）是这条线上更早的实验：抗遗忘的承重件是 on-policy 数据，不是 KL 正则，也不是优势估计。nrehiew 明确写：RLVR 里把 KL 惩罚拿掉或拧得很松，抗遗忘往往还在，所以「SFT = Forward KL、RL = Reverse KL」最多算半句。

## 5. 学生超过退化教师

nrehiew 预期 RL 教师蒸出的学生会更好。表不是这样：


| 模型            | Pass@1 | LCB v6 |
| ----------------- | -------- | -------- |
| SFT 教师        | 0.775  | 0.286  |
| RL 教师         | 0.792  | 0.320  |
| OPD ← SFT 教师 | 0.800  | 0.297  |
| OPD ← RL 教师  | 0.787  | 0.314  |

两个 OPD 学生彼此接近。从 SFT 教师蒸出来的学生，Pass@1 高于两个教师，LCB 也高于 SFT 教师自己。如果教师分布是主因，学生应当把教师的遗忘一起继承。它没有。博客的判断：数据从哪来（学生自己的前缀）比教师是谁更承重；可以先用蛮力 SFT 把专项教师训过头，再 OPD 把能力迁到学生身上。

Nie 把同一现象收到更干净的格子里。加压 SFT 教师：GSM8K 0.420 / TruthfulQA 0.245 / MMLU 0.364。从它做 OPD：0.466 / 0.275 / 0.430，三列都超过教师。论文把教师表现拆成两块：局部条件 $\pi_T(\cdot\mid s)$，以及教师自己爱走的轨迹 $d^{\pi_T}$。加压 SFT 可以毁掉后者，而前者在学生走到的许多 $s$ 上仍然有用。学生问的是「我现在这里，教师下一步会怎样」，不是「教师自己会去哪些状态」。

![Student samples prefix s; frozen teacher is queried only at s and returns a short continuation; student learns that continuation](./images/fig-opd-query-student-state.png)

> 图 2：学生自己 rollout 出前缀 $s$。冻结的教师只在这个 $s$ 上被查询，给出短续写。学生用交叉熵学续写。虚线是教师自己的轨迹，这条路径不进损失。

**图 2 解析**

- **左，桃色**：学生策略采样。状态分布 $d^{\pi_S}$ 由学生决定。
- **中，白色 $s$**：当前前缀。箭头从学生框右边中点进 $s$ 左边中点。
- **右上，冰蓝色教师**：冻结。只在 $s$ 上被问「下一步」。不把教师完整轨迹抄过来。
- **右下，交叉熵**：学生在教师续写上更新。这是 Nie 实验里唯一没崩的 OPD 变体。
- **底栏虚线**：教师自己的 rollout。标了 NOT COPY。

Agarwal et al. 2023 已经在 GSM8K 上看到过蒸馏学生超过教师。nrehiew 补了两条假说：监督打在学生自己的错误区域；KL 匹配不是奖励最大化，教师分布里的风格、不确定性、备选续写可以改采样行为，而不必复现教师的贪心输出。后一条他写明是推测。

## 6. 一步 KL 会崩，续写才站住

Nie 有一句很硬、也最容易被 01 那篇地基文漏掉的话。一步 next-token KL 在他们的 run 里把 GSM8K 打到 0.040。换成教师从学生状态生成短续写、学生用交叉熵去学，目标任务才回来。成功变体更像 DAgger：学生控制状态，教师给局部修复，损失是续写上的 NLL，不是 MiniLLM 那条对学生采样路径反传的 reverse KL。

一步 KL 崩到 0.040，可以想成：每个前缀只拿到教师在该点的局部分布，没有「从这里把题做完」的轨迹级示范。GSM8K 这种要走完一条算术链的任务，局部匹配可以把质量推到短、错、高置信的续写上。教师短续写把监督从「下一步的词表」拉成「接下来一小段该怎么走」，状态来源仍是学生，信号密度接近 SFT。这就是为什么成功变体看起来像「学生前缀上的 SFT」，而不是 01 文里 MiniLLM 的 reverse KL + policy gradient。GKD 的梯度不对采样路径反传，状态已经 on-policy；Nie 的 continuation-OPD 连损失都收成 NLL。三条路共享状态来源，不共享散度方向。

Mukherjee et al. 发现 RL 更新更稀疏、Yuan et al. 发现裁参数时 RL 掉得更快。nrehiew 认为这两条对 SFT vs RL 站得住，但不足以解释 OPD：OPD 的监督也是稠密 token 级，却继承了 RL 的抗遗忘。承重件只好回到 on-policy 数据，而不是「更新有多稀」。

本库 [01](../../01-OPD-学生前缀蒸馏/01-OPD-学生前缀蒸馏.md) 把 OPD 的招牌写成 reverse KL，那是 MiniLLM 的目标，不是 OPD 的定义。[4.6.2 综述](../../4.6.2-OPD综述/4.6.2-OPD综述.md) 已经把采样源和 $f$-散度拆开。Nie 的崩盘是另一条证据：就算散度写成 KL，若只在每个前缀上给一步局部分布、不教如何把轨迹走完，推理任务仍可能学废。Qwen3 报告只写 minimize KL，未点名正反向；V4 用全词表 reverse KL，K3 用 clip 对数比，分叉见 [09](../../09-MOPD-多教师蒸馏/09-MOPD-多教师蒸馏.md) / [10](../../10-OPD-各家报告对照/10-OPD-各家报告对照.md)。不要把 0.040 和 17,920 GPU hours 写进同一句。

nrehiew 把 OPD 松散类比为「用学生–教师对数比代替优势」。类比有用，但不等于实现。他后文自己也说：KL 匹配 $\neq$ 奖励最大化，OPD 的熵坍缩比 RL 更剧烈。Thinking Machines 的工业博文（2025-10-27）选的是 per-token reverse KL，并用 Tinker 复现 Qwen3「大约十分之一 RL 算力」那一格。那一格的分母只在 Qwen3 Table 21：同一 off-policy distilled 8B、只比 math+code、AIME'24 括号 pass@64。不要把博文的工程选择读成 Nie 的成功变体。

## 7. MMD 几乎一样，遗忘不是一回事

Nie 最初想用标量状态漂移解释遗忘。加压 SFT 的 MMD 是 0.01093，从加压教师做 OPD 是 0.01092，on-policy RL 是 0.01098。三个数贴在一起。保持比却是 0.8258、0.9515、0.9902。漂移幅度几乎说明不了谁在忘。

把 Table 2 整行摊开，对照才清楚。基座 GSM8K 0.448 / TruthfulQA 0.300 / MMLU 0.436。温和 SFT：0.512 / 0.295 / 0.444，MMD 0.00956，遗忘 −0.0015（保持略涨）。加压 SFT：0.420 / 0.245 / 0.364，MMD 0.01093，遗忘 0.0635，保持比 0.8258。从温和教师做 OPD：GSM8K 仍是 0.512，保持 0.9810，MMD 反而最大（0.01470）——漂移大、忘得不多。从加压教师做 OPD：0.466 / 0.275 / 0.430，MMD 0.01092，保持 0.9515。轻量 RL：0.472 / 0.290 / 0.442，MMD 0.01098，遗忘 0.0020。目标涨幅最大的是温和 SFT（+0.064），不是 RL（+0.024）也不是加压教师上的 OPD（相对基座 +0.018，相对教师 +0.046）。这篇论文要的不是「谁分最高」，是「同样往外漂一点，谁把保持弄坏了」。

从温和教师做 OPD 的 MMD 最大（0.01470），遗忘却只有 0.0060。若把「rollout 分布走得远 = 忘得多」写成定律，这一行已经是反例。词汇 MMD 测的是前缀表层漂了多少，测不到更新打在学生能不能修的那些 $s$ 上。论文自己把漂移估计器写成词汇特征加 RBF 核，不是隐状态嵌入。这是机制假说的证据，不是基准数字。

nrehiew 把 Forward KL 展开成交叉熵减熵：

$$
D_{\mathrm{KL}}(p \| q_\theta)=-H(p)+H(p,q_\theta).

$$

在固定数据集上做 NLL，起始分布 $q_\theta$ 不进损失的「该往哪边靠」——只进「示范 token 概率够不够」。所以目标可以离起始策略任意远。Shenfeld et al. 的最近最优策略是另一头：REINFORCE + 0/1 奖励时，奖励像过滤器，最优策略有很多个，on-policy 采样迫使更新停在离当前 $\pi$ 最近、且 completion 全过关的那个。显式 KL 惩罚可以再加一道箍，但箍不是抗遗忘的必要条件。

## 8. 网上怎么讲，哪些别搬进公式

[渴口可乐](https://zhuanlan.zhihu.com/p/2044017882586206645) 把 2023–2026.05 收成一条时间线，结尾三句和博客、论文同向：差别不在 loss 名字，在监督落在哪个分布上；当前 RLVR 更像支持集内重加权；以后单看 pass@1 不够。雷达图那句「OPD 看起来最均衡，但多样性可能比 RL 还差」指向 2026-05 的 OPSD 多样性论文，不是 Nie 的 Table 2。专栏的 16 篇清单只作覆盖面，数字不从那里抄。

[明了个明](https://zhuanlan.zhihu.com/p/2070597972572771514) 写明受 nrehiew 启发，后面的信息几何和自做概念验证是作者自己的展开。m-投影 / e-投影可以把 Forward / Reverse KL 画成流形上的两种投影，方便记；那不是 Nie 论文里的定理。专栏里的玩具 MLP 表不要写进本篇主叙述。

Thinking Machines 的 [On-Policy Distillation](https://thinkingmachines.ai/blog/on-policy-distillation/) 是工业侧同构故事：off-policy 蒸馏在教师世界里学，复合误差随序列变长；on-policy 蒸馏在学生轨迹上打密信号。棋的类比和 nrehiew 的几何是同一幅画。Moonlight、EmergentMind、alphaXiv 讲座对 2605.22731 基本是摘要复述，没有多出来的表。

另有一篇几乎同时的 [arXiv:2605.16826](https://arxiv.org/abs/2605.16826)，把「前缀从谁来」和「KL 朝哪边」拆成笛卡尔积。Nie / nrehiew 只强调前缀来源；那篇补了 off-diagonal：教师前缀 + reverse KL、学生前缀 + forward KL。本篇不展开，只标明两根轴还可以再叉一次。

## 9. 失效和边界

加压超参值得单独钉：五个 epoch、学习率 $5\times 10^{-4}$、LoRA rank 64、alpha 128。这不是「SFT 默认就会忘」，是论文有意把 off-policy 压力拧过临界。温和 SFT 用 GSM8K SFT 数据产出非退化教师，目标涨、保持几乎不动。读这篇如果只记住「SFT 会忘」，就把阴性对照扔掉了。

Nie 自己写了：一个 0.6B 基座、一份 GSM8K、LoRA、有限保持任务、最小 GRPO 风格 RL，不是 verl 全规模。一步 OPD 崩到 GSM8K 0.040，说明「on-policy + 教师」仍可能学废，缺的是轨迹级局部监督。nrehiew 的熵坍缩解释、以及「乱码自蒸馏也能涨」那条 Zhang et al.，作者标了推测。博客引用的 GLM-5 / DeepSeek-V4「最终检查点不走 RL、用 OPD 并专家」，捆法以各报告为准，入口在 [10](../../10-OPD-各家报告对照/10-OPD-各家报告对照.md)，17,920 vs 1,800 不要安到 V4。

实验设定也限制外推：基座模型不用 chat 模板，prompt 是普通 GSM8K 风格；保持任务里 MMLU 只是选定子集，不是全科。把 0.448 读成「Qwen3-0.6B 的官方 GSM8K」会错，那是这篇管线自己测的基座点。LoRA 只训适配器，不等于全参加压 SFT 的遗忘曲线，也不能直接外推到 8B / 32B 全参后训练。单卡 3090 的轻量 RL 同样不能代表 verl 全规模 GRPO。

OPSD 里风格 token 的逐 token KL 高于数学 token，是 [02-OPSD](../../02-OPSD-参考解自蒸馏/02-OPSD-参考解自蒸馏.md) 的 Privileged Context 那一格，需要 $y^{\star}$。没有参考解时教师退化成学生，散度为 0。nrehiew 把 OPSD 写成更像 RLHF 而不是 RLVR，因为信号偏差高、要裁剪。这和 02 专文不冲突，专文钉的是三集平均 37.1→43.4 那个分母。

nrehiew 文末把开源管线写成 Pretrain → SFT → RL → OPD。SFT 仍被需要，因为没有格式和基本指令跟随，RL 采样效率会烂（Chu et al., 2025）。GLM-5 和 DeepSeek-V4 用 OPD 并专家、最终检查点不再走 RL，问的是专家自己该怎么训。他引用 MiMo-V2-Flash 技术报告 Table 7：数学和代码倾向 RL 教师，创意写作和偏知识的基准更吃蒸馏 / 自蒸馏。合并后的学生在 RL 域几乎总超过教师，在自蒸馏教师的域以及 SFT 域的 BrowseComp 上才会比教师差。这和「从加压 SFT 教师 OPD 仍能超过教师」同向，但分母是厂商报告，不是 Nie 的 0.6B 格子。并专家的损失分叉回 [09](../../09-MOPD-多教师蒸馏/09-MOPD-多教师蒸馏.md)。

假想中「比 RL 更省算力、还保住能力 vs KL 前沿」的算法，nrehiew 认为必须靠 on-policy 数据。另一只旋钮仍是信用分配：outcome reward 太稀，PRM 规模上不好训，logit 蒸馏密但有偏、要裁剪。形状比解清楚：密度、无偏、on-policy 三件同时要。这不是新口号，Thinking Machines 博文和 4.6 节地图第 1 节写的是同一缺口。
