# 后训练看状态不看 token

语言模型是序列上的一个分布。后训练是在改这个分布。损失叫交叉熵、策略梯度还是 KL，往往没有「监督打在哪段前缀上」来得关键。同一个数字，接在正确推理链后面和接在自相矛盾的链后面，是两次不同的更新。策略一变，模型下一步会走到的前缀集合也变。后训练改的不只是固定上下文上的词表概率，还有模型自己会去哪。

状态就是 prompt 加上已经生成的前缀。下面把 SFT、RL、OPD 放到同一套记号里，看训练状态从哪来、信号从哪来。Qwen3 Table 21 那种 GPU hours 对照在 [01](../01-OPD-学生前缀蒸馏/01-OPD-学生前缀蒸馏.md)；这里只把这根轴写清楚。

## 1. 状态是完整的条件上下文

自回归策略是

$$
\pi_{\theta}(y_{t}\mid x,y_{<t}). \tag{1}
$$

条件上下文写成状态

$$
s_{t}=(x,y_{<t}). \tag{2}
$$

下一个 token $y_t$ 是动作，一段生成答案是穿过状态的一条轨迹。令 $d^{\pi}(s)$ 表示策略 $\pi$ 在 prompt 分布上诱导的状态访问分布。状态不是隐层激活，不是一条训练样本，也不是孤立的 token 位置。它就是 next-token 策略所作用的完整条件上下文。

工程上，这段上下文就是已经写进 KV Cache 的那一截。换一个前缀，注意力看到的键值全换，同一套权重给出的下一词分布可以差得很远。所以「同一个 token」在损失里只是词表上的一个下标；在更新里，它乘的是不同前缀上的雅可比。把后训练理解成逐 token 打分，等于把这条雅可比丢掉了。

同一下标 `42`，接在「先通分」后面和接在「所以答案是」后面，反传到注意力的路径完全不同。前者主要拧算术步的残差方向，后者拧的是收束格式。损失只看见 log π(42|s)，看不见 s 里已经写了什么。这就是「看状态」要比「看 token」更硬的物理原因：token 是离散动作，状态才是雅可比的自变量。

KV Cache 把这件事写得很具体。前缀每多一个词，缓存里就多一组键值。损失对 θ 的梯度，要穿过这组键值再回到权重。off-policy 的黄金前缀，缓存里躺的是示范写过的键；on-policy 的学生前缀，缓存里躺的是学生自己写过的键。两套键值对应两套线性化。同一条交叉熵公式，作用在两套线性化上，可以推出完全不同的参数位移。后面加压 SFT 把保持打穿、同样密的 continuation-OPD 却能修回来，差的就是这套键从哪来。

给定 prompt 分布 $\rho(x)$，策略诱导

$$
\tau=(s_{1},y_{1},s_{2},y_{2},\ldots,s_{T},y_{T}), \tag{3}
$$

其中 $s_{t+1}=(x,y_{\leq t})$。诱导状态分布可以非正式写成

$$
d^{\pi}(s)=\mathbb{E}_{x\sim\rho,\,y_{<t}\sim\pi}\left[\frac{1}{T}\sum_{t=1}^{T}\mathbf{1}\{s_{t}=s\}\right]. \tag{4}
$$

实践里这个分布从未被精确观察到，只用 rollout 和采样前缀来近似。$\theta$ 一动，$d^{\pi}$ 就动。后训练的每一步同时做两件事：改当前 $s$ 上的 $\pi(\cdot\mid s)$，以及改明天还会不会再走到这个 $s$。第二件事经常被算法名盖住。SFT 把模型往数据集轨迹上推，推完之后学生自己采样，可能再也不经过那些黄金前缀。RL 只在自己采样到的前缀上动手，所以改完的地方，推理时还在。OPD 把这两件事拆开：前缀仍由学生决定，信号可以来自另一套冻结权重。

有一个容易滑过去的细节。$d^{\pi}$ 是访问频率，不是「模型会不会这个前缀」。低频前缀上也可以有很高的条件概率质量。遗忘测的是另一类 prompt 上的准确率，那些 prompt 诱导的前缀集合，和训练时挨打的前缀集合，交集可大可小。交集小，训练再猛，保持任务也可以看起来没事；交集大，即使目标任务分数还在涨，保持已经在掉。后面 MMD 几乎相等、保持差一截，就是这个交集问题，不是「漂了多远」的标量问题。

## 2. 一次更新拆成两件事

后训练的一步可以写成：从 $q_k$ 抽状态，从 $\mathcal{S}(s)$ 拿信号，再对 $\pi_{\theta}(\cdot\mid s)$ 做更新。

$$
\begin{align}
s &\sim q_{k}(s), \tag{5} \\
z &\sim \mathcal{S}(s), \tag{6} \\
\theta_{k+1} &= \theta_{k}-\eta\nabla_{\theta}\ell\big(\pi_{\theta}(\cdot|s),z\big). \tag{7}
\end{align}
$$

$q_k$ 是训练状态分布，$\mathcal{S}$ 是信号提供者，$z$ 可以是黄金 token、短续写、奖励、偏好或一整张教师分布。得到的新策略再诱导新的 $d^{\pi}$。SFT 里 $q_k=d_{\mathrm{data}}$，不依赖当前学习器。RL 里 $q_k=d^{\pi_{\theta_k}}$。OPD 里即便信号来自冻结教师，$q_k$ 仍是学生自己的 $d^{\pi_S}$。

算法名常常把这两根轴压在一起。SFT 被说成交叉熵，RL 被说成奖励，蒸馏被说成 KL。同一教师、两种前缀，其实是两个问题。教师轨迹上的 KL 是离线模仿；学生轨迹上查询同一教师，是 on-policy 校正。黄金前缀上的交叉熵，也不等于学习器自己前缀上的交叉熵，哪怕损失看起来都叫监督。

| 方法 | 训练状态从哪来 | 监督信号 |
|------|----------------|----------|
| SFT | 数据集轨迹 | 黄金 token |
| 离线蒸馏 | 教师轨迹 | 教师 logits / token |
| OPD | 学生轨迹 | 教师 logits / 续写 |
| RL | 当前策略轨迹 | 奖励 |
| DAgger | 学习者轨迹 | 专家动作 |

表 1：按状态来源排。OPD 和 DAgger 同一列，学习者控制去哪，专家只在那些点上给局部修复。

![SFT uses dataset prefixes and gold tokens; OPD uses student prefixes and teacher continuations; RL uses student prefixes and sparse reward](./images/fig-state-signal-two-axes.png)

> 图 1：三列从左到右是 SFT、OPD、RL。上格是状态从哪来，下格是信号从哪来。竖箭只在同一列里从上格底边进到下格顶边。红框标的是同一套交叉熵打在不同前缀上，学习问题已经变了。

左列的状态来自数据集 $d_{\mathrm{data}}$，下格是黄金 token，监督密，前缀却往往不是学生推理时会走到的那些。中列的状态来自学生 $d^{\pi_S}$，下格是教师的 logits 或短续写，信号仍密，前缀换成学生自己的。右列状态同样来自学生，下格换成稀疏奖励，前缀对了，密度没了。把 SFT 的交叉熵搬到学生前缀上（Iterative-SFT、DAgger、后面站住的 continuation-OPD），名字可以还叫监督，问题已经不是原来那个。

这两根轴还可以再叉一次。前缀从谁来是一行，KL 朝哪边是一列，笛卡尔积里有离线 reverse KL、学生前缀上的 forward KL。下面的实验主要动前缀这一行。散度方向会改变 mode-seeking 还是 mode-covering，改变不了「这个梯度打在哪段上下文上」。Qwen3 报告写 minimize KL，未点名正反向；V4 用全词表 reverse KL，K3 用 clip 对数比。那些分叉在 [09](../09-MOPD-多教师蒸馏/09-MOPD-多教师蒸馏.md) / [10](../10-OPD-各家报告对照/10-OPD-各家报告对照.md)。这里不把 OPD 定义成 reverse KL。MiniLLM 才是 reverse KL 再对采样路径做 policy gradient；GKD 已经 on-policy，梯度却不对采样路径反传。

## 3. 示范前缀上的误差，自己走会按 $T^{2}$ 复合

行为克隆在专家轨迹上训练，学习器走到示范里没有的状态就会吃复合误差。序列预测里的暴露偏差是同一件事：黄金前缀上训练，模型生成前缀上测试。DAgger 把这件事写成界：训练分布上每步误差 $\epsilon$，学习者自己走状态时，轨迹总偏差按 $O(\epsilon T^{2})$ 复合，而不是独立误差的 $O(\epsilon T)$。

![Gold prefixes keep per-step error linear in T; own prefixes compound to quadratic](./images/fig-compounding-prefix-error.png)

> 图 2：上行训练始终接回黄金前缀，每步误差 $\epsilon$ 加起来是 $O(\epsilon T)$。下行测试吃自己的输出，前缀漂出示范，总偏差变成 $O(\epsilon T^{2})$。底栏：这些误差不是独立的。

资格条件不是免费定理。推导默认专家在学习者走到的 $s$ 上仍然给得出靠谱动作。学生前缀严重 OOD 时，教师的 $\pi_T(\cdot\mid s)$ 自己会坏。后面「学生超过退化教师」靠的是另一头：教师的局部条件在学生可达的 $s$ 上仍有用，全局轨迹已经坏了。两边都成立，OPD 才是校正；只抄教师自己的轨迹，抄到的就是一份更差的路。

用一条短链把数量级摊开。设 $T=8$，每步条件错误率 $\epsilon=0.1$。若每步误差独立、并且下一步仍在示范前缀上，总偏差大约 $0.8$。若误差会改变下一步状态，后续每步都在更差的条件上再错一次，平方项把总偏差推到大约 $6$ 的量级。GSM8K 一条完整解答经常几十上百 token，推理链越长，off-policy 前缀越贵。这就是为什么「每个 token 都有密监督」在 SFT 里看起来很赚，推理时却可能一步偏、整题废。

Scheduled sampling 把黄金前缀和自己前缀按比例混，看起来像在缓解暴露偏差。混进去的那些自己前缀上，标签往往仍是黄金续写，不是「当前这个 $s$ 上专家会怎么修」。它减轻的是训练时前缀的错配，没有把信号源改成对学习者状态的查询。DAgger / continuation-OPD 多出来的那一步，正是查询。没有查询，学生前缀上的黄金答案可能在语义上对不上：学生已经写错了条件，黄金下一步是给正确条件准备的。硬拟合等于在错误的 $s$ 上按一份正确条件的答案，梯度方向会拧。

SFT 会因为没有把概率分给某个特定答案而受罚。RL 的监督贴在任务成功上，不贴在某一串指定 token 上。测试时因为自回归，学生的一次错误可能把它带到示范里从未出现过的状态。前缀一旦和示范会走的路不一样，错配就会复合。on-policy 数据聚合减小的就是这种错配：训练时已经在自己会走的前缀上挨打，测试时那些前缀不再是意外。

温和 SFT 抬目标、几乎不伤保持，说明数据集状态和基座策略还相容时，off-policy 不一定破坏。压力拧过临界，遗忘才出来。On-policy 更新更可能打在模型实际能到达、也能修好的状态上；标量漂移低不低是另一件事。教师失败若主要是轨迹分布坏了、局部条件还在，学生可以超过教师。两个方法可以测得几乎一样的漂移，保持却差一截，因为收到监督的那些 $s$ 对学习器可不可修，并不写在 MMD 里。

## 4. 交叉熵把模型往数据集上拉

SFT 的数据在训练之前就存在。当前模型是一个分布，数据集是另一个。交叉熵把前者往后者上拉。

$$
\mathcal{L}_{\mathrm{SFT}}(\theta)=-\mathbb{E}_{s\sim d_{\mathrm{data}}}\log\pi_{\theta}(y^{\star}\mid s). \tag{8}
$$

监督稠密，状态 off-policy。负对数似然不太管你从哪个分布出发，只看示范 token 的概率够不够。Forward KL 展开成

$$
D_{\mathrm{KL}}(p \| q_\theta)=-H(p)+H(p,q_\theta).
$$

$H(p)$ 是数据集的熵，跟 $\theta$ 无关。损失里活着的只有交叉熵。所以目标可以离起始策略任意远。交叉熵也没有内建机制去区分任务关键 token 和数据集里偶然带上的词，梯度从高概率区域和低概率区域一齐施压。峰被压、谷被填，旧能力若碰巧占用了这些质量，就会一起被挪走。

这不等于 SFT 一用就会忘。Qwen3-0.6B-Base 加 LoRA、单卡 3090、普通 GSM8K 风格 prompt（不用 chat 模板）那组对照里，温和 SFT 把 GSM8K 从 0.448 提到 0.512，TruthfulQA 0.295、MMLU 0.444，平均保持比 1.0008。数据集状态若还挨着基座会走的路，每个 token 都是密信号，不必付昂贵采样就能抬一项能力。遗忘是条件的：off-policy 压力够强、或数据集前缀和基座前缀错配够大，才会出来。

加压把同一套 off-policy 更新拧过临界：五个 epoch，学习率 $5\times 10^{-4}$，LoRA rank 64、alpha 128。GSM8K 掉到 0.420，TruthfulQA 0.245，MMLU 0.364，保持比 0.8258。目标任务也掉了。遗忘在这里具体表现为：稠密 off-policy 更新把策略推到自己 rollout 到不了、也修不回来的区域。学习率 $5\times 10^{-4}$ 对 LoRA 已经很猛，再乘五个 epoch，等于在一份并不大的 GSM8K SFT 数据上反复按。rank 64 / alpha 128 把适配器容量开得不小，适配器足够改残差流方向。全参会不会忘得更狠，这组实验没说；适配器已经够把保持比打到 0.8258，说明不必改所有权重，只要改那些前缀上的方向。

目标任务一起掉，说明加压 SFT 连「专项」都没保住。一种读法是过拟合到示范写法，泛化到 GSM8K 测试前缀时已经偏了。另一种读法是策略被推到自己采样都到不了的区域，训练损失还在降，推理前缀已经不在训练支持里。两种读法都指向同一处：挨打的 $s$ 和测试时的 $s$ 不再是一批。

最小代码编辑那组实验把这件事摊得更开。模型拿到被破坏的有 bug 函数，只许修这个 bug，再检查其余部分有没有被改写。SFT 教师 Pass@1 0.775，规范化 Levenshtein 0.450，LiveCodeBench v6 掉到 0.286；RL 教师 Pass@1 0.792，Levenshtein 0.063，LCB 0.320。专项都能学会，通用代码生成只在 SFT 教师上明显掉。Levenshtein 0.450 几乎是在重写半个函数；0.063 才是「只改该改的那一行」。交叉熵分不清必须改的那一行和数据集里顺便带着的写法，压力铺得很宽。后面 OPD 学生两边都把 Levenshtein 收到 0.055–0.059。「少改」贴在学生自己会走到的编辑前缀上，SFT 教师那种爱重写的全局风格并没有被学走。

0.450 和 0.063 差了大约七倍。Pass@1 却几乎贴着（0.775 vs 0.792）。专项对了，编辑半径差一截。交叉熵在黄金补丁上拟合时，示范里那些「顺便改了的空行、重排、重命名」也有损失。模型为了把 NLL 压下去，学会了一种更宽的编辑策略。RL 的 0/1 奖励只看 bug 修没修、其余测试过没过，宽编辑拿不到额外分，半径自然收。OPD 学生拿到的是 SFT 教师，却把半径收到 0.059：查询发生在学生自己的残缺前缀上，教师给的局部补丁够用，教师爱重写的那些全局动作进不了学生的 $s$。风格没有被状态支持放进来。

把抗遗忘完全写成「SFT 是 Forward KL、RL 是 Reverse KL」，只覆盖了一半。RLVR 里把对参考模型的 KL 惩罚拿掉或拧得很松，抗遗忘往往还在。*Retaining by Doing* 那组实验也把承重件指回 on-policy 数据，而不是 KL 正则本身，也不是优势估计的形式。显式 KL 可以再加一道箍。箍不是必要条件。

SFT 里还有不少低概率、低熵 token：模型对自己很自信，却被迫拟合一个分叉的真值标签。这种位置上的梯度特别伤既有表征，因为它在打「你原来很确定的东西」。任务关键算符往往不是这些位置；「therefore」「we can see that」这类连接词才是。损失不知道差别。这能解释 SFT 为什么铺得宽，仍然解释不了后面那句：稠密监督打在学生前缀上，可以既密又不太忘。密的是信号，宽不宽取决于 $q_k$ 盖住多大一片状态空间。

## 5. RL 只改自己已经走到的区域

在线 RL 从当前策略采样，样本被奖励打分，再用策略梯度把期望奖励往上推。

$$
\max_{\theta}\mathbb{E}_{s\sim d^{\pi_{\theta}},y\sim\pi_{\theta}(\cdot|s)}[r(s,y)]. \tag{9}
$$

奖励可以稀疏，状态是 on-policy 的。这里不太存在一个事先画好的外部分布在把模型往外拖。梯度只通过当前策略已经访问的区域起作用。任务可以涨，却不必对无关能力施加同样宽的压力。奖励没意义时这套不成立：可验证奖励常常是质量的不错代理；奖励模型不完美时，方向会漂。

模型经常进入某种推理模式，奖励就打在那里。它从不访问数据集式前缀，RL 也不会把那个前缀按进策略。KL 惩罚、裁剪、参考模型可以再加约束，更基本的局部性来自状态来源本身。TruthfulQA、MMLU 那些前缀，如果轻量 GSM8K RL 根本走不到，梯度就不会去改它们。保持比 0.9902、遗忘 0.0020，和「没打到那些 $s$ 上」是同一件事的两种说法。

用带 0/1 奖励的 REINFORCE 最容易看清几何。奖励 1 贡献正信号，奖励 0 贡献为零，奖励像过滤器，接近拒绝采样。最优策略可以定义成「该策略下所有 completion 奖励都是 1」。这样的最优策略有很多个；样本来自当前策略时，被选中的是离当前 $\pi$ 最近、且 completion 全过关的那个。一步策略梯度是在把当前策略拟合到这个新的最优策略上，而它隐含地对当前策略有低 KL。学到的是最近的任务求解策略。

![Current policy samples, keeps reward-1 completions, fits the nearest solving policy rather than a far optimum](./images/fig-nearest-optimal-policy.png)

> 图 3：从当前 $\pi$ 采样，只留下 $r=1$ 的 completion，拟合到最近的 $\pi^{*}$。虚线指更远的最优集合，那条路不走。

On-policy 数据把训练约束到每一步都靠近起始策略的分布。SFT 的目标可以任意远。显式 KL 惩罚可以再加一道箍，箍不是抗遗忘的必要条件。图 3 里「最近」是采样过程逼出来的，不是损失里写了一项 $D_{\mathrm{KL}}(\pi\|\pi_{\mathrm{ref}})$。所以 RLVR 把 KL 系数拧到接近 0，局部性还可以在。SFT 没有这一步过滤，数据集在哪，梯度就跟到哪。

RL 的参数更新往往更稀疏、更满秩，SFT 诱发更稠密的更新；裁掉更新参数之后，RL 掉得更快。这两条对 SFT 对 RL 站得住。OPD 的监督同样是稠密 token 级，却常常继承 RL 的一部分抗遗忘。稀疏更新解释不了这件事。承重的仍是状态从学生自己来。稠密梯度可以只打在一小片状态支持上：每个 token 都有损失，这些 token 却都来自学生自己的前缀。参数空间里看起来密，状态空间里仍然局部。把「密」理解成「改得宽」，把两层空间混在一起了。

组内归一化奖励时，多样性高、方差大的组更新更小，模型不确定时幅度会自然收一收。这是数据依赖的正则，不是显式 KL。它解释 RL 为什么不敢在糊成一团的组上猛推，解释不了 OPD。OPD 没有组内优势，照样可以不太忘，因为 $q_k$ 仍是 $d^{\pi_S}$。

轻量 RL 把 GSM8K 从 0.448 提到 0.472，涨幅 +0.024，小于温和 SFT 的 +0.064。这不丢人。这组实验要比的是同样往外漂一点谁把保持弄坏，不是谁分最高。稀疏奖励样本效率低，是 RL 付的价钱；局部性是它收回来的东西。

## 6. OPD 让学生决定去哪

OPD 有教师信号，数据却来自学生。

$$
\mathcal{L}_{\mathrm{OPD}}(\theta)=\mathbb{E}_{s\sim d^{\pi_{S}}}\left[D(\pi_{T}(\cdot|s)\,\|\,\pi_{S}(\cdot|s))\right]. \tag{10}
$$

工程上常见的一种写法是 reverse KL：每一步 on-policy 采样，梯度把学生往教师分布上拉，用学生与教师的对数比代替优势。这是类比。KL 匹配并不等于奖励最大化。最小化 KL 的信号偏差高于可验证的 0/1 奖励。教师分布里可能带着风格、不确定性、备选续写和推理结构。匹配它可以改采样行为，不必复现教师的贪心输出。

真正在小规模对照里站住的变体，甚至不把 KL 当招牌。教师从学生状态生成短续写，学生用交叉熵去学。学生控制状态分布，教师只提供局部修复。教师不是被复制成完整轨迹生成器，它被查询为学生状态上的局部条件策略。

![Student samples prefix s; frozen teacher is queried only at s and returns a short continuation; student learns that continuation](./images/fig-opd-query-student-state.png)

> 图 4：学生 rollout 出前缀 $s$。冻结的教师只在这个 $s$ 上被查询，给出短续写。学生用交叉熵学续写。底栏虚线是教师自己的轨迹，不进损失。

左侧桃色是学生采样，$d^{\pi_S}$ 由学生决定。中间白色框是当前前缀 $s=(x,y_{<t})$。右上冻结教师只在这个 $s$ 上被问下一步，右下交叉熵在短续写上更新。底栏虚线标的是教师自己爱走的路，这条路不进损失。

问和抄不是同一件事。抄是把 $d^{\pi_T}$ 整条搬过来，学生在教师爱去的地方模仿。问是固定学生已经走到的 $s$，只取 $\pi_T(\cdot\mid s)$ 或从这里写出的一小段 $z$。退化教师可以在自己的轨迹上写得很差，在学生的 $s$ 上仍能给出还能用的下一步。这就是后面表 3 里「唯一监督来源是退化教师，三列却都超过教师」能成立的几何。

Qwen3 Table 21 那一格（8B、同一 off-policy distilled 检查点、只比 math+code）上，on-policy 蒸馏大约用了 RL 十分之一的 GPU hours。17,920 vs 1,800 只在那一格成立，不能安到下面 0.6B、单卡 3090 的数字上。算力优势来自密信号，不是来自「换成 reverse KL」这五个字。

## 7. 一步 KL 会把题做废

一步 next-token KL 在同一套 0.6B 管线里把 GSM8K 打到 0.040。换成教师从学生状态生成短续写、学生用交叉熵去学，目标任务才回来。

![One-step next-token KL collapses GSM8K to 0.040; short teacher continuation recovers the target](./images/fig-onestep-vs-continuation.png)

> 图 5：两列都从学生前缀 $s$ 出发。左列只匹配下一步词表，GSM8K 落到 0.040。右列学教师短续写 $z$，目标回来。差别是信号有多长，不是状态从哪来。

每个前缀只拿到教师在该点的局部分布，没有「从这里把题做完」的轨迹级示范。GSM8K 要走完一条算术链，还要在固定格式里给出最终数字。局部匹配容易把质量推到短、错、高置信的续写上：提前停、抄一个看起来像答案的数、把链截断在「所以答案是」之后立刻乱写。教师在学生 OOD 前缀上给出的一步分布，本身也可以偏向这些短路径。学生再去匹配这张分布，等于在强化「别把题做完」。0.040 不是随机猜测的噪声，是学废了的解。随机瞎猜 GSM8K 最终数字，命中率远低于这个数都正常；0.040 更像模型还在输出「看起来像答案」的短串，只是算术链已经被截断。格式还在，推理没了。这和加压 SFT 把目标掉到 0.420 不是一类病：加压 SFT 还能把题做完，只是做完的路已经偏；一步 KL 连「做完」这件事都学没了。

短续写把监督从「下一步的词表」拉成「接下来一小段该怎么走」。状态来源仍是学生，信号密度接近 SFT，又多了一截轨迹级示范。看起来像学生前缀上的 SFT，梯度路径却和 MiniLLM 的 reverse KL + policy gradient 不是一条。GKD 已经 on-policy，损失仍是前缀上的 KL；continuation-OPD 连损失都收成 NLL。三条路共享状态来源，不共享散度方向。

续写该有多长，公开材料没钉死一个 token 数。太短接近一步 KL，太长又开始像在抄教师轨迹，on-policy 的好处会被冲淡。[OM-FREEPLAY] 实务上更合理的是「够把当前这道小题走完一小段」，不必抄教师自己会生成的整条答案。图 4 底栏那条虚线，就是在防后一种滑法。

on-policy 加教师，仍可能学废。缺的是轨迹级局部监督。状态来源对了，信号形式仍能把任务打穿。两根轴缺一根都不行。

还可以把一步 KL 想成信用分配的极端。整条 GSM8K 轨迹的对错，被压进「当前这个 $s$ 上下一个词表长什么样」。信息量看起来很大，其实大部分是「别选那三万个明显不对的词」，对「这条算术链下一步该往哪走」贡献很小。短续写把信用分配从词表拉开到一小段路径：至少要写出「先通分再约分」这类局部计划，远不止抬高某个数字的 logit。RL 的 outcome reward 走到另一头，整题一个比特，信用分配更稀。三种信号排成密度谱：一步词表、短续写、题末标量。GSM8K 这种必须做完的任务，谱的两端都容易废，中间那段续写才卡得住。

![Three columns share student prefix s; left matches one-step vocab and collapses; middle learns a short continuation; right uses a scalar outcome reward](./images/fig-credit-assignment-spectrum.png)

> 图 6：三行都从学生前缀 $s$ 出发。上行匹配一步词表，GSM8K 落到 0.040。中行学短续写 $z$，目标回来。下行只拿题末 $r\in\{0,1\}$，每条轨迹大约一比特。差别是信号有多长。

一步 KL 的「密」是假密。词表长度 $|V|$ 上每个位置都有 KL，看起来像 $O(|V|)$ 比特。真正对解题有用的方向，藏在「接下来该写哪类算术动作」那几个 bit 里。其余质量都花在「不要输出标点乱码、不要提前 EOS、不要换一种看起来像样的短答案」上。学生前缀一旦偏了，教师一步分布本身也会偏向这些短路径。匹配这张分布，等于用密损失去强化截断。

短续写把监督从词表切到一条局部计划。$z$ 里至少要包含一个完整的局部目标：通分、移项、代入。交叉熵这时打在一段路径上，信用分配有了时间宽度。太短会退回一步 KL；太长会把教师自己的全局轨迹掺进来，图 4 底栏那条虚线就会被踏过去。[OM-FREEPLAY] 没有公开材料钉死 token 数，能站得住的只有区间：长过「下一个词」，短过「教师会写完的整题」。

题末 0/1 走到谱的另一头。整题对了才有一个正信号，中间那些通分步骤没有自己的标签。样本效率差，是因为信用分配要把那一个比特摊回整条轨迹。局部性好，是因为摊回去的那些 token 全部来自学生自己的 $s$。密和局部在这里拆开了：RL 不密，但局部；一步 KL 很密，却可以把任务做废；续写卡在中间。

## 8. 换教师，学生仍然长得很像

最小代码编辑还能测两件事。一类破坏上训练、另一类上评估，看学到的是「少改」还是「还原某几种破坏」；微调后再上 LiveCodeBench，看通用代码生成掉多少。SFT 教师和 RL 教师都学会了最小编辑，RL 泛化更好、LCB 掉得少。若教师分布是主因，从 RL 教师蒸出的学生应当明显更好。

| 模型 | Pass@1 | Norm. Levenshtein | Added CC | LCB v6 |
|------|--------|-------------------|----------|--------|
| SFT 教师 | 0.775 | 0.450 | 0.450 | 0.286 |
| RL 教师 | 0.792 | 0.063 | 0.206 | 0.320 |
| OPD ← SFT 教师 | 0.800 | 0.059 | 0.206 | 0.297 |
| OPD ← RL 教师 | 0.787 | 0.055 | 0.228 | 0.314 |

表 2：最小编辑（域外破坏）和 LiveCodeBench v6。

两个 OPD 学生彼此接近。从 SFT 教师蒸出来的学生 Pass@1 0.800，高于两个教师；LCB 0.297，也高于 SFT 教师自己的 0.286。RL 教师在自己的训练 run 里最终奖励更高，也没改变这个格局。若教师分布是主因，学生应当把教师的遗忘一起继承。它没有。数据从学生自己的前缀来，比教师是谁更承重。

Levenshtein 把这句话写死了。SFT 教师 0.450，两个 OPD 学生 0.059 和 0.055，贴着 RL 教师的 0.063。学生没有把「重写半个函数」学走，学走的是在自己的编辑前缀上「这一处该怎么修」。SFT 教师作为轨迹生成器是差的，作为局部修复器还够用。可以先用蛮力 SFT 把专项教师训过头，再在学生前缀上蒸馏，专项留下，其它能力不必按教师掉的幅度一起掉。

Pass@1 0.800 超过两个教师，不必神化成「蒸馏一定青出于蓝」。一种机制是监督打在学生自己的错误区域，学生的错不必是教师的错，修复的是自己会犯的那些。另一种机制是 KL 或续写匹配会改采样行为，教师分布里的风格和备选续写不必变成贪心输出也能用。后一条仍是推测。GKD 那篇工作在 GSM8K 上早就见过学生超过教师，不是新奇迹，是 on-policy 蒸馏反复出现的现象。

更反直觉的旁证是：每个 prompt 只用 1 条模型生成的 completion、不做正确性过滤，编码仍可能涨；高温自蒸馏把数据变成乱码，有时也能涨。一种解释是新能力周围的 mode collapse。训练中的熵，OPD 往往比 RL 坍得更狠，和 reverse KL 的 mode-seeking 相符。这仍然是推测。能站住的只有一句：训练是在改分布的形状，不是在逐 token 抄答案。乱码还能涨，说明「示范有多正确」有时没有「在哪些前缀上改形状」重要。这句话不能拿去当训练配方，只能拿去防一种直觉：看见低质量数据就判断学不会。

## 9. 局部条件还能用，全局轨迹已经坏了

同一现象在 GSM8K 格子里更干净。基座 GSM8K 0.448、TruthfulQA 0.300、MMLU 0.436。MMLU 是选定子集。0.448 是这条管线自己测的基座点，不是官方 GSM8K。遗忘 $F=\mathrm{Score}_{\mathrm{base}}-\mathrm{Score}_{\mathrm{post}}$，保持比 $\mathrm{Score}_{\mathrm{post}}/\mathrm{Score}_{\mathrm{base}}$，在 TruthfulQA 和 MMLU 上平均。状态漂移用固定 prompt 集上的 rollout 前缀，词汇特征加 RBF 核的 MMD。

| Run | GSM8K | TruthfulQA | MMLU | MMD | Forgetting | Retention |
|-----|-------|------------|------|-----|------------|-----------|
| Base | 0.448 | 0.300 | 0.436 | – | – | – |
| Mild SFT | 0.512 | 0.295 | 0.444 | 0.00956 | -0.0015 | 1.0008 |
| Stress SFT | 0.420 | 0.245 | 0.364 | 0.01093 | 0.0635 | 0.8258 |
| OPD from mild SFT | 0.512 | 0.290 | 0.434 | 0.01470 | 0.0060 | 0.9810 |
| OPD from stress SFT | 0.466 | 0.275 | 0.430 | 0.01092 | 0.0155 | 0.9515 |
| On-policy RL | 0.472 | 0.290 | 0.442 | 0.01098 | 0.0020 | 0.9902 |

表 3：GSM8K 是目标，TruthfulQA / MMLU 是保持。

加压 SFT 教师是 0.420 / 0.245 / 0.364。从它做 OPD 得到 0.466 / 0.275 / 0.430，三列都超过教师，而教师是唯一监督来源。教师表现可以拆成两块：局部条件 $\pi_T(\cdot\mid s)$，以及教师自己爱走的轨迹 $d^{\pi_T}$。加压 SFT 可以毁掉后者，前者在学生走到的许多 $s$ 上仍然有用。学生问的是「我现在这里，下一步该怎样」，不是「教师自己会去哪些状态」。

从温和教师做 OPD，GSM8K 仍是 0.512，保持 0.9810。轻量 RL 把 GSM8K 提到 0.472，TruthfulQA 0.290，MMLU 0.442，遗忘只有 0.0020。目标涨幅最大的是温和 SFT（+0.064），RL 是 +0.024，加压教师上的 OPD 相对基座 +0.018、相对教师 +0.046。要比的不是谁分最高，是同样往外漂一点，谁把保持弄坏了。

温和教师上的 OPD 没有再抬 GSM8K，保持却从 1.0008 降到 0.9810，MMD 反而最大（0.01470）。读法是：教师已经够用，再在学生前缀上蒸一轮，主要在改学生自己的轨迹形状，目标分数到顶了，漂移量还能涨。加压教师上的 OPD 才是「修复」：目标从 0.420 回到 0.466，保持从 0.8258 回到 0.9515。OPD 不是无条件优于 SFT，它是在教师或数据已经把轨迹搞坏时，把监督搬回学生自己的 $s$ 上。

## 10. MMD 几乎一样，忘的不是同一批能力

加压 SFT 的 MMD 是 0.01093，从加压教师做 OPD 是 0.01092，on-policy RL 是 0.01098。三个数贴在一起。保持比却是 0.8258、0.9515、0.9902。从温和教师做 OPD 的 MMD 反而最大（0.01470），遗忘只有 0.0060。把「rollout 分布走得远 = 忘得多」写成定律，这一行已经反了。

词汇 MMD 测的是前缀表层漂了多少。用词特征加 RBF 核，看到的是 n-gram 长得像不像，看不到梯度打在哪些 $s$ 上，也看不到那些 $s$ 学生能不能自己走回去修。保持任务的 prompt 诱导的是另一批前缀。加压 SFT 在 GSM8K 示范前缀上猛推，这些示范和 TruthfulQA / MMLU 的前缀可能共享大量表层词，适配器把残差流在这些共享方向上拧歪，保持就掉。RL 和 OPD 的更新钉在学生 GSM8K rollout 上，表层词可以漂得一样远（MMD 贴着 0.011），共享方向却没被按那么死。所以会出现「漂幅一样、忘的不是同一批能力」。

机制假说可以靠这种标量，基准榜不能靠它。换一套嵌入、换隐状态、换分类器双样本检验，数字都会变。不变的是那句：要看监督打在哪片状态支持上，以及这片支持和保持任务的前缀有没有交集。

在固定数据集上做 NLL，$q_\theta$ 不进「该往哪边靠」。目标可以离起始策略任意远。0/1 奖励的最近最优策略是另一头。抗遗忘更像绑在 on-policy 状态上，而不像绑在某一次把 KL 写成正向还是反向。

参数空间和状态空间不要混着用「密」这个字。SFT 的梯度对每个示范 token 都有，参数更新可以很稠密，覆盖的 $s$ 却是数据集那一小撮前缀。RL 的梯度对多数 token 是零（没奖励就没信号），参数更新可以很稀疏，覆盖的 $s$ 却是模型自己会走的那片。OPD 两边都占：token 级损失是密的，支持集是学生的。看见「密监督」就推论「一定忘」，等于用参数空间的 denseness 去猜状态空间的 support。表 3 里加压 SFT 和加压教师 OPD 的 MMD 贴着 0.011，保持差一截，就是 support 不同，不是 denseness 不同。

保持任务掉，通常不是「模型把 TruthfulQA 的答案忘了」这么简单。更常见的是：那些题的前缀，和训练时被拧过的方向共享残差流。适配器在 GSM8K 示范前缀上学会一种说话方式，这种方式在事实问答前缀上把概率质量从正确答案挪走。RL 没在那些共享方向上挨那么多密标签，挪得就少。这是一种可检验的说法：若保持任务改成和 GSM8K 前缀几乎不共享的领域，加压 SFT 的遗忘应当变小。这组实验没有做这一格，所以只是推论，不是表 3 里的数。

还有一桩可证伪的事。若「状态支持」真是承重件，换一套和 GSM8K 示范几乎不共享表层词的保持任务，加压 SFT 的遗忘应当变小；换一套前缀高度重叠的保持任务，遗忘应当变大。MMD 可以继续贴着 0.011，保持曲线应当跟着交集走，不跟着漂幅走。这组对照没有这一格。没有这一格，就不能把 MMD 判死刑，只能说：在现有两列保持任务上，标量漂移解释不了遗忘差。

LoRA 把这件事写得更窄。rank 64 的适配器只能改残差流里低秩的那几条方向。加压 SFT 已经够把保持比打到 0.8258，说明遗忘不需要动满秩权重。那几条低秩方向，大概率就是示范前缀和保持前缀共享的说话方式。全参会不会忘得更开，这组实验没测。能说的只有：低秩已经够用，遗忘不必神话成「整网被洗掉」。

## 11. 自蒸馏密，偏差也密

On-Policy Self Distillation 里，教师和学生是同一套权重，算教师对数概率时教师会拿到参考解当前缀。特权信息提供学习信号。两边大多数 token 上输出非常接近。逐 token KL 里，wait、alright 这类风格词的 KL 可以高于 power、exponent、logarithm。这些位置更新太猛，模型可能坍缩，所以要逐 token 裁剪。

信号偏差高时，需要 KL 惩罚和置信域式裁剪，情形更接近 RLHF。可验证奖励偏差更低，RLVR 才更敢把显式 KL 拿掉，或用 GRPO 替换 PPO。outcome reward 每个 episode 大约只有 $O(1)$ 比特；OPSD 走到另一极端，每个 token 都有自己的「奖励」，噪声和偏差也更大。没有参考解 $y^{\star}$ 时，教师退化成学生，散度为 0。三集平均 37.1→43.4 那个分母在 [02](../02-OPSD-参考解自蒸馏/02-OPSD-参考解自蒸馏.md)。

风格 token 的 KL 高，并不等于它们更「重要」。KL 高常常只是两边在这些枢纽词上最容易分叉。若按 KL 大小加权更新，模型会先学会把 wait 说得像教师，数学步骤反而不动。裁剪是在承认：密信号的重要性排序，不能直接用散度当代理。这和 SFT 分不清关键算符与连接词，是同一类失败，只是代理从「示范里出现过」换成了「KL 大」。

## 12. 什么时候用哪一种

把前面的格子收成可执行的判断，不必再发明一个算法名。

数据集前缀和基座会走的前缀还挨着、目标只是换格式或补一项不太偏的能力，温和 SFT 往往够用。表 3 第一行对照就是这个：GSM8K +0.064，保持几乎不动。这时候上 RL 或 OPD，付采样成本，涨幅不一定更大。

专项已经训过头，教师或 SFT 检查点在自己的轨迹上坏了，但局部条件还在，适合把监督搬到学生前缀上。表 2 的 SFT 教师、表 3 的加压教师，都是这种。OPD 在这里做的是修复，不是无条件刷分。教师局部条件也坏了，学生前缀严重 OOD，问也问不出好 $z$，continuation 会变成抄一份同样坏的局部动作，DAgger 的资格条件不成立。

用表 3 走一遍选择。基座 0.448。若只想把 GSM8K 抬起来、保持几乎不动，温和 SFT 已经给出 0.512 / 1.0008，停在这里是理性的。若已经不小心做成加压 SFT（0.420 / 0.8258），不要继续加 epoch，把同一检查点当教师，在学生前缀上做 continuation-OPD，目标回到 0.466，保持回到 0.9515。若从基座直接上轻量 RL，目标 0.472、保持 0.9902，涨得少、忘得最少。没有可验证奖励、又已经有一份过拟合教师，OPD 比再 SFT 一轮更对症。有奖励、也有算力，RL 更稳。没有教师也没有奖励，只剩自己生成的 completion，那是另一篇文章的问题，不能把表 3 的 OPD 行搬过去用。

有可验证奖励、而且付得起采样，RL 把更新钉在自己走到的区域上，保持通常最稳。价钱是样本效率。密信号想省算力，就要接受偏差，再决定裁不裁、续写有多长、KL 朝哪边。

多数开源模型走 Pretrain → SFT → RL → OPD。预训练之后仍需要 SFT，既为了格式，也为了基本指令跟随；没有这些，RL 采样效率会烂。GLM-5 和 DeepSeek-V4 用 OPD 把专家并进最终模型，最终检查点可以不再走 RL。专家自己怎么训，仍然分域。MiMo-V2-Flash 的 Table 7 里，数学和代码倾向 RL 教师，创意写作和偏知识的基准更吃蒸馏。合并后的学生在 RL 域几乎总超过教师；真正比教师差的，出现在教师也是自蒸馏的域，以及 SFT 域的 BrowseComp。并专家的损失分叉在 [09](../09-MOPD-多教师蒸馏/09-MOPD-多教师蒸馏.md)。厂商报告和 0.6B 的 GSM8K 格子不是同一组实验。

Outcome reward 太稀，所以 RL 贵。过程奖励模型在规模上不好训。从教师做 logit 蒸馏，每个 token 更密，代价是偏差，然后又被迫上裁剪。密、无偏、还要 on-policy，三件叠在同一套更新上，目前没有一份大家都认的做法。能同时逼近三件的，大概率仍要 on-policy 状态；差别只在 $z$ 是奖励、续写还是 logits。

## 13. 这些数字能外推到哪

加压超参是故意拧过临界的：五 epoch、$5\times 10^{-4}$、LoRA rank 64、alpha 128。温和 SFT 那一行在，说明 SFT 并不是一用就忘。

整组对照是一个 0.6B 基座、一份 GSM8K、LoRA、有限保持任务、最小 GRPO 风格 RL。漂移度量用词汇特征。LoRA 只训适配器，不等于全参加压 SFT 的遗忘曲线，也不能直接外推到 8B / 32B 全参。单卡 3090 的轻量 RL 也不能代表全规模 GRPO。基座不用 chat 模板。MMLU 只是选定子集。数字只在这条管线里比。

表 2 的代码编辑和表 3 的 GSM8K 也不是同一台机器、同一套超参。能对齐的是结构：off-policy 密监督容易铺宽，on-policy 状态把更新钉住，教师作为局部修复器和作为轨迹生成器要分开看。不能对齐的是绝对分数。0.448 不是官方 GSM8K，0.800 也不是 LiveCodeBench 榜上的数。

外推时先问三件事。基座会不会自己走进示范前缀附近：会，温和 SFT 往往够用；不会，加压会把保持打穿，OPD 才有修复的位置。教师在学生可达的 $s$ 上局部条件还在不在：在，问得出好 $z$；不在，continuation 只是把坏的局部动作搬到学生前缀上。有没有可验证奖励：有，RL 的局部性最干净；没有，密信号只能从教师或数据来，这时状态从哪来比损失叫什么更关键。

chat 模板会改 $s$。这组 GSM8K 基座不用 chat 模板，0.448 是这条管线自己的点。换模板等于换状态分布，表 3 的差不能直接搬到带模板的 chat 检查点上。全参、多卡、长链推理，复合误差的 $T$ 更大，off-policy 前缀更贵，结构判断多半还在，绝对分数一定不在。

一句收束。后训练改的是 $\pi(\cdot\mid s)$ 和 $d^{\pi}(s)$ 两件事。算法名经常只写出第一件。第二件才决定更新会不会打在推理时还在的那些前缀上。SFT、OPD、RL 的差别，先看 $q_k$ 从哪来，再看 $z$ 有多长。token 是动作，状态才是条件。

训练前可以先问三句。前缀是不是学生自己会走的。信号有没有时间宽度，够不够把当前这一步的局部计划写完。保持任务的前缀和训练前缀有没有共享方向。三句都答得上，才谈得上选 SFT、OPD 还是 RL。答不上，算法名只是标签。

加压 SFT 的保持比 0.8258 和一步 KL 的 0.040 不要放在同一条遗忘曲线上读。前者还能交卷，后者已经不会做题。状态来源和信号长度是两根独立的轴，一张表里的「掉分」可能来自完全不同的机制。

SFT 的数据配方在 [4.2](../../4.2-SFT/4.2-SFT.md)。OPD 的名字、两条梯度和 Table 21 分母在 [01](../01-OPD-学生前缀蒸馏/01-OPD-学生前缀蒸馏.md)。$f$-散度那根尺子在 [4.6.2](../4.6.2-OPD综述/4.6.2-OPD综述.md)。这里只回答一件事：监督打在哪些状态上。
