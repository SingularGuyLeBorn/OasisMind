# 4.2.3 DFT 与 SFT 的 RL 视角

> 相关阅读: [4.2 SFT](../4.2-SFT.md) · [4.2.1 SFT 原理与实践](../4.2.1-SFT原理与实践/4.2.1-SFT原理与实践.md) · [4.4.0 强化学习的数学原理](../../4.4-强化学习基础/01-强化学习的数学原理/01-强化学习的数学原理.md) · [PPO](../../4.4-强化学习基础/04-PPO/04-PPO.md) · [GRPO](../../4.5-GRPO家族与RLVR/01-GRPO/01-GRPO.md) · [4.4.8 SFT 与 RL 的融合策略](../../4.8-推理与Agent能力/4.8.3-SFT与RL的融合策略/4.8.3-SFT与RL的融合策略.md)

SFT 的梯度可以改写成一个策略梯度. 材料是 DFT, ASFT, PSFT 三篇 2025 年的论文, 它们从这个改写出发, 各自修改了 SFT 的 token 权重或约束.

SFT 用交叉熵拟合专家答案, RL 用奖励信号更新模型自己采样的答案. 经验上前者容易记住训练集, 后者泛化更好但贵. 三篇论文都从「SFT 的梯度和 RL 的梯度差在哪一项」出发: DFT 把多出来的那一项抵消掉, ASFT 用下界框架解释 DFT 为什么会漂并给它加一个锚点, PSFT 换一条路, 借 PPO 的裁剪给每个 token 的概率涨幅设上限.

记号: 数据集 $\mathcal D$ 由提示 $x$ 和专家答案 $y^*=(y_1^*,\dots,y_T^*)$ 组成. $\pi_\theta$ 是待训练策略, $\pi_\theta(y\mid x)=\prod_t\pi_\theta(y_t\mid y_{<t},x)$. $\mathrm{sg}(\cdot)$ 是停梯度 (stop-gradient), 前向取值不变, 反向不传梯度. 第 $t$ 步的状态记 $s_t=(x,y^*_{<t})$.

## 1. SFT 梯度改写成策略梯度

### 1.1 两个目标

SFT 的损失与梯度 (DFT 论文式 (1)(2)):

$$
\mathcal L_{\mathrm{SFT}}(\theta)=\mathbb E_{(x,y^*)\sim\mathcal D}\bigl[-\log\pi_\theta(y^*\mid x)\bigr],\qquad
\nabla_\theta\mathcal L_{\mathrm{SFT}}=\mathbb E_{(x,y^*)\sim\mathcal D}\bigl[-\nabla_\theta\log\pi_\theta(y^*\mid x)\bigr] \tag{1}
$$

序列级 RL 的目标与策略梯度 (原文式 (3)(4)), $r(x,y)$ 是奖励:

$$
J(\theta)=\mathbb E_{x\sim\mathcal D_x}\,\mathbb E_{y\sim\pi_\theta(\cdot\mid x)}\bigl[r(x,y)\bigr],\qquad
\nabla_\theta J=\mathbb E_{x}\,\mathbb E_{y\sim\pi_\theta}\bigl[\nabla_\theta\log\pi_\theta(y\mid x)\,r(x,y)\bigr] \tag{2}
$$

式 (1) 的期望在固定数据上取, 式 (2) 的期望在模型自己的采样上取. 二者差在采样分布.

### 1.2 重要性采样改写

固定 $x$, 把对 $y^*$ 的取值写成对 $y\sim\pi_\theta$ 的期望. 对任意函数 $f$, $f(y^*)=\sum_y\mathbf 1[y=y^*]f(y)=\mathbb E_{y\sim\pi_\theta}\bigl[\tfrac{\mathbf 1[y=y^*]}{\pi_\theta(y\mid x)}f(y)\bigr]$. 取 $f=-\nabla_\theta\log\pi_\theta$, 得到 (原文式 (5)):

$$
\nabla_\theta\mathcal L_{\mathrm{SFT}}=-\mathbb E_{x}\,\mathbb E_{y\sim\pi_\theta}\Bigl[\underbrace{\frac{1}{\pi_\theta(y\mid x)}}_{w(y\mid x)}\;\underbrace{\mathbf 1[y=y^*]}_{r(x,y)}\;\nabla_\theta\log\pi_\theta(y\mid x)\Bigr] \tag{3}
$$

对照式 (2), 最小化 SFT 损失就是在最大化一个奖励为 $r=\mathbf 1[y=y^*]$ 的 RL 目标, 但每个样本多乘了 $w=1/\pi_\theta(y^*\mid x)$ (原文式 (6)). 这个奖励只在模型恰好生成专家答案时为 1, 是极稀疏的. 权重 $w$ 在模型给专家答案低概率时变得很大. 一条长度上千 token 的推理链, 序列概率可以小到 $10^{-100}$ 量级以下, 对应的 $w$ 没有上界, 估计量的方差也就没有上界.

DFT 论文据此认为, SFT 泛化差的一个来源是这个隐式权重: 梯度被模型最不认同的样本主导, 优化落到一个过拟合专家措辞的方向上.

### 1.3 权重抵消

既然多出来的是 $1/\pi_\theta$, 乘回 $\pi_\theta$ 就能抵消. 为了不改变梯度方向, 乘的是停梯度值 (原文式 (7)(8)):

$$
\mathcal L_{\mathrm{DFT}}^{\mathrm{seq}}(\theta)=\mathbb E_{(x,y^*)\sim\mathcal D}\bigl[-\mathrm{sg}\bigl(\pi_\theta(y^*\mid x)\bigr)\log\pi_\theta(y^*\mid x)\bigr] \tag{4}
$$

式 (4) 的梯度是 $-\mathbb E[\mathrm{sg}(\pi_\theta)\nabla\log\pi_\theta]$, 代回式 (3) 后 $w\cdot\pi_\theta=1$, 剩下一个奖励为 $\mathbf 1[y=y^*]$, 权重恒为 1 的策略梯度.

序列概率是 token 概率的连乘, 直接用会数值下溢. 原文最终采用 token 级版本 (原文式 (9)):

$$
\mathcal L_{\mathrm{DFT}}(\theta)=\mathbb E_{(x,y^*)\sim\mathcal D}\Bigl[-\sum_{t=1}^{T}\mathrm{sg}\bigl(\pi_\theta(y_t^*\mid s_t)\bigr)\log\pi_\theta(y_t^*\mid s_t)\Bigr] \tag{5}
$$

token 级不再是式 (4) 的精确无偏版本, 它和 PPO 类方法一样在 token 粒度近似序列级重要性权重.

### 1.4 token 级的读法

式 (3) 是序列级的. 换到 token 级看同一件事: 第 $t$ 步的状态 $s_t$ 取自专家前缀, 动作 $a_t=y_t^*$. 交叉熵对这一步的梯度是 $-\nabla\log\pi_\theta(y_t^*\mid s_t)$, 按同样的重要性采样改写, 等于在 $s_t$ 处对 $a\sim\pi_\theta(\cdot\mid s_t)$ 做奖励为 $\mathbf 1[a=y_t^*]$, 权重为 $1/\pi_\theta(y_t^*\mid s_t)$ 的单步策略梯度. 这里有两处与真正的 RL 不同:

1. 状态分布不同. RL 的 $s_t$ 来自模型自己的前缀, SFT 的 $s_t$ 来自专家前缀 (teacher forcing). 这一项 DFT 没有改, DFT 仍然是离线方法.
2. 权重不同. 单步权重 $1/\pi_\theta(y_t^*\mid s_t)$ 的上界是 $1/\min_t p_t$, 比序列级的 $1/\prod_t p_t$ 小很多个数量级, 但仍可在罕见 token 上达到上百. token 级 DFT 抵消的就是这个单步权重.

所以 token 级 DFT 的含义是: 在专家前缀上, 把每一步当成一个奖励为「是否命中专家 token」的单步 bandit, 用权重为 1 的策略梯度去优化. 它修正的是权重, 状态分布偏差留给在线方法 (见 [4.6 OPD](../../4.9-OPD/4.9-OPD.md) 与 4.4 节各 RL 方法). DFT 论文 Table 5 在 Qwen2.5-Math-1.5B 上比较了三种权重粒度, 五个基准平均: 序列级 15.75, 几何平均 (每 token 取序列概率的 $1/T$ 次方) 17.21, token 级 31.58. 序列级和几何平均与 SFT 的 18.01 相近或更低, 只有 token 级有效.

## 2. DFT 的梯度到底改了什么

### 2.1 与交叉熵和 focal loss 对比

记 $p=\pi_\theta(y_t^*\mid s_t)$. 对单个 token, 三种损失的梯度 (DFT 论文附录 A.3):

| 损失 | 形式 | 梯度 | 对低 $p$ token |
|---|---|---|---|
| 交叉熵 (SFT) | $-\log p$ | $-\frac{1}{p}\nabla p$ | 放大 $1/p$ 倍 |
| DFT | $-\mathrm{sg}(p)\log p$ | $-\nabla p$ | 不放大 |
| focal loss | $-(1-p)^\gamma\log p$ | 约 $-\frac{(1-p)^\gamma}{p}\nabla p$ (省略 $\gamma$ 项) | 进一步放大 |

focal loss 来自目标检测, 用来让模型关注难样本. DFT 的权重方向相反, 它降低模型当前认为不可能的 token 的影响. 两者在 $p\to1$ 时都趋于普通交叉熵的量级, 在 $p\to0$ 时行为相反.

### 2.2 手算一个例子

softmax 输出下, 目标 token 的 logit 记 $z$. $\partial(-\log p)/\partial z=-(1-p)$, 所以交叉熵对目标 logit 的梯度大小是 $1-p$; DFT 乘了 $p$, 大小是 $p(1-p)$.

取两个 token, 一个 $p=0.9$, 一个 $p=0.01$:

| | $p=0.9$ | $p=0.01$ | 低概率 / 高概率 |
|---|---|---|---|
| 交叉熵 $1-p$ | 0.1 | 0.99 | 9.9 |
| DFT $p(1-p)$ | 0.09 | 0.0099 | 0.11 |

交叉熵下, 低概率 token 的梯度是高概率 token 的 9.9 倍; DFT 下只有 0.11 倍. 一条专家答案里如果混着几个模型极不认同的 token (罕见措辞, 训练集特有的格式, 或者标注错误), 交叉熵会让它们主导这一步更新, DFT 几乎忽略它们.

$p(1-p)$ 在 $p=0.5$ 处最大. DFT 对模型「半信半疑」的 token 学得最用力, 对已经学会 ($p\to1$) 和完全不信 ($p\to0$) 的 token 都给小梯度.

### 2.3 训练后概率分布的变化

DFT 论文 Figure 2 统计了训练集 token 在训练后的概率分布. SFT 把概率整体往高处推, 分布变窄. DFT 让分布两极化: 一部分 token 概率被推得更高, 另一部分保持在很低的区间. 作者检查了最低概率区间的 token, 主要是连接词和标点这类功能词. 他们的解读是: 数学推理的关键 token 被强化, 不影响推理正确性的措辞 token 没有被强行拟合.

这条解读只在数学推理数据上做了检查. 在需要逐字记住事实的任务里, 「模型原本不信的 token」恰恰可能是要学的新知识, 第 3.4 节的掉点和第 4.3 节的漂移都出在这里.

### 2.4 实现

在 PyTorch 里, 对已有的 token 级交叉熵乘一个 detach 过的概率即可:

```python
import torch
import torch.nn.functional as F

def dft_loss(logits, labels, ignore_index=-100):
    # logits: [B, T, V], labels: [B, T], 已经右移对齐
    logp = F.log_softmax(logits.float(), dim=-1)
    mask = labels.ne(ignore_index)
    safe = labels.masked_fill(~mask, 0)
    tok_logp = logp.gather(-1, safe.unsqueeze(-1)).squeeze(-1)  # log p_t
    weight = tok_logp.detach().exp()                             # sg(p_t)
    loss = -(weight * tok_logp)[mask]
    return loss.sum() / mask.sum()
```

损失掩码沿用 SFT 的设置 (assistant-only 或 completion-only), 分母的归一化口径与 [4.2.1](../4.2.1-SFT原理与实践/4.2.1-SFT原理与实践.md) 1.3 到 1.5 节讨论的一样. 由于每个 token 的权重 $p\le1$, DFT 的损失数值比交叉熵小, 不能直接拿 loss 曲线和 SFT 比收敛快慢.

## 3. DFT 的实验设置与结果

### 3.1 设置 (DFT 论文 §4.1)

- 数据: NuminaMath CoT 中采样 10 万条.
- 框架与优化: verl, AdamW, 学习率 5e-5 (LLaMA-3.1-8B 用 2e-5), batch 256, 最大长度 2048, cosine 调度, warmup 比例 0.1.
- 评测: Math500, Minerva Math, OlympiadBench, AIME24, AMC23, 每题采样 16 次取平均 (avg@16), 温度 1.0, 最大生成长度 4096.

附录 A.7 的学习率扫描中, 1e-4 和 5e-5 两档最好. DFT 和 SFT 用同一组超参, 对比只改损失.

### 3.2 主结果, 换数据集与换 LoRA

| 模型 | 底座 | SFT | DFT |
|---|---|---|---|
| LLaMA-3.2-3B | 1.19 | 3.24 | 4.65 |
| LLaMA-3.1-8B | 1.00 | 6.33 | 11.02 |
| DeepSeekMath-7B | 2.64 | 9.82 | 18.15 |
| Qwen2.5-Math-1.5B | 15.92 | 18.01 | 31.58 |
| Qwen2.5-Math-7B | 21.25 | 23.62 | 37.15 |

两处细节. Qwen2.5-Math-1.5B 的 OlympiadBench 上, SFT 从底座 15.88 降到 12.63, DFT 到 27.08. Qwen2.5-Math-7B 的 AIME24 上, SFT 从 6.68 降到 2.48, DFT 是 8.56. 也就是说 SFT 在难题上可以低于底座, DFT 在同样数据上没有出现这种退化.

训练曲线 (Figure 1) 上, DFT 在 120 步以内达到峰值, 在 10 到 20 步时已经超过 SFT 整个训练过程中的最好成绩.

上表是 Table 1 的五基准平均. 换训练数据或换成参数高效微调, DFT 的领先都还在:

- OpenR1-Math (约 4.5 万条, 3 epoch, 附录 Table 8): Qwen2.5-Math-1.5B 底座 15.92, SFT 29.16, DFT 38.19. 换成更长更难的数据, SFT 涨幅变大, DFT 仍领先 9 分.
- LoRA (秩 8, $\alpha=16$, 附录 Table 9): 同一模型 15.92, 16.87, 32.90. LoRA 下 SFT 几乎不涨, DFT 涨幅与全参数相当. LoRA 本身见 [4.3.1](../../4.3-PEFT/4.3.1-LoRA低秩适应/4.3.1-LoRA低秩适应.md).

LoRA 这一组差距最大: 同样秩 8 的低秩更新, SFT 平均只涨 0.95 分, DFT 涨 16.98 分, 与全参数下的 15.66 分相当. 论文没有分析原因; 一个与第 2 节一致的解释是, 低秩更新容量有限, SFT 的梯度被少数低概率 token 主导时, 这点容量主要花在拟合这些 token 上.

### 3.3 与离线 RL 和 iw-SFT 的比较

这组实验把 DFT 放进有奖励信号的离线设置: Qwen2.5-Math-1.5B 对每个问题采样 4 个回答, 用答案验证器保留正确的, 约 14 万条. 基线配置: DPO 用 10 万对, 学习率 1e-6; PPO 和 GRPO 学习率 1e-6, batch 256, GRPO 组大小 4.

| 方法 | 五基准平均 |
|---|---|
| DPO | 23.20 |
| RFT (拒绝采样微调) | 23.97 |
| PPO | 28.66 |
| GRPO | 32.00 |
| DFT, 3.2 节的 SFT 数据 | 31.58 |
| DFT, 离线自采样正确样本 | 35.43 |

RFT 就是在自采样正确样本上做 SFT. 同一份数据, RFT 23.97, DFT 35.43, 差别只在损失. 在线 GRPO 32.00 低于离线 DFT, 这是 1.5B 模型, 组大小 4 的配置, 论文没有在更大模型或更大组上重复这个对比.

Qin 与 Springenberg (2025) 从另一条路得到 SFT 与 RL 的联系 (见 4.1 节), 提出 importance-weighted SFT (iw-SFT). DFT 论文附录 A.4 按 iw-SFT 原文设置 (epoch 改为 1) 在五个模型上对比. 平均分上 DFT 在四个模型领先: LLaMA-3.2-3B 高 2.39, LLaMA-3.1-8B 高 4.15, DeepSeekMath-7B 高 3.34, Qwen2.5-Math-1.5B 高 1.30. Qwen2.5-Math-7B 上 iw-SFT 39.60, DFT 37.15, iw-SFT 高 2.45. iw-SFT 在个别基准上低于普通 SFT, 例如 LLaMA-3.2-3B 的 Math500 (5.13 对 8.65). 实现上 iw-SFT 要一个单独的参考模型计算重要性权重, DFT 的权重直接取自当前模型的 token 概率.

### 3.4 代码, 多模态与知识型任务的反例

代码和多模态上 DFT 同样领先, SFT 在 HumanEval 上甚至低于底座:

- 代码 (Table 3): UltraFeedback 中 1 万条代码数据, Qwen2.5-Coder-7B. HumanEval 底座 62.2, SFT 54.9, DFT 67.7; MultiPL-E 平均 57.76, 57.62, 62.30. SFT 在 HumanEval 上低于底座.
- 多模态 (Table 4): MathVerse 总分 33.83, 35.66, 37.54.

知识型任务是反例. DFT 论文 §4.5 把方法用到 Natural Questions 这类事实问答上: 底座 31.24, SFT 36.62, DFT 30.14. DFT 低于底座. 作者把它列为局限: 当目标是灌入模型原本不知道的事实时, 「降低模型不信的 token 的权重」正好阻止了学习.

## 4. 下界框架与 ASFT 的锚点

### 4.1 SFT 是 RL 目标的一个下界

ASFT 论文 (Zhu 等人 2025) 采用 reward-weighted regression (RWR) 框架, 沿用 Qin 与 Springenberg 的推导. 设奖励是二值的 $R(\tau)\in\{0,1\}$, $\tau=(x,y)$, 正确集合 $D^+=\{\tau: R(\tau)=1\}$. 参考策略 $\pi_{\mathrm{ref}}$ 采样落在 $D^+$ 的概率记 $c_{\mathrm{ref}}=\mathbb P_{\pi_{\mathrm{ref}}}(\tau\in D^+)$. 原文 Proposition 1:

$$
J(\theta)\ \ge\ c_{\mathrm{ref}}\cdot\mathbb E_{\tau\in D^+}\bigl[\log\pi_\theta(\tau)\bigr] \tag{6}
$$

右边除了常数, 就是在正确样本上做最大似然, 也就是 SFT. 这个结论给第 1 节一个补充: 在只保留正确样本的数据上, SFT 最大化的是 RL 目标的一个下界. 推导里用到不等式 $u\ge1+\log u$, 当 $u=\pi_\theta/\pi_{\mathrm{ref}}=1$ 时取等. 训练让 $\pi_\theta$ 离 $\pi_{\mathrm{ref}}$ 越远, 下界越松.

### 4.2 换一个辅助分布

对任意支撑合适的辅助分布 $q(\tau)$, 下界可以推广为 (原文式 (2)):

$$
J(\theta)\ \ge\ c_{\mathrm{ref}}\cdot\mathbb E_{\tau\in D^+}\Bigl[\frac{q(\tau)}{\pi_{\mathrm{ref}}(\tau)}\log\pi_\theta(\tau)\Bigr] \tag{7}
$$

$q=\pi_{\mathrm{ref}}(\cdot\mid D^+)$ 时回到式 (6). ASFT 论文证明, DFT 等价于选 (原文式 (4)):

$$
q(\tau)=\frac{\pi_{\mathrm{ref}}(\tau\mid D^+)\,\mathrm{sg}\bigl[p_\theta(\tau)\bigr]}{\mathbb E_{\tau'\sim\pi_{\mathrm{ref}}(\cdot\mid D^+)}\bigl[\mathrm{sg}[p_\theta(\tau')]\bigr]} \tag{8}
$$

即按模型当前概率重新加权参考分布. 原文 Theorem 1: 只要 $p_\theta(\tau)$ 在 $D^+$ 上不是常数 ($\mathrm{Var}(p_\theta)>0$), 式 (8) 给出的下界严格紧于 SFT 的下界. 这解释了 DFT 在数学推理上为什么比 SFT 好: 它优化的代理目标离真实 RL 目标更近.

### 4.3 漂移

同一个框架也给出 DFT 的问题. 在式 (8) 下, 取等条件变成 $u=\pi_\theta(\tau)/q_\theta(\tau)=1$, 也就是 $p_\theta$ 在 $D^+$ 上为常数. 训练让 $q$ 越来越集中到模型已经给高概率的轨迹上, 模型只在越来越小的子集上学习, $p_\theta$ 越来越不均匀, 下界越来越松, 重要性权重的方差越来越大, 有效样本量下降. ASFT 论文 Figure 1 在医疗任务上画了相对底座的 KL: DFT 持续上升, SFT 和 ASFT 保持低位.

用有效样本量 (effective sample size) 可以手算这种集中. 归一化权重 $\bar w_i$ 下, $\mathrm{ESS}=1/\sum_i\bar w_i^2$. 设一个 batch 里只有 4 条正确样本, 按式 (8) 的权重正比于 $p_\theta(\tau_i)$:

| 阶段 | $p_\theta$ 归一化后 | $\sum\bar w_i^2$ | ESS |
|---|---|---|---|
| 训练早期 | 0.4, 0.3, 0.2, 0.1 | 0.30 | 3.33 |
| 训练后期 | 0.85, 0.10, 0.04, 0.01 | 0.7342 | 1.36 |

这组数字是为了演示构造的, 不来自论文. 早期 4 条样本相当于 3.3 条有效样本; 后期相当于 1.4 条, 几乎只剩模型最有把握的那一条在提供梯度. SFT 的权重恒为均匀分布, ESS 恒为 4, 不会出现这种退化, 代价是下界更松.

这和 3.4 节的现象一致. 数学推理数据里, 底座已经具备大部分能力, 集中到高概率轨迹上损失不大; 医疗知识和事实问答需要学底座没有的内容, 漂移就表现为掉点.

### 4.4 ASFT 的目标

ASFT (原文式 (6)):

$$
\mathcal L_{\mathrm{ASFT}}(\theta)=\mathcal L_{\mathrm{DFT}}(\theta)+\lambda\,\mathbb E_{s}\Bigl[D_{\mathrm{KL}}\bigl(\pi_{\mathrm{base}}(\cdot\mid s)\,\|\,\pi_\theta(\cdot\mid s)\bigr)\Bigr] \tag{9}
$$

$\pi_{\mathrm{base}}$ 是训练开始时的模型, KL 在每个 token 位置的整个词表分布上算. 方向是前向 KL ($\pi_{\mathrm{base}}$ 在前): 它惩罚 $\pi_\theta$ 在 $\pi_{\mathrm{base}}$ 有概率的地方给低概率, 也就是防止模型丢掉底座原有的输出模式. 原文消融中前向 KL 好于反向 KL. 主实验 $\lambda=0.05$, 扫描中 0.1 附近最好.

KL 项不改变下界结构, 只限制 $\pi_\theta$ 离开底座的距离, 从而限制式 (8) 中 $q$ 的集中程度. 原文还试了用 SFT 损失代替 KL 作锚点 (原文式 (7)): $\mathcal L_{\mathrm{DFT}}+\alpha\mathcal L_{\mathrm{SFT}}$, 少存一份底座 logits.

## 5. PSFT: 给 SFT 加信赖域

### 5.1 PSFT 的目标

PSFT (Zhu 等人 2025) 从 TRPO 和 PPO 出发. PPO 的裁剪目标是 $\mathbb E[\min(r_t\hat A_t,\mathrm{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t)]$, $r_t=\pi_\theta(a_t\mid s_t)/\pi_{\theta_{\mathrm{old}}}(a_t\mid s_t)$. 离线数据里每个专家动作都当作「好的」, 取 $\hat A_t=1$, 得到 (原文式 (6)):

$$
L^{\mathrm{PSFT}}(\theta)=\mathbb E_{(s_t,a_t)\sim\mathcal D}\Bigl[\min\bigl(r_t(\theta),\ \mathrm{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\bigr)\Bigr] \tag{10}
$$

$\hat A_t=1$ 时, $\min(r,\mathrm{clip}(r))$ 在 $r<1+\epsilon$ 时等于 $r$, 在 $r>1+\epsilon$ 时等于常数 $1+\epsilon$. 梯度 (原文式 (7)):

$$
\nabla_\theta L^{\mathrm{PSFT}}=\mathbb E\bigl[\mathbb I_{\mathrm{trust}}(r_t)\,r_t\,\nabla_\theta\log\pi_\theta(a_t\mid s_t)\bigr],\qquad
\mathbb I_{\mathrm{trust}}(r)=\begin{cases}0,& r>1+\epsilon\\ 1,&\text{其他}\end{cases} \tag{11}
$$

在 $r_t=1$ 处, 式 (11) 就是 SFT 的梯度. 区别只在一个 token 的概率相对旧策略涨过 $1+\epsilon$ 之后, 这个 token 不再贡献梯度. 下界方向不裁剪: 一个 token 的概率被其他更新拉低了, 它仍然有梯度把概率拉回来.

手算 $\epsilon=0.28$ 下的信赖域. 一个 token 在旧策略下概率 $p_{\mathrm{old}}$, 它能被 PSFT 推到的上限是 $1.28\,p_{\mathrm{old}}$:

| $p_{\mathrm{old}}$ | 上限 | 绝对涨幅上限 |
|---|---|---|
| 0.5 | 0.64 | 0.14 |
| 0.1 | 0.128 | 0.028 |
| 0.01 | 0.0128 | 0.0028 |

$p_{\mathrm{old}}>1/1.28\approx0.78$ 时上限超过 1, 裁剪不再起作用. 比例约束对低概率 token 很紧: 模型原本不信的专家 token, 每轮旧策略刷新之间只能涨一点点, 要多轮才能学到. 这和 DFT 的方向一致, 都在限制低概率 token 对模型的拉动, 机制不同: DFT 直接降权, PSFT 限制单轮涨幅, 只要训练轮数够, 低概率 token 最终仍能被学到. DAPO 论文 §3.1 用 $\epsilon=0.2$, 概率 0.01 与 0.9 两个 token 的类似算例说明对称裁剪会压制低概率 token 的探索, 所以把上界放宽到 0.28; PSFT 主实验也用了 0.28.

原文强调 PSFT 不是策略梯度 RL: 数据是离线的, 没有优势估计, 裁剪的作用是限制单个 token 概率的变化幅度并重新加权梯度.

### 5.2 两个实现选择

- **$\pi_{\theta_{\mathrm{old}}}$ 动态更新**: 旧策略随训练推进, 不固定为初始模型. 固定为初始模型会把整个训练限制在初始模型附近的信赖域里, 从数据中能学到的东西有限.
- **warm-up**: 训练初期 $\pi_{\theta_{\mathrm{old}}}$ 和数据分布差得远, 原文可选先用普通 SFT 预热若干步. 表中 PSFT$_{\text{warm-up}}$ 就是这个变体.

$\epsilon$ 取 0.2 或 0.28, 主实验用 0.28. 对照组 SFT-KL 的 KL 系数 0.5.

旧策略的更新频率 (原文 §5.3, Table 6, Qwen2.5-7B-Instruct):

| | AIME-24 | AIME-25 | TruthfulQA | IFEval (loose) |
|---|---|---|---|---|
| 底座 | 11.25 | 8.75 | 66.10 | 73.94 |
| PSFT, 旧策略不更新 | 13.02 | 11.15 | 66.61 | 76.46 |
| PSFT, 每 16 步更新 | 21.56 | 23.54 | 66.10 | 69.33 |
| PSFT, 每 8 步更新 | 19.38 | 21.98 | 67.16 | 73.03 |
| PSFT, 每 4 步更新 | 22.50 | 22.92 | 66.72 | 72.08 |
| SFT | 22.08 | 23.02 | 63.14 | 54.42 |

旧策略固定时, 数学成绩只比底座高两三分, 印证了上面第一条. 每 4 步更新时 AIME 与 SFT 持平, IFEval 只比底座低 1.86 分, SFT 低 19.52 分. 原文还观察到, 更小的 batch 配合相对更高的学习率能提高域内成绩, 代价是波动大, 泛化变差.

被裁剪的 token 是哪些 (原文 §5.1): 主要集中在 「wait」 「alternatively」 这类表达不确定的词上, 它们对应长推理里反复检查, 换思路的模式. 训练推进时这些 token 被裁剪得更明显. 裁剪阈值的消融 (原文 §5.2) 显示, 去掉裁剪后熵保持得更高, 但梯度范数大且不稳定, 下游成绩起伏很大; 加上裁剪后熵不塌缩, 梯度平稳, 成绩稳步上升, 中等的 $\epsilon$ (如 0.28) 折中最好.

### 5.3 PSFT 的结果与 DFT 的对照

设置: OpenR1-Math-8192 长 CoT 数据, Qwen2.5-7B-Instruct 和 Llama3.1-8B-Instruct, 训练约 10 epoch, 每 epoch 178 步.

Qwen2.5-7B-Instruct (Table 1):

| | 底座 | SFT | SFT-KL | PSFT$_{\text{warm-up}}$ | PSFT |
|---|---|---|---|---|---|
| 域内平均 | 37.98 | 47.99 | 47.08 | 48.17 | 46.98 |
| 域外平均 | 59.85 | 57.90 | 57.38 | 58.53 | 61.26 |
| IFEval | 73.94 | 54.42 | | | 73.03 |

Llama3.1-8B-Instruct 域外平均: 52.70, 50.49, 49.31, 53.48, 59.25.

域内 (数学) 上 PSFT 与 SFT 相差一分左右; 域外上 SFT 低于底座, PSFT 高于底座. 指令遵循最明显: 用数学长 CoT 做 SFT 让 IFEval 掉了约 19.5 分, PSFT 只掉 0.9 分.

训练动态 (Figure 1): SFT 和 SFT-KL 的熵每过一个 epoch 就明显下降一截, PSFT 的熵曲线平滑. 原文认为这让 PSFT 更适合做后续 RL 的起点. Table 2 用 DAPO-Math-17k 接 GRPO, Qwen 的 AIME24: SFT 起点 27.40, PSFT 起点 28.13.

和 DFT 放在一起看, DFT 按 token 的绝对概率 $p$ 加权, 与训练进度无关; PSFT 按相对旧策略的概率比裁剪, 只在单步更新过大时起作用. DFT 改变的是「学哪些 token」, PSFT 改变的是「每步最多学多少」. 两者可以叠加, 原文没有做这个实验.

## 6. 方法对照与使用边界

### 6.1 权重指数

把 token 级损失写成

$$
\mathcal L_\alpha=-\sum_t \mathrm{sg}(p_t)^{\alpha}\log p_t,\qquad p_t=\pi_\theta(y_t^*\mid s_t) \tag{12}
$$

对目标 logit 的梯度大小是 $p_t^{\alpha}(1-p_t)$. $\alpha=0$ 是交叉熵, $\alpha=1$ 是 DFT. 这个参数化是这里为了比较引入的, DFT 论文只做了 $\alpha\in\{0,1\}$ 和三种粒度的比较. $\alpha$ 越大, 低概率 token 的权重越小; 序列级 DFT 相当于把 $p_t$ 换成整条序列的概率, 权重极小且不同样本间相差几十个数量级, 这和 Table 5 序列级效果差一致.

focal loss 的权重是 $(1-p)^\gamma$, 位于这条轴的另一侧 (相当于给高概率 token 降权), 用在 SFT 上会进一步放大式 (3) 的方差问题.

### 6.2 汇总

| 方法 | 改动 | 需要额外模型 | 主要证据 | 已知弱点 |
|---|---|---|---|---|
| SFT | 无 | 否 | | 低概率 token 主导梯度, 域外与指令遵循退化 |
| DFT | token 权重 $\mathrm{sg}(p)$ | 否 | 数学推理五基准, 代码, MathVerse | 事实问答, 医疗知识掉点; 分布漂移 |
| iw-SFT | 相对参考策略的重要性权重 | 参考模型前向 | DFT 论文 Table 6, ASFT 论文 Table 2 | 多一个参考模型; 部分基准低于 SFT |
| ASFT | DFT + 前向 KL 到底座 | 底座前向 (LoRA 下共享) | 医疗, 数学, 代码 | 全参数下显存约翻倍 |
| PSFT | 概率比上界裁剪 | 旧策略概率 | 域外保持, 熵稳定, 接 RL 更好 | 域内略低于 SFT, 需 warm-up 补回 |

五种方法的差别可以落到两个问题上. 第一, token 权重看什么: SFT 不看, DFT 看当前模型的绝对概率, iw-SFT 看相对参考策略的比值, PSFT 看相对旧策略的比值且只在比值过大时介入. 第二, 用什么防止模型走远: SFT 和 DFT 没有约束, ASFT 用到底座的 KL, PSFT 用裁剪. 第二个问题的答案决定了要不要多存一份模型: ASFT 要底座的 logits, iw-SFT 要参考模型前向, PSFT 只要旧策略在采样时的概率, 可以在数据流里顺带记下.

表里的「主要证据」一列来自三篇论文各自的实验, 底座, 数据和评测都不同, 横向只能比方向, 不能比数值.

### 6.3 使用边界

三篇论文的证据都有明确的适用范围. 下面五条讲的是这些方法在什么任务, 什么数据, 什么评测下成立, 以及它们和在线方法的分界:

1. **任务类型**: DFT 的正面证据集中在数学推理和代码, 训练数据是底座已有能力范围内的 CoT. 目标是灌入新事实 (医疗知识, 开放域问答) 时, DFT 本身会掉点, 需要 ASFT 一类的锚点或直接用 SFT.
2. **数据噪声的双面性**: DFT 忽略模型不信的 token, 对错误标注更稳; 但同一机制也会忽略正确但罕见的 token. 数据里低概率 token 是噪声还是新知识, DFT 无法区分.
3. **评测设置**: DFT 论文的评测用温度 1.0 和 avg@16; ASFT 和 PSFT 用各自的基准组合. 三篇论文的数字不能跨表直接比较.
4. **后续 RL**: PSFT 和 ASFT 都报告了作为 RL 起点更好 (PSFT Table 2, ASFT Table 2), 涨幅分别是 0.73 和 3.86 分, 设置各不相同. SFT 与 RL 的组合方式见 [4.4.8](../../4.8-推理与Agent能力/4.8.3-SFT与RL的融合策略/4.8.3-SFT与RL的融合策略.md).
5. **与 RL 的边界**: 这些方法都只用专家或已筛选的正确样本, 没有负样本, 也没有模型自己前缀上的状态. 需要从错误中学习或需要纠正模型自己的推理路径时, 离线加权 SFT 无法替代在线 RL 或在线蒸馏.

### 6.4 实现与监控

实现层面的问题不改变方法的结论, 但会让复现出来的数字对不上. 权重粒度最容易出错: 序列级权重下溢, 几何平均也无效 (Table 5), 实现时要确认权重是 token 级, 且在 float32 下算 softmax. 其次是 loss 曲线: DFT 和 ASFT 的损失数值与交叉熵不在同一量级, 早停和学习率调度如果按 SFT 的 loss 阈值设定, 需要重新标定.

漂移需要专门监控. 4.3 节的分析给出三个可以直接记录的量. 一是在保留集上算 $D_{\mathrm{KL}}(\pi_{\mathrm{base}}\|\pi_\theta)$ 的逐 token 均值, 对应 ASFT Figure 1 的曲线; 二是每个 batch 内 DFT 权重的 ESS 与 batch 中 token 数之比, 持续下降说明梯度集中到少数 token; 三是训练集 token 概率的分桶直方图, 对应 DFT 论文 Figure 2. 三者都只需要前向, 不需要额外评测.

### 6.5 相关工作

**DeepSeekMath 的统一范式** (Shao 等人 2024, §5.2.1) 把 SFT, RFT, DPO, PPO, GRPO 的梯度写成「数据源, 奖励函数, 梯度系数」三项. SFT 的数据源是人工数据, 梯度系数恒为 1. 同节实验中, 在线 RFT 在训练后期明显好于离线 RFT. 第 1 节的改写可以看作这个范式下对 SFT 梯度系数的进一步拆解: 范式里 SFT 的系数恒为 1, 改写之后这个 1 拆成了奖励 $\mathbf 1[y=y^*]$ 和权重 $1/\pi_\theta$ 两部分, DFT 动的是后者.

**IFT** (Hua 等人 2024) 在 token 级 MDP 中把 SFT 和偏好优化拆成偏好估计与转移优化两个子过程, 认为 SFT 是偏好优化的一个特例. IFT 用「时间残差连接」让模型用自己对整段回答的预测参与估计, 数据需求与 SFT 相同.
