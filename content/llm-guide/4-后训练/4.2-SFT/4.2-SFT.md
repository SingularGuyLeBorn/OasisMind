# 4.2 监督微调 (SFT)

预训练模型会续写文本, 不会按对话轮次回答. SFT 用 (prompt, 回答) 对继续训练, 让模型学会聊天模板, 回答格式, 何时停止. 它是几乎所有后训练流水线的第一步: InstructGPT 先做 SFT 再做 RM 和 PPO, Llama 2 用 27,540 条人工示范做 SFT 后才进入拒绝采样和 PPO, Tülu 3 的 SFT 之后再接 DPO 和 RLVR, DeepSeek-R1 也在 RL 前放了一小段冷启动 SFT. 后面所有阶段都从 SFT 模型出发, 4.4 和 4.6 节里的参考模型 $\pi_{\mathrm{ref}}$ 一般就是它.

SFT 的公式是交叉熵, 难点在公式以外: 掩码盖住哪些 token, 损失按什么分母平均, 数据留哪些, 底座选哪个. 这些选择单独看都是细节, 叠在一起足以让两份「相同」配方训出的模型相差几分.

## 1. 目标函数里藏着的选择

### 1.1 掩码与模板

给定 prompt $x$ 和示范回答 $y^*=(y_1^*,\dots,y_T^*)$, SFT 的损失是

$$
\mathcal L_{\mathrm{SFT}}(\theta)=-\sum_{t=1}^{T} m_t\log\pi_\theta(y_t^*\mid x,y_{<t}^*), \tag{1}
$$

$m_t\in\{0,1\}$ 是掩码. 只对 assistant 回答计损失是默认做法, 也有对全部 token 计损失和只对选定轮次计损失的变体. 回答末尾的结束 token 必须在掩码之内, 漏掉它模型就学不会停止, 生成时会一直写下去. 这类错误在损失曲线上看不出来, 只能靠固定 prompt 的生成检查.

模板同样影响结果. Tülu 3 在同一份数据上比较了几种聊天模板, 最好和最差相差 1.4 分 (53.0 对 51.6), 差别只在角色标记和换行. 最好的变体把 assistant 消息末尾的换行换成 eos, 但 Tülu 3 没有采用, 因为后续 DPO 和 RLVR 的生成要和 SFT 模板一致. 模板一旦定下, 整条流水线都要沿用.

### 1.2 归一化分母

式 (1) 没有写分母. 按 batch 内全部 token 平均和先在样本内平均再在样本间平均, 是两个不同的目标. 4.2.1 的手算: 短样本 A 有 10 个 token, 长样本 B 有 990 个 token, 按样本平均时 A 的每个 token 权重是 B 的 99 倍, A 只占 1% 的 token, 却贡献了一半梯度. 梯度累积和多卡切分又会改变「样本」的边界, 结果是换了累积步数, 训出的模型也变了.

Tülu 3 在自己的框架和 TPU 实现之间发现了性能差距, 定位到的主要原因就是这个分母. 他们改用 sum loss, 去掉分母直接求和, 每个 token 等权且与卡数无关; 代价是梯度大小随 batch 内 token 数变化, 学习率要重扫, 最终 8B 用 5e-6, 训练超过 2 个 epoch 不再提升. 另一种修法是用全局 token 数 $N$ 统一做分母. packing 时还要隔离样本边界, 否则注意力会跨样本看到无关内容.

## 2. 数据, 底座与检查点

### 2.1 量, 质与筛选

公开配方的数据量相差三个数量级: LIMA 1000 条, 训 15 个 epoch, 靠残差 dropout 防过拟合; Llama 2-Chat 27,540 条; Tülu 3 939,344 条. LIMA 的消融里, 把数据量扩到 16 倍, 生成质量基本不变, 去掉质量过滤则降 0.5 分; 在 1000 条里加 30 条多轮对话, 多轮回答的优秀率从 45.2% 升到 76.1%. 这两组数字说明质量和覆盖比条数重要.

[4.2.2](./4.2.2-SFT数据质量筛选与训练技巧/4.2.2-SFT数据质量筛选与训练技巧.md) 讲具体怎么筛. AlpaGasus 让强模型给 52,002 条 Alpaca 打分, 留下 9,229 条, 训练快 5.7 倍且效果更好; Deita 按复杂度, 质量和多样性组合选出 6K 条, MT-Bench 6.46, 随机 6K 只有 5.84. 但「取最长的 1000 条」这个基线也很强, 打分方法要和它比才算有效. 规则过滤之外, 去污染是必须做的一步: Tülu 3 用 8-gram 匹配检查评测集, 发现 LMSys Chat 与 Do-Anything-Now 的重叠达 90.3%.

### 2.2 底座和种子

底座决定 SFT 的上限. Tülu 3 用同一份 SFT 数据训不同底座, Qwen 2.5 7B 的 MATH 为 49.4, Llama 3.1 8B 为 31.5, 差 17.9 分, 加过数学预训练的 Qwen 2.5 Math 7B 再高 7.0 分. Gekhman 等人的闭卷问答实验给出了另一面: 微调数据里底座原本不知道的事实学得慢, 学会之后幻觉倾向随之上升. SFT 适合教格式和行为, 不适合灌知识.

超参数在几份公开配方之间差别也大. InstructGPT 的 SFT 训 16 个 epoch, 1 个 epoch 后验证损失就开始过拟合, 但继续训练仍能提高 RM 打分和人类偏好; LIMA 学习率从 1e-5 线性降到 1e-6, 训 15 个 epoch; Llama 2-Chat 学习率 2e-5, 只训 2 个 epoch; Tülu 3 的 70B 学习率降到 2e-6, 在 64 张 H100 上训约 50 小时. 数据越少, epoch 越多, 防过拟合的手段 (残差 dropout, 按生成选检查点) 越重要.

检查点选择也有坑. InstructGPT 和 LIMA 都发现验证损失或困惑度与生成质量变化方向不同, 检查点要按生成结果选. Tülu 3 换随机种子, 8B 上分数差 0.3, 70B 上差 2.6, 所以 70B 规模下 2 分以内的配方差异需要多跑几次才能下结论.

## 3. 结果对哪些选择敏感

### 3.1 对照表

| 选择 | 常见取法 | 选错的表现 | 量级 | 细节所在 |
|---|---|---|---|---|
| 归一化分母 | sum loss 或全局 token 数 | 换卡数, 换累积步数后结果变 | 短样本 token 权重可差 99 倍 | [4.2.1](./4.2.1-SFT原理与实践/4.2.1-SFT原理与实践.md) |
| 聊天模板 | 与后续 DPO, RL 阶段一致 | 平均分波动 | 1.4 分 | 4.2.1 |
| 数据筛选 | 打分加多样性, 与最长 1000 条基线比 | 量大质差, 训练慢 | Deita 6K 对随机 6K: 6.46 对 5.84 | [4.2.2](./4.2.2-SFT数据质量筛选与训练技巧/4.2.2-SFT数据质量筛选与训练技巧.md) |
| 去污染 | 8-gram 匹配评测集 | 分数虚高 | 重叠可达 90.3% | 4.2.2 |
| token 权重 | 交叉熵或 DFT 一族 | 低概率 token 主导梯度, 域外退化 | Qwen2.5-Math-7B: 23.62 对 37.15 | [4.2.3](./4.2.3-DFT与SFT的RL视角/4.2.3-DFT与SFT的RL视角.md) |

表里前两行的错误在损失曲线上看不出来, 只能靠固定 prompt 的生成和换配置复跑去发现; 中间两行影响的是评测数字是否可信; 最后一行改的是训练目标本身. 4.2.1 和 4.2.2 用的是同一批技术报告, 一篇看训练侧, 一篇看数据侧. Tülu 3 在两篇里都是主要材料: 4.2.1 用它的 sum loss, 模板消融和种子实验, 4.2.2 用它的配比流程和去污染. 读完这两篇可以复现一份公开配方.

第三篇换了一个出发点. 前两篇默认交叉熵是对的, 只讨论怎样用好它; 4.2.3 质疑交叉熵本身给每个 token 的权重. 三篇的结论之间有一处张力: 4.2.2 说质量过滤后的数据更好, 4.2.3 的 DFT 却主动降低模型不信的 token 的权重, 数据里低概率的 token 是噪声还是新知识, 这个方法无法区分.

### 3.2 从策略梯度看 SFT

把 SFT 的梯度用重要性采样改写成策略梯度, 得到

$$
\nabla_\theta\mathcal L_{\mathrm{SFT}}=-\mathbb E_{y\sim\pi_\theta}\Bigl[\frac{\mathbf 1[y=y^*]}{\pi_\theta(y\mid x)}\nabla_\theta\log\pi_\theta(y\mid x)\Bigr], \tag{2}
$$

奖励是 $\mathbf 1[y=y^*]$, 权重是 $1/\pi_\theta$. 模型越不信示范, 这个权重越大, 梯度方差随之变大. DFT 在 token 级乘上 $\mathrm{sg}(\pi_\theta(y_t^*\mid s_t))$ 抵消这个 $1/\pi$, Qwen2.5-Math-7B 的数学平均从 SFT 的 23.62 升到 37.15. 这个权重必须放在 token 级: 序列级和几何平均版本分别只有 15.75 和 17.21, 不如 SFT 的 18.01.

DFT 在事实问答上是反例: Natural Questions 上底座 31.24, SFT 36.62, DFT 30.14, 降低模型不信的 token 的权重恰好阻止了新知识的学习. ASFT 在 DFT 上加一项到底座的前向 KL, 医疗任务从 25.97 升到 42.03; PSFT 借 PPO 的比率裁剪给 SFT 加信赖域, 域外能力保持得更好, 作为 RL 起点也更好. 这三种方法都只用正确样本, 没有负样本, 也不在模型自己的前缀上训练, 需要纠正模型自己的推理路径时仍要换成在线 RL 或 4.9 节的 on-policy 蒸馏.

## 4. 从哪一篇开始

### 4.1 按手头的任务

第一次自己跑 SFT 的读者, 先读 [4.2.1](./4.2.1-SFT原理与实践/4.2.1-SFT原理与实践.md) 的损失, 模板和失效清单, 它列出的八条失效里前五条是实现错误, 损失曲线上都看不出来. 已经有训练框架, 要整理数据的读者, 直接读 [4.2.2](./4.2.2-SFT数据质量筛选与训练技巧/4.2.2-SFT数据质量筛选与训练技巧.md) 的打分, 长度基线和去污染三节. 数据从哪来, 怎样标注, 在 [4.1 后训练数据](../4.1-后训练数据/4.1-后训练数据.md).

熟悉 RL 的读者可以从 [4.2.3](./4.2.3-DFT与SFT的RL视角/4.2.3-DFT与SFT的RL视角.md) 读起. 它用的记号和 [4.4 节 01 篇](../4.4-强化学习基础/01-强化学习的数学原理/01-强化学习的数学原理.md) 一致, 式 (2) 也是 DeepSeekMath 统一范式中「梯度系数」一项的拆解.

### 4.2 与相邻各节的接口

显存不够做全参数微调时, 接 [4.3 PEFT](../4.3-PEFT/4.3-PEFT.md); LoRA 在指令微调上与全参数接近, 在继续预训练式的大数据上差距明显. SFT 之后接偏好优化, 读 [4.6](../4.6-偏好优化/4.6-偏好优化.md); 接可验证奖励 RL, 读 [4.5](../4.5-GRPO家族与RLVR/4.5-GRPO家族与RLVR.md).

SFT 和 RL 的顺序与混合方式在 [4.8.3](../4.8-推理与Agent能力/4.8.3-SFT与RL的融合策略/4.8.3-SFT与RL的融合策略.md): SRFT 的对照里 SFT 后接 RL 平均 52.5, RL 后接 SFT 只有 37.4. SFT 为什么比 on-policy 方法忘得多, 见 [4.10 持续学习](../4.10-持续学习/4.10-持续学习.md) 第 5 节.
