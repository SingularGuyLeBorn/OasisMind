# 4.4 强化学习基础

SFT 只能模仿示范, 模型自己生成的回答好不好, 它得不到反馈. 强化学习把这个反馈接进训练: 策略 $\pi_\theta$ 对 prompt $x$ 采样回答 $y$, 奖励模型或判定函数给出 $r(x,y)$, 再沿提高期望奖励的方向更新. InstructGPT 用 PPO 做了这件事, 之后的 GRPO, DPO 和 OPD 都可以看作对这套做法某一环的替换. 这一节讲替换之前的原型和最早的几种简化, 4.5 节的 GRPO 一族与 4.6 节的偏好优化都以它为起点.

LLM 上的 RL 和 Atari, MuJoCo 上的 RL 不太一样. 状态是 prompt 加已生成的前缀, 动作是下一个 token, 转移是把 token 接到末尾, 完全确定; 奖励通常只在整段回答结束时给一次. 这两条性质决定了经典 RL 里很多为环境随机性和长视野设计的组件, 在这里收益有限.

## 1. 策略梯度的两个难点

### 1.1 方差

策略梯度定理给出

$$
\nabla_\theta J(\theta)=\mathbb E_{y\sim\pi_\theta}\bigl[(r(x,y)-b(x))\,\nabla_\theta\log\pi_\theta(y\mid x)\bigr], \tag{1}
$$

$b(x)$ 是只依赖 prompt 的基线. 只要 $b$ 不依赖 $y$, 减去它不改变梯度的期望, 只改变方差. 不减基线时, 奖励全为正的任务里每个样本都会被推高, 好样本和差样本只差在推得多少; 减去基线后, 低于基线的样本被压低, 梯度方向才有对比. [01 强化学习的数学原理](./01-强化学习的数学原理/01-强化学习的数学原理.md) 从 MDP 和 Bellman 方程推到式 (1), 并证明了基线的无偏性.

基线取什么, 是这一节后半部分的主线. PPO 训练一个价值网络 $V(s_t)$ 在每个 token 位置估计期望回报, 用 GAE 组合出 token 级优势; REINFORCE 用奖励的滑动平均; RLOO 用同一 prompt 下其余样本的平均; ReMax 用贪婪解码那条回答的奖励. 四种取法的方差, 显存和采样代价各不相同.

### 1.2 步长

策略梯度是一阶方法, 步子大了策略会塌, 步子小了学得慢. TRPO 从性能差恒等式出发, 证明带 KL 罚的替代目标是真实回报的下界, 再把罚项改成平均 KL 不超过 $\delta$ 的约束, 用共轭梯度加线搜索求解, 论文取 $\delta=0.01$. 按理论推荐的罚系数, $\gamma=0.99$ 时罚项系数约 39600, 步长会小到几乎不动, 这是改成约束形式的原因.

PPO 把信任域换成比率裁剪:

$$
L^{\mathrm{CLIP}}(\theta)=\mathbb E_t\Bigl[\min\bigl(r_t(\theta)\hat A_t,\ \mathrm{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat A_t\bigr)\Bigr], \tag{2}
$$

$r_t(\theta)$ 是新旧策略在 token $t$ 上的概率比, 常用 $\epsilon=0.2$. 裁剪只用一阶优化器就能实现, 不需要 Fisher 矩阵, 这是 PPO 取代 TRPO 的主要原因. 4.5 节的 GSPO, GMPO, CISPO, SAPO 改的正是式 (2) 里比率的粒度和越界后的处理.

## 2. 两条线上的六篇

### 2.1 信任域一线: TRPO 与 PPO

[03 TRPO](./03-TRPO/03-TRPO.md) 和 [04 PPO](./04-PPO/04-PPO.md) 是经典 RL 的结果. TRPO 一篇给出了自然策略梯度和 TRPO 的分界: 两者方向相同, TRPO 多了线搜索保证约束成立, 在 Hopper 和 Walker 上这决定了能不能学会走路. PPO 一篇讲 GAE, 裁剪和价值函数, 再落到 InstructGPT 的完整配置.

InstructGPT 的 RLHF 同时驻留四份模型: 策略, 价值网络, 奖励模型, 参考模型. 它的 PPO 用 31k 条 prompt, KL 系数 $\beta=0.02$, 256k 个 episode, batch 512, 每批只做 1 个内层 epoch, 价值网络用 6B 模型, 所有规模的策略共用. PPO-ptx 混入预训练梯度, 系数 27.8, 用来补回公开 NLP 基准上的退步. 结果是 1.3B 的 InstructGPT 在人类偏好上胜过 175B 的 GPT-3.

PPO 之前的两步同样决定结果. InstructGPT 的 SFT 用约 13k 条 prompt, 奖励模型用 33k 条 prompt, 每条让标注员对 4 到 9 个回答排序, 一次排序拆成全部两两比较放进同一个 batch, 避免同一组比较被拆散后过拟合. 奖励模型用 6B 而不用 175B, 原因是 175B 的奖励模型训练不稳定, 不适合当价值函数的初始化. 这套流程在 [4.0 后训练概述](../4.0-后训练概述/4.0-后训练概述.md) 有更细的整理, 标注协议见 [4.1](../4.1-后训练数据/4.1-后训练数据.md).

### 2.2 去掉价值网络: REINFORCE, RLOO, ReMax

[02 REINFORCE](./02-REINFORCE-序列级策略梯度/02-REINFORCE-序列级策略梯度.md) 的材料是 Ahmadian 等人 2024 年的论文. 他们的论点是: RLHF 的策略从 SFT 模型初始化, 起点已经很好, 动作空间虽大但概率集中, PPO 为高方差和不稳定设计的组件在这里大多用不上. 实测裁剪只在不到 5% 的 token 上触发; 把整段回答当一个动作, 用滑动平均基线的 REINFORCE, 胜率全面高于 PPO.

[05 RLOO](./05-RLOO-留一法基线/05-RLOO-留一法基线.md) 对同一 prompt 采 $k$ 条, 第 $i$ 条的基线取其余 $k-1$ 条奖励的平均, 不训价值网络, 不除标准差, 不裁剪. [06 ReMax](./06-ReMax-贪婪基线/06-ReMax-贪婪基线.md) 只多采一条贪婪解码的回答, 用它的奖励当基线, 显存约为 PPO 的 54%. 这三篇是 4.5 节 GRPO 的直接前身: GRPO 的组内均值基线乘以 $(G-1)/G$ 后就是 RLOO 的留一均值, 区别在 GRPO 还除了组内标准差, 这一项后来被 Dr.GRPO 指出会引入难度偏差.

## 3. 四种基线的代价

### 3.1 对照表

| 方法 | 基线 | 优势的粒度 | 驻留模型 | 每个 prompt 采样 | 主要证据 |
|---|---|---|---|---|---|
| PPO | 价值网络 $V(s_t)$ + GAE | token | 策略, 价值, RM, 参考 | 1 | InstructGPT 1.3B 胜过 175B GPT-3 |
| REINFORCE | 奖励滑动平均 | 序列 | 策略, RM, 参考 | 1 | 三组胜率都高于 PPO 与 Vanilla PG |
| RLOO | 其余 $k-1$ 条均值 | 序列 | 策略, RM, 参考 | $k$ | 胜率比 PPO 高 10.3 到 32.1 |
| ReMax | 贪婪解码的奖励 | 序列 | 策略, RM, 参考 | 2 (采样 + 贪婪) | 显存 172GB 对 PPO 319GB |

表的第四列是去掉价值网络的直接收益. 价值网络和策略同样大, 还要单独存优化器状态, 去掉它几乎省下一半训练显存. ReMax 论文附录按 Llama-2-7B 估算, PPO 需要 319.14GB, ReMax 为 172.12GB, 其中冻结的奖励模型只占约 4%, 价值网络连同梯度和优化器状态约占 46%. 训练时间上, PPO 必须开 offload 才能放下, 每个 epoch 2.9 小时, ReMax 不开 offload 只要 1.8 小时.

第五列是代价. RLOO 用 $k$ 倍采样换基线的质量, 采样越多, 留一均值越准; ReMax 只多一条贪婪解码, 但贪婪那条和采样那条相关性不确定, 基线质量依赖任务. 当奖励只在终点给出时, GAE 在 $\gamma=\lambda=1$ 下的优势退化成 $r-V(s_t)$, 价值网络在每个前缀上估计同一个终点奖励, 能带来的信息有限, 这是三种序列级方法能追上 PPO 的根本原因.

### 3.2 胜率与第三方对比

Ahmadian 等人在 TL;DR 摘要和 Anthropic-HH 上报告的胜率 (对参考回答):

| 方法 | TL;DR | HH (Pythia) | HH (Llama) |
|---|---|---|---|
| RLOO $k=4$ | 77.9 | 43.7 | 64.1 |
| REINFORCE | 70.7 | 37.9 | 55.3 |
| PPO | 67.6 | 29.2 | 32.0 |
| DPO | 66.6 | 39.0 | 61.9 |

RLOO 在三组设置上都最高, PPO 在 HH-Llama 上落后最多. RLOO 取 $k=2$ 时, 与用 $k=4$ 的 RAFT 持平或更好, 样本量只有一半; 它对 KL 系数和奖励噪声也更稳. DPO 排在 REINFORCE 和 PPO 之间, 说明这组任务上离线偏好优化并不吃亏, 4.6 节会接着讨论它在什么条件下吃亏.

这些结果都在 RLHF 设定下, 奖励来自学到的奖励模型. 换到可验证奖励时排序会变: Yue 等人在 RLVR 上比较多种算法, ReMax 的 pass@1 在六种方法里最低. 0/1 奖励下贪婪基线只有两个取值, 对方差的压缩不如组内多条样本的均值, 4.5 节 GRPO 的组内多采样在这里更合适. 同一组实验里各方法的 pass@256 都没有明显超过基座, 这个现象是 4.5 节 RLVR 局限性一篇的主题.

## 4. 进入这一节的路线

### 4.1 按背景

没学过 RL 的读者, 从 [01](./01-强化学习的数学原理/01-强化学习的数学原理.md) 读起. 它从 MDP 讲到 KL 正则目标的闭式解 $\pi^*\propto\pi_{\mathrm{ref}}\exp(r/\beta)$, 这个闭式解是 4.6 节 DPO 的出发点; 它还提前给出了 GRPO 组内标准化, 零梯度组的概率 $p^G+(1-p)^G$ 和 k3 KL 估计器, 读 4.5 节时可以回查. 熟悉经典 RL 的读者可以跳过 01 的前半, 直接读 [02 REINFORCE](./02-REINFORCE-序列级策略梯度/02-REINFORCE-序列级策略梯度.md) 里 LLM 设定与 Deep-RL 基准的对比.

要复现 RLHF 的读者, 重点读 [04 PPO](./04-PPO/04-PPO.md) 的 InstructGPT 配置和 [05 RLOO](./05-RLOO-留一法基线/05-RLOO-留一法基线.md) 的超参, 显存紧张时看 [06 ReMax](./06-ReMax-贪婪基线/06-ReMax-贪婪基线.md). 只想理解 PPO 为什么长成现在这样的读者, 按 [03 TRPO](./03-TRPO/03-TRPO.md) 再 04 的顺序读.

### 4.2 与 4.5, 4.6 的分界

这一节的方法都需要一个打分器. 打分器是可验证的判定函数时, 训练配方和改法集中在 [4.5 GRPO 家族与 RLVR](../4.5-GRPO家族与RLVR/4.5-GRPO家族与RLVR.md); 只有成对偏好, 不想训奖励模型时, 看 [4.6 偏好优化](../4.6-偏好优化/4.6-偏好优化.md). 奖励模型被优化过头的问题和 Best-of-$N$, RAFT 一类做法在 [4.7](../4.7-AI反馈与奖励过优化/4.7-AI反馈与奖励过优化.md).

RL 之前的 SFT 起点在 [4.2](../4.2-SFT/4.2-SFT.md), 它决定了 Ahmadian 等人所说的「起点已经很好」是否成立. RL 和 SFT 在遗忘上的差别, 见 [4.10 持续学习](../4.10-持续学习/4.10-持续学习.md) 第 5 节.
