# 持续学习：后训练侧的选型入口

> 本页只回答“后训练流程何时需要持续学习、应该跳到哪里继续读”。跨任务协议、遗忘度量、持续预训练、在线学习与测试时训练的唯一正本是 [`content/continual-learning`](../../../continual-learning/_garden.md)。这里不复制第二套完整教材。

## 1. 先判断变化是否应该写入权重

部署后的“新信息”至少分为四类，它们不应被同一种更新手段处理：

| 变化 | 典型例子 | 优先载体 | 为什么 |
|---|---|---|---|
| 高频、可撤销、需逐条溯源的事实 | 价格、库存、法规条文、当天新闻 | 检索、数据库或工具 | 无需重新训练，来源和生效时间可审计 |
| 稳定领域分布 | 医学写作风格、企业术语、某种代码库模式 | 继续预训练或领域自适应 | 目标是改变表示与生成分布，而非记住几条事实 |
| 明确任务行为 | 输出格式、拒答边界、工具调用规范 | SFT、偏好优化或规则层 | 有可验证的输入—目标行为对 |
| 用户或租户差异 | 客户术语、个性化风格、私有工作流 | 独立 adapter、prompt 或外部记忆 | 便于隔离、授权、撤销和版本治理 |

“模型不知道最新政策”并不自动推出“应该持续训练”。如果答案必须带出处、随时撤销或按权限变化，先做外部知识更新；只有重复出现、相对稳定且确实属于模型能力或分布缺口的变化，才进入权重更新流程。

## 2. 后训练中的四个基本选择

### 2.1 回放与混合训练

把一部分旧任务样本或其代表样本与新数据混合训练，是最直接的抗遗忘基线。它的有效性取决于回放集怎样覆盖旧能力，而不是一个固定的“旧数据占比”。工程上必须记录：

- 回放样本的来源、许可、去重与隐私边界；
- 新旧数据的采样器、每阶段 token 数和实际采样比例；
- 旧能力回归集是否与训练回放集独立；
- 数据分布改变时是否仍可重放历史数据。

如果原始数据不能保留，可研究生成式回放或蒸馏，但合成样本会继承教师偏差，也可能丢掉低频边界案例，不能写成等价替代。

### 2.2 正则化与蒸馏

EWC 用旧任务附近的参数重要性近似约束参数漂移；LwF 用旧模型输出作为蒸馏目标。二者都在“适应新任务”和“保持旧行为”之间设置权衡，但不提供无条件保证：

- EWC 的 Fisher 近似、任务边界和系数都影响结果；
- LwF 保持的是教师在所选数据上的输出，不等于保持所有旧知识；
- 旧教师本身的错误、安全缺陷和校准偏差也可能被保留。

原始来源：[EWC](https://doi.org/10.1073/pnas.1611835114)、[Learning without Forgetting](https://arxiv.org/abs/1606.09282)。

### 2.3 参数隔离与 PEFT

冻结基座并训练 LoRA、adapter 或 prompt 参数，可以减少可训练参数和优化器状态，并使不同任务的增量权重更容易版本化。但“基座没变”不等于“旧任务表现不会退化”：启用新 adapter 会改变模型行为，多个 adapter 还需要路由、合并、冲突测试和回滚策略。

PEFT 成本也不能由“可训练参数比例”直接换算。前向计算、激活保存、序列长度、训练 token 数、量化和通信仍会影响总时间与显存。LoRA 的原始定义与实验边界见 [LoRA 论文](https://arxiv.org/abs/2106.09685)。

### 2.4 架构扩展

Progressive Networks 等方法通过为新任务增加容量并冻结旧列来减少直接参数干扰，代价是容量随任务增长，而且任务路由和跨列连接需要额外治理。它适合作为“隔离换稳定性”的概念基线，不应被描述成可无限扩展的默认生产方案。[原始论文](https://arxiv.org/abs/1606.04671)。

## 3. 最小评测协议

持续学习的结论必须绑定任务序列。设依次学习任务 $1,\ldots,T$，在完成第 $t$ 阶段后，用固定评测集测所有已见任务，得到矩阵 $a_{t,j}$。至少保留：

- 当前任务表现 $a_{t,t}$：模型是否真的学会新任务；
- 旧任务轨迹 $a_{t,j}$（$j<t$）：不是只看最终平均数；
- 最终平均表现 $\frac{1}{T}\sum_{j=1}^{T} a_{T,j}$；
- 每个旧任务从历史最好值到最终值的下降；
- 与“联合训练上界”“只训练新任务”“不更新模型”三类基线的比较；
- 安全、校准、事实性和格式遵循等非单一准确率回归。

如果任务顺序、数据可见性、回放预算或评测集发生变化，就不能把结果当作同一个持续学习实验直接比较。更完整的矩阵定义、平均遗忘、前向/后向迁移和协议模板见 [评测协议、指标与任务顺序](../../../continual-learning/03-评测与实践/3.1-评测协议指标与任务顺序.md)。

## 4. 在 LLM 流水线中的落点

| 目标 | 可先做的低成本基线 | 何时升级 |
|---|---|---|
| 更新可引用事实 | 检索或工具 + 时间/权限过滤 | 检索仍无法覆盖稳定语言分布时，再评估训练 |
| 适应领域语料 | 小规模继续预训练 + 旧域回放 | 新域收益稳定且旧域回归可控后扩大 token 预算 |
| 新增任务行为 | SFT + 旧任务混合 + 独立回归集 | 多任务冲突明显时再考虑 adapter 路由或偏好优化 |
| 多租户个性化 | 独立 adapter/prompt/外部记忆 | 需要跨租户共享时，先做权限和负迁移审计 |
| 在线交互适应 | 先记录反馈、离线重放与人工审核 | 只有奖励可靠、可回滚且安全门禁完备时才在线更新 |

自蒸馏持续学习（SDFT）的专文位于 [SDFT：示范持续学习](../4.6-OPD/03-SDFT-示范持续学习/03-SDFT-示范持续学习.md)。它是特定方法，不代表持续学习全部路线。

## 5. 常见错误

- **把参数冻结等同于零遗忘**：输出还受 adapter、prompt、检索内容和解码配置影响。
- **只报告新任务成绩**：这无法判断旧能力是否被破坏。
- **用训练回放集做旧任务评测**：会把记忆样本当作泛化能力。
- **给出跨项目固定成本比**：可训练参数少不等于端到端成本按同比例下降。
- **把实时事实写进权重**：更新慢、撤销难，也缺少逐条来源。
- **无版本回滚**：即使平均指标上升，安全或少数关键任务也可能退化。

## 7. 本页核验清单

- 是否先证明问题需要权重更新，而不是检索、工具或规则？
- 是否记录任务顺序、新旧 token 预算、回放策略和数据许可？
- 是否有独立旧任务回归集与联合训练/不更新基线？
- 是否把平均指标之外的关键安全与少数任务退化单独报告？
- 是否能按模型、adapter、数据快照和评测版本回滚？
