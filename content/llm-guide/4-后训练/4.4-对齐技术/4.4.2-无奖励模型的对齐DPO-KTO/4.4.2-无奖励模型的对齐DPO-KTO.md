# 4.4.2 无奖励模型的偏好优化

这一节不训独立奖励模型，也不在训练环里跑 PPO。成对偏好直接写成分类或几率比；二值样本走 KTO；不想加载 $\pi_{\mathrm{ref}}$ 时看 SimPO。已经 SFT 过、不想再标偏好对时，看 SPIN：人标永远当 winner，上一迭代自生成当 loser。要把离线 DAP 改成当场采、当场标，看 OAIF：当前策略出两条，LLM 当裁判，损失仍是 DPO / IPO / SLiC。公式和表以各专文为准，不要把下面当第二份推导。

| 编号 | 专文 | 钉什么 |
|------|------|--------|
| 01 | [DPO](./01-DPO/01-DPO.md) | Bradley-Terry；隐式奖励 $r=\beta\log(\pi_\theta/\pi_{\mathrm{ref}})+\beta\log Z(x)$，$Z$ 成对抵消；样本 $(x,y_w,y_l)$ |
| 02 | [ORPO](./02-ORPO/02-ORPO.md) | $\mathcal{L}_{\mathrm{SFT}}+\lambda\mathcal{L}_{\mathrm{OR}}$；平均对数再 exp 的几何平均 $P$，不是 token 连乘；无 $\pi_{\mathrm{ref}}$ |
| 03 | [KTO](./03-KTO-前景理论对齐/03-KTO-前景理论对齐.md) | 二值、不成对；$z_0=\mathrm{KL}(\pi_\theta\Vert\pi_{\mathrm{ref}})$，错配估计、不反传。不是 Forward KL 再减一个阈值 |
| 04 | [SimPO](./04-SimPO-无参考长度平均/04-SimPO-无参考长度平均.md) | 无 $\pi_{\mathrm{ref}}$；奖励 $(\beta/|y|)\log\pi_\theta$，再减间隔 $\gamma$ |
| 05 | [SPIN](./05-SPIN-自对弈微调/05-SPIN-自对弈微调.md) | 人标 $y$ 永远赢，上一迭代自生成 $y'$ 当输；参考是 $p_{\theta_t}$，不是冻到结束的 SFT；不是 UltraFeedback DPO |
| 06 | [OAIF](./06-OAIF-在线AI反馈/06-OAIF-在线AI反馈.md) | 当前 $\pi$ 采两条，LLM 当场标；套 DPO/IPO/SLiC；TL;DR 4-way 人评 58.00%；不是 Lee RLAIF |

夹里还有一篇旧路径的 DPO 推导，当补充阅读，不另占号。

## 1. 六条专文怎么分

PPO 那条要奖励模型、参考、价值和策略同驻，在 [4.4.1](../4.4.1-基于奖励模型的RL-RLHF-PPO/4.4.1-基于奖励模型的RL-RLHF-PPO.md)。前四篇把更新写成离线损失，训练期不采样环境。SPIN 每轮用上一迭代生成 $y'$，损失形态仍像 DPO 的 logistic，但不吃 UltraFeedback 成对。OAIF 每步从当前策略采两条，LLM 当场判胜负，损失还是 DAP，不跑 REINFORCE。

DPO 仍要参考策略：KL 约束的最优策略可以反解成隐式奖励，成对代入 Bradley-Terry 之后 $Z(x)$ 消掉。ORPO 把 SFT 交叉熵和几率比罚项写在同一条损失里，不再加载参考。KTO 不要成对，一条 $y$ 加 desirable / undesirable 就回梯度。SimPO 用长度平均的 $\log\pi_\theta$ 当奖励，连参考都不要。SPIN 的 winner 钉死为人标，$y_w$ 不是 GPT-4 挑出来的。OAIF 的两条都来自当前 $\pi$，胜负由标注 LLM 当场给。

不要把 ORPO 写成「先 DPO 再加一项 SFT」。不要把 KTO 的 $z_0$ 写成 $\mathrm{KL}(\pi_{\mathrm{ref}}\Vert\pi_\theta)$。不要把 SimPO 写成「DPO 去掉参考还用同一条 $\beta\log(\pi/\pi_{\mathrm{ref}})$」。不要把 SPIN 写成「DPO 换了个名」。不要把 OAIF 写成 Lee 的 RLAIF。

| | 数据 | $\pi_{\mathrm{ref}}$ | 损失形态 |
|--|------|----------------------|----------|
| DPO | 成对 | 要 | $-\log\sigma(\beta\Delta\log\frac{\pi}{\pi_{\mathrm{ref}}})$ |
| ORPO | 成对 | 不要 | SFT + 几率比 |
| KTO | 二值单条 | 要（可退化） | $\lambda_y-v$，$z_0$ 错配 KL |
| SimPO | 成对 | 不要 | 长度平均 $\log\pi$ 对间隔 $\gamma$ |
| SPIN | 人标 vs 自生成 | 每轮换成 $p_{\theta_t}$ | 形态像 DPO logistic，winner 固定为人标 |
| OAIF | 当前 $\pi$ 采两条，LLM 当场标 | 要（DAP 里的 $\pi_{\mathrm{ref}}$） | 仍是 DPO/IPO/SLiC，数据槽换成在线 |

## 2. 不是谁

**不是** [4.4.1](../4.4.1-基于奖励模型的RL-RLHF-PPO/4.4.1-基于奖励模型的RL-RLHF-PPO.md) 的在线策略梯度：那里有采样、有奖励模型或规则验证器，GRPO / GSPO / RLOO / RAFT 都还在那一夹。

**不是** [4.4.3 RLAIF](../4.4.3-RLAIF/4.4.3-RLAIF.md)：RLAIF 换的是标签来源（人 → 现成 LLM），策略梯度还在，附录 E 是带价值基线的 REINFORCE。OAIF 也用 LLM 标偏好，但不拟合 RM、不跑 REINFORCE，正本在本夹 06。

**不是** [4.4.4](../4.4.4-其他对齐技术/4.4.4-其他对齐技术.md) 的 SLiC / RRHF / IPO。SLiC 是序列似然的 hinge 校准；RRHF 是长度归一 logp 的 ranking hinge；IPO 把对数比之差回归到 $1/(2\tau)$。那三篇的公式以专文为准，不要用这页旧讲义里的 BT σ 去读 RRHF。

需要人标成本、CoT 再 softmax 的，读 4.4.3。需要组相对或 clip 的，读 4.4.1。
