# 4.4.1 基于奖励模型的策略梯度

这一节还留着奖励模型（或规则验证器）：先打分，再更新策略。PPO 把 token 当动作、用 GAE 和 clip；后面几条拆四模型、换基线、换 clip 位置。公式和表以各专文为准。

| 编号 | 专文 | 钉什么 |
|------|------|--------|
| 01 | [GMPO](./01-GMPO/01-GMPO.md) | 几何均值收组内信号，和 GRPO 的算术均值不是同一把尺 |
| 02 | [GRPO](./02-GRPO/02-GRPO.md) | 组内 $z$-score，均值含自己；DeepSeekMath 的 GSM8K / MATH |
| 03 | [GSPO](./03-GSPO/03-GSPO.md) | 序列级几何平均重要性采样 $s_i$，clip 打在 $s_i$ 上，不是 token 比率再算术平均 |
| 04 | [PPO](./04-PPO/04-PPO.md) | Actor-Critic、GAE、clip；四模型怎么咬合 |
| 05 | [TRPO](./05-TRPO/05-TRPO.md) | 信任域，平均 KL $\le\delta=0.01$；PPO 的理论前身 |
| 06 | [RLOO](./06-RLOO-留一法基线/06-RLOO-留一法基线.md) | 留一法基线：第 $i$ 条不进自己的均值，通常不除组内 std |
| 07 | [RAFT](./07-RAFT-奖励排序微调/07-RAFT-奖励排序微调.md) | 每 prompt 采 $K$ 条，只对奖励最高的那条做 SFT；不是 RLOO |
| 08 | [CISPO](./08-CISPO-裁剪重要性权重/08-CISPO-裁剪重要性权重.md) | clip 的是 IS 权重再 stop-grad，梯度仍走 $\log\pi$；不是 sigmoid 软剪裁 |
| 09 | [SAPO](./09-SAPO-温度软门/09-SAPO-温度软门.md) | 温度 sigmoid 软门；$\tau_{\mathrm{pos}}=1.0$，$\tau_{\mathrm{neg}}=1.05$；不是熵滑动 $\varepsilon$ |
| 10 | [REINFORCE](./10-REINFORCE-序列级策略梯度/10-REINFORCE-序列级策略梯度.md) | 整段 $y$ 当一个动作；无偏滑动平均 $b_{\mathrm{MA}}$；不是 PPO clip，不是 RLOO 留一法 |

同层目前到 10。不要再发 11。

## 1. 这一夹怎么走

先读 [04-PPO](./04-PPO/04-PPO.md)。采样、KL 扣在中间 token、终局加 RM 分、GAE、clip 代理目标，都在那篇。下面伪代码只标明调用顺序，细节不要在这页再推一遍。

```python
for iteration in range(N):
    prompts = next_batch(dataset)
    responses, old_logp, old_values = sample(old_policy, prompts)
    rewards = score(reward_model, ref_model, prompts, responses)
    advantages, returns = gae(rewards, old_values)
    for _ in range(ppo_epochs):
        policy_model = ppo_update(policy_model, old_logp, advantages, returns)
    old_policy = policy_model
```

`sample` 冻结权重；`score` 不更新 RM 和参考；`ppo_update` 才动 Actor 和 Critic。同一批经验会在内层循环里反复用。

[05-TRPO](./05-TRPO/05-TRPO.md) 是 clip 之前那条信任域：平均 KL 写成约束，不是惩罚系数随便拧。PPO 用一阶 clip 近似同一件事。

组相对从 [02-GRPO](./02-GRPO/02-GRPO.md) 起：一道题采 $G$ 条，奖励做 $z$-score，均值含自己。§4 写了结果监督、过程监督、迭代 RL，以及它在谱系里的位置。

[03-GSPO](./03-GSPO/03-GSPO.md) 把重要性采样收到序列几何平均。[01-GMPO](./01-GMPO/01-GMPO.md) 是 token 级 $|\rho_t\hat{A}|$ 的几何平均，不要和 GSPO 的 $s_i$ 混。

## 2. 基线、过滤、闸门

四模型太重之后，拆法不只有「扔掉 Critic」。

[06-RLOO](./06-RLOO-留一法基线/06-RLOO-留一法基线.md) 仍走在线策略梯度，第 $i$ 条的基线是其余 $k-1$ 条，自己不进均值。[10-REINFORCE](./10-REINFORCE-序列级策略梯度/10-REINFORCE-序列级策略梯度.md) 是单样本、整段动作、历史奖励的滑动平均，和留一法不是同一条基线。[ReMax](../4.4.6-其他策略梯度/01-ReMax-贪婪基线/01-ReMax-贪婪基线.md) 把减数换成当前策略的 greedy 回答，落在 4.4.6，不要在本夹发 11。[Dr.GRPO](../4.4.6-其他策略梯度/03-DrGRPO-去标准差/03-DrGRPO-去标准差.md) 同样落在 4.4.6/03：两项归一化都删，不是只去 $\mathrm{std}$，也不要在本夹发 11。[07-RAFT](./07-RAFT-奖励排序微调/07-RAFT-奖励排序微调.md) 同样采 $K$ 条，但只克隆第一名，其余丢掉。采样预算可以一样，梯度吃法完全不同。

[08-CISPO](./08-CISPO-裁剪重要性权重/08-CISPO-裁剪重要性权重.md) clip 的是重要性权重，再 stop-grad，出界 token 的 $\log\pi$ 还在。[09-SAPO](./09-SAPO-温度软门/09-SAPO-温度软门.md) 把硬 clip 换成温度 sigmoid，正负两侧温度可以不对称。

不要把 SAPO 读成「$\varepsilon$ 随熵滑动」。不要把 GSPO 读成滑窗。不要把 RAFT 读成 RLOO。

## 3. 不是谁

**不是** [4.4.2](../4.4.2-无奖励模型的对齐DPO-KTO/4.4.2-无奖励模型的对齐DPO-KTO.md)：那边没有独立 RM，更新是离线分类或几率比。

**不是** [4.4.3 RLAIF](../4.4.3-RLAIF/4.4.3-RLAIF.md)：换的是标签来源。Lee 那篇实验是带学习价值网络的 REINFORCE，和 [10](./10-REINFORCE-序列级策略梯度/10-REINFORCE-序列级策略梯度.md) 用的移动平均基线不是同一套。人评表只在 4.4.3。

**不是** [4.4.5 GxPO](../4.4.5-GxPO家族/4.4.5-GxPO家族.md)：DAPO / Clip-Higher 那一族的结构扩展在那边对照，GSPO 公式仍以 03 为准。

**不是** [4.4.6 ReMax](../4.4.6-其他策略梯度/01-ReMax-贪婪基线/01-ReMax-贪婪基线.md)：那边基线是 greedy 解码的 RM 分，不是本夹 10 的 $b_{\mathrm{MA}}$，也不是 06 的留一法。

**不是** [4.4.6/03 Dr.GRPO](../4.4.6-其他策略梯度/03-DrGRPO-去标准差/03-DrGRPO-去标准差.md)：那边两项都删（$1/|o_i|$ 与组 $\mathrm{std}$），Oat-Zero-7B AIME 2024 是 43.3%，不是本夹 02 的带 $\mathrm{std}$ 原式。
