# 1.2 · 科普与行业杂谈: 大模型世界的生态图谱

技术文如果只讨论矩阵乘法和 loss，会误以为这个领域只是 arXiv 游戏。它已经是算力、实验室、开源权重和应用分发叠在一起的产业。本节按**角色**切生态，不写死某一年的 SKU；某次发布捆了哪些积木，统一去 [第 05 章模型家族与选型](../../05-模型家族与选型/05-模型家族与选型.md) 的对应版本正本。

从业者至少需要三件事：选型时看现金流与合规而不只看榜；职业路径在预训练 / 对齐 / 推理 / Agent / 产品之间已经分叉；当巨头卷基座时，缝隙往往在端侧、垂直领域和应用层。

## 1. 全球格局：按角色，不按型号

### 1.1 闭源实验室

**OpenAI** 用闭源旗舰 + API + ChatGPT 订阅定义了这一轮的「心跳」。壁垒与其说是某一版权重，不如说是对齐后的行为可控性——企业客户买的是这个。具体代际见第 05 章 OpenAI 家族正本，这里不跟踪 GPT-n 的市场名。

**Google（DeepMind + Google Research）** 同时有 Transformer 出身的研究纵深、搜索/视频语料，以及 TPU 这条非 GPU 训练轨。产品化长期慢于 OpenAI，是典型的创新者窘境，不是「不会做模型」。

**Anthropic** 把安全与对齐做成差异化。Constitutional AI 用原则约束行为，而不是只堆人类偏好数据。长上下文曾经是它的产品标签；窗口数字每个季度都在变，以第 05 章 Claude 版本正本所链的官方材料为准。

### 1.2 开源权重实验室

**Meta** 不靠卖 API：把强基座开出去，削弱闭源壁垒，把开发者拉到自家分发面。LLaMA 家族仍是开源对照系的零点。

**DeepSeek** 把 MLA、aux-loss-free MoE、低训练成本写成可复核的技术报告，R1 把开源推理能力推到能和闭源 o 系列对照的位置。机制本体在第 2 章，发布配方与来源链在第 05 章 DeepSeek 家族正本。

**Qwen / GLM / Kimi / 豆包** 分别靠开源谱系、统一预训练目标、长上下文产品、流量入口占位。中文场景、合规和本地化服务是国内厂商的差异化，不是「再发一个 7B」。

国内 2023 年「百模大战」之后格局已经收敛：能持续出报告、出权重、出推理栈的实验室留下，其余被应用层吸收。

### 1.3 欧洲与第二梯队

**Mistral** 以小团队做出 Dense/MoE 开源对照。**Cohere** 走企业 embedding 与 RAG 基础设施。**xAI** 绑的是实时社交数据管道，不是又一个通用聊天窗口。

### 1.4 开源枢纽

Hugging Face 与 GitHub 是权重、数据集和推理脚本的汇合点。开源的价值是可审计、可私有化微调，而不只是「免费」。

## 2. 关键概念（够用即可）

**参数规模**是脑容量的粗指标。Dense 模型几乎每参数都参与一次前向；MoE 用总参数撑容量、用稀疏激活控这次推理的 FLOPs。数字随报告变，以第 05 章版本正本所链的一手来源为准。

**上下文长度**是工作记忆。瓶颈是注意力 $O(n^2)$，不是「再买一张卡」。线性注意力、稀疏窗、RoPE 外推、检索压缩是四条不同的路，本体在第 2 章。

**多模态**分拼接式（视觉编码器 + 投影 + LLM）和原生式（预训练起就混 token）。前者便宜、融合浅；后者贵、理论上更深。细节在第 8 章。

**Agent** 是规划 + 记忆 + 工具 + 行动的闭环，不是「会聊天的模型」。可靠性瓶颈是规划失败和错误恢复，系统工程在第 13 章。

## 3. 时间线（2022–2026）：记范式，不记 SKU

**2022** ChatGPT 把对话产品做成大众界面；文生图同期破圈。

**2023** GPT-4 多模态输入、LLaMA/LLaMA 2 把开源可用性打穿、Gemini 入场、OpenAI 治理危机把安全和商业张力摊开。

**2024** 视频生成（Sora 一类）触发世界模型争论；o1 把测试时计算做成可卖的「慢思考」；DeepSeek-V3 用可公开的训练成本数字冲击「只有巨头能训」的迷信。

**2025** DeepSeek-R1 把开源推理拉到可与闭源 o 系列对照；行业焦点从「谁的基座更大」转到推理成本、Agent 可靠性和端侧可用。

**2026** 不是再猜一个闭源旗舰的发布月，而是开源报告潮把 Muon/残差扩展/稀疏注意力/PD 分离写进生产配方。导论只点轴，报告身份与来源走第 05 章，硬件走第 9 章。

## 4. 商业落地

客服、营销内容、代码辅助、企业 RAG、教育和医疗辅助，已经从概念验证走到要控幻觉与合规的阶段。高风险领域仍然是辅助决策，不是替代持证专家。

结构性趋势就三条：**闭源–开源能力差在收窄**；**推理成本按年降一个数量级**；**形态从文本生成扩到多模态和可行动的 Agent**。记住这三条，比记住本季的产品名有用。
