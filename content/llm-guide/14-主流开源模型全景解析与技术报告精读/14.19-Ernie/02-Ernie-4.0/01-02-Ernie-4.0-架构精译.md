# 文心一言 4.0: 知识增强大语言模型

>  **[返回 14.19-Ernie 家族总览](../../14.19-Ernie.md)** · 前代：[3.5](../01-Ernie-3.5/01-01-Ernie-3.5-架构精译.md)

> 该家族依靠其独特的算力优势与数据护城河, 在 LLM 红海中占据了核心生态位。

2023-10-17 百度世界产品发布，**不是**技术报告。李彦宏：理解 / 生成 / 逻辑 / 记忆全面升级；综合「与 GPT-4 相比毫不逊色」——这是演讲句，**没有**公开 MMLU 表。王海峰（科技日报 2023-10-25 转述）：理解和生成提升幅度相近；**逻辑**提升幅度达到理解的近 **3 倍**；**记忆**达到理解的 **2 倍多**；9 月小流量后一个多月效果再提升近 **30%**。架构与 3.0/3.5 一脉相承。

## 1. 训练系统（公开句，不是并行度表）

万卡上跑飞桨；集群调度 + 框架软硬协同。多维数据闭环（挖掘 / 分析 / 合成 / 标注 / 评估）。后训练：SFT、偏好学习、强化学习多阶段对齐。**可再生训练**：增量式参数调优以省资源和时间。

**没有** 4.0 总参、激活参、层数。2025 开源的 ERNIE **4.5** MoE（常见转述 424B/47B、Apache 2.0）是另一代，**禁止**写进本 D2 规格表。

## 2. 产品面

现场扫码邀测；企业走千帆申请 4.0 API。后续还有 4.0 Turbo、工具版（2024-04 Create），本篇只记一行。

## 3. 失效条件

- 给 4.0 写 424B。
- 把「近 3 倍 / 2 倍多」当成公开基准百分数。
