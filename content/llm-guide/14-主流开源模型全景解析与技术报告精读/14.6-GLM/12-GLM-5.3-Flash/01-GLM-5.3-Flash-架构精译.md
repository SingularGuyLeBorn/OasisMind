权重 [zai-org/GLM-5.3-Flash](https://huggingface.co/zai-org/GLM-5.3-Flash)，仓库协议 **MIT**。官方文档把它写成 GLM-5 系列里 **第一个原生多模态** 模型，并且是「开源前沿里第一个把稀疏注意力和线性注意力捆在一起」的基座。角色不是 GLM-5.3 换个量化档：同页拿 **GLM-5.3** 当对照，说 Flash 把每 token 注意力算力和 KV 压到对方的 $1/3.01$ 和 $1/4.44$。

**材料类型**：没有独立 Flash 架构 PDF。数字以 [Z.ai 文档](https://docs.z.ai/guides/vlm/glm-5.3-flash) + HF README/`config.json` + [vLLM recipe](https://recipes.vllm.ai/zai-org/GLM-5.3-Flash) + [SGLang cookbook](https://cookbook.sglang.io/autoregressive/GLM/GLM-5.3-Flash) 为准。HF 引用 GLM-5 报告 [arXiv:2602.15763](https://arxiv.org/abs/2602.15763)——那是 **2026-02 的 GLM-5**，不要用它的 DSA 适配段冒充 Flash 的混合骨架。`z.ai/blog/glm-5.3-flash` 本会话 WebFetch 超时，博文数字以文档页为准。

官方口径：总参数 **320B**、激活 **18B**。vLLM recipe 写 **~321B** / 18B。后文两边都标，禁止合成第三个数。

## 1. 这一次捆了哪些技术

| 面 | 这次用了什么 | 本体 |

| 积木 | 混合 **KDA 线性** + **稀疏 MLA（indexer + IndexPool）**；残差 **mHC** | IndexPool / KDA / mHC 专文 |

## 2. 和 GLM-4.5 / GLM-5.3 差在哪

文档「Architecture for Extreme Efficiency」段用两套对照，不要混成一张「全面更小」表。

相对 **GLM-4.5 系列**（总参数接近）：

| | GLM-4.5 系列（文档） | GLM-5.3-Flash |
|--|----------------------|----------------|
| 总参数 | 355B | **320B**（vLLM ~321B） |
| 激活 | 32B | **18B** |
| 层数 | 92 | **45** |

相对 **GLM-5.3**（同页 Overview 与后文表格各写了一套倍数）：

| 口径 | 注意力算力 | KV cache |
|------|------------|----------|
| Overview | **3.01×** 更少 | **4.44×** 更少 |
| 后文 per-head-per-layer 对照 | **3.0×** | **4.4×** |

两套都是官方给出的，禁止平均出 3.005。对照对象还包括 DeepSeek-V4-Flash 和 Kimi K3：文档说 Flash 的注意力算力在这组里最低，KV 仍略大于 K3 和 V4-Flash。那是 **每头每层注意力 FLOPs / 每层平均 KV（BF16）** 的归一化对比，不是墙钟、不是电费。

基座评测：文档写 GLM-5.3-Flash-**Base** 整体超过 GLM-4.5-Base，多数基准上和 GLM-5-Base 打平。柱高在官方图里，**不把图当配图、不估像素**。

## 3. 层日程：34 KDA + 11 稀疏 MLA

`layer_types` 的模式是 **三层 `linear_attention` + 一层 `deepseek_sparse_attention`**，重复 11 次（44 层），最后再垫一层线性（第 44 层，0-based）。`linear_attn_config` 写明：

- `kda_layers`：34 个下标（0,1,2, 4…42, 44）
- `full_attn_layers`：11 个下标（3,7,…,43）——名字叫 full，类型仍是稀疏 MLA

vLLM：45 层 **KDA + NoPE sparse MLA**。SGLang：文本 45 层是 **MLA + DSA + KDA**。本目录统一用官方文档的「线性 / 稀疏」+ config 的类型名；线性层按 vLLM/SGLang 点名为 **KDA**。

KDA 配置（不要在本目录再推通道对角门）：

| 字段 | 值 |
|------|----|
| `num_heads` | 64 |
| `head_dim` | 128 |
| `gate_lower_bound` | **-5.0** |
| `short_conv_kernel_size` | 4 |

SGLang 警告不要覆盖 `linear_lower_bound`（对应这只下界）。数值和 K3 的 $g_{\min}=-5$ 相同；Flash **没有**写出 K3 式 (5) 的 Sigmoid 参数化，本篇只记配置。KDA 状态池和 KV 池分开，serving 用 `--mamba-full-memory-ratio`（SGLang cookbook）。

稀疏 MLA：

| 字段 | 值 |
|------|----|
| `kv_lora_rank` | 512 |
| `q_lora_rank` | 1536 |
| `qk_nope_head_dim` | 256 |
| `qk_rope_head_dim` | **0** |
| `v_head_dim` | 256 |
| `mla_use_nope` | true |
| `num_attention_heads` / `num_key_value_heads` | 64 / 64 |

IndexPool 的 $k=4$、$K=2048$ 见专文。不要和 QSA 的平均池化混名。

mHC：`mhc: true`，`hc_mult: 4`，`hc_sinkhorn_iters: 20`，`hc_eps: 1e-6`。公式在 [01-mHC](../../../2-核心原理与架构/2.1-深度学习基础组件/2.1.3-残差连接/01-Hyper-Connections与mHC.md)，本目录不抄 Sinkhorn。

## 5. 评测（只抄文档写出的格子）

不要去抄第三方柱状图。文档正文给出：

| 基准 | Flash | 对照 |
|------|-------|------|
| DeepSWE v1.1 | **63.4** | GLM-5.2 **46.2** |
| AutomationBench | **48.8** | GLM-5.2 **26.2** |
| Z.ai Code Bench v1.0（max effort；跑在 Claude Code **2.1.207**） | **29.0** | Claude Opus 4.8 **29.5** |
| Artificial Analysis Intelligence Index v4.1.1 | **57** | 同页写 **$0.045 / task**（discounted） |

发布前用匿名名 **ox-alpha** 在 OpenCode / OpenRouter 上测；文档说当周最热，流量跑在国产芯片上。

API：`glm-5.3-flash`；推荐 `temperature: 1`，`top_p: 0.95`，`reasoning_effort: max`；思考模式不能关。

## 6. Infra：EPD 三分，而不是只拆 PD

文档「Serving at Scale on Chinese AI Chips」：单卡算力/显存不够撑 1M，所以用「算力换带宽、通信换带宽」。点名的技术：**线性注意力与 LM head 的节点内 TP**、**ReplaySSM**、**W8A8**、混合 **INT8/FP8/BF16** cache、**Layer Split**。集群上把多模态 **Encode**、prompt **Prefill**、逐 token **Decode** 拆成三池独立扩缩——他们叫 **EPD**。相对同硬件最初基线，端到端 serving **3×**。没有公开芯片型号和 FLOPS，本篇不编。

vLLM recipe：默认 FP8 权重大约 **306 GiB**；Hopper 上 FP8 KV **不支持**，Blackwell 可以。SGLang：不要改 `linear_lower_bound`。

## 8. 失效条件

- 把 Flash 写成 GLM-5.3 的量化 SKU。
- 为非 Flash 的 GLM-5.3 mkdir。
- 用 2602.15763 冒充 Flash 混合注意力证明。
- 把 3.01× 与 3.0× 合成一个倍数；把 320B 与 321B 合成一个参数量。
- 把 `full_attn_layers` 读成满注意力。
- 把 IndexPool 写成 QSA。
- 编优化器名字、芯片型号、未写出的基准柱高。
- 把 serving 的 3× 和注意力 3.01× 收成同一个「三倍」。
