# GPT-4: 跨越模态界限的专家混合架构 (MoE) - 技术探测与反向工程

>  **[返回 14.12-OpenAI 家族总览](../../14.12-OpenAI.md)** · 前代：[ChatGPT](../05-ChatGPT-3.5/01-05-ChatGPT-3.5-反向工程精译.md) · 已有长 D5：[MoE 推测](./05-GPT-4-MoE架构推测与训练规模经济学.md)

> **背景**：该模型并未完全开源其底层代码与权重，本精译基于其官方发布的技术报告(Technical Report)、系统卡片(System Card)以及顶级研究团队的逆向探测论文重构。

**材料类型（2026-08）**：**技术报告精读**。空壳标题把 **MoE** 写进名字——[GPT-4 Technical Report](https://arxiv.org/html/2303.08774v6) §2 **明文**：因竞争与安全，**不再提供**架构（含模型大小）、硬件、训练算力、数据集构造、训练方法或类似细节。后训练是 **RLHF**。MoE / 1.8T 是业界推测，**不是**本报告 Table。

## 1. 报告实际承认的形状

- 大规模 **多模态**：图+文进，**只出文本**
- Transformer-style，预训练 next-token；公开网页 + 第三方授权数据
- 对齐后事实性与「按期望行事」更好
- 工程重点：跨尺度可预测的 infra / 优化，用不超过 GPT-4 算力 **1/1,000**（能力）到 **1/10,000**（loss 拟合）的小模型，预测终局部分指标

§3.1：内部代码库（不在训练集）上的终局 loss，用 $L(C)=aC^{b}+c$ 在开跑后不久、不用部分结果的情况下拟合，图 1 对得上。§3.2：HumanEval 子集的 mean log pass rate 同样可外推；最容易那一桶 GPT-4 **低于**预测。Hindsight Neglect（Inverse Scaling Prize）上 GPT-4 **反转**了随规模变差的趋势。

## 2. 评测（Table 1 / 2，设置不要混）

**律师资格模拟考**：Uniform Bar **298 / 400（约 90th）**；GPT-3.5 **213 / 400（约 10th）**。视觉关不关，Bar 都是 298。LSAT 163（~88th）vs no-vision 161。多数考试用 post-trained RLHF 模型；**没有为这些考试专项训练**。选择题上 base 与 RLHF **平均一样好**（附录 B）。

Table 2（GPT-4 few-shot vs GPT-3.5）：

| | GPT-4 | GPT-3.5 | 设置 |
|--|-------|---------|------|
| MMLU | **86.4%** | 70.0% | 5-shot |
| HellaSwag | **95.3%** | 85.5% | 10-shot |
| ARC Challenge | **96.3%** | 85.2% | 25-shot |
| WinoGrande | **87.5%** | 81.6% | 5-shot |
| HumanEval | **67.0%** | 48.1% | 0-shot |
| DROP F1 | **80.9** | 64.1 | 3-shot（此项输给专项 SOTA 88.4） |
| GSM-8K | **92.0%**\* | 57.1% | 5-shot CoT；\* 预训练混了部分训练集 |

翻译 MMLU：26 种语言里 **24** 种超过当时英文本地 SOTA。ChatGPT/API 用户 prompt 5214 条，人评 GPT-4 比 GPT-3.5 更好占 **70.2%**。

视觉：任意交错的图文 prompt，出文本。文档/照片/图/截图。few-shot / CoT 对视觉同样有效。

排除 BIG-bench（训练时误混）。开源 **OpenAI Evals**。
