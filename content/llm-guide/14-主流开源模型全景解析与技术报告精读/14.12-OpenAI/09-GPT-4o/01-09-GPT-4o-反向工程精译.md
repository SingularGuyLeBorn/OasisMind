# GPT-4o: Omni 全模态端到端原生架构 - 技术探测与反向工程

## 1. 主张（博文）

GPT-4o 的 o = omni。输入：任意组合的 **text / audio / image**（系统卡还写了 **video**）。输出：任意组合的 **text / audio / image**。相对旧 Voice Mode（三个模型串起来：ASR → GPT 文本 → TTS；平均延迟 GPT-3.5 **2.8 s**、GPT-4 **5.4 s**），4o 是 **一个新模型端到端**训过 text、vision、audio，同一套神经网络处理所有输入输出。因此旧管线里 GPT-4 听不到语调、多人、背景声，也笑不出、唱不出。

音频回复最快 **232 ms**，平均 **320 ms**（博文比人类对话反应时间）。英语文本和代码对齐 GPT-4 Turbo；非英语文本显著更好；API **快一倍、一半价格、5× 速率限制**（相对 Turbo）。视觉和音频理解自称尤其更好。

当天 ChatGPT：**免费档**可用文本+图；Plus **最高 5×** 消息额度。Voice Mode 新版在 Plus **alpha、未来几周**。API 当天只有 **text + vision**；audio/video 给一小撮 trusted partners「未来几周」。

## 2. 评测（博文正文有百分数的才抄）

全部用新开源的 **simple evals** 库：

| | GPT-4o | 设置 |
|--|--------|------|
| MMLU | **88.7%** | 0-shot CoT |
| MMLU | **87.2%** | 传统 5-shot **无** CoT |

Llama 3 400B「仍在训练」是脚注，不是对照分。ASR：相对 Whisper-v3 全面更好、低资源语言尤其好——**没有百分数**。语音翻译：MLS 上 SOTA、好过 Whisper-v3——**没有百分数**。M3Exam：所有列出语言都强过 GPT-4；斯瓦希里/爪哇视觉题 ≤5 道所以省略。视觉：自称感知基准 SOTA；全 0-shot；**MMMU / MathVista / ChartQA 是 0-shot CoT**。博文图柱 **本篇不估成第三个数**。

新 tokenizer 压缩示例（同一句自我介绍，20 种语言表）：古吉拉特 **4.4×**（145→33 token），泰卢固 3.5×（159→45），泰米尔 3.3×（116→35），… 英语 **1.1×**（27→24）。不要把 4.4× 写成「所有语言」。

## 3. 系统卡多出来的训练与安全数字

预训练文本与语音能力数据截止 **October 2023**。公开网页 + 合作方非公开数据（点名 Shutterstock）。多模态含图/音/视频。DALL·E 3 用户 opt-out 的图用指纹从 4o 系列训练集抠掉。

Preparedness：cyber / CBRN / persuasion / autonomy **都没有高于 Medium**（博文同句）。博文写 70+ 外部专家；系统卡写 **100+** 红队、45 种语言、29 国，2024-03 初到 6 月末四阶段。两套口径并存，不合成第三个数。

语音输出分类器：相对系统声线的 meaningful 偏离抓住 **100%**。Table 2：English precision **0.96** / recall **1.0**；Non-English 0.95 / 1.0。说话人识别安全行为（Table 3）：Should Refuse 0.83→**0.98**；Should Comply 0.70→**0.83**（对应正文「拒答 +14、该答应时 +12」）。只允许预制声线。
