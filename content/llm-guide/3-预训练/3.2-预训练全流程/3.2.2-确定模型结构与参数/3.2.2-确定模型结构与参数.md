# 3.2.2 确定模型结构与参数

定结构是在**性能、训练 FLOPs、推理 KV 与延迟**之间取点。积木怎么算（MHA、GQA、RoPE、SwiGLU）在第 2 章；本节只定「用哪套积木、层数和宽度填多少」。给定算力下 $N$ 与 $D$ 怎么分，见 [3.2.6](../3.2.6-Scaling-Law/3.2.6-Scaling-Law.md)，这里不重推 Kaplan 幂律。

## 1. 三个约束

- **性能**：更大通常更强，但边际递减。同推理成本下，过训小模型（Llama 3 8B / 15T token）可以打过欠训大模型。
- **训练成本**：近似 $C\approx 6ND$（Chinchilla 附录的 Transformer FLOPs 计数）。数据不够就不要盲目加层。
- **推理成本**：KV Cache 随序列长度、KV 头数、层数涨。GQA 少 KV 头，是 7B 以上的默认，不是再发明一套注意力。

## 2. Decoder-only 默认积木

![](./images/fig-decoder-block-choice.png)

> 图 1：一层的选择。残差 + RMSNorm + GQA/RoPE + SwiGLU。公式回第 2 章。

**图 1 解析**

- Pre-Norm RMSNorm：深网更稳，比 Post-LN 省事。
- GQA + RoPE：查询头多、KV 头少；相对位置进点积。MHA 标准形式 → [01-MHA](../../../2-核心原理与架构/2.2-基础注意力机制/2.2.2-多头注意力变体/01-MHA-多头注意力的标准形式/01-MHA-多头注意力的标准形式.md)；GQA 折中 → [03-GQA](../../../2-核心原理与架构/2.2-基础注意力机制/2.2.2-多头注意力变体/03-GQA-在性能与缓存之间折中/03-GQA-在性能与缓存之间折中.md)；RoPE → [01-RoPE](../../../2-核心原理与架构/2.1-深度学习基础组件/2.1.4-位置编码/01-RoPE本体-旋转位置编码/01-RoPE本体-旋转位置编码.md)。
- SwiGLU FFN：Llama 起标配，中间层大约 $d$ 的 3.5 倍量级（含门控，参数比两层 ReLU FFN 更贵）。

MoE、MLA 是另一条结构岔路，分别见 2.4.1 与 2.3.5，不要在本节再推路由或低秩 KV。

## 3. 超参表（公开配置）

`head_dim = hidden_size / n_heads`，常见 128。

| 模型 | 层数 | $d_{\mathrm{model}}$ | $n_{\mathrm{heads}}$ | $n_{\mathrm{kv}}$ | FFN 中间维 | 词表 | 预训练上下文 |
|------|------|----------------------|----------------------|-------------------|------------|------|----------------|
| Llama 2 7B | 32 | 4096 | 32 | 32（MHA） | 11008 | 32K | 4K |
| Llama 3 8B | 32 | 4096 | 32 | 8 | 14336 | 128256 | 8K |
| Llama 3 70B | 80 | 8192 | 64 | 8 | 28672 | 128256 | 8K |
| GPT-3 175B | 96 | 12288 | 96 | 96 | 49152 | 50257 | 2K |

来源：Llama 2 / Llama 3 报告与模型卡；GPT-3 Table 2.1。GPT-4 层数未公开，不写「推测 120 层」。

**GQA**：Llama 3 8B 是 32 个 Q 头对 8 个 KV 头（4:1）；70B 是 64:8（8:1）。KV 头钉在 8，Cache 主要跟层数和序列走，不跟 $d_{\mathrm{model}}$ 线性涨满。

**深度 vs 宽度**：8B→70B，层数 32→80（2.5×），宽度 4096→8192（2×）。这是这一家的选择，不是定理。过深会不稳，靠 Pre-Norm 和较小的峰值学习率顶住。

其它常改项：`rope_theta`（Llama 3 为 $5\times 10^5$）、预训练 dropout 多为 0、`max_position_embeddings` 与后续长上下文续训分开（Llama 3 先 8K 再续到 128K）。

## 4. 设计顺序

1. 部署延迟、卡数、可用 token。
2. 用 3.2.6 估一个 $N$，再对标同规模开源配置填层数/宽度。
3. 选稠密 Decoder-only，或 MoE / MLA（链第 2 章，不在这里展开）。
4. 1B 级试点：学习率、稳定性、梯度范数。
5. 小规模 loss 若和缩放预测差太远，先查数据与学习率，再改深度。

词表 $V$ 由 [3.3](../../3.3-分词器与Tokenizer/3.3-分词器与Tokenizer.md) 决定，embedding 参数 $V d$ 在 70B 里占比小，但 8B 上已经能感到。
