# 3.2.3 训练框架选择

结构定了之后，要把一层层矩阵放到几千张 GPU 上。显存装的是参数、梯度、Adam 状态和激活；时间则花在计算和 All-Reduce / P2P 上。并行实现的更细切分（序列并行、Ulysses）见 [6.1.1](../../../6-训练与推理优化/6.1-训练基础设施/6.1.1-分布式训练/6.1.1-分布式训练.md)。本节钉 3D 并行和 ZeRO 的文档数字。

## 1. 为什么必须切

70B 量级，BF16 权重约 140GB；Adam 的 FP32 一阶/二阶动量再乘二，优化器状态往往比权重大。再加激活（随 batch 和序列）。一张 80GB H100 放不下完整副本，普通 DDP 直接出局。

算力同样不够单卡。**Llama 3 405B**（不是 70B）在最多 **16K 张 H100** 上预训练 **15.6T** token；报告里一段 54 天快照用于统计中断（Grattafiori et al., 2024, §3）。旧文把 16K H100 / 54 天安在 70B 上，分母错了。

## 2. 3D 并行

![](./images/fig-3d-parallel.png)

> 图 1：TP 切层内矩阵（节点内 NVLink），PP 切层到不同 stage，DP 复制整条流水线、不同 batch。总卡数 $= TP\times PP\times DP$。

**图 1 解析**

- **数据并行**：每卡一份（或 ZeRO 分片后的）模型，不同 micro-batch，梯度 All-Reduce 或 Reduce-Scatter。实现简单，模型大于单卡显存时不够。
- **流水线并行**：层按 stage 切开。气泡比例约 $(p-1)/m$（$p$ stage，$m$ micro-batch）；1F1B 和 interleaved schedule（Narayanan et al., 2021）用来填气泡。Llama 3 报告写总体气泡 $\frac{\mathrm{PP}-1}{V\cdot M}$。
- **张量并行**：把一列 Linear / 一组头切到节点内 GPU。通信量高，通常 $TP\le 8$，绑 NVLink。Megatron-LM（Shoeybi et al., 2019；Narayanan et al., 2021）是这一档的参考实现。

| 维 | 典型范围 | 通信 |
|----|----------|------|
| TP | 1–8，节点内 | 极高 |
| PP | 数段到十几段 | stage 间激活，较低 |
| DP | 随卡数放大 | 梯度同步，高 |

Llama 3 405B 公开过一组并行：例如 8192 卡时 TP=8、PP=16、DP=64，全局 16M token/batch，BF16 MFU **43%**；16K 卡 DP=128 时 MFU **41%**（报告 Table 4）。不要把「Megatron 一定 50%+ MFU」当成框架属性。

## 3. ZeRO（DeepSpeed）

标准混合精度 Adam 每参数大约：FP16 权重 2B + FP16 梯度 2B + FP32 动量/方差 8B ≈ **12 bytes**（主权重若另存 FP32 还会更高）。ZeRO（Rajbhandari et al., 2020, arXiv:1910.02054）按数据并行组切冗余：

| 级别 | 切什么 | 论文给出的显存降幅（相对未切分 DP） |
|------|--------|--------------------------------------|
| ZeRO-1 | 优化器状态 | 约 **4×** |
| ZeRO-2 | + 梯度 | 约 **8×** |
| ZeRO-3 | + 参数 | 随 $N_d$ 线性，前向/反向要 All-Gather 当前层 |

ZeRO-2 用 Reduce-Scatter 代替整包 All-Reduce 来切梯度；ZeRO-3 每层 gather 参数，通信量明显高于 ZeRO-2。Offload / Infinity / ZeRO++ 是后续扩展，场景是 CPU/NVMe 换显存或量化通信，不是 3D 并行的替代。

旧文「7.5B 模型标准 DP 120GB」没有对应表，不引用。

## 4. 框架怎么选

| 框架 | 文档里的强项 | 典型用法 |
|------|--------------|----------|
| **DeepSpeed** | ZeRO 1/2/3、Offload、HF 集成 | 中小规模、快速 ZeRO-3 |
| **Megatron-LM / Megatron-Core** | TP + interleaved PP、序列并行 | 旗舰稠密模型 |
| **PyTorch FSDP** | 原生分片，接近 ZeRO-3 | 单机到中等集群 |
| **Megatron-DeepSpeed** | 3D + ZeRO 组合 | 历史上的超大作业 |

FSDP 侵入小；Megatron 要按 Column/Row Parallel 改层。70B+ 多机通常 TP 钉在节点内，PP/DP 拉跨机，需要时再叠 ZeRO-1 优化器分片（Megatron 分布式优化器）。

确定框架后的学习率、精度、batch 在 [3.2.4](../3.2.4-预训练策略/3.2.4-预训练策略.md)；挂了怎么拉起在 [3.2.5](../3.2.5-训练容灾与监控/3.2.5-训练容灾与监控.md)。
