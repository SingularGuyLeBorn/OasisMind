# 3.2.7 继续预训练:CPT 不是 SFT

基座已经按 [3.2.6](../3.2.6-Scaling-Law/3.2.6-Scaling-Law.md) 的预算训过一轮.继续预训练(continued pretraining, CPT)是:**同一套 next-token 损失,换一批(或混一批)语料,接着改权重**.它要解决的是知识截止日期,领域分布,目标语言或代码密度,不是「听懂用户指令」.指令对齐是 [第 4 章 SFT](../../../4-后训练/4.2-SFT/4.2-SFT.md);终身顺序任务是 [4.7 持续学习](../../../4-后训练/4.7-持续学习/4.7-持续学习.md).本篇只写预训练管道上的这一段.

## 1. CPT 卡住的瓶颈:灾难性遗忘

给定基座 $\theta_0$,在新语料 $D_{\mathrm{new}}$ 上梯度下降得到 $\theta_1$.若不对旧分布做任何约束,常见结果是

$$
\mathcal{L}(\theta_1, D_{\mathrm{new}}) < \mathcal{L}(\theta_0, D_{\mathrm{new}}),\quad
\mathcal{L}(\theta_1, D_0) \gg \mathcal{L}(\theta_0, D_0) \tag{1}
$$

同一参数 $\theta_i$ 同时参与旧知识与新知识的表示.更新

$$
\Delta\theta_i = -\eta\,\partial_{\theta_i}\mathcal{L}(D_{\mathrm{new}}) \tag{2}
$$

不会只改「金融那一维」.这就是灾难性遗忘,不是 SFT 里 prompt mask 没设好.

度量通常用旧评测集准确率跌幅,旧验证损失涨幅,或输出分布相对 $\theta_0$ 的 KL.工程上更可操作的是:**领域 loss 下降的同时,通用集(MMLU / 通用 PPL)只允许小幅变差**.

## 2. 和 SFT 差在损失掩码,不在优化器名字

![](./images/fig-cpt-vs-sft.png)

> 图 1:CPT 对序列所有位置做 next-token;SFT 通常 mask 掉 prompt,只在回答上计损失.二者都可以用 AdamW,数据与掩码不同.

**图 1 解析**

- 左列:从基座 checkpoint 出发,把领域 token 和通用 replay 混进同一批,**每个位置都进损失**--这仍是语言模型,只是数据混合物变了.
- 右列:样本是 instruction / response;prompt 同质化高,损失打在回答上,目标是改变**条件生成行为**.
- 中间虚线:CPT 注入分布(代码,中文,长上下文),SFT 教格式与意图.第 4 章原文也写:知识注入应走 continue-pretrain,不要在 SFT 里塞五十万条代码硬灌.
- **不是**:CPT 等于「小学习率的 SFT」;也不是 LoRA 的同义词.LoRA-CPT 是参数隔离变体,骨干可以冻住,见 §5.

## 3. 缓解遗忘:小步长 + 旧数据 replay

### 3.1 学习率

从零预训练常用峰值 $\sim 3\times 10^{-4}$.CPT 通常降一个数量级(Code Llama 长上下文阶段用 $2\times 10^{-5}$,见 Rozière et al., 2023).直觉:$\eta$ 小则 $\Delta\theta$ 小,旧盆地里的位移小.这是启发式,不是定理.

### 3.2 混合物

$$
\mathcal{L}_{\mathrm{total}}=\lambda\,\mathcal{L}(D_{\mathrm{new}})+(1-\lambda)\,\mathcal{L}(D_{\mathrm{old}}) \tag{3}
$$

$\lambda$ 大则领域涨得快,通用掉得快.Code Llama 在代码为主的 500B tokens 里仍保留一部分自然语言,并写明:抽通用 batch **有助于 MBPP**(论文 §2.2).这是「replay 不是浪费 FLOP」的一手证据.

经验区间([OM-FREEPLAY] 数量级,不是论文表):领域 : 通用大约 $2:1$ 到 $1:1$,用通用验证集当刹车,而不是锁死 $\lambda$.

### 3.3 EWC 一类正则

弹性权重巩固把 Fisher 对角元当「参数重要性」,对偏离 $\theta^*$ 加二次罚.大规模稠密 CPT 里算 Fisher 贵,工业上更常见的是 **replay + 小 $\eta$**.EWC 的公式与任务冲突写在 [4.7](../../../4-后训练/4.7-持续学习/4.7-持续学习.md),这里不复制第二套.

## 4. 案例:Code Llama 是 CPT;BloombergGPT 不是

**Code Llama**(Rozière et al., 2023)从 Llama 2 权重初始化,再在代码偏重数据上训 **500B** tokens(70B 为 1T).HumanEval pass@1(greedy):

| 模型 | 尺寸 | HumanEval pass@1 |
|------|------|-----------------:|
| Llama 2 | 70B | 30.5% |
| Code Llama | 34B | 48.8% |
| Code Llama | 70B | 53.0% |
| Code Llama - Python | 34B | 53.7% |

表:Rozière et al. Table 2.同文:Llama 2 70B 在 Python 代码基准上大致相当于 Code Llama 7B--500B 领域 CPT 换来的,不是换骨干.

长上下文那一截也是 CPT:16,384 长度,RoPE $\theta=10^6$,论文称为 LCFT.副作用:短序列 HumanEval / MBPP 平均会掉一点(Table 10:HumanEval pass@1 约 −0.52 个百分点).**拉长窗口不是免费的.**

**BloombergGPT**(Wu et al., 2023)是 **从零** 训的 50B 级金融模型,不是 CPT.FinPile 约 **363B tokens,占训练混合物 51.27%**,其余为通用语料.它说明的是:即便从零做领域模型,也要接近一半通用文本;不能拿它当「CPT 配比模板」却写成继续训练.

Llama 3 把窗口从 8K 接到 128K 的阶段,用了约 **800B** tokens 的继续预训练,并明确用 needle-in-a-haystack 检查是否适应新长度(Grattafiori et al., 2024, §3.4).那是「同一目标,加长上下文」的 CPT,评估协议见 [3.4.3](../../3.4-预训练评估/3.4.3-大海捞针测试/3.4.3-大海捞针测试.md).

## 5. 失效与边界

| 现象 | 原因 | 说明 |
|------|------|------|
| 通用 MMLU 断崖 | $\lambda$ 过大或 $\eta$ 仍是预训练峰值 | 降 $\lambda$ 或降峰值,不要加 SFT 数据充数 |
| 领域 loss 降,下游不动 | 领域语料是网页壳或重复模板 | 质量过滤优先于加 token |
| 词表加了中文,一上来就满学习率 | 新 embedding 未预热 | 先冻骨干,只训新行,或极小 $\eta$ 短预热 |
| 把 BloombergGPT 当 CPT 案例 | 它是从零混合训练 | 学的是 50/50 配比,不是 continue |
| 用 LoRA 当「已解决遗忘」 | 容量在低秩里 | 领域很重时仍可能欠拟合;解冻骨干会回到式 (1) |
