**图 1 解析**

- **数据**: 采集, 清洗, 配比, 见 [3.1](../3.1-预训练数据/3.1-预训练数据.md). 分词器在数据之后, 结构之前确定, 见 [3.3](../3.3-分词器与Tokenizer/3.3-分词器与Tokenizer.md); 词表大小同时影响 embedding 参数和输出层的计算量, 在 [3.2.1](./3.2.1-确定模型结构与参数/3.2.1-确定模型结构与参数.md) 第 5 节核算.

- **训练策略**: 学习率日程, warmup, batch, 退火与数据切换, 长上下文阶段. 见 [3.2.3](./3.2.3-预训练策略/3.2.3-预训练策略.md).
- **checkpoint 与监控**: 故障统计, checkpoint 间隔, loss spike, 监控信号. 见 [3.2.4](./3.2.4-训练容灾与监控/3.2.4-训练容灾与监控.md).

图中五个环节是依次确定的, 但后面的环节会反过来约束前面: 流水线并行的段数影响层数的选择 (3.2.1 第 3 节); 故障率决定了 checkpoint 必须足够快, 这又影响框架选择 (3.2.4 第 4 节).

## 3. 一个模型的决策顺序

以 Llama 3 405B 为例, 各篇的内容对应这样一串决策:

1. **算力与规模** (3.2.5): 在 $6\times10^{18}$ 到 $10^{22}$ FLOPs 之间做 IsoFLOP 实验, 外推到 $3.8\times10^{25}$ FLOPs, 得到约 402B 参数, 16.55T token; 最终用 405B 参数.
2. **形状** (3.2.1): 126 层, 宽度 16,384, 128 个查询头, 8 个 KV 头, 词表 128K.
3. **并行** (3.2.2): 最多 16K 张 H100, 张量, 流水线, 上下文, 数据并行四维组合, MFU 38% 到 43%.
4. **日程** (3.2.3): 峰值学习率 $8\times10^{-5}$, 8000 步 warmup, 余弦衰减; batch 从 4M token 逐步加到 16M; 末段退火, 最后扩展到 128K 上下文.
5. **运行** (3.2.4): 54 天里 466 次中断, 有效训练时间 90% 以上.

各步的数字和出处在对应文章里给出.
