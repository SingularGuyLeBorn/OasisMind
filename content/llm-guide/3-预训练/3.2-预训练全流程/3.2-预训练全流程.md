# 3.2 预训练全流程

数据备好之后，训练是一条系统链：定结构、选框架、定优化与精度、把 checkpoint 和监控铺上。分词器训练是链上的一步，但 **BPE 怎么合并、Unigram 怎么裁，写在 [3.3](../3.3-分词器与Tokenizer/3.3-分词器与Tokenizer.md)**，本节不推完 Tokenizer。Scaling Law 在 [3.2.6](./3.2.6-Scaling-Law/3.2.6-Scaling-Law.md)，继续预训练在 [3.2.7](./3.2.7-继续预训练/3.2.7-继续预训练.md)。

## 1. 分词器：本节只定接口

词表大小 $V$ 进 embedding 和 LM head；合并规则文件随模型发布。代表性语料上训 BPE 或 SentencePiece，再对多语言、代码、特殊符号做编解码回归。算法步骤、byte-level 与 Unigram 对比全部去 3.3。

## 2. 结构：Decoder-only 积木，公式在第 2 章

当前基座默认 Decoder-only：Pre-Norm（RMSNorm）、GQA、SwiGLU FFN、RoPE。MHA / GQA / RoPE 的矩阵式在

- [01-MHA](../../2-核心原理与架构/2.2-基础注意力机制/2.2.2-多头注意力变体/01-MHA-多头注意力的标准形式/01-MHA-多头注意力的标准形式.md)
- [03-GQA](../../2-核心原理与架构/2.2-基础注意力机制/2.2.2-多头注意力变体/03-GQA-在性能与缓存之间折中/03-GQA-在性能与缓存之间折中.md)
- [RoPE](../../2-核心原理与架构/2.1-深度学习基础组件/2.1.4-位置编码/01-RoPE本体-旋转位置编码/01-RoPE本体-旋转位置编码.md)

3.2.2 只讨论 $n_{\mathrm{layers}}$、$d_{\mathrm{model}}$、KV 头数怎么随规模变。

## 3. 框架与并行

单卡装不下 70B 的参数 + 梯度 + Adam 状态。3D 并行把矩阵切在节点内（TP）、层切到不同机（PP）、不同 batch 做数据并行（DP）。ZeRO 再把优化器状态（以及更激进的梯度/参数）分片。细节与文档数字在 3.2.3；序列并行、Megatron-SP 的 MFU 表在 [6.1.1](../../6-训练与推理优化/6.1-训练基础设施/6.1.1-分布式训练/6.1.1-分布式训练.md)。

## 4. 策略与容灾

优化器几乎都是 AdamW；学习率要么余弦衰减（Llama 3 405B 报告），要么 WSD 平台期（MiniCPM）。精度默认 BF16。步间必须能从最近合法 snapshot 拉起来——同步训练里一张 GPU 挂了整作业停。数字用 3.2.4 / 3.2.5 的报告，不在首页画假 Loss 曲线。

## 5. 和 3.2.6、3.2.7 的边界

给定 FLOPs，先问 $N$ 与 $D$ 配多少：3.2.6。已经有通用基座、只想灌医学或法律：3.2.7，不是把 3.2 整条链再跑一遍。
