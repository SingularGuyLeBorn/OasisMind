## 1. 预算, 参数与 FLOPs

### 1.1 预算如何变成一张配置表

预训练开始前要交出一张配置表. 它受三类约束:

1. **算力**. 给定总 FLOPs $C$, Scaling Laws 给出参数量 $N$ 与 token 数 $D$ 的分配 (见 [3.3.2](../3.3.2-Scaling-Laws/3.3.2-Scaling-Laws.md)). 这一步只给出一个标量 $N$, 不告诉你层数和宽度.
2. **训练系统**. 层数要能被流水线段数整除, 头数和 FFN 维要能被张量并行度整除, 单卡显存要放得下一段的参数, 优化器状态和激活 (见 [3.4.1](../../3.4-训练过程/3.4.1-训练框架选择/3.4.1-训练框架选择.md)).
3. **推理成本**. KV cache 大小由 $n_{\mathrm{layer}}$, $n_{kv}$, $d_h$ 决定, 解码速度受激活参数量和访存量限制.

第 1 类约束在 3.2.5 讨论. 本文处理的是把标量 $N$ 展开成一组形状参数, 并核算每个选择对参数量, FLOPs 和 KV cache 的影响. 公开配置取三家: Llama 3 (稠密, GQA), DeepSeek-V3 (MoE, MLA), Qwen3 (稠密与 MoE 两条线).

当前基座的块结构基本一致: Pre-Norm (RMSNorm), 注意力 (GQA 或 MLA, 带 RoPE), SwiGLU FFN 或 MoE FFN, 残差相加.

![](./images/fig-decoder-block-choice.png)

> 图 1: Decoder-only 块. 两次 RMSNorm 分别在注意力和 FFN 之前, 两条残差绕过各自的子层.

**图 1 解析**

- **自下而上**: 输入向量先过 RMSNorm, 再进 GQA (内部对 Q, K 施加 RoPE), 输出加回残差; 然后过第二个 RMSNorm, 进 SwiGLU FFN, 输出再加回残差.
- **可调形状**: 这张图里能调的只有注意力的头数 ($n_h$, $n_{kv}$, $d_h$) 和 FFN 的中间维 $d_{\mathrm{ff}}$; 块的堆叠次数是 $n_{\mathrm{layer}}$; 块内所有向量的宽度是 $d_{\mathrm{model}}$.
- **不在图里的部分**: 输入嵌入矩阵 $V\times d_{\mathrm{model}}$, 末层 RMSNorm, 输出头 $d_{\mathrm{model}}\times V$. 这三项不随层数增长, 第 1.4 节单独核算.

### 1.2 参数与 FLOPs 的计数: Kaplan Table 1

Kaplan 等人 (2020) 用 $n_{\mathrm{layer}}$ (层数), $d_{\mathrm{model}}$ (残差流维度), $d_{\mathrm{ff}}$ (FFN 中间维), $d_{\mathrm{attn}}$ (注意力输出维), $n_{\mathrm{heads}}$ 描述一个 Transformer, 逐项列出参数量和每 token 前向 FLOPs (Table 1, 忽略非线性, 偏置和 LayerNorm):

| 运算 | 参数量 | 每 token 前向 FLOPs |
|------|--------|-------------------|
| 嵌入 | $(n_{\mathrm{vocab}}+n_{\mathrm{ctx}})d_{\mathrm{model}}$ | $4d_{\mathrm{model}}$ |
| 注意力 QKV | $n_{\mathrm{layer}}d_{\mathrm{model}}3d_{\mathrm{attn}}$ | $2n_{\mathrm{layer}}d_{\mathrm{model}}3d_{\mathrm{attn}}$ |
| 注意力 mask | 无 | $2n_{\mathrm{layer}}n_{\mathrm{ctx}}d_{\mathrm{attn}}$ |
| 注意力输出投影 | $n_{\mathrm{layer}}d_{\mathrm{attn}}d_{\mathrm{model}}$ | $2n_{\mathrm{layer}}d_{\mathrm{attn}}d_{\mathrm{embd}}$ |
| FFN | $n_{\mathrm{layer}}2d_{\mathrm{model}}d_{\mathrm{ff}}$ | $2n_{\mathrm{layer}}2d_{\mathrm{model}}d_{\mathrm{ff}}$ |
| 反嵌入 | 无 | $2d_{\mathrm{model}}n_{\mathrm{vocab}}$ |
| 合计 (非嵌入) | $N=2d_{\mathrm{model}}n_{\mathrm{layer}}(2d_{\mathrm{attn}}+d_{\mathrm{ff}})$ | $C_{\mathrm{forward}}=2N+2n_{\mathrm{layer}}n_{\mathrm{ctx}}d_{\mathrm{attn}}$ |

每个矩阵乘的 FLOPs 是参数量的 2 倍 (一次乘一次加), 所以除注意力打分那一行外, 前向 FLOPs 都等于 2 倍参数. 注意力打分 $QK^\top$ 与加权 $AV$ 没有参数, 计算量随上下文线性增长, 单列为 mask 一行.

取 $d_{\mathrm{attn}}=d_{\mathrm{ff}}/4=d_{\mathrm{model}}$ (Kaplan 式 2.1):

$$
N=2d_{\mathrm{model}}n_{\mathrm{layer}}(2d_{\mathrm{model}}+4d_{\mathrm{model}})=12\,n_{\mathrm{layer}}d_{\mathrm{model}}^2 \tag{1}
$$

反向传播约为前向的 2 倍 (对激活和对权重各求一次梯度), 因此训练每 token 的 FLOPs:

$$
C_{\mathrm{token}}\approx 3C_{\mathrm{forward}}=6N+6n_{\mathrm{layer}}n_{\mathrm{ctx}}d_{\mathrm{attn}} \tag{2}
$$

Kaplan 指出 $d_{\mathrm{model}}>n_{\mathrm{ctx}}/12$ 时上下文项相对很小, 于是略去它, 得到训练总量:

$$
C\approx 6ND \tag{3}
$$

$D$ 是训练 token 数. 系数 6 可以从单个线性层推出来. 设 $Y=XW$, $X\in\mathbb{R}^{m\times k}$ 是 $m$ 个 token 的输入, $W\in\mathbb{R}^{k\times n}$. 前向 $XW$ 需要 $2mkn$ FLOPs, 每 token 每参数 2 次. 反向要算两个矩阵乘: 对输入的梯度 $\partial L/\partial X=(\partial L/\partial Y)W^\top$ 传给上一层, 对权重的梯度 $\partial L/\partial W=X^\top(\partial L/\partial Y)$ 交给优化器, 各 $2mkn$. 合计每 token 每参数 6 次. 如果为省显存做激活重计算, 反向前要把前向再算一遍, 每 token 变成约 $8N$; Megatron-LM 估算训练时间时用的就是 8 倍 (见 [3.4.1](../../3.4-训练过程/3.4.1-训练框架选择/3.4.1-训练框架选择.md) 第 5 节). 优化器更新每参数只有常数次运算, 与 token 数无关, 不进入式 (3).

式 (3) 是后面所有预算估算的起点. Kaplan 的 $N$ 不含嵌入参数; Hoffmann 等人 (2022, Chinchilla) 附录 F 改为计入全部 FLOPs (含嵌入), 两篇的 $N$ 口径不同, 3.2.5 会再遇到这个差别.

### 1.3 改到 SwiGLU 和 GQA

现代块与 Kaplan 的设定有两处不同.

**FFN 有三个矩阵**. SwiGLU 的 FFN 是 $W_2\bigl(\mathrm{SiLU}(W_1x)\odot W_3x\bigr)$, $W_1, W_3\in\mathbb{R}^{d_{\mathrm{ff}}\times d_{\mathrm{model}}}$, $W_2\in\mathbb{R}^{d_{\mathrm{model}}\times d_{\mathrm{ff}}}$, 参数 $3d_{\mathrm{model}}d_{\mathrm{ff}}$. 两矩阵 FFN 取 $d_{\mathrm{ff}}=4d_{\mathrm{model}}$ 时参数为 $8d_{\mathrm{model}}^2$; 要让 SwiGLU 参数相同:

$$
3d_{\mathrm{model}}d_{\mathrm{ff}}=8d_{\mathrm{model}}^2\ \Rightarrow\ d_{\mathrm{ff}}=\tfrac{8}{3}d_{\mathrm{model}} \tag{4}
$$

DeepSeek LLM (2024) 明确采用 $d_{\mathrm{ff}}=\frac{8}{3}d_{\mathrm{model}}$. Llama 3 偏大: 8B 和 70B 的 $d_{\mathrm{ff}}/d_{\mathrm{model}}=14336/4096=28672/8192=3.5$, 405B 为 $53248/16384=3.25$. Qwen3-32B 是 $25600/5120=5.0$.

**K, V 只有 $n_{kv}$ 个头**. GQA 下 Q 投影是 $d_{\mathrm{model}}\times n_hd_h$, K 和 V 各是 $d_{\mathrm{model}}\times n_{kv}d_h$, 输出投影 $n_hd_h\times d_{\mathrm{model}}$. 每层注意力参数:

$$
P_{\mathrm{attn}}=2d_{\mathrm{model}}n_hd_h+2d_{\mathrm{model}}n_{kv}d_h \tag{5}
$$

每层总参数 $P_{\mathrm{layer}}=P_{\mathrm{attn}}+3d_{\mathrm{model}}d_{\mathrm{ff}}$ (RMSNorm 的增益向量每层 $2d_{\mathrm{model}}$, 量级可忽略).

### 1.4 用 Llama 3 核算

Llama 3 (Grattafiori 等人 2024) Table 3 给出三个尺寸的配置, 词表都是 128,000 (tiktoken 的 100K 加 28K 非英语 token), RoPE 基频 $\theta=500{,}000$, 激活函数 SwiGLU:

| | 8B | 70B | 405B |
|---|---|---|---|
| $n_{\mathrm{layer}}$ | 32 | 80 | 126 |
| $d_{\mathrm{model}}$ | 4096 | 8192 | 16384 |
| $d_{\mathrm{ff}}$ | 14336 | 28672 | 53248 |
| $n_h$ | 32 | 64 | 128 |
| $n_{kv}$ | 8 | 8 | 8 |
| 峰值学习率 | $3\times10^{-4}$ | $1.5\times10^{-4}$ | $8\times10^{-5}$ |

三者 $d_h=d_{\mathrm{model}}/n_h=128$. 代入式 (5) 与 FFN 项, 输入嵌入和输出头不共享 (各 $Vd_{\mathrm{model}}$):

| | 每层注意力 | 每层 FFN | 层内合计 $\times n_{\mathrm{layer}}$ | 嵌入 + 输出头 | 总计 | 嵌入占比 |
|---|---|---|---|---|---|---|
| 8B | 41.94M | 176.16M | 6.979B | 1.049B | 8.028B | 13.1% |
| 70B | 150.99M | 704.64M | 68.451B | 2.097B | 70.548B | 3.0% |
| 405B | 570.43M | 2617.25M | 401.647B | 4.194B | 405.841B | 1.0% |

几点读法:

- **FFN 占层内参数的大头**. 8B 每层 FFN 是注意力的 4.2 倍. GQA 让 K, V 投影只有 Q 的 $n_{kv}/n_h$ (8B 为 1/4, 405B 为 1/16), 注意力参数进一步缩小, FFN 的占比随之升高.
- **式 (1) 的近似误差**. $12n_{\mathrm{layer}}d_{\mathrm{model}}^2$ 对 8B 给出 6.44B, 比逐项结果的层内 6.98B 少 8%; 对 405B 给出 405.87B, 与逐项结果的层内 401.65B 差 1%. 偏差来自 $d_{\mathrm{ff}}$ 偏离 $\frac{8}{3}d_{\mathrm{model}}$ 和 GQA 少掉的 K, V 参数, 两者方向相反, 在不同尺寸上抵消程度不同.
- **嵌入占比随规模下降**. 嵌入参数正比于 $Vd_{\mathrm{model}}$, 层内参数正比于 $n_{\mathrm{layer}}d_{\mathrm{model}}^2$. 词表固定时小模型受嵌入影响大: 8B 有 13% 参数在嵌入和输出头上, 405B 只有 1%. Qwen3 Table 1 的 Tie Embedding 一列与这一趋势一致: 0.6B, 1.7B, 4B 共享输入输出嵌入, 8B 及以上不共享.

### 1.5 DeepSeek LLM 的 $M$: 把注意力项算回来

式 (3) 丢掉了注意力打分的 FLOPs. DeepSeek LLM (2024) 指出 $6N$ 形式在小规模下最多偏差 50%, 改用每 token 非嵌入 FLOPs $M$ 衡量模型规模:

$$
6N_1=72\,n_{\mathrm{layer}}d_{\mathrm{model}}^2,\qquad M=72\,n_{\mathrm{layer}}d_{\mathrm{model}}^2+12\,n_{\mathrm{layer}}d_{\mathrm{model}}\,l_{\mathrm{seq}} \tag{6}
$$

$l_{\mathrm{seq}}$ 是序列长度. 第二项是注意力打分与加权的计算, 不带参数, 随序列长度线性增长, 对应式 (2) 里被式 (3) 略去的上下文项. 两项之比:

$$
\frac{12\,n_{\mathrm{layer}}d_{\mathrm{model}}l_{\mathrm{seq}}}{72\,n_{\mathrm{layer}}d_{\mathrm{model}}^2}=\frac{l_{\mathrm{seq}}}{6d_{\mathrm{model}}} \tag{7}
$$

$d_{\mathrm{model}}=4096$, $l_{\mathrm{seq}}=4096$ 时比值为 $1/6$; 小模型 $d_{\mathrm{model}}=512$ 配 $l_{\mathrm{seq}}=4096$ 时比值为 $4/3$, 注意力 FLOPs 超过矩阵乘. Scaling Laws 实验通常从几千万参数做起, 这一项决定了小模型那端的拟合点落在哪里. DeepSeek LLM 用 $M$ 拟合出的最优分配是 $M_{\mathrm{opt}}=0.1715\,C^{0.5243}$, $D_{\mathrm{opt}}=5.8316\,C^{0.4757}$.

## 2. 形状: 宽度, 深度与注意力头

### 2.1 形状对 loss 不敏感

Kaplan 等人在固定非嵌入参数量下改变宽深比 $d_{\mathrm{model}}/n_{\mathrm{layer}}$, 发现宽深比在 40 倍范围内变动时 loss 变化很小; 例如 $(n_{\mathrm{layer}},d_{\mathrm{model}})=(6,4288)$ 与 $(48,1600)$ 的 loss 相差在 3% 以内. 他们的结论是 loss 主要由 $N$ 决定, 形状是次要变量. 实验设置: 上下文 1024, WebText2 数据, 词表 50257, Adam 训练 $2.5\times10^5$ 步, batch 为 512 条 1024 token 序列, 3000 步 warmup 后余弦衰减到 0, 超过 1B 参数时换 Adafactor.

这条结论的适用范围是 Kaplan 实验覆盖的规模 (非嵌入参数从 768 到 1.5B). 大模型实践里的形状由下面两个因素决定.

### 2.2 公开配置的宽深比

| 模型 | $n_{\mathrm{layer}}$ | $d_{\mathrm{model}}$ | $d_{\mathrm{model}}/n_{\mathrm{layer}}$ |
|------|----|------|------|
| Llama 3 8B | 32 | 4096 | 128 |
| Llama 3 70B | 80 | 8192 | 102.4 |
| Llama 3 405B | 126 | 16384 | 130.0 |
| DeepSeek LLM 7B | 30 | 4096 | 136.5 |
| DeepSeek LLM 67B | 95 | 8192 | 86.2 |
| DeepSeek-V3 | 61 | 7168 | 117.5 |
| Qwen3-32B | 64 | 5120 | 80 |
| Qwen3-235B-A22B | 94 | 4096 | 43.6 |
| PaLM 540B | 118 | 18432 | 156.2 |

稠密模型集中在 80 到 156. Qwen3-235B-A22B 只有 43.6, 但它的注意力宽度 $n_hd_h=64\times128=8192$ 是 $d_{\mathrm{model}}$ 的 2 倍, 专家 FFN 的总宽度也远大于 $d_{\mathrm{model}}$, 残差流窄不代表每层计算窄. 这种配置下 Kaplan 的 $d_{\mathrm{attn}}=d_{\mathrm{model}}$ 假设不成立, 式 (1) 不能直接套用.

表里的层数还要服从流水线切分. DeepSeek LLM 在 67B 上选择加深而不加宽 FFN (95 层), 并说明层数的取值考虑了流水线切分. Llama 3 的 126 层也来自流水线: 405B 用 16 段流水线, 报告说明为平衡首段 (含嵌入) 和末段 (含输出头和 loss) 的负载, 从首末两段各去掉一层. 若每段 8 层, $16\times8-2=126$. 层数在 Scaling Laws 意义上可以有很大自由度, 最终取值由并行配置决定.

### 2.3 从参数量反推宽度, 以及深度的代价

固定宽深比 $r=d_{\mathrm{model}}/n_{\mathrm{layer}}$, 代入式 (1) 得 $N=12n_{\mathrm{layer}}d_{\mathrm{model}}^2=12d_{\mathrm{model}}^3/r$, 解出 $d_{\mathrm{model}}=(rN/12)^{1/3}$. 宽度只随参数量的立方根增长: 参数翻 8 倍, 宽度翻 2 倍, 层数也翻 2 倍.

代入几组值: $N=8$B 时 $r=100$ 给出 4055, $r=128$ 给出 4403; $N=405$B 时 $r=100$ 给出 15000, $r=128$ 给出 16287. Llama 3 的实际取值 4096 和 16384 都在 $r$ 取 100 到 128 的区间内, 并取到 $d_h=128$ 和张量并行度 8 的公倍数. 这个公式只给出量级, 最后的取值要回到式 (5) 逐项核算, 因为 $d_{\mathrm{ff}}$ 和 $n_{kv}$ 的选择会让实际参数量偏离 $12n_{\mathrm{layer}}d_{\mathrm{model}}^2$.

$r$ 取多少还牵涉训练稳定性. Wortsman 等人 (2023) 用小模型代理大模型的训练不稳定性, 定义「学习率敏感度」: 学习率在三个数量级内变化时最终 loss 偏离最优值的期望. 他们发现加深模型时敏感度上升得比加宽更快. 对于 Kaplan 意义下 loss 相近的两种形状, 更深的那种需要更仔细地调学习率和 warmup. 这是在宽深比无关 loss 的结论之外, 偏向适度宽度的一条理由. 同一组实验里, 在他们测试的最大规模上, 只加深得到的验证 loss 比只加宽更低; 宽度和深度一起放大在最大规模上 loss 最好, 外推出的 scaling 曲线也最可靠.

### 2.4 注意力的头维与头数

上表各模型的头维 $d_h=d_{\mathrm{model}}/n_h$ (或 HF 配置的 `head_dim`):

- Llama 3 三个尺寸, DeepSeek LLM, Qwen3 稠密与 MoE: 128.
- DeepSeek-V3 MLA: 每头 $d_h=128$, 另有解耦 RoPE 维 $d_h^R=64$.
- PaLM 540B: 48 头, 头维 256, $d_{\mathrm{model}}=18432$.

头维固定时, 头数随 $d_{\mathrm{model}}$ 线性增长 (Llama 3 从 32 到 128). 张量并行要求 $n_h$ 能被并行度 $t$ 整除, Llama 3 用 $t=8$, 三个尺寸的 $n_h$ 都是 8 的倍数.

### 2.5 KV 头数与 KV cache

推理时每 token 要缓存每层的 K 和 V. BF16 下每 token 字节数:

$$
S_{\mathrm{KV}}=2\times n_{\mathrm{layer}}\times n_{kv}\times d_h\times 2\ \text{bytes} \tag{8}
$$

第一个 2 是 K 和 V, 最后的 2 是 BF16 字节数. 代入公开配置:

| 模型 | $n_{\mathrm{layer}}$ | $n_{kv}$ | 每 token | 128K token |
|------|----|----|------|------|
| Llama 3 8B | 32 | 8 | 128 KiB | 16.0 GiB |
| Llama 3 70B | 80 | 8 | 320 KiB | 40.0 GiB |
| Llama 3 405B | 126 | 8 | 504 KiB | 63.0 GiB |
| Qwen3-32B | 64 | 8 | 256 KiB | 32.0 GiB |
| Qwen3-235B-A22B | 94 | 4 | 188 KiB | 23.5 GiB |

Llama 3 70B 若改为 64 头 MHA ($n_{kv}=n_h$), 每 token 是 $320\times8=2560$ KiB = 2.5 MiB, 128K 上下文需要 320 GiB. GQA 把这一项压到 1/8, 参数量只少了 K, V 投影.

DeepSeek-V3 用 MLA, 每层缓存一个 $d_c=512$ 维的压缩 KV 潜变量和一个 $d_h^R=64$ 维的解耦 RoPE key, 每 token 每层 576 个元素:

$$
S_{\mathrm{MLA}}=(d_c+d_h^R)\times n_{\mathrm{layer}}\times 2=576\times61\times2=70{,}272\ \text{bytes}\approx 68.6\ \text{KiB} \tag{9}
$$

128K 上下文约 8.6 GiB. MLA 的矩阵吸收和 RoPE 解耦见第 2 章 [MLA](../../../2-核心原理与架构/2.2-注意力机制/2.2.2-多头注意力变体/03-MLA-低秩潜变量与解耦RoPE/03-MLA-低秩潜变量与解耦RoPE.md).

### 2.6 KV 头数对训练系统的影响

KV 头数也改变训练时的并行设计. Llama 3 做上下文并行时没有用 ring attention, 而是先 all-gather 全部 K, V 再算本地 Q 块的注意力, 报告给出两条理由: all-gather 方式更容易支持文档 mask 等不同的注意力 mask; GQA 下 K, V 张量比 Q 小得多, 暴露在关键路径上的 all-gather 延迟很小, 注意力计算是 $O(S^2)$, all-gather 是 $O(S)$. Llama 3 的 $n_{kv}=8$ 与张量并行度 $t=8$ 相等, 每个张量并行 rank 恰好持有一个 KV 头; $n_{kv}<t$ 时 KV 头要在多个 rank 上复制.

Qwen3 还做了两处与头相关的改动: 注意力加 QK-Norm, 去掉 QKV 偏置. QK-Norm 对应 Wortsman 等人复现的「注意力 logit 增长」不稳定性, 他们在小模型高学习率下复现了这一现象, qk-layernorm 能让训练在三个数量级的学习率范围内保持稳定.

## 3. 词表与训练上下文长度

### 3.1 词表

词表大小 $V$ 同时进入三处:

1. **参数**: 输入嵌入和输出头各 $Vd_{\mathrm{model}}$, 见 1.4 节的占比.
2. **FLOPs**: 输出头每 token 前向 $2d_{\mathrm{model}}V$ (Kaplan Table 1 的反嵌入一行); 它不计入 $N$, 但真实存在. 输入嵌入是查表, 几乎没有计算. 以层内参数为分母, Llama 3 8B 输出头的 FLOPs 是层内矩阵乘的 $2\times4096\times128000/(2\times6.979\text{B})=7.5\%$, 70B 是 1.5%, 405B 是 0.5%. 小模型用大词表时, 这一项和注意力项一起让 $6N$ 低估真实计算量.
3. **序列长度**: 压缩率越高, 同样文本的 token 越少, 等于同样的 token 预算覆盖更多文本, 同样的上下文窗口容纳更多内容.

公开配置:

| 模型 | 词表 |
|------|------|
| Llama 3 | 128,000 (100K tiktoken + 28K 非英语) |
| DeepSeek LLM | 102,400 |
| DeepSeek-V3 | 128K (byte-level BPE) |
| Qwen3 | 151,669 (HF 配置的嵌入行数为 151,936) |

Llama 3 报告给出新词表对英语数据的压缩率从每 token 3.17 字符提升到 3.94 字符. 按这个比值, 同样的英语文本 token 数减少约 $1-3.17/3.94=19.5\%$. 训练 token 预算 $D$ 是按 token 计的, 词表改变后 $D$ 对应的文本量也随之改变, 跨模型比较 token 数时要考虑这一点. 嵌入行数常向上取整到便于切分的倍数, 所以 HF 配置的 `vocab_size` 可能大于分词器实际的词表 (Qwen3 即是一例). 分词器怎么训练见 [3.2](../../3.2-分词器与Tokenizer/3.2-分词器与Tokenizer.md).

### 3.2 上下文长度与注意力 FLOPs 的占比

由式 (2), 注意力项与 $2N$ (前向矩阵乘) 之比为:

$$
r_{\mathrm{attn}}=\frac{2n_{\mathrm{layer}}n_{\mathrm{ctx}}d_{\mathrm{attn}}}{2N}=\frac{n_{\mathrm{layer}}n_{\mathrm{ctx}}d_{\mathrm{attn}}}{N} \tag{10}
$$

代入 Llama 3 ($d_{\mathrm{attn}}=d_{\mathrm{model}}$):

| 模型 | $n_{\mathrm{ctx}}=8192$ | $n_{\mathrm{ctx}}=131072$ |
|------|------|------|
| 8B | 13.4% | 214.7% |
| 405B | 4.2% | 66.8% |

8K 上下文时 405B 的注意力项只有 4.2%, $6N$ 近似足够; 128K 时注意力项是矩阵乘的三分之二, 8B 则超过矩阵乘的 2 倍. 式 (10) 按完整矩阵计, 因果 mask 只需下三角时实际约减半, 但量级结论不变. PaLM 附录 B 计算 MFU 时用的每 token FLOPs 是 $6N+12LHQT$ ($L$ 层数, $H$ 头数, $Q$ 头维, $T$ 序列长度), 与式 (2) 是同一项的另一种写法 (见 [3.4.1](../../3.4-训练过程/3.4.1-训练框架选择/3.4.1-训练框架选择.md) 第 5 节).

### 3.3 上下文长度分阶段的做法

注意力 FLOPs 随 $n_{\mathrm{ctx}}$ 线性增长, 激活显存的注意力部分随 $n_{\mathrm{ctx}}^2$ 增长 (未使用 FlashAttention 类实现时), 三家都把长上下文放到训练末段:

- **Llama 3**: 预训练序列长度 4096, 训练到 252M token 后升到 8192; 末段分 6 个阶段从 8K 扩到 128K, 共约 800B token. 每一阶段的判断标准是短上下文评测完全恢复, 且大海捞针在该长度上全部正确.
- **DeepSeek-V3**: 预训练序列长度 4K, 之后用 YaRN 分两段扩到 32K 和 128K, 每段 1000 步.
- **Qwen3**: S1 与 S2 阶段序列长度 4096; 长上下文阶段在 32768 上训练数千亿 token, 同时用 ABF 把 RoPE 基频从 10,000 提到 1,000,000, 推理时再用 YaRN 和 DCA 扩到 4 倍.

结构层面要提前确定的是 RoPE 基频 (Llama 3 一开始就用 500,000) 和是否使用文档 mask. Llama 3 的文档 mask 禁止同一序列内不同文档互相注意, 报告说明它在标准预训练中影响有限, 对长序列继续预训练很重要. 长上下文训练的数据与外推方法见 [3.5.2](../../3.5-继续预训练与长上下文训练/3.5.2-长上下文训练与数据/3.5.2-长上下文训练与数据.md).

## 4. MoE: 总参数与激活参数

### 4.1 两个参数量各管什么

MoE 层把一个 FFN 换成 $E$ 个专家和一个路由器, 每 token 只激活 $k$ 个. 于是有两个参数量:

- **总参数 $N_{\mathrm{total}}$**: 决定权重和优化器状态的显存, 决定 checkpoint 大小.
- **激活参数 $N_{\mathrm{act}}$**: 决定每 token 的 FLOPs. 训练计算量近似为 $6N_{\mathrm{act}}D$.

### 4.2 核算 Qwen3-235B-A22B

Qwen3 Table 2 给出 235B-A22B 为 94 层, 64 个 query 头和 4 个 KV 头, 128 个专家激活 8 个, 不设共享专家. HF 配置补充: `hidden_size` 4096, `head_dim` 128, `moe_intermediate_size` 1536, 词表 151936, 嵌入不共享. 逐项:

$$
P_{\mathrm{expert}}=3\times4096\times1536=18.87\text{M},\qquad P_{\mathrm{attn}}=2\times4096\times8192+2\times4096\times512=71.30\text{M} \tag{11}
$$

- 专家: $128\times18.87\text{M}\times94=227.1$B, 激活 $8\times18.87\text{M}\times94=14.19$B.
- 注意力: $71.30\text{M}\times94=6.70$B.
- 嵌入加输出头: $2\times151936\times4096=1.245$B.

合计总参 235.0B, 激活 22.1B, 与 235B-A22B 的命名一致 (路由器每层 $4096\times128$ 参数, 可忽略). 总参中 96.6% 在专家上, 激活参数里专家占 64%, 注意力占 30%.

### 4.3 DeepSeek-V3 的配置

DeepSeek-V3 (2024) 61 层, 隐藏维 7168. 前 3 层用稠密 FFN, 其余 58 层是 MoE: 1 个共享专家加 256 个路由专家, 专家中间维 2048, 每 token 激活 8 个路由专家, 每 token 最多路由到 4 个节点. 总参 671B, 激活 37B.

路由专家每层 $256\times3\times7168\times2048=11.27$B, 58 层合计 653.9B, 占总参的 97%. 每 token 激活的专家参数 (8 路由加 1 共享) 每层 396.4M, 58 层 23.0B, 剩下约 14B 激活参数来自注意力, 前 3 层稠密 FFN 和嵌入.

训练计算量:

$$
6N_{\mathrm{act}}D=6\times37\times10^9\times14.8\times10^{12}=3.29\times10^{24} \tag{12}
$$

Llama 3 405B 为 $6\times405\times10^9\times15.6\times10^{12}=3.79\times10^{25}$, 与其报告的 $3.8\times10^{25}$ 一致. 两者的训练 FLOPs 相差 11.5 倍, 而 DeepSeek-V3 的总参数是 405B 的 1.66 倍. 这里也能看出 MoE 的系统代价: 显存按 671B 准备, 计算按 37B 计费, 专家必须分布到多机上, 引入专家并行和 all-to-all 通信 (DeepSeek-V3 用 64 路专家并行, 见 [3.4.1](../../3.4-训练过程/3.4.1-训练框架选择/3.4.1-训练框架选择.md) 第 4.5 节).

专家中间维取这么小, 对应的是专家粒度的选择. Krajewski 等人 (2024) 定义粒度 $G=d_{\mathrm{ff}}/d_{\mathrm{expert}}$, 即一个稠密 FFN 的中间维是单个专家中间维的多少倍. 他们的拟合显示专家与 FFN 同尺寸 ($G=1$) 几乎在任何预算下都不是最优, 最优 $G$ 随预算增大. DeepSeek-V3 的专家中间维 2048, 只有隐藏维 7168 的 0.29 倍; Qwen3-235B 的 1536 是隐藏维 4096 的 0.375 倍, 稠密 Qwen3 的 FFN 中间维是隐藏维的 5 倍 (32B). 两家的专家都是细粒度的. MoE 的 Scaling Laws 见 [3.3.2](../3.3.2-Scaling-Laws/3.3.2-Scaling-Laws.md) 第 5 节, 路由与负载均衡见 [2.6](../../../2-核心原理与架构/2.6-MoE/2.6-MoE.md).

## 5. 超参数, 完整示例与边界

### 5.1 与形状绑定的超参数

形状一变, 有几项超参数要跟着变. 它们在配置表里和结构参数放在一起, 训练日程的其余部分见 [3.4.2](../../3.4-训练过程/3.4.2-预训练策略/3.4.2-预训练策略.md).

第一项是峰值学习率, 公开配置里它随规模下降:

| 模型 | 峰值学习率 |
|------|------|
| Llama 3 8B / 70B / 405B | $3\times10^{-4}$ / $1.5\times10^{-4}$ / $8\times10^{-5}$ |
| DeepSeek LLM 7B / 67B | $4.2\times10^{-4}$ / $3.2\times10^{-4}$ |
| DeepSeek-V3 (671B, 激活 37B) | $2.2\times10^{-4}$ |

Llama 3 的宽度每翻一倍, 峰值学习率约减半. DeepSeek LLM 把最优学习率和 batch 写成计算预算的幂律: $\eta_{\mathrm{opt}}=0.3118\,C^{-0.1250}$, $B_{\mathrm{opt}}=0.2920\,C^{0.3271}$ ($B$ 以 token 计). 代入 $C=10^{24}$ 得 $\eta_{\mathrm{opt}}\approx3.1\times10^{-4}$, $B_{\mathrm{opt}}\approx2.1\times10^7$ token; 代入 $C=10^{22}$ 得 $5.5\times10^{-4}$ 和 $4.6\times10^6$. 预算增大 100 倍, 学习率只降到 0.56 倍, batch 增大 4.5 倍. Qwen3 报告也说明用 Scaling Laws 为每个模型预测了学习率和 batch, 但没有给出系数.

第二项是初始化与参数化. DeepSeek LLM 和 DeepSeek-V3 的权重初始化标准差都是 0.006, 不随宽度变化. MiniCPM (Hu 等人 2024) 采用 Tensor Program (μP) 参数化, 在小模型上调好的学习率 (约 0.01) 可以直接迁移到更宽的模型, 省去在每个宽度上重新扫学习率. 两种做法对应两种定超参的流程: 前者在目标规模附近用 Scaling Laws 外推学习率, 后者依赖参数化保证最优学习率与宽度无关. Wortsman 等人在带 qk-layernorm 的小模型上测了 μP: 最优学习率确实不再随宽度漂移, 但最终 loss 没有改善, 学习率敏感度也没有降低. μP 解决的是「最优点在哪」, 不改变最优点附近曲线的陡峭程度.

第三项是优化器常数. Wortsman 等人观察到梯度范数随模型规模和学习率增大而下降, AdamW 默认的 $\epsilon$ 相对于梯度二阶矩的平方根变得过大, 使更新幅度偏小. 在他们测试的最大规模和最大学习率上, 梯度均方根已经接近默认值 $\epsilon=10^{-8}$; 4.8B 模型在学习率 0.3 下把 $\epsilon$ 降到 $10^{-15}$ 后 loss 更低, 升到 $10^{-6}$ 则训练失稳. 他们还发现学习率与 weight decay 独立缩放 (Loshchilov 与 Hutter 2019 的建议) 能降低学习率敏感度. 宽度大幅增加时, $\epsilon$ 和 weight decay 的写法要和学习率一起检查.

最后, MoE 配置里还要定负载均衡的强度. DeepSeek-V3 用无辅助损失的偏置调整, 偏置更新速度 $\gamma=0.001$ (前 14.3T token, 之后为 0), 另加系数 $\alpha=0.0001$ 的序列级均衡损失. Qwen3 MoE 用全局 batch 的负载均衡损失, HF 配置中的 `router_aux_loss_coef` 为 0.001. 这些系数和专家数, 激活数一起决定专家并行时各卡的负载是否均匀.

### 5.2 一个完整的定配置过程: Llama 3 405B

把前面的计算串起来, Llama 3 报告给出了从预算到配置的全过程.

1. **预算**: 旗舰模型的训练预算 $3.8\times10^{25}$ FLOPs.
2. **Scaling Laws 实验**: 在 $6\times10^{18}$ 到 $10^{22}$ FLOPs 之间, 训练 40M 到 16B 参数的模型, 拟合最优训练 token 数 $N^\star(C)=AC^\alpha$, $(\alpha,A)=(0.53,0.29)$. 外推到 $3.8\times10^{25}$, 建议 402B 参数, 16.55T token.
3. **取整**: IsoFLOP 曲线在大预算下最小值附近变平, 模型大小和 token 数的小幅偏移对最终 loss 影响很小. 最终选 405B, 训练 15.6T token, 每参数 38.5 个 token.
4. **形状**: 126 层, $d_{\mathrm{model}}=16384$, $d_{\mathrm{ff}}=53248$, 128 个 query 头, 8 个 KV 头, 词表 128K. 层数由 16 段流水线减去首末各一层得到.
5. **验证**: 参数量逐项相加 405.84B (1.4 节), 与命名一致; 计算量 $6ND=3.79\times10^{25}$, 与预算一致.

第 2 步的 $(\alpha,A)$ 只给到两位有效数字, 直接代入 $0.29\times(3.8\times10^{25})^{0.53}$ 得到约 10.5T, 与报告的 16.55T 不符. 原因是指数 $\alpha$ 的舍入: $C$ 在 $10^{25}$ 量级, $\alpha$ 变动 0.01 会让 $C^\alpha$ 变化 $10^{25.58\times0.01}\approx1.8$ 倍. 外推结果对拟合参数的精度很敏感, 引用别人的拟合时要用原文的预测值, 不要用舍入后的常数重算.

### 5.3 边界

前面的计数公式在四处容易用错:

- **$6N$ 忽略注意力**. 上下文长或模型小时偏差显著, 见式 (7) 与式 (10). 比较不同上下文长度的训练成本时要用式 (2) 或 DeepSeek LLM 的 $M$.
- **$d_{\mathrm{attn}}\ne d_{\mathrm{model}}$**. Qwen3-235B 的注意力宽度是隐藏维的 2 倍, 式 (1) 的 12 系数不再成立, 要回到式 (5) 逐项算.
- **MoE 的 $N$**. 计算量用 $N_{\mathrm{act}}$, 显存用 $N_{\mathrm{total}}$. 对 MoE 套 $C=6N_{\mathrm{total}}D$ 会高估约 18 倍 (671/37).
- **嵌入是否计入**. Kaplan 不计, Chinchilla 计入. 小模型上两种口径差 10% 以上 (Llama 3 8B 为 13.1%), 用别人的 Scaling Laws 系数前要先对齐口径.

形状结论也有范围. Kaplan 的宽深比结论来自 1.5B 以下的模型和固定的训练设置. 大模型的形状由流水线整除, 张量并行整除, KV cache 和稳定性共同决定, 这些约束都不在 loss 拟合里. Wortsman 等人发现深度对学习率敏感度的影响大于宽度, 也说明「loss 相同」不等于「训练难度相同」.

还有一类约束来自推理侧. $n_{kv}$, $d_h$ 和注意力类型几乎不影响训练 loss (在 GQA 与 MHA 之间), 但决定 KV cache. 部署场景要求长上下文时, 这几个数应当先于宽深比确定. MoE 的激活参数决定解码 FLOPs, 总参数决定部署所需的显存和卡数, 两者的取舍在预训练前就要定下.

读不同论文时, 同一个字母常指不同的量. 下表把本文用到的几个放在一起, 最容易错的是 Llama 3 的 $N^\star(C)$: 它是 token 数, 与 Kaplan 和 Chinchilla 的参数量 $N$ 同名.

| 记号 | 出处 | 含义 |
|------|------|------|
| $N$ | Kaplan 2020 | 非嵌入参数量, 式 (1) |
| $N$ | Chinchilla 2022 | 全部参数, FLOPs 计入嵌入 |
| $M$ | DeepSeek LLM 2024 | 每 token 非嵌入 FLOPs, 含注意力项, 式 (6) |
| $N^\star(C)$ | Llama 3 2024 | 最优**训练 token 数**, 不是参数量 |
| $N_{\mathrm{act}}$ | MoE 文献 | 每 token 激活的参数 |
| $d_{\mathrm{attn}}$ | Kaplan 2020 | 注意力输出维 $n_hd_h$, 不一定等于 $d_{\mathrm{model}}$ |
| $G$ | Krajewski 2024 | 粒度 $d_{\mathrm{ff}}/d_{\mathrm{expert}}$, 与 GQA 的组数无关 |
