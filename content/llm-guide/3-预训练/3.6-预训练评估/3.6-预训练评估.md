# 3.6 预训练评估

训练 loss 每一步都有, 但它在训练分布上算, 说明不了模型会不会做题; 下游基准能说明会不会做题, 但在小模型和早期 checkpoint 上常停在随机水平, 而且分数随提示格式, 打分方式和实现变化. 预训练评估要在两者之间选出合适的量, 并知道每个量的误差有多大. 本节四篇按评估对象划分: 语言建模本身 (3.4.1), 知识与短推理 (3.4.2), 长上下文 (3.4.3), 代码数学与多语言 (3.4.4).

后训练模型的对话质量, 偏好评测和最新排行榜不在本节, 见 [第 4 章 后训练](../../4-后训练/4-后训练.md).

> 图 1: 本节四篇对应的评估对象. 每个框回答一个不同的问题, 合起来不是一张排行榜.

**图 1 解析**

- **3.4.1 PPL / BPC**: 训练健康度. 固定协议下看 loss 是否还在下降, 跨 tokenizer 时换成每字节或每字符比特.
- **3.4.2 academic benches**: MMLU, GSM8K, HumanEval 等基准. 分数依赖提示格式, 打分方式和聚合方式.
- **3.4.3 NIAH then RULER**: 先用大海捞针确认能取回单句, 再用 RULER 区分声称长度和有效长度.
- **3.4.4 code and math**: 代码用单测和 pass@k, 数学用答案等价和多数投票; PRM 是检查每一步的奖励模型. 3.4.4 另外讲了图中没有画出的多语言评估.
- 箭头表示阅读顺序, 不表示评估的先后: 训练中这四类评估是同时跑的.

## 本节回答的问题

1. 困惑度和交叉熵是什么关系? 换了 tokenizer 后怎么比较两个模型, BPB 和 BPC 怎么换算?
2. 同一个模型在同一份语料上, 窗口, 步长, 文档切法会让 PPL 差多少? 语言模型当压缩器用, 把参数也算进码长会怎样?
3. PPL 降低何时对应下游变好? 「涌现」有多少来自度量的选择?
4. MMLU, HellaSwag, ARC, GSM8K, HumanEval, BBH 各自怎么构造, 怎么打分? pass@k 的无偏估计怎么推?
5. 完形填空式和多选字母式打分差多少, 为什么小模型在多选字母式下停在随机? 做数据消融时用什么基准?
6. 污染怎么检测, n-gram 检测为什么挡不住改写?
7. NIAH 为什么几乎所有模型都满分? RULER 的有效长度怎么定义, 和声称长度差多少? 相关信息放在中间为什么用得最差?
8. 代码题的单测不足会让 pass@k 虚高多少? 数学题答案怎么判等价, 答对但推理错的比例有多大? 多语言评测里翻译和文化偏差各带来什么问题?
