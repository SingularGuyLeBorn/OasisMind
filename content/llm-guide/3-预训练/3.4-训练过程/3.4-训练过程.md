# 3.4 预训练全流程

![](./images/fig-pretrain-workflow.png)

> 图 1: 预训练的五个环节: 数据, 模型结构, 训练框架, 训练策略, checkpoint 与监控.

**图 1 解析**

- **数据**: 采集, 清洗, 配比, 见 [3.1](../3.1-预训练数据/3.1-预训练数据.md). 分词器在数据之后, 结构之前确定, 见 [3.3](../3.2-分词器与Tokenizer/3.2-分词器与Tokenizer.md); 词表大小同时影响 embedding 参数和输出层的计算量, 在 [3.2.1](../3.3-模型配置与Scaling-Laws/3.3.1-确定模型结构与参数/3.3.1-确定模型结构与参数.md) 第 3.1 节核算.
- **模型结构**: 层数, 宽度, 注意力头, 词表, 上下文长度, 是否用 MoE. 见 [3.2.1](../3.3-模型配置与Scaling-Laws/3.3.1-确定模型结构与参数/3.3.1-确定模型结构与参数.md).
- **训练框架**: 显存估算, 数据并行与 ZeRO/FSDP, 张量, 流水线, 上下文, 专家并行的组合. 见 [3.2.2](./3.4.1-训练框架选择/3.4.1-训练框架选择.md).
- **训练策略**: 学习率日程, warmup, batch, 退火与数据切换, 长上下文阶段. 见 [3.2.3](./3.4.2-预训练策略/3.4.2-预训练策略.md).
- **checkpoint 与监控**: 故障统计, checkpoint 间隔, loss spike, 监控信号. 见 [3.2.4](./3.4.3-训练容灾与监控/3.4.3-训练容灾与监控.md).

图中五个环节是依次确定的, 但后面的环节会反过来约束前面: 流水线并行的段数影响层数的选择 (3.2.1 第 2 节); 故障率决定了 checkpoint 必须足够快, 这又影响框架选择 (3.2.4 第 3 节).

图外还有两篇. [3.2.5 Scaling Laws](../3.3-模型配置与Scaling-Laws/3.3.2-Scaling-Laws/3.3.2-Scaling-Laws.md) 讨论给定算力下模型多大, 训练多少 token: Kaplan 与 Chinchilla, 闭式最优解, Besiroglu 的重新拟合, 数据重复, 推理成本, MoE, 超参数规律, 降低实验成本. [3.2.6 继续预训练](../3.5-继续预训练与长上下文训练/3.5.1-继续预训练/3.5.1-继续预训练.md) 讨论在已有基座上学新领域时怎样少遗忘: 学习率重新升温, 回放比例, 数据配比与 epoch, 长上下文继续训练, Code Llama 和 Llemma 的结果.

**一个模型的决策顺序.** 以 Llama 3 405B 为例, 各篇的内容对应这样一串决策:

1. **算力与规模** (3.2.5): 在 $6\times10^{18}$ 到 $10^{22}$ FLOPs 之间做 IsoFLOP 实验, 外推到 $3.8\times10^{25}$ FLOPs, 得到约 402B 参数, 16.55T token; 最终用 405B 参数.
2. **形状** (3.2.1): 126 层, 宽度 16,384, 128 个查询头, 8 个 KV 头, 词表 128K.
3. **并行** (3.2.2): 最多 16K 张 H100, 张量, 流水线, 上下文, 数据并行四维组合, MFU 38% 到 43%.
4. **日程** (3.2.3): 峰值学习率 $8\times10^{-5}$, 8000 步 warmup, 余弦衰减; batch 从 4M token 逐步加到 16M; 末段退火, 最后扩展到 128K 上下文.
5. **运行** (3.2.4): 54 天里 466 次中断, 有效训练时间 90% 以上.

各步的数字和出处在对应文章里给出. 注意力, 位置编码, FFN 的推导在第 2 章, 如 [MHA](../../2-核心原理与架构/2.2-注意力机制/2.2.2-多头注意力变体/01-MHA-多头注意力的标准形式/01-MHA-多头注意力的标准形式.md), [GQA](../../2-核心原理与架构/2.2-注意力机制/2.2.2-多头注意力变体/02-MQA与GQA-共享KeyValue头/02-MQA与GQA-共享KeyValue头.md), [RoPE](../../2-核心原理与架构/2.1-深度学习基础组件/2.1.4-位置编码/01-RoPE本体-旋转位置编码/01-RoPE本体-旋转位置编码.md); 通信原语和并行实现在 [6.1.1 分布式训练](../../6-训练与推理优化/6.1-训练基础设施/6.1.1-分布式训练/6.1.1-分布式训练.md); 困惑度和基准测试在 [3.4](../3.6-预训练评估/3.6-预训练评估.md).
