# 3.2 分词器与 Tokenizer

本节的子文是 [3.2.1 训练 Tokenizer](./3.2.1-训练Tokenizer/3.2.1-训练Tokenizer.md), 内容包括四种算法, 预分词, 数字与特殊 token, 词表大小, 以及 HF tokenizers / sentencepiece 的训练代码与实测.

子词的学法有四种: BPE 按相邻对频率合并, WordPiece 按 $\mathrm{freq}(XY)/(\mathrm{freq}(X)\,\mathrm{freq}(Y))$ 打分, Unigram 从大词表出发用 EM 剪枝, SentencePiece 把空格编进 token 流以保证可逆. 字节级 BPE 以 256 个字节作原子, 消除未登录字符; GPT-2 / `cl100k_base` / `o200k_base` 的预分词正则决定哪些字符永远不会被合并到一起, 以及数字怎么切.

词表大小改变序列长度, 嵌入参数和每 token 的计算量. Tao et al. (2024) 给出了按非嵌入参数估算最优词表的方法; Llama 3 从 32K 扩到 128K, 换来了压缩率的提升. 中文和多语言要注意: 汉字的 UTF-8 编码占 3 个字节, 字符覆盖率和字节回退的设置, 特殊 token 的保留与防注入.

开源权重必须和训练时同一份 tokenizer 配套使用. 换词表会改变嵌入矩阵的行, 属于 [3.5.1 继续预训练](../3.5-继续预训练与长上下文训练/3.5.1-继续预训练/3.5.1-继续预训练.md) 讨论的范围. 训练语料的过滤与去重见 [3.1.3](../3.1-预训练数据/3.1.3-数据处理/3.1.3-数据处理.md).
