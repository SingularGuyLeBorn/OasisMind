# 3.3 分词器与 Tokenizer

## 本节问题

1. **子词怎么学出来?** BPE 按相邻对频率合并, WordPiece 按 $\mathrm{freq}(XY)/(\mathrm{freq}(X)\,\mathrm{freq}(Y))$ 打分, Unigram 从大词表出发用 EM 剪枝, SentencePiece 把空格编进 token 流以保证可逆.
2. **为什么要字节级 BPE 和预分词正则?** 256 个字节作原子消除未登录字符; GPT-2 / `cl100k_base` / `o200k_base` 的正则决定哪些字符永远不会被合并到一起, 数字怎么切.
3. **词表多大合适?** 词表大小改变序列长度、嵌入参数和每 token 的计算量; Tao et al. (2024) 给出了按非嵌入参数估算最优词表的方法, Llama 3 从 32K 扩到 128K 换来的压缩率提升.
4. **中文和多语言要注意什么?** 汉字的 UTF-8 编码占 3 个字节, 字符覆盖率和字节回退的设置, 特殊 token 的保留与防注入.
