# 3.1 预训练数据: 来源, 合成, 处理

## 太长不看版

- 模型只能从读过的文本里学. 预训练数据要回答三件事: 原始文本从哪来, 不够或不好时能不能让模型生成, 拿到之后怎么过滤, 去重和配比.
- 三件事分别写在 3.1.1, 3.1.2, 3.1.3. 本页只列问题和入口.

## 本节问题

1. **从哪里拿到数万亿 token 的文本?** Common Crawl 网页怎么抽正文, 代码, 书籍, 论文各有什么公开来源, 许可和 robots 限制怎么处理, 数据重复多少遍还有收益.
2. **能不能用模型写训练数据?** 教科书风格的合成语料 (Phi, Cosmopedia), 对网页做风格改写 (WRAP), 在低质量网页上做改写扩充 (Nemotron-CC), 以及合成数据的多样性和模型坍缩问题.
3. **原始语料怎么变成能训练的数据?** 规则过滤 (C4, Gopher), MinHash-LSH 与精确子串去重, 质量分类器, 毒性与 PII, 用 DoReMi / RegMix 学配比, 评测集去污染.
