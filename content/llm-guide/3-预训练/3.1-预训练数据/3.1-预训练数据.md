# 3.1 预训练数据：来源、清洗与配比

预训练语料是对人类文本的采样。架构再精巧，没读过的领域也编不出来。本节写**原材料从哪来、怎么洗、怎么配**。Kaplan / Chinchilla 的公式与最优 $N$–$D$ 配比在 [3.2.6 Scaling Law](../3.2-预训练全流程/3.2.6-Scaling-Law/3.2.6-Scaling-Law.md)，这里不推第二套。BPE 合并规则在 [3.3](../3.3-分词器与Tokenizer/3.3-分词器与Tokenizer.md)。

## 1. 数据来源

优秀语料要在广度（领域与语言）、深度（专业文本）、时效之间折中。下面五类是公开报告里反复出现的桶，不是互斥清单。

### 1.1 Common Crawl：最大的脏桶

Common Crawl 从 2008 年起抓公开网页，是多数基座的最大单一来源。覆盖面大：新闻、博客、论坛、百科都有。原始包里同时有 SEO 垃圾、导航模板、广告和有害文本。所有认真的训练都会再滤一遍。Llama 2 用内部质量分类器打分后只留高分网页；后续开源流水线（C4、CCNet、FineWeb）把规则、语言模型困惑度、教育价值分类器串成固定步骤。保留比例随阈值而变，**不要把「留下 10%–30%」当成一条定律**——那是经验区间，不是某一篇论文的表。

### 1.2 代码：结构，不只是「会写程序」

代码有类型约束和控制流，注释/docstring 又把自然语言绑在实现上。The Stack / The Stack v2（BigCode）是常见公开来源。清洗侧要去掉密钥、明显自动生成物、许可证冲突片段。代码比例升高往往伴随数学/推理基准变好，但具体几个百分点取决于评测集和其余配比，不要把「15%–20% 代码」写成普适最优。

### 1.3 书籍：长程叙事

书比网页长、情节更连贯，对长上下文和文风有用。Books3 因版权诉讼退出主流配方；公共领域（Gutenberg）和授权书目才是能写进报告里的来源。

### 1.4 论文与百科：结构化硬知识

arXiv、PubMed、Wikipedia 提供公式、定义和主题组织。LaTeX 源要决定是保留标记还是渲染成文本。百科的信息框和内链接近「浅知识图谱」，但编辑群体偏西方，代表性问题见第 6 节。

### 1.5 对话与论坛：交互先验

预训练里的 Reddit / 论坛线程只能提供「一问一答长什么样」。真正的助手行为是 [第 4 章](../../4-后训练/4-后训练.md) 的 SFT / 偏好数据，不要把 ShareGPT 级语料当成预训练主粮。

### 1.6 配比：用报告里的表，不用猜的百分比

| 模型 | 公开组成（token 或文档加权，以论文为准） |
|------|------------------------------------------|
| GPT-3 | 过滤后 Common Crawl 约 60%、WebText2 22%、Books1/2 共约 16%、Wikipedia 3%（Brown et al., 2020, Table 2.2）。**没有**单独的大比例代码桶。 |
| LLaMA-1 | CommonCrawl 67%、C4 15%、GitHub 4.5%、Wikipedia 4.5%、Books 4.5%、arXiv 2.5%、StackExchange 2.0%（Touvron et al., 2023, Table 1）。 |
| Llama 3 | 报告写了质量分类、去重、多语言与代码上采样，**未**公布与 LLaMA-1 同粒度的百分比表（Grattafiori et al., 2024, §3.1）。 |
| Code Llama | 在 Llama 2 上再吃约 500B 代码 token 的继续预训练（Rozière et al., 2023），不是从零按 70% 代码混一个新基座。 |

## 2. 清洗：去重、质量、隐私

### 2.1 去重

重复会浪费步数，也会让模型背下高频片段。万亿文档不能两两比。常用 **MinHash + LSH** 估 Jaccard，再用 suffix array 做精确子串去重。

文档 $A,B$ 的 $n$-gram 集合 $S_A,S_B$：

$$
J(A,B)=\frac{|S_A\cap S_B|}{|S_A\cup S_B|} \tag{1}
$$

$k$ 个哈希函数下，MinHash 签名的逐位相等比例是 $J$ 的无偏估计。再把签名切成 $b$ 个 band，只对同 band 碰撞的候选对算精确 Jaccard。工程上分三层：文档级、段落级、子串级（版权栏、导航）。

**能钉上的数字**（Lee et al., 2022, ACL；C4 上 NEARDUP）：近重复约占训练样本 **3.04%**、token **约 7.18%**；验证集里约 **4%** 能在训练集找到近似副本。去重后同样步数下困惑度不差，逐字背诵大约少一个数量级。那条「MinHash 之后 Common Crawl 少 20%–40%」没有对应表，不写。

SimHash 走海明距离，对改写新闻更松；超大规模网页仍以 MinHash LSH 为主。

### 2.2 质量过滤

三层，由便宜到贵：

1. **规则**：长度、符号比、语言 ID（fastText）、明显成人/暴力词表。
2. **统计**：在 Wikipedia 一类参照语料上训小模型，用困惑度丢掉「太随机」或「太模板」的两端。CCNet（Wenzek et al., 2020）用 KenLM 做这一档。
3. **分类器**：人工标高/低质量，再蒸馏到能扫全库的小分类器。C4、MassiveText、Llama 3、FineWeb-Edu 都走这条。用 Wikipedia 当正样本会压低口语和少数群体语体，过滤模型要分语体训，不要单阈值一刀切。

![清洗流水线](./images/fig-data-cleaning-pipeline.png)

> 图 2：清洗顺序示意。不要把「保留 40% / 28% / 12%」当成论文表。

**图 2 解析**

- 先规则减体积，再哈希去重，再质量和 PII。
- 去污染（decontamination）把评测题的 $n$-gram 从训练集抠掉，否则 MMLU / HumanEval 虚高。

### 2.3 PII 与去污染

正则抓电话、邮箱、证件号；NER 抓人名地名。密集 PII 的文档直接丢，比乱替换更安全。去污染常用 13-gram 与测试集对齐。具体掉几个评测点因模型和基准而异，DeepSeek 等报告只强调「必须做」，没有统一的「虚高 $x$ 个百分点」。

## 3. 配比

自然分布会让网页淹没代码和数学。LLaMA-1 已经在降权采样 arXiv/GitHub；DoReMi（Xie et al., 2023）用小 reference 模型 + Group DRO 学域权重，再放大到大模型。网格搜索只在小模型上付得起。在线按验证集改配比是系统能力，不是算法论文里的默认项。

## 4. Scaling Law：这里只留指针

固定算力 $C$ 时，参数量 $N$ 和 token 数 $D$ 怎么分，是 [3.2.6](../3.2-预训练全流程/3.2.6-Scaling-Law/3.2.6-Scaling-Law.md) 的题目。本章需要记住的工程含义只有三条：

1. Kaplan（2020）倾向「同样算力把模型做大」。
2. Chinchilla（Hoffmann et al., 2022）拟合出近似 $D_{\mathrm{opt}}\approx 20N$（token 对参数），GPT-3 175B / 300B token 按这条是欠训。
3. Llama 3 8B 在约 15T token 上训练，远超 Chinchilla 最优，换的是同推理成本下的更强小模型（herd 报告原文）。

不另画假坐标曲线冒充 Kaplan / Chinchilla 的拟合图。

## 5. Tokenization：词表大小会改序列长度

文本必须变成离散 ID。算法本体（BPE 合并、Unigram 裁剪、SentencePiece 字节流）在 [3.3](../3.3-分词器与Tokenizer/3.3-分词器与Tokenizer.md)。数据节只关心一件工程事实：**词表太小，非英语会碎成字节，序列变长，注意力更贵**。

Llama 2 词表 32K；Llama 3 扩到 128K，报告写明是为了多语言和压缩率。示意：`"Hello, 世界!"` 在小词表下中文可能变成多个 UTF-8 字节 token，大词表可以收成一个词。

![词表大小与切分](./images/fig-tokenization-vocab.png)

> 图 3：小词表 vs 大词表的切分示意，不是某一条句子的官方 tokenize 输出。

嵌入矩阵是 $V\times d$。对 70B 级模型，词表从 32K 升到 128K 增加的参数占比通常很小，换来的是更短序列。细节与中文效率数字见 3.3，不要在这里手填「每个汉字 1.5 个 token」。

## 6. 偏见、版权、治理

- **版权**：Books3、纽约时报诉 OpenAI 等仍在司法过程中。「合理使用」不是全球统一答案。欧盟 AI Act 要求训练数据更可追溯。
- **有害内容**：过滤不足会进生成；过滤过严会挖掉历史课和新闻。预训练只做粗滤，细对齐在第 4 章。
- **代表性**：英文网页远多于全球母语比例。职业刻板印象在未对齐基座上可复现。缓解：低资源语言加采、重采样、后训练约束、Data Card。
- **合成数据**：能补教科书腔，但用模型喂模型有坍缩风险（Shumailov et al., 2023）。语料蒸馏专文见 [3.1.2](./3.1.2-数据蒸馏/3.1.2-数据蒸馏.md)。
