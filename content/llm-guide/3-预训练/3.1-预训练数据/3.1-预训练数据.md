# 3.1 预训练数据: 来源, 合成, 处理

本节三篇子文分别讨论预训练语料从哪来, 能不能由模型生成, 以及怎么洗和配.

[3.1.1 预训练数据收集](./3.1.1-预训练数据收集/3.1.1-预训练数据收集.md) 讨论数万亿 token 的文本从哪里拿: Common Crawl 网页怎么抽正文, 代码, 书籍, 论文各有什么公开来源, 许可和 robots 限制怎么处理, 数据重复多少遍还有收益.

[3.1.2 合成与改写数据](./3.1.2-数据蒸馏/3.1.2-数据蒸馏.md) 讨论用模型写训练数据: 教科书风格的合成语料 (Phi, Cosmopedia), 对网页做风格改写 (WRAP), 在低质量网页上做改写扩充 (Nemotron-CC), 以及合成数据的多样性和模型坍缩问题.

[3.1.3 数据处理](./3.1.3-数据处理/3.1.3-数据处理.md) 讨论原始语料怎么变成能训练的数据: 规则过滤 (C4, Gopher), MinHash-LSH 与精确子串去重, 质量分类器, 毒性与 PII, 用 DoReMi / RegMix 学配比, 评测集去污染.

相关章节: 固定算力下参数量与 token 数怎么分, 见 [3.2.5 Scaling Laws](../3.2-预训练全流程/3.2.5-Scaling-Laws/3.2.5-Scaling-Laws.md); 文本怎么切成 token, 见 [3.3 分词器](../3.3-分词器与Tokenizer/3.3-分词器与Tokenizer.md).
