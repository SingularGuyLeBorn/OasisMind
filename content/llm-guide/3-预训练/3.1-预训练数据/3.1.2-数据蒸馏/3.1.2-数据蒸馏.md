# 3.1.2 数据蒸馏:教师生成合成语料

这里的「蒸馏」是 **语料蒸馏**:用更强的教师模型写出文本,滤完之后混进学生的预训练(或继续预训练)集合.学生学的是**词序列**,不必碰教师的 logits 或中间层.

这和另外两件事不是同一个槽:

- Hinton 等(2015)的知识蒸馏:学生匹配教师的**软标签 / 特征**,通常发生在同一任务,同一输入上.
- 本库 [4.6 On-Policy Distillation](../../../4-后训练/4.6-OPD/4.6-OPD.md):后训练里,学生按自己的前缀采样,教师在这些前缀上给逐 token 监督.**那是后训练蒸馏,不是语料蒸馏.**

DeepSeek-R1 把推理轨迹 SFT 到 Qwen / Llama 上,落在后训练;若把同一批 `<prompt, 教师回答>` 再当预训练文档用,才回到本节.不要把 R1-Distill 检查点直接写成「预训练数据工程」.

## 1. 教师 → 合成语料 → 学生

![](./images/fig-teacher-synthetic-corpus.png)

> 图 1:语料蒸馏主路径.

**图 1 解析**

- 教师只当生成器:网页风格,教科书,习题讲解都可以.
- 合成文本仍要走 [3.1](../3.1-预训练数据.md) 的去重,质量,去污染,再和真实网页按权重混合.
- 学生继续做 CLM,没有 KL(教师∥学生) 这一项.

Phi-1(Gunasekar et al., 2023)把这条路写进报告:约 1.3B 参数,约 **7B** token 的「教科书质量」网页筛选结果,外加约 **1B** token 的合成教科书,在 HumanEval 上超过许多用大得多的网页堆出来的码模.旧文「50 亿 token」不准确.

Self-Instruct / Evol-Instruct 生成的是指令–回答对,默认去 SFT,只有显式写进预训练混合时才算本节.

## 2. 经典 KD 三范式(对照,不是预训练主路径)

需要访问教师内部时,才谈 soft label / 特征.三种训练日程:

![](./images/fig-kd-three-paradigms.png)

> 图 2:离线(教师已训完),在线(师生同训),自蒸馏(同一套网).Gou et al., 2021 综述口径.

**图 2 解析**

- **离线硬标签**:即图 1.闭源 API 只能走这条.
- **离线软标签**:温度 $T$ 平滑后的词表分布,KL 对齐.词表 10 万,语料万亿时,存全量 logits 不现实;开源教师也极少把预训练做成全词表蒸馏.
- **在线 / 自蒸馏**:没有现成大教师时的正则手段,Llama 4 等报告里的 co-distillation 属于训练策略,仍不是「爬虫替代」.

特征蒸馏要对齐中间层形状,预训练 Decoder-only 很少这么做.

## 3. 失效

| 现象 | 原因 | 说明 |
|------|------|------|
| 模式坍塌 | 教师温度太低,种子太窄 | 合成页长得像同一篇作文 |
| 错误放大 | 教师胡编进语料 | 学生当事实记住 |
| 模型坍塌 | 多代只吃合成 | Shumailov et al., 2023 |
| 和 OPD 搞混 | 把 SFT 轨迹叫预训练 | 回 4.6 |
