# 3.1.3 数据处理:配比,合成,筛选

收集之后还要决定**各桶采多少,要不要用教师再写一批,留下什么**.三件事是杠杆,不是三个独立产品.

![](./images/fig-data-processing-levers.png)

> 图 1:配比 / 合成 / 质量.图内公式是示意权重,不是某一篇论文的编号式.

## 1. 数据配比

网页多,代码和数学少,按自然频率混会得到「会聊天,弱推理」的基座.LLaMA-1 公开了文档加权表(Touvron et al., 2023, Table 1):CommonCrawl 67%,C4 15%,GitHub 4.5%,Wikipedia 4.5%,Books 4.5%,arXiv 2.5%,StackExchange 2.0%.这是**降权采样之后**的目标混合,不是互联网原比例.

Llama 2 报告强调更多代码与多语言,但没有同等粒度的新表.Llama 3 同样只描述分类器与上采样,不给百分比.旧文里「Llama-2 90% 英文」「Llama-3 代码>15%」「DeepSeek 中英 3:7」没有一手表,不写.

**DoReMi**(Xie et al., 2023):先训小 proxy,用 Group DRO 把「学得差的域」权重抬高,再把学到的域权重套到大模型.收益写在该论文的下游表里,不要概括成「任意预算都一致提升」.

均匀采样,人工上采样,课程(先通识后代码)都是启发式;课程没有统一调度公式.

## 2. 合成数据

自然高质量文本不够时,用教师写.和 [3.1.2](../3.1.2-数据蒸馏/3.1.2-数据蒸馏.md) 同一条生成路径,这里只标处理时要注意的点.

- **Self-Instruct**(Wang et al., 2023):175 条种子指令扩写.默认产物是 SFT 集.
- **Evol-Instruct**(Xu et al., 2023, WizardLM):加深约束或换领域,提高指令难度.
- **教科书合成**:Phi-1 用约 7B 筛选网页 + 约 1B 合成教科书训 1.3B 模型(Gunasekar et al., 2023).不是「50 亿 token 超过万亿网页」这种无分母的比较.

挑战:多样性崩,教师错误进学生,多代合成坍缩(Shumailov et al., 2023).缓解是混真实网页,多教师,抽检,不是再提高生成温度一档就结束.

## 3. 质量筛选与去重

### 3.1 去重

Lee et al. (2022) 在 C4 上:NEARDUP 近重复约占样本 **3.04%**,token **约 7.18%**;未去重模型会把训练集里的句子背出来(他们测到未提示生成里超过 1% 是逐字复制).Exact substring 能删掉重复 6 万次的 61 词英文句.旧文「去重后困惑度降 5–10%」「Common Crawl 少 20–40%」没有对应表.

MinHash LSH 步骤:shingle → 多哈希签名 → 分桶 → 桶内比.文档 / 段落 / 子串三层与 [3.1](../3.1-预训练数据.md) 相同.

### 3.2 启发式与分类器

语言 ID,长度,符号比,KenLM 困惑度(CCNet),毒性词表,正文抽取,都是便宜过滤器.GPT-3 用质量分类器筛 WebText 类数据(Brown et al., 2020).CCNet 按语言模型分数分桶,**具体 0.3 / 0.6 阈值不是该论文的通用标准**,部署时自己定.

PII 用正则 + NER.毒性过滤过严会误伤新闻与历史.

## 4. 串起来

```
原始数据 → 语言过滤 → 文档去重 → 质量分类 → 毒性/PII → 子串去重 → 按域配比 → 可选合成扩增 → 混洗 → 训练
```

万亿 token 预处理本身是分布式 CPU/GPU 作业(MapReduce 去重,GPU 跑分类器).下一节存储与流式加载若存在 3.1.4 再写;本目录没有 3.1.4 子文时,token 化见 [3.3](../../3.3-分词器与Tokenizer/3.3-分词器与Tokenizer.md).
