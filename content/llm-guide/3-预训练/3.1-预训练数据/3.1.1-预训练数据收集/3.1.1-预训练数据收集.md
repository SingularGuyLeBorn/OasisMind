# 3.1.1 预训练数据收集

收集要回答的是：原始网页、代码、书、论文怎样变成「可以送进 3.1 清洗流水线」的文本。目标是多样来源 + 可重复的过滤，不是炼金术，也不是把 SFT 对话和 RAG 知识库提前做完。指令微调、偏好对齐、检索增强在 [第 4 章](../../../4-后训练/4-后训练.md)。

下一词预测强迫模型找可压缩的规律，这是信息论直觉，不是收集流水线的操作步骤。**Grokking**（Power et al., 2022）描述的是小网络在合成算法任务上「先过拟合再突然泛化」的曲线，不是 Common Crawl 工程的主线。下面只留一张示意，避免把它写成「数据工程的核心目标」。

> 图 1：Grokking 示意（记忆平台 → 陡升 → 泛化）。任务是模运算一类小问题，不是网页语料收集。

## 1. 从原始语料到可训 token

![](./images/fig-data-collection-pipeline.png)

> 图 2：收集之后的标准顺序。旧 `image_1.png` 带知乎水印，文件保留，正文改引用本图。

**图 2 解析**

1. **收集**：网页（Common Crawl）、书、代码、论文。领域模型提高对应桶的采样，而不是只换架构。
2. **质量过滤**：启发式（长度、符号比、语言 ID）+ 分类器。Llama 3 把教师打分蒸馏到可扫全库的小分类器；FineWeb-Edu 用教育价值分。
3. **去重**：文档 / 段落 / 子串。数字见 [3.1](../3.1-预训练数据.md) 对 Lee et al. 的引用，不在这里另编百分比。
4. **隐私**：检测并删除或占位 PII。
5. **分词**：复用基座词表，或为领域术语扩词表。算法在 [3.3](../../3.3-分词器与Tokenizer/3.3-分词器与Tokenizer.md)。

## 2. 排兵布阵：混合、格式、课程

- **混合比例**：LLaMA-1 对 arXiv、GitHub **降权**采样（Touvron et al., 2023, Table 1），避免高质量但窄的桶挤掉网页常识。DoReMi 用小模型动态加困难域的权重。
- **格式**：同一知识，带中间步骤的文本比「题+答案」更好学。这仍然是预训练文档的写法，不是 SFT 模板。
- **课程**：Code Llama 的做法是先有通用 Llama 2，再在代码上继续预训练（Rozière et al., 2023），而不是从第一步就 100% 代码。计算极紧、只要代码时，纯代码继续预训练往往比 50/50 从零混更划算——因为通用语言能力已经在基座里。

旧文里的 SFT 三格图、RLHF「训狗」比喻、RAG 开卷考试，属于后训练与应用，不在收集节。带水印的 `images/image_2.png` 保留，不再嵌入。

## 3. 案例：中文公开语料的三条路径

OpenCSG Chinese Corpus（arXiv:2501.08197）给出三类可复现做法，对应「滤网页 / 合成教科书 / 合成多轮话」：

![](./images/fig-opencsg-chinese-corpus.png)

> 图 3：三条构造路径示意。旧 `image_3.jpg` 有水印，文件保留。

**图 3 解析**

- **教育向网页**：大池抽样 → 模型打分 → 小分类器全量过滤。这是预训练主食。
- **教科书式合成**：种子主题 + 模板 → 教师生成 → 清洗。补的是结构，不是另抓一遍互联网。
- **多轮对话**：给后训练 SFT 用，**不是**预训练网页桶的替代。
