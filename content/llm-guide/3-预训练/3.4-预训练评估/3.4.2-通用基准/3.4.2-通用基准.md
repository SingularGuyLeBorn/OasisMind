# 3.4.2 通用基准

[3.4.1](../3.4.1-困惑度-PPL/3.4.1-困惑度-PPL.md) 的 PPL 只说明模型是否还在拟合语言.通用基准把能力切成可重复的考场:知识广度,小学数学,函数级代码.数字只引用**打开过的论文 / 官方报告表**;2026 产品分统一回到 [第 05 章型号正本](../../../05-模型家族与选型/05-模型家族与选型.md).旧路径 [3.3.2](./3.3.2-通用基准.md) 为重定向.

## 1. 为什么要考场

PPL 降 10% 不等于人类观感好 10%.选择题有 25% 随机基线;代码必须过单测.考场的代价是**污染**:题一旦进预训练,分数测量的是记忆.GPT-4 报告对 HumanEval 估计约 25% 重叠,去污后 67.0% → 65.58%(OpenAI, 2023, Table 11).

考场另一个作用是给出可复现的对比锚.同样的 checkpoint,用同样的 5-shot prompt,换一组题就能看到知识盲区.但考场分数不是训练目标:刷榜模型可能在 MMLU 上很好看,却在实际对话里答非所问.所以 3.4 只把基准当诊断工具,不是优化目标.

## 2. 三份必须能指回原文的集合

**MMLU**(Hendrycks et al., 2021):**15,908** 道题,**57** 个科目,四选一.划分:每科 5 道 few-shot 开发集,验证 1,540,测试 14,079.GPT-3 175B 5-shot 平均 **43.9%**(Hendrycks 表,亦被 Llama 1 转引).GPT-4 5-shot **86.4%**(GPT-4 Table 2).不要把本页未核对的「美国历史 84.2%」单科表写进来.

**GSM8K**(Cobbe et al., 2021):约 **8.5K** 小学应用题,**7.5K 训练 + 1K 测试**,2–8 步四则运算.GPT-4 报告:**92.0%**(5-shot CoT;脚注:训练混合里含部分 GSM8K 训练集).

**HumanEval**(Chen et al., 2021):**164** 道手写 Python 函数,平均 7.7 个单测.指标是 pass@k,定义见 [3.4.4](../3.4.4-特定能力评估/3.4.4-特定能力评估.md).Codex 论文:GPT-3 在该集上 **接近 0%**;Codex-12B 单样本 **28.8%**.GPT-4 Table 2:**67.0%**(0-shot).不要把 GPT-3 写成 17.7%,也不要把 GPT-4 写成 87.2%.

**MATH**(Hendrycks et al., 2021):**12,500** 道竞赛题(7,500 训练 + 5,000 测试),难度 1–5,七个科目.不是「总共 5,000 道」.GPT-4 报告 Table 2 **没有** MATH 总分;过程监督数字见 3.4.4 的 PRM800K.

## 3. 其它常用切片(只写集合,不编排行榜)

| 集合 | 论文 | 形式 |
|------|------|------|
| HellaSwag | Zellers et al., 2019 | 活动描述续写四选一 |
| ARC Challenge | Clark et al., 2018 | 科学选择题 |
| MBPP | Austin et al., 2021 | 约 974 道基础 Python |
| BBH | Suzgun et al., 2022 | Big-Bench 里 23 个难子集 |

GPT-4 Table 2 另有:HellaSwag 10-shot **95.3%**,ARC-C 25-shot **96.3%**.少样本,CoT,多数投票会改分数,对比时必须写清协议.

Hugging Face Open LLM Leaderboard 换过题集(v1:ARC / HellaSwag / MMLU / TruthfulQA;v2 加入 MMLU-Pro 等).那是排行榜产品,不是论文 Table;本页不抄「截至 2025 年」四档百分比.

## 4. 使用时的三条铁律

1. **协议对齐**:0-shot vs 5-shot,是否 CoT,pass@1 greedy vs 采样,差几个点很常见.
2. **污染**:优先更新更晚的集(MMLU-Pro,LiveBench)或私有 holdout.
3. **选择题上限**:四选一随机 25%;「专家水平」要以原论文人类基线为准,不要口头加百分数.
