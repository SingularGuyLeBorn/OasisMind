# 3.4.4 特定能力评估：代码过单测、数学过步骤

通用基准里的四选一可以被排除法抬高。[3.4.2](../3.4.2-通用基准/3.4.2-通用基准.md) 已经把集合尺寸对齐到论文。本篇只把 **pass@k 的无偏估计** 和 **过程监督 PRM** 写清楚。旧路径 [3.3.4](./3.3.4-特定能力评估.md) 为重定向。DeepSeek-R1 的 93% / MATH 83.9% 本篇未打开原报告，不写进表。

## 1. 为什么代码和数学是试金石

函数体要么通过全部单测，要么不通过。竞赛数学在规范化后可以精确匹配 boxed 答案。二者都强制多步，没法只靠选项字母。这不是「理科一定比文科难」，而是**可自动判分的深度推理切片**。

## 2. HumanEval 与无偏 pass@k

HumanEval：164 道手写题，签名 + docstring + 单测（Chen et al., 2021）。Kulal 式「生成 k 个里有一个过就算过」方差大。Codex 改用 $n\ge k$ 次采样（文中 $n=200$，$k\le 100$），$c$ 为通过次数，无偏估计

$$
\mathrm{pass@}k
=\mathbb{E}_{\mathrm{problems}}\left[1-\frac{\binom{n-c}{k}}{\binom{n}{k}}\right] \tag{1}
$$

当 $n-c<k$ 时组合数为 0，该项为 1。这是**无放回**抽 $k$ 个全失败的概率，再取补。用 $1-(1-\widehat{\mathrm{pass@}1})^k$ 会系统性偏低。

![](./images/fig-pass-at-k.png)

> 图 1：$n$ 个样本里 $c$ 个过单测，再对 $k$ 做组合修正。Chen et al. (2021) 式 (1)。不是模型分数条。

**图 1 解析**

- 绿块：通过单测的 $c$ 个；橙块：失败的 $n-c$ 个。
- 公式读作：从 $n$ 个里抽 $k$ 个全落在失败池的概率，用 1 减去。
- pass@1 看单次质量（IDE 补全）；pass@10 / 100 看覆盖。温度升高通常伤 pass@1、帮 pass@k（Code Llama Figure 6）。

一手分数（ greedy / 0-shot 除非注明）：

| 模型 | HumanEval pass@1 | 出处 |
|------|----------------:|------|
| GPT-3（未代码精调） | ≈ 0% | Codex 摘要 |
| Codex-12B | 28.8% | 同上 |
| Llama 2 70B | 30.5% | Code Llama Table 2 |
| Code Llama 34B | 48.8% | 同上 |
| Code Llama - Python 34B | 53.7% | 同上 |
| GPT-4 | 67.0% | GPT-4 Table 2；Code Llama 表转引同一格 |

MBPP（Austin et al., 2021）更偏日常题，约千道量级；Code Llama 对 MBPP 用 3-shot。FIM（中间填空）是另一套协议，见 Code Llama §3.2，不要和 pass@1 函数生成混成一张「代码能力总分」。

## 3. GSM8K、MATH、过程奖励

GSM8K：8.5K 小学题，见 3.4.2。GPT-4：**92.0%**（5-shot CoT）。

MATH：12,500 道竞赛题（7,500+5,000），Level 1–5。只看最终数字会把「算对但证错」算进去。

Lightman et al. (2023) 比较结果监督（ORM）与过程监督（PRM）：PRM 对思维链**每一步**打对/错/模糊。他们发布 **PRM800K**（80 万步级人工标签）；过程监督模型在 MATH 的一个代表子集上解出 **78.2%**。这不是 GPT-4 的 MATH 总分，不要写进 3.4.2 的 Table 2 空格。

## 4. 失效

| 现象 | 原因 |
|------|------|
| 两张表 HumanEval 差 20 个点 | 混用了 0-shot greedy、pass@1 采样、污染子集 |
| 「生成 10 次有一次对」当 pass@10 | 没用式 (1) |
| 用 SFT 后的对话模型比 Codex 论文的 base | 后训练改变解码，不是预训练切片 |
| 把 PRM 子集 78.2% 写成 MATH 全测 78% | 论文写的是 representative subset |

2026 的 LiveCodeBench / SWE-bench / AIME 写在第 4.5 与各模型 D2，本篇当公式课，不再抄旗舰榜。
