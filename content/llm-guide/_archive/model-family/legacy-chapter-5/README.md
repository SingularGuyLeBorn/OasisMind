# 旧第 5 章模型汇总稿归档说明

本目录保存原“主流模型全解”下的汇总、对比、国内外模型盘点和演进史原稿及其配图。它们不再属于公共教学树，也不再承担模型事实、时间线或选型结论的正本职责。

## 为什么归档

- 多篇文章按同一批模型重复罗列，形成互相竞争的版本和导航；
- 大量参数、价格、排行榜与“领先”判断缺少精确版本、日期、评测设置或一手来源；
- 国内/国外、开源/闭源等粗分类把机构、产品、权重、API 与系统能力混为一谈；
- 演进稿存在日期粒度不一、论文日期与产品发布日期混写、历史节点重复等问题；
- 旧图服务于静态阵营比较或过期架构，不适合作为当前课程证据。

| 架构、后训练和推理优化方法 | 第 02、04、06 章对应方法课程 |

归档文件保留原貌仅用于追溯。若其中内容与公共正本冲突，以公共正本和其所列一手来源为准；不要从本目录恢复静态排行榜、未经核验的宣传结论或平行模型百科。
