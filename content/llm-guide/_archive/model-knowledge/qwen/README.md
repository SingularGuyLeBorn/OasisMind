# Qwen 历史模型知识归档说明

本目录保存退出公共技术树的二次解读、重复索引、部署估算与预测材料。可核验的公开正本见：`05-模型家族与选型/5.3-模型家族/qwen/`。

## 保全与处置边界

- 31 篇旧 Markdown 与 3 张 Qwen4 预测图完整归档，没有删除知识正文或附件。
- Qwen4 预测稿即使明确标注“尚未发布”，仍包含对未来最终模型的推演，因此不进入公开事实层。
- Qwen2.5-Math 旧材料混入 Qwen2-Math 论文链接；公开页已改用正确的 Qwen2.5-Math 报告 arXiv:2409.12122，旧稿留作审计证据。
- Qwen3.5–3.7 的旧“架构剖析/工程实践”含未由完整技术报告逐项支持的归因和估算，统一保留在此，不回填公开页。
- 归档默认未校勘，不参与公共课程导航。

## 使用纪律

引用任何规格、日期、许可、参数量、上下文或评测结论前，先回公开身份页并核对一手来源。不能把托管 SKU、开放检查点和架构预览合并成同一个“版本”。
