- 将 Modified MIT 或 K3 自定义许可误标为 Apache-2.0 / 标准 MIT；
- 旧第 5 章演进稿含无一手来源的架构数字、占位式 arXiv 编号和跨版本推测；
- AI 精译、二次分析和旧导航与官方报告原文重复，无法作为独立权威来源。

这些文件按原字节保留，供追溯独有表达和排查历史错误；未经一手来源复核，不应复制回公开正文。
