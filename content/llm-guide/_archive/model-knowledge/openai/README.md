# OpenAI 历史归档

本目录保存从旧第 5/14 章退出公开树的 OpenAI 稿件和非正本资产。归档不代表内容正确，也不参与公开导航。

## 为什么归档

- 旧稿大量把闭源模型的 MoE、参数量、训练硬件、RL 配方或内部路由写成确定事实，而官方并未披露。
- ChatGPT 产品、API 模型、论文实验和开放权重经常被混为一谈；新正本已按身份拆开。
- GPT-5/5.1/5.2/5.3-Codex/5.4 的旧 HTML 是“尚未发布”占位页，和 2026-09-01 官方目录冲突。
- GPT-5.5 稿中的 Spud、AOMTO、特定稀疏注意力、训练数据规模与能耗数字缺乏一手证据。
- 旧 OpenAI-GPT 专题包含第三方二次稿、Sora 逆向猜测和来源不明图片；Sora 主题也不属于本次语言模型家族正本。
- Cloudflare 挑战、404 保存页、伪装成 PDF 的短 HTML、旧作者自制图仅为迁移取证保留。

- `old14/`：原第 14 章 `14.12-OpenAI` 下的旧作者 Markdown 与非一手资产。
- `old5-root/`：旧第 5 章根层的 GPT/o/Operator 平行专题。
- `old5-foreign/`：旧“国外大模型”下的 `OpenAI`、`OpenAI-GPT` 二次稿与图片。
