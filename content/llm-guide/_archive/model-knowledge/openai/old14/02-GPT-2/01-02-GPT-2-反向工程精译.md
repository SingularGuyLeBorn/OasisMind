# GPT-2: 多任务学习与 Zero-Shot 的萌芽 - 技术探测与反向工程

>  **[返回 14.12-OpenAI 家族总览](../../14.12-OpenAI.md)** · 前代：[GPT-1](../01-GPT-1/01-01-GPT-1-反向工程精译.md) · 后继：[GPT-3](../03-GPT-3/01-03-GPT-3-反向工程精译.md) · 已有长 D5：[05-02](./05-02-GPT-2-核心技术专题.md)

> **背景**：该模型并未完全开源其底层代码与权重，本精译基于其官方发布的技术报告(Technical Report)、系统卡片(System Card)以及顶级研究团队的逆向探测论文重构。

**论文精读**。上面「背景」原样保留。事实源是 Radford et al. *Language Models are Unsupervised Multitask Learners*（2019）。占位段的「拒绝采样 / 几十项代码数学 Benchmark」是模板，**不是**这篇：GPT-2 的主轴是 **zero-shot 语言建模与任务迁移**，没有 RLHF。权重后来开源（`openai/gpt-2`），不要把「未开源」写成论文原句。

## 1. 主张

不微调、不改架构：只做语言建模，在下游任务上 **zero-shot**。最大模型叫 GPT-2，**1.5B** 参数 Transformer；在测过的 8 个语言建模集里 **7 个** zero-shot SOTA，但仍 **underfit WebText**。CoQA：文档+对话史+`A:`，greedy，dev **55 F1**，没用那 127k+ 训练问答。容量对 zero-shot 迁移是必需的，跨任务近似 **log-linear**。

## 2. 架构（Table 2）

沿 GPT，改动：

- LayerNorm 挪到每个 sub-block **输入**（pre-activation 残差那种），最后一层 self-attention 后再加一层 LN
- 残差层初始化乘 $1/\sqrt{N}$（$N$ = 残差层数）
- 词表 **50,257**；上下文 **512 → 1024**；batch **512**
- 输入：byte-level BPE，禁止跨字符类别 merge（空格除外）

| 参数 | 层 | $d_{\mathrm{model}}$ |
|------|----|----------------------|
| **117M** | 12 | 768 |
| **345M** | 24 | 1024 |
| **762M** | 36 | 1280 |
| **1542M** | 48 | 1600 |

最小档 ≈ 原 GPT；第二小 ≈ BERT-large。学习率按 WebText **5% held-out** PPL 手调。长 D5 里的 124M / 355M / 774M 是后来发布档命名，**不要写进 Table 2**。

## 3. 数据：WebText

不直接用脏 Common Crawl。Reddit 出站链接、至少 **3 karma** → 约 **4500 万** 链接的文本子集。本篇结果用的是 **2017-12 之后链接不算** 的初版：去重+启发式清洗后略多于 **800 万** 文档、**40 GB** 文本。抽掉全部维基，避免和评测重叠。法语检测大约只有 **10MB**（相对常见单语法语语料约 500× 小）。

## 4. 评测（只抄论文）

Table 3 zero-shot（1542M）：LAMBADA PPL **8.63** / acc（停词过滤）**63.24%**；CBT-CN/NE **93.30 / 89.05%**（验证集，因为 *Jungle Book* 在训练里）；WikiText-2 PPL **18.34**；PTB **35.76**；enwik8 **0.93** BPB；WikiText-103 **17.48**；**1BW 仍明显落后**（句级打乱）。

其它：Winograd **70.70%**（+7 点 SOTA；仅 273 例）；摘要 CNN/DM 加 `TL;DR:`，top-k=2 采 100 token 取前 3 句，R-AVG **21.40**（去掉 hint 掉 6.4）；WMT14 En→Fr **5 BLEU**、Fr→En **11.5 BLEU**；Natural Questions exact match **4.1%**（最小模型不超过「按题型最常见答案」的 1.0%；最自信 1% 问题上 **63.1%**）。

## 5. 失效条件

- 把占位段的拒绝采样写进 GPT-2。
- 把 124/355/774 写成论文 Table 2。
- 把 CoQA 55 F1 写成微调结果。
- 把「已拟合 WebText」写成结论——论文说仍 underfit。
