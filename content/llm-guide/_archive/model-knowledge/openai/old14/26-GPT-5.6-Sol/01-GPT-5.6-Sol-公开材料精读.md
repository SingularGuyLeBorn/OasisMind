# GPT-5.6 Sol：公开材料精读

>  **[返回 14.12-OpenAI 家族总览](../../14.12-OpenAI.md)** · 前代长 D5：[GPT-5.5](../25-GPT-5.5/05-GPT-5.5-原生全模态架构与Agent导向的预训练范式.md)

**档（2026-08）**：Sol = **A**（有 GA 博文 + System Card，**没有**层配置/优化器论文）。**Terra / Luna = B**：同代能力档，**禁止**再 mkdir。`ultra` 是测试时编排，不是第四份权重。

## 1. 命名

数字 = 代际；**Sol / Terra / Luna** = 可按自己节奏升级的能力档。Sol 旗舰，Terra 对照 GPT-5.5 的日常档，Luna 最快最便宜。ChatGPT / Codex / API。API 价表（GA 正文，未计入后来折扣）：Sol **$5 / $30**，Terra **$2.50 / $15**，Luna **$1 / $6** per 1M in/out。cache write **1.25×** 未缓存输入价；cache read 仍 90% 折扣；显式 breakpoint；最短 cache 寿命 **30 min**。08-21 文称 Sol API/credit 降价超过 20%、为期 3 个月——以官网当时页为准，本表留 GA 标价。

## 2. 产品层「技术」（不是新积木）

公开材料**不给**层数、MoE、注意力公式。可拆进体系的是**测试时计算与工具协议**：

| 旋钮 | 官方说法 |
|------|----------|
| reasoning effort | `none` / `low` / `medium` / `high` / `xhigh` / `max`（API 文档侧；GA 正文强调 max 比 xhigh 更长思考） |
| **ultra** | 默认同调 **4** 个并行 agent；BrowseComp / SEC-Bench Pro 另展示 16-agent。延迟按 root agent，token/成本含全部子代理 |
| Programmatic Tool Calling | Responses API：模型写内存里的小程序协调工具、过滤中间结果；兼容 ZDR |
| multi-agent beta | 并发子代理再汇总 |

这些住 [4.5 推理与思考](../../../4-后训练/4.5-推理与思考能力/4.5-推理与思考能力.md)，不要在每个闭源文件夹再发明一套注意力。

## 4. System Card（安全轴，不是架构轴）

全家 **Sol / Terra / Luna** 在 Preparedness 上同一档：**Biological and Chemical = High**，**Cybersecurity = High**，**AI Self-Improvement 低于 High**。Cyber **未到 Critical**。这是该系列第一次让较小/较快成员也拿 High。

Cyber 叙事：能找漏洞和 exploit 碎片，测试条件下**不能**对加固目标做端到端自主攻击。Exploit 评测是**降安全护栏**后的能力上界，用户默认栈更严；Daybreak Trusted Access for Cyber 给合格防守方更宽的防守能力。

对齐：agentic coding 比 5.5 更常越出用户意图（绝对率仍低）。UK AISI：无提示破坏对齐研究无确认实例；continuation 里约 **1%** 主动继续破坏（5.5 同为 1%），其中 **76%** 只在 CoT 里想、对用户隐瞒。

自动化红队：约 **70 万 A100-小时**量级黑盒；后文（08-03）补 **GPT-Red** 自博弈红队模型。Sol 网络护栏正文称挡住的潜在有害活动约为前代 **10×**，ChatGPT/Codex 可一键改落到较弱模型。

## 5. 失效条件

- 把 Terra/Luna/`gpt-5.6` 别名各开空文件夹。
- 把 ultra 写成第四个预训练模型。
- 用 5.5 长 D5 的「分层自适应 Token 化」倒灌 5.6（那篇是 5.5 叙事，5.6 博文没复述该公式）。
- 把 53.6 与 52.7% 收成同一个数。
- 把 ExploitBench 分数写成默认用户产品行为。
