# 2.3.3 · 线性注意力机制

softmax 注意力的归一化分母依赖整行分数,$(QK^\top)V$ 不能重排成 $Q(K^\top V)$,KV cache 随上下文线性增长.线性注意力改写相似度或改成状态递推,每个头只保留一个 $d_k\times d_v$ 的状态,代价是状态容量有限,生产模型多与全注意力层混合使用.
