# 2.3.3 · 线性注意力机制

Softmax 注意力要先物化 $n\times n$ 分数再加权 $V$。FlashAttention 把 HBM 读写压下去，**FLOPs 仍是二次**。稀疏注意力放弃「每个 query 看全体 key」，但仍走 softmax。线性路线换的是 **相似度本身**：能结合律重排，或根本不做 $q^\top k$。本篇是 **地图**：钉住「谁换核、谁近似 softmax、谁通道衰减、谁还留着 softmax」，长公式与表在 [2.3.4 §5](../2.3.4-高效注意力全景综述/2.3.4-高效注意力全景综述.md)；2026 通道级 delta 门在 [01-KDA](./01-Kimi-Delta-Attention-KDA/01-Kimi-Delta-Attention-KDA.md)。**不是**把第 14 章厂商文再抄一遍。

**反例**：MiniMax-M2 系列在生产规模上退回全层 softmax+GQA，论文写明不再用 Text-01 的 Lightning 混合（[arXiv:2605.26494](https://arxiv.org/abs/2605.26494) §2.2.2）。Lightning / 4M 窗口留在 Text-01，不要写进 M2 文件夹当架构。

## 1. 卡住的瓶颈：softmax 分母绑死整行

标准注意力（记号沿用 [01-MHA](../../2.2-基础注意力机制/2.2.2-多头注意力变体/01-MHA-多头注意力的标准形式/01-MHA-多头注意力的标准形式.md)）

$$
O=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V. \tag{1}
$$

分母 $\sum_l\exp(S_{il})$ 要看整行 $n$ 个元素。$(QK^\top)V$ 因此不能重排成 $Q(K^\top V)$。序列从 4K 拉到 128K，分数矩阵按 $n^2$ 涨；decode 还要把历史 $K,V$ 再读一遍。

三条不要揉成一句「更快的 attention」：

1. **硬件精确注意力**（[2.3.1](../2.3.1-硬件高效注意力/2.3.1-硬件高效注意力.md)）：语义仍是式 (1)，改 IO。
2. **稀疏 / 驱逐**（[2.3.2](../2.3.2-稀疏与压缩注意力/2.3.2-稀疏与压缩注意力.md)）：仍是 softmax，只少看一部分 key，或少搬一部分 KV。
3. **本夹**：改 $\mathrm{sim}(q,k)$，或改成通道衰减 / 状态空间，让逐步代价不随已生成长度涨。

## 2. 年表：谁在分解 softmax，谁根本没碰

| 年份 | 方法 | 实际在做什么 | 不是 |
| --- | --- | --- | --- |
| 2020 | Linear Transformer（Katharopoulos et al.，[2006.16236](https://arxiv.org/abs/2006.16236)，ICML 2020） | 换非负 $\mathrm{sim}(q,k)=\phi(q)^\top\phi(k)$，$\phi=\mathrm{elu}+1$；外积 $\phi(k)v^\top$ 累进 $S$，另累 $Z$ | **没有**分解 softmax。指数核特征无限维 |
| 2020 | Performer / FAVOR+（Choromanski et al.，[2009.14794](https://arxiv.org/abs/2009.14794)，ICLR 2021） | 正随机特征近似 softmax 核 $\exp(q^\top k)$ | 不是三角 $\sin/\cos$ RFF |
| 2021 | RFA（Hao Peng et al.，[2103.02143](https://arxiv.org/abs/2103.02143)，ICLR 2021） | 三角 RFF + 先把 $Q,K$ 单位化；可选 RFA-Gate | **不是** Performer，**不是** Bo Peng 的 RWKV。`2006.11239` 是 DDPM |
| 2021 | AFT（Zhai et al.，[2105.14103](https://arxiv.org/abs/2105.14103)） | pairwise $w$ 加权逐元素 $K,V$，再 $\odot\sigma(Q)$ | **没有** $QK^\top$。AFT-full 时间仍可二次，**不是** RNN |
| 2020 | Linformer | 沿序列投影 $K,V$，**softmax 还在** | 不是 $O(n)$ 核线性化 |
| 2023 | RWKV-4（Bo Peng et al.，[2305.13048](https://arxiv.org/abs/2305.13048)） | 把 AFT 的 pairwise $w$ 换成 **通道级**时间衰减，写成 RNN | **不是** 2021；**没有** $q^\top k$；RWKV-4 **已经是** RNN |
| 2023 | Mamba（Gu & Dao，[2312.00752](https://arxiv.org/abs/2312.00752)） | 输入依赖的选择性 SSM | 不是 elu 核，也不是 WKV |
| 2024 | Mamba-2（Dao & Gu，[2405.21060](https://arxiv.org/abs/2405.21060)） | SSD：选择性 SSM $\leftrightarrow$ 结构化线性注意力 | 不要写成「5/6 才变成递归」那种 RWKV 误读的平行句 |
| 2024–25 | Gated DeltaNet → KDA | delta 擦写 + 遗忘门；KDA 把门做到通道对角 | 头级 $\alpha_t$ **不是** $\mathrm{Diag}(\boldsymbol{\alpha}_t)$ |

**RFA ≠ Performer ≠ RWKV。** 同年 ICLR 的两篇（Performer / RFA）都在用随机特征把指数核写成内积，特征族相反：FAVOR+ 用正特征，并写明三角 RFF 不适合当注意力核；RFA 走三角 + 单位化。RWKV 的作者是 **Bo Peng**，论文是 2023 的 2305.13048，祖先是 AFT 不是 FAVOR+。

## 3. 换核：Linear Transformer 累 $S$ 和 $Z$

2006.16236 §3.2.1：指数核的特征映射是 **无限维**。他们不分解 softmax，只换任意非负相似度（同一个 $\phi$）。论文式 (4)–(5)：

$$
V'_i=\frac{\phi(Q_i)^\top\sum_j\phi(K_j)V_j^\top}{\phi(Q_i)^\top\sum_j\phi(K_j)},\qquad \phi(x)=\mathrm{elu}(x)+1. \tag{2}
$$

分子状态 $S=\sum\phi(K)V^\top$（**外积**，不是 $\phi(k)^\top v$ 那个会缩成标量的写法），还要单独累加 $Z=\sum\phi(K)$。丢掉 $Z$，输出就不是加权平均。因果时 $S_i,Z_i$ 对长度 $N$ 常数时间更新；每步 $\mathcal{O}(d^2)$，**不是**把 FLOPs 写成 $O(1)$。「常数」指 **不随已生成长度涨**。

**4000× 接在语言模型上会漂。** 摘要「最高约 4000×」来自 CIFAR-10 **逐像素**（Table 2：**4462×** images/sec）。MNIST Table 1：**317×**。没有「64K 吞吐量仍 85%」这张表。展开、反向常数显存、复制符号任务，见 [2.3.4 §5.1.1](../2.3.4-高效注意力全景综述/2.3.4-高效注意力全景综述.md)。

## 4. 近似 softmax 核：Performer 正特征，RFA 三角特征

Performer 的 FAVOR+ 才是「用有限正特征去碰 $\exp(q^\top k)$」。Lemma 1 是正随机特征的无偏恒等式；三角 $\sin/\cos$ 在分数接近 0 时方差爆炸，论文明确说 **不适合当注意力核**。实用复杂度 $O(Lmd)$，$m$ 是特征数。展开见 [2.3.4 §5.2.1](../2.3.4-高效注意力全景综述/2.3.4-高效注意力全景综述.md)。

RFA 与 Performer **并发**。分歧：

| | RFA | Performer FAVOR+ |
| --- | --- | --- |
| 特征 | Rahimi–Recht 三角 RFF，维 $2D$ | $\phi(x)\propto\exp(\omega^\top x-\|x\|^2/2)$，再正交 |
| 方差对策 | 先 $\ell_2$ 单位化 $Q,K$，再学温度 | 正特征；三角被明确排除 |
| 额外件 | 可选 RFA-Gate：因果状态乘 sigmoid 门 | 无这套门 |
| 作者 | Hao Peng | Choromanski et al. |

RFA 的 12× 是 2048 greedy 解码模拟，不是 2006.16236 的 CIFAR 4000×。表与式见 [2.3.4 §5.2.2](../2.3.4-高效注意力全景综述/2.3.4-高效注意力全景综述.md)。

## 5. 不做 $QK^\top$：AFT 与 RWKV-4

**AFT** 式 (2)：学到的 pairwise $w$ 加权逐元素 $K,V$，再乘 $\sigma_q(Q)$（默认 sigmoid）。**没有** $QK^\top$，也 **不是** $\phi(q)^\top\phi(k)$。AFT-simple 时间 $O(Td)$；AFT-full 时间仍 $O(T^2d)$，省的是不存注意力矩阵。pairwise $w$ 绑死序列长 $T$，AFT-full **不能直接当 RNN**。见 [2.3.4 §5.1.4](../2.3.4-高效注意力全景综述/2.3.4-高效注意力全景综述.md)。

**RWKV-4** 把 AFT 的 $w_{t,i}$ 换成通道级衰减 $w_{t,i}=-(t-i)w$，才能写成 RNN。WKV 是 **逐通道**加权（论文式 (16)），**没有** query-key 点积。$r$ 只出现在后面的 $\sigma(r)\odot wkv$，再乘 $W_o$。token-shift 是逐维 $\mu\odot x_t+(1-\mu)\odot x_{t-1}$，不是标量 $\mu x_t$。

Appendix D 已经是 RNN（分子 $a$、分母 $b$）：

$$
a_t=e^{-w}\odot a_{t-1}+e^{k_t}\odot v_t,\qquad b_t=e^{-w}\odot b_{t-1}+e^{k_t}. \tag{3}
$$

**RWKV-4 就已经是 RNN**，不要写成「5/6 才改成递归」。Table 1：推理时间 $O(Td)$、空间 $O(d)$。一层训练主项仍是投影 $O(BTd^2)$；WKV 扫描 $O(BTd)$。矩阵值状态是 RWKV-5/6，**不在** 2305.13048。展开见 [2.3.4 §5.1.2](../2.3.4-高效注意力全景综述/2.3.4-高效注意力全景综述.md) 与 [2.4.4](../../2.4-前沿架构与变体/2.4.4-线性RNN与Griffin/2.4.4-线性RNN与Griffin.md)。

## 6. 选择性 SSM：Mamba 把 $A,B,C,\Delta$ 做成输入的函数

连续 SSM $\dot h=Ah+Bx$、$y=Ch$。Mamba 把离散化步长 $\Delta$ 以及 $B,C$ 写成 $x_t$ 的函数，每个 token 自己的遗忘 / 写入 / 读取。这不是 elu 核，也不是 RWKV 的 $w$。Mamba-2 的 SSD 把选择性 SSM 和带结构化掩码的线性注意力对上，块内可并行。工业混合（Jamba 等）和失效模式见 §8–§9；SSM 公式不在本篇重推。

## 7. 2026：delta 擦写之后，遗忘做到通道上

加法记忆 $S_t=S_{t-1}+k_tv_t^\top$ 会涨、会串。Delta 规则先按当前 key 擦再写。Gated DeltaNet 再乘 **头级**标量 $\alpha_t$。KDA 把 $\alpha_t$ 换成 $\mathrm{Diag}(\boldsymbol{\alpha}_t)$：每个特征维自己的衰减，擦写仍是 rank-1。

Kimi Linear 用 **3 层 KDA : 1 层 MLA**，不要和 Qwen 的 **3 层 GDN : 1 层全注意力 / QSA** 混积木。K3 对 log-decay 加 $g_{\min}=-5$、输出门改满秩——**只写在** [01-KDA §5](./01-Kimi-Delta-Attention-KDA/01-Kimi-Delta-Attention-KDA.md)，不要倒灌进 *Kimi Linear* 论文。也不要和 [AttnRes](../../2.2-基础注意力机制/2.2.2-多头注意力变体/Kimi-Attention-Residuals-深度维注意力聚合.md)（深度维残差聚合）或 QSA（softmax 块稀疏）缠名。

> 图 1：线性路线省掉的是显式 $QK^\top$，换来的是状态压缩。工业上常见的是混合，而不是纯替换。2026-08 自绘（浅色，保留）。

**图 1 解析**

- **左上**：标准 softmax 要物化 $n\times n$；右边那条「$\phi(Q)\,(\phi(K)^\top V)$」是 **能结合律重排** 的示意。Katharopoulos 用的是 $\phi=\mathrm{elu}+1$ 换核，**不是**把 softmax 核分解成有限特征。Performer 才走随机特征去碰 $\exp(q^\top k)$。
- **右上**：FAVOR+ / 核映射。正特征那条是 Performer；三角 RFF + 单位化是 RFA，不要画成同一个 $\phi$。
- **左下**：RWKV 是通道衰减状态，不是 $q^\top k$；Mamba 是输入依赖的 $A_t,B_t,C_t$。两者都不是 Linear Transformer 的 $(S,Z)$。
- **右下**：纯二次 / 纯线性 / 混合。生产里 MiniMax-M2 退回 softmax（文首反例）；Kimi Linear 走 3:1 KDA+MLA，见 [01-KDA](./01-Kimi-Delta-Attention-KDA/01-Kimi-Delta-Attention-KDA.md)。

## 9. 工业：混合是默认，退回 softmax 也是数据

| 方向 | 例子 | 钉住的一句 |
| --- | --- | --- |
| 线性 + 标准层混合 | Jamba（Mamba 与 Transformer 交替）、Kimi Linear（3:1 KDA:MLA）、Qwen3-Next（3:1 GDN:全注意力/QSA） | 日程形状可以像，**门和全局层不是同一块积木** |
| 纯线性 / 纯 SSM | Falcon Mamba、RWKV 开源档 | 长程精确检索往往先露馅 |
| 生产退回 softmax | MiniMax-M2 全层 GQA | Lightning 留在 Text-01，见文首 |

短序列（$<2$K）高并发：标准 Transformer + FlashAttention 仍常更划算——线性 kernel 的固定开销摊不掉。需要「这一问回头看那一针」时，线性状态是摘要，不是满 KV。

## 10. 失效模式

| 场景 | 原因 | 不要做的事 |
| --- | --- | --- |
| 检索 / 多跳 | 历史被压进固定大小状态 | 用 PG-19 PPL 打包票 NIAH |
| 把 Katharopoulos 写成分解 softmax | 指数核无限维 | 把 4000× 接到语言建模吞吐 |
| 把 RWKV 写成 $r^\top k$ | 那是 softmax | 把 2021 / $O(d^2)$ 矩阵状态写进 2305.13048 |
| 把 RFA 写成 Performer | 特征族相反 | 把 12× 和 CIFAR 4000× 拧成一句 |
| 把 AFT 写成线性 RNN | AFT-full 仍二次、无 $QK^\top$ | 和 RWKV 互换公式 |
| 头级 GDN 冒充 KDA | 遗忘粒度不同 | 把 $g_{\min}=-5$ 写进 Linear 论文 |
