# 2.3.5 MLA：为什么还挂在 2.3

MLA（Multi-Head Latent Attention）把推理时要缓存的 KV **从满秩头向量换成低维潜向量** $c^{KV}$（外加解耦 RoPE 键 $k^{R}$）。它卡住的瓶颈是 **每 token 的 KV 字节**，不是 $N\times N$ 注意力核怎么在 SRAM 里跑。

公式、解耦 RoPE、坐标展开与数值走查在 [2.2.2/04 MLA：低秩潜变量](../../2.2-基础注意力机制/2.2.2-多头注意力变体/04-MLA-低秩潜变量与解耦式注意力/04-MLA-低秩潜变量与解耦式注意力.md)。Prefill 非吸收 / Decode 吸收两套图是否代数等价，在 [2.2.2/05 矩阵吸收双版本](../../2.2-基础注意力机制/2.2.2-多头注意力变体/05-MLA矩阵吸收与非吸收双版本/05-MLA矩阵吸收与非吸收双版本.md)。本页只回答一件事：**2.3 为什么还挂 MLA**——它改的是 KV **表示**，FlashAttention / 稀疏 / 线性改的是注意力 **算子**。

不是专栏转写，也不是把第 14 章 DeepSeek 精读再抄一遍。

## 1. 表示 vs 算子

| 子专题 | 改什么 | 不改什么 |
|--------|--------|----------|
| 2.3.1 FA / Paged | 核 IO、分页块表 | Q/K/V 仍是 MHA 形对象 |
| 2.3.2 稀疏 | 连哪些边 | 选中的边仍是 softmax 注意力 |
| 2.3.3 线性 | 核函数 / 递推状态 | 不是低秩 KV cache |
| **2.3.5 MLA** | **cache 里存什么** | 训练时仍是多头；核可以仍走 FA |

2.3 的前四块都在问「同样的 $QK^{\top}$，怎么少搬、少连、少平方」。MLA 问的是另一句：**推理时是否必须缓存与训练时同形的高维 $k_t,v_t$？** DeepSeek-V2 的答案是不必——联合压到 $c^{KV}$，只 cache $c^{KV}$ 与 $k^{R}$。

![MLA：只缓存潜向量 $c_{KV}$，注意力前再重建 K/V](./images/fig-mla-kv-latent-cache.png)

> 图 1：缓存的是 $c_{KV}$，不是满秩 K/V。下投影 $W^{DKV}$、上投影 $W^{UK}/W^{UV}$ 的矩阵式见 [04 式与图 2](../../2.2-基础注意力机制/2.2.2-多头注意力变体/04-MLA-低秩潜变量与解耦式注意力/04-MLA-低秩潜变量与解耦式注意力.md)。

**图 1 解析**

- 左：$h_t$ 经 $W^{DKV}$ 进入虚线框 **Latent Cached**。
- 框内只有 $c_{KV}$：decode 持久化的是这一截，不是每头一份 $k,v$。
- 右：算分前再升维出 $K_t,V_t$，与 $Q_t$ 做 Attention。升维可以显式做（非吸收）或吸进 Q/O（吸收），分叉在 [05](../../2.2-基础注意力机制/2.2.2-多头注意力变体/05-MLA矩阵吸收与非吸收双版本/05-MLA矩阵吸收与非吸收双版本.md)。

DeepSeek-V2 Table 9：同规模 MoE 下，MLA 相对 MHA 的 KV cache 约 **4%–14%**。吞吐提升不全是 MLA，MoE 稀疏激活也占一份。

## 2. 不是 MQA

MQA 把 KV **份数**收到 1，cache 里仍是满维 $d_h$ 的 $k,v$。MLA 把 KV **维度**收到 $d_c$，cache 里是更短的 $c^{KV}$ 外加解耦的 $k^{R}$；多头还在，体现在 $W^{UQ}$ 与 per-head 打分。GQA 是份数插值（$G$ 组），压缩比被组数锁死。

| 机制 | 压缩手段 | 每 token cache（量级） |
|------|----------|------------------------|
| MHA | 无 | $2 n_h d_h$ |
| MQA | 份数 → 1 | $2 d_h$ |
| GQA | 份数 → $G$ | $2 G d_h$ |
| MLA | 维度 → $d_c$ | $d_c + d_h^{R}$ |

![MHA、GQA 与 MLA 的归档类比](./images/fig-mla-archive-analogy.png)

> 图 2：MHA 每头一座档案柜；GQA 分组共用；MLA 只留一罐 $c^{KV}$，用 $H$ 路上投影现场还原。旧深色稿 `mla_archive_analogy.png` 仍在同夹，不再引用。

**图 2 解析**

- 左栏货架全满：MHA 的内存脚印。
- 中栏半空：GQA 共享，压缩上限仍是 $G$。
- 右栏金罐 + 投影仪：物理上只存 latent；各头的 K/V 是算出来的，不是再写进 cache。

短序列上低秩变换的固定开销可能划不来；RoPE 必须解耦，否则位置旋转会挡住矩阵吸收。这些边界的公式仍在 04 / 05，这里不重推。
