# MTP：一次多看几步，因式分解仍是从左到右

标准自回归每个位置只监督下一个 token。MTP 在训练里加未来若干步的损失，推理时这块可以当投机解码的 draft。它 **不是** 扩散语言模型（[2.4.7](./2.4.7-扩散语言模型DLM指针.md)），也 **不是** JEPA 那种预测表示（[LLM-JEPA](./01-LLM-JEPA：联合嵌入预测架构与自监督表示学习.md)）。投机框架本体在 [6.6.2](../../6-训练与推理优化/6.6-推理框架与高级优化/6.6.2-投机解码/6.6.2-投机解码.md)。

两条 2026 线不要混：**DeepSeek-V4 的 MTP 配置与 V3 相同，不是 EAGLE-3**；**Kimi K3 才把预训练 MTP 微调成 EAGLE-3 风格 draft**。

## 1. Meta 的并行头：条件独立，训完就扔

Gloeckle 等人（[arXiv:2404.19737](https://arxiv.org/abs/2404.19737)）用 $D$ 个独立头并行预测未来 $D$ 个 token。预测 $t_{i+2}$ 时看不见自己对 $t_{i+1}$ 的预测，等于假设未来 token 条件独立。许多实现推理时丢掉这些头，训练目标和部署图不一致。

## 2. DeepSeek-V3：顺序模块，因果链还在

V3 报告：主模型在位置 $i$ 的最终隐状态 $\mathbf{h}_i^0$，与真实（训练）或草稿（推理）token $t_{i+1}$ 的嵌入拼接，送进额外的 Transformer 层 $M_1$，再走 **共享** 输出头预测 $t_{i+2}$：

$$
\mathbf{h}_i^{\prime 1}=M_1\bigl[\mathrm{RMSNorm}(\mathbf{h}_i^0);\,\mathrm{RMSNorm}(\mathrm{Emb}(t_{i+1}))\bigr]. \tag{1}
$$

深度 $D=1$ 时只多预测一步。损失

$$
\mathcal{L}_{\mathrm{MTP}}=\frac{\lambda}{D}\sum_{k=1}^{D}\mathcal{L}_{\mathrm{MTP}}^k,\qquad
\mathcal{L}=\mathcal{L}_{\mathrm{NT}}+\mathcal{L}_{\mathrm{MTP}}. \tag{2}
$$

$\lambda$ 预训练前期 0.3、学习率衰减后改 0.1（V3 / V4 报告同一套）。嵌入层与输出头共享；MTP 的 Transformer 层和 RMSNorm 独立。

## 3. V3 报告里能核对的数

小 MoE 消融（推理时丢掉 MTP 模块，对比训练信号）：HumanEval 20.7 → **26.8**，GSM8K 25.4 → **31.4**（V3 Table 4）。大模型增益更温和。

推理当 draft：第二 token 接受率 **85%–90%**，报告写解码 **1.8× TPS**。这是 V3 自己的 serving 数字，**不是** K3 的加速比。本篇不编 K3 投机倍数。

## 4. V4：原样保留，不是 EAGLE-3

V4 系列报告写明：保留 DeepSeekMoE 与 MTP；**MTP 配置与 V3 相同、不做修改**。Flash / Pro 预训练里 $\lambda$ 仍是大部分时间 0.3、学习率衰减开始改 0.1。系统栈点名 EAGLE 投机解码，那是 **serving 组件列表**，不是改 MTP 公式。不要写成「V4 改用 EAGLE-3」。精读：[14.1 V4](../../14-主流开源模型全景解析与技术报告精读/14.1-DeepSeek/10-DeepSeek-V4/01-DeepSeek-V4技术报告精译.md)。

## 5. K3：冻住目标，把 MTP 微调成 EAGLE-3 draft

Kimi K3 预训练仍有一块 MTP backbone。后训练 **冻住目标模型**，把这块微调成 EAGLE-3 风格草稿：直接预测 token、融合多层特征、训练时把草稿输出喂回（training-time test）。融合的是 AttnRes **第 1、第 4、最后一块**，不是随便抽三层 Transformer。

损失不是 §2 的下一 token CE 再加一项，而是接受质量：

$$
\mathcal{L}_{\mathrm{LK}}=-\log\sum_x \min\bigl(p(x),q(x)\bigr). \tag{3}
$$

温度 1，**不加**额外真值交叉熵。$\sum_x\min(p,q)$ 是一次验证里质量重叠的下界（与 $1-D_{\mathrm{TV}}(p,q)$ 同源）。EAGLE-3 论文（[2503.01840](https://arxiv.org/abs/2503.01840)）本身仍用 token 损失 + training-time test，**没有**写 $\mathcal{L}_{\mathrm{LK}}$。分界：[6.6.2](../../6-训练与推理优化/6.6-推理框架与高级优化/6.6.2-投机解码/6.6.2-投机解码.md)；K3 后训练段：[14.5 D2 §8](../../14-主流开源模型全景解析与技术报告精读/14.5-Kimi/05-Kimi-K3/01-Kimi-K3-架构精译.md)。

## 6. 失效

- 把 MTP 说成「推理不用草稿、一次吐 $k$ 个就结束」。V3/V4 的 MTP **就是**内嵌 draft，仍要验证。
- 把 V4 和 K3 合成一句「2026 都改成 EAGLE-3」。
- 把 1.8× 安到 K3 上。
- DualPipe 首尾同 PP 秩，才能物理共享嵌入/输出头——这是训练布局，不是 MTP 的数学定义。
