# 2.4.3 · Mamba：公式在 SSM 篇，这里讲选型

连续 ODE、ZOH、LTI 卷积核对偶已经写在 [2.4.2](../2.4.2-状态空间模型SSM/2.4.2-状态空间模型SSM.md)。S4 训完 $A,B,C$ 就冻住，无法按内容决定写还是跳。Mamba（Gu & Dao, [arXiv:2312.00752](https://arxiv.org/abs/2312.00752)）只改这一条：**让 $\Delta,B,C$ 变成当前 token 的函数**，并为此换一套硬件感知扫描。本篇不重推式 (1)–(4)。

## 1. 选择：大 $\Delta$ 写入，小 $\Delta$ 跳过

对每个位置 $t$、每个通道：

$$
\Delta_t=\mathrm{softplus}(\mathrm{Linear}_\Delta(x_t)),\quad
B_t=\mathrm{Linear}_B(x_t),\quad
C_t=\mathrm{Linear}_C(x_t). \tag{1}
$$

离散化仍用 2.4.2 的指数，只是每步不同：

$$
\bar A_t=\exp(\Delta_t A),\qquad
\bar B_t\approx\Delta_t B_t, \tag{2}
$$

$$
h_t=\bar A_t h_{t-1}+\bar B_t x_t,\qquad y_t=C_t h_t. \tag{3}
$$

$\Delta_t$ 大：当前输入大幅覆盖状态（写）。$\Delta_t$ 小：状态几乎不动（跳）。论文把 $\bar B$ 的一阶近似写进实现；完整 ZOH 仍是 2.4.2 式 (3)。

![$\Delta_t,B_t,C_t$ 从 $x_t$ 来；大步长写入、小步长跳过](./images/fig-mamba-selection.png)

> 图 1：选择机制。公式在 2.4.2；本图只画「这一 token 写不写进状态」。

**图 1 解析**

- 左：$x_t$ 投影出三个时变参数，不是一套全局滤波器。
- 中上：大 $\Delta$ → 状态被当前 token 覆盖。
- 中下：小 $\Delta$ → 停用词一类可以几乎不扰动 $h$。
- 右：$y_t=C_t h_t$，读出也依赖当前 token。

时变之后 **没有全局卷积核**，FFT 训练路径关掉，必须扫描。

## 2. 硬件感知扫描，不是再写一遍 RNN for 循环

朴素 `for t in range(L)` 会把 $O(BLDN)$ 的状态在 HBM 里倒腾。Mamba 的 fused scan：在 SRAM 里做离散化 + 状态更新，**中间 $h$ 不写回 HBM**，只把 $y$ 写回去。并行前缀扫描（Blelloch）把串行深度打到对数级。这是实现，不是新的 SSM 方程。

Mamba **块**还叠了：扩展投影、因果 depthwise conv（局部）、SiLU 门控、输出投影。块图与伪代码以论文 Figure 3 / 官方 `mamba-ssm` 为准，本篇不贴 200 行参考实现。

## 3. Mamba-2：SSD 对偶，训练改走分块矩阵乘

Mamba-2（Dao & Gu, [arXiv:2405.21060](https://arxiv.org/abs/2405.21060)）证明：带半可分掩码的线性注意力与选择 SSM 是同一件事的两种写法。工程后果是 Prefill / 训练可以切成 block，块内走 Tensor Core 矩阵乘，块间用状态 $h$ 传递。张量并行比 Mamba-1 的纯扫描好切。推理仍可走 $O(dN)$ 状态，**不要**把 SSD 说成「训练也改回 $O(n^2)$ softmax」。

## 4. 和邻居的「不是」

| | 本篇 | 不是 |
|--|------|------|
| 公式 | 2.4.2 的离散化 + 式 (1)–(3) | 再抄一遍 HiPPO 矩阵 |
| 混合层 | Jamba 等把少量 softmax 插进 Mamba 栈 | 本篇发明新算子；地图在 [2.4.5](../2.4.5-新兴架构与混合模型/2.4.5-新兴架构与混合模型.md) |
| 线性 RNN | 通道衰减见 [2.4.4](../2.4.4-线性RNN与Griffin/2.4.4-线性RNN与Griffin.md) | $q^\top k$ 或 RWKV-5 矩阵状态 |
| 精确复制 | 弱于全注意力 | 「Mamba 已经替代 Transformer」 |

Jamba（[arXiv:2403.19887](https://arxiv.org/abs/2403.19887)）：约每 8 层里 7 层 Mamba、1 层注意力，52B / 12B 激活。KV 只在注意力层涨。数字以该论文为准；不要把 256B 总参安到初代 Jamba 上。

## 5. 失效

- 上下文检索 / 拷贝粘贴：状态压缩是有损的，工业上用混合层兜底。
- $\Delta$ 分支异常值大，粗暴 W8A8 容易崩——量化要单独对待，本篇不编 INT4 表。
- 逐步解码的状态是整块张量，不能直接套 PagedAttention 的 KV 页；serving 要 PagedState 一类 gather/scatter，细节不在本篇展开。
