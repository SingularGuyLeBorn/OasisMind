# 2.4.5 · 混合架构：线性层 + 稀疏/全注意力，不要发明第三种算子

没有任何一种序列核同时做到：局部精确匹配、长程低成本、推理状态不随 $n$ 涨。混合架构的答案是 **编排已有积木**，不是再造一个名字。公式分别住在：[2.4.2 SSM](../2.4.2-状态空间模型SSM/2.4.2-状态空间模型SSM.md)、[2.4.3 Mamba](../2.4.3-Mamba系列/2.4.3-Mamba系列.md)、[2.4.4 RWKV / Griffin 入口](../2.4.4-线性RNN与Griffin/2.4.4-线性RNN与Griffin.md)、[2.3.3 线性注意力 / KDA](../../2.3-高效与稀疏注意力/2.3.3-线性注意力机制/2.3.3-线性注意力机制.md)、[2.3.2 稀疏与压缩](../../2.3-高效与稀疏注意力/2.3.2-稀疏与压缩注意力/)。本篇是地图。

![多数层走线性 / SSM / GLRU；少数层保留 softmax，KV 只在这些层涨](./images/fig-hybrid-linear-sparse-attn.png)

> 图 1：混合的最小图画。左注针对绿层：状态 $O(d)$，不随已生成长度涨；橙层仍有 KV，只是层数少。不要把整栈都画成无 KV。

**图 1 解析**

- 绿层：递推或线性核，逐步推理状态与已生成长度无关（投影仍是每步 $O(d^2)$ 量级）。
- 橙层：全量或局部 softmax，负责精确查找；KV Cache 只在这些层增长。
- 底栏：混合是排积木。mHC、CSA/HCA、MLA 是 **层内通路** 的另一类混合，见下表，不要画进这张「层间交错」图里冒充新算子。

## 3. 量化骨干不是混合层

BitNet b1.58（[2402.17764](https://arxiv.org/abs/2402.17764)）改的是 **权重网格**，拓扑仍是 Transformer（或你插进去的那种层）。不要和 Jamba 的层交错算成一类。MoE 量化见 [09](../2.4.1-混合专家模型MoE/09-MoE模型量化技术综述.md)。

xLSTM（[2405.04517](https://arxiv.org/abs/2405.04517)）是 LSTM 记忆升级，不是 SSM。需要公式时读论文，本篇不编 sLSTM/mLSTM 对照表。

## 4. 失效（混合特有）

- 线性层与注意力层输出尺度不一致，交接处 softmax 饱和 → 过渡点加 RMSNorm / 预热，见各模型报告，不要抄成万能超参。
- 把 MiniMax-M2 写成 Lightning 混合。
- 把 V4 的 CSA/HCA 公式再抄一遍冒充「新兴架构」——那是注意力章的事。
- 用本篇的示意 FLOPs 表（旧稿那张 45 tok/s）当基准：已删，数字回各论文 Table。
