# 2.1.4 位置编码 (Positional Encoding - RoPE, ALiBi)

自注意力的分数 $q_m^\top k_n$ 只看内容. 把输入里两个 token 对调, 输出只是跟着对调, 模型不知道顺序变了. 位置编码负责把「第几个」和「相距多远」注入进去. 各种方案的分歧在于位置信息加在哪一层: 正弦和可学习编码加在输入端, Shaw 和 Transformer-XL 加在打分的展开项里, T5 和 ALiBi 加在 logits 上, RoPE 以旋转的形式乘在投影后的 $q,k$ 上. 现在的开源 LLM 基本都用 RoPE, 本节两篇都围绕它展开.

## 本节回答的问题

1. 一个好的位置编码应满足什么条件, 加性的绝对编码和相对编码各差在哪?
2. RoPE 怎样从「内积只依赖相对距离」这个条件推导出来, 频率 $\theta_i=10000^{-2i/d}$ 和正弦编码是什么关系?
3. 远程衰减到底衰减的是什么, 相邻维配对和前后半配对两种实现为什么权重不能混用?
4. RoPE 为什么不能直接外推, PI, NTK-aware, YaRN 各自补上了哪个缺口?
5. 图像和视频的位置怎么编码 (M-RoPE), RoPE 和 MLA 的低秩 KV 压缩为什么冲突?
6. 工程上哪些地方会静默出错: 精度, KV Cache, 位置编号?
