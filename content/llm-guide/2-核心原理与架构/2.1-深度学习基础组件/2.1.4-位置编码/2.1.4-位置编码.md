# 2.1.4 · 位置编码

自注意力的分数 $q_m^\top k_n$ 只看内容. 不加因果掩码时, 把输入里两个 token 对调, 输出只是跟着对调, 模型不知道顺序变了. 位置编码负责把「第几个」和「相距多远」注入进去. 2017 年以来的方案很多, 分歧主要在位置信息加在注意力计算的哪一层, 以及它表达的是绝对位置还是相对距离.

这一节两篇文章都围绕 RoPE. [01 RoPE 本体](./01-RoPE本体-旋转位置编码/01-RoPE本体-旋转位置编码.md) 从其他方案的局限出发, 推导旋转形式, 讲它的相对位置性质, 远程衰减和两种实现; [02 RoPE 扩展](./02-RoPE扩展-长上下文,多模态与工程实现/02-RoPE扩展-长上下文,多模态与工程实现.md) 处理 RoPE 用到训练分布之外时的问题: 更长的序列, 二维和三维的位置, 与低秩 KV 压缩的冲突, 以及数值精度.

## 1. 位置信息加在哪一层

### 1.1 置换等变

设 $P$ 是置换矩阵, 不加掩码和位置信息时 $\mathrm{Attention}(PX)=P\cdot\mathrm{Attention}(X)$, 推导见 [2.2.1 自注意力机制](../../2.2-注意力机制/2.2.1-自注意力机制/2.2.1-自注意力机制.md) 第 3.3 节. 「狗咬人」和「人咬狗」里, 「咬」这一行的输出完全相同. FFN 和归一化是逐位置操作, 同样对顺序等变, 所以整个没有位置信息的 Transformer 编码器都不区分顺序.

因果掩码会打破这种对称: 位置 $i$ 只能看到 $i$ 个 token, 模型可以近似数出自己前面有多少个可见 token. 不加任何位置编码的因果语言模型困惑度与带位置编码的模型相差不大, 而双向的掩码语言模型去掉位置编码后训练不收敛. 尽管如此, 主流 decoder-only 模型仍然显式地加位置编码, 相对距离信息由编码直接提供, 比让模型自己从掩码里推出来可靠.

### 1.2 四类注入点

| 方案 | 位置信息加在哪 | 表达的是 | 代表 |
|:----|:-------------|:--------|:----|
| 正弦 / 可学习绝对编码 | 输入嵌入上, 加法 | 绝对位置 | 原始 Transformer, BERT, GPT-2 |
| Shaw / Transformer-XL | 打分展开式里的 Key, Value 项 | 相对距离 (查表或正弦) | Transformer-XL |
| T5 偏置 / ALiBi | softmax 之前的 logits, 加法 | 相对距离的标量 | T5, BLOOM |
| RoPE | 投影后点积前的 $q, k$, 乘法 (旋转) | 绝对位置的旋转, 点积里只剩相对距离 | LLaMA, Qwen, DeepSeek 等 |

前三行都可以看作对打分公式 $q_m^\top k_n$ 的修改, 区别在修改的深度. 绝对编码把 $p_m$ 加到输入上, 展开后的四项里有内容-内容, 内容-位置和位置-位置三类交叉项, 相对距离只能由模型从中间接学出; 相对编码直接把绝对位置换成 $m-n$; T5 和 ALiBi 把位置压成每对距离一个标量偏置, ALiBi 连可学习参数都不要, 每个头按预设斜率线性减去距离.

01 第 1.3 节总结了相对编码这一族的三处代价: 要改写打分公式, FlashAttention 一类内核要为附加项单独支持; 依赖「先加后展开」的结构, 和不存在完整分数矩阵的线性注意力不兼容; 标量偏置只影响分数的大小, 不和内容向量的方向发生作用. RoPE 换了一个位置, 作用在投影之后, 点积之前, 而且是乘性的, 这三处代价因此都不存在.

## 2. RoPE 的记号与三条性质

### 2.1 旋转与频率谱

把 $d$ 维的 $q, k$ 两两分成 $d/2$ 个二维平面, 第 $i$ 个平面以频率 $\theta_i=b^{-2i/d}$ 旋转, base $b$ 默认取 10000. 位置 $m$ 的 Query 在第 $i$ 个平面上转过角度 $m\theta_i$, 写成块对角旋转矩阵 $R_m$. 由旋转矩阵的性质 $R_m^\top R_n=R_{n-m}$:

$$
(R_m q)^\top (R_n k)=q^\top R_{n-m}\,k \tag{1}
$$

分数只依赖相对距离 $n-m$, 绝对位置在点积里相消. 第 $i$ 个平面的波长是 $\lambda_i=2\pi/\theta_i$, $i=0$ 的波长是 $2\pi$, 最慢的 $i=d/2-1$ 接近 $2\pi b$. 两篇共用这套记号: $d$ 为头维度, $i$ 为平面下标, $L$ 为训练长度, $s$ 为扩展倍数.

01 第 2 节从「内积只依赖相对位置」这个条件出发, 在二维上解出旋转形式, 再推广到 $d$ 维, 并给出一个手算例子. 第 5.1 节说明 RoPE 和正弦编码的频率谱完全相同, 区别是正弦编码把 $\sin, \cos$ 加到输入上, RoPE 把它们乘在 $q, k$ 上, 所以只有后者在点积里给出严格的相对位置.

### 2.2 远程衰减和两种配对

RoFormer 说取 $\theta_i=10000^{-2i/d}$ 时内积随相对距离增大而衰减. 01 第 3.4 节用 Abel 变换重做了这个推导, 并说明三层边界: 衰减的是分数的上界, 分数本身还乘着由学到的 $q, k$ 决定的系数; 衰减不单调, 距离 5000 处的上界比距离 1000 处还大; Chen 等人 (2023) 指出这个上界很松, 用同形式的三角级数在 $[0,2048]$ 上拟合, 区间外的值可以超过 8000. 这条最后会变成第 3 节外推失效的原因.

实现上有两种维度配对: Meta 原版 Llama 把相邻两维看成一个复数 (交错配对), HF transformers 把前后两半配对. 两者差一个置换, 表达能力完全相同, 但权重不能直接互相加载. 拿错布局加载不会报任何形状错误, 模型照常运行, 只是每个平面配错了维度, 输出变成乱码. 01 第 4.3 和 4.4 节给出证明和同时实现两种配对的代码.

## 3. 训练长度之外

### 3.1 越界的是低频平面

式 (1) 对任意整数位置都有定义, 这不等于模型在训练长度之外表现正常. Chen 等人 (2023) 的表 1: 预训练窗口 2048 的 LLaMA 7B, PG19 上 2048 窗口困惑度 7.20, 拉到 4096 及以上全部超过 $10^3$. 原因可以从频率谱算出来: 第 $i$ 个平面在训练中见过的最大角度是 $L\theta_i$, 波长大于 $L$ 的平面连一圈都没转满, 超出 $L$ 后出现从未见过的角度. $d=128$, $b=10000$, $L=2048$ 时这样的平面有 23 个, 最慢的那个只转过 0.24 弧度.

高频平面在训练中已经转过数百圈, $i=0$ 在 2048 个 token 内转了约 326 圈, 任何角度都见过. 所以越界的是低频平面, 高频平面在长序列上并不缺角度. 01 第 5.2 节给出这个算例, 02 第 1 节从这里接着讲: 模型只在 $[0,L]$ 上约束过式 (1) 的三角级数, 区间外的值可以任意大, 分数一旦越界就会爆掉.

### 3.2 从 PI 到 YaRN

02 第 2, 3 节按顺序讲四种修补, 每一步补上一步的缺口. PI 把位置除以 $s$, 全部压回训练区间, 越界消失但高频平面也被压了 $s$ 倍, 扩到 8192 不微调困惑度 16.10, 微调 200 步后 7.12. NTK-aware 不动位置, 只把 base 改成 $b'=b\cdot s^{d/(d-2)}$, 高频几乎不动, 但中间一部分平面压得不够, 仍有少量越界. NTK-by-parts 按每个平面在训练长度内转过的圈数分三段: 转了很多圈的不插值, 不满一圈的完全按 PI 插值, 中间两者混合. YaRN 再加一个与 $s$ 有关的温度, 修正长窗口下注意力的熵.

YaRN 的标准结果是微调过的: Llama 2 7B 用 64k 长的数据训练, $s=32$ 的模型在 131072 窗口困惑度 2.37. 不微调的版本是与动态缩放组合的 Dynamic-YaRN, 能力是扩展 2 倍以上. 四种方法都只改 $\cos, \sin$ 表, 推理时没有额外计算. 训练阶段直接用大 base 是另一条路, Code Llama 把 base 设为 $10^6$, Llama 3 预训练时就设成 500000. 这一节只讲改位置编码本身; 在注意力计算上分块处理长序列的 DCA 和 S²-Attn 在 [2.7.1 长度外推](../../2.7-长上下文与外推技术/2.7.1-长度外推/2.7.1-长度外推.md).

## 4. 多模态, 低秩缓存与数值精度

### 4.1 M-RoPE 与解耦 RoPE

图像 patch 按行展平再用一维 RoPE, 水平相邻的两个 patch 距离为 1, 垂直相邻的却等于每行 patch 数, 视频相邻帧之间还隔着一整帧. Qwen2-VL 的 M-RoPE 把旋转拆成时间, 高, 宽三个分量, 每个 token 有一组三元位置; 文本三个分量取同一编号, 此时与一维 RoPE 完全相同. 02 第 4.2 节手算了一张 224×224 的图消耗多少位置编号.

MLA 把 Key 和 Value 压成一个低维潜变量缓存, 推理时把上投影矩阵合并进 Query 一侧. 内容 Key 带位置旋转时, 旋转矩阵夹在两个矩阵之间, 随位置变化, 合并不了. DeepSeek-V2 让内容部分完全不带 RoPE, 另开一条 $d_h^R=64$ 维的通道, 用所有头共享的一个 Key 承载位置, 每 token 每层缓存 $512+64=576$ 个元素. 02 第 4.4, 4.5 节从位置编码一侧推导这个冲突, MLA 的完整结构见 [2.2.2 多头注意力变体](../../2.2-注意力机制/2.2.2-多头注意力变体/2.2.2-多头注意力变体.md) 下的 03 篇.

### 4.2 精度与 KV Cache

最高频平面 $\theta_0=1$, 角度就等于位置本身, 长上下文下可以到 $10^5$ 弧度. bf16 只有 8 位有效位, 位置在 $[65536,131072)$ 区间时相邻可表示数的间隔是 512, 角度误差最大 256 弧度; fp16 的最大值是 65504, 位置 100000 直接溢出; fp32 下同样的角度误差约 0.006 弧度. 所以位置, 频率, 角度和 $\cos, \sin$ 都要用 float32 算, 算完再转成计算精度, HF 的 `LlamaRotaryEmbedding` 在 forward 里强制这样做.

KV Cache 里通常存的是已经旋转过的 Key, 每个 token 只转一次, 这要求每个位置的旋转角在整个生成过程中不变. 动态缩放每步都改 $s$, 历史 Key 却保留旧 $s$ 下的角度, 正确做法是缓存旋转前的 Key. RoPE 的输入是位置编号, 不是张量下标, 批量推理的左填充, 多文档拼接和多模态的三元位置都要显式传 `position_ids`. 这些错误都不会报错, 只会让输出质量下降, 02 第 5.4 节把它们和长度扩展本身的问题一起列成失效模式表.

## 5. 读法

### 5.1 按目的选篇

第一次读位置编码的读者按顺序读 01: 第 1 节的四类方案对照, 第 2 节推导, 第 3 节性质, 第 4 节实现. 已经熟悉 RoPE 公式, 只想知道长上下文扩展的读者, 读完 01 第 5.2 节就可以进 02 第 1 节, 那里的低频平面算例是 PI, NTK, YaRN 三者的共同出发点.

做模型移植和推理部署的读者, 重点在 01 第 4.3 节的配对布局和 02 第 5 节的精度与缓存问题, 这两处错了都不会报错, 只会让输出质量下降. 关心多模态和 DeepSeek 系列的读者读 02 第 4 节, 再分别接 [8 多模态](../../../8-多模态/8-多模态.md) 和 2.2.2 的 MLA 两篇.

### 5.2 与相邻章节的关系

位置编码是 [2.1 深度学习基础组件](../2.1-深度学习基础组件.md) 里唯一直接改变注意力分数的组件, 与 [2.1.2 归一化层](../2.1.2-归一化层/2.1.2-归一化层.md), [2.1.3 残差连接](../2.1.3-残差连接/2.1.3-残差连接.md) 平行. 它依赖的注意力公式在 2.2.1, 被它影响的长上下文方法在 2.7: 2.7.1 讲推理阶段怎样把模型用到更长的窗口, 2.7.2 的 KV 驱逐方法要处理保留下来的 token 的位置编号.

线性注意力和状态空间模型按顺序递推, 顺序信息由递推本身给出. 混合架构里位置编码只关系到 softmax 注意力层, 而且结论因结构而异: [2.5.5 混合架构](../../2.5-线性注意力与状态空间模型/2.5.5-混合架构/2.5.5-混合架构.md) 记录了 Jamba 的消融, 不用位置编码与用 RoPE 结果相近, 论文的解释是前面的 Mamba 层已经提供了隐式位置; Samba 去掉 RoPE 后 4K 困惑度几乎不变, 到 16K 却升到 314.78. 第一种情况里位置编码可以省掉, 第二种情况里它决定了能不能外推.
