# 02 激活函数谱系：从饱和到软门

激活函数是 position-wise FFN 两层线性中间的非线性 $\phi$：没有它，$W_1$ 与 $W_2$ 塌成一层线性；$\phi$ 两端饱和，梯度在深层里先死。本篇只写 **SwiGLU 之前** 的单路线谱——Sigmoid / Tanh 饱和、ReLU 硬折、GELU / SiLU 软门——给 [2.1.1 节首页](../2.1.1-前馈网络FFN与激活函数.md) 补上「只有 SwiGLU 和 K3」之外的度量零点。不是 GLU 三矩阵（那是 [03 GLU 家族](../03-GLU家族-从GLU到SwiGLU/03-GLU家族-从GLU到SwiGLU.md)），也不写 SiTU / PowLU。

---

## 1. 单路 FFN 里，$\phi$ 在卡什么

设单个 token 的隐藏向量 $x\in\mathbb{R}^{d}$。原版 Transformer 的 position-wise FFN 是两次线性、中间插一个逐元素非线性：

$$
\mathrm{FFN}(x)=\phi(xW_1+b_1)W_2+b_2 \tag{1}
$$

$W_1\in\mathbb{R}^{d\times d_{ff}}$ 升维，$W_2\in\mathbb{R}^{d_{ff}\times d}$ 压回。现代实现常把偏置拿掉，但灵魂仍是中间的 $\phi$：若 $\phi$ 是恒等，两次矩阵乘合成一次，表达能力不升。

本篇的 $\phi$ 都作用在**同一条**隐藏通道上：输入一个标量、输出一个标量，再交给 $W_2$。后面 SwiGLU 的门虽然用的是 SiLU，但那是「另一条线性支路 × 这条门」——结构变了，不是把式 (1) 的 $\phi$ 换成 SiLU。Shazeer (2020) 把单路记成 $\mathrm{FFN}_{\mathrm{ReLU}}$ / $\mathrm{FFN}_{\mathrm{GELU}}$ / $\mathrm{FFN}_{\mathrm{Swish}}$，把门控记成 $\mathrm{FFN}_{\mathrm{SwiGLU}}$；名字差一个词，矩阵数差一块。

下面按失败模式走：先看两端饱和为什么被换掉，再看 ReLU 硬折留下什么，最后看 GELU / SiLU 的软门究竟软在哪。对照曲线见 §5 图 1；数字见 §6，以 Shazeer Table 1 为准，不要先验「GELU 一定比 ReLU 低 perplexity」。

---

## 2. Sigmoid / Tanh：两端饱和，梯度先死

Logistic sigmoid 与双曲正切是早期多层网络的默认非线性：

$$
\sigma(x)=\frac{1}{1+e^{-x}}\in(0,1) \tag{2}
$$

$$
\tanh(x)=\frac{e^{x}-e^{-x}}{e^{x}+e^{-x}}=2\sigma(2x)-1\in(-1,1) \tag{3}
$$

它们的导数有封闭上界，而且在 $|x|$ 大时迅速贴零：

$$
\sigma'(x)=\sigma(x)\bigl(1-\sigma(x)\bigr)\le\frac{1}{4},\qquad
\tanh'(x)=1-\tanh^{2}(x)\le 1 \tag{4}
$$

$|x|\to\infty$ 时两者都 $\to 0$。反向传播里，误差要乘上 $\phi'$ 再传到 $W_1$：预激活一旦落到饱和区，这一层对 $W_1$ 的梯度几乎是零。堆深层时，这个因子连乘，就是教科书里的**梯度消失**。Tanh 零中心、饱和值是 $\pm 1$，通常比 Sigmoid 好训一点，但两端仍是平的——失败模式同类，只是饱和值不同。

原版 Transformer **没有**把 Sigmoid / Tanh 当作 FFN 的主激活。Vaswani et al. (2017) §3.3 写明：每个位置的前馈是两次线性，**中间是 ReLU**。注意力里的归一化是 Softmax，那是另一路算子，不要和 FFN 的 $\phi$ 混为一谈。GLU 原文确实用 $\sigma$ 去乘一条线性，那是门控结构，推导留给 [03](../03-GLU家族-从GLU到SwiGLU/03-GLU家族-从GLU到SwiGLU.md)。

## 3. ReLU：正区间梯度恒 1；原版 Transformer 用它

Rectified Linear Unit：

$$
\mathrm{ReLU}(x)=\max(0,x)=
\begin{cases}
x, & x>0 \\
0, & x\le 0
\end{cases} \tag{5}
$$

正半轴导数恒为 $1$，负半轴导数恒为 $0$。相对式 (4)，只要预激活经常落在正区，梯度就能以因子 $1$ 穿过 $\phi$，不再被饱和函数压成小数。这是 ReLU 能训深网的直接原因（Nair & Hinton, 2010；Glorot et al., 2011）。在 FFN 里，它表现为**硬阈值**：通道为负就整段清零，为正就原样放行，前向 naturally 稀疏。

Vaswani et al. (2017) 式 (2) 把这件事写进 Transformer 本体；Shazeer (2020) 式 (1) 原样引用，再给出无偏置版：

$$
\mathrm{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2 \tag{6}
$$

$$
\mathrm{FFN}_{\mathrm{ReLU}}(x)=\max(xW_1,0)\,W_2 \tag{7}
$$

失败模式也硬。某通道若长期 $xW_1+b_1\le 0$（初始化、学习率、分布漂移任一即可），前向恒 $0$、反向梯度恒 $0$，这个隐藏单元不再更新——**dead ReLU**。宽 FFN 里死掉一小部分通道未必立刻崩，但有效容量在减。原点不可导（工程上取 $x=0$ 处导数 $0$ 或 $1$），对 SGD 通常无妨；真正刺手的是负区梯度被彻底切断，模型没有「稍微负一点就往回拉」的通道。

## 4. GELU：$x\Phi(x)$，按大小加权而不是按符号一刀切

Gaussian Error Linear Unit（Hendrycks & Gimpel, 2016）把 ReLU 的硬指示函数换成标准正态 CDF：

$$
\mathrm{GELU}(x)=x\,\Phi(x)=x\cdot\frac{1}{2}\Bigl[1+\mathrm{erf}\bigl(\tfrac{x}{\sqrt{2}}\bigr)\Bigr] \tag{8}
$$

其中 $\Phi(x)=P(X\le x)$，$X\sim\mathcal{N}(0,1)$。论文的随机动机是：用 $m\sim\mathrm{Bernoulli}(\Phi(x))$ 去乘输入，再取期望，得到 $x\Phi(x)$。ReLU 是 $x\cdot\mathbf{1}_{x>0}$（按**符号**硬门）；GELU 是按「这个值相对高斯有多靠右」做**连续加权**。$x\to+\infty$ 时 $\Phi\to 1$，渐近等于恒等；$x\to-\infty$ 时 $\Phi\to 0$，输出贴零，但途中仍有一段非零导数——负区不是死的。

工程上 $\mathrm{erf}$ 不便宜。同一篇论文给出 tanh 近似（实验里他们用的就是这条），以及一个更快的 sigmoid 缩放：

$$
\mathrm{GELU}(x)\approx 0.5\,x\Bigl(1+\tanh\Bigl[\sqrt{\tfrac{2}{\pi}}\bigl(x+0.044715\,x^{3}\bigr)\Bigr]\Bigr) \tag{9}
$$

$$
\mathrm{GELU}(x)\approx x\,\sigma(1.702\,x) \tag{10}
$$

记住常数不如记住目的：在保留软门的前提下，避开逐点 $\mathrm{erf}$。PyTorch `F.gelu` 默认走精确 $\mathrm{erf}$；GPT 系实现里常见式 (9) 那条 tanh 近似（Hugging Face 称为 `gelu_new`）。两条曲线在常用区间很近，但不是逐点相等，换实现要核对。

BERT 为什么换过来，原文写得很短：用 GELU 而不是 standard ReLU，**following OpenAI GPT**（Devlin et al., 2018）。动机与式 (8) 一致——软门、负区还留一点梯度，优化比硬折更稳。GPT-3 声明与 GPT-2 同一套架构（除层间交替的稀疏注意力；Brown et al., 2020）。本次未打开 GPT-2 PDF；NVIDIA Megatron-LM（Shoeybi et al., 2019）明确写：GPT-2 与 BERT 都用 GeLU，原版 Transformer 才用 ReLU。这一代 dense 语言模型的 FFN 主激活，是 GELU 而不是式 (6)。

GELU 仍然是**逐元素、单路、同一条曲线**。它解决「阈值太硬」，不解决「要不要另开一条支路来决定放行多少」。那一跳是 GLU，不是再换一个 $\phi$。

## 5. SiLU / Swish：后面 SwiGLU 的门是它；单路 FFN 不是 SwiGLU

把式 (8) 里的高斯 CDF 换成 Logistic CDF，就是 Hendrycks & Gimpel 在同一篇 GELU 文里写的 Sigmoid Linear Unit：

$$
\mathrm{SiLU}(x)=x\,\sigma(x) \tag{11}
$$

Ramachandran et al. (2017) 用搜索得到 $x\cdot\sigma(\beta x)$，命名 Swish；$\beta$ 可以是常数或可学习。$\beta=1$ 时 Swish 与 SiLU 是同一个函数。$\beta\to\infty$ 时 $\sigma(\beta x)$ 趋近 $0$-$1$ 阶跃，Swish 趋近 ReLU；$\beta=0$ 时退化为 $x/2$。LLM 里 FFN 与后来的 SwiGLU 门，用的几乎都是 $\beta=1$，也就是式 (11)。PyTorch 入口是 `F.silu`。

SiLU 无上界、有下界、光滑、**非单调**：负半轴有一个浅 bump（大约在 $x\in[-5,0]$）。相对 ReLU，负区梯度不是恒零；相对 GELU，形状接近（Ramachandran 文中写 GELU 外形约等于 $\beta\approx 1.4$ 的 Swish）。Shazeer 把单路 FFN 写成：

$$
\begin{aligned}
\mathrm{FFN}_{\mathrm{GELU}}(x)&=\mathrm{GELU}(xW_1)\,W_2 \\
\mathrm{FFN}_{\mathrm{Swish}}(x)&=\mathrm{Swish}_{1}(xW_1)\,W_2
\end{aligned} \tag{12}
$$

式 (12) 仍是两块矩阵、一条隐藏通道。SwiGLU 的门是 $\mathrm{Swish}_1$，但还要再乘另一条线性、再降维——**单路 SiLU-FFN 不是 SwiGLU**。把 `F.silu` 塞进式 (1) 只是换 $\phi$；多出来的那条门控支路才是下一篇的对象。

![](./images/fig-act-sigmoid-relu-gelu-silu.png)

> 图 1：饱和 → 硬折 → 软门的四条示意曲线（不是论文描点）。左一 Sigmoid / Tanh 两端贴平；左二 ReLU 在原点折断、负轴恒零；右二 GELU 按 $\Phi(x)$ 软加权；右一 SiLU $=x\sigma(x)$，仍是单路。门控 FFN 见 [03](../03-GLU家族-从GLU到SwiGLU/03-GLU家族-从GLU到SwiGLU.md)。

**图 1 解析**

- **画布**：四张白底坐标，横轴预激活 $x$，纵轴 $\phi(x)$。色块只用来分区，不是数据。
- **左一（Sigmoid / Tanh）**：两条 S 形。左右尾巴水平，对应式 (4) 导数贴零。标签 SATURATED 标的就是梯度消失区。Transformer 原论文 FFN **不用**这两条当主激活。
- **左二（ReLU）**：负轴躺平、原点尖折、正轴斜率 $1$。KINK 是硬阈值；DEAD 是 $x\le 0$ 时梯度恒 $0$ 的死区。这是 Vaswani 式 (2) / Shazeer 式 (1) 的 $\phi$。
- **右二（GELU）**：过原点附近被抹圆，负区有浅凹再贴零，正区渐近 $y=x$。SOFT GATE 对应 $x\Phi(x)$：按大小加权，不是按符号一刀切。
- **右一（SiLU）**：形状接近 GELU，负区 bump 更可见。ONE PATH 提醒：这仍是式 (12) 的单路 $\phi$，不是 SwiGLU 的双支路乘积。后面把门换成它，结构才变。
- **不要当论文 Figure 用**：曲线是教学示意，没有误差棒，也没有 Table 1 的 perplexity。数字只信 §6。

## 6. 换 $\phi$ 几乎打平；跳变发生在门控

Shazeer (2020) 在 T5 同款 encoder–decoder（$d_{model}=768$，$d_{ff}=3072$，无 dropout 预训练）上，把式 (7)(12) 与若干 GLU 变体做参数量对齐比较。度量是 C4 span-filling 的 **heldout log-perplexity**，越低越好。Table 1 里与本篇有关的三行：

| 单路 FFN | 65,536 步 | 524,288 步 |
|----------|-----------|------------|
| $\mathrm{FFN}_{\mathrm{ReLU}}$（基线） | 1.997 (0.005) | **1.677** |
| $\mathrm{FFN}_{\mathrm{GELU}}$ | 1.983 (0.005) | **1.679** |
| $\mathrm{FFN}_{\mathrm{Swish}}$ | 1.994 (0.003) | **1.683** |

短训（四次重复，括号是波动）GELU 略好于 ReLU；训满 524288 步后三者几乎打平，ReLU 还略低。**不要编「GELU 一定比 ReLU 低 ppl」**——这张表上没有这件事。Swish 单路甚至略差（1.683）。BERT / GPT 换 GELU，说的是可训性与软门，不是这张 T5 表上的 heldout 必赢。

同一张表里，门控变体把 524288 步打到 $\mathrm{FFN}_{\mathrm{GEGLU}}=1.633$、$\mathrm{FFN}_{\mathrm{SwiGLU}}=1.636$。相对单路 ReLU 的 $1.677$，这才是跳变。原因不是「SiLU 比 ReLU 更光滑」，而是多了一条线性再逐元素相乘。三矩阵怎么写、宽度为什么约 $8d/3$，见 [03](../03-GLU家族-从GLU到SwiGLU/03-GLU家族-从GLU到SwiGLU.md)。

极简对应（只换 $\phi$，仍是两矩阵）：

```python
import math
import torch
import torch.nn.functional as F

def gelu_erf(x: torch.Tensor) -> torch.Tensor:
    return x * 0.5 * (1.0 + torch.erf(x / math.sqrt(2.0)))

def gelu_tanh(x: torch.Tensor) -> torch.Tensor:
    # Hendrycks & Gimpel (2016) tanh 近似，式 (9)
    inner = math.sqrt(2.0 / math.pi) * (x + 0.044715 * x * x * x)
    return 0.5 * x * (1.0 + torch.tanh(inner))

# FFN_ReLU / FFN_GELU / FFN_Swish：down(phi(up(x)))
# F.silu(x) == x * sigmoid(x)  （β = 1 的 Swish / SiLU）
```

`F.silu(up(x))` 再 `down`，名字可以叫 SiLU-FFN / Swish-FFN，不要叫 SwiGLU。

## 7. 失效模式

| 现象 | 原因 | 说明 |
|------|------|------|
| Sigmoid / Tanh 深层训不动 | 两端 $\phi'\to 0$，式 (4) | 原版 Transformer FFN **不是**用它们当主激活 |
| dead ReLU | $x\le 0$ 时前向与梯度皆 $0$ | 宽 FFN 里通道静音；换 GELU / SiLU 是为了负区还留一点梯度 |
| 原点折点「不光滑」 | ReLU 在 $0$ 不可导 | 对 SGD 通常次要；真正的结构限制是硬门 |
| 以为换 GELU / Swish 必降 ppl | Shazeer Table 1 单路几乎打平 | 524288 步：ReLU **1.677**，GELU **1.679**，Swish **1.683** |
| 把 `F.silu` 的两矩阵 FFN 叫成 SwiGLU | 单路 $\phi$ ≠ 双支路乘积 | 门是 SiLU；SwiGLU 还要另一条线性。见 03 |
| 混用 $\mathrm{erf}$ 与 tanh 近似当「同一个算子」 | 式 (8) 与式 (9) 非逐点相等 | 对权重、对数值，不要无声明切换 |

## 8. 本节小结

单路 FFN 的激活沿一条失败模式链换代：Sigmoid / Tanh 两端饱和 → ReLU 正区梯度 $1$、负区死亡 → GELU / SiLU 用 CDF 做软门，负区还留梯度。原版 Transformer 的 FFN 是 ReLU（Vaswani 式 (2)）；BERT / GPT 这一代把 $\phi$ 换成 GELU；SiLU 是后来 SwiGLU 的门，但式 (12) 的 $\mathrm{FFN}_{\mathrm{Swish}}$ 仍是两矩阵。Shazeer Table 1 显示，在对齐参数的 T5 预训练上，换 $\phi$ 几乎不降 heldout log-ppl；降发生在门控。
