## 2. 神经网络基础: 从感知机到反向传播

### 2.1 感知机: 一个带参数的线性判别

要解决的问题是: 给一个 $d$ 维输入, 输出一个可学习的判决. 1958 年 Frank Rosenblatt 提出的感知机给出了最简单的参数化形式. 给定输入 $\mathbf{x} = [x_1, x_2, \dots, x_d]^T \in \mathbb{R}^d$, 权重 $\mathbf{w} \in \mathbb{R}^d$ 给每个输入维度一个系数, 偏置 $b \in \mathbb{R}$ 平移决策边界, 激活函数 $\sigma(\cdot)$ 把线性得分映射成输出:

$$
\hat{y} = \sigma\left( \mathbf{w}^T \mathbf{x} + b \right) = \sigma\left( \sum_{i=1}^{d} w_i x_i + b \right) \tag{1}
$$

$\mathbf{w}$ 决定各输入维度对判决的贡献; $b$ 让决策边界可以不过原点, 没有 $b$ 时无论 $\mathbf{w}$ 怎么调, 边界都被迫经过坐标原点; $\sigma(\cdot)$ 决定输出的形状, 原始感知机用的是阶跃函数.

#### 几何解释: 一个超平面

$\mathbf{w}^T \mathbf{x} + b = 0$ 是输入空间里的一个**超平面(hyperplane)**, 它把空间一分为二, 正样本在一侧, 负样本在另一侧. $\mathbf{w}$ 是超平面的法向量, $|b|/\|\mathbf{w}\|$ 是原点到超平面的距离. 训练感知机就是调整这个超平面的朝向和位置.

#### 局限与多层网络

Minsky 和 Papert 1969 年在 *Perceptrons* 一书中证明, 单个感知机只能解线性可分问题. 异或(XOR)是最小的反例: 四个点 $(0,0), (1,1)$ 为一类, $(0,1), (1,0)$ 为另一类, 平面上找不到一条直线把它们分开.

解决办法是把多个感知机堆叠成**多层感知机(Multi-Layer Perceptron, MLP)**, 并在线性层之间插入非线性激活. 非线性是必要条件: 两个线性层直接相乘, $\mathbf{W}_2(\mathbf{W}_1 \mathbf{x}) = (\mathbf{W}_2\mathbf{W}_1)\mathbf{x}$, 仍是一个线性变换, 堆多少层都等价于一层. 插入非线性之后, [Cybenko (1989)](https://doi.org/10.1007/BF02551274) 和 Hornik (1991) 的万能逼近定理说明, 单隐层足够宽的网络可以在紧集上以任意精度逼近连续函数. 这个定理只保证这样的网络存在, 不保证梯度下降能找到它, 也不说明需要多宽.

#### 代码: 感知机的向量化实现

```python
import torch
import torch.nn as nn

class Perceptron(nn.Module):
    """
    单层感知机的线性部分
    对应公式 (1): y_hat = sigma(w^T x + b), 激活 sigma 在外部施加
    """
    def __init__(self, input_dim: int, output_dim: int):
        super().__init__()
        # weight: (output_dim, input_dim), bias: (output_dim,)
        self.weight = nn.Parameter(torch.randn(output_dim, input_dim) * 0.01)
        self.bias = nn.Parameter(torch.zeros(output_dim))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: (batch_size, input_dim)
        返回: (batch_size, output_dim)
        """
        # x @ W^T 等价于对 batch 里每一行 x 计算 W x
        return torch.matmul(x, self.weight.T) + self.bias

batch_size, input_dim, output_dim = 4, 10, 3
x = torch.randn(batch_size, input_dim)
model = Perceptron(input_dim, output_dim)
out = model(x)
assert out.shape == (batch_size, output_dim), f"期望 (4, 3), 得到 {out.shape}"
```

### 2.2 激活函数: 非线性从哪里来

上一节已经说明, 没有非线性激活时 1000 层网络也只是一次矩阵乘法. 激活函数的选择还决定了反向传播时每层乘上的导数有多大, 这一点直接影响深层网络能不能训练. 完整曲线, 更多变体和 SwiGLU 的参数量分析在 [2.1.1 激活函数](./2.1.1-激活函数/2.1.1-激活函数.md); 本节只给四个常见函数的定义, 导数和代价.

#### Sigmoid: 输出可以当概率, 导数最大只有 0.25

$$
\sigma(x) = \frac{1}{1 + e^{-x}} \tag{2}
$$

Sigmoid 把任意实数压到 $(0, 1)$ 区间, 所以二分类的最后一层常用它, 输出直接解释为「样本属于正类的概率」. 它的导数可以用自身表示:

$$
\sigma'(x) = \sigma(x) \cdot (1 - \sigma(x)) \tag{3}
$$

式 (3) 在 $x = 0$ 处取最大值 $0.25$. $|x|$ 大时 $\sigma(x)$ 饱和在 0 或 1 附近, 导数趋近 0. 反向传播每经过一层 Sigmoid 就要乘一次 $\sigma'$, 即使权重为 1, 十层下来梯度也最多剩 $0.25^{10} \approx 10^{-6}$. 这就是**梯度消失**, 也是 LLM 的隐藏层不用 Sigmoid 作逐元素激活的原因. Sigmoid 仍出现在门控结构里(LSTM 的门, GLU 的门), 那里需要的就是一个 $(0, 1)$ 之间的系数.

#### ReLU: 正区导数为 1, 负区可能死亡

$$
\text{ReLU}(x) = \max(0, x) \tag{4}
$$

ReLU(Rectified Linear Unit)在正区导数恒为 1, 激活这一项不再随层数连乘衰减, 这缓解了 Sigmoid 和 tanh 带来的梯度消失, 但没有消除它, 权重矩阵的连乘仍会让梯度变大或变小. [Krizhevsky et al. (2012)](https://papers.nips.cc/paper/2012/hash/c399862d3b9d6b76c8436e924a68c45b-Abstract.html) 的 AlexNet 用 ReLU 训练深层卷积网络, 论文图 1 报告四层卷积网络在 CIFAR-10 上用 ReLU 达到 25% 训练误差比 tanh 快约 6 倍. [Glorot et al. (2011)](https://proceedings.mlr.press/v15/glorot11a.html) 则指出 ReLU 输出精确的 0, 隐藏层激活因此是稀疏的.

代价在负区. 负区导数为 0, 一个神经元如果在训练中被推到对所有输入都输出负的预激活, 它的输出和梯度就一直为 0, 参数不再更新, 称为 **Dying ReLU**. 学习率过大时这种神经元会成片出现, 网络的有效容量随之下降.

#### GELU: 用正态分布函数做软截断

$$
\text{GELU}(x) = x \cdot \Phi(x) = x \cdot \frac{1}{2}\left[ 1 + \text{erf}\left( \frac{x}{\sqrt{2}} \right) \right] \tag{5}
$$

其中 $\Phi(x)$ 是标准正态分布的累积分布函数, $\text{erf}$ 是误差函数. 工程里常用 tanh 近似:

$$
\text{GELU}(x) \approx 0.5x \left( 1 + \tanh\left[ \sqrt{\frac{2}{\pi}} \left( x + 0.044715x^3 \right) \right] \right) \tag{6}
$$

[Hendrycks & Gimpel (2016)](https://arxiv.org/abs/1606.08415) 给 GELU 的动机是随机正则化: 把输入 $x$ 乘上一个掩码 $m \sim \text{Bernoulli}(\Phi(x))$, $x$ 越大越可能被保留, 这个随机操作的期望就是 $x\Phi(x)$. 和 ReLU 的硬截断相比, GELU 在负区不是常数 0: 它非单调, 在 $x \approx -0.75$ 处取最小值约 $-0.17$, $x \to -\infty$ 时趋于 0. 负区的梯度不为 0, 所以不存在 ReLU 那种整片死亡.

BERT 和 GPT 系列的隐藏层用 GELU. 原论文的证据是在 MNIST, CIFAR, TIMIT 等任务上 GELU 与 ReLU, ELU 持平或略好; 这些实验不能推出平滑性是 Transformer 预训练的必要条件, 后来的 LLaMA 等模型也换成了门控形式.

#### Swish 与 SwiGLU: 门控 FFN

$$
\text{Swish}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}} \tag{7}
$$

Swish 由 [Ramachandran et al. (2017)](https://arxiv.org/abs/1710.05941) 通过自动搜索得到, 和 Elfwing 等人提出的 SiLU 是同一个函数. 它在正区接近恒等, 负区平滑衰减, 处处可导, 曲线形状和 GELU 接近.

SwiGLU 把 Swish 放进门控线性单元(Gated Linear Unit, GLU, [Dauphin et al. 2016](https://arxiv.org/abs/1612.08083))的结构里:

$$
\text{SwiGLU}(x, W, V) = \text{Swish}(xW) \otimes (xV) \tag{8}
$$

$\otimes$ 是逐元素乘法, $W$ 和 $V$ 是两个独立的投影矩阵. 两路输出逐分量相乘, 每个隐藏单元的值等于「$xW$ 经 Swish 后的值」乘「$xV$ 的线性值」, 所以隐藏层的激活随输入本身动态缩放, 而不是固定曲线. FFN 用 SwiGLU 时要三个矩阵 $W, V, W_2$, 比原来的两矩阵 FFN 多一个. [Shazeer (2020)](https://arxiv.org/abs/2002.05202) 为保持参数量和计算量不变, 把隐藏维 $d_{ff}$ 缩到原来的 $2/3$(T5 base 里从 3072 降到 2048), 即常说的 $8d/3$. 他的 Table 1 里, 训练 524,288 步后 GEGLU 的 log-perplexity 是 1.633, SwiGLU 是 1.636, ReLU 基线是 1.677. Shazeer 在结论里明说没有解释这些变体为什么有效. 公式和更多对照见 [2.1.1 激活函数](./2.1.1-激活函数/2.1.1-激活函数.md).

#### 代码: 激活函数对照

```python
import torch
import torch.nn as nn
import math

def gelu_exact(x: torch.Tensor) -> torch.Tensor:
    """对应公式 (5): x * 0.5 * (1 + erf(x / sqrt(2)))"""
    return x * 0.5 * (1 + torch.erf(x / math.sqrt(2)))

def gelu_approx(x: torch.Tensor) -> torch.Tensor:
    """对应公式 (6): tanh 近似(Hendrycks & Gimpel, 2016)"""
    return 0.5 * x * (1 + torch.tanh(
        math.sqrt(2 / math.pi) * (x + 0.044715 * x ** 3)
    ))

def swish(x: torch.Tensor) -> torch.Tensor:
    """对应公式 (7): x * sigmoid(x)"""
    return x * torch.sigmoid(x)

class SwiGLUFFN(nn.Module):
    """
    SwiGLU 门控 FFN: (Swish(xW) * xV) W2
    w, v: (dim -> hidden_dim); w2: (hidden_dim -> dim)
    hidden_dim 通常取 8*dim/3, 使参数量与 4*dim 的两矩阵 FFN 相当
    """
    def __init__(self, dim: int, hidden_dim: int):
        super().__init__()
        self.w = nn.Linear(dim, hidden_dim, bias=False)
        self.v = nn.Linear(dim, hidden_dim, bias=False)
        self.w2 = nn.Linear(hidden_dim, dim, bias=False)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.w2(swish(self.w(x)) * self.v(x))

t = torch.tensor(-3.0)
print("ReLU(-3)    =", torch.relu(t).item())       # 0.0, 导数也为 0
print("GELU(-3)    =", gelu_exact(t).item())       # 约 -0.004, 非零
print("Sigmoid(-3) =", torch.sigmoid(t).item())    # 约 0.047, 导数约 0.045
```

### 2.3 反向传播: 梯度怎样逐层传回

要解决的问题是: 网络有成千上万个参数, 需要知道损失对每一个参数的偏导. 对每个参数单独做数值差分, 代价随参数量线性增长, 每个参数还要一次前向. [Rumelhart, Hinton & Williams (1986)](https://doi.org/10.1038/323533a0) 推广的反向传播只需一次前向加一次反向, 就得到全部梯度. 它的基础是链式法则. 设复合函数 $y = f(g(x))$:

$$
\frac{\partial y}{\partial x} = \frac{\partial y}{\partial g} \cdot \frac{\partial g}{\partial x} \tag{9}
$$

放到网络里, 式 (9) 的意思是: 损失对第 $l$ 层参数的梯度, 等于损失对第 $l$ 层输出的梯度乘以该层输出对参数的梯度. 前者由后面各层逐层传回, 后者只依赖本层.

#### 两层网络的推导

考虑一个两层网络, 省略偏置. 输入 $\mathbf{x}$ 先经过第一层线性变换 $\mathbf{W}^{[1]}$ 和激活 $\sigma$, 得到隐藏层预激活 $\mathbf{z}^{[1]}$ 与输出 $\mathbf{a}^{[1]}$:

$$
\mathbf{z}^{[1]} = \mathbf{W}^{[1]} \mathbf{x}, \quad \mathbf{a}^{[1]} = \sigma(\mathbf{z}^{[1]}) \tag{10}
$$

$\mathbf{a}^{[1]}$ 再经过第二层权重 $\mathbf{W}^{[2]}$ 和激活, 得到预测 $\hat{\mathbf{y}}$:

$$
\mathbf{z}^{[2]} = \mathbf{W}^{[2]} \mathbf{a}^{[1]}, \quad \hat{\mathbf{y}} = \sigma(\mathbf{z}^{[2]}) \tag{11}
$$

损失取均方误差 $\mathcal{L} = \frac{1}{2}(\hat{y} - y)^2$, $y$ 是真实标签. 定义误差信号 $\delta^{[l]} = \partial \mathcal{L} / \partial \mathbf{z}^{[l]}$, 即损失对第 $l$ 层预激活的梯度. 输出层的误差信号是预测误差乘上激活函数在 $\mathbf{z}^{[2]}$ 处的局部导数:

$$
\delta^{[2]} = \frac{\partial \mathcal{L}}{\partial \mathbf{z}^{[2]}} = (\hat{y} - y) \odot \sigma'(\mathbf{z}^{[2]}) \tag{12}
$$

$\odot$ 表示逐元素乘法. 隐藏层的误差信号由 $\delta^{[2]}$ 传回: $(\mathbf{W}^{[2]})^T$ 把输出层误差映射回隐藏层维度, 再乘上隐藏层激活的局部导数 $\sigma'(\mathbf{z}^{[1]})$:

$$
\delta^{[1]} = \frac{\partial \mathcal{L}}{\partial \mathbf{z}^{[1]}} = \left( (\mathbf{W}^{[2]})^T \delta^{[2]} \right) \odot \sigma'(\mathbf{z}^{[1]}) \tag{13}
$$

有了每层的误差信号, 权重梯度是误差信号与该层输入的外积:

$$
\frac{\partial \mathcal{L}}{\partial \mathbf{W}^{[2]}} = \delta^{[2]} (\mathbf{a}^{[1]})^T, \quad \frac{\partial \mathcal{L}}{\partial \mathbf{W}^{[1]}} = \delta^{[1]} \mathbf{x}^T \tag{14}
$$

式 (12) 说明输出层误差信号直接依赖预测误差; 式 (13) 说明隐藏层误差信号经权重转置逐层回传, 每过一层都要乘一次激活导数; 式 (14) 说明权重的更新量由误差信号和该层输入共同决定. 网络更深时, 式 (13) 会重复 $L-1$ 次, 每次都乘 $(\mathbf{W}^{[l+1]})^T$ 和 $\sigma'$, 梯度消失和爆炸都出在这串连乘上.

#### 数值走查: 一步反向传播

假设输入 $x = 2.0$, 真实标签 $y = 1.0$, 参数 $w^{[1]} = 0.5$, $w^{[2]} = 1.5$, 两层都用 Sigmoid. 每一步对应的式号写在第一列.

| 步骤 | 计算 | 结果 |
| --- | --- | --- |
| 前向, 式 (10): 隐藏层预激活 | $z^{[1]} = 0.5 \times 2.0$ | $1.0$ |
| 前向, 式 (10): 隐藏层输出 | $a^{[1]} = \sigma(1.0)$ | $0.731$ |
| 前向, 式 (11): 输出层预激活 | $z^{[2]} = 1.5 \times 0.731$ | $1.097$ |
| 前向, 式 (11): 预测 | $\hat{y} = \sigma(1.097)$ | $0.750$ |
| 损失 | $\mathcal{L} = 0.5 \times (0.750 - 1.0)^2$ | $0.0313$ |
| 反向, 式 (12): 输出误差 | $\delta^{[2]} = (0.750 - 1.0) \times \sigma'(1.097) = -0.25 \times 0.187$ | $-0.0468$ |
| 反向, 式 (13): 隐藏误差 | $\delta^{[1]} = (1.5 \times -0.0468) \times \sigma'(1.0) = -0.0702 \times 0.197$ | $-0.0138$ |
| 式 (14): $w^{[2]}$ 的梯度 | $-0.0468 \times 0.731$ | $-0.0342$ |
| 式 (14): $w^{[1]}$ 的梯度 | $-0.0138 \times 2.0$ | $-0.0276$ |

误差信号从输出层到隐藏层由 $-0.0468$ 变成 $-0.0138$, 缩小到约 $0.29$ 倍, 这个倍数就是 $w^{[2]} \cdot \sigma'(1.0) = 1.5 \times 0.197$. Sigmoid 的导数不超过 $0.25$, 只要权重不大, 每多一层误差信号就再缩小一次, 层数一多就是梯度消失.

#### 代码: 手算梯度与 autograd 对照

```python
import torch

def sigmoid(x):
    return 1 / (1 + torch.exp(-x))

def sigmoid_derivative(x):
    """对应公式 (3): sigma'(x) = sigma(x) * (1 - sigma(x))"""
    s = sigmoid(x)
    return s * (1 - s)

def mse_loss(y_pred, y_true):
    """L = 0.5 * (y_pred - y_true)^2"""
    return 0.5 * (y_pred - y_true) ** 2

x = torch.tensor(2.0)
y_true = torch.tensor(1.0)
w1 = torch.tensor(0.5, requires_grad=True)
w2 = torch.tensor(1.5, requires_grad=True)

# 前向, 对应式 (10)(11)
z1 = w1 * x
a1 = sigmoid(z1)
z2 = w2 * a1
y_pred = sigmoid(z2)
loss = mse_loss(y_pred, y_true)

# 手动反向, 对应式 (12)(13)(14)
delta2 = (y_pred - y_true) * sigmoid_derivative(z2)
delta1 = w2 * delta2 * sigmoid_derivative(z1)
grad_w2_manual = delta2 * a1
grad_w1_manual = delta1 * x

loss.backward()
print(f"手动计算 dw1: {grad_w1_manual.item():.6f}, dw2: {grad_w2_manual.item():.6f}")
print(f"autograd dw1: {w1.grad.item():.6f}, dw2: {w2.grad.item():.6f}")
# 两者一致(误差 < 1e-6)
```

## 3. 优化器: 怎样用梯度更新参数

有了梯度, 还要决定每一步走多远, 方向要不要用历史信息修正, 不同参数要不要用不同步长. SGD, Momentum, Adam 依次回答了这三个问题.

### 3.1 SGD: 沿负梯度走一步

$$
\theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}(\theta_t) \tag{15}
$$

$\theta_t$ 是第 $t$ 步的参数, $\eta$ 是学习率(learning rate), $\nabla_\theta \mathcal{L}(\theta_t)$ 是在一个随机抽取的 mini-batch 上估计的梯度, SGD 名字里的「随机」就指这一点.

SGD 的问题有三个:

1. **对学习率敏感**: $\eta$ 太大则在最优点附近震荡甚至发散, 太小则收敛很慢.
2. **病态曲率与鞍点**: 损失面在不同方向上曲率相差很大时, 大曲率方向要求小步长, 小曲率方向又需要大步长, 单一的 $\eta$ 两头顾不上. [Dauphin et al. (2014)](https://arxiv.org/abs/1406.2572) 指出, 高维非凸问题里梯度为零的点大多是鞍点而不是局部极小, SGD 在鞍点附近的梯度很小, 前进缓慢.
3. **所有参数共用一个学习率**: 稀疏特征(罕见词的嵌入)很少收到梯度, 常见词的嵌入每步都有梯度, 两者被迫用同样的步长. Adagrad([Duchi et al. 2011](https://jmlr.org/papers/v12/duchi11a.html))最早按参数缩放步长来处理这个问题.

#### 代码: SGD

```python
import torch

def sgd_update(params, grads, lr=0.01):
    """对应公式 (15): theta_{t+1} = theta_t - eta * grad"""
    for param, grad in zip(params, grads):
        param.data -= lr * grad

model = torch.nn.Linear(10, 2)
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

loss = model(torch.randn(4, 10)).sum()
loss.backward()
optimizer.step()       # theta = theta - lr * grad
optimizer.zero_grad()  # 清空梯度, 防止跨步累积
```

### 3.2 Momentum: 累积历史梯度

SGD 的第 2 个问题在曲率差异大的方向上最明显: 梯度在大曲率方向上来回变号, 在小曲率方向上符号一致但数值小, 参数在前者上震荡, 在后者上前进缓慢. Momentum([Polyak 1964](https://doi.org/10.1016/0041-5553(64)90137-5) 的 heavy ball 方法)维护一个速度向量 $\mathbf{v}_t$, 把历史梯度累积进去:

$$
\mathbf{v}_{t+1} = \gamma \mathbf{v}_t + \nabla_\theta \mathcal{L}(\theta_t) \tag{16}
$$

$$
\theta_{t+1} = \theta_t - \eta \mathbf{v}_{t+1} \tag{17}
$$

其中 $\mathbf{v}_t$ 是速度向量, 初始为 0; $\gamma \in [0, 1)$ 是动量系数, 通常取 0.9, 决定历史梯度衰减多快; $\nabla_\theta \mathcal{L}(\theta_t)$ 是当前梯度, $\gamma \mathbf{v}_t$ 是上一步速度保留下来的部分. 式 (16) 和 PyTorch `torch.optim.SGD` 在 `momentum > 0, dampening = 0` 时的实现一致.

把式 (16) 从 $\mathbf{v}_0 = \mathbf{0}$ 递推展开:

$$
\mathbf{v}_t = \sum_{i=0}^{t-1} \gamma^{t-1-i} \nabla_\theta \mathcal{L}(\theta_i) \tag{18}
$$

式 (16) 是**指数衰减累积, 不是平均**: 各项权重 $\gamma^{t-1-i}$ 之和为 $(1-\gamma^t)/(1-\gamma)$, 趋于 $1/(1-\gamma)$, $\gamma = 0.9$ 时约为 10. 梯度方向长期一致时, $\mathbf{v}_t$ 接近单步梯度的 10 倍, 有效步长相应放大; 梯度来回变号的分量在求和中相互抵消, 震荡被抑制. 10 步之前的梯度在 $\mathbf{v}_t$ 中的权重是当前梯度的 $\gamma^{10} \approx 0.35$ 倍. 也有实现写成 $\mathbf{v}_{t+1} = \gamma \mathbf{v}_t + (1-\gamma)\nabla_\theta \mathcal{L}$, 这才是指数移动平均, 两种写法只差学习率的一个常数因子.

边界: 动量放大的是一致方向上的步长, 所以 $\eta$ 要相应调小; 动量对第 3 个问题, 即不同参数需要不同步长, 没有帮助.

### 3.3 Adam: 按参数缩放步长

Adam(Adaptive Moment Estimation, [Kingma & Ba 2015](https://arxiv.org/abs/1412.6980))把 Momentum 和按参数缩放结合起来, AdamW 是 Transformer 预训练最常用的优化器. 它为每个参数维护两个状态. 一阶矩 $\mathbf{m}_t$ 是梯度的指数移动平均, 提供方向; 二阶矩 $\mathbf{v}_t$ 是梯度平方的指数移动平均, 度量该参数梯度的幅度. 记第 $t$ 步梯度为 $\mathbf{g}_t = \nabla_\theta \mathcal{L}(\theta_t)$:

$$
\mathbf{m}_t = \beta_1 \mathbf{m}_{t-1} + (1 - \beta_1) \mathbf{g}_t \tag{19}
$$

$$
\mathbf{v}_t = \beta_2 \mathbf{v}_{t-1} + (1 - \beta_2) \mathbf{g}_t^2 \tag{20}
$$

$\mathbf{g}_t^2$ 是逐元素平方. 论文默认 $\beta_1 = 0.9$, $\beta_2 = 0.999$. 和式 (16) 不同, 这里乘了 $(1-\beta)$, 是真正的指数移动平均.

$\mathbf{m}_0$ 和 $\mathbf{v}_0$ 初始化为 0, 前几步的估计会偏向 0. 例如 $t = 1$ 时 $\mathbf{m}_1 = 0.1\,\mathbf{g}_1$, 只有真实梯度的十分之一. Adam 除以 $1 - \beta^t$ 做偏差修正:

$$
\hat{\mathbf{m}}_t = \frac{\mathbf{m}_t}{1 - \beta_1^t}, \quad \hat{\mathbf{v}}_t = \frac{\mathbf{v}_t}{1 - \beta_2^t} \tag{21}
$$

更新时以 $\hat{\mathbf{m}}_t$ 为方向, 用 $\sqrt{\hat{\mathbf{v}}_t}$ 逐元素缩放步长:

$$
\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{\hat{\mathbf{v}}_t} + \epsilon} \hat{\mathbf{m}}_t \tag{22}
$$

$\epsilon$(通常 $10^{-8}$)防止除以零. 式 (19) 积累梯度方向; 式 (20) 积累梯度平方; 式 (21) 消除零初始化带来的低估; 式 (22) 把两者合起来, 梯度幅度大的参数步长被压小, 幅度小的参数步长被放大. 梯度方向稳定时 $|\hat{\mathbf{m}}_t| \approx \sqrt{\hat{\mathbf{v}}_t}$, 单步更新量接近 $\eta$, 与梯度的绝对尺度无关.

**为什么 Transformer 需要 Adam**: [Zhang et al. (2024)](https://arxiv.org/abs/2402.16788) 从 Hessian 角度给出一种解释. 他们发现 Transformer 不同参数块(嵌入, Q/K/V 投影, FFN 等)的 Hessian 谱差异很大, 称为「block heterogeneity」; 在有这种异质性的问题上 SGD 明显落后于 Adam, 在 CNN 这类没有明显异质性的问题上两者相当. 他们的初步理论分析把原因归于 SGD 对所有参数块只用一个学习率.

**AdamW 与工程配置**: [Loshchilov & Hutter (2019)](https://arxiv.org/abs/1711.05101) 指出, 在 Adam 里把 L2 正则加进梯度, 会被式 (22) 的分母一起缩放, 效果和权重衰减不等价. AdamW 把衰减项从梯度中拿出来, 直接作用在参数上: $\theta_{t+1} = \theta_t - \eta\left(\hat{\mathbf{m}}_t / (\sqrt{\hat{\mathbf{v}}_t} + \epsilon) + \lambda \theta_t\right)$, $\lambda$ 是权重衰减系数. [LLaMA (Touvron et al. 2023)](https://arxiv.org/abs/2302.13971) §2.3 的配置是 AdamW, $\beta_1 = 0.9$, $\beta_2 = 0.95$, 权重衰减 0.1, 梯度裁剪 1.0, 2000 步 warmup 后余弦衰减.

代价: Adam 为每个参数多存 $\mathbf{m}$ 和 $\mathbf{v}$ 两份状态, 用 FP32 存时每个参数多占 8 字节, 优化器状态的显存是参数本身(BF16 时 2 字节)的 4 倍.

#### 代码: Adam 的简化实现

```python
import torch

class Adam:
    """
    Adam 简化实现
    对应公式 (19)-(22):
      m_t = beta1 * m_{t-1} + (1-beta1) * g_t
      v_t = beta2 * v_{t-1} + (1-beta2) * g_t^2
      m_hat = m_t / (1 - beta1^t),  v_hat = v_t / (1 - beta2^t)
      theta = theta - lr * m_hat / (sqrt(v_hat) + eps)
    """
    def __init__(self, params, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8):
        self.params = list(params)
        self.lr, self.beta1, self.beta2, self.eps = lr, beta1, beta2, eps
        self.t = 0
        self.m = [torch.zeros_like(p) for p in self.params]  # 与参数同 shape
        self.v = [torch.zeros_like(p) for p in self.params]

    def step(self):
        self.t += 1
        for i, param in enumerate(self.params):
            if param.grad is None:
                continue
            g = param.grad
            self.m[i] = self.beta1 * self.m[i] + (1 - self.beta1) * g          # 式 (19)
            self.v[i] = self.beta2 * self.v[i] + (1 - self.beta2) * (g ** 2)   # 式 (20)
            m_hat = self.m[i] / (1 - self.beta1 ** self.t)                     # 式 (21)
            v_hat = self.v[i] / (1 - self.beta2 ** self.t)
            param.data -= self.lr * m_hat / (torch.sqrt(v_hat) + self.eps)    # 式 (22)

    def zero_grad(self):
        for param in self.params:
            if param.grad is not None:
                param.grad.zero_()

# AdamW: 权重衰减直接作用在参数上, 不经过式 (22) 的分母
model = torch.nn.Linear(100, 10)
optimizer_torch = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)
```

## 4. 正则化: Dropout

过拟合的典型场景是参数多, 数据少: 一个几百万参数的分类网络只有几万张标注图片, 网络可以把训练集逐条记住, 在新数据上表现变差. LLM 预训练的情况不同. 现代 LLM 预训练的 token 数通常远多于参数数, [Chinchilla (Hoffmann et al. 2022)](https://arxiv.org/abs/2203.15556) 给出的计算最优配比约为每个参数 20 个 token, 70B 参数配 1.4T token; LLaMA 7B 训练了 1T token, 约每个参数 140 个 token. 在这个区间里大部分数据只过一遍, 正则化的必要性比小数据监督学习低得多.

### 4.1 Dropout 的定义

Dropout 由 [Hinton et al. (2012)](https://arxiv.org/abs/1207.0580) 提出, [Srivastava et al. (2014)](https://jmlr.org/papers/v15/srivastava14a.html) 系统整理. 训练时, 对某层输出 $\mathbf{h} \in \mathbb{R}^d$ 构造随机掩码 $\mathbf{m}$, 每个分量独立地以概率 $p$ 置 0:

$$
m_i \sim \text{Bernoulli}(1 - p), \quad \tilde{\mathbf{h}} = \mathbf{m} \odot \mathbf{h} \tag{23}
$$

$p$ 是丢弃概率, 例如 0.1 表示每个分量有 10% 的概率被置 0. 掩码后输出的期望变成 $(1-p)\mathbf{h}$, 为了让推理时不必改动网络, 训练时除以 $1-p$ 补偿(inverted dropout):

$$
\tilde{\mathbf{h}} = \frac{\mathbf{m} \odot \mathbf{h}}{1 - p} \tag{24}
$$

式 (24) 保证 $\mathbb{E}[\tilde{\mathbf{h}}] = \mathbf{h}$. 推理时 Dropout 关闭, 所有分量都参与计算.

### 4.2 为什么有效: 子网络平均

Srivastava et al. 的解释是**模型集成**. 有 $n$ 个可丢弃单元的网络有 $2^n$ 种掩码, 每次前向相当于从中采样一个共享权重的子网络来训练. 推理时用完整网络, 并按保留概率缩放权重, 近似于对这 $2^n$ 个子网络的预测做平均.

另一种解释是减少共适应(co-adaptation): 任何一个单元都可能在下一步被置 0, 其他单元不能依赖某个特定单元的存在, 每个单元都要学到单独有用的特征.

### 4.3 在 Transformer 里放在哪里

[Vaswani et al. (2017)](https://arxiv.org/abs/1706.03762) 原始 Transformer 把 Dropout 用在两处: 每个子层的输出在加回残差之前, 以及 token 嵌入与位置编码相加之后, 基础模型取 $P_{drop} = 0.1$. BERT 等实现还在注意力权重(softmax 之后)上加 Dropout.

边界: Shazeer (2020) 在 T5 预训练里去掉了 Dropout, 并报告这样效果更好, 微调时才用 0.1. 这和本节开头的配比一致: 数据只过一遍时, Dropout 引入的噪声主要是拖慢拟合. 数据少, 要多轮遍历的微调阶段, Dropout 的作用才明显.

#### 代码: Dropout

```python
import torch
import torch.nn as nn

class Dropout(nn.Module):
    """
    对应公式 (24)
    训练时: h_tilde = m * h / (1 - p)
    推理时: h_tilde = h
    """
    def __init__(self, p: float = 0.5):
        super().__init__()
        self.p = p

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        if not self.training or self.p == 0.0:
            return x
        mask = (torch.rand_like(x) > self.p).float()  # 1 保留, 0 丢弃, E[mask] = 1 - p
        return x * mask / (1 - self.p)

x = torch.ones(1000, 1000)
dropout = Dropout(p=0.3)
dropout.train()
out = dropout(x)
print(f"输入均值: {x.mean().item():.4f}")    # 1.0
print(f"输出均值: {out.mean().item():.4f}")  # 约 1.0, 缩放补偿了丢弃
```

## 5. 归一化: BatchNorm, LayerNorm, RMSNorm

深层网络对初始化和学习率很敏感, 每层输出的尺度随训练漂移, 后面的层要不断适应前面层的变化. 归一化层在每层把激活的统计量拉回固定范围. 三种方法的差别在于沿哪个轴求统计量, 以及求哪些统计量. LN 与 RMSNorm 的完整推导, 代码对照和失效模式见 [2.1.2 归一化层](./2.1.2-归一化层/2.1.2-归一化层.md), 残差怎么接见 [2.1.3 残差连接](./2.1.3-残差连接/2.1.3-残差连接.md).

### 5.1 BatchNorm: 沿 batch 求统计量

[Ioffe & Szegedy (2015)](https://arxiv.org/abs/1502.03167) 提出的 Batch Normalization 对一个 mini-batch 的输入 $\mathbf{x} \in \mathbb{R}^{B \times d}$($B$ 是 batch size, $d$ 是特征维度)逐特征维度计算 batch 内的均值 $\mu_B$ 和方差 $\sigma_B^2$:

$$
\mu_B = \frac{1}{B} \sum_{i=1}^{B} \mathbf{x}_i, \quad \sigma_B^2 = \frac{1}{B} \sum_{i=1}^{B} (\mathbf{x}_i - \mu_B)^2 \tag{25}
$$

式 (25) 的求和沿 batch 轴进行, 每个特征维度得到一个均值和一个方差. 然后用它们标准化每个样本:

$$
\hat{\mathbf{x}}_i = \frac{\mathbf{x}_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} \tag{26}
$$

式 (26) 把每个特征维度变成零均值, 单位方差, $\epsilon$ 防止除以零. 最后做一个可学习的仿射变换, $\gamma$ 和 $\beta$ 是与特征维度同长的参数:

$$
\mathbf{y}_i = \gamma \odot \hat{\mathbf{x}}_i + \beta \tag{27}
$$

式 (27) 让网络在需要时撤销标准化: 学到 $\gamma = \sqrt{\sigma_B^2 + \epsilon}$, $\beta = \mu_B$ 时就恢复原输入. 推理时没有 batch 可用, BN 改用训练期间累积的滑动平均 $\mu$ 和 $\sigma^2$. 论文报告在 ImageNet 上用 BN 的 Inception 网络以少 14 倍的训练步数达到原来的精度.

#### BN 为什么有效: 两种解释

Ioffe & Szegedy 用**内部协变量偏移(Internal Covariate Shift, ICS)**解释 BN: 前层参数更新使后层输入分布不断变化, BN 固定了每层输入的均值和方差, 减轻了这种变化. [Santurkar et al. (2018)](https://arxiv.org/abs/1805.11604) 对此做了检验: 他们在 BN 之后人为注入随时间变化的噪声, 使分布偏移更大, 网络仍然训练得很好; 测量也显示 BN 不一定减少 ICS. 他们的结论是 BN 的收益主要来自让损失面更平滑, 损失和梯度的 Lipschitz 常数变小, 从而可以用更大的学习率. 更详细的讨论见 [2.1.2 归一化层](./2.1.2-归一化层/2.1.2-归一化层.md).

#### 为什么 BN 不适合 Transformer

原因主要有三个. 第一, 统计量依赖 batch: batch 小时 $\mu_B$, $\sigma_B^2$ 噪声大, 而 LLM 训练受显存限制, 单卡上的 micro-batch 常常只有几条序列. 第二, 序列长度不一, padding 位置会混进统计量, 需要额外掩码处理. 第三, 推理行为与训练不一致: 自回归生成每次只处理一个新 token, batch 内样本各不相同, 只能用训练时的滑动平均, 和训练时用的 batch 统计量不是同一个量. 所以 Transformer 用的是按 token 归一化的 LayerNorm.

### 5.2 LayerNorm: 沿特征维求统计量

[Ba, Kiros & Hinton (2016)](https://arxiv.org/abs/1607.06450) 提出的 Layer Normalization 换了统计轴: 对每个样本的每个 token, 在它自己的 $d$ 个特征上求均值 $\mu$ 和方差 $\sigma^2$. 记单个 token 的表示为 $\mathbf{x} \in \mathbb{R}^d$, $x_j$ 是它的第 $j$ 个分量:

$$
\mu = \frac{1}{d} \sum_{j=1}^{d} x_j, \quad \sigma^2 = \frac{1}{d} \sum_{j=1}^{d} (x_j - \mu)^2 \tag{28}
$$

式 (28) 只用到这个 token 自己的分量, 与 batch 里其他样本和序列里其他位置都无关. 标准化后同样接可学习的 $\gamma$, $\beta$:

$$
\text{LN}(\mathbf{x}) = \gamma \odot \frac{\mathbf{x} - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta \tag{29}
$$

式 (29) 中的 $\gamma$ 和 $\beta$ 让网络在标准化之后仍能调整每个特征的尺度和偏移.

统计轴换成特征维之后, 上一节的三个问题都没有了: 统计量不依赖 batch 大小; padding 位置只影响它自己, 不污染其他 token; 训练和推理用同一个公式, 不需要滑动平均.

#### Post-LN 与 Pre-LN

原始 Transformer 把 LN 放在残差相加之后, 称为 Post-LN; GPT-2 起把 LN 移到每个子层的输入端, 并在最后一层之后再加一个 LN, 称为 Pre-LN. 记第 $l$ 层输入为 $\mathbf{x}_l$, 子层(注意力或 FFN)为 $F$:

$$
\text{Post-LN: } \mathbf{x}_{l+1} = \text{LN}\left(\mathbf{x}_l + F(\mathbf{x}_l)\right), \qquad \text{Pre-LN: } \mathbf{x}_{l+1} = \mathbf{x}_l + F\left(\text{LN}(\mathbf{x}_l)\right)
$$

两个式子只是顺序交换, 训练行为却差很多. [Xiong et al. (2020)](https://arxiv.org/abs/2002.04745) 用平均场理论证明: 初始化时, Post-LN 中靠近输出层的参数的期望梯度很大, 直接用大学习率会不稳定, 所以 Post-LN 需要学习率 warmup; Pre-LN 的梯度在初始化时既不爆炸也不消失. 他们在 IWSLT14, WMT14 翻译和 BERT 预训练上去掉 warmup 训练 Pre-LN, 达到与基线相当的结果, 训练时间更短. 从结构上看, Pre-LN 的残差主路径上没有 LN, 从最后一层到第一层存在一条恒等路径. GPT-3, LLaMA 等模型都用 Pre-LN.

### 5.3 RMSNorm: 去掉均值

RMSNorm(Root Mean Square Normalization)是 LN 的简化, 去掉了减均值和偏置 $\beta$, 只按均方根缩放:

$$
\text{RMSNorm}(\mathbf{x}) = \gamma \odot \frac{\mathbf{x}}{\sqrt{\frac{1}{d} \sum_{j=1}^{d} x_j^2 + \epsilon}} \tag{30}
$$

[Zhang & Sennrich (2019)](https://arxiv.org/abs/1910.07467) 的假设是: LN 的效果主要来自重新缩放(re-scaling)带来的不变性, 重新居中(re-centering)不是必需的. 去掉均值后少了一次沿特征维的归约(reduce, 即沿某个维度把很多数聚合成一个统计量), 他们在多个模型上报告运行时间节省 7%–64%, 效果与 LN 相当. LLaMA, Qwen 等开源模型都用 RMSNorm. RMSNorm 的计算减少不代表 LayerNorm 的数学目标有错, 实际的速度收益取决于实现和算子融合方式.

#### 代码: LayerNorm 与 RMSNorm

```python
import torch
import torch.nn as nn

class LayerNorm(nn.Module):
    """对应公式 (28)(29): gamma * (x - mu) / sqrt(sigma^2 + eps) + beta"""
    def __init__(self, normalized_shape: int, eps: float = 1e-5):
        super().__init__()
        self.eps = eps
        self.gamma = nn.Parameter(torch.ones(normalized_shape))
        self.beta = nn.Parameter(torch.zeros(normalized_shape))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x: (B, T, d), 统计量沿最后一维
        mean = x.mean(dim=-1, keepdim=True)                  # (B, T, 1)
        var = x.var(dim=-1, keepdim=True, unbiased=False)    # (B, T, 1)
        x_norm = (x - mean) / torch.sqrt(var + self.eps)
        return self.gamma * x_norm + self.beta

class RMSNorm(nn.Module):
    """对应公式 (30): gamma * x / sqrt(mean(x^2) + eps)"""
    def __init__(self, dim: int, eps: float = 1e-6):
        super().__init__()
        self.eps = eps
        self.gamma = nn.Parameter(torch.ones(dim))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + self.eps)  # (B, T, 1)
        return self.gamma * (x / rms)

batch_size, seq_len, hidden_dim = 2, 10, 64
x = torch.randn(batch_size, seq_len, hidden_dim)
ln, rms = LayerNorm(hidden_dim), RMSNorm(hidden_dim)
assert ln(x).shape == x.shape and rms(x).shape == x.shape

out_ln = ln(x)
print(f"LN 输出均值: {out_ln.mean(dim=-1).abs().mean().item():.6f}")   # 约 0
print(f"LN 输出标准差: {out_ln.std(dim=-1).mean().item():.6f}")        # 约 1
```

## 6. 嵌入层与位置编码

### 6.1 Token Embedding: 从整数索引到向量

问题是: 分词器输出的是整数 token ID, 而网络只能对连续向量做矩阵运算. 设词表大小为 $V$, 嵌入维度为 $d$, Token Embedding 是一张可学习的查找表 $\mathbf{E} \in \mathbb{R}^{V \times d}$, 第 $i$ 个 token 的向量就是第 $i$ 行:

$$
\mathbf{e}_i = \mathbf{E}[i] \in \mathbb{R}^d \tag{31}
$$

$i \in \{0, 1, \dots, V-1\}$ 是 token 的整数索引. 写成线性代数形式, 记 $\mathbf{x}_{\text{one-hot}} \in \mathbb{R}^{1 \times V}$ 为第 $i$ 位是 1, 其余为 0 的行向量:

$$
\mathbf{e} = \mathbf{x}_{\text{one-hot}} \mathbf{E} \tag{32}
$$

式 (32) 与式 (31) 等价: one-hot 向量乘嵌入矩阵, 结果就是按索引取出对应行. 实现上直接查表, 不做这个乘法; 反向传播时只有本 batch 出现过的那些行收到梯度.

#### 分布式假设

嵌入向量能学到语义, 依据是**分布式假设(Distributional Hypothesis)**: 一个词的含义由它常出现的上下文决定. 在上下文里可互换的词得到相近的梯度, 训练后向量也相近. [Mikolov et al. (2013)](https://arxiv.org/abs/1301.3781) 的 word2vec 显示, 词向量的差可以编码一部分语义关系, 例如 $\vec{\text{king}} - \vec{\text{man}} + \vec{\text{woman}}$ 的最近邻是 $\vec{\text{queen}}$. 嵌入空间的单个维度一般没有人能读懂的标签, 语义信息分布在整个向量上.

#### 输入输出嵌入共享

语言模型最后一层要把 $d$ 维隐藏状态映射回 $V$ 个词的 logits, 这个输出矩阵的形状也是 $V \times d$. [Press & Wolf (2017)](https://arxiv.org/abs/1608.05859) 提出让输入嵌入和输出矩阵共享同一份权重(Weight Tying), 在他们的语言模型实验里参数更少, perplexity 也更低. 是否共享因模型而异: GPT-2 共享输入输出嵌入, LLaMA 不共享. 以 LLaMA 7B 为例, $V = 32000$, $d = 4096$, 一份嵌入矩阵约 1.31 亿参数, 不共享就多出这么多.

#### 代码: Token Embedding

```python
import torch
import torch.nn as nn

class TokenEmbedding(nn.Module):
    """对应公式 (31): e = E[token_id]"""
    def __init__(self, vocab_size: int, d_model: int):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)  # E: (vocab_size, d_model)
        self.scale = d_model ** 0.5  # 原始 Transformer 把嵌入乘以 sqrt(d_model)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x: (batch_size, seq_len) 的整数 token ID -> (batch_size, seq_len, d_model)
        return self.embedding(x) * self.scale

vocab_size, d_model = 50000, 768
token_ids = torch.randint(0, vocab_size, (2, 128))
emb = TokenEmbedding(vocab_size, d_model)
assert emb(token_ids).shape == (2, 128, 768)
```

### 6.2 位置编码: 为什么需要, 怎么加

Token Embedding 对每个 token 独立查表, 不含位置信息; 后面的自注意力对输入**置换等变**: 把输入序列的 token 打乱顺序, 输出只是同样地打乱, 每个 token 的输出向量不变. 所以没有位置信息时, 模型分不出「猫追老鼠」和「老鼠追猫」, 两句话的 token 集合相同. 位置编码就是把位置信息加进来. 完整的演进和推导见 [2.1.4 位置编码](./2.1.4-位置编码/2.1.4-位置编码.md).

#### 正弦位置编码

原始 Transformer 用固定的正弦和余弦函数. 记 $pos$ 为位置索引, $i$ 为维度对的索引, $d_{model}$ 为模型维度:

$$
PE_{(pos, 2i)} = \sin\left( \frac{pos}{10000^{2i/d_{model}}} \right) \tag{33}
$$

$$
PE_{(pos, 2i+1)} = \cos\left( \frac{pos}{10000^{2i/d_{model}}} \right) \tag{34}
$$

第 $i$ 对维度的角频率是 $\omega_i = 10000^{-2i/d_{model}}$, 从 1 递减到约 $1/10000$. Vaswani et al. 选这种形式的理由是: 对任意固定偏移 $k$, $PE_{pos+k}$ 可以写成 $PE_{pos}$ 的线性函数:

$$
PE_{pos+k} = M_k \, PE_{pos} \tag{35}
$$

$M_k$ 是只依赖 $k$, 不依赖 $pos$ 的线性变换. 由和角公式, 它是分块对角矩阵, 第 $i$ 个 $2 \times 2$ 块是

$$
\begin{pmatrix} \sin((pos+k)\omega_i) \\ \cos((pos+k)\omega_i) \end{pmatrix} = \begin{pmatrix} \cos(k\omega_i) & \sin(k\omega_i) \\ -\sin(k\omega_i) & \cos(k\omega_i) \end{pmatrix} \begin{pmatrix} \sin(pos\,\omega_i) \\ \cos(pos\,\omega_i) \end{pmatrix}
$$

式 (35) 说明「相距 $k$」这种关系可以用同一个线性变换表达, 不必为每个绝对位置分别学. 但正弦编码是加在输入上的, 经过 $W_Q$, $W_K$ 投影和非线性之后, 注意力分数里并不直接只剩相对位置.

**可学习位置编码**是另一种做法(BERT, GPT-2 采用): 位置索引像 token 一样查表, $\mathbf{p}_{pos} = \mathbf{P}[pos]$, $\mathbf{P} \in \mathbb{R}^{L_{max} \times d}$ 是可学习矩阵, $L_{max}$ 是最大长度. 它的代价是位置上限被固化在参数表里, 超过 $L_{max}$ 的位置没有对应的行.

#### RoPE: 旋转位置编码

RoPE(Rotary Position Embedding, [Su et al. 2021](https://arxiv.org/abs/2104.09864))不在输入端加位置向量, 而是在注意力里对 Query 和 Key 按位置旋转. LLaMA, Qwen 等模型都用 RoPE. 把 $d$ 维向量的第 $2i$, $2i+1$ 两个分量看成一个复数 $x^{(i)} = x_{2i} + \mathrm{i}\, x_{2i+1}$, 位置 $m$ 处的 RoPE 是乘上一个相位:

$$
\text{RoPE}(\mathbf{x}, m)^{(i)} = x^{(i)} \, e^{\mathrm{i}\, m \theta_i} \tag{36}
$$

$\theta_i = \text{base}^{-2i/d}$ 是第 $i$ 对维度的频率, base 默认 10000, 与正弦编码的 $\omega_i$ 同形. 写成实矩阵形式, 位置 $m$ 的向量 $\mathbf{x}_m$ 乘上旋转矩阵 $\mathbf{R}_m$:

$$
\mathbf{x}_m^{(rot)} = \mathbf{R}_m \mathbf{x}_m \tag{37}
$$

$\mathbf{R}_m$ 是分块对角矩阵, 第 $i$ 个 $2 \times 2$ 块是角度 $m\theta_i$ 的旋转:

$$
\mathbf{R}_m^{(i)} = \begin{pmatrix} \cos(m\theta_i) & -\sin(m\theta_i) \\ \sin(m\theta_i) & \cos(m\theta_i) \end{pmatrix} \tag{38}
$$

旋转矩阵满足 $\mathbf{R}_m^T \mathbf{R}_n = \mathbf{R}_{n-m}$, 所以位置 $m$ 的 Query 和位置 $n$ 的 Key 做点积时, $(\mathbf{R}_m \mathbf{q})^T (\mathbf{R}_n \mathbf{k}) = \mathbf{q}^T \mathbf{R}_{n-m} \mathbf{k}$, 结果只依赖相对距离 $n - m$, 与绝对位置无关. 和正弦编码相比, RoPE 的相对位置直接出现在注意力分数里, 不必经过投影后再由模型去恢复.

边界: 这个相对位置性质不代表 RoPE 能直接用到比训练更长的上下文. 超出训练长度后, 低频维度会出现训练中没见过的旋转角, 效果会明显下降. 外推需要额外的方法, 如位置插值(PI, [Chen et al. 2023](https://arxiv.org/abs/2306.15595)), NTK-aware 插值, YaRN([Peng et al. 2023](https://arxiv.org/abs/2309.00071)), 见 [2.5 长上下文与外推技术](../2.5-长上下文与外推技术/2.5-长上下文与外推技术.md).

#### 代码: 正弦编码与 RoPE

```python
import torch
import torch.nn as nn
import math

class SinusoidalPositionEncoding(nn.Module):
    """
    对应公式 (33)(34):
      PE[pos, 2i]   = sin(pos / 10000^(2i/d))
      PE[pos, 2i+1] = cos(pos / 10000^(2i/d))
    """
    def __init__(self, d_model: int, max_len: int = 5000):
        super().__init__()
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        # 10000^(-2i/d) = exp(2i * -log(10000) / d)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model))
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        self.register_buffer('pe', pe.unsqueeze(0))  # (1, max_len, d_model)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x: (batch_size, seq_len, d_model)
        return x + self.pe[:, :x.size(1), :]

def apply_rope(x: torch.Tensor, base: float = 10000.0) -> torch.Tensor:
    """
    对应公式 (37)(38)
    x: (batch_size, n_heads, seq_len, head_dim), head_dim 为偶数
    """
    _, _, t, d = x.shape
    inv_freq = 1.0 / (base ** (torch.arange(0, d, 2, dtype=torch.float32) / d))  # (d/2,), theta_i
    angles = torch.outer(torch.arange(t, dtype=torch.float32), inv_freq)        # (t, d/2), m * theta_i
    cos, sin = angles.cos(), angles.sin()
    x1, x2 = x[..., 0::2], x[..., 1::2]  # 每对维度 (x_{2i}, x_{2i+1})
    out = torch.empty_like(x)
    out[..., 0::2] = x1 * cos - x2 * sin
    out[..., 1::2] = x1 * sin + x2 * cos
    return out

# 验证式 (35): 第 i 对维度上 PE[pos+k] = M_k PE[pos], M_k 与 pos 无关
emb = SinusoidalPositionEncoding(d_model=64, max_len=100).pe.squeeze(0)  # (100, 64)
k, i = 5, 3
w = 10000 ** (-2 * i / 64)
M = torch.tensor([[math.cos(k * w), math.sin(k * w)], [-math.sin(k * w), math.cos(k * w)]])
for p in [0, 17, 60]:
    v = torch.stack([emb[p, 2 * i], emb[p, 2 * i + 1]])
    v_shift = torch.stack([emb[p + k, 2 * i], emb[p + k, 2 * i + 1]])
    assert torch.allclose(M @ v, v_shift, atol=1e-5)

# 验证 RoPE: 同一对 q, k 放在 (3, 5) 和 (10, 12), 点积相同, 只依赖相对距离 2
q, kv = torch.randn(64), torch.randn(64)
seq_q = apply_rope(q.expand(1, 1, 16, 64).clone())
seq_k = apply_rope(kv.expand(1, 1, 16, 64).clone())
s1 = seq_q[0, 0, 3] @ seq_k[0, 0, 5]
s2 = seq_q[0, 0, 10] @ seq_k[0, 0, 12]
assert torch.allclose(s1, s2, atol=1e-4)
```

这段代码说明两件事. 第一, `M` 只由偏移 `k` 和频率 `w` 决定, 对三个不同的 `p` 都成立, 这就是式 (35) 里 $M_k$ 不依赖 $pos$ 的含义. 第二, `apply_rope` 之后点积只依赖位置差, 对应 $\mathbf{R}_m^T \mathbf{R}_n = \mathbf{R}_{n-m}$.

## 7. 损失函数

损失函数定义了什么样的预测算好, 它决定了梯度朝哪个方向推参数. 语言模型主要用交叉熵, 强化学习的价值函数和部分蒸馏用 MSE, 表示学习和奖励模型用对比损失.

### 7.1 交叉熵: 语言模型的训练目标

对单个样本, 真实类别为 $y \in \{1, 2, \dots, C\}$, 模型输出 logits $\mathbf{z} = [z_1, \dots, z_C]$(logits 指 softmax 之前的原始分数). Softmax 把 logits 变成预测分布 $\hat{\mathbf{p}} = [\hat{p}_1, \dots, \hat{p}_C]$:

$$
\hat{p}_i = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}} \tag{39}
$$

式 (39) 中指数保证每个输出为正, 分母保证和为 1. 实现上先减去 $\max_j z_j$ 再取指数, 结果不变, 但避免溢出. 交叉熵损失为:

$$
\mathcal{L}_{CE} = -\sum_{i=1}^{C} p_i \log \hat{p}_i = -\log \hat{p}_y \tag{40}
$$

$p_i$ 是真实分布, 这里是 one-hot, 只有 $p_y = 1$, 所以式 (40) 化简为正确类别的负对数似然(Negative Log-Likelihood, NLL). 语言模型的预训练目标就是对每个位置的下一个 token 算式 (40), 再对所有位置取平均; perplexity 是这个平均损失的指数.

#### 信息论含义与梯度

交叉熵可以分解为 $H(p, \hat{p}) = H(p) + D_{KL}(p \,\|\, \hat{p})$. 真实分布是 one-hot 时熵 $H(p) = 0$, 交叉熵就等于 KL 散度, 即用 $\hat{p}$ 编码真实分布比最优编码多出的平均码长. $-\log \hat{p}_y$ 本身是事件 $y$ 在模型下的自信息(surprisal).

把式 (39) 代入式 (40) 求导, 损失对 logits 的梯度形式很简单:

$$
\frac{\partial \mathcal{L}_{CE}}{\partial z_i} = \hat{p}_i - p_i
$$

正确类别的梯度是 $\hat{p}_y - 1$, 其他类别是 $\hat{p}_i$. $\hat{p}_y \to 0$ 时损失 $-\log \hat{p}_y$ 无界增长, 但对 logits 的梯度有界, 模值不超过 1, 所以 softmax 加交叉熵不会因为预测错得离谱而出现梯度爆炸.

**标签平滑(Label Smoothing)**: one-hot 目标会持续推高正确类别的 logit, 模型趋向过度自信. 标签平滑([Szegedy et al. 2016](https://arxiv.org/abs/1512.00567))把目标分布从 $[0, 0, 1, 0]$ 改成 $[\epsilon/(C-1), \epsilon/(C-1), 1-\epsilon, \epsilon/(C-1)]$, 给其他类别留少量概率. 原始 Transformer 用 $\epsilon_{ls} = 0.1$, 论文写明这会让 perplexity 变差, 但提高了准确率和 BLEU.

#### 代码: 交叉熵

```python
import torch
import torch.nn.functional as F

def cross_entropy_manual(logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
    """
    对应公式 (39)(40): L = -log(softmax(logits)[target])
    logits: (batch_size, num_classes); targets: (batch_size,)
    """
    stabilized = logits - logits.max(dim=-1, keepdim=True).values  # 减最大值防溢出
    exp_logits = torch.exp(stabilized)
    probs = exp_logits / exp_logits.sum(dim=-1, keepdim=True)
    target_probs = probs[torch.arange(logits.size(0)), targets]
    return (-torch.log(target_probs + 1e-10)).mean()

batch_size, num_classes = 8, 1000
logits = torch.randn(batch_size, num_classes)
targets = torch.randint(0, num_classes, (batch_size,))
print(f"手动 CE: {cross_entropy_manual(logits, targets).item():.6f}")
print(f"PyTorch CE: {F.cross_entropy(logits, targets).item():.6f}")  # 两者一致
```

### 7.2 均方误差: 回归目标

$$
\mathcal{L}_{MSE} = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2 \tag{41}
$$

$N$ 是样本数, $\hat{y}_i$ 是预测值, $y_i$ 是目标值. 平方使大误差受到更重的惩罚: 偏差 10 的损失是偏差 5 的 4 倍. 这也意味着 MSE 对离群点敏感.

在 LLM 相关的训练里, MSE 出现在三类地方: 强化学习中 critic 网络用 MSE 拟合回报; 知识蒸馏里直接匹配教师和学生的 logits, [Hinton et al. (2015)](https://arxiv.org/abs/1503.02531) 指出这是带温度的软标签交叉熵在高温极限下的特例; 部分自监督表示学习, 如 BYOL([Grill et al. 2020](https://arxiv.org/abs/2006.07733)), 用归一化向量之间的 MSE 让两个视图的表示靠近.

### 7.3 对比损失: 学习哪些样本相近

问题是: 很多任务没有类别标签, 只有「这两个样本应该相近, 那些应该远离」这类信号. 对比损失把这种信号变成一个分类问题.

#### InfoNCE

InfoNCE([van den Oord et al. 2018](https://arxiv.org/abs/1807.03748))是 SimCLR([Chen et al. 2020](https://arxiv.org/abs/2002.05709)), CLIP([Radford et al. 2021](https://arxiv.org/abs/2103.00020))等方法的基础:

$$
\mathcal{L}_{\text{InfoNCE}} = -\log \frac{e^{\text{sim}(\mathbf{z}_i, \mathbf{z}_i^+) / \tau}}{e^{\text{sim}(\mathbf{z}_i, \mathbf{z}_i^+) / \tau} + \sum_{j} e^{\text{sim}(\mathbf{z}_i, \mathbf{z}_j^-) / \tau}} \tag{42}
$$

其中 $\mathbf{z}_i$ 是锚点(anchor)样本的表示, $\mathbf{z}_i^+$ 是与它配对的正样本, $\mathbf{z}_j^-$ 是负样本, $\text{sim}(\cdot, \cdot)$ 通常是余弦相似度或点积, $\tau$ 是温度.

#### 多分类视角与温度

式 (42) 就是式 (39)(40) 的交叉熵: 把相似度除以 $\tau$ 当 logits, 锚点要在 $\{1^+, 1^-, 2^-, 3^-, \dots\}$ 这个候选集合里认出自己的正样本. 温度 $\tau$ 控制 softmax 的尖锐程度:

- **$\tau$ 小(CLIP 初始化为 0.07)**: 相似度的微小差异被放大, 梯度集中在与锚点最相似的少数难负样本上, 区分度强, 但对假负样本(其实语义相同却被当成负样本)敏感, 优化也更难.
- **$\tau$ 大**: 分布平缓, 所有负样本的梯度接近, 训练稳定, 但学到的表示区分度下降.

#### 和奖励模型, DPO 的关系

RLHF 的奖励模型用 Bradley-Terry 模型([Bradley & Terry 1952](https://doi.org/10.2307/2334029))从成对偏好里学习. 记 $r(x, y)$ 为奖励模型给提示 $x$ 和回答 $y$ 的分数, $y_w$ 是人更偏好的回答, $y_l$ 是另一个, InstructGPT([Ouyang et al. 2022](https://arxiv.org/abs/2203.02155))的奖励模型损失是:

$$
\mathcal{L}_{\text{RM}} = -\log \sigma\left( r(x, y_w) - r(x, y_l) \right) = -\log \frac{e^{r(x, y_w)}}{e^{r(x, y_w)} + e^{r(x, y_l)}}
$$

对照式 (42), Bradley-Terry 损失可以看成只有一个负样本, 温度 $\tau = 1$, 相似度换成奖励分数的 InfoNCE. DPO([Rafailov et al. 2023](https://arxiv.org/abs/2305.18290))把奖励写成策略与参考模型的对数概率比 $\beta \log \frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)}$, 代回同一个 Bradley-Terry 损失, 从而不必单独训练奖励模型. 句向量模型(如 BGE, [Xiao et al. 2023](https://arxiv.org/abs/2309.07597))则直接用式 (42), batch 内其他样本当负样本.

#### 代码: InfoNCE

```python
import torch
import torch.nn.functional as F

def info_nce_loss(anchor: torch.Tensor, positive: torch.Tensor,
                  negatives: torch.Tensor, temperature: float = 0.07) -> torch.Tensor:
    """
    对应公式 (42)
    anchor: (d,), positive: (d,), negatives: (num_negatives, d)
    """
    sim_pos = F.cosine_similarity(anchor.unsqueeze(0), positive.unsqueeze(0), dim=-1)  # (1,)
    sim_negs = F.cosine_similarity(anchor.unsqueeze(0), negatives, dim=-1)             # (num_negatives,)
    logits = torch.cat([sim_pos, sim_negs]) / temperature  # 正样本在索引 0
    return -F.log_softmax(logits, dim=0)[0]

anchor = torch.randn(128)
positive = anchor + torch.randn(128) * 0.1  # 与锚点高度相似
negatives = torch.randn(10, 128)            # 随机负样本, 余弦相似度接近 0

for tau in [0.01, 0.07, 1.0]:
    loss = info_nce_loss(anchor, positive, negatives, temperature=tau)
    print(f"tau={tau:.2f}, loss={loss.item():.4f}")
# 正样本明显比负样本相似时, tau 越小 loss 越接近 0; tau=1 时 loss 约为 log(1 + 10/e)
```

## 8. 从 RNN/LSTM 到 Transformer

Transformer 之前, 序列建模的主流是循环神经网络(RNN)及其门控版本 LSTM 和 GRU. 它们的两个局限, 即长程梯度和串行计算, 是自注意力要解决的问题.

### 8.1 RNN: 用一个隐藏状态累积历史

RNN 在每个时间步 $t$ 读入输入 $\mathbf{x}_t$, 和上一步的隐藏状态 $\mathbf{h}_{t-1}$ 一起更新出 $\mathbf{h}_t$. $\mathbf{W}_{hh}$ 是隐藏到隐藏的权重, $\mathbf{W}_{xh}$ 是输入到隐藏的权重, $\mathbf{b}_h$ 是偏置:

$$
\mathbf{h}_t = \tanh(\mathbf{W}_{hh} \mathbf{h}_{t-1} + \mathbf{W}_{xh} \mathbf{x}_t + \mathbf{b}_h) \tag{43}
$$

每一步的输出 $\hat{\mathbf{y}}_t$ 由 $\mathbf{h}_t$ 经输出权重 $\mathbf{W}_{hy}$ 和偏置 $\mathbf{b}_y$ 得到:

$$
\hat{\mathbf{y}}_t = \mathbf{W}_{hy} \mathbf{h}_t + \mathbf{b}_y \tag{44}
$$

$\mathbf{h}_t$ 是前 $t$ 个输入的一个固定维度的摘要. 式 (43) 的递推结构让 RNN 可以处理任意长度的序列, 参数量不随长度增长. 它的问题有三个.

1. **无法沿时间并行**: 计算 $\mathbf{h}_t$ 必须先算完 $\mathbf{h}_{t-1}$, 长度为 $T$ 的序列需要 $T$ 步串行计算, GPU 的并行能力只能用在 batch 和隐藏维上.
2. **长程梯度消失或爆炸**: 误差从时间步 $T$ 传回时间步 $t$, 要乘 $T-t$ 个雅可比矩阵:

$$
\frac{\partial \mathcal{L}}{\partial \mathbf{h}_t} = \frac{\partial \mathcal{L}}{\partial \mathbf{h}_T} \cdot \prod_{k=t}^{T-1} \frac{\partial \mathbf{h}_{k+1}}{\partial \mathbf{h}_k} \tag{45}
$$

由式 (43), 每个因子是 $\frac{\partial \mathbf{h}_{k+1}}{\partial \mathbf{h}_k} = \text{diag}(1 - \mathbf{h}_{k+1}^2)\, \mathbf{W}_{hh}$. [Bengio et al. (1994)](https://doi.org/10.1109/72.279181) 分析了这串连乘, [Pascanu et al. (2013)](https://arxiv.org/abs/1211.5063) 给出条件: 对 tanh 而言, $\mathbf{W}_{hh}$ 的最大奇异值小于 1 足以导致梯度消失, 大于 1 是梯度爆炸的必要条件. 两种情况都随 $T - t$ 指数变化, 远处的输入对参数更新的影响要么消失, 要么淹没其他信号. 爆炸可以用梯度裁剪压住, 消失没有这么简单的补救.

3. **信息瓶颈**: 整段历史被压进一个固定维度的 $\mathbf{h}_t$, 序列越长, 早期信息越容易被后续输入覆盖.

### 8.2 LSTM: 加一条乘遗忘门的细胞状态

LSTM(Long Short-Term Memory, [Hochreiter & Schmidhuber 1997](https://doi.org/10.1162/neco.1997.9.8.1735))针对式 (45) 的连乘, 引入独立的细胞状态 $\mathbf{C}_t$ 和三个门. 记 $[\mathbf{h}_{t-1}, \mathbf{x}_t]$ 为上一步隐藏状态与当前输入的拼接. 遗忘门 $\mathbf{f}_t$ 决定旧细胞状态的每个分量保留多少:

$$
\mathbf{f}_t = \sigma(\mathbf{W}_f [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_f) \tag{46}
$$

输入门 $\mathbf{i}_t$ 决定新内容写入多少:

$$
\mathbf{i}_t = \sigma(\mathbf{W}_i [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_i) \tag{47}
$$

候选细胞状态 $\tilde{\mathbf{C}}_t$ 是待写入的新内容:

$$
\tilde{\mathbf{C}}_t = \tanh(\mathbf{W}_C [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_C) \tag{48}
$$

细胞状态的更新是旧状态按遗忘门逐分量缩放, 再加上按输入门缩放的新内容:

$$
\mathbf{C}_t = \mathbf{f}_t \odot \mathbf{C}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{C}}_t \tag{49}
$$

输出门 $\mathbf{o}_t$ 决定细胞状态的哪些部分输出为隐藏状态:

$$
\mathbf{o}_t = \sigma(\mathbf{W}_o [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_o) \tag{50}
$$

$$
\mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{C}_t) \tag{51}
$$

式 (46) 和式 (47) 的 Sigmoid 输出 $(0, 1)$ 之间的系数, 分别控制保留旧信息和写入新信息的比例; 式 (49) 是 LSTM 改善梯度传播的地方; 式 (51) 把细胞状态经 tanh 压缩后由输出门筛选成隐藏状态.

#### 细胞状态上的梯度

只看式 (49) 里 $\mathbf{C}_{t-1}$ 直接出现的那一项, $\partial \mathbf{C}_t / \partial \mathbf{C}_{t-1} = \text{diag}(\mathbf{f}_t)$. 沿细胞状态从 $T$ 传回 $t$, 梯度乘的是 $\prod_{k=t+1}^{T} \mathbf{f}_k$, 每一步乘一次遗忘门, 没有 $\mathbf{W}_{hh}$ 和 tanh 导数. 遗忘门接近 1 的分量上梯度衰减很少, 遗忘门小的分量上梯度照样指数衰减. 所以 LSTM 是让网络通过学习遗忘门来决定哪些信息, 以及对应的梯度, 能保留多久, 而不是保证梯度不衰减. 1997 年的原始 LSTM 没有遗忘门, 相当于 $\mathbf{f}_t \equiv 1$; 遗忘门是 [Gers et al. (2000)](https://doi.org/10.1162/089976600300015015) 加上的, 用来让网络能主动清空细胞状态. GRU([Cho et al. 2014](https://arxiv.org/abs/1406.1078))把遗忘门和输入门合成一个更新门, 去掉了独立的细胞状态.

边界: LSTM 改善的是梯度传播, 没有改变计算结构. 式 (46)–(51) 的每个门都依赖 $\mathbf{h}_{t-1}$, 训练仍然要按时间步串行, 两个远距离位置之间的计算路径长度仍随间隔线性增长.

### 8.3 自注意力: 任意两个位置一步相连

[Vaswani et al. (2017)](https://arxiv.org/abs/1706.03762) 的 *Attention Is All You Need* 去掉了循环结构, 用**自注意力(Self-Attention)**建模序列依赖. 对序列中每个位置的表示 $\mathbf{x}_i$, 用三个投影矩阵算出 $\mathbf{q}_i = \mathbf{x}_i W_Q$, $\mathbf{k}_i = \mathbf{x}_i W_K$, $\mathbf{v}_i = \mathbf{x}_i W_V$. 位置 $i$ 的输出是所有位置 $\mathbf{v}_j$ 的加权和, 权重由 $\mathbf{q}_i$ 与 $\mathbf{k}_j$ 的点积经 softmax 得到. 把所有位置堆成矩阵 $\mathbf{Q}, \mathbf{K}, \mathbf{V}$, $d_k$ 为 Key 的维度:

$$
\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left( \frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{d_k}} \right) \mathbf{V} \tag{52}
$$

除以 $\sqrt{d_k}$ 是因为分量独立, 方差为 1 时点积的方差是 $d_k$, 不缩放的话 softmax 容易饱和. 式 (52) 的逐步展开和手算例子见 [2.2 基础注意力机制](../2.2-基础注意力机制/2.2-基础注意力机制.md).

Vaswani et al. 的 Table 1 把自注意力层和循环层放在同一组维度上比较, $n$ 为序列长度, $d$ 为表示维度:

| 层类型 | 每层计算量 | 串行操作数 | 任意两位置间最长路径 |
| --- | --- | --- | --- |
| 自注意力 | $O(n^2 \cdot d)$ | $O(1)$ | $O(1)$ |
| 循环层 | $O(n \cdot d^2)$ | $O(n)$ | $O(n)$ |

由此有两点. 第一, 训练时所有位置的 $\mathbf{Q}, \mathbf{K}, \mathbf{V}$ 和注意力权重可以同时计算, 串行步数不随序列长度增长. 第二, 任意两个位置在一层注意力内直接交互, 梯度不必穿过中间的每一步, 式 (45) 那串随距离增长的连乘不再出现. 需要说明, 自回归生成时 Transformer 仍然一次只产生一个 token, 并行只在训练和 prefill 阶段成立, decode 阶段靠 KV Cache 避免重复计算历史.

注意力权重常被当作解释工具, 把它画成热力图, 看哪个词「关注」了哪个词. 这只是权重分布, 不等于解释. [Jain & Wallace (2019)](https://arxiv.org/abs/1902.10186) 发现, 注意力权重与基于梯度的特征重要性往往相关性很弱, 而且可以构造出差别很大的注意力分布, 却得到几乎相同的预测.

**代价**: 每层计算量是 $O(n^2 d)$, 朴素实现还要把 $n \times n$ 的分数矩阵存下来. 128K 上下文时一个头的分数矩阵有 $131072^2 \approx 1.7 \times 10^{10}$ 个元素, FP16 下约 34 GB. FlashAttention 通过分块计算避免把这个矩阵写回显存, 但计算量仍是 $O(n^2 d)$; 稀疏注意力和线性注意力则尝试降低计算量本身, 见 [2.3 高效与稀疏注意力](../2.3-高效与稀疏注意力/2.3-高效与稀疏注意力.md).
