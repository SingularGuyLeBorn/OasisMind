# 2.1.2 归一化层

在深度学习早期,训练深层网络非常依赖初始化,学习率和梯度裁剪等经验性设置.核心困难在于梯度信号在多层传递时容易消失或爆炸,损失曲面对优化器过于敏感,深层训练稳定性差.

归一化层不直接增加模型容量,也不直接提升某项基准分数,但它通过约束中间表示的数值分布,让优化过程更平滑,更可控,并支持更深层的网络.可以把它的作用概括为:不为 Attention,FFN 或位置编码提供新能力,但为这些模块提供稳定的数值范围,使其能正常工作.

对于现代大语言模型,归一化层的重要性比早期更高.模型越深,参数越多,上下文越长,精度越低,对数值稳定性的要求越严格.BatchNorm,LayerNorm,RMSNorm,Pre-Norm,Post-Norm 这些选择不仅影响训练稳定性,也影响推理效率,量化可行性和长上下文能力.

本文围绕五个问题展开:

1. 归一化层到底在稳定什么.
2. 为什么 BatchNorm 在视觉任务中有效,却不适合 LLM 主干.
3. 为什么 LayerNorm 成为 Transformer 时代的核心,以及 RMSNorm 为何进一步替代它.
4. 为什么 Pre-Norm 几乎成为大模型默认结构.
5. 为什么归一化层成为训练,量化,长上下文和工程部署中的隐性关键模块.

## 1. 归一化层解决的核心问题

最常见的粗略说法是:归一化层可以「减少内部协变量偏移」.这里的「协变量」指参与描述输入或中间表示分布的特征变量,「偏移」指这些变量的统计范围在训练过程中不断变化.这种说法有启发性,但不够准确.更严格的理解是:归一化层通过约束中间激活的尺度与分布,让优化景观更平滑,从而使梯度下降更可预测,学习率更宽容,深层训练更稳定.

这个问题可以从三个层面理解.

第一,激活值如果逐层放大或塌缩,后续模块就会在异常数值范围内工作.放大指层输出幅值越来越大,塌缩指输出越来越接近零.这会导致注意力 logits,FFN 中间态或残差主干的数值持续漂移.logits 指模块在 softmax 或离散决策前输出的原始分数,残差主干指跨层直接相加的主路径,负责把早期信息稳定地传到更深层.

第二,混合精度训练会放大这类数值问题,因为 BF16,FP16 以及更低精度对异常幅值更敏感.

第三,网络越深,这些小的分布偏移越容易在主干上逐层累积,最终破坏整个优化过程.分布偏移指激活值的均值,方差或整体尺度在层与层之间不断变化,后续模块不得不持续适应新的输入范围.

因此,归一化层的工作不是让所有层输出一致,而是防止它们失控.它持续约束可能发散的表示,将其拉回优化器能够处理的范围.

- batch loss 到参数更新的边携带梯度 $\nabla_\theta\mathcal{L}$。归一化参数 $\gamma,\beta$ 或 $g$ 是可学习参数，也参与这一步更新。
- 激活 mean、RMS 和 outlier rate 可按层与训练步记录。比较不同精度实现时须固定输入、参数和其余设置。
- 局部统计稳定不等于全局损失曲面、收敛速度或最终性能的保证；这些结论需要结合完整结构、学习率、初始化和实际测量判断。

## 2. BatchNorm: 卷积时代的关键发明,为什么不适合 LLM 主干

[Ioffe & Szegedy (2015)](https://arxiv.org/abs/1502.03167) 提出的 Batch Normalization,简称 **BatchNorm**,是深度学习训练史上的重要方法.这里的小批量(mini-batch)指一次参数更新时同时送入模型的一批样本.其核心思路是:利用当前小批量的统计量,对每个特征维度做标准化,再通过可学习参数恢复表示能力.

给定一个批次输入 $B=[x_1, ..., x_m]$,对某个特征维度,BatchNorm 先计算批次均值与方差:

$$
\mu_B=\frac{1}{m}\sum_{i=1}^{m}x_i
$$

$\mu_B$ 表示当前 batch 在该维度上的平均水平,为后续标准化提供中心参照.

$$
\sigma_B^2=\frac{1}{m}\sum_{i=1}^{m}(x_i-\mu_B)^2
$$

$\sigma_B^2$ 表示当前 batch 在该维度上的离散程度,即样本围绕均值的波动范围.只有知道中心和波动范围,才能将不同 batch 拉回相近尺度.

然后执行标准化与可学习仿射变换:

$$
\hat{x}_i=\frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}
$$

这一步把输入重新压到更稳定的数值范围.$\epsilon$ 是一个很小的数值稳定项,避免分母过小甚至为零.

$$
y_i=\gamma \hat{x}_i+\beta
$$

$\gamma,\beta$ 是可学习参数.BatchNorm 把当前 batch 的该维特征拉回「零均值,单位方差」的尺度附近,再允许模型学会恢复最合适的缩放和平移.如果没有这一步,归一化会把表示固定得过死,反而削弱网络表达能力.

在卷积网络中,这种方法非常有效.图像任务里,同一层特征在 batch 内往往有较强统计一致性,且卷积结构本身也容易从 batch 统计中获益.BatchNorm 显著提升了 CNN 的训练稳定性和收敛速度.

但它并不适合作为 LLM 主干的归一化方案,原因主要有三个.第一,NLP 序列长度动态变化,padding token 容易污染 batch 统计量.第二,自回归推理是逐 token 生成,推理时很难获得与训练一致的 batch 统计.第三,大模型训练和部署阶段常常使用很小的 micro-batch,这会让 BatchNorm 的统计量本身噪声很大.

因此,BatchNorm 在视觉模型中占主导地位,在 LLM 主干中基本退出.这一点说明了一个核心事实: **归一化不是通用的,而是强依赖数据结构和推理模式.**

## 3. LayerNorm: Transformer 时代为什么按特征归一化

[Ba, Kiros, & Hinton (2016)](https://arxiv.org/abs/1607.06450) 提出的 **Layer Normalization**,简称 **LayerNorm**,是归一化轴的一次关键旋转:它不再跨 batch 统计,而是对**单个样本内部的特征维度**做归一化.

对于一个 token 表示 $x\in\mathbb{R}^d$,LayerNorm 先计算该 token 的层内均值与方差:

$$
\mu_L=\frac{1}{d}\sum_{j=1}^{d}x_j
$$

$\mu_L$ 是当前 token 在所有特征维度上的平均值.它回答的问题不是「这一批样本平均怎样」,而是「这一个 token 自己当前整体偏到哪里去了」.

$$
\sigma_L^2=\frac{1}{d}\sum_{j=1}^{d}(x_j-\mu_L)^2
$$

$\sigma_L^2$ 是当前 token 内部各维特征的波动范围.它衡量的是这个表示向量本身是否过度发散,而不是 batch 内不同样本之间是否一致.

然后进行标准化与仿射变换:

$$
\text{LN}(x)=\frac{x-\mu_L}{\sqrt{\sigma_L^2+\epsilon}}\odot \gamma+\beta
$$

其中 $\gamma,\beta\in\mathbb{R}^d$ 是逐维度可学习参数,$\odot$ 表示逐元素乘法.和 BatchNorm 相比,LayerNorm 的关键变化在于:它完全不依赖 batch 统计,因此对 batch size 不敏感,对 padding 噪声也不敏感,训练和推理阶段的行为更加一致.

这恰好击中了 NLP 和 Transformer 的核心需求.每个 token 都有自己的表示,每个位置都可以独立完成归一化,不必依赖同批次中其他样本的分布.这使 LayerNorm 成为 Transformer 时代真正意义上的基础设施.

![Temporal BatchNorm 与 LayerNorm 的统计组：BN 在固定特征上聚合 batch 和序列位置，LN 只聚合同一 token 的最后特征维](./images/redrawn-image_3-v2.png)

> 图 2: 以逻辑 shape $[B,S,d]$ 示意。Temporal BatchNorm 在固定特征维上聚合 $B\times S$ 个单元；LayerNorm 对固定 $(b,s)$ 的 token 沿 $d$ 聚合。

**图 2 解析**

- 对 Temporal BatchNorm，固定一个特征 $f$ 后，统计组为所有 $(b,s)$ 位置。PyTorch `BatchNorm1d` 的序列接口为 $[B,d,S]$，与这里的逻辑 $[B,S,d]$ 只是维度顺序不同。
- 对 LayerNorm，固定一个 token 位置 $(b,s)$ 后，只对它的最后特征维 $d$ 计算统计量，不借用其它 token 或其它样本的统计量。
- 默认 `track_running_stats=True` 时，BatchNorm 推理使用运行统计量；LayerNorm 在训练和推理均用当前输入统计量。LayerNorm 不会自动忽略 padding，padding mask 仍由 Attention、loss 或数据管线处理。

## 4. RMSNorm: 大模型为什么开始去掉均值中心化

[Zhang & Sennrich (2019)](https://arxiv.org/abs/1910.07467) 提出的 **RMSNorm**,可以看作对 LayerNorm 的一次极简化:它保留了尺度归一化,但去掉了均值中心化.

其核心定义是:

$$
\text{RMS}(x)=\sqrt{\frac{1}{d}\sum_{j=1}^{d}x_j^2+\epsilon}
$$

RMS 表示均方根尺度,即这个向量整体有多大.它关心的是表示的模长是否稳定,而不是均值是否恰好落在零点附近.

$$
\text{RMSNorm}(x)=\frac{x}{\text{RMS}(x)}\odot g
$$

这里 $g\in\mathbb{R}^d$ 是逐维度可学习增益参数.与 LayerNorm 相比,RMSNorm 不再计算均值 $\mu_L$,也不再执行减均值操作,只保留「按均方根缩放」这一步.

为什么这样做有效?因为在很多高维表示空间里,真正重要的是**向量的尺度是否可控**,而不是均值是否恰好被移到零点.对大模型来说,去掉均值分支意味着:

- 少一组归约(reduce)统计;
- 少一次减法路径;
- 算子更容易融合;
- 数值路径更短.

从工程角度看,这正是大模型时代需要的简化.RMSNorm 因此成为 Llama,Qwen 等现代大模型的主流选择.

![LayerNorm 与 RMSNorm 的完整计算路径：中心化、缩放分母、epsilon 与可学习仿射参数均连接到真实消费者](./images/redrawn-image_4-v3.png)

> 图 3: 对单个 token 向量，LayerNorm 先计算均值并中心化，再计算缩放分母；RMSNorm 直接由输入计算均方根分母。两图的每个除法节点都显示分子、分母与仿射参数来源。

**图 3 解析**

- LayerNorm 中 $x$ 同时用于求均值与中心化，$z=x-\mu$ 同时用于计算分母 $s_L$ 和作为除法分子；$\epsilon$ 进入根号内，$\gamma,\beta$ 进入最后的仿射变换。
- RMSNorm 中输入 $x$ 同时用于均方根 $s_R$ 和除法分子，随后只有逐维增益 $g$；它没有均值或中心化计算节点。
- 两种方法都沿最后特征维计算统计量，输入和输出形状相同。RMSNorm 的计算减少不代表 LayerNorm 的数学目标错误；具体融合收益取决于实现和硬件。

## 5. Pre-Norm 为什么几乎成为大模型默认结构

归一化层不只是「谁来做,怎么算」的问题,还涉及它**放在残差结构的哪里**.这就是 Transformer 发展史上的一个关键分歧:**Post-Norm** 与 **Pre-Norm**.Post-Norm 指「先做子层和残差相加,再归一化」,Pre-Norm 指「先归一化,再送入子层」.

Post-Norm 写成:

$$
x_{l+1}=\text{Norm}(x_l+F(x_l))
$$

Pre-Norm 写成:

$$
x_{l+1}=x_l+F(\text{Norm}(x_l))
$$

这两个公式看起来只是顺序交换,但训练行为差异很大.Pre-Norm 的优势在于,它给残差主干保留了一条更清晰的恒等路径.把式子递归展开,输入信号可以更直接地跨层累积,而不必在每层都先穿过一个归一化层再回传梯度.

这个恒等项有助于解释 Pre-Norm 的优化特性。[Xiong 等人（2020）](https://proceedings.mlr.press/v119/xiong20b.html) 分析了初始化时的梯度尺度，并在所测 Transformer 设置中验证了 Pre-LN 的训练优势。具体稳定性和效果仍取决于初始化、深度、残差缩放与学习率设置。

![Post-LN 与 Pre-LN 单子层前向：原输入沿恒等捷径进入加法点，LayerNorm 分别位于加法后与子层前](./images/redrawn-fig-preln-vs-postln-v2.png)

> 图 4: Post-LN 对相加结果归一化，Pre-LN 只对子层输入归一化。两列均为单子层前向，采用等维恒等捷径；图中省略 dropout 与堆叠末端的最终归一化。残差展开见 [2.1.3](../2.1.3-残差连接/2.1.3-残差连接.md)。

**图 4 解析**

- Post-LN：$x_l$ 与 $F(x_l)$ 分别进入 Add，相加结果再经过 LayerNorm。
- Pre-LN：$x_l$ 一路经过 LayerNorm 和 $F$，另一路保持原值进入 Add；恒等捷径的来源是归一化之前的输入。
- 输入、子层输出与相加结果均为 $[B,S,d]$，LayerNorm 沿最后的特征维 $d$ 计算统计量。$F$ 表示一个 Attention 或 FFN 子层。

## 6. 归一化层为什么会成为工程隐性瓶颈

归一化层不是参数大头,也不是 FLOPs 大头,但它常常是**数值稳定性,精度路径和算子融合**的关键节点.算子(kernel)指 GPU 上执行某一步计算的底层实现,融合(fusion)指把多步本来分开的操作拼成一次更大的底层计算,减少中间读写与调度开销.真正的工程难点不在于归一化本身复杂,而在于它刚好卡在所有主干模块的输入输出之间.

先看训练阶段.归一化层会参与每一次前向和每一次反向,而且它的归约(reduce)操作天然比简单逐元素算子更敏感.reduce 指沿某个维度把很多数聚合成少量统计量,例如求和,求均值,求方差.若统计量不在 FP32 中累加,或融合算子(fused kernel)与参考实现(reference implementation)存在微小差异,这些误差会在长训练中被放大.参考实现指最标准,最直接,通常也最慢的对照实现,常被用来检查高性能实现有没有算偏.

再看推理阶段.归一化层虽然单层不重,但层数很多,而且常常需要和残差相加(residual add),dropout,线性投影(linear projection)一起融合,才能避免算子启动(kernel launch)过碎.算子启动指 GPU 每调用一次底层算子都要付出的调度成本;步骤拆得太碎,调度本身就会变贵.对大模型部署来说,归一化层属于「单层不贵,总量不小,容易被忽视」的模块.

最后看量化.归一化层本质上是在管理激活的尺度分布.只要这一步失真,后面的 FFN,Attention 或输出层量化误差都会被系统性放大.所以归一化层虽然不是量化压缩的主要对象,却常常是量化成败的隐性前提.

## 7. 训练,量化与长上下文中的检查重点

归一化层的工程价值,最终会体现在一组具体检查项上.训练时,最值得监控的是:

1. 归一化前后激活 RMS 或方差是否稳定.
2. 增益参数 $\gamma$ 是否出现异常漂移.
3. LayerNorm / RMSNorm 输出分布是否在深层持续扩张或塌缩.
4. 混合精度下是否出现归约路径溢出.
5. 融合算子与参考实现是否数值一致.

量化时,应重点关注:

1. 归一化输出分布是否仍与高精度版本接近.
2. norm 层是否需要在更高精度中执行.
3. 量化前后余弦相似度是否在深层明显恶化.

长上下文时,则更应关注:

1. 归一化输出尺度是否随长度逐步漂移.
2. 残差主干幅值是否累积放大.
3. 深层 attention / FFN 前的输入分布是否越来越极端.

这些指标看起来琐碎,但它们往往比单看全局损失(loss)更接近问题本源.loss 指模型当前输出与目标之间的总体误差;它能告诉你「整体好不好」,却不一定能告诉你「是哪一层先坏了」.很多「模型怎么突然不稳了」的问题,最后都会在归一化层的统计上留下痕迹.

![归一化层诊断：记录输入、统计量、修正与输出，并在固定比较条件下检查精度和量化输出差异](./images/redrawn-fig-norm-diagnostics-v4.png)

> 图 5: 在同一输入位置记录 $x$、归一化统计量、$\Delta=F(\mathrm{Norm}(x))$ 与 $y=x+\Delta$。所有结果栏为待测，指标用于定位，不能单独证明因果。

**图 5 解析**

- 记录点：对同一输入位置记录输入 $x$、LayerNorm 的 $\mu,v$ 或 RMSNorm 的 $r$、子层修正 $\Delta$ 与输出 $y$。统计量均沿最后特征维计算。
- 参数与精度：单独记录 $\gamma,\beta$ 的层间和通道变化；精度比较固定同一输入、同一参数与其余设置，分别得到 FP32 与低精度输出，再计算相对差异。
- 量化：令 $Q(y_{32})$ 表示同一 FP32 输出先量化再反量化，比较它与 $y_{32}$ 的局部输出差异。该指标不代表整个模型的量化性能。
- 先定位首次异常层，再分别检查输入统计、归一化实现、参数、精度和量化设置；只有填入真实测量并结合层间趋势和任务表现，才能形成结论。

## 8. 极简实现: LayerNorm 与 RMSNorm 的 PyTorch 映射

下面用极简代码说明这两类归一化层在实现上的核心差别:

```python
import torch
import torch.nn as nn

class SimpleLayerNorm(nn.Module):
    def __init__(self, dim: int, eps: float = 1e-5):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(dim))
        self.bias = nn.Parameter(torch.zeros(dim))
        self.eps = eps

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        mean = x.mean(dim=-1, keepdim=True)
        var = (x - mean).pow(2).mean(dim=-1, keepdim=True)
        normed = (x - mean) / torch.sqrt(var + self.eps)
        return normed * self.weight + self.bias

class SimpleRMSNorm(nn.Module):
    def __init__(self, dim: int, eps: float = 1e-5):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(dim))
        self.eps = eps

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + self.eps)
        return (x / rms) * self.weight
```

这段代码清楚说明了两点.第一,LayerNorm 比 RMSNorm 多出「求均值 -> 减均值」这一分支.第二,RMSNorm 的简化并不是偷懒,而是有意识地把归一化保留在「尺度控制」这个最必要的层面上.仿射(affine)变换指最后那一步可学习的缩放和平移变换,它让模型保留「必要时把归一化部分撤回来」的自由度.

## 9. 技术前瞻: 归一化层还会怎么演化

归一化层不是一个已经完全收敛的话题.至少还有四条趋势值得继续关注.

第一,面向融合算子的归一化设计会继续增强.未来很多归一化方案是否能成为主流,不只取决于数学解释,还取决于它是否容易被高效融合进推理路径.

第二,低比特与混合精度会继续反向塑造归一化设计.随着 FP8,FP6,FP4 路线推进,归一化的统计路径,缩放路径和精度路径会变得更敏感.

第三,极深网络与长上下文会继续放大主干稳定性问题,这意味着 Pre-Norm,残差幅值控制和归一化层的协同设计仍然是核心课题.

第四,多模态模型会继续挑战「同一种归一化适合所有模态」这个假设.文本,图像,音频,视频共享主干之后,归一化层很可能承担更多模态对齐职责,而不只是数值稳定职责.

## 10. 本节小结

归一化层不是大模型里最引人注目的模块,但它几乎是最不容失手的模块之一.它的价值不在于单独抬高某个基准测试(benchmark)分数,而在于为整个系统提供一个可扩展,可训练,可量化,可部署的数值基础.

从 BatchNorm 到 LayerNorm,再到 RMSNorm 与 Pre-Norm,归一化层的演化逻辑非常一致:**谁更符合现代模型的训练方式,推理方式和硬件约束,谁就会成为主流.** 对 LLM 而言,归一化层不是附属模块,而是决定模型能否在深度,稳定性,长上下文和效率上同时达标的关键基础设施之一.
