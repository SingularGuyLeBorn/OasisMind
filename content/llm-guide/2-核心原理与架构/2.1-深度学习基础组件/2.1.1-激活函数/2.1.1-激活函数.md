# 2.1.1 激活函数: 非线性,梯度与门控

激活函数在神经网络里只做一件事: 在层与层之间引入非线性. 但「引入非线性」这个表述太轻飘, 容易让人以为它只是点缀. 实际上, 激活函数决定了梯度怎么流,神经元会不会死,输出分布会不会爆炸,低精度推理是否稳定. 对 FFN 来说, 激活函数是两层线性投影之间的唯一非线性环节; 没有它, $W_1$ 与 $W_2$ 就会塌成一层线性映射.

理解激活函数不能只看公式曲线, 而要看三个维度:

1. **梯度行为**: 正区间,负区间,饱和区分别给梯度什么待遇.
2. **稀疏性**: 输出有多少坐标被压到零或接近零.
3. **光滑性**: 函数是否处处可导, 边界是否有折点, 导数变化是否剧烈.

不同的激活函数, 本质是在这三个维度上做不同的取舍.

![Sigmoid,Tanh,ReLU,GELU,SiLU 与 SwiGLU 在梯度行为,稀疏性和光滑性上的取舍](./images/fig-activation-three-way-tradeoff.png)

> 图: 激活函数没有全局最优解. Sigmoid 与 Tanh 光滑但存在饱和区; ReLU 能产生精确稀疏激活, 代价是负区间梯度为零且原点不可导; GELU 与 SiLU 采用平滑软门控, 通常不产生精确的零激活. SwiGLU 严格说不是单变量激活函数, 而是 $\text{SiLU}(xW_g)\odot(xW_u)$ 形式的双支路门控结构: 它保持平滑, 并通过乘性门控形成输入相关的软稀疏.

> FFN 整体结构,工程成本与 MoE 定位见 [2.1.5 前馈网络 FFN](../2.1.5-前馈网络FFN/2.1.5-前馈网络FFN.md).

## 1. 激活函数要解决的根本问题

神经网络的层可以写成复合映射 $f_L \circ f_{L-1} \circ \cdots \circ f_1(x)$. 如果每个 $f_i$ 都是线性变换, 那么无论多少层, 整体仍等价于一个线性变换. 下面给出两层的情形, 多层依此类推.

设 $f_1(x)=W_1 x+b_1$, $f_2(x)=W_2 x+b_2$, 则

$$
f_2(f_1(x))=W_2(W_1 x+b_1)+b_2=(W_2 W_1)x+(W_2 b_1+b_2)=W'x+b'.
$$

复合后仍是线性变换: 权重矩阵变成 $W'=W_2 W_1$, 偏置变成 $b'=W_2 b_1+b_2$. 对 $L$ 层线性网络, 同样的归纳给出

$$
f_L \circ \cdots \circ f_1(x) = (W_L \cdots W_1)x + \tilde{b},
$$

其中 $\tilde{b}$ 是把所有偏置合并后得到的向量. 因此, 没有非线性时, 增加层数只是让可学习参数变多, 模型的函数空间并没有扩大: 它仍然只能表示线性映射. 想要表达能力随深度增长, 必须在某些层插入非线性.

但非线性不是随便加的. 一个好的激活函数至少要同时满足:

- **非线性**: 否则深度失去意义.
- **梯度可传播**: 不能让大部分输入区间的梯度接近零, 否则深层训练瘫痪.
- **输出可控**: 不能让大输入产生无界大输出, 否则量化,混合精度和推理都会出问题.
- **计算友好**: 最好只用基础运算 (乘法,比较,指数等), 工程实现不要引入昂贵特殊函数.

历史上, 激活函数的演进基本围绕「如何在非线性,梯度,稀疏性,光滑性之间重新平衡」展开.

这个平衡的实质不是寻找一个 universally 最优函数, 而是根据模型规模,训练精度和硬件约束, 选择当前最不拖后腿的方案. 小模型优先考虑梯度效率, 大模型优先考虑数值稳定性, 推理侧优先考虑量化友好. 激活函数的每一次主流更替, 本质上都是这三类约束的优先级发生变化后的重新选择.

## 2. 第一代: Sigmoid 与 Tanh 的饱和困境

Sigmoid 和 Tanh 是神经网络早期最常用的激活函数:

$$
\sigma(x)=\frac{1}{1+e^{-x}},
\qquad
\tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}.
$$

两者都把实数输入压缩到有限区间: Sigmoid 到 $(0,1)$, Tanh 到 $(-1,1)$. 这个特性让它们适合输出概率或做门控. 但作为隐藏层激活, 它们有一个共同问题: **两端饱和**.

它们的导数有闭式上界, 而且在 $|x|$ 大时迅速贴零:

$$
\sigma'(x)=\sigma(x)\bigl(1-\sigma(x)\bigr)\le\frac{1}{4},\qquad
\tanh'(x)=1-\tanh^{2}(x)\le 1.
$$

$|x|\to\infty$ 时, 两个导数都趋于 0. 反向传播时, 梯度在这些区域被逐层乘小, 深层网络靠近输入的层几乎学不到东西. 这就是著名的**梯度消失问题**. 在 RNN 和早期深层网络里, 这个缺陷非常致命.

原版 Transformer **没有**把 Sigmoid / Tanh 当作 FFN 的主激活: 论文写明每个位置的前馈是两次线性变换, **中间是 ReLU**. 注意力里的 Softmax 是另一路算子, 不要和 FFN 的激活混为一谈. Sigmoid 和 Tanh 并未消失: Sigmoid 仍是门控逻辑的首选; Tanh 在 LSTM 细胞状态,某些归一化方案和门控残差中仍有使用.

## 3. 第二代: ReLU 的硬阈值革命

ReLU 的公式极其简单:

$$
\text{ReLU}(x)=\max(0,x).
$$

它在正区间是恒等映射, 导数恒为 1; 在负区间输出为零, 导数为零. 这个设计带来几个好处:

- 正区间梯度不衰减, 缓解了深层网络的梯度消失.
- 负区间输出为零, 天然产生稀疏激活, 减少冗余计算.
- 计算极其简单, 只需一个阈值比较.

原版 Transformer 把这件事写进式 (2):

$$
\mathrm{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2.
$$

无偏置版本更常见:

$$
\mathrm{FFN}_{\mathrm{ReLU}}(x)=\max(xW_1,0)\,W_2.
$$

但 ReLU 也有明确代价:

- **神经元死亡**: 若某神经元初始权重或学习率设置不当, 它可能长期停留在负区间, 永远不再更新.
- **负区间信息完全丢失**: 所有负响应被一刀切为零.
- **输出无界**: 大正输入会产生任意大的输出, 给量化带来压力.
- **原点不可导**: 工程上取 $x=0$ 处导数为 $0$ 或 $1$; 对 SGD 通常无妨, 真正棘手的是负区梯度被彻底切断.

这些代价催生了一批 ReLU 的改进版, 如 Leaky ReLU,PReLU,ELU 等. 它们的核心思路都是: 在负区间给一点梯度或给一点非零输出, 让「死亡」不那么绝对.

## 4. 第三代: GELU 与 SiLU 的软门

GELU 和 SiLU 代表了另一种思路: 不再用硬阈值, 而是用概率或 sigmoid 做**软门控**.

SiLU 的公式最直接:

$$
\text{SiLU}(x)=x\cdot\sigma(x).
$$

GELU 的精确形式用高斯 CDF:

$$
\mathrm{GELU}(x)=x\,\Phi(x)=x\cdot\frac{1}{2}\Bigl[1+\mathrm{erf}\bigl(\tfrac{x}{\sqrt{2}}\bigr)\Bigr].
$$

工程上 $\mathrm{erf}$ 不便宜, 常用 tanh 近似:

$$
\mathrm{GELU}(x)\approx 0.5x\Bigl(1+\tanh\Bigl[\sqrt{\tfrac{2}{\pi}}\bigl(x+0.044715x^3\bigr)\Bigr]\Bigr).
$$

SiLU 在 $x$ 很小或很负时输出接近零, 在 $x$ 为正时输出接近 $x$ 本身, 中间过渡平滑. GELU 的随机解释是: 用 $m\sim\mathrm{Bernoulli}(\Phi(x))$ 去乘输入, 再取期望, 得到 $x\Phi(x)$. ReLU 是 $x\cdot\mathbf{1}_{x>0}$ (按**符号**硬门); GELU 是按「这个值相对高斯有多靠右」做**连续加权**. $x\to+\infty$ 时 $\Phi\to 1$, 渐近等于恒等; $x\to-\infty$ 时 $\Phi\to 0$, 输出贴零, 但途中仍有一段非零导数: 负区不是死的.

BERT / GPT 系列把 FFN 的激活从 ReLU 换成 GELU, 动机就是软门,负区还留一点梯度, 优化比硬折更稳. PyTorch `F.gelu` 默认走精确 $\mathrm{erf}$; GPT 系实现里常见 tanh 近似 (Hugging Face 称为 `gelu_new`). 两条曲线在常用区间很近, 但不是逐点相等, 换实现要核对.

这一代激活函数的核心特征是:

- 处处可导, 没有硬折点.
- 负区间保留小梯度, 神经元不容易彻底死亡.
- 正区间近似线性, 不主动压缩大正响应.

![饱和, 硬折, 软门四条示意曲线](./images/fig-act-sigmoid-relu-gelu-silu.png)

> 图 1: 饱和 → 硬折 → 软门的四条示意曲线. 左一 Sigmoid / Tanh 两端贴平; 左二 ReLU 在原点折断, 负轴恒零; 右二 GELU 按 $\Phi(x)$ 软加权; 右一 SiLU $=x\sigma(x)$, 仍是单路. 门控 FFN 见 §5.

**图 1 解析**

- **左一 (Sigmoid / Tanh)**: 两条 S 形. 左右尾巴水平, 对应导数贴零. 原版 Transformer FFN **不用**这两条当主激活.
- **左二 (ReLU)**: 负轴躺平, 原点尖折, 正轴斜率 $1$. 这是原版 Transformer 式 (2) 的激活.
- **右二 (GELU)**: 过原点附近被抹圆, 负区有浅凹再贴零, 正区渐近 $y=x$. SOFT GATE 对应 $x\Phi(x)$: 按大小加权, 不是按符号一刀切.
- **右一 (SiLU)**: 形状接近 GELU, 负区 bump 更可见. ONE PATH 提醒: 这仍是单路激活, 不是 SwiGLU 的双支路乘积.

## 5. 第四代: GLU 与 SwiGLU 的门控乘法

GLU (Gated Linear Unit) 不再把激活函数当成「对单条路径的非线性扭曲」, 而是把它变成**两条路径之间的逐元素乘法门**:

$$
\text{GLU}(x)=(xW_g)\odot\sigma(xW_u).
$$

Dauphin 等人在卷积网络里提出这种结构后, Shazeer 在 GLU Variants Improve Transformer 中把它引入 Transformer FFN, 并衍生出 ReGLU,GEGLU,SwiGLU 等变体. SwiGLU 用 SiLU 代替 Sigmoid 做门控:

$$
\text{SwiGLU}(x)=\bigl[(xW_g)\odot\text{SiLU}(xW_g)\bigr]\odot(xW_u)\,W_d.
$$

注意: SwiGLU 不只是「把 FFN 的激活从 GELU 换成 SiLU」, 而是把 FFN 从单路径改成门控双路径. 在单路 FFN 里, 同一个隐藏向量先升维,过激活,再降维; 在 SwiGLU 里, 输入 $x$ 分别走门支路 $xW_g$ 和值支路 $xW_u$. 门支路经 SiLU 后与值支路逐元素相乘, 最后由 $W_d$ 降维.

这里需要澄清一个工程术语. 两条从 $d$ 维升到隐藏维 $d_{ff}'$ 的线性投影都叫 **up 投影**: 门支路对应的矩阵叫 gate_up_proj, 值支路对应的矩阵也常叫 up_proj. 工程代码里常把 $W_g$ 与 $W_u$ 拼成一次 `gate_up_proj`, 输出沿隐藏维拆成两半; 它们的物理作用不同, 但几何方向相同, 都是从低维模型空间升到高维 FFN 空间. 最后把乘积压回 $d$ 维的 $W_d$ 叫 **down 投影**.

门控结构带来的变化可以从三个角度理解:

- **表达能力增强**: 门支路可以条件地放行或抑制值支路的不同坐标. 同一个输入坐标, 在不同样本或不同层里, 可以被门选择性地放大或关闭, 这比单路激活的逐元素固定曲线更灵活.
- **参数量变化**: 门控 FFN 有三套矩阵 ($W_g$, $W_u$, $W_d$), 而单路 FFN 只有两套 ($W_1$, $W_2$). 若保持隐藏维不变, 参数量会变为 1.5 倍. 工程上通常把隐藏维从 $4d$ 压缩到 $8d/3$, 使三矩阵的总参数量与两矩阵 $4d$ 方案对齐. 推导很简单: $3d\cdot d_{ff}'=2d\cdot 4d$ 给出 $d_{ff}'=8d/3$.
- **数值风险**: 门支路与值支路都无界, 乘积可能产生大激活. 当某个坐标上门值和值都接近 100 时, 乘积就近似 $10^4$, 给混合精度训练和量化带来异常值风险.

SwiGLU 已成为 Llama,Qwen,DeepSeek 等主流模型的默认 FFN 形态. 但它也催生了新一轮激活函数改造, 专门处理它的数值稳定性问题. 三矩阵结构,保参推导与 Shazeer 的实验对比见 [02 GLU 家族](./02-GLU家族-从GLU到SwiGLU/02-GLU家族-从GLU到SwiGLU.md).

## 6. 第五代: 控制 SwiGLU 的大激活

SwiGLU 的乘积无界, 在超大模型和混合精度训练里会放大激活异常值. 理解这个问题的关键是: SwiGLU 的输出不是 $g\cdot u$ 那么简单, 而是 $(g\cdot\sigma(g))\cdot u$. 当 $g$ 很大时, $\sigma(g)\approx 1$, 门支路近似 $g$ 本身; 若此时 $u$ 也很大, 乘积就近似 $g\cdot u$, 动态范围被平方放大. 在 BF16 甚至 FP8 训练里, 这种大激活更容易触发溢出, 也让量化后的分布更难对齐.

近两年出现几条不同路线来解决这个问题:

| 路线 | 代表 | 核心思想 | 代价 |
|---|---|---|---|
| 光滑上界 | [SiTU-GLU](./01-SiTU-GLU/01-SiTU-GLU.md) | 用 $\beta\tanh(x/\beta)$ 分别限制门支路与 up (值) 支路 | 饱和区梯度变小, 但无硬折点 |
| 降增长阶 | [PowLU](./03-PowLU-Ling对SwiGLU的稳定化改写/03-PowLU-Ling对SwiGLU的稳定化改写.md) | 正半轴从二次增长改为渐近线性 | 仍然无界, 但增长速度受控 |
| 硬截断 | DeepSeek-V4 / gpt-oss | 对两支路做 clip | 边界不可导, 梯度被掐死 |

三条路的目标不同, 不要混成一回事. SiTU-GLU 给每个支路设了光滑上界, 乘积自然被控在一个有限范围内; PowLU 不强制有界, 只是把正半轴从近似二次增长改成渐近线性, 让大值出现得更慢; 硬截断直接 clip 到一个固定区间, 效果最硬但边界梯度为零.

选择哪条路线取决于训练精度,硬件支持和模型规模. K3 选择 SiTU-GLU, 是因为它在低精度训练里能把异常值压到可控范围, 同时避免了硬截断在边界处掐死梯度的问题. PowLU 更适合希望保持函数无界,只降低增长速度的场景; 硬截断实现最简单, 但对优化不友好.

## 7. 单路与门控的定量对比

Shazeer 在 T5 同款编码器–解码器上做了参数量对齐比较. 度量是 C4 span-filling 的留出集 log-perplexity (越低越好). Table 1 中与本节有关的几行:

| 结构 | 524,288 step 留出集 log-ppl |
|------|-------------------------------|
| $\mathrm{FFN}_{\mathrm{ReLU}}$ (baseline) | 1.677 |
| $\mathrm{FFN}_{\mathrm{GELU}}$ | 1.679 |
| $\mathrm{FFN}_{\mathrm{Swish}}$ | 1.683 |
| $\mathrm{FFN}_{\mathrm{GLU}}$ | 1.663 |
| $\mathrm{FFN}_{\mathrm{GEGLU}}$ | **1.633** |
| $\mathrm{FFN}_{\mathrm{SwiGLU}}$ | **1.636** |

单路换激活函数的差异很小: ReLU, GELU, Swish 的差值只有 0.002–0.006. 门控结构才是跳变: GEGLU 与 SwiGLU 把基线从 1.677 压到 1.633 附近. 原因不是「SiLU 比 ReLU 更光滑」, 而是多了一条线性再逐元素相乘. 完整推导与变体列表见 [02 GLU 家族](./02-GLU家族-从GLU到SwiGLU/02-GLU家族-从GLU到SwiGLU.md).

极简对应 (只换 $\phi$, 仍是两矩阵):

```python
import math
import torch
import torch.nn.functional as F

def gelu_erf(x: torch.Tensor) -> torch.Tensor:
    return x * 0.5 * (1.0 + torch.erf(x / math.sqrt(2.0)))

def gelu_tanh(x: torch.Tensor) -> torch.Tensor:
    # tanh 近似, GELU 原文式
    inner = math.sqrt(2.0 / math.pi) * (x + 0.044715 * x * x * x)
    return 0.5 * x * (1.0 + torch.tanh(inner))

# FFN_ReLU / FFN_GELU / FFN_Swish: down(phi(up(x)))
# F.silu(x) == x * sigmoid(x)  (beta = 1 的 Swish / SiLU)
```

`F.silu(up(x))` 再 `down`, 名字可以叫 SiLU-FFN / Swish-FFN, 不要叫 SwiGLU.

## 8. 失效模式

| 现象 | 原因 | 说明 |
|------|------|------|
| Sigmoid / Tanh 深层训不动 | 两端导数贴零 | 原版 Transformer FFN **不是**用它们当主激活 |
| dead ReLU | $x\le 0$ 时前向与梯度皆 $0$ | 宽 FFN 里通道静音; 换 GELU / SiLU 是为了负区还留一点梯度 |
| 原点折点「不光滑」 | ReLU 在 $0$ 不可导 | 对 SGD 通常次要; 真正的结构限制是硬门 |
| 以为换 GELU / Swish 必降 ppl | Table 1 单路几乎打平 | 524288 步: ReLU **1.677**, GELU **1.679**, Swish **1.683** |
| 把 `F.silu` 的两矩阵 FFN 叫成 SwiGLU | 单路 $\phi$ != 双支路乘积 | 门是 SiLU; SwiGLU 还要另一条线性. 见 [02 GLU 家族](./02-GLU家族-从GLU到SwiGLU/02-GLU家族-从GLU到SwiGLU.md) |
| 混用 $\mathrm{erf}$ 与 tanh 近似当「同一个算子」 | 精确式与近似式非逐点相等 | 对权重, 对数值, 不要无声明切换 |

## 9. 怎么选激活函数

不存在 universally 最好的激活函数. 选择时要考虑:

1. **模型规模**: 小模型对梯度效率更敏感, 大模型对数值稳定性更敏感.
2. **训练精度**: FP32,BF16,FP8,MXFP8 对激活函数的数值范围要求不同.
3. **FFN 结构**: 单路 FFN 用 GELU/SiLU; 门控 FFN 用 SwiGLU 及其改型.
4. **硬件友好度**: 某些激活函数有专门融合 kernel, 实际速度差异可能很大.
5. **已有生态**: 复现某个模型家族时, 最好沿用其原配激活, 否则数值细节会对不上.

一个实用的判断框架是: 如果你做的是标准 dense Transformer, GELU 或 SiLU 是稳妥起点; 如果你要追 SOTA 大模型, SwiGLU 及其稳定化变体 (SiTU,PowLU,硬截断) 几乎已经是默认选项.

## 11. 本节小结

激活函数看起来只是网络里的一层非线性包装, 但它同时控制:

- 梯度能传多远 (避免梯度消失或爆炸);
- 神经元会不会大面积死亡 (训练可持续性);
- 输出动态范围 (量化友好度);
- 模型表达能力 (门控,条件耦合,稀疏性).

从 Sigmoid / Tanh 的饱和困境, 到 ReLU 的硬阈值革命, 再到 GELU / SiLU 的软门, 最后到 SwiGLU 的门控乘法和 SiTU / PowLU 的稳定化改造, 激活函数的每一次主流更替, 都对应着模型规模,训练精度和硬件约束的演进. 理解这些取舍, 比记住某一条曲线更重要.
