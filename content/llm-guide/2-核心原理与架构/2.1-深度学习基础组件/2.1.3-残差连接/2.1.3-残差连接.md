# 2.1.3 残差连接

残差连接(Residual Connection)是一个加法: 输出等于子层变换 $F(x)$ 加上输入 $x$.在深层网络里, 它同时保护两条路径: 一条让梯度能够直接回传, 一条让早期信息能够到达深层.没有它, 网络变深后训练会迅速退化; 有了它, 才允许模型持续加深而不失控.

对大语言模型来说, 这一结构比在 ResNet 中更重要.Transformer 每一层都包含 Attention,FFN,归一化和残差路径, 层数常达几十甚至上百.残差连接不是可选组件, 而是整个网络信息流的默认骨架.

标准残差是单条流 $H(x)=F(x)+x$.2024 年起, Hyper-Connections(HC)把残差扩成 $N$ 条可学习混合的流; mHC 用双随机约束把深度连乘稳住, 主设定 $N=4$; xHC 在 mHC 基础上把记忆宽度扩到 $N=16$, 每子层只更新 $k=4$; Gated Residual 同样加宽到 $n_r=4$, 但丢掉 $H_{\mathrm{res}}$, 读用逐元素门. 这些变体的公式、消融与工程细节在三篇后续中展开: [01-Hyper-Connections 与 mHC](./01-Hyper-Connections与mHC/01-Hyper-Connections与mHC.md)、[02-xHC: Expanded Hyper-Connections](./02-xHC-Expanded-Hyper-Connections/02-xHC-Expanded-Hyper-Connections.md)、[03-Gated Residual](./03-Gated-Residual/03-Gated-Residual.md). 注意不要把它们和 HCA 混名, 也不要把 GR 写成 [Gated Attention $G_1$](../../2.2-基础注意力机制/2.2.2-多头注意力变体/06-Gated-Attention-SDPA输出门控/06-Gated-Attention-SDPA输出门控.md); AttnRes 是深度维注意力聚合, 见 [2.2.2 AttnRes](../../2.2-基础注意力机制/2.2.2-多头注意力变体/08-AttnRes-深度维注意力聚合/08-AttnRes-深度维注意力聚合.md).

本文围绕四个问题展开:

1. 残差连接到底在解决什么问题.
2. 为什么学习修正比学习完整映射更容易.
3. 为什么梯度能在深层网络里稳定回传.
4. 为什么残差连接在 Transformer 里会与 Pre-Norm,FFN,Attention 深度绑定.

## 1. 残差连接到底在解决什么问题

在残差连接出现之前, 深度学习里有一个反直觉现象: 网络更深, 理论上表达能力更强, 实际训练结果反而可能更差.这被称为退化问题(Degradation).这里的退化不是过拟合, 而是即使在训练集上, 更深的网络也不一定能优化得比浅网络更好.

退化来自两个相互叠加的原因.第一, 梯度路径变长.反向传播每多经过一层, 就要再多乘一次局部 Jacobian; 层数一多, 梯度更容易在连乘中衰减或爆炸.第二, 前向信息被层层改写.每一层都在输出新的表示, 如果没有保底通路, 早期层里已经学习到的信息可能在深层丢失.残差连接的价值, 就是同时给这两件事加一条直接通路.

## 2. 残差连接的数学形式: 为什么是 $H(x)=F(x)+x$

残差连接最经典的写法是:

$$
H(x)=F(x)+x \tag{1}
$$

这里 $x$ 是输入表示, $F(x)$ 是子网络学到的变换, $H(x)$ 是残差块最终输出.公式只是多了一项输入直连, 但它改变了网络的学习目标.

如果没有残差连接, 子网络必须直接学会完整映射 $H(x)$.有了残差连接后, 子网络只需要学习:

$$
F(x)=H(x)-x \tag{2}
$$

也就是说, 它不再需要从零重建整个映射, 而是学习在现有表示基础上补充多少修正.

### 2.1 何凯明等人的核心论证

残差连接不是一拍脑袋的工程技巧. He 等人从 2015 年的 arXiv 预印本到 2016 年的 CVPR 与 ECCV, 连续三篇文章用大量实验说明: 让网络学习残差函数 $F(x)=H(x)-x$ 比直接学习 $H(x)$ 更容易优化, 而且恒等捷径能直接保留浅层信号. 其中 *Deep Residual Learning for Image Recognition* 给出了 ImageNet 上的深度实验, *Identity Mappings in Deep Residual Networks* 进一步论证了恒等映射的稳定性, 后续 ResNeXt 等变体则把这种「默认保留, 局部修正」的结构继续扩展到更宽的分支聚合上.

### 2.2 一个简单的数学推导

假设某层理想映射是 $H(x)$, 残差形式要求该层学习 $F(x)=H(x)-x$. 若 $H(x)$ 接近恒等映射, 则 $F(x)$ 接近零. 对 $F$ 的参数做一阶展开:

$$
F(x; \theta) \approx F(x; \theta_0) + J_F(x; \theta_0)\,(\theta - \theta_0).
$$

当初始化让 $F(x; \theta_0) \approx 0$ 时, 优化起点就在恒等映射附近; 训练只需要把 $\theta$ 推向一个小的修正, 而不是重新拟合整个 $H(x)$. 这正是 He 等人在实验中观察到的现象: 同样深度的残差网络比 Plain 网络收敛更快, 且深层不会比浅层更差.

> 图 1: 残差学习把「直接拟合完整映射」改成了「只学习增量修正」, 从而降低优化难度.

**图 1 解析**

- 左: 整块必须学会 $H(x)$, 没有退路.

- 若 $F \to 0$, 整块退化成恒等; 这就是「更深至少不要更差」的结构保证.

## 3. 为什么学习修正比学习完整映射更容易

如果某一层最理想的行为只是大体保持输入不变,只做一点局部修正, 那么普通网络必须让很多非线性层联合优化成近似恒等映射, 这并不容易.相反, 残差结构只要让 $F(x)$ 趋近于零, 就能自然退化成恒等映射.

这件事让「更深的网络至少不比浅层更差」成为可实现目标.即使新增层暂时没学到有用的东西, 它也可以先学会不破坏原有表示.深层网络不再被要求每层都立即有用, 而是允许部分层先作为保守修正器, 再逐步承担更多表达任务.从优化角度看, 一个零附近的小修正通常比一个完整替代更容易被梯度下降找到.

## 4. 为什么梯度能在深层网络里稳定回传

残差连接的梯度特性可以直接从求导里看出来.若:

$$
y=x+F(x) \tag{3}
$$

其中 $L$ 是损失函数, 则:

$$
\frac{\partial L}{\partial x}
=
\frac{\partial L}{\partial y}
\left(I+\frac{\partial F(x)}{\partial x}\right) \tag{4}
$$

这里最关键的不是 $\partial F(x)/\partial x$, 而是恒等项 $I$.它意味着: 即使子层内部的梯度变得很弱, 主干路径上仍然存在一条不依赖子层质量的直接回传通路.残差连接不保证梯度永远理想, 但它保证梯度不至于被局部坏层完全堵死.

## 5. 残差连接如何保护前向信息

残差连接在反向传播之外, 对前向传播同样重要.没有残差时, 模型默认每层都在重写表示; 有了残差后, 模型默认保留原输入, 再叠加修正.这使得前面的有用信息不容易被后面的子层彻底覆盖.

这对语言模型尤其关键.一个 token 的最终表示往往同时承载原始词义,句法角色,上下文依赖,任务指令偏置和领域风格信息.如果每层都完全覆盖上一层表示, 这些不同层次的信息会互相挤压.残差主干让它们更容易以叠加方式共存, 而不是以后层替换前层的方式竞争.

![残差主干保留原表示, 旁路叠加修正](./images/fig-residual-backbone.png)

> 图 2: 残差主干负责保留原表示, 子层分支负责叠加修正, 信息以「保留 + 增量」方式持续流动.

**图 2 解析**

- 蓝线 identity path 把 $x$ 原样送到加法点.

## 6. 在 Transformer 中, 残差连接的角色有什么变化

在 ResNet 中, 残差连接最直接的职责是解决卷积网络变深后的优化退化问题.到了 Transformer 里, 它的角色进一步升级.

Transformer 每层通常包含两个重型子层: Attention 和 FFN.这两个子层都可能对输入做很强变换.如果没有残差主干, 表示在层间会漂移得很厉害, 梯度路径也会更脆弱.因此在 Transformer 里, 残差连接已经不只是帮助训练, 而是构成整个主干信息流的默认骨架.Attention 和 FFN 更像在主干上不断写入修正项, 而不是彻底接管主干.

## 7. 残差连接为什么与 Pre-Norm 深度绑定

残差连接在 Transformer 里能发挥到极致, 与归一化层的位置密切相关.最关键的分歧是:

Post-Norm:

$$
x_{l+1}=\text{Norm}(x_l+F(x_l)) \tag{5}
$$

Pre-Norm:

$$
x_{l+1}=x_l+F(\text{Norm}(x_l)) \tag{6}
$$

两者差别不只是 Norm 放哪儿, 而是残差主干是否保持纯净恒等通路.在 Pre-Norm 里, 输入 $x_l$ 几乎原样沿主干往下走, Norm 和子层都被放到旁路修正里; 在 Post-Norm 里, 主干相加后的结果还要立刻再穿过一层归一化.深层大模型几乎一边倒选择 Pre-Norm, 因为它优先保护最重要的主干路径, 不让残差路径本身被每层额外数值变换反复扰动.

## 8. 残差连接的工程意义: 不止稳定训练

残差连接的工程价值远不止能训练更深.在现代大模型里, 它至少还影响四件事:

1. **量化稳定性**: 主干保留更稳定的参考表示, 子层只做增量修正, 这通常比完全覆盖式变换更容易控制量化误差.
2. **参数高效微调**: LoRA,Adapter 等方法本质上也是在主干上添加增量修正, 残差结构天然适合这类改动.
3. **多阶段训练迁移**: 预训练,SFT,对齐,蒸馏等阶段都更容易建立在稳定主干之上做增量行为修正, 而不是整网重写.
4. **模块可组合性**: 新模块,新桥接器,新工具路径更容易以旁路修正方式接入, 而不是要求完全替代原有主干.

这些现象背后是同一个原则: 稳定主干 + 增量修正, 比每一层都彻底重写, 更适合大规模系统演化.

## 9. 训练与部署中应该重点观察什么

在训练或部署深层模型时, 残差路径本身值得单独观察.最值得看的通常有:

1. 残差分支输出与主干幅值的比例.
2. 各层 residual add 前后的 RMS / 方差变化.
3. 深层主干幅值是否持续扩张.
4. 子层是否长期学不到有效修正.
5. 量化后 residual add 是否引入明显精度损失.

一个常见误区是以为 residual add 只是 $x + \mathrm{something}$ 的机械操作, 不值得看.但在深层网络里, 残差分支太强会破坏主干, 太弱又说明子层没起作用.这不是「有没有」的问题, 而是「修正强度是否合理」的问题.

## 10. 极简实现: 残差块与 Pre-Norm 残差

最简形式的残差块可以写成:

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, module: nn.Module):
        super().__init__()
        self.module = module

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return x + self.module(x)

class PreNormResidual(nn.Module):
    def __init__(self, norm: nn.Module, module: nn.Module):
        super().__init__()
        self.norm = norm
        self.module = module

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return x + self.module(self.norm(x))
```

第一段是最基础的残差结构: 主干原样通过, 旁路负责增量修正.第二段更接近现代大模型: 在修正分支前先做归一化, 但主干本身尽量保持纯净.

这也说明残差连接的实现并不复杂, 复杂的是它在整个系统中的作用.它之所以重要, 不是因为代码难, 而是因为它决定了深层模型的默认信息流形态.

## 11. 残差连接的演化方向

残差连接已经非常经典, 但仍在演化.未来值得持续关注的方向包括:

1. **残差幅值控制更精细**: residual scaling,DeepNorm,不同深度下的主干配方优化.
2. **与量化路径的协同**: 低比特推理中, residual add 的精度选择可能直接影响模型稳定性.
3. **与模块化插桩的关系**: Adapter,LoRA,工具增强,多模态桥接等路线, 本质上都在继续利用残差结构.
4. **更复杂的主干结构**: 多分支残差,门控残差,带权重的残差融合.公式与图见 [01 mHC](./01-Hyper-Connections与mHC/01-Hyper-Connections与mHC.md),[02 xHC](./02-xHC-Expanded-Hyper-Connections/02-xHC-Expanded-Hyper-Connections.md),[03 Gated Residual](./03-Gated-Residual/03-Gated-Residual.md).xHC 是残差主干的 scaling 轴, 不要和 HCA 混名.

无论形式怎么演化, 残差连接的核心原则大概率不会变: 默认保留已有表示, 只让子层为真正必要的变化负责.

## 12. 设计取舍: 为什么默认保留输入

残差连接背后的设计选择可以被概括为「默认保留, 显式改写」.网络不把每一层都设计成必须重新发明表示, 而是假设当前表示已经包含大量有用信息, 子层只负责输出一个差值.这个假设极大地降低了优化的初始难度, 也让深层堆叠变得可行.

但这个假设也有代价.它意味着模型需要额外的宽度或显式机制来引入真正的新信息, 例如 FFN 的升维再降维,多分支残差结构等.如果所有层都只做保守修正, 模型可能陷入表示塌缩, 深层与浅层过于相似.残差家族的各种变体, 从 HC 到 GR, 本质上都是在「保留多少」与「改写多少」之间做不同取舍.

## 13. 本节小结

残差连接之所以成为现代深度学习的基础设施, 不是因为它数学上复杂, 而是因为它现实地解决了深层系统的核心矛盾: 模型越深, 越需要一条不依赖局部子层质量的稳定主干.

它让层学会做修正而不是重做, 让梯度保持直接回传通道, 让表示以叠加方式累积.从 ResNet 到 Transformer, 再到今天的大语言模型, 残差连接已经不只是一个历史技巧, 而是深层模型设计里最稳定,最持久的原则之一.
