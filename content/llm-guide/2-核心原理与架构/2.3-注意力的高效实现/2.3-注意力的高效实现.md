# 2.3 · 硬件高效注意力

本节的方法都计算标准注意力 $\operatorname{softmax}(QK^\top/\sqrt{d})V$,结果在数值误差内不变,改的是分块,融合和缓存管理.前四篇按时间顺序排列,第五篇比较框架中可用的几条实现路径.
