# 01 · 高效注意力机制全景图

标准自注意力有两个随序列长度 $n$ 增长的量: prefill 时的分数矩阵是 $n\times n$, decode 时每生成一个 token 都要把 $O(n)$ 条历史 KV 从显存读一遍. 这几年的高效注意力方法各自只动其中一个量, 其中一部分连注意力的数学定义都不改. 本文把它们放进同一套记号, 每种方法回答四个问题: 计算和显存随 $n$ 怎么涨, 推理时缓存什么, 输出和 softmax 注意力是否精确相等, 用在训练期还是只在推理期. 推导和实验细节在 [2.3.1 硬件高效注意力](../2.3-注意力的高效实现.md), [2.3.2 稀疏与压缩注意力](../../2.4-稀疏注意力/2.4-稀疏注意力.md), [2.3.3 线性注意力机制](../../2.5-线性注意力与状态空间模型/2.5.1-线性注意力机制/2.5.1-线性注意力机制.md) 和 [2.2.2 多头注意力变体](../../2.2-注意力机制/2.2.2-多头注意力变体/2.2.2-多头注意力变体.md); 没有专篇的方法 (Linformer, Reformer, Routing Transformer, Sparse Sinkhorn, Star-Transformer, Star Attention, AFT, Synthesizer, LightConv, RFA, SageAttention) 在这里写到能复述的程度.

## 1. 记号与两个基线数

### 1.1 标准注意力的两笔开销

单头注意力:

$$
O=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V \tag{1}
$$

$Q,K,V\in\mathbb{R}^{n\times d}$ 由当前层输入 $X\in\mathbb{R}^{n\times d_{model}}$ 线性投影得到, $d$ 是头维. 分数矩阵 $S=QK^\top/\sqrt{d}$ 和概率矩阵 $P=\mathrm{softmax}(S)$ 都是 $n\times n$. 训练和 prefill 时整段一起算, 计算量 $O(n^2d)$; 朴素实现把 $S$ 和 $P$ 写进显存, 额外显存 $O(n^2)$.

decode 的形状不同. 第 $t$ 步只有一个新 query $q_t$, 它要和 $k_1,\ldots,k_t$ 逐个做点积, 再对 $v_1,\ldots,v_t$ 加权求和. 计算只有 $O(td)$, 但这 $t$ 条 K 和 V 每一步都要从显存读出来. 历史的 Q 用过就丢, 不进缓存. 每个 token 的缓存字节是:

$$
\text{KV 字节}=2\cdot L\cdot H_{kv}\cdot d\cdot b \tag{2}
$$

其中 $2$ 对应 K 和 V 两份, $L$ 是层数, $H_{kv}$ 是 KV 头数 (MHA 里等于 query 头数 $H$), $b$ 是每个元素的字节数.

### 1.2 两个手算

**分数矩阵.** $n=1024$ 时 $n^2=1{,}048{,}576$ 个元素, FP32 每个 4 字节, 一个头一条序列 4 MB. $n=131072$ (128K) 时 $n^2\approx1.72\times10^{10}$, 同样口径约 68.7 GB, 一个头就超出单卡显存. 这就是硬件高效类方法要解决的问题: 计算量 $O(n^2d)$ 还可以接受, 但中间矩阵不能整块落地.

**KV cache.** vLLM 论文用 OPT-13B 举例: $L=40$, $H\cdot d=5120$, FP16 时 $b=2$, 代入式 (2) 得 $2\times40\times5120\times2=819{,}200$ 字节, 每个 token 约 800 KB, 2048 个 token 的请求约 1.6 GB. decode 每一步都要把这 1.6 GB 读一遍, 而计算只是每条 KV 一次点积, 瓶颈在显存带宽. KV 表示压缩类和推理期驱逐类方法就是从这个数下手.

### 1.3 比较的四个维度

后文每种方法都按下面四项写, 第 5.2 节汇总成一张表.

| 维度 | 问的是什么 |
| --- | --- |
| 复杂度 | 训练/prefill 的计算与额外显存随 $n$ 怎么涨; decode 每一步算多少, 读多少 |
| 缓存 | 推理时每层留下什么: 全部 KV, 一个预算内的 KV, 还是固定大小的状态 |
| 精确/近似 | 输出和式 (1) 是否逐元素相等 (浮点误差以内) |
| 训练期/推理期 | 要不要用这个注意力从头训或续训; 能不能直接套在训好的稠密模型上 |

## 2. 硬件高效: 输出精确, 只改执行方式

### 2.1 Memory Efficient Attention

这一类方法输出等于式 (1), 训练好的模型可以直接换上. 它们降的是额外显存和 HBM 读写, 计算量仍是 $O(n^2d)$.

Rabe 和 Staats 的 *Self-attention Does Not Need $O(n^2)$ Memory* ([arXiv:2112.05682](https://arxiv.org/abs/2112.05682), 2021) 把 key 和 value 切成块, 每块算局部 softmax 的分子与分母, 用 running max 保持数值稳定, 最后合并, 全程不物化 $n\times n$ 矩阵. 理论上单个 query 的额外显存是 $O(1)$, 整段自注意力 $O(\log n)$; 在加速器上实用的实现按 $\sqrt{n}$ 分块, 额外显存 $O(\sqrt{n})$, 运行时间与标准实现相差几个百分点. 长度 16384 时, 自注意力的显存开销推理降 59 倍, 求导降 32 倍 (摘要). 公式与 JAX 实现见 [01 Memory Efficient Attention](../02-Memory-Efficient-Attention/02-Memory-Efficient-Attention.md).

### 2.2 FlashAttention 一族

Dao 等人的 FlashAttention ([arXiv:2205.14135](https://arxiv.org/abs/2205.14135), NeurIPS 2022) 和 MEA 用的是同一类分块加在线 softmax, 目标换成了 GPU 上 HBM 与 SRAM 之间的读写次数. 论文 Theorem 2: 标准注意力需要 $\Theta(nd+n^2)$ 次 HBM 访问, FlashAttention 需要 $\Theta(n^2d^2M^{-1})$ 次, $M$ 是 SRAM 容量. 反向传播时 $S$ 和 $P$ 不存, 由保存的行统计量重算, FLOPs 略增, 但 GPT-2 上注意力算子仍快 7.6 倍 (Figure 1). 额外显存随 $n$ 线性.

FlashAttention-2 ([arXiv:2307.08691](https://arxiv.org/abs/2307.08691)) 减少非矩阵乘运算, 单个头也沿序列切到多个 thread block 上并行. FlashAttention-3 ([arXiv:2407.08608](https://arxiv.org/abs/2407.08608)) 面向 Hopper: 摘要写 FlashAttention-2 在 H100 上只到 35% 利用率, FlashAttention-3 前向相对它快 1.5–2.0 倍, FP16 最高 740 TFLOPs/s (75% 利用率), FP8 接近 1.2 PFLOPs/s. 在线 softmax 推导与 IO 分析见 [02 FlashAttention](../03-FlashAttention-IO感知分块/03-FlashAttention-IO感知分块.md), Hopper 与 Blackwell 上的核见 [03](../04-FlashAttention-Hopper与Blackwell/04-FlashAttention-Hopper与Blackwell.md). decode 时 query 只有一行, 并行度要从 KV 方向切, 这一路 (split-KV) 在 [6.6.3 Flash-Decoding](../../../6-训练与推理优化/6.6-推理框架与高级优化/6.6.3-Flash-Decoding原理与实现/6.6.3-Flash-Decoding原理与实现.md).

### 2.3 PagedAttention, SageAttention 与这一类的边界

Kwon 等人 ([arXiv:2309.06180](https://arxiv.org/abs/2309.06180), SOSP 2023) 改的是 KV 在显存里怎么放. 此前的系统按最大长度给每个请求预留一段连续显存, 论文 Fig. 2 测得其中只有 20.4%–38.2% 存的是真实 token 状态. PagedAttention 把 KV 切成固定大小的块, 用 block table 把逻辑位置映射到不连续的物理块, 浪费只剩每个序列最后一块的空位, 前缀相同的请求还能共享块. 注意力数值不变. vLLM 在同等延迟下吞吐提高 2–4 倍. 细节见 [04 PagedAttention](../../2.7-长上下文与外推技术/2.7.3-长上下文推理优化/01-PagedAttention/01-PagedAttention.md). PagedAttention 管存放, FlashAttention 管计算, 两者作用在不同层面, 可以叠加.

SageAttention ([arXiv:2410.02367](https://arxiv.org/abs/2410.02367)) 是这一类里唯一的近似方法, 专门面向推理. 它把 $Q,K$ 量化到 INT8 做 $QK^\top$, $PV$ 用 FP16 矩阵乘配 FP16 累加器, softmax 本身保持全精度.

量化 $K$ 之前先做平滑: 沿 token 维减去均值 $\bar{k}=\frac{1}{n}\sum_j k_j$. 对第 $i$ 行, $q_i^\top(k_j-\bar{k})=q_i^\top k_j-q_i^\top\bar{k}$, 后一项对这一行所有 $j$ 是同一个常数, softmax 对整行加常数不变, 所以输出不变. 平滑去掉了 $K$ 里跨 token 共享的大偏移, 量化误差随之变小, 论文 Table 10 测得这一步的耗时开销小于 0.2%. 核的 OPS 比 FlashAttention-2 和 xformers 分别高约 2.1 倍和 2.7 倍. 本库没有 SageAttention 的专篇.

回到这一类整体看, MEA 和 FlashAttention 解决的是「放不下」, 计算量仍是 $n^2$; PagedAttention 解决的是 KV 显存的碎片, 每个 token 存多少字节不变. 当 $n$ 大到 $n^2d$ 次乘加本身就是瓶颈, 或者式 (2) 的字节数本身太大, 这一类方法就不够了, 需要后面几类改模型本身.

## 3. 稀疏与推理期选读: 保留 softmax, 只算一部分连边

### 3.1 滑动窗口

这一节的方法让每个 query 只和一部分 key 做点积, softmax 只在这部分上归一化. 输出和式 (1) 不再相等, 所以都要在训练时就用上 (3.6 节的 Star Attention 例外).

因果滑动窗口让位置 $i$ 只看最近 $w$ 个位置:

$$
P_{ij}=\frac{\exp(q_i^\top k_j/\sqrt{d})}{\sum_{j'=i-w}^{i}\exp(q_i^\top k_{j'}/\sqrt{d})},\qquad i-w\le j\le i \tag{3}
$$

窗口外 $P_{ij}=0$. 计算从 $O(n^2d)$ 降到 $O(nwd)$; decode 时比 $w$ 更早的 KV 再也不会被读到, 缓存可以固定为 $w$ 条.

Longformer ([arXiv:2004.05150](https://arxiv.org/abs/2004.05150)) 用的是双向窗, 每边 $\frac{1}{2}w$ 个邻居, 复杂度 $O(n\times w)$, $\ell$ 层叠起来顶层感受野 $\ell\times w$. 它另加按任务指定的全局 token (分类时的 CLS, 问答时的问题 token), 这些位置看全序列, 也被全序列看到. 论文消融写明局部注意力负责上下文表示, 全局注意力负责整段表示, 两者都需要.

Mistral 7B ([arXiv:2310.06825](https://arxiv.org/abs/2310.06825)) 用因果窗 $W=4096$, `context_len` 为 8192. 第 $k$ 层的位置 $i$ 只看上一层的 $[i-W,i]$, 信息经过多层可以传出 $W\times k$ 个位置, 论文按 32 层算出最后一层的理论跨度约 131K. 这个跨度是多跳传递的上界, 单层仍只有 $W$ 条直接边. 缓存用 rolling buffer: 固定 $W$ 个槽, 位置 $i$ 的 K 和 V 写到第 $i \bmod W$ 槽. 32K 长的序列上 cache 显存降 8 倍; 16K 长度上, 对 FlashAttention 和 xFormers 的改动带来 2 倍速度.

### 3.2 膨胀窗口与因子分解

窗口内跳着取, 连接数不变, 跨度变大. Longformer 的 dilated sliding window 留宽为 $\delta$ 的空隙:

$$
P_{ij}\neq0 \iff i-j=m\delta,\quad m\in\left\{-\tfrac{w}{2},\ldots,\tfrac{w}{2}\right\} \tag{4}
$$

每个 query 仍连 $w$ 个 key, 一层跨度变成约 $w\delta$, 各层 $\delta$ 和 $w$ 固定时顶层感受野为 $\ell\times\delta\times w$. 实际配置是分层分头的: 字符级语言模型的下层不用膨胀, 保留局部上下文; 上层只给少数头加一点膨胀. 论文写不同头用不同膨胀配置效果更好, 一部分头看局部, 一部分看远处.

更早的 Sparse Transformer (Child 等人, [arXiv:1904.10509](https://arxiv.org/abs/1904.10509)) 用 strided 和 fixed 两种因子分解图案, 把注意力复杂度降到 $O(n\sqrt{n})$: 一部分头看最近 $\sqrt{n}$ 个位置, 另一部分头隔 $\sqrt{n}$ 取一个, 两跳可达任意位置.

### 3.3 BigBird: 随机, 窗口, 全局三种边

Zaheer 等人 *Big Bird* ([arXiv:2007.14062](https://arxiv.org/abs/2007.14062), NeurIPS 2020) 让每个 query 看三类 key: $r$ 个随机位置, 宽 $w$ 的滑动窗口, $g$ 个全局 token. $r,w,g$ 是常数时, 内积次数是 $O(n)$. 实现上先把序列切成块, 在块上做随机, 窗口和全局连接, 这样访存是连续的.

这篇的理论部分把三种边的作用分开. 第一, 通用逼近定理要求注意力图包含一个星图 $S$, 也就是要有全局节点; 第二, 在标准的精度假设下 BigBird 是图灵完备的; 第三, 稀疏有代价 (§3.4): 给定序列找每个向量的最远向量, 满注意力用常数层就能做, 而在正交向量猜想下, 边数为 $\tilde{O}(n)$ 的稀疏注意力需要多得多的层. 稀疏省下的是内积次数, 换来的是表达同一个函数可能要更深. 摘要说在相近硬件上能处理此前 8 倍长的序列; NLP 主实验的序列长度是 4096.

### 3.4 Star-Transformer: 一个中继节点加一个环

Guo 等人的 Star-Transformer ([arXiv:1902.09113](https://arxiv.org/abs/1902.09113), NAACL 2019) 比 BigBird 早一年, 整个编码器的拓扑都是星形: 每个 token 一个卫星节点, 再加一个共享的中继节点 $s$. 卫星节点只看左右邻居, 自己的输入嵌入和中继节点, 相邻卫星连成环; 中继节点看全部卫星. 连接数从 $n^2$ 降到 $2n$, 一层代价 $O(6nd)$ (环 $O(5nd)$ 加径向 $O(nd)$), 任意两个不相邻的卫星经中继两跳可达.

实验是中小规模数据上的编码器. MTL-16 的 16 个文本分类域上平均准确率 86.98, 同设定 Transformer 是 82.78; 测集推理平均快约 4.5 倍. 它和 BigBird 的区别在全局通道的数量: BigBird 有 $g$ 个全局 token, Star-Transformer 只有一个中继, 每层所有非局部信息都要经过它.

### 3.5 按内容分组: Reformer, Routing, Sinkhorn

前面几种图案都和内容无关. 下面三种先按 $Q,K$ 的内容把位置分组, 只在组内做 softmax.

**Reformer** (Kitaev 等人, [arXiv:2001.04451](https://arxiv.org/abs/2001.04451), ICLR 2020) 用局部敏感哈希. 固定一个随机矩阵 $R\in\mathbb{R}^{d\times b/2}$, 哈希函数是:

$$
h(x)=\arg\max\big([xR;\,-xR]\big) \tag{5}
$$

$[u;v]$ 表示拼接. 方向相近的向量大概率落进同一个桶, $R$ 不训练. 为了让 query 和 key 用同一个哈希, Reformer 让 $Q$ 和 $K$ 共用一个投影 (shared-QK), 论文测得这样不伤性能. 按桶号排序后切成等长的块, 每块看自己和前一块; 多轮哈希取并集以降低漏掉近邻的概率. 注意力复杂度从 $O(n^2)$ 降到 $O(n\log n)$. 另外两件省显存: 可逆残差, 反传时由输出重算输入, 只存一份激活; FFN 按位置分块算, 去掉 $d_{ff}$ 那一截激活.

**Routing Transformer** (Roy 等人, [arXiv:2003.05997](https://arxiv.org/abs/2003.05997), TACL 2021) 的分组是学出来的: 在线球面 $k$-means, 质心用指数滑动平均更新 (衰减通常 0.999). query 只看与自己同簇且在自己之前的 key. 取簇数 $\sqrt{n}$ 时复杂度 $O(n^{1.5}d)$. 结果: Wikitext-103 测集 PPL 15.8 (Transformer-XL 18.3), PG-19 33.2 (Compressive Transformer 33.6), ImageNet-64 3.43 bits/dim (Sparse Transformer 3.44, 论文引 Reformer 约 3.65).

**Sparse Sinkhorn Attention** (Tay 等人, [arXiv:2002.11296](https://arxiv.org/abs/2002.11296), ICML 2020) 在块的粒度上排序. 序列切成 $N_B$ 块, 每块 $B=\ell/N_B$ 个 token; 一个排序网络给出块之间的打分矩阵, 经 Sinkhorn 迭代归一成双随机矩阵, 用它把块重新排列, 然后在重排后的邻域上做标准的局部注意力. 显存从 $O(\ell^2)$ 降到 $O(B^2+N_B^2)$, $\ell=1024, N_B=64$ 时省约 240 倍. 因果版本 (Causal Sinkhorn Balancing) 只允许用到当前块之前的信息; SortCut 再把排序后的序列截断到固定预算, 只适合编码器. 排序之后做的仍是 $QK^\top$ 点积.

三者的差别在分组方式: Reformer 是不训练的随机投影, Routing 是学出来的质心, Sinkhorn 学的是块的排列.

### 3.6 推理期的分布式块稀疏: Star Attention

Ring Attention (Liu 等人, [arXiv:2310.01889](https://arxiv.org/abs/2310.01889), ICLR 2024) 把长序列切到多台设备上, KV 块沿环传递, 通信与块内计算重叠, 算的是精确的全局注意力. 原理在 [6.1.1 分布式训练](../../../6-训练与推理优化/6.1-训练基础设施/6.1.1-分布式训练/6.1.1-分布式训练.md).

NVIDIA 的 Star Attention ([arXiv:2411.17116](https://arxiv.org/abs/2411.17116)) 和 3.4 节的 Star-Transformer 无关, 它不改权重, 只改长上下文推理怎么切块. 前提是长任务多为「很长的 context, 短的 query」. 分两个阶段:

1. **局部编码.** context 切成 $b$ 个 token 一块, 分到各台主机. 除第一块外, 每块前面拼上第一块 $c_1$ (锚块), 主机只在这 $2b$ 个 token 上做自注意力, 主机之间不通信. 锚块的 KV 算完丢掉, 只留本块的. 没有锚块时, 每块开头会各自长出一个 attention sink, 和全局注意力的分布对不上; 拼上锚块后 sink 落在锚块上.
2. **查询与生成.** query 广播到所有主机, 每台用本地 KV 算出局部注意力输出和 softmax 分母, 指定的 query 主机收集后按分母加权合并成全局 softmax. 每个 token 每台主机只传一个向量和一个标量. 生成阶段只有 query 主机更新 KV.

第一阶段对 context 的复杂度是线性的, 这一步是近似; 第二阶段对已缓存的 KV 是精确的. 摘要写推理最多快 11 倍, 精度保持在 97–100%. Table 1 里 Llama-3.1-8B-Instruct 在 128K 的 RULER 上比 Ring Attention 低 1.90%, 快 2.7 倍. 锚块消融 (RULER-NIAH): 全局注意力 64K 为 99.50, 去掉锚块掉到 60.11; 128K 从 98.49 掉到 73.75.

### 3.7 推理期 KV 驱逐与选读

第 3 节的稀疏图案要在训练时就用上. 另一组方法不改训练, 在训好的稠密模型上决定 decode 时留下或读取哪些 KV. 它们的 decode 每步读取量从 $t$ 条降到预算 $B_{kv}$ 条, 输出都是近似. 按打分依据分:

| 方法 | 打分依据 | 是否删掉 KV |
| --- | --- | --- |
| StreamingLLM | 固定保留开头几个 sink token 加最近窗口 | 删 |
| H2O | 累积注意力分数, 与最近 token 各占一半预算 | 删 |
| SnapKV | prompt 末尾观测窗投票, prefill 后一次性选 | 删 |
| PyramidKV | 层间预算递减, 层内沿用 SnapKV | 删 |
| FastGen | prefill 时按头画像选保留策略 | 删 |
| ScissorHands | 窗口内低分次数, 成批丢弃 | 删 |
| TOVA | 当前 query 下注意力最低的那条 | 删 |
| Quest | 页内 key 的逐维最小/最大值估上界, 只读 top-k 页 | 不删, 只少读 |

各篇的机制与数字在 [2.3.2 稀疏与压缩注意力](../../2.4-稀疏注意力/2.4-稀疏注意力.md) 的「推理期 KV 压缩与驱逐」一组. 同一节的「训练期稀疏注意力」一组 (MoBA, NSA, DeepSeek-V4 的 CSA/HCA, Qwen 的 QSA) 是第 3 节思路在当代大模型上的版本: 稀疏单元从 token 变成连续块, 由一个打分模块 (块均值, 压缩 token 或 indexer) 选 top-k 块, 并在预训练或续训中学出来.

删 KV 和只少读的差别在可恢复性: 被删掉的 KV 之后的 query 再也用不到, 后面的问题若恰好依赖它就答不出; Quest 一类的全量 KV 仍在显存, 只省带宽不省容量.

## 4. 线性, 核化与去掉点积

### 4.1 Linear Transformer: 换核与 RNN 形式

这一节的方法改的是式 (1) 本身. 有的把 softmax 换成可分解的核, 让矩阵乘可以先算 $K^\top V$; 有的直接去掉 $QK^\top$. 共同点是推理时不再需要逐 token 的 KV, 代价是输出与 softmax 注意力不等, 必须用新的注意力训练.

Katharopoulos 等人 *Transformers are RNNs* ([arXiv:2006.16236](https://arxiv.org/abs/2006.16236), ICML 2020) 把相似度 $\exp(q^\top k)$ 换成 $\phi(q)^\top\phi(k)$, $\phi$ 是一个非负特征映射. 第 $i$ 个输出变成:

$$
o_i=\frac{\phi(q_i)^\top\sum_{j}\phi(k_j)v_j^\top}{\phi(q_i)^\top\sum_{j}\phi(k_j)} \tag{6}
$$

分子里的 $\sum_j\phi(k_j)v_j^\top$ 和 $i$ 无关, 先算一次, 每个 query 复用, 复杂度从 $O(n^2d)$ 变成 $O(nd_\phi d)$, $d_\phi$ 是特征维. 因果时求和上限改成 $i$, 就得到两个递推状态:

$$
S_i=S_{i-1}+\phi(k_i)v_i^\top,\qquad z_i=z_{i-1}+\phi(k_i),\qquad o_i=\frac{S_i^\top\phi(q_i)}{z_i^\top\phi(q_i)} \tag{7}
$$

$S_i\in\mathbb{R}^{d_\phi\times d}$ 存加权的 value, $z_i\in\mathbb{R}^{d_\phi}$ 存归一化分母, 少了 $z$ 输出就不再是加权平均. 每一步更新 $O(d_\phi d)$, 与已生成长度无关. 训练时整段已知, 可以按式 (6) 并行; 推理时按式 (7) 走 RNN. 实验用 $\phi(x)=\mathrm{elu}(x)+1$, 论文选 elu 而不选 relu, 是为了 $x<0$ 时梯度不为零.

状态大小可以手算. 取 $d_\phi=d=128$, 每头状态 $S$ 有 $128\times128=16384$ 个元素, 加上 $z$ 的 128 个. 按式 (2) 的口径, 同一个头缓存 $t$ 个 token 的 K 和 V 要 $2\times128\times t$ 个元素, $t=64$ 时两者持平, 之后 KV 继续线性增长而 $S$ 不变. 反过来, 再长的历史也只能压进这 16384 个数里, 这是线性注意力在检索类任务上吃亏的来源.

数字要按任务读. 摘要「最高约 4000 倍」来自 CIFAR-10 逐像素生成 (序列长 3072): 17.85 对 0.004 images/s, 即 4462 倍, bits/dim 3.40 对 3.47. MNIST 上快 317 倍. 语音识别 (WSJ, CTC) 上线性注意力 PER 8.08, softmax 5.12, 每 epoch 824 s 对 2711 s, 快了, 但错误率更高.

### 4.2 Performer 与 RFA: 用随机特征逼近 softmax 核

Linear Transformer 换掉了 softmax 核. Performer (Choromanski 等人, [arXiv:2009.14794](https://arxiv.org/abs/2009.14794), ICLR 2021) 保留 softmax 核, 用随机特征做无偏估计:

$$
\exp(q^\top k)=\mathbb{E}_{\omega\sim\mathcal{N}(0,I)}\Big[\exp\big(\omega^\top q-\tfrac{\|q\|^2}{2}\big)\exp\big(\omega^\top k-\tfrac{\|k\|^2}{2}\big)\Big] \tag{8}
$$

取 $m$ 个 $\omega$ 组成特征 $\phi(x)\in\mathbb{R}^m$, 代入式 (6) 即可. 特征全为正, 分数接近零时估计的方差不会像 $\sin/\cos$ 特征那样变大; 再对 $\omega$ 做正交化进一步降方差, 这套机制叫 FAVOR+ (Fast Attention Via positive Orthogonal Random features). 论文给出时间 $O(nmd)$, 空间 $O(nm+nd+md)$. 无偏指的是核估计, 有限的 $m$ 下逼近质量仍取决于 $m$, softmax 很尖的行最难逼近.

同样用随机特征的还有 RFA. Peng 等人 *Random Feature Attention* ([arXiv:2103.02143](https://arxiv.org/abs/2103.02143), ICLR 2021) 和 Performer 同期. 它用 Rahimi 和 Recht 的随机傅里叶特征 ($\sin$ 与 $\cos$ 拼接) 近似高斯核, 先把 $q,k$ 做 $\ell_2$ 归一化, 这样 $\exp(q^\top k)$ 与高斯核只差常数. 因果时的状态与式 (7) 同构. RFA 另加一个可选的门: 每步把旧状态乘一个学出来的 sigmoid 门 $g_t$, 新信息乘 $1-g_t$, 让模型偏向最近的历史. 参数增加不到 0.1%. WikiText-103 上门控带来超过 1.8 的 PPL 改善; 机器翻译里解码快 1.9 倍.

### 4.3 Linformer: 沿序列维投影, 保留 softmax

Wang 等人 *Linformer* ([arXiv:2006.04768](https://arxiv.org/abs/2006.04768), 2020) 观察到 softmax 后的 $P$ 近似低秩, 于是把 K 和 V 沿序列维投影到 $k$ 行:

$$
O=\mathrm{softmax}\!\left(\frac{Q(EK)^\top}{\sqrt{d}}\right)(FV),\qquad E,F\in\mathbb{R}^{k\times n} \tag{9}
$$

注意力图从 $n\times n$ 变成 $n\times k$, 每层复杂度 $O(nkd)$, softmax 还在. 投影矩阵可以每头一对, 也可以在层内各头共享, K 与 V 共享, 甚至全网一层共用一个. 下游平均分 ($n=512, k=256$, K/V 共享且逐层共享) 为 92.30, 同语料 RoBERTa-base 为 92.25. 推理效率 (Table 3, V100): $n=512, k=128$ 时快 1.5 倍, 最大 batch 大 1.7 倍; $n=65536, k=128$ 时快 20 倍, 显存省 60 倍.

局限来自 $E,F$ 的形状里含 $n$: 训练长度定了投影就定了. 论文做的是 MLM 编码器; 沿整段序列的投影会把未来位置混进 $EK$, 不能直接用于因果解码, 也就没有 decode 的 KV 可谈.

### 4.4 AFT 与 RWKV-4: 去掉 $QK^\top$, 改成逐通道衰减

Zhai 等人 *An Attention Free Transformer* ([arXiv:2105.14103](https://arxiv.org/abs/2105.14103), 2021) 不做 query 与 key 的点积. AFT-full 的形式是:

$$
y_t=\sigma(q_t)\odot\frac{\sum_{t'}\exp(k_{t'}+w_{t,t'})\odot v_{t'}}{\sum_{t'}\exp(k_{t'}+w_{t,t'})} \tag{10}
$$

$\odot$ 是逐元素乘, $\sigma$ 是 sigmoid, $w\in\mathbb{R}^{T\times T}$ 是学出来的成对位置偏置 ($T$ 为最大长度). key 和 value 逐元素结合, 等于每个特征维各有一套隐式注意力, 但不物化任何 $n\times n$ 的图. 论文 Table 1 的复杂度:

| 变体 | 时间 | 空间 |
| --- | --- | --- |
| Transformer | $O(T^2d)$ | $O(T^2+Td)$ |
| AFT-full | $O(T^2d)$ | $O(Td)$ |
| AFT-local / AFT-conv | $O(Tsd)$, $s<T$ | $O(Td)$ |
| AFT-simple | $O(Td)$ | $O(Td)$ |

AFT-full 时间仍是二次, 省的是空间. AFT-local 只在宽 $s$ 的窗内学偏置, 窗外 $w=0$, 窗外的 key 仍参与加权, 全局连通性保留. AFT-simple 去掉 $w$, 退化成全局池化. 因为 $w_{t,t'}$ 是成对的, AFT-full 不能写成固定状态的递推; 4.4 节的 RWKV 把它换成随距离线性衰减, 才得到 RNN 形式.

AFT 之后的 RWKV-4 沿着这条线走. Peng 等人 *RWKV* ([arXiv:2305.13048](https://arxiv.org/abs/2305.13048), 2023) 从 AFT 出发, 把成对偏置 $w_{t,i}$ 换成 $-(t-i)w$, $w$ 是非负的逐通道衰减向量, 这样分子分母都能写成逐通道的指数衰减递推. 论文 Table 1 写推理时间 $O(Td)$, 空间 $O(d)$, 对照 Linear Transformer 的 $O(Td^2)$ 和 $O(Td+d^2)$: RWKV 的状态是向量, Linear Transformer 的状态是矩阵. 训练可以像 Transformer 一样并行. 所有模型在 Pile (330B token) 上训一个 epoch, 最大 14B. 公式展开见 [2.4.4 线性 RNN 与 Griffin](../../2.5-线性注意力与状态空间模型/2.5.4-线性RNN与Griffin/2.5.4-线性RNN与Griffin.md).

### 4.5 Synthesizer 与 LightConv: 不用点积的对齐

Tay 等人 *Synthesizer* ([arXiv:2005.00743](https://arxiv.org/abs/2005.00743), ICML 2021) 保留 $\mathrm{softmax}(B)\,G(X)$ 的形式, $G(X)$ 是 value 的线性投影, 换掉的是对齐矩阵 $B$ 的来源. Dense 版本让每个位置只用自己的表示, 经两层前馈网络输出长度为 $N$ 的一行; Random 版本让 $B$ 直接是一个可训练 (或固定) 的 $N\times N$ 参数矩阵, 与输入无关. 两种都没有 token 之间的成对交互. softmax 仍作用在 $N\times N$ 上, 时间复杂度仍是二次, 省的只是 $QK^\top$ 的投影与点积.

论文的主要发现是 Random 对齐矩阵的效果出人意料地有竞争力, 但成对点积在句对任务上仍有用, 混合使用常更好. 摘要: 与 Dynamic Convolution 相比, Random Synthesizer 快 60%, PPL 相对改善 3.5%.

和 Synthesizer 一样不算 $QK^\top$ 的还有卷积. Wu 等人 *Pay Less Attention with Lightweight and Dynamic Convolutions* ([arXiv:1901.10430](https://arxiv.org/abs/1901.10430), ICLR 2019) 把编码器和解码器里的自注意力换成卷积, 解码器的 source-target 注意力保留. LightConv 是 depthwise 卷积, 核在宽度 $k$ 上做 softmax 归一化, 每 $d/H$ 个通道共享一组核: $d=1024, k=7$ 时普通卷积要 7,340,032 个权重, depthwise 要 7,168 个, 按 $H=16$ 共享后只剩 112 个. DynamicConv 让核由当前位置的表示经线性层生成, 只看当前步, 不看整段上下文. 两者的计算都随 $n$ 线性. WMT'14 英德上 DynamicConv 达到 29.7 BLEU, 比高度优化的自注意力基线快 20%.

### 4.6 衰减, 门控与 delta 规则

式 (7) 的状态只加不减, 历史越长越拥挤. 之后的工作都在改这一步更新. 统一写成列向量形式, 输出 $o_t=S_tq_t$, $S_t\in\mathbb{R}^{d_v\times d_k}$ (省略 $\phi$ 和归一化):

$$
\begin{aligned}
\text{Linear Transformer:}&\quad S_t=S_{t-1}+v_tk_t^\top\\
\text{RetNet:}&\quad S_t=\gamma S_{t-1}+v_tk_t^\top\\
\text{GLA:}&\quad S_t=S_{t-1}\,\mathrm{Diag}(\alpha_t)+v_tk_t^\top\\
\text{DeltaNet:}&\quad S_t=S_{t-1}\big(I-\beta_tk_tk_t^\top\big)+\beta_tv_tk_t^\top
\end{aligned} \tag{11}
$$

- **RetNet** (Sun 等人, [arXiv:2307.08621](https://arxiv.org/abs/2307.08621), 2023): 每头一个固定衰减 $\gamma$, 支持并行, 递推和分块递推三种计算形式, 训练用并行或分块, 推理用递推. 7B 模型 8K 长度下解码比带 KV cache 的 Transformer 快 8.4 倍, 省 70% 显存.
- **GLA** (Yang 等人, [arXiv:2312.06635](https://arxiv.org/abs/2312.06635), 2023): 衰减 $\alpha_t$ 由输入决定, 逐 key 维门控. 配套的 FlashLinearAttention 在 1K 这样的短序列上也比 FlashAttention-2 快; 2K 上训练的模型外推到 20K 以上 PPL 没有明显变差.
- **DeltaNet** (Yang 等人, [arXiv:2406.06484](https://arxiv.org/abs/2406.06484), 2024): 写入前先按当前 key 读出旧值, 只写入差值, 即 $S_t=S_{t-1}-\beta_t(S_{t-1}k_t-v_t)k_t^\top$, 展开就是式 (11) 最后一行. 原始算法沿序列串行, 这篇用 Householder 矩阵乘积的紧凑表示做成可并行的分块训练, 在 1.3B, 100B token 上超过同期线性时间基线.
- **Mamba** (Gu 和 Dao, [arXiv:2312.00752](https://arxiv.org/abs/2312.00752), 2023) 从状态空间模型出发, 让 SSM 参数随输入变化 (selective), 用硬件感知的并行扫描训练, 推理吞吐比 Transformer 高 5 倍, 复杂度随长度线性. 见 [2.4.3 Mamba 系列](../../2.5-线性注意力与状态空间模型/2.5.3-Mamba系列/2.5.3-Mamba系列.md).

把门控和 delta 规则合起来, 再把门细化到通道, 就是 Kimi Delta Attention, 见 [01 KDA](../../2.5-线性注意力与状态空间模型/2.5.1-线性注意力机制/01-Kimi-Delta-Attention-KDA/01-Kimi-Delta-Attention-KDA.md). 这一族的状态都是固定大小, 生产模型多把它和全注意力层按比例混合 ([2.3.3](../../2.5-线性注意力与状态空间模型/2.5.1-线性注意力机制/2.5.1-线性注意力机制.md)).

## 5. KV 表示压缩, 统一对比与按瓶颈选

### 5.1 KV 表示压缩: 改每个 token 存多少

这一类不改连边, 每个 query 仍看全部历史, 改的是式 (2) 里每个 token 的字节数. 都要在训练时定下来 (GQA 也可以从 MHA 检查点 uptrain).

- **MQA** (Shazeer, [arXiv:1911.02150](https://arxiv.org/abs/1911.02150)): 所有 query 头共享一组 K/V, $H_{kv}=1$.
- **GQA** (Ainslie 等人, [arXiv:2305.13245](https://arxiv.org/abs/2305.13245)): query 头分成 $G$ 组, 组内共享, $H_{kv}=G$. $G=H$ 时是 MHA, $G=1$ 时是 MQA. 公式与 KV 字节对照见 [02 MQA 与 GQA](../../2.2-注意力机制/2.2.2-多头注意力变体/02-MQA与GQA-共享KeyValue头/02-MQA与GQA-共享KeyValue头.md).
- **MLA** (DeepSeek-V2, [arXiv:2405.04434](https://arxiv.org/abs/2405.04434)): 每个 token 先下投影成 $d_c$ 维潜变量, 各头的 K 和 V 由它上投影得到, 推理只缓存潜变量和一个各头共享的 $d_h^R$ 维 RoPE key. DeepSeek-V2 取 $d_c=4d_h=512$, $d_h^R=d_h/2=64$, 每 token 每层缓存 $512+64=576$ 个元素; 同为 128 头, 头维 128 的 MHA 要 $2\times128\times128=32768$ 个. 论文 Table 1 写 MLA 的缓存相当于只有 2.25 组的 GQA. 整机口径上, DeepSeek-V2 相对 DeepSeek 67B 的 KV cache 减少 93.3%. 推导见 [03 MLA](../../2.2-注意力机制/2.2.2-多头注意力变体/03-MLA-低秩潜变量与解耦RoPE/03-MLA-低秩潜变量与解耦RoPE.md), 矩阵吸收与 kernel 见 [04 MLA 工程实现](../../2.2-注意力机制/2.2.2-多头注意力变体/04-MLA-矩阵吸收与工程实现/04-MLA-矩阵吸收与工程实现.md).

这三种压缩的是头维 (每个位置存几个头的 K/V, 或存一个更低维的向量); prefill 的计算仍是 $O(n^2)$. DeepSeek-V4 的 CSA/HCA 沿序列维把若干相邻 token 的 KV 合成一条, 和这里的头维压缩可以叠加, 见 [2.3.2](../../2.4-稀疏注意力/2.4-稀疏注意力.md).

### 5.3 按瓶颈选

先判断瓶颈落在式 (1) 还是式 (2).

**prefill 或训练时显存不够.** 中间矩阵 $n\times n$ 放不下是最常见的情况, 用 FlashAttention 一族. 输出精确, 不用改模型, 训练好的检查点直接换. 只有 $n^2d$ 的计算量本身成了瓶颈 (例如 1.2 节的 128K 量级, 每层每头仍有约 $1.72\times10^{10}\times d$ 次乘加), 才需要动注意力图.

**decode 读 KV 太慢或太占显存.** 如果能决定架构, 训练期用 GQA 或 MLA, 把式 (2) 的 $H_{kv}d$ 降下来, 这一步对模型来说没有近似. 如果模型已经训好, 推理期可以叠第 3.7 节的驱逐或选读, 代价是丢掉的 KV 无法恢复. PagedAttention 在两种情况下都适用, 它只消除碎片, 和其它方法正交.

**长度大到 $n^2$ 不可接受.** 这时才轮到第 3 节和第 4 节. 稀疏图案保留 softmax, 但要决定哪些连边可以丢, BigBird 的下界说明丢边可能需要更多层来补; 线性与递推方法把历史压进固定大小的状态, decode 每步代价与长度无关, 1.2 节和 4.1 节的手算说明状态容量是硬上限. 这两类都要用新结构训练. 当前的长上下文模型多是混合方案: Mistral 7B 在全部层用滑动窗口; Kimi Linear 一类模型把线性注意力层和全注意力层按比例交错, 用少量全注意力层保住检索能力.

组合时的判断依据是每种方法动的是哪一个量. 线性注意力没有逐 token 的 KV, PagedAttention 对它无事可做; KV 驱逐要求还有逐 token 的 KV 可删; FlashAttention 加 MLA 时, K 和 V 要从潜变量上投影或吸收进 query, kernel 的分块方式要跟着改, 见 [04 MLA 工程实现](../../2.2-注意力机制/2.2.2-多头注意力变体/04-MLA-矩阵吸收与工程实现/04-MLA-矩阵吸收与工程实现.md).

本节在 [2.3 高效与稀疏注意力](../2.3-注意力的高效实现.md) 下, 前三篇按类展开.
