# 2.5.1 · 线性注意力机制

softmax 注意力在解码第 $t$ 步要读入前 $t$ 个 token 的 K 和 V, 上下文到百万 token 时, 解码时间基本花在读 KV cache 上. 线性注意力把注意力改写成一个矩阵状态的递推, 每个头只存一个 $d_k\times d_v$ 的矩阵, 解码每步的计算和读写都是常数. 这一小节讲这个状态怎样从 softmax 注意力推出来, 后来的工作怎样修改它的更新规则, 以及它在生产模型里为什么总是和全注意力层一起出现.

本小节的专篇是 [01 Kimi Delta Attention](./01-Kimi-Delta-Attention-KDA/01-Kimi-Delta-Attention-KDA.md). Linear Transformer, Performer, RFA, RetNet, GLA, DeltaNet 没有单独成篇, 公式和实验数字在 [2.3 的高效注意力综述](../../2.3-注意力的高效实现/01-高效注意力全景综述/01-高效注意力全景综述.md) 第 4 节. 下文的数字没有另注出处的, 都取自这两篇.

## 1. 从 softmax 到矩阵状态

### 1.1 归一化挡住了结合律

记 $Q,K\in\mathbb R^{n\times d_k}$, $V\in\mathbb R^{n\times d_v}$. softmax 注意力先算 $n\times n$ 的分数 $QK^\top$, 逐行做 softmax, 再乘 $V$. 如果没有 softmax, $(QK^\top)V=Q(K^\top V)$, 右边先算一个 $d_k\times d_v$ 的矩阵, 代价对 $n$ 是线性的. softmax 挡住了这个重排: 它对每一行先取指数, 再除以整行之和, 指数作用在每个 $q_i^\top k_j$ 上, 不能拆成 $q_i$ 的函数与 $k_j$ 的函数之积.

Katharopoulos 等人 ([2020](https://arxiv.org/abs/2006.16236)) 的办法是把相似度 $\exp(q^\top k)$ 换成 $\phi(q)^\top\phi(k)$, $\phi$ 是非负的特征映射. 这样第 $i$ 个输出的分子 $\phi(q_i)^\top\sum_j\phi(k_j)v_j^\top$ 中, 求和项与 $i$ 无关, 算一次就能给所有 query 复用. 论文用 $\phi(x)=\operatorname{elu}(x)+1$, 选 elu 而不选 relu, 是为了 $x<0$ 时梯度不为零. Performer 和 RFA 走的是另一条路: 用随机特征去逼近 softmax 核或高斯核本身, 不改变要逼近的目标, 只是逼近质量取决于特征数 $m$.

### 1.2 两个状态, 一个递推

因果解码时求和上限改成当前位置 $t$, 就得到两个随 $t$ 累加的状态:

$$
S_t=S_{t-1}+\phi(k_t)v_t^\top,\qquad z_t=z_{t-1}+\phi(k_t),\qquad o_t=\frac{S_t^\top\phi(q_t)}{z_t^\top\phi(q_t)}. \tag{1}
$$

$S_t\in\mathbb R^{d_k\times d_v}$ 存加权的 value, $z_t\in\mathbb R^{d_k}$ 存分母, 少了 $z_t$ 输出就不再是加权平均. 后来的工作 (RetNet, GLA, DeltaNet, KDA) 大多去掉了 $z_t$, 改用输出端的归一化, 并把 $\phi$ 换成恒等或短卷积加激活. 下文沿用这种写法: 状态为 $S_t$, 读出 $o_t=S_t^\top q_t$, 只看 $S_t$ 怎样更新.

式 (1) 训练时可以按整段并行算, 推理时按递推走, Linear Transformer 论文的标题就叫 *Transformers are RNNs*. 状态大小可以直接比较: $d_k=d_v=128$ 时一个头的 $S_t$ 有 16384 个数, 同一个头缓存 64 个 token 的 K 和 V 也是 16384 个数. 超过 64 个 token, KV 继续增长, $S_t$ 不变. 论文摘要里的「最高约 4000 倍」来自 CIFAR-10 逐像素生成, 序列长 3072; 在 WSJ 语音识别上它每个 epoch 快了约 3 倍, 但音素错误率 8.08 比 softmax 的 5.12 高. 速度和质量的差距从这一篇就已经出现.

## 2. 更新规则的四步修改

### 2.1 把更新看成一步梯度下降

KDA 论文用在线学习统一了这一族方法: 每一步对状态 $S$ 在某个目标上做一次梯度下降. 式 (1) 对应的目标是 $-\langle S^\top k_t,v_t\rangle$, 只奖励写入, 没有说明要擦掉什么, 所以状态只加不减. 把 key 看成地址, 状态就是一张从 key 到 value 的联想表. 若写入的 $k_i$ 两两正交, 用 $k_j$ 读出的就是 $v_j$; $\mathbb R^{128}$ 里最多 128 个两两正交的向量, 超过这个数, 读 $k_j$ 时必然混进 $\sum_{i\ne j}(k_i^\top k_j)v_i$ 这一项干扰.

几十万 token 的上下文, 只有 128 个正交方向可用, 状态必须决定留下哪些联想. 这一族方法之后的改动都在回答这个问题, 改法可以按两个维度排: 旧状态整体怎样衰减 (不衰减, 每头一个常数, 每头一个随输入变化的标量, 每个通道一个随输入变化的数), 以及新写入怎样处理当前 key 上已有的旧值 (直接叠加, 还是先读出再替换).

### 2.2 衰减与门

RetNet ([Sun 等人, 2023](https://arxiv.org/abs/2307.08621)) 给每个头一个固定衰减 $\gamma$, $S_t=\gamma S_{t-1}+k_tv_t^\top$, 越早的写入权重越小. 固定衰减使整段输出可以写成带衰减掩码的二次形式, 训练用并行或分块, 推理用递推; 7B 模型在 8K 长度上解码比带 KV cache 的 Transformer 快 8.4 倍, 省 70% 显存. RFA 更早加过一个可选的 sigmoid 门, 每步旧状态乘 $g_t$, 新信息乘 $1-g_t$, 在 WikiText-103 上带来超过 1.8 的困惑度改善.

GLA ([Yang 等人, 2023](https://arxiv.org/abs/2312.06635)) 把衰减改成由输入决定的对角矩阵, $S_t=\operatorname{Diag}(\alpha_t)S_{t-1}+k_tv_t^\top$, 每个 key 通道按自己的速度遗忘. 配套的 FlashLinearAttention 在 1K 这样的短序列上也比 FlashAttention-2 快. Mamba-2 的选择性状态空间模型在式 (1) 的写法下也属于这一类, 只是衰减是每头一个标量 ([2.5.3](../2.5.3-Mamba系列/2.5.3-Mamba系列.md) 第 5 节). 衰减解决的是状态无界增长, 没有解决同一个 key 上新旧值叠在一起的问题.

### 2.3 先擦后写, 再细化到通道

DeltaNet ([Yang 等人, 2024](https://arxiv.org/abs/2406.06484)) 把目标换成重建误差 $\frac12\|S^\top k_t-v_t\|^2$, 梯度步为

$$
S_t=(I-\beta_tk_tk_t^\top)S_{t-1}+\beta_tk_tv_t^\top. \tag{2}
$$

先用 $S_{t-1}^\top k_t$ 读出当前 key 上已有的值, 再按学习率 $\beta_t$ 往 $v_t$ 拉. $k_t$ 归一化且 $\beta_t=1$ 时, 写入后 $S_t^\top k_t=v_t$, 旧值被完全替换. $I-\beta_tk_tk_t^\top$ 是广义 Householder 变换, DeltaNet 论文用 Householder 乘积的紧凑表示把式 (2) 做成可分块并行的训练. Gated DeltaNet (GDN, [Yang 等人, 2024](https://arxiv.org/abs/2412.06464)) 再乘一个每头的标量门 $\alpha_t$, 让与当前 key 无关的旧联想也能被遗忘.

[KDA](./01-Kimi-Delta-Attention-KDA/01-Kimi-Delta-Attention-KDA.md) 把 GDN 的标量门换成通道级的 $\operatorname{Diag}(\alpha_t)$, 更新为 $S_t=(I-\beta_tk_tk_t^\top)\operatorname{Diag}(\alpha_t)S_{t-1}+\beta_tk_tv_t^\top$. 对角阵和秩 1 项不交换, 先衰减再擦写的顺序有意义. 论文给的动机来自位置编码: 把注意力分数写成 $q_t^\top(\prod_jR_j)k_i$, RoPE 的 $R_j$ 是旋转, GDN 的 $R_j$ 是数据相关的转移, 形式相同; RoPE 不同维度对用不同频率, 标量门在各维上相同. 在回文, MQAR 和栈三个合成任务上, KDA 随长度增加准确率都最高, Mamba2 在同一设置下三个任务都没学会.

## 3. 更新规则与计算代价

### 3.1 各方法的对照

| 方法 | 状态更新 | 衰减粒度 | 擦除 | 训练形式 |
|---|---|---|---|---|
| Linear Transformer | $S_{t-1}+\phi(k_t)v_t^\top$ | 无 | 无 | 并行或递推 |
| RetNet | $\gamma S_{t-1}+k_tv_t^\top$ | 每头常数 | 无 | 并行, 分块 |
| GLA | $\operatorname{Diag}(\alpha_t)S_{t-1}+k_tv_t^\top$ | 通道, 依赖输入 | 无 | 分块 |
| DeltaNet | $(I-\beta_tk_tk_t^\top)S_{t-1}+\beta_tk_tv_t^\top$ | 无 | 有 | Householder 分块 |
| GDN | $\alpha_t(I-\beta_tk_tk_t^\top)S_{t-1}+\beta_tk_tv_t^\top$ | 每头标量, 依赖输入 | 有 | 分块 |
| KDA | $(I-\beta_tk_tk_t^\top)\operatorname{Diag}(\alpha_t)S_{t-1}+\beta_tk_tv_t^\top$ | 通道, 依赖输入 | 有 | WY/UT 分块 |

表中的状态大小都是每头 $d_k\times d_v$, 推理时的读写量相同, 区别全在转移矩阵上. 按行往下读, 衰减和擦除两列是两个独立的维度, 一直到 GDN 才把两者合在一起. 后四行的写法沿用 KDA 论文 Table 7, 省略了归一化和核函数; Mamba2 在这张表里与 GDN 同为头级标量衰减, 但没有擦除.

转移矩阵越复杂, 分块训练越难写. 标量衰减在块内可以写成一个 $C\times C$ 的衰减矩阵, 直接乘到 $KK^\top$ 上; 通道衰减在每个通道上不同, 只能把累积衰减 $\Gamma$ 和 $1/\Gamma$ 分别乘到 $K$ 的各行. $\Gamma$ 是许多 $(0,1)$ 内的数连乘, 块越长越接近 0, 倒数在半精度下可能溢出. GLA 在对数域算相对衰减并做二级分块, 代价是用不满半精度矩阵乘. KDA 把对角加低秩转移的两个低秩向量都绑到 $k_t$ 上, 二级分块的矩阵计算从四次减到两次, 序列长度 64K 时比通用 DPLR 算子快接近 2 倍.

### 3.2 什么长度开始划算

KDA 论文给出单头, 头维 $d_h$, 块长 $C=64$ 时的 FLOPs:

$$
\text{FLOPs}_{\text{KDA}}=6Td_h^2+3TCd_h+TC^2,\qquad\text{FLOPs}_{\text{Attn}}=2T^2d_h. \tag{3}
$$

取 $d_h=128$, KDA 每个 token 约 126976 次运算, 与长度无关; 注意力平均每个 token $256T$ 次. 两者在 $T\approx496$ 处相等. 这里只算了 token 混合, 投影和 MoE 两边相同. 短上下文下线性注意力省不了多少计算, 4k 到 16k 的 prefill 上 Kimi Linear 与全 MLA 相当.

解码阶段的收益来自不读 KV. KDA 每步先对状态逐行乘衰减, 再按 $k_t(k_t^\top\tilde S)$ 的顺序算擦写项, 不用构造 $d_k\times d_k$ 的矩阵, 最后读出, 合计是 $d_kd_v$ 的常数倍. 解码瓶颈在显存带宽, 状态读写量固定, 所以 KDA 层的解码时间不随上下文增长. 整模型的加速受限于剩下的全注意力层, 见下一节.

## 4. 在模型里的位置

### 4.1 三层线性配一层全注意力

固定状态的容量上限决定了纯线性模型在长程检索上吃亏, Kimi Linear 按层混合, 每 3 层 KDA 接 1 层 MLA. MLA 层不用位置编码, 位置信息全交给 KDA 层; 推理时 NoPE 的 MLA 可以转成纯 MQA, 扩上下文也不用调 RoPE 底数. 只有四分之一的层有 KV cache, 长序列下 KV 占用最多减少 75%. 消融里 7:1 的验证困惑度明显变差, 1:1 接近 3:1 但全注意力层多一倍; 输出门从 Sigmoid 换成 GDN 原文的 Swish, 验证困惑度从 5.65 升到 5.81, 比去掉门还差.

同配方对比在 48B 总参数, 3B 激活, 1.4T token 上做. 128k 长文本的 RULER 上, 全 MLA 81.3, GDN 混合 80.5, Kimi Linear 84.3; MLA 改回 RoPE 的变体降到 78.8. prefill 在 512k 时快 2.3 倍, 1M 时快 2.9 倍. 每 4 层仍有 1 层 MLA 的二次项, 只看 token 混合整模型最多快 4 倍, 2.9 倍在这个上限之内. 1M 上下文解码, batch 为 1 时快 2.3 倍; 省下的显存放更大的 batch, 每 token 输出时间 1.84 ms 对 11.48 ms. 继续训到 5.7T token 的发布检查点, 1M 上下文 RULER 为 94.8. Kimi K3 沿用 3:1, 注意力层为 69 层 KDA 加 24 层 MLA, 衰减改成有下界的参数化, 并为 KDA 做了前缀扫描形式的上下文并行.

### 4.2 往哪里读

第一次接触这一族的读者, 先读综述第 4.1 节和第 4.6 节, 那里有 Linear Transformer 的状态手算和 RetNet, GLA, DeltaNet 的统一写法; 再读 [KDA](./01-Kimi-Delta-Attention-KDA/01-Kimi-Delta-Attention-KDA.md) 第 1 节的在线学习视角和第 2 节的 WY 与 UT 分块推导, 它的第 2.8 节有一段 NumPy 代码, 按递推和分块各算一遍并检查两者一致. 想看同一个递推式从状态空间模型一侧怎样得到, 读 [2.5.3 Mamba 系列](../2.5.3-Mamba系列/2.5.3-Mamba系列.md) 第 5 节的状态空间对偶.

RWKV-4 的逐通道衰减和 Griffin 的 RG-LRU 状态是向量而不是矩阵, 推导在 [2.5.4 线性 RNN 与 Griffin](../2.5.4-线性RNN与Griffin/2.5.4-线性RNN与Griffin.md). 线性层与注意力层怎样配比, 以及 MiniMax 从 Text-01 的 7:1 闪电注意力混合退回 M2 全注意力的理由, 在 [2.5.5 混合架构](../2.5.5-新兴架构与混合模型/2.5.5-新兴架构与混合模型.md). 整条线的位置和与状态空间模型的对照见 [2.5 节首页](../2.5-线性注意力与状态空间模型.md); 不改 softmax, 只改执行方式或只读部分 KV 的做法分别在 [2.3](../../2.3-注意力的高效实现/2.3-注意力的高效实现.md) 和 [2.4](../../2.4-稀疏注意力/2.4-稀疏注意力.md).
