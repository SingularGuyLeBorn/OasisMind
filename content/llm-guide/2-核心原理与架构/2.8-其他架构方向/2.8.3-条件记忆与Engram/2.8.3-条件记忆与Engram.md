# 2.8.3 · 条件记忆与 Engram

## 1. 问题

语言建模里有一类模式是局部、静态、固定搭配式的: 多 token 专名, 成语, 公式化短语. 经典 $n$-gram 语言模型用计数表处理它们. 标准 Transformer 没有按局部上下文查表的算子, 只能在早期层用 Attention 和 FFN 逐层把这些条目拼出来, 占用了本可用于组合推理的深度.

MoE 解决的是另一件事: 按隐藏态选少数专家做矩阵乘, 稀疏的是计算. 条件记忆 (Engram, Cheng et al., 2026) 稀疏的是表行: 用当前 token 及其前几个 token 组成的 N-gram 做哈希, 从大嵌入表里取出向量, 经上下文门控加进残差. 查表地址只依赖 token ID, 在进入网络之前就能算出, 表因此可以放在 Host 内存里异步预取.
