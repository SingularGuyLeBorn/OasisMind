# · LLM-JEPA: 在嵌入空间里加一项预测

材料是 Huang, LeCun, Balestriero 的 LLM-JEPA 论文 ([2509.14252](https://arxiv.org/abs/2509.14252)), 问题是视觉里那种「在嵌入空间让一个视图预测另一个视图」的目标能不能加到生成式 LLM 上.

## 问题: 语言模型只在输入空间学习

### 两类表示学习

LLM-JEPA 论文的引言把表示学习分成两派. 第一派是生成或重建: 模型在输入空间里还原数据, 语言里是预测下一个 token, 视觉里是 MAE 这类遮住图块再还原像素的方法. 第二派是不做重建的联合嵌入预测架构 (Joint Embedding Predictive Architecture, JEPA): 同一对象的不同视图 (论文举的例子是同一栋楼在一天中不同时刻的照片) 经编码后, 要求能在嵌入空间里互相预测, 同时防止所有嵌入塌缩到同一点.

论文引用的结论是: 离开输入空间的目标偏差更小, 代价是表示可能发生维度塌缩; 在视觉感知任务上, JEPA 有多项可证明的好处. 语言这边情况相反, 重建式方法仍占绝对主导. 一个原因是今天评价 LLM 主要看它能不能在输入空间里生成文本, 纯嵌入空间的目标没有生成能力.

### 已有的嵌入空间目标为什么不够

论文第 2 节列了语言上已有的几种嵌入空间方法:

- SimCSE (Gao 等, 2021) 把同一句话在两种 dropout 下的表示当作正样本对, 用对比损失训练, 得到当时最好的句子嵌入.
- Wang 等 (2022) 用弱监督的文本对训练联合嵌入架构; Ni 等 (2021) 改用预训练模型代替有监督文本对.
- Reimers 和 Gurevych (2019) 在 BERT 上加语义损失, 让语义相近的句子嵌入靠近.

这些方法的共同点是产出文本嵌入, 模型本身不能生成. 大量评测和应用要求生成, 所以它们无法替代 LLM 的训练目标.

另一类工作 (论文第 3.2 节提到 Barrault 等 2024、Wang 和 Sun 2025) 已经在 LLM 上加了嵌入空间的正则项或训练目标, 但依赖对嵌入空间的复杂结构约束, 例如层次组织和聚类, 论文认为它们不属于 JEPA 的范畴. 还有一类做法把 (自然语言, 正则)、(自然语言, SQL)、(issue, 代码 diff) 这样的成对数据用于微调, 但只是学习从一个视图生成另一个, 没有 JEPA 式的损失. LLM-JEPA 的要求是两件事同时成立: 保留生成能力, 同时在嵌入空间加一个 JEPA 目标. 论文把 JEPA 式 LLM 的缺位归因于为语言设计这类目标的难度, 并把自己定位为这个方向上的第一步, 同时覆盖微调和预训练.

### 视图从哪里来

视觉 JEPA 的两个视图来自数据增强 (裁剪、遮挡等). 文本没有对应的成熟增强手段. 论文的选择是先只用天然带两个视图的数据集: 同一知识以两种形式出现. 典型例子:

- NL-RX: 正则表达式的英文描述 (Text) 与正则表达式本身 (Code).
- Spider: 数据库 ID 加查询描述 (Text) 与 SQL (Code).
- GSM8K: 题目与解答.
- git issue 与对应的代码 diff.

论文强调, 能否拿到非平凡的视图是 JEPA 目标成败的关键; 如果将来有类似视觉数据增强的机制, JEPA 目标才能用到任意数据集上. 以下沿用论文的记号, 用 Text 和 Code 指代两个视图, 方法本身对视图的类型没有要求.

## 目标函数与实现

### 生成项

论文式 (1) 是标准的 next-token 损失:

$$
\mathcal L_{\mathrm{LLM}}(\mathrm{Text}_{1:L-1},\mathrm{Text}_L)=\mathrm{XEnt}\Bigl(\mathrm{Classifier}\bigl(\underbrace{\mathrm{Enc}(\mathrm{Text}_{1:L-1})}_{\text{前缀的隐状态}}\bigr),\ \underbrace{\mathrm{Text}_L}_{\text{下一个 token}}\Bigr). \tag{1}
$$

$\mathrm{XEnt}$ 是交叉熵, $\mathrm{Classifier}$ 把隐状态映射到词表上的 logits. 因果注意力让所有位置的损失在一次前向中同时算出. 论文说明 LLM-JEPA 的构造与 $\mathcal L_{\mathrm{LLM}}$ 的具体形式无关; 在 Text 到 Code 的生成任务里, 它就是给定 Text 生成 Code 的交叉熵.

**完整损失**

LLM-JEPA 的损失 (论文式 2) 是:

$$
\mathcal L_{\mathrm{LLM\text{-}JEPA}}=\underbrace{\sum_{\ell=2}^{L}\mathcal L_{\mathrm{LLM}}(\mathrm{Text}_{1:\ell-1},\mathrm{Text}_\ell)}_{\text{生成能力}}+\lambda\cdot\underbrace{d\bigl(\mathrm{Pred}(\mathrm{Enc}(\mathrm{Text})),\ \mathrm{Enc}(\mathrm{Code})\bigr)}_{\text{抽象能力 (JEPA)}}. \tag{2}
$$

$\lambda\ge0$ 平衡两项, $\mathrm{Enc}$ 是编码器, $\mathrm{Pred}$ 是预测器, $d$ 是度量. 三个部件的具体选择如下.

**编码器.** 一段输入的嵌入取最终一层、最终一个 token 的隐状态, 这是 LLM probing 的常用做法. 编码器就是 LLM 本身, 没有另外的网络.

**度量.** 论文沿用视觉里的通行做法, 用余弦相似度比较嵌入. 写成要最小化的距离:

$$
d(\boldsymbol u,\boldsymbol v)=1-\frac{\boldsymbol u^\top\boldsymbol v}{\|\boldsymbol u\|\,\|\boldsymbol v\|}. \tag{3}
$$

$\boldsymbol u$ 是预测出的 Code 嵌入, $\boldsymbol v$ 是实际的 Code 嵌入. 两者方向相同时 $d=0$, 正交时 $d=1$, 相反时 $d=2$. 手算一个二维例子: $\boldsymbol u=(3,4)$, $\boldsymbol v=(4,3)$, 则 $\boldsymbol u^\top\boldsymbol v=24$, 两个范数都是 5, 余弦为 $24/25=0.96$, $d=0.04$. 把 $\boldsymbol u$ 放大成 $(30,40)$, $d$ 不变: 余弦只看方向, 不看长度.

**预测器.** 论文利用 LLM 自身的自回归结构做预测器: 在输入末尾追加特殊 token `[PRED]`, 让输入再经过若干步非线性处理, 取最终一个 `[PRED]` 在最终一层的嵌入作为 $\mathrm{Pred}(\mathrm{Enc}(\cdot))$. 追加的个数 $k\in\{0,\dots,K\}$; $k=0$ 时预测器是恒等映射, $\mathrm{Pred}(x)=x$, 此时 JEPA 项直接要求两个视图的嵌入方向一致. 预测器复用 LLM 权重 (tied weights), 不增加参数, 也省掉了预测器结构的设计选择.

**塌缩问题.** 单看式 (3), 有一个平凡解: 把所有输入都映射到同一个向量, $d$ 恒为 0. 视觉 JEPA 需要专门的机制防止这种塌缩, 引言里提到的「维度塌缩」就是它的弱化形式 (嵌入只占据少数几个维度). 式 (2) 里没有 EMA 目标编码器, 也没有停止梯度; 生成项始终存在, 要求最终一层隐状态仍能区分不同的下一个 token, 所有输入映射到同一向量的解会让生成项变得很差. 第 4.2 节的消融显示, 生成项权重为 0 时模型完全失效.

**数值例子.** 设某个批次的平均 next-token 损失为 0.80, Text 经 $k=1$ 个 `[PRED]` 得到的预测嵌入与 Code 嵌入的余弦为 0.60, 取 $\lambda=2$. 式 (2) 的值为 $0.80+2\times(1-0.60)=1.60$. 训练若干步后余弦升到 0.95, next-token 损失仍为 0.80, 总损失降为 $0.80+2\times0.05=0.90$. 第 2.4 节的实验显示, 实际训练中出现的正是这种情况: 生成项几乎不变, JEPA 项单独下降.

**实现: 一次额外前向**

要算式 (2) 的 JEPA 项, 需要 Text 和 Code 各自独立的嵌入. 生成项本来就把 Text 和 Code 拼在一起输入, 但在因果注意力下, 拼在后面的 Code 能看到前面的 Text, 它的最终一个 token 的隐状态已经混入了 Text 的信息, 不能当作 Code 的独立嵌入. 朴素做法是三次前向: 拼接序列一次 (生成项), Text 单独一次, Code 单独一次.

**分块因果掩码.** 论文第 3.2 节把 Text 和 Code 打包进同一个上下文窗口, 用一个分为 2 块、每块内部因果的注意力掩码, 让两段互不可见. 设 Text 占位置 1 到 3, Code 占位置 4 到 5, 掩码矩阵 (行为查询, 列为键; 0 表示可见, $-\infty$ 表示屏蔽) 为:

$$
M=\begin{pmatrix}
0&-\infty&-\infty&-\infty&-\infty\\
0&0&-\infty&-\infty&-\infty\\
0&0&0&-\infty&-\infty\\
-\infty&-\infty&-\infty&0&-\infty\\
-\infty&-\infty&-\infty&0&0
\end{pmatrix}. \tag{4}
$$

左上 $3\times3$ 和右下 $2\times2$ 各是一个下三角块, 两块之间全部屏蔽. 一次前向后, 位置 3 的隐状态只依赖 Text, 位置 5 的只依赖 Code, 两个嵌入同时得到. HuggingFace 的大多数 Transformer 实现支持加性注意力掩码, 论文给出的代码就是先把整个矩阵填 $-\infty$, 再把两个对角块换成三角掩码.

这样 JEPA 项只需要一次额外前向, 总共两次而不是三次. 论文代码中掩码张量的批维度是 `batch_size * 2`: 每个样本对应两条序列, 一条是生成项用的拼接序列, 一条是用分块掩码同时编码 Text 和 Code 的序列 (末尾带 $k$ 个 `[PRED]`). 两条序列长度相近, 所以训练的前向计算大约翻倍; 反向传播也要经过两条序列. 论文结论部分把这称为训练计算量翻倍, 是目前的主要瓶颈; 推理时只用生成路径, 没有额外开销.

**只训 next-token 损失不会顺带优化 JEPA 项**

论文第 3.3 节先回答一个问题: JEPA 项是否已经被 next-token 目标隐式地最小化了? 设置是 Llama-3.2-1B-Instruct 在 NL-RX-SYNTH 上微调, 比较两种训练:

1. 只用 $\mathcal L_{\mathrm{LLM}}$ 求梯度, 同时监测 JEPA 距离 (不回传梯度).
2. 用式 (2) 求梯度.

图 3 右侧的结果: 第一种训练中 JEPA 距离基本保持常数, 第二种中它持续下降, 说明需要显式加入这一项. 两种训练的 next-token 损失曲线几乎重叠, 加入 JEPA 项没有损害下一 token 预测. 最终准确率分别为 51.95% 和 71.10%. 由于两者的 next-token 损失相近, 论文认为准确率差距主要来自 JEPA 项.

论文把这与 Balestriero 和 LeCun (2024) 的发现对照: 图像空间的自编码器可以在不牺牲重建和生成目标的前提下, 变成强得多的分类器.

**实验结果**

### 实验协议

所有实验用 5 个固定随机种子 $\{82,23,37,84,4\}$ 各跑一次, 报告均值和标准差, 并做配对单尾 t 检验. 为了与最强的基线比较, 先对每个 (模型, 数据集) 组合在 $\{1\mathrm e{-5},2\mathrm e{-5},4\mathrm e{-5},8\mathrm e{-5}\}$ 中选出让标准微调 4 个 epoch 后准确率最高的学习率, 再固定学习率, 在 $(k,\lambda)\in\{0,1,2,3,4\}\times\{0.5,1,2,4\}$ 的 20 个格点上搜索 LLM-JEPA 的超参数.

评测口径: NL-RX 系列要求生成的正则表达式完全匹配; GSM8K 要求最终答案完全匹配; Spider 要求生成的 SQL 执行结果完全匹配.

表 1 和附录表 11 给出了 NL-RX-SYNTH 上的生成样例. 标准微调的一类常见错误是在正确的正则后面多出一个 `.*`, 例如目标为 `(([0-9])|(.)).*([AEIOUaeiou]).*` 时输出了 `(([0-9])|(.)).*([AEIOUaeiou]).*.*`, LLM-JEPA 输出正确. LLM-JEPA 也会出错, 表 11 最终几行中它同样多写了 `.*`. 完全匹配的口径下, 多一个 `.*` 就算错.

**改写数据预训练** (附录表 9): cestwc/paraphrase 数据集中每组有 5 个互为改写的句子, 用第 $i$ 个版本预测第 $i+1$ 个版本的嵌入来构造 JEPA 项, 目的是把同一组改写的嵌入收进一个紧凑的子空间. 预训练 4 个 epoch, 再在 Rotten Tomatoes 和 Yelp 上微调 1 个 epoch; 微调阶段不用 JEPA 项. 预训练跑 5 次, 每个预训练模型再微调 5 次. 结果: Rotten Tomatoes 从 56.57 到 57.76, Yelp 从 26.46 到 27.15, p 值分别为 7.38e-4 和 1.00e-3. 预训练数据与评测数据没有直接联系, 提升只能来自预训练阶段. 附录表 7 的生成样例显示, JEPA 预训练后模型仍能续写句子, 只是不擅长结束. 例如给出开头后, 模型生成「A man is riding a horse in a field」, 与真值一致, 但后面接了一长串句点; 另一些样例在后半句偏离真值, 例如真值的「on top of a building」变成了「on a rock」.

### 表示空间发生了什么

论文第 4.2 节和附录 A.2、A.6 分析表示. 用 t-SNE 画出 Text 和 Code 的嵌入 (图 4、图 6): 基座模型有一定结构, 标准微调后结构被打乱, LLM-JEPA 微调后出现清晰的结构, $k=0$ 和 $k=1$ 的模式相似.

论文的假设是: JEPA 项把 $\mathrm{Enc}(\mathrm{Text})$ 到 $\mathrm{Enc}(\mathrm{Code})$ 的映射约束在一个窄的子空间里. 如果是这样, 差值矩阵 $\mathrm{Enc}(\mathrm{Text})-\mathrm{Enc}(\mathrm{Code})$ 的奇异值应当显著变小, 图 3 左侧证实了这一点: LLM-JEPA 的前 100 个奇异值比基座和标准微调低几个数量级.

用一个极端例子理解这两个检验. 设有 $N$ 个样本, 每个样本的 Code 嵌入恰好等于 Text 嵌入加上同一个向量 $\boldsymbol c$. 差值矩阵的 $N$ 行都是 $\boldsymbol c$, 秩为 1, 只有一个非零奇异值. 若关系是 $\mathrm{Enc}(\mathrm{Code})=\mathrm{Enc}(\mathrm{Text})A$, 取 $X=A$ 即可让下面的线性回归误差为 0. 奇异值小说明差值集中在少数方向上, 回归误差小说明两组嵌入之间可以用一个线性映射对应起来. 论文进一步假设映射近似线性, 用最小二乘 $\min_X\|\mathrm{Enc}(\mathrm{Text})X-\mathrm{Enc}(\mathrm{Code})\|_2$ 检验 (附录表 14):

| 模型 | 线性回归误差 | 前 100 个奇异值均值 |
|---|---|---|
| 基座 | 3953.11 | 310.73 |
| 标准微调 | 3035.01 | 341.80 |
| LLM-JEPA, $k=1$ | 4.47 | 94.84 |
| LLM-JEPA, $k=0$ | 4.04 | 16.82 |

LLM-JEPA 让两个视图的嵌入之间几乎是一个线性变换, 回归误差降了约三个数量级. 论文的措辞是这「可能」是准确率提升的原因; 表示结构与准确率之间的因果关系没有单独检验.

### 设计选择

表 3 在 NL-RX-SYNTH 上比较 ($\mathrm{lr}=2\mathrm e{-5},\lambda=1,k=1$):

| 变体 | 准确率 |
|---|---|
| 标准微调 | 57.29 ± 5.32 |
| LLM-JEPA (余弦, `[PRED]` 追加在末尾, Text 预测 Code) | 71.46 ± 1.34 |
| 度量换成 $\ell_2$ 范数 | 2.22 ± 0.07 |
| 度量换成 MSE | 70.64 ± 2.05 |
| `[PRED]` 放在开头 | 68.07 ± 2.57 |
| 反方向, Code 预测 Text | 65.70 ± 2.63 |
| 换成 InfoNCE ($\tau=0.07$) | 34.40 ± 6.10 |

所有替代方案都不如原设计, 但除 $\ell_2$ 和 InfoNCE 外都好于标准微调. $\ell_2$ 范数和 MSE (平方 $\ell_2$) 只差一个平方, 结果却从 70.64 掉到 2.22, 论文没有给出解释. InfoNCE 是对比学习的标准损失, 它不仅低于基线, 标准差也远大于其他变体.

### 生成项不能去掉

式 (2) 中生成项的权重固定为 1, 无法降到 0. 附录 A.3 加入权重 $\gamma$:

$$
\mathcal L_{\mathrm{LLM\text{-}JEPA}}=\gamma\sum_{\ell=2}^{L}\mathcal L_{\mathrm{LLM}}(\mathrm{Text}_{1:\ell-1},\mathrm{Text}_\ell)+\lambda\cdot d\bigl(\mathrm{Pred}(\mathrm{Enc}(\mathrm{Text})),\mathrm{Enc}(\mathrm{Code})\bigr), \tag{5}
$$

并保持 $\max(\gamma,\lambda)=1$, 以便固定学习率. 附录表 10 ($k=0$):

| $\gamma/\lambda$ | 0 | 0.01 | 0.1 | 1 | 10 | 100 | $\infty$ |
|---|---|---|---|---|---|---|---|
| 准确率 | 0.00 | 1.38 | 45.80 | 70.42 | 67.52 | 66.83 | 57.29 |

$\gamma=0$ 时模型只输出空串. $\gamma/\lambda=\infty$ 即 $\lambda=0$, 就是标准微调. 两项权重相当时最好, JEPA 项权重降到生成项的 1% 时 (比值 100) 仍比标准微调高近 10 个百分点. 论文据此把 JEPA 项定位为正则项, 补充生成损失, 不能取代它.

### 降低训练成本: 随机丢弃 JEPA 项

第 5.2 节提出 JEPA 损失丢弃 (loss dropout): 以批次为单位, 按比例 $\alpha$ 随机不算 JEPA 项. 被丢弃的批次不需要额外那次前向. 每个 epoch 的计算量变为标准微调的 $(2-\alpha)$ 倍:

- $\alpha=0$: 2 倍, 即原始的 LLM-JEPA.
- $\alpha=0.5$: 1.5 倍.
- $\alpha=0.75$: 1.25 倍.

论文的经验规则是让 $\lambda(1-\alpha)$ 大致保持不变. 例如 $\alpha=0$ 时 $\lambda=1$, 乘积为 1; $\alpha=0.5$ 时取 $\lambda=2$, $\alpha=0.75$ 时取 $\lambda=4$, 乘积都是 1. 直观上, 只有 $(1-\alpha)$ 比例的批次有 JEPA 梯度, 放大 $\lambda$ 让平均下来的 JEPA 权重不变.

表 6 的每一行是同一计算预算 (相邻两行相差 4.83 PFLOPs). 最终一行 (预算最大) 的准确率:

| 配置 | $\alpha=0,\lambda=1$ | $\alpha=0.5,\lambda=2$ | $\alpha=0.75,\lambda=4$ |
|---|---|---|---|
| 准确率 | 63.96 ± 1.07 | 72.11 ± 2.18 | 73.08 ± 1.28 |

同样的计算量下, 丢弃 75% 的 JEPA 项反而最好. 按 $(2-\alpha)$ 算, $\alpha=0.75$ 时每个批次的成本是原始 LLM-JEPA 的 $1.25/2=0.625$, 同样预算能多训练 $2/1.25=1.6$ 倍的批次. 预算最小的第一行差距更大: 三种配置 ($\alpha=0$; $\alpha=0.5,\lambda=1$; $\alpha=0.75,\lambda=1$) 分别为 19.85、25.00、32.46. 图 5 还显示, 在同样 PFLOPs 下 LLM-JEPA 比标准微调收敛更快.

## 与相关方法的关系和边界

### 与相关方法的关系

**I-JEPA.** JEPA 这一架构名称出自 LeCun (2022) 的立场论文, 那篇文章主张在表示空间而不是输入空间里做预测, 以此学习世界模型, 但没有给出语言模型上的具体配方. I-JEPA (Assran 等, CVPR 2023) 是视觉中的 JEPA: 从图像的一个上下文块预测其他目标块的表示, 不重建像素.

I-JEPA 的三个部件都是 ViT: 上下文编码器、目标编码器和预测器. 只有上下文编码器和预测器靠梯度更新; 目标编码器初始化为上下文编码器的拷贝, 之后按指数滑动平均 (EMA) 跟随它, 动量从 0.996 线性升到 1.0. 论文说 EMA 目标编码器对用 ViT 训练联合嵌入架构是必需的, I-JEPA 也一样. 损失是预测表示与目标表示之间的平方 $\ell_2$ 距离. 掩码用 multi-block 策略: 每张图采样 4 个可以重叠的目标块, 面积比例在 $(0.15,0.2)$, 长宽比在 $(0.75,1.5)$; 再采样 1 个面积比例在 $(0.85,1.0)$ 的上下文块, 并去掉与目标块重叠的区域. 表 6 的消融 (ViT-B/16 预训练 300 epoch, ImageNet-1K 只用 1% 标签做线性评估) 中, multi-block 得到 54.2, 把图像切成四个象限预测其中一个只有 15.5, 单个大块 20.2, 随机图块 17.6. 规模上, ViT-H/14 在 ImageNet 上用 16 张 A100 训练不到 72 小时.

对照式 (2) 可以看出两边的差别: I-JEPA 用 EMA 目标编码器防塌缩, 视图由掩码构造; LLM-JEPA 没有 EMA 也没有单独的预测器网络, 防塌缩靠生成项 (第 4.2 节), 视图来自数据. 损失度量也不同, I-JEPA 是平方 $\ell_2$, LLM-JEPA 是余弦, 表 3 中换成 MSE 后准确率从 71.46 降到 70.64. LLM-JEPA 论文的结论部分说自己的目标是视觉 JEPA 目标的直接复刻; 实现上, 编码器和预测器都是 LLM 本身, 视图来自数据集里的成对样本, 生成项一直保留.

**对比学习.** SimCSE 一类方法也在嵌入空间训练, 但需要负样本, 产出的模型不能生成. LLM-JEPA 只拉近正样本对的嵌入, 没有负样本; 表 3 中把损失换成带负样本的 InfoNCE, 效果明显变差.

**MTP.** 多 token 预测 ([2.8.1](../2.8.1-多Token预测MTP/2.8.1-多Token预测MTP.md)) 让模型多预测后面几个 token, 损失仍是词表上的交叉熵, 属于输入空间重建. LLM-JEPA 的附加项在嵌入空间, 不经过词表.

**扩散语言模型.** 掩码扩散 ([2.8.2](../2.8.2-扩散语言模型DLM/2.8.2-扩散语言模型DLM.md)) 改变的是生成方式, 损失同样在 token 上. 两者改动的层面不同.

| | 损失所在空间 | 第二视图 | 是否保留生成 | 负样本 |
|---|---|---|---|---|
| 标准 next-token | token | 无 | 是 | 无 |
| MTP | token | 无 | 是 | 无 |
| SimCSE | 嵌入 | 同一句话的另一次 dropout | 否 | 有 |
| LLM-JEPA | token + 嵌入 | 数据集中的成对样本 | 是 | 无 |

### 边界

**视图来源.** 实验几乎全部依赖天然成对的数据 (描述与正则、描述与 SQL、题目与解答、改写组). 论文自己承认, 没有类似视觉数据增强的机制之前, JEPA 目标不能用到任意语料上. 问答数据上的尝试 (本文第 3.4 节) 提升约 1 到 1.5 个百分点.

**规模.** 模型在 1B 到 8B 之间, 以微调为主. 预训练实验用的是 NL-RX-SYNTH 和改写数据这样的小数据集, 论文称其为初步结果. 在通用语料上做大规模预训练的效果未知.

**计算.** 训练计算约为两倍, 丢弃机制能降到 1.25 倍左右并且在同预算下更好, 但仍高于标准训练.

**超参数.** 多了 $\lambda$ 和 $k$ 两个超参数. 论文的局限部分指出最优点可能出现在 $(\lambda,k)$ 网格的任何位置 (图 7), 调参成本高. 图 7 列出了 6 组网格 (Llama 在 GSM8K、Spider、NL-RX-SYNTH 预训练上, Gemma、OpenELM、OLMo 在 NL-RX-SYNTH 上), 最好的格点可能在 $\lambda$ 或 $k$ 的高端, 也可能在低端, 还有随机位置的凹陷和尖峰. 相邻格点的准确率通常接近, 论文据此认为可能存在更高效的调参算法, 但还没有找到.

**评测口径.** 预训练和 8B 实验改用前缀匹配, 因为模型学不会结束生成. 这些数字与完全匹配下的数字不能直接比较.
