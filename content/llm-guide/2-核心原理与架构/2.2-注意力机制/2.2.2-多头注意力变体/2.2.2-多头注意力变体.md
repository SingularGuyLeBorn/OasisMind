# 多头注意力变体

[2.2.1 自注意力机制](../2.2.1-自注意力机制/2.2.1-自注意力机制.md) 给出了单头缩放点积注意力. 本节讨论多头注意力的几种结构变体. 训练时注意力的主要开销是序列长度的平方项; 逐 token 生成时, 主要开销变成每一步都要从显存读出全部历史 Key/Value. MQA, GQA, MLA 都在减少每个 token 缓存的 Key/Value 元素数, 同时尽量保住模型质量. Gated Attention 和 AttnRes 不改缓存的份数, 分别改 SDPA 的输出和层与层之间的聚合方式.

FlashAttention, PagedAttention 这类不改公式, 只改计算顺序和显存布局的方法, 见 [2.3 高效与稀疏注意力](../../2.3-注意力的高效实现/2.3-注意力的高效实现.md).

## 1. 本节要回答的问题

- 推理时每生成一个 token, 要读多少字节的 KV Cache, 它和层数 $L$, batch $B$, 序列长度 $T$, 每层每 token 缓存的元素数 $d_{kv}$ 是什么关系.
- 多个 Query 头共享 Key/Value 头 (MQA, GQA) 能省多少缓存, 质量损失多大, 已有 MHA 检查点怎么转换.
- MLA 怎样把 Key/Value 压成一个低秩潜向量, 为什么 RoPE 必须单独拆出一路, 矩阵吸收在 prefill 和 decode 里各自什么时候划算.
- 在 SDPA 输出上加一个逐头 sigmoid 门, 为什么能减轻 attention sink 和激活离群值.
- 把残差连接换成对前面各层输出的注意力 (AttnRes), 改的是哪一维的聚合.

## 2. 缓存规模

每层每 token 缓存的元素数记为 $d_{kv}$, 整个模型的 KV Cache 元素数是

$$
\text{KV Cache} = L \times B \times T \times d_{kv} \tag{1}
$$

设 Query 头数为 $h$, 每头维度为 $d_h$. 各变体的 $d_{kv}$:

| 变体 | 结构改动 | 每层每 token 缓存 $d_{kv}$ | 文章 |
|:----|:--------|:---------|:-----|
| MHA | 每个头独立的 K, V | $2hd_h$ | [01 MHA](./01-MHA-多头注意力的标准形式/01-MHA-多头注意力的标准形式.md) |
| MQA | 所有 Query 头共享一组 K, V | $2d_h$ | [02 MQA 与 GQA](./02-MQA与GQA-共享KeyValue头/02-MQA与GQA-共享KeyValue头.md) |
| GQA | $g$ 组 K, V, 每组被 $h/g$ 个 Query 头共享 | $2gd_h$ | [02 MQA 与 GQA](./02-MQA与GQA-共享KeyValue头/02-MQA与GQA-共享KeyValue头.md) |
| MLA | K, V 压成潜向量 $c^{KV}$, 外加一份共享的 RoPE Key | $d_c + d_h^R$ | [03 MLA](./03-MLA-低秩潜变量与解耦RoPE/03-MLA-低秩潜变量与解耦RoPE.md), [04 MLA 矩阵吸收与工程实现](./04-MLA-矩阵吸收与工程实现/04-MLA-矩阵吸收与工程实现.md) |
| Gated Attention | SDPA 输出逐头乘 sigmoid 门 | 与所用的 MHA/GQA 相同 | [06 Gated Attention](./05-Gated-Attention-SDPA输出门控/05-Gated-Attention-SDPA输出门控.md) |
| AttnRes | 深度维上对前面各层输出做注意力 | 不涉及 token 维 KV | [08 AttnRes](../../2.1-深度学习基础组件/2.1.3-残差连接/04-AttnRes-深度维注意力聚合/04-AttnRes-深度维注意力聚合.md) |

DeepSeek-V2 取 $d_c=4d_h$, $d_h^R=d_h/2$, 每层每 token 缓存 $4.5d_h$ 个元素, 相当于 $g=2.25$ 的 GQA. 具体推导和数字见 03.
