# 2.2 · 基础注意力机制

RNN 按时间步更新一个状态向量, 位置 1 的信息要经过 $T-1$ 次递推才到达位置 $T$, 训练也只能沿时间串行. 自注意力让每个位置直接和所有位置做点积打分, 再对 Value 加权求和: 任意两个位置之间的路径长度是 $O(1)$, 一层的计算是几次大矩阵乘法 ([Vaswani et al., 2017](https://arxiv.org/abs/1706.03762), Table 1). 代价有两处. 一是分数矩阵为 $T\times T$, 计算量随序列长度平方增长; 二是自回归推理时每个历史 token 的 Key 和 Value 都要留在显存里 (KV Cache). 2.2.1 处理单头机制和第一处代价, 2.2.2 处理多头和第二处代价.

## 本节要解决的问题

1. 单头注意力从输入到输出经过哪几步, 每一步的 shape 是什么; 分数为什么要除以 $\sqrt{d_k}$; 因果掩码加在哪里, 为什么并行训练和逐 token 生成得到同样的结果; 没有位置编码时, 自注意力为什么对 token 的排列顺序不敏感.
2. 一层自注意力的 FLOPs 和中间显存从哪里来, 什么时候平方项压过投影项; softmax 在低精度下怎样算才不溢出.
3. 多头注意力怎样把 $d_{model}$ 切成 $H$ 个头; 推理分 Prefill 和 Decode 两段, Decode 每步只有一行 Query, 却要读完全部历史 KV, 瓶颈从算力转到显存带宽; MQA, GQA, MLA 分别从哪一截压缩 KV Cache; 在注意力输出上加门 (Gated Attention) 和沿层深方向做注意力聚合 (AttnRes) 改的是哪一处.

前两组问题在 2.2.1, 第三组在 2.2.2.
