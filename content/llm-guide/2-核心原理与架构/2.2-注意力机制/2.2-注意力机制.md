# 2.2 · 注意力机制

注意力机制是第 2 章其余各节的共同起点. [2.3 注意力的高效实现](../2.3-注意力的高效实现/2.3-注意力的高效实现.md) 不改公式, 只改算法的执行顺序; [2.4 稀疏注意力](../2.4-稀疏注意力/2.4-稀疏注意力.md) 让每个 query 只读一部分 key; [2.5 线性注意力与状态空间模型](../2.5-线性注意力与状态空间模型/2.5-线性注意力与状态空间模型.md) 用固定大小的状态代替随长度增长的缓存; [2.7 长上下文与外推技术](../2.7-长上下文与外推技术/2.7-长上下文与外推技术.md) 处理训练长度之外的位置和推理期的缓存. 这些方法要改的对象, 都在这一节的两篇文章里定义.

两篇的分工按代价划分. 一层自注意力有两笔开销: 打分矩阵是 $T\times T$, 计算和中间显存随序列长度平方增长; 自回归推理时, 每个历史 token 的 Key 和 Value 要留在显存里, 每生成一个 token 都要读一遍. [2.2.1 自注意力机制](./2.2.1-自注意力机制/2.2.1-自注意力机制.md) 讲单头的计算和第一笔开销, [2.2.2 多头注意力变体](./2.2.2-多头注意力变体/2.2.2-多头注意力变体.md) 讲多头和第二笔开销.

## 1. 递推之后的路径长度

### 1.1 三种层的比较

RNN 的第 $t$ 步状态是 $h_t=f(h_{t-1},x_t)$, 位置 1 的信息要经过 $T-1$ 次状态更新才到达位置 $T$, 同一层内的 $T$ 步只能串行. 卷积层一次只看宽度为 $k$ 的窗口, 用空洞卷积要叠 $O(\log_k T)$ 层才能让序列两端连上. 自注意力让每个位置直接和所有位置打分, Vaswani et al. (2017) Table 1 把这几种层放在一起比较 ($n$ 为序列长度, $d$ 为表示维度):

| 层类型 | 每层复杂度 | 串行操作数 | 最大路径长度 |
| :-- | :-- | :-- | :-- |
| Self-Attention | $O(n^2\cdot d)$ | $O(1)$ | $O(1)$ |
| Recurrent | $O(n\cdot d^2)$ | $O(n)$ | $O(n)$ |
| Convolutional | $O(k\cdot n\cdot d^2)$ | $O(1)$ | $O(\log_k n)$ |
| Self-Attention (restricted) | $O(r\cdot n\cdot d)$ | $O(1)$ | $O(n/r)$ |

前三行对应三种主干. 自注意力在串行操作数和路径长度两列都是常数, 代价落在复杂度一列的 $n^2$ 上. 论文 §4 的判断是路径越短, 长程依赖越容易学, 并且 $n<d$ 时自注意力层比循环层还快; 2017 年机器翻译的句子大多满足 $n<d$, 今天动辄数万 token 的上下文早已不满足, 平方项因此成为第 2 章后半部分反复处理的对象.

最终一行只看半径 $r$ 的邻域, 用路径长度换复杂度, 后来的滑动窗口和块稀疏注意力都在这个方向上. 第 2 章的 2.5 节则从循环层一行出发, 把状态做成矩阵, 设法在保留 $O(n)$ 复杂度的同时恢复并行训练. 所以这张表也可以当作第 2 章的地图: 第一行是 2.2 和 2.3, 最终一行是 2.4, 第二行的改造是 2.5.

### 1.2 从对齐模块到主干

注意力早于 Transformer 出现. Bahdanau 等人 (2014) 在 RNN 编码器-解码器的机器翻译模型里, 让解码器每生成一个词就用一个单隐层网络给编码器各隐状态打分, softmax 后加权求和得到上下文向量, 这种打分方式叫加性注意力. 它解决的是「整句源语言压进一个定长向量」的瓶颈, 递推仍然是主干.

Transformer 改了两处. 打分函数换成缩放点积, 因为点积可以直接用高度优化的矩阵乘法实现; 注意力从挂在 RNN 上的对齐模块变成主干, Query, Key, Value 都来自同一个序列, 每层都做, 不再有递推. 「自」指三者同源. Query 来自一个序列, Key 和 Value 来自另一个序列时叫交叉注意力, 编码器-解码器结构里解码器读编码器输出用的就是它; 第 2 章讨论的 decoder-only 模型主干里只有自注意力.

## 2. 一层自注意力与本节记号

### 2.1 公式和共用记号

输入是一层的隐藏状态 $X\in\mathbb{R}^{T\times d_{model}}$, 三个可学习矩阵把它投影成 $Q=XW^Q$, $K=XW^K$, $V=XW^V$. 单头输出为

$$
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V \tag{1}
$$

$M$ 是因果掩码, $j>i$ 处取 $-\infty$, 其余为 0. 两篇文章共用这套记号: $T$ 为序列长度, $d_{model}$ (常简写为 $d$) 为隐藏维, $d_k$, $d_v$ 为单头 Key 和 Value 的维度; 到了多头, $H$ 为 Query 头数, $d_h$ 为每头维度, 标准配置下 $Hd_h=d_{model}$, $N$ 为层数. 2.2.2 再加入 KV 头数 $G$ 和每层每 token 的缓存元素数 $d_{kv}$.

式 (1) 的输出是 Value 的凸组合, 每行权重非负且和为 1. 这一性质决定了几件事: 注意力自己不能产生 Value 张成空间之外的方向, 非线性要靠后面的 FFN 和残差; softmax 在 Value 一侧是线性的, 这也是 2.2.2 第 5 篇 Gated Attention 要在 SDPA 输出后补一个门的原因.

### 2.2 缩放, 掩码与位置

$\sqrt{d_k}$ 的来历是一个方差论证: 假设 $q, k$ 各分量独立, 均值 0, 方差 1, 则 $q\cdot k$ 的方差是 $d_k$. $d_k=128$ 时, 不缩放的两个分数之差标准差为 16, softmax 权重比约 $e^{16}\approx8.9\times10^6$, 几乎是 one-hot, 梯度消失. 2.2.1 第 2 节给出完整推导和饱和时的梯度表, 并说明这个论证只描述初始化附近的分数尺度, 不限制训练后的分数.

因果掩码让第 $i$ 行输出只依赖前 $i$ 个 token, 由此并行训练和逐 token 生成得到相同结果, 历史位置的 $K, V$ 也不会随新 token 改变, 可以缓存. 不加掩码也不加位置信息时, 自注意力对输入顺序是置换等变的, 打乱 token 只会让输出按同样方式打乱 (2.2.1 第 3.3 节). 所以位置信息必须另外注入, 正弦编码和 RoPE 放在 [2.1.4 位置编码](../2.1-深度学习基础组件/2.1.4-位置编码/2.1.4-位置编码.md).

## 3. 两笔代价分到两篇

### 3.1 平方项

按稠密计算, 标准多头配置下 Q, K, V, O 四个投影共 $8Td^2$ FLOPs, 所有头的打分和聚合共 $4T^2d$. 两者在 $T=2d$ 时相等, $d=4096$ 时序列超过 8192 token, 注意力核心的计算就超过四个投影. 显存一侧更紧: 如果把整张注意力矩阵存下来, 128K 长度下单个头单层就是 32 GiB 的 FP16 数据.

2.2.1 第 4 节在这里停下, 讲到数值稳定的 softmax 和它的一遍扫描在线版本为止. 在线 softmax 让注意力可以分块计算, 不必把 $T\times T$ 矩阵写进显存, FlashAttention 系列就建立在这一步上, 归 [2.3](../2.3-注意力的高效实现/2.3-注意力的高效实现.md). 分块之后计算量仍是平方的, 想减少计算量就要少算一部分位置对, 这是 2.4 稀疏注意力的出发点.

### 3.2 缓存项

生成第 $t$ 个 token 时只有一行 Query, 打分和聚合约 $2t(d_k+d_v)$ FLOPs, 却要读出全部 $t$ 行缓存, 每读一个元素只做约 2 次浮点运算, 这一步受显存带宽限制. 乘上头数和层数后, Llama-2-7B 的配置下每 token 缓存 512 KiB, 一条 4096 token 的序列就是 2 GiB, 13 GB 的权重只够放 6 条.

2.2.2 从这个数字出发, 比较 MQA, GQA 和 MLA 各自压缩缓存的哪一截, 以及 MLA 的矩阵吸收在 Prefill 和 Decode 上为什么要选不同的算法. 那一篇的第 5 篇文章 Gated Attention 不碰缓存, 讨论的是注意力输出一侧缺失的非线性, 它和 attention sink 的关系对 2.7 的 KV 保留策略有直接影响.

## 4. 读法与后续章节

### 4.1 按背景选起点

第一次接触注意力的读者按顺序读: 先读 2.2.1 第 1, 2 节的公式和手算例子, 再读第 3 节的掩码与位置, 第 4 节的复杂度可以等到读 2.3 之前再回来看. 前置的线性层, 归一化和残差在 [2.1 深度学习基础组件](../2.1-深度学习基础组件/2.1-深度学习基础组件.md). 熟悉公式, 关心推理部署的读者可以跳过 2.2.1, 直接从 2.2.2 第 1 节的缓存公式读起, 那里的 Llama-2-7B 例子会在 2.2.2 的各篇文章里一直沿用.

准备读 FlashAttention 的读者, 至少要读 2.2.1 第 4.3 和 4.4 节, 在线 softmax 的递推式是 2.3 各篇的公共前提. 准备读 DeepSeek 系列模型的读者, 2.2.2 里 MLA 的两篇和 2.1.4 第 2 篇里解耦 RoPE 的一节要连起来读, 前者讲缓存的结构, 后者讲位置通道为什么必须单独开.

### 4.2 后续章节怎样接上

这一节之后的路线大致按代价分流. 平方项由 2.3 和 2.4 处理, 前者精确计算但调度更省, 后者近似计算只读部分位置. 缓存项有三条路: 2.2.2 的结构改动在训练前就定下每 token 存什么; [2.5.1 线性注意力机制](../2.5-线性注意力与状态空间模型/2.5.1-线性注意力机制/2.5.1-线性注意力机制.md) 用固定大小的状态彻底去掉随长度增长的缓存; 2.7 在训好的模型上做外推, 缓存驱逐和分页.

这几条路可以组合. Qwen3-Next 每 4 层里 3 层线性注意力, 1 层带输出门的 GQA 全注意力; Kimi Linear 用 3 层 KDA 配 1 层 MLA. 读这类混合架构时, 每一层用的是哪种注意力, 缓存怎么算, 都可以回到本节的记号和式 (1) 上对照.
