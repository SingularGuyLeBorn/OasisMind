## 0. 本章目标

GSPO是**阿里巴巴Qwen团队**提出的LLM强化学习算法，解决了GRPO在MoE模型训练中的不稳定问题.

> **GSPO核心思想**: 奖励是序列级的，优化也应该是序列级的.

本章将:

1. 分析GRPO的token级问题
2. 详细推导GSPO的序列级重要性比率
3. 解释为什么GSPO更稳定
4. 展示公式级最小张量实现

---

## 1. 动机: GRPO的隐患

### 1.1 Token级 vs 序列级的不匹配

**GRPO的矛盾**:

| 组件 | 级别 | 说明 |
|------|------|------|
| 奖励 | **序列级** | 整个response一个分数 |
| 优化 | **Token级** | 每个token独立的概率比 |

**问题**: Token级概率比的乘积可能爆炸或坍缩:

$$r^{seq} = \prod_{t=1}^T \frac{\pi_\theta(y_t|y_{<t})}{\pi_{old}(y_t|y_{<t})} = \prod_{t=1}^T r_t$$

当 $T$ 很大(长CoT推理)时:
- 如果多数 $r_t > 1$: $r^{seq}$ 可能爆炸到 $10^{10}$
- 如果多数 $r_t < 1$: $r^{seq}$ 可能坍缩到 $10^{-10}$

### 1.2 MoE训练的特殊问题

Mixture-of-Experts (MoE) 模型在GRPO训练中经常崩溃:

- **原因**: 专家路由的微小变化导致token级概率剧烈波动
- **现象**: 训练loss爆炸，模型崩溃
- **Qwen发现**: 这是token级优化的根本问题

## 2. GSPO的核心创新

### 2.1 序列级重要性比率

**GSPO的关键改变**：对一条回答的 token log-ratio 做 masked mean，再指数化为长度归一的序列比率。

$$\log s_i^{GSPO}=\frac1{|y_i|}\sum_{t=1}^{|y_i|}\log\frac{\pi_\theta(y_{i,t}|x,y_{i,<t})}{\pi_{old}(y_{i,t}|x,y_{i,<t})}$$

等价于:
$$s_i^{GSPO}=\exp\left(\frac1{|y_i|}\sum_t(\ell^{new}_{i,t}-\ell^{old}_{i,t})\right)$$

**与GRPO的对比**:

| 方法 | 公式 | 数值范围 |
|------|------|----------|
| GRPO | 每个 token 使用 $\rho_{i,t}$ | 逐 token 裁剪，不构造乘积 |
| GSPO | $s_i=\exp(\operatorname{mean}_t\log\rho_{i,t})$ | 每条回答一个长度归一比率 |

![Token级 vs 序列级](./images/sequence_vs_token.png)

*图注：左侧是 GRPO 的逐 token surrogate，右侧是 GSPO 的长度归一序列比率与整回答裁剪。示意图不表示 GRPO 会把 token 比率相乘。*

### 2.2 序列级裁剪

GSPO在序列级别应用PPO裁剪:

$$L^{GSPO}=-\mathbb E\left[\min(s_i\hat A_i,\operatorname{clip}(s_i,1-\epsilon_{low},1+\epsilon_{high})\hat A_i)\right]$$

**关键点**:
- 裁剪作用于整个序列的概率比
- 而不是每个token的概率比

### 2.3 序列级奖励对齐

> **Qwen的核心论点**: 奖励的单位应该与优化的单位一致.

| 单位 | 奖励 | 优化 | GSPO |
|------|------|------|------|
| Token级 | ✗ | ✓ (GRPO) | ✗ |
| 序列级 | ✓ | ✓ (GSPO) | ✓ |

## 3. 数学推导

### 3.1 GRPO的问题分析

GRPO 的 surrogate 在每个 token 上使用 $\rho_{i,t}$。GSPO 论文认为，当回答奖励是序列级而离策略修正却发生在单个 next-token 样本上时，token ratio 会带来高方差噪声，并在长回答和 MoE 路由变化下累积。这是 GSPO 的论文论点，不应改写成“GRPO 计算 token ratio 的乘积”。

### 3.2 GSPO的解决方案

**对 masked log-ratio 求平均**：

$$\log s_i^{GSPO}=\frac{\sum_t m_{i,t}(\ell^{new}_{i,t}-\ell^{old}_{i,t})}{\sum_t m_{i,t}}$$

长度归一既降低不同回答长度造成的方差，也让不同长度共享同一量级的 sequence clip。关键区别包括比率定义、裁剪粒度和优化单位，而不仅是数值计算位置。

**GRPO裁剪**：
```python
ratio = exp(new_logp - old_logp.detach())       # [B,T]
token_surrogate = min(ratio * A, clip(ratio) * A)
```

**GSPO裁剪**:
```python
## masked mean，而不是 masked sum
seq_ratio = exp(((new_logp-old_logp.detach()) * mask).sum(-1) / mask.sum(-1))
clipped_seq_ratio = clip(seq_ratio, 1-ε_low, 1+ε_high)
```

### 3.3 数值稳定性分析

若 token log-ratio 的方差为 $\sigma^2$，独立近似下 masked mean 的方差约为 $\sigma^2/|y_i|$。这只是解释长度归一的统计直觉；真实 token 相关性、路由变化和 off-policy 程度仍需实测。裁剪后的 surrogate 使用限定区间，但未裁剪的 $s_i$ 本身不保证有界。

## 4. GSPO完整算法

### 4.1 伪代码

```
算法: GSPO

输入: 策略模型 π_θ, 采样策略快照 π_old, Prompt集合 D, 组大小 G

重复:
  1. 组采样:
     对每个 prompt x ∈ D:
       采样 {y_1, ..., y_G} ~ π_old，并保存回答区间的旧策略 log-prob
       计算奖励 {R_1, ..., R_G}

  2. 计算组优势:
     A_i = (R_i - mean(R_1, ..., R_G)) / (std(R_1, ..., R_G) + eps)

  3. 计算序列级log概率:
     mean_log_ratio_i = Σ_t mask_t·(log π_θ - log π_old) / Σ_t mask_t

  4. 计算序列级比率:
     s_i = exp(mean_log_ratio_i)

  5. 序列级裁剪:
     clipped_s_i = clip(s_i, 1-ε_low, 1+ε_high)

  6. GSPO损失:
     L = -mean(min(s_i · A_i, clipped_s_i · A_i))

  7. 梯度更新:
     θ ← θ - α∇L
```

### 4.2 超参数

| 参数 | 值 | 说明 |
|------|----|----|
| clip_low / clip_high | $3\times10^{-4}$ / $4\times10^{-4}$ | 论文实验设置；不是跨任务默认值 |
| group_size | 需显式记录 | 每个 prompt 的采样数；论文公式用 $G$ 表示，不把某个实现默认值当成跨任务结论 |
| advantage | 组内标准化 | Eq. 6 的默认定义 |

## 5. GSPO vs GRPO vs DAPO

### 5.1 核心差异

| 特性 | GRPO | GSPO | DAPO |
|------|------|------|------|
| 比率级别 | 逐 token | 长度归一序列级 | 逐 token |
| 裁剪方式 | Token级对称 | 序列级对称 | Token级解耦 |
| MoE稳定性 | ✗ | ✓ | 中 |
| 来源 | DeepSeek | Qwen | ByteDance |

### 5.2 公式对比

**GRPO**：每个 token 使用 $\rho_{i,t}=\pi_\theta(y_{i,t}|\cdot)/\pi_{old}(y_{i,t}|\cdot)$。

**GSPO**:
$$s_i^{GSPO}=\exp\left(\frac1{|y_i|}\sum_t\log\frac{\pi_\theta(y_{i,t}|\cdot)}{\pi_{old}(y_{i,t}|\cdot)}\right)$$

两者数学上不等价：GRPO 保留 token ratio，GSPO 构造长度归一的 sequence ratio。

## 6. 本章总结

### 6.1 核心公式

| 组件 | 公式 |
|------|------|
| masked mean log-ratio | $\bar\ell_i=|y_i|^{-1}\sum_t(\ell^{new}_{i,t}-\ell^{old}_{i,t})$ |
| 序列比率 | $s_i=\exp(\bar\ell_i)$ |
| GSPO损失 | $-\min(s_iA_i,\operatorname{clip}(s_i)A_i)$ |

### 6.2 GSPO的贡献

1. **解决MoE不稳定**: 序列级优化避免token级方差爆炸
2. **奖励-优化对齐**: 序列级奖励匹配序列级优化
3. **Qwen3支柱**: 所有Qwen3变体的核心算法
4. **简化基础设施**: 减少精度敏感性
