# GSPO: 从公式到代码的实现指南

> 实现状态：教学骨架；未运行 Qwen3/MoE 训练，只核对论文 Eq. 5–7 的张量语义。

本文档解释 GSPO 如何构造长度归一的序列比率，并与 GRPO 的逐 token surrogate 区分。

---

## 1. 核心差异: Token级 vs 序列级

### 1.1 GRPO (Token级)

**公式**:
$$\rho_{i,t}=\frac{\pi_\theta(y_{i,t}|x,y_{i,<t})}{\pi_{old}(y_{i,t}|x,y_{i,<t})}$$

**代码**:
```python
## GRPO直接使用并裁剪每个token ratio，不构造乘积
per_token_ratio = torch.exp(log_probs - old_log_probs.detach())
token_surrogate = torch.minimum(per_token_ratio * A, clipped_ratio * A)
```

### 1.2 GSPO (序列级)

**公式**:
$$s_i^{GSPO}=\exp\left(\frac1{|y_i|}\sum_t(\ell^{new}_{i,t}-\ell^{old}_{i,t})\right)$$

**代码**:
```python
## 长度归一的序列比率 = exp(masked mean log-ratio)
valid = response_mask.to(log_probs.dtype)  # 只含回答 token
mean_log_ratio = ((log_probs - old_log_probs.detach()) * valid).sum(-1) / valid.sum(-1)
seq_ratio = torch.exp(mean_log_ratio)
```

### 1.3 关键区别

| 步骤 | GRPO | GSPO |
|------|------|------|
| 1. 计算 | token级 ratio | token级 log-ratio |
| 2. 聚合 | 不构造回答级乘积 | masked mean 后指数化 |
| 3. 裁剪 | token级 | 序列级 |

## 2. 序列级log概率计算

### 2.1 公式

$$\bar\ell_i=\frac{\sum_t m_{i,t}(\ell^{new}_{i,t}-\ell^{old}_{i,t})}{\sum_t m_{i,t}}$$

### 2.2 代码

```python
def compute_sequence_log_probs(logits, labels, response_mask):
    # 对齐
    shift_logits = logits[:, :-1, :]
    shift_labels = labels[:, 1:]
    shift_mask = response_mask[:, 1:]

    # Log softmax
    log_probs = F.log_softmax(shift_logits, dim=-1)

    # 提取目标token
    per_token_logp = torch.gather(
        log_probs, dim=2, index=shift_labels.unsqueeze(-1)
    ).squeeze(-1)

    # 单策略平均log-prob；构造ratio时应直接平均new-old差值
    token_count = shift_mask.sum(dim=-1).clamp_min(1)
    seq_log_probs = (per_token_logp * shift_mask).sum(dim=-1) / token_count

    return seq_log_probs
```

## 3. 序列级裁剪

### 3.1 GRPO vs GSPO 裁剪

```python
## GRPO: 每个token的surrogate独立裁剪
token_ratio = torch.exp(log_probs - old_log_probs.detach())
clipped_token_ratio = torch.clamp(token_ratio, 1-eps, 1+eps)
token_surrogate = torch.minimum(token_ratio * A, clipped_token_ratio * A)

## GSPO: 序列级裁剪 (有界)
seq_ratio = torch.exp(masked_mean_log_ratio)
clipped_seq_ratio = torch.clamp(seq_ratio, 1-eps_low, 1+eps_high)
```

## 4. 数值稳定性分析

### 4.1 示例代码

```python
def verify_length_normalization(token_log_ratio):
    """常数token log-ratio不应随回答长度改变GSPO比率。"""
    gspo_ratio = torch.exp(token_log_ratio.mean())
    doubled = torch.exp(token_log_ratio.repeat(2).mean())
    assert torch.allclose(gspo_ratio, doubled)
    return gspo_ratio
```

### 4.2 数学解释

- **GRPO**：使用逐 token $\rho_{i,t}$ 与逐 token surrogate，不构造回答级乘积。
- **GSPO**：$s_i=\exp(\operatorname{mean}_t\log\rho_{i,t})$，整条回答共享一个裁剪决策。
