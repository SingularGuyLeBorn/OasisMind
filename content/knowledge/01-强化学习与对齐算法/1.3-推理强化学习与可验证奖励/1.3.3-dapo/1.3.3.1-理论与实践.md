# DAPO: 从公式到代码的实现指南

> 实现状态：教学骨架；未运行论文规模训练，只核对 Eq. 5–13 的公式与边界。

本文档解释 DAPO 的四项技术如何从数学公式转化为代码实现。

---

## 1. Clip-Higher (解耦裁剪)

### 1.1 公式

**标准PPO**:
$$\text{clip}(r, 1-\epsilon, 1+\epsilon)$$

**DAPO**:
$$\text{clip}^{DAPO}(r, A) = \begin{cases}
\min(r, 1+\epsilon_{high}) & A > 0 \\
\max(r, 1-\epsilon_{low}) & A < 0
\end{cases}$$

### 1.2 代码

```python
def dapo_clip(ratio, advantages, eps_high=0.28, eps_low=0.2):
    clipped = torch.where(
        advantages > 0,
        torch.clamp(ratio, max=1 + eps_high),  # 正优势: 只裁上界
        torch.clamp(ratio, min=1 - eps_low)    # 负优势: 只裁下界
    )
    return clipped
```

### 1.3 对比

| 场景 | PPO | DAPO | 效果 |
|------|-----|------|------|
| A>0, r=1.5 | clip到1.2 | clip到1.28 | 更多探索 |
| A<0, r=0.7 | clip到0.8 | clip到0.8 | 相同约束 |

## 2. Token-Level Loss

### 2.1 公式

**每回答等权（GRPO）**：
$$L_{GRPO}=-\frac1B\sum_i\frac1{|y_i|}\sum_t u_{i,t}$$

**Token级 (DAPO)** :
$$L_{DAPO}=-\frac{1}{\sum_i|y_i|}\sum_i\sum_t u_{i,t}$$

### 2.2 代码

```python
## GRPO和DAPO都保留逐token ratio
per_token_ratio = torch.exp(log_ratio)
surrogate = torch.minimum(per_token_ratio * A, clipped_ratio * A) * mask
grpo_loss = -(surrogate.sum(-1) / mask.sum(-1).clamp_min(1)).mean()

## DAPO改变的是统一token分母
dapo_loss = -surrogate.sum() / mask.sum().clamp_min(1)
```

## 3. Dynamic Sampling

### 3.1 公式 (算法描述)

```
while valid_count < target:
    sample responses
    filter prompts whose within-group rewards are all equal
    add new prompts until the valid batch reaches the fixed target
```

### 3.2 代码

```python
def informative_groups(rewards, group_size):
    rewards_grouped = rewards.view(-1, group_size)
    return rewards_grouped.max(dim=1).values > rewards_grouped.min(dim=1).values
```

## 4. Overlong Reward Shaping

### 4.1 公式

$$R_{length}=\begin{cases}0,&|y|\le L_{max}-L_{cache}\\((L_{max}-L_{cache})-|y|)/L_{cache},&L_{max}-L_{cache}<|y|\le L_{max}\\-1,&|y|>L_{max}\end{cases}$$

### 4.2 代码

```python
def overlong_reward_shaping(rewards, lengths, max_len, cache_len):
    start = max_len - cache_len
    soft = (start - lengths) / cache_len
    length_reward = torch.where(lengths <= start, 0.0,
        torch.where(lengths <= max_len, soft, -1.0))
    return rewards + length_reward
```

## 5. DAPO vs GRPO 代码对比

### 5.1 裁剪

```python
## GRPO: 对称裁剪
clipped = torch.clamp(ratio, 1-eps, 1+eps)

## DAPO: 解耦裁剪
clipped = torch.where(adv > 0,
    torch.clamp(ratio, max=1+eps_high),
    torch.clamp(ratio, min=1-eps_low))
```

### 5.2 损失级别

```python
ratio = torch.exp(log_probs - old_log_probs.detach())
surrogate = torch.minimum(ratio * adv[:, None], clipped * adv[:, None]) * mask
grpo_loss = -(surrogate.sum(-1) / mask.sum(-1).clamp_min(1)).mean()

## DAPO: Token级
dapo_loss = -surrogate.sum() / mask.sum().clamp_min(1)
```

## 6. 关键超参数

| 参数 | DAPO值 | 说明 |
|------|--------|------|
| eps_high | 0.28 | 比标准0.2更宽松 |
| eps_low | 0.2 | 保持标准 |
| valid_batch_size | 固定目标 | 补采样直到获得固定数量的有效 prompt |
| max_len / cache_len | 16384 / 4096 | 论文实验的软惩罚窗口 |

## 7. 代码结构总结

```
DAPO流程                        →  核心函数
──────────────────────────────────────────
采样responses                   →  sample_fn()
过长奖励塑造                    →  overlong_reward_shaping()
过滤组内奖励全同prompts         →  informative_groups()
计算组优势                      →  compute_advantages()
Token级概率比                   →  exp(log_probs - old_log_probs)
解耦裁剪                        →  dapo_clip()
统一token分母损失               →  -Σsurrogate / Σmask
```
