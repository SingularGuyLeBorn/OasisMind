# GMPO:token 重要性比的几何均值策略优化

> 证据状态:arXiv:2507.20673 v3(2025-10-18),已作为 ICLR 2026 conference paper 发表;本页对照论文和作者仓库整理,未独立复现实验.

GMPO(Geometric-Mean Policy Optimization)是 GRPO 的稳定化变体.**GMPO 保留 GRPO 的组相对 advantage,改变的是一条 rollout 内 token-level importance-weighted terms 的聚合方式:从算术平均换成几何平均.**

## 1. 从 GRPO 的 token 聚合开始

对 rollout $o_i$ 的第 $t$ 个 token,重要性比为:

$$
\rho_{i,t}(\theta)=
\frac{\pi_\theta(o_{i,t}\mid q,o_{i,<t})}
{\pi_{\theta_{\mathrm{old}}}(o_{i,t}\mid q,o_{i,<t})}.

$$

GRPO 的未裁剪主项对 token 做算术平均:

$$
\frac1{|o_i|}\sum_t \rho_{i,t}(\theta)\hat A_i.

$$

$\hat A_i$ 仍由同一 prompt 的 rollout 奖励归一化得到.GMPO 不要求奖励为正,也不计算 $\log R_i$.

![GMPO 保留组相对 advantage,只改变同一 rollout 内的 token 聚合](./images/redrawn-gmpo-token-aggregation.png)

> 图 1: 同一 prompt 的 rollout 奖励仍按 GRPO 计算标量 $\hat A_i$.变化发生在 rollout 内部:GRPO 对有效 token 的 $\rho_{i,t}\hat A_i$ 做算术平均;GMPO 对其绝对值做几何平均,再用 $\operatorname{sgn}(\hat A_i)$ 恢复方向.padding 不参与分母或聚合.

**图 1 解析**

- reward group 只负责产生 $\hat A_i$;几何均值不作用于 $r_1,\ldots,r_G$.
- 每个 token 的 $\rho_{i,t}$ 仍由当前策略与 old policy 在同一 token 上的概率比得到.
- 未裁剪时,$\rho_{\mathrm{geo}}=\exp(\operatorname{mean}_t\log\rho_{i,t})$,因此可在 log space 稳定实现.

## 2. GMPO 目标

忽略裁剪时,GMPO 用绝对值的几何均值控制幅度,再用 advantage 符号恢复优化方向:

$$
\left(\prod_{t=1}^{|o_i|}|\rho_{i,t}(\theta)\hat A_i|\right)^{1/|o_i|}
\operatorname{sgn}(\hat A_i).

$$

因为同一 rollout 的 $\hat A_i$ 对所有 token 相同,其梯度权重可以看成:

$$
\left(\prod_t\rho_{i,t}(\theta)\right)^{1/|o_i|}\hat A_i,

$$

即**序列内 token 重要性比的几何均值**.单个极端 $\rho_{i,t}$ 不再独自决定一个 token 的梯度权重.

![GMPO 将逐 token 梯度权重改为序列共享的几何均值比率](./images/redrawn-gmpo-gradient-weights.png)

> 图 2: GRPO 的每个 token gradient 分别乘自己的 $\rho_{i,t}$;GMPO 先将整条序列的 ratio 聚合成 $\rho_{\mathrm{geo}}$,再让所有有效 token gradient 共用这个序列级权重.离群 ratio 仍有影响,但先以 $1/T$ 系数进入 $\operatorname{mean}(\log\rho)$.

**图 2 解析**

- 蓝色 $g_{i,t}=\hat A_i\nabla_\theta\log\pi_\theta(o_{i,t}\mid q,o_{i,<t})$ 表示 token gradient direction;两种方法不改变该方向.
- GRPO 分别形成 $\rho_{i,t}g_{i,t}$;GMPO 分别形成 $\rho_{\mathrm{geo}}g_{i,t}$,随后再求平均.
- 对正 ratio,AM-GM 给出 $\rho_{\mathrm{geo}}\le T^{-1}\sum_t\rho_{i,t}$.图中省略 clipping,只比较基本梯度权重.

完整目标先按 advantage 符号在 token 层做裁剪,再在 log space 求几何均值.作者采用 $\log\rho$ 空间的对称裁剪 $[-0.4,0.4]$,等价于比例范围 $[e^{-0.4},e^{0.4}]$;这个数值属于论文 recipe,不是通用默认.

![GMPO 按 advantage 方向做 token-level clipping 并在 log space 聚合](./images/redrawn-gmpo-logspace-clipping.png)

> 图 3: Algorithm 1 先令 $d_t=\log\rho_t$,$s=\operatorname{sgn}(\hat A)$,在 $u_t=sd_t$ 空间执行相同的 `clamp` 与 `min`;再映射回 $d$ 空间,只对 mask=1 的 token 求均值并指数化,最后得到 $L_i=-\hat A\rho_{\mathrm{geo}}$.

**图 3 解析**

- advantage 的符号先统一“有利方向”,所以正负 $\hat A$ 可以复用同一组 token-level clipping 步骤.
- `old_logp` 停止梯度,padding token 不进入 log-space 平均.
- 论文 $\epsilon=0.4$ 对应 ratio 区间 $[e^{-0.4},e^{0.4}]$;这是实验 recipe,不是 GMPO 的普适常数.
- reward 不进入 `log()`;$\hat A_i$ 仍由 GRPO 的组相对奖励产生.

## 3. 稳定性与实验边界

论文用算术—几何均值不等式说明 GMPO 主项幅度上界更窄,并从梯度形式解释它为何降低极端 token ratio 的影响.实验覆盖数学推理的多种 1.5B/7B/32B 模型和 Geometry3K 多模态设置;作者报告 7B 设置在五个数学基准平均 Pass@1 上比对应 GRPO 高 4.1 个百分点,Geometry3K 高 1.4 个百分点.

这些数字只适用于论文给定模型,数据,rollout,clip 和评测协议.不能据此宣称 GMPO 对所有奖励分布或所有 GRPO 实现都更好.

## 4. 实现状态

本目录的 `implementation.py` 是对论文 Algorithm 1 的最小张量实现,只验证符号,mask,停止梯度和 log-space 聚合;没有复现作者训练系统或论文表格.
