# OREO 复现检查

复现时先固定 token-level MDP：状态是 prompt 加已生成前缀，动作是下一个 token，终局奖励只在结束位置非零。然后逐项核对 reference policy、$\beta$、suffix return $R_t$、value target 的停止梯度、policy Bellman residual、KL regularizer 和 padding/EOS mask。

若采用 step-level 或 response-level 变体，要单独报告动作边界和目标变化。若使用 value-guided tree search，要把训练改进与额外测试时计算分开。当前本地没有可训练实现，不能用隔离归档中的随机 mock 代码做数值验证。
