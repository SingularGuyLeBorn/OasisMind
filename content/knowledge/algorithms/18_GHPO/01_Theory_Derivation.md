# GHPO：基于难度检测与自适应提示的混合策略优化

> 证据状态：arXiv v2，2025-07-16；本文按论文公开版本整理，未独立复现实验。

GHPO 的论文标题是 **GHPO: Adaptive Guidance for Stable and Efficient LLM Reinforcement Learning**，方法全称为 Guided Hybrid Policy Optimization。它不是简单地把一个 SFT loss 与 PPO loss 固定加权，而是针对 RLVR 的“能力—难度不匹配”设计动态课程：能被当前策略探索到正确答案的问题继续在线 RL；一组 rollout 全部失败的问题逐步加入真实解题提示，把分布推向可学习区域。

## 1. 为什么困难样本没有有效梯度

对 prompt $q$ 采样 $G$ 个回答，令可验证奖励为 $r_1,\ldots,r_G$。如果：

$$
r_1=\cdots=r_G=0,
$$

组内相对优势也通常全为零，当前 batch 对这一问题不给策略方向。简单丢弃它会浪费数据；直接提供完整答案又可能让任务过易，弱化探索。

GHPO 把“全部 rollout 奖励为零”作为当前策略下的困难信号。它是一个操作性判据，不等同于题目具有客观固定难度：更换模型、采样温度、rollout 数或奖励器后，判定可能变化。

## 2. 两个核心模块

### 2.1 自动难度检测

在每轮训练中：

- 如果组内存在成功 rollout，保留原问题并做 on-policy RL；
- 如果组内全部失败，将该问题送入提示精炼流程；
- 判定依赖奖励正确性，因此答案提取器、代码执行器或数学验证器的错误会直接污染课程。

### 2.2 多阶段自适应提示精炼

对困难问题，GHPO 从真实解题轨迹中截取一定比例的前缀作为 hint，附加到 prompt。论文先从较小提示比例开始；若模型仍无法成功，再在后续阶段增加提示长度。

可以抽象为：

```text
原问题
  → G 次采样
  → 至少一次成功：原问题上 RL
  → 全部失败：加入部分真值轨迹
      → 再采样
      → 仍失败：增加提示比例
      → 成功：在被引导分布上获得学习信号
```

这让方法在可处理样本上保留探索，在过难样本上使用近似模仿学习的引导。提示比例、阶段数和真值轨迹质量都是重要超参数。

## 3. “Hybrid”具体混合了什么

| 样本状态 | 输入 | 学习模式 | 主要风险 |
|---|---|---|---|
| 当前策略可解 | 原始问题 | 在线 RL 与可验证奖励 | 奖励攻击、探索不足 |
| 当前策略过难 | 问题 + 部分真值提示 | 引导式生成/模仿信号与 RL | 提示泄漏、过度简化、依赖教师轨迹 |

它不是在所有样本上永久使用同一个 `RL loss + λ·SFT loss`。旧稿中的固定混合目标与论文方法不符，已隔离到不公开归档。

## 4. 数据与评测边界

GHPO 使用 ground-truth solution traces，因此要区分：

- 训练时提示来自何处、是否有许可证、是否包含 benchmark 测试答案；
- 验证和测试时是否完全移除提示；
- 改善来自学会推理、记忆教师轨迹，还是训练/测试污染；
- 对没有可靠真值轨迹的任务，方法如何获得提示。

论文作者报告在六个数学 benchmark 上平均约 5% 的性能提升，并强调稳定性与样本效率。该数字属于其模型、数据和协议，不能直接写成 GHPO 的普遍收益。

## 5. 实现与验收清单

1. 难度检测基于每个 prompt 的完整 rollout 组，不能混用跨 prompt 奖励；
2. 记录每个问题的 hint stage，避免无限增加提示；
3. 真值提示只在训练路径使用，评测路径硬隔离；
4. 同时报告原始问题成功率、带提示成功率与最终无提示测试结果；
5. 对奖励器误判、错误解题轨迹和提示过长做故障注入；
6. 比较“丢弃过难样本”“固定提示”“自适应提示”和普通课程学习，证明复杂度有收益。
