# 第3讲: 现代 Transformer 的架构选择

原始 Transformer 给出了可工作的基本结构, 现代 decoder-only 模型却很少原样采用 2017 年的配置. LayerNorm 从残差相加之后移到子层之前, RMSNorm 省去均值中心化, ReLU 或 GeLU 被 SwiGLU 等门控 FFN 替换, 加性位置向量让位于 RoPE, Attention 的 KV 头数也从每个 Query 头独立配置逐步发展出 MQA、GQA 和 MLA. 单项改动看似局部, 实际会同时改变梯度路径、参数分配、内存访问与推理 cache.

[主讲义](./3.1-主讲义/3.1-主讲义.md)用多代模型的配置对照说明哪些选择逐渐形成共识, 也保留了不同模型仍在探索的部分. 本讲的重点不是把某一代模型当成固定答案, 而是建立可比较的坐标: 规范化放在哪里、对哪些分量做统计; FFN 怎样分配投影矩阵和中间维度; 位置信息怎样进入 $QK^T$; Decode 阶段究竟缓存什么. **现代架构的演进主线是让深层训练更稳定, 同时降低每个 token 的访存与状态成本.**

## 1. 先固定 Transformer 块的参照

### 1.1 原始结构与现代结构

原始 Transformer 块包含多头自注意力、FFN、残差连接与 Post-Norm, 并把正弦位置向量加到 token embedding. 现代 decoder-only 模型常改用 Pre-Norm、RMSNorm、RoPE 与 SwiGLU, 线性层通常省略 bias. 这些改动没有改变自回归目标: 每一层仍在 token 位置之间聚合信息, 再由逐位置 FFN 变换通道表示. 变化集中在信息进入子层之前怎样缩放、FFN 怎样选择特征、Attention 怎样表达位置以及推理时怎样保存历史状态.

比较架构时必须统一参数量和训练预算. 门控 FFN 多出一条输入投影, 若仍使用原有中间维度, 参数与 FLOPs 都会增加; MQA、GQA 减少 KV 头数, 主要收益出现在 Decode 的 cache 容量与带宽; Pre-Norm 改变梯度传播, 却不等于所有 Post-Norm 变体都无法训练. 主讲义中不同模型的配置表适合观察组合趋势, 不能把共现直接当作单一组件的因果实验.

### 1.2 稳定性技巧作用于不同位置

训练不稳定可能来自残差流尺度、Attention score 或输出 logits. QK-Norm 在点积之前约束 Query 与 Key 的尺度, 避免 score 过大使 softmax 饱和. Z-loss 对输出层的 log-partition 施加惩罚, 控制 logits 整体漂移. Logit soft-capping 用平滑函数限制极端 logits. 三种方法的干预点不同, 不能互相替换成同一条“稳定训练”开关.

判断一项技巧时应先定位张量. 若问题发生在 $QK^T$ 的 score, 输出层正则不能直接修复 Attention 内部的饱和; 若输出词表 logits 持续增大, QK-Norm 也没有约束输出头. **稳定性方法的名称不如作用位置重要: 先确定哪一个张量失控, 再选择相应约束.**

## 2. 规范化与 FFN

### 2.1 Pre-Norm、Post-Norm 与 RMSNorm

[Normalization Strategies](./3.4-Normalization-Strategies/3.4-Normalization-Strategies.md)比较两个独立维度. 第一个维度是位置: Post-Norm 先执行子层与残差相加, 再规范化; Pre-Norm 先规范化子层输入, 然后把子层输出加回未经过规范化的残差流. Pre-Norm 为跨层梯度保留较直接的恒等路径, 深层训练通常更稳定. [Where to put Norm and why](./3.6-Where-to-put-Norm-and-why/3.6-Where-to-put-Norm-and-why.md)进一步从梯度衰减、爆炸和训练中的梯度尖峰观察这种差异.

第二个维度是规范化算子. LayerNorm 对单个 token 的 hidden 分量执行去均值与方差缩放, 再应用可学习增益和偏置. RMSNorm 只依据均方根缩放并保留增益, 不做中心化. 它减少了一次统计与部分参数, 更重要的是简化低算术强度算子的访存过程. 规范化 FLOPs 占比很小仍可能占用可观运行时间, 因为读取和写回激活比少量标量运算更接近瓶颈.

Pre-Norm 与 RMSNorm 经常同时出现, 但两者解决的问题不同. 前者重排残差与子层的计算顺序, 后者改变单次规范化的统计量. Gemma 2 等结构还在子层输出与残差相加之间增加规范化, 说明架构选择仍取决于深度、初始化与训练配置.

### 2.2 门控 FFN 的参数公平性

[Gated Activations](./3.3-Gated-Activations/3.3-Gated-Activations.md)从标准 FFN 转向 GLU 族. 标准 FFN 用一条上投影、激活函数与下投影; GLU 增加第二条输入投影, 两条分支逐元素相乘后再下投影. SwiGLU 对其中一条分支应用 Swish, GeGLU 则使用 GeLU. 门值随输入变化, 同一组 FFN 参数能够对不同 token 选择不同的通道组合.

多一条投影意味着比较时必须缩小中间维度. 非门控 FFN 常取 $d_{ff}=4d_{model}$; 门控结构若希望维持相近参数量, 中间维度常接近原来的 $2/3$, 因而形成约 $8/3$ 的宽度比例, 实现中还会按硬件友好的倍数取整. 若忽略这一步, “SwiGLU 优于 GeLU”可能混入更多参数和 FLOPs 的影响.

门控带来的表达收益也有代价. 两条输入投影增加中间激活和矩阵乘法, 实际吞吐依赖 kernel 融合与维度取整. 阅读模型配置时应同时记录激活函数、三组权重 shape 与 $d_{ff}$, 不能仅凭“SwiGLU”推断参数规模.

## 3. RoPE 把位置写入 Attention score

### 3.1 相对位置怎样出现

[Rotary Position Embeddings](./3.5-Rotary-Position-Embeddings/3.5-Rotary-Position-Embeddings.md)从目标条件出发: 位置 $m$ 的 Query 与位置 $n$ 的 Key 做点积后, 位置相关部分应由相对差 $m-n$ 决定. RoPE 把 head 维度两两配对, 对每一对分量施加与位置成比例、频率各异的二维旋转. 位置 $m$ 与 $n$ 的旋转矩阵在点积中合成为相对旋转, 因而 score 含有 $m-n$.

RoPE 作用于 Query 和 Key, Value 通常不旋转. 实现会预先生成各位置与频率对应的 cosine、sine, 再把偶数和奇数分量重排组合. shape 通常包含 batch、sequence、head 与 head dimension, cosine 和 sine 必须能沿正确维度广播. 配对顺序或广播轴出错时, 输出 shape 仍然合法, 却不再实现预期旋转.

RoPE 不等于长度外推已经解决. 训练长度之外的位置对应更大的旋转角, 高频分量可能呈现训练中未覆盖的相位模式. 基频选择、位置缩放和长上下文方法会改变外推行为. **RoPE 保证点积具有相对位置结构, 不保证任意长度上的质量保持不变.**

### 3.2 与后续 Attention 压缩的关系

RoPE 位于生成 $Q,K$ 后、计算 score 前. 这个位置在标准 MHA 中直接, 到 MLA 中却会影响矩阵吸收: 依赖 token 位置的旋转矩阵夹在投影之间时, 某些预先合并权重的做法不再成立. 因此理解 RoPE 的算子位置, 是理解 MLA 为何要把带位置的 Key 分量单独保留的前置条件.

在 Prefill 阶段, 所有位置的 RoPE 可以并行应用; Decode 阶段只需为新 token 生成对应位置的旋转量, 历史 Key 已带有各自位置. cache 中保存的到底是旋转前还是旋转后表示, 必须与 Attention 实现一致, 否则重复旋转或遗漏旋转都会改变 score.

## 4. 从 MHA 到 MLA

### 4.1 KV cache 是主要约束

[GQA、MQA 与 MLA](./3.2-GQA-MQA-MLA/3.2-GQA-MQA-MLA.md)用统一符号展开四种 Attention. MHA 为每个 Query 头配置独立 Key 与 Value 头, 能在多个子空间并行匹配, 但每层、每个历史 token 都要缓存全部 KV 头. Decode 每一步只产生一个新 Query, 却要读取所有历史 KV, 此时显存容量和带宽往往比矩阵 FLOPs 更先形成约束.

MQA 让所有 Query 头共享一组 Key 与 Value, KV cache 按头数大幅缩小, 代价是 KV 表达共享更强. GQA 把 Query 头分组, 每组共享一组 KV. 若 KV 组数 $G$ 等于 Query 头数, GQA 退化为 MHA; 若 $G=1$, 则成为 MQA. 这条参数轴便于在模型质量、cache 容量和 Decode 带宽间选择折中点.

### 4.2 MLA 缓存低维潜变量

MLA 不直接缓存完整 Key 与 Value, 而是把 hidden state 下投影成较低维潜变量, 推理时从潜变量恢复或通过矩阵结合直接参与 score 与输出计算. 压缩收益取决于潜变量维度和需要额外保存的 RoPE 分量. 矩阵吸收能把部分上投影并入 Query 或输出侧权重, 避免为每个历史位置显式重建大向量.

MLA 的推导应分别检查 score 路径与 Value 输出路径. score 路径关心 Query 投影、Key 上投影与位置旋转能否交换或合并; Value 路径关心潜变量加权后怎样恢复到输出空间. 缓存的量与临时计算的量也要分开. **MHA、MQA、GQA 和 MLA 的主要差异落在历史 KV 的表示方式, 自注意力的加权聚合目标没有改变.**

## 5. 阅读路线

先读[主讲义](./3.1-主讲义/3.1-主讲义.md), 用模型配置表建立各组件所在位置. 接着阅读[Normalization Strategies](./3.4-Normalization-Strategies/3.4-Normalization-Strategies.md)与[Where to put Norm and why](./3.6-Where-to-put-Norm-and-why/3.6-Where-to-put-Norm-and-why.md), 区分算子类型和残差位置; 再读[Gated Activations](./3.3-Gated-Activations/3.3-Gated-Activations.md), 对照参数量调整中间维度.

Attention 路线先读[RoPE](./3.5-Rotary-Position-Embeddings/3.5-Rotary-Position-Embeddings.md), 确认位置旋转进入 score 的位置, 再进入[GQA、MQA 与 MLA](./3.2-GQA-MQA-MLA/3.2-GQA-MQA-MLA.md), 按 MHA、MQA、GQA、MLA 的次序比较 cache. 时间有限时可先抓住三条依赖: Pre-Norm 管梯度路径, SwiGLU 管 FFN 通道选择, GQA/MLA 管 Decode 历史状态; RoPE 则横跨 Attention 表达与 cache 压缩实现.
