# CSA2 与逐层数据流

CSA2 把注意力分支里的「存什么」与「选哪些行」拆成两个可独立复用的对象. hidden state 仍逐层更新, main Q 仍由当前层输入产生, SWA K/V 仍属于当前层, 正式注意力也仍在当前层执行. 可共享的是 global main KV、由它投影得到的 indexer K, 以及在适当层产生的 Top-K 行号. 这条路线使用统一的行向量约定, 将每次投影和每条缓存边映射到可见矩阵.

## 1. 行向量约定

第 $l$ 层输入写作 $H_l^{in}\in\mathbb{R}^{N\times5120}$. 每一行对应一个 token, 每一列对应 hidden dimension 的一个元素. 图中的最外层大框表示整个矩阵; 大框内部的横向条带表示 token 行向量; 条带内部的小格表示元素 $h_{i,j}$. 维度过大时只显示第 1 行、第 2 行、省略行和第 $N$ 行, 每行只显示前三个元素、省略格与第 5120 个元素.

第一次归一化使用标准函数形式:

$$
X_l=\operatorname{RMSNorm}(H_l^{in};\gamma_{l,1}).
$$

归一化改变元素尺度, 不改变矩阵 shape. $X_l$ 进入 Query、局部 Key 和局部 Value 的独立投影. Query 先压缩到 1280 维, 再展开为 64 个 512 维 head. 局部 Key 与局部 Value 分别通过 `W_l^{K,loc}` 和 `W_l^{V,loc}` 产生, 只保留最近 128 行供 SWA 读取.

## 2. 三种模式只改变全局分支

Full 层完成 global main KV 的生产、indexer K 投影和 Top-K 选择. Encoder 的 Full 层从当前路径指定的 hidden state 生产压缩条目; 与 CED 组合时, decoder 的 Full 层从第 20 层最终 hidden state 获得全局 KV. Full 层随后使用本层 indexer Q 对 indexer K 打分, 选择 512 个位置供 main Q 正式读取.

Reindex 层不产生新的 main KV 和 indexer K. 本层只计算新的 indexer Q, 对共享的 indexer K 重新打分, 再得到本层自己的 Top-512. 由于 decoder 后续 Reindex 层只在第一个 Full 层建立的候选池内搜索, 每次重新选择的范围可以与完整上下文长度解耦. 图中这条边从共享缓存进入当前 attention, 标签写成「共享 KV + 新 Top-512」.

Reuse 层同时读取最近 Full 层的 global main KV / indexer K, 以及最近一次 Full 或 Reindex 得到的 Top-K 行号. 它不运行新的 indexer 选择, 但 main Q 仍由当前层输入产生. 因而 Reuse 层的 attention 权重不会简单复制前层: Query 已经变化, 只是被读取的全局行集合相同.

SWA-only 层不出现全局缓存节点. 第 1、2 层仍然包含 64 个 Query head、局部 K/V、输出投影、两次残差与 MoE. 把 SWA-only 画成一根从输入直达输出的箭头会漏掉绝大多数本层计算, 也无法说明局部缓存如何写入.

## 3. 多头注意力需要画出 head 内部

每个 head 接收自己的 $Q_h$、$K_h$、$V_h$. 当前 Query 与 Key 计算缩放点积, softmax 沿可见位置归一化, 权重再乘 Value 得到 $O_h$. 结构可以写成:

$$
O_h=\operatorname{softmax}\!\left(\frac{Q_hK_h^\top}{\sqrt{d_h}}\right)V_h.
$$

64 个 head 并行执行同一结构. 文章宽度只展示 Head 1、Head 2、省略号和 Head 64, 但每个代表 head 内都保留 `Q/K/V → score → softmax → ×V → O_h`. 最后把 $O_1,\ldots,O_{64}$ 拼接, 再乘输出投影 $W_l^O$ 得到 $O_l$. 省略号只压缩重复的 head 实例, 每个 head 内部的计算阶段保持完整.

非 SWA-only 层的每个 head 同时面对局部与全局来源. 局部部分最多 128 行, 全局部分由 Top-512 行号从 shared main KV 中 gather. 两部分在位置轴上组成该层正式注意力的可见集合. 图用一条从投影节点来的主边和一条从共享缓存来的侧边表达来源, 避免用没有起点的折线模拟拼接.

## 4. Router 与专家内部结构

第二次 RMSNorm 写为:

$$
Y_l=\operatorname{RMSNorm}(H_l';\gamma_{l,2}).
$$

Router 计算 $g=Y_lW_l^R\in\mathbb{R}^{N\times384}$. 每个 token 都得到一个 384 维专家得分行向量. 图显示六个入选位置及其示例分数, 其余 378 个位置折叠为一个省略格. 示例分数只用来展示排序; 实际值随 token 与当前层输入变化.

每个 routed expert 内部继续展开 SwiGLU 结构. 输入一条分支经过 $W^{gate}$ 与 SiLU, 另一条分支经过 $W^{up}$, 两路逐元素相乘后再经过 $W^{down}$. 1 个 shared expert 始终执行, Router 选出的 6 个 routed expert 按得分加权汇合. 因而 MoE 节点同时表达了「从 384 个中选 6 个」和「每个专家内部如何把行向量变换后投回 hidden dimension」.

## 5. 两次残差决定变量名称

注意力输出投影之后, 第一次残差节点接收两条有箭头的边: 一条来自 $O_l$, 另一条直接来自输入 $H_l^{in}$. 节点内部完整写出 $H_l'=H_l^{in}+O_l$. `H_l^{in}` 标签必须放在旁路边上, 不能放在加法节点右侧冒充输出.

MoE 之后的第二次残差同理. 一条边来自 $O_l^{FFN}$, 另一条从第一次残差结果 $H_l'$ 绕过第二次 RMSNorm 和 MoE, 最终得到 $H_l^{out}=H_l'+O_l^{FFN}$. 这两条残差旁路使用完整 smooth-step edge 与闭合箭头, 不再由几个 CSS 线段拼接, 因而不会出现断线或多余线头.
