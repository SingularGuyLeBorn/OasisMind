# 架构与缓存

DeepSeek V4.1-Flash 把长上下文成本拆成几个可以分别处理的对象: hidden state 的逐层计算、全局 main KV 的生成与共享、indexer K 的检索表示、Top-K 行号的选择, 以及每层私有的 SWA K/V. 这些对象都与注意力有关, 但它们的 shape、写入频率和生命周期不同. 只有先把边界划清, 才能判断某个「复用」究竟省了矩阵乘法、显存容量、检索开销, 还是只减少了持久化流量.

## 1. 同一条残差流上的前后两半

语言主干共有 40 层, hidden dimension 为 5120. 第 1–20 层被称为 causal encoder, 第 21–40 层被称为 decoder. token 在 Decode 阶段仍然串行经过全部 40 层, 所以这个命名不能解释成两套彼此分离的网络. CED 的收益主要出现在 Prefill: prompt 的完整 token 矩阵先经过前 20 层, decoder 全局 KV 再由第 20 层输出投影产生. 后 20 层不需要为 prompt 重复执行完整的全局层路径.

一层内部仍保持 pre-norm Transformer 的基本顺序. 输入 $H_l^{in}\in\mathbb{R}^{N\times5120}$ 先经过带增益参数 $\gamma_{l,1}$ 的 RMSNorm, 然后进入注意力子层. 输出投影得到 $O_l$, 第一次残差汇合形成 $H_l'=H_l^{in}+O_l$. 第二次 RMSNorm 产生 MoE 输入, MoE 输出记作 $O_l^{FFN}$, 第二次残差汇合得到 $H_l^{out}=H_l'+O_l^{FFN}$. 两条残差边必须直接连接对应加法节点; 把 `H_l^{in}` 写在第一次加法之后, 或把 `H_l'` 写在第二次加法之后, 都会颠倒变量生命周期.

## 2. 局部 KV 与全局 KV 不是同一份权重

每层都计算本层的 Query 与 SWA K/V. 局部分支读取最近 128 个 token, 因而局部缓存按层独立存在, 长度受窗口限制. `W_l^{K,loc}` 与 `W_l^{V,loc}` 是两个权重矩阵: 前者把归一化 hidden state 投影成 Key, 后者投影成 Value. 图上必须拆成两块. 二者的参数和输出均独立, 并处在注意力的不同计算位置.

全局分支的 main KV 属于 CSA2. 报告用 main KV 表示供正式稀疏注意力读取的缓存条目, indexer K 则是从 main KV 投影得到的轻量检索表示. indexer Q 先对 indexer K 打分, 产生 Top-K 行号; main Q 再根据这些行号读取 main KV 并执行正式注意力. 因而 `main KV → indexer K → Top-K indices` 是三个连续但不同的对象. Top-K 行号能够跨层复用, 不等于对应层共享了 Query 或 attention 输出.

把全局生产矩阵写成 `W^{KV}` 容易造成误解, 因为局部注意力已经有分开的 `W^K` 和 `W^V`. 本库统一添加作用域: `W^{K,loc}`、`W^{V,loc}` 表示本层 SWA 的独立投影; `W^{KV,global}` 表示 Full 路径产生 global main KV 的投影. 名称中的 `KV` 描述缓存表示的职责, 不是把两块局部权重拼成一个参数矩阵.

## 3. 四十层的静态责任分配

第 1、2 层只运行 SWA, 没有全局分支. Encoder 的第 3–20 层按六层一组: 第 3、9、15 层为 Full, 每组其余五层为 Reuse. Full 层生产一组新的 main KV 与 indexer K, 同时运行 indexer 得到 Top-512; 同组后续层直接读取这些对象. Encoder 组内没有额外 Reindex 层, 因而 Top-K 选择也随 Full 层结果一起复用.

Decoder 的第 21–40 层按四层一组. 第 21 层是第一个 Full 层, 它从 causal encoder 的最终 hidden state 获得全局 KV, 对完整可见位置打分, 并为后续层建立候选池. 第 25、29、33、37 层为 Reindex: 它们不重新生成 main KV, 但使用各自的 indexer Q 在共享候选池内重新打分并选择 Top-512. 第 22–24、26–28、30–32、34–36、38–40 层为 Reuse, 同时复用最近可用的全局 KV 与 Top-K 行号.

这套静态分配需要从两个方向阅读. 沿层号向下看, hidden state 始终串行变化, 所以后层 Query 与 Router 得分仍然不同. 沿缓存边看, main KV 的生产深度被显著减少, Top-K 的计算频率也被限制在 Full / Reindex 层. 「层还在」与「该层不再生产一份全局缓存」可以同时成立.

## 4. Prefill、Decode 与缓存生命周期

Prefill 处理整段 prompt, 输入是 $N\times5120$ 矩阵. 矩阵乘法可以批量执行, 但每层仍有明确的数据依赖. CED 减少的是后半段对 prompt 的完整计算, CSA2 减少的是全局缓存的重复生产与重复选择, SWA 则把局部注意力限制在固定窗口. 三项设计作用在不同乘数上, 不应合写成一句「共享 KV 所以 Prefill 更快」.

Decode 每次只加入一个新 token. 新 token 的 hidden row 仍经过 40 层; 每层生成当前 token 的 Query 和局部 K/V, 更新本层滚动窗口. 全局分支依据层型生产、重新选择或读取共享状态. 因为 Query 与 hidden state 每层变化, Reuse 层仍然会执行正式注意力和输出投影. 被跳过的是全局 main KV / indexer K 的生产路径, 以及某些层的 indexer 计算.
