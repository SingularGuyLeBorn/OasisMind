# 结构、记忆与推理

这组论文探索的是:标准的序列到序列之外,**网络还能怎么处理结构化数据**。指针网络处理可变输出集合,关系网络处理对象间关系,图网络处理拓扑结构,Neural Turing Machine 给网络装上外部可读写记忆。这些工作的共同问题是——当输入不是平坦序列却是有内部结构时,归纳偏置应该放在哪里。

这一组研究普通「向量进,向量出」的网络怎样处理位置,集合,对象关系,图结构和外部记忆.六篇围绕结构化计算给出互补方案.

## 输出空间可以指向输入

普通分类器的 softmax 维度固定,seq2seq 解码器通常也从固定词表中选 token.组合优化任务的输出却常是输入元素的排列,输入长度变化时,合法类别数也随之变化.Pointer Networks 直接把 attention 分数当作输出分布,第 $i$ 步在 $n$ 个输入位置中选择一个.输出词表由当前输入动态生成,模型由此能处理凸包,旅行商和排序等问题.

指针解决的是「输出引用谁」.它没有自动保证排列合法,也没有给组合优化提供最优性证明.训练依赖监督解序列,解码时还要用 mask 禁止重复选择.长度外推结果显示网络学到部分算法结构,准确率仍会随未见规模增长而下降.因此指针是一种输出参数化,不是通用求解器.

### 集合输入需要处理置换

集合的语义与输入排列无关,但 RNN 编码器按顺序更新状态,不同排列会产生不同表示.Order Matters 先用实验说明这种差异足以影响结果,再提出 Read-Process-Write:Read 阶段用注意力从集合元素中读取,Process 阶段让内部状态多次更新,Write 阶段生成输出.按内容寻址允许模型在每一步重新访问全部元素,减弱任意输入顺序的影响.

严格的置换不变性需要函数对所有排列给出相同结果.注意力读取在没有位置特征且聚合方式对称时可以满足这一点,具体实现仍要检查初始状态,mask 和归一化是否引入顺序.这与后来 Deep Sets 的对称聚合定理形成对照:一个强调可学习迭代读取,另一个给出置换不变函数的结构形式.

### 关系计算放在什么对象之间

Relation Networks 先把场景表示为对象集合,再对每对对象应用共享函数 $g_\theta(o_i,o_j,q)$,求和后交给 $f_\phi$.共享的关系函数让同一规则作用于所有对象对,代价是对象数为 $n$ 时通常需要 $O(n^2)$ 次配对.在 CLEVR 中,这种归纳偏置显著改善计数和属性比较,说明当时通用 CNN+LSTM 流水线缺少显式关系计算.

Relational RNN 把相同思想放进时间状态.记忆由多个 slot 组成,slot 之间用多头注意力交互,再通过门控与新输入融合.它结合了对象化记忆和循环更新,适合需要跨时间维护关系的任务.固定 slot 数限制容量,全连接 slot 注意力也带来平方计算;它解决的是状态内部怎样交互,没有消除长期信息选择问题.

### 图网络把关系限制在边上

Message Passing Neural Network 用消息函数,更新函数和读出函数统一多种图神经网络.节点 $v$ 在第 $t$ 轮聚合邻居消息

$$m_v^{t+1}=\sum_{w\in N(v)}M_t(h_v^t,h_w^t,e_{vw}),\qquad
h_v^{t+1}=U_t(h_v^t,m_v^{t+1}).$$

共享函数带来对节点编号的等变性,最终对称 readout 产生图级不变量.关系网络枚举全部对象对,MPNN 则只沿已知图边传播,计算量随边数增长.多轮消息传递扩大感受范围,也可能出现过平滑,过压缩和无法区分某些图结构等限制.

## 外部记忆把状态变成可寻址矩阵

Neural Turing Machine 把记忆写成 $N\times M$ 矩阵,控制器产生读取和写入权重.内容寻址按相似度查找,位置移位允许沿地址移动,erase 与 add 向量完成可微写入.读写权重是连续分布,整个系统可以用梯度下降训练.复制,排序和关联回忆实验检验模型能否学到跨长度复用的内部过程.

可微寻址的代价是每一步通常扫描全部记忆位置,训练也容易受到模糊权重和长程信用分配影响.NTM 展示了神经网络可以学习读写程序,后续 DNC,Memory Networks 和注意力系统分别保留了其中不同部分.

六篇材料可以按四个问题比较:输出域是否固定,输入是否有顺序,关系由全配对还是给定边定义,状态能否被显式寻址.所谓「结构化推理」最终要落实到张量和对称性:哪些元素共享参数,哪些排列应保持结果不变,一次更新能传播多远,复杂度随对象数怎样增长.

### 不变性与等变性要分开

集合分类希望输入元素重排后输出不变,这是 permutation invariance.节点分类则希望输入节点重排后,输出节点按相同方式重排,这是 permutation equivariance.对称求和 readout 可以产生不变量,逐节点共享更新通常保持等变性.Pointer Network 输出的是输入索引序列,重排输入后正确索引也应随之变化,它需要的是更细致的等变关系.

以三个对象 $o_1,o_2,o_3$ 为例,RN 对九个有序对应用同一个 $g$.交换 $o_1,o_2$ 只会重新排列求和项,总和不变.若改用拼接后直接送入普通 MLP,每个槽位有独立含义,交换输入就会改变结果.这种手算比「模型懂集合」更准确:不变性来自共享函数与对称聚合,不是从数据中自动长出的保证.

### 复杂度和表达力一起看

RN 的全配对为 $O(n^2)$,稠密 self-attention 也是 $O(n^2)$;MPNN 若图稀疏,每轮约为 $O(|E|)$,但距离为 $d$ 的节点至少需要 $d$ 轮才能交换信息.NTM 单步内容寻址扫描 $N$ 个槽位,序列长 $T$ 时约为 $O(TN)$.这些量只描述主要交互次数,实际成本还取决于向量宽度,批处理和内存访问.

减少连接会限制一次更新可访问的信息,增加轮数又会加深优化路径.结构先验的作用正在于选择哪些交互值得直接计算.已知分子键时沿图边传消息很自然;视觉场景中的对象关系未知,全配对可以减少漏边,代价是更多计算.没有一种连接图在所有任务上同时最省且最强.

### 记忆容量与访问方式

单向量状态把内容混在固定通道中,slot memory 把对象分行存放,外部矩阵再增加显式地址.容量逐步更清楚,读写控制也更复杂.可微软寻址在训练中提供平滑梯度,却可能把多个位置混成模糊平均;尖锐寻址更接近离散指针,梯度和探索又更困难.

评测记忆系统时应把存储,寻址和推理拆开.复制任务主要检验写入与顺序读取,关联回忆检验内容寻址,图任务检验局部组合,关系问答还需要多对象计算.一个模型在某类任务上成功,不能直接证明它获得通用算法能力.长度外推,扰动对象顺序和改变图规模能进一步检查学到的是规则还是训练范围内的模式.
