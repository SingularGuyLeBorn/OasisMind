# Attention 与 Transformer

2015 年 Bahdanau 给 seq2seq 加了软对齐机制,让解码器在每一步自己选择看编码器的哪些位置。2017 年 Vaswani 去掉 RNN,只留 Attention,写出了**「Attention Is All You Need」**——可能是过去十年引用最高的论文。这篇论文不只提出了一种新架构,它改变了整个领域的计算范式:从串行递推转向并行矩阵乘。本组从 Bahdanau 到原始 Transformer,再到 Harvard NLP 的 Annotated Transformer 代码实现,覆盖概念、论文和工程三层。

本站按概念依赖排列:先读 Bahdanau 注意力,再读 Transformer,最终用 Annotated Transformer 对照实现.

## 动态对齐先解决了固定向量瓶颈

早期神经机器翻译用编码器 RNN 把整句源文本压缩成一个向量,解码器只凭这个向量逐词生成.句子增长以后,开头和局部对应关系都要挤进固定维度状态.Bahdanau Attention 保留每个源位置的双向编码状态 $h_j$,解码第 $i$ 个词时计算

$$e_{ij}=v_a^T\tanh(W_as_{i-1}+U_ah_j),\qquad
\alpha_{ij}=\frac{\exp e_{ij}}{\sum_k\exp e_{ik}}.$$

上下文 $c_i=\sum_j\alpha_{ij}h_j$ 随输出位置变化.模型因此能在生成每个词时重新选择源句信息,对齐也成为可视化的中间量.这里的 attention 是解码器对编码器状态的跨序列读取,仍然依赖循环编码器和循环解码器.

这个机制交换了存储与计算.编码器要保存全部位置状态,每个解码步还要扫描源长度,单句对齐计算约为 $T_xT_y$.在 2014 年翻译句长下可接受,长上下文中会成为明显成本.注意力权重还只是模型行为的一个切面,不能自动等同于因果解释;改变权重而保持输出的情况并不少见.

### 自注意力把读取扩展到同一序列内部

Transformer 让每个位置分别产生 query,key,value.Query 与所有 key 的点积决定读取权重,再对 value 加权求和:

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V.$$

缩放项 $\sqrt{d_k}$ 控制点积方差,避免维度增加后 softmax 过早饱和.多头注意力使用多组投影,允许不同子空间形成不同的匹配与搬运模式.位置前馈网络逐 token 变换通道,残差连接和 LayerNorm 负责层间传播.位置编码补回纯集合运算缺少的顺序信息.

编码器 self-attention 可以读取整段输入;解码器用 causal mask 屏蔽未来位置,再通过 cross-attention 读取编码器输出.训练时目标序列整体右移后并行计算所有位置,mask 保证第 $i$ 个位置只依赖此前 token.推理仍要逐 token 生成,KV cache 只是复用历史 key 和 value,没有消除自回归依赖.

### 并行优势与平方代价同时出现

RNN 的单层计算量大致随序列长度线性增长,但关键路径包含 $n$ 个串行步骤.全注意力把主要运算写成矩阵乘,训练关键路径缩短,更适合 GPU/TPU.代价是 $n\times n$ 注意力矩阵:序列加倍时,分数计算和中间激活约增至四倍.因此「训练并行」与「长序列昂贵」来自同一设计,不能只讲其中一边.

原论文在 WMT14 英德和英法翻译上比较质量,训练成本与当时的卷积和循环系统,还展示了句法分析迁移.这些结果证明特定规模的纯注意力架构可行,并未穷尽后来语言模型的训练配方.GPT 的 decoder-only 布局,pre-norm,RoPE,KV cache 和大规模预训练都属于后续发展.

### 从论文图到可运行代码

Annotated Transformer 的价值在细节.它展示张量怎样从 `[batch,length,d_model]` 拆成多头形状,mask 怎样广播,`transpose` 后为什么需要 `contiguous`,标签平滑如何构造目标分布,Noam 学习率怎样随 warmup 和步数变化.这些细节决定公式能否稳定运行.

实现与 2017 年论文也并非逐字一致.注释版代码采用 pre-norm 风格,而原论文图示是 post-norm;示例解码每生成一个 token 都重跑当前前缀,没有现代 KV cache;torchtext 的分桶策略属于数据管线优化.阅读时应分别标记论文结构,博客实现选择和今天常用做法,避免把后来形成的默认配置倒写成原论文结论.

三篇材料连成一条清楚的机制线:动态对齐让解码器按需读取源位置,self-attention 让任意位置直接交互,工程实现再把公式落实成 shape,mask,优化器和批处理.读完后,看到新的注意力变体时可以沿四项比较:谁产生 query,可读取哪些 key,value 保存什么,读取代价怎样随长度变化.

## 手算一行注意力

设一个 query 与三个 key 的缩放点积分数为 $(1,0,-1)$.softmax 后权重约为 $(0.665,0.245,0.090)$.若对应 value 是标量 $(2,4,10)$,输出为 $0.665\times2+0.245\times4+0.090\times10\approx3.21$.注意力先用 query-key 决定读取比例,再搬运 value;分数与内容是两套投影,不能把较高权重直接解释成输出中保留了完整的 key 信息.

加入 causal mask 时,被屏蔽位置的分数在 softmax 前设为负无穷,其概率变为 0.数值实现常使用数据类型可表示的极小值,还要避免某一整行全部被 mask 后产生 NaN.padding mask 与 causal mask 负责不同约束:前者排除补齐位置,后者排除未来位置,两者的广播 shape 必须分别检查.

### 归一化位置为何影响深层训练

post-norm 形式先做子层与残差相加,再 LayerNorm;pre-norm 先归一化输入,子层输出再加回残差.二者计算同一类子层,梯度路径却不同.pre-norm 的残差主干保留更直接的恒等通道,深层训练通常更稳定;post-norm 在某些设置下可能得到不同的最终表示尺度.所谓「Transformer 原版」需要连同 norm 位置一起说明.

Annotated Transformer 的代码选择 pre-norm,正好适合提醒读者:可运行讲义可能有意调整论文细节.验证实现时,先为每个子层写出输入输出 shape,再测试 mask,残差和 norm 的顺序,最终用很小的复制任务确认损失能下降.能跑通不表示复现论文数字,但能排除许多结构误读.

### 阅读现代变体的统一坐标

MQA/GQA 改变 key/value 头的共享关系,FlashAttention 改变计算与显存调度而不改变精确数学结果,稀疏注意力限制可读取位置,线性注意力重排或近似核计算,位置编码改变分数中的位置信息.把这些方法都写回 $QK^T$ 与 $V$ 的数据流,便能看出它改的是表示,连接图,近似误差还是 kernel.名称中的「attention」相同,工程收益和表达约束可能完全不同.

评测也要分训练与推理.训练关注整段序列吞吐,激活显存和反向计算;prefill 关注一次处理长提示的矩阵效率;decode 每步只有少量 query,常受 KV cache 读取带宽限制.同一个注意力变体在三阶段的收益可能完全不同,所以复杂度公式要配合实际 shape 和硬件测量.

对照三篇材料时,可以固定一句短翻译手算 Bahdanau 对齐,再用四个 token 手算 causal self-attention,最终在代码中打印 mask 与多头张量形状.概念,公式和实现三次得到一致结果,才算真正掌握这一条路线.

还要核对位置与内容的分工:没有位置编码的 self-attention 对输入排列保持等变,无法仅凭内容区分相同 token 的先后;加入绝对或相对位置信号后,分数才携带顺序.位置方案变化会影响长度外推,但不会替代 causal mask 的可见性约束.
