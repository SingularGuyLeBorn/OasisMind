# CNN 与视觉基础

从 AlexNet 到 ResNet,这条线建立了**层次特征学习**的基本范式。AlexNet 2012 年把 ImageNet top-5 error 从 26% 降到 16%,证明了 GPU + 大数据 + 深层卷积的组合可行性。ResNet 2015 年用残差连接让 152 层网络可训练,把「深度」从工程瓶颈变成了可调超参数。空洞卷积和 CS231n 则分别解决感受野扩展和系统教学的问题。

这一组解释深度卷积网络如何从可训练的工程系统,演化为更深,更稳定且感受野可控的视觉骨架.

## 局部连接如何变成层次表示

图像包含强烈的空间先验:相邻像素更可能组成局部边缘,同一种模式可以出现在不同位置.卷积用局部感受野和权重共享表达这两点.若输入为 $H\times W\times C_{in}$,卷积核为 $K\times K$,输出通道为 $C_{out}$,参数量是 $K^2C_{in}C_{out}$,与图像面积无关.同尺寸的全连接层则会让参数量随 $HW$ 快速增长.卷积省下参数以后,网络才能把多层局部变换叠成从边缘到纹理,再到部件和对象的层次表示.

AlexNet 的贡献来自一组彼此配合的选择:ImageNet 提供百万级标注数据,两块 GPU 承担大规模卷积,ReLU 缓解饱和激活造成的慢训练,dropout 与数据增强抑制过拟合.单独拿出任何一项都不是完整解释.它证明的是:在给定数据和计算条件下,端到端学习的深层视觉表示能够显著超过当时的手工特征流水线.结果同时暴露了显存,训练时间和模型容量之间的约束,后续网络的很多改动都在处理这些工程问题.

### 深度增加为何先遇到优化退化

更深网络理论上包含浅网络的函数类:在已有网络后面加恒等层,至少应复制原有解.实际训练中,普通 56 层网络的训练误差却可能高于 20 层网络.这叫 degradation problem,与测试集上的过拟合不同.残差块把目标映射 $H(x)$ 改写为 $F(x)+x$,让新增层可以通过 $F(x)=0$ 表示恒等映射.捷径连接同时给前向信号和反向梯度提供加法路径,深层优化因此更容易.

Identity Mappings 继续追问捷径两端还应放什么.若 shortcut 上有缩放,门控或投影,连续单元之间的直接路径会累积乘法因子;若加法之后立刻经过 ReLU,负信号会被截断.预激活单元把 BN 和 ReLU 移到权重层之前,使加法后的主干更接近恒等映射.这一结论有明确范围:尺寸变化的单元仍要投影,收益也会随深度和任务变化.它提供的是信息传播与消融证据,不是所有网络都必须照抄的固定模板.

### 感受野和分辨率的交换

分类网络常用 stride 或 pooling 扩大感受野,代价是降低空间分辨率.语义分割需要逐像素输出,过早下采样会丢掉边界信息.空洞卷积在卷积核采样点之间插入间隔,不增加参数就扩大有效感受野.对一维长度为 $k$ 的核,膨胀率 $r$ 对应有效宽度 $k+(k-1)(r-1)$.连续使用指数增长的膨胀率可以快速覆盖大范围上下文,同时保留特征图尺寸.

这项交换也有成本.高分辨率特征图增加激活显存和计算量;固定膨胀模式可能产生栅格效应;理论感受野覆盖全图也不表示每个位置获得同等有效贡献.论文中的 context module 展示了当时的可行方案,后来分割系统又加入多尺度池化,可变形卷积和注意力来补充它.

### 从公式到实现

CS231n 把这些架构放回训练闭环.卷积输出尺寸,参数量和显存都可以在运行前手算;反向传播用局部导数与链式法则组合;数值梯度只负责校验小规模实现;学习率,初始化和正则化共同决定优化轨迹.课程要求用 NumPy 写 forward 和 backward,目的是让张量形状,缓存值和梯度累加变得可见.

五项材料分别覆盖数据与算力,深度优化,残差单元内部结构,稠密预测感受野和训练方法.读完后应能沿三条轴比较视觉架构:参数怎样共享,信息怎样跨层传播,空间分辨率怎样变化.现代视觉 Transformer 更换了 token 混合算子,但 patch 表示,层次特征,残差路径与训练稳定性仍然沿用这些问题坐标.

## 用一张 224×224 图做形状检查

设输入为 `224×224×3`,第一层使用 64 个 `7×7` 卷积核,stride 为 2,padding 为 3.输出宽高为 $\lfloor(224-7+2\times3)/2\rfloor+1=112$,输出形状 `112×112×64`,参数量为 $7\times7\times3\times64$ 加偏置.若随后使用 `3×3,stride=2` 的池化,空间尺寸继续降到 56.每次下采样扩大后续单元在原图上的有效步幅,也让边界位置更难精确恢复.

残差块若保持 `56×56×64`,shortcut 可以直接使用 $x$.若主分支把通道升到 128 且 stride 为 2,输出变成 `28×28×128`,shortcut 就必须投影或补维.这正是 identity 推导的边界:大多数同尺寸单元有纯加法通道,少数阶段切换单元需要改变形状.手算形状可以避免把「残差连接」误解成任何两个张量都能直接相加.

### 评测时拆开三类收益

架构论文常同时改变深度,宽度,输入分辨率,增强和训练时长.比较结果前先找参数量与 FLOPs,再找训练配置,最终看单模型还是集成,单裁剪还是多裁剪.AlexNet 的 ImageNet 结果与 ResNet 的结果跨越数年,数据增强和测试协议已经变化,不能只把 top-5 数字排成单一架构排名.

机制消融提供更窄但更可靠的证据.相同深度下去掉 shortcut,相同参数下更换激活位置,相同前端下加入 context module,这些比较更接近回答具体因果问题.读者应把「该配置在该实验中更好」与「该机制普遍必要」分开,再看后续工作能否在不同任务和规模上复现.

### 与大模型架构的连接

卷积网络留下的不仅是视觉模块.残差路径成为 Transformer 的层间主干,pre-activation 的分析与后来 pre-norm 的稳定性讨论相呼应,数据并行和 GPU kernel 经验也进入更大模型训练.但类比必须落到公式:ResNet 的空间卷积与 self-attention 的 token 混合不同,BN 的 batch 统计与 LayerNorm 的逐样本统计也不同.保留共同的优化问题,同时写清算子与归一化轴,才能避免用历史相似性替代机制分析.

读完整组后可以做一次闭环检查:给定输入尺寸和卷积配置,算出每层 shape,参数和感受野;给定残差块,指出 shortcut 是否需要投影;给定分割任务,说明下采样节省了什么又损失了什么.这些量都能落到数字,也正是视觉架构阅读中最可靠的共同语言.

同样的检查还能揭示实现错误:padding 少一格会改变残差两支的尺寸,通道数错位会让加法无法执行,测试裁剪口径不同会让准确率失去可比性.公式,代码和实验表必须使用同一组形状与口径.
