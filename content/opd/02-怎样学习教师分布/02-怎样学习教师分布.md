# 怎样学习教师给出的概率分布

学生已经生成了一条轨迹, 教师也能读取其中每个前缀, 接下来仍有一个很大的空白: 教师究竟返回什么, 训练器又怎样把它变成梯度? 完整 logits、top-$k$ 概率、采样 token 的 log-prob、整段文本评价和最终成败, 都可以被叫作「教师反馈」, 但它们携带的信息量、需要的接口和允许使用的目标函数完全不同. **OPD 是一种数据分布安排, 不是某个固定的 KL 损失.** 学生轨迹只确定监督落在哪里, 并不自动决定监督采用什么粒度.

设学生在状态 $s_t=(x,y_{<t})$ 上的分布为 $q_\theta(\cdot\mid s_t)$, 教师分布为 $p_T(\cdot\mid s_t)$. 白盒条件下, 训练器能读取两边整个词表上的概率, 因而可以直接计算 $D(p_T\|q_\theta)$; 接口只返回已采 token 的两个 log-prob 时, 训练器看到的是分布在一个动作上的投影; 教师只返回文本时, 还要经过偏好建模、结果验证或另一个评分器, 才能进入更新. 从完整分布到标量结果, 信号越来越便宜, 同时也越来越依赖估计与信用分配.

## 1. 本章只处理可读取概率的教师

训练器能够读取教师 logits 或指定 token 的 log-prob 时, 才能直接讨论「怎样学习教师分布」. [外部教师](2.1-外部教师/2.1-外部教师.md) 路线在统一记号下比较 GKD、MiniLLM 与 DistiLLM: 它们都能查询教师概率, 差别在前缀由谁生成、比较哪一种散度, 以及采样分布对参数的依赖是否进入梯度.

接口仍有三个层次. Full-vocab 保留整个动作分布;top-$k$ 保留高概率候选和经过约定处理的尾部质量;sampled-token 只读取学生实际动作上的教师概率. 三者都属于白盒访问, 携带的反事实信息却逐级减少. 具体估计器和压缩误差放在[教师反馈怎样变成梯度](../03-反馈怎样变成梯度/03-反馈怎样变成梯度.md), 本章集中回答散度目标与状态来源怎样组合.

教师只返回文本、批评或偏好时, 训练器无法计算这里的词表散度. 它需要先把输出转成示范、偏好对或奖励, 属于第三章的 black-box 信号转换. 环境只返回结果时, 主要问题变成信用分配与探索, 进入[CoT 蒸馏与 RL](../05-CoT蒸馏与RL.md). 同一模型借助参考解、反馈或成功轨迹形成特权教师, 则进入[同一个模型怎样教自己](../04-同一个模型怎样教自己/04-同一个模型怎样教自己.md). 这些路线会再次用到本章的散度, 但不会混进外部白盒教师的目录.

## 2. 散度方向改变了怎样的学习压力

Forward KL

$$
D_{\mathrm{KL}}(p_T\|q_\theta)=\sum_a p_T(a\mid s)\log\frac{p_T(a\mid s)}{q_\theta(a\mid s)}
$$

要求学生覆盖教师认为可能的动作. 教师分布有多个可行模式时, 它会推动学生为这些模式都保留概率. 学生容量不足或教师长尾噪声较多时, 这种覆盖会把有限概率质量摊得过散. Reverse KL

$$
D_{\mathrm{KL}}(q_\theta\|p_T)=\mathbb E_{a\sim q_\theta}\left[\log q_\theta(a\mid s)-\log p_T(a\mid s)\right]
$$

把期望放在学生分布上, 更强调学生已经会访问的动作. 它倾向集中到教师支持的少数模式, 却也可能忽略学生尚未覆盖的正确路径. **KL 方向控制局部动作分布的几何, on-policy 控制状态来自哪里;二者没有互相推出的关系.**

JSD、skew KL 与其他 $f$-divergence 位于两端之间. 它们有的限制极端概率比, 有的通过混合分布改善支持集不重合时的数值行为. 选择它们时不能只看名称, 还要检查求和是否覆盖完整词表、采样动作是否 stop-gradient、token mask 与归一化怎样写. 同一个公式在 full-vocab 与 sampled-token 实现中可能对应完全不同的估计器.

## 3. 完整词表、top-k 与采样动作

完整词表损失保留教师对候选动作的相对排序, 代价约随 $B\times T\times |V|$ 增长. 教师和学生若在不同设备组上, logits 的跨机传输往往比公式本身更棘手. Top-$k$ 只传高概率候选和尾部质量, 能显著降低存储与通信, 但截断后的重归一化会改变梯度:尾部被当成一个桶、均匀摊回去、直接丢弃, 三种实现学到的分布都不一样.

只保留已采 token 的 log-prob 时, 每个位置只观察一个动作. 训练器可以把教师与学生的 log-ratio 当作稠密奖励, 再用即时项、return-to-go 或带 baseline 的策略梯度估计. 这里有两个容易混淆的问题. **时间信用分配决定一处反馈影响轨迹中的哪些动作;词表概率路由决定压低当前动作后, 概率质量流向哪些候选.** 只算已采 token 能回答前一个问题的一部分, 无法恢复教师在其余词表上的偏好.

因此, sampled-token 方案节约的不是「无损压缩」. 它用更低带宽换来更高方差与更弱的反事实信息. 若任务动作空间很窄、学生与教师已经接近, 这个交换可能很值;若教师优势主要体现在学生尚未采到的替代步骤, 单 token 投影会把最重要的方向丢掉.

## 4. 白盒家族怎样演进

[GKD](2.1-外部教师/2.1.1-GKD.md) 把轨迹来源和散度选择拆开, 允许固定数据与学生样本混合, 也允许 forward KL、reverse KL 或广义 JSD. 它奠定了现代 OPD 最清楚的实验坐标:先问状态由谁产生, 再问同一状态上怎样比较分布.

[MiniLLM](2.1-外部教师/2.1.2-MiniLLM.md) 从序列级 reverse KL 展开策略梯度, 把教师 log-prob 解释为隐式奖励的一部分, 并处理长度、方差与教师混合采样. 它提醒读者, 「逐位置都能计算 log-ratio」不代表目标天然是局部可微的 token KL;序列采样对参数的依赖会带来额外梯度项.

[DistiLLM 与 DistiLLM-2](2.1-外部教师/2.1.3-DistiLLM.md) 沿稳定性和数据复用继续推进. Skew divergence 缓和支持集与极端概率比问题;自适应 off-policy 样本减少每步 rollout;双路对比目标分别处理教师样本与学生样本. 这些方法也说明「严格 on-policy」不是唯一可用点, 真实训练常在新鲜度和吞吐之间选择 near-policy 区域.

## 5. 选择目标之前先验证信息链

教师在独立答题上更强, 仍可能无法解释学生已经走偏的前缀. 最小验证应从学生轨迹中截取正确、可恢复错误与彻底崩坏三类状态, 比较教师优势、熵、top-token 重合率以及正确动作的 margin. 如果教师在错误前缀上同样混乱, 更精细的散度只会精确拟合坏目标.

随后检查词表与模板. Token-level 分布匹配要求动作空间可比较;tokenizer 不同、特殊 token 位置不一致、chat template 多一段系统前缀, 都会让逐位置 KL 失去语义. 可以退回字符或字节对齐, 也可以改用序列级反馈, 但不能把不同词表的第 $i$ 个 logit 直接相减.

完成前两项验证后再选择散度和压缩接口. 记录教师熵、师生 KL、有效 token 数、top-$k$ 尾质量、EOS 概率与回答长度, 并同时看任务指标. KL 下降只能证明学生更像教师;若任务分数不涨, 可能是教师没有增量、估计器把方向压扁, 也可能是模型只学会缩短回答. **分布损失是机制变量, 任务能力才是最终因变量.**
