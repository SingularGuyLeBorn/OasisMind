# MiniLLM: 序列 reverse KL 与策略梯度

MiniLLM 直接最小化学生序列分布到教师序列分布的 reverse KL. 学生既是被优化的分布, 也是轨迹采样分布. 对完整序列目标求导时, 除了固定轨迹上的 token 损失, 还要计算采样概率随参数变化的项. 由此产生的 reward-to-go、方差和长度偏置, 构成 MiniLLM 与 GKD stop-gradient 训练器的主要区别.

论文面向教师远大于学生的场景. forward KL 要求容量有限的学生覆盖教师的多种输出模式, 可能把概率摊到质量较差的区域;序列 reverse KL 允许学生集中到教师支持且自身能表达的模式. 但 reverse KL 并不免费: 对学生样本求期望后, 无偏梯度是 policy gradient, 长序列上的估计方差明显高于普通 teacher-forcing.

## 1. 序列目标如何展开

### 1.1. 从 KL 到 log-ratio

沿用论文记号, 输入分布为 $p_x$, 教师序列分布为 $p(y\mid x)$, 学生为 $q_\theta(y\mid x)$. 目标是

$$
\mathcal L(\theta)=D_{\mathrm{KL}}(q_\theta\|p)
=\mathbb E_{x\sim p_x,\,y\sim q_\theta}
\left[\log q_\theta(y\mid x)-\log p(y\mid x)\right]. \tag{1}
$$

自回归分解给出

$$
\log\frac{p(y\mid x)}{q_\theta(y\mid x)}
=\sum_{t=1}^{T}
\log\frac{p(y_t\mid x,y_{<t})}{q_\theta(y_t\mid x,y_{<t})}. \tag{2}
$$

定义单步 log-ratio

$$
r_t=\log p(y_t\mid s_t)-\log q_\theta(y_t\mid s_t), \tag{3}
$$

则最小化式 (1) 等价于最大化学生样本上的 $\sum_t r_t$. 教师给已采 token 的 log-prob, 学生 log-prob 同时出现在采样策略与奖励表达式中. $-\log q_\theta$ 提供熵相关作用, 避免目标只追逐教师最可能的单一路径.

### 1.2. 梯度为什么包含未来

对含参数的采样分布使用对数导数技巧. 轨迹 log-prob 为 $\log q_\theta(y\mid x)=\sum_t\log q_\theta(y_t\mid s_t)$. 整理后, MiniLLM 给出形如

$$
\nabla_\theta\mathcal L
=-\mathbb E_{y\sim q_\theta}
\left[\sum_{t=1}^{T}(R_t-1)
\nabla_\theta\log q_\theta(y_t\mid s_t)\right], \tag{4}
$$

其中

$$
R_t=\sum_{u=t}^{T}r_u. \tag{5}
$$

$R_t$ 是从位置 $t$ 开始的 reward-to-go. 当前 token 会改变 $s_{t+1}$ 以及所有后续状态, 所以后续 log-ratio 被归因给当前动作. 式 (4) 中的常数项来自 $\log q_\theta$ 对参数的直接依赖; 它不是随意添加的 baseline.

这一步回答了 MiniLLM 与局部 KL 训练的差别. 若把学生 rollout detach 后再逐位置计算 reverse KL, 梯度只校正当前状态的条件分布, 没有式 (5). 两者可能使用同一批学生生成文本, 也都可能写着 reverse KL, 但优化目标不同.

两步手算：设回答只有两步, 已采 token 的 log-ratio 为 $r_1=0.2,r_2=-0.1$. 则 $R_2=-0.1$, $R_1=0.1$. 第二个动作只承担自身差异;第一个动作同时承担两步总差异. 如果第一步换一个 token 会让第二步进入教师更认可的状态, 这种影响只能通过 $R_1$ 表达.

若使用零折扣局部奖励, 两步优势分别取 $0.2$ 与 $-0.1$, 第一动作不再看到第二步结果. 局部估计方差较小, 但丢掉状态转移影响. MiniLLM 选择保留未来项, 随后必须处理它带来的训练不稳定.

### 1.3. 三个稳定化改动

单步分解：直接估计式 (4) 时, 每个 $R_t$ 汇总许多随机项. 序列越长, 方差越大. MiniLLM 把当前步 $r_t$ 与未来回报 $R_{t+1}$ 分开. 当前状态上的 reverse KL 可以在完整词表上解析计算:

$$
\mathbb E_{a\sim q_\theta(\cdot\mid s_t)}
\left[\log\frac{q_\theta(a\mid s_t)}{p(a\mid s_t)}\right]
=D_{\mathrm{KL}}(q_\theta(\cdot\mid s_t)\|p(\cdot\mid s_t)). \tag{6}
$$

式 (6) 可以直接对完整词表求和, 无须用单个采样 token 估计当前步的分布差异. 教师与学生读取同一前缀并输出各自的词表分布, learner 对词表求和; 未来状态效应仍由蒙特卡洛轨迹估计. 这样既保留序列目标的两部分, 又降低当前步估计的噪声.

代价是 full-vocab 计算. 对长序列与大词表, 式 (6) 的 logits 占用与 GKD 精确 KL 相同. 若工程实现只读取已采 token, 就没有实现论文的解析单步项, 方差性质也随之改变.

教师混合采样：纯学生采样可能迅速集中到狭窄、重复或过短的序列. MiniLLM 使用教师与学生的混合策略收集轨迹:

$$
\tilde p(a\mid s)=\alpha p(a\mid s)+(1-\alpha)q_\theta(a\mid s). \tag{7}
$$

因为目标期望仍属于 $q_\theta$, 从 $\tilde p$ 采样后原则上需要重要性权重. 完整序列权重是逐步比率连乘, 长度增加时方差会爆炸. 论文使用单步近似权重, 牺牲无偏性换取可训练性, 实验中取 $\alpha=0.2$.

混合采样改变了访问状态. 教师动作比例提高后, 前缀更靠近教师分布;学生错误状态覆盖减少. 因而 MiniLLM 是以 on-policy 学生为主、带教师 roll-in 与近似修正的混合算法, 不能把所有训练 token 都描述成严格当前学生样本.

长度归一化：原始累积 $R_{t+1}=\sum_{u=t+1}^{T}r_u$ 随剩余长度变化. 即使单步质量相同, 长回答也会累计更多负项或正项, EOS 决策会受到系统性偏置. MiniLLM 用未来平均代替未来总和:

$$
R^{\mathrm{norm}}_{t+1}
=\frac{1}{T-t-1}\sum_{u=t+1}^{T}r_u. \tag{8}
$$

式 (8) 让不同剩余长度的回报更可比. 但它也改变了严格序列 KL 的梯度权重, 属于有意引入的稳定化偏差. 论文报告, 缺少长度归一化时模型容易偏好短输出. 实现中还要处理 $t=T$ 时分母为零, 通常末步没有未来项.

## 2. 数据流与缓存

### 2.1. 一批样本的生命周期

输入 prompt 先进入混合 rollout. 每一步需要学生 logits;按 $\alpha$ 决定混合策略后采 token. 若实现精确混合采样, 教师在 Decode 期间也要逐步给 logits, 这比「学生先生成完整回答、教师再 Prefill」更昂贵. 另一种工程方式是分别采教师序列和学生序列再混 batch, 但状态分布与逐步混合式 (7) 不同.

轨迹生成后, 缓存至少包含 token id、每步行为策略 log-prob、学生 log-prob、教师 log-prob、有效长度和采样来源. 计算单步解析 KL 时还需要师生全词表分布或能够重算这些分布的模型状态. 优化器更新后, 旧轨迹仍对应旧学生;多 epoch 复用会增加 off-policy 偏移.

学生参数在 learner 更新, 教师参数冻结. 论文还加入预训练语料上的语言模型损失以维持通用能力, 所以一个优化 step 可能同时消费蒸馏 batch 与通用语料 batch. 两个 loss 的 token 数与归一化口径必须明确, 否则混合系数不具可比性.

这条数据流也解释了 MiniLLM 为何比局部蒸馏更难「只保存最终文本」: reward-to-go、行为分布修正和版本滞后诊断都需要 token 级概率与采样来源.

### 2.2. 缓存保留什么

若只实现 sampled-token policy gradient, 完整教师 logits 可以在算出已采 token log-prob 后丢弃; 代价是失去解析式 (6). 若保留 top-$k$, 可以近似当前步分布差异, 但需要处理尾部质量. 若只保存总序列 reward, 就无法重算 reward-to-go、检查哪个位置出现教师优势反转, 也无法改变长度归一化.

行为策略 log-prob 不应过早丢弃. 混合采样与策略滞后都需要知道样本由什么分布产生. 没有行为 log-prob, 训练器只能假设样本来自当前学生, 重要性修正和偏移诊断都无法进行. 这项缓存相对词表 logits很小, 每个 token 只需一个标量.

## 3. 论文实验与可解释范围

### 3.1. 模型、数据与训练

MiniLLM 使用 GPT-2、OPT 与 LLaMA 模型族, 教师大于学生. 指令数据主要来自过滤后的 Dolly, 并在多个指令跟随集合上评测. 论文还在训练中加入预训练语料语言模型损失, 用于缓解通用能力遗忘. 因此最终结果来自 reverse-KL 蒸馏、教师混合 roll-in、长度归一化与通用语料正则的组合, 不能只归因于单个公式.

论文按参考回答长度分析方法差异. 短回答的输出空间较小, 学生更容易覆盖教师模式, forward KL 与 reverse KL 的差距有限;回答变长后, 教师分布包含更多学生难以同时覆盖的模式, reverse-KL 方法优势更明显. 这一解释与容量约束一致, 但评测仍局限于论文使用的模型族和任务.

暴露偏差与校准：论文使用累积误差指标分析自由生成与训练条件之间的差异, 报告 MiniLLM 在长生成下的暴露偏差低于 KD 与 SeqKD 基线. 这与学生主导的状态覆盖相符. 但混合 roll-in 意味着训练状态并非完全等于纯学生部署分布, 更准确的理解是: MiniLLM 显著增加了学生访问状态的训练比例.

校准实验显示, MiniLLM 在论文设定下优于若干蒸馏基线. reverse KL 的 mode-seeking 性质本身没有给出更好校准的保证;这里的结果同时受 on-policy 状态、序列目标、教师规模和语言模型正则影响. 更准确的结论是这套组合在相应实验中改善了校准.

教师规模：论文固定小学生、增大教师后, MiniLLM 性能随教师规模提升, 与一些 off-policy 蒸馏中「教师太强反而难学」的现象形成对照. 一种解释是 reverse KL 不要求小学生覆盖教师全部模式, 学生只需在自身样本附近得到教师偏好. 另一项必要条件是教师必须在学生前缀上仍能给出稳定分布;仅有最终任务分数差距不足以保证这一点.

教师变大还会改变训练成本和反馈尖锐度. 更强教师若给出更低熵分布, 极端 log-ratio 可能增多, 方差控制随之更重要. 因此教师规模实验应同时报告吞吐、教师熵和 advantage 分位数, 才能区分能力收益与优化难度.

## 4. 与 GKD 和 RL 的关系

### 4.1. 与 GKD 的严格区别

GKD 的纯 on-policy 版本先用学生生成, 再把生成序列 detach, 对每个前缀计算条件散度. MiniLLM 直接对序列分布 reverse KL 求导, 采样分布依赖产生 reward-to-go. 如果 GKD 选择 reverse KL, 两者的局部散度看起来相同, 但 MiniLLM 多了状态分布对参数变化的梯度.

换一个角度看, GKD 每轮优化「在当前采样状态上模仿教师」; MiniLLM 优化「让学生整条序列分布接近教师」. 前者更容易并行和稳定, 后者目标更完整但估计困难. 工程实现若去掉 MiniLLM 的未来回报与解析单步项, 就已经迁移到另一种估计器.

与 RL 的对应：式 (3) 把教师 log-prob 变成逐 token 信号, policy gradient 把后续信号归因给当前动作. 从优化器接口看, MiniLLM 很像 RL: rollout、reward-to-go、行为概率、重要性权重和裁剪都可能出现. 区别在于奖励完全由师生概率比定义, 教师是明确的行为分布目标.

环境 RL 的标量奖励可以鼓励学生超过教师, 但信用分配稀疏;MiniLLM 给每个 token 稠密教师信号, 上界受教师偏好影响. 两者可以组合, 但组合后要防止教师项压过任务奖励或任务奖励破坏蒸馏稳定性. 报告结果时应把两项单独消融.

## 5. 机制推导、实验与适用边界

### 5.1. 方差失控

长序列让 $R_t$ 汇总大量随机 log-ratio. 若教师与学生在少数位置概率差极大, 单个 $r_t$ 就会主导整段前缀梯度. 训练表现为 advantage 长尾、梯度裁剪频繁、不同 batch loss 波动巨大. 应查看按位置的 $r_t$ 分位数、$R_t$ 方差、有效长度和重要性权重分布, 而不是只看平均 KL.

概率下溢也会制造极端比值. 教师对已采 token 给出接近零的概率时, $\log p$ 成为大负数. 需要在 log-softmax 域计算, 明确最小 log-prob 或裁剪规则, 并统计被裁剪比例. 裁剪改善数值稳定性, 同时改变目标, 必须进入方法说明.

### 5.2. 长度与重复

未做长度归一化时, reward-to-go 的尺度随剩余 token 数变化. EOS 概率的小偏差可能被整段未来回报放大, 导致过短回答. 另一方面, 教师若对重复局部模式仍给较高概率, 学生可能进入重复循环以获得稳定 log-ratio. 监控平均长度不足以发现后者, 还需看重复 n-gram、EOS 位置分布与每位置熵.

教师混合比例过高会减少学生错误状态, 训练越来越像教师轨迹蒸馏;比例过低则可能让弱学生在坏状态中自我强化. 合适的 $\alpha$ 取决于学生起点与任务, 原论文的 $0.2$ 不是普适常数.

### 5.3. 实现错位

最常见错误是 KL 方向写反. 许多框架 API 的参数顺序与数学记号不同;应对三 token 分布手算式 (6), 再与代码输出和 autograd 梯度比较. 第二类错误是把新学生 log-prob 与旧行为 log-prob 混用. 式 (3) 中的 $q_\theta$ 属于目标学生, 重要性权重分母属于行为策略, 两者版本不同.

第三类错误是 response mask 错一位. 教师在位置 $t-1$ 的 logits 预测 token $y_t$;若直接用同位置 token 对齐, 全部监督偏移一格. 短样本逐 token 打印是必要测试. 第四类错误是将 prompt token 也计入序列 KL, 让大量梯度消耗在复制输入模板上.

复现顺序：先在短序列、小词表上验证式 (1) 与直接枚举一致. 然后固定一批学生轨迹, 分别计算 stop-gradient 局部 reverse KL 与 MiniLLM 梯度, 确认未来项造成的差异. 再加入解析单步项, 比较梯度方差;之后才加入教师混合采样、重要性近似、长度归一化和通用语料损失. 一次加入全部组件, loss 下降也无法定位是哪项起作用.

扩展到分布式训练时, 为每条轨迹保存学生版本、教师版本、采样来源与行为 log-prob. 教师与学生 tokenizer 必须一致或有严格对齐方案. 训练报告至少包括 $\alpha$、轨迹复用次数、序列最大长度、回报归一化、裁剪阈值、通用语料损失权重和生成解码参数.

**MiniLLM 展开了序列 reverse KL 对学生采样分布的依赖, 并处理由此出现的方差和长度问题.** 实现是否保留原目标, 取决于未来回报、解析单步项和行为分布修正是否仍在计算图中.

reward-to-go 的数值核对：实现式 (5) 时, 最容易出现的错误是反向累计方向. 给四个位置设置 $r=(1,2,3,4)$, 正确的 reward-to-go 应为 $(10,9,7,4)$. 若使用未来项 $R_{t+1}$, 则应为 $(9,7,4,0)$. 再应用长度归一化后, 对应值是 $(3,3.5,4,0)$. 这个固定例子能查出 inclusive/exclusive、反向扫描与末位分母处理三类问题.

mask 会让累计更复杂. batch 中较短样本的 padding 位置必须先置零, 再反向累计;若先累计后乘 mask, padding 上的数值可能已经进入前面的回报. EOS 是否计入 $r_t$ 也要固定. 教师与学生对结束概率的差异直接影响长度, 不应在没有说明的情况下删掉 EOS.

baseline、标准化与裁剪：策略梯度常减去 baseline 以降低方差. MiniLLM 推导中的常数项来自目标本身, 不能与经验 baseline 混为一项. 如果实现又对 advantage 做 batch 均值中心化或标准差归一化, 梯度尺度和相对权重会改变. 这些处理可能有助训练, 但已经是论文目标之外的估计选择.

裁剪同样需要区分对象. 裁剪 log-ratio 限制单 token 极端值;裁剪重要性比限制行为策略与目标策略偏移;裁剪最终 advantage 限制回报长尾;梯度范数裁剪发生在反向传播之后. 四种裁剪作用位置不同, 不应只报告一个 `clip=0.2`.

教师混合采样的实现分叉：逐 token 混合要求每个 Decode 步同时取得教师与学生分布, 再从式 (7) 采样. 这样得到的前缀可能由教师动作与学生动作交错构成, 严格对应混合策略. 代价是大教师进入顺序 Decode 路径, 延迟和 KV cache 成本很高.

按序列混合则先以概率 $\alpha$ 选择整条教师轨迹或学生轨迹. 这种实现只需各模型独立生成, 吞吐更容易扩展, 但轨迹分布是 $\alpha p(y)+(1-\alpha)q(y)$, 不等于各位置条件分布混合后的乘积. 另一种做法是 batch 内分别采两类序列. 三者都可称混合 roll-in, 数学分布不同, 必须注明.

解析单步项的分块实现：式 (6) 需要对词表求和, 但不一定要同时保存全部 teacher 与 student logits. 可以先计算每个位置的 log-normalizer, 再按词表块重算或流式读取 logits, 累积 $q(v)(\log q(v)-\log p(v))$. 这样降低峰值显存, 代价是额外计算或更复杂的 kernel.

如果教师服务只返回 top-$k$, 尾部不能简单视作零. 可把尾部概率质量合并成一个桶, 得到粗化分布上的 reverse KL;该目标忽略尾部内部排序. 当学生大量概率落在教师 top-$k$ 之外时, 尾部桶会掩盖重要差异, 应同时监控尾部质量.

通用语料损失如何影响判断：MiniLLM 训练中加入通用语言模型损失, 这一项在原始文本前缀上做 next-token prediction. 它提供稳定梯度并帮助保持基础能力, 同时引入 off-policy 状态. 移除该项后的性能下降混合了遗忘和优化稳定性变化, 需要配套消融才能判断 reverse KL 本身的贡献.

混合两个数据流时, 应按有效 token 数分别归一化. 假设蒸馏 batch 有 $N_d$ 个 response token, 通用语料有 $N_l$ 个 token, 可先得到两个均值损失再乘系数. 直接把全部 token 拼接后平均, 实际权重会随回答长度和 batch padding 改变.

教师比学生强的含义：最终准确率更高只是教师优势的一种表现. 对 MiniLLM 而言, 更直接的量是在学生访问状态上, 教师是否给优质延续更高概率. 一个在自身生成轨迹上很强、遇到学生风格前缀却分布混乱的教师, 可能无法提供稳定 reward. 反过来, 最终分数略高但条件分布校准较好的教师也可能有用.

可以构造前缀续写测试: 从学生正确与错误轨迹分别截取多个位置, 让教师和学生对候选下一步打分, 比较正确候选的 margin. 还可以让教师从学生前缀继续生成, 检查恢复率. 这些诊断比只看教师独立答题分数更贴近蒸馏接口.

从小实验到长序列：短序列上 reward-to-go 方差有限, full-vocab 项也容易放进显存. 扩大最大长度后, 未来项数量、极端 log-ratio 机会和 logits 物化同时增长. 因此长度扩展不只是调大一个配置值. 应逐档增加长度, 记录 advantage 分位数、裁剪比例、峰值显存、每 token 耗时和回答长度分布.

如果长序列训练出现后半段梯度几乎为零, 可能是长度平均削弱了信号;前半段梯度异常大, 可能是 reward-to-go 累积. 若回答越来越短, 检查 EOS 与归一化;若越来越长, 检查截断样本是否把未生成 EOS 当作正常结束. 每种症状都对应具体状态与公式, 不需要靠笼统调低学习率处理.

可比较的实验报告：一个可比较的 MiniLLM 实验至少报告教师与学生检查点、tokenizer、prompt 模板、混合采样粒度、$\alpha$、行为策略版本、轨迹复用次数、最大长度、温度、reward-to-go 定义、长度归一化、重要性近似、裁剪位置、通用语料损失与权重. 缺少这些信息, 同名方法可能对应明显不同的目标.

结果表之外还应给出训练动态. 任务分数、序列 KL 估计、局部 KL、advantage 方差、回答长度、重复率和通用基准遗忘共同构成最小集合. 只展示最终任务分数, 无法判断收益来自蒸馏、长度变化还是通用语料正则.

复现实验还应公开停止条件. 若根据验证集生成指标选择检查点, 这与根据训练 KL 最低点选择不同;长训练中 reverse KL 可能继续下降, 任务质量却因熵收缩或遗忘而回落. 检查点选择规则本身会影响最终比较.

逐位置诊断样本应保存学生 token、教师与学生 log-prob、$r_t$、$R_t$ 和 mask. 这些量可以直接复算单条轨迹的训练信号. 汇总曲线显示总体趋势, 逐位置样本则暴露公式与实现的偏差.

这些记录也能区分算法失败与系统失败. 如果逐位置信号正确但任务分数不升, 问题更可能在教师能力或目标选择;如果信号在版本同步后突然变化, 则应先检查权重、模板和缓存一致性. 把两类故障分开, 才能让超参数实验产生可解释结论.

### 5.4. 从序列 reverse KL 完整推导梯度

目标中有两处参数依赖：对固定 prompt $x$, 记

$$
L_x(\theta)=\sum_y q_\theta(y\mid x)
\log\frac{q_\theta(y\mid x)}{p(y\mid x)}. \tag{9}
$$

$\theta$ 同时出现在采样概率 $q_\theta(y\mid x)$ 和对数比率中的 $\log q_\theta(y\mid x)$. 直接求导:

$$
\begin{aligned}
\nabla L_x
&=\sum_y \nabla q_\theta(y\mid x)
\log\frac{q_\theta(y\mid x)}{p(y\mid x)}
+\sum_y q_\theta(y\mid x)\nabla\log q_\theta(y\mid x)\\
&=\mathbb E_{y\sim q_\theta}
\left[\left(\log\frac{q_\theta(y\mid x)}{p(y\mid x)}+1\right)
\nabla\log q_\theta(y\mid x)\right]. \tag{10}
\end{aligned}
$$

利用 $\mathbb E_q[\nabla\log q]=0$, 常数 1 在完整期望中可作为 baseline 消掉. 论文按 $r_t=\log p-\log q$ 改写后出现 $(R_t-1)$;两种记法的符号与常数要整体对应, 不能从单独一项判断实现方向.

自回归展开：序列 log-prob 分解为

$$
\log q_\theta(y\mid x)=\sum_{t=1}^{T}\log q_\theta(y_t\mid s_t).
$$

把序列回报 $R_1=\sum_{u=1}^{T}r_u$ 代入 score-function 项, 初始形式会让每个动作乘整条轨迹回报. 对第 $t$ 步动作, 过去 $u<t$ 的奖励在给定 $s_t$ 后与当前动作无关, 其期望梯度为零, 所以只保留 reward-to-go $R_t=\sum_{u=t}^{T}r_u$. 由此得到论文式 (2).

这一步是信用分配的来源. 当前 token 改变所有未来前缀, 后续师生 log-ratio 因而回传到当前动作. 若实现只让第 $t$ 步乘 $r_t$, 就删掉了序列状态转移效应.

为什么常数项不能随手删除：在精确期望下, 与动作无关的 baseline 不改变梯度. 蒙特卡洛 batch 有限时, 保留或减去 baseline 会改变方差. 论文推导里的 $-1$ 来自 reverse KL 中 $\log q$ 的直接导数, 与人为加入的价值 baseline 来源不同.

实现若又对 advantage 减 batch 均值, 应先写出最终估计器. 两个常数可能在期望上都不改梯度, 对有限 batch、mask 与长度归一化的交互却不同. 把它们统称为「baseline」会隐藏公式差异.

当前步可以解析求和：给定状态 $s_t$, 当前动作上的期望为

$$
\mathbb E_{a\sim q_\theta(\cdot\mid s_t)}
\left[\log\frac{p(a\mid s_t)}{q_\theta(a\mid s_t)}\right]
=-D_{\mathrm{KL}}(q_\theta\|p). \tag{11}
$$

动作空间是有限词表, 所以式 (11) 可直接求和, 不必用一个采样 token 估计. MiniLLM 把当前步 $r_t$ 交给解析 reverse KL, 未来 $R_{t+1}$ 仍用轨迹蒙特卡洛估计. 最终梯度分成 single 与 long 两部分.

方差为何下降：采样估计当前步时, 一个低概率 token 可能带来极端 log-ratio, 其方差由动作采样决定. 解析求和对所有 token 按 $q$ 加权, 给定状态后没有动作采样噪声. 状态本身仍来自随机轨迹, 所以方差没有归零.

single 项还给所有词表动作梯度, 能直接压低未被当前轨迹采到的学生伪模式. long 项只沿已采动作分配未来信用. 二者信息粒度不同, 不能用一个 sampled-token loss 同时精确替代.

分解后的符号核对：论文把 $r_t$ 定义为 $\log p-\log q$, 所以希望提高 $r_t$. single 部分写成对该期望的负梯度, 等价于最小化 reverse KL. 若代码把 `student_logprob - teacher_logprob` 当 reward, policy gradient 的方向会反转.

最小测试可令教师偏好 token A, 学生偏好 B. single 梯度应提高 A 或降低 B;long 梯度在后续教师更喜欢的轨迹上提高前序动作. 两项都通过才说明符号正确.

逐 token 混合产生什么分布：MiniLLM 在每个状态定义

$$
\tilde p(a\mid s)=\alpha p(a\mid s)+(1-\alpha)q_\theta(a\mid s). \tag{12}
$$

轨迹概率是这些逐步混合条件分布的乘积. 它不同于先抛一次硬币、整条轨迹选教师或学生. 前者允许同一回答中交替出现教师与学生动作, 后者只产生纯教师或纯学生轨迹.

逐步混合把状态往教师高概率区域拉, 小学生较少进入重复、空回答或乱码状态. 代价是轨迹不再由 $q_\theta$ 采样, 必须用重要性权重恢复 reverse-KL 目标.

精确前缀权重：到第 $t$ 步的精确权重为

$$
w_t^{\mathrm{full}}=\prod_{u=1}^{t}
\frac{q_\theta(y_u\mid s_u)}{\tilde p(y_u\mid s_u)}. \tag{13}
$$

它把 $\tilde p$ 下的前缀期望转换成 $q$ 下的前缀期望. 当多个单步比率稍大于或小于 1 时, 连乘会随长度指数放大或缩小. 长回答上绝大多数权重可能接近零, 少数轨迹承担几乎全部梯度.

单步近似引入什么偏差：论文近似使用

$$
w_t\approx
\frac{q_\theta(y_t\mid s_t)}{\tilde p(y_t\mid s_t)}. \tag{14}
$$

它修正当前动作分布, 没有修正状态 $s_t$ 已由混合策略产生这一事实. 方差大幅降低, 估计器带偏. 偏差随 $d_{\tilde p}$ 与 $d_q$ 的差距增大;也就是 $\alpha$ 越大、序列越长, 状态分布偏差通常越明显.

这项选择体现 MiniLLM 的核心取舍: 目标是序列 reverse KL, 可训练实现接受近似. 报告方法时应同时说「on-policy 目标」和「teacher-mixed 采样下的局部重要性近似」.

权重范围：因为 $\tilde p(a)\ge(1-\alpha)q(a)$, 单步比率满足

$$
0\le\frac{q(a)}{\tilde p(a)}\le\frac1{1-\alpha}. \tag{15}
$$

单步权重天然有上界. 例如 $\alpha=0.2$ 时上界为 1.25. 精确前缀权重上界则是 $1.25^t$, 仍会随长度增长. 这进一步解释单步近似为何稳定.

原回报的长度倾向：$R_{t+1}$ 是未来 log-ratio 总和. 教师通常比学生给已采轨迹更高概率时, 各项 $r_u$ 偏正;回答越长, 总和绝对值越大. 若符号与具体状态组合使长轨迹得到更差回报, 策略会通过提前 EOS 规避未来累计项, 最终产生空回答或过短回答.

论文观察到原式偏好短句, 因而改成未来平均:

$$
R_{t+1}^{\mathrm{Norm}}
=\frac{1}{T-t-1}\sum_{u=t+1}^{T}r_u. \tag{16}
$$

平均后, 回报尺度不再随剩余长度线性增长. 它同时改变了完整序列 reverse KL 的梯度, 属于有意的偏差, 目标是消除长度带来的训练不稳定.

分母边界：论文记号在尾部需要特殊处理. 当 $t=T$ 或未来 token 数为零时, long 项应为 0, 不能除零. 若 EOS 计入序列, 倒数第二步的未来集合是否只含 EOS 也需和代码一致.

padding 后批处理应按每条序列的有效剩余长度计算分母. 用 batch 最大长度会让短样本未来回报被过度稀释. 固定四步手算 $(r_1,r_2,r_3,r_4)$ 是检查反向累计和分母的直接方法.

平均仍会改变 EOS：长度归一化减弱累计偏置, 没有移除 EOS 的局部 reverse KL. 教师和学生结束偏好不同, single 项仍会调整 EOS. 所以回答长度变化不能全部归因于 long 项;应分别记录 single/long 梯度在 EOS logit 上的贡献.

PPO 式裁剪在这里裁什么：训练算法对 long 项使用比率

$$
\rho_t(\theta)=\frac{q_\theta(y_t\mid s_t)}{\tilde p(y_t\mid s_t)}. \tag{17}
$$

并借鉴 PPO 将其限制在 $[1-\epsilon,1+\epsilon]$. 裁剪限制 learner 相对行为分布的单步变化, 防止某些 token 的重要性比主导更新. 它不等于裁剪教师—学生 log-ratio $r_t$, 也不等于梯度范数裁剪.

当 $R_{t+1}^{\mathrm{Norm}}$ 符号不同, PPO 的 `min` 形式需要像标准 PPO 一样处理正负 advantage. 直接对比率做 `clamp` 再乘回报, 与 clipped surrogate 的梯度区域不同. 实现核对要看具体计算图, 不能只看配置里有 `clip_range`.

single 项的解析 KL与 long 项裁剪作用不同. 若 single 项完全不裁剪, 极端教师概率仍可能产生大梯度;论文稳定性来自解析求和、teacher mix、long 裁剪与预训练 loss 的组合.

预训练语言模型损失的作用：MiniLLM 每步还从长文档预训练语料 $\mathcal D_{PT}$ 取 batch, 优化

$$
L_{PT}=-\mathbb E_{d\sim\mathcal D_{PT}}\log q_\theta(d). \tag{18}
$$

它维持通用语言能力, 并给训练提供稳定的 teacher-forcing 梯度. 最终更新是 single、归一化 long 与 $L_{PT}$ 三者相加. 因此 MiniLLM 的实验结果属于整个组合, 不是纯 reverse-KL policy gradient 的单组件结果.

三个梯度没有天然相同尺度. single 按词表期望, long 按采样轨迹, PT loss 按语料 token. batch size、有效长度和归一化都会决定实际比例. 复现时需要记录每项梯度范数, 而不是只抄一个总学习率.

预训练 loss 也改变状态来源: 它在离线自然文本前缀上训练学生. 这些状态不属于指令 rollout, 却能保护基础建模能力. 若消融移除 PT loss 后通用基准下降, 不能简单归因 reverse KL 破坏能力;还要与等 token 的普通 SFT 对照.

### 5.5. 训练算法的阶段结构

SFT 初始化：论文先在指令—回答数据上监督微调学生, 选择验证 loss 最低的 checkpoint, 再开始 MiniLLM. 这一步让学生进入教师可反馈的区域, 也建立回答格式和基础指令能力. reverse KL 随后在学生支持中选择教师认可模式.

跳过 SFT 会改变研究问题. 弱学生轨迹可能大多无意义, teacher-mixed sampling 被迫由教师承担更多动作, 重要性偏差增大. MiniLLM 并未证明从随机或纯预训练学生直接做 reverse-KL OPD同样有效.

每轮三批数据：一轮至少涉及指令 prompt、混合策略生成的 response 和预训练文档. teacher-mixed Decode 产生轨迹;师生在这些前缀上计算 single 与 long 所需概率;另一个 PT batch 提供语言模型梯度. 三路数据的 tokenizer 一致, mask 语义不同.

prompt token 不应进入 response reverse KL, 预训练文档则所有 next-token 位置都参与. 若复用同一个 loss collator, 很容易让 prompt 也产生蒸馏梯度或让 PT 文档错误 mask.

教师在线 Decode 的成本：逐 token 混合式 (12) 要在生成每一步同时取得教师和学生分布. 大教师进入顺序 Decode 路径, 比学生先生成、教师再 Prefill 评分昂贵. 这与后来的简化 OPD 配方不同, 后者通常让学生独立 rollout 后再批量查教师 log-prob.

若工程实现改成整条轨迹层面的教师/学生混合, 或只用学生 rollout, 就改变了 MiniLLM 原始行为分布. 可能仍是有效变体, 需要单独命名和消融.

教师概率对应隐式奖励：在最大熵 RL 中, 最优策略常可写成参考策略与指数奖励的组合. 反过来, 给定教师 $p$ 与学生 $q$, log-ratio

$$
r(s,a)=\log p(a\mid s)-\log q(a\mid s) \tag{19}
$$

可以视为教师相对学生赋予动作的密集优势. 教师高概率、学生低概率的动作得到正信号;学生高概率、教师低概率的动作得到负信号.

这不是外部任务奖励. 它编码教师行为, 上限受教师限制. inverse RL 视角帮助解释为何 MiniLLM 能复用 RL 优化工具, 也提醒我们 log-ratio 只是从教师策略反推出的代理信号.

熵项：reverse KL 展开为

$$
D_{\mathrm{KL}}(q\|p)=\mathbb E_q[-\log p]-H(q). \tag{20}
$$

第一项让学生选择教师高概率序列, $-H(q)$ 对应鼓励学生保持熵. 所以 MiniLLM 不是简单最大化教师 log-prob;学生自身的熵进入目标. 论文式 (2) 中的 $-\log q$ 正是这一结构.

mode-seeking 与熵项并不矛盾. reverse KL 在教师多峰之间倾向选择少数峰, 但在所选峰内部仍有熵激励. 最终多样性由教师形状、学生容量与解码温度共同决定.

原论文的模型与数据范围：论文覆盖 GPT-2 约 120M、340M、760M, OPT 1.3B、2.7B、6.7B, 以及 LLaMA 7B 学生. 对应教师包括 GPT-2 1.5B、OPT 13B、LLaMA 13B, 附录还报告 GPT-J 6B 教师. 这形成约 120M 到 13B 的模型范围和多个架构族.

训练数据来自 databricks-dolly-15K 的人工指令—回答对. 过滤超过上下文长度的样本后, 论文随机划出约 1K 验证、0.5K 测试, 剩约 12.5K 训练. 教师先在这套数据上微调, 学生也先做 SFT 初始化.

因此实验属于白盒教师、共享或兼容词表、指令跟随任务. 今天的大型混合专家模型、超长思维链和异构 tokenizer 不在原验证范围. 方法原理可迁移, 训练稳定性与成本需要重新测.

评测为什么用了多种尺度：论文在五个评测集上使用 ROUGE-L、GPT-4 反馈和人工判断. ROUGE-L 看参考文本重合, 自动评审看总体回答质量, 人工判断补充模型评审偏差. 三者关注不同层面.

reverse KL 可能产生更精准、较集中的回答, ROUGE 与模型评审都可能受长度和风格影响. 人工评测能检查流畅性与相关性, 样本量又较小. 结论最稳的部分是多种指标方向一致, 不是任一指标单独绝对可靠.

论文还分析暴露偏差、校准、不同回答长度和生成多样性. 这些分析与方法机制直接对应: on-policy 训练应减小自由生成偏移;reverse KL 可能改变校准和模式覆盖;长度归一化应改善长回答;mode-seeking 可能牺牲多样性.
