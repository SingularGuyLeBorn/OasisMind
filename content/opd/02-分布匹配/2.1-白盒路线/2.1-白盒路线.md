# 白盒路线: 状态分布与目标

OPD 文献最容易混淆的地方, 是把「学生生成轨迹」和「使用 reverse KL」绑定成一个概念. 两者并不绑定. 轨迹来源决定外层期望在哪些状态上取值; 散度方向决定同一个状态上如何比较师生下一 token 分布; 是否对采样分布求导又决定当前动作是否承担未来状态的影响. 三条轴分别改变算法, 应当逐项记录.

设输入为 $x$, 回答为 $y$, 状态为 $s_t=(x,y_{<t})$. 对任意采样策略 $\mu$, 状态访问分布记为 $d_\mu(s)$. 一个统一目标是

$$
\mathcal J(\theta;\mu)=\mathbb E_{s\sim d_\mu}
\left[D_f\!\left(\pi_T(\cdot\mid s),\pi_\theta(\cdot\mid s)\right)\right]. \tag{1}
$$

当 $\mu$ 是固定数据生成策略时, 式 (1) 是 off-policy 蒸馏; 当 $\mu=\pi_{\theta_k}$ 且每轮刷新时, 式 (1) 是 stop-gradient OPD. 若让 $\mu=\pi_\theta$ 并对其参数依赖求导, 目标会多出 score-function 梯度. [GKD](01-GKD.md) 主要研究前两种之间的混合与 $D_f$ 的选择; [MiniLLM](02-MiniLLM.md) 从序列 reverse KL 推导后一种.

## 1. 状态分布先决定学生会在哪里犯错

### 1.1. 前缀来源改变学习位置

固定参考答案给出的前缀通常语法正确、推理连贯. 学生自由生成后的前缀可能包含错误变量、重复句段、格式破损或已经走错的中间结论. 在固定前缀上学会预测教师, 不保证学生能从自身错误状态恢复. 自回归依赖使单步误差改变后续输入, 这正是模仿学习中状态分布偏移的来源.

DAgger 的做法是让学习者执行, 再让专家标注学习者访问的状态. OPD 把专家动作扩展为下一 token 分布. 但教师分布只描述局部下一步, 并不自动提供长程信用分配. 如果学生已经走到一个无解前缀, 教师仍必须在该前缀后分配概率; 局部最合理的 token 不一定能恢复全局任务. 因而学生状态覆盖部署分布是必要改进, 不是教师监督正确性的保证.

混合 roll-in 可以在两种风险之间折中. 教师或数据前缀比例高, 状态更规整, 训练初期稳定, 但学生错误区域覆盖不足. 学生比例高, 分布匹配更直接, 但弱学生会产生大量低质量状态. 混合比例应和学生冷启动质量一起报告; 只写「使用 on-policy 数据」不足以复现实验.

### 1.2. 散度方向改变局部压力

在一个固定状态 $s$ 上, 令教师分布为 $p(v)$, 学生分布为 $q(v)$. forward KL 与 reverse KL 分别为

$$
D_{\mathrm{KL}}(p\|q)=\sum_v p(v)\log\frac{p(v)}{q(v)}, \tag{2}
$$

$$
D_{\mathrm{KL}}(q\|p)=\sum_v q(v)\log\frac{q(v)}{p(v)}. \tag{3}
$$

式 (2) 由教师概率加权. 教师认为可能而学生漏掉的 token 会产生强梯度, 因而倾向覆盖教师支持. 式 (3) 由学生概率加权. 学生已经放高概率、教师却不支持的 token 会被重点压低, 学生没有探索到的教师模式贡献很小. 两者都可以在学生前缀上计算, 所以两者都可以是 OPD.

散度方向还决定需要谁的完整分布. 精确 forward KL 的梯度可以由教师全词表概率监督学生; 精确 reverse KL 也需要学生全词表概率以及相应教师 log-prob. sampled-token 估计天然适合以学生为采样分布的量, 但一个样本无法同时重建教师低概率尾部的结构. top-$k$ 介于两者之间, 且必须说明 $k$ 由教师还是学生选择、尾部概率是否聚合.

**从局部散度走到序列目标。**

**采样梯度决定信用分配。**

式 (1) 若把 $d_{\pi_\theta}$ 当作常数, 梯度只更新每个已访问状态上的条件分布. 当前 token 改变未来前缀的路径被停止. 这种估计计算稳定, 可以像普通 token 级监督一样反向传播. GKD 明确采用学生生成序列, 再在序列上计算平均 token 散度;工程实现常把 rollout 与 learner 解耦, 正是这一估计的系统表达.

若目标本身是两个序列分布的 reverse KL, 轨迹概率也依赖 $\theta$. 对数导数技巧会把后续 log-ratio 汇成 reward-to-go, 当前动作因而承担未来差异. MiniLLM 的推导保留了这项, 再用单步分解、教师混合采样和长度归一化降低方差. **是否有未来回报, 取决于对哪个数学目标求导, 不能只看损失名称里有没有 reverse KL.**

有些 RL 框架把逐 token 的 $\log\pi_T-\log\pi_\theta$ 当作奖励, 并令折扣为 0. 这种实现只保留当前 token 的局部比值, 便于复用 policy-gradient 基础设施, 但没有 MiniLLM 的完整未来项. 训练日志中应区分「逐 token KL 监督」「零折扣 sampled-token reward」与「序列 reverse-KL policy gradient」.

**一个三 token 走查。**

考虑词表只有 $\{A,B,C\}$, 某个学生前缀上教师分布为 $p=(0.7,0.2,0.1)$, 学生分布为 $q=(0.4,0.4,0.2)$. forward KL 为

$$
0.7\log\frac{0.7}{0.4}+0.2\log\frac{0.2}{0.4}+0.1\log\frac{0.1}{0.2}\approx0.184. \tag{4}
$$

reverse KL 为

$$
0.4\log\frac{0.4}{0.7}+0.4\log\frac{0.4}{0.2}+0.2\log\frac{0.2}{0.1}\approx0.192. \tag{5}
$$

两个数接近, 梯度来源却不同. 式 (4) 的最大权重落在教师的 $A$ 上; 式 (5) 对学生过量分配的 $B,C$ 更敏感. 若学生只采到 $B$, sampled-token reverse-KL 样本是 $\log0.4-\log0.2=\log2$. 该样本完全没有告诉训练器 $A$ 应从 $0.4$ 升到 $0.7$, 只有多次采样的期望才恢复式 (5).

状态再向前走一步时, 差异会扩大. 若采到 $B$ 后教师进入一个低置信状态, 下一步教师分布可能接近均匀. stop-gradient 局部训练只处理两个已观察状态; 序列目标还会把第二步的 log-ratio 归因给第一步动作 $B$. 这正是局部监督与序列信用分配的分界.

## 2. 估计器、数据接口与训练稳定性

### 2.1. 训练前检查与失效模式

第一项检查是学生起点. 如果大部分 rollout 无法通过格式解析, 教师监督会集中在格式修复, 很少进入任务核心状态. 第二项是教师兼容性. 教师在自身答案上强, 不代表在学生前缀上稳定; 应测教师对学生轨迹的 token NLL、top-token 重合和优势分布. 第三项是支持重合. 师生 tokenizer、特殊 token 或聊天模板不一致时, 逐 token 对齐可能从输入端已经失效.

训练中常见的表面成功是 KL 降低而任务分数不升. 原因可能是回答缩短、熵下降、重复增多或 rollout 版本过旧. 另一种失败是教师过强且风格不兼容: 学生访问的状态在教师分布下极低概率, 教师每个位置都给出尖锐但互不连贯的局部修正. 混入教师前缀可以缓解分布断裂, 但会削弱严格 on-policy 覆盖.

### 2.2. 路线选择

需要一个稳定、容易并入监督训练栈的起点时, 先读 GKD. 它把 rollout 当作数据, 允许混合固定序列, 并用任务实验比较不同散度. 需要理解序列级 reverse KL、采样梯度和方差来源时, 读 MiniLLM. 两篇不是替代关系: GKD 给出可组合的训练接口, MiniLLM 给出更完整但更难估计的序列目标.

工程团队还应先确定教师接口. 能访问完整 logits 时, 两条路线都可精确实现局部分布项;只能访问已采 token log-prob 时, GKD 的 forward KL 与 MiniLLM 的解析单步项都无法原样计算. 接口能力会先于公式偏好缩小选择范围. [DistiLLM 与 DistiLLM-2](03-DistiLLM.md) 在这套坐标上继续处理 skew KL、历史学生样本复用,以及教师/学生两路回答应否采用不同目标.

选择完成后, 用同一批冻结轨迹对不同损失做离线梯度比较. 观察梯度余弦、位置分布和极端值, 可以在投入在线 rollout 成本前发现方向写反、mask 错位和尾部截断问题.

如果目标是压缩部署模型, 应优先比较同一算力预算下的监督 KD、GKD 与 MiniLLM, 而不是给三者相同步数. OPD 每步包含 rollout 与教师评分, 单步成本不同;公平口径可以是总训练 FLOPs、GPU 小时或教师 token 数. 如果目标是提升推理能力, 还应区分 pass@1 与 pass@k, 因为散度与采样可能分别改变主模式质量和分布覆盖.

路线中的公式都默认教师冻结且师生共享输出空间. 一旦教师随学生更新、教师带特权上下文或动作空间不是 token, 状态分布框架仍可使用, 但教师目标的非平稳性与对齐映射需要单独进入定义. 这些扩展不能只更换教师名称后沿用同一结论.

**状态分布偏移怎样累积。**

设学生在每个训练分布状态上的错误概率至多为 $\epsilon$. 若一次错误会把后续状态带到训练集没有覆盖的区域, 长度 $T$ 的序列损失可能按 $O(T^2\epsilon)$ 增长. 直觉是第 $t$ 步犯错后, 剩余 $T-t$ 步都可能受影响;对所有 $t$ 求和便出现二次项. DAgger 通过反复收集学习者状态并由专家标注, 把保证改善到与 $T$ 线性相关的量级.

语言模型中的「状态」就是完整 token 前缀. 学生写错一个数字、调用错误工具或选择错误证明分支, 后续条件分布都会改变. 固定答案训练只能教会模型沿正确路径继续;OPD 还能询问教师如何处理学生自己造成的局面. 但教师若无法从错误前缀恢复, 数据聚合本身不会自动解决问题.

**四种外层分布。**

固定人工回答对应经验分布 $d_{\mathcal B}$. 教师自由生成对应 $d_T$. 当前学生生成对应 $d_{\theta_k}$. 教师与学生逐步混合 roll-in 则产生 $d_{\mathrm{mix}}$. 它们可以搭配相同的局部 KL, 得到完全不同的训练样本. 一个准确的方法描述至少给出外层分布、局部损失和参数更新时谁被 stop-gradient.

严格 on-policy 要求生成策略与被更新策略一致. 分布式训练通常只能做到近似: rollout worker 持有 $\theta_k$, learner 已到 $\theta_j$. 可以用版本差 $j-k$ 做粗指标, 再用已采 token 上 $D_{\mathrm{KL}}(\pi_{\theta_k}\|\pi_{\theta_j})$ 衡量真实移动. 只要明确滞后并控制偏移, near-policy 数据仍可训练;把旧轨迹无限复用则失去 on-policy 的主要意义.

**信号轴不止一种 KL。**

硬标签只告诉学生一个 token. 教师 sampled-token log-prob 告诉学生已采动作在教师处的相对支持度. top-$k$ 给出若干主要竞争动作, 完整 logits 给出整个词表. 信息越完整, 计算和通信越重;同时也越能看见「学生应把概率从哪个错误 token 移向哪个候选」.

任务奖励属于另一条信号轴. 终局正确性可以鼓励学生超过教师, 却不提供细粒度信用分配. 过程奖励给中间步骤打分, 粒度介于终局奖励与逐 token 教师分布之间. 选择信号时应先问任务的可验证性: 数学答案可自动判定, 开放式写作很难得到可靠终局标量, 后者更依赖教师分布或偏好比较.

**一次更新的概率对象。**

rollout 阶段从行为策略 $b$ 采出 $y$. 教师在每个 $s_t$ 上给 $p_T(\cdot\mid s_t)$. learner 用当前 $q_\theta(\cdot\mid s_t)$ 计算损失. 若 $b=q_\theta$, 样本严格 on-policy;若二者不同, 需要接受偏差或使用重要性比率 $q_\theta(y_t\mid s_t)/b(y_t\mid s_t)$.

序列重要性比率是各步比率连乘. 即便单步偏移很小, 长序列乘积也会迅速趋近零或出现极端值. 所以实际方法常做逐 token 裁剪、只修正局部动作或完全停梯度. 每种处理都改变估计器, 其价值在于可控方差, 不能笼统写成「仍然无偏」.

## 3. 与 SFT、DPO、RL 的关系

SFT 的状态通常来自数据, 信号是硬 token, 更新是监督梯度. DPO 的状态与成对回答也通常离线给定, 信号是偏好差, 通过参考策略构造分类式目标. RL 的状态来自学生, 信号是环境或奖励模型给出的标量, 更新包含采样分布影响. OPD 的状态来自学生, 信号是教师的稠密动作分布;具体更新可以是停梯度局部匹配, 也可以像 MiniLLM 一样估计序列分布梯度.

这张坐标解释了方法组合. SFT 可以先扩大支持集, OPD 在学生状态上校正行为, RL 再搜索教师之外的高回报策略, DPO 则利用已有偏好对调整相对排序. 组合顺序没有普适答案, 但每次切换都改变状态分布或信号来源, 应分别做消融.

### 3.1. 教师可靠性的条件化评测

比较教师和学生各自独立答题不足以判断 OPD 是否适用. 应从学生 rollout 中截取不同深度的前缀, 标记前缀是否仍可恢复, 再测教师续写成功率、正确动作 margin 与熵. 若教师优势随错误深度迅速消失, 纯学生轨迹会产生大量低质量监督, 混入教师前缀或加入回溯机制更合理.

还要区分知识缺失与策略错误. 教师若知道事实但不能在学生混乱前缀下调用, 特权上下文可能改善教师;学生若根本没有相关 token 模式, reverse-KL OPD 又难以从零创造支持. 前者需要改教师条件, 后者需要 SFT、领域中训或更强探索.

### 3.2. 长度、EOS 与截断

EOS 是控制状态分布的关键动作. 教师比学生更偏好 EOS 时, reverse KL 会增加结束概率;教师偏好继续时则相反. 按序列求和会让长回答拥有更多损失项, 按 token 平均会改变每条样本权重. 最大长度截断又把「没有生成 EOS」与「正常结束」混在一起. 长度现象必须结合这三项解释.

可复算的诊断是按位置绘制教师与学生的 EOS log-odds 差, 再按最终长度和正确性分桶. 只看平均回答长度会掩盖两种相反变化: 一部分样本更早正确结束, 另一部分样本因重复而撞到截断上限.

## 4. 目标选择与适用边界

先确认动作空间能否比较, 再确认教师在学生状态上是否可靠, 然后选择外层状态分布. 只有这三项成立, 才值得讨论 forward KL、reverse KL 或 JSD. 散度无法补救 tokenizer 错位, 也无法把不可靠教师变成正确监督.

学生容量与初始化也会改变选择. 小学生无法覆盖教师多模态分布时, reverse KL 或 JSD 往往更现实;学生需要保留多种答案时, forward KL 的覆盖倾向更合适. 确定这些条件以后, 再选择 full-vocab、top-$k$ 或 sampled-token 估计器, 并用同一冻结 batch 比较梯度方向、方差和显存.

**状态来源决定模型会在哪些问题上被纠正, 目标分布决定纠正方向, 估计器决定这份方向还能保留多少.** 三者共同构成 OPD, 少写任何一层都会让同名实验无法复现.

### 4.1. 从占用测度看 on-policy

对有限时域生成, 可把各时刻状态分布平均成占用测度

$$
d_\pi(s)=\frac{1}{T}\sum_{t=1}^{T}\Pr_\pi(s_t=s).
$$

固定数据 KD 优化 $d_{\mathcal B}$ 上的误差, OPD 优化 $d_{\pi}$ 上的误差. 两个局部损失完全相同时, 占用测度仍会让梯度关注不同区域. 这也是「加入学生生成文本」产生收益的最小理论解释: 训练预算被移到部署策略真正访问的前缀.

混合轨迹对应 $d=(1-\lambda)d_{\mathcal B}+\lambda d_\pi$ 的近似. 注意, 逐序列混合、逐 token 混合与先采两类 batch 再拼接并不产生同一个占用测度. 序列越长, 早期一个教师动作对后续状态的影响越大. 实验报告需要写明混合粒度.

### 4.2. 状态覆盖的盲区

纯 on-policy 只看学生当前能访问的区域. 如果正确策略需要穿过学生概率极低的动作, 训练几乎不会看到那个分支. 教师在已访问状态上给再精确的分布, 也可能无法克服探索瓶颈. SFT 轨迹、教师 roll-in 或环境搜索的价值, 就是把训练状态带到学生尚未覆盖但值得学习的区域.

另一方面, 过多教师 roll-in 会隐藏学生真实错误. 合适的混合比例取决于学生成熟度: 冷启动阶段需要更多可学前缀, 后期应逐渐增加学生状态. 这一日程可由 rollout 成功率和教师在错误状态上的恢复率驱动, 比按固定步数切换更有解释力.

### 4.3. 把生成过程写成有限时域决策过程

要继续推导, 先把语言生成里的随机对象分开. 提示 $x$ 从任务分布 $p(x)$ 采样, 初始状态是 $s_1=x$. 第 $t$ 步, 策略从词表 $\mathcal V$ 选择动作 $a_t=y_t$, 环境以确定性转移 $s_{t+1}=(s_t,a_t)$ 更新前缀. EOS 动作或最大长度 $T$ 结束轨迹. 对自回归语言模型而言, 随机性只来自提示和动作采样;转移函数本身并不需要学习. 一条完整轨迹的概率是

$$
q_\theta(y\mid x)=\prod_{t=1}^{|y|}q_\theta(y_t\mid x,y_{<t}). \tag{6}
$$

教师对应 $p_T(y\mid x)$, 行为策略对应 $b(y\mid x)$. 三者可能恰好相同, 也可能由三个不同版本的模型给出. 训练记录里若只出现「student」, 很容易漏掉生成学生、正在更新的学生和损失中的旧策略其实不是同一份参数. 式 (6) 中每一个条件概率属于谁, 会直接改变梯度估计的目标.

有限时域写法还能容纳 EOS. 可以把 EOS 后的状态设为吸收态, 其后损失为零;也可以让每条序列拥有随机终止时刻 $\tau$. 第二种写法更贴近实现:

$$
J(\theta)=\mathbb E_{x\sim p(x),\,y\sim q_\theta(\cdot\mid x)}
\left[\sum_{t=1}^{\tau(y)}\ell_\theta(s_t)\right]. \tag{7}
$$

这里 $\ell_\theta(s_t)$ 可以是词表上的 KL, 也可以是采样动作的 log-ratio. 随机上限 $\tau$ 会让长度成为目标的一部分. 若直接除以 $\tau$, 优化对象又变成每条回答平均损失;长答案和短答案的相对权重随之改变. 因而「token 平均」不是无害的日志归一化, 它会改变最优策略偏好的长度分布.

状态 $s_t$ 包含完整前缀, 理论上满足马尔可夫性. 实际模型有上下文窗口, 超出窗口的早期 token 被截断, 两条不同历史可能映射到同一个可见输入. 此时 learner 面对的是部分可观测问题: 可见前缀不足以唯一确定完整生成历史. 如果任务需要早期约束, 长度截断会让教师和学生即使共享可见状态也拥有不同的隐含信息. 这类偏差不能靠改变 KL 方向消除, 只能通过保留状态、压缩记忆或重新定义任务观测处理.

**占用测度怎样把单步误差放大。**

设策略 $\pi$ 在时刻 $t$ 的状态分布为 $d_\pi^t$. 对一个有界局部代价 $c(s,a)\in[0,1]$, 总代价是

$$
J(\pi)=\sum_{t=1}^{T}\mathbb E_{s\sim d_\pi^t,\,a\sim\pi(\cdot\mid s)}[c(s,a)]. \tag{8}
$$

行为克隆只在专家分布 $d_{\pi_T}^t$ 上控制分类误差. 假设每一步在专家状态上犯错的概率为 $\epsilon$. 到时刻 $t$ 之前至少犯过一次错的概率由并集界上界为 $(t-1)\epsilon$. 一旦偏离专家轨迹, 最坏情况下后续每步都付出单位代价. 对 $t$ 求和:

$$
J(\pi)-J(\pi_T)
\leq \sum_{t=1}^{T}(t-1)\epsilon
=\frac{T(T-1)}{2}\epsilon
=O(T^2\epsilon). \tag{9}
$$

式 (9) 是最坏情况界, 不表示真实语言模型误差一定二次增长. 它揭示的是训练分布没有约束偏离后的状态. 如果错误 token 对后续没有影响, 或模型能在下一步恢复, 实际累积远小于上界. 反过来, 数学证明中的一个符号错误可能让所有后续推导失去意义, 此时二次上界的悲观性就有现实对应.

DAgger 每轮用当前学习者收集状态, 再请专家给这些状态提供动作. 若在线分类器的平均遗憾趋近零, 聚合数据中至少存在一轮策略在自身诱导分布上具有低损失. 语言模型 OPD 与这条思路相似, 但有两个差别. 第一, 教师通常给出一整个 token 分布, 监督比单个专家动作更密. 第二, 自然语言中的错误前缀未必存在唯一恢复动作, 教师也可能在分布外状态失灵. 因此 DAgger 的分布匹配动机可以迁移, 专家可靠性假设不能原封不动照搬.

从性能差异引理还能看见局部优势的作用. 令 $A_{\pi_T}(s,a)$ 表示在状态 $s$ 采取 $a$ 后继续执行教师, 相对直接执行教师的额外代价. 则有限时域下可以写成

$$
J(\pi)-J(\pi_T)
=\sum_{t=1}^{T}\mathbb E_{s\sim d_\pi^t,\,a\sim\pi(\cdot\mid s)}
[A_{\pi_T}(s,a)]. \tag{10}
$$

这说明最匹配部署目标的权重应当同时考虑学生访问概率和动作对未来的影响. 普通 token KL 只约束动作分布距离, 默认所有 token 的局部差异具有相近价值. 在格式符号、推理分支和无关措辞混在同一词表时, 这个默认并不成立. 序列级目标或任务奖励试图补上价值差异, 代价是估计方差和奖励误差都会进入训练.

**roll-in 混合不是一个单独的比例。**

「教师占比 $\beta$」至少有三种实现. 第一种按整条序列选择策略: 以概率 $\beta$ 让教师生成完整回答, 否则由学生生成. 此时占用测度近似为两种轨迹分布的凸组合. 第二种在每个 token 独立选择教师或学生动作. 早期选择会改变后续状态, 所以最终状态分布不是 $\beta d_T+(1-\beta)d_\theta$ 的简单形式. 第三种先由教师生成一段前缀, 在随机切换点交给学生;它有意让学生学习从正确中间状态继续, 却很少覆盖学生早期错误造成的区域.

以两步生成作手算. 初态 $s_1$ 上教师选择 $A$ 的概率为 $0.9$, 学生为 $0.4$. 若逐 token 以 $\beta=0.5$ 混合, 第一步选到 $A$ 的概率是 $0.65$. 第二步状态为 $s_2^A$ 的概率因而也是 $0.65$. 若按整条序列混合, 边际上仍得到 $0.65$, 但策略身份与状态相关: 到达 $s_2^A$ 后, 继续动作来自同一个先前选中的策略. 逐 token 混合会在 $s_2^A$ 再抛一次硬币. 两者第一步边际相同, 二步联合分布不同. 长序列里这种相关性会不断积累.

教师强制的另一个常见变体是 scheduled sampling: 训练时逐渐把真实前一 token 替换为模型样本. 其出发点也是暴露偏差, 但局部条件目标在混合前缀上并不必然对应任何一致的序列似然. 如果训练状态由一个策略产生, 标签却假设另一条未发生的历史, 条件分布可能互相矛盾. OPD 至少让教师真正读取当前前缀后再给分布, 因而标签与可见状态相配;教师是否懂得修复该状态仍需另外验证.

混合日程可以由两个可测量量控制. 一个是「可恢复率」: 从学生前缀交给教师继续生成, 最终任务成功的比例. 另一个是「覆盖增益」: 加入学生状态后, 相比固定数据多覆盖了多少会在部署时出现的错误类型. 可恢复率低时继续提高学生 roll-in, 只会大量采集教师也无能为力的状态;覆盖增益低时继续保留高教师比例, 又会把训练预算耗在已有正确轨迹上.

混合也会改变提示条件. 如果教师答案采用一种固定模板, 学生答案采用另一种聊天模板或推理格式, roll-in 来源可能被模型从表面标记识别出来. learner 随后学到「看到教师格式时模仿教师, 看到学生格式时做另一件事」. 在比较分布前应统一系统提示、角色 token、停止符与可见工具返回, 否则所谓状态差异掺入了协议差异.

## 5. 散度方向、支持集与容量约束

### 5.1. forward KL 与 reverse KL 的梯度到底压在哪里

在固定状态上, 令教师 logits 为 $u_i$, 学生 logits 为 $z_i$, 对应概率为 $p_i$ 与 $q_i$. forward KL 对学生 logit 的梯度很简洁:

$$
\frac{\partial D_{\mathrm{KL}}(p\|q)}{\partial z_j}=q_j-p_j. \tag{11}
$$

推导从交叉熵开始. 与 $z$ 有关的部分为 $-\sum_i p_i\log q_i$, 而 softmax 满足 $\partial\log q_i/\partial z_j=\mathbf 1[i=j]-q_j$. 代入后得到 $-p_j+q_j\sum_i p_i=q_j-p_j$. 因此教师头部 token 若被学生低估, 会产生接近 $-p_j$ 的明显梯度;教师尾部每项很小, 但词表很大时总质量仍可能可观.

reverse KL 的梯度为

$$
\frac{\partial D_{\mathrm{KL}}(q\|p)}{\partial z_j}
=q_j\left(\log\frac{q_j}{p_j}-D_{\mathrm{KL}}(q\|p)\right). \tag{12}
$$

式 (12) 的 $q_j$ 因子意味着学生几乎不访问的 token 梯度也很小. 括号里的中心化项来自 softmax 各分量相互竞争, 它保证所有 logit 梯度之和为零. 学生把较大质量放到教师低概率 token 时, $\log(q_j/p_j)$ 为正且可能很大, 该 logit 会被压低. 这解释了 reverse KL 训练早期为什么常表现出强烈的「清理学生错误尾部」倾向.

不过「forward KL 一定覆盖模式、reverse KL 一定丢模式」不能当作无条件定理. 当学生族能够精确表达教师且优化充分时, 两个 KL 的唯一全局零点都是 $q=p$. [Wu et al. (2024)](https://arxiv.org/abs/2404.02657) 进一步分析了 LLM 蒸馏中的梯度动态, 指出两者最终目标一致, 训练初期关注区域不同. 容量受限、训练轮数有限、估计器截断和优化路径共同决定最终表现. 模式说法在受限分布族的投影问题里有直觉价值, 离开这些条件就容易误导.

用三分类再算一次梯度. 取 $p=(0.8,0.15,0.05)$, $q=(0.5,0.25,0.25)$. forward KL 对三个学生 logit 的梯度由式 (11) 得到 $(-0.3,0.1,0.2)$. 它明确提升第一个 token, 同时压低后两个. reverse KL 先算

$$
D_{\mathrm{KL}}(q\|p)
=0.5\log0.625+0.25\log\frac{5}{3}+0.25\log5
\approx0.311. \tag{13}
$$

再代入式 (12), 三个梯度约为 $(-0.391,0.050,0.341)$. reverse KL 对第三个严重过量的尾部 token 压力更强, 第一项也因 softmax 守恒得到更大提升. 这个例子展示的是当前点的梯度, 不能推出整个训练过程始终保持相同比例. 当 $q$ 接近 $p$ 时, 两者的局部二阶近似都会趋向 Fisher 几何下的同一形式.

**支持集不重合时会发生什么。**

数学 KL 对零概率很敏感. 如果存在 $p_i>0,q_i=0$, forward KL 为无穷;如果存在 $q_i>0,p_i=0$, reverse KL 为无穷. 标准 softmax 在有限 logits 下给每个词表项正概率, 理论上不会精确为零. 实际训练却会用低精度、top-$k$ 截断、词表裁剪或黑盒接口, 数值支持集可以真的缺项. 此时「完整 KL」和「截断后 KL」是不同目标.

设教师只返回 top-$k$ 集合 $K_T$, 返回的概率总和为 $m<1$. 一种做法是重新归一化 $\tilde p_i=p_i/m$, $i\in K_T$. 这样得到的是教师条件在头部集合内的分布, 尾部总质量消失. 另一种做法把所有尾部并成一个 OTHER 类, 保留质量 $1-m$. 前者会人为增强头部间竞争, 后者保留「尾部整体有多少」却不知道尾部内部结构. 如果学生词表里某个错误 token 落在教师 top-$k$ 外, 只有 OTHER 类时无法单独惩罚它.

温度也会改变支持权重. 设温度为 $\tau$, 则 $p_i^{(\tau)}\propto\exp(u_i/\tau)$. $\tau>1$ 拉平教师分布, 暴露更多次优 token 的相对关系;同时让很低概率的候选获得更大总质量. 经典 KD 常给损失乘 $\tau^2$, 用于抵消 softmax 梯度随温度缩小的尺度. 对自回归 OPD, 温度还会影响 rollout 时的状态分布. 只在教师打分时升温和在学生采样时升温回答的是两个问题, 不能共用一个「temperature」字段含混记录.

tokenizer 不同会造成更根本的支持错位. 教师把「北京」编码成一个 token, 学生可能拆成两个;逐位置 KL 没有一一对应的动作. 可以让教师在学生前缀对应的文本上打分学生候选字符串, 也可以退回序列级概率或采样文本监督. 前一种方案需要计算每个学生 token 字符串在教师 tokenizer 下的若干步概率, 成本明显增加;后一种方案丢掉词表级软分布. 因此共享 tokenizer 是多数白盒 OPD 方法隐含但很强的前提.

### 5.2. 一般 $f$ 散度怎样形成共同坐标

GKD 使用 $f$ 散度把多种局部目标放进统一形式. 对凸函数 $f$ 且 $f(1)=0$, 可定义

$$
D_f(p\|q)=\sum_{v\in\mathcal V}q(v)f\!\left(\frac{p(v)}{q(v)}\right). \tag{14}
$$

取 $f(r)=r\log r$ 得 forward KL;取 $f(r)=-\log r$ 得 reverse KL. Jensen-Shannon 散度先构造 $m=(p+q)/2$, 再平均 $D_{\mathrm{KL}}(p\|m)$ 与 $D_{\mathrm{KL}}(q\|m)$. 由于 $m$ 在两者任一有质量处都为正, JSD 有界, 面对支持错位时不会像 KL 那样发散. 有界也意味着极端错误的惩罚被压缩, 稳定性与纠错力度之间存在直接交换.

总变差距离 $\frac12\sum_i|p_i-q_i|$ 直观且有界, 但绝对值在相等点不可导, 梯度也不利用概率比值的尺度. 交叉熵只保留 $H(p,q)$ 时, 若教师固定, 它与 forward KL 关于学生参数的梯度相同, 因为教师熵 $H(p)$ 是常数. 看到实现里写 cross-entropy 不能据此判断它不是 KL 蒸馏;应检查 soft target、状态来源和归一化轴.

$f$ 散度的统一形式只覆盖固定状态上的分布差. 外层状态仍可能来自数据、教师、学生或混合策略. 把式 (14) 填进式 (1) 后, 至少得到「roll-in 分布 × 局部散度」两个自由度. 若外层分布也依赖当前参数并参与求导, 还会增加第三个自由度. 同名 GKD 配置只报 $f$ 的名称, 仍不足以说明实际算法.

容量约束可以看作把教师分布投影到学生可表达集合 $\mathcal Q$. forward 投影求 $\arg\min_{q\in\mathcal Q}D(p\|q)$, reverse 投影求 $\arg\min_{q\in\mathcal Q}D(q\|p)$. 当 $p\in\mathcal Q$ 时两者都回到 $p$;当 $\mathcal Q$ 缚得很紧, 投影点才明显分离. 小模型的层数、宽度和已有表示决定 $\mathcal Q$ 的形状, 不能仅凭参数量推断哪种散度更合适. 同样规模但初始化不同的学生, 可达区域也会不同.

**序列 reverse KL 与采样梯度。**

**从序列 KL 展开到 token log-ratio。**

MiniLLM 直接考虑学生序列分布到教师序列分布的 reverse KL:

$$
\mathcal L_{\mathrm{RKL}}(\theta)
=\mathbb E_{x\sim p(x),\,y\sim q_\theta(\cdot\mid x)}
\left[\log\frac{q_\theta(y\mid x)}{p_T(y\mid x)}\right]. \tag{15}
$$

利用自回归分解, 序列 log-ratio 是单步 log-ratio 之和:

$$
\log\frac{q_\theta(y\mid x)}{p_T(y\mid x)}
=\sum_{t=1}^{\tau}
\left[\log q_\theta(y_t\mid s_t)-\log p_T(y_t\mid s_t)\right]. \tag{16}
$$

令 $r_t=\log p_T(y_t\mid s_t)-\log q_\theta(y_t\mid s_t)$, 那么最小化式 (15) 等价于最大化期望累计 $r_t$. 第一项鼓励教师认为合理的动作, 第二项相当于学生熵奖励: 因为 $\mathbb E_q[-\log q]=H(q)$. 这两个作用同时存在. 只保留教师 log-prob 会把目标改成对教师能量的强化学习, 学生可能过早坍缩;只保留熵又没有教师方向.

对式 (15) 求导, 既要对 integrand 求导, 也要对采样分布 $q_\theta(y\mid x)$ 求导. 使用 $\nabla q=q\nabla\log q$:

$$
\nabla_\theta\mathcal L
=\mathbb E_{y\sim q_\theta}
\left[
\nabla_\theta\log q_\theta(y\mid x)
\left(1+\log\frac{q_\theta(y\mid x)}{p_T(y\mid x)}\right)
\right]. \tag{17}
$$

由于 score function 的期望为零, $\mathbb E_q[\nabla\log q]=0$, 常数 1 可以作为基线消去. 再展开 $\nabla\log q(y)=\sum_t\nabla\log q(y_t\mid s_t)$ 并交换求和, 当前动作只需乘从当前到终点的 log-ratio 回报:

$$
\nabla_\theta\mathcal L
=-\mathbb E
\left[
\sum_{t=1}^{\tau}
\nabla_\theta\log q_\theta(y_t\mid s_t)
\sum_{t'=t}^{\tau}r_{t'}
\right]. \tag{18}
$$

式 (18) 展示了序列信用分配. 第 $t$ 步动作会改变所有未来状态, 因而乘上 reward-to-go. 如果训练代码在采完轨迹后只对每个位置计算完整词表 reverse KL, 并把前缀 detach, 它优化的是学生占用测度上的局部匹配近似, 没有式 (18) 的未来项. 两种方法都使用学生样本, 数学目标仍然不同.

**单步分解为什么能降低方差。**

式 (18) 的回报包含许多随机未来 token. 序列越长, 不同采样路径的总和方差越大. 一个动作的真实影响被后续大量与它弱相关的语言选择淹没. MiniLLM 的 single-step decomposition 利用教师和学生在当前状态上的完整分布, 把能够解析求和的当前项精确计算, 只把未来部分留给 Monte Carlo. 这是 Rao-Blackwell 化的思路: 对已知条件分布可以求期望的随机量先积分掉, 估计仍指向同一量, 方差通常下降.

把回报拆成当前 $r_t$ 与未来 $R_{t+1}=\sum_{t'>t}r_{t'}$. 当前动作的局部贡献可写成词表求和:

$$
g_t^{\mathrm{local}}
=-\sum_{a\in\mathcal V}q_\theta(a\mid s_t)
\nabla_\theta\log q_\theta(a\mid s_t)
\left[\log p_T(a\mid s_t)-\log q_\theta(a\mid s_t)\right]. \tag{19}
$$

若完整 logits 可得, 式 (19) 不需要真的采一个 $a$. 未来项仍依赖采取哪个动作后到达的状态, 通常只能通过 rollout 估计. 这也解释了为什么黑盒教师会显著限制 MiniLLM: 只返回一个采样文本时, 无法解析计算整个词表的局部项.

基线可以继续降方差. 对任何只依赖状态的 $b(s_t)$,

$$
\mathbb E_{a_t\sim q_\theta}
[\nabla\log q_\theta(a_t\mid s_t)b(s_t)]=0. \tag{20}
$$

所以可从 reward-to-go 减去状态基线而不改变期望. 最优标量基线与回报和 score 范数的条件期望有关, 实践中常用批均值、价值网络或逐位置均值近似. 若基线偷偷依赖当前采样动作, 式 (20) 不再自动成立;把同一批动作回报直接作为每个动作专属基线可能引入偏差.

**教师混合采样与重要性比率。**

纯学生采样可能找到教师分布里概率尚可却语义无用的短串、重复串. MiniLLM 引入 teacher-mixed sampling, 让每一步的采样分布结合教师与学生. 设行为策略为

$$
b_\alpha(a\mid s)=(1-\alpha)q_\theta(a\mid s)+\alpha p_T(a\mid s). \tag{21}
$$

$\alpha=0$ 回到纯学生采样, $\alpha=1$ 完全由教师采样. 混合提高了高质量区域的访问概率, 也让采样轨迹不再严格服从 $q_\theta$. 若仍想估计学生期望, 可使用重要性比率 $\rho_t=q_\theta(a_t\mid s_t)/b_\alpha(a_t\mid s_t)$. 因为 $b_\alpha\ge(1-\alpha)q$, 当 $\alpha<1$ 时有 $\rho_t\le1/(1-\alpha)$, 单步比率得到上界, 比从任意离线行为策略修正稳定.

序列级修正需要连乘 $\prod_{i\le t}\rho_i$. 假设每步比率只有 $1.05$, 长度 200 时乘积约为 $1.05^{200}\approx17293$. 反向稍小的比率也会迅速趋近零. 这种爆炸或消失源于长时域 off-policy 估计本身. 因而实际算法可能裁剪比率、只用单步修正或接受有偏估计. 报告「用了 importance sampling」时, 必须进一步说明比率作用于当前 token、整段前缀还是完整序列.

混合采样还有一个容易忽略的因果方向. 教师动作改变下一个状态, 所以即使对当前动作使用重要性修正, 后续状态也来自混合策略. 单步比率只修正动作边际, 没有把状态占用测度恢复成纯学生分布. 完整前缀比率理论上可以修正, 方差却随长度爆炸. 训练稳定往往来自有意接受这种偏差, 用更可学的状态换取较低方差.

**长度归一化与空回答漏洞。**

若每个 token 的教师 log-prob 都是负数, 累计值随长度通常越来越负. 奖励定义和熵项组合不当时, EOS 提前结束可以减少后续负贡献, 学生便学会输出极短甚至空回答. MiniLLM 报告的消融也观察到, 缺少长度归一化或教师混合时, reverse KL 虽然下降, 生成质量却因短、重复或无意义文本而恶化. KL 曲线变好没有保证任务行为变好.

一种长度归一化回报是

$$
\bar R_t=\frac{1}{\tau-t+1}\sum_{t'=t}^{\tau}r_{t'}. \tag{22}
$$

它把「多生成一步就多累积一项」改成剩余 token 的平均质量. 但式 (22) 也改变了原始序列 KL 的梯度权重: 早期动作和晚期动作被不同的随机分母缩放. 这个修改更像带有长度偏好的代理目标, 其合理性来自训练行为, 不是对式 (15) 的无损代数化简.

另一个办法是给正常 EOS 单独建模. 若任务有参考长度区间, 可把 EOS 前的任务完成状态作为条件, 让「已经完成后结束」得到正向信号, 「尚未回答就结束」受到惩罚. 仅对长度加固定奖励会把所有任务推向同一个长度, 开放问答和短分类显然不适合共用. 更稳妥的诊断是按任务类型、正确性和终止原因分桶观察 EOS 概率.

到达最大长度而停止的序列没有选择 EOS. 若训练器把边界位置当作正常终止, 会错误奖励撞上上限的重复回答. 轨迹分别记录两种状态: `terminated` 表示策略选择终止, `truncated` 表示外部上限切断. 两种终止原因对应不同的回报边界条件和长度统计.

### 5.3. 估计器的偏差、方差与数值行为

**full-vocab、top-k 与 sampled-token 分别保留什么。**

完整词表 KL 在每个已采状态上枚举所有动作, 局部梯度方差最低, 代价是保存或在线计算教师 logits. 设词表大小 $V$, 序列 token 数 $N$, 仅存 FP16 教师 logits 就需要约 $2NV$ 字节. $V=128000,N=4096$ 时单条序列超过 1 GB, 还没算学生 logits、梯度和通信. 实现通常边算边归约、只存 top-$k$, 或把教师与 learner 放在同一流水线上避免落盘.

top-$k$ 保存头部候选和概率, 空间降到 $O(Nk)$. 它对 forward KL 的影响取决于教师尾部总质量, 对 reverse KL 的影响还取决于学生把多少概率放在教师 top-$k$ 外. 如果只取教师 top-$k$, 学生最严重的错误 token 可能完全不在集合内. 取教师与学生 top-$k$ 的并集能覆盖双方头部, 但集合随参数变化, 截断边界带来不连续性.

sampled-token 只需记录实际动作在师生下的 log-prob, 空间 $O(N)$. 对 $a\sim q$,

$$
\mathbb E_{a\sim q}\left[\log\frac{q(a)}{p(a)}\right]
=D_{\mathrm{KL}}(q\|p). \tag{23}
$$

所以单个 log-ratio 是 reverse KL 数值的无偏样本. 但把该样本直接反向传播时必须处理「样本分布依赖参数」与 integrand 自身依赖参数两条路径. 只对 $\log q(a)$ 做普通监督梯度, 得到的未必是式 (12) 或式 (17). 无偏的损失数值估计和无偏的梯度估计是两件事.

对 forward KL, 若只能从学生采样, 可以写成重要性形式

$$
D_{\mathrm{KL}}(p\|q)
=\mathbb E_{a\sim q}
\left[\frac{p(a)}{q(a)}\log\frac{p(a)}{q(a)}\right]. \tag{24}
$$

学生漏掉而教师重视的动作恰好具有巨大 $p/q$ 比率, 同时又很难从 $q$ 采到. 估计器会呈现「大多数样本接近零, 偶尔一个样本极大」的重尾行为. 这正是从学生样本估计 forward KL 困难的原因. 从教师采样可直接得到稳定得多的样本, 但状态轨迹是否来自学生仍是另一层选择.

**stop-gradient 到底切断哪条路径。**

训练代码中至少有三处可以 stop-gradient. 第一处是教师 logits, 通常教师冻结, 因而自然不求导. 第二处是生成动作, 离散采样本来就不能通过普通反向传播;若需要考虑采样概率, 必须使用 score-function、连续松弛或其他估计器. 第三处是状态访问分布: 把 rollout 视为固定数据后, learner 只对当前状态上的条件损失求导.

令

$$
J(\theta)=\sum_s d_\theta(s)L_\theta(s). \tag{25}
$$

完整梯度分成

$$
\nabla J
=\sum_s d_\theta(s)\nabla L_\theta(s)
+\sum_s L_\theta(s)\nabla d_\theta(s). \tag{26}
$$

局部 OPD 保留第一项, 序列 policy gradient 试图估计第二项. 第一项已能改善学生实际访问状态上的动作分布, 因而不等于「没有 on-policy 作用」. 第二项才让早期动作因其会把模型带到未来高损失状态而被额外调整. 两项的方差、偏差和计算方式都不同.

若 rollout 由旧参数 $\theta_k$ 生成, 更新时为 $\theta$, 实际第一项是 $\mathbb E_{s\sim d_{\theta_k}}[\nabla L_\theta(s)]$. 只要策略变化较小, 它可以是合理近似;多轮复用后差距扩大. 可在已采动作上测量 $\log q_\theta(a_t|s_t)-\log q_{\theta_k}(a_t|s_t)$, 也可用完整 logits 估局部 KL. 版本号只表示隔了多少次更新, 不表示每次参数移动有多大.

**一个两步树的完整梯度手算。**

考虑两步二叉生成. 第一步学生以概率 $q$ 选 $A$, 以 $1-q$ 选 $B$. 若选 $A$, 第二步产生固定累计局部损失 $L_A$;若选 $B$, 损失为 $L_B$. 暂时忽略第一步损失, 目标为

$$
J(q)=qL_A+(1-q)L_B. \tag{27}
$$

直接求导得 $dJ/dq=L_A-L_B$. 如果 $L_A<L_B$, 应提高 $q$. 把 $q=\sigma(z)$ 写成 logit 参数, 则

$$
\frac{dJ}{dz}=q(1-q)(L_A-L_B). \tag{28}
$$

现在把采样分布冻结, 只在第二步状态上优化局部损失. 第一步 $z$ 不参与第二步 logits 的计算, 梯度为零. learner 可以分别改善到达 $A$ 或 $B$ 后的行为, 却不会因为 $B$ 分支更难修复而降低第一步选 $B$ 的概率. 完整序列梯度通过 score-function 恢复式 (28).

取 $q=0.4,L_A=0.2,L_B=1.2$, 则 $J=0.8$, $dJ/dz=0.4\times0.6\times(-1)=-0.24$. 梯度下降会增加 $z$ 和 $q$, 偏向较低损失的 $A$. 单次 Monte Carlo 若采到 $A$, score 为 $\partial\log q/\partial z=1-q=0.6$, 乘损失得到 $0.12$;采到 $B$, score 为 $-q=-0.4$, 乘损失得到 $-0.48$. 两者按 $0.4/0.6$ 加权, 期望 $0.4(0.12)+0.6(-0.48)=-0.24$, 与解析梯度一致, 但单样本方向会波动.

加入基线 $b=J=0.8$ 后, 采到 $A$ 的估计为 $0.6(0.2-0.8)=-0.36$, 采到 $B$ 为 $-0.4(1.2-0.8)=-0.16$. 期望仍为 $-0.24$, 两个样本差距由 $0.60$ 缩到 $0.20$. 这个手算显示基线只移除与动作无关的共同部分, 不改变哪个分支更好. 在长文本中, 合理基线要估计每个前缀后续 log-ratio 的条件均值.

**数值精度、mask 与位置权重。**

教师概率很小时, 直接先做 softmax 再取对数可能下溢. 稳定实现应使用 log-softmax, KL 也尽量在 log 空间组合. 混合精度训练中, 归约词表维度的求和可提升到 FP32. 否则数万个很小项累加会有明显舍入误差, 尤其温度较高、分布较平时更突出.

mask 错位会制造看似正常的下降曲线. 因果语言模型输入 token $y_t$ 用于预测 $y_{t+1}$, 教师和学生 logits 必须与目标 token 向左或向右正确对齐. 提示部分通常不计回答损失, 但提示末 token 对第一个回答 token 的预测位置必须保留. padding、EOS 和截断位置还要分别处理. 最简单的验证是构造三个 token 的人工样本, 手工写出每个位置应比较的目标, 再逐位置打印损失.

位置平均也会改变样本权重. 若先对每条序列取 token 均值再对 batch 平均, 每条序列权重相同;若把所有有效 token 放在一起平均, 长序列权重更大. 两者在长度分布很宽时差别明显. 若任务由很多短分类和少量长推理组成, token 全局平均可能让长推理主导梯度. 应根据任务采样意图选择, 并把分母写进目标定义.

**教师能力、恢复性与反例。**

**强教师在学生状态上也可能很弱。**

教师在标准基准上的独立生成分数, 测的是 $s\sim d_T$ 或数据提示上的能力. OPD 需要的是教师在 $s\sim d_S$ 上给出有用条件分布. 学生前缀可能语义矛盾、格式破损、引用了不存在的变量, 这些状态离教师训练分布更远. 一个整体更强的教师, 未必比经过错误恢复训练的较小教师更适合作为 OPD 标注器.

可恢复性可以通过「接管实验」测量. 从学生轨迹在位置 $t$ 截断, 让教师从该前缀继续生成若干次, 用任务验证器测成功率 $R(t,e)$, 其中 $e$ 是此前错误类型. 同时记录教师下一动作熵、正确动作 margin 和不同采样间一致性. 若错误一出现 $R$ 就接近零, 继续对这些状态做局部 KL 只是在学习教师的猜测. 若 $R$ 随深度缓慢下降, 学生状态监督更有价值.

恢复率也不能单独解释监督质量. 教师可能通过完全改写答案恢复任务, 但 token 级分布在当前格式下偏好结束当前片段再重启. 学生容量不足时, 它只能学到表面转折词, 学不到完整重规划. 因而还应比较教师恢复轨迹的编辑距离、剩余长度和策略复杂度. 教师能做到与学生能模仿是两层条件.

特权教师带来另一种错配. 教师若看到参考答案、检索结果或隐藏环境状态, 其下一 token 分布可能依赖学生部署时不可见的信息. 蒸馏可以把部分特权知识压入参数, 但在每个实例都需要新隐藏信息时, 学生没有足够条件变量重建教师决策. 这会表现为同一可见状态对应互相冲突的教师标签, 条件熵存在不可消除的下界.

**四个能推翻直觉的极端例子。**

第一个例子是确定性教师. 若教师对唯一 token 的概率为 1, reverse KL 对学生任何其他正概率都趋向无穷, forward KL 只含 $-\log q(a^*)$. 数值截断后两者都强烈推动同一 token, 所谓模式覆盖差异几乎没有解释力. 这时优化稳定性主要由 label smoothing、温度和有限精度决定.

第二个例子是学生支持缺失. 假设正确推理必须在第一步选择 $A$, 学生初始化给 $q(A)=10^{-12}$. 纯学生 sampled-token reverse KL 在可承受的样本数内几乎看不到 $A$, 即使教师给 $p(A)=0.9$ 也无法从样本中传递这一信息. full-vocab forward KL 会直接产生约 $-0.9$ 的 logit 梯度. 教师 roll-in、SFT 或提高采样温度也能把 $A$ 带入训练. 「on-policy 更贴近部署」在这里成立, 却不足以解决探索.

第三个例子是不可恢复前缀. 学生先输出「设 $2+2=5$」, 后续任务要求沿这个等式证明结果. 教师可能选择纠正前提、拒绝继续或勉强遵循错误假设. 三种行为都可能在不同训练语料中出现, 形成高熵分布. 局部模仿会教会学生处理错误后的语言姿态, 但降低第一次算错概率仍需要把最终失败信用传回早期动作, 或直接在正确状态上强化算术知识.

第四个例子是多答案任务. 教师对两种同样正确的写法各给接近一半概率, 小学生只能稳定表达其中一种. reverse 投影可能选择一条路线, forward 投影会努力覆盖两者并在容量不足时产生折中. 对创意写作, 保留多样性可能有价值;对要求唯一格式的工具调用, 集中到一个可靠模式反而更好. 不能脱离任务效用判断「丢模式」究竟是缺陷还是容量分配.

**教师错误会怎样被 OPD 放大。**

固定数据蒸馏至少把教师暴露在人工选择的状态上. OPD 让学生不断生成新状态, 教师偏差可能与学生偏差形成反馈. 若教师在某类错误前缀上总倾向给出看似流畅的补丁, 学生学会该补丁后更容易进入相邻状态, 下一轮数据又提高这类样本比例. 这是一种闭环选择偏差, KL 持续下降也可能伴随任务分布变窄.

可以用冻结锚点集监控闭环. 锚点同时包含正常数据前缀、常见学生错误、对抗前缀和不可恢复状态. 每轮测教师—学生散度、任务正确性、熵与状态类别占比. 如果在线 rollout 指标改善而锚点上的正确状态性能下降, 学生可能只适应了近期状态. 锚点不参与梯度, 才能作为相对稳定的参照.

多教师可以降低单一偏差, 但聚合方式会带来新的目标. 概率算术平均倾向保留任一教师支持的 token;logits 平均相当于几何组合, 任一教师给极低概率都能强烈压制候选;多数投票又丢失置信度. 教师之间若共享训练数据和错误, 数量增加也不会产生独立证据. 选择聚合前要先决定希望保守求交集, 还是扩大可接受答案并集.

**把任务奖励接进来时发生了什么。**

GKD 允许把蒸馏与 RL 目标组合. 一个简单形式是

$$
J_{\mathrm{mix}}(\theta)
=\lambda\,\mathbb E_{s\sim d_\theta}[D_f(p_T\|q_\theta)]
-(1-\lambda)\,\mathbb E_{y\sim q_\theta}[R(x,y)]. \tag{29}
$$

$\lambda$ 大时学生受教师约束, $\lambda$ 小时更愿意探索教师之外的高奖励行为. 两项的数值尺度不同, 直接设 $\lambda=0.5$ 不代表梯度贡献各半. 更有意义的诊断是记录两项梯度范数和夹角. 若夹角长期为负, 说明教师偏好与任务奖励在当前状态上冲突;简单相加会让训练速度变慢或来回摆动.

任务奖励可让学生超过教师, 前提是验证器确实衡量目标. 若奖励只检查最终数字, 学生可能省去必要解释;若奖励检查字符串格式, 学生可能学会模板而忽略内容. 蒸馏分布在这里提供行为先验, 限制奖励漏洞. 但教师本身也可能带来冗长或固定风格, 因而正则强度需要按任务与训练阶段调整.

还可把教师 log-ratio 解释为稠密奖励, 把环境奖励放在终点. 总回报为 $\sum_t r_t^{T}+\eta R_{\mathrm{env}}$. 这比只在终点给奖励更容易分配信用, 但教师项每个 token 都累积, 长序列中可能压过一次终局奖励. 对两项分别做尺度归一化、按长度校准并报告实际梯度贡献, 才能知道组合目标在优化什么.

### 5.4. 从目标定义走到可复现实验

**一个完整方法至少需要九个概率对象。**

复现 OPD 时可以沿一条生成轨迹逐项写下对象. 提示来自哪个分布;roll-in 用哪个策略和温度;教师读取什么上下文;教师输出完整 logits、top-$k$ 还是采样文本;学生损失采用哪种散度;状态分布是否参与求导;行为策略与 learner 相差多少版本;序列如何终止与归一化;任务奖励怎样进入. 这些项目不是额外说明, 合在一起才定义了算法.

同一句「在学生生成上做 reverse KL」可能对应至少三种训练. 其一, 学生先生成文本, 冻结文本后逐位置计算 full-vocab reverse KL. 其二, 从学生逐 token 采样, 用采样 log-ratio 构造局部 policy gradient. 其三, 优化完整序列 reverse KL, 回报含未来 log-ratio 并配合方差降低. 三者共享状态来源和散度名称, 梯度却不相同.

数据记录应足以重建损失. 每条轨迹至少保留提示版本、token ids、attention mask、行为策略版本、采样参数、终止原因与教师版本. 若要做 off-policy 修正, 还需行为策略对已采动作的 log-prob. 若要重算 full-vocab KL, 需要教师 logits 或可再次查询的确定接口. 只保存最终文本会丢掉 tokenizer、采样和旧策略概率信息.

**公平比较需要固定哪些量。**

比较监督 KD、GKD 和序列 reverse-KL 时, 固定 optimizer step 并不公平. GKD 额外消耗学生生成和教师打分, MiniLLM 还可能多次采样. 可选口径包括总训练 FLOPs、教师前向 token 数、学生更新 token 数、GPU 小时和最大显存. 每个口径回答的问题不同: 部署团队更关心达到目标质量的总成本, 算法消融更关心相同教师信息量下目标本身的效果.

生成评测必须固定解码设置. reverse KL 可能降低熵, greedy 分数上升而 pass@k 或多样性下降;forward KL 可能保留更多候选, 高温采样受益. 至少同时报告 greedy 或低温的单次质量、固定样本数的 pass@k、长度分布与重复率. 开放式任务还要防止评审模型偏好教师风格, 否则蒸馏越像教师越容易被同源评审奖励.

状态覆盖也需要对照. 可以固定一批学生轨迹, 分别在数据前缀、教师前缀与学生前缀上评估局部 KL 和任务恢复率. 如果某方法只在自身采样状态上 KL 很低, 换到共同状态集便失去优势, 改善可能来自访问了更容易的状态. 共同状态集与各自 on-policy 状态集要同时报告.

**消融应切断一条机制而不是换一堆配置。**

验证状态分布作用时, 保持散度、教师、更新 token 数和优化器相同, 只把前缀从固定数据换成学生生成或混合生成. 验证散度方向时, 固定同一批冻结状态并使用完整词表, 防止采样方差混进结论. 验证采样梯度时, 在同一学生轨迹上比较局部 stop-gradient 与包含 reward-to-go 的估计, 同时匹配梯度尺度.

长度归一化消融必须按终止原因分桶. 若移除后平均长度变短, 要继续看正确结束、空回答和截断的比例. 教师混合消融则需报告混合系数、混合粒度与重要性修正. 单步分解消融除了任务分数, 还应比较梯度方差或多随机种子曲线;它的直接机制是降方差, 只看最终均值可能漏掉作用路径.

一个反事实检查是交换教师. 若更强教师在标准答案上更好, 在学生错误状态上却带来更差 OPD, 说明瓶颈在恢复性而非独立任务能力. 另一个检查是冻结 rollout 数据多训练几轮. 如果继续优化局部 KL 能提高离线拟合却损害新 on-policy 轨迹, 状态陈旧已经成为主要误差.

**诊断矩阵比单条 KL 曲线更有信息。**

训练诊断可以按「状态来源 × 状态深度 × 状态质量」建矩阵. 来源分数据、教师、当前学生和旧学生;深度按回答位置分桶;质量按可恢复、已错误但可修复、不可恢复划分. 每个格子记录教师熵、师生 KL、正确动作 margin、学生更新后的恢复率. 这张矩阵能区分学生在哪些区域真正追上教师, 哪些区域只是降低了无意义的分布差.

梯度侧至少记录范数、极值、位置分布和不同目标间夹角. reverse KL 的尾部比值可能产生少数大梯度;importance ratio 又会放大旧策略样本. 只看平均 loss 会把这些事件淹没. 按 token 位置画梯度范数, 常能发现第一个回答 token、EOS 或长序列尾端被异常放大.

概率校准也应条件化. 总体 ECE 把不同任务和位置混在一起, 语言模型词表又极大. 可分别看可验证答案的序列置信度、正确 token 的 margin、EOS 概率和采样答案的经验成功率. MiniLLM 报告 reverse-KL 学生较若干基线有更好的校准表现, 这是特定训练与评测设置的实证结果, 不能直接推成 reverse KL 在所有 OPD 配置下都改善校准.

**选择路线时先回答四个实质问题。**

第一, 学生部署时最常进入而固定数据缺少的状态是什么. 如果主要问题是轻微格式漂移, 局部 GKD 已可能覆盖;如果是早期推理分支导致的长程失败, 序列信用分配或环境奖励更重要. 第二, 教师在这些状态上是否仍有优势. 没有恢复能力的教师无法靠更多查询变成好监督.

第三, 可获得什么概率接口. 完整 logits 支持精确局部 $f$ 散度和单步解析分解;top-$k$ 需要处理尾部质量;只有文本或采样 token 时, 目标选择会受到估计器限制. 第四, 学生当前支持集是否覆盖教师关键动作. 若缺少, 纯学生采样很难发现, 应先用 SFT、教师 roll-in 或更强探索扩展支持.

回答完四项后, 方法选择会自然收敛. 教师在学生状态上可靠、完整 logits 可用、希望先得到稳定基线时, 采用学生 roll-in 加局部 GKD. 需要让早期动作承担未来分布差, 并能承受 Monte Carlo 方差时, 再引入序列 reverse-KL 梯度. 任务有可信验证器且目标允许超过教师时, 将环境奖励与蒸馏约束组合. 这些路线可以逐级增加复杂度, 每一级都能用前述消融确认新增机制是否真的起作用.

**OPD 的完整单位是一条闭环: 策略产生状态, 教师评价动作, 估计器再把评价传回参数.** 状态分布决定看见哪些错误, 条件散度决定当前状态怎样比较, 采样梯度决定未来后果能否返回早期动作. 三者的定义完整, 「on-policy distillation」才对应一个可分析、可复现的训练目标.

**条件 KL 的链式法则给出最干净的参照。**

序列分布的 KL 可以严格分解成沿某一方轨迹访问状态时的条件 KL. 对 forward KL, 从教师序列分布出发:

$$
\begin{aligned}
D_{\mathrm{KL}}(p_T(y\mid x)\|q_\theta(y\mid x))
&=\mathbb E_{y\sim p_T}\left[
\log\frac{p_T(y\mid x)}{q_\theta(y\mid x)}
\right]\\
&=\sum_{t=1}^{T}\mathbb E_{s_t\sim d_{p_T}^t}
\left[D_{\mathrm{KL}}(p_T(\cdot\mid s_t)\|q_\theta(\cdot\mid s_t))\right].
\end{aligned} \tag{30}
$$

第一行代入自回归乘积, log 把乘积变为求和;再对前缀边缘分布取期望, 就得到第二行. 因而「教师轨迹上的逐 token forward KL」并非随意代理, 它正好等于序列 forward KL. 如果把外层状态换成数据前缀, 只有当数据确实由教师序列分布采样时才保持等价;人工答案分布和教师分布通常不完全相同.

reverse KL 同样有链式分解:

$$
D_{\mathrm{KL}}(q_\theta(y\mid x)\|p_T(y\mid x))
=\sum_{t=1}^{T}\mathbb E_{s_t\sim d_{q_\theta}^t}
\left[D_{\mathrm{KL}}(q_\theta(\cdot\mid s_t)\|p_T(\cdot\mid s_t))\right]. \tag{31}
$$

式 (31) 解释了一个容易混在一起的问题: 序列 reverse KL 的数值可以写成学生状态上的局部 reverse KL 之和, 但对参数求导时, 外层 $d_{q_\theta}^t$ 也依赖参数. 如果每轮用当前学生采状态, 然后把状态冻结做若干局部梯度步, 算法在数据层面逼近式 (31), 单步梯度仍漏掉占用测度导数. 当每轮更新很小、频繁刷新轨迹时, 这种交替优化可能工作良好;它与一次无偏估计完整梯度仍不是同一个算法.

两条链式法则还说明散度方向与自然 roll-in 的配对. 精确序列 forward KL 的自然状态分布是教师, 精确序列 reverse KL 的自然状态分布是学生. GKD 故意打破这组配对, 允许学生状态上计算 forward KL、混合状态上计算 JSD 等目标. 这种自由度很实用, 但得到的是广义局部匹配目标, 不应自动冠以某个序列 KL 的精确分解.

考虑学生状态上的 forward KL:

$$
J_{SF}(\theta)=\sum_t\mathbb E_{s_t\sim d_{q_\theta}^t}
[D_{\mathrm{KL}}(p_T(\cdot\mid s_t)\|q_\theta(\cdot\mid s_t))]. \tag{32}
$$

它把教师的覆盖型局部信号放到学生实际访问区域. 式 (32) 既不同于式 (30), 也不同于式 (31). 优点是教师头部动作即使学生尚未采到, 仍通过 full-vocab 梯度进入更新;风险是教师在学生错误前缀上的整个分布可能不可靠. 这个组合正好展示三条轴的独立性: 学生 roll-in 不强迫使用 reverse KL.

### 5.5. DAgger 假设、参数耦合与状态加权

**DAgger 类保证依赖哪些假设。**

DAgger 的核心保证常被压缩成「在线收集学习者状态后, 误差从二次累积变成线性累积」. 完整条件包括有界代价、可查询专家、在线学习器低遗憾以及策略类中存在表现足够好的比较策略. 若专家在学习者状态上不能给出合理动作, 聚合再多数据也无法满足监督假设. 若学生容量不足, 在线损失最低的策略仍可能离教师很远.

在第 $i$ 轮, 令 roll-in 策略为 $\pi_i$, 收集状态分布 $d_{\pi_i}$, 定义损失

$$
\ell_i(\pi)=\mathbb E_{s\sim d_{\pi_i}}
[\mathbb E_{a\sim\pi(\cdot\mid s)}Q_{\pi_T}(s,a)]. \tag{33}
$$

$Q_{\pi_T}(s,a)$ 表示采取 $a$ 后再跟随教师的未来代价. 在线遗憾为

$$
\mathrm{Regret}_N
=\sum_{i=1}^{N}\ell_i(\pi_i)
-\min_{\pi\in\Pi}\sum_{i=1}^{N}\ell_i(\pi). \tag{34}
$$

若平均遗憾 $\mathrm{Regret}_N/N$ 很小, 聚合轮次中存在一个策略在这些学习者分布上接近策略类内最优者. 语言模型蒸馏通常没有直接得到 $Q_{\pi_T}$, 而是使用下一 token 的教师分布作为代理. 局部 KL 与未来任务代价只有在教师动作优势和 token 分布距离存在合理联系时, 才能继承类似解释.

一个反例能看出差距. 某状态有两个 token $a,b$, 教师给 $(0.51,0.49)$. 选择 $a$ 会进入可完成任务的分支, 选择 $b$ 会在十步后必然失败. 局部 KL 认为两者几乎等价, $Q$ 代价却相差很大. 如果教师分布来自普通语言建模而没有经过任务最优训练, 概率 margin 不一定编码长程价值 margin. 反过来, 教师给某个措辞很低概率也可能只是风格偏好, 对任务成功毫无影响.

DAgger 还常用逐轮衰减的专家混合系数, 保证训练早期不至于进入任意坏状态. 在语言生成里, 专家动作插入会改变文字风格和隐藏语义, 后续学生看到的是一种人工拼接轨迹. 拼接点附近的条件分布可能比纯教师、纯学生都少见. 如果每 token 混合, 应单独检查切换次数与教师恢复率;降低 $\beta$ 不能只按轮数机械推进.

专家查询成本在 LLM 中也更突出. DAgger 的理论把专家标签当作可得, 但白盒教师 full-vocab 前向可能占主要训练成本. 只标注不确定状态、只保存头部 logits或由小教师预筛选, 都会改变损失采样分布. 若按学生熵选择状态, 得到的是主动查询目标;训练时需考虑高熵状态被过度采样, 否则模型会牺牲常见低熵位置.

**参数共享让逐位置目标发生耦合。**

前面的局部公式把每个状态的分布当作可独立调整, 真实 Transformer 的参数在所有状态和位置间共享. 在一个错误前缀上降低 token $v$ 的 logit, 可能同时改变数百万正常前缀上的 $v$. 因而「只训练学生访问状态」并不意味着影响只留在这些状态. 表示泛化可以把恢复能力迁移到相似前缀, 也可能造成遗忘.

设每个状态的学生 logits 为 $z_\theta(s)$. 两个状态 $s,s'$ 的损失梯度内积

$$
G(s,s')=\nabla_\theta L(s)^\top\nabla_\theta L(s') \tag{35}
$$

可以近似描述相互作用. $G>0$ 时一次更新同时降低两处损失, $G<0$ 时两处冲突. 学生错误状态与标准数据状态若长期负相关, 增加 OPD 比例可能损害基础能力. 混入 SFT 数据的作用不只是「防止跑偏」, 它向优化器持续提供正常状态梯度, 平衡共享参数上的冲突.

神经切线近似下, 一个状态的 logit 更新可写成

$$
\Delta z(s')\approx-\eta J_\theta(s')J_\theta(s)^\top
\nabla_{z(s)}L(s), \tag{36}
$$

其中 $J_\theta(s)=\partial z_\theta(s)/\partial\theta$. 核矩阵 $J(s')J(s)^\top$ 决定从训练状态向其他状态传播的方向. 学生容量、参数高效微调方式和冻结层数都会改变这个核. 同一种 OPD 损失用于全量微调与 LoRA, 可能呈现不同的状态泛化, 原因不只在可训练参数数量.

参数共享还解释了为什么极端错误状态未必值得大量训练. 这些状态与正常部署流量距离很远, 梯度却会经共享词嵌入、注意力和输出头传播到常见状态. 若教师在极端状态上不稳定, 影响可能覆盖远大于样本占比. 可按状态严重度设权重, 把几乎不可恢复的前缀用于评测和拒绝策略训练, 而不是全部送进 token 分布拟合.

灾难性遗忘的检查不能只看初始 SFT loss. OPD 改变生成状态后, 即使固定数据上的 teacher-forcing loss只小幅变化, 自由生成行为也可能显著漂移. 应同时跑固定提示的生成评测和局部概率评测. 前者能看见误差累积, 后者能定位哪个位置的概率发生变化.

**状态抽样本身也是优化权重。**

一批轨迹包含的 token 并非独立样本. 同一回答内相邻状态共享几乎全部前缀, 梯度高度相关. 若按 token 均匀抽样, 长回答贡献更多状态;若按序列均匀抽样再平均, 每个提示贡献相同. 如果长回答恰好更难, 两种方案又把长度与难度耦合. 训练目标必须明确权重落在 prompt、sequence 还是 token 上.

设数据集中第 $i$ 条序列长度为 $T_i$, 局部损失为 $L_{it}$. 序列均权目标是

$$
J_{\mathrm{seq}}=\frac1B\sum_{i=1}^{B}\frac1{T_i}\sum_{t=1}^{T_i}L_{it}, \tag{37}
$$

token 均权目标是

$$
J_{\mathrm{tok}}=\frac{\sum_i\sum_tL_{it}}{\sum_iT_i}. \tag{38}
$$

若两条序列长度分别为 10 和 100, 式 (37) 各给一半权重, 式 (38) 给长序列约 $90.9\%$ 权重. 两种归约对应不同的风险定义. 选择应与部署请求相符, 不应由方便的张量归约方式偶然决定.

位置抽样也会偏向某些机制. 只取每条轨迹末尾若干 token, 更关注终止和长程累积后的状态;均匀取位置则早期位置因每条序列都有而占稳定比例;按教师—学生 KL 采样会集中于分歧最大处. 按 KL 采样类似 hard-example mining, 可以提高单位 token 信号, 但大 KL 可能源于教师错误、模板差异或极低概率数值噪声.

优先级抽样需要重要性校正才能保持原目标. 若状态 $s$ 按概率 $r(s)$ 采样, 原本希望在 $d(s)$ 下取期望, 权重应含 $d(s)/r(s)$. 精确 $d(s)$ 通常未知, 实践会用未归一化优先级和裁剪权重. 这再次形成偏差—方差交换: 完全校正可能被少数低采样概率状态支配, 不校正则优化优先级重加权后的新目标.

**黑盒教师把哪些目标关掉了。**

黑盒 API 若只返回生成文本, 最直接的做法是 sequence-level KD: 把教师文本当硬标签做 SFT. 状态主要来自教师, token 监督只有一个样本. 若 API 允许给任意学生前缀续写, 可以在学生状态上请求教师样本, 形成 DAgger 式硬动作标注. 多次查询同一状态能近似教师分布, 但词表巨大, 尾部估计需要不可接受的样本量.

若接口返回已生成 token 的 log-prob, 可以估计教师对行为动作的支持, 构造 sampled reverse-KL 或教师奖励. 但没有未采动作概率, 不能精确算 full-vocab forward KL, 也不能执行式 (19) 的解析局部求和. 若只返回 top-$k$ log-prob, 可以在头部并集上近似, 仍需处理尾部总质量和学生错误 token不在教师列表中的情况.

查询教师时的解码参数与打分参数也要分开. 生成接口中的温度改变采样分布;返回 log-prob 有时基于原始模型温度, 有时基于采样后分布. presence penalty、frequency penalty 和安全过滤会进一步改变可见概率. 如果这些处理没有记录, 收集到的「教师分布」已经是产品策略与基础模型的组合.

黑盒教师还可能随服务版本更新. 同一前缀在不同日期得到不同模型或安全策略的响应, 聚合数据不再来自固定教师 $p_T$. 可以保留请求时间、模型版本和少量锚点响应, 检测分布漂移. 若版本无法固定, 更适合把教师当非平稳反馈源, 不宜把训练曲线解释为收敛到某个静态 KL 最优点.

### 5.6. 从局部改善到任务提升

局部 KL 降低要转化成任务提升, 至少需要三层联系. 第一层是概率校准: 教师在当前状态上给高概率的动作确实更可能正确. 第二层是动态稳定: 当前动作更接近教师后, 后续状态也进入教师擅长的区域. 第三层是容量迁移: 对训练状态的更新能泛化到未见提示, 且不会破坏已有能力. 任一层断开, KL 都可能下降而任务不变.

第一层可以用教师概率与可验证动作结果的可靠性图检查. 把候选动作按教师概率分桶, 比较进入该动作后的任务成功率或局部验证率. 如果高概率只代表语言自然, 与推理正确性相关很弱, 教师分布更适合做风格先验而非主要奖励. 数学与代码任务有验证器时尤其容易做这种条件化分析.

第二层可以用干预测试. 在某个状态把学生原本动作替换为教师 top-1, 其后仍由学生继续, 比较最终成功率. 如果单步替换很少改善, 可能需要连续多个教师动作、状态回退或更长程训练. 这能区分「学生在一个关键岔路口选错」与「整个后续策略都缺能力」.

第三层可用留出状态族检查. 根据错误类型或提示领域分组, 只在部分组做 OPD, 看相邻组是否受益. 若收益局限于近乎重复的前缀, 模型只在记忆轨迹;若正常状态下降, 说明梯度冲突显著. 这些现象决定下一步应扩大状态多样性、混入 SFT, 还是调整可训练参数范围.

任务指标本身也可能掩盖概率改善. 精确匹配只看最终字符串, 学生从完全错误提升到接近正确仍记为零;pass@k 会受到熵与采样温度影响;评审模型分数可能偏好教师风格. 因而最有解释力的证据通常是「目标项下降 + 对应机制指标改善 + 独立任务指标提升」同时出现. 单独一条曲线只能证明优化器改变了它所测的量.

**最终选择可以落到一张机制表。**

| 训练配置 | 状态来自哪里 | 当前状态的信号 | 未来影响 | 主要优势 | 主要风险 |
|---|---|---|---|---|---|
| 固定数据 soft KD | 数据或参考答案 | full-vocab forward KL | 无 | 稳定, 可直接监督教师头部 | 部署状态覆盖不足 |
| 学生 roll-in GKD | 当前或近端学生 | 可选 $f$ 散度 | 通常停止 | 覆盖学生真实错误, 容易接入 SFT | 教师在错误状态失灵, 轨迹陈旧 |
| 混合 roll-in GKD | 教师、数据与学生混合 | 可选 $f$ 散度 | 通常停止 | 冷启动更稳, 可调覆盖 | 混合粒度改变联合分布 |
| MiniLLM 式序列 RKL | 学生或教师混合行为策略 | token log-ratio 与解析局部项 | reward-to-go | 早期动作承担后续差异 | 高方差、长度漏洞、off-policy 偏差 |
| OPD 加任务 RL | 学生 | 教师分布与环境奖励 | 由 RL 估计 | 可探索教师之外的高回报策略 | 验证器漏洞与梯度冲突 |

表中的「未来影响」指梯度是否显式把后续结果归因给当前动作, 不等于模型没有看到未来 token. teacher-forcing 的反向传播会经过同一序列中各位置的网络计算, 但因果 mask 下, 后面位置的损失不会通过离散 token 选择回到较早采样动作. score-function 或其他序列梯度估计负责补的是这条离散因果路径.

路线升级应由观测到的瓶颈推动. 固定 KD 在学生自由生成时明显退化, 才需要学生 roll-in;纯学生状态不可恢复比例过高, 才加入教师混合;局部 KL 降低但早期分支错误不变, 才考虑未来回报;教师约束限制了可验证任务上限, 才提高环境奖励权重. 每一步都对应一个可测现象, 避免把复杂算法当作默认配置.

反过来, 简单方法可能已经足够. 学生初始化接近教师、任务回答短、部署状态与数据状态重合、教师 logits 完整可得时, 固定数据 forward KL 往往具备很强基线. 此时 OPD 的额外 rollout 可能只重复已覆盖状态. 「on-policy」描述数据来源, 不自动代表更高样本效率或更好最终性能.

这套判断也适用于 token 之外的动作. 工具调用可以把动作定义为结构化 API;视觉语言模型可把状态加入图像与历史操作;agent 的状态还包含环境观测. 只要明确状态、动作、教师条件分布和轨迹转移, 占用测度与采样梯度的分析仍成立. 动作空间无法与教师逐项对齐时, 则应选择序列行为、价值或可验证结果作为监督, 不能硬套 token KL.

**熵项、交叉熵与教师能量可以拆开看。**

reverse KL 有一个很有用的分解:

$$
D_{\mathrm{KL}}(q\|p_T)
=-H(q)+H(q,p_T), \tag{39}
$$

其中 $H(q)=-\sum_aq(a)\log q(a)$ 是学生熵, $H(q,p_T)=-\sum_aq(a)\log p_T(a)$ 是用学生分布加权的教师负对数概率. 第一项鼓励学生保留熵, 第二项让学生把质量放到教师高概率区域. 两项都依赖学生, 相互制衡后才得到 reverse KL. 把教师 log-prob 当奖励但漏掉 $-\log q$ 项, 相当于删除熵贡献;再额外加一个固定熵系数, 则优化的是温度变化后的新分布.

具体地, 考虑目标

$$
J_\alpha(q)=\mathbb E_{a\sim q}[-\log p_T(a)]-\alpha H(q). \tag{40}
$$

在概率单纯形上用拉格朗日乘子求最优解. 对 $q(a)$ 求导并令零, 可得

$$
q^*(a)=\frac{p_T(a)^{1/\alpha}}{\sum_b p_T(b)^{1/\alpha}}. \tag{41}
$$

$\alpha=1$ 时恢复教师分布;$\alpha<1$ 时分布更尖锐;$\alpha>1$ 时更平. 因而熵系数不是单纯的稳定旋钮, 它改变了学生要逼近的教师温度. 如果训练里另有采样温度, 两种温度会同时影响状态分布和目标分布, 需要分别记录.

forward KL 也可写成教师交叉熵减教师熵:

$$
D_{\mathrm{KL}}(p_T\|q)=H(p_T,q)-H(p_T). \tag{42}
$$

教师固定时, 第二项对学生梯度为零, 所以 soft-label cross-entropy 与 forward KL 更新一致. 数值报告却差一个教师熵. 不同状态上的教师熵不同, 直接比较 cross-entropy 会把「教师本来就不确定」混进学生误差;报告 KL 能扣除这部分不可约项. 这在学生错误前缀上尤其重要, 因为教师熵常随状态破损而升高.

教师温度同样能从式 (41) 理解. 把 $p_T$ 替换为 $p_T^{1/\tau}/Z$ 等价于调平能量差. 高温教师把更多尾部关系暴露出来, 但若学生容量有限, 它也要求学生把概率分给更多模式. 对 reverse KL, 再加熵系数会形成复合指数;不把两者写开, 很难判断最终目标的尖锐程度.

**轨迹陈旧可以用信任域理解。**

异步 OPD 中, rollout 策略 $q_{\mathrm{old}}$ 与 learner $q_\theta$ 不同. 一个实用思路是限制两者在已访问状态上的平均 KL:

$$
\bar D=\frac{1}{N}\sum_{t=1}^{N}
D_{\mathrm{KL}}(q_{\mathrm{old}}(\cdot\mid s_t)\|q_\theta(\cdot\mid s_t)). \tag{43}
$$

$\bar D$ 小表示局部动作分布未移动太远, 但不能严格保证状态占用测度接近. 长序列里许多小变化仍会累积. 利用 Pinsker 不等式, 单步总变差距离满足

$$
\mathrm{TV}(q_{\mathrm{old}},q_\theta)
\le\sqrt{\frac12D_{\mathrm{KL}}(q_{\mathrm{old}}\|q_\theta)}. \tag{44}
$$

若每步 KL 上界为 $\delta$, 粗略并集界会让长度 $T$ 的轨迹分布差随 $T\sqrt{\delta}$ 增长. 这仍是宽松上界, 却说明同样的单步 KL 对 50-token 回答和 5000-token agent 轨迹含义不同. 长程任务需要更频繁刷新 rollout, 或接受更强的 off-policy 修正.

版本滞后与策略滞后也不相同. 两个 checkpoint 相隔 100 次更新, 若学习率很小且梯度互相抵消, 分布变化可能有限;相隔一次大更新也可能明显移动. 因而应优先记录行为 log-prob, 直接计算已采动作比率和局部 KL. 只有版本号而没有概率, 只能做运行调度诊断.

信任域还可以约束 student 相对初始化或参考策略. 若 OPD 教师在错误状态上偶尔给出异常分布, 参考 KL 能限制一次更新造成的大范围遗忘. 但参考策略若来自 SFT, 它在学生错误状态上同样可能没有可靠行为. 参考 KL 的主要作用是限制参数诱导的输出变化, 不能替代教师质量检查.

裁剪重要性比率会产生方向明确的偏差. 设 $\rho=q_\theta(a|s)/q_{\mathrm{old}}(a|s)$, 用 $\min(\rho,c)$ 会压低那些当前策略相对更重视的动作贡献. 方差下降, 但目标不再是精确的当前策略期望. 选择裁剪阈值时应同时观察有效样本量

$$
\mathrm{ESS}=\frac{(\sum_i w_i)^2}{\sum_iw_i^2}. \tag{45}
$$

ESS 很低表示估计几乎由少数轨迹决定. 即使平均比率接近 1, 长尾比率也可能让 ESS 崩掉;分位数与最大值比均值更有诊断价值.

### 5.7. 局部几何、闭环更新与知识保留

**局部几何解释为什么两种 KL 靠近最优点后相似。**

令学生分布是教师附近的小扰动 $q_i=p_i+\epsilon_i$, 且 $\sum_i\epsilon_i=0$. 对 $\log(1+u)$ 作二阶展开. forward KL 为

$$
D_{\mathrm{KL}}(p\|q)
=-\sum_ip_i\log\left(1+\frac{\epsilon_i}{p_i}\right)
\approx\frac12\sum_i\frac{\epsilon_i^2}{p_i}. \tag{46}
$$

一阶项 $-\sum_i\epsilon_i$ 因归一化约束消失. reverse KL 同样展开:

$$
D_{\mathrm{KL}}(q\|p)
=\sum_i(p_i+\epsilon_i)\log\left(1+\frac{\epsilon_i}{p_i}\right)
\approx\frac12\sum_i\frac{\epsilon_i^2}{p_i}. \tag{47}
$$

两者在 $q=p$ 附近共享相同二阶型, 即概率单纯形上的 Fisher 局部几何. 这解释了训练接近教师后, 散度方向差异常弱于优化器、学习率与采样噪声. 两者最明显的差异出现在离教师较远、容量受限或支持截断的区域, 恰好也是 OPD 早期和学生错误状态常见的情形.

式 (46)–(47) 还说明低概率项为何敏感: 分母是 $p_i$. 同样绝对误差 $\epsilon_i$, 落在教师小概率 token 上会贡献更大二阶距离. 但 softmax 参数空间里的梯度还乘概率与 Jacobian, 不能把分布空间曲率直接等同于 logit 更新大小. 式 (11) 与式 (12) 才给出具体 logit 梯度.

JSD 在两分布接近时也具有相同局部二次结构, 只差常数因子. 它的区别主要在远距离时有界. 因而散度选择应关注训练会访问多远的分布区域. 学生已经由同族教师初始化且差距小, 几种平滑散度可能表现接近;从弱基座蒸馏强教师时, 远距离几何和支持问题更重要.

**一条从诊断到更新的完整走查。**

假设任务是四步算术推理, 学生在第一步选错运算符, 随后计算在错误分支内自洽. 第一步先测教师在该前缀上的分布与任务验证器: 若教师对正确运算符有清晰 margin, full-vocab 局部 KL 已能直接提供修正. 若正确运算符在学生概率中几乎为零, sampled reverse KL 很难探索到, 应加入教师前缀或 SFT 样本扩大支持.

第二步检查错误发生后的恢复率. 如果教师从错误运算符后仍能回退并修正, 学生 roll-in 状态值得保留, 因为它教模型恢复. 如果教师只能沿错误分支继续, 后续局部分布再精确也无法带来终局成功. 训练权重应更多放在错误发生前的岔路状态, 或使用终局奖励把失败传回第一步.

第三步比较两个梯度. 在冻结轨迹上算第一步 full-vocab forward KL 梯度, 再算含终局回报的 policy-gradient 估计. 若方向高度一致, 局部教师 margin 已代理长程价值, 简单 GKD 足够. 若方向冲突, 检查教师局部偏好、验证器目标和长度项. 冲突可能揭示教师偏爱语言自然的错误步骤, 也可能是 Monte Carlo 方差造成.

第四步更新少量参数后重新生成轨迹. 只在旧轨迹上 loss 下降不能证明第一步错误率下降. 记录新轨迹中正确运算符概率、最终成功率、回答长度和新错误类型. 如果正确分支上升但出现更多提前 EOS, 说明目标改善了一处又打开长度漏洞;需要调整 EOS 处理而非继续提高总体 KL 权重.

第五步回到固定锚点. 检查其他算术类型和普通指令是否退化, 再决定提高学生 roll-in 比例还是混入更多 SFT. 这一闭环把每个选择连接到可观测现象: 支持不足对应数据注入, 状态错位对应 roll-in, 长程归因不足对应序列梯度, 教师不可靠对应换教师或引入验证器. 公式由此成为诊断工具, 不只是损失名称.

**提示分布是闭环最外侧的一层。**

前面的式子把 $x\sim p(x)$ 当作固定条件, 训练系统却常会主动选择提示. 例如只重采学生失败的题、按不确定性提高某类提示比例、用生成器合成更难任务. 一旦提示抽样依赖当前学生, OPD 就多了一层课程分布: 学生既决定回答前缀, 又间接决定下轮看见哪些问题. 此时状态占用测度应写成 $d_{q_\theta}(x,s)$, 不能只分析同一提示内的 token 转移.

失败重采样能提高有效监督密度, 也会改变训练风险. 假设部署提示分布为 $p_{\mathrm{deploy}}(x)$, 训练按失败概率 $h_\theta(x)$ 重采样, 则实际提示分布近似

$$
p_{\mathrm{train}}(x)
=\frac{p_{\mathrm{deploy}}(x)h_\theta(x)}
{\mathbb E_{x'\sim p_{\mathrm{deploy}}}[h_\theta(x')]}. \tag{48}
$$

模型进步后 $h_\theta$ 变化, 训练课程随之移动. 若某类任务始终较难, 它会长期占据大部分 batch;若失败检测器对某种格式特别敏感, 课程会过度追逐格式. 可以限制每类提示的最大权重, 并保留按部署分布抽样的锚点 batch, 让能力提升与原始风险都可观察.

难度课程还会与教师可靠性相互作用. 学生失败最多的提示往往也是教师最不稳定的区域. 单纯选择高学生损失样本, 可能把预算集中到师生都不会的问题. 更合理的优先级同时考虑学生缺口与教师优势, 例如用教师成功而学生失败的事件筛选. 这类筛选得到的训练分布强调「可教差距」, 比只看学生 loss 更接近蒸馏目的.

提示级重要性权重理论上可把训练风险换回部署风险. 若已知抽样概率 $p_{\mathrm{train}}(x)$, 对每个提示乘 $p_{\mathrm{deploy}}(x)/p_{\mathrm{train}}(x)$. 但稀有提示会带来大权重, 方差问题与 token 级 off-policy 修正相同. 分层采样后在层内均匀平均, 往往比逐样本极端权重稳定;报告结果时再按真实部署占比聚合各层指标.

评测提示必须与自适应训练池隔离. 若同一失败样本反复进入下一轮 OPD, 模型可能记住具体轨迹, 在线成功率迅速上升. 留出的同类型新提示才能检验机制是否泛化. 对合成题还应按生成模板或底层题型划分, 随机拆分表面文本不足以防止结构泄漏.

**分布匹配不会自动保留知识。**

教师分布只在给定状态上提供行为约束. 如果提示没有触发某项知识, OPD batch 对那部分参数没有直接保护;共享参数更新仍可能让旧能力漂移. 因而知识保持取决于状态覆盖、参数耦合与正则, 不能从「有强教师」直接推出. 教师没有被查询到的区域, 对当前梯度等于不存在.

可以把训练状态集合分成核心部署区、恢复区和保持区. 核心区是学生日常会访问的正常状态;恢复区是偏离后仍值得修复的状态;保持区覆盖容易遗忘但本轮 rollout 少见的能力. 三类状态可共享教师, 抽样目标却不同. 核心区追求部署质量, 恢复区追求鲁棒性, 保持区限制遗忘. 将三者混成一个平均 KL, 会让占比最大的区域决定更新.

保持区也不能无限扩张. 若试图在整个预训练分布上维持教师行为, 蒸馏成本接近重新训练, 新任务梯度又被大范围约束稀释. 实际选择应围绕明确的能力集合: 基础指令遵循、关键安全行为、通用语言与任务所需知识. 对每类保留少量稳定锚点, 比笼统加入大量随机预训练文本更容易解释.

参数空间正则如 $\|\theta-\theta_0\|^2$ 只限制权重距离, 权重小幅移动也可能在某些状态造成大输出变化;输出 KL 更贴近行为, 但只能保护被采状态. 两者结合时, 参数正则提供全局弱约束, 锚点 KL 提供局部强约束. 具体权重仍需以保持指标与新任务指标的 Pareto 曲线选择.

最终验收应把「追上教师」与「保持自身优势」分开. 学生可能在某些短回答上比教师更简洁, 或在领域格式上已有专长. 全面最小化教师 KL 会把这些差异也抹掉. 若学生优势可由验证器确认, 可以在对应状态降低蒸馏权重, 或仅当教师价值高于学生时查询. OPD 的目标是把教师的有效信息送到学生会访问的地方, 不是把学生压成教师的低容量复制品.
