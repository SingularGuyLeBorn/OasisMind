# 判别反馈：从教师文本到可优化奖励

教师只返回文本时，一个自然办法是训练判别器判断回答更像教师还是学生，再把判别分数当作奖励。它把高维序列压成可进入 RL 的标量，也绕开了 logits 接口。压缩并非免费：判别器学到的任何偏差都会成为学生的优化目标。

## 1. 理想判别器与密度比

若教师文本来自分布 $p_T(y\mid x)$，学生文本来自 $p_\theta(y\mid x)$，在类别先验相等且判别器达到最优时，

$$
D^*(x,y)=\frac{p_T(y\mid x)}{p_T(y\mid x)+p_\theta(y\mid x)}.
$$

因此 logit $\log D^*-\log(1-D^*)$ 等于教师与学生序列概率的 log-ratio。理想条件下，最大化它会把学生推向教师分布。现实训练中的有限数据、非最优判别器和持续变化的学生都会破坏这个等式。

## 2. 为什么需要交替更新

学生每更新一次，负样本分布就发生变化。冻结判别器会让奖励逐渐陈旧；频繁重训又可能导致奖励尺度跳动，使策略优化不稳定。训练循环通常需要交替收集学生 rollout、补充教师样本、更新判别器，再更新学生。各阶段的步数比例属于算法参数，而非纯吞吐设置。

若判别器远强于学生，它可能轻易把两类文本分开，输出接近饱和，学生得到的梯度反而变弱。若判别器太弱，奖励接近噪声。warmup、标签平滑、梯度惩罚或限制判别更新次数都在控制这场动态博弈。

## 3. 捷径从哪里来

教师与学生若使用不同温度、最大长度、停止条件或格式模板，判别器会先学这些低成本特征。学生随后拉长答案、复制固定短语或改变标点，就能提高奖励而不改善任务能力。数据管线必须让非语义统计尽量匹配，并用反事实样本测试判别器是否依赖内容。

即使采样配置相同，教师风格也可能与正确性不完全一致。模仿教师分布适合教师确实更强且风格差异与能力相关的场景；若目标是可验证正确性，判别奖励应与环境验证器共同评估，不能把“像教师”直接当作“答案正确”。

## 4. 序列奖励的信用分配

判别器通常对完整回答打分，早期 token 通过策略梯度承担同一个序列回报。长轨迹中方差会很高。可以训练前缀判别器或过程判别器提供更密反馈，但前缀标签如何定义又成为新问题：一段暂时像教师的推理未必最终正确，一段表达不同的推理也可能成功。

使用 value baseline、优势归一化或分段奖励能降低方差，却不会修复奖励语义。实验应先证明判别分数与教师似然、任务成功率或人工偏好相关，再讨论优化器稳定性。

## 5. 漂移与奖励投机怎样测

最直接的诊断是保留一组跨版本锚点回答，在每轮判别更新后比较分数排序。如果同一回答的奖励大幅漂移，策略训练看到的目标就不稳定。还应构造长度、格式、复述和语义等价的对照组，检查判别器是否被表面特征驱动。

学生在训练判别器上得分提高时，应同步观察未参与训练的独立判别器、任务验证器和人工抽检。只有训练判别器上涨而其他指标不动，是典型奖励投机。用教师生成更多数据可能暂时缓解，却不能代替独立评价。

## 6. 与白盒分布匹配的差别

白盒 OPD 在每个学生前缀上读取教师动作分布，监督位置细、目标语义直接；判别反馈比较完整序列，接口更宽松，却把教师分布经过有限样本和分类器压缩。两者都可能使用学生 rollout，也都可能称为 on-policy，信息通道完全不同。

因此选择黑盒路线时，应把判别器当作核心算法组件，完整报告其数据、更新频率、校准和失败模式。若只给出学生最终成绩，读者无法判断收益来自教师知识、判别捷径还是额外生成预算。

## 7. 判别对象可以位于三个粒度

序列判别器输入完整回答，最接近教师与学生的序列密度比，但奖励稀疏。步骤判别器对推理段落打分，信用更短，却需要可靠步骤切分和标签。token 判别器最稠密，也最容易把局部措辞当作来源特征。粒度越细，不代表监督越准确。

可用 continuation 实验选择粒度：从某个前缀继续生成多次，用最终成功率估计该状态价值，再看不同判别分数与价值的相关。若 token 分数只追踪文风、序列分数却能预测成功，强行细化会恶化语义。

### 8. 训练判别器的数据不是静态语料

负样本由学生主动产生，学生更新后旧负样本会越来越容易分类；正样本若长期缓存，也会让判别器记住固定教师措辞。训练集应保留一部分历史样本维持覆盖，同时提高当前学生样本比例，使分类边界围绕正在优化的策略。

提示层也要配对。同一题的教师与学生回答构成最可靠正负对；若教师样本集中在简单题、学生样本集中在困难题，判别器会利用题型。按提示分组划分训练与验证，还能避免同题模板泄漏造成虚高准确率。

### 9. 判别奖励与任务奖励的关系

判别奖励衡量像不像教师，任务奖励衡量是否完成目标。教师可靠时两者相关，却不会完全一致。训练时可联合使用，评估时必须分开报告。学生在任务上超过教师后，继续最大化来源判别可能反而拉回教师行为。

独立环境验证器提供最硬的停止信号：当判别分数继续上涨、任务回报不再提高甚至下降，应降低判别权重。没有验证器的开放任务，则需要独立教师盲评、人类样本或跨模型评估，避免同一判别器既训练又裁判。

### 11. 判别器容量的两面

容量过小，判别器无法捕捉教师与学生的语义差异；容量过大，又容易记住训练回答和细小模板。训练准确率不能决定合适容量，应看同题改写、跨提示和跨学生版本上的泛化。一个较小但稳定预测任务成功的判别器，可能比高准确率的大模型更适合作为奖励。

冻结语言模型只训练分类头能减少记忆和成本，却继承底座表征偏差；全量微调适应更强，也更容易随当前负样本过拟合。两者应在相同数据上比较校准、锚点稳定性和策略更新后的独立收益。

### 12. 奖励更新频率的边界

每轮重训判别器最贴近当前学生，奖励尺度也最不稳定；长期冻结简单，却会被学生逐渐利用。更新频率应由当前样本上的分类间隔、锚点漂移和学生策略距离共同决定，而非只按固定步数。

无论采用快更新、慢更新还是集成，学生更新后都要在独立任务指标上验收。判别器稳定只说明训练目标没跳动，不说明目标方向正确。
