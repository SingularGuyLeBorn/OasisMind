# 怎样证明 OPD 真的有效

OPD 的训练曲线很容易制造一种错觉:师生 KL 持续下降, 模型似乎就在持续变强. KL 只说明学生靠近了教师给出的目标. 教师若没有增量、在错误前缀上不可靠, 或者目标把有用差异压没, loss 越低只代表拟合得越彻底. **评测要把教师可教性、信号传递和任务收益拆开, 否则无法判断失败发生在哪一层.**

这一章不再按算法名组织, 而是沿一条因果链检查:学生能否访问有价值的状态, 教师在这些状态上是否更好, 接口是否保留教师优势, 梯度是否把信号送到正确动作, 参数更新是否转成可泛化能力. 任一环节断掉, 后续指标都可能给出误导.

## 1. 教师优势要在学生状态上测

教师独立生成的准确率只能证明它会自己答题. OPD 需要教师接续学生前缀, 所以应从学生 rollout 截取多类状态:正确路径、刚出现错误但可恢复、错误累积、格式崩坏和接近终止. 在每类状态上比较教师与学生的下一步概率、可恢复动作 margin、熵和续写后的终局成功率.

可把局部教师优势写成

$$
A_T(s_t,a)=\log p_T(a\mid s_t)-\log q_\theta(a\mid s_t).
$$

这个量只表示教师相对偏好, 不保证动作正确. 需要用验证器、人工标注或反事实续写确认高优势动作是否真的提高成功率. 若高 $A_T$ 主要落在标点、格式和同义改写上, 蒸馏信号很密, 能力信号却很薄.

教师与学生的推理习惯越不兼容, 教师在学生前缀上的优势越可能抖动. 模型规模差距太大也未必更好:大教师可能把小学生推向无法表达的多模态分布, 或无法理解学生的简化中间表示. 因而需要同时比较多个教师尺寸与同家族/跨家族组合, 不能默认最大教师最适合.

## 2. 支持集决定学生能学到哪里

On-policy 只能在学生访问的状态上学习. 学生从不采到某类推理步骤时, reverse-KL 或 sampled-token 目标不会凭空把它召回. 衡量支持集可看正确轨迹出现率、关键动作覆盖、采样温度下的 pass@$k$、教师高概率动作是否进入学生 top-$k$. 若教师正确动作长期位于学生极低概率区, 应先做 SFT、混入教师轨迹或调整课程, 而不是增加 OPD epoch.

另一方面, 过度提高采样温度会得到大量教师也无法修复的状态. 这些样本增加计算, 还可能让目标被乱码前缀主导. 最合适的区域通常是学生会访问、仍有多种可能、教师能够纠偏的边界状态. Prompt 选择也应围绕这个区域, 而非只按题目难度分层.

训练过程中支持集会变化. 早期需要更多教师示范扩大覆盖, 中期需要新鲜学生轨迹暴露错误, 后期师生趋同后则要引入更难问题、外部验证或不同教师. 一套固定采样分布从头跑到尾, 很容易在中后期只重复已解决状态.

## 3. 信号传递有没有丢掉关键差异

比较 full-vocab、top-$k$ 与 sampled-token 时, 至少固定 prompt、学生 checkpoint、教师和 rollout. Full-vocab 是信息较完整的参照;top-$k$ 需要报告 $k$、尾质量与重归一化方式;sampled-token 需要报告 baseline、return 定义、序列归一化和方差. 只比较最终分数而不报告这些细节, 无法知道收益来自接口还是额外计算.

信号位置同样重要. 按 token 位置、语义角色和轨迹成败统计 KL, 检查梯度是否集中在真正改变推理方向的节点. 若绝大多数损失来自开头格式、结尾 EOS 或少数模板词, 总 KL 会很好看, 方法却没有覆盖核心决策. 可对高 KL 位置做 token 替换或分支续写, 验证其因果作用.

Hybrid 目标还要检查 gating. 只保留成功轨迹会造成幸存者偏差;把失败轨迹全部赋负权又可能惩罚其中正确的前半段. 按可恢复性、教师置信度与环境结果分桶, 比一个单独的 0/1 mask 更能看清信号.

## 4. 公平预算下比较 SFT、RL 与 OPD

训练步数不是公平预算. OPD 每步包含学生 Decode、教师 Prefill 和 learner 反向;RLVR 可能需要每题多条 rollout;SFT 复用固定数据, 单步便宜得多. 至少同时报告优化 token、学生生成 token、教师评分 token、总 FLOPs、GPU 小时和墙钟时间. 如果系统规模不同, 还要报告硬件与并行方式.

数据预算也要对齐. OPD 使用的 prompt 是否与教师离线数据相同, RLVR 是否多采了 $k$ 倍回答, SFT 是否能重复多轮, 都会改变比较. 合理做法是给出多条预算曲线, 而不是挑一个终点宣布谁更省.

任务指标之外, 需要保留能力与行为切片:基础知识、指令跟随、长度、重复、格式、拒答、校准和旧领域表现. 自蒸馏在专项 benchmark 上上涨, 同时可能压低多样性或遗忘通用能力. 平均分会掩盖这些交换.

## 5. 五类常见失败

**教师失败**:教师在学生错误前缀上没有可用优势, 或特权信息本身错误. 现象是教师独立得分高, 但条件化续写不稳定. 修复方向是更换教师、改变教师上下文或过滤状态.

**支持集失败**:学生访问不到正确模式, 或采样落在大量不可恢复状态. 现象是正确动作长期不在 student top-$k$, 教师优势再大也没有有效样本. 需要冷启动和课程, 不是更强的 KL.

**估计器失败**:Top-$k$ 截断、sampled-token 方差、长度归一化或 importance ratio 让原始优势失真. 现象是离线重算的教师方向与实际梯度不一致. 应先用小批 full-vocab 参照验证估计器.

**闭环失败**:Rollout 版本滞后、回放过旧或教师同步规则错误. 现象是行为策略与 learner KL 增长, 旧样本梯度互相冲突. 需要限制版本差和复用次数, 记录每条轨迹的来源 checkpoint.

**评测失败**:数据污染、解码配置变化、长度增长或格式匹配造成假提升. 现象是 benchmark 上涨却无法在新题、不同采样或真实工具环境中复现. 需要留出集、污染检查和多解码设置.

这些故障的修法不同. 一律减小学习率只能让问题变慢, 不会让目标重新正确.

## 6. 自蒸馏的能力上限

同源教师靠参考解、反馈、工具结果或长上下文获得特权. 新信息位于条件中, 不在「同一模型教自己」这句话里. 如果教师和学生看到完全相同的信息、使用相同参数且没有采样共识或外部验证, 所谓自蒸馏大多只是在重排已有分布.

参数共享还会限制纠错上限. 教师与学生可能在相同位置犯错, 也可能随着训练同步收敛而失去差异. 固定教师保留稳定目标, EMA 教师提供平滑, 周期刷新教师跟上新能力, 三者交换的是新鲜度、稳定性与增量. 应画出教师优势随训练步数的曲线, 在优势耗尽后停止蒸馏或引入新信息.

是否能够超过教师取决于评价口径. 学生可以因正则、解码或任务分布差异在某些 benchmark 上超过教师, 也可以通过环境奖励发现教师没有展示的策略;这不意味着纯粹模仿凭空创造了知识. 报告应区分迁移收益、优化收益和外部反馈带来的新能力.

## 7. 长时程与 Agent 的开放问题

单轮文本中, 状态可近似为 token 前缀. 多轮 Agent 中, 状态还包括工具观察、文件、浏览器页面与环境隐变量. 教师必须读取与学生一致的外部状态, 否则逐 token 分布没有共同条件. 工具副作用还让离线回放变得困难:同一动作在不同时间可能返回不同结果.

信用分配也跨越多轮. 一个早期检索动作可能在数十步后才显出价值, 即时 token KL 很难覆盖这条因果链. 未来方法需要把过程验证、层级动作和环境模型接入 OPD, 同时控制教师调用成本. 综述把 agent-level distillation 列为开放方向, 原因就在这里:现有公式大多默认文本前缀足以描述状态, 真实 Agent 并不满足这个假设.

### 7.1. 最小验收矩阵

一项可信实验至少包含固定前缀 KD、学生前缀 OPD 与 on-policy RL/结果优化三组, 共享学生起点、prompt、教师和解码预算. 对 OPD 再拆 full-vocab、压缩接口或采样估计器;对自蒸馏再拆无特权条件、错误特权条件与正确特权条件. 这些对照能分别回答收益来自状态覆盖、教师信息还是优化器.

训练过程保存每轮学生 checkpoint 与少量可复算轨迹. 对同一批状态离线重算教师分布、估计器梯度和更新后概率变化, 能抓出模板、mask、版本与归一化错误. 这些检查通过后, 再在未见 prompt、不同难度、不同解码和旧能力集上复测. **能复算一批更新, 能解释一条收益曲线, 能指出方法在哪些状态上失效, 才算把 OPD 评测闭环.**

本章主要参照 2026 年 OPD 综述的统一分类与开放问题, 以及 *Rethinking On-Policy Distillation of Large Language Models* 对兼容性、教师增量、冷启动和 prompt 选择的机制分析. 单项结论仍以对应原论文和可复现实验为准.
