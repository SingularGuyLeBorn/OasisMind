# G-OPD: 从模仿教师到奖励外推

普通蒸馏的终点通常很直观: 学生尽量接近教师. 可是在 2026 年的 G-OPD 实验里, 同尺寸学生沿教师方向再多走一点, 居然能在数学和代码任务上超过教师;多个领域教师合并回共同 base 时, 一个统一学生还能同时越过两个专家. 这件事听起来像「学生凭空获得了教师没有的知识」, 实际变化发生在目标几何上. 教师是 base model 经过领域 RL 后得到的策略, 教师相对 base 的 log-ratio 携带了一条优化方向. 标准 OPD 走到教师位置, G-OPD 允许沿这条方向插值或外推.

外推也会放大错误. 论文中 $\lambda=1.25$ 的效果稳定, $\lambda=1.5$ 已出现性能回落, 回答长度还会随 $\lambda$ 增长. 所以 G-OPD 的重点不在「把 KL 系数调大」这句话, 而在三个相互绑定的对象: 哪个模型充当 reference, 教师相对 reference 的 log-ratio 是否真能解释成奖励, 这份奖励放大后会不会把长度偏置和异常 token 一起放大.

## 1. 标准 OPD 里藏着一个会抵消的 reference

给定 prompt $x$, 学生策略为 $\pi_\theta$, 教师为 $\pi^*$. 先看序列级 reverse KL:

$$
\mathcal L_{\mathrm{OPD}}(\theta)
=\mathbb E_{y\sim\pi_\theta(\cdot\mid x)}
\left[
\log\frac{\pi_\theta(y\mid x)}{\pi^*(y\mid x)}
\right]. \tag{1}
$$

向式 (1) 插入任意支持集兼容的参考策略 $\pi_{\mathrm{ref}}$:

$$
\log\frac{\pi_\theta}{\pi^*}
=\log\frac{\pi_\theta}{\pi_{\mathrm{ref}}}
-\log\frac{\pi^*}{\pi_{\mathrm{ref}}}. \tag{2}
$$

最小化式 (1), 等价于最大化

$$
\mathcal J_{\mathrm{OPD}}(\theta)
=\mathbb E_{y\sim\pi_\theta}
\left[
\underbrace{\log\frac{\pi^*(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}}_{r^*(x,y)}
-\underbrace{\log\frac{\pi_\theta(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}}_{\text{KL integrand}}
\right]. \tag{3}
$$

$r^*(x,y)$ 可以解释为教师相对 reference 的隐式奖励. 对自回归模型, 它沿 token 相加:

$$
r^*(x,y)=\sum_{t=1}^{T}
\left[
\log\pi^*(a_t\mid s_t)
-\log\pi_{\mathrm{ref}}(a_t\mid s_t)
\right]. \tag{4}
$$

式 (3) 与 KL 约束 RL 的形式相同, 并且每个已采 token 都能获得稠密 log-ratio. 标准 OPD 中奖励与 KL 正则的相对强度固定为 $1:1$. 此时 reference 在式 (2) 中完全抵消, 换哪个 reference 都不会改变原来的 $D_{\mathrm{KL}}(\pi_\theta\|\pi^*)$. 这也解释了为什么早期 OPD 公式根本不必写 reference: 它存在于 RL 解释中, 没有进入最终目标的自由度.

G-OPD 把奖励强度改为 $\lambda$:

$$
\mathcal J_{\mathrm{G\text{-}OPD}}(\theta)
=\mathbb E_{y\sim\pi_\theta}
\left[
\lambda\log\frac{\pi^*(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}
-\log\frac{\pi_\theta(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}
\right]. \tag{5}
$$

$\lambda$ 一旦离开 1, reference 就不再抵消. 同样一个教师, 配不同 reference 会产生不同奖励方向和不同正则中心. 因而「G-OPD 只多一个系数」会漏掉一半方法: 系数决定走多远, reference 决定从哪里出发以及教师变化被解释成什么.

## 2. 插值与外推来自同一个闭式解

固定 $x$ 并对所有序列分布优化式 (5), 归一化后的最优策略满足

$$
\pi_\lambda(y\mid x)
=\frac{1}{Z_\lambda(x)}
\pi^*(y\mid x)^\lambda
\pi_{\mathrm{ref}}(y\mid x)^{1-\lambda}, \tag{6}
$$

其中 $Z_\lambda(x)$ 是归一化常数. 写成 log 概率,

$$
\log\pi_\lambda
=\log\pi^*
+(\lambda-1)(\log\pi^*-\log\pi_{\mathrm{ref}})
-\log Z_\lambda. \tag{7}
$$

$\lambda=0$ 时回到 reference, $\lambda=1$ 时到达教师. $0<\lambda<1$ 产生 reference 与教师的几何插值; $\lambda>1$ 延续教师相对 reference 的 log 概率位移. 论文把后一段称为 ExOPD, 即 reward extrapolation.

一个双动作例子能看出「越过教师」的含义. 设 reference 对动作 $(A,B)$ 的概率为 $(0.8,0.2)$, 领域教师经过训练后变成 $(0.6,0.4)$. 教师把 $B$ 从 0.2 提高到 0.4, 因而 $B$ 的隐式奖励比 $A$ 更高. 当 $\lambda=0.5$ 时,

$$
\pi_{0.5}\propto
(\sqrt{0.8\times0.6},\sqrt{0.2\times0.4})
\approx(0.693,0.283),
$$

归一化后约为 $(0.710,0.290)$, 落在 reference 与教师之间. 当 $\lambda=1.5$ 时,

$$
\pi_{1.5}\propto
\left(\frac{0.6^{1.5}}{0.8^{0.5}},
\frac{0.4^{1.5}}{0.2^{0.5}}\right)
\approx(0.520,0.566),
$$

归一化后约为 $(0.479,0.521)$. 动作 $B$ 在教师中只有 0.4, 外推后超过 0.5. 学生没有发现一个新动作, 它只是把教师已经表现出的相对偏好推得更远.

这条推导给出机制解释, 没有保证任务奖励随 $\lambda$ 单调增长. 若教师把 $B$ 的概率提高是因为可靠任务反馈, 适度外推可能继续获益;若变化来自过拟合、长度偏置或采样噪声, 外推会把同一误差放大. 闭式解说明模型被推向哪里, benchmark 才能说明那个方向是否有用.

## 3. sampled-token 更新究竟多了哪一项

训练时无法枚举所有序列, G-OPD 在学生 rollout 上使用 token log-prob. 记

$$
d_t^{S,T}=\log\pi_{\bar\theta}(a_t\mid s_t)-\log\pi^*(a_t\mid s_t),
$$

$$
d_t^{R,T}=\log\pi_{\mathrm{ref}}(a_t\mid s_t)-\log\pi^*(a_t\mid s_t),
$$

其中 $\bar\theta$ stop-gradient. 对最小化形式, 论文给出的 sampled-token 系数可以整理为

$$
A_t^{\mathrm{G\text{-}OPD}}
=d_t^{S,T}+(\lambda-1)d_t^{R,T}. \tag{8}
$$

$\lambda=1$ 时第二项消失, 恢复标准 reverse-KL OPD 的 $\log\pi_S-\log\pi_T$. $\lambda>1$ 时, reference 相对教师的差异被额外加入. 若教师比 reference 更支持已采动作, $d_t^{R,T}<0$, 额外项会增强提高该动作概率的压力;若 reference 更支持它, 更新方向相反.

结合行为策略 $\pi_{\mathrm{old}}$, 一个常见 surrogate 写成

$$
\mathcal L_{\mathrm{sur}}(\theta)
=\mathbb E_{y\sim\pi_{\mathrm{old}}}
\left[
\sum_t
\rho_t(\theta)
\operatorname{sg}\!\left[A_t^{\mathrm{G\text{-}OPD}}\right]
\right],qquad
\rho_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\mathrm{old}}(a_t\mid s_t)}. \tag{9}
$$

若用 $\log\pi_\theta$ 形式实现, 梯度符号和优化器的最小化/最大化约定要一起检查. 可验证的不变量更可靠: $\lambda=1$ 必须逐 token 退化到现有 OPD; $\lambda=0$ 的最优分布应回到 reference;教师、reference 和学生三者完全相同时, 所有系数都为零.

式 (8) 使用已采 token 估计 reverse KL, 没有直接传回未采候选的教师排序. 增大 $\lambda$ 会同时增大有效 advantage 的尾部. 一个教师概率极小或 reference 概率极小的 token, log-ratio 可以取得很大绝对值;若 rollout 又刚好采到它, 单个样本会主导 batch. 官方实现基于 verl, 示例脚本开启 `only_reverse_kl_advantages`, 将 `lambda_vals` 设为 1.25, 同时使用 token-level rollout correction. 这些配置说明论文实现走 sampled-token policy-gradient 路径, 不能与 full-vocab KL 的直接反传混为一条计算图.

### 3.1. 从序列目标到 token 系数

式 (5) 的单条序列 integrand 记为

$$
F_\theta(y)=
\lambda\log\frac{\pi^*(y)}{\pi_{\mathrm{ref}}(y)}
-\log\frac{\pi_\theta(y)}{\pi_{\mathrm{ref}}(y)}.
$$

对 $\mathbb E_{y\sim\pi_\theta}[F_\theta(y)]$ 求导时, 一部分梯度来自采样分布, 另一部分来自 $F_\theta$ 内部的 $-\log\pi_\theta$. 后一部分的期望为 $-\mathbb E[\nabla\log\pi_\theta(y)]=0$, 因而可以留下 score-function 形式. 再利用 $\log\pi(y)=\sum_t\log\pi(a_t\mid s_t)$, 序列系数能够拆到 token. 若采用即时信用, 每个位置只用自己的局部 log-ratio;若采用 reward-to-go, 早期 token 还会乘后续位置的累计信号. G-OPD 论文与官方实现采用局部 sampled-token advantage, 奖励强度 $\lambda$ 调的是局部 dense reward, 没有自动获得长程信用传播.

这一区别在两步分叉任务上很明显. 第一步动作 $A$ 与 $B$ 在 teacher/reference 下比率相同, 选择 $B$ 后第二步才出现很高的教师奖励. 即时式 (8) 不会因第二步奖励直接提高第一步 $B$;序列 return 会把后续项传回第一步. 前者方差较低, 后者更接近完整序列目标却更受长度和晚期异常比率影响. 因而 G-OPD 的 $\lambda$ 与折扣或 return 定义是两只旋钮: 一个改变奖励幅度, 一个改变奖励沿时间传播的范围.

### 3.2. full-vocab 形式会怎样外推

若教师、reference 与学生能返回共同词表上的完整分布, 给定状态 $s$ 可以直接优化

$$
\ell_\lambda(s)
=\sum_{v\in V}q_\theta(v\mid s)
\left[
\log q_\theta(v\mid s)
-\lambda\log p^*(v\mid s)
-(1-\lambda)\log p_{\mathrm{ref}}(v\mid s)
\right]. \tag{9a}
$$

它等价于学生到局部外推目标 $p_\lambda(v\mid s)\propto p^*(v\mid s)^\lambda p_{\mathrm{ref}}(v\mid s)^{1-\lambda}$ 的 reverse KL. 所有候选都获得梯度, teacher/reference 的差异会明确告诉概率质量应流向哪些未采 token. sampled-token 式 (8) 只在许多动作样本的期望下恢复对应方向, 单个 batch 的词表路由更依赖学生采样.

full-vocab 也更容易暴露外推的数值问题. 当 $\lambda>1$ 时, reference 指数为负, reference 概率很小的候选会被放大. 计算 $p_\lambda$ 应在 log 空间减去 log-sum-exp;直接做幂运算可能上溢. top-$k$ 再增加一层截断: 教师头部以外的 reference 小概率 token 可能恰好拥有很高外推分数, 却在候选选择前就被丢掉. 因而 ExOPD 的 top-$k$ 集合若仍只按教师概率选取, 不能保证包含外推目标的头部.

## 4. reference 怎样从可消元符号变成奖励语义

### 4.1. 同一个 base 训练出的领域专家

设原始 base 为 $\pi_0$, 数学与代码专家分别由它进行领域 RL 得到 $\pi_M^*$ 和 $\pi_C^*$. 对数学样本选择数学教师, 对代码样本选择代码教师, reference 都取 $\pi_0$. 两个隐式奖励

$$
r_M=\log\frac{\pi_M^*}{\pi_0},qquad
r_C=\log\frac{\pi_C^*}{\pi_0}
$$

拥有共同零点. 统一学生可以按领域路由读取对应教师, 同时受同一个 base 约束. 标准 OPD 倾向于在每个领域复现相应教师;ExOPD 则分别放大两条 RL 位移. 论文的多教师实验采用这种构造, 报告 ExOPD 在全部数学和代码基准上同时超过两个领域教师.

共同 base 很关键. 若两个教师来自不同预训练底座、不同 tokenizer 或不同聊天模板, $\log(\pi^*/\pi_{\mathrm{ref}})$ 会混入底座差异. 此时某个 token 的高比率可能来自词表切分、格式偏好或知识容量, 很难再解释成领域 RL 奖励. 统一 reference 提供的坐标系只有在动作空间与条件状态对齐时才成立.

### 4.2. 大教师向小学生蒸馏

强到弱蒸馏通常只有大教师 $\pi_T^*$ 和小学生 base $\pi_S^0$. 默认 reference 取 $\pi_S^0$, 隐式奖励为

$$
r_{\mathrm{default}}=\log\frac{\pi_T^*}{\pi_S^0}. \tag{10}
$$

这个比率同时包含大教师的预训练容量、模型架构、指令调优和后训练效果. G-OPD 仍可使用它, 论文在 Qwen3-30B-A3B-Instruct-2507 教师向 1.7B 与 4B 学生蒸馏时, 默认 ExOPD 已经超过 OPD. 但「放大了更准确的奖励」在此处并不严格, 因为式 (10) 里有大量与奖励训练无关的模型差异.

若能拿到大教师进行 RL 之前的 base $\pi_T^0$, 可以改成

$$
r_{\mathrm{corrected}}=\log\frac{\pi_T^*}{\pi_T^0}. \tag{11}
$$

它更接近大教师后训练所诱导的 implicit reward. 从默认奖励到校正奖励, 等价于添加

$$
\log\frac{\pi_S^0}{\pi_T^0}.
$$

这项恰好移除小学生 base 与大教师 base 的错位. 论文将该选择称为 reward correction, 实验中持续改善 ExOPD. 代价也很实在: learner 除了大教师 log-prob, 还要计算大教师 pre-RL base 的 log-prob;reference 从小模型变成大模型后, 显存、通信和评分延迟都会上升.

式 (5) 还能改写为

$$
\mathcal J_{\mathrm{G\text{-}OPD}}
=\mathbb E_{y\sim\pi_\theta}
\left[
(\lambda-1)\log\frac{\pi^*}{\pi_{\mathrm{ref}}}
-\log\frac{\pi_\theta}{\pi^*}
\right]. \tag{12}
$$

式 (12) 把 G-OPD 分成「继续贴近教师」和「额外追逐教师奖励」两部分. 当 $\lambda=1$ 时, 奖励校正完全不起作用;只有外推或插值区间才需要认真选择 reference. 这条边界适合抓实现错误: 标准 OPD 的结果若随着 reference 改变, 说明代码没有正确抵消 reference 项.

### 4.3. reference 还决定可达方向

把 teacher/reference log-ratio 看成向量 $u(y)=\log\pi^*(y)-\log\pi_{\mathrm{ref}}(y)$. G-OPD 只沿 $u$ 这条方向移动, $\lambda$ 调整步幅. 教师相对 reference 从未提高的行为, 外推不会凭空获得正奖励. 多个领域教师提供多条方向, 数据路由决定每个 prompt 使用哪一条;同一个 prompt 若同时混合教师, 还要定义是在概率空间混合教师, 还是分别计算奖励后混合. 两种操作通常不交换.

若先混合教师 $\pi_M=\alpha\pi_1^*+(1-\alpha)\pi_2^*$, 奖励是 $\log\pi_M-\log\pi_{\mathrm{ref}}$. 若先混合 log-ratio, 得到 $\alpha\log\pi_1^*+(1-\alpha)\log\pi_2^*-\log\pi_{\mathrm{ref}}$, 对应教师的几何混合. 算术混合更保留任一教师的高概率模式, 几何混合会惩罚某位教师极低概率的动作. G-OPD 论文的多教师实验按样本领域选择教师, 避开了同一状态如何融合分歧教师的问题.

reference 自身若已经做过同类 RL, teacher/reference 比率只留下两者增量差. 这有时正是所需的 reward correction, 有时会把共同能力全部消去. 例如 teacher 与 reference 都学会正确格式, 只有 teacher 额外提高数学推理, 比率会集中在数学 token;若 reference 的格式训练不同, EOS 与模板 token 会重新占据高奖励. 所谓「更好的 reference」取决于希望从教师变化中抽取哪一段训练增量.

## 5. 实验结果支持什么, 又留下什么

论文先从 Qwen3-4B-Non-Thinking 训练数学与代码领域教师, 再把教师蒸馏回同一个 base. $\lambda$ 扫描集合为 $\{0,0.25,0.5,0.75,1,1.25,1.5\}$. 插值区间的准确率和响应长度大体位于 base 与教师之间;标准 OPD 接近教师;适度外推继续提高准确率. $\lambda=1.25$ 在报告的同尺寸设置中稳定超过标准 OPD 与教师, $\lambda=1.5$ 可能失稳并退化. 这一扫描比只报最优点更重要, 因为它同时验证了式 (6) 的连续路径与外推过强的风险.

强到弱实验使用 Qwen3-30B-A3B-Instruct-2507 教师. 对 1.7B 学生, 四个数学基准平均准确率从 OPD 的 23.1 提高到 ExOPD 的 25.4;对 4B 学生, 从 42.6 提高到 45.3. 大教师本身平均为 59.7, 所以这里证明的是 ExOPD 超过标准 OPD, 没有证明小学生越过大教师. 「学习超越教师」主要出现在同尺寸领域专家和多教师合并场景, 不能把标题结论无条件搬到所有 strong-to-weak 组合.

训练动态还显示 ExOPD 得到更高训练 reward、更长 response 和更高 response entropy. 长度增加可能提供更多计算 token, 也可能来自 implicit reward 的长度偏置. 若评测允许更长答案, 准确率提升中会混入推理预算变化. 严格对照应同时报告平均有效 token、截断率、同长度分桶准确率与 EOS log-odds;把生成长度固定后仍保留的收益, 才更接近目标几何本身的贡献.

论文将 $\lambda=1.5$ 的退化解释为 implicit reward hacking 风险: 学生过度拟合 log-ratio 的尖峰, 即使峰值来自偏差. 这是机制解释与实验现象的结合, 尚未形成对任意模型都成立的阈值. 最优 $\lambda$ 会随 teacher/reference 间距、任务、tokenizer、采样温度和 advantage 裁剪改变. 1.25 是论文配置下的经验点, 不能当成 G-OPD 常数.

## 6. 外推最容易在哪些地方跑偏

支持集是最基础的数学边界. 若 reference 对某个教师支持的动作给出零概率, $\log(\pi^*/\pi_{\mathrm{ref}})$ 发散;神经 softmax 理论上为每个词表 token 给正概率, 低精度下溢、不同词表和 top-$k$ 截断仍会制造近似零. log-prob floor 可以限制数值, 同时改变外推目标. 报告 floor 触发率比只写一个裁剪值更有意义.

序列奖励按 token 求和, 长回答天然拥有更多累计 log-ratio 项. 如果教师相对 reference 在普通推理 token 上有轻微正偏, 外推会鼓励延长序列. 按长度平均会削弱这项偏置, 也会改变式 (5) 对序列分布的原始定义. 更稳妥的诊断是分别计算每 token 平均隐式奖励、序列总奖励和终止动作奖励, 再决定任务是否需要长度归一或显式成本.

teacher/reference 的聊天模板必须让同一 token 事件对齐. 教师用 `<|im_end|>` 结束, reference 用另一 EOS 时, 结束位置会出现持续的大 log-ratio;ExOPD 会进一步压低或抬高学生 EOS, 最终表现为长度爆炸或过早终止. reward correction 引入第三个模型后, 三方 tokenizer、模板、system prompt 和 response mask 都要一致. 能跑出标量 loss 不代表这些概率处在同一个条件事件上.

策略陈旧会放大尾部. rollout 来自 $\pi_{\mathrm{old}}$, learner 已移动到 $\pi_\theta$ 时, 重要性比率 $\rho_t$ 与 G-OPD advantage 相乘. 一个罕见 token 同时具有大 $\rho_t$ 和大外推 log-ratio, 会产生极端梯度. 官方脚本使用 token-level rollout correction 并设置阈值, 说明实现已把训练/推理策略偏差视为独立风险. 裁剪可以稳定训练, 也会让实际优化目标偏离式 (5);阈值命中率应与 $\lambda$ 一起观察.

多教师还会出现 reward scale 不一致. 数学教师相对 base 的 log-ratio 方差可能远大于代码教师, 共用 $\lambda$ 后数学样本主导梯度. 每个领域单独标准化会改善数值平衡, 也会抹去奖励绝对尺度, 改变原始 G-OPD. 可以先记录领域内均值、方差、长度和裁剪比例, 再判断是否需要领域系数;不能用一个全局 loss 均值证明多教师已经平衡.

### 6.1. 正规化常数与「超过教师」的边界

式 (7) 里的 $Z_\lambda(x)$ 对同一个 prompt 的序列排序没有影响, 对跨 prompt 的 loss 数值和精确概率却不可省. 自回归 token 局部外推每一步都会产生自己的正规化常数, 逐步归一后的策略未必等于对完整序列一次性应用式 (6), 因为后续状态分布也随前面采样变化. 论文的策略梯度在学生访问状态上估计目标, 它提供可训练方向, 没有声称有限步神经网络优化会精确达到闭式序列分布.

「学生超过教师」也依赖评测函数. 外推目标让学生在 teacher/reference 奖励上走得更远, 任务准确率只有在这份隐式奖励与 verifier 对齐时才可能继续上升. 教师由相同 verifier 的 RL 得到时, 对齐假设更可信;教师来自通用指令调优时, log-ratio 混合了安全、风格、长度和格式偏好. 超过教师的 benchmark 分数属于实验结论, 无法由式 (6) 单独证明.

### 6.2. 方差随哪几个量增长

令局部外推系数为 $A_t=d_t^{S,T}+(\lambda-1)d_t^{R,T}$. score-function 梯度二阶矩受 $A_t^2\|\nabla\log\pi_\theta(a_t\mid s_t)\|^2$ 控制. $\lambda$ 增大时, $d_t^{R,T}$ 的方差被近似按 $(\lambda-1)^2$ 放大, 它与标准 OPD 项的协方差还会增加或抵消总方差. 因此只看 advantage 均值判断外推强度不够, 方差、分位数和两项协方差都能揭示何时少数 token 开始主导更新.

状态相关 baseline 可以从 $A_t$ 中减去不依赖当前动作的量, 在理想 on-policy score-function 下不改变期望. clip、log-prob floor 与按领域归一化会直接改变目标或引入偏差. 三种稳定手段的含义不同: baseline 主要降方差, clip 限制单样本影响, floor 重定义极低概率区域. ExOPD 的收益若只在强裁剪下出现, 实际有效目标已经是「外推后再截断」, 应按该组合解释.

### 6.3. 一组能区分机制的对照

固定一批学生前缀, 保存 teacher、reference 与 student 的完整 log-prob, 可以在不重新 rollout 的情况下离线扫描 $\lambda$. 每个位置计算外推目标头部、sampled-token $A_t$、尾部分位数和 EOS 分数. 这一步检验目标几何与数值范围, 没有混入新状态分布. 随后才让不同 $\lambda$ 的模型重新生成, 比较状态覆盖、长度与准确率. 两阶段差异能显示收益来自同一状态上的动作重排, 还是来自更新后访问了新的推理分支.

reference 对照固定 $\lambda>1$, 分别使用 student base 与 teacher pre-RL base. 除准确率外, 还应比较两种 reference 下 implicit reward 与 verifier 结果的相关性, 以及格式 token、推理 token、EOS 各自贡献的奖励. reward correction 真正有效时, 改善应集中在任务相关动作, 而非仅仅改变模板或长度. $\lambda=1$ 作为负对照必须对 reference 不敏感, 它能直接验证实现是否符合式 (2).

论文扫描的 $\lambda$ 从 0 到 1.5, 对应从 reference、插值、标准 OPD 到外推. $\lambda<0$ 会反转教师相对 reference 的奖励方向, 最优分布更偏向教师压低的行为, 已经脱离能力蒸馏的通常目的;论文没有用实验支持这一范围. 很大的正 $\lambda$ 则让式 (6) 接近选择 teacher/reference 比率最大的少数模式, 分布熵和正规化常数会变得极端. 因而 G-OPD 的有效设计空间主要位于 1 附近, 外推是一段受控延伸, 不是无限增大奖励.

$\lambda=0$ 也是很有用的边界对照. 此时教师奖励完全关闭, 目标只把学生拉回 reference;若从 reference 本身初始化且采样、模板都一致, 理想更新应接近零. 实验里把 $\lambda=0$ 直接记成 base 性能, 本质上利用了这个固定点. 训练实现若在该点仍持续漂移, 原因应来自采样校正、数值估计、额外正则或数据管线, 不能归给教师蒸馏.

公平比较还要固定推理预算. 如果 ExOPD 生成更长答案, 它在固定样本数评测中实际消耗了更多 token. 可以同时报告固定最大长度、固定总生成 token 和自然长度三种口径: 自然长度反映部署行为, 固定长度隔离额外思考预算, 固定总 token 对齐服务成本. 三种口径的差异能说明外推主要改善了单位 token 决策, 还是通过延长推理换取正确率.

### 6.4. 它与自蒸馏算法分别改了什么

[OPSD](../4.1-自蒸馏算法/4.1.2-OPSD.md) 给教师参考解, [SDFT](../4.1-自蒸馏算法/4.1.3-SDFT.md) 给教师示范, [SDPO](../4.1-自蒸馏算法/4.1.4-SDPO.md) 给教师环境反馈或成功轨迹. 它们改变 $\pi^*$ 的条件信息, 回答「教师为什么在学生前缀上更强」. G-OPD 接受已经构造好的 $\pi^*$, 再选择 $\pi_{\mathrm{ref}}$ 和 $\lambda$, 回答「这份教师相对 reference 的偏好应推进多远」.

同源教师同样可以接入 G-OPD. 官方仓库提供 on-policy context-distillation 示例, 教师读取 ground-truth solution、external feedback 或 high-level experience;仓库说明其实现固定教师为学生初始状态, 并报告 EMA 在该配置下容易 collapse. 这属于具体实现观察, 没有把 G-OPD 限定为外部大教师. 组合时仍要验证额外上下文是否真的改善教师, 因为 $\lambda>1$ 会把无效条件造成的分布偏移一并外推.

面对新设置时, 可以用三个问题确定 G-OPD 是否合适: teacher 相对 reference 的变化能否解释成任务需要的方向;适度超过 teacher 是否有意义;外推增加的长度、熵与尾部梯度能否被观测和约束. 三个问题有一个答不清, 标准 OPD 往往是更可靠的起点.
