# 目标校准与稳定性

找到一个更强的教师, 只完成了 on-policy distillation 的一半. 另一半藏在训练目标里: 教师与哪个参考策略比较, 师生差异应该放大到什么程度, 答对和答错的轨迹是否值得接受同样强的更新. 这三件事混在一起时, 很容易把长度膨胀归咎于教师, 把坏前缀上的噪声归咎于 reverse KL, 又把多样性下降解释成模型容量不足. 真正变化的量可能只是 reference、奖励系数或一组轨迹的权重.

这一节以普通 OPD 为共同起点. [G-OPD](4.2.1-G-OPD.md) 沿目标函数向里拆, 把教师相对 reference 的 log-ratio 看成稠密奖励, 再单独调节奖励强度. [SCOPE](4.2.2-SCOPE.md) 沿样本组织向外拆, 用验证结果把同题轨迹分流, 让正确轨迹学习学生自己的低概率成功路径, 让错误轨迹只在教师对该前缀仍有把握时接受蒸馏. 两条路线可以共用 rollout 和教师服务, 修改的位置却不相同.

## 1. 教师分布进入梯度以后, 仍有三层选择

给定题目 $x$, 当前学生从行为策略 $\pi_{\mathrm{old}}$ 采样回答 $y=(a_1,\ldots,a_T)$. 学生 learner 记为 $\pi_\theta$, 教师记为 $\pi_T$, 第 $t$ 步学生访问的状态为 $s_t=(x,a_{<t})$. sampled-token OPD 常用局部 log-ratio

$$
\Delta_{i,t}=\log\pi_{\bar\theta}(a_{i,t}\mid s_{i,t})
-\log\pi_T(a_{i,t}\mid s_{i,t}),
$$

其中 $\bar\theta$ 表示 stop-gradient 的学生快照. learner 通过重要性比率

$$
\rho_{i,t}(\theta)=
\frac{\pi_\theta(a_{i,t}\mid s_{i,t})}
{\pi_{\mathrm{old}}(a_{i,t}\mid s_{i,t})}
$$

接收更新. 同步单步训练时 $\rho$ 接近 1;轨迹经过多轮复用、异步生成或参数已经移动后, 它负责描述行为策略与 learner 的偏离. $\Delta$ 说明已采 token 更接近学生还是教师, $\rho$ 说明这条旧轨迹对当前 learner 还有多大代表性. 两者解决的是不同问题.

普通 OPD 还隐含了一个 reference $\pi_{\mathrm{ref}}$. 把 reverse KL 展开,

$$
\mathbb E_{y\sim\pi_\theta}
\left[\log\frac{\pi_\theta(y\mid x)}{\pi_T(y\mid x)}\right]
=\mathbb E_{y\sim\pi_\theta}
\left[\log\frac{\pi_\theta(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}
-\log\frac{\pi_T(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}\right].
$$

右边第二项可以读成教师相对 reference 的隐式奖励, 第一项约束学生别离 reference 太远. 标准 OPD 恰好以 $1:1$ 组合这两项, reference 在代数上抵消, 所以平时看不见它. G-OPD 放开这个固定比例以后, reference 会重新影响最优分布, 也成为实验必须报告的对象.

第三层选择发生在轨迹之间. 一道题采样八条回答, 可能有五条已经答对, 两条虽错但教师能从前缀中恢复, 还有一条进入循环、乱码或自相矛盾. 对八条轨迹统一求平均, 等于默认它们承载相同质量的训练信号. SCOPE 用 verifier 将正确与错误轨迹分开, 再分别根据学生和教师 perplexity 分配权重. 这里的 perplexity 是整条 response 的长度归一化概率, 它决定哪条轨迹的 token loss 更值得进入 batch, 没有替代 token 内部的 OPD 信号.

## 2. 两种故障把 OPD 推向两条分支

### 2.1. 标准 OPD 会复现教师, 也可能停在教师附近

当模型容量足够、优化达到理想解时, 最小化 $D_{\mathrm{KL}}(\pi_\theta\|\pi_T)$ 会把学生推向教师. 这个性质适合能力迁移, 也限定了目标的默认终点. 如果教师本身是从同一个 base model 经过领域 RL 得到的专家, 教师与 base 的 log-ratio 已经编码了后训练偏好. 只把学生拉到教师位置, 相当于完整复现这段移动;若希望沿同一方向再走一段, 普通 OPD 没有独立旋钮.

G-OPD 引入奖励系数 $\lambda$. $0<\lambda<1$ 时, 最优 log 概率位于 reference 与教师之间; $\lambda=1$ 回到普通 OPD; $\lambda>1$ 沿教师相对 reference 的方向外推, 这一区间称为 ExOPD. 论文在同尺寸数学与代码实验中观察到 $\lambda=1.25$ 稳定优于标准 OPD, $\lambda=1.5$ 已可能退化. 随 $\lambda$ 增大, 回答长度也上升, 暗示 log-ratio 奖励包含长度偏置. 奖励外推由此带来一个很清楚的新故障: 少量异常大的 token log-ratio 会被同步放大, 学生可能追逐 implicit reward 的尖峰.

reference 的选择决定「沿哪个方向」. 领域专家由共同 base 经 RL 得到时, 共同 base 是自然参照. 强教师向小学生蒸馏时, 默认只能拿到学生 base 与教师, 用学生 base 作 reference 会把架构、容量和预训练知识差异一起塞进奖励. 若教师的 pre-RL base 可用, 改用它可以更接近教师后训练真正引入的奖励, 同时增加一次大模型 log-prob 计算. 这属于奖励校正, 与换教师或给教师追加上下文没有同义关系.

### 2.2. 同一个教师在不同学生前缀上, 可靠性会变化

on-policy 的价值来自学生自己提供状态, 代价也来自这些状态. 学生一旦进入严重错误的推理分支, 教师必须在这个坏前缀后继续判断下一 token. 教师若仍能识别修复方向, dense KL 很有价值;教师若对前缀同样困惑, 大幅 log-ratio 可能只反映低概率与高熵, 并不代表一条可靠纠错路线.

SCOPE 的前置实验把错误轨迹按教师 perplexity 分桶, 再截取不同长度的错误前缀让教师续写. 在截断比例 0.2 时, 最低与最高 PPL 桶的恢复率分别为 64.9% 和 45.4%;截断比例 0.8 时分别为 35.8% 和 28.6%. 这组结果给出了经验上的筛选依据: 对错误轨迹, 教师越熟悉整条学生 response, 从其中间前缀恢复正确答案的概率通常越高. 它没有证明 PPL 能识别每一个 token 的因果错误, 因此 SCOPE 把它用作组内轨迹权重, 没有将它包装成过程奖励.

正确轨迹面对另一种问题. 高频成功路径本来就容易被学生采到, 均匀 MLE 会继续增加这些模式的质量;低概率但有效的解法在样本中更少, 每次出现又只拿到同样权重. SCOPE 对正确轨迹使用学生 PPL, 给学生自己觉得意外的成功更高权重. 这会部分抵消 on-policy 采样频率, 同时也会放大 verifier 误判、偶然猜对或格式漏洞, 所以验证器质量是这条路径的硬边界.

## 3. 三个坐标别混在一个算法名里

| 层 | 主要问题 | 典型改动 | 保持不变的对象 |
| --- | --- | --- | --- |
| 教师信息 | 教师为何比学生知道得多 | OPSD 的参考解、SDFT 的示范、SDPO 的反馈 | 学生 rollout 的状态来源 |
| 目标几何 | 师生差异沿哪个 reference 方向推进多远 | G-OPD 的 $\pi_{\mathrm{ref}}$ 与 $\lambda$ | 已选定的教师条件分布 |
| 轨迹价值 | 哪些 rollout 值得更强监督 | SCOPE 的正确/错误分流与组内 PPL 权重 | 每条错误轨迹内部的 token OPD 信号 |
| token 估计 | 一条轨迹内部怎样形成梯度 | full-vocab KL、top-$k$、sampled-token log-ratio | 轨迹怎样被采到与分组 |

[OPSD](../4.1-自蒸馏算法/4.1.2-OPSD.md)、[SDFT](../4.1-自蒸馏算法/4.1.3-SDFT.md) 与 [SDPO](../4.1-自蒸馏算法/4.1.4-SDPO.md) 位于表格第一行. 它们改变教师额外看到的条件 $c$, 让同源模型产生更强的 $\pi_T(\cdot\mid s,c)$. G-OPD 假定教师已经给定, 重新解释并缩放 $\log(\pi_T/\pi_{\mathrm{ref}})$. SCOPE 再观察 rollout 结果与 perplexity, 决定一条轨迹在 batch 中承担多少权重.

这几个部件在数学上可以组合. 例如 SDPO 用环境反馈构造特权教师, G-OPD 决定这份教师奖励相对 reference 的强度, SCOPE 决定不同成功或失败轨迹的损失权重. 组合后会出现新的耦合: SDPO 的反馈改变教师 PPL, ExOPD 放大教师/reference 的异常比率, SCOPE 又可能集中权重到少数轨迹. 单项有效不保证叠加有效, 消融需要一次只改变一个坐标.

还有一个容易被缩写遮住的区别: G-OPD 与 SCOPE 对「强信号」的定义并不相同. G-OPD 观察同一个动作在 teacher 与 reference 下的概率比, 比率大表示教师训练把该动作沿奖励方向推高. SCOPE 的错误分支观察 teacher 对整条学生 response 的平均概率, 概率高表示教师较熟悉这类前缀. 一个动作拥有很高 implicit reward, 它所在的错误轨迹仍可能让教师整体困惑;一条教师很熟悉的轨迹, 师生之间又可能几乎没有差异. 前者决定 token 更新方向和外推幅度, 后者决定整条轨迹进入 batch 的相对权重.

这两个量的统计尺度也不同. G-OPD 的 log-ratio 可正可负, 沿 token 相加后直接进入 advantage;SCOPE 的 PPL 始终为正, 经组内 softmax 后权重和为 1. 将 PPL 当奖励加进 token advantage, 会让它承担原论文没有赋予的信用分配作用;将 log-ratio 先在整条轨迹平均再只做筛选, 又会丢掉 OPD 的局部方向. 组合方法应保留两层结构, 再观察它们相乘后是否把梯度集中到少量样本.

从因果链看, 三层改动对应三种不同的失败对照. 怀疑教师信息不足时, 固定目标和权重, 比较带不带特权上下文的教师在同一批学生前缀上的续写正确率与 KL. 怀疑奖励强度不合适时, 固定教师与轨迹, 扫描 $\lambda$ 并替换 reference. 怀疑样本质量不均时, 固定每条轨迹的 token loss, 只切换均匀权重与双路径权重. 只有这种逐层固定, 才能把收益归到真实变化的量上.

## 4. 稳定性来自可分辨的观测量

训练曲线至少应拆成四组. 目标几何记录 teacher、reference 与 student 之间的 token log-ratio 和 KL;生成行为记录响应长度、EOS 概率、重复率与熵;轨迹组成记录每题正确/错误数量、两条分支的有效组数与权重熵;策略陈旧记录 $\rho_{i,t}$ 的分位数、裁剪比例和 rollout 到 learner 的版本差. 只画总 loss 会把这些变化压成一条无法归因的曲线.

这些观测量共同回答「更新方向、生成行为、样本组成和策略时差」四件事, 缺一项都可能把症状归错层.

G-OPD 的关键扫描量是 $\lambda$. 合理实验固定教师、reference、数据、采样温度和训练 token, 同时比较准确率与长度. 性能随 $\lambda$ 上升而提高, 长度也同步增加时, 还要用长度受控评测确认增益是否来自更多推理预算. 改用 teacher pre-RL reference 的实验则固定 $\lambda$, 否则 reward correction 与 reward extrapolation 的贡献无法拆开.

SCOPE 的关键扫描量是组大小 $N$ 和权重温度 $\tau$. $N$ 太小会频繁出现全对或全错组, 其中一条路径没有候选; $\tau$ 太小会把权重压到极少数异常轨迹, 太大又接近均匀 OPD. 论文在 $\tau\in\{0.5,1,2\}$ 中采用 1, 并通过移除、保留和反转两条权重做消融. AIME25 Pass@32 在移除整套 DPAW 后从 50.9% 降到 45.7%;反转教师权重使 AIME24 Avg@32 从 42.7% 降到 38.6%. 这些结果支持权重方向, 适用范围仍受数学验证器、所用学生和教师限制.

计算账也要对齐. G-OPD 若 reference 与已有冻结模型重合, 可以复用 log-prob;reward correction 使用 teacher pre-RL base 时, 多出一个大模型评分通道. SCOPE 每题生成多条轨迹并调用教师评分, 论文的同步实现每步总耗时为 641.9 秒, 对照 GRPO 为 459.0 秒、单 rollout OPD 为 227.5 秒. 其中教师评分占 200.0 秒, 权重计算本身很轻. 因而 SCOPE 的主要代价来自多 rollout 与教师服务, 不能把公式只多两个 softmax 当作全部开销.

## 5. 读完这一节应能做出的判断

看到「学生被教师上限卡住」时, 先检查目标是否确实收敛到教师, 再考虑 G-OPD 的奖励外推;看到长度和熵随外推一同漂移时, 应回查 log-ratio 的长度偏置与异常峰值. 看到「坏前缀上的教师信号很吵」时, 可以用 SCOPE 的教师 PPL 检查轨迹级可靠性;看到 Pass@1 上升而 Pass@k 下降时, 再检查正确轨迹是否过度集中到高频路径. 教师本身缺少信息时, 应回到 OPSD、SDFT 或 SDPO 的条件构造, 调权重无法创造教师没有的知识.

G-OPD 的完整推导、手算与 reference 边界见 [G-OPD: 从模仿教师到奖励外推](4.2.1-G-OPD.md). SCOPE 的双路径估计器、权重温度、空组与验证器边界见 [SCOPE: 按信号质量分配轨迹权重](4.2.2-SCOPE.md).
