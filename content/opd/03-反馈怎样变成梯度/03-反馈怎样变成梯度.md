# 教师反馈怎样变成梯度

学生已经产生轨迹, 教师也给出了某种反馈, 中间仍隔着一整段估计过程. 教师可能返回完整词表、top-$k$、已采 token 的 log-prob、自然语言批评或整段回答的分数. 训练器还要决定反馈作用于哪个 token、怎样处理旧轨迹, 以及最终用监督梯度还是策略梯度更新. 这些选择改变的不只是实现成本, 连优化目标也会一起变化.

本章把这条链拆成三个能够独立闭合的问题. [逐 token 教师信号怎么计算](3.1-逐token信号怎么计算.md) 研究同一个前缀上的词表信息与计算图;[旧轨迹还能训练多久](3.2-旧轨迹还能训练多久.md) 研究行为策略与 learner 分离后的状态偏移;[黑盒教师怎样提供反馈](3.3-黑盒教师怎样提供反馈.md) 研究 logits 不可见时, 文本、偏好和判别器怎样成为训练信号. 章首页只建立它们之间的关系, 公式推导与手算留在三篇叶子里.

## 1. 一条信号链里有四次选择

设学生 rollout 快照为 $\mu$, 当前 learner 为 $\pi_\theta$, 教师为 $p_T$. 学生在 prompt $x$ 上生成 $y$, 第 $t$ 步状态为 $s_t=(x,y_{<t})$. 一次更新可以抽象成

$$
x\xrightarrow{\mu} (s_t,a_t)
\xrightarrow{\text{teacher}} z_t
\xrightarrow{\text{estimator}} A_t
\xrightarrow{\text{optimizer}} \Delta\theta . \tag{1}
$$

$z_t$ 表示原始教师信息,$A_t$ 表示真正进入损失的权重或目标. 原始信息可能很丰富, 经过接口和估计器后只剩一个标量. 反过来, 一个序列分数也能通过 return-to-go、价值函数或过程定位影响多个动作. 因而「教师给了逐 token 反馈」只描述 $z_t$ 的位置, 还没有定义 $A_t$ 的计算图.

四次选择分别回答: 状态由哪个学生版本产生;教师在该状态上能看到什么;接口保留多少反馈;估计器把反馈分配给哪些动作. 某篇论文同时改变其中两三项时, 消融要逐项拆开, 否则总分上涨无法归因.

## 2. 反馈接口决定词表里还剩多少方向

| 接口 | 教师返回 | 学生直接得到的方向 | 主要代价 |
| --- | --- | --- | --- |
| Full-vocab | 每个词表项的概率 | 哪些候选该升、哪些该降 | 词表投影、显存与通信 |
| Top-$k$ | 高概率候选与可选尾部质量 | 头部替代动作, 尾部依赖重构规则 | 截断偏差与动态 $k$ |
| Sampled-token | 已采动作的教师 log-prob | 当前动作受不受教师支持 | 高方差, 缺少未采动作排序 |
| Black-box text | 续写、批评、偏好或分数 | 需经 SFT、偏好学习或奖励模型转换 | 查询成本与中间模型偏差 |

完整 forward KL 在固定状态上可以直接得到学生 logit 梯度 $q-p_T$, 教师对未采候选的偏好立即进入更新. Sampled-token 只观察 $a_t\sim\mu$ 这一件事, 常把师生 log-ratio 作为 advantage 接入策略梯度. 它能给每个已采 token 一个稠密数值, 无法直接指定被压低的概率应流向哪个未采 token. 这一区别称为词表路由, 由第一篇叶子的三 token 手算展开.

黑盒 API 连已采 token 的教师概率也不提供. 教师续写可以成为新示范, 教师比较可以形成偏好对, 教师文本还能训练判别器. GAD 让判别器区分教师回答与当前学生回答, 再把判别分数当作学生 rollout 的奖励. 学生状态仍来自当前策略, 梯度接口已经更接近奖励驱动 RL. 第三篇叶子用 SeqKD、GAD 与 SODA 对照这几种转换.

## 3. 时间信用与词表路由作用在不同维度

词表路由处理同一状态 $s_t$ 上的候选动作. 时间信用处理后续反馈是否影响此前动作. 即时 log-ratio 只更新当前位置, reward-to-go 则把后续师生差异累计回来:

$$
G_t=\sum_{u=t}^{T}r_u^T . \tag{2}
$$

若教师在第 $t$ 步已经知道正确分叉, full-vocab 局部目标可以立刻提高正确候选. 若错误要到第 $t+5$ 步才暴露, 当前步需要 sequence-level return、过程验证或回溯信号. 增加时间信用不会补回词表中未观测的替代动作;增加 full-vocab 也不会自动把未来失败归因到早期选择.

两者在长 CoT 中很容易混淆. 一条回答每个 token 都有教师 log-prob, 看起来比终局奖励密得多, 仍可能只形成零折扣即时优势. 训练结果改善说明局部教师方向有用, 不能据此推出模型已经解决长时程信用分配. 第一篇叶子的分叉任务把这两条轴分别开关.

## 4. 轨迹新鲜度是第三条轴

Rollout 由行为策略 $\mu$ 生成, learner 更新后变成 $\pi_\theta$. 一批数据训练多轮时, 状态和动作逐渐偏离当前策略. 单步重要性比

$$
\rho_t=\frac{\pi_\theta(a_t\mid s_t)}{\mu(a_t\mid s_t)} \tag{3}
$$

可以修正固定状态上的动作期望, 完整前缀分布还涉及此前比率的乘积. 长序列中的乘积会形成严重长尾, 所以训练器常采用裁剪、拒绝、单步近似或有限 replay. 每种稳定手段都带来不同偏差.

同一条冻结 rollout 内的 token 共用一个行为策略版本. 序列尾部更难, 通常来自累计分叉、教师可恢复性下降和样本数减少, 不是尾部 token 对应更旧 checkpoint. 真正的陈旧由 $\mu$ 与 $\pi_\theta$ 的距离决定. 第二篇叶子详细区分 rollout policy、old policy、reference policy 与 learner, 并给出重要性权重、ESS 与 Agent 环境回放的判断方法.

## 5. Outcome 与 self-play 改变信息来源

Outcome-based 方法只知道轨迹最终是否成功, 或由教师给出整段评分. 稀疏结果要经过优势估计才能作用于 token. 教师分布可以进一步提供局部方向:结果负责筛选「哪条路值得学」, 教师概率负责决定「同一路径下一步怎样移动概率」. 两路信号组合时要分别保存来源、尺度和归一化, 不能提前求和后只留下一个总奖励.

Self-play 改变的是教师身份. 多个样本互评、模型分别扮演解题者与批评者、历史策略给当前策略提供对手, 都能在学生状态上产生反馈. 信息增量可能来自角色上下文、工具结果、外部规则、多样本共识或历史能力. 所有角色共享相同信息和盲点时, 自洽容易强化共同错误.

外部锚点可以是单元测试、形式证明器、检索证据、人工标签或独立模型. 代码 self-play 可以由一个副本产题、另一个副本解题, 隐藏测试负责筛选;数学多样本可以互评证明, 答案检查器或证明助手负责确认. 第四章进一步讨论参考解、示范与环境反馈怎样形成特权自教师, 第五章把这些信号放回 CoT、OPD 与 RLVR 的推理训练链.

## 6. 一批数据经过训练器时发生什么

Rollout 阶段保存 `input_ids`、response mask、行为 log-prob、采样配置与学生版本. 教师评分阶段追加完整 logits、top-$k$ 结果、已采 token 概率或黑盒反馈. Learner 用当前参数重算学生 logits, estimator 构造局部目标或 advantage, optimizer 只更新学生. EMA 自教师在 optimizer step 后按自己的时间尺度移动.

这条数据流里最常见的错误来自身份混淆. Prompt token 进入响应损失, EOS 与截断位置没有区分, rollout log-prob 被误当作当前 learner log-prob, reference policy 被误当作行为策略, 或教师模板改写了学生前缀. Loss 仍然可能平稳下降, 优化的却已是另一个目标.

最低限度的诊断应同时观察任务成功率、回答长度、重复率、师生 KL、教师优势分位数、top-$k$ 覆盖、重要性比与 rollout 版本差. 这些量分别对应任务、生成行为、教师信息、估计器与状态分布. 异常发生时, 先确定它属于哪一段信号链, 再调整相应组件;统一降低学习率只能同时压小正确与错误信号.
