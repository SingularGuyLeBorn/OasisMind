# 旧轨迹还能拿来训练多久

生成一批长回答很贵, 自然会想多训练几轮. 但学生参数更新后, 旧轨迹不再来自当前策略. 设生成轨迹的行为策略为 $\mu$, 当前 learner 为 $\pi_\theta$, 单步重要性比是

$$
\rho_t=\frac{\pi_\theta(y_t\mid s_t)}{\mu(y_t\mid s_t)}.
$$

$\rho_t$ 接近 1 时, 旧动作仍能代表当前学生. 长序列若把比率连乘, 方差会迅速失控;逐 token 截断能稳定训练, 同时引入偏差. 与其追求形式上的无偏, 更实用的做法是限制 checkpoint 版本差和最大复用轮数, 并监控 ratio 的分位数.

旧轨迹也有价值. 它可能保存当前学生已经很少访问的失败状态, 帮助模型避免能力回退;还可以让教师评分与 learner 并行, 提高设备利用率. 使用 replay 时需要测量样本变旧后, 梯度是否仍与新轨迹一致.

可以按生成版本把样本分桶, 比较每桶的师生 KL、importance ratio、梯度余弦和任务收益. 若旧桶开始与新桶产生系统性梯度冲突, 继续复用只是在提高无效吞吐. 对长 CoT, 还应按 token 位置统计, 因为序列尾部生成得更晚, 更容易面对策略滞后.

严格 on-policy、near-policy 与 replay 形成连续谱. 新鲜样本最贴近当前错误, 历史样本吞吐更高并保留罕见状态. **轨迹新鲜度是一项可测的训练变量, 不是方法名称里的道德判断.**
