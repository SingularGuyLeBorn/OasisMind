# SCOPE: 按信号质量分配轨迹权重

同一道数学题采样八次, 八条轨迹的训练价值差得很远. 一条高概率正确解可能只是模型反复走的老路;一条低概率正确解可能刚好落在能力边界;一条错误解停在可修复的算术偏差;另一条错误解已经进入重复循环, 连教师读完前缀都不知道该往哪里接. 标准 OPD 对所有 rollout 均匀蒸馏, 等于假设教师在每条轨迹上同样可靠, 每次成功也同样值得强化.

SCOPE 从这个假设下手. 它让 verifier 先把同题轨迹分成正确与错误两组. 正确轨迹不再模仿教师, 改为强化学生自己生成的答案, 并给学生低置信的成功更高权重. 错误轨迹继续接受逐 token OPD, 但教师越不熟悉整条错误 response, 该轨迹权重越低. 权重发生在轨迹层, 每条错误轨迹内部仍由 token importance ratio 和师生 log-ratio 决定梯度. 这两层若混成一句「按 PPL 加权 token」, 会误解算法实际改动的位置.

## 1. 两种均匀训练各自损失了什么

对正确 rollout 做均匀 MLE, 可以提高单次采样命中率, 也会反复强化本来就常见的路径. on-policy 样本的出现频率已经与学生概率成正比, 再给每条出现的正确轨迹相同更新, 高频模式获得双重优势. SCOPE 论文引用的 positive sample reinforcement 结果中, Qwen2.5-7B 的 Pass@1 上升, Pass@32 却从 93.7% 降到 84.9%. 单次最优路径更集中, 多次采样覆盖的解法变少.

把正确轨迹也交给教师做 OPD, 同样可能压低学生独有的有效路径. 教师与学生在某条正确推理上分布不同, 差异未必代表学生错误;它可能来自两种都成立的证明、不同的代码结构或教师自己的模式偏好. SCOPE 的前置实验观察到普通 OPD 提高 Pass@1 时, Pass@32 从 76.5% 降到 75.0%. 变化不如 PSR 剧烈, 仍说明 dense teacher supervision 没有自动解决多样性收缩.

错误 rollout 的问题正好相反. 它没有可以直接强化的成功目标, 因而需要教师指出局部方向. 可是 on-policy 教师必须在学生已经写出的前缀后评分. 前缀只错一个符号时, 强教师也许能恢复;前缀堆满矛盾、乱码或循环时, 教师分布会变平, sampled-token log-ratio 的绝对值还可能很大. 均匀 OPD 会让这类高噪声样本与可修复错误拥有相同轨迹权重.

论文用 2000 道 DeepMath 题、每题 4 条学生轨迹做了恢复实验. 错误轨迹按教师 PPL 分成四个等量桶, 再按 0.2、0.4、0.6、0.8 的比例截断到换行边界, 让教师从错误前缀继续生成 4 次. 截断比例 0.2 时, 最低 PPL 桶恢复率为 64.9%, 最高 PPL 桶为 45.4%;比例 0.8 时两者为 35.8% 和 28.6%. 前缀越长越难恢复, 同一长度下较低教师 PPL 又与较高恢复率相关. 这是一条受控经验规律, 支撑 PPL 作为轨迹筛选代理, 没有把 PPL 证明成逐 token 正确性的充分条件.

## 2. verifier 先决定每条轨迹走哪条路

对 prompt $x$, 行为策略 $\pi_{\mathrm{old}}$ 生成 $N$ 条 response:

$$
Y^x=\{y_1,\ldots,y_N\},qquad
y_i=(a_{i,1},\ldots,a_{i,|y_i|}).
$$

verifier 给每条轨迹二值结果 $R_i\in\{0,1\}$, 形成两个集合

$$
\Omega_c^x=\{i:R_i=1\},qquad
\Omega_w^x=\{i:R_i=0\}. \tag{1}
$$

这个分组使用序列最终结果, 没有声称知道哪一个 token 导致成功或失败. verifier 在这里承担路由器职责: 结果正确的轨迹走学生路径, 结果错误的轨迹走教师路径. 数学答案解析器、代码单测或形式验证器适合提供这种路由;开放式写作中的模糊打分很难稳定划出同样边界.

learner $\pi_\theta$ 更新时, 轨迹仍来自旧策略. 第 $t$ 个 token 的重要性比率为

$$
\rho_{i,t}(\theta)=
\frac{\pi_\theta(a_{i,t}\mid x,a_{i,<t})}
{\pi_{\mathrm{old}}(a_{i,t}\mid x,a_{i,<t})}. \tag{2}
$$

论文实验每个 batch 只更新一个 epoch, 减少 $\pi_\theta$ 与 $\pi_{\mathrm{old}}$ 的距离. 公式仍保留 $\rho$, 因为生成与 learner 前向之间不一定完全同步. 这个比率属于 token 层, 它校正策略陈旧;后面的 PPL 权重属于 trajectory 层, 它表达同题组里哪条 response 更值得学习.

### 2.1. 正确轨迹用学生自己的成功做 MLE

对 $i\in\Omega_c^x$, SCOPE 使用 surrogate

$$
\mathcal L_{\mathrm{MLE}}(x,y_i;\theta)
=-\sum_{t=1}^{|y_i|}\rho_{i,t}(\theta). \tag{3}
$$

式 (3) 的数值形式看起来不像常见的 $-\sum_t\log\pi_\theta(a_{i,t})$, 梯度却在 $\theta=\theta_{\mathrm{old}}$ 附近对应 on-policy MLE. 因为

$$
\nabla_\theta\rho_{i,t}
=\rho_{i,t}\nabla_\theta\log\pi_\theta(a_{i,t}\mid s_{i,t}),
$$

当 $\rho=1$ 时, 最小化式 (3) 产生 $-\nabla\log\pi_\theta$ 的更新. 它强化学生实际生成并通过验证的 token, 不要求教师赞同这条推理风格.

这条路径保留学生自己的有效模式, 同时继承自训练的边界. verifier 若只检查最终答案, 一条推理错误、碰巧猜对的 response 也会被强化;代码测试覆盖不全时, 利用测试漏洞的实现会被当作成功. SCOPE 后续的高 PPL 加权还可能放大这种罕见假阳性. 因而正确路径依赖 verifier precision, 不能只看组内正样本数量.

### 2.2. 错误轨迹保留逐 token 教师信号

对 $i\in\Omega_w^x$, 教师策略为 $\pi_T$. SCOPE 使用 sampled reverse-KL surrogate:

$$
\mathcal L_{\mathrm{OPD}}(x,y_i;\theta)
=\sum_{t=1}^{|y_i|}\rho_{i,t}(\theta)
\left[
\log\pi_{\bar\theta}(a_{i,t}\mid s_{i,t})
-\log\pi_T(a_{i,t}\mid s_{i,t})
\right], \tag{4}
$$

$\bar\theta$ 从梯度图中 detach. 方括号里的量是每个已采 token 的 OPD 信号. 教师比学生更支持该 token 时, 差值为负, 最小化损失会提高它的概率;教师反对时, 差值为正, 更新会压低它. 轨迹即使最终答错, 前半段仍可能包含教师认可的定义、变形和中间结论, 逐 token 信号可以保留这些局部结构.

式 (4) 只查询学生采到的动作. 教师更希望改成哪个未采 token, 没有直接进入梯度;概率质量流向取决于学生 softmax 与后续采样. SCOPE 改善了哪些错误轨迹值得蒸馏, 没有把 sampled-token 估计器变成 full-vocab KL. 若系统改用完整教师分布, 轨迹权重仍可乘在 full-vocab 损失外层, 但那已经是基于 SCOPE 思路的另一种实现, 不能拿原论文的计算成本直接套用.

## 3. 两个方向相反的 PPL 权重

定义模型 $M$ 对 response 的长度归一化 perplexity:

$$
\operatorname{PPL}_M(y_i\mid x)
=\exp\left(
-\frac{1}{|y_i|}
\sum_{t=1}^{|y_i|}
\log\pi_M(a_{i,t}\mid x,a_{i,<t})
\right). \tag{5}
$$

长度归一化让 PPL 表示平均 token 惊讶度, 避免序列概率随长度指数下降. 它仍会受 tokenizer、回答风格与重复模式影响, 所以权重只在同一个 prompt 的同类轨迹组内归一化.

正确组使用学生 PPL 的正方向:

$$
w_i^{\mathrm{stu}}
=\frac{\operatorname{PPL}_S(y_i\mid x)^{1/\tau}}
{\sum_{j\in\Omega_c^x}
\operatorname{PPL}_S(y_j\mid x)^{1/\tau}}. \tag{6}
$$

学生越意外却又答对的轨迹, 权重越大. 错误组使用教师 PPL 的反方向:

$$
w_i^{\mathrm{tea}}
=\frac{\operatorname{PPL}_T(y_i\mid x)^{-1/\tau}}
{\sum_{j\in\Omega_w^x}
\operatorname{PPL}_T(y_j\mid x)^{-1/\tau}}. \tag{7}
$$

教师越熟悉一条错误 response, 该轨迹的蒸馏权重越大;教师 PPL 很高时, 权重接近零. $\tau$ 控制组内 softmax 的尖锐程度. $\tau$ 较小会集中到极少数轨迹, 较大则趋向均匀.

取三条正确轨迹, 学生 PPL 分别为 $(1.2,1.8,3.0)$, $\tau=1$. 权重约为 $(0.20,0.30,0.50)$, 最意外的正确轨迹承担一半正确分支更新. 三条错误轨迹的教师 PPL 若同样为 $(1.2,1.8,3.0)$, 取倒数后归一化得到约 $(0.47,0.31,0.19)$. 同一组数值在两条路径上方向相反: 学生意外的成功值得挖掘, 教师意外的失败前缀应降低蒸馏强度.

整体目标为

$$
\mathcal J_{\mathrm{SCOPE}}
=\mathbb E_{x\sim\mathcal D}
\left[
\sum_{i\in\Omega_c^x}w_i^{\mathrm{stu}}
\mathcal L_{\mathrm{MLE}}(x,y_i)
+\sum_{i\in\Omega_w^x}w_i^{\mathrm{tea}}
\mathcal L_{\mathrm{OPD}}(x,y_i)
\right]. \tag{8}
$$

两个集合各自归一到 1. 当两组都非空时, 正确分支和错误分支各形成一个轨迹梯度的凸组合, 总体上拥有相近的分支级尺度;组内有多少条样本不会线性放大该分支. 某一组为空时, 对应求和项应消失, 实现必须避免对空集合做 softmax. 每题只采一条轨迹时, 非空组内权重恒为 1, 双路径加权失去组内选择能力.

## 4. 轨迹权重怎样作用到 token 梯度

把式 (8) 展开, 正确轨迹的第 $t$ 个 token 梯度近似带有系数 $w_i^{\mathrm{stu}}\rho_{i,t}$;错误轨迹则带有

$$
w_i^{\mathrm{tea}}\rho_{i,t}
\operatorname{sg}\!\left[
\log\pi_{\bar\theta}(a_{i,t}\mid s_{i,t})
-\log\pi_T(a_{i,t}\mid s_{i,t})
\right]. \tag{9}
$$

$w_i$ 对同一条 response 的所有 token 相同, token 之间的差异来自 $\rho_{i,t}$ 与局部师生 log-ratio. 所以 SCOPE 有两级信号: 轨迹级 PPL 判断整条 response 是否值得较强更新, token 级 OPD 判断已采动作在该位置应升还是应降. 它没有在一条轨迹内部自动定位首个逻辑错误, 也没有把后续失败的信用通过 reward-to-go 传回早期动作.

PPL 按长度归一, 式 (3) 与式 (4) 却沿 token 求和. 两条轨迹拥有相同 $w_i$ 时, 较长 response 仍可能贡献更大梯度范数. 因而长度归一只防止权重天然偏爱短序列, 没有消除 loss 聚合中的长度效应. 若实现再对每条 response 的 token loss 取平均, 分支目标会改变, 结果应与原论文的求和形式分开报告.

这种乘法结构会产生几个值得直接观测的量. 一条低教师 PPL 的错误轨迹获得高 $w_i^{\mathrm{tea}}$, 但师生几乎一致时, token log-ratio 很小, 实际梯度仍小. 一条高 PPL 轨迹虽然被降权, 某个 token 的 log-ratio 极大时仍可能留下明显梯度. 权重温度只调外层相对比例, log-prob floor、importance ratio 和 token loss clip 才控制内层尖峰. 把所有稳定性都归给 $\tau$ 会漏掉乘法另一侧.

组内归一化控制权重总和. 对一组梯度 $g_i$, 有

$$
\left\|\sum_iw_ig_i\right\|
\leq\sum_iw_i\|g_i\|
\leq\max_i\|g_i\|. \tag{10}
$$

这条上界说明 raw PPL 不会直接把组梯度无限放大, 没有保证不同轨迹梯度相互同向, 也没有约束 token log-ratio 自身. SCOPE 论文明确把该加权描述为 signal-calibrated bias: 它有意改变原始 on-policy 期望, 强调罕见正确路径和教师可信的错误轨迹, 并不追求原始 OPD 的无偏估计.

错误路径的动机还能从梯度二阶矩看出来. 令

$$
A_{i,t}=\log\pi_{\bar\theta}(a_{i,t}\mid s_{i,t})
-\log\pi_T(a_{i,t}\mid s_{i,t}),
$$

若 score function 范数满足 $\|\nabla\log\pi_\theta(a_{i,t}\mid s_{i,t})\|\leq G$, 单条 response 的 OPD 梯度二阶矩可由

$$
\mathbb E\|g_{\mathrm{OPD}}(x,y_i)\|^2
\leq |y_i|G^2\sum_t\mathbb E[A_{i,t}^2] \tag{11}
$$

控制. 教师在坏前缀上给已采 token 极低概率时, $A_{i,t}$ 绝对值变大, 更新方差随平方增长. teacher PPL 汇总了整条轨迹上的低 likelihood 区域, 式 (7) 因而倾向于压低高二阶矩样本. 这是上界驱动的机制解释, 没有推出 PPL 权重在所有分布下达到最小方差;token 间相关、学生 log-prob 与梯度范数都被上界放松了.

两个分支各自归一还隐含了分支平衡选择. 某题七条正确、一条错误时, 错误轨迹仍独占错误分支总权重 1, 与七条正确轨迹构成的凸组合并列;某题一条正确、七条错误时则相反. 这让稀少分支不会因数量少而消失, 也可能让单个异常样本权重过大. 组内数量、分支 loss 范数和 verifier 置信度共同决定实际平衡, 单看 $w_i$ 的和无法判断哪个分支主导参数更新.

若希望分支权重跟随正确率, 可以再乘 $|\Omega_c|/N$ 与 $|\Omega_w|/N$;若希望每题始终兼顾巩固与纠错, 可以保持两边各 1 或另设系数. 两者优化的目标不同. 原 SCOPE 公式采用分支内归一, 文章中的消融结论对应这一定义, 不能在悄悄乘入组占比后仍把结果解释成同一个目标.

正确路径的权重还能从采样频率理解. 忽略长度归一与组内常数, $w^{\mathrm{stu}}(y)\propto\pi_S(y)^{-1/(\tau|y|)}$. on-policy 抽到 $y$ 的概率原本正比于 $\pi_S(y)$, 加权后有效指数降为 $1-1/(\tau|y|)$. 高频路径的优势被削弱, 却没有完全消失;长度 $|y|$ 很大时, 指数修正也较温和. 因而 SCOPE 是部分频率校正, 不会保证每种正确推理模式得到均匀覆盖.

## 5. PPL 是有证据的代理量, 也有清楚盲区

教师低 PPL 表示教师给学生这条 response 较高平均概率. 对错误轨迹, 这可能意味着前缀结构尚且连贯, 教师能在局部位置提供稳定分布;恢复实验支持这一解释. 它也可能意味着教师同样认可一条最终错误路径. 后一种情况下 $w_i^{\mathrm{tea}}$ 很高, 师生 log-ratio却可能很小, 训练获得不了多少纠错方向. 低 PPL 衡量熟悉度, 没有直接衡量教师相对 verifier 的正确性.

教师高 PPL 也有两种来源. 学生前缀可能已经彻底崩坏, 继续蒸馏价值低;也可能只是学生找到一种教师不熟悉但接近正确的表示, 最终因一个小错误失败. SCOPE 会压低两者. 若任务拥有过程验证、错误定位或可执行状态, 可以把 PPL 与错误类型联合分析;原方法保持简单, 选择以总体恢复率相关性换取一定误筛.

学生高 PPL 的正确轨迹可能是有价值的另类路线, 也可能是长尾噪声、答案泄漏或 verifier 漏洞. 二值结果把这些情况全放进 $\Omega_c$. 高 PPL 加权对 verifier 的假阳性尤其敏感: 高频正常正确解权重下降, 罕见漏洞解权重上升. 数学精确答案和覆盖充分的代码测试更适合这套假设;主观评分任务应额外检查人工一致性与 reward hacking.

PPL 还受长度平均掩盖. 一条长 response 前半段很流畅, 末尾突然崩坏, 平均教师 PPL 可能仍低;另一条短 response 只有一个罕见符号, 平均 PPL 可能很高. SCOPE 用 response 级 PPL 是为了稳定和低开销, 没有完成位置级可靠性估计. 若改成 prefix PPL、滑动窗口或逐 token 熵, 权重会变成新的算法, 需要重新验证方向与方差.

组内相对权重还意味着跨题 PPL 不可直接比较. 一道简单题的错误轨迹 PPL 全在 1.2 附近, 一道困难题全在 3.0 附近, 两题各自仍会产生和为 1 的错误分支. 困难题里「相对最低」的 2.7 可能比简单题里最高的 1.4 更不可靠, 组内 softmax却会给前者较高权重. 这种设计避免困难题因 raw PPL 大而完全失去训练机会, 同时放弃跨题绝对可靠性门槛. 若教师在一整题上都失去能力, 相对排序救不了它, 需要额外的阈值、题目过滤或更强教师.

student PPL 同样是组内量. 两条正确轨迹都来自极易题时, 较高 PPL 的那条仍会被强调;这不等于它比另一道难题的正确轨迹更接近全局能力边界. SCOPE 选择「每题内部找少见成功」, 因而减少 prompt 难度和长度尺度差异. 代价是每题必须生成足够多样本, 才有可比较的正确轨迹. $N=1$ 时这层统计结构完全消失.

## 6. 消融怎样支撑双路径设计

论文以 DeepSeek-R1-Distill-Qwen-1.5B 搭配 SkyWork-OR1-7B, 以及 Qwen3-1.7B-Base 搭配 Qwen3-8B-Instruct. 训练数据为 DeepMath, 主实验覆盖 AIME24、AIME25、AMC23、MATH500、Minerva 与 OlympiadBench, 同时报告 Avg@32 和 Pass@32. 前者看平均单样本稳定性, 后者看 32 次采样至少一次成功的覆盖能力.

主配置下, SCOPE 相对标准 OPD 的 Avg@32 平均相对提升为 11.42%, Pass@32 平均相对提升为 7.30%;论文表中的六个数学基准汇总还给出 Avg@32 平均提升 5.54 个百分点. 百分比与百分点口径不同, 写结果时应保留原表含义. Pass@k 曲线在较大 $k$ 继续上升, 支持低概率正确路径没有像均匀强化那样快速收缩.

移除整套 DPAW 后, AIME25 Pass@32 从 50.9% 降到 45.7%. 去掉 student-guided weight, AIME24 Pass@32 从 77.9% 降到 74.1%;反转权重方向同样退化. teacher-guided weight 被移除或反转也损害结果, 其中反转教师方向使 AIME24 Avg@32 从 42.7% 降到 38.6%. 这些消融同时验证了「高学生 PPL 正确样本上调」和「高教师 PPL 错误样本下调」的方向, 比只比较 SCOPE 与 OPD 更能对应公式中的具体变量.

权重温度扫描 $\tau\in\{0.5,1,2\}$, 论文采用 1. $\tau=0.5$ 让权重过度集中到极端 PPL, 容易放大 outlier; $\tau=2$ 使分布变平, 逐渐退回均匀 OPD. 这个结果说明自适应强度存在中间区间, 没有证明 1 能跨模型复用. 组大小、采样温度和 teacher/student 差距都会改变 PPL 分布, $\tau$ 应与权重熵和最大权重一起报告.

训练配置里 GRPO 与 SCOPE 每题生成 8 条, 标准 OPD 只生成 1 条. 同步实现的单步总耗时分别为 459.0、641.9 和 227.5 秒;SCOPE 的教师评分占 200.0 秒, 权重计算开销很小. 这组数字揭示收益与成本的真实来源: SCOPE 既用了质量加权, 也用了更大的同题 rollout 组. 消融支持 DPAW 的额外贡献, 系统预算比较仍应固定总生成 token、教师评分 token 与墙钟时间.

这里还有一个评测口径上的细节. Avg@32 把 32 次采样的平均正确率作为单样本能力, Pass@32 衡量至少一次成功的覆盖. 模型只把概率集中到一条常见正确路径时, Avg@32 可能提高, Pass@32 的边际增长却变慢;模型保留多个低概率有效模式时, 两者可能同时改善, 也可能以少量平均准确率换取更高覆盖. SCOPE 的动机更接近同时维护这两条曲线, 所以只报 greedy accuracy 无法检验「低概率正确路径被保留」这一主张.

论文的恢复实验则检验错误分支代理量. 它测教师从截断错误前缀继续生成后的最终正确率, 与训练中的逐 token log-ratio并非同一个指标. 前者说明 teacher PPL 能预测宏观恢复能力, 后者才直接进入梯度. 更强的机制验证可以在相同 PPL 桶内测 token advantage 方差、梯度范数与一次更新后的纠错率, 看轨迹权重是否确实过滤了高噪声梯度, 而非只筛掉较难题目.

### 6.1. 与 OPSD、SDFT、SDPO 以及 G-OPD 的位置关系

[OPSD](4.1-OPSD.md) 把参考解放进教师上下文, [SDFT](4.2-SDFT.md) 用示范唤起 in-context 能力, [SDPO](4.3-SDPO.md) 使用环境反馈或同题成功轨迹. 三者改变教师知道什么, 从而改变 $\pi_T(\cdot\mid s,c)$. SCOPE 接收一个已经确定的教师, 再根据 verifier 与 PPL 决定哪些 rollout 用 MLE, 哪些用 OPD, 每条轨迹占多大权重.

[G-OPD](4.5-G-OPD.md) 修改错误路径内部也可使用的 OPD 目标: reference 决定隐式奖励坐标, $\lambda$ 决定奖励相对 KL 约束的强度. SCOPE 修改轨迹外层权重. 两者结合时, 式 (4) 可以换成 G-OPD 的 token advantage, 再乘 $w_i^{\mathrm{tea}}$;这会同时放大 reward extrapolation 和轨迹筛选, 极端 log-ratio 可能在少数低 PPL 轨迹上集中. 这种组合从公式上可以成立, 仍需联合实验检验.

SDPO 与 SCOPE 都使用结果信息, 落点依然不同. SDPO 把环境反馈送进教师上下文, 让反馈改变每个状态的教师分布;SCOPE 用二值结果路由整条 response, verifier 文本不会自动进入教师. 同一个系统可以让错误轨迹先由反馈条件化教师评分, 再用教师 PPL 加权, 但 PPL 此时也会随反馈模板变化, 原论文的恢复率关系需要重测.

### 6.2. 一组可复算的验证实验

最小实验先用一个 prompt 和四条固定轨迹. 两条正确、两条错误, 手工指定 student/teacher token log-prob 与长度. 逐条算式 (5) 到式 (7), 检查两组权重各自和为 1;交换正确轨迹的 student PPL 后, 只有正确分支权重交换;交换错误轨迹的 teacher PPL 后, 只有错误分支变化. 将 $\tau$ 增大, 权重应连续趋近均匀.

梯度检查分开冻结 trajectory weight 与 token signal. 正确路径在 $\theta=\theta_{\mathrm{old}}$ 时, 式 (3) 的自动微分应与 $-\sum_t\nabla\log\pi_\theta(a_t)$ 一致. 错误路径固定 $w_i^{\mathrm{tea}}$ 后, 教师更支持的已采 token 应获得提高概率的方向. 把 $\bar\theta$ 的 detach 去掉会出现额外梯度, 这项测试能抓到 teacher/student 计算图串联.

真实训练再记录每题 $|\Omega_c|$、$|\Omega_w|$、两个分支的权重熵、最大权重、teacher PPL 分桶恢复率、Pass@1 与 Pass@k. 全对组频繁出现时, 错误纠正分支缺样本;全错组频繁出现时, 正确 MLE 分支缺样本;一半一半只是采样结果, 并非算法要求. 将 verifier 人为注入少量假阳性, 可以直接测量高 student PPL 权重对错误成功标签有多敏感.

读者最终应能区分三句话: 「这条轨迹答对了」来自 verifier, 「学生觉得这条正确轨迹有多意外」来自 student PPL, 「教师在这条错误轨迹上有多熟悉」来自 teacher PPL. 三个信号各管一层, 任意一个失真都会把权重送到错误位置.
