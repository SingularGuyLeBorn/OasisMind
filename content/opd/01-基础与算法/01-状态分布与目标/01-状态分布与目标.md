# 状态分布与目标

OPD 文献最容易混淆的地方, 是把「学生生成轨迹」和「使用 reverse KL」绑定成一个概念. 两者并不绑定. 轨迹来源决定外层期望在哪些状态上取值; 散度方向决定同一个状态上如何比较师生下一 token 分布; 是否对采样分布求导又决定当前动作是否承担未来状态的影响. 三条轴分别改变算法, 应当逐项记录.

设输入为 $x$, 回答为 $y$, 状态为 $s_t=(x,y_{<t})$. 对任意采样策略 $\mu$, 状态访问分布记为 $d_\mu(s)$. 一个统一目标是

$$
\mathcal J(\theta;\mu)=\mathbb E_{s\sim d_\mu}
\left[D_f\!\left(\pi_T(\cdot\mid s),\pi_\theta(\cdot\mid s)\right)\right]. \tag{1}
$$

当 $\mu$ 是固定数据生成策略时, 式 (1) 是 off-policy 蒸馏; 当 $\mu=\pi_{\theta_k}$ 且每轮刷新时, 式 (1) 是 stop-gradient OPD. 若让 $\mu=\pi_\theta$ 并对其参数依赖求导, 目标会多出 score-function 梯度. [GKD](01-GKD.md) 主要研究前两种之间的混合与 $D_f$ 的选择; [MiniLLM](02-MiniLLM.md) 从序列 reverse KL 推导后一种.

## 状态与散度

### 前缀来源改变学习位置

固定参考答案给出的前缀通常语法正确、推理连贯. 学生自由生成后的前缀可能包含错误变量、重复句段、格式破损或已经走错的中间结论. 在固定前缀上学会预测教师, 不保证学生能从自身错误状态恢复. 自回归依赖使单步误差改变后续输入, 这正是模仿学习中状态分布偏移的来源.

DAgger 的做法是让学习者执行, 再让专家标注学习者访问的状态. OPD 把专家动作扩展为下一 token 分布. 但教师分布只描述局部下一步, 并不自动提供长程信用分配. 如果学生已经走到一个无解前缀, 教师仍必须在该前缀后分配概率; 局部最合理的 token 不一定能恢复全局任务. 因而学生状态覆盖部署分布是必要改进, 不是教师监督正确性的保证.

混合 roll-in 可以在两种风险之间折中. 教师或数据前缀比例高, 状态更规整, 训练初期稳定, 但学生错误区域覆盖不足. 学生比例高, 分布匹配更直接, 但弱学生会产生大量低质量状态. 混合比例应和学生冷启动质量一起报告; 只写「使用 on-policy 数据」不足以复现实验.

### 散度方向改变局部压力

在一个固定状态 $s$ 上, 令教师分布为 $p(v)$, 学生分布为 $q(v)$. forward KL 与 reverse KL 分别为

$$
D_{\mathrm{KL}}(p\|q)=\sum_v p(v)\log\frac{p(v)}{q(v)}, \tag{2}
$$

$$
D_{\mathrm{KL}}(q\|p)=\sum_v q(v)\log\frac{q(v)}{p(v)}. \tag{3}
$$

式 (2) 由教师概率加权. 教师认为可能而学生漏掉的 token 会产生强梯度, 因而倾向覆盖教师支持. 式 (3) 由学生概率加权. 学生已经放高概率、教师却不支持的 token 会被重点压低, 学生没有探索到的教师模式贡献很小. 两者都可以在学生前缀上计算, 所以两者都可以是 OPD.

散度方向还决定需要谁的完整分布. 精确 forward KL 的梯度可以由教师全词表概率监督学生; 精确 reverse KL 也需要学生全词表概率以及相应教师 log-prob. sampled-token 估计天然适合以学生为采样分布的量, 但一个样本无法同时重建教师低概率尾部的结构. top-$k$ 介于两者之间, 且必须说明 $k$ 由教师还是学生选择、尾部概率是否聚合.

## 梯度与手算

### 采样梯度决定信用分配

式 (1) 若把 $d_{\pi_\theta}$ 当作常数, 梯度只更新每个已访问状态上的条件分布. 当前 token 改变未来前缀的路径被停止. 这种估计计算稳定, 可以像普通 token 级监督一样反向传播. GKD 明确采用学生生成序列, 再在序列上计算平均 token 散度;工程实现常把 rollout 与 learner 解耦, 正是这一估计的系统表达.

若目标本身是两个序列分布的 reverse KL, 轨迹概率也依赖 $\theta$. 对数导数技巧会把后续 log-ratio 汇成 reward-to-go, 当前动作因而承担未来差异. MiniLLM 的推导保留了这项, 再用单步分解、教师混合采样和长度归一化降低方差. **是否有未来回报, 取决于对哪个数学目标求导, 不能只看损失名称里有没有 reverse KL.**

有些 RL 框架把逐 token 的 $\log\pi_T-\log\pi_\theta$ 当作奖励, 并令折扣为 0. 这种实现只保留当前 token 的局部比值, 便于复用 policy-gradient 基础设施, 但没有 MiniLLM 的完整未来项. 训练日志中应区分「逐 token KL 监督」「零折扣 sampled-token reward」与「序列 reverse-KL policy gradient」.

### 一个三 token 走查

考虑词表只有 $\{A,B,C\}$, 某个学生前缀上教师分布为 $p=(0.7,0.2,0.1)$, 学生分布为 $q=(0.4,0.4,0.2)$. forward KL 为

$$
0.7\log\frac{0.7}{0.4}+0.2\log\frac{0.2}{0.4}+0.1\log\frac{0.1}{0.2}\approx0.184. \tag{4}
$$

reverse KL 为

$$
0.4\log\frac{0.4}{0.7}+0.4\log\frac{0.4}{0.2}+0.2\log\frac{0.2}{0.1}\approx0.192. \tag{5}
$$

两个数接近, 梯度来源却不同. 式 (4) 的最大权重落在教师的 $A$ 上; 式 (5) 对学生过量分配的 $B,C$ 更敏感. 若学生只采到 $B$, sampled-token reverse-KL 样本是 $\log0.4-\log0.2=\log2$. 该样本完全没有告诉训练器 $A$ 应从 $0.4$ 升到 $0.7$, 只有多次采样的期望才恢复式 (5).

状态再向前走一步时, 差异会扩大. 若采到 $B$ 后教师进入一个低置信状态, 下一步教师分布可能接近均匀. stop-gradient 局部训练只处理两个已观察状态; 序列目标还会把第二步的 log-ratio 归因给第一步动作 $B$. 这正是局部监督与序列信用分配的分界.

## 使用边界

### 训练前检查与失效模式

第一项检查是学生起点. 如果大部分 rollout 无法通过格式解析, 教师监督会集中在格式修复, 很少进入任务核心状态. 第二项是教师兼容性. 教师在自身答案上强, 不代表在学生前缀上稳定; 应测教师对学生轨迹的 token NLL、top-token 重合和优势分布. 第三项是支持重合. 师生 tokenizer、特殊 token 或聊天模板不一致时, 逐 token 对齐可能从输入端已经失效.

训练中常见的表面成功是 KL 降低而任务分数不升. 原因可能是回答缩短、熵下降、重复增多或 rollout 版本过旧. 另一种失败是教师过强且风格不兼容: 学生访问的状态在教师分布下极低概率, 教师每个位置都给出尖锐但互不连贯的局部修正. 混入教师前缀可以缓解分布断裂, 但会削弱严格 on-policy 覆盖.

### 路线选择

需要一个稳定、容易并入监督训练栈的起点时, 先读 GKD. 它把 rollout 当作数据, 允许混合固定序列, 并用任务实验比较不同散度. 需要理解序列级 reverse KL、采样梯度和方差来源时, 读 MiniLLM. 两篇不是替代关系: GKD 给出可组合的训练接口, MiniLLM 给出更完整但更难估计的序列目标.

工程团队还应先确定教师接口. 能访问完整 logits 时, 两条路线都可精确实现局部分布项;只能访问已采 token log-prob 时, GKD 的 forward KL 与 MiniLLM 的解析单步项都无法原样计算. 接口能力会先于公式偏好缩小选择范围.

选择完成后, 用同一批冻结轨迹对不同损失做离线梯度比较. 观察梯度余弦、位置分布和极端值, 可以在投入在线 rollout 成本前发现方向写反、mask 错位和尾部截断问题.

如果目标是压缩部署模型, 应优先比较同一算力预算下的监督 KD、GKD 与 MiniLLM, 而不是给三者相同步数. OPD 每步包含 rollout 与教师评分, 单步成本不同;公平口径可以是总训练 FLOPs、GPU 小时或教师 token 数. 如果目标是提升推理能力, 还应区分 pass@1 与 pass@k, 因为散度与采样可能分别改变主模式质量和分布覆盖.

路线中的公式都默认教师冻结且师生共享输出空间. 一旦教师随学生更新、教师带特权上下文或动作空间不是 token, 状态分布框架仍可使用, 但教师目标的非平稳性与对齐映射需要单独进入定义. 这些扩展不能只更换教师名称后沿用同一结论.
