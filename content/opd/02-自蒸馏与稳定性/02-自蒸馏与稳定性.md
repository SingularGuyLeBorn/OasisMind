# 自蒸馏与稳定性

外部大教师不是 OPD 的必要条件. 同一个模型在额外看到参考解、专家示范、环境反馈或同题成功轨迹后, 条件分布可能比只看题目的学生更强. 自蒸馏利用这个差异: 学生先在普通上下文中生成, 教师再带着特权信息读取学生前缀, 两侧参数可以同源, 但输入信息不同. 教师没有凭空增加参数知识, 它把上下文学习能力转成逐 token 监督.

这类方法把 OPD 的适用范围从「大模型压缩」扩展到「现有模型自我改进」, 同时带来新的不稳定因素. 教师强度取决于特权上下文是否有效;同源师生的分布会随训练接近, 信号可能衰减;学生产生的坏前缀会让教师也失去判断力. 因而自蒸馏不能只检查教师最终答案是否更好, 还要检查教师在学生访问状态上是否持续提供有方向的条件分布.

## 1. 两条路线

### 1.1. 特权教师从哪里来

[特权教师](01-特权教师/01-特权教师.md) 把 OPSD、SDFT 与 SDPO 放在同一框架内. 三者都让学生对题目自行 rollout, 再让同源教师读取额外信息. [三种自蒸馏](01-特权教师/01-三种自蒸馏.md) 逐项区分信息来源、教师参数更新、散度接口与能力边界: OPSD 使用参考解, SDFT 使用专家示范并以 EMA 维护教师, SDPO 使用环境反馈或组内成功解构造富反馈教师.

共同形式可写为学生 $\pi_\theta(\cdot\mid x,y_{<t})$ 与特权教师 $\pi_{\bar\theta}(\cdot\mid x,c,y_{<t})$ 的比较. $c$ 是学生推理时不可见的信息, $\bar\theta$ 可以是初始参数、EMA 参数或另一个冻结快照. 教师必须 stop-gradient;否则同一个损失会同时推动两侧靠近, 目标随梯度移动, 蒸馏含义不再稳定.

### 1.2. 目标怎样校准

教师确定后, 目标仍有三处自由度: 教师奖励与参考策略的组合, 正确和错误轨迹的相对权重, 以及异常训练动态的归因. G-OPD 调整 KL 约束 RL 中的奖励强度与参考策略;SCOPE 用双路径权重区分正确和错误 rollout;sampled-token 偏差、坏前缀、长度膨胀和教师不兼容分别对应估计器、状态、生成行为与教师选择问题.

两条路线不能交换顺序. 若特权上下文本身不能提高教师, 调散度与权重只会稳定地拟合无效目标. 若教师有效但训练仍退化, 才进入目标校准: 分清奖励强度、参考分布、轨迹质量和估计器分别造成的偏差.

## 2. 共用记号与状态变化

### 2.1. 自蒸馏的一个更新

给定题目 $x$, 学生快照先采样 $y\sim\pi_{\theta_k}(\cdot\mid x)$. 第 $t$ 步状态是 $s_t=(x,y_{<t})$. 教师读取同一状态并追加特权上下文 $c$;实现时 $c$ 可以放在参考解区、反馈区或额外消息中, 但不能泄漏进学生输入. 局部损失为

$$
\ell_t=D\!\left(\operatorname{sg}[\pi_{\bar\theta}(\cdot\mid s_t,c)],\pi_\theta(\cdot\mid s_t)\right). \tag{1}
$$

学生 rollout 后新增 token、采样 log-prob 与任务结果. 教师评分后新增教师 logits、top-$k$ 分布或已采 token log-prob. learner 反向后只更新学生参数;冻结教师不变, EMA 教师则在 optimizer step 后按 $\bar\theta\leftarrow\rho\bar\theta+(1-\rho)\theta$ 缓慢移动. 若只保留 top-$k$, 尾部内部结构被丢弃;若只保留采样 token, 所有替代 token 的教师偏好都被丢弃.

### 2.2. 校准的统一视角

令参考策略为 $\pi_{\mathrm{ref}}$. 教师相对参考策略的 log-ratio 可以解释为隐式稠密奖励:

$$
r_T(s,a)=\log\pi_T(a\mid s)-\log\pi_{\mathrm{ref}}(a\mid s). \tag{2}
$$

标准 reverse-KL OPD 相当于奖励与 KL 约束取固定相对强度. G-OPD 放开奖励倍数与参考策略选择;SCOPE 不改教师是谁, 而是按轨迹对错与 token 信号重新加权. 两者作用位置不同: 前者改最优分布, 后者改有限样本下哪些轨迹产生更大更新.

## 3. 训练判断

### 3.1. 先验证教师增益

对同一批学生轨迹, 分别让无特权模型与特权教师打分. 除了最终正确率, 还应测已采 token 的教师优势、正确下一步的 margin、top-$k$ 重合和分位置熵. 如果特权上下文只让教师更自信, 却没有提高正确动作的相对概率, 自蒸馏可能收缩熵而不增加能力.

模型规模是明确边界. 小模型可能无法从长参考解或反馈中提取有效条件分布;教师输入更长甚至会稀释题目与当前前缀. 特权上下文的顺序、模板和截断位置都属于方法定义, 不能只报告「加入参考解」.

### 3.2. 再检查训练动态

稳定训练需要同时看任务成功率、回答长度、重复率、师生 KL、教师优势分位数和 rollout 新鲜度. KL 下降而任务分数不升, 常见原因是信号已耗尽、回答变短或教师与学生共同进入低熵区域. 错误轨迹上的梯度突然增大, 可能来自教师在坏前缀上给出极低概率, 也可能来自 sampled-token log-ratio 的长尾.

训练修复应对准故障位置. 冷启动解决学生到不了有效状态;教师对齐 prompt 解决思考风格不兼容;top-$k$ 或 full-vocab 解决单 token 信号不足;长度正则处理 EOS 与重复相变;按对错分流的权重处理有效轨迹与坏前缀不应同等更新. 把所有问题都交给学习率或全局 KL 系数, 只能偶然掩盖症状.

### 3.3. 把教师增益和训练收益拆开测

特权教师在离线样本上更准，只能证明额外上下文有用，还不能证明学生能够吸收这部分信息。比较实验至少需要四条曲线：无特权学生、只改变教师输入但不更新学生、使用固定教师完成蒸馏、教师随学生更新的自蒸馏。第一组给出学生起点，第二组测量教师增益，第三组检验分布监督能否传递能力，第四组才包含教师漂移带来的影响。若第二组明显领先而第三组没有改善，问题通常出在散度接口、状态覆盖或学生容量，而非特权信息本身。

评测还要区分训练题上的局部拟合与新题上的能力变化。参考解可能让教师在已知题目上轻易恢复正确 token，却没有教会学生可迁移的中间步骤。可以按题型、难度和轨迹首次出错位置分桶，并在未见题目上比较 pass@1、pass@$k$、答案长度与校准误差。学生只在训练题上提高、同时熵快速下降时，更像记住了教师偏好；新题上的成功率和错误恢复率同步提高，才说明自蒸馏改变了可复用的推理行为。

系统侧也要保存一条轨迹从生成到更新的版本关系。学生快照、教师快照、反馈生成器和 learner 若异步运行，同一批数据可能混入多个版本。版本差过大时，教师评的是旧学生状态，learner 却在新分布上拟合，KL 数值仍会下降，但它已不能代表当前策略上的教师增益。记录每条轨迹的四个版本号，并按版本差分桶观察收益，可以把算法退化与流水线陈旧数据区分开。

## 4. 来源与读法

### 4.1. 原论文与官方实现

自蒸馏路线依据 [Self-Distilled Reasoner](https://arxiv.org/abs/2601.18734)、[Self-Distillation Enables Continual Learning](https://arxiv.org/abs/2601.19897) 与 [Reinforcement Learning via Self-Distillation](https://arxiv.org/abs/2601.20802); SDPO 官方代码为 [lasgroup/SDPO](https://github.com/lasgroup/SDPO). 目标校准依据 [G-OPD](https://arxiv.org/abs/2602.12125) 及其 [官方代码](https://github.com/RUCBM/G-OPD)、[SCOPE](https://arxiv.org/abs/2604.10688) 与 [官方代码](https://github.com/machine981/SCOPE), 失败诊断使用三篇原论文 [2603.25562](https://arxiv.org/abs/2603.25562)、[2604.08527](https://arxiv.org/abs/2604.08527)、[2604.13016](https://arxiv.org/abs/2604.13016).

这些方法作用在训练循环的不同位置. 特权信息改变教师条件, G-OPD 把教师分布改写成带参考策略的奖励, SCOPE 再给轨迹与 token 分配权重. 同一个训练器可以同时采用三者, 但消融需要分别关闭对应组件.

### 4.2. 工程定位

OPSD、SDFT 与 SDPO 决定教师多看哪些信息;G-OPD 决定参考策略与奖励强度;SCOPE 决定正确和错误轨迹如何进入梯度. 训练异常可沿这三个位置检查输入条件、局部目标和样本权重.

工程复现时, 每个实验都应保存学生版本、教师版本、特权上下文类型、轨迹结果、散度方向、反馈粒度和权重. 缺少任一项, loss 曲线即使可复现, 也无法解释模型究竟从什么信号学到了什么.

## 5. 能力来源、教师动态与稳定机制

### 5.1. 自蒸馏为什么可能产生增益

学生和教师共享参数来源, 不代表二者在一次更新里拥有相同条件. 学生只读取部署时可见的 prompt 与自己的前缀;教师还可以读取参考答案、环境反馈、成功轨迹、批评文本或工具结果. 额外条件 $z$ 改变教师分布 $p_\theta(a\mid s,z)$, 学生拟合的是对当前状态有帮助的行为, 而不是复制参数本身.

若没有任何额外条件, 同一个模型在同一状态、同一温度下给出的分布完全相同, 精确 KL 为零. 有限采样上的 SFT 仍会产生随机梯度, 但这种更新不会稳定创造新信息, 还可能让模型逐渐偏离原分布. 因而自蒸馏的核心变量是条件差、视图差或时间差.

时间差对应旧教师保护旧能力. 模型先学习新领域, 再让旧检查点在当前学生前缀上恢复通用行为, 可以减轻遗忘. 条件差对应参考解或反馈. 视图差对应教师看见完整轨迹、学生只看见可部署前缀. 三者都能形成非零监督, 但传递的能力来源不同.

### 5.2. 固定教师、在线教师与 EMA 教师

固定教师给出稳定目标, 便于把学生变化与教师变化分开. 它适合能力恢复和大模型压缩, 代价是学生接近教师后信号耗尽. 在线教师与学生同步更新, 能持续适应任务, 同时形成移动目标;若教师只跟随学生而没有新增反馈, 两者可能一起漂移.

EMA 教师满足 $\bar\theta\leftarrow\tau\bar\theta+(1-\tau)\theta$. 大 $\tau$ 产生慢教师, 提供平滑历史平均;小 $\tau$ 更快追随学生. EMA 降低目标抖动, 不会自动提高教师能力. 教师增益仍需来自特权信息、筛选或环境验证.

当教师与学生同源时, stop-gradient 尤其重要. 教师分支若参与反向传播, 优化器可能同时移动目标和预测, KL 下降却没有明确知识迁移. 即便教师参数冻结, 共享缓存或权重别名也可能让更新泄漏. 一个最小测试是在 backward 后确认教师所有参数梯度为空, 再检查 optimizer parameter group 不包含教师.

### 5.3. 稳定性来自四个层面

第一层是状态. rollout 必须覆盖学生真实会访问的前缀, 又不能让不可恢复的坏状态占满 batch. 第二层是目标. 教师在特权信息下应更可靠, 但过尖分布会产生极端 log-ratio. 第三层是估计器. top-$k$、尾桶、权重裁剪和归一化共同决定梯度偏差与方差. 第四层是时间. 学生、教师与 rollout worker 的版本变化形成非平稳系统.

只观察平均 KL 会把四层混在一起. 状态质量可看 rollout 成功率和错误深度;目标质量可看教师在学生前缀上的正确动作 margin;估计器可看 advantage 分位数、裁剪比例与尾部概率;时间稳定性可看版本差、新旧策略 KL 和教师 EMA 距离.

### 5.4. OPSD、SDFT 与 SDPO 的差异

OPSD 用参考解或可验证结果构造特权自教师, 让模型在自己生成的推理轨迹上获得逐 token 反馈. SDFT 把示范放进教师上下文, 学生则在不看示范的条件下生成;它特别关心学新技能时怎样保留旧能力. SDPO 把环境反馈、批评或成功信息转成教师条件, 再用稠密分布信号替代单一终局奖励的一部分信用分配.

三者的共同式可以写为

$$
\mathcal L(\theta)=\mathbb E_{s\sim d_{\pi_\theta}}
[D(p_{\text{priv}}(\cdot\mid s,z)\|\pi_\theta(\cdot\mid s))].
$$

差异集中在 $z$ 是什么、教师是否冻结、散度方向和是否保留状态分布梯度. 把它们都称为自蒸馏没有错, 但实验结论不能跨方法直接移植. 参考答案有效, 不等于自然语言批评也会产生同质量教师.

### 5.5. 校准教师信号

教师在正确轨迹上更强, 可能在错误轨迹上过度自信. 可把样本按结果正确性和教师置信度分成四格. 正确且高置信的样本适合强化;错误且低置信的样本信息弱;错误却高置信最危险, 因为它会用大梯度推向错误模式. SCOPE 一类方法据此分别调节轨迹权重与 token 权重.

反馈并非越多越好. 把完整参考解、错误说明和工具结果一起塞给教师, 可能让教师回答依赖学生部署时永远看不到的捷径. 蒸馏可以传递这种条件下的输出风格, 却未必让学生学会产生中间信息. 特权教师的设计需要检查「去掉 $z$ 后, 学生是否仍拥有完成动作所需的可观察量」.

## 6. 持续学习、稳定配方与停止条件

### 6.1. 与持续学习的关系

顺序 SFT 学习新数据时, 梯度只关心新目标, 旧行为容易漂移. 用旧模型作教师并在当前学生状态上蒸馏, 可以让旧策略主动纠正学生正在发生的偏移. 相比固定旧样本回放, on-policy 状态更贴近更新后模型的错误区域.

这种保护仍有容量边界. 新旧任务冲突时, 同一参数模型不可能同时精确实现两套相反策略. 蒸馏权重过大还会阻止新知识进入. 因此持续学习实验要同时报告新任务获得、旧任务保留和两者的 Pareto 曲线, 不能只展示平均分.

### 6.2. 信号耗尽、塌缩与能力上限

师生接近后, KL 下降并不代表还能继续提高任务能力. reverse KL 持续优化可能进一步收缩熵, 让学生只保留教师的一小部分模式. 教师若由学生 EMA 得到, 两者还可能共同收敛到狭窄分布. 监控教师熵、学生熵、top-$k$ 重合与任务多样性, 才能发现这种信号耗尽.

另一个失效点是能力上限. 自教师借助参考答案能够纠正已知任务, 但无法验证开放世界中的未知事实. 环境反馈若可被钻空子, 特权教师会把奖励漏洞转成稠密监督, 反而加速策略劣化. 可靠验证器、独立教师或人工审查仍有必要.

**自蒸馏中的「自」描述参数来源, 「教师」描述信息条件.** 只要教师条件确实更有信息, 同源模型也能形成有效监督;条件没有增量时, 重复拟合自己的有限样本只会引入采样噪声.

### 6.3. 偏差—方差视角下的稳定配方

完整词表分布提供低方差局部目标, 计算代价最高. sampled-token 信号最轻, 单样本方差大. top-$k$ 位于二者之间, 尾部桶是否保留决定概率质量能否闭合. 特权教师越尖锐, 被截掉的尾部越少;教师在不确定状态上分布较平时, 小 $k$ 会丢失更多结构.

轨迹级筛选也会引入偏差. 只训练成功轨迹能提高信号质量, 却不再覆盖学生最常犯的错误;同时训练所有失败轨迹能保留状态覆盖, 教师又可能无法可靠恢复. 一个折中是按可恢复性而非最终成败分层: 让教师从不同位置续写, 只有仍能回到正确解的前缀进入稠密蒸馏.

### 6.4. 温度与教师强度

学生采样温度决定访问状态的广度. 温度太低, rollout 集中于已有模式;温度太高, 大量前缀脱离任务. 教师温度则改变目标熵. 两者无需相同: 可以用较高学生温度探索状态, 再用经过校准的教师分布纠正;但温差过大会产生极端 KL.

温度缩放应作用于 logits 后再归一化. 对蒸馏损失, 常见的 $T^2$ 梯度缩放来自软目标蒸馏的尺度补偿, 不能与生成温度混为一个参数. 训练配置最好把 rollout temperature、teacher target temperature 和 evaluation temperature 分开记录.

### 6.5. 何时应停止

师生 KL 接近噪声底、教师在学生状态上的优势消失、任务指标停止提升或旧能力开始回落, 都是停止信号. 其中任何单项都不充分. 固定教师下 KL 仍下降而任务不升, 往往表示学生继续拟合教师细节;移动教师下 KL 很低, 还可能表示教师追得太快.

可采用二维停止条件: 主任务和旧能力位于可接受区域, 同时教师优势的增量低于阈值. 这比按固定训练步数更适合自蒸馏, 因为信号强度会随学生吸收能力而自然衰减.
