# 特权教师

自蒸馏看似违反常识: 如果教师和学生来自同一组参数, 教师还能教什么? 差异不一定来自参数规模, 也可以来自输入信息. 学生只看题目并自行生成;教师额外看到参考解、专家示范、验证器反馈或同题成功轨迹, 再对学生已经走到的前缀计算下一 token 分布. 额外上下文把模型已有的理解能力转成即时监督, 学生通过训练把这部分条件行为吸收到无特权输入的参数中.

这条路线源于 context distillation, 但训练状态不同. 传统 context distillation 常在教师生成或固定数据上训练;on-policy 自蒸馏让当前学生产生轨迹, 教师在学生错误真正出现的位置提供反馈. 前者解决「如何内化上下文」, 后者再处理「监督落在哪些状态」. 只有学生轨迹与特权教师同时存在, 才是这里讨论的 on-policy self-distillation.

## 1. 统一结构

### 1.1. 两个视图, 一组参数来源

输入为 $x$, 学生回答为 $y$, 第 $t$ 步状态为 $s_t=(x,y_{<t})$. 学生条件分布是 $\pi_\theta(\cdot\mid s_t)$, 教师额外读取 $c$:

$$
q_t(\cdot)=\pi_{\bar\theta}(\cdot\mid s_t,c),\qquad
p_t(\cdot)=\pi_\theta(\cdot\mid s_t). \tag{1}
$$

$c$ 决定教师获得哪种特权, $\bar\theta$ 决定教师参数从哪里来. 两项必须分开记录. OPSD 用参考解作为 $c$, 教师通常固定在初始策略;SDFT 用专家示范作为 $c$, 并以学生 EMA 形成 $\bar\theta$;SDPO 把环境反馈或组内成功解放进 $c$, 教师可用 EMA 或与初始策略插值.

教师前向需要 stop-gradient. 如果 $q_t$ 与 $p_t$ 同时接受散度梯度, 教师会向学生靠拢, 特权信息产生的差距被主动抹平. 共享参数不等于共享计算图: 同一权重可以先以教师模式无梯度前向, 再以学生模式保留梯度前向.

### 1.2. 一次更新的状态

学生 rollout 前, 系统持有 prompt、学生快照、教师快照与特权上下文. rollout 后新增学生 token、行为 log-prob、EOS 位置和任务结果. 教师评分后新增完整 logits、top-$k$ 分布或已采 token 的 log-prob. learner 更新后学生参数改变;冻结教师保持不变, EMA 教师在更新后缓慢跟随.

不同反馈粒度丢失的信息不同. full-vocab KL 保留教师对所有替代 token 的排序;top-$k$ 看不到尾部内部结构;sampled-token 只知道学生已经选中的动作是否被教师支持. 特权上下文很强但反馈接口过窄时, 大量「教师更愿意选什么」不会进入梯度.

## 2. 三种特权信息

### 2.1. 参考解与示范

OPSD 的教师看到题目参考解, 学生看不到. 教师在学生前缀上结合参考解重新分配下一 token 概率, 并不沿参考解前缀预测. 因而参考解只进入教师条件, 训练状态仍来自学生. 参考解错误、风格不兼容或题目太难时, 教师优势会减弱.

SDFT 把更一般的专家示范放进教师上下文, 目标是从少量示范学习新任务并减轻旧能力遗忘. EMA 教师让目标随学生缓慢进步, 但也引入非平稳性. EMA 系数过小, 教师追得太快, 师生差距迅速消失;系数过大, 教师长期停留在旧能力.

### 2.2. 环境反馈与成功轨迹

SDPO 面向只能得到结果奖励或文本反馈的任务. 对答错轨迹, 教师可以看到验证器反馈以及同一题组中答对的解;对答对轨迹, 教师可看到确认信息或自身成功解. 教师在这些信息条件下对原学生轨迹逐 token 评分, 把序列级反馈转成稠密分布信号.

成功轨迹不是拿来做 SFT 的固定标签. 学生仍在自己的前缀上受监督, 成功轨迹只进入教师上下文. 如果直接把成功轨迹作为目标序列训练, 方法会变成筛选式自训练;两者在状态覆盖与信用分配上不同.

## 3. [三种方法怎样分工](01-三种自蒸馏.md)

### 3.1. OPSD、SDFT 与 SDPO 的轴

三种方法最稳定的比较轴是特权信息、教师参数、分布损失和任务假设. OPSD 依赖每题参考解;SDFT 依赖少量专家示范以及模型的 in-context learning;SDPO 依赖在线反馈或同组成功样本. OPSD 与 SDFT 更像把已有高质量信息内化, SDPO 更强调在训练中把新反馈转成教师条件分布.

散度结论不能互相照搬. OPSD 的实验偏向 full-vocab forward KL 与逐点裁剪;SDFT 的理论表达与实际最佳配置并不完全相同;SDPO 常用 reverse KL 或 JSD, 并以 top-$k$ 加尾部桶控制成本. 这些差异来自任务、教师条件与估计器, 不能缩成「自蒸馏统一使用某一种 KL」.

### 3.2. 选择顺序

有可靠逐题参考解时, OPSD 给出最直接的固定教师. 只有少量示范、希望连续学习时, SDFT 的 EMA 教师更贴近问题. 环境能返回验证结果或富反馈, 且同题能采到成功轨迹时, SDPO 可以把在线反馈转成 token 信号. 如果三类信息都没有, 同源教师没有新增条件, 自蒸馏很可能只做分布自匹配.

选择之后先做教师增益测试: 固定学生 rollout, 比较有无特权上下文时正确下一步的概率、已采错误 token 的概率和最终续写成功率. 只有教师在学生状态上确实更好, 才进入训练器与超参数比较.

还要确定特权信息的取得成本. 人工参考解适合小规模高质量任务, 自动验证器适合可判定结果, 文本反馈适合错误可描述但难写标准答案的任务. 信息成本应按有效训练样本计算: 如果多数 rollout 没有成功同伴或反馈无法解析, 名义上的在线自蒸馏 batch 会大幅缩水.

不同信息可以组合, 但组合时要保留来源标记. 教师同时看到参考解与验证反馈后变强, 不能判断是哪项提供增益;先做单来源对照, 再验证组合是否互补. 推理部署仍只给学生普通输入, 这是所有比较不变的条件.

## 4. 工程与失败边界

### 4.1. 上下文不能泄漏

学生输入与教师输入必须分别构造. 共享 batch 时, 最容易出现 attention mask 复用错误, 让学生看见参考解或反馈 token. 泄漏后的训练 loss 会快速下降, 评测时移除特权信息便失效. 测试应检查学生每个位置的可见 token, 不能只比较两侧解码文本.

教师模板也会改变信号. 参考解放在 system、user 还是独立消息中, 模型的利用能力可能不同;长反馈被截断后, 教师只看到结尾或只看到题目, 都会改变目标. 模板、截断侧与最大长度应和散度一起进入实验配置.

### 4.2. 同源不保证更强

小模型可能无法从示范或反馈中提取正确规律. 教师上下文更长还会增加困惑, 使教师在学生前缀上反而更差. 应按模型规模、题目难度和轨迹对错分桶测教师优势, 不能用全局平均掩盖困难样本上的负迁移.

另一个边界是信号耗尽. 学生逐渐吸收特权行为后, 师生 KL 会下降. 此时继续训练可能只压低熵或放大模板偏好. EMA 教师可以随学生变化, 但 EMA 本身不会创造新信息;需要新的反馈、示范或更强上下文才能继续提供能力增量.

## 5. 条件信息怎样变成策略差

设基础模型为 $f_\theta$, 学生输入为状态 $s$, 教师额外获得特权变量 $z$. 两个策略分别为

$$
\pi_S(a\mid s)=f_\theta(a\mid s),\qquad
\pi_T(a\mid s,z)=f_{\bar\theta}(a\mid s,z).
$$

即便 $\bar\theta=\theta$, $z$ 也会改变注意力上下文与下一 token 分布. 蒸馏训练把 $\pi_T$ 在学生状态上的偏好压回不含 $z$ 的 $\pi_S$. 能否成功取决于 $s$ 是否包含足够线索: 若教师答案完全依赖部署时不可见的秘密信息, 学生最多学到数据集中的相关性, 无法在新样本上恢复秘密.

特权信息可分为三类. 「答案型」信息给最终结果或参考推理;「反馈型」信息指出学生轨迹哪里出错;「经验型」信息给成功历史、工具观察或旧模型行为. 答案型信号容易构造强教师, 也最容易让教师跳过学生需要掌握的中间过程. 反馈型更贴近纠错, 质量受批评准确性影响. 经验型适合多轮决策, 但状态与动作对齐最复杂.

### 5.1. 教师看到参考解时发生了什么

参考解放入上下文后, 教师可能逐字复制, 也可能只利用其中结论重新组织回答. 若目标是让学生学推理, 需要区分这两种行为. 可遮掉参考解的一部分, 检查教师是否仍能在学生错误前缀上给出合理续写;也可比较教师 top token 与参考解下一个 token 的重合率. 完全复制提供的是强序列模仿信号, 未必产生错误恢复能力.

参考解长度还会影响位置对齐. 教师上下文包含额外 token, 学生上下文没有, 但两者预测的是同一学生 response 位置;不能直接按绝对序号切 logits. 正确做法是在各自模板中定位 response span, 再按学生动作逐位置取教师分布.

### 5.2. 环境反馈怎样进入教师

环境反馈可以是正确/错误标记、编译器报错、单元测试、工具返回或自然语言批评. 一个标量反馈本身信息很少, 把它加入教师上下文后, 教师利用自身知识解释失败原因并生成稠密分布. 这相当于用教师完成信用分配.

风险也随之集中到教师. 错误反馈、奖励漏洞或提示注入会改变每个 token 的监督. 若环境文本由外部工具返回, 教师模板应明确数据边界, 避免把工具内容当指令. 对可验证任务, 还应抽查教师建议是否提高后续成功率, 而非只让解释更流畅.

### 5.3. 成功轨迹作为特权视图

多轮任务中, 教师可以看到一条成功轨迹, 学生仍从自身状态行动. 成功轨迹提供高层策略, 但当前学生状态可能已偏离示范. 教师需要把示范原则映射到当前状态, 不能机械输出示范中的下一动作. 状态差距越大, 这种映射越不可靠.

可用状态相似度或可恢复性筛选教师监督. 对距离成功轨迹太远的前缀, 先回退到环境重置、搜索或终局奖励;对仍可恢复的前缀再做逐 token 蒸馏. 这比让教师对所有坏状态保持高置信更稳健.

### 5.4. 为什么同源教师不等于循环论证

同一个模型在不同条件下可表现出显著能力差. chain-of-thought 提示、工具结果和参考答案改变了可用计算与信息. 自蒸馏试图把条件化表现转成无特权条件下的参数行为. 这一过程类似 context distillation: 上下文中暂时提供的信息被梯度吸收.

但参数吸收有容量限制. 教师依赖很长参考资料时, 少量更新可能只学到答案模式;大量更新又可能遗忘通用能力. 训练结果应在未见问题上评估, 并设置没有特权信息的同源教师对照, 才能确认增益来自 $z$ 而非额外训练 token.

### 5.5. 教师更新速度

固定教师的目标易解释. 学生超过教师后, 固定目标会限制进一步探索. EMA 教师能跟随学生的新能力, 其滞后又能抑制瞬时噪声. 令更新间隔为 $K$, 衰减为 $\tau$, 教师的有效时间尺度同时受二者影响;只报告 $\tau$ 不能完整描述教师响应速度.

在线教师若还读取新反馈, 教师改进与学生改进会耦合. 此时应保留一份固定锚点教师或参考策略, 监控移动教师是否整体漂移. 两个模型 KL 很小可能表示一致收敛, 也可能表示共同塌缩, 需要外部任务指标判断.

### 5.6. 特权泄漏与公平比较

训练时的教师可以看参考答案, 评测时学生不能看. 若评测 prompt 意外保留答案字段、工具缓存或模板标记, 得分会虚高. 数据管道应在 token 级检查学生输入, 而不是只看原始 JSON 字段. 同一 batch 同时打印 teacher input 与 student input, 能直接暴露泄漏.

比较特权教师与外部大教师时, 还要计入信息预算. 一个小自教师看到标准答案, 与大教师只看问题并非同等条件. 公平问题取决于研究目的: 若目标是利用已有答案压缩行为, 特权条件合理;若要比较模型本身的指导能力, 就必须统一可见信息.

### 5.7. 可学习性的三个必要条件

第一, 特权变量确实改善教师在学生状态上的动作分布. 第二, 学生可观察状态包含推断目标动作所需的信息. 第三, 学生模型和初始化对目标行为有足够表示与支持. 缺第一项, 教师没有增益;缺第二项, 问题不可辨识;缺第三项, reverse-KL 学习难以访问目标模式.

可以为三项分别做测试. 教师增益用前缀续写成功率测;可辨识性用移除或打乱 $z$ 后的条件差测;学生支持用教师高概率 token 在学生分布中的累计质量测. 三项通过后, 再调 EMA、top-$k$ 或学习率才有意义.

特权教师是同一个模型在更多信息下形成的条件策略. 蒸馏的任务是把其中可由学生状态预测的部分留下, 把只依赖训练期秘密的部分挡在部署边界之外.

### 5.8. 信息论边界

若特权变量 $z$ 与正确动作 $a^*$ 在给定学生状态 $s$ 后仍有条件互信息 $I(a^*;z\mid s)>0$, 教师可以利用学生看不到的信息提高预测. 蒸馏只能把训练分布中可由 $s$ 统计预测的部分压入参数. 对每个新样本都独立变化、且不在 $s$ 留下线索的那部分信息无法被恢复.

这给出了一个清楚的反例. 若教师看到随机生成的密码, 学生只看见「请输入密码」, 再多蒸馏也无法让学生预测新密码. 若教师看到的是解题示范, 而题目结构与示范步骤之间存在规律, 学生则可能把规律学进参数. 两种情形在训练 loss 上都能下降, 泛化结果完全不同.

### 5.9. 反事实测试

把特权信息随机打乱是一项有效对照. 若教师仍保持高分, $z$ 可能没有真正被使用;若教师输出随打乱显著变化, 再观察学生能否从非特权状态预测这些变化. 还可以只保留答案、只保留错误说明或只保留工具观察, 分解哪类信息贡献最大.

另一个测试是交换前缀. 给教师正确答案, 同时提供另一条学生错误轨迹, 检查教师能否针对当前错误而非复述标准解. 这能区分「条件化纠错教师」和「带答案的文本生成器」, 对长推理任务尤其重要.

### 5.10. 多教师情形

不同特权视图可以产生多个教师. 一个看参考解, 一个看环境反馈, 一个保留旧模型能力. 简单平均概率会把相互冲突的模式混在一起;按状态选择教师则需要可靠路由. 多教师目标可写成 $\sum_i w_i(s)D(p_i\|q)$, 权重既可由教师置信度给出, 也可由外部验证器确定.

置信度路由有自信错误风险. 更稳妥的信号是教师建议经过环境验证后的成功率. 若没有验证器, 应保留教师分歧并降低冲突状态权重, 避免平均分布把学生推向各教师都不会真正选择的中间模式.

### 5.11. 条件蒸馏的风险分解

设数据来自联合分布 $p(s,z,a)$，教师给出 $p_T(a\mid s,z)$，学生只能表示 $q_\theta(a\mid s)$。以 forward KL 为例，理想目标为

$$
\mathcal L(\theta)=
\mathbb E_{s,z}\left[D_{KL}
\big(p_T(\cdot\mid s,z)\|q_\theta(\cdot\mid s)\big)\right].
$$

对固定 $s$，最优无限容量学生是对特权变量边缘化后的混合：

$$
q^*(a\mid s)=\mathbb E_{z\sim p(z\mid s)}[p_T(a\mid s,z)].
$$

如果同一学生状态对应多个互相冲突的 $z$，学生只能学习混合。一个简单例子：同一题面 $s$ 的隐藏答案由独立硬币 $z$ 决定，教师分别给 A 或 B，学生最优只能各给 0.5。训练 loss 可以稳定收敛，部署准确率仍只有随机水平。这是不可辨识性，不是优化器没有调好。

真实任务中，$z$ 往往与 $s$ 有统计联系。参考解由题目推导，编译错误由当前代码造成，成功轨迹受环境状态限制。学生能够从 $s$ 预测一部分教师行为。可把风险拆成三个项：教师相对真值的误差、特权边缘化造成的不可辨识误差、学生有限容量与优化误差。只看最终蒸馏 loss，三者混在一起。

令真实最优策略为 $p^*(a\mid s)$，边缘教师为 $\bar p_T(a\mid s)$，则可用一组比较量区分：教师在带 $z$ 条件下的任务成功率；$\bar p_T$ 的任务成功率；学生与 $\bar p_T$ 的 KL；学生真实成功率。教师很强、$\bar p_T$ 很弱，问题在特权不可预测；两者都强、学生 KL 大，问题在容量或优化；学生 KL 小但任务差，教师目标本身有偏。

#### 5.11.1. 蒸馏方向改变模式行为

Forward KL $D_{KL}(p_T\|q)$ 要求学生覆盖教师有质量的模式，容易得到较宽分布。Reverse KL $D_{KL}(q\|p_T)$ 更偏向选择教师高峰，可能丢掉次要模式。对多解推理，forward KL 有利于保留多个有效动作；对生成阶段需要一条连贯轨迹时，过宽分布又可能在不同模式间拼接。

Token 级 forward KL 常用教师 logits直接训练。若教师看到答案后对某个 token极度自信，学生在没有答案时被迫拟合这个尖峰；多个 $z$ 对应不同尖峰，平均后可能形成不自然分布。温度可以软化目标：

$$
p_T^{(\tau)}(a)=\frac{\exp(l_a/\tau)}
{\sum_b\exp(l_b/\tau)}.
$$

$\tau$ 增大保留更多替代动作，也会把教师噪声扩散到长尾。温度需要按教师校准与学生支持选择，不能固定套用分类蒸馏经验。

截断 top-k 教师分布降低存储和计算，却会删除教师尾部。若学生当前高概率动作不在教师 top-k，reverse 方向或 off-policy更新可能缺少梯度支持。应报告截断前质量、被保留 token的教师累计概率，以及学生动作落在截断外的比例。教师极尖时小 $k$ 足够，开放式语言状态可能需要更宽支持。

序列级蒸馏只采一条教师轨迹，绕开完整 logits存储，目标变成行为克隆。采样温度和拒绝规则决定留下的模式，少量轨迹容易模式坍缩。多采样加验证保留多条成功路径，覆盖提高，成本也上升。Token KL 与序列 SFT 可以组合：先用验证轨迹提供状态覆盖，再在这些状态上使用教师分布。

### 5.12. 教师信息的充分性与最小性

特权变量太弱，教师没有增益；太强，教师可能跳过学生要学的过程。最有用的 $z$ 通常提供「足以纠错但仍要求完成任务」的信息。例如只给最终答案，教师可以围绕答案反向编造推理；给失败测试与局部提示，教师仍要定位修改。两者产生的 token监督密度和可迁移性不同。

可以从教师增益和学生可预测性画二维图。横轴是 $z$ 带来的教师成功提升 $\Delta_T$，纵轴是学生从 $s$ 预测教师动作的能力。左下角没有信号，右下角是强但不可学秘密，左上角是可学却无额外价值，右上角才适合蒸馏。实验应寻找右上区域，而非一味增加教师信息。

最小特权集可通过逐字段消融寻找。参考解包含答案、步骤、引用和格式；工具反馈包含退出码、stderr、diff和测试。每次删除一类字段，测教师续写、学生蒸馏与未见任务表现。若删除答案后教师略降、学生泛化上升，说明答案诱导了捷径。若删除错误位置后两者都降，定位信息是真正有效条件。

信息顺序也会改变教师。先展示学生错误再给参考解，教师更可能针对失败；先给完整答案再展示学生前缀，注意力可能主要复制答案。两个 prompt包含相同字段，条件策略仍不同。模板属于方法，应版本化并做顺序消融。

特权信息还可能污染输出格式。教师在分析中引用「参考答案显示」「根据测试反馈」，学生部署时没有这些对象，蒸馏会学到元话语。训练可要求教师输出部署可执行的动作，隐藏或清理来源措辞；清理不能删除真实推理。更稳妥的做法是让教师内部使用 $z$，输出仍遵循学生协议。

#### 5.12.1. 答案型教师的因果反例

设数学题训练集中某种表面模板总对应答案 42，教师看到标准解后输出正确推理。学生可通过模板捷径预测 42，在同分布验证上表现好；模板与答案关系在新题族中改变，学生失败。蒸馏成功吸收了 $p(a\mid s)$ 的训练相关性，却没有获得参考解中的因果算法。

要检验算法迁移，可构造保持推理结构、改变数字与表面的反事实题；也可打乱不影响解法的叙述顺序，观察学生是否稳定。只对原题改写，可能仍保留模板线索。对形式证明，改变变量名、前提顺序与等价 statement，更能检查学生是否学到证明结构。

教师本身也可能利用答案倒推一条错误但结论一致的链。最终 answer verifier无法发现中间错误。过程验证、逐步执行或隐藏反例能够过滤；没有可靠过程验证时，学生应降低对教师链的置信，保留最终正确与推理可信两种标签。

### 5.13. 轨迹教师与状态分布

成功轨迹 $\tau^*=(s_0^*,a_0^*,\ldots)$ 来自教师或旧策略的状态分布 $d_T(s)$，学生部署访问 $d_S(s)$。行为克隆在 $d_T$ 上学习，学生小错误会进入轨迹中未覆盖的状态，产生 covariate shift。让教师看成功轨迹并在学生状态上给动作，是把示范知识投影到 $d_S$，前提是教师能理解偏离状态。

可以定义学生状态与示范最近状态的距离 $D(s,s_j^*)$，但文本、代码和网页没有统一度量。更直接的可恢复性测试是从当前状态执行教师建议，再由环境验证是否提高完成概率。少量分支 rollout可估计：

$$
\hat Q_T(s,a)=\frac1K\sum_{k=1}^KR(\tau_k\mid s,a).
$$

教师语言置信度高而 $\hat Q$ 低，说明它在错位状态上产生了似是而非建议。

状态偏离有不同类型。目标未变、只多了无关探索时，成功轨迹仍可参考；文件或页面已被部分修改，需要先诊断与回滚；不可逆外部动作发生后，原示范可能不再可达。教师输入应包含当前环境事实，不能只给聊天历史。训练数据标记可恢复、需重置与不可恢复三类，避免把重置后的动作硬接到受损状态。

在线采集可用学生 rollout产生真实错误状态，再让特权教师纠错，类似 dataset aggregation。随着学生变强，状态分布移动，教师数据也更新。若只保留教师成功续写，困难状态可能反复被过滤掉；应记录教师失败率与状态类型，确认课程没有悄悄退回简单样本。

轨迹特权还可能泄漏未来。教师看到整条成功轨迹时，知道后续工具结果与环境变化；它在早期状态给出的动作可能依赖尚未发生的信息。学生无法预测这种反事实未来。可以只给截至当前时间可合法获得的示范摘要，或将未来信息限制为高层目标，再用因果遮罩测试教师动作是否依赖未来 token。

### 5.14. EMA 教师作为双时间尺度系统

在线自蒸馏常令教师参数

$$
\bar\theta_{n+1}=\tau\bar\theta_n+(1-\tau)\theta_n.
$$

展开可见教师是历史学生的指数加权平均，样本年龄约为 $1/(1-\tau)$ 个更新单位。若每 $K$ 步才同步一次，有效墙钟滞后还乘 $K$。大滞后提供稳定目标，也可能跟不上学生发现的新策略；小滞后让教师迅速共享学生噪声，失去锚点。

双时间尺度要求学生更新快、教师变化慢，但二者梯度尺度和数据刷新也会影响。可以监控 $D_{KL}(\pi_T\|\pi_S)$、教师与固定锚点 KL、两者任务成功率。师生 KL下降同时成功率上升是良性收敛；KL下降而成功率一起下降是共同坍缩；KL持续增大可能是教师过旧或学生不稳定。

EMA 权重平均未必等于策略平均，神经网络参数空间非线性。两个功能良好的 checkpoint平均后可能性能下降，尤其跨越不同 basin。较短时间尺度和连续训练通常更安全。可以直接比较 EMA教师、周期 checkpoint教师与 logits ensemble，判断稳定来自参数平滑还是预测集成。

教师读取特权 $z$，学生不读，两个 forward的上下文长度与激活分布不同。即使共享参数，EMA只同步权重，无法保证无特权路径也同步改善。训练中应分别评估教师带 $z$、教师去掉 $z$、学生无 $z$ 三种条件；第二项能看见教师参数本身是否增长，第一与第二差值是条件增益。

### 5.15. OPSD、SDFT 与 SDPO 的目标差异

几条自蒸馏路线都使用同源教师，监督对象并不相同。OPSD 更接近在学生状态上用特权条件教师给 token分布，让当前策略直接拟合；SDFT 强调从自生成或特权行为中筛选序列，再做监督微调；SDPO 把教师分布放进策略优化或偏好形式，保留 reference与相对更新。理解方法时要看状态来自谁、教师看见什么、损失在哪些 token上计算。

若数据状态 $s$ 来自固定离线集，目标近似

$$
L_{offline}=\mathbb E_{s\sim D}
D(p_T(\cdot\mid s,z)\|q_\theta(\cdot\mid s)).
$$

它稳定、可重复，却只覆盖 $D$。在线方法从当前学生 $s\sim d_{\pi_\theta}$ 采样，再向特权教师查询；覆盖贴近部署，目标分布随参数移动。两者的训练曲线不可直接比较，在线方法额外支付 rollout和反馈成本。

SDFT 若只保留验证成功序列，相当于从提议分布 $q(\tau)$ 经接受概率 $A(\tau)$ 得到

$$
p_{train}(\tau)\propto q(\tau)A(\tau).
$$

它提升平均质量，也引入选择偏差：易验证、格式规范和当前模型已经接近成功的轨迹更容易留下。失败状态、恢复和少数正确形式会减少。数据卡应报告提议数、接受率、失败原因与任务难度变化，不能只给最终 token数。

SDPO 一类目标保留正负或教师—学生相对信息。若教师看到 $z$ 后偏好 $a^+$，学生当前动作是 $a^-$，可以优化相对 log-ratio；reference限制策略偏离。它比直接 SFT 更强调区分，仍依赖教师偏好正确且学生状态可辨识。教师因秘密信息选择 $a^+$ 时，偏好目标同样不可学习。

三类方法还可串联。先用 SDFT 建立动作支持和格式，再用在线 token蒸馏覆盖学生错误状态，随后用可验证偏好优化提高成功率。顺序改变结果：没有 SFT支持时，KL或偏好梯度可能指向学生几乎无概率的 token；先过度 SFT 又可能压掉探索。每阶段保存独立评测与分布统计，才能知道收益来自哪里。

#### 5.15.1. 状态、动作与损失掩码

教师输入含特权字段，学生输入不含，两者 response span必须对齐到同一动作。System prompt、参考解与反馈 token不参与学生 policy loss；工具观察和用户消息构成状态，也不应被当成学生生成。一个 mask错误就会训练学生预测环境文本或特权答案。

多轮轨迹中，教师可在每个学生动作位置重新读取更新后的 $z_t$，也可一次看到整条特权信息。前者更接近因果在线条件，调用昂贵；后者易泄漏未来。轨迹重建要保存每一步教师实际输入与版本，不能事后用完整日志重新拼装。

动作可能是自然语言、工具 JSON 或代码。教师自动修复学生格式后得到成功，修复后的序列并非学生真实动作。若拿它作 token目标，相当于教正确格式，合理但需标记为编辑监督；若计算 on-policy ratio，则不能冒充学生采样。数据层同时保存原动作、教师建议和执行动作。

Top-k 教师 logits的 tokenization必须一致。同源模型通常共享 tokenizer，模板插入不同仍会让 response边界不同。不同 teacher/student tokenizer则无法逐 token KL，需要序列蒸馏、字符串对齐或在共享词级表示上比较。强行按 token序号对齐会产生无意义目标。

### 5.16. 特权教师的校准与弃权

教师知道更多信息，也会犯错。它可能误读反馈、使用过期参考解、在不可恢复状态中自信给出动作。蒸馏会把每次错误放大到学生参数，因此教师需要校准与弃权机制。可用的置信度应当来自建议通过环境或验证器后的成功概率，教师在文本中声称「我很确定」没有同等分量。

对可验证任务，可从同一状态采样 $K$ 个教师动作，执行后得到 reward $R_k$。教师动作 $a$ 的经验价值和方差为

$$
\hat Q_T(s,a)=\frac1K\sum_kR_k,\qquad
\widehat{Var}(R)=\frac1{K-1}\sum_k(R_k-\hat Q)^2.
$$

均值高且方差低的监督最可靠；均值中等可作为探索或偏好；全失败状态不宜强制学生模仿。执行成本高时，只在教师—学生分歧大、价值模型不确定或安全风险高的状态验证。

没有硬验证器时，可以使用多教师一致、过程检查和反事实扰动。多个教师共享训练数据，错误可能相关，一致并非真值。将问题数值、表述或无关上下文变化，教师结论应按任务语义稳定；对微小无关扰动剧烈变化的监督降权。

弃权并非删除所有困难样本。教师可以输出「需要更多观察」「应重置」「当前信息不足」等可执行策略；若部署允许查询工具，这也是正确动作。真正不可学的是教师利用学生永远看不到的信息直接给出唯一答案。训练应区分主动获取信息与凭空猜测。

可用权重 $w(s,z)$ 调节蒸馏：

$$
L=\mathbb E[w(s,z)D(p_T\|q)].
$$

$w$ 可由验证成功、教师 margin、学生支持和状态可恢复性共同决定。权重模型也可能偏爱简单样本，需保留任务覆盖约束。报告加权前后状态分布、难度与领域比例，避免稳定性来自删除所有困难例子。

教师校准还受特权强度影响。看完整答案时教师概率尖锐，却未必更适合学生；只看提示时概率较宽，动作可能更可预测。置信度不能跨不同 $z$ 直接比较。可以在每种特权视图内校准，再由验证结果选择视图。

### 5.17. 多教师聚合的几何

有 $M$ 个教师分布 $p_m(a\mid s,z_m)$。算术平均

$$
\bar p(a)=\sum_mw_mp_m(a)
$$

覆盖各教师模式，等价于最小化加权 forward KL到学生。几何平均

$$
p_G(a)\propto\prod_mp_m(a)^{w_m}
$$

强调共识，某教师给接近零概率的动作会被强烈压制。教师互补时算术平均更合适，教师应共同满足约束时几何平均更严格。

多个确定动作相互冲突，平均分布可能把概率给各自模式，学生采样仍选其中之一；token级平均也可能在长序列中把不同推理前缀拼接。先按完整轨迹聚类、每次选择一个教师模式，比逐 token混合更连贯。路由器根据状态、领域和验证历史选择教师，需要独立校准。

教师权重若来自自身置信，会放大自信错误。外部 verifier、历史成功率与分布外检测更可靠。设教师 $m$ 在状态族 $c$ 的校准成功率为 $u_{m,c}$，可令

$$
w_m(s)=\frac{\exp(u_{m,c(s)}/\tau)}
{\sum_j\exp(u_{j,c(s)}/\tau)}.
$$

类别过细数据不足，过粗掩盖专长；需要层级平滑与最低样本数。

分歧本身是有用信号。若看参考解的教师与看环境反馈的教师冲突，可能说明参考解不适用于当前状态，或反馈错误。直接平均会掩盖。训练数据保留分歧类型，优先交给环境验证或人工审计；无法判定时降低权重，比制造虚假共识安全。

旧模型教师用于防遗忘，新任务特权教师用于学习，两者冲突体现稳定—可塑性权衡。可以在旧数据或锚点状态上偏向旧教师，在新任务可验证状态偏向特权教师；只用全局固定权重，很难兼顾。Continual learning 的自蒸馏正需要按状态分配约束。

### 5.18. 稳定性为何会失败

第一种失败是确认偏差。学生生成轨迹，教师与学生同源且只获得弱反馈，容易合理化学生错误；这些建议再训练学生，错误被强化。外部 verifier、强反例和固定锚点能打断回路。只提高 EMA衰减会减慢确认偏差，不能消除。

第二种失败是熵塌缩。教师分布比学生更尖，反复 KL让学生更尖；EMA教师再继承低熵，探索逐渐消失。监控 token熵、有效词表和多采样成功率。温度、熵正则或多教师覆盖可缓解，过强会保留无关长尾。

第三种失败是策略漂移。在线教师随学生更新，没有固定 reference，师生共同远离原能力。固定锚点数据、reference KL和周期性外部评测提供坐标。锚点过强则新任务学不动，需要按领域与风险分配。

第四种失败是特权捷径。教师输出高度依赖答案格式、反馈模板或工具标记，学生学到与任务无关的表面线索。打乱、遮罩和跨模板评测可以发现。数据生产时使用多种等价模板，降低单一标记相关性。

第五种失败是状态选择偏差。只蒸馏教师能救回的学生轨迹，训练池逐渐缺少真正困难和不可恢复状态；成功率看似上升，部署遇到这些状态仍失败。应报告原始 rollout分布和被接受比例，保留独立困难集。

第六种失败是 teacher overreach。教师在信息不足时给出长而确定的计划，学生学会无视环境检查。允许教师先请求观察，并奖励校准的停顿。错误恢复任务尤其需要「先确认状态」而非直接复制成功轨迹下一步。

#### 5.18.1. 一个线性稳定性近似

把学生参数在局部最优附近的偏差记为 $e_n$，教师偏差为 $\bar e_n$。简化更新

$$
e_{n+1}=(1-\eta\lambda)e_n+\eta\lambda\bar e_n+\eta\xi_n,
$$

$$
\bar e_{n+1}=\tau\bar e_n+(1-\tau)e_{n+1},
$$

$\lambda$ 是蒸馏曲率，$\xi_n$ 包含教师目标误差。$\eta\lambda$ 过大，学生追逐移动教师产生振荡；$\tau$ 太接近一，教师偏差消失慢；太小则两者几乎同步，平滑作用弱。真实网络非线性，这个近似仍说明学习率、蒸馏权重和 EMA不能独立调。

若 $\xi_n$ 有固定偏置，稳定系统也会收敛到偏置点。训练曲线平滑不等于目标正确。外部验证与反事实测试用于估计偏置，优化稳定性只处理方差和动态。

### 5.19. 学生支持与可达性

教师偏好的 token若在学生分布中概率极低，有限 batch很难提供稳定更新。设教师目标 token集合 $A_T$，学生支持质量

$$
M_S(s)=\sum_{a\in A_T}\pi_S(a\mid s).
$$

$M_S$ 很小时，on-policy学生几乎采不到这些动作；纯 teacher-forcing仍能给梯度，但部署时一个早期偏差会离开监督前缀。先用 SFT或较宽教师分布提高支持，再做在线蒸馏，通常比直接强推尖锐目标稳。

支持不仅是 token层。学生可以逐 token模仿一段教师轨迹，在自己的采样下却很少生成完整前缀，序列概率是各步概率乘积。每步给正确 token 0.9，100 步完整路径概率约 $0.9^{100}\approx2.7\times10^{-5}$。长推理需要状态级纠错、验证和多路径，而非只让每步局部接近。

教师也可选择学生可达的替代动作。若最优动作 $a^*$ 概率极低，次优 $a'$ 已在学生支持且能进入可恢复状态，课程教师先指导 $a'$，待学生能力提高再转向 $a^*$。这相当于在教师质量与可学性间做路径规划。只按教师最高概率监督，可能让梯度长期集中在不可达模式。

可以把教师选择写成带可达性正则：

$$
\tilde p_T(a\mid s)\propto
p_T(a\mid s)^\alpha\pi_S(a\mid s)^{1-\alpha}.
$$

$\alpha=1$ 完全跟教师，$\alpha=0$ 不提供新方向；中间值偏向教师认可且学生已有支持的动作。它会限制跳跃式学习，适合作为早期课程，后期逐渐提高 $\alpha$。若学生初始偏差很大，过度考虑支持会困在原策略。

离线数据还存在 coverage问题。训练状态集合没有包含某类失败，教师再强也无法在那些状态上提供梯度。主动采样师生分歧大、价值不确定和部署频率高的状态，能提高信息效率；只选择分歧最大可能集中在无意义的格式或噪声，需加任务价值过滤。

### 5.20. 特权信息的泄漏通道

显式泄漏容易发现：学生 prompt保留答案字段、测试输出或参考轨迹。隐式泄漏更隐蔽。数据按答案排序、文件名含标签、模板长度与类别相关、工具缓存残留、教师输出引用答案特有短语，都能让学生利用训练期线索。评测去掉字段后失效，常被误判为蒸馏优化失败。

Token级审计应从最终送进 tokenizer的学生输入开始，而非原始数据结构。对每个特权字段生成 canary，确认它不出现在学生 token、attention mask可见区域、缓存前缀和工具描述中。Teacher 与 student batch若共享张量，切片错误可能让学生看见末尾特权 token，却在日志打印时被省略。

KV Cache 也是泄漏面。先运行含答案的教师，再复用同一 prefix cache给学生，如果 cache key没有包含完整上下文或角色，学生可能继承教师状态。Teacher/student forward应使用隔离 cache或严格内容哈希。多请求服务还需防跨样本页复用。

训练标签本身可以泄漏格式。若所有正确答案都被教师包在特殊标记，而评测解析器奖励该标记，学生先学格式即可提高。将格式 reward与任务 reward分开，使用多个等价格式和隐藏解析，能判断提升来自内容还是包装。

参考解的措辞也可能与评测答案重合。学生在训练集上记忆长 n-gram，未见题下降。按题族、来源与时间去重，检查 teacher output与评测 reference的近重合。对数学和代码，仅按问题文本去重不够，同一证明或补丁可能被多种 prompt改写。

环境反馈包含隐藏测试名、路径和期望值时，教师可能把它们写进建议，学生随后针对检查器投机。反馈应提供足够诊断、避免直接暴露秘密验收；或在训练时允许、评测时使用不同测试，验证学到一般修复能力。

#### 5.20.1. 无泄漏并不等于公平

学生输入干净，训练仍可能使用大量评测域答案。研究目标若是「将已有题库压入模型」，这可以接受；若声称未见泛化，就需要按来源和题族分割。特权训练的信息预算必须写清：多少参考解、多少环境调用、多少教师采样。与只看问题的基线比较时，额外信息属于方法成本。

外部大教师与同源特权教师的公平对照可以做两组。统一信息时比较模型指导能力；统一模型时比较特权信息价值。把大教师无答案与小教师有答案放在一张排名里，只能比较完整数据生产方案，不能归因到模型大小或自蒸馏本身。

### 5.21. 数据选择与偏差

特权教师数据常经过多级筛选：学生先生成，环境给反馈，教师再建议，验证器筛成功，并按长度与格式清洗。产出的分布由各级接受概率共同决定。某类任务在任一级难以验证，就会系统性缺失；某类短答案容易通过，会被过度表示。

把原始任务 $x$ 的入选概率记为 $a(x)$，训练分布

$$
q(x)=\frac{p(x)a(x)}{\mathbb E_{p}[a(x)]}.
$$

如果目标仍是 $p(x)$，可做重要性加权 $p/q$，但低接受率任务权重巨大、方差高。更实际的做法是保留独立按 $p$ 采样的评测，训练时承认课程分布改变，并设置每类最低覆盖。

只保留教师比学生好的状态也会偏向可纠错边界。教师和学生都失败的极难状态消失，双方都成功的基础能力也减少。前者需要更强工具、外部数据或任务分解，后者可作为防遗忘锚点。数据池按「师胜、生胜、同成、同败」四格统计，比单一接受率更有诊断价值。

长度过滤常被低估。长轨迹调用贵、格式更易失败，清洗后数据变短；学生在 benchmark上可能提高，真实长程恢复仍弱。报告筛选前后 token、turn和工具步数分布，按长度评测。若长样本质量确实低，应改进教师与验证，不能只删掉再宣称稳定。

教师温度和采样次数改变数据多样性。贪心教师稳定、覆盖窄；高温多采样产生替代路径，也增加错误。验证器能区分正确序列时，多样采样有价值；只能判断最终答案时，高温可能留下过程错误。数据中保留 teacher seed、温度、候选数和选择规则。

在线数据还有时间相关。学生 checkpoint更新后，旧教师数据来自不同状态分布；全部混合会造成 replay稳定，也可能拖慢新能力。按 policy版本分桶，比较新旧数据的 teacher advantage和学生 loss；过旧样本转为锚点或降低权重，而非无差别堆入。

### 5.22. 成本与有效监督量

特权教师每个状态可能需要学生 rollout、教师 forward、环境验证和训练 forward。设各成本 $C_R,C_T,C_V,C_U$，候选接受率 $a$，每个有效样本成本约为

$$
C_{eff}=\frac{C_R+C_T+C_V}{a}+C_U.
$$

提高教师质量但让验证接受率从 50% 降到 10%，有效成本可能增长五倍。只报告训练 FLOPs会漏掉数据生产主项。

Token logits蒸馏的存储也大。词表 $V$、监督 token数 $T$，全 logits需要 $TV$；top-k只存 $Tk$ 个值与索引，加上残余质量。若 $k=32$、$V=128K$，压缩约四千倍，前提是教师分布足够尖。开放状态中 top-k累计质量低时，截断目标偏差增加。

在线教师与学生同源，可在一次权重驻留中用不同输入批处理，减少加载；特权上下文更长，KV与算力仍更多。教师采用 EMA权重时需要第二份参数或切换，分布式训练还要同步。系统优化应与算法对照分开：同一目标更快不等于目标更好。

有效监督量还受相关性影响。同一道题的 32 条教师轨迹共享高层解法，统计独立性远低于 32；多题单轨迹可能覆盖更多状态。可用动作、状态和题族多样性估计有效样本。测试时扩展与训练数据扩展也不要重复计数。

一个预算例子：一万学生状态，教师每个采 4 条，单条教师与验证成本 0.08 美元，接受率 25%，最终约一万有效轨迹，数据成本 3200 美元；若把教师改成更强模型，单条 0.20 美元、接受率升到 50%，有效一万条需两万候选，成本 4000 美元。强教师单条贵，因接受率提高后总差距小于价格倍数。真实选择要比较每美元的未见任务增益。

## 6. 可证伪的实验矩阵

第一组检验特权是否真被教师使用。原始 $z$、打乱 $z$、遮罩 $z$、只保留格式四种条件，比较教师动作、成功率和置信。若原始与打乱相同，教师没有利用内容；若只保留格式仍高，可能存在模板捷径。

第二组检验学生是否能学。固定教师输出，在原始学生状态、删除关键线索、增加等价线索和分布外状态上蒸馏。删除线索后仍预测特权答案，可能记忆；增加等价线索后改善，说明可辨识性限制；训练 loss低而未见状态差，说明泛化而非优化问题。

第三组拆分同源与额外训练。相同模型无 $z$教师、同源有 $z$教师、外部教师无 $z$、外部教师有 $z$ 四格，在相同 token与调用预算下比较。它能分开模型能力、特权信息和数据量。无法完全统一成本时，同时给固定样本与固定费用两种口径。

第四组比较固定、EMA与即时教师。记录师生 KL、教师锚点漂移、熵、成功率和恢复能力。固定教师限制上限，EMA平滑，即时教师响应快；哪种更好取决于任务噪声与学生进步速度，不能只凭最终平均分。

第五组检查序列过程。最终答案相同的正确链、错误链和捷径链分别输入，观察教师与学生偏好；在中途注入错误，测能否发现、回滚和改道。特权教师若只会从干净前缀复述答案，恢复测试会暴露。

第六组检查泄漏。Canary字段、cache隔离、模板交换、题族去重与隐藏测试同时运行。任何一个失败，性能结果先标记为污染，停止讨论算法增益。泄漏检查属于实验前提，不是附录装饰。

第七组检查稳定—可塑性。新任务训练前后评估旧能力、新能力与通用锚点；分别移除旧教师、新特权教师和reference KL。观察遗忘来自数据覆盖、目标冲突还是权重漂移。仅给新任务增益无法证明持续学习有效。

### 6.1. 与持续学习的连接

新任务学习时，特权教师提供塑性信号；旧模型教师提供稳定约束。对新数据 $D_{new}$ 与回放状态 $D_{old}$，一个简化目标为

$$
L=\mathbb E_{D_{new}}D(p_T^{priv}\|q_\theta)
+\lambda\mathbb E_{D_{old}}D(p_{old}\|q_\theta).
$$

$\lambda$ 太小会遗忘，太大限制新能力。更细的权重应依赖状态：新旧任务共享知识时，旧教师可能阻碍修正错误；完全旧域则更需保护。使用梯度余弦诊断两项目标是协同还是冲突，比只扫全局 $\lambda$ 更能解释。

旧教师也可能已经有缺陷。无条件保持旧分布会把错误冻结。可以只在旧教师经验证正确、高置信且任务仍适用的状态蒸馏；对于新证据推翻的知识，允许更新。Continual learning 的目标是保留能力，不是逐 token复制旧模型。

回放数据决定保护范围。只回放少数 benchmark，模型可在未覆盖旧任务上遗忘；保存全部数据又昂贵。可从旧状态按功能、难度与边界分层选锚点，使用生成回放补充；生成数据由旧模型产生，会逐轮积累偏差。定期用固定真实锚点校准。

特权新教师可能看到新任务答案，旧教师只看普通输入，信息条件不对称。梯度规模会偏向尖锐的新教师。温度、loss归一和分批更新能平衡数值，最终仍要看旧新任务 Pareto曲线。单个加权平均分可能掩盖某个域完全崩溃。

参数共享让局部更新传播到通用能力。按层、模块或低秩适配限制可塑区域，降低遗忘；也可能阻碍新任务需要的底层表示。特权蒸馏与参数隔离是两条正交轴：前者决定目标信息，后者决定更新空间。消融时不要把二者收益混在一起。

若教师使用当前学生的 EMA，旧知识锚点也会慢慢漂移。保留一个冻结的初始教师或周期历史 checkpoint，能测长期漂移。EMA适合短期平滑，冻结教师适合绝对坐标；组合时在新域由 EMA指导，在旧锚点由冻结模型约束。

#### 6.1.1. 功能距离优于参数距离

参数 L2 小不保证输出接近，不同重参数化也可实现相同函数。防遗忘更适合在旧状态上比较 logits、价值或任务结果。Logit KL仍只覆盖选定状态；环境任务可比较动作后果。高风险能力使用行为测试作为硬门槛，不能只依赖平均 KL。

功能保持也不要求所有 token相同。旧模型在某状态有多个等价正确动作，KL会惩罚新模型换用另一条正确路径。Verifier-aware distillation 可只约束正确集合或状态价值；缺少验证器时，用多样旧教师样本扩大等价支持。

### 6.2. 安全策略与特权教师

教师看到安全规则、用户权限或隐藏风险标签，可以给出更安全动作；学生部署时若看不到这些变量，同样面临不可辨识。例如两个表面相同请求，一个用户有授权、一个没有，权限 $z$ 不在学生状态，学生无法同时给正确动作。解决办法是把必要权限暴露为部署可见状态，而非试图蒸馏秘密。

某些安全知识可以参数化：危险命令模式、隐私边界和常见攻击。教师用详细策略文档指导，学生之后不需全文也能识别。要区分稳定规则与每次请求动态授权。前者适合 context distillation，后者必须实时查询。

工具反馈可能含 prompt injection。特权教师读取网页、日志与参考答案时，恶意文本会冒充指令，教师建议随之污染。模板应将外部内容标记为数据，工具权限由系统层限制，并用注入测试评估。学生若蒸馏了攻击成功轨迹，部署即使不再显示原文本，也可能学到错误模式。

教师拥有更高权限时，建议可能无法由学生执行。它能读取隐藏文件、调用管理 API 或跳过审批，学生学到动作后在部署反复失败，甚至尝试越权。教师 rollout必须使用学生动作空间与权限；特权只用于观察或判断，除非目标明确训练权限请求行为。

安全拒绝也会模式坍缩。教师在不确定时总拒绝，学生容易学会保守捷径，安全指标上升、任务可用性下降。评测包含允许、拒绝与需要澄清三类，测过拒与漏拒。特权风险标签可用于训练，部署状态必须含足够线索区分三类。

多教师安全聚合中，安全教师和任务教师可能冲突。将安全作为硬约束、任务在可行集合内优化，比简单平均概率更清楚。若安全判断本身不确定，提供请求确认或低权限替代动作；平均一个执行与一个拒绝分布可能生成语义不完整的折中文本。

### 6.3. 教师分布的分辨率

教师监督可以在 token、句子、步骤、动作或整条轨迹层级。粒度越细，信号越密，越容易把表面措辞当成目标；粒度越粗，允许等价实现，信用分配更难。特权信息类型应匹配层级：参考答案适合序列或步骤，编译错误适合修复动作，成功轨迹适合状态价值与策略。

Token KL 在教师与学生使用同一动作语言时自然。若教师思维更长、学生需要简洁，逐 token模仿会继承冗长。可只蒸馏最终动作分布或让教师输出标准化中间计划。压缩教师 reasoning时，过程信息可能丢失，需验证学生恢复能力。

步骤级监督先把轨迹分段，对每步给目标或价值。分段规则若依赖教师文本标记，学生格式变化会错位；基于环境动作、验证事件和状态 diff更稳定。自然语言推理缺少明确边界，可用句子或证明 tactic作为近似。

动作级偏好允许多个表述映射到同一工具调用或代码 diff，减少措辞惩罚。解析器必须准确，自动修复后的动作需标记。若一个自然语言动作包含多个副作用，粗粒度又会隐藏哪部分错误。

轨迹级 reward最忠于最终任务，稀疏且方差高。特权教师可把终局反馈转成细粒度建议，本质是学习 credit assignment。教师建议是否真的对应因果贡献，需要环境分支或反事实验证；可读解释不自动等于正确信用。

多粒度目标可组合：token KL保证局部可学，步骤价值指导恢复，终局 verifier守住目标。权重过多会产生冲突。逐级消融并报告每级梯度范数，避免某个高密度 token loss压过真正任务信号。

### 6.4. 训练与评测的分层统计

平均任务分数无法揭示特权蒸馏在哪些状态有效。至少按教师优势 $A_T=R_T-R_S$、学生支持、状态偏离、轨迹长度和特权类型分桶。教师优势大但支持低是潜在高收益难例；优势小的样本主要提供稳定性；教师负优势应隔离或反向学习。

对每个桶报告样本数、接受率、教师成功、学生训练前后成功和 KL。某桶样本很少，百分比波动大，给置信区间。在线采样让同一任务多次出现，bootstrap按任务而非轨迹，避免把相关 rollout当独立样本。

序列任务同时报告 pass@k与单次成功。自蒸馏可能增加分布多样性，提高 pass@k却降低稳定性；也可能熵塌缩，单次略升、pass@k空间变小。固定总采样预算与解码参数比较。

恢复能力单列。构造已偏离示范的状态，测发现错误、诊断、回滚和重新规划。只在干净起点评测，会夸大成功轨迹教师。教师本身也跑同一恢复集，确认它确有优势。

校准用可靠性图和选择性风险。允许学生在低置信时请求工具或弃权，观察覆盖率—成功率曲线。特权蒸馏若只提高自信、没有提高正确率，校准会恶化；平均准确率未必立即暴露。

旧能力评测使用固定锚点与更广抽样。锚点监控精确回归，广抽样捕捉未预期遗忘。对生成任务，字符串匹配不够，使用功能验证或多参考，同时保留原始输出供审计。

#### 6.4.1. 显著性与实际意义

样本很多时，极小提升也可统计显著。应同时报告绝对成功点、每美元或每 token增益、最坏桶变化和失败类型。教师调用翻倍换 0.2 点，是否值得取决于应用；高风险桶下降即使平均上升，也不能被掩盖。

配对实验使用同一任务、初态和随机种子，降低方差。教师方案与基线若数据量不同，另做等 token和等成本对照。训练 checkpoint选择不能偷看最终测试，用验证集固定规则。多次尝试只报最好一次会高估稳定性。

### 6.5. 一次完整手算

假设同一学生状态有两个可见类型 $s_1,s_2$，各占一半；每类又有特权变量 $z\in\{0,1\}$。在 $s_1$，$z$ 可由状态线索以 90%准确率预测；在 $s_2$，$z$ 独立随机。教师看到 $z$ 后总能选正确动作 A 或 B。

无限容量学生在 $s_1$ 最优准确率 90%，在 $s_2$ 只能 50%，总上限

$$
0.5\times0.9+0.5\times0.5=0.7.
$$

教师是 100%，学生即使完美蒸馏仍只有 70%。如果实验只报告师生差 30 点，不能归因优化；其中 30 点来自信息边界。给学生增加一个部署可见观测，使 $s_2$ 中 $z$可预测到 80%，新上限变为 85%，这才是改变问题可辨识性。

再看有限支持。学生在正确动作上的初始概率：$s_1$为 0.2，$s_2$为 0.01。直接采样一条正确 20 步轨迹，概率分别约 $0.2^{20}$ 和 $0.01^{20}$，在线成功几乎不会出现。Teacher-forcing能逐步提高概率；若只用成功 on-policy轨迹，第二类永远缺数据。先离线蒸馏或让教师接管关键步，才能进入可学习区。

假设教师查询 4 次，每次 0.05 美元，环境验证 0.02，接受率在 $s_1$为 50%、$s_2$为 10%。每个有效监督成本分别约 $4(0.05+0.02)/2=0.14$ 与 $4(0.07)/0.4=0.70$ 美元。困难不可辨识状态不仅上限低，数据也更贵。继续加采样不划算，应先改善学生观测或任务定义。

这个例子把三类瓶颈分开：信息上限决定能否学，支持决定优化能否触达，接受率决定数据成本。EMA、温度和 loss权重只能在后两类局部改善，无法突破第一类。

### 6.6. 参考解、反馈与成功轨迹的组合

三类特权信息提供不同条件。参考解回答「目标路径是什么」，反馈回答「当前路径哪里出错」，成功轨迹回答「环境中怎样走通」。只给参考解，教师可能忽略当前状态；只给反馈，教师知道症状但缺少修复方向；只给成功轨迹，状态偏离后动作无法直接复用。组合的价值来自互补，不来自上下文越长越好。

可把教师决策分解为诊断和提案：

$$
d\sim p_T(d\mid s,z_{feedback}),\qquad
a\sim p_T(a\mid s,d,z_{solution},z_{traj}).
$$

先诊断再提案允许分别验证。诊断错，后续动作即使流畅也应降权；诊断对、动作错，说明执行知识不足。把所有信息一次塞进 prompt，只能看到最终文本，难以定位。

信息间也会冲突。参考解基于初始状态，当前反馈说明文件已经变化；成功轨迹使用旧工具版本，环境返回新 schema。教师需要优先当前可验证事实，再把参考材料当建议。模板中明确时间和版本，要求引用证据；最终仍以环境验证为准。

多视图训练可随机丢弃一类特权，让教师不过度依赖单一路径。全部视图用于强教师，部分视图提供鲁棒教师，学生只看无特权状态。比较教师随视图删除的性能，可以估计每类信息边际价值与交互。若删除任何一类都无影响，它可能冗余或没有被使用。

组合上下文长度会挤压学生轨迹。教师看了长参考解后，可能看不到最早错误；压缩反馈和轨迹又可能删关键状态。可先用结构化摘要保留目标、当前环境、失败证据和不可逆动作，完整材料通过检索按需展开。摘要器也成为潜在错误源，需要版本和消融。

参考解和成功轨迹可能含同一信息，重复会让教师注意力过度集中。去重不能只做文本匹配，应识别动作与状态等价。保留来源标签，让教师知道某事实由多个独立证据支持，和同一证据重复三次含义不同。

#### 6.6.1. 何时只用一种特权

纯数学题有可靠参考解、状态几乎就是题目，答案型教师足够；编译修复中当前错误日志比标准补丁更能定位，反馈型更重要；网页或工具任务状态转移复杂，成功轨迹与实时环境共同必要。方法选择应服从任务可观测性，不能把三类信息固定成通用模板。

若 verifier强、教师弱，可用反馈和验证迭代，不必提供完整参考；若参考解强但 verifier弱，序列蒸馏较稳，过程真实性有限；两者都弱时，自蒸馏容易自我确认，应先改善证据。数据生产能力决定算法上限。

### 6.7. 与奖励模型和价值模型的关系

奖励模型给轨迹或动作标量，特权教师给条件分布或文本建议。标量便于优化和排序，信息密度低；教师分布能指出替代 token，错误也会更细地传播。价值模型估计状态未来成功，适合筛选状态与片段，未必告诉具体动作。

三者可以顺序更新。价值模型找出高不确定或高潜力状态，特权教师提出动作，环境或奖励模型验证，成功数据更新学生；新轨迹再更新价值。每个模型若都由同一学生数据训练，错误相关会形成回路。固定验证集、外部规则和版本化日志提供独立证据。

教师概率不能直接当 reward而不考虑归一化。Token log-prob累加偏向短序列，教师措辞偏好可能超过任务质量。若用于 RL，通常计算相对 reference的 shaping或在动作级聚合，并用终局 verifier守住目标。否则策略可能学会生成教师喜欢的风格。

奖励模型可选择多个教师候选。若 RM 本身偏好长度、格式或答案泄漏，选择会放大偏差。报告 teacher raw pass、RM-selected pass和 oracle pass，三者差距分别反映候选质量、选择器能力与上限。只报 selected结果无法判断教师强还是 RM强。

价值模型用于 productive segment时受事后相关性影响。特权教师看到参考解可解释片段，仍可能把后期常见动作误当因果。状态分支和动作干预是更强验证。没有分支环境时，至少用不同轨迹的相同状态、删除片段与隐藏测试对照。

教师还可训练过程奖励模型：以特权信息判断每步。PRM随后在部署无特权时评价学生过程，其输入边界要与部署一致；若 PRM训练时也看答案，推理时拿掉会发生条件移位。可以蒸馏一个无特权 PRM，并单独验证校准。

### 6.8. 开放式任务的特殊困难

开放写作、研究和对话缺少唯一参考解与硬 verifier。特权教师可能看到用户偏好、资料和后续反馈，学生训练后要在新用户上泛化。条件信息中哪些是稳定风格、哪些是当次秘密，需要分开。把个别用户具体事实压入参数既无用也有隐私风险。

对写作任务，教师的最终文本只能提供一种实现。逐 token蒸馏容易复制措辞和 AI习惯，目标应更偏向结构、事实选择和可读性。可以让教师给多种草稿、抽取共同约束，再用人工或偏好数据选择。风格蒸馏需要明确归属与同意。

研究任务的特权可能是完整资料。学生无法把不断更新的世界事实全部参数化，适合学习检索、核查和综合方法；具体事实仍从工具获取。评测换新资料，看学生是否会用证据，而非背训练答案。教师引用应可追踪，避免幻觉被蒸馏成高置信记忆。

对话中的后续用户反馈属于未来信息。教师事后知道用户真正意图，可以教早期提出更好的澄清问题；不能教模型直接说出尚未透露的答案。将未来反馈转成「当时哪项不确定需要询问」的标签，比把完整未来对话塞进教师输出更因果。

开放任务的验证可用多维 rubric与成对比较，仍有主观偏差。多个独立评审、一致性与人工抽查提供校准。教师和评审若同一模型，风格自偏好尤其严重；至少加入外部事实检查和不同模型或人类样本。

长输出增加序列错位。教师参考文本和学生草稿结构不同，逐位置 logits未必对应同一语义。可在段落计划、事实单元或编辑操作层蒸馏；局部语言由学生自由生成。粒度选择比盲目对齐长 token序列重要。

### 6.9. 隐私与数据治理

特权信息常包含标准答案、内部日志、用户历史、未公开代码和权限信息。教师输入可用不等于允许进入模型参数。训练前要按数据许可与敏感等级筛选，动态秘密只用于当次推理或安全聚合，避免长期记忆。

模型可能从蒸馏数据提取罕见字符串。参考解中唯一 API key、个人标识或私有代码比常见文本更易被记忆。脱敏在教师调用前完成，输出后再次扫描；只清输出不够，教师可能改写或编码秘密。Canary和成员推断测试能估计泄漏。

如果目标是让学生学习处理秘密的流程，可用合成占位符与模拟服务。学生学会从安全存储取句柄、传给工具和不写日志，无需接触真实值。占位符保留类型和作用域，避免所有秘密变成同一 token。

数据删除需要血缘。特权字段、教师输出、筛选轨迹、训练 shard和 checkpoint之间建立来源映射。源数据撤回时，至少能删除未来训练集并评估模型去学习需求。没有血缘时，特权蒸馏会把原数据变成难追踪派生文本。

多教师调用外部 API还涉及服务条款与跨境。记录提供方、版本、保留策略与是否允许训练。知识库讨论算法时不能把这些问题当工程尾注，它们决定某种数据生产是否能合法复现。

差分隐私可限制单样本影响，代价是梯度噪声与性能。特权样本稀少、复杂时，DP更容易损伤学习。优先减少敏感数据、用合成替代和参数隔离，再评估 DP预算；不能拿「之后会做 DP」为过量收集辩护。

### 6.10. 最小复现协议

第一步固定学生 checkpoint、teacher来源、特权模板、数据分割和 tokenizer。抽取少量状态，打印最终 teacher/student token ids与loss mask，确认特权只在教师侧，动作位置对齐。Canary检查 cache与 batch没有泄漏。

第二步测教师价值。原始、打乱、遮罩与不同特权子集上运行教师，给续写成功、校准和输出差异。教师看更多信息却没有稳定增益，就停止进入大规模蒸馏。

第三步测可学性。用小数据训练，比较 teacher advantage、学生支持和未见题增益。训练 loss降、未见结果不升，检查不可辨识与模板捷径；正确 token概率几乎为零，先改善支持或课程。

第四步接入在线状态。学生 rollout后在真实错误状态查询教师，按恢复类型分类。环境验证教师建议，失败建议隔离。固定教师、EMA和无特权教师在相同状态、token和费用下比较。

第五步扩大训练，记录每个样本的 student policy、teacher版本、$z$ 类型、验证结果、接受规则和成本。Checkpoint评测包含新任务、旧锚点、恢复、校准、安全与长度分桶。模型选择规则在训练前固定。

第六步做泄漏和分布审计。按题族、来源和时间去重，交换模板、参考解与反馈；学生输入扫描特权 n-gram。任何污染都单列，不用清洗后的部分成绩替代完整说明。

第七步发布复现材料。提供公式对应代码位置、关键超参、teacher prompt、mask规则、数据漏斗、版本、随机种子和逐任务结果。无法公开特权数据时，给合成小集复现管线，并说明主结果中哪些部分外部无法重建。

#### 6.10.1. 复现失败怎样定位

教师性能不复现，先检查模板、模型版本、解码和 $z$ 内容；教师正确、学生不学，检查对齐、mask、支持和 loss方向；训练集提升、未见集不升，检查去重、不可辨识和捷径；新任务升、旧任务降，检查回放与锚点；平均稳定、恢复差，检查状态分布和成功轨迹偏差。

师生 KL异常小，可能教师没用 $z$、cache串用或目标实现错误；KL异常大，可能 response span错位、tokenizer不同、教师温度过低。梯度正常也无法排除语义错位，必须人工查看同一动作位置的上下文与 top token。

### 6.11. 证据边界

特权教师的核心结论可以从条件蒸馏数学、context distillation与相关自蒸馏论文中支持：同源模型在更多信息下形成更强条件策略，学生可以吸收其中可由自身状态预测的部分。它不保证任意秘密都能参数化，也不保证同源教师天然正确。

参考解、环境反馈和成功轨迹三类信息的作用可以由对应实验验证；具体哪种最好取决于任务、模板与 verifier。没有统一 benchmark和预算时，不写成普遍排名。OPSD、SDFT、SDPO共享自蒸馏家族关系，损失、状态分布和筛选不同，应在各自文章中核对细节。

EMA提供平滑和滞后，其最优衰减没有跨任务常数。Top-k、温度、teacher采样数同样依赖分布。本文给出的是影响方向、手算与验收方法，具体默认值以论文和复现实验为准。

成功轨迹的反事实价值、未来信息遮罩和多教师路由仍需要更强公开证据。能够从机制推出的风险不等于论文已经完成相应实验。建议性实验明确作为验证方案，不能改写成作者结论。

内容扩展在此停留于可辨识性、优化、数据、稳定、安全与复现六条主线。继续增加相邻自蒸馏论文的具体表格会与各论文页重复，也会混淆主题页职责。新的事实只有在一手论文或官方实现可核查时再加入。

### 6.12. 从条件分布到学生更新的逐步推导

对单个学生状态 $s$，教师条件分布依赖 $z$。Forward KL展开为

$$
D_{KL}(p_T\|q_\theta)=
\sum_a p_T(a\mid s,z)log p_T(a\mid s,z)
-\sum_a p_T(a\mid s,z)\log q_\theta(a\mid s).
$$

第一项与学生参数无关，因此梯度是带软标签的交叉熵：

$$
\nabla_\theta L=-\sum_a p_T(a\mid s,z)
\nabla_\theta\log q_\theta(a\mid s).
$$

相比 one-hot SFT，每个 token都从教师分布获得方向。教师错误高置信时，梯度也更强；温度和样本权重本质上都在改变这组梯度。多个 $z$ 对同一 $s$ 出现时，期望梯度对应边缘教师 $\bar p_T$，前述混合上限由此直接得到。

若加入 reference策略 $q_0$，可用 log-ratio约束更新。一个简化目标为

$$
L=-\mathbb E_{a\sim p_T}[\log q_\theta(a\mid s)]
+\beta D_{KL}(q_\theta(\cdot\mid s)\|q_0(\cdot\mid s)).
$$

第一项拉向特权教师，第二项保留原策略。$\beta$ 大时更新保守，教师新模式难进入；小则容易遗忘与熵塌缩。Reference若本身在新任务上很差，统一 $\beta$ 会阻碍最需要改变的状态。可按 teacher advantage和旧能力风险调整，仍需固定锚点评测防止权重模型投机。

偏好形式只观察教师认为 $a^+$ 优于 $a^-$。Bradley–Terry概率可写为

$$
P(a^+\succ a^-\mid s)=
\sigma\left(\beta\left[
\log\frac{q_\theta(a^+\mid s)}{q_0(a^+\mid s)}-
\log\frac{q_\theta(a^-\mid s)}{q_0(a^-\mid s)}
\right]\right).
$$

它只约束相对差，不恢复教师完整不确定性。教师有多个等价正动作时，单对偏好可能任意压低其中一个；软分布或多正例能保留。教师偏好来自特权秘密时，相对目标仍无解，并不会因换成偏好损失消失。

序列 $y=(a_1,\ldots,a_T)$ 的 teacher-forcing loss为

$$
L_{seq}=-\sum_{t=1}^T\sum_a
p_T(a\mid s_t,z)\log q_\theta(a\mid s_t).
$$

这里的 $s_t$ 来自哪条轨迹会改变训练目标。若由教师轨迹构成，学生只学专家状态；若由学生轨迹构成，教师在错误状态上纠错；若混合，需标记来源。同一公式掩盖了状态分布差异，很多自蒸馏方法的区别正来自这里。

学生状态上的教师可能使用未来信息。令合法特权为 $z_{\le t}$，完整轨迹特权为 $z_{1:T}$。因果目标应是

$$
p_T(a_t\mid s_t,z_{\le t}),
$$

使用 $z_{>t}$ 会形成 hindsight teacher。Hindsight可以教高层策略，但动作监督是否可预测需要反事实检查。把未来信息先转成「应询问什么」「应验证什么」的因果标签，比直接给下一动作更稳。

#### 6.12.1. 梯度冲突手算

设二动作学生 logit差为 $u$，$q(A)=\sigma(u)$。新任务特权教师要 A，旧教师要 B。两项 one-hot交叉熵梯度分别为

$$
g_{new}=q(A)-1,\qquad g_{old}=q(A).
$$

总梯度 $g=g_{new}+\lambda g_{old}=(1+\lambda)q(A)-1$。平衡点

$$
q^*(A)=\frac1{1+\lambda}.
$$

$\lambda=1$ 时学生停在 0.5，两个任务都不确定。此时优化器已经收敛，真正的矛盾来自同一可见状态上的相反目标。若任务 ID或环境线索加入状态，模型可以分别输出，冲突消失。这个手算再次说明先改善可观测状态，再调 loss权重。

还有一种容易漏掉的情形：教师掌握的特权变量只在训练期与答案相关，部署环境一变，这种相关性便消失。设训练分布中 $z$ 与动作 $a$ 高度相关，而测试分布改变了 $p(z\mid x)$。若学生通过教师软标签间接记住这条捷径，它即使从未直接看见 $z$，也会继承教师的分布偏好。检查办法是固定可见状态 $x$，对特权变量做干预或置换，再观察教师建议与学生输出是否同步漂移。真正可以迁移的知识应落在由 $x$ 支撑的因果关系上；只能由训练期偶然相关性解释的部分，应降低蒸馏权重，或者交给显式的不确定性头处理。

若旧、新状态可区分，仅共享参数造成梯度冲突，模型容量或参数隔离可以缓解。测同一 batch两项梯度余弦：负值表示局部竞争，零附近可能使用不同参数，正值表示协同。梯度 surgery能处理数值冲突，却无法解决同一状态标签矛盾。

#### 6.12.2. 教师优势的估计误差

用有限 rollout估计教师优势 $A_T=Q_T-Q_S$。每边各采 $K$ 次二元结果，方差约

$$
Var(\hat A_T)=\frac{p_T(1-p_T)}K+
\frac{p_S(1-p_S)}K.
$$

两者都接近 0.5、$K=4$ 时，标准差约 $\sqrt{0.125}\approx0.354$，一次估计很不稳定。只因教师 3 胜、学生 1 胜就给高权重，可能是采样噪声。贝叶斯平滑、更多重复或按状态族汇总能降低方差。

环境随机性相关时，上式还低估方差。配对相同初态和随机种子，让教师与学生面对相同外部扰动，更能测策略差；对网页等无法固定环境，记录时间和错误，使用分层统计。教师优势估计的置信区间应进入权重或至少进入审计。

这些推导把三个常见误区分开。换损失不能创造学生看不到的信息；收敛到混合可能是目标冲突；有限样本下教师优势会被噪声夸大。特权蒸馏的第一步始终是定义学生状态与合法信息，然后才轮到 KL方向、EMA和优化超参。

### 6.13. 一份训练前判定表

先写清部署时学生能看到的状态。用户输入、工具 schema、当前环境、权限与历史分别有哪些；动态授权和未来反馈不得假设已知。随后列教师额外看到的 $z$，逐项判断它是可由学生状态统计预测的规律、可通过动作主动查询的信息，还是每个样本独立变化的秘密。第三类不适合直接参数化。

再验证教师优势。对相同学生状态，带 $z$、无 $z$、打乱 $z$ 的教师使用相同采样与预算；比较任务成功、动作变化和校准。教师只写得更长、成功率不升，不能当作有效监督。教师优势只在少数状态出现，就将调用集中到这些状态。

接着检查学生支持。统计教师高质量动作在学生分布中的概率、完整轨迹可达性和错误状态覆盖。支持太低时先做 SFT、课程或动作分解；状态缺失时采学生 rollout再查询教师。不要期待 EMA或更大学习率弥补没有数据的区域。

数据进入训练前，核对 response span、loss mask、tokenizer、cache隔离、未来信息和自动修复动作。每类特权样本保存教师输入、学生输入、版本、验证与接受理由。随机抽样人工回放，确认标签语义与执行状态一致。

训练中同时看任务、KL、熵、teacher advantage、旧能力和恢复。Loss平滑只证明优化器在拟合当前目标。出现新能力上升、旧能力下降时定位数据与梯度；师生一起下降时检查移动教师；熵快速下降时检查尖锐目标和选择偏差。

训练后用未见题族、模板交换、状态扰动、错误恢复、权限与泄漏测试。学生在原模板成功、换表述失败，说明吸收了表面模式；答案正确、过程反事实失败，说明可能靠捷径；低置信时会查询或澄清，通常比盲目高置信更可靠。

报告按信息与成本分别组织。教师调用、验证、接受率、训练 token和推理预算分别列出；同信息比较模型，同模型比较特权，不同完整方案则只下端到端结论。所有无法复现的私有 $z$ 与验证器单独说明，避免读者把缺失资源误解为算法细节。

这张表的顺序有意把信息边界放在优化之前。特权教师最常见的误判，是看到一个更强条件策略便假设学生能够无条件复制。只有状态充分、教师可靠、动作可达和数据无泄漏同时成立，蒸馏目标才真正有意义。
