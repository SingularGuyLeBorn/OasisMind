# OPSD：参考解条件化的自蒸馏

推理数据集常常同时拥有两样东西：一道题的参考解，以及一个已经具备基本解题能力、却仍会在自由生成时走偏的模型。直接拿参考解做 SFT，模型只在参考解给出的正确前缀上学习；只做结果奖励 RL，模型又只能在整条回答结束后收到一个稀疏分数。2026 年 1 月发布的 **Self-Distilled Reasoner** 把两者接了起来：先让学生模型生成自己的轨迹，再让同一个模型在额外看见参考解的条件下，沿学生已经生成的前缀给出下一 token 分布。论文把这套方法称为 **On-Policy Self-Distillation，OPSD**。

这里最容易看错的是参考解的位置。参考解不是学生要逐字复现的标签，也不负责产生受监督前缀。学生先按当前策略生成

$$
y\sim \pi_{\theta_k}(\cdot\mid x),\qquad s_t=(x,y_{<t}),
$$

教师随后读取同一个 $s_t$，只是多看一份经过验证的推理轨迹 $c$：

$$
q_t(v)=\pi_{\bar\theta}(v\mid x,c,y_{<t}),\qquad
p_t(v)=\pi_\theta(v\mid x,y_{<t}).
$$

$\bar\theta$ 固定在训练起点，教师前向停止梯度；更新只作用于学生分布 $p_t$。这样一来，若学生在第十步写错了变量，训练仍会抵达这个错误状态。教师借助参考解判断接下来哪些 token 能修复推理，再把判断压回不带参考解的学生。**参考解提供方向，学生 rollout 决定训练发生在哪里。**

## 1. 为什么它比参考解 SFT 多做了一件事

设参考解前缀为 $c_{<t}$，学生前缀为 $y_{<t}$。SFT 优化的是 $-\log\pi_\theta(c_t\mid x,c_{<t})$；当学生部署时生成了 $y_{<t}\neq c_{<t}$，这个目标没有说明如何从当前位置继续。OPSD 则直接比较 $q_t(\cdot\mid x,c,y_{<t})$ 与 $p_t(\cdot\mid x,y_{<t})$。两种训练都使用参考解，但前者学习参考轨迹上的动作，后者学习学生访问状态上的恢复策略。

这也解释了为什么 OPSD 仍需要一个不太弱的起点。若学生 rollout 大部分无法解析，或错误前缀已经丢失了求解所需的信息，参考解条件化教师也未必能够恢复。参考解还可能采用另一套符号、跳过中间步骤，甚至本身有误。训练前应固定一批学生轨迹，比较教师加入参考解前后的正确续写率、关键 token margin 与续写最终成功率；只有条件视图确实更强，蒸馏才有信息可传。

## 2. 分布目标与逐点裁剪

OPSD 使用 full-vocabulary 的逐 token 分布监督。以教师到学生的 forward KL 为例：

$$
\mathcal L_t=D_{\mathrm{KL}}(q_t\Vert p_t)
=\sum_{v\in V}q_t(v)\log\frac{q_t(v)}{p_t(v)}.
$$

完整词表让学生同时看见教师提高了哪些候选、压低了哪些候选，比只观察已经采到的 token 信息更完整。代价是每个位置都要处理 $|V|$ 维 logits。论文还对逐 token 的概率比进行裁剪，避免坏前缀上极端小概率形成异常大的更新。这里的裁剪作用于局部分布项，并不是把整条序列套进 PPO 的策略比率目标。

裁剪需要和信号损失一起观察。阈值过松，少数异常位置支配梯度；阈值过紧，教师最明确的纠错意见也会被截掉。除了任务正确率，至少还要记录被裁剪 token 的比例、它们集中在推理步骤还是格式 token，以及裁剪前后的教师优势分布。

## 3. OPSD 的能力边界

OPSD 的教师没有新增参数知识。它利用的是模型看到参考解后的上下文学习能力，因此收益受三道门槛限制：参考解是否含有有效信息，模型能否把参考解用于当前学生前缀，学生参数是否有能力在没有参考解时重现这种判断。教师最终答案正确，只能证明它会解题；真正相关的是它能否在学生已经犯错的位置给出更好的局部条件分布。

论文在数学推理任务上展示了比结果奖励方法更高的 token 效率，也优于若干离线蒸馏基线。这个结论对应论文所用模型、数据和参考解质量，不能直接外推成「自蒸馏总比 RL 好」。环境能够发现教师未知策略时，外部奖励仍然不可替代；没有逐题可靠参考解时，OPSD 的特权条件也无法构造。

## 4. 实现检查

一次更新至少要保存学生 rollout 的权重版本、参考解版本、教师参数版本、学生可见 token mask、教师可见 token mask，以及裁剪统计。最危险的错误是学生 mask 意外放开参考解：训练 loss 会快速下降，部署时移除参考解便立刻失效。第二类错误是教师沿参考解前缀评分，而没有沿学生前缀评分；这样训练又退回了 off-policy 蒸馏。第三类错误是 rollout 长期复用，名义上的 on-policy 数据已经落后于当前学生。
