# tt-material-animation：材质动画 Prompt Skill

> 来源：QQ 转发（转自 DCSkills / pwWheel / t-design）
> 用途：把用户指定的实体材质或传统物理媒介，转成「具体工艺 + 视觉隐喻 + 可直接复制的首尾帧图片/视频 Prompt」，并在可用时按确认直接生成端点图片。

## 一句话

主打「材质动画」的创意小视频 Prompt skill：软陶定格、半调纸拼贴、孔版印刷、水墨晕染、毛毡、沙画……都可以套用。

## 工作方式：三段式确认流程

每一步都等用户点头，不会一股脑堆给你：

1. **确认材质工艺**
   - 从 7 个材质族 / 9 种工艺中推荐最匹配的候选
   - 跨材质推荐 3 个；指定材质族则只在族内推荐
   - 说明理由、材质特征、色彩方向、运动语言与取舍

2. **确认视觉隐喻**
   - 2~3 个方向
   - 每个含：核心意思、开场状态、结尾状态、核心变化动作

3. **交付 Prompt**
   - 自包含的【图片 Prompt】+【视频 Prompt】+【建议上传的图片清单】
   - Prompt 内嵌全部视觉信息（色彩、光影、构图、Avoid 清单）
   - 模型无关，直接粘进任意图像/视频工具

## 边界

- 以 Prompt 设计为主
- 当前会话存在 image_gen 且明确同意时，可直接生成端点图片
- 不生成视频
- 不创建项目目录、contact sheet 或 QA 文件

## 值得借鉴的点

- 分段确认避免「一股脑堆 Prompt」，交互体验好
- Prompt 自包含（色彩/光影/构图/Avoid），不依赖特定模型
- 「首尾帧」思维：先定开场与结尾状态，再定变化动作，天然适配视频生成
