# PPO 式 RLHF 流水线

RLHF 包含一条数据与模型相互依赖的训练链。SFT 决定策略起点；同一 prompt 的多个回答经过比较标注后训练奖励模型；当前策略在线生成新回答，奖励模型给出终局分数，reference policy 提供分布锚点，critic 与 GAE 把序列回报变成 token 级 advantage，PPO 再更新策略。

这条链里至少要分清 policy、old policy、reference、reward model 与 critic。old policy 是本轮采样版本，可以只保存 log-prob；reference 长期冻结，用于控制相对 SFT 起点的漂移；reward model 定义代理目标；critic 预测当前策略下的未来回报。奖励模型过拟合、critic 偏差和 ratio 失配会沿不同路径传播，不能都归结为“PPO 不稳定”。

[PPO 式 RLHF 训练流水线](./2.1.1-ppo式rlhf流水线.md)从 completion-only SFT 写到偏好数据、Bradley–Terry 奖励模型、token KL shaping、GAE 和 minibatch 更新。它还讨论 reward hacking 与独立 holdout，帮助读者判断一个结果来自策略真的改善，还是代理奖励被利用。
