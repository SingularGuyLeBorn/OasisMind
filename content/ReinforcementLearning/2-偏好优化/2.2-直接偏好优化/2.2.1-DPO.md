# DPO: 从 KL 正则 RL 到离线偏好损失

> 论文: [Direct Preference Optimization: Your Language Model is Secretly a Reward Model](https://arxiv.org/abs/2305.18290), Rafael Rafailov, Archit Sharma, Eric Mitchell, Stefano Ermon, Christopher D. Manning, Chelsea Finn, 2023.

经典 RLHF 先用成对偏好训练 reward model, 再让策略在 reward 与 reference policy 的 KL 约束之间优化. DPO 观察到, 这个 KL 正则 RL 问题的最优策略具有闭式形式. 反过来, reward 也能写成最优策略与 reference policy 的 log-ratio. 把这个表达代回 Bradley-Terry 偏好模型, 同一 prompt 下不可计算的配分函数会在两个回答的 reward difference 中抵消, 最终只剩一个可以用语言模型 log probability 训练的二元交叉熵.

这条推导很漂亮, 但每一步都有条件. 闭式解针对给定 reward 的 KL 正则目标; Bradley-Terry 假设偏好概率只由 reward difference 决定; 离线数据只覆盖被采样和标注过的回答; 实际神经网络也未必能表示理论最优策略. **DPO 把特定 RLHF 目标改写成偏好似然, 并没有让任意离线偏好训练都自动等价于 on-policy RL.**

## 1. 数据, 符号与 shape

DPO 的推导从 KL 正则 reward maximization 开始,但训练数据最终只是离线的 chosen/rejected pair. 要把两端接起来,必须固定 reference policy、completion log-prob 口径和 pair 的数据分布. batch 中有四个 sequence log-prob，它们经由逐 prompt 的 KL 正则最优策略，连接到隐式 reward。Reference 同时限定支持集、提供 log-ratio 坐标系并充当 KL 锚点，训练期间必须保持口径稳定。

### 1.1. 偏好样本与序列概率

一条偏好样本写成 $(x,y_w,y_l)$. $x$ 是 prompt, $y_w$ 是标注者更偏好的 chosen response, $y_l$ 是 rejected response. 数据集由某个收集分布 $q(x,y_w,y_l)$ 产生, 它可能包含人工撰写回答, 也可能来自一个或多个行为策略生成的候选. Reference policy 记为 $\pi_{\mathrm{ref}}(y\mid x)$, 训练策略记为 $\pi_\theta(y\mid x)$. $\pi_{\mathrm{ref}}$ 在 DPO 训练中冻结. 对 autoregressive language model, 一个长度为 $T$ 的回答 $y=(y_1,\ldots,y_T)$ 的 log probability 是
$$
\log\pi_\theta(y\mid x)
=\sum_{t=1}^{T}\log\pi_\theta(y_t\mid x,y_{<t}).
\tag{1}
$$
批量大小为 $B$, chosen 与 rejected token 序列可以 padding 到 $T_w$ 和 $T_l$. 模型输出 logits 的 shape 分别为 $[B,T_w,|\mathcal V|]$ 与 $[B,T_l,|\mathcal V|]$. 按真实 token gather log-softmax, 用 completion mask 去掉 padding 与 prompt, 再沿 token 维求和, 得到四个 $[B]$ 向量:

$$
\ell_{\theta,w},\ \ell_{\theta,l},
\ell_{\mathrm{ref},w},\ \ell_{\mathrm{ref},l}.
$$
式 (1) 是否包含 EOS 必须在 policy 与 reference 中保持一致. Prompt token 不属于 $y$, 不应混入 completion log probability. 即便 chosen 与 rejected 共用相同 prompt, 把 prompt loss 混进实现仍会增加无关数值和 mask 出错机会.

### 1.2. KL 正则 RL 的逐 prompt 问题

先固定一个 prompt $x$, 设 reward 为 $r(x,y)$, 简写成 $r_y$. KL 正则目标为
$$
\max_{\pi(\cdot\mid x)}
\sum_y\pi(y\mid x)r_y
-\beta\sum_y\pi(y\mid x)
\log\frac{\pi(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)},
\tag{2}
$$
约束是

$$
\sum_y\pi(y\mid x)=1,\qquad \pi(y\mid x)\ge0.
\tag{3}
$$
$\beta>0$ 是 KL penalty coefficient. 在式 (2) 中, $\beta$ 越大, 偏离 reference 的代价越大. 若 $\pi_{\mathrm{ref}}(y\mid x)=0$ 而 $\pi(y\mid x)>0$, forward KL 为无穷大, 所以有限目标下的最优策略不会把质量放到 reference 支持集之外. 对 softmax language model, 理论概率通常为正, 但极小概率区域在有限精度和有限样本下仍近似不可达. 对 prompt 分布 $x\sim\mathcal D_x$ 取期望, 就得到常见的 KL 正则 RLHF 目标. 因为归一化约束对每个 $x$ 独立, 闭式解可以逐 prompt 推导.
用拉格朗日乘子求最优策略。 为式 (3) 的归一化加入乘子 $\lambda_x$:
$$
\mathcal J_x(\pi,\lambda_x)
=\sum_y\pi_y r_y
-\beta\sum_y\pi_y\log\frac{\pi_y}{\pi_{\mathrm{ref},y}}
+\lambda_x\left(\sum_y\pi_y-1\right).
\tag{4}
$$
这里 $\pi_y=\pi(y\mid x)$, $\pi_{\mathrm{ref},y}=\pi_{\mathrm{ref}}(y\mid x)$. 对支持集内的 $\pi_y$ 求偏导:

$$
\frac{\partial\mathcal J_x}{\partial\pi_y}
=r_y-\beta\left(
\log\frac{\pi_y}{\pi_{\mathrm{ref},y}}+1
\right)+\lambda_x.
\tag{5}
$$
令式 (5) 为 0:

$$
\log\frac{\pi_y}{\pi_{\mathrm{ref},y}}
=\frac{r_y}{\beta}+\frac{\lambda_x}{\beta}-1.
$$
取指数:

$$
\pi_y
=\pi_{\mathrm{ref},y}
\exp\left(\frac{r_y}{\beta}\right)
\exp\left(\frac{\lambda_x}{\beta}-1\right).
\tag{6}
$$
右侧指数因子由 $x$ 决定，与 $y$ 无关。利用归一化条件，配分函数写为

$$
Z(x)=\sum_y\pi_{\mathrm{ref}}(y\mid x)
\exp\left(\frac{r(x,y)}{\beta}\right).
\tag{7}
$$
最优策略为

$$
\boxed{
\pi_r^*(y\mid x)
=\frac{1}{Z(x)}\pi_{\mathrm{ref}}(y\mid x)
\exp\left(\frac{r(x,y)}{\beta}\right)
}.
\tag{8}
$$
式 (8) 中，较高 reward 通过指数权重放大，reference policy 则给出优化起点与支持集。$\beta$ 控制 reward 改变 reference 分布的强度。这个结果描述式 (2) 在策略空间不受参数化限制时的最优分布，不对应某一次参数梯度更新。

### 1.3. 隐式奖励与配分函数抵消

对式 (8) 取对数:
$$
\log\pi_r^*(y\mid x)
=\log\pi_{\mathrm{ref}}(y\mid x)
+\frac{r(x,y)}{\beta}-\log Z(x).
$$
移项得到

$$
\boxed{
r(x,y)=\beta\log
\frac{\pi_r^*(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}
+\beta\log Z(x)
}.
\tag{9}
$$
Reward 只能由偏好识别到每个 prompt 的加性常数. 给同一 $x$ 的所有回答 reward 都加上 $f(x)$, Bradley-Terry probability 不变, 式 (2) 的最优策略也不变. 式 (9) 中的 $\beta\log Z(x)$ 正是这种只依赖 prompt 的基线. DPO 无需单独求它, 因为成对比较只使用 reward difference. 隐式 reward 可以定义为

$$
r_\theta(x,y)=\beta\log\frac{\pi_\theta(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}.
$$
它只确定到 prompt-dependent constant,而且数值依赖 reference. 同一个 policy 换一份 reference,隐式 reward 就会改变,即使生成结果完全相同. 因此 reference 不只是初始化 checkpoint;它定义了 reward 的零点与相对坐标. $\beta$ 在原 KL 正则目标中表示偏离 reference 的代价. 给定 reward 时,$\beta$ 越大,闭式最优策略越接近 reference. 在 DPO loss 中,$\beta$ 还直接缩放 logit 和局部 gradient,与 learning rate、epoch 和 margin saturation 共同作用. 训练日志里观察到的 policy divergence 不能只由单步梯度的 $\beta$ 系数判断.
从 Bradley-Terry 到可训练的 logsigmoid。 最优策略闭式解仍包含未知 reward 与配分函数. Bradley-Terry 模型只使用同一 prompt 下两个回答的 reward difference,恰好让只依赖 prompt 的配分函数抵消. DPO loss 由此只剩 policy/reference log-ratio 的二元 likelihood. 这个变换没有删除偏好模型假设. 它把 scalar reward 的参数化吸收到 policy log-ratio 中,并要求 chosen 与 rejected 共享 prompt. 梯度大小则由当前模型对 pair 排序错误的程度决定.
Bradley-Terry 代入与配分函数抵消。 Bradley-Terry model 假设同一 prompt 下 chosen 胜过 rejected 的概率为
$$
p^*(y_w\succ y_l\mid x)
=\sigma\left(r(x,y_w)-r(x,y_l)\right),
\tag{10}
$$
其中 $\sigma(z)=1/(1+e^{-z})$. 把式 (9) 分别代入 $y_w$ 与 $y_l$:

$$
\begin{aligned}
r(x,y_w)-r(x,y_l)
={}&\beta\log\frac{\pi_r^*(y_w\mid x)}
{\pi_{\mathrm{ref}}(y_w\mid x)}
-\beta\log\frac{\pi_r^*(y_l\mid x)}
{\pi_{\mathrm{ref}}(y_l\mid x)} \\
&+\beta\log Z(x)-\beta\log Z(x).
\end{aligned}
\tag{11}
$$
两个回答共享 prompt $x$，因此使用同一个 $Z(x)$，相减后该项严格抵消。不同 prompt 各有自己的配分函数，无法使用这一抵消。可训练策略的偏好 logit 定义为

$$
z_\theta(x,y_w,y_l)
=\beta\left[
\log\frac{\pi_\theta(y_w\mid x)}
{\pi_{\mathrm{ref}}(y_w\mid x)}
-\log\frac{\pi_\theta(y_l\mid x)}
{\pi_{\mathrm{ref}}(y_l\mid x)}
\right].
\tag{12}
$$
于是模型对 chosen 胜出的预测为 $\sigma(z_\theta)$. 对数据分布 $q$ 做 maximum likelihood, DPO loss 是

$$
\boxed{
\mathcal L_{\mathrm{DPO}}(\theta)
=-\mathbb E_{(x,y_w,y_l)\sim q}
\left[\log\sigma(z_\theta(x,y_w,y_l))\right]
}.
\tag{13}
$$
式 (13) 不需要显式输出 scalar reward model, 也不需要在每个优化 step 用当前 policy 重新生成回答. Reference forward pass 可以在线计算, 也可以在数据固定时预先缓存四个序列 log probability 中的 reference 两项.

### 1.4. DPO 梯度与数值手算

单样本 loss 为 $\ell(z)=-\log\sigma(z)$. 利用
$$
\frac{d\ell}{dz}=-\sigma(-z),
$$
以及 reference policy 冻结, 有
$$
\nabla_\theta z_\theta
=\beta\left[
\nabla_\theta\log\pi_\theta(y_w\mid x)
-\nabla_\theta\log\pi_\theta(y_l\mid x)
\right].
$$
因此

$$
\boxed{
\nabla_\theta\ell
=-\beta\sigma(-z_\theta)
\left[
\nabla_\theta\log\pi_\theta(y_w\mid x)
-\nabla_\theta\log\pi_\theta(y_l\mid x)
\right]
}.
\tag{14}
$$
$\sigma(-z_\theta)$ 是当前模型给 rejected 排在 chosen 前面的概率. 当 chosen margin 很小或为负时, 权重大; margin 已经很大时, 权重趋近 0. 梯度下降沿 $-\nabla\ell$ 更新, 局部上增大 chosen 相对 reference 的 log-ratio, 减小 rejected 相对 reference 的 log-ratio. 「增大 chosen 概率, 减小 rejected 概率」只能当局部直觉. 两个序列共享大量参数和 token prefix, 一次参数更新会同时改变词表中其他 token 的归一化概率. 式 (14) 严格说明的是两条 sequence log-probability gradient 的对比, 不保证每个样本更新后 chosen 的绝对概率必然上升.

梯度权重 $\sigma(-z)$ 还带来自动聚焦:模型已经给 chosen 很大 margin 时,该 pair 的权重接近零;模型排序错误时,权重接近一. 若标签含错标,一个模型高度确信却与标签冲突的 pair 反而获得很大权重,因此 DPO 对系统性标签错误并不天然鲁棒. 可以用 label smoothing 把硬标签从 $1$ 改成 $1-\varepsilon$,同时给反向次序 $\varepsilon$ 权重,但这已经改变 likelihood 假设. Pair 置信度、标注者一致率或重复标注可以提供更直接的噪声信息;若全部压成相同硬标签,训练端无法区分明确偏好与勉强选择.
数值手算一:最优策略与 reward 反解。 一个 prompt 只有回答 $a,b$. Reference policy 为
$$
\pi_{\mathrm{ref}}(a\mid x)=0.5,
\qquad
\pi_{\mathrm{ref}}(b\mid x)=0.5.
$$
令 reward 为 $r(x,a)=1$, $r(x,b)=0$, 并取 $\beta=1$. 式 (7) 给出

$$
Z(x)=0.5e^1+0.5e^0=\frac{e+1}{2}\approx1.8591.
$$
由式 (8),

$$
\pi_r^*(a\mid x)=\frac{0.5e}{1.8591}
=\frac{e}{e+1}\approx0.7311,
$$
$$
\pi_r^*(b\mid x)=\frac{0.5}{1.8591}
=\frac{1}{e+1}\approx0.2689.
$$
现在用式 (9) 反解. 因为 $\log Z\approx0.6201$,

$$
\log\frac{0.7311}{0.5}+\log Z
\approx0.3799+0.6201=1,
$$
$$
\log\frac{0.2689}{0.5}+\log Z
\approx-0.6201+0.6201=0.
$$
Reward 被准确恢复. 两者相减时 $\log Z$ 消失, reward difference 为 1. Bradley-Terry preference probability 是 $\sigma(1)\approx0.7311$. 在这个两回答例子里, 最优策略概率与偏好概率数值相同, 来自对称 reference 和 $\beta=1$ 的特殊设置, 不是一般规律.

### 1.5. 损失权重的数值复算

设某条偏好样本上
$$
\pi_{\mathrm{ref}}(y_w\mid x)=0.2,
\quad
\pi_{\mathrm{ref}}(y_l\mid x)=0.3,
$$
当前 policy 给出

$$
\pi_\theta(y_w\mid x)=0.3,
\quad
\pi_\theta(y_l\mid x)=0.2,
$$
并取 $\beta=0.1$. 两个 log-ratio 是

$$
\log(0.3/0.2)=\log1.5\approx0.4055,
$$
$$
\log(0.2/0.3)=\log(2/3)\approx-0.4055.
$$
所以

$$
z_\theta=0.1\times(0.4055-(-0.4055))
\approx0.0811.
$$
模型预测 chosen 胜出的概率为 $\sigma(0.0811)\approx0.5203$, 单样本 loss 为

$$
-\log0.5203\approx0.6534.
$$
错误概率权重为 $\sigma(-z)\approx0.4797$. 把 sequence log probability 暂时视作两个独立标量, 则

$$
\frac{\partial\ell}{\partial\log\pi_\theta(y_w\mid x)}
=-0.1\times0.4797=-0.0480,
$$
$$
\frac{\partial\ell}{\partial\log\pi_\theta(y_l\mid x)}
=+0.0480.
$$
梯度下降会扩大 chosen 与 rejected 的相对 margin. 若把 $\beta$ 改大, 在当前 log-ratio 不变时 $z$ 与直接梯度尺度都会改变. 但训练后的 policy 也会随之改变, 所以不能仅凭单步梯度断言较大 $\beta$ 一定产生更强偏离. 在原 KL 正则目标式 (2) 中, 较大 $\beta$ 明确表示更强的 reference 约束; DPO loss 中的优化动态还同时受 learning rate, 数据 margin 和参数化影响.

### 1.6. 长度效应、支持集与可识别性

语言模型的 action 是 token,偏好标签却落在完整回答上.DPO 用 token log-prob 求和得到 sequence log-prob,因此回答长度、EOS 与 mask 直接进入隐式 reward. 这属于目标定义,不能只当作数据预处理. 偏好 pair 只约束被比较回答之间的差. 未出现 completion、reference 极低概率区域和不连通比较图中的不同分量,都缺少直接监督. 可识别性决定模型能从数据中恢复什么,参数共享只负责在约束之外做归纳.
序列聚合与长度效应。 原始 DPO 使用式 (1) 的 sequence log probability sum. 长回答包含更多 token 项, 因而其 log probability 绝对值通常更负. DPO 使用 policy 与 reference 的序列 log-ratio, 两个模型共有的长度趋势可能部分抵消, 但不会自动完全抵消. 如果 policy 相对 reference 在每个 token 上有一个小的平均偏移, 总 log-ratio 会随长度累积. 设每个 completion token 的平均 log-ratio 为 $m(y)$, 则
$$
\log\frac{\pi_\theta(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}
=|y|\,m(y).
\tag{15}
$$
chosen 与 rejected 长度差很大时, 式 (12) 同时比较内容偏好和累积长度效应. 数据收集阶段的长度偏好也会进入标签. 应报告使用的是 token sum 还是 length-normalized score, 以及 EOS 是否计入. 把 sum 擅自改为 mean 会得到另一个目标, 不能继续声称它就是式 (2) 推出的原始 DPO. Padding mask 的错误尤其隐蔽. 如果 rejected 较短, 多出的 padding token 被误计入, loss 会系统性依赖 batch padding. 正确实现应分别对 chosen 和 rejected 的 completion mask 求和, 再构造 $[B]$ 级别的 log-ratio 与 logit. 下面用手算比较长度聚合。

设 chosen 有 2 个 completion token, 每个 token 的 policy-reference log-ratio 都是 $0.10$. Rejected 有 4 个 completion token, 每个 token 的 log-ratio 都是 $0.08$. 用原始 sequence sum:
$$
s_w=2\times0.10=0.20,
\qquad
s_l=4\times0.08=0.32.
$$
虽然 chosen 的逐 token 平均提升更大, 序列 margin 却是

$$
s_w-s_l=0.20-0.32=-0.12.
$$
取 $\beta=1$, DPO 预测 chosen 胜出的概率为 $\sigma(-0.12)\approx0.4700$, loss 约为 $0.7549$. 如果改用 length mean, 两边分数分别是 $0.10$ 和 $0.08$, margin 变成 $0.02$, chosen probability 约为 $0.5050$, loss 约为 $0.6832$. 这两个结果没有谁在数学上自动更正确. Sum 对应式 (1) 中完整序列概率, 能接回式 (8) 的策略分布推导; mean 消除了线性长度累积, 同时改变了隐式 reward 的定义. 选择 mean 时应把它写成目标函数改动, 并重新解释 $\beta$ 的尺度, 不能只把它当作无影响的数值归一化.
Support、可识别性与外推。 式 (8) 的闭式解只在 reference 支持集上成立. 离散例子里, 若 $\pi_{\mathrm{ref}}(c\mid x)=0$, 那么无论 $r(x,c)$ 多高, 乘积 $\pi_{\mathrm{ref}}(c\mid x)\exp(r/\beta)$ 仍为 0. 这是 forward KL 的绝对连续性要求. Language model softmax 在实数算术下通常给所有 token 正概率, 但一个完整长序列的概率可以小到离线采样几乎永远看不到. 理论上的非零支持不等于数据上的有效覆盖.

Preference data 只包含被拿来比较的回答. 对一个从未出现的回答 $y_u$, 式 (13) 没有直接约束它的 log-ratio. 参数共享可能让训练迁移到 $y_u$, 也可能意外提高一个不安全 completion. 这种外推来自 neural network inductive bias, 不是 Bradley-Terry likelihood 给出的保证. 因此 held-out pair 只能测试相似比较上的泛化, 生成评测还要覆盖 policy 当前真的会产生什么.

Reward 可识别性也只到 prompt-dependent constant. 更一般地, 如果观测只有 pair order, 数据直接约束的是各 pair 的 reward difference. 比较图不连通时, 不同连通分量之间的 reward offset 也无法由数据确定. DPO 绕开显式 reward 标定, 但没有创造数据中不存在的跨分量比较信息. Pair 构造应让重要候选之间形成足够连接, 否则某些回答簇只会通过模型参数共享间接耦合.

例如同一 prompt 有回答 $a,b,c,d$,数据只比较 $a\succ b$ 和 $c\succ d$. 第一组 reward 同时加 $10$,第二组保持不变,两个观测概率完全不变;数据无法判断 $a$ 与 $c$ 谁更好. 若再加入 $b\succ c$,比较图连通,四个回答的相对位置才被串起来,但整体加性常数仍不可识别. 在神经网络中,共享 token 与语义表示会让两个分量互相影响,这属于模型归纳偏置,并非 pair likelihood 提供了跨分量证据. 评测时若只抽取训练图内部的边,会高估对新回答簇的排序能力.

有限数据下还可能出现可分问题. 若模型能够把所有训练 pair 的 $z_\theta$ 不断推大, logistic loss 会继续趋近 0, 却没有有限 margin 处的监督信号告诉它停止. Reference log-ratio, 有限容量, 优化设置和额外正则共同限制实际解. 这也是训练 pair accuracy 达到 100% 后仍需观察 held-out loss, 生成质量与 policy-reference divergence 的原因. 训练集上的完美排序只说明已见 pair 被分开, 无法证明未见 prompt 上的回答质量同步改善.

## 2. 离线数据分布、噪声与理论边界

DPO 优化的是离线 pair 分布 $q$,不是当前 policy 的 on-policy 生成分布. 候选由哪个 SFT 或行为策略生成、标注者按什么准则排序、哪些 pair 被丢弃,共同决定可学习区域. 离线复用带来训练便利,也让覆盖偏差持续存在. 增加 epoch 只能继续拟合已见支持集,无法自动发现新 policy 的失败. Bradley-Terry 错设、标签噪声和 reference 变化又会从不同路径进入最终 margin.
离线偏好数据的来源。 式 (13) 的期望来自数据分布 $q$, 不是当前 policy $\pi_\theta$ 的 on-policy 分布. 数据生成策略决定了候选回答的范围与难度. 如果两条回答都来自较弱模型, 数据可能教会 policy 区分明显错误, 却没有覆盖当前强 policy 常见的细微失败. 如果候选来自多个策略而未记录来源, pair 难度, 长度和风格可能与生成器绑定, 模型会学到这些旁路信号.

DPO 通常不对行为策略做 trajectory importance sampling. 它把观察到的 pair 当作监督偏好样本, 最大化它们在 Bradley-Terry 参数化下的 likelihood. 因此同一离线数据可以训练多个 epoch, 这比 on-policy PPO 更便于复用. 代价是重复训练只会继续拟合 $q$ 的支持集, 不会自动发现当前 policy 生成的新失败模式. 数据复用要同时观察训练 pair accuracy, held-out preference likelihood 与实际生成. Pair accuracy 接近饱和以后继续降低训练 loss, 可能只是把已见 margin 推得更大. Reference 固定时, 数据可以缓存 reference log probability; 一旦更换 reference, tokenizer, chat template 或 EOS 处理, 缓存就失效, 因为式 (12) 的比较口径已经变化.

典型流程会先得到一份 SFT policy,用它作为 reference,并用同一模型或相近行为策略生成候选. 这不是数学强制条件:pair 也可以来自人工答案或多个模型. 但行为策略与 reference 越不一致,log-ratio 越可能混入生成器风格和支持集差异,训练时应保存每条候选的来源.

当前 policy 经过多个 epoch 后可能离开候选生成分布. Held-out pair accuracy 仍可继续上升,而新生成回答暴露出数据里没有的失败. 迭代偏好优化会重新采样当前 policy 的回答并补标,其实是在更新离线分布 $q$;它不是同一份静态数据上无限训练的自然结果.

### 2.2. 偏差与噪声从哪些地方进入

**偏好标签噪声**来自标注者分歧, 顺序效应和评价准则不一致. Bradley-Terry 将每个 pair 压成一个标量 reward difference, 无法表示「回答 A 更准确, 回答 B 风格更好」这类多维权衡, 除非数据收集先把准则固定.

**模型设定偏差**来自 Bradley-Terry 假设. 真实偏好可能不满足传递性, 也可能依赖未记录的标注者或上下文. 即使有无限 pair, 错设的 likelihood 也只会收敛到该模型族中最匹配数据的参数, 不等于恢复真实 reward.

**覆盖偏差**来自 $q$. 没被生成, 比较和标注的回答不会直接出现在 loss 中. Neural network 会依靠共享参数向外泛化, 泛化方向不受偏好似然保证. Policy 逐渐离开数据生成策略后, 离线 pair 对当前错误的代表性会下降.

**Reference 偏差**来自 KL 基座. 相同 pair 配上不同 reference, 式 (12) 的 margin 不同. Reference 不是只用于数值稳定的可删常数, 它定义了隐式 reward 的坐标系, 也决定式 (2) 中偏离哪个策略需要付费.

**长度与格式偏差**来自 sequence log probability 聚合和候选构造. 如果 chosen 系统性更长, 模型可能把长度当作偏好线索; 如果两类回答使用不同模板, 特殊 token 也会成为旁路特征. Pair 去重, 长度分桶和同模板重算 log probability 都属于必要的数据检查.

Pair 顺序也可能产生位置偏差. 若标注界面总把某个生成器放在左侧,chosen 标签会与位置或生成器身份相关. 随机交换展示顺序、隐藏模型身份并记录标注者一致性,能够把这些变量从内容偏好中分离出来. 偏差分析不能只看总体比例. 应按 prompt 域、长度差、行为策略、标注者和 margin 分桶,比较训练与验证分布. 某个大桶的高准确率可能掩盖小而关键的安全域完全没有覆盖.
理论等价成立需要哪些条件。 DPO 推导建立了下面这条对应关系:

1. 给定 reward $r$, reference $\pi_{\mathrm{ref}}$ 和 $\beta$, 式 (2) 在完整策略分布空间中的最优解是式 (8).
2. 若 pair preference 严格由该 reward 的 Bradley-Terry model 产生, reward difference 可以用式 (9) 表示.
3. 同一 prompt 的两个回答共享 $Z(x)$, 因而 preference likelihood 可以写成式 (13).
4. 若 policy class 能表示对应最优策略, 数据充分覆盖相关 pair, 优化又能找到 population loss 的合适最优点, 拟合偏好 likelihood 才能恢复这条理论对应中的策略.

真实离线训练会同时放松这些条件. Pair 来自有限且有选择的数据; 标签可能不是单一 reward 的 Bradley-Terry sample; policy 受到 neural network 参数化限制; SGD 只优化有限 batch; reference 与数据生成策略也未必相同. DPO loss 依然清晰, 可微且实用, 但「省掉显式 reward model」不等于 reward 假设消失, 它只是通过 log-ratio 被吸收到 policy 参数化中.

还要区分 policy optimum 与训练路径. 式 (8) 描述的是已知 reward 下的最优分布, 不规定怎样用有限步 SGD 到达它. 式 (13) 拟合 pair likelihood, 也没有在训练过程中显式测量当前 policy 的 forward KL 或真实环境 reward. $\beta$ 源自理论目标, 在实际优化中却与 learning rate, epoch 数, batch composition 和 sequence length 一起决定最终偏移.

**理论等价给出 DPO loss 的来源, 真实训练质量仍由偏好数据, reference, 模型容量和优化过程共同决定.** 这句话比「DPO 等价于 RLHF」更准确, 因为 RLHF 可以使用其他 reward model, 其他 preference likelihood, 不同 KL 方向和 on-policy 探索, 那些设置不在上述推导覆盖范围内.
实现、验证与复现实验。 DPO 实现最常见的风险来自 policy 与 reference 的序列口径不一致。Tokenizer、chat template、prompt mask、EOS 和长度归约任一处不同，都会改变四个 log-prob 与最终 margin。 可复现实验还要固定数据切分、reference checkpoint、$\beta$、pair 权重与缓存版本. 训练 pair accuracy 只能说明已见比较被分开,需要结合 held-out likelihood、生成质量和 policy-reference divergence 判断外推. 任何缓存或模板变化都要显式进入实验版本,这样同一 loss 才能被重新计算和解释.
一次标准 DPO batch。 一次标准 DPO batch 可以按以下顺序计算:

1. 用同一 tokenizer 与 chat template 构造 chosen, rejected 序列, 分离 prompt mask 与 completion mask.
2. Policy 对两个序列前向, 按式 (1) 求 completion token log probability sum.
3. Reference 在无梯度模式下计算同口径的两个 sum, 或读取由完全相同配置生成的缓存.
4. 分别算 chosen 与 rejected 的 policy-reference log-ratio, 按式 (12) 得到 $z\in\mathbb R^B$.
5. 使用 `-logsigmoid(z)` 得到逐样本 loss, 再按明确的 pair 权重聚合.
6. 同时记录 chosen reward proxy, rejected reward proxy, margin, pair accuracy, 序列长度和 held-out loss, 不用单个训练 accuracy 代替生成评测.
可复算的不变量。 调试时可以检查三个不变量. 当 $\pi_\theta=\pi_{\mathrm{ref}}$ 时, 所有 $z=0$, 单样本 loss 为 $\log2$. 交换 chosen 与 rejected 后, $z$ 应精确变号. 给同一 prompt 下所有隐式 reward 加相同常数, preference probability 应保持不变. 这三项分别检查 reference 差分, pair 顺序与配分函数抵消是否实现正确. 还可以构造一个 policy 与 reference 完全相同的两样本 batch,手算梯度符号. Chosen 的 sequence log-prob 梯度系数应为负,rejected 应为正;梯度下降随后扩大 chosen margin. 若交换标签后系数没有同时变号,通常是 pair 拼接、mask 或 logsigmoid 符号写反. Reference cache 要带 checkpoint、tokenizer、template、最大长度和 EOS 口径的版本指纹. 任一项改变都应整体失效重算,否则训练 loss 仍能下降,但四个 log-prob 已经不在同一概率空间中.
开源实现与配置映射。 - [Hugging Face TRL](https://github.com/huggingface/trl) 提供 `DPOTrainer`.
- [verl](https://github.com/volcengine/verl) 覆盖大模型后训练工作流.
- [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory) 提供多种偏好优化训练配置.

这些实现的默认 chat template, loss variant, 长度归一化, label smoothing 和 reference 处理可能不同. 使用前应先把配置映射回式 (1), 式 (12) 与式 (13), 确认训练的究竟是不是这里推导的原始 DPO 目标.
拼接、packing 与 pair 权重。 第 5.1 节已经定义了 shift 与 response mask，这里只补充 batch 组织。Chosen 与 rejected 可沿 batch 维拼接成一次前传，输出序列分数后再按原顺序切开。若使用 sequence packing 节省 padding，后一条样本不能看到前一条 completion；position id、causal mask 与 loss mask 要在样本边界同步重置。仅重置 loss mask 虽然不会给跨界 token 直接加损失，注意力上下文仍然泄漏，四项 log-prob 已不再对应原始独立样本。 下面手算三条样本的加权结果。 令 $\beta=0.2$, 三条样本的未缩放 gap
$$
h=s_w-s_l=(-1,0,2),\qquad z=\beta h=(-0.2,0,0.4).
$$
逐样本 loss 约为
$$
-\log\sigma(z)=(0.7981,0.6931,0.5130),
$$
错误概率权重 $\sigma(-z)$ 约为 $(0.5498,0.5,0.4013)$. 第一条排序错误, 因而权重最大; 第三条已有正 margin, 仍有非零更新. 等权均值约为 $0.6681$. 现在假设三条 pair 分别来自同一 candidate group, 该 group 总共枚举了 3 条边, 而另一个 prompt 只贡献 1 条边. 若逐 pair 等权, 候选多的 prompt 获得更大权重. 可以令每个 group 的 pair 权重和为 1. 对当前三条边各给 $1/3$, 另一个 prompt 的单边给 1, 再按 group 数求平均. 这会改变估计目标: 前者估计「随机 pair」上的风险, 后者更接近「随机 prompt/group」上的风险. 二者都可以使用, 但采样与报告必须讲明白. 若 pair 有置信度 $c_i$, 加权损失写成
$$
\mathcal L=\frac{\sum_i c_i\,[-\log\sigma(z_i)]}{\sum_i c_i}.
$$
分母应使用有效权重之和, 而不是固定 batch size. 分布式训练中还要跨 rank 汇总分子与分母; 若每张卡先做局部均值再等权平均, 有效 pair 数不同的 rank 会获得相同影响. 这里的权重定义会直接改变经验风险。若一个 prompt 有 8 个候选并枚举 28 条边，另一个 prompt 只有 1 条边，逐 pair 平均会让前者占据绝大多数梯度；先做 group 内均值，则两个 prompt 各占一半。前者回答「随机抽一条观测边时模型表现怎样」，后者回答「随机抽一个 prompt 时表现怎样」。它们并非单纯的工程归约差异。数据加载器若对大 group 采样更多边，loss 端又做 group 归一化，两次加权还可能互相抵消或重复修正，因此采样概率与 loss 权重需要放在一起核算。
标签噪声、估计偏差与方差。 对固定 pair, 设真实选择概率为 $q=P(y_w\succ y_l\mid x)$. 若重复标注得到 $n$ 次独立 Bernoulli 结果, 经验胜率 $\hat q$ 的条件方差为 $q(1-q)/n$. 当 $q=0.5$ 时方差最大; 当偏好明确时更小. 现实中的标注者共享 rubric、训练材料和界面偏差, 并不独立, 所以这个公式通常低估真实不确定性, 但它说明了「难例需要更多票」的基本原因.

硬 DPO 把观察到的 winner 当成概率 1. 如果同一 pair 重复出现, 正反标签的总体 likelihood 会自然拟合经验胜率. 如果数据管线在冲突时只保留多数票, 就把 $6:4$ 与 $10:0$ 都变成同一个硬标签, 同时丢掉样本量与分歧. 可以保存所有投票, 或使用软交叉熵
$$
\ell_q(z)=-q\log\sigma(z)-(1-q)\log\sigma(-z),
\qquad \frac{\partial\ell_q}{\partial z}=\sigma(z)-q.
$$
当模型预测概率等于 $q$ 时梯度为零, 不再要求 margin 无界增大. 但软标签只处理观测分歧, 不能修复候选覆盖偏差或 Bradley-Terry 错设. 离线 DPO 的估计误差可粗分为三类. **有限样本方差**来自 prompt、候选和标注抽样, 可通过更多独立 group、合理分层与重复标注降低. **目标错设偏差**来自把多维、非传递或依赖标注者的偏好压进单一 Bradley-Terry logit, 数据再多也不会消失. **分布偏差**来自训练分布 $q$ 与部署时 $x\sim p_{deploy},y\sim\pi_\theta$ 不同; 在旧 pair 上降低经验风险并不保证新生成回答更好.

还有一种容易忽略的 optimizer-induced bias. 为了控制显存, 实现可能截断长回答、按长度分桶或丢弃 chosen/rejected 任一方超长的 pair. 于是实际训练分布是「通过预处理过滤后的 $q$」. 若 rejected 更常冗长并被截掉, 剩余数据的偏好比例会改变. 应报告每一步过滤前后的样本数、chosen/rejected 长度分布和任务分布, 不能只给最终 pair 数.
多 epoch 复用到底增加了什么。 同一离线 pair 做十个 epoch, 不会获得十次独立的人类判断. 它只让优化器更充分地拟合同一经验目标. 早期 epoch 往往修正明显错序; 后期 epoch 主要扩大已见 pair 的 margin. 因为 $-\log\sigma(z)$ 在有限 $z$ 处仍持续下降, 若数据近似可分, 参数范数和 policy-reference divergence 可能继续增长, 即使 pair accuracy 已经不变.

因此 checkpoint 选择应至少联合观察:

- 训练与 held-out 的 preference log loss, 不只看 accuracy;
- 按 prompt group 去重后的验证集, 防止同一候选泄漏;
- 当前策略生成回答的盲评胜率与长度分布;
- 隐式 reward margin、reference KL 的估计量与通用能力回归;
- 对错标、tie、长短反事实 pair 的稳健性.

Reference KL 在 DPO 训练中没有像 PPO 那样被逐样本显式加入 loss 后直接报告. 可以在固定 prompt 上从当前 policy 采样, 计算 sampled log-ratio 的均值来估计 forward KL; 也可在每个 token 对全词表计算条件 KL 后沿生成轨迹汇总. 两者口径不同, 都要说明采样策略与长度归约. 只看训练 loss 无法推出实际 KL 大小.

## 3. Reference、缓存与迭代训练

Reference log-prob 可以缓存, 因为固定数据上的 $y_w,y_l$ 不变. 缓存项至少要绑定 `sample_id`, chosen/rejected 身份, checkpoint hash, tokenizer 文件, chat template, truncation 策略, 最大长度, EOS 与 sequence aggregation. 如果只按原始文本做 key, 模板中 system message 或 special token 改动后仍可能命中旧值. 使用参数高效微调时, 有些框架通过临时关闭 adapter 得到 reference 输出. 这只有在 base 权重确实冻结、reference 就定义为无 adapter 的 base model 时才等价于独立 reference. 若 base 也更新, 或多个 adapter 共享可训练模块, 「关闭 adapter」得到的 reference 会随训练漂移, 式 (12) 的坐标系不再固定.

迭代 DPO 常按「训练策略—重新生成候选—重新标注—再训练」循环. 新一轮可以继续用最初 reference, 也可以把上一轮策略设为新 reference; 两者不是同一目标. 固定 reference 让各轮 log-ratio 有共同锚点, 但当前策略可能离它越来越远. 刷新 reference 会把每轮更新限制在新锚点附近, 却让不同轮的隐式 reward 与 $\beta$ 不再能直接比较. 更换 reference 后所有缓存必须重算.

假设第一轮 reference 对 chosen/rejected 的 log-prob 为 $(-4,-5)$, 当前 policy 为 $(-3.5,-5.2)$, gap $h=1.7$. 如果第二轮把当前 policy 变成 reference, 新策略初始也复制它, 那么训练开始时四项相减后 $h=0$, loss 回到 $\log2$. 第一轮学到的生成行为仍保留在新 reference 中; 归零的是相对坐标, 新 loss 从此只度量策略偏离新锚点的距离.
DPO 实验的结论边界。 ### 3.2. DPO 梯度的几何与饱和

DPO 的单 pair loss 是一个 logistic 分类损失，但 logit 由 policy 与 reference 的序列 log-ratio 差构成。理解这个标量怎样变成参数梯度，才能判断难例、错标和长度对更新的影响。
Margin 与自适应权重。 定义隐式 margin
$$
z=\beta\left[
\log\frac{\pi_\theta(y_w\mid x)}{\pi_{ref}(y_w\mid x)}
-\log\frac{\pi_\theta(y_l\mid x)}{\pi_{ref}(y_l\mid x)}
\right].
$$
loss 为 $-\log\sigma(z)$，对 $z$ 的导数为 $\sigma(z)-1=-\sigma(-z)$。参数梯度因此是

$$
\nabla_\theta\ell=
-\beta\sigma(-z)
[\nabla\log\pi_\theta(y_w\mid x)
-\nabla\log\pi_\theta(y_l\mid x)].
$$
当模型已给 winner 很大 margin，$z\gg0$，权重 $\sigma(-z)$ 接近零；模型偏向 loser 时，权重接近一。DPO 自动把更多梯度给当前错排 pair，但高置信错标也获得最大权重。
饱和不等于 Pair 已学好。 loss 饱和只说明相对 reference 的序列 log-ratio margin 足够大，不说明 winner 绝对概率高。policy 可以同时降低 winner 和 loser 概率，只要 loser 降得更多，margin 仍提高。这是纯 pairwise 目标的可识别边界。 SFT loss、NLL 正则或 chosen-only 项能约束 winner 绝对似然，同时改变标准 DPO 目标。监控 chosen 与 rejected 的 policy log-prob 各自变化，比只看 accuracy 和 margin 更容易发现两者共同下降。
Beta 的两重角色。 从 KL 正则 RL 推导看，$\beta$ 是 KL 温度；在 DPO loss 中，它又缩放分类 logit 与梯度。增大 $\beta$ 会让相同 raw margin 更快进入饱和，同时未饱和区域梯度前系数也变大，效果并非简单“更保守”。 reference、初始化、学习率与数据 margin 分布共同决定最终策略距离。只凭 $\beta$ 不能预测 KL。应报告 policy-reference KL、winner/loser log-ratio 和 margin 分位数，才能解释不同配方。
Hessian 与局部曲率。 对标量 margin 的二阶导为
$$
\frac{\partial^2\ell}{\partial z^2}
=\sigma(z)\sigma(-z).
$$
它在 $z=0$ 最大，绝对 margin 大时趋近零。决策边界附近 pair 提供最大 logistic 曲率；高置信正确和高置信错误样本的标量曲率都低，但错误样本一阶梯度仍大。 神经参数 Hessian 还包含 log-prob 的二阶项，不等于简单 outer product。Adam 等一阶方法不显式利用 Hessian，batch 中 near-tie pair 仍会影响损失局部条件数与学习率稳定性。
Reference Policy 到底约束了什么。 reference 不参与反向传播，却进入每个 pair 的 margin。它定义隐式 reward 的零点与策略变化的比较基准。
Reference Ratio 的抵消结构。 DPO 比较
$$
[\log\pi_\theta(y_w)-\log\pi_\theta(y_l)]
-[\log\pi_{ref}(y_w)-\log\pi_{ref}(y_l)].
$$
reference 对两个回答的相对偏好被从 policy 相对偏好中扣除。如果 reference 已强烈偏好 winner，policy 需要在此基础上进一步提高才得到正 margin；reference 错误偏好 loser，DPO 会要求 policy 克服这个先验。 提示相关常数在 winner/loser 差中抵消，因此 reference 的绝对 sequence normalization 不重要，条件相对概率重要。tokenizer、template 和截断必须一致，否则比较的不是同一回答空间。
Reference-free 并非没有先验。 去掉 reference 项后，loss 直接比较 policy 的 winner 与 loser log-prob。此时初始模型、参数化和数据本身仍提供先验，只是没有显式 KL 正则对应的闭式推导。长序列概率天然更低，长度与内容效应更直接混合。 若 policy 从 SFT 初始化并只做小步，初始策略在早期近似充当隐式 reference；多 epoch 后这种局部解释逐渐失效。reference-free 配方应以实证目标描述，不能直接沿用标准 DPO 的 KL-regularized RL 等价。
Reference Cache 的一致性。 reference 固定时可预计算 chosen/rejected log-prob。缓存必须绑定 reference checkpoint、tokenizer、template、最大长度、截断侧、EOS 规则和 loss mask。任何一项变化都使旧值失效。 padding 不影响有效 token log-prob sum；packing 若改变 position ids、attention mask 或跨样本可见性，缓存与在线计算会不一致。抽样重算并比较到逐 token 误差，是上线缓存前的基本验收。
Iterative DPO 的移动锚点。 迭代 DPO 生成新候选、收集偏好并继续训练。若每轮把上一 policy 设为新 reference，每一步只约束局部变化，累计 policy 可远离最初 SFT。若始终固定初始 reference，后期 margin 更难提高，但总漂移更受约束。 可以同时使用 rolling reference 训练、initial reference 监控，或在 loss 中加入两种 KL。多锚点改变理论目标，应明确权重。每轮数据来自不同 policy，还要绑定生成版本，防止把分布变化误作模型学习。

## 4. 长度、截断与序列概率

DPO 以完整回答 log-prob 和为基本单位。序列长度、EOS、模板与截断不仅是数据处理细节，会直接改变 margin。
Sum 与 Mean Log-prob。 标准推导使用
$$
\log\pi(y\mid x)=\sum_{t=1}^{T}
\log\pi(y_t\mid x,y_{<t}).
$$
改用 token mean 等于比较每 token 平均负对数似然，不再是同一个 sequence probability。mean 能减弱长度尺度，却改变偏好模型与 KL-RL 推导。 若 winner 普遍更长，sum log-prob 更负，但 DPO 使用 policy-reference 差，reference 会抵消部分共同长度效应。policy 与 reference 的 per-token 改善仍可随长度累积。需要按长度差分层观察 margin，而不是假设 reference 已完全消除偏差。

### 4.2. EOS 是序列概率的一部分

自然结束回答的概率包含 EOS。若 loss mask 排除 EOS，模型只学习内容 token 相对概率，不直接学习在哪里停止。chosen/rejected 长度差大时，这会改变目标。 最大长度截断没有真实 EOS，不能补造结束 token。截断回答可能缺少结论，偏好标签也受影响；数据应记录终止原因，并决定是否保留这类 pair。chosen 被截断、rejected 自然结束的比较尤其难解释。
Prompt 与 Response 边界。 prompt token 不属于回答概率，completion-only mask 应从第一个 assistant 生成 token 开始。多轮对话中，历史 assistant turn 是给定上下文还是待优化动作，取决于数据构造；chosen/rejected 必须共享完全相同的 prompt prefix。 若 pair 的 system prompt、工具返回或历史消息不同，差值混合了上下文变化与回答偏好。除非目标明确比较整条轨迹，否则应拒绝或重新对齐。字符串看似相同也要检查模板渲染后的 token ids。
截断造成的选择偏差。 固定最大长度会更常截断长回答。若数据预处理丢弃截断 pair，训练集偏向短样本；若保留，模型学习对不完整文本的偏好。按长度桶报告保留率和 winner 比例能看到这种偏差。 合理策略包括提高上限、按任务设长度、仅保留两边都完整的 pair，或把截断作为明确结果交给标注者。每种选择改变数据分布，不能只用“防 OOM”概括。
噪声偏好与稳健 DPO。 标准 DPO 假设 winner 标签正确。真实标注含随机错误、群体分歧与不可判定 pair，高置信错标会给出持续大梯度。
对称标签噪声。 设真实偏好以概率 $1-\eta$ 被正确记录，以 $\eta$ 翻转。观测 winner probability 为
$$
P_{obs}=(1-\eta)\sigma(z)+
\eta[1-\sigma(z)].
$$
$\eta$ 接近 $0.5$ 时标签几乎无信息。若已知或估计噪声率，可直接使用这个观测模型；普通 DPO 相当于假设 $\eta=0$，会试图无限增大矛盾 pair 的 margin。
Label Smoothing 与保守 Margin。 把 hard target 1 改为 $1-\epsilon$，同时给反向标签 $epsilon$，最优有限 logit 为 $\log[(1-\epsilon)/\epsilon]$。这阻止模型对每个 pair 追求无限置信，能缓和错标影响。 统一 smoothing 假设所有 pair 噪声相同。若有投票比例、标注置信或任务难度，可使用样本级软标签。置信度本身可能有偏，需要在重复标注集上校准。
冲突 Pair 与循环偏好。 同一 prompt 出现 A>B、B>C、C>A 时，标量隐式 reward 无法全部满足。DPO 会按 pair 权重折中，loss 不会归零。去重时若简单保留多数关系，会丢失分歧；保留全部则需要接受不可约 loss。 构建偏好图并检查强连通循环，可区分数据错误与真实非传递偏好。事实正确性等维度适合仲裁修正，风格权衡可能需要多维或条件化偏好模型。
异常 Pair 的梯度审计。 按 loss、margin、梯度范数排序检查样本，高 loss pair 可能是有价值难例、错标、模板错误或截断。直接丢弃所有高 loss 会清除模型当前不会的知识，形成自确认。 结合标注一致性、规则验证、长度、来源和重复 pair 判断。对可疑样本复标，对明确数据 bug 修复，对真实难例保留并适当控制权重。审计结果应回到数据生成流程，而非每轮手工黑名单。
离线数据分布决定学到什么。 DPO 不与环境在线交互，训练信号完全由已有 prompt、chosen 和 rejected 决定。优化稳定、loss 下降与数据分布外表现是三件不同的事。
Prompt 分布就是任务权重。 训练目标可写成
$$
\mathbb E_{x\sim q(x),(y_w,y_l)\sim q(\cdot\mid x)}
[\ell_{DPO}].
$$
$q(x)$ 由数据收集、过滤、去重和采样器共同决定。某领域 prompt 出现十倍，其偏好梯度也近似获得十倍权重。按 token batching 还会让长度改变实际采样频率。 若知道部署分布 $p(x)$，可用 $p/q$ 重加权；权重差异大时方差上升，且 $q=0$ 的任务无法恢复。更实际的方法是分层构建数据、设置显式任务权重，并在部署切片独立评估。
Pair 选择改变决策边界。 同一 prompt 可从 $K$ 个候选构造许多 pair。只取最好与最差，margin 大、标签稳定，却缺少相邻质量边界；取相邻排序，信号细、噪声高。枚举全部 pair 让该 prompt 权重平方增长。 每 prompt 固定 pair 数并按用途混合更可控。若不同 prompt 的候选数不同，先在 prompt 内平均 pair loss，再跨 prompt 平均，可保持 prompt 等权；直接全 pair mean 会重权候选多的 prompt。
Behavior Policy 与数据可识别性。 候选由行为策略 $\mu$ 生成，数据只覆盖其支持。DPO 能把 winner 相对 loser 的概率差推大，却无法知道未生成答案的质量。SFT 或强模型生成分布决定探索边界。 不同生成策略混合时，pair 难度和风格来源变化。保存候选的行为 log-prob 与版本，可分析数据覆盖；标准 DPO loss 不使用行为概率做校正，因此训练目标仍按收集分布加权。
多 Epoch 复用与记忆。 离线数据允许无限 epoch，经验 loss 会持续下降，模型可能记住 prompt 与具体措辞。validation 若随机按 pair 切分，同 prompt 或近重复回答跨集合，过拟合不易显现。 按 prompt、来源、时间和语义簇切分更严格。监控 train/holdout margin、chosen/rejected 绝对 log-prob 与生成评估；loss 下降而 holdout 停滞时，继续 epoch 只增加记忆和漂移。

## 5. 隐式 Reward 能告诉我们什么

DPO 定义隐式 reward
$$
r_\theta(x,y)=
\beta\log\frac{\pi_\theta(y\mid x)}
{\pi_{ref}(y\mid x)}+c(x).
$$
$c(x)$ 不可识别，pair 差可以计算。这个量适合诊断 policy 相对 reference 的重加权，不等于独立训练的真实 reward model。
Reward Difference 与 Margin。 chosen/rejected 隐式 reward 差就是 DPO logit $z$。按任务、长度和来源画分布，可以看到模型在哪些 pair 上提高 margin。训练 accuracy 高但 margin 只在少数模板上增大，说明改善集中。 隐式 reward 会随 policy 参数更新，同一个回答的分数不是固定环境属性。用它比较不同 checkpoint 时必须使用同一 reference 和 $\beta$；更换 reference 后绝对差值口径改变。

### 5.2. 隐式 Reward 的不可转移性

对训练 pair，隐式 reward 排序由 DPO 直接优化；对新回答，它反映 policy/reference log-ratio，可能受流畅性、长度和 SFT 先验影响。不能将其当作独立 judge 验收同一个 policy，否则评价与训练目标同源。 独立人评、规则验证或外部 RM 才能提供否证。隐式 reward 可用于定位“policy 在哪里变化”，外部评价用于判断“变化是否更好”。
Common-offset 与绝对概率。 pair loss 对同一 prompt 下 chosen 与 rejected log-prob 同时加相同变化不敏感。神经网络共享参数和概率归一化会约束这种自由度，但不保证 winner 绝对概率上升。 记录 policy chosen NLL、rejected NLL、reference-relative 两项和序列 entropy。若两者都下降但 rejected 降得更快，DPO loss 改善，生成质量可能因常见好回答概率下降而受损。加入 SFT regularizer 是一种干预，需要作为新目标报告。
从隐式 Reward 回看数据。 高 loss pair 是当前隐式 reward 与标签冲突；极高正 margin pair 可能已经饱和。主动数据选择可关注新 prompt 上低 margin、高不确定 pair，而不是重复大量饱和样本。 若模型对明确事实 pair 长期低 margin，可能缺知识或输入截断；对风格 pair 冲突，可能是群体偏好不一致。margin 是排查入口，不能单独给出原因。
优化器、Batch 与数值实现。 DPO 没有 rollout 和 critic，训练图更简单；sequence log-prob、pair 聚合和分布式 reduce 仍有许多静默错误。
Pair Batch 的正确 Reduce。 每个 pair 产生一个 scalar loss。标准 batch mean 为
$$
L=\frac1B\sum_{i=1}^B\ell_i.
$$
chosen/rejected 长度不应自动改变 pair 权重。若先把所有 token loss 混在一起平均，长序列会获得更多权重，且不再等于 DPO sequence margin。 分布式 worker pair 数不同，应 all-reduce loss sum 与 pair count。各 worker 本地 mean 后等权平均会重权小 batch。gradient accumulation 同样按累计 pair 数归一化。
Concatenated Forward 的等价条件。 将 chosen 与 rejected 在 batch 维拼接，只做一次 forward，可减少开销。等价要求两边独立 attention、正确 position ids、各自 completion mask，并在输出后按原 pair id 配对。 packing 多个序列时必须使用 block-diagonal causal mask，禁止跨样本注意。若 chosen 和 rejected 长度排序后重排，pair mapping 不能依赖相邻位置。随机样本逐条 forward 与拼接结果应数值一致。
Logsigmoid 的稳定实现。 直接计算 $-\log\sigma(z)$ 在大负 $z$ 时可能溢出，使用 `-logsigmoid(z)` 或 softplus $\log(1+e^{-z})$。半精度下 sequence log-prob sum 和 margin 建议用更高精度累积。 超长序列 log-prob 很负，但 DPO 只使用差值；先分别半精度求和再相减会损失精度。逐 token 计算 policy-reference 差再高精度求和，通常更稳定，前提是两模型 token 对齐。
Adam、Gradient Clip 与 Beta。 loss 梯度含 $\beta\sigma(-z)$。改变 $\beta$ 同时改变权重分布和整体尺度，Adam 会部分归一化尺度，不能消除饱和边界变化。学习率与 $\beta$ 需联合校准。 global gradient clipping 若频繁触发，会把高 loss 错排 pair 的额外权重压平。记录裁剪前后范数、触发率与样本 margin。per-sample clipping 则直接改变 pair 权重，属于稳健目标修改。
DPO 与其他偏好目标的分界。 许多离线偏好算法共享 chosen/rejected log-prob，却通过 margin、reference 和正则形式表达不同假设。公式相似不代表目标等价。
DPO 与 SFT。 SFT chosen-only loss最大化 $\log\pi(y_w\mid x)$，不使用 rejected。DPO 最大化 policy 相对 reference 的 chosen-rejected差，可能同时降低两者绝对概率。混合 loss
$$
L=L_{DPO}+\lambda L_{SFT}
$$
兼顾相对偏好与 chosen 似然，$\lambda$ 选择新的折中。
DPO 与 IPO。 DPO 使用 logistic loss，错排 pair 梯度趋近常数、正确大 margin 梯度趋零。IPO 类平方目标让 margin 靠近有限目标值，避免无限扩大置信。它对离群 margin 的惩罚和噪声敏感性不同。 二者都可从正则偏好优化角度解释，但假设和有限样本行为不同。比较应看生成质量、policy-reference KL、margin 分布与标签噪声稳健性。
DPO 与 ORPO/SimPO。 ORPO 将 chosen SFT 与 odds-ratio 偏好项结合，通常不需要单独 reference forward。SimPO 使用长度归一化 log-prob 与目标 margin，也改变了 sequence probability 口径。省 reference 计算是工程优势，理论目标相应变化。 不能只用相同 $\beta$ 比较，因为各公式中超参数含义不同。应校准实际 policy KL、chosen/rejected NLL 与训练 compute，在同数据和评估下比较。
DPO 与在线 RLHF。 DPO 利用固定离线 pair，训练稳定、无需 RM/critic/rollout；在线 RLHF 能让当前 policy 探索新回答，用可执行 reward 或更新 RM 评价。离线数据覆盖好时 DPO 高效，policy 需要超出数据支持时在线交互更有信息。 迭代 DPO 通过新 policy 生成候选并回流标注，逐步接近在线闭环，却仍在每轮用离线分类目标。其成本、分布漂移和 reward hacking 风险不会因不用 PPO 自动消失。
