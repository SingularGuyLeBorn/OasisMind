# 策略梯度与优势估计

价值函数回答「从这里继续走,按当前策略平均能拿多少回报」. 如果动作空间很小,还可以逐个比较 $Q(s,a)$,挑一个价值最高的动作. 但在连续控制中,动作是一组实数;在语言生成中,每一步可选的是整张词表. 此时直接参数化随机策略 $\pi_\theta(a\mid s)$,让训练调整动作概率,比枚举所有动作的价值自然得多. 困难也随之出现:策略改变了当前动作,当前动作又改变后续状态和 reward. 环境通常无法微分,目标却依赖整条随机轨迹.

这条路线先用 [策略梯度定理](./1.2.1-策略梯度定理.md)确定梯度应从哪里来,再用 [REINFORCE](./1.2.2-reinforce.md)把它变成可运行的采样算法,最后进入 [Actor-Critic 与 GAE](./1.2.3-actor-critic与gae.md). 三篇文章解决的故障不同:第一篇关心梯度公式是否对应原目标,第二篇关心样本均值是否足够稳定,第三篇关心能否用较少样本、更短等待时间取得有用的更新. 读到 PPO、GRPO 或长程任务里的 advantage 时,也可以沿这条线回查它到底估计了什么.

## 1. 从未知环境中拿到梯度

统一记号:时刻 $t$ 在状态 $s_t$ 采动作 $a_t$,随后环境给出 $r_{t+1}$ 和 $s_{t+1}$. 对一条长度为 $T$ 的 episode,若目标是从初始状态出发的折扣回报,可写为 $J(\theta)=\mathbb E[\sum_{t=0}^{T-1}\gamma^t r_{t+1}]$. 这里 $0<\gamma\leq1$,期望同时覆盖策略采样和环境随机性. 轨迹概率由初始分布、每一步的策略概率和环境转移概率连乘而成;只有策略项含 $\theta$. 对数求导把连乘变成 score 之和,环境项的导数消失. 这不要求知道转移概率的数值,但要求环境动力学本身不随 $\theta$ 改变.

令 $G_t=\sum_{k=t}^{T-1}\gamma^{k-t}r_{k+1}$ 表示从动作 $a_t$ 之后开始的相对时刻回报. 在上述固定起点目标下,梯度可写成

$$
\nabla_\theta J=\mathbb E\left[\sum_{t=0}^{T-1}\gamma^t\nabla_\theta\log\pi_\theta(a_t\mid s_t)G_t\right].
$$

score $\nabla_\theta\log\pi_\theta(a_t\mid s_t)$ 指出要怎样移动参数,回报 $G_t$ 决定这次采样给它多大权重. 时刻 $t$ 之前的 reward 已经发生,不会受到 $a_t$ 影响,因此从权重里删去它们;这就是 reward-to-go 的因果性. 式中外侧的 $\gamma^t$ 也有出处:固定初始分布的折扣目标给晚期 reward 较小权重. 某些实现把它吸收到折扣状态访问分布,另一些实现直接用时间步均值作为 surrogate. 外观相近的 loss 不一定在估计同一个 $J$;对照实验先固定目标、采样分布和归约方式.

放到语言生成里,状态可以是题目与已生成前缀,动作是下一个 token. 给定动作后,前缀多了一个 token,直到模型输出结束符或达到长度上限. 若验证器只在整段回答完成后给分,每一步的 score 都会收到由最终分数构造的权重. 梯度公式因而仍能计算,但「能计算」不代表它已经认出关键 token:无关词、推理转折和最终答案可能共享同一个终局分数. 后面的 baseline 与优势估计,都在尝试让这个学习信号更有辨别力.

## 2. 期望正确,一次更新仍可能乱跳

REINFORCE 用当前策略采完整 episode,在结束后从尾部算出每个 $G_t$,然后把 $G_t$ 乘在对应动作的 log-prob 上. 它不需要一个价值网络,也不要求 reward 对参数可微. 代价是早期动作要等很久才能更新,并背负许多后续随机转移. 假设最后一步才给出 $R$,较早的动作都要根据同一个结果调整概率;单条成功轨迹无法告诉我们哪些动作真正促成成功. episode 越长,这种采样噪声和信用分配困难越明显.

一个常用的降噪办法,是从回报中减去仅依赖当前状态的 baseline $b(s_t)$. 给定 $s_t$,动作按策略采样,所以 $\mathbb E_{a_t\sim\pi_\theta}[\nabla_\theta\log\pi_\theta(a_t\mid s_t)b(s_t)]=b(s_t)\nabla_\theta\sum_a\pi_\theta(a\mid s_t)=0$. baseline 没有改变平均更新方向,却有机会减去动作之间共有的回报波动. [REINFORCE 的两动作手算](./1.2.2-reinforce.md)把加入 baseline 前后的样本梯度与概率分布画在一起:一个特定例子里方差恰好降为零,一般随机环境并没有这么幸运.

$V^\pi(s_t)$ 是易于理解的状态 baseline:它给出当前策略从 $s_t$ 出发的平均回报,于是 $G_t-V^\pi(s_t)$ 表示「这一次比该状态的常态好多少」. 它并非所有参数化策略下严格最小化梯度方差的 baseline;最优值还受到 score 范数的权重影响. 学到的 $V_\phi$ 若预测很差,减 baseline 甚至可能增大方差. 因而要分开检查估计器均值、梯度方差和 value error,不能只看 policy loss 更平滑就断言方法更准确. 这些边界在 [REINFORCE](./1.2.2-reinforce.md) 中有逐项证明与数值例.

这里还要区分三个看似接近的量. $Q^\pi(s,a)=\mathbb E[G_t\mid s_t=s,a_t=a]$ 是采取指定动作后的期望回报; $V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a)$ 对当前策略会采取的动作再求平均; $A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$ 才是这个动作相对常态的优势. 一条实际轨迹给出的 $G_t-V^\pi(s_t)$ 只是优势的带噪样本,不等于已知真实 $A^\pi(s_t,a_t)$. 连续动作时把求和换成积分,三者的关系不变. 如果文章把「采样回报」「价值预测」和「真实优势」统统记作 $A_t$,读者便看不出误差究竟从哪一步进入.

## 3. 用预测换更及时的学习信号

若每次都等完整未来,长 episode 和持续任务会让更新周期过长. Actor-Critic 增加一个 critic $V_\phi(s)$,用一步 reward 和下一状态预测构造 TD residual. 令 $d_t=1$ 表示这一步进入真实终态,则 $\delta_t=r_{t+1}+\gamma(1-d_t)V_\phi(s_{t+1})-V_\phi(s_t)$. Actor 仍按策略梯度更新;critic 通过自己的 value loss 校准预测. 奖励由环境或 verifier 给出,critic 只是估计在现有策略下的未来回报,它不负责定义「什么行为算好」.

这一步把估计误差换了位置. 一步 TD 只承受眼前一步的随机结果,因而通常比完整 MC 回报波动小;未来部分却来自 $V_\phi(s_{t+1})$,critic 估错时会引入 bootstrap 偏差. 多步 return 往后看更多真实 reward,减少对末端预测的依赖,同时重新承担更多环境随机性. [GAE](./1.2.3-actor-critic与gae.md)把不同步数的 TD residual 按 $(\gamma\lambda)^k$ 聚合,可递推写为 $\hat A_t=\delta_t+\gamma\lambda(1-d_t)\hat A_{t+1}$. $\lambda=0$ 只看一步;当 $\lambda$ 接近 1,估计器吸收更长的真实未来. 选择 $\lambda$ 是估计器设计,没有一个对所有任务都最好的常数.

终止边界比选一个漂亮的 $\lambda$ 更重要. 真终态之后没有价值,bootstrap 应归零;固定 rollout 长度或时间上限只是采样被截断,环境仍可能继续,末状态还需要价值预测. 把 `truncated` 和 `terminated` 合成一个 `done`,会让 critic 在边界系统性低估未来,再把误差传回 actor. 共享 backbone 时还要分清梯度来源:policy loss 使用固定的 advantage 权重,value loss 更新 critic;让 policy loss 通过 advantage 反向操纵 value 预测,相当于给 actor 留了一条伪造学习信号的路.

还有一处常见混淆发生在样本复用. 上面的 score 公式对「由当前 $\pi_\theta$ 采出的轨迹」取期望. 如果轨迹由旧策略 $\pi_{\mathrm{old}}$ 生成,随后直接把新策略的 log-prob 塞进同一个样本均值,采样分布已经变了. 重要性比率 $\pi_\theta(a\mid s)/\pi_{\mathrm{old}}(a\mid s)$ 可以修正动作分布差异,但比率波动本身可能放大方差;状态访问分布也会随策略改变. PPO 对更新幅度施加限制,正是因为同一批数据不能无限次当作新策略的在线样本. 这一层属于数据复用问题,不能拿「GAE 方差小」来替它背书.

读完这一节后,遇到新算法可以沿四个量辨认它改了什么:轨迹由哪个策略采,奖励何时出现,baseline 从哪来,优势怎样分配到每个动作. REINFORCE 的 MC 回报、Actor-Critic 的 TD、GAE 的多步混合只是三种答案. PPO 又限制同一批旧轨迹被新策略反复更新时的步幅;GRPO 则在同一题的多个回答之间构造相对基线. 名称会继续增加,但只要四个量没有混在一起,就能判断新方法解决的是梯度偏差、采样方差、信用分配,还是旧数据复用的稳定性.
