# 策略梯度与优势估计

已知价值并不等于知道怎样调整一个参数化策略。策略梯度用 likelihood-ratio trick 把“分布依赖参数”的导数改写成可采样期望，[策略梯度定理](./1.2.1-策略梯度定理.md)负责这条数学主线：环境转移为何从导数中消失，reward-to-go 为何成立，状态 baseline 在什么条件下不改变期望。

[REINFORCE](./1.2.2-reinforce.md)把定理变成最朴素的 Monte Carlo 算法。完整轨迹回报容易计算，却把终局随机性广播到所有动作，方差很高。均值 baseline、状态 baseline 和同组样本 baseline 都是在做控制变量；它们能否保持无偏，取决于 baseline 是否依赖当前动作以及样本之间怎样相关。

[Actor-Critic 与 GAE](./1.2.3-actor-critic与gae.md)加入可学习的状态价值。critic 预测当前策略下的未来回报，不负责定义奖励；TD residual 将真实一步奖励与 bootstrap 估计结合，GAE 再用 $\lambda$ 混合多个时间尺度。$\lambda$ 调节偏差与方差，不能替代正确的状态、奖励和终止定义。

三篇文章构成一条因果链：REINFORCE 暴露轨迹回报高方差，critic 用函数逼近换取更及时的 baseline，GAE 在 Monte Carlo 与一步 TD 之间连续插值。新增代价也沿这条线出现：critic 本身会估错，bootstrap 引入偏差，共享骨干还会让 policy loss 与 value loss 争夺同一组参数。
