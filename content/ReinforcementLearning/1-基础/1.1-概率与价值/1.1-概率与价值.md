# 概率、轨迹与价值

一条训练日志里写着「状态、动作、奖励」，看上去已经可以做强化学习了。可如果状态漏掉了决定下一步的历史，或者「结束」其实只是采样器耗尽预算，后面的价值估计从第一行就算错。概率、轨迹和价值这些词不难背，难的是把它们放回同一个实验里：一条回答由谁采出来？奖励属于哪一步？从这个状态继续，未来还有多少机会？这几个问题确定以后，Bellman 递归才有明确对象。[Sutton 与 Barto 的教材](http://incompleteideas.net/book/the-book-2nd.html)也是从交互、回报和状态价值逐步进入动态规划。

本节的两篇叶子分别处理这条链的两端：[概率、轨迹与 MDP](./1.1.1-概率轨迹与mdp.md)回答「样本从哪个分布来」，[Bellman 递归与动态规划](./1.1.2-贝尔曼递归与动态规划.md)回答「已定义的长期回报怎样分解和求解」。下面先把两篇共用的记号与容易混淆的条件接起来。

## 1. 一条轨迹的概率从哪里来

时刻 $t$ 的状态为 $S_t$,策略按 $\pi(a\mid s)$ 选动作 $A_t$,环境随后产生奖励 $R_{t+1}$ 和状态 $S_{t+1}$. 长度为 $T$ 的轨迹 $\tau$ 包含初态和这 $T$ 次转移。若环境满足 Markov 条件,轨迹概率可分解为

$$
p_\pi(\tau)=\rho_0(s_0)\prod_{t=0}^{T-1}\pi(a_t\mid s_t)P(s_{t+1},r_{t+1}\mid s_t,a_t).
$$

这里有三处不同的随机性:初态从 $\rho_0$ 抽取,动作由策略采样,下一状态与奖励来自环境。我们能改策略,不等于能随意改环境。换一个策略后,动作概率直接变了,之后访问到哪些状态也会跟着变。拿旧策略数据评估新策略时,只把新动作概率塞进旧日志,不会自动得到新策略会访问的状态。重要性采样通过概率比修正已观察到的轨迹,但行为策略从未尝试的动作没有可供修正的样本;比率相乘还会随轨迹变长而变得不稳定。

语言生成能把「题目加已生成前缀」视作状态,下一个 token 是动作;若只研究模型内部生成,追加 token 后的前缀转移近乎确定。工具调用不同:浏览器页面、文件内容、接口返回和剩余预算都会改变下一步能做什么。只记录最近一条消息,却忽略网页已经跳转或工具结果被截断,就把两种未来不同的情形压成了同一个状态。模型可以用完整历史、摘要或外部记忆表示状态,但压缩后的表示是否保留了决策所需信息,需要用任务检验,不能凭名字断言它满足 Markov 条件。

## 2. Return 是样本,价值是条件期望

从 $t$ 开始的折扣回报定义为 $G_t=\sum_{k=0}^{T-t-1}\gamma^kR_{t+k+1}$,其中 $0\le\gamma\le1$. $G_t$ 属于一条已经发生的轨迹;同一状态再次出现,后续动作或环境结果变了,回报也可能不同。固定策略后的状态价值 $V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]$ 则对这些未来取平均;动作价值 $Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a]$ 还固定了当前动作。二者满足 $V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a)$. 连续动作时把求和换成积分。

这组定义告诉我们为什么「这次拿了高分」不足以证明某个动作好。它可能碰巧进入有利的随机分支;也可能所在状态本来就容易。优势 $A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$ 才把动作与同状态下策略的平均选择比较。后面的策略梯度、critic、GAE 都会用到这三个对象:前者决定应怎样改变动作概率,后两者试图从有限轨迹里估计尚未看到的未来。价值函数是条件期望,不是保存在环境里的「标准答案」;用神经网络拟合它还会叠加表示和优化误差。

折扣 $\gamma$ 既改变较远奖励在目标里的权重,也影响价值的数值尺度。若每步都拿到 $1$ 且环境永不结束, $\gamma=0.5$ 时价值为 $1+0.5+0.25+\cdots=2$;若同一状态下还可以立即拿 $1.5$ 后结束,继续循环比马上结束多 $0.5$。把 $\gamma$ 改成 $0.1$,循环价值只有 $1/0.9\approx1.11$,动作排序就反过来了。原因是折扣系数改变了优化目标。有限时域还要知道剩余步数:相同物理位置在还剩十步和只剩一步时,可兑现的未来奖励并不相同。

## 3. Bellman 递归拆开什么,又没有替我们解决什么

把 $G_t$ 的第一项提出,得到 $G_t=R_{t+1}+\gamma G_{t+1}$. 对给定状态取条件期望,再按当前策略和环境转移展开,就是

$$
V^\pi(s)=\sum_a\pi(a\mid s)\sum_{s',r}P(s',r\mid s,a)\bigl[r+\gamma V^\pi(s')\bigr].
$$

这个等式把无限或很长的未来收进下一状态的价值,因此小型已知 MDP 可以反复 backup 求解。固定 $\pi$ 时做的是 policy evaluation;把动作平均改成 $\max_a$ 后,求的是最优控制问题。先有明确的状态、转移、奖励和终止边界,才能讨论这些算子是否收敛。一个很小的 Bellman residual 表明模型满足自己写下的递归式,不能单独证明状态表示完整,也不能证明奖励设计符合任务目标。[Bellman 叶子文](./1.1.2-贝尔曼递归与动态规划.md)把精确枚举、value iteration、policy iteration 和采样 TD 放在同一组小 MDP 上比较。

真实训练常拿不到完整 $P(s',r\mid s,a)$. 用一次采样构造 $R_{t+1}+\gamma V_\phi(S_{t+1})$ 是 TD target;它便宜,但下一状态价值由当前 critic 预测。等到 episode 结束再用实际 $G_t$ 是 Monte Carlo target;它不依赖末端预测,却承受更长未来的随机性。两个 target 都可以服务于同一个 $V^\pi$,估计误差与等待成本不同。状态动作覆盖不足时,网络把未见区域填出一个数,那个数来自参数共享与先验,不是数据直接证明的反事实。

## 4. 从样本走回定义,别把三类误差揉成一个数

假设日志里某状态 $s$ 被访问一百次,动作 $a_1$ 有九十九次,$a_2$ 只有一次。用 $N(s,a,s')/N(s,a)$ 可以估计已执行动作的转移概率,但 $a_2$ 的估计会极不稳定;若它一次也没出现,分母就是零,不存在「由这批数据估出的 $a_2$ 转移」。给每个后继状态补一个伪计数可以形成平滑模型,这个先验选择必须和观测计数分开。再用平滑后的模型反复 Bellman backup,数值收敛也只是收敛到这个估计模型的固定点。

第二层是采样误差。同一策略在同一状态执行同一动作,未来仍可能分叉,因此 $Q$ 的估计最好同时展示均值与离散程度。把一条长轨迹里的许多时间步当成彼此独立的样本,置信区间会过窄;任务难度若也随时间变化,还要按任务或 episode 分层看。第三层是表示误差:观察到的 $o_t$ 没包含真正的环境状态时,单个 $V(o_t)$ 只能平均混在一起的未来。增加采样量能缓解前一层的噪声,却不会补回丢失的状态变量。这就是为何先看数据生成方式与状态定义,再比较算法的 loss 曲线。

两种策略的回报也只有在同一初态分布、奖励尺度和时间上限下才方便横比。测试题变了,均值差可能来自题目难度,与策略更新的好坏无关。

终止位也在这里进入公式。任务真正进入吸收终态时,之后的价值为零;采样器因为长度上限停止,环境却可能继续,此时把下一状态价值清零会低估靠近边界的动作。语言模型的 EOS 和最大 token 截断同样要分开。沿一条轨迹追问:它由哪个策略生成,状态包含什么,奖励何时到达,边界是否还可继续,再检查 Bellman backup 使用了哪一种估计。到了后面的策略梯度章节,每个 $V$、$Q$ 和 advantage 都有来处。
