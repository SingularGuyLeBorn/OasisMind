# Bellman 方程: 从回报递归到动态规划

MDP 定义 trajectory distribution，Bellman equation 利用 Markov property 把无限 future return 改写成 one-step reward 加 next-state value，并在相邻时刻之间建立同一个 value object 的 fixed-point relation。Environment model 已知且 state space 可枚举时，可以直接解线性方程或做 dynamic programming；model 未知时，Monte Carlo 与 Temporal Difference 用 sample 估计这些 expectation。 符号约定为 $n=|\mathcal S|$, $m=|\mathcal A|$, $V^\pi\in\mathbb R^n$, $Q^\pi\in\mathbb R^{n\times m}$. Reward 采用 $R(s,a)=\mathbb E[R_{t+1}\mid S_t=s,A_t=a]$, transition 为 $P(s'\mid s,a)$. 若 reward 显式依赖 $s'$, 只需把 $R(s,a)$ 改成 transition 内的 $R(s,a,s')$ 加权和.

## 1. 从 return 到 Bellman expectation

Bellman expectation equation 评估一个固定 policy. 它不选择更优 action, 只把当前 policy 在每个 state 上诱导的 future return 写成 one-step recursion. 推导中最重要的动作是连续两次使用全期望: 先按 policy 对 action 求和, 再按 environment 对 next state 与 reward 求和. 这一节同时保留 state value 与 action value. $V^\pi$ 适合写 matrix fixed point, $Q^\pi$ 则把第一步 action 固定下来, 后续 policy gradient,Actor-Critic 与 control algorithm 都会使用它. Value,Q 与 advantage. Return identity 为
$$
G_t=R_{t+1}+\gamma G_{t+1}.
\tag{1}
$$
固定 policy $\pi$, state value 与 action value 定义为

$$
V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s],
\tag{2}
$$
$$
Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].
\tag{3}
$$
Advantage 是

$$
A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s).
\tag{4}
$$
对固定 state, $V^\pi$ 是 action value 按 policy 的 expectation:

$$
### 1.1. Value、Q 与条件期望

V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a).
\tag{5}
$$
因此

$$
\sum_a\pi(a\mid s)A^\pi(s,a)=0.
$$
这个零均值关系后面会进入 policy gradient baseline 和 TRPO performance difference lemma. Bellman expectation equation 逐步推导. 从式 (2) 代入式 (1):

$$
V^\pi(s)
=\mathbb E_\pi[R_{t+1}+\gamma G_{t+1}\mid S_t=s].
\tag{6}
$$
先对 $A_t$ 使用全期望公式:

$$
V^\pi(s)
=\sum_a\pi(a\mid s)
\mathbb E[R_{t+1}+\gamma G_{t+1}
\mid S_t=s,A_t=a].
\tag{7}
$$
再对 next state $S_{t+1}$ 分层. Markov property 让 future return 在给定 $S_{t+1}=s'$ 后只由 $s'$ 与后续 policy 决定, 所以

$$
\mathbb E_\pi[G_{t+1}\mid S_t=s,A_t=a,S_{t+1}=s']
=V^\pi(s').
$$
代回式 (7):

$$
\boxed{
V^\pi(s)=\sum_a\pi(a\mid s)
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s')\right]
}.
\tag{8}
$$
括号内正是 $Q^\pi(s,a)$:

$$
\boxed{
Q^\pi(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s')
}.
\tag{9}
$$
再用式 (5) 消掉 $V^\pi(s')$:

$$
### 1.2. 奖励时序与下一状态

Q^\pi(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)
\sum_{a'}\pi(a'\mid s')Q^\pi(s',a').
\tag{10}
$$
式 (8)–(10) 是 expectation equation, 因为 action 按固定 policy 求 expectation. 它们做 policy evaluation, 没有在每个 state 选择最优 action. 三层随机性怎样进入式 (8). 式 (8) 外层的 $\pi(a\mid s)$ 来自 policy randomness, 内层的 $P(s'\mid s,a)$ 来自 transition randomness, $V^\pi(s')$ 又是从 next state 开始对所有 future trajectory 的 expectation. 如果 reward 本身在给定 $(s,a,s')$ 后仍随机, 更完整的形式是

$$
V^\pi(s)=\sum_a\pi(a\mid s)
\sum_{s',r}p(s',r\mid s,a)
\left[r+\gamma V^\pi(s')\right].
\tag{11}
$$
把 reward 先求条件期望, 才能得到正文使用的 $R(s,a)$ 形式. 两个公式描述同一个 expectation, 只是 joint kernel 版本保留了 reward distribution. Expected Bellman target 与 sampled target 也要区分. 已知 model 时, 式 (8) 枚举所有 $a,s'$ 得到精确 expectation. 与 environment 交互时只观察一个 $(a_t,r_{t+1},s_{t+1})$, target

$$
Y_t=r_{t+1}+\gamma V(s_{t+1})
$$
是对相应 Bellman quantity 的 sample estimate. 它可能高于或低于 expectation. Stochastic approximation 依靠许多 sample 和合适 update step 逼近 fixed point. Reward 依赖 next state 时怎样写. 有些 environment 的 reward 由到达哪里决定. 例如从同一 $(s,a)$ 出发, 到达 goal 给 $+5$, 滑回原地给 $-1$. 这时可以直接使用 joint kernel 形式式 (11), 也可以先定义

$$
R(s,a,s')=\mathbb E[R_{t+1}\mid s,a,s']
$$
再写

$$
Q^\pi(s,a)
=\sum_{s'}P(s'\mid s,a)
\left[R(s,a,s')+\gamma V^\pi(s')\right].
$$
如果改用 $R(s,a)=\sum_{s'}P(s'\mid s,a)R(s,a,s')$, 则

$$
Q^\pi(s,a)
=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^\pi(s').
$$
两个口径等价, 前提是 expected reward 的 transition average 只做一次. 常见错误是在 transition sum 外写 $R(s,a,s')$, 让 $s'$ 在求和号外成为 free variable; 或者已经算出 $R(s,a)$ 后, 又给 reward 乘一次 transition probability. Reward timing 也要固定. 本文用 $R_{t+1}$ 表示执行 $A_t$ 并进入 $S_{t+1}$ 后收到的 reward. 有些 codebase 将它记为 $r_t$. Index 改名不会改变算法, 但 trajectory tuple,return 和 bootstrap target 必须同步, 否则很容易把 reward 与错误的 state transition 对齐. Tower property 是递归成立的核心. 令 $\mathcal F_t$ 表示时刻 $t$ 已知的信息，回报满足 $G_t=R_{t+1}+\gamma G_{t+1}$。条件期望的 tower property 给出

$$
\mathbb E[G_t\mid\mathcal F_t]
=\mathbb E[R_{t+1}+\gamma
\mathbb E[G_{t+1}\mid\mathcal F_{t+1}]mid\mathcal F_t].
$$
若 $S_t$ 是充分 Markov 状态，内层条件期望可写成 $V^\pi(S_{t+1})$，外层只需对当前状态动作诱导的下一步分布积分。Bellman 递归依赖的是条件充分性，不是时间序列天然拥有的代数性质。 状态遗漏时，$\mathbb E[G_{t+1}\mid\mathcal F_{t+1}]$ 不能缩成只依赖观测 $O_{t+1}$ 的函数。强行拟合 $V(O)$ 得到历史混合平均，写出的观测级 Bellman 方程通常不闭合。加入 belief、循环 hidden state 或必要历史，是为了恢复这个闭合条件。 tower property 还解释多步 backup。对 $n$ 步递归展开：

$$
V^\pi(S_t)=\mathbb E_\pi\left[
\sum_{k=0}^{n-1}\\gamma^kR_{t+k+1}
+\\gamma^nV^\pi(S_{t+n})\mid S_t
\right].
$$
一步、$n$ 步和完整 Monte Carlo 在真实价值下具有同一期望，有限样本方差和近似 bootstrap 偏差不同。若中途发生真终止，尾项消失；时间截断则保留条件价值。 Reward timing 影响下标而非机制. 有的教材把 $R_t$ 定义为进入 $S_t$ 时获得的奖励，有的使用 $R_{t+1}$ 表示从 $(S_t,A_t)$ 转移后的奖励。两种约定都可行，混用会产生一位偏移。应先写联合核 $p(s',r\mid s,a)$，再由它定义期望即时奖励。 若 reward 依赖转移三元组，

$$
r(s,a)=\sum_{s',r}p(s',r\mid s,a)r,
$$
Bellman 方程仍可写成 $r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')$。但当 reward 与 $S'$ 条件相关时，采样方差分析不能把二者当独立随机变量。联合采样 target $R+\gamma V(S')$ 自动保留协方差。 状态奖励 $r(s)$、动作奖励 $r(s,a)$ 和转移奖励 $r(s,a,s')$ 可以相互扩展状态表示，但参数共享与方差不同。将转移奖励提前成状态奖励，往往要把上一动作或上一状态并入当前状态。形式等价不代表学习难度和表示成本等价。

## 2. Linear system,fixed point 与 policy evaluation

固定 policy 后, Bellman expectation operator 是 affine map: reward 提供常数项, transition matrix 传播 next-state value. Finite MDP 因而可以直接解 linear system, 也可以从任意初值反复 backup. 两种方法求的是同一个 fixed point, 差别只在数值计算路径. 这一节先把 action dimension 按 policy average 掉, 得到 $P_\pi$ 与 $r_\pi$; 再证明 operator 是 contraction, 最终对三状态例子既做 linear solve 又做 iterative evaluation. Matrix shape 与逐 state equation 会逐项对齐. Matrix form. 对固定 policy 定义 expected reward vector $r_\pi\in\mathbb R^n$:
$$
r_\pi(s)=\sum_a\pi(a\mid s)R(s,a),
$$
以及 policy-induced transition matrix $P_\pi\in\mathbb R^{n\times n}$:
$$
P_\pi(s,s')=\sum_a\pi(a\mid s)P(s'\mid s,a).
$$
式 (8) 写成
$$
V^\pi=r_\pi+\gamma P_\pi V^\pi.
\tag{12}
$$
移项:

$$
(I-\gamma P_\pi)V^\pi=r_\pi.
$$
在 finite discounted MDP 中, $\gamma<1$ 保证 $I-\gamma P_\pi$ 可逆:

$$
V^\pi=(I-\gamma P_\pi)^{-1}r_\pi.
\tag{13}
$$
显式 inverse 适合小问题与推导, 大 state space 通常通过 iterative update 或 linear solver 求解. 定义 Bellman expectation operator

$$
(\mathcal T^\pi V)(s)=
\sum_a\pi(a\mid s)
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')\right].
$$
它在 sup norm 下是 $\gamma$-contraction:

$$
\|\mathcal T^\pi V-\mathcal T^\pi U\|_\infty
\le\gamma\|V-U\|_\infty.
\tag{14}
$$
原因是 probability weights 非负且和为 1, 加权差的绝对值不会超过最大的 component difference. 所以 fixed point 唯一, 从任意有限 $V_0$ 反复执行 $V_{k+1}=\mathcal T^\pi V_k$ 都收敛到 $V^\pi$. Contraction inequality 展开. 固定 state $s$, 定义 $\Delta=V-U$. Reward 项在两个 operator 中完全相同, 相减后抵消:

$$
\begin{aligned}
&|(\mathcal T^\pi V)(s)-(\mathcal T^\pi U)(s)|\\
={}&\gamma\left|
\sum_a\pi(a\mid s)\sum_{s'}P(s'\mid s,a)\Delta(s')
\right|.
\end{aligned}
$$
使用 triangle inequality:

$$
\le\gamma\sum_a\pi(a\mid s)
\sum_{s'}P(s'\mid s,a)|\Delta(s')|.
$$
每个 $|\Delta(s')|\le\|V-U\|_\infty$, 而 action probability 与 transition probability 的加权和为 1, 所以

$$
|(\mathcal T^\pi V)(s)-(\mathcal T^\pi U)(s)|
\le\gamma\|V-U\|_\infty.
$$
再对 $s$ 取 maximum 就得到式 (14). 这个证明同时解释了 reward 为什么不影响 contraction coefficient: 比较同一 MDP 上的两个 value input 时, reward 在 operator difference 中消失. $\gamma$ 决定误差从 next state 传回当前 state 时最多保留多少. 由 contraction 可直接得到 iteration error bound:

$$
\|V_k-V^\pi\|_\infty
\le\\gamma^k\|V_0-V^\pi\|_\infty.
\tag{15}
$$
这是 worst-case upper bound, 实际收敛可以更快. 当 $\gamma$ 接近 1, bound 下降很慢, long-horizon reward 也更容易让 value error 传播很多步. 同一个 MDP 的 policy evaluation. 沿用上一节三状态环境, $\mathcal S=\{A,B,T\}$, $\gamma=0.5$. Policy 为

$$
\pi(\texttt{quit}\mid A)=0.25,
\quad
\pi(\texttt{go}\mid A)=0.75,
$$
$$
\pi(\texttt{cash}\mid B)=0.5,
\quad
\pi(\texttt{loop}\mid B)=0.5.
$$
Terminal value 为 0. 在 $B$ 上使用式 (8):

$$
\begin{aligned}
V^\pi(B)
&=0.5\times4
+0.5\times\left(1+0.5V^\pi(B)\right)\\
&=2.5+0.25V^\pi(B).
\end{aligned}
$$
所以

$$
0.75V^\pi(B)=2.5,
\qquad
V^\pi(B)=\frac{10}{3}\approx3.3333.
\tag{16}
$$
在 $A$ 上:

$$
\begin{aligned}
V^\pi(A)
&=0.25\times1.5
+0.75\times\left(0+0.5V^\pi(B)\right)\\
&=0.375+0.375\times\frac{10}{3}
=1.625.
\end{aligned}
\tag{17}
$$
这与枚举所有可能 loop 次数的 trajectory expectation 相同. Bellman recursion 把 infinite trajectory sum 收进了式 (16) 的 self-reference. 对应 matrix 为

$$
P_\pi=
\begin{bmatrix}
0&0.75&0.25\\
0&0.5&0.5\\
0&0&1
\end{bmatrix},
\qquad
r_\pi=
\begin{bmatrix}
0.375\\2.5\\0
\end{bmatrix}.
$$
$V^\pi=[1.625,10/3,0]^\top$ 代入式 (12) 可以逐行复核. 若直接用 matrix equation, 第二行是

$$
V(B)=2.5+0.5\times0.5V(B),
$$
第一行是

$$
V(A)=0.375+0.5\times0.75V(B)+0.5\times0.25V(T).
$$
这里 $P_\pi[A,B]=0.75$ 表示在 $A$ 按 policy 选择 `go` 后到达 $B$ 的 probability; `quit` 的 $0.25$ probability 进入 $T$. Reward vector 已经对 action 求过 expectation, 所以第一行不能再把 `quit` reward 重复加一次. Linear system 完整手算. 按 state 顺序 $(A,B,T)$, 有

$$
I-\gamma P_\pi
=\begin{bmatrix}
1&-0.375&-0.125\\
0&0.75&-0.25\\
0&0&0.5
\end{bmatrix}.
$$
Linear equation $(I-\gamma P_\pi)V=r_\pi$ 从末行向上解. 第三行给

$$
0.5V(T)=0\quad\Longrightarrow\quad V(T)=0.
$$
第二行给

$$
0.75V(B)-0.25V(T)=2.5
\quad\Longrightarrow\quad
V(B)=\frac{2.5}{0.75}=\frac{10}{3}.
$$
第一行给

$$
V(A)-0.375V(B)-0.125V(T)=0.375,
$$
所以

$$
V(A)=0.375+0.375\times\frac{10}{3}=1.625.
$$
每个 coefficient 都能回到 policy 与 transition. $-0.375=-\gamma P_\pi[A,B]=-0.5\times0.75$; $0.75=1-\gamma P_\pi[B,B]=1-0.5\times0.5$. Matrix solve 没有引入新的 RL 假设, 只是一次性联立所有 Bellman expectation equation. Iterative policy evaluation 逐轮数值. 不做 linear solve, 从 $V_0=(0,0,0)$ 同步更新也会到同一 fixed point. 第一轮:

$$
V_1(B)=2.5+0.25V_0(B)=2.5,
$$
$$
V_1(A)=0.375+0.375V_0(B)=0.375.
$$
第二轮:

$$
V_2(B)=2.5+0.25\times2.5=3.125,
$$
$$
V_2(A)=0.375+0.375\times2.5=1.3125.
$$
第三轮:

$$
V_3(B)=2.5+0.25\times3.125=3.28125,
$$
$$
V_3(A)=0.375+0.375\times3.125=1.546875.
$$
$B$ 的 scalar recursion 为 $V_{k+1}(B)=2.5+0.25V_k(B)$. Fixed point 是 $10/3$, error 每轮精确乘 $0.25$. $A$ 的更新读取上一轮 $B$, 因而慢一拍传播. General contraction bound 使用全局 $\gamma=0.5$, 给出较宽但对所有 MDP 都成立的 upper bound; 这个具体 policy 的有效 self-loop coefficient 更小, 所以实际收敛更快. Inverse 的 Neumann series 解释. 式 (13) 的 inverse 可以展开为

$$
(I-\gamma P_\pi)^{-1}
=I+\gamma P_\pi+\\gamma^2P_\pi^2+\cdots.
$$
因为 stochastic matrix $P_\pi$ 的 spectral radius 不超过 1, $\gamma<1$ 时 series 收敛. 代入 reward vector:

$$
V^\pi
=r_\pi+\gamma P_\pi r_\pi
+\\gamma^2P_\pi^2r_\pi+\cdots.
$$
第一项是当前 state 的 expected one-step reward; 第二项先按 policy transition 一步, 再取 next-state reward; 第 $k$ 项是 $k$ 步后的 expected reward. Matrix inverse 因而不是一个没有 RL 含义的代数技巧, 它把所有 future reward propagation 一次求和. 截断到前 $K$ 项就得到有限次 iterative evaluation 的展开. Tail norm 可由 geometric series 控制:

$$
\left\|\sum_{k=K}^{\infty}
\\gamma^kP_\pi^kr_\pi\right\|_\infty
\le\frac{\\gamma^K}{1-\gamma}\|r_\pi\|_\infty.
$$
这个 bound 使用 $\|P_\pi^k r\|_\infty\le\|r\|_\infty$. 当 $\gamma$ 接近 1, 要让 tail 很小需要更大的 $K$, 与 long effective horizon 的直觉一致. 条件数决定线性求解对误差的敏感度。
矩阵形式 $(I-\gamma P_\pi)V=r_\pi$ 给出了精确解，也暴露数值敏感性。令 $A=I-\gamma P_\pi$，若奖励向量存在扰动 $\Delta r$，解的变化满足
$$
A\Delta V=\Delta r,qquad
\frac{\lVert\Delta V\rVert}{\lVert V\rVert}
\le\kappa(A)
\frac{\lVert\Delta r\rVert}{\lVert r\rVert},
$$
其中 $\kappa(A)=\lVert A\rVert\lVert A^{-1}\rVert$ 是条件数。$\gamma$ 接近一、链存在缓慢混合模式时，$A$ 会接近奇异，奖励或转移的小误差被显著放大。求解器残差很小不等于价值相对误差一定小，还要结合条件数。 直接求逆通常不如解线性方程。显式形成 $A^{-1}$ 增加计算与舍入误差；稀疏 MDP 可以用迭代求解器只调用矩阵—向量乘。预条件器改变谱结构以加快收敛，却不改变原方程的解。比较「动态规划迭代」与「线性求解」时，应按矩阵稀疏度、精度目标和可利用结构计算成本。

转移矩阵的特征值解释收敛速度。$P_\pi$ 的特征值模不超过一，迭代误差满足 $e_{k+1}=\gamma P_\pi e_k$。最坏收缩率是 $\gamma$，具体初始误差若很少投影到慢特征方向，实际可能更快。只报告理论上界会过于悲观，只报告一个初值的快速曲线又可能隐藏慢模式。 加权范数与状态访问分布需要一起确定。
sup norm 给出与状态分布无关的最坏界，却可能由几乎不可达状态主导。实践中的回归 loss 常按采样分布 $\mu(s)$ 加权：
$$
\lVert f\rVert_\mu^2=\sum_s\mu(s)f(s)^2.
$$
Bellman 算子在该范数下不一定是收缩，尤其当 backup 把误差从低权重状态搬到高权重状态。On-policy 平稳分布、折扣占用与 replay 分布给出不同几何，训练 loss 相同并不代表控制性能相同。 若训练分布对目标占用有覆盖，$d^\pi(s)\le C\mu(s)$，则目标分布误差可以由训练误差乘 $C$ 控制。$C$ 很大时，平均回归误差几乎没有决策保证；某个在 replay 中罕见却位于最优路径上的状态，能支配最终性能。

优先级 replay 按 TD error 增加高残差样本概率，改变的正是这个加权范数。若用重要性权重完全校正，可以恢复原采样目标但增加方差；不完全校正则有意优化另一个加权投影。优先级不是纯粹的数据加载技巧，它参与定义近似固定点。 Krylov solver 只需要矩阵—向量乘。
求解 $(I-\gamma P_\pi)V=r$ 时，状态数大到无法存储稠密矩阵，但可以计算 $P_\pi v$，便可使用 Krylov 子空间方法。第 $k$ 轮在
$$
\mathcal K_k(A,r)=\operatorname{span}{r,Ar,A^2r,\ldots,A^{k-1}r}
$$
中寻找近似解。每个基向量对应更深一层的转移传播，与 Neumann series 的多步解释相呼应。 共轭梯度要求矩阵对称正定，而一般 $I-\gamma P_\pi$ 不对称，不能直接套用；GMRES 等方法适用于一般线性系统。把 normal equation $A^\top Ax=A^\top r$ 后再用共轭梯度，会把条件数平方，可能恶化数值精度。 预条件器 $M^{-1}$ 让 $M^{-1}A$ 的谱更集中。Jacobi 预条件只用对角项，便宜但忽略状态耦合；基于局部子图或多尺度状态聚合的预条件能捕捉慢传播结构，构造成本更高。预条件改变迭代路径，不改变精确固定点。

迭代求解停止时应同时看线性 residual $r-AV$ 与控制所需误差。条件数很大时，小 residual 仍可能对应较大解误差；另一方面，解误差若只集中在目标策略不访问的状态，对当前 $J(\pi)$ 影响可能很小。数值线性代数指标与决策分布指标应共同报告。 Fundamental matrix 统计访问次数。
折扣 fundamental matrix
$$
Z_\pi=(I-\gamma P_\pi)^{-1}
=\sum_{t=0}^{\infty}\\gamma^tP_\pi^t
$$
的元素 $Z_{ij}$ 表示从状态 $i$ 出发，对状态 $j$ 的期望折扣访问次数。价值 $V=Zr$ 因而是每个状态奖励按未来访问次数加权。 奖励对价值的导数直接为

$$
\frac{\partial V(i)}{\partial r(j)}=Z_{ij}.
$$
某状态奖励的微小误差影响哪些起点，由可达性和访问频率决定。全局 reward scale 只给粗上界，fundamental matrix 能定位具体传播路径。 转移参数的灵敏度也可由隐函数求导。若 $P=P(\xi)$，

$$
\frac{\partial V}{\partial\xi}
=Z\left(\frac{\partial r}{\partial\xi}
+\gamma\frac{\partial P}{\partial\xi}V\right).
$$
括号内是局部模型变化，左乘 $Z$ 把它传播到所有前驱。这个公式用于模型校准、环境参数优化和影响分析，也清楚展示两次 horizon 放大的来源。 Successor representation 拆分动力学与奖励。
若奖励可写成特征线性形式 $r(s)=\phi(s)^\top w$，固定策略价值为
$$
V^\pi(s)=\mathbb E_\pi\left[
\sum_{t=0}^{\infty}\\gamma^t\phi(S_t)\mid S_0=s
\right]^\top w.
$$
定义 successor feature

$$
\psi^\pi(s)=\mathbb E_\pi\left[
\sum_{t=0}^{\infty}\\gamma^t\phi(S_t)\mid S_0=s
\right],
$$
便有 $V^\pi(s)=\psi^\pi(s)^\top w$。$\psi$ 编码策略与动力学造成的未来访问，$w$ 编码奖励偏好。环境和策略不变、奖励权重改变时，可以复用 successor feature 快速评估新任务。 $\psi$ 自身满足向量 Bellman 方程

$$
\psi^\pi(s)=\phi(s)+\gamma
\mathbb E_{S'\sim P_\pi}[\psi^\pi(S')].
$$
successor representation 把标量奖励替换为特征向量，每个特征维度传播其折扣访问次数。特征若无法线性表示新奖励，复用会产生表示误差；策略改变后，旧 $\psi^\pi$ 也不再对应新占用。 generalized policy improvement 同时保存多个旧策略的 successor feature，对新奖励计算各自 $Q$，再逐状态选择最高动作。即使没有重新训练完整模型，也能组合已有技能。保证依赖价值近似误差与新任务奖励确实位于共享特征空间。 语言模型中，可以把正确性、长度、格式和工具成本视为奖励特征，但这些特征可能依赖整条序列，不是当前状态的简单向量。把 history 或自动机状态扩入 MDP 后仍可使用相同思想，代价是 successor 表示需要覆盖更大状态。

### 2.1. Bellman optimality 与 policy improvement

Policy evaluation 回答「给定 $\pi$ 会得到多少 return」, optimality 则问「所有可选 policy 中哪一个最好」. 在 finite discounted MDP 中, one-step action 后的 future 可以再次按 optimal value 计算, 因而 global control problem 仍能写成 recursive equation. 从 expectation 到 max 不是一个排版替换. Operator,data requirement 与 error propagation 都随之改变. 本节先定义 optimal value, 再证明对 exact $Q^\pi$ 做 greedy improvement 不会降低任何 state 的 value. Bellman optimality equation. Optimal state value 定义为
$$
### 2.2. 最优 Bellman 算子

V^*(s)=\max_\pi V^\pi(s).
\tag{18}
$$
在 finite discounted MDP 中, 存在 deterministic stationary optimal policy. 若 next-state optimal value 已知, 当前 state 选择让 one-step return 最大的 action:

$$
\boxed{
V^*(s)=\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^*(s')\right]
}.
\tag{19}
$$
Optimal action value 为

$$
\boxed{
Q^*(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)
\max_{a'}Q^*(s',a')
}.
\tag{20}
$$
式 (19) 的 `max` 替换了式 (8) 中按 $\pi$ 的 action expectation. 这一步改变了 operator: $\mathcal T^\pi$ 评估固定 policy, $\mathcal T^*$ 寻找 optimal fixed point, 因而任务从 policy evaluation 转向 control. 是否属于 off-policy 还取决于采样行为: 当 data 由 behavior policy 生成、target 却按 greedy policy 的 action max 计算时, 才是 off-policy control, Q-learning 就是典型例子. 如果样本始终来自当前 target policy, 仅看到 `max` 还不能推出离策略. Optimal Bellman operator 同样是 $\gamma$-contraction:

$$
(\mathcal T^*V)(s)=\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')\right].
$$
利用 $|\max_a f_a-\max_a g_a|\le\max_a|f_a-g_a|$, 可得

$$
\|\mathcal T^*V-\mathcal T^*U\|_\infty
\le\gamma\|V-U\|_\infty.
\tag{21}
$$
因此 $V^*$ 是唯一 fixed point. Policy improvement theorem. 为什么对 $Q^\pi$ greedy 会得到不差于 $\pi$ 的 policy? 定义

$$
\pi'(s)\in\arg\max_aQ^\pi(s,a).
$$
由 maximum 不小于 policy average:

$$
Q^\pi(s,\pi'(s))
=\max_aQ^\pi(s,a)
\ge\sum_a\pi(a\mid s)Q^\pi(s,a)
=V^\pi(s).
\tag{22}
$$
左侧等于 $(\mathcal T^{\pi'}V^\pi)(s)$. 因而

$$
V^\pi\le\mathcal T^{\pi'}V^\pi.
$$
继续应用 monotone operator $\mathcal T^{\pi'}$:

$$
### 2.3. 策略改进与近似误差

V^\pi
\le\mathcal T^{\pi'}V^\pi
\le(\mathcal T^{\pi'})^2V^\pi
\le\cdots.
$$
右侧收敛到 $\mathcal T^{\pi'}$ 的 unique fixed point $V^{\pi'}$, 所以

$$
V^{\pi'}(s)\ge V^\pi(s),\qquad\forall s.
\tag{23}
$$
若某个状态 $s$ 上 inequality 严格，且从所讨论的起点按 $\pi'$ 有正概率在有限时间到达 $s$，新 policy 在该起点才有严格改进；不可达状态上的严格优势不会改变这个起点的 value。若只讨论逐状态结论，则该状态自身作为起点已经满足可达条件。这条 theorem 支撑 policy iteration, 但依赖 exact $Q^\pi$. 用 noisy critic 做 approximate greedy 时, estimation error 可能选错 action, monotonic improvement 不再自动成立. Action gap 决定 approximate greedy 是否稳. 定义当前 policy value 下最优 action 与次优 action 的 gap:

$$
\Delta_\pi(s)=Q^\pi(s,a_{(1)})-Q^\pi(s,a_{(2)}).
$$
若 approximate critic 满足每个 action 的 absolute error 不超过 $\epsilon$, 两个 action 的 estimated difference 最多被扭曲 $2\epsilon$. 当 $\Delta_\pi(s)>2\epsilon$ 时, greedy ranking 在该 state 不会被这组误差翻转; gap 很小时, 很小 critic error 就能选到另一个 action. 例如 true action values 为 $(2.0,1.9)$, gap 为 $0.1$. 若第一项 estimate 偏低 $0.06$, 第二项偏高 $0.06$, estimates 变成 $(1.94,1.96)$, greedy action 被翻转. Policy improvement theorem 对 true $Q^\pi$ 仍成立, 但实现使用的是 wrong ranking. 这也是为什么只看 critic mean squared error 不够. 相同 MSE 若集中在 large-gap state, policy 可能不受影响; 若集中在 small-gap,high-occupancy state, 很多 action choice 会改变. Control evaluation 应同时观察 action agreement,advantage sign 与 state visitation weight. Stochastic improvement 与 entropy.

Exact greedy improvement 产生 deterministic policy, 在多个 action tie 时任取其一. 有些算法使用 soft improvement, 例如让新 policy 对较大 $Q$ 分配更高 probability, 同时保留 entropy. 这时求解的是加入 entropy regularization 的 objective, 对应 Bellman operator 会出现 log-sum-exp 或 policy entropy 项. Soft operator 仍可以有自己的 contraction 与 fixed point, 但 fixed point 不等于式 (19) 的 unregularized $V^*$. Temperature 趋近 0 时 softmax 才接近 hard max. 将 entropy bonus 加入训练而在论文公式里仍写普通 Bellman optimality, 会把两个 objective 混在一起. 大模型 RL 中 entropy,KL-to-reference 与 reward 经常同时存在. 它们都影响 optimal policy, 作用却不同: entropy 鼓励单个 state 下 action distribution 分散, reference KL 鼓励 policy 接近指定基座, environment reward 定义 task preference. Bellman target 若要容纳这些 regularizer, 必须明确它们按 token,sequence 还是 trajectory 聚合. Approximate value 会带来多大 policy 损失. 设 approximate value $\widetilde V$ 满足
$$
\|\widetilde V-V^*\|_\infty\le\epsilon,
$$
并令 $\widetilde\pi$ 对 $\widetilde V$ 做 one-step greedy. 对任一 state-action, next-state value error 经过 transition expectation 与 discount 后最多为 $\gamma\epsilon$. 比较两个 action 时, 最优 action 可能被低估 $\gamma\epsilon$, 被选 action 可能被高估 $\gamma\epsilon$, 所以 one-step optimality gap 最多为 $2\gamma\epsilon$. 这个局部 gap 在后续执行 $\widetilde\pi$ 时递归传播. Discounted sum 给出经典形式的 performance bound:
$$
\|V^*-V^{\widetilde\pi}\|_\infty
\le\frac{2\gamma}{1-\gamma}\epsilon.
$$
它是 worst-case bound, 不要求每个 state 都真的达到最大误差. 但系数 $1/(1-\gamma)$ 再次说明 long horizon 会放大 value approximation 对 policy 的影响. 只报告 critic loss, 不把它换算到 action gap 或 policy quality, 很难判断误差是否重要. 如果训练 data 只覆盖部分 state, uniform $\epsilon$ 往往无法成立. 可以在 occupancy-weighted distribution 下讨论平均误差, 结论会依赖 policy 访问哪些 state. Offline setting 中 target policy 走出 behavior coverage 后, 这种 weighted guarantee 也可能失效. 最优算子的不可微点来自动作并列。
最优 Bellman 算子含有 $\max_aQ(s,a)$。当唯一最优动作具有正 action gap 时，小价值扰动不会改变 argmax，算子局部表现为对应确定策略的线性 Bellman 算子。两个动作并列时，max 在交界处不可微，小扰动便可能切换贪心动作。

这解释了策略不稳定与价值稳定可以同时出现。两个动作价值只差 $10^{-5}$，价值误差很小，argmax 却在训练批次间反复切换；若两动作后续行为差异大，数据分布也会随之跳动。报告 value loss 时同步查看 action gap 与策略切换率，才能判断误差是否跨越决策边界。 softmax backup
$$
### 2.4. 熵正则与性能差分

V_\alpha(s)=\alpha\log\sum_a\exp(Q(s,a)/\alpha)
$$
把不可微 max 平滑化，其与 max 的差满足 $0\le V_\alpha-\max_aQ_a\le\alpha\log|\mathcal A|$。平滑带来可控偏差，并让多个近优动作获得梯度。动作数很大时，$\log|\mathcal A|$ 仍会影响误差尺度。 Performance difference lemma 连接局部优势与总体改进。
任意两策略 $\pi,\pi'$ 的性能差可以写成
$$
J(\pi')-J(\pi)=\frac{1}{1-\gamma}
\mathbb E_{s\sim d^{\pi'},a\sim\pi'}[A^\pi(s,a)].
$$
若对所有状态都有 $\mathbb E_{a\sim\pi'}A^\pi(s,a)\ge0$，策略改进定理立即成立。实际算法只在旧策略占用 $d^\pi$ 下估计优势，右侧却需要新策略占用 $d^{\pi'}$。二者差距构成局部 surrogate 与真实改进之间的误差。 令 $\epsilon=\max_s|\mathbb E_{a\sim\pi'}A^\pi(s,a)|$，再用新旧策略总变差控制占用差，可以得到「代理收益减去策略移动惩罚」形式的下界。TRPO 的信任域思想来自这里。只提高旧分布上的优势而不限制策略变化，无法保证新分布进入的状态同样有正优势。 这个引理还揭示离线策略选择的困难。数据来自行为策略 $\mu$，若候选策略 $\pi'$ 会访问 $d^\mu$ 几乎没有质量的状态，优势估计没有支持。保守策略改进限制 occupancy 或动作 ratio，牺牲潜在收益以换取可评估性。

多个最优策略会引出 tie-breaking 问题。
最优价值函数唯一，不代表最优策略唯一。若多个动作在状态 $s$ 同时达到 $Q^*(s,a)=V^*(s)$，任意只在这些动作间随机化的策略都最优。实现中的 argmax 通常按索引选择第一个动作，因而引入无关但可复现的 tie-breaking。

数值误差会把理论并列变成微小差异。若下游关心公平性、负载或动作切换成本，应显式定义次级目标，而非依赖浮点顺序。词典序优化先保证主要回报最优，再在最优集合中优化成本；加一个很小的惩罚近似该目标，但惩罚多小才不改变主要最优集合取决于 action gap。 最优集合也影响模仿与蒸馏。教师始终选某个并列动作，学生选择另一个时，action mismatch 很高但 return 不变。用教师动作准确率评价会错误惩罚等价策略；应结合 $Q^*$ gap、环境结果和次级约束。 策略混合的价值具有非线性。
令 $\pi_\lambda=(1-\lambda)\pi_0+\lambda\pi_1$。即时奖励与转移核对 $\lambda$ 线性，但
$$
V^{\pi_\lambda}=(I-\gamma P_{\pi_\lambda})^{-1}r_{\pi_\lambda}
$$
含矩阵逆，因此通常不等于 $(1-\lambda)V^{\pi_0}+\lambda V^{\pi_1}$。每步随机混合策略会产生两策略都没有的交错轨迹，不能用整条 episode 先抛硬币选择一个策略的价值代替。 沿混合方向的导数可由 performance difference 或隐函数求导得到。它依赖当前混合策略的访问分布与动作优势，所以优势会随 $\lambda$ 改变。只在 $\lambda=0$ 处估计一阶改进，无法保证沿整个线段单调。 部署中的流量分配常是 episode 级 A/B，而策略优化中的随机策略是每个状态重新采样动作。二者边缘动作比例可能相同，轨迹相关结构不同。实验说明「混合比例」时必须指出混合发生在用户、episode、状态还是 token 层。 Conservative policy update 可以给出解析下界。
考虑混合更新 $\pi_\alpha=(1-\alpha)\pi+\alpha\pi'$。小 $\alpha$ 限制 occupancy 改变。若旧占用下代理优势
$$
L=\mathbb E_{s\sim d^\pi,a\sim\pi'}[A^\pi(s,a)]
$$
为正，而最大优势绝对值为 $\epsilon$，可推导真实改进至少是线性收益 $\alpha L/(1-\gamma)$ 减去与 $\alpha^2\epsilon$ 及 horizon 有关的分布漂移项。二次项来自策略改变后访问状态变化。 这个结构说明保守步长为何有效：在一阶收益可靠时，足够小的 $\alpha$ 可让线性项压过二次误差。优势估计有噪声时，还应为 $L$ 减去置信下界；若下界不为正，不应声称保证改进。 固定混合系数并非总合理。action gap 大且估计确定的状态可更大胆更新，gap 小或数据少的状态应保守。状态依赖步长会改变策略类与分析，但更贴合不确定性分布。 Potential shaping 在特定条件下保持最优动作。
定义塑形奖励
$$
F(s,a,s')=\gamma\Phi(s')-\Phi(s).
$$
一条轨迹上的折扣塑形和为
$$
\sum_{t=0}^{T-1}\\gamma^tF_t
=-\Phi(S_0)+\\gamma^T\Phi(S_T).
$$
无限时域且 $\Phi$ 有界、$\gamma<1$ 时，尾项趋零；给定起点后总回报只减去与动作选择无关的常数。于是

$$
Q_F^\pi(s,a)=Q^pi(s,a)-\Phi(s),
$$
所有动作同时平移，argmax 保持不变。有限 episode 需要处理终点势函数；若不同终点 $\Phi(S_T)$ 不同且尾项未消失，塑形可能改变策略排序。 塑形能够加速价值传播。例如稀疏迷宫只在终点给奖励，以到目标的启发式负距离作势函数，可以让中间转移立即获得方向信号。启发式即使不精确，只要严格采用势差形式，仍保持最优策略；随意给「靠近目标」加正分则未必具备该保证。 状态动作势函数和非平稳势也有推广，但必须相应修改策略提取或把时间并入状态。把任意过程奖励都称为 potential shaping，会误用不变性结论。最直接的检查是把整条折扣和展开，看中间项能否望远镜抵消。

## 3. Value iteration 与 policy iteration

Bellman optimality equation 给出 fixed point, dynamic programming 决定怎样求它. Value iteration 每轮做一次 optimal backup; policy iteration 则在完整 evaluation 与 greedy improvement 之间交替. 两者都假设 model 已知,state-action 可枚举, 只是把计算量放在不同位置. 三状态例子能够把每一轮完整列出. 它还展示一个重要现象: 改善下游 state 后, 上游 action 的优劣才会变化. Policy improvement 需要反复 evaluation, 因为 action 的长期价值取决于后续 policy. Value iteration 手算. Value iteration 直接反复应用 optimal Bellman backup:
$$
### 3.2. Value iteration 的逐轮手算

V_{k+1}(s)=\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V_k(s')\right].
\tag{24}
$$
令 $V_0(A)=V_0(B)=V_0(T)=0$. 第一轮:

$$
V_1(A)=\max(1.5,0+0.5V_0(B))=1.5,
$$
$$
V_1(B)=\max(4,1+0.5V_0(B))=4.
$$
第二轮:

$$
V_2(A)=\max(1.5,0+0.5\times4)=2,
$$
$$
V_2(B)=\max(4,1+0.5\times4)=4.
$$
第三轮仍得到 $(2,4,0)$, 所以这个小环境已经到 fixed point:

$$
V^*(A)=2,\qquad V^*(B)=4,\qquad V^*(T)=0.
$$
Greedy policy 在 $A$ 选 `go`, 在 $B$ 选 `cash`. `loop` 的持续 policy value 是 $1/(1-0.5)=2$, 低于立即 `cash` 的 4. 一般问题不会两轮精确结束. Contraction 给出误差持续按至多 $\gamma$ 缩小的依据, stopping criterion 可以观察 $\|V_{k+1}-V_k\|_\infty$, 再结合所需 value 或 policy 精度设置 threshold. Residual 与 value error. Bellman residual 定义为

$$
\varepsilon_k=\|\mathcal T^*V_k-V_k\|_\infty
=\|V_{k+1}-V_k\|_\infty.
$$
利用 contraction 与 triangle inequality:

$$
\begin{aligned}
\|V_k-V^*\|_\infty
&\le\|V_k-\mathcal T^*V_k\|_\infty
+\|\mathcal T^*V_k-\mathcal T^*V^*\|_\infty\\
&\le\varepsilon_k+\gamma\|V_k-V^*\|_\infty.
\end{aligned}
$$
移项得到

$$
\|V_k-V^*\|_\infty
\le\frac{\varepsilon_k}{1-\gamma}.
\tag{25}
$$
所以同样的 residual 在 $\gamma=0.99$ 时对应更宽的 value-error upper bound. 只报告 iteration 次数而不报告 $\gamma$ 与 stopping criterion, 无法比较两个 value iteration 实验的精度. Policy iteration 手算. Policy iteration 在两个操作之间交替:

1. **Policy evaluation**: 求当前 $\pi_k$ 的 $V^{\pi_k}$.
2. **Policy improvement**: 对每个 state 选择
$$
\pi_{k+1}(s)\in\arg\max_a
\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^{\pi_k}(s')\right].
\tag{26}
$$
取初始 deterministic policy $\pi_0(A)=\texttt{quit}$, $\pi_0(B)=\texttt{loop}$. Evaluation 得到

$$
### 3.3. Policy iteration 与有限时域

V^{\pi_0}(A)=1.5,
\qquad
V^{\pi_0}(B)=1+0.5V^{\pi_0}(B)=2.
$$
第一次 improvement:

$$
Q^{\pi_0}(A,\texttt{quit})=1.5,
\quad
Q^{\pi_0}(A,\texttt{go})=0.5\times2=1,
$$
所以 $A$ 暂时保持 `quit`. 在 $B$,

$$
Q^{\pi_0}(B,\texttt{cash})=4,
\quad
Q^{\pi_0}(B,\texttt{loop})=1+0.5\times2=2,
$$
所以改成 `cash`. 新 policy $\pi_1$ 的 evaluation 是 $V^{\pi_1}(A)=1.5$, $V^{\pi_1}(B)=4$. 第二次 improvement 在 $A$ 比较

$$
Q^{\pi_1}(A,\texttt{quit})=1.5,
\quad
Q^{\pi_1}(A,\texttt{go})=0.5\times4=2,
$$
于是改成 `go`. 得到 $\pi_2(A)=\texttt{go}$, $\pi_2(B)=\texttt{cash}$, 再 improvement 不变, algorithm 结束. 这个例子展示了 policy iteration 为什么可能需要多轮. 第一轮评价中 $B$ 仍由差 policy 控制, 所以从 $A$ 前往 $B$ 看起来不划算. 先改善 $B$ 后重新评价, `go` 的长期价值才显现出来. Policy iteration 在 finite MDP 中每次严格改进都会换到一个更好的 deterministic policy, 而 deterministic stationary policy 的数量有限, 所以 exact 版本会在有限次改进后停止. 这个结论不代表每次 evaluation 便宜. 解 linear system 的代价会随 state 数增长, sparse structure 与 iterative evaluation 在大问题中十分重要. Tie 也需要固定规则. 多个 action 的 $Q$ 完全相同时, improvement 若每轮任意切换 tie action, policy 表面上会变化但 value 不变. 实现可以保留当前 action 或使用 deterministic tie breaking, 让 termination detection 稳定. 两种 iteration 的关系.

Policy iteration 每轮把当前 policy 评估到 fixed point, 再做 greedy improvement. Value iteration 每次只做一次 optimal backup, 可以看作截断 policy evaluation 与 immediate improvement 的组合. 前者 iteration 较少但单轮 evaluation 更贵; 后者单轮便宜, 可能需要更多轮. Modified policy iteration 处于两者之间: 每次 improvement 前只执行有限轮 evaluation. 这说明它们不是彼此无关的算法, 区别在于每次 greedy update 前把当前 value 解到多精确. 二者在这里都要求完整 environment model $P,R$, 并遍历 state-action space. State 数量巨大或 continuous 时, exact table backup 不可行, 需要 sampling 与 function approximation. Monte Carlo 用完整 sample return 估计 value; TD 用 $R_{t+1}+\gamma V(S_{t+1})$ bootstrap; Q-learning 把式 (20) 的 max 放入 sample target. 它们共享 Bellman object, 估计方式和 data distribution 不同. Finite-horizon backward induction. 若 episode 最多剩 $H-t$ 步, value 还依赖 time:
$$
V_t^\pi(s)=\sum_a\pi_t(a\mid s)
\left[R_t(s,a)+\gamma\sum_{s'}P_t(s'\mid s,a)V_{t+1}^\pi(s')\right].
\tag{27}
$$
给定 terminal condition $V_H(s)$，可以从 $t=H-1$ 一直向前算到 0。Optimal recursion 将 action expectation 换成 max，在 time-indexed sequence 上做 backward induction。把剩余时间加入 augmented state 后，也能重新写成 Markov form。 Finite horizon 下, 同一个物理 state 在不同 $t$ 可能选择不同 action. 临近 episode 结束时, 一个需要多步才获得 reward 的 action 可能来不及兑现. 如果数据有 time limit, critic 输入却不含剩余时间, 它会把不同 future opportunity 的 sample 压成同一个 value. Synchronous,asynchronous 与 in-place update.

正文的 value iteration 使用 synchronous update: 先用完整旧 vector $V_k$ 计算所有 state 的 $V_{k+1}$, 再整体替换. In-place update 则在遍历 state 时立刻写回新值, 后面的 state 可能读取同一轮刚更新的结果. 两者的逐轮数值不同, 在适当访问条件下都可收敛到相同 fixed point. 三状态例子若先更新 $B$, 再更新 $A$, 第一轮 in-place update 得到 $V(B)=4$, 随后 $V(A)=\max(1.5,0.5\times4)=2$, 一次 sweep 就达到 optimal value. 若先更新 $A$ 再更新 $B$, 第一轮仍是 $(1.5,4)$. 因此报告 iteration 数时还要说明 update order 与 synchronous/in-place 口径. Prioritized sweeping 进一步优先更新 Bellman residual 大或影响很多 predecessor 的 state. 它不改变 Bellman equation, 只改变计算资源投向哪里. Sparse transition graph 中, 一个 state value 改变后只需通知实际 predecessor, 无需每轮扫描所有 state. Parallel accelerator 更适合 synchronous batch backup, CPU sparse solver 可能偏好 asynchronous update. 算法选择不仅由理论 iteration count 决定, 还取决于 state graph,memory layout 与可并行性. 一轮 backup 的计算量.

Dense tabular transition 中, 计算一个 $(s,a)$ 的 next-state expectation 要遍历 $n$ 个 state, 完整 optimal sweep 大约需要 $O(n^2m)$ 次标量运算. Transition graph 若每个 action 只有 $d$ 个非零 successor, sparse sweep 可降到 $O(nmd)$. 三状态例子里的 transition deterministic, 每个 action 只有一个 successor. Policy iteration 的 exact evaluation 若用通用 dense linear solver, 粗略代价随 $n^3$ 增长; iterative evaluation 每个 sweep 利用 sparse transition, 可以提前停止. 因此「policy iteration 轮数少」不等于 wall-clock 一定更低, 还要算每轮 evaluation 精度与 model sparsity. Memory 也可能成为瓶颈. Dense $P$ 的 shape 是 $[n,m,n]$, state 数大时无法存储. Simulator 能按需 sample next state, 却不能直接提供所有 successor probability, algorithm 就从 exact dynamic programming 进入 sample-based RL. Value iteration 的 stopping threshold 若设得过严, 可能花大量计算改善不会改变 greedy action 的小数位. Action gap 较大时, value 还有一定 error 也能得到正确 policy; gap 很小时则需要更精确 evaluation. 实际 solver 可以同时观察 Bellman residual 与 greedy policy 是否稳定. Stochastic transition 的逐轮手算. 再看一个只有 nonterminal state $U$ 与 terminal $T$ 的环境. 在 $U$ 可选 `stop` 或 `try`. `stop` 以 probability 1 进入 $T$, reward 为 0. `try` 有 $0.6$ probability 进入 $T$ 并得 3, 有 $0.4$ probability 留在 $U$ 并得 $-1$. 取 $\gamma=0.9$. 对任意 value estimate $V_k(U)$,
$$
Q_k(U,\texttt{stop})=0,
$$
$$
\begin{aligned}
Q_k(U,\texttt{try})
&=0.6\times(3+0.9V_k(T))\\
&\quad+0.4\times(-1+0.9V_k(U))\\
&=1.4+0.36V_k(U).
\end{aligned}
$$
Terminal value 为 0. 从 $V_0(U)=0$ 开始做 value iteration:

| $k$ | `stop` | `try` backup | $V_{k+1}(U)$ |
|---:|---:|---:|---:|
| 0 | 0 | 1.400000 | 1.400000 |
| 1 | 0 | 1.904000 | 1.904000 |
| 2 | 0 | 2.085440 | 2.085440 |
| 3 | 0 | 2.150758 | 2.150758 |

V^*(U)=1.4+0.36V^*(U),
$$
所以

$$
V^*(U)=\frac{1.4}{0.64}=2.1875.
$$
该值为正, 因而确实高于 `stop` 的 0, 假设自洽. 这里 reward 与 next state 相关, 计算时必须在每个 transition branch 内先写 $r+\gamma V(s')$, 再按 probability 加权. 如果先把 reward 误写成无条件 3 或 $-1$, fixed point 会变成另一个问题. 从误差看, recursion coefficient 是 $0.36=0.4\times0.9$. 只有失败并留在 $U$ 的 branch 会把 old value 带回当前 state, 所以实际 error 每轮乘 $0.36$, 比 global contraction upper bound $0.9$ 紧得多. 这个例子说明 transition structure 会让局部收敛速度优于只看 $\gamma$ 的 worst-case 判断. 随机 horizon 可以用吸收概率解释。
有限时域通常显式把剩余时间写进状态。另一种构造是在每一步以概率 $1-\gamma$ 终止，以概率 $\gamma$ 继续，并对未折扣奖励求和。若终止事件与环境转移独立，则
$$
\mathbb E\left[\sum_{t=0}^{T-1}R_{t+1}\right]
=\mathbb E\left[\sum_{t=0}^{\infty}\\gamma^tR_{t+1}\right].
$$
折扣回报因此可以解释为几何随机 horizon 下的未折扣回报。这个解释要求每步独立终止；业务会话的真实终止通常依赖状态和动作，不能简单等同于固定 $\gamma$。 状态依赖 survival probability $c(s,a,s')$ 会得到 transition-based discount：

$$
V(s)=\mathbb E[R_{t+1}+c(S_t,A_t,S_{t+1})V(S_{t+1})\mid S_t=s].
$$
只要沿任意长期路径的 continuation product 足够衰减，递归仍可能有唯一解。把所有 $c$ 压成单个 $\gamma$ 会丢掉不同终止风险，尤其在失败吸收和成功吸收概率差异很大的任务中。 Modified policy iteration 构成一条连续谱。
policy iteration 每轮把当前策略评估到收敛，再做一次贪心改进；value iteration 每次只做一步最优 backup。Modified policy iteration 在二者之间：对当前策略做 $m$ 次评估 sweep，再改进策略。$m=1$ 接近 value iteration，$m\to\infty$ 恢复精确 policy iteration。 增加 $m$ 能减少贪心时的评估误差，却使每轮策略改进更贵。早期策略离最优较远时，精确评估一个很差的策略可能浪费计算；后期 action gap 很小时，更精确评估可避免错误切换。动态调整 $m$ 比固定极端方案更符合误差结构。

广义策略迭代把 evaluation 与 improvement 看成两个并行过程。它们不必各自完成才交替：critic 朝当前策略价值移动，actor 同时朝 critic 的贪心策略移动。Actor-Critic 正是这种不完全交替。稳定性取决于两个过程时间尺度；actor 变化过快，critic 追逐移动目标，评估误差会进入改进步骤。

Gauss–Seidel、优先级 sweeping 都依赖更新顺序。
同步 value iteration 用上一轮完整向量计算下一轮。Gauss–Seidel 更新立即使用本轮已经写入的新值。在有向无环任务中，逆拓扑顺序一次 sweep 就能得到精确价值；相反顺序需要多轮传播。循环 MDP 中没有全局拓扑序，更新顺序仍能显著改变有限预算收敛速度。 prioritized sweeping 维护 predecessor 关系，把 Bellman residual 大的状态及其前驱优先入队。它利用「价值变化沿反向转移传播」的结构，避免均匀扫描大量无变化状态。优先级只说明当前模型下可能有大更新，若 transition model 漏掉前驱，关键信号不会进入队列。

异步收敛通常要求每个状态被无限次更新，使用的信息延迟有界，并保留压缩条件。实际分布式系统若热点状态频繁更新、冷门状态长期饥饿，训练 loss 可以下降但全局固定点条件未满足。记录每个状态族或任务桶的更新覆盖，比只看总 backup 数更可靠。 Stopping criterion 可以从 residual 推出 value bound。
value iteration 常在 $\lVert V_{k+1}-V_k\rVert_\infty<\epsilon$ 时停止。相邻迭代差和到固定点的误差不是同一个量。利用压缩性可得
$$
\lVert V_k-V^*\rVert_\infty
\le\frac{\lVert TV_k-V_k\rVert_\infty}{1-\gamma}.
$$
因此 $\gamma=0.99$ 时 residual $10^{-3}$ 只保证 value error 不超过约 $0.1$。目标 action gap 若更小，这个精度仍不足以保证贪心策略正确。 策略损失还会再经过一次放大。若 $\lVert V-V^*\rVert_\infty\le\delta$，对 $V$ 的贪心策略通常可得到与 $\delta/(1-\gamma)$ 同阶的性能界。长 horizon 任务要从策略容忍误差反推 residual 阈值，不能沿用短 horizon 的固定数字。 采样环境无法计算全状态 sup residual，只能估计样本分布下 residual。独立验证状态集、模型可用时的精确 backup，以及针对稀有高风险状态的覆盖测试应当并用。训练 TD loss 达到阈值，只是所采数据上的停止条件。

Finite horizon 策略通常依赖时间。
剩余一步时只关心即时奖励，剩余很多步时可以承担短期代价换长期收益。因此有限 horizon 的最优策略一般写成 $\pi_t(a\mid s)$。若只用平稳策略 $\pi(a\mid s)$，等于限制策略类，可能失去最优性。 把时间 $t$ 或剩余预算 $H-t$ 加入状态，可以把非平稳策略改写成扩展状态上的平稳策略。代价是状态数乘以 horizon，跨时间共享需要函数逼近。语言模型生成中的剩余 token 预算同样影响策略：靠近上限时应收束答案，预算充足时可以继续验证。 backward induction 从终点条件 $V_H(s)$ 开始：
$$
V_t(s)=\max_a\mathbb E[R_{t+1}+V_{t+1}(S_{t+1})\mid s,a].
$$
这里无需折扣也能良定义，因为递归只有有限层。终点价值若代表未完成任务的 salvage value，需要显式给出；一律设零相当于声明 horizon 后所有状态等价。 滚动时域控制每次只规划未来 $H$ 步，执行第一步后重新规划。它能利用新观测，却可能短视：目标收益始终位于窗口外时，策略永远不愿承担准备成本。terminal value approximation 用较长程价值补偿窗口边界，其误差会影响每次重规划。 Anderson acceleration 利用残差历史。
普通 fixed-point iteration 只用当前 $V_k$ 计算 $TV_k$。Anderson acceleration 保存最近若干残差 $F(V_i)=TV_i-V_i$，选择线性组合使组合残差尽量小，再生成下一迭代。对近线性问题，它能近似 Krylov 加速；对非线性最优算子，动作切换会让局部模型改变。

加速不自动保持 Bellman 单调性。线性组合系数可能为负，使价值越过上下界；max 算子的不可微点附近还可能振荡。damping、系数正则和残差回退用于保护稳定性。若加速候选 residual 变差，退回普通 backup 是可检查的安全条件。 多步 lookahead 是另一种加速：对动作树向前展开 $h$ 层，再用当前价值 bootstrap。模型准确时，它把奖励更快传播；分支因子使计算指数增长，近似搜索又引入选择偏差。MCTS 用选择性展开分配预算，得到的是搜索增强策略，不等同于完整 $T^hV$。

Multigrid 处理不同时间尺度。
局部 Bellman backup 很快消除高频误差，跨大区域缓慢变化的低频误差传播较慢。multigrid 把状态聚合到粗尺度，在粗图上快速传播全局修正，再插值回细尺度。这个思想适合网格控制与具有层级结构的状态空间。 粗状态必须近似保留奖励与转移。若把动力学截然不同的状态聚合，粗修正会把错误同时传播到许多细状态。restriction、coarse operator 和 prolongation 的选择决定加速是否保持原固定点。 层级价值与 option 也可看作时间尺度上的粗化：高层 backup 跨越多个底层步。它改善长程传播，但需要正确的持续时间折扣与 option 终止模型。少算几层并不免费，复杂度转移到了抽象构造。 单调上下界可以给出可认证停止。
若已知 $L_0\le V^*\le U_0$，最优 Bellman 算子的单调性保证
$$
T^kL_0\le V^*\le T^kU_0.
$$
奖励有界 $R_{\min}\le r\le R_{\max}$ 时，可以取常数界 $L_0=R_{\min}/(1-\gamma)$ 与 $U_0=R_{\max}/(1-\gamma)$。上下序列间距按压缩率收缩，提供直接 value 误差证书。 若某状态动作的下界已高于其他动作上界，该动作可以被认证为最优，无需等待所有 value 达到统一高精度。action gap 大的状态会较早确定，计算可集中到仍有歧义的状态。启发式搜索中的 admissible heuristic 与区间 value iteration 都利用这种结构。 浮点舍入可能破坏严格上下界。需要 outward rounding 或为数值误差留余量；否则打印出的「认证区间」可能并不包含真实值。采样 backup 也不能直接提供确定界，需结合置信区间，并为同时覆盖多状态动作做概率校正。 区间重叠只表示当前证据不足，不表示动作真实等价。反过来，区间分离依赖模型、奖励界与置信假设正确。认证结论应连同失败概率和覆盖范围报告。

### 3.1. Termination,sampling 与 approximation 边界

前四节的收敛结论建立在 finite state-action,stationary Markov dynamics,exact expectation 与 $\gamma<1$ 上. 实际任务会逐项放松这些条件: observation 可能不是 state, episode 可能被 time limit 截断, model 只能从 sample 学, value 还要由 neural network 近似. 这些变化不意味着 Bellman target 失效, 而是 fixed-point proof 不能原样搬过去. 需要区分目标 equation,sample estimator 与 function approximator 三层: equation 定义想求的对象, estimator 决定 bias/variance, approximator 决定可表示范围与 optimization error. Markov,discount 与 termination. 第一, Bellman fixed point 依赖 Markov state. Observation 丢失 history 时, 用 $V(o)$ 近似 value 可能出现 state aliasing, 同一个 observation 对应不同 hidden state 与 future return. 第二, $\gamma<1$ 的 contraction 是 discounted continuing case 的核心条件. Finite horizon 可以把剩余时间并入 state, 得到 time-dependent value $V_t(s)$ 并从终点 backward induction. Average-reward continuing task 则需要另一套 Bellman equation, 不能直接把 $\gamma$ 设成 1 后沿用全部结论. 第三, Bellman optimality equation 假设 reward 与 transition 已经定义. Reward misspecification 下, 求得的 policy 可能精确优化错误目标. Distribution shift 下, $P_{\mathrm{train}}$ 的 optimal value 也未必对应 deployment environment. Termination 与 truncation 的 bootstrap mask. 设 sample transition 包含 termination flag $d_t$ 与 truncation flag $u_t$. True termination 表示 MDP 进入 terminal, 标准 discounted target 为
$$
Y_t=R_{t+1}+\gamma(1-d_t)V(S_{t+1}).
$$
Time-limit truncation 只表示 collector 不再记录, environment 的 future 仍可能存在. 如果 objective 对应 continuing task, $u_t=1,d_t=0$ 时通常仍应 bootstrap. 把 `done = termination OR truncation` 直接乘成 0, 会系统性低估靠近 time limit 的 value. 另一种定义是把 time limit 本身当作 environment termination. 那么 remaining time 必须进入 state 或 task specification, terminal 后 future value 的确为 0. 两种处理都可成立, 取决于想解哪个 MDP; 错误来自训练 target 与 evaluation task 使用不同定义. Sequence generation 中 EOS 类似 true termination, max-length cutoff 更接近 truncation. 如果超过长度本身应受惩罚, cutoff 可以带 terminal penalty; 如果只是显存限制, critic 可能需要对 unfinished sequence bootstrap. 直接把两者都标成 EOS 会改变 length preference. Sampling,max 与 function approximation.

第四, function approximation, off-policy sampling 与 bootstrap 同时出现时可能不稳定. Tabular contraction proof 不会自动转移到 nonlinear neural network. DQN 使用 target network, replay 与其他稳定化机制, 正是在处理从 exact operator 到 approximate stochastic update 后出现的问题. 第五，action max 会产生 selection bias。用 noisy $Q$ estimate 同时选择和评价最大 action，最大值更容易挑中正噪声。Double Q-learning 一类方法将 action selection 与 evaluation 部分分开，以处理这项 overestimation mechanism。偏差发生在有限 noisy estimate 近似 max expectation 的过程中，Bellman optimality equation 使用真实期望时没有这项采样偏差。 第六, model-based backup 的误差会递归传播. 如果 learned transition model 在某类 state-action pair 上偏差很大, value iteration 可能反复利用这个虚假 transition, 产生 model exploitation. 增加 rollout depth 并不必然更准; horizon 越长, model error 能影响的后继越多. Bellman error 的三种来源. Neural critic 的 total error 可以按概念拆成三类. **Approximation error** 来自 function class 无法表示 true value; **estimation error** 来自 finite sample 与 distribution coverage; **optimization error** 来自 loss 没有被训练到当前 function class 中的最佳点. 增加 gradient step 只能直接减少第三类, 无法补上未访问 state 或缺失 feature. 常见 squared TD loss 为
$$

\left[V_\phi(s)-\left(r+\gamma V_{\bar\phi}(s')\right)\right]^2.
$$
Target parameter $\bar\phi$ 暂时冻结, 让 regression target 在若干 step 内较稳定. 即使 training loss 很小, 也只说明 dataset distribution $\mathcal D$ 上接近 frozen target, 不证明 $V_\phi$ 接近 true $V^\pi$ 或 $V^*$. Off-policy data 还改变 loss weighting. 高频 behavior state 对 gradient 贡献大, target policy 常访问但 behavior 少见的 state 贡献小. Tabular case 可以靠逐 state step-size 与 sufficient visitation 讨论收敛; neural case 中 parameter sharing 让一个 state 的 update 同时改变其他 state, 分析更复杂. Average reward 不是把 $\gamma$ 直接设为 1. Continuing task 若关心长期每步平均 reward, 可以定义

$$
g^\pi=\lim_{T\to\infty}\frac1T
\mathbb E_\pi\left[\sum_{t=0}^{T-1}R_{t+1}\right].
$$
Differential value $h^\pi(s)$ 衡量从 $s$ 出发相对 steady-state average 多获得多少 transient reward. 对应 equation 形如

$$
g^\pi+h^\pi(s)
=\sum_a\pi(a\mid s)
\left[R(s,a)+\sum_{s'}P(s'\mid s,a)h^\pi(s')\right].
$$
$h^\pi$ 只确定到 additive constant, 因为给所有 state 同加常数不会改变 equation. 这与 discounted case 的 unique $V^\pi$ 不同. Average-reward theory 还需要 chain ergodicity 等条件, 不能把正文 contraction proof 中的 $\gamma$ 删除后继续使用. 选择 discounted return 还是 average reward 会改变 policy preference. Discounted objective 更重视靠近当前时刻的 reward, average reward 忽略有限 transient 对无限期平均的影响. 部署 task 若有自然 episode, discounted/episodic 口径通常更直观; 持续控制或资源调度可能更关心 long-run rate. TD(0),n-step 与 Monte Carlo target. 对固定 policy, one-step TD target 是

$$
G_t^{(1)}=R_{t+1}+\gamma V(S_{t+1}).
$$
$n$-step target 展开更多真实 reward:

$$
G_t^{(n)}
=\sum_{k=0}^{n-1}\\gamma^kR_{t+k+1}
+\\gamma^nV(S_{t+n}).
$$
若 episode 在 $n$ 步前 true termination, bootstrap 项为 0, sum 截到 terminal. $n$ 增大时, target 对 current critic 的依赖减少, 对 sampled reward sequence 的依赖增加. 一般表现为 bias 降低而 variance 上升, 具体大小还取决于 reward stochasticity 与 critic error. Monte Carlo target 一直累积到 terminal, 不 bootstrap. Episodic environment 中它直接 sample $G_t$, 对 true $V^\pi$ unbiased 的前提是 trajectory 来自 $\pi$ 且 return 定义一致. Episode 很长或 continuing 时, 等待 terminal 成本高, return variance 也可能很大. $\lambda$-return 将不同 $n$-step target 做 geometric mixture. GAE 在 advantage 侧使用相近结构, 把 TD residual 按 $\gamma\lambda$ 累积. 这些方法没有改变 Bellman expectation object, 只是选择用多少真实 future reward 与多少 bootstrap 来估计它. 实现中必须明确 value target 是否 stop-gradient. 若 target 内的 $V(S_{t+n})$ 与 prediction 同时反向传播, loss 不再是通常的 semi-gradient TD update. Residual-gradient method 有另一套推导, 不能在无说明时混用. Error 应该沿哪条链排查.

当 critic prediction 错误时, 可以沿四层排查. 第一层是 task definition: reward,discount 与 termination 是否表达了想要的 objective. 第二层是 state: observation 是否满足 Markov 条件, remaining time 与 hidden variable 是否缺失. 第三层是 data: behavior coverage,sample correlation 与 importance ratio 是否可接受. 第四层才是 optimization: network capacity,learning rate 与 target update 是否合适. 这条顺序很重要. Reward timing 错一位时, 再大的 network 也只会更精确地拟合错误 target; terminal mask 把 truncation 当结束时, 增加 data 会稳定地产生 biased value; unseen action 没有 coverage 时, 降低 training loss 也无法验证它的 $Q$. 对 tabular toy MDP, 可以把 model enumeration,linear solve,iterative backup 与 Monte Carlo rollout 四个结果互相核对. 它们若不一致, 通常是 reward index,discount,terminal 或 transition probability 中至少一处实现错误. 对 large environment 无法精确求解时, 仍可构造小 state slice 或 deterministic fixture 保留这种交叉检查. Replay distribution 与 Bellman loss weighting.

Replay buffer 改变的是哪些 state-action error 被频繁优化. Uniform replay 对 buffer 中 transition 均匀抽样, 并不等于对 current policy occupancy 均匀, 也不等于对 state space 均匀. Old policy data 占比很大时, critic loss 主要在 old occupancy 上下降. Prioritized replay 按 TD error 提高某些 transition 的采样 probability. 这能更快处理当前 residual 大的样本, 也改变了 objective weighting. 若希望恢复 uniform-buffer expectation, 需要 importance weight 修正 sampling probability; clip 或不完全修正会留下 bias, 换取较低 variance 与更稳定 optimization. Rare state 还会遇到另一层问题: TD error 只有访问后才能计算. 从未进入 buffer 的 catastrophic state 不会因 priority mechanism 自动出现. Exploration,scenario generation 与 offline coverage 属于 data acquisition, replay scheduling 只在已有 data 内重新分配计算. 验证 critic 时应至少分开报告 replay-distribution loss,on-policy rollout error 与 task-level return. 第一项衡量 optimizer 是否拟合训练 target, 第二项衡量 current policy 常见 state, 第三项还包含 policy choice 与 environment feedback. 三者同时改善时证据更完整; 只有 replay loss 下降, 无法推出 control performance 提升. Expected value 看不见 return distribution.

标准 Bellman equation 传播 expected return. 两个 action 可以有相同 $Q$ mean, return risk 却完全不同. 例如 action `stable` 恒得 1, action `risky` 以相同 probability 得 0 或 2. 两者 expected reward 都是 1, risk-neutral Bellman backup 将它们视为 tie; variance 分别是 0 与 1. 如果任务关心 downside risk,tail probability 或安全约束, scalar $V$ 不足以表达目标. 可以增加 cost value 与 constraint, 使用 CVaR 等 risk measure, 或学习完整 return distribution. Distributional RL 传播的是 random return distribution 的 representation, 其 expectation 仍应与普通 value 在口径一致时对应. Risk-sensitive objective 往往不再满足简单的 expectation linearity. 例如 utility $\mathbb E[u(G)]$ 在 nonlinear $u$ 下, 不能只把 $\mathbb E[G]$ 送进 $u$. Bellman recursion 需要把足以计算 future utility 的 state 或 distribution 保留下来. 直接在普通 $V$ 上附加一句「考虑风险」不会产生正确 equation. 大模型后训练也有类似差别. 平均 verifier reward 相同的两个 policy, 一个可能稳定产出中等答案, 另一个偶尔满分,偶尔产生严重违规. 只优化 mean reward 会忽略 tail behavior. Safety evaluation 因而要报告 violation rate 与 severity distribution, 不能只给 average reward. 这一边界不否定 expected Bellman equation. 它精确解的是 risk-neutral discounted expectation. 当产品目标包含风险,约束或多目标权衡时, 应先修改 objective 与 state, 再推对应 operator; 不能要求原 equation 回答它没有编码的问题.

交付前怎样复核一个 Bellman 实现. 先构造只有两三个 state 的 deterministic fixture, 手算每个 action 的 reward,next state 和 discount. 用 model enumeration,matrix solve,iterative evaluation 与大量 Monte Carlo rollout 分别计算同一个 $V^\pi$, 四者应在数值误差范围内一致. 再加入 stochastic branch, 检查 transition probability 是否只乘一次. 随后分别制造 true termination 与 time-limit truncation, 查看 target 中 bootstrap mask 是否符合 task definition. 把 policy action probability改成非均匀值, 检查 $P_\pi$ 与 $r_\pi$ 是否同时更新. 将 value 初值换成正数,负数和随机数, contraction case 应收敛到相同 fixed point. Control 路径还要验证 expectation 与 max 没有混写. 固定 policy evaluation 应按 $\pi$ 对 action 求和, value iteration 才使用 max. 对 tie action 设置 deterministic rule, 对 approximate critic 人为加入可控误差, 检查 action gap 小时是否出现预期的 ranking flip. 再跑 large environment. 记录 Bellman residual,value scale,termination rate,target/prediction distribution 与 greedy action change. 一旦指标异常, 先回到 fixture 定位 reward index,mask,transition 和 update order, 不要直接靠调 learning rate 掩盖定义错误. 这套复核顺序的目标是先证明数学对象与实现对齐, 再讨论 function approximation 的性能. Toy fixture 过不了时, 大规模训练曲线再平滑也不能证明 Bellman update 正确.
定义, 数据与更新必须逐项对应.

**Bellman equation 给出 value 必须满足的递归结构, 不替任何具体 estimator 保证收敛.** 读后续方法时要分别检查 target 来自 expectation 还是 max, data 由哪个 policy 采样, next-state value 是真实值, table estimate 还是 neural critic, 以及更新究竟在做 evaluation 还是 control. Double estimator 在误差相关性较弱时减少 max bias。
设两个动作真实价值都为零，估计为 $\hat Q_a=\epsilon_a$，噪声独立且零均值。虽然每个估计无偏，$\mathbb E[\max_a\hat Q_a]>0$，因为 max 更容易选择正噪声。动作越多、噪声越大，过估计通常越强。 Double Q 的核心是把「选择」与「评价」分给两套误差较弱相关的估计。用估计器 A 选动作
$$
a^*=\arg\max_aQ_A(s',a),
$$
再用 B 评价 $Q_B(s',a^*)$。A 的正噪声会影响选择，但若 B 的噪声独立，它不会因同一次 max 被系统挑高。完全独立是理想条件；共享数据、网络主干或同步 target 会增加误差相关性，降低去偏效果。 Double estimator 不保证无偏，可能产生低估。某个真实最优动作被 A 的负噪声错过，B 会诚实评价一个次优动作。过估计与低估之间的交换取决于 action gap、噪声相关与更新频率。只观察平均 Q 下降不能证明估计更准，应与 Monte Carlo return、策略回报和校准误差对照。 Distributional Bellman operator 保存回报分布。
期望价值把随机回报压成一个均值。Distributional RL 定义随机回报 $Z^\pi(s,a)$，满足分布等式
$$
Z^\pi(s,a)\overset D=
R(s,a,S')+\gamma Z^\pi(S',A'),
$$
其中 $S'\sim P$，$A'\sim\pi$。右侧是随机变量的平移与缩放，不是标量加法。对两边取期望才恢复普通 Bellman expectation equation。 固定策略的 distributional Bellman operator 在某些 Wasserstein 距离下是压缩；加入 control max 后性质更微妙，因为「按期望选择动作」与「比较回报分布」不是同一个序。风险中性控制通常仍按 $\mathbb E[Z]$ 选动作，分布用于改善表示与估计；风险敏感控制则需明确 CVaR、效用函数或随机支配准则。

离散原子或 quantile 近似会引入投影。C51 把平移缩放后的质量投影回固定支持，QR-DQN 用 quantile regression 近似分位点。投影误差与 Bellman 误差交织，均值看似正确时，尾部仍可能严重错位。评估应包含分位数校准与覆盖，而非只看期望回报。
