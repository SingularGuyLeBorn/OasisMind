# GMPO:token 重要性比的几何均值策略优化

论文信息如下：
- **标题**: Geometric-Mean Policy Optimization
- **作者**: Yuzhong Zhao、Yue Liu、Junpeng Liu 等
- **年份**: 2025（arXiv v3）
- **论文**: [arXiv:2507.20673](https://arxiv.org/abs/2507.20673) **前置知识**: GRPO, GSPO

## 1. 动机: 算术平均放大了什么

### 1.1. 单 token 离群权重的来源

GRPO 的 surrogate 对一条 rollout 内的 token 做算术平均: $\frac{1}{|o_i|}\sum_t\rho_{i,t}\hat A_i$. 算术平均对离群值敏感——一个 token 的 $\rho_{i,t}=8$, 其余都是 $1$, 平均立刻被拉到 $3$ 以上, 而这条 rollout 的「平均似然漂移」远没有这么大. 离群从哪来? 和 GSPO (GSPO 文章) 分析的同一源头: policy 更新让某些位置的 log-prob 大幅移动, 路由敏感的架构里集体翻转更常见. 逐 token clip 是 GRPO 的应对, 但 clip 是逐位置独立的硬截断, 截完之后整条链的权重结构仍然由算术平均决定, 离群值的「余波」还在.

一个量化锚点: rollout 内比率分布的「撕裂度」可以用 max/mean 衡量, 正常更新下这个比值在 1.5 到 3 之间, 路由翻转时刻能冲到 10 以上. 算术平均的合成权重随撕裂度线性涨, 几何均值按开方压, 撕裂度 10 时两者差出三倍——稳定性收益全部来自这个区间, 监控撕裂度分布就能预判 GMPO 在自己管线里的收益空间.

撕裂度还有一个近亲指标: 组内 reward 的标准差 (GRPO 优势归一的分母). 两者常一起涨——模型在难题上输出方差大, 路由也更容易翻转. 区分它们的方法: 分别画「高撕裂度低 reward 方差」和「低撕裂度高 reward 方差」的 batch 占比, 前者多说明病灶在优化侧 (GMPO/GSPO 的适用区), 后者多在数据侧 (该调难度筛选).

GMPO 的切入点在聚合函数：先按优势符号对每个 token 的 log-ratio 做裁剪，再把整条回答的 clipped importance-weighted reward 从算术均值改成几何均值。GSPO 对序列 ratio 做一次整体裁剪；GMPO 保留 token 级裁剪，却在裁剪后使用回答级几何聚合。两者会得到相近的未裁剪几何 ratio，裁剪位置与梯度开关不同。

### 1.2. 算术平均的另一个问题: 向量抵消失效

原论文用一个小例子说明算术平均在「向量层面」的麻烦. 设 $T=3$, $\hat A=1$, 三个 token 的比率 $\rho=(1,1,8)$, 梯度向量 $g_1=(1,0)$, $g_2=(0,1)$, $g_3=(-1,0)$. GRPO 的合成梯度是 $\frac{1}{3}[(1,0)+(0,1)+(-8,0)]=(-7/3,\,1/3)$: 第三个 token 的离群权重不仅自己方向占主导, 还把前两个 token 的贡献几乎全部抵消. 一次更新被单个位置绑架.

换成几何均值, 权重变成 $\rho_{geo}=(1\cdot1\cdot8)^{1/3}=2$, 合成梯度是 $\frac{1}{3}[(2,0)+(0,2)+(-2,0)]=(0,\,2/3)$: 离群值被压缩到 $2$, 三个 token 的贡献按接近相等的权重合成, 方向由多数意见决定. 这个例子是机制演示, 不是实测梯度, 但它准确指出了算术平均的失败模式: **权重离群会同时破坏合成的方向和幅度**.

值得补一句: 向量抵消在真实训练里不一定是坏事——两个方向相反的 token 梯度相互抵消, 可能正是「模型在两个候选行为间犹豫」的忠实反映. GMPO 的问题不在抵消本身, 而在**抵消由离群权重主导**: 一个 $\rho=8$ 的 token 强迫其余 token 陪它抵消, 多数意见被绑架. 几何压缩后权重接近, 抵消重新反映多数意见, 这才是它想要的修正.

## 2. 几何均值聚合

### 2.1. 定义与 log space 实现

GMPO 的主项写成
$$
\left(\prod_{t=1}^{|o_i|}|\rho_{i,t}(\theta)\hat A_i|\right)^{1/|o_i|}\operatorname{sgn}(\hat A_i).
$$
忽略裁剪时，同一 rollout 的 $\hat A_i$ 对所有 token 相同，可以拆出来，梯度权重等价于
$$
\rho_{geo}=\left(\prod_t\rho_{i,t}(\theta)\right)^{1/|o_i|},
$$
即序列内 token 重要性比的几何均值，方向由 $\hat A_i$ 的符号恢复。实现上直接算乘积会下溢或上溢，标准做法是在 log space 运算：$\log\rho_{geo}=\frac{1}{|o_i|}\sum_t\log\rho_{i,t}$。未裁剪时它与 GSPO 的长度归一序列 ratio 是同一个表达式。完整 GMPO 会先依据优势符号逐 token 裁剪 log-ratio，再对裁剪结果求均值；最终每条回答仍产生一个几何聚合标量。 这个「表达式相同, 用法不同」的观察值得记住一半: 几何均值和长度归一似然比是同一个数学对象, 争议从来不在它是什么, 在它在哪个粒度上服务什么目标.

从估计理论看, 几何均值对应「对数空间的平均漂移」. 它无偏估计的是 $\mathbb{E}[\log \rho]$——一个和 KL 散度直接相关的量. 这让 GMPO 的修正有清晰的信息论含义: 它按「平均对数似然变化」加权, 和 GSPO 一样是有偏但方差可控的选择, 偏差的结构同样写在 log 空间.

### 2.2. AM-GM 与权重重塑

正数范围内, 算术平均不小于几何均值: $\rho_{geo}\le\frac{1}{T}\sum_t\rho_{i,t}$. 等号当且仅当所有 $\rho_{i,t}$ 相等. 含义: GMPO 的合成权重永远不大于 GRPO 的, 且**比率分布越不均匀, 两者差距越大**——均匀时两者相等, 一个离群时 GMPO 相对 GRPO 压缩得最多. 这正是想要的结构: 对「正常」的 rollout, GMPO 和 GRPO 行为接近; 对「撕裂」的 rollout, GMPO 自动压低合成幅度. 稳定性收益集中在最需要的地方.

注意 AM-GM 比的是标量权重的幅度, 不能直接推出合成梯度范数的关系. 反例: $T=2$, $\rho=(2,1)$, $g_1=(1,0)$, $g_2=(-2,0)$, GRPO 两项恰好抵消 (范数 $0$), GMPO 得 $(-\sqrt2/2,0)$ (范数 $0.707$). 算术抵消反而更小的情形确实存在. 几何均值的优势应落在**避免单点主导合成方向**上; 上一节的 $(-7/3,1/3)$ 例子里, GMPO 的方向明显更可信, 却不能由此宣称梯度范数总会更小.

「更可信」三个字需要落地: 可信与否最终由下游指标裁决, 但至少有一个先验标准——合成方向应该主要由「多数 token 的意见」决定, 而不是由「最极端的 token」决定. 几何均值按乘积计票, 一个离群 token 需要其余所有 token 反向才能扳回, 满足这个标准; 算术平均按加和计票, 一个足够大的离群可以单挑全组, 不满足.

这个「计票」视角还能解释为什么不选更激进的稳健统计量 (中位数, 截尾均值): 中位数完全丢弃幅度信息, 几何均值保留了「每个 token 投多少」的连续权重, 只是按乘票压缩. 在「保留信号」和「压制离群」的谱系上, 算术和几何分别靠两端, 中位数在几何之外, 选择上先动几何, 不够再考虑更激进的方案.
手算: 权重对照。 取图 1 的设定: 组内 reward $r=(0,1,0,1)$, 总体标准差下 $\operatorname{mean}=\operatorname{std}=0.5$, $o_2$ 的优势 $\hat A_2=(1-0.5)/0.5=+1$. $o_2$ 有三个有效 token, 比率 $(0.5,1,8)$. 算术平均: $(0.5+1+8)/3=3.1667$. 几何均值: $(0.5\times1\times8)^{1/3}=4^{1/3}\approx1.5874$. GRPO 的合成权重是 $3.17$, GMPO 是 $1.59$, 压缩近一半, 且压缩量主要来自那个 $8$. 再看 log space 的稳定性: $\log\rho=(-0.693,0,2.079)$, 均值 $0.462$, 指数化回 $1.587$, 与直接开立方一致. 每一步的量级都温和 (最大 $2.08$), 没有乘积形式的 $0.5\times1\times8=4$ 之外的中间量爆炸——其实乘积本身也不大, 但几千 token 时乘积的指数增长会失控, log space 是必须而非风格. padding 不进平均, 有效 token 数大于零, $\hat A=0$ 时主项为零, 这三条和 GRPO 的约定一致.

再补一个数值细节: 几何均值对接近零的比率格外敏感——$\rho=10^{-6}$ 的 token 把乘积拉低六个数量级, 开方后仍有 $10^{-6/T}$ 的痕迹. 实现里通常给 $\log\rho$ 设下限 (例如 $-20$), 防的是极端位置把整个 rollout 的权重归零; 这个下限和 clip 的下界 ($-0.4$) 是两道独立的闸, 一道管数值存活, 一道管训练语义, 别合并. 下限的取值随精度变: float32 下 $-20$ 绰绰有余, bf16 下 log 空间的有效位数少, 建议全程 float32 算 log-ratio 再转回, 和 ORPO (1.2.4 节 §4.1) 的精度纪律同一来源. 把这条纪律推广: 凡是「先求和/求积再取对数」的环节, 都在 log 空间用 float32 完成中间运算, 这已经是 RL 实现的通用约定, 写新损失时默认遵守即可.
手算二: 均匀与撕裂的对照。 固定 $T=4$, 看两种比率形态. 形态一「均匀微漂」: $\rho=(1.05,0.97,1.01,0.99)$, 算术平均 $1.005$, 几何均值 $(1.05\times0.97\times1.01\times0.99)^{1/4}\approx1.0049$. 两者几乎重合——均匀场景下 GMPO 不改变任何行为, 这是设计的一部分: 不动正常的更新. 形态二「单点离群」: $\rho=(1,1,1,4)$, 算术平均 $1.75$, 几何均值 $4^{1/4}\approx1.414$. 压缩 $19\%$. 形态三「双点对冲」: $\rho=(2,0.5,1,1)$, 算术平均 $1.25$, 几何均值 $(2\times0.5)^{1/4}=1$. 算术平均被两个方向的离群同时推高, 几何均值识别出「乘积没变」——这条链的平均似然漂移其实是零. 三个形态合起来说明几何均值的工作方式: 它回答的问题是「这条链的 likelihood 乘积漂移多少」, 而不是「这条链的比率加起来多少」, 前者才是 off-policy 修正理论真正关心的量.

形态三还纠正一个直觉: 「离群对冲」 (一个大正配一个大负) 在算术平均下完全隐形——加和 $2+0.5=2.5$ 看着温和, 实际链上发生了剧烈的此消彼长. 几何均值靠乘积结构 ($2\times0.5=1$) 识别出净漂移为零. 如果任务里这类对冲常见 (例如长链推理中间改道), 几何均值的信号质量优势明显.

## 3. 裁剪与方向恢复
符号、裁剪与聚合顺序。 GMPO 的完整目标分三步. 第一, 用 $\hat A_i$ 的符号统一「有利方向」, 使正负 advantage 复用同一套 token 级裁剪. 第二, 在 $\log\rho_{i,t}$ 空间做对称裁剪 $[-\epsilon,\epsilon]$, 论文取 $\epsilon=0.4$, 对应比率区间 $[e^{-0.4},e^{0.4}]\approx[0.67,1.49]$. 第三, 对裁剪后的 log-ratio 求平均, 连同符号一起进损失. 这个顺序和 GRPO 不同: GRPO 先逐 token 构造 $\rho A$ 再 clip  surrogate, GMPO 先在 log space 裁 $\log\rho$ 再聚合. 差异看似细微, 后果不小: log space 的裁剪是**对称的加法截断**, ratio 空间的 clip 是不对称的乘法截断; 前者对大小离群一视同仁 ($\pm0.4$ 对应 $0.67$ 和 $1.49$, 相对幅度不同), 后者按相对幅度截停. 哪个更合理取决于你关心「对数漂移」还是「相对漂移」——和 GSPO §3.3 的量纲之争同源.

选择量纲有一个可操作的判别: 看你想让 clip 在「概率翻倍」处如何动作. log 空间对翻倍 ($d=0.69$) 和腰斩 ($d=-0.69$) 给对称处理; ratio 空间的 $\epsilon=0.2$ 在翻倍前就截停了. 如果训练经验是「翻倍常常是合理的强化」, log 空间顺眼; 如果「翻倍几乎总是失控」, ratio 空间顺眼. 论文选 log 空间, 和它对「正向强化放宽」的目标 (§3.3) 一致.

### 3.2. 单侧截断的解读

论文的裁剪和 min 组合有一个精妙的化简. 记 $d_t=\log\rho_{i,t}$, 裁剪值 $c_t=\operatorname{clamp}(d_t,-\epsilon,\epsilon)$, 目标里的 $\min$ 取 $u_t=d_t$ 与 $c_t$ 的较小者. 因为 $\min(d_t,\operatorname{clamp}(d_t,-\epsilon,\epsilon))=\min(d_t,\epsilon)$, 映射回有效 log-ratio: **正 advantage 对应 $d_{eff,t}=\min(d_t,\epsilon)$, 负 advantage 对应 $d_{eff,t}=\max(d_t,-\epsilon)$**——单侧截断, 截的方向和 advantage 符号一致. 这和 PPO 的 clip 语义完全对齐: 好动作只截上端 (概率涨太多才停), 坏动作只截下端. GMPO 在 log space 里用对称 clamp 加 min, 实现了 ratio 空间里 Direction-aware 的单侧截停, 而且正负分支共享同一行代码. 手算验证: $d=(-0.7,0.1,0.8)$, $\epsilon=0.4$, 正 advantage 得 $(-0.7,0.1,0.4)$, 负 advantage 得 $(-0.4,0.1,0.8)$, 平均后分别是 $-1/15$ 和 $1/6$——负的 log-ratio 在正 advantage 下原样保留 (概率降的位置继续降), 正的 log-ratio 被截到 $0.4$; 负 advantage 镜像. 逐条语义都可解释.

这个单侧化简还有一个工程红利: 实现不需要按 advantage 符号写两套 clip 分支, 一行 `torch.min` 加一行 `clamp` 就够了, 符号分流由 min 的数学结构自动完成. 减少了分支就减少了测试面, §7.2 的第一个不变量验证的正是这个化简. 负 advantage 分支里的 `max(d, -eps)` 来自 `min` 结构在负号下的镜像. 两个方向共享同一个 $\epsilon$，配置由此保持正负 log 边界一致.
log clip 与 ratio clip 的手算对照。 把两种裁剪并排算一遍, 看清量纲差异. 取 $d=\log\rho=0.4$ (即 $\rho=e^{0.4}\approx1.49$) 和 $d=-0.4$ ($\rho\approx0.67$): log clip ($\pm0.4$) 两端都恰好放行, ratio clip 若用 GRPO 式的 $[0.8,1.2]$, 两个都越界被截. 同一边界在两种量纲下宽差一倍. 再看 $d=2.0$ ($\rho=7.4$): log clip 截到 $0.4$, 相对压缩 $e^{-1.6}\approx20\%$; ratio clip ($\epsilon=0.2$) 截到 $1.2$, 相对压缩 $84\%$. log clip 对大幅正漂移温和得多, 对小幅负漂移严格得多.

这个不对称是特性: 训练里最需要压制的是「负向滑移」 (概率不该降的位置降了), 它对应负的 $d$, log clip 用 $-0.4$ 的紧边界盯着它; 「正向强化」 (对的 token 概率涨) 对应正的 $d$, 宽边界 ($0.4$ 对应 $49\%$ 涨幅) 放行. 和 Clip-Higher (DAPO 文章) 的哲学一致, 实现路径不同: Clip-Higher 在 ratio 空间调不对称边界, GMPO 在 log 空间用对称边界天然获得不对称效果——$\pm0.4$ 对 $e^x$ 就是 $+49\%$ 与 $-33\%$.

把三个方法的「正向放宽」并排收个尾: Clip-Higher 调 ratio 上界 ($1.2\to1.28$), GSPO 把 clip 整体搬到序列级并缩小量纲, GMPO 用 log 对称边界获得隐式不对称. 目标相同, 手段的量纲不同, 复用时最容易出错的就是把一家的数值搬到另一家的量纲里.

## 4. 与 GRPO, GSPO 的并排

### 4.1. 三种聚合的坐标

| 维度 | GRPO | GSPO | GMPO |
|------|------|------|------|
| **比率级别** | 逐 token $\rho_{i,t}$ | 序列级 $s_i$ | 逐 token, 几何聚合 |
| **聚合函数** | 算术平均 | log-ratio 平均后指数化 | log-ratio 裁剪后平均 (即几何均值) |
| **clip 位置** | ratio 空间, 逐 token | 序列级, ratio 空间 | log 空间, 逐 token |
| **clip 语义** | 双侧, min 结构 | 双侧, min 结构 | 对称 clamp + min ⇒ 单侧 |
| **离群处理** | 逐点截停, 算术放大 | 平均消解 | 几何压缩 + log 截停 |
| **KL** | 通常保留 | 视配方 | 论文 recipe 省略 |

三个方法是一条轴上的三个点: **聚合粒度** (token 级 → 序列级) 和 **聚合函数** (算术 → 几何) 两个坐标. GRPO 是 (token, 算术), GSPO 是 (序列, 几何), GMPO 是 (token, 几何). 这个坐标系比「谁更好」的问题更有用: 每个坐标的选择各有独立的理由, 组合出新变体的空间也一目了然.

坐标视角还解释了这三个方法的发布顺序: GRPO (2024.02) 定下坐标原点; DAPO (2025.03) 在 clip 坐标上调参; GSPO (2025.07) 和 GMPO (2025.07, 同期) 分别探索两个聚合坐标的另一端. 半年内三个团队独立地往同一坐标系填点, 说明这个坐标系不是事后整理, 是社区正在共同摸出来的结构.

这个坐标系对未来变体也有预测力: 剩下的空格 (序列级 × 算术) 没有方法占据, 因为序列级比率天然在 log 空间定义, 算术平均对它没有意义; (token 级 × 其他稳健统计量, 如截尾均值) 是下一个可能被填的格子. 读者若在文献里见到新变体, 先在这个坐标系里找它的位置, 比从动机叙事读起快得多.
GMPO 与 GSPO 的关系。 §2.1 已经指出 $\rho_{geo}$ 和 $s_i$ 是同一表达式. 两个方法的分歧在裁剪和粒度: GSPO 把平均后的标量当「这条链的似然漂移」, 做一次序列级判决; GMPO 把平均当「压缩离群后的 token 级权重」, 保留逐 token 的梯度贡献 (每个 token 的梯度方向仍由各自的 $g_{i,t}$ 决定, 只是权重被几何压缩统一). 用 §1.2 的例子: GMPO 的合成梯度是 $(0,2/3)$, 三个 token 的贡献都还在; GSPO 的序列级 clip 只产生一个标量决策, token 间的方向差异在比率层面不再可见.

哪个更合理, 取决于离群的性质: 若离群是「集体伪影」 (路由翻转), GSPO 的平均更彻底; 若离群里混着「个别位置的真实信号」, GMPO 的几何压缩保留了位置的存在感, 只压幅度. GMPO 论文的定位是前者场景的轻量替代: 不改粒度, 不换基建, 只换聚合函数, 拿到大部分稳定性收益.

这段关系也提示一个组合可能: GMPO 的几何聚合和 GSPO 的序列级 clip 并不互斥——先逐 token 做 log 裁剪和几何平均, 再对 $\rho_{geo}$ 做一次序列级 clip, 两个粒度的防护叠在一起. 没有公开实现验证这种组合, 代价是增加两个 clip 边界的联合标定, 收益与稳定性均未知, 因而目前不能作为训练建议.

## 5. 稳定性机制与边界
几何压缩的稳态效果。 把 §2.2 的 AM-GM 结构放进训练动态里看. 训练深入后, rollout 内比率分布的离散度随 off-policy 程度增长, 算术平均的合成权重被离群 token 持续推高, 有效学习率随 batch 构成漂移; 几何均值的合成权重被同一批离群压缩, 有效学习率更平. 论文的稳定性实验 (极端 token ratio 下 GRPO loss 爆炸, GMPO 平滑) 正是这个机制的直接证据. 附带收益: 合成幅度低意味着 clip 触发率也低, 有效梯度占比高.

这套机制有一个可证伪的预测: 如果 GMPO 的收益来自几何压缩, 那么把 GRPO 的 clip 边界大幅收紧 (让 clip 代替压缩) 应该复现一部分收益, 但不能全部复现——因为 clip 截的是单点, 算术平均的结构没变. 论文没有做这组对照, 读者在自己的管线上可以用它检验「聚合函数是独立故障源」这个归因.

这组对照还有一个副作用: 若「收紧 clip」复现了大部分收益, 说明问题主要在单点离群, 聚合函数是次要的; 若复现不了, 算术平均的结构本身在作妖, GMPO 的替换才是对因治疗. 一组对照实验同时回答「该不该上」和「上了管不管用」两个问题.

### 5.2. AM-GM 不能推出的结论

边界也要写明. 第一, AM-GM 只给幅度关系, 不给方向关系, §2.2 的抵消反例说明「GMPO 梯度范数一定更小」不成立. 第二, 几何均值对**均匀分布的离群不敏感, 对系统性偏移敏感**: 所有 token 的 $\rho$ 同时涨到 $1.5$, 几何均值一样到 $1.5$, 压缩无从发挥——它治的是「撕裂」, 不是「整体漂移」, 后者靠 clip 和 KL. 第三, log space 的加法裁剪按对数尺度截停, 对已经很大的正漂移 ($d=2$, 上限 $0.4$) 截得狠, 对很小的负漂移 ($d=-0.5$, 下限 $-0.4$) 截得轻, 这个不对称是按设计来的, 移植时若想换成 ratio 空间的对称 clip, 语义已经不同.

GMPO 的计算顺序必须保留：clip 发生在平均之前，几何平均的是 clip 后的 token 量。若先做几何平均，再对得到的标量 clip，目标已经变成另一个算法，语义更接近 GSPO 的序列级裁剪。两个版本在 $\epsilon$ 很小时接近，$\epsilon$ 增大后分叉，配置与论文必须核对这一顺序。
与 DAPO 补丁的叠加关系。 GMPO 和 DAPO 的 token-level loss 名字相近, 作用点不同, 值得拆开. DAPO 的 token-level loss 改的是**回答之间**的归约分母 (按条等权改成按 token 数加权), GMPO 改的是**回答内部**的聚合函数 (算术改几何), 两者正交, 可以同时用. clip-higher 和 GMPO 的 log clip 都动 clip, 语义相容 (§3.3 已说明两者都偏向「正向强化放宽」), 数值要重新标定. 动态采样, 长度塑形, 优势归一完全不受影响.

叠加时有一个隐藏的次序问题: 若同时用 GMPO 的几何聚合和 DAPO 的 token 统一分母, 分母把长回答的 token 权重放大, 几何均值把离群压缩, 两个效应在梯度上相乘, 有效权重结构变得更难直觉把握. 不是不能用, 是调试时每个现象都要归因到两层中的哪一层——这正是 §4.1 坐标系的价值, 报配置时把每个坐标的选择写明. 叠加的验证成本也随层数增长: 单层 clip 的调试是单因子扫描, 两层 clip 的交互是二维扫描, 每层还要配自己的标定流程.

调试预算的分配反过来也指导选型: 若团队只有一个 RL 工程师的调试带宽, 与其维护两层 clip 的组合, 不如选单层方案把边界情况跑全, 稳定性差距往往小于调试事故的损失. 团队规模小或调试带宽紧时, 先把单层方案吃透, 叠加留给有明确证据需要的场景.

## 6. 实验, 边界与选型
论文报告的结果。 论文在数学推理的 1.5B/7B/32B 模型和 Geometry3K 多模态设置上做实验, 报告 7B 设置在五个数学基准的平均 Pass@1 上比对应 GRPO 高 $4.1$ 个百分点, Geometry3K 高 $1.4$ 个百分点, 同时训练曲线更稳. 方法层面可靠的结论是: token 级算术平均是 GRPO 稳定性的一个可分离的故障源, 只换聚合函数 (不动采样, 不动优势, 不动粒度) 就能拿到可观的稳定性收益. 作为独立作者的工作被 ICLR 2026 接收, 也说明评审认可这个归因的干净. 也要指出实验设置的边界: 对照的 GRPO 是「教科书版」 (算术平均, 对称 clip, 无 DAPO 补丁), 和 DAPO 与 GSPO 文章反复强调的社区现状有距离. 4.1 分应读作「GMPO 对 vanilla GRPO 的提升」, 不是「GMPO 对当代最佳实现的提升」; 后者需要把 DAPO 补丁逐个加回对照组再测.

五个数学基准的 Pass@1 平均是常见口径，但 Pass@1 对采样温度敏感，对比需要使用一致的解码配置。引用实验数字时，同时标明表格、模型规模与评估设置，避免把不同配置的结果并排解释.

### 6.2. 批评与边界

第一, 4.1 分绑定特定模型, 数据和评测协议, 且对照的 GRPO 未必带 DAPO 系的补丁 (Clip-Higher, token-level loss 本身就在改聚合)——在带补丁的 GRPO 上 GMPO 的边际收益没有公开数据. 第二, $\epsilon=0.4$ 的量纲绑定 log space, 迁移时和 GSPO 的 clip 一样要重新标定 (§3.1). 第三, 几何均值在零值处发散: 某个 token 的 $\pi_\theta$ 降到零 (mask 外的极端情况), log-ratio 是 $-\infty$, 实现里要靠有效 token 过滤和数值下限兜住, 这个工程细节论文着墨不多.

第四个批评关于归因粒度: 论文把稳定性提升归给几何均值, 但 log clip 的引入是同时的, 两个改变没有独立消融 (只有「两者一起 vs GRPO」的对照). 「聚合函数」和「log 空间 clip」哪个贡献更大, 现有证据分不开. 复现者若想验证, 做一个「算术平均 + log clip」的中间变体就能拆开, 成本不高.

第五个边界: 论文没有覆盖多模态之外的任务类型, 代码修复, 工具调用等结构化输出的 reward 稀疏性和长度分布都不同, 几何压缩的收益曲线未必平移. 跨任务推广前, 先用 §7.2 的重放检查在自己的 batch 上测适配度, 这一步比任何论文数字都接近真相. 这条纪律对 GMPO 尤其重要, 因为它的收益结构 (治撕裂) 和任务的数据结构强相关.
什么时候试 GMPO。 已有 GRPO 基建, 不想动粒度 (保留 token 级日志和监控), 但被离群 token 的 loss 尖峰折磨时, GMPO 是最小改动: 聚合函数一行, clip 搬去 log space 几行. 三个判断信号和 §4.2 一致: 离群里含真实信号选 GMPO, 纯伪影选 GSPO, 想先零成本验证则按 §7.2 的不变量在历史 batch 上重放两种聚合的合成梯度, 看方向差异有多大.

还有一类场景不建议上 GMPO: 优势本身噪声大 (reward 方差高或组大小小) 时, 几何压缩稳定的是比率维度, 稳定不了优势维度, 两个噪声源叠加, 收益被稀释. 先把采样侧 (组大小, 难度筛选) 调好, 再动聚合函数, 顺序和 DAPO §7.3 的建议一致: 按症状下药, 不按流行升级. GMPO 的症状清单再列一遍: rollout 内比率撕裂度高, loss 尖峰与个别 token 同步, 收紧 clip 治不住. 三条全中再动手; 只中一条, 先查更便宜的解释 (数据噪声, 学习率, 参考策略版本). 训练崩溃前若干步的指标快照、参考策略版本和近期数据变更，可以区分 ratio 聚合异常、版本错配与数据分布突变，减少无效的算法归因.
实现生态与复现路径。 GMPO 的官方实现 (callsys/GMPO) 是单作者仓库, 规模和维护力度不能和 verl 这类框架比, 复现路径有两条. 一是直接在官方代码上跑小规模验证: 仓库自带最小训练脚本, 适合确认机制和论文曲线的大形状; 生产使用要自己补监控, 日志和容错. 二是在已有 GRPO 基建上按 §7.1 自实现: 改动集中在损失函数, 其余 (采样, 优势, 调度) 全部复用, 多数团队一天内能完成. 两条路的共同前提是先跑 §7.2 的不变量测试.

社区采用度方面, GMPO 作为 ICLR 2026 的新工作, 主流框架 (verl, OpenRLHF, TRL) 的集成还在早期, 搜配置时注意区分「官方 recipe」和「框架默认改造版」, 后者常把 log clip 的数值按框架习惯重标定, 和论文的 $\epsilon=0.4$ 不是一回事. 这个区分和 GRPO 文章「五个开关」的核对清单是同一套动作: 名字相同, 坐标不同.

GMPO 与 GSPO 都出现于 2025 年 7 月: 前者改聚合函数, 后者改约束粒度; 一个月后的 Dr. GRPO 又继续讨论归一化问题. 比较这组工作时, GRPO 原版提供共同坐标, 三个变体则分别对应不同训练症状. 方法选择应按被修改的坐标进行, 不能只比较论文名称和单项分数.

按名字选型的风险在本家族已经兑现过: 「都叫 GRPO」的实现可能差了 clip, 归约, 采样三个坐标, 「都叫稳定化」的论文动的是完全不同的量. 坐标系是防这类事故的疫苗. 这套防法不增加任何运行时成本, 只要求报配置时多写两行. 对单人团队, 这两行可以固化成配置模板里的固定字段, 让坐标报告成为提交训练配置的强制项. 模板化之后, 回看历史 run 时也能直接读出当时的选择, 省去翻代码的工夫. 这也是配置即文档原则在 RL 训练里的具体落地. 1.3 节的各篇实现清单都可照此模板归档.

实现。 教学实现。

```python
import torch

def gmpo_loss(new_logp, old_logp, advantages, mask, eps=0.4):
    # new_logp, old_logp: [batch, seq]；advantages: [batch]；mask: [batch, seq]
    d = (new_logp - old_logp.detach()) * mask          # log ρ，padding 为 0
    d_eff = torch.min(d, torch.full_like(d, eps))      # 正 advantage 分支
    # 负 advantage：max(d, -eps) = -min(-d, eps)，按符号分流
    neg = advantages < 0
    d_eff = torch.where(neg.unsqueeze(-1),
                        torch.max(d, torch.full_like(d, -eps)), d_eff)
    lengths = mask.sum(-1, keepdim=True).clamp(min=1)
    log_geo = d_eff.sum(-1, keepdim=True) / lengths    # [batch, 1]
    weights = torch.exp(log_geo).squeeze(-1)           # ρ_geo
    adv = advantages.detach()
    surr = weights * adv
    # min 结构的另一半 (权重偏大时取裁剪值) 已在 d_eff 的单侧截断中体现
    return -surr.mean()

```
对应论文 Algorithm 1 的核心: log space 裁剪, 单侧化简, masked 几何平均. `advantages.detach()` 和 `old_logp.detach()` 不可省. $\hat A=0$ 的 rollout 主项为零, 可在损失前过滤. 这段代码省略了论文 Algorithm 1 的两个外围步骤: 优势的标准差归一 (沿用 GRPO 的组内归一, 在进损失前完成) 和无效组的过滤 (全同 reward 组主项天然为零, 是否显式丢弃看吞吐策略). 省略它们不影响核心机制, 完整的训练循环按 GRPO 文章的流程图拼装.
验证清单。 三个不变量. 第一, 单侧化简: 对随机 $d$ 和两种符号, 验证 `min(d, clamp(d,-eps,eps))` 等于 `min(d,eps)` (正) / `max(d,-eps)` (负), 这是 §3.2 的代码级重述. 第二, 等价性: 短序列 (如 $T=3$) 上, log-space 几何平均与直接乘积开方在 float32 内一致; 长序列 (如 $T=4096$) 上直接乘积溢出而 log 版本正常——这个对照本身就是 log space 必要性的演示. 第三, 退化: 全等比率 $(c,c,\ldots)$ 下 $\rho_{geo}=c$, 几何平均退化为常数; 全零 mask 的 rollout 被过滤或主项为零. 另补一个历史 batch 重放检查: 对同一批 (log-ratio, 优势), 分别用算术和几何聚合算合成梯度, 报告方向余弦和范数比, 作为迁移前的适配度测量.

这组不变量同样可以离线跑在历史 batch 上, 不依赖训练: 第一个验证代码正确性, 第二个验证数值稳定性, 第三个验证退化语义, 重放检查测适配度. 四步都不需要 GPU 训练循环, 符合「先测后训」的调试纪律, 也是这套实现可以进 CI 的原因.

### 6.3. 从 GRPO 到 GMPO 的目标函数

GRPO 聚合的对象. 给定问题 $q$，old policy 生成 $G$ 条回答 $o_1,\ldots,o_G$，组内 reward 标准化得到
$$
\hat A_i=\frac{r_i-\operatorname{mean}(r_1,\ldots,r_G)}
{\operatorname{std}(r_1,\ldots,r_G)}.
$$
第 $i$ 条回答中第 $t$ 个 token 的 importance ratio 为

$$
\rho_{i,t}(\theta)=
\frac{\pi_\theta(o_{i,t}\mid q,o_{i,<t})}
{\pi_{old}(o_{i,t}\mid q,o_{i,<t})}.
$$
暂时略去裁剪，GRPO 对一条回答优化

$$
J_i^{\text{GRPO}}=\frac1{T_i}\sum_{t=1}^{T_i}\rho_{i,t}\hat A_i.
$$
因此算术平均的对象是 token 级 importance-weighted reward $\rho_{i,t}\hat A_i$。优势在同一回答内共享，ratio 随 token 变化。某个极端 ratio 会单独放大对应 token 的参数梯度。 GMPO 聚合的对象. GMPO 将同一组正负同号的 token reward 取绝对值后做几何均值，再用优势符号恢复方向：

$$
J_i^{\text{GMPO}}
=\left(\prod_{t=1}^{T_i}|\rho_{i,t}\hat A_i|\right)^{1/T_i}
\operatorname{sgn}(\hat A_i).
$$
因为 $\rho_{i,t}>0$ 且 $\hat A_i$ 在序列内为常数，未裁剪时可化简为

$$
J_i^{\text{GMPO}}=hat A_i
\left(\prod_{t=1}^{T_i}\rho_{i,t}\right)^{1/T_i}.
$$
这里的聚合结果属于回答级标量，内部原料来自 token 级 ratio 与序列级 advantage。用「token 方法」或「sequence 方法」单独概括都容易丢掉一半信息：GMPO 的裁剪发生在 token 级，几何聚合和最终 surrogate 发生在回答级。 完整的 token 级裁剪. 论文算法在 log 空间按优势符号裁剪。令

$$
d_{i,t}=\log\rho_{i,t},\qquad z_{i,t}=\operatorname{sgn}(\hat A_i)d_{i,t}.
$$
对称 log 边界 $[-\epsilon,\epsilon]$ 下，先计算

$$
\tilde z_{i,t}=\min\left(z_{i,t},
\operatorname{clip}(z_{i,t},-\epsilon,\epsilon)\right),
$$
恢复方向 $\tilde d_{i,t}=\operatorname{sgn}(\hat A_i)\tilde z_{i,t}$，得到

$$
\tilde\rho_{geo,i}
=\exp\left(\frac1{T_i}\sum_t\tilde d_{i,t}\right),
\qquad
J_i=\hat A_i\tilde\rho_{geo,i}.
$$
正优势时，上方过大的 $d_t$ 被截住；负优势时，过小的 $d_t$ 被截住。另一侧保留梯度，与 PPO 的 min surrogate 方向一致。这个符号变换比直接把所有 $d_t$ 钳到双侧区间更准确，后者会多裁一侧本应保留的更新。
梯度推导与共享权重。 未裁剪梯度. 定义几何 ratio
$$
g_i=\left(\prod_{k=1}^{T_i}\rho_{i,k}\right)^{1/T_i}.
$$
对参数求导：
$$
\nabla_\theta g_i
=g_i\nabla_\theta\left(\frac1{T_i}\sum_k\log\rho_{i,k}\right)
=\frac{g_i}{T_i}\sum_k\nabla_\theta\log\pi_\theta(o_{i,k}\mid q,o_{i,<k}).
$$
于是

$$
\nabla_\theta J_i^{\text{GMPO}}
=\frac{g_i\hat A_i}{T_i}\sum_k\nabla_\theta\log\pi_\theta(o_{i,k}\mid q,o_{i,<k}).
$$
同一回答内所有 token 共享 $g_i\hat A_i/T_i$ 这一标量系数。GRPO 则给第 $k$ 个 token 权重 $\rho_{i,k}\hat A_i/T_i$。GMPO 把位置相关 ratio 换成回答共享的几何 ratio，极端 token 不再单独扩大自己的梯度。 裁剪后的梯度 mask. 完整 GMPO 中，每个 $\tilde d_{i,t}$ 对原 $d_{i,t}$ 的导数为零或一。记未被方向性裁剪的位置集合为 $U_i$，则

$$
\nabla_\theta J_i
=\frac{\tilde\rho_{geo,i}\hat A_i}{T_i}
\sum_{t\in U_i}\nabla_\theta\log\pi_\theta(o_{i,t}\mid q,o_{i,<t}).
$$
被裁 token 不贡献直接梯度，未裁 token 共享同一个几何权重。GSPO 的序列级裁剪一旦触发，会让整条回答的梯度归零；GMPO 只移除越过方向边界的位置，其余 token 继续更新。论文把这一点作为 token-level clipping 的主要动机。 一个必须修正的直觉. 几何均值并非给每个 token 分配各自压缩后的权重。最终梯度中，未裁位置全部乘同一个 $\tilde\rho_{geo}$。离群 token 的 ratio 通过平均 log-ratio 影响共享尺度；若它本身被裁，其直接 score gradient 被 mask 掉，但裁剪值仍进入几何平均。 因此「多数 token 投票」只是帮助理解共享尺度，无法推出梯度方向必然服从多数。方向由各 token score gradient 的向量和决定。即使权重相同，一个 Jacobian 范数特别大的位置仍可主导参数更新。

### 6.4. 聚合方式、离群值与长度效应

AM-GM 能证明什么. 对正数 $x_t=|\rho_t\hat A|$，有
$$
\left(\prod_tx_t\right)^{1/T}
\le\frac1T\sum_tx_t.
$$
这说明同一条回答、同一组 token 数值下，几何聚合的绝对目标不超过绝对值的算术聚合。等号仅在所有 $x_t$ 相等时成立。ratio 越不均匀，两者差距通常越大。 它无法证明 GMPO 的梯度范数总小于 GRPO。GRPO 不同 token 梯度可能抵消，GMPO 改为共享权重后抵消结构也改变。目标值范围较窄提供稳定性的线索，训练稳定仍需梯度范数、KL、熵与外部能力实验支持。 对大离群与小离群的敏感性. 长度 $T$ 的序列中，$T-1$ 个 ratio 为一，一个为 $M$，几何均值为 $M^{1/T}$，算术均值为 $(T-1+M)/T$。$M$ 很大时，算术均值近似 $M/T$，几何均值按 $T$ 次根增长。

若离群值为很小的 $m$，几何均值为 $m^{1/T}$，算术均值约为 $(T-1)/T$。几何均值对接近零的值更敏感，会把整条回答共享权重向下拉。方向性 token clipping 给 log-ratio 设置边界，可避免单个极小概率变化把负或正优势序列压得过低。 方差近似. 令 $d_t=\log\rho_t$，均值 $\mu$、方差 $\sigma^2$。若位置近似独立，则
$$
\log g=\bar d,qquad
\operatorname{Var}(\bar d)=\frac{\sigma^2}{T}.
$$
token 相关系数近似为 $c$ 时，

$$
\operatorname{Var}(\bar d)
=\frac{\sigma^2}{T}[1+(T-1)c].
$$
局部零均值波动会随长度平均，共同漂移则保留。MoE 路由若只让少数位置尖峰，几何聚合明显受益；若整段 token 同方向变化，平均无法消除。
Token 裁剪与序列几何聚合。 为什么先裁剪再聚合. 若先算 $g=\exp(T^{-1}\sum d_t)$ 再裁剪，整条回答共享一个 clip 开关。均值越界时全部 token 梯度归零，均值未越界时局部极端仍保留直接梯度。GMPO 先逐 token 做方向性裁剪，局部极端位置归零，其余位置继续学习。 顺序不可交换。设正优势、两个 log-ratio 为 $(0.8,-0.2)$，边界为 $0.4$。先 token 裁剪得到 $(0.4,-0.2)$，均值 $0.1$，几何 ratio $e^{0.1}$；先平均得到 $0.3$，序列裁剪不触发，ratio 为 $e^{0.3}$。前者同时压低共享尺度并屏蔽第一个 token 的直接梯度。 Log 边界与 ratio 边界. 论文采用 $e^{-0.4}$ 到 $e^{0.4}$ 的 ratio 范围，对应对称 log 边界 $[-0.4,0.4]$，数值约为 $[0.670,1.492]$。这比 GRPO 常见 $[0.8,1.2]$ 宽，并且在 log 空间倒数对称。 ratio 空间 $[1-\epsilon,1+\epsilon]$ 在 log 空间不对称。例如 $[0.8,1.2]$ 对应约 $[-0.223,0.182]$。对数对称更符合乘性变化的倒数关系：概率乘 $e^{0.4}$ 与除 $e^{0.4}$ 距离相等。 Clip 更宽为何仍可能稳定.

GMPO 先压制 ratio 离群对共享权重的影响，再允许更宽 token 边界，以换取探索空间。更宽 clip 单独用于 GRPO 可能放大单点梯度；与几何聚合结合后，某个大 ratio 对共享尺度仅通过平均 log 值进入。 这不是无条件保证。多个 token 同时接近宽边界时，几何均值也会接近边界；reward 假阳性还可能让整条错误轨迹获得更强更新。论文实验支持特定模型与任务上的稳定性，换数据后仍要扫 clip 范围。
长度效应。 单离群随长度稀释. 一个 token 的 log-ratio 异常为 $a$，其余为零，几何 ratio 为 $e^{a/T}$。长度越长，异常对共享尺度影响越小。$a=\log8$ 时，$T=3$ 得二，$T=100$ 只约为一点零二一。 若异常 token 未被裁，它的直接 score gradient 仍在集合 $U$ 中，且共享系数含 $1/T$；长序列进一步减小单位置显式权重。关键局部动作可能因长度被稀释，必须用 token ratio 极值、位置分桶与行为案例补充监控。 序列等权与 token 等权. GMPO 每条回答产生一个几何 surrogate，再在组和 batch 中平均，典型形式保持回答等权。梯度中的 $1/T$ 让一条回答的 token score 总和按长度平均。DAPO 的 token-level loss 则让长回答按 token 数获得更大 batch 权重。 二者可以组合成「GMPO ratio + token batch 归约」，但这会改变论文目标。长回答的几何 ratio 仍由内部平均 log-ratio决定，最终总权重却随长度增加。组合实验必须与原始序列等权版本并列。

添加零变化尾缀. 原回答平均 log-ratio 为 $\bar d$，附加 $K$ 个 $d_t=0$ 的稳定模板后，新均值为 $T\bar d/(T+K)$。几何 ratio 更接近一，裁剪后的异常也被分母稀释。模型可能通过冗余尾缀降低共享权重波动。 长度 reward、EOS 与重复检测负责约束行为；GMPO 自身不区分必要推理和冗余。评估按自然结束、截断、正确长解和重复长解分桶，才能判断长度稳定来自推理改善还是模板稀释。

### 6.5. 策略滞后与相邻方法边界

几何 ratio 的统计含义. 严格轨迹 importance ratio 为
$$
\rho_{seq}=\prod_t\rho_t.
$$
GMPO 使用的未裁几何 ratio 为 $g=\rho_{seq}^{1/T}$。$\rho_{seq}$ 能在支持集覆盖时完成轨迹分布的 importance correction，$T$ 次根后的 $g$ 一般不具备该无偏关系。GMPO 选择更稳定的近端 surrogate，并非严格离策略估计器。 current 与 old 很接近时，$d_t$ 都小，$g\approx1+T^{-1}\sum_td_t$，可作为每 token 平均变化的平滑代理。policy lag 很大时，$g$ 仍可能温和，真实轨迹比已随 $T$ 指数增长。 多 epoch 复用. 论文设置中 old policy 生成 rollout 后，current 进行多次更新。epoch 增加时 token ratio 分布逐步展开，方向性 clip mask 增多，几何共享权重也发生变化。后期 epoch 可能主要复用少量未裁 token。 每个 epoch 应记录正负优势的 token clip fraction、回答中未裁 token 比例、几何 ratio 分位和与新鲜 rollout 梯度的余弦。若未裁比例很低，继续复用的计算收益有限；若新鲜梯度方向已经分叉，旧数据会误导更新。 行为分布必须真实.

old log-prob 应对应生成时的温度、top-p、top-k、重复惩罚与语法 mask。服务若只保存基础 softmax log-prob，ratio 分母与实际采样分布不一致。误差在 log 空间被整段平均，可能形成稳定偏移。 每条 rollout 绑定 producer checkpoint、解码配置、tokenizer 和服务精度。GMPO 缓解 ratio 离群，无法纠正错误 ratio。实现差异被平均后曲线可能更平，反而更难从 loss 发现。
与 GRPO、DAPO、GSPO 的关系。 GRPO 提供组优势，GMPO 改聚合. GMPO 保留 GRPO 的 group sampling、reward normalization 和无 critic 结构。它替换同一回答内 token importance-weighted reward 的算术平均，并调整裁剪到 log 空间。全同组、reward 噪声和 prompt 分布问题仍然存在。 当所有 token ratio 相等时，算术均值与几何均值相同，GMPO 退化到 GRPO 的共享 ratio 情形。收益集中在 ratio 不均匀、离群明显的 rollout。监控算术均值与几何均值之比，可以估计可用空间。 DAPO 中可组合的部分. Dynamic sampling 处理全同组，overlong shaping 改变 reward，二者与 GMPO 的 ratio 聚合处于不同层级，可以组合。Clip-higher 与 GMPO 的 wide log clip 都扩大探索范围，但参数化不同；不能同时机械叠加两套数值。 DAPO token-level loss 改变 batch 中长短回答权重，GMPO 原目标为序列等权。组合后应明确分母，并重新评估长度偏好。四项开关同时打开的最终收益无法直接归给几何均值。 GSPO 中不可替代的部分.

忽略裁剪时，GMPO 几何 ratio 与 GSPO 长度归一序列 ratio 形式相同。差异集中在裁剪：GSPO 对聚合后的 sequence ratio 一次裁剪，GMPO 对每个 token 方向性裁剪后再聚合。 GMPO 能保留回答中未越界 token 的梯度，GSPO 提供整条回答一致开关。前者更局部，后者更严格地让序列共同进退。两者不能通过换一个 clip 数字互相替代，应以局部异常、整段漂移和有效梯度利用率选择。
Reward、优势与全同组。 优势符号决定裁剪方向. GMPO 的 `sgn(A)` 不只是恢复几何均值的正负，还决定哪一侧 ratio 变化属于过度更新。正优势希望增大 sampled action 概率，过大的正 log-ratio 被截；负优势希望降低概率，过大的负向变化被截。 优势接近零时，几何 ratio 仍可计算，但 surrogate 幅度接近零。实现若通过 `sign(0)` 得零，随后裁剪路径也应保持零梯度。给 $A$ 加微小 epsilon 以避免符号零，会给全同组制造虚假方向。 Reward 噪声的整段影响. 假阳性让错误回答获得正优势，未被裁的位置全部沿正向更新，并共享几何 ratio。几何聚合降低单个 ratio 离群的主导，却无法判断 reward 是否正确。宽 clip 还可能让错误轨迹探索得更远。

对同一回答重复运行 verifier，估计标签翻转与分数方差。组内分差低于噪声地板时，标准化会放大随机差异。唯一高分、极端 advantage 与高几何 ratio 的轨迹应优先抽检。 全同组仍无任务梯度. 组内 reward 全相等时 $\hat A_i=0$，GMPO 任务项为零。几何聚合不能从空信号中产生方向。Dynamic sampling、可靠过程奖励或更合适难度数据仍然必要。 若总 loss 包含独立 KL，零优势组可能产生 KL 梯度；应分别记录任务项与 KL 项。过滤全同组也会改变 KL 施加的 prompt 分布，这属于组合配方的额外变化。 多目标 reward 的标尺. 正确性、格式、长度和工具成本加权成一个标量后，优势符号控制整条回答方向。几何均值不会保留各 reward 分量的 Pareto 结构。长度分压过正确性时，算法会稳定地优化错误目标。

日志保存每个 reward 分量、总分与排序翻转。增加某一分量前后，统计同组 winner 改变比例；高翻转率意味着训练目标已实质变化，不能把后续差异归给 GMPO。
