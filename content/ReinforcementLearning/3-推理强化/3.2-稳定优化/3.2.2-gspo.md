# GSPO (Group Sequence Policy Optimization)

论文信息如下：
- **标题**: Group Sequence Policy Optimization
- **作者**: Qwen Team, Alibaba Inc.
- **年份**: 2025
- **论文**: [arXiv:2507.18071](https://arxiv.org/abs/2507.18071)
- **应用**: Qwen3 Instruct、Coder 与 Thinking 的强化学习训练

---

## 1. 动机: 奖励的单位与优化的单位

### 1.1. GRPO 的 token 级 surrogate

GRPO 在每个 token 上构造比率 $\rho_{i,t}=\pi_\theta(y_{i,t}|y_{i,<t})/\pi_{old}(y_{i,t}|y_{i,<t})$，与整条回答共享的优势相乘后逐位置裁剪。若一条回答有几千个 token，损失中就有几千个独立的裁剪决策；奖励本身却只有一个序列标量。GSPO 处理的正是这个粒度差别。

一批 rollout 被反复用于更新后，新旧策略的 token 概率会逐渐分开。路由敏感的 MoE 模型还可能在部分位置出现较大的概率变化。逐 token 裁剪让每个位置独立进入或离开平台；对正优势而言，比率高于上界的位置不再提供显式比率梯度，其他位置仍可更新。DAPO 调整 token 级裁剪等训练环节，GSPO 则换了比率和裁剪的单位。

这个改动会让同一条回答共享一个比率和一个裁剪开关。它能减少逐位置裁剪的碎片，却也失去依据 token 比率分别保留梯度的能力。两种方式各有适用场景，后面用手算例子看差别。

### 1.2. MoE 崩溃: 压垮骆驼的那根稻草

Qwen 团队报告，使用 GRPO 训练大规模 MoE 模型时出现模型崩溃，回退检查点、调整超参数仍难以稳定训练。新旧策略的专家路由可能不同，部分 token 的 log-prob 随之大幅变化；GRPO 按 token 分别计算比率并裁剪，而奖励只在整条回答结束后给出。GSPO 将比率与裁剪放到回答粒度：先把有效 token 的 log-ratio 求平均，再由一条回答共用一个裁剪决策。论文在 Qwen3 MoE 训练中报告了更稳定的过程。

长链生成代价高，同一批 rollout 更可能被复用多次。更新次数增加，新旧策略的偏离也会扩大，逐 token 比率的波动更值得留意。GSPO 对这类波动的处理不依赖专家路由的存在，但目前这篇论文的稳定性实验主要落在 Qwen3 MoE 上。至于「第 N 步推理错了」这样的位置判断，序列奖励给不出答案；GRPO 的逐 token 裁剪依据也是概率比率。要给具体步骤分配信用，还得有步骤奖励或过程验证器。

## 2. 序列级重要性比率

### 2.1. 长度归一的序列比率

GSPO 把一条回答的全部 token log-ratio 求有效位置均值，再取指数，得到长度归一的序列比率：
$$
s_i^{GSPO}=\exp\left(\frac{1}{|y_i|}\sum_{t=1}^{|y_i|}\log\frac{\pi_\theta(y_{i,t}|x,y_{i,<t})}{\pi_{old}(y_{i,t}|x,y_{i,<t})}\right).
$$
$|y_i|$ 是有效 token 数，prompt 和 padding 不进入分子，也不进入分母。若各位置的 log-ratio 方差均为 $\sigma^2$ 且彼此不相关，均值方差为 $\sigma^2/|y_i|$：长度 200 与 4000 时，分别是单 token 方差的 $1/200$ 与 $1/4000$。真实序列里相邻位置有关联，平均化的收益还取决于相关性。实现时若错用 batch 的固定长度作分母，短回答的平均 log-ratio 绝对值会被压小，$s_i$ 被拉向 1；下文的长度不变性检查能抓住这个错误。

### 2.2. 与「token 比率乘积」的区分

GSPO 使用平均 log-ratio 的指数, **没有**把 GRPO 的逐 token 比率直接相乘. 序列似然比 $\prod_t\rho_{i,t}$ 的对数是 log-ratio 之和, 不带 $1/|y_i|$; GSPO 则取对数的平均, 两者相差长度因子. 乘积形式随长度指数漂移 ($T$ 个 1.001 的乘积是 $e^{0.001T}$), 平均形式对长度不敏感. 因而「token 比率乘积的 clip」并不是 GSPO 的目标. RLHF 采用小步迭代, 每轮重新采样会继续修正前一轮的估计偏差; 方差过大却可能一次就把参数推得太远, 使后续校正追不上. PPO 选择 clip 而非无截断的 importance sampling 已经体现了这项权衡, GSPO 又在序列级采用了相同取舍.

GSPO 的比率是每 token 平均 log-ratio 的指数。它与逐 token 比率的数值范围不同：DAPO 上界偏移 0.28 指 token 概率比率的上界为 1.28，GSPO 的 $4\times10^{-4}$ 指序列比率的上界为 1.0004。比较裁剪参数时要同时看比率定义、回答长度和实际分布，单凭两个偏移量的大小没有意义。

经典轨迹级 importance sampling 使用 token 比率乘积，可以精确变换轨迹分布的期望，但长链上的权重容易变得极端。GSPO 的几何平均控制了比率尺度，代价是它不再等于完整轨迹的密度比；这个取舍服务于稳定的近端优化目标。

拿四个 token 手算一次。设 log-ratio 为 $d=[0.01,0.02,-0.01,0]$，均值是 $0.005$，GSPO 的序列比率 $s=e^{0.005}\approx1.00501$；逐 token 比率约为 $[1.010,1.020,0.990,1.000]$。对正优势而言，若 GRPO 的上界是 $1.2$，四个 token 均未被上侧裁剪；若 GSPO 使用论文实验中的上界 $1.0004$，整条回答都落入上侧平台。四个 log-ratio 全为 $0.01$ 时，$s\approx1.01005$，结论仍然如此。若正负变化恰好抵消，使 $s\approx1$，GSPO 的序列梯度仍存在；$s=1$ 只表示平均 log-ratio 为零，不等于损失对新策略参数的导数为零。GRPO 的各位置也同乘这一条回答的优势；概率比率的正负偏移不会自行翻转优势的符号，只会改变各位置权重及是否被裁剪。

平均化能压低零均值的局部波动，但无法判断某段推理是否正确。若局部变化来自专家路由扰动，序列平均可能减少噪声；若确有步骤级奖励，单一序列优势又可能太粗。要区分两种情况，可以按任务类型观察 token log-ratio 的分布，并将训练结果与步骤奖励方法做受控比较。

作为纯算术例子，若 $T=2000$、各位置独立且同方差 $\sigma^2=0.01$，均值的标准差约为 $0.00224$，大于 $3\times10^{-4}$ 与 $4\times10^{-4}$ 的裁剪偏移。训练中的裁剪率还受均值、分布尾部、位置相关性及优势正负影响。比较 GRPO 与 GSPO 时，分别记录序列裁剪率、token 裁剪率和有效梯度样本占比，才看得出各自保留了多少更新信号。

## 3. 序列级 clip 与损失

### 3.1. 一条回答共享一个裁剪决策

GSPO 的损失为：
$$
L^{GSPO}=-\mathbb{E}\left[\min\left(s_i\hat A_i,\ \operatorname{clip}(s_i,1-\epsilon_{low},1+\epsilon_{high})\hat A_i\right)\right].
$$

![GSPO 先汇合 token 对数比率，再以整条回答共享一个裁剪开关；GRPO 则逐 token 裁剪](./images/gspo-sequence-ratio-clip.png)

*图：按 [GSPO 原文式 (5)–(10)](https://arxiv.org/pdf/2507.18071) 重绘机制。每个 token 的 $d_t$ 在生成位置出现，全部求均值后得到 $s_i$；未触平台时各位置共享标量系数 $-s_i\hat A_i/|y_i|$，但参数梯度还取决于各自的 log-prob 导数。*

损失沿用 PPO 的裁剪形式，裁剪对象却从每个 token 的 $\rho_{i,t}$ 换成每条回答的 $s_i$。一条 4000 token 的回答，GRPO 有 4000 个位置级裁剪决策，GSPO 只有一个序列级决策。局部 log-ratio 会进入均值，但它们对最终决策的影响取决于幅度、符号与回答长度。

所有有效位置都参与 $s_i$ 的计算，但求均值后不再保留各位置的比率差异。若任务需要区分某一步的行为质量，得从过程奖励等信号获得位置信息；序列级裁剪不会自行恢复它。

### 3.2. 梯度结构的差别

把两边的有效梯度写开。GRPO 中，未触平台的 token 贡献与 $A_i\nabla\log\pi_\theta(y_{i,t})$ 成比例，每个位置分别判断是否裁剪。GSPO 的 $s_i$ 依赖整条回答的平均 log-ratio，未裁剪时，每个有效 token 的 log-prob 都得到相同标量系数 $-s_iA_i/|y_i|$。两者的优势符号都来自同一条回答；区别在于逐位置开关与整条回答共享开关。共享系数不意味着参数梯度向量同向：不同 token 的 $\nabla_\theta\log\pi_\theta(y_{i,t})$ 可能相互抵消。GSPO 也没有因此获得 SFT 那样的逐 token 正确标签。

这种共享开关会牺牲局部选择性：一条正优势回答的 $s_i$ 一旦超过上界，所有有效 token 的显式比率梯度都归零；GRPO 仍可能保留未越界的位置。不过，哪个位置被保留只由概率比率决定，不等于它恰好是值得奖励的推理步骤。两种目标在局部信用分配上的差别，仍要结合奖励粒度来判断。

论文实验中的 GSPO 裁剪区间是 $[1-3\times10^{-4},\,1+4\times10^{-4}]$。它比常见的 token 级 PPO/GRPO 区间窄得多，因为 $s_i$ 衡量的是**平均每 token 的对数概率变化**。例如平均 log-ratio 为 $4\times10^{-4}$、长度为 4000 时，完整轨迹比率为 $e^{1.6}\approx4.95$，而 $s_i=e^{0.0004}\approx1.00040008$，刚越过 GSPO 的 $1.0004$ 上界。完整轨迹比率已接近五倍，序列比率看起来却只比一大约 0.04%；两者描述的是不同尺度。换模型或调整 rollout 复用时，应先看实际的 $s_i$ 分布与裁剪率，再设定边界。

## 4. 与 GRPO, DAPO 的并排

### 4.1. 三个损失并排

| 维度 | GRPO | DAPO | GSPO |
|------|------|------|------|
| **比率级别** | 逐 token $\rho_{i,t}$ | 逐 token (解耦 clip) | 序列级 $s_i$ |
| **clip 粒度** | token, 对称 | token, 正负异界 | 序列, 实验中正负异界 |
| **clip 量级** | $\epsilon\sim0.2$ | $\epsilon_{high}=0.28,\ \epsilon_{low}=0.2$ | $\epsilon_{low}=3\times10^{-4},\ \epsilon_{high}=4\times10^{-4}$ |
| **归约分母** | 每回答等权 (或 token 级, 见 DAPO) | 批内 token 统一分母 | 内建于比率 (长度归一) |
| **MoE 稳定性** | Qwen 报告训练崩溃 | 与 GSPO 未作同设置对照 | Qwen 报告训练更稳定 |
| **来源** | DeepSeekMath | ByteDance Seed | Qwen Team |

三者的关系是「同一骨架上的三处补丁」: GRPO 是基线; DAPO 不动比率定义, 改 clip 边界, 采样过滤, 归约分母; GSPO 动比率定义本身, clip 和归约随之重写. 没有谁取代谁的问题——DAPO 的技巧 (动态采样, 长度塑形) 可以和 GSPO 的比率组合, Qwen 自己的训练系统里也保留了这些工程件. 这张表还揭示了一个命名学现象: 三个名字 (GRPO, DAPO, GSPO) 各自的论文都把自家版本写成「默认之上的修正」, 但修正的落点不同——采样端, clip 端, 比率端. 把它们当成同一坐标系里的三个点而不是三个竞争的「算法」, 讨论会清晰得多: 选 surrogate 坐标 (GRPO vs GSPO), 再选 clip 坐标 (对称 vs 解耦 vs 序列级), 再选采样坐标, 三轴独立. 这个坐标视角也解释了社区实现的分叉: verl, OpenRLHF, TRL 各自的「GRPO」其实是坐标系里的不同点, 报配置时按三轴展开, 比报一个名字信息量高一个量级.

### 4.2. GSPO 的优势什么时候显性化

按机制推测，路由敏感、回答较长、同批 rollout 被复用较多时，GSPO 的序列裁剪更可能显示出收益。模型较小、回答短且几乎不复用旧样本时，比率波动和裁剪造成的差别可能减小，具体幅度取决于同底座、同数据的对照结果。步骤奖励和多轮交互改变了奖励或回答的边界，序列优势也得随之重新定义。
GSPO 的序列比率可以与 DAPO 的动态采样、长度奖励等数据侧做法组合。左右异界在 GSPO 实验里已经存在，但阈值约为 $3\times10^{-4}$ 与 $4\times10^{-4}$；DAPO 的 0.2/0.28 针对 token 比率，数值要按序列比率重新设定。损失归约也需单独选择：GSPO 原式按回答平均，若改为按全 batch token 平均，长回答会获得不同权重。这是另一个可定义的目标，而非对原式的等价实现。

## 5. 稳定性机制再分析

### 5.1. MoE 路由与集体波动

MoE 路由变化会改变部分 token 的专家输出，因而使这些位置的新旧策略 log-prob 相差较大。GRPO 按位置计算比率并裁剪；GSPO 先对整条回答的 log-ratio 求均值，再做一次裁剪。举个算术例子：长度 4000 的回答里，40 个位置的 log-ratio 是 $+0.5$，其余 3960 个位置是 $+0.001$，均值约为 $0.00599$，所以 $s_i\approx1.006$。它**仍高于**论文使用的 $1.0004$ 上界；正优势样本会被整条裁剪，而不是因为平均化就落回区间。若局部正负变化大体抵消，均值才可能接近零，序列裁剪也才可能不触发。平均化压低局部波动的影响，但不会保证大幅变化总能穿过裁剪。

序列平均会同时压低信号和噪声, 因而用分辨率换取了较小方差. 路由敏感的 MoE 中噪声占主导时, 平均更有利; 步骤结构清晰、局部信用信号较强时, 逐 token 更新可能保留更多信息. 论文验证的是前一种场景, 后一种场景需要重新比较 (§6.3).

### 5.2. 长度归一的另一面

$s_i$ 对长度归一, 因而两条平均漂移相同但长度差十倍的链获得相同的 clip 处理; 若改用完整序列似然比, 长链的总偏移会大得多. GSPO 选择约束「平均每 token 漂移」. DAPO 的 token-level loss 则按 token 数加权, 长链得到更大权重. 两种方法针对的「长度问题」定义不同: reward 究竟评价整条行为, 还是平均 token 行为. 实践上这个分歧没有看起来大: GRPO 系的 token 级 clip 下, 长链内部的大漂移早被逐位置截停, 实际生效的更新也被压向「平均意见」; GSPO 只是把这个效果显式化. 真正的实验分歧出现在极端长度差的 batch 上, 日常混合 batch 里两者差距有限.

这个「日常差距有限」的判断可以量化验证: 取历史训练的 batch, 分别用两种分母重放梯度, 比较参数更新的余弦相似度. 相似度高于 0.99 就说明在你的数据上这个争论无关紧要, 低于 0.95 才值得专门消融——先测再争论, 是这类「哲学分歧」的标准化解法.

这个方法也适用于 5.1 的「平均抑制集体波动」之争: 与其论证平均对不对, 不如统计训练 batch 中集体波动的占比——占比低, 平均无害; 占比高, 该担心的不是平均, 是路由为什么如此敏感, 那是模型侧的问题. 顺着这个思路, MoE 训练稳定的另一条路线是 router 正则与负载均衡损失的调校, 和 surrogate 的选择正交, 值得并行排查. 工程上这两路的排查成本不同: surrogate 替换要动训练器, router 调校只动模型配置, 先排查成本低的一侧. 当然, 若两路排查完崩溃仍在, 就该回头怀疑「崩溃」的归因本身, 而不是继续叠加补丁.
与 Dr. GRPO 之争的关系。 GRPO 文章 §3 记录过 Dr. GRPO 对 GRPO 的两项批评: 组内标准差归一造成难度偏差, 按回答长度归约造成长度偏差. GSPO 和这组批评的关系微妙. 一方面, GSPO 的序列比率内建了长度归一, 长链的 token 梯度带 $1/|y_i|$ 因子, 和 Dr. GRPO 的方向一致; 另一方面, GSPO 论文保留组内标准差归一的优势构造, 没有采纳 Dr. GRPO 的去归一建议. 也就是说, Qwen 接受了「长度维度」的批评, 没接受「难度维度」的批评. 两类偏差作用的位置不同: 难度归一影响「不同题之间的梯度配比」, 在 Qwen 的生产设置里可能由课程和采样策略缓冲; 长度偏差影响「同题内长短链的判决」, 会直接扰动序列比率并触发训练崩溃. 因此工程修复的优先级取决于实际出现的崩溃模式.

相互矛盾的方法建议可以先还原到各自针对的失效模式. 若系统中没有出现对应症状, 直接叠加修正只会增加耦合; 若症状已经出现, 检查它的存在性通常也比完整的方法对照实验便宜.

## 6. 实验, 边界与选型
论文报告的结果。 论文报告 GSPO 在 Qwen3 系列 (Instruct, Coder, Thinking 及 MoE 变体) 的大规模 RL 中替代 GRPO, 训练稳定性显著改善, MoE 崩溃不再出现, 下游能力持平或更好. 作为方法学证据, 它的分量来自「生产管线全量替换」: 不是消融跑分, 是一个头部团队把主力算法的 surrogate 换掉并公开背书. 序列级实现也简化了工程记录: 每条回答只需存一个 $s_i$, 日志、监控和异常分析都从 token 矩阵降到标量向量, 调试成本随之降低. 这组生产证据没有公开同算力、同数据、只替换 surrogate 的严格对照组. 论文给出的是替换前后的稳定性变化和下游指标, 足以说明 GSPO 在 Qwen3 的规模与架构上可稳定运行, 还不足以推出它在所有模型和数据配方上都优于 GRPO.

论文还提供了生产实现所需的比率定义、裁剪范围和适用模型信息. 这些内容能支持复现, 但不能替代受控消融；方法的可实现性与跨设置的因果结论需要分别验证.

### 6.2. 批评与开放问题

平均 log-ratio 的指数改变了完整轨迹似然比的统计含义，策略滞后较大时尤其需要留意。Qwen 训练中的稳定性收益也同时受学习率、裁剪界和模型路由影响；换架构时应重新量测比率分布。若奖励细化到步骤级，序列级比率仍可计算，但一个共享系数很难表达不同步骤的信用差别。序列奖励与步骤奖励混合时，两个粒度的损失权重还需要分别设定。

「混合粒度 surrogate」正在探索这个空白: 有工作尝试步骤级比率与序列级比率的加权组合, 在保留步骤信号的同时控制方差. 该方向尚无定论, 开源框架 (verl, OpenRLHF) 的 recipe 变化通常比正式论文更早显露工程选择.
选型。 MoE 或路由敏感架构 + 长链推理 + 深复用, 三个条件占两个以上, GSPO 值得作为默认 surrogate 试跑. Dense 模型短链场景, 留在 GRPO/DAPO 生态更省事实验. 无论选哪个, §4.1 的六行对照表都是核对实现的清单, 尤其 clip 量级那一行——它和比率定义绑定, 迁移时必须先重标定. 生产报告还显示了一项论文指标之外的收益: GSPO 的日志从 token 矩阵降到标量后, 某个 prompt 的组内方差异常或单条链的 reward 离群更容易暴露. 团队若长期受 GRPO 调试复杂度影响, 这项可观测性改善本身就可能抵消迁移成本. 评估 surrogate 改动时, 可以把平均异常定位时间与下游指标一起记录; 基建收益常会在前一项上体现.

实现。 7.1 教学实现.

```python
import torch

def gspo_loss(new_logp, old_logp, advantages, mask, eps_low=3e-4, eps_high=4e-4):
    # new_logp, old_logp: [batch, seq]（有效 token 的 log π）
    # advantages: [batch]，序列级优势
    # mask: [batch, seq]，有效 token 为 1
    log_ratio = (new_logp - old_logp.detach()) * mask
    mean_log_ratio = log_ratio.sum(-1) / mask.sum(-1)   # [batch]
    s = torch.exp(mean_log_ratio)
    clipped = s.clamp(1 - eps_low, 1 + eps_high)
    advantages = advantages.detach()
    surr = torch.min(s * advantages, clipped * advantages)
    return -surr.mean()

```
代码把有效 token 的 log-ratio 均值指数化为序列比率，裁剪损失按回答计算。旧策略 log-prob 和优势都应从梯度图中分离。若训练仅需要 GSPO 的序列比率，旧策略侧可保存有效 token 的 log-prob 之和与长度；能节省多少存储，取决于系统是否还要逐 token 的 KL、诊断或其他损失。

三个不变量. 第一, 归一正确性: 构造 mask 不规则的输入 (padding 穿插), 用朴素循环重算 $\sum_t m_t d_t/\sum_t m_t$ 对比向量化结果, 逐位一致. 第二, 长度不敏感性: 把同一条 log-ratio 序列复制成两倍长度 (均值不变), $s$ 必须不变; 这个不变量直接检验「平均而非求和」, 漏除长度是最常见的实现错误. 第三, clip 退化: $\epsilon\to\infty$ 时损失退化为 $-\mathbb{E}[s_i A_i]$, 与解析值对照. 另补一个集成检查: 全链 log-ratio 同号且均值超界时, clip 必须按 $s$ 的整体值触发一次, 而不是按 token 触发 (和 GRPO 实现交叉对比两者的触发计数). 存储上的另一个测试点: 只存 $\sum_t\ell^{old}_{i,t}$ 和 $|y_i|$ 两个标量的实现, 必须能在重新前向时还原 mean log-ratio 到 float32 精度; 半精度下先求和再相减会丢精度, 建议在 log 空间全程 float32 运算, 这一点和 ORPO (1.2.4 节) 的数值纪律相同. 从序列比率反推每个 token 的梯度.

令 $d_t=\log\pi_\theta(y_t\mid x,y_{<t})-\log\pi_{old}(y_t\mid x,y_{<t})$，则 $s=\exp(\frac{1}{T}\sum_t d_t)$。在未触发裁剪且优势为 $A$ 时，单条样本损失为 $L=-sA$，对任一新策略对数概率的导数都是
$$
\frac{\partial L}{\partial\log\pi_\theta(y_t\mid x,y_{<t})}=-\frac{sA}{T}.
$$
因此 GSPO 虽然在序列级构造比率，梯度仍会回到每个有效 token；同一回答内各位置共享相同的序列系数 $sA/T$。mask 后的有效长度必须进入分母，否则 padding 会把长短回答的更新尺度改乱。若 $s$ 落到裁剪平台且被裁剪分支选中，该样本对应方向的梯度变为零，这也是 clip fraction 可以直接反映有效样本利用率的原因。

这个导数还给出一项简单的实现检查：构造长度分别为 4 和 8、平均 log-ratio 与优势都相同的两条回答，单 token 梯度应相差一倍，而整条回答的梯度绝对值之和应接近一致。若两条回答的梯度和也相差一倍，通常是遗漏了 $1/T$；若 padding 位置出现非零梯度，则 mask 在求和或分母处使用错误。

### 6.3. 轨迹概率与序列级裁剪

真正的轨迹 importance ratio. 自回归策略对完整回答的概率为
$$
\pi_\theta(y\mid x)=\prod_{t=1}^{T}\pi_\theta(y_t\mid x,y_{<t}).
$$
因此 current 相对 old 的轨迹概率比为
$$
\rho_{seq}=\frac{\pi_\theta(y\mid x)}{\pi_{old}(y\mid x)}
=\prod_{t=1}^{T}\rho_t,
\qquad
\rho_t=\frac{\pi_\theta(y_t\mid x,y_{<t})}
{\pi_{old}(y_t\mid x,y_{<t})}.
$$
在 log 空间中，$\log\rho_{seq}=\sum_t\log\rho_t$。这是标准轨迹级 importance sampling 的权重；只要行为策略覆盖目标策略支持集，它能把 old 策略下轨迹期望改写成 current 策略期望。问题在于乘积随长度迅速产生极端值。每个 token ratio 仅为 $1.01$，长度一千时乘积也约为 $2.1\times10^4$；每个 token ratio 为 $0.99$ 时则约为 $4.3\times10^{-5}$。 GSPO 定义的序列 ratio 为

$$
s(y)=\left(\rho_{seq}\right)^{1/T}
=\exp\left(\frac1T\sum_{t=1}^{T}\log\rho_t\right)
=\left(\prod_{t=1}^{T}\rho_t\right)^{1/T}.
$$
它是 token ratio 的几何平均，也是每 token 平均 log-ratio 的指数。$s$ 与真正轨迹 importance ratio 的关系为 $\rho_{seq}=s^T$。二者不能互换：$s$ 控制长度归一后的平均策略变化，$\rho_{seq}$ 才是严格的轨迹密度比。 几何平均为何自然出现. 算术平均 $T^{-1}\sum_t\rho_t$ 容易被少数巨大 ratio 主导，也无法保留概率乘法结构。几何平均先在 log 空间累加，再除以长度，描述一条序列上典型的乘性变化率。若每个 token 概率都乘同一个常数 $c$，则 $s=c$，与长度无关。 Jensen 不等式给出

$$
s=\exp\bigl(\mathbb E_t[\log\rho_t]\bigr)
\le \mathbb E_t[\rho_t].
$$
ratio 波动越大，算术平均与几何平均差距越大。例如两个 token ratio 为 $0.5$ 和 $2$，算术平均为 $1.25$，几何平均为一。GSPO 将这条序列视为平均概率尺度未变，但局部概率发生了四倍相对摆动。稳定的序列 ratio 可以与激烈的 token 变化并存。 几何平均还有重复制不变性：将同一 ratio 序列完整复制一遍，$s$ 不变。这个性质消除了单纯长度重复对 clip 的影响，也会掩盖重复模式。模型若把一段异常推理复制十次，局部 ratio 结构相同，$s$ 仍保持原值；reward、长度约束与重复检测仍需承担行为控制。 GSPO ratio 并非严格 importance correction. 用 $s$ 替代 $\rho_{seq}$ 后，目标一般无法严格等价于 current 策略下的轨迹期望。设 $f(y)$ 为任意函数，严格关系为

$$
\mathbb E_{y\sim\pi_{old}}[\rho_{seq}f(y)]
=\mathbb E_{y\sim\pi_\theta}[f(y)].
$$
把权重换成 $s=\rho_{seq}^{1/T}$，右侧不再成立。GSPO surrogate 因此是一种稳定的近端优化目标，通过序列单位与 reward 对齐来获得训练效果，代价是密度比修正的统计含义发生变化。 这一区分在 policy lag 增大时尤其重要。current 与 old 很接近时，令 $\delta_t=\log\rho_t$，则

$$
s=\exp(\bar\delta)\approx1+\bar\delta+\frac12\bar\delta^2.
$$
局部一阶变化由平均 log-ratio 控制，近端区域内可作为平滑代理。数据很旧时，$s$ 仍可能温和，而真实轨迹比 $s^T$ 已经极端，近似的行为解释随之变弱。
序列级裁剪的梯度结构。 同一序列共享一个开关. GSPO surrogate 可写成
$$
L=-\mathbb E_i\left[
\min\left(s_iA_i,
\operatorname{clip}(s_i,1-\epsilon_{low},1+\epsilon_{high})A_i\right)
\right].
$$
未触发裁剪时，$\partial s/\partial\log\pi_\theta(y_t)=s/T$，所以每个有效 token 获得相同的标量系数 $-sA/T$，再乘各自 log-prob 对参数的 Jacobian。序列 reward、序列 advantage、序列 ratio 和序列 clip 在统计单位上对齐。 一旦 $s$ 越过与优势方向对应的边界，整条序列进入平坦区。GRPO 的 token 级裁剪可能只屏蔽若干位置，其余 token 仍更新；GSPO 则共享一个开关。它降低了同一轨迹内部「一些 token 被裁、另一些继续走」造成的梯度碎片，也可能因单个序列均值越界而丢掉全部 token 信号。 正负优势的分段导数. 对 $A>0$，$s\le1+\epsilon_{high}$ 时

$$
\frac{\partial L}{\partial \log\pi_\theta(y_t)}=-\frac{sA}{T},
$$
$s>1+\epsilon_{high}$ 后导数为零。对 $A<0$，$s\ge1-\epsilon_{low}$ 时保持同一形式，$s<1-\epsilon_{low}$ 后归零。论文实验本来就使用不同的左右边界；改边界只移动序列级开关，不会变成逐 token 的局部裁剪。每个 log-prob 的标量导数相同，也不代表参数梯度向量相同：不同位置的 hidden state 和参数 Jacobian 不同。

看一个四 token 的正优势例子：$\rho_t=(1.5,1,1,1)$。若 token 级上界是 $1.2$，第一个位置进入裁剪平台，后三个位置继续产生显式比率梯度；GSPO 的 $s=1.5^{1/4}\approx1.107$，超过论文使用的 $1.0004$ 上界，所以**整条回答**进入平台。几何平均将局部尖峰从 $1.5$ 压到 $1.107$，但这个数对 GSPO 的窄边界仍然太大。

再看 $\rho_t=(1.5,1.5,0.8,0.8)$：几何平均约为 $1.095$。在正优势、token 级上界 $1.2$ 的例子里，前两个位置被裁剪，后两个位置保留；GSPO 在上界 $1.0004$ 时仍将整条回答裁剪。要得到「token 变化很大、GSPO 却不裁剪」的例子，可以取 $(2,0.5)$，此时 $s=1$。但序列梯度并未消失，且 $s=1$ 也不会告诉我们哪一个位置的行为是对的。

### 6.4. 长度效应、方差与策略滞后

平均 log-ratio 的方差. 令 $d_t=\log\rho_t$，均值为 $\mu$，方差为 $\sigma^2$。若不同位置独立同分布，则
$$
\operatorname{Var}(\bar d)=\frac{\sigma^2}{T}.
$$
长序列的平均 log-ratio 更集中，$s=\exp(\bar d)$ 也更稳定。实际 token 强相关，若任意两位置相关系数近似为 $\rho$，则
$$
\operatorname{Var}(\bar d)
=\frac{\sigma^2}{T}[1+(T-1)\rho].
$$
正相关使方差下降变慢；当整条序列受同一参数变化或 MoE 路由扰动影响时，$\rho$ 可显著大于零。GSPO 的稳定性来自平均化，但收益取决于相关结构。 指数变换带来的偏移. 即便 $\bar d$ 的均值为零，$s$ 的均值也可能大于一。若 $\bar d\sim\mathcal N(\mu,v)$，则

$$
\mathbb E[s]=\exp(\mu+v/2).
$$
当 mean log-ratio 为零，指数变换仍可能使平均序列 ratio 高于一；方差越大，上偏越明显。监控最好同时看 $\bar d$ 的均值方差、$s$ 的分位数与两侧裁剪率。若各位置扰动近似独立，短回答的平均值方差较大，更容易撞到裁剪边界；正相关或统一漂移会改变这种长度效应。再看单点异常：只有一个 token 的 log-ratio 为 $a$、其余为零时，$s=\exp(a/T)$。取 $a=\log4$，长度十时 $s\approx1.149$，长度一百时 $s\approx1.014$。后者相对 $1.149$ 已明显缩小，却仍远高于 GSPO 的 $1.0004$ 上界；正优势样本仍会被整体裁剪。

可增加辅助约束，例如监控 $\max_t|d_t|$、高分位数或局部窗口均值。若把这些量直接加入裁剪目标，又会重新引入 token 或片段级开关，需要通过消融判断是否破坏 GSPO 的序列一致性。监控与优化约束应分开讨论。 长度随机变量与目标权重. 同一 prompt 可能生成不同长度。GSPO 对每条序列使用平均 log-ratio，再对回答取平均，序列作为基本单位等权；单 token 显式梯度含 $1/T$，整条序列的显式权重和约为 $sA$。这与 DAPO token-level loss 的按 token 聚合不同。 如果长推理确实包含更多必要决策，序列等权可能让单步学习信号过小；若长推理主要是冗余，等权能避免其因 token 多而支配 batch。GSPO 的长度归一解决 ratio 尺度问题，同时作出了序列等权选择。两个选择可以拆开实验，不应把所有收益都归于几何平均。
策略滞后时，长度归一后的 $s$ 与完整轨迹比率可能相差很大。若平均每 token log-ratio 为 $0.01$，则 $s=e^{0.01}\approx1.010$，而长度两千的完整轨迹比率为 $e^{20}$。这里 $s$ 对完整轨迹比率已显著缩小，但对论文的 $1.0004$ 上界依然过大；正优势样本会被裁剪。若正负 log-ratio 互相抵消，$s$ 才可能落在区间内，而完整轨迹中的局部概率变化仍值得监控。多 epoch 复用同一批轨迹时，可按生成版本记录 $\bar d$、最大 token log-ratio、序列裁剪率，以及与新鲜 rollout 梯度的差异。采样温度也属于行为策略的一部分。

采样温度、top-p、top-k 和语法约束共同定义 old 行为分布。保存基模型未调温 log-prob 作为分母，会得到错误 ratio。温度 $\tau$ 下的行为分布为
$$
q_{old}(a\mid s)=\frac{\exp(z_a/\tau)}{\sum_b\exp(z_b/\tau)}.
$$
分母应使用 $q_{old}$ 的真实 log-prob。动态调整温度时，每条轨迹绑定自己的解码配置。不同配置混合后，几何平均仍能计算，但统计分布不同，最好按 sampler 分桶监控。

### 6.5. MoE 路由与相邻方法边界

路由变化进入概率比. MoE 模型中，token hidden state 经 router 选择专家。参数更新、负载均衡和并行数值误差都可能改变边界附近 token 的专家组合，进而使某些位置 logits 突变。相邻 token 因内容不同进入不同专家，ratio 波动呈现位置依赖。 token 级裁剪逐点决定是否保留梯度，一条正优势序列可能留下零散 token 更新。它们继续改变路由边界，下一轮又产生新的 ratio 尖峰，形成不稳定反馈。GSPO 将整条回答的平均变化作为一个权重，使局部路由抖动在 log 空间平均，论文报告其对大规模 MoE 训练更稳定。 集体变化仍会穿过聚合. 若某一专家影响整段推理，多个 token 的 log-ratio 同号，平均后仍明显偏移，GSPO 会裁剪整条序列。平均只抑制局部零均值波动，无法消除一致漂移。这是合理性质：整条行为分布确实发生变化时，近端约束应触发。

可以把 $d_t$ 分解为序列公共项 $c$ 与局部扰动 $\eta_t$：
$$
d_t=c+\eta_t,\qquad \mathbb E_t[\eta_t]=0.
$$
GSPO 的 $\bar d=c$，局部扰动被平均掉；token 级方法同时响应 $c$ 和每个 $\eta_t$。若 $\eta_t$ 代表数值噪声，GSPO 有益；若它代表关键局部策略变化，被消除的正是有意义信号。需要通过路由日志与行为案例区分。 Dense 模型同样可能受益. 注意力、归一化、量化和长序列位置变化也会制造 token ratio 长尾，因此 GSPO 不局限于 MoE。MoE 只是让问题更突出。Dense 模型若 token ratio 平滑、policy lag 小，序列与 token 目标差距可能有限；这时替换 surrogate 的收益需要实验确认。
与 GRPO、DAPO 的机制关系。 三者改动的坐标. GRPO 用组内 reward 构造序列 advantage，常见实现却在 token 层计算 ratio、裁剪和归约。DAPO 保留 token ratio，加入非对称裁剪、动态采样、token-level loss 与超长塑形。GSPO 将 ratio 与裁剪提升到序列层，重新对齐 reward 与优化单位。 三者共享组相对估计，因而都面对全同组、reward 噪声与 prompt 选择问题。GSPO 并未自动提供 dynamic sampling，也未解决长度 reward 和验证器错误。DAPO 的数据与 reward 机制可与 GSPO 组合，但 token-level loss 与序列等权之间需要明确选择。 GSPO 与 Clip-Higher. 非对称边界可以直接作用于 $s$：正优势使用 $1+\epsilon_{high}$，负优势使用 $1-\epsilon_{low}$。由于 $s$ 的方差通常比单 token ratio 小，沿用 DAPO 的数值区间可能过宽。应根据 sequence ratio 分位数重新选择，而非复制 token 级超参数。 若正侧 sequence clip fraction 本来接近零，进一步放宽上界不会恢复多少样本，只会允许少数极端序列走得更远。有效性证据应包含边界附近的样本密度、解锁比例和对应外部收益。 GSPO 与 Dynamic Sampling.

Dynamic sampling 改变进入更新的 prompt 分布，GSPO 改变保留组的梯度权重。两者作用层不同，可以组合。全同组被过滤后，sequence ratio 的方差估计来自更窄的中等难度分布，clip 参数可能随课程变化失配。 训练期间按全对、全错和有效组分别记录 ratio，即便前两者不更新。若困难全错组具有更大 policy lag 或更长回答，过滤会让总体 ratio 看起来更稳定。监控仅覆盖训练组会低估真实生成分布的不稳定性。 GSPO 与 Token-Level Loss. GSPO 论文中的序列目标让每条回答贡献一个 surrogate。若把 $s_iA_i$ 再广播到 token 并按全 batch token 平均，长回答重新获得更大总权重，形成「序列 ratio、token 加权」的混合目标。它在数学上可定义，却不再保持序列等权。

混合目标可能适合长链任务，也可能让长回答支配。实验需分离两因素：固定 sequence ratio，比较序列平均与 token 平均；再固定归约，比较 token ratio 与 sequence ratio。四格实验比直接比较 GRPO 与 GSPO 更能定位收益。
