# 组内估计

## 1. 基线、组采样与有限样本误差

组内方法的核心问题，是怎样用同一提示下的有限回答近似条件期望。下面从基线恒等式开始，再进入自相关、二值奖励、样本相关性和异常值；这些对象共同决定估计器的偏差与方差。

策略梯度中的 score function 满足
$$
\mathbb E_{a\sim\pi(\cdot\mid s)}
[\nabla_\theta\log\pi_\theta(a\mid s)]=0.
$$
所以从回报中减去只依赖状态的 $b(s)$，不会改变期望梯度。方差最小的标量基线并非简单的平均回报；若 score 的模长随动作变化，最优基线还会按 $\lVert\nabla\log\pi\rVert^2$ 加权。价值函数 $V^\pi(s)$ 是常用近似，因为它给出条件平均回报，而且可以跨多次访问共享统计强度。

语言模型中，同一提示 $x$ 采样多条回答，相当于在近似相同起始状态下观察多个回报。组均值可作为 $V(x)$ 的蒙特卡洛替代，不需要训练独立 critic。它只估计提示级基线，无法估计回答生成到一半时的前缀价值；终局奖励仍被广播到整条序列。

### 1.1. 包含自身会产生什么偏差

令 $G$ 条独立回报为 $R_1,\ldots,R_G$。包含自身的组均值给出
$$
R_i-\bar R=\left(1-\frac1G\right)R_i
-\frac1G\sum_{j\ne i}R_j.
$$
当前样本的系数从 $1$ 缩到 $(G-1)/G$。若直接把它乘在当前样本 score 上，期望梯度也按这个系数缩放；固定组大小时可被学习率吸收，但不同组大小、过滤后有效样本数变化时，缩放不再统一。leave-one-out 基线

$$
b_{-i}=\frac1{G-1}\sum_{j\ne i}R_j
$$
与当前动作条件独立，在同分布采样假设下保留无偏性。它的方差取决于其他 $G-1$ 个样本，组越大，基线均值越准确，生成预算也线性增长。

组内标准差又加入随机分母。标准化获得奖励平移与正比例缩放不变性，却不再只是简单 baseline；同组极端值会同时改变所有样本幅度。$G$ 较小时，样本标准差本身波动很大，$\epsilon$ 的数值会直接决定近零方差组的梯度尺度。

### 1.2. 二值奖励可以完整手算

假设组内 $k$ 条成功、$G-k$ 条失败，成功率为 $p=k/G$。若用总体方差口径，标准差为 $\sqrt{p(1-p)}$。成功样本优势为
$$
A_+=\frac{1-p}{\sqrt{p(1-p)}}
=\sqrt{\frac{1-p}{p}},
$$
失败样本优势为 $A_-=-\sqrt{p/(1-p)}$。当只有一条成功时，成功样本权重大，许多失败样本各自权重较小；两类总优势仍相互抵消。当 $k=0$ 或 $k=G$ 时，分母和分子同时为零，整组没有排序信息。

这也揭示提示权重的变化。每个提示最终贡献多少，不只由平均 reward 决定，还由组内成功数、回答长度和 loss reduce 决定。接近全对或全错的组一旦仍有单个异类，异类会得到很大标准化优势；加入固定 $\epsilon$ 可以限制幅度，却破坏严格尺度不变性。
组采样为何不天然独立。 同一随机种子、共享前缀缓存、确定性解码或低温采样会让回答高度相关。名义组大小为 $G$，有效独立样本数可能远小于 $G$。如果答案都来自同一种推理模板，组均值无法代表策略分布的真实方差，增加样本数只会重复同一模式。

多样性控制应对应任务结构。提高全局温度会同时扰动高层方案与低层算术；按答案去重只看最终字符串，可能保留语义相同的推理；基于轨迹分支或程序行为的去重更接近探索对象。评估组采样质量时，可以报告独立答案数、语义簇数、奖励相关性和前缀分叉位置。
提示分布与零方差组。 设原始提示分布为 $q(x)$，训练过滤掉全同奖励组，相当于按事件「本组含有至少两种奖励」重加权。二值奖励下，该事件概率为
$$
1-p_x^G-(1-p_x)^G.
$$
它在 $p_x$ 居中时最大，在极易和极难提示上接近零。过滤提高每批有效梯度密度，也把目标集中到当前策略能力边界附近。策略能力变化后，重加权分布随之移动，形成动态课程。

若希望保留原始任务权重，可以记录每个难度桶的采样与丢弃概率，再做重要性校正；权重可能具有高方差，实践中常接受目标变化。此时评测必须回到固定原始分布，避免把课程分布上的奖励上升误当成全任务改进。
相关样本下的有效组大小。 组内回答若两两相关，方差下降不会按 $1/G$ 发生。设每条回报方差为 $\sigma^2$，任意两条回报的相关系数近似为 $\rho$，则组均值方差为
$$
\operatorname{Var}(\bar R)=\frac{\sigma^2}{G}\bigl(1+(G-1)\rho\bigr).
$$
可把它写成 $\sigma^2/G_{\rm eff}$，得到有效组大小
$$
G_{\rm eff}=\frac{G}{1+(G-1)\rho}.
$$
当 $\rho=0$ 时恢复独立样本；当 $\rho$ 接近 $1$，无论名义上采多少条，有效样本数都接近一。低温解码、相同高概率前缀和模式坍缩都会提高相关性。增加组大小之前，先提高轨迹分支多样性，可能获得更高的信息增益。

相关性也影响留一基线。其他 $G-1$ 条回答如果和当前回答共享大量随机因素，基线可以消除提示难度和共同模式带来的波动；如果相关性来自重复同一错误路径，它也会让组内缺少反事实差异。前者是有益的 common random numbers，后者是覆盖不足，两者要通过前缀分叉位置和语义簇来区分。
连续奖励中的异常值。 连续验证分数可能带有重尾。一个异常高奖励同时抬高组均值与标准差，其余正常样本的标准化优势会被压缩；若异常值来自验证器漏洞，它还会获得强正更新。对奖励做 winsorize 或 rank transform 能限制异常值影响，却会改变原始效用间距。

排序优势只保留次序，对任意单调变换不敏感，适合奖励刻度不可靠的场景；它无法表达第一名远好于第二名的幅度。稳健均值、median-of-means 等估计器保留部分尺度信息，但小组内统计效率有限。选择之前应先看奖励分位数、异常值的语义内容及其跨批次复现情况。

推理模型的强化学习通常会对同一个问题采样多条回答。这样做不只是为了提高撞到正确答案的概率，更重要的是得到一个可比较的小型样本集：同一道题、同一个策略版本、相同采样配置下，哪些回答比同组回答更好？如果答案可以由规则验证器打分，那么组内差异就能代替一部分价值函数的工作。GRPO 与 RLOO 都建立在这层直觉上，但它们对「基线里能不能包含当前样本」以及「要不要按组内标准差缩放」给出了不同答案。

## 2. 先把问题写清楚

对提示 $x$，旧策略一次生成 $G$ 条回答 $y_1,\ldots,y_G$，验证器给出奖励 $r_1,\ldots,r_G$。策略梯度用奖励相对基线的差构造优势。基线不改变期望梯度的前提，是它不能依赖当前被乘上的随机动作；有限样本实现里，不同基线会带来不同偏差、方差与样本耦合。组内估计处理的正是这件事。

最常见的组均值与标准差写法为
$$
\bar r=\frac{1}{G}\sum_{j=1}^{G}r_j,\qquad
s_r=\sqrt{\frac{1}{G}\sum_{j=1}^{G}(r_j-\bar r)^2+\epsilon}.
$$
GRPO 常用 $A_i=(r_i-\bar r)/s_r$，把同题奖励转成相对位置。它省去了单独训练 critic，也让不同难度题目的奖励尺度更接近。不过标准差并不是无害的单位换算：容易题若组内奖励全相同，梯度会消失；标准差很小时，少数差异会被放大；不同题目的更新权重也会随组内离散程度变化。因此，理解 GRPO 不能停在「PPO 去掉价值模型」这句话上，必须同时检查采样组、归一化、全同组过滤、token 聚合与裁剪。

RLOO 使用 leave-one-out 基线：
$$
b_{-i}=\frac{1}{G-1}\sum_{j\ne i}r_j,\qquad A_i=r_i-b_{-i}.
$$
当前样本不参与自己的基线，使估计量与经典 REINFORCE 控制变量的条件更容易对齐。它不按组内标准差归一化，因而保留奖励尺度，但也更依赖奖励校准和 batch 组织。二者并不是谁全面替代谁：GRPO 更像一套围绕组相对奖励形成的训练骨架，RLOO 更像对基线估计条件的直接坚持。

### 2.1. 组大小不是普通超参数

$G$ 增大时，组均值或 leave-one-out 均值更稳定，也更可能采到正负奖励并存的有效组；代价是 rollout 数量、解码 token、验证器执行和缓存占用近似同步增长。若固定总生成预算，增加每题样本数意味着减少 prompt 多样性。前者改善单题内的比较，后者决定训练分布覆盖，两者不能只用最终准确率判断。

二值奖励尤其容易暴露这个矛盾。设单次答对概率为 $p$，一组全部同奖的概率是 $p^G+(1-p)^G$。当模型对一批题几乎总对或总错时，继续增加这类 prompt 的组大小未必产生有效梯度。训练系统往往需要动态采样、难度分桶或全同组过滤，但过滤会改变实际训练分布：日志里必须同时记录原始 prompt 分布、过滤率和进入更新的数据分布。

## 3. 从估计量走到实现

阅读实现时先核对五件事。第一，组是在单个 prompt 内形成，还是跨 prompt 混合统计；后者会把题目难度差异误当作回答质量。第二，标准差是按组、按 batch 还是跨设备计算，分布式 all-reduce 的边界会直接改变数值。第三，优势是序列级复制到每个 token，还是结合 token 级奖励重新分配。第四，损失按 token 平均还是先按序列平均，回答长度会因此获得不同权重。第五，rollout 的 old log-prob 与训练时重新计算的 log-prob 是否来自同一模型版本、同一模板和同一 mask。

一个最小数值例子足以检查符号。四条回答奖励为 $[1,1,0,0]$ 时，组均值为 $0.5$。GRPO 在忽略 $\epsilon$ 时给正样本相同正优势、负样本相同负优势；RLOO 对第一条正样本使用其余三条的均值 $1/3$，优势为 $2/3$，对一条负样本使用其余三条均值 $2/3$，优势为 $-2/3$。若代码算出相反符号，通常是 winner/loser、reward 或最小化损失的负号混淆。

### 3.1. 阅读顺序

先读 [GRPO](./3.1.1-grpo.md)，建立组采样、标准化优势、PPO 式代理目标和长度偏差的完整链条；再读 [RLOO](./3.1.2-rloo.md)，比较 leave-one-out 基线与组标准化在统计条件上的差别。之后进入「稳定优化」，观察 DAPO、GSPO、GMPO 与 GDPO 如何修改采样、裁剪、聚合和多奖励归一化。这样读，后续算法就不会变成一串缩写，而会落回同一组可检查的问题：样本从哪里来、基线如何估、权重落在哪个粒度、哪些样本最终贡献了梯度。

## 4. 验收边界

复现实验至少应报告组大小、温度、top-p、最大生成长度、每题有效回答数、全同组比例、奖励各分项、优势均值与方差、正负裁剪比例，以及按回答长度分桶后的梯度贡献。只报告训练奖励上升无法区分模型真的学会推理、验证器被利用，还是采样分布变简单。组内估计的价值在于减少价值模型负担，但它没有消除分布偏移、奖励投机和实现不一致；这些边界必须与最终 benchmark 一起观察。

### 4.1. 容易混淆的三个层次

第一层是奖励中心化。减去组均值只是在同题内部建立相对坐标，它没有说明更新应该按什么尺度进行。第二层是尺度归一。除以标准差会让离散程度不同的题获得相近量级的优势，但也会重写题目间权重。第三层是损失聚合。即使两份实现得到完全相同的优势，只要一个按全部有效 token 求均值、另一个先按序列再按 batch 求均值，长回答的贡献就不同。讨论「GRPO 是否有长度偏差」时，必须指明说的是哪一层。

还要分清采样独立与实现独立。同题回答通常从同一策略独立采样，但它们进入组均值后，优势已经相互耦合。某条回答的奖励改变，会同时改变其他回答的优势。这种耦合正是相对比较的来源，也意味着不能把组内的 $G$ 条回答当成 $G$ 个完全独立训练样本来估算有效样本量。

## 5. 一个训练批次怎样流动

系统先选择一批 prompt，为每题生成固定或动态数量的回答；验证器分别产出正确性、格式或执行结果；聚合器在 prompt 边界内形成奖励向量；优势模块计算组均值、标准差或 leave-one-out 基线；训练端用保存的 old log-prob 与当前 log-prob 形成比率，再应用裁剪、mask 与聚合。任何一步丢失 prompt 分组 ID，都会让后面的统计失去含义。

分布式训练时尤其要确认组是否跨 rank 拆开。如果一个 prompt 的回答分布到多张卡，而优势只在本地 rank 计算，同一组会得到多个不一致均值。正确做法可能是让组保持共置，也可能是显式通信后再统计；两种方案性能不同，但数值语义必须相同。检查方法很简单：用手工构造的小 batch 在单卡和多卡各跑一次，比较每条样本的奖励、优势和最终 loss，而不只是比较总均值。

### 5.1. 什么时候不适合组内方法

若任务奖励无法可靠自动判定、每个 prompt 只能负担一次生成、不同回答不能放在同一尺度比较，组内估计的优势会明显减弱。极小组也可能让估计高度离散，二值奖励下尤为明显。此时 critic、跨批次基线、过程监督或偏好数据也许更合适。选择方法的依据应是反馈结构和采样预算，而不是算法名称的新旧。

反过来，当验证器可靠、同题可并行采样、生成系统吞吐充足时，组内方法提供了非常直接的闭环。它把训练问题压缩为几项可测量对象：组内成功率、有效差异、基线方差、裁剪比例和单位生成 token 的能力增益。围绕这些量做实验，比围绕单一总奖励调参更容易找到真正瓶颈。

组大小也会改变单位预算的信息密度。固定总生成 token 时，增大每题样本数意味着减少提示数：前者改善同一状态下的相对比较，后者扩大任务覆盖。若提示间难度方差远大于同题回答方差，多覆盖提示更有价值；若主要噪声来自同题随机生成，多采样能得到更准基线。可以用分层方差分解
$$
\operatorname{Var}(R)=\operatorname{Var}_x(\mathbb E[R\mid x])
+\mathbb E_x[\operatorname{Var}(R\mid x)]
$$
估计预算应投向提示数还是组大小。第一项描述题目差异，第二项描述同题采样差异。这个分解比固定采用某个组大小更能迁移到新任务。

分层抽样还可以直接利用该分解：难度桶之间按任务权重分配提示，桶内再按条件方差分配组大小。这样既不让简单题数量淹没困难题，也避免给几乎确定全对或全错的提示持续追加无信息样本。
