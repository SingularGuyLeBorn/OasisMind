## 使用示例
```json
// 组合键 + 间隔
{ "target": "window", "windowTitle": "记事本", "keys": ["ctrl", "a"], "interval": 30 }

// 组合键后接文本（需分两步：先组合键，再 Type text）
{ "target": "window", "windowTitle": "记事本", "keys": ["ctrl", "v"] }
{ "target": "window", "windowTitle": "记事本", "text": "粘贴后追加内容", "interval": 20 }
```

## 注意事项
- `interval`：键与键之间延迟（ms），默认 20。组合键建议 30-50 确保修饰键生效。
- 修饰键顺序：`["ctrl", "shift", "key"]` 会按顺序按下，释放时逆序。
- 部分应用对 `win` 键拦截不同，实测为准。
- UWP 应用可能不响应部分系统级组合键。
